The trading system based on crossing of the DI+ and DI- lines of the
Fractal_ADX_Cloud
indicator. The signal is formed when a bar is closing if there is crossing of red and green lines of the indicator.
Place Fractal_ADX_Cloud.ex5 and Fractal_ADX_Cloud_HTF.ex5 compiled files to the
<terminal_data_folder>\MQL5\Indicators
.
The Fractal_ADX_Cloud_HTF indicator in the EA is intended only for a more convenient visualization of trends in the strategy tester, in other operation modes it is inactive.
After compilation, the Exp_Fractal_ADX_Cloud.ex5 expert file contains the Fractal_ADX_Cloud.ex5 and Fractal_ADX_Cloud_HTF.ex5 indicators as
resources
,
and therefore, they are not required to be present in the terminal folder for the compiled EA to work! For this purpose, the corresponding code has been added to the EA code in order to include these indicators in the expert's executable file.
The indicator executable files have been added as resources at the global scope
//---- Include the indicators in the EA code as resources
#resource
"\\Indicators\\Fractal_ADX_Cloud.ex5"
#resource
\\Indicators\\Fractal_ADX_Cloud_HTF.ex5
