The Expert Advisor Exp_XMACD based on the signals received from the
XMACD
universal histogram. The signal is formed when a bar is closing if there is breakthrough in MACD histogram of a zero level or there is change in histogram direction or signal line and if also is breakthrough in signal line histogram (depending on the options selected in the input parameter Mode).
Place XMACD.ex5 compiled file to the terminal_data_folder\MQL5\Indicators.
Default Expert Advisor's input parameters have been used during the tests shown below. Stop Loss and Take Profit have not been used during the tests.
