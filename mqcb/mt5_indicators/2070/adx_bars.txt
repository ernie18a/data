The indicator changes the bar color to the color of the current trend calculated based on the
ADX
technical indicator. If the trend and candlestick direction match, the color of the bar is light, if opposite, the bar is dark.
Originally this indicator has been written in MQL4 and was first published in the
Code Base at mql4.com
on 31.10.2007.
