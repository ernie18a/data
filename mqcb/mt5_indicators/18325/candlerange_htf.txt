The
CandleRange
indicator with the timeframe selection option available in the indicator input parameters:
input
ENUM_TIMEFRAMES
TimeFrame=
PERIOD_H4
;
// Indicator chart period (timeframe)
To provide correct operation of the indicator, add the compiled CandleRange.mq5 indicator file to terminal_data_folder\MQL5\Indicators.
