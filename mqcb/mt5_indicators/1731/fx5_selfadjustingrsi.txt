The RSI oscillator with the boundaries of the overbought/oversold areas expressed by Bollinger Bands.
Indicator input parameters:
//+-----------------------------------+
//|  INDICATOR INPUT PARAMETERS       |
//+-----------------------------------+
input
uint
Length=
12
;
// RSI period
input
ENUM_APPLIED_PRICE
RSIPrice=
PRICE_CLOSE
;
// RSI timeseries price
input
double
BandsDeviation=
2.0
;
// deviation
input
bool
MA_Method=
true
;
// used smoothing for Bollinger Bands
input
int
Shift=
0
;
// Horizontal shift of the indicator in bars
