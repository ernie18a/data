The indicator shows a text block with the values ​​of the user defined
RVI
oscillator period for each timeframe. The size of the text block is customizable. You can also change the text font and disable the display of unused timeframes. The maximum number of simultaneously displayed indicators is ten. The color of the text block depends on the position of the RVI indicator relative to overbought and oversold zones, which are set in the indicator input parameters.

0.22

clrDarkGreen
;
// overbought color
input
color

clrDarkKhaki
;
// no-trend color
input
color
LowColor=
clrPurple
;
// oversold color
