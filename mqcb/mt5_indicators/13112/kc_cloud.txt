Cloud channel based on Moving Averages and Average True Range.
Indicator input parameters:
input
PriceMode Mode=MODE_HIGHLOW;
// Prices calculation method
//---- Moving Average parameters
input
Smooth_Method XMA_Method=
MODE_SMA
;
// Averaging method
input
int
XLength=
12
;
// Smoothing depth
input
int
XPhase=
15
;
// Smoothing parameter
// for JJMA it varies within the range -100 ... +100 and influences the quality of the transient process;
// for VIDIA it is a CMO period, for AMA it is a slow average period
//---- ATR parameters
input
uint
ATRPeriod=
13
;
input
double
ATRFactor=
1.5
;
input
int
Shift=
0
;
// Horizontal indicator shift in bars
The indicator uses the classes of the SmoothAlgorithms.mqh library. Working with these classes was described in details in the article
"Averaging Price Series for Intermediate Calculations Without Using Additional Buffers"
.
