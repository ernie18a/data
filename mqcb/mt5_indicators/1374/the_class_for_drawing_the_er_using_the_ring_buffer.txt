Description
The CEROnRingBuffer class is designed to calculate the technical indicator Efficiency Ratio (ER) used in the Adaptive Moving Average
(
Adaptive Moving Average
, AMA) using the algorithm of
the ring buffer
.
Declaration
class
CEROnRingBuffer :
public
CArrayRing
Title
#include <IncOnRingBuffer\CEROnRingBuffer.mqh>
File of the CEROnRingBuffer.mqh class must be placed in the IncOnRingBuffer folder that need to be established in MQL5\Include\. Two files with the examples used by the class from this folder are attached to the description. File with the class of
the ring buffer
also must be in this folder.
