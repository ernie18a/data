Description
The CAMAOnRingBuffer class is designed for calculation of the technical indicator
Adaptive Moving Average (
Adaptive Moving Average
, AMA)
using the algorithm of
the ring buffer
.

CAMAOnRingBuffer :
public
CArrayRing
Title
#include <IncOnRingBuffer\CAMAOnRingBuffer.mqh>
File of the CAMAOnRingBuffer.mqh class must be placed in the IncOnRingBuffer folder that need to be established in MQL5\Include\. Two files with the examples used by the class from this folder are attached to the description. File of the class of
the ring buffer
and the class of
Efficiency Ratio
also must be in this folder.
