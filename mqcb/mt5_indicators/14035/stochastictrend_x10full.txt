A variant of the
StochasticTrend_x10
indicator with the option to individually customize the input parameters for each Stochastic oscillator which are used to display the current trends.
The indicator uses a class of the
GetFontName.mqh
library (should be copied to the <terminal_data_folder>\MQL5\Include).
