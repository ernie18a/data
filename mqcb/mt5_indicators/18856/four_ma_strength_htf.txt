The
Four_MA_Strength
indicator with the timeframe selection option available in input parameters:
input
ENUM_TIMEFRAMES
TimeFrame=
PERIOD_H4
;
// Indicator chart period (timeframe)
The indicator requires the Four_MA_Strength.mq5 indicator file. Save it to <terminal_data_folder>\MQL5\Indicators.
