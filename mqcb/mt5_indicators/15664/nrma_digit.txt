Famous indicator by Konstantin Kopyrkin, it produced numerous realizations of the NRTR indicator. It displays the most recent value as a price label with the possibility to round the channel levels up to a required number of digits. The number of digits to round is set in the
Digit
input:
input
uint
Digit=3;
//Number of digits to round to
The indicator uses SmoothAlgorithms.mqh library classes (copy it to <terminal_data_folder>\MQL5\Include). The use of the classes was thoroughly described in the article
"Averaging Price Series for Intermediate Calculations Without Using Additional Buffers"
.
This indicator was first implemented in MQL4 and published in
Code Base at mql4.com
on 19.08.2006.
