A variant of the
SSL
indicator performed in the form of the channel and represented as the colored cloud. The indicator submits alert when the trend changes its direction.
Indicator input parameters:
//+----------------------------------------------+
//| Indicator input parameters                   |
//+----------------------------------------------+
input
uint
period=
13
;
// Moving averages period
input
bool
NRTR=
true
;
// NRTR form
input
int
Shift=
0
;
// Horizontal shift of the indicator in bars
input
uint
AlertCount=
0
;
// Number of submitted alerts
input
uint
AlertBar=
0
;
// The bar, from which the alert is
