Three Bollinger Bands channels based on one moving average, drawn as a colored cloud, with the display of the last values as price labels and the possibility to round Bollinger levels up to a required number of digits. The number of digits to round is set in the
Digit
input:
input
uint
Digit=
2
;
//Number of digits to round to
The indicator uses SmoothAlgorithms.mqh library classes (copy it to <terminal_data_folder>\MQL5\Include). The use of the classes was thoroughly described in the article
"Averaging Price Series for Intermediate Calculations Without Using Additional Buffers"
.
