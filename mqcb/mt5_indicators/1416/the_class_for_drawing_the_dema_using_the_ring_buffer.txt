Description
The CDEMAOnRingBuffer class is designed for calculation of the technical indicator Double Exponential Moving Average (
Double Exponential Moving Average
, DEMA) using the algorithm of
the ring buffer
.
Declaration
class
CDEMAOnRingBuffer :
public
CArrayRing
Title
#include <IncOnRingBuffer\CDEMAnRingBuffer.mqh>
File of the CDEMAOnRingBuffer.mqh class must be placed in the IncOnRingBuffer folder that need to be established in MQL5\Include\. Two files with the examples used by the class from this folder are attached to the description. File with the classes of
the ring buffer
and the
Moving Average
also must be in this folder.
