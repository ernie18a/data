The
XXRSX
indicator with additional trend strength indication using colored dots based on the standard deviation algorithm.
If the standard deviation of the XXRSX indicator is higher than the dK input parameter value, then a colored dot appears on the moving average. Its color corresponds to the current trend direction.
input
double
dK=
2.0
;
// Square-law filter coefficient
The indicator uses SmoothAlgorithms.mqh library classes (copy it to <terminal_data_folder>\MQL5\Include). The use of the classes was thoroughly described in the article
"Averaging Price Series for Intermediate Calculations Without Using Additional Buffers"
.
