Features
GUI Buttons
: "Close Buys" and "Close Sells" with customizable colors, positions, and text.
Dynamic Visibility
: Hides buttons when no positions exist (optional).
Position Closure
: Closes all buy/sell positions on button click; shows net profit (profit + swap + commission).
Event Handling
: Uses 100ms timer for updates and chart events for clicks.
Profit Calculation
: Computes net profit, including commission from trade history.
Use Case
Simplifies closing positions for traders on a specific symbol.
