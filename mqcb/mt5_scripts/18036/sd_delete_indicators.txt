The script allows to quickly remove indicators from charts. It has two operating modes:
ONLY_THIS_CHART
- only delete from the current chart (used by default);
ALL_CHARTS
- delete from the current chart and all other charts opened in the trading platform.
Note
: before using this scripts, it is may be sometimes useful to run the
SD W indicators and charts
script, which displays information about all running indicators in the Experts tab. This can prevent you from removing useful information before you save necessary combinations and manual settings of running indicators.
