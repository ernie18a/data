Sometimes it's simple to forget the experts and their setting, especiallty in a case of the simultaneous use of a large number of experts.
We have to open the expert properties for each chart. It's tiresome. Now I can easily see which advisor on the chart and even save the history.
This script creates the file
Expert List.htm
in \experts\files folder. The same advisors are grouped into a single table with the following parameters: chart, period, trade allow option, etc.
It can show up to 20 expert advisor parameters. If you need more - not problem, just increase the size of the
param
array - but remember that each additional parameter needs two array elements.
