This EA will set BUY Stop and SELL Stop (pending order) on next opening candle then will delete one pending order after open BUY or SELL occur (OCO).
This EA will follow candle movement for each tick to catch candle movement by setting BUY STOP and SELL STOP
Use small time frame 1M-5M for this EA
Users can set the EA options, there is clear explanations on each options, read carefully before apply
Distance : pips distance for BUY/SELL stop from current open price
Expiration: expire minutes after opening BUY/SELL stop if BUY/SELL event not hit
EA runs base on server time, thus users MUST calculate time difference from your local time or time on
http://www.forexfactory.com/calendar.php
events time which usually set to match your local time.
