Exp_X2MA_Digit_DM_361 trend-following trading system is based on
ColorX2MA_Digit
and
ColorDM_361
indicator signals. ColorX2MA_Digit indicator is used to define the main slow trend direction, while ColorDM_361 indicator allows us to define an entry point when a fast trend direction is changing. An entry signal is generated at a bar closure if the following two conditions are met:
Fast and slow trend signals coincide;
Fast trend has changed its direction.

String variables containing text in the inputs code are included only for better visual display of the EA inputs window.
ColorDM_361_HTF and ColorX2MA_Digit_HTF indicators in the EA are included only for more convenient trend visualization in the strategy tester. They are not used in other operation modes.
Place ColorX2MA_Digit.ex5, ColorX2MA_Digit_HTF.ex5, ColorDM_361.ex5 and ColorDM_361_HTF.ex5 compiled files to the <terminal_data_folder>\MQL5\Indicators for the generated EA correct operation.

together with position opening
