This is a classic trading strategy based on Parabolic SAR indicator. It has AutoLot options and built-in Trailing Stop.
This code can be used in both MetaTrader5 and MetaTrader4.
Just change the file extension from .mq5 to .mq4
and compile the file in MetaEditor.
This expert advisor is designed with
visual strategy builder -
Mission Automate. Code is generated automatically. More info:
https://www.mql5.com/en/articles/4951
This EA is available as a template in a free demo version, so you can easily modify / customise it without programming.
