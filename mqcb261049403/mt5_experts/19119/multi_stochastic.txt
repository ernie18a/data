The Expert Advisor allows trading based on the iStochastic (Stochastic Oscillator) indicator signals four financial symbols at a time. Symbol names, as well as Stop Loss and Take Profit levels are set in input parameters:
Use symbol #1
- allow or prohibit using symbol #1
The symbol name #1
- the name of symbol #1
Use symbol #2
- allow or prohibit using symbol #2
The symbol name #2
- the name of symbol #2
Use symbol #3
- allow or prohibit using symbol #3
The symbol name #3
- the name of symbol #3
Use symbol #4
- allow or prohibit using symbol #4
The symbol name #4
- the name of symbol #4
Stop Loss (in pips)
- Stop Loss value
Take Profit (in pips)
- Take Profit value
magic number
- Expert Advisor identifier
