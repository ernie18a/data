The simplest EA based on the
Fractal_WeightOscillator weighted oscillator
. Sells at downward crossing of the oscillator overbought level, buys at the upward crossing of oscillator oversold level. The signal is formed at the close of a bar, if the level is crossed.
The Fractal_WeightOscillator_HTF indicator in the EA is intended only for a more convenient visualization of trends in the strategy tester, in other operation modes it is inactive.
Place Fractal_WeightOscillator.ex5 and Fractal_WeightOscillator_HTF.ex5 compiled files to the
<terminal_data_folder>\MQL5\Indicators
.
After compilation, the Exp_Fractal_WeightOscillator.ex5 expert file contains the Fractal_WeightOscillator.ex5 and Fractal_WeightOscillator_HTF.ex5 indicators as
resources
,
and therefore, they are not required to be present in the terminal folder for the compiled EA to work! For this purpose, the corresponding code has been added to the EA code in order to include these indicators in the expert's executable file.
The indicator executable files have been added as resources at the global scope
//---- Include the indicators in the EA code as resources
#resource
"\\Indicators\\Fractal_WeightOscillator.ex5"
#resource
"\\Indicators\\Fractal_WeightOscillator_HTF.ex5"

Thus, the compiled executable file of the expert can be used on other trade terminals on its own without the indicators.
