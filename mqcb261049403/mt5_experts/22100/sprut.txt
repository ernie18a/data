The EA places a grid consisting of pending Stop and Limit orders.
Grid features
: the first pending grid order can be placed at the
First

DeltaFirst
xxxx parameter is not considered, and vice versa, when
First
xxxx is equal to zero, the
DeltaFirst
xxxx parameter is activated.

Stop loss (
