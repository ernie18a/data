This program downloads daily EVZ data which is needed in the
Euro FX Vix
indicator from Yahoo Finance. It is necessary to add the URL "https://query1.finance.yahoo.com" to the list of allowed URLs in the 'Advisors' tab (Tools > Options > Expert Advisors) for this program to work.
It can download data once and be removed or run in the background and update each 1-5-10 minutes (but it's not recommended, when switching charts the script will get removed).
You can find the generated files in Common Files folder. The file is also compatible with the MT5 versions of
Euro FX Vix
and
EVZ Reader
