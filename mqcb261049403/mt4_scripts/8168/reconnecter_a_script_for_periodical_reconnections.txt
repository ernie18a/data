The script should solve the
"fading charts" problem
- the situation when the charts stop being updated while the connection to the server remains ok.
Usage:
- add to Favorites the account you are going to connect to (it must be located in the first line!);
- enable using DLLs in the terminal parameters;
- launch the script having specified the necessary pause between relogins (by default, 10 minutes (600 seconds)).
The first (trial) connection will be performed immediately after the launch.
