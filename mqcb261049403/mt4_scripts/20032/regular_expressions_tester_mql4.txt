Most Useful CRegex Class Methods
IsMatch()
- Checks whether the regular expression finds a match in the input string.
Matches()
- Searches an input string for all occurrences of a regular expression and returns all the matches.
Replace()
- In a specified input string, replaces strings that match a regular expression pattern with a specified replacement string.
Split()
- Splits the subject string along regex matches, returning an array of strings. The array contains the text between the regex matches (i.e. split performs inverse match).
