Indicator shows a different Forex sessions, market hours of the exchanges and user defined time lines.
It's a very useful tool for manual and automatic trading.
To perform a correct winter/summer time change, check the following parameters:
Broker_standard_time_zone
- time zone, standard UTC+ broker server shift. The default value +1 - EST (Eastern Standard Time).
Broker_DST_start
- Broker server's date and time for the summer time change.
Broker_DST_end
- Broker server's date and time for the winter time (standard) change.
