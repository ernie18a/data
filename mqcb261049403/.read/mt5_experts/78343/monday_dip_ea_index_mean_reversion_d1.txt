The Expert Advisor trades directly on whichever symbol chart it is attached to (no hardcoded symbols). It executes a maximum of one trade per week and all strategy decisions are calculated exclusively using Daily (D1) closed candle data based on server time.
⚡ Core Rules
Rule 1 — Entry:
On Monday close, the closing price is compared with the previous session's close (usually Friday). A long position is triggered only if Monday’s close is strictly lower than the prior trading day’s close. This check occurs only once per week.
Rule 2 — Exit:
The open position is automatically closed at Wednesday's daily close (executed at the first tick of the next daily session), regardless of profit or loss. If Wednesday close is missed, any subsequent daily close (Thursday, Friday, or weekend close) will trigger the exit.
Rule 3 — Stop Loss & Safety:
A percentage-based Stop Loss ( InpStopLossPercent ) is applied upon entry, respecting the broker's minimum stop distance ( SYMBOL_TRADE_STOPS_LEVEL ). If 5 consecutive attempts to apply or modify the Stop Loss fail, the EA attempts an immediate market close to ensure capital safety.
Note: There is no Take Profit target—exits are entirely time- and stop-based.
🛡️ Optional Entry Filters
Both filters are optional toggles that can only restrict entries further (they will never create entries on their own or loosen Rule 1):
Internal Bar Strength (IBS) Filter:
Calculates IBS = (Close - Low) / (High - Low) for Monday's candle. Entry is permitted only if IBS <= InpIBSMax . If High equals Low, the day is ignored and logged.
Moving Average (MA) Filter:
Requires Monday’s close to be strictly below a Simple Moving Average ( InpMAPeroid ) calculated over closed D1 candles including Monday.
⚙️ Key Specifications
Chart Timeframe:
Timeframe independent (uses D1 series internally). Attaching to a D1 chart is recommended for clean log monitoring.
Symbol Compatibility:
Multi-index compatible (US500, UK100, GER40, etc.).
Risk Management:
Strict 1-position limit with robust retry logic for order execution and emergency closes.
