The
Ozymandias_v2
indicator in the form of a colored cloud with the timeframe selection option available in the input parameters:
input
ENUM_TIMEFRAMES
TimeFrame=
PERIOD_H4
;
// Indicator chart period (timeframe)
The indicator requires Ozymandias_v2.mq5 indicator file. Place it in <terminal_data_folder>\MQL5\Indicators.
