DeMark's Oscillator
with an option of setting a fixed timeframe for the calculation of the indicator in the input parameters.
//+-------------------------------------+
//| Indicator input parameters          |
//+-------------------------------------+
input
ENUM_TIMEFRAMES
TimeFrame=
PERIOD_H4
;
// Chart period
input
uint
DeMarker_Period=
14
;
// Averaging period
input
int
Shift=
0
;
// Horizontal shift of the indicator in bars
