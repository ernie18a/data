The
Extrem_N
indicator with the timeframe selection option available in input parameters:
input
ENUM_TIMEFRAMES
TimeFrame=
PERIOD_H4
;
// Indicator chart period (timeframe)
The indicator requires Extrem_N.mq5 indicator file. Add it to <terminal_data_folder>\MQL5\Indicators.
