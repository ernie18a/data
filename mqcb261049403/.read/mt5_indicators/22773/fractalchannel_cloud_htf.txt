FractalChannel_Cloud
indicator with the timeframe selection option available in input parameters:
input
ENUM_TIMEFRAMES
TimeFrame=
PERIOD_H4
;
// The indicator chart period (timeframe)
For the indicator to operate, the
FractalChannel_Cloud.ex5
