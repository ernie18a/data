The
Wajdyss_Ichimoku_Candle
indicator with the ability to change the timeframe using the input parameters:
input
ENUM_TIMEFRAMES
TimeFrame=
PERIOD_H4
;
// The indicator chart period (timeframe)
For the indicator to operate, the
Wajdyss_Ichimoku_Candle.ex5
indicator must be available under <terminal_data_directory>\MQL5\Indicators folder.
