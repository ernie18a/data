TrendManager
indicator with the timeframe selection option available in input parameters:
input
ENUM_TIMEFRAMES
TimeFrame=
PERIOD_H4
;
// Indicator chart period (timeframe)
For the indicator to operate, the
TrendManager.ex5
indicator should be added to the <terminal_data_directory>\MQL5\Indicators folder.
