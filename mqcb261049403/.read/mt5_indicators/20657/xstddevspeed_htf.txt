Indicator
XStdDevSpeed
with the timeframe selection option in input parameters:
input
ENUM_TIMEFRAMES
TimeFrame=
PERIOD_H4
;
// Indicator chart period (timeframe)
For the indicator to work, there must be indicator
XStdDevSpeed.ex5
in the <terminal_data_directory>\MQL5\Indicators folder.
