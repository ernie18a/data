The
XMA_Range_Channel
indicator with the timeframe selection option available in the input parameters:
input
ENUM_TIMEFRAMES
TimeFrame=
PERIOD_H4
;
// Indicator chart period (timeframe)
The indicator requires XMA_Range_Channel.mq5 indicator file. Place it in <terminal_data_folder>\MQL5\Indicators.
