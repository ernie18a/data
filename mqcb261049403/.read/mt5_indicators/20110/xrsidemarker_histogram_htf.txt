The
XRSIDeMarker_Histogram
indicator with the possibility to change the indicator timeframe in input parameters:
input
ENUM_TIMEFRAMES
TimeFrame=
PERIOD_H4
;
// Indicator chart period (timeframe)
To enable the indicator operation, add the
XRSIDeMarker_Histogram.ex5
indicator file to <terminal data directory>\MQL5\Indicators.
Fig1. The XRSIDeMarker_Histogram_HTF indicator.
