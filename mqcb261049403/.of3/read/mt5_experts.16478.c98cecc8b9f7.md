Calculation: smoothed projection = round(MA(method 2, shorter lookback, phase 2, MA(selected applied price, method 1, longer lookback, phase 1) + (base - base[integer-truncated quarter of longer lookback]) + (base - 2 × base[integer-truncated quarter] + base[integer-truncated eighth of longer lookback]) / 2 + (base - 3 × base[integer-truncated quarter] + 3 × base[integer-truncated eighth] - base[integer-truncated twelfth of longer lookback]) / 6), curve rounding precision), where base = MA(selected applied price, method 1, longer lookback, phase 1); calculated on T1 bars, with the signal offset selecting a forming or completed bar
Calculation: direction = bullish when smoothed projection > smoothed projection[1], bearish when smoothed projection < smoothed projection[1], otherwise direction[1]
Calculation: change = smoothed projection - smoothed projection[1]
Long: (round(change, instrument precision plus precision offset) > round(first filter multiplier × StdDev(change, volatility lookback), instrument precision plus precision offset) AND round(change, instrument precision plus precision offset) <= round(second filter multiplier × StdDev(change, volatility lookback), instrument precision plus precision offset)) OR round(change, instrument precision plus precision offset) > round(second filter multiplier × StdDev(change, volatility lookback), instrument precision plus precision offset) OR (long-entry mode is direct AND direction[1] is bearish AND direction is bullish)
Short: (round(change, instrument precision plus precision offset) < -round(first filter multiplier × StdDev(change, volatility lookback), instrument precision plus precision offset) AND round(change, instrument precision plus precision offset) >= -round(second filter multiplier × StdDev(change, volatility lookback), instrument precision plus precision offset)) OR round(change, instrument precision plus precision offset) < -round(second filter multiplier × StdDev(change, volatility lookback), instrument precision plus precision offset) OR (short-entry mode is direct AND direction[1] is bullish AND direction is bearish)
Exit: long, (long-exit mode is point AND short-entry mode is not point AND the bearish point condition) OR (long-exit mode is direct AND direction is bearish)
Exit: short, (short-exit mode is point AND long-entry mode is not point AND the bullish point condition) OR (short-exit mode is direct AND direction is bullish)
