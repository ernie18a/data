Calculation: Trend state on T1 bars = initialize the previous state as neutral and previous upper and lower bands as close on the first calculated bar; on each bar set raw upper/lower bands to MA(applied price, MA lookback, MA type) ± volatility multiplier × ATR(ATR lookback), carry forward the previous state, set it to long if high > previous upper band, then to short if low < previous lower band (short overrides); in a long state set the lower band to max(raw lower band, previous lower band), and in a short state set the upper band to min(raw upper band, previous upper band); use the resulting bands on the next bar.
Long: Trend state changes from neutral or short to long at the selected signal-bar offset on T1 (a completed bar for a positive offset; the forming bar for zero offset).
Short: Trend state changes from neutral or long to short at the selected signal-bar offset on T1 (a completed bar for a positive offset; the forming bar for zero offset).
Exit: long, Trend state is short at the selected signal-bar offset on T1 (a completed bar for a positive offset; the forming bar for zero offset).
Exit: short, Trend state is long at the selected signal-bar offset on T1 (a completed bar for a positive offset; the forming bar for zero offset).
