Calculation: StepLine(step size) = for each bar, let q = CCX; initialize trend to 0 and prior upper and lower bands to opposite sentinels; set trend to +1 if q > prior upper band, then set it to −1 if q < prior lower band, otherwise retain the prior trend; set the lower band to max(q − band-width multiplier × step size, prior lower band) when trend is +1, otherwise q − band-width multiplier × step size; set the upper band to min(q + band-width multiplier × step size, prior upper band) when trend is −1, otherwise q + band-width multiplier × step size; output lower band + step size when trend is +1 or upper band − step size when trend is −1; carry trend and bands to the next bar
