Calculation: long entry score = Σ from i=1 to 4 of (long coefficient_i − common baseline) × the difference between LWMA(close, long average lookback, current bar) and LWMA(weighted close, long average lookback, (i × long lag spacing) bars ago), using the adjacent weighted-close averages for i>1, plus long threshold − common baseline
Calculation: short entry score = the same score formula using separate short coefficients, average lookback, lag spacing, and threshold
Calculation: supervisor score = the same score formula using separate supervisor coefficients, average lookback, lag spacing, and threshold
Calculation: Ichimoku filter direction = +1 when Tenkan line > Kijun line, −1 when Tenkan line < Kijun line, otherwise 0
Calculation: ADX filter direction = +1 when ADX(open, ADX lookback, T1, still-forming bar) ≥ ADX threshold and +DI > −DI; −1 when ADX is at least the threshold and +DI < −DI; otherwise 0; evaluated on chart bars using T1 values
Calculation: MACD filter direction = +1 when chart-bar MACD(open, chart fast, chart slow, chart signal, current bar) > its prior value and its signal, with either cross confirmation off and MACD > 0, or cross confirmation on and MACD < 0 and prior MACD < prior signal; and, when T1 confirmation is enabled, T1 MACD with separate fast, slow, and signal lookbacks > its signal on the still-forming T1 bar; −1 for the corresponding falling conditions, with either cross confirmation off and MACD < 0, or cross confirmation on and MACD > 0 and prior MACD > prior signal, and T1 MACD < signal when T1 confirmation is enabled; otherwise 0
Calculation: OsMA filter direction = +1 when OsMA(open, OsMA fast, OsMA slow, OsMA signal, chart bar) > 0 and, when T1 confirmation is enabled, OsMA with the same lookbacks on the still-forming T1 bar > 0; −1 when both applicable values are < 0; otherwise 0; evaluated on chart bars
Calculation: SAR filter direction = +1 when chart SAR(current bar) < low[0] and SAR[1] < close[1], with either cross confirmation off or SAR[2] > high[2], and, when T1 confirmation is enabled, SAR on the still-forming T1 bar < low on that bar; −1 when chart SAR(current bar) > high[0] and SAR[1] > close[1], with either cross confirmation off or SAR[2] < low[2], and, when T1 confirmation is enabled, SAR on the still-forming T1 bar > high on that bar; otherwise 0
Calculation: candle filter direction = +1 when high[1] > high[2], −1 when low[1] < low[2], otherwise 0
Calculation: fast moving-average filter direction = +1 when LWMA(weighted close, fast lookback, shift 1) − SMA(close, fast lookback, shift 1) > fast threshold × point size, and each enabled increase or acceleration condition is positive; −1 when the difference is below −fast threshold × point size and each enabled increase or acceleration condition is negative; otherwise 0; increase is the difference between consecutive LWMA values and acceleration is the change in that difference
Calculation: slow moving-average filter direction = the fast moving-average filter formula using separate slow lookback, threshold, increase setting, and acceleration setting
Calculation: moving-average group filter direction = +1 when LWMA(close), LWMA(high), and LWMA(low) at shift 1 all exceed their respective values at shift 2, and at least one of shifts 2, 3, or 4 has all three values less than or equal to their respective next-shift values; when long-term confirmation is enabled, LWMA(close, four times the group lookback, shift 1) must also exceed its shift 2 value; −1 for the corresponding reversed comparisons; otherwise 0
Calculation: fractal filter direction = +1 when the upper fractal at shift 3 is absent or high[0] exceeds it; −1 when the lower fractal at shift 3 is absent or low[0] is below it; otherwise 0
Calculation: RSI filter direction = +1 when RSI(open, RSI lookback, current bar) > RSI threshold, −1 when it is below the threshold, otherwise 0
Calculation: CCI filter direction = +1 when CCI(typical price, CCI lookback, current bar) > positive CCI threshold, −1 when it is below negative CCI threshold, otherwise 0
Calculation: Awesome Oscillator filter direction = +1 when Awesome Oscillator(current bar) > 0, −1 when it is < 0, otherwise 0
Calculation: Accelerator Oscillator filter direction = +1 when Accelerator Oscillator(current bar) > 0, −1 when it is < 0, otherwise 0
Calculation: euro strength = sum, over the euro exchange rates against the dollar, pound, franc, yen, Canadian dollar, and Australian dollar, of (moving average of weighted close at shift 0 − moving average of weighted close at the configured prior shift) × 10^(quote precision), using the configured average type and lookback on chart bars
Calculation: euro-strength filter direction = +1 when euro strength > 0, −1 when it is < 0, otherwise 0
Calculation: XO direction = process the configured lookback of completed closes from oldest to newest, starting with upper and lower bounds equal to the oldest close; a close above the upper bound plus box size sets the direction up and resets the bounds to close and close minus box size, while a close below the lower bound minus box size sets it down and resets the bounds to close plus box size and close; otherwise retain the direction; the prior direction is the direction before processing the latest close
Calculation: XO filter direction = +1 when XO direction is up and either cross confirmation is off or the prior direction was down; −1 when XO direction is down and either cross confirmation is off or the prior direction was up; otherwise 0
Calculation: price Fibonacci direction = +1 when close[1] exceeds highest high over the configured lookback starting at shift 1 minus the high-low range times the retracement parameter; otherwise −1 when close[1] is below lowest low over that lookback plus the range times the retracement parameter; otherwise retain the previous direction
Calculation: moving-average Fibonacci direction = +1 when close[1] exceeds the maximum LWMA(weighted close, moving-average lookback) over shifts 1 through the configured range, minus that average range times the retracement parameter; otherwise −1 when close[1] is below the minimum over that range plus the average range times the retracement parameter; otherwise retain the previous direction
Calculation: bullish filter gate = at least one indicator filter is enabled and every enabled indicator filter direction is +1
Calculation: bearish filter gate = at least one indicator filter is enabled and every enabled indicator filter direction is −1
Long: indicator manager is enabled AND bullish filter gate
Short: indicator manager is enabled AND bearish filter gate
Long: long entry score > 0 AND (indicator manager is disabled OR bullish filter gate)
Short: short entry score < 0 AND (indicator manager is disabled OR bearish filter gate)
Long: supervisor score > 0 AND long entry score > 0 AND (indicator manager is disabled OR bullish filter gate)
Short: supervisor score ≤ 0 AND short entry score < 0 AND (indicator manager is disabled OR bearish filter gate)
Calculation: long target distance = when ATR exits are enabled, ATR(ATR lookback, chart bar still forming at entry) × long target parameter × target ATR multiplier ÷ percentage scale; otherwise long target parameter × point size
Calculation: long stop distance = when ATR exits are enabled, ATR(ATR lookback, chart bar still forming at entry) × long stop parameter × stop ATR multiplier ÷ percentage scale; otherwise long stop parameter × point size
Calculation: short target distance = when ATR exits are enabled, ATR(ATR lookback, chart bar still forming at entry) × short target parameter × target ATR multiplier ÷ percentage scale; otherwise short target parameter × point size
Calculation: short stop distance = when ATR exits are enabled, ATR(ATR lookback, chart bar still forming at entry) × short stop parameter × stop ATR multiplier ÷ percentage scale; otherwise short stop parameter × point size
Exit: long, low ≤ entry price − long stop distance OR high ≥ entry price + long target distance
Exit: short, high ≥ entry price + short stop distance OR low ≤ entry price − short target distance
Exit: long, order-close manager is enabled AND SAR(current chart bar) > high[0]
Exit: short, order-close manager is enabled AND SAR(current chart bar) < low[0]
