Calculation: EMA retracement event = for a bar with close above the longer-lookback EMA, let D = abs(low − that EMA) / point size; it is an event if D < (high − low) / point size and D is less than abs(low − that same EMA) / point size for each of the P_neighborCount bars beyond the immediately adjacent bar on both sides; for a bar with close below the EMA, use high instead of low throughout.
Calculation: Fast EMA break event = (open and close above the longer-lookback EMA AND the shorter-lookback EMA above the longer-lookback EMA AND (open < shorter-lookback EMA AND close > shorter-lookback EMA OR shorter-lookback EMA[1] < longer-lookback EMA AND shorter-lookback EMA > longer-lookback EMA)) OR (open and close below the longer-lookback EMA AND the shorter-lookback EMA below the longer-lookback EMA AND (open > shorter-lookback EMA AND close < shorter-lookback EMA OR shorter-lookback EMA[1] > longer-lookback EMA AND shorter-lookback EMA < longer-lookback EMA).
Calculation: Stochastic threshold event = (open and close above the longer-lookback EMA AND the shorter-lookback EMA above the longer-lookback EMA AND Stochastic %K(P_K, P_D, P_slowing, EMA smoothing, low/high)[1] <= P_lowerThreshold AND Stochastic %K(P_K, P_D, P_slowing, EMA smoothing, low/high) >= P_lowerThreshold) OR (open and close below the longer-lookback EMA AND the shorter-lookback EMA below the longer-lookback EMA AND Stochastic %K(P_K, P_D, P_slowing, EMA smoothing, low/high)[1] >= P_upperThreshold AND Stochastic %K(P_K, P_D, P_slowing, EMA smoothing, low/high) <= P_upperThreshold).
Long: On the last completed chart bar, open and close > EMA(close, longer lookback) AND EMA(close, shorter lookback) > EMA(close, longer lookback) AND ADX(P_ADXLookback) < P_ADXThreshold AND the latest EMA retracement, fast EMA break, and stochastic threshold events are each within P_eventWindow bars AND the latest fast EMA break occurred after the latest EMA retracement AND more than P_longSignalGap bars have passed since the previous long signal AND counted buy-order count < P_longOrderLimit AND counted sell-order count < P_shortOrderLimit.
Short: On the last completed chart bar, open and close < EMA(close, longer lookback) AND EMA(close, shorter lookback) < EMA(close, longer lookback) AND ADX(P_ADXLookback) < P_ADXThreshold AND the latest EMA retracement, fast EMA break, and stochastic threshold events are each within P_eventWindow bars AND the latest fast EMA break occurred after the latest EMA retracement AND more than P_shortSignalGap bars have passed since the previous short signal AND counted buy-order count < P_longOrderLimit AND counted sell-order count < P_shortOrderLimit.
Long: With the same-side spacing hedge mode selected, the most recent buy entry price (or current ask if there is no buy entry) − current ask >= P_hedgeDistance × point size.
Short: With the same-side spacing hedge mode selected, current bid − the most recent sell entry price (or current bid if there is no sell entry) >= P_hedgeDistance × point size.
Long: With the latest-order hedge mode selected, (the latest order is short AND account-wide open-order count = P_singleOrderCount AND current bid − latest order entry price >= P_hedgeDistance × point size) OR (the latest order is long AND account-wide open-order count > P_singleOrderCount AND latest order entry price − current ask >= P_hedgeDistance × point size).
Short: With the latest-order hedge mode selected, (the latest order is long AND account-wide open-order count = P_singleOrderCount AND latest order entry price − current ask >= P_hedgeDistance × point size) OR (the latest order is short AND account-wide open-order count > P_singleOrderCount AND current bid − latest order entry price >= P_hedgeDistance × point size).
Exit: long, account equity > account balance AND account-wide open-order count != P_singleOrderCount AND the selected close mode does not use trailing stops.
Exit: short, account equity > account balance AND account-wide open-order count != P_singleOrderCount AND the selected close mode does not use trailing stops.
