Calculation: Filtered(x, multiplier, lookback) = x on the first bar or when multiplier ≤ 0; otherwise, return the previous filtered value when |x − previous filtered value| < multiplier × sqrt(sum of squared deviations of the current and previous lookback−1 absolute changes from each change’s lookback mean, divided by lookback), and x otherwise; missing-history changes are zero
Calculation: Aroon value = Filtered(Aroon Oscillator(Filtered(selected high-price series, price filter multiplier, filter lookback), Filtered(selected low-price series, price filter multiplier, filter lookback), Aroon lookback), oscillator filter multiplier, filter lookback); price and oscillator filter multipliers are the filter multiplier when their respective filters are enabled, otherwise zero; filter lookback uses its separate parameter when positive, otherwise Aroon lookback
Calculation: Quantile(x, lookback, percentile) = linear interpolation at rank (lookback − 1) × percentile / 100 in the sorted current and preceding values, padding missing history with zero
Long: Aroon value > Quantile(Aroon value, band lookback, upper percentile)
Short: Aroon value < Quantile(Aroon value, band lookback, lower percentile)
