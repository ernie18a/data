Calculation: scan direction = the direction of the first qualifying chart-bar lag, scanning from the start-lag parameter through the end-lag parameter in ascending order. A lag qualifies as long when LWMA(typical price, short setup lookback)[lag] > LWMA(typical price, middle setup lookback)[lag] > LWMA(typical price, long setup lookback)[lag], low[lag] <= LWMA(typical price, short setup lookback)[lag], low[lag] > LWMA(typical price, long setup lookback)[lag], and current close > highest(high, breakout lookback, prior completed chart bars). A lag qualifies as short when LWMA(typical price, short setup lookback)[lag] < LWMA(typical price, middle setup lookback)[lag] < LWMA(typical price, long setup lookback)[lag], high[lag] >= LWMA(typical price, short setup lookback)[lag], high[lag] < LWMA(typical price, long setup lookback)[lag], and current close < lowest(low, breakout lookback, prior completed chart bars). Otherwise the direction is none. The setup lookbacks are ordered short < middle < long.
Long: abs(current close - close[two-bar lag]) > retracement-distance parameter × point size AND scan direction = long AND LWMA(typical price, fast lookback, T1, current-forming bar) > LWMA(typical price, slow lookback, T1, current-forming bar) AND low[two-bar lag] < high[one-bar lag] AND RSI(close, RSI lookback, T2, current-forming bar) > RSI(close, same RSI lookback, T2, last completed bar)
Short: abs(current close - close[two-bar lag]) > retracement-distance parameter × point size AND scan direction = short AND LWMA(typical price, fast lookback, T1, current-forming bar) < LWMA(typical price, slow lookback, T1, current-forming bar) AND low[one-bar lag] < high[two-bar lag] AND RSI(close, RSI lookback, T2, current-forming bar) < RSI(close, same RSI lookback, T2, last completed bar)
Exit: long, current close <= entry price - stop-loss parameter × pip size OR current close >= entry price + take-profit parameter × pip size OR trailing-stop parameter > 0 AND highest(high since entry) > entry price + trailing-stop parameter × pip size AND current close <= highest(high since entry) - trailing-stop parameter × pip size OR break-even enabled AND (trailing-stop parameter <= 0 OR break-even trigger parameter <= trailing-stop parameter) AND highest(high since entry) > entry price + break-even trigger parameter × pip size AND current close <= entry price + break-even offset parameter × pip size
Exit: short, current close >= entry price + stop-loss parameter × pip size OR current close <= entry price - take-profit parameter × pip size OR trailing-stop parameter > 0 AND lowest(low since entry) < entry price - trailing-stop parameter × pip size AND current close >= lowest(low since entry) + trailing-stop parameter × pip size OR break-even enabled AND (trailing-stop parameter <= 0 OR break-even trigger parameter <= trailing-stop parameter) AND lowest(low since entry) < entry price - break-even trigger parameter × pip size AND current close >= entry price - break-even offset parameter × pip size
