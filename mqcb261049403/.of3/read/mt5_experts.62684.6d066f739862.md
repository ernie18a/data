Calculation: signal price = close(T1, last completed bar) when close-price signals are selected; otherwise current bid
Calculation: fast-MA slope magnitude = abs(SMA(close, fast lookback, T1, last completed bar) - SMA(close, fast lookback, T1, preceding completed bar))
Calculation: average entry price = volume-weighted mean of position entry prices
Calculation: grid step = max(minimum grid step, fixed step) in fixed-step mode; otherwise max(minimum grid step, ATR(step lookback, T2, bar still forming) * ATR multiplier)
Calculation: take-profit distance = ATR(step lookback, T2, bar still forming) * ATR multiplier when ATR-step mode is enabled and ATR is valid; otherwise fixed take-profit distance
Long: signal price > SMA(close, fast lookback, T1, last completed bar) AND signal price > SMA(close, slow lookback, T1, last completed bar) AND signal price - SMA(close, fast lookback, T1, last completed bar) >= minimum signal distance AND volume(T1, last completed bar) >= volume(T1, preceding completed bar) * volume multiplier AND (MA slope filter disabled OR fast-MA slope magnitude >= minimum MA slope) AND (volatility filter disabled OR ATR(long volatility lookback, T1, bar still forming) = 0 OR ATR(short volatility lookback, T1, bar still forming) / ATR(long volatility lookback, T1, bar still forming) < volatility threshold) AND spread <= maximum spread AND current time >= last cycle start time + minimum entry delay AND current time >= last cycle close time + cycle cooldown AND number of trades in current cycle < maximum total trades AND (no short cycle is active OR signal-flip-close is enabled) AND daily loss limit is not reached AND market is open
Short: signal price < SMA(close, fast lookback, T1, last completed bar) AND signal price < SMA(close, slow lookback, T1, last completed bar) AND SMA(close, fast lookback, T1, last completed bar) - signal price >= minimum signal distance AND volume(T1, last completed bar) >= volume(T1, preceding completed bar) * volume multiplier AND (MA slope filter disabled OR fast-MA slope magnitude >= minimum MA slope) AND (volatility filter disabled OR ATR(long volatility lookback, T1, bar still forming) = 0 OR ATR(short volatility lookback, T1, bar still forming) / ATR(long volatility lookback, T1, bar still forming) < volatility threshold) AND spread <= maximum spread AND current time >= last cycle start time + minimum entry delay AND current time >= last cycle close time + cycle cooldown AND number of trades in current cycle < maximum total trades AND daily loss limit is not reached AND market is open
Long: short cycle is active AND signal-flip-close and flip-on-opposite-signal are enabled AND current time > cycle start time + minimum cycle duration AND (close(T1, last completed bar) > SMA(close, fast lookback, T1, last completed bar) OR close(T1, last completed bar) > SMA(close, slow lookback, T1, last completed bar)) AND daily loss limit is not reached AND market is open
Short: long cycle is active AND signal-flip-close and flip-on-opposite-signal are enabled AND current time > cycle start time + minimum cycle duration AND (close(T1, last completed bar) < SMA(close, fast lookback, T1, last completed bar) OR close(T1, last completed bar) < SMA(close, slow lookback, T1, last completed bar)) AND daily loss limit is not reached AND market is open
Long: buy cycle is active AND grid trading is enabled AND average entry price - current bid >= grid step AND last trade price - current bid >= grid step AND number of trades in current cycle < maximum grid trades AND number of trades in current cycle < maximum total trades AND minimum grid-trade interval has elapsed AND (volatility filter disabled OR ATR(long volatility lookback, T1, bar still forming) = 0 OR ATR(short volatility lookback, T1, bar still forming) / ATR(long volatility lookback, T1, bar still forming) < volatility threshold) AND spread <= maximum spread AND daily loss limit is not reached AND market is open
Short: sell cycle is active AND grid trading is enabled AND current ask - average entry price >= grid step AND current ask - last trade price >= grid step AND number of trades in current cycle < maximum grid trades AND number of trades in current cycle < maximum total trades AND minimum grid-trade interval has elapsed AND (volatility filter disabled OR ATR(long volatility lookback, T1, bar still forming) = 0 OR ATR(short volatility lookback, T1, bar still forming) / ATR(long volatility lookback, T1, bar still forming) < volatility threshold) AND spread <= maximum spread AND daily loss limit is not reached AND market is open
Exit: long, grid-profit closure is enabled AND grid-profit threshold > 0 AND (current bid - average entry price) / pip size >= grid-profit threshold
Exit: short, grid-profit closure is enabled AND grid-profit threshold > 0 AND (average entry price - current ask) / pip size >= grid-profit threshold
Exit: long, current bid >= average entry price + take-profit distance + spread * pip size
Exit: short, current ask <= average entry price - take-profit distance - spread * pip size
Exit: long, emergency close is enabled AND maximum drawdown > 0 AND balance > 0 AND (balance - equity) / balance * 100 >= maximum drawdown
Exit: short, emergency close is enabled AND maximum drawdown > 0 AND balance > 0 AND (balance - equity) / balance * 100 >= maximum drawdown
Exit: long, stagnation age has elapsed AND abs(current bid - average entry price) / pip size <= stagnation threshold
Exit: short, stagnation age has elapsed AND abs(current ask - average entry price) / pip size <= stagnation threshold
Exit: long, when position-age limit is enabled, elapsed holding hours - 48 * floor(elapsed holding hours / 168) >= maximum position age
Exit: short, when position-age limit is enabled, elapsed holding hours - 48 * floor(elapsed holding hours / 168) >= maximum position age
Exit: long, number of trades in current cycle >= maximum total trades OR (grid trading is enabled AND number of trades in current cycle >= maximum grid trades)
Exit: short, number of trades in current cycle >= maximum total trades OR (grid trading is enabled AND number of trades in current cycle >= maximum grid trades)
