Calculation: STC = Schaff Trend Cycle(close, STC parameters, timeframe of the bars being evaluated)
Long: STC on the chart bar > 0
Short: STC on the chart bar < 0
Long: On chart bars using T1 values, STC on the still-forming T1 bar > 0 AND STC on the last completed T1 bar <= 0
Short: On chart bars using T2 values, STC on the still-forming T2 bar < 0 AND STC on the last completed T2 bar >= 0
Exit: long, on chart bars using T1 values, STC on the still-forming T1 bar < 0
Exit: short, on chart bars using T2 values, STC on the still-forming T2 bar > 0
