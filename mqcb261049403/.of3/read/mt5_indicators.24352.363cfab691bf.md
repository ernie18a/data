Calculation: Advance-decline ratio = (advancing symbols - declining symbols) / (advancing symbols + declining symbols), using available symbols with a bar matching the chart-bar time; a symbol advances when close > open and declines when close < open, with these comparisons reversed for inverse symbols; equal open and close counts as neither; return zero when both counts are zero.
Calculation: Smoother(x, period) = use effective period max(period, 1), beta = 0.45*(effective period-1)/(0.45*(effective period-1)+2), alpha = beta^3; initialize s0=s1=s4=x and s2=s3=0; on each following chart bar, s0=(1-alpha)*x+alpha*s0[1], s1=(x-s0)*(1-beta)+beta*s1[1], s2=s0+s1, s3=(s2-s4[1])*(1-alpha)^2+alpha^2*s3[1], s4=s4[1]+s3; return s4.
Calculation: Smoothed advance-decline oscillator = Smoother(advance-decline ratio, shorter smoothing period) - Smoother(advance-decline ratio, longer smoothing period).
Calculation: Floating levels = let H=highest(smoothed advance-decline oscillator, floating-level lookback) and L=lowest(smoothed advance-decline oscillator, floating-level lookback); upper=L+upper percentage*(H-L)/100; lower=L+lower percentage*(H-L)/100; middle=(upper+lower)/2.
Long: (selected color-change mode is floating levels AND smoothed advance-decline oscillator > upper floating level) OR (selected color-change mode is slope AND (smoothed advance-decline oscillator > smoothed advance-decline oscillator[1] OR (smoothed advance-decline oscillator = smoothed advance-decline oscillator[1] AND the latest earlier non-flat oscillator change was upward))) OR (selected color-change mode is middle level AND smoothed advance-decline oscillator > middle floating level).
Short: (selected color-change mode is floating levels AND smoothed advance-decline oscillator < lower floating level) OR (selected color-change mode is slope AND (smoothed advance-decline oscillator < smoothed advance-decline oscillator[1] OR (smoothed advance-decline oscillator = smoothed advance-decline oscillator[1] AND the latest earlier non-flat oscillator change was downward))) OR (selected color-change mode is middle level AND smoothed advance-decline oscillator < middle floating level).
