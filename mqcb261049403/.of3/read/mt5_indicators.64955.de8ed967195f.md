Calculation: Bullish and bearish block counts = on each chart bar, set the reference to the completed T1 close at the chart bar’s backward offset plus one shift; scan that close and the next older T1 closes for the lookback; with threshold equal to block size in points times point size, both counts initially zero and both directions enabled, for each close, if it is at least one threshold above the reference while bearish counting is enabled, increment the bearish count and raise the reference by one threshold, then if it is at least one threshold below the reference while bullish counting is enabled, increment the bullish count and lower the reference by one threshold; when opposite-break is enabled, disable counting in the opposite direction after either count increments
Long: Bullish block count > 0
Short: Bearish block count > 0
