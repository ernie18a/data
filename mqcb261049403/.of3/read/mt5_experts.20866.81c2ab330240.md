Calculation: BrainTrend2 state(ATR lookback, normalization parameter, width multiplier) = seed direction as up iff close[2] > close[1], otherwise down, seed trail = close[1] and all true-range slots with the first true range; on each source-timeframe bar let ask high = high + bid-ask spread, true range = max(ask high - low, abs(ask high - close[1]), abs(low - close[1])), weighted range = 2 * Σ((ATR lookback - n) * true range[n bars ago], n = 0..ATR lookback-1) / (normalization parameter * (normalization parameter + 1)), and width = width multiplier * weighted range; switch up to down if low < trail - width and set trail = ask high, or switch down to up if ask high > trail + width and set trail = low; then set trail = low if up and low > trail, or trail = ask high if down and ask high < trail. A requested bar offset selects the forming bar at zero, the last completed bar at one, or an earlier completed bar at a larger offset.
Long: (BrainTrend2 state(chart ATR lookback, normalization parameter, width multiplier) on chart bars at the chart marker offset is up AND the preceding chart bar is down) OR (BrainTrend2 state(long ATR lookback, normalization parameter, width multiplier) on T1 bars at the long signal-bar offset is up AND the preceding T1 bar is down)
Short: (BrainTrend2 state(chart ATR lookback, normalization parameter, width multiplier) on chart bars at the chart marker offset is down AND the preceding chart bar is up) OR (BrainTrend2 state(short ATR lookback, normalization parameter, width multiplier) on T2 bars at the short signal-bar offset is down AND (the preceding T2 bar is down OR the preceding T2 bar is up and its open is greater than its close))
Exit: long, BrainTrend2 state(long ATR lookback, normalization parameter, width multiplier) on T1 bars at the long signal-bar offset is down
Exit: short, BrainTrend2 state(short ATR lookback, normalization parameter, width multiplier) on T2 bars at the short signal-bar offset is up
