Calculation: PercentageCrossover = initialize the line to close; on each T1 bar set it to close × (1 − percentage deviation / 100) if that value exceeds the prior line, else to close × (1 + percentage deviation / 100) if that value is below the prior line, else retain the prior line; color is rising when the line rises, falling when it falls, and otherwise retains its prior color.
Calculation: TradingWindow = (start hour < end hour AND ((hour = start hour AND minute >= start minute) OR (hour > start hour AND hour < end hour) OR (hour = end hour AND minute < end minute))) OR (start hour = end hour AND hour = start hour AND minute >= start minute AND minute < end minute) OR (start hour > end hour AND ((hour >= start hour AND minute >= start minute) OR hour < end hour OR (hour = end hour AND minute < end minute))).
Long: long entry is enabled AND (time filter is disabled OR TradingWindow) AND PercentageCrossover color on the selected completed T1 signal bar changes from falling on the preceding completed T1 bar to rising.
Short: short entry is enabled AND (time filter is disabled OR TradingWindow) AND PercentageCrossover color on the selected completed T1 signal bar changes from rising on the preceding completed T1 bar to falling.
Exit: long, (stop-loss distance is enabled AND low <= entry price − stop-loss distance) OR (take-profit distance is enabled AND high >= entry price + take-profit distance) OR (long exits are enabled AND selected completed T1 signal bar color is falling AND (preceding completed T1 signal bar color is falling OR short entry is disabled)) OR (time filter is enabled AND NOT TradingWindow).
Exit: short, (stop-loss distance is enabled AND high >= entry price + stop-loss distance) OR (take-profit distance is enabled AND low <= entry price − take-profit distance) OR (short exits are enabled AND selected completed T1 signal bar color is rising AND (preceding completed T1 signal bar color is rising OR long entry is disabled)) OR (time filter is enabled AND NOT TradingWindow).
