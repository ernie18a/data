Calculation: chart direction = upward if MA(MA(applied price, method A, lookback A, phase A), method B, lookback B, phase B) is greater than its value on the prior chart bar, downward if less, otherwise the prior direction (initially neutral)
Long: chart direction is upward
Short: chart direction is downward
Calculation: T1 direction = upward if MA(MA(applied price, method A, lookback A, phase A), method B, lookback B, phase B) on T1 bars is greater than its value on the prior T1 bar, downward if less, otherwise the prior direction (initially neutral); use the T1 bar still forming and carry its value onto chart bars
Long: T1 direction is upward
Short: T1 direction is downward
