Calculation: Grid spacing = fixed spacing when ATR spacing is disabled; otherwise clamp(ATR(ATR spacing lookback, T2, last completed bar) × ATR spacing multiplier, minimum spacing, maximum spacing), evaluated at cycle start using T2 data.
Calculation: Drift = mean(abs(SMA(close, drift lookback, T1, last completed bar)[i] − SMA(close, drift lookback, T1, last completed bar)[i+1])) for i from zero to drift lookback minus one; evaluated on chart bars using T1 data.
Calculation: SigmaMu = min(ATR(regime ATR lookback, T1, last completed bar) / Drift, SigmaMu cap) when Drift is at least the drift floor, otherwise SigmaMu cap; evaluated on chart bars and at cycle start using T1 data.
Calculation: VolatilityFavorable = SigmaMu ≥ minimum SigmaMu ratio AND (ATR(regime ATR lookback, T1, last completed bar) / grid spacing is within the minimum and maximum volatility ratios OR ATR spacing is enabled) AND the cooldown after initialization or the last unfavorable check has elapsed; checked on chart bars using T1 data.
Calculation: CPDBlock becomes active when frozen-baseline CUSUM fires and remains active until VolatilityFavorable; on each new T1 bar, use the first baseline-window Drift observations after reset to calculate and freeze their mean and sample standard deviation, then update S_high = max(0, prior S_high + Drift − baseline mean − delta × baseline standard deviation / 2) and S_low = max(0, prior S_low − Drift + baseline mean − delta × baseline standard deviation / 2); fire when S_high > threshold × baseline standard deviation OR S_low > threshold × baseline standard deviation, then reset both sums while retaining the baseline.
Calculation: PriceLevelBlocked = price-level filter enabled AND sufficient T1 bars and positive T1 ATR are available AND min(max(0, highest high of the preceding price-level lookback T1 bars − close), max(0, close − lowest low of the preceding price-level lookback T1 bars)) < minimum ATR distance × ATR(regime ATR lookback, T1, last completed bar); checked at cycle start and on chart bars using completed T1 bars.
Calculation: WeekendWindow = weekend close enabled AND (server time is Friday at or after the Friday close hour OR Saturday OR Sunday OR Monday before the Monday resume hour).
Calculation: GridMode = MGT if MGT is enabled and the preceding TGT cycle ended by kill or regime restart; otherwise TGT if TGT is enabled and (CPDBlock OR SigmaMu < TGT SigmaMu threshold); otherwise BGT if BGT is enabled; otherwise no cycle.
Calculation: CycleAllowed = NOT (CPDBlock AND TGT is disabled) AND NOT PriceLevelBlocked AND NOT WeekendWindow.
Long: CycleAllowed AND GridMode = BGT AND, at any configured grid level, high ≥ anchor + level index × grid spacing OR low ≤ anchor − level index × grid spacing.
Short: CycleAllowed AND GridMode = BGT AND, at any configured grid level, high ≥ anchor + level index × grid spacing OR low ≤ anchor − level index × grid spacing, with levels above the anchor excluded when buy bias above anchor is enabled.
Long: CycleAllowed AND GridMode = TGT AND SMA(close, drift lookback, T1, last completed bar) ≥ SMA(close, drift lookback, T1, preceding completed T1 bar) AND low ≤ anchor − level index × grid spacing at a configured level below the anchor.
Short: CycleAllowed AND GridMode = TGT AND SMA(close, drift lookback, T1, last completed bar) < SMA(close, drift lookback, T1, preceding completed T1 bar) AND high ≥ anchor + level index × grid spacing at a configured level above the anchor.
Long: CycleAllowed AND GridMode = MGT AND low ≤ anchor − level index × grid spacing at a configured level below the anchor.
Short: CycleAllowed AND GridMode = MGT AND high ≥ anchor + level index × grid spacing at a configured level above the anchor.
Exit: long, GridMode is BGT or MGT AND high ≥ entry price + grid spacing.
Exit: short, GridMode is BGT or MGT AND low ≤ entry price − grid spacing.
Exit: long or short, profit-percent mode is enabled AND profit target percent > 0 AND equity − cycle start equity ≥ cycle start equity × profit target percent / 100 OR fixed-profit mode is enabled AND profit target dollars > 0 AND equity − cycle start equity ≥ profit target dollars.
Exit: long or short, cycle start equity > 0 AND (cycle start equity − equity) / cycle start equity ≥ MGT kill threshold when GridMode = MGT and that threshold > 0, otherwise general kill threshold.
Exit: long or short, current time − cycle start time ≥ maximum cycle duration, checked on chart bars.
Exit: long or short, weekend close is enabled AND server time is Friday at or after the Friday close hour.
Exit: long or short, TGT is enabled AND GridMode = TGT AND NOT CPDBlock AND SigmaMu ≥ TGT SigmaMu threshold, checked on chart bars using the last completed T1 bar.
