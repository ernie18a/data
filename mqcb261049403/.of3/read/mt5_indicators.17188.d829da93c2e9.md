Calculation: effective level type = fixed when the level period disables dynamic levels; otherwise the selected level type
Calculation: effective color mode = slope when the effective level type is fixed; otherwise the selected color mode
Calculation: upper level = if effective level type is floating, Lowest(PDFMA(selected price, PDFMA period, variance, mean), level period) + upper percentile * (Highest(PDFMA(selected price, PDFMA period, variance, mean), level period) - Lowest(PDFMA(selected price, PDFMA period, variance, mean), level period)) / 100; if quantile, Quantile(PDFMA(selected price, PDFMA period, variance, mean), level period, upper percentile); if fixed, PDFMA(selected price, PDFMA period, variance, mean)
Calculation: lower level = if effective level type is floating, Lowest(PDFMA(selected price, PDFMA period, variance, mean), level period) + lower percentile * (Highest(PDFMA(selected price, PDFMA period, variance, mean), level period) - Lowest(PDFMA(selected price, PDFMA period, variance, mean), level period)) / 100; if quantile, Quantile(PDFMA(selected price, PDFMA period, variance, mean), level period, lower percentile); if fixed, PDFMA(selected price, PDFMA period, variance, mean)
Calculation: middle level = if effective level type is quantile, Quantile(PDFMA(selected price, PDFMA period, variance, mean), level period, (upper percentile + lower percentile) / 2); otherwise (upper level + lower level) / 2
Calculation: color state = if effective color mode is level, long when PDFMA(selected price, PDFMA period, variance, mean) > upper level, otherwise short when it is < lower level, otherwise neutral when it is > lower level AND < upper level, otherwise the prior color state; if effective color mode is middle, long when PDFMA(selected price, PDFMA period, variance, mean) > middle level, short when it is < middle level, otherwise neutral; if effective color mode is slope, long when PDFMA(selected price, PDFMA period, variance, mean) > its prior value, short when it is < its prior value, otherwise the prior color state; initial prior color state is neutral
Long: color state is long
Short: color state is short
Long: color state at the selected alert bar is long AND differs from its state on the preceding chart bar
Short: color state at the selected alert bar is short AND differs from its state on the preceding chart bar
