Calculation: Quote scale = 10 when reference quote precision has five digits; otherwise 1
Calculation: Open-delay threshold = open-delay parameter × quote scale
Calculation: Open-after threshold = open-after parameter × quote scale
Calculation: Buy movement = current bid − low(current forming chart bar) × point size
Calculation: Sell movement = high(current forming chart bar) − current ask × point size
Long: ((reversing is off AND Parabolic SAR(step parameter, maximum parameter) on the current forming chart bar < close(current forming chart bar) AND Parabolic SAR(step parameter, maximum parameter) on the last completed chart bar > close(last completed chart bar)) OR (reversing is on AND Parabolic SAR(step parameter, maximum parameter) on the current forming chart bar > close(current forming chart bar) AND Parabolic SAR(step parameter, maximum parameter) on the last completed chart bar < close(last completed chart bar))) AND (open-delay threshold is disabled OR open-delay threshold ≥ buy movement) AND open-after threshold < buy movement
