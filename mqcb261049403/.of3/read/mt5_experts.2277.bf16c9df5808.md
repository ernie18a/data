Calculation: On T1 bars, evaluate the bar at the signal-offset parameter (forming if the offset is zero; completed otherwise). Let D be either an ATR factor × EMA(ATR(ATR lookback), EMA lookback) or a fixed distance parameter × point size, according to the selected mode. Let the prior stop be the preceding bar’s stop, initialized to the close before the first calculated bar. Stop = prior stop if close = prior stop; min(prior stop, close + D) if both the prior and current closes are below the prior stop; max(prior stop, close − D) if both are above it; close − D if the current close is above it; otherwise close + D. Uptrend = close > stop; downtrend = close < stop; up signal = uptrend AND the prior bar was not in uptrend; down signal = downtrend AND the prior bar was not in downtrend.
Long: (direct direction mode AND up signal) OR (inverse direction mode AND down signal)
Short: (direct direction mode AND down signal) OR (inverse direction mode AND up signal)
Exit: long, (direct direction mode AND downtrend OR inverse direction mode AND uptrend) AND NOT ((direct direction mode AND down signal) OR (inverse direction mode AND up signal))
Exit: short, (direct direction mode AND uptrend OR inverse direction mode AND downtrend) AND NOT ((direct direction mode AND up signal) OR (inverse direction mode AND down signal))
