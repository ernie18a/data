Calculation: pip size = symbol point × (10 if symbol digits are 3 or 5, otherwise 1)
Long: On each chart update using T1 indicator values, DeMarker(T1, lookback, last completed bar) < lower DeMarker threshold AND DeMarker(T1, lookback, still-forming bar) >= lower DeMarker threshold AND Stochastic main line(K lookback, D smoothing, slowing, EMA, high-low, T1, last completed bar) < lower Stochastic threshold AND Stochastic main line(K lookback, D smoothing, slowing, EMA, high-low, T1, still-forming bar) >= lower Stochastic threshold
Short: On each chart update using T1 indicator values, DeMarker(T1, lookback, last completed bar) > upper DeMarker threshold AND DeMarker(T1, lookback, still-forming bar) <= upper DeMarker threshold AND Stochastic main line(K lookback, D smoothing, slowing, EMA, high-low, T1, last completed bar) > upper Stochastic threshold AND Stochastic main line(K lookback, D smoothing, slowing, EMA, high-low, T1, still-forming bar) <= upper Stochastic threshold
Exit: long, current Bid <= entry price - stop-loss parameter × pip size OR current Bid >= entry price + take-profit parameter × pip size
Exit: short, current Ask >= entry price + stop-loss parameter × pip size OR current Ask <= entry price - take-profit parameter × pip size
