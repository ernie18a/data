Calculation: Lower excursion = (EMA Envelope lower band(close, EMA lookback, envelope deviation, T1, last completed bar) - low[1,T1]) / pip size
Calculation: Upper excursion = (high[1,T1] - EMA Envelope upper band(close, EMA lookback, envelope deviation, T1, last completed bar)) / pip size
Calculation: Account drawdown = max(0, (base equity - equity) / base equity * 100), where base equity is max(balance, running peak equity) when peak-equity mode is enabled and balance otherwise
Long: ask <= EMA Envelope lower band(close, EMA lookback, envelope deviation, T1, bar still forming)
Short: bid >= EMA Envelope upper band(close, EMA lookback, envelope deviation, T1, bar still forming)
Long: buy enabled AND long position count = 0 AND spread <= maximum spread AND drawdown lock inactive AND (closed-bar mode AND low[1,T1] <= EMA Envelope lower band(close, EMA lookback, envelope deviation, T1, last completed bar) AND (high[1,T1] < EMA Envelope upper band(close, EMA lookback, envelope deviation, T1, last completed bar) OR (abs(lower excursion - upper excursion) < excursion tie tolerance AND close[1,T1] >= open[1,T1]) OR (abs(lower excursion - upper excursion) >= excursion tie tolerance AND lower excursion > upper excursion)) OR forming-bar mode AND ask <= EMA Envelope lower band(close, EMA lookback, envelope deviation, T1, bar still forming)) AND (new-bar-only mode disabled OR this is a new T1 bar)
Short: sell enabled AND short position count = 0 AND spread <= maximum spread AND drawdown lock inactive AND (closed-bar mode AND high[1,T1] >= EMA Envelope upper band(close, EMA lookback, envelope deviation, T1, last completed bar) AND (low[1,T1] > EMA Envelope lower band(close, EMA lookback, envelope deviation, T1, last completed bar) OR (abs(lower excursion - upper excursion) < excursion tie tolerance AND close[1,T1] < open[1,T1]) OR (abs(lower excursion - upper excursion) >= excursion tie tolerance AND upper excursion > lower excursion)) OR forming-bar mode AND bid >= EMA Envelope upper band(close, EMA lookback, envelope deviation, T1, bar still forming)) AND (new-bar-only mode disabled OR this is a new T1 bar)
Long: on the first update after startup only, recent-signal recovery enabled AND maximum signal age > 0 AND no long or short positions AND spread <= maximum spread AND drawdown lock inactive AND buy enabled AND the newest qualifying completed T1 bar within maximum signal age has low <= its EMA Envelope lower band(close, EMA lookback, envelope deviation, T1, that bar) AND current ask <= that lower band + max(0, recent-signal distance)
Short: on the first update after startup only, recent-signal recovery enabled AND maximum signal age > 0 AND no long or short positions AND spread <= maximum spread AND drawdown lock inactive AND sell enabled AND the newest qualifying completed T1 bar within maximum signal age has high >= its EMA Envelope upper band(close, EMA lookback, envelope deviation, T1, that bar) AND current bid >= that upper band - max(0, recent-signal distance) AND buy does not qualify on that same bar when buy is enabled
Long: long grid-level count >= 1 AND long grid-level count < maximum positions per direction AND (newest long entry price - current ask) / pip size >= grid distance
Short: short grid-level count >= 1 AND short grid-level count < maximum positions per direction AND (current bid - newest short entry price) / pip size >= grid distance
Exit: long, long grid-level count = 1 AND (current bid - weighted-average long entry price) / pip size >= single-trade take-profit
Exit: short, short grid-level count = 1 AND (weighted-average short entry price - current ask) / pip size >= single-trade take-profit
Exit: long, long grid-level count >= 2 AND long basket floating profit plus swap >= basket profit target
Exit: short, short grid-level count >= 2 AND short basket floating profit plus swap >= basket profit target
Exit: long, account drawdown >= maximum drawdown
Exit: short, account drawdown >= maximum drawdown
