Calculation: Step line(x, step size) = initialize trend to 0, lower bound to 999999, and upper bound to −999999; on each T1 bar set trend to −1 if x < prior lower bound, otherwise +1 if x > prior upper bound, otherwise retain the prior trend; set lower candidate to x − band multiplier × step size and upper candidate to x + band multiplier × step size; set lower bound to max(lower candidate, prior lower bound) when trend is positive, otherwise to lower candidate; set upper bound to min(upper candidate, prior upper bound) when trend is negative, otherwise to upper candidate; output lower bound + step size when trend is positive, upper bound − step size when trend is negative, and no value when trend is 0
Calculation: Fast step line = Step line(normalized deviation, smaller fast step size), calculated on each T1 bar
Calculation: Slow step line = Step line(normalized deviation, larger slow step size), calculated on each T1 bar
