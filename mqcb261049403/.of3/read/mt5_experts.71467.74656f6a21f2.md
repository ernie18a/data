Calculation: SL distance = max(if SL mode is ATR then ATR(ATR lookback, last completed chart bar) × SL ATR multiplier, else SL fixed points × point size; broker minimum stop level × point size + spread + broker stop buffer)
Calculation: TP distance = max(if TP mode is ATR then ATR(ATR lookback, last completed chart bar) × TP ATR multiplier, else TP fixed points × point size; broker minimum stop level × point size + spread + broker stop buffer)
Long: bullish entries enabled AND an unfilled, untraded tracked bullish 3-bar FVG exists with low[k] > high[k-2] AND low[k] - high[k-2] >= minimum gap in points × point size AND the last completed chart bar low is between high[k-2] - (low[k] - high[k-2]) and low[k], inclusive AND (confirmation disabled OR (last completed chart bar close > open AND close >= high[k-2])) AND (EMA filter disabled OR (ask > EMA(close, shorter EMA lookback, T1 current forming bar, sampled on chart bars) AND EMA(close, shorter EMA lookback, T1 current forming bar, sampled on chart bars) > EMA(close, longer EMA lookback, T1 current forming bar, sampled on chart bars))) AND (ADX filter disabled OR (ADX(ADX lookback, current forming chart bar) >= minimum ADX strength AND +DI(ADX lookback, current forming chart bar) > -DI(ADX lookback, current forming chart bar)))
Short: bearish entries enabled AND an unfilled, untraded tracked bearish 3-bar FVG exists with high[k] < low[k-2] AND low[k-2] - high[k] >= minimum gap in points × point size AND the last completed chart bar high is between high[k] and low[k-2] + (low[k-2] - high[k]), inclusive AND (confirmation disabled OR (last completed chart bar close < open AND close <= low[k-2])) AND (EMA filter disabled OR (bid < EMA(close, shorter EMA lookback, T1 current forming bar, sampled on chart bars) AND EMA(close, shorter EMA lookback, T1 current forming bar, sampled on chart bars) < EMA(close, longer EMA lookback, T1 current forming bar, sampled on chart bars))) AND (ADX filter disabled OR (ADX(ADX lookback, current forming chart bar) >= minimum ADX strength AND -DI(ADX lookback, current forming chart bar) > +DI(ADX lookback, current forming chart bar)))
Exit: long, current bid <= entry price - SL distance OR current bid >= entry price + TP distance
Exit: short, current ask >= entry price + SL distance OR current ask <= entry price - TP distance
