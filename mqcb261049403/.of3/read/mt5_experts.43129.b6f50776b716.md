Calculation: Bearish MACD divergence = On each new completed T1 bar, compute M = MACD(close, bearish fast lookback, bearish slow lookback, bearish signal lookback, T1). Require M[1], M[2], M[3], and M[4] > bearish threshold and M[2] > M[1], M[3], and M[4]. Set recent high to High[p] for the smallest p from 0 through recent price search span where High[p] > each High[p+1] through High[p+pivot width]; shift 0 is the forming T1 bar, and recent high remains 0 if none qualifies. Scan i from prior scan start through T1 history; consider i only when i > prior minimum index, M[i] through M[i-4] > bearish threshold, and M[i-2] > M[i], M[i-1], M[i-3], and M[i-4]. Accept the first such prior MACD peak, then accept later peaks only when M[i-2] > the last accepted prior peak; stop at the first failure. For each accepted peak at depth <= maximum divergence depth, set prior high to High[j] for the smallest j from i-pivot width through i+recent price search span where High[j] > each High[j+1] through High[j+pivot width]; if none qualifies, retain the prior high, initially 0. Return true if (M[i-2] > M[2] AND prior high < recent high) OR (M[i-2] < M[2] AND prior high > recent high).
Calculation: Bullish MACD divergence = On each new completed T2 bar, compute M = MACD(close, bullish fast lookback, bullish slow lookback, bullish signal lookback, T2). Require M[1], M[2], M[3], and M[4] < -bullish threshold and M[2] < M[1], M[3], and M[4]. Set recent low to Low[p] for the smallest p from 0 through recent price search span where Low[p] < each Low[p+1] through Low[p+pivot width]; shift 0 is the forming T2 bar, and recent low remains 0 if none qualifies. Scan i from prior scan start through T2 history; consider i only when i > prior minimum index, M[i] through M[i-4] < -bullish threshold, and M[i-2] < M[i], M[i-1], M[i-3], and M[i-4]. Accept the first such prior MACD peak, then accept later peaks only when M[i-2] < the last accepted prior peak; stop at the first failure. For each accepted peak at depth <= maximum divergence depth, set prior low to Low[j] for the smallest j from i-pivot width through i+recent price search span where Low[j] < each Low[j+1] through Low[j+pivot width]; if none qualifies, retain the prior low, initially 0. Return true if (M[i-2] > M[2] AND prior low < recent low) OR (M[i-2] < M[2] AND prior low > recent low).
Calculation: Stochastic band check = On chart bars, check the configured stochastic series on its timeframe at completed-bar shifts 1 + starting offset through starting offset + bar count. Return true when the oldest checked value is within the inclusive lower and upper limits and no more than max(exception allowance, 0) checked values are outside them.
Calculation: Pip price distance = the price distance corresponding to a pip-distance parameter.

Short: Bearish MACD divergence
