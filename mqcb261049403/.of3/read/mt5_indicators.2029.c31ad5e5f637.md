Calculation: TripleSmooth(x, method, phase, depth1, depth2, depth3) = Smooth(Smooth(Smooth(x, method, phase, depth1), method, phase, depth2), method, phase, depth3)
Calculation: SMI(price, lookback, method, phase, depth1, depth2, depth3) = if TripleSmooth(Highest(high, lookback) - Lowest(low, lookback), method, phase, depth1, depth2, depth3) != 0 then 200 * TripleSmooth(price - Lowest(low, lookback), method, phase, depth1, depth2, depth3) / TripleSmooth(Highest(high, lookback) - Lowest(low, lookback), method, phase, depth1, depth2, depth3) - 100 else 0
Calculation: T1 SMI = SMI(T1 price, T1 lookback, T1 method, T1 phase, T1 depth1, T1 depth2, T1 depth3), calculated on T1 bars using the still-forming bar and copied at each T1 bar's opening onto chart bars
Calculation: T1 Signal = Smooth(T1 SMI, T1 method, T1 phase, T1 depth3), calculated on T1 bars and copied at each T1 bar's opening onto chart bars
Long: SMI(current chart bar, chart price, chart lookback, chart method, chart phase, chart depth1, chart depth2, chart depth3) > Smooth(SMI(current chart bar, chart price, chart lookback, chart method, chart phase, chart depth1, chart depth2, chart depth3), chart method, chart phase, chart depth3) OR (SMI(current chart bar, chart price, chart lookback, chart method, chart phase, chart depth1, chart depth2, chart depth3) > 0 AND SMI(current chart bar, chart price, chart lookback, chart method, chart phase, chart depth1, chart depth2, chart depth3) != SMI(previous chart bar, chart price, chart lookback, chart method, chart phase, chart depth1, chart depth2, chart depth3))
Short: SMI(current chart bar, chart price, chart lookback, chart method, chart phase, chart depth1, chart depth2, chart depth3) < Smooth(SMI(current chart bar, chart price, chart lookback, chart method, chart phase, chart depth1, chart depth2, chart depth3), chart method, chart phase, chart depth3) OR (SMI(current chart bar, chart price, chart lookback, chart method, chart phase, chart depth1, chart depth2, chart depth3) < 0 AND SMI(current chart bar, chart price, chart lookback, chart method, chart phase, chart depth1, chart depth2, chart depth3) != SMI(previous chart bar, chart price, chart lookback, chart method, chart phase, chart depth1, chart depth2, chart depth3))
