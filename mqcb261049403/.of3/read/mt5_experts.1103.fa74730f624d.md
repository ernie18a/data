Calculation: color = on T1 bars, bullish or bearish or neutral using the Bulls/Bears Eyes indicator value on the last completed bar: bullish if the selected direction-change mode and the value is greater than the previous T1 bar's value, or the selected middle-threshold mode and the value is above the middle threshold, or the selected overbought/oversold mode and the value is above the overbought threshold, or the selected boundary-cross mode and the value crosses above either the overbought or oversold threshold; bearish if the selected direction-change mode and the value is less than the previous T1 bar's value, or the selected middle-threshold mode and the value is below the middle threshold, or the selected overbought/oversold mode and the value is below the oversold threshold, or the selected boundary-cross mode and the value crosses below either threshold; neutral otherwise
Calculation: signal = on each T1 bar, -2 if signal[1] > 0 AND color is bearish; -1 if (signal[1] <= 0 AND color is bearish) OR (signal[1] < 0 AND color is neutral); +2 if signal[1] < 0 AND color is bullish; +1 if (signal[1] >= 0 AND color is bullish) OR (signal[1] > 0 AND color is neutral); 0 otherwise
Long: signal = +2 AND long entries are enabled
Short: signal = -2 AND short entries are enabled
Exit: long, signal = -1 OR (signal = -2 AND short entries are disabled), AND long exits are enabled
Exit: short, signal = +1 OR (signal = +2 AND long entries are disabled), AND short exits are enabled
