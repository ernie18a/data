Calculation: chaos = absolute value of mean(r) divided by population standard deviation(r), where r[i] = log(close(T1, i)) - log(close(T1, i+1)) over the chaos lookback; use the current forming T1 bar and recompute on chart bars; chaos is 0.5 if fewer than the lookback bars are available or the standard deviation is zero
Calculation: signal strength = the sum of enabled components: RSI component weight × RSI model weight × (RSI(close, RSI lookback, T1, current forming bar sampled once at the start of each T1 bar and carried across chart bars) - RSI center) / RSI scale; ADX component weight × ADX model weight × (ADX(high, low, close, ADX lookback, T1, current forming bar sampled once at the start of each T1 bar and carried across chart bars) - ADX reference) / ADX scale; moving-average component weight × moving-average model weight × (SMA(close, shorter lookback, T1, current forming bar sampled once at the start of each T1 bar and carried across chart bars) - SMA(close, longer lookback, T1, current forming bar sampled once at the start of each T1 bar and carried across chart bars)) / instrument point size; chaos component weight × chaos model weight × chaos; quantum-state component weight × quantum-state model weight × (random integer state from zero to one less than the quantum-state count - half the quantum-state count) / quantum-state count
Long: (chaos filter disabled OR chaos >= chaos filter threshold) AND signal strength > signal threshold
Short: (chaos filter disabled OR chaos >= chaos filter threshold) AND signal strength < -signal threshold
