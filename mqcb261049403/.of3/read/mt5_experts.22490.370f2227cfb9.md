Calculation: RSI step line(step, band multiplier, RSI lookback) = on each chart bar, for each step independently, let r=RSI(close, RSI lookback); initialize prior lower=+∞, prior upper=−∞, and trend=0; set lower=r−band multiplier×step and upper=r+band multiplier×step; set trend to +1 if r>prior upper, then to −1 if r<prior lower, and otherwise retain prior trend; if trend>0, set lower=max(lower, prior lower); if trend<0, set upper=min(upper, prior upper); output lower+step for positive trend or upper−step for negative trend; store lower, upper, and trend for the next bar. Use separate fast and slow step parameters, with fast step < slow step.
Long: RSI step line(fast step, band multiplier, RSI lookback)[1] > RSI step line(slow step, band multiplier, RSI lookback)[1] AND RSI step line(fast step, band multiplier, RSI lookback)[0] <= RSI step line(slow step, band multiplier, RSI lookback)[0]
Short: RSI step line(fast step, band multiplier, RSI lookback)[1] < RSI step line(slow step, band multiplier, RSI lookback)[1] AND RSI step line(fast step, band multiplier, RSI lookback)[0] >= RSI step line(slow step, band multiplier, RSI lookback)[0]
Exit: long, RSI step line(fast step, band multiplier, RSI lookback)[1] < RSI step line(slow step, band multiplier, RSI lookback)[1]
Exit: short, RSI step line(fast step, band multiplier, RSI lookback)[1] > RSI step line(slow step, band multiplier, RSI lookback)[1]
