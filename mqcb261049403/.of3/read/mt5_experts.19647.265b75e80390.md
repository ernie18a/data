Calculation: First cloud line(system, T) = if system reverse setting then -MA(system applied price, system longer lookback, system long method, system long phase, T) / MA(system applied price, system middle lookback, system middle method, system middle phase, T) else MA(system applied price, system shorter lookback, system short method, system short phase, T) / MA(system applied price, system middle lookback, system middle method, system middle phase, T); each system has separate shorter, middle, and longer lookbacks, methods, and phases.
Calculation: Second cloud line(system, T) = if system reverse setting then -MA(system applied price, system shorter lookback, system short method, system short phase, T) / MA(system applied price, system middle lookback, system middle method, system middle phase, T) else MA(system applied price, system longer lookback, system long method, system long phase, T) / MA(system applied price, system middle lookback, system middle method, system middle phase, T).
Long: On chart bars, first cloud line(long system, T1, last completed bar) > second cloud line(long system, T1, last completed bar) AND first cloud line(long system, T1, forming bar) <= second cloud line(long system, T1, forming bar)
Short: On chart bars, first cloud line(short system, T2, last completed bar) < second cloud line(short system, T2, last completed bar) AND first cloud line(short system, T2, forming bar) >= second cloud line(short system, T2, forming bar)
Exit: long, on chart bars, first cloud line(long system, T1, last completed bar) < second cloud line(long system, T1, last completed bar)
Exit: short, on chart bars, first cloud line(short system, T2, last completed bar) > second cloud line(short system, T2, last completed bar)
