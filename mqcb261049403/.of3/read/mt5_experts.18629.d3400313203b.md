Calculation: CommonPivot[n] = scan chart bars from current toward older bars; append a slot with its high price when the short and long ZigZag main and high-buffer values are equal and nonzero, then append a slot with its low price when their main and low-buffer values are equal and nonzero; set the other price to zero and stop after the third match. The short ZigZag uses short depth, deviation, and backstep; each long ZigZag parameter equals its corresponding short parameter times one shared scale parameter.
Calculation: CommonPivotCount = number of slots appended to CommonPivot.
Calculation: UpCount = number of nonzero short-ZigZag pivots, where the main value equals its high or low buffer, counted while the latest matched common pivot is a high; update the latest matched type before counting each bar and stop before counting the bar that adds the third common pivot.
Calculation: DownCount = number of nonzero short-ZigZag pivots, where the main value equals its high or low buffer, counted while the latest matched common pivot is a low; update the latest matched type before counting each bar and stop before counting the bar that adds the third common pivot.
Long: CommonPivotCount >= 2 AND UpCount > DownCount × count-ratio parameter AND CommonPivot[0].high > CommonPivot[1].low AND CommonPivot[2].high > CommonPivot[1].low AND CommonPivot[1].low > 0 AND (CommonPivot[2].high - CommonPivot[1].low) × swing-ratio parameter < CommonPivot[0].high - CommonPivot[1].low
Short: CommonPivotCount >= 2 AND UpCount × count-ratio parameter < DownCount AND CommonPivot[0].low < CommonPivot[1].high AND CommonPivot[2].low < CommonPivot[1].high AND CommonPivot[1].high > 0 AND (CommonPivot[1].high - CommonPivot[2].low) × swing-ratio parameter < CommonPivot[1].high - CommonPivot[0].low
