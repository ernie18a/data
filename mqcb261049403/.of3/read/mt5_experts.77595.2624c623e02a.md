Calculation: KCI displacement = close of the current forming chart bar - SMA(close, KCI base lookback) on chart bars including the current forming bar
Calculation: start-of-day balance = current account balance - the sum of today's realized profit, swap, and commission
Calculation: KCI volatility distance = population standard deviation of true range over the volatility lookback * (2 - abs(close[0] - close[volatility lookback - 1]) / max(sum(abs(close[j] - close[j+1]), j=0..volatility lookback-2), abs(close[0] - close[volatility lookback - 1]), point)); true range[j] = max(high[j] - low[j], abs(high[j] - close[j+1]), abs(low[j] - close[j+1])); use current forming chart bars
Calculation: KCI-DX positive-flow index = 100 / (1 + exp(-sensitivity * ZScore(positive-flow series, KCI-DX z-score lookback))); at each offset i, positive-flow series[i] = sum(max(d[j], 0), j=0..KCI base lookback-1) / (path floor + sum(abs(d[j]), j=0..KCI base lookback-1)) * population standard deviation(close[i..i+KCI base lookback-1]), where d[j] = close[i+j] - close[i+j+1]; ZScore uses population variance and returns 0 when variance is at or below the variance cutoff
Calculation: KCI-DX negative-flow index = 100 / (1 + exp(-sensitivity * ZScore(negative-flow series, KCI-DX z-score lookback))); at each offset i, negative-flow series[i] = sum(max(-d[j], 0), j=0..KCI base lookback-1) / (path floor + sum(abs(d[j]), j=0..KCI base lookback-1)) * population standard deviation(close[i..i+KCI base lookback-1]), where d[j] = close[i+j] - close[i+j+1]; ZScore uses population variance and returns 0 when variance is at or below the variance cutoff
Calculation: KCI-DX directional index = 100 / (1 + exp(-sensitivity * ZScore(directional-flow series, KCI-DX z-score lookback))); at each offset i, directional-flow series[i] = abs(sum(d[j], j=0..KCI base lookback-1)) / (path floor + sum(abs(d[j]), j=0..KCI base lookback-1)) * population standard deviation(close[i..i+KCI base lookback-1]), where d[j] = close[i+j] - close[i+j+1]; ZScore uses population variance and returns 0 when variance is at or below the variance cutoff
Long: close > Parabolic SAR(SAR step, SAR maximum step) on the current forming chart bar AND datetime.hour >= configured start hour AND datetime.hour < configured end hour AND spread <= maximum spread
Short: close < Parabolic SAR(SAR step, SAR maximum step) on the current forming chart bar AND datetime.hour >= configured start hour AND datetime.hour < configured end hour AND spread <= maximum spread
Long: KCI displacement >= 0 AND spread <= maximum spread AND datetime is within the configured trading schedule AND (fixed-size mode OR daily drawdown limit <= 0 OR current equity > start-of-day balance * (1 - daily drawdown limit / 100))
Short: KCI displacement < 0 AND spread <= maximum spread AND datetime is within the configured trading schedule AND (fixed-size mode OR daily drawdown limit <= 0 OR current equity > start-of-day balance * (1 - daily drawdown limit / 100))
Exit: long, KCI displacement < 0
Exit: short, KCI displacement >= 0
Long: KCI Trend indicator(z-score lookback, compression threshold, base lookback) has a valid color output below the color classification threshold AND (MA filter disabled OR EMA(close, fast lookback) > EMA(close, middle lookback) AND EMA(close, middle lookback) > EMA(close, slow lookback)) AND datetime.hour >= configured start hour AND datetime.hour < configured end hour AND spread <= maximum spread
Short: KCI Trend indicator(z-score lookback, compression threshold, base lookback) has a valid color output at or above the color classification threshold AND (MA filter disabled OR EMA(close, fast lookback) < EMA(close, middle lookback) AND EMA(close, middle lookback) < EMA(close, slow lookback)) AND datetime.hour >= configured start hour AND datetime.hour < configured end hour AND spread <= maximum spread
Exit: long, KCI Trend indicator has a valid color output at or above the color classification threshold
Exit: short, KCI Trend indicator has a valid color output below the color classification threshold
Long: KCI displacement > noise-filter points * point AND spread <= maximum spread AND datetime is within the configured trading schedule AND (fixed-size mode OR daily drawdown limit <= 0 OR current equity > start-of-day balance * (1 - daily drawdown limit / 100)) AND (scalping style OR (KCI-DX directional index >= threshold for the selected non-scalping style AND KCI-DX positive-flow index > KCI-DX negative-flow index)) AND (dynamic volatility-distance mode disabled OR round(KCI volatility distance / point) >= minimum volatility points)
Short: KCI displacement < -(noise-filter points * point) AND spread <= maximum spread AND datetime is within the configured trading schedule AND (fixed-size mode OR daily drawdown limit <= 0 OR current equity > start-of-day balance * (1 - daily drawdown limit / 100)) AND (scalping style OR (KCI-DX directional index >= threshold for the selected non-scalping style AND KCI-DX negative-flow index > KCI-DX positive-flow index)) AND (dynamic volatility-distance mode disabled OR round(KCI volatility distance / point) >= minimum volatility points)
Exit: long, KCI displacement < -(noise-filter points * point)
Exit: short, KCI displacement > noise-filter points * point
