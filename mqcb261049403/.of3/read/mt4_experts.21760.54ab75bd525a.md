Calculation: fractal level = first nonzero upper or lower Fractals value scanning chart bars from oldest to current within a lookback, checking upper before lower on each bar; zero if none
Calculation: Renko direction = scan chart bars from oldest to current over a retrace lookback; at each bar return up if current ask − low >= threshold, otherwise return down if high − current ask >= threshold; threshold is ATR(lookback, current chart bar) when ATR mode is enabled, otherwise box size converted to pips; none if no match
Long: open position count < maximum positions AND abs(current bid − close[2]) > retrace parameter × point AND (close[4] <= fractal level OR close[3] <= fractal level OR close[2] <= fractal level) AND close[1] > fractal level AND Renko direction is up AND low[2] < high[1]
Short: open position count < maximum positions AND abs(current ask − close[2]) > retrace parameter × point AND (close[4] >= fractal level OR close[3] >= fractal level OR close[2] >= fractal level) AND close[1] < fractal level AND Renko direction is down
