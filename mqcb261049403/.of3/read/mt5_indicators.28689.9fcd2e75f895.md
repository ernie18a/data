Calculation: ZigZag direction = calculate ZigZag pivots on T1 and T2 bars, including the forming bar, using shared depth, deviation, backstep, level, and scan-range parameters; indices are bars ago. On T1, return +1 if the latest low pivot index is less than the latest high pivot index, or -1 if greater. On T2, return +1 or -1 when the more recent pivot index is greater than 0 and less than a recent-pivot cutoff parameter, according to whether it is a low or high; return +2 or -2 when that index is greater than the cutoff; otherwise return 0.
Calculation: MA trend = on chart bars, including the forming bar, let E=EMA(close, EMA lookback), S=SMA(close, source lookback), A=SMA(S, shorter lookback), and B=SMA(S, longer lookback), with longer lookback > shorter lookback. Return bullish if (E[0]>E[1] AND S[0]>S[1] AND A[0]>B[0] AND A[0]-B[0]>=A[1]-B[1] AND (A[2]<B[2] OR A[0]>A[1])) OR (E[0]>E[1] AND S[0]>S[1] AND S[0]-A[0]>S[1]-A[1] AND B[0]>B[1] AND S[0]>A[0]); return bearish if (E[0]<E[1] AND S[0]<S[1] AND A[0]<B[0] AND A[0]-B[0]<=A[1]-B[1] AND (A[2]>B[2] OR A[0]<A[1])) OR (E[0]<E[1] AND S[0]<S[1] AND S[0]-A[0]<S[1]-A[1] AND B[0]<B[1] AND S[0]<A[0]); otherwise return neutral.
Calculation: Direction = start neutral on each chart-bar calculation and apply these updates in order, each replacing the current direction: set up if (ZigZag direction on T2=+1 AND ZigZag direction on T1=+1) OR (MACD histogram[0]>MACD histogram[1] AND MACD main[0]>MACD main[1]); set down if (ZigZag direction on T2=-1 AND ZigZag direction on T1=-1) OR (MACD histogram[0]<MACD histogram[1] AND MACD main[0]<MACD main[1]); set down if current direction is up AND ZigZag direction on T2=+2; set up if current direction is down AND ZigZag direction on T2=-2; set up if MACD main[0]>=MACD main[1] AND MACD main[0]>MACD signal[0] AND MACD signal[0]>MACD signal[1]; set down if MACD main[0]<=MACD main[1] AND MACD main[0]<MACD signal[0] AND MACD signal[0]<MACD signal[1]; set up if MA trend is bullish; set down if MA trend is bearish.
