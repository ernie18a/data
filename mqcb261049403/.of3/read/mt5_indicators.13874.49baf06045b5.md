Calculation: normalized JMA deviation = JurX smooth(applied price - JMA(applied price, common JMA lookback, common JMA phase), JurX lookback) / JurX smooth(abs(applied price - JMA(applied price, common JMA lookback, common JMA phase)), JurX lookback), clipped to [-1, 1]
Calculation: weighted JCCX sum = shortest-term weight * normalized JMA deviation(applied price, common JMA lookback, common JMA phase, shortest JurX lookback) + second-shortest-and-middle-term weight * normalized JMA deviation(applied price, common JMA lookback, common JMA phase, second-shortest JurX lookback) + second-shortest-and-middle-term weight * normalized JMA deviation(applied price, common JMA lookback, common JMA phase, middle JurX lookback) + second-longest-term weight * normalized JMA deviation(applied price, common JMA lookback, common JMA phase, second-longest JurX lookback) + longest-term weight * normalized JMA deviation(applied price, common JMA lookback, common JMA phase, longest JurX lookback)
Calculation: smoothed weighted JCCX sum = weighted JCCX sum / smoothing lookback + prior smoothed weighted JCCX sum * (1 - 1 / smoothing lookback); initialize to weighted JCCX sum / smoothing lookback
Long: weighted JCCX sum > smoothed weighted JCCX sum, calculated on chart bars
Short: weighted JCCX sum < smoothed weighted JCCX sum, calculated on chart bars
Long: weighted JCCX sum > smoothed weighted JCCX sum, calculated on T1 bars using the still-forming T1 bar and sampled onto chart bars
Short: weighted JCCX sum < smoothed weighted JCCX sum, calculated on T1 bars using the still-forming T1 bar and sampled onto chart bars
