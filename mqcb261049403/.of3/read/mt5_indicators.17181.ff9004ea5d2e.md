Calculation: Recursive DSS = repeat for the depth parameter: on the first repetition, set C, H, and L to the median, maximum, and minimum, respectively, of the selected close-, high-, and low-price inputs; on later repetitions, set C=H=L to the prior output. Set S=MA(100*(C-LL(L, stochastic lookback))/(HH(H, stochastic lookback)-LL(L, stochastic lookback)), smoothing period, selected MA method), using 0 when the denominator is 0; output MA(100*(S-LL(S, stochastic lookback))/(HH(S, stochastic lookback)-LL(S, stochastic lookback)), smoothing period, selected MA method), using 0 when the denominator is 0.
Calculation: Percentile = sort the most recent level lookback Recursive DSS values, padding unavailable initial values with zero, then linearly interpolate at zero-based index (level lookback-1)*percentile/100.
Calculation: Upper threshold = upper-percent parameter when level lookback <= 1 or level mode is fixed; rolling minimum of Recursive DSS over the level lookback plus upper-percent parameter times its rolling range divided by 100 when level mode is floating; otherwise Percentile(Recursive DSS, level lookback, upper-percent parameter).
Calculation: Lower threshold = lower-percent parameter when level lookback <= 1 or level mode is fixed; rolling minimum of Recursive DSS over the level lookback plus lower-percent parameter times its rolling range divided by 100 when level mode is floating; otherwise Percentile(Recursive DSS, level lookback, lower-percent parameter).
Calculation: Middle threshold = mean of the upper- and lower-percent parameters when level lookback <= 1 or level mode is fixed; mean of the upper and lower thresholds when level mode is floating; otherwise Percentile(Recursive DSS, level lookback, mean of the upper- and lower-percent parameters).
Long: (signal mode is outer levels AND Recursive DSS > Upper threshold) OR (signal mode is middle level AND Recursive DSS > Middle threshold) OR (signal mode is slope AND Recursive DSS > Recursive DSS[1])
Short: (signal mode is outer levels AND Recursive DSS < Lower threshold) OR (signal mode is middle level AND Recursive DSS < Middle threshold) OR (signal mode is slope AND Recursive DSS < Recursive DSS[1])
