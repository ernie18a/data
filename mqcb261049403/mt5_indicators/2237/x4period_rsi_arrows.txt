Four semaphore signal indicators based
RSI oscillators
with different periods on one price chart.
Trend signals occur when the RSI oscillators are in the oversold and overbought areas specified in the input parameters:
input
uint
rsiUpperTrigger=
62
;
// Overbought level
input
uint
rsiLowerTrigger=
38
;
// Oversold level
Originally this indicator has been written in MQL4 and was first published in the
Code Base at mql4.com
on 19.09.2007.
