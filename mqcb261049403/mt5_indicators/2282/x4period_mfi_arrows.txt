Four semaphore signal indicators based on
MFI oscillators
with different periods on one price chart.
Trend signals occur when the RSI oscillators are in the oversold and overbought areas specified in the input parameters:
input
uint
rsiUpperTrigger=
62
;
// Overbought level
input
uint
rsiLowerTrigger=
38
;
// Oversold level
