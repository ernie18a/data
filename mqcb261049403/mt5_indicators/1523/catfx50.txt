A semaphore arrow signal indicator drawn on the basis of the EMA trend and reversal signals from crossings of the
StepSto_v1
oscillator and its signal line.
Place the StepSto_v1.ex5 compiled file to the terminal_data_folder\MQL5\Indicators.
Indicator input parameters:
//+----------------------------------------------+
//| Indicator input parameters                   |
//+----------------------------------------------+
input
int
confirm_StepMA_Bars=
2
;
//the number of bars to confirm the signal
input
HourCount TradeTimeFrom=D00;
//start trading
input
HourCount TradeTimeTo=D23;
//stop trading
input
bool
alert_ON=
false
;
//permission to send alert
input
double
Kfast=
1.0000
;
input
double
Kslow=
1.0000
;
input
uint
EMA_Period=
50
;
