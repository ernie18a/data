Description
The CATROnRingBuffer class is designed for calculation of the Average True Range indicator (
Average True Range
, ATR) using the algorithm of
the ring buffer
.
Declaration
class
CATROnRingBuffer
Title
#include <IncOnRingBuffer\CATROnRingBuffer.mqh>
File of the CATROnRingBuffer.mqh should be placed to the IncOnRingBuffer folder that need to be established in MQL5\Include\. Two files with the examples used by the class from this folder are attached to the description. File with the class of
the ring buffer
and with the class of
Moving Average
also must be in this folder.
