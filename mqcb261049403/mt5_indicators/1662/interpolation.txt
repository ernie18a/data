The Lagrange interpolating polynomial is used to determine the functions by the specified points. In fact, the indicator takes the coordinates of price points between
input int ibegin
and
input int iend
(They are drawn by red and blue lines in the chart) and with the help of the Lagrange interpolating polynomial it calculates the coordinates of the next points.
Remarks:
iend-ibegin = the degree of the polinomial
. That is, if the distance between ibegin and iend is equal to two, then the chart will be a parabola, if the three, it will be hyperbola, etc.
Indicator input parameters:
//+----------------------------------------------+
//|  INDICATOR INPUT PARAMETERS                  |
//+----------------------------------------------+
input
uint
inumPrognoz=
2
;
// Number of predicted bars
input
uint
ibegin=
0
;
// Starting bar for the analysis
input
uint
iend=
5
;
// Last bar for the analysis
