Description
The COBVOnRingBuffer class is designed for calculation the technical indicator On Balance Volume (
On Balance Volume
, OBV) using the algorithm of
the ring buffer
.
Declaration
class
COBVOnRingBuffer :
public
CArrayRing
Title
#include <IncOnRingBuffer\COBVnRingBuffer.mqh>
File of the COBVOnRingBuffer.mqh class must be placed in the IncOnRingBuffer folder that need to be established in MQL5\Include\. Two files with the examples used by the class from this folder are attached to the description. File with the class of
the ring buffer
also must be in this folder.

Integer
: if the value is 0 (default) the indicator works like the one included to the terminal - it will be calculated for all bars of the chart. In case of any other positive value specified number of bars is used (Moving Average principle) for value calculation at each chart bar.
