This is a "standard"
Relative Strength Index (RSI)
indicator with an ultralinear smoothing instead of a common one.
The indicator uses the CJurX class of the SmoothAlgorithms.mqh library. The use of this class is described in the article
"Averaging Price Series for Intermediate Calculations Without Using Additional Buffers"
.
Generated indicator was smoothed using the CJJMA class from the same file. All standard elements of the technical analysis can be applied to this indicator.
