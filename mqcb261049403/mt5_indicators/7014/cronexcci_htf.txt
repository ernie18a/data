The
CronexCCI
indicator with the timeframe selection option available in input parameters:
input
ENUM_TIMEFRAMES
TimeFrame=
PERIOD_H4
;
// Indicator chart period (timeframe)
To provide correct operation of the indicator, place the compiled CronexCCI.mq5 indicator file in terminal_data_folder\MQL5\Indicators.
