The
RSIWithFlat
indicator with the timeframe selection option available in input parameters:
input
ENUM_TIMEFRAMES
TimeFrame=
PERIOD_H4
;
// Indicator chart period (timeframe)
To provide correct operation of the indicator, place the compiled indicator file RSIWithFlat.mq5 in terminal_data_folder\MQL5\Indicators.
