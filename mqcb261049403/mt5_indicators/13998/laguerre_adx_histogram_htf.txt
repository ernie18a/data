The
Laguerre_ADX_Histogram
indicator with the timeframe selection option available in input parameters.:
input
ENUM_TIMEFRAMES
TimeFrame=
PERIOD_H4
;
// Indicator chart period (timeframe)
The indicator requires Laguerre_ADX_Histogram.mq5 indicator file. Place it in <terminal_data_folder>\MQL5\Indicators.
