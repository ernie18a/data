The
ColorX2MA_Osc
indicator with the timeframe selection option available in the input parameters:
input
ENUM_TIMEFRAMES
TimeFrame=
PERIOD_H4
;
// Indicator chart period (timeframe)
The indicator requires ColorX2MA_Osc.mq5 indicator file. Place it in <terminal_data_folder>\MQL5\Indicators.
