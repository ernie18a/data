The
OscSAR_Histogram
indicator with the timeframe selection option available in the indicator input parameters:
input
ENUM_TIMEFRAMES
TimeFrame=
PERIOD_H4
;
// Indicator chart period (timeframe)
To provide correct operation of the indicator, place the compiled OscSAR_Histogram.mq5 indicator file in terminal_data_folder\MQL5\Indicators.
