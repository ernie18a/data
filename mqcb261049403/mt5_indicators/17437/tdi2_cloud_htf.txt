The
TDI-2
indicator with the timeframe selection option available in input parameters:
input
ENUM_TIMEFRAMES
TimeFrame=
PERIOD_H4
;
// Indicator chart period (timeframe)
The TDI-2_HTF repeater indicator requires the compiled custom indicator file TDI-2.mq5 in order to compile. Place it in
<terminal_data_folder>\MQL5\Indicators
.
After compilation, the TDI-2_HTF.ex5 indicator file contains the TDI-2.ex5 indicator as a
resource
,
and therefore, it is not required to be present in the terminal folder for the compiled indicator to work! For this purpose, the corresponding code has been added to the indicator code in order to include the TDI-2 indicator in the executable file.
The indicator executable file has been added as resources at the global scope
//---- Include custom indicators in the indicator code as resources
#resource
\\Indicators\\TDI-2.ex5
Changed the string path to the indicator used as resource in the block of the OnInit() function
//--- getting the TDI-2 indicator handle
Ind_Handle=
iCustom
(
Symbol
(),TimeFrame,
"::Indicators\\TDI-2"
,TdiMethod,TdiPeriod,TdiPhase,IPC,
0
);
Thus, the compiled executable file of the repeater indicator can be used on other trade terminals on its own without the original indicator.
