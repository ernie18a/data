SetBuyStopLimitOrder script is developed for placing a BuyStopLimit order with fixed trigger levels, Stop Loss and Take Profit levels in points from the current price and order trigger prices. The main advantage of this script is its ability to fix a deal volume, which depends on the entire deposit size, using MM (Money Management) script input parameter. This script determines a ratio between the amount of funds involved in the deal and all the funds of the deposit.
