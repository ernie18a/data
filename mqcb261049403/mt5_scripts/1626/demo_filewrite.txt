The script defines the signals formed by the
MACD

In script input parameters can be specified parameters for the MACD indicator calculation, the name of the currency pair and timeframe, as well as date from which we will analyze the data. The file with the indicator signals will be located in the "Data" subdirectory of the local terminal folder.
