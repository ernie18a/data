Calculation: Fast line = selected smoothing method(MFI(MFI lookback, selected tick or real volume), shorter lookback, method-specific parameter)
Calculation: Slow line = selected smoothing method(MFI(MFI lookback, selected tick or real volume), longer lookback, same smoothing method and method-specific parameter)
Long: Fast line > Slow line
Short: Fast line < Slow line
Calculation: T1 fast line = Fast line calculated on T1 bars using the still-forming T1 bar, sampled on the first chart bar of each T1 interval and held across that interval
Calculation: T1 slow line = Slow line calculated on T1 bars using the still-forming T1 bar, sampled on the first chart bar of each T1 interval and held across that interval
Long: On chart bars, T1 fast line > T1 slow line
Short: On chart bars, T1 fast line < T1 slow line
