Calculation: base SMA-distance pair = (round(scale A × percentage distance of the last completed T1 close from SMA(close, base lookback, T1, last completed bar)), round(scale A × percentage distance of the last completed T1 open from SMA(open, base lookback, T1, last completed bar))); evaluated on chart bars.
Calculation: shorter/longer SMA-distance features = (round(scale B × percentage distance of the last completed T1 close from SMA(close, shorter lookback A, T1, last completed bar)), round(scale B × percentage distance of that close from SMA(close, longer lookback A, T1, last completed bar)), round(scale B × percentage distance of the last completed T1 open from SMA(open, shorter lookback A, T1, last completed bar)), round(scale B × percentage distance of that open from SMA(open, longer lookback A, T1, last completed bar))); evaluated on chart bars, with shorter lookback A < longer lookback A.
Calculation: longer-horizon SMA-distance pair = (round(scale A × percentage distance of the last completed T1 close from SMA(close, shorter lookback B, T1, last completed bar)), round(scale A × percentage distance of that close from SMA(close, longer lookback B, T1, last completed bar))); evaluated on chart bars, with shorter lookback B < longer lookback B.
Calculation: MACD level/change pair = (round(level scale × MACD main(close, fast lookback, slow lookback, signal lookback, T1, last completed bar)), round(change scale × (MACD main at the last completed T1 bar − MACD main at the preceding completed T1 bar))); evaluated on chart bars.
Calculation: CCI level/change pair = (round(scale C × CCI(close, lookback, T1, last completed bar)), round(scale C × (CCI at the last completed T1 bar − CCI at the preceding completed T1 bar))); evaluated on chart bars.
Calculation: completed-bar range-shape triple = (round(range height units / range-bin width), round(((high − open) / price unit) / (range normalizer × percent factor × range-bin width)), round(((high − close) / price unit) / (range normalizer × percent factor × range-bin width))), using the last completed T1 bar; range height units are (high − low) / price unit, either rounded to an integer before categorization or normalized to a precision setting before categorization; evaluated on chart bars.
Calculation: combined Bulls Power/Bears Power level/change pair = (round(level scale × (Bulls Power(close, lookback, T1, last completed bar) + Bears Power(close, lookback, T1, last completed bar))), round(change scale × (combined power at the last completed T1 bar − combined power at the preceding completed T1 bar))); evaluated on chart bars.
Calculation: close-extrema lookback/span pair = (close-extrema lookback, round(span scale × (high of the T1 bar with the highest close in the lookback − low of the T1 bar with the lowest close in the lookback))); the lookback starts with the current forming T1 bar; evaluated on chart bars.
Calculation: long signal count = sum of ten separate tuple-membership matches against bullish parameter tables A–J, respectively using: base SMA-distance pair; first and second shorter/longer SMA-distance features; third and first features; fourth and second features; longer-horizon SMA-distance pair; MACD level/change pair; CCI level/change pair; completed-bar range-shape triple; combined Bulls Power/Bears Power level/change pair; close-extrema lookback/span pair. Each table is a separate parameterized set of accepted tuples.
Calculation: short signal count = sum of ten separate tuple-membership matches against bearish parameter tables A–J, respectively using: base SMA-distance pair; first and second shorter/longer SMA-distance features; third and first features; fourth and second features; longer-horizon SMA-distance pair; MACD level/change pair; CCI level/change pair; completed-bar range-shape triple; combined Bulls Power/Bears Power level/change pair; close-extrema lookback/span pair. Each table is a separate parameterized set of accepted tuples.
Long: long signal count ≥ minimum signal count AND long signal count > short signal count
Short: short signal count ≥ minimum signal count AND short signal count > long signal count
Exit: long, time-exit switch enabled AND elapsed time since entry ≥ holding-period count × T1 duration
Exit: short, time-exit switch enabled AND elapsed time since entry ≥ holding-period count × T1 duration
