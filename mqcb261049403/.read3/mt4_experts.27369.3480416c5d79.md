Calculation: Correlation-long basket = buy pair A and sell pair B when the pairs share a base or quote currency; otherwise buy both pairs
Calculation: Correlation-short basket = sell pair A and buy pair B when the pairs share a base or quote currency; otherwise sell both pairs
Calculation: Group-side net profit = sum of open-position profit, commission, and swap for one basket in one pair group
Calculation: Group-side order count = count of open orders in one basket across both pair legs in one group
Calculation: Group-side lot-tick value = sum across both pair legs of total lots multiplied by each leg's tick value
Calculation: Progression factor = current basket-group count for linear progression; sum of successive group indices through the current count for geometric progression; or sum of max(floor parameter, growth-base parameter^(index minus exponent-offset parameter)) through the current count for exponential progression
Calculation: Group-side profit-close threshold = profit-target parameter × group-side lot-tick value − group spread costs and commissions
Calculation: Group-side loss-close threshold = −(loss-target parameter × group-side lot-tick value) − group spread costs and commissions
Calculation: Group-side next-entry loss threshold = −(add-step parameter × progression factor × group-side lot-tick value) − group spread costs and commissions
Calculation: Per-ticket profit threshold = order lots × per-ticket profit-target parameter × tick value × tick-conversion parameter
Calculation: Per-ticket loss threshold = −(order lots × per-ticket loss-target parameter × tick value × tick-conversion parameter)
Long: Open the correlation-long basket when a pair leg has no open order in that basket OR manual loss-add mode or close-in-profit-and-stop mode is selected, a complete basket is open, group-side net profit ≤ group-side next-entry loss threshold, the long basket order count ≥ the short basket order count when profit-close mode is per-side, and required seed orders and order-balance checks pass OR automatic loss-add mode and normal operation are selected, the long basket order count is zero, and the short basket has at least one complete basket; require the long side to be selected, entries enabled, market open, spread check passed when enabled, order limit permitting, and no close routine active
Short: Open the correlation-short basket when a pair leg has no open order in that basket OR manual loss-add mode or close-in-profit-and-stop mode is selected, a complete basket is open, group-side net profit ≤ group-side next-entry loss threshold, the short basket order count ≤ the long basket order count when profit-close mode is per-side, and required seed orders and order-balance checks pass OR automatic loss-add mode and normal operation are selected, the short basket order count is zero, and the long basket has at least one complete basket; require the short side to be selected, entries enabled, market open, spread check passed when enabled, order limit permitting, and no close routine active
Exit: long, regular close mode permits closing, market is open, and the long position's profit plus commission and swap ≥ per-ticket profit threshold OR ≤ per-ticket loss threshold
Exit: short, regular close mode permits closing, market is open, and the short position's profit plus commission and swap ≥ per-ticket profit threshold OR ≤ per-ticket loss threshold
Exit: long, whole-ticket loss-close mode and group-side net profit < 0 and ≤ group-side loss-close threshold for the loss-close delay in consecutive ticks; OR partial-ticket loss-close mode, active long basket-group count ≥ its start-close parameter, group-side net profit < 0, and ≤ group-side loss-close threshold for the loss-close delay in consecutive ticks
Exit: short, whole-ticket loss-close mode and group-side net profit < 0 and ≤ group-side loss-close threshold for the loss-close delay in consecutive ticks; OR partial-ticket loss-close mode, active short basket-group count ≥ its start-close parameter, group-side net profit < 0, and ≤ group-side loss-close threshold for the loss-close delay in consecutive ticks
Exit: long, per-side profit-close mode, group-side net profit > 0 and ≥ group-side profit-close threshold for the profit-close delay in consecutive ticks
Exit: short, per-side profit-close mode, group-side net profit > 0 and ≥ group-side profit-close threshold for the profit-close delay in consecutive ticks
Exit: long, basket profit-close mode, combined long and short group-side net profit > 0 and ≥ the greater of the two group-side profit-close thresholds for the profit-close delay in consecutive ticks
Exit: short, basket profit-close mode, combined long and short group-side net profit > 0 and ≥ the greater of the two group-side profit-close thresholds for the profit-close delay in consecutive ticks
Exit: long, automatic loss-add mode, long group-side net profit > 0, long basket order count ≤ short basket order count, and short group-side net profit ≤ its next-entry loss threshold for the profit-close delay in consecutive ticks
Exit: short, automatic loss-add mode, short group-side net profit > 0, short basket order count ≤ long basket order count, and long group-side net profit ≤ its next-entry loss threshold for the profit-close delay in consecutive ticks
Exit: long, hybrid profit-close mode with loss-add mode disabled, and the highest-profit and lowest-profit long groups among all but the first configured group have combined net profit ≥ the greater of their long-side profit-close thresholds
Exit: short, hybrid profit-close mode with loss-add mode disabled, and the highest-profit and lowest-profit short groups among all but the first configured group have combined net profit ≥ the greater of their short-side profit-close thresholds
Exit: long, hybrid profit-close mode with loss-add mode enabled, and the highest-net-profit and lowest-net-profit groups among all but the first configured group have combined net profit ≥ the greater of the long-side and short-side profit-close thresholds at the lowest-profit group
Exit: short, hybrid profit-close mode with loss-add mode enabled, and the highest-net-profit and lowest-net-profit groups among all but the first configured group have combined net profit ≥ the greater of the long-side and short-side profit-close thresholds at the lowest-profit group
Exit: long, immediate-close-all mode is selected
Exit: short, immediate-close-all mode is selected
