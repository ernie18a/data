Calculation: quiet-bar range(lookback) = maximum of high[n] - low[n] for n = 2 through lookback + 1, in pips
Calculation: breakout-bar range = high[1] - low[1]
Long: EMA(close, long first shorter lookback)[1] > EMA(close, long first longer lookback)[1] AND EMA(close, long second shorter lookback)[1] > EMA(close, long second longer lookback)[1] AND open[1] > EMA(close, long breakout-open lookback)[1] AND quiet-bar range(long quiet-bar lookback) > long minimum quiet-bar range AND (close[1] - open[1]) in pips >= quiet-bar range(long quiet-bar lookback) * long impulse-strength parameter AND close[1] >= open[1] AND (long minimum candle size <= 0 OR breakout-bar range in pips >= long minimum candle size) AND (long maximum candle size <= 0 OR breakout-bar range in pips <= long maximum candle size) AND close[1] >= high[1] - breakout-bar range * long maximum upper-wick percentage / 100 AND open[1] >= low[1] + breakout-bar range * long minimum lower-wick percentage / 100 AND low[1] <= EMA(close, long breakout-low lookback)[1]
Short: EMA(close, short first shorter lookback)[1] < EMA(close, short first longer lookback)[1] AND EMA(close, short second shorter lookback)[1] < EMA(close, short second longer lookback)[1] AND open[1] < EMA(close, short breakout-open lookback)[1] AND quiet-bar range(short quiet-bar lookback) > short minimum quiet-bar range AND (open[1] - close[1]) in pips >= quiet-bar range(short quiet-bar lookback) * short impulse-strength parameter AND close[1] < open[1] AND (short minimum candle size <= 0 OR breakout-bar range in pips >= short minimum candle size) AND (short maximum candle size <= 0 OR breakout-bar range in pips <= short maximum candle size) AND open[1] <= high[1] - breakout-bar range * short minimum upper-wick percentage / 100 AND close[1] <= low[1] + breakout-bar range * short maximum lower-wick percentage / 100 AND high[1] >= EMA(close, short breakout-high lookback)[1]
Exit: long, low <= entry price - long stop-loss distance OR high >= entry price + long take-profit distance
Exit: short, high >= entry price + short stop-loss distance OR low <= entry price - short take-profit distance
