Calculation: moving-average spread[n] = MA(close, shorter lookback, method parameter, T1, bar n) - MA(close, longer lookback, same method parameter, T1, bar n), calculated on T1 bars with bar 0 still forming and bars 1 and 2 completed; chart bars use these T1 values
Long: hour of the signal bar's datetime is within the configured session hours, adjusted by the data-timezone parameter, AND moving-average spread[0] > 0 AND (moving-average spread[1] < 0 OR (moving-average spread[1] = 0 AND moving-average spread[2] < 0) OR (moving-average spread[1] > 0 AND moving-average spread[2] > moving-average spread[1] AND moving-average spread[0] >= moving-average spread[1] AND moving-average spread[1] <= bounce parameter × point size)
Short: hour of the signal bar's datetime is within the configured session hours, adjusted by the data-timezone parameter, AND moving-average spread[0] < 0 AND (moving-average spread[1] > 0 OR (moving-average spread[1] = 0 AND moving-average spread[2] > 0) OR (moving-average spread[1] < 0 AND moving-average spread[2] < moving-average spread[1] AND moving-average spread[0] <= moving-average spread[1] AND absolute value of moving-average spread[1] <= bounce parameter × point size)
