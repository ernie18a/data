Calculation: bullish votes on T = on chart bars, using the T bar mapped from each chart-bar timestamp (which may still be forming), count one vote for each condition: EMA(close, short lookback, T, mapped bar) > EMA(close, short lookback, T, previous bar); EMA(close, medium lookback, T, mapped bar) > EMA(close, medium lookback, T, previous bar); EMA(close, long lookback, T, mapped bar) > EMA(close, long lookback, T, previous bar); CCI(close, lookback, T, mapped bar) > centerline; MACD main(close, fast lookback, slow lookback, signal lookback, T, mapped bar) > MACD signal(close, fast lookback, slow lookback, signal lookback, T, mapped bar); +DI(lookback, T, mapped bar) > -DI(lookback, T, mapped bar); Bulls Power(close, lookback, T, mapped bar) > zero; Bears Power(close, lookback, T, mapped bar) > zero; Stochastic main(K lookback, D lookback, slowing, simple, low/high, T, mapped bar) >= Stochastic signal(same parameters); RSI(close, lookback, T, mapped bar) >= centerline; Force Index(close, volume, lookback, simple, T, mapped bar) >= zero; Momentum(close, lookback, T, mapped bar) >= neutral level; DeMarker(lookback, T, mapped bar) >= DeMarker(lookback, T, previous bar). Calculation: bearish votes on T = on chart bars, using the T bar mapped from each chart-bar timestamp (which may still be forming), count one vote for each condition: EMA(close, short lookback, T, mapped bar) < EMA(close, short lookback, T, previous bar); EMA(close, medium lookback, T, mapped bar) < EMA(close, medium lookback, T, previous bar); EMA(close, long lookback, T, mapped bar) < EMA(close, long lookback, T, previous bar); CCI(close, lookback, T, mapped bar) < centerline; MACD main(close, fast lookback, slow lookback, signal lookback, T, mapped bar) < MACD signal(same parameters); +DI(lookback, T, mapped bar) < -DI(lookback, T, mapped bar); Bulls Power(close, lookback, T, mapped bar) < zero; Bears Power(close, lookback, T, mapped bar) < zero; Stochastic main(K lookback, D lookback, slowing, simple, low/high, T, mapped bar) < Stochastic signal(same parameters); RSI(close, lookback, T, mapped bar) < centerline; Force Index(close, volume, lookback, simple, T, mapped bar) < zero; Momentum(close, lookback, T, mapped bar) < neutral level; DeMarker(lookback, T, mapped bar) < DeMarker(lookback, T, previous bar). Use the same indicator parameters on T1 through T7.
Calculation: bullish power percentage = sum of bullish votes on T1 through T7 divided by the sum of bullish and bearish votes on T1 through T7, expressed as a percentage.
Calculation: bearish power percentage = the complement of the bullish power percentage rounded to the nearest whole percentage point.
Calculation: upward analysis percentage = upward analysis votes divided by all upward and downward analysis votes on chart bars, expressed as a percentage. Upward votes are: RSI(close, longer analysis lookback) now > RSI(close, longer analysis lookback) at the analysis lag; RSI(close, shorter analysis lookback) now > RSI(close, longer analysis lookback) now AND RSI(close, shorter analysis lookback) at the analysis lag < RSI(close, longer analysis lookback) at the analysis lag; longer-lookback RSI > RSI midpoint AND <= RSI upper band; Stochastic main(K lookback, D lookback, slowing, simple, low/high) now > the same Stochastic main at the analysis lag; either Stochastic signal now > Stochastic main now AND Stochastic signal on the previous bar < Stochastic main on the previous bar, OR Stochastic signal now < Stochastic main now AND Stochastic signal on the previous bar > Stochastic main on the previous bar; Stochastic main > Stochastic midpoint AND <= Stochastic upper band. Downward votes are: longer-lookback RSI now < longer-lookback RSI at the analysis lag; shorter-lookback RSI now < longer-lookback RSI now AND shorter-lookback RSI at the analysis lag > longer-lookback RSI at the analysis lag; longer-lookback RSI >= RSI lower band AND <= RSI midpoint; Stochastic main now < Stochastic main at the analysis lag; Stochastic main >= Stochastic lower band AND <= Stochastic midpoint. The two Stochastic crossover patterns each add an upward vote. The shorter analysis RSI lookback is shorter than the longer analysis RSI lookback.
Calculation: downward analysis percentage = the complement of the upward analysis percentage.
Calculation: analysis prediction category = strong long if upward analysis percentage >= prediction analysis floor AND bullish power percentage > strong-power threshold; otherwise strong short if downward analysis percentage >= prediction analysis floor AND bearish power percentage > strong-power threshold; otherwise weak long if upward analysis percentage >= prediction analysis floor AND bullish power percentage < weak-power ceiling; otherwise weak short if downward analysis percentage >= prediction analysis floor AND bearish power percentage < weak-power ceiling.
Calculation: upper buy zone = session pivot + first ATR-derived distance.
Calculation: lower sell zone = session pivot - first ATR-derived distance.
Calculation: first upper target = session pivot + first ATR-derived distance + second ATR-derived distance.
Calculation: first lower target = session pivot - first ATR-derived distance - second ATR-derived distance.
