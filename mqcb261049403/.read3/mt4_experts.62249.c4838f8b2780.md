Calculation: next grid distance(side) = base step in price units × selected spacing multiplier; fixed spacing uses a unit multiplier, linear spacing uses the same-side open order count, and exponential spacing uses max(unit multiplier, grid growth factor^(same-side open order count after the first))
Long: Long orders enabled AND (no open long order OR (an open long order AND (short orders disabled OR an open short order) AND ((with-trend grid AND high >= latest long entry price + next grid distance(long)) OR (contrary-trend grid AND low <= latest long entry price - next grid distance(long)))))
Short: Short orders enabled AND (no open short order OR (an open short order AND (long orders disabled OR an open long order) AND ((with-trend grid AND low <= latest short entry price - next grid distance(short)) OR (contrary-trend grid AND high >= latest short entry price + next grid distance(short)))))
