Calculation: Relative-strength signal = long when RSI(close, RSI lookback, T1, last completed bar) is greater than RSI(close, RSI lookback, T1, prior completed bar) and below the upper RSI threshold; short when it is lower than the prior value and above the separate lower RSI threshold; otherwise neutral. Evaluated on chart bars using T1 values.
Calculation: Moving-average signal = long when SMA(close, moving-average lookback, T2, last completed bar, moving-average shift) is greater than its prior completed T2-bar value and greater than the current forming chart-bar close; short when it is lower than its prior value and lower than the current forming chart-bar close; otherwise neutral. Evaluated on chart bars using T2 values.
Calculation: Open-bar correlation signal = the current chart-bar direction from the open-bar correlation indicator, using four configured related instruments, an independent direction sign for each, confirmation-count bounds, movement and history lookbacks, minimum entry difference, close steps before and opposite movement, and a trend lookback.
Calculation: Quantum signal = the current chart-bar direction from the Quantum indicator using its configured orientation, history lookback, and calculation method; the method selects either the first signal output or the inverse of the third signal output.
Calculation: Twitter-sentiment signal = short if the current forming chart-bar sell output is nonzero; otherwise long if its buy output is nonzero; otherwise neutral. The indicator uses separate distance, mood-maximum, and moving-average-period parameters.
Calculation: Entry confirmation count = count aligned signal evaluations since the last opposite-direction evaluation; a neutral evaluation resets both counts only when neutral reset is enabled, and otherwise leaves them unchanged.
Calculation: Swing-extrema permissions = on chart bars, using the current forming bar, long is blocked only if the highest-high position in the last N bars is more recent than the lowest-low position, current close minus the N-bar low exceeds the stop-loss distance, and either the first-half highest high is no greater than the highest high in the N bars starting at round(N/2)+1 or the first-half lowest low is no greater than the lowest low in that older window; short is blocked only if the highest-high position is older than the lowest-low position, the N-bar high minus current close exceeds the stop-loss distance, and either the first-half highest high is no less than the highest high in that older window or the first-half lowest low is no less than the lowest low in that older window.
Calculation: T3 trend slope = abs((close[1,T3] - close[D,T3]) / (point size * D)), using completed T3 bars.
Calculation: T3 trend deviation = sum for k from 1 through D of abs(close[k,T3] - (close[1,T3] + k * (close[D,T3] - close[1,T3]) / D)) / point size, using completed T3 bars.
Calculation: Location-trend signal = long when T3 trend slope is at least the minimum slope, T3 trend deviation is no greater than the maximum deviation, and close[1,T3] is at least close[D,T3]; short when those slope and deviation conditions hold and close[1,T3] is below close[D,T3]; otherwise neutral. Evaluated on chart bars using T3 values.
Calculation: Temporary-tick direction = long when the count of upward quote-price changes among the configured recent ticks is at least the required count; short when that count is no greater than the sample size minus the required count; otherwise neutral. No direction is reported when the required count is no greater than half the sample size.
Calculation: Pending peak levels = at a directional signal, current price minus the configured fraction of the high-low range over the configured chart-bar lookback for a long, or plus that amount for a short; each level expires after the configured number of forward chart bars. While active, long is blocked above its level and short is blocked below its level.
Calculation: Exit-trend direction = sum the enabled exit-signal votes: each enabled swing-extrema, location-trend, temporary-trend, or peak filter votes long if it permits only long, short if it permits only short, and neutral if it permits both or neither; each enabled indicator signal votes its direction. Direction is long when at least one exit signal is enabled, the sum is at least the number enabled, and, if the Twitter-sentiment exit signal is enabled, its direction value is no greater than the negative distance parameter; short when the sum is no greater than the negative number enabled and, if that signal is enabled, its direction value is at least the distance parameter; otherwise neutral.
Calculation: Exit confirmation = for the relevant exit's four separate settings (filter enabled, confirmation value, follow-trend, and keep-no-trend), return the confirmation value if the filter is disabled or no exit signals are enabled; otherwise return its opposite if a long position has Twitter-sentiment direction below the distance parameter or a short position has direction above the negative distance parameter, if exit-trend direction is neutral while keep-no-trend is enabled, or if exit-trend direction matches the position while follow-trend is enabled; return the confirmation value otherwise.
Calculation: Encoded duration in seconds = 3600 * floor(hours.minutes parameter) + 6000 * fractional_part(hours.minutes parameter).
Calculation: Clock value = current hour + current minute / 100.
Calculation: Recross state = track the position's running price extremes and upper and lower midpoint-touch counts since entry, initialized at one and updated at most once per chart bar; count bars since entry whose high-low range contains a midpoint when a new extreme resets that count, shifting short-position bar ranges by spread.
Long: At least one entry signal is enabled, every enabled entry signal is long, the long confirmation count is at least the configured repeat count, and all of the following hold: current datetime is not strictly inside either configured no-trade interval; if the trading-time filter is enabled, the weekday and clock value are in its configured window (Sunday, Friday, or Monday window, or either of the two Tuesday-through-Thursday windows); spread plus broker minimum stop distance is no greater than stop-loss distance, and broker minimum stop distance is no greater than spread plus take-profit distance; if the swing-extrema filter is enabled, swing-extrema permissions allow long; if the location-trend filter is enabled, the location-trend signal is not short; if the temporary-trend filter is enabled, temporary-tick direction is not short; if the peak filter is enabled, no long peak is pending or current price is no greater than its active level.
Short: At least one entry signal is enabled, every enabled entry signal is short, the short confirmation count is at least the configured repeat count, and all of the following hold: current datetime is not strictly inside either configured no-trade interval; if the trading-time filter is enabled, the weekday and clock value are in its configured window (Sunday, Friday, or Monday window, or either of the two Tuesday-through-Thursday windows); spread plus broker minimum stop distance is no greater than stop-loss distance, and broker minimum stop distance is no greater than spread plus take-profit distance; if the swing-extrema filter is enabled, swing-extrema permissions allow short; if the location-trend filter is enabled, the location-trend signal is not long; if the temporary-trend filter is enabled, temporary-tick direction is not long; if the peak filter is enabled, no short peak is pending or current price is no less than its active level.

Exit: short, the temporary-trend exit is enabled, temporary-tick direction is long, and stop-loss price minus current ask is no greater than the configured near-stop distance.

Exit: long, the recross exit is enabled, let midpoint equal (running high + running low) / 2; select lower count and bad coefficient if midpoint is below entry price, otherwise select upper count and good coefficient; selected count is at least the configured recross threshold, lower count exceeds upper count, and current bid is no greater than midpoint + (running high - midpoint) * selected coefficient; its exit confirmation is true.
Exit: short, the recross exit is enabled, let midpoint equal running low - (running high - running low) / 2; select lower count and bad coefficient if midpoint is above entry price, otherwise select upper count and good coefficient; selected count is at least the configured recross threshold, lower count exceeds upper count, and current ask is no less than midpoint - (midpoint - running high) * selected coefficient; its exit confirmation is true.
