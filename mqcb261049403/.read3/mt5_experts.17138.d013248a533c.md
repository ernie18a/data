Calculation: ATR stop reversal(T1) = For each T1 bar b, lower[b] = MAX(high[b+i] - ATR(T1, ATR lookback)[b+i] * ATR multiplier) and upper[b] = MIN(low[b+i] + ATR(T1, ATR lookback)[b+i] * ATR multiplier) for i from 0 through stop lookback minus one; carry direction[b+1] forward, set direction bullish if close[b] > upper[b+1] and bearish if close[b] < lower[b+1], ratchet lower[b] to MAX(lower[b], lower[b+1]) while bullish and upper[b] to MIN(upper[b], upper[b+1]) while bearish; signal bullish when direction changes from bearish at bar 1 to bullish at bar 0, bearish for the reverse, otherwise neutral. Evaluated on chart updates using T1 bars, including the forming bar 0.
Calculation: Step trend(T1) = Let F = SMA(typical price, fast lookback, T1) and G = SMMA(median price, slow lookback, T1). Initialize H = L = F[1] and hiIndex = loIndex = 0; for i from r down to 0, set H = F[i] and hiIndex = i if F[i] > H, and set L = F[i] and loIndex = i if F[i] < L. Let D = F[0] - G[0] and Dprev = F[1] - G[1]. Initialize up and down false; scan j from p minus one down to 0, where p = new-bar scan length on the first evaluation or when the T1 bar count changes, otherwise p = r. In order, if hiIndex > loIndex and F[j] > L set up true and down false; if hiIndex > loIndex and D < Dprev set down true and up false; if hiIndex < loIndex and F[j] < H set down true and up false; if hiIndex < loIndex and D > Dprev set up true and down false. Output bullish if up, bearish if down, otherwise neutral. Evaluated on chart updates using T1 bars, including the forming bar 0.
Long: ATR stop reversal(T1) is bullish AND Step trend(T1) is bullish
