Calculation: SentimentScore(T) = score scale × Clamp(trend weight × Clamp((EMA(close, fast lookback, T) − EMA(close, slow lookback, T)) / ATR(lookback, T), trend lower bound, trend upper bound) / trend divisor + MACD weight × Clamp(MACD histogram(fast, slow, signal lookbacks, T) / ATR(lookback, T), MACD lower bound, MACD upper bound) / MACD divisor + stochastic weight × Clamp((Stochastic %K(K, D, slowing lookbacks, T) − stochastic center) / stochastic scale, stochastic lower bound, stochastic upper bound), score lower bound, score upper bound); indicators use T’s still-forming bar
Calculation: BollingerWidthPercentile(T) = percentile scale × count(Bollinger Band Width(current, T) ≤ Bollinger Band Width(i bars ago, T), i over the preceding width lookback) / preceding width sample count; Bollinger Bands use their lookback and deviation, and the current bar is still forming
Calculation: TrendDirection(T) = uptrend if EMA(close, fast lookback, T) > EMA(close, mid lookback, T) > EMA(close, slow lookback, T); downtrend if the inequalities are reversed; otherwise sideways; uses T’s still-forming bar
Calculation: MomentumState(T) = flat if TrendDirection(T) is sideways; for an uptrend, confirming if MACD histogram and Stochastic %K both rise from the previous completed bar, diverging if neither rises, otherwise mixed; for a downtrend, confirming if neither rises, diverging if both rise, otherwise mixed
Calculation: TrendStage(T) = sideways if TrendDirection(T) is sideways; otherwise nascent if the sign of fast EMA minus mid EMA differs between the current bar and the stage comparison lag; otherwise established if the absolute EMA gap widens over that lag and MomentumState(T) is confirming; otherwise aging if the gap does not widen and MomentumState(T) is not diverging; otherwise reversal risk
Calculation: BreakoutState(T) = false up fade if any of the preceding fade window’s completed bars has a high above the highest high of the Donchian lookback bars preceding it and the current close is below the upper Donchian channel; else false down fade if any such bar has a low below the lowest low of the preceding Donchian lookback bars and the current close is above the lower channel; else confirmed up if the previous completed close is above the upper channel and the current close exceeds it by more than the breakout ATR multiplier × current ATR; else confirmed down by the inverse comparison; else testing upper if current close is above the upper channel; else testing lower if below the lower channel; otherwise inside range. Donchian channels use the preceding completed bars; current close and ATR use T’s still-forming bar
