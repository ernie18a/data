Calculation: Indicator signal(mode, x, y, z, previous x, close, second-buffer index, third-buffer index) = zero-cross: bearish if x < z, bullish if x > z, otherwise neutral; two-line cross: bullish if x < y, bearish if x > y, otherwise neutral; ASH: bullish if x > zero, otherwise bearish if y > zero, otherwise neutral; AO: bearish if x < previous x, bullish if x > previous x, otherwise neutral; moving averages: bullish if x < close, bearish if x > close, otherwise neutral; Lines: bullish if x equals the active-line marker, otherwise bearish if y equals the active-line marker, otherwise neutral; WAE: bullish if x > z, otherwise bearish if y > z, otherwise neutral; WAE volume: bullish if x > z or y > z, otherwise bearish; RSX: bullish if x is nonzero, otherwise bearish if y is nonzero, otherwise neutral; level cross: bearish if x < -z, bullish if x > z, otherwise neutral; NULL: bearish if x is not empty, otherwise bullish if y is not empty, otherwise neutral; upper/lower comparison: bullish if x > the second-buffer index, otherwise bearish if x < the third-buffer index, otherwise neutral. x, y, z, and close are values on the evaluated chart bar; previous x is from the preceding chart bar. Each indicator slot has its own selected indicator, mode, and buffer selectors.
Calculation: First confirmation signal = Indicator signal using the first confirmation slot's selection.
Calculation: Second confirmation signal = its selected indicator signal when enabled, otherwise the first confirmation signal.
Calculation: Exit indicator signal = its selected indicator signal when enabled, otherwise the first confirmation signal.
Calculation: Extra signal = its selected indicator signal when enabled; otherwise bullish in volume-based mode, the baseline signal in baseline-linked mode when the baseline is enabled, or the first confirmation signal.
Calculation: Baseline signal = its selected indicator signal when enabled; otherwise the extra signal in baseline-linked mode when the extra is enabled, or the first confirmation signal.
Calculation: Volume signal = its selected indicator signal when enabled; otherwise bullish when volume direction is disabled, or the first confirmation signal when volume direction is enabled.
Calculation: Baseline reference = the selected baseline indicator's first-buffer value when the baseline is enabled, otherwise entry price.
Calculation: Extra reference = the selected extra indicator's first-buffer value when the extra is enabled in baseline-linked mode, otherwise entry price.
Calculation: Long transition = the previous completed chart bar's first confirmation, second confirmation, or baseline signal is not bullish, or the extra mode is baseline-linked or directional and its previous extra signal is not bullish.
Calculation: Short transition = the previous completed chart bar's first confirmation, second confirmation, or baseline signal is not bearish, or the extra mode is baseline-linked or directional and its previous extra signal is not bearish.
Calculation: Long continuation state becomes true after a long entry or, when continuation without a prior trade is enabled, after a bar with bullish first confirmation, second confirmation, exit, and baseline signals, an extra signal that is bullish or a volume-based or remaining extra mode, and a long transition. It becomes false when continuation trades are disabled, the baseline signal is not bullish, or baseline-linked mode has an extra signal that is not bullish. The entry gate uses the state carried into the current bar.
Calculation: Short continuation state becomes true after a short entry or, when continuation without a prior trade is enabled, after a bar with bearish first confirmation, second confirmation, exit, and baseline signals, an extra signal that is bearish or a volume-based or remaining extra mode, and a short transition. It becomes false when continuation trades are disabled, the baseline signal is not bearish, or baseline-linked mode has an extra signal that is not bearish. The entry gate uses the state carried into the current bar.
Calculation: Long stop starts at entry price minus ATR(lookback, last completed chart bar at entry) times the stop-loss parameter. When scale-out and trailing are enabled, if the previous completed close minus entry price is at least ATR at entry times the trailing-start parameter and the previous close minus the current stop exceeds ATR at entry times the trailing-distance parameter, set the stop to the previous close minus that trailing distance. When scale-out is enabled, the second target is absent, the first scaled leg has closed, the current open is above entry price, and the stop is below entry price, set the stop to entry price.
Calculation: Short stop starts at entry price plus ATR(lookback, last completed chart bar at entry) times the stop-loss parameter. When scale-out and trailing are enabled, if entry price minus the previous completed close is at least ATR at entry times the trailing-start parameter and the current stop minus the previous close exceeds ATR at entry times the trailing-distance parameter, set the stop to the previous close plus that trailing distance. When scale-out is enabled, the second target is absent, the first scaled leg has closed, the current open is below entry price, and the stop is above entry price, set the stop to entry price.
Long: First confirmation, second confirmation, exit indicator, and baseline signals are bullish AND (extra signal is bullish OR extra mode is volume-based or remaining) AND long transition AND (((distance parameter is at its bypass setting OR (baseline reference + distance parameter * ATR(lookback, last completed chart bar) > previous completed close AND extra reference + distance parameter * ATR(lookback, last completed chart bar) > previous completed close)) AND (extra signal is bullish OR extra mode is baseline-linked or directional) AND volume signal is bullish) OR long continuation state).
Short: First confirmation, second confirmation, exit indicator, and baseline signals are bearish AND (extra signal is bearish OR extra mode is volume-based or remaining) AND short transition AND (((distance parameter is at its bypass setting OR (baseline reference - distance parameter * ATR(lookback, last completed chart bar) < previous completed close AND extra reference - distance parameter * ATR(lookback, last completed chart bar) < previous completed close)) AND (extra signal is bullish OR extra mode is not volume-based) AND (extra signal is bearish OR extra mode is not remaining) AND ((volume direction is disabled AND volume signal is bullish) OR (volume direction is enabled AND volume signal is bearish))) OR short continuation state).
Exit: Long, first confirmation signal is not bullish OR second confirmation signal is not bullish OR exit indicator signal is not bullish OR baseline signal is not bullish OR (extra mode is baseline-linked or directional AND extra signal is not bullish) OR low <= long stop OR high >= entry price + ATR(lookback, last completed chart bar at entry) * take-profit parameter OR (scale-out enabled AND second target enabled AND high >= entry price + ATR(lookback, last completed chart bar at entry) * second take-profit parameter).
Exit: Short, first confirmation signal is not bearish OR second confirmation signal is not bearish OR exit indicator signal is not bearish OR baseline signal is not bearish OR (extra mode is baseline-linked or directional AND extra signal is not bearish) OR high + spread * point size >= short stop OR low + spread * point size <= entry price - ATR(lookback, last completed chart bar at entry) * take-profit parameter OR (scale-out enabled AND second target enabled AND low + spread * point size <= entry price - ATR(lookback, last completed chart bar at entry) * second take-profit parameter).
