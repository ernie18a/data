Calculation: Range reversal state = on T1 bars, initialize upper and lower thresholds to the selected applied price and state to 0; when selected applied price > upper threshold + range distance, set upper threshold to selected applied price, lower threshold to upper threshold − range distance, and state to +1; otherwise, when selected applied price < lower threshold − range distance, set lower threshold to selected applied price, upper threshold to lower threshold + range distance, and state to −1; otherwise retain the thresholds and state; mark bullish on a change from −1 to +1 and bearish on a change from +1 to −1, retaining the latest marker direction and bar
Long: bullish marker at lag N on T1 bars (N=0 uses the forming bar; N>0 uses a completed bar) OR position side is long AND close − entry price > add-on step × point size AND add-on count < maximum add-ons
Short: bearish marker at lag N on T1 bars (N=0 uses the forming bar; N>0 uses a completed bar) OR position side is short AND entry price − close > add-on step × point size AND add-on count < maximum add-ons
Exit: long, the latest reversal marker older than lag N on T1 bars is bearish
Exit: short, the latest reversal marker older than lag N on T1 bars is bullish
