Calculation: Stochastic RSI = 100 × sum over the slowing lookback of (selected RSI value − its rolling minimum over the stochastic lookback) / sum over the slowing lookback of (its rolling maximum − its rolling minimum); selected RSI value = selected RSI method(MA(selected price, selected smoothing method, smoothing lookback), RSI lookback); return zero if the denominator is zero
Calculation: Upper level = fixed upper-level parameter, or rolling minimum(Stochastic RSI, level lookback) + upper range percentage parameter × rolling range(Stochastic RSI, level lookback) / 100, or rolling quantile(Stochastic RSI, level lookback, upper percentile parameter), according to level mode
Calculation: Lower level = fixed lower-level parameter, or rolling minimum(Stochastic RSI, level lookback) + lower range percentage parameter × rolling range(Stochastic RSI, level lookback) / 100, or rolling quantile(Stochastic RSI, level lookback, lower percentile parameter), according to level mode
Calculation: Middle level = (Upper level + Lower level) / 2
Calculation: Color state = in outer-level mode, up when Stochastic RSI > Upper level, down when Stochastic RSI < Lower level, neutral when Lower level < Stochastic RSI < Upper level, otherwise the prior state; in middle-line mode, up when Stochastic RSI > Middle level, down when Stochastic RSI < Middle level, otherwise neutral; in slope mode, up when Stochastic RSI > Stochastic RSI[1], down when Stochastic RSI < Stochastic RSI[1], otherwise neutral
Long: Color state = up AND Color state[1] ≠ up, on the alert-selected chart bar
Short: Color state = down AND Color state[1] ≠ down, on the alert-selected chart bar
