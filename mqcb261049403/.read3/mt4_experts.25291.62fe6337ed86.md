Long: absolute distance between current bid and close[2] > retracement distance in points × point size AND LWMA(typical price, fast lookback, chart, current forming bar) > LWMA(typical price, slow lookback, chart, current forming bar) AND fast lookback < slow lookback AND low[2] < high[1] AND RSI(close, chart RSI lookback, chart, last completed bar) > long RSI threshold AND RSI(close, T1 RSI lookback, T1 current forming bar sampled on chart bars) > RSI(close, same T1 RSI lookback, T1 last completed bar sampled on chart bars) AND upper fractal trendline first anchor price > second anchor price AND lower fractal trendline first anchor price > second anchor price
Short: absolute distance between current ask and close[1] > retracement distance in points × point size AND LWMA(typical price, fast lookback, chart, current forming bar) < LWMA(typical price, slow lookback, chart, current forming bar) AND fast lookback < slow lookback AND low[1] < high[2] AND RSI(close, chart RSI lookback, chart, last completed bar) < short RSI threshold AND RSI(close, T1 RSI lookback, T1 current forming bar sampled on chart bars) < RSI(close, same T1 RSI lookback, T1 last completed bar sampled on chart bars) AND upper fractal trendline first anchor price < second anchor price AND lower fractal trendline first anchor price < second anchor price
Calculation: short-period EMA alignment = EMA(typical price, p1, T2 current forming bar sampled on chart bars) = EMA(typical price, p2, T2 current forming bar sampled on chart bars) = EMA(typical price, p3, T2 current forming bar sampled on chart bars) = EMA(typical price, p4, T2 current forming bar sampled on chart bars) = EMA(typical price, p5, T2 current forming bar sampled on chart bars) = EMA(typical price, p6, T2 current forming bar sampled on chart bars), where p1 < p2 < p3 < p4 < p5 < p6
Calculation: long-period EMA alignment = EMA(typical price, q1, T2 current forming bar sampled on chart bars) = EMA(typical price, q2, T2 current forming bar sampled on chart bars) = EMA(typical price, q3, T2 current forming bar sampled on chart bars) = EMA(typical price, q4, T2 current forming bar sampled on chart bars) = EMA(typical price, q5, T2 current forming bar sampled on chart bars) = EMA(typical price, q6, T2 current forming bar sampled on chart bars), where p6 < q1 < q2 < q3 < q4 < q5 < q6
Exit: long, short-period EMA alignment OR long-period EMA alignment OR close[1] <= Bollinger lower band(close, lookback, standard-deviation multiplier, chart, last completed bar)
Exit: short, short-period EMA alignment OR long-period EMA alignment OR close[1] <= Bollinger lower band(close, lookback, standard-deviation multiplier, chart, last completed bar)
