Calculation: Fan(T1) = +1 when EMA(close, longest lookback, T1, last completed bar) < EMA(close, next-longest lookback, T1, last completed bar) < EMA(close, middle lookback, T1, last completed bar) and their instrument-digit-rounded values satisfy middle <= next-shortest <= shortest; -1 for the reversed inequalities; otherwise 0. Evaluate on each chart bar.
Calculation: Fan(T2) = +1 when EMA(close, longest lookback, T2, last completed bar) < EMA(close, next-longest lookback, T2, last completed bar) < EMA(close, middle lookback, T2, last completed bar) < rounded EMA(close, next-shortest lookback, T2, last completed bar) <= rounded EMA(close, shortest lookback, T2, last completed bar); -1 for the reversed inequalities; otherwise 0. Evaluate on each chart bar.
Calculation: Fan(T3) = +1 when EMA(close, longest lookback, T3, last completed bar) < EMA(close, next-longest lookback, T3, last completed bar) < EMA(close, middle lookback, T3, last completed bar) < EMA(close, next-shortest lookback, T3, last completed bar) < EMA(close, shortest lookback, T3, last completed bar); -1 for the reversed inequalities; otherwise 0. Evaluate on each chart bar. The five EMA lookbacks are shared across T1, T2, and T3, with shortest < next-shortest < middle < next-longest < longest.
Calculation: FanWidth(T) = round to the nearest whole point of (maximum minus minimum of the five EMAs at T's last completed bar)/point. Evaluate on each chart bar.
Calculation: FlatBounds(T1, start shift) = the upper and lower bounds of the first qualifying range grown backwards from start shift using T1 completed bars, up to a maximum scan lookback. At each added bar, invalidate if range > maximum flat height; return the range if its bar count > minimum flat length and its range < price-precision-rounded (bar count x flat-width coefficient x point); otherwise return no bounds.
Calculation: NearestHammer(T1) = the signed shift of the nearest matching T1 completed bar found scanning from bar 1 through the hammer search lookback, or 0 if none. For range = high-low, lower wick = min(open,close)-low, upper wick = high-max(open,close): return positive shift if range > minimum hammer size x point, 100 x lower wick > minimum long-shadow percentage x range, and 100 x upper wick < maximum short-shadow percentage x range; return negative shift for the reverse wick conditions.
Calculation: Bullish stochastic divergence(T1) = true when, at the recent pivot offset b, Stochastic %K(T1) is a trough lower than the following pivot-neighborhood values and satisfies K[b] < K[b-1] < ... < K[b-pivot-neighborhood]; scanning older shifts i from b plus pivot-neighborhood plus one to the divergence scan limit, return true at the first local trough i > b + minimum pivot separation whose K[i] is below K[b] and every K value scanned since b, whose price-window low is above the price-window low at b, and for which no scanned low is below the price-window low at b; otherwise false. A local trough is below each of the pivot-neighborhood %K values on both sides; each price-window low is the minimum low in the centered price-window bars.
Calculation: Bearish stochastic divergence(T1) = true when, at the recent pivot offset b, Stochastic %K(T1) is a peak higher than the following pivot-neighborhood values and satisfies K[b] > K[b-1] > ... > K[b-pivot-neighborhood]; scanning older shifts i from b plus pivot-neighborhood plus one to the divergence scan limit, return true at the first local peak i > b + minimum pivot separation whose K[i] is above K[b] and every K value scanned since b, whose price-window high is below the price-window high at b, and for which no scanned high is above the price-window high at b; otherwise false. A local peak is above each of the pivot-neighborhood %K values on both sides; each price-window high is the maximum high in the centered price-window bars.
