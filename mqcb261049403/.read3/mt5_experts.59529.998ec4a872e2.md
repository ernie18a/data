Calculation: PivotHigh(T1 bar i) = its high is greater than or equal to the highs of each of the left pivot count more recent bars and right pivot count older bars; candidates have both neighbor counts and are evaluated on each new T1 bar, using the still-forming bar if it is in the neighbor window.
Calculation: PivotLow(T1 bar i) = its low is less than or equal to the lows of each of the left pivot count more recent bars and right pivot count older bars; candidates have both neighbor counts and are evaluated on each new T1 bar, using the still-forming bar if it is in the neighbor window.
Calculation: Latest five pivots (X,A,B,C,D) = the five most recent T1 bars with PivotHigh or PivotLow, in chronological order; use the high price and high type if both qualify on one bar.
Calculation: Butterfly quality(X,A,B,C,D,direction) = clamp(quality floor, quality ceiling, quality ceiling - price penalty × (abs(B - idealB)/diff + abs(C - idealC)/diff + abs(D - idealD)/diff) - time penalty × (abs(time symmetry target - (time(B)-time(A))/(time(D)-time(C))) + abs(time symmetry target - (time(A)-time(X))/(time(C)-time(B)))); direction is +1 for bullish and -1 for bearish, diff = direction × (A-X), idealB = A - direction × B retracement ratio × diff, idealC = B + quality C ratio × (A-B), and idealD = C - quality D extension × (C-B).
Long: on a new T1 bar, X,A,B,C,D from the latest five pivots are high, low, high, low, high respectively AND diff=A-X>0 AND abs(B-(A-B retracement ratio × diff)) <= B tolerance × diff AND BC lower ratio × diff <= C-B <= BC upper ratio × diff AND CD lower ratio × diff <= C-D <= CD upper ratio × diff AND D<X AND Butterfly quality(X,A,B,C,D,+1) >= minimum quality AND (session filter disabled OR (session start hour < session end hour AND server-time hour >= session start hour AND server-time hour < session end hour) OR (session start hour >= session end hour AND (server-time hour >= session start hour OR server-time hour < session end hour))).
Short: on a new T1 bar, X,A,B,C,D from the latest five pivots are high, low, high, low, high respectively AND diff=X-A>0 AND abs(B-(A+B retracement ratio × diff)) <= B tolerance × diff AND BC lower ratio × diff <= B-C <= BC upper ratio × diff AND CD lower ratio × diff <= D-C <= CD upper ratio × diff AND D>X AND Butterfly quality(X,A,B,C,D,-1) >= minimum quality AND (session filter disabled OR (session start hour < session end hour AND server-time hour >= session start hour AND server-time hour < session end hour) OR (session start hour >= session end hour AND (server-time hour >= session start hour OR server-time hour < session end hour))).
