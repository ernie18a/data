Calculation: Long reference level = round(the still-forming chart-bar close, price precision) + reference offset
Calculation: Short reference level = round(the still-forming chart-bar close, price precision) - reference offset
Calculation: Long score = trend reward × I(RAVI(open, shorter SMA lookback, longer SMA lookback, T2, forming) < neutral RAVI level) + excursion reward × I(a high in the far-excursion lookback of completed T2 bars > long reference level + far-excursion distance) + setup reward × I(chart-bar close < long reference level AND close(T1, last completed) > long reference level AND low(T2, forming) > long reference level - reference offset + setup cushion AND low(T2, last completed) > long reference level - reference offset + setup cushion AND low(T2, second-last completed) > long reference level - reference offset) - score deduction × (count of high(T1, x) > long reference level + near-excursion distance over the recent T1 lookback + count of [high(T1, x + pattern lag) - low(T1, x) > pattern range AND open(T1, x + pattern lag) > close(T1, x) AND RAVI(open, shorter SMA lookback, longer SMA lookback, T3, forming) < -pattern RAVI bound] over the pattern T1 lookback + I(no high in the H1 excursion lookback of T2 bars > long reference level + mid-excursion distance) + I(all highs in the quiet T4 lookback of T4 bars < long reference level + quiet-range distance)); T1–T4 values are sampled on chart bars, shift zero is forming, and positive shifts are completed
Calculation: Short score = trend reward × I(RAVI(open, shorter SMA lookback, longer SMA lookback, T2, forming) > neutral RAVI level) + excursion reward × I(a low in the far-excursion lookback of completed T2 bars < short reference level - far-excursion distance) + setup reward × I(chart-bar close > short reference level AND close(T1, last completed) < short reference level AND high(T2, forming) < short reference level + reference offset - setup cushion AND high(T2, last completed) < short reference level + reference offset - setup cushion AND high(T2, second-last completed) < short reference level + reference offset) - score deduction × (count of low(T1, x) < short reference level - near-excursion distance over the recent T1 lookback + count of [high(T1, x) - low(T1, x + pattern lag) > pattern range AND close(T1, x) > open(T1, x + pattern lag) AND RAVI(open, shorter SMA lookback, longer SMA lookback, T3, forming) > pattern RAVI bound] over the pattern T1 lookback + I(no low in the H1 excursion lookback of T2 bars < short reference level - mid-excursion distance) + I(all lows in the quiet T4 lookback of T4 bars > short reference level - quiet-range distance)); T1–T4 values are sampled on chart bars, shift zero is forming, and positive shifts are completed
Long: long score >= entry score threshold
Short: short score >= entry score threshold
