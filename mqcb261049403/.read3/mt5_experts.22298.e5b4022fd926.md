Calculation: Skyscraper direction, computed independently for each instance on T bars using the bar still forming = carry the prior direction, initially neutral, and initialize both prior thresholds to the first close; on each bar set offset to offset multiplier × step, where step = point × truncate(step multiplier × sensitivity × (highest ATR(ATR period) + lowest ATR(ATR period)) / point), with the ATR extrema taken over the volatility lookback; if the prior direction is bullish, set candidate upper/lower thresholds to low + offset and high − offset, otherwise set them to close + offset and close − offset; start with the prior direction, change to bullish if close > prior upper threshold, then change to bearish if close < prior lower threshold; if the resulting direction is bullish, set the new lower threshold to max(candidate lower threshold, prior lower threshold) and the new upper threshold to candidate upper threshold; otherwise set the new upper threshold to min(candidate upper threshold, prior upper threshold) and the new lower threshold to candidate lower threshold.
Long: Skyscraper direction on the current forming T1 bar is bullish (chart bars take values from T1).
Long: Skyscraper direction on the previous T1 bar is bearish AND Skyscraper direction on the current forming T1 bar is bullish.
Short: Skyscraper direction on the current forming T2 bar is bearish (chart bars take values from T2).
Short: Skyscraper direction on the previous T2 bar is bullish AND Skyscraper direction on the current forming T2 bar is bearish.
