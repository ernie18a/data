Calculation: MACD momentum = sensitivity × (MACD main line(close, fast lookback, slow lookback, signal lookback, T1 bar) − MACD main line(close, fast lookback, slow lookback, signal lookback, preceding T1 bar)), evaluated on chart bars using the T1 bar mapped to each chart bar, including the still-forming bar
Calculation: Bollinger Band width = upper Bollinger Band(close, lookback, deviation, T1 bar) − lower Bollinger Band(close, lookback, deviation, T1 bar), evaluated on chart bars using the T1 bar mapped to each chart bar, including the still-forming bar
Calculation: Dead-zone threshold = instrument point size × dead-zone parameter
Long: current MACD momentum > 0 AND current MACD momentum > current Bollinger Band width AND current MACD momentum > dead-zone threshold AND current Bollinger Band width > dead-zone threshold AND current Bollinger Band width > preceding completed T1 bar's Bollinger Band width AND current MACD momentum > MACD momentum at the momentum-lag T1 bar before the mapped bar AND 100 × (current MACD momentum − lagged MACD momentum) / current MACD momentum ≥ trend-power parameter AND 100 × (current Bollinger Band width − preceding completed T1 bar's Bollinger Band width) / current Bollinger Band width ≥ explosion-power parameter
Short: current MACD momentum < 0 AND abs(current MACD momentum) > current Bollinger Band width AND abs(current MACD momentum) > dead-zone threshold AND current Bollinger Band width > dead-zone threshold AND current Bollinger Band width > preceding completed T1 bar's Bollinger Band width AND abs(current MACD momentum) > abs(MACD momentum at the momentum-lag T1 bar before the mapped bar) AND 100 × (abs(current MACD momentum) − abs(lagged MACD momentum)) / abs(current MACD momentum) ≥ trend-power parameter AND 100 × (current Bollinger Band width − preceding completed T1 bar's Bollinger Band width) / current Bollinger Band width ≥ explosion-power parameter
Exit: long, current MACD momentum > 0 AND current MACD momentum < current Bollinger Band width AND current MACD momentum < MACD momentum at the momentum-lag T1 bar before the mapped bar AND lagged MACD momentum > Bollinger Band width on the preceding completed T1 bar AND current MACD momentum > dead-zone threshold AND current Bollinger Band width > dead-zone threshold
Exit: short, current MACD momentum < 0 AND abs(current MACD momentum) < current Bollinger Band width AND abs(current MACD momentum) < abs(MACD momentum at the momentum-lag T1 bar before the mapped bar) AND abs(lagged MACD momentum) > Bollinger Band width on the preceding completed T1 bar AND current MACD momentum > dead-zone threshold AND current Bollinger Band width > dead-zone threshold
