Calculation: Asian range low = minimum(low, chart bars in the current server day's Asian range window)
Calculation: Asian range size = Asian range high - Asian range low
Calculation: Minimum pending-order distance = max(broker stop-level points, broker freeze-level points) * point size * distance safety-margin parameter
Calculation: Entry buffer = max(buffer ATR multiplier parameter * ATR(trade-management lookback parameter, chart timeframe, still-forming bar at order placement), minimum pending-order distance at order placement)
Calculation: Stop distance = max(stop ATR multiplier parameter * ATR(trade-management lookback parameter, chart timeframe, still-forming bar at order placement), minimum pending-order distance at order placement * stop-distance floor multiplier parameter)
Calculation: Target distance = stop distance * reward-multiple parameter
