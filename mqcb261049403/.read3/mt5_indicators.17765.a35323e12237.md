Calculation: Noise filter(x, strength, lookback) = x when filtering is off; otherwise let d[j] = |x[j] - y[j-1]| and m[j] = rolling mean of d over lookback; set y[j] = y[j-1] if d[j] < strength × sqrt(rolling mean of (d - m)^2 over lookback), else x[j]; return x on the first bar and zero-pad missing history
Calculation: Filtered Aroon oscillator(high-price source, low-price source, Aroon lookback, filter settings, T1, bar still forming) = Aroon Oscillator of the selected sources, applying the shared noise filter to the selected sources and/or oscillator output as configured; calculate on T1 bars and map values to chart bars
Calculation: Rolling quantile(x, lookback, percentile, T1, bar still forming) = linearly interpolated percentile of the current and prior x values on T1, zero-padding missing history and mapping values to chart bars
Long: Filtered Aroon oscillator(selected high-price source, selected low-price source, Aroon lookback, filter settings, T1, bar still forming) > Rolling quantile(the same oscillator, threshold lookback or Aroon lookback if unspecified, upper percentile, T1, bar still forming)
Short: Filtered Aroon oscillator(selected high-price source, selected low-price source, Aroon lookback, filter settings, T1, bar still forming) < Rolling quantile(the same oscillator, threshold lookback or Aroon lookback if unspecified, lower percentile, T1, bar still forming)
