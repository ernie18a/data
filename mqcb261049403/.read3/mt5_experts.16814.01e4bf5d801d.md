Calculation: T1 RAVI = RAVI(EMA(close, shorter lookback, T1, forming bar), EMA(close, longer lookback, T1, forming bar)), sampled each tick
Calculation: T2 RAVI = RAVI(EMA(close, shorter lookback, T2, forming bar), EMA(close, longer lookback, T2, forming bar)), sampled each tick
Calculation: LongLevel = Round(close of the forming chart bar, rounding precision) + long level offset
Calculation: ShortLevel = Round(close of the forming chart bar, rounding precision) - short level offset
Calculation: LongScore = IF(T1 RAVI < long H1 RAVI cutoff, long RAVI weight, 0) + IF(MAX(high(T1, first prior completed bar), high(T1, second prior completed bar)) > LongLevel + long rise distance, long H1 high weight, 0) + IF(close of the forming chart bar < LongLevel AND close(T3, first prior completed bar) > LongLevel AND low(T1, forming bar) > LongLevel - long level offset + long setup buffer AND low(T1, first prior completed bar) > LongLevel - long level offset + long setup buffer AND low(T1, second prior completed bar) > LongLevel - long level offset, long setup weight, 0) - long M1 extreme penalty * COUNT(x from 0 through long M1 extreme lookback, high(T3, x bars ago) > LongLevel + long M1 extreme distance) - long reversal penalty * COUNT(x from 0 through long reversal lookback, high(T3, x bars ago + long reversal offset) - low(T3, x bars ago) > long reversal range AND open(T3, x bars ago + long reversal offset) > close(T3, x bars ago) AND T2 RAVI < long daily reversal cutoff) - IF(MAX(high(T1, current bar through long H1 cross lookback bars ago)) <= LongLevel + long H1 cross distance, long no-cross penalty, 0) - IF(MAX(high(T4, current bar through long T4 lookback bars ago)) < LongLevel + long T4 distance, long T4 penalty, 0)
Calculation: ShortScore = IF(T1 RAVI > short H1 RAVI cutoff, short RAVI weight, 0) + IF(MIN(low(T1, first prior completed bar), low(T1, second prior completed bar)) < ShortLevel - short fall distance, short H1 low weight, 0) + IF(close of the forming chart bar > ShortLevel AND close(T3, first prior completed bar) < ShortLevel AND high(T1, forming bar) < ShortLevel + short level offset - short setup buffer AND high(T1, first prior completed bar) < ShortLevel + short level offset - short setup buffer AND high(T1, second prior completed bar) < ShortLevel + short level offset, short setup weight, 0) - short M1 extreme penalty * COUNT(x from 0 through short M1 extreme lookback, low(T3, x bars ago) < ShortLevel - short M1 extreme distance) - short reversal penalty * COUNT(x from 0 through short reversal lookback, high(T3, x bars ago) - low(T3, x bars ago + short reversal offset) > short reversal range AND close(T3, x bars ago) > open(T3, x bars ago + short reversal offset) AND T2 RAVI > short daily reversal cutoff) - IF(MIN(low(T1, current bar through short H1 cross lookback bars ago)) >= ShortLevel - short H1 cross distance, short no-cross penalty, 0) - IF(MIN(low(T4, current bar through short T4 lookback bars ago)) > ShortLevel - short T4 distance, short T4 penalty, 0)
Long: LongScore >= long entry threshold
Short: ShortScore >= short entry threshold
