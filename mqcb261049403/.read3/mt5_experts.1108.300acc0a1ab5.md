Calculation: Price-direction pattern = for each configured pattern price-sampling threshold, add the current close to its sample history when it moves beyond that threshold from the latest sample; evaluate when it moves beyond a separate pattern-refresh threshold from the last evaluated price; encode comparisons between successive samples in the latest sample-history length, with each bit true when the newer sample is greater than the next older sample.
Calculation: Upward outcome probability = upward outcome weight / (upward outcome weight + downward outcome weight + smoothing parameter); for each pattern and virtual stop-distance level, open a virtual observation at the current close when none is active and the observation cooldown has elapsed; when price first moves beyond its entry by the level's stop distance, divide both prior weights by the forgetting factor, add the outcome-weight increment to the weight for the direction of the move, and increment the resolved virtual-outcome count.
Calculation: Downward outcome probability = downward outcome weight / (upward outcome weight + downward outcome weight + smoothing parameter), using the same pattern, virtual observations, weight updates, and resolved virtual-outcome count as the upward outcome probability.
Calculation: Resolved virtual-outcome count = the number of virtual observations resolved for the current price-direction pattern and virtual stop-distance level; virtual stop distance equals the base stop-distance step multiplied by the level index.
Long: for any current price-direction pattern and virtual stop-distance level, upward outcome probability > opening probability threshold AND resolved virtual-outcome count > minimum outcome count AND elapsed time since the previous long entry > cooldown multiple × chart-bar duration.
Short: for any current price-direction pattern and virtual stop-distance level, downward outcome probability > opening probability threshold AND resolved virtual-outcome count > minimum outcome count AND elapsed time since the previous short entry > cooldown multiple × chart-bar duration.
Exit: long, (for any current price-direction pattern and virtual stop-distance level, downward outcome probability > opening probability threshold AND resolved virtual-outcome count > minimum outcome count AND elapsed time since the previous short entry > cooldown multiple × chart-bar duration AND downward outcome probability > the probability recorded for the previous qualifying long-close check + probability-rise threshold) OR (downward outcome probability > exit probability threshold AND resolved virtual-outcome count > minimum outcome count AND close > entry price + base stop-distance step / profit-distance divisor).
Exit: short, (for any current price-direction pattern and virtual stop-distance level, upward outcome probability > opening probability threshold AND resolved virtual-outcome count > minimum outcome count AND elapsed time since the previous long entry > cooldown multiple × chart-bar duration AND upward outcome probability > the probability recorded for the previous qualifying short-close check + probability-rise threshold) OR (upward outcome probability > exit probability threshold AND resolved virtual-outcome count > minimum outcome count AND entry price > close + base stop-distance step / profit-distance divisor).
