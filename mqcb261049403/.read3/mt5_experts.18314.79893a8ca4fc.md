Calculation: Bull prevalence = clamp(2 × (100 × count(Bulls Power(high, close, power lookback) > 0 over prevalence lookback T1 bars ending at this T1 bar) / prevalence lookback − 50), 0, 100)
Calculation: Bear prevalence = clamp(2 × (100 × count(Bears Power(low, close, power lookback) < 0 over prevalence lookback T1 bars ending at this T1 bar) / prevalence lookback − 50), 0, 100)
Calculation: Trade window active = (start hour < end hour AND ((current server hour = start hour AND current server minute >= start minute) OR (current server hour > start hour AND (current server hour < end hour OR (current server hour = end hour AND current server minute < end minute))))) OR (start hour = end hour AND current server hour = start hour AND current server minute >= start minute AND current server minute < end minute) OR (start hour > end hour AND ((current server hour >= start hour AND current server minute >= start minute) OR current server hour < end hour OR (current server hour = end hour AND current server minute < end minute))
Long: long entries enabled AND Bull prevalence crosses above Bear prevalence on the selected signal bar of T1 (still forming at zero signal-bar offset, completed at positive offset; compared with the immediately older T1 bar) AND (trading-time filter disabled OR Trade window active)
Short: short entries enabled AND Bear prevalence crosses above Bull prevalence on the selected signal bar of T1 (still forming at zero signal-bar offset, completed at positive offset; compared with the immediately older T1 bar) AND (trading-time filter disabled OR Trade window active)
Exit: long, (long exits enabled AND Bull prevalence < Bear prevalence on the selected signal bar of T1) OR (trading-time filter enabled AND NOT Trade window active)
Exit: short, (short exits enabled AND Bull prevalence > Bear prevalence on the selected signal bar of T1) OR (trading-time filter enabled AND NOT Trade window active)
