Calculation: Upper cloud line = initialize to the selected applied price on the first calculated T1 bar; on each later T1 bar, if (applied price > prior upper line AND applied price > prior applied price) OR (applied price < prior upper line AND applied price < prior applied price), set the line to prior upper line + (applied price - prior upper line) / smoothing factor; otherwise retain prior upper line
Calculation: Lower cloud line = initialize to the selected applied price on the first calculated T1 bar; on each later T1 bar, if (applied price > prior lower line AND applied price < prior applied price) OR (applied price < prior lower line AND applied price > prior applied price), set the line to prior lower line + (applied price - prior lower line) / smoothing factor; otherwise retain prior lower line
Calculation: In trading interval = if start hour < end hour, (hour = start hour AND minute >= start minute) OR (hour > start hour AND hour < end hour) OR (hour = end hour AND minute < end minute); if start hour = end hour, hour = start hour AND minute >= start minute AND minute < end minute; if start hour > end hour, (hour >= start hour AND minute >= start minute) OR hour < end hour OR (hour = end hour AND minute < end minute)
Long: long entry enabled AND (time filter disabled OR In trading interval) AND Upper cloud line (T1, bar still forming) <= Lower cloud line (T1, bar still forming) AND Upper cloud line (T1, last completed bar) > Lower cloud line (T1, last completed bar)
Short: short entry enabled AND (time filter disabled OR In trading interval) AND Upper cloud line (T1, bar still forming) >= Lower cloud line (T1, bar still forming) AND Upper cloud line (T1, last completed bar) < Lower cloud line (T1, last completed bar)
Exit: long, (long exit enabled AND Upper cloud line (T1, last completed bar) < Lower cloud line (T1, last completed bar)) OR (time filter enabled AND NOT In trading interval)
Exit: short, (short exit enabled AND Upper cloud line (T1, last completed bar) > Lower cloud line (T1, last completed bar)) OR (time filter enabled AND NOT In trading interval)
