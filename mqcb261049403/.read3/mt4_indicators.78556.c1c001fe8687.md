Calculation: Technical score = (mean of sign(close − EMA(close, each of six ascending lookbacks)) and sign(close − SMA(close, the corresponding six lookbacks)) + mean of these eight votes)/2; votes are +1 for RSI below its oversold level and rising, −1 for RSI above its overbought level and falling, otherwise 0; +1 for Stochastic %K below its oversold level and above %D, −1 for %K above its overbought level and below %D, otherwise 0; +1 for CCI below its negative threshold and rising, −1 for CCI above its positive threshold and falling, otherwise 0; +1 for AO above zero and rising, −1 for AO below zero and falling, otherwise 0; +1 when Momentum rises, otherwise −1; +1 when MACD main is above its signal, −1 when below, otherwise 0; +1 for Williams %R below its oversold level and rising, −1 above its overbought level and falling, otherwise 0; +1 for BBP above zero and rising, −1 below zero and falling, otherwise 0. Use separate parameters for each indicator lookback and threshold.
Calculation: FXR value = let midpoint=(high+low)/2, upper=Highest(high, lookback), lower=Lowest(low, lookback), x=clamp(normalization factor*((midpoint−lower)/max(upper−lower, tick size×range-floor factor)−center)+x[1]×x-smoothing factor, −clip bound, clip bound), and value=0.5×ln((1+x)/(1−x))+0.5×value[1]; initialize x and value at zero. The tick size is the instrument's minimum price increment.
Calculation: MITP indicator states = for each I in {ALMA(close, lookback, offset, sigma), DEMA(close, lookback), EMA(close, lookback), HMA(close, lookback), KAMA(close, efficiency lookback, fast lookback, slow lookback), LSMA(close, lookback), TEMA(close, lookback), WMA(close, lookback), SMA(close, lookback), AO(hl2, shorter lookback, longer lookback), SMA(CCI(typical price, lookback), separate lookback), Coppock Curve(close, longer ROC lookback, shorter ROC lookback, WMA smoothing lookback), Fisher Transform(hl2, lookback), MACD main(close, fast lookback shorter than slow lookback, signal lookback), MACD histogram(close, fast lookback shorter than slow lookback, signal lookback), PMO(close, first smoothing lookback, second smoothing lookback), PPO main(close, fast lookback shorter than slow lookback, signal lookback), PPO histogram(close, fast lookback shorter than slow lookback, signal lookback), RCI(close, base lookback), RCI(close, blue lookback), RCI(close, red lookback; red longer than blue), SMA(RSI(close, lookback), separate lookback), Relative Vigor Index(open, high, low, close, lookback), Relative Volatility Index(close, standard-deviation lookback, smoothing lookback), SMI Ergodic(close change, shorter smoothing lookback, longer smoothing lookback), SMI(close, range lookback, smoothing lookback), TSI(close change, shorter smoothing lookback, longer smoothing lookback), Pearson correlation(close, bar index, lookback), BBP(high, low, EMA(close, lookback)), CMO(close, lookback), Chop Zone(OHLC, EMA lookback, range lookback), Technical score}: for trend-based I, vote +1 when I>I[1], −1 when I<I[1], otherwise retain its previous vote; for BBP, CMO, and Technical score, vote by the sign of I; for Chop Zone, vote +1 at or above its positive threshold, −1 at or below its negative threshold, otherwise 0. On each completed chart bar, each indicator's trigger state retains its prior state and pending high/low: an opposite vote cancels the pending trigger; a +1 vote confirms bullish state when close exceeds a positive pending high, then clears it, and arms the current high when no high is pending and state is not bullish; a −1 vote confirms bearish state when close is below a positive pending low, then clears it, and arms the current low when no low is pending and state is not bearish. Neutral votes leave pending triggers unchanged. Confirmed state persists until an opposite confirmation. Count bullish and bearish states across all listed indicators as the respective MITP counts.
Calculation: ATR trailing-stop state = use True Range and Wilder ATR with its own lookback; initialize ATR as the mean of True Range over that lookback, trail at close minus ATR times its own factor, and state bullish. On each completed chart bar, update ATR by Wilder smoothing. If current and previous closes are both above the trail, update the trail to the greater of its old value and current close minus factor×current ATR when already bullish; otherwise set it to the greater of current close minus factor×current ATR and previous close minus factor×previous ATR and set state bullish. If both closes are below the trail, symmetrically update to the lesser of the old trail and current close plus factor×current ATR when already bearish; otherwise use the lesser of current close plus factor×current ATR and previous close plus factor×previous ATR and set state bearish. Otherwise retain trail and state.
Calculation: Best Slope state = on each completed chart bar, set bullish when Stochastic, CCI, DeMarker, MFI, OSMA, Acceleration/Deceleration, AO, and Accumulation/Distribution are all greater than their respective prior-bar values; set bearish when all are less than their prior-bar values; otherwise retain prior state.
Calculation: FXR state = set bullish when FXR value > 0, bearish when FXR value < 0, otherwise retain prior state.
Calculation: Key Master state = set bullish when RSI exceeds its bullish level, Heikin-Ashi close exceeds Heikin-Ashi open, Stochastic exceeds its bullish level, CCI exceeds its negative gate, and Williams %R exceeds its negative gate; set bearish when RSI is below its bearish level, Heikin-Ashi close is below Heikin-Ashi open, Stochastic is below its bearish level, CCI is below its positive gate, and Williams %R is below its positive gate; otherwise retain prior state. Use separate parameters for the RSI, Stochastic, CCI, and Williams %R gates.
Calculation: Key Trading state = set bullish when RSI exceeds its midpoint, Parabolic SAR is below close, Heikin-Ashi close exceeds Heikin-Ashi open, Stochastic exceeds its midpoint, CCI is positive, Williams %R exceeds its midpoint, and Bulls Power is positive; set bearish when RSI is below its midpoint, Parabolic SAR is above close, Heikin-Ashi close is below Heikin-Ashi open, Stochastic is below its midpoint, CCI is negative, Williams %R is below its midpoint, and Bears Power is negative; otherwise retain prior state.
Calculation: Institutional MACD state = on each completed chart bar, let delta be the current minus prior value of MACD main plus MACD histogram, using the same MACD parameters (fast lookback shorter than slow lookback); let threshold be ATR with its own lookback times a factor that is doubled when ADX with its own lookback is below its own threshold. Set bullish when delta>threshold, bearish when delta≤−threshold, otherwise retain prior state.
Calculation: Ultimate MACD state = on each completed chart bar, let delta be the current minus prior value of MACD main plus MACD histogram, using the same MACD parameters (fast lookback shorter than slow lookback); let threshold be the population standard deviation of MACD histogram over its own lookback times its own band factor. Set bullish when delta>threshold, bearish when delta<−threshold, otherwise retain prior state.
Calculation: Full-consensus MITP state = on each completed chart bar, when all MITP indicator states are bearish cancel any pending bullish high; when all are bullish cancel any pending bearish low. Confirm bullish state when all are bullish and close exceeds a positive pending high; confirm bearish state when all are bearish and close is below a positive pending low. When all are bullish and no high is pending and state is not bullish, arm the current high; symmetrically arm the current low when all are bearish and state is not bearish. Otherwise retain state and pending triggers.
Calculation: Threshold MITP state = on each chart bar, let bullish-on and bearish-on mean the respective MITP state counts meet their separately parameterized thresholds; new means on now but not on the prior bar. If only bullish-on, set bullish; if only bearish-on, set bearish. If both are on, set bullish only when bullish is new and bearish is not, or bearish only when bearish is new and bullish is not; otherwise retain prior state. If neither is on, retain prior state.
Calculation: Pin-Point state = on each completed chart bar, set bullish when Relative Vigor Index, AO, Acceleration/Deceleration, MACD main, and OSMA are all greater than their respective prior-bar values; set bearish when all five are less than their respective prior-bar values; otherwise retain prior state.
Calculation: Convergence state = on each completed chart bar, count bullish and bearish states among the ATR trailing-stop, Best Slope, FXR, Key Master, Key Trading, Institutional MACD, Ultimate MACD, Full-consensus MITP, Threshold MITP, and Pin-Point states. Clamp the separately parameterized convergence threshold to at least one and at most the number of these states. Set bullish when the bullish count meets the threshold and the bearish count does not; set bearish when the bearish count meets the threshold and the bullish count does not; otherwise retain prior state. The forming chart bar carries the latest completed-bar state.
Calculation: DotCount = count the bullish states among the ten states used by Convergence on each completed chart bar.
