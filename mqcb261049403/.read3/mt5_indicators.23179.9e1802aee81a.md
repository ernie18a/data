Calculation: ask price = close + current spread in points * point size, on each chart bar
Calculation: center = open of the still-forming T1 bar in open mode, or Pivot Point of the last completed T1 bar in pivot mode, using T1 values on chart bars
Calculation: average range = mean of SMA(high - low, shortest lookback, T1, last completed bars), SMA(high - low, second-shortest lookback, T1, last completed bars), SMA(high - low, second-longest lookback, T1, last completed bars), and SMA(high - low, longest lookback, T1, last completed bars), calculated on chart bars; lookbacks are in ascending duration
Calculation: long area level = center + long-area offset * point size
Calculation: first long target level = center + first long-target offset * point size
Calculation: second long target level = center + second long-target offset * point size
Calculation: short area level = center - short-area offset * point size
Calculation: first short target level = center - first short-target offset * point size
Calculation: second short target level = center - second short-target offset * point size
Long: (ask price > long area level - alert tolerance * point size AND ask price < long area level + alert tolerance * point size) OR (ask price > long area level - label tolerance * point size AND ask price < long area level + label tolerance * point size) OR (ask price > first long target level - alert tolerance * point size AND ask price < first long target level + alert tolerance * point size) OR (ask price > first long target level - label tolerance * point size AND ask price < first long target level + label tolerance * point size) OR (ask price > second long target level - alert tolerance * point size AND ask price < second long target level + alert tolerance * point size) OR (ask price > second long target level - label tolerance * point size AND ask price < second long target level + label tolerance * point size)
Short: (close > short area level - alert tolerance * point size AND close < short area level + alert tolerance * point size) OR (close > short area level - label tolerance * point size AND close < short area level + label tolerance * point size) OR (close > first short target level - alert tolerance * point size AND close < first short target level + alert tolerance * point size) OR (close > first short target level - label tolerance * point size AND close < first short target level + label tolerance * point size) OR (close > second short target level - alert tolerance * point size AND close < second short target level + alert tolerance * point size) OR (close > second short target level - label tolerance * point size AND close < second short target level + label tolerance * point size)
Long: (close >= long area level AND close < first long target level) OR (close >= first long target level AND close < second long target level) OR (close >= second long target level AND close < center + average range)
Short: (close <= short area level AND close > first short target level) OR (close <= first short target level AND close > second short target level) OR (close <= second short target level AND close > center - average range)
