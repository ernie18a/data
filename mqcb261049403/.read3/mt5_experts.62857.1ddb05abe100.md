Calculation: implied cross ask/bid = normalized executable cross-rate ask/bid derived from the component-pair quotes, using reciprocal bid/ask sides when a component pair is quoted inversely
Calculation: arbitrage cost threshold = target point size + sum of component and target spread points + sum of each leg's commission multiplied by its point size
Long: implied cross ask - target ask > arbitrage cost threshold + the selected setup's minimum-arbitrage threshold
Short: implied cross bid - target bid < -(arbitrage cost threshold + the selected setup's minimum-arbitrage threshold)
