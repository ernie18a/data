Calculation: smoothed volume = JJMA(volume, smoothing lookback, smoothing phase)
Calculation: volume-weighted normalized price = JJMA((scale parameter * (applied price - selected moving average(applied price, price-smoother method, price-smoother lookback, price-smoother phase) + smoothed range) / (range-divisor parameter * (smoothed range if nonzero, otherwise zero-range fallback parameter)) - offset parameter) * volume, smoothing lookback, smoothing phase)
