Calculation: EMA slope = (EMA(open, EMA lookback, T1, bar still forming) - EMA(open, EMA lookback, T1, last completed bar)) / point size, evaluated on chart bars using T1 values
Calculation: long entry reference price = chart-bar open[0] at entry - entry-price adjustment × point size - bid-ask spread at entry
Calculation: short entry reference price = chart-bar open[0] at entry + entry-price adjustment × point size + bid-ask spread at entry
Long: position side is not long AND EMA slope >= minimum slope AND EMA slope <= maximum slope AND current datetime's minute component > entry-minute threshold AND close[0] <= open[0] AND close[0] <= low[0] + entry-slip × point size AND abs(open[n] - open[n-1]) / point size < big-jump threshold for every n in {1,2,3,4,5} AND abs(open[n] - open[n-2]) / point size < double-jump threshold for every n in {2,3,4,5}
Short: position side is not short AND EMA slope <= -minimum slope AND EMA slope >= -maximum slope AND current datetime's minute component > entry-minute threshold AND close[0] >= open[0] AND close[0] >= high[0] - entry-slip × point size AND abs(open[n] - open[n-1]) / point size < big-jump threshold for every n in {1,2,3,4,5} AND abs(open[n] - open[n-2]) / point size < double-jump threshold for every n in {2,3,4,5}
Exit: long, volume[1] <= minimum volume OR (close[0] <= long entry reference price - stop-loss × point size AND current datetime's minute component > exit-minute threshold AND close[0] >= open[0] AND close[0] >= high[0] - exit-slip × point size)
Exit: short, volume[1] <= minimum volume OR (close[0] >= short entry reference price + stop-loss × point size AND current datetime's minute component > exit-minute threshold AND close[0] <= open[0] AND close[0] <= low[0] + exit-slip × point size)
