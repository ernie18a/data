Calculation: Prior long-signal low = low of the latest emitted long signal on each signal stream, initially zero; update only when the flat-distance condition passes
Calculation: Prior short-signal high = high of the latest emitted short signal on each signal stream, initially zero; update only when the flat-distance condition passes
Calculation: Pending long price = low at the latest up-cross that passes the RSI condition while confirmation is enabled; clear on a down-cross that passes its RSI condition or on the first bar from that up-cross onward where high − pending long price >= confirmation distance and close <= high
Calculation: Pending short price = high at the latest down-cross that passes the RSI condition while confirmation is enabled; clear on an up-cross that passes its RSI condition or on the first bar from that down-cross onward where pending short price − low >= confirmation distance and open >= close
Long: Confirmation disabled AND MA(close, shorter lookback, method, shift) crosses above MA(close, longer lookback, method, shift) AND (RSI filter disabled OR RSI(close, RSI lookback) > RSI threshold) AND abs(low − prior long-signal low) >= flat distance; evaluated on chart bars or on T1 bars using the bar still forming, with T1 signal values carried onto chart bars
Long: Confirmation enabled AND pending long price exists AND high − pending long price >= confirmation distance AND close <= high AND abs(low − prior long-signal low) >= flat distance; evaluated on chart bars or on T1 bars using the bar still forming, with T1 signal values carried onto chart bars
Short: Confirmation disabled AND MA(close, shorter lookback, method, shift) crosses below MA(close, longer lookback, method, shift) AND (RSI filter disabled OR RSI(close, RSI lookback) < RSI threshold) AND abs(high − prior short-signal high) >= flat distance; evaluated on chart bars or on T1 bars using the bar still forming, with T1 signal values carried onto chart bars
Short: Confirmation enabled AND pending short price exists AND pending short price − low >= confirmation distance AND open >= close AND abs(high − prior short-signal high) >= flat distance; evaluated on chart bars or on T1 bars using the bar still forming, with T1 signal values carried onto chart bars
