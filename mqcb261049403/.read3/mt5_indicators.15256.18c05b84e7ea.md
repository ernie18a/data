Calculation: NRTR trend = Seed trend at zero and extreme and stop at close on the oldest calculated bar, then process that bar and each later bar chronologically; let distance = SMA(abs(high − low), lookback) / 10^(reference-instrument price precision − traded-instrument price precision − digit adjustment). If prior trend >= 0, set extreme = max(prior extreme, high) and stop = max(prior stop, extreme × (1 − distance)); if high < stop, set trend = −1, extreme = high, and stop = extreme × (1 + distance), otherwise retain prior trend. If prior trend < 0, set extreme = min(prior extreme, low) and stop = min(prior stop, extreme × (1 + distance)); if low > stop, set trend = +1, extreme = low, and stop = extreme × (1 − distance), otherwise retain prior trend.
Long: On chart bars, the NRTR trend from the still-forming T1 bar is positive.
Short: On chart bars, the NRTR trend from the still-forming T1 bar is negative.
