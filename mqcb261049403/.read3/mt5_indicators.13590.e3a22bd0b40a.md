Calculation: MA angle = positive scale factor * (MA(close, lookback, MA method)[end shift] - MA(close, lookback, MA method)[start shift]) / (start shift - end shift)
Long: MA angle > 0
Short: MA angle < 0
Long: MA angle(T1, still-forming bar) > 0 on chart bars receiving values from T1
Short: MA angle(T1, still-forming bar) < 0 on chart bars receiving values from T1
