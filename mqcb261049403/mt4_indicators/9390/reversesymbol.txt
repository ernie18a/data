This indicator is the simplified version of
Monitoring-Spread
tool.
It allows to use the reversed symbols (
1 / X
) in a realtime.
Image:
ReverseSymbol example
How to use:
Attach indicator to the chart, set "
allow DLL use
".
Open chart of "reversed" symbol in
Offline
mode (File->Open Offline).
