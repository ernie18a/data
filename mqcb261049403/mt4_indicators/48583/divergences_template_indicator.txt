Finding
pivot highs
and
pivot lows
in
indicatorBuffer
depends on
pivots_period
input. The bigger you choose this value it will search larger swings for possible divergences.
Another input is alert_confirm_candles which defines how many bars to wait for confirming a signal. Divergence indicators are mostly lagging and issue a lot of false signals. The bigger you choose this value it will wait more and the number of false signals reduce. It is a compromise whether you want on-time signals or you want confirmed ones.
Normally you are not allowed to apply
pivots_period
< 2.
Repaint issue
Indicators that rely on pivot calculations has to wait as long as
pivots_period
to get a confirmation of the recent high/low. So this indicator needs to repaint signals as far as
pivots_period
back in time.
