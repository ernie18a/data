At each trading-day rollover, record a daily equity reference: use the greater of balance and equity, or balance alone, according to configuration. On each tick, compare account equity with both a buffered daily loss floor derived from that reference and a buffered maximum-loss floor derived from the initial account size. If equity reaches or falls below the maximum-loss floor, permanently halt trading. If it reaches or falls below the daily floor, halt trading until the next rollover. On either breach, set the account-wide halt signal and, when configured, close all open positions and delete all pending orders. Persist breach state and the daily reference so restarts do not clear a halt or reset the reference; a new trading day clears only the daily breach, while an explicit reset clears stored state.
