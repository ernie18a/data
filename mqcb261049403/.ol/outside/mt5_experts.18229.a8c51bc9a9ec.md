At the start of each day, during the brief early-day entry window, if trading is enabled and no managed positions are open, compare the first instrument’s previous daily close with its daily close one day earlier. If its return is positive, go long the first and second instruments, short the third, and go long the fourth; if negative, reverse all four directions. Hold positions until the late-day cutoff, then close them. If aggregate profit or loss reaches an enabled configured exit threshold, close all managed positions. If aggregate loss reaches the emergency threshold, the code attempts once per day to duplicate profitable positions in the same direction; however, its symbol filter prevents those orders from being placed when the instruments are distinct.
