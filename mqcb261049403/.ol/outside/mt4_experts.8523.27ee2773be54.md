When no strategy positions are open, at the daily entry window and when trading is allowed, use the previous completed daily return of EURUSD to choose a four-instrument basket: if positive, go long EURUSD and USDCHF, short GBPUSD, and go long AUDUSD; if negative, reverse all four directions. Close the basket at the daily exit time. If aggregate basket profit monitoring is enabled, close all basket positions when profit reaches its configured target or loss reaches its configured limit. If aggregate loss reaches the emergency threshold while emergency trading is enabled, open a same-direction clone of each currently profitable non-emergency position; allow this emergency action once per day.
