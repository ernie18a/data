Use the traded instrument’s OHLC bars on a configurable timeframe. For each bar, select the low if close is below open, the high if close is above open, or the close if they are equal. Calculate half the sum of that selected value and the close; if the result is zero, use the close. Smooth this series with a configurable moving-average method and period. Classify each bar as rising, falling, or flat by comparing its smoothed value with the previous bar.

Evaluate signals on the configured bar offset at each new timeframe bar, or on every tick if the offset selects the current bar. Open long when the selected bar is rising and the preceding bar was falling or flat; open short when it is falling and the preceding bar was rising or flat. A rising bar also signals closing a short, and a falling bar signals closing a long, even without a change in direction. Apply separate enable switches for each entry and exit. Close before opening, and open only if no position exists on the instrument. Attach configurable stop-loss and take-profit distances. Limit repeat entries in the same direction until the start of the next timeframe bar after the prior entry signal.

Optionally restrict entries by server time and close all positions on the instrument whenever outside the permitted period. For a start hour earlier than the end hour, permit the start hour from the start minute onward, all intervening hours, and the end hour before the end minute. For equal hours, permit minutes from the start minute inclusive to the end minute exclusive. For a start hour later than the end hour, permit hours at or after the start hour only when the current minute is at least the start minute, all hours before the end hour, and the end hour before the end minute. Signal-based exits remain active regardless of the time restriction.
