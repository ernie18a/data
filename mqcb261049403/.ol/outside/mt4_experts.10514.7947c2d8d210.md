On each tick, generate a bullish signal when the current parabolic-SAR point is below the current close and the previous point was above the previous close; generate a bearish signal for the opposite transition. In normal mode, a bullish signal closes the first selected sell order when signal-based closing is enabled, then may open a buy; a bearish signal closes the first selected buy order, then may open a sell. Reverse mode swaps these close and entry directions. Permit entry only when no order with this strategy’s identifier has been found and the configured delay and minimum-movement gates pass, using the corresponding current-bar bid/low measure for buys or high/ask measure for sells. Attach configured stop-loss and take-profit levels to new orders. When trailing is enabled, tighten stop-losses on orders for the current instrument as price moves favorably; the resulting stop can exit the position.
