For each open position the user chooses to hedge, find two available currency pairs that together synthetically represent the opposite exposure, using an intermediary currency absent from the target pair. Size each leg in proportion to the target position’s tick-value exposure divided by that leg’s tick value. Among eligible pair combinations, choose the one with the lowest estimated transaction cost, calculated as the sum of each leg’s size multiplied by its tick value and spread. Set each leg’s buy or sell direction according to the base/quote orientation needed to offset the selected position, then submit both legs.
