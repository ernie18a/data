For an existing position, a trailing stop can use a moving average of the chart instrument even when the position is in a different instrument. Read the latest moving-average value and round it to the position instrument’s tick size. For a long position, set it as the stop only if it is below the current position price; for a short, only if it is above. If a stop already exists, change it only when the new level tightens it by at least the configured step. Keep the existing stop if the moving average is unavailable or the conditions fail. The position exits when its stop is triggered.
