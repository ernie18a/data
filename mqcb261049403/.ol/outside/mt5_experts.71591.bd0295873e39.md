Act only on valid commands from the external spreadsheet that match the current account. For a close command, exit every open position if the target is “all,” or only positions in the specified instrument. For a break-even command, move each targeted position’s stop loss to its entry price adjusted by the supplied offset: above entry for longs and below entry for shorts; apply the change only if there is no stop loss or the new stop improves the existing one. Ignore invalid or unrecognized commands. No entry or options decisions are made.
