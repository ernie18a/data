For each currency, calculate average strength across configured currency pairs. For each pair, measure the current price’s position within the recent high–low range, optionally smoothing across periods; convert that position into an ordinal strength score. Add the score to the pair’s base currency and its inverse to the quote currency, then average each currency’s contributions. For every traded pair, go long when its base currency is strong and its quote currency is weak; go short when the base is weak and the quote is strong. Only open a new position when the trading-time window and market session are open, the pair has not already been traded that day, no position is already open for that pair, and the portfolio’s simultaneous-position limit permits it. Manage open positions with a trailing stop. Optionally add to a position when price moves against it by a volatility- or distance-based step, increasing position size geometrically and setting a shared take-profit around the volume-weighted average entry. Close all managed positions when the daily profit target is reached.
