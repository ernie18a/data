On each new signal bar, calculate an oscillator from the selected price series: smooth consecutive price changes and their absolute values separately, divide the signed-change result by the absolute-change result, scale by 100, then smooth the ratio. Compare three consecutive oscillator values, oldest to newest. If it fell and then rose, open a long if enabled and close any short if that exit is enabled. If it rose and then fell, open a short if enabled and close any long if that exit is enabled. Equal values produce no reversal signal. Independently, close any position on the traded instrument once its holding time exceeds the configured limit, if timed exits are enabled.
