Once sufficient indicator history is available, if the optional trading-time restriction is enabled, close all positions in the traded instrument whenever server time is outside the permitted interval. Determine the interval as follows: when the start hour is earlier than the end hour, permit the start hour from the start minute onward, all intervening hours, and the end hour before the end minute; when the hours are equal, permit that hour from the start minute up to but excluding the end minute; when the start hour is later, permit hours at or after the start hour only when the current minute is at least the start minute, all hours before the end hour, and the end hour before the end minute. Do not open positions outside the permitted interval.
