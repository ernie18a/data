Act only when the user creates a horizontal line with a recognized buy, sell, buy-pending, or sell-pending command. A buy command opens a market long; a sell command opens a market short. A buy-pending command places a buy stop when its line is above the current ask, otherwise a buy limit. A sell-pending command places a sell stop when its line is below the current ask, otherwise a sell limit. Set the stop loss and take profit at the configured pip distances from the entry price, below and above entry respectively for longs and above and below entry for shorts. For market orders, use the current market price; for pending orders, use the line price. For an open position with a positive trailing distance, once favorable movement from entry exceeds that distance, move the stop to that distance behind the current close price, only if this tightens the existing stop. User movement of an order's stop-loss or take-profit line changes that level; movement of a pending order's price line changes its entry price. Exit through the resulting stop loss or take profit.
