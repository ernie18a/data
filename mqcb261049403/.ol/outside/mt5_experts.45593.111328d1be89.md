For an existing position, use the current moving average of the chart instrument as a candidate stop loss, even if the position is on another instrument. Normalize the candidate to the position instrument's tick size. For a long, accept it only below the current position price; for a short, only above it. Set it if no stop exists; otherwise move the stop only in the position's favorable direction by at least the configured minimum step. Keep the existing take profit. If the moving average is unavailable or zero, leave the stop unchanged. The position exits when its stop is reached.
