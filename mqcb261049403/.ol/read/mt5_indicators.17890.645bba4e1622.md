Calculation: Selected price = close, open, high, low, (high+low)/2, (close+high+low)/3, (2×close+high+low)/4, (open+close)/2, (open+close+high+low)/4, or the trend-following price: high if close>open, low if close<open, otherwise close; or the second trend-following price: (high+close)/2 if close>open, (low+close)/2 if close<open, otherwise close; or Demark price = ((r−low)+(r−high))/2, where r=(high+low+close+low)/2 if close<open, (high+low+close+high)/2 if close>open, and (high+low+close+close)/2 if close=open.
Calculation: XOSignal direction = initialize upper and lower thresholds to the preceding bar's selected price and direction to neutral; thereafter, if selected price > upper threshold + range distance, set upper threshold to selected price, lower threshold to upper threshold − range distance, and direction to long; if selected price < lower threshold − range distance, set lower threshold to selected price, upper threshold to lower threshold + range distance, and direction to short; otherwise retain thresholds and direction. Range distance = range parameter × minimum price increment.
Long: XOSignal direction changes from short to long on a higher-timeframe bar that is still forming.
Short: XOSignal direction changes from long to short on a higher-timeframe bar that is still forming.
