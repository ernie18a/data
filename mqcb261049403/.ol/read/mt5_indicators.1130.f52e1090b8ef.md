Calculation: XOSMA = Smooth the difference between a short-lookback smoothing and a longer-lookback smoothing of price, subtract a smoothed value of that difference, then smooth the result again.
Long: XOSMA > 0
Short: XOSMA < 0
Long: Higher-timeframe XOSMA on the still-forming bar > 0
Short: Higher-timeframe XOSMA on the still-forming bar < 0
