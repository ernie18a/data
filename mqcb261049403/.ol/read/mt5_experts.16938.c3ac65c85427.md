Calculation: Fractal RSI = On the configured indicator timeframe, use the applied price. For each bar, find its highest and lowest value over the lookback; normalize each value in that window to (price − lowest)/(highest − lowest). Sum the path lengths between consecutive normalized values, where each step length is sqrt(change² + 1/lookback²). Set fractal dimension to 1 + (ln(path length) + ln 2)/ln(2 × (lookback − 1)); if the range or path length is zero, use fractal dimension 0. Set Hurst exponent to 2 − fractal dimension, then set the RSI lookback to round(normal speed/(2 × Hurst exponent)). RSI is 100 − 100/(1 + average gain/average loss) over that lookback; use 100 if average loss is zero but gain is positive, otherwise 50 if both are zero. Use completed indicator-timeframe bars.
Long: Fractal RSI on the previous completed bar <= oversold level AND Fractal RSI on the signal completed bar > oversold level
Short: Fractal RSI on the previous completed bar >= overbought level AND Fractal RSI on the signal completed bar < overbought level
Exit: long, Fractal RSI on the previous completed bar >= overbought level AND Fractal RSI on the signal completed bar < overbought level OR low <= entry price − configured stop-loss distance OR high >= entry price + configured take-profit distance
Exit: short, Fractal RSI on the previous completed bar <= oversold level AND Fractal RSI on the signal completed bar > oversold level OR high >= entry price + configured stop-loss distance OR low <= entry price − configured take-profit distance
