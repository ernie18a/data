Calculation: Smoothed RSI = RSI of close smoothed by the selected moving-average method over a shorter lookback.
Calculation: QQE trailing line = initialize the line and prior Smoothed RSI to 50; let distance be the absolute change in Smoothed RSI smoothed twice by the selected moving-average method, using the same longer lookback for both passes, then multiplied by a factor. If current Smoothed RSI is below the prior line, set the line to current Smoothed RSI + distance, clamped to the prior line if prior Smoothed RSI was below the prior line and this candidate exceeds it. If current Smoothed RSI is above the prior line, set the line to current Smoothed RSI − distance, clamped to the prior line if prior Smoothed RSI was above the prior line and this candidate is below it. Otherwise carry forward the prior line. The longer lookback is 2 × the RSI lookback − 1.
Long: On higher-timeframe bars, using the bar still forming, prior Smoothed RSI ≤ prior QQE trailing line AND current Smoothed RSI > current QQE trailing line
Short: On higher-timeframe bars, using the bar still forming, prior Smoothed RSI ≥ prior QQE trailing line AND current Smoothed RSI < current QQE trailing line
