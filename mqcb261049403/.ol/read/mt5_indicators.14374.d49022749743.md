Calculation: LeManTrend histogram = apply an EMA to each of (current high minus the highest high over each of three lookbacks) and (the lowest low over each of the same lookbacks minus current low); subtract the second EMA from the first, then smooth the difference with the selected smoothing method. The three lookbacks are shortest, intermediate, and longest. For the higher-timeframe version, use the selected timeframe’s bar matching the chart bar’s time, including that bar while it is still forming.
Long: On the signal bar, histogram < 0 AND histogram > previous histogram AND current histogram < 0 AND current histogram < previous histogram
Short: On the signal bar, histogram < 0 AND histogram < previous histogram AND current histogram < 0 AND current histogram > previous histogram
