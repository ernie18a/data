Calculation: MACD histogram = MACD main line − MACD signal line; MACD direction uses current versus previous values of both the histogram and main line.
Calculation: Moving-average trend = bullish if any of these hold: (1) short EMA rising, medium SMA rising, the short SMA of the medium SMA crosses above the longer SMA of the medium SMA, and the gap between those two SMAs is nondecreasing; (2) short EMA and medium SMA rising, the short SMA of the medium SMA is above the longer one and rising, and their gap is nondecreasing; (3) short EMA and medium SMA rising, the medium SMA’s gap above the short SMA of the medium SMA is increasing, the longer SMA of the medium SMA is rising, and the medium SMA is above the short SMA of the medium SMA. It is bearish if the corresponding conditions hold with directions reversed. The longer SMA has a longer lookback than the short SMA. Use current forming bars and prior completed bars for slope and crossover comparisons.
Calculation: Direction state = start with the prior state (initially neutral); set bullish if both higher-timeframe ZigZag directions are bullish, or if MACD histogram and main line both rise; set bearish if both ZigZag directions are bearish, or if both MACD values fall. Then, in order, set bearish if the state is bullish and the higher-timeframe ZigZag indicates a delayed bearish turn, or both MACD values fall; set bullish if the state is bearish and the higher-timeframe ZigZag indicates a delayed bullish turn, or both MACD values rise. Then set bullish if MACD main is nondecreasing, above its signal, and the signal is rising; set bearish if main is nonincreasing, below its signal, and the signal is falling. Finally, override with bullish or bearish when the moving-average trend is bullish or bearish. ZigZag and MACD use current forming and prior completed bars on higher timeframes; moving averages use current forming and prior completed bars on a lower timeframe.
Calculation: Adjusted close = (higher-timeframe high + low + 2 × close) / 4 − medium SMA; compare its current value with its prior value. Use current forming and prior completed bars; the higher-timeframe close and lower-timeframe SMA are from their respective bars.
Long: Direction state is bullish AND adjusted close is rising
Short: Direction state is bearish AND adjusted close is falling
