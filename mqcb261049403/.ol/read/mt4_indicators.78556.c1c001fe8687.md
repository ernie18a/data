Calculation: ATR trailing state = On each completed chart bar, update an ATR-based trailing level; set bullish when the current and previous closes are above the level, bearish when both are below, and otherwise retain the previous state.
Calculation: Best Slope state = Set bullish when Stochastic, CCI, DeMarker, MFI, MACD histogram, Accelerator Oscillator, Awesome Oscillator, and Accumulation/Distribution are all higher than on the previous completed chart bar; set bearish when all are lower; otherwise retain the previous state.
Calculation: FXR state = Apply a smoothed Fisher transform to the current bar midpoint’s position within the highest high and lowest low over a lookback, and set bullish when the result is above zero or bearish when below zero; otherwise retain the previous state.
Calculation: Key Master state = Set bullish when RSI is above its lower threshold, Heiken Ashi is bullish, Stochastic is above its lower threshold, CCI is above its lower threshold, and Williams %R is above its lower threshold; set bearish when RSI is below its upper threshold, Heiken Ashi is bearish, Stochastic is below its upper threshold, CCI is below its upper threshold, and Williams %R is above its lower bound; otherwise retain the previous state.
Calculation: Key Trading System state = Set bullish when RSI is above its midpoint, Parabolic SAR is below close, Heiken Ashi is bullish, Stochastic is above its midpoint, CCI is positive, Williams %R is above its midpoint, and Bulls Power is positive; set bearish when RSI is below its midpoint, Parabolic SAR is above close, Heiken Ashi is bearish, Stochastic is below its midpoint, CCI is negative, Williams %R is below its midpoint, and Bears Power is negative; otherwise retain the previous state.
Calculation: Institutional MACD state = Calculate MACD and signal line, then the difference between the current and previous values of MACD plus its distance from the signal line. Set bullish when this difference exceeds an ATR-scaled threshold, or bearish when it is at or below the negative threshold; otherwise retain the previous state. The threshold is larger below an ADX threshold.
Calculation: Ultimate MACD state = Calculate the difference between the current and previous values of MACD plus its distance from the signal line. Set bullish when this difference exceeds a multiple of the standard deviation of recent MACD histogram values, or bearish when it is below the negative threshold; otherwise retain the previous state.
Calculation: MITP all-indicator state = For each of 32 indicators, derive a bullish, bearish, or neutral vote from its value’s direction on the current versus previous completed chart bar; for BBP, CMO, and the technical composite use the sign of the value, and for Chop Zone use positive or negative threshold crossings. Maintain a confirmed state per indicator: an opposite vote cancels its pending trigger; a bullish vote arms the current high and confirms bullish when a later close exceeds that high while the vote remains bullish; a bearish vote arms the current low and confirms bearish when a later close falls below that low while the vote remains bearish. The MITP state becomes bullish when all 32 confirmed states are bullish and a close breaks above the armed high; bearish when all 32 are bearish and a close breaks below the armed low; otherwise retain the previous state.
Calculation: MITP threshold state = Count the 32 confirmed bullish and bearish indicator states. Set bullish when the bullish count reaches its configured threshold and bearish when the bearish count reaches its configured threshold; if both apply, change state only when exactly one threshold condition has newly become true; otherwise retain the previous state.
Calculation: Pin-Point state = Set bullish when RVI, Awesome Oscillator, Accelerator Oscillator, MACD, and MACD histogram are all higher than on the previous completed chart bar; set bearish when all are lower; otherwise retain the previous state.
Calculation: Bullish convergence count = Number of bullish states among ATR trailing, Best Slope, FXR, Key Master, Key Trading System, Institutional MACD, Ultimate MACD, MITP all-indicator, MITP threshold, and Pin-Point.
Calculation: Bearish convergence count = Number of bearish states among ATR trailing, Best Slope, FXR, Key Master, Key Trading System, Institutional MACD, Ultimate MACD, MITP all-indicator, MITP threshold, and Pin-Point.
