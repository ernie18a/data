Calculation: Linear regression slope = ordinary least-squares slope of close values ordered oldest to newest, including the current forming bar
Calculation: R-squared = coefficient of determination for the same linear regression and lookback as the slope
Calculation: ADX = standard ADX value on the current bar, including the current forming bar
Long: linear regression slope > 0 AND R-squared >= minimum AND ADX >= minimum
Short: linear regression slope <= 0 AND R-squared >= minimum AND ADX >= minimum
