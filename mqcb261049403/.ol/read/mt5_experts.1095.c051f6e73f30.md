Calculation: BinaryWave = selected smoothing of the weighted sum of seven votes, calculated on the configured indicator timeframe (which may be higher or lower than the chart timeframe): +weight if close is above its moving average, −weight if below; +weight if MACD is rising, −weight if falling; +weight if OsMA > 0, −weight if OsMA < 0; +weight if CCI > 0, −weight if CCI < 0; +weight if Momentum > 100, −weight if Momentum < 100; +weight if RSI > 50, −weight if RSI < 50; +weight if +DI > −DI, −weight if +DI < −DI. Each vote is 0 on equality or when its weight is zero. Use completed indicator-timeframe bars; the current signal bar and all compared prior bars must be completed.
Long: BinaryWave on the current completed bar > 0 AND BinaryWave on the preceding completed bar <= 0 OR BinaryWave on the current completed bar > BinaryWave on the preceding completed bar AND BinaryWave on the bar before that > BinaryWave on the preceding completed bar
Short: BinaryWave on the current completed bar < 0 AND BinaryWave on the preceding completed bar >= 0 OR BinaryWave on the current completed bar < BinaryWave on the preceding completed bar AND BinaryWave on the bar before that < BinaryWave on the preceding completed bar
Exit: long, BinaryWave on the current completed bar < 0 OR BinaryWave on the current completed bar < BinaryWave on the preceding completed bar OR low <= entry price − stop-loss distance OR high >= entry price + take-profit distance
Exit: short, BinaryWave on the current completed bar > 0 OR BinaryWave on the current completed bar > BinaryWave on the preceding completed bar OR high >= entry price + stop-loss distance OR low <= entry price − take-profit distance
