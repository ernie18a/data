Calculation: Trend momentum = (MACD on the current source bar − MACD on the previous source bar) × sensitivity; the source timeframe is the chart timeframe or a configured timeframe no lower than it. The current source bar is still forming; previous source bars are completed.
Calculation: Explosion width = upper Bollinger Band − lower Bollinger Band on the source bar; compare the current width with the width on the previous completed source bar.
Calculation: Dead-zone threshold = pip size × dead-zone parameter.
Calculation: Trend power = 100 × (current trend momentum magnitude − previous trend momentum magnitude) / current trend momentum magnitude; for long entries, use signed trend momentum instead of magnitude.
Calculation: Explosion power = 100 × (current explosion width − previous explosion width) / current explosion width.
Long: Trend momentum > 0 AND Trend momentum > Explosion width AND Trend momentum > Dead-zone threshold AND Explosion width > Dead-zone threshold AND Explosion width > previous explosion width AND Trend momentum > previous trend momentum AND Explosion power ≥ explosion-power threshold AND Trend power ≥ trend-power threshold
Short: Trend momentum < 0 AND |Trend momentum| > Explosion width AND |Trend momentum| > Dead-zone threshold AND Explosion width > Dead-zone threshold AND Explosion width > previous explosion width AND |Trend momentum| > |previous trend momentum| AND Explosion power ≥ explosion-power threshold AND Trend power ≥ trend-power threshold
Exit: long, Trend momentum > 0 AND Trend momentum < Explosion width AND Trend momentum < previous trend momentum AND previous trend momentum > explosion width on the previous completed source bar AND Trend momentum > Dead-zone threshold AND Explosion width > Dead-zone threshold
Exit: short, Trend momentum < 0 AND |Trend momentum| < Explosion width AND |Trend momentum| < |previous trend momentum| AND |previous trend momentum| > explosion width on the previous completed source bar AND Trend momentum > Dead-zone threshold AND Explosion width > Dead-zone threshold
