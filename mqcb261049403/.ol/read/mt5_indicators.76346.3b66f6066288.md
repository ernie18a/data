Calculation: Confirmed pivot high/low = a bar whose high/low is strictly above/below the corresponding highs/lows of the configured number of bars on each side; use completed bars only.
Calculation: Cleaned pivots = confirmed pivots in time order, collapsing consecutive pivots of the same type to the highest high or lowest low.
Calculation: Pattern points = the latest five cleaned pivots, numbered 1–5; pattern width = bars from point 1 to point 5.
Calculation: Line slope(A,B) = (price at B − price at A) / (bar index B − bar index A); line value(A,B,x) = price at A + Line slope(A,B) × (x − bar index A).
Calculation: Pattern height = highest price among points 1–5 − lowest price among points 1–5.
Calculation: Convergence point = intersection bar index of lines 1–3 and 2–4; convergence measure = absolute difference of their slopes × pattern width / pattern height; point-5 line distance = absolute difference between point 5 price and line 1–3 at point 5 / pattern height.
Long: points 1–5 are low, high, low, high, low AND point 3 price < point 1 price AND point 4 price < point 2 price AND pattern width is within configured minimum and maximum AND lines 1–3 and 2–4 have different slopes AND convergence point > point 5 bar index AND convergence measure ≥ configured minimum AND point-5 line distance ≤ configured tolerance AND, if target hiding is enabled, no completed bar from point 5 through the latest bar has high ≥ line 1–4 at that bar.
Short: points 1–5 are high, low, high, low, high AND point 3 price > point 1 price AND point 4 price > point 2 price AND pattern width is within configured minimum and maximum AND lines 1–3 and 2–4 have different slopes AND convergence point > point 5 bar index AND convergence measure ≥ configured minimum AND point-5 line distance ≤ configured tolerance AND, if target hiding is enabled, no completed bar from point 5 through the latest bar has low ≤ line 1–4 at that bar.
