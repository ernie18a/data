Calculation: Up score = Jurik-smoothed count of lookbacks where the Jurik-smoothed close rose from the preceding bar; lookbacks run from shortest to longest in equal increments. If calculated on a higher timeframe, use its bar still forming.
Calculation: Down score = Jurik-smoothed count of lookbacks where the Jurik-smoothed close did not rise from the preceding bar, using the same lookbacks as the up score. If calculated on a higher timeframe, use its bar still forming.
Long: Up score > Down score
Short: Up score <= Down score
