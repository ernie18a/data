Calculation: Applied price P = configured series: close, open, high, low, (high+low)/2, (close+high+low)/3, (2*close+high+low)/4, (open+close)/2, (open+close+high+low)/4, trend-follow 0 (high if close>open, low if close<open, otherwise close), trend-follow 1 ( (high+close)/2 if close>open, (low+close)/2 if close<open, otherwise close), or DeMark price: let R=high+low+close; replace R with (R+low)/2 if close<open, (R+high)/2 if close>open, or (R+close)/2 if close=open; then (2R-low-high)/2.
Calculation: Loco level Q = initialize Q to P on the oldest calculated bar. For each next bar, let Pprev be the configured applied price Length bars earlier and Qprev the prior Loco level. If P=Qprev, Q=Qprev. Otherwise, if Pprev>Qprev and P>Qprev, Q=max(Qprev,0.999P); else if Pprev<Qprev and P<Qprev, Q=min(Qprev,1.001P); otherwise Q=0.999P if P>Qprev, or 1.001P if P<Qprev. Calculated on chart-timeframe bars; the HTF version uses the same calculation on a higher timeframe, using the bar still forming.
Long: P > prior Loco level Q
Short: P < prior Loco level Q
