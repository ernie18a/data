Calculation: Signal line = moving average of MACD
Long: MACD > 0 AND MACD > previous MACD OR MACD > previous Signal line
Long: MACD < 0 AND MACD > previous MACD
Short: MACD < 0 AND MACD < previous MACD OR MACD < previous Signal line
Short: MACD > 0 AND MACD < previous MACD
