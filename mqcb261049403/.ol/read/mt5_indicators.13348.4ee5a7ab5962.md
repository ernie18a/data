Calculation: JMA-smoothed Laguerre RSI = 100 times a JMA-smoothed Laguerre RSI. From the selected bar price, recursively calculate L0=(1−γ)price+γ·previous L0; L1=−γL0+previous L0+γ·previous L1; L2=−γL1+previous L1+γ·previous L2; L3=−γL2+previous L2+γ·previous L3. CU is the sum of positive differences among L0,L1,L2,L3; CD is the sum of the absolute values of negative differences. Laguerre RSI=CU/(CU+CD), retaining its previous value if CU+CD=0. Apply JMA to this series.
Calculation: Direction state = bullish when the current JMA-smoothed Laguerre RSI is above the high threshold; bearish when below the low threshold. Between the middle and high thresholds, set bearish if the previous value was above the high threshold, retain the previous state if it was also between the middle and high thresholds, and set bullish if it was at or below the middle threshold. Between the low and middle thresholds, set bearish if the previous value was above the middle threshold, retain the previous state if it was also between the low and middle thresholds, and set bullish if it was below the low threshold.
Long: Direction state = bullish
Short: Direction state = bearish
