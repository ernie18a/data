Calculation: Grid level = the configured grid anchor plus or minus successive grid spacings; when no anchor is configured, use the grid-aligned price range centered on the current bid.
Calculation: Grid spacing = the configured distance between adjacent grid levels.
Calculation: Rank 1 target distance = base take-profit distance; rank 2 = base take-profit distance + one grid spacing; rank 3 = base take-profit distance + two grid spacings.
Calculation: EMA = exponential moving average of close.
Calculation: MACD main line = difference between the short-period and long-period exponential moving averages of close.
Calculation: SAR = parabolic stop-and-reverse value.
Calculation: SMA = simple moving average of close.
Calculation: Stochastic main and signal lines = stochastic oscillator lines.
Long: At a grid level, place a long order if longs are permitted, its level is above the EMA when the EMA filter is enabled, the long limit is not reached, and no same-side order within one grid spacing already has that target rank; place a buy stop when level > ask and breakout orders are enabled, or a buy limit when level <= ask and countertrend orders are enabled. If MACD filtering is enabled, require the current and previous MACD main values > 0 and the value two bars earlier > 0. If SAR filtering is enabled, require SAR < close. If the moving-average group filter is enabled, require SMA(5) > SMA(13) > SMA(21) > SMA(60) > SMA(200), SMA(5) - SMA(21) > the configured threshold, and, when stochastic filtering is enabled, stochastic main - signal > the configured threshold. Indicator bars use the current forming bar and prior bars on timeframes higher than the chart timeframe.
Short: At a grid level, place a short order if shorts are permitted, its level is below the EMA when the EMA filter is enabled, the short limit is not reached, and no same-side order within one grid spacing already has that target rank; place a sell stop when level < bid and breakout orders are enabled, or a sell limit when level >= bid and countertrend orders are enabled. If MACD filtering is enabled, require the current and previous MACD main values < 0 and the value two bars earlier < 0. If SAR filtering is enabled, require SAR > close. If the moving-average group filter is enabled, require SMA(5) < SMA(13) < SMA(21) < SMA(60) < SMA(200), SMA(21) - SMA(5) > the configured threshold, and, when stochastic filtering is enabled, stochastic signal - main > the configured threshold. Indicator bars use the current forming bar and prior bars on timeframes higher than the chart timeframe.
Exit: Long, price >= entry price + the selected rank's target distance or price <= its stop-loss level or the trailing-stop level; also exit on a MACD zero-cross in either direction when MACD filtering and close-open-positions are enabled, or when the moving-average group changes to its bearish condition and close-open-positions is enabled.
Exit: Short, price <= entry price - the selected rank's target distance or price >= its stop-loss level or the trailing-stop level; also exit on a MACD zero-cross in either direction when MACD filtering and close-open-positions are enabled, or when the moving-average group changes to its bullish condition and close-open-positions is enabled.
