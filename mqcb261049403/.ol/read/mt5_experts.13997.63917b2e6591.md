Calculation: Laguerre directional index = Apply the same Laguerre filter separately to ADX +DI and −DI, each computed with the same lookback: for input x, L0=(1−γ)x+γ·previous L0; L1=−γ·current L0+previous L0+γ·previous L1; L2=−γ·current L1+previous L1+γ·previous L2; L3=−γ·current L2+previous L2+γ·previous L3. Let CU be the sum of positive differences between adjacent stages L0−L1, L1−L2, and L2−L3; let CD be the sum of their absolute values when negative. The output is CU/(CU+CD), retaining its prior value when CU+CD=0. Initialize filter states at zero.
Long: current selected signal-timeframe bar’s +DI Laguerre directional index > its −DI Laguerre directional index AND the immediately preceding bar’s +DI Laguerre directional index < its −DI Laguerre directional index
Short: current selected signal-timeframe bar’s +DI Laguerre directional index < its −DI Laguerre directional index AND the immediately preceding bar’s +DI Laguerre directional index > its −DI Laguerre directional index
Exit: short, current selected signal-timeframe bar’s +DI Laguerre directional index > its −DI Laguerre directional index AND the immediately preceding bar’s +DI Laguerre directional index < its −DI Laguerre directional index
Exit: long, current selected signal-timeframe bar’s +DI Laguerre directional index < its −DI Laguerre directional index AND the immediately preceding bar’s +DI Laguerre directional index > its −DI Laguerre directional index
