Calculation: Laguerre ROC = For each bar, compute n-bar rate of change as (close − close n bars ago) / close n bars ago + minimum price increment. Smooth it through four Laguerre stages: L0 = (1 − γ) × ROC + γ × previous L0; L1 = −γ × current L0 + previous L0 + γ × previous L1; L2 = −γ × current L1 + previous L1 + γ × previous L2; L3 = −γ × current L2 + previous L2 + γ × previous L3. Let U be the sum of positive differences between consecutive stages (L0−L1, L1−L2, L2−L3), and D the sum of their absolute negative differences. Laguerre ROC = U / (U + D); retain the prior value when U + D = 0. Initialize each stage and its prior value to the first ROC.
Long: Chart-timeframe Laguerre ROC > 0.5 OR higher-timeframe Laguerre ROC > 0.5, using the higher timeframe’s still-forming bar
