Calculation: Trend state and thresholds = On the indicator timeframe (same as or higher than the chart), use the still-forming bar’s high, low, moving average, and ATR; carry state and thresholds from the preceding bar. Initialize state as neutral and both thresholds as the first bar’s close. Set the upper and lower thresholds to moving average + volatility factor × ATR and moving average − volatility factor × ATR. Starting from the prior state, set state to positive if high > prior upper threshold, then set it to negative if low < prior lower threshold (this second condition takes precedence if both hold). If state is positive, set the lower threshold to the greater of its calculated value and the prior lower threshold; if negative, set the upper threshold to the lesser of its calculated value and the prior upper threshold. Long: Prior trend state ≤ 0 AND current trend state > 0
Short: Prior trend state ≥ 0 AND current trend state < 0
