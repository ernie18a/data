Calculation: Ultra-linear filter = For input x and length N, set a=3/(N+2), b=1-a; initialize six filter states to the first x. On each bar update f1=b*f1+a*x, f2=a*f1+b*f2, v1=1.5*f1-0.5*f2, f3=b*f3+a*v1, f4=a*f3+b*f4, v2=1.5*f3-0.5*f4, f5=b*f5+a*v2, f6=a*f5+b*f6; output 1.5*f5-0.5*f6.
Calculation: Smoothed relative-strength oscillator = Apply the ultra-linear filter separately to the change in selected price and its absolute value, using the same length; divide the first result by the second, clamp to [-1,1], then apply a Jurik moving average with a separately selected smoothing length and phase. The result is unavailable when the denominator is zero.
Calculation: Cycle oscillator = Subtract the longer-length smoothed relative-strength oscillator from the shorter-length one, using the same price, smoothing length and phase. Normalize this difference over a rolling cycle lookback to 100*(value-min)/(max-min), retaining the previous first-stage value if the range is zero; smooth it recursively as previous first-stage value plus 0.5 times the change from that value. Normalize the smoothed first stage over the same lookback to 200*(value-min)/(max-min)-100, retaining the previous output if the range is zero; smooth this second stage recursively with the same factor. Use independent parameter sets for long and short decisions. Each set uses a selected chart timeframe or a higher or lower timeframe, and a selected signal bar: the last completed bar or the still-forming bar, or an earlier completed bar at a selected offset.
Long: Long-parameter cycle oscillator on the selected signal bar > 0 AND its value on the preceding oscillator bar <= 0.
Short: Short-parameter cycle oscillator on the selected signal bar < 0 AND its value on the preceding oscillator bar >= 0.
Exit: long, long-parameter cycle oscillator on the selected signal bar < 0 OR low <= entry price minus the selected stop-loss distance OR high >= entry price plus the selected take-profit distance.
Exit: short, short-parameter cycle oscillator on the selected signal bar > 0 OR high >= entry price plus the selected stop-loss distance OR low <= entry price minus the selected take-profit distance.
