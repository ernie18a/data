Calculation: MACD values = MACD main and signal lines on another timeframe (which may be higher, equal to, or lower than the chart timeframe): current bar is still forming; previous bar is completed.
Calculation: ZigZag positions = the most recent ZigZag high and low pivot positions among the last 100 bars on another timeframe (which may be higher, equal to, or lower than the chart timeframe), including the bar still forming.
Calculation: Moving-average conditions = On another timeframe (which may be higher, equal to, or lower than the chart timeframe), compare the current and previous values of the 2-period EMA and 20-period SMA, and compare the current and previous values of the 10-period and 62-period simple moving averages of that 20-period SMA; the 10-period average is shorter-term and the 62-period average is longer-term. Also compare the current and previous difference between the 20-period SMA and the 10-period average, and the current and previous difference between the 10-period and 62-period averages. The current bar is still forming; previous bars are completed. These comparisons define bullish conditions: (EMA rising AND SMA rising AND the 10-period minus 62-period difference nondecreasing AND the 10-period average crossed above the 62-period average between two bars ago and the current bar) OR (EMA rising AND SMA rising AND the 10-period minus 62-period difference nondecreasing AND the 10-period average above the 62-period average AND rising) OR (EMA rising AND SMA rising AND the 20-period minus 10-period difference rising AND the 62-period average rising AND the 20-period SMA above the 10-period average). Define bearish conditions by reversing the directions and inequalities, with the cross occurring below.
Calculation: Direction state = Start bullish if ((the low-pivot position is more recent than the high-pivot position AND the low-pivot position is greater than zero and less than four AND the M30 low-pivot position is more recent than its high-pivot position) OR (the current MACD main-minus-signal difference exceeds the previous difference AND the current MACD main line exceeds the previous main line)); start bearish if ((the high-pivot position is more recent than the low-pivot position AND the high-pivot position is greater than zero and less than four AND the M30 high-pivot position is more recent than its low-pivot position) OR (the current MACD main-minus-signal difference is below the previous difference AND the current MACD main line is below the previous main line)). Then, in order: if bullish and the low-pivot position is greater than four, or the current main line is below its previous value and the current main-minus-signal difference is below its previous value, set bearish and clear bullish; if bearish and the high-pivot position is greater than four, or the current main line is above its previous value and the current main-minus-signal difference is above its previous value, set bullish and clear bearish; if the current main line is at least its previous value AND above the current signal line AND the current signal line is above its previous value, set bullish and clear bearish; if the current main line is at most its previous value AND below the current signal line AND the current signal line is below its previous value, set bearish and clear bullish; finally, bullish moving-average conditions set bullish and clear bearish, and bearish moving-average conditions set bearish and clear bullish.
Long: bullish direction state
Short: bearish direction state
