Calculation: Fast trailing stochastic line = On each bar, let S be the 0–100 Stochastic oscillator and q the smaller step. Set candidate lower and upper bands to S−2q and S+2q. Set trend to rising if S exceeds the prior upper band, falling if S is below the prior lower band, otherwise retain prior trend. When rising, set lower band to max(candidate lower, prior lower) and fast line to lower band+q; when falling, set upper band to min(candidate upper, prior upper) and fast line to upper band−q. Initialize prior lower/upper bands to +∞/−∞, trend to neutral, and prior line to 0.
Calculation: Slow trailing stochastic line = Use the same recurrence as the fast trailing stochastic line with the larger step.
Long: Fast trailing stochastic line on the higher timeframe's still-forming bar crosses above the slow trailing stochastic line (previous fast ≤ previous slow and current fast > current slow)
Short: Fast trailing stochastic line on the higher timeframe's still-forming bar crosses below the slow trailing stochastic line (previous fast ≥ previous slow and current fast < current slow)
