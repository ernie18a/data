Calculation: Anchored momentum = 100 × (EMA(close, shorter lookback) / SMA(close, longer lookback) − 1) on chart-timeframe bars
Calculation: Higher-timeframe anchored momentum = the same calculation on higher-timeframe bars, using the still-forming higher-timeframe bar
Long: Anchored momentum > 0 OR higher-timeframe anchored momentum > 0
Short: Anchored momentum < 0 OR higher-timeframe anchored momentum < 0
