Calculation: Fisher Cyber Cycle = apply a 4-bar weighted midpoint-price smoother (weights 1,2,2,1) to the midpoint price (high + low)/2; filter it as a Cyber Cycle using coefficients (1 − 0.5 × Alpha)², 2 × (1 − Alpha), and −(1 − Alpha)² on the current second difference and the two prior cycle values; normalize the current cycle over the current and prior Length bars to [0,1] (use 0 when the range is zero); smooth the normalized value with weights 4,3,2,1 over the current and three prior bars, divide by 10, then apply 0.5 × ln((1 + 1.98 × (value − 0.5))/(1 − 1.98 × (value − 0.5)). On the higher timeframe, use the bar still forming. Its Trigger is the Fisher Cyber Cycle value one bar earlier.
Long: higher-timeframe Fisher Cyber Cycle > 0 OR higher-timeframe Fisher Cyber Cycle > Trigger
