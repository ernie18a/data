Calculation: QQE line = EMA of RSI of the selected applied price (an OHLC price or its median, typical, or weighted price); RSI = 50 × (1 + Wilder-smoothed price change / Wilder-smoothed absolute price change), using the RSI-period lookback, then EMA-smoothed using the RSI-smoothing period. Calculate on the chart timeframe or a selected higher timeframe; when using a higher timeframe, use its still-forming bar.
Calculation: QQE fast and slow levels = trailing levels around the QQE line. For each, smooth the absolute bar-to-bar change in the QQE line with two successive EMAs using the RSI period, then multiply by its width factor; the fast factor is smaller than the slow factor. For each bar, starting from the prior level L and prior QQE value Qₚ, set the candidate to L. If current Q < L, set it to Q + smoothed change × width factor, but clamp it to L when Qₚ < L and the candidate > L. Then, if Q > the candidate, set it to Q − smoothed change × width factor, but clamp it to L when Qₚ > L and the candidate < L. The resulting candidate is the level.
Long: QQE line > QQE fast level AND QQE line > QQE slow level
Short: QQE line < QQE fast level AND QQE line < QQE slow level
