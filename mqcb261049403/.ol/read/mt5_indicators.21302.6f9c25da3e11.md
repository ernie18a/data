Calculation: Applied price = selected bar price: open, high, low, close, (high + low) / 2, (high + low + close) / 3, (2 × close + high + low) / 4, (open + close) / 2, (open + close + high + low) / 4; trend-follow price = high if close > open, low if close < open, otherwise close; second trend-follow price = (high + close) / 2 if close > open, (low + close) / 2 if close < open, otherwise close; Demark price = ((R − low) + (R − high)) / 2, where R = (high + low + close + low) / 2 if close < open, (high + low + close + high) / 2 if close > open, otherwise (high + low + close + close) / 2.
Calculation: First line = previous first-line value + (applied price − previous first-line value) / averaging coefficient when applied price is above both the previous first-line value and previous applied price, or below both; otherwise it equals the previous first-line value. Initialize from applied price.
Calculation: Second line = previous second-line value + (applied price − previous second-line value) / averaging coefficient when applied price is above the previous second-line value and below the previous applied price, or below the previous second-line value and above the previous applied price; otherwise it equals the previous second-line value. Initialize from applied price.
