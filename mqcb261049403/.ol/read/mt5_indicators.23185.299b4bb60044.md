Calculation: Smoothed volume-weighted Fisher value = 100 × the selected smoother applied to volume × Fisher value, where each bar's normalized price is (selected applied price − lowest low over the lookback) / (highest high over the lookback − lowest low over the lookback); recursively set x = normalized price − 0.5 + 0.67 × prior x, then Fisher value = 0.5 × ln((1 + x) / (1 − x)) + 0.5 × prior Fisher value.\nCalculation: Trigger = prior bar's smoothed volume-weighted Fisher value.\nLong: On the chart timeframe, smoothed volume-weighted Fisher value > Trigger OR on a higher timeframe, smoothed volume-weighted Fisher value > Trigger, using the higher-timeframe bar still forming.\nShort: On the chart timeframe, smoothed volume-weighted Fisher value < Trigger OR on a higher timeframe, smoothed volume-weighted Fisher value < Trigger, using the higher-timeframe bar still forming.
