Calculation: Cycle period = Let P=(high+low)/2; S=(P+2P[-1]+2P[-2]+P[-3])/6. Initialize Cycle=(P-2P[-1]+P[-2])/4 for the first six bars; thereafter Cycle=(1-0.5α)^2(S-2S[-1]+S[-2])+2(1-α)InstPeriod·Cycle[-1]-(1-α)^2Cycle[-2]. Q=(0.0962Cycle+0.5769Cycle[-2]-0.5769Cycle[-4]-0.0962Cycle[-6])·(0.5+0.08InstPeriod); I=Cycle[-3]. When current and prior Q are nonzero, phase change=(I/Q-I[-1]/Q[-1])/(1+I·I[-1]/(Q·Q[-1])); otherwise retain the prior phase change. Clip each phase change to [0.1,1.1], take the median of the latest five, set DC=6.28318/median+0.5 (or 15 if median is zero), then InstPeriod=0.67InstPeriod[-1]+0.33DC and CyclePeriod=0.85CyclePeriod[-1]+0.15InstPeriod.
Calculation: Adaptive RVI = Let L=floor((4·CyclePeriod+3·CyclePeriod[-1]+2·CyclePeriod[-2]+CyclePeriod[-3])/20). For each bar, U=(close-open+2(close[-1]-open[-1])+2(close[-2]-open[-2])+(close[-3]-open[-3]))/6 and V=(high-low+2(high[-1]-low[-1])+2(high[-2]-low[-2])+(high[-3]-low[-3]))/6. Adaptive RVI=sum of the latest L values of U divided by sum of the latest L values of V.
