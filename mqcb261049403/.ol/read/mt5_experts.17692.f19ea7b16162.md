Calculation: IBS-RSI-CCI main line = On each bar, form the average of (700 × (smoothed IBS − 0.5)), CCI, and (9 × (RSI − 50)); IBS is (close − low) / max(high − low, minimum price increment), smoothed by a moving average. Apply a recursive threshold filter: move the prior main-line value to raw value minus the threshold when the difference exceeds the threshold, to raw value plus the threshold when it is below the negative threshold, and otherwise retain the prior value. Use the slow parameter set on a higher timeframe than the chart and the fast parameter set on a lower timeframe; the slow line is read from its last completed bar, and fast-line comparisons use the two latest completed bars. The slow parameter set is longer-term than the fast set.
Calculation: IBS-RSI-CCI signal line = the average of two moving averages of the rolling highest and rolling lowest main-line values, using the same lookback and smoothing periods. Use the corresponding slow or fast parameter set and timeframe as for the main line.
Long: Slow main line > slow signal line AND fast main line on the earlier completed bar <= fast signal line on that bar AND fast main line on the latest completed bar > fast signal line on that bar
Short: Slow main line < slow signal line AND fast main line on the earlier completed bar >= fast signal line on that bar AND fast main line on the latest completed bar < fast signal line on that bar
Exit: long, slow main line < slow signal line OR fast main line < fast signal line on the latest completed bar
Exit: short, slow main line > slow signal line OR fast main line > fast signal line on the latest completed bar
