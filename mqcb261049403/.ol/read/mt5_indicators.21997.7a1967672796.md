Calculation: Trend-envelope state = Smooth each bar’s high and low with the same selected moving-average type and lookback; calculate the standard deviation of close over its lookback as sqrt((sum(close²) - sum(close)²/N) / N), using up to N available bars but dividing by N; set raw upper and lower bands to smoothed high + deviation multiplier × standard deviation and smoothed low − deviation multiplier × standard deviation. For each bar, set trend to +1 if close exceeds the prior upper band, otherwise −1 if close is below the prior lower band, otherwise retain the prior trend (initial trend is 0). When trend is +1, carry forward the prior lower band if the raw lower band is lower; when trend is −1, carry forward the prior upper band if the raw upper band is higher. If calculated on a higher timeframe, use the higher-timeframe bar containing the chart bar’s time, including while that bar is still forming.
Long: Current trend = +1 AND prior trend != +1
Short: Current trend = −1 AND prior trend != −1
