Calculation: RSI = Relative Strength Index calculated from median price (high + low) / 2; use the current chart bar while it is forming.
Calculation: Stochastic = Stochastic Oscillator using high/low prices and SMA smoothing; use the current chart bar while it is forming unless comparing with the preceding bar, which is completed. Use a longer-lookback version and a shorter-lookback version.
Long: Current chart bar tick volume is at the first-tick threshold AND longer-lookback Stochastic main line > signal line AND main line < lower threshold AND absolute difference between shorter-lookback Stochastic main and signal lines > separation threshold
Short: Current chart bar tick volume is at the first-tick threshold AND longer-lookback Stochastic main line < signal line AND main line > upper threshold AND absolute difference between shorter-lookback Stochastic main and signal lines > separation threshold
Exit: long, current chart bar tick volume is at the first-tick threshold AND RSI > upper exit threshold AND longer-lookback Stochastic signal line > upper stochastic threshold AND current signal line < preceding completed bar signal line
Exit: short, current chart bar tick volume is at the first-tick threshold AND RSI < lower exit threshold AND longer-lookback Stochastic signal line < lower stochastic threshold AND current signal line > preceding completed bar signal line
