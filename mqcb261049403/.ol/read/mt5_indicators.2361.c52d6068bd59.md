Calculation: DynamicRS state = On each bar of the selected timeframe (same as or higher than the chart timeframe), set the line to the close and state to 1 initially. Thereafter, if high < previous high AND high < high from the longer lookback AND high < previous line, set the line to high plus the vertical offset and set state to 1 if the previous state was 2, otherwise 0. Else, if low > previous low AND low > low from the longer lookback AND low > previous line, set the line to low plus the vertical offset and set state to 1 if the previous state was 0, otherwise 2. Otherwise, keep the previous line and state; if state is 1, set it to 2 when the state two bars ago was 0, or to 0 when the state two bars ago was 2.
Long: Current chart bar opens at the start of a selected-timeframe bar AND the state of that still-forming selected-timeframe bar = 2
Short: Current chart bar opens at the start of a selected-timeframe bar AND the state of that still-forming selected-timeframe bar = 0
