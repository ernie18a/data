On the first tick of each new bar, optionally exit based on account-wide data:
- If the enabled percentage profit target is nonzero, scan open orders from the last position down to position 1, accumulating floating profit for market orders on the traded instrument. Whenever the running total reaches the configured percentage of account balance, close all market orders and delete all pending orders on that instrument, regardless of strategy identifier.
- If the enabled equity stop finds that the combined floating profit of this strategy's market orders on the instrument is negative and its absolute value exceeds the configured percentage of the account equity reference, close those orders. Update the equity reference only when this comparison is evaluated: reset it to current equity if there are no such orders, then set it to previous equity if the reference is below previous equity; otherwise set it to current equity. Finally store current equity as previous equity.
- If money trailing is enabled, the instrument's scanned net profit including commission and swap is negative, and this strategy's gross floating loss exceeds the configured equity-risk percentage times the equity reference times the loss multiplier, scan orders from the last position down to position 1. For market orders on the instrument, accumulate the absolute value of each order's profit including commission and swap. After each matching instrument order, close all market orders and delete all pending orders on the instrument if that accumulated amount reaches the configured money-loss threshold. The equity reference is updated as above when the loss comparison is evaluated.
