Read the economic calendar in order and consider only the first event whose scheduled time has not fallen more than a configurable waiting period into the past. Act only if it is a high-importance event with an actual value and a comparison value: use the forecast when present, otherwise the previous value. No trade is made when the values are equal. The event is eligible even before its scheduled time if an actual value is already present.

Trade EURUSD for EUR or USD news, GBPUSD for GBP, AUDUSD for AUD, NZDUSD for NZD, USDJPY for JPY, USDCHF for CHF, and USDCAD for CAD. If the actual value exceeds the comparison value, buy for EUR, GBP, AUD, or NZD news and sell for USD, JPY, CHF, or CAD news. If it is lower, reverse the direction.

Suppress a trade if an open or historical order already has a matching key formed from the event currency, actual value, and comparison value, regardless of direction. Size the trade using a configurable stepped schedule based on the absolute percentage difference between actual and comparison values. Set a stop loss at a configurable distance from entry and a take profit at a configurable multiple of that distance. Optionally close tagged positions after a configurable elapsed time, measured from the most recent order attempt.
