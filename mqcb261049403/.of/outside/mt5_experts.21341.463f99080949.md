On each tick, determine whether the current server time is inside the configured trading window. If time filtering is disabled, treat it as outside for the profit check, but do not close positions merely for being outside. For a start hour before the end hour, include the start hour from the start minute onward, all intervening hours, and the end hour before the end minute. For equal hours, include minutes from the start minute through just before the end minute. For a start hour after the end hour, include any hour at or after the start hour only when its minute is at least the start minute, all hours before the end hour, and the end hour before the end minute.

If aggregate account floating profit is positive, no stop is latched, and the time is inside the window, take no action. Otherwise, if no stop is latched, latch it when either the absolute aggregate floating profit divided by account balance, expressed as a percentage, reaches or exceeds the configured percentage threshold, or, in currency mode, the absolute aggregate floating profit exceeds the configured currency threshold. This calculation can trigger on positive profit outside the window or when time filtering is disabled.

When the stop is latched, or time filtering is enabled and the time is outside the window, attempt to close all open long and short positions across all instruments. Keep retrying on subsequent ticks while the stop remains latched; clear the latch once no positions remain. The strategy does not open positions.
