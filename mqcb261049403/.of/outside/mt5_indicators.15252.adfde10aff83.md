Track a direction using closing prices and a reversal threshold based on recent average high–low range, scaled by symbol precision. In an uptrend, raise the reference to each new closing high and set the threshold below it; a close below the threshold switches to downtrend and signals short. In a downtrend, lower the reference to each new closing low and set the threshold above it; a close above the threshold switches to uptrend and signals long. Signal only on direction changes.
