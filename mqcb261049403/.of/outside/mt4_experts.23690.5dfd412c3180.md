On the first tick of each new bar, apply these enabled account-based exits:
- If the configured profit percentage is nonzero, scan open orders in descending position-index order from the order count through index 1, accumulating floating profit for market orders on the traded instrument. Whenever the running total reaches the configured percentage of account balance, close all market orders and delete all pending orders on that instrument, regardless of strategy identifier. Index 0 is omitted from the profit calculation.
- If the strategy's market positions on the instrument have a negative combined floating profit, update an equity reference: if its stored value is below the previously sampled account equity, set it to that previous equity; otherwise set it to current account equity. Then save current equity as the previous sample. If the loss exceeds the configured percentage of the reference, close all of the strategy's market positions on the instrument. Initialize both stored equity values to zero.
