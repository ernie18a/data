Use account-wide data in these decisions:

- In all versions except the sixth, if percentage profit taking is enabled and its threshold is nonzero, scan open orders from the highest position index down to index one, accumulating the traded instrument's gross profit for market positions. As soon as the running sum reaches the configured percentage of account balance, close all market positions and delete pending orders on that instrument, regardless of ownership.
- In the fourth, fifth and sixth versions, if the equity stop is enabled, close the strategy's market positions on the instrument when their combined gross profit is negative and its absolute value exceeds a configured percentage of the equity reference. Update that reference only when this negative-profit test is evaluated: if there are no strategy positions, first set it to current account equity; then, if the reference is less than the previously recorded equity, set it to that previous equity, otherwise set it to current equity. Finally record current equity as previous equity. The sixth version checks this stop only on a new bar; the others check every tick.
- In the sixth version, when basket protection is enabled, on every tick sum profit, swap and commission for the strategy's market positions on the instrument. If at least one exists, close them and stop processing that tick when the sum reaches the configured positive percentage of account balance, falls to the negative hard-stop percentage of balance, or falls to the configured negative percentage of balance with at least the configured minimum number of positions.
- In the sixth version's enabled money-trailing logic, a negative net instrument profit can also initiate an exit when the strategy's gross instrument loss exceeds the configured equity-risk percentage of the equity reference multiplied by the configured loss factor. Scan order indices from the total down to one, accumulating absolute net profits of market positions on the instrument; close all instrument orders when that running sum reaches the absolute difference between the stored trailing reference and the configured money-stop amount. Before each comparison, replace the stored reference with the absolute current net instrument profit if the latter is no greater than the absolute stored reference.
- Entry and averaging orders are also gated by account-wide free margin, trade permission and broker margin or stop-out checks. The initial hedge is attempted on a new bar when no strategy order exists on the instrument; each side is checked separately. Averaging requires the applicable price-distance condition and margin checks.
