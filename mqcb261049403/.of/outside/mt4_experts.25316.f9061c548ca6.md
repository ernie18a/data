Use account-level balance and equity for these exits on the traded instrument:

- If enabled, accumulate the open positions’ gross profit for the instrument in reverse order, skipping position index zero. After each iteration, if the accumulated profit reaches the configured percentage of account balance, close all market positions and delete all pending orders for the instrument, regardless of strategy identifier.
- If the equity stop is enabled, sum the gross profit of this strategy’s open positions on the instrument. When it is negative and its absolute value exceeds the configured percentage of the account-equity reference, close all of those positions.
- If money trailing is enabled and this strategy has an open position, sum net profit including commission and swap for the instrument’s market positions in reverse order, skipping position index zero. If that sum is negative, below the configured money-profit threshold, and this strategy’s gross loss exceeds the configured percentage of the account-equity reference multiplied by the configured loss factor, iterate the same positions in reverse order. Accumulate the absolute net profit of each position. Whenever the absolute total net profit is no greater than the absolute stored trailing value, set that value to the absolute total net profit. If the accumulated absolute profit reaches the absolute difference between the stored value and the configured money-stop amount, close all market positions and delete all pending orders for the instrument. Reset the stored trailing value to zero when the strategy has no open positions; it is also updated by the positive-profit trailing logic.

For each equity-reference calculation, first set the reference to current account equity if the strategy has no open positions. Then, if the reference is below the equity recorded at the previous reference calculation, set it to that previous equity; otherwise set it to current equity. Record current equity for the next calculation. Evaluate the money-trailing exit before the equity stop; entry processing can still occur afterward.
