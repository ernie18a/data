When the time restriction is enabled and sufficient indicator history is available, close all positions in the traded instrument whenever server time is outside the permitted interval. Do not open positions outside it. Determine whether the current hour and minute are permitted as follows: if the start hour is earlier than the end hour, permit the start hour from the start minute onward, all hours strictly between them, and the end hour before the end minute. If the hours are equal, permit that hour from the start minute up to, but excluding, the end minute. If the start hour is later than the end hour, permit hours at or after the start hour only when the current minute is at least the start minute; also permit all hours before the end hour and the end hour before the end minute.
