Once per new bar, evaluate these enabled exits in order:
1. If the configured balance-percentage profit target is nonzero, scan open orders backward from the out-of-range position equal to the order count down to position 1. Accumulate gross profit from market positions on the traded symbol, regardless of identifier. After each iteration, if the accumulated profit reaches the configured percentage of account balance, close all market positions and delete all pending orders on that symbol.
2. For the money-trailing exit, reset its stored profit reference when there are no market positions on the symbol with the strategy identifier. Otherwise, sum net profit, including commission and swap, for market positions on the symbol using the same order-index scan. When this sum is positive but below the configured profit ceiling, scan those orders again, update the stored reference to the greater of itself and the total net profit, and close all symbol orders if the running net-profit subtotal falls at least the configured money distance below that reference. When the total net profit is negative and below the ceiling, and the strategy-identified symbol positions' gross loss exceeds the configured equity-risk percentage times the equity reference times the configured loss multiplier, scan again: accumulate the absolute net profit of each market position, replace the stored reference with the absolute total net profit whenever the latter is no greater than the absolute stored reference, and close all symbol orders if the running absolute subtotal reaches the absolute difference between that reference and the configured money distance.
3. If the equity stop is enabled and the gross profit of strategy-identified market positions on the symbol is negative, close those positions when its absolute value exceeds the configured equity-risk percentage of the equity reference.
The equity reference is stateful and is updated whenever either equity-based test evaluates it: if there are no strategy-identified market positions on the symbol, first set it to current account equity; then set it to the previous observed equity if the reference is lower than that previous value, otherwise set it to current equity. Finally record current equity as the previous observed equity. Initially both stored values are zero.
