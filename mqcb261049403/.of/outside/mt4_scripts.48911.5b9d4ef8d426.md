On a single run, if trading is allowed, process enabled profit-based exit rules in this order: all profitable, long profitable, short profitable, all losing, long losing, short losing. Each rule tests the monetary profit of the currently selected order before selecting any orders for that rule; this order may belong to any instrument and may have been selected by an earlier management pass. For each enabled positive threshold, proceed if the selected order's profit is less than or equal to the shared all-positions positive threshold, even for direction-specific rules. For each enabled negative threshold, proceed if the selected order's profit is greater than or equal to the negation of that rule's threshold. When a test passes, close all active positions across instruments in the rule's specified direction, or both directions for an all-positions rule. The short-only negative rule instead closes long positions. Each pass selects orders while iterating, so it can change the selected order used by the next rule.
