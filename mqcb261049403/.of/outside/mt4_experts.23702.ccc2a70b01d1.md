On the first tick of each new chart bar, apply these enabled account-dependent exits:

- Percentage profit target: Set the target to a configured percentage of account balance. Traverse open-order positions from the total order count down to 1, summing gross profit of market positions on the traded instrument. After each iteration, if the running sum reaches the target, close all market positions and delete all pending orders on that instrument, regardless of identifier. Skip this rule if the configured percentage is zero.
- Equity stop: Sum gross profit of the instrument's market positions with the strategy's identifier. If it is negative and its absolute value exceeds a configured percentage of the equity reference, close those positions.
- Money trailing loss exit: Sum profit, commission and swap for the instrument's market positions by traversing order positions from the total count down to 1. If this sum is negative and below the configured money profit threshold, and the strategy-identified positions' gross loss exceeds the configured equity-risk percentage of the equity reference multiplied by the configured loss factor, traverse the same positions again. Accumulate the absolute net profit of each market position on the instrument; once the accumulation reaches the configured money loss threshold, close all market positions and delete all pending orders on that instrument, regardless of identifier.

Whenever either loss test needs the equity reference, update it as follows: if there are no strategy-identified market positions on the instrument, first set the reference to current account equity. Then, if the reference is below the previously recorded equity, set it to that previous equity; otherwise set it to current equity. Record current equity as the previous equity. Evaluate the money trailing loss exit before the equity stop.
