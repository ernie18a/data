Poll the external command sheet for pending commands addressed to the current account. For a close-all command, close every open position in the specified symbol, or across all symbols if requested. For a break-even command, set each matching position's stop loss to its entry price plus the requested point offset for a long position or minus it for a short position, but only if no stop exists or the new stop improves the existing one; preserve the take profit. In strategy testing only, on the first tick, attempt one minimum-volume long position if margin calculation succeeds and free margin exceeds the required margin plus a safety buffer.
