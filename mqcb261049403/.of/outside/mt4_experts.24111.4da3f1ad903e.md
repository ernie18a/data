Run on the first tick of each new bar. Entry logic is unreachable because a second new-bar check always returns, so no new positions are opened.

If percentage take-profit is enabled, accumulate gross profit of the current instrument's market orders in reverse order, starting at the order count and stopping at index one. After each addition, if the running sum reaches the configured percentage of account balance, close all market orders and delete all pending orders for the instrument, regardless of identifier.

For the equity-based exits, compute gross profit of the instrument's market orders with the configured identifier. Whenever an equity reference is requested, first reset its stored value to current account equity if there are no such trades; then set it to previous equity if the stored value is below previous equity, or to current equity otherwise. Save current equity as previous equity.

If money trailing is enabled, at least one identified trade exists, the instrument's net profit including commission and swap is negative and below the configured money-profit threshold, and the identified trades' gross loss exceeds the configured equity-risk percentage of the equity reference multiplied by the loss multiplier, apply the loss-trailing exit. Using orders at indices from the order count down to one, sum absolute net profit for the instrument's market orders; maintain the shared trailing state by replacing it with the absolute total net loss whenever that loss is no greater than the state's absolute value. If the running absolute sum reaches the absolute difference between that state and the configured money-loss amount, close all market orders and delete all pending orders for the instrument. Reset the trailing state when there are no identified trades; the positive-profit trailing branch can also update it to the highest observed total net profit.

If the equity stop is enabled and the identified trades' gross profit is negative, close those trades when its absolute loss exceeds the configured equity-risk percentage of the equity reference.
