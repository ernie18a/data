On each new bar, if percentage profit-taking is enabled and its threshold is nonzero, scan open orders from the last index down to index 1, accumulating the traded instrument's market-order profit. After each iteration, if the running profit reaches the specified percentage of account balance, close all market orders and delete all pending orders for the instrument. If the equity stop is enabled and the strategy's market orders on the instrument have a loss exceeding the specified percentage of the equity reference, close those orders. Update the equity reference only when this loss test requires it: first set it to current account equity if there are no such orders; then set it to the previously recorded equity if the reference is below that previous equity, otherwise set it to current equity; finally record current equity as the previous equity. If money trailing is enabled, total net profit on the instrument's market orders is negative and below the money-profit target, and the strategy's market-order loss exceeds the specified equity-risk percentage of that reference multiplied by the loss factor, scan orders from the last index down to index 1. Accumulate the absolute net profit of the instrument's market orders; once that running sum reaches the money-loss threshold, close all market orders and delete all pending orders for the instrument. Net profit includes commission and swap. These scans omit order index 0.
