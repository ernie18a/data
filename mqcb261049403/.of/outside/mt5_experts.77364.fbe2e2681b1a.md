Guard either all account positions or only those in the chart instrument, as configured. On each tick and timer check, sum guarded exit-deal profit, swap, and commission since server midnight and guarded open-position profit and swap. If the enabled daily loss limit is positive and this total is at or below its negative, lock trading until the next server day and, if configured, close all guarded positions. Use a fixed monetary limit when positive; otherwise use a configured percentage of the balance recorded when the current server day was initialized. Persist the lock across restarts on the same server day; initialization records the then-current balance. On a new entry deal, close the resulting guarded position if locked; otherwise close it if the guarded open-position count exceeds the enabled cap. For an oversized position, if trimming is enabled and a stop exists, calculate its stop distance from entry. If no stop exists and forced stops are enabled, first set one at the configured distance below entry for a long or above entry for a short, and use that calculated stop even if modification fails. Calculate permitted volume from fixed risk or a configured percentage of current account balance, divided by the stop distance and loss per unit of distance per lot; round down to the volume step and clamp to the instrument's minimum and maximum volume. If the calculation is valid and current volume exceeds permitted volume, round and clamp the excess in the same way. Close the whole position if permitted volume or the remaining volume is below the minimum; otherwise close the excess volume.
