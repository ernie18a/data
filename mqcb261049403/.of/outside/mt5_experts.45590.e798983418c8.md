For a managed position, use the current value of a configurable moving average calculated on the chart instrument and timeframe as a proposed trailing stop. This can use data from outside the traded instrument when the chart instrument differs. Round the proposed stop to the traded instrument's tick size. Set it only if it is below the current price for a long position or above it for a short position, and either no stop exists or the new stop improves the existing stop by at least the configured minimum step. Keep the existing take-profit level. If the moving-average value cannot be read or is zero, leave the stop unchanged. Exit when the resulting stop is hit.
