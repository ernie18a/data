Use the traded instrument’s selected price series on a configurable timeframe to maintain two smoothed lines. Initialize both to the selected price at the first calculated bar. For each bar, move the first line from its previous value toward the current price by the configured smoothing fraction only when price is above both that line and the previous bar’s price, or below both. Move the second line similarly only when price is above that line but below the previous price, or below that line but above the previous price. Otherwise retain each line’s previous value.

At the configured signal-bar offset, compare the lines with their values on the preceding bar. When the first line crosses above the second, signal a long entry; when it crosses below, signal a short entry. Whenever the first line is above the second, signal closing shorts; whenever it is below, signal closing longs. Apply the independent entry and exit permission settings, and process exits before entries. Recalculate on each new indicator-timeframe bar, or every tick when the signal offset selects the current bar. Allow at most one entry per direction and strategy identifier until the next indicator bar, and do not open another position with the same identifier while one exists.

If the trading-time restriction is enabled, permit entries only during the server-time window and close matching strategy positions outside it. For a start hour earlier than the end hour, allow the start hour from the start minute, all intervening hours, and the end hour before the end minute. For equal hours, allow minutes from the start minute up to but excluding the end minute. For a start hour later than the end hour, allow hours at or after the start hour only when the current minute is at least the start minute, all hours before the end hour, and the end hour before the end minute. If the restriction is disabled, entries are unrestricted by time. Apply configured stop-loss and take-profit distances to entries.
