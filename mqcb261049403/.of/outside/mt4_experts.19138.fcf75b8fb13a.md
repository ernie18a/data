On each tick, allow new trades only when platform trading is permitted and no enabled calendar event is within its configured before-and-after window. Use the selected news source, adjust event times to the configured time zone, and optionally restrict events to the traded pair’s currencies. Apply the configured window for each enabled impact level; an enabled Non-farm Payrolls event uses its separate window. With the Investing source, events of a disabled impact level are discarded before the Non-farm Payrolls check. Window boundaries are exclusive. If multiple events qualify, the strongest determines the displayed status, but any qualifying event blocks trading. Otherwise, if there are no open or pending orders account-wide, buy when the current hourly bar’s latest price is above the previous hourly bar’s open, or sell when it is below. Do nothing if they are equal. Set each new position’s stop loss and take profit at the specified fixed distances from its entry quote. News does not close existing positions.
