On each tick, calculate Parabolic SAR for the traded instrument on the current timeframe. A bullish signal occurs when SAR is below the current bar’s close and was above the preceding bar’s close; a bearish signal requires the opposite strict inequalities. Optionally reverse the direction associated with each signal.

On a signal, optionally close the first account-wide open order if its type opposes the signal’s resulting direction, regardless of its symbol. Then open a position in that direction only if there are no open or pending orders anywhere in the account and the direction’s entry filter passes. Repeated entries are possible while the same signal persists.

For the entry filter, multiply both configured thresholds by 10 if EURUSD has five quote digits, otherwise by 1. For a long, calculate the integer-truncated value of bid minus the current bar’s low multiplied by the traded instrument’s point size. For a short, calculate the integer-truncated value of the current bar’s high minus ask multiplied by that point size. In both expressions multiplication occurs before subtraction. Entry passes if the scaled maximum threshold is zero or at least the calculated value, and the scaled minimum threshold is strictly below that value.

Set a fixed stop loss and take profit at configured distances from the entry quote, scaling both distances by the same EURUSD-digit multiplier and the traded instrument’s point size. Optionally trail stops on all market orders for the traded symbol: use the greater of the scaled trailing distance and the broker’s minimum stop distance, moving a long stop up to bid minus that distance or a short stop down to ask plus that distance only when it improves the stop; also set a missing short stop.
