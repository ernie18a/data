On each tick and timer event, calculate daily account profit and loss by summing profit, swap, and commission for all open market trades and market trades closed since the start of the current server day, across all symbols. If the enabled daily loss limit is reached, or otherwise the enabled daily profit target is reached, lock account protection and stop automatic trade management. If closing is enabled for the triggered limit, exit all open market trades matching the configured symbol scope, buy/sell selection, and trade identifier filter. Check the loss limit before the profit target. Clear the protection lock at the start of a new server day, but do not automatically restart management.
