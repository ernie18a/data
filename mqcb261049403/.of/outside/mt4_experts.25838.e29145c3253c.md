On each new bar, evaluate these account-dependent exits for the traded instrument. When the equity-stop option is enabled, close its strategy positions if their combined floating profit is negative and its absolute value exceeds a configured fraction of the tracked account equity. The equity tracker is updated only when this test is evaluated: reset it to current equity if there are no strategy positions, then set it to the previous equity if that exceeds the tracked value, otherwise to current equity; finally save current equity as previous equity. Also, when the equity-stop option is enabled, calculate a risk amount as account balance times the configured risk fraction. Using the currently selected order's opening price, calculate a loss threshold as the absolute difference between that price and base lot size times risk amount divided by the instrument's tick value per tick size, multiplied by the number of open strategy positions. Calculate a profit threshold as the absolute sum of that price and the same lot-size and risk term, multiplied by twice the number of positions. Close all strategy positions if the absolute combined floating profit is below the loss threshold or the combined floating profit exceeds the profit threshold. If the optional percentage profit target is enabled and nonzero, traverse open orders from the total order count down to index one, accumulating floating profit for market positions in the traded instrument; whenever the running total reaches the configured fraction of account balance, close all positions and delete pending orders for that instrument. If the optional money trailing feature is enabled and the same instrument-wide net profit sum is negative and below its configured profit ceiling, first require the strategy positions' combined floating loss to exceed the configured fraction of tracked account equity multiplied by the loss multiplier. Then traverse orders from the total count down to index one, accumulating absolute net profit for matching market positions; close all positions and delete pending orders for the instrument when that running sum reaches the configured money-loss amount. Net profit includes commission and swap. The account equity tracker is updated by this test as described above.
