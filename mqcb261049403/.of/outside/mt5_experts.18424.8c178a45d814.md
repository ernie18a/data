Use the traded instrument’s selected price series on a configurable timeframe. Apply a fixed-coefficient FATL digital filter, smooth it with a Jurik moving average, and round the result to a configurable price increment. Classify each bar as rising or falling from the change in the rounded line; carry the previous classification forward when the line is unchanged. At the selected signal bar, open a long when the classification changes to rising, or a short when it changes to falling, subject to separate direction permissions and no existing position. A rising classification also closes a short, and a falling classification closes a long, subject to separate exit permissions. Evaluate on each new indicator bar, or on every tick when using the current bar. When the optional trading-time restriction is enabled, allow entries only inside the configured server-time window and close all positions in the instrument outside it. For a window spanning midnight, the late-day portion requires both the hour to be at or after the start hour and the minute to be at or after the start minute; the early-day portion includes hours before the end hour and the end hour before its end minute. For a same-day window, include the start minute and exclude the end minute. Process exits before entries. Apply configurable stop-loss and take-profit distances to new positions.
