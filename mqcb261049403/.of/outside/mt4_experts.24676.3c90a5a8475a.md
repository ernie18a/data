On each tick, if the account-equity stop is enabled and the strategy's open positions on the traded instrument have a combined floating loss exceeding a configured fraction of the account equity reference, close those positions. The equity reference is stateful: when there are no such positions, set it to current account equity; then set it to the previous observed equity if that exceeds the reference, otherwise set it to current equity. Update the previous observed equity whenever the reference is evaluated.

If the percentage profit target is enabled and nonzero, scan open orders from the highest position index down through index 1, accumulating floating profit for market positions on the traded instrument. Whenever the running sum reaches the configured percentage of account balance, close all market positions and delete all pending orders on that instrument, regardless of strategy identifier.

If money trailing is enabled, first sum profit, commission and swap for market positions on the instrument using the same index range. When that sum is negative and the strategy's combined floating loss exceeds the configured equity-risk fraction times the equity reference times a loss multiplier, scan those orders again, accumulating the absolute net profit of each market position. Once that running sum reaches the configured monetary loss threshold, close all market positions and delete all pending orders on the instrument.
