Configure an ordered set of indicator-based or expression-based conditions and assign each an action. Indicators may be custom and may use external data; expressions may also read terminal global variables. On each evaluation, refresh indicator values. At the start of a new bar, preserve the last values from the preceding bar as the previous snapshot.

A condition can test whether an indicator value is nonempty, positive, negative, or empty; whether it crosses above or below another indicator or a fixed level, using strict inequality now and inclusive inequality in the previous snapshot; or whether it is above, below, or equal to another indicator or a level. A level comparison may also test inequality. Comparing an indicator with itself compares its current value with its previous snapshot. Alternatively, evaluate a configured expression over current and previous indicator values and other available data, and test whether its result is positive, negative, or nonzero.

Process enabled conditions in order. A true condition emits its configured action: signal long, signal short, exit long, exit short, exit both, or combine an entry with the opposite exit. A condition configured to proceed acts as a gate: if false, skip the following conditions through the first condition whose action is not proceed; if true, continue normally. Multiple conditions may emit signals in one evaluation. For each direction, the first enabled entry signal supplies its configured vote weight; any enabled exit signal requests the corresponding exit. The surrounding trading framework applies its configured voting thresholds and execution rules.
