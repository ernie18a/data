Apply broker volume and margin limits; set no stop loss or take profit.

On each tick, manage the strategy's open shorts in the designated instrument. Traverse matching trades newest first, processing up to a configured count. For each visited trade, calculate the average net monetary profit across all matching open shorts. If it exceeds the first threshold, close the most profitable short, then the least profitable remaining short. Next, traverse matching shorts again, skipping the configured count, and repeat the same process using a second threshold. Recalculate the average and select trades from those still open at each iteration.
