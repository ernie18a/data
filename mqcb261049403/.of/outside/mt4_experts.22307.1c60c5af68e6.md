On each tick, if basket protection is enabled and there are strategy positions on the traded instrument, sum their floating profit, swap, and commission. Close those positions and skip further processing for the tick if the sum reaches a configured percentage of account balance in profit or loss.

On each new bar, if the equity stop is enabled and the strategy's positions on the instrument have a combined floating loss exceeding a configured percentage of the tracked account equity, close those positions. When evaluated, the tracked equity is set to current equity if there are no strategy positions; then it is set to previous equity if its value is below previous equity, otherwise to current equity. Store current equity as previous equity afterward.

If money trailing is enabled, there is at least one strategy position, and the instrument's combined net floating profit is negative, compare the strategy positions' floating loss with a configured multiple of the equity-stop threshold. If it exceeds that threshold, accumulate the absolute net profit of each selected instrument position in reverse order, excluding position index zero. Update the shared trailing value to the absolute total net loss when that loss is no greater than the absolute trailing value. If the accumulated amount reaches the absolute difference between the trailing value and the configured money-stop amount, close all positions and delete pending orders on the instrument.
