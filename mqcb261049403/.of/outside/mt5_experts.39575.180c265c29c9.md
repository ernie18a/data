On each new bar, process externally supplied orders. At the configured trading hour for an order's instrument, if its date is today, process zero-amount orders first: close positions opened by this system, either across all instruments or only those with the matching order ID, according to the ID setting. Then process nonzero orders: if the instrument has fewer than the allowed number of open positions, open long for a positive amount or short for a negative amount, using its absolute value as size, optionally scaled by current equity divided by initial equity. Pass the order's stop-loss and take-profit values to the trade. On every new bar, also close any system position whose ID matches a zero-amount order more than one day past its timestamp.
