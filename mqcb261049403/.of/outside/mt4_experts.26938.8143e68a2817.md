On each tick, apply these enabled account-based exits before considering entries; trading may resume on the same tick after an exit.

- Equity stop: Sum the gross floating profit of this instrument's market positions belonging to this strategy. If it is negative and its absolute value exceeds a configured percentage of an account-equity reference, close all such positions. Whenever the reference is evaluated, first set it to current equity if there are no strategy positions; then set it to the previously sampled equity if the reference is below that previous equity, otherwise set it to current equity. Finally store current equity as the previous sample.
- Percentage profit target: Scan open orders in descending position-index order, starting at the order count and stopping at index one. Accumulate gross floating profit of this instrument's market positions, regardless of strategy. After each selected order, if the accumulated profit reaches the configured percentage of account balance, close all market positions and delete all pending orders for this instrument, regardless of strategy.
- Money-trailing loss exit: If enabled and the instrument's net floating profit, including commission and swap, is negative and below the configured money-profit threshold, evaluate the strategy's gross floating profit. If that profit is negative and its absolute value exceeds the configured equity-risk percentage multiplied by the account-equity reference and a loss multiplier, scan the instrument's open orders in the same descending index range. Accumulate absolute net profit for each market position; once this sum reaches the configured money-loss threshold, close all positions and delete all pending orders for the instrument. The equity reference is updated as described above when evaluated.
