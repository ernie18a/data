Once per new bar, manage exits before considering entries. If enabled, close the strategy's positions on the traded instrument when their combined floating profit is negative and its absolute value exceeds a configurable percentage of account equity. The equity reference is updated only when this check is evaluated: reset it to current equity when there are no strategy positions; then, if the stored reference is below the equity recorded on the preceding evaluation, replace it with that preceding equity; otherwise replace it with current equity. Record current equity for the next evaluation.

If enabled, close all positions and delete pending orders on the instrument when the running sum of floating profit reaches a configurable percentage of account balance. Calculate this sum by scanning open orders from index equal to the order count down through index one, skipping invalid selections and index zero; test the threshold after each selection.

If money trailing is enabled and the strategy has positions, calculate net floating profit including commission and swap for the same index range. When that total is negative and below the configured profit ceiling, and the strategy's own floating loss exceeds a configurable multiple of the account-equity risk threshold, scan the same orders and accumulate the absolute net result of each instrument position. During that scan, replace the stored trailing reference with the absolute total if it is no greater than the reference; close all instrument orders when the accumulated amount reaches the absolute difference between that reference and the configured money stop. Reset the reference when the strategy has no positions.

Entry signals also require sufficient account free margin, a successful direction-specific margin and stop-out check, valid stop levels, and trading permission. Subject to the position limit and history requirements, buy when the absolute distance from bid to the previous close exceeds a configured distance, the previous low is below the current fast linearly weighted moving average of typical price while the previous close is above it, that fast average is above the slow equivalent, and the previous low is below the previous lower simple moving-average envelope. Sell with the symmetric conditions using ask, previous high, and the upper envelope. Evaluate the buy first and stop entry processing if its signal occurs, even if order placement fails.
