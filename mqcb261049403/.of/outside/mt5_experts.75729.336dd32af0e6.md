On each tick and timer event, calculate the account-wide daily result as the sum of profit, swap and commission on closing deals since server midnight, plus floating profit and swap on all open positions. If deal history cannot be retrieved, use current equity minus the balance recorded when the current server day was first observed. If an enabled, positive daily loss limit is reached or exceeded, close matching positions only if closing on loss is enabled, then disable position management. Otherwise, if an enabled, positive daily profit target is reached or exceeded, close matching positions only if closing on profit is enabled, then disable position management. Match positions by the configured current-symbol or all-symbol scope, enabled trade directions, and manual-only, all-position, or specified identifier filter. Check account protection even when management is disabled.
