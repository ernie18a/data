Use the traded instrument’s price on a configurable timeframe to maintain a percentage-offset trailing line: initialize it to the first price; for each subsequent bar, raise it to price times one minus the configured percentage if that exceeds the previous line, otherwise lower it to price times one plus the percentage if that is below the previous line, otherwise leave it unchanged. Mark the direction up when the line rises, down when it falls, and retain the prior direction when it is flat. At each new bar, or on every tick when the configured signal bar is the current bar, inspect its direction and that of the preceding bar. An up direction signals closing shorts, and a change from down to up signals opening a long. A down direction signals closing longs, and a change from up to down signals opening a short. Apply independent permissions for each entry and exit; close before opening, and open only when no position exists in the instrument. With time filtering enabled, close all positions in the instrument whenever the server time is outside the configured interval and permit entries only inside it. For a same-day interval, include the start and exclude the end. For an overnight interval, the code permits times before the end hour, times in the end hour before the end minute, and times at or after the start hour only when their minute is at least the start minute. Attach configurable stop-loss and take-profit distances to new positions.
