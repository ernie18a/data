Account-level global stop-loss that exits every open position at once. It does not use price data and never opens trades. Keep a persistent boolean 'liquidation active' flag, initially false. On every tick, read the account balance and the total floating profit/loss across all open positions. (1) If the flag is false and floating profit is positive, do nothing. (2) If the flag is false and floating profit is zero or negative, compute the loss and compare it to a user-set threshold. The loss is measured in one of two selectable modes. In percent mode, loss = absolute value of 100 * floating profit / balance, and the flag is set when loss is greater than or equal to the threshold. In currency mode, loss = absolute value of floating profit in deposit currency, and the flag is set when loss is strictly greater than the threshold. (3) While the flag is true, on each tick check the number of open positions. If there are none, clear the flag and stop. Otherwise iterate over all open positions on all symbols and close each one at market for its full volume, capped at the symbol's maximum order volume. A long position is closed with a sell and a short position with a buy. Closing uses a fill-or-kill order with a small price deviation allowed and no SL/TP. Validate the request before sending it. If a close fails, leave the flag set so the next tick retries the remaining positions. Once the flag is set, liquidation continues on subsequent ticks even if floating profit recovers, until no positions remain.
