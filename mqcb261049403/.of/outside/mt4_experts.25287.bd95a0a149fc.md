Evaluate once per new chart bar. Account-wide equity, balance and free margin affect these decisions:

- If enabled, close all strategy-tagged positions in the traded instrument when their combined floating profit is negative and its magnitude exceeds a configured percentage of the equity reference. Update that reference when evaluated: if there are no tagged positions, first set it to current equity; then use previous equity if the reference is below previous equity, otherwise use current equity. Save current equity as previous equity.
- If enabled, close all positions and delete pending orders in the instrument when the running sum of its positions' floating profit reaches a configured percentage of account balance. Iterate order positions from the total count down to index one, checking the threshold after each selected order; index zero is omitted.
- If money trailing is enabled, tagged positions exist, the instrument's net floating result including commission and swap is negative and below the configured money-profit threshold, and tagged floating loss exceeds a configured percentage of the equity reference multiplied by a loss factor, accumulate the absolute net result of each instrument position in that same descending, index-one-inclusive scan. Close all instrument positions and delete its pending orders when the running total reaches the absolute difference between the saved trailing-profit state and the configured money-loss distance. Before each comparison, replace the saved state with the absolute aggregate result if that result is no greater than the absolute saved state. Reset the state when no tagged positions exist.
- Free margin and broker margin checks gate entries. Subject to those checks, the position limit, sufficient chart history and valid protective levels, enter long when the absolute distance from bid to the close two bars ago exceeds a configured distance, the fast typical-price linear weighted moving average exceeds the slow one on the selected higher timeframe, and the low two bars ago is below the previous bar's high. Enter short on the corresponding ask-distance test, fast average below slow, and previous low below the high two bars ago. In live trading, additionally require both trend lines through the most recent and third-most-recent ZigZag highs and lows to slope down for a long, or both to slope up for a short. Testing omits these line filters. If the preliminary long conditions hold, do not evaluate the short entry even if the live filter or an execution check fails.
