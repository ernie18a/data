When processing is enabled, first check the strategy's positions on the traded instrument. If their combined profit reaches the configured target, close all positions. Otherwise, if their combined unweighted pip result reaches the configured loss threshold and loss closing is enabled, close either the first position on each side or all positions, according to the selected mode. Otherwise, if hedging is enabled, combined position profit including swap is negative, and its absolute value as a percentage of account balance reaches the configured threshold, enter hedge mode and open a position opposite the larger total position volume, sized as the volume difference times the configured hedge multiplier. If volumes are equal, enter hedge mode without opening a position. Hedge mode prevents another such hedge; it is also set when there is more than one position on each side and total volumes are equal, and is cleared only when no positions remain. Profit and loss exits take priority over hedging. When the completed-bar setting is enabled, tick processing always returns without making decisions.
