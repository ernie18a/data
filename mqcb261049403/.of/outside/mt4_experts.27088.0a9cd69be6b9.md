When enabled, on every tick sum the open positions’ profit, swap and commission for the traded instrument and strategy identifier. If that basket reaches the configured profit percentage of account balance or falls to the configured negative loss percentage, close those positions and skip the rest of that tick.

When enabled, once per new bar, close the strategy’s positions on the traded instrument if their combined unrealized profit is negative and its absolute value exceeds the configured percentage of the account equity reference. The reference is updated when needed: if there are no strategy positions, set it to current equity; then, if it is below the previously recorded equity, set it to that previous equity, otherwise set it to current equity. Finally record current equity as previous equity.

When money trailing is enabled and its tracked net profit for the instrument is negative and below the configured profit threshold, apply its loss exit only if the strategy’s gross position loss exceeds the configured equity-risk percentage times the equity reference and loss multiplier. Iterate instrument orders in descending position index, excluding index zero; accumulate absolute net profit for market positions. Maintain a stored trailing value, initially zero, replacing it with the absolute total net profit only when that absolute total is no greater than the stored value’s absolute value. If the accumulated absolute net profit reaches the absolute difference between that stored value and the configured money-stop amount, close all market positions and delete pending orders on the instrument.
