When scheduling is enabled, close the strategy's positions in the traded instrument whenever broker server time is outside the permitted period. If the start hour precedes the end hour, permit times from the start time inclusive to the end time exclusive. If both hours match, permit only that hour with minutes at least the start minute and below the end minute. If the start hour follows the end hour, permit times when the hour is at least the start hour AND the minute is at least the start minute, or the hour precedes the end hour, or the hour equals the end hour and the minute precedes the end minute. Perform these exits before processing entries; the schedule does not prevent new entries outside the permitted period.
