On each new bar, optionally exit all positions and delete all pending orders for the traded instrument when the summed open profit of its market orders reaches a configured percentage of account balance. The profit calculation examines order-list positions from the total count down to index one, omitting index zero. Optionally, if the summed open profit of this strategy's market positions on the instrument is negative and its absolute value exceeds a configured percentage of the account-equity reference, close those positions. Update that reference when evaluating the stop: if there are no strategy positions, first set it to current equity; then set it to previous equity if the reference is lower than previous equity, otherwise set it to current equity. Save current equity as previous equity.
