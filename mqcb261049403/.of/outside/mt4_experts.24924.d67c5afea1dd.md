On the first tick of each new chart bar, apply the enabled account-based exits:
- Percentage profit target: Multiply account balance by the configured percentage. Scan open orders from position index equal to the order count down through index 1, summing raw profit of market positions on the traded instrument, regardless of strategy identifier. After each iteration, if the running sum reaches the target, close all market positions and delete all pending orders on that instrument. Skip this check if the configured percentage is zero.
- Equity stop: Sum raw profit of open market positions on the traded instrument with the strategy identifier. If the sum is negative, update the equity reference: first set it to current account equity if there are no such positions; then, if the reference is below the previously recorded account equity, set it to that previous equity, otherwise set it to current equity. Record current equity as the previous equity. If the absolute loss exceeds the configured percentage of the resulting reference, close all market positions on the instrument with the strategy identifier.
