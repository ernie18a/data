At the first tick of each new bar, evaluate these optional exits using account data:
- For the percentage profit target, scan open orders from the end down to index 1. Accumulate the floating profit of market orders on the traded instrument, regardless of strategy identifier. If the running sum reaches the configured percentage of account balance, close all market orders and delete all pending orders on that instrument.
- For the equity stop, sum the floating profit of this strategy's market orders on the instrument. If it is negative and its absolute value exceeds the configured percentage of the equity reference, close those orders.
- For the money-trailing loss branch, if the instrument's net floating profit including commission and swap is negative and below the configured money profit threshold, and this strategy's floating loss exceeds the configured equity-risk percentage multiplied by the equity reference and a loss multiplier, scan orders from the end down to index 1. Accumulate the absolute net profit of market orders on the instrument; when that running sum reaches the configured money loss amount, close all market orders and delete all pending orders on the instrument.

For each equity-reference calculation, first set the reference to current account equity if this strategy has no market orders on the instrument. Then, if the reference is below the previous equity observation, set it to that previous observation; otherwise set it to current equity. Finally store current equity as the previous observation. The reference and previous observation initially equal zero.
