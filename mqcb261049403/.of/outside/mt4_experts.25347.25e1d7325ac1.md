On each tick, apply these enabled account-based exits:
- Sum the floating profit, excluding commission and swap, of this strategy’s open buy and sell positions on the current instrument. If the sum is negative and its absolute value exceeds a configured percentage of the account equity reference, close those positions. Update the equity reference only when evaluating this negative-profit condition: if the stored reference is below the equity recorded at the previous evaluation, replace it with that previous equity; otherwise replace it with current equity. Then record current equity for the next evaluation.
- For the account-balance profit target, scan open orders in descending position order, starting at the total order count and stopping at position one; thus position zero is omitted. Accumulate floating profit, excluding commission and swap, for buy and sell positions on the current instrument regardless of strategy. After each iteration, if the running sum reaches the configured percentage of current account balance, close all buy and sell positions and delete all pending orders on that instrument.
