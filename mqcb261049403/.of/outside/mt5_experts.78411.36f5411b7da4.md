Construct a synthetic index from configured underlying instruments and signed weights, using either a scaled product of prices raised to their weights or a weighted sum. For its bid, use each positive-weight leg's bid and each negative-weight leg's ask; reverse those choices for its ask.

When automatic trading is enabled, sample the index bid and use the last sample in each configured time interval as that bar's close. Seed fast and slow exponential moving averages with the first close and update them on each subsequent closed bar. After the slow-average warm-up, signal long if the fast average is above the slow average or short if below. Thereafter, signal only when their nonzero ordering reverses, ignoring equality. A take-profit or stop-loss exit alone does not generate a new entry.

For a signal, keep a complete basket already in the signaled direction; otherwise close any existing basket and, once flat, attempt to open the signaled direction. For a long index basket, buy positive-weight legs and sell negative-weight legs; reverse the sides for a short basket. Maintain at most one basket.

For a complete open basket, calculate its entry index from the volume-weighted actual entry price of each leg. Close every leg when the current index bid minus entry for a long, or entry minus the current index ask for a short, reaches the enabled profit target or falls to the negative of the enabled stop distance. Disable either threshold when set to zero. Pause these exits if the basket is incomplete. Manual commands can also open either direction or close the basket.
