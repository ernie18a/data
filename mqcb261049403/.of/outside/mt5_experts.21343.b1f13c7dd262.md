On each tick, use account-wide floating profit and balance to evaluate a global exit. In percentage mode, trigger when the loss as a percentage of balance is at least the configured loss limit or profit as a percentage of balance is at least the configured profit limit. In currency mode, trigger when the absolute loss or profit strictly exceeds its respective configured limit. Once triggered, keep attempting to close all open long and short positions until no positions remain, then reset the trigger. Also close all positions whenever the optional time filter is enabled and the current server time is outside its permitted interval. Determine that interval exactly as follows: if the start hour is earlier than the end hour, permit the start hour from the start minute onward, all intermediate hours, and the end hour before the end minute. If the hours are equal, permit only that hour from the start minute inclusive to the end minute exclusive. If the start hour is later, permit any hour at or after the start hour only when its minute is at least the start minute, any hour before the end hour, and the end hour before the end minute. No positions are opened.
