For an existing position, calculate a moving average of the chart instrument using the configured timeframe, period, shift, averaging method and applied price. The chart instrument may differ from the position's instrument. If the latest average is unavailable or zero, leave the stop unchanged. Round the average to the position instrument's tick size. For a long position, use it as the stop only if it is below the current position price; for a short position, only if it is above. Set the stop if none exists; otherwise move it only in the favorable direction and by at least the configured minimum step. Preserve the take-profit level. The position exits when its stop or take-profit is reached.
