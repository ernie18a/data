On the first tick of each new chart bar, apply these enabled account-dependent exits in order:

1. For the percentage profit target, scan open orders from position index equal to the order count down through index 1. Accumulate the floating profit of market orders on the traded symbol, regardless of strategy identifier. As soon as the running sum reaches the configured percentage of account balance, close all market orders and delete all pending orders on that symbol.
2. For the money-trailing loss rule, sum profit, commission and swap over the same index range and symbol. If this sum is negative and the strategy's own market-order floating loss on the symbol exceeds a configured multiple of an equity-risk percentage of the equity reference, scan those orders again in the same order, accumulating the absolute value of each market order's profit plus commission and swap. Once the running sum reaches the configured money-loss amount, close all market orders and delete all pending orders on the symbol.
3. For the equity stop, if the strategy's own market-order floating loss on the symbol exceeds the configured equity-risk percentage of the equity reference, close those strategy market orders.

Update the equity reference whenever either loss comparison needs it: if there are no strategy market orders on the symbol, first set the reference to current account equity. Then, if the reference is below the previously observed equity, set it to that previous equity; otherwise set it to current equity. Finally record current equity as the previous equity. The reference and previous equity start at zero. The remaining entry and exit rules use only the traded instrument's data.
