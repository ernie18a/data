For an existing position, optionally trail its stop using the current moving-average value of the chart instrument, which may differ from the position’s instrument. Normalize the candidate to the position instrument’s tick size. For a long, use it only if it is below the current position price and, if a stop already exists, above that stop by at least the trailing step. For a short, use it only if it is above the current position price and, if a stop already exists, below that stop by at least the trailing step. Keep the existing take-profit. If the moving average cannot be read or is zero, leave the stop unchanged. The position exits when its stop is subsequently hit.
