Use four configured instruments. On each tick, require nonzero current-bar closes and the two most recent completed daily closes for all four; otherwise do nothing. When profit monitoring is enabled, calculate each tracked position's profit in instrument points using bid for longs and ask for shorts. Sum the last encountered profit for each of the four regular trade identifiers and all profits for the emergency identifier. If the sum reaches an enabled basket profit target or loss limit, close every position with a tracked identifier. Profit monitoring stops for the tick if any open position belongs to an instrument outside the four configured instruments or its quote is unavailable. At or after the configured daily closing hour, close all tracked positions and stop. Otherwise, enter only during the configured daily entry window, when trading is enabled and permitted and no tracked position is open. Compare the first instrument's most recent completed daily close with its preceding daily close. If it rose, buy the first, second and fourth instruments and sell the third; if it fell, reverse all four directions; if unchanged, do nothing. Submit the four orders sequentially and stop if a required quote is unavailable. When basket loss reaches the emergency threshold, the code attempts once to duplicate profitable tracked positions in their existing directions and volumes, then disables that attempt until the next entry window. Its instrument filter admits a position only if its instrument equals all four configured instruments simultaneously, so with distinct instruments no emergency trades are placed.
