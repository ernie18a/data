Evaluate once at the first tick of each new chart candle. Manage exits before considering a new entry; an exit does not prevent a new entry on the same candle.

For the optional equity stop, sum the open price profits of this strategy's market positions on the instrument. If the sum is negative and its absolute value exceeds the configured percentage of the account equity reference, close those positions. Update that reference only when the check reaches it: if there are no strategy positions, first set it to current equity; then set it to the previous recorded equity if the reference is below that previous equity, otherwise set it to current equity, and record current equity for the next call.

For the optional balance-based profit exit, scan open orders from the out-of-range position immediately after the last order down through position one, excluding position zero. Accumulate price profit for market positions on the instrument, irrespective of strategy. If the running sum reaches the configured percentage of account balance, close all market positions and delete all pending orders on the instrument.

For the optional money trailing exit, calculate instrument-wide market-position profit including commission and swap using the same scan that excludes position zero. If this total is negative, below the configured money target, and the strategy's price-profit loss exceeds the configured equity-risk percentage times the equity reference times the configured loss multiplier, scan those orders again, adding the absolute net profit of each market position. Close all instrument orders when that running sum reaches the configured money-loss amount. The equity reference is updated as described above whenever this loss test reaches it.

Entry also depends on account margin. Require sufficient history, a valid configured profit target, free margin above the configured base-lot margin threshold, fewer than the configured maximum strategy positions, sufficient post-trade margin under the account stop-out rules, valid stop and target distances, and trading permission. Size begins with the base lot multiplied by the configured exponent raised to the number of open strategy positions. If loss-based sizing is enabled and more than one losing historical order on this instrument occurs before the most recent profitable one, replace that size with the configured fraction of free margin; clamp and round to broker volume limits.

Use the chart timeframe and a designated higher timeframe: select the higher timeframe according to the chart timeframe. The third indicator timeframe is the chart timeframe because its timeframe selector remains zero. On the current chart candle, require the fast linear-weighted moving average of typical price to be below the slow one for either direction. For a long, require the low two candles ago below the previous candle's high, the last completed MACD main line strictly above its signal and nonzero on both the chart and designated higher timeframe, and the absolute distance from current bid to the close two candles ago above the configured point distance. For a short, require the previous candle's low below the high two candles ago, the same MACD main lines strictly below their signals and nonzero, and the absolute distance from current ask to the previous close above that distance. Attempt the long first and do not attempt the short on that candle if the long signal reaches its order attempt. Attach the configured price-based stop and profit target to each entry.
