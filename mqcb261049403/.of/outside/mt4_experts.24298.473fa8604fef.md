On the first tick of each new bar, apply these enabled exits in order:
1. For the balance-based profit target, scan open orders from position index equal to the order count down through index 1, excluding index 0. Accumulate profit from market positions in the traded instrument, regardless of strategy identifier. After each iteration, if the running profit reaches the configured percentage of account balance, close all market positions and delete all pending orders for the instrument.
2. For the equity-based risk stop, sum the profit of this strategy's market positions in the instrument. If the sum is negative, update the equity reference: if its stored value is below the previously recorded account equity, replace it with that previous equity; otherwise replace it with current account equity. Then record current account equity as the previous equity. If the absolute loss exceeds the configured percentage of the updated reference, close this strategy's market positions in the instrument. The equity reference and previous equity start at zero and are updated only when this negative-profit test is reached.
