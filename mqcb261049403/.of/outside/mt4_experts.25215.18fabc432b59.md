On each tick, if basket protection is enabled, sum profit, swap and commission for open market positions on the traded instrument with the base strategy identifier. If at least one exists, close those positions and stop processing the tick when the sum reaches a configured fraction of account balance, falls to a separate hard-loss fraction of balance, or falls to a configured loss fraction of balance while the position count is at least a configured minimum.

If the equity stop is enabled, sum price profit excluding swap and commission for the same positions. If it is negative and its magnitude exceeds a configured fraction of the equity reference, close those positions. Calculate the equity reference on each call as follows: when there are no matching market positions, first set it to current account equity; then, if it is below the previously observed equity, set it to that previous equity, otherwise set it to current equity. Store current equity as the previous equity.

If money trailing is enabled and matching positions exist, use the net profit including swap and commission of all market positions on the instrument. When this total is negative, below the configured profit threshold, and the matching positions' price-profit loss exceeds a configured fraction of the equity reference multiplied by a loss factor, scan instrument orders in descending position order, starting at the total order count and excluding position zero. Accumulate absolute net profit for market orders. If the absolute total net profit is no greater than the stored trailing reference, replace that reference with the absolute total. After each instrument order, close all instrument market positions and delete its pending orders if the accumulated amount reaches the absolute difference between the reference and the configured money-trailing distance. Reset the reference to zero when no matching market positions exist.
