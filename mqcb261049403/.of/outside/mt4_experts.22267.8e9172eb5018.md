Use account-level data to manage exits for the current instrument. On every tick, if basket protection is enabled and at least one strategy-owned market position exists, sum its positions' profit, swap and commission. Close all those positions when the sum reaches the configured profit percentage of account balance or falls to the negative configured loss percentage; then stop processing that tick. On each new bar, if equity protection is enabled and the strategy-owned positions' gross profit is negative and its absolute value exceeds the configured percentage of the equity reference, close those positions. When evaluated, the equity reference is the previous sampled account equity if it exceeds the stored reference; otherwise it is current account equity. Then store current equity as the previous sample. If money trailing is enabled, reset its stored profit reference when there are no strategy-owned market positions. Otherwise, sum profit, swap and commission for current-instrument market positions across all owners, iterating open-order indices from the order count down to 1, thus excluding index 0. When that sum is positive but below the configured money-profit threshold, update the stored reference to the greater of itself and the sum; during the same reverse iteration, close all current-instrument orders if the running net profit falls at least the configured money-stop amount below that reference. When the sum is negative and below the money-profit threshold, and the strategy-owned gross loss exceeds the configured equity-risk percentage of the equity reference multiplied by the loss factor, iterate the same orders, accumulating absolute net position profits. If the absolute total is no greater than the absolute stored reference, replace the reference with the absolute total. Close all current-instrument orders when the accumulated amount reaches the absolute difference between the reference and the configured money-stop amount.
