Use account-level balance, equity, and free margin in these decisions for the current instrument:
- If basket protection is enabled and there are strategy positions, close all of them when their combined floating profit, including swap and commission, reaches a configured fraction of account balance or falls to a configured negative fraction. Stop processing that tick.
- On each new bar, if the strategy's combined floating profit is negative and its absolute loss exceeds a configured fraction of account equity, close its positions. The equity reference is updated from current and previous account equity by comparing the stored reference with the previous value: use the previous value if it is greater, otherwise use current equity.
- If money trailing is enabled, the instrument's sampled net floating profit is negative and below the configured money-profit threshold, and the strategy's floating loss exceeds a configured fraction of the same equity reference multiplied by a loss factor, scan the instrument's orders and accumulate absolute net profit. Close all orders on the instrument when that running total reaches the absolute difference between the stored trailing-profit value and the configured money-stop amount. The scan updates the stored value to the absolute sampled loss when that loss is no greater than the absolute stored value.
- Block new entries when free margin is below the configured lot-based minimum or the proposed trade fails the account margin and stop-out checks. These checks filter the instrument's own price-based entry signals.
