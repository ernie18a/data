On each tick, use account-wide floating profit and balance, and optionally a configured server-time trading interval. When the interval is enabled, consider the time inside it as follows: if the start hour is before the end hour, include the start hour from its start minute, all intervening hours, and the end hour before its end minute; if the hours are equal, include minutes from the start minute up to but excluding the end minute; if the start hour is later, include hours at or after the start hour only when the current minute is at least the start minute, plus all hours before the end hour and the end hour before its end minute. When the interval is disabled, treat the time as outside it for the profit check, but do not exit merely because of time.

If no exit is already latched, floating profit is negative, and the time is inside the interval, take no action. Otherwise, if no exit is latched, latch one when either the absolute floating profit as a percentage of balance is at least the configured percentage threshold, or, in currency mode, the absolute floating profit exceeds the configured currency threshold. If an exit is latched or the enabled interval is outside its permitted time, close all open positions across all instruments. Keep a latched exit active and retry closing on subsequent ticks until no positions remain; then clear it. The strategy opens no positions.
