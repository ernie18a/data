Use account-level data for these optional exits, in order on each tick:
1. For the current instrument's market positions with the base strategy identifier, sum profit, swap and commission. Close that basket if its net profit reaches a target percentage of account balance, its loss reaches a hard percentage of balance, or its loss reaches a separate percentage of balance while at least a minimum number of positions are open. Stop processing the tick when triggered.
2. Maintain a shared money-trailing reference, reset to zero when no base-identifier market positions are open. Sum net profit across all market positions on the current instrument. When that sum is positive and below a profit ceiling, update the reference to the greater of itself and the total, then traverse the instrument's orders in reverse order, accumulating net market-position profit; close all its market positions and delete its pending orders if the running sum falls at least a specified amount below the reference. When the total is negative and below the ceiling, and the base-identifier positions' gross loss exceeds a specified fraction of the tracked account equity multiplied by a loss factor, traverse the instrument's orders from the last position down to position 1, excluding position 0. Accumulate absolute net market-position profits; reduce the reference to the absolute total loss when that loss is no greater than the absolute reference. Close all instrument orders if the running absolute sum reaches the absolute difference between the reference and the specified money amount.
3. If the base-identifier positions' gross loss exceeds a specified fraction of tracked account equity, close those positions. For each equity-tracker update, first set the tracked value to current equity if no base-identifier market positions exist; then replace it with previous equity if it is below previous equity, otherwise replace it with current equity. Save current equity as previous equity.
