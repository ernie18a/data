On each bar, calculate the stochastic main line minus its signal line for each of three configured instruments, using the same stochastic settings. Round each difference to the traded instrument's price precision plus two decimal places. For each instrument, mark up if its difference is positive and down if negative; zero initially has neither mark.

Apply these rules in order, retaining all existing marks: If the first and second are up, the third is down, and the second's absolute difference exceeds the third's, also mark the third up. If the first and third are up, the second is down, and the third's absolute difference exceeds the second's, also mark the second up. Apply the symmetric rules for down marks against an opposing up mark. Next, if the first and second are up and the third is not down, mark the third up; if the first and third are up and the second is not down, mark the second up. Apply the symmetric rules for down marks. Finally, if the second and third are up and the first is not down, mark the first up; if the second and third are down and the first is not up, mark the first down.

Signal long when all three have up marks and short when all three have down marks. Signal exit from a short whenever the first has an up mark, and exit from a long whenever it has a down mark. These are independent signals and can coexist.
