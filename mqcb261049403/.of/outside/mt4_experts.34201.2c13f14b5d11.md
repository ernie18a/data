When the scheduler is enabled, check the current weekday and minute using the selected local or server clock. Trading is permitted if the time falls within any configured range for that weekday, including its start and excluding its end; an end at midnight extends to the end of that day. Outside all ranges, if automated trading is enabled and the close-trades setting is on, attempt to close all open long and short positions and delete all pending orders across instruments, provided the terminal is connected and trading is allowed. Then disable automated trading even if closing fails. Inside a permitted range, enable automated trading if it is disabled.
