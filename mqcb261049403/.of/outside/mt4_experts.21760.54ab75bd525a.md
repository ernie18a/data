On the first tick of each new chart bar, apply these account-dependent rules in order. Profit sums use open positions on the traded instrument; equity-stop sums include only positions belonging to this strategy. The account-equity reference is updated when evaluated: reset it to current equity if the strategy has no open positions, then set it to the previous recorded equity if that is higher than the reference, otherwise to current equity; record current equity for the next evaluation.

If enabled, close all positions and delete pending orders on the instrument when accumulated instrument profit reaches a configured percentage of account balance. The accumulation iterates order positions from the order count down to one, omitting index zero, and tests the threshold after each addition.

If money trailing is enabled, strategy positions exist, and the instrument's net profit including commission and swap is negative but below the configured money-profit threshold, first require the strategy's gross floating loss to exceed a configured fraction of the account-equity reference multiplied by a loss factor. Then accumulate absolute net losses in the same order-index range. Maintain the stored trailing value as implemented: replace it with the absolute aggregate net profit when that absolute profit is no greater than the stored value. Close all instrument positions and delete its pending orders if the accumulating absolute loss reaches the absolute difference between the stored value and the configured money-stop amount. Reset the stored value when no strategy positions exist.

If the equity stop is enabled and the strategy's gross floating loss exceeds a configured fraction of the account-equity reference, close its positions on the instrument.

New entries also require sufficient account margin and the broker's stop-out, order-size, stop-distance and trading-permission checks. Evaluate entries only with sufficient chart history and fewer than the configured maximum strategy positions. Find the first upper or lower fractal while scanning a configured lookback from oldest to newest, checking the upper fractal first; use zero if none exists. Determine direction by scanning a configured candle range from oldest to current: return up at the first candle where ask minus its low reaches the configured box size, otherwise return down at the first candle where its high minus ask reaches that size. The box size may instead be the current ATR. Go long if bid differs from the close two bars ago by more than the configured distance, at least one of the closes two through four bars ago is at or below the fractal level, the last close is above it, direction is up, and the low two bars ago is below the last bar's high. Otherwise go short if the corresponding ask-to-close distance exceeds the threshold, at least one of those earlier closes is at or above the fractal level, the last close is below it, and direction is down. Long takes priority.

Set entry size to a base size multiplied by an exponent raised to the number of open strategy positions. If loss-based sizing is enabled and the instrument's history contains more than one losing trade since its most recent profitable trade, replace that size with a configured fraction of account free margin. Clamp and round the size to broker limits. Attach configured stop-loss and take-profit distances to each entry.
