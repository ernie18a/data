On each new bar of the base instrument, compare it with an indirect instrument on the same timeframe. Recalibrate periodically and, when flat, if the last calibration predates the previous daily bar. Over a training window, find each instrument's highest high and lowest low. Scale the indirect instrument's range to the base instrument's range, using a scale of one if the indirect range is zero, and align their lows. For negative correlation, reflect the scaled indirect price across the base range. Define divergence as the base close minus this adjusted indirect close, in base price points. Set the entry threshold to a configured fraction of the greatest absolute historical divergence over a configured search window.

Use the last completed bar's divergence. Close the positions if its sign has crossed to positive while the base-equivalent position is long, or to negative while it is short. Also close if absolute divergence is below a configured fraction of the entry threshold and combined position profit including commission is positive, or if that profit exceeds a configured percentage of account balance. In cross-instrument mode, reverse the base-equivalent direction for an inverse cross. Evaluate exits before entries, so a new entry can follow an exit on the same bar.

Enter only when absolute divergence is at least the threshold and is no greater than on the preceding completed bar. Positive divergence signals a short base position; negative divergence signals a long base position. Trade the indirect instrument in the opposite direction for positive correlation and the same direction for negative correlation. Alternatively trade a direct cross in the base direction, or an inverse cross in the opposite direction. Outside testing, after the code's configured date condition, replace the entry direction with the parity of the final digit of the current base bid: even means long and odd means short.

Set the target number of entries to the rounded ratio of absolute divergence to threshold, capped at the configured maximum. For an existing position, target volume equals that number times existing volume divided by its entry count; otherwise use that number times the configured initial volume. Enter only if target volume exceeds existing volume. In two-instrument mode, submit an entry for each leg only if that leg has no existing volume; size the indirect leg using the range scale and the ratio of base to indirect tick values. In cross mode, submit the incremental target volume. Initial volume may be fixed or based on equity and one-lot buy margin, with broker volume limits and steps applied.
