On the first tick of each new bar, apply these optional account-dependent exits:
- Close the strategy's positions in the traded instrument when their combined floating profit is negative and its absolute value exceeds a configured percentage of the account-equity reference. Update that reference to the previous account equity if the stored reference exceeds the previous equity; otherwise update it to current equity. Reset it to current equity when there are no strategy positions.
- If the profit target as a percentage of account balance is enabled, close all positions and delete all pending orders in the instrument when the running sum of their floating profits reaches that percentage of account balance. The scan starts beyond the last order and excludes the order at position zero; test the running sum after each iteration.
- If money trailing is enabled and the instrument's summed net floating profit is negative and below its configured profit ceiling, check whether the strategy's floating loss exceeds the equity-based risk threshold multiplied by a configured loss factor. If so, scan the instrument's orders, excluding position zero, accumulating the absolute net profit of each market order. Update the stored trailing value to the absolute summed net profit when that value is no greater than the stored value. Close all instrument positions and delete its pending orders when the accumulated amount reaches the absolute difference between the stored value and the configured money-loss distance.
