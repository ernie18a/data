On each timer event, use the current server hour to determine whether it is within the configured trading window, including windows that cross midnight; equal start and end hours define an empty window. During the window, if trading is permitted, funds and volume are valid, there are no pending orders anywhere in the account, and the current instrument has no open position, place a buy stop above the ask and a sell stop below the bid by a configured distance, each with a configured stop loss. Leave the opposite order in place when one triggers. Outside the window, close all positions and delete all pending orders bearing the configured identifier, across all instruments.
