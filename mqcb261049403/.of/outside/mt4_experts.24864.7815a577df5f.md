On the first tick of each new bar, optionally apply these account-based exits:
- If the combined floating profit of this strategy's positions in the traded instrument is negative and its absolute value exceeds a configured percentage of the account equity reference, close all of those positions. Update the reference when evaluated: reset it to current equity if there are no strategy positions, then use previous equity if the reference is below previous equity; otherwise use current equity. Store current equity as previous equity.
- If percentage take profit is enabled and nonzero, scan open orders from the highest position index down to index one, accumulating floating profit for market positions in the instrument. As soon as the running sum reaches the configured percentage of account balance, close all market positions and delete pending orders in the instrument, regardless of strategy identifier.
- If money trailing is enabled, total the instrument's market-position profit including commission and swap, scanning the same indices. When that total is negative and the strategy's floating loss exceeds the configured equity-risk threshold multiplied by a configured loss factor, scan those orders again, accumulating the absolute net profit of each market position. Once that running sum reaches the configured money-loss amount, close all market positions and delete pending orders in the instrument. The equity reference is updated as described above when this threshold is evaluated.
