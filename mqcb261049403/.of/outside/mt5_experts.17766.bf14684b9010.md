On each tick, first check account-wide equity against balance. If the enabled profit or loss percentage threshold is reached, close all positions managed by this strategy and take no further action on that tick. Otherwise, if the enabled daily closing-time window is active, close all managed positions and take no further action. Otherwise, during the daily opening-time window, open the configured long or short position for each enabled instrument that has no managed position in that same direction. Use the configured size for each instrument. Both time windows start at their configured time and last for the configured duration.
