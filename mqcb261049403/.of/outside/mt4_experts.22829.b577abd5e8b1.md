On the first tick of each new bar, apply these account-dependent rules:

- If enabled, close all orders for the instrument when the summed open profit reaches a configured percentage of account balance. The summation scans open-order positions from the order count down to position one, omitting position zero, and checks the threshold after each selected order.
- If enabled, close this strategy's positions in the instrument when their combined open profit is negative and its absolute value exceeds a configured percentage of the equity reference. Each time the reference is requested, set it to current equity if there are no strategy positions; then set it to previous equity if the reference is below previous equity, otherwise set it to current equity. Finally store current equity as previous equity.
- If money trailing is enabled, the instrument's net open profit, including commission and swap, is negative and below the configured money target, and the strategy's open loss exceeds the configured equity-risk percentage multiplied by a loss factor, scan the same order positions. Accumulate absolute net profit per instrument position; update the stored trailing value to the absolute total net profit whenever that value is no greater than the absolute stored value. Close all instrument orders if the accumulated amount reaches the absolute difference between the stored value and the configured money stop. Reset the stored value when the strategy has no positions. In the positive-profit trailing branch, update that value to the maximum observed total net profit and close all instrument orders if the running net-profit sum falls by the configured money stop from that value.
- Entry requires sufficient free margin relative to the base trade size, enough post-trade margin to satisfy the account's stop-out rules, valid broker stops, trading permission, sufficient history, a valid configured profit target and fewer than the maximum strategy positions. Size starts at the base size multiplied by a configured exponent raised to the number of strategy positions. If loss-based sizing is enabled and more than one losing historical trade in the instrument appears before the most recent winning trade, replace that size with a configured fraction of free margin; clamp and round it to broker volume limits.
- Subject to those gates, buy when the stochastic main line crosses upward through its lower threshold between the two preceding bars, current parabolic SAR is below the previous bar's open, the current fast linear-weighted typical-price average exceeds the slow one, the low two bars ago is below the previous high, and the absolute distance from bid to the close two bars ago exceeds a configured point distance. Sell when stochastic crosses downward through its upper threshold, SAR is above the previous open, the fast average is below the slow one, the previous low is below the high two bars ago, and the absolute distance from ask to the previous close exceeds that distance. A qualifying buy takes precedence over a sell.
