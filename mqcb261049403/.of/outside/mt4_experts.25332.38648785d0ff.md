On each new bar, apply the enabled account-based exits. For the percentage profit target, scan open orders from the highest position index down to index one, accumulating floating profit from market positions on the traded symbol regardless of strategy identifier. If the running sum reaches the configured percentage of account balance, close all market positions and delete all pending orders on that symbol. For the equity stop, sum floating profit on the symbol’s market positions with the strategy identifier; if it is negative and its absolute value exceeds the configured percentage of the equity reference, close those positions. Update the equity reference when evaluated: if there are no matching market positions, set it to current account equity; then set it to previous equity if the reference is below previous equity, otherwise set it to current equity, and save current equity as previous equity. For the enabled money-trailing loss exit, if the scanned symbol-wide net profit including commission and swap is negative, and the matching strategy positions’ floating loss exceeds the configured equity-risk percentage times the equity reference and loss multiplier, scan the same order indexes again, accumulating absolute net profit for symbol market positions; close all symbol orders when that accumulation reaches the configured money-loss threshold. The equity reference is updated whenever this loss test or the equity stop evaluates it.
