On every tick, if basket protection is enabled, sum profit, swap, and commission for this instrument’s open positions belonging to the strategy. If at least one exists, close all of them when the sum reaches the configured percentage of account balance in profit, reaches the hard loss percentage of account balance, or reaches the configured loss percentage of account balance with at least the configured minimum number of positions. Stop processing that tick after a close is triggered.

On each new bar, if the equity stop is enabled, sum the open positions’ profit excluding swap and commission for this instrument and strategy. If it is negative and its absolute value exceeds the configured risk percentage of the account equity reference, close those positions. Update the reference when queried: if there are no strategy positions, set it to current account equity; then set it to the previous observed equity if the reference is below that previous equity, otherwise set it to current equity. Save current equity as the previous observed equity.

If money trailing is enabled and strategy positions exist, also evaluate its loss branch on every tick. When the net profit including swap and commission of all this instrument’s positions is negative and below the configured money-profit threshold, and the strategy positions’ profit excluding costs is negative with its magnitude exceeding the equity reference times the configured risk percentage and loss multiplier, scan this instrument’s orders from the total-order count down to index one. Accumulate the absolute net profit of each market position. For each selected order on the instrument, replace the shared trailing reference with the absolute net total if that total is no greater than the reference; if the accumulated absolute profit is at least the absolute difference between that reference and the configured money stop, close all positions and delete pending orders on the instrument. Reset the shared trailing reference to zero when no strategy positions exist; it is also updated by the money-trailing profit branch.
