Evaluate once at the first tick of each new chart bar. Versions 1–3 use all cross rates among EUR, GBP, AUD, NZD, USD, CAD, CHF and JPY on the chart timeframe to calculate currency strengths:
- Version 1: for each pair, calculate the percentage difference between the previous bar's open and close, using the close as denominator. Add this value to the base currency's strength and subtract it from the quote currency's strength.
- Version 2: use the percentage change from the close a configurable number of bars before the previous bar to the previous close, and aggregate with the same signs.
- Version 3: use the previous bar's close-based RSI for each pair. For each currency, average its seven pair contributions: the RSI when it is the base, and 100 minus the RSI when it is the quote.

A currency's stored classification becomes strongest when its strength is strictly greater than every other strength, or weakest when strictly lower than every other strength. Otherwise retain its previous classification, including on ties. Initially classifications are empty.

Maintain separate persistent long and short signal flags, initially false. For each supported pair, when its base is classified strongest and its quote weakest, set its long flag to whether the chart symbol contains that pair's name. When the classifications are reversed, similarly update its short flag. Leave each flag unchanged when its corresponding classification condition is false. Supported pairs are EURJPY, EURGBP, EURAUD, EURNZD, EURUSD, EURCAD, EURCHF, GBPAUD, GBPNZD, GBPUSD, GBPCAD, GBPCHF, GBPJPY, AUDNZD, AUDCAD, AUDCHF, AUDJPY, USDCHF, USDCAD and USDJPY. GBPAUD and GBPNZD share one flag per direction and are updated in that order. Additionally, AUD strongest and USD weakest updates a long flag by testing for GBPUSD; the reverse updates a short flag using the same symbol test. For the AUDJPY short flag, test AUD weakest and USD strongest instead of JPY strongest.

Subject to the configured position limit, available margin, trading permission and valid broker order levels, enter long when any long flag is set, the current fast linear-weighted moving average of typical price exceeds the slow one, the low two bars ago is below the previous high, and the absolute distance from bid to the reference close exceeds a configured point threshold. Enter short when any short flag is set, the fast average is below the slow one, the previous low is below the high two bars ago, and the absolute distance from ask to the reference close exceeds that threshold. The long reference is the previous close in versions 1 and 3 and the close two bars ago in version 2; the short reference is the close two bars ago in version 3 and the previous close in versions 1 and 2. Require sufficient chart history and a valid configured take-profit distance. Evaluate long first and stop evaluating entries for that bar if its signal conditions are met, even if its order cannot be placed.

Version 4 returns before its currency-strength and entry logic on every bar, so it makes no cross-instrument entry decisions.
