On each new chart bar, first apply enabled account-based exits, then consider entries. For the equity stop, sum the open price profits of this strategy's positions in the traded instrument. If the sum is negative and its magnitude exceeds a configured fraction of account equity, close those positions. The equity reference is updated when this check is reached: reset it to current equity if there are no strategy positions; then use previous equity if it exceeds the reference, otherwise use current equity, and store current equity as previous equity. If the percentage profit target is enabled, scan open orders in reverse position order, skipping position zero, and accumulate price profit for market positions in the traded instrument. Whenever the running sum reaches the configured percentage of account balance, close all market positions and delete all pending orders for that instrument, regardless of strategy. If money trailing is enabled and there are strategy positions, a negative instrument profit including commission and swap can trigger an exit when the strategy's price-profit loss exceeds a configured fraction of the equity reference times a configured multiplier: scan the same orders, accumulating absolute individual net profits, and close all instrument orders when that running sum reaches the absolute difference between the stored trailing value and the configured money stop. Update the stored trailing value to the absolute aggregate net loss only when that loss is no greater than the stored value. For entries, require sufficient account free margin, sufficient margin after the proposed order, and compliance with the broker's stop-out rules, as well as the configured position limit and valid protective stops. Find the first qualifying higher-timeframe typical-price linear weighted moving average in ascending period order: a bullish bounce has that average above a longer average, with the last closed candle opening above it and touching it with its low; a bearish bounce is the converse using the high. Go long on a bullish bounce when the chart-timeframe fast average exceeds the slow average, the earlier closed candle's low is below the later candle's high, and bid is sufficiently far from the earlier close. Go short on a bearish bounce when the fast average is below the slow average, the later closed candle's low is below the earlier candle's high, and ask is sufficiently far from the later close. The long condition takes priority. Position size normally increases geometrically with the number of strategy positions; after more than one consecutive losing historical trade in the instrument, if the increase feature is enabled, instead size from account free margin. Conform size to broker volume limits and increments.
