On each tick, if trading is enabled, first close all strategy-tagged positions on the current instrument during the configured daily closing window, if timed closing is enabled. Then, if trailing is enabled, trail each tagged current-instrument position only after its profit exceeds the configured distance: move its stop to that distance behind the current bid for a long or ask for a short when the existing stop is sufficiently farther away. During the configured daily opening window, open a long and/or short according to the enabled directions, independently skipping a direction if any strategy-tagged position in that direction exists on any instrument. Set optional fixed stop-loss and take-profit levels relative to the entry-side quote. The opening and closing windows may overlap, in which case closing is processed before opening on every tick.
