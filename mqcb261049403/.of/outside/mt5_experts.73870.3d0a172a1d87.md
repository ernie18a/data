At each configured daily reset, record the account balance or equity as the reference and release any existing lock. Calculate the loss as the greater of zero and the reference minus current account equity. Set the loss limit either to a fixed amount or to a fraction of the reference, and set the trigger to a fraction of that limit. When the unlocked account's loss reaches or exceeds the trigger, close every open position, cancel all pending orders, and lock the account. While locked, repeatedly flatten the account if flat enforcement is enabled; otherwise, retry closing for a limited period after the lock. A confirmed manual close-all command also closes positions and cancels pending orders. A confirmed manual lock does the same and engages the lock. After a confirmed manual unlock, suppress the automatic trigger until loss falls below a specified fraction of the trigger; check for a new trigger on subsequent events. Preserve the reference and lock across restarts within the same reset period.
