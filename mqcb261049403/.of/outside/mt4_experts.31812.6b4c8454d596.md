When enabled, initialize an equity target from account balance plus a configured percentage of that balance. Whenever account equity strictly exceeds the target, close every open long and short position and delete all pending orders, then recalculate the target from the current balance.

When enabled, for each open position whose profit plus commission and swap strictly exceeds the greater of a fixed minimum amount and a configured percentage of account balance, adjust its stop loss as follows. For a long, if there is no stop or the stop is below the bid minus the configured trailing distance, additional adjustment distance, and chart instrument spread, set it to the bid minus the trailing distance and chart instrument spread. For a short, if there is no stop or the stop is above the ask plus those three distances, set it to the ask plus the trailing distance and chart instrument spread. Convert point distances using the position instrument's point size and round prices to its precision. The resulting stop can exit the position.
