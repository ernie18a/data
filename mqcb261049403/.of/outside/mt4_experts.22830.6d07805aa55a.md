On the first tick of each new bar, apply these optional account-dependent exits:
- Close all market positions and delete pending orders for the traded instrument when their accumulated floating profit reaches a configured percentage of account balance. Accumulate in descending order-position order, starting at the total order count and stopping at position one; check the threshold after each iteration.
- Close this strategy's positions on the traded instrument when their combined floating loss exceeds a configured percentage of an equity reference. When no such positions exist, set the reference to current equity; then, if the reference is below the previous recorded equity, replace it with that previous equity, otherwise replace it with current equity. Record current equity for the next evaluation.
- The optional money trailing rule also uses the same equity reference: when total net profit for the instrument is negative and below its configured profit ceiling, and the strategy's floating loss exceeds the configured equity-risk percentage multiplied by a loss factor, scan orders in the same descending position range. Accumulate absolute net profits, update the stored trailing reference to the absolute total net profit if that is no greater than the absolute stored reference, and close all positions and delete pending orders for the instrument if the accumulated absolute net profit reaches the absolute difference between that reference and the configured money-stop amount. Reset the trailing reference when the strategy has no positions.
