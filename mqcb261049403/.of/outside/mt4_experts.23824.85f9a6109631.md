On each new chart bar, apply enabled account-based exits before considering new entries. For the percentage profit target, scan open orders from the highest position index down to index 1, accumulating gross profit of market positions in the traded instrument, regardless of strategy identifier. After each scan step, if the running sum reaches the configured percentage of account balance, close all market positions and delete all pending orders for that instrument, regardless of identifier. For the equity stop, if the combined gross profit of this strategy's market positions in the instrument is negative and its absolute value exceeds the configured percentage of the equity reference, close those positions. Update the equity reference whenever it is requested: if there are no such positions, first set it to current account equity; then, if the reference is below the previously recorded equity, set it to that previous equity, otherwise set it to current equity; finally record current equity as previous equity. The optional monetary trailing exit also uses this reference: reset its stored profit marker when there are no strategy positions. Otherwise sum instrument-wide market-position profit including commission and swap, scanning order indices from the total down to 1. When that sum is positive and below the configured profit threshold, scan the same orders, updating the marker to the maximum of itself and the total, and close all instrument orders if the running net-profit sum falls at least the configured monetary distance below the marker. When the total is negative and below the profit threshold, and the strategy positions' gross loss exceeds the configured equity-risk percentage times the equity reference times the loss multiplier, scan the same orders while accumulating absolute net profits; replace the marker with the absolute total if that is no greater than the marker, and close all instrument orders if the running absolute sum reaches the absolute difference between the marker and the configured monetary distance.
