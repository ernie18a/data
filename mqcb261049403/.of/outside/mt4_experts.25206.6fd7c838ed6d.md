Use account-wide balance and equity to manage positions in the traded instrument. When enabled, first calculate net profit including swap and commission for open positions with the base strategy identifier. If any exist, close those positions and stop processing the tick when profit reaches a configured percentage of account balance, loss reaches a hard-stop percentage of balance, or loss reaches a separate percentage of balance while the position count meets a minimum. When enabled, close those same positions if their combined profit excluding swap and commission is negative and its absolute value exceeds a configured percentage of the tracked account equity. Update tracked equity when evaluated: if there are no matching positions, set it to current equity; then set it to the preceding observed equity if the tracked value is lower than that preceding value, otherwise set it to current equity; finally record current equity as the preceding value. When money trailing is enabled, a negative net profit for all market positions in the instrument can also trigger closure of all its orders if the matching positions' loss exceeds a configured multiple of the equity-based risk limit. In that case, traverse orders in reverse position order, excluding position zero, accumulating absolute net profits of the instrument's market positions; update the stored trailing value to the absolute total net loss only when that loss is no greater than the stored value. After each instrument order, close all its market and pending orders if the accumulated amount reaches the absolute difference between the stored trailing value and the configured money distance. Reset the trailing value when no matching market positions exist.
