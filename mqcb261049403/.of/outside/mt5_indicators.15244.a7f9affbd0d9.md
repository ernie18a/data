Use a volatility-scaled trailing reversal threshold. Set its distance from the rolling average of each bar’s high–low range, adjusted using the decimal-digit precision difference between EURUSD and the traded instrument. In an uptrend, track the highest high and place the threshold below it; reverse to short when the current high falls below the threshold, then reset the extreme and place the threshold above the current high. In a downtrend, track the lowest low and place the threshold above it; reverse to long when the current low rises above the threshold, then reset the extreme and place the threshold below the current low. Emit a signal only when the trend reverses.
