When enabled, manage filtered positions on the current instrument as a group. At the configured adjustment interval, sum their floating profits and net long volume; optionally include swaps and entry commissions. Apply the selected bid/ask spread adjustment to hedged positions as they are encountered. Proceed only if net volume and the instrument's loss point value are nonzero, total profit meets the trigger and exceeds both zero and the desired additional profit. For instruments whose loss point value requires currency conversion, obtain it from contract size and tick size, converting profit currency to account currency using the ask of a matching direct forex pair or the reciprocal bid of an inverse pair; use one if no pair exists and negative one if either quote is zero. Other supported calculation modes use the instrument's loss tick value. Divide the resulting unit cost by the instrument's point size. Set the group target to bid minus (total profit minus desired additional profit) divided by the absolute product of net volume and loss point value for net longs; use ask plus that distance for net shorts. If the target is positive, adjust it by the spread for positions opposite the selected bid/ask convention when the group contains the other direction, and round it to the nearest tick. For each long, set this target as stop loss if it is below bid by more than the minimum stop distance, or as take profit if it is above ask by more than that distance. For each short, set it as stop loss if above ask by more than the minimum stop distance, or as take profit if below bid by more than that distance. Modify only when the selected level differs from its existing value by more than half a point, preserving the other level.
