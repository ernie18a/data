Use server time to enforce an optional trading window. When enabled, close all positions in the traded instrument outside the window and allow new entries only inside it. For a start hour earlier than the end hour, allow the start hour from the start minute, all intervening hours, and the end hour before the end minute. For equal hours, allow minutes from the start minute up to but excluding the end minute. For an overnight window, allow hours at or after the start hour only when the current minute is at least the start minute, plus all hours before the end hour and the end hour before the end minute.

On the traded instrument and selected timeframe, calculate bull power as high minus the exponential moving average of close, and bear power as low minus that average. Over a configurable lookback, count bars with positive bull power and bars with negative bear power. For each count, calculate its integer percentage of the lookback, subtract half the percentage scale, double, and clamp to the percentage scale. Compare these two values on the selected signal bar and its preceding bar. If the bull value crosses above the bear value, open a long if enabled; if it crosses below, open a short if enabled. Whenever the bull value is above the bear value, close a short if enabled; whenever below, close a long if enabled. Equality produces no signal. Evaluate each tick when the selected signal bar is the current bar; otherwise evaluate at each new bar. Close positions before opening, and open only if no position in the instrument remains. Apply configured stop loss and take profit to entries.
