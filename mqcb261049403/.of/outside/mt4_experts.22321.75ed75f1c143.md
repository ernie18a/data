On each new chart bar, optionally close all positions and delete pending orders for the traded instrument when the accumulated gross profit of its market positions reaches a configured percentage of account balance. The accumulation scans orders backward starting one index beyond the last order and stops before index zero, checking the threshold after each selected order. Optionally apply a money trailing rule: when the instrument's aggregate net profit is negative and the strategy's gross profit on that instrument is negative by more than a configured fraction of an account-equity reference, scan the same order indices backward, accumulating the absolute net profit of each market position. Close all positions and delete pending orders for the instrument when this accumulated amount reaches the absolute difference between the stored trailing reference and a configured money distance. Update the stored trailing reference to the absolute aggregate net loss only when that loss is no greater than the current reference. The equity reference is the previous observed equity if it exceeds the stored reference; otherwise it is current equity. Reset the trailing reference when no strategy positions are open.
