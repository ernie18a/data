On each tick, if basket protection is enabled, sum the traded instrument's open strategy positions' profit, swap, and commission. Close those positions and stop processing the tick if the sum reaches a configured percentage of account balance, falls to a separate hard-loss percentage of balance, or falls to a configured loss percentage of balance while at least a configured number of positions are open.

If money trailing is enabled and there is at least one open strategy position, calculate net profit across all market positions on the instrument. When that total is negative and the strategy positions' gross loss exceeds a configured percentage of the equity reference multiplied by a loss factor, scan the instrument's orders in descending order, skipping position index zero. Accumulate the absolute net profit of each market position; after each matching instrument order, reduce the stored trailing reference to the absolute total net profit if that is no greater than the reference. Close all instrument orders if the accumulated amount reaches the absolute difference between the reference and the configured money stop.

On each new bar, if the equity stop is enabled and the strategy positions' gross loss exceeds a configured percentage of the equity reference, close those positions. Each time the equity reference is requested, reset it to current account equity if no strategy positions are open; then, if the reference is below the previously observed equity, set it to that previous equity, otherwise set it to current equity. Record current equity as the previous equity.
