For the current instrument, manage market orders with the base strategy identifier using account-wide balance and equity:

- If basket protection is enabled, close those orders when their combined profit, swap and commission reaches a configured percentage of account balance, falls to an emergency loss percentage of balance, or falls to a configured loss percentage of balance while at least a configured number of orders are open. Skip the remaining tick processing when any of these conditions triggers.
- If the equity stop is enabled, close those orders when their combined profit excluding swap and commission is negative and its absolute value exceeds a configured percentage of the equity reference. Update that reference whenever it is queried: reset it to current equity if no such orders exist; then set it to the previous queried equity if the stored reference is below that previous equity, otherwise set it to current equity. Store current equity as the previous queried equity.
- If money trailing is enabled and the current-instrument net profit is negative and below its configured ceiling, activate its loss branch when the base-identifier orders' loss excluding swap and commission exceeds a configured multiple of the equity-stop threshold. Iterate current-instrument orders in reverse order, skipping position zero; accumulate the absolute net profit of market orders. If the absolute total current-instrument net profit is no greater than the absolute stored trailing reference, replace that reference with the absolute total. Close all current-instrument market orders and delete its pending orders when the running sum reaches the absolute difference between that reference and the configured money stop. The same reference is updated to the maximum total net profit in the positive-profit trailing branch and reset when no base-identifier market orders remain.
