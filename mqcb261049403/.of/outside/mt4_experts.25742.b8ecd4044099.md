On each new chart bar, apply the enabled account-based exits before considering new entries. For the percentage profit target, sum floating price profit for the traded symbol's market orders, scanning order positions from the total count down to position 1. After each addition, if the running sum reaches the configured percentage of account balance, close all market orders and delete all pending orders for the symbol, regardless of strategy identifier.

For the equity stop, sum floating price profit for the symbol's market orders with the strategy identifier. Maintain an equity reference each time it is requested: if there are no such market orders, first set the reference to current account equity; then set it to the previous sampled equity if the reference is below that previous value, otherwise set it to current equity. Save current equity as the previous sampled equity. If the strategy's summed profit is negative and its absolute value exceeds the configured percentage of this reference, close its market orders for the symbol.

For the enabled money trailing exit, reset the stored profit reference when there are no strategy market orders. Otherwise sum symbol market-order profit including commission and swap, scanning positions from the total count down to position 1. When that sum is negative and below the configured profit threshold, and the strategy's price-profit loss exceeds the configured equity-risk percentage times the equity reference and loss multiplier, scan those positions again. Accumulate the absolute net profit of each symbol market order; whenever the absolute total net profit is no greater than the absolute stored profit reference, replace that reference with the absolute total net profit. If the running accumulation reaches the absolute difference between the stored reference and the configured money stop, close all market orders and delete all pending orders for the symbol.
