Refresh the economic calendar daily and adjust event times by the configured time-zone offset. On each tick, select the first calendar event whose day of month matches the local day, whose time is in the configured lead window, whose currency matches a three-character component of the traded symbol, and whose importance is enabled. The medium-importance setting enables both high and medium events; the high-importance setting enables low events. Compare the selected event description with the description selected on the preceding tick, then replace the stored description with the current selection, including an empty selection when no event qualifies.

For a newly selected event, if both local time and broker time are strictly inside the lead window before its scheduled time, place a buy stop and a sell stop if there are no matching orders. If only one pending stop exists, place the other. Calculate the buy entry as the highest high of the current and configured number of preceding one-minute candles, plus the current spread and a configured offset. Calculate the sell entry as the corresponding lowest low minus the offset. Set the buy stop-loss to the current bid plus the offset minus the configured stop distance; set the sell stop-loss to the current ask minus the offset plus the stop distance. Set each take-profit the configured profit distance beyond its entry. The pending orders become long or short positions when their respective prices are reached.

While the same description remains selected and broker time is within the lead window but before the configured modification cutoff, recalculate and update pending entries and their associated stops and targets whenever an entry changes. After the scheduled time, while the same description remains selected, optionally cancel the opposite pending stop if exactly one position and its opposite pending stop exist. After the configured post-event waiting period, cancel remaining pending stops in the recognized combinations of pending orders and positions.

For matching open positions, independently apply optional break-even and trailing stops on each tick: after profit exceeds the respective configured threshold, move an eligible stop just beyond entry for break-even, or trail it at the configured distance from the current bid for a long or ask for a short, only when the stop improves. Positions also exit at their stop-loss or take-profit. Match orders by traded symbol and an identifier recomputed on each tick as the sum of the local day of month, hour, and minute; only orders with the current identifier participate in management.
