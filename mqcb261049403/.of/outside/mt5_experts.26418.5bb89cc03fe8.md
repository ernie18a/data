When there are no open trades or pending orders, open a market trade in the configured starting direction. While trades are open and no grid order is pending, place a limit order in the same direction as the most recently opened trade, one grid interval beyond its opening price against the position. Size each successive order by multiplying the previous order’s size by the configured lot multiplier. Set the take-profit for all open trades to the volume-weighted average entry price plus a target distance for long positions, or minus it for short positions. When the positions close, remove any remaining pending grid order; once the cycle is fully clear, start a new cycle in the opposite direction from the last closed trade.
