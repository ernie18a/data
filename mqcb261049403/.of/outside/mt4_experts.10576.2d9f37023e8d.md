Both versions inspect all account orders without filtering by instrument. When there are no orders anywhere, open a position on the chart instrument: in trend mode, buy if its current price is above the previous bar's moving average and sell if below; alternatively, a configured mode forces either direction. The first version uses a linear weighted average on a configured timeframe; the second uses an exponential average on the chart timeframe. Do nothing at equality.

When the account has an eligible number of orders below the configured maximum, inspect the last order in the account list. If it is a market position and its adverse movement reaches the configured distance, open another position on the chart instrument in that order's direction, using the size multiplier for that level. The first version implements two additional levels; the second implements four. Then, among the first orders in the account list up to the scan limit, if any market position has reached the configured favorable distance, close all market positions and delete all stop orders of that direction across the account. Entry and add-on attempts return before this profit check.

In the second version, before entry, if moving-average reversal is enabled and any account order exists, compare the previous chart-bar close with its exponential average: below it, close all buys and buy stops across the account and set the mode to forced sell; above it, close all sells and sell stops and set the mode to forced buy. If the account becomes empty, the new forced direction can be entered immediately. Also, when the optional stop is enabled and the account order count equals the configured maximum minus one, inspect the last order; if its adverse movement reaches the stop distance, close all positions and stop orders of its direction across the account and return.

After these checks, user controls can close all market positions and delete buy and sell stops, close market positions whose profit plus swap exceeds a configured amount, or delete buy and sell stops. These controls apply account-wide and are reached only if an earlier branch has not returned.
