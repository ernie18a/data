On each new bar, optionally close all orders for the traded instrument when the running sum of its open market-order profits reaches a configured percentage of account balance. The sum scans order positions from the total count down to position 1, omitting position 0, and is checked after each selection.

Optionally close this strategy's market positions on the instrument when their combined profit is negative and its absolute value exceeds a configured percentage of account equity. The equity reference is updated when this comparison is evaluated: reset it to current equity if there are no strategy positions, then replace it with the previous recorded equity if that is greater than the reference; otherwise replace it with current equity. Finally record current equity as previous equity.

If money trailing is enabled and the instrument's scanned net profit, including commission and swap, is negative, check whether the strategy's combined loss exceeds the equity-based threshold multiplied by a configured loss factor. If so, scan the same order positions and accumulate the absolute net profits of the instrument's market orders; close all orders for the instrument as soon as that accumulation reaches the configured money-loss amount. These scans also omit position 0.
