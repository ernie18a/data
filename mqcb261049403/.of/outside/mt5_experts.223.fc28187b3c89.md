When the user enables account-wide closing and at least one position exists, evaluate the selected measure on each tick. The calculation repeatedly reads the currently selected position once for every open position plus one; it does not select each position in the loop. Sum its floating profit for the currency measure, or divide that sum by account balance and express it as a percentage, rounded to two decimal places. For the points measure, sum rounded ask minus rounded entry price for a long position, or rounded entry price minus rounded ask for a short position, with each price expressed in that position's point units. If the selected measure reaches or exceeds the enabled upper threshold, or reaches or falls below the enabled lower threshold, close all positions across all instruments, delete all pending orders, and disable account-wide closing. A zero threshold disables that bound. If no measure is selected, the measure remains zero.
