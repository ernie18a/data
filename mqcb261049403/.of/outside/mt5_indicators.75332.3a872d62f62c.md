For each scanned instrument, identify a higher-timeframe bullish zone when a bearish candle is followed by a bullish candle that closes above the bearish candle’s high, with the next candle’s low above that high; define the zone as the bearish candle’s high-to-low range. Identify a bearish zone symmetrically: a bullish candle is followed by a bearish candle closing below the bullish candle’s low, and the next candle’s high is below that low; use the bullish candle’s range as the zone. Consider only the most recently found qualifying zone, and signal only while the instrument’s current bid is inside it. If enabled, reject a bullish setup when the previous daily candle was bearish, and reject a bearish setup when it was bullish. If enabled, require the current time to fall within either configured trading session. For a bullish zone, signal long when the previous lower-timeframe candle closes above the latest detected swing high and its tick volume exceeds the mean plus the configured multiple of the standard deviation of recent lower-timeframe tick volumes. For a bearish zone, signal short when that candle closes below the latest detected swing low with the same volume condition. Otherwise wait; the logic specifies no exit signal.
