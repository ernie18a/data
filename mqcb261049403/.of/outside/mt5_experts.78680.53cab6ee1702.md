Track a trading day using a configurable reset hour in server time. Maintain a day-start balance and a persistent lock state. When no saved balance exists for the current day, reconstruct it as current account balance minus the profit, swap, commission, and fees of all buy and sell deals since the day began. At each new day, set the reference balance to the current account balance and clear an expired lock. If the reference balance minus current account equity reaches the configured loss limit, lock until the next trading-day boundary. While locked, repeatedly close every open position across all instruments, optionally restricted to a configured position identifier. A manual unlock clears the lock and resets the reference balance to current equity. The system does not initiate trades.
