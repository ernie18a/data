Calculation: Step line = For each bar, let W be Williams %R plus 100 and let step be a parameter. Initialize the previous lower band to a large positive value, the previous upper band to a large negative value, and trend to zero. Set the current upper band to W + 2 × step and the current lower band to W − 2 × step. If W is greater than the previous upper band, set trend to positive; if W is less than the previous lower band, set trend to negative; otherwise retain the previous trend. If trend is positive, replace the current lower band with the maximum of the current and previous lower bands, and set the step line to the current lower band plus step. If trend is negative, replace the current upper band with the minimum of the current and previous upper bands, and set the step line to the current upper band minus step. Carry both current bands and the trend forward to the next bar. Calculate a fast step line and a slow step line using the same Williams %R and a smaller step for the fast line.
