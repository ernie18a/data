Calculation: MACD line = EMA of an applied price derived from OHLC with a shorter lookback minus EMA of the same price with a longer lookback.
Calculation: MACD signal line = simple moving average of the MACD line.
Long: MACD line > MACD signal line.
Short: MACD line < MACD signal line.
Long: Higher-timeframe MACD line > higher-timeframe MACD signal line, using the higher-timeframe bar still forming.
Short: Higher-timeframe MACD line < higher-timeframe MACD signal line, using the higher-timeframe bar still forming.
