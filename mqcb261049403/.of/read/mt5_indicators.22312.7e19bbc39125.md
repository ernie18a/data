Calculation: Skyscraper state = On the chart timeframe or a higher timeframe, calculate ATR and its highest and lowest values over a separate lookback. Set step to the sensitivity factor times their average, truncated down to a whole price quantum. Initialize the previous upper and lower thresholds to the first processed close and the previous state to neutral. On each bar, set the upper candidate to low + 2 × step and the lower candidate to high − 2 × step; alternatively use close in place of both low and high. If close > the previous upper threshold, set state to bullish; if close < the previous lower threshold, set state to bearish; otherwise retain the previous state. If state is bullish, set the lower threshold to the maximum of the lower candidate and previous lower threshold, and set the upper threshold to positive infinity. Otherwise, set the upper threshold to the minimum of the upper candidate and previous upper threshold, and set the lower threshold to the smallest positive representable value. For a higher timeframe, use its still-forming bar and carry its result across the chart bars within it.

Long: Skyscraper state = bullish AND previous Skyscraper state is bearish or neutral
Short: Skyscraper state is bearish or neutral
Short: Skyscraper state is bearish or neutral AND previous Skyscraper state = bullish
