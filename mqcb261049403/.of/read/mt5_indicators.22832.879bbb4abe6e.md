Calculation: Smoothed Fisher = Smooth the Fisher value, where Fisher value is 0.5 × ln((1 + x) / (1 − x)) + 0.5 × prior Fisher value, x = (applied price − lowest low) / (highest high − lowest low) − 0.5 + 0.67 × prior x, and highest high/lowest low span the same lookback; use the current chart bar or, when selected, the current still-forming higher-timeframe bar.
Calculation: Trigger = prior bar’s Smoothed Fisher.
Long: Smoothed Fisher > Trigger
Short: Smoothed Fisher < Trigger
