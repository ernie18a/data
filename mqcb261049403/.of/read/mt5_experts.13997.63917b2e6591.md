Calculation: Directional Laguerre values = Apply the same calculation independently to the positive and negative directional indicators from iADX, using the same period and smoothing coefficient. Calculate on a configurable indicator timeframe, which may be higher, lower, or equal to the chart timeframe; use the last completed indicator bar by default, or a configurable forming or earlier bar. For each input x, initialize L0, L1, L2, and L3 to zero and update chronologically: L0 = (1 - g) * x + g * previous L0; L1 = -g * L0 + previous L0 + g * previous L1; L2 = -g * L1 + previous L1 + g * previous L2; L3 = -g * L2 + previous L2 + g * previous L3. Let U be the sum of max(Li - L(i+1), 0) and D the sum of max(L(i+1) - Li, 0), for i from 0 through 2. The output is U / (U + D) when the denominator is nonzero; otherwise retain the preceding output in the calculation pass, initialized to zero. Call the outputs positive and negative Laguerre values.
