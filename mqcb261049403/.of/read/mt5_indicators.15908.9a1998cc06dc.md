Calculation: Input price = selectable close, open, high, low, (high + low) / 2, (high + low + close) / 3, (high + low + 2 × close) / 4, (open + close) / 2, (open + high + low + close) / 4, trend-follow price, or half trend-follow price. Trend-follow price is high if close > open, low if close < open, otherwise close. Half trend-follow price is (high + close) / 2 if close > open, (low + close) / 2 if close < open, otherwise close.
Calculation: Ultra-linear moving average = apply three stages to the input price; each stage returns 1.5 × EMA1 − 0.5 × EMA2, where EMA1 smooths the stage input and EMA2 smooths EMA1, both with smoothing factor 3 / (length + 2) and initialized to the first input.
Calculation: Parabolic moving average = value at the newest bar of a least-squares quadratic fitted to the input prices over the lookback.
Calculation: First and second averages = independently parameterized moving averages of the same input price; the first has a shorter default lookback than the second. Each may use SMA, EMA, SMMA, LWMA, JMA, ultra-linear moving average, parabolic moving average, T3, VIDYA, or Kaufman adaptive moving average. Calculate both on the chart timeframe or on the still-forming higher-timeframe bar.
Long: First average > second average AND low of the same timeframe bar > first average AND (volume weighting is disabled OR volume of the same timeframe bar > 0)
Short: First average < second average AND high of the same timeframe bar < first average AND (volume weighting is disabled OR volume of the same timeframe bar > 0)
