Calculation: Trend lines = For each bar, calculate CCI of typical price plus a fixed offset and compare it with a threshold. Maintain an up line and a down line, initially zero. Before calculating the current lines, if adjusted CCI is >= the threshold and the previous adjusted CCI was < it, set the previous up line equal to the previous down line; if adjusted CCI is <= the threshold and the previous adjusted CCI was > it, set the previous down line equal to the previous up line. If adjusted CCI is > the threshold, set the down line to zero and the up line to low minus a fixed price offset; instead retain the previous up line if the previous lines differ AND (close < open OR the candidate up line < the previous up line OR high < previous high). If adjusted CCI is < the threshold, set the up line to zero and the down line to high plus the fixed price offset; instead retain the previous down line if the previous lines differ AND (close > open OR the candidate down line > the previous down line OR low > previous low). At equality, leave the lines unchanged. The indicator may use the chart timeframe or a configurable higher or lower timeframe; the trading decision uses a configurable completed bar on that timeframe, with the immediately preceding bar for the previous lines.
Long: Previous down line != 0 AND current up line != 0.
Short: Previous up line != 0 AND current down line != 0.
Exit: long, previous up line != 0 AND current down line != 0 OR the most recent nonzero trend line at or before the preceding bar is the down line OR low <= entry price minus stop-loss distance OR high >= entry price plus take-profit distance.
Exit: short, previous down line != 0 AND current up line != 0 OR the most recent nonzero trend line at or before the preceding bar is the up line OR high >= entry price plus stop-loss distance OR low <= entry price minus take-profit distance.
