Calculation: Reference bar = last completed higher-timeframe bar.
Calculation: Target distance = reference bar range at entry multiplied by a take-profit factor.
Long: Close > reference bar high AND reference bar close > (reference bar high + reference bar low) / 2.
Short: Close < reference bar low AND reference bar close < (reference bar high + reference bar low) / 2.
Exit: Long, high >= entry price + target distance.
