Calculation: Tick volume index = For each bar, let up = (volume + (close - open) / price point size) / 2 and down = volume - up. Smooth up and down separately with the same moving-average method and first lookback, then smooth each result with the same method and a second independent lookback. Calculate 100 * (twice-smoothed up - twice-smoothed down) / (twice-smoothed up + twice-smoothed down), then smooth this ratio with the same method and a third independent lookback.
Calculation: Trading interval = For start hour less than end hour, time is inside when (hour = start hour AND minute >= start minute) OR (hour > start hour AND hour < end hour) OR (hour = end hour AND minute < end minute). For equal start and end hours, time is inside when hour = start hour AND minute >= start minute AND minute < end minute. For start hour greater than end hour, time is inside when (hour >= start hour AND minute >= start minute) OR hour < end hour OR (hour = end hour AND minute < end minute).
Long: Chart-timeframe tick volume index > 0 AND chart-timeframe tick volume index != its previous-bar value.
Short: Chart-timeframe tick volume index < 0 AND chart-timeframe tick volume index != its previous-bar value.
Long: On a higher timeframe, the last completed bar's tick volume index > the preceding bar's value AND the value two bars before the last completed bar > the preceding bar's value.
Short: On a higher timeframe, the last completed bar's tick volume index < the preceding bar's value AND the value two bars before the last completed bar < the preceding bar's value.
Exit: long, on a higher timeframe, the last completed bar's tick volume index < the preceding bar's value.
Exit: short, on a higher timeframe, the last completed bar's tick volume index > the preceding bar's value.
Exit: long, time-of-day is outside the enabled trading interval OR low <= entry price - stop-loss distance OR high >= entry price + take-profit distance.
Exit: short, time-of-day is outside the enabled trading interval OR high >= entry price + stop-loss distance OR low <= entry price - take-profit distance.
