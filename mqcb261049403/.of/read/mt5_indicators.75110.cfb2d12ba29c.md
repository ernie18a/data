Calculation: Confirmed pivot = for a candidate bar a configurable radius of bars before the current bar, a pivot high has high >= every high in the equally sized preceding window and > every high in the following window through the current bar; a pivot low has low <= every low in the preceding window and < every low in the following window. If both occur, use the pivot high.
Calculation: Pivot center = the first confirmed pivot price initially; thereafter, when a pivot is confirmed, (2 * previous center + pivot price) / 3; otherwise carry the previous center forward.
Calculation: Trails = lower raw band is pivot center - ATR * multiplier and upper raw band is pivot center + ATR * multiplier. The lower trail is max(lower raw band, previous lower trail) if the previous close > previous lower trail, otherwise lower raw band. The upper trail is min(upper raw band, previous upper trail) if the previous close < previous upper trail, otherwise upper raw band. Calculate trails only when the center exists and ATR is valid and > 0; otherwise they are unavailable.
Calculation: Trend = initially bullish; on each bar with valid trails, set bullish if close > previous upper trail, else set bearish if close < previous lower trail, else retain the previous trend. If trails are unavailable, retain the previous trend.
Long: Trend = bullish AND previous trend = bearish
Short: Trend = bearish AND previous trend = bullish
