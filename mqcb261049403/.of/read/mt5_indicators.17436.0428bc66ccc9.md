Calculation: NRTR state = On the first bar with ATR available, set direction to up if close >= open, otherwise down; set the extreme to close and the stop to close minus ATR times a multiplier for up, or close plus ATR times the same multiplier for down. On each subsequent bar, process these rules in order: if the previous direction is up and low > previous extreme, keep direction up and set extreme to close and stop to close minus ATR times the multiplier; otherwise, if the previous direction is up and close < previous stop, set direction down and set extreme to close and stop to close plus ATR times the multiplier; otherwise, if the previous direction is down and high < previous extreme, keep direction down and set extreme to close and stop to close plus ATR times the multiplier; otherwise, if the previous direction is down and close > previous stop, set direction up and set extreme to close and stop to close minus ATR times the multiplier; otherwise carry all state forward.
Calculation: Higher-timeframe NRTR state = NRTR state calculated on a higher timeframe using its bar still forming. The higher-timeframe indicator's historical values are mapped to the first chart bar of each higher-timeframe bar and carried forward until the next higher-timeframe bar; historical mapping can therefore reflect the completed higher-timeframe bar.
Long: NRTR direction = up OR higher-timeframe NRTR direction = up
Short: NRTR direction = down OR higher-timeframe NRTR direction = down
