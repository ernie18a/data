Long: current price (the close of the latest bar) > open of the still-forming bar of a given timeframe. Evaluate this separately for each timeframe in a fixed set of timeframes that spans lower to higher than the chart timeframe and is independent of it; each timeframe gives its own bullish marking.
Short: current price (the close of the latest bar) < open of the still-forming bar of a given timeframe. Evaluate this separately for each timeframe in the same set; each timeframe gives its own bearish marking. If current price = that open, the marking is neutral (neither long nor short).
