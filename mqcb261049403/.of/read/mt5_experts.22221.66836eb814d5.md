Calculation: Schaff Trend Cycle = Apply a stochastic normalization over the cycle lookback to the difference between fast JJRSX and slow JJRSX, smooth it by 0.5, apply a second stochastic normalization over the same lookback scaled to −100 to 100, then smooth it by 0.5. Fast JJRSX uses a shorter lookback than slow JJRSX.
Long: Schaff Trend Cycle on the last completed signal-timeframe bar > 0 AND Schaff Trend Cycle on the preceding completed signal-timeframe bar ≤ 0
Short: Schaff Trend Cycle on the last completed signal-timeframe bar < 0 AND Schaff Trend Cycle on the preceding completed signal-timeframe bar ≥ 0
Exit: long, Schaff Trend Cycle on the last completed signal-timeframe bar < 0
