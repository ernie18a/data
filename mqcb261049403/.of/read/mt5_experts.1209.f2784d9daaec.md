Calculation: Trend buffers = On each indicator bar, let midpoint = (high + low) / 2, lower band = midpoint - ATR × multiplier, and upper band = midpoint + ATR × multiplier. Initialize phase as neutral. Set both buffers to zero on each bar; while neutral, set both to midpoint. If phase is not bullish and the previous bearish buffer is nonzero and close > previous bearish buffer, set phase to bullish and the bullish buffer to the lower band. Then, if phase is not bearish and the previous bullish buffer is nonzero and close < previous bullish buffer, set phase to bearish and the bearish buffer to the upper band. In bullish phase, set the bullish buffer to the lower band if it is greater than the previous bullish buffer, or if the current bullish buffer is nonzero in visual or expert mode; otherwise set it to the previous bullish buffer. In bearish phase, set the bearish buffer to the upper band if it is less than the previous bearish buffer, or if the current bearish buffer is nonzero in visual or expert mode; otherwise set it to the previous bearish buffer. In SuperTrend mode, perform the bullish or bearish buffer update only if that buffer was nonzero two bars earlier. On a bullish phase change, SuperTrend and NewWay modes also overwrite the previous bullish buffer with the previous bearish buffer; visual mode copies the previous bearish buffer into the current bearish buffer. On a bearish phase change, SuperTrend and NewWay modes also overwrite the previous bearish buffer with the previous bullish buffer; visual mode copies the previous bullish buffer into the current bullish buffer. Apply these mode-specific assignments in the stated order before the phase buffer updates.
Calculation: Markings = In SuperTrend, NewWay, and expert modes, a bullish marking occurs when the previous bearish buffer and current bullish buffer are both nonzero; a bearish marking occurs when the previous bullish buffer and current bearish buffer are both nonzero. In visual mode, a bullish marking occurs when the previous bullish buffer is zero and the current bullish buffer is nonzero; a bearish marking occurs when the previous bearish buffer is zero and the current bearish buffer is nonzero. The standalone indicator uses chart-timeframe bars. The expert uses expert-mode buffers on a configurable higher or lower timeframe, normally the last completed bar; if configured for the current bar, use the bar still forming.
Long: Bullish marking = present.
Short: Bearish marking = present.
Exit: long, expert-mode bearish marking = present OR expert-mode bearish marking = absent AND expert-mode bearish buffer != 0.
Exit: short, expert-mode bullish marking = present OR expert-mode bullish marking = absent AND expert-mode bullish buffer != 0.
Exit: long, low <= entry price - stop-loss distance OR high >= entry price + take-profit distance.
Exit: short, high >= entry price + stop-loss distance OR low <= entry price - take-profit distance.
