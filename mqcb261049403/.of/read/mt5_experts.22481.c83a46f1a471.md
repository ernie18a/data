Calculation: Volume-weighted shifted Williams %R = smooth((Williams %R + 50) × selected volume), on the configured indicator timeframe (which may be the same as, higher, or lower than the chart timeframe).
Long: The latest completed value > the preceding completed value AND the preceding completed value < the value before it.
Short: The latest completed value < the preceding completed value AND the preceding completed value > the value before it.
Exit: long, the latest completed value < the preceding completed value AND the preceding completed value > the value before it.
Exit: short, the latest completed value > the preceding completed value AND the preceding completed value < the value before it.
