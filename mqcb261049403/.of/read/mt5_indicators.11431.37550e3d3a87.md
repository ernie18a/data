Calculation: Trend = a recursive state calculated on each bar, starting at the bar whose zero-based index equals lookback + 1. On that first bar, set it to long if close > open, otherwise short. Thereafter, if the previous state is long, set it to short when the selected current price is less than or equal to every low in the preceding lookback bars, otherwise keep it long; the selected price is either current close or current low. If the previous state is short, set it to long when the selected current price is greater than or equal to every high in the preceding lookback bars, otherwise keep it short; the selected price is respectively current close or current high.
Calculation: Higher-timeframe trend = Trend calculated on a higher timeframe using its still-forming bar, sampled on the first chart bar of each higher-timeframe bar and held until the next higher-timeframe bar. The higher timeframe may instead equal the chart timeframe.
Long: chart-timeframe Trend = long OR Higher-timeframe trend = long
Short: chart-timeframe Trend = short OR Higher-timeframe trend = short
