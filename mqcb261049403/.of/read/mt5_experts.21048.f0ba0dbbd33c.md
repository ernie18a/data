Calculation: Bullish and bearish oscillator values = On the configured signal timeframe, apply an LWMA to the selected price over a lookback, then apply an LWMA of the same lookback to that result. For each lookback in an ascending evenly spaced ladder from shorter to longer, calculate the configured moving average of this smoothed price; count averages that rose since the preceding bar as bullish votes and all others as bearish votes. Smooth each vote count with the configured smoothing method and lookback. Use the last completed signal-timeframe bar and the preceding completed bar; the signal timeframe may be higher or lower than the chart timeframe.
Long: Previous completed bar's bullish oscillator value < its bearish oscillator value AND current completed bar's bullish oscillator value > its bearish oscillator value
Short: Previous completed bar's bullish oscillator value > its bearish oscillator value AND current completed bar's bullish oscillator value < its bearish oscillator value
Exit: Long, current completed bar's bullish oscillator value < its bearish oscillator value OR low <= entry price - stop-loss distance OR high >= entry price + take-profit distance
Exit: Short, current completed bar's bullish oscillator value > its bearish oscillator value OR high >= entry price + stop-loss distance OR low <= entry price - take-profit distance
