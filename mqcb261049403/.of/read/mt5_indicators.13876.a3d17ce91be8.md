Calculation: Kagi pivots = Start with the first close as the first pivot. For each subsequent close, calculate the reversal distance as either a fixed price increment times a threshold or, in percentage mode, the current close times a percentage threshold, rounded down to a whole price increment. Once the close moves at least that distance from the initial pivot, append it as a new pivot. For an upward leg, replace the latest pivot with any higher close; append a new pivot when the close is at least the reversal distance below that pivot. For a downward leg, replace the latest pivot with any lower close; append a new pivot when the close is at least the reversal distance above that pivot. Process the upward-leg and downward-leg checks in that order on each bar.
Calculation: Kagi direction = Initialize the direction as long if the second pivot is above the first; otherwise initialize it as short. Starting with the third pivot, change a short direction to long when the latest pivot is above both preceding pivots; change a long direction to short when the latest pivot is below both preceding pivots. Until a third pivot exists, the displayed direction is long. Recalculate the direction from the pivot sequence on each bar. For the higher-timeframe variant, use the still-forming higher-timeframe bar.
Long: Kagi direction is long.
Short: Kagi direction is short.
