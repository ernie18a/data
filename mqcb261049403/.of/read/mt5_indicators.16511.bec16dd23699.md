Calculation: Williams %R = 100 × (close − highest high over lookback) / (highest high − lowest low)
Calculation: Bullish Delta WPR state = slow Williams %R > signal level AND fast Williams %R > slow Williams %R; the fast lookback is shorter than the slow lookback
Calculation: Bearish Delta WPR state = slow Williams %R < signal level AND fast Williams %R < slow Williams %R
Long: Bullish Delta WPR state OR (on a higher timeframe, the bullish Delta WPR state changes from false to true between the last two completed chart bars, using the higher-timeframe bar still forming)
Short: Bearish Delta WPR state OR (on a higher timeframe, the bearish Delta WPR state changes from false to true between the last two completed chart bars, using the higher-timeframe bar still forming)
