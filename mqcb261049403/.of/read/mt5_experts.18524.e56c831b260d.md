Calculation: Oscillator lines = Jurik moving averages of close minus close at the respective lookback; the first line uses a shorter momentum lookback than the second, with independently configurable smoothing. Calculate on a configurable indicator timeframe, which may be higher or lower than the chart timeframe, using the last completed indicator bar by default or the still-forming bar if configured; compare with the preceding indicator bar.
Calculation: Trading interval = when start hour < end hour: (hour = start hour AND minute >= start minute) OR (hour > start hour AND hour < end hour) OR (hour = end hour AND minute < end minute); when start hour = end hour: hour = start hour AND minute >= start minute AND minute < end minute; when start hour > end hour: (hour >= start hour AND minute >= start minute) OR hour < end hour OR (hour = end hour AND minute < end minute).
Long: First oscillator line > second oscillator line AND previous first oscillator line <= previous second oscillator line AND (time filter disabled OR datetime is inside trading interval).
Short: First oscillator line < second oscillator line AND previous first oscillator line >= previous second oscillator line AND (time filter disabled OR datetime is inside trading interval).
Exit: long, first oscillator line < second oscillator line OR (time filter enabled AND datetime is outside trading interval) OR low <= entry price minus stop-loss distance OR high >= entry price plus take-profit distance.
Exit: short, first oscillator line > second oscillator line OR (time filter enabled AND datetime is outside trading interval) OR high >= entry price plus stop-loss distance OR low <= entry price minus take-profit distance.
