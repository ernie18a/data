Calculation: Laguerre directional oscillator = For either +DI or -DI from ADX, use the higher-timeframe bar still forming at the start of each higher-timeframe interval. Initialize L0, L1, L2, L3 and the oscillator to zero. On each higher-timeframe bar, set L0 = (1 - gamma) * DI + gamma * previous L0; L1 = -gamma * L0 + previous L0 + gamma * previous L1; L2 = -gamma * L1 + previous L1 + gamma * previous L2; L3 = -gamma * L2 + previous L2 + gamma * previous L3. Let U be the sum of max(L0 - L1, 0), max(L1 - L2, 0), and max(L2 - L3, 0); let D be the sum of max(L1 - L0, 0), max(L2 - L1, 0), and max(L3 - L2, 0). If U + D is nonzero, the oscillator is U / (U + D); otherwise retain its preceding value.
Calculation: Cloud values = At the start of each higher-timeframe interval, take the +DI and -DI Laguerre directional oscillators using the same ADX period and gamma. If their absolute difference is below a threshold, add an adjustment to whichever corresponding cloud value was greater on the previous chart bar. Hold both cloud values unchanged for the remaining chart bars in the higher-timeframe interval.
Long: +DI cloud value > -DI cloud value
Short: +DI cloud value < -DI cloud value
