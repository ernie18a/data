Calculation: Rolling high/low = highest high / lowest low over the lookback on the higher timeframe; moving averages = the selected moving-average type of high / low over the same lookback.
Calculation: Trend state = On each higher-timeframe bar, update the state in this order: if the pending state is bullish, raise the tracked low to the greater of its prior value and the rolling low; if the moving average of highs is below that tracked low AND close is below the prior bar's low, set trend bearish, pending state bearish, and tracked high to the rolling high. Then, if the pending state is bearish, lower the tracked high to the lesser of its prior value and the rolling high; if the moving average of lows is above that tracked high AND close is above the prior bar's high, set trend bullish, pending state bullish, and tracked low to the rolling low. Initialize trend and pending state as bearish, tracked low as zero, and tracked high above all prices. Signals use the selected bar on the higher timeframe, which may still be forming.
Long: Trend state changes from bearish on the preceding higher-timeframe bar to bullish on the selected higher-timeframe bar.
Short: Trend state changes from bullish on the preceding higher-timeframe bar to bearish on the selected higher-timeframe bar.
