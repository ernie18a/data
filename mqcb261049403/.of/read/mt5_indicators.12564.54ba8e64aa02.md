Calculation: Trend state = On the chart timeframe for the standalone indicator, or on the selected higher timeframe for the higher-timeframe indicator, calculate the moving averages of high and low using the same period and method, and the rolling highest high and lowest low using that period. Use the selected higher-timeframe bar, which may be the bar still forming or a completed bar. Initialize trend to 0, next trend to 0, maximum low to 0, minimum high to 9999999, and direction to unset. On each bar, in order: if next trend is 1, set maximum low to the greater of itself and the rolling lowest low; then, if the high moving average is below maximum low AND close is below the previous bar's low, set trend to 1, next trend to 0, and minimum high to the rolling highest high. If next trend is 0, set minimum high to the lesser of itself and the rolling highest high; then, if the low moving average is above minimum high AND close is above the previous bar's high, set trend to 0, next trend to 1, and maximum low to the rolling lowest low. Set direction to short when trend changes from 0 to 1, and to long when trend changes from 1 to 0; otherwise retain direction.
Long: Trend state direction = long
Short: Trend state direction = short
