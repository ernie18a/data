Calculation: Smoothed MFI family = selected moving average of MFI over progressively longer lookbacks, each increased by the same step
Calculation: Bull count = number of family members whose current value is greater than their previous-bar value
Calculation: Bear count = number of family members whose current value is less than or equal to their previous-bar value
Calculation: Bull line = selected moving average of bull count
Calculation: Bear line = selected moving average of bear count
Long: Bull line > Bear line
Short: Bear line > Bull line
