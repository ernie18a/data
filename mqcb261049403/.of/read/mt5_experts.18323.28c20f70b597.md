Calculation: Percentage crossover line = for each bar, set the line to close × (1 − percentage) if that value is above the previous line; otherwise set it to close × (1 + percentage) if that value is below the previous line; otherwise carry forward the previous line. State is rising when the line increases, falling when it decreases, and otherwise retains its previous state. Use completed bars on the configured indicator timeframe, which may be higher or lower than the chart timeframe.
Long: State changes from falling to rising AND current time is within the configured trading interval (when time filtering is enabled).
Short: State changes from rising to falling AND current time is within the configured trading interval (when time filtering is enabled).
Exit: long, state is falling OR time is outside the configured trading interval (when time filtering is enabled) OR price ≤ entry price − configured stop-loss distance OR price ≥ entry price + configured take-profit distance
Exit: short, state is rising OR time is outside the configured trading interval (when time filtering is enabled) OR price ≥ entry price + configured stop-loss distance OR price ≤ entry price − configured take-profit distance
