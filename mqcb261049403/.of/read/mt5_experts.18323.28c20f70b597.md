Calculation: Percentage crossover line = On the selected indicator timeframe, initialize the line to the first close. For each subsequent bar, set it to close × (1 − percentage deviation) if that exceeds the previous line; otherwise set it to close × (1 + percentage deviation) if that is below the previous line; otherwise retain the previous line. The indicator timeframe may be higher or lower than the chart timeframe; use the selected completed bar, or the forming bar when the signal-bar offset is zero.
Calculation: Direction = Up when the percentage crossover line rises, down when it falls, and otherwise the previous direction; initialize to up.
Calculation: Trading interval = If start hour < end hour, (hour = start hour AND minute ≥ start minute) OR (hour > start hour AND hour < end hour) OR (hour = end hour AND minute < end minute). If start hour = end hour, hour = start hour AND minute ≥ start minute AND minute < end minute. If start hour > end hour, (hour ≥ start hour AND minute ≥ start minute) OR hour < end hour OR (hour = end hour AND minute < end minute).
Long: Direction = up AND previous indicator-bar direction = down AND (trading interval restriction disabled OR current time is in trading interval) AND position side = flat
Short: Direction = down AND previous indicator-bar direction = up AND (trading interval restriction disabled OR current time is in trading interval) AND position side = flat
Exit: long, direction = down OR (trading interval restriction enabled AND current time is outside trading interval) OR (stop loss enabled AND low ≤ entry price − stop distance) OR (take profit enabled AND high ≥ entry price + profit distance)
Exit: short, direction = up OR (trading interval restriction enabled AND current time is outside trading interval) OR (stop loss enabled AND high ≥ entry price + stop distance) OR (take profit enabled AND low ≤ entry price − profit distance)
