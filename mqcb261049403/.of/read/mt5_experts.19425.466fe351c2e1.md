Calculation: Applied price P = a selected bar price: open, high, low, close, (high + low)/2, (high + low + close)/3, (high + low + 2 × close)/4, (open + close)/2, or (open + high + low + close)/4; alternatively, if close > open use high, if close < open use low, otherwise close; or if close > open use (high + close)/2, if close < open use (low + close)/2, otherwise close; or use (R − low + R − high)/2, where R = (high + low + close + X)/2 and X is low if close < open, high if close > open, otherwise close.
Calculation: Reversal stop S = initialize the previous stop to 0 at the first eligible bar, then process bars chronologically. If P = previous S, S = previous S; otherwise, if previous P < previous S AND P < previous S, S = min(previous S, P × (1 + offset)); otherwise, if previous P > previous S AND P > previous S, S = max(previous S, P × (1 − offset)); otherwise, if P > previous S, S = P × (1 − offset); otherwise S = P × (1 + offset). Evaluate on the chart timeframe for indicator markings; for the trading strategy use the configured indicator timeframe, which may be higher or lower than the chart timeframe, and the selected completed bar or the still-forming bar.
Calculation: Trading interval = when start hour < end hour, (hour = start hour AND minute ≥ start minute) OR (hour > start hour AND hour < end hour) OR (hour = end hour AND minute < end minute); when start hour = end hour, hour = start hour AND minute ≥ start minute AND minute < end minute; when start hour > end hour, (hour ≥ start hour AND minute ≥ start minute) OR hour < end hour OR (hour = end hour AND minute < end minute).
Long: P > S AND previous P < previous S AND previous S ≠ 0
Short: P < S AND previous P > previous S AND previous S ≠ 0
Long: P > S AND previous P < previous S AND previous S ≠ 0 AND (time filter disabled OR time is in trading interval)
Short: P < S AND previous P > previous S AND previous S ≠ 0 AND (time filter disabled OR time is in trading interval)
Exit: long, the latest available reversal marking is short OR (time filter enabled AND time is outside trading interval) OR (stop loss enabled AND low ≤ entry price − stop distance) OR (take profit enabled AND high ≥ entry price + profit distance)
Exit: short, the latest available reversal marking is long OR (time filter enabled AND time is outside trading interval) OR (stop loss enabled AND high ≥ entry price + stop distance) OR (take profit enabled AND low ≤ entry price − profit distance)
