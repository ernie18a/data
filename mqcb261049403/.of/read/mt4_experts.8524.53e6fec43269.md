Long: configured opening mode is arrow and buy-signal buffer != 0 and != missing-value OR configured opening mode is line-cross and current main line > current signal line and previous main line <= previous signal line OR configured opening mode is level-cross and current line > buy level and previous line <= buy level OR configured opening mode is three-point-extremum and current line > middle line and line two bars back > middle line; NOT (short condition also true)
Short: configured opening mode is arrow and sell-signal buffer != 0 and != missing-value OR configured opening mode is line-cross and current main line < current signal line and previous main line >= previous signal line OR configured opening mode is level-cross and current line < sell level and previous line >= sell level OR configured opening mode is three-point-extremum and current line < middle line and line two bars back < middle line; NOT (long condition also true)
Exit: long, close signal is present OR low <= entry price - stop-loss distance OR high >= entry price + take-profit distance; if profit checking is enabled, current profit >= minimum profit; if stop-loss checking is enabled and stop-loss is nonzero, stop-loss profit < minimum protected profit
Exit: short, close signal is present OR high >= entry price + stop-loss distance OR low <= entry price - take-profit distance; if profit checking is enabled, current profit >= minimum profit; if stop-loss checking is enabled and stop-loss is nonzero, stop-loss profit < minimum protected profit
Exit: long, configured exit mode is reversal and short-entry condition is true OR configured exit mode is arrow and close-long buffer != 0 and != missing-value OR configured exit mode is line-cross and current main line < current signal line and previous main line >= previous signal line OR configured exit mode is level-cross and current line < close-long level and previous line >= close-long level OR configured exit mode is three-point-extremum and current line < middle line and line two bars back < middle line
Exit: short, configured exit mode is reversal and long-entry condition is true OR configured exit mode is arrow and close-short buffer != 0 and != missing-value OR configured exit mode is line-cross and current main line > current signal line and previous main line <= previous signal line OR configured exit mode is level-cross and current line > close-short level and previous line <= close-short level OR configured exit mode is three-point-extremum and current line > middle line and line two bars back > middle line
