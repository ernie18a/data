Calculation: NRTR step = if fixed step is enabled, sensitivity × fixed step size; otherwise, half the sensitivity × (running maximum + running minimum) of the lookback average High−Low range, rounded to a price increment. The range average is a simple average or a linearly weighted average with greater weight on recent bars.
Calculation: NRTR trend = Initialize upper and lower thresholds at Low + 2 steps and High − 2 steps. On each bar, set candidate thresholds to Low + 2 steps and High − 2 steps, or Close ± 2 steps in close-only mode. While bearish, the upper threshold can only decrease; while bullish, the lower threshold can only increase. Turn bullish when Close exceeds the previous upper threshold; turn bearish when Close falls below the previous lower threshold; otherwise retain the prior trend.
Long: chart-timeframe NRTR trend > 0 AND prior chart-timeframe NRTR trend < 0 OR higher-timeframe NRTR trend > 0 AND prior higher-timeframe NRTR trend < 0 (higher-timeframe bar still forming)
Short: chart-timeframe NRTR trend < 0 AND prior chart-timeframe NRTR trend > 0 OR higher-timeframe NRTR trend < 0 AND prior higher-timeframe NRTR trend > 0 (higher-timeframe bar still forming)
