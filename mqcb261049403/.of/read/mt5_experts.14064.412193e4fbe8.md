Calculation: DeMarker trend cycle = On the selected indicator timeframe, subtract the longer-lookback DeMarker from the shorter-lookback DeMarker. Stochastically normalize that difference over a cycle lookback to 0–100, carrying forward the previous value when the range is zero; smooth it recursively as previous smoothed value plus half the change from that value to the new normalized value. Stochastically normalize the smoothed result over the same cycle lookback to -100–100, carrying forward the previous cycle value when the range is zero; smooth this result by the same recursive method. The indicator timeframe may be higher or lower than the chart timeframe; use the last completed indicator bar, or the still-forming bar if configured.
