Calculation: Supertrend = computed on the Supertrend timeframe (equal to or higher than the chart timeframe) with ATR = simple moving average of true range over an ATR lookback and a multiplier; hl2 = (high+low)/2; basicUpper = hl2 + multiplier*ATR; basicLower = hl2 - multiplier*ATR; finalUpper = basicUpper if (basicUpper < previous finalUpper OR previous close > previous finalUpper) else previous finalUpper; finalLower = basicLower if (basicLower > previous finalLower OR previous close < previous finalLower) else previous finalLower; state of the first bar = up if close >= hl2 else down; afterwards state = down if (previous state is up AND close < finalLower), up if (previous state is down AND close > finalUpper), else previous state
Long: Supertrend state of the last completed Supertrend-timeframe bar is up AND Supertrend state of the bar before it is down (signal is taken only after that bar has closed, never on the still-forming bar)
Short: Supertrend state of the last completed Supertrend-timeframe bar is down AND Supertrend state of the bar before it is up (signal is taken only after that bar has closed, never on the still-forming bar)
