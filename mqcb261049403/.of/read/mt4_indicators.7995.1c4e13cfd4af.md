Calculation: Reverse Fisher oscillator = On each chart-bar evaluation, traverse chart bars from the current bar toward the oldest available bar, retaining the final smoothed value and oscillator from the preceding evaluation as the initial state; initialize both to zero. For each visited bar, select a price from open, high, low, close, their median, typical, four-price average, or open-close average. Normalize it to the range from the lowest low to the highest high over the lookback ending at that bar: x = 2 * ((price - lowest low) / (highest high - lowest low) - 0.5). Smooth x with a weighted average of x and the retained smoothed value, clamp it symmetrically inside (-1, 1), and calculate oscillator = 0.5 * ln((1 + smoothed value) / (1 - smoothed value)) + a smoothing coefficient * retained oscillator. Update the retained values after each visited bar. At each bar, the comparison oscillator values are the retained values from the immediately preceding and second preceding iterations, which correspond to more recent bars in the traversal.
Calculation: Directional score for each of three ordered timeframes = Count the rising close simple moving averages among five increasing lookbacks for the upward score, and count the falling ones for the downward score. Add an accelerator-oscillator weight to the upward or downward score respectively when its corresponding directional condition below holds. Use the still-forming bar on each timeframe; the three timeframes are ordered shortest to longest and can each be lower than, equal to, or higher than the chart timeframe. The same five lookbacks and accelerator-oscillator parameters apply to each timeframe.
Long: Reverse Fisher oscillator > positive threshold AND oscillator < preceding-iteration oscillator AND preceding-iteration oscillator >= second-preceding-iteration oscillator.
Short: Reverse Fisher oscillator < negative threshold AND oscillator > preceding-iteration oscillator AND preceding-iteration oscillator <= second-preceding-iteration oscillator.
Exit: long, reverse Fisher oscillator < 0 AND preceding-iteration oscillator > 0.
Exit: short, reverse Fisher oscillator > 0 AND preceding-iteration oscillator < 0.
Long: Close simple moving average on any one of the three ordered timeframes, using its still-forming bar, > its value on the preceding bar of that timeframe; evaluate each of the five increasing lookbacks separately.
Short: Close simple moving average on any one of the three ordered timeframes, using its still-forming bar, < its value on the preceding bar of that timeframe; evaluate each of the five increasing lookbacks separately.
Long: On any one of the three ordered timeframes, using the still-forming accelerator oscillator as A0 and its three preceding values as A1, A2 and A3, (A1 > A2 AND A2 > A3 AND A0 < 0 AND A0 > A1) OR (A0 > A1 AND A1 > A2 AND A0 > 0).
Short: On any one of the three ordered timeframes, using the still-forming accelerator oscillator as A0 and its three preceding values as A1, A2 and A3, (A1 < A2 AND A2 < A3 AND A0 > 0 AND A0 < A1) OR (A0 < A1 AND A1 < A2 AND A0 < 0).
Long: Upward directional score > score threshold on each of the three ordered timeframes.
Short: Downward directional score > score threshold on each of the three ordered timeframes.
