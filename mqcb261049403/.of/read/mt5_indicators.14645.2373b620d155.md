Calculation: Stepped DeMarker line = For each bar, let D be DeMarker multiplied by 100 and let s be a step parameter. Initialize the prior upper bound to negative infinity, the prior lower bound to positive infinity, the trend to neutral, and the line to zero. Set the current upper bound to D + 2s and the current lower bound to D - 2s. If D is greater than the prior upper bound, set the trend to up; if D is less than the prior lower bound, set the trend to down. In an uptrend, raise the current lower bound to the prior lower bound if it is lower, and set the line to the current lower bound + s. In a downtrend, lower the current upper bound to the prior upper bound if it is higher, and set the line to the current upper bound - s. In a neutral trend, retain the prior line. Carry the current bounds, trend, and line forward to the next bar. Calculate a fast line and a slow line using the same DeMarker period and a smaller step for the fast line. Calculate on the chart timeframe or on a higher timeframe using its still-forming bar.
Long: The previous fast line <= the previous slow line AND the current fast line > the current slow line.
Short: The previous fast line >= the previous slow line AND the current fast line < the current slow line.
