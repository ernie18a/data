Calculation: Selected price = configurable open, high, low, median price, typical price, weighted close, close, (open + close)/2, (open + high + low + close)/4, or one of: high if close > open, low if close < open, otherwise close; (high + close)/2 if close > open, (low + close)/2 if close < open, otherwise close; DeMark price. The default selection is open.
Calculation: Fractal RSI = on the higher timeframe, use the last completed bar by default, with the still-forming bar selectable. For each bar, let n be the fractal lookback, maximum be the greater of zero and the highest selected price in the last n bars, and minimum be the lesser of a fixed initialization ceiling and the lowest selected price in those bars. Normalize each selected price in that window as (price - minimum)/(maximum - minimum). Let length be the sum over adjacent normalized prices of sqrt((difference between adjacent normalized prices)^2 + 1/n^2); if maximum <= minimum, length is zero. Let dimension = 1 + ln(2 * length)/ln(2 * (n - 1)) when length > 0, otherwise dimension = 0. Let period = round(normal speed/(2 * (2 - dimension))). Compute RSI from the sums of gains and losses over the last period selected-price changes, without Wilder smoothing: 100 - 100/(1 + gains/losses); use 100 when losses are zero and gains are positive, and 50 when both are zero.
Long: Direct mode AND previous Fractal RSI <= lower threshold AND Fractal RSI > lower threshold
Long: Inverse mode AND previous Fractal RSI >= upper threshold AND Fractal RSI < upper threshold
Short: Direct mode AND previous Fractal RSI >= upper threshold AND Fractal RSI < upper threshold
Short: Inverse mode AND previous Fractal RSI <= lower threshold AND Fractal RSI > lower threshold
Exit: long, direct mode AND previous Fractal RSI >= upper threshold AND Fractal RSI < upper threshold
Exit: long, inverse mode AND previous Fractal RSI <= lower threshold AND Fractal RSI > lower threshold
Exit: short, direct mode AND previous Fractal RSI <= lower threshold AND Fractal RSI > lower threshold
Exit: short, inverse mode AND previous Fractal RSI >= upper threshold AND Fractal RSI < upper threshold
Exit: long, low <= entry price - stop-loss distance OR high >= entry price + take-profit distance
Exit: short, high >= entry price + stop-loss distance OR low <= entry price - take-profit distance
