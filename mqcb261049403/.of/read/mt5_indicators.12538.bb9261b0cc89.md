Calculation: Trend state = On the chart timeframe or the higher timeframe, calculate the rolling highest high and lowest low over the same lookback, and moving averages of high and low over that lookback using the same method. Initialize state to 0, tracked low to 1, and tracked high to 99999999. On each bar, set tracked low to the maximum of its previous value and the rolling lowest low, and tracked high to the minimum of its previous value and the rolling highest high. Carry forward the previous state. If the high moving average is below tracked low AND close is below the previous bar's low, set state to -1 and reset tracked low to the rolling lowest low. Then, if the low moving average is above tracked high AND close is above the previous bar's high, set state to 1 and reset tracked high to the rolling highest high.
Calculation: Higher-timeframe cloud boundaries = Using the still-forming higher-timeframe bar, calculate trend state and ATR. Initialize both boundaries to 0. When state changes between -1 and 1, carry forward both boundaries. When current and previous state are both 1, set the first boundary to the maximum of tracked low and its previous value, and the second boundary to the first boundary minus half the ATR. When current and previous state are both -1, set the first boundary to the minimum of tracked high and its previous value, and the second boundary to the first boundary plus half the ATR. Otherwise carry forward both boundaries.
Long: Chart-timeframe trend state > 0 AND previous trend state != 0
Short: Chart-timeframe trend state < 0 AND previous trend state != 0
Long: Higher-timeframe first cloud boundary > second cloud boundary
Short: Higher-timeframe first cloud boundary < second cloud boundary
