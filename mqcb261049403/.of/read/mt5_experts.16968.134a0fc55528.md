Calculation: GO = ((MA(close) − MA(open)) + (MA(high) − MA(open)) + (MA(low) − MA(open)) + (MA(close) − MA(low)) + (MA(close) − MA(high))) × current bar volume; each MA uses the same lookback and smoothing method on the chart timeframe, including the bar still forming
Long: GO > 0
Short: GO < 0
Exit: long, GO < 0
Exit: short, GO > 0
