Calculation: ATR stop state = On the chart timeframe, initialize trend and both stop buffers to zero before the first eligible bar, after ATR is available. For each bar, let distance = current ATR multiplied by a coefficient. Starting with the prior bar's trend and stop buffers, in order: if trend <= 0 AND prior low > prior downside stop, replace the prior upside stop with prior low - distance and set trend to +1; if trend >= 0 AND prior high < prior upside stop, replace the prior downside stop with prior high + distance and set trend to -1. If trend >= 0, set the current upside stop to prior low - distance when prior low > prior upside stop + distance, otherwise carry forward the prior upside stop; otherwise set it to zero. If trend <= 0, set the current downside stop to prior high + distance when prior high < prior downside stop - distance, otherwise carry forward the prior downside stop; otherwise set it to zero. Retain any replacements of prior stops for subsequent calculations.
Calculation: Higher-timeframe ATR stop state = Apply the same ATR stop state calculation to the still-forming higher-timeframe bar, mapping its state and prior state to chart bars within that higher-timeframe bar.
Long: ATR stop state trend > 0 AND prior trend <= 0
Short: ATR stop state trend < 0 AND prior trend >= 0
Long: Higher-timeframe ATR stop state trend > 0 AND prior higher-timeframe trend <= 0
Short: Higher-timeframe ATR stop state trend < 0 AND prior higher-timeframe trend >= 0
