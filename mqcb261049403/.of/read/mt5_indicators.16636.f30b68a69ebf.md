Calculation: Filtered series = For each input series independently, if filtering is disabled, use the input. Otherwise, let change be the absolute difference between the current input and the previous filtered output. Let average change be the sum of the most recent changes over the moving-average period divided by that period, and deviation be the square root of the sum over the same period of (change minus its corresponding average change) squared, divided by the period. If the current change is less than the filter multiplier times deviation, use the previous filtered output; otherwise use the current input. Initialize missing history to zero.
Calculation: Channel = Apply the same selected simple, exponential, smoothed, or linear weighted moving average and period separately to the previous bar's high and low. Optionally filter the high and low inputs, the resulting averages, or both; when filtering prices, also filter the current close. Use separate filter histories for each series and the same period as the moving averages. Calculate on the chart timeframe or on a higher timeframe using its still-forming bar.
Calculation: Trend state = Up if the current close, filtered when price filtering is enabled, is above the upper channel; otherwise down if it is below the lower channel; otherwise retain the previous trend state. Initialize as neutral. For a higher timeframe, map its state to the corresponding chart bars.
Long: Trend state = up
Short: Trend state = down
