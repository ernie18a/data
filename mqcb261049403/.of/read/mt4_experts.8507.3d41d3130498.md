Calculation: EMA set = close-price EMAs with evenly spaced periods from shortest to longest; let C be the number of lines per group, N the number of EMAs, and index the EMAs from 0 in increasing period order. Use the selected chart bar and its preceding bar.
Calculation: Rising count = number of increases from the preceding bar among EMA indices N-C-i, N-2C-i+1, and i, for each integer i from 0 through C; count repeated indices repeatedly. Falling count is defined identically using decreases.
Calculation: Long setup flags = persist three initially false flags. Set the reset flag when the last completed close is below EMA[N-1]; when it is set and the last completed close is above EMA[0], clear all three flags. Set the Laguerre flag when EMA[N-2C] > EMA[N-C] AND Laguerre is below its lower threshold AND the last completed close > EMA[N-1] AND the last completed low < EMA[0]. Set the EMA flag when EMA[N-2C] > EMA[N-C] AND the short-period signal EMA < the long-period signal EMA. Clear all three flags after a long entry.
Calculation: Short setup flags = persist three initially false flags. Set the reset flag when the last completed close is above EMA[N-1]; when it is set and the last completed close is below EMA[0], clear all three flags. Set the Laguerre flag when EMA[N-2C] < EMA[N-C] AND Laguerre is above its upper threshold AND the last completed close < EMA[N-1] AND the last completed high > EMA[0]. Set the EMA flag when EMA[N-2C] < EMA[N-C] AND the short-period signal EMA > the long-period signal EMA. Clear all three flags after a short entry.
Long: EMA[N-2C] > EMA[N-C] AND Laguerre > its lower threshold AND long Laguerre flag = true AND short-period signal EMA > long-period signal EMA AND long EMA flag = true AND MACD main line on the last completed chart bar > 0 AND rising count > N/2.
Short: EMA[N-2C] < EMA[N-C] AND Laguerre < its upper threshold AND short Laguerre flag = true AND short-period signal EMA < long-period signal EMA AND short EMA flag = true AND MACD main line on the last completed chart bar < 0 AND falling count > N/2.
