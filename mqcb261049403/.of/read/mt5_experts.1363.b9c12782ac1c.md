Calculation: Corrected average = On the higher indicator timeframe, calculate a moving average and standard deviation of the selected applied price using the same lookback and moving-average method. Initialize the corrected average to the moving average. On each subsequent indicator bar, let d = (previous corrected average − current moving average)² and v = current standard deviation²; set k = 0 if d = 0 or d < v, otherwise k = 1 − v/d. The current corrected average = previous corrected average + k × (current moving average − previous corrected average). Use the last completed indicator bar and its preceding bar; optionally use the still-forming indicator bar and its preceding bar instead.
Long: Indicator-timeframe close > corrected average + breakout distance AND preceding indicator-timeframe close <= preceding corrected average + breakout distance
Short: Indicator-timeframe close < corrected average − breakout distance AND preceding indicator-timeframe close >= preceding corrected average − breakout distance
Exit: long, indicator-timeframe close < corrected average − breakout distance OR chart-bar low <= entry price − stop-loss distance OR chart-bar high >= entry price + take-profit distance
Exit: short, indicator-timeframe close > corrected average + breakout distance OR chart-bar high >= entry price + stop-loss distance OR chart-bar low <= entry price − take-profit distance
