Calculation: Selected price = a parameter-selected open, high, low, close, (high+low)/2, (open+close)/2, (high+low+close)/3, (high+low+2×close)/4, (open+high+low+close)/4, trend-biased price, or extreme trend-biased price. Trend-biased price is (high+close)/2 when close>open and (low+close)/2 otherwise; extreme trend-biased price is high when close>open, low when close<open, and close otherwise. The same choices may use Heikin-Ashi OHLC instead of ordinary OHLC.
Calculation: Phase-accumulation adaptive MACD = adaptive EMA of selected price using the shorter cycle target minus adaptive EMA using the longer cycle target. Process bars oldest to newest. For each cycle target maintain separate phase histories: for the first six bars use selected price as smoothed price and return period zero; thereafter smoothed price is (4×price+3×previous price+2×price two bars ago+price three bars ago)/10. For any series x, let H(x)=(0.0962×x current+0.5769×x two bars ago−0.5769×x four bars ago−0.0962×x six bars ago)×(0.075×previous adaptive period+0.54). Detrender=H(smoothed price); Q=0.15×H(detrender)+0.85×previous Q; I=0.15×detrender three bars ago+0.85×previous I. Start phase at its previous value; if I is nonzero set it to degrees(atan(abs(Q/I))); then, for I<0 and Q>0 replace phase by 180−phase, for I<0 and Q<0 by 180+phase, and for I>0 and Q<0 by 360−phase. Phase increment=previous phase−phase, except add 360 when previous phase<90 and phase>270; clamp the increment to [7,60]. Instantaneous period is the number of consecutive increments from the current bar backward needed to reach the cycle target in degrees, stopping before the oldest bar; retain its previous value if no increments are available. Smooth instantaneous period with an EMA using that cycle's filter parameter. The period-smoothing EMA is shared: calculate the shorter-cycle period first and the longer-cycle period second on each bar, and use the previous bar's longer-cycle smoothed period as the prior EMA value for both. For each adaptive price EMA, use alpha=2/(1+its current adaptive period); when the period is at most 1 or there is no previous EMA, set the EMA to current price. Initialize unavailable history to zero. Calculations use the chart timeframe or a higher timeframe's still-forming bar.
Calculation: Adaptive levels = either floating levels or quantile levels of adaptive MACD over a lookback including the current bar. Floating levels are the lookback minimum plus a selected fraction of its range; the middle uses one half, and upper and lower use their respective selected fractions. Quantile levels are linearly interpolated sorted-sample quantiles at the selected upper and lower fractions and their average for the middle; pad unavailable initial observations with zero.
Calculation: Trend state = in slope mode, 1 when adaptive MACD is greater than its previous value, −1 when lower, and the previous state when equal; in middle-level mode, 1 when adaptive MACD is above the middle adaptive level, −1 when below, and 0 when equal; in outer-level mode, 1 when adaptive MACD is above the upper adaptive level, −1 when below the lower adaptive level, and 0 otherwise.
Long: Trend state = 1 OR trend state = 0 AND previous trend state = −1.
Short: Trend state = −1 OR trend state = 0 AND previous trend state = 1.
