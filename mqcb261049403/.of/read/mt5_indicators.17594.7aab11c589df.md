Calculation: Range factor = simple moving average of high minus low, including the current bar, multiplied by a price-scale parameter.
Calculation: Trend state and trailing level = initialize the trend to neutral and both the running extreme and trailing level to the close of the first processed bar. For each bar, if the prior trend is neutral or up, set the running extreme to the maximum of its prior value and the current high, and the trailing level to the maximum of its prior value and the running extreme multiplied by (1 minus the range factor). If the current high is below that level, set the trend to down, the running extreme to the current high, and the trailing level to the current high multiplied by (1 plus the range factor). Otherwise retain the trend. If the prior trend is down, set the running extreme to the minimum of its prior value and the current low, and the trailing level to the minimum of its prior value and the running extreme multiplied by (1 plus the range factor). If the current low is above that level, set the trend to up, the running extreme to the current low, and the trailing level to the current low multiplied by (1 minus the range factor). Otherwise retain the trend.
Calculation: Up-trend high = highest high since the current up trend began; down-trend low = lowest low since the current down trend began. Apply these calculations and the trend state either on the chart timeframe or on a higher timeframe using its still-forming bar.
Long: Trend is up AND (previous bar's trend is not up OR current high is greater than the previous up-trend high).
Short: Trend is down AND (previous bar's trend is not down OR current low is less than the previous down-trend low).
