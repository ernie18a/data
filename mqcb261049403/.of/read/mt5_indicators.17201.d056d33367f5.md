Calculation: Price = a selected open, high, low, close, median, typical, weighted, OHLC average, body midpoint, trend-biased price, or corresponding Heikin-Ashi price. Trend-biased price is (high + close)/2 when close > open and (low + close)/2 otherwise; extreme trend-biased price is high when close > open, low when close < open, and close otherwise. Apply the same formulas to Heikin-Ashi OHLC when selected.
Calculation: Directional state = using the selected price on the chart timeframe or the still-forming bar of a higher timeframe, calculate the price change and its positive and negative magnitudes. Smooth each magnitude recursively as ((period - 1) × previous value + current magnitude) / period, starting at zero. Divide each smoothed magnitude by their sum, using zero for both ratios when the sum is zero. Smooth each ratio by the same recursive formula, starting at zero. Set the state to long when the smoothed positive ratio > 0.5; otherwise set it to short when the smoothed negative ratio > 0.5; otherwise retain the previous state, initially neutral.
Long: Directional state = long
Short: Directional state = short
