Calculation: Adaptive lines = On the selected indicator timeframe, which may be higher or lower than the chart timeframe, use a configurable bar offset: the last completed bar or an earlier completed bar, or the still-forming bar when the offset is zero. Let N be the lookback rounded down to an even number. For each bar, let R1 and R2 be the high-low ranges of the recent and preceding N/2 bars, each divided by N/2, and R3 be the high-low range of the latest N bars divided by N. Let D = (ln(R1 + R2) - ln(R3)) * 1.442695. Set a = clamp(exp(-main multiplier * (D - 1)), 0.01, 1) and b = exp(-signal multiplier * (D - 1)), without clamping b. Main = a * close + (1 - a) * previous main; signal = b * main + (1 - b) * previous signal. Seed both lines with the close of the first bar having the configured lookback of history.
Long: Selected bar's main > signal AND preceding indicator bar's main <= signal.
Short: Selected bar's main < signal AND preceding indicator bar's main >= signal.
Exit: long, selected indicator bar's main < signal OR low <= entry price - configured stop-loss distance OR high >= entry price + configured take-profit distance.
Exit: short, selected indicator bar's main > signal OR high >= entry price + configured stop-loss distance OR low <= entry price - configured take-profit distance.
