Calculation: Demand Index = positive when smoothed buy pressure exceeds smoothed sell pressure, negative when it is lower, and zero when equal. For each bar, weighted close = (2 × close + high + low) / 4; true range = max(current high, previous high) − min(current low, previous low). Average true range is the period simple average of true range; average volume is smoothed over the same period. Let price ratio = (current weighted close − previous weighted close) / min(current weighted close, previous weighted close), volume ratio = current volume / average volume, and base pressure = volume ratio / exp(min(3 × abs(price ratio) × current weighted close / average true range, 88)). If price ratio is positive, raw buy pressure = volume ratio and raw sell pressure = base pressure; otherwise, raw buy pressure = base pressure and raw sell pressure = volume ratio. Smooth each pressure over the period using (previous smoothed pressure × (period − 1) + current raw pressure) / period.
Long: Demand Index crosses above 0
Short: Demand Index crosses below 0
