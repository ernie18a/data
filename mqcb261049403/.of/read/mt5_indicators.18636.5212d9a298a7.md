Calculation: Swing markers = Process bars chronologically after the initial lookback. Initialize swing and previous swing to 0, peak and trough to the first processed bar's high and low, and both peak and trough indices to that bar. On each bar, compare its high and low with the highest high and lowest low of the preceding lookback bars. If both extremes are exceeded, set swing to 2 and, when the previous swing is 1 or -1, respectively set the peak or trough index to the preceding bar. Otherwise, set swing to -1 if the low is below the preceding lowest low, or to 1 if the high is above the preceding highest high; if neither condition holds, retain swing. If swing differs from a nonzero previous swing, replace swing 2 with the negative of previous swing, then record a trough marker at the trough index with the stored trough value if swing is 1, or a peak marker at the peak index with the stored peak value if swing is -1; reset peak and trough to the current high and low. If swing is 1 and current high is at least peak, update peak and its index to the current bar; if swing is -1 and current low is at most trough, update trough and its index to the current bar. Set previous swing to swing. Markers are assigned retrospectively to their stored indices when a later bar confirms the swing change.
Calculation: Higher-timeframe swing markers = Apply Swing markers to higher-timeframe bars, including the bar still forming. Map each higher-timeframe marker to the first chart bar at or after that higher-timeframe bar's start whose high reaches the marker value for a peak or whose low reaches it for a trough; if none exists, use the highest-high or lowest-low chart bar in that interval, respectively. Recalculate as bars form and markers change.
Long: A chart-timeframe trough marker is recorded OR a higher-timeframe trough marker is mapped to the chart bar.
Short: A chart-timeframe peak marker is recorded OR a higher-timeframe peak marker is mapped to the chart bar.
