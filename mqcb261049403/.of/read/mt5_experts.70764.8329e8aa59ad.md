Calculation: Grid levels = cycle anchor price plus or minus each positive integer multiple of grid spacing.
Calculation: ATR = average true range over a lookback on a higher timeframe, using the last completed bar.
Calculation: Drift magnitude = mean absolute change between consecutive simple moving averages over a lookback on a higher timeframe, using completed bars only.
Calculation: Sigma-to-drift ratio = ATR divided by drift magnitude; treat a drift magnitude below a small positive floor as an effectively infinite ratio.
Calculation: Signed drift = latest completed-bar simple moving average minus the preceding completed-bar simple moving average on a higher timeframe.
Calculation: ATR-based grid spacing = ATR on a higher timeframe, using the last completed bar, multiplied by a parameter and clamped to configured minimum and maximum spacing; use fixed spacing if ATR spacing is disabled or unavailable.
Long: In bidirectional mode, price reaches any grid level; in trending mode, signed drift is positive and price reaches a grid level above the cycle anchor; in mean-reversion mode, price reaches a grid level below the cycle anchor. Bidirectional mode is selected when sigma-to-drift ratio is at least its threshold; trending mode is selected when the ratio is below its threshold or a change point is detected; mean-reversion mode follows a trending cycle ended by the drawdown kill switch. When fixed spacing is used, require ATR divided by grid spacing to be within its configured minimum and maximum. In bidirectional mode, omit sells above the anchor if the optional buy bias is enabled.
Short: In bidirectional mode, price reaches any grid level; in trending mode, signed drift is negative and price reaches a grid level below the cycle anchor; in mean-reversion mode, price reaches a grid level above the cycle anchor. Bidirectional mode is selected when sigma-to-drift ratio is at least its threshold; trending mode is selected when the ratio is below its threshold or a change point is detected; mean-reversion mode follows a trending cycle ended by the drawdown kill switch. When fixed spacing is used, require ATR divided by grid spacing to be within its configured minimum and maximum.
Exit: long, bar high >= entry price + grid spacing
Exit: short, bar low <= entry price - grid spacing
