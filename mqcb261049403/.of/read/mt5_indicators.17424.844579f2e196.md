Calculation: RSI input = a selectable price: open, high, low, close, median, typical, weighted close, OHLC average, body midpoint, trend-biased price, or the corresponding Heikin-Ashi price. Trend-biased price is (high + close)/2 if close > open, otherwise (low + close)/2; the alternative extreme version is high if close > open, low if close < open, otherwise close. Apply the same formulas to Heikin-Ashi OHLC when selected.
Calculation: RSI = a selectable RSI variant of the selected input: standard Wilder RSI, Cutler's RSI, RSX, Harris RSI, rapid RSI, slow RSI, or Ehlers smoothed RSI. For a lookback, let U and D be the sums of positive and absolute negative input changes. Rapid RSI = 100 × U/(U + D); slow RSI is rapid RSI recursively smoothed with coefficient 1/lookback, initialized at 50; Harris RSI = 100 × average positive change/(average positive change + average absolute nonpositive change); Ehlers smoothed RSI = rapid RSI applied to (input + 2 × previous input + input two bars ago)/4, using the unsmoothed input for the first three bars. Use zero for a zero denominator. Standard RSI is initialized from the available price changes and returns 50 when their absolute sum is zero.
Calculation: RSI stop state = initially neutral. For each bar, calculate the selected moving average of RSI and the standard deviation of RSI over independently selectable lookbacks; standard deviation may use population or sample correction. Set raw upper and lower bands to moving average ± a selectable multiplier × standard deviation. Set state to up if RSI > previous adjusted upper band, otherwise down if RSI < previous adjusted lower band, otherwise retain the previous state. In the down state, cap the current upper band at the previous adjusted upper band; in the up state, floor the current lower band at the previous adjusted lower band. The resulting bands are the adjusted bands. Calculate on the chart timeframe or on a higher timeframe using its still-forming bar.
Long: RSI stop state is up AND previous RSI stop state is not up.
Short: RSI stop state is down AND previous RSI stop state is not down.
