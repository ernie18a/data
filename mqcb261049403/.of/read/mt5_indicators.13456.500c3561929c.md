Calculation: WPR trend cycle = Subtract longer-lookback Williams %R from shorter-lookback Williams %R. Stochastically normalize the difference over a cycle lookback to 0–100; if its range is zero, use the previous smoothed result. Smooth the result as the average of the current normalized value and the previous smoothed value. Stochastically normalize this smoothed series over the same cycle lookback to -100–100; if its range is zero, use the previous cycle value. Smooth again as the average of the current normalized value and the previous cycle value. Initialize the rolling histories and previous cycle value to zero and leave the first value of each smoothing stage unsmoothed. Calculate either on the chart timeframe or on the still-forming bar of a higher timeframe; for the higher-timeframe version, use the value sampled on its first chart bar and hold it until the next higher-timeframe bar.
Long: WPR trend cycle >= 0
Short: WPR trend cycle < 0
