Calculation: Range factor = the mean of high minus low over the current bar and a lookback of chart bars, multiplied by a price-precision scaling parameter.
Calculation: Trailing state = initialize trend to zero and both extreme and level to the close of the first eligible bar after the lookback warm-up. On each bar, if the previous trend is nonnegative, set extreme to the greater of its previous value and the current high, then set level to the greater of its previous value and extreme times one minus the range factor; if the current high is below that level, set extreme to the current high, level to extreme times one plus the range factor, and trend to negative. Otherwise, if the previous trend is negative, set extreme to the lesser of its previous value and the current low, then set level to the lesser of its previous value and extreme times one plus the range factor; if the current low is above that level, set extreme to the current low, level to extreme times one minus the range factor, and trend to positive. If no reversal occurs, retain the previous trend.
Calculation: Higher-timeframe trailing state = the same trailing state calculated on higher-timeframe bars, sampled from the still-forming higher-timeframe bar on its first chart bar and held until the next higher-timeframe bar begins.
Long: Trailing-state trend > 0 AND trailing-state level != 0
Short: Trailing-state trend < 0 AND trailing-state level != 0
Long: Higher-timeframe trailing-state trend > 0 AND higher-timeframe trailing-state level != 0
Short: Higher-timeframe trailing-state trend < 0 AND higher-timeframe trailing-state level != 0
