Calculation: NRTR trend and reversal level = Let d equal the mean of |high−low| over the lookback divided by 10^(EURUSD digits − chart instrument digits − digit adjustment). Start with neutral trend and anchor and level at the first close. In a nonnegative trend, set anchor=max(previous anchor, high) and level=max(previous level, anchor×(1−d)); if high<level, set trend bearish and reset anchor=high, level=anchor×(1+d). In a negative trend, set anchor=min(previous anchor, low) and level=min(previous level, anchor×(1+d)); if low>level, set trend bullish and reset anchor=low, level=anchor×(1−d). For the HTF variant, calculate on a higher timeframe using its still-forming bar.
Long: Previous trend bearish AND current low > updated reversal level
Short: Previous trend bullish AND current high < updated reversal level
