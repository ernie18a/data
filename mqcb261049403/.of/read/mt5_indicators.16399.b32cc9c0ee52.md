Calculation: Trend = (shorter-period moving average of a selected price - longer-period moving average of the same price) × an independently configured moving average of a selected price.
Calculation: Higher-timeframe trend state = compare the higher-timeframe Trend with its preceding higher-timeframe value, using the higher-timeframe bar still forming at the start of each higher-timeframe interval; carry that comparison forward through the interval.
Long: Trend >= previous chart-bar Trend.
Short: Trend < previous chart-bar Trend.
Long: Higher-timeframe trend state changes from falling to non-falling.
Short: Higher-timeframe trend state changes from non-falling to falling.
