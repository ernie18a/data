Calculation: MACD contribution = weight × (MACD main-line sign relative to zero + MACD main-line sign relative to signal line) / 2; each sign is +1 above, −1 below, and 0 equal
Calculation: Awesome Oscillator contribution = weight × (Awesome Oscillator sign relative to zero + sign of its change from the previous bar) / 2; each sign is +1 for positive/upward and −1 for negative/downward, and 0 for equality
Calculation: Moving Average of Oscillator contribution = weight × sign of the oscillator relative to zero; sign is +1 above, −1 below, and 0 equal
Calculation: Williams %R contribution = weight × (+1 when %R crosses above the oversold level, −1 when it crosses below the overbought level, otherwise 0)
Calculation: Stochastic contribution = weight × (signal from %K crossing above the oversold level or below the overbought level + sign of %K relative to %D) / 2; each comparison yields +1, −1, or 0 for equality/no crossing
Calculation: Total signal = accumulate contributions for enabled indicator/timeframe pairs in MACD, Awesome Oscillator, Moving Average of Oscillator, Williams %R, then Stochastic order, processing each family from higher to lower timeframe and truncating to an integer after each addition; each timeframe uses its last completed bar (for a timeframe different from the chart, it may be higher or lower)
Calculation: Dynamic long stop = entry price − configured stop distance × total signal × multiplier; dynamic long target = entry price + configured target distance × total signal × multiplier; dynamic short stop = entry price + configured stop distance × (−total signal) × multiplier; dynamic short target = entry price − configured target distance × (−total signal) × multiplier
Long: Total signal > 0 AND no open long position
Short: Total signal < 0 AND no open short position
Exit: Long, (dynamic mode enabled AND total signal ≠ 0 AND ((stop distance > 0 AND dynamic long stop > 0 AND bid ≤ dynamic long stop) OR (target distance > 0 AND dynamic long target > 0 AND bid ≥ dynamic long target))) OR (dynamic mode disabled AND an attached stop or target level is hit)
Exit: Short, (dynamic mode enabled AND total signal ≠ 0 AND ((stop distance > 0 AND dynamic short stop > 0 AND ask ≥ dynamic short stop) OR (target distance > 0 AND dynamic short target > 0 AND ask ≤ dynamic short target))) OR (dynamic mode disabled AND an attached stop or target level is hit)
