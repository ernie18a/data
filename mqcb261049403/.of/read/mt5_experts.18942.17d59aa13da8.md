Calculation: Applied price = selected bar price: close, open, high, low, (high+low)/2, (close+high+low)/3, (2×close+high+low)/4, (open+close)/2, (open+close+high+low)/4, high if close>open else low if close<open else close, (high+close)/2 if close>open else (low+close)/2 if close<open else close, or Demark price: let x=high+low+close; x=(x+low)/2 if close<open, (x+high)/2 if close>open, or (x+close)/2 if equal; then ((x-low)+(x-high))/2.
Calculation: Stop-reversal level = for each bar t, let P be applied price and L be the prior bar's level. If P_t=L, level_t=L; else if P_(t-1)<L and P_t<L, level_t=min(L, P_t×(1+offset)); else if P_(t-1)>L and P_t>L, level_t=max(L, P_t×(1−offset)); else if P_t>L, level_t=P_t×(1−offset); otherwise level_t=P_t×(1+offset). Initialize prior level to zero.
Long: On the last completed bar of the indicator timeframe (lower than the chart timeframe), applied price > stop-reversal level AND prior bar's applied price < prior stop-reversal level AND prior stop-reversal level ≠ 0.
Short: On the last completed bar of the indicator timeframe (lower than the chart timeframe), applied price < stop-reversal level AND prior bar's applied price > prior stop-reversal level AND prior stop-reversal level ≠ 0.
Exit: long, on the last completed bar of the indicator timeframe (lower than the chart timeframe), applied price < stop-reversal level AND prior bar's applied price > prior stop-reversal level AND prior stop-reversal level ≠ 0.
Exit: short, on the last completed bar of the indicator timeframe (lower than the chart timeframe), applied price > stop-reversal level AND prior bar's applied price < prior stop-reversal level AND prior stop-reversal level ≠ 0.
