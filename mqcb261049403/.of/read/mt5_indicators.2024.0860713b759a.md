Calculation: Momentum = shorter-period moving average of a selected bar price minus longer-period moving average of the same price, using the same averaging method.
Calculation: Accelerator = Momentum minus a moving average of Momentum. Calculate it on the chart timeframe or on the still-forming bar of a higher timeframe; compare it with the preceding bar of that same timeframe.
Calculation: Signal = moving average of Accelerator, calculated on the same timeframe as Accelerator.
Long: Accelerator > Signal
Long: Accelerator > 0 AND Accelerator != previous Accelerator
Short: Accelerator < Signal
Short: Accelerator < 0 AND Accelerator != previous Accelerator
