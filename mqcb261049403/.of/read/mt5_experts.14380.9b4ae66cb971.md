Calculation: Laguerre ROC = On a selectable higher or lower timeframe, use the last completed bar, or the still-forming bar if the signal-bar setting selects it. Let r = (close - close n bars ago) / close n bars ago + a fixed price-point offset. Initialize all four stages to the first available r. For each subsequent bar, with previous stages p0 through p3 and smoothing coefficient g, calculate s0 = (1-g)*r + g*p0, s1 = -g*s0 + p0 + g*p1, s2 = -g*s1 + p1 + g*p2, and s3 = -g*s2 + p2 + g*p3. Let U be the sum of max(s0-s1,0), max(s1-s2,0), and max(s2-s3,0); let D be the sum of max(s1-s0,0), max(s2-s1,0), and max(s3-s2,0). The value is U/(U+D) when U+D is nonzero; otherwise retain the preceding value calculated in the current calculation pass, initialized to zero at the start of the pass.
Calculation: Oscillator state = Start at 2; set to 4 if Laguerre ROC > upper threshold, otherwise to 3 if Laguerre ROC > 0.5; then set to 0 if Laguerre ROC < lower threshold, otherwise to 1 if Laguerre ROC < 0.5.
Long: Position side = flat AND current oscillator state = 4 AND previous oscillator state < 4
Short: Position side = flat AND current oscillator state = 0 AND previous oscillator state > 0
Exit: long, oscillator state < 2 OR low <= entry price - stop-loss distance OR high >= entry price + take-profit distance
Exit: short, oscillator state > 2 OR high >= entry price + stop-loss distance OR low <= entry price - take-profit distance
