Calculation: Adjusted Bollinger bands and trend = On each indicator bar, calculate the upper and lower Bollinger Bands of close. Initialize trend to neutral, previous adjusted upper and previous bearish stop to -999999999, and previous adjusted lower and previous bullish stop to 999999999. In chronological order, set trend to bullish if close > previous adjusted upper, then set it to bearish if close < previous adjusted lower; otherwise retain the applicable prior trend. In a bullish trend, adjusted lower = max(lower Bollinger Band, previous adjusted lower); otherwise adjusted lower = lower Bollinger Band. In a bearish trend, adjusted upper = min(upper Bollinger Band, previous adjusted upper); otherwise adjusted upper = upper Bollinger Band. Let offset = (risk factor - 1) / 2 × (adjusted upper - adjusted lower). Bullish stop = adjusted lower - offset, raised to the previous bullish stop if trend is bullish and it is lower. Bearish stop = adjusted upper + offset, lowered to the previous bearish stop if trend is bearish and it is higher. Store the adjusted bands and stops for the next bar.
Calculation: Indicator state = Calculate the adjusted bands, trend, and stops on the chart timeframe for indicator markings. For expert-advisor decisions, calculate them on a configurable timeframe that may be higher or lower than the chart timeframe, using a configurable signal bar: the last completed bar, an earlier completed bar, or the bar still forming. The previous indicator bar is the bar immediately before the selected signal bar.
Long: Chart-timeframe trend = bullish AND bullish stop != 0
Short: Chart-timeframe trend = bearish AND bearish stop != 0
Long: Selected signal-bar trend = bullish AND selected signal-bar bullish stop != 0 AND previous indicator-bar trend = bearish AND previous indicator-bar bearish stop != 0
Short: Selected signal-bar trend = bearish AND selected signal-bar bearish stop != 0 AND previous indicator-bar trend = bullish AND previous indicator-bar bullish stop != 0
Exit: long, selected signal-bar trend = bearish AND selected signal-bar bearish stop != 0
Exit: short, selected signal-bar trend = bullish AND selected signal-bar bullish stop != 0
Exit: long, low <= entry price - enabled stop-loss distance OR high >= entry price + enabled take-profit distance
Exit: short, high >= entry price + enabled stop-loss distance OR low <= entry price - enabled take-profit distance
