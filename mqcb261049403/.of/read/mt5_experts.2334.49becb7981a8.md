Calculation: Indicator state = On the indicator timeframe, initialize the line to the close immediately before the first calculated bar and the state to neutral. For each subsequent bar, if its high is below the preceding high, the high a lookback period ago, and the previous line, set the line to its high and set the state to neutral if the previous state was up, otherwise down. Otherwise, if its low is above the preceding low, the low a lookback period ago, and the previous line, set the line to its low and set the state to neutral if the previous state was down, otherwise up. Otherwise, retain the previous line and state; if the retained state is neutral, change it to up if the state two bars ago was down, or to down if the state two bars ago was up. Use either the chart timeframe or a higher indicator timeframe. For the higher timeframe, evaluate at the start of each new indicator bar using a selectable signal bar: the last completed bar or an earlier completed bar, or the still-forming bar. The compared pair consists of that signal bar and the immediately preceding indicator bar.
Long: Indicator state on the preceding bar = down AND indicator state on the signal bar != down
Short: Indicator state on the preceding bar = up AND indicator state on the signal bar != up
Exit: long, indicator state on the preceding bar = up AND indicator state on the signal bar != up
Exit: short, indicator state on the preceding bar = down AND indicator state on the signal bar != down
Exit: long, low <= entry price - stop-loss distance OR high >= entry price + take-profit distance
Exit: short, high >= entry price + stop-loss distance OR low <= entry price - take-profit distance
