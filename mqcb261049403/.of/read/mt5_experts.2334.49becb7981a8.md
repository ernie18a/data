Calculation: Dynamic reversal state = On each bar of the configured indicator timeframe, initialize the line to the prior close and the state to neutral. If the current high is below the prior high, the high N bars earlier, and the prior line, set the line to the current high and the state to long unless the prior state was short, in which case set it to neutral. Otherwise, if the current low is above the prior low, the low N bars earlier, and the prior line, set the line to the current low and the state to short unless the prior state was long, in which case set it to neutral. Otherwise carry forward the prior line and state; if the carried state is neutral, set it to short when the state two bars earlier was long, or long when it was short. N is the indicator lookback. Evaluate the state on the last completed bar and compare it with the preceding bar, both on the configured indicator timeframe, which may be higher or lower than the chart timeframe.
Long: latest completed bar's state is long AND preceding bar's state is not long
Short: latest completed bar's state is short AND preceding bar's state is not short
Exit: long, latest completed bar's state is short AND preceding bar's state is not short
Exit: short, latest completed bar's state is long AND preceding bar's state is not long
