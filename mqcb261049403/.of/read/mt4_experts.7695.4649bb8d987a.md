Calculation: Gap threshold = (minimum gap size in points + current spread in points) × point size
Calculation: Long exit target = previous completed chart bar low at entry − current spread × point size
Calculation: Short exit target = previous completed chart bar high at entry + current spread × point size
Long: Current chart bar open < previous completed chart bar low − Gap threshold
Short: Current chart bar open > previous completed chart bar high + Gap threshold
Exit: long, chart bar high ≥ Long exit target
Exit: short, chart bar low ≤ Short exit target
