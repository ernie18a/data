Calculation: ADXm = with prev = previous bar; dh = max(high - prev high, 0); dl = max(prev low - low, 0); if dh == dl then dh = dl = 0, else set the smaller of the two to 0; tr = max(high, prev close) - min(low, prev close); dhk = 100*dh/tr and dlk = 100*dl/tr (0 if tr = 0); sdh = EMA(dhk, ADXm period) and sdl = EMA(dlk, ADXm period); DI = sdh - sdl; raw = 100*DI/|sdh + sdl| (0 if the denominator is 0); ADXm = EMA(raw, ADXm period), using the same period for all three EMAs.
Calculation: SmoothedADXm = Jurik smoothing of ADXm, with a smoothing period shorter than the ADXm period. It is computed on the chart timeframe, or optionally on a higher timeframe's bars, read on each chart bar from the still-forming higher-timeframe bar; the slope below is then between consecutive higher-timeframe bars.
Long: SmoothedADXm > SmoothedADXm of the previous bar (rising slope). If equal, keep the previous bar's long/short state.
Short: SmoothedADXm < SmoothedADXm of the previous bar (falling slope). If equal, keep the previous bar's long/short state.
