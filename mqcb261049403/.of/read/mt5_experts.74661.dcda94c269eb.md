Calculation: Stochastic = close-based stochastic oscillator with SMA slowing and an SMA signal line; use the current forming bar and previous completed bar of a selectable timeframe that may be the chart timeframe, higher, or lower. For exits, round %K and %D to the price's decimal precision minus one; for entries, use unrounded %D.
Long: position side is flat AND previous %D <= lower entry threshold AND current %D > lower entry threshold.
Short: position side is flat AND previous %D >= upper entry threshold AND current %D < upper entry threshold. The upper entry threshold is equally far above the stochastic midpoint as the lower entry threshold is below it.
Exit: long, the selected profit filter is satisfied AND either (previous %K >= previous %D AND current %K < current %D AND current %D > overbought threshold) OR (previous %D <= overbought threshold AND current %D > overbought threshold) OR (previous %D >= overbought threshold AND current %D < overbought threshold); select one of these three conditions as the closing mode.
Exit: short, the selected profit filter is satisfied AND either (previous %K <= previous %D AND current %K > current %D AND previous %D < oversold threshold) OR (previous %D >= oversold threshold AND current %D < oversold threshold) OR (previous %D <= oversold threshold AND current %D > oversold threshold); select the same closing mode as for long exits.
Calculation: Profit filter = select one of: loss only, profit only, or all positions. For a long position, loss means close < entry price and profit means close > entry price; for a short position, loss means close > entry price and profit means close < entry price. The all-positions selection includes equality.
