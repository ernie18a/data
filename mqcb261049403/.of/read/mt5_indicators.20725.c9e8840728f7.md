Calculation: Selected price = a configurable choice of close, open, high, low, (high+low)/2, (high+low+close)/3, (high+low+2*close)/4, (open+close)/2, (open+high+low+close)/4, trend price A, trend price B, or DeMark price. Trend price A is high if close > open, low if close < open, and close otherwise. Trend price B is (high+close)/2 if close > open, (low+close)/2 if close < open, and close otherwise. DeMark price is (high+low+close+X)/2-(high+low)/2, where X is low if close < open, high if close > open, and close otherwise.
Calculation: Variable-smoothing average = initialize with the first selected price; for each subsequent bar, set weight = minimum sensitivity + (maximum sensitivity - minimum sensitivity) * (1 - exp(-abs(selected price - previous average / E factor)^A factor)), then average = previous average + weight * (selected price - previous average).
Calculation: Average change = current variable-smoothing average - previous variable-smoothing average.
Calculation: Lower and upper filters = lower and higher configurable multipliers, respectively, times the population standard deviation of average change over a configurable lookback. Round average change and both filters to a configurable price precision before filter comparisons.
Calculation: Higher-timeframe values = calculate the same average, average change, and filters on a higher timeframe using its still-forming bar sampled at the first chart bar of each higher-timeframe bar; retain those sampled values until the next higher-timeframe bar.
Long: Current variable-smoothing average > previous variable-smoothing average OR rounded average change > lower filter OR higher-timeframe current average > higher-timeframe previous average OR higher-timeframe rounded average change > higher-timeframe lower filter.
Short: Current variable-smoothing average < previous variable-smoothing average OR rounded average change < -lower filter OR higher-timeframe current average < higher-timeframe previous average OR higher-timeframe rounded average change < -higher-timeframe lower filter.
