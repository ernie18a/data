Calculation: Directional scores = For each selected timeframe except the longest, compare the current bar with the preceding bar for open, high, low, close, (high + low) / 2, (high + low + close) / 3, and (high + low + 2 × close) / 4. Award one long vote when the current value is greater; otherwise award one short vote. Each score is the integer-truncated percentage of its votes out of all votes across the selected timeframes. Use the bar still forming for each timeframe, whether it is lower than, equal to, or higher than the chart timeframe.
Long: Long score > opening threshold
Short: Short score > opening threshold
Exit: long, long score < closing threshold
Exit: short, short score < closing threshold
