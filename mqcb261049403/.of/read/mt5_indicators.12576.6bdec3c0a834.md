Calculation: Ozymandias trend state = On each bar, let HH and LL be the highest high and lowest low over the same lookback, and let HMA and LMA be moving averages of highs and lows using the same lookback and averaging method. Initialize trend = 0, next trend = 0, max low = 0, and min high = 9999999. If next trend = 1, set max low to max(LL, max low); if HMA < max low AND close < prior bar low, set trend = 1, next trend = 0, and min high = HH. If next trend = 0, set min high to min(HH, min high); if LMA > min high AND close > prior bar high, set trend = 0, next trend = 1, and max low = LL. Carry these states forward bar by bar. Trend color is bearish for trend = 1 and bullish for trend = 0.
Long: On the first chart bar of a higher-timeframe bar, the Ozymandias trend color on the still-forming higher-timeframe bar changes from bearish on the prior higher-timeframe bar to bullish.
Short: On the first chart bar of a higher-timeframe bar, the Ozymandias trend color on the still-forming higher-timeframe bar changes from bullish on the prior higher-timeframe bar to bearish.
