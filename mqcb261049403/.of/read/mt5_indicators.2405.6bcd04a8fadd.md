Calculation: Smoothed oscillator pair = apply a selected moving-average method with a shorter period to the Accelerator Oscillator; apply the same method with a longer period to that result.
Calculation: Higher-timeframe difference = first value minus second value of the smoothed oscillator pair on the higher-timeframe bar still forming, sampled on its first chart bar and held until the next higher-timeframe bar.
Long: The first value of the chart-timeframe smoothed oscillator pair > the second value
Short: The first value of the chart-timeframe smoothed oscillator pair < the second value
Long: Higher-timeframe difference > 0 OR higher-timeframe difference = 0 AND its most recent nonzero value > 0
Short: Higher-timeframe difference < 0 OR higher-timeframe difference = 0 AND its most recent nonzero value < 0
