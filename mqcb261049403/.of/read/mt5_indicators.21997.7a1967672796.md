Calculation: Trend envelope = Use chart bars or higher-timeframe bars still forming. On each calculation bar, calculate population standard deviation of close over a deviation lookback; before enough bars exist, use available closes but retain the full lookback as the divisor. Calculate separate moving averages of high and low using the same smoothing period and a selectable simple, exponential, smoothed, or linear-weighted method; the smoothed average starts with the raw price on each of the first two bars. Set raw upper = high average + standard deviation multiplied by a factor, and raw lower = low average - standard deviation multiplied by the same factor. Initialize trend to neutral and both bounds to their raw values. On each later bar, set trend to up if close > previous upper bound, otherwise to down if close < previous lower bound, otherwise retain the previous trend. If trend is up, set lower bound to the greater of raw lower and previous lower bound; otherwise use raw lower. If trend is down, set upper bound to the lesser of raw upper and previous upper bound; otherwise use raw upper.
Long: Trend changes to up AND, when using a higher timeframe, the chart bar is the first bar of that higher-timeframe bar.
Short: Trend changes to down AND, when using a higher timeframe, the chart bar is the first bar of that higher-timeframe bar.
