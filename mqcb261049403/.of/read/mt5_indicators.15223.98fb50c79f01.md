Calculation: Ozymandias line = On each bar, calculate the moving average of highs and the moving average of lows over the same short lookback, and the highest high and lowest low over that lookback. Initialize the trend state and next-trend state to 0, the running maximum low to 0, the running minimum high to a value above all prices, and the line to its prior-bar value. In chronological order, if next-trend is 1, raise the running maximum low to at least the current lookback's lowest low; if the high moving average is below it and the close is below the prior bar's low, set trend to 1, next-trend to 0, and running minimum high to the current lookback's highest high. Then, if next-trend is 0, lower the running minimum high to at most the current lookback's highest high; if the low moving average is above it and the close is above the prior bar's high, set trend to 0, next-trend to 1, and running maximum low to the current lookback's lowest low. When trend is 0, carry forward the prior line if prior trend was 1; otherwise set the line to the greater of the running maximum low and prior line. When trend is 1, carry forward the prior line if prior trend was 0; otherwise set the line to the lesser of the running minimum high and prior line. Use the chart timeframe; in the higher-timeframe variant, use the selected higher timeframe's bar still forming.
Long: Current Ozymandias line change (current line minus prior bar's line), rounded to symbol precision plus two digits, > the multiplier parameter × population standard deviation of Ozymandias line changes over the lookback including the current change, rounded to symbol precision plus two digits.
Short: Current Ozymandias line change (current line minus prior bar's line), rounded to symbol precision plus two digits, < −1 × the multiplier parameter × population standard deviation of Ozymandias line changes over the lookback including the current change, rounded to symbol precision plus two digits.
