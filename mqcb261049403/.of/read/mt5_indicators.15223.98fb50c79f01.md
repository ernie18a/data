Calculation: Trend line = On each bar, calculate the highest high and lowest low over a shared lookback and moving averages of high and low using the same lookback and method. Initialize trend as up, the next-switch state as seeking an up switch, the running low as zero, and the running high as a large sentinel. When seeking a down switch, raise the running low to the maximum of itself and the current lowest low; if the high moving average is below the running low AND close is below the previous bar's low, switch trend down, seek an up switch, and set the running high to the current highest high. Then, if seeking an up switch, lower the running high to the minimum of itself and the current highest high; if the low moving average is above the running high AND close is above the previous bar's high, switch trend up, seek a down switch, and set the running low to the current lowest low. On a trend switch, the line equals its previous value; otherwise, in an up trend it equals the maximum of the running low and its previous value, and in a down trend it equals the minimum of the running high and its previous value. Initialize the previous line value to zero.
Calculation: Line direction = Up when the trend line rises, down when it falls, and otherwise the previous line direction; initialize as neutral.
Calculation: Increment filter = A multiplier times the population standard deviation of trend-line changes over a lookback. Round both the current trend-line change and the filter to the same configurable price precision before comparing them.
Long: Line direction is up.
Short: Line direction is down.
Long: Current trend-line change > increment filter.
Short: Current trend-line change < negative increment filter.
Calculation: Higher-timeframe decisions = Apply the same trend-line, direction, and increment-filter calculations to a higher timeframe using its bar still forming; carry its latest result across chart bars until the next higher-timeframe bar begins.
