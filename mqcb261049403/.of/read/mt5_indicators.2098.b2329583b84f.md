Calculation: Step state = Process chart bars chronologically. On the first eligible bar, initialize the previous upper and lower bands to that bar's close, the previous trend to 0, and the running maximum and minimum range averages to negative and positive infinity. An eligible bar has enough preceding bars for the range lookback and initialization. For each bar, calculate the mean high minus low over the range lookback and update its running maximum and minimum. If the fixed-step parameter is zero, step = integer truncation of (sensitivity × (running maximum + running minimum) / (2 × price increment)), multiplied by the price increment; otherwise step = integer truncation of (sensitivity × fixed-step parameter), multiplied by the price increment. Set the candidate upper band to close + 2 × step and the candidate lower band to close − 2 × step; in high/low mode use low + 2 × step and high − 2 × step instead. Start with the previous trend; set it to +1 if close > previous upper band, then set it to −1 if close < previous lower band. If trend > 0, set the lower band to the maximum of its candidate and previous value and keep the upper band at its candidate; otherwise set the upper band to the minimum of its candidate and previous value and keep the lower band at its candidate. The bullish line is the lower band when trend > 0, otherwise 0; the bearish line is the upper band when trend ≤ 0, otherwise 0.
Calculation: Higher-timeframe Step state = The same Step state calculated on higher-timeframe bars, using the bar still forming. On the first chart bar of each higher-timeframe bar, use its current Step state; on subsequent chart bars retain the state captured on that first chart bar. Historical display can change as the higher-timeframe bar develops.
Long: Bullish line > 0
Short: Bearish line > 0
Long: Previous bullish line > 0 AND current bearish line > 0
Short: Previous bearish line > 0 AND current bullish line > 0
Long: Higher-timeframe bullish line > 0
Short: Higher-timeframe bearish line > 0
Long: First chart bar of a higher-timeframe bar AND previous higher-timeframe bearish line > 0 AND current higher-timeframe bullish line > 0
Short: First chart bar of a higher-timeframe bar AND previous higher-timeframe bullish line > 0 AND current higher-timeframe bearish line > 0
