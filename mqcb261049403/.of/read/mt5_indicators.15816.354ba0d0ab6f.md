Calculation: Applied price = a selected OHLC price or combination: open, high, low, close, (high + low)/2, (high + low + close)/3, (high + low + 2 × close)/4, (open + close)/2, or (open + high + low + close)/4; alternatively, select high, low, or close when close is respectively above, below, or equal to open; select (high + close)/2, (low + close)/2, or close under the same respective conditions; or calculate ((high + low + close + X)/2) - (high + low)/2, where X is low if close < open, high if close > open, and close otherwise.
Calculation: Adaptive average = for a lookback of N applied prices, set range = maximum - minimum and L = the sum over adjacent prices in the lookback of sqrt(((price - preceding price)/range)^2 + (1/N)^2) when range > 0; otherwise set L = 0. Set D = 1 + ln(2 × L)/ln(2 × (N - 1)) when L > 0, otherwise D = 0. Set H = 2 - D, replacing H with 2 if H = 0. Set the averaging length to round(speed/(2 × H)), bounded to at least 1 and at most the available rolling-buffer capacity. The adaptive average is the simple average of that many most recent applied prices.
Calculation: Higher-timeframe adaptive average = adaptive average calculated on the higher timeframe's still-forming bar at the first chart bar of each higher-timeframe bar and retained until the next higher-timeframe bar; compare it with the preceding higher-timeframe bar's adaptive average. The alert conditions use a selected chart-bar offset of these retained comparisons.
Long: Chart-timeframe adaptive average > its previous-bar value
Short: Chart-timeframe adaptive average < its previous-bar value
Long: Higher-timeframe adaptive average > its preceding higher-timeframe-bar value
Short: Higher-timeframe adaptive average < its preceding higher-timeframe-bar value
Long: At the selected chart-bar offset, higher-timeframe adaptive average < its preceding higher-timeframe-bar value
Short: At the selected chart-bar offset, higher-timeframe adaptive average = its preceding higher-timeframe-bar value
