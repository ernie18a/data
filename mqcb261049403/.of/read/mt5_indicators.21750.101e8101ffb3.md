Calculation: Money Flow Index (MFI) = MFI calculated from bar prices and volume.
Calculation: Smoothed MFI lines = MFI smoothed using a family of lookbacks that increase by a constant step from shortest to longest.
Calculation: Rising count = number of smoothed MFI lines whose current value is greater than their previous-bar value.
Calculation: Falling count = number of smoothed MFI lines whose current value is less than or equal to their previous-bar value.
Calculation: Bull line = rising count smoothed over time.
Calculation: Bear line = falling count smoothed over time.
Long: Bull line > Bear line
Short: Bear line > Bull line
