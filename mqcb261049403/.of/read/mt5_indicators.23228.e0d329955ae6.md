Calculation: Selected price = a configurable choice of close, open, high, low, (high+low)/2, (high+low+close)/3, (high+low+2*close)/4, (open+close)/2, (open+high+low+close)/4, trend-following price, half trend-following price, or DeMark price. Trend-following price is high if close>open, low if close<open, otherwise close. Half trend-following price is (high+close)/2 if close>open, (low+close)/2 if close<open, otherwise close. DeMark price is (high+low+close+X-high-low)/2, where X is low if close<open, high if close>open, otherwise close.
Calculation: Volume-weighted Fisher oscillator = for each bar, take the highest high and lowest low over the configured lookback including the current bar; calculate v=(selected price-lowest low)/(highest high-lowest low)-0.5+0.67*previous v, initialized to zero. Calculate r=(1+v)/(1-v), replacing r with 1 if r<0.0000001; calculate f=0.5*ln(r)+0.5*previous f, initialized to zero. Apply a configurable smoothing method and its parameters to f*volume and multiply by 100. Apply the same smoothing method and parameters separately to volume to obtain smoothed volume.
Long: Volume-weighted Fisher oscillator > upper threshold * smoothed volume AND volume-weighted Fisher oscillator >= previous bar's volume-weighted Fisher oscillator
Long: Previous bar's volume-weighted Fisher oscillator < 0 AND volume-weighted Fisher oscillator >= 0
Short: Volume-weighted Fisher oscillator < lower threshold * smoothed volume AND volume-weighted Fisher oscillator <= previous bar's volume-weighted Fisher oscillator
Short: Previous bar's volume-weighted Fisher oscillator > 0 AND volume-weighted Fisher oscillator <= 0
