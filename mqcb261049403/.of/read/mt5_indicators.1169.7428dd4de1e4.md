Calculation: Filtered NonLagMA = On the chart timeframe, or on the selected higher timeframe projected onto chart bars (use its still-forming bar when present), compute a weighted mean of the configured applied price over Length bars. For i = 0…N−1, where N = 5×Length−1, let phase = Length−1; set t = i/(phase−1) if i ≤ phase−1, otherwise t = 1 + (i−phase+1)×7/(4×Length−1); set g = 1 if t ≤ 0.5, otherwise 1/(3πt+1); use weight g×cos(πt), and divide the weighted sum by the sum of weights. Then, if PctFilter > 0 and the previous line value is positive, hold the previous value when the absolute line change is less than PctFilter times the population standard deviation of the last Length absolute line changes; otherwise, if PointFilter > 0, hold the previous value when the absolute line change is less than PointFilter times the instrument point-to-pip scale.
Long: Filtered NonLagMA > its previous value
Short: Filtered NonLagMA < its previous value
