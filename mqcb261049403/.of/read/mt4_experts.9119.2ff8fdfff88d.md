Calculation: Bar index 0 is the chart bar still forming when a new chart bar starts; index 1 is the last completed chart bar. The additional timeframe used by ADX and optional multi-timeframe filters may be higher or lower than the chart timeframe; use its bar still forming.
Calculation: Weighted price = (high + low + 2 × close) / 4.
Calculation: Perceptron = w1 × (LWMA of close at index 0 − LWMA of weighted price at index p) + w2 × (LWMA of weighted price at index p − its value at index 2p) + w3 × (its value at index 2p − its value at index 3p) + w4 × (its value at index 3p − its value at index 4p) + bias. Each perceptron has its own weights, bias, LWMA length and spacing p.
Calculation: Price retracement state starts at 0. At each evaluation, find the highest high H and lowest low L over a lookback ending at index 1. Set the state to 1 if close[1] > H − r × (H − L), then set it to −1 if close[1] < L + r × (H − L); otherwise retain its previous value.
Calculation: Moving-average retracement state starts at 0. At each evaluation, find the highest H and lowest L of the weighted-price LWMA over a lookback ending at index 1. Set the state to 1 if close[1] > H − r × (H − L); otherwise set it to −1 if close[1] < L + r × (H − L); otherwise retain its previous value.
Calculation: Box direction starts at 0. Process a lookback of completed closes from oldest to newest, initializing upper and lower boundaries to the oldest close. If a close exceeds the upper boundary plus box size, set direction to 1, upper boundary to that close and lower boundary to that close minus box size. If a close is below the lower boundary minus box size, set direction to −1, lower boundary to that close and upper boundary to that close plus box size. Record direction immediately before processing the most recent completed close as previous box direction.
