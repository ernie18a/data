Calculation: Volume-scaled oscillator state = On bars of the configured indicator timeframe, which may be higher or lower than the chart timeframe, calculate Bulls Power + Bears Power as high + low − 2 × EMA(close); smooth this sum through four recursive stages: L0=(1−gamma)×input+gamma×previous L0, then each next stage Lk=−gamma×L(k−1)+previous L(k−1)+gamma×previous Lk. Let CU be the sum of the positive adjacent differences among L0–L3 and CD the sum of the absolute negative adjacent differences; oscillator=(CU+CD>0 ? 100×CU/(CU+CD)−50 : −50)×selected volume, then apply the configured moving average. Apply the same moving average to selected volume. Define upper and lower levels as their configured level multipliers times smoothed volume. State=0 if oscillator>upper level 2; else 1 if oscillator>upper level 1; else 4 if oscillator<lower level 2; else 3 if oscillator<lower level 1; else 2. Use the two latest completed indicator-timeframe bars.
Long: latest state=1 AND preceding state>1 OR latest state=0 AND preceding state>0
Short: latest state=3 AND preceding state<3 OR latest state=4 AND preceding state<4
Exit: long, latest state=3 OR latest state=4
Exit: short, latest state=1 OR latest state=0
