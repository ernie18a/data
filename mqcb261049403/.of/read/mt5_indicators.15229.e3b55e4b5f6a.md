Calculation: RVI = On the higher timeframe’s still-forming bar, divide the sum of the last Length values of (close−open + 2×previous (close−open) + 2×(close−open) two bars ago + (close−open) three bars ago)/6 by the corresponding sum calculated using high−low; use 0 if the denominator is 0
Calculation: Trigger = RVI from the previous higher-timeframe bar
Long: RVI > Trigger
Short: RVI < Trigger
