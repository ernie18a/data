Calculation: Rank correlation = For a configurable indicator timeframe, which may be higher than, lower than, or the same as the chart timeframe, use either its last completed bar or its still-forming bar as the signal bar; the previous value uses the immediately preceding indicator bar. For each value, take the signal bar and a configurable number of consecutive earlier closes, newest first. Multiply each close by a configurable price precision factor and truncate to an integer. Sort these integers descending or ascending according to a configurable direction. Assign ranks starting at 1 in sorted order; assign tied values their average rank, but after processing each tied group skip the immediately following sorted position when searching for further tied groups. Map ranks back to the newest-first closes. The result is 1 - 6 × sum((rank at index i - i - 1)²) / (N³ - N), with i starting at 0 and N the lookback length.
Long: Position side = flat AND ((entry mode = zero breakout AND rank correlation > 0 AND previous rank correlation <= 0) OR (entry mode = extreme zone AND rank correlation > 0 AND rank correlation > upper threshold AND (previous rank correlation <= 0 OR previous rank correlation <= upper threshold)))
Short: Position side = flat AND ((entry mode = zero breakout AND rank correlation < 0 AND previous rank correlation >= 0) OR (entry mode = extreme zone AND rank correlation < 0 AND rank correlation < lower threshold AND (previous rank correlation >= 0 OR previous rank correlation >= lower threshold)))
Exit: long, (exit mode = zero breakout AND rank correlation < 0) OR (exit mode = extreme zone AND rank correlation < 0 AND rank correlation < lower threshold) OR low <= entry price - stop-loss distance OR high >= entry price + take-profit distance
Exit: short, (exit mode = zero breakout AND rank correlation > 0) OR (exit mode = extreme zone AND rank correlation > 0 AND rank correlation > upper threshold) OR high >= entry price + stop-loss distance OR low <= entry price - take-profit distance
