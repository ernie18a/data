Calculation: Skyscraper state = Process bars chronologically. Initialize the prior lower and upper bounds to the first processed close and the prior direction to neutral. For each bar, set step to the price increment multiplied by truncation toward zero of sensitivity × (highest ATR + lowest ATR) / (2 × price increment), using the highest and lowest ATR over a configurable lookback including the current bar. Set candidate lower to high − 2 × step and candidate upper to low + 2 × step; alternatively use close in place of both high and low. Start with the prior direction; set it to long if close > prior upper bound, then set it to short if close < prior lower bound. If direction is long, set lower bound to max(candidate lower, prior lower bound) and upper bound to candidate upper. Otherwise, set upper bound to min(candidate upper, prior upper bound) and lower bound to candidate lower. For the next bar, replace the upper bound with the largest representable value after a long bar, or the lower bound with the smallest positive representable value after any other bar. Retain the resulting direction. The neutral direction is treated as short for markings.
Calculation: Higher-timeframe Skyscraper state = Apply the same calculation to higher-timeframe bars, using the bar still forming. Associate its state with the first chart bar in that higher-timeframe bar and carry it across the remaining chart bars in the same higher-timeframe bar.
Long: Skyscraper state = long OR higher-timeframe Skyscraper state = long
Short: Skyscraper state = short or neutral OR higher-timeframe Skyscraper state = short or neutral
