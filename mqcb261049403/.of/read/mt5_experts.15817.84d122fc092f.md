Calculation: Applied price = selectable open, high, low, close, median price, typical price, weighted close, (open + close)/2, (open + high + low + close)/4, trend-following price, or DeMark price. Trend-following price is selectable as high if close > open, low if close < open, otherwise close; or (high + close)/2 if close > open, (low + close)/2 if close < open, otherwise close. DeMark price is (X - low + X - high)/2, where X is (high + low + close + low)/2 if close < open, (high + low + close + high)/2 if close > open, otherwise (high + low + 2 × close)/2.
Calculation: Fractal adaptive average = for each bar, take the applied prices of a lookback of N bars, newest first; normalize each as z[i] = (price[i] - minimum)/(maximum - minimum). If the range is zero, set length to zero; otherwise length = sum for i = 1 through N-1 of sqrt((z[i] - z[i-1])² + 1/N²). Set dimension = 1 + ln(2 × length)/ln(2 × (N-1)) if length > 0, otherwise zero. Set divisor = 2 - dimension, replacing zero with 2. Set averaging length = clamp(round(speed parameter/(2 × divisor)), 1, 10000); average that many most recent applied prices. Calculate on the chart timeframe for the indicator markings. For the expert's decisions, calculate on the selectable indicator timeframe, which may be higher or lower than the chart timeframe; use the last completed bar by default, or the still-forming bar or an earlier completed bar when the signal-bar setting selects it.
Long: Fractal adaptive average on the chart bar > its previous value.
Short: Fractal adaptive average on the chart bar < its previous value.
Long: Selected indicator-bar fractal adaptive average > its previous value AND its previous value <= its value two indicator bars earlier.
Short: Selected indicator-bar fractal adaptive average < its previous value AND its previous value >= its value two indicator bars earlier.
Exit: long, selected indicator-bar fractal adaptive average < its previous value.
Exit: short, selected indicator-bar fractal adaptive average > its previous value.
Exit: long, stop loss enabled AND low <= entry price - stop distance OR take profit enabled AND high >= entry price + target distance.
Exit: short, stop loss enabled AND high >= entry price + stop distance OR take profit enabled AND low <= entry price - target distance.
