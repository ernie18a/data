Calculation: Trend lines = On the chart timeframe, calculate midpoint = (high + low) / 2, lower band = midpoint − ATR × multiplier, and upper band = midpoint + ATR × multiplier. Process bars chronologically with phase initially neutral and both prior lines initially zero. Set both current lines to zero; in the neutral phase set both to midpoint. If phase is not long, the previous bearish line is nonzero, and close > previous bearish line, set phase to long and the current bullish line to the lower band. If phase is not short, the previous bullish line is nonzero, and close < previous bullish line, set phase to short and the current bearish line to the upper band. Evaluate these two transitions in that order. On a transition, in SuperTrend and NewWay modes also copy the opposite previous line into the previous line for the new phase; in Visual mode copy the opposite previous line into the current opposite line. In long phase, if the mode is not SuperTrend or the bullish line two bars ago is nonzero, set the current bullish line to the lower band if the lower band > previous bullish line or the current bullish line is nonzero and the mode is Visual or ExpertSignal; otherwise set it to the previous bullish line. In short phase, if the mode is not SuperTrend or the bearish line two bars ago is nonzero, set the current bearish line to the upper band if the upper band < previous bearish line or the current bearish line is nonzero and the mode is Visual or ExpertSignal; otherwise set it to the previous bearish line. Treat zero as absent.
Calculation: Higher-timeframe trend lines = Calculate the same trend lines on a higher timeframe using the bar still forming; sample their values on the first chart bar of each higher-timeframe bar and carry those values forward until the next higher-timeframe bar.
Long: Chart-timeframe bullish trend line is nonzero OR higher-timeframe bullish trend line is nonzero.
Short: Chart-timeframe bearish trend line is nonzero OR higher-timeframe bearish trend line is nonzero.
