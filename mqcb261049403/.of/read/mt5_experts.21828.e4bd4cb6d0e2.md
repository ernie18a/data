Calculation: Trend Intensity Index = clamp(100 × smoothed positive deviation / (smoothed positive deviation + smoothed negative deviation), 0, 100); positive deviation is selected price minus its moving average when positive, otherwise 0; negative deviation is the moving average minus selected price when positive, otherwise 0; if the denominator is 0, the index is 100. Apply the configured smoothing to both deviations. Use the configured indicator timeframe (higher, equal to, or lower than the chart timeframe) and the last completed bars.
Long: Trend Intensity Index > overbought threshold AND the preceding completed bar's Trend Intensity Index ≤ overbought threshold
Short: Trend Intensity Index < oversold threshold AND the preceding completed bar's Trend Intensity Index ≥ oversold threshold
Exit: long, Trend Intensity Index < oversold threshold AND the preceding completed bar's Trend Intensity Index ≥ oversold threshold OR bar low ≤ entry price − stop distance OR bar high ≥ entry price + target distance
Exit: short, Trend Intensity Index > overbought threshold AND the preceding completed bar's Trend Intensity Index ≤ overbought threshold OR bar high ≥ entry price + stop distance OR bar low ≤ entry price − target distance
