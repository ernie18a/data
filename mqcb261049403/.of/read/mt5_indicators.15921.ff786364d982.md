Calculation: Box boundaries = Process bars chronologically in a repeating five-phase cycle. Initialize the top and bottom to the high and low of the bar immediately before the first processed bar; start processing after a number of earlier bars equal to the channel shift plus one. In phase one, set the top to the current high and, if symmetry is enabled, set the bottom to the current low. In phase two, set the top to the current high if the high is at least the top. In phase three, set the bottom to the current low if the high is below the top; otherwise set the top to the current high. In phases four and five, if the high is below the top, set the bottom to the current low when the low is at most the bottom; otherwise set the top to the current high. After phase five, return to phase one. For each decision, use the boundaries from the bar a configurable channel shift earlier. Calculate either on the chart timeframe or on a higher timeframe using the bar still forming; in the higher-timeframe version, apply its decision to the chart bars within that higher-timeframe bar.
Long: Close of the calculation timeframe > shifted box top AND close of the calculation timeframe >= shifted box bottom
Short: Close of the calculation timeframe < shifted box bottom
