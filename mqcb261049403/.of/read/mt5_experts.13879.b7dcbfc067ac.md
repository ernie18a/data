Calculation: Jurik-smoothed deviation oscillator = for a chosen bar price, subtract its Jurik moving average, apply the same JurX smoothing to the deviation and its absolute value, divide the former by the latter, and clamp the result to [-1, 1]; treat a zero denominator as undefined. JurX smoothing uses three cascaded stages, each consisting of two sequential exponential updates with coefficient 3 / (smoothing length + 2), followed by 1.5 times the first update minus 0.5 times the second; initialize both updates in each stage to its first input.
Calculation: Cycle oscillator = subtract the longer-moving-average-length Jurik-smoothed deviation oscillator from the shorter-moving-average-length one, with the same smoothing length and phase; normalize that difference to its rolling minimum and maximum over the cycle lookback and scale to [0, 100], retaining the previous normalized value when the range is zero. Smooth the result recursively with weight 0.5, normalize the smoothed values over the same lookback to [-100, 100], retaining the previous cycle oscillator when the range is zero, and smooth recursively with weight 0.5.
