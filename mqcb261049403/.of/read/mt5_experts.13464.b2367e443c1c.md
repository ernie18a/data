Calculation: RSI trend cycle = On the indicator timeframe, subtract the longer-period RSI of the selected OHLC-derived price from the shorter-period RSI. Normalize that difference to 0–100 using its rolling minimum and maximum over the cycle lookback; if the range is zero, use the previous smoothed first-stage value. Smooth the result as previous smoothed value + 0.5 × (raw value − previous smoothed value). Normalize the smoothed values over the same lookback to −100–100; if the range is zero, use the previous cycle value. Apply the same recursive smoothing to obtain the cycle. The indicator timeframe may be higher, lower, or the same as the chart timeframe; evaluate the last completed indicator bar by default, or a configurable earlier bar or the still-forming bar, and compare it with its preceding indicator bar.
Long: RSI trend cycle > 0 AND RSI trend cycle > upper threshold AND (previous RSI trend cycle <= 0 OR previous RSI trend cycle <= upper threshold)
Short: RSI trend cycle < 0 AND RSI trend cycle < lower threshold AND (previous RSI trend cycle >= 0 OR previous RSI trend cycle >= lower threshold)
Exit: long, (RSI trend cycle < 0 AND RSI trend cycle < lower threshold) OR low <= entry price − stop-loss distance OR high >= entry price + take-profit distance
Exit: short, (RSI trend cycle > 0 AND RSI trend cycle > upper threshold) OR high >= entry price + stop-loss distance OR low <= entry price − take-profit distance
