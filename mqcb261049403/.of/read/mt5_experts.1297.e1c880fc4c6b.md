Calculation: Stepped RSI line = On the indicator timeframe, calculate RSI of close. For each step size independently, initialize the previous upper band to negative infinity, previous lower band to positive infinity, and trend to neutral. On each bar set upper = RSI + 2 × step size and lower = RSI − 2 × step size. If RSI > previous upper, set trend positive; if RSI < previous lower, set trend negative; otherwise retain the previous trend. If trend is positive, set lower = max(lower, previous lower) and the line = lower + step size. If trend is negative, set upper = min(upper, previous upper) and the line = upper − step size. Carry both bands and trend forward. The fast line has a smaller step size than the slow line. The indicator timeframe can be higher or lower than the chart timeframe; evaluate the selected completed indicator bar and its predecessor, or the still-forming indicator bar and its predecessor when configured for a forming-bar signal.
Long: fast line > slow line AND previous fast line <= previous slow line
Short: fast line < slow line AND previous fast line >= previous slow line
Exit: long, fast line < slow line OR low <= entry price − stop-loss distance OR high >= entry price + take-profit distance
Exit: short, fast line > slow line OR high >= entry price + stop-loss distance OR low <= entry price − take-profit distance
