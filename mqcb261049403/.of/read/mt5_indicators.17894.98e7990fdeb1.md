Calculation: Close-based parabolic value = Process bars chronologically using close as both the high and low input. Initialize on the second bar with extreme = close, previous parabolic value = close, acceleration = 0, direction = short, last high = 0, and last low = 999999999. Starting with the third bar, calculate candidate = previous parabolic value + acceleration × (extreme − previous parabolic value). In the long direction: if extreme < close and acceleration + lower-side step ≤ lower-side maximum, increase acceleration by the lower-side step; if candidate ≥ close, set direction to short, acceleration to the lower-side step, extreme and last low to close, and parabolic value to max(close, last high); otherwise, again increase acceleration by the lower-side step if extreme < close and the maximum permits it, update extreme and last high to close if extreme < close, and set parabolic value to candidate. In the short direction: if extreme > close and acceleration + upper-side step ≤ upper-side maximum, increase acceleration by the upper-side step; if candidate ≤ close, set direction to long, acceleration to the upper-side step, extreme and last high to close, and parabolic value to min(close, last low); otherwise, again increase acceleration by the upper-side step if extreme > close and the maximum permits it, update extreme and last low to close if extreme > close, and set parabolic value to candidate. Cap each step input at its corresponding maximum. Carry the resulting state and parabolic value forward to the next bar.
Calculation: Higher-timeframe parabolic comparison = Apply the same close-based parabolic calculation to a higher timeframe using its bar still forming. Sample whether its close is below its parabolic value at the first chart bar of each higher-timeframe bar and carry that comparison forward until the next higher-timeframe bar.
Long: Chart close ≥ chart close-based parabolic value OR higher-timeframe parabolic comparison is false.
Short: Chart close < chart close-based parabolic value OR higher-timeframe parabolic comparison is true.
