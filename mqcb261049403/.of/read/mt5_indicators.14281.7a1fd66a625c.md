Calculation: Filtered weighted price = for a selected OHLC-derived price series and smoothing length L, set P=L-1 and N=4L+P. For lag i=0 to N-1, start t=0, calculate w_i=cos(pi*t) times 1 if t<=0.5, otherwise 1/(3*pi*t+1); after each lag, increase t by 1/(P-1) if t<1, otherwise by 7/(4L-1) if t<N-1. The raw value is sum(w_i*price[i])/abs(sum(w_i)), or the previous filtered value if the weight sum is zero. If the absolute difference between the raw value and previous filtered value is less than the price-distance filter, use the previous filtered value; otherwise use the raw value. Initialize the previous value to the close of bar N, counting from zero.
Calculation: Dot direction = long if the filtered weighted price exceeds its previous value by more than the price-distance filter, short if it is below its previous value by more than the filter, and otherwise the preceding dot direction; initialize direction to long. The selected price series can be open, high, low, close, (high+low)/2, (high+low+close)/3, (high+low+2*close)/4, (open+close)/2, (open+high+low+close)/4, high when close>open and low when close<open and close otherwise, (high+close)/2 when close>open and (low+close)/2 when close<open and close otherwise, or (close+X)/2 where X is low when close<open, high when close>open, and close otherwise.
Calculation: Smoothed candle open and close = filtered weighted prices calculated separately from open and close using the same smoothing length and filter.
Calculation: Higher-timeframe smoothed candle open and close = smoothed candle open and close calculated on the higher-timeframe bar still forming at the first chart bar of that higher-timeframe period, then held constant for the period.
Long: dot direction = long
Short: dot direction = short
Long: smoothed candle close > smoothed candle open
Short: smoothed candle close < smoothed candle open
Long: higher-timeframe smoothed candle close >= higher-timeframe smoothed candle open
Short: higher-timeframe smoothed candle close < higher-timeframe smoothed candle open
