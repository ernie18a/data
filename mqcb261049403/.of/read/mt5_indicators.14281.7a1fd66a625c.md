Calculation: Dots(price) = For each bar, calculate a weighted average of the last 5L-1 values of the selected price, where L is the smoothing lookback. Set t=0 and, for each value in order from newest to oldest, use weight cos(pi*t) when t<=0.5, otherwise cos(pi*t)/(3*pi*t+1). After each value, increase t by 1/(L-2) while t<1, otherwise by 7/(4L-1). Divide the weighted sum by the absolute sum of weights; if that sum is zero, use the previous Dots value. If the change from the previous value is smaller than the filter threshold, retain the previous value.
Long: Dots(close) - previous Dots(close) > filter threshold OR Dots(close) > Dots(open) OR higher-timeframe Dots(close) > higher-timeframe Dots(open), using the still-forming higher-timeframe bar
Short: previous Dots(close) - Dots(close) > filter threshold OR Dots(close) < Dots(open) OR higher-timeframe Dots(close) < higher-timeframe Dots(open), using the still-forming higher-timeframe bar
