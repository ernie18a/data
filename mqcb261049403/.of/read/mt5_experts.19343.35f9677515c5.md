Calculation: ATR trailing state = On the chosen indicator timeframe, which may be higher or lower than the chart timeframe, calculate ATR and process bars chronologically. Initialize trend, upward stop, and downward stop to zero. For each bar t, let distance = ATR[t] multiplied by a coefficient, and start with the preceding stops and trend. If trend <= 0 AND low[t-1] > downward stop[t-1], replace upward stop[t-1] with low[t-1] - distance and set trend to 1. Then, if trend >= 0 AND high[t-1] < upward stop[t-1], replace downward stop[t-1] with high[t-1] + distance and set trend to -1. Set both stops at t to zero; if trend >= 0, set upward stop[t] to low[t-1] - distance when low[t-1] > upward stop[t-1] + distance, otherwise to upward stop[t-1]. If trend <= 0, set downward stop[t] to high[t-1] + distance when high[t-1] < downward stop[t-1] - distance, otherwise to downward stop[t-1]. Compare the resulting trend with the preceding completed indicator bar's trend. Evaluate the indicator on a selectable signal bar: the still-forming bar or a specified completed bar, including the last completed bar.
Calculation: Trading interval membership = If start hour < end hour, membership holds when (hour = start hour AND minute >= start minute) OR (hour > start hour AND hour < end hour) OR (hour = end hour AND minute < end minute). If start hour = end hour, membership holds when hour = start hour AND minute >= start minute AND minute < end minute. If start hour > end hour, membership holds when (hour >= start hour AND minute >= start minute) OR hour < end hour OR (hour = end hour AND minute < end minute).
Long: Indicator trend > 0 AND preceding indicator trend <= 0 AND upward stop != 0 AND (time filter disabled OR trading interval membership = true)
Short: Indicator trend < 0 AND preceding indicator trend >= 0 AND downward stop != 0 AND (time filter disabled OR trading interval membership = true)
Exit: long, downward stop != 0 OR (time filter enabled AND trading interval membership = false) OR low <= entry price - stop-loss distance OR high >= entry price + take-profit distance
Exit: short, upward stop != 0 OR (time filter enabled AND trading interval membership = false) OR high >= entry price + stop-loss distance OR low <= entry price - take-profit distance
