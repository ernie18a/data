Calculation: Brake state and level = On the third-oldest available chart bar, initialize the state to rising, the anchor to that bar's low, the anchor bar to that bar, and the running high and low to negative and positive infinity. On each bar in chronological order, first update the running high and low with the bar's high and low. Let distance = (exp(elapsed bars since the anchor bar × exponential rate) − 1) × price-distance scale. In the rising state, the level is anchor + distance; if the level > current low, switch to falling, set the anchor and level to the running high, set the anchor bar to the current bar, and reset the running high and low to negative and positive infinity. In the falling state, the level is anchor − distance; if the level < current high, switch to rising, set the anchor and level to the running low, set the anchor bar to the current bar, and reset the running high and low to negative and positive infinity. At most one switch occurs per bar. For the Expert Advisor, calculate this on a configurable indicator timeframe, which may be the chart timeframe or a higher or lower timeframe; use a configurable indicator bar, which may be the forming bar or a completed bar.
Long: Previous indicator bar's state = falling AND previous level > 0 AND current indicator bar's state = rising AND current level > 0
Short: Previous indicator bar's state = rising AND previous level > 0 AND current indicator bar's state = falling AND current level > 0
Exit: long, indicator state = falling AND indicator level != 0
Exit: short, indicator state = rising AND indicator level != 0
Exit: long, low <= entry price − stop-loss distance OR high >= entry price + take-profit distance
Exit: short, high >= entry price + stop-loss distance OR low <= entry price − take-profit distance
