Calculation: Applied price = a selectable price series: open, high, low, (high + low)/2, (high + low + close)/3, (high + low + 2*close)/4, close, (open + close)/2, (open + high + low + close)/4, high if close > open else low if close < open else close, (high + close)/2 if close > open else (low + close)/2 if close < open else close, or DeMark price where x = (high + low + close + (low if close < open else high if close > open else close))/2 and price = x - (high + low)/2.
Calculation: Forecast oscillator = 100*(current applied price - W)/W, where W = 6/(L*(L+1)) times the sum over i = 1 to L of (i - (L+1)/3)*applied price from L-i bars ago.
Calculation: Smoothed forecast oscillator = -b^3*E6 + 3*(b^2+b^3)*E5 - 3*(2*b^2+b+b^3)*E4 + (1+3*b+3*b^2+b^3)*E3, where E1 through E6 are six successive recursive exponential averages, each with smoothing coefficient 2/(1 + (1 + (T-1)/2)), initialized to zero; E1 averages the forecast oscillator and each subsequent average takes the current value of the preceding average. Start calculation after L+2 chart bars.
Calculation: The oscillator pair is calculated either on the chart timeframe or on a higher timeframe. For the higher timeframe, sample the still-forming higher-timeframe bar at the first chart bar in that interval and retain that sample for the interval; historical recalculation instead samples the completed higher-timeframe bar.
Long: Forecast oscillator > smoothed forecast oscillator.
Short: Forecast oscillator < smoothed forecast oscillator.
