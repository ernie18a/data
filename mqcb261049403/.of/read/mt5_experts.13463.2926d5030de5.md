Calculation: Momentum cycle = On the higher timeframe, use the last completed bar and a configurable applied price. Subtract longer-lookback Momentum from shorter-lookback Momentum. Normalize this difference over the cycle lookback to 0–100; if its range is zero, use the previous smoothed first-stage value. Smooth recursively with factor 0.5. Normalize the smoothed values over the same cycle lookback to −100–100; if their range is zero, use the previous cycle value. Smooth the result recursively with factor 0.5. Initialize both rolling windows and the previous cycle value to zero; do not smooth the first calculated value of either stage.
Long: Momentum cycle > 0 AND Momentum cycle > upper level AND (previous Momentum cycle <= 0 OR previous Momentum cycle <= upper level)
Short: Momentum cycle < 0 AND Momentum cycle < lower level AND (previous Momentum cycle >= 0 OR previous Momentum cycle >= lower level)
Exit: long, (Momentum cycle < 0 AND Momentum cycle < lower level) OR low <= entry price − stop-loss distance OR high >= entry price + take-profit distance
Exit: short, (Momentum cycle > 0 AND Momentum cycle > upper level) OR high >= entry price + stop-loss distance OR low <= entry price − take-profit distance
