Calculation: Adaptive oscillator = Let midpoint be (high + low) / 2 and n be the smaller of the number of preceding bars available and floor(Ehlers cycle period / 2). The oscillator is (n + 1) / 2 minus the sum of (i + 1) × midpoint[i] for i from 0 to n − 1 divided by the sum of midpoint[i] over the same bars; i = 0 is the current bar. It is undefined when that denominator is zero.
Calculation: Ehlers cycle period = Starting with zero-filled histories and instantaneous period and cycle period both initialized to 1, calculate each bar as follows. Smooth = (midpoint[0] + 2 × midpoint[1] + 2 × midpoint[2] + midpoint[3]) / 6. For the first six bars, cycle = (midpoint[0] − 2 × midpoint[1] + midpoint[2]) / 4; thereafter cycle = (1 − alpha / 2)² × (smooth[0] − 2 × smooth[1] + smooth[2]) + 2 × (1 − alpha) × cycle[1] − (1 − alpha)² × cycle[2]. Quadrature = (0.0962 × cycle[0] + 0.5769 × cycle[2] − 0.5769 × cycle[4] − 0.0962 × cycle[6]) × (0.5 + 0.08 × previous instantaneous period); in-phase = cycle[3]. If current and previous quadrature are nonzero, phase change = (in-phase[0] / quadrature[0] − in-phase[1] / quadrature[1]) / (1 + in-phase[0] × in-phase[1] / (quadrature[0] × quadrature[1])); otherwise reuse the phase change from five bars ago. Clamp phase change to 0.1–1.1 and take its five-bar median. Dominant cycle = 6.28318 / median + 0.5, or 15 if the median is zero. Instantaneous period = 0.67 × previous instantaneous period + 0.33 × dominant cycle; cycle period = 0.85 × previous cycle period + 0.15 × instantaneous period.
Long: Adaptive oscillator on the still-forming higher-timeframe bar > its value on the preceding higher-timeframe bar.
