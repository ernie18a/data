Calculation: TSI = 100 × XMA(XMA(Williams %R momentum, first smoothing length), second smoothing length) ÷ XMA(XMA(absolute Williams %R momentum, first smoothing length), second smoothing length), where Williams %R momentum is current Williams %R minus Williams %R from the momentum lookback bars earlier; use the same XMA method and lengths in numerator and denominator. If calculated on a higher timeframe, use its still-forming bar.
Calculation: TSI signal = XMA(TSI, signal smoothing length), using the same XMA method.
Long: TSI > TSI signal
Short: TSI < TSI signal
