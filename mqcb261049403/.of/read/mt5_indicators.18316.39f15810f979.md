Calculation: Percentage crossover line = At each bar, if close × (1 − p) is greater than the previous line value, set the line to close × (1 − p); otherwise, if close × (1 + p) is less than the previous line value, set it to close × (1 + p); otherwise retain the previous line value. p is the percentage deviation expressed as a fraction.
Long: Percentage crossover line > its previous value
Short: Percentage crossover line < its previous value
Calculation: Higher-timeframe percentage crossover line = The same calculation on higher-timeframe bars, using the still-forming higher-timeframe bar; carry its latest value across chart bars.
Long: Higher-timeframe percentage crossover line > its previous value
Short: Higher-timeframe percentage crossover line < its previous value
