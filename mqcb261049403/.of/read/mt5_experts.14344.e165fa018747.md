Calculation: Oscillator = change from the previous bar in the difference between a short-term moving average and a long-term moving average of the same selected price series
Long: Chart-timeframe oscillator > 0
Short: Chart-timeframe oscillator < 0
Long: Last completed higher-timeframe oscillator > 0 AND preceding higher-timeframe oscillator <= 0
Short: Last completed higher-timeframe oscillator < 0 AND preceding higher-timeframe oscillator >= 0
Exit: long, last completed higher-timeframe oscillator < 0 OR low <= entry price minus stop-loss distance OR high >= entry price plus take-profit distance
Exit: short, last completed higher-timeframe oscillator > 0 OR high >= entry price plus stop-loss distance OR low <= entry price minus take-profit distance
