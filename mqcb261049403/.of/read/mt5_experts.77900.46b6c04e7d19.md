Calculation: Stoch = close-to-close stochastic signal line: K = 100*(close - lowest close over lookback)/(highest close - lowest close over same lookback, including current bar), clipped to 0-100 (previous K if range is zero); main = SMMA(K, slowing length); Stoch = SMMA(main, signal length); K lookback is longer than both smoothing lengths
Calculation: Bands = Bollinger bands (SMA middle, fixed standard-deviation multiple) of weighted price (high+low+2*close)/4
Long: evaluated once at the open of each new chart bar (bar1 = last completed bar, bar2 = the one before it, and so on), only while flat: Stoch[bar3] < Stoch[bar2] AND Stoch[bar2] > Stoch[bar1] (peak, turning down) AND open[bar3] < upper Bands[bar4]; then place a buy stop at the high of the last completed bar of a higher timeframe (daily), valid only if that level is above the current price; it replaces any pending buy stop, is filled when price trades up to that level, and is cancelled if unfilled after a set number of chart bars
Short: evaluated once at the open of each new chart bar, only while flat: Stoch[bar3] > Stoch[bar2] AND Stoch[bar2] < Stoch[bar1] (trough, turning up) AND open[bar3] > lower Bands[bar4]; then place a sell stop at the low of the last completed bar of a higher timeframe (daily), valid only if that level is below the current price; it replaces any pending sell stop, is filled when price trades down to that level, and is cancelled if unfilled after a set number of chart bars
Exit: long, low <= entry price*(1 - stop percent/100) OR high >= entry price*(1 + target percent/100)
Exit: short, high >= entry price*(1 + stop percent/100) OR low <= entry price*(1 - target percent/100)
