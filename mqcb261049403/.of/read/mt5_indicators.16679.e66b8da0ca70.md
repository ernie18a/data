Calculation: ZPF = smoothed volume × (short-period smoothed applied price − long-period smoothed applied price) / 2; both use the same smoothing method, and the long lookback is twice the short lookback. On a higher timeframe, use the bar still forming.
Long: chart-timeframe ZPF > 0 OR higher-timeframe ZPF > 0
Short: chart-timeframe ZPF < 0 OR higher-timeframe ZPF < 0
