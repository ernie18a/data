Calculation: Price source = a selectable bar price: open, high, low, close, (high+low)/2, (high+low+close)/3, (high+low+2*close)/4, (open+close)/2, (open+high+low+close)/4, trend-follow price, half trend-follow price, or DeMark price. Trend-follow price is high if close > open, low if close < open, otherwise close. Half trend-follow price is (high+close)/2 if close > open, (low+close)/2 if close < open, otherwise close. DeMark price is (high+low+2*close+low)/4 if close < open, (high+low+2*close+high)/4 if close > open, otherwise (high+low+3*close)/4.
Calculation: Rounded moving average = apply eight successive EMAs of the same length to the price source, seeding each EMA with its first available input and starting each successive EMA one bar later. Combine the stages as 8*EMA1 - 28*EMA2 + 56*EMA3 - 70*EMA4 + 56*EMA5 - 28*EMA6 + 8*EMA7 - EMA8, add a selectable price offset, and round to the nearest selectable price increment. Calculate either on chart bars or on higher-timeframe bars, using the still-forming higher-timeframe bar and the preceding higher-timeframe bars.
Long: The most recent nonzero change in the rounded moving average is > 0.
Short: The most recent nonzero change in the rounded moving average is < 0.
