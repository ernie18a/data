Calculation: Selected price = a configurable choice of close, open, high, low, (high + low)/2, (high + low + close)/3, (high + low + 2*close)/4, (open + close)/2, (open + high + low + close)/4, or one of: high if close > open, low if close < open, otherwise close; (high + close)/2 if close > open, (low + close)/2 if close < open, otherwise close; or (2*close + high + low + X)/4, where X is low if close < open, high if close > open, otherwise close.
Calculation: Histogram = A - B, initialized with A = B = selected price on the third available bar. On each subsequent bar, set A to previous A + (selected price - previous A)/smoothing coefficient if selected price is both greater than previous A and greater than previous selected price, or both less than previous A and less than previous selected price; otherwise retain previous A. Set B to previous B + (selected price - previous B)/smoothing coefficient if selected price > previous B AND selected price < previous selected price, or selected price < previous B AND selected price > previous selected price; otherwise retain previous B.
Calculation: Higher-timeframe histogram = histogram calculated on a higher timeframe, sampled from the higher-timeframe bar still forming at the first chart bar of that higher-timeframe interval and held until the next interval. Historical indicator copying uses the final value of that higher-timeframe bar.
Long: Histogram >= 0
Short: Histogram < 0
Long: Previous higher-timeframe histogram < 0 AND higher-timeframe histogram >= 0
Short: Previous higher-timeframe histogram >= 0 AND higher-timeframe histogram < 0
