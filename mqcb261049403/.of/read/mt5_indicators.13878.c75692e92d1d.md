Calculation: Jurik-smoothed deviation ratio = clamp(Jurik ultralinear smoothing of (price − Jurik moving average of price) / Jurik ultralinear smoothing of abs(price − Jurik moving average of price), −1, 1); the two smoothing operations use the same length, and a zero denominator produces no value.
Calculation: Jurik ultralinear smoothing = apply three consecutive stages to the input; in each stage update a = (1 − k) × previous a + k × input, then b = k × a + (1 − k) × previous b, and output 1.5 × a − 0.5 × b, where k = 3 / (smoothing length + 2); initialize a and b to the first input to each stage.
Calculation: Trend cycle = subtract the longer-length Jurik-smoothed deviation ratio from the shorter-length ratio, using the same price, moving-average phase and deviation-smoothing length. Normalize this difference to its rolling minimum and maximum over a cycle lookback on a 0–100 scale, carrying forward the prior normalized value when the range is zero; smooth it recursively as the average of its current value and its prior smoothed value. Normalize that smoothed series over the same lookback to a −100–100 scale, carrying forward the prior trend cycle when the range is zero; smooth it recursively as the average of its current value and its prior smoothed value. Calculate either on the chart timeframe or on a higher timeframe using the bar still forming.
Long: trend cycle > 0
Short: trend cycle < 0
