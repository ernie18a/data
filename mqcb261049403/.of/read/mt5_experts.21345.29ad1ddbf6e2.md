Calculation: Pivot = (high + low + close) / 3 of the chart bar immediately before the selected CCI signal bar; the signal bar is either the current bar or the last completed bar.
Calculation: Jump filter = every absolute difference between opens of adjacent bars among the current chart bar and the preceding five bars is below an adjacent-bar threshold AND every absolute difference between opens two bars apart within those bars is below a separate two-bar threshold.
Calculation: Long trailing stop = initial stop-loss price, or unset if stop loss is disabled; on each bar, if trailing is enabled AND close - entry price > trailing distance + trailing step AND the stop is unset or below close - trailing distance - trailing step, set it to close - trailing distance.
Long: No open position AND jump filter passes AND current Awesome Oscillator > 0 AND CCI of the selected signal bar >= 0 AND current close > pivot AND (previous-bar Awesome Oscillator < 0 OR CCI of the bar preceding the selected signal bar <= 0 OR close of the last completed reference-timeframe bar < pivot). The reference timeframe may be higher or lower than the chart timeframe.
Exit: Long, stop loss is enabled AND low <= entry price - stop-loss distance OR take profit is enabled AND high >= entry price + take-profit distance OR trailing stop is set AND low <= trailing stop.
