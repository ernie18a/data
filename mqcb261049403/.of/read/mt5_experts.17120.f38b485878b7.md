Calculation: Applied price = a configurable choice of close, open, high, low, (high+low)/2, (high+low+close)/3, (high+low+2*close)/4, (open+close)/2, (open+high+low+close)/4, high if close>open else low if close<open else close, (high+close)/2 if close>open else (low+close)/2 if close<open else close, or (high+low+close+x-low-high)/2 where x is low if close<open, high if close>open, otherwise close.
Calculation: Fractal MFI = on a configurable timeframe that may be the chart timeframe or a higher or lower timeframe, use the last completed bar by default, or the forming bar if configured. For each bar t, let n be the fractal lookback, p the applied price, maximum=max(0, highest p over n bars), minimum=min(9999999999, lowest p over n bars), and q[j]=(p[j]-minimum)/(maximum-minimum). If maximum>minimum, L=sum for j=t-n+2 through t of sqrt((q[j]-q[j-1])^2+1/n^2); otherwise L=0. Set dimension=1+log(2*L)/log(2*(n-1)) if L>0, otherwise dimension=0. Set m=round(normal speed/(2*(2-dimension))). For j=t-m+1 through t, add p[j]*volume[max(0,j-2)] to positive flow if p[j]>p[j-1], or to negative flow if p[j]<p[j-1]; otherwise add neither. Fractal MFI=100-100/(1+positive flow/negative flow) if negative flow is nonzero, otherwise 100.
Long: In direct mode, previous Fractal MFI <= lower threshold AND current Fractal MFI > lower threshold; OR in reverse mode, previous Fractal MFI >= upper threshold AND current Fractal MFI < upper threshold.
Short: In direct mode, previous Fractal MFI >= upper threshold AND current Fractal MFI < upper threshold; OR in reverse mode, previous Fractal MFI <= lower threshold AND current Fractal MFI > lower threshold.
Exit: long, in direct mode, previous Fractal MFI >= upper threshold AND current Fractal MFI < upper threshold; OR in reverse mode, previous Fractal MFI <= lower threshold AND current Fractal MFI > lower threshold; OR low <= entry price minus enabled stop distance; OR high >= entry price plus enabled target distance.
Exit: short, in direct mode, previous Fractal MFI <= lower threshold AND current Fractal MFI > lower threshold; OR in reverse mode, previous Fractal MFI >= upper threshold AND current Fractal MFI < upper threshold; OR high >= entry price plus enabled stop distance; OR low <= entry price minus enabled target distance.
