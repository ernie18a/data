Calculation: Adaptive brick state = For each bar, choose H and L as either close and close, or high and low. Initialize upper boundary U = H, lower boundary D = L, brick size B = max(multiplier × (H − L), minimum price distance), and trend T = 0 on the first bar after the volatility lookback. On each bar, set V = max(multiplier × volatility, minimum price distance), where volatility is either ATR or the standard deviation of close around its simple moving average. Starting from the previous bar's U, D, B and T, if H > U + B, set U = U + floor((H − U) / B) × B, B = V, and D = U − B. Then, using these updated values, if L < D − B, set D = D − floor((D − L) / B) × B, B = V, and U = D + B. If U > the previous bar's U, set T = 1; then if D < the previous bar's D, set T = −1. Otherwise retain T. Bullish support = D − B when T > 0, otherwise 0; bearish resistance = U + B when T < 0, otherwise 0.
Calculation: Signal state = Adaptive brick state calculated separately for long and short decisions with independently configurable parameters and timeframes. Each timeframe can be the chart timeframe or a higher or lower timeframe; use either its last completed bar, an earlier completed bar at a configurable offset, or its still-forming bar. Compare the selected bar with the immediately preceding bar of that timeframe.
Long: chart-timeframe bullish support != 0
Short: chart-timeframe bearish resistance != 0
Long: long signal state's bullish support != 0 AND its previous bar's bearish resistance != 0
Short: short signal state's bearish resistance != 0 AND its previous bar's bullish support != 0
Exit: long, long signal state's bearish resistance != 0 OR low <= entry price − long stop distance OR high >= entry price + long profit distance
Exit: short, short signal state's bullish support != 0 OR high >= entry price + short stop distance OR low <= entry price − short profit distance
