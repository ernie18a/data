Calculation: Adaptive Laguerre Filter = Apply the adaptive Laguerre filter to median price, (high + low) / 2: take the absolute difference between price and the prior filter value; normalize it over the filter-period lookback to [0,1] (use 0 if the range is zero); let alpha be the median of these normalized differences over a window of max(filter period × smoothing, 2), zero-filling unavailable values; set gamma to 1 − alpha, clamped to (0,1). Recursively calculate L0 = (1 − gamma) × price + gamma × prior L0; L1 = −gamma × L0 + prior L0 + gamma × prior L1; L2 = −gamma × L1 + prior L1 + gamma × prior L2; L3 = −gamma × L2 + prior L2 + gamma × prior L3. The filter value is (L0 + 2 × L1 + 2 × L2 + L3) / 6. Use the chart timeframe, or the configured equal or higher timeframe; on a higher timeframe use the bar containing the chart bar, including while it is still forming.
