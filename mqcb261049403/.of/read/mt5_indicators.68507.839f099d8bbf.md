Calculation: Chart trend = Starting at the bar indexed by the statistical lookback, set the upper and lower bands to midpoint plus and minus ATR times the multiplier and set the trend to bearish. On each subsequent bar, calculate raw bands the same way; set the upper band to the raw upper band if it is below the previous upper band OR the previous close is above the previous upper band, otherwise retain the previous upper band; set the lower band to the raw lower band if it is above the previous lower band OR the previous close is below the previous lower band, otherwise retain the previous lower band. Set trend to bullish if close is above the current upper band, otherwise to bearish if close is below the current lower band, otherwise retain the previous trend. Midpoint is (high + low) / 2. The multiplier is the base multiplier, optionally multiplied by 1 + abs(close Z-score) / 10; calculate the Z-score over the statistical lookback including the current close using population standard deviation, with Z-score 0 when standard deviation is 0.
Calculation: Scanner trend = On a configurable higher, lower, or chart timeframe, use the bar still forming and a configurable history depth. Initialize the oldest scanned bar's upper and lower bands to midpoint plus and minus ATR times the base multiplier, and its trend to bullish if close is above midpoint, otherwise bearish. Process subsequent bars through the forming bar using the same band ratchet and trend update as the chart trend, with the base multiplier and without the Z-score adjustment.
Long: Chart trend = bullish OR scanner trend = bullish
Short: Chart trend = bearish OR scanner trend = bearish
