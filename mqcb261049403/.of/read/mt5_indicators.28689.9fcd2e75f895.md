Calculation: All referenced non-chart timeframes are fixed independently of the chart timeframe and may be higher than, lower than, or equal to it. The moving-average timeframe is shorter than both ZigZag timeframes; the MACD timeframe is the longer ZigZag timeframe. Use each timeframe's still-forming bar as index 0 and its preceding bars as indices 1, 2, and so on.
Calculation: E = short-period EMA of median price; S = longer-period SMA of median price; A = shorter-period SMA of S; B = longer-period SMA of S, all on the moving-average timeframe.
Calculation: Upward moving-average condition = E[0] > E[1] AND S[0] > S[1] AND ((A[0] - B[0] >= A[1] - B[1] AND ((A[2] < B[2] AND A[0] > B[0]) OR (A[0] > B[0] AND A[0] > A[1]))) OR (S[0] - A[0] > S[1] - A[1] AND B[0] > B[1] AND S[0] > A[0])).
Calculation: Downward moving-average condition = E[0] < E[1] AND S[0] < S[1] AND ((A[0] - B[0] <= A[1] - B[1] AND ((A[2] > B[2] AND A[0] < B[0]) OR (A[0] < B[0] AND A[0] < A[1]))) OR (S[0] - A[0] < S[1] - A[1] AND B[0] < B[1] AND S[0] < A[0])).
Calculation: M = MACD main line of close; T = SMA signal line of M; H = M - T, on the MACD timeframe.
Calculation: On each ZigZag timeframe, compute ZigZag with depth, deviation and backstep parameters, including the forming bar. Let low age and high age be the respective bar indices of its most recent low and high. On the shorter timeframe, direction is up if low age < high age and down if high age < low age. On the longer timeframe, direction is recent up if low age < high age AND 0 < low age < recency threshold, recent down if high age < low age AND 0 < high age < recency threshold, old up if low age < high age AND low age > recency threshold, and old down if high age < low age AND high age > recency threshold; otherwise it is neutral.
Calculation: Direction state = initially neutral; retain the previous state unless an update applies. Apply these updates in order, with each later applicable update overriding earlier ones: set up if both ZigZag directions are recent up on the longer timeframe and up on the shorter timeframe, OR H[0] > H[1] AND M[0] > M[1]; set down if the longer direction is recent down AND the shorter direction is down, OR H[0] < H[1] AND M[0] < M[1]; set down if the current state is up AND the longer direction is old up, OR M[0] < M[1] AND H[0] < H[1]; set up if the current state is down AND the longer direction is old down, OR M[0] > M[1] AND H[0] > H[1]; set up if M[0] >= M[1] AND M[0] > T[0] AND T[0] > T[1]; set down if M[0] <= M[1] AND M[0] < T[0] AND T[0] < T[1]; set up if the upward moving-average condition holds; set down if the downward moving-average condition holds.
Long: Direction state = up.
Short: Direction state = down.
