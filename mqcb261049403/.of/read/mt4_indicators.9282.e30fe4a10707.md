Calculation: HP trend = the Hodrick–Prescott trend fitted to a rolling window of the selected applied price, minimizing squared deviations from price plus a smoothing factor times the sum of squared second differences. Index 0 is the newest fitted value. The applied price is open, high, low, close, median, typical, weighted, or OHLC average. For a higher or lower calculation timeframe, use its bar still forming at the chart bar's evaluation time; previous values and previous decisions refer to previous bars of that calculation timeframe.
Long: (each HP trend value over the trend lookback >= the next older value in the current fit, OR the trend lookback is zero AND the current newest HP trend value >= the previous bar's newest HP trend value) AND (the previous bar satisfied the long condition OR the current newest HP trend value >= the previous bar's newest HP trend value AND the current applied price >= the current newest HP trend value)
Short: (each HP trend value over the trend lookback <= the next older value in the current fit, OR the trend lookback is zero AND the current newest HP trend value <= the previous bar's newest HP trend value) AND (the previous bar satisfied the short condition OR the current newest HP trend value <= the previous bar's newest HP trend value AND the current applied price <= the current newest HP trend value)
