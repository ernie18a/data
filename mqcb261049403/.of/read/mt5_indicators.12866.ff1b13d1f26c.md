Calculation: Smoothed RSI = moving average of RSI of a selected OHLC-derived price, using a selectable smoothing method and smoothing period.
Calculation: RSI trailing line = let distance be a multiplier times the twice-smoothed absolute one-bar change in smoothed RSI; both smoothing passes use the same method as smoothed RSI and a period equal to twice the RSI period minus one. Starting with a trailing-line value of zero, on each bar set it to smoothed RSI plus distance if smoothed RSI is below the previous trailing line, except retain the previous trailing line if the previous smoothed RSI was also below it and the proposed value exceeds it; set it to smoothed RSI minus distance if smoothed RSI is above the previous trailing line, except retain the previous trailing line if the previous smoothed RSI was also above it and the proposed value is below it; otherwise retain the previous trailing line.
Calculation: Higher-timeframe trend = calculate smoothed RSI and its trailing line on a higher timeframe using the bar still forming; sample their comparison on the first chart bar of each higher-timeframe bar and hold it for the rest of that higher-timeframe bar. On equality retain the last non-equal comparison.
Long: Chart-timeframe smoothed RSI > chart-timeframe RSI trailing line OR higher-timeframe trend > 0
Short: Chart-timeframe smoothed RSI < chart-timeframe RSI trailing line OR higher-timeframe trend < 0
Long: Chart-timeframe smoothed RSI crosses above the RSI midpoint AND its preceding crossing of the RSI trailing line was upward
Short: Chart-timeframe smoothed RSI crosses below the RSI midpoint AND its preceding crossing of the RSI trailing line was downward
