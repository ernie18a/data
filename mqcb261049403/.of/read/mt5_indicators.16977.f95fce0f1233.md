Calculation: DMI stochastic = For each bar, calculate upward movement as the positive high change when it exceeds the downward low change, otherwise zero; calculate downward movement as the positive downward low change when it exceeds the high change, otherwise zero. Smooth each movement and true range using the same selected moving-average method and period. DMI oscillator = 100 × (smoothed upward movement − smoothed downward movement) / smoothed true range. For each bar, find the highest and lowest DMI oscillator values over the stochastic lookback. DMI stochastic = 100 × the sum over the slowing lookback of (DMI oscillator − its rolling lowest value) / the sum over the same lookback of (its rolling highest value − its rolling lowest value); use zero when the denominator is zero. Use available bars when a lookback extends before the start of the data. The selected smoothing method is simple, exponential, smoothed, or linear weighted moving average; initialize exponential and smoothed averages with the input value, and start the smoothed-average recursion on the third bar. Calculate on the chart timeframe or on a higher timeframe using its bar still forming.
Long: DMI stochastic > previous DMI stochastic, when slope mode is selected
Short: DMI stochastic < previous DMI stochastic, when slope mode is selected
Long: DMI stochastic > midpoint of upper and lower levels, when midpoint mode is selected
Short: DMI stochastic < midpoint of upper and lower levels, when midpoint mode is selected
Long: DMI stochastic > upper level, when outer-level mode is selected
Short: DMI stochastic < lower level, when outer-level mode is selected
