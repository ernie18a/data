Calculation: Rounded moving-average value for price P = smooth P with the selected moving-average method; update the prior rounded value to the current smoothed value if its distance from either the prior smoothed value or prior rounded value exceeds the rounding threshold, or if it moves across the prior rounded value in the same direction as the prior rounded-value movement; otherwise retain the prior rounded value.
Calculation: Rounded candle color = compare rounded close with rounded open, where rounded open is the previous bar’s rounded close if the bar’s absolute open-close difference is at most the gap threshold; otherwise it is the rounded value of open. Color is bullish when rounded close > rounded open, bearish when rounded close < rounded open, and neutral when equal. Use the configured indicator timeframe, whether higher or lower than the chart timeframe, and only completed bars.
Long: Current rounded candle color is bullish AND previous rounded candle color is not bullish
Short: Current rounded candle color is bearish AND previous rounded candle color is not bearish
Exit: Long, current rounded candle color is bearish AND previous rounded candle color is not bearish OR low <= entry price - stop distance OR high >= entry price + target distance
Exit: Short, current rounded candle color is bullish AND previous rounded candle color is not bullish OR high >= entry price + stop distance OR low <= entry price - target distance
