On each bar, calculate the lowest low and highest high over the same lookback, including the current bar. If seeking a downward reversal, update running low to the greater of its previous value and the lowest low; if the moving average of highs over that lookback is below running low AND close is below the previous bar's low, set the state to bearish, seek an upward reversal, and set running high to the highest high. Then, if seeking an upward reversal, update running high to the lesser of its previous value and the highest high; if the moving average of lows over the same lookback is above running high AND close is above the previous bar's high, set the state to bullish, seek a downward reversal, and set running low to the lowest low. The moving averages use the same method. Calculate this state either on the chart timeframe or on a higher timeframe using the bar still forming.
