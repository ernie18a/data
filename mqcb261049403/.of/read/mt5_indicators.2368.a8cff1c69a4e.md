Calculation: Fast smoothed DeMarker = DeMarker smoothed with the selected averaging method using a shorter lookback, on the chart timeframe or a higher timeframe’s still-forming bar
Calculation: Slow smoothed DeMarker = DeMarker smoothed with the selected averaging method using a longer lookback, on the same timeframe and bar state as the fast smoothed DeMarker
Long: Fast smoothed DeMarker > slow smoothed DeMarker
Short: Fast smoothed DeMarker < slow smoothed DeMarker
