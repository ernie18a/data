Calculation: Oscillator = Let x = high + low - 2 × EMA(close). Starting with a = b = c = d = 0, update each bar in order: a = (1 - smoothing) × x + smoothing × previous a; b = -smoothing × a + previous a + smoothing × previous b; c = -smoothing × b + previous b + smoothing × previous c; d = -smoothing × c + previous c + smoothing × previous d. Let U = max(a - b, 0) + max(b - c, 0) + max(c - d, 0), and D = max(b - a, 0) + max(c - b, 0) + max(d - c, 0). The oscillator is 100 × U / (U + D), or 0 when U + D = 0.
Calculation: Direction = For the selected mode: slope mode gives +1 when oscillator > previous oscillator, -1 when oscillator < previous oscillator, otherwise 0; middle-level mode gives +1 when oscillator > middle level, -1 when oscillator < middle level, otherwise 0; extreme-level mode gives +1 when oscillator > upper level, -1 when oscillator < lower level, otherwise 0; crossing mode starts at 0, changes to +1 when the previous oscillator <= either extreme level and the current oscillator > that level, changes to -1 when the previous oscillator >= either extreme level and the current oscillator < that level, and otherwise retains its previous value. The lower level is below the middle level, which is below the upper level.
Calculation: Persistent direction = The most recent nonzero direction, initially 0. For the trading algorithm, calculate the oscillator and direction on the selected indicator timeframe, which may be higher or lower than the chart timeframe; use the selected completed indicator bar or the still-forming indicator bar. Evaluate a completed-bar selection when a new indicator bar begins; evaluate the still-forming selection as it updates.
Long: Direction > 0.
Short: Direction < 0.
Long: Indicator-timeframe direction > 0 AND previous indicator-timeframe persistent direction < 0.
Short: Indicator-timeframe direction < 0 AND previous indicator-timeframe persistent direction > 0.
Exit: long, indicator-timeframe persistent direction < 0 OR low <= entry price - stop-loss distance OR high >= entry price + take-profit distance.
Exit: short, indicator-timeframe persistent direction > 0 OR high >= entry price + stop-loss distance OR low <= entry price - take-profit distance.
