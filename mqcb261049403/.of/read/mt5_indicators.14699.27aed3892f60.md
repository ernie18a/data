Calculation: XRSX = 100 × clamp(smoothed applied-price change / smoothed absolute applied-price change, −1, 1), using the same smoothing and lookback for both; calculate on the selected signal timeframe and use the selected signal bar (default: the bar still forming). The selected timeframe may be higher or lower than the chart timeframe.
Calculation: Fast and slow trailing lines = for each line with its own step size (fast step shorter than slow): set x = (XRSX + 100) / 2, candidate upper = x + 2 × step, candidate lower = x − 2 × step. Set trend up if x exceeds the previous upper band; set it down if x is below the previous lower band; otherwise retain trend. In an uptrend, clamp the candidate lower band to at least the previous lower band and set the line to the clamped lower band + step. In a downtrend, clamp the candidate upper band to at most the previous upper band and set the line to the clamped upper band − step. Initialize prior upper/lower bands to −999999/+999999 and trend to 0.
Long: previous fast trailing line ≤ previous slow trailing line AND current fast trailing line > current slow trailing line
Short: previous fast trailing line ≥ previous slow trailing line AND current fast trailing line < current slow trailing line
