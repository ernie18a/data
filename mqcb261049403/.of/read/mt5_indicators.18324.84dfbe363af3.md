Calculation: Percentage channel = For each bar, initialize the middle to the first close. Thereafter, if close × (1 − percentage) > previous middle, set middle to close × (1 − percentage); otherwise, if close × (1 + percentage) < previous middle, set middle to close × (1 + percentage); otherwise retain the previous middle. Upper channel = middle × (1 + percentage); lower channel = middle × (1 − percentage). Compare against the channel shifted forward by a configurable number of bars. Calculate on either the chart timeframe or a higher timeframe, using the higher-timeframe bar still forming.
Long: Chart-timeframe close > shifted chart-timeframe upper channel OR forming higher-timeframe close > shifted higher-timeframe upper channel
Short: Chart-timeframe close < shifted chart-timeframe lower channel OR forming higher-timeframe close < shifted higher-timeframe lower channel
