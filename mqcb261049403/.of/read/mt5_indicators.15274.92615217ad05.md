Calculation: Adaptive market level = For each chart bar, or for the still-forming higher-timeframe bar, let the fractal lookback be n and the smoothing lag be L. Let R1 be the range from the highest high to the lowest low over the latest n bars divided by n, R2 the same range over the preceding n bars divided by n, and R3 the range over both groups divided by 2n. Set dimension to log2((R1 + R2) / R3) when R1 + R2 > 0 AND R3 > 0, otherwise set it to zero. Set alpha to exp(-L × (dimension - 1)), bounded by the minimum and maximum smoothing coefficients. Smooth (high + low + 2 × open + 2 × close) / 6 recursively with alpha. Initialize the smoothing history and the preceding adaptive market level to the first bar's weighted price. If the absolute difference between the current smoothed price and its value L bars earlier is at least L² × the price increment parameter, set the level to the current smoothed price; otherwise set it to the preceding level. Add the vertical offset parameter to the resulting level on every bar, including when the preceding level is carried forward.
Calculation: Level direction = Up when the adaptive market level is greater than its preceding value; down when it is less; otherwise retain the preceding direction, initially neutral.
Calculation: Level change filter = Round the current adaptive market level change and the filter multiplier times the population standard deviation of level changes over the filter lookback independently to the chosen price precision.
Long: Adaptive market level != 0 AND level direction = up
Short: Adaptive market level != 0 AND level direction = down
Long: Adaptive market level != 0 AND rounded level change > rounded level change filter
Short: Adaptive market level != 0 AND rounded level change < negative rounded level change filter
