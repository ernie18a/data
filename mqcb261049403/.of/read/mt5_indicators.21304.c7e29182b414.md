Calculation: For each of open, low, and close, maintain a primary and secondary value, initialized to that field's value on the second bar. On each subsequent bar, using the previous bar's maintained values: update the primary value to its previous value plus (current field value minus its previous value) divided by an averaging coefficient if the current field value is strictly above both the previous primary value and previous field value, or strictly below both; otherwise retain it. Update the secondary value to the previous secondary low plus (current field value minus the previous secondary value for that field) divided by the coefficient if the current field value is above its previous secondary value and below its previous field value; update it to the previous secondary close plus that same fraction if the current field value is below its previous secondary value and above its previous field value; otherwise retain it. Define indicator open and indicator close as the respective primary value minus secondary value.
Calculation: The indicator is evaluated on the chart timeframe and separately on a higher timeframe. For the higher-timeframe version, use the still-forming higher-timeframe bar as observed on its first chart bar, and hold that result until the next higher-timeframe bar begins.
Long: Indicator open < indicator close on the chart timeframe OR indicator open < indicator close on the higher timeframe.
Short: Indicator open > indicator close on the chart timeframe OR indicator open > indicator close on the higher timeframe.
