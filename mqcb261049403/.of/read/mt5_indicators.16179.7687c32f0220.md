Calculation: Main line = shorter-period moving average of the Chaikin oscillator, whose accumulation/distribution input uses volume and whose shorter and longer averages use the same selectable method.
Calculation: Signal line = longer-period moving average of the main line, using the same smoothing method as the main line.
Calculation: Higher-timeframe lines = the main and signal lines calculated on a higher timeframe using its still-forming bar, sampled on the first chart bar of each higher-timeframe bar and held until the next higher-timeframe bar begins.
Long: Chart-timeframe main line >= chart-timeframe signal line
Short: Chart-timeframe main line < chart-timeframe signal line
Long: Higher-timeframe main line >= higher-timeframe signal line
Short: Higher-timeframe main line < higher-timeframe signal line
