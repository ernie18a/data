Calculation: Level = highest high over an extreme-point lookback minus a parameterized fraction of the difference between that highest high and the lowest low over the same lookback.
Calculation: Up event = prior bar's level <= level one signal-lag bar before the prior bar AND current level > level one signal-lag bar before the current bar.
Calculation: Down event = prior bar's level >= level one signal-lag bar before the prior bar AND current level < level one signal-lag bar before the current bar.
Calculation: Higher-timeframe trend = direction of the most recent up or down event calculated on higher-timeframe bars, using either the still-forming bar or a selected completed bar and its preceding history.
Long: Chart-timeframe up event OR higher-timeframe trend = up.
Short: Chart-timeframe down event OR higher-timeframe trend = down.
