Calculation: Applied price = a configurable choice of open, high, low, close, (high+low)/2, (high+low+close)/3, (high+low+2*close)/4, (open+close)/2, (open+high+low+close)/4, or one of: high if close>open, low if close<open, otherwise close; (high+close)/2 if close>open, (low+close)/2 if close<open, otherwise close; or (X-low+X-high)/2 where X=(high+low+close+(low if close<open, high if close>open, otherwise close))/2.
Calculation: Filtered dot = for smoothing length N, set L=4*N+N-1, t=0, and for i=0 through L-1 set w[i]=cos(pi*t)*(1 if t<=0.5 else 1/(3*pi*t+1)), then increase t by 1/(N-2) if t<1, otherwise by 7/(4*N-1) if t<L-1. The raw dot is sum(w[i]*applied price[i bars ago])/abs(sum(w[i])); if the weight sum is zero use the previous filtered dot. Seed the previous filtered dot with the close immediately before the first calculated dot. If the absolute difference between the raw dot and previous filtered dot is less than the configurable filter distance, use the previous filtered dot; otherwise use the raw dot.
Calculation: Dot direction = up when the filtered dot exceeds its previous value by more than the filter distance, down when its previous value exceeds it by more than the filter distance, and otherwise retain the preceding direction; initialize to up. Calculate on the chart timeframe for indicator markings and on a configurable higher or lower timeframe for the trading system. For the trading system use a configurable signal bar: the last completed bar or the bar still forming, with the immediately preceding bar for comparison.
Long: chart-timeframe dot direction = up
Short: chart-timeframe dot direction = down
Long: trading-system dot direction = up AND preceding dot direction = down
Short: trading-system dot direction = down AND preceding dot direction = up
Exit: long, trading-system dot direction = down OR low <= entry price - stop-loss distance OR high >= entry price + take-profit distance
Exit: short, trading-system dot direction = up OR high >= entry price + stop-loss distance OR low <= entry price - take-profit distance
