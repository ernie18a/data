Calculation: Filtered composite = Let R be the moving average of (close − low) / max(high − low, minimum price increment), and let RSI and CCI be their standard values using their configured applied prices. The raw composite is [7 × 100 × (R − 0.5) + CCI + 9 × (RSI − 50)] / 3. Starting from the prior filtered value, update to raw composite − threshold when raw composite exceeds the prior value by more than the threshold; update to raw composite + threshold when it falls by more than the threshold; otherwise retain the prior value. Calculate on the configured indicator timeframe, using completed bars.
Calculation: Cloud boundary = The mean of a moving average of the rolling maximum and a moving average of the rolling minimum of the filtered composite. Both extrema use the same lookback; both moving averages use the same shorter smoothing lookback. Calculate on the configured indicator timeframe, using completed bars.
