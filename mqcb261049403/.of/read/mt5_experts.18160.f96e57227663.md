Calculation: Trend buffers = For each bar, let midpoint = (high + low) / 2, lower band = midpoint - ATR × multiplier, and upper band = midpoint + ATR × multiplier. Process bars oldest to newest with phase initially neutral and both buffers initially zero; on a neutral bar set both buffers to midpoint. If phase is not bullish and the previous bearish buffer is nonzero and close > that buffer, set phase bullish and the current bullish buffer to the lower band. If phase is not bearish and the previous bullish buffer is nonzero and close < that buffer, set phase bearish and the current bearish buffer to the upper band. Apply these two tests in that order. On a phase change, in the two line-display modes copy the previous opposite buffer into the previous new-phase buffer; in visual mode copy the previous opposite buffer into the current opposite buffer. In bullish phase, update the bullish buffer to the lower band if it exceeds the previous bullish buffer, or if the current bullish buffer is nonzero in visual or expert mode; otherwise copy the previous bullish buffer. In bearish phase, update the bearish buffer to the upper band if it is below the previous bearish buffer, or if the current bearish buffer is nonzero in visual or expert mode; otherwise copy the previous bearish buffer. In the SuperTrend display mode, perform the bullish or bearish update only if the corresponding buffer two bars earlier is nonzero. Evaluate buffer values as they exist at the decision time, including changes to the previous bar.
Calculation: Signal bars = Evaluate the fast trend on the chart timeframe and the slow trend on a higher timeframe, using completed bars. At each new fast bar, use the fast bar at a configurable completed-bar offset and the fast bar two bars before it; use the slow bar at that same offset and the immediately preceding slow bar. Refresh the slow buffers only when a new slow bar begins.
Long: Chart-timeframe bullish trend buffer != 0
Short: Chart-timeframe bearish trend buffer != 0
Long: Slow bullish buffer != 0 on both signal bars AND fast bullish buffer != 0 on the later signal bar AND fast bearish buffer != 0 on the earlier signal bar
Short: Slow bearish buffer != 0 on both signal bars AND fast bearish buffer != 0 on the later signal bar AND fast bullish buffer != 0 on the earlier signal bar
Exit: long, slow bearish buffer != 0 on both signal bars OR fast bearish buffer != 0 on the later signal bar OR low <= entry price - stop distance OR high >= entry price + profit-target distance
Exit: short, slow bullish buffer != 0 on both signal bars OR fast bullish buffer != 0 on the later signal bar OR high >= entry price + stop distance OR low <= entry price - profit-target distance
