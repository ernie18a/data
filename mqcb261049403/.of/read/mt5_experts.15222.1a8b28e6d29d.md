Calculation: Channel state = On a configurable indicator timeframe, which may be higher or lower than the chart timeframe or the same, evaluate a configurable signal bar: the last completed bar or an earlier completed bar, or the still-forming bar. For each indicator bar in chronological order, let H and L be the highest high and lowest low over the channel lookback including that bar. Set upper = H - risk fraction × (H - L) and lower = L + risk fraction × (H - L). Initialize the previous upper, previous lower, trend, and both continuation values to zero. If close > previous upper, set trend to bullish; then if close < previous lower, set trend to bearish; otherwise retain the last assigned trend. In a bullish trend replace lower with max(lower, previous lower); in a bearish trend replace upper with min(upper, previous upper). Set the bullish reversal value to lower if trend is bullish and the previous bearish continuation value > 0, otherwise zero. Set the bearish reversal value to upper if trend is bearish and the previous bullish continuation value > 0, otherwise zero. Set the bullish continuation value to lower if trend is bullish and the previous bearish continuation value <= 0, otherwise zero. Set the bearish continuation value to upper if trend is bearish and the previous bullish continuation value <= 0, otherwise zero. Carry the adjusted upper, lower, trend, and continuation values forward.
Long: bullish reversal value != 0
Short: bearish reversal value != 0
Exit: long, bearish reversal value != 0 OR bearish continuation value != 0
Exit: short, bullish reversal value != 0 OR bullish continuation value != 0
Exit: long, stop-loss distance > 0 AND low <= entry price - stop-loss distance OR take-profit distance > 0 AND high >= entry price + take-profit distance
Exit: short, stop-loss distance > 0 AND high >= entry price + stop-loss distance OR take-profit distance > 0 AND low <= entry price - take-profit distance
