Calculation: Step-channel oscillator = For each bar, let P be the selected applied price and M its moving average. Let D be a moving average of sqrt(mean((P - current M)^2)) over the same lookback as M, multiplied by a deviation factor. Smooth high, low, and close with the same separate moving average to obtain H, L, and C. Initialize stepped high, low, and close to the first bar's high, low, and close. On each bar, update stepped high to H if H - D > previous stepped high, to H + D if H + D < previous stepped high, otherwise retain its previous value. Update stepped low to L if L + D < previous stepped low, to L - D if L - D > previous stepped low, otherwise retain its previous value. In simple mode use B = D; in hybrid mode use B = D / 2. Update stepped close to C - B if C - B > previous stepped close, to C + B if C + B < previous stepped close, otherwise retain its previous value. Smooth (stepped high + stepped low + stepped close) / 3 in simple mode, or (stepped high + stepped low + 2 * stepped close) / 4 in hybrid mode, using a separate moving average to obtain the channel center. The oscillator is (P - channel center) / (0.015 * mean(abs(P - current channel center)) over the oscillator lookback), or zero if the denominator is zero. Calculate on the chart timeframe or on a higher timeframe using its bar still forming; for the higher timeframe, map its oscillator and its comparison with the previous higher-timeframe oscillator to each chart bar in that higher-timeframe interval.
Long: On the selected chart bar, the mapped oscillator > 0 AND the mapped oscillator differs from its preceding oscillator value AND on the preceding chart bar the mapped oscillator < 0 AND the mapped oscillator differs from its preceding oscillator value.
Short: On the selected chart bar, the mapped oscillator < 0 AND the mapped oscillator differs from its preceding oscillator value AND on the preceding chart bar the mapped oscillator > 0 AND the mapped oscillator differs from its preceding oscillator value.
