Calculation: Adaptive threshold = max(sensitivity, volatility multiplier × max(sensitivity, asymmetric smoothed volatility)). Volatility is ATR, standard deviation of close using an SMA, or EMA of volume. First smooth volatility with an EMA using the shorter of the front and damping periods. Then smooth that result using the longer period: if the front period is shorter than the damping period, apply EMA smoothing only when the input is below the previous smoothed value; otherwise apply EMA smoothing only when the input is above the previous smoothed value. When smoothing is not applied, use the input directly. If the periods are equal, use that period for both stages and apply the second-stage smoothing only when the input is above the previous smoothed value. Sensitivity is expressed in the units of the selected volatility source.
Long: MACD main line < -adaptive threshold
Short: MACD main line > adaptive threshold
