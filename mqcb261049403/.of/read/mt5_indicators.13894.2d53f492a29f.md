Calculation: Selected price = a configurable choice of open, high, low, close, (high + low)/2, (high + low + close)/3, (high + low + 2 × close)/4, (open + close)/2, (open + high + low + close)/4, or a trend-following price. The first trend-following price is high when close > open, low when close < open, and close otherwise. The second is (high + close)/2 when close > open, (low + close)/2 when close < open, and close otherwise.
Calculation: Filter and velocity = initialize the filter to the first selected price and velocity to zero. For each subsequent bar, distance = selected price − previous filter; velocity = previous velocity + distance × smoothing coefficient; filter = previous filter + distance × square root of smoothing coefficient + velocity + configurable price offset. Calculate either on the chart timeframe or on a higher timeframe using its still-forming bar.
Long: Signal mode is trend AND filter >= previous filter OR signal mode is velocity AND velocity > 0
Short: Signal mode is trend AND filter < previous filter OR signal mode is velocity AND velocity <= 0
