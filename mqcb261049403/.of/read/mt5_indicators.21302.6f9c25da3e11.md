Calculation: Applied price = a selectable price: open, high, low, close, (high + low) / 2, (high + low + close) / 3, (high + low + 2 × close) / 4, (open + close) / 2, (open + high + low + close) / 4, high if close > open else low if close < open else close, (high + close) / 2 if close > open else (low + close) / 2 if close < open else close, or (high + low + close + X) / 2 − (high + low) / 2 where X is low if close < open, high if close > open, otherwise close.
Calculation: Trend line and countertrend line = initialize both to the applied price of the third bar. On each subsequent bar, update the trend line to its previous value + (applied price − its previous value) / averaging coefficient if applied price is above both its previous value and the previous bar's applied price, or below both; otherwise retain its previous value. Update the countertrend line by the same formula if applied price is above its previous value and below the previous bar's applied price, or below its previous value and above the previous bar's applied price; otherwise retain its previous value. For the higher-timeframe version, calculate on higher-timeframe bars, sample the still-forming higher-timeframe bar on its first chart bar, and carry that sample forward until the next higher-timeframe bar. Historical samples use the final higher-timeframe bar value.
Long: Trend line > countertrend line
Short: Trend line < countertrend line
