Calculation: Fractal directional indicators = For a chosen OHLC-derived price and lookback n, set maximum to the greater of zero and the highest price in the last n bars, and minimum to the lesser of 9999999999 and the lowest price in those bars. Normalize each price as (price - minimum) / (maximum - minimum) when the range is positive. Let L be the sum, over adjacent normalized prices in the window, of sqrt(price difference squared + 1/n squared). Set fractal dimension to 1 + ln(2L) / ln(2(n-1)) when L > 0, otherwise zero. Set adaptive period p to round(normal speed / (2(2 - fractal dimension))). For each bar, set up = max(high - previous high, 0) and down = max(previous low - low, 0); retain only the larger, or set both to zero if equal. Divide each by true range and multiply by 100, using zero when true range is zero. For each resulting series, seed an EMA with its value p bars ago and apply p updates through the current bar with coefficient 2/(p+1). The results are the positive and negative fractal directional indicators. Calculate on the chart timeframe or on a higher timeframe using its still-forming bar.
