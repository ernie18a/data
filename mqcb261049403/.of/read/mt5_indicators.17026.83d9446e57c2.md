Calculation: Fractal-adaptive +DI and −DI = On each bar, calculate FDI from the selected applied-price series over the e_period-bar window: normalize each price to the window’s minimum and maximum, sum sqrt((difference between consecutive normalized prices)^2 + 1/e_period^2), then FDI = 1 + [ln(sum) + ln(2)] / ln(2(e_period − 1)). Set n = round(normal_speed / [2(2 − FDI)]). For each bar, +DM = max(high − previous high, 0) and −DM = max(previous low − low, 0); retain only the larger value, or set both to zero if equal. Divide each by true range and multiply by 100, then smooth each with an EMA of period n (α = 2/(n + 1)); both use the same n. Calculate on the chart timeframe, or on the higher timeframe and use its still-forming bar in the HTF variants.
Long: Fractal-adaptive +DI > Fractal-adaptive −DI
Short: Fractal-adaptive −DI > Fractal-adaptive +DI
