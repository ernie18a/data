Calculation: Main line = shorter-period moving average of the Awesome Oscillator.
Calculation: Signal line = longer-period moving average of the main line, using the same smoothing method.
Calculation: Higher-timeframe sampled lines = main and signal lines calculated on the higher timeframe using its still-forming bar, sampled on the first chart bar of each higher-timeframe bar and held until the next higher-timeframe bar begins.
Long: Chart-timeframe main line > chart-timeframe signal line.
Short: Chart-timeframe main line < chart-timeframe signal line.
Long: Higher-timeframe sampled main line >= higher-timeframe sampled signal line.
Short: Higher-timeframe sampled main line < higher-timeframe sampled signal line.
