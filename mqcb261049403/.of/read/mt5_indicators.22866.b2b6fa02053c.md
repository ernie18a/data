Calculation: Fisher candle open and close = For each of the open and close price series separately, find the highest high and lowest low over the same lookback including the current bar; if equal, increase the highest high by a price increment. Set v = (price − lowest low) / (highest high − lowest low) − 0.5 + 0.67 × previous v, with initial v = 0. Set r = (1 + v) / (1 − v); if r < 0.0000001, set r = 1. Set Fisher = 0.5 × ln(r) + 0.5 × previous Fisher, with initial Fisher = 0. Smooth each Fisher series independently with the same selectable moving-average method and parameters. The candle close is the smoothed close Fisher. The candle open is the smoothed open Fisher, except when abs(open − close) <= the gap threshold, in which case it is the previous bar's smoothed close Fisher. Calculate on the chart timeframe or on a higher timeframe using its still-forming bar.
Long: Fisher candle close > Fisher candle open
Short: Fisher candle close < Fisher candle open
