Calculation: RMACD = Relative Vigor Index with the shorter lookback minus True Relative Vigor Index with the longer lookback, on the configured indicator timeframe; True Relative Vigor Index is the lookback-weighted sum of volume-weighted open-to-close changes divided by the lookback-weighted sum of volume-weighted low-to-high changes, where each volume-weighted change is current volume times the price change plus 8 times each of the next two older bars’ volume-weighted changes plus the third older bar’s volume-weighted change
Calculation: Signal line = configured smoother of RMACD
Long: When zero-level crossing mode is selected, previous completed RMACD <= 0 AND latest completed RMACD > 0 OR when histogram-direction-change mode is selected, oldest of three completed RMACD values > middle value AND middle value < latest value OR when signal-line-direction-change mode is selected, oldest of three completed signal-line values > middle value AND middle value < latest value OR when histogram/signal-line crossing mode is selected, previous completed RMACD <= previous completed signal line AND latest completed RMACD > latest completed signal line OR previous completed RMACD > signal line two bars earlier AND latest completed RMACD < signal line one bar earlier
Short: When zero-level crossing mode is selected, previous completed RMACD >= 0 AND latest completed RMACD < 0 OR when histogram-direction-change mode is selected, oldest of three completed RMACD values < middle value AND middle value > latest value OR when signal-line-direction-change mode is selected, oldest of three completed signal-line values < middle value AND middle value > latest value OR when histogram/signal-line crossing mode is selected, previous completed RMACD >= previous completed signal line AND latest completed RMACD < latest completed signal line OR previous completed RMACD < signal line two bars earlier AND latest completed RMACD > signal line one bar earlier
Exit: short, When zero-level crossing mode is selected, latest completed RMACD > 0 OR when histogram-direction-change mode is selected, middle completed RMACD value < latest completed value OR when signal-line-direction-change mode is selected, middle completed signal-line value < latest completed value OR when histogram/signal-line crossing mode is selected, latest completed RMACD > latest completed signal line
Exit: long, When zero-level crossing mode is selected, latest completed RMACD < 0 OR when histogram-direction-change mode is selected, middle completed RMACD value > latest completed value OR when signal-line-direction-change mode is selected, middle completed signal-line value > latest completed value OR when histogram/signal-line crossing mode is selected, latest completed RMACD < latest completed signal line
