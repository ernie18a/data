Calculation: Channel levels = On the indicator timeframe, which may be higher or lower than the chart timeframe, use the selected completed indicator bar and a lookback window ending a configurable number of indicator bars before it. Let H and L be the highest high and lowest low in that window, R = H - L, c = the channel fraction, and d = the additional stop-channel fraction. Upper = H + R*c; lower = L + R*c; stop upper = H - R*(c+d); stop lower = L + R*(c+d). Use the same lookback and offset for all four levels.
Calculation: Indicator states and markings = Process completed indicator bars oldest to newest, initializing trend and stop state to false. On each bar, save their previous values, then apply these updates in order: if close < lower AND close < upper AND stop state = true, set trend = false; if close > upper AND close > lower AND stop state = false, set trend = true; if (close > stop upper OR close > stop lower) AND trend = false, set stop state = false; if (close < stop lower OR close < stop upper) AND trend = true, set stop state = true. Then, if close < lower AND close < upper AND stop state = false, mark a sell and set stop state = true; if close > upper AND close > lower AND stop state = true, mark a buy and set stop state = false. Also mark a sell if trend changed from true to false, and a buy if trend changed from false to true. Mark a buy stop if stop state changed from false to true, and a sell stop if it changed from true to false. Changes are measured against the saved previous-bar values.
Long: Buy marking = true.
Short: Sell marking = true.
Exit: long, sell marking = true OR (buy marking = false AND sell marking = false AND the most recent stop marking at or before the selected completed indicator bar is a buy stop, with a sell stop taking precedence if both occur on the same bar) OR low <= entry price - stop-loss distance OR high >= entry price + take-profit distance.
Exit: short, buy marking = true OR (buy marking = false AND sell marking = false AND the most recent stop marking at or before the selected completed indicator bar is a sell stop, with a sell stop taking precedence if both occur on the same bar) OR high >= entry price + stop-loss distance OR low <= entry price - take-profit distance.
