Calculation: Price = a selected open, high, low, close, median, typical, weighted-close, open-close average, or OHLC average; alternatively, select high if close > open, low if close < open, otherwise close; select (high + close)/2 if close > open, (low + close)/2 if close < open, otherwise close; or select DeMark price, defined as (X - low - high)/2, where X = (high + low + close + low)/2 if close < open, (high + low + close + high)/2 if close > open, otherwise (high + low + 2 * close)/2.
Calculation: First line = Price minus the selected middle, upper, or lower Bollinger Band; second line = 2 * moving average - high - low. The moving average and Bollinger Bands have independently selected prices and lookbacks.
Calculation: Higher-timeframe lines = first and second lines calculated on the higher-timeframe bar still forming. At the start of each higher-timeframe bar, if the absolute difference between the lines is below a threshold, add an offset to the first line if the preceding chart bar's displayed first line was greater than its second line, or to the second line if the preceding chart bar's displayed first line was less than its second line. Carry these displayed values across the higher-timeframe bar, updating them as its forming values change.
Long: First line > second line OR higher-timeframe displayed first line > higher-timeframe displayed second line.
Short: First line < second line OR higher-timeframe displayed first line < higher-timeframe displayed second line.
