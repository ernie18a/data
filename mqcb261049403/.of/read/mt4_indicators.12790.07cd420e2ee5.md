Calculation: Indicator value = the selected indicator on a pair: MACD main line; Stochastic main line minus 50; RSI minus 50; CCI; RVI main line; or DeMarker minus 0.5. For MACD only, divide values from pairs quoted in JPY by 100. Use the configured indicator timeframe; if it differs from the chart timeframe, use the bar containing each chart bar’s timestamp (the higher-timeframe bar is still forming; for a lower timeframe use the corresponding lower-timeframe bar).
Calculation: Base currency index and quote currency index = for EURUSD, GBPUSD, or AUDUSD, let A be the chart pair’s indicator value, B respectively EURJPY, GBPJPY, or AUDJPY, and C be USDJPY: base=(A+B)/2, quote=(-A+C)/2. For EURJPY or GBPJPY, let A be the chart pair, B respectively EURUSD or GBPUSD, and C be USDJPY: base=(A+B)/2, quote=(-A-C)/2. For USDJPY, let A=USDJPY, B=EURUSD, C=EURJPY: base=(A-B)/2, quote=(-A-C)/2. For USDCAD or USDCHF, let A be the chart pair, B respectively CADJPY or CHFJPY, and C be USDJPY: base=(A+C)/2, quote=(-A+B)/2.
Long: Base currency index > quote currency index AND previous bar’s base currency index < previous bar’s quote currency index
Short: Base currency index < quote currency index AND previous bar’s base currency index > previous bar’s quote currency index
