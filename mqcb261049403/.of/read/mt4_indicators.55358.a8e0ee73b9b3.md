Calculation: Direction score = selected oscillator value centered at its neutral level: Stochastic − 50, CCI, RSI − 50, MACD main line, Momentum − 100, Williams %R + 50, ADX main line, or DeMarker − 0.5; use the chart timeframe or a higher timeframe, and its bar still forming.
Calculation: Squeeze ratio = Bollinger standard deviation × Bollinger deviation ÷ (average true range × Keltner factor), using the same timeframe and bar as the direction score.
Long: previous bar squeeze ratio < 1 AND current squeeze ratio ≥ 1 AND current direction score > 0
Short: previous bar squeeze ratio < 1 AND current squeeze ratio ≥ 1 AND current direction score < 0
Exit: Long, current direction score ≤ 0 OR current squeeze ratio < 1
Exit: Short, current direction score ≥ 0 OR current squeeze ratio < 1
