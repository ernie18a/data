Calculation: Chandelier Exit upper and lower lines = On each selected higher-timeframe bar, let upper candidate = highest high over the lookback ending Shift bars before the bar minus ATR multiplied by the ATR multiplier; let lower candidate = lowest low over the same lookback plus ATR multiplied by the ATR multiplier. Start direction neutral. When direction is neutral or up, if close < upper candidate set Up = lower candidate, Dn = upper candidate, and direction down; otherwise set Up = upper candidate, Dn = lower candidate. When direction is down, if close > lower candidate set Up = upper candidate, Dn = lower candidate, and direction up; otherwise set Up = lower candidate, Dn = upper candidate. Use the selected bar, which may still be forming, and the prior bar's Up and Dn values.
Long: Prior Dn <= prior Up AND current Dn > current Up
Short: Prior Dn >= prior Up AND current Dn < current Up
