Calculation: Upper = Apply the configured smoother to adaptive series U, where U holds its prior value unless current selected price and prior selected price are both above U's prior value or both below it; when either condition holds, set U to prior U + (current selected price − prior U) / configured coefficient.
Calculation: Lower = Apply the same configured smoother and parameters to adaptive series L, where L holds its prior value unless (current selected price > prior L and current selected price < prior selected price) or (current selected price < prior L and current selected price > prior selected price); when either condition holds, set L to prior L + (current selected price − prior L) / configured coefficient. The selected price is derived from the bar's OHLC using the configured applied-price rule. Compare consecutive bars on the configured indicator timeframe, which may be higher or lower than the chart timeframe; the latest sampled bar is the configured signal bar (completed or still forming according to its selected shift), and the other is the immediately older bar.
Long: older Upper <= older Lower AND latest Upper > latest Lower
Short: older Upper >= older Lower AND latest Upper < latest Lower
Exit: long, older Upper >= older Lower AND latest Upper < latest Lower OR low <= entry price − configured stop-loss distance OR high >= entry price + configured take-profit distance OR trading-time filter is enabled AND current time is outside the configured trading interval
Exit: short, older Upper <= older Lower AND latest Upper > latest Lower OR high >= entry price + configured stop-loss distance OR low <= entry price − configured take-profit distance OR trading-time filter is enabled AND current time is outside the configured trading interval
