Calculation: Timeframes = three fixed analysis timeframes: a moving-average timeframe, a ZigZag/MACD timeframe, and a shorter ZigZag timeframe. Each can be higher than, lower than, or equal to the chart timeframe; use the bar still forming as the current bar and the preceding completed bars for historical offsets.
Calculation: Moving-average inputs = on the moving-average timeframe, calculate a short EMA and a longer SMA of median price; calculate a shorter SMA and a longer SMA of that SMA. Current, previous, and two-bars-ago values refer to that timeframe.
Calculation: Bullish moving-average condition = short EMA rises AND base SMA rises AND ((shorter smoothed SMA minus longer smoothed SMA does not decrease AND ((shorter smoothed SMA two bars ago < longer smoothed SMA two bars ago AND shorter smoothed SMA > longer smoothed SMA) OR (shorter smoothed SMA > longer smoothed SMA AND shorter smoothed SMA rises))) OR (base SMA minus shorter smoothed SMA increases AND longer smoothed SMA rises AND base SMA > shorter smoothed SMA)).
Calculation: Bearish moving-average condition = short EMA falls AND base SMA falls AND ((shorter smoothed SMA minus longer smoothed SMA does not increase AND ((shorter smoothed SMA two bars ago > longer smoothed SMA two bars ago AND shorter smoothed SMA < longer smoothed SMA) OR (shorter smoothed SMA < longer smoothed SMA AND shorter smoothed SMA falls))) OR (base SMA minus shorter smoothed SMA decreases AND longer smoothed SMA falls AND base SMA < shorter smoothed SMA)).
Calculation: ZigZag offsets = within a fixed lookback including the forming bar, find the smallest bar offset where the bar high equals a ZigZag high and the smallest offset where the bar low equals a ZigZag low, separately for each ZigZag timeframe; use zero when no matching high or low exists.
Calculation: MACD histogram = MACD main line minus MACD signal line on the ZigZag/MACD timeframe, using the forming bar and the previous completed bar.
Calculation: Direction = initialize up and down to false on each evaluation. In the following order, apply every matching rule: set up true if (the ZigZag low offset is smaller than the high offset, greater than zero and below a recent-offset threshold, AND the shorter-timeframe low offset is smaller than its high offset) OR (MACD histogram rises AND MACD main line rises); set down true if (the ZigZag low offset is greater than the high offset, the high offset is greater than zero and below the same threshold, AND the shorter-timeframe low offset is greater than its high offset) OR (MACD histogram falls AND MACD main line falls); set down true and up false if (up is true AND the ZigZag low offset exceeds the threshold) OR (MACD main line and histogram both fall); set up true and down false if (down is true AND the ZigZag high offset exceeds the threshold) OR (MACD main line and histogram both rise); set up true and down false if MACD main line does not fall AND main line > signal line AND signal line rises; set down true and up false if MACD main line does not rise AND main line < signal line AND signal line falls; set up true and down false if the bullish moving-average condition holds; set down true and up false if the bearish moving-average condition holds.
Calculation: Weighted-close deviation = (high + low + 2 × close) / 4 minus the SMA of median price on the ZigZag/MACD timeframe; compare the forming bar with the previous completed bar.
Long: Direction up = true.
Short: Direction up = false AND direction down = true.
Long: Direction up = true AND weighted-close deviation rises.
Short: Direction down = true AND weighted-close deviation falls.
