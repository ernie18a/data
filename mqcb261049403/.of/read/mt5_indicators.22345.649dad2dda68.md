Calculation: Skyscraper trend state = On each calculation-timeframe bar, compute ATR; let step be the ATR lookback’s maximum and minimum ATR averaged, multiplied by a sensitivity factor and rounded down to the price tick. Using either bar highs/lows or closes as the configured source, set raw upper = source low + 2×step and raw lower = source high − 2×step (for close source, use close for both). Set trend up if close > the prior upper threshold, down if close < the prior lower threshold, otherwise retain the prior trend. In an up trend, raise the lower threshold to the maximum of its raw value and the prior lower threshold; in a down trend, lower the upper threshold to the minimum of its raw value and the prior upper threshold. The base indicator uses the chart timeframe; its higher-timeframe variant uses the higher timeframe’s still-forming bar.
Long: Previous bar’s trend is down AND current bar’s trend is up
Short: Previous bar’s trend is up AND current bar’s trend is down
