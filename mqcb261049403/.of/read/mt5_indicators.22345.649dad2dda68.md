Calculation: Skyscraper state = On the calculation timeframe, initialize the previous lower and upper thresholds to the close of the first eligible bar and the previous trend to neutral. On each bar, calculate ATR and the highest and lowest ATR over a separate lookback including the current bar. Set step to the sensitivity factor times their average, truncated down to a whole price increment. Set the candidate upper threshold to low + 2 × step and the candidate lower threshold to high − 2 × step; alternatively, use close in place of both high and low. Start with the previous trend; set it to up if close > previous upper threshold, then set it to down if close < previous lower threshold. If trend is up, set the lower threshold to the maximum of its candidate and previous value; otherwise set the upper threshold to the minimum of its candidate and previous value. Retain the other candidate threshold unchanged. Store both thresholds and the trend for the next bar. Treat neutral as down for the displayed state. Calculate this state on the chart timeframe or on a higher timeframe using its still-forming bar.
Long: Skyscraper state is up
Short: Skyscraper state is down or neutral
