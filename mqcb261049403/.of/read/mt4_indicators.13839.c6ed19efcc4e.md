Calculation: Moving-average buy count = number of simple and exponential moving averages of median price, using the same six distinct lookbacks from shortest to longest for each method, that are less than or equal to the current price; use the selected chart, higher, or lower timeframe's forming bar.
Long: RSI of close > upper neutral threshold, using the selected chart, higher, or lower timeframe's forming bar.
Short: RSI of close <= lower neutral threshold, using the selected chart, higher, or lower timeframe's forming bar.
Long: Stochastic signal line, using simple smoothing and low/high prices, > upper neutral threshold, using the selected chart, higher, or lower timeframe's forming bar.
Short: Stochastic signal line, using simple smoothing and low/high prices, < lower neutral threshold, using the selected chart, higher, or lower timeframe's forming bar.
Long: MACD main line of close > zero, using the chart timeframe and a shorter and a longer moving-average lookback.
Short: MACD main line of close < zero, using the chart timeframe and a shorter and a longer moving-average lookback.
Long: CCI of typical price > upper neutral threshold, using the selected chart, higher, or lower timeframe's forming bar.
Short: CCI of typical price <= lower neutral threshold, using the selected chart, higher, or lower timeframe's forming bar.
Long: Momentum of close > its neutral level, using the selected chart, higher, or lower timeframe's forming bar.
Short: Momentum of close < its neutral level, using the selected chart, higher, or lower timeframe's forming bar.
Long: Moving-average buy count > upper count threshold.
Short: Moving-average buy count <= lower count threshold.
Exit: long, low <= entry price minus stop distance OR high >= entry price plus profit distance.
Exit: short, high >= entry price plus stop distance OR low <= entry price minus profit distance.
