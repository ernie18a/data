Calculation: Non-lag moving average = For period n, let phase = n − 1 and length = 4n + phase. For each lag k from 0 through length − 1, let t = k / (phase − 1) if k ≤ phase − 1; otherwise let t = 1 + (k − phase + 1) × 7 / (4n − 1). Let weight[k] = cos(πt) × (1 if t ≤ 0.5, otherwise 1 / (3πt + 1)). Take the weighted mean of the moving average of the selected price at those lags, divide by the sum of the weights, and multiply by 1 plus the deviation parameter. If the absolute difference from the previous filtered value is less than the filter threshold, use the previous filtered value instead. Calculate either on chart bars or on the still-forming higher-timeframe bar and its preceding higher-timeframe bars.
Calculation: Trend = Set to 1 when the non-lag moving average exceeds its previous value by more than the filter threshold; set to −1 when its previous value exceeds it by more than the filter threshold; otherwise retain the previous trend. Initialize to 0.
Long: Trend > 0
Short: Trend < 0
