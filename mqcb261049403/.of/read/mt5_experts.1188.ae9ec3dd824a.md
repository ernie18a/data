Calculation: Adaptive Renko direction markers = On the configured indicator timeframe (which may be higher, equal to, or lower than the chart timeframe), calculate adaptive Renko levels using either close or high/low as the price input. Initialize the brick size as the greater of multiplier × (initial high − low) and the minimum brick size. For each bar, set volatility size to the greater of multiplier × ATR or standard deviation and the minimum brick size. If the input high exceeds the upper level by more than the current brick size, advance the upper level by whole current bricks, set the brick size to volatility size, and set the lower level to upper level − brick size. If the input low falls below the lower level by more than the current brick size, move the lower level down by whole current bricks, set the brick size to volatility size, and set the upper level to lower level + brick size. Set direction up when the upper level rises, down when the lower level falls, and otherwise retain the prior direction. The uptrend marker is nonzero when direction is up; the downtrend marker is nonzero when direction is down.
Long: Uptrend marker on the last completed signal-timeframe bar != 0 AND uptrend marker on the preceding completed bar = 0
Short: Downtrend marker on the last completed signal-timeframe bar != 0 AND downtrend marker on the preceding completed bar = 0
Exit: long, downtrend marker on the last completed signal-timeframe bar != 0
Exit: short, uptrend marker on the last completed signal-timeframe bar != 0
