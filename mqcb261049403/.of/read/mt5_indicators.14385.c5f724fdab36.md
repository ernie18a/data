Calculation: Rounded moving average = A selected moving average of a selected OHLC-derived price, updated recursively. On each bar, replace the previous rounded value with the current moving average if the current moving average differs from either the previous moving average or the previous rounded value by more than a configurable price threshold, OR if it is above the previous rounded value and the last nonzero change in the rounded value was upward, OR if it is below the previous rounded value and the last nonzero change was downward. Otherwise retain the previous rounded value.
Calculation: Channel bounds = When the rounded moving average equals its previous value, set both bounds to the rounded moving average plus and minus a stored width. Set the width to the current ATR multiplied by a configurable factor on the first unchanged bar after a change in the rounded moving average; otherwise retain the previous width. When the rounded moving average changes, retain the previous bounds if channel continuity is enabled; otherwise set both bounds to zero. Initialize the width and bounds to zero. Calculate either on the chart timeframe or on a higher timeframe; for the higher timeframe, sample the still-forming higher-timeframe bar at the first chart bar in that period and hold that sampled result until the next higher-timeframe bar.
Long: Upper channel bound != 0
Short: Lower channel bound != 0
