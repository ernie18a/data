Calculation: SuperTrend direction = On each chart bar, calculate true range as high minus low on the first bar and otherwise the maximum of high minus low, absolute high minus previous close, and absolute low minus previous close. Calculate ATR using Wilder smoothing, seeded with the simple average of the first ATR-period true ranges. From the first bar with ATR, calculate raw upper and lower bands as (high + low) / 2 plus and minus an ATR multiplier times ATR. For each band, use the previous band as zero if undefined. Set the lower band to its raw value if the raw value > previous lower band OR previous close < previous lower band; otherwise retain the previous lower band. Set the upper band to its raw value if the raw value < previous upper band OR previous close > previous upper band; otherwise retain the previous upper band. A missing previous close makes its comparison false. On the first bar with ATR, direction = 1. On subsequent bars, if the previous SuperTrend line = previous upper band, direction = -1 when close > current upper band, otherwise direction = 1; if the previous SuperTrend line != previous upper band, direction = 1 when close < current lower band, otherwise direction = -1. The SuperTrend line is the lower band when direction = -1 and the upper band when direction = 1.
