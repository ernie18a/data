Calculation: Trend direction = On each scanned timeframe, use its current still-forming bar; scanned timeframes may be higher or lower than the chart timeframe. Compute ATR and basic upper/lower bands as (high + low) / 2 ± multiplier × ATR. Initialize the oldest available bar's direction as +1. For each newer bar, set direction to +1 if close > the prior bar's final upper band, to -1 if close < the prior bar's final lower band, otherwise retain the prior direction. When direction is +1, final lower band = max(basic lower band, prior final lower band); when direction is -1, final upper band = min(basic upper band, prior final upper band). The other band remains its basic value.
Calculation: Signal reference price = close of the most recent bar where trend direction changes; if direction never changes in the available history, use the oldest available close.
Long: trend direction = +1 AND signal reference price != 0
Short: trend direction = -1 AND signal reference price != 0
