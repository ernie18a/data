Calculation: Smoothed price = moving average of the selected applied price, using the first smoothing method and the same lookback as the range average.
Calculation: Smoothed range = moving average of high − low, using the second smoothing method.
Calculation: KlPrice oscillator = JMA-smoothed value of 50 × (selected applied price − smoothed price) ÷ smoothed range; use 1 as the denominator when smoothed range is zero.
Long: KlPrice oscillator > 0
Short: KlPrice oscillator < 0
