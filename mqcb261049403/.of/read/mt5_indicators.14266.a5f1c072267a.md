Calculation: Selected price = for the selected input code, use open for 1, high for 2, low for 3, (high+low)/2 for 4, (high+low+close)/3 for 5, (high+low+2*close)/4 for 6, close for 7, (open+close)/2 for 8, (open+high+low+close)/4 for 9; for 10 use high if close>open, low if close<open, otherwise close; for 11 use (high+close)/2 if close>open, (low+close)/2 if close<open, otherwise close; for 12 set X=(high+low+close+Y)/2, where Y is low if close<open, high if close>open, otherwise close, and use X-(high+low)/2.
Calculation: Dots average = for smoothing length L, set phase=L-1, N=4*L+phase, t=0, and for each lag i from 0 through N-1 set g=1 if t<=0.5, otherwise 1/(3*pi*t), and weight[i]=g*cos(pi*t); after each weight, increase t by 1/(phase-1) if t<1, otherwise by 7/(4*L-1) if t<N-1. The raw average is the sum of weight[i]*selected price at lag i divided by the absolute sum of weights. If the weight sum is zero, use the previous Dots average. Initialize the previous average to the preceding bar's close at the first calculation. If the absolute change from the previous average is less than the filter distance, use the previous average instead.
Calculation: Dots direction = long if the Dots average exceeds its previous value by more than the filter distance, short if its previous value exceeds it by more than the filter distance, otherwise the preceding direction; initialize the direction as long.
Long: Chart-timeframe Dots direction = long.
Short: Chart-timeframe Dots direction = short.
Long: Forming higher-timeframe Dots direction = long AND (the chart bar starts a higher-timeframe bar OR repetition is enabled).
Short: Forming higher-timeframe Dots direction = short AND (the chart bar starts a higher-timeframe bar OR repetition is enabled).
