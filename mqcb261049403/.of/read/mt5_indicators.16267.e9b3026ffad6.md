Calculation: Directional range score = (count of bars whose high is greater than the preceding bar's high minus count of bars whose low is less than the preceding bar's low) / lookback length, over the current chart bar and preceding bars in the lookback.
Calculation: Higher-timeframe directional range score = the same calculation on higher-timeframe bars, including the bar still forming.
Long: Directional range score > 0
Short: Directional range score <= 0
Long: Higher-timeframe directional range score > 0
Short: Higher-timeframe directional range score <= 0
