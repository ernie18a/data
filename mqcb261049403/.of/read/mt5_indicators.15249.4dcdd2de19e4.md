Calculation: NRTR trend = Starting with the first bar after the lookback, initialize trend to neutral and both the extreme and stop to that bar's close. On each bar, calculate distance as the mean absolute high-minus-low range over the lookback including the current bar, multiplied by a configurable price-precision scaling factor. If trend is neutral or up, set extreme to max(previous extreme, close) and stop to max(previous stop, extreme × (1 − distance)); if close < stop, set trend to down, extreme to close, and stop to close × (1 + distance). If trend is down, set extreme to min(previous extreme, close) and stop to min(previous stop, extreme × (1 + distance)); if close > stop, set trend to up, extreme to close, and stop to close × (1 − distance). Otherwise retain the prior trend.
Calculation: Higher-timeframe NRTR trend = Apply the same calculation to higher-timeframe bars, using the bar still forming. Map its value to the first chart bar in each higher-timeframe interval and carry it forward through that interval; recalculate that mapped value as the higher-timeframe bar forms. Historical mapping uses the final higher-timeframe bar value at the start of its interval.
Long: NRTR trend = up OR higher-timeframe NRTR trend = up
Short: NRTR trend = down OR higher-timeframe NRTR trend = down
