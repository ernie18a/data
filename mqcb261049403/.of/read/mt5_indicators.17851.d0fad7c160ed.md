Calculation: Signed ADXm = Apply a linear weighted moving average to close, high, and low separately, then sort the three smoothed values into low, close, and high. Let upward movement be max(high - previous high, 0) and downward movement be max(previous low - low, 0); set the smaller movement to zero, or both to zero if equal. Divide each movement by true range, multiply by 100, and use zero when true range is zero. Exponentially smooth each result using alpha = 2 / (period + 1), initialized with its first value. Compute 100 times their difference divided by their sum, or zero if the sum is zero. Exponentially smooth this signed result with the same alpha, initialized at zero. Calculate on the chart timeframe or on a higher timeframe using its still-forming bar.
Calculation: Upper, middle, and lower levels = Over a separate lookback of signed ADXm including the current bar, either take configured upper and lower fractions of the range above its minimum and use the range midpoint as the middle level, or take configured upper and lower quantiles and use the quantile at the midpoint of their probabilities as the middle level. The upper fraction or probability exceeds the lower. For quantiles, sort the lookback values and linearly interpolate between adjacent ranks; pad unavailable initial values with zero.
Calculation: Direction state = In outer-level mode, set to long when signed ADXm is above the upper level, short when below the lower level, and neutral when strictly between them; retain the previous state at either boundary. In middle-level mode, set to long above the middle level and short below it; retain the previous state at equality. In slope mode, set to long when signed ADXm rises and short when it falls; retain the previous state at equality. Initialize neutral. Use slope mode when the level lookback is at most one.
Long: Direction state = long
Short: Direction state = short
