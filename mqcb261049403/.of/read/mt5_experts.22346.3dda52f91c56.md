Calculation: Adaptive level = On chart bars, or on independently selected higher- or lower-timeframe bars using the last completed bar or the still-forming bar, let n be a lookback and L a lag. Let R1 and R2 be the high-low ranges of the latest n bars and preceding n bars, each divided by n; let R3 be the range of the combined 2n bars divided by 2n. Set D = log2((R1 + R2)/R3) when R1 + R2 > 0 and R3 > 0, otherwise D = 0. Set alpha = clamp(exp(-L*(D-1)), 0.01, 1), price = (high + low + 2*open + 2*close)/6, and smooth = alpha*price + (1-alpha)*previous smooth, initialized to zero. Set the level to smooth when abs(smooth - smooth L bars ago) >= L²*price increment; otherwise retain the previous level. Its direction is up when the level rises, down when it falls, and otherwise retains its previous direction, initially neutral.
Calculation: ATR trend = On chart bars, or on independently selected higher- or lower-timeframe bars using the last completed bar or the still-forming bar, calculate ATR and take its maximum and minimum over a separate lookback. Set step = price increment * truncate(sensitivity*(maximum ATR + minimum ATR)/(2*price increment)). Initialize the upper and lower thresholds to the starting close and direction to neutral. For each bar, set direction up if close > previous upper threshold, then down if close < previous lower threshold; otherwise retain direction. Set candidate upper = low + 2*step and candidate lower = high - 2*step, or use close in place of both high and low. In the up direction set lower = max(candidate lower, previous lower) and upper = infinity; otherwise set upper = min(candidate upper, previous upper) and lower = the smallest positive number.
Long: Adaptive-level direction = up
Short: Adaptive-level direction = down
Long: ATR-trend direction = up
Short: ATR-trend direction = down
Long: Adaptive-level direction = up AND previous adaptive-level direction != up
Short: Adaptive-level direction = down AND previous adaptive-level direction != down
Long: ATR-trend direction = up AND previous ATR-trend direction != up
Short: ATR-trend direction = down AND previous ATR-trend direction != down
Exit: long, adaptive-level direction = down OR ATR-trend direction = down OR low <= entry price - stop distance OR high >= entry price + profit distance
Exit: short, adaptive-level direction = up OR ATR-trend direction = up OR high >= entry price + stop distance OR low <= entry price - profit distance
