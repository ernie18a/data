Calculation: Selected price = a configurable choice of open, high, low, close, (high + low) / 2, (high + low + close) / 3, (high + low + 2 × close) / 4, (open + close) / 2, (open + high + low + close) / 4, or one of the following: if close > open use high, if close < open use low, otherwise use close; if close > open use (high + close) / 2, if close < open use (low + close) / 2, otherwise use close; or (close + X) / 2, where X is low if close < open, high if close > open, and close otherwise.
Calculation: Loco state = initialize the previous state to the selected price of the first processed bar. For each bar, let P be its selected price, Q the selected price a configurable lookback earlier, and S the previous state. If P = S, the state is S. If Q > S AND P > S, the state is max(S, P × (1 − offset)). If Q < S AND P < S, the state is min(S, P × (1 + offset)). Otherwise, if P > S, the state is P × (1 − offset); if P < S, the state is P × (1 + offset). Use the same configurable offset in both directions. The previous state for the next bar is this bar's completed state. For the higher-timeframe version, calculate this state using the higher-timeframe bar still forming.
Long: Selected price > previous Loco state OR selected price = previous Loco state AND the current bar's previously assigned direction is long OR selected price = previous Loco state AND the current bar has no previously assigned direction.
Short: Selected price < previous Loco state OR selected price = previous Loco state AND the current bar's previously assigned direction is short.
