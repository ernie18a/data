Calculation: Rising count = number of smoothed Williams %R series whose current value is greater than their previous value. The series use the same Williams %R and smoothing method, with progressively longer smoothing lengths.
Calculation: Non-rising count = number of those smoothed Williams %R series whose current value is less than or equal to their previous value.
Calculation: Bull and bear lines = rising count and non-rising count, respectively, each smoothed with the same smoothing method and length.
Long: Bull line > bear line.
Short: Bull line < bear line.
Long: Bull line > bear line calculated on the still-forming higher-timeframe bar.
Short: Bull line < bear line calculated on the still-forming higher-timeframe bar.
