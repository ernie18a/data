Calculation: Smoothed Fisher value = For each bar, set x = 2 * (close - lowest low over the lookback) / (highest high over the lookback - lowest low over the lookback) - 1, or x = 0 if the range is zero. Smooth x twice recursively with a = 3 / (2 + the first smoothing-length parameter): s1 = (1 - a) * previous s1 + a * x; s2 = (1 - a) * previous s2 + a * s1. Clamp 1.5 * s1 - s2 to [-0.999, 0.999], call the result v, and set z = ln((1 + v) / (1 - v)). Smooth z twice in the same way with an independent second smoothing-length parameter and return 1.5 * s1 - s2. Initialize both first-stage smoothing states to the first x. The source initializes both second-stage states using a transform of uninitialized local values, so its initial state is not reproducible from the supplied data.
Calculation: Higher-timeframe Smoothed Fisher value = Smoothed Fisher value calculated on a higher timeframe. In live calculation it uses the bar still forming; on historical calculation the final value of each higher-timeframe bar is copied to the first chart bar within it and carried forward through that higher-timeframe bar.
Long: Smoothed Fisher value > 0 AND Smoothed Fisher value != previous Smoothed Fisher value
Short: Smoothed Fisher value < 0 AND Smoothed Fisher value != previous Smoothed Fisher value
Long: Higher-timeframe Smoothed Fisher value > 0 AND the higher-timeframe Smoothed Fisher value differs from its previous higher-timeframe bar value
Short: Higher-timeframe Smoothed Fisher value < 0 AND the higher-timeframe Smoothed Fisher value differs from its previous higher-timeframe bar value
