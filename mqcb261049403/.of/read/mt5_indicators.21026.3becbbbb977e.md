Calculation: Double-smoothed average = apply a selected moving-average method to a selected bar price, then apply a second selected moving-average method to the result; the two smoothing stages have independently selected parameters.
Calculation: Cloud averages = the same double-smoothed average with identical parameters calculated on two independently selected timeframes, each equal to or higher than the chart timeframe; for a higher timeframe use its still-forming bar, with its value assigned from the start of that bar and carried forward until the next higher-timeframe bar.
Long: Double-smoothed average on the chart timeframe > its previous-bar value
Short: Double-smoothed average on the chart timeframe < its previous-bar value
Long: First cloud average > second cloud average
Short: First cloud average < second cloud average
