Calculation: Smoothed RSI = EMA of RSI of a selected OHLC-derived price.
Calculation: QQE trailing level = recursively update the previous level using the current and previous smoothed RSI. Let distance be a multiplier times a twice-smoothed EMA of the absolute bar-to-bar change in smoothed RSI; both EMAs use a period of twice the RSI period minus one. If current smoothed RSI is below the previous level, set the level to current smoothed RSI plus distance, capped at the previous level when previous smoothed RSI was also below that level. If current smoothed RSI is above the previous level, set the level to current smoothed RSI minus distance, floored at the previous level when previous smoothed RSI was also above that level. If equal, retain the previous level. Initialize the level to zero.
Calculation: Multi-timeframe values = calculate smoothed RSI and its trailing level on either a higher or lower timeframe. For open-based prices, use the bar containing the chart bar's open, including a still-forming bar. For other prices, use the last bar completed by the chart bar's close.
Long: Smoothed RSI crosses above the RSI midpoint AND a prior upward cross of smoothed RSI above its QQE trailing level has occurred.
Short: Smoothed RSI crosses below the RSI midpoint AND a prior downward cross of smoothed RSI below its QQE trailing level has occurred.
