Calculation: Session range = the highest high and lowest low of chart bars from the bar containing the start through the bar containing the end, inclusive, for the most recently completed daily session; if the end time is not later than the start time, the end is on the following day. For a session boundary in a data gap, use the nearest earlier bar.
Long: The session start and end fall in different available chart bars AND the session range height is between the minimum and maximum inclusive AND open <= session range high AND close > session range high AND (ATR filter is disabled OR (ATR > 0 AND abs(close - open) >= ATR multiplied by the minimum body-to-ATR ratio)).
Short: The session start and end fall in different available chart bars AND the session range height is between the minimum and maximum inclusive AND open >= session range low AND close < session range low AND (ATR filter is disabled OR (ATR > 0 AND abs(close - open) >= ATR multiplied by the minimum body-to-ATR ratio)).
