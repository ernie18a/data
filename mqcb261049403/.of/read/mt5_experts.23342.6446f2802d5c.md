Calculation: Rank correlation = 1 - 6 × sum((price rank[i] - (i + 1))²) / (N³ - N), for i from 0 to N - 1, where i = 0 is the newest bar and prices are closes truncated to the selected decimal precision. Rank closes in descending order or, alternatively, ascending order, assigning tied closes their average rank. Calculate on a higher timeframe using the last completed bar or, alternatively, the still-forming bar; previous means the immediately preceding bar of that timeframe.
Long: Weekly time >= configured start AND weekly time < configured end AND ((zero-crossing mode AND rank correlation > 0 AND previous rank correlation <= 0) OR (extreme-entry mode AND rank correlation > upper threshold AND previous rank correlation <= upper threshold)).
Short: Weekly time >= configured start AND weekly time < configured end AND ((zero-crossing mode AND rank correlation < 0 AND previous rank correlation >= 0) OR (extreme-entry mode AND rank correlation < lower threshold AND previous rank correlation >= lower threshold)).
Exit: long, weekly time < configured start OR weekly time >= configured end OR ((zero-exit mode AND rank correlation < 0) OR (extreme-exit mode AND rank correlation < lower threshold)) OR low <= entry price - stop distance OR high >= entry price + profit-target distance.
Exit: short, weekly time < configured start OR weekly time >= configured end OR ((zero-exit mode AND rank correlation > 0) OR (extreme-exit mode AND rank correlation > upper threshold)) OR high >= entry price + stop distance OR low <= entry price - profit-target distance.
