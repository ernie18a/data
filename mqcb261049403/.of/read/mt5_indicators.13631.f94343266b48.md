Calculation: Fisher RVI = For each bar, calculate the weighted averages of close minus open and high minus low over the current and previous three bars, using weights 1, 2, 2, 1 from newest to oldest. Divide the sum of the first average over the lookback by the sum of the second over the same lookback, or use zero if the denominator is zero. Normalize this ratio within its highest and lowest values over the same lookback, using zero if they are equal. Take the weighted average of the current and previous three normalized values using weights 4, 3, 2, 1 from newest to oldest, divided by 10. Let x be 1.98 times this average minus 0.99; return 0.5 times ln((1+x)/(1-x)), or zero if 1-x is zero.
Calculation: Cloud values = On the same or a higher timeframe, use Fisher RVI from the bar still forming and its previous bar as the first and second values. At the first chart bar of each new timeframe bar, if their absolute difference is less than 0.01, add 0.05 to the first value when the preceding chart bar's first cloud value is greater than its second, or to the second value when the preceding chart bar's first cloud value is less than its second. Carry these values forward across the remaining chart bars of the timeframe bar.
Long: First cloud value > second cloud value
Short: First cloud value < second cloud value
