## 移動平均線 01. 移動平均線MA是什麼？

移動平均線意思是什麼？移動平均線英文是 MA (Moving Avergae) 簡稱均線，概念是將市場一段時間的價格進行平均計算後繪製成一條線，可以用來判斷趨勢與價格的相對關係，比如當價格在線上時，表示最近的價格高於一段時間的平均價格，當價格跌破移動平均線時，表示最近的價格比前段時間的平均價格還低，有助於交易者看懂市場動向，也正因移動平均線概念簡單、使用好上手，移動平均線逐漸成為了交易者最愛用的指標之一。

## 移動平均線 02. 移動平均線有哪幾種？

幾乎所有人在入門時都會接觸到移動平均線，但不是每個人都了解移動平均線其實有許多種，以下介紹幾個常見的移動平均線：

### 02-1. 簡單移動平均線

簡單移動平均線的英文是 Simple Moving Average，簡稱SMA，計算方式非常簡單，只要將特定時間範圍內的價格進行平均計算，再將連續的不同日所計算出來的平均價格連成一條線，就可以一眼看出最近一段時間均價的變化，無論是日線周期或是分線周期都有人使用，是最基礎的一種移動平均線。

### 02-2. 指數平滑移動平均線

指數平滑移動平均線的英文是 Exponential Moving Average，簡稱EMA，這種移動平均線的特點就是會對於越新的價格給予較高的權重，比起SMA來說，EMA在近期價格上的反應更為敏感，最近的價格如果變化較大，EMA可能會早SMA一步產生趨勢線方向的變化，敏感的均線有時可以讓你早一步捕捉市場的動向。

### 02-3. 加權移動平均線

加權移動平均線的英文是 Weighted Moving Average，簡稱WMA，WMA是一種較少人使用的均線，很多人會把WMA跟EMA搞混的原因，是因為WMA跟EMA的概念其實類似，兩者都是越靠近現在時間的價格會得到更多的權重，時間越遠的價格則是權重較低。
但在實際計算上則不同，具體來說，WMA與EMA最大的區別是權重遞減的方式不一樣，WMA是線性遞減，而EMA則是不固定遞減，因此WMA在市場上比起SMA跟EMA來說使用者比較少。

移動平均線根據計算方式的不同，會衍生出各種不同的加權均線，以下是三種常見均線的計算公式：

### 03-1. 簡單移動平均線

SMA = （P1 + P2 + … + Pn） / n
SMA在計算上十分簡單，P1~Pn為特定時間週期的收盤價數據，n為指定的範圍週級，根據需求可以調整為n日、n分、n秒以此類推，計算時將範圍內所有的價格加總後，除予時間週期即可。

### 03-2. 指數平滑移動平均線

EMA（當前） = （收盤價 – 前EMA值） × （2 / (選定的期數 + 1)） + 前EMA
EMA在計算上會針對較新的價格有更高的權重，因此會根據當下的收盤價進行計算，扣除前一個週期的EMA，再乘上選定的價格範圍就可以得出，計算上呈指數性變動，故稱平滑線。

### 03-3. 加權移動平均線

WMA = （P1 × w1 + P2 × w2 + … + Pn × wn） / （w1 + w2 + … + wn）
將P1~Pn特定範圍內的價格乘上w1至Wn對應權重，再除上總權重，就可以得出加權移動平均線，可以從公式裡看出，加權移動平均線的計算可以公平地將權重攤在所有價格上，因此價格權重不會像EMA那樣成指數遞減。

## 移動平均線 04. MACD移動平均線

MACD線是什麼？MACD全稱是 指數平滑異同移動平均線 ，是一種從基本移動平均線發展出來的衍生指標，MACD英文是Moving Average Convergence Divergence，CD的意思就是收斂與發散，換言之MACD就是將均價取出收斂與發散值後再計算的一個指標，被交易者運用在期貨與股票交易等商品上。
那麼MACD該如何計算呢？這需要用使到EMA的概念，在計算時我們必須先以EMA的邏輯，針對市場行情取出一條「快線」與一條「慢線」，在計算快慢線時最常被使用到的三個數字是9、12、26。
快線會是12個週期的EMA減去26個週期的EMA，算出兩者的差離值(DIF)，這個數字代表的意義就是快慢週期的偏離狀況，接著將DIF線再依照EMA的概念取一次週期為9的線，就會得出DEM也就是MACD線(訊號線)。
在觀察的時候，會觀察快慢線是向上黃金交叉還是向下死亡交叉，如是黃金交叉且MACD穿越零軸由負翻正，表示行情上漲的機會大，反之若是死亡交叉且MACD跌破零軸由正轉負，則未來行情下跌機會大。
