# Adaptive Flow Channel [Market Structure Lab]

Source: https://www.tradingview.com/script/e59oBSmB-Adaptive-Flow-Channel/

## Description

Adaptive Flow Channel is a trend structure indicator that builds independent adaptive upper and lower flow boundaries instead of relying on a traditional centerline with symmetrical volatility bands.
Unlike conventional channels that simply offset a moving average by a fixed volatility measure, Adaptive Flow Channel models the upper and lower sides of the market independently. Each ribbon responds only to the price behavior relevant to its own side, allowing the channel to expand, contract and reshape asymmetrically as market conditions evolve.
Rather than assuming that bullish and bearish pressure affect the market equally, the indicator continuously evaluates both sides separately. This produces a channel capable of adapting naturally to directional imbalance while maintaining a smooth representation of the underlying market structure.
━━━━━━━━━━━━━━━━━━
🧠 Design Philosophy
━━━━━━━━━━━━━━━━━━
Most volatility channels assume that market structure evolves symmetrically around a central reference line.
Adaptive Flow Channel removes this assumption.
Instead of forcing both channel boundaries to react identically, the algorithm allows each side to evolve independently according to its own directional behavior.
The objective is not to predict price, but to visualize how market structure expands, contracts and transitions over time.
━━━━━━━━━━━━━━━━━━
⚙️ What Makes It Different
━━━━━━━━━━━━━━━━━━
Traditional adaptive channels generally follow concepts such as:
• Moving Average ± ATR
• Moving Average ± Standard Deviation
• Moving Average ± Fixed Offset
In all of these approaches, both boundaries remain mathematically linked.
Adaptive Flow Channel follows a different architecture.
✅ Upper boundary is built from recent Highs
✅ Lower boundary is built from recent Lows
✅ Each side is calculated independently before forming the final channel
✅ The channel naturally deforms whenever directional pressure becomes unbalanced
━━━━━━━━━━━━━━━━━━
🏗 Algorithm Architecture
━━━━━━━━━━━━━━━━━━
① Independent Price Flow
Instead of one central reference, the indicator creates two independent flow models.
• Upper Flow → derived from recent Highs
• Lower Flow → derived from recent Lows
These become the structural foundation of the adaptive channel.
② Volatility Adaptation
Current volatility is measured using ATR.
Instead of acting as a fixed offset, volatility becomes a dynamic scaling component that continuously adjusts ribbon spacing.
As volatility increases, the structure naturally widens.
As volatility decreases, it contracts.
③ Directional Pressure
Directional movement is evaluated separately on each side of the market.
⬆ Positive pressure is estimated from advancing highs.
⬇ Negative pressure is estimated from declining lows.
Both values are normalized by current volatility, allowing consistent behavior across different markets.
④ Independent Ribbon Expansion
This is the defining feature of the algorithm.
Each ribbon expands only according to its own calculated pressure.
Possible structural states include:
🟢 Expanding upper ribbon
🔴 Expanding lower ribbon
🟡 Simultaneous expansion
⚪ Simultaneous contraction
Unlike mirrored channels, neither boundary is constrained by the other.
⑤ Adaptive Smoothing
Both flow models are smoothed independently before rendering.
This reduces short-term market noise while preserving meaningful structural changes.
━━━━━━━━━━━━━━━━━━
🌈 Layered Ribbon Visualization
━━━━━━━━━━━━━━━━━━
Each ribbon consists of multiple adaptive layers surrounding its primary flow boundary.
Ribbon width is calculated dynamically using:
• Current volatility
• Measured directional pressure
As directional activity increases, ribbons gradually widen.
As activity decreases, they naturally contract.
The layered rendering improves structural readability without affecting the underlying calculations.
━━━━━━━━━━━━━━━━━━
📍 Signal Logic
━━━━━━━━━━━━━━━━━━
Signal markers are not generated by ribbon touches or simple crossovers.
Instead, the indicator maintains an internal directional tracking engine.
A signal appears only after:
✅ The internal flow state changes direction
✅ The directional transition is confirmed
This helps reduce repeated signals during sustained trends while highlighting meaningful structural transitions.

━━━━━━━━━━━━━━━━━━
📊 Practical Interpretation
━━━━━━━━━━━━━━━━━━
Typical observations include:
📈 Expanding upper ribbon → strengthening upward pressure
📉 Expanding lower ribbon → strengthening downward pressure
📍 Contracting ribbons → decreasing directional activity
⚖ Asymmetrical ribbon expansion → directional imbalance
🔄 Confirmed flow transition → potential structural change
Adaptive Flow Channel is designed as a market structure visualization tool and is intended to complement price action analysis rather than function as a standalone trading system.

````pine
// This Source Code Form is subject to the terms of the Mozilla Public License 2.0.
// https://mozilla.org/MPL/2.0/
//
// Adaptive Flow Channel
// Developed by Market Structure Lab
//
// An open-source adaptive channel for visualizing
// dynamic upper and lower market flow boundaries.
//
// © Market Structure Lab

//@version=6
indicator(
     title                = "Adaptive Flow Channel [Market Structure Lab]",
     shorttitle           = "AFC",
     overlay              = true,
     explicit_plot_zorder = true
)

//──────────────────────────────────────────────────────────────
// INPUT GROUPS
//──────────────────────────────────────────────────────────────

groupEngine  = "Flow Engine"
groupChannel = "Adaptive Channel"
groupSignals = "Signals"
groupStyle   = "Visual Style"

//──────────────────────────────────────────────────────────────
// FLOW ENGINE
//──────────────────────────────────────────────────────────────

priceSource = input.source(
     close,
     "Source",
     group = groupEngine,
     display = display.none
)

responseLength = input.int(
     20,
     "Response Length",
     minval = 1,
     tooltip = "Controls the sensitivity of the internal directional engine.",
     group = groupEngine,
     display = display.none
)

responseFactor = input.float(
     3.5,
     "Response Factor",
     minval = 0.1,
     step = 0.1,
     tooltip = "Higher values produce fewer directional changes.",
     group = groupEngine,
     display = display.none
)

confirmOnClose = input.bool(
     true,
     "Confirm Signals On Bar Close",
     tooltip = "Signals are displayed only after the current candle closes.",
     group = groupEngine,
     display = display.none
)

//──────────────────────────────────────────────────────────────
// CHANNEL SETTINGS
//──────────────────────────────────────────────────────────────

flowLength = input.int(
     20,
     "Flow Length",
     minval = 2,
     tooltip = "Controls the general speed of the upper and lower ribbons.",
     group = groupChannel,
     display = display.none
)

flowSmoothness = input.int(
     5,
     "Flow Smoothness",
     minval = 1,
     tooltip = "Higher values create smoother and slower ribbon movement.",
     group = groupChannel,
     display = display.none
)

volatilityLength = input.int(
     20,
     "Volatility Length",
     minval = 1,
     tooltip = "Controls how quickly the channel adapts to volatility.",
     group = groupChannel,
     display = display.none
)

channelDistance = input.float(
     1.15,
     "Channel Distance",
     minval = 0.1,
     step = 0.05,
     tooltip = "Controls how far the ribbons are positioned from price.",
     group = groupChannel,
     display = display.none
)

flowReaction = input.float(
     1.4,
     "Flow Reaction",
     minval = 0.0,
     step = 0.1,
     tooltip = "Controls how strongly each ribbon reacts to directional pressure.",
     group = groupChannel,
     display = display.none
)

ribbonThickness = input.float(
     0.75,
     "Ribbon Thickness",
     minval = 0.10,
     maxval = 3.0,
     step = 0.05,
     tooltip = "Controls the thickness of the volumetric ribbons.",
     group = groupChannel,
     display = display.none
)

//──────────────────────────────────────────────────────────────
// SIGNAL SETTINGS
//──────────────────────────────────────────────────────────────

showSignalTags = input.bool(
     true,
     "Show Signal Tags",
     group = groupSignals,
     display = display.none
)

signalDistance = input.float(
     0.05,
     "Signal Distance",
     minval = 0.0,
     maxval = 2.0,
     step = 0.05,
     group = groupSignals,
     display = display.none
)

paintCandles = input.bool(
     false,
     "Color Candles",
     group = groupSignals,
     display = display.none
)

//──────────────────────────────────────────────────────────────
// VISUAL STYLE
//──────────────────────────────────────────────────────────────

upperColor = input.color(
     #FF0000,
     "Upper Ribbon Color",
     group = groupStyle,
     display = display.none
)

lowerColor = input.color(
     #00FFAA,
     "Lower Ribbon Color",
     group = groupStyle,
     display = display.none
)

showRibbonGlow = input.bool(
     true,
     "Show Ribbon Glow",
     group = groupStyle,
     display = display.none
)

showInnerShading = input.bool(
     true,
     "Show Inner Shading",
     group = groupStyle,
     display = display.none
)

showFlowGuide = input.bool(
     false,
     "Show Flow Guide",
     group = groupStyle,
     display = display.none
)

//──────────────────────────────────────────────────────────────
// INTERNAL DIRECTIONAL ENGINE
//──────────────────────────────────────────────────────────────

rawImpulse = math.abs(ta.change(priceSource))

noiseBaseline = ta.rma(
     rawImpulse,
     responseLength
)

flowThreshold =
     noiseBaseline *
     responseFactor

var float trackingLevel = na

previousTracking =
     nz(trackingLevel[1], priceSource)

upperTrigger =
     previousTracking +
     flowThreshold

lowerTrigger =
     previousTracking -
     flowThreshold

if priceSource > upperTrigger
    trackingLevel := priceSource - flowThreshold
else if priceSource < lowerTrigger
    trackingLevel := priceSource + flowThreshold
else
    trackingLevel := previousTracking

//──────────────────────────────────────────────────────────────
// FLOW STATE
//──────────────────────────────────────────────────────────────

var int flowState = 0

if trackingLevel > trackingLevel[1]
    flowState := 1
else if trackingLevel < trackingLevel[1]
    flowState := -1
else
    flowState := nz(flowState[1], 0)

positiveFlow =
     flowState == 1

negativeFlow =
     flowState == -1

positiveShift =
     positiveFlow and
     nz(flowState[1], 0) != 1

negativeShift =
     negativeFlow and
     nz(flowState[1], 0) != -1

signalConfirmed =
     not confirmOnClose or
     barstate.isconfirmed

positiveSignal =
     positiveShift and
     signalConfirmed

negativeSignal =
     negativeShift and
     signalConfirmed

//──────────────────────────────────────────────────────────────
// VOLATILITY ENGINE
//──────────────────────────────────────────────────────────────

trueRangeAverage = ta.rma(
     ta.tr(true),
     volatilityLength
)

safeVolatility =
     math.max(
         trueRangeAverage,
         syminfo.mintick
     )

//──────────────────────────────────────────────────────────────
// INDEPENDENT PRICE FLOW
//──────────────────────────────────────────────────────────────

upperPriceFlow = ta.ema(
     high,
     flowLength
)

lowerPriceFlow = ta.ema(
     low,
     flowLength
)

upperImpulse = ta.rma(
     math.max(
         ta.change(high),
         0.0
     ),
     flowLength
)

lowerImpulse = ta.rma(
     math.max(
         -ta.change(low),
         0.0
     ),
     flowLength
)

upperPressure = math.min(
     upperImpulse / safeVolatility,
     2.0
)

lowerPressure = math.min(
     lowerImpulse / safeVolatility,
     2.0
)

//──────────────────────────────────────────────────────────────
// RAW FLOW BOUNDARIES
//──────────────────────────────────────────────────────────────

rawUpperFlow =
     upperPriceFlow +
     safeVolatility * channelDistance +
     safeVolatility * upperPressure * flowReaction

rawLowerFlow =
     lowerPriceFlow -
     safeVolatility * channelDistance -
     safeVolatility * lowerPressure * flowReaction

upperFlow = ta.ema(
     rawUpperFlow,
     flowSmoothness
)

lowerFlow = ta.ema(
     rawLowerFlow,
     flowSmoothness
)

//──────────────────────────────────────────────────────────────
// ADAPTIVE RIBBON DEPTH
//──────────────────────────────────────────────────────────────

upperDepth =
     safeVolatility *
     ribbonThickness *
     (1.0 + upperPressure * 0.35)

lowerDepth =
     safeVolatility *
     ribbonThickness *
     (1.0 + lowerPressure * 0.35)

// Upper volumetric boundaries.

upperBright =
     upperFlow

upperInner =
     upperFlow +
     upperDepth * 0.30

upperSoft =
     upperFlow +
     upperDepth * 0.65

upperFade =
     upperFlow +
     upperDepth * 1.20

upperGlow =
     upperFlow +
     upperDepth * 1.90

// Lower volumetric boundaries.

lowerBright =
     lowerFlow

lowerInner =
     lowerFlow -
     lowerDepth * 0.30

lowerSoft =
     lowerFlow -
     lowerDepth * 0.65

lowerFade =
     lowerFlow -
     lowerDepth * 1.20

lowerGlow =
     lowerFlow -
     lowerDepth * 1.90

//──────────────────────────────────────────────────────────────
// UPPER RIBBON
//──────────────────────────────────────────────────────────────

upperGlowPlot = plot(
     showRibbonGlow ? upperGlow : na,
     title = "Upper Glow Boundary",
     color = color.new(upperColor, 100),
     editable = false,
     display = display.all - display.status_line
)

upperFadePlot = plot(
     upperFade,
     title = "Upper Fade Boundary",
     color = color.new(upperColor, 100),
     editable = false,
     display = display.all - display.status_line
)

upperSoftPlot = plot(
     upperSoft,
     title = "Upper Soft Boundary",
     color = color.new(upperColor, 96),
     linewidth = 1,
     editable = false,
     display = display.all - display.status_line
)

upperInnerPlot = plot(
     upperInner,
     title = "Upper Inner Boundary",
     color = color.new(upperColor, 98),
     editable = false,
     display = display.all - display.status_line
)

upperBrightPlot = plot(
     upperBright,
     title = "Upper Flow Edge",
     color = color.new(upperColor, 5),
     linewidth = 3,
     display = display.all - display.status_line
)

fill(
     upperGlowPlot,
     upperFadePlot,
     color = showRibbonGlow
         ? color.new(upperColor, 88)
         : na,
     title = "Upper Outer Glow"
)

fill(
     upperFadePlot,
     upperSoftPlot,
     color = color.new(upperColor, 74),
     title = "Upper Outer Volume"
)

fill(
     upperSoftPlot,
     upperInnerPlot,
     color = color.new(upperColor, 64),
     title = "Upper Middle Volume"
)

fill(
     upperInnerPlot,
     upperBrightPlot,
     color = showInnerShading
         ? color.new(upperColor, 54)
         : color.new(upperColor, 68),
     title = "Upper Inner Volume"
)

//──────────────────────────────────────────────────────────────
// LOWER RIBBON
//──────────────────────────────────────────────────────────────

lowerBrightPlot = plot(
     lowerBright,
     title = "Lower Flow Edge",
     color = color.new(lowerColor, 5),
     linewidth = 3,
     display = display.all - display.status_line
)

lowerInnerPlot = plot(
     lowerInner,
     title = "Lower Inner Boundary",
     color = color.new(lowerColor, 98),
     editable = false,
     display = display.all - display.status_line
)

lowerSoftPlot = plot(
     lowerSoft,
     title = "Lower Soft Boundary",
     color = color.new(lowerColor, 96),
     linewidth = 1,
     editable = false,
     display = display.all - display.status_line
)

lowerFadePlot = plot(
     lowerFade,
     title = "Lower Fade Boundary",
     color = color.new(lowerColor, 100),
     editable = false,
     display = display.all - display.status_line
)

lowerGlowPlot = plot(
     showRibbonGlow ? lowerGlow : na,
     title = "Lower Glow Boundary",
     color = color.new(lowerColor, 100),
     editable = false,
     display = display.all - display.status_line
)

fill(
     lowerBrightPlot,
     lowerInnerPlot,
     color = showInnerShading
         ? color.new(lowerColor, 54)
         : color.new(lowerColor, 68),
     title = "Lower Inner Volume"
)

fill(
     lowerInnerPlot,
     lowerSoftPlot,
     color = color.new(lowerColor, 64),
     title = "Lower Middle Volume"
)

fill(
     lowerSoftPlot,
     lowerFadePlot,
     color = color.new(lowerColor, 74),
     title = "Lower Outer Volume"
)

fill(
     lowerFadePlot,
     lowerGlowPlot,
     color = showRibbonGlow
         ? color.new(lowerColor, 88)
         : na,
     title = "Lower Outer Glow"
)

//──────────────────────────────────────────────────────────────
// OPTIONAL FLOW GUIDE
//──────────────────────────────────────────────────────────────

flowGuide =
     (upperFlow + lowerFlow) / 2.0

plot(
     showFlowGuide
         ? flowGuide
         : na,
     title = "Flow Guide",
     color = color.new(color.white, 72),
     linewidth = 1,
     display = display.all - display.status_line
)

//──────────────────────────────────────────────────────────────
// SIGNAL POSITIONS
//──────────────────────────────────────────────────────────────

positiveTagPosition =
     lowerFade -
     safeVolatility * signalDistance

negativeTagPosition =
     upperFade +
     safeVolatility * signalDistance

//──────────────────────────────────────────────────────────────
// SIGNAL TAGS
//──────────────────────────────────────────────────────────────

plotshape(
     showSignalTags and positiveSignal
         ? positiveTagPosition
         : na,
     title = "Positive Flow Signal",
     style = shape.labelup,
     location = location.absolute,
     color = lowerColor,
     text = "",
     textcolor = color.new(lowerColor, 100),
     size = size.small,
     force_overlay = true,
     display = display.all - display.status_line
)

plotshape(
     showSignalTags and negativeSignal
         ? negativeTagPosition
         : na,
     title = "Negative Flow Signal",
     style = shape.labeldown,
     location = location.absolute,
     color = upperColor,
     text = "",
     textcolor = color.new(upperColor, 100),
     size = size.small,
     force_overlay = true,
     display = display.all - display.status_line
)

//──────────────────────────────────────────────────────────────
// OPTIONAL CANDLE COLORING
//──────────────────────────────────────────────────────────────

activeFlowColor =
     positiveFlow ? lowerColor :
     negativeFlow ? upperColor :
     color.gray

barcolor(
     paintCandles
         ? activeFlowColor
         : na
)

//──────────────────────────────────────────────────────────────
// ALERTS
//──────────────────────────────────────────────────────────────

alertcondition(
     positiveSignal,
     title = "Adaptive Flow Positive",
     message = "Adaptive Flow Channel: positive flow confirmed on {{exchange}}:{{ticker}} at {{close}}"
)

alertcondition(
     negativeSignal,
     title = "Adaptive Flow Negative",
     message = "Adaptive Flow Channel: negative flow confirmed on {{exchange}}:{{ticker}} at {{close}}"
)

//──────────────────────────────────────────────────────────────

//──────────────────────────────────────────────────────────────
````
