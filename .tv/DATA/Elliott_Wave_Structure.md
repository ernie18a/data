# Elliott Wave Structure

Source: https://www.tradingview.com/script/MAFSHswT-Elliott-Wave-Structure/

## Description

Elliott Wave Structure is a visual market-structure tool that identifies potential Elliott Wave sequences using confirmed swing highs and lows.

The indicator connects confirmed pivots to create a clear wave structure and labels the most recent sequence as 1–2–3–4–5 and A–B–C when sufficient swing points are available.

Impulse Waves

Wave 1 — The initial move that begins a potential new trend.

Wave 2 — A corrective retracement of Wave 1 that does not completely invalidate the new trend.

Wave 3 — Typically the strongest impulse phase, as participation in the developing trend increases.

Wave 4 — A corrective pause following Wave 3 before the potential final impulse.

Wave 5 — The final impulse wave of the sequence, often occurring with weaker momentum than Wave 3.

Corrective Waves

Wave A — The initial move against the preceding five-wave trend.

Wave B — A temporary counter-move that attempts to resume the previous trend.

Wave C — The final leg of the correction, completing the potential A–B–C structure.

How It Works

The indicator uses confirmed pivot points to identify significant market swings. The **Pivot Length** input controls how sensitive the swing detection is:

* Lower values detect smaller and more frequent swings.
* Higher values focus on larger and more significant swings.

Because pivots require confirmation, the most recent wave structure can change as new price action develops.

Important Note

Elliott Wave analysis involves interpretation and multiple valid wave counts can exist on the same market. This indicator provides a **visual representation of potential wave structure** based on confirmed market swings; it does not determine the definitive Elliott Wave count.

## Source Code

````pine
//@version=6
indicator("Elliott Wave Structure", shorttitle="EW Structure", overlay=true, max_lines_count=100, max_labels_count=100)

//------------------------------------------------------------------------------
// Inputs
//------------------------------------------------------------------------------
pivotLength = input.int(5, "Pivot Length", minval=2, maxval=20)
showZigZag  = input.bool(true, "Show Wave Structure")
showLabels  = input.bool(true, "Show Wave Labels")
showPivots  = input.bool(true, "Show Pivot Points")

//------------------------------------------------------------------------------
// Pivot detection
//------------------------------------------------------------------------------
pivotHigh = ta.pivothigh(high, pivotLength, pivotLength)
pivotLow  = ta.pivotlow(low, pivotLength, pivotLength)

highConfirmed = not na(pivotHigh)
lowConfirmed  = not na(pivotLow)

//------------------------------------------------------------------------------
// Store swing points
//------------------------------------------------------------------------------
var float[] prices = array.new_float()
var int[] bars = array.new_int()
var int[] types = array.new_int()

// type = 1  → swing high
// type = -1 → swing low

addSwing(float price, int barIndex, int swingType) =>
    if array.size(prices) == 0
        array.push(prices, price)
        array.push(bars, barIndex)
        array.push(types, swingType)
    else
        lastType = array.get(types, array.size(types) - 1)
        lastPrice = array.get(prices, array.size(prices) - 1)

        // New swing in the opposite direction.
        if swingType != lastType
            array.push(prices, price)
            array.push(bars, barIndex)
            array.push(types, swingType)

        // Same direction: keep the more extreme pivot.
        else
            if swingType == 1 and price > lastPrice
                array.set(prices, array.size(prices) - 1, price)
                array.set(bars, array.size(bars) - 1, barIndex)

            if swingType == -1 and price < lastPrice
                array.set(prices, array.size(prices) - 1, price)
                array.set(bars, array.size(bars) - 1, barIndex)

    // Keep the latest 8 swing points.
    while array.size(prices) > 8
        array.shift(prices)
        array.shift(bars)
        array.shift(types)

//------------------------------------------------------------------------------
// Register confirmed pivots
//------------------------------------------------------------------------------
if highConfirmed
    addSwing(pivotHigh, bar_index - pivotLength, 1)

if lowConfirmed
    addSwing(pivotLow, bar_index - pivotLength, -1)

//------------------------------------------------------------------------------
// Drawing objects
//------------------------------------------------------------------------------
var line[] structureLines = array.new_line()
var label[] waveLabels = array.new_label()

//------------------------------------------------------------------------------
// Draw structure on the latest bar
//------------------------------------------------------------------------------
if barstate.islast

    // Delete previous wave lines.
    if array.size(structureLines) > 0
        for i = 0 to array.size(structureLines) - 1
            line.delete(array.get(structureLines, i))
        array.clear(structureLines)

    // Delete previous labels.
    if array.size(waveLabels) > 0
        for i = 0 to array.size(waveLabels) - 1
            label.delete(array.get(waveLabels, i))
        array.clear(waveLabels)

    totalPoints = array.size(prices)

    if totalPoints >= 2

        // ---------------------------------------------------------------
        // Determine starting point.
        // ---------------------------------------------------------------
        startIndex = math.max(0, totalPoints - 8)
        visiblePoints = totalPoints - startIndex

        // ---------------------------------------------------------------
        // Draw ZigZag wave structure.
        // ---------------------------------------------------------------
        if showZigZag
            if visiblePoints >= 2
                for i = startIndex to totalPoints - 2

                    x1 = array.get(bars, i)
                    y1 = array.get(prices, i)

                    x2 = array.get(bars, i + 1)
                    y2 = array.get(prices, i + 1)

                    waveLine = line.new(
                         x1=x1,
                         y1=y1,
                         x2=x2,
                         y2=y2,
                         xloc=xloc.bar_index,
                         width=2)

                    array.push(structureLines, waveLine)

        // ---------------------------------------------------------------
        // Draw pivot points and Elliott Wave labels.
        // ---------------------------------------------------------------
        if showLabels or showPivots

            for i = startIndex to totalPoints - 1

                relativeIndex = i - startIndex
                pointBar = array.get(bars, i)
                pointPrice = array.get(prices, i)
                pointType = array.get(types, i)

                // Elliott Wave sequence:
                // 1 → 2 → 3 → 4 → 5 → A → B → C
                waveName = ""

                if visiblePoints == 8
                    if relativeIndex == 0
                        waveName := "1"
                    else if relativeIndex == 1
                        waveName := "2"
                    else if relativeIndex == 2
                        waveName := "3"
                    else if relativeIndex == 3
                        waveName := "4"
                    else if relativeIndex == 4
                        waveName := "5"
                    else if relativeIndex == 5
                        waveName := "A"
                    else if relativeIndex == 6
                        waveName := "B"
                    else if relativeIndex == 7
                        waveName := "C"
                else
                    // Before 8 points are available, use sequential
                    // numbers to make the developing structure visible.
                    waveName := str.tostring(relativeIndex + 1)

                // ---------------------------------------------------------
                // Pivot marker.
                // ---------------------------------------------------------
                if showPivots
                    pivotLabel = label.new(
                         x=pointBar,
                         y=pointPrice,
                         text="",
                         xloc=xloc.bar_index,
                         style=pointType == 1 ? label.style_circle : label.style_circle,
                         size=size.tiny)

                    array.push(waveLabels, pivotLabel)

                // ---------------------------------------------------------
                // Wave label.
                // ---------------------------------------------------------
                if showLabels
                    labelStyle = pointType == 1 ? label.style_label_down : label.style_label_up

                    waveLabel = label.new(
                         x=pointBar,
                         y=pointPrice,
                         text=waveName,
                         xloc=xloc.bar_index,
                         style=labelStyle,
                         size=size.small,
                         textcolor=color.white)

                    array.push(waveLabels, waveLabel)
````
