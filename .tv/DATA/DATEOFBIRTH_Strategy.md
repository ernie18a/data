# Date of Birth Strategy — Annual High & Low Levels

## Overview

The **Date of Birth Strategy** is an experimental market-analysis tool based on the concept of identifying and tracking the High and Low of a market's historically significant "Date of Birth."

For example, if an index or instrument has a defined inception/date-of-birth date, this script identifies the High and Low formed on that particular calendar date and plots those levels across subsequent years.

The objective is to provide a **historical reference framework** that traders can use alongside conventional technical analysis, price action, market structure, and risk-management techniques.

## How It Works

The script:

* Uses a user-defined **Date of Birth**.
* Identifies the corresponding calendar day for each year.
* Captures the **High and Low** of that day's trading session.
* Plots the levels as horizontal reference lines.
* Extends the levels so traders can observe how price reacts around historically derived levels.
* Can be used for historical analysis as well as monitoring future occurrences of the selected calendar date.

### Example

If the selected Date of Birth is **3 November**, the script attempts to identify the High and Low of 3 November for each available year.

These historical levels can then be studied for:

* Support and resistance reactions
* Breakouts and breakdowns
* Price rejection
* Market structure
* Confluence with technical indicators
* Historical price behavior around the annual date

## Important Considerations

This indicator is intended as a **research and educational tool**. Historical price levels do not necessarily have predictive power, and the appearance of a reaction around a DOB level should not be interpreted as proof of a causal relationship.

The results may vary depending on:

* The selected symbol
* Exchange trading calendar
* Historical data availability
* Timeframe
* Session settings
* Corporate actions or contract changes
* Data-feed differences between brokers and exchanges

Users should independently verify important historical levels against reliable market data.

## Suggested Usage

For better analysis, consider combining the DOB levels with established methods such as:

* Price action
* Market structure
* Volume analysis
* Support and resistance
* Moving averages
* Volatility analysis
* Trend analysis
* Risk/reward assessment

Do not use the DOB levels as a standalone signal for entering or exiting a trade.

//@version=6
indicator("DATEOFBIRTH Strategy)", shorttitle="DATEOFBIRTH strategy)", overlay = true, max_lines_count = 500, max_labels_count = 500)

// -----------------------------------------------------------------------------
// USER CONFIGURATION
// -----------------------------------------------------------------------------
var string G_DATE = "Anniversary Target Configuration"
int    targetMonth = input.int(11, "Target Month (1-12)", minval = 1, maxval = 12, group = G_DATE, tooltip = "Default: 11 (November)")
int    targetDay   = input.int(3, "Target Day (1-31)", minval = 1, maxval = 31, group = G_DATE, tooltip = "Default: 3")
int    startYear   = input.int(1995, "Starting Year", minval = 1900, maxval = 2100, group = G_DATE)

var string G_STYLE = "Visual Styling & Display"
color  highColor    = input.color(color.new(#089981, 0), "High Level Color", group = G_STYLE)
color  lowColor     = input.color(color.new(#f23645, 0), "Low Level Color", group = G_STYLE)
int    lineWidth    = input.int(1, "Line Width", minval = 1, maxval = 4, group = G_STYLE)
string lineStyleInp = input.string("Solid", "Line Style", options = ["Solid", "Dashed", "Dotted"], group = G_STYLE)
bool   extendRight  = input.bool(true, "Extend Lines Rightward", group = G_STYLE)
bool   showLabels   = input.bool(true, "Show Year & Price Labels", group = G_STYLE)

// Map line style
lineStyle = switch lineStyleInp
    "Dashed" => line.style_dashed
    "Dotted" => line.style_dotted
    => line.style_solid

lineExtend = extendRight ? extend.right : extend.none

// -----------------------------------------------------------------------------
// PERSISTENT DRAWING STORAGE (Never deletes older levels)
// -----------------------------------------------------------------------------
var line[]  allYearLines  = array.new_line()
var label[] allYearLabels = array.new_label()

// -----------------------------------------------------------------------------
// MULTI-TIMEFRAME DAILY DATA FETCH (EXCHANGE TIMEZONE CONTEXT)
// -----------------------------------------------------------------------------
[dTime, dHigh, dLow] = request.security(
     syminfo.tickerid,
     "1D",
     [time, high, low],
     lookahead = barmerge.lookahead_off,
     gaps = barmerge.gaps_off
 )

// Extract calendar components from the daily bar using exchange timezone
int dYear  = year(dTime, syminfo.timezone)
int dMonth = month(dTime, syminfo.timezone)
int dDay   = dayofmonth(dTime, syminfo.timezone)

// -----------------------------------------------------------------------------
// ZERO-FAIL HOLIDAY ROLLOVER & LEVEL DETECTION LOGIC
// -----------------------------------------------------------------------------
var int  trackedYear       = na
var bool targetCaptured    = false

// Detect the open of a new daily bar
bool isNewDailyBar = ta.change(dTime) != 0

if isNewDailyBar and not na(dYear) and dYear >= startYear
    // When rolling into a new calendar year, reset the flag for the new year
    if na(trackedYear) or dYear != trackedYear
        trackedYear    := dYear
        targetCaptured := false

    // If the anniversary for this year has not yet been captured:
    if not targetCaptured
        // Target timestamp for exact anniversary in milliseconds
        int targetTimestamp = timestamp(syminfo.timezone, dYear, targetMonth, targetDay, 0, 0, 0)

        // If today's bar time is on or after the target timestamp, this is guaranteed
        // to be the exact target date OR the very first trading day after a weekend/holiday.
        if dTime >= targetTimestamp
            targetCaptured := true

            // Format date tag for display (indicates rollover date if holiday)
            string actualDateStr = str.format("{0,date,dd-MMM-yyyy}", dTime)

            // 1. High Level Line
            line hLine = line.new(
                 x1 = dTime,
                 y1 = dHigh,
                 x2 = dTime + 86400000,
                 y2 = dHigh,
                 xloc = xloc.bar_time,
                 extend = lineExtend,
                 color = highColor,
                 style = lineStyle,
                 width = lineWidth
             )
            array.push(allYearLines, hLine)

            // 2. High Level Label
            if showLabels
                label hLabel = label.new(
                     x = dTime,
                     y = dHigh,
                     text = str.tostring(dYear) + " High (" + str.tostring(dHigh, "#.##") + ")\n[" + actualDateStr + "]",
                     xloc = xloc.bar_time,
                     style = label.style_label_lower_left,
                     color = color.new(highColor, 80),
                     textcolor = highColor,
                     size = size.small
                 )
                array.push(allYearLabels, hLabel)

            // 3. Low Level Line
            line lLine = line.new(
                 x1 = dTime,
                 y1 = dLow,
                 x2 = dTime + 86400000,
                 y2 = dLow,
                 xloc = xloc.bar_time,
                 extend = lineExtend,
                 color = lowColor,
                 style = lineStyle,
                 width = lineWidth
             )
            array.push(allYearLines, lLine)

            // 4. Low Level Label
            if showLabels
                label lLabel = label.new(
                     x = dTime,
                     y = dLow,
                     text = str.tostring(dYear) + " Low (" + str.tostring(dLow, "#.##") + ")\n[" + actualDateStr + "]",
                     xloc = xloc.bar_time,
                     style = label.style_label_upper_left,
                     color = color.new(lowColor, 80),
                     textcolor = lowColor,
                     size = size.small
                 )
                array.push(allYearLabels, lLabel)
