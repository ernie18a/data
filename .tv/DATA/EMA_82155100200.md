# EMA 8/21/55/100/200 均线组

Source: https://www.tradingview.com/script/E8IhFUdn/

## Description

EMA 8/21/55/100/200 均线组

一个简洁实用的多周期 EMA 均线系统：将 EMA 8、21、55、100、200 五条指数移动平均线整合到一张图上，帮助快速识别趋势方向、支撑压力位与关键均线突破。适用于股票、指数、外汇、加密货币等品种与任意周期。

与其他均线指标的不同之处

1. EMA 8 智能显隐：默认隐藏；手动开启后，仅在非加密货币市场显示，在加密货币市场中自动隐藏，避免短线均线干扰。
2. 显示长度控制：默认只绘制最近 25 根 K 线内的均线，一键切换全部长度，图表更清爽。
3. 末端数值标签：最后一根 K 线自动标注各均线当前数值，EMA 8 和 EMA 21 额外显示与现价的偏离百分比，方便快速判断乖离。
4. 五档独立警报：价格分别触及 EMA 8、21、55、100、200 时触发提醒。

设置说明

1. 周期：自定义五条均线的周期。
2. 显示长度：是否显示全部长度、最近显示 K 线根数。
3. EMA 开关：各均线的显示开关（EMA 8 智能显隐）。
4. 标签：字号、缩写、差值百分比、标签颜色。
5. 线条颜色与粗细在"样式"页调整。

使用建议

1. 趋势跟随：价格站上 EMA 21/55 且均线多头排列时顺势看多；跌破关键均线时注意风险。
2. 乖离预警：EMA 8 或 EMA 21 偏离现价过大（如超过 1%）时，警惕短线回撤。
3. 支撑压力：EMA 55、100、200 常作为中期与长期支撑压力参考。

风险提示

本指标仅用于技术分析参考，不构成任何投资建议。市场有风险，交易需谨慎。

EMA 8/21/55/100/200 Moving Average Group

A clean and practical multi-timeframe EMA system that combines five exponential moving averages (8, 21, 55, 100, 200) on one chart, helping you quickly identify trend direction, support/resistance levels, and key moving-average breakouts. Works across stocks, indices, forex, crypto, and any timeframe.

What makes it different

1. Smart EMA 8: hidden by default; when enabled, it only appears on non-crypto markets and auto-hides on crypto charts to reduce noise.
2. Display length control: by default, MAs are drawn only over the most recent 25 bars; one click switches to full length for a cleaner chart.
3. Last-bar value labels: the latest bar shows each MA's current value, with EMA 8 and EMA 21 also showing the % distance from price for quick overextension checks.
4. Five independent alerts: get notified when price touches EMA 8, 21, 55, 100, or 200.

Settings

1. Periods: customize each EMA period.
2. Display length: show full length or limit to recent bars.
3. EMA switches: show/hide each EMA (EMA 8 smart show/hide).
4. Labels: size, abbreviation, % difference and label colors.
5. Line colors and widths are adjusted in the Style tab.

Usage tips

1. Trend following: price above EMA 21/55 with bullish MA alignment suggests an uptrend; watch risk below key MAs.
2. Overextension warning: if EMA 8 or EMA 21 deviates too far from price (e.g. more than 1%), be alert to short-term pullbacks.
3. Support and resistance: EMA 55, 100, and 200 often act as medium- and long-term support/resistance references.

## Source Code

````pine
//@version=6
indicator("EMA 8/21/55/100/200 均线组", shorttitle="EMA 21/55/100/200", overlay=true)

// ==================== 1. 周期设置 ====================
group_len = "1. 周期"
ema8_len   = input.int(8,   title="EMA 8 周期",   minval=1, group=group_len)
ema21_len  = input.int(21,  title="EMA 21 周期",  minval=1, group=group_len)
ema55_len  = input.int(55,  title="EMA 55 周期",  minval=1, group=group_len)
ema100_len = input.int(100, title="EMA 100 周期", minval=1, group=group_len)
ema200_len = input.int(200, title="EMA 200 周期", minval=1, group=group_len)

// ==================== 2. 显示长度设置 ====================
group_display = "2. 显示长度"
show_all_bars = input.bool(false, "显示全部长度", group=group_display)
visible_bars  = input.int(25, "仅显示最近 K 线根数", minval=1, group=group_display)

// ==================== 3. EMA 开关设置 ====================
// 说明：线条颜色与粗细请在“样式(Style)”页调整（每个 plot 都有原生样式入口），
//       这里不再重复提供颜色/粗细输入，避免两处设置互相覆盖造成困惑。
group_style = "3. EMA 开关"
is_crypto = syminfo.type == "crypto"
show_ema8_auto = not is_crypto 
show_ema8_manual = input.bool(false, "启用 EMA 8 (智能显隐)", group=group_style, tooltip="【智能显隐说明】：默认隐藏。手动开启后，该均线仅在非加密货币市场（如股市、指数、外汇）中显示。在加密货币市场中，此线会自动隐藏以减少干扰。")
show_ema21        = input.bool(true, "显示 EMA 21", group=group_style)
show_ema55        = input.bool(true, "显示 EMA 55", group=group_style)
show_ema100       = input.bool(true, "显示 EMA 100", group=group_style)
show_ema200       = input.bool(true, "显示 EMA 200", group=group_style)

// ==================== 4. 标签设置 ====================
group_label = "4. 标签"
lbl_size_str = input.string("中", "标签字号", options=["小", "中", "大"], group=group_label)
use_abbr     = input.bool(false, "使用缩写 (E21)", group=group_label)
show_diff_ema8  = input.bool(true, "显示 EMA 8 差值 %", group=group_label)
show_diff_ema21 = input.bool(true, "显示 EMA 21 差值 %", group=group_label)
// 标签文字颜色（标签不会出现在“样式”页，因此在这里单独设置）
lbl_color_ema8   = input.color(color.new(#d1d4dc, 0), "EMA 8 标签颜色", group=group_label)
lbl_color_ema21  = input.color(color.orange, "EMA 21 标签颜色", group=group_label)
lbl_color_ema55  = input.color(color.red,    "EMA 55 标签颜色", group=group_label)
lbl_color_ema100 = input.color(color.purple, "EMA 100 标签颜色", group=group_label)
lbl_color_ema200 = input.color(color.green,  "EMA 200 标签颜色", group=group_label)

f_get_size(_s) => _s == "小" ? size.small : _s == "中" ? size.normal : size.large
lbl_size = f_get_size(lbl_size_str)

// ==================== 5. 指标计算 ====================
ema8   = ta.ema(close, ema8_len)
ema21  = ta.ema(close, ema21_len)
ema55  = ta.ema(close, ema55_len)
ema100 = ta.ema(close, ema100_len)
ema200 = ta.ema(close, ema200_len)

is_visible = show_all_bars or (last_bar_index - bar_index < visible_bars)
final_show_ema8 = show_ema8_manual and show_ema8_auto

// ==================== 6. 绘图 ====================
// 线条默认颜色与粗细在此设定，之后可在“样式”页自由修改（样式页优先）
plot(final_show_ema8 and is_visible ? ema8  : na, title="EMA 8",   color=color.new(#d1d4dc, 0), linewidth=1)
plot(show_ema21       and is_visible ? ema21  : na, title="EMA 21",  color=color.orange, linewidth=1)
plot(show_ema55       and is_visible ? ema55  : na, title="EMA 55",  color=color.red,    linewidth=1)
plot(show_ema100      and is_visible ? ema100 : na, title="EMA 100", color=color.purple, linewidth=1)
plot(show_ema200      and is_visible ? ema200 : na, title="EMA 200", color=color.green,  linewidth=1)

// ==================== 7. 标签函数 ====================
f_draw_label(_show, _val, _len, _color, _show_diff) =>
    var label _lbl = na
    if _show and barstate.islast
        name_prefix = use_abbr ? "E" : "EMA "
        txt_name = name_prefix + str.tostring(_len) + ": " + str.tostring(_val, format.mintick)
        
        txt_diff = ""
        if _show_diff
            raw_diff = (_val - close) / close * 100
            abs_diff = math.abs(raw_diff)
            if abs_diff >= 1.0
                // 移除了“距离：”文字，保持极致简洁
                txt_diff := "\n" + str.tostring(abs_diff, "0.00") + "%"

        label.delete(_lbl) 
        _lbl := label.new(x=bar_index, y=_val, text=txt_name + txt_diff, color=color.new(color.black, 100), textcolor=_color, style=label.style_label_left, size=lbl_size, textalign=text.align_left)

f_draw_label(final_show_ema8, ema8,  ema8_len,   lbl_color_ema8,   show_diff_ema8)
f_draw_label(show_ema21,      ema21, ema21_len,  lbl_color_ema21,  show_diff_ema21)
f_draw_label(show_ema55,      ema55, ema55_len,  lbl_color_ema55,  false)
f_draw_label(show_ema100,     ema100,ema100_len, lbl_color_ema100, false)
f_draw_label(show_ema200,     ema200,ema200_len, lbl_color_ema200, false)

// ==================== 8. 固定参数警报 ====================
alertcondition(ta.cross(close, ema8),   "触及 EMA 8",   "价格触及 EMA 8")
alertcondition(ta.cross(close, ema21),  "触及 EMA 21",  "价格触及 EMA 21")
alertcondition(ta.cross(close, ema55),  "触及 EMA 55",  "价格触及 EMA 55")
alertcondition(ta.cross(close, ema100), "触及 EMA 100", "价格触及 EMA 100")
alertcondition(ta.cross(close, ema200), "触及 EMA 200", "价格触及 EMA 200")
````
