# Multi-Timeframe Qualified Candle Ghost v1.11

Source: https://www.tradingview.com/script/IB0s1eHZ-Ghost-Pattern-Finder/

## Description

Ghost Pattern Finder searches an instrument’s historical price action for candle patterns that closely resemble a user-selected section of the current chart.

The idea is simple:

If price behaved like this before, what happened next?

Unlike a traditional pattern indicator, the script does not look for predefined formations such as triangles, flags, or head-and-shoulders patterns. Instead, you manually select the price sequence you want to analyze. The indicator then searches the instrument’s own history for similar market behavior and overlays the historical pattern directly on the selected area.

Candle-based Ghost Overlay

The historical match is displayed as a transparent candle overlay rather than only as a line.

This makes it possible to visually compare:

candle bodies
wicks
bullish and bearish sequences
local swings
volatility
acceleration and consolidation phases
the overall shape of the move

The overlay is intentionally semi-transparent so the original chart remains clearly visible underneath it.

Historical Candle Forecast

Once a qualified historical match is found, the candles that actually followed that historical pattern are projected forward.

The projected candles are therefore not generated by AI, regression, or mathematical extrapolation.

They are the real OHLC candles that occurred after the historical match, adjusted to the current price level and time scale.

The forecast should therefore be understood as a historical ghost, not as a guaranteed prediction.

Multi-Timeframe Search

The indicator can search neighboring timeframes automatically.

For example, when used on a 1-hour chart, it can compare patterns from approximately:

15 minutes
30 minutes
1 hour
2 hours
4 hours

A match from another timeframe is not required to have exactly the same number of candles.

Variable Pattern Duration

Historical market structures often develop faster or slower than the current pattern.

For this reason, the indicator also searches different pattern lengths within every timeframe.

By default, historical candidates can range from approximately:

0.5× to 2.0× the duration of the selected pattern.

All candidates are normalized before comparison.

This allows the indicator to recognize similar market behavior even when the historical event unfolded at a different speed.

Strict Ghost Qualification

The script does not simply display the best available candidate.

A historical pattern must pass several independent filters before it is accepted as a Qualified Ghost.

The qualification process evaluates:

overall price-shape correlation
correlation of the most recent part of the pattern
candle-body and wick similarity
swing/directional structure
normalized shape distance
robustness when the comparison window is slightly shortened or shifted

If no candidate meets the selected requirements, the indicator displays:

NO QUALIFIED GHOST

This is intentional. A weak historical similarity should not automatically produce a forecast.

Ghost Stability

Similar matches belonging to the same historical event are grouped into a Ghost Family.

This prevents slightly shifted versions of the same historical pattern from being treated as completely new signals.

The AUTO mode also favors the currently active ghost unless another qualified historical event becomes clearly superior.

The goal is to reduce unnecessary forecast switching when only a few new candles appear.

Multiple Ghosts

The indicator can retain several independent qualified historical matches.

The user can choose:

AUTO
Ghost #1
Ghost #2
Ghost #3
Ghost #4
Ghost #5

This allows manual inspection of alternative historical analogs instead of relying entirely on the algorithm’s highest-ranked candidate.

Adjustable Search Parameters

The settings allow control over:

timeframes included in the search
historical search depth
minimum and maximum pattern-duration scaling
search precision
correlation requirements
tail correlation
candle similarity
swing similarity
robustness
shape distance
ranking weights
ghost-family clustering
ghost switching sensitivity

Preset modes are available for easier use:

Strict, Balanced, Loose and Manual.

Appearance

Overlay and forecast visuals can be customized independently.

Users can adjust:

overlay bullish candle color
overlay bearish candle color
overlay wick color
overlay transparency
forecast bullish candle color
forecast bearish candle color
forecast wick color
forecast transparency
selected-pattern area
invalidation level

This allows the historical ghost to remain visible without hiding the original chart.

How to Use

Select a meaningful section of price action using the Pattern START and Pattern END inputs.

The indicator then:

Builds the selected candle pattern.
Searches historical data across the enabled timeframes.
Tests multiple historical pattern durations.
Scores and filters the candidates.
Groups similar candidates into historical Ghost Families.
Overlays the selected ghost as transparent candles.
Projects the actual historical candles that followed it.

For a conservative workflow, start with Ghost Strictness = Strict.

Important

Ghost Pattern Finder is a historical analog analysis tool.

Markets do not have to repeat previous behavior. A high-quality historical match only means that a similar sequence existed in the past; it does not mean the same outcome will occur again.

The projected candles show what happened after a historical analog, not what must happen next.

The indicator does not place trades and should be used as additional market context rather than as a standalone trading signal.

f_merge_one(array<int> dstTime, array<float> dstOpen, array<float> dstHigh, array<float> dstLow, array<float> dstClose, int newTime, float newOpen, float newHigh, float newLow, float newClose) =>

    if not na(newTime) and not na(newClose)

        int n = array.size(dstTime)

        if n == 0

            array.push(dstTime, newTime)
            array.push(dstOpen, newOpen)
            array.push(dstHigh, newHigh)
            array.push(dstLow, newLow)
            array.push(dstClose, newClose)

        else

            int lastIndex = n - 1
            int lastTime = array.get(dstTime, lastIndex)

            if newTime > lastTime

                array.push(dstTime, newTime)
                array.push(dstOpen, newOpen)
                array.push(dstHigh, newHigh)
                array.push(dstLow, newLow)
                array.push(dstClose, newClose)

            else if newTime == lastTime

                array.set(dstOpen, lastIndex, newOpen)
                array.set(dstHigh, lastIndex, newHigh)
                array.set(dstLow, lastIndex, newLow)
                array.set(dstClose, lastIndex, newClose)


f_merge_ltf(array<int> dstTime, array<float> dstOpen, array<float> dstHigh, array<float> dstLow, array<float> dstClose, array<int> reqTime, array<float> reqOpen, array<float> reqHigh, array<float> reqLow, array<float> reqClose) =>

    int n = array.size(reqTime)

    if n > 0

        for i = 0 to n - 1

            f_merge_one(dstTime, dstOpen, dstHigh, dstLow, dstClose, array.get(reqTime, i), array.get(reqOpen, i), array.get(reqHigh, i), array.get(reqLow, i), array.get(reqClose, i))

f_clip01(float value) =>
    math.max(0.0, math.min(1.0, value))


f_array_mean(array<float> values) =>

    int n = array.size(values)
    float total = 0.0

    if n > 0
        for i = 0 to n - 1
            total += array.get(values, i)

    n > 0 ? total / n : na


f_array_std(array<float> values) =>

    int n = array.size(values)
    float result = 0.0

    if n > 0

        float meanValue = f_array_mean(values)
        float sumSquares = 0.0

        for i = 0 to n - 1

            float difference = array.get(values, i) - meanValue
            sumSquares += difference * difference

        result := math.sqrt(sumSquares / n)

    result

f_nearest_time_index(array<int> times, int targetTime) =>

    int n = array.size(times)
    int result = -1

    if n > 0 and targetTime != 0

        int firstTime = array.get(times, 0)
        int lastTime = array.get(times, n - 1)

        if targetTime <= firstTime

            result := 0

        else if targetTime >= lastTime

            result := n - 1

        else

            int lowIndex = 0
            int highIndex = n - 1

            while lowIndex <= highIndex

                int middleIndex = int(math.floor((lowIndex + highIndex) / 2.0))
                int middleTime = array.get(times, middleIndex)

                if middleTime < targetTime

                    lowIndex := middleIndex + 1

                else if middleTime > targetTime

                    highIndex := middleIndex - 1

                else

                    result := middleIndex
                    lowIndex := highIndex + 1

            if result == -1

                int upperCandidate = math.min(n - 1, lowIndex)
                int lowerCandidate = math.max(0, highIndex)

                int upperDistance = math.abs(array.get(times, upperCandidate) - targetTime)
                int lowerDistance = math.abs(array.get(times, lowerCandidate) - targetTime)

                result := upperDistance < lowerDistance ? upperCandidate : lowerCandidate

    result


f_source_last_index_before(int sourceId, int targetTime) =>

    int n = f_source_size(sourceId)
    int result = -1

    if n > 0

        int lowIndex = 0
        int highIndex = n - 1

        while lowIndex <= highIndex

            int middleIndex = int(math.floor((lowIndex + highIndex) / 2.0))
            int middleTime = f_source_time(sourceId, middleIndex)

            if middleTime < targetTime

                result := middleIndex
                lowIndex := middleIndex + 1

            else

                highIndex := middleIndex - 1

    result

f_correlation_slice(array<float> a, array<float> b, int startIndex, int endIndexExclusive) =>

    int totalN = array.size(a)
    float result = na

    int startSafe = math.max(0, startIndex)
    int endSafe = math.min(totalN, endIndexExclusive)
    int count = endSafe - startSafe

    if count > 2 and array.size(b) == totalN

        float meanA = 0.0
        float meanB = 0.0

        for i = startSafe to endSafe - 1

            meanA += array.get(a, i)
            meanB += array.get(b, i)

        meanA /= count
        meanB /= count

        float covariance = 0.0
        float varianceA = 0.0
        float varianceB = 0.0

        for i = startSafe to endSafe - 1

            float da = array.get(a, i) - meanA
            float db = array.get(b, i) - meanB

            covariance += da * db
            varianceA += da * da
            varianceB += db * db

        float denominator = math.sqrt(varianceA * varianceB)

        if denominator > 0.0000000001
            result := covariance / denominator

    result


f_correlation(array<float> a, array<float> b) =>
    f_correlation_slice(a, b, 0, array.size(a))


f_tail_correlation(array<float> a, array<float> b) =>

    int n = array.size(a)
    int tailLength = math.max(6, int(math.round(float(n) * 0.35)))
    int tailStart = math.max(0, n - tailLength)

    f_correlation_slice(a, b, tailStart, n)

f_robustness(array<float> queryShape, array<float> candidateShape) =>

    int n = array.size(queryShape)
    float result = 0.0

    if n > 12

        int trim = math.max(2, int(math.round(float(n) * 0.08)))

        float fullCorr = nz(f_correlation(queryShape, candidateShape), -1.0)
        float noStartCorr = nz(f_correlation_slice(queryShape, candidateShape, trim, n), -1.0)
        float noEndCorr = nz(f_correlation_slice(queryShape, candidateShape, 0, n - trim), -1.0)
        float middleCorr = nz(f_correlation_slice(queryShape, candidateShape, trim, n - trim), -1.0)

        result := f_clip01(math.min(math.min(fullCorr, noStartCorr), math.min(noEndCorr, middleCorr)))

    result

f_weighted_distance(array<float> queryValues, array<float> candidateValues, float recency) =>

    int n = array.size(queryValues)

    float errorSum = 0.0
    float weightSum = 0.0

    if n > 0

        for i = 0 to n - 1

            float progress = n > 1 ? float(i) / float(n - 1) : 0.0
            float weight = 1.0 + recency * progress
            float difference = array.get(queryValues, i) - array.get(candidateValues, i)

            errorSum += weight * difference * difference
            weightSum += weight

    weightSum > 0.0 ? math.sqrt(errorSum / weightSum) : na

// SWING SIMILARITY
//=============================================================================

f_swing_similarity(array<float> queryShape, array<float> candidateShape) =>

    int n = array.size(queryShape)

    float similaritySum = 0.0
    int comparisons = 0

    if n > 8

        int swingStep = math.max(2, int(math.round(float(n) / 24.0)))

        int i = swingStep

        while i < n

            float queryDelta = array.get(queryShape, i) - array.get(queryShape, i - swingStep)
            float candidateDelta = array.get(candidateShape, i) - array.get(candidateShape, i - swingStep)

            float queryAbs = math.abs(queryDelta)
            float candidateAbs = math.abs(candidateDelta)

            float oneSimilarity = 0.0

            if queryAbs < 0.05 and candidateAbs < 0.05

                oneSimilarity := 1.0

            else if queryDelta * candidateDelta > 0.0

                float magnitudeSimilarity = 1.0 / (1.0 + math.abs(queryAbs - candidateAbs))
                oneSimilarity := 0.70 + 0.30 * magnitudeSimilarity

            else if queryAbs < 0.05 or candidateAbs < 0.05

                oneSimilarity := 0.35

            else

                oneSimilarity := 0.0

            similaritySum += oneSimilarity
            comparisons += 1

            i += swingStep

    comparisons > 0 ? similaritySum / comparisons : 0.0

f_build_query_candle_features(int startIndex, int windowLength, int sampleCount, array<float> bodyFeatures, array<float> upperFeatures, array<float> lowerFeatures) =>

    array.clear(bodyFeatures)
    array.clear(upperFeatures)
    array.clear(lowerFeatures)

    for i = 0 to sampleCount - 1

        int relativePosition = sampleCount > 1 ? int(math.round(float(i) * float(windowLength - 1) / float(sampleCount - 1))) : 0

        int candleIndex = startIndex + relativePosition

        float o = array.get(chartOpenData, candleIndex)
        float h = array.get(chartHighData, candleIndex)
        float l = array.get(chartLowData, candleIndex)
        float c = array.get(chartCloseData, candleIndex)

        float candleSpan = math.max(h - l, syminfo.mintick)

        float body = (c - o) / candleSpan
        float upper = (h - math.max(o, c)) / candleSpan
        float lower = (math.min(o, c) - l) / candleSpan

        array.push(bodyFeatures, body)
        array.push(upperFeatures, upper)
        array.push(lowerFeatures, lower)

f_source_candle_similarity(int sourceId, int candidateStart, int candidateLength, int sampleCount, array<float> queryBody, array<float> queryUpper, array<float> queryLower) =>

    float errorSum = 0.0

    for i = 0 to sampleCount - 1

        int relativePosition = sampleCount > 1 ? int(math.round(float(i) * float(candidateLength - 1) / float(sampleCount - 1))) : 0

        int sourceIndex = candidateStart + relativePosition

        float o = f_source_open(sourceId, sourceIndex)
        float h = f_source_high(sourceId, sourceIndex)
        float l = f_source_low(sourceId, sourceIndex)
        float c = f_source_close(sourceId, sourceIndex)

        float candleSpan = math.max(h - l, syminfo.mintick)

        float body = (c - o) / candleSpan
        float upper = (h - math.max(o, c)) / candleSpan
        float lower = (math.min(o, c) - l) / candleSpan

        float bodyError = math.abs(body - array.get(queryBody, i)) / 2.0
        float upperError = math.abs(upper - array.get(queryUpper, i))
        float lowerError = math.abs(lower - array.get(queryLower, i))

        float oneError = 0.50 * bodyError + 0.25 * upperError + 0.25 * lowerError

        errorSum += oneError

    f_clip01(1.0 - errorSum / sampleCount)

f_total_return_raw(array<float> values) =>

    int n = array.size(values)
    float result = 0.0

    if n > 1

        float firstPrice = array.get(values, 0)
        float lastPrice = array.get(values, n - 1)

        float denominator = math.max(math.abs(firstPrice), 0.000000001)

        result := (lastPrice - firstPrice) / denominator

    result


f_volatility_raw(array<float> values) =>

    int n = array.size(values)
    float result = 0.0

    if n > 2

        int returnCount = n - 1
        float returnSum = 0.0

        for i = 1 to n - 1

            float previousPrice = array.get(values, i - 1)
            float currentPrice = array.get(values, i)

            float denominator = math.max(math.abs(previousPrice), 0.000000001)

            returnSum += (currentPrice - previousPrice) / denominator

        float returnMean = returnSum / returnCount
        float variance = 0.0

        for i = 1 to n - 1

            float previousPrice = array.get(values, i - 1)
            float currentPrice = array.get(values, i)

            float denominator = math.max(math.abs(previousPrice), 0.000000001)

            float oneReturn = (currentPrice - previousPrice) / denominator
            float difference = oneReturn - returnMean

            variance += difference * difference

        result := math.sqrt(variance / returnCount)

    result


f_shape_slope(array<float> values) =>

    int n = array.size(values)

    float sumX = 0.0
    float sumY = 0.0
    float sumXX = 0.0
    float sumXY = 0.0

    for i = 0 to n - 1

        float xValue = float(i)
        float yValue = array.get(values, i)

        sumX += xValue
        sumY += yValue
        sumXX += xValue * xValue
        sumXY += xValue * yValue

    float denominator = n * sumXX - sumX * sumX

    math.abs(denominator) > 0.000000001 ? (n * sumXY - sumX * sumY) / denominator : 0.0


f_end_momentum(array<float> values) =>

    int n = array.size(values)
    float result = 0.0

    if n > 4

        int startIndex = int(math.floor(float(n - 1) * 0.80))

        float startPrice = array.get(values, startIndex)
        float endPrice = array.get(values, n - 1)

        result := startPrice != 0.0 ? endPrice / startPrice - 1.0 : 0.0

    result


f_breakout_position(array<float> values) =>

    int n = array.size(values)

    float minimumPrice = array.get(values, 0)
    float maximumPrice = minimumPrice

    for i = 1 to n - 1

        float currentValue = array.get(values, i)

        minimumPrice := math.min(minimumPrice, currentValue)
        maximumPrice := math.max(maximumPrice, currentValue)

    float priceSpan = maximumPrice - minimumPrice

    float result = 0.5

    if priceSpan > 0.000000001
        result := (array.get(values, n - 1) - minimumPrice) / priceSpan

    f_clip01(result)


f_ratio_similarity(float a, float b, float floorValue) =>

    float denominator = math.max(math.max(math.abs(a), math.abs(b)), floorValue)

    1.0 / (1.0 + math.abs(a - b) / denominator)


//=============================================================================

f_evaluate_source_window(int sourceId, int candidateStart, int candidateLength, int sampleCount, array<float> queryRaw, array<float> queryShape, array<float> queryBody, array<float> queryUpper, array<float> queryLower, float queryReturn, float queryVolatility, float querySlope, float queryMomentum, float queryBreakout, array<float> candidateRaw, array<float> candidateShape) =>

    f_fill_source_samples(sourceId, candidateRaw, candidateStart, candidateLength, sampleCount)

    f_normalize_zscore(candidateRaw, candidateShape)

    float corr = nz(f_correlation(queryShape, candidateShape), -1.0)

    float tailCorr = nz(f_tail_correlation(queryShape, candidateShape), -1.0)

    float distance = nz(f_weighted_distance(queryShape, candidateShape, recencyStrength), 10.0)

    float candleSimilarity = f_source_candle_similarity(sourceId, candidateStart, candidateLength, sampleCount, queryBody, queryUpper, queryLower)

    float swingSimilarity = f_swing_similarity(queryShape, candidateShape)

    float robustness = f_robustness(queryShape, candidateShape)

    float candidateReturn = f_total_return_raw(candidateRaw)
    float candidateVolatility = f_volatility_raw(candidateRaw)
    float candidateSlope = f_shape_slope(candidateShape)
    float candidateMomentum = f_end_momentum(candidateRaw)
    float candidateBreakout = f_breakout_position(candidateRaw)

    float returnSimilarity = f_ratio_similarity(queryReturn, candidateReturn, 0.005)
    float volatilitySimilarity = f_ratio_similarity(queryVolatility, candidateVolatility, 0.0001)
    float slopeSimilarity = f_ratio_similarity(querySlope, candidateSlope, 0.005)
    float momentumSimilarity = f_ratio_similarity(queryMomentum, candidateMomentum, 0.005)
    float breakoutSimilarity = f_clip01(1.0 - math.abs(queryBreakout - candidateBreakout))

    float regimeScore = 0.25 * returnSimilarity + 0.20 * volatilitySimilarity + 0.20 * slopeSimilarity + 0.20 * momentumSimilarity + 0.15 * breakoutSimilarity

    float qualityScore = (weightCorrelation * f_clip01(corr) + weightTail * f_clip01(tailCorr) + weightCandles * candleSimilarity + weightSwings * swingSimilarity + weightRobustness * robustness) / totalRankingWeight

    [qualityScore, corr, tailCorr, distance, candleSimilarity, swingSimilarity, robustness, regimeScore]

    bool distanceOK = distance <= maxShapeDistance
    bool candlesOK = candleSimilarity >= minCandleSimilarity

    corrOK and tailOK and distanceOK and candlesOK and swingsOK and robustOK

f_insert_local(array<int> ends, array<int> lengths, array<float> scores, int candidateEnd, int candidateLength, float candidateScore, int poolLimit) =>

    int insertionPosition = 0

    while insertionPosition < array.size(scores) and candidateScore <= array.get(scores, insertionPosition)
        insertionPosition += 1

    if insertionPosition < poolLimit

        array.insert(ends, insertionPosition, candidateEnd)
        array.insert(lengths, insertionPosition, candidateLength)
        array.insert(scores, insertionPosition, candidateScore)

        if array.size(scores) > poolLimit
            array.pop(ends)
            array.pop(lengths)
            array.pop(scores)


f_insert_global(array<int> sourceIds, array<int> ends, array<int> lengths, array<float> scores, array<float> correlations, array<float> tails, array<float> distances, array<float> candles, array<float> swings, array<float> robustnessValues, array<float> regimes, int sourceId, int candidateEnd, int candidateLength, float score, float correlation, float tailCorrelation, float distance, float candleSimilarity, float swingSimilarity, float robustness, float regime, int poolLimit) =>

    int insertionPosition = 0

    while insertionPosition < array.size(scores) and score <= array.get(scores, insertionPosition)
        insertionPosition += 1

    if insertionPosition < poolLimit

        array.insert(sourceIds, insertionPosition, sourceId)
        array.insert(ends, insertionPosition, candidateEnd)
        array.insert(lengths, insertionPosition, candidateLength)

        array.insert(scores, insertionPosition, score)
        array.insert(correlations, insertionPosition, correlation)
        array.insert(tails, insertionPosition, tailCorrelation)
        array.insert(distances, insertionPosition, distance)
        array.insert(candles, insertionPosition, candleSimilarity)
        array.insert(swings, insertionPosition, swingSimilarity)
        array.insert(robustnessValues, insertionPosition, robustness)
        array.insert(regimes, insertionPosition, regime)

        if array.size(scores) > poolLimit

            array.pop(sourceIds)
            array.pop(ends)
            array.pop(lengths)

            array.pop(scores)
            array.pop(correlations)
            array.pop(tails)
            array.pop(distances)
            array.pop(candles)
            array.pop(swings)
            array.pop(robustnessValues)
            array.pop(regimes)

f_interval_overlap_ratio(int startA, int endA, int startB, int endB) =>

    int overlapStart = math.max(startA, startB)
    int overlapEnd = math.min(endA, endB)

    int overlapDuration = math.max(0, overlapEnd - overlapStart)

    int durationA = math.max(1, endA - startA)
    int durationB = math.max(1, endB - startB)

    float(overlapDuration) / float(math.min(durationA, durationB))

f_search_source(int sourceId, bool sourceEnabled, int sourceSeconds, int selectedStartTime, int selectedPatternLength, int chartTfSeconds, int forecastLength, int historySearchBars, int precision, int coarseSamples, int fineSamples, array<float> coarseQueryRaw, array<float> coarseQueryShape, array<float> coarseQueryBody, array<float> coarseQueryUpper, array<float> coarseQueryLower, float coarseQueryReturn, float coarseQueryVolatility, float coarseQuerySlope, float coarseQueryMomentum, float coarseQueryBreakout, array<float> fineQueryRaw, array<float> fineQueryShape, array<float> fineQueryBody, array<float> fineQueryUpper, array<float> fineQueryLower, float fineQueryReturn, float fineQueryVolatility, float fineQuerySlope, float fineQueryMomentum, float fineQueryBreakout, array<int> globalSourceIds, array<int> globalEnds, array<int> globalLengths, array<float> globalScores, array<float> globalCorrs, array<float> globalTails, array<float> globalDistances, array<float> globalCandles, array<float> globalSwings, array<float> globalRobustness, array<float> globalRegimes) =>

    int coarseScanned = 0
    int fineScanned = 0
    int qualifiedCount = 0

    int sourceBarCount = f_source_size(sourceId)

    if sourceEnabled and sourceBarCount > 50

        int sourceCutIndex = f_source_last_index_before(sourceId, selectedStartTime)

        if sourceCutIndex > 20

            int baseLength = int(math.round(float(selectedPatternLength) * float(chartTfSeconds) / float(sourceSeconds)))

            baseLength := math.max(8, baseLength)

            array<int> candidateLengths = array.new_int()

            int durationSteps = math.max(1, int(math.floor((maximumTimeScale - minimumTimeScale) / timeScaleStep)) + 1)

            for scaleIndex = 0 to durationSteps - 1

                float scaleFactor = math.min(maximumTimeScale, minimumTimeScale + float(scaleIndex) * timeScaleStep)

                int candidateLength = int(math.round(float(baseLength) * scaleFactor))

                candidateLength := math.max(8, math.min(MAX_HIST_PATTERN_BARS, candidateLength))

                if array.indexof(candidateLengths, candidateLength) == -1
                    array.push(candidateLengths, candidateLength)

            int finalScaleLength = int(math.round(float(baseLength) * maximumTimeScale))

            finalScaleLength := math.max(8, math.min(MAX_HIST_PATTERN_BARS, finalScaleLength))

            if array.indexof(candidateLengths, finalScaleLength) == -1
                array.push(candidateLengths, finalScaleLength)

            int candidateLengthCount = array.size(candidateLengths)

            int totalCandidateCount = 0

            for lengthIndex = 0 to candidateLengthCount - 1

                int candidateLength = array.get(candidateLengths, lengthIndex)

                float historicalForecastBars = float(forecastLength) * float(candidateLength) / float(selectedPatternLength)

                int requiredFuture = int(math.ceil(historicalForecastBars)) + 2

                int candidateEndMaximum = sourceCutIndex - requiredFuture - 1

                int candidateEndMinimum = math.max(candidateLength - 1, sourceCutIndex - historySearchBars)

                if candidateEndMaximum >= candidateEndMinimum
                    totalCandidateCount += candidateEndMaximum - candidateEndMinimum + 1

            int adaptiveStride = 1

            if totalCandidateCount > 0
                adaptiveStride := int(math.ceil(float(totalCandidateCount) / float(MAX_COARSE_PER_SOURCE)))

            adaptiveStride := math.max(precision, math.max(1, adaptiveStride))

            array<int> coarseEnds = array.new_int()
            array<int> coarseLengths = array.new_int()
            array<float> coarseScores = array.new_float()

            array<float> candidateRaw = array.new_float()
            array<float> candidateShape = array.new_float()

            float tfDistance = math.abs(math.log(float(sourceSeconds) / float(chartTfSeconds))) / math.log(4.0)

            for lengthIndex = 0 to candidateLengthCount - 1

                int candidateLength = array.get(candidateLengths, lengthIndex)

                float historicalForecastBars = float(forecastLength) * float(candidateLength) / float(selectedPatternLength)

                int requiredFuture = int(math.ceil(historicalForecastBars)) + 2

                int candidateEndMaximum = sourceCutIndex - requiredFuture - 1

                int candidateEndMinimum = math.max(candidateLength - 1, sourceCutIndex - historySearchBars)

                if candidateEndMaximum >= candidateEndMinimum

                    int candidateEnd = candidateEndMinimum

                    while candidateEnd <= candidateEndMaximum

                        int candidateStart = candidateEnd - candidateLength + 1

                        [coarseScoreRaw, coarseCorr, coarseTail, coarseDistance, coarseCandle, coarseSwing, coarseRobust, coarseRegime] = f_evaluate_source_window(sourceId, candidateStart, candidateLength, coarseSamples, coarseQueryRaw, coarseQueryShape, coarseQueryBody, coarseQueryUpper, coarseQueryLower, coarseQueryReturn, coarseQueryVolatility, coarseQuerySlope, coarseQueryMomentum, coarseQueryBreakout, candidateRaw, candidateShape)

                        coarseScanned += 1

                        if coarseCorr >= minCorrelation - 0.15

                            float rankedScore = coarseScoreRaw - timeframeTiePenalty * tfDistance

                            f_insert_local(coarseEnds, coarseLengths, coarseScores, candidateEnd, candidateLength, rankedScore, COARSE_POOL_PER_SOURCE)

                        candidateEnd += adaptiveStride

            array<int> fineEnds = array.new_int()
            array<int> fineLengths = array.new_int()
            array<float> fineScores = array.new_float()
            array<int> fineVisited = array.new_int()

            int localStride = math.max(1, int(math.ceil(float(adaptiveStride) / 8.0)))

            int coarseCount = array.size(coarseEnds)

            if coarseCount > 0

                for coarseIndex = 0 to coarseCount - 1

                    int seedEnd = array.get(coarseEnds, coarseIndex)
                    int candidateLength = array.get(coarseLengths, coarseIndex)

                    float historicalForecastBars = float(forecastLength) * float(candidateLength) / float(selectedPatternLength)

                    int requiredFuture = int(math.ceil(historicalForecastBars)) + 2

                    int legalMaximum = sourceCutIndex - requiredFuture - 1

                    int legalMinimum = math.max(candidateLength - 1, sourceCutIndex - historySearchBars)

                    int fineStart = math.max(legalMinimum, seedEnd - adaptiveStride)

                    int fineEnd = math.min(legalMaximum, seedEnd + adaptiveStride)

                    int fineCandidateEnd = fineStart

                    while fineCandidateEnd <= fineEnd

                        int visitKey = fineCandidateEnd * 13001 + candidateLength

                        bool unseen = array.indexof(fineVisited, visitKey) == -1

                        if unseen

                            array.push(fineVisited, visitKey)

                            int fineCandidateStart = fineCandidateEnd - candidateLength + 1

                            [fineScoreRaw, fineCorr, fineTail, fineDistance, fineCandle, fineSwing, fineRobust, fineRegime] = f_evaluate_source_window(sourceId, fineCandidateStart, candidateLength, fineSamples, fineQueryRaw, fineQueryShape, fineQueryBody, fineQueryUpper, fineQueryLower, fineQueryReturn, fineQueryVolatility, fineQuerySlope, fineQueryMomentum, fineQueryBreakout, candidateRaw, candidateShape)

                            fineScanned += 1
