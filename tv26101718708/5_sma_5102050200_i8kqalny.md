## Description

5 SMA (5/10/20/50/200) in a same indicator
You could change the color for each different moving average

## Source Code

````pine
// This Pine Script® code is subject to the terms of the Mozilla Public License 2.0 at https://mozilla.org/MPL/2.0/

//@version=6
indicator("SMA 5/10/20/50/200", overlay=true)
plot(ta.sma(close, 5), color=color.orange)
plot(ta.sma(close, 10), color=color.gray)
plot(ta.sma(close, 20), color=color.green)
plot(ta.sma(close, 50), color=color.blue)
plot(ta.sma(close, 200), color=color.red)
````
