# SBP Structural State Detector

- url: https://www.tradingview.com/script/TU1TVGqu-SBP-Structural-State-Detector/
- type: indicator
- pine_id: PUB;b7a602157fb74996bbbe1734c522dbc5
- version: 2.0

## Description

SBP Structural State Detector is a rule-based analytical indicator designed to identify confirmed changes between bullish and bearish structural states. It does not attempt to predict exact market tops or bottoms. Instead, it evaluates whether current price behaviour provides sufficient evidence that the prevailing directional state has changed.

The script uses one integrated calculation process. It does not require another indicator, external script, higher-timeframe data source, or manual confirmation tool.

Core Method

The calculation begins by measuring price-path efficiency. This compares the net movement of price with the total distance travelled over the same period. A more direct price path receives a higher efficiency reading, while irregular movement produces a lower reading.

That efficiency value controls the response rate of an internal structural centre. The centre adapts more quickly when price movement is directional and more slowly when movement is noisy. The centre is used internally and is not drawn as a separate trendline.

A volatility-normalized structural band is then calculated around the internal centre. Its width expands when price behaviour is less efficient and contracts when movement becomes more orderly. This makes the visible band responsive to both volatility and market noise rather than relying on a fixed price distance.

Directional qualification uses five related observations:

1. Price location relative to the internal structural centre.
2. Normalized displacement from that centre.
3. Direction of the structural slope.
4. Volatility-normalized momentum.
5. Candle direction, body expansion, and closing location.

A bullish or bearish candidate must receive the required level of evidence and must exceed the evidence supporting the opposite direction. The condition must then persist before it can reach the final event process.

Signal Behaviour

All events are evaluated on confirmed bars.

The final event process enforces strict alternation. After a BUY event, another BUY cannot be accepted until a SALE event has occurred. After a SALE event, another SALE cannot be accepted until a BUY event has occurred.

The Minimum Signal Gap setting specifies the minimum number of confirmed bars required between accepted opposite-direction events. It is a spacing control and does not create same-direction re-entry signals.

Chart Display

The Structural State Band changes colour according to the last accepted directional state:

Green indicates that the last accepted event was bullish.
Red indicates that the last accepted event was bearish.
Gray indicates that no directional event has yet been accepted in the loaded chart history.

BUY and SALE triangles identify accepted state changes. They are placed outside the candle using an ATR-based visual distance so that the markers remain readable without changing their event bar.

Inputs

Minimum Signal Gap: Controls the minimum number of confirmed bars between accepted opposite-direction events.

Show Structural State Band: Shows or hides the volatility- and noise-adjusted state band.

Show BUY / SALE: Shows or hides accepted event markers.

State Band Transparency: Controls only the visual transparency of the band and does not affect calculations or events.

Alerts

Two alert conditions are available:

SBP Structural BUY Event
SBP Structural SALE Event

Alerts should be created through TradingView's Create Alert dialog. Alert behaviour follows confirmed BUY and SALE events generated by the script.

How to Use

Apply the indicator to a standard candlestick or bar chart. Observe the band colour together with accepted BUY and SALE events. The indicator is intended to provide a consistent structural-state reference that can be considered alongside the user's own entry, exit, position-sizing, and risk-management rules.

Limitations

This is an indicator, not a strategy. It does not place orders, calculate position size, provide stop-loss levels, provide profit targets, or report backtested performance.

Signals are based on historical and current confirmed price data. Confirmation introduces delay, especially when price changes direction rapidly. Sideways or volatile markets can produce alternating state changes. The Minimum Signal Gap can reduce closely spaced events but cannot eliminate false or late signals.

The indicator does not guarantee accuracy, profitability, or future market direction. Past chart behaviour does not ensure similar future behaviour. Use standard charts for signal interpretation and conduct independent analysis before making trading decisions.

## Source Code

````pine
//@version=6
indicator(
     "SBP Structural State Detector",
     overlay = true,
     max_bars_back = 500)

string GROUP_SIGNAL  = "Signal Settings"
string GROUP_DISPLAY = "Display"

int minimumSignalGap = input.int(
     3,
     "Minimum Signal Gap",
     minval = 0,
     maxval = 50,
     group = GROUP_SIGNAL,
     tooltip = "Minimum confirmed bars between accepted opposite-direction events in the unified sequence.")

string pivotSignalMode = input.string(
     "Balanced",
     "Structural Response Mode",
     options = ["Conservative", "Balanced", "Responsive"],
     group = GROUP_SIGNAL)

int pivotSwingStrength = input.int(
     5,
     "Structural Turn Strength",
     minval = 2,
     maxval = 20,
     group = GROUP_SIGNAL,
     tooltip = "Bars required on both sides to validate a confirmed structural turn.")

bool showStateBand = input.bool(
     true,
     "Show Structural State Band",
     group = GROUP_DISPLAY)

bool showSignals = input.bool(
     true,
     "Show BUY / SALE",
     group = GROUP_DISPLAY)

int stateBandTransparency = input.int(
     82,
     "State Band Transparency",
     minval = 0,
     maxval = 100,
     group = GROUP_DISPLAY)

const int ATR_LENGTH = 14
const int EFFICIENCY_LENGTH = 13
const int MOMENTUM_LENGTH = 8
const int PERSISTENCE_BARS = 2
const int REQUIRED_EVIDENCE = 4

const float BAND_MULTIPLIER = 1.55
const float TRANSITION_THRESHOLD = 0.52
const float RELEASE_THRESHOLD = 0.24

const float FAST_CONSTANT = 2.0 / 3.0
const float SLOW_CONSTANT = 2.0 / 31.0

float atrValue = ta.atr(ATR_LENGTH)

float safeATR =
     math.max(
          atrValue,
          syminfo.mintick)

float candleRange =
     math.max(
          high - low,
          syminfo.mintick)

float closeChange =
     ta.change(close)

float priceChange =
     math.abs(closeChange)

float netTravel =
     math.abs(
          close - close[EFFICIENCY_LENGTH])

float totalTravel =
     math.sum(
          priceChange,
          EFFICIENCY_LENGTH)

float pathEfficiency =
     totalTravel > 0.0
     ? math.min(netTravel / totalTravel, 1.0)
     : 0.0

float adaptiveRate =
     math.pow(
          pathEfficiency *
          (FAST_CONSTANT - SLOW_CONSTANT) +
          SLOW_CONSTANT,
          2.0)

var float stateCenter = na

stateCenter :=
     na(stateCenter[1])
     ? close
     : stateCenter[1] +
       adaptiveRate *
       (close - stateCenter[1])

float stateSlope =
     stateCenter -
     nz(stateCenter[1], stateCenter)

float stateNormalizedSlope =
     stateSlope /
     safeATR

float noiseFactor =
     1.0 +
     (1.0 - pathEfficiency) *
     0.65

float bandDistance =
     safeATR *
     BAND_MULTIPLIER *
     noiseFactor

float stateUpper =
     stateCenter +
     bandDistance

float stateLower =
     stateCenter -
     bandDistance

float normalizedDisplacement =
     bandDistance > 0.0
     ? (close - stateCenter) / bandDistance
     : 0.0

float stateMomentum =
     ta.ema(
          closeChange,
          MOMENTUM_LENGTH)

float normalizedStateMomentum =
     stateMomentum /
     safeATR

float closeLocation =
     (close - low) /
     candleRange

float normalizedBody =
     math.abs(close - open) /
     safeATR

bool bullishCandle =
     close > open and
     closeLocation >= 0.60 and
     normalizedBody >= RELEASE_THRESHOLD

bool bearishCandle =
     close < open and
     closeLocation <= 0.40 and
     normalizedBody >= RELEASE_THRESHOLD

int bullishEvidence =
     (close > stateCenter ? 1 : 0) +
     (normalizedDisplacement >= TRANSITION_THRESHOLD ? 1 : 0) +
     (stateNormalizedSlope > 0.0 ? 1 : 0) +
     (normalizedStateMomentum > 0.0 ? 1 : 0) +
     (bullishCandle ? 1 : 0)

int bearishEvidence =
     (close < stateCenter ? 1 : 0) +
     (normalizedDisplacement <= -TRANSITION_THRESHOLD ? 1 : 0) +
     (stateNormalizedSlope < 0.0 ? 1 : 0) +
     (normalizedStateMomentum < 0.0 ? 1 : 0) +
     (bearishCandle ? 1 : 0)

bool stateBullishCandidate =
     bullishEvidence >= REQUIRED_EVIDENCE and
     bullishEvidence > bearishEvidence

bool stateBearishCandidate =
     bearishEvidence >= REQUIRED_EVIDENCE and
     bearishEvidence > bullishEvidence

int stateCurrentCandidate =
     stateBullishCandidate ? 1 :
     stateBearishCandidate ? -1 :
     0

var int statePendingDirection = 0
var int statePendingBars = 0

if stateCurrentCandidate == 0
    statePendingDirection := 0
    statePendingBars := 0
else if stateCurrentCandidate == statePendingDirection
    statePendingBars += 1
else
    statePendingDirection := stateCurrentCandidate
    statePendingBars := 1

bool stateBullishPersistent =
     statePendingDirection == 1 and
     statePendingBars >= PERSISTENCE_BARS

bool stateBearishPersistent =
     statePendingDirection == -1 and
     statePendingBars >= PERSISTENCE_BARS

var int stateTransitionDirection = 0
var int stateLastEventBar = na

bool stateEventGapPassed =
     na(stateLastEventBar) or
     bar_index - stateLastEventBar >= minimumSignalGap

bool stateRawBuy = false
bool stateRawSale = false

if barstate.isconfirmed and stateEventGapPassed
    if stateTransitionDirection == 0
        if stateBullishPersistent and not stateBearishPersistent
            stateRawBuy := true
        else if stateBearishPersistent and not stateBullishPersistent
            stateRawSale := true
    else if stateTransitionDirection == 1 and stateBearishPersistent
        stateRawSale := true
    else if stateTransitionDirection == -1 and stateBullishPersistent
        stateRawBuy := true

if stateRawBuy
    stateTransitionDirection := 1
    stateLastEventBar := bar_index
    statePendingDirection := 0
    statePendingBars := 0
else if stateRawSale
    stateTransitionDirection := -1
    stateLastEventBar := bar_index
    statePendingDirection := 0
    statePendingBars := 0

int pivotBaseLength =
     pivotSignalMode == "Conservative" ? 34 :
     pivotSignalMode == "Responsive" ? 18 : 24

int pivotSmoothLength =
     pivotSignalMode == "Conservative" ? 12 :
     pivotSignalMode == "Responsive" ? 6 : 9

float pivotPressureThreshold =
     pivotSignalMode == "Conservative" ? 0.18 :
     pivotSignalMode == "Responsive" ? 0.07 : 0.11

float pressureReferenceSlopeThreshold =
     pivotSignalMode == "Conservative" ? 0.035 :
     pivotSignalMode == "Responsive" ? 0.012 : 0.020

int pivotMinimumSignalGap =
     pivotSignalMode == "Conservative" ? 10 :
     pivotSignalMode == "Responsive" ? 4 : 6

float pivotBodyPressure =
     (close - open) /
     candleRange

float pivotClosePressure =
     ((close - low) - (high - close)) /
     candleRange

float pivotWickPressure =
     (
          math.min(open, close) - low -
          (high - math.max(open, close))
     ) /
     candleRange

[plusDI, minusDI, adxValue] =
     ta.dmi(14, 14)

float diTotal =
     math.max(
          plusDI + minusDI,
          1.0)

float pivotDirectionalPressure =
     (plusDI - minusDI) /
     diTotal

float pivotRawPressure =
     pivotBodyPressure        * 0.40 +
     pivotClosePressure       * 0.30 +
     pivotWickPressure        * 0.10 +
     pivotDirectionalPressure * 0.20

float pivotSmoothedPressure =
     ta.ema(
          pivotRawPressure,
          pivotSmoothLength)

float pivotPriceBase =
     ta.ema(
          hlc3,
          pivotBaseLength)

float smoothedATR =
     ta.rma(
          atrValue,
          5)

float pivotPressureAdjustment =
     pivotSmoothedPressure *
     smoothedATR

float pivotRawLine =
     pivotPriceBase +
     pivotPressureAdjustment

float pivotStageOne =
     ta.ema(
          pivotRawLine,
          pivotSmoothLength)

float pivotStageTwo =
     ta.ema(
          pivotStageOne,
          pivotSmoothLength)

float pressureReference =
     2.0 *
     pivotStageOne -
     pivotStageTwo

float pressureReferenceSlope =
     pressureReference -
     nz(
          pressureReference[3],
          pressureReference)

float normalizedPressureSlope =
     pressureReferenceSlope /
     safeATR

float confirmedPivotHigh =
     ta.pivothigh(
          high,
          pivotSwingStrength,
          pivotSwingStrength)

float confirmedPivotLow =
     ta.pivotlow(
          low,
          pivotSwingStrength,
          pivotSwingStrength)

bool pivotHighConfirmed =
     barstate.isconfirmed and
     not na(confirmedPivotHigh)

bool pivotLowConfirmed =
     barstate.isconfirmed and
     not na(confirmedPivotLow)

float reversalPressure =
     pivotSmoothedPressure[pivotSwingStrength]

float reversalSlope =
     normalizedPressureSlope[pivotSwingStrength]

float reversalClose =
     close[pivotSwingStrength]

float reversalReference =
     pressureReference[pivotSwingStrength]

float reversalPlusDI =
     plusDI[pivotSwingStrength]

float reversalMinusDI =
     minusDI[pivotSwingStrength]

float reversalADX =
     adxValue[pivotSwingStrength]

bool bullishPivotQualified =
     pivotLowConfirmed and
     reversalADX >= 12.0 and
     (
          reversalPressure > -pivotPressureThreshold or
          reversalSlope > -pressureReferenceSlopeThreshold or
          reversalClose >= reversalReference or
          reversalPlusDI >= reversalMinusDI
     )

bool bearishPivotQualified =
     pivotHighConfirmed and
     reversalADX >= 12.0 and
     (
          reversalPressure < pivotPressureThreshold or
          reversalSlope < pressureReferenceSlopeThreshold or
          reversalClose <= reversalReference or
          reversalMinusDI >= reversalPlusDI
     )

var int turnEventDirection = 0
var int lastTurnEventBar = na

int confirmedTurnBar =
     bar_index -
     pivotSwingStrength

bool turnGapPassed =
     na(lastTurnEventBar) or
     confirmedTurnBar -
     lastTurnEventBar >= pivotMinimumSignalGap

bool turnRawBuy = false
bool turnRawSale = false

if barstate.isconfirmed and turnGapPassed
    if bullishPivotQualified and turnEventDirection != 1
        turnRawBuy := true
    else if bearishPivotQualified and turnEventDirection != -1
        turnRawSale := true

if turnRawBuy
    turnEventDirection := 1
    lastTurnEventBar := confirmedTurnBar
else if turnRawSale
    turnEventDirection := -1
    lastTurnEventBar := confirmedTurnBar

var int sequenceState = 0

bool buySignal = false
bool saleSignal = false

bool acceptedBuyOnTurnBar = false
bool acceptedSaleOnTurnBar = false

if barstate.isconfirmed
    if sequenceState == 0
        if (stateRawBuy or turnRawBuy) and not (stateRawSale or turnRawSale)
            buySignal := true
            acceptedBuyOnTurnBar := turnRawBuy

        else if (stateRawSale or turnRawSale) and not (stateRawBuy or turnRawBuy)
            saleSignal := true
            acceptedSaleOnTurnBar := turnRawSale

        else if (stateRawBuy or turnRawBuy) and (stateRawSale or turnRawSale)
            if stateRawBuy and not stateRawSale
                buySignal := true
                acceptedBuyOnTurnBar := turnRawBuy
            else if stateRawSale and not stateRawBuy
                saleSignal := true
                acceptedSaleOnTurnBar := turnRawSale

    else if sequenceState == 1
        if (stateRawSale or turnRawSale)
            saleSignal := true
            acceptedSaleOnTurnBar := turnRawSale

    else if sequenceState == -1
        if (stateRawBuy or turnRawBuy)
            buySignal := true
            acceptedBuyOnTurnBar := turnRawBuy

if buySignal
    sequenceState := 1
else if saleSignal
    sequenceState := -1

color stateColor =
     sequenceState == 1 ? color.green :
     sequenceState == -1 ? color.red :
     color.gray

upperPlot = plot(
     showStateBand
     ? stateUpper
     : na,
     title = "Structural State Upper",
     color = color.new(
          color.red,
          35),
     linewidth = 1,
     editable = false)

lowerPlot = plot(
     showStateBand
     ? stateLower
     : na,
     title = "Structural State Lower",
     color = color.new(
          color.green,
          35),
     linewidth = 1,
     editable = false)

fill(
     upperPlot,
     lowerPlot,
     color =
          showStateBand
          ? color.new(
               stateColor,
               stateBandTransparency)
          : na,
     title = "Structural State Band",
     editable = false)

plotshape(
     showSignals and buySignal and not acceptedBuyOnTurnBar,
     title = "State BUY",
     style = shape.labelup,
     location = location.belowbar,
     color = color.rgb(0, 170, 115),
     text = "BUY",
     textcolor = color.white,
     size = size.small,
     editable = false)

plotshape(
     showSignals and saleSignal and not acceptedSaleOnTurnBar,
     title = "State SALE",
     style = shape.labeldown,
     location = location.abovebar,
     color = color.rgb(220, 65, 65),
     text = "SALE",
     textcolor = color.white,
     size = size.small,
     editable = false)

plotshape(
     showSignals and buySignal and acceptedBuyOnTurnBar,
     title = "Confirmed Turn BUY",
     style = shape.labelup,
     location = location.belowbar,
     offset = -pivotSwingStrength,
     color = color.rgb(0, 170, 115),
     text = "BUY",
     textcolor = color.white,
     size = size.small,
     editable = false)

plotshape(
     showSignals and saleSignal and acceptedSaleOnTurnBar,
     title = "Confirmed Turn SALE",
     style = shape.labeldown,
     location = location.abovebar,
     offset = -pivotSwingStrength,
     color = color.rgb(220, 65, 65),
     text = "SALE",
     textcolor = color.white,
     size = size.small,
     editable = false)

alertcondition(
     buySignal,
     title = "SBP Structural BUY",
     message = "SBP Structural State Detector | BUY | {{ticker}} | {{interval}} | Confirmation close {{close}}")

alertcondition(
     saleSignal,
     title = "SBP Structural SALE",
     message = "SBP Structural State Detector | SALE | {{ticker}} | {{interval}} | Confirmation close {{close}}")

alertcondition(
     buySignal or saleSignal,
     title = "SBP Structural BUY or SALE",
     message = "SBP Structural State Detector | New BUY or SALE event | {{ticker}} | {{interval}} | Confirmation close {{close}}")
````
