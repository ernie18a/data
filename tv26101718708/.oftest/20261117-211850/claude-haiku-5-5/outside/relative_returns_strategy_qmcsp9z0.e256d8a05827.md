Go long on the traded instrument when the bar time is at or after the backtest start time and at or before the backtest end time, and: if the return-comparison switch is on and the moving-average switch is on, the moving average of the traded instrument's lookback return is greater than the moving average of the index's lookback return; if the return-comparison switch is on and the moving-average switch is off, the traded instrument's lookback return is greater than the index's lookback return; if the return-comparison switch is off, the difference between the traded instrument's lookback return and the index's lookback return is greater than the moving average of that difference. A lookback return at the current bar is (the series value at the current bar minus its value lookback-length bars earlier) divided by its value at the current bar; the traded instrument's series is its close, and the index's series is the close of the index ticker at the index timeframe for the bar containing each chart bar. Each moving average is of the moving-average type and moving-average length.
Close the long position on the traded instrument when: if the return-comparison switch is on and the moving-average switch is on, the moving average of the traded instrument's lookback return is less than the moving average of the index's lookback return; if the return-comparison switch is on and the moving-average switch is off, the traded instrument's lookback return is less than the index's lookback return; if the return-comparison switch is off, the difference between the traded instrument's lookback return and the index's lookback return is less than the moving average of that difference. A lookback return at the current bar is (the series value at the current bar minus its value lookback-length bars earlier) divided by its value at the current bar; the traded instrument's series is its close, and the index's series is the close of the index ticker at the index timeframe for the bar containing each chart bar. Each moving average is of the moving-average type and moving-average length.
