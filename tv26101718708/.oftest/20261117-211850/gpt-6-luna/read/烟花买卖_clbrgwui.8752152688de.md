Calculation: first Kaufman adaptive moving average = recursive average of close, initialized at zero; each bar's smoothing factor is the square of the interpolation between fast and slow EMA factors using the efficiency ratio abs(close − close N bars ago) / sum of abs(close changes) over N bars, or zero when the denominator is zero. Its period, fast, and slow parameters are separate from the second average's.
Calculation: second Kaufman adaptive moving average = the same calculation with its own separately set period, fast, and slow parameters.
Calculation: first fractal adaptive moving average = recursive average of its selected price, initialized at zero; calculate fractal dimension D = (log(N1 + N2) − log(N3)) / log(2), where for period L and half-period H = L/2, N1 and N2 are high-low ranges over H-bar windows divided by H (the second window is the L-bar window shifted back H bars), and N3 is the high-low range over L bars divided by L. Use the previous D if any range is nonpositive. Set a = clamp(exp(log(2/(slow parameter + 1)) × (D − 1)), 0.01, 1), n = ((slow parameter − fast parameter) × ((2 − a)/a − 1) / (slow parameter − 1)) + fast parameter, and smoothing factor = clamp(2/(n + 1), 2/(slow parameter + 1), 1). Its period, fast, and slow parameters are separately set; its selected price defaults to (high + low)/2.
Calculation: second fractal adaptive moving average = the same calculation with its own separately set period, fast, and slow parameters and selected price; in the dimension exponent, use the first fractal average's slow parameter.
Long: first Kaufman adaptive moving average > second Kaufman adaptive moving average AND first fractal adaptive moving average > second fractal adaptive moving average
Short: first Kaufman adaptive moving average < second Kaufman adaptive moving average AND first fractal adaptive moving average < second fractal adaptive moving average
