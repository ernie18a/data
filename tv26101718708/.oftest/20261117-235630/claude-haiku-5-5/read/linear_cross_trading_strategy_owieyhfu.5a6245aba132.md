Calculation: PredictedPrice = a + b * volume, where a = SMA(close, regression lookback) - b * SMA(volume, regression lookback) and b = SUM((volume - SMA(volume, regression lookback)) * (close - SMA(close, regression lookback)), regression lookback) / SUM((volume - SMA(volume, regression lookback)) * (volume - SMA(volume, regression lookback)), regression lookback)
Long: PredictedPrice crosses above WMA(PredictedPrice, linear lookback) AND MACDsignal(PredictedPrice, shorter lookback, longer lookback, signal lookback) < MACDline(PredictedPrice, shorter lookback, longer lookback) AND rising(MACDline(PredictedPrice, shorter lookback, longer lookback), MACD rising lookback)
Short: MACDline(PredictedPrice, shorter lookback, longer lookback) < MACDsignal(PredictedPrice, shorter lookback, longer lookback, signal lookback) AND falling(MACDline(PredictedPrice, shorter lookback, longer lookback), MACD falling lookback) AND falling(low, low falling lookback)
