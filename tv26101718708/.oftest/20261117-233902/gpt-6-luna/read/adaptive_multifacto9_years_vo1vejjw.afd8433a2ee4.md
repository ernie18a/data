Calculation: Fisher = 0.5 * ln(v / (1 - v)), where v = 0.5 if highest(close, Fisher lookback) = lowest(close, Fisher lookback), otherwise clamp((close - lowest(close, Fisher lookback)) / (highest(close, Fisher lookback) - lowest(close, Fisher lookback)), 0.001, 0.999)
Calculation: Score = (1 if MACD(close, fast lookback, slow lookback, signal lookback).line > MACD(...).signal, otherwise -1) + (1 if Stochastic(high, low, close, stochastic lookback) > SMA(Stochastic(...), stochastic smoothing), otherwise -1) + (1 if Momentum(close, momentum lookback) > 0, otherwise -1) + (1 if RSI(close, RSI lookback) > 50, otherwise -1) + (1 if VortexPlus(high, low, close, Vortex lookback) > VortexMinus(high, low, close, Vortex lookback), otherwise -1) + (1 if +DI(high, low, close, DMI lookback) > -DI(high, low, close, DMI lookback), otherwise -1) + (1 if MFI(high, low, close, volume, MFI lookback) > 50, otherwise -1) + (1 if Fisher > SMA(Fisher, Fisher signal lookback), otherwise -1)
Long: Score >= long score threshold AND Parabolic SAR(low, high, SAR start, SAR increment, SAR maximum) < close AND RSI(close, RSI lookback) < long RSI limit
Short: Score <= short score threshold AND Parabolic SAR(low, high, SAR start, SAR increment, SAR maximum) > close AND RSI(close, RSI lookback) > short RSI limit
Exit: long, Score <= long exit threshold OR Parabolic SAR(low, high, SAR start, SAR increment, SAR maximum) > close
Exit: short, Score >= short exit threshold OR Parabolic SAR(low, high, SAR start, SAR increment, SAR maximum) < close
