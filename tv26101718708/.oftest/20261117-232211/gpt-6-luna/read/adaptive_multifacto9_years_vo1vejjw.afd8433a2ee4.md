Calculation: Parabolic SAR = SAR(low, high, start parameter, increment parameter, maximum parameter)
Calculation: RSI = RSI(close, RSI lookback)
Calculation: Positive vortex index = SUM(abs(high - nz(low[1], 0)), vortex lookback) / SUM(TrueRange, vortex lookback)
Calculation: Negative vortex index = SUM(abs(low - nz(high[1], 0)), vortex lookback) / SUM(TrueRange, vortex lookback)
Calculation: Money flow index = 100 when SUM(negative money flow, money flow lookback) = 0; otherwise 100 - 100 / (1 + SUM(positive money flow, money flow lookback) / SUM(negative money flow, money flow lookback)), where typical price = (high + low + close) / 3, raw money flow = typical price * volume, positive money flow = raw money flow when typical price > nz(typical price[1], 0) and 0 otherwise, and negative money flow = raw money flow when typical price < nz(typical price[1], 0) and 0 otherwise
Calculation: Fisher transform = 0.5 * ln(v / (1 - v)), where v = clamp((close - lowest(close, Fisher lookback)) / (highest(close, Fisher lookback) - lowest(close, Fisher lookback)), 0.001, 0.999), or 0.5 before clamping when highest = lowest
Calculation: Score = sum of eight values, each +1 when its condition is true and -1 otherwise: EMA(close, fast lookback) - EMA(close, slow lookback) > EMA(EMA(close, fast lookback) - EMA(close, slow lookback), signal lookback); Stochastic(high, low, close, stochastic lookback) > SMA(Stochastic(high, low, close, stochastic lookback), stochastic signal lookback); Momentum(close, momentum lookback) > 0; RSI > 50; Positive vortex index > Negative vortex index; DMI positive DI > DMI negative DI (both using the DMI lookback); Money flow index > 50; Fisher transform > SMA(Fisher transform, Fisher signal lookback)
Long: Score >= long score threshold AND Parabolic SAR < close AND RSI < long RSI limit
Short: Score <= short score threshold AND Parabolic SAR > close AND RSI > short RSI limit
Exit: Long, Score <= long exit threshold OR Parabolic SAR > close
Exit: Short, Score >= short exit threshold OR Parabolic SAR < close
