Calculation: Volume RSI = 100 * RMA(abs(source - source[1]) * up volume when source > source[1], RSI lookback) / (RMA(abs(source - source[1]) * up volume when source > source[1], RSI lookback) + RMA(abs(source - source[1]) * down volume when source < source[1], RSI lookback)); up and down volume are summed from T1 bars and mapped to chart bars, using the bar still forming when available; with weighted wicks enabled, for an up T1 bar allocate volume between up and down in proportion to (top wick + body + bottom wick) and (top wick + bottom wick), respectively, using weights 2, 1, 2 for top wick, body, bottom wick in the denominator, and for a down T1 bar allocate it in proportion to (top wick + bottom wick) and (top wick + body + bottom wick), respectively, using the same denominator; otherwise assign all volume to up when close >= open and to down when close < open.
Long: Volume RSI > 50 + 50 * RSI threshold OR (Volume RSI > 50 - 50 * RSI threshold AND prior trend is long)
Short: Volume RSI < 50 - 50 * RSI threshold OR (Volume RSI < 50 + 50 * RSI threshold AND prior trend is short)
