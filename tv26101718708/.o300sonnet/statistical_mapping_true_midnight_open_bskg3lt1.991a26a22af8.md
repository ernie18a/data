參考週期（預設為日；回測週期須小於它）。每根參考週期開盤價為 O。

統計：取過去 90 個已完成的同類週期，日線取同星期幾，日內取同一時段。每個週期算 up = high−open、dn = open−low。收盤 > 開盤的週期記為上漲，收盤 < 開盤的記為下跌，收平者不計。
- 順向幅度 D：上漲週期取 up，下跌週期取 dn。
- 逆向幅度 M：上漲週期取 dn，下跌週期取 up。
- D 與 M 各取樣本的平均或中位數。若同時使用兩者，取較小值。

本週期的四條線（以本週期 O 為基準）：
+D = O + D
−M = O + M
+M = O − M
−D = O − D

做多：本週期最低價 <= O − M，即回落到 +M（下殺假動作區）。這是找多單進場的位置。

做空：本週期最高價 >= O + M，即上衝到 −M（上拉假動作區）。這是找空單進場的位置。

方向偏向（只用來判斷偏多或偏空，不是進場條件）：close > O 為偏多，close < O 為偏空。

出場：
- 多單在最高價 >= O + D（+D）時獲利了結。
- 空單在最低價 <= O − D（−D）時獲利了結。
- 持多單時，O 是反向做空判斷的失效或停損參考線；持空單時同理。

過濾：價格穿越 ±M 後若持續推進而不是停滯，視為趨勢日，不宜逆勢做 ±M 的反轉單。
