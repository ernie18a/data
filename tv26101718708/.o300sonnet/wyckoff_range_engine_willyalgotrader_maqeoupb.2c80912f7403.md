資料皆在收盤確認後逐根計算，做多與做空規則完全對稱。

基本指標：
1. ATR14 = ta.atr(14)。
2. 努力值：有成交量用 volume，否則用 high-low；努力比 = 努力值 / SMA(努力值, 50)。一段走勢的平均努力比、最大努力比，皆取該段各根努力比的平均與最大。
3. 擺動點（ATR 反轉法）：上升段追蹤最高價，當 close < 最高價 − 1.0×ATR 時，確認該最高價為擺動高點，之後轉為下降段追蹤最低價。下降段當 close > 最低價 + 1.0×ATR 時，確認擺動低點。每個擺動點記錄價格、所在K棒、結束於此的那一段的平均努力比、最大努力比、長度（價差/ATR）、K棒數。保留最近60個擺動點。暖機50根以後才開始。

區間座標 u：區間有 top、bottom 與方向 side。吸籌（多）u=(p−bottom)/(top−bottom)；派發（空）u=(top−p)/(top−bottom)。u=0 為高潮端，u=1 為反應端。

一、高潮候選（無活躍區間時，每出現新擺動點就檢查）：
- 以新擺動點為候選（擺動低點對應賣出高潮，擺動高點對應買入高潮）。向前回溯：從倒數第2個擺動點 s 起，每次檢查往前2個的同類擺動點 prevOpp：賣出高潮要求 prevOpp.price > s.price，且兩者之間的擺動點價格 > 候選價；買入高潮方向相反（prevOpp.price < s.price，且中間擺動點價格 < 候選價）。符合就往前2個擺動點繼續，計數+1，否則停止。得到 run 起點價（最後一個 s 的價格）、起點K棒、計數。
- run 價差=|起點價−候選價|，runAtr=價差/ATR，runBars=候選K棒−起點K棒，runEff、runPeak 為起點K棒（不含）到候選K棒的平均與最大努力比。
- 分數=round(30×clamp(runEff−1) + 30×clamp((runPeak−1)/3) + 20×clamp((runAtr−2)/6) + 20×clamp((runAtr/max(runBars,1))/0.5))，clamp 為限制在0到1。
- 條件：計數≥2 且 runPeak≥2.0 且 分數≥60，才成為候選。賣出高潮候選方向=做多（吸籌），買入高潮候選方向=做空（派發）。
- 候選期間若出現更深的同側擺動（低點更低/高點更高）就更新候選價並把其距離加到 run 價差；從候選K棒起超過60根沒確認 AR 就放棄。

二、自動反應 AR（確認區間）：候選期間，出現反應側擺動（做多候選等擺動高點，做空候選等擺動低點），且與候選價距離≥3×ATR，且距離/run價差≥0.5，則建立區間。做多：top=該擺動高點，bottom=候選低點；做空：bottom=該擺動低點，top=候選高點。進入階段A。

三、區間內逐根檢查（依序）：
1. 逾時：自候選K棒起超過400根仍未突破，區間結束（失敗）。
2. 決定性跌破：未突破前，close 的 u < −0.5×ATR/區間高度，區間失敗結束。
3. 待確認彈簧：若有待確認的高潮端破壞，close 的 u≥0 時確認；若超過8根仍未收回則區間失敗。
4. 突破失敗：已突破但尚未 LPS，之後的K棒 close 的 u<0.5，區間失敗結束。
5. 突破 SOS（做多）/SOW（做空）：條件為區間尚未突破、無待確認破壞、目前段落方向與區間方向相同（做多時目前處於上升段，做空時處於下降段）、且已有至少1次 ST 或已有彈簧。目前段落從上一個擺動點（起點）到現在，平均努力比 legEff、長度 legAtr=|close−起點價|/ATR。品質：legEff≥1.2 或 legAtr≥1.5（預設 OR；可改 AND）。突破：close 的 u > 1 + 0.1×ATR/區間高度 且品質成立。成立即 SOS（多）/SOW（空）。
6. LPS 逾時：突破後超過60根無 LPS，區間結束。

四、擺動點分類（區間活躍時，每出現新擺動點）：
高潮端擺動（做多區間為擺動低點、做空區間為擺動高點），u 為該擺動價的 u：
- 若 u<0 且未突破：若當下 close 的 u≥0：若需要先前 ST 且尚無 ST，僅延伸高潮端邊界（bottom/top 改為該擺動價），不算彈簧；否則為 Spring（做多）/ UTAD（做空）。若當下 close 的 u<0，則標為待確認，之後 close u≥0 時（第三項）才確認，此時同樣依「需先前 ST」規則決定是延伸或彈簧。
- 已突破：若尚未 LPS 且該擺動K棒晚於突破K棒且 u≥0.75，則為 LPS（做多）/ LPSY（做空），區間結束。
- 已有彈簧、尚未 Test：u 大於彈簧價的 u 且 u≤0.4 且該段平均努力比小於彈簧段平均努力比，為 Test。
- 其他：0≤u≤0.30 且 ST 次數<3，為 ST（次要測試，ST 次數+1，階段進入B）。
反應側擺動：若有待確認破壞且 u<0，區間失敗；若 u>1 且未突破：尚無 ST 且無彈簧時，反應端延伸（AR+），若延伸後高度>8×ATR 則視為趨勢、放棄區間；其他情況且 close 的 u≤1 為 UT/Shakeout（不改變狀態）。

五、進出場（預設進場事件為 LPS/LPSY，可選 Spring/UTAD、SOS/SOW、Spring+LPS）：
- 做多：事件為 LPS（預設）。選 Spring/UTAD 時為 Spring；選 SOS/SOW 時為 SOS；選 Spring+LPS 時 Spring 或 LPS 皆可。
- 做空：對應事件 LPSY（預設）、UTAD、SOW。
- 進場價為訊號K棒收盤價。已有同方向部位時忽略同向訊號；有反向部位時，反向訊號先平倉再反向開倉（反向訊號平倉只在該K棒，新開倉需當下無部位，即平倉後同一根可立即反向進場）。
- 停損（預設 Wick-Anchored）：做多停損=min(訊號K棒low−0.25×ATR14, close−0.5×ATR14)；做空停損=max(high+0.25×ATR14, close+0.5×ATR14)。Structure 模式：以事件價位（LPS擺動低點/彈簧極值/區間邊緣）取代K棒 low/high，其餘同。ATR 模式：停損=收盤∓1.5×ATR14。風險 R=|進場價−停損|，要求 R>0。
- 停利（Balanced）：TP1=進場±1R，TP2=±2R，TP3=±3R。進場K棒之後的K棒才檢查：做多 high≥目標、做空 low≤目標。TP1 首次觸及後停損移到進場價（保本）；TP3 觸及或停損觸及則出場。同根K棒停損與 TP1/TP3 同時觸及時以停利優先。做多停損觸及條件 low≤停損，做空 high≥停損。
