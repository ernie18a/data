【資料】逐根收盤確認後計算，ATR=14期ATR（high-low-close真實波幅）。圖形標示：高點確認為朝下三角，低點確認為朝上三角，故高點確認指向做空，低點確認指向做多。高低點各自獨立判斷，不強制交替；同一根兩側都成立時不判先後。

【一階段：做空/做多進場】在目前K棒t收盤時，原點為t-3那根（origin=t-3）。
做空（swing high）需同時成立：
1. 左側：high[3] >= max(high[4..9])（6根）。
2. 右側：high[3] > max(high[0..2])（含目前這根，嚴格大於）。
3. 深度過濾：min(high[3]-min(high[4..9]), high[3]-min(high[0..2])) / ATR[3] >= 0.20。
4. 間隔過濾：與上一個被接受的高點原點相隔 >= 3根。
5. 至少有 6+3+1=10 根連續有效資料。
全部成立 → 於t收盤做空。
做多（swing low）為鏡像：low[3] <= min(low[4..9])，low[3] < min(low[0..2])，min(max(low[4..9])-low[3], max(low[0..2])-low[3]) / ATR[3] >= 0.20，與上一個被接受的低點原點相隔 >= 3根 → 做多。

【二階段再確認：同方向】對一階段已被接受的原點，在其後第8根收盤（原點=t-8）：高點原點價 > max(high[0..7]) 則再次指向做空；低點原點價 < min(low[0..7]) 則再次指向做多。

【三階段再確認：同方向】同一原點在其後第21根收盤（原點=t-21）：必須已通過二階段，且高點原點價 > max(high[0..20]) 指向做空；低點原點價 < min(low[0..20]) 指向做多；需21根資料連續有效。
