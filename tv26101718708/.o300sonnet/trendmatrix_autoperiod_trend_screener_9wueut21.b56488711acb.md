【做多/做空：狀態切換】預設用收盤價 src（可選改用 EMA10(close)）。
1. 帶狀線與中線：
- 上錨 = 近20根 src 最高值，下錨 = 近20根 src 最低值。
- m = 近20根 src 的線性回歸在當根的值。
- z = (src − EMA50(src)) / stdev50(src)；stdev 為 0 時 z = 0。
- mu = 2×(1 − 0.4/(1+e^(−z)))，ml = 2×(1 − 0.4/(1+e^(z)))。
- ATR 取20期。vol_rank = 對 stdev200(close) 取 EMA20 後，在252根內的 percentrank，缺值時用50。
- 寬度調整 k = 1 + vol_rank/100×0.5。
- A = 0.7×上錨 + 0.3×m − mu×ATR×k。
- B = 0.7×下錨 + 0.3×m + ml×ATR×k。
- upper = max(A,B)，lower = min(A,B)。
- 中線 C = EMA10((upper+lower)/2)。
2. 預設觸發（快速中線突破）：
- 做多觸發 = src 上穿 C。
- 做空觸發 = src 下穿 C。
3. 另兩種可選觸發：
- 保守：做多 = 最近2根內（含當根）曾上穿 C，且 src > C，且 m > 前一根 m；做空 = 最近2根內曾下穿 C，且 src < C，且 m < 前一根 m。
- 帶狀反轉：做多 = src 上穿 lower；做空 = src 下穿 upper。
4. 狀態機：
- 初始偏多旗標 = false。
- 做多觸發時旗標 = true，做空觸發時旗標 = false，否則維持。
- 做多進場 = 做多觸發，且前一根旗標為 false。
- 做空進場 = 做空觸發，且前一根旗標為 true；因初始旗標為 false，第一個做空觸發不算，須先有做多進場。
5. 出場：多單遇做空進場出場，空單遇做多進場出場，即反向訊號出場。

【出場：停損比較，針對多單】
6. 趨勢停損：
- 在 n ∈ {21,42,63,126,189,252}（加密貨幣同）中，選 ln(close) 對時間回歸的 |Pearson R| 最大者，窗口為最近 n 根。
- 停損價 = 該窗口內最高收盤 × (1 − 20%)。
- close ≤ 停損價即視為跌破，出場。
7. 事件停損：
- 停損價 = 41根前的收盤（共42根窗口起點）× (1 − 10%)。
- close ≤ 停損價即視為跌破，出場。
