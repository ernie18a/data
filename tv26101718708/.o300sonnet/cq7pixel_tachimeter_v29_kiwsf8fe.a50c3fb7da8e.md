一、動量方向（▲多／▼空／停止）：
RPM = 收盤價 − 往前 N 根的收盤價（N 預設 10）。
sRPM = |RPM| × 敏感度（預設 1）。若啟用 ATR 正規化，則 sRPM = |RPM| ÷ ATR(14) × 100 × 敏感度。
- 做多：RPM >= 0 且 sRPM >= 10，顯示 ▲ 並以綠色標示。
- 做空：RPM < 0 且 sRPM >= 10，顯示 ▼ 並以紅色標示。
- sRPM < 10 為停止狀態，視為中性，不做多也不做空。

二、逐根漲跌方向：
- 收盤價 >= 前一根收盤價，標示為多。
- 收盤價 < 前一根收盤價，標示為空。
