只有做多（買進）判斷，沒有做空判斷；出場為賣出持倉（獲利了結）。以下都以每根K線的「交易價」逐根計算：交易價=該根開盤價（開盤模式）或收盤價（收盤確認模式）。

【做多一：回撤買進】
- 追蹤波段高點P：交易價 > P（或P尚未存在）時，P=交易價，並重置4個回撤級別為未使用。
- 回撤% = (交易價 / P − 1)×100。
- 第N級（N=1..4）：該級門檻>0、該級本輪未使用、且 回撤% <= −門檻N 時做多買進（手動預設門檻10、20、30、40，%）。買進成功後該級標為已用，直到出現新高P才重置。可同一根觸發多級。
- 只有資金足以買到至少最小數量才算成立。

【做多二：定期買進】
- 自起始日起，每隔固定天數（預設30天）觸發一次定期買進；起始那根也買一次。

【出場（賣出，多單減碼/平倉）】
過濾：同一根K線若已發生定期買進或回撤買進則不賣；若上次賣出後，交易價尚未升至「上次賣出價×(1+最小再上漲%)」（預設20%）則不賣；一旦升到此價，之後回檔仍保持解鎖。完全平倉後重置。
追蹤停利（模式為追蹤時）：
1. 持倉均價A；估計淨出場價=交易價×(1−成本率)。獲利% = (淨出場價/A −1)×100。
2. 未啟動且 交易價 > 上次觸發時的追蹤高點（若有）且 獲利% >= 啟動門檻（預設50%）時，啟動追蹤，追蹤高點=交易價。
3. 啟動後追蹤高點=max(追蹤高點, 交易價)；停損價=追蹤高點×(1−距離%)（預設3%）。
4. 交易價 <= 停損價時賣出持倉的固定比例（預設20%），並結束追蹤、記錄此追蹤高點，需交易價高於它才能再啟動。
其他賣出模式：
- 定期再平衡：每隔N個月（預設12），若未實現淨獲利>0且現金比例<目標現金%，賣出至達目標現金比例。
- 現金比例再平衡：現金佔比 < 觸發%（預設10）且持倉淨獲利>0時，賣出至現金佔比達目標%。
- 追蹤+現金比例：同追蹤停利的觸發，且淨獲利>0時，賣出至現金佔比達目標%。
現金佔比=(現金−欠費)/(現金−欠費+持倉數量×交易價)。
全部賣出模式預設關閉。
