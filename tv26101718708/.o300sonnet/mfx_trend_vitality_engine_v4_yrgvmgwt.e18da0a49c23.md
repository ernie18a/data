【判斷】
做多：(A) 多方主導；(B) Green Recovery：wt 由下往上穿越 wtSig，且 wt<0，且賣方活力<=40；(C) 買方活力>80 且賣方活力<20。
做空：(A) 空方主導；(B) Blood Diamond：wt 由上往下穿越 wtSig，且 wt>0，且買方活力<=40；(C) 賣方活力>80 且買方活力<20。
多方主導：close>SMA(close,50) 且買方活力>=賣方活力；或不符合空方主導條件時買方活力>賣方活力。
空方主導：close<SMA(close,50) 且賣方活力>=買方活力；或不符合多方主導條件時賣方活力>買方活力。
兩者相等且不符合以上條件時為中性。

【指標計算，全部在回測資料的週期上算】
wt：ap=SMA(hlc3,9)；esa=EMA(ap,12)；d=EMA(|ap-esa|,12)；ci=(ap-esa)/(0.015*d)，d=0 時 ci=0；wt=EMA(ci,3)；wtSig=SMA(wt,3)。
mf：mfv=((close-low)-(high-close))/(high-low)，high=low 時為 0。cmf=sum(mfv*volume,20)/sum(volume,20)，分母為 0 時為 0。mfi=MFI(hlc3,14)。對 cmf 與 mfi 各自做 100 根正規化 (x-lowest100)/(highest100-lowest100)*100-50，區間為 0 時為 0。mf 為兩者的平均。

買方波：wt 上穿 0 時，峰值WT=wt、峰值MF=mf、價格=close、面積=0。wt>0 的每根 K：面積+=wt；若 wt>峰值WT，則更新峰值WT=wt、峰值MF=mf、價格=close。wt 下穿 0 且已有峰值時，把（峰值WT、面積、峰值MF、價格）存成最近一筆完成買方波，保留最近 4 筆，1 為最新，然後清空。
賣方波是鏡像：wt 下穿 0 時啟動，wt<0 時累積|wt|，峰值取|wt| 與|mf|，價格取 close。wt 上穿 0 時存成完成賣方波，同樣保留 4 筆。

買方結構活力（需要第 1 到第 3 筆買方波都存在，賣方同理，用賣方波與下列鏡像條件）：
- 價格創高：價格1>價格3。
- WT 衰減：WT1<WT3。
- 面積衰減：面積1<面積3。
- MF 衰減：MF1<MF3。
- 進度%=(價格1-價格3)/max(價格3,0.0001)*100。
- 能量=max(1,面積1+面積2+面積3)。
- 效率=進度%/能量。
- 賣方鏡像：價格創低為 價格1<價格3，進度%=(價格3-價格1)/max(價格3,0.0001)*100。

效率衰減：只在波完成那根 K，且已有上一次效率時計算。比率=|效率|/max(|上次效率|,0.0001)，比率<0.92 即效率衰減。算完後把上次效率更新為本次效率。

老化衝擊：價格創高且WT衰減 +18；面積衰減 +14；MF衰減 +12；效率衰減 +6；四項(價格創高、WT、面積、MF 都成立) +16。賣方用價格創低。

罰分狀態從 0 起算：波完成那根 K 為 罰分+=衝擊*0.35；其他 K 為 罰分+=衝擊*0.02-0.75。每次更新後夾在 0 到 100。

波分數：
- 有資料時：WT分=clamp(WT1/80,0,1)*35；面積分=clamp(面積1/max(面積2,1),0,2)*17.5；MF分=clamp(MF1/max(MF2,1),0,2)*15；波分數=min(100,三者之和)。
- 沒資料時：波分數=100。

結構活力=clamp((波分數*0.7+(100-罰分)*0.3),0,100)。

即時活力：買方 WT比=min(1,max(0,wt+30)/80)，MF比=min(1,max(0,mf+20)/70)。賣方把 wt、mf 取負號後用同一公式。即時活力=5+45*WT比+45*MF比。

活力=round(clamp(結構活力*0.4+即時活力*0.6,0,100))。買方與賣方各算一個，即上面的買方活力與賣方活力。
