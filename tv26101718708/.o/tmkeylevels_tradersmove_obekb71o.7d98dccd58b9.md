只有開盤區間突破一組判斷，沒有出場判斷。

開盤區間：每個交易時段第一根 K 棒開盤時間記為 t0。取 t0 起前 N 分鐘內（K 棒時間 < t0 + N 分鐘，N 預設 15）所有 K 棒的最高價為 ORH、最低價為 ORL。K 棒週期必須 ≤ N 分鐘，否則不判斷。

做多：在同一時段內，且 K 棒時間 > t0 + N 分鐘，收盤價由下往上穿越 ORH，即 close > ORH 且前一根 close <= ORH。
做空：條件同上，收盤價由上往下穿越 ORL，即 close < ORL 且前一根 close >= ORL。

以收盤確認，每次穿越只觸發一次。三個時段（亞洲、倫敦、紐約）各自獨立計算，開盤區間尚未形成（ORH 或 ORL 為空值）時不判斷。
