共通：ATR=近14根 true range（max(high-low, |high-前收|, |low-前收|)）的簡單平均。轉折高/低=前後各8根(swing=8)中最高/最低的 high/low，需右側8根收盤確認後才成立。只用已確認轉折（最近約10個高點與10個低點、距今≤300根）。

【邊界】任兩個轉折高點連成上邊界、任兩個轉折低點連成下邊界；線上價格=p1+(p2-p1)/(b2-b1)*(b-b1)。有效條件：兩錨點之間及之後每根 high（上邊界）不得高於線+0.25*ATR、low（下邊界）不得低於線-0.25*ATR。上下邊界需有重疊（共同區間≥較長邊界長度的30%）。

【形態分類】角度=atan(每根斜率/ATR)轉度數。平坦=|角度|<1.5度。起點=兩邊界較晚的第一錨點，span=兩邊界較長的錨點跨度。頂點=兩線交點，收斂=頂點在起點之後且距起點≤1.5*span。寬度比=重疊區末端寬度/起端寬度。
- 上下皆平坦且寬度比在1/1.5~1.5：矩形（雙向）。
- 上角<下角且收斂：上平→上升三角（偏多）；下平→下降三角（偏空）；上角<0且下角>0且較小/較大角絕對值比≥0.3→對稱三角（雙向），若span≤40且起點前20根收盤變動≥3*ATR→三角旗（雙向）；兩角同負→下降楔形（偏多）；兩角同正→上升楔形（偏空）。
- 其餘若非快速發散、|上角-下角|≤15度、寬度比在1/1.5~1.5：平均角>1.5度→上升通道（雙向），若span≤40且起點前20根收盤跌≥3*ATR則為熊旗（偏空）；平均角<-1.5度→下降通道（雙向），若span≤40且前20根收盤漲≥3*ATR則為牛旗（偏多）。
- 矩形/上升三角的平坦邊、下降三角的平坦邊，自起點到目前的漂移不得超過形態高度的25%且不得超過1.25*ATR。
- 形態存活：目前根數≤頂點（無頂點則起點+2*span），且距起點≤300根；通道/矩形/旗類寬度比需維持在1/1.5~1.5；旗類超過起點+40根即不再算旗（改為對應通道/對稱三角）。

【頸線形態】
- 雙頂：最近兩個轉折高點價差≤0.5*ATR，且兩者之間最低轉折低點低於兩高點的較低者；頸線=該低點水平線。雙底對稱（轉折低點價差≤0.5*ATR，其間最高轉折高點高於兩低點的較高者）。
- 頭肩頂：最近三個轉折高點，中間頭比兩肩各高>0.5*ATR，兩肩價差≤0.75*ATR，頭與兩肩之間各有一個低於相鄰高點的轉折低點；頸線=這兩個低點連線。頭肩底鏡像。
- 形態高度（頭到頸線或兩頂到頸線）需>0且≤6*ATR。頸線在形成後不得被high（頂型）/low（底型）穿越超過0.25*ATR。

【出場判斷／做多做空方向】逐根收盤判斷：
- 一般形態：收盤>當根上邊界價 → 向上突破（做多方向）；收盤<當根下邊界價 → 向下突破（做空方向）。方向取突破方向，不論該形態傳統偏多或偏空（傳統偏向僅為標示：下降楔形、上升三角、牛旗、雙底、頭肩底偏多；上升楔形、下降三角、熊旗、雙頂、頭肩頂偏空）。
- 雙頂、頭肩頂：收盤<頸線價 → 做空；雙底、頭肩底：收盤>頸線價 → 做多。
- 形態逾期（超過頂點/存活條件）未突破則失效，不進場。

【進場價與停損停利】進場價=突破當根收盤。R=形態高度（左緣處上下邊界價差；頸線形態為頭/頂到頸線距離），上限=前7根日線 true range 平均（無日線資料時可略）。做多：停利=進場+0.25R/0.5R/1R；做空反向。停損=進場價反向至對側邊界在突破當根的價位（頸線形態為兩頂/頭肩的最遠極值），距離至少0.5R。出場：持倉後逐根檢查，做多 high≥停利價 即該停利達成，low≤停損價 即停損出場；做空則 low≤停利價、high≥停損價。
