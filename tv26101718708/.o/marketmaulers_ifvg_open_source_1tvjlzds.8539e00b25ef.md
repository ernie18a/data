做多(看多)＝反向的看空缺口被收盤價向上收破。做空(看空)＝反向的看多缺口被收盤價向下收破。

缺口定義(三根K線，需第三根收盤確認)：
- 看多缺口：本根low > 前兩根(i-2)的high；缺口區間 = [high(i-2), low(i)]。
- 看空缺口：本根high < 前兩根(i-2)的low；缺口區間 = [high(i), low(i-2)]。
- 缺口高度需 >= 2個最小跳動，且 >= 0.03×ATR(14)。
- 缺口形成後30根內有效，超過即作廢。
- 另可把同一段走勢(中間無反向的3K擺動高/低：中間K線的high為三根最高即擺動高、low為三根最低即擺動低)內連續同向的2個以上缺口合併成一個大區間(取最高頂、最低底)，此時須收破整個區間的遠端。

做多進場：
1. 有一個看空缺口(上緣=low(i-2)，下緣=high(i))，在形成後30根內，某根收盤價 > 該缺口上緣 → 做多，進場價取第一次收破那根的收盤價。
2. 過濾：該缺口(含合併區間)須通過下列檢查，檢查分數 = 1(反轉本身) + 以下各項各1分，分數須 >= 2：
   a. 近期掃流動性：近30根內，價格曾向下刺破前低(波段低點為3根pivot low；或前12根最低；或極端大K線 range>3×ATR 的低點)，且該根或其後3根內收盤收回該價位之上，且之後未再跌破該次刺破期間的最低價。
   b. 回補：近30根內價格曾觸及高週期(15m/1H/4H/日，高於當前週期)中方向向上的看多缺口(缺口以該週期K線 low > 前兩根high、且中間K線收陽判定)，且該缺口尚未被收盤跌破其下緣。
   c. 位移：近5根內任一根實體 |close-open| >= 1.2×ATR(14)。
   d. 目標空間：上方存在未被突破的前高(波段高點／極端K線高點／兩個相近的等高點)，距收盤價 >= 1.5×ATR。
   e. SMT：掃低當下，相關品種未同步創低。
3. 缺口形成時間需與掃流動性時點相差15根內才算「有掃流動性」配對。
4. 同方向已有多單尚未走完(尚未到達止盈階梯)且未被止損時，不再做第二次多單；進場後5根內不再重複同方向訊號。
5. 若當下有空單在進行，多單須為反轉：收盤價 > 該空單區域的最高上緣、檢查分數 >= 4、且近5根有位移(實體>=1.2×ATR)，才可反手做多。

做空進場：與做多完全鏡像。
1. 有一個看多缺口(上緣=low(i)，下緣=high(i-2))，形成後30根內某根收盤價 < 該缺口下緣 → 做空，進場價取第一次收破那根的收盤價。
2. 檢查分數(1+各項)須 >= 2：近期向上刺破前高後收回其下、向下的高週期看空缺口被觸及、近5根位移、下方有未被跌破的前低且距離 >= 1.5×ATR、掃高當下相關品種未同步創高。
3. 同方向空單未走完不再開第二次；5根內不重複。
4. 若有多單在進行，空單須收盤價 < 該多單區域最低下緣、分數 >= 4、近5根有位移，才可反手做空。

出場(止損)：
- 多單：收盤價 < 反轉區域(看空缺口)的下緣 → 止損出場；或止損價＝區域下緣 − 2個最小跳動(或近35根最低點 − 2跳動)，以收盤跌破判定。
- 空單：收盤價 > 反轉區域(看多缺口)的上緣 → 止損出場；或止損價＝區域上緣 + 2個最小跳動(或近35根最高點 + 2跳動)。
- 止盈階梯：以單位 U = |近35根擺動極值 − 進場價|(多單取近35根最低點，空單取近35根最高點)，多單目標為進場價 + 1U、2U、2.5U、4U，空單為進場價 − 1U、2U、2.5U、4U；以high/low觸及判定，觸及1U後可將止損移至保本。
- 到達上述最遠階梯(預設4U)、或下一個未被取走的流動性目標價位被收盤觸及後，該單視為完成，不再因收盤跌破區域而止損。
