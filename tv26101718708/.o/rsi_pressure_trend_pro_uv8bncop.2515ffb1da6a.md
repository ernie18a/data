【RSI14】RSI14 = RSI(close, 14)。

【1. RSI 快慢均線方向（預設顯示）】
快線 = EMA(RSI14, 5)，慢線 = EMA(RSI14, 21)；自動模式依週期改用 13/34 等長度，均線種類可選 EMA 或 SMA。快線上穿慢線轉為多方狀態，下穿慢線轉為空方狀態，交叉之間維持原狀態。起始狀態為快線 >= 慢線時偏多，否則偏空。多方狀態指向做多，空方狀態指向做空，出場為狀態反轉。

【2. RSI 慢速均線方向（預設顯示）】
快線 = SMA(RSI14, 20)，慢線 = SMA(RSI14, 50)。判斷方式同第 1 項：上穿為多方、下穿為空方，狀態持續到反向交叉。

【3. 壓力指標均線交叉（預設隱藏）】
快線 = EMA(S0, 5)，慢線 = EMA(S0, 21)，自動模式依週期使用 13/34 等長度。S0 為壓力指標，計算方式見第 5 項。快線上穿慢線為多、下穿為空，狀態持續到反向交叉。

【4. RSI 位階顏色】
RSI14 > 51.5 為偏多色（60、70、80、90 為更強的多方色階）。RSI14 < 48.5 為偏空色（40、30、20、10 為更強的空方色階）。48.5 到 51.5 之間為中性，不指向方向。

【5. 價格確認的壓力趨勢（核心判斷）】
壓力指標 S0 的計算：
- level = RSI14。
- range = 100*(RSI14 - 21 根最低)/(21 根最高 - 21 根最低)，高低相同時為 50。
- trend = 50 + 18*z。z 為 spread 的 34 根標準分數，z = (spread - SMA34(spread))/stdev34(spread)，stdev 為 0 時 z=0。spread = EMA(RSI14,8) - EMA(RSI14,21)。
- velocity = 50 + 16*z。z 為 ROC(RSI14,3) 的 34 根標準分數。
- band = 100*(RSI14 - 下軌)/(上軌 - 下軌)。上下軌 = SMA(RSI14,20) ± 2*stdev(RSI14,20)。
- volume = sum(RSI14*relvol,20)/sum(relvol,20)。relvol = volume/SMA(volume,20)，volume 或均量不大於 0 時 relvol=1。
- 以上各項限制在 0 到 100。
- wt1 = (1.00*level + 1.20*range + 1.35*trend + 0.45*velocity + 0.90*band + 0.60*volume)/5.5。
- 壓力指標 S0 = SMA(wt1, 6)，S = EMA(S0, 3)。

趨勢軌道：
- basis = EMA(hlc3, 21)，ATR = ATR(14)。
- bias = clamp((S-50)/50, -1, 1)，mult = 1 + 0.75*|bias|。
- 多方軌道 = basis - ATR*mult，空方軌道 = basis + ATR*mult。
- 容忍值 tol = 0.05*ATR。

多空狀態：S >= 55 時為多方狀態，S <= 45 時為空方狀態，介於 45 與 55 之間沿用前一狀態，起始為多方。

判斷：
- 做多（確認多方）：S >= 55 且 close >= 多方軌道 - tol。
- 做空（確認空方）：S <= 45 且 close <= 空方軌道 + tol。
- 轉向偏空：S >= 55 但 close < 多方軌道 - tol，此時顯示空方色，視為多方失效、偏空。
- 轉向偏多：S <= 45 但 close > 空方軌道 + tol，此時顯示多方色，視為空方失效、偏多。
- 45 < S < 55 為中性，不指向方向。
- 強度分級：確認多方時 S >= 70 與 S >= 80 的色階更強，確認空方時 S <= 30 與 S <= 20 的色階更強。
- 出場：持多時，上述狀態不再成立、轉為中性或反向就出場，持空時反之。

【6. 成交量加權 RSI 的方向（預設顯示）】
VWA = sum(RSI14*relvol,20)/sum(relvol,20)。VWA >= 前一根標為上升（多方色），VWA < 前一根標為下降（空方色）。

【7. RSI 背離（預設顯示）】
以 RSI14 找擺動點：
- 波峰：RSI 自波段最高回落達 12 點以上時確認。
- 波谷：RSI 自波段最低回升達 12 點以上時確認。
- 每個擺動點記錄該點的 RSI 值與該根的 high（波峰）或 low（波谷）。

與前一個同側擺動點比較：
- 一般看漲背離（做多）：新波谷價格 low 低於前一波谷 low，且新波谷 RSI 高於前一波谷 RSI。
- 一般看跌背離（做空）：新波峰價格 high 高於前一波峰 high，且新波峰 RSI 低於前一波峰 RSI。
- 隱藏看漲背離（做多）：新波谷價格 low 高於前一波谷 low，且新波谷 RSI 低於前一波谷 RSI。
- 隱藏看跌背離（做空）：新波峰價格 high 低於前一波峰 high，且新波峰 RSI 高於前一波峰 RSI。

背離線在最近 144 根內有效；超出範圍就不再視為有效訊號。
