定義：以 ph、pl 表示前一根的高、低，以 ph2、pl2 表示前前根的高、低。
1. 判斷 K 棒類型：
- 內包(1)：高 <= 前根高，且低 >= 前根低。
- 外包(3)：高 > 前根高，且低 < 前根低。
- 2U：高 > 前根高，且低 >= 前根低。
- 2D：低 < 前根低，且高 <= 前根高。
2. 以已收盤的前一根為 setup K 棒，setup高=ph，setup低=pl。進場只看目前這根，每根逐一比較。
3. 做多：目前這根最高價 >= setup高 + 偏移。偏移預設為 1 個最小跳動，可調。
- 若 setup K 棒是 Failed 2D，進場價改為 setup高 + 1 個最小跳動。
- 其他 setup 的進場價為 setup高 + 偏移。
- 單根做多觸發條件：最高價 >= 進場價。
4. 做空：目前這根最低價 <= setup低 - 偏移。
- 若 setup K 棒是 Failed 2U，進場價改為 setup低 - 1 個最小跳動。
- 其他 setup 的進場價為 setup低 - 偏移。
5. 若同一根同時觸及多空兩個進場價，視為外包，不進場。
6. Failed 2 定義（在該根收盤後確認）：
- Failed 2U：該根為 2U 且收盤 < 該根開盤，指向做空。
- Failed 2D：該根為 2D 且收盤 > 該根開盤，指向做多。
- 若該根高低兩側都突破前根，則為 3，不算 Failed 2。
- 前一根的顏色不限。
7. 常見形態與方向（皆以 setup 高低突破決定方向）：
- 前一根是 2D，向上突破其高，是 2-2U 反轉，做多。
- 前一根是 2U，向下突破其低，是 2-2D 反轉，做空。
- 前一根是 2U，向上突破其高，是 2U 延續，做多。
- 前一根是 2D，向下突破其低，是 2D 延續，做空。
- 前一根是 1，向上突破是 x-1-2U，做多；向下突破是 x-1-2D，做空。
- 前一根是 3，向上突破做多，向下突破做空。
8. 出場，持倉中從進場後下一根起逐根判斷：
- 多單停損：最低價 <= setup低 - 偏移。若是 Failed 2D，停損為 setup低 - 1 個最小跳動。
- 空單停損：最高價 >= setup高 + 偏移。若是 Failed 2U，停損為 setup高 + 1 個最小跳動。
- 風險 R = |進場價 - 停損價|。
- 多單停利：最高價 >= 進場價 + 2R（預設 2R，可調 0.5R 到 5R）。
- 空單停利：最低價 <= 進場價 - 2R。
- 同一根同時觸及停利與停損，順序不明，不計輸贏。
- 可選的時間出場（預設關閉）：進場那根為第 0 根，持倉滿 N 根完整 K 棒後，若停利、停損都未觸及，以第 N 根收盤價出場。
9. 可選過濾（預設關閉）：要求所選的多個較大週期，其現價相對各自週期開盤價全部同向。
- 全部現價 > 開盤價才允許做多。
- 全部現價 < 開盤價才允許做空。
- 只過濾進場，已有持倉照常管理。
10. 持倉期間不再開新單。出場後，從下一根起才可再依新的 setup 進場。
