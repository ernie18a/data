【指標】ATR=ATR(14)。轉換線T：T[0]=close[0]；之後每根 pull=close−T[前]，scale=max(ATR×5, 極小值)，alpha=|pull|/(|pull|+scale)，T=T[前]+pull×alpha。每根方向 d=sign(T−T[前])，等同 sign(close−T[前])。d=0 時沿用最近一次非 0 的方向，記為狀態S。第一次出現非 0 的 d 只用來設定S，不產生訊號。
【做多】S 原為下(−1)，本根收盤後翻為上(+1)（即本根 close>T[前]，且前一個非 0 方向為下）時，以本根收盤做多。
【做空】S 原為上(+1)，本根收盤後翻為下(−1)（即本根 close<T[前]，且前一個非 0 方向為上）時，以本根收盤做空。
【過濾】只有S翻向的那一根才算訊號。同一個方向的S持續期間不重複發訊號。
