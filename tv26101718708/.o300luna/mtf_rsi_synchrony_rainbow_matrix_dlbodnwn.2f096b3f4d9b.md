計算：多週期 RSI＝在五個由快至慢的時間框架分別計算 RSI
計算：主 RSI＝五個多週期 RSI 的加權平均，中間兩個權重最高、兩端權重相等、第二快次高
計算：動態通道＝主 RSI 回看高低點的 EMA 平滑值；以通道中點和上下半幅延伸出警戒、力竭及極端邊界，力竭邊界比警戒邊界遠，極端邊界比力竭邊界遠
計算：常規背離＝比較 RSI 頂點或底點所在 bar 的價格高點或低點與 RSI 值，和前一個同類頂點或底點比較
做多：任一多週期 RSI 或主 RSI ≤ 超賣界線
做多：任一多週期 RSI 或主 RSI 出現常規底背離（價格低點更低且 RSI 底點更高）
做多：最快 RSI ≤ 強背離下界且最慢 RSI ≥ 強背離上界，或最快 RSI ≤ 中度背離下界且最慢 RSI ≥ 中度背離上界、且未達強背離
做多：主 RSI 下穿動態下方力竭邊界
做多：主 RSI 位於動態下方極端區且主 RSI 出現常規底背離、最快與最慢 RSI 達強背離條件
做空：任一多週期 RSI 或主 RSI ≥ 超買界線
做空：任一多週期 RSI 或主 RSI 出現常規頂背離（價格高點更高且 RSI 頂點更低）
做空：最快 RSI ≥ 強背離上界且最慢 RSI ≤ 強背離下界，或最快 RSI ≥ 中度背離上界且最慢 RSI ≤ 中度背離下界、且未達強背離
做空：主 RSI 上穿動態上方力竭邊界
做空：主 RSI 位於動態上方力竭區且主 RSI 出現常規頂背離、至少兩個多週期 RSI 同時出現常規頂背離
