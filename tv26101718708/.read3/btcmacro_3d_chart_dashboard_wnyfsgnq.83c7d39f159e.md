Calculation: Z-score(x, lookback) = if STDEV(x, lookback) = 0 then 0 else (x - SMA(x, lookback)) / STDEV(x, lookback)
Calculation: Weighted oscillator = Pi-cycle weight * Z-score(Pi-cycle multiplier * SMA(close, shorter moving-average lookback) / SMA(close, longer moving-average lookback) - Pi-cycle offset, normalization lookback) + MVRV weight * Z-score(close, normalization lookback) + NUPL weight * Z-score(close, normalization lookback) + Puell weight * Z-score(close, normalization lookback) + Stock-to-Flow weight * Z-score(close, normalization lookback) + Risk Wave weight * Z-score(close, normalization lookback) + log-deviation weight * Z-score(LOG(close) - LINEAR_REGRESSION(LOG(close), normalization lookback, current bar), normalization lookback) + M2 weight * Z-score(close / close, normalization lookback) + ISM/PMI weight * Z-score(close, normalization lookback) + volume weight * Z-score(ROC(volume, volume lookback), normalization lookback)
Calculation: Smoothed oscillator = EMA(Weighted oscillator, smoothing lookback)
Long: Smoothed oscillator < center level
Short: Smoothed oscillator > SMA(Smoothed oscillator, cycle lookback) + deviation multiplier * STDEV(Smoothed oscillator, cycle lookback)
