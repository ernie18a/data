Calculation: Higher-is-better score(value, weak threshold, strong threshold) = clamp(100 * (value - weak threshold) / max(strong threshold - weak threshold, denominator floor), 0, 100)
Calculation: Lower-is-better score(value, strong threshold, weak threshold) = clamp(100 * (weak threshold - value) / max(weak threshold - strong threshold, denominator floor), 0, 100)
Calculation: Upside expansion attempt = upside is enabled AND highest(high[1], prior-range lookback) > lowest(low[1], prior-range lookback) AND ((high - low) / ATR(ATR lookback) >= sensitivity-adjusted expansion-bar ATR threshold OR ATR(ATR lookback) / SMA(ATR(ATR lookback), longer ATR-baseline lookback) >= ATR-expansion ratio threshold) AND high > highest(high[1], prior-range lookback) + ATR(ATR lookback) * sensitivity-adjusted edge-break threshold AND (close - low) / (high - low) >= sensitivity-adjusted close-location threshold AND (realtime is permitted OR the bar is confirmed)
Calculation: Downside expansion attempt = downside is enabled AND highest(high[1], prior-range lookback) > lowest(low[1], prior-range lookback) AND ((high - low) / ATR(ATR lookback) >= sensitivity-adjusted expansion-bar ATR threshold OR ATR(ATR lookback) / SMA(ATR(ATR lookback), longer ATR-baseline lookback) >= ATR-expansion ratio threshold) AND low < lowest(low[1], prior-range lookback) - ATR(ATR lookback) * sensitivity-adjusted edge-break threshold AND (close - low) / (high - low) <= 1 - sensitivity-adjusted close-location threshold AND (realtime is permitted OR the bar is confirmed)
Calculation: Active expansion event = the most recent upside or downside expansion attempt, retaining its side, prior-range edge, ATR, event-bar range divided by event ATR, event-bar volume divided by its volume-baseline SMA, and the best high or low since the event; it remains active until another attempt replaces it
Calculation: Event age = number of chart bars since the active expansion event
Calculation: Expansion progress = for an upside event, (highest high since the event - event edge) / event ATR; for a downside event, (event edge - lowest low since the event) / event ATR
Calculation: Inside depth = for an upside event, (event edge - close) / event ATR; for a downside event, (close - event edge) / event ATR
Calculation: Edge distance = for an upside event, (close - event edge) / event ATR; for a downside event, (event edge - close) / event ATR
Calculation: Current relative volume = volume / SMA(volume, volume-baseline lookback)
Calculation: Failure risk score = clamp(expansion-score weight * Higher-is-better score(event-bar range / event ATR, sensitivity-adjusted expansion threshold * weak-expansion multiplier, sensitivity-adjusted expansion threshold * strong-expansion multiplier) + close-failure weight * Higher-is-better score(max(inside depth, 0), 0, max(required-travel threshold * close-depth multiplier, minimum close depth)) + travel-loss weight * Lower-is-better score(expansion progress, required-travel threshold * travel-strength fraction, required-travel threshold) + volume-score weight * Higher-is-better score(max(current relative volume, event-bar relative volume), weak-volume threshold, volume-support threshold * strong-volume multiplier) + re-entry-score weight * Higher-is-better score(max(inside depth, 0), sensitivity-adjusted re-entry threshold, max(required-travel threshold, sensitivity-adjusted re-entry threshold + re-entry margin)), 0, 100)
Calculation: Failure volume is supported = current relative volume >= volume-support threshold OR event-bar relative volume >= volume-support threshold
Calculation: Required travel is missing = expansion progress < required-travel threshold
Calculation: Range re-entry confirmed = inside depth >= sensitivity-adjusted re-entry threshold
Calculation: Trend opposes event = for an upside event, close < EMA(close, context EMA lookback); for a downside event, close > EMA(close, context EMA lookback)
Calculation: Failure confirmation = realtime-allowed mode OR (bar confirmed AND (close-failure mode OR close-and-volume mode AND failure volume is supported OR strict mode AND failure volume is supported AND required travel is missing AND range re-entry is confirmed AND trend opposes event))
Calculation: Reset context = active event AND (event age > failure-window length OR expansion progress >= required-travel threshold * reset-travel multiplier AND edge distance > reset edge-distance threshold)
Calculation: Failure ready = active event AND event age <= failure-window length AND failure confirmation AND range re-entry confirmed AND required travel is missing AND failure risk score >= ready-score threshold
Calculation: Failure watch = active event AND event age <= failure-window length AND (for an upside event, close < event edge; for a downside event, close > event edge) AND required travel is missing AND failure risk score >= watch-score threshold AND NOT failure ready
Calculation: Expansion hold marking = active event AND event age <= failure-window length AND expansion progress >= required-travel threshold AND edge distance > 0 AND (NOT reset context OR failure risk score < watch-score threshold)
Calculation: Unresolved edge marking = active event AND event age <= failure-window length AND NOT reset context AND NOT failure ready AND NOT failure watch AND expansion progress < required-travel threshold
Long: upside expansion attempt OR (active upside event AND (expansion hold marking OR unresolved edge marking)) OR (active downside event AND (failure ready OR failure watch))
Short: downside expansion attempt OR (active downside event AND (expansion hold marking OR unresolved edge marking)) OR (active upside event AND (failure ready OR failure watch))
