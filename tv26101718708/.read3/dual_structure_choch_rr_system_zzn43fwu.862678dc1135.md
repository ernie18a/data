Calculation: Internal structure trend = on chart bars and independently on each dashboard timeframe T1–T6, initialize neutral; track the latest confirmed pivothigh(high, internal pivot lookback, internal pivot lookback) and pivotlow(low, internal pivot lookback, internal pivot lookback); reset each level's broken flag when its corresponding new pivot confirms; set bullish on the first bullish pivot break of an unbroken high and bearish on the first bearish pivot break of an unbroken low, marking that level broken; otherwise retain the trend. Evaluate breaks against the trend before current-bar updates; if both breaks occur, update the high break before the low break. The internal pivot lookback and swing pivot lookback are separate parameters, with the internal lookback shorter.
Calculation: Swing structure trend = on chart bars and independently on each dashboard timeframe T1–T6, initialize neutral; track the latest confirmed pivothigh(high, swing pivot lookback, swing pivot lookback) and pivotlow(low, swing pivot lookback, swing pivot lookback); reset each level's broken flag when its corresponding new pivot confirms; set bullish on the first bullish pivot break of an unbroken high and bearish on the first bearish pivot break of an unbroken low, marking that level broken; otherwise retain the trend. Evaluate breaks against the trend before current-bar updates; if both breaks occur, update the high break before the low break. The swing pivot lookback is longer than the internal pivot lookback.
