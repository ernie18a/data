Calculation: Upper-zone buy, sell, and total volume = the respective footprint volumes summed over the highest configured number of footprint rows, using the configured row width.
Calculation: Upper-zone delta = upper-zone buy volume - upper-zone sell volume.
Calculation: Lower-zone buy, sell, and total volume = the respective footprint volumes summed over the lowest configured number of footprint rows, using the configured row width.
Calculation: Lower-zone delta = lower-zone buy volume - lower-zone sell volume.
Calculation: Average footprint-row volume = total footprint volume / number of footprint rows.
Calculation: Short reference = the highest enabled level swept by the current high beyond the configured sweep depth: the latest confirmed pivot high using the same lookback on each side, the developing session high through the preceding chart bar while in session, or the high of the last completed T1 bar sampled on chart bars. If reclaim is required, include only levels above which the close is below.
Calculation: Long reference = the lowest enabled level swept by the current low beyond the configured sweep depth: the latest confirmed pivot low using the same lookback on each side, the developing session low through the preceding chart bar while in session, or the low of the last completed T1 bar sampled on chart bars. If reclaim is required, include only levels below which the close is above.
Calculation: Short score = the count of these conditions: ATR is available and short reference - close is at least the configured reclaim-distance fraction of ATR(lookback parameter); (high - close) / max(high - low, minimum tick) is at least the configured wick fraction; any upper-zone row has a footprint sell imbalance by the configured imbalance test; upper-zone delta <= 0 OR (POC-row buy volume > 0 AND upper-zone buy volume <= the configured exhaustion factor * POC-row buy volume) OR (average footprint-row volume > 0 AND upper-zone total volume >= the configured absorption factor * average footprint-row volume AND upper-zone delta > 0); volume SMA is unavailable OR volume >= the configured volume factor * SMA(volume, lookback parameter); prior-day context is enabled, prior completed T1 high is available, and high >= prior completed T1 high - configured tolerance.
Calculation: Long score = the count of these conditions: ATR is available and close - long reference is at least the configured reclaim-distance fraction of ATR(lookback parameter); (close - low) / max(high - low, minimum tick) is at least the configured wick fraction; any lower-zone row has a footprint buy imbalance by the configured imbalance test; lower-zone delta >= 0 OR (POC-row sell volume > 0 AND lower-zone sell volume <= the configured exhaustion factor * POC-row sell volume) OR (average footprint-row volume > 0 AND lower-zone total volume >= the configured absorption factor * average footprint-row volume AND lower-zone delta < 0); volume SMA is unavailable OR volume >= the configured volume factor * SMA(volume, lookback parameter); prior-day context is enabled, prior completed T1 low is available, and low <= prior completed T1 low + configured tolerance.
