Calculation: Filtered Williams Vix Fix = V = 100 × (highest(close, WVF period) − low) / highest(close, WVF period); upper = SMA(V, WVF band lookback) + WVF band multiplier × stdev(V, WVF band lookback); range = highest(V, WVF range lookback) × WVF range fraction; (V[1] ≥ upper[1] OR V[1] ≥ range[1]) AND V < upper AND V < range AND low > low[1] AND close > high[1] AND (close < close[long downtrend lookback] OR close < close[mid downtrend lookback]) AND close > close[strength lookback].
Calculation: Williams Vix Fix Top = V = 100 × (lowest(close, WVF period) − high) / lowest(close, WVF period); lower = SMA(V, WVF band lookback) − WVF band multiplier × stdev(V, WVF band lookback); range = lowest(V, WVF range lookback) × WVF range fraction; (V[1] ≤ lower[1] OR V[1] ≤ range[1]) AND V > lower AND V > range.
Calculation: Trend Quality Index = arithmetic mean of efficiency ratio, clipped volatility quality, clipped structure quality, and clipped momentum quality; efficiency ratio = min(abs(close − close[ER lookback]) / sum(abs(close − close[1]), ER lookback), 1), or 0 when the denominator is 0; volatility quality = clip((ATR(volatility lookback) / SMA(ATR(volatility lookback), twice the volatility lookback) − volatility ratio floor) / volatility ratio scale); structure quality = clip(((close − SMA(close, structure lookback)) / ATR(volatility lookback) + structure offset) / structure scale); momentum quality = clip(((close − close[momentum lookback]) / close[momentum lookback] × 100 + momentum offset) / momentum scale), or 0 when close[momentum lookback] ≤ 0; clip each quality to its configured bounds.

Calculation: Confluence score = configured EMA weight if enabled bullish EMA alignment occurred within the core arm window of the latest filtered-WVF occurrence, plus configured VIDYA weight if enabled bullish VIDYA occurred within that window, plus configured OBV weight if Candle-signed OBV > its value at the OBV lookback, plus configured DELTA weight if EMA(signed candle volume, DELTA lookback) > 0 occurred within the DELTA arm window of the latest filtered-WVF occurrence, plus configured FVG weight if FVG scoring is enabled and Bullish FVG armed, plus TQI score contribution, plus configured VOL-HI weight if PercentRank(ATR(VOL ATR lookback), VOL rank lookback) ≥ VOL-HI cut, minus configured VOL-LO penalty if that PercentRank is below the VOL-LO cut.

Calculation: Normalized CVI = (close − lowest(low, CVI lookback)) / (highest(high, CVI lookback) − lowest(low, CVI lookback)), or the configured neutral value when the range is 0.
Calculation: Market-bias up component = max(HMA(sum(max((close − close[momentum lookback]) / EMA(high − low, momentum lookback) × 100, 0), bias lookback), smoothing lookback), 0); down component = max(HMA(−sum(min((close − close[momentum lookback]) / EMA(high − low, momentum lookback) × 100, 0), bias lookback), smoothing lookback), 0); bound = EMA(average(up component, down component), bound lookback) + stdev(average(up component, down component), bound lookback) × bound multiplier.
Calculation: Bull-pressure percentage = 100 × sum(1 when close ≥ open, otherwise 0, pressure lookback) / pressure lookback.
Calculation: Swing VWAP = cumulative(hlc3 × volume) / cumulative(volume) from the latest confirmed pivot high or low; accept a new pivot only when its price differs from the prior accepted pivot price by more than ATR(pivot ATR lookback) × pivot ATR multiplier; use the pivot lookback on both sides.
Calculation: Adaptive Trend Fit = log(close) linear-regression slope and Pearson correlation for each lookback in the selected ordered short- or long-horizon candidate set, using the candidate with the highest Pearson correlation.
