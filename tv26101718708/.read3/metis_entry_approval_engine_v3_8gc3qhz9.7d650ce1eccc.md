Calculation: Daily RSI = EMA(RSI(close, daily RSI lookback), daily RSI smoothing lookback), on chart bars
Calculation: Daily signal = EMA(Daily RSI, daily signal lookback), on chart bars
Calculation: Weekly RSI = EMA(RSI(close, weekly RSI lookback, T1, bar still forming), weekly RSI smoothing lookback), computed on T1 bars and projected to chart bars
Calculation: Weekly signal = EMA(Weekly RSI, weekly signal lookback, T1, bar still forming), computed on T1 bars and projected to chart bars
Calculation: Relative volume = if SMA(volume, relative volume lookback) != 0 then volume / SMA(volume, relative volume lookback) else 0, on chart bars
Calculation: Daily score = daily buy-zone points if Daily RSI >= buy-zone lower bound AND Daily RSI <= buy-zone upper bound, else 0, plus daily above-signal points if Daily RSI > Daily signal, else 0, plus daily momentum points if Daily RSI > Daily RSI[1], else 0, plus daily trend points if trend filter is disabled OR close > EMA(close, daily trend EMA lookback), else 0, plus daily volume points if volume filter is disabled OR Relative volume >= minimum relative volume, else 0
Calculation: Weekly score = weekly RSI minimum points if Weekly RSI >= weekly RSI minimum, else 0, plus weekly above-signal points if Weekly RSI > Weekly signal, else 0, plus weekly momentum points if Weekly RSI projected to the current chart bar > Weekly RSI[1] projected to the previous chart bar, else 0, plus weekly trend points if trend filter is disabled OR T1 close from the bar still forming > EMA(close, weekly trend EMA lookback, T1, bar still forming), else 0; T1 values are projected to chart bars
Calculation: Composite score = ROUND(Daily score * (if daily weight + weekly weight != 0 then daily weight / (daily weight + weekly weight) else daily fallback weight) + Weekly score * (if daily weight + weekly weight != 0 then weekly weight / (daily weight + weekly weight) else weekly fallback weight))
Calculation: Drawdown percentage = if Highest(high, recent-high lookback) != 0 then (1 - close / Highest(high, recent-high lookback)) * 100 else 0, on chart bars
Long: Composite score >= high-conviction score threshold AND Daily RSI > Daily signal AND Weekly RSI > Weekly signal AND Relative volume >= high-conviction relative volume AND Daily RSI <= daily RSI avoid upper bound
Long: Composite score >= approved score threshold AND Composite score < high-conviction score threshold AND Daily RSI <= daily RSI avoid upper bound
Long: extreme mode enabled AND Drawdown percentage >= extreme drawdown threshold AND Weekly RSI <= extreme weekly RSI maximum AND Daily RSI <= extreme daily RSI maximum AND (daily turn-up requirement disabled OR Daily RSI > Daily RSI[1]) AND (daily above-signal requirement in extreme mode disabled OR Daily RSI > Daily signal)
