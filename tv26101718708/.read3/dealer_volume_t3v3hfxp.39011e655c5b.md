Calculation: profile statistics = On each chart bar, use up to the profile-lookback number of chart bars, including the current forming bar; divide the range from the lowest low to the highest high into the profile-bin count of equal price bins; allocate each bar's volume across overlapped bins in proportion to range overlap when range distribution is selected and the bar range and bin width are positive, otherwise allocate it to the bin containing HLC3; split each allocation by the selected buy/sell method, assigning all volume to buy when close >= open and otherwise to sell for the up/down method, or splitting by positive and negative body sizes, equally on a doji, for the body-proportional method; calculate each bin's total as buy plus sell, total buy and sell volume, and the volume-weighted mean of bin midpoints using max(total volume, volume floor) as denominator; set POC to the midpoint of the leftmost bin with maximum total; expand the value area from the POC toward the adjacent bin with greater total, choosing right on ties, until accumulated volume reaches total volume times the value-area percentage, and use the outer edges as the value-area bounds.
Calculation: bounded tanh = tanh(clamp(input, -tanh limit, +tanh limit)).
Calculation: raw regime score = bounded tanh(delta weight * (buy volume - sell volume) / max(total volume, volume floor) + normalized-price weight * bounded tanh((close - volume-weighted mean bin midpoint) / max(ATR(ATR lookback), ATR floor)) + value-area weight * (1 if close > value-area high, -1 if close < value-area low, otherwise 0)).
Calculation: regime state = initialize neutral; on each chart bar with positive profile price span, set bullish if EMA(raw regime score, smoothing lookback), seeded with the first raw score, is greater than the hysteresis band, or if the previous state is bullish and that EMA is greater than or equal to the negative hysteresis band; otherwise set bearish if that EMA is less than the negative hysteresis band, or if the previous state is bearish and that EMA is less than or equal to the hysteresis band; otherwise set neutral; retain the previous state when the profile price span is not positive.
