Calculation: Squeeze-off = Bollinger Bands lower < Keltner Channel lower AND Bollinger Bands upper > Keltner Channel upper, where Bollinger Bands = SMA(close, BB lookback) ± standard deviation(close, BB lookback) * squeeze multiplier, and Keltner Channel = SMA(close, KC lookback) ± SMA(true range or high-low, KC lookback) * the same squeeze multiplier
Calculation: Trend average = selected RMA, SMA, EMA, DEMA, TEMA, WMA, HMA, or VWMA of selected price source over MA lookback
Calculation: Position-open ATR = ATR(ATR lookback) on the bar the position is first recognized as open
Calculation: Stop distance = entry price * stop-loss value / 100 for Percentage stops, Position-open ATR * stop-loss value for ATR stops, and undefined for None
Long: Squeeze-off AND ((selected long-entry color is light green AND Squeeze Momentum(close, high, low, KC lookback) > 0 AND Squeeze Momentum(close, high, low, KC lookback) > its value one bar ago) OR (selected long-entry color is dark green AND Squeeze Momentum(close, high, low, KC lookback) > 0 AND Squeeze Momentum(close, high, low, KC lookback) <= its value one bar ago)) AND (squeeze filter disabled OR the number of consecutive preceding chart bars where Squeeze-off is false >= squeeze-dot-count parameter) AND (MA filter disabled OR close > Trend average)
Short: Squeeze-off AND ((selected short-entry color is light red AND Squeeze Momentum(close, high, low, KC lookback) <= 0 AND Squeeze Momentum(close, high, low, KC lookback) < its value one bar ago) OR (selected short-entry color is dark red AND Squeeze Momentum(close, high, low, KC lookback) <= 0 AND Squeeze Momentum(close, high, low, KC lookback) >= its value one bar ago)) AND (squeeze filter disabled OR the number of consecutive preceding chart bars where Squeeze-off is false >= squeeze-dot-count parameter) AND (MA filter disabled OR close < Trend average)
Exit: Long, ((selected long-close color is light green AND Squeeze Momentum(close, high, low, KC lookback) > 0 AND Squeeze Momentum(close, high, low, KC lookback) > its value one bar ago) OR (selected long-close color is dark green AND Squeeze Momentum(close, high, low, KC lookback) > 0 AND Squeeze Momentum(close, high, low, KC lookback) <= its value one bar ago) OR (selected long-close color is light red AND Squeeze Momentum(close, high, low, KC lookback) <= 0 AND Squeeze Momentum(close, high, low, KC lookback) < its value one bar ago) OR (selected long-close color is dark red AND Squeeze Momentum(close, high, low, KC lookback) <= 0 AND Squeeze Momentum(close, high, low, KC lookback) >= its value one bar ago)) AND (profit-only close disabled OR close > entry price)
Exit: Short, ((selected short-close color is light green AND Squeeze Momentum(close, high, low, KC lookback) > 0 AND Squeeze Momentum(close, high, low, KC lookback) > its value one bar ago) OR (selected short-close color is dark green AND Squeeze Momentum(close, high, low, KC lookback) > 0 AND Squeeze Momentum(close, high, low, KC lookback) <= its value one bar ago) OR (selected short-close color is light red AND Squeeze Momentum(close, high, low, KC lookback) <= 0 AND Squeeze Momentum(close, high, low, KC lookback) < its value one bar ago) OR (selected short-close color is dark red AND Squeeze Momentum(close, high, low, KC lookback) <= 0 AND Squeeze Momentum(close, high, low, KC lookback) >= its value one bar ago)) AND (profit-only close disabled OR close < entry price)
Exit: Long, (stop-loss type is Percentage or ATR AND low <= entry price - Stop distance) OR (take-profit type is Percentage AND high >= entry price * (1 + take-profit value / 100)) OR (take-profit type is ATR AND high >= entry price + Position-open ATR * take-profit value) OR (take-profit type is Risk/Reward AND high >= entry price + Stop distance * take-profit value)
