Calculation: Volume-adjusted SuperTrend(T, L, F) = on chart bars, center = MAType(close(T) × chart volume, L) / MAType(chart volume, L), where MAType is the shared SMA, EMA, WMA, RMA, or VWMA choice; raw bands = center ± F × ATR(L, T), with ATR calculated on T bars using the still-forming T bar. On chart bars, trail the lower band to the raw lower band if it is above the prior lower band or the prior chart close is below the prior lower band, otherwise hold the prior lower band; trail the upper band to the raw upper band if it is below the prior upper band or the prior chart close is above the prior upper band, otherwise hold the prior upper band. Initialize bearish when prior ATR is unavailable; if the prior line equals the prior upper band, set direction bullish iff chart close > upper band, otherwise bearish; otherwise set direction bearish iff chart close < lower band, otherwise bullish. The line is the lower band when bullish and the upper band when bearish. Use separate T, L, and F parameters for the first and second instances.
Calculation: KNN score(ST, P, S) = inverse-distance-weighted mean of the k nearest samples among n = max(k, sample-count parameter) chart bars, including the current bar; each sample i has value ST[i] and label 1 iff WMA(close, P)[i] > WMA(ST, S)[i], otherwise 0; distance = abs(current ST − ST[i]) and weight = 1 / (distance + epsilon). k, sample-count parameter, and epsilon are shared; P and S are separate parameters for each SuperTrend.
Calculation: ADX, +DI, and -DI(T, A) = on chart bars carrying T high, low, and close from the still-forming T bar, with each [1] value taken one chart bar earlier: up = high(T) − high(T)[1], down = low(T)[1] − low(T); +DM = up if up > down and up > 0, otherwise 0; -DM = down if down > up and down > 0, otherwise 0; R = WMA(abs(high(T) − low(T)) + abs(high(T) − close(T)[1]) + abs(low(T) − close(T)[1]), A); +DI = 100 × WMA(+DM, A) / R; -DI = 100 × WMA(-DM, A) / R; ADX = WMA(100 × abs(+DI − -DI) / (+DI + -DI), A). All WMA calculations run on chart bars; A is shared.
