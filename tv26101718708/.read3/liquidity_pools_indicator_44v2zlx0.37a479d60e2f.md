Calculation: VolumeRatio = volume of the pivot bar / SMA(volume, volume length), both on T1 bars at the last completed T1 bar that confirms the pivot, where the pivot bar is pivot length bars before that bar
Calculation: LiquidityPools(side), side = BSL or SSL, = unswept pools of that side, updated on each chart bar, where more extreme means highest for BSL and lowest for SSL: first, for each pivot newly confirmed by the last completed T1 bar (BSL: PivotHigh(high, pivot length, pivot length); SSL: PivotLow(low, pivot length, pivot length); both on T1 bars, taken from the last completed T1 bar), insert a pool at the pivot price with base score = swing base score and ratio = VolumeRatio, and if the previous pivot of the same side is within EQ tolerance (pips) of it, also insert a pool at the more extreme of the two prices with base score = swing base score + EQ bonus; an insert within EQ tolerance (pips) of an existing pool of the same side merges into that pool: price = more extreme of the two, base score = max(old, new) + touch bonus, ratio = max(old, new); otherwise it is added, and if adding makes the count exceed max pools, the oldest pool is removed; then remove each pool with high >= price + sweep buffer * pip size (BSL) or low <= price - sweep buffer * pip size (SSL)
Calculation: VolumeScore(ratio) = 0 if volume strength is off; otherwise high volume score if ratio >= high volume multiplier, low volume score if ratio <= low volume multiplier, normal volume score otherwise
Calculation: PoolScore(pool) = base score + VolumeScore(ratio of pool) + danger bonus if distance <= danger distance, where distance = abs(close - pool price) / pip size
Calculation: TradeGate(side) = TRADE if the nearest pool on that side is absent or its distance exceeds danger distance, else NO TRADE if PoolScore(nearest) >= major score, else WAIT if PoolScore(nearest) >= medium score and trade-on-wait is off, else TRADE; nearest pool = highest-priced pool in LiquidityPools(SSL) below close for SSL, lowest-priced pool in LiquidityPools(BSL) above close for BSL; distance = abs(close - nearest pool price) / pip size
Long: trade mode is long AND TradeGate(SSL) is TRADE AND TradeGate(SSL)[1] is not TRADE
Short: trade mode is short AND TradeGate(BSL) is TRADE AND TradeGate(BSL)[1] is not TRADE
Exit: long, high >= lowest price in LiquidityPools(BSL) that is above entry price
Exit: short, low <= highest price in LiquidityPools(SSL) that is below entry price
