Short: MA(Return(chart close, return lookback), MA type, MA lookback) crosses below MA(Return(T1 still-forming close sampled on chart bars, return lookback), same MA type and lookback)

Calculation: comparison index return = (comparison index closing price at T1 − comparison index closing price at T1 return lookback chart bars ago) / comparison index closing price at T1
Calculation: relative return = instrument return − comparison index return
