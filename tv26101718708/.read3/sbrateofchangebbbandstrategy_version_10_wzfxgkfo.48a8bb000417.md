Calculation: band state = set raw state to +1 when the selected RSI(hlc3, oscillator lookback) or MFI(hlc3, oscillator lookback) is below its lower Bollinger Band, −1 when above its upper Bollinger Band, and 0 otherwise; starting with previous state 0, if previous state > 0 and raw state >= 0, set state to previous state + 1; otherwise, if previous state < 0 and raw state <= 0, set state to previous state − 1; otherwise set state to raw state; reset state to 0 when its absolute value exceeds the persistence limit; oscillator Bollinger Bands use the oscillator lookback and the deviation multiplier shared with the ROC Bollinger Bands
Long: crossover(ROC(close, ROC lookback), lower Bollinger Band(ROC(close, ROC lookback), ROC lookback, deviation multiplier)) AND band state > 0
Short: crossunder(ROC(close, ROC lookback), upper Bollinger Band(ROC(close, ROC lookback), ROC lookback, deviation multiplier)) AND band state < 0
