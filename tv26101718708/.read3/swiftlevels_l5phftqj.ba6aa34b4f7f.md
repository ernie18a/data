Calculation: RelativePercentDistance(price, level) = abs(price - level) / level * 100
Calculation: Previous regular-hours session high/low = max(high)/min(low) of chart bars in the preceding regular-hours session, assigned using the configured timezone
Calculation: Previous regular-hours week high/low = max(high)/min(low) of chart bars in the preceding regular-hours week, assigned using the configured timezone
Long: On each chart bar, (T1 range row enabled AND close > high of the last completed T1 bar, using the previous regular-hours session high instead when regular-hours-only mode is enabled on intraday charts) OR (T2 range row enabled AND close > high of the last completed T2 bar, using the previous regular-hours week high instead when regular-hours-only mode is enabled on intraday charts) OR (for any enabled one of five independently configured SMA or EMA calculations of close on T1, each with its own lookback and using the still-forming T1 bar: close >= the moving average AND RelativePercentDistance(close, the moving average) > the shared proximity threshold) OR (for any enabled one of those five moving averages: its value on the still-forming T1 bar > its value on the preceding completed T1 bar)
Short: On each chart bar, (T1 range row enabled AND close < low of the last completed T1 bar, using the previous regular-hours session low instead when regular-hours-only mode is enabled on intraday charts) OR (T2 range row enabled AND close < low of the last completed T2 bar, using the previous regular-hours week low instead when regular-hours-only mode is enabled on intraday charts) OR (for any enabled one of five independently configured SMA or EMA calculations of close on T1, each with its own lookback and using the still-forming T1 bar: close < the moving average AND RelativePercentDistance(close, the moving average) > the shared proximity threshold) OR (for any enabled one of those five moving averages: its value on the still-forming T1 bar <= its value on the preceding completed T1 bar)
