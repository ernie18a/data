Calculation: Upper middle EMA band = EMA(close, base lookback) + (EMA(high, base lookback) - EMA(close, base lookback)) * upper-band multiplier
Calculation: Lower middle EMA band = EMA(close, base lookback) - (EMA(close, base lookback) - EMA(low, base lookback)) * lower-band multiplier
Calculation: Inner sell zone = WMA(EMA(close, base lookback) + RMA(high - low, base lookback) * inner-zone multiplier, zone-smoothing lookback) when Keltner zones are enabled; otherwise WMA(EMA(close, base lookback) + (EMA(high, base lookback) - EMA(close, base lookback)) * φ * upper-band multiplier * π, zone-smoothing lookback)
Calculation: Inner buy zone = WMA(EMA(close, base lookback) - RMA(high - low, base lookback) * inner-zone multiplier, zone-smoothing lookback) when Keltner zones are enabled; otherwise WMA(EMA(close, base lookback) - (EMA(close, base lookback) - EMA(low, base lookback)) * φ * lower-band multiplier * π, zone-smoothing lookback)
Calculation: Outer sell zone = WMA(EMA(close, base lookback) + RMA(high - low, base lookback) * outer-zone multiplier, zone-smoothing lookback) when Keltner zones are enabled; otherwise WMA(EMA(close, base lookback) + (EMA(high, base lookback) - EMA(close, base lookback)) * φ * upper-band multiplier * (φ + outer-zone offset), zone-smoothing lookback)
Calculation: Outer buy zone = WMA(EMA(close, base lookback) - RMA(high - low, base lookback) * outer-zone multiplier, zone-smoothing lookback) when Keltner zones are enabled; otherwise WMA(EMA(close, base lookback) - (EMA(close, base lookback) - EMA(low, base lookback)) * φ * lower-band multiplier * (φ + outer-zone offset), zone-smoothing lookback)
Calculation: Candle cross above(level) = open < level AND close > level
Calculation: Upward wiggle(level) = open > level AND close > level AND close[1] <= level[1]
Calculation: Candle cross below(level) = open > level AND close < level
Calculation: Downward wiggle(level) = open < level AND close < level AND close[1] >= level[1]
Calculation: Buy-zone failure = candle cross above the selected buy zone OR (upward wiggle at that zone AND the previous bar did not candle-cross above it)
Calculation: Sell-zone failure = candle cross below the selected sell zone OR (downward wiggle at that zone AND the previous bar did not candle-cross below it)
Calculation: Lower Bollinger exhaustion bar = RSI(source, RSI lookback) < oversold threshold AND source[1] < lower Bollinger Band(source, BB lookback, standard-deviation multiplier)[1] AND source > lower Bollinger Band(source, BB lookback, standard-deviation multiplier)
Calculation: Upper Bollinger exhaustion bar = RSI(source, RSI lookback) > overbought threshold AND source[1] > upper Bollinger Band(source, BB lookback, standard-deviation multiplier)[1] AND source < upper Bollinger Band(source, BB lookback, standard-deviation multiplier)
Calculation: Leledc bearish bar = bearish candle AND up-count > qualification threshold AND high >= Highest(high, extreme lookback); up-count increments when close > close[comparison lookback], carries its value from count-offset bars ago, and resets after an accepted bearish bar; when the volume filter is enabled, require volume > SMA(volume, volume-average lookback) * volume multiplier
Calculation: Leledc bullish bar = bullish candle AND down-count > qualification threshold AND low <= Lowest(low, extreme lookback); down-count increments when close < close[comparison lookback], carries its value from count-offset bars ago, and resets after an accepted bullish bar; when the volume filter is enabled, require volume > SMA(volume, volume-average lookback) * volume multiplier
Calculation: BB-Keltner squeeze = SMA(T1 close, squeeze BB lookback) ± squeeze standard-deviation multiplier * STDEV(T1 close, squeeze BB lookback) is wholly inside EMA(T1 close, squeeze Keltner lookback) ± EMA(T1 high - T1 low, squeeze Keltner lookback) * Keltner range multiplier; calculated on chart bars taking last completed T1 values, where T1 is the selected squeeze resolution or the chart timeframe
Calculation: No filtered middle-band breakout in delay window = no filtered upward breakout of the upper middle EMA band and no filtered downward breakout of the lower middle EMA band on the current chart bar or any of the preceding delayed-close lookback bars
Calculation: Selected bearish Leledc close event for a long position = bearish Leledc bar that is the configured occurrence since the current long position opened, scanning back no farther than the scan limit
Calculation: Selected bullish Leledc close event for a short position = bullish Leledc bar that is the configured occurrence since the current short position opened, scanning back no farther than the scan limit
Calculation: Selected upper Bollinger exhaustion close event for a long position = upper Bollinger exhaustion bar that is the configured occurrence since the current long position opened, scanning back no farther than the scan limit
Calculation: Selected lower Bollinger exhaustion close event for a short position = lower Bollinger exhaustion bar that is the configured occurrence since the current short position opened, scanning back no farther than the scan limit
Calculation: Countertrend-long market-close signal = upward crossing of the band or zone named by the selected cross-close mode, using candle cross only for the outer-buy-zone mode; or the first bearish Leledc bar when that close mode is selected; or an upper Bollinger exhaustion bar when that close mode is selected; false for touch-close modes
Calculation: Countertrend-short market-close signal = downward crossing of the band or zone named by the selected cross-close mode, using candle cross only for the outer-sell-zone mode; or the first bullish Leledc bar when that close mode is selected; or a lower Bollinger exhaustion bar when that close mode is selected; false for touch-close modes
Calculation: Countertrend-long touch target = the target named by the selected touch-close mode: inner buy zone, upper or lower middle EMA band, inner sell zone, or outer sell zone; undefined for cross or exhaustion close modes
Calculation: Countertrend-short touch target = the target named by the selected touch-close mode: inner sell zone, lower or upper middle EMA band, inner buy zone, or outer buy zone; undefined for cross or exhaustion close modes
