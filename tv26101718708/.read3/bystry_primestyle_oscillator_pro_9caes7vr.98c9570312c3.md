Calculation: Normalized(x, lookback) = 0 if StDev(x, lookback) = 0; otherwise clamp(normalization scale * tanh(((x - SMA(x, lookback)) / StDev(x, lookback)) / tanh divisor), -normalization cap, normalization cap)
Calculation: Price impulse = Normalized(ZLEMA(selected source - selected source[main lookback], oscillator smoothing lookback), normalization lookback)
Calculation: Trend deviation = Normalized(selected source - ZLEMA(selected source, main lookback), normalization lookback)
Calculation: MFI component = clamp((MFI(HLC3, max(minimum MFI lookback, money-flow lookback)) - MFI midpoint) * MFI scale, -MFI cap, MFI cap)
Calculation: Money flow = Normalized(ZLEMA(EMA(volume * (body weight * (close - open) / max(high - low, range floor) + close-location weight * ((close - low) - (high - close)) / max(high - low, range floor)), money-flow lookback), money-flow smoothing lookback), normalization lookback), calculated on the selected flow timeframe (chart timeframe or T1); when T1 is used, chart bars take its current, still-forming value with lookahead off
Calculation: Volume pressure = clamp(ZLEMA(volume scale * EMA((close >= open ? volume : 0) - (close < open ? volume : 0), money-flow lookback) / max(EMA(volume, money-flow lookback), volume floor) * volume sensitivity, money-flow smoothing lookback), -volume cap, volume cap)
Calculation: Price-mode oscillator = ZLEMA(price-impulse weight * Price impulse + trend-deviation weight * Trend deviation + RSI weight * clamp((RSI(selected source, max(minimum RSI lookback, floor(main lookback / RSI divisor))) - RSI midpoint) * RSI scale, -RSI cap, RSI cap) + CCI weight * clamp(CCI(HLC3, max(minimum CCI lookback, floor(main lookback / CCI divisor))) * CCI scale, -CCI cap, CCI cap) + MFI weight * MFI component + money-flow weight * Money flow, oscillator smoothing lookback)
Calculation: Volume-mode oscillator = ZLEMA(volume-pressure weight * Volume pressure + money-flow weight * Money flow + price-impulse weight * Price impulse + MFI weight * MFI component, oscillator smoothing lookback)
Calculation: Main oscillator = Price-mode oscillator or Volume-mode oscillator according to the selected mode
Calculation: Bullish count = number of true conditions among: Main oscillator > 0; Main oscillator > ZLEMA(Main oscillator, signal lookback); Rising(Main oscillator, score momentum lookback); Money flow > 0; Volume pressure > 0; close > EMA(close, fast trend lookback) and EMA(close, fast trend lookback) > EMA(close, medium trend lookback); close > EMA(close, long trend lookback), with fast < medium < long trend lookbacks
Calculation: Bearish count = number of true conditions among: Main oscillator < 0; Main oscillator < ZLEMA(Main oscillator, signal lookback); Falling(Main oscillator, score momentum lookback); Money flow < 0; Volume pressure < 0; close < EMA(close, fast trend lookback) and EMA(close, fast trend lookback) < EMA(close, medium trend lookback); close < EMA(close, long trend lookback), with fast < medium < long trend lookbacks
Long: Main oscillator >= ZLEMA(Main oscillator, signal lookback) OR Money flow > 0 OR Volume pressure > 0 OR Bullish count >= Bearish count OR Bullish count >= power confirmation threshold OR crossover(Main oscillator, ZLEMA(Main oscillator, signal lookback)) AND Main oscillator < lower threshold AND Money flow > Money flow[1] OR selected mode is Volume-mode AND Main oscillator < lower threshold AND Rising(Main oscillator, warning lookback) OR confirmed pivotlow(Main oscillator, left pivot lookback, right confirmation lookback) < lower threshold OR a confirmed oscillator pivot low has low[right confirmation lookback] below the low at the preceding confirmed oscillator pivot low AND its oscillator value is above that preceding pivot low
Short: Main oscillator < ZLEMA(Main oscillator, signal lookback) OR Money flow < 0 OR Volume pressure < 0 OR Bullish count < Bearish count OR Bearish count >= power confirmation threshold OR crossunder(Main oscillator, ZLEMA(Main oscillator, signal lookback)) AND Main oscillator > upper threshold AND Money flow < Money flow[1] OR selected mode is Volume-mode AND Main oscillator > upper threshold AND Falling(Main oscillator, warning lookback) OR confirmed pivothigh(Main oscillator, left pivot lookback, right confirmation lookback) > upper threshold OR a confirmed oscillator pivot high has high[right confirmation lookback] above the high at the preceding confirmed oscillator pivot high AND its oscillator value is below that preceding pivot high
