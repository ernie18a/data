Calculation: normalized price movement = selected price movement / SMA(abs(selected price movement), normalization lookback), with a zero SMA mapped to zero; selected price movement is close - open in close-open mode, otherwise high - low when close > open, -(high - low) when close < open, and zero when equal.
Calculation: normalized volume pressure = [volume * (close - open) / max(high - low, instrument minimum tick)] / SMA(abs(volume * (close - open) / max(high - low, instrument minimum tick)), normalization lookback), with a zero SMA mapped to zero.
Calculation: logistic-smoothed divergence = recursively smooth the selected moving average of -(normalized price movement - normalized volume pressure) * abs(normalized price movement); on each chart bar, add the change from the prior recursive value multiplied by 1 / (1 + exp(-abs(change) / logistic bandwidth)), seeding with the selected moving average value.
Calculation: divergence change = current logistic-smoothed divergence - its prior committed value; it is undefined before a prior committed value exists.
Calculation: mean absolute divergence change = EMA(abs(divergence change), momentum memory), seeded with the first defined absolute change.
Calculation: directional momentum = x / (1 + abs(x)), where x = divergence change / mean absolute divergence change, or zero when mean absolute divergence change is not positive; use current candidate values in Repainting mode, and prior committed values on unconfirmed chart bars and current candidate values on confirmed chart bars in Non-Repainting mode.
Calculation: momentum plot value = directional momentum when momentum MA length <= 1, otherwise the selected moving average of directional momentum using the momentum MA length and type.
Calculation: pressure-reserve plot value = the selected moving average, when reserve MA length > 1, of clamp(decayed sum / (momentum memory * mean absolute divergence change), -1, 1), or the clamped value when reserve MA length <= 1; the decayed sum is current divergence change plus its prior committed value multiplied by (momentum memory - 1) / momentum memory, and the result is zero when mean absolute divergence change is not positive; use current candidate values in Repainting mode, and prior committed values on unconfirmed chart bars and current candidate values on confirmed chart bars in Non-Repainting mode.
Long: momentum plot value >= 0 OR pressure-reserve plot value >= 0
Short: momentum plot value < 0 OR pressure-reserve plot value < 0
