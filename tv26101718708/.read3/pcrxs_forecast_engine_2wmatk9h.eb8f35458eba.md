Calculation: Oscillator = if ATR(close, ATR lookback) > 0 then 100 * (WMA(close, signal smoothing lookback) - WMA(close, filter lookback)) / ATR(close, ATR lookback) else WMA(close, signal smoothing lookback) - WMA(close, filter lookback)
Calculation: Halving cycle value = cos(2π * max(current time - reference halving time, 0) / halving interval - phase offset)
Calculation: Dry powder = USDT dominance > Highest(USDT dominance, dry-powder lookback) * dry-powder proximity factor AND USDT dominance < USDT dominance[dry-powder decline lag]
Long: Oscillator crosses above -StDev(Oscillator, standard-deviation lookback) * sigma multiplier AND close on T1, current T1 bar (still forming, sampled onto chart bars) > EMA(close, structural short lookback, T1, current T1 bar still forming, sampled onto chart bars) AND EMA(close, structural short lookback, T1, current T1 bar still forming, sampled onto chart bars) > EMA(close, structural long lookback, T1, current T1 bar still forming, sampled onto chart bars) AND RSI(close, RSI lookback) < RSI overbought threshold AND MACD histogram >= MACD histogram[previous bar] AND CMF(high, low, close, volume, CMF lookback) > -CMF entry tolerance AND volume > SMA(volume, volume-average lookback) * entry volume factor AND Halving cycle value > negative halving-cycle entry threshold AND USDT dominance <= EMA(USDT dominance, dominance EMA lookback) AND ((traded base currency is Bitcoin AND BTC dominance > EMA(BTC dominance, dominance EMA lookback)) OR (traded base currency is not Bitcoin AND BTC dominance < EMA(BTC dominance, dominance EMA lookback))) AND (BTC futures basis <= overleveraged-long threshold)
Short: Oscillator crosses below StDev(Oscillator, standard-deviation lookback) * sigma multiplier AND close on T1, current T1 bar (still forming, sampled onto chart bars) < EMA(close, structural short lookback, T1, current T1 bar still forming, sampled onto chart bars) AND EMA(close, structural short lookback, T1, current T1 bar still forming, sampled onto chart bars) < EMA(close, structural long lookback, T1, current T1 bar still forming, sampled onto chart bars) AND RSI(close, RSI lookback) > RSI oversold threshold AND MACD histogram <= MACD histogram[previous bar] AND CMF(high, low, close, volume, CMF lookback) < CMF entry tolerance AND volume > SMA(volume, volume-average lookback) * entry volume factor AND Halving cycle value < halving-cycle short-entry threshold AND USDT dominance >= EMA(USDT dominance, dominance EMA lookback) AND ((traded base currency is Bitcoin AND BTC dominance <= EMA(BTC dominance, dominance EMA lookback)) OR (traded base currency is not Bitcoin AND BTC dominance >= EMA(BTC dominance, dominance EMA lookback))) AND NOT Dry powder AND BTC futures basis is not above overleveraged-long threshold
Exit: long, Oscillator crosses below 0
Exit: short, Oscillator crosses above 0
