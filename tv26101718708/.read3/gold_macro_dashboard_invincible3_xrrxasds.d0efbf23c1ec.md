Calculation: Normalized score(close, lookback, inverse) = if highest(close, lookback) = lowest(close, lookback) then 50 else if inverse then 100 - 100 * (close - lowest(close, lookback)) / (highest(close, lookback) - lowest(close, lookback)) else 100 * (close - lowest(close, lookback)) / (highest(close, lookback) - lowest(close, lookback)); calculated on T1 bars and mapped to chart bars using the last completed T1 bar historically and the still-forming T1 bar in real time
Calculation: Trend(close, shorter EMA lookback, longer EMA lookback) = close > EMA(close, longer EMA lookback) AND EMA(close, shorter EMA lookback) > EMA(close, longer EMA lookback); calculated on T1 bars and mapped to chart bars using the last completed T1 bar historically and the still-forming T1 bar in real time
Calculation: Breadth score = 100 * count of breadth series for which Trend(close, shorter EMA lookback, longer EMA lookback) is true / breadth series count; calculated on chart bars from mapped T1 values
Calculation: Technical score = (close > EMA(close, longer EMA lookback) ? price trend weight : 0) + (EMA(close, shorter EMA lookback) > EMA(close, longer EMA lookback) ? EMA trend weight : 0) + (RSI(close, RSI lookback) > RSI midpoint ? RSI weight : 0); calculated on T1 bars and mapped to chart bars using the last completed T1 bar historically and the still-forming T1 bar in real time
Calculation: Macro score = inverse-normalized real-yield close score * real-yield weight + inverse-normalized dollar close score * dollar weight + normalized gold-liquidity close score * liquidity weight + inverse-normalized rate close score * rate weight + normalized risk close score * risk weight + breadth score * breadth weight; calculated on chart bars from mapped T1 values
Calculation: Macro strength score = macro score * macro strength weight + technical score * technical weight; calculated on chart bars from mapped T1 values
Long: Any normalized source score, breadth score, macro score, or macro strength score >= bullish cutoff
Short: Any normalized source score, breadth score, macro score, or macro strength score < bearish cutoff
Long: Trend(close, shorter EMA lookback, longer EMA lookback) is true for a trend-marked source series
Short: Trend(close, shorter EMA lookback, longer EMA lookback) is false for a trend-marked source series
