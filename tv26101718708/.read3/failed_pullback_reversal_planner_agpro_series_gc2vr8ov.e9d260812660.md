Calculation: Adjusted ATR = max(ATR(ATR lookback) if available, high-low otherwise, instrument minimum tick)
Calculation: Volume ratio = nz(volume, 0) / SMA(nz(volume, 0), volume-baseline lookback) when the average is positive; otherwise 1
Calculation: Base EMA slope ATR = (EMA(close, base lookback) - EMA(close, base lookback)[base-slope lookback]) / Adjusted ATR
Calculation: Bullish-trend pullback touch = side mode permits bullish trend AND EMA(close, fast lookback) > EMA(close, base lookback) > EMA(close, slow lookback), with fast, base, and slow lookbacks ordered short-to-long, AND Base EMA slope ATR >= minimum trend slope AND low <= EMA(close, fast lookback) + Adjusted ATR × sensitivity-adjusted pullback reach AND close < EMA(close, fast lookback) + Adjusted ATR × pullback-close offset
Calculation: Bearish-trend pullback touch = side mode permits bearish trend AND EMA(close, fast lookback) < EMA(close, base lookback) < EMA(close, slow lookback) AND Base EMA slope ATR <= -minimum trend slope AND high >= EMA(close, fast lookback) - Adjusted ATR × sensitivity-adjusted pullback reach AND close > EMA(close, fast lookback) - Adjusted ATR × pullback-close offset
Calculation: Bearish reversal candidate = barssince(Bullish-trend pullback touch) is defined and <= failure-window lookback AND (barssince(Bearish-trend pullback touch) is undefined or > failure-window lookback OR barssince(Bullish-trend pullback touch) <= barssince(Bearish-trend pullback touch))
Calculation: Bullish reversal candidate = barssince(Bearish-trend pullback touch) is defined and <= failure-window lookback AND NOT (barssince(Bullish-trend pullback touch) is defined and <= failure-window lookback AND barssince(Bullish-trend pullback touch) <= barssince(Bearish-trend pullback touch))
Calculation: Pullback depth ATR = for a bearish reversal candidate, max(EMA(close, fast lookback) - lowest(low, failure-window lookback), 0) / Adjusted ATR; for a bullish reversal candidate, max(highest(high, failure-window lookback) - EMA(close, fast lookback), 0) / Adjusted ATR; otherwise 0
Calculation: Control-break ATR = for a bearish reversal candidate, (EMA(close, base lookback) - Adjusted ATR × control buffer - close) / Adjusted ATR; for a bullish reversal candidate, (close - EMA(close, base lookback) - Adjusted ATR × control buffer) / Adjusted ATR; otherwise 0
Calculation: Follow-through ATR = for a bearish reversal candidate, (lowest(low, follow-through lookback)[1] - close) / Adjusted ATR; for a bullish reversal candidate, (close - highest(high, follow-through lookback)[1]) / Adjusted ATR; otherwise 0
Calculation: Pullback depth score = if Pullback depth ATR <= ideal depth, clamp((Pullback depth ATR - minimum meaningful depth) / (ideal depth - minimum meaningful depth) × 100, 0, 100); otherwise clamp((excessive depth - Pullback depth ATR) / (excessive depth - ideal depth) × 100, 0, 100)
Calculation: Follow-through score = clamp(Follow-through ATR / follow-through score threshold × 100, 0, 100)
Calculation: Target-room ATR = use the prior structure low, lowest(low, target-structure lookback)[1], for a bearish reversal candidate or prior structure high, highest(high, target-structure lookback)[1], for a bullish reversal candidate; if unavailable or raw room is below minimum structure room, use close minus or plus Adjusted ATR × fallback target distance, respectively; divide the nonnegative distance from close to that target by Adjusted ATR
Calculation: Failure score = round(clamp(depth weight × Pullback depth score + control-loss weight × clamp(Control-break ATR / control-break score threshold × 100, 0, 100) + close-quality weight × (candle closes against former trend ? 1 : weak-candle factor) × clamp(close-against-trend metric / close-location threshold × 100, 0, 100) + volume weight × clamp(Volume ratio / volume threshold × 100, 0, 100) + follow-through weight × Follow-through score, 0, 100)); close-against-trend metric is 1 - (close - low) / max(high - low, instrument minimum tick) for a bearish reversal candidate and (close - low) / max(high - low, instrument minimum tick) for a bullish reversal candidate
Calculation: Target-room strict filter = confirmation mode is not Strict OR (Follow-through score >= strict follow-through threshold AND Target-room ATR >= strict target-room threshold AND Pullback depth score >= strict depth threshold)
Calculation: Reversal confirmation quality = (Bearish reversal candidate AND close < open OR Bullish reversal candidate AND close > open) AND (confirmation mode is Close Only OR Volume ratio >= volume threshold) AND Target-room strict filter
