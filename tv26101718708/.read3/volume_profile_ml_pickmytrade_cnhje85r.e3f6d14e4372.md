Calculation: Profile = volume profile of the last min(profile_lookback, bars so far) confirmed bars, split between the lowest low and the highest high into profile_rows equal rows; each bar with volume > 0 and high >= low spreads its volume over the rows from its low row to its high row in proportion to max(1 - |row centre - (high + low + close) / 3| / max(row height * rows spanned * 0.5, row height), weight_floor), normalised to the bar volume; recomputed every profile_rebuild_period confirmed bars and held between recomputations; POC = first row with maximum volume; value area = rows expanded outward from POC until they hold value_area_share of total volume
Calculation: NodeCut(p) = linear-interpolated p-th percentile of the volumes of the non-empty rows of Profile
Calculation: Node = Profile row index floor((close - profile low) / row height) of the confirmed bar's close, if that index is within the profile rows, the row volume is > 0, the row volume is >= NodeCut(hvn_percentile) or <= NodeCut(lvn_percentile), the row's last Arrival was at least max(rearm_distance, resolution_timeout) confirmed bars ago, and the row differs from the row of the previous confirmed bar's close; otherwise none
Calculation: NodePrice = profile low + (Node + 0.5) * row height
Calculation: Arrival = +1 if Node is not none, bar index >= warmup_bars, ATR(atr_length) > 0 and close[approach_lag] < NodePrice; -1 if Node is not none, bar index >= warmup_bars, ATR(atr_length) > 0 and close[approach_lag] >= NodePrice; 0 otherwise; when Arrival is nonzero, the current bar becomes the last Arrival of the Node row
Calculation: Features = nine values f0 to f8 at Arrival: f0 = min(Node row volume / total volume * profile_rows, cap0); f1 = (count of non-empty rows with volume < Node row volume) / (count of non-empty rows); f2 = min(sum of volumes of rows within thickness_half_width of the Node row / total volume * profile_rows / (2 * thickness_half_width + 1), cap2); f3 = min(|close - close[approach_lag]| / ATR(atr_length), cap3); f4 = (POC price - NodePrice) / max(profile high - profile low, minimum price increment) * Arrival, where POC price is the mid of the POC row; f5 = (NodePrice - profile low) / max(profile high - profile low, minimum price increment); f6 = min(volume / SMA(volume, volume_average_length), cap6), or 1 if that SMA is 0; f7 = min(POC row volume / total volume * profile_rows, cap7); f8 = min(max((NodePrice - value area low) / max(value area high - value area low, minimum price increment), floor8), cap8)
Calculation: Library = labelled arrivals, most recent library_cap kept, each holding Features and label (1 if held, 0 if broke). On each confirmed bar, before Arrival is evaluated, every pending arrival from an earlier bar is tested, break first: label 0 if its side is +1 and close >= its NodePrice + break_multiple * its stored ATR, or its side is -1 and close <= its NodePrice - break_multiple * its stored ATR; otherwise label 1 if its side is +1 and low <= its NodePrice - reject_multiple * its stored ATR, or its side is -1 and high >= its NodePrice + reject_multiple * its stored ATR; otherwise it is discarded without a label when bar index - its bar index >= resolution_timeout, and stays pending. Each nonzero Arrival is stored as pending with its side, NodePrice, bar index, ATR and Features
Calculation: HoldVote = (sum over the n nearest Library entries i of w_i * label_i + shrinkage_weight * (mean label over all of Library)) / (sum of w_i + shrinkage_weight), where n = min(neighbours, size of Library), nearest means smallest distance_i, distance_i = sum over the nine features a of log(1 + |Features_a - entry_i,a|), and w_i = 1 / (1 + distance_i)
Calculation: AnalogueDistance = mean of distance_i over the same n nearest Library entries used in HoldVote
Long: Arrival = +1 AND outcome_vote_enabled AND size of Library >= min(min_library_size, library_cap) AND AnalogueDistance <= max_analogue_distance AND HoldVote < majority_threshold
Long: Arrival = -1 AND outcome_vote_enabled AND size of Library >= min(min_library_size, library_cap) AND AnalogueDistance <= max_analogue_distance AND HoldVote >= majority_threshold
Short: Arrival = +1 AND outcome_vote_enabled AND size of Library >= min(min_library_size, library_cap) AND AnalogueDistance <= max_analogue_distance AND HoldVote >= majority_threshold
Short: Arrival = -1 AND outcome_vote_enabled AND size of Library >= min(min_library_size, library_cap) AND AnalogueDistance <= max_analogue_distance AND HoldVote < majority_threshold
