Calculation: Profile peaks = midpoints of up to the profile peak-count highest-volume local-maximum bins in the volume histogram for the profile lookback; the histogram spans the lowest low to highest high, uses the profile bin-count evenly spaced prices, and each bar with high > low contributes volume × bin width / (high − low) to each intersected bin; a local maximum is positive, at least as large as each existing adjacent bin, and strictly larger than at least one.
Calculation: Confluent(top, bottom) = a current Profile peak is between bottom − ATR(ATR lookback) × tolerance multiplier and top + ATR(ATR lookback) × tolerance multiplier.
Calculation: Bullish OB zone = on a confirmed pivot low, use the pivot candle if it is non-green and the following candle is green, or the preceding candle if the pivot candle is green and the preceding candle is non-green; on a confirmed pivot high, use the preceding candle if the pivot candle and both adjacent candles are non-green. A pivot is pivotlow(low, pivot lookback, pivot lookback) or pivothigh(high, pivot lookback, pivot lookback); green means close > open and non-green means close ≤ open. Zone bounds use the source candle's high and low when wick inclusion is enabled, otherwise max(open, close) and min(open, close); retain only if zone width ≥ SMA(abs(close − open), OB size lookback)[1] × OB size multiplier. Check confluence against the source candle's full high-low range.
Calculation: Bearish OB zone = on a confirmed pivot low, use the preceding candle if the pivot candle and both adjacent candles are green; on a confirmed pivot high, use the pivot candle if it is green and the following candle is non-green, or the preceding candle if the pivot candle is non-green and the preceding candle is green. A pivot is pivotlow(low, pivot lookback, pivot lookback) or pivothigh(high, pivot lookback, pivot lookback); green means close > open and non-green means close ≤ open. Zone bounds use the source candle's high and low when wick inclusion is enabled, otherwise max(open, close) and min(open, close); retain only if zone width ≥ SMA(abs(close − open), OB size lookback)[1] × OB size multiplier. Check confluence against the source candle's full high-low range.
Long: (an active, currently confluent bearish OB zone and close > zone top and signal mode includes Break) OR (a bullish OB zone existed and was active on the prior bar, is currently active and confluent, close[1] ≥ zone bottom, close[1] ≤ zone top, close > zone top, and signal mode includes Exit) OR (FVG signals enabled and signal mode includes Break and an active, currently confluent bearish FVG formed by high < low[2] with low[2] − high ≥ SMA(abs(close − open), FVG size lookback)[1] × FVG size multiplier, and close > low[2]) OR (FVG signals enabled and signal mode includes Exit and a bullish FVG formed by low > high[2] with low − high[2] ≥ SMA(abs(close − open), FVG size lookback)[1] × FVG size multiplier existed and was active on the prior bar, is currently active and confluent, close[1] ≥ high[2], close[1] ≤ low[2], and close > low[2]); FVG confluence uses its gap bounds.
