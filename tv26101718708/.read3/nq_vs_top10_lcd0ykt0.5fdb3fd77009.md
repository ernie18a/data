Calculation: Weighted constituent contribution = sum of each valid constituent's configured weight fraction × its chart-bar close return from the selected session-open or previous-close reference × the traded instrument's reference, which is its current, still-forming T1 open or previous completed T1 close sampled onto chart bars.
Calculation: Smoothed weighted constituent contribution = the configured HMA, EMA, SMA, or identity of weighted constituent contribution using the smoothing lookback.
Calculation: Constituent VWAP balance = the percentage of configured constituent weight above current-session VWAP minus the percentage below it; normalize weights over constituents with valid references, and calculate VWAP from HLC3 on chart bars.
Long: (inside the configured plotting session or no session filter is set) AND valid active constituent count meets the minimum active-count parameter AND smoothed weighted constituent contribution > 0 AND constituent VWAP balance > 0
Short: (inside the configured plotting session or no session filter is set) AND valid active constituent count meets the minimum active-count parameter AND smoothed weighted constituent contribution < 0 AND constituent VWAP balance < 0
