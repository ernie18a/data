Calculation: lower-wick percentage = if high > low, 100 × (min(open, close) - low) / (high - low), otherwise 0
Calculation: upper-wick percentage = if high > low, 100 × (high - max(open, close)) / (high - low), otherwise 0
Calculation: body percentage = if high > low, 100 × abs(close - open) / (high - low), otherwise 0
Calculation: quick recovery = after at least the quick-recovery lookback of prior chart bars, any high[n] for n from 1 through that lookback exceeds close × (1 + quick-recovery percentage / 100)
Calculation: bullish reversal signal = after at least the reversal lookback of prior chart bars, a bar whose close is below every low in the preceding reversal-lookback-minus-one bars starts or replaces a candidate recording its low and high; before any later close below the candidate low, the first later close above the candidate high within the reversal-confirm window marks the candidate confirmed and signals if volume confirmation is disabled or current volume > SMA(volume, volume-average lookback)
Calculation: bearish reversal signal = after at least the reversal lookback of prior chart bars, a bar whose close is above every high in the preceding reversal-lookback-minus-one bars starts or replaces a candidate recording its low and high; before any later close above the candidate high, the first later close below the candidate low within the reversal-confirm window marks the candidate confirmed and signals if volume confirmation is disabled or current volume > SMA(volume, volume-average lookback)
Calculation: long score = long-oversold weight if RSI(close, RSI lookback) < oversold threshold, plus long-extreme-oversold weight if RSI(close, RSI lookback) < extreme-oversold threshold (below the oversold threshold), plus long-RSI-turn-up weight if RSI(close, RSI lookback) > RSI(close, RSI lookback)[1], plus long-MACD-negative weight if MACD(close, fast lookback, slow lookback, signal lookback).line < 0, plus long-MACD-turn-up weight if that MACD line > its value[1], plus long-MACD-histogram-improving weight if that MACD histogram > its value[1], plus long-lower-wick weight if lower-wick percentage > wick-percent threshold, plus long-small-body weight if body percentage < body-size threshold, plus long-bullish-close weight if close > open, plus long-quick-recovery weight if quick recovery, plus long-bullish-reversal weight if bullish reversal signal
Calculation: exit score = exit-overbought weight if RSI(close, RSI lookback) > overbought threshold, plus exit-extreme-overbought weight if RSI(close, RSI lookback) > extreme-overbought threshold (above the overbought threshold), plus exit-RSI-turn-down weight if RSI(close, RSI lookback) < RSI(close, RSI lookback)[1], plus exit-MACD-positive weight if MACD(close, fast lookback, slow lookback, signal lookback).line > 0, plus exit-MACD-turn-down weight if that MACD line < its value[1], plus exit-MACD-histogram-declining weight if that MACD histogram < its value[1], plus exit-upper-wick weight if upper-wick percentage > wick-percent threshold, plus exit-bearish-close weight if close < open, plus exit-bearish-reversal weight if bearish reversal signal
Calculation: long stop = when a long position opens with risk/reward management enabled, the minimum of low on the opening bar and low[n] for n from 1 through the stop-loss lookback, multiplied by (1 - stop-loss buffer percentage / 100)
Calculation: long target = when a long position opens with risk/reward management enabled, entry price + (entry price - long stop) × risk/reward ratio
