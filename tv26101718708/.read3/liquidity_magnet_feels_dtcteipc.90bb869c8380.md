Calculation: active liquidity pools = on chart bars, add confirmed pivothigh(high, equal left/right pivot-lookback parameter) and pivotlow(low, equal left/right pivot-lookback parameter) as high and low pools, storing each pivot bar's index and volume; merge each pivot with the nearest same-side pool when abs(pool price - pivot price) / pivot price <= the selected merge tolerance, setting it equal, adding pivot-bar volume, retaining the original pivot-bar index, and keeping the higher price for high pools or lower price for low pools; otherwise create a non-equal pool. The merge tolerance is the chart-timeframe-selected tolerance when equal-level auto-scaling is enabled, otherwise the manual tolerance. Remove a high pool when high > pool price, a low pool when low < pool price, or any pool when current chart-bar index - pivot-bar index > maximum pool age or abs(ln(pool price / close)) > the selected maximum log-distance; the cap is chart-timeframe-selected when distance auto-scaling is enabled, otherwise the manual cap. Remove oldest pools until their count is at most the maximum active-pool count.
Calculation: liquidity pool score = max(strength weight × strength + proximity weight × proximity + age-decay weight × age factor + momentum weight × momentum factor, minimum score); strength = (1 if summed pivot-bar volume is unavailable or SMA(volume, pool-volume lookback) <= 0, else min(summed pivot-bar volume / SMA(volume, pool-volume lookback), volume-factor cap)) × (equal-pool bonus multiplier if equal, else 1); for distance d = abs(ln(pool price / close)), proximity = very-near factor if d < very-near threshold, else max(proximity floor, proximity baseline - abs(d - preferred distance) × proximity slope) if d < proximity-band threshold, else max(far-distance floor, proximity baseline - (d - proximity-band threshold) × far-distance decay rate); for age = current chart-bar index - pivot-bar index, age factor = fresh-pool factor if age < minimum pool age, else mature-pool factor if age < maturity-age threshold, else max(old-pool floor, mature-pool factor - (age - maturity-age threshold) / old-pool decay span); momentum = EMA(close, shorter momentum lookback) - EMA(close, longer momentum lookback), with the shorter lookback less than the longer lookback; momentum factor = momentum baseline + clamp((+1 if pool price > close, else -1) × (momentum / close if close > 0, else 0) × momentum scale, -momentum-alignment bound, +momentum-alignment bound).
Calculation: liquidity bias = zero if there are no scored pools; otherwise choose the first pool with the highest liquidity pool score, sum scores of pools on that pool's side, divide by total score of all pools, multiply by percentage scale, and make the result positive for a high pool or negative for a low pool.
Long: liquidity bias > pull threshold
Short: liquidity bias < -pull threshold
Long: liquidity bias > bullish alert level AND liquidity bias[one bar ago] <= bullish alert level
Short: liquidity bias < bearish alert level AND liquidity bias[one bar ago] >= bearish alert level
