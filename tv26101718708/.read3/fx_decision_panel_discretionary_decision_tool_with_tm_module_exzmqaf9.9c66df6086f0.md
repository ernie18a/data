Calculation: Regime = on each confirmed chart bar, trend when ADX(ADX lookback, same smoothing lookback) >= trend threshold AND ATR(ATR lookback) / SMA(ATR(ATR lookback), ATR-average lookback) >= minimum ATR ratio (use a ratio of one when the denominator is zero); otherwise range when abs(EMA(close, long-term EMA lookback) - that EMA slope-lookback chart bars ago) < ATR(ATR lookback) * flatness threshold; otherwise neutral
Calculation: Range bounds = nearest-rank percentile of close over zone lookback at the floor percentile and ceiling percentile
Calculation: Bias = in trend regime, long when T1 close > EMA(close, long-term EMA lookback) on T1 and T1 ADX(ADX lookback, same smoothing lookback) >= trend threshold, short when T1 close < that EMA under the same ADX gate, otherwise neutral; in range regime, long when close <= floor bound, short when close >= ceiling bound, otherwise neutral; in neutral regime, neutral. T1 values are requested on chart bars with lookahead off: last completed T1 values historically and the still-forming T1 bar in real time; the same ADX lookback and long-term EMA lookback apply locally and on T1
Calculation: Reference stop = for long bias, max(min(floor bound - ATR * structural buffer, EMA(close, short-term EMA lookback) - ATR * stop multiple), EMA(close, short-term EMA lookback) - ATR * maximum stop distance); for short bias, min(max(ceiling bound + ATR * structural buffer, EMA(close, short-term EMA lookback) + ATR * stop multiple), EMA(close, short-term EMA lookback) + ATR * maximum stop distance)
Calculation: Reference target = for long bias, EMA(close, short-term EMA lookback) + abs(EMA(close, short-term EMA lookback) - reference stop) * target multiple; for short bias, EMA(close, short-term EMA lookback) - abs(EMA(close, short-term EMA lookback) - reference stop) * target multiple
Calculation: Setup invalidated = on confirmed chart bars, reset both side states when bias changes, then for long bias set invalidated when close <= reference stop and keep it set until close >= reference stop + ATR * recovery threshold; for short bias set invalidated when close >= reference stop and keep it set until close <= reference stop - ATR * recovery threshold; clear a side's state when bias is not that side
Calculation: Long pullback state and trigger = on confirmed chart bars, start the state when bias is long, low <= EMA(close, short-term EMA lookback) + ATR * pullback-zone multiple, and close > that EMA; store that bar's high and reset age. While active, increment age; if low <= that EMA + ATR * pullback-zone multiple and close > that EMA, update the stored high and reset age even if bias has changed. Deactivate when age exceeds pullback memory. The trigger is active state AND close > stored high; clear the state and stored high after triggering
Calculation: Short pullback state and trigger = on confirmed chart bars, start the state when bias is short, high >= EMA(close, short-term EMA lookback) - ATR * pullback-zone multiple, and close < that EMA; store that bar's low and reset age. While active, increment age; if high >= that EMA - ATR * pullback-zone multiple and close < that EMA, update the stored low and reset age even if bias has changed. Deactivate when age exceeds pullback memory. The trigger is active state AND close < stored low; clear the state and stored low after triggering
Calculation: Long entry condition = long pullback trigger AND bias is long AND NOT setup invalidated AND (regime is range OR (regime is trend AND highest(high, expansion lookback) - EMA(close, short-term EMA lookback) > ATR * expansion multiple))
Calculation: Short entry condition = short pullback trigger AND bias is short AND NOT setup invalidated AND (regime is range OR (regime is trend AND EMA(close, short-term EMA lookback) - lowest(low, expansion lookback) > ATR * expansion multiple))
Calculation: Trade risk = abs(entry price - reference stop captured when the trade opens); unrealized R = (close - entry price) / trade risk for a long position and (entry price - close) / trade risk for a short position
Calculation: Trailing stop = once unrealized R reaches the trail-arm threshold, stay armed; on each confirmed chart bar, the long trail is the running maximum, starting at the first armed bar, of highest(high, trail lookback) - ATR * trail ATR multiple; the short trail is the running minimum, starting at the first armed bar, of lowest(low, trail lookback) + ATR * trail ATR multiple
Long: bias is long
Short: bias is short
Long: long pullback state is active AND it was inactive on the prior chart bar
Short: short pullback state is active AND it was inactive on the prior chart bar
Long: long pullback trigger AND NOT setup invalidated
Short: short pullback trigger AND NOT setup invalidated
Long: long pullback trigger AND bias is long AND NOT setup invalidated
Short: short pullback trigger AND bias is short AND NOT setup invalidated
Long: long entry condition
Short: short entry condition
Exit: Long, close <= initial stop when trailing is unarmed, or close <= max(initial stop, long trailing stop) when trailing is armed, OR close >= initial target, OR bias is neutral, OR (bias is short AND NOT short entry condition)
Exit: Short, close >= initial stop when trailing is unarmed, or close >= min(initial stop, short trailing stop) when trailing is armed, OR close <= initial target, OR bias is neutral, OR (bias is long AND NOT long entry condition)
