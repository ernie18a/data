Calculation: Delta = for each chart bar, sum completed T1 intrabar volume × sign(close − open), using sign(close − previous intrabar close) for doji intrabars; if no T1 intrabars exist, chart-bar volume × sign(close − open)
Calculation: Run efficiency = SUM(high − low, run-length chart bars) / SUM(ABS(Delta), run-length chart bars)
Long: on a closed chart bar, Delta is positive for a streak that first reaches the run-length parameter AND (efficiency mode is unrestricted OR (mode is efficient and Run efficiency ≥ the prior chart bar's SMA(Run efficiency, efficiency-baseline lookback)) OR (mode is absorbed and Run efficiency < the prior chart bar's SMA(Run efficiency, efficiency-baseline lookback))) AND (isolation is not required OR no opposite-direction run exists OR the latest opposite-direction completed run is more than max(1, round(isolation-window minutes × 60 / chart-bar seconds)) chart bars ago)
Short: on a closed chart bar, Delta is negative for a streak that first reaches the run-length parameter AND (efficiency mode is unrestricted OR (mode is efficient and Run efficiency ≥ the prior chart bar's SMA(Run efficiency, efficiency-baseline lookback)) OR (mode is absorbed and Run efficiency < the prior chart bar's SMA(Run efficiency, efficiency-baseline lookback))) AND (isolation is not required OR no opposite-direction run exists OR the latest opposite-direction completed run is more than max(1, round(isolation-window minutes × 60 / chart-bar seconds)) chart bars ago)
