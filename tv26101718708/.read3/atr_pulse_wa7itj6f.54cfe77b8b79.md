Calculation: ATR trailing stop = recursively, using the prior bar's stop (0 if unavailable): if close > prior stop AND close[1] > prior stop, max(prior stop, close - sensitivity multiplied by ATR(ATR lookback)); else if close < prior stop AND close[1] < prior stop, min(prior stop, close + sensitivity multiplied by ATR(ATR lookback)); else if close > prior stop, close - sensitivity multiplied by ATR(ATR lookback); otherwise close + sensitivity multiplied by ATR(ATR lookback)
Calculation: candle body percentage = if high > low, abs(close - open) / (high - low) multiplied by 100; otherwise 0
