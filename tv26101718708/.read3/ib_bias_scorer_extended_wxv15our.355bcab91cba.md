Calculation: StructureScore = 2 if the latest swing high > the previous swing high AND the latest swing low > the previous swing low; else -2 if the latest swing high < the previous swing high AND the latest swing low < the previous swing low; else 0; where swing highs are the non-n/a values of PivotHigh(high, pivot length, pivot length) and swing lows are the non-n/a values of PivotLow(low, pivot length, pivot length)
Calculation: EMAOrder = 1 if EMA(close, fast EMA length) > EMA(close, mid EMA length) > EMA(close, slow EMA length); else -1 if EMA(close, fast EMA length) < EMA(close, mid EMA length) < EMA(close, slow EMA length); else 0; where fast EMA length < mid EMA length < slow EMA length
Calculation: EMAStackScore = 2 if EMAOrder = 1 AND close > EMA(close, fast EMA length); else -2 if EMAOrder = -1 AND close < EMA(close, fast EMA length); else 1 if EMAOrder = 1 AND close < EMA(close, fast EMA length); else -1 if EMAOrder = -1 AND close > EMA(close, fast EMA length); else 0
Calculation: VWAPPositionScore = 2 if close > VWAP AND VWAP slope > VWAP flat threshold; else 1 if close > VWAP AND |VWAP slope| <= VWAP flat threshold; else -2 if close < VWAP AND VWAP slope < -VWAP flat threshold; else -1 if close < VWAP AND |VWAP slope| <= VWAP flat threshold; else 0; where VWAP = VWAP(typical price, anchored at the start of the current T3 bar, which is still forming) and VWAP slope = (VWAP - VWAP[VWAP slope lookback]) / VWAP[VWAP slope lookback]
Calculation: HTFBias(T) = 1 if close > EMA(close, HTF EMA length); else -1 if close < EMA(close, HTF EMA length); else 0; where close and EMA are computed on bars of T and each chart bar takes them from the last completed T bar
Calculation: HTFTrendScore = HTFBias(T1) + HTFBias(T2); where T1 is shorter than T2
Calculation: MomentumScore = 2 if RSI(close, RSI length) >= RSI bull threshold; else -2 if RSI(close, RSI length) <= RSI bear threshold; else 1 if RSI(close, RSI length) > RSI midline; else -1 if RSI(close, RSI length) < RSI midline; else 0
Calculation: UnweightedSum = StructureScore + EMAStackScore + VWAPPositionScore + HTFTrendScore + MomentumScore
Calculation: VolumeRatio = volume / SMA(volume, volume lookback)
Calculation: VolumeScore = sign(UnweightedSum) * (2 if VolumeRatio >= volume high multiplier; else -1 if VolumeRatio <= volume low multiplier; else 0.5)
Calculation: UnmitigatedCount(side) = number of levels not yet removed that lie beyond close, where side is high or low; the levels are the high (side high) or low (side low) of the last completed Asia session window, last completed London session window, and last completed NY session window (in session timezone), plus, if the prior-day level toggle is on, the last completed T3 bar; a level is set when its source completes and is removed at the first bar, including the current bar, with high >= level (side high) or low <= level (side low), and stays removed until its source completes again; beyond means above close for side high and below close for side low
Calculation: LevelImbalance = UnmitigatedCount(high) - UnmitigatedCount(low)
Calculation: LiquidityScore = 1 if UnmitigatedCount(high) = 0 AND UnmitigatedCount(low) > 0; else -1 if UnmitigatedCount(low) = 0 AND UnmitigatedCount(high) > 0; else 2 if LevelImbalance >= strong imbalance count; else 1 if LevelImbalance >= weak imbalance count; else -2 if LevelImbalance <= -strong imbalance count; else -1 if LevelImbalance <= -weak imbalance count; else 0
Calculation: Composite = 10 * (StructureScore * structure weight + EMAStackScore * EMA stack weight + VWAPPositionScore * VWAP weight + HTFTrendScore * HTF weight + MomentumScore * momentum weight + VolumeScore * volume weight + LiquidityScore * liquidity weight) / (2 * (structure weight + EMA stack weight + VWAP weight + HTF weight + momentum weight + volume weight + liquidity weight))
Long: Composite > chop ceiling
Short: Composite < -chop ceiling
