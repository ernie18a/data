Calculation: Relative strength = close / benchmark close from the current chart-timeframe bar, including the bar still forming in real time
Calculation: Relative-strength template condition = the configured mode selects one of: relative strength > relative strength[short RS lookback]; relative strength > relative strength[short RS lookback] AND relative strength > relative strength[long RS lookback] AND relative strength > EMA(relative strength, fast RS lookback); or those three conditions AND EMA(relative strength, fast RS lookback) > EMA(relative strength, slow RS lookback) AND EMA(relative strength, fast RS lookback) > EMA(relative strength, fast RS lookback)[RS slope lookback]
Calculation: RS leads price = relative strength > Highest(relative strength[1], price lookback) AND high <= Highest(high[1], price lookback)
Calculation: Trend score = count of true conditions among: close > EMA(close, middle EMA lookback) AND close > EMA(close, long EMA lookback); EMA(close, middle EMA lookback) > EMA(close, long EMA lookback); EMA(close, long EMA lookback) > EMA(close, long EMA lookback)[EMA slope lookback]; EMA(close, short EMA lookback) > EMA(close, middle EMA lookback) AND EMA(close, short EMA lookback) > EMA(close, long EMA lookback); 100 * (close / Lowest(low, price lookback) - 1) >= minimum percent above lookback low; 100 * (Highest(high, price lookback) - close) / Highest(high, price lookback) <= maximum percent below lookback high; relative-strength template condition; close > EMA(close, short EMA lookback). The short, middle, and long EMA lookbacks are ordered shortest to longest.
Calculation: RS score = count of true conditions among: relative strength > relative strength[short RS lookback]; relative strength > relative strength[long RS lookback]; relative strength > EMA(relative strength, fast RS lookback); EMA(relative strength, fast RS lookback) > EMA(relative strength, slow RS lookback); EMA(relative strength, fast RS lookback) > EMA(relative strength, fast RS lookback)[RS slope lookback]; relative strength >= Highest(relative strength[1], price lookback) * (1 - near-high percentage / 100); RS leads price. The short RS lookback is shorter than the long RS lookback, and the fast RS EMA lookback is shorter than the slow RS EMA lookback.
Calculation: Range percentage(window) = 100 * (Highest(high, window) - Lowest(low, window)) / Lowest(low, window)
Calculation: Stored pivot = price and bar of the latest confirmed PivotHigh(high, left pivot lookback, right pivot lookback) whose pivot age at confirmation is no greater than the base lookback
Calculation: Dynamic pivot valid = stored pivot exists AND current bar index - stored pivot bar index <= maximum pivot age
Calculation: Active pivot = stored pivot price when the dynamic pivot is valid; otherwise Highest(high[1], fallback pivot lookback) when fallback is enabled; otherwise undefined
Calculation: Setup score = count of true conditions among: close > EMA(close, short EMA lookback) AND 100 * (Highest(high, base lookback) - Lowest(low, base lookback)) / Highest(high, base lookback) <= maximum base depth percentage AND close < Highest(high, base lookback); Range percentage(middle contraction lookback) < Range percentage(long contraction lookback) AND Range percentage(short contraction lookback) < Range percentage(middle contraction lookback); SMA(ATR(high, low, close, ATR lookback) / close * 100, short ATR smoothing lookback) < SMA(ATR(high, low, close, ATR lookback) / close * 100, long ATR smoothing lookback) * ATR contraction ratio; Range percentage(short contraction lookback) <= maximum final range percentage; SMA(volume, dry-volume lookback) < SMA(volume, volume-average lookback) * dry-volume ratio; active pivot exists AND (close - active pivot) / active pivot * 100 <= 0 AND (close - active pivot) / active pivot * 100 >= -near-pivot percentage; RS score >= RS-strength threshold. The long, middle, and short contraction lookbacks are ordered longest to shortest; the short ATR smoothing lookback is shorter than the long ATR smoothing lookback; the dry-volume lookback is shorter than the volume-average lookback.
Calculation: VCP ready = Trend score >= minimum trend-score threshold AND Setup score >= minimum setup-score threshold AND (dynamic pivot valid OR fallback enabled) AND close > EMA(close, short EMA lookback) AND 100 * (close / EMA(close, short EMA lookback) - 1) <= maximum extension above short EMA
Calculation: Leader bottom condition = benchmark close <= Lowest(benchmark close[1], leader-bottom lookback) AND low > Lowest(low[1], leader-bottom lookback) AND relative strength > relative strength[short RS lookback] AND relative strength > EMA(relative strength, fast RS lookback)
Long: Trend score equals its maximum AND Trend score[1] is below its maximum
Long: RS leads price AND NOT RS leads price[1]
Long: VCP ready AND NOT VCP ready[1]
Long: active pivot exists AND close > active pivot AND close[1] <= active pivot AND volume >= SMA(volume, volume-average lookback) * breakout-volume ratio
Long: VCP ready AND active pivot exists AND (close - active pivot) / active pivot * 100 <= 0 AND (close - active pivot) / active pivot * 100 >= -near-pivot percentage
Long: active pivot exists AND close > active pivot AND 100 * (close / active pivot - 1) <= ideal maximum extension above pivot
Long: Leader bottom condition AND NOT Leader bottom condition[1]
