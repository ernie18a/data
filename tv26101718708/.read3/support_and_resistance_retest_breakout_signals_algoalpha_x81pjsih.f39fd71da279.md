Calculation: VolatilityBand = STDEV(close, volatility lookback) * zone tolerance multiplier
Calculation: AnchorPrice = max(p1.high, p2.high) for swing-high zones, min(p1.low, p2.low) for swing-low zones, where p1 (older) and p2 (newer) are the two most recent PivotHigh(high, swing length, swing length) points for swing-high zones or PivotLow(low, swing length, swing length) points for swing-low zones; a zone forms on the bar p2 is confirmed only if |p1 price - p2 price| <= VolatilityBand at formation
Calculation: Width = max(minimum price increment, max |AnchorPrice - v| over v in {open, high, low, close of p1 and p2} where v is below AnchorPrice for swing-high zones or above it for swing-low zones and |AnchorPrice - v| <= VolatilityBand at formation)
Calculation: UpperBound = AnchorPrice for swing-high zones, AnchorPrice + Width for swing-low zones
Calculation: LowerBound = AnchorPrice - Width for swing-high zones, AnchorPrice for swing-low zones
Calculation: RetestPhase = 0 before the zone forms, else with prev = RetestPhase[1]: if prev = 0 then -1 if high < LowerBound, 1 if low > UpperBound, else 0; if prev = -1 then 2 if close > UpperBound, else -1; if prev = 1 then -2 if close < LowerBound, else 1; if prev = 2 then 3 if high >= LowerBound AND low <= UpperBound AND close >= LowerBound, else -1 if high < LowerBound, else 0 if close < LowerBound, else 2; if prev = -2 then -3 if high >= LowerBound AND low <= UpperBound AND close <= UpperBound, else 1 if low > UpperBound, else 0 if close > UpperBound, else -2; if prev = 3 or -3 then prev
Long: for some zone, RetestPhase[1] = 2 AND high >= LowerBound AND low <= UpperBound AND close >= LowerBound AND bars since p1 <= expiration bars
Short: for some zone, RetestPhase[1] = -2 AND high >= LowerBound AND low <= UpperBound AND close <= UpperBound AND bars since p1 <= expiration bars
