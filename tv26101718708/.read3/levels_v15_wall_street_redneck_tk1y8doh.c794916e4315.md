Calculation: Active resistance levels = on each chart bar, discard levels more than maximum level age bars past their pivot bar; then, when resistance levels are enabled, add confirmed PivotHigh(high, pivot lookback, pivot lookback) values only if pivot price − max(high[pivot lookback − 1], high[pivot lookback + 1]) ≥ minimum pivot strength × ATR basis, no active resistance level is within < merge distance × ATR basis, and the pre-break active resistance count is below the active-level limit; keep each level eligible through its first bar with close > level + break sensitivity × ATR basis, then remove it
Calculation: Active support levels = on each chart bar, discard levels more than maximum level age bars past their pivot bar; then, when support levels are enabled, add confirmed PivotLow(low, pivot lookback, pivot lookback) values only if min(low[pivot lookback − 1], low[pivot lookback + 1]) − pivot price ≥ minimum pivot strength × ATR basis, no active support level is within < merge distance × ATR basis, and the pre-break active support count is below the active-level limit; keep each level eligible through its first bar with close < level − break sensitivity × ATR basis, then remove it
