Calculation: HTF EMA = EMA(close, EMA lookback) on T1 bars, sampled onto chart bars with lookahead off and gaps filled; the current T1 bar is used while forming in realtime, and completed T1 values are used historically.
Calculation: HTF EMA slope = HTF EMA − HTF EMA[slope lag chart bars ago].
Calculation: Pool padding = min(ATR(padding ATR lookback) × ATR padding coefficient, close × price padding fraction) × pool width parameter, calculated on the candidate pool bar and held for that pool.
Calculation: Pool-broken state = shared state, initially false; set true when either a candidate pool fails its line scan or an active pool breaks, and reset false when either candidate pool is accepted.
Calculation: Upper pool break = On each confirmed Pivot High(high, pivot span, pivot span), prepend the pivot to the high-pivot list. If the newest pivot is below the previous pivot, set the upper validation flag to pool-broken state OR (the newest two pivots are each below the next two older pivots); otherwise retain the flag. When valid, form an unpadded line through the previous and newest pivots. Scan chart bars from the current bar back through the previous pivot, moving the line endpoint to each scanned bar and subtracting one line slope from its y each step; reject the candidate if any scanned low exceeds that endpoint. Clear the pivot list after processing a valid candidate. On rejection, clear the active upper pool and set pool-broken state true; on acceptance, install the unpadded line and a parallel line below it by pool padding, and reset pool-broken state false. While active, break and clear the pool when low exceeds the stored endpoint of the unpadded line; set pool-broken state true.
Calculation: Lower pool break = On each confirmed Pivot Low(low, pivot span, pivot span), prepend the pivot to the low-pivot list. If the newest pivot is above the previous pivot, set the lower validation flag to pool-broken state OR (the newest two pivots are each above the next two older pivots); otherwise retain the flag. When valid, form an unpadded line through the previous and newest pivots. Scan chart bars from the current bar back through the previous pivot, moving the line endpoint to each scanned bar and subtracting one line slope from its y each step; reject the candidate if any scanned high is below that endpoint. Clear the pivot list after processing a valid candidate. On rejection, clear the active lower pool and set pool-broken state true; on acceptance, install the unpadded line and a parallel line above it by pool padding, and reset pool-broken state false. While active, break and clear the pool when high is below the stored endpoint of the parallel line above the unpadded line; set pool-broken state true.
Long: Upper pool break AND position size = 0 AND (trend filter disabled OR (close > HTF EMA AND HTF EMA slope > 0)).
Short: Lower pool break AND position size = 0 AND (trend filter disabled OR (close < HTF EMA AND HTF EMA slope < 0)).
Calculation: Stop distance = ATR(stop ATR lookback) on the entry-signal bar × stop multiplier, frozen for the position.
Calculation: Target distance = ATR(stop ATR lookback) on the entry-signal bar × target multiplier, frozen for the position.
Exit: Long, low ≤ entry-signal-bar close − stop distance OR high ≥ entry-signal-bar close + target distance.
Exit: Short, high ≥ entry-signal-bar close + stop distance OR low ≤ entry-signal-bar close − target distance.
