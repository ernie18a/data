Calculation: Bullish divergence event(T) = on T bars, the current confirmed low pivot is below the previous confirmed low pivot AND the smoothed Stochastic %K at the current pivot is above its value at the previous pivot AND the pivot separation is within the maximum pivot distance AND (the pivot-zone filter is disabled OR either pivot's smoothed Stochastic %K is at or below the oversold level)
Calculation: Bearish divergence event(T) = on T bars, the current confirmed high pivot is above the previous confirmed high pivot AND the smoothed Stochastic %K at the current pivot is below its value at the previous pivot AND the pivot separation is within the maximum pivot distance AND (the pivot-zone filter is disabled OR either pivot's smoothed Stochastic %K is at or above the overbought level)
Calculation: Divergence code(T) = on T bars, 1 when a bullish divergence event occurred within the display duration and (no bearish divergence event occurred within the display duration OR bars since the bullish event < bars since the bearish event); -1 when a bearish divergence event occurred within the display duration and (no bullish divergence event occurred within the display duration OR bars since the bearish event <= bars since the bullish event); otherwise 0
