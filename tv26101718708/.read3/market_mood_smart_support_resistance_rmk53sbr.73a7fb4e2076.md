Calculation: ATRv = ATR(high, low, close, ATR lookback)
Calculation: ImpulseReq = SMA(high - low, ADR lookback, T1, last completed bar) / close(T1, last completed bar) * 100 * impulse factor
Calculation: Swings = alternating list of (type, bar, price) swing points; at bar t, if a pivot high at bar t - swing legs (its high is the highest over swing legs bars on each side) or a pivot low at that bar (its low is the lowest likewise) exists, then: a pivot of the same type as the last point replaces it only if more extreme, a pivot of the opposite type is appended (or appended if the list is empty), and if both pivots exist the one opposite the last point's type is used (high if the list is empty); Changed(t) = a point is appended or replaced at t
Calculation: BullABCD(t) = Changed(t) AND Swings has at least four points AND the prices A, B, C, D of its last four points have types high, low, high, low AND A > C AND D < B AND AB > 0 AND BC / AB >= retrace min AND BC / AB <= retrace max AND CD / BC >= extension min AND CD / BC <= extension max, where AB = A - B, BC = C - B, CD = C - D
Calculation: BearABCD(t) = Changed(t) AND Swings has at least four points AND the prices A, B, C, D of its last four points have types low, high, low, high AND A < C AND D > B AND AB > 0 AND BC / AB >= retrace min AND BC / AB <= retrace max AND CD / BC >= extension min AND CD / BC <= extension max, where AB = B - A, BC = B - C, CD = D - C
Calculation: BullSetup(t) = (A price, D bar) of the latest bar c <= t with BullABCD(c) true, if t - D bar <= max pattern age AND no BullBreak(s) true for any s in [c, t) AND no BearABCD(s) true for any s in (c, t]; otherwise none
Calculation: BearSetup(t) = (A price, D bar) of the latest bar c <= t with BearABCD(c) true, if t - D bar <= max pattern age AND no BearBreak(s) true for any s in [c, t) AND no BullABCD(s) true for any s in (c, t]; otherwise none
Calculation: BullBreak(t) = BullSetup(t) is not none AND P > A + ATRv * breakout buffer AND (P[1] <= A + ATRv * breakout buffer OR BullABCD(t)), where A = A price of BullSetup(t) and P = close or high per breakout-mode parameter
Calculation: BearBreak(t) = BearSetup(t) is not none AND Q < A - ATRv * breakout buffer AND (Q[1] >= A - ATRv * breakout buffer OR BearABCD(t)), where A = A price of BearSetup(t) and Q = close or low per breakout-mode parameter
Calculation: ScanLen(t) = min(max(t - D bar of the setup broken at t, min streak), max scan)
Calculation: DemandAnchor(t) = the k in [min streak, ScanLen(t)] (k bars ago) with the largest Move(k) among those where close[k] < open[k] AND Run(k) >= min streak AND Move(k) >= ImpulseReq(t), or none; Run(k) = count of consecutive bars with close > open walking from bar k-1 toward bar t, stopping before the first bar with close <= open; Move(k) = (close of the last bar counted in Run(k) - low[k-1]) / low[k-1] * 100
Calculation: SupplyAnchor(t) = the k in [min streak, ScanLen(t)] (k bars ago) with the largest Move(k) among those where close[k] > open[k] AND Run(k) >= min streak AND Move(k) >= ImpulseReq(t), or none; Run(k) = count of consecutive bars with close < open walking from bar k-1 toward bar t, stopping before the first bar with close >= open; Move(k) = (high[k-1] - close of the last bar counted in Run(k)) / high[k-1] * 100
Calculation: Zone(t) = if BullBreak(t) AND DemandAnchor(t) is not none: demand zone with k = DemandAnchor(t), top = high[k], bottom = low[k], invalidation = bottom - ATRv(t) * invalidation buffer; if BearBreak(t) AND SupplyAnchor(t) is not none: supply zone with k = SupplyAnchor(t), top = high[k], bottom = low[k], invalidation = top + ATRv(t) * invalidation buffer; otherwise none
Long: BullBreak(t)
Long: Zone(t) is demand
Long: exists c < t such that Zone(c) is demand AND count of zones of either direction created in (c, t] < max zones AND low[t] <= top(c) AND high[t] >= bottom(c) AND no bar s in (c, t) has low[s] <= top(c) AND high[s] >= bottom(c) AND close[s] >= invalidation(c) for all bars s in [c, t]
Short: BearBreak(t)
Short: Zone(t) is supply
Short: exists c < t such that Zone(c) is supply AND count of zones of either direction created in (c, t] < max zones AND low[t] <= top(c) AND high[t] >= bottom(c) AND no bar s in (c, t) has low[s] <= top(c) AND high[s] >= bottom(c) AND close[s] <= invalidation(c) for all bars s in [c, t]
Exit: long, exists c <= t such that Zone(c) is demand AND count of zones of either direction created in (c, t] < max zones AND close[t] < invalidation(c) AND close[s] >= invalidation(c) for all bars s in [c, t)
Exit: short, exists c <= t such that Zone(c) is supply AND count of zones of either direction created in (c, t] < max zones AND close[t] > invalidation(c) AND close[s] <= invalidation(c) for all bars s in [c, t)
