Calculation: PA range = range quantity times the selected price distance: absolute price units, pip units, point units, minimum-tick units, close times range quantity divided by 100, ATR(range lookback), or EMA(abs(close-close[1]), range lookback), using ATR if average change is unavailable; when range smoothing is enabled, apply EMA(range, range-smoothing lookback).
Calculation: sample event, evaluated on chart bars = every sample-count-th bar, phase-shifted by sample-cycle offset; or the first chart bar of each new, still-forming T1 bar, where T1 is the chart timeframe multiplied by the interval multiplier, phase-shifted by the offset (every chart bar if the multiplier is one); or a bar where abs(selected price source-last range anchor) reaches PA range, with the anchor initialized to zero and replaced by the source at each threshold crossing, phase-shifted by the offset (every chart bar if range quantity is zero).
Calculation: sampled filter = the selected SMA, EMA, ZLEMA, DEMA, RMA, WMA, HMA, ALMA(source, filter lookback, ALMA offset, ALMA sigma), volume-weighted mean of sampled sources weighted by volume accumulated since the preceding sample event, Butterworth low-pass filter, Gaussian low-pass filter, Super Smoother, or EMA(2×EMA(source, rounded half-lookback)−EMA(source, filter lookback), rounded square-root lookback); update on sample events using the selected price source and hold between events. Each filter uses its filter lookback; all filter calculations use sample-event observations.
Calculation: filter direction = 1 when sampled filter is greater than its previous chart-bar value, −1 when less, and otherwise its previous value; initialize to zero.
Long: filter direction = 1
Short: filter direction = −1
