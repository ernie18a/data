Calculation: lower trend band = if close[1] > lower trend band[1] then max(hl2 - band multiplier * ATR(ATR lookback), lower trend band[1]) else hl2 - band multiplier * ATR(ATR lookback)
Calculation: upper trend band = if close[1] < upper trend band[1] then min(hl2 + band multiplier * ATR(ATR lookback), upper trend band[1]) else hl2 + band multiplier * ATR(ATR lookback)
Calculation: trend state = if close > upper trend band[1] then 1 else if close < lower trend band[1] then -1 else nz(trend state[1], 0)
Calculation: upper channel = EMA(highest(average(low, close), fast lookback), fast lookback)
Calculation: lower channel = EMA(lowest(average(high, close), slow lookback), slow lookback)
Calculation: triple EMA composite = triple EMA weight * (EMA(close, unit EMA lookback) - EMA(EMA(close, unit EMA lookback), unit EMA lookback)) + EMA(EMA(EMA(close, unit EMA lookback), unit EMA lookback), unit EMA lookback)
Calculation: double EMA composite = double EMA weight * EMA(close, slow lookback) - EMA(EMA(close, slow lookback), fast lookback)
Calculation: signal line = if triple EMA composite > double EMA composite then max(upper channel, lower channel) else min(upper channel, lower channel)
