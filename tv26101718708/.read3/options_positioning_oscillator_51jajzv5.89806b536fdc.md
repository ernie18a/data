Calculation: Z(x, lookback) = (x - SMA(x, lookback)) / StDev(x, lookback), or 0 if StDev(x, lookback) <= 0.
Calculation: Oscillator = EMA(N / D, output-smoothing lookback), or EMA(0, output-smoothing lookback) if D <= 0; N = -IV weight * ((PercentRank(implied-volatility-index close, IV-rank lookback) - midpoint of the 0–100 percentile scale) / standard deviation of the 0–100 percentile scale) - term weight * Z(implied-volatility-index close - EMA(implied-volatility-index close, term-mean lookback), normalization lookback) + basis weight * coalesce(Z(100 * (futures close - spot close) / spot close, normalization lookback), 0) + (if enabled and valid, PCR weight * (high-PCR-is-bullish parameter ? 1 : -1) * Z(PCR source, normalization lookback)) - (if enabled and valid, skew weight * Z(option-skew source, normalization lookback)); D = IV weight + term weight + basis weight + each included valid optional weight. IV-rank and term components are computed on T1 bars; chart bars take the latest T1 values, including the still-forming T1 bar in realtime, with lookahead off. Other components use chart bars; basis is missing when spot close <= 0.
