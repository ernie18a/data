Calculation: Normalized ATR spread = (ATR(fast ATR lookback) − ATR(slow ATR lookback)) / (StDev(ATR(fast ATR lookback), ATR standard-deviation lookback) + normalization stabilizer), on chart bars; the fast lookback is shorter than the slow lookback
Calculation: HTF normalized ATR spread = Normalized ATR spread calculated on T1 bars and sampled on the previous chart bar; the T1 bar may still be forming
Calculation: Regime index = SUM(ABS(Normalized ATR spread[1]) > base-spike threshold, regime-window lookback), on chart bars
Calculation: Decay confirmation = if decay-persistence lookback is at most one bar, Regime index[2] >= regime event count AND Regime index[1] <= regime event count − decay buffer; otherwise, Regime index[1] < regime event count − decay buffer AND BarsSince(Regime index[1] > regime event count − decay buffer) >= decay-persistence lookback
Long: ABS(Normalized ATR spread[1]) > base-spike threshold AND ABS(Normalized ATR spread[1]) == Highest(ABS(Normalized ATR spread), local-extreme lookback)[1] AND ABS(Normalized ATR spread[1]) > SMA(ABS(Normalized ATR spread), local-extreme lookback × local-average multiplier)[1] × super-spike multiplier AND Regime index[1] >= regime event count AND Normalized ATR spread[1] > 0 AND close[1] == Lowest(close, local-extreme lookback)[1] AND HTF normalized ATR spread > base-spike threshold
Short: ABS(Normalized ATR spread[1]) > base-spike threshold AND ABS(Normalized ATR spread[1]) == Highest(ABS(Normalized ATR spread), local-extreme lookback)[1] AND ABS(Normalized ATR spread[1]) > SMA(ABS(Normalized ATR spread), local-extreme lookback × local-average multiplier)[1] × super-spike multiplier AND Regime index[1] >= regime event count AND Normalized ATR spread[1] < 0 AND close[1] == Highest(close, local-extreme lookback)[1] AND HTF normalized ATR spread < −base-spike threshold
Exit: Long, high >= average entry price × (1 + take-profit percentage / 100) OR low <= average entry price × (1 − stop percentage / 100) OR Decay confirmation
Exit: Short, low <= average entry price × (1 − take-profit percentage / 100) OR high >= average entry price × (1 + stop percentage / 100) OR Decay confirmation
