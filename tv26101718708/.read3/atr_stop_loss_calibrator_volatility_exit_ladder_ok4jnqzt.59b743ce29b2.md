Calculation: Reset = (snapshot model AND (first chart bar OR T1 period of this chart bar differs from T1 period of prior chart bar)) OR (manual model AND anchor enabled AND bar time >= anchor start time AND (first chart bar OR prior chart bar time < anchor start time))
Calculation: Reference = Source[1] for the prior-bar model; Source for the rolling model; for the snapshot model, Open on the most recent Reset bar if snapshot price is period-open, else Close[1] on that bar; for the manual model, the anchor price; Source is the field selected by the source parameter
Calculation: ATR used = ATR(ATR length, ATR smoothing)[1] for the prior-bar model; ATR(ATR length, ATR smoothing) for the rolling model; for the snapshot and manual models, ATR(ATR length, ATR smoothing)[1] on the most recent Reset bar if the ATR update parameter is frozen, ATR(ATR length, ATR smoothing)[1] if it is prior-bar, and ATR(ATR length, ATR smoothing) if it is current-bar
Calculation: Cycle ATR = ATR used on the most recent Reset bar
Calculation: Ratchet enabled = (snapshot model OR manual model) AND (locked behavior parameter is immediate OR locked behavior parameter is delayed)
Calculation: Long extreme = MAX(High, Long extreme[1]), where Long extreme[1] is Reference on a Reset bar
Calculation: Long core level = MAX(prior level, Long extreme - ATR used x Core multiplier) if Ratchet enabled AND Long ratchet active, otherwise Reference - ATR used x Core multiplier; prior level = Long core level[1] on non-Reset bars and Reference - ATR used x Core multiplier on Reset bars; Long ratchet active = immediate behavior OR (delayed behavior AND ((Long ratchet active[1] AND NOT Reset) OR Long extreme - Reference >= activation parameter x Cycle ATR))
Calculation: Long core reached = long side displayed AND ATR used > 0 AND (Close <= Long event level if event test is close-based, or Low <= Long event level if event test is wick-based); Long event level = Long core level[1] if Ratchet enabled AND confirmed-events parameter AND ratchet updates are confirmed-bar AND NOT Reset, Reference - ATR used x Core multiplier if Ratchet enabled AND Reset, otherwise Long core level
Exit: long, Long core reached AND (Reset OR NOT Long core reached[1])
Calculation: Short extreme = MIN(Low, Short extreme[1]), where Short extreme[1] is Reference on a Reset bar
Calculation: Short core level = MIN(prior level, Short extreme + ATR used x Core multiplier) if Ratchet enabled AND Short ratchet active, otherwise Reference + ATR used x Core multiplier; prior level = Short core level[1] on non-Reset bars and Reference + ATR used x Core multiplier on Reset bars; Short ratchet active = immediate behavior OR (delayed behavior AND ((Short ratchet active[1] AND NOT Reset) OR Reference - Short extreme >= activation parameter x Cycle ATR))
Calculation: Short core reached = short side displayed AND ATR used > 0 AND (Close >= Short event level if event test is close-based, or High >= Short event level if event test is wick-based); Short event level = Short core level[1] if Ratchet enabled AND confirmed-events parameter AND ratchet updates are confirmed-bar AND NOT Reset, Reference + ATR used x Core multiplier if Ratchet enabled AND Reset, otherwise Short core level
Exit: short, Short core reached AND (Reset OR NOT Short core reached[1])
