Calculation: SmoothedATR = EMA(ATR(high, low, close, ATR length), EMA smoothing length)
Calculation: VolumeRatio = volume / SMA(volume, volume SMA length)
Calculation: Clusters(side) = in chronological order over the most recent S/R pivot memory pivots of side, keeping those with bar age ≤ analysis window, where side demand uses pivot low(low, S/R pivot length, S/R pivot length) and side supply uses pivot high(high, S/R pivot length, S/R pivot length); each pivot joins the first existing cluster whose price is within cluster tolerance * SmoothedATR of the pivot price, otherwise starts a new cluster; cluster price = mean of member pivot prices; touches = member count; firstBar = earliest member pivot bar; lastBar = latest member pivot bar; avgVolumeRatio = mean of VolumeRatio at member pivot bars; extreme = minimum (demand) or maximum (supply) of member pivot prices
Calculation: TrendHits(side, price) = number of pivot pairs (earlier, later) among the most recent trend pivot memory trend pivots of side, where side demand uses pivot low(low, trend pivot length, trend pivot length) with later price above earlier price, side supply uses pivot high(high, trend pivot length, trend pivot length) with later price below earlier price, the earlier pivot has bar age ≤ analysis window, the line through the pair has value at the current bar within (cluster tolerance + trend price margin) * SmoothedATR of price, and the count of sampled bars (from the earlier pivot bar to the current bar, every trend sampling step bars) whose low (demand) or high (supply) lies within trendline tolerance * SmoothedATR of the line is ≥ minimum trendline touches
Calculation: ZoneScore(c, side) = min(maximum score, touch weight * min(1, ln(c.touches) / ln(max(TopTouchCount, touch saturation))) + trendline weight * min(1, TrendHits(side, c.price) / trendline saturation) + recency weight * (1 - min(1, (current bar - c.lastBar) / (recency fraction * analysis window))) + age weight * min(1, (current bar - c.firstBar) / analysis window) + volume weight * VolumeBonus), where TopTouchCount = max touches over all clusters of both sides, and VolumeBonus = max(0, min(1, (c.avgVolumeRatio - 1) / volume saturation)) if volume filter is on, else 0
Calculation: Zones = for each cluster c of Clusters(demand) followed by each cluster c of Clusters(supply) with c.touches ≥ minimum zone touches, with zone top = c.price + zone height * SmoothedATR / 2 and zone bottom = c.price - zone height * SmoothedATR / 2, keep the zone if (nearby filter off OR abs(c.price - close) ≤ nearby range * SmoothedATR) AND ZoneScore(c, side) ≥ minimum score AND (if demand: close ≥ zone bottom - break margin * SmoothedATR AND close ≥ c.price - wrong-side factor * zone height * SmoothedATR / 2; if supply: close ≤ zone top + break margin * SmoothedATR AND close ≤ c.price + wrong-side factor * zone height * SmoothedATR / 2)
Calculation: MergedZones = if merge flag is on, Zones merged in their order, where each zone joins the first earlier merged zone of the same side whose range overlaps it (zone bottom ≤ merged top AND zone top ≥ merged bottom), and the merged zone gets top = max of tops, bottom = min of bottoms, score = min(maximum score, merged score + merge score weight * zone score), extreme = minimum (demand) or maximum (supply) of extremes; if merge flag is off, MergedZones = Zones
Calculation: SelectedZones = the first maximum zones entries of MergedZones sorted by score descending
Calculation: Plan(z) for z in SelectedZones = {entry, stop, tp1, tp2, rr1}, where entry = z.top for demand and z.bottom for supply; stop = z.bottom - stop buffer * SmoothedATR (demand) or z.top + stop buffer * SmoothedATR (supply) if stop reference is zone, and z.extreme - stop buffer * SmoothedATR (demand) or z.extreme + stop buffer * SmoothedATR (supply) if stop reference is extreme; for demand, targets = bottoms of supply zones in SelectedZones with bottom above entry and score ≥ target score fraction * minimum score, sorted ascending; for supply, targets = tops of demand zones in SelectedZones with top below entry and score ≥ target score fraction * minimum score, sorted descending; tp1 = first target if any, else entry + target extension * SmoothedATR (demand) or entry - target extension * SmoothedATR (supply); tp2 = second target if at least two, else entry + target extension * TP2 multiplier * SmoothedATR (demand) or entry - target extension * TP2 multiplier * SmoothedATR (supply); rr1 = abs(tp1 - entry) / abs(entry - stop)
Calculation: PlanZones = SelectedZones if top-only plan flag is off, else the first entry of SelectedZones
Long: count(z in PlanZones where z is demand AND Plan(z).rr1 ≥ minimum risk-reward) ≥ 1
Short: count(z in PlanZones where z is supply AND Plan(z).rr1 ≥ minimum risk-reward) ≥ 1
Exit: Long, count(z in PlanZones where z is demand AND Plan(z).entry = entry price AND Plan(z).rr1 ≥ minimum risk-reward AND (low ≤ Plan(z).stop OR high ≥ Plan(z).tp1 OR high ≥ Plan(z).tp2)) ≥ 1
Exit: Short, count(z in PlanZones where z is supply AND Plan(z).entry = entry price AND Plan(z).rr1 ≥ minimum risk-reward AND (high ≥ Plan(z).stop OR low ≤ Plan(z).tp1 OR low ≤ Plan(z).tp2)) ≥ 1
