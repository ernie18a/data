Calculation: Core score = EMA(Z-score(EMA(close, trend EMA lookback) - EMA(close, trend EMA lookback)[1], z-score lookback) + Z-score(ROC(close, momentum ROC lookback), z-score lookback) + Z-score(OBV - OBV[1], z-score lookback) + Z-score((ATR(ATR lookback) - ATR(ATR lookback)[1]) * (close > EMA(close, volume-direction EMA lookback) ? +1 : -1), z-score lookback), base smoothing lookback); Z-score is zero when standard deviation is zero.
Calculation: Smoothed core = EMA(core score, flow smoothing lookback) on chart bars.
Calculation: Core signal = EMA(smoothed core, same flow smoothing lookback) on chart bars.
Calculation: Weighted timeframe force = EMA(W1 × core score(T1, last completed T1 bar) + W2 × core score(T2, last completed T2 bar) + W3 × core score(T3, last completed T3 bar) + W4 × core score(T4, last completed T4 bar) + W5 × core score(T5, last completed T5 bar) + W6 × core score(T6, last completed T6 bar), flow smoothing lookback) on chart bars; W1–W6 are separate parameters and T1–T6 are separate timeframe parameters.
Long: Weighted timeframe force > 0 AND at least the minimum aligned-layer count of the six last-completed timeframe core scores are > 0 OR all six last-completed timeframe core scores are > 0 OR smoothed core > core signal AND smoothed core > 0 OR smoothed core > weighted timeframe force.
Short: Weighted timeframe force < 0 AND at least the minimum aligned-layer count of the six last-completed timeframe core scores are < 0 OR all six last-completed timeframe core scores are < 0 OR smoothed core < core signal AND smoothed core < 0 OR smoothed core <= weighted timeframe force.
