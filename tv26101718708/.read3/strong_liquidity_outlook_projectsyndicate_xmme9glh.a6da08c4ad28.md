Long: EMA(close, shorter lookback) > EMA(close, longer lookback) AND close > EMA(close, shorter lookback)
Short: EMA(close, shorter lookback) < EMA(close, longer lookback) AND close < EMA(close, shorter lookback)
Calculation: GapUpZone = low[1] > high[2] AND low[1] - high[2] >= ATR(ATR length) * min gap ATR multiple AND (low[1] - high[2]) / close[1] * 100 >= min gap percent; when true, adds a zone below price with bottom high[2], top low[1], born 1 bar ago, zone volume = volume + volume[1]
Calculation: GapDownZone = high[1] < low[2] AND low[2] - high[1] >= ATR(ATR length) * min gap ATR multiple AND (low[2] - high[1]) / close[1] * 100 >= min gap percent; when true, adds a zone above price with bottom high[1], top low[2], born 1 bar ago, zone volume = volume + volume[1]
Calculation: PoolUpZone = PivotHigh(high, pivot left, pivot right) is defined; when true, adds a zone above price with bottom = PivotHigh + ATR(ATR length) * pool offset, top = bottom + ATR(ATR length) * pool height, born pivot right bars ago, zone volume = SUM(volume, pivot left + pivot right)
Calculation: PoolDownZone = PivotLow(low, pivot left, pivot right) is defined; when true, adds a zone below price with top = PivotLow - ATR(ATR length) * pool offset, bottom = top - ATR(ATR length) * pool height, born pivot right bars ago, zone volume = SUM(volume, pivot left + pivot right)
Calculation: Merge = if the newest unresolved same-side zone (side = above or below price) whose overlap ratio with the new zone is >= overlap threshold exists, the new zone is not added; that zone's bounds become the union of both, zone volume += new zone volume, confluence count += 1, last touch bar = new zone's born bar; overlap ratio = (min of tops - max of bottoms) / min(both heights) if that overlap is > 0, else 0
Calculation: Prune = after a zone is added, while the zone count exceeds the zone cap, remove the oldest resolved zone if one exists, otherwise the oldest zone
Calculation: Update = for each unresolved zone at the current bar, after forming, merging and pruning: touched if high >= bottom (zone above price) or low <= top (zone below price), using original bounds; if touched, tests += 1 when not touched on the previous bar, and last touch bar = current bar; resolved if high >= top (zone above price) or low <= bottom (zone below price); removed if not resolved and |close - midpoint| / midpoint * 100 > stale percent; any zone with bars since born bar > max zone age is removed
Calculation: NormVol = SMA(volume, volume length) * (pivot left + pivot right)
Calculation: ZoneScore = 10 * AgeFactor * (volume weight * min(zone volume / (NormVol * volume norm), 1) + size weight * min(original height / (ATR(ATR length) * size norm), 1) + tests weight * min(tests / tests norm, 1) + confluence weight * min((confluence count - 1) / confluence norm, 1) + proximity weight * max(1 - |midpoint - close| / (ATR(ATR length) * proximity norm), 0)) / (sum of the five weights), where AgeFactor = max(1 - (1 - decay floor) * min(bars since last touch / decay bars, 1), decay floor)
Calculation: ZoneWeight = ZoneScore * (1 + ln(1 + zone volume / max(NormVol, 1))), for each unresolved zone with ZoneScore >= min score
Calculation: ShareAbove = SUM(ZoneWeight over zones formed above price) / SUM(ZoneWeight over all zones), or 0.5 when that total is 0
Calculation: NetPull = (ShareAbove - 0.5) * 200
Long: NetPull >= balance band
Short: NetPull <= -balance band
