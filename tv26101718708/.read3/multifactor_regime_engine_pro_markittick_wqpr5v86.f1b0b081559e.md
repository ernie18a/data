Calculation: RSI momentum = (RSI(close, cycle lookback) - RSI center) / RSI scale
Calculation: Signed DMI score = min(ADX(cycle lookback, cycle lookback) / ADX scale, normalized feature ceiling) multiplied by positive one when DI+(cycle lookback, cycle lookback) >= DI-(cycle lookback, cycle lookback), and negative one otherwise
Calculation: Direction score = RSI weight * RSI momentum + DMI weight * signed DMI score + price distance weight * clamp((close - SMA(close, cycle lookback)) / (ATR(cycle lookback) * price ATR scale + division guard), -feature cap, feature cap) + moving average spread weight * clamp((SMA(close, cycle lookback) - SMA(close, longer lookback)) / (ATR(cycle lookback) + division guard), -feature cap, feature cap) + ROC weight * clamp(ROC(close, cycle lookback) / (stdev(ROC(close, longer lookback), cycle lookback) * ROC scale + division guard), -feature cap, feature cap) + close consistency weight * (count of close[i] > close[i+1] minus count of close[i] <= close[i+1], for i from one through the cycle lookback) / cycle lookback; all weights are separate parameters
Calculation: Confidence score = clamp(SMA(raw confidence, max(round(cycle lookback * (one minus prediction weight) * smoothing factor + smoothing offset), minimum smoothing length)), confidence floor, confidence ceiling), where raw confidence = direction confidence weight * ((direction score + direction centering offset) / direction normalization range) + quality confidence weight * quality score + band extreme weight * abs(band position - band center) * band extreme scale; quality score = volatility stability weight * min(ATR(longest lookback) / (ATR(cycle lookback) * volatility stability scale + division guard), volatility stability ceiling) + volume weight * (min(volume / SMA(volume, cycle lookback) / volume scale, volume ceiling) when that SMA is positive, otherwise neutral volume value) + band width weight * min((BB upper - BB lower) / (ATR(cycle lookback) * band width ATR scale + division guard), band width ceiling) / band width scale + DMI quality weight * abs(signed DMI score); band position = (close - BB lower) / (BB upper - BB lower) when band width is positive, otherwise band center; BB uses cycle lookback and its configured deviation parameter
Calculation: Trend direction = initialize bullish; each bar calculate adaptive multiplier = macro trend threshold * (adaptive multiplier base - confidence score * confidence compression), raw upper = (high + low) / two + ATR(cycle lookback) * adaptive multiplier, and raw lower = (high + low) / two - ATR(cycle lookback) * adaptive multiplier; current upper band is min(raw upper, prior upper band) when prior direction is bearish, otherwise raw upper, and current lower band is max(raw lower, prior lower band) when prior direction is bullish, otherwise raw lower; when prior bands are undefined use the raw bands; flip buffer = ATR(cycle lookback) * flip buffer scale * (one - confidence score * confidence buffer scale); regime shift occurs when ATR(cycle lookback) > ATR(longest lookback) * volatility spike ratio and sign(RSI momentum) differs from sign(RSI momentum[1]) and abs(RSI momentum) > momentum shift threshold; if prior direction is bullish, direction becomes bearish when close < current lower band - flip buffer or regime shift occurs and direction score < zero, otherwise it stays bullish; if prior direction is bearish, direction becomes bullish when close > current upper band + flip buffer or regime shift occurs and direction score >= zero, otherwise it stays bearish
Long: trend direction[1] is bullish AND trend direction[2] is bearish
Short: trend direction[1] is bearish AND trend direction[2] is bullish
Exit: long, trend direction[1] is bullish AND trend direction[2] is bearish
