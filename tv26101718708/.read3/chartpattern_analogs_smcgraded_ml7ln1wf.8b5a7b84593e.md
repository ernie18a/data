Calculation: Effective PIP window = fixed window when adaptive sizing is off; otherwise round(Ehlers Homodyne Discriminator(hl2, minimum cycle, maximum cycle) × cycle multiplier), clamped between the minimum effective window and the fixed-window cap. Use the completed chart bar.
Calculation: Normalized PIP vector = normalize to [0,1] the seven close values selected from the effective window by starting with its oldest and newest bars, then repeatedly adding the unselected bar with greatest absolute distance from the straight line between adjacent selected points, until seven points are selected. Break ties by taking the first encountered point.
Calculation: Template candidate = the highest-scoring normalized-vector RMSE match among the fixed templates: double top [0.10,0.55,1,0.50,1,0.55,0.10], double bottom [0.90,0.45,0,0.50,0,0.45,0.90], head and shoulders [0.20,0.65,0.45,1,0.45,0.65,0.20], inverse head and shoulders [0.80,0.35,0.55,0,0.55,0.35,0.80], triple top [0.10,1,0.45,1,0.45,1,0.10], and triple bottom [0.90,0,0.55,0,0.55,0,0.90]. Each fit is max(0, 1 − RMSE / template-tolerance); accept the best only when it meets the minimum template fit. Ties use the first template in this order. Directions are short for tops and head and shoulders, and long for bottoms and inverse head and shoulders.
Calculation: Geometric candidate = fit ordinary least-squares lines to the strict interior PIP local highs and lows versus their window positions. Require at least two of each and minimum(line R²) ≥ minimum R². Let convergence be right channel width / left channel width (or 1 if left width ≤ 0); let each slope be line slope / max(ATR(ATR-length), minimum price increment); a line is flat when its absolute slope is below the flat-slope threshold. Classify in this order: convergence > widening threshold = broadening, neutral; flat upper line and rising lower line = ascending triangle, long; flat lower line and falling upper line = descending triangle, short; falling upper and rising lower lines = symmetric triangle, neutral; both rising = rising wedge and short if convergence < wedge threshold, otherwise ascending channel and long; both falling = falling wedge and long if convergence < wedge threshold, otherwise descending channel and short. Fit is minimum(line R²) × pivot-count penalty, where the penalty is 1 when each line has at least three pivots and otherwise the configured two-pivot penalty.
Calculation: Detected pattern = choose the geometric candidate over the accepted template candidate only when its fit is strictly greater; otherwise choose the template candidate. If neither qualifies, there is no pattern. A pattern is large enough when the range of its seven PIP prices ≥ minimum pattern height × max(ATR(ATR-length), minimum price increment). It is fresh when its last PIP is within the completion-recency parameter of the window's right edge.
Calculation: Sweep context = form an equal-high pool when two successive confirmed pivot highs, each using the liquidity-swing length on both sides, differ by no more than equal-level tolerance × ATR; its level is the higher high. Form an equal-low pool analogously, using the lower low. A high sweep is a selected-source high above an equal-high pool with selected-source close below it, or a high above the last pivot high with selected-source close below it and chart close < open. A low sweep is the symmetric condition, with chart close > open for the last-pivot case. A long sweep is a low sweep within the sweep-validation lookback; a short sweep is a high sweep within that lookback. Dealing-range position = (selected-source close − last pivot low) / (last pivot high − last pivot low), when both pivots exist and the range is positive.
Calculation: Analog direction, confidence, and motif = when analog matching is enabled and the resolved memory contains at least the minimum memory size, compare the current normalized PIP vector with each stored resolved vector using absolute-difference dynamic time warping with cumulative minimum of vertical, horizontal, and diagonal paths, divided by twice the vector length. Take the nearest min(neighbor count, memory size) vectors. Direction is the sign of their mean signed forward close move divided by entry ATR; confidence is the fraction whose move has that sign and absolute size ≥ follow-through ATR multiple. Motif strength = max(0, 1 − nearest distance / mean distance to all stored vectors), when the mean distance is positive. Store only emitted directional patterns; resolve each after the horizon using (horizon close − entry close) / entry ATR, and retain only the configured number of most recently resolved vectors. The analog result is mature when at least one neighbor is used and confidence exists; otherwise use the detected pattern's direction and fit as direction and confidence.
Calculation: Breakout quality = weighted sum, using separate quality weights, of min(1, true range / safe ATR / displacement saturation), min(1, abs(close − open) / bar range / body saturation), min(1, max(0, (volume z-score + volume offset) / volume scale)), and the directional sweep indicator. Safe ATR is ATR when positive, otherwise close × fallback ATR fraction; volume z-score uses volume minus its moving average divided by its standard deviation, with denominator 1 when the deviation is zero. Setup grade score = the normalized weighted average, using separate grade weights, of signal confidence, breakout quality (weight zero when quality grading is disabled), directional sweep, and favorable location. Favorable location means long below the dealing-range midpoint or short above it. Map the score to A+, A, B, C, or no grade using the configured grade cutoffs.
Calculation: Pattern signal direction = on confirmed chart bars, require a detected pattern, a fresh last PIP, the minimum pattern height, elapsed cooldown since any prior emitted pattern, and no enabled regime veto. Efficiency Ratio = abs(close − close[regime lookback]) / sum(abs(close − close[1]), regime lookback); reversal families (double top/bottom, head and shoulders, inverse head and shoulders, triple top/bottom, rising/falling wedge) are vetoed above the trending threshold; continuation families (ascending/descending triangle and channel) are vetoed below the choppy threshold; symmetric triangle and broadening are also vetoed below that threshold when range-pattern veto is enabled. Use mature analog direction/confidence when available, otherwise detected-pattern direction/fit. Require motif strength ≥ motif threshold when the threshold is positive and analogs are mature. When smart-money context is enabled, veto longs above the premium/discount threshold and shorts below its complementary threshold when dealing-range position exists. Also require the setup grade to meet minimum grade unless smart-money context is disabled or minimum grade is set to none. If all gates pass, return the selected direction, including zero for a neutral pattern, and start cooldown; otherwise return no signal. If analog matching, smart-money context, location veto, quality grading, or regime veto is disabled, omit its corresponding behavior.
Calculation: New significant-edge direction = on confirmed bars, resolve each emitted directional pattern after the horizon; a family win means the close moved at least the follow-through ATR multiple in the emitted direction from entry, using entry ATR. Track family wins and resolved count, and track baseline up and down follow-through rates from every chart bar over the same horizon. For each directional family with at least the minimum family sample count and no prior edge alert, let hit rate be family wins / family count and baseline rate be the up or down baseline rate matching that family's implied direction. Require baseline rate strictly between 0 and 1; calculate z = (hit rate − baseline rate) / sqrt(baseline rate × (1 − baseline rate) / family count). Return the implied direction of the highest-numbered family whose hit rate exceeds baseline and z exceeds the deflated-z cutoff selected by tested-family count; otherwise return no signal. Latch each alerted family so it alerts only once. The cutoff schedule uses separate parameters for test counts ≤1, 2, 3, 4, ≤6, ≤9, and >9.
Long: Pattern signal direction > 0 OR New significant-edge direction > 0
Short: Pattern signal direction < 0 OR New significant-edge direction < 0
