Calculation: EWO = moving average of the selected price source at the shorter lookback minus moving average of the same source at the longer lookback, using the same selected moving-average method.
Calculation: A confirmed EWO lobe is a nonzero-sign run ending when EWO reaches zero or changes sign; its oscillator pivot is the latest bar at its highest EWO value for a positive run or lowest EWO value for a negative run, and its price pivot is the run's highest high or lowest low, respectively; confirm it only after the run ends and the confirmation lookback bars after its oscillator pivot have closed.
Calculation: Same-side rolling EWO amplitude = rolling maximum over the strength lookback of max(EWO, 0) for positive lobes or max(-EWO, 0) for negative lobes, using available completed bars.
Long: On chart bars and separately on bars of each configured scanner timeframe T1, using only each timeframe's last completed bars, a confirmed negative current lobe has a prior confirmed negative lobe whose oscillator pivot is between the minimum and maximum pivot spacing before the current pivot, whose confirmation time is no later than the current lobe's, and which was not consumed before the current pivot by EWO moving below its oscillator pivot; when strong-anchor filtering is enabled, the prior lobe's absolute EWO pivot is at least its same-side rolling amplitude at that pivot times the greater of the minimum height ratio and minimum strength ratio; select the eligible prior lobe with the lowest EWO pivot, choosing the earliest pivot on ties; and, when largest-per-anchor/type filtering is enabled, no prior selected gap exists for this anchor and divergence type or the absolute difference between the two lobe low-wick price pivots exceeds its prior selected gap or ties it with a later current pivot; AND ((regular bullish divergence is enabled AND the current lobe low-wick price pivot is below the anchor's AND its EWO pivot is greater than or equal to the anchor's) OR (hidden bullish divergence is enabled AND the current lobe low-wick price pivot is above the anchor's AND its EWO pivot is below the anchor's)).
Short: On chart bars and separately on bars of each configured scanner timeframe T1, using only each timeframe's last completed bars, a confirmed positive current lobe has a prior confirmed positive lobe whose oscillator pivot is between the minimum and maximum pivot spacing before the current pivot, whose confirmation time is no later than the current lobe's, and which was not consumed before the current pivot by EWO moving above its oscillator pivot; when strong-anchor filtering is enabled, the prior lobe's absolute EWO pivot is at least its same-side rolling amplitude at that pivot times the greater of the minimum height ratio and minimum strength ratio; select the eligible prior lobe with the highest EWO pivot, choosing the earliest pivot on ties; and, when largest-per-anchor/type filtering is enabled, no prior selected gap exists for this anchor and divergence type or the absolute difference between the two lobe high-wick price pivots exceeds its prior selected gap or ties it with a later current pivot; AND ((regular bearish divergence is enabled AND the current lobe high-wick price pivot is above the anchor's AND its EWO pivot is less than or equal to the anchor's) OR (hidden bearish divergence is enabled AND the current lobe high-wick price pivot is below the anchor's AND its EWO pivot is above the anchor's)).
