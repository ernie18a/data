Calculation: Earnings = EPS TTM if auto EPS switch is on and EPS TTM is available and greater than 0, else manual EPS
Calculation: Valuation gap = (Earnings * (base multiple + growth multiplier * Growth) * reference yield / Bond yield - Price) / Price * 100, where Growth = SGR if auto growth switch is on and SGR is available, else YoY if auto growth switch is on and YoY is available, else manual growth; SGR = min(ROE TTM * max(0, 1 - DPS TTM / Earnings) * 100, growth cap), available if ROE TTM > 0 and DPS TTM >= 0; YoY = min(max((new - old) / abs(old) * 100, 0), growth cap), with new and old being fiscal-year EPS at the latest change of fiscal-year EPS, available if old != 0; Bond yield = 10-year government bond yield of the traded instrument's country on T1, last completed bar, if auto bond switch is on and it is available and greater than 0, else manual bond yield; Price = close if close price switch is on, else manual price
Long: Valuation gap >= safety margin threshold
Short: Valuation gap < 0
