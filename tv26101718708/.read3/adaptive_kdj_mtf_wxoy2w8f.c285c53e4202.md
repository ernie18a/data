Calculation: KDJ lookback(T) = static-lookback parameter in static mode; otherwise round a linear interpolation between short- and long-lookback parameters using ATR(ATR-lookback parameter, T bar still forming) / close(T bar still forming), clamped at low- and high-volatility threshold parameters; normal mode maps low volatility to long lookback and high volatility to short lookback, reversed mode swaps them. ATR runs on T bars.
Calculation: Smoothed weighted KDJ component X = EMA(ΣT wT × KDJ_X(high(T), low(T), close(T), KDJ lookback(T), K-smoothing parameter, D-smoothing parameter), EMA-smoothing lookback), for X ∈ {K,D,J}; wT1 + wT2 + wT3 = 1. KDJ runs on chart bars using OHLC values from the still-forming T bars.
Calculation: Smoothed weighted KDJ total = EMA(ΣT wT × (KDJ_K(T) + KDJ_D(T) + KDJ_J(T)) / 3, EMA-smoothing lookback).

Long: Smoothed weighted KDJ K is rising AND smoothed weighted KDJ D is falling AND abs(smoothed weighted KDJ K - smoothed weighted KDJ D) < anticipation-gap parameter AND smoothed weighted KDJ total < anticipation-buy threshold
