Calculation: Adaptive regression = on bars of the evaluation timeframe, scan the latest pivot-scan-horizon confirmed pivot highs and lows using the same pivot sensitivity on each side; fit OLS of close from each pivot's following bar through the current bar; require at least the minimum regression sample length, nonzero close variance, and R2 >= minimum R2; score each candidate as R2 * ln(sample count), select the highest score with ties keeping the newest pivot, and return its slope, current fitted close, residual standard error sqrt(SSE / max(1, sample count - 2)), and valid status; invalid if none qualify.
Calculation: Smoothed entropy = EMA of Shannon entropy (-sum(p * log2(p)), where p is each bin's fraction) for an equal-width histogram of ln(close / prior close) over entropy-lookback chart bars, using histogram-bin-count bins spanning the rolling minimum to maximum; if the range is zero, assign all values to the first bin; use the entropy-smoothing lookback.
Calculation: Entropy-adjusted deviation = adaptive regression residual standard error * (base deviation factor + clamp((smoothed entropy - entropy normalization floor) / entropy normalization span, 0, 1) * entropy width factor)
Calculation: Inner regression bands = lower band: adaptive regression fitted close - inner band multiplier * entropy-adjusted deviation; upper band: adaptive regression fitted close + inner band multiplier * entropy-adjusted deviation
Calculation: Regression z-score = (close - adaptive regression fitted close) / entropy-adjusted deviation when the adaptive regression is valid and entropy-adjusted deviation > 0, otherwise 0
