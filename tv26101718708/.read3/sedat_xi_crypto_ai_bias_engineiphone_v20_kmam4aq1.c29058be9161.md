Calculation: T1 values = values calculated on each T1 bar, including the still-forming bar, and mapped onto chart bars
Calculation: volume ratio = if SMA(T1 volume, volume lookback) > 0 then T1 volume / SMA(T1 volume, volume lookback) else zero
Calculation: bullish trend = EMA(T1 close, shorter EMA lookback) > EMA(T1 close, middle EMA lookback) AND EMA(T1 close, middle EMA lookback) > EMA(T1 close, longer EMA lookback), where shorter lookback < middle lookback < longer lookback
Calculation: bearish trend = EMA(T1 close, shorter EMA lookback) < EMA(T1 close, middle EMA lookback) AND EMA(T1 close, middle EMA lookback) < EMA(T1 close, longer EMA lookback)
Calculation: bullish breakout = T1 close > Highest(T1 high, breakout lookback)[1] AND volume ratio >= active volume threshold, where [1] is the previous completed T1 bar
Calculation: bearish breakout = T1 close < Lowest(T1 low, breakout lookback)[1] AND volume ratio >= active volume threshold, where [1] is the previous completed T1 bar
Calculation: score = (trend weight if bullish trend, negative trend weight if bearish trend, otherwise zero) + (price weight if T1 close > EMA(T1 close, longer EMA lookback), otherwise negative price weight) + (RSI weight if RSI(T1 close, RSI lookback) > upper RSI threshold, negative RSI weight if RSI(T1 close, RSI lookback) < lower RSI threshold, otherwise zero) + (breakout weight if bullish breakout, negative breakout weight if bearish breakout, otherwise zero) + (active volume weight if volume ratio >= active volume threshold, otherwise zero) + (extreme trend weight if volume ratio >= extreme volume threshold and bullish trend, negative extreme trend weight if volume ratio >= extreme volume threshold and bearish trend, otherwise zero), where extreme volume threshold > active volume threshold and upper RSI threshold > lower RSI threshold
Long: bullish breakout OR score > zero OR RSI(T1 close, RSI lookback) > upper RSI threshold
Short: bearish breakout OR score < zero OR RSI(T1 close, RSI lookback) < lower RSI threshold
