Calculation: dip setup = armed by the first qualifying dip; while awaiting oscillator confirmation, each qualifying dip refreshes its timeout without changing the first-dip anchor; expires when more than the confirmation-window parameter bars pass since the last qualifying dip without oscillator confirmation
Calculation: post-oscillator setup = armed on oscillator confirmation during the dip setup; expires when more than the confirmation-window parameter bars pass without MACD confirmation; clears on MACD trigger
Long: close < lower band of VWAP bands((high + low + close) / 3, standard-deviation multiplier, T1 reset; calculated on chart bars) AND (VWAP - lower band) >= minimum VWAP-band distance in pips × pip size AND (ADX filter disabled OR ADX(DI length, smoothing length, T2, last completed bar; sampled on chart bars) > threshold when the above-threshold option is selected OR < threshold when the below-threshold option is selected)
Long: dip setup AND ((RSI mode AND RSI(close, RSI length) > RSI level) OR (StochRSI threshold mode AND StochRSI %K(RSI(close, RSI length), StochRSI lookback, %K smoothing) > oversold threshold) OR (StochRSI %K/%D mode AND StochRSI %K > SMA(StochRSI %K, %D smoothing))) AND (strict-cross mode AND the selected oscillator crosses upward on this bar OR relaxed mode AND its latest upward cross is on/after the first dip and within the confirmation window)
Long: post-oscillator setup AND (MACD line(close, fast length, slow length, signal length) > 0 in zero-cross mode OR MACD line > MACD signal line in signal-cross mode) AND (strict-cross mode AND the selected MACD line crosses upward on this bar OR relaxed mode AND its latest selected upward cross is on/after the first dip and within the confirmation window) AND (flat OR long position); when flat, the market order fills at the next chart-bar open
Calculation: long stop = entry price - stop distance until breakeven is armed; stop distance is stop ATR multiple × ATR(lookback) captured on the first chart bar with a long position in ATR-stop mode, otherwise stop-loss pips × pip size; when breakeven is enabled and any post-entry high reaches entry price + breakeven trigger pips × pip size, use max(entry price - stop distance, entry price + breakeven lock pips × pip size) for the rest of the position
Calculation: long target = if ATR risk mode is selected, max(current session VWAP - target buffer pips × pip size, entry price + target ATR multiple × ATR(lookback) captured on the first chart bar with a long position, entry price + minimum-profit pips × pip size); else if VWAP target mode is selected, max(current session VWAP - target buffer pips × pip size, entry price + minimum-profit pips × pip size); otherwise entry price + fixed take-profit pips × pip size
Exit: long, low <= long stop - spread pips × pip size OR high >= long target - spread pips × pip size
