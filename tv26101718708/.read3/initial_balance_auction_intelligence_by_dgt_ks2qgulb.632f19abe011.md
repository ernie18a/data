Calculation: IBH and IBL = running highest high and lowest low of chart bars in the configured Initial Balance session, frozen when it ends; initialize from the first chart bar’s T2 intrabars when the chart timeframe is longer than T2.
Calculation: T1-window OHLC = first open, highest high, lowest low, and latest close within each T1 window, accumulated on chart bars; initialize from the first chart bar’s T2 intrabars when the chart timeframe is longer than T2, where T2 is shorter than T1. Use the last completed T1 window for state updates and the current forming T1 window for decision-candle colors.
Calculation: Auction state = Building IB until the Initial Balance session ends, then Balanced; after completion, chart-bar high > IBH sets Probing Above, else chart-bar low < IBL sets Probing Below. At each T1 change, process the last completed T1 window on chart bars in this order: if an awaited retest is touched (accepted above and window low <= IBH, or accepted below and window high >= IBL), set Continuation if its close remains beyond the accepted level (above: close > IBH; below: close < IBL), otherwise Rejection; retain the awaited retest after Continuation and clear it after Rejection. Otherwise, set Two-Sided Auction if the window fails both boundaries or fails a boundary after an opposite-side failure in the same session; else set Failed Below if (open < IBL OR low < IBL) AND IBL < close < IBH; else set Failed Above if (open > IBH OR high > IBH) AND IBL < close < IBH; else set Accepted Above if close > IBH; else set Accepted Below if close < IBL; otherwise retain the state. Acceptance sets the accepted side and awaits a retest of its IB boundary; failure flags persist through the session. Reset accepted-side, retest, and failure flags for each new session.
Calculation: Auction pressure = reset to zero each Initial Balance session; when the auction state changes into Accepted Above/Below, add/subtract the acceptance weight; into Failed Above/Below, subtract/add the failure weight; into Continuation, add/subtract the retest weight for an accepted-above/below side; into Rejection, subtract/add that weight for an accepted-above/below side. Clamp each update between negative and positive pressure-cap parameters.
Long: Auction state is Accepted Above OR Failed Below OR (Continuation AND accepted side is above) OR (Rejection AND accepted side is below) OR auction pressure > pressure threshold.
Short: Auction state is Accepted Below OR Failed Above OR (Continuation AND accepted side is below) OR (Rejection AND accepted side is above) OR auction pressure < negative pressure threshold.
Long: On chart bars while a T1 window is forming, its high >= IBH AND low <= IBH OR its high >= IBL AND low <= IBL, and its open < latest close.
Short: On chart bars while a T1 window is forming, its high >= IBH AND low <= IBH OR its high >= IBL AND low <= IBL, and its open >= latest close.
