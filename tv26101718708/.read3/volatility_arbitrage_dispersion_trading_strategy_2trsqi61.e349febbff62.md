Calculation: weighted basket log return = sum(normalized weight of each enabled, valid component other than the chart asset when automatic exclusion is enabled * log(component close / prior component close))
Calculation: implied correlation = clamp((basket annualized realized volatility^2 - sum((normalized component weight * component annualized realized volatility)^2)) / ((sum(normalized component weight * component annualized realized volatility))^2 - sum((normalized component weight * component annualized realized volatility)^2)), -1, 1), where each annualized realized volatility is standard deviation of log returns over the short volatility window * sqrt(days per year * seconds per day / chart bar seconds); defined only with at least two valid components and a positive denominator
Calculation: residual s-score = (cumulative sum of chart log return - prior-bar hedge ratio * weighted basket log return - AR(1) equilibrium) / AR(1) equilibrium standard deviation; hedge ratio = Pearson correlation of chart and basket log returns over the hedge window * standard deviation of chart log returns over the hedge window / standard deviation of basket log returns over the hedge window; fit AR(1) to cumulative residual over the OU window; equilibrium = AR(1) intercept / (1 - AR(1) coefficient); equilibrium standard deviation = sqrt(max(variance of cumulative residual - AR(1) coefficient * covariance of current and prior cumulative residual, 0) / (1 - AR(1) coefficient^2)); defined only when the AR(1) coefficient is between zero and one and equilibrium standard deviation is positive
Calculation: reversion half-life = ln(2) / -ln(AR(1) coefficient)
