Calculation: Hurst exponent = clamp(log(Variance(close - close[scaling lag], Hurst lookback) / max(Variance(close - close[previous bar], Hurst lookback), numerical floor)) / (2 * log(scaling lag)), 0, 1), using a neutral Hurst estimate if undefined
Calculation: Adaptive trend line = form a volume-weighted source using the selected MA type and ATR length (SMA, EMA, WMA, or RMA of close * volume divided by the same MA of volume with a numerical floor, or VWMA(close, ATR length)); recursively smooth it from the initial source using the prior smoother plus clamp(base Kalman gain * (gain offset + Hurst exponent), gain floor, gain ceiling) times the difference between source and prior smoother; set band width to ATR(ATR length) * (base multiplier + Hurst scale factor * (1 - Hurst exponent)); trail the lower band with the maximum of the prior lower band and smoother minus band width while the prior trend is bullish, otherwise reset it to smoother minus band width; trail the upper band with the minimum of the prior upper band and smoother plus band width while the prior trend is bearish, otherwise reset it to smoother plus band width; use the smoother as a missing prior band and initialize prior trend as bullish; set trend bullish when smoother exceeds prior upper band, bearish when smoother is below prior lower band, otherwise keep prior trend; return the lower band when bullish and upper band when bearish
Calculation: Weighted K-nearest-neighbor score = when at least the historical sample count is stored, calculate the inverse-distance-weighted mean of the labels for the K nearest stored adaptive trend line values to the current adaptive trend line, using weight 1 / (absolute distance + distance stabilizer); otherwise use a neutral fallback score. Each stored label is positive when WMA(close, price trend length) > WMA(adaptive trend line, signal smoothing length), and negative otherwise
Long: Weighted K-nearest-neighbor score = 1 AND its prior bar value < 1 AND no bullish signal has occurred since the most recent bearish signal or initialization
Short: Weighted K-nearest-neighbor score = 0 AND its prior bar value > 0 AND no bearish signal has occurred since the most recent bullish signal or initialization
