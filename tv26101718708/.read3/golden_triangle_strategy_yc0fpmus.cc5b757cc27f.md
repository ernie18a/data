Calculation: White-space start index = scan prior bars from nearest to farthest through a search lookback; return the first index i where low[i] < SMA(close, SMA lookback)[i] and close[i] > SMA(close, SMA lookback)[i]; otherwise stop with 0 at the first bar where open[i] < SMA(close, SMA lookback)[1] and high[i] < SMA(close, SMA lookback)[i], or return 0 if none match
Calculation: Pivot ATR trend = smooth each new confirmed pivot high, or pivot low when no pivot high exists, with the previous center using separate weights; calculate upper and lower bands as center minus or plus ATR(ATR lookback) times an ATR factor; trail the upper band using the maximum of its prior value and the current upper band when prior close exceeds prior upper band, otherwise use the current upper band; trail the lower band using the minimum of its prior value and current lower band when prior close is below prior lower band, otherwise use the current lower band; trend is bullish when close exceeds the prior lower band, bearish when close is below the prior upper band, and otherwise carries the prior trend, defaulting to bullish
Long: Every bar in a prior-bar confirmation window has high and low above the current SMA(close, SMA lookback), current high is above and current low is below that SMA, white-space start index is greater than one, and either triangle plotting after a long position is enabled or no long position is open
Long: A triangle setup has been found, current volume exceeds every prior volume in a volume-confirmation lookback, and close > VWAP
Long: A triangle setup has been found, pivot ATR trend is bullish, and close crosses above VWAP
Long: Pivot ATR trend is bullish and was bullish on the prior bar
