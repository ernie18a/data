Calculation: SwingLookback = max(pivot lookback parameter, minimum lookback parameter)
Calculation: PivotHighLevel = high of the most recent PivotHigh(high, SwingLookback, SwingLookback), held until the next pivot high, and reset to empty at each day start when structure reset on new day is on
Calculation: PivotLowLevel = low of the most recent PivotLow(low, SwingLookback, SwingLookback), held until the next pivot low, and reset to empty at each day start when structure reset on new day is on
Calculation: SmaSlope(L) = SMA(close, L) - SMA(close, L)[1], where L is the short, middle, or long SMA lookback, with short < middle < long
Calculation: RisingCount(N) = number of the first N SMAs in lookback order short, middle, long with SmaSlope(L) > 0
Calculation: FallingCount(N) = number of the first N SMAs in lookback order short, middle, long with SmaSlope(L) < 0
Calculation: AboveCount(N) = number of the first N SMAs in lookback order short, middle, long with close > SMA(close, L)
Calculation: BelowCount(N) = number of the first N SMAs in lookback order short, middle, long with close < SMA(close, L)
Calculation: LastBreakDir = +1 if the latest break before this bar was upward, -1 if downward, 0 if none; an upward break is the first bar since PivotHighLevel was set where high >= PivotHighLevel (close > PivotHighLevel when intrabar entry is off); a downward break is the first bar since PivotLowLevel was set where low <= PivotLowLevel (close < PivotLowLevel when intrabar entry is off); reset to 0 at each day start when structure reset on new day is on
Calculation: LongStop = StopBase - buffer points - entry price * buffer percent / 100, where StopBase = entry price - (entry price - PivotLowLevel at signal bar) * swing percent / 100 for the swing stop type, low of signal bar for the entry-candle stop type, or entry price * (1 - stop percent / 100) for the percent stop type; signal bar is the bar on which the entry conditions were evaluated
Calculation: ShortStop = StopBase + buffer points + entry price * buffer percent / 100, where StopBase = entry price + (PivotHighLevel at signal bar - entry price) * swing percent / 100 for the swing stop type, high of signal bar for the entry-candle stop type, or entry price * (1 + stop percent / 100) for the percent stop type; signal bar is the bar on which the entry conditions were evaluated
Calculation: LongTarget = entry price + (entry price - LongStop) * long R:R multiple
Calculation: ShortTarget = entry price - (ShortStop - entry price) * short R:R multiple

Long: intrabar entry is off AND long entries allowed AND close > PivotHighLevel AND (no earlier bar since PivotHighLevel was set has close > PivotHighLevel) AND RisingCount(N) >= K AND AboveCount(N) >= P AND ((SMA(close, short) > SMA(close, middle)) + (SMA(close, middle) > SMA(close, long))) >= S AND ((SmaSlope(short) > SmaSlope(middle)) + (SmaSlope(middle) > SmaSlope(long))) >= D AND (NY VWAP filter off OR close > VWAP(ohlc4) anchored at NY anchor time) AND (daily VWAP filter off OR close > VWAP(ohlc4) anchored at daily anchor time) AND (trading window filter off OR bar time is inside trading window) AND (strong candle filter off OR (close > open AND abs(close - open) >= ((high - low) - abs(close - open)) * (1 + body-over-wick percent / 100))) AND PivotHighLevel > PivotLowLevel AND ((BOS allowed AND LastBreakDir >= 0) OR (CHoCH allowed AND LastBreakDir < 0)) AND PivotHighLevel differs from the level of the last long entry today AND position is not long AND trades opened today < max trades per day
