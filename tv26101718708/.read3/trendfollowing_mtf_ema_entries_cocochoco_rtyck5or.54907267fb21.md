Calculation: Bullish EMA bias(T) = close(T, current bar) > EMA(close, EMA lookback, T, current bar) AND EMA(close, EMA lookback, T, current bar) > EMA(close, EMA lookback, T, prior bar); T0 values are evaluated on chart bars, while T1/T2 values are carried onto chart bars using lookahead_off (last completed T1/T2 bar historically, still-forming bar in realtime).
Calculation: Bearish EMA bias(T) = close(T, current bar) < EMA(close, EMA lookback, T, current bar) AND EMA(close, EMA lookback, T, current bar) < EMA(close, EMA lookback, T, prior bar); T0 values are evaluated on chart bars, while T1/T2 values are carried onto chart bars using lookahead_off (last completed T1/T2 bar historically, still-forming bar in realtime).
Calculation: Rising strong ADX = ADX(ADX lookback for both DI length and smoothing length, T0, current bar) > ADX threshold AND ADX(ADX lookback for both DI length and smoothing length, T0, current bar) > ADX(ADX lookback for both DI length and smoothing length, T0, prior bar).
Long: Chart timeframe = T0 AND T0 < T1 < T2 AND Bullish EMA bias(T0) AND Bullish EMA bias(T1) AND Bullish EMA bias(T2) AND Rising strong ADX AND first qualifying signal in each continuous T0 bullish EMA bias run; the same EMA lookback is used on all three timeframes.
Short: Chart timeframe = T0 AND T0 < T1 < T2 AND Bearish EMA bias(T0) AND Bearish EMA bias(T1) AND Bearish EMA bias(T2) AND Rising strong ADX AND first qualifying signal in each continuous T0 bearish EMA bias run; the same EMA lookback is used on all three timeframes.
Exit: Long, close crosses below EMA(close, EMA lookback) on T0 chart bars.
Exit: Short, close crosses above EMA(close, EMA lookback) on T0 chart bars.
