Select the eligible line with greatest touchCount*chartTouchWeight + span; ties keep the first encountered candidate.
Calculation: T1 trendline(side) = the straight line through the eligible pair of same-side T1 pivots, using PivotHigh(high, t1PivotStrength, t1PivotStrength) or PivotLow(low, t1PivotStrength, t1PivotStrength). When an ATH/ATL anchor is enabled, also test it as the first point to each later same-side pivot and add anchorScoreBonus.
