Calculation: Centered momentum = clamp(((HMA(momentum source, momentum smoothing lookback), with unavailable values replaced by momentum midpoint) - momentum midpoint) * centering multiplier * rib amplification, -score cap, score cap); momentum source is selected between MFI(hlc3, momentum lookback) and RSI(close, momentum lookback)
Calculation: Signed ADX = ADX from DMI(DMI lookback, same DMI lookback) * (plus DI >= minus DI ? 1 : -1)
Calculation: Oscillator middle = for Hull-VWMA mode, 0 if the prior HMA is unavailable or zero, otherwise clamp(((HMA(VWMA(close, VWMA lookback), oscillator HMA lookback) - its value oscillator lag bars ago) / its value oscillator lag bars ago * percentage conversion factor * Hull-VWMA scale, -score cap, score cap); for ADX mode, clamp(HMA(Signed ADX, oscillator HMA lookback), -score cap, score cap)
Calculation: Momentum slope(L) = (Centered momentum - its value L chart bars ago) / L
Calculation: Oscillator slope(L) = (Oscillator middle - its value L chart bars ago) / L
Long: (Momentum slope(forecast slope lookback) > 0 AND Oscillator slope(forecast slope lookback) > 0 AND NOT (Momentum slope(forecast slope lookback) on the prior chart bar > 0 AND Oscillator slope(forecast slope lookback) on the prior chart bar > 0)) OR (Momentum slope(min(forecast slope lookback, time-span parameter)) > 0 AND Oscillator slope(min(forecast slope lookback, time-span parameter)) > 0)
Short: (Momentum slope(forecast slope lookback) < 0 AND Oscillator slope(forecast slope lookback) < 0 AND NOT (Momentum slope(forecast slope lookback) on the prior chart bar < 0 AND Oscillator slope(forecast slope lookback) on the prior chart bar < 0)) OR (Momentum slope(min(forecast slope lookback, time-span parameter)) < 0 AND Oscillator slope(min(forecast slope lookback, time-span parameter)) < 0)
