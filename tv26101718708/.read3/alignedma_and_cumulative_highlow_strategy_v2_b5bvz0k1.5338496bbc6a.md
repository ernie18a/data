Calculation: alignment grade = using a parameterized stack of alignment MA lookbacks in increasing order, count the comparisons close > the shortest MA and each MA > the next; return the positive full-alignment score if all comparisons are greater, or the negative full-alignment score if close and every successive MA are strictly decreasing; otherwise, if partial alignment is enabled, return the positive strong-partial score when the count exceeds the upper threshold, the negative strong-partial score when it is below the lower threshold, the positive weak-partial score when it exceeds the middle threshold, and the negative weak-partial score otherwise; return zero when partial alignment is disabled. The thresholds are ordered upper > middle > lower, and the score values are ordered positive full > positive strong partial > positive weak partial > zero > negative weak partial > negative strong partial > negative full. All MAs use close on chart bars and the alignment MA type.
Calculation: extreme pulse = a positive unit when high equals highest(high, extreme lookback), otherwise a negative unit of equal magnitude when low equals lowest(low, the same lookback), otherwise zero; the high comparison takes precedence.
Calculation: directional state(x) = up when x > x[shorter directional lookback] if x is positive, or x > x[longer directional lookback] otherwise; if not up, down when x < x[shorter directional lookback] if x is negative, or x < x[longer directional lookback] otherwise; otherwise retain the previous non-neutral state, or neutral if none. Evaluate on chart bars.
Calculation: high-side gate = on each chart bar, let H be high[1] from the last completed T1 bar, sampled onto chart bars; let H1 and H2 be H at the base chart-bar offset and at the base offset multiplied by a separate offset multiplier, respectively. The gate is ((H or H1 is missing OR H > H1) AND (H or H2 is missing OR H > H2)) OR (true if H is missing; otherwise close > H if H1 is missing; otherwise close > max(H, H1) if H2 is missing; otherwise close > max(H, min(H1, H2))) OR the shared high/low filter is disabled.
Calculation: low-side gate = on each chart bar, let L be low[1] from the last completed T1 bar, sampled onto chart bars; let L1 and L2 be L at the base chart-bar offset and at the base offset multiplied by the same offset multiplier, respectively. The gate is ((L or L1 is missing OR L < L1) AND (L or L2 is missing OR L < L2)) OR (true if L is missing; otherwise close < L if L1 is missing; otherwise close < min(L, L1) if L2 is missing; otherwise close < min(L, max(L1, L2))) OR the shared high/low filter is disabled.
Calculation: risk threshold reached = false while flat; for a long position, Supertrend(multiplier parameter, supertrend lookback parameter) > average entry price + ATR(separate ATR lookback parameter) × the same Supertrend multiplier × risk-reward parameter; for a short position, that Supertrend value < average entry price − ATR(separate ATR lookback parameter) × the same Supertrend multiplier × risk-reward parameter.
Calculation: trailing stop = let S be Supertrend(multiplier parameter, supertrend lookback parameter) and A be ATR(separate ATR lookback parameter), evaluated on chart bars. Use S unless the risk threshold is reached; then use S − ATR-padding parameter × A when Supertrend is up, or S + ATR-padding parameter × A when Supertrend is down. For a long position, keep the prior stop if this value is below it; for a short position, keep the prior stop if this value is above it; while flat, use this value.
Long: directional state(sum(alignment grade, shared aggregation lookback)) is up AND directional state(sum(extreme pulse, the same aggregation lookback)) is up AND high-side gate
Short: directional state(sum(alignment grade, shared aggregation lookback)) is down AND directional state(sum(extreme pulse, the same aggregation lookback)) is down AND low-side gate
Long: secondary MA(close, separate secondary MA type and lookback) > its value at the lag parameter bars ago
Short: secondary MA(close, separate secondary MA type and lookback) < its value at the lag parameter bars ago
Long: Supertrend(multiplier parameter, supertrend lookback parameter) is up AND risk threshold not reached
Short: Supertrend(multiplier parameter, supertrend lookback parameter) is down AND risk threshold not reached
Long: directional state(sum(alignment grade, shared aggregation lookback)) is up AND directional state(sum(extreme pulse, the same aggregation lookback)) is up AND high-side gate AND secondary MA(close, separate secondary MA type and lookback) > its value at the lag parameter bars ago AND Supertrend(multiplier parameter, supertrend lookback parameter) is up AND low > trailing stop AND chart datetime is on or after January 1 of the current calendar year minus the lookback-years parameter AND (position is flat OR risk threshold reached)
Short: directional state(sum(alignment grade, shared aggregation lookback)) is down AND directional state(sum(extreme pulse, the same aggregation lookback)) is down AND low-side gate AND secondary MA(close, separate secondary MA type and lookback) < its value at the lag parameter bars ago AND Supertrend(multiplier parameter, supertrend lookback parameter) is down AND low < trailing stop AND chart datetime is on or after January 1 of the current calendar year minus the lookback-years parameter AND (position is flat OR risk threshold reached)
Exit: long, Supertrend(multiplier parameter, supertrend lookback parameter) is down OR low <= trailing stop
Exit: short, Supertrend(multiplier parameter, supertrend lookback parameter) is up
