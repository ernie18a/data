Calculation: ATR-safe = max(ATR(ATR lookback), minimum tick size)
Calculation: Pool evidence update = old evidence * evidence decay + evidence increment * clamp(1 - abs(close - pool price) / (ATR-safe * evidence radius), 0, 1) * (base evidence weight + volume evidence weight * min(volume ratio, evidence volume cap) + wick evidence weight * min(side-specific wick / ATR-safe, wick cap) + approach evidence weight * min(side-specific close approach / ATR-safe, approach cap)); volume ratio = fallback volume ratio if volume or its SMA is unavailable or the SMA is zero, otherwise min(volume / SMA(volume, volume baseline lookback), volume ratio cap); side-specific wick is the upper wick for an upper pool or lower wick for a lower pool; side-specific close approach is max(close - close[1], 0) for an upper pool or max(close[1] - close, 0) for a lower pool
Calculation: Active pools = create upper pools from confirmed fast, medium, and slow pivot highs and lower pools from confirmed fast, medium, and slow pivot lows, each with its own horizon-specific seed evidence; process pivots from shortest to longest lookback; merge each pivot into the nearest same-side pool within ATR-safe * pool merge distance, setting price to (old price * old evidence + pivot price * seed evidence) / (old evidence + seed evidence) and adding seed evidence, or create a pool if none qualifies; on each chart bar update pool evidence using Pool evidence update, then remove pools older than the maximum pool age, upper pools cleared by close > pool price + ATR-safe * clearance buffer, and lower pools cleared by close < pool price - ATR-safe * clearance buffer; if pool count exceeds pool capacity, remove the oldest pool before evaluating sweeps
Long: an active lower pool exists where low < pool price - ATR-safe * sweep penetration and close > pool price
Long: on a confirmed chart bar, close > the latest confirmed medium pivot high that has not already been broken; rearm on each newly confirmed medium pivot high and disarm after the break
Short: an active upper pool exists where high > pool price + ATR-safe * sweep penetration and close < pool price
Short: on a confirmed chart bar, close < the latest confirmed medium pivot low that has not already been broken; rearm on each newly confirmed medium pivot low and disarm after the break
