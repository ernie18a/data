Calculation: Velocity = (selected source - selected source[velocity lookback]) / (ATR(ATR lookback) if ATR normalization is enabled and ATR is positive, otherwise 1)
Calculation: Velocity z-score = 0 if StDev(Velocity, z-score window) is 0; otherwise (Velocity - SMA(Velocity, z-score window)) / StDev(Velocity, z-score window)
Calculation: Dynamic threshold = base z threshold in strict mode or when adaptive threshold is disabled; otherwise max(base z threshold × adaptive floor fraction, PercentileLinearInterpolation(abs(Velocity z-score), z-score window × percentile-window multiplier, adaptive percentile)), using the base z threshold if the percentile is unavailable
Calculation: Volume surge = 1 if SMA(volume, volume window) is unavailable or nonpositive; otherwise volume / SMA(volume, volume window)
Calculation: Acceleration = Velocity - Velocity[1]
Calculation: Close location = 0.5 if high - low <= 0; otherwise (close - low) / (high - low)
Long: (tint enabled AND Velocity z-score <= -Dynamic threshold) OR (bars since previous long signal > cooldown AND ((strict mode AND Velocity z-score <= -base z threshold AND Volume surge >= volume surge threshold AND Acceleration > 0 AND Acceleration[1] <= 0) OR (strict mode disabled AND (stretch filter disabled OR EMA(close, baseline lookback) - close >= stretch distance × ATR(ATR lookback)) AND ((Lowest(Velocity z-score, acceleration-flip window + 1) <= -Dynamic threshold AND (Volume surge >= volume surge threshold OR Volume surge <= volume dry-up threshold) AND Acceleration crosses above zero) OR (Velocity z-score <= -Dynamic threshold × hard-climax multiplier AND Volume surge >= volume surge threshold) OR (Lowest(Velocity z-score, acceleration-flip window + 1) <= -Dynamic threshold AND lower wick ratio >= wick ratio threshold AND Close location >= bar-range midpoint) OR (divergence path enabled AND low <= Lowest(low, divergence lookback) AND Velocity z-score > Lowest(Velocity z-score, divergence lookback)[1] (or 0 if unavailable) AND Velocity z-score <= -Dynamic threshold × divergence fraction AND close > open))))
Short: (tint enabled AND Velocity z-score >= Dynamic threshold) OR (bars since previous short signal > cooldown AND ((strict mode AND Velocity z-score >= base z threshold AND Volume surge >= volume surge threshold AND Acceleration < 0 AND Acceleration[1] >= 0) OR (strict mode disabled AND (stretch filter disabled OR close - EMA(close, baseline lookback) >= stretch distance × ATR(ATR lookback)) AND ((Highest(Velocity z-score, acceleration-flip window + 1) >= Dynamic threshold AND (Volume surge >= volume surge threshold OR Volume surge <= volume dry-up threshold) AND Acceleration crosses below zero) OR (Velocity z-score >= Dynamic threshold × hard-climax multiplier AND Volume surge >= volume surge threshold) OR (Highest(Velocity z-score, acceleration-flip window + 1) >= Dynamic threshold AND upper wick ratio >= wick ratio threshold AND Close location <= bar-range midpoint) OR (divergence path enabled AND high >= Highest(high, divergence lookback) AND Velocity z-score < Highest(Velocity z-score, divergence lookback)[1] (or 0 if unavailable) AND Velocity z-score >= Dynamic threshold × divergence fraction AND close < open))))
Long: Lower wick ratio = 0 when high - low <= 0; otherwise (min(open, close) - low) / (high - low)
Short: Upper wick ratio = 0 when high - low <= 0; otherwise (high - max(open, close)) / (high - low)
