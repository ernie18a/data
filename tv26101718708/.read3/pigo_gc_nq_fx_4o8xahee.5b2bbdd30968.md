Calculation: Trend status(T) = neutral if the flat filter is enabled and either Impulse MACD histogram(impulse lookback, signal lookback) = 0 or its prior-bar value = 0; otherwise, in single-EMA direction mode, uptrend if EMA(close, first EMA lookback) > its prior-bar value and downtrend if it is less; in two-EMA comparison mode, uptrend if EMA(close, first EMA lookback) > EMA(close, second EMA lookback) and downtrend if it is less; equal comparisons are neutral. The first and second EMA lookbacks are separate parameters. Compute on bars of T; for requested timeframes, use the forming T bar in realtime and the latest confirmed T value historically, mapped to chart bars.
Long: Trend status(T) = uptrend, for the chart timeframe and each requested timeframe T1.
Short: Trend status(T) = downtrend, for the chart timeframe and each requested timeframe T1.
