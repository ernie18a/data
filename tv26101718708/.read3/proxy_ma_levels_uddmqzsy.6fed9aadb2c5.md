Calculation: Short proxy EMA = EMA(close, separate short lookback on T1, T1 bars) when the chart timeframe is below T2; EMA(close, separate short lookback on T2, T2 bars) otherwise. T1 < T2. Read the source value on chart bars; use the last completed source bar historically and the still-forming source bar on realtime updates.
Calculation: Long proxy EMA = EMA(close, separate long lookback on T1, T1 bars) when the chart timeframe is below T2; EMA(close, separate long lookback on T2, T2 bars) otherwise. Read the source value on chart bars; use the last completed source bar historically and the still-forming source bar on realtime updates. Its lookbacks are longer than the short proxy EMA lookbacks.
Calculation: Upper tolerance band(level, tolerance) = level * (1 + tolerance / 100). The short and long proxy EMAs have separate tolerance parameters.
Calculation: Lower tolerance band(level, tolerance) = level * (1 - tolerance / 100). The short and long proxy EMAs have separate tolerance parameters.
Calculation: Level touch(level) = high >= level AND low <= level.
Long: (short proxy enabled AND close > Upper tolerance band(short proxy EMA, its tolerance) AND NOT Level touch(short proxy EMA) AND Level touch(short proxy EMA) occurred since the latest confirmed PivotHigh(high, L, L) or PivotLow(low, L, L) AND this direction has not triggered for this level in the current pivot leg) OR (long proxy enabled AND close > Upper tolerance band(long proxy EMA, its tolerance) AND NOT Level touch(long proxy EMA) AND Level touch(long proxy EMA) occurred since the latest confirmed PivotHigh(high, L, L) or PivotLow(low, L, L) AND this direction has not triggered for this level in the current pivot leg).
Short: (short proxy enabled AND close < Lower tolerance band(short proxy EMA, its tolerance) AND NOT Level touch(short proxy EMA) AND Level touch(short proxy EMA) occurred since the latest confirmed PivotHigh(high, L, L) or PivotLow(low, L, L) AND this direction has not triggered for this level in the current pivot leg) OR (long proxy enabled AND close < Lower tolerance band(long proxy EMA, its tolerance) AND NOT Level touch(long proxy EMA) AND Level touch(long proxy EMA) occurred since the latest confirmed PivotHigh(high, L, L) or PivotLow(low, L, L) AND this direction has not triggered for this level in the current pivot leg).
