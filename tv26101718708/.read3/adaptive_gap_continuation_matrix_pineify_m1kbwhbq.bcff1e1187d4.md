Calculation: Valid OHLCV = open, high, low, close, and volume are present; volume > 0; high >= low; high >= max(open, close); low <= min(open, close)
Calculation: Qualifying gap = first regular-session bar on the supported standard intraday chart, with valid OHLCV, a prior regular-session close, valid OHLCV on every preceding baseline-lookback chart bar, prior completed chart-bar ATR(baseline lookback) > 0, prior completed chart-bar median(volume, baseline lookback) > 0, and abs(open - prior regular-session close) >= minimum-gap/ATR parameter × prior ATR
Calculation: Gap direction = +1 for an up gap and -1 for a down gap
Calculation: Gap size = abs(first regular-session open - prior regular-session close)
Calculation: Retention = gap direction × (close - prior regular-session close) / gap size
Calculation: Close fill = clamp(1 - retention, 0, 1)
Calculation: Capped relative volume = min(volume / the prior completed chart-bar median volume frozen at gap start, relative-volume cap parameter)
Calculation: Mean relative volume = mean capped relative volume across up to the path-lookback number of most recent event samples, including the current sample
Calculation: Recent flow = (sum of recent event steps / sum of their absolute values) × min(sqrt(mean relative volume), flow-volume saturation parameter), or 0 if the sum of absolute values is 0; each event step = gap direction × (close - previous event close)
Calculation: Candidate state = continuation if the confirmed state is continuation and retention >= continuation persistence-retention parameter and recent flow >= entry-flow parameter × release fraction parameter and mean relative volume >= minimum-participation parameter × persistence-participation fraction parameter; otherwise repair if the confirmed state is repair and close fill >= repair persistence-fill parameter and recent flow <= -entry-flow parameter × release fraction parameter and mean relative volume >= minimum-participation parameter × persistence-participation fraction parameter; otherwise continuation if mean relative volume >= minimum-participation parameter and retention >= continuation entry-retention parameter and recent flow >= entry-flow parameter; otherwise repair if mean relative volume >= minimum-participation parameter and close fill >= repair entry-fill parameter and recent flow <= -entry-flow parameter; otherwise stalled
Calculation: Range touch = gap direction = +1 and low <= prior regular-session close, or gap direction = -1 and high >= prior regular-session close
Long: During an eligible event close, the confirmed state changes to continuation after the confirmation-count parameter consecutive eligible closes with candidate state continuation and gap direction = +1, or changes to repair after that many consecutive eligible closes with candidate state repair and gap direction = -1
Short: During an eligible event close, the confirmed state changes to continuation after the confirmation-count parameter consecutive eligible closes with candidate state continuation and gap direction = -1, or changes to repair after that many consecutive eligible closes with candidate state repair and gap direction = +1
Exit: long, a valid regular-session event bar after the gap-start bar has a range touch
Exit: short, a valid regular-session event bar after the gap-start bar has a range touch
