Calculation: Relative volume = volume / SMA(volume, relative-volume lookback) when SMA(volume, relative-volume lookback) > 0, otherwise 0
Calculation: Volatility score = full component points * (ATR percentile rank of ATR(ATR lookback) over volatility-rank lookback / volatility floor) when the rank is below the volatility floor; full component points when the rank is between the floor and ceiling inclusive; full component points * clamp((maximum percentile rank - rank) / (maximum percentile rank - volatility ceiling), 0, 1) when the rank is above the ceiling
Calculation: Long score = trend points when close > EMA(close, longer EMA lookback) + trend points when EMA(close, shorter EMA lookback) > EMA(close, longer EMA lookback) + full component points * clamp((RSI(close, RSI lookback) - RSI midpoint) / RSI momentum span, 0, 1) + full component points * clamp(Kaufman efficiency ratio(close, efficiency lookback) / full-points efficiency ratio, 0, 1) when close > close[efficiency lookback], otherwise 0 + volatility score + (when SMA(volume, relative-volume lookback) > 0, full component points * clamp(relative volume - relative-volume baseline, 0, 1) when close > open, otherwise 0; when SMA(volume, relative-volume lookback) <= 0, no-volume neutral points)
Calculation: Short score = trend points when close < EMA(close, longer EMA lookback) + trend points when EMA(close, shorter EMA lookback) < EMA(close, longer EMA lookback) + full component points * clamp((RSI midpoint - RSI(close, RSI lookback)) / RSI momentum span, 0, 1) + full component points * clamp(Kaufman efficiency ratio(close, efficiency lookback) / full-points efficiency ratio, 0, 1) when close < close[efficiency lookback], otherwise 0 + volatility score + (when SMA(volume, relative-volume lookback) > 0, full component points * clamp(relative volume - relative-volume baseline, 0, 1) when close < open, otherwise 0; when SMA(volume, relative-volume lookback) <= 0, no-volume neutral points)
Calculation: Long trailing stop = close - ATR(ATR lookback) * stop ATR multiple on the long-entry signal bar; thereafter max(previous long trailing stop, close - ATR(ATR lookback) * stop ATR multiple)
Calculation: Short trailing stop = close + ATR(ATR lookback) * stop ATR multiple on the short-entry signal bar; thereafter min(previous short trailing stop, close + ATR(ATR lookback) * stop ATR multiple)
Long: on a confirmed bar, long entries enabled AND position is flat AND bar index > max(longer EMA lookback, volatility-rank lookback) AND ATR(ATR lookback) > 0 AND Long score >= entry threshold AND Long score[1] < entry threshold
Short: on a confirmed bar, short entries enabled AND position is flat AND bar index > max(longer EMA lookback, volatility-rank lookback) AND ATR(ATR lookback) > 0 AND Short score >= entry threshold AND Short score[1] < entry threshold AND NOT (long entries enabled AND Long score >= entry threshold AND Long score[1] < entry threshold)
Exit: long, low <= Long trailing stop[1] OR (on a confirmed bar, Long score < exit threshold)
Exit: short, high >= Short trailing stop[1] OR (on a confirmed bar, Short score < exit threshold)
