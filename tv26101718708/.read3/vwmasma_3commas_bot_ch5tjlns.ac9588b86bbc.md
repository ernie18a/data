Calculation: Stochastic %K = SMA(Stochastic(close, high, low, stochastic lookback parameter), K smoothing lookback parameter)
Calculation: Stochastic %D = SMA(Stochastic %K, D smoothing lookback parameter)
Calculation: Stochastic midpoint = arithmetic mean(Stochastic %K, Stochastic %D)
Calculation: Long target level = close + ATR(ATR lookback parameter) * target multiple parameter at each slow VWMA crossing above slow SMA; otherwise retain its previous value; initialized to zero
Calculation: Long stop level = close - ATR(ATR lookback parameter) * stop multiple parameter at each slow VWMA crossing above slow SMA; otherwise retain its previous value; initialized to zero
Calculation: Short target level = close - ATR(ATR lookback parameter) * target multiple parameter at each slow VWMA crossing below slow SMA; otherwise retain its previous value; initialized to zero
Calculation: Short stop level = close + ATR(ATR lookback parameter) * stop multiple parameter at each slow VWMA crossing below slow SMA; otherwise retain its previous value; initialized to zero
Long: VWMA(price source parameter, fast VWMA lookback parameter) > SMA(price source parameter, fast SMA lookback parameter)
Long: VWMA(price source parameter, slow VWMA lookback parameter) > SMA(price source parameter, slow SMA lookback parameter)
Short: VWMA(price source parameter, fast VWMA lookback parameter) <= SMA(price source parameter, fast SMA lookback parameter)
Short: VWMA(price source parameter, slow VWMA lookback parameter) <= SMA(price source parameter, slow SMA lookback parameter)
Long: datetime > start-time parameter AND datetime < end-time parameter AND ((entry-signal parameter selects fast pair AND VWMA(price source parameter, fast VWMA lookback parameter) crosses above SMA(price source parameter, fast SMA lookback parameter)) OR (entry-signal parameter selects medium pair AND VWMA(price source parameter, fast VWMA lookback parameter) crosses above SMA(price source parameter, slow SMA lookback parameter)) OR (entry-signal parameter selects slow pair AND VWMA(price source parameter, slow VWMA lookback parameter) crosses above SMA(price source parameter, slow SMA lookback parameter)))
Short: datetime > start-time parameter AND datetime < end-time parameter AND ((entry-signal parameter selects fast pair AND VWMA(price source parameter, fast VWMA lookback parameter) crosses below SMA(price source parameter, fast SMA lookback parameter)) OR (entry-signal parameter selects medium pair AND VWMA(price source parameter, fast VWMA lookback parameter) crosses below SMA(price source parameter, slow SMA lookback parameter)) OR (entry-signal parameter selects slow pair AND VWMA(price source parameter, slow VWMA lookback parameter) crosses below SMA(price source parameter, slow SMA lookback parameter)))
Exit: Long, high >= long target level OR low <= long stop level OR slow VWMA crosses below slow SMA OR (stochastic exit enabled AND Stochastic %K crosses below Stochastic %D AND Stochastic midpoint >= overbought threshold parameter)
Exit: Short, low <= short target level OR high >= short stop level OR slow VWMA crosses above slow SMA OR (stochastic exit enabled AND Stochastic %K crosses above Stochastic %D AND Stochastic midpoint <= oversold threshold parameter)
