Calculation: Main stochastic %D = the series selected by the main-source parameter from four SMA(Stochastic(close, high, low, its K lookback), its D lookback) series, each with separate K and D lookback parameters
Calculation: Continuation stochastic %D = the series selected independently by the continuation-source parameter from the same four stochastic %D series
Calculation: Oversold visit state = initially false; set when Main stochastic %D <= the lower extreme threshold; clear after a main long signal or when Main stochastic %D >= the upper extreme threshold while this state is set
Calculation: Overbought visit state = initially false; set when Main stochastic %D >= the upper extreme threshold; clear after a main short signal or when Main stochastic %D <= the lower extreme threshold while this state is set
Calculation: Qualifying ADX peak state = initially false; set when Main stochastic %D <= the lower extreme threshold or >= the upper extreme threshold and ADX(DI lookback, smoothing lookback equal to DI lookback) >= the ADX peak threshold; clear after either main signal, or upon reaching the opposite extreme while its corresponding visit state is set
Calculation: Main long signal = Main stochastic %D crosses above the stochastic crossover level AND Oversold visit state AND (ADX filter disabled OR (Qualifying ADX peak state AND ADX(DI lookback, smoothing lookback equal to DI lookback) < its value on the previous bar)) AND (candle-color filter disabled OR close > open) AND (price-structure filter disabled OR low > Lowest(low, pivot lookback)[1]) AND (volume filter disabled OR volume > SMA(volume, volume lookback)) AND (ATR filter disabled OR ATR(ATR lookback) > SMA(ATR(ATR lookback), ATR baseline lookback) * minimum ATR ratio)
Calculation: Main short signal = Main stochastic %D crosses below the stochastic crossover level AND Overbought visit state AND (ADX filter disabled OR (Qualifying ADX peak state AND ADX(DI lookback, smoothing lookback equal to DI lookback) < its value on the previous bar)) AND (candle-color filter disabled OR close < open) AND (price-structure filter disabled OR high < Highest(high, pivot lookback)[1]) AND (volume filter disabled OR volume > SMA(volume, volume lookback)) AND (ATR filter disabled OR ATR(ATR lookback) > SMA(ATR(ATR lookback), ATR baseline lookback) * minimum ATR ratio)
Calculation: Long continuation mode = initially off; turn on after a main long signal and turn off after a main short signal
Calculation: Short continuation mode = initially off; turn on after a main short signal and turn off after a main long signal
Long: Main long signal OR (Long continuation mode AND Continuation stochastic %D crosses above the stochastic crossover level)
Short: Main short signal OR (Short continuation mode AND Continuation stochastic %D crosses below the stochastic crossover level)
