Calculation: VolumeAdjustedSource = let q = (close - open) × volume / (high - low); v = q + CUM(q); s = (v - SMA(v, volume-smoothing lookback)) / STDEV(v - SMA(v, volume-smoothing lookback), volatility lookback) × STDEV(high - low, volatility lookback); return high + s if s > 0, otherwise low + s
Calculation: TrendLine = let base = EMA(VolumeAdjustedSource, chart-bar lookback of T1 duration / chart-bar duration × intraday factor on intraday charts, otherwise fallback lookback; uses chart bars only); lower = base - SuperTrend multiplier × ATR(ATR lookback); upper = base + SuperTrend multiplier × ATR(ATR lookback); lower trail = max(lower, prior lower trail) if prior close > prior lower trail, otherwise lower; upper trail = min(upper, prior upper trail) if prior close < prior upper trail, otherwise upper; direction = positive if close > prior upper trail, negative if close < prior lower trail, otherwise prior direction defaulting positive; return lower trail when direction is positive, otherwise upper trail
Long: (close crosses above TrendLine AND close > EMA(open, same chart-bar lookback as TrendLine)) OR close crosses below (LinearRegression(close, regression lookback, regression offset) + TP multiplier × STDEV(close, same regression lookback))
Short: (close crosses below TrendLine AND close < EMA(open, same chart-bar lookback as TrendLine)) OR close crosses above (LinearRegression(close, regression lookback, regression offset) - TP multiplier × STDEV(close, same regression lookback))
