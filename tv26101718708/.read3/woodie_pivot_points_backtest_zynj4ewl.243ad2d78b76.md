Calculation: Pivot direction = long if close[1] < WoodiePivot(high(T1, last completed bar), low(T1, last completed bar), close(T1, last completed bar))[1] AND close > WoodiePivot(high(T1, last completed bar), low(T1, last completed bar), close(T1, last completed bar)), else short if close < WoodiePivot(high(T1, last completed bar), low(T1, last completed bar), close(T1, last completed bar)), else previous chart bar's Pivot direction (initially flat); the pivot values are sampled on chart bars
Long: (direction-reversal parameter disabled AND Pivot direction is long) OR (direction-reversal parameter enabled AND Pivot direction is short)
Short: (direction-reversal parameter disabled AND Pivot direction is short) OR (direction-reversal parameter enabled AND Pivot direction is long)
