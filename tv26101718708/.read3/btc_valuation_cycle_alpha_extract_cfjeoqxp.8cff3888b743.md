Calculation: Logistic score(z, curve intensity) = score scale / (1 + exp(−z × curve intensity))
Calculation: Valuation index = EMA(weighted mean of available scores with positive separate weights, cycle smoothing lookback), on chart bars, where the scores are logistic scores of chart-bar z-scores: SOPR(T1, last completed close) using the shared normalization lookback; BTC price(T1, last completed close) / (realized cap(T1, last completed close) / supply(T1, last completed close)) using that lookback; market cap(T1, last completed close) / realized cap(T1, last completed close), scored by the selected mode as either its z-score using the shared normalization lookback, its z-score using the separate MVRV z-score lookback, or the mean of both; and BTC close(T2, last completed bar) / SMA(BTC close, Mayer SMA lookback, T2, last completed bar) using the shared normalization lookback. T1 and T2 values are sampled on chart bars; the z-scores and EMA run on chart bars. All scores share the curve intensity.
Long: confirmed chart bar AND (Valuation index crosses below bottom threshold OR Valuation index crosses above cold threshold)
Short: confirmed chart bar AND (Valuation index crosses above top threshold OR Valuation index crosses below hot threshold OR BTC close(T2, last completed bar) / SMA(BTC close, Mayer SMA lookback, T2, last completed bar) crosses above Mayer threshold)
Calculation: MVRV = market capitalization / realized capitalization, using previous completed T1 closes
Calculation: Cycle = min(100, max(0, EMA(weighted mean of available scores with positive weights, cycle smoothing length))); SOPR score = 100 / (1 + exp(-z-score(SOPR − 1, normalization length) × curve intensity)); price-to-realized score = 100 / (1 + exp(-z-score(Bitcoin price / (realized capitalization / Bitcoin supply), normalization length) × curve intensity)); MVRV score is the ratio score, z-score score, or their mean according to MVRV mode, where ratio score = 100 / (1 + exp(-z-score(MVRV, normalization length) × curve intensity)) and z-score score = 100 / (1 + exp(-z-score(MVRV, MVRV z-score length) × curve intensity)); Mayer score = 100 / (1 + exp(-z-score(Mayer multiple, normalization length) × curve intensity)), where Mayer multiple = Bitcoin price / SMA(Bitcoin price, Mayer price SMA length); use previous completed T1 closes for SOPR, Bitcoin price, market capitalization, realized capitalization, and Bitcoin supply, and the previous completed T2 value for Mayer multiple; weighted mean = sum of each available score × its separate weight / sum of their weights
Short: Cycle crosses above top threshold on a confirmed chart bar
Long: Cycle crosses below bottom threshold on a confirmed chart bar
Short: previous chart-bar Cycle ≥ hot threshold AND current Cycle < hot threshold AND chart bar confirmed
Long: previous chart-bar Cycle ≤ cold threshold AND current Cycle > cold threshold AND chart bar confirmed
