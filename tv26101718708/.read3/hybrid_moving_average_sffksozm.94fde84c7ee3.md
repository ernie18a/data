Calculation: Direction vote(price, line) = bullish when price is above line, bearish when price is below line, and neutral when equal.
Calculation: Slope vote(series) = bullish when the series rises, bearish when it falls, and neutral when unchanged.
Calculation: Heikin-Ashi midpoint = average of Heikin-Ashi open and Heikin-Ashi close.
Calculation: Consensus vote total = sum of direction votes for close versus HMA(source, base lookback), THMA(source, shorter lookback), KAMA(source, shorter lookback, KAMA fast smoothing parameter A, KAMA slow smoothing parameter A), rolling VWAP(HLC3, base lookback), ALMA(source, base lookback, ALMA offset parameter, ALMA sigma parameter), and HMA(Heikin-Ashi midpoint, base lookback).
Calculation: Long-term line = average of ALMA(source, longer lookback, ALMA offset parameter, ALMA sigma parameter), rolling VWAP(HLC3, longer lookback), and KAMA(source, longer lookback, KAMA fast smoothing parameter B, KAMA slow smoothing parameter B).
Calculation: Consensus hybrid = fast average times reactive weight plus slow average times the complement of reactive weight; fast average is the mean of HMA(source, base lookback), THMA(source, shorter lookback), and KAMA(source, shorter lookback, KAMA fast smoothing parameter A, KAMA slow smoothing parameter A); slow average is the mean of rolling VWAP(HLC3, base lookback), ALMA(source, base lookback, ALMA offset parameter, ALMA sigma parameter), HMA(Heikin-Ashi midpoint, base lookback), and the long-term line; reactive weight is the clamped sum of a base weight parameter, a vote contribution parameter times the normalized absolute consensus vote total, and a distance contribution parameter times abs(close minus long-term line) divided by max(ATR(base lookback), tick-size parameter), using separate lower and upper clamp parameters.
Calculation: Consensus direction = bullish when consensus vote total meets or exceeds the agreement threshold and close is above the consensus hybrid; bearish when consensus vote total meets or falls below the negative agreement threshold and close is below the consensus hybrid; neutral otherwise.
Calculation: Raw switch line = weighted sum of HMA(source, base lookback), EHMA(source, intermediate lookback), KAMA(source, shorter lookback, KAMA fast smoothing parameter C, KAMA slow smoothing parameter C), HMA(Heikin-Ashi midpoint, base lookback), and rolling VWAP(HLC3, base lookback), using a separate weight parameter for each component.
Calculation: Switch alpha = clamp(base alpha plus abs(price pressure) times pressure gain parameter plus cross-pull parameter when EMA(source, trigger lookback) crosses the previous trend switch, using separate lower and upper clamp parameters); base alpha is the clamped sum of the complement of trend memory parameter and Kaufman efficiency ratio(source, shorter lookback) times efficiency gain parameter, using separate lower and upper clamp parameters; price pressure is the clamped difference between EMA(source, trigger lookback) and the previous trend switch divided by max(ATR(base lookback), tick-size parameter), using separate lower and upper pressure parameters.
Calculation: Trend switch = raw switch line on the first bar; thereafter previous trend switch plus switch alpha times the difference between raw switch line and previous trend switch.
Calculation: Switch direction = bullish when the sum of slope votes for HMA(source, base lookback), trend switch, and direction votes for source versus KAMA(source, shorter lookback, KAMA fast smoothing parameter C, KAMA slow smoothing parameter C), Heikin-Ashi close versus Heikin-Ashi open, source versus rolling VWAP(HLC3, base lookback), and EMA(source, trigger lookback) versus trend switch meets or exceeds the agreement threshold and close is above trend switch; bearish when that sum meets or falls below the negative agreement threshold and close is below trend switch; neutral otherwise.
Calculation: Aligned direction = bullish when consensus direction and switch direction are both bullish; bearish when both are bearish; neutral otherwise.
Long: Aligned direction is bullish.
Short: Aligned direction is bearish.
Long: Aligned direction is bullish AND aligned direction on the prior bar was not bullish.
Short: Aligned direction is bearish AND aligned direction on the prior bar was not bearish.
