Calculation: Long trend persistence = bars since close was above EMA(close, longer EMA lookback) >= trend-persistence bar count.
Calculation: Short trend persistence = bars since close was below EMA(close, longer EMA lookback) >= trend-persistence bar count.
Calculation: Volume spike = volume >= SMA(volume, volume-average lookback) * volume-spike multiplier.
Calculation: Body expansion = abs(close - open) >= SMA(abs(close - open), body-expansion lookback) * body-expansion multiplier.
Calculation: Lower-low count = on each swing-low bar, start at one if there is no prior swing low or the current low is >= the prior swing low; otherwise increment the count. Retain the count between swing lows. Reset the count and prior swing low when close crosses above EMA(close, longer EMA lookback). A swing low is low < low[n1] AND low < low[n2] AND low[n1] < low[n2] AND low[n1] < low[n3], where n1, n2, and n3 are consecutive swing-pattern offsets in ascending order.
Calculation: Higher-high count = on each swing-high bar, start at one if there is no prior swing high or the current high is <= the prior swing high; otherwise increment the count. Retain the count between swing highs. Reset the count and prior swing high when close crosses below EMA(close, longer EMA lookback). A swing high is high > high[n1] AND high > high[n2] AND high[n1] > high[n2] AND high[n1] > high[n3], using the same swing-pattern offsets.
Calculation: Long score = the number of true conditions among: Long trend persistence; bars since close was above EMA(close, shorter EMA lookback) >= acceleration bar count AND Long trend persistence; Volume spike; Body expansion; close < EMA(close, longer EMA lookback) AND abs(close - EMA(close, longer EMA lookback)) / ATR(ATR lookback) >= extension ATR multiplier; Lower-low count >= minimum swing-leg count.
Calculation: Short score = the number of true conditions among: Short trend persistence; bars since close was below EMA(close, shorter EMA lookback) >= acceleration bar count AND Short trend persistence; Volume spike; Body expansion; close > EMA(close, longer EMA lookback) AND abs(close - EMA(close, longer EMA lookback)) / ATR(ATR lookback) >= extension ATR multiplier; Higher-high count >= minimum swing-leg count.
Long: Long score >= minimum score AND close < open AND (volume spike is required only if its requirement toggle is enabled) AND close < EMA(close, longer EMA lookback) AND (time filter is disabled OR bar time is between the configured start and end times inclusive).
Short: Short score >= minimum score AND close > open AND (volume spike is required only if its requirement toggle is enabled) AND close > EMA(close, longer EMA lookback) AND (time filter is disabled OR bar time is between the configured start and end times inclusive).
Exit: long, (stop-loss toggle enabled AND low <= signal-bar close - ATR(ATR lookback) on the signal bar * stop-loss multiplier) OR (take-profit toggle enabled AND high >= signal-bar close + ATR(ATR lookback) on the signal bar * take-profit multiplier) OR (trailing-stop toggle enabled AND the active long trailing stop is hit, with activation distance and offset each equal to current ATR(ATR lookback) * trailing-stop multiplier).
Exit: short, (stop-loss toggle enabled AND high >= signal-bar close + ATR(ATR lookback) on the signal bar * stop-loss multiplier) OR (take-profit toggle enabled AND low <= signal-bar close - ATR(ATR lookback) on the signal bar * take-profit multiplier) OR (trailing-stop toggle enabled AND the active short trailing stop is hit, with activation distance and offset each equal to current ATR(ATR lookback) * trailing-stop multiplier).
