Calculation: Bullish HTF bias(T) = last completed T bar close > EMA(close, shorter HTF EMA lookback, T) > EMA(close, longer HTF EMA lookback, T); bearish HTF bias reverses both comparisons. Calculate these on T bars and sample the last completed T bar values on chart bars; use separate timeframes T1 and T2.
Calculation: Bullish HTF alignment = bullish HTF bias(T1) AND bullish HTF bias(T2); bearish HTF alignment = bearish HTF bias(T1) AND bearish HTF bias(T2). Evaluate on chart bars using each timeframe’s last completed bar.
Calculation: Bull structure break = on a confirmed chart bar, close crosses above the latest confirmed Pivot High(high, pivot lookback, pivot lookback); bear structure break = close crosses below the latest confirmed Pivot Low(low, pivot lookback, pivot lookback). The latest break sets structure direction; a break opposite the prior direction is a CHOCH, otherwise a BOS.
Calculation: Recent bull sweep = a bull sweep occurred within the event lookback chart bars; recent bear sweep = a bear sweep occurred within the event lookback chart bars. Recent bull structure = a bull structure break occurred within the event lookback chart bars; recent bear structure = a bear structure break occurred within the event lookback chart bars.
Calculation: Bull order-block touch = current low <= top and close >= bottom of any unbroken bullish order-block zone; create such zones only on a bull CHOCH, from the first qualifying prior bearish candle within the OB lookback, with zone between its close and open and absolute body > ATR(ATR lookback) * OB body fraction; remove a zone when close < bottom. Bear order-block touch = current high >= bottom and close <= top of any unbroken bearish order-block zone; create such zones only on a bear CHOCH, from the first qualifying prior bullish candle within the OB lookback with the same body filter, and remove a zone when close > top.
Calculation: Bull fair-value-gap touch = current low <= top and close >= bottom of any unfilled bullish fair-value-gap zone created on a confirmed chart bar when low - high[gap spacing] >= ATR(ATR lookback) * minimum gap fraction; zone boundaries are high[gap spacing] and low, and remove it when low < bottom. Bear fair-value-gap touch = current high >= bottom and close <= top of any unfilled bearish fair-value-gap zone created when low[gap spacing] - high >= ATR(ATR lookback) * minimum gap fraction; zone boundaries are high and low[gap spacing], and remove it when high > top.
Calculation: Confluence score(side) = clamp(score floor, score ceiling, current same-side sweep weight or, if absent, recent same-side sweep weight; plus both same-side HTF alignment weight or, if only T1 bias agrees, T1-only HTF weight; plus current same-side structure weight or, if absent, recent same-side structure weight or, if absent, same-side latest structure-direction weight; plus kill-zone weight when the chart bar is in either configured UTC kill zone, otherwise session weight when it is in either configured UTC London or New York session; plus same-side order-block touch weight; plus same-side fair-value-gap touch weight; plus range-location weight when close is below rolling low + (rolling high - rolling low) * range fraction for long, or above rolling high - (rolling high - rolling low) * range fraction for short, using rolling high/low over range lookback chart bars; plus above-average ATR weight when ATR(ATR lookback) > SMA(ATR(ATR lookback), ATR average lookback); minus extreme-volatility penalty when ATR(ATR lookback) > SMA(ATR(ATR lookback), ATR average lookback) * volatility multiplier). Use separate score weights for each listed contribution and penalty.
Calculation: Bullish momentum dominance = (close - close[momentum lookback]) / (ATR(ATR lookback) * momentum lookback) > momentum move threshold OR the count of bullish candles among the last momentum lookback chart bars >= momentum lookback * directional candle fraction; bearish momentum dominance uses the inverse move and bearish candles.
Long: bull sweep, defined as a confirmed chart bar with low < lowest low of the previous sweep lookback chart bars AND close > that low threshold.
Short: bear sweep, defined as a confirmed chart bar with high > highest high of the previous sweep lookback chart bars AND close < that high threshold.
Long: bull structure break.
Short: bear structure break.
Long: sensitivity selects the branch requiring recent bull sweep AND recent bull structure AND (bull order-block touch OR bull fair-value-gap touch) AND bullish confluence score >= score threshold, or the branch requiring recent bull sweep AND recent bull structure AND bullish confluence score >= score threshold, or the branch requiring bullish confluence score to cross above score threshold AND bullish HTF bias(T1), or the branch requiring bullish confluence score >= score threshold AND bullish HTF bias(T1); confirmed chart bar AND (momentum filter disabled OR NOT bearish momentum dominance).
Short: sensitivity selects the branch requiring recent bear sweep AND recent bear structure AND (bear order-block touch OR bear fair-value-gap touch) AND bearish confluence score >= score threshold, or the branch requiring recent bear sweep AND recent bear structure AND bearish confluence score >= score threshold, or the branch requiring bearish confluence score to cross above score threshold AND bearish HTF bias(T1), or the branch requiring bearish confluence score >= score threshold AND bearish HTF bias(T1); confirmed chart bar AND (momentum filter disabled OR NOT bullish momentum dominance).
Long: the long signal condition above AND more than the signal cooldown parameter chart bars since either side last fired.
Short: the short signal condition above AND more than the signal cooldown parameter chart bars since either side last fired.
