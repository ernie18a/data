Calculation: EMA slope = EMA(close, EMA length) - EMA(close, EMA length)[EMA slope lookback]
Calculation: Window range(offset, length) = highest(high, length)[offset] - lowest(low, length)[offset]
Calculation: Build range = Window range(0, build length)
Calculation: Close position = (close - lowest(low, build length)) / Build range if Build range > 0, else 0.5
Calculation: Arch compression = Window range(0, half length) < Window range(build length - half length, half length), where half length = max(2, floor(build length * 0.5))
Calculation: Rising low trend = linear regression(low, build length, 0) > linear regression(low, build length, 1)
Calculation: Falling high trend = linear regression(high, build length, 0) < linear regression(high, build length, 1)
Calculation: Range contraction = Build range < Window range(build length, build length)
Calculation: Strong compression = (Window range(build length - third length, third length) > Window range(max(0, build length - 2 * third length), third length) AND Window range(max(0, build length - 2 * third length), third length) > Window range(0, third length)) OR (Arch compression AND SMA(high - low, build length) < SMA(high - low, build length)[build length]), where third length = max(2, floor(build length / 3))
Calculation: Weighted overlap = (sum over i from 0 to build length - 2 of w(i) * ov(i)) / (sum over the same i of w(i)), where w(i) = 1 + overlap recency weight * (build length - 1 - i), ov(i) = max(0, min(high[i], high[i+1]) - max(low[i], low[i+1])) / max(high[i] - low[i], high[i+1] - low[i+1]), and ov(i) = 0 when that denominator is 0
Calculation: Noise quality good = (count of wick bars > count of hard bars) OR count of hard bars = 0, where the bars i from 0 to build length - 1 with high[i] - low[i] >= ATR(ATR length) * small-bar ATR multiplier are counted, a counted bar is a wick bar if abs(close[i] - open[i]) / (high[i] - low[i]) < noise body ratio OR (high[i] <= highest(high, build length) + ATR(ATR length) * noise range ATR multiplier AND low[i] >= lowest(low, build length) - ATR(ATR length) * noise range ATR multiplier), and otherwise a hard bar
Calculation: EMA near cluster = EMA(close, EMA length) >= lowest(low, build length) - ATR(ATR length) * EMA near ATR multiplier AND EMA(close, EMA length) <= highest(high, build length) + ATR(ATR length) * EMA near ATR multiplier
Calculation: Build-up score = build narrow weight * [Build range <= ATR(ATR length) * build range ATR multiplier] + build overlap weight * [Weighted overlap >= overlap threshold] + build small-bar weight * [count of bars among the last build length with high - low < ATR(ATR length) * small-bar ATR multiplier >= build length - noise bars allowed] + build EMA weight * [EMA near cluster] + (build strong-compression weight if Strong compression, else build weak-compression weight if (Rising low trend OR Falling high trend OR Arch compression OR Range contraction), else 0) + build barrier weight * [Near upper barrier OR Near lower barrier] + build noise weight * [Noise quality good]
Calculation: Build-up = Build-up score >= build score minimum
Calculation: Nearest upper barrier = min of those among {most recent pivot high(high, swing length, swing length), second most recent pivot high(high, swing length, swing length), highest(high[build length], barrier lookback), ceil(close / round step) * round step if round barrier switch on} that are greater than close, undefined if none, where round step = round interval pips * pip size
Calculation: Nearest lower barrier = max of those among {most recent pivot low(low, swing length, swing length), second most recent pivot low(low, swing length, swing length), lowest(low[build length], barrier lookback), floor(close / round step) * round step if round barrier switch on} that are less than close, undefined if none, where round step = round interval pips * pip size
Calculation: Near upper barrier = Nearest upper barrier exists AND abs(Nearest upper barrier - highest(high, build length)) <= barrier near pips * pip size
Calculation: Near lower barrier = Nearest lower barrier exists AND abs(lowest(low, build length) - Nearest lower barrier) <= barrier near pips * pip size
Calculation: Long room OK = Near upper barrier OR (Nearest upper barrier does not exist) OR round((Nearest upper barrier - close) / pip size) >= minimum room pips
Calculation: Short room OK = Near lower barrier OR (Nearest lower barrier does not exist) OR round((close - Nearest lower barrier) / pip size) >= minimum room pips
Calculation: EMA stretch OK = abs(close - EMA(close, EMA length)) <= ATR(ATR length) * EMA stretch ATR multiplier
Calculation: Range position = (close - lowest(low, range lookback)) / (highest(high, range lookback) - lowest(low, range lookback)) if the denominator > 0, else 0.5
Calculation: Range state = range filter on AND highest(high, range lookback) - lowest(low, range lookback) <= ATR(ATR length) * range width ATR multiplier AND abs(EMA(close, EMA length) - EMA(close, EMA length)[range lookback]) <= ATR(ATR length) * range EMA flat ATR multiplier AND count of bars among the last range lookback where close crosses EMA(close, EMA length) >= range cross minimum
Calculation: Strong bull bar = close > open AND high - low > ATR(ATR length) * power bar ATR multiplier AND abs(close - open) / (high - low) >= power body ratio
Calculation: Strong bear bar = close < open AND high - low > ATR(ATR length) * power bar ATR multiplier AND abs(close - open) / (high - low) >= power body ratio
Calculation: In session(start, end) = (JST hour >= start AND JST hour < end) if end <= 24, else (JST hour >= start OR JST hour < end - 24), where JST hour = hour of bar datetime in JST
Calculation: Session OK = session filter off OR In session(London start, London end) OR In session(NY start, NY end)
Calculation: Long score = max(0, dir trend weight * [EMA slope >= -ATR(ATR length) * EMA slope ATR multiplier] + dir EMA weight * [close >= EMA(close, EMA length) OR EMA near cluster] + dir compression weight * [Rising low trend OR Arch compression] + dir close weight * [Close position >= buy score close threshold] + dir wick weight * [sum of (min(open, close) - low) over last build length bars >= sum of (high - max(open, close)) over the same bars] + dir barrier weight * [Long room OK AND SMA(max(0, open - close), build length) <= weak body ratio * SMA(abs(close - open), build length)] - HTF penalty * [HTF filter on AND EMA(close, EMA length, T1, last completed bar) >= EMA(close, EMA length)])
Calculation: Short score = max(0, dir trend weight * [EMA slope <= ATR(ATR length) * EMA slope ATR multiplier] + dir EMA weight * [close <= EMA(close, EMA length) OR EMA near cluster] + dir compression weight * [Falling high trend OR Arch compression] + dir close weight * [Close position <= sell score close threshold] + dir wick weight * [sum of (high - max(open, close)) over last build length bars >= sum of (min(open, close) - low) over the same bars] + dir barrier weight * [Short room OK AND SMA(max(0, close - open), build length) <= weak body ratio * SMA(abs(close - open), build length)] - HTF penalty * [HTF filter on AND EMA(close, EMA length, T1, last completed bar) <= EMA(close, EMA length)])
Long: Session OK AND Build-up AND Long score >= dir score minimum AND Long score > Short score AND Long score - Short score >= dir gap minimum AND (NOT Range state OR Long score - Short score >= range dir gap minimum) AND (EMA near cluster OR Near upper barrier) AND Close position >= buy entry close threshold AND Long room OK AND EMA stretch OK AND close - lowest(low, surge lookback) <= ATR(ATR length) * surge ATR multiplier AND (NOT Range state OR Range position >= range upper percentile) AND no Strong bull bar among the last power lookback bars including the current bar AND (no earlier Long OR bars since last Long > cooldown bars)
Short: Session OK AND Build-up AND Short score >= dir score minimum AND Short score > Long score AND Short score - Long score >= dir gap minimum AND (NOT Range state OR Short score - Long score >= range dir gap minimum) AND (EMA near cluster OR Near lower barrier) AND Close position <= sell entry close threshold AND Short room OK AND EMA stretch OK AND highest(high, surge lookback) - close <= ATR(ATR length) * surge ATR multiplier AND (NOT Range state OR Range position <= range lower percentile) AND no Strong bear bar among the last power lookback bars including the current bar AND (no earlier Short OR bars since last Short > cooldown bars)
