Calculation: Bullish embedded level = max(lowest(low, lookback, T1 still-forming bar, sampled on chart bars) + (overbought level / 100) * (highest(high, lookback, T1 still-forming bar, sampled on chart bars) - lowest(low, lookback, T1 still-forming bar, sampled on chart bars)), previous chart-bar value of this level, defaulting to the current raw level if unavailable)
Calculation: Bearish embedded level = min(lowest(low, lookback, T1 still-forming bar, sampled on chart bars) + (oversold level / 100) * (highest(high, lookback, T1 still-forming bar, sampled on chart bars) - lowest(low, lookback, T1 still-forming bar, sampled on chart bars)), previous chart-bar value of this level, defaulting to the current raw level if unavailable)
Calculation: Scaled %K = Bearish embedded level + (Stochastic %K(close, high, low, lookback, T2 still-forming bar, sampled on chart bars) - oversold level) * (Bullish embedded level - Bearish embedded level) / (overbought level - oversold level)
Long: close > Bearish embedded level AND ((Scaled %K > Scaled %K[1] AND Scaled %K[1] <= oversold level) OR crosses above oversold level)
Short: close < Bullish embedded level AND ((Scaled %K < Scaled %K[1] AND Scaled %K[1] >= overbought level) OR crosses below overbought level)
