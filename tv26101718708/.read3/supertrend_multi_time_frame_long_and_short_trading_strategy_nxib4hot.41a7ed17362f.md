Calculation: Chandelier Exit direction = initialize direction at 1; on each bar of its timeframe, distance = multiplier × ATR(shared lookback); raw long stop = (highest(close, shared lookback) when close-extremum mode is enabled, otherwise highest(high, shared lookback)) − distance; long stop = max(raw long stop, prior long stop) when prior close > prior long stop, otherwise raw long stop; raw short stop = (lowest(close, shared lookback) when close-extremum mode is enabled, otherwise lowest(low, shared lookback)) + distance; short stop = min(raw short stop, prior short stop) when prior close < prior short stop, otherwise raw short stop; when a prior stop is unavailable, use the current raw stop; direction = 1 when close > prior short stop, −1 when close < prior long stop, otherwise prior direction; use the same lookback, multiplier, and close-extremum setting on chart bars, T1, and T2.
Long: Chandelier Exit direction on chart bars changes from −1 to 1 AND Chandelier Exit direction(T1, last completed bar) = 1 AND Chandelier Exit direction(T2, last completed bar) = 1 AND configured trade side allows long AND chart bar datetime > configured start datetime AND chart bar datetime < configured end datetime
Short: Chandelier Exit direction on chart bars changes from 1 to −1 AND Chandelier Exit direction(T1, last completed bar) = −1 AND Chandelier Exit direction(T2, last completed bar) = −1 AND configured trade side allows short AND chart bar datetime > configured start datetime AND chart bar datetime < configured end datetime
Exit: long, low < entry price × (1 − configured stop-loss percentage)
Exit: short, high > entry price × (1 + configured stop-loss percentage)
Exit: long, high >= entry price × (1 + first take-profit percentage) OR high >= entry price × (1 + second take-profit percentage) OR high >= entry price × (1 + third take-profit percentage)
Exit: short, low <= entry price × (1 − first take-profit percentage) OR low <= entry price × (1 − second take-profit percentage) OR low <= entry price × (1 − third take-profit percentage)
Exit: long, Chandelier Exit direction on chart bars changes from 1 to −1 AND (short trading is disabled OR chart bar datetime <= configured start datetime OR chart bar datetime >= configured end datetime OR Chandelier Exit direction(T1, last completed bar) >= 0 OR Chandelier Exit direction(T2, last completed bar) >= 0)
Exit: short, Chandelier Exit direction on chart bars changes from −1 to 1 AND (long trading is disabled OR chart bar datetime <= configured start datetime OR chart bar datetime >= configured end datetime OR Chandelier Exit direction(T1, last completed bar) <= 0 OR Chandelier Exit direction(T2, last completed bar) <= 0)
