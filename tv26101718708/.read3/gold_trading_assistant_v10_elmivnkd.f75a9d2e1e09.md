Calculation: DXY directional score = for valid DXY data, if z-score mode is enabled, strong positive score when DXY return z-score <= negative strong z threshold, mild positive score when <= negative mild z threshold, strong negative score when >= strong z threshold, mild negative score when >= mild z threshold, otherwise zero; if z-score mode is disabled, apply the same ordered comparisons to DXY percent return using separate strong and mild negative and positive return thresholds; otherwise zero. DXY percent return uses the last completed T3 close and the close lookback bars before it. Its z-score compares that return with SMA and standard deviation over the z-score lookback of chart bars carrying the last-completed-T3 return; use zero when standard deviation is zero.
Calculation: Silver directional score = for valid silver data, if z-score mode is enabled, strong positive score when silver return z-score >= strong z threshold, mild positive score when >= mild z threshold, strong negative score when <= negative strong z threshold, mild negative score when <= negative mild z threshold, otherwise zero; if z-score mode is disabled, apply the same ordered comparisons to silver percent return using separate strong and mild positive and negative return thresholds; otherwise zero. Silver percent return uses the last completed T3 close and the close lookback bars before it. Its z-score compares that return with SMA and standard deviation over the z-score lookback of chart bars carrying the last-completed-T3 return; use zero when standard deviation is zero.
Calculation: Yield directional score = for valid yield data, if z-score mode is enabled, strong positive score when yield change in basis points z-score <= negative strong z threshold, mild positive score when <= negative mild z threshold, strong negative score when >= strong z threshold, mild negative score when >= mild z threshold, otherwise zero; if z-score mode is disabled, apply the same ordered comparisons to yield change in basis points using separate strong and mild negative and positive change thresholds; otherwise zero. Yield change uses the last completed T3 close and the close lookback bars before it. Its z-score compares that change with SMA and standard deviation over the z-score lookback of chart bars carrying the last-completed-T3 change; use zero when standard deviation is zero.
Calculation: Macro directional percentage = weighted sum of valid DXY, silver, and yield directional scores divided by the sum of their available maximum absolute weighted scores; use zero when that denominator is zero. The three weights are separate parameters.

Calculation: Long structure score = support points if any enabled previous T4 low, previous T5 low, one of the latest confirmed chart-bar pivot lows, or round-number level is strictly below close and within ATR(ATR lookback) × structure-proximity ATR multiple; otherwise zero. Round-number levels use the round-number step.
Calculation: Short structure score = resistance points if any enabled previous T4 high, previous T5 high, one of the latest confirmed chart-bar pivot highs, or round-number level is strictly above close and within ATR(ATR lookback) × structure-proximity ATR multiple; otherwise zero. Round-number levels use the round-number step.
Calculation: Long trend score = strong rising-trend points when (EMA(close, fast EMA lookback) - EMA(close, fast EMA lookback)[trend lookback]) / ATR(ATR lookback) > strong trend threshold; mild rising-trend points when it is > mild trend threshold; otherwise zero.
Calculation: Short trend score = strong falling-trend points when (EMA(close, fast EMA lookback) - EMA(close, fast EMA lookback)[trend lookback]) / ATR(ATR lookback) < negative strong trend threshold; mild falling-trend points when it is < negative mild trend threshold; otherwise zero.
Calculation: News bonus = news-clear points when news filtering is enabled, no enabled event is within its impact-specific blackout window of the current bar time, and there is no enabled future event or the nearest enabled future event is more than the news-clear lead-time parameter away; otherwise zero. Each event's blackout window is its configured high-, medium-, or low-impact duration before and after its configured datetime.
Calculation: Long confluence = pattern points + long timeframe score + MAX(Macro directional percentage, 0) × macro-score scale + volume score + long structure score + long trend score + news bonus.
Calculation: Short confluence = pattern points + short timeframe score + MAX(-Macro directional percentage, 0) × macro-score scale + volume score + short structure score + short trend score + news bonus.
Calculation: Long first-target reward/risk = (long first target - close) / long risk when long risk > 0, otherwise zero. Long risk = close - MIN(LOWEST(low, stop swing lookback) - ATR(ATR lookback) × stop swing ATR buffer, close - ATR(ATR lookback) × ATR stop multiple). Long baseline target = close + long risk × first-target reward/risk target. When hybrid targets are enabled and an eligible resistance exists, long first target is the nearest enabled resistance above close and at or below the baseline target, less the structure buffer converted from pips to price; otherwise it is the baseline target. Eligible resistances are previous completed T4 high, previous completed T5 high, latest confirmed chart-bar pivot highs, and round-number levels, each subject to its enable toggle.
Calculation: Short first-target reward/risk = (close - short first target) / short risk when short risk > 0, otherwise zero. Short risk = MAX(MAXIMUM(high, stop swing lookback) + ATR(ATR lookback) × stop swing ATR buffer, close + ATR(ATR lookback) × ATR stop multiple) - close. Short baseline target = close - short risk × first-target reward/risk target. When hybrid targets are enabled and an eligible support exists, short first target is the nearest enabled support below close and at or above the baseline target, plus the structure buffer converted from pips to price; otherwise it is the baseline target. Eligible supports are previous completed T4 low, previous completed T5 low, latest confirmed chart-bar pivot lows, and round-number levels, each subject to its enable toggle.
