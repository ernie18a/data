Calculation: volume pressure = EMA(( ((close - low) / max(high - low, minimum price increment)) - ((high - close) / max(high - low, minimum price increment)) ) * volume (zero when missing), pressure smoothing lookback) / max(EMA(volume (zero when missing), pressure smoothing lookback), minimum volume denominator)
Calculation: relative volume = volume (zero when missing) / max(SMA(volume (zero when missing), volume average lookback), minimum volume denominator)
Calculation: pressure score = clamp(base score + (volume pressure > 0 ? positive pressure points : negative pressure points) + (OBV(close, volume) > SMA(OBV(close, volume), volume average lookback) ? positive OBV points : negative OBV points) + (close > VWAP(hlc3) ? positive VWAP points : negative VWAP points) + (relative volume > relative-volume gate ? high-volume points : low-volume points), pressure-score floor, pressure-score ceiling)
Calculation: kinetic trend and acceleration = initialize price estimate to first close and velocity and acceleration to zero; on each chart bar, predict price as prior estimate + prior velocity + acceleration multiplier * prior acceleration, predict velocity as prior velocity + prior acceleration, and calculate residual as close - predicted price; set boost to high boost multiplier when abs(residual) / max(ATR(ATR lookback), minimum price increment) > residual boost threshold, otherwise to base boost multiplier; update price estimate by predicted price + (1 - lambda^3) * boost * residual, velocity by predicted velocity + beta coefficient * (1 - lambda)^2 * (1 + lambda) * boost * residual, and acceleration by prior acceleration + gamma coefficient * (1 - lambda)^3 * boost * residual; kinetic trend is velocity / max(ATR(ATR lookback), minimum price increment)
Calculation: regression confidence and slope = let regression be linear regression(close, regression window, offset zero), residual be close - regression, and confidence be zero when variance(close, regression window) is zero, otherwise clamp(1 - variance(residual, regression window) / variance(close, regression window), confidence floor, confidence ceiling); slope is regression - regression[slope lag]
Calculation: structure direction = initialize neutral; track the latest confirmed pivot high and pivot low, each using pivot lookback bars to the left and right; on confirmed chart bars, set direction bullish and clear the pivot high when close > latest pivot high + ATR(ATR lookback) * structure-break ATR multiple, and set direction bearish and clear the pivot low when close < latest pivot low - ATR(ATR lookback) * structure-break ATR multiple; otherwise retain direction
Calculation: ALMA band direction = on bars of the requested timeframe, use the preceding bar's close as source; calculate ALMA(source, ALMA lookback, ALMA offset, ALMA sigma) and standard deviation(source, deviation lookback); raw upper and lower bands are ALMA plus and minus deviation-factor * standard deviation; trailing upper is raw upper if raw upper < prior trailing upper or prior source > prior trailing upper, otherwise prior trailing upper; trailing lower is raw lower if raw lower > prior trailing lower or prior source < prior trailing lower, otherwise prior trailing lower; direction is bullish if source > trailing upper, bearish if source < trailing lower, otherwise prior direction, initialized neutral
Calculation: ALMA vote = the sum of ALMA band direction on T1, T2, T3, and T4; calculate each on its timeframe bars from the last completed bar, with chart bars taking the latest returned value from each timeframe
Calculation: directional scores = clamp the sum of the applicable category weights, using the same weights for each side, to the score floor and ceiling; long score adds the structure weight when structure direction is bullish, higher-timeframe weight when the last completed close on T5 > EMA(close, shorter EMA lookback) on T5's last completed bar, ALMA weight when ALMA vote >= ALMA vote threshold, kinetic weight when kinetic trend > kinetic trend threshold and acceleration >= 0, regression weight when regression confidence >= minimum confidence and regression slope > 0, pressure weight when pressure score > long pressure-score threshold, and trend weight when close > EMA(close, shorter EMA lookback) > EMA(close, longer EMA lookback); short score uses the corresponding bearish comparisons, ALMA vote <= -ALMA vote threshold, kinetic trend < -kinetic trend threshold and acceleration <= 0, regression slope < 0, pressure score < short pressure-score threshold, and close < EMA(close, shorter EMA lookback) < EMA(close, longer EMA lookback)
Long: confirmed chart bar AND (no prior accepted strategy entry OR chart bars since the last accepted strategy entry >= cooldown bars) AND ATR(ATR lookback) / close > volatility threshold AND long score >= score-entry threshold AND volume pressure > pressure gate AND relative volume >= relative-volume gate
Short: confirmed chart bar AND (no prior accepted strategy entry OR chart bars since the last accepted strategy entry >= cooldown bars) AND ATR(ATR lookback) / close > volatility threshold AND short score >= score-entry threshold AND volume pressure < -pressure gate AND relative volume >= relative-volume gate
Exit: long, low <= max(entry price - ATR(ATR lookback) * stop ATR multiple, if trailing is enabled then the maximum since the current long position began of close - ATR(ATR lookback) * trailing ATR multiple, otherwise entry price - ATR(ATR lookback) * stop ATR multiple) OR high >= entry price + ATR(ATR lookback) * target ATR multiple OR chart bars since the position first became nonflat >= time-stop bars OR structure direction is bearish OR short score > long score + score-invalidation margin
Exit: short, high >= min(entry price + ATR(ATR lookback) * stop ATR multiple, if trailing is enabled then the minimum since the current short position began of close + ATR(ATR lookback) * trailing ATR multiple, otherwise entry price + ATR(ATR lookback) * stop ATR multiple) OR low <= entry price - ATR(ATR lookback) * target ATR multiple OR chart bars since the position first became nonflat >= time-stop bars OR structure direction is bullish OR long score > short score + score-invalidation margin
