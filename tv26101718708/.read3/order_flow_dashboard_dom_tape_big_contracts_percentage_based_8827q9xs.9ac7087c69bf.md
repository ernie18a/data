Calculation: Estimated bar delta = volume * (2 * close - high - low) / (high - low) when high > low, otherwise 0; set to 0 outside the configured session when the session filter is enabled
Long: Sum(Estimated bar delta, DOM lookback chart bars) >= 0 OR Sum(Estimated bar delta, Tape lookback chart bars) > 0 OR Cumulative Delta(Estimated bar delta, reset time each calendar day) >= 0 OR (volume >= big-contract volume threshold AND close > open on chart bars when detection uses the chart timeframe, or on each T1 bar, including the still-forming bar, when detection uses T1)
