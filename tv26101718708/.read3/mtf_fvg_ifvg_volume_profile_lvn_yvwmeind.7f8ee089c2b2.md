Calculation: Profile row size = max(minimum-tick parameter, round(raw row size / minimum-tick parameter) * minimum-tick parameter), fixed at chart-history start, where raw row size is the fixed row-size parameter if positive and otherwise ATR(lookback, T_profile, last completed bar) / row-size divisor parameter.
Calculation: Relative gap volume(top, bottom) = mean profile volume across rows from floor(bottom / profile row size) through floor(top / profile row size), excluding the first and last rows when there are at least three and counting empty rows as zero, divided by total profile volume / number of occupied profile rows; each chart bar distributes its volume evenly across rows from floor(low / profile row size) through floor(high / profile row size); undefined if profile total is zero or the gap midpoint row is outside the occupied row range.
Calculation: LVN-confirmed FVG(top, bottom) = volume-profile filter disabled OR (Relative gap volume(top, bottom) is defined AND Relative gap volume(top, bottom) <= LVN threshold parameter).
Long: For each enabled T in T1–T5 whose duration is at least the chart timeframe, on a chart bar when T begins, low(T, last completed bar) > high(T, three bars before the current T bar) AND low(T, last completed bar) - high(T, three bars before the current T bar) >= minimum-gap parameter * ATR(lookback, T, last completed bar) AND LVN-confirmed FVG(low(T, last completed bar), high(T, three bars before the current T bar)).
Long: For each enabled T in T1–T5 whose duration is at least the chart timeframe, on a chart bar when T begins, iFVG alerts are enabled AND close(T, last completed bar) > the top of a previously stored, active bearish FVG zone formed on T by high(T, last completed bar at formation) < low(T, three bars before the current T bar at formation) with gap size >= minimum-gap parameter * ATR(lookback, T, last completed bar at formation) AND (the zone was LVN-confirmed when formed OR storage of unconfirmed FVGs is enabled) AND (iFVG source is all FVGs OR the zone was LVN-confirmed when formed) AND the zone remains among the maximum-stored-zones parameter for T.
