Calculation: Cumulative min-max(x) = (x − running minimum(x)) / (running maximum(x) − running minimum(x)), or 0.5 when the range is zero.
Calculation: Feature vector = up to six separately configured features, each with its own type, lookbacks, and weight: EMA(RSI(source, lookback), smoothing lookback) / 100; cumulative min-max(WaveTrend(hlc3, lookback, smoothing lookback) − its signal line); cumulative min-max(EMA(CCI(source, lookback), smoothing lookback)); ADX(lookback, same lookback) / 100; MFI(hlc3, lookback) / 100; or normalized Fisher Transform(hl2, lookback).
Calculation: ANN prediction = for each labeled historical feature vector in the recent training window, sampled at the configured chronological spacing, calculate the configured weighted feature distance using the selected Lorentzian, Manhattan, Euclidean, or hybrid metric; vote with its label using weight 1 / (1 + distance) when distance weighting is enabled, otherwise equal weight. Labels are long when the source's move over the prediction horizon exceeds the neutral-zone width times ATR at the sample bar, short when it is below the negative threshold, and neutral otherwise. Sum the weighted votes, or equal votes when weighting is disabled; when distance weighting is enabled, divide by the sum of weights and multiply by K. K is the configured base K or its volatility-scaled value, floored at the configured minimum K; volatility scaling uses the percentile rank of the recent ATR. Each feature's distance contribution is multiplied by its feature weight; Euclidean distance takes the square root of the weighted sum of squared differences.
Calculation: ANN confidence = 100 × absolute value of the sum of weighted historical labels divided by the sum of vote weights; use equal vote weights when distance weighting is disabled.
Calculation: Model signal = long when ANN prediction > 0, ANN confidence meets its minimum threshold, and every enabled volatility, regime, and ADX filter passes; short when ANN prediction < 0 and the same gates pass; otherwise retain the previous model signal, initially neutral. The volatility filter compares recent ATR with longer-lookback ATR; the regime filter requires absolute EMA separation (shorter versus longer lookback) divided by ATR to exceed its threshold; the ADX filter requires ADX to exceed its threshold.
Calculation: Rational-quadratic kernel estimate = Nadaraya-Watson weighted average of the configured source on chart bars, with weight (1 + i² / (2 × relative weight × lookback²))^(−relative weight) for each current or prior bar i in the capped regression-level and lookback span.
Calculation: Gaussian kernel estimate = Nadaraya-Watson weighted average of the configured source on chart bars, with weight exp(−i² / (2 × lookback²)); its lookback is the rational-quadratic lookback minus the configured lag, floored at the minimum kernel lookback, and it uses the same regression-level span.
Calculation: Long ATR trail = entry close − ATR(trailing-stop lookback) × trailing-stop multiplier; while long, update to the greater of the prior trail and close − ATR(trailing-stop lookback) × trailing-stop multiplier.
Calculation: Short ATR trail = entry close + ATR(trailing-stop lookback) × trailing-stop multiplier; while short, update to the lesser of the prior trail and close + ATR(trailing-stop lookback) × trailing-stop multiplier.
