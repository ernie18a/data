Calculation: SelectedFastEMA = EMA(close, primary fast EMA lookback, T1, current forming T1 bar), or EMA(close, fallback fast EMA lookback, T1, current forming T1 bar) when fallback is enabled and the primary EMA is unavailable; use the T1 value on chart bars
Calculation: SelectedSlowEMA = EMA(close, primary slow EMA lookback, T1, current forming T1 bar), or EMA(close, fallback slow EMA lookback, T1, current forming T1 bar) when fallback is enabled and the primary EMA is unavailable; use the T1 value on chart bars
Calculation: RSIComponent = clamp((overbought RSI level - RSI(close, RSI lookback, T1, current forming T1 bar)) / (overbought RSI level - oversold RSI level) × score maximum, zero, score maximum)
Calculation: TrendComponent = when both selected EMAs are available, (SelectedFastEMA > SelectedSlowEMA ? fast-above-slow trend points : zero) + (chart close > SelectedSlowEMA ? above-slow trend points : zero) + (SelectedSlowEMA > SelectedSlowEMA[slow EMA slope lookback in T1 bars] ? rising-slow trend points : zero), with zero rising-slow points when the lagged EMA is unavailable; otherwise unavailable
Calculation: FastPercentDistance = (chart close - SelectedFastEMA) / SelectedFastEMA × 100%
Calculation: SlowPercentDistance = (chart close - SelectedSlowEMA) / SelectedSlowEMA × 100%
Calculation: FastSupport = when SelectedFastEMA is available, max(zero, if FastPercentDistance >= zero then score maximum - FastPercentDistance / fast above-line zero-score distance × score maximum else score maximum + FastPercentDistance / fast below-line zero-score distance × score maximum); otherwise zero
Calculation: SlowSupport = when SelectedSlowEMA is available, max(zero, if SlowPercentDistance >= zero then score maximum - SlowPercentDistance / slow above-line zero-score distance × score maximum else score maximum + SlowPercentDistance / slow below-line zero-score distance × score maximum) × slow support cap / score maximum; otherwise zero
Calculation: SupportComponent = unavailable if neither selected EMA is available; otherwise max(FastSupport, SlowSupport), capped at the not-uptrend support cap when both EMAs are available and SelectedFastEMA <= SelectedSlowEMA
Calculation: BuyScore = (RSIComponent × RSI weight + TrendComponent × trend weight + SupportComponent × support weight) / the sum of weights for available components, when that sum is positive; otherwise unavailable
Long: BuyScore crosses above the alert threshold on chart bars
