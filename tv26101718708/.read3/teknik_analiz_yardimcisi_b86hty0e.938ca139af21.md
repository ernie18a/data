Calculation: OBV MACD state = bullish when the filtered value rises, bearish when it falls, otherwise the prior state (initially neutral); filtered value equals the raw value when it exceeds the prior filtered value plus the threshold or falls below the prior filtered value minus the threshold, otherwise it equals the prior filtered value (use the raw value as prior filtered value when none exists); threshold = cumulative sum of absolute differences between raw value and prior filtered value (use raw value when none exists) divided by max(number of bars preceding the current bar, 1); raw value = DEMA(synthetic price, shorter OBV DEMA lookback) - EMA(close, longer OBV EMA lookback); synthetic price = high plus offset when offset > 0, otherwise low plus offset; offset = 0 when SD(OBV(close, volume) - SMA(OBV(close, volume), OBV smoothing lookback), OBV spread lookback) = 0, otherwise [OBV(close, volume) - SMA(OBV(close, volume), OBV smoothing lookback)] / SD(OBV(close, volume) - SMA(OBV(close, volume), OBV smoothing lookback), OBV spread lookback) * SD(high - low, OBV spread lookback); OBV(close, volume) = cumulative sum of sign(change(close)) * volume.
Calculation: net signal balance = sum of four EMA votes (+1 when close is above each corresponding EMA, otherwise -1), RSI vote (+1 when RSI(close, RSI lookback) <= oversold threshold, -1 when RSI(close, RSI lookback) >= overbought threshold, otherwise 0), Bollinger vote (+1 when close <= lower Bollinger Band(close, Bollinger lookback, deviation multiplier), -1 when close >= upper Bollinger Band(close, Bollinger lookback, deviation multiplier), otherwise 0), VWAP vote (+1 when close > VWAP(close), otherwise -1), Supertrend vote (+1 when Supertrend(ATR lookback, ATR multiplier) is bullish, otherwise -1), and OBV MACD vote (+1 when OBV MACD state is bullish, otherwise -1).
Long: close > EMA(close, shortest signal EMA lookback) OR close > EMA(close, second-shortest signal EMA lookback) OR close > EMA(close, second-longest signal EMA lookback) OR close > EMA(close, longest signal EMA lookback) OR RSI(close, RSI lookback) <= oversold threshold OR close <= lower Bollinger Band(close, Bollinger lookback, deviation multiplier) OR close > VWAP(close) OR Supertrend(ATR lookback, ATR multiplier) is bullish OR OBV MACD state is bullish OR net signal balance >= 1
Short: close <= EMA(close, shortest signal EMA lookback) OR close <= EMA(close, second-shortest signal EMA lookback) OR close <= EMA(close, second-longest signal EMA lookback) OR close <= EMA(close, longest signal EMA lookback) OR RSI(close, RSI lookback) >= overbought threshold OR close >= upper Bollinger Band(close, Bollinger lookback, deviation multiplier) OR close <= VWAP(close) OR Supertrend(ATR lookback, ATR multiplier) is bearish OR OBV MACD state is not bullish OR net signal balance <= -1
