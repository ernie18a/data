Calculation: Renko(high, low, open, close, box size) = on each bar, set up-trigger, down-trigger, flip-up, and flip-down flags false; if boundaries are unset, set the lower boundary to floor(close / box size) * box size, the upper boundary one box higher, and direction up when close >= open, otherwise down; if direction is up and low <= lower boundary - box size, step down once, set direction down, down-trigger, and flip-down, then step down while low <= lower boundary - box size; otherwise step up while high >= upper boundary + box size, setting up-trigger; if direction is down and high >= upper boundary + box size, step up once, set direction up, up-trigger, and flip-up, then step up while high >= upper boundary + box size; otherwise step down while low <= lower boundary - box size, setting down-trigger; each step moves both boundaries one box in its direction.
Calculation: Active Renko = Renko(high, low, open, close, micro box size) when the micro source is selected; otherwise Renko(high, low, open, close, macro box size).
Long: Active Renko up-trigger AND (change-only mode disabled OR Active Renko flip-up).
Short: Active Renko down-trigger AND (change-only mode disabled OR Active Renko flip-down).
