Calculation: HTF bullish = on chart bars, current (still-forming in realtime) T1 bar close > EMA(close, HTF lookback) from that T1 bar, using lookahead-off values
Calculation: HTF bearish = on chart bars, current (still-forming in realtime) T1 bar close < EMA(close, HTF lookback) from that T1 bar, using lookahead-off values
