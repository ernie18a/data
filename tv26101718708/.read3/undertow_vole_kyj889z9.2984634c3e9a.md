Calculation: Engine OHLC = chart-bar OHLC or standard Heikin-Ashi OHLC, according to a candle-source parameter; calculation volume = chart volume when available, otherwise chart high − low.
Calculation: Expansion index = prior expansion index × (1 + return) when current calculation volume is greater than prior-bar calculation volume, otherwise prior expansion index; initialize at 1, with return = 0 when prior engine close is missing or zero, else current engine close / prior engine close − 1.
Calculation: Contraction index = prior contraction index × (1 + return) when current calculation volume is less than prior-bar calculation volume, otherwise prior contraction index; initialize at 1, with return = 0 when prior engine close is missing or zero, else current engine close / prior engine close − 1.
Calculation: Expansion oscillator = (expansion index − EMA(expansion index, volume-index smoothing lookback)) × 100 / (highest(EMA(expansion index, volume-index smoothing lookback), volume-index range lookback) − lowest(EMA(expansion index, volume-index smoothing lookback), volume-index range lookback)); use 0 when the denominator is zero.
Calculation: Quiet oscillator = (contraction index − EMA(contraction index, volume-index smoothing lookback)) × 100 / (highest(EMA(contraction index, volume-index smoothing lookback), volume-index range lookback) − lowest(EMA(contraction index, volume-index smoothing lookback), volume-index range lookback)); use 0 when the denominator is zero.
Calculation: Centered band position = (engine close − SMA(engine close, band lookback)) × 100 / (2 × band-width parameter × standard deviation(engine close, band lookback)); use 0 when the denominator is zero.
Calculation: Trend blend = (RSI(engine close, shared RSI/MFI lookback) + MFI(engine close, shared RSI/MFI lookback; use 50 when unavailable) + centered band position + Stochastic(engine close, engine high, engine low, stochastic lookback, stochastic smoothing lookback; use raw %K 50 when highest(engine high, stochastic lookback) equals lowest(engine low, stochastic lookback))) / 2, with the stochastic value divided by 3 before summing.
Calculation: Crowd reading = trend blend + expansion oscillator.
Long: quiet oscillator crosses above EMA(trend blend, trend-average lookback) AND quiet oscillator > 0 AND crowd reading < 0 AND (candle filter disabled OR engine close > engine open) AND (position guard disabled OR the last guard-accepted filtered event was short or none; a filtered short resets the guard even when short tracking is disabled) AND long tracking enabled AND (intrabar mode OR current chart bar is confirmed).
Short: quiet oscillator crosses below 0 AND crowd reading > trend blend AND crowd reading > EMA(trend blend, trend-average lookback) AND (strength filter disabled OR quiet oscillator < EMA(trend blend, trend-average lookback)) AND (candle filter disabled OR engine close < engine open) AND (position guard disabled OR the last guard-accepted filtered event was long or none; a filtered long resets the guard even when long tracking is disabled) AND short tracking enabled AND (intrabar mode OR current chart bar is confirmed).
