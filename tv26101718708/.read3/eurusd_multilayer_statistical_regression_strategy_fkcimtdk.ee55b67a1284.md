Calculation: Regression stats(L) = on chart bars, for each non-na close[i] with i from 0 through L−1, set x=i+1 and y=close[i]; with n valid samples, slope=(nΣxy−ΣxΣy)/(nΣx²−(Σx)²), or zero if its denominator is zero; correlation=(nΣxy−ΣxΣy)/sqrt((nΣx²−(Σx)²)(nΣy²−(Σy)²)), or zero if its denominator is zero; R²=correlation². Return na for slope, correlation, and R² when n < max(minimum valid sample count, minimum valid fraction × L). Use separate short-, medium-, and long-lookback parameters, ordered short < medium < long.
Calculation: Adaptive R² threshold = when adaptive thresholds are enabled and chart-bar index ≥ adaptation lookback, the nearest-rank adaptive percentile of the most recent adaptation-lookback valid short-lookback R² values if their count > percentile sample threshold, clamped between adaptive R² floor and ceiling; otherwise use the minimum R² threshold.
Calculation: Primary significance(L) = R²(L) ≥ adaptive R² threshold AND abs(correlation(L)) ≥ minimum correlation AND abs(slope(L)) ≥ minimum slope.
Calculation: Fallback significance(L) = for the short lookback, R²(L) ≥ short fallback R² threshold AND abs(correlation(L)) ≥ short fallback correlation threshold; for medium and long lookbacks, R²(L) ≥ medium/long fallback R² threshold AND abs(correlation(L)) ≥ medium/long fallback correlation threshold.
Calculation: Layer quality(L) = R²(L) × quality R² coefficient + abs(correlation(L)) × quality correlation coefficient + min(quality slope cap, abs(slope(L)) × quality slope scale) × quality slope coefficient.
Calculation: Layer signal(L) = if Primary significance(L), 1 when slope(L)>0 and −1 otherwise; else if Fallback significance(L), (1 when slope(L)>0 and −1 otherwise) × fallback signal scale × Layer quality(L); else if slope(L) is not na and Layer quality(L)>weak-signal quality floor, (1 when slope(L)>0 and −1 otherwise) × weak signal scale × Layer quality(L); otherwise zero.
Calculation: Layer weights = if dynamic weighting is enabled, chart-bar index ≥ dynamic-weight warmup, and total layer quality >0, normalize for each layer (dynamic blend × its quality / total layer quality + (1−dynamic blend) × its base weight); otherwise use the separate short-, medium-, and long-layer base weights.
Calculation: Weighted signal score = short-lookback layer signal × short-layer weight + medium-lookback layer signal × medium-layer weight + long-lookback layer signal × long-layer weight.
Calculation: Prediction accuracy and short-layer reliability = after chart-bar index ≥ validation lookback + prediction horizon, compute actual return=(close−close[prediction horizon])/close[prediction horizon]; replace each layer slope[prediction horizon] that is na with zero; compute ensemble error=abs(actual return−prediction horizon × the sum of each such lagged slope × its current layer weight), and short error=abs(actual return−prediction horizon × lagged short slope); retain each error and max(accuracy floor, accuracy ceiling−ensemble error × accuracy error scale) over the validation lookback, dropping older observations. Prediction accuracy is the mean retained score if its count > validation sample threshold, otherwise the validation fallback value. Short-layer reliability is 1−mean retained short error if its count > validation sample threshold, otherwise the validation fallback value.
Calculation: Confidence = (agreement coefficient × abs(sum of layer signals whose absolute value exceeds the signal inclusion threshold) / their count, or zero if none, + statistical coefficient × the sum of each layer R² × its current layer weight + validation coefficient × prediction accuracy) × min(reliability cap, short-layer reliability + reliability bonus).
Calculation: Long active stop = max(entry price−initial risk distance, high−trailing ATR multiple × ATR(ATR lookback) if high−entry price ≥ trail activation multiple × initial risk distance, otherwise entry price−initial risk distance).
Calculation: Short active stop = min(entry price+initial risk distance, low+trailing ATR multiple × ATR(ATR lookback) if entry price−low ≥ trail activation multiple × initial risk distance, otherwise entry price+initial risk distance).
Calculation: Initial risk distance = initial stop ATR multiple × ATR(ATR lookback), using the current chart bar.
Calculation: T1-start equity = account equity on the first chart bar of each T1 period.
