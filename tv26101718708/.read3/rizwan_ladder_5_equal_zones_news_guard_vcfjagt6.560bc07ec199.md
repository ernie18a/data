Calculation: Zone half-width = max(ATR(ATR length) on T1 bars using the still-forming bar, sampled on chart bars * zone-thickness parameter / width divisor, minimum-tick parameter * tick-floor multiple)
Calculation: Quarter-range = (highest(high, range lookback) on daily bars using the still-forming bar, sampled on chart bars - lowest(low, range lookback) on daily bars using the still-forming bar, sampled on chart bars) / range-division count
Long: close is between lowest(low, range lookback) on daily bars using the still-forming bar, sampled on chart bars - zone half-width and lowest(low, range lookback) on daily bars using the still-forming bar, sampled on chart bars + zone half-width, inclusive OR close is between lowest(low, range lookback) on daily bars using the still-forming bar, sampled on chart bars + quarter-range - zone half-width and lowest(low, range lookback) on daily bars using the still-forming bar, sampled on chart bars + quarter-range + zone half-width, inclusive
Short: close is between highest(high, range lookback) on daily bars using the still-forming bar, sampled on chart bars - quarter-range - zone half-width and highest(high, range lookback) on daily bars using the still-forming bar, sampled on chart bars - quarter-range + zone half-width, inclusive OR close is between highest(high, range lookback) on daily bars using the still-forming bar, sampled on chart bars - zone half-width and highest(high, range lookback) on daily bars using the still-forming bar, sampled on chart bars + zone half-width, inclusive
