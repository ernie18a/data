Long: On chart bars within a configured session, the first breakout of that session occurs when close > the current session MA AND close[1] <= the current session MA; or, if close confirmation is disabled, when high > the current session MA AND high[1] <= the current session MA. The session MA is the configured SMA, EMA, WMA, or VWMA of close over the shared lookback parameter, evaluated on chart bars.
Short: On chart bars within a configured session, the first breakout of that session occurs when close < the current session MA AND close[1] >= the current session MA; or, if close confirmation is disabled, when low < the current session MA AND low[1] >= the current session MA. The session MA is the configured SMA, EMA, WMA, or VWMA of close over the shared lookback parameter, evaluated on chart bars.
Long: After a downward breakout in a configured session, at least the fakeout-wait parameter number of chart bars later, close > the current session MA.
Short: After an upward breakout in a configured session, at least the fakeout-wait parameter number of chart bars later, close < the current session MA.
