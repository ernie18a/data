Calculation: Cloud top = max(Senkou Span A(shorter lookback, longer lookback)[displacement], Senkou Span B(longest lookback)[displacement])
Calculation: Cloud bottom = min(Senkou Span A(shorter lookback, longer lookback)[displacement], Senkou Span B(longest lookback)[displacement])
Calculation: Price-cloud state = 1 when close > Cloud top, -1 when close < Cloud bottom, otherwise 0
Calculation: Future-cloud state = 1 when Senkou Span A(shorter lookback, longer lookback) > Senkou Span B(longest lookback), -1 when Senkou Span A(shorter lookback, longer lookback) < Senkou Span B(longest lookback), otherwise 0
Calculation: Tenkan-Kijun state = 1 when Tenkan-sen(shorter lookback) > Kijun-sen(longer lookback), -1 when Tenkan-sen(shorter lookback) < Kijun-sen(longer lookback), otherwise 0
Calculation: Chikou state = 1 when close > max(open[displacement], close[displacement]) AND close > Cloud top[displacement], -1 when close < min(open[displacement], close[displacement]) AND close < Cloud bottom[displacement], otherwise 0
Calculation: Chart-timeframe score = Price-cloud state + Future-cloud state + Tenkan-Kijun state + Chikou state, computed on chart bars
Calculation: T1 score = Price-cloud state + Future-cloud state + Tenkan-Kijun state + Chikou state, computed on T1 bars and sampled from the last completed T1 bar on chart bars
Calculation: Long breakout setup = breakout enabled AND longs permitted by the direction setting AND T1 score >= trend score threshold AND Chart-timeframe score >= breakout score threshold AND close[1] >= Cloud bottom[1] AND close[1] <= Cloud top[1] AND close > Cloud top
Calculation: Short breakout setup = breakout enabled AND shorts permitted by the direction setting AND T1 score <= -trend score threshold AND Chart-timeframe score <= -breakout score threshold AND close[1] <= Cloud top[1] AND close[1] >= Cloud bottom[1] AND close < Cloud bottom
Calculation: Long checklist setup = checklist enabled AND longs permitted by the direction setting AND T1 score >= trend score threshold AND Price-cloud state = 1 AND Future-cloud state = 1 AND Tenkan-Kijun state = 1 AND Chikou state = 1
Calculation: Short checklist setup = checklist enabled AND shorts permitted by the direction setting AND T1 score <= -trend score threshold AND Price-cloud state = -1 AND Future-cloud state = -1 AND Tenkan-Kijun state = -1 AND Chikou state = -1
Calculation: Long Kijun setup = Kijun setup enabled AND longs permitted by the direction setting AND T1 score >= trend score threshold AND Chart-timeframe score >= trend score threshold AND Price-cloud state = 1 AND Future-cloud state = 1 AND low <= Kijun-sen(longer lookback) AND close > Kijun-sen(longer lookback) AND close > open AND close[1] > Kijun-sen(longer lookback)[1]
Calculation: Short Kijun setup = Kijun setup enabled AND shorts permitted by the direction setting AND T1 score <= -trend score threshold AND Chart-timeframe score <= -trend score threshold AND Price-cloud state = -1 AND Future-cloud state = -1 AND high >= Kijun-sen(longer lookback) AND close < Kijun-sen(longer lookback) AND close < open AND close[1] < Kijun-sen(longer lookback)[1]
Long: (Long breakout setup AND NOT Long breakout setup[1]) OR (Long checklist setup AND NOT Long checklist setup[1]) OR (Long Kijun setup AND NOT Long Kijun setup[1])
Short: (Short breakout setup AND NOT Short breakout setup[1]) OR (Short checklist setup AND NOT Short checklist setup[1]) OR (Short Kijun setup AND NOT Short Kijun setup[1])
Exit: Long, Tenkan-sen(shorter lookback) crosses below Kijun-sen(longer lookback) OR close < Kijun-sen(longer lookback) OR close <= Cloud top
Exit: Short, Tenkan-sen(shorter lookback) crosses above Kijun-sen(longer lookback) OR close > Kijun-sen(longer lookback) OR close >= Cloud bottom
