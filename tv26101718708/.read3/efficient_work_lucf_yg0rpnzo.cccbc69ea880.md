Calculation: Work efficiency = (high - min(open, nz(close[1], close)) + max(open, nz(close[1])) - low) == 0 ? 0 : (close - nz(close[1], open)) / (high - min(open, nz(close[1], close)) + max(open, nz(close[1])) - low)
Calculation: Chart signal = selected SMA, EMA, WMA, VWMA, ALMA(work efficiency, signal lookback, offset parameter, sigma parameter), linear regression(work efficiency, signal lookback, offset parameter), or HMA of work efficiency on chart bars; on real-time bars use the prior chart-bar value when chart-timeframe repainting is disabled, otherwise use the current chart-bar value
Calculation: T1 signal = work efficiency calculated on T1 bars and sampled on chart bars from the forming T1 bar when higher-timeframe repainting is enabled, otherwise from the last completed T1 bar
Calculation: T2 signal = work efficiency calculated on T2 bars and sampled on chart bars from the forming T2 bar when higher-timeframe repainting is enabled, otherwise from the last completed T2 bar
Calculation: Aggregate signal = (chart signal * chart weight + (T1 available ? T1 signal * T1 weight : 0) + (T2 available ? T2 signal * T2 weight : 0)) / (chart weight + (T1 available ? T1 weight : 0) + (T2 available ? T2 weight : 0))
Calculation: Main line = selected aggregate signal, chart signal, T1 signal, or T2 signal; unavailable when the line source is None
Calculation: Divergence level = main line on the latest chart bar where sign(close - open) differs from sign(main line - main line[1]); retain the prior level otherwise
Long: (main-line coloring has at least one condition enabled, every enabled condition is bullish, and the volatility filter passes; the bullish conditions are main line > centerline, main line > highest(main line, channel lookback)[1], main line > divergence level, main line > T1 signal, main line > T2 signal, chart signal > T1 signal, chart signal > T2 signal, T1 signal > centerline, and T2 signal > centerline; the filter passes when set to all, or to high volatility with ATR(short-term lookback) > ATR(long-term lookback), or to low volatility with ATR(short-term lookback) <= ATR(long-term lookback)) OR (the background mode selects one of those nine conditions and it is bullish)
Short: (main-line coloring has at least one condition enabled, every enabled condition is bearish, and the volatility filter passes; the bearish conditions are main line < centerline, main line < lowest(main line, channel lookback)[1], main line < divergence level, main line < T1 signal, main line < T2 signal, chart signal < T1 signal, chart signal < T2 signal, T1 signal < centerline, and T2 signal < centerline; the filter passes when set to all, or to high volatility with ATR(short-term lookback) > ATR(long-term lookback), or to low volatility with ATR(short-term lookback) <= ATR(long-term lookback)) OR (the background mode selects one of those nine conditions and it is bearish)
