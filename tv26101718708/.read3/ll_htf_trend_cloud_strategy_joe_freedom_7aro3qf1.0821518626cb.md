Calculation: ATR offset = ATR factor × EMA(True Range, shortest lookback, T1 bars; values sampled on chart bars from the current T1 bar, which may still be forming)
Calculation: HTF trend state = 1 when close(T1 bars; values sampled on chart bars from the current T1 bar, which may still be forming) > EMA(close, second-shortest lookback, T1 bars; values sampled on chart bars from the current T1 bar, which may still be forming) + ATR offset; -1 when that close < that EMA - ATR offset; otherwise the previous state, initialized to 0
Calculation: Cloud boundary = EMA(close, second-shortest lookback, T1 bars; values sampled on chart bars from the current T1 bar, which may still be forming) - ATR offset when HTF trend state = 1; EMA(close, second-shortest lookback, T1 bars; values sampled on chart bars from the current T1 bar, which may still be forming) + ATR offset when HTF trend state = -1
Long: HTF trend state = 1
Short: HTF trend state != 1
Long: HTF trend state = 1 AND previous HTF trend state = -1 AND bullish entry signals are enabled AND (trend alignment is not required OR (EMA(close, shortest lookback, T1 bars; values sampled on chart bars from the current T1 bar, which may still be forming) > EMA(close, second-shortest lookback, T1 bars; values sampled on chart bars from the current T1 bar, which may still be forming) > EMA(close, third-shortest lookback, T1 bars; values sampled on chart bars from the current T1 bar, which may still be forming) > EMA(close, longest lookback, T1 bars; values sampled on chart bars from the current T1 bar, which may still be forming) AND close(T1 bars; values sampled on chart bars from the current T1 bar, which may still be forming) >= EMA(close, second-shortest lookback, T1 bars; values sampled on chart bars from the current T1 bar, which may still be forming)))
Short: HTF trend state = -1 AND previous HTF trend state = 1 AND bearish entry signals are enabled AND (trend alignment is not required OR (EMA(close, shortest lookback, T1 bars; values sampled on chart bars from the current T1 bar, which may still be forming) < EMA(close, second-shortest lookback, T1 bars; values sampled on chart bars from the current T1 bar, which may still be forming) < EMA(close, third-shortest lookback, T1 bars; values sampled on chart bars from the current T1 bar, which may still be forming) < EMA(close, longest lookback, T1 bars; values sampled on chart bars from the current T1 bar, which may still be forming) AND close(T1 bars; values sampled on chart bars from the current T1 bar, which may still be forming) <= EMA(close, second-shortest lookback, T1 bars; values sampled on chart bars from the current T1 bar, which may still be forming)))
Exit: Long, close < Cloud boundary AND HTF trend state = 1 OR stop-loss/take-profit is enabled AND (low <= average entry price × (1 - stop-loss percentage) OR high >= average entry price × (1 + take-profit percentage))
Exit: Short, close > Cloud boundary AND HTF trend state = -1 OR stop-loss/take-profit is enabled AND (high >= average entry price × (1 + stop-loss percentage) OR low <= average entry price × (1 - take-profit percentage))
