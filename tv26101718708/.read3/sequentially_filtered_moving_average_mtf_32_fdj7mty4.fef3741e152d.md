Calculation: Sequentially filtered SMA(source, lookback) = SMA(source, lookback) when all of its last lookback one-bar changes are strictly positive or all strictly negative; otherwise its prior value, or the current SMA if it has no prior value
Calculation: Retained direction(filtered SMA on T) = up if its current value exceeds its previous T-bar value, down if it is lower, otherwise its prior retained direction (initially neutral)
Long: On chart bars using values calculated on T1 bars, (persistent neutral disabled AND Sequentially filtered SMA(source parameter 1, lookback parameter 1) at the still-forming T1 bar > its value at the previous T1 bar) OR (persistent neutral enabled AND not inverted AND retained direction of that SMA on T1 = up) OR (persistent neutral enabled AND inverted AND (its current value > its previous T1-bar value OR (its current value = its previous T1-bar value AND retained direction of that SMA on T1 = down)))
Short: On chart bars using values calculated on T1 bars, (persistent neutral disabled AND Sequentially filtered SMA(source parameter 1, lookback parameter 1) at the still-forming T1 bar < its value at the previous T1 bar) OR (persistent neutral enabled AND not inverted AND retained direction of that SMA on T1 = down) OR (persistent neutral enabled AND inverted AND (its current value < its previous T1-bar value OR (its current value = its previous T1-bar value AND retained direction of that SMA on T1 = up)))
