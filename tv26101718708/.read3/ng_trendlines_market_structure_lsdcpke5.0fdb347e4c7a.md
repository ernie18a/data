Calculation: Range high = highest(high, range lookback)
Calculation: Range low = lowest(low, range lookback)
Calculation: Range midpoint = range low + (range high - range low) * midpoint fraction
Calculation: Range tolerance = (range high - range low) * proximity fraction
Calculation: In range = range high and range low are defined AND high <= range high AND low >= range low
Calculation: Current range average volume = sum of volume[1] for in-range bars accumulated since the last range-bound change or breakout divided by their count; if the count is zero, SMA(volume, range lookback)
Calculation: Locked average volume = current range average volume captured on a confirmed bullish or bearish breakout; clear it when either range bound changes and otherwise retain it
Calculation: Bullish raw breakout = close > range high AND close > VWAP(close)
Calculation: Bearish raw breakout = close < range low AND close < VWAP(close)
Calculation: Confirmed bullish breakout = bullish raw breakout[1] AND close > range high AND volume >= current range average volume
Calculation: Confirmed bearish breakout = bearish raw breakout[1] AND close < range low AND volume >= current range average volume
Calculation: Strong breakout volume = locked average volume is defined AND volume > locked average volume * strong-volume multiplier
Calculation: Volume spike = locked average volume is defined AND volume > locked average volume * volume-spike multiplier
Calculation: Bullish rejection = close < range midpoint AND low <= range low + range tolerance AND close > open
Calculation: Bearish rejection = close > range midpoint AND high >= range high - range tolerance AND close < open
Calculation: Long reversal confirmation = pending long reversal[1] AND close > high[1]
Calculation: Short reversal confirmation = pending short reversal[1] AND close < low[1]
Calculation: Pending long reversal = set true when bullish rejection AND close > high[1] AND current range average volume is defined; set false after either reversal confirmation; otherwise retain the prior value
Calculation: Pending short reversal = set true when bearish rejection AND close < low[1] AND current range average volume is defined; set false after either reversal confirmation; otherwise retain the prior value
Calculation: Bullish breakout alert = bullish raw breakout AND strong breakout volume
Calculation: Bearish breakout alert = bearish raw breakout AND strong breakout volume
Calculation: Market-state side = initialize neutral; on each chart bar, if close > EMA(close, short lookback) > EMA(close, medium lookback) > EMA(close, long lookback), set long if confirmed bullish breakout OR (bullish rejection AND close > high[1] AND volume >= current range average volume) OR long reversal confirmation OR in range, otherwise retain the prior side; else if close < EMA(close, short lookback) < EMA(close, medium lookback) < EMA(close, long lookback), set short if confirmed bearish breakout OR (bearish rejection AND close < low[1] AND volume >= current range average volume) OR short reversal confirmation OR in range, otherwise retain the prior side; otherwise set long if confirmed bullish breakout, else short if confirmed bearish breakout, else long if bullish rejection AND volume >= current range average volume, else short if bearish rejection AND volume >= current range average volume, else neutral
Long: market-state side is long OR close > EMA(close, long lookback) OR on chart bars using values computed on the current, possibly still-forming T1 bar, close > EMA(close, shorter bias lookback, T1) + EMA(close, shorter bias lookback, T1) * bias tolerance OR on chart bars using values computed on the current, possibly still-forming T2 bar, close > EMA(close, shorter bias lookback, T2) + EMA(close, shorter bias lookback, T2) * bias tolerance OR on chart bars using values computed on the current, possibly still-forming T3 bar, close > EMA(close, longer bias lookback, T3) + EMA(close, longer bias lookback, T3) * bias tolerance OR on chart bars using values computed on the current, possibly still-forming T4 bar, close > EMA(close, longer bias lookback, T4) + EMA(close, longer bias lookback, T4) * bias tolerance OR bullish breakout alert OR (NOT bullish breakout alert AND NOT bearish breakout alert AND volume spike AND close > open) OR close > open
Short: market-state side is short OR close < EMA(close, long lookback) OR on chart bars using values computed on the current, possibly still-forming T1 bar, close < EMA(close, shorter bias lookback, T1) - EMA(close, shorter bias lookback, T1) * bias tolerance OR on chart bars using values computed on the current, possibly still-forming T2 bar, close < EMA(close, shorter bias lookback, T2) - EMA(close, shorter bias lookback, T2) * bias tolerance OR on chart bars using values computed on the current, possibly still-forming T3 bar, close < EMA(close, longer bias lookback, T3) - EMA(close, longer bias lookback, T3) * bias tolerance OR on chart bars using values computed on the current, possibly still-forming T4 bar, close < EMA(close, longer bias lookback, T4) - EMA(close, longer bias lookback, T4) * bias tolerance OR (NOT bullish breakout alert AND bearish breakout alert) OR (NOT bullish breakout alert AND NOT bearish breakout alert AND volume spike AND close < open) OR close <= open
