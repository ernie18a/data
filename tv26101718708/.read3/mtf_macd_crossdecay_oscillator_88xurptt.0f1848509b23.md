Calculation: MACD-cross freshness(T) = direction of the latest cross between EMA(close, fast lookback) - EMA(close, slow lookback) and EMA(MACD line, signal lookback) (+1 for a cross above, -1 for a cross below), multiplied by exp(-decay rate * T-bars since that cross), or 0 if no cross exists or the exponential is below the freshness floor; calculate on T bars and use the last completed T bar when T is shorter than the chart timeframe, otherwise use the still-forming T bar sampled on chart bars
Calculation: Main score = the EMA over the output lookback of the weighted mean of MACD-cross freshness(T) across all 15 timeframe slots; each enabled slot's effective weight is its separate manual weight multiplied by (T duration / chart duration)^exponent when auto-weighting is enabled, otherwise its manual weight; disabled slots have weight 0; use the raw weighted mean when the output lookback is 1, and 0 when total effective weight is 0
Calculation: Higher-timeframe score = the same weighted mean and output smoothing as the Main score, using only the 10 slots in the higher-timeframe group
Long: Main score > 0 OR Higher-timeframe score > 0
Short: Main score < 0 OR Higher-timeframe score < 0
