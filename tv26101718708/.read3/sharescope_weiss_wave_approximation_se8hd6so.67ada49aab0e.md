Calculation: Reversal-wave state = initialize to 0 on the first bar, with the upper and lower bounds set to that bar's selected up and down prices. On later bars, selected up price is high when the high/low source parameter is enabled, otherwise close; selected down price is low when enabled, otherwise close. Let p be the reversal percentage parameter divided by 100; the downside threshold for extreme x is x/(1+p) when symmetric mode is enabled, otherwise x*(1-p). While the state is 0, update the upper and lower bounds to the maximum upper bound and up price, and minimum lower bound and down price; if up price >= lower bound*(1+p), set state to +1 and the extreme to up price, else if down price <= the downside threshold of the upper bound, set state to -1 and the extreme to down price. While state is +1, update the extreme to the maximum of its previous value and up price; if down price <= the downside threshold of the extreme, set state to -1 and the extreme to down price. While state is -1, update the extreme to the minimum of its previous value and down price; if up price >= extreme*(1+p), set state to +1 and the extreme to up price.
Long: Reversal-wave state >= 0
Short: Reversal-wave state < 0
