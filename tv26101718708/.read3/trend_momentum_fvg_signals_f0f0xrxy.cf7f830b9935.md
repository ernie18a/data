Calculation: Trend-up state = close > EMA(close, macro lookback) AND EMA(close, shorter lookback) > EMA(close, longer lookback), with shorter < longer < macro lookback
Calculation: Trend-down state = close < EMA(close, macro lookback) AND EMA(close, shorter lookback) < EMA(close, longer lookback), with shorter < longer < macro lookback
Calculation: HTF bullish = EMA(close, shorter lookback) calculated on T1 bars and mapped to chart bars with lookahead off (last confirmed T1 value historically; current, possibly forming T1 value in realtime) > EMA(close, longer lookback) calculated the same way
Calculation: HTF bearish = EMA(close, shorter lookback) calculated on T1 bars and mapped to chart bars with lookahead off (last confirmed T1 value historically; current, possibly forming T1 value in realtime) < EMA(close, longer lookback) calculated the same way
Calculation: Bullish RSI divergence = the latest confirmed pivot low in low is lower than the preceding confirmed pivot low AND RSI at the latest pivot is higher than RSI at the preceding pivot; use the same pivot lookback on the left and right, with pivots confirmed after the right lookback
Calculation: Bearish RSI divergence = the latest confirmed pivot high in high is higher than the preceding confirmed pivot high AND RSI at the latest pivot is lower than RSI at the preceding pivot; use the same pivot lookback on the left and right, with pivots confirmed after the right lookback
Calculation: Volume ratio = volume / SMA(volume, volume lookback), or one if that SMA is zero
Calculation: Close z-score = (close - SMA(close, extension lookback)) / standard deviation(close, extension lookback), or zero if that standard deviation is zero

Calculation: Continuation confidence = continuation score / (continuation score + reversal score), expressed as a percentage, or the midpoint percentage when the combined score is zero
Calculation: Reversal confidence = the complement of continuation confidence to one hundred percent
Long: EMA(close, shorter EMA lookback) crosses above EMA(close, longer EMA lookback) AND close > EMA(close, macro EMA lookback) AND continuation confidence >= confidence threshold AND (HTF filter disabled OR HTF bullish)
Short: EMA(close, shorter EMA lookback) crosses below EMA(close, longer EMA lookback) AND close < EMA(close, macro EMA lookback) AND continuation confidence >= confidence threshold AND (HTF filter disabled OR HTF bearish)
Exit: long, trend-up state AND reversal confidence >= confidence threshold AND (Bearish RSI divergence OR RSI(RSI lookback) > upper long-exit RSI threshold OR absolute value of close z-score > extreme z-score threshold)
Exit: short, trend-down state AND reversal confidence >= confidence threshold AND (Bullish RSI divergence OR RSI(RSI lookback) < lower short-exit RSI threshold OR absolute value of close z-score > extreme z-score threshold)
