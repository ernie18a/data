Calculation: CloseLocation = if high = low then midpoint else (close - low) / (high - low)
Calculation: RelativeVolume = volume / median(previous diurnal-lookback volumes from the same time-of-day slot) when diurnal volume is enabled, bars are intraday, and at least the minimum slot-history observations exist; otherwise volume / SMA(volume, rank lookback)[1]; undefined when the selected denominator is not positive
Calculation: Rank2(x, lookback) = 2 × count(x[i] < x, i = 1..lookback) + count(x[i] = x, i = 1..lookback), using prior active bars; undefined unless all lookback values are defined
Calculation: SpreadRank = Rank2((high - low) / ATR(ATR lookback)[1], rank lookback)
Calculation: RelativeVolumeRank = Rank2(RelativeVolume, rank lookback)
Calculation: PriorMove = (close[1] - close[1 + leg lookback]) / ATR(ATR lookback)[1]
Calculation: HTF_EMA_slope = EMA(close, trend lookback, T1, last completed T1 bar) - EMA(close, trend lookback, T1, preceding completed T1 bar), sampled on chart bars
