Calculation: Latest pivot high = most recent non-missing PivotHigh(high, left-lookback parameter, right-lookback parameter) on T1 bars, read on chart bars from the still-forming T1 bar
Calculation: Latest pivot low = most recent non-missing PivotLow(low, left-lookback parameter, right-lookback parameter) on T1 bars, read on chart bars from the still-forming T1 bar
Calculation: Active pivot range = both latest pivots exist; a new pivot confirmation activates the range, and a chart close outside the range from min(latest pivot high, latest pivot low) to max(latest pivot high, latest pivot low) deactivates it until another pivot confirmation
Calculation: Anchored VWAP = cumulative hlc3 × volume since the start of T2 divided by cumulative volume since the start of T2, calculated on chart bars; use hlc3 when cumulative volume is zero
Long: FVGs enabled AND signals enabled AND low > high[2] AND (low - high[2]) / high[2] × 100 >= minimum FVG size parameter AND Active pivot range AND latest pivot high confirmed after latest pivot low AND close >= latest pivot low + (latest pivot high - latest pivot low) × lower retracement parameter AND close <= latest pivot low + (latest pivot high - latest pivot low) × upper retracement parameter AND (VWAP filter disabled OR close > Anchored VWAP)
Short: FVGs enabled AND signals enabled AND high < low[2] AND (low[2] - high) / low[2] × 100 >= minimum FVG size parameter AND Active pivot range AND latest pivot low confirmed after latest pivot high AND close >= latest pivot low + (latest pivot high - latest pivot low) × lower retracement parameter AND close <= latest pivot low + (latest pivot high - latest pivot low) × upper retracement parameter AND (VWAP filter disabled OR close < Anchored VWAP)
