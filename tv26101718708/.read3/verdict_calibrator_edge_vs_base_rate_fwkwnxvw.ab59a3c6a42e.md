Calculation: Breakout direction state = +1 when close > Highest(high, breakout lookback)[1], -1 when close < Lowest(low, breakout lookback)[1], otherwise the prior state; initialize to 0.
Calculation: RSI reversal direction state = +1 when RSI(close, RSI lookback)[1] < oversold level and RSI(close, RSI lookback) >= oversold level, -1 when RSI(close, RSI lookback)[1] > overbought level and RSI(close, RSI lookback) <= overbought level, otherwise the prior state; initialize to 0.
Calculation: Bollinger fade direction state = +1 when close < lower Bollinger Band(close, band lookback, band multiplier), -1 when close > upper Bollinger Band(close, band lookback, band multiplier), otherwise the prior state; initialize to 0.
Calculation: Control value = fractional part of (sin(bar ordinal × hash multiplier) × hash scale).
Calculation: Selected signal direction = for External source mode, use +1 or -1 according to whether the external signal series is rising or falling, above or below its SMA(external signal series, centering lookback), or above or below the fixed signal level, as selected; when the mean is unavailable or the comparison is equal, use 0. For MA cross mode, use +1 when EMA(close, shorter MA lookback) > EMA(close, longer MA lookback), -1 when it is lower, otherwise 0. For MACD cross mode, use +1 when MACD(close, faster MACD lookback, slower MACD lookback, MACD signal lookback) line > its signal line, -1 when it is lower, otherwise 0. For Supertrend flip mode, use +1 in the uptrend and -1 in the downtrend. For RSI 50-cross mode, use +1 when RSI(close, RSI lookback) > RSI midpoint level, -1 when it is lower, otherwise 0. For RSI 30/70 reversal mode, use the RSI reversal direction state. For Stochastic cross mode, compare SMA(Stochastic(close, high, low, %K lookback), %K smoothing) with its SMA(%D lookback): use +1 when the former is greater, -1 when it is lower, otherwise 0. For Breakout mode, use the breakout direction state. For VWAP cross mode, use +1 when close > VWAP(hlc3), -1 when it is lower, otherwise 0. For Bollinger fade mode, use the Bollinger fade direction state. For Random control mode, use +1 when the control value > random threshold, otherwise -1.
Long: Selected signal direction = +1 AND its prior value != +1 AND bars since the previous fire >= minimum-gap parameter.
Short: Selected signal direction = -1 AND its prior value != -1 AND bars since the previous fire >= minimum-gap parameter.
