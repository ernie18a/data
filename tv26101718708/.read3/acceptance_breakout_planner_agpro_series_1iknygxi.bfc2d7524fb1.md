Calculation: Breakout ATR = max(ATR(ATR length), high - low when ATR is unavailable, minimum price increment)
Long: bullish breaks enabled AND both prior reference edges are available AND highest(high[1], reference lookback) > lowest(low[1], reference lookback) AND close > highest(high[1], reference lookback) + break-buffer parameter × Breakout ATR AND (no active sequence OR active sequence age > sequence-expiry parameter OR active sequence is bearish) AND (bar is confirmed in close-confirmed mode OR confirmation mode is live preview)
Short: bearish breaks enabled AND both prior reference edges are available AND highest(high[1], reference lookback) > lowest(low[1], reference lookback) AND close < lowest(low[1], reference lookback) - break-buffer parameter × Breakout ATR AND (no active sequence OR active sequence age > sequence-expiry parameter OR active sequence is bullish) AND (bar is confirmed in close-confirmed mode OR confirmation mode is live preview)
