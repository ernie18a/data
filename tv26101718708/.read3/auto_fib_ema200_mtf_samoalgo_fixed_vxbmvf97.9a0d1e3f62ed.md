Calculation: Swing size = setup pivot high price − setup pivot low price, using the latest confirmed pivots when the setup is activated
Calculation: Long entry level = setup pivot low price + swing size × entry retracement parameter, stored when the setup is activated
Calculation: Short entry level = setup pivot high price − swing size × entry retracement parameter, stored when the setup is activated
Calculation: Long Fibonacci target level = setup pivot low price + swing size × target extension parameter, stored when the setup is activated
Calculation: Short Fibonacci target level = setup pivot high price − swing size × target extension parameter, stored when the setup is activated
Calculation: Long stop price = ATR exit mode ? signal-bar close − ATR(ATR lookback parameter on chart bars) × stop-distance parameter : setup pivot low price − ATR(ATR lookback parameter on chart bars at setup activation) × stop-buffer parameter, stored at the entry signal
Calculation: Short stop price = ATR exit mode ? signal-bar close + ATR(ATR lookback parameter on chart bars) × stop-distance parameter : setup pivot high price + ATR(ATR lookback parameter on chart bars at setup activation) × stop-buffer parameter, stored at the entry signal
Calculation: Long target price = ATR exit mode ? signal-bar close + ATR(ATR lookback parameter on chart bars) × target-distance parameter : fixed R:R target mode ? signal-bar close + (signal-bar close − long stop price) × target R:R parameter : long Fibonacci target level, stored at the entry signal
Calculation: Short target price = ATR exit mode ? signal-bar close − ATR(ATR lookback parameter on chart bars) × target-distance parameter : fixed R:R target mode ? signal-bar close − (short stop price − signal-bar close) × target R:R parameter : short Fibonacci target level, stored at the entry signal
