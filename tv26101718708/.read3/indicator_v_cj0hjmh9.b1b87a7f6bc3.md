Calculation: Bearish engulfing = abs(close - open) >= ATR value * engulfing ATR multiple AND close < open AND close location <= bearish close-location maximum AND close < open[1] AND open > close[1] AND Volume spike, where close location = (close - low) / (high - low) when high > low, otherwise the zero-range close-location fallback

Calculation: T1 low sweep = the previous chart-bar value of the mapped T1 low <= lowest(low, T1 sweep lookback, T1, last completed bar) AND the current mapped T1 close > that lowest value; evaluate on chart bars using the current, possibly forming T1 low and close
Calculation: T1 bias = set bearish on T1 high sweep, then set bullish on T1 low sweep; otherwise retain the prior value

Calculation: Correlated-market low sweep = prior chart-bar correlated-market low <= lowest(correlated-market low, liquidity lookback)[1] AND current correlated-market close > that lowest value
Calculation: Correlated-market alignment = correlation filter enabled AND the corresponding correlated-market sweep

Calculation: T4 bearish FVG midpoint = rounded midpoint of the latest T4 bearish FVG; retain it until another T4 bearish FVG occurs

Calculation: T2 bullish override of T4 bearish FVG = T4 bearish FVG AND T2 bullish FVG AND rounded T2 bullish gap size >= rounded T4 bearish gap size * FVG override size ratio AND abs(last completed T2 low - close) <= FVG override distance

Calculation: Bearish structure flip = Bearish engulfing AND Short structure
Calculation: Long sweep count = reset to zero on a new rolling swing high when the count is positive; increment on each Low sweep and reset the short count; reset to zero on each High sweep
Calculation: Short sweep count = reset to zero on a new rolling swing low when the count is positive; increment on each High sweep and reset the long count; reset to zero on each Low sweep; use highest(high, swing-anchor lookback) and lowest(low, swing-anchor lookback), including the current chart bar, for new swing highs and lows
Calculation: Long confluence score = min(score cap, base score weight * number of true conditions (T1 bias bullish, Enabled-session condition, Volume spike, Correlated-market low sweep with correlation filter enabled, Relative-strength difference positive, T4 bullish FVG AND NOT T2 bearish override of T4 bullish FVG, T2 bullish FVG, Near prior T2 low, Falling volatility index, Long sweep count >= sweep-count threshold, Long structure) + pattern score weight * number of true conditions (Bullish structure flip, Bullish FVG entry))

Calculation: Bearish range break = an active compact range exists AND close < stored range low AND open > stored range low AND abs(close - open) >= ATR value * range-break body multiplier; form and retain the range as for Bullish range break, and deactivate it on either break
Calculation: Structure conflict = (Chart bullish FVG AND High sweep) OR (Chart bearish FVG AND Low sweep)
