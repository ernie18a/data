Calculation: risk ATR = max(ATR(ATR lookback) when available, otherwise true range, minimum tick size).
Calculation: anchored VWAP = cumulative sum of selected price source × volume / cumulative volume through the current chart bar since the latest selected anchor; reset at the first confirmed chart bar if no anchor exists, the first chart bar reaching the selected manual time, the selected T1, T2, or T3 period opening boundary detected on chart bars, a high-volume event where volume / SMA(volume, relative-volume lookback) >= high-volume threshold AND abs(close - open) > risk ATR × body-size threshold AND bars since the prior anchor >= minimum anchor spacing, or a confirmed pivot high or low using the same pivot lookback on each side (pivot high takes precedence if both confirm together).
Calculation: readiness score = round(clamp(base-score parameter + clamp((1 - min(abs(close - anchored VWAP) / risk ATR, extension-risk parameter) / max(extension-risk parameter, distance-floor parameter)) × distance-score weight/cap parameter, 0, distance-score weight/cap parameter) + clamp(relative volume × relative-volume score weight, 0, relative-volume score cap) + clamp(min(bars since anchor, anchor-age normalization lookback) / anchor-age normalization lookback × anchor-age score weight/cap parameter, 0, anchor-age score weight/cap parameter), 0, score ceiling parameter)); relative volume = volume / SMA(volume, relative-volume lookback) when the SMA is positive, otherwise 1.
Long: close crosses above anchored VWAP + risk ATR × reclaim-buffer parameter AND readiness score >= minimum ready score.
Short: close crosses below anchored VWAP - risk ATR × reclaim-buffer parameter AND readiness score >= minimum ready score.
