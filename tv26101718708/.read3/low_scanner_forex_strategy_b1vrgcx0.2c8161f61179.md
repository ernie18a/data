Calculation: T1 sampled close = close of the first chart bar in each T1 period, while that T1 bar is forming, carried forward on subsequent chart bars
Calculation: first lookback = first duration parameter divided by chart-bar duration in minutes times the shared scale parameter on intraday charts, and the shared scale parameter otherwise
Calculation: second lookback = second duration parameter divided by chart-bar duration in minutes times the shared scale parameter on intraday charts, and the shared scale parameter otherwise
Calculation: momentum trigger = negative EMA of RSI(CUM(change(T1 sampled close) × volume), RSI lookback) on the previous chart bar minus WMA of that RSI series with the first lookback on the previous chart bar, using the second lookback; calculated on chart bars
Calculation: weighted composite = WMA(weight parameter × WMA(T2 close, base lookback divided by short divisor) − WMA(T2 close, base lookback divided by medium divisor) − WMA(T2 close, base lookback divided by long divisor), base lookback divided by long divisor); calculated on T2 bars
Long: (momentum trigger crosses above the zero threshold parameter OR Linear Regression(close, regression lookback, offset parameter) crosses above the weighted composite from the shift-selected T2 bar, sampled onto chart bars; positive shifts select completed T2 bars and zero selects the forming T2 bar) AND datetime is within the inclusive start and end datetime parameters
Short: Linear Regression(close, regression lookback, offset parameter) crosses below the weighted composite from the shift-selected T2 bar, sampled onto chart bars; positive shifts select completed T2 bars and zero selects the forming T2 bar
Exit: long, high reaches entry price increased by any of the four separate take-profit percentage parameters OR low reaches entry price decreased by the stop-loss percentage parameter
