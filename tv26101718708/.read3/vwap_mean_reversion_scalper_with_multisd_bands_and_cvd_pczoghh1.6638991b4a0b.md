Calculation: HLC3 = (high + low + close) / 3
Calculation: VWAP SD bands = for each of three separate SD multipliers, upper band = VWAP(HLC3, volume, T1 anchor) + VWAP deviation × multiplier and lower band = VWAP(HLC3, volume, T1 anchor) − VWAP deviation × multiplier, where VWAP deviation = sqrt(max(0, cumulative(volume × HLC3²) / cumulative(volume) − VWAP²)); accumulate chart bars since each T1 boundary, including the current chart bar
Calculation: VWAP touch = low <= VWAP(HLC3, volume, T1 anchor) AND high >= VWAP(HLC3, volume, T1 anchor)
Calculation: Lower touch level = 3 if low <= lower SD band 3, else 2 if low <= lower SD band 2, else 1 if low <= lower SD band 1, else 0 if VWAP touch, else −1
Calculation: Upper touch level = 3 if high >= upper SD band 3, else 2 if high >= upper SD band 2, else 1 if high >= upper SD band 1, else 0 if VWAP touch, else −1
Calculation: Current-bar delta = sum(volume × sign(close − open)) over the available T2 bars inside the current chart bar, including a T2 bar still forming
Long: close > open AND (lower touch level > 0 OR VWAP touch) AND current-bar delta > delta threshold AND (volatility filter disabled OR high − low >= ATR(lookback) × range multiplier) AND (lower touch level > 0 OR (VWAP signals enabled AND VWAP touch)) AND (clean-signal mode disabled OR most recent signal side is not long OR the close has been strictly between SD bands 1 since the most recent signal (initially true) OR lower touch level > level recorded by the most recent signal) AND current chart bar index − most recent signal chart bar index >= cooldown (initial last-signal bar index 0)
