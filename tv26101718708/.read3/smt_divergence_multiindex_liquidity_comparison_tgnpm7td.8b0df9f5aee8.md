Calculation: HighBreakState(m,i,T) = 1 if the current T-bar high of market m exceeds the high at T-bar offset i+1 and every intervening T-bar high is at most that reference high; 0 if it does not exceed the reference high and every intervening T-bar high is at most the reference high; invalid otherwise. Evaluate on chart bars using T-bar values, with the current T bar still forming.
Calculation: LowBreakState(m,i,T) = 1 if the current T-bar low of market m is below the low at T-bar offset i+1 and every intervening T-bar low is at least that reference low; 0 if it is not below the reference low and every intervening T-bar low is at least the reference low; invalid otherwise. Evaluate on chart bars using T-bar values, with the current T bar still forming.
Calculation: Divergence(a,b,c) = true if a, b, and c are all 0 or 1 and are not all equal.
Long: For some j in {1,2,3,4,5} and i in {0,...,Lj−1}, Divergence(LowBreakState(m1,i,Tj), LowBreakState(m2,i,Tj), LowBreakState(m3,i,Tj)); each Tj has its own lookback parameter Lj.
Short: For some j in {1,2,3,4,5} and i in {0,...,Lj−1}, Divergence(HighBreakState(m1,i,Tj), HighBreakState(m2,i,Tj), HighBreakState(m3,i,Tj)); each Tj has its own lookback parameter Lj.
