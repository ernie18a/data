Calculation: FVG chain = bullish FVG when low > high[P1], bearish FVG when high < low[P1]; each FVG span is bars P1 bars ago through current, inclusive. Start a chain with a FVG; append a later FVG only if its direction matches, bars since the prior FVG <= P2, and correction from the pre-append chain range <= P3 (bullish: (chain highest high - current low) / range * 100; bearish: (current high - chain lowest low) / range * 100; correction is 0 if range <= 0). Chain range is highest high minus lowest low over all included FVG spans. Finalize an active chain when a FVG cannot append or, on a bar without a FVG, bars since the prior FVG > P2 or correction > P3; a FVG that cannot append starts a new chain.
Calculation: Intervening block valid = true if no prior impulse was marked or there are no bars between the prior marked impulse end and candidate chain start; otherwise, for a bullish chain, some candidate-chain bar has max(open, close) > the highest high between them, and for a bearish chain, some candidate-chain bar has min(open, close) < the lowest low between them.
Calculation: Minimum impulse size = P4a on chart timeframe T1 and any unmatched chart timeframe, P4b on T2, P4c on T3.
Long: A bullish FVG chain finalizes, its range >= Minimum impulse size, and Intervening block valid.
Short: A bearish FVG chain finalizes, its range >= Minimum impulse size, and Intervening block valid.
