Calculation: MACD line = EMA(close, shorter lookback) - EMA(close, longer lookback)
Calculation: StochRSI K = StochRSI(RSI(close, RSI lookback), stochastic lookback)
Long: Since the previous long signal, a bar has StochRSI K < StochRSI oversold threshold AND SMA(StochRSI K, smoothing lookback) < the same threshold AND, if enabled, MACD line < 0 and strictly decreasing across its consecutive-bar lookback AND, if enabled, ADX(high, low, close, lookback) > ADX threshold; if candle confirmation is enabled, that setup bar must close below its open and the signal is the first later bar closing above its open while the setup remains pending, otherwise the setup bar signals long. Also calculated on chart bars and on each table timeframe T1–T5; chart bars read each still-forming T1–T5 bar for table signals.
Short: Since the previous short signal, a bar has StochRSI K > StochRSI overbought threshold AND SMA(StochRSI K, smoothing lookback) > the same threshold AND, if enabled, MACD line > 0 and strictly increasing across its consecutive-bar lookback AND, if enabled, ADX(high, low, close, lookback) > ADX threshold; if candle confirmation is enabled, that setup bar must close above its open and the signal is the first later bar closing below its open while the setup remains pending, otherwise the setup bar signals short. Also calculated on chart bars and on each table timeframe T1–T5; chart bars read each still-forming T1–T5 bar for table signals.
