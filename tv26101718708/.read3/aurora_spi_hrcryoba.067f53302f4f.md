Calculation: Estimated buy fraction on each completed analysis bar = in BVC mode, standard normal CDF(clamp((close - close[1]) / sample standard deviation of the preceding valid close changes over the volatility lookback, -maximum standardized move, maximum standardized move)) when the current change is valid, at least min(warmup count, volatility lookback) preceding changes exist, and deviation exceeds the minimum-deviation threshold; otherwise 0.5. A valid change requires consecutive in-session bars with a gap no greater than the continuity-gap parameter times the analysis-bar duration. In candle-direction mode, use 1 when close > open, 0 when close < open, and 0.5 when equal. In intrabar-direction mode, use 1 or 0 according to the latest nonzero valid close change, resetting to 0.5 after an invalid change.
Calculation: Profile row volume = sum over analysis bars of volume × max(0, min(high, row top) - max(low, row bottom)) / (high - low); when high = low, assign full volume to its containing row. At each comparison, row boundaries divide the current in-session prefix range from its low to its high into the profile row count, using max(prefix high - prefix low, minimum tick size) as the total range. Use completed T1 bars, processing T1 intrabars when T1 is lower than the chart timeframe and committing them at chart-bar close; otherwise use chart bars. Include only bars in the configured session.
Calculation: Profile row buy volume = sum over the same bars of profile row volume × estimated buy fraction.
Long: On each completed analysis bar, after at least max(minimum session-candle count, 2 × window length, confirmation count) in-session analysis bars, a profile row has current-window volume and preceding-window volume each at least the minimum row-volume percentage of the strongest current-window row, current-window buy volume / current-window volume >= dominant-share parameter, preceding-window buy volume / preceding-window volume <= 1 - dominant-share parameter, and each of the latest confirmation-count analysis bars has positive row volume and row buy volume / row volume >= dominant-share parameter.
Short: On each completed analysis bar, after at least max(minimum session-candle count, 2 × window length, confirmation count) in-session analysis bars, a profile row has current-window volume and preceding-window volume each at least the minimum row-volume percentage of the strongest current-window row, current-window buy volume / current-window volume <= 1 - dominant-share parameter, preceding-window buy volume / preceding-window volume >= dominant-share parameter, and each of the latest confirmation-count analysis bars has positive row volume and row buy volume / row volume <= 1 - dominant-share parameter.
