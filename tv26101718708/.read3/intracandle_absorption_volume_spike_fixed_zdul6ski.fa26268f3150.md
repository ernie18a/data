Calculation: RollingMean(x) = mean of x over lookback T1 bars ending with the current T1 bar, treating unavailable prior values as zero
Long: On chart bars, if any T1 bar being processed, including one still forming, has (volume >= RollingMean(volume) * absorption-volume threshold AND (high - low) <= RollingMean(high - low) * stall-range percentage / 100 AND close >= (high + low) / 2) OR (volume >= RollingMean(volume) * volume-spike threshold AND NOT (volume >= RollingMean(volume) * absorption-volume threshold AND (high - low) <= RollingMean(high - low) * stall-range percentage / 100) AND close > open)
