Calculation: SafeATR = max(ATR(ATR lookback) if available, otherwise high - low, traded instrument minimum price increment)
Calculation: CoilRelease = (highest(high, coil lookback)[previous bar] - lowest(low, coil lookback)[previous bar]) / SafeATR <= coil tightness threshold
Calculation: ImpulseStrength(direction) = clamp(round to score increment(range points: if (high-low)/SafeATR >= range top cutoff then range top points, else if >= range high cutoff then range high points, else if >= range middle cutoff then range middle points, else if >= range low cutoff then range low points, else range floor points; + body points: if abs(close-open)/(high-low) >= body top cutoff then body top points, else if >= body high cutoff then body high points, else if >= body middle cutoff then body middle points, else body floor points; + close-location points: use (close-low)/(high-low) for long and 1-(close-low)/(high-low) for short, then award close top points if >= close top cutoff, close high points if >= close high cutoff, close middle points if >= close middle cutoff, otherwise close floor points; + net-move points: if abs(close-close[run window])/SafeATR >= net-move top cutoff then net-move top points, else if >= net-move high cutoff then net-move high points, else if >= net-move middle cutoff then net-move middle points, else net-move floor points; + consecutive-close points: if consecutive closes in direction >= run top cutoff then run top points, else if >= run middle cutoff then run middle points, else run floor points; + volume points: let v=volume/SMA(volume, volume lookback) when that SMA is positive, otherwise v=1; award volume top points if v >= volume top cutoff, volume high points if >= volume high cutoff, volume middle points if >= volume middle cutoff, volume low points if >= volume low cutoff, otherwise volume floor points; + acceleration points if direction's close-minus-close-at-acceleration-lookback is positive for long or negative for short and is greater for long or less for short than that value on the previous bar; + coil points if CoilRelease; + structure points if close is above the latest confirmed swing high for long or below the latest confirmed swing low for short; + trend points: both EMA and HTF alignment points if both align, otherwise single alignment points if either aligns), clamped between score floor and score ceiling and rounded to score increment. EMA alignment is EMA(close, fast EMA lookback) above its value at the EMA slope lookback for long or below it for short. HTF alignment is true if the HTF filter is disabled or its EMA is unavailable; otherwise compare chart-bar close to EMA(close, HTF EMA lookback, T1, last completed T1 bar), sampled on chart bars, using above for long and below for short. Acceleration lookback, score cutoffs, score points, score floor, score ceiling, and score increment are parameters.
Calculation: LongImpulse = on each chart bar at its close, close > open AND (high-low)/SafeATR >= ignition range threshold AND abs(close-open)/(high-low) >= minimum body ratio AND (close-low)/(high-low) >= close-position threshold AND (structure-break requirement disabled OR a latest confirmed swing high exists and close > it, using the pivot lookback on each side) AND (coil-release requirement disabled OR CoilRelease) AND (volume-thrust requirement disabled OR volume >= SMA(volume, volume lookback) * volume multiplier)
Calculation: ShortImpulse = on each chart bar at its close, close < open AND (high-low)/SafeATR >= ignition range threshold AND abs(close-open)/(high-low) >= minimum body ratio AND 1-(close-low)/(high-low) >= close-position threshold AND (structure-break requirement disabled OR a latest confirmed swing low exists and close < it, using the pivot lookback on each side) AND (coil-release requirement disabled OR CoilRelease) AND (volume-thrust requirement disabled OR volume >= SMA(volume, volume lookback) * volume multiplier)
Calculation: EntryRisk(side) = clamp(abs(entry price - (anchor - side * SafeATR on entry bar * stop buffer)), SafeATR on entry bar * minimum risk floor, SafeATR on entry bar * maximum risk cap), where side is +1 for long and -1 for short; anchor is the entry-bar lowest low over the momentum run window for long or highest high over that window for short when the stop basis is structural, and the entry-bar low for long or high for short when the stop basis is the ignition bar
Calculation: Stop(side) = entry price - side * EntryRisk(side)
Calculation: TP3(side) = entry price + side * EntryRisk(side) * TP3 R multiple
Long: LongImpulse AND ImpulseStrength(long) > 0
Short: ShortImpulse AND ImpulseStrength(short) > 0
Long: LongImpulse AND ImpulseStrength(long) >= minimum strength AND (only-strong filter disabled OR ImpulseStrength(long) >= strong threshold) AND (HTF alignment filter disabled OR HTF EMA unavailable OR chart close > EMA(close, HTF EMA lookback, T1, last completed T1 bar), sampled on chart bars) AND (cooldown disabled OR chart bars since last entry >= cooldown bars) AND no position is active AND no position exited on this bar AND ATR is available
Short: ShortImpulse AND ImpulseStrength(short) >= minimum strength AND (only-strong filter disabled OR ImpulseStrength(short) >= strong threshold) AND (HTF alignment filter disabled OR HTF EMA unavailable OR chart close < EMA(close, HTF EMA lookback, T1, last completed T1 bar), sampled on chart bars) AND (cooldown disabled OR chart bars since last entry >= cooldown bars) AND no position is active AND no position exited on this bar AND ATR is available
Exit: long, low <= Stop(long) OR (high >= TP3(long) AND low > Stop(long))
Exit: short, high >= Stop(short) OR (low <= TP3(short) AND high < Stop(short))
