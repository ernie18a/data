Calculation: normalized OBV = (OBV(volume, close) - rolling lowest OBV over the normalization lookback) / (rolling highest OBV over the normalization lookback - rolling lowest OBV over the normalization lookback) × 100 - 50
Calculation: normalized accumulation/distribution = (EMA(accumulation/distribution line, smoothing lookback) - rolling lowest smoothed line over the normalization lookback) / (rolling highest smoothed line over the normalization lookback - rolling lowest smoothed line over the normalization lookback) × 100 - 50
Calculation: custom volume flow = flow scale × SMA(signed capped volume, flow lookback) × flow lookback / prior-bar SMA(volume, volume-average lookback), where signed capped volume is capped volume if HLC3 - HLC3[1] > cutoff, negative capped volume if HLC3 - HLC3[1] < -cutoff, and zero otherwise; capped volume = min(volume, prior-bar SMA(volume, volume-average lookback) × volume-cap multiplier); cutoff = cutoff multiplier × standard deviation of log(HLC3 / HLC3[1]) over the volatility lookback × close
Calculation: momentum core = momentum weight 1 × custom volume flow + momentum weight 2 × Laguerre RSI(close, gamma) + momentum weight 3 × smoothed Fisher component × Fisher scale + momentum weight 4 × TSI(close, long smoothing lookback, short smoothing lookback) / TSI divisor + momentum weight 5 × (MFI(lookback) - MFI midpoint) / MFI divisor + momentum weight 6 × normalized OBV + momentum weight 7 × normalized accumulation/distribution + momentum weight 8 × CMF(lookback) × CMF scale
Calculation: smoothed momentum = EMA(momentum core, smoothing lookback)
Calculation: momentum signals = bullish when smoothed momentum > 0 and > its prior-bar value; bearish when smoothed momentum < 0 and < its prior-bar value
Calculation: momentum bases = pairwise averages of EMA(Momentum(close, lookback), five ordered lookbacks from shortest to longest), pairing lookbacks 1–2, 2–3, 3–4, 4–5, and 5–1
Calculation: momentum basis average = arithmetic mean of the five momentum bases
Calculation: momentum bands = SMA(momentum basis average, band lookback) plus or minus standard deviation(momentum basis average, band lookback) × band multiplier
Calculation: all-bullish alignment = Momentum(close, momentum lookback) > each of the five momentum bases; all-bearish alignment = Momentum(close, momentum lookback) <= each of the five momentum bases
Calculation: momentum wave signals = bullish when momentum basis 1 > momentum basis 2, momentum basis 1 is rising over the rising/falling lookback, and momentum basis 1 - momentum basis 5 > spread threshold; bearish when momentum basis 1 < momentum basis 2, momentum basis 1 is falling over that lookback, and momentum basis 1 - momentum basis 5 < -spread threshold
Calculation: extreme momentum conditions = bullish when momentum basis 1 and Momentum(close, momentum lookback) are above the upper momentum band and Momentum is above its value at the extreme comparison lag; bearish when both are below the lower band and Momentum is below its value at that lag
Calculation: wave score = +1 if a bullish momentum wave signal or all-bullish alignment; otherwise -1 if a bearish momentum wave signal or all-bearish alignment; otherwise 0
Calculation: bullish order block active = set active and store the high and low from one bar after a confirmed pivot low when close > high at the swing pivot lookback offset; clear when close < stored low; otherwise retain the prior state
Calculation: bearish order block active = set active and store the high and low from one bar after a confirmed pivot high when close < low at the swing pivot lookback offset; clear when close > stored high; otherwise retain the prior state
Calculation: market structure = on each confirmed pivot high, set bullish if it exceeds the prior highest pivot high, otherwise set bearish; on each confirmed pivot low, set bearish if it is below the prior lowest pivot low, otherwise set bullish; process pivot highs before pivot lows and retain the state between pivots
Calculation: bullish structure signal = (bullish order block active or low > high at the gap lookback offset) and bullish market structure and close below the midpoint of the rolling highest high and lowest low over the equilibrium lookback; bearish structure signal = (bearish order block active or high < low at that offset) and bearish market structure and close above that midpoint
Calculation: structure score = +1 for a bullish structure signal, -1 for a bearish structure signal, otherwise 0
Calculation: volume surge = volume > SMA(volume, volume-average lookback) × volume-surge multiplier
Calculation: liquidity signals = bullish when low < the latest confirmed pivot low and volume surge; bearish when high > the latest confirmed pivot high and volume surge
Calculation: liquidity score = +1 for a bullish liquidity signal, -1 for a bearish liquidity signal, otherwise 0
Calculation: trend direction = -1 when close > HLC3 midpoint + trend multiplier × ATR(trend ATR lookback), +1 when close < that midpoint - trend multiplier × ATR(trend ATR lookback), otherwise the prior direction, initially +1
Calculation: trend signals = bullish when Hull Moving Average(close, Hull lookback) is rising over the Hull direction lookback, trend direction = -1, ADX(DMI lookback, DMI smoothing) > ADX threshold, and EMA(close, shortest alignment lookback) > EMA(close, middle alignment lookback) > EMA(close, longest alignment lookback); bearish when the Hull is falling over that lookback, trend direction = +1, ADX exceeds the threshold, and those EMAs descend in order
Calculation: trend score = +1 for a bullish trend signal, -1 for a bearish trend signal, otherwise 0
Calculation: oscillator composite = RSI(close, RSI lookback) - oscillator midpoint + MACD line(close, fast lookback, slow lookback, signal lookback) + TSI(close, long smoothing lookback, short smoothing lookback) + SMA(Stochastic(close, high, low, stochastic lookback), stochastic smoothing lookback) - oscillator midpoint
Calculation: bullish divergence state = on a bar with both a confirmed price pivot low and confirmed RSI pivot low, set true if the price pivot is below its prior pivot low and the RSI pivot is above its prior pivot low; otherwise set false; retain between such bars
Calculation: bearish divergence state = on a bar with both a confirmed price pivot high and confirmed RSI pivot high, set true if the price pivot is above its prior pivot high and the RSI pivot is below its prior pivot high; otherwise set false; retain between such bars
Calculation: oscillator confluence count = on a bullish divergence setup, count the RSI pivot rising from its prior pivot and each of MACD line, TSI, and smoothed Stochastic above its value at the oscillator comparison lag; on a bearish divergence setup, count the RSI pivot falling from its prior pivot and each of those indicators below its value at that lag; retain the prior count otherwise
Calculation: divergence signals = bullish divergence state and oscillator confluence count >= confluence minimum and oscillator composite < -divergence threshold; bearish divergence state and oscillator confluence count >= confluence minimum and oscillator composite > divergence threshold
Calculation: divergence score = +1 for a bullish divergence signal, -1 for a bearish divergence signal, otherwise 0
Calculation: volatility index = arithmetic mean of three percentile values, each calculated as (current value - rolling lowest value) / (rolling highest value - rolling lowest value) × 100: EMA(ATR(ATR lookback), ATR smoothing lookback), Bollinger bandwidth(close, band lookback, band multiplier), and standard deviation(log(close / close[1]), return lookback) × square root of annualization factor × volatility scale; use the percentile lookback for each rolling high and low
Calculation: squeeze state = Bollinger lower band(close, squeeze band lookback, squeeze band multiplier) > EMA(close, channel lookback) - ATR(channel ATR lookback) × channel multiplier and Bollinger upper band < EMA(close, channel lookback) + ATR(channel ATR lookback) × channel multiplier
Calculation: volatility signals = bullish when squeeze state was true one bar ago and is false now, close > close[1], and volatility index < low-volatility threshold; bearish when squeeze state changed the same way, close < close[1], and volatility index < that threshold
Calculation: flow index = (CMF(CMF lookback) × flow CMF scale + MFI(MFI lookback) - flow midpoint + normalized OBV + normalized accumulation/distribution) / flow component count
Calculation: institutional signals = bullish when flow index > institutional flow threshold, CMF > 0, and MFI > MFI midpoint; bearish when flow index < -institutional flow threshold, CMF < 0, and MFI < MFI midpoint
Calculation: institutional score = +1 for a bullish institutional signal, -1 for a bearish institutional signal, otherwise 0
Calculation: bullish confluence total = momentum score + structure score + wave score + liquidity score + trend score + divergence score + volatility score + institutional score
Calculation: bullish signal count = count of true bullish momentum, structure, momentum wave, liquidity, trend, divergence, volatility, and institutional signals
Calculation: bearish signal count = count of true bearish momentum, structure, momentum wave, liquidity, trend, divergence, volatility, and institutional signals
Calculation: bullish bonus count = count of true bullish extreme momentum condition, all-bullish alignment, oscillator confluence count = maximum possible count, and volume surge with flow index > bullish bonus flow threshold
Calculation: bearish bonus count = count of true bearish extreme momentum condition, all-bearish alignment, oscillator confluence count = maximum possible count, and volume surge with flow index < -bearish bonus flow threshold
Calculation: bullish total score = bullish signal count + bullish bonus count + max(bullish confluence total, 0)
Calculation: bearish total score = bearish signal count + bearish bonus count + max(-bullish confluence total, 0)
