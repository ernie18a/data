Calculation: Pivots(T, L) = alternating pivots of bars of T: PivotHigh(high, L, L) with direction +1 and PivotLow(low, L, L) with direction -1; a pivot with the same direction as the last pivot replaces it if more extreme and is otherwise ignored, and a pivot with the opposite direction is appended
Calculation: WaveLabel(T) = (state, direction) from the last six Pivots(T, L_T) p0..p5 with directions d0..d5, where w1=|p1-p0|, w2=|p2-p1|, w3=|p3-p2|, w4=|p4-p3|, w5=|p5-p4|; the first test that holds gives the state: WAVE_5 if d0..d5 alternate, p5 is beyond p0, p2 is beyond p0 in the direction of p5 from p0, W2_MIN*w1 <= w2 < W2_MAX*w1, w3 >= W3_MIN*w1, and p4 is not beyond p1 against that direction by more than OVERLAP*w1; WAVE_4 if d0..d4 alternate, p4 is beyond p0 and the same w2, w3 and p4 tests hold; WAVE_3 if d0..d3 alternate, p3 is beyond p0 and the w2 and w3 tests hold; WAVE_2 if d0..d2 alternate, p2 is beyond p0 and the w2 test holds; WAVE_1 if d0 != d1 and p1 != p0; WAVE_C if d1 = d3, d0 != d1, d1 != d2, w3 >= CORR_C*w1 and CORR_B_LO <= w2/w1 <= CORR_B_HI, with direction sign(p0-p3); WAVE_B if d0 != d1, d1 != d2 and w2 >= CORR_B_MIN*w1, with direction sign(p0-p2); WAVE_A if d0 != d1, with direction sign(p0-p1); impulse states have direction sign(end pivot - p0); WAVE_5 is truncated when p5 does not pass p3; otherwise UNKNOWN with direction 0; a layer not valid for the chart timeframe is UNKNOWN, and on chart bars a layer T takes the value of its last completed bar
Calculation: FlatPattern = on bars where the newest chart pivot is confirmed, the type of the last four chart pivots p0..p3 with directions d0..d3 when d1 = d3, d1 != d2 and d0 != d1, where BA = 100*|p2-p1|/|p1-p0|, CA = 100*|p3-p2|/|p1-p0| and TOLF = TOL, multiplied by TOL_TRUNC_MULT while the chart WaveLabel is a truncated WAVE_5: REGULAR if BA in [REG_BA_MIN-TOLF, 100+TOLF] and CA in [100-TOLF, REG_CA_MAX+TOLF]; else EXPANDED if BA in [100-TOLF, EXP_BA_MAX+TOLF] and CA in [EXP_CA_MIN-TOLF, EXP_CA_MAX+TOLF]; else RUNNING if BA > 100 and CA < 100-TOLF; else NONE; NONE on all other bars
Calculation: FlatSignal = -d1 when FlatPattern is REGULAR or EXPANDED, +d1 when FlatPattern is RUNNING, otherwise 0
Calculation: PullbackSignal = -d3 on bars where the newest chart pivot is confirmed and d1 = d3, d1 != d2, d0 != d1 and |CA-100| <= PB_TOL (CA as in FlatPattern), otherwise 0
Calculation: MomDiv(s) = for s=+1, highest(high, DIV_N) > highest(high, DIV_N) measured DIV_N bars earlier AND highest(RSI(close, RSI_N), DIV_N) < that RSI high measured DIV_N bars earlier; for s=-1, lowest(low, DIV_N) < its value DIV_N bars earlier AND lowest(RSI(close, RSI_N), DIV_N) > its value DIV_N bars earlier
Calculation: VolSpike = volume at the newest chart pivot > VOL_SPIKE * SMA(volume, VOLAVG_N) at that pivot
Calculation: TrendAligned(s) = for s=+1, close >= EMA(close, TREND_N); for s=-1, close <= EMA(close, TREND_N)
Calculation: WaveAStrength = |p1-p0| >= MIN_A*ATR(ATR_N) AND |p1-p0|/|p0-p1| in [RETR_MIN, RETR_MAX] AND volume at the C pivot > SMA(volume, VOLAVG_N) at the C pivot
Calculation: RevFactors(d1) = count of: MomDiv(d1); VolSpike; CA in [CA_BAND1_LO, CA_BAND1_HI] or [CA_BAND2_LO, CA_BAND2_HI] or [CA_BAND3_LO, CA_BAND3_HI]; (T1 or T2 WaveLabel in {WAVE_4, WAVE_C}) or (T3 WaveLabel in {WAVE_4, WAVE_C}); TrendAligned(FlatSignal)
Calculation: HtfConfluence(d1) = min(HTF_CAP, sum of: 30 if chart WaveLabel is WAVE_5; 25 if chart direction is nonzero and equals T1 direction; 20 if T1 direction is nonzero and equals T2 direction; 15 if T2 direction is nonzero and equals T3 direction; 10 if T4 direction = -d1; 10 if MomDiv(d1); 10 if chart WaveLabel is WAVE_4 or WAVE_5 and chart W3 volume > W3VOL_MULT * volume average at the W3 pivot and chart W4 volume < SMA(volume, VOL_N) at the W4 pivot; 5 if chart WaveLabel is WAVE_3, WAVE_4 or WAVE_5, chart w3 >= chart w1 and (chart WAVE_3 or chart w3 >= chart w5); 5 if chart WAVE_5 and w5/w1 is in W5FIB_A, W5FIB_B or W5FIB_C range; 5 if w2/w1 in [W2FIB_LO, W2FIB_HI] and (chart not WAVE_4 or WAVE_5, or w4/w3 in [W4_LO, W4_HI]); 15 if T7 direction is nonzero and equals T1 direction; 10 if T5 is WAVE_5 and T7 direction is nonzero and equals T5 direction; 10 if T5, T6 and T7 directions are equal and nonzero; 5 if chart WAVE_5 and T7 is WAVE_3)
Calculation: StackedFlat(d1) = FlatPattern is REGULAR or EXPANDED and any of T1..T4 has WaveLabel WAVE_B or WAVE_C with direction d1
Calculation: Cascade(d1) = (T5 or T7 has WaveLabel WAVE_B or WAVE_C with direction d1) AND (T1 or T2 has WaveLabel WAVE_4 with direction d1)
Calculation: FlatTier(d1) = 0 if Cascade(d1); otherwise t = 4 if HtfConfluence(d1) >= TIER4_HTF and RevFactors(d1) >= TIER4_RF, else 3 if HtfConfluence(d1) >= TIER3_HTF and RevFactors(d1) >= TIER3_RF, else 2 if HtfConfluence(d1) >= TIER2_HTF and RevFactors(d1) >= TIER2_RF, else 1; then t+1 if StackedFlat(d1) and t <= 3
Calculation: FlatScore(d1) = min(100, SC_BASE - SC_NOA*[not WaveAStrength] + SC_BAW*(100 - |BA - IDEAL_BA|) + SC_CAW*(100 - |CA - IDEAL_CA|) + SC_MOM*[MomDiv(d1)] + SC_VOL*[VolSpike] + SC_BCL*BCLOSE + SC_Q*FlatQuality), where (IDEAL_BA, IDEAL_CA) = (100, 100) for REGULAR, (IDEAL_BA_EXP, IDEAL_CA_EXP) for EXPANDED, (IDEAL_BA_RUN, IDEAL_CA_RUN) for RUNNING; BCLOSE = 1 unless FlatPattern is EXPANDED, where it is 1 if the close on the B-pivot bar is above P0 when d1 = +1 or below P0 when d1 = -1, else 0; FlatQuality = for REGULAR: min(100, max(0, 100 - (|BA-100| + |CA-100|)/2) + Q_REG*[CA in [Q_REG_LO, Q_REG_HI]]); for EXPANDED: min(100, max(0, 100 - (|BA-Q_EXP_BA| + |CA-Q_EXP_CA|)/2) + Q_BCL*BCLOSE), then min(100, that + Q_CA161*[CA in [Q161_LO, Q161_HI]]); for RUNNING: min(100, max(0, 100 - (|BA-Q_RUN_BA| + |CA-Q_RUN_CA|)/2) + Q_VOL*[VolSpike] + Q_TREND*[TrendAligned(d1)])
Calculation: W4Zone(T) = band between p3 - D*W4_LO*|p3-p2| and p3 - D*W4_HI*|p3-p2| of layer T, where D is the direction of its WaveLabel, defined when WaveLabel is WAVE_3, WAVE_4, WAVE_5 or WAVE_C
Calculation: TfAgreeCount(s) = number of layers T1..T7 whose WaveLabel direction equals s
Calculation: ScalpSetup = WaveLabel(T5) is WAVE_5 AND (WaveLabel(T1) or WaveLabel(T2) is WAVE_3 or WAVE_C)
Calculation: CPending = WaveLabel(chart) is WAVE_B, or a valid B pivot of a chart flat is latched (alternation holds and |B-A| >= B_LATCH*|A-origin|) and not yet cleared by a completed C pivot or by a close beyond the origin
Calculation: CLevels = for the latched flat with A pivot pA, B pivot pB and origin P0: CSideUp = pA > P0 (pB > pA when there is no origin); waveA = |pA - P0| (|pB - pA| when there is no origin); CMIN = pB + s*waveA, CSTD = pB + s*waveA*C_STD_MULT, CEXT = pB + s*waveA*C_EXT_MULT, with s = +1 if CSideUp else -1
Long: FlatSignal = +1 AND (FlatTier(d1) in {0, 2, 3, 4} OR (FlatScore(d1) >= SCORE_MIN AND min(HTF_CAP, HtfConfluence(d1) + STACK_ADD*StackedFlat(d1)) >= HTF_MIN))
Short: FlatSignal = -1 AND (FlatTier(d1) in {0, 2, 3, 4} OR (FlatScore(d1) >= SCORE_MIN AND min(HTF_CAP, HtfConfluence(d1) + STACK_ADD*StackedFlat(d1)) >= HTF_MIN))
Long: PullbackSignal = +1
Short: PullbackSignal = -1
Exit: long, close < P0 of a stored pullback whose PullbackSignal was +1, or close < P0 of a stored REGULAR or EXPANDED flat whose FlatSignal was +1
Exit: short, close > P0 of a stored pullback whose PullbackSignal was -1, or close > P0 of a stored REGULAR or EXPANDED flat whose FlatSignal was -1

Long: a stored flat with d1 = -1 and a five-wave extension (d5 = +1 and P5 > P3, with P4 and P5 stored), high > P5 on this or an earlier bar, no earlier retest of that flat, AND high >= min(P1,P2,P3) AND low <= max(P1,P2,P3) AND close > open
