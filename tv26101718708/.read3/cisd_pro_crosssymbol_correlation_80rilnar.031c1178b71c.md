Calculation: Bullish CISD setup(source OHLC, pivot lookback, scan lookback) = a confirmed pivot low with equal left and right pivot lookbacks; searching backward from the pivot through the scan lookback, the nearest bar with close < open and the consecutive close < open bars immediately before it form the stretch; level = open of the oldest stretch bar; size = abs(level - close of the nearest bar)
Calculation: Bearish CISD setup(source OHLC, pivot lookback, scan lookback) = a confirmed pivot high with equal left and right pivot lookbacks; searching backward from the pivot through the scan lookback, the nearest bar with close > open and the consecutive close > open bars immediately before it form the stretch; level = open of the oldest stretch bar; size = abs(level - close of the nearest bar)
Calculation: Volatility multiplier(close) = using log(close / close[1]), update fast and slow EWMA variances of squared returns on each source bar, initialized at zero; ratio = sqrt(fast variance) / sqrt(slow variance), or one when slow variance is zero; return the high volatility multiplier when ratio exceeds the upper regime threshold, the low volatility multiplier when ratio is below the lower regime threshold, otherwise one
Calculation: CISD size multiplier(close) = base ATR multiple × Volatility multiplier(close) when advanced analytics and GARCH sizing are enabled, otherwise base ATR multiple
Calculation: Purge(source OHLC, direction, CISD pivot bar, tolerance) = a previously confirmed pivot high is swept when a later high exceeds its price, or a previously confirmed pivot low is swept when a later low falls below its price; the sweep must occur on or within tolerance bars after the CISD pivot, using a high pivot for short direction and a low pivot for long direction
Long: On chart bars, after a bullish CISD setup is detected, before its confirmation timeout, chart close > setup level AND directional bias permits long AND (size filter is disabled OR setup size >= ATR(ATR lookback) on the setup detection bar × CISD size multiplier(chart close)) AND (purge filter is disabled OR Purge(chart OHLC, long, setup pivot bar, purge tolerance))
Short: On chart bars, after a bearish CISD setup is detected, before its confirmation timeout, chart close < setup level AND directional bias permits short AND (size filter is disabled OR setup size >= ATR(ATR lookback) on the setup detection bar × CISD size multiplier(chart close)) AND (purge filter is disabled OR Purge(chart OHLC, short, setup pivot bar, purge tolerance))
Long: On T1 higher-timeframe bars using last completed T1 OHLC, after a bullish CISD setup is detected, before the MTF confirmation timeout, last completed T1 close > setup level AND directional bias permits long AND (MTF size filter is disabled OR setup size >= ATR(ATR lookback) on the T1 pivot bar × CISD size multiplier(chart close))
Short: On T1 higher-timeframe bars using last completed T1 OHLC, after a bearish CISD setup is detected, before the MTF confirmation timeout, last completed T1 close < setup level AND directional bias permits short AND (MTF size filter is disabled OR setup size >= ATR(ATR lookback) on the T1 pivot bar × CISD size multiplier(chart close))
Long: On configured selected-symbol bars (chart timeframe or T2), using last completed selected-symbol OHLC, after a bullish CISD setup is detected, before the CISD confirmation timeout, last completed selected-symbol close > setup level AND directional bias permits long AND (size filter is disabled OR setup size >= ATR(ATR lookback) on the selected-symbol pivot bar × CISD size multiplier(selected-symbol close)) AND (purge filter is disabled OR Purge(selected-symbol OHLC, long, setup pivot bar, purge tolerance))
Short: On configured selected-symbol bars (chart timeframe or T2), using last completed selected-symbol OHLC, after a bearish CISD setup is detected, before the CISD confirmation timeout, last completed selected-symbol close < setup level AND directional bias permits short AND (size filter is disabled OR setup size >= ATR(ATR lookback) on the selected-symbol pivot bar × CISD size multiplier(selected-symbol close)) AND (purge filter is disabled OR Purge(selected-symbol OHLC, short, setup pivot bar, purge tolerance))
