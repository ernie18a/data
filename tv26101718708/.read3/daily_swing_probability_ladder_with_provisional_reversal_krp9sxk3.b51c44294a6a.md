Short: Bear reversal = true
Long: Direction after start = -1 AND (Up recovery score >= recovery score threshold OR high > Anchor after start)
Short: Direction after start = 1 AND (Down recovery score >= recovery score threshold OR low < Anchor after start)
Calculation: Leg pivot = the pivot that most recently passed the leg test, where a confirmed PivotHigh(high, pivot length, pivot length) passes if there is no Leg pivot, the Leg pivot before this test is a low, or the PivotHigh price is above that Leg pivot's price, and a confirmed PivotLow(low, pivot length, pivot length) passes if there is no Leg pivot, the Leg pivot before this test is a high, or the PivotLow price is below that Leg pivot's price; the PivotHigh test precedes the PivotLow test on each bar
Calculation: Structural direction = 1 if Leg pivot is a low, -1 if Leg pivot is a high
Calculation: Structural extreme = if Structural direction = 1, the maximum of the Leg pivot price and all highs from the bar on which the Leg pivot was set through the current bar; if Structural direction = -1, the minimum of the Leg pivot price and all lows over the same bars
Calculation: Magnitude met(X, s, ATR trigger, percent trigger) = (s * (close - X) / ATR(ATR length) >= ATR trigger) OR (s * (close - X) / X * 100 >= percent trigger), where s is 1 or -1
Calculation: Volume score(s) = count of true among [volume / SMA(volume, volume average length) >= RVOL threshold], [volume >= volume thrust multiplier * SMA(volume, volume average length)], [s * (OBV - OBV[OBV lookback]) > 0], [s * (close - open) > 0]
Calculation: Bull reversal = (a new Leg pivot is set on this bar OR Provisional direction[1] = 0) AND Structural direction = -1 AND close[i] > open[i] for every i from 0 to reversal candle count - 1 AND close > Highest(high, reversal breakout lookback)[1] AND close > EMA(close, fast EMA length) AND Magnitude met(Structural extreme, 1, reversal ATR trigger, reversal percent trigger)
Calculation: Bear reversal = (a new Leg pivot is set on this bar OR Provisional direction[1] = 0) AND Structural direction = 1 AND close[i] < open[i] for every i from 0 to reversal candle count - 1 AND close < Lowest(low, reversal breakout lookback)[1] AND close < EMA(close, fast EMA length) AND Magnitude met(Structural extreme, -1, reversal ATR trigger, reversal percent trigger)
Calculation: Direction after start = 1 if Bull reversal; -1 if Bear reversal; 0 if a new Leg pivot is set on this bar; otherwise Provisional direction[1]
Calculation: Extreme after start = high if Bull reversal; low if Bear reversal; max(Provisional extreme[1], high) if Direction after start = 1; min(Provisional extreme[1], low) if Direction after start = -1; otherwise NA
Calculation: Anchor after start = Structural extreme if Bull reversal or Bear reversal; Provisional anchor[1] if Direction after start != 0; otherwise NA
Calculation: Up recovery score = count of true among [Magnitude met(Extreme after start, 1, recovery ATR trigger, recovery percent trigger)], [close > EMA(close, fast EMA length)], [the number of i from 0 to recovery momentum lookback - 1 with close[i] > close[i+1] is at least max(1, recovery momentum lookback - 1)], [the number of i from 0 to recovery momentum lookback - 1 with high[i] > high[i+1] and low[i] >= low[i+1] is at least max(1, recovery momentum lookback - 1)], [high > Highest(high, recovery breakout lookback)[1]], [Volume score(1) >= minimum volume score]
Calculation: Down recovery score = count of true among [Magnitude met(Extreme after start, -1, recovery ATR trigger, recovery percent trigger)], [close < EMA(close, fast EMA length)], [the number of i from 0 to recovery momentum lookback - 1 with close[i] < close[i+1] is at least max(1, recovery momentum lookback - 1)], [the number of i from 0 to recovery momentum lookback - 1 with high[i] <= high[i+1] and low[i] < low[i+1] is at least max(1, recovery momentum lookback - 1)], [low < Lowest(low, recovery breakout lookback)[1]], [Volume score(-1) >= minimum volume score]
Calculation: Provisional direction = 1 if Direction after start = -1 AND Up recovery score >= recovery score threshold; -1 if Direction after start = 1 AND Down recovery score >= recovery score threshold; -1 if Direction after start = 1 AND low < Anchor after start; 1 if Direction after start = -1 AND high > Anchor after start; otherwise Direction after start
Calculation: Provisional extreme = (high if Provisional direction = 1, low if Provisional direction = -1) if Provisional direction != Direction after start; otherwise Extreme after start
Calculation: Provisional anchor = Extreme after start if Provisional direction != Direction after start; otherwise Anchor after start
