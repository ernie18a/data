Calculation: Volume-weighted RSI = 100 when the down average is 0, 0 when the up average is 0, otherwise 100 − 100 / (1 + up average / down average), where change = close − close[1], weighted change = change × (volume if volume weighting is enabled and volume is available, otherwise 1), up average = selected moving average(max(weighted change, 0), RSI lookback), and down average = selected moving average(max(−weighted change, 0), RSI lookback)
Calculation: Current volume-weighted RSI = selected moving average of volume-weighted RSI on chart bars using the smoothing lookback and smoothing averaging type when smoothing is enabled, otherwise volume-weighted RSI
Calculation: Context volume-weighted RSI = volume-weighted RSI on T1 bars using the same RSI lookback, averaging type, and volume-weighting setting as the chart calculation; on chart bars, use either the still-forming T1 bar or the last completed T1 bar according to the update setting
Long: Current volume-weighted RSI crosses above the midline OR Current volume-weighted RSI > midline AND Context volume-weighted RSI > midline AND NOT (Current volume-weighted RSI[1] > midline AND Context volume-weighted RSI[1] > midline)
Short: Current volume-weighted RSI crosses below the midline OR Current volume-weighted RSI <= midline AND Context volume-weighted RSI <= midline AND NOT (Current volume-weighted RSI[1] <= midline AND Context volume-weighted RSI[1] <= midline)
