Calculation: Korean premium = 100 × (BTC/KRW price − BTC/USD index price × USD/KRW rate) / (BTC/USD index price × USD/KRW rate) when Bitcoin index data is selected; otherwise 100 × (chart instrument KRW price − matching USDT price × USD/KRW rate) / chart instrument KRW price for a KRW-quoted chart; otherwise 100 × (matching KRW price / USD/KRW rate − chart instrument USDT price) / chart instrument USDT price, using corresponding close, high, or low prices
Calculation: ALMA period = max(3, integer(3 × smoothing period parameter / chart timeframe period))
Calculation: Signal value = EMA(Korean premium, Bollinger signal EMA period) when absolute mode is off and Bollinger mode is on; otherwise Korean premium
Calculation: Lower threshold = configured absolute lower premium threshold when absolute mode is on; otherwise lower Bollinger Band of Korean premium when Bollinger mode is on; otherwise lowest rolling EMA of Korean premium lows + (highest rolling EMA of Korean premium highs − lowest rolling EMA of Korean premium lows) × lower relative percentage / 100 when EMA threshold mode is on; otherwise lowest rolling ALMA of Korean premium lows + (highest rolling ALMA of Korean premium highs − lowest rolling ALMA of Korean premium lows) × lower relative percentage / 100
Calculation: Upper threshold = configured absolute upper premium threshold when absolute mode is on; otherwise upper Bollinger Band of Korean premium when Bollinger mode is on; otherwise lowest rolling EMA of Korean premium lows + (highest rolling EMA of Korean premium highs − lowest rolling EMA of Korean premium lows) × upper relative percentage / 100 when EMA threshold mode is on; otherwise lowest rolling ALMA of Korean premium lows + (highest rolling ALMA of Korean premium highs − lowest rolling ALMA of Korean premium lows) × upper relative percentage / 100
Long: Signal value < lower threshold AND previous chart bar's signal value ≥ its lower threshold AND chart bar time is within configured start and end times AND configured trade mode permits long entries
Short: Signal value > upper threshold AND previous chart bar's signal value ≤ its upper threshold AND chart bar time is within configured start and end times AND configured trade mode permits short entries
Exit: Long, signal value > upper threshold AND previous chart bar's signal value ≤ its upper threshold AND chart bar time is within configured start and end times AND configured trade mode is long only
Exit: Short, signal value < lower threshold AND previous chart bar's signal value ≥ its lower threshold AND chart bar time is within configured start and end times AND configured trade mode is short only
