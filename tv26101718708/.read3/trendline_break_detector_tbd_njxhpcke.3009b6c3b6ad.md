Calculation: Pivot-trendline event(L) = On chart bars, detect confirmed pivot highs and lows using L bars on each side, sourcing wick highs/lows or candle-body highs/lows according to the configured pivot-source mode; Auto selects wicks on either of two configured chart timeframes and bodies otherwise. For each tier, maintain its trend state, prior pivot highs/lows, and active trendline independently. At each bar, extend an active line by its slope and deactivate it if its age exceeds the configured maximum. On a newly changed high pivot with no simultaneous changed low pivot: if trend is not up, the high exceeds the prior high, pivot spacing exceeds the configured minimum, and the prior low is recent enough, set trend up and start a horizontal active line from that low; otherwise, if a line is active and the pivot satisfies high < line-start-price + slope AND (high > line-end-price + slope OR slope = 0), compare the pivot-bar close with the line price at that pivot. If the close is below the line, update the line through the pivot; when its prior slope is zero, repeatedly reanchor at the high of the bar with the greatest positive close-minus-line deviation in the configured reanchor history, recalculating slope until no positive deviation remains. Otherwise deactivate the line and emit an upward event if trend is not up. If there is no newly changed high pivot, an active line emits an upward event and deactivates when trend is not up and close > its current endpoint. Apply the symmetric low-pivot logic for downward events: start a horizontal line from the prior high and set trend down when the low is below the prior low and spacing and recency qualify; otherwise update an active line when low > line-start-price + slope AND (low < line-end-price + slope OR slope = 0), reanchoring a zero-slope line at the low of the bar with greatest positive line-minus-close deviation; otherwise deactivate and emit a downward event if trend is not down. With no newly changed low pivot, an active line emits a downward event and deactivates when trend is not down and close < its current endpoint. Use separate pivot-lookback parameters for the Fast, Medium, and Slow tiers; their activation is configurable. The minimum pivot spacing, maximum line age, and reanchor history are parameters.
Calculation: Adaptive trail direction(fast ATR bound, slow ATR bound) = Calculate Efficiency Ratio as abs(close − close[E]) / sum(abs(close − close[1]), E), using parameter E, then smooth it with EMA using parameter S. Set alpha = [smoothed ER × (2/(fast bound+1) − 2/(slow bound+1)) + 2/(slow bound+1)]². Set dynamic ATR length to clamp(1/alpha, max(minimum dynamic length, fast bound − fast offset), slow bound + slow offset); set the ATR multiplier by linear interpolation from the high-ER multiplier to the low-ER multiplier as ER falls. Calculate true range with the recursive average r := prior r + (1/dynamic length) × (true range − prior r), initialized to true range; multiply by the adaptive multiplier for trail distance. Maintain a stop initialized in the up state at close − trail distance: in the up state ratchet it to max(prior stop, close − trail distance), switching down when close < stop and resetting stop to close + trail distance; in the down state ratchet it to min(prior stop, close + trail distance), switching up when close > stop and resetting stop to close − trail distance. Return +1 in the up state and −1 in the down state. E, S, minimum dynamic length, fast offset, slow offset, and both multipliers are parameters.
Calculation: Adaptive composite bias = adaptive trail direction on chart bars × chart weight + adaptive trail direction on each of T1, T2, and T3 bars × its separate weight. T1, T2, and T3 are successively longer than the chart timeframe. Calculate each direction on its own timeframe bars and take its value on chart bars with lookahead off (last completed timeframe bar historically; still-forming timeframe bar in realtime). Use the same separate fast and slow ATR-bound parameters on all timeframes; each weight is a separate parameter.
Calculation: Tier signal gate(side, L) = AND of the following enabled gates; a disabled gate passes. VWAP gate: calculate ((session VWAP(hlc3) − its value N chart bars ago) / N) / ATR(A); strong up/down means this value > threshold / < −threshold. For long, Block-opposite passes unless strong down and Require-aligned passes only if strong up; for short, reverse the directions; Off passes either side. Adaptive gate: Strict passes long if composite bias ≥ minimum absolute score and short if bias ≤ its negative; Loose passes long if bias > the negative minimum and short if bias < the positive minimum; Off passes. Auto uses Strict when chart timeframe is at or below its configured threshold timeframe, otherwise Loose. HTF-anchor gate: using the tier's last two confirmed pivot highs and lows, long requires the latest high and low each exceed their prior value; short requires each to be lower. LTF-break gate: long requires close > latest tier pivot high; short requires close < latest tier pivot low. Volume gate: volume ≥ the linear-interpolation percentile of volume over its lookback at its percentile threshold, and, if rising volume is required, volume > volume[1]. N, threshold, A, adaptive minimum score, volume lookback, volume percentile, and the gate enablement and mode choices are parameters; L is that tier's separate pivot-lookback parameter.
Long: For any selected Fast, Medium, or Slow tier, Pivot-trendline event(L) emits an upward event AND Tier signal gate(long, L) passes.
Short: For any selected Fast, Medium, or Slow tier, Pivot-trendline event(L) emits a downward event AND Tier signal gate(short, L) passes.
