Calculation: Choppiness = 100 * log10(Sum(TrueRange(high, low, close), lookback) / (Highest(high, lookback) - Lowest(low, lookback))) / log10(lookback), or the zero-range fallback when the denominator is not positive
Calculation: Direction state = +1 when the sum of four votes is at least the consensus threshold, -1 when it is at most the negative consensus threshold, otherwise 0; each vote is +1 when its condition is true and -1 otherwise: EMA(source, shorter lookback) > EMA(source, intermediate lookback); EMA(source, intermediate lookback) > EMA(source, longer lookback); close > the average of those three EMAs; +DI > -DI from DMI(lookback, same lookback)
Calculation: Bullish structural break = confirmed chart-bar close > the latest confirmed Pivot High(high, pivot strength on both sides) AND close[1] <= that pivot high
Calculation: Bearish structural break = confirmed chart-bar close < the latest confirmed Pivot Low(low, pivot strength on both sides) AND close[1] >= that pivot low
Calculation: Structure state = +1 after a bullish structural break, -1 after a bearish structural break, otherwise the previous state; initially 0
Calculation: Healthy trend = ADX(lookback, same lookback) >= trend floor AND Choppiness < chop ceiling
Calculation: Bullish absorption = confirmed chart bar, volume > SMA(volume, volume lookback) * volume multiplier, abs(close - open) / (high - low) < maximum body-to-range ratio, close >= open, and close <= high - (high - low) * close-position fraction; use body-to-range ratio 0 when high = low
Calculation: Bearish absorption = confirmed chart bar, volume > SMA(volume, volume lookback) * volume multiplier, abs(close - open) / (high - low) < maximum body-to-range ratio, close <= open, and close >= low + (high - low) * close-position fraction; use body-to-range ratio 0 when high = low
Calculation: Last liquidity sweep side = the side of the most recent confirmed, not-previously-swept level among the retained pivot levels: sell-side for a pivot low with low < level and close > level; buy-side for a pivot high with high > level and close < level
Calculation: Compression ratio = (Highest(high, compression lookback) - Lowest(low, compression lookback)) / (ATR(ATR lookback) * compression lookback), or the zero-denominator fallback
Calculation: Normalized EMA slope = clamp(midpoint + Z * scale, lower bound, upper bound), where Z is (slope mix - SMA(slope mix, z-score lookback)) / StDev(slope mix, z-score lookback), or 0 when StDev is 0; slope mix is the average of EMA(source, shorter lookback) - EMA(source, shorter lookback)[1], EMA(source, intermediate lookback) - EMA(source, intermediate lookback)[1], and EMA(source, longer lookback) - EMA(source, longer lookback)[1]
Calculation: Bias score = clamp(weight for direction * Direction state + weight for structure * Structure state + (Healthy trend AND Direction state != 0 ? weight for healthy trend * Direction state : 0) + (bullish structural break ? weight for break : bearish structural break ? -weight for break : 0) + (Bullish absorption ? weight for absorption : Bearish absorption ? -weight for absorption : 0) + (Last liquidity sweep side is sell-side ? weight for sweep : buy-side ? -weight for sweep : 0) + (Normalized EMA slope > upper slope threshold ? weight for slope : Normalized EMA slope < lower slope threshold ? -weight for slope : 0), -maximum score, maximum score)
Long: Structure state = +1 OR Bullish absorption OR Last liquidity sweep side is sell-side OR Direction state >= 0 OR (confirmed chart bar AND Bias score > bias-transition threshold AND Bias score[1] <= bias-transition threshold) OR (confirmed chart bar AND Compression ratio >= compression threshold AND Healthy trend AND Bias score > 0)
Short: Structure state = -1 OR Bearish absorption OR Last liquidity sweep side is buy-side OR Direction state < 0 OR (confirmed chart bar AND Bias score < -bias-transition threshold AND Bias score[1] >= -bias-transition threshold) OR (confirmed chart bar AND Compression ratio >= compression threshold AND Healthy trend AND Bias score < 0)
