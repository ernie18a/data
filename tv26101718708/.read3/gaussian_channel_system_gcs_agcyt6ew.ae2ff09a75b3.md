Calculation: Gaussian MA(source, filter length, sigma, offset) = sum(i=0..filter length-1, source[i] * exp(-0.5 * ((i - floor(offset * (filter length - 1))) / sigma)^2)) / sum(i=0..filter length-1, exp(-0.5 * ((i - floor(offset * (filter length - 1))) / sigma)^2))
Calculation: Gaussian channel width = StDev(source - Gaussian MA(source, filter length, sigma, offset), filter length) * channel-width multiplier
Calculation: Normalized Gaussian slope = (Gaussian MA(source, filter length, sigma, offset) - Gaussian MA(source, filter length, sigma, offset)[slope lookback]) / slope lookback / ATR(normalization lookback)
Long: (low <= Gaussian MA(source, filter length, sigma, offset) - Gaussian channel width / 2 AND normalized Gaussian slope > trend threshold AND ZScore(source, z-score lookback)[1] < lower z-score threshold OR ADX(DMI lookback, same DMI lookback) > ADX threshold AND (DI+(DMI lookback, same DMI lookback) > DI-(DMI lookback, same DMI lookback) AND close crosses above Gaussian MA(source, filter length, sigma, offset) + Gaussian channel width AND EMA(close, fast EMA lookback) > EMA(close, slow EMA lookback) OR close crosses above Gaussian MA(source, filter length, sigma, offset) + Gaussian channel width AND EMA(close, fast EMA lookback) > EMA(close, slow EMA lookback) OR EMA(close, fast EMA lookback) crosses above EMA(close, slow EMA lookback) AND close > Gaussian MA(source, filter length, sigma, offset))) AND (volume filter disabled OR volume > SMA(volume, volume lookback) * volume multiplier) AND bars since prior long signal, or chart start, > cooldown
Short: (high >= Gaussian MA(source, filter length, sigma, offset) + Gaussian channel width / 2 AND normalized Gaussian slope < -trend threshold AND ZScore(source, z-score lookback)[1] > upper z-score threshold OR ADX(DMI lookback, same DMI lookback) > ADX threshold AND (DI-(DMI lookback, same DMI lookback) > DI+(DMI lookback, same DMI lookback) AND close crosses below Gaussian MA(source, filter length, sigma, offset) - Gaussian channel width AND EMA(close, fast EMA lookback) < EMA(close, slow EMA lookback) OR close crosses below Gaussian MA(source, filter length, sigma, offset) - Gaussian channel width AND EMA(close, fast EMA lookback) < EMA(close, slow EMA lookback) OR EMA(close, fast EMA lookback) crosses below EMA(close, slow EMA lookback) AND close < Gaussian MA(source, filter length, sigma, offset))) AND (volume filter disabled OR volume > SMA(volume, volume lookback) * volume multiplier) AND bars since prior short signal, or chart start, > cooldown
