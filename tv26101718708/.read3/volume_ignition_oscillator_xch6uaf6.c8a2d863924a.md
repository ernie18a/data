Calculation: Volume excess = 0 if SMA(volume, volume lookback) = 0; otherwise max(volume / SMA(volume, volume lookback) - 1, 0)
Calculation: Ignition oscillator = EMA(top contribution + bottom contribution, oscillator smoothing lookback), where range position is Stochastic %K(range lookback) / 100, or 0.5 when highest(high, range lookback) = lowest(low, range lookback); top contribution is volume excess × range position when range position >= top-zone parameter and a move with close - close[move lookback] > move ATR multiple × ATR(ATR lookback) occurred on the current bar or within the preceding watch-window parameter bars, otherwise 0; bottom contribution is -volume excess × (1 - range position) when range position <= bottom-zone parameter and a move with close - close[move lookback] < -move ATR multiple × ATR(ATR lookback) occurred on the current bar or within the preceding watch-window parameter bars, otherwise 0
Long: Ignition oscillator crosses below -signal threshold parameter
Short: Ignition oscillator crosses above signal threshold parameter
