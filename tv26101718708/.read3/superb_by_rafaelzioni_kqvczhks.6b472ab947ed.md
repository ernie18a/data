Calculation: trend state = On chart bars, calculate signed spread = ((close - open) * 100) * (volume / ((high - low) * 100)); accumulated spread = signed spread + CUM(signed spread); smoothed spread = SMA(accumulated spread, smoothing lookback); spread deviation = STDEV(accumulated spread - smoothed spread, shared lookback); price deviation = STDEV(high - low, shared lookback); shadow = (accumulated spread - smoothed spread) / spread deviation * price deviation; adjusted price = shadow > 0 ? high + shadow : low + shadow; center = EMA(adjusted price, EMA lookback); lower candidate = center - ATR(ATR lookback) * ATR multiplier; upper candidate = center + ATR(ATR lookback) * ATR multiplier. Initialize trend state to 0, age to 0, lower rail to lower candidate, and upper rail to upper candidate on the first chart bar. On later bars, increment age and carry the prior trend state and rails unless changed as follows: at age 1, if lower candidate >= prior upper rail, set upper rail to lower candidate and trend state to 1; otherwise set lower rail to upper candidate and trend state to -1. At age > 1 with prior trend state > 0, if lower candidate >= prior upper rail, set upper rail to lower candidate; otherwise, if upper candidate < prior upper rail * (1 - reversal factor), set lower rail to upper candidate and trend state to -1. At age > 1 with prior trend state <= 0, if upper candidate <= prior lower rail, set lower rail to upper candidate; otherwise, if lower candidate > prior lower rail * (1 + reversal factor), set upper rail to lower candidate and trend state to 1. The shared lookback is used for both standard deviations; smoothing lookback, EMA lookback, ATR lookback, ATR multiplier, and reversal factor are separate parameters.
Long: trend state = 1 AND trend state[1] = -1
Short: trend state = -1 AND trend state[1] = 1
