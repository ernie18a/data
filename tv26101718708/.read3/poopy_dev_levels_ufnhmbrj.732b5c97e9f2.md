Short: On chart bars, signal when close < the pending short anchor. A newly confirmed PivotHigh(high, P1 left bars, P1 right bars) above the preceding confirmed PivotHigh, with a confirmed PivotLow available, clears the prior pending short setup; set the new anchor to the latest confirmed PivotLow only if it occurred before that PivotHigh.
Long: On chart bars, signal when close > the pending long anchor. A newly confirmed PivotLow(low, P1 left bars, P1 right bars) below the preceding confirmed PivotLow, with a confirmed PivotHigh available, clears the prior pending long setup; set the new anchor to the latest confirmed PivotHigh only if it occurred before that PivotLow.
