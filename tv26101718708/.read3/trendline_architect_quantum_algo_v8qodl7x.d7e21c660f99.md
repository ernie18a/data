Calculation: Trendline candidates = connect each successive pair of confirmed PivotLow(low, pivot lookback, pivot lookback) values as support and each successive pair of confirmed PivotHigh(high, pivot lookback, pivot lookback) values as resistance; require anchor span ≥ pivot lookback and ≤ maximum anchor span; reject if any close between the anchors crosses the candidate by more than ATR(ATR lookback) at candidate creation × line-validity ratio; reject if an active same-side line has current value distance < ATR(ATR lookback) × duplicate-distance ratio AND absolute slope difference × duplicate-slope multiplier < ATR(ATR lookback) × duplicate-slope ratio; when active same-side lines reach the maximum lines per side, remove the line with the fewest touches, oldest first on ties; line value at bar b = first anchor value + slope × (b − first anchor bar), where slope = (second anchor value − first anchor value) / anchor span.
Calculation: Trendline state = each candidate starts forming with two touches; on each confirmed chart bar, an active support gains a touch when low is between line value ± ATR(ATR lookback) × touch-tolerance ratio and close > line value, and active resistance gains a touch when high is between line value ± ATR(ATR lookback) × touch-tolerance ratio and close < line value; a line becomes confirmed when touches reach the touches-to-confirm parameter; active support breaks when close < line value − ATR(ATR lookback) × breakout-buffer ratio, and active resistance breaks when close > line value + ATR(ATR lookback) × breakout-buffer ratio; if confirmed-only is enabled, retire a break of a line that was forming at the start of that bar, otherwise put the broken line on retest watch regardless of breakout grade; process the break before retiring an active line whose age from its first anchor exceeds maximum line age; retire a watch line after the retest-watch window, or after its first qualifying retest on a subsequent confirmed chart bar.
Calculation: Breakout grade = score the breakout as base grade score + 1 for each of: volume z-score > volume-z threshold, absolute close-to-line distance / ATR(ATR lookback) > penetration threshold, and (high > low ? absolute(close − open) / (high − low) : 0) > body-ratio threshold; volume z-score = 0 if its standard deviation is unavailable or zero, otherwise (volume − SMA(volume, volume lookback)) / standard deviation(volume, volume lookback); grade is A when score ≥ A-grade score threshold, B when score = B-grade score, and C otherwise.
Long: confirmed chart bar AND ((resistance line is active AND close > line value + ATR(ATR lookback) × breakout-buffer ratio AND (confirmed-only is disabled OR line was confirmed at the start of the bar) AND breakout grade ≥ minimum breakout grade) OR (resistance line is on retest watch after its break and within the retest-watch window AND low ≤ line value + ATR(ATR lookback) × touch-tolerance ratio AND close > line value))
Short: confirmed chart bar AND ((support line is active AND close < line value − ATR(ATR lookback) × breakout-buffer ratio AND (confirmed-only is disabled OR line was confirmed at the start of the bar) AND breakout grade ≥ minimum breakout grade) OR (support line is on retest watch after its break and within the retest-watch window AND high ≥ line value − ATR(ATR lookback) × touch-tolerance ratio AND close < line value))
