Calculation: ATR = SMA(TrueRange(high, low, close), ATR lookback)
Calculation: UpperLine = line through two confirmed PivotHigh(high, swing strength, swing strength) pivots P1 (older) and P2 (newer, the latest confirmed when the line forms), kept at bar t while no high after P1 up to t is above the line by pierce multiple * ATR and bars since P1 <= pattern lookback
Calculation: LowerLine = line through two confirmed PivotLow(low, swing strength, swing strength) pivots P1 (older) and P2 (newer, the latest confirmed when the line forms), kept at bar t while no low after P1 up to t is below the line by pierce multiple * ATR and bars since P1 <= pattern lookback
Calculation: UpperCandidates(t) = up to survivor count UpperLines with smallest |UpperLine(t) - close(t)|; LowerCandidates(t) = up to survivor count LowerLines with smallest |LowerLine(t) - close(t)|
Calculation: Angle(X) = atan(slope(X) / ATR) in degrees, where slope(X) = price change per bar of line X
Calculation: Start(U, L) = later of the first anchor bars of U and L
Calculation: AnchorSpan(U, L) = longer of the anchor-to-anchor bar distances of U and L
Calculation: Apex(U, L) = bar where U and L meet, counted only when they are not parallel and the bar is positive
Calculation: Converging(U, L) = Apex(U, L) > Start(U, L) AND Apex(U, L) - Start(U, L) <= apex span multiple * AnchorSpan(U, L)
Calculation: Diverging(U, L) = Apex(U, L) exists AND Apex(U, L) <= Start(U, L) AND Start(U, L) - Apex(U, L) <= apex span multiple * AnchorSpan(U, L)
Calculation: IsBrief(U, L) = AnchorSpan(U, L) <= flag span multiple * pole lookback
Calculation: PoleMove(U, L) = (close(Start(U, L)) - close(Start(U, L) - pole lookback)) / ATR
Calculation: WidthChange(U, L) = (U - L) at the last bar of their common anchor span / (U - L) at its first bar; fails when there is no common span or a width is not positive
Calculation: Shape(U, L) = first matching of: Rectangle when both |Angle(U)| and |Angle(L)| < flat tolerance AND NOT Diverging AND WidthChange in [1/width max, width max]; none when both |Angle(U)| and |Angle(L)| < flat tolerance; Ascending Triangle when |Angle(U)| < flat tolerance AND Angle(U) < Angle(L) AND Converging; Descending Triangle when |Angle(L)| < flat tolerance AND Angle(U) < Angle(L) AND Converging; none when Angle(U) < 0 < Angle(L) AND Converging AND symmetry ratio < symmetry minimum, where symmetry ratio = min(|Angle(U)|, |Angle(L)|) / max(|Angle(U)|, |Angle(L)|); Pennant when Angle(U) < 0 < Angle(L) AND Converging AND IsBrief AND |PoleMove| >= pole minimum; Symmetrical Triangle when Angle(U) < 0 < Angle(L) AND Converging; Falling Wedge when Angle(U) < Angle(L) AND Converging AND Angle(U) < 0; Rising Wedge when Angle(U) < Angle(L) AND Converging; Bear Flag when Parallel AND Mean > flat tolerance AND IsBrief AND PoleMove <= -pole minimum; Rising Channel when Parallel AND Mean > flat tolerance; Bull Flag when Parallel AND Mean < -flat tolerance AND IsBrief AND PoleMove >= pole minimum; Falling Channel when Parallel AND Mean < -flat tolerance; none otherwise; where Parallel = NOT Diverging AND |Angle(U) - Angle(L)| <= parallel tolerance AND WidthChange in [1/width max, width max], and Mean = (Angle(U) + Angle(L)) / 2
Calculation: Limit(U, L) = earliest of: (a) if Apex(U, L) > Start(U, L), Apex(U, L) - 1 when U(Apex) <= L(Apex) else Apex(U, L), otherwise Start(U, L) + age span multiple * AnchorSpan(U, L); (b) for rectangles, channels and flags, Start + W0 * (width max - 1) / drift when drift > 0, or Start + W0 * (1 - 1 / width max) / |drift| when drift < 0, where W0 = U(Start) - L(Start) and drift = slope(U) - slope(L); (c) for flags and pennants, Start + flag span multiple * pole lookback, applied only when the name they demote to is disabled
Calculation: Expired(U, L, t) = t > Limit(U, L) OR t - Start(U, L) > pattern lookback
Calculation: Admitted(U, L, t) = U in UpperCandidates(t) AND L in LowerCandidates(t) AND Shape(U, L) is not none AND its name is enabled AND no NeckLive pattern shares an anchor pair with U or L AND (U, L) not admitted at an earlier bar AND each line claimed flat by Shape (both lines for Rectangle, upper for Ascending Triangle, lower for Descending Triangle) has |slope| * (t - its first anchor bar) / W0 <= flat travel fraction AND |slope| * (t - its first anchor bar) / ATR <= flat drift multiple AND t <= Limit(U, L) AND, for flags and pennants, t <= Start(U, L) + flag span multiple * pole lookback AND t - Start(U, L) <= pattern lookback
Calculation: Live(U, L, t) = Admitted(U, L, t') for some bar t' <= t, and not completed, expired or dropped before t; when an admission would exceed active cap, the oldest live pattern is dropped
Calculation: DoubleTopNeck = the latest two confirmed PivotHigh pivots A (older) and B with |A - B| <= top match multiple * ATR and the lowest PivotLow between A and B below both; neckline = horizontal line at that low; Start = A
Calculation: DoubleBottomNeck = the latest two confirmed PivotLow pivots A (older) and B with |A - B| <= top match multiple * ATR and the highest PivotHigh between A and B above both; neckline = horizontal line at that high; Start = A
Calculation: HeadShouldersNeck = when DoubleTopNeck does not form, the latest three confirmed PivotHigh pivots S1, H, S2 with H above both S1 and S2 by head multiple * ATR, |S1 - S2| <= shoulder multiple * ATR, the lowest PivotLow between S1 and H below both S1 and H, and the lowest PivotLow between H and S2 below both H and S2; neckline = line through those two lows; Start = S1
Calculation: InverseHeadShouldersNeck = when DoubleBottomNeck does not form, the latest three confirmed PivotLow pivots S1, H, S2 with H below both S1 and S2 by head multiple * ATR, |S1 - S2| <= shoulder multiple * ATR, the highest PivotHigh between S1 and H above both S1 and H, and the highest PivotHigh between H and S2 above both H and S2; neckline = line through those two highs; Start = S1
Calculation: NeckDistance = distance from the neckline to the higher of the two tops (double top), to the lower of the two bottoms (double bottom), or to the head (head-and-shoulders forms, neckline read at the head bar)
Calculation: NeckLimit = Start + age span multiple * (last anchor bar - Start), last anchor being B for doubles and S2 for head-and-shoulders forms
Calculation: NeckCandidate = DoubleTopNeck, DoubleBottomNeck, HeadShouldersNeck or InverseHeadShouldersNeck formed at the bar its newest anchor pivot confirms, when its name is enabled, 0 < NeckDistance <= neck max multiple * ATR, its neckline is not pierced after its first anchor (tops: no low below neckline - pierce multiple * ATR; bottoms: no high above neckline + pierce multiple * ATR), and that bar <= NeckLimit AND that bar - Start <= pattern lookback
Calculation: NeckLive(N, t) = NeckCandidate N formed at a bar <= t and not completed, expired or dropped before t; when a new candidate would exceed neck cap, the oldest live neckline pattern is dropped
Long: close > UpperLine(t) + completion multiple * ATR AND Live(U, L, t) AND NOT Expired(U, L, t), for some pair (U, L)
Long: close > Neckline(N, t) + completion multiple * ATR AND NeckLive(N, t) for N in DoubleBottomNeck or InverseHeadShouldersNeck AND t <= NeckLimit AND t - Start <= pattern lookback
Short: close < LowerLine(t) - completion multiple * ATR AND Live(U, L, t) AND NOT Expired(U, L, t), for some pair (U, L)
Short: close < Neckline(N, t) - completion multiple * ATR AND NeckLive(N, t) for N in DoubleTopNeck or HeadShouldersNeck AND t <= NeckLimit AND t - Start <= pattern lookback
Calculation: RCap = cap multiple * SMA(TrueRange(high, low, close), cap lookback) computed on T1 bars, each chart bar taking the last completed T1 value; when chart timeframe >= T1, computed on chart bars at the current bar; unlimited when cap multiple is zero
Calculation: R = min(Height, RCap at the completion bar), where Height = |U(Start) - L(Start)| for trendline patterns and NeckDistance for neckline patterns
Calculation: Entry = close at the completion bar; Target(k) = Entry + side * target multiple(k) * R, side = +1 for long and -1 for short; Target(last) = Target of the highest-numbered enabled tier
Calculation: FarPrice = L(completion bar) for a long trendline pattern, U(completion bar) for a short trendline pattern, lowest anchor price for a long neckline pattern, highest anchor price for a short neckline pattern
Calculation: Stop = Entry - side * max(side * (Entry - FarPrice), stop floor multiple * R) when the stop is at structure, else Entry - side * stop multiple * R
Calculation: PercentDone = (completion bar - Start) / (min(Limit, Start + pattern lookback) - Start), with NeckLimit in place of Limit for neckline patterns
Exit: long, (low <= Stop + half tick OR high >= Target(last) - half tick) AND bar after entry bar AND (band gate off OR PercentDone at entry inside level band)
Exit: short, (high >= Stop - half tick OR low <= Target(last) + half tick) AND bar after entry bar AND (band gate off OR PercentDone at entry inside level band)
