Calculation: Bullish CISD reference = the armed open of the latest eligible bearish candle-sequence start (close < open; a doji ends a sequence), selected by the configured source mode: every bearish sequence, or the first bearish sequence from a confirmed PivotHigh(high, left lookback, right confirmation lookback), using its sequence start even if before the pivot when the pivot belongs to it and waiting for a bearish sequence if none is present; in swing mode discard a candidate if any close after its source and before pivot confirmation is above its open; each source can arm once, newer sources replace it, and it expires when source age exceeds the maximum-age parameter; evaluate the existing reference before replacement and a newly selected reference on its selection bar; only confirmed chart bars can signal, and the source bar cannot signal.
Calculation: Bearish CISD reference = the armed open of the latest eligible bullish candle-sequence start (close > open; a doji ends a sequence), selected by the configured source mode: every bullish sequence, or the first bullish sequence from a confirmed PivotLow(low, left lookback, right confirmation lookback), using its sequence start even if before the pivot when the pivot belongs to it and waiting for a bullish sequence if none is present; in swing mode discard a candidate if any close after its source and before pivot confirmation is below its open; each source can arm once, newer sources replace it, and it expires when source age exceeds the maximum-age parameter; evaluate the existing reference before replacement and a newly selected reference on its selection bar; only confirmed chart bars can signal, and the source bar cannot signal.
