Calculation: Drift = EMA(log return, longer drift lookback)
Calculation: EmergingDrift = EMA(log return, shorter emerging drift lookback)
Calculation: Instability = -sign(Drift) * PercentRank(mean over i of |i-th smallest of the last W log returns - i-th smallest of the W log returns before them| / stdev(log return, W), rank length), where W = instability window
Calculation: ZScore = clip((log return - SMA(log return, obs window)) / stdev(log return, obs window), -winsor clip, +winsor clip)
Calculation: PChange = posterior probability of run length 0 in Bayesian online changepoint detection over ZScore, with hazard, a Student-t predictive with dof degrees of freedom, location = sum of ZScore over the run / (prior pseudo-count + run length), scale^2 = 1 + 1/(prior pseudo-count + run length), and run lengths capped at run cap
Calculation: CusumUp = max(0, CusumUp[1] + ZScore - CUSUM slack); CusumDown = min(0, CusumDown[1] + ZScore + CUSUM slack); CusumVar = max(0, CusumVar[1] + ZScore^2 - 1 - CUSUM slack); MeanBreak = CusumUp > mean break threshold OR CusumDown < -mean break threshold; VarBreak = CusumVar > variance break threshold; after a MeanBreak CusumUp and CusumDown are set to 0, and after a VarBreak CusumVar is set to 0
Calculation: ChangeDir = 0 if EmergingDrift * Drift > 0 AND |EmergingDrift| > accel multiplier * |Drift|, otherwise -sign(Drift)
Calculation: ChangeStrength = 25 * min(PChange / change threshold, 2) + 25 * min(|ZScore| / 4, 1) + 25 * min(max(CusumUp, -CusumDown) / 5, 1)
Calculation: Held(event, direction, strength, decay, hold) = direction * strength * decay^age if age <= hold, else 0, where age = bars since the latest bar on which event is true with direction != 0, and direction and strength are those taken on that bar
Calculation: ChangepointSig = Held((PChange >= change threshold AND PChange[1] < change threshold) OR MeanBreak OR VarBreak, ChangeDir, max(ChangeStrength, changepoint strength floor), changepoint decay, changepoint hold)
Calculation: Stretch = PercentRank(|close - close[displacement length]| / ATR(atr length), 100)
Calculation: ExhaustionDir = +1 if close < close[longer efficiency lookback] AND EfficiencyRatio(close, longer efficiency lookback) >= trend floor AND EfficiencyRatio(close, shorter efficiency lookback) < EfficiencyRatio(close, shorter efficiency lookback)[fade lag] AND Stretch >= stretch threshold; -1 if close > close[longer efficiency lookback] AND EfficiencyRatio(close, longer efficiency lookback) >= trend floor AND EfficiencyRatio(close, shorter efficiency lookback) < EfficiencyRatio(close, shorter efficiency lookback)[fade lag] AND Stretch >= stretch threshold; otherwise 0
Calculation: Absorption = min(RelVolume / max(|close - close[absorption lag]| / ATR(atr length), absorption floor), absorption cap) / absorption cap, where RelVolume = volume / SMA(volume, volume baseline); Absorption = 0 when there is no volume
Calculation: Panic = PercentRank(ATR(atr length), 100) / 100 >= panic ATR percentile AND |close - close[panic lag]| / ATR(atr length) >= panic run threshold
Calculation: ExhaustionStrength = min((40 + 0.6 * Stretch) * Boost, 100), where Boost = 1 + 0.4 * Absorption + (0.15 if Panic) when absorption boost is enabled, otherwise Boost = 1
Calculation: ExhaustionSig = Held(ExhaustionDir != 0, ExhaustionDir, ExhaustionStrength, exhaustion decay, exhaustion hold)
Calculation: VolumeZ = time-of-day-normalized z-score of volume when time-of-day normalization is enabled on intraday bars (volume minus the prior mean for this minute of day, divided by the square root of the prior variance for this minute of day, with that mean and variance then updated at the time-of-day adaptation rate), otherwise z-score of volume over volume baseline
Calculation: RangeZ = z-score of (high - low) over volume baseline
Calculation: CLV = ((close - low) - (high - close)) / max(high - low, epsilon)
Calculation: Composite = 30 + 60 * (clip((VolumeZ - volume z threshold) / 2, 0, 1) + clip((RangeZ - range z threshold) / 2, 0, 1) + clip((|CLV| - rejection threshold) / (1 - rejection threshold), 0, 1)) / 3
Calculation: ConformalQ = ConformalQ[1] + adaptation rate * ((Composite > ConformalQ[1] ? 1 : 0) - rarity alpha), starting at initial quantile and updated on each confirmed bar with volume
Calculation: ClimaxDir = +1 if volume is present AND VolumeZ >= volume z threshold AND RangeZ >= range z threshold AND CLV >= rejection threshold AND (conformal disabled OR Composite >= ConformalQ); -1 if volume is present AND VolumeZ >= volume z threshold AND RangeZ >= range z threshold AND CLV <= -rejection threshold AND (conformal disabled OR Composite >= ConformalQ); otherwise 0
Calculation: FlowAgree = min(max(ClimaxDir * FlowRatio, 0), 1), where FlowRatio = sum over the CVD window of volume * S / (SMA(volume, volume baseline) * CVD window), S = 2 * Phi(log return / stdev(log return, return-vol window)) - 1 when BVC is enabled, otherwise S = CLV, and Phi = standard normal CDF; evaluated on the climax bar
Calculation: ClimaxStrength = min(Composite * (1 + 0.2 * FlowAgree), 100) on the bar a secondary test starts, then min(ClimaxStrength * 1.25, 100) once that test's retest holds
Calculation: ClimaxSig = ClimaxDir * ClimaxStrength while a secondary test is active; a test starts on each bar with ClimaxDir != 0 and ends when it is invalidated or more than secondary window bars have passed since it started; for a bullish test, invalidation = low < test-start low - invalidation band * ATR, and a retest holds once (after the start bar) when low is between test-start low - invalidation band * ATR and test-start low + retest band * ATR and volume <= test-start volume * retest fraction; for a bearish test, invalidation = high > test-start high + invalidation band * ATR, and a retest holds once when high is between test-start high - retest band * ATR and test-start high + invalidation band * ATR and volume <= test-start volume * retest fraction
Calculation: LastPivotHigh = high of the most recent bar that is the highest bar of its swing length on each side (known swing length bars after it); LastPivotLow = low of the most recent bar that is the lowest bar of its swing length on each side
Calculation: SweepDir = +1 on a bar with low < LastPivotLow AND close > LastPivotLow; otherwise -1 on a bar with high > LastPivotHigh AND close < LastPivotHigh; otherwise the most recent SweepDir, cleared when more than sweep window bars have passed since it was set
Calculation: StructFire = (SweepDir = +1 AND close > LastPivotHigh AND |close - close[1]| / ATR(atr length) >= break displacement) OR (SweepDir = -1 AND close < LastPivotLow AND |close - close[1]| / ATR(atr length) >= break displacement)
Calculation: StructureSig = Held(StructFire, SweepDir, min(40 + 30 * min(|close - close[1]| / ATR(atr length) / 2, 1) + 30, 100), 1, structure hold)
Calculation: UpCount = number of [Instability >= watch threshold, ChangepointSig >= trigger threshold, ExhaustionSig >= gate threshold, ClimaxSig >= extreme threshold, StructureSig >= confirm threshold]; DownCount = number of [Instability <= -watch threshold, ChangepointSig <= -trigger threshold, ExhaustionSig <= -gate threshold, ClimaxSig <= -extreme threshold, StructureSig <= -confirm threshold]; ConfDir = +1 if UpCount >= minimum agreeing AND UpCount >= DownCount, -1 if DownCount >= minimum agreeing AND DownCount > UpCount, otherwise 0
Calculation: Stage (0 none, 1 WATCH, 2 ARMED, 3 EXTREME, 4 CONFIRMED) and CandDir (+1 bottom, -1 top, 0 none) update in order each bar: (a) if Stage >= 2, Clock = Clock + 1; if Stage is 2 or 3 and Clock > expiry window, Stage = 0 and CandDir = 0; (b) if Stage <= 1: if ConfDir != 0, Stage = 2, CandDir = ConfDir and Clock = 0; otherwise if |Instability| >= watch threshold, Stage = 1 and CandDir = sign(Instability); otherwise Stage = 0 and CandDir = 0; (c) if Stage = 2 AND CandDir * ClimaxSig >= extreme threshold, Stage = 3; (d) if Stage is 2 or 3 AND CandDir * StructureSig >= confirm threshold, Stage = 4; (e) after the fire tests of this bar, if Stage = 4 and the previous bar's Stage = 4, Stage = 0 and CandDir = 0
Calculation: MeanReversionGate = (0.5 * max(0, -Correlation(Deviation[1], log return, trust window)) + 0.5 * clip((1 - VR) / 0.5, 0, 1)) * (1 if Dickey-Fuller test disabled or DFt <= Dickey-Fuller critical, else 0), where Deviation = close - SMA(close, trust window), VR = Variance(sum of log returns over q bars, VR window) / (q * Variance(log return, VR window)), and DFt = OLS t-statistic of the slope of one-bar close change on lagged close over the Dickey-Fuller window
Calculation: TurbulenceGate = max(0, 1 - veto strength * (Branch - cascade level) / (1 - cascade level)) if turbulence veto is enabled AND Cascade, otherwise 1; where Shock = 1 if |log return| > shock threshold * stdev(log return, return-vol window) else 0, Burst = sum of Shock over shock sub-window, Fano = Variance(Burst, Fano window) / SMA(Burst, Fano window), Branch = max(0, min(1, 1 - 1 / sqrt(max(Fano, 1)))) with Branch = 0 when the mean is 0, and Cascade = Branch >= cascade level AND Branch >= Branch[1]
Calculation: TrendDir = the selected ride trend basis: for the EMA/DEMA stack basis, +1 if shorter trend MA > longer trend MA AND longer trend MA >= longer trend MA[1], -1 if shorter < longer AND longer <= longer[1], otherwise 0, where each MA is EMA or DEMA per trend MA type; for the Williams Alligator basis, +1 if awake AND lips > teeth AND teeth > jaw AND lips >= lips[1], -1 if awake AND lips < teeth AND teeth < jaw AND lips <= lips[1], otherwise 0, where jaw, teeth and lips are SMMA of median price over the jaw, teeth and lips lengths and awake = |lips - jaw| >= awake fan * ATR(atr length); for the 100 DEMA basis, +1 if DEMA(close, DEMA length) > DEMA of the nearest higher ladder timeframe AND at least cross count of the higher ladder timeframes (T2 to T8 above the chart timeframe) have DEMA below the chart DEMA, -1 if DEMA(close, DEMA length) < DEMA of the nearest higher ladder timeframe AND at least cross count of those timeframes have DEMA above the chart DEMA, otherwise 0; higher-timeframe values use the last completed bar
Calculation: RideDir = +1 if ride enabled AND TrendDir = +1 AND (flow requirement disabled OR LTFDelta > 0) AND Entry, where Entry = TrendDir turned +1 on this bar for on-the-cross timing, otherwise (highest high over pullback lookback - low >= pullback threshold * ATR(atr length)) AND ResumeUp, with ResumeUp = close crosses above MA(close, shorter trend MA length) for EMA re-cross timing, or close > high[1] AND close > open for Early timing; RideDir = -1 if ride enabled AND TrendDir = -1 AND (flow requirement disabled OR LTFDelta < 0) AND Entry, where Entry = TrendDir turned -1 on this bar for on-the-cross timing, otherwise (high - lowest low over pullback lookback >= pullback threshold * ATR(atr length)) AND ResumeDown, with ResumeDown = close crosses below MA(close, shorter trend MA length) for EMA re-cross timing, or close < low[1] AND close < open for Early timing; otherwise 0
Calculation: LTFDelta = (volume of T1 bars within the current chart bar that close above their open - volume of those that close below their open) / (total volume of those bars that close above or below their open), or na when that total is 0
Calculation: AgainstTrend = alignment role is not off AND role sign * (count of included TFs with TrendBias = CandDir - count of included TFs with TrendBias = -CandDir) / (count of included TFs) < -alignment margin, where role sign = -1 for the reversal role and +1 for the continuation role, included TFs = the N nearest of T2 to T8 at or above the chart timeframe, and TrendBias on T_k = +1 if close > EMA(close, alignment trend length) AND EMA > EMA[1], -1 if close < EMA AND EMA < EMA[1], otherwise 0, using the last completed bar of T_k
Calculation: OptionsPass = options filter disabled OR (at least 3 of [RealizedVolPercentile < premium percentile threshold, RealizedVol > RealizedVol[volatility slope lookback], ExpectedMove >= minimum move, NOT ThetaCaution] AND ExpectedMove >= minimum move), where RealizedVol = sqrt(mean over realized-vol window of ln(high/close) * ln(high/open) + ln(low/close) * ln(low/open)), RealizedVolPercentile = PercentRank(RealizedVol, volatility percentile lookback), ExpectedMove = close * RealizedVol * sqrt(resolve horizon), and ThetaCaution = theta caution enabled AND (0 <= minutes to session close <= late-day minutes OR weekday = expiry weekday)
Calculation: InSession = session filter disabled OR the bar time is within the session window
Calculation: GateOK = (mean-reversion gate disabled OR MeanReversionGate >= mean-reversion floor) AND (turbulence veto disabled OR TurbulenceGate >= turbulence floor)
Calculation: ReversalFire = Stage = actionable stage AND Stage[1] != actionable stage AND GateOK AND InSession AND NOT (alignment block enabled AND AgainstTrend) AND (LTF gate disabled OR CandDir * LTFDelta > LTF threshold) AND OptionsPass
Long: ReversalFire AND CandDir = 1
Short: ReversalFire AND CandDir = -1
Long: Stage = 3 AND Stage[1] != 3 AND CandDir = 1 AND GateOK
Short: Stage = 3 AND Stage[1] != 3 AND CandDir = -1 AND GateOK
Long: CandDir = 1
Short: CandDir = -1
Long: RideDir = 1 AND (turbulence veto disabled OR TurbulenceGate >= turbulence floor) AND OptionsPass AND NOT ReversalFire
Short: RideDir = -1 AND (turbulence veto disabled OR TurbulenceGate >= turbulence floor) AND OptionsPass AND NOT ReversalFire
