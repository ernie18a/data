Calculation: T1 midpoint = (high + low) / 2 of the last completed T1 bar, calculated on T1 bars and sampled onto chart bars
Calculation: T2 midpoint = (high + low) / 2 of the last completed T2 bar, calculated on T2 bars and sampled onto chart bars
Calculation: T3 midpoint = (high + low) / 2 of the last completed T3 bar, calculated on T3 bars and sampled onto chart bars
Calculation: Latest pivot high = most recent confirmed Pivot High(high, shared left-lookback parameter, shared right-lookback parameter) on chart bars
Calculation: Latest pivot low = most recent confirmed Pivot Low(low, shared left-lookback parameter, shared right-lookback parameter) on chart bars
Calculation: Session membership = chart-bar opening time in New York is within either configured interval [session A start, session A end) or [session B start, session B end)
Calculation: Long score = (session score parameter if session membership, else 0) + (higher-timeframe score parameter if close > T2 midpoint AND close > T3 midpoint, else 0) + (retest score parameter if (close > T1 midpoint AND low[1] <= T1 midpoint) OR (close > T1 midpoint AND low[1] <= latest pivot low AND close > latest pivot low), else 0) + (structure-break score parameter if close > latest pivot high AND close[1] <= latest pivot high, else 0) + (gap score parameter if low > high[gap-lookback parameter bars ago], else 0)
Calculation: Short score = (session score parameter if session membership, else 0) + (higher-timeframe score parameter if close < T2 midpoint AND close < T3 midpoint, else 0) + (retest score parameter if (close <= T1 midpoint AND high[1] >= T1 midpoint AND close < T1 midpoint) OR (close <= T1 midpoint AND high[1] >= latest pivot high AND close < latest pivot high), else 0) + (structure-break score parameter if close < latest pivot low AND close[1] >= latest pivot low, else 0) + (gap score parameter if high < low[gap-lookback parameter bars ago], else 0)
Long: close > T1 midpoint AND long score >= score threshold parameter AND current chart-bar index minus prior long-signal chart-bar index > signal-spacing parameter (use index 0 before any long signal)
Short: close <= T1 midpoint AND short score >= score threshold parameter AND current chart-bar index minus prior short-signal chart-bar index > signal-spacing parameter (use index 0 before any short signal)
