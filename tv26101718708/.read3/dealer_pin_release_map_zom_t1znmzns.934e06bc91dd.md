Calculation: Prior magnet = nearest strike magnet on the preceding chart bar, or the current nearest strike magnet on the first chart bar
Calculation: Magnet width = max(ATR(ATR lookback) * magnet-width parameter, minimum tick)
Calculation: Volatility ratio = ATR(ATR lookback) / EMA(ATR(ATR lookback), compression lookback), or neutral volatility ratio parameter if the EMA is nonpositive
Calculation: Directional pressure = EMA((((close - low) - (high - close)) / max(high - low, minimum tick)) * volume / max(SMA(volume, relative-volume lookback), volume-floor parameter) * pressure-scale parameter, pressure-smoothing lookback)
