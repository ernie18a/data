Long: EMA(close, shorter EMA lookback) crosses above EMA(close, longer EMA lookback)
Short: EMA(close, shorter EMA lookback) crosses below EMA(close, longer EMA lookback)
Long: EMA(close, shorter EMA lookback) > EMA(close, longer EMA lookback)
Short: EMA(close, shorter EMA lookback) < EMA(close, longer EMA lookback)
Long: close < EMA(close, shorter EMA lookback) - ATR(ATR lookback) * ATR multiplier
Short: close > EMA(close, shorter EMA lookback) + ATR(ATR lookback) * ATR multiplier
Long: On chart bars using values from the current, still-forming T1, T2, T3, T4, T5, T6, T7, or T8 bar, EMA(close, shortest EMA lookback) > EMA(close, intermediate EMA lookback) AND EMA(close, intermediate EMA lookback) > EMA(close, longest EMA lookback)
Short: On chart bars using values from the current, still-forming T1, T2, T3, T4, T5, T6, T7, or T8 bar, EMA(close, shortest EMA lookback) < EMA(close, intermediate EMA lookback) AND EMA(close, intermediate EMA lookback) < EMA(close, longest EMA lookback)
