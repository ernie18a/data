Calculation: body-to-range ratio = abs(close - open) / (high - low)
Long: on chart bars, low < Highest(high, T1 lookback parameter, calculated on T1 bars using the last completed T1 bar value on chart bars) AND close > Lowest(low, same T1 lookback parameter, calculated on T1 bars using the last completed T1 bar value on chart bars)
Short: on chart bars, high > Highest(high, T1 lookback parameter, calculated on T1 bars using the last completed T1 bar value on chart bars) AND close < Highest(high, same T1 lookback parameter, calculated on T1 bars using the last completed T1 bar value on chart bars)
Long: the most recent sweep event is bullish (a bearish sweep takes precedence if both occur on the same chart bar) AND no prior long confirmation has occurred since that sweep AND close > open AND high > low AND body-to-range ratio >= body fraction parameter
Short: the most recent sweep event is bearish (a bearish sweep takes precedence if both occur on the same chart bar) AND no prior short confirmation has occurred since that sweep AND close < open AND high > low AND body-to-range ratio >= body fraction parameter
Long: a bullish reversal signal has occurred since the previous long confirmation AND the most recent sweep event is bullish (a bearish sweep takes precedence if both occur on the same chart bar) AND no prior long confirmation has occurred since that sweep AND close > the most recent confirmed PivotHigh(high, swing-strength parameter bars on each side)
Short: a bearish reversal signal has occurred since the previous short confirmation AND the most recent sweep event is bearish (a bearish sweep takes precedence if both occur on the same chart bar) AND no prior short confirmation has occurred since that sweep AND close < the most recent confirmed PivotLow(low, swing-strength parameter bars on each side)
