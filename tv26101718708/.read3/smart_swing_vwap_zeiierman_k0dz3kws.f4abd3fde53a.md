Calculation: Scale Leg(i) = +1 if the most recent high pivot of scale i is more recent than the most recent low pivot of scale i, else -1; a high pivot is a bar whose high is not lower than any high of the last Scale Length(i) bars including itself, and a low pivot is a bar whose low is not higher than any low of the last Scale Length(i) bars including itself; evaluated on each completed bar
Calculation: Candidate(i) = origin bar, origin price, direction, where direction = Scale Leg(i), origin bar = the most recent low pivot of scale i if direction = +1, else the most recent high pivot of scale i, origin price = the low or high at origin bar; Candidate(i) is present only if Scale Enabled(i) AND bars since origin bar < Max Lookback
Calculation: Candidate Strength(i) = (Progress * Range Expansion * Volume Participation)^(1/3) * (Strength Floor + (1 - Strength Floor) * min(Progress, Range Expansion, Volume Participation)), where bounded(x) = min(1, max(0, x)), sums run over the bars from origin bar of Candidate(i) through the current bar, d = direction and p = origin price of Candidate(i), Move = max(d * (close - p), 0), Progress = sqrt(bounded((Move / sum of true range) / Efficiency Scale) * bounded(Move / (Displacement Multiple * ATR(Average Length) at origin bar))), Range Expansion = bounded((sum of true range / sum of RMA(true range, Average Length) - Range Expansion Offset) / Range Expansion Scale), Volume Participation = bounded((sum of volume / sum of RMA(volume, Average Length) - Volume Offset) / Volume Scale)
Calculation: Proximity Link(i,j) = max(exp(-abs(p_i - p_j) / (Price Proximity * ATR(Average Length))), exp(-abs(o_i - o_j) / Bar Proximity)) if Candidate(i) and Candidate(j) are present with equal direction, else 0, where p_i and o_i are origin price and origin bar of Candidate(i)
Calculation: Agreement(i) = sum over all j of Proximity Link(i,j) / number of present candidates
Calculation: Candidate Score(i) = Agreement Weight * Agreement(i) + Range Weight * bounded(abs(Scale High(i) - Scale Low(i)) / (ATR(Average Length) * Range Divisor)) + Strength Weight * Candidate Strength(i), where Scale High(i) and Scale Low(i) are the prices at the most recent high pivot and low pivot of scale i
Calculation: Winner = the present candidate with the highest Candidate Score among candidates with Candidate Score >= Min Anchor Score AND Candidate Strength >= Min Move Strength; undefined if none
Calculation: Rank Step = (Scale Leg(i) changed on this bar for some i with Scale Enabled(i)) OR (no Anchor exists AND bar index >= minimum of Scale Length(i) over all i)
Calculation: Anchor = origin bar, origin price, direction, score, set bar; on a Rank Step with a Winner, if a present candidate has the same origin bar and direction as Anchor, Anchor score := that candidate's Candidate Score; on New Anchor, Anchor := Winner's origin bar, origin price, direction, score = Winner's Candidate Score, set bar = current bar; if Segment Mode, on Bull Flip or Bear Flip, Anchor := Structure's origin bar, price and direction, score = Min Anchor Score, set bar = current bar
Calculation: New Anchor = Rank Step AND Winner present AND (no Anchor exists OR (NOT (Winner direction = Anchor direction AND abs(Winner origin price - Anchor origin price) <= Same Price Tolerance * ATR(Average Length) AND abs(Winner origin bar - Anchor origin bar) <= Bar Proximity) AND bars since Anchor set >= Bars Between Anchors AND (Winner direction != Anchor direction OR Winner Candidate Score >= Anchor score + Score Margin)))
Calculation: Structure = direction, origin bar, price; on New Anchor, Structure := Anchor's direction, origin bar, origin price; on Bull Flip, Structure direction := +1, origin bar := bar of the lowest low from the previous origin bar through the current bar, price := that lowest low; on Bear Flip, Structure direction := -1, origin bar := bar of the highest high from the previous origin bar through the current bar, price := that highest high
Calculation: Bull Flip = Anchor exists AND NOT New Anchor AND Structure direction < 0 AND close >= Structure price
Calculation: Bear Flip = Anchor exists AND NOT New Anchor AND Structure direction > 0 AND close <= Structure price
Calculation: AVWAP = num / den; on each New Anchor, num := Anchor origin price * volume at Anchor origin bar and den := volume at Anchor origin bar, then the update below is applied to every bar from Anchor origin bar through the current bar; on each other completed bar, the update is applied to the current bar; update: a = 1 - 0.5^(1 / Speed), num := (1 - a) * num + a * ((high + low + close) / 3) * volume, den := (1 - a) * den + a * volume; Speed of a bar = round(min(Speed Max, max(Speed Min, Price Tracking Speed / R))) with R = (ATR(Average Length) / RMA(ATR(Average Length), Average Length))^Volatility Adjustment Strength if Adjust Speed With Volatility, else R = 1, evaluated on the bar being updated
Calculation: Band Touch = low <= AVWAP + Retest Touch Zone * ATR(Average Length) AND high >= AVWAP - Retest Touch Zone * ATR(Average Length)
Calculation: Retest Setup State = 0 if New Anchor OR Bull Flip OR Bear Flip OR no Anchor exists; else if Retest Setup State[1] = +1 AND Structure direction > 0 AND Band Touch AND close > AVWAP AND close >= open, then 0; else if Retest Setup State[1] = -1 AND Structure direction < 0 AND Band Touch AND close < AVWAP AND close <= open, then 0; else if close > AVWAP + Retest Setup Distance * ATR(Average Length), then +1; else if close < AVWAP - Retest Setup Distance * ATR(Average Length), then -1; else Retest Setup State[1]
Long: Structure direction > 0
Long: New Anchor AND Anchor direction > 0

Long: close crosses above AVWAP AND bar is completed AND Anchor exists AND NOT New Anchor AND NOT Bull Flip AND NOT Bear Flip

Short: Structure direction < 0
Short: New Anchor AND Anchor direction < 0
Short: Bear Flip
