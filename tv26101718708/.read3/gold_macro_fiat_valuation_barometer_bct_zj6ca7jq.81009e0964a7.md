Calculation: gold fair value = valid M2 supply × (median(gold price / valid M2 supply, chart-timeframe-selected M2 lookback) or current gold price / valid M2 supply if unavailable) × exp(−yield sensitivity × (valid 10-year real yield − neutral real-yield benchmark)); valid M2 supply is M2 supply on T2 when positive, otherwise the M2 fallback; valid 10-year real yield is the 10-year real yield on T1 when available, otherwise the yield fallback
Calculation: valuation dispersion = (gold price − gold fair value) / (standard deviation(gold price − gold fair value, chart-timeframe-selected spread lookback) if positive, otherwise the standard-deviation fallback)
Calculation: macro score = EMA(real-yield points + M2-valuation points + fiat-breadth points + gold/silver-ratio points + valuation-dispersion points, score-smoothing period), where real-yield points are favorable-yield points if valid 10-year real yield < favorable-yield cutoff OR < SMA(valid 10-year real yield, chart-timeframe-selected yield lookback), restrictive-yield points if valid 10-year real yield > restrictive-yield cutoff AND > that SMA, otherwise neutral-yield points; M2-valuation points are cheap-M2 points if percentile rank(gold price / valid M2 supply, chart-timeframe-selected M2 lookback) ≤ cheap-M2 cutoff, expensive-M2 points if that rank > expensive-M2 cutoff, otherwise neutral-M2 points; fiat-breadth points are favorable-breadth points if the count of gold prices in USD, EUR, JPY, GBP, and AUD above their respective chart-timeframe EMAs is ≥ favorable-breadth cutoff, restrictive-breadth points if that count ≤ restrictive-breadth cutoff, otherwise neutral-breadth points; gold/silver-ratio points are favorable-ratio points if gold price / valid silver price > high-ratio cutoff OR (≥ mid-ratio cutoff AND its ROC over the chart-timeframe-selected ratio lookback is negative), restrictive-ratio points if that ratio < low-ratio cutoff, otherwise neutral-ratio points; valuation-dispersion points are favorable-dispersion points if valuation dispersion ≤ −discount-Z threshold, restrictive-dispersion points if ≥ extended-Z threshold, otherwise neutral-dispersion points. Periods selected by chart timeframe use separate parameters for each source branch; valid silver price is silver price in USD when positive, otherwise the silver fallback
Long: crossover(macro score, accumulation threshold)
Exit: long, crossunder(macro score, restrictive threshold)
Long: valuation dispersion ≤ −discount-Z threshold AND valuation dispersion is rising AND no tactical buy has fired since valuation dispersion last exceeded the buy-reset threshold
Exit: long, valuation dispersion ≥ extended-Z threshold AND valuation dispersion is falling AND no tactical sell has fired since valuation dispersion last fell below the sell-reset threshold
