Calculation: Julian date(datetime) = datetime / milliseconds-per-day + Julian Unix epoch
Calculation: Lunar age = positive-modulo(Julian date(datetime) - reference new-moon Julian date, synodic-month duration)
Calculation: Lunar bias = -cos(Lunar age / synodic-month duration * full-cycle angle)
Calculation: Lunar long score = max(Lunar bias, 0) * lunar-score scale
Calculation: Lunar short score = max(-Lunar bias, 0) * lunar-score scale
Calculation: Lunar phase bucket = floor((Lunar age / synodic-month duration + phase offset) * phase count) modulo phase count
Calculation: Phase changed = current chart-bar phase bucket differs from the previous chart-bar phase bucket; treat the first chart bar as unchanged
Calculation: New-moon transition = phase bucket is zero AND Phase changed
Calculation: Full-moon transition = phase bucket is half the phase count AND Phase changed
Calculation: Higher-timeframe bull = on each chart bar, T1 current-bar close > EMA(close, trend lookback) AND EMA(close, fast lookback) > EMA(close, slow lookback); calculate on T1 bars and request the values on chart bars with lookahead off, using the developing T1 bar in real time and completed T1 values historically
Calculation: Higher-timeframe bear = on each chart bar, T1 current-bar close < EMA(close, trend lookback) AND EMA(close, fast lookback) < EMA(close, slow lookback); calculate on T1 bars and request the values on chart bars with lookahead off, using the developing T1 bar in real time and completed T1 values historically
Calculation: Bull trend = close > EMA(source, longest lookback) AND EMA(source, shortest lookback) > EMA(source, intermediate lookback) AND EMA(source, shortest lookback) > EMA(source, shortest lookback)[1]
Calculation: Bear trend = close < EMA(source, longest lookback) AND EMA(source, shortest lookback) < EMA(source, intermediate lookback) AND EMA(source, shortest lookback) < EMA(source, shortest lookback)[1]
Calculation: Relative volume = volume / max(SMA(volume, relative-volume lookback), volume floor)
Calculation: Bull participation = Relative volume >= relative-volume threshold AND close > open AND (close - low) / max(high - low, minimum price increment) >= close-location threshold AND abs(close - open) >= ATR(ATR lookback) * body-to-ATR threshold
Calculation: Bear participation = Relative volume >= relative-volume threshold AND close < open AND (high - close) / max(high - low, minimum price increment) >= close-location threshold AND abs(close - open) >= ATR(ATR lookback) * body-to-ATR threshold
Calculation: Bull momentum score = clamp((Bull trend ? trend weight : 0) + (close > EMA(source, intermediate lookback) ? slow-price weight : 0) + (RSI(source, RSI lookback) >= bull RSI threshold ? MACD weight : 0) + (close > session VWAP(hlc3) ? VWAP weight : 0) + (Bull participation ? participation weight : 0) + (HTF filter disabled OR Higher-timeframe bull ? Calculation: Bear momentum score = clamp((Bear trend ? trend weight : 0) + (close < EMA(source, intermediate lookback) ? slow-price weight : 0) + (RSI(source, RSI lookback) <= bear RSI threshold ? RSI weight : 0) + (RSI(source, RSI lookback) < bear RSI threshold - RSI margin ? strong-RSI weight : 0) + (MACD histogram(source, shorter lookback, longer lookback, signal lookback) < 0 AND MACD histogram(source, shorter lookback, longer lookback, signal lookback) <= its previous-bar value ? MACD weight : 0) + (close < session VWAP(hlc3) ? VWAP weight : 0) + (Bear participation ? participation weight : 0) + (HTF filter disabled OR Higher-timeframe bear ? HTF weight : 0), score lower bound, score upper bound)
Calculation: Long confluence = clamp(Bull momentum score * momentum-confluence weight + Lunar long score * lunar-confluence weight + (Full-moon transition ? moon-phase bonus : 0), score lower bound, score upper bound)
Calculation: Short confluence = clamp(Bear momentum score * momentum-confluence weight + Lunar short score * lunar-confluence weight + (New-moon transition ? moon-phase bonus : 0), score lower bound, score upper bound)
Calculation: Long stop = at the latest long-entry signal bar, lowest(low, swing lookback) - ATR(ATR lookback) * stop buffer
Calculation: Short stop = at the latest short-entry signal bar, highest(high, swing lookback) + ATR(ATR lookback) * stop buffer
Calculation: Long target 2 = at the latest long-entry signal, signal-bar close + max(signal-bar close - Long stop, minimum price increment * minimum-risk ticks) * target-2 R multiple
Calculation: Short target 2 = at the latest short-entry signal, signal-bar close - max(Short stop - signal-bar close, minimum price increment * minimum-risk ticks) * target-2 R multiple
