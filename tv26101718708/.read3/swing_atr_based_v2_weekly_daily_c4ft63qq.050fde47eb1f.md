Calculation: bullish swing confirmation(T1) = on chart bars when the imported T1 close changes, use the latest available T1 OHLC and ATR(ATR lookback T1, T1, current bar); initialize swing direction upward and the extreme to the first high; in the upward state update the extreme on higher highs, reset the candidate count, count bearish candles whose body size is at least ATR times the minimum candle-size multiplier T1, and after the count becomes positive update candidate high and low each bar; confirm a bearish swing when the count reaches the minimum candidate candle count and candidate high minus candidate low reaches ATR times the range multiplier T1; in the downward state mirror this using lower lows and qualifying bullish candles to confirm a bullish swing; track the highest and lowest close since the prior confirmation, set resistance to the tracked highest close on bearish confirmation and support to the tracked lowest close on bullish confirmation, reset both close tracks to the confirmation close, and reset candidate high and low after confirmation; T1 values come from request.security with lookahead off, so they use the forming T1 bar in realtime and the latest completed T1 bar historically, while the swing state runs on chart bars.
Calculation: bullish swing confirmation(T2) = on every chart bar, use chart OHLC and ATR(ATR lookback T2, T2, current bar); initialize swing direction upward and the extreme to the first high; in the upward state update the extreme on higher highs, reset the candidate count, count bearish candles whose body size is at least ATR times the minimum candle-size multiplier T2, and after the count becomes positive update candidate high and low each bar; confirm a bearish swing when the count reaches the minimum candidate candle count and candidate high minus candidate low reaches ATR times the range multiplier T2; in the downward state mirror this using lower lows and qualifying bullish candles to confirm a bullish swing; track the highest and lowest close since the prior confirmation, set resistance to the tracked highest close on bearish confirmation and support to the tracked lowest close on bullish confirmation, reset both close tracks to the confirmation close, and reset the candidate count but retain candidate high and low after confirmation.
Calculation: active support and resistance levels(T1) = create support at the tracked lowest close on each bullish swing confirmation and resistance at the tracked highest close on each bearish swing confirmation; on chart bars remove each support when the latest available T1 close is below it and each resistance when that close is above it; count the supports and resistances removed on each bar.
Calculation: active support and resistance levels(T2) = create support at the tracked lowest close on each bullish swing confirmation and resistance at the tracked highest close on each bearish swing confirmation; on chart bars remove each support when chart close is below it and each resistance when chart close is above it; count the supports and resistances removed on each bar.
Calculation: SGE score(T1) = initialize from initial score T1; on each chart bar first apply the score pending from the prior chart bar; when supports break, set the next score to the negative extreme if no supports remain or the support break count reaches the multiple-break threshold, otherwise set it to neutral if the current score is the positive extreme and to the negative extreme otherwise; when resistances break, set the next score to the positive extreme if no resistances remain or the resistance break count reaches the multiple-break threshold, otherwise set it to neutral if the current score is the negative extreme and to the positive extreme otherwise; if both kinds break on one bar, the resistance result takes precedence; apply the next score on the following chart bar. The break threshold is shared across directions and timeframes.
