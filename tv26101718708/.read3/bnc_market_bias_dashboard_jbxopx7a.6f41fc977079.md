Calculation: Bias(Ti) = on Ti bars, use the current Ti bar (last completed historically and still forming in realtime); add EMA points (+P_ema_full if EMA(close, ema_length_1) > EMA(close, ema_length_2) > EMA(close, ema_length_3) > EMA(close, ema_length_4) > EMA(close, ema_length_5); else -P_ema_full if the first four EMAs are strictly descending; else +P_ema_partial if close is above both EMA lengths 4 and 5; else -P_ema_partial if close is below both; else 0), RSI points (+P_rsi_high if RSI(close, rsi_length) >= rsi_bull_gate; else +P_rsi_mid if >= rsi_flip; else -P_rsi_low if >= rsi_support; else -P_rsi_bottom), Stoch RSI points (-P_stoch_negative if Stoch RSI(RSI(close, stoch_rsi_length), stoch_length, k_smoothing) >= stoch_upper; else +P_stoch_positive if >= stoch_middle; else -P_stoch_negative if >= stoch_lower; else -P_stoch_bottom), Ichimoku points (+P_cloud_high if close > max(Ichimoku Span A[cloud_displacement], Ichimoku Span B[cloud_displacement]); else -P_cloud_low if close < min of those spans; else +P_base_high if close > Ichimoku base line; else -P_base_low), and Keltner Channel points (-P_channel_negative if close > upper band; else +P_channel_positive if close < lower band; else +P_channel_positive if close > basis; else -P_channel_negative); RSI thresholds and score points are separate parameters, as are all listed indicator lengths and thresholds; Ichimoku Span A uses conversion and base lengths and Span B uses its own length; Keltner basis is EMA(close, channel_length) and bands are basis plus or minus channel_multiplier * ATR(channel_length)
Calculation: Overall bias = sum(weight_Ti * Bias(Ti) for each enabled Ti) / sum(weight_Ti for each enabled Ti), or 0 if none are enabled; the seven weights are separate parameters; calculate on chart bars from Ti values requested with lookahead off
Calculation: Downtrend break = on chart bars, connect the latest two confirmed pivot highs using a line when the newer pivot is lower; project that line using the slope between the pivots; accept it only when the absolute rounded angle is strictly between the angle limits and the selected source (close or high) has not crossed above the line over the selected validation segment (disabled, Point A to Point B, or Point A to current); angle = degrees(atan(slope * range_horizon / axis_ratio / (highest(high, clamp(bar_index, 1, range_horizon)) - lowest(low, clamp(bar_index, 1, range_horizon))))), rounded to angle_precision; the line must have remained unbroken for more than min_unbroken_bars, and the selected source must cross from at or below the prior line to above the current line
Calculation: Uptrend break = on chart bars, connect the latest two confirmed pivot lows using a line when the newer pivot is higher; project that line using the slope between the pivots; accept it only when the rounded angle is strictly between the angle limits and the selected source (close or low) has not crossed below the line over the selected validation segment (disabled, Point A to Point B, or Point A to current); use the same angle calculation as for Downtrend break without taking the absolute value; the line must have remained unbroken for more than min_unbroken_bars, and the selected source must cross from at or above the prior line to below the current line; both pivot calculations use the same pivot_length
