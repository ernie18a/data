Calculation: Darvas box = when no box is forming or active, seed the candidate top and bottom with the current chart bar's high and low; on a later bar with a higher high, restart the candidate at that bar, otherwise update its bottom to the lowest low since the seed; activate when age is at least the minimum box age and height in ATR is between the minimum and maximum box-height ATR parameters; discard a forming or active box when age exceeds the maximum box age; resolve an active box on its first confirmed chart bar that breaks either boundary, using close beyond the boundary when close confirmation is enabled and high or low beyond it otherwise.
Calculation: Darvas box age = number of chart bars from the seed bar through the current bar, inclusive.
Calculation: ATR-safe = max(nz(ATR(ATR lookback on chart bars), True Range), minimum tick size).
Calculation: Box height in ATR = (Darvas box top - Darvas box bottom) / ATR-safe.
Calculation: Age score = if box age is at or below ideal age, box age / ideal age * score ceiling; otherwise clamp(score ceiling - (box age / ideal age beyond ideal age) * age-decay parameter, age-score floor, score ceiling), where ideal age = max(minimum box age * ideal-age multiplier, minimum box age + ideal-age offset).
Calculation: Box compression score = clamp(height score * height weight + age score * age weight, score floor, score ceiling), where height score = clamp(score ceiling - ((box height in ATR - minimum box-height ATR) / max(maximum box-height ATR - minimum box-height ATR, minimum height-score span) * score ceiling), score floor, score ceiling).
Calculation: Relative volume = current volume / SMA(volume, volume lookback on chart bars); volume data is ready when current volume and the SMA are valid and the SMA is positive.
Calculation: Volume score = when volume data is ready, clamp(relative volume / volume-support threshold * score ceiling, score floor, score ceiling); otherwise use the missing-volume score.
Calculation: Breakout quality score = clamp(box compression score * compression weight + volume score * volume weight + distance score * distance weight + close-location score * close-location weight + body score * body weight, score floor, score ceiling), where bar range = max(high - low, minimum tick size); distance score = clamp(directional close-to-box-boundary distance / ATR-safe / target breakout distance in ATR * score ceiling, score floor, score ceiling); close-location score = for an upward break, (close - low) / bar range * score ceiling, and for a downward break, (high - close) / bar range * score ceiling; body score = clamp(abs(close - open) / bar range * score ceiling, score floor, score ceiling).
Long: active Darvas box AND confirmed chart bar AND close above box top when close confirmation is enabled, otherwise high above box top AND (volume support is not required OR volume data is ready and relative volume >= volume-support threshold) AND breakout quality score >= minimum breakout score.
Short: active Darvas box AND confirmed chart bar AND close below box bottom when close confirmation is enabled, otherwise low below box bottom AND (volume support is not required OR volume data is ready and relative volume >= volume-support threshold) AND breakout quality score >= minimum breakout score.
Short: an upward break of an active Darvas box occurred on an earlier chart bar within the failure window AND current close < that box's top.
Long: a downward break of an active Darvas box occurred on an earlier chart bar within the failure window AND current close > that box's bottom.
