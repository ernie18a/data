Calculation: BaseSlope = (EMA(close, base EMA length) - EMA(close, base EMA length)[base slope lookback]) / ATR(ATR length)
Calculation: BullStack = long side enabled AND EMA(close, fast EMA length) > EMA(close, base EMA length) AND EMA(close, base EMA length) > EMA(close, slow EMA length) AND BaseSlope >= minimum base slope ATR
Calculation: BearStack = short side enabled AND EMA(close, fast EMA length) < EMA(close, base EMA length) AND EMA(close, base EMA length) < EMA(close, slow EMA length) AND BaseSlope <= -minimum base slope ATR
Calculation: LongContext = BullStack OR (LongContext[1] AND NOT BearStack AND close >= EMA(close, slow EMA length) - ATR(ATR length) * (MAX(band width ATR, rail buffer ATR) + hold offset ATR) AND BARSSINCE(BullStack) <= hold bars)
Calculation: ShortContext = BearStack OR (ShortContext[1] AND NOT BullStack AND close <= EMA(close, slow EMA length) + ATR(ATR length) * (MAX(band width ATR, rail buffer ATR) + hold offset ATR) AND BARSSINCE(BearStack) <= hold bars)
Calculation: BandTouch = (LongContext OR ShortContext) AND low <= EMA(close, base EMA length) + ATR(ATR length) * band width ATR AND high >= EMA(close, base EMA length) - ATR(ATR length) * band width ATR
Calculation: CloseLocation = (close - low) / (high - low)
Calculation: VolumeRatio = volume / SMA(volume, volume length)
Calculation: LongRail = MIN(EMA(close, base EMA length) - ATR(ATR length) * (band width ATR + rail buffer ATR), EMA(close, slow EMA length) - ATR(ATR length) * rail buffer ATR * rail slow factor)
Calculation: ShortRail = MAX(EMA(close, base EMA length) + ATR(ATR length) * (band width ATR + rail buffer ATR), EMA(close, slow EMA length) + ATR(ATR length) * rail buffer ATR * rail slow factor)
Calculation: LongSlopeScore = CLAMP((BaseSlope - minimum base slope ATR) / slope span ATR * 100, 0, 100)
Calculation: ShortSlopeScore = CLAMP((-BaseSlope - minimum base slope ATR) / slope span ATR * 100, 0, 100)
Calculation: LongRoomScore = IF close > HIGHEST(high, target lookback)[1] THEN 100 ELSE CLAMP((MAX(HIGHEST(high, target lookback)[1] - close, 0) / ATR(ATR length) - minimum room ATR) / (clean room ATR - minimum room ATR) * 100, 0, 100)
Calculation: ShortRoomScore = IF close < LOWEST(low, target lookback)[1] THEN 100 ELSE CLAMP((MAX(close - LOWEST(low, target lookback)[1], 0) / ATR(ATR length) - minimum room ATR) / (clean room ATR - minimum room ATR) * 100, 0, 100)
Calculation: LongPullbackAtr = MAX(EMA(close, fast EMA length) - low, 0) / ATR(ATR length)
Calculation: ShortPullbackAtr = MAX(high - EMA(close, fast EMA length), 0) / ATR(ATR length)
Calculation: LongScore = ROUND(CLAMP(trend weight * (stack share * 100 + slope share * LongSlopeScore) + pullback weight * CLAMP(MIN(LongPullbackAtr / ideal pullback ATR, (deep pullback ATR - LongPullbackAtr) / (deep pullback ATR - ideal pullback ATR)) * 100, 0, 100) + close points + volume weight * CLAMP(VolumeRatio / volume need * 100, 0, 100) + room weight * LongRoomScore, 0, 100))
Calculation: ShortScore = ROUND(CLAMP(trend weight * (stack share * 100 + slope share * ShortSlopeScore) + pullback weight * CLAMP(MIN(ShortPullbackAtr / ideal pullback ATR, (deep pullback ATR - ShortPullbackAtr) / (deep pullback ATR - ideal pullback ATR)) * 100, 0, 100) + close points + volume weight * CLAMP(VolumeRatio / volume need * 100, 0, 100) + room weight * ShortRoomScore, 0, 100))
Long: BullStack AND BARSSINCE(BandTouch) <= acceptance window bars AND close > EMA(close, base EMA length) AND CloseLocation >= close location need AND close >= open AND close >= LongRail AND LongScore >= accepted threshold AND (bar is confirmed OR realtime entry enabled) AND (VolumeRatio >= volume need OR NOT volume confirmation enabled) AND ((LongSlopeScore >= strict slope floor AND LongRoomScore >= strict room floor) OR NOT strict confirmation enabled)
Long: BullStack AND BARSSINCE(BandTouch) <= acceptance window bars AND close > EMA(close, base EMA length) AND CloseLocation >= close location need AND close >= open AND close >= LongRail AND LongScore >= accepted threshold AND LongScore >= alert threshold AND (bar is confirmed OR realtime entry enabled) AND (VolumeRatio >= volume need OR NOT volume confirmation enabled) AND ((LongSlopeScore >= strict slope floor AND LongRoomScore >= strict room floor) OR NOT strict confirmation enabled)
Short: BearStack AND BARSSINCE(BandTouch) <= acceptance window bars AND close < EMA(close, base EMA length) AND 1 - CloseLocation >= close location need AND close <= open AND close <= ShortRail AND ShortScore >= accepted threshold AND (bar is confirmed OR realtime entry enabled) AND (VolumeRatio >= volume need OR NOT volume confirmation enabled) AND ((ShortSlopeScore >= strict slope floor AND ShortRoomScore >= strict room floor) OR NOT strict confirmation enabled)
Short: BearStack AND BARSSINCE(BandTouch) <= acceptance window bars AND close < EMA(close, base EMA length) AND 1 - CloseLocation >= close location need AND close <= open AND close <= ShortRail AND ShortScore >= accepted threshold AND ShortScore >= alert threshold AND (bar is confirmed OR realtime entry enabled) AND (VolumeRatio >= volume need OR NOT volume confirmation enabled) AND ((ShortSlopeScore >= strict slope floor AND ShortRoomScore >= strict room floor) OR NOT strict confirmation enabled)
Exit: Long, close < LongRail AND LongContext
Exit: Short, close > ShortRail AND ShortContext
