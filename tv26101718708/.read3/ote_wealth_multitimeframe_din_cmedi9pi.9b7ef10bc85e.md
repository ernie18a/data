Calculation: Accepted OTE(T) = on T bars, detect confirmed PivotHigh(high, pivot sensitivity) and PivotLow(low, pivot sensitivity); for an upswing ending at a pivot high, anchor at the lowest confirmed pivot low between the previous confirmed pivot high and the candidate high, or at the most recent earlier pivot low if deep anchoring is off or no in-window low exists; for a downswing ending at a pivot low, use the highest confirmed pivot high between the previous confirmed pivot low and the candidate low, or the most recent earlier pivot high under the same fallback; if there is no previous same-type pivot, use the T-specific lookback window as the anchor search start. Require the anchor-to-end span to be at least the minimum leg length and no greater than the T-specific lookback, and the candidate pivot's age at confirmation to be no greater than that lookback. Require the upswing high to exceed its anchor low or the downswing low to be below its anchor high. Apply the selected BOS filter (upswing high exceeds the previous confirmed pivot high, or downswing low is below the previous confirmed pivot low; pass if no previous same-type pivot exists) and selected ATR displacement filter (leg range meets the displacement threshold times ATR(ATR lookback) on the pivot confirmation bar; pass if ATR is unavailable or the threshold is nonpositive). Retain no more than the pivot-history capacity of each pivot type and retain the latest accepted leg. Run on current T bars or the previous completed T bar according to the confirmation setting, and request T values with lookahead off; each enabled T has its own lookback parameter.
Calculation: New OTE(T) = a valid Accepted OTE(T) exists on the current chart bar and its pivot-end time, direction, swing high, or swing low differs from the prior chart-bar returned state.
Calculation: OTE level price(direction, swing high, swing low, ratio) = swing high - (swing high - swing low) * ratio for a bullish direction; swing low + (swing high - swing low) * ratio for a bearish direction. Use separate parameters for the shallow OTE ratio, intermediate ratio, sweet-spot ratio, core-deep ratio, and deepest/invalidation ratio; the core shallow ratio selects the shallow OTE or intermediate ratio.
Calculation: First overlap(condition, zone) = condition on the current chart bar AND (the zone was created on the current chart bar OR condition was false on the prior chart bar for that same zone).
Long: For any enabled T1 through T5, New OTE(T) is bullish.
Short: For any enabled T1 through T5, New OTE(T) is bearish.
Long: On chart bars, for any active bullish OTE returned from an enabled T1 through T5, First overlap(high >= min(OTE level price(bullish, swing high, swing low, shallow OTE ratio), OTE level price(bullish, swing high, swing low, deepest/invalidation ratio)) AND low <= max(the same two level prices), zone).
Short: On chart bars, for any active bearish OTE returned from an enabled T1 through T5, First overlap(high >= min(OTE level price(bearish, swing high, swing low, shallow OTE ratio), OTE level price(bearish, swing high, swing low, deepest/invalidation ratio)) AND low <= max(the same two level prices), zone).
Long: On chart bars, for any active bullish OTE returned from an enabled T1 through T5, First overlap(high >= min(OTE level price(bullish, swing high, swing low, core shallow ratio), OTE level price(bullish, swing high, swing low, core-deep ratio)) AND low <= max(the same two level prices), zone).
Short: On chart bars, for any active bearish OTE returned from an enabled T1 through T5, First overlap(high >= min(OTE level price(bearish, swing high, swing low, core shallow ratio), OTE level price(bearish, swing high, swing low, core-deep ratio)) AND low <= max(the same two level prices), zone).
Long: On chart bars, for any active bullish OTE returned from an enabled T1 through T5, First overlap(high >= OTE level price(bullish, swing high, swing low, sweet-spot ratio) AND low <= OTE level price(bullish, swing high, swing low, sweet-spot ratio), zone).
Short: On chart bars, for any active bearish OTE returned from an enabled T1 through T5, First overlap(high >= OTE level price(bearish, swing high, swing low, sweet-spot ratio) AND low <= OTE level price(bearish, swing high, swing low, sweet-spot ratio), zone).
Exit: long, on chart bars an active bullish OTE returned from an enabled T1 through T5 is invalidated when low is below its deepest/invalidation level if wick invalidation is selected, otherwise when close is below that level.
Exit: short, on chart bars an active bearish OTE returned from an enabled T1 through T5 is invalidated when high is above its deepest/invalidation level if wick invalidation is selected, otherwise when close is above that level.
