Calculation: Analog score = clamp the weighted average of shape score, normalized error score, and regime score using separate shape, error, and regime weights (use shape score if their sum is zero); shape score = clamp(50 × (Pearson correlation + 1), 0, 100) for current and candidate close patterns normalized from each pattern’s oldest close using the selected log-return or percent-change mode; normalized error score = 100 / (1 + RMSE × error sensitivity × 100); regime score = 100 when regime filtering is disabled, otherwise calculate trend scores as 100 / (1 + absolute difference between current and candidate (close − EMA(close, trend lookback)) / ATR(ATR lookback)), volatility scores as max(0, 100 − absolute percentage difference between current and candidate ATR / close), combine trend and volatility scores using separate weights, and multiply by the regime penalty factor when the result is below the regime tolerance.
Calculation: Historical analogs = on chart bars, scan candidate end offsets from Pattern Length + Projection Length + start margin through min(Historical Search Depth, available bars − Pattern Length − trend lookback − end margin), stepping by Scan Step; retain candidates whose analog score is at least Minimum Similarity, then select up to three highest-scoring candidates separated by Minimum Match Spacing.
Calculation: Consensus endpoint = the analog-score-weighted mean of the selected candidates’ smoothed projected prices at Projection Length; each candidate’s raw projected price at step s is current close × close[candidate end offset − s] / close[candidate end offset], and its smoothed price is the mean of raw projected prices from max(0, s − smoothing length + 1) through s.
Long: Consensus endpoint is defined AND Consensus endpoint >= close
Short: Consensus endpoint is defined AND Consensus endpoint < close
