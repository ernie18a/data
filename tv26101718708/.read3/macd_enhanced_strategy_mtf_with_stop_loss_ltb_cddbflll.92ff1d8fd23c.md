Calculation: MACD score = A + B + C + X, where M, S, and H are the MACD line, signal line, and histogram of MACD(fast lookback, slow lookback, signal lookback); A = if M > M[1] then (if H > H[1] then indicator-direction weight + histogram-direction weight else indicator-direction weight) else (if H == H[1] then indicator-direction weight else indicator-direction weight - histogram-direction weight); B = if M < M[1] then (if H < H[1] then -(indicator-direction weight + histogram-direction weight) else -indicator-direction weight) else (if H == H[1] then -indicator-direction weight else -(indicator-direction weight - histogram-direction weight)); C = if M == M[1] then (if H > H[1] then histogram-direction weight else if H < H[1] then -histogram-direction weight else 0) else 0; X = current cross contribution + cross-persistence parameter × X[1], where current cross contribution is cross weight if M >= S and M[1] < S[1], -cross weight if M <= S and M[1] > S[1], and 0 otherwise.
Calculation: Result = (MACD score on chart bars + timeframe-dependent weight × MACD score calculated on higher timeframe T1 bars and sampled on chart bars using the lookahead setting) / (1 + timeframe-dependent weight); T1 is higher than the chart timeframe, and the lookahead setting selects the last completed or still-forming T1 bar.
Long: Result != Result[1] AND Result > 0
Short: Result != Result[1] AND Result < 0
