Calculation: ATR trailing stop = on each source-timeframe bar, initialize prior stop and prior direction to 0; let distance = ATR(ATR lookback) × ATR multiplier; long trigger when prior direction is not long and high > prior stop; short trigger when prior direction is not short and low < prior stop; current stop = high + distance if short trigger, else low − distance if long trigger, else max(low − distance, prior stop) if prior direction is long, else min(high + distance, prior stop) if prior direction is short, else prior stop; current direction = long if long trigger, else short if short trigger, else prior direction
Calculation: Timeframe direction = independently for the chart timeframe and T1, T2, and T3, initialize to 0 and update on each chart bar to short if chart low ≤ that timeframe's stop, else long if chart high ≥ that timeframe's stop, else retain the prior direction; calculate the chart-timeframe stop on chart bars and each T1/T2/T3 stop on that timeframe's bars, using its last completed bar's stop on chart bars
Long: all four timeframe directions are long AND chart-bar datetime is on or after the configured start timestamp and on or before the configured end timestamp
Short: all four timeframe directions are short AND chart-bar datetime is on or after the configured start timestamp and on or before the configured end timestamp
Exit: long, chart-bar datetime is before the configured start timestamp or after the configured end timestamp OR (the sum of the four timeframe directions is ≤ 0 AND at least one timeframe direction is not short)
Exit: short, chart-bar datetime is before the configured start timestamp or after the configured end timestamp OR (the sum of the four timeframe directions is ≥ 0 AND at least one timeframe direction is not long)
