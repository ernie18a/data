Calculation: TrendSlope = (EMA(close, shorter EMA lookback) - EMA(close, longer EMA lookback)) / ATR(ATR lookback)
Calculation: PulseZScore = (close - SMA(close, pulse lookback)) / STDEV(close, pulse lookback)
Calculation: RangeLocation = (close - mid) / half range, where mid = (Highest(high, range lookback) + Lowest(low, range lookback)) / 2 and half range = (Highest(high, range lookback) - Lowest(low, range lookback)) / 2
Calculation: UpBreak = close > latest confirmed PivotHigh(pivot left, pivot right) AND a PivotHigh was confirmed since the last UpBreak
Calculation: DownBreak = close < latest confirmed PivotLow(pivot left, pivot right) AND a PivotLow was confirmed since the last DownBreak
Calculation: StructureDirection = up after UpBreak, down after DownBreak, otherwise unchanged
Calculation: SellSideSweep = low < level - sweep depth * ATR(ATR lookback) AND close > level, for some equal-low level not yet swept; an equal-low level is created when a PivotLow is confirmed within equal-level tolerance * ATR(ATR lookback) of the previous confirmed PivotLow, takes that new PivotLow as its level, and is retired after its first sweep; at most max tracked liquidity levels are kept, dropping the oldest
Calculation: BuySideSweep = high > level + sweep depth * ATR(ATR lookback) AND close < level, for some equal-high level not yet swept, with equal-high levels created from PivotHigh values as in SellSideSweep
Calculation: LiquidityPressure = sweep decay * LiquidityPressure[1], set to +1 when SellSideSweep and to -1 when BuySideSweep
Calculation: OrderBlockPressure = clamp(sum over active order blocks of s, -1, 1), where s = +1 for a bullish block and -1 for a bearish block when close is within [bottom - ATR(ATR lookback), top + ATR(ATR lookback)] of the block, else 0; an UpBreak creates a bullish block with top and bottom equal to the high and low of the latest bar among the previous order-block search lookback bars whose close is below its open, and a DownBreak creates a bearish block from the latest such bar whose close is above its open; a bullish block becomes inactive when close < bottom and a bearish block when close > top; only the most recent max active order blocks are kept
Calculation: UpProbability = logistic(w0 + sum over i of w_i * z_i), where x = (TrendSlope, OrderBlockPressure, LiquidityPressure, RangeLocation, PulseZScore, (close - close[momentum lookback]) / (ATR(ATR lookback) * sqrt(momentum lookback))) is clamped to a fixed symmetric range, z_i = clamp((x_i - mean_i) / sqrt(variance_i)) with mean_i and variance_i as EWMAs (smoothing = standardization smoothing) updated with the current x before use, and once per bar the weights take one gradient step on log-loss plus L2 penalty (ML learning rate, L2 penalty; no penalty on w0) using the x from forecast horizon bars ago, standardized with the current statistics, with label = 1 if close > close[forecast horizon] else 0
Calculation: RegimeState = 9 * BiasBin + 3 * VolatilityBin + PulseBin, where each bin is 0 if its value is below minus its band, 2 if above its band, else 1; BiasBin uses TrendSlope with bias band, VolatilityBin uses (ATR(ATR lookback) - SMA(ATR(ATR lookback), volatility lookback)) / STDEV(ATR(ATR lookback), volatility lookback) with volatility band, and PulseBin uses PulseZScore with pulse band
Calculation: Stance = argmax over {flat, long, short} of Q(RegimeState, action), ties going to the earliest in that order, after Q(RegimeState[1], Stance[1]) is updated: Q(RegimeState[1], Stance[1]) = Q(RegimeState[1], Stance[1]) + RL learning rate * (reward + RL discount * max over actions of Q(RegimeState, action) - Q(RegimeState[1], Stance[1])), with reward = BarReturn if Stance[1] is long, -BarReturn if short, and -flat penalty * abs(BarReturn) if flat, where BarReturn = (close - close[1]) / ATR(ATR lookback)
Long: bar index > warm-up length AND UpProbability > upper probability threshold AND (RL gate disabled OR Stance == long) AND (UpProbability crosses above upper probability threshold OR UpBreak OR LiquidityPressure > sweep trigger threshold) AND (confluence filter disabled OR (StructureDirection == up AND (OrderBlockPressure > 0 OR LiquidityPressure > 0) AND RangeLocation < range threshold))
Short: bar index > warm-up length AND UpProbability < lower probability threshold AND (RL gate disabled OR Stance == short) AND (UpProbability crosses below lower probability threshold OR DownBreak OR LiquidityPressure < -sweep trigger threshold) AND (confluence filter disabled OR (StructureDirection == down AND (OrderBlockPressure < 0 OR LiquidityPressure < 0) AND RangeLocation > -range threshold))
Long: UpBreak
Short: DownBreak
Long: a PivotHigh(pivot left, pivot right) is confirmed on this bar AND it is higher than the previous confirmed PivotHigh
Long: a PivotLow(pivot left, pivot right) is confirmed on this bar AND it is higher than the previous confirmed PivotLow
Short: a PivotHigh(pivot left, pivot right) is confirmed on this bar AND it is not higher than the previous confirmed PivotHigh
Short: a PivotLow(pivot left, pivot right) is confirmed on this bar AND it is not higher than the previous confirmed PivotLow
Long: SellSideSweep
Short: BuySideSweep
Long: PulseZScore < -stretch threshold
Short: PulseZScore > stretch threshold
