Calculation: Cloud line = if Andean Oscillator bullish line > bearish line, max(previous cloud line, min(EMA(close, EMA lookback), EMA(linear regression(close, regression lookback, offset 0), regression smoothing lookback), AlphaTrend(RSI(close, RSI lookback), SMA(true range, ATR lookback), ATR multiplier)[2])); else if bearish line > bullish line, min(previous cloud line, max(the same three values)); else previous cloud line
Calculation: Cloud trend = +1 when cloud line is greater than each of its prior two values; -1 when it is less than each of its prior two values; otherwise its prior value
Calculation: Rolling pivot low = lowest value over the pivot stop lookback of the carried-forward latest confirmed pivot low, where a pivot low uses the pivot confirmation lookback on both sides
Calculation: Rolling pivot high = highest value over the pivot stop lookback of the carried-forward latest confirmed pivot high, where a pivot high uses the pivot confirmation lookback on both sides
Calculation: Long stop = rolling pivot low when cloud trend changes to +1; otherwise its prior value while cloud trend is +1; otherwise rolling pivot low
Calculation: Short stop = rolling pivot high when cloud trend changes to -1; otherwise its prior value while cloud trend is -1; otherwise rolling pivot high
Calculation: Tracked low = current low when flat; otherwise current low if it is below the prior bar's low, else its prior value
Calculation: Tracked high = current high when flat; otherwise current high if it is above the prior bar's high, else its prior value
Calculation: Long-entry lock, initialized to 0 = 1 when cloud trend changes to +1; else 0 when re-entry is enabled and tracked low crosses below long stop; else 1 while long; else 0 when cloud trend is -1; else its prior value
Calculation: Short-entry lock, initialized to 0 = 1 when cloud trend changes to -1; else 0 when re-entry is enabled and tracked high crosses above short stop; else 1 while short; else 0 when cloud trend is +1; else its prior value
Long: long entries enabled AND the condition (cloud trend > 0 AND close > cloud line AND chart-bar time strictly between the configured start and end times AND position is flat or short) changes value from the prior bar AND prior long-entry lock = 0
Short: short entries enabled AND the condition (cloud trend < 0 AND close < cloud line AND chart-bar time strictly between the configured start and end times AND position is flat or long) changes value from the prior bar AND prior short-entry lock = 0
Exit: Long, cloud trend changes to -1 OR (stop/target exits enabled AND (low <= long stop OR high >= entry price + (entry price - rolling pivot low captured at the signal) * first reward/risk parameter OR high >= entry price + (entry price - rolling pivot low captured at the signal) * second reward/risk parameter))
Exit: Short, cloud trend changes to +1 OR (stop/target exits enabled AND (high >= short stop OR low <= entry price - (rolling pivot high captured at the signal - entry price) * first reward/risk parameter OR low <= entry price - (rolling pivot high captured at the signal - entry price) * second reward/risk parameter))
