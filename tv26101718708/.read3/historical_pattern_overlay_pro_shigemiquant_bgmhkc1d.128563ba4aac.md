Calculation: Top1 match = the eligible historical close window with the lowest NormalizedMatchDistance, among chart-symbol and enabled cross-symbol windows ending from pattern lookback + projection length through pattern lookback + projection length + history scan depth − 1 bars ago, bounded by available history; discard windows with missing closes or a zero anchor, and apply configured session and event-date filters (the session filter applies only when the chart timeframe is below T1).
Calculation: Top1 projection = Top1 match’s close projection length bars after its window end × current close / Top1 match’s close at its window end.
