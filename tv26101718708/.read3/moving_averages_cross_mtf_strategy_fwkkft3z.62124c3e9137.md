Calculation: First moving average = selected SMA/EMA/DEMA/TEMA/WMA/VWMA/SMMA/Hull/LSMA/ALMA(first source, first lookback, first LSMA offset, first ALMA offset, first ALMA sigma), calculated on chart bars when its alternate-timeframe option is disabled, or on T1 bars and sampled on chart bars when enabled (using the still-forming T1 bar in real time and the last completed T1 bar historically)
Calculation: Second moving average = selected SMA/EMA/DEMA/TEMA/WMA/VWMA/SMMA/Hull/LSMA/ALMA(second source, second lookback, second LSMA offset, second ALMA offset, second ALMA sigma), calculated on chart bars when its alternate-timeframe option is disabled, or on T2 bars and sampled on chart bars when enabled (using the still-forming T2 bar in real time and the last completed T2 bar historically)
Calculation: Long trigger count = count of eligible long triggers, including the current trigger, since the latest short trigger; reset on a long exit or whenever the latest trigger state is not long
Calculation: Short trigger count = count of eligible short triggers, including the current trigger, since the latest long trigger; reset on a short exit or whenever the latest trigger state is not short
Calculation: Long average entry price = mean of closes on long entry-condition bars since the latest short entry condition; reset on a long exit or whenever the latest entry-condition state is not long
Calculation: Short average entry price = mean of closes on short entry-condition bars since the latest long entry condition; reset on a short exit or whenever the latest entry-condition state is not short
Calculation: Long running high = highest high on chart bars while the latest entry-condition state is long; reset when that state is not long
Calculation: Short running low = lowest low on chart bars while the latest entry-condition state is short; reset when that state is not short
Long: ((flip-opens option is disabled AND First moving average crosses above Second moving average) OR (flip-opens option is enabled AND First moving average crosses below Second moving average)) AND short-only option is disabled AND (Long trigger count <= lower long-count parameter OR Long trigger count >= upper long-count parameter OR Long trigger count = equal long-count parameter)
Short: ((flip-opens option is disabled AND First moving average crosses below Second moving average) OR (flip-opens option is enabled AND First moving average crosses above Second moving average)) AND long-only option is disabled AND (Short trigger count <= lower short-count parameter OR Short trigger count >= upper short-count parameter OR Short trigger count = equal short-count parameter)
Exit: long, no long entry condition AND ((take-profit option is enabled AND close > Long average entry price + Long average entry price / 100 * (take-profit parameter / 100)) OR (stop-loss option is enabled AND close < Long average entry price - Long average entry price / 100 * (stop-loss parameter / 100)) OR (trailing-stop option is enabled AND Long running high exists AND Long running high >= Long average entry price + Long average entry price / 100 * (activation parameter / 100) AND low <= Long running high - Long running high / 100 * (trailing-distance parameter / 100)))
Exit: short, no short entry condition AND ((take-profit option is enabled AND close < Short average entry price - Short average entry price / 100 * (take-profit parameter / 100)) OR (stop-loss option is enabled AND close > Short average entry price + Short average entry price / 100 * (stop-loss parameter / 100)) OR (trailing-stop option is enabled AND Short running low exists AND Short running low <= Short average entry price - Short average entry price / 100 * (activation parameter / 100) AND high >= Short running low + Short running low / 100 * (trailing-distance parameter / 100)))
