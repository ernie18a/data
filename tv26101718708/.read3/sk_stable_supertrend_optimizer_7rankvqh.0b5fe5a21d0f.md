Calculation: Grid score = the configured optimization metric on simulated trades within the trailing learning window; the first in-window close sets the entry, each later Supertrend direction flip closes the trade at that close and resets the entry, and each return is the signed percentage return for the previous direction. Scores are unavailable until the minimum closed-trade count. Metrics are win rate = wins/trades × 100, net profit = sum of returns, profit factor = gross profit/gross loss (99 if gross loss is zero and gross profit is positive, otherwise 0), total trades, average trade = sum of returns/trades, reward/risk = average winning return/average absolute losing return (99 if there are no losses and average win is positive, otherwise 0), gross profit, total wins, or win/loss ratio (99 if there are no losses and at least one win, otherwise 0).
Calculation: Active Supertrend direction = manual Supertrend direction using the manual lookback and multiplier in Manual mode; otherwise use the highest-scoring grid pair in Best Single mode, or the interior pair with the highest mean score across itself and its immediately adjacent pairs on both grid axes in Stable Zone mode, falling back to the highest-scoring pair if no complete neighborhood is scored. Grid lookbacks and multipliers are separate ascending sequences from their respective start and step parameters; ties select the earliest pair in lookback-then-multiplier order.
Calculation: Grid agreement = 100 × the number of grid pairs whose Supertrend direction equals the active direction ÷ the total number of grid pairs.
Calculation: Long momentum score = (close > EMA(close, fast momentum lookback)) + (EMA(close, fast momentum lookback) > EMA(close, slow momentum lookback)) + (RSI(close, RSI lookback) >= long RSI threshold) + (close > close[1]) + (volume confirmation disabled OR volume >= SMA(volume, volume lookback)).
Calculation: Short momentum score = (close < EMA(close, fast momentum lookback)) + (EMA(close, fast momentum lookback) < EMA(close, slow momentum lookback)) + (RSI(close, RSI lookback) <= short RSI threshold) + (close < close[1]) + (volume confirmation disabled OR volume >= SMA(volume, volume lookback)).
Calculation: ATR percentage = close != 0 ? 100 × ATR(close, manual Supertrend lookback) / close : 0.
Calculation: Bars since last signal = current chart-bar index minus the chart-bar index of the most recent long or short signal; undefined before the first signal.
Long: Active Supertrend direction is bullish.
Short: Active Supertrend direction is bearish.
Long: Active Supertrend direction is bullish AND a best grid score exists AND grid agreement >= minimum agreement AND minimum ATR percentage <= ATR percentage <= maximum ATR percentage AND (momentum filter disabled OR long momentum score >= minimum momentum score).
Short: Active Supertrend direction is bearish AND a best grid score exists AND grid agreement >= minimum agreement AND minimum ATR percentage <= ATR percentage <= maximum ATR percentage AND (momentum filter disabled OR short momentum score >= minimum momentum score).
Long: ((active direction was bearish on the previous chart bar AND is bullish on the current chart bar) OR (pullback entries enabled AND active direction was bullish on the previous and current chart bars AND close crosses above EMA(close, fast momentum lookback) AND close > EMA(close, slow momentum lookback))) AND (trend filter disabled OR close > EMA(close, trend lookback)) AND (momentum filter disabled OR long momentum score >= minimum momentum score) AND a best grid score exists AND grid agreement >= minimum agreement AND minimum ATR percentage <= ATR percentage <= maximum ATR percentage AND (bars since last signal undefined OR bars since last signal > cooldown).
Short: ((active direction was bullish on the previous chart bar AND is bearish on the current chart bar) OR (pullback entries enabled AND active direction was bearish on the previous and current chart bars AND close crosses below EMA(close, fast momentum lookback) AND close < EMA(close, slow momentum lookback))) AND (trend filter disabled OR close < EMA(close, trend lookback)) AND (momentum filter disabled OR short momentum score >= minimum momentum score) AND a best grid score exists AND grid agreement >= minimum agreement AND minimum ATR percentage <= ATR percentage <= maximum ATR percentage AND (bars since last signal undefined OR bars since last signal > cooldown).
