Calculation: context bias = RSI contribution weight * RSI bias + volume contribution weight * volume bias
Calculation: MTF bias score = bias score scale * (chart context weight * context bias from the last completed chart bar + T1 weight * context bias calculated on T1 bars from the last completed T1 bar + T2 weight * context bias calculated on T2 bars from the last completed T2 bar)

Calculation: upper break level = upper pattern boundary + breakout buffer(upper pattern boundary); lower break level = lower pattern boundary - breakout buffer(lower pattern boundary)
Calculation: symmetrical upper confirmation = max(upper break level, internal pattern high + breakout buffer(upper pattern boundary)); symmetrical lower confirmation = min(lower break level, internal pattern low - breakout buffer(lower pattern boundary))
Calculation: retest tolerance(level) = max(abs(level) * retest percentage tolerance / 100, ATR(chart bars, ATR lookback) * retest ATR tolerance)
Calculation: failed-break tolerance(level) = max(ATR(chart bars, ATR lookback) * failed-break ATR tolerance, abs(level) * failed-break percentage tolerance / 100)
Calculation: risk is valid(entry, stop, side) = stop < entry for long or stop > entry for short, and abs(entry - stop) / max(abs(entry), minimum price increment) * 100 <= maximum risk percentage, and abs(entry - stop) / max(ATR(chart bars, ATR lookback), minimum price increment) <= maximum risk ATR
