Calculation: Window range(lookback) = IF(close > 0, (Highest(high, lookback) - Lowest(low, lookback)) / close * 100, N/A), evaluated on T1 bars using the current bar while it is forming
Calculation: Base percentage = IF(Highest(high, base lookback) > 0, (Highest(high, base lookback) - Lowest(low, base lookback)) / Highest(high, base lookback) * 100, N/A), evaluated on T1 bars using the current bar while it is forming
Calculation: Relative volume = IF(SMA(volume, longer volume-average lookback) > 0, volume / SMA(volume, longer volume-average lookback), N/A), evaluated on T1 bars using the current bar while it is forming
Calculation: Pivot percentage = IF(Highest(high[1], pivot lookback) > 0, (close / Highest(high[1], pivot lookback) - 1) * 100, N/A), evaluated on T1 bars using the current bar while it is forming
Calculation: Contraction score = IF(Highest(high, base lookback) > 0 AND Base percentage >= minimum base depth AND Base percentage <= maximum base depth, base-depth points, 0) + IF(close > 0 AND Window range(short range lookback) < Window range(medium range lookback) * short-to-medium range factor, short-to-medium range points + right-side tightness points, 0) + IF(close > 0 AND Window range(medium range lookback) < Window range(long range lookback) * medium-to-long range factor, medium-to-long range points, 0) + IF(ATR(short ATR lookback) < ATR(medium ATR lookback) * short-to-medium ATR factor, short-to-medium ATR points, 0) + IF(ATR(medium ATR lookback) < ATR(long ATR lookback) * medium-to-long ATR factor, medium-to-long ATR points, 0) + IF(SMA(volume, longer volume-average lookback) > 0 AND Relative volume < current-volume dry-up threshold AND SMA(volume, shorter volume-average lookback) / SMA(volume, longer volume-average lookback) < average-volume dry-up threshold, volume dry-up points, 0), evaluated on T1 bars using the current bar while it is forming
Calculation: Trend qualification = SMA(close, intermediate trend-average lookback) > SMA(close, long trend-average lookback) AND SMA(close, long trend-average lookback) > SMA(close, long trend-average lookback)[slope lookback] AND SMA(close, short trend-average lookback) > SMA(close, intermediate trend-average lookback) AND SMA(close, short trend-average lookback) > SMA(close, long trend-average lookback) AND close > SMA(close, short trend-average lookback) AND close >= Lowest(low, extreme-range lookback) * low-price multiplier AND close >= Highest(high, extreme-range lookback) * high-price multiplier, evaluated on T1 bars using the current bar while it is forming
Long: Trend qualification AND Contraction score >= minimum contraction score AND Pivot percentage >= -ready-zone distance AND Pivot percentage <= 0, evaluated on T1 bars using the current bar while it is forming
