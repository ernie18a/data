Calculation: T1 high samples = H0 is the high of the last completed T1 bar, sampled on each chart bar; H1 = H0[n]; H2 = H0[2n], where n is a chart-bar offset parameter
Calculation: T1 low samples = L0 is the low of the last completed T1 bar, sampled on each chart bar; L1 = L0[n]; L2 = L0[2n], using the same n
Calculation: Bullish MA alignment = close > MA(close, L1) > MA(close, L2) > MA(close, L3) > MA(close, L4) > MA(close, L5) > MA(close, L6) > MA(close, L7), where L1 through L7 are seven strictly increasing lookback parameters and the selected MA type is EMA, SMA, HMA, RMA, VWMA, or WMA
Calculation: Long ATR trailing stop = max(close − ATR(ATR lookback) × ATR multiplier, prior value of this stop) while long
Long: crossover(close, Donchian upper(entry lookback)[1]) AND (yearly high/low filter disabled OR (((H0 missing OR H1 missing) ? true : H0 > H1) AND ((H0 missing OR H2 missing) ? true : H0 > H2)) OR (H0 missing ? true : H1 missing ? close > H0 : H2 missing ? close > max(H0,H1) : close > max(H0,min(H1,H2)))) AND (new high/low filter disabled OR highest(high, shorter high/low lookback) = highest(high, longer high/low lookback)) AND (MA alignment filter disabled OR bullish MA alignment was true on at least one of the last MA-alignment lookback chart bars)
Short: crossunder(close, Donchian lower(entry lookback)[1]) AND (yearly high/low filter disabled OR (((L0 missing OR L1 missing) ? true : L0 < L1) AND ((L0 missing OR L2 missing) ? true : L0 < L2)) OR (L0 missing ? true : L1 missing ? close < L0 : L2 missing ? close < min(L0,L1) : close < min(L0,max(L1,L2)))) AND (new high/low filter disabled OR lowest(low, shorter high/low lookback) = lowest(low, longer high/low lookback))
Exit: long, crossunder(close, Donchian lower(exit lookback)[1]) OR (DC exit mode selected AND low <= Donchian lower(exit lookback)) OR (ATR trailing-stop mode selected AND low <= Long ATR trailing stop)
Exit: short, crossover(close, Donchian upper(exit lookback)[1])
