Calculation: Entry risk distance = ATR(ATR lookback, T1 current value sampled on the entry chart bar with lookahead off) * ATR stop parameter
Long: On chart bars using T1 values requested with lookahead off (current T1 bar, which may be forming in realtime; [1] means the previous chart-bar sample), HMA(configured Hull source, shorter fast lookback, T1) > HMA(configured Hull source, longer slow lookback, T1); a push latch is set when high(T1) - HMA(configured Hull source, reference lookback, T1) >= separation parameter * ATR(ATR lookback, T1), then a pullback latch is set when low(T1) - HMA(configured Hull source, reference lookback, T1) <= tolerance parameter * ATR(ATR lookback, T1) (on or after the push bar); the setup is unexpired (counting the pullback bar, within the expiry parameter in chart bars) and has not fired; the configured trigger mode is prior-chart-bar high break (close(T1) > previous chart-bar sample of high(T1)), reference reclaim (crossover of close(T1) above HMA(configured Hull source, reference lookback, T1) on chart bars), or either; MACD filter is disabled or MACD histogram(MACD(configured MACD source, shorter fast lookback, longer slow lookback, signal lookback, T1)) > its previous chart-bar sample; session filter is disabled or chart-bar datetime is within the configured entry session; selected order quantity > 0; and position is flat or flip is enabled and position is short. Reset push and pullback latches when the regime ends, pullback age exceeds expiry, or the raw long trigger fires.
Short: On chart bars using T1 values requested with lookahead off (current T1 bar, which may be forming in realtime; [1] means the previous chart-bar sample), HMA(configured Hull source, shorter fast lookback, T1) < HMA(configured Hull source, longer slow lookback, T1); a push latch is set when HMA(configured Hull source, reference lookback, T1) - low(T1) >= separation parameter * ATR(ATR lookback, T1), then a pullback latch is set when HMA(configured Hull source, reference lookback, T1) - high(T1) <= tolerance parameter * ATR(ATR lookback, T1) (on or after the push bar); the setup is unexpired (counting the pullback bar, within the expiry parameter in chart bars) and has not fired; the configured trigger mode is prior-chart-bar low break (close(T1) < previous chart-bar sample of low(T1)), reference reclaim (crossunder of close(T1) below HMA(configured Hull source, reference lookback, T1) on chart bars), or either; MACD filter is disabled or MACD histogram(MACD(configured MACD source, shorter fast lookback, longer slow lookback, signal lookback, T1)) < its previous chart-bar sample; session filter is disabled or chart-bar datetime is within the configured entry session; selected order quantity > 0; and position is flat or flip is enabled and position is long. Reset push and pullback latches when the regime ends, pullback age exceeds expiry, or the raw short trigger fires.
Exit: Long, low <= entry-signal chart close - entry risk distance captured at entry OR high >= entry-signal chart close + entry risk distance captured at entry * reward-risk parameter
Exit: Short, high >= entry-signal chart close + entry risk distance captured at entry OR low <= entry-signal chart close - entry risk distance captured at entry * reward-risk parameter
