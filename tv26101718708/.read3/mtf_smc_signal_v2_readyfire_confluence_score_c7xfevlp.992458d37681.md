Calculation: EMA direction(T) = on T bars, bullish when close > EMA(close, shared EMA lookback) and EMA(close, shared EMA lookback) > its prior value; bearish when close < EMA(close, shared EMA lookback) and EMA(close, shared EMA lookback) < its prior value; otherwise neutral. Use the last completed T bar. T1 and T2 are higher than chart bars, with T2 longer than T1; both use the same EMA lookback.
Calculation: Structure state = on chart bars, track PivotHigh(high, same swing lookback on both sides) and PivotLow(low, same swing lookback on both sides). A close above the latest unbroken pivot high emits an upward event, sets bias bullish, classifies the event as CHoCH if prior bias was neutral or bearish and BOS otherwise, then clears that pivot. A close below the latest unbroken pivot low emits a downward event, sets bias bearish, classifies it as CHoCH if prior bias was neutral or bullish and BOS otherwise, then clears that pivot. Store the latest event direction, type, and bar.
Calculation: Active chart FVG zones = when FVG detection is enabled, on confirmed chart bars create a bullish zone [high[2], low] if low > high[2], close[1] > high[2], and low - high[2] >= FVG size multiple × ATR(ATR lookback); create a bearish zone [high, low[2]] if high < low[2], close[1] < low[2], and low[2] - high >= FVG size multiple × ATR(ATR lookback). Remove a bullish zone when close < its bottom and a bearish zone when close > its top.
Calculation: T4 FVG state = on the latest available T4 bar, including the bar still forming, track the latest bullish zone [high[2], low] when low > high[2] and close[1] > high[2], and the latest bearish zone [high, low[2]] when high < low[2] and close[1] < low[2]. Clear a bullish zone when close < its bottom and a bearish zone when close > its top.
Calculation: Range equilibrium = (Highest(high, FVG range lookback) + Lowest(low, FVG range lookback)) / 2 on chart bars; discount is close < equilibrium and premium is close > equilibrium.
Calculation: FVG distance(direction) = the smallest distance from close to an active chart FVG zone in that direction, divided by ATR(ATR lookback); distance is zero inside a zone and undefined when no such zone exists.
Calculation: FVG grade = for the current direction's retested basis zone, S if it overlaps the matching active T4 FVG and daily-grade scoring is enabled; otherwise A if close is in discount for bullish direction or premium for bearish direction; otherwise B. Grade is absent when there is no basis zone.
Calculation: Ready state = on confirmed chart bars, set bullish Ready on the first post-creation touch of an unfilled bullish chart FVG (high >= zone bottom and low <= zone top), and bearish Ready on the corresponding bearish FVG touch. Store the touch bar and basis zone; retain Ready until it fires or its age exceeds the setup window.
Calculation: Reversal confirmation = bullish engulfing (close > open, open <= close[1], close > open[1], close > high[1]) or bullish pin bar (high > low, close - low > (high - low) × bullish body ratio, high - close < (high - low) × bullish wick ratio) or upward CHoCH/BOS or, when lower-timeframe breakout confirmation is enabled, the latest available T3 close exceeds the highest high of the preceding T3 lookback bars. Bearish confirmation uses the inverse engulfing and pin-bar comparisons, downward CHoCH/BOS, or latest available T3 close below the preceding T3 lookback bars' lowest low. The T3 breakout is evaluated on chart bars using T3 values, including the latest T3 bar still forming.
Calculation: Setup score = zero when bias is neutral; otherwise the capped sum of: structure points when the latest event is within the setup window and its direction matches bias; FVG points of zero when distance is undefined, grade-specific exact-zone points when distance is zero, near-zone points when distance is above zero and at most the FVG proximity cutoff, otherwise zero; and directional position points when bullish bias is in discount or bearish bias is in premium. Use separate parameters for the cap, each point value, and the proximity cutoff.
Calculation: Execution score = zero when bias is neutral; otherwise the capped sum of event-freshness points and FVG-retest-precision points. Freshness points use separate values for event age through the newest-event cutoff, through the next freshness cutoff, and through the setup window, and zero thereafter. Retest-precision points are zero for undefined distance, the exact-zone value at zero distance, the near-zone value through the FVG proximity cutoff, and the farther-zone value beyond it. Use separate parameters for the cap, cutoffs, and point values.
Calculation: Confluence score = round(setup weight × Setup score + execution weight × Execution score).
