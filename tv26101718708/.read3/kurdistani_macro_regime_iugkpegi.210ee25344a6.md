Calculation: T2 observations = federal funds rate, ECB policy rate, 10-year, 2-year, and 30-year yields, VIX, TIPS inflation compensation, high-yield and investment-grade credit spreads, and emerging-market spread values mapped onto chart bars from T2; historical bars use the last completed T2 bar and realtime bars use the T2 bar still forming.
Calculation: T3 observations = real GDP values mapped onto chart bars from T3; historical bars use the last completed T3 bar and realtime bars use the T3 bar still forming.
Calculation: Inflation proxy = if Change(CPI observation) != zero then ROC(CPI observation, CPI chart-bar lookback) else CPI fallback parameter.
Calculation: Previous inflation proxy = if Change(CPI observation) != zero then ROC(CPI observation, CPI chart-bar lookback)[previous chart bar] else previous CPI fallback parameter.
Calculation: GDP growth = ROC(real GDP observation, GDP chart-bar lookback).
Calculation: M2 growth = ROC(M2 observation, M2 chart-bar lookback).
Calculation: PMI proxy = PMI offset parameter + RSI(manufacturing employment observation, PMI RSI lookback) * PMI scale parameter.
Calculation: Real rate = federal funds rate - inflation proxy.
Calculation: Yield curve slope = 10-year yield - 2-year yield.
Calculation: Long yield slope = 30-year yield - 2-year yield.
Calculation: Policy rate spread = federal funds rate - ECB policy rate.
Calculation: Credit spread = high-yield credit spread - investment-grade credit spread.
Calculation: VIX score = high-VIX penalty if VIX > high-VIX threshold, low-VIX reward if VIX < low-VIX threshold, otherwise zero.
Calculation: Trend classification(current, previous) = UP if current > previous * trend-up multiplier, DN if current < previous * trend-down multiplier, otherwise FL.
Calculation: Inflation trend = Trend classification(inflation proxy, previous inflation proxy).
Calculation: GDP trend = Trend classification(GDP growth, GDP growth[previous chart bar]).
Calculation: Growth score = (GDP growth > high-growth threshold ? high-GDP-growth points : GDP growth > moderate-growth threshold ? moderate-GDP-growth points : GDP growth < zero ? negative-GDP-growth points : zero) + (PMI proxy > high-PMI threshold ? high-PMI points : PMI proxy > moderate-PMI threshold ? moderate-PMI points : PMI proxy < low-PMI threshold ? negative-PMI points : zero) + (unemployment rate < low-unemployment threshold ? low-unemployment points : unemployment rate > high-unemployment threshold ? high-unemployment penalty : zero) + (GDP trend is UP ? rising-GDP-trend points : GDP trend is DN ? falling-GDP-trend points : zero).
Calculation: Inflation score = (inflation proxy > CPI hot threshold ? high-inflation points : inflation proxy > moderate-inflation threshold ? moderate-inflation points : inflation proxy < CPI cold threshold ? cold-inflation points : zero) + (Inflation trend is UP ? rising-inflation-trend points : Inflation trend is DN ? falling-inflation-trend points : zero).
Calculation: Liquidity score = (M2 growth > high-M2-growth threshold ? high-M2-growth points : M2 growth > moderate-M2-growth threshold ? moderate-M2-growth points : M2 growth < low-M2-growth threshold ? negative-M2-growth points : zero) + (federal funds rate < low-policy-rate threshold ? low-rate points : federal funds rate > high-policy-rate threshold ? high-rate penalty : zero) + (Yield curve slope < inverted-curve threshold ? inverted-curve points : Yield curve slope > positive-curve threshold ? positive-curve points : zero) + VIX score / VIX-score divisor.
Calculation: Expansion regime = Growth score >= expansion growth threshold AND Inflation score < expansion inflation ceiling.
Calculation: Stagflation regime = Inflation score >= stagflation inflation threshold AND Growth score <= stagflation growth ceiling.
Calculation: Recession regime = Growth score <= recession growth threshold.
Calculation: Recovery regime = Growth score >= recovery growth threshold AND Inflation score < recovery inflation ceiling.
Calculation: Recession probability = minimum of its cap and (Yield curve slope < severe-inversion threshold ? severe-inversion points : Yield curve slope < flat-curve threshold ? mild-inversion points : zero) + (unemployment rate > unemployment rate[previous chart bar] * unemployment-rise multiplier ? rising-unemployment points : zero) + (PMI proxy < low-PMI threshold ? low-PMI points : PMI proxy < moderate-PMI threshold ? moderate-PMI points : zero) + (GDP growth < zero ? negative-GDP-growth points : GDP growth < low-GDP-growth threshold ? low-GDP-growth points : zero) + (Real rate > high-real-rate threshold ? high-real-rate points : zero) + (Credit spread > wide-credit-spread threshold ? wide-credit-spread points : zero).

Calculation: Risk-on = Risk score >= risk-on threshold.
Calculation: Risk-off = Risk score <= risk-off threshold.
Calculation: Federal pivot probability = minimum of its cap and pivot points for each condition: Yield curve slope > Yield curve slope at pivot lookback chart bars ago; federal funds rate > pivot rate threshold; unemployment rate > pivot unemployment threshold; inflation proxy < pivot inflation threshold; GDP growth < pivot GDP threshold.
Calculation: Milkshake score = minimum of its cap and (policy rate spread > high-rate-spread threshold ? high-rate-spread points : policy rate spread > moderate-rate-spread threshold ? moderate-rate-spread points : zero) + (emerging-market spread > high-emerging-spread threshold ? high-emerging-spread points : emerging-market spread > moderate-emerging-spread threshold ? moderate-emerging-spread points : zero) + (Credit spread > high-credit-spread threshold ? high-credit-spread points : Credit spread > moderate-credit-spread threshold ? moderate-credit-spread points : zero) + (VIX > high-milkshake-VIX threshold ? high-VIX-milkshake points : VIX > moderate-milkshake-VIX threshold ? moderate-VIX-milkshake points : zero) + (Real rate > high-milkshake-real-rate threshold ? high-real-rate-milkshake points : zero).
Calculation: Rate weight = recession rate weight in Recession regime, expansion rate weight in Expansion regime, otherwise base rate weight.
Calculation: Inflation weight = stagflation inflation weight in Stagflation regime, expansion inflation weight in Expansion regime, otherwise base inflation weight.
Calculation: Liquidity weight = recession liquidity weight in Recession regime, recovery liquidity weight in Recovery regime, otherwise base liquidity weight.
Calculation: Growth weight = expansion growth weight in Expansion regime, recession growth weight in Recession regime, otherwise base growth weight.
