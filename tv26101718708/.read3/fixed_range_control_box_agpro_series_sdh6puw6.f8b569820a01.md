Calculation: Active range = In pivot mode, take the latest confirmed pivot high and pivot low using the pivot-length parameter; set the upper and lower bounds to their maximum and minimum, and the origin to the earlier pivot bar. Rebuild when both pivots exist, the bounds pass the minimum-width test (midpoint > 0 and width / midpoint × 100 ≥ the minimum-width parameter), either bound differs from the current range by more than tick size × the pivot-change threshold, and rebuilding is eligible. In lookback mode, use the highest high and lowest low over the lookback window; in compression mode, use the highest high and lowest low over the compression window; in both modes rebuild on each eligible bar when the bounds pass the minimum-width test. Rebuilding is eligible when there is no current range, the current range is failed, or its age meets the minimum-lifespan parameter, and, if failed, the failed cooldown has elapsed. In manual mode, start a range from the first bar within the start and end datetime parameters and expand its bounds to include each bar within that window while it is not failed. Freeze a range when it fails; reset control state and counters when a range is rebuilt.
Calculation: Control line = volume-weighted average of typical price (high + low + close) / 3 from the range origin through the prior bar when a range is created, then updated by adding each active bar; use volume 1 when unavailable. If there is no weight, use the range midpoint. If the weighted average is outside the range after excluding the edge-buffer fraction of its width from both ends, use the midpoint.
Calculation: Control state = Failed when close > the active range upper bound or close < its lower bound; otherwise Upper when the above-control counter ≥ the reclaim-count parameter; otherwise Lower when the below-control counter ≥ the reclaim-count parameter; otherwise Inside unless the previous state was Failed. The control source is close in strict mode; in loose mode it is high when close > the control line and low otherwise. When the source is above the control line, increment the above-control counter and reset the below-control counter; when below, increment the below-control counter and reset the above-control counter; when equal, leave both unchanged.
Long: control state is Upper
Short: control state is Lower
