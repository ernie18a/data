Calculation: VA_HIGH and VA_LOW = value area bounds per T1 period from chart bars: RH and RL = highest high and lowest low of chart bars from the period's first bar through the current bar; s = (RH - RL) / bin count; bin i for i = 0 to bin count spans prices from RH - s*(i+1) inclusive to RH - s*i exclusive; c_i = number of chart-bar closes from the period's second bar through the current bar that fall in bin i; POC = bin with the highest c_i, ties to the bin with the larger index; target = value-area fraction x sum of all c_i; u = d = POC; sum = c_POC; repeat bin count + 1 times: if sum < target, u = max(0, u - 1) and sum += c_u; if sum < target, d = min(bin count, d + 1) and sum += c_d; VA_HIGH = RH - s*u; VA_LOW = RH - s*(d+1); the previous T1 period's VA_HIGH and VA_LOW are the values taken at that period's last chart bar
Calculation: ZONES = clusters of MEMBERS, where MEMBERS = for each enabled pivot timeframe among T1 to T4, classic pivot points P, R1, S1, R2, S2 of its last completed bar, plus R3 and S3 if R3 enabled; for each enabled high/low timeframe among T1 to T5, high and low of its last completed bar; if value area enabled, previous-period VA_HIGH and VA_LOW; THRESH = ATR(ATR length, T6) of the currently forming T6 bar x ATR multiplier if threshold mode is ATR, percent threshold / 100 x close if threshold mode is percent, tick count x tick size if threshold mode is ticks; sort MEMBERS ascending; a cluster starts at its lowest member and adds each next member while that member minus the cluster's lowest member <= THRESH; a cluster with at least minimum level count members is a zone with lower bound = its lowest member and upper bound = its highest member
Long: any zone in ZONES has upper bound < close AND side coloring enabled
Short: any zone in ZONES has lower bound > close AND side coloring enabled
