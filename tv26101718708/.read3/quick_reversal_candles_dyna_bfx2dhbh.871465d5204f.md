Calculation: Activity value = volume when cumulative volume through the signal bar is positive; otherwise high - low, on the signal bar.
Calculation: Activity points = component point cap × clamp((Activity value / max(SMA(Activity value, activity average lookback) ending on the signal bar, minimum price increment) - 1) / max(activity multiplier - 1, activity denominator floor), 0, 1).
Calculation: Guarded ATR = max(ATR(ATR lookback) on the signal bar, minimum price increment).
Calculation: Bullish conviction score = base pattern points + Activity points + component point cap × clamp(1 - (signal low - lowest(low, swing lookback) ending on the signal bar) / (Guarded ATR × maximum swing distance in ATR), 0, 1) + component point cap × clamp((close[prior-move lookback] - signal close) / (Guarded ATR × minimum prior move in ATR), 0, 1), where close[prior-move lookback] is measured from the signal bar.
Calculation: Bearish conviction score = base pattern points + Activity points + component point cap × clamp(1 - (highest(high, swing lookback) ending on the signal bar - signal high) / (Guarded ATR × maximum swing distance in ATR), 0, 1) + component point cap × clamp((signal close - close[prior-move lookback]) / (Guarded ATR × minimum prior move in ATR), 0, 1), where close[prior-move lookback] is measured from the signal bar.
