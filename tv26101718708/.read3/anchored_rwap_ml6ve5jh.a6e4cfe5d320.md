Calculation: Anchored recency-weighted price = sum(source × decay^age) / sum(decay^age) since the selected timestamp, session, or calendar anchor, optionally limited to the latest maximum-window parameter; decay is either the fixed-decay parameter or the retained-weight parameter raised to the reciprocal of max(minimum-span-bars parameter, round(memory-span parameter × bars per trading day)); intraday bars per trading day is the median bar count over the day-sample parameter of most recent completed trading days, otherwise use calendar conversion.
Calculation: Normalized slope = (anchored recency-weighted price − anchored recency-weighted price[lookback]) / ATR(ATR lookback).
Calculation: Directional state = neutral when the anchor is inactive or reset, or the normalized slope is unavailable; otherwise, from bullish state switch to bearish when normalized slope ≤ −directional threshold, else to neutral when normalized slope < max(directional threshold − hysteresis width, 0), else remain bullish; from bearish state switch to bullish when normalized slope ≥ directional threshold, else to neutral when normalized slope > −max(directional threshold − hysteresis width, 0), else remain bearish; from neutral state switch to bullish when normalized slope ≥ directional threshold, switch to bearish when normalized slope ≤ −directional threshold, else remain neutral; when bar-close confirmation is enabled, hold the prior state until bar close.
Long: chart-timeframe directional state is bullish.
Short: chart-timeframe directional state is bearish.
Long: directional state calculated on each enabled slower timeframe T1 or T2 is bullish, using the selected last completed or forming T1 or T2 bar and mapping its value onto chart bars.
Short: directional state calculated on each enabled slower timeframe T1 or T2 is bearish, using the selected last completed or forming T1 or T2 bar and mapping its value onto chart bars.
