Calculation: Trend basis = EMA(EMA(hlc3, trend lookback), smoothing lookback)
Calculation: Smoothed ATR = EMA(ATR(ATR lookback), smoothing lookback)
Calculation: Bullish trail = if Bullish trail[1] is undefined then Trend basis - Smoothed ATR * trail distance, else if close < Bullish trail[1] then Trend basis - Smoothed ATR * trail distance, else max(Trend basis - Smoothed ATR * trail distance, Bullish trail[1])
Calculation: Bearish trail = if Bearish trail[1] is undefined then Trend basis + Smoothed ATR * trail distance, else if close > Bearish trail[1] then Trend basis + Smoothed ATR * trail distance, else min(Trend basis + Smoothed ATR * trail distance, Bearish trail[1])
Calculation: Bullish confirmation count = number of true conditions among EMA(close, shorter lookback) > EMA(close, longer lookback); RSI(close, RSI lookback) > bullish RSI threshold; MACD(close, fast lookback, slower lookback, signal lookback) line > signal line and histogram > zero; Stochastic(high, low, close, lookback) %K > SMA(%K, smoothing lookback) and %K > bullish Stochastic threshold; CCI(hlc3, lookback) > zero; DMI(lookback, lookback) +DI > -DI and ADX >= minimum ADX; ROC(close, lookback) > zero; MFI(hlc3, volume, lookback) > bullish MFI threshold; OBV(close, volume) > EMA(OBV(close, volume), lookback); close > session VWAP(hlc3)
Calculation: Bearish confirmation count = number of true conditions among EMA(close, shorter lookback) < EMA(close, longer lookback); RSI(close, RSI lookback) < bearish RSI threshold; MACD(close, fast lookback, slower lookback, signal lookback) line < signal line and histogram < zero; Stochastic(high, low, close, lookback) %K < SMA(%K, smoothing lookback) and %K < bearish Stochastic threshold; CCI(hlc3, lookback) < zero; DMI(lookback, lookback) -DI > +DI and ADX >= minimum ADX; ROC(close, lookback) < zero; MFI(hlc3, volume, lookback) < bearish MFI threshold; OBV(close, volume) < EMA(OBV(close, volume), lookback); close < session VWAP(hlc3)
Calculation: Trend state = initially bullish if close >= Trend basis and bearish otherwise; thereafter retain the current side until a qualifying Long or Short signal sets it to that side
Long: Trend state is bullish
Short: Trend state is bearish
Long: confirmed bar AND Trend state is bearish AND close > Bearish trail AND close > Trend basis AND Bullish confirmation count >= required confirmations
Short: confirmed bar AND Trend state is bullish AND close < Bullish trail AND close < Trend basis AND Bearish confirmation count >= required confirmations
Exit: long, confirmed bar after the Long signal bar AND high >= Long signal close + Smoothed ATR on the Long signal bar * first target distance AND this target has not previously been reached since that signal
Exit: long, confirmed bar after the Long signal bar AND high >= Long signal close + Smoothed ATR on the Long signal bar * second target distance AND this target has not previously been reached since that signal
Exit: long, confirmed bar after the Long signal bar AND high >= Long signal close + Smoothed ATR on the Long signal bar * third target distance AND this target has not previously been reached since that signal
Exit: short, confirmed bar after the Short signal bar AND low <= Short signal close - Smoothed ATR on the Short signal bar * first target distance AND this target has not previously been reached since that signal
Exit: short, confirmed bar after the Short signal bar AND low <= Short signal close - Smoothed ATR on the Short signal bar * second target distance AND this target has not previously been reached since that signal
Exit: short, confirmed bar after the Short signal bar AND low <= Short signal close - Smoothed ATR on the Short signal bar * third target distance AND this target has not previously been reached since that signal
