Calculation: Change(X,T) = 100 * (close(X,T,current bar) - close(X,T,previous T bar)) / close(X,T,previous T bar), or 0 if the previous close is missing or zero; use the current still-forming T bar on chart bars and the previous completed T bar.
Calculation: Impact(X,T) = +1 for inverse measures when Change(X,T) < -P_move, -1 when Change(X,T) > P_move, else 0; inverse measures are the 10-year, 2-year, 20-year, and 30-year Treasury yields, USD/JPY, USD/CHF, equity breadth (% above its 200-day average), and Bitcoin price. For direct measures (VIX, US CPI year-over-year, USD/CNH, EUR/USD), return +1 when Change(X,T) > P_move, -1 when Change(X,T) < -P_move, else 0. For the US dollar index, return 0 when the T3 VIX close >= P_vix_dollar; otherwise use the inverse rule. For the Nikkei 225, Hang Seng, and global equity index, return -1 when Change(X,T3) > P_move, +1 when Change(X,T3) < -P_move and the T3 VIX close > P_vix_equity, else 0. For WTI crude oil, return -1 when its T3 close > P_oil and Change(X,T3) > P_move, or its close <= P_oil and Change(X,T3) < -P_move; return +1 when its close <= P_oil and Change(X,T3) > P_move, or its close > P_oil and Change(X,T3) < -P_move; else 0. For silver, return +1 when Change(X,T) > P_half, -1 when Change(X,T) < -P_half, else 0. Core measures (US dollar index, 10-year Treasury yield, USD/JPY, USD/CHF, VIX, silver) use T1, T2, and T3; all other measures use T3. Values are sampled on chart bars from the current still-forming T bar; VIX gates use T3.
Calculation: Macro bias(T) = Impact(US dollar index,T) + Impact(10-year Treasury yield,T) + Impact(USD/JPY,T) + Impact(USD/CHF,T) + Impact(VIX,T) + Impact(silver,T) + Impact(2-year Treasury yield,T3) + Impact(20-year Treasury yield,T3) + Impact(30-year Treasury yield,T3) + Impact(US CPI year-over-year,T3) + Impact(equity breadth,T3) + Impact(Nikkei 225,T3) + Impact(Hang Seng,T3) + Impact(global equity index,T3) + Impact(USD/CNH,T3) + Impact(EUR/USD,T3) + Impact(Bitcoin price,T3) + Impact(WTI crude oil,T3).
Calculation: Scenario = stagflationary when WTI close(T3) > P_oil and Change(reference gold price,T3) < -P_half; gold hedge active when WTI close(T3) > P_oil and Change(reference gold price,T3) > P_half; risk-off when WTI close(T3) < P_oil and Change(reference gold price,T3) > P_half and 10-year Treasury yield close(T3) > P_yield; reflationary when WTI close(T3) < P_oil and Change(reference gold price,T3) > P_half and 10-year Treasury yield close(T3) < P_yield; risk-on when WTI close(T3) < P_oil and Change(reference gold price,T3) < -P_half; mixed otherwise. Use current still-forming T3 values on chart bars.
Long: Impact(X,T) = +1 for any listed measure at its assigned timeframe, or Macro bias(T) >= P_bias for T1, T2, or T3, or Change(reference gold price,T) > P_move for T1, T2, or T3, or equity breadth close(T3) <= P_breadth_low, or Scenario is gold hedge active, risk-off, or reflationary.
Short: Impact(X,T) = -1 for any listed measure at its assigned timeframe, or Macro bias(T) <= -P_bias for T1, T2, or T3, or Change(reference gold price,T) < -P_move for T1, T2, or T3, or equity breadth close(T3) > P_breadth_high, or Scenario is risk-on.
