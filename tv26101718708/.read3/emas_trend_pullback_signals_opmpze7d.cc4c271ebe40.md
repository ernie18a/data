Calculation: long setup = EMA(source price, each of four short lookbacks in ascending order) has its shortest-lookback and longest-lookback values and both EMA(source price, shorter long lookback) and EMA(source price, longer long lookback) rising from their prior chart-bar values, with the shorter-long-lookback EMA above the longer-long-lookback EMA; at least one of the current or preceding bounce-lookback chart bars has open below the maximum of the four short EMAs, close above that maximum, and close above open; when the EMA50-touch filter is enabled, low <= EMA(source price, longest short lookback) on at least one of the current or preceding EMA50-touch-lookback chart bars; MACD histogram(close, fast lookback, slow lookback, signal smoothing) < 0 and, when the MACD-turn filter is enabled, its current value > its prior chart-bar value; maximum short EMA - minimum short EMA >= ATR(ATR lookback) * zone ATR-multiple threshold; when the short-EMA-position filter is enabled, minimum short EMA >= EMA(source price, longer long lookback); abs(EMA(source price, shorter long lookback) - EMA(source price, longer long lookback)) >= ATR(ATR lookback) * long-EMA ATR-multiple threshold; when the Stoch RSI filter is enabled, StochRSI K crosses above StochRSI D on at least one of the current or preceding Stoch-cross-lookback chart bars, and, when the extreme-zone filter is enabled, current StochRSI K < oversold threshold; when the T1 trend filter is enabled, EMA(close, shorter long lookback, T1 bar still forming) > EMA(close, longer long lookback, T1 bar still forming), with these T1 values sampled on chart bars using lookahead off. StochRSI K uses separate RSI lookback, stochastic lookback, and K-smoothing parameters; StochRSI D is SMA(StochRSI K, D-smoothing parameter).
Calculation: short setup = EMA(source price, each of four short lookbacks in ascending order) has its shortest-lookback and longest-lookback values and both EMA(source price, shorter long lookback) and EMA(source price, longer long lookback) falling from their prior chart-bar values, with the shorter-long-lookback EMA below the longer-long-lookback EMA; at least one of the current or preceding bounce-lookback chart bars has open above the minimum of the four short EMAs, close below that minimum, and close below open; when the EMA50-touch filter is enabled, high >= EMA(source price, longest short lookback) on at least one of the current or preceding EMA50-touch-lookback chart bars; MACD histogram(close, fast lookback, slow lookback, signal smoothing) > 0 and, when the MACD-turn filter is enabled, its current value < its prior chart-bar value; maximum short EMA - minimum short EMA >= ATR(ATR lookback) * zone ATR-multiple threshold; when the short-EMA-position filter is enabled, maximum short EMA <= EMA(source price, longer long lookback); abs(EMA(source price, shorter long lookback) - EMA(source price, longer long lookback)) >= ATR(ATR lookback) * long-EMA ATR-multiple threshold; when the Stoch RSI filter is enabled, StochRSI K crosses below StochRSI D on at least one of the current or preceding Stoch-cross-lookback chart bars, and, when the extreme-zone filter is enabled, current StochRSI K > overbought threshold; when the T1 trend filter is enabled, EMA(close, shorter long lookback, T1 bar still forming) < EMA(close, longer long lookback, T1 bar still forming), with these T1 values sampled on chart bars using lookahead off. StochRSI K uses separate RSI lookback, stochastic lookback, and K-smoothing parameters; StochRSI D is SMA(StochRSI K, D-smoothing parameter).
Calculation: pending first Long setup = a prior long setup captured as the first while none was pending; it remains pending through windowBars chart bars after capture and is cleared by a downtrend.
Calculation: pending first Short setup = a prior short setup captured as the first while none was pending; it remains pending through windowBars chart bars after capture and is cleared by an uptrend.

Short: short setup AND no pending first Short setup.
Short: short setup AND pending first Short setup AND chart bars since that first setup >= minimum spacing AND (configured same-direction cooldown is zero OR no prior subsequent Short signal OR chart bars since the most recent subsequent Short signal >= configured same-direction cooldown).
