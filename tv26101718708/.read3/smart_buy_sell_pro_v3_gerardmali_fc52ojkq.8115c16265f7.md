Calculation: False resistance breakout = latest resistance exists AND any close n bars ago > latest resistance for n from one through false-break lookback AND close < latest resistance
Calculation: False support breakdown = latest support exists AND any close n bars ago < latest support for n from one through false-break lookback AND close > latest support
