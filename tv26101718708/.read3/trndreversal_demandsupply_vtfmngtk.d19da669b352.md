Calculation: Most recent confirmed pivot high = high[right pivot lookback] from the latest confirmed pivot high using the shared left and right pivot lookbacks; update on each confirmation.
Calculation: Most recent confirmed pivot low = low[right pivot lookback] from the latest confirmed pivot low using the shared left and right pivot lookbacks; update on each confirmation.
Calculation: Demand-zone hit = a bar where low <= the top of any active demand zone; create each zone on a confirmed pivot low, with bottom = low[right pivot lookback] and top = bottom + ATR(ATR lookback)[right pivot lookback] * zone-width multiplier; remove it on its first hit.
Calculation: Supply-zone hit = a bar where high >= the bottom of any active supply zone; create each zone on a confirmed pivot high, with top = high[right pivot lookback] and bottom = top - ATR(ATR lookback)[right pivot lookback] * zone-width multiplier; remove it on its first hit.
Calculation: Volume delta = 0 if high = low, otherwise volume * (2 * close - high - low) / (high - low).
Calculation: Bullish structure break pending = set true when a demand-zone hit and close crosses above the most recent confirmed pivot high occur on the same bar; reset on each demand-zone hit before checking that bar's condition, and after a long signal.
Calculation: Bearish structure break pending = set true when a supply-zone hit and close crosses below the most recent confirmed pivot low occur on the same bar; reset on each supply-zone hit before checking that bar's condition, and after a short signal.
Long: Bullish structure break pending AND a new pivot low is confirmed using the shared left and right pivot lookbacks, with its low[right pivot lookback] greater than the preceding confirmed pivot low AND volume delta > SMA(volume delta, delta lookback) + standard deviation(volume delta, delta lookback) * standard-deviation multiplier.
Short: Bearish structure break pending AND a new pivot high is confirmed using the shared left and right pivot lookbacks, with its high[right pivot lookback] less than the preceding confirmed pivot high AND volume delta < SMA(volume delta, delta lookback) - standard deviation(volume delta, delta lookback) * standard-deviation multiplier.
