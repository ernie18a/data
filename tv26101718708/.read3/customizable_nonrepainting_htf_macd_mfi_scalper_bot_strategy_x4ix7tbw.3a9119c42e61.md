Calculation: Money-flow RSI = RSI(SUM(volume(T1 last completed bar) × hlc3(T1 last completed bar) when change(hlc3(T1 last completed bar)) > 0, MFI lookback), SUM(volume(T1 last completed bar) × hlc3(T1 last completed bar) when change(hlc3(T1 last completed bar)) < 0, MFI lookback)), calculated on chart bars using T1 values
Calculation: Long signal close = close on the most recent chart bar where (MACD(source from T1 last completed bar, shorter fast lookback, longer slow lookback, signal lookback; oscillator and signal moving averages each selectable as SMA or EMA), calculated on chart bars using T1 values, crosses above its signal line OR (Money-flow RSI crosses above the MFI lower threshold AND EMA(close from T1 last completed bar, ribbon lookback) > SMA(close from T1 last completed bar, same ribbon lookback)), calculated on chart bars using T1 values) AND (trend filter is off OR close > SMA(close from T1 last completed bar, trend lookback), calculated on chart bars using T1 values) AND (RSI filter is off OR RSI(close from T1 last completed bar, RSI lookback), calculated on chart bars using T1 values, < RSI threshold)
Long: (MACD(source from T1 last completed bar, shorter fast lookback, longer slow lookback, signal lookback; oscillator and signal moving averages each selectable as SMA or EMA), calculated on chart bars using T1 values, crosses above its signal line OR Money-flow RSI crosses above the MFI lower threshold) AND EMA(close from T1 last completed bar, ribbon lookback) > SMA(close from T1 last completed bar, same ribbon lookback), calculated on chart bars using T1 values AND (trend filter is off OR close > SMA(close from T1 last completed bar, trend lookback), calculated on chart bars using T1 values) AND (RSI filter is off OR RSI(close from T1 last completed bar, RSI lookback), calculated on chart bars using T1 values, < RSI threshold)
Exit: Long, close < (Long signal close − ATR(high, low, and close from T1 last completed bar, ATR lookback, calculated on chart bars using T1 values) × ATR multiplier) OR, after high reaches entry price + (Long signal close × trailing percentage), low falls below the highest high since activation − (Long signal close × trailing percentage) OR (take-profit is enabled AND high ≥ entry price × (1 + take-profit percentage))
