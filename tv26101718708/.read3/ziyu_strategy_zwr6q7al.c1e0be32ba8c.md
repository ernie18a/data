Calculation: Opening-range high = maximum chart-bar high during the configured opening session, reset each exchange day.
Calculation: Classic pivot resistances R1–R5 = Classic Pivot Points from the last completed T1 bar, sampled on chart bars; T1 represents the daily timeframe.
Calculation: Intermediate resistance levels R0.5, R1.5, R2.5, R3.5, R4.5 = respectively ORB high + abs(R1 − ORB high)/2, R1 + abs(R2 − R1)/2, R2 + abs(R3 − R2)/2, R3 + abs(R4 − R3)/2, R4 + abs(R5 − R4)/2.
Calculation: Daily setup count = reset to 0 during the opening session and at exchange-day end; otherwise increment the prior count when the opening range is complete, open < ORB high, high > ORB high, R1 > ORB high, and flat; otherwise retain the prior count.
Calculation: Setup low = low[1] on each bar where the opening range is complete, open < ORB high, high > ORB high, R1 > ORB high, flat, prior daily setup count < daily trade limit, and not in cooldown; retain the latest value until exchange-day end.
Calculation: Initial stop = min(entry price, entry price × (1 − configured stop percentage)) in percentage mode when the percentage is positive; when it is zero, use a separate fallback-percentage parameter in that formula; in previous-low mode use min(entry price, setup low).
Calculation: Trailing stop, updated while long and reset when flat or at exchange-day end = first candidate above the prior trailing stop in this order: R4 if high > R5; R3.5 if high > R4.5; R3 if high > R4; R2.5 if high > R3.5; R2 if high > R3; R1.5 if high > R2.5; R1 if high > R2; R0.5 if high > R1.5; ORB high if high > R0.5; otherwise retain the prior trailing stop.
Long: opening range complete AND flat AND prior daily setup count < daily trade limit AND outside the cooldown following the configured number of consecutive losing trades for the configured cooldown duration AND chart-bar time > configured start time AND chart-bar time < configured end time AND open < ORB high; submit a stop entry at ORB high.
Exit: long, low <= max(initial stop, trailing stop) OR chart-bar close time = close time of the current, still-forming T1 bar (evaluated on chart bars).
