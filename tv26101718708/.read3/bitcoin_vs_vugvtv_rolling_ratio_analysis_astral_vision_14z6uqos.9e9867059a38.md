Calculation: Composite normalized momentum = average of the range-normalized percentage return over the lookback period for Bitcoin price and the VUG/VTV ratio; each return is 100 × (current value − value one lookback period ago) ÷ value one lookback period ago, and each normalized return is 100 × (return − lowest return over the normalization period) ÷ (highest return over the normalization period − lowest return over the normalization period), or the scale midpoint if that range is zero.
Long: valuation mode AND composite normalized momentum < oversold threshold OR non-valuation mode AND composite normalized momentum >= scale midpoint
Short: valuation mode AND composite normalized momentum > overbought threshold OR non-valuation mode AND composite normalized momentum < scale midpoint
