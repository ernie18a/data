Calculation: Momentum shift = (OFPI[1] > OFPI[2] AND OFPI < OFPI[1]) OR (OFPI[1] < OFPI[2] AND OFPI > OFPI[1])
Calculation: Langlands state fields are zero before the warm-up length; afterward, L-score = tanh(sum over n from 1 through the Möbius lookback of percent price return from close[n] to close[n-1] * Mobius(n) / n^s, divided by sum of abs(Mobius(n) / n^s)); correlation = correlation(close, volume, Frobenius lookback); rank = normalized percentrank(ATR(high, low, close, ATR lookback), Frobenius lookback); correspondence error = abs(L-score - nz(correlation)); chart trend = sign(close - SMA(close, trend lookback)); T1 trend = sign(T1 close - SMA(T1 close, trend lookback))
Calculation: T1 close, RSI, SMA, and ATR are calculated on T1 bars and returned to chart bars with lookahead off; historical chart bars use the last completed T1 bar and realtime chart bars use the forming T1 bar

Calculation: Composite signal = clamp(weighted average of the first composition-arity strategy signals using their confidences, multiplied by (1 + chart trend * trend-mixing weight) and (1 + T1 trend * trend-mixing weight), to [-1, 1]; use zero if total confidence is zero)
Calculation: Agreement direction = 1 if at least the agreement-count parameter of selected strategy signals exceed the positive agreement cutoff, else -1 if at least that count are below the negative cutoff, else 0
Calculation: Market stress = ATR(high, low, close, ATR lookback) > SMA(ATR(high, low, close, ATR lookback), stress lookback) * stress factor
Calculation: Unified displayed score = clamp(10 * amplified score, -10, 10), where base score = L-score * L weight + Galois score * Galois weight + composite signal * operadic weight + correspondence score * correspondence weight; Galois score = market stress ? -rank : rank, overridden to -abs(Galois score) when T1 trend < 0; correspondence score = (1 - correspondence error) * sign(composite signal); for positive base score apply the common base amplification, the volatility amplification if market stress is false, the flow amplification if OFPI exceeds the positive score-flow cutoff, and the T1 amplification if T1 trend > 0; for negative base score apply the common base amplification, the volatility amplification if market stress is true, the flow amplification if OFPI is below the negative score-flow cutoff, and the T1 amplification if T1 trend < 0
Calculation: Signal allowed = (ATR(high, low, close, ATR lookback) > SMA(ATR(high, low, close, ATR lookback), chart volatility lookback) * volatility factor AND T1 ATR > SMA(the chart-bar series of T1 ATR values, T1 volatility lookback) * the same volatility factor) AND (chart trend != 0 OR T1 trend != 0)
