Calculation: Session CVD = three separate cumulative sums, one for each configured UTC session, of volume * (2 * (close - low) / (high - low) - 1) when high != low, otherwise 0; reset the sums at each UTC day boundary and select the active stream in Asian, London, then New York order.
Long: At a confirmed pivot low of the active Session CVD, using the same pivot-lookback parameter for bars on each side, compare with the previous confirmed pivot low from the same session: the current pivot-bar low is lower and the current CVD pivot is higher, OR the current pivot-bar low is higher and the current CVD pivot is lower.
Short: At a confirmed pivot high of the active Session CVD, using the same pivot-lookback parameter for bars on each side, compare with the previous confirmed pivot high from the same session: the current pivot-bar high is higher and the current CVD pivot is lower, OR the current pivot-bar high is lower and the current CVD pivot is higher.
