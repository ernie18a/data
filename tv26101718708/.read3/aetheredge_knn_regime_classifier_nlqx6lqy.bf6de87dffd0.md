Calculation: Bollinger width ratio = Bollinger bandwidth(close, BB lookback, BB deviation multiplier) / SMA(Bollinger bandwidth, width-average lookback), or the ratio fallback when the average is not positive
Calculation: Relative volume = volume / SMA(volume, volume-average lookback), or the ratio fallback when the average is not positive
Calculation: Regression slope percentage = the difference between linear regression of close at the current bar and at the oldest structure-lookback offset, divided by close and expressed as a percentage; use zero when close is not positive
Calculation: Range position = (close - lowest(low, structure lookback)) / (highest(high, structure lookback) - lowest(low, structure lookback)); use the range midpoint when highest high equals lowest low
Calculation: Feature vector = [clamp((ADX - ADX feature center) / ADX feature scale, feature bounds), clamp((DI+ - DI-) / DMI feature scale, feature bounds), clamp((Bollinger width ratio - BB width feature center) / BB width feature scale, feature bounds), clamp((RSI - RSI feature center) / RSI feature scale, feature bounds), clamp(log(relative volume) / volume feature scale, feature bounds), clamp(regression slope percentage / slope feature scale, feature bounds), range position mapped linearly to a centered interval, clamp(ROC(close, ROC lookback) / ROC feature scale, feature bounds)]; use separate feature centers, scales, and bounds as applicable
Calculation: Historical regime = Breakout if Bollinger width ratio > breakout width threshold AND relative volume > breakout volume threshold AND abs(ROC(close, ROC lookback)) > breakout ROC threshold; otherwise Reversal if (RSI > reversal high threshold OR RSI < reversal low threshold) AND sign(ROC(close, ROC lookback)) differs from its value at the reversal comparison lag; otherwise Trending Up if ADX > trend threshold AND DI+ > DI- AND regression slope percentage is positive; otherwise Trending Down if ADX > trend threshold AND DI- > DI+ AND regression slope percentage is negative; otherwise Range if ADX < range threshold AND Bollinger width ratio < range width threshold; otherwise Range
Calculation: Current regime = on each confirmed chart bar, the historical regime label with the greatest vote among the nearest min(neighbor-count parameter, retained-memory count) historical feature vectors; compare using the selected Euclidean distance (square root of summed squared component differences), Manhattan distance (sum of absolute component differences), or cosine distance (one minus cosine similarity, or the zero-vector fallback); use equal vote weights or inverse-distance weights of 1 / (distance + distance regularizer); break vote ties in the order Trending Up, Trending Down, Range, Breakout, Reversal; leave undefined until retained memory reaches the minimum-memory parameter; retain at most the memory-capacity parameter and discard oldest patterns first
Long: Current regime = Trending Up
Short: Current regime = Trending Down
