Calculation: timeframe sentiment points(T) = the sum of eight signed components evaluated on T bars: +1 if close > open, -1 if close < open, otherwise 0; +1 if (close - low) / (high - low) >= upper range-position threshold, -1 if <= lower range-position threshold, otherwise 0 (use the midpoint when high = low); +1 if EMA(close, short lookback) > EMA(close, medium lookback) > EMA(close, long lookback), -1 if the order is reversed, otherwise 0; +1 if RSI(close, RSI lookback) > upper RSI threshold, -1 if < lower RSI threshold, otherwise 0; +1 if MACD histogram(close, fast, slow, signal lookbacks) > 0, -1 if < 0, otherwise 0; +1 if close > open and volume > SMA(volume, volume lookback) * volume multiplier, -1 if close < open and the same volume condition holds, otherwise 0; +1 if Stochastic(close, high, low, stochastic lookback) > upper stochastic threshold, -1 if < lower stochastic threshold, otherwise 0; +1 if close rises at each step across the configured consecutive-close sequence, -1 if it falls at each step, otherwise 0. EMA lookbacks are ordered short < medium < long; MACD fast lookback is shorter than slow lookback.
Calculation: normalized timeframe sentiment(T) = round((timeframe sentiment points(T) - minimum possible points) / (maximum possible points - minimum possible points) * percentage scale); calculate indicators on T bars and use the current, potentially forming T bar's returned value on each chart bar.
Calculation: weighted total sentiment = round(normalized timeframe sentiment(T1) * T1 weight + normalized timeframe sentiment(T2) * T2 weight + normalized timeframe sentiment(T3) * T3 weight + normalized timeframe sentiment(T4) * T4 weight); use the current, potentially forming requested-timeframe values on chart bars.
Calculation: blended momentum-volume score = round(RSI(close, RSI lookback) * RSI weight + clamp(MACD histogram(close, MACD lookbacks) / close * MACD price scale + normalization offset, lower clip, upper clip) * MACD weight + clamp(Volume Oscillator(volume, short EMA lookback, long EMA lookback) + normalization offset, lower clip, upper clip) * volume weight); volume EMA lookbacks are ordered short < long. This calculation runs on chart bars.
Calculation: T4 recovery condition = (T4 close - lowest of T4 low values returned on chart bars over the range lookback) / max(highest of T4 high values returned on chart bars over the range lookback - lowest of those T4 low values, range floor) > recovery threshold AND T4 close > EMA(close, medium lookback, T4); the EMA runs on T4 bars, and chart bars use the current, potentially forming T4 bar. The lowest and highest run over chart bars taking returned T4 values.
Calculation: bias point count = count of these conditions, using current, potentially forming requested bars on chart bars: T5 close > T5 open; T5 close > EMA(close, medium lookback, T5); T4 close > T4 open; T4 close > EMA(close, medium lookback, T4); T4 close > EMA(close, long lookback, T4); T4 close > EMA(close, extended lookback, T4); EMA(close, medium lookback, T4) > EMA(close, long lookback, T4); T4 recovery condition. The EMAs run on their stated timeframe bars, with short < medium < long < extended lookbacks.
Calculation: regular bullish pivot divergence = on the latest two confirmed price pivot lows, using the same pivot lookback on each side, the latest pivot low < the preceding pivot low AND the blended momentum-volume score at the latest pivot bar > its value at the preceding pivot bar.
Calculation: regular bearish pivot divergence = on the latest two confirmed price pivot highs, using the same pivot lookback on each side, the latest pivot high > the preceding pivot high AND the blended momentum-volume score at the latest pivot bar < its value at the preceding pivot bar.
Calculation: hidden bullish pivot divergence = on the latest two confirmed price pivot lows, using the same pivot lookback on each side, the latest pivot low > the preceding pivot low AND the blended momentum-volume score at the latest pivot bar < its value at the preceding pivot bar.
Calculation: hidden bearish pivot divergence = on the latest two confirmed price pivot highs, using the same pivot lookback on each side, the latest pivot high < the preceding pivot high AND the blended momentum-volume score at the latest pivot bar > its value at the preceding pivot bar.
Calculation: bullish alignment across T1-T3 = normalized timeframe sentiment(T1), normalized timeframe sentiment(T2), and normalized timeframe sentiment(T3) are each >= bullish alignment threshold.
Calculation: bearish alignment across T1-T3 = normalized timeframe sentiment(T1), normalized timeframe sentiment(T2), and normalized timeframe sentiment(T3) are each <= bearish alignment threshold.
Calculation: bullish alignment across T1-T4 = bullish alignment across T1-T3 AND normalized timeframe sentiment(T4) >= bullish alignment threshold.
Calculation: bearish alignment across T1-T4 = bearish alignment across T1-T3 AND normalized timeframe sentiment(T4) <= bearish alignment threshold.
