Calculation: SSL state(T) = bullish if close > MA(high, SSL lookback, MA type), bearish if close < MA(low, SSL lookback, MA type), otherwise the prior state; calculate on each bar of T.
Calculation: Channel-width ratio = ATR(high, low, close, ATR lookback) > 0 ? abs(MA(high, SSL lookback, MA type) - MA(low, SSL lookback, MA type)) / ATR(high, low, close, ATR lookback) : 0; calculated on chart bars.
Calculation: Clamp(x, lower, upper) = min(max(x, lower), upper).
Calculation: Unit scale(x, lower, upper) = upper > lower ? Clamp((x - lower) / (upper - lower), unit interval lower bound, unit interval upper bound) : unit interval lower bound.
Calculation: Candle range = max(high - low, tick-size parameter).
Calculation: Body ratio = abs(close - open) / candle range.
Calculation: Long price-action points = flip points + Unit scale(long breakout distance, breakout scale lower bound, breakout scale upper bound) × breakout weight + body ratio × body weight + Clamp((close - low) / candle range, unit interval lower bound, unit interval upper bound) × close-location weight.
Calculation: Short price-action points = flip points + Unit scale(short breakout distance, breakout scale lower bound, breakout scale upper bound) × breakout weight + body ratio × body weight + Clamp((high - close) / candle range, unit interval lower bound, unit interval upper bound) × close-location weight.
Calculation: Long breakout distance = ATR(high, low, close, ATR lookback) > 0 ? max(close - MA(high, SSL lookback, MA type), 0) / ATR(high, low, close, ATR lookback) : 0.
Calculation: Short breakout distance = ATR(high, low, close, ATR lookback) > 0 ? max(MA(low, SSL lookback, MA type) - close, 0) / ATR(high, low, close, ATR lookback) : 0.
Calculation: Long RSI points = Unit scale(RSI(close, RSI lookback) - RSI midpoint, RSI-score lower bound, RSI-score upper bound) × RSI-score weight + (RSI(close, RSI lookback) > RSI(close, RSI lookback)[1] ? RSI momentum bonus : 0).
Calculation: Short RSI points = Unit scale(RSI midpoint - RSI(close, RSI lookback), RSI-score lower bound, RSI-score upper bound) × RSI-score weight + (RSI(close, RSI lookback) < RSI(close, RSI lookback)[1] ? RSI momentum bonus : 0).
Calculation: Long trend points = (+DI > -DI ? directional trend bonus : 0) + Unit scale(ADX, profile ADX threshold, profile ADX threshold + ADX-score span) × ADX-score weight + Clamp((+DI - -DI) / max(+DI + -DI, DI-sum floor), unit interval lower bound, unit interval upper bound) × DI-dominance weight + (ADX > ADX[1] ? ADX momentum bonus : 0), using DMI(high, low, close, DI lookback, ADX smoothing).
Calculation: Short trend points = (-DI > +DI ? directional trend bonus : 0) + Unit scale(ADX, profile ADX threshold, profile ADX threshold + ADX-score span) × ADX-score weight + Clamp((-DI - +DI) / max(+DI + -DI, DI-sum floor), unit interval lower bound, unit interval upper bound) × DI-dominance weight + (ADX > ADX[1] ? ADX momentum bonus : 0), using DMI(high, low, close, DI lookback, ADX smoothing).
Calculation: Volume points = volume or SMA(volume, volume lookback) missing, or SMA(volume, volume lookback) <= 0 ? missing-volume points : Unit scale(volume / SMA(volume, volume lookback), relative-volume lower bound, relative-volume upper bound) × relative-volume weight; calculated on chart bars.
Calculation: Regime points = Unit scale(channel-width ratio, profile channel-width threshold × lower width multiplier, profile channel-width threshold × upper width multiplier) × regime weight + (channel-width ratio > channel-width ratio[1] ? width-expansion bonus : 0).
Calculation: Long wick penalty = ((high - max(open, close)) / candle range > opposing-wick threshold ? ((high - max(open, close)) / candle range) × wick penalty weight : 0) + Unit scale(ATR(high, low, close, ATR lookback) > 0 ? abs(close - MA(low, SSL lookback, MA type)) / ATR(high, low, close, ATR lookback) : 0, extension scale lower bound, extension scale upper bound) × extension penalty weight.
Calculation: Short wick penalty = ((min(open, close) - low) / candle range > opposing-wick threshold ? ((min(open, close) - low) / candle range) × wick penalty weight : 0) + Unit scale(ATR(high, low, close, ATR lookback) > 0 ? abs(close - MA(high, SSL lookback, MA type)) / ATR(high, low, close, ATR lookback) : 0, extension scale lower bound, extension scale upper bound) × extension penalty weight.
Calculation: Long score = round(Clamp(long price-action points + long RSI points + long trend points + volume points + regime points - long wick penalty, score lower bound, score upper bound)).
Calculation: Short score = round(Clamp(short price-action points + short RSI points + short trend points + volume points + regime points - short wick penalty, score lower bound, score upper bound)).
