Calculation: Prior mean true range = SMA(TrueRange(high, low, close), baseline lookback)[1]
Calculation: Prior median volume = Median(volume, baseline lookback)[1]
Calculation: Price scale = max(TrueRange(high, low, close), prior mean true range, minimum price increment)
Calculation: Valid sample = current OHLC values are present, high >= max(open, close), low <= min(open, close), high >= low, volume > 0, close[1] is present, prior mean true range and prior median volume are present, prior median volume > 0, and all preceding baseline-lookback bars have valid OHLC and positive volume
Calculation: Valid sample count = consecutive valid samples since the last invalid sample; reset to zero on an invalid sample
Calculation: Participation weight = sqrt(min(volume / prior median volume, relative-volume cap) / relative-volume cap)
Calculation: Directional sample = participation weight * (body weight * (close - open) + close-location weight * (2 * close - high - low)) / price scale
Calculation: Rejection sample = participation weight * (min(open, close) - low - high + max(open, close)) / price scale
Calculation: Directional pressure = EMA(directional sample, alpha = 1 - 0.5^(1 / memory half-life)), seeded at zero and reset to zero on an invalid sample
Calculation: Rejection pressure = EMA(rejection sample, alpha = 1 - 0.5^(1 / memory half-life)), seeded at zero and reset to zero on an invalid sample
Calculation: Candidate phase = balance if abs(directional pressure) <= release-pressure threshold AND abs(rejection pressure) <= release-pressure threshold; otherwise rejection with the sign of rejection pressure if abs(rejection pressure) >= entry-pressure threshold AND abs(rejection pressure) >= rejection dominance ratio * abs(directional pressure); otherwise accumulation with the sign of directional pressure if abs(directional pressure) >= entry-pressure threshold AND (directional pressure + rejection pressure) * sign(directional pressure) > 0; otherwise the current rejection phase if the current phase is a rejection phase AND rejection pressure * sign(current phase) >= release-pressure threshold AND (directional pressure + rejection pressure) * sign(current phase) > 0; otherwise the current accumulation phase if the current phase is an accumulation phase AND directional pressure * sign(current phase) >= release-pressure threshold AND (directional pressure + rejection pressure) * sign(current phase) > 0 AND abs(rejection pressure) < rejection dominance ratio * abs(directional pressure); otherwise mixed pressure, using this priority order
Calculation: Confirmed phase = unavailable initially; on valid confirmed closes after the valid sample count reaches the maturity count, update to a different candidate phase after it persists for the confirmation count of consecutive eligible closes; a changed candidate restarts the count at one, and an invalid sample resets the phase to unavailable and clears the pending candidate and count
Calculation: Last accumulation direction = most recently confirmed accumulation direction; retain it through other phases, clear it on balance or a confirmed rejection phase opposite to it, and reset it to none on an invalid sample
Long: confirmed phase transitions to upward accumulation OR transitions to upward rejection while the preceding last accumulation direction is downward
Short: confirmed phase transitions to downward accumulation OR transitions to downward rejection while the preceding last accumulation direction is upward
