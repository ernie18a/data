Calculation: Return state = bucketize r = nz(close - close[1]) using z = (r - SMA(r, return lookback)) / STDEV(r, return lookback): strong down if z < -outer cutoff, down if z < -inner cutoff, flat if z <= inner cutoff, up if z <= outer cutoff, otherwise strong up; inner and outer cutoffs are symmetric, with outer greater than inner.
Calculation: Mahalanobis D² = (dx²·vy - 2·dx·dy·cxy + dy²·vx) / max(vx·vy - cxy², determinant floor), where x = log(volume + 1), y = abs(close - close[1]) / ATR(ATR lookback), dx = x - μx, dy = y - μy; initialize means from the first feature pair and variances and covariance from their starting parameters; before each confirmed-bar update, calculate D², then update each mean μ as μ + α·(feature - μ), each variance v as (1 - α)·(v + α·e²), and covariance cxy as (1 - α)·(cxy + α·ex·ey), where e is the feature minus its updated mean and α is the covariance EWMA rate.
Calculation: Anomaly event = Mahalanobis D² > anomaly threshold AND log(volume + 1) > its online EWMA mean.
Calculation: Expected-direction score = sum of each return state's ordinal score relative to flat multiplied by its probability in the normalized transition-count row keyed by current anomaly status and return state; initialize each transition count with a Laplace prior and, on each confirmed bar, increment the count keyed by previous anomaly status, previous return state, and current return state.
Long: Anomaly event AND (close > close[1] OR (bar confirmed AND warmup passed AND expected-direction score > expected-score threshold))
Short: Anomaly event AND (close < close[1] OR (bar confirmed AND warmup passed AND expected-direction score < -expected-score threshold))
