Calculation: Adaptive volatility = max((ATR(high, low, close, short ATR lookback) * short ATR weight + ATR(high, low, close, long ATR lookback) * long ATR weight + EMA(Parkinson volatility(high, low, close), Parkinson smoothing lookback) * Parkinson weight) / volatility normalizer, minimum tick size)
Calculation: MTF bias counts = on chart bars, count T1 and T2 values requested with lookahead off (last completed higher-timeframe bar historically and the developing bar in realtime); a timeframe is bullish when its close > EMA(close, medium EMA lookback) > EMA(close, long EMA lookback), bearish when its close < EMA(close, medium EMA lookback) < EMA(close, long EMA lookback); bull count and bear count are the respective totals
Calculation: Qualified trendlines = for each of three separate discovery lookbacks and each side, form straight lines through pairs of confirmed pivot lows for support or pivot highs for resistance, using separate left and right pivot lookbacks; test recent candidate pivots separated by at least discovery lookback * minimum anchor separation, and score recent score pivots within that lookback. A touch uses the pivot price for Wicks mode or the support candle's lower body edge / resistance candle's upper body edge for Bodies mode, and qualifies when its distance from the line is <= touch tolerance * historical adaptive volatility (or current adaptive volatility when historical ATR scoring is disabled); separate touch clusters by the cluster gap. Sample bars from current through the discovery lookback at a step of max(one bar, rounded discovery lookback / sampled-bar count); a support violation is close < line - violation tolerance * sampled adaptive volatility, and a resistance violation is close > line + violation tolerance * sampled adaptive volatility. A sample is respected when its range crosses the line and its body edge remains on the supported side. A line is valid when cluster count >= minimum clusters, fit score >= minimum fit, and violation rate <= maximum violation rate. Fit score = clamp(one - average touch distance / average touch tolerance); violation score = clamp(one - violation rate / maximum violation rate); respect score = clamp((two * respect hits - respect failures) / sample count); touch score = clamp(cluster count / (minimum clusters + cluster score offset)); rejection score = rejection count / touch count; wick score = average relevant wick fraction at touches; span score = newest-to-oldest touch span / discovery lookback; recency score = one - bars since newest touch / discovery lookback; confluence score = clamp(one - nearest distance from line to EMA(fast EMA lookback), EMA(medium EMA lookback), EMA(long EMA lookback), or VWAP(hlc3), divided by adaptive volatility and confluence distance scale). Raw quality is the weighted sum of those scores * quality scale * MTF quality multiplier. The MTF multiplier is neutral when MTF bias is disabled; otherwise it depends on agreement and conflict counts. Keep the highest raw-quality valid candidate per side and lookback when raw quality >= the configured creation floor and absolute slope / max(adaptive volatility, minimum tick) is within the configured slope bounds and its normalized angle is within the configured maximum. Merge same-side duplicates when their current and forward projected prices are within duplicate price distance * adaptive volatility and their slopes are within duplicate slope distance * adaptive volatility; replace a duplicate only with higher raw quality. Prune stored lines to the configured maximum by lowest display score. Effective quality = clamp(raw quality + confluence score * confluence boost - min(age penalty cap, bars since creation / age normalization * age penalty) - min(stale penalty cap, bars since touch / stale normalization * stale penalty)); display score = effective quality + recency * recency weight + cluster count * cluster weight + respect score * respect weight - distance from close to line / adaptive volatility * distance penalty. Rank stored lines by display score within each side; project each line to the current chart bar.
Calculation: Signal filter = the configured filter mode passes when it is None, when its Trend component passes, when its Momentum component passes, or when both pass, as selected. Trend passes long when close > EMA(close, fast EMA lookback) >= EMA(close, medium EMA lookback), and short when close < EMA(close, fast EMA lookback) <= EMA(close, medium EMA lookback). Momentum passes long when smoothed RSI(close, RSI lookback, RSI smoothing lookback) >= the RSI midpoint and MACD histogram(close, fast MACD lookback, slow MACD lookback, MACD signal lookback) >= zero; short uses the inverse comparisons. If MTF agreement is required and MTF bias is enabled, long requires bull count >= bear count and short requires bear count >= bull count. If volume filtering is enabled, volume / SMA(volume, volume lookback) >= minimum volume ratio, or the ratio is unavailable. Signal evaluation requires signals enabled and, when confirmed-bar processing is enabled, a confirmed chart bar.
Calculation: Target levels = for an eligible target signal, entry is close and volatility band = max(min(ATR(high, low, close, target ATR lookback) * target ATR multiplier, close * maximum target band percent / percent scale), minimum tick size). ATR risk = band * ATR target distance multiplier. Long structure risk = entry - (trendline price - band * structure buffer); short structure risk = trendline price + band * structure buffer - entry. Select ATR risk, structure risk, or the greater of the two according to target mode, then floor risk at the volatility band. Long stop = entry - risk and take-profit = entry + risk * reward/risk parameter; short stop = entry + risk and take-profit = entry - risk * reward/risk parameter. Targets start only when target display is enabled and the selected target signal source accepts the breakout, retest, or rejection event; an active target is replaced only when replacement is enabled.
