Calculation: Volume ratio = volume / SMA(volume, volume-average lookback), when the average is positive and available
Calculation: Bullish volume direction = close > open AND close > close[1]
Calculation: Bearish volume direction = close < open AND close < close[1]
Calculation: Previous resistance = highest(high, breakout lookback)[1]
Calculation: Previous support = lowest(low, breakout lookback)[1]
Calculation: Bullish raw breakout = close > previous resistance
Calculation: Bearish raw breakdown = close < previous support
Calculation: Bullish buffered breakout = close > previous resistance + ATR(ATR lookback) * breakout ATR buffer
Calculation: Bearish buffered breakdown = close < previous support - ATR(ATR lookback) * breakout ATR buffer
Calculation: Bollinger width = (upper Bollinger Band - lower Bollinger Band) / middle Bollinger Band, using the Bollinger lookback and deviation multiplier
Calculation: Recent squeeze = a Bollinger squeeze occurred within the squeeze recency window, where a squeeze is Bollinger width < SMA(Bollinger width, squeeze comparison lookback) * squeeze factor
Calculation: Bollinger expansion = Bollinger width > Bollinger width[1]
Calculation: MTFState(T) = computed on chart bars from lookahead-off values of the current T bar (still forming in realtime); bullish if close(T) > EMA(close(T), medium EMA lookback) AND EMA(close(T), shortest EMA lookback) > EMA(close(T), medium EMA lookback) AND RSI(close(T), RSI lookback) > RSI midpoint; bearish if all three comparisons are reversed; otherwise neutral. T1, T2, and T3 are separate timeframes ordered short-term, middle-term, and long-term.
Calculation: Bullish MTF count = number of T1, T2, and T3 whose MTFState is bullish
Calculation: Bearish MTF count = number of T1, T2, and T3 whose MTFState is bearish
Calculation: Relative-strength ratio = close / benchmark close, using the current corresponding benchmark bar with lookahead off
Calculation: Relative-strength average = EMA(relative-strength ratio, relative-strength average lookback)
Calculation: Relative strength is bullish when enabled and available and the ratio > its average; bearish when enabled and available and the ratio < its average
Calculation: Relative strength is rising when enabled and available and the ratio > relative-strength ratio[relative-strength slope lookback]; falling when enabled and available and the ratio < relative-strength ratio[relative-strength slope lookback]
Calculation: Bullish trend points = bullish price-above-medium-EMA weight when close > EMA(close, medium EMA lookback), plus bullish EMA-stack weight for each of EMA(shortest)>EMA(medium), EMA(medium)>EMA(long), and EMA(long)>EMA(longest), plus bullish slope weight when EMA(shortest)>its value[EMA slope lookback] AND EMA(medium)>its value[EMA slope lookback], plus fresh bullish crossover weight when bars since EMA(shortest) crosses above EMA(medium) <= fresh-cross window
Calculation: Bearish trend points = bearish price-below-medium-EMA weight when close < EMA(close, medium EMA lookback), plus bearish EMA-stack weight for each of EMA(shortest)<EMA(medium), EMA(medium)<EMA(long), and EMA(long)<EMA(longest), plus bearish slope weight when EMA(shortest)<its value[EMA slope lookback] AND EMA(medium)<its value[EMA slope lookback], plus fresh bearish crossover weight when bars since EMA(shortest) crosses below EMA(medium) <= fresh-cross window
Calculation: Bullish RSI points = bullish RSI-level weight when RSI(close, RSI lookback) >= bullish RSI threshold, plus bullish RSI-slope weight when RSI > RSI[RSI slope lookback]
Calculation: Bearish RSI points = bearish RSI-level weight when RSI(close, RSI lookback) <= bearish RSI threshold, plus bearish RSI-slope weight when RSI < RSI[RSI slope lookback]
Calculation: Bullish MACD points = bullish MACD-line weight when MACD line > signal line, plus bullish histogram-sign weight when histogram > 0, plus bullish histogram-slope weight when histogram > histogram[1]
Calculation: Bearish MACD points = bearish MACD-line weight when MACD line < signal line, plus bearish histogram-sign weight when histogram < 0, plus bearish histogram-slope weight when histogram < histogram[1]
Calculation: Bullish DMI points = bullish DI-lead weight when +DI > -DI, plus bullish ADX-level weight when +DI > -DI AND ADX >= minimum ADX, plus bullish ADX-slope weight when +DI > -DI AND ADX > ADX[1]
Calculation: Bearish DMI points = bearish DI-lead weight when -DI > +DI, plus bearish ADX-level weight when -DI > +DI AND ADX >= minimum ADX, plus bearish ADX-slope weight when -DI > +DI AND ADX > ADX[1]
Calculation: Bullish volume points = 0 unless the volume average is available and bullish volume direction holds; otherwise use strong-volume points when volume ratio >= strong-volume ratio, RUN-volume points when >= RUN-volume ratio, elevated-volume points when >= elevated-volume ratio, and baseline-volume points otherwise
Calculation: Bearish volume points = 0 unless the volume average is available and bearish volume direction holds; otherwise use strong-volume points when volume ratio >= strong-volume ratio, RUN-volume points when >= RUN-volume ratio, elevated-volume points when >= elevated-volume ratio, and baseline-volume points otherwise
Calculation: Bullish structure points = bullish breakout points when the bullish buffered breakout holds; otherwise raw-breakout points when the bullish raw breakout holds; otherwise descending proximity points when (previous resistance-close)/ATR is <= the nearest, middle, or far resistance-distance threshold; otherwise 0
Calculation: Bearish structure points = bearish breakdown points when the bearish buffered breakdown holds; otherwise raw-breakdown points when the bearish raw breakdown holds; otherwise descending proximity points when (close-previous support)/ATR is <= the nearest, middle, or far support-distance threshold; otherwise 0
Calculation: Bullish volatility points = squeeze-expansion points when recent squeeze AND Bollinger expansion AND close > Bollinger middle band; otherwise squeeze points when a squeeze holds; otherwise expansion points when Bollinger expansion AND close > middle band; otherwise 0
Calculation: Bearish volatility points = squeeze-expansion points when recent squeeze AND Bollinger expansion AND close < Bollinger middle band; otherwise squeeze points when a squeeze holds; otherwise expansion points when Bollinger expansion AND close < middle band; otherwise 0
Calculation: Bullish MTF points = 0 when MTF is disabled; otherwise bullish MTF count / number of MTF timeframes * maximum MTF points
Calculation: Bearish MTF points = 0 when MTF is disabled; otherwise bearish MTF count / number of MTF timeframes * maximum MTF points
Calculation: Bullish relative-strength points = 0 when relative strength is unavailable; otherwise bullish-relative-strength weight when bullish plus rising-relative-strength weight when rising
Calculation: Bearish relative-strength points = 0 when relative strength is unavailable; otherwise bearish-relative-strength weight when bearish plus falling-relative-strength weight when falling
Calculation: Active score maximum = base score maximum + volume maximum adjustment when volume average is available + MTF maximum adjustment when MTF is enabled + relative-strength maximum adjustment when relative strength is available
Calculation: Bullish score = min(score cap, (bullish trend points + bullish RSI points + bullish MACD points + bullish DMI points + bullish volume points + bullish structure points + bullish volatility points + bullish MTF points + bullish relative-strength points) / active score maximum * score scale)
Calculation: Bearish score = min(score cap, (bearish trend points + bearish RSI points + bearish MACD points + bearish DMI points + bearish volume points + bearish structure points + bearish volatility points + bearish MTF points + bearish relative-strength points) / active score maximum * score scale)
Calculation: Bullish RUN condition = bullish score >= RUN score threshold AND bullish buffered breakout AND volume average available AND volume ratio >= RUN-volume ratio AND bullish volume direction
Calculation: Bearish FALL condition = bearish score >= RUN score threshold AND bearish buffered breakdown AND volume average available AND volume ratio >= RUN-volume ratio AND bearish volume direction
Calculation: Strong bullish condition = bullish score >= strong score threshold AND bullish buffered breakout AND volume average available AND volume ratio >= strong-volume ratio AND +DI > -DI AND ADX >= strong ADX threshold
Calculation: Strong bearish condition = bearish score >= strong score threshold AND bearish buffered breakdown AND volume average available AND volume ratio >= strong-volume ratio AND -DI > +DI AND ADX >= strong ADX threshold
Calculation: Bullish state = strongest bullish state if strong bullish condition; otherwise RUN state if bullish RUN condition; otherwise breakout state if bullish raw breakout AND bullish score >= setup threshold; otherwise setup state if bullish score >= setup threshold; otherwise early state if bullish score >= early threshold; otherwise watch state if bullish score >= watch threshold; otherwise neutral
Calculation: Bearish state = strongest bearish state if strong bearish condition; otherwise FALL state if bearish FALL condition; otherwise breakdown state if bearish raw breakdown AND bearish score >= setup threshold; otherwise warning state if bearish score >= setup threshold; otherwise early state if bearish score >= early threshold; otherwise caution state if bearish score >= watch threshold; otherwise neutral
Calculation: Bullish core = close > EMA(medium) AND EMA(shortest) > EMA(medium) AND EMA(medium) > EMA(long) AND RSI >= bullish RSI threshold AND MACD line > signal line AND MACD histogram > 0 AND +DI > -DI AND ADX >= minimum ADX AND volume average available AND bullish volume direction AND volume ratio >= RUN-volume ratio AND bullish buffered breakout AND (MTF disabled OR bullish MTF count >= MTF confirmation count) AND (relative strength unavailable OR relative strength bullish)
Calculation: Bearish core = close < EMA(medium) AND EMA(shortest) < EMA(medium) AND EMA(medium) < EMA(long) AND RSI <= bearish RSI threshold AND MACD line < signal line AND MACD histogram < 0 AND -DI > +DI AND ADX >= minimum ADX AND volume average available AND bearish volume direction AND volume ratio >= RUN-volume ratio AND bearish buffered breakdown AND (MTF disabled OR bearish MTF count >= MTF confirmation count) AND (relative strength unavailable OR relative strength bearish)
Calculation: Bullish RSI-divergence event = when a confirmed pivot low forms, its low is below the preceding confirmed pivot low AND RSI at the pivot is above RSI at the preceding confirmed pivot; pivot strength is a separate parameter for left and right bars
Calculation: Bearish RSI-divergence event = when a confirmed pivot high forms, its high is above the preceding confirmed pivot high AND RSI at the pivot is below RSI at the preceding confirmed pivot; pivot strength is a separate parameter for left and right bars
Calculation: Bullish RSI-divergence recency = a bullish RSI-divergence pivot occurred within the divergence recency window, with age measured from the pivot bar
Calculation: Bearish RSI-divergence recency = a bearish RSI-divergence pivot occurred within the divergence recency window, with age measured from the pivot bar
Calculation: Bullish retest event = a bullish buffered breakout first became true, then within the retest window a later bar has low <= its stored breakout level + ATR * retest tolerance AND close >= that level AND close > open, and this held condition was false on the preceding bar
Calculation: Bearish retest event = a bearish buffered breakdown first became true, then within the retest window a later bar has high >= its stored breakdown level - ATR * retest tolerance AND close <= that level AND close < open, and this held condition was false on the preceding bar
Calculation: Signal ready = close-only confirmation is disabled OR the chart bar is confirmed
Calculation: Bullish overall dashboard status = strong bullish condition; otherwise bullish RUN condition if neither strong condition holds; otherwise bullish state >= breakout and bullish score > bearish score if neither strong nor RUN condition holds; otherwise bullish state >= setup and bullish score > bearish score + status lead margin if no earlier status condition holds; otherwise bullish state >= early and bullish score > bearish score + status lead margin if no earlier status condition holds
Calculation: Bearish overall dashboard status = bearish strong condition when bullish strong condition is false; otherwise bearish FALL condition when both strong conditions and bullish RUN condition are false; otherwise bearish state >= breakdown and bearish score > bullish score when all preceding status conditions are false; otherwise bearish state >= warning and bearish score > bullish score + status lead margin when no earlier status condition holds; otherwise bearish state >= early and bearish score > bullish score + status lead margin when no earlier status condition holds
