Calculation: S(T) = EMA ribbon score + RSI score + volume score, calculated on T bars and sampled on chart bars with lookahead off (current T bar in real time; last completed T bar historically); T1, T2, T3, and T4 are distinct timeframes from shortest to longest. EMA ribbon score is 1 when EMA(close, shortest EMA lookback) > EMA(close, next-shortest EMA lookback) > EMA(close, next-longest EMA lookback) > EMA(close, longest EMA lookback), -1 when all inequalities are reversed, otherwise 0; RSI score is 1 when RSI(close, RSI lookback) > bullish RSI threshold, -1 when RSI(close, RSI lookback) < bearish RSI threshold, otherwise 0; volume score is 1 when volume > SMA(volume, volume lookback) * volume multiplier and close > open, -1 when that volume condition holds and close < open, otherwise 0. The four EMA lookbacks are separate parameters ordered shortest to longest; RSI thresholds, volume lookback, and volume multiplier are separate parameters.
Calculation: C = S(T1) + S(T2) + S(T3) + S(T4), on chart bars.
Long: S(T1) >= 2 OR S(T2) >= 2 OR S(T3) >= 2 OR S(T4) >= 2
Short: S(T1) <= -2 OR S(T2) <= -2 OR S(T3) <= -2 OR S(T4) <= -2
Long: C >= aligned threshold OR (C >= lean threshold AND C < aligned threshold)
Short: C <= -aligned threshold OR (C <= -lean threshold AND C > -aligned threshold)
Long: ((C >= aligned threshold AND C[1] < aligned threshold) OR (C >= lean threshold AND C < aligned threshold AND NOT ((C[1] >= lean threshold AND C[1] < aligned threshold) OR C[1] >= aligned threshold))) AND (last fired signal was not short OR ((neutral reset is not required OR |C| reached the neutral threshold since the last fired signal) AND chart bars since the last fired signal >= minimum bar gap))
Short: ((C <= -aligned threshold AND C[1] > -aligned threshold) OR (C <= -lean threshold AND C > -aligned threshold AND NOT ((C[1] <= -lean threshold AND C[1] > -aligned threshold) OR C[1] <= -aligned threshold))) AND (last fired signal was not long OR ((neutral reset is not required OR |C| reached the neutral threshold since the last fired signal) AND chart bars since the last fired signal >= minimum bar gap))
