Calculation: Anchored profile POC = midpoint of the highest-volume bin accumulated from the selected anchor; bins are anchored at source on that bar, with width max(ATR(lookback), minimum tick)/rows-per-ATR. On chart bars, spread each bar’s volume evenly across bins intersecting its high-low range, assigning ranges over the maximum bin span to their midpoint bin; when enabled without borrowed volume, instead assign each T1 lower-timeframe bar’s volume to the bin containing its hlc3, including a still-forming T1 bar within the current chart bar.
Calculation: Decayed profile value = the POC or value-area midpoint (selected mode) of bins updated on chart bars by multiplying prior bin volumes by 2^(-1/half-life), then adding current chart-bar volume spread across bins intersecting its high-low range; assign ranges over the maximum bin span to their midpoint bin. The value-area midpoint is the midpoint of the value area expanded from the POC toward the larger adjacent bin until the selected volume fraction is covered. These values use the current chart bar, including while it is forming.
Calculation: Anchored volume-weighted standard deviation = sqrt(sum(source^2 * volume)/sum(volume) - anchored VWAP(source, volume, selected anchor)^2), with sums accumulated from the selected anchor.
Long: crossover(decayed profile value, anchored profile POC)
Short: crossunder(decayed profile value, anchored profile POC)
Long: z-score(source, anchored VWAP(source, volume, selected anchor), anchored volume-weighted standard deviation) crosses above stretch threshold
Short: z-score(source, anchored VWAP(source, volume, selected anchor), anchored volume-weighted standard deviation) crosses below negative stretch threshold
