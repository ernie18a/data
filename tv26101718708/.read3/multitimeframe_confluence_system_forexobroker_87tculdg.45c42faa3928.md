Calculation: Trend state = on each timeframe's bars, bullish when EMA(close, fast lookback) > EMA(close, slow lookback) AND close > EMA(close, trend lookback), bearish when EMA(close, fast lookback) < EMA(close, slow lookback) AND close < EMA(close, trend lookback), otherwise neutral; the fast, slow, and trend lookbacks are ordered shortest to longest.
Calculation: Momentum state = on each timeframe's bars, bullish when RSI(close, RSI lookback) > bull threshold AND, when MACD confirmation is enabled, MACD(close, shorter lookback, longer lookback, signal lookback) histogram >= histogram threshold; bearish when RSI(close, RSI lookback) < bear threshold AND, when MACD confirmation is enabled, the histogram <= histogram threshold; otherwise neutral.
Calculation: Swing structure = on each timeframe's bars, bullish when the latest confirmed PivotHigh(high, swing lookback, swing lookback) is greater than the preceding confirmed pivot high AND the latest confirmed PivotLow(low, swing lookback, swing lookback) is greater than the preceding confirmed pivot low; bearish when both latest pivots are less than their preceding pivots; otherwise neutral, including when either pair is unavailable.
Calculation: Confluence(direction) = sum across the chart timeframe and each enabled T1-T4 of 1 when every required trend, momentum, and structure state matches direction, otherwise 0; the chart timeframe is always included and each dimension has a separate required toggle. Trend, momentum, and structure are calculated on their respective timeframe bars; T1-T4 values are requested on chart bars and can come from the still-forming T1-T4 bar.
Long: Confluence(long) >= minimum confluence AND current chart bar index - previous long-signal bar index, initially zero, >= long-signal cooldown bars
Short: Confluence(short) >= minimum confluence AND current chart bar index - previous short-signal bar index, initially zero, >= short-signal cooldown bars
Long: Confluence(long) >= minimum confluence - near-threshold margin
Short: Confluence(short) >= minimum confluence - near-threshold margin
Long: Confluence(long) = number of enabled analyses, including the chart timeframe
Short: Confluence(short) = number of enabled analyses, including the chart timeframe
