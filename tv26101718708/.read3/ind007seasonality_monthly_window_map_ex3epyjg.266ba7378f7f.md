Calculation: Seasonal window statistics = On the last chart bar, use T1 closes sampled on chart bars (historical T1 bars are completed and the current T1 bar is still forming). For each start day s from 1 through 365 and calendar-day length L from minimum window length through maximum window length where s+L <= 365, calculate each available year's return r = 100 * (close on day s+L / close on day s - 1), using only years with both closes. Let sample count be the number of such years, effective minimum samples = max(minimum-sample floor, min(minimum historical samples, number of years)), bullish hit rate = 100 * count(r > 0) / sample count, bearish hit rate = 100 * count(r < 0) / sample count, mean return = average(r), bullish directional average = mean return, and bearish directional average = -mean return. For each direction, confidence factor = 1 + (sqrt(sample count / effective minimum samples) - 1) * confidence weight when sample adjustment is enabled, otherwise 1; score = clamp(hit rate * directional average * confidence factor / sqrt(L) * score scale, 0, score ceiling). A directional candidate qualifies when sample count >= effective minimum samples, hit rate >= minimum historical hit rate, score >= minimum historical score, and either the directional-average filter is disabled or directional average > 0.
Calculation: Window overlap percentage = 100 * max(0, min(end1, end2) - max(start1, start2)) / min(max(1, end1 - start1), max(1, end2 - start2)).
Calculation: Best seasonal windows = On the last chart bar, independently process bullish and bearish qualifying candidates in ascending start day, then ascending length. Reject a candidate if its overlap percentage with any currently retained same-direction candidate >= overlap threshold; otherwise insert it in descending score order, after existing equal-score candidates, and retain at most the configured number of windows. The first retained candidate of each direction is its best window, with its start day, end day, hit rate, mean return, and score.
Calculation: Current day of year = Day of year from the timestamp of the current T1 bar still forming, sampled on chart bars.
