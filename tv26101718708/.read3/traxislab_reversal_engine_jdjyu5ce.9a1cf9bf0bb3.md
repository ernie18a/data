Calculation: signal threshold = positive score override, otherwise the threshold selected by the signal mode from its separate mode thresholds.
Calculation: volume expansion = volume > SMA(volume, volume lookback) × volume expansion multiplier.
Calculation: swing position = (close − lowest(low, swing lookback)) / (highest(high, swing lookback) − lowest(low, swing lookback)) when the range is positive; swing lookback = pivot lookback × swing-window multiplier.
Calculation: candle conditions = body ratio abs(close − open) / (high − low) when high > low, otherwise zero; bullish engulfing when close > open, previous close < previous open, close > previous open, and open < previous close; bearish engulfing when close < open, previous close > previous open, close < previous open, and open > previous close; bullish hammer when close > open, open − low > body × hammer-wick multiplier, and high − close < body × small-wick multiplier; bearish shooting star when close < open, high − open > body × hammer-wick multiplier, and close − low < body × small-wick multiplier; strong bullish or bearish candle when body ratio exceeds the strong-body threshold and close is respectively above or below open.
Calculation: structure breaks = bullish when a stored confirmed PivotHigh(high, pivot lookback, right-confirmation lookback) exists, close is above it, and previous close is at or below it; bearish when a stored confirmed PivotLow(low, pivot lookback, right-confirmation lookback) exists, close is below it, and previous close is at or above it. Store newly confirmed pivots, clear the corresponding stored pivot after its break, initialize structure trend as neutral, and update it to the break direction; a break against the prior trend is a CHoCH.
Calculation: long score = min(score ceiling, trend points + RSI points + stochastic points + structure points + candle points + volume points + support points + ADX points). Trend points: when the EMA filter is enabled, add the fast/mid trend weight if EMA(close, fast lookback) > EMA(close, mid lookback), and the close/slow trend weight if close > EMA(close, slow lookback); otherwise add the trend-filter-disabled weight. RSI points: add the oversold weight if RSI(close, RSI lookback) < oversold threshold, else add the moderately-low weight if RSI is below the moderate-low threshold. Stochastic points: add the oversold weight if Stochastic(close, high, low, stochastic lookback) < lower extreme threshold, else add the moderately-low weight if it is below the lower moderate threshold. Structure points: add the CHoCH weight for a bullish CHoCH, else the BOS weight for a bullish break. Candle points: add the engulfing weight for a bullish engulfing candle, else the reversal-candle weight for a bullish hammer, else the strong-body weight for a strong bullish candle. Volume points: when the volume filter is enabled, add the volume-expansion weight if volume expansion is true; otherwise, when the filter is disabled, add the volume-filter-disabled weight. Add the support weight if the swing range is positive and swing position < support-proximity threshold. ADX points: when the ADX filter is enabled, add the ADX-strength weight if ADX(ADX lookback) > ADX minimum; otherwise, when the filter is disabled, add the ADX-filter-disabled weight.
Calculation: short score = min(score ceiling, trend points + RSI points + stochastic points + structure points + candle points + volume points + resistance points + ADX points). Trend points: when the EMA filter is enabled, add the fast/mid trend weight if EMA(close, fast lookback) < EMA(close, mid lookback), and the close/slow trend weight if close < EMA(close, slow lookback); otherwise add the trend-filter-disabled weight. RSI points: add the overbought weight if RSI(close, RSI lookback) > overbought threshold, else add the moderately-high weight if RSI is above the moderate-high threshold. Stochastic points: add the overbought weight if Stochastic(close, high, low, stochastic lookback) > upper extreme threshold, else add the moderately-high weight if it is above the upper moderate threshold. Structure points: add the CHoCH weight for a bearish CHoCH, else the BOS weight for a bearish break. Candle points: add the engulfing weight for a bearish engulfing candle, else the reversal-candle weight for a bearish shooting star, else the strong-body weight for a strong bearish candle. Volume points: when the volume filter is enabled, add the volume-expansion weight if volume expansion is true; otherwise, when the filter is disabled, add the volume-filter-disabled weight. Add the resistance weight if the swing range is positive and swing position > resistance-proximity threshold. ADX points: when the ADX filter is enabled, add the ADX-strength weight if ADX(ADX lookback) > ADX minimum; otherwise, when the filter is disabled, add the ADX-filter-disabled weight.
Calculation: trail direction = initialize neutral with no trail; trail distance is (ATR(ATR lookback), or close × ATR fallback fraction when unavailable) × trail multiplier. On each bar, in order: if a confirmed long signal occurs or direction is bullish and close > trail, set trail to close − trail distance, taking the maximum with the prior trail only if direction was already bullish, and set direction bullish; then if a confirmed short signal occurs or direction is bearish and close < trail, set trail to close + trail distance, taking the minimum with the prior trail only if direction was already bearish, and set direction bearish; then if direction is bullish and close < trail, set trail to close + trail distance and direction bearish; if direction is bearish and close > trail, set trail to close − trail distance and direction bullish.
Long: long score >= signal threshold AND bar distance from the previous confirmed long signal > cooldown AND NOT (ADX filter enabled AND ADX(ADX lookback) < ADX minimum).
Short: short score >= signal threshold AND bar distance from the previous confirmed short signal > cooldown AND NOT (ADX filter enabled AND ADX(ADX lookback) < ADX minimum).
Long: bullish structure break.
Short: bearish structure break.
Long: long score >= round(signal threshold × pending percentage) AND long score < signal threshold AND bar distance from the previous confirmed long signal > cooldown AND NOT (ADX filter enabled AND ADX(ADX lookback) < ADX minimum).
Short: short score >= round(signal threshold × pending percentage) AND short score < signal threshold AND bar distance from the previous confirmed short signal > cooldown AND NOT (ADX filter enabled AND ADX(ADX lookback) < ADX minimum).
Long: trail direction = bullish AND trail direction on the previous bar = bearish.
Short: trail direction = bearish AND trail direction on the previous bar = bullish.
