## Description

EMA Trend Stack 34/89/144/200 gives you a clean, powerful view of market structure using four key exponential moving averages
[list]
[*] EMA 34 — Tracks short-term trend shifts and early momentum changes.
[*] EMA 89 — Captures the mid-term trend and helps filter market noise.
[*] EMA 144 — Acts as a deeper trend guide and dynamic pullback zone.
[*] EMA 200 — Represents the major long-term trend and institutional-level bias.
[/list] 

Together — The 34/89/144/200 stack creates a clear trend map: alignment shows strength, compression signals transition, and separation highlights momentum.

## Source Code

````pine
//@version=6
indicator("EMA 34/89/144/200", overlay = true)

shortest = ta.ema(close, 34)
short = ta.ema(close, 89)
longer = ta.ema(close, 144)
longest = ta.ema(close, 200)

plot(shortest, color = color.red)
plot(short, color = color.orange)
plot(longer, color = color.aqua)
plot(longest, color = color.blue)
````
