On each pair of consecutive higher-timeframe candles, compare the traded instrument’s highs and lows with enabled correlated instruments over the same period. If the traded instrument makes a new high while any valid reference does not, or vice versa, signal short. If it makes a new low while any valid reference does not, or vice versa, signal long. Ignore references that are the same instrument or whose candle periods do not match. No exit rule is defined.
