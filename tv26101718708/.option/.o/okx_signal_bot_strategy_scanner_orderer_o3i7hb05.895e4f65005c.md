For each configured scanned instrument, evaluate up to six enabled conditions using indicator values from the chart instrument: compare a selected volatility, moving-average, momentum, trend-strength, or money-flow indicator with another selected indicator or a fixed numeric threshold, using a relational comparison or crossover/crossunder. Combine enabled long conditions and enabled short conditions separately, using either all conditions or any condition as configured. When the long group is true, exit any short position and enter long; when the short group is true, exit any long position and enter short. There is no separate exit rule.
