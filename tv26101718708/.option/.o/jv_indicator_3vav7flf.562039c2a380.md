A long setup occurs when price closes above a recently formed bearish fair-value gap with an impulsive, non-doji candle; a short setup occurs when it closes below a recently formed bullish fair-value gap with such a candle. The gap must be inverted within the configured candle window, and only one signal of each direction is allowed per manipulation leg. Grade each direction from its matching higher-timeframe fair-value-gap location and recent liquidity sweep, plus shared session, liquidity-structure, and SMT confirmations; emit the setup only if it meets the configured minimum grade. When the ES SMT filter is enabled, ES trading near either prior-day extreme adds confirmation equally to long and short setups, affecting eligibility but not direction. The script defines no exit signal.
