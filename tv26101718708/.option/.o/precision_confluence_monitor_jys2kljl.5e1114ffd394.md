For each supplied traded-instrument level paired with an external-index level, monitor closes relative to both levels. Start a bullish setup when both instruments close above their respective levels, or a bearish setup when both close below; require the optional volume and trend filters to agree at setup. On the following bar, enter long or short only if both instruments remain on the same side and the volume filter still passes. If the traded instrument reverses across its level or the external index loses its confirming side before entry, cancel the setup and count a failed attempt. After repeated failures, suppress the entry. Once entered, exit if the traded instrument closes back across its level against the position. If no external level is supplied, treat the external index as confirming.
