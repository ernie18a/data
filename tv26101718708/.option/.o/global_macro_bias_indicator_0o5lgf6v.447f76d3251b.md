Use external macro data to score market risk appetite: add a bullish point when the U.S. 10-year minus 2-year yield spread is steepening, the dollar is weakening, or volatility is calm; add a bearish point for a flattening spread, a strengthening dollar, or elevated volatility. Treat each factor as neutral when neither condition applies. If bullish factors outnumber bearish ones, go long; if bearish factors outnumber bullish ones, go short; if they are tied, exit or stay flat.
