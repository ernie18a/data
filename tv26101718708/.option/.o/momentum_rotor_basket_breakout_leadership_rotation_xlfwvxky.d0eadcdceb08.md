For a traded symbol included in a configurable basket, calculate each member’s rate of change over a configurable lookback and rank them. Enter long only when the traded symbol ranks first, closes above its prior rolling high, satisfies the optional close-above-long-term-average filter, and has no open position. While long, exit if it loses first place in the ranking; optionally require that loss to persist for a configurable number of bars. Also place a volatility-scaled stop and a profit target at a configurable reward-to-risk multiple. Never enter short.
