Within the configured trading date range, compute rolling z-scores for the MOVE-to-inverse-VIX ratio, the VIX-to-VVIX ratio, and the oil-price-to-inverse-OVX ratio. Also compute the traded instrument’s Bollinger %B and, when the EMA filter is enabled, its EMA. Use the enabled indicator selection: with all three enabled, a bearish signal requires all three z-scores above zero and %B below its midpoint; a bullish exit condition requires all three below zero and %B above its midpoint. With one indicator enabled, use that indicator’s z-score with the same %B conditions. With two enabled, a bearish signal requires both selected z-scores above zero and %B below midpoint; the bullish exit condition uses the VIX z-score and %B above midpoint, as coded. For a bearish signal, enter short only if currently long and, when the EMA filter is enabled, price is below its EMA; close longs on the applicable bullish exit condition. Whenever the bearish signal is false, attempt to enter long if flat or short, and close shorts when the applicable bearish exit condition holds. In two-indicator selections, the short exit condition uses the VIX z-score and %B below midpoint, including when VIX is not selected. With the EMA filter disabled, omit the EMA requirement. The oil-only branch uses the MOVE-based long and short exit conditions.
