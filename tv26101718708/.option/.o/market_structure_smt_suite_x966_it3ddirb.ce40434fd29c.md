For each enabled timeframe, compare the traded instrument’s current interval high and low with prior unsuperseded interval highs and lows, and compare the same movements in each available reference market. If the traded instrument and any reference market disagree on whether the current interval exceeded a prior high, signal short. If they disagree on whether it fell below a prior low, signal long. When reference markets are enabled, require at least one valid comparison; missing comparison data cannot trigger a signal. The indicator defines no exit decision.
