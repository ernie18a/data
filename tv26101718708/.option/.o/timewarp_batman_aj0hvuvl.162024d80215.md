Near the configured end-of-session entry time, if no position is already active, enter both a long call butterfly above spot and a long put butterfly below spot, using the next session’s expiry or Monday expiry when entering on Friday. Set both fly bodies symmetrically out of the money from the rounded spot reference; set wing width from the configured fixed width or scale it by external VIX readings, and round strikes to the instrument’s strike increments. A move through either outer wing triggers a position-compromised alert, but no automatic exit rule is defined.
