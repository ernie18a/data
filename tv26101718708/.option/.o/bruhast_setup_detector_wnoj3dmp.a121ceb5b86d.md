On each confirmed bar, generate long signals for a bullish inside-bar breakout, a breakout above the prior rolling high, a bullish reversal filling a qualifying downward gap, or a bullish outside bar; generate short signals for a bearish inside-bar breakout, a bearish continuation after an upward gap, or a bearish outside bar. Apply the enabled setup-specific requirements and common filters for volume, relative volume, bar range versus ATR, minimum price, session, and alignment with the selected market index. When index alignment is enabled, allow longs only if the index closes above its own EMA and shorts only if it closes below its own EMA. The script issues no exit signals.
