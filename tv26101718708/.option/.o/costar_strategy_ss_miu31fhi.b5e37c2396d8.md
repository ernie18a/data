Using a second instrument’s prices, fit a linear model to estimate the traded instrument’s expected price and calculate an upper and lower range around that estimate. Select the first lookback length whose pair residuals pass a stationarity test; if none pass, do not trade. Go long when the traded price crosses above the lower range, and exit the long when it crosses above the expected price. Go short when the traded price crosses below the upper range, and exit the short when it crosses below the expected price.
