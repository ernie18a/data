On each confirmed bar, use a rolling linear model trained to predict the traded instrument’s return from the previous bar’s standardized returns of the reference markets and the instrument’s own momentum. After the learning warmup, apply the model to current standardized returns to forecast the next return. Go long when the forecast exceeds a volatility-scaled positive threshold; go short when it falls below the matching negative threshold; otherwise remain flat. Treat a change from long or short bias to flat or the opposite bias as ending that bias.
