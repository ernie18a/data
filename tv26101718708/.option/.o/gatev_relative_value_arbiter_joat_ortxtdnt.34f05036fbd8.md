Use the peer’s prices and the chart instrument’s prices to estimate their rolling log-price relationship, then measure how far the chart instrument’s residual spread is from its recent mean in standard-deviation units. Only act when the instruments’ returns are sufficiently correlated and the spread has nonzero variability. On a confirmed bar, go long the chart instrument when the spread is unusually cheap and begins moving back upward; go short when it is unusually rich and begins moving downward. Enforce a configurable cooldown between these entries. Also signal a long when a smoothed residual estimate is unusually negative and reversion pressure is strong, and a short when it is unusually positive under the same condition; emit each such signal only when it first becomes true. Exit or reset the position when the valid spread returns within the configured near-fair-value band.
