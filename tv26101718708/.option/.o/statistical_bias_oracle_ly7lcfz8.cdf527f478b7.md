For each asset in a correlated group, set or retain a bullish bias when its previous completed candle sweeps below the preceding candle’s low and closes back above it, or closes above the preceding high. Set or retain a bearish bias for the inverse patterns. If higher-timeframe confirmation is enabled, keep a directional bias only when the next higher timeframe agrees; otherwise treat it as neutral. Aggregate the group’s biases using the configured chart-asset, majority, or unanimous rule. Go long on bullish consensus, short on bearish consensus, and exit or remain flat when consensus is neutral.
