Smooth the external weekly exposure index and daily equity put/call ratio. Convert each to a 0–100 sentiment score using configured fear and greed bounds: higher exposure and lower put/call readings indicate greater greed, with scores clamped at the bounds. Apply configured weights and sum the scores, then smooth the combined index. Enter long when the prior bar’s smoothed index is below the configured buy level and forms a local trough, with the values on both adjacent bars higher. Exit the long when the prior bar’s index is above the configured sell level and forms a local peak, with both adjacent values lower; an optional configured calendar end date also closes the position.
