At each monthly rebalance, calculate each configured offensive and defensive asset’s momentum from weighted returns over short, medium, and long lookback horizons, with greater weight on recent returns. Count offensive assets with nonpositive momentum. If that count meets or exceeds the configured breadth threshold, go long the defensive asset with the highest momentum; otherwise, go long the offensive asset with the highest momentum. Exit the previously held asset when the selected asset changes. Break tied scores by choosing the asset listed first in its group.
