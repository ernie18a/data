At each scheduled rebalance, use the selected asset universe’s price history to estimate annualized return covariance, excluding assets without a complete estimation history. Build a neutral prior allocation using equal weights, inverse volatility, or supplied benchmark weights, then infer equilibrium returns from that prior and the covariance. Blend in each usable supplied absolute-return or relative-outperformance view according to its stated confidence, and optimize portfolio weights from the resulting expected returns and covariance. Set unavailable assets to zero; optionally remove negative weights when shorting is disabled; then apply gross-exposure, volatility-targeting, leverage, per-asset, and total-exposure limits. For each asset, a positive final weight means long, a negative weight means short when permitted, and zero means exit or remain out. If the optional chart-instrument trend filter is enabled, hold all assets at zero while its fast moving average is at or below its slow moving average; when it rises above, resume allocation and rebalance immediately. Recompute on the normal rebalance schedule, when the filter returns to active, or when the number of eligible assets changes.
