## Description

SUPER KOTANJAN TREND

Super Kotanjan Trend is a modern trend-following system designed to identify directional market structure while filtering out a large portion of market noise.

Unlike traditional trend indicators that rely primarily on moving averages or volatility calculations, Super Kotanjan Trend combines structure analysis, directional force measurement, cotangent market geometry, and adaptive trend filtering into a single visual framework.

━━━━━━━━━━━━━━━━━━
HOW IT WORKS
━━━━━━━━━━━━━━━━━━

The engine continuously evaluates price position inside a rolling market structure block.

Instead of focusing only on price direction, the indicator measures how strongly price is positioned within its recent structure range and transforms that information into a directional strength score.

This creates a dynamic view of market pressure rather than a simple moving average crossover.

The indicator then applies a Cotangent Geometry Engine.

The cotangent calculation estimates the relationship between price displacement and time displacement.

This allows the system to classify market conditions into:

• Trending Markets
• Squeeze Markets
• Neutral Markets

By separating trend environments from compression environments, Super Kotanjan Trend attempts to reduce many of the false signals commonly generated by traditional trend indicators.

━━━━━━━━━━━━━━━━━━
EMA FILTERING
━━━━━━━━━━━━━━━━━━

A dual EMA filtering model is used:

• EMA 100 acts as the primary long-term trend filter.
• EMA 50 acts as the short-term bearish filter.

Long signals are only allowed when price remains above EMA 100.

Short signals are only allowed when price remains below EMA 50.

This asymmetric filtering model was intentionally designed to allow trends to develop while still reacting relatively quickly to bearish market conditions.

━━━━━━━━━━━━━━━━━━
BUY & SELL SIGNALS
━━━━━━━━━━━━━━━━━━

BUY signals appear only when:

• Bullish structure is detected.
• Cotangent structure confirms directional strength.
• EMA trend conditions are satisfied.
• Market structure transitions into a bullish state.

SELL signals appear only when:

• Bearish structure is detected.
• Cotangent structure confirms directional weakness.
• EMA filter conditions are satisfied.
• Market structure transitions into a bearish state.

Signals are generated only when the trend state changes.

This helps prevent repetitive signal spam during established trends.

━━━━━━━━━━━━━━━━━━
TREND LINE
━━━━━━━━━━━━━━━━━━

The trend line is the core visual component of the system.

Green Trend Line:
Represents active bullish structure.

Red Trend Line:
Represents active bearish structure.

The line continuously adapts to evolving market structure and attempts to act as a dynamic trend reference.

The objective is not to predict future prices but to provide a clear representation of the dominant market direction.

## Source Code

````pine
//@version=5
indicator("KOTANJAN COT TREND MODERN", overlay=true, max_bars_back=500, max_labels_count=500)

//━━━━━━━━ INPUTS
groupSize   = input.int(5, "Block Size", minval=2, maxval=20)
eliteLevel  = input.float(0.85, "Elite Strength", step=0.05)
majorLevel  = input.float(0.65, "Major Strength", step=0.05)
zoneTimeout = input.int(80, "Trend Hold Bars", minval=10)

useEma  = input.bool(true, "Use EMA Filter")
showEma = input.bool(false, "Show EMA 50/100")

cotLen       = input.int(14, "Cotangent Lookback")
cotATRLen    = input.int(14, "ATR Length")
cotSqueezeTh = input.float(2.5, "Squeeze Threshold", step=0.1)
cotTrendTh   = input.float(0.7, "Trend Threshold", step=0.1)

showBg    = input.bool(true, "Cotangent Background")
showPanel = input.bool(true, "Panel")
showSig   = input.bool(true, "BUY / SELL")

bullCol = input.color(color.lime, "Bull Color")
bearCol = input.color(color.red, "Bear Color")

//━━━━━━━━ EMA FILTER
ema50  = ta.ema(close, 50)
ema100 = ta.ema(close, 100)

bullFilter = close > ema100
bearFilter = close < ema50

plot(showEma ? ema50 : na, "EMA 50", color=color.new(color.orange, 0), linewidth=1)
plot(showEma ? ema100 : na, "EMA 100", color=color.new(color.aqua, 0), linewidth=2)

//━━━━━━━━ STRUCTURE CORE
groupHigh  = ta.highest(high, groupSize)
groupLow   = ta.lowest(low, groupSize)
priceRange = math.max(groupHigh - groupLow, syminfo.mintick)

buyForce  = (close - groupLow) / priceRange
sellForce = (groupHigh - close) / priceRange
netForce  = buyForce - sellForce
strength  = math.abs(netForce)

isConf = barstate.isconfirmed

//━━━━━━━━ COTANGENT CORE
atrCot   = ta.atr(cotATRLen)
priceMov = close - close[cotLen]
yStep    = atrCot > 0 ? priceMov / atrCot : 0.0
xStep    = float(cotLen)

slope    = yStep / xStep
angleDeg = math.atan(slope) * 180 / math.pi
cotVal   = math.abs(yStep) > 0.0001 ? xStep / math.abs(yStep) : 999.0

isSqueeze = cotVal > cotSqueezeTh
isTrend   = cotVal < cotTrendTh

//━━━━━━━━ RAW STRUCTURE SIGNAL
isElite = isConf and strength >= eliteLevel
isMajor = isConf and strength >= majorLevel and strength < eliteLevel

rawBullSig =
     (isElite and netForce > 0 and strength[1] < eliteLevel) or
     (isMajor and netForce > 0 and strength[1] < majorLevel)

rawBearSig =
     (isElite and netForce < 0 and strength[1] < eliteLevel) or
     (isMajor and netForce < 0 and strength[1] < majorLevel)

bullSig = rawBullSig and (not useEma or bullFilter)
bearSig = rawBearSig and (not useEma or bearFilter)

//━━━━━━━━ MODERN TREND MEMORY
var int   trendDir  = 0
var float trendLine = na
var int   trendBar  = na

newBuy  = bullSig and trendDir != 1
newSell = bearSig and trendDir != -1

if newBuy
    trendDir  := 1
    trendLine := groupLow
    trendBar  := bar_index

if newSell
    trendDir  := -1
    trendLine := groupHigh
    trendBar  := bar_index

if trendDir == 1 and not na(trendLine)
    trendLine := math.max(trendLine, groupLow)

if trendDir == -1 and not na(trendLine)
    trendLine := math.min(trendLine, groupHigh)

killTrend =
     not na(trendBar) and bar_index - trendBar > zoneTimeout

if killTrend
    trendDir  := 0
    trendLine := na
    trendBar  := na

//━━━━━━━━ MODERN SUPERTREND STYLE LINE
lineCol =
     trendDir == 1 ? bullCol :
     trendDir == -1 ? bearCol :
     color.gray

plot(trendLine, "Kotanjan Trend Line", color=color.new(lineCol, 0), linewidth=4, style=plot.style_linebr)

supportLine = trendDir == 1 ? trendLine : na
resistLine  = trendDir == -1 ? trendLine : na

pSup = plot(supportLine, "Bull Base", color=color.new(bullCol, 75), linewidth=1, style=plot.style_linebr)
pRes = plot(resistLine, "Bear Base", color=color.new(bearCol, 75), linewidth=1, style=plot.style_linebr)

pClose = plot(close, "Price Fill Base", color=color.new(color.white, 100))

fill(pClose, pSup, color=trendDir == 1 ? color.new(bullCol, 88) : na)
fill(pClose, pRes, color=trendDir == -1 ? color.new(bearCol, 88) : na)

//━━━━━━━━ BUY SELL
plotshape(showSig and newBuy, title="BUY", style=shape.labelup, location=location.belowbar, color=bullCol, textcolor=color.black, text="BUY", size=size.small)

plotshape(showSig and newSell, title="SELL", style=shape.labeldown, location=location.abovebar, color=bearCol, textcolor=color.white, text="SELL", size=size.small)

//━━━━━━━━ BAR COLOR
barcolor(trendDir == 1 ? color.new(bullCol, 65) : trendDir == -1 ? color.new(bearCol, 65) : na)

//━━━━━━━━ BACKGROUND
bgCol =
     showBg and isSqueeze ? color.new(color.yellow, 93) :
     showBg and isTrend   ? color.new(color.aqua, 94) :
     na

bgcolor(bgCol)

//━━━━━━━━ PANEL
var table tbl = table.new(position.top_right, 2, 7, border_width=1)

if showPanel and barstate.islast
    trendTxt = trendDir == 1 ? "BULL TREND" : trendDir == -1 ? "BEAR TREND" : "WAIT"
    trendTxtCol = trendDir == 1 ? bullCol : trendDir == -1 ? bearCol : color.gray

    stateTxt = isSqueeze ? "SQUEEZE" : isTrend ? "TREND" : "NORMAL"
    stateCol = isSqueeze ? color.yellow : isTrend ? color.aqua : color.gray

    emaTxt =
         close > ema100 ? "LONG OK" :
         close < ema50  ? "SHORT OK" :
         "NEUTRAL"

    emaCol =
         close > ema100 ? bullCol :
         close < ema50  ? bearCol :
         color.gray

    table.cell(tbl, 0, 0, "KOTANJAN", text_color=color.white, bgcolor=color.new(color.black, 0))
    table.cell(tbl, 1, 0, "COT TREND", text_color=color.gray, bgcolor=color.new(color.black, 0))

    table.cell(tbl, 0, 1, "Trend", text_color=color.white)
    table.cell(tbl, 1, 1, trendTxt, text_color=trendTxtCol)

    table.cell(tbl, 0, 2, "EMA Filter", text_color=color.white)
    table.cell(tbl, 1, 2, emaTxt, text_color=emaCol)

    table.cell(tbl, 0, 3, "Cot State", text_color=color.white)
    table.cell(tbl, 1, 3, stateTxt, text_color=stateCol)

    table.cell(tbl, 0, 4, "Angle", text_color=color.white)
    table.cell(tbl, 1, 4, str.tostring(angleDeg, "#.0") + "°", text_color=angleDeg >= 0 ? bullCol : bearCol)

    table.cell(tbl, 0, 5, "Cot", text_color=color.white)
    table.cell(tbl, 1, 5, str.tostring(cotVal, "#.##"), text_color=stateCol)

    table.cell(tbl, 0, 6, "Strength", text_color=color.white)
    table.cell(tbl, 1, 6, str.tostring(strength, "#.##"), text_color=color.white)

//━━━━━━━━ ALERTS
alertcondition(newBuy, "Kotanjan BUY", "Kotanjan Cot Trend BUY")
alertcondition(newSell, "Kotanjan SELL", "Kotanjan Cot Trend SELL")
````
