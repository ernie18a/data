Within the selected test period, evaluate four configurable signal groups. Each group combines up to four comparisons between selected indicators, price fields, an external series, or a fixed threshold, using crossover, crossunder, cross, rising/falling, or relational operators; combine active comparisons in order with AND/OR. The default long-entry rule is: the second selected indicator crosses above the third, AND the second is below its threshold, AND the first is below the current low. The default short-entry rule is the inverse pattern: the second crosses below the third, AND is above its threshold, AND the first is above the current high. No explicit exit rules are active by default; an opposite entry closes the existing position. Indicator choices, sources, timeframes, comparisons, joins, and thresholds are configurable.
