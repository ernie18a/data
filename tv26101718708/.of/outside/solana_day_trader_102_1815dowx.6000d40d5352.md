The first newly observed exit type triggers a partial exit; a second distinct type within the escalation window triggers a full exit. Any such exit triggers a full exit if nearby overhead sell-side liquidity is detected. An optional trend-quality collapse—prior value above its upper threshold and current value below its lower threshold—also triggers a full exit immediately.
