On each chart bar, evaluate the traded instrument, total crypto market capitalization, and Bitcoin dominance at the chart timeframe. Apply the same event engine to each series:

1. Detect a confirmed range-engulfing bar when the recent short window contains both the high and low of the preceding double-length window and one extreme occurred at the specified offset. After the required separation from a previous valid bar, retain its high and low. A close crossing above the retained high or below the retained low changes the range-break direction; emit an event only when that direction changes.
2. Detect confirmed pivot highs and lows. From each pivot, project a descending high line or ascending low line using a slope based on the selected ATR, standard deviation, or absolute linear-regression calculation. Emit a directional event on the first close beyond the corresponding projected line after each pivot. Pair a range-break event and a projected-line event of the same direction within the pairing window, in either order, to produce a structural event. Expire unmatched events; process range events before line events.
3. Calculate a causal Gaussian-weighted close estimate and an envelope based on the moving average of its absolute error. Record the latest lower-envelope downward cross as bullish and upper-envelope upward cross as bearish. Also maintain an ATR-distance trailing stop and its direction. A bullish confirmation occurs when a lower-envelope cross happens while the stop direction is bullish, or the stop turns bullish while the latest envelope cross is bullish; bearish confirmation is symmetric. Optionally require a recent same-direction liquidity sweep. For the traded instrument only, optionally require its ADX to meet the threshold. Use the instrument's ATR for its stop and a simple average of true range for the two external series.
4. Arm a phase whenever the traded instrument's volume exceeds its threshold and its close differs from its exponential average; for either external series, arm it whenever true range exceeds its average. Arming resets the phase even if it was already active. In the armed phase, bearish confirmation emits a bullish phase event and bullish confirmation emits a bearish phase event, then moves to a second phase. In the second phase, bullish confirmation emits a bullish phase event and bearish confirmation emits a bearish phase event, then returns to idle. Respect that order if both confirmations occur.
5. Pair each phase event with a structural event of the same direction within the second pairing window, in either order, expiring unmatched events and processing phase events first. Invert the resulting direction: a paired bearish event is a long event and a paired bullish event is a short event.

For the traded instrument, optionally block its long event if recent RSI was below its lower boundary, the MACD histogram is negative and falling, or a recent bearish candle body exceeds current ATR times its multiplier, according to which filters are enabled. Symmetrically block its short event for RSI above its upper boundary, a positive and rising MACD histogram, or an oversized recent bullish body.

Remember each external long and short event independently for the macro alignment window. Generate an early long when total-cap and dominance long memories first become simultaneously active, provided there is no unblocked instrument long event on that bar. Generate an early short symmetrically from both external short memories, provided there is no unblocked instrument short event. The instrument's unblocked long or short events also trigger their respective trades regardless of macro alignment; the named macro combinations only classify those same events.

Maintain flat, long, or short state. On a long trigger, if not already long, close any short and then enter long. Next process a short trigger: if not already short, close any long and then enter short. Thus simultaneous triggers are processed long first and short second. There is no independent exit rule.
