For a forex pair, calculate each currency’s return against USD over a rolling lookback or from the weekly open, invert returns for currencies quoted against USD, then subtract the average return across the currency basket from each currency’s return. Optionally smooth both strengths. When base strength crosses above quote strength, signal bullish momentum in the pair (long); when it crosses below, signal bearish momentum (short). When the absolute strength gap first reaches a configurable overextension threshold, issue an exhaustion warning to watch for a reversal; this is not itself an exit signal.
