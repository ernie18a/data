Use externally supplied SPX gamma levels for the zero-gamma boundary and positive-gamma ceiling. Translate each to the traded futures price scale by adding the latest available difference between completed futures and SPX bar closes whose closing timestamps match; retain the last matched difference, or use zero until one is available.

Track the latest confirmed swing high and low using a configurable symmetric pivot window. When the close crosses below the latest swing low, set bearish structure and clear bullish structure. When it crosses above the latest swing high, set bullish structure and clear bearish structure; if both events occur on one bar, bullish structure takes precedence. Structure remains in effect until an opposite break.

Favor short when the futures close is below the adjusted zero-gamma boundary and either the optional structure filter is disabled or bearish structure is active. Otherwise favor long when the close is above the adjusted ceiling and either the filter is disabled or bullish structure is active. Short takes precedence if both conditions hold. If price meets a directional threshold but its required structure is absent, await structure. Otherwise report neutral. The indicator does not define automatic entries or exits; its entry zones, stops, targets, volume and liquidity readings are displayed references rather than additional decision conditions.
