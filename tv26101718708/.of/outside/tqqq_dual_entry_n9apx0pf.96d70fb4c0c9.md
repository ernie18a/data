Use the reference ETF’s closing price, moving averages, and volume to generate long entries for the traded leveraged ETF. Enter when either (a) the reference close newly satisfies the configured sustained-above-long-term-average condition, including any enabled price buffer, or (b) it newly closes above a short-term EMA while satisfying any enabled volume-above-average and rising-EMA trend filters. If both entry conditions first occur together, use the long-term-average entry mode. Execute entry signals at the next bar’s open. For long-term-average entries, exit when the reference close newly satisfies the configured sustained-below-exit-average condition, including any enabled downside buffer. For EMA entries, exit when the reference close crosses below the short-term EMA; if, while in the position, the reference close ever rises above the long-term entry average, permanently switch that position to the long-term-average exit rule. Also exit intrabar if the traded ETF’s low reaches the configured loss threshold below its entry price, using the bar open if it gaps below that threshold and otherwise the threshold price.
