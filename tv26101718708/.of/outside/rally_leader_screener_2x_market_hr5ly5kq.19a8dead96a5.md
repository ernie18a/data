For each stock, compare its percentage return over a configurable lookback with the benchmark index return over the same period. Flag it as a rally leader when the index return is positive and the stock return is at least a configurable multiple of the index return. When the index return is zero or negative, flag it as resisting weakness if the stock return meets a configurable minimum. Apply configurable liquidity and trend filters to both flags, including minimum price, average volume, price above a moving average, and an up-day requirement. These are screening flags, not entry or exit signals.
