Compute realized volatility from the traded instrument’s log returns and compare it with an implied-volatility measure from a relevant volatility index. Define the spread as implied volatility minus realized volatility, and use the spread’s rolling standard deviation to set symmetric upper and lower thresholds. Go long when the spread is above the upper threshold; go short when it is below the lower threshold. Exit a long when the spread crosses above zero, and exit a short when it crosses below zero.
