Compare the traded instrument’s lookback percentage return with an external market index’s lookback percentage return, optionally smoothing both with the same moving-average method. Enter long when the instrument’s return is greater than the index’s; close the long when it is less. In the alternative mode, compare the instrument’s return minus the index’s return with a moving average of that difference: enter long when the difference is greater than its average, and close when it is less. Entries are restricted to the configured backtest date range; no short positions are opened.
