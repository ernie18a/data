At each bar, compare six configured USD-denominated assets with each other and with USD. For each pair of assets, calculate the selected trend test on the price ratio with the earlier-configured asset as numerator; for each asset versus USD, calculate it on the asset's own price. A test is bullish when RSI is above its midpoint, CCI is above zero, SuperTrend indicates an uptrend, positive directional movement exceeds negative directional movement, or Parabolic SAR is below close, respectively. In the combined mode, the test is bullish if any one of those five tests is bullish. Award one point to the numerator or asset when its test is bullish; otherwise award one point to the denominator or USD. Sum each candidate's points. Select the highest score by starting with the previous bar's winning index, initially the first asset, and scanning the assets in configuration order followed by USD, replacing the winner only for a strictly higher score. Thus the prior winner retains a tie if it shares the maximum; otherwise the first encountered maximum wins. Hold the selected asset long and exit the previous asset when the selection changes; if USD wins, hold cash. Use the completed bar's selection for the following bar's position.
