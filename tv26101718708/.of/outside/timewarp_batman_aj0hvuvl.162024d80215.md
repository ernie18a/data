At the configured time before the market close, once per session, use the underlying’s closing price rounded to its strike increment as the reference. Choose a wing width from the configured fixed width or the volatility-based sizing rule. Place a long call butterfly above spot and an independent long put butterfly below spot: offset each body from the reference by a fixed distance plus the wing width, round to the strike increment, and place equal wings on either side. Enter both flies for the applicable next-session expiry, using the configured reward-to-risk range to set the target debit per fly. On Fridays, use the following Monday’s expiry. Alert if price reaches or passes either outer wing; this is a review signal, not an explicit exit instruction.
