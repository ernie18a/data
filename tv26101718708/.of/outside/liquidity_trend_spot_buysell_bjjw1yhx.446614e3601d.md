On each daily bar, sum US, eurozone, Japanese, Chinese, UK and Canadian M2 after converting each to USD using its corresponding exchange rate. Smooth the sum with a simple moving average, calculate its rate of change relative to the absolute value of its earlier smoothed value, and standardize that impulse using the mean and sample standard deviation of prior impulses, excluding the current bar. When the score exceeds the positive threshold, set a persistent preliminary liquidity state bullish; when it falls below the negative threshold, set it bearish; otherwise retain its previous state. Confirm a change after the preliminary state persists for the configured number of bars, including bars back inside the band; an opposite threshold breach can cancel it. Before the first confirmed state, use the preliminary state immediately. A missing score leaves the preliminary state unchanged.

For the trend component, calculate fast and slow Wilder-smoothed averages of the selected price series: Bitcoin by default, or the traded instrument. The trend is bullish only when both averages are available and the fast average is strictly above the slow average.

Select liquidity-only, trend-only, or combined mode. In combined mode, the desired state is long if either component is bullish; otherwise it is cash. In each single-component mode, it is long only if that component is bullish. Initialize the position to the desired state on the first bar. Thereafter, change to the current desired state only after the existing long or cash state has lasted the configured minimum number of bars; reset the counter at each change. Buy on a change to long and sell to cash on a change out of long. Never short.
