For each market, select commercial or non-commercial traders and use weekly COT reports, optionally including options. Compute each group’s net position as longs minus shorts, then subtract the opposite group’s net from the selected group’s net. For short, medium and long report windows, express the current spread’s position within its historical minimum–maximum range; use the midpoint when the range is flat and whatever history is available when shorter than the window. Compute the previous report’s short- and medium-window readings the same way. Form a weighted average of the three current readings, giving greater weight to longer windows, and calculate the selected group’s weekly net-position change.

Apply these states in order: If any current reading is unavailable, report no data. Define a bullish setup as either all three readings being at low extreme thresholds, or the weighted average and long-window reading both being below their respective bullish thresholds. Within a bullish setup, if the short-window reading has risen and the medium-window reading has not fallen, report a bullish turn; if net position also increased, report long build instead. Otherwise report a buy/bottom setup. Define a bearish setup symmetrically using high extreme thresholds or high weighted-average and long-window thresholds. Within a bearish setup, if the short-window reading has fallen and the medium-window reading has not risen, report a bearish turn; if net position also decreased, report short build instead. Otherwise report top risk. For either turn, allow a missing previous medium-window reading, but require the previous short-window reading.

If neither setup applies, report long bias when the weighted average is below a bullish threshold, changing it to long unwind if net position decreased. Report short bias when the weighted average is above a bearish threshold, changing it to short cover if net position increased. Otherwise report neutral. Commercial-mode states describe the commercial participant’s perspective.
