On each bar, calculate realized volatility as the rolling standard deviation of the traded instrument's log close-to-close returns, annualized by the square root of bars per year and expressed as a percentage. Subtract it from the same-timeframe close of an external implied-volatility index. Normalize this difference using its rolling mean and standard deviation, using zero when the standard deviation is not positive, then smooth it with an exponential moving average. Signal long when the smoothed value crosses upward through a negative stretch threshold: the previous value was at or below the threshold and the current value is above it. Signal short when it crosses downward through the corresponding positive threshold: the previous value was at or above the threshold and the current value is below it. No exit rule is specified.
