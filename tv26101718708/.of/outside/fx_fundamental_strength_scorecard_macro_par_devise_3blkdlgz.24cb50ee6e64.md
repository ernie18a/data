Directional macro bias for a currency pair (base/quote), computed from external macro data only. The user selects the two currencies, and the bias applies to the pair, so long means long base against quote. Per currency, use central bank policy rate and government bond yields at 2-year and 10-year tenors. Yields are daily closes, and the euro uses German bond yields. For each enabled metric (policy rate, 2Y yield, 10Y yield), compute differential = base value minus quote value. Skip any metric whose data is unavailable. Each available metric casts a vote equal to the sign of its differential: +1 if positive, -1 if negative, 0 if zero. Bias score = sum of votes divided by the number of available metrics, which lies between -1 and +1. If no metric is available, there is no bias and no position. Decision: if the score is clearly positive (above roughly one third, so a majority of available metrics favor the base), go or stay long the pair. If the score is clearly negative (below roughly minus one third, so a majority favor the quote), go or stay short the pair. Otherwise the bias is neutral, so exit or stay flat. Strength is graded as moderate when the magnitude is above one third and strong when it is above about two thirds, but the action is the same. Trend of the differentials over a lookback window is display-only and does not affect the decision. Re-evaluate on each bar using the latest available data. The bias is a directional context filter rather than an entry timing signal.
