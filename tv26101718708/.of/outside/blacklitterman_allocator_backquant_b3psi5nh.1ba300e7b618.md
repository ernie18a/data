On confirmed bars, maintain a rolling window of each selected asset’s log returns, replacing missing returns with zero. Admit an asset after it has accumulated a full window of valid price observations; exclude views referencing unavailable assets. Begin with zero weights. After the start date, rebalance when the window is full and at least two assets are available, on scheduled bars, when the number of available assets changes, or when the optional chart-symbol regime filter changes from inactive to active. Between rebalances, retain weights. If the filter is enabled and the chart symbol’s fast closing-price EMA is not above its slow EMA, flatten all positions; otherwise the regime is active.

At each rebalance, annualize the sample covariance of the rolling log returns, shrink off-diagonal terms toward zero and add a small diagonal stabilizer. Form a normalized prior across available assets using equal weights, inverse historical volatility, or nonnegative manual weights; if manual weights total zero, use equal weights. Use either manual risk aversion or the bounded ratio of prior-weighted annualized lookback simple return minus the risk-free rate to prior portfolio variance, falling back to manual risk aversion if variance is nonpositive. Multiply covariance by the prior weights and risk aversion to obtain equilibrium returns.

For each enabled, available investor view, create an exposure row with positive exposure to the first asset and, for a relative view, negative exposure to the second. Set its expected annual return and confidence from the user’s inputs. Scale covariance by prior uncertainty. Give each view diagonal uncertainty equal to its confidence-odds of error times the greater of its exposure variance and a small positive floor. Combine equilibrium returns with the views using the standard Black-Litterman posterior: add the scaled covariance times the transposed exposure matrix times the inverse of exposure covariance plus view uncertainty times the difference between stated and equilibrium-implied view returns. If enabled and there are usable views, use the corresponding posterior covariance adjustment; otherwise use the original covariance. Use a pseudoinverse when a matrix cannot be safely inverted.

Obtain raw weights by multiplying posterior expected returns by the inverse of risk aversion times the chosen covariance. If any raw weight is unavailable, retain the previous book. Otherwise zero unavailable assets and, in long-only mode, clip negative weights to zero. If gross weight is zero, retain the previous book. Normalize remaining weights to the requested gross exposure, scale them by target volatility divided by covariance-based portfolio volatility within the configured scaling limits, cap each absolute position, then proportionally reduce the whole book if its gross exposure exceeds the final limit. Commit these weights: positive means long, negative means short, and zero means exit. Apply the current bar’s return using the previous weights before committing the new book.
