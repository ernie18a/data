After the configured start and before option expiry, act only at scheduled hedge intervals. In Simple mode, when the traded instrument’s close crosses above the strike, open the configured position size if the selected option type and position side call for a long; otherwise close the hedge if they call for a short. When the close crosses below the strike, open the configured size for a short if called for, otherwise close the hedge. In Synthetic option mode, calculate the option’s delta from the selected option model and market inputs, then compare delta-scaled position size with the current instrument position. If the difference is positive, trade that amount in the direction set by the configured position side; if negative, trade its absolute amount in the opposite direction. Trade only when the adjustment does not exceed the configured position size. Close the hedge after option expiry. In None mode, do not trade.
