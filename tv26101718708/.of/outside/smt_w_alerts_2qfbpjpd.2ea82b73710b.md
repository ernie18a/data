On each bar, confirm swing highs and lows on the traded instrument using configurable left and right pivot windows. Compare each newly confirmed pivot with the preceding pivot of the same type, provided their separation is positive and within a configurable maximum. For each pivot, record each comparison instrument's highest high or lowest low, as appropriate, within a configurable tolerance around the pivot bar, using only bars available at confirmation. Require the preceding pivot's value for the first comparison instrument to be available. Signal short when consecutive traded-instrument highs move strictly in the opposite direction to the corresponding highs of either the first comparison instrument or an enabled second comparison instrument. Signal long when consecutive lows move strictly in the opposite direction to the corresponding lows of either comparison instrument. Equal values do not diverge. Emit signals on the pivot confirmation bar; long and short signals can occur together. No exit rule is specified.
