On each underlying bar, calculate an exponential moving average of the close and VWAP of the typical price. Track one option position, its entry premium, and its profit target. First, if the high of the configured premium contract for the open option reaches its target, exit at the target and clear the position. Then process crossovers: when the moving average crosses below VWAP, signal an exit for any open call and, if the configured put contract's close is available, buy a put. When it crosses above VWAP, signal an exit for any open put and, if the configured call contract's close is available, buy a call. For each purchase, round the underlying close to the nearest configured strike interval and select the adjacent in-the-money strike. Record the configured option contract's close as the entry premium and set the target to that premium increased by the configured profit percentage. Premium data comes from independently configured call and put contracts, which need not match the calculated strikes. If a reversal exit occurs but the new option's close is unavailable, the existing position state and target remain unchanged. Evaluate targets before crossovers, so a new position cannot hit its target on its entry bar.
