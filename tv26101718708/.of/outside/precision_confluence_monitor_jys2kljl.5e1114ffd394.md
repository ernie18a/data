For each configured traded-index level and its positionally paired external-index level, treat a missing external level as always confirmed. When both indices close above their levels, start a call setup; when both close below, start a put setup. If enabled, require both indices to satisfy the direction’s fast/slow moving-average trend filter to start a setup, and require the configured volume threshold on setup and confirmation bars. On the next bar, enter the corresponding calls or puts only if both indices remain on the same side of their levels; avoid entry if that level has reached the repeated-failure cutoff. If price reverses across its level or the external index loses confirmation before entry, cancel the setup and count a failure. Reset setup states and failure counts each day.
