Use configured offensive and defensive asset universes and daily closes. For each asset, calculate a momentum score as the weighted sum of simple returns over four configured lookbacks, with greater weight on shorter lookbacks. Count offensive assets whose score is zero or negative. If that count reaches the configured breadth threshold, select the defensive asset with the highest score; otherwise select the offensive asset with the highest score. Break ties by universe order. Hold the selected asset long with the entire allocation, exiting the previous asset when selection changes. Initialize as soon as all assets have valid positive current and lookback closes. In monthly mode, update on the first bar of a new month using the previous bar's scores; otherwise update daily using current scores. If the required data is unavailable at an update, retain the existing allocation.
