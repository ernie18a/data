On each closed bar, update the two most recent confirmed swing highs and lows for the traded instrument and a correlated instrument on the same timeframe. Confirm each swing using an equal configurable number of bars on either side; carry forward the correlated instrument's last available data across gaps. A short signal occurs only when a new traded-instrument swing high is confirmed, its latest high exceeds its previous high, and the correlated instrument's latest high is below its previous high. A long signal occurs only when a new traded-instrument swing low is confirmed, its latest low is below its previous low, and the correlated instrument's latest low exceeds its previous low. For either signal, require two relevant swings for each instrument and require the latest swing bars to be within a configurable number of bars of each other. If the optional volatility filter is enabled, also require the traded instrument's current average true range to be at least a configurable multiple of its simple moving average, calculated over twice the average true range period. Evaluate using all swing updates confirmed on the current close. No exit rule is specified.
