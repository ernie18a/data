Process the traded instrument, total crypto market capitalization, and Bitcoin dominance on the chart timeframe. Maintain independent state for each series. All periods, thresholds, multipliers, and matching windows are configurable parameters.

For each series, detect a confirmed range event when the extrema over a recent window also equal those over the preceding double-length window, at least one extremum occurs at the specified offset, and enough bars have passed since the previous valid event. Save the event's high and low. Generate an upward or downward range-break event when close crosses the saved high or low and changes the persistent range direction.

Also track confirmed pivot highs and lows. At each pivot, set a slope from either ATR, close standard deviation, or absolute linear-regression slope, scaled as configured. Project the high line downward and the low line upward each bar. Generate an upward or downward pivot-break event the first time close exceeds the appropriately offset projected high line or falls below the offset projected low line after its latest pivot. For each direction, match a range-break event and a pivot-break event in either order within the first matching window. Expire unmatched events, reset the window on each event, and process range-break events before pivot-break events when both occur on the same bar.

Independently calculate a one-sided Gaussian-weighted average of current and historical closes and an envelope whose width is a moving average of absolute deviations from that average times a multiplier. Remember the most recent downward crossing of the lower envelope as bullish and upward crossing of the upper envelope as bearish. Maintain an ATR-distance trailing stop: ratchet it upward while consecutive closes are above the prior stop, downward while consecutive closes are below it, and otherwise reset it to close minus or plus the distance according to which side close occupies. A close crossing the prior stop changes the persistent stop direction. A bullish or bearish envelope-stop event occurs when an envelope crossing agrees with the current stop direction, or a stop-direction change agrees with the remembered envelope direction. Optionally require a recent downside or upside liquidity sweep respectively; a sweep breaches the previous lookback low or high and closes back inside it. For the traded instrument only, optionally also require its ADX to meet the configured threshold. Use the instrument's ATR for its stop and slope; for the external series use simple averages of their true ranges.

For each series, maintain a phase initially idle. A pump resets it to the first phase on every bar: for the instrument, volume exceeds its threshold and close differs from its exponential average; for an external series, true range exceeds its average. In the first phase, a bearish envelope-stop event emits a bullish phase event, while a bullish envelope-stop event emits a bearish phase event; either moves to the second phase. In the second phase, bullish and bearish envelope-stop events emit their respective same-direction phase events and return to idle. Apply the pump reset before processing events and give the bearish event priority in the first phase and the bullish event priority in the second.

For each direction, match the corresponding phase event and range-plus-pivot event in either order within a second matching window, with independent expiration and reset. Process the phase event first if both occur together. Invert the resulting direction: a bearish match is a long signal and a bullish match is a short signal.

Optionally block an instrument long signal when recent RSI has fallen below its lower boundary, the MACD histogram is negative and falling, or a recent bearish candle body exceeds current ATR times its expansion multiplier, according to which filters are enabled. Block an instrument short signal analogously for RSI above its upper boundary, a positive rising MACD histogram, or a large bullish candle body. Each enabled filter blocks independently.

Remember each external long and short signal for the macro alignment window; opposite signals may both remain active. An early long occurs when the total-cap long and dominance long states first become simultaneously active, provided there is no unblocked instrument long on that bar. An early short analogously uses both external short states and requires no unblocked instrument short. An unblocked instrument signal is itself actionable regardless of macro alignment.

Enter long on an unblocked instrument long or early long; enter short on an unblocked instrument short or early short. Keep a persistent flat, long, or short position state and ignore signals for the current position. On an opposite signal, issue the existing position's exit before the new entry. Process long conditions before short conditions, so simultaneous opposite signals can cause two sequential position changes. Alerts are configured for once per bar close.
