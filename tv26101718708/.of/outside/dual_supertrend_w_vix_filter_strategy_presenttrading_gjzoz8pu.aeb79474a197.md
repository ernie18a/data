On each confirmed bar, calculate two independent trend states from the traded instrument using separately parameterized ATR lengths and multipliers. For each, set basic bands to the high-low midpoint minus and plus the multiplier times Wilder-smoothed ATR. Carry the lower band upward using the maximum of its current and previous values when the previous close was above the previous lower band; otherwise reset it to the current basic lower band. Carry the upper band downward analogously using the minimum when the previous close was below the previous upper band. Set the state bullish if the close exceeds the previous upper band, bearish if it falls below the previous lower band, and otherwise retain the previous state.

Request the volatility index's daily close without lookahead, mapped onto the traded instrument's bars. Calculate its rolling mean, standard deviation and EMA on that mapped series. Independently select a long filter from: below the mean minus a standard-deviation band, below the mean, below the EMA, above the mean, above the EMA, or unrestricted. Select a short filter from: above the mean plus a standard-deviation band, above the mean, above the EMA, or unrestricted. All comparisons are strict. The volatility filter can also be disabled entirely.

In an allowed trading direction, enter long when both trend states are bullish and the long filter passes; enter short when both are bearish and the short filter passes. Enter only if flat or holding the opposite direction, reversing an opposite position. Close a long when either state becomes bearish, and close a short when either becomes bullish; these trend exits do not require the volatility filter to pass.

Optionally place four partial take-profit orders, each for a configured percentage of the original position, at favorable distances from the average entry price. Distances are either configured percentages of entry or configured multiples of the current ATR, recalculated each bar. Each partial order also has the same adverse percentage stop; any unallocated position remains subject to trend exits. Alternatively, enable a full-position percentage profit target and stop, with an optional trailing stop activated at a favorable percentage distance from entry and using the configured entry-price-based trail offset in ticks. The partial-exit mode overrides the standard exit mode.
