On each closed bar, sum the current volume of the traded instrument across enabled external exchanges, treating unavailable volumes as zero. Compare this sum with either the average or maximum of the sums over a configurable window of preceding bars, excluding the current bar. If anomaly detection is enabled, the current sum and baseline are positive, and the current sum reaches the baseline multiplied by one plus a configurable excess threshold, signal long when the footprint delta is nonnegative and short when it is negative. If footprint delta is unavailable, signal long when the close is at or above the open and short otherwise. Otherwise, produce no signal. This rule applies when detection is set to all bars and the selected volume metric is the sum across exchanges.
