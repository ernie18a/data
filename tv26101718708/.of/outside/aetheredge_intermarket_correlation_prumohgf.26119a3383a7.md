On each chart bar, calculate percentage returns for the traded instrument and six configurable reference markets, using the selected reference timeframe; use zero returns for blank references. Standardize each return using its rolling mean and standard deviation, with a small positive floor on the deviation. Initialize an online linear regression, including an intercept, to zero. On each confirmed bar after the initial startup bars, update it by gradient descent using the previous bar's standardized returns as features and the current traded-instrument return as the target. Then forecast the next return from the current standardized returns and updated coefficients. After the configured warmup, designate long when the forecast exceeds a configurable multiple of the traded instrument's rolling return standard deviation, short when it is below the negative threshold, and flat otherwise. Emit a directional signal only when its corresponding bias becomes true after being false. Training is not gated on feature availability: unavailable early standardized values propagate into the coefficients and can leave the model permanently unable to produce a directional bias.
