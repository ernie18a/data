On each chart bar, calculate fast and slow EMAs of the instrument and of the external OTHERS.D index. Classify the instrument as bullish when its fast EMA is at least its slow EMA, otherwise bearish; classify the index the same way. A long EMA signal occurs when the instrument fast EMA is above its slow EMA, or they are equal and the index is bearish. A short EMA signal occurs whenever the instrument fast EMA is below its slow EMA.

Confirm swing highs and lows using a symmetric window of bars, retaining the latest confirmed value of each. Set the structural trend bullish when the close breaks above the latest swing high and bearish when it breaks below the latest swing low; otherwise retain its previous state. If both breaks occur on the same bar, bearish takes precedence.

When flat, enter long if the long EMA signal and bullish structural trend hold, RSI is below its upper entry threshold, and long entry is not blocked. Enter short if the short EMA signal and bearish structural trend hold, RSI is above its lower entry threshold, and short entry is not blocked. An opposite EMA signal closes an existing position when entry in that direction is not blocked, even if the structural trend or RSI does not permit a new entry. An opposing structural trend also closes the position. Orders are evaluated on bar close, with position changes following the strategy's normal order-fill timing.

Calculate open-position return from the latest entry price and current close. If it falls below the loss threshold, close a long only when there is no short EMA signal, or a short only when there is no long EMA signal, and block re-entry in the stopped direction. Clear a long block when the previous instrument classification was bullish and the current classification is anything except instrument bearish with index bullish. Clear a short block when the previous instrument classification was bearish and the current classification is anything except instrument bullish with index bearish.

Once per position, partially close a profitable long when the previous bar had both instrument and index bullish and that joint state ends, provided there is no short EMA signal. Similarly, partially close a profitable short when the previous bar had both bearish and that joint state ends, provided there is no long EMA signal. Require return to exceed the configured minimum profit.

If take profit is enabled, set three fixed targets at entry using the signal-bar close plus or minus successive multiples of the signal-bar ATR, scaled by a configurable factor. For a long, trigger each target once when a later bar's high strictly exceeds it; for a short, when its low strictly falls below it. Each trigger closes a configured fraction of the remaining position. The remainder is subject to the other exit rules.
