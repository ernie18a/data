For each bar, encode the traded instrument's source change and the reference instrument's close change as binary states: nonnegative is up, negative is down. Over a rolling window, estimate transfer entropy in each direction as the sum over observed state triples of P(target current, target previous, source previous) times log2[P(target current | target previous, source previous) / P(target current | target previous)]. If finite-sample correction is enabled, add (number of observed target-current/target-previous pairs + number of observed target-previous/source-previous pairs - number of observed target-previous states - number of observed triples) / (2 × window size × ln(2)) to each estimate. Subtract traded-to-reference entropy from reference-to-traded entropy, and optionally smooth the difference with an exponential moving average.

If the optional trend filter is enabled, estimate the traded instrument's Hurst exponent as the slope of a linear regression of log(mean absolute log-price change) against log(lag), using lags of 1, 2, 4 and 8 bars over a rolling window. Clamp the slope to the range from zero to one; the filter passes when it is at least one-half.

When the net entropy is at least the lead threshold and the trend filter passes or is disabled, signal long if the reference close has risen over its momentum lookback, or short if it has fallen. A flat reference, unavailable required data, or failure of either filter produces no signal. The calibration statistics do not gate signals. No exit rule is specified.
