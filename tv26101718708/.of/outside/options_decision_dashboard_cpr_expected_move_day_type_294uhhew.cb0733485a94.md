On each intraday bar, calculate the prior session’s central pivot as (high + low + close) / 3, its bottom level as (high + low) / 2, and its top level as twice the pivot minus the bottom level. Order the two outer levels to form the pivot range. Rank its absolute width against a rolling history of daily widths by the percentage strictly below the current width, including the current session’s width. Classify the rank as narrow, wide, or neutral using configurable thresholds. Direction is bullish when the current close is above the range, bearish when below it, and absent otherwise.

Calculate implied volatility from the configured volatility index, option-straddle proxy, or manual source, with the configured source selection and fallbacks. Calculate annualized realized volatility from the configured daily estimator. The volatility premium is implied minus realized volatility; classify it as rich when its rolling median-and-MAD standardized score exceeds a configurable threshold. Also classify implied volatility as high when its rank within the volatility index’s rolling high-low range reaches a configurable threshold; this rank is available only when the index supplies implied volatility. Options are expensive if either condition holds.

For the selected horizon and anchor, calculate the expected move as anchor price times annualized implied volatility times the square root of horizon in years. For bullish direction, the first target is twice the pivot minus the prior low; for bearish direction, it is twice the pivot minus the prior high. The target covers the priced move when the absolute distance from today’s open to that target is at least the expected move. Treat this test as passed if it is disabled or either value is unavailable. Suppress buying when the selected horizon, subject to its minimum floor, is less than the configured expiry threshold.

Apply these decisions in order: if the chart is not intraday or the volatility premium or pivot-width history is unavailable, make no trade decision. If the day is wide, or direction is absent and the day is not narrow, sell option premium when options are expensive; otherwise stay out. If the day is narrow and direction is present, buy a call for bullish direction or a put for bearish direction when the optional expensive-volatility veto does not apply, expiry suppression does not apply, and the target covers the priced move. Under the same conditions except that the target fails to cover the priced move, sell option premium. If the expensive-volatility veto applies, wait. If expiry suppression applies, stay out. All remaining cases produce no trade decision.

For the displayed headline, override any decision with stay out when the volatility index percentile reaches its configured tail threshold or realized volatility exceeds a configured multiple of its rolling median. This override does not change the underlying decision code or its alerts. The separate gap, expiry and false-momentum buyer-safety checks annotate buys without changing that decision. The two-day pivot relationship and historical calibration likewise do not change the decision.
