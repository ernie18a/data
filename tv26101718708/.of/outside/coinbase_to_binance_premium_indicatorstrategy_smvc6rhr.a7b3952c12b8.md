When trading is enabled and the bar is within the optional date window, calculate the premium as the Coinbase USD pair close minus the Binance USDT pair close. Select one signal rule: if the moving-average rule is enabled, buy when the fast weighted moving average of the premium crosses above the slow one and sell when it crosses below; otherwise, if the raw-difference rule is enabled, buy or sell when the premium crosses above or below a configurable threshold; otherwise, if the smoothing rule is enabled, use the smoothed fast weighted moving average crossing that threshold; otherwise use the fast weighted moving average crossing that threshold. If multiple rules are enabled, the moving-average rule takes precedence over raw-difference, which takes precedence over smoothing. A buy signal enters long. A sell signal enters short when shorting is allowed; in long-only mode it closes all positions.
