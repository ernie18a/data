On each chart bar, consider a long only when the traded instrument’s EMA is rising, its swing-break trend is up, and ADX exceeds its threshold; consider a short under the opposite EMA and trend conditions with ADX above the threshold. Define the swing-break trend by retaining the latest confirmed swing high and low: a close above the high sets it up, and a close below the low sets it down, until another break changes it. For the daily filter, apply the same trend rule to confirmed daily pivots and the previous daily close. If daily and chart trends oppose, block entries when price is within the inclusive middle Fibonacci zone of the latest daily swing range; allow them outside it. An unknown daily trend or unavailable swing range does not block entry. When the optional external footprint filter is enabled, calculate a moving average of buy-minus-sell volume for the selected reference instrument on the chart timeframe. Allow longs only when it is positive and shorts only when it is negative. A zero average blocks both directions; unavailable footprint data passes the filter. When the filter is disabled, it imposes no restriction. Enter only while flat; if an opposite position exists, close it first and wait until flat before entering.
