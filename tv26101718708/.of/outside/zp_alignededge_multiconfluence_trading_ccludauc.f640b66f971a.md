On each bar close, confirm swing highs and lows using symmetric pivots. A close crossing above the latest confirmed swing high activates bullish-break state and clears bearish-break state; crossing below the latest confirmed swing low activates bearish-break state and clears bullish-break state. Generate a long signal when bullish-break state is active and either the fast EMA crosses above the middle EMA or the middle EMA crosses above the long weighted moving average. Generate a short signal when bearish-break state is active and either the fast EMA crosses below the middle EMA or the middle EMA crosses below the long weighted moving average. If the higher-timeframe filter is enabled, allow longs only when the prior completed higher-timeframe bar's three EMAs are stacked in ascending order, and shorts only when they are stacked in descending order. The indicator defines no exit rule.
