On each bar, calculate fast and slow EMAs of the traded instrument's close and of a selected sector dominance series: either altcoin or memecoin market capitalization divided by total crypto market capitalization. A long signal requires both fast EMAs strictly above their slow EMAs; a short signal requires both strictly below. If the index filter is disabled, use only the instrument's EMA comparison for signals.

Define four alignment states using both EMA pairs even when the index filter is disabled: fully bullish when both fast EMAs are at least their slow EMAs; instrument-only bullish when the instrument fast EMA is at least its slow EMA and the index fast EMA is below its slow EMA; index-only bullish when the instrument fast EMA is below its slow EMA and the index fast EMA is above its slow EMA; otherwise fully bearish.

Close any position outside an enabled date window. Calculate directional percentage return from the latest entry price to the current close. Close the position when return exceeds the take-profit threshold. When return falls below the negative stop-loss threshold, close a long only if there is no short signal, or a short only if there is no long signal; block re-entry in the stopped direction. Clear a long block when the previous state was fully bullish or instrument-only bullish and the current state is not index-only bullish. Clear a short block when the previous state was fully bearish or index-only bullish and the current state is not instrument-only bullish.

If enabled, partially close a profitable long once per position when the previous state was fully bullish and the current state is not, provided return exceeds a small profit threshold and there is no short signal. Apply the symmetric rule to a short leaving the fully bearish state, provided there is no long signal. Close a configured fraction, rounded down to a multiple of an estimated minimum quantity, with at least that minimum.

Within the date window and while equity exceeds a configured fraction of initial capital, enter or reverse long on a long signal unless long is blocked; enter or reverse short on a short signal unless short is blocked. Only enter if flat or holding the opposite direction. Size the new position as a configured fraction of either current equity or initial capital divided by the current close. Reset the partial-exit flag and clear the directional block on entry.
