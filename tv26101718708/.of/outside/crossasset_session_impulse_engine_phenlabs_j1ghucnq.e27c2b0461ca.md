For each selected session, reset all state. Build and freeze the traded instrument’s opening high and low from a configurable number of session bars. Independently build the same opening range for each enabled external instrument using same-timeframe data and the same session clock; exclude the traded instrument and unavailable feeds. After each range locks, record whether its price has closed above its high or below its low. Each direction remains recorded for the rest of the session, so an external instrument can vote in both directions; reverse its votes if configured as inverse.

On a confirmed session bar, if ATR is available and positive and the optional relative-volume gate passes, arm long on the traded instrument’s first close above its opening high, or arm short on its first close below its opening low. The volume gate passes when disabled, when relative volume is unavailable, or when current volume divided by its moving average meets the configured minimum. A first break occurring while ATR or the volume gate fails cannot arm later. A subsequent first break in the opposite direction replaces the armed direction.

On each eligible confirmed session bar, signal the armed direction when the number of currently live external instruments with a recorded vote in that direction reaches the configured minimum. If no external instruments are live, bypass the vote requirement. Allow at most one signal per session; an armed direction can wait for later confirmation even if price returns inside the range.

After a long signal, flag invalidation if a confirmed session close falls below the opening low; after a short signal, flag invalidation if it rises above the opening high. Invalidation does not trigger another signal or explicitly execute an exit.
