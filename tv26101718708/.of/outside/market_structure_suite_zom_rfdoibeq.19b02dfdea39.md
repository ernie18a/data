After a confirmed swing pivot, if a bullish trend bias is active from a higher swing high, enter long when price pulls back by the configured fraction of the latest swing range from the latest high, then forms a bullish candle closing above the prior bar’s high. If a bearish bias is active from a lower swing low, enter short when price rallies by the configured fraction of the latest swing range from the latest low, then forms a bearish candle closing below the prior bar’s low. Each signal can occur only once per confirmed pivot. No exit rule is defined.
