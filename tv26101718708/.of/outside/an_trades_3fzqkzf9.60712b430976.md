On each chart bar, independently evaluate long and short entries using the traded instrument and, when enabled, a correlated instrument on the chart timeframe. Parameters control the timeframes, lookbacks, thresholds and optional filters.

Track the latest bullish and bearish fair value gap on each configured higher timeframe. A bullish gap spans the high two bars ago to the current low when the former is lower; a bearish gap spans the current high to the low two bars ago when the latter is higher. Replace the previous gap of the same direction when a new one appears. On each chart bar, discard a bullish gap if the close is above its top and a bearish gap if the close is below its bottom. A surviving gap is touched when the bar's range overlaps it. The lower-timeframe inverted gaps do not affect entries: each is discarded on the same bar it is created.

Track the latest confirmed pivot high and low, using equal left and right lookbacks. A bullish sweep occurs when the low falls below the latest pivot low and the close is above it; a bearish sweep occurs when the high exceeds the latest pivot high and the close is below it. Each sweep remains recent for a configured number of bars. Also compare each bar's low and high with the accumulated daily low and high before updating them; on the first bar of a new day, this comparison still uses the preceding day's extremes.

A long candidate requires a touched bullish higher-timeframe gap. A short candidate requires a touched bearish higher-timeframe gap. These touches also satisfy the sweep requirement, so sweeps and daily extremes do not independently restrict candidates. If manipulation invalidation is enabled, block a long after any close below the level of the latest bullish sweep, until another bullish sweep resets the block; mirror this for shorts using a close above the latest bearish sweep level.

If delivery confirmation is enabled, require the long bar's close to exceed the open of the latest bearish candle whose body-to-range ratio meets the configured minimum; require the short bar's close to be below the corresponding latest bullish candle open. Update these opens before testing confirmation and clear each open when its corresponding confirmation occurs, whether or not an entry results.

If divergence is enabled, require a long bar to make a low below the traded instrument's previous lookback low while the correlated instrument's low remains above its own previous lookback low. For a short, require a new traded-instrument high while the correlated instrument's high remains below its own previous lookback high.

If the liquidity-distance filter is enabled, retain the configured number of latest confirmed pivot highs and lows. When both a pivot high above the close and a pivot low below it exist, block a long if the nearest low is closer than the nearest high; block a short if the nearest high is closer than the nearest low. If the wick filter is enabled, block a long when its lower wick exceeds a configured multiple of average true range, and block a short when its upper wick exceeds that threshold.

Emit each direction's entry signal whenever its candidate and all enabled filters pass. Both signals can occur on the same bar. No exit or options decision is specified.
