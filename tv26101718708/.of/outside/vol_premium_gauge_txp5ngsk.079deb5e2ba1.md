On each chart bar, calculate realized volatility as the standard deviation of close-to-close log returns over the standard window, annualized by the square root of the applicable annualization factor and expressed as a percentage. Use the configured factor, except that its default selects the crypto or non-crypto factor according to the instrument. Obtain daily implied volatility from the configured custom index or, in automatic mode, from the matching published index: Bitcoin uses DVOL; S&P 500 uses VIX; Nasdaq 100 uses VXN; Russell 2000 uses RVX; Dow uses VXD; gold uses GVZ; crude oil uses OVX; and EUR/USD uses EVZ. Smooth the daily index values with an EMA on the chart timeframe. If the index is unmapped or its current value is unavailable, produce no option decision. Calculate the premium as smoothed implied volatility minus realized volatility. Calculate implied-volatility rank as the current smoothed value's position between its rolling minimum and maximum over the rank window; the rank is unavailable if that range is zero. Signal selling options when the premium is at least the rich threshold and rank is strictly above the upper rank threshold. Advise against selling when the premium is at most the cheap threshold and rank is strictly below the lower rank threshold. Otherwise give a neutral verdict. Emit a marker or alert only when either corresponding condition changes from false to true. The avoid-selling condition is not an instruction to buy options.
