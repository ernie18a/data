Calculation: Bull trend score = 40 if fast EMA > slow EMA, plus 30 if close > macro EMA, plus 20 if fast EMA slope > 0, plus 10 if slow EMA slope > 0; otherwise each component contributes 0. Fast EMA uses a shorter lookback than slow EMA; macro EMA uses a longer lookback than both. Slopes are EMA change over a lookback divided by that lookback.
Calculation: Bear trend score = 40 if fast EMA < slow EMA, plus 30 if close < macro EMA, plus 20 if fast EMA slope < 0, plus 10 if slow EMA slope < 0; otherwise each component contributes 0.
Calculation: Bull momentum score = 35 if RSI > its midline, plus 35 if MACD line > signal line, plus 30 if MACD histogram > its prior-bar value; otherwise each component contributes 0. MACD uses a shorter fast-EMA lookback than slow-EMA lookback.
Calculation: Bear momentum score = 35 if RSI < its midline, plus 35 if MACD line < signal line, plus 30 if MACD histogram < its prior-bar value; otherwise each component contributes 0.
Calculation: Bull volume score = 60 if volume >= its moving average times the spike multiplier and close > open, plus 40 if volume > prior-bar volume and close > open; otherwise each component contributes 0.
Calculation: Bear volume score = 60 if volume >= its moving average times the spike multiplier and close < open, plus 40 if volume > prior-bar volume and close < open; otherwise each component contributes 0.
Calculation: Bull structure score = 60 if the latest confirmed pivot high and low are both above their respective preceding pivots, plus 40 if prior-bar close exceeds the latest pivot high while the last structure-break direction is not bullish; otherwise each component contributes 0. Confirm pivots as strict extrema in a symmetric window, using only completed bars, and track the two latest confirmed highs and lows.
Calculation: Bear structure score = 60 if the latest confirmed pivot high and low are both below their respective preceding pivots, plus 40 if prior-bar close is below the latest pivot low while the last structure-break direction is not bearish; otherwise each component contributes 0.
Calculation: Bull score = weighted average of bull trend, momentum, volume, and structure scores using their respective weights, divided by the sum of those weights (use 1 if the sum is zero).
Calculation: Bear score = weighted average of bear trend, momentum, volume, and structure scores using their respective weights, divided by the sum of those weights (use 1 if the sum is zero).
Calculation: Volatility condition = ATR / close * 100 >= minimum ATR percentage.
Calculation: Higher-timeframe trend condition = last completed bar's close > its slow EMA for bullish alignment, or < its slow EMA for bearish alignment. Use the selected timeframe, clamped to at least the chart timeframe; use its last completed bar.
Calculation: Long target levels = signal entry close + (ATR at signal * stop multiplier * each target's risk/reward multiple).
Calculation: Short target levels = signal entry close - (ATR at signal * stop multiplier * each target's risk/reward multiple).
Long: Bull score >= medium threshold AND bull score - bear score >= minimum score gap AND (higher-timeframe trend filter disabled OR bullish higher-timeframe trend condition) AND (volatility filter disabled OR volatility condition) AND no prior long signal or bars since prior long signal >= minimum bar gap AND current bar is confirmed.
Short: Bear score >= medium threshold AND bear score - bull score >= minimum score gap AND (higher-timeframe trend filter disabled OR bearish higher-timeframe trend condition) AND (volatility filter disabled OR volatility condition) AND no prior short signal or bars since prior short signal >= minimum bar gap AND current bar is confirmed.
Exit: long, short condition OR high >= any long target level.
Exit: short, long condition OR low <= any short target level.
