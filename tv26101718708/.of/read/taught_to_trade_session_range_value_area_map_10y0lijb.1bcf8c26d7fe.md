Calculation: Prior value area (VAH, VAL) = from the previous session's bars, split the session's low-to-high range into equal-width price bins; spread each bar's volume equally across all bins its high-low range touches; start at the bin with the most volume (POC), then repeatedly add the adjacent bin (above or below) with more volume (above if tied) until the enclosed volume reaches a set percentage of the session's total volume; VAH = upper edge of the top included bin, VAL = lower edge of the bottom included bin
Calculation: Opening range high/low = highest high / lowest low of the current session's bars whose open time falls within the first N minutes of the session (updated bar by bar, at the chart timeframe)
Long: (close crosses above prior VAH, i.e. previous close <= VAH and current close > VAH) OR (close crosses above opening range high, i.e. previous close <= opening range high and current close > opening range high); only on bars inside the current session with the level defined
Short: (close crosses below prior VAL, i.e. previous close >= VAL and current close < VAL) OR (close crosses below opening range low, i.e. previous close >= opening range low and current close < opening range low); only on bars inside the current session with the level defined
