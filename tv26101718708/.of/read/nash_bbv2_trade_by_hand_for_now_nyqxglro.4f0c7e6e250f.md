Calculation: Session opens = opens of lower-timeframe bars at the three ordered daily anchor times in the configured timezone; retain each until replaced, and clear the second and third opens when the first is replaced.
Calculation: Higher-timeframe series = values from the last completed higher-timeframe bar on historical chart bars and from the still-forming higher-timeframe bar in real time.
Calculation: Fair value gap = on the first chart bar where the higher-timeframe bar index changes, compare the higher-timeframe series' current high and low with those two higher-timeframe bars earlier. A bullish gap has upper edge equal to the current low and lower edge equal to the earlier high; a bearish gap has upper edge equal to the earlier low and lower edge equal to the current high. Record its direction and creation chart bar. A gap is mitigated once any chart bar from its creation onward has high >= its lower edge AND low <= its upper edge.
Calculation: Structure levels = the most recent confirmed chart-timeframe pivot high and pivot low, using the same number of bars on each side. On confirmation, mark a new pivot high used if the confirmation bar close > pivot high, and a new pivot low used if the confirmation bar close < pivot low. Otherwise mark it unused. Mark an unused high used on the first bar whose close > the high in close-break mode or high > the high in wick-break mode; mark an unused low used on the first bar whose close < the low in close-break mode or low < the low in wick-break mode, regardless of whether other signal filters pass.
Calculation: Open-level upward break = for any available session open, previous chart close < that current open level AND current close > that level in close-break mode, OR previous chart close <= that current open level AND current high > that level in wick-break mode.
Calculation: Open-level downward break = for any available session open, previous chart close > that current open level AND current close < that level in close-break mode, OR previous chart close >= that current open level AND current low < that level in wick-break mode.
Long: Close > higher-timeframe EMA.
Short: Close <= higher-timeframe EMA.
Long: On the third session-open event, second session open > first session open AND third session open > second session open.
Short: On the third session-open event, second session open <= first session open AND third session open <= second session open.
Long: Open-level upward break AND, if the EMA filter is enabled, close > higher-timeframe EMA.
Short: Open-level downward break AND, if the EMA filter is enabled, close < higher-timeframe EMA.
Long: On a higher-timeframe bar-index change, the higher-timeframe low > the higher-timeframe high two bars earlier.
Short: On a higher-timeframe bar-index change, the higher-timeframe high < the higher-timeframe low two bars earlier.
Long: Unused structure high exists AND the configured close-break or wick-break comparison first exceeds it AND a gap created on an earlier chart bar has age <= the maximum chart-bar age AND upper edge <= structure high AND structure high minus upper edge <= maximum distance AND, if direction matching is enabled, the gap is bullish AND, if the open-gap filter is enabled, the gap is unmitigated AND, if the EMA filter is enabled, close > higher-timeframe EMA AND, if the open-level filter is enabled, an open-level upward break occurs.
Short: Unused structure low exists AND the configured close-break or wick-break comparison first falls below it AND a gap created on an earlier chart bar has age <= the maximum chart-bar age AND lower edge >= structure low AND lower edge minus structure low <= maximum distance AND, if direction matching is enabled, the gap is bearish AND, if the open-gap filter is enabled, the gap is unmitigated AND, if the EMA filter is enabled, close < higher-timeframe EMA AND, if the open-level filter is enabled, an open-level downward break occurs.
