Calculation: Watched high and low = either the highest high and lowest low of a lookback ending on the previous bar, or the latest confirmed pivot high and pivot low, using separate left and right confirmation lookbacks. A newly confirmed pivot replaces the previous pivot and becomes unconsumed.
Calculation: Break tolerance = either a fixed price distance or ATR multiplied by a parameter.
Calculation: Active break = a marked break whose level and tolerance are frozen at the break bar. It becomes inactive before evaluating new breaks when its age reaches the acceptance horizon, when an upward break closes below its frozen level minus its frozen tolerance, when a downward break closes above its frozen level plus its frozen tolerance, or at a session boundary if session restriction is enabled.
Long: ATR > 0 AND the bar is within the configured session if session restriction is enabled AND close > watched high + break tolerance AND previous close <= current watched high + current break tolerance AND bars since the last marked upward break >= directional cooldown AND active upward break count = 0 AND, if using pivots, the watched high is unconsumed; marking consumes that pivot.
Short: ATR > 0 AND the bar is within the configured session if session restriction is enabled AND close < watched low - break tolerance AND previous close >= current watched low - current break tolerance AND bars since the last marked downward break >= directional cooldown AND active downward break count = 0 AND, if using pivots, the watched low is unconsumed; marking consumes that pivot.
Long: ATR > 0 AND the bar is within the configured session if session restriction is enabled AND low < watched low - break tolerance AND close >= watched low AND previous low >= current watched low - current break tolerance AND no downward break is marked on the same bar.
Short: ATR > 0 AND the bar is within the configured session if session restriction is enabled AND high > watched high + break tolerance AND close <= watched high AND previous high <= current watched high + current break tolerance AND no upward break is marked on the same bar.
