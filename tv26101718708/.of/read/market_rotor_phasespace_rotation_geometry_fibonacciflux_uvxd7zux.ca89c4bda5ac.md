Calculation: Raw axes = Choose either (log(close) minus its EMA, fast EMA of log return minus slow EMA of log return), (log(close) minus its EMA, lower-timeframe signed-volume imbalance), (log(close) minus its EMA, close-location value), or (log return, change in realized volatility). Log return is the change in log(close), with its first value zero. Realized volatility is the square root of the rolling mean of squared log returns. Close-location value is 2 * (close - low) / (high - low) - 1, or zero when high equals low. Lower-timeframe signed-volume imbalance is the sum of each completed lower-timeframe bar's volume signed by the change in its close from the preceding lower-timeframe close, divided by chart-bar volume; use close-location value when lower-timeframe bars are unavailable or chart-bar volume is zero.
Calculation: Phase-space position = Lag the second raw axis by a configurable number of chart bars. Separately standardize each raw axis using its rolling mean and population standard deviation, with a positive denominator floor. Optionally freeze those statistics at a configurable bar after warm-up. Optionally whiten the standardized pair using the inverse square root of its rolling population covariance matrix, with positive determinant and denominator floors; when anchored, freeze that matrix at the same anchor bar. Clip each resulting coordinate symmetrically to a configurable limit. Call the coordinates x and y; radius is sqrt(x² + y²).
Calculation: Turning angle = atan2(x_previous * y - y_previous * x, x_previous * x + y_previous * y), or zero if either radius is below the dead-zone threshold or fewer than two chart bars have elapsed.
Calculation: Rotation consistency = Rolling sum of turning angle divided by the rolling sum of its absolute value, provided the latter exceeds the total-turning threshold; otherwise undefined.
Calculation: Spiral index = Rolling sum, over the same window as rotation consistency, of the change in log(radius + positive offset), divided by the rolling sum of absolute turning angle; set the change to zero wherever turning angle is suppressed by the dead zone or initial-bar rule. It is undefined when the total-turning threshold is not exceeded.
Calculation: Phase-slip hazard = Clip to a nonnegative upper limit the sum of: absolute deviation of turning angle from its EMA divided by the greater of its rolling population standard deviation and a positive floor; a positive coefficient times the decrease, floored at zero, in absolute rotation consistency from the preceding bar; and a positive bonus when consecutive rotation consistencies have opposite signs and the preceding absolute consistency exceeds a threshold. Treat undefined consistency as zero in this calculation.
Calculation: Return reversal = Current log(close) minus log(close) a configurable number of chart bars earlier; use zero when that earlier close is unavailable.
Calculation: Readiness = Bar index is at least a configurable multiple of the longest of the normalization, equilibrium EMA, consistency, winding and loop-area windows; when anchored normalization is selected, bar index is also at least the anchor bar.
Calculation: Cooldown = Number of chart bars since the most recent long or short signal of any type; initialize as sufficiently large to allow the first signal and update after evaluating all signals on each bar.
Long: Readiness AND cooldown >= cooldown threshold AND x < -reversal threshold AND return reversal > 0 AND previous return reversal <= 0 AND absolute rotation consistency > consistency threshold AND spiral index < spiral threshold AND phase-slip hazard < reversal hazard threshold.
Short: Readiness AND cooldown >= cooldown threshold AND x > reversal threshold AND return reversal < 0 AND previous return reversal >= 0 AND absolute rotation consistency > consistency threshold AND spiral index < spiral threshold AND phase-slip hazard < reversal hazard threshold.
Long: Readiness AND cooldown >= cooldown threshold AND previous x <= breakout threshold AND x > breakout threshold AND return reversal > 0 AND radius > breakout radius threshold AND spiral index > spiral threshold AND phase-slip hazard < breakout hazard threshold.
Short: Readiness AND cooldown >= cooldown threshold AND previous x >= -breakout threshold AND x < -breakout threshold AND return reversal < 0 AND radius > breakout radius threshold AND spiral index > spiral threshold AND phase-slip hazard < breakout hazard threshold.
