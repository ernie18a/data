Calculation: Candle measures = range = max(high - low, minimum positive price increment); upper wick = high - max(open, close); lower wick = min(open, close) - low; bullish close quality = (close - low) / range; bearish close quality = 1 - bullish close quality. Safe ATR = max(ATR, minimum positive price increment), using true range when ATR is unavailable. Relative volume = volume / SMA(volume), or 1 when volume is unavailable or its SMA is not positive.
Calculation: High-good score(x, weak, strong) = clamp(100 * (x - weak) / (strong - weak), 0, 100), or 0 if strong equals weak. Range score = high-good score(range / safe ATR, lower range threshold, ideal range threshold) when range / safe ATR <= ideal range threshold; otherwise clamp(100 * (maximum range threshold - range / safe ATR) / (maximum range threshold - ideal range threshold), 0, 100), or 0 if the two thresholds are equal. Volume score = high-good score(relative volume, lower volume threshold, higher volume threshold) when volume support is enabled, otherwise a neutral volume score.
Calculation: Bullish candidate = lower wick / range >= wick threshold AND bullish close quality >= close threshold AND lower wick > upper wick. Bearish candidate = upper wick / range >= wick threshold AND bearish close quality >= close threshold AND upper wick > lower wick. Each side's base score = (0.36 * high-good score(its wick / range, wick threshold, stronger wick threshold) + 0.34 * high-good score(its close quality, close threshold, stronger close threshold) + 0.30 * range score) * (1 - volume weight) + volume score * volume weight. Sensitivity adjusts the wick, close, and quality thresholds before use, with each adjusted threshold clamped to its permitted bounds.
Calculation: Active context = the most recent qualified rejection event whose bar is at least the event cooldown after the previous such event; a new event replaces the previous context. Store its side, bar, close, safe ATR, confirmation rail, failure edge and target guide. For bullish contexts, rail = event high + confirmation buffer * event safe ATR, failure edge = event low - failure buffer * event safe ATR, and target = event close + target multiple * max(abs(event close - failure edge), minimum risk fraction * event safe ATR). For bearish contexts, rail = event low - confirmation buffer * event safe ATR, failure edge = event high + failure buffer * event safe ATR, and target = event close - target multiple * max(abs(event close - failure edge), minimum risk fraction * event safe ATR). Process a new event before the existing context's transitions on each bar. Initially the context is unconfirmed, unfailed, untargeted and unexpired. In order, mark failure if unfailed, untargeted and unexpired and the failure comparison is true; otherwise mark target reached and confirmed if untargeted and unexpired and the target comparison is true; otherwise mark confirmed if unconfirmed and unexpired and the confirmation comparison is true. Then mark expired if unfailed, untargeted and unexpired and its age exceeds the maximum context age. Clear the context when the number of bars since failure, target or expiration exceeds the resolved display duration. Failure and target comparisons use close and have priority over confirmation.
Long: Bullish candidate AND bullish base score >= bearish base score AND bullish base score >= quality threshold AND bars since the previous qualified rejection event >= event cooldown, or no previous qualified rejection event exists.
Short: Bearish candidate AND (bullish candidate is false OR bullish base score < bearish base score) AND bearish base score >= quality threshold AND bars since the previous qualified rejection event >= event cooldown, or no previous qualified rejection event exists.
Long: Active context side is bullish AND context is unconfirmed and unexpired AND close > confirmation rail AND no higher-priority failure or target transition occurs on the bar.
Short: Active context side is bearish AND context is unconfirmed and unexpired AND close < confirmation rail AND no higher-priority failure or target transition occurs on the bar.
Exit: long, active context side is bullish AND context is unfailed, untargeted and unexpired AND close < failure edge.
Exit: short, active context side is bearish AND context is unfailed, untargeted and unexpired AND close > failure edge.
Exit: long, active context side is bullish AND context is untargeted and unexpired AND close >= target guide AND no higher-priority failure transition occurs on the bar.
Exit: short, active context side is bearish AND context is untargeted and unexpired AND close <= target guide AND no higher-priority failure transition occurs on the bar.
