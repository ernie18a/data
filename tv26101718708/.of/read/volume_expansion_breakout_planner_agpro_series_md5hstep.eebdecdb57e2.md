Calculation: Prior upper and lower levels = highest high and lowest low over the same lookback, excluding the current bar; range height = upper level minus lower level.
Calculation: Relative volume = current volume divided by its SMA, including the current bar; use 1 when the SMA is not positive. Smoothed relative volume = SMA of relative volume over a separate lookback.
Calculation: Breakout = for the bullish side, close > prior upper level + ATR × breakout buffer AND previous close <= that same current-bar threshold; for the bearish side, close < prior lower level - ATR × breakout buffer AND previous close >= that same current-bar threshold. Require a positive prior range height.
Calculation: Breakout score = round the sum of these components, clamped to [0, 100]: volume = clamp((relative volume - 0.85) / max(0.10, full-volume ratio - 0.85) × 25, 0, 25); body = clamp(abs(close - open) / (high - low) × 18, 0, 18); close location = clamp((close - low) / (high - low) × 17, 0, 17) for bullish or clamp((high - close) / (high - low) × 17, 0, 17) for bearish; distance = clamp(directional distance from the broken level / ATR / max(0.10, breakout buffer × 4) × 15, 0, 15); trend = 15 if the shorter EMA is above the longer EMA AND close is above the shorter EMA for bullish, or both comparisons are reversed for bearish; otherwise 8 if the shorter EMA is at least the longer EMA OR close is above the shorter EMA for bullish, or the comparisons are reversed for bearish; otherwise 2; range = 10 when range height / ATR is between the minimum and maximum range ratios, otherwise clamp(range height / ATR / minimum range ratio × 10, 0, 10) below the minimum or clamp(maximum range ratio / (range height / ATR) × 10, 0, 10) above the maximum. Use a positive price-increment floor for candle range and ATR, and true range when ATR is unavailable.
Calculation: Active path = a breakout whose score is at least the weak-path threshold, unless the preceding active path has the same direction and its age is at most max(minimum acceptance age + 2, round(path monitoring length × 0.65)). A new path replaces the preceding path, freezes its broken level and ATR, starts at age 0, and resets its accepted and failed flags. Otherwise age increases by one each bar; paths remain active until replaced.
Calculation: Favorable side of the band = close > frozen level + frozen ATR × band width for a bullish path, or close < frozen level - frozen ATR × band width for a bearish path. Returned inside = close < frozen level for bullish, or close > frozen level for bearish. Invalidation = close < frozen level - frozen ATR × invalidation distance for bullish, or close > frozen level + frozen ATR × invalidation distance for bearish.
Calculation: Acceptance event = active path is neither accepted nor failed AND age >= minimum acceptance age AND close is on the favorable side of the band AND smoothed relative volume >= sustained-volume threshold. Set accepted on this event.
Calculation: Failure event = active path is not failed AND age > 0 AND (invalidation OR (returned inside AND smoothed relative volume <= weak-volume threshold) OR (age >= minimum acceptance age AND close is not on the favorable side of the band AND smoothed relative volume < sustained-volume threshold AND relative volume <= weak-volume threshold)). Set failed on this event unless acceptance occurs on the same bar; evaluate both events before updating the flags.
Calculation: Expansion event = active path is not failed AND age > 0 AND age <= path monitoring length AND relative volume >= expansion threshold AND close is on the favorable side of the band AND (close > open AND close >= previous close for bullish, or close < open AND close <= previous close for bearish).
Long: Bullish breakout AND breakout score >= high-quality threshold.
Short: Bearish breakout AND breakout score >= high-quality threshold.
Long: Active bullish path AND age <= path monitoring length.
Short: Active bearish path AND age <= path monitoring length.
Long: Active bullish path AND (expansion event OR acceptance event).
Short: Active bearish path AND (expansion event OR acceptance event).
Long: Prior range height > 0 AND close < prior upper level AND (prior upper level - close) / ATR <= watch distance AND relative volume >= sustained-volume threshold AND close > open AND close > shorter EMA AND bars since the previous watch marking >= watch cooldown.
Short: Prior range height > 0 AND close > prior lower level AND (close - prior lower level) / ATR <= watch distance AND relative volume >= sustained-volume threshold AND close < open AND close < shorter EMA AND bars since the previous watch marking >= watch cooldown AND the bullish watch condition is false.
Exit: long, active bullish path AND failure event.
Exit: short, active bearish path AND failure event.
