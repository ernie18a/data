Calculation: Confirmed swing high or low = a pivot high or low confirmed after the configured number of right-side bars, using independently configured left-side bars; retain its price and pivot bar. Use separate pivot parameters for the chart and higher timeframes.
Calculation: Higher-timeframe structure direction = on each higher-timeframe bar, record an upward break when close > the latest confirmed swing high AND the previous close <= that same swing high; record a downward break when close < the latest confirmed swing low AND the previous close >= that same swing low. Direction is that of the most recent break, or bearish if both breaks occur on the same bar; it is neutral before any break. Use the direction from the last completed higher-timeframe bar.
Calculation: Higher-timeframe bias = the last completed higher-timeframe structure direction. If EMA alignment is enabled, bullish additionally requires the last completed higher-timeframe close > its EMA AND that EMA > the preceding higher-timeframe bar's EMA; bearish additionally requires the corresponding close < EMA AND EMA < the preceding EMA. Otherwise bias is neutral.
Calculation: Unique chart break = a chart close crossing above the current latest confirmed swing high, or below the current latest confirmed swing low, using the current swing price for both the current and previous close comparisons, provided that swing's pivot bar differs from the pivot bar of the most recent unique break in the same direction. Record every unique break, even when its bias or origin conditions fail.
Calculation: Active structure direction = initially neutral. On each chart bar, first reset it to neutral if higher-timeframe bias differs from it OR, for a bullish structure, the selected close or low < its stored origin OR, for a bearish structure, the selected close or high > its stored origin. Then, if it is neutral OR replacement is enabled, a valid bullish or bearish chart break sets it to that direction and stores the latest opposite chart swing price as origin. A valid bullish break is a unique upward chart break with bullish higher-timeframe bias AND the latest confirmed chart swing low's pivot bar later than the broken high's pivot bar and earlier than the current bar AND the swing low < close. A valid bearish break is a unique downward chart break with bearish higher-timeframe bias AND the latest confirmed chart swing high's pivot bar later than the broken low's pivot bar and earlier than the current bar AND the swing high > close.

Short: Higher-timeframe bias = bearish

Short: Unique downward chart break AND higher-timeframe bias = bearish AND latest confirmed chart swing high's pivot bar > broken low's pivot bar AND latest confirmed chart swing high's pivot bar < current bar AND latest confirmed chart swing high > close
