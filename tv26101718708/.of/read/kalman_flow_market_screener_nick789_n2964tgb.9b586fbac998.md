Calculation: Scan bars = chart-timeframe bars or bars aggregated to a higher timeframe; use the last completed scan bar when close confirmation is enabled, otherwise use the still-forming scan bar. If the selected scan timeframe is lower than the chart timeframe, use chart-timeframe bars.
Calculation: Structure impulse = 1 when close crosses above the latest confirmed pivot high, otherwise -1 when close crosses below the latest confirmed pivot low, otherwise 0. Pivots use equal left and right lookbacks; compare both the current and previous close with the current latest confirmed pivot. Structure activity is the RMA of the absolute impulse; structure bias is the RMA of the impulse over the same lookback.
Calculation: Fast and slow Kalman estimates = independently initialize estimate to the source price and error to 1; on each bar set gain = (error + process noise) / (error + process noise + measurement noise), estimate = estimate + gain * (source price - estimate), and error = (1 - gain) * (error + process noise). The default source is OHLC4; fast process noise is greater than slow process noise, with equal measurement noise.
Calculation: Flow basis = initialize to the fast Kalman estimate; subsequently move the prior basis toward the fast estimate by an adaptive coefficient interpolated between a slower and a faster EMA coefficient using structure activity. Add structure bias multiplied by ATR, a push coefficient, and an agreement coefficient; use the full agreement coefficient when structure bias and the fast-minus-slow Kalman difference have the same sign, otherwise use a smaller disagreement coefficient. Then move the result toward the midpoint of the latest confirmed pivot high and low by structure activity times an anchor coefficient, if both pivots exist.
Calculation: Flow boundaries = flow basis plus or minus ATR multiplied by a boundary multiplier. Initialize trend direction bullish if close >= flow basis, otherwise bearish; thereafter set it bullish when close > upper boundary and, if slope confirmation is enabled, flow basis > prior flow basis; set it bearish when close < lower boundary and, if slope confirmation is enabled, flow basis < prior flow basis; otherwise retain the prior direction.
Calculation: Higher-timeframe direction = the same trend direction calculated on a timeframe higher than or equal to the scan timeframe, using its last completed bar when close confirmation is enabled and its still-forming bar otherwise. If the selected filter timeframe is lower than the scan timeframe, use the scan timeframe.
Calculation: Bullish flip risk = trend direction is bearish AND close >= upper flow boundary - ATR multiplied by a warning distance. Bearish flip risk = trend direction is bullish AND close <= lower flow boundary + ATR multiplied by a warning distance.
Calculation: Fresh direction = the direction of the most recent confirmed trend flip while the number of scan bars since that flip <= the fresh-window length. Pending direction = the trend direction on the still-forming scan bar when close confirmation is enabled and that direction differs from the last completed scan bar's direction.
Calculation: Displayed direction = pending direction if present, otherwise fresh direction if present, otherwise trend direction. When higher-timeframe filtering is enabled, a row is displayed in all-states mode if trend direction, pending direction, or active flip-risk direction equals higher-timeframe direction; in fresh-only mode it is displayed if fresh direction or pending direction equals higher-timeframe direction, or an enabled flip-risk direction equals higher-timeframe direction. When the filter is disabled, the corresponding direction match always passes. Fresh-only mode also requires a fresh direction, pending direction, or enabled flip risk.
Long: Displayed direction = bullish AND the row is displayed.
Short: Displayed direction = bearish AND the row is displayed.
Long: Bullish flip risk is active AND flip-risk warnings are enabled AND no bullish flip occurs on the same scan bar AND the row is displayed.
Short: Bearish flip risk is active AND flip-risk warnings are enabled AND no bearish flip occurs on the same scan bar AND the row is displayed.
