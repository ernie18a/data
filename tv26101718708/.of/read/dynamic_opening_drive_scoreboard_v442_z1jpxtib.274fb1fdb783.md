Calculation: Relative volume = volume / SMA(volume), including the current bar.
Calculation: Armed setup = on a new calendar day clear the setup and entry state; otherwise, when no setup or entry is active and close > EMA AND close > session VWAP AND relative volume >= setup threshold, store the close and arm a trigger at that close plus a price buffer. After evaluating entry on each subsequent bar, clear an unfilled setup when its age > maximum setup age. If the optional structure-failure reset is enabled, clear setup and entry state when close <= EMA AND close <= session VWAP. Clear entry state when its age > maximum entry age. Apply these resets before evaluating exit decisions.
Calculation: Entry state = when an armed setup triggers, record the trigger as entry price and the current bar as entry bar; retain this state until the armed-setup calculation clears it.
Calculation: Current R = (close - entry price) / active risk, where active risk is current ATR multiplied by the chart-timeframe-specific ATR multiplier; if ATR risk is unavailable, use entry price minus the current calendar day's low plus the structure-stop buffer. Current R is unavailable if active risk <= 0.
Calculation: Stalling or weakness = close <= EMA AND close <= session VWAP OR, after the entry bar, close < open AND (close - low) / (high - low) <= weak-close threshold AND exactly one of close > EMA and close > session VWAP OR, after the entry bar, close < open AND (high - close) / (high - low) >= giveback threshold AND high - low >= very-wide range threshold OR, after the entry bar, close < open AND (close <= EMA OR close <= session VWAP) AND (current R >= base-hit threshold OR current R < lower R threshold) OR close < open AND (close - low) / (high - low) <= weak-close threshold AND (close <= EMA OR close <= session VWAP) OR, after the entry bar, relative volume < volume threshold AND (close <= EMA OR close <= session VWAP). Range ratios are unavailable when high = low.
Long: Setup is armed AND current bar is after the setup bar AND high >= trigger AND close > EMA AND close > session VWAP AND relative volume >= entry threshold AND (increasing-volume filter disabled OR volume > previous bar volume).
Exit: long, entry state is active AND stalling or weakness.
Exit: long, entry state is active AND stalling or weakness is false AND current bar is the entry bar AND current R >= base-hit threshold AND close > EMA AND close > session VWAP.
Exit: long, entry state is active AND stalling or weakness is false AND current bar is after the entry bar AND ((close - EMA) / EMA >= EMA exhaustion threshold AND (close - session VWAP) / session VWAP >= VWAP exhaustion threshold OR high - low >= very-wide range threshold AND (high - low) / close >= very-wide percentage-range threshold AND current R >= base-hit threshold AND close > EMA AND close > session VWAP OR current R >= base-hit threshold AND (close - low) / (high - low) >= strong-close threshold AND ((close - EMA) / EMA >= EMA extension threshold OR (close - session VWAP) / session VWAP >= VWAP extension threshold) AND close > EMA AND close > session VWAP).
