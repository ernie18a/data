Calculation: All calculations use chart bars. Each score uses the first matching case; bracketed numbers are fixed score outputs, and named thresholds and multipliers are parameters.
Calculation: Direction score = [90] close > short EMA > long EMA AND short EMA > its previous value AND close > high - upper-edge fraction × (high - low); [75] close > short EMA > long EMA; [55] close > short EMA AND short EMA < long EMA; [40] close < short EMA AND short EMA > long EMA; [15] close < short EMA < long EMA AND short EMA < its previous value AND close < low + lower-edge fraction × (high - low); [25] close < short EMA < long EMA; otherwise [50].
Calculation: Momentum score = [90] RSI >= upper RSI threshold AND RSI > previous RSI AND close > previous high; [75] RSI >= middle-high RSI threshold AND RSI < upper RSI threshold AND RSI > previous RSI; [55] RSI >= middle-low RSI threshold AND RSI <= middle-high RSI threshold AND absolute close-to-close percentage change < small-change threshold; [35] RSI >= low RSI threshold AND RSI < middle-low RSI threshold AND RSI < previous RSI; [20] RSI >= extreme-low RSI threshold AND RSI < low RSI threshold AND RSI < previous RSI AND close < previous low; [5] RSI < extreme-low RSI threshold OR RSI > extreme-high RSI threshold; otherwise [50].
Calculation: Absolute return = absolute close-to-close change divided by previous close, expressed as a percentage. Volume ratio = volume divided by its SMA, including the current bar.
Calculation: Velocity score = let average velocity be the SMA of absolute return over a velocity lookback, excluding the current bar; [90] absolute return > average velocity × highest velocity multiplier AND volume ratio > highest velocity-volume threshold; [75] absolute return > average velocity × high velocity multiplier AND volume ratio > high velocity-volume threshold; [55] absolute return >= average velocity × moderate-low velocity multiplier AND absolute return <= average velocity × moderate-high velocity multiplier; [35] absolute return < average velocity × moderate-low velocity multiplier AND absolute return > average velocity × low velocity multiplier; [15] absolute return < average velocity × low velocity multiplier AND volume ratio < low velocity-volume threshold; [5] absolute return < minimum absolute-return threshold; otherwise [50].
Calculation: Behavior score = let body be absolute close minus open, shadows be high minus max(open, close) plus min(open, close) minus low, and body ratio be body divided by high minus low; [90] body ratio > highest body threshold AND shadows < body × smallest shadow multiplier; [75] body ratio > high body threshold AND shadows < body × larger shadow multiplier; [55] body ratio >= middle body threshold AND body ratio <= high body threshold; [35] body ratio >= low body threshold AND body ratio < middle body threshold; [15] body ratio >= lowest body threshold AND body ratio < low body threshold; [5] body ratio < lowest body threshold AND shadows > body × large shadow multiplier; otherwise [50].
Calculation: Battle score = [90] the current and previous two candles alternate between close > open and close < open; [75] the current and previous candle have opposite non-doji directions; [55] the last three candles do not alternate AND are not all bullish; [30] the last three candles are bullish AND the last five candles are not all bullish; [5] the last five candles are bullish; otherwise [50].
Calculation: Previous key high and low = highest high and lowest low over the key-level lookback ending at the previous bar.
Calculation: Hunting score = [90] (high > previous key high AND close <= previous key high OR low < previous key low AND close >= previous key low) AND volume ratio > hunt-volume threshold; [55] high > previous key high × near-high multiplier AND high < previous key high OR low < previous key low × near-low multiplier AND low > previous key low; [10] (close > previous key high OR close < previous key low) AND volume ratio > breakout-volume threshold; otherwise [40].
Calculation: Bollinger width = (upper Bollinger Band - lower Bollinger Band) / Bollinger basis. Rolling percentile = sort the current and preceding values over its lookback in ascending order and select the zero-based index floor(percentile × (lookback - 1) / 100).
Calculation: Squeeze score = let width percentile be the rolling upper percentile of Bollinger width and ATR ratio be ATR divided by its SMA; [90] Bollinger width < width percentile × smallest width multiplier AND ATR ratio < lowest ATR-ratio threshold; [75] Bollinger width < width percentile × small width multiplier AND ATR ratio < low ATR-ratio threshold; [55] Bollinger width < width percentile × middle width multiplier AND ATR ratio < middle ATR-ratio threshold; [40] Bollinger width >= width percentile × middle width multiplier AND Bollinger width <= width percentile × high width multiplier; [25] Bollinger width > width percentile × high width multiplier AND Bollinger width < width percentile × highest width multiplier; [10] Bollinger width >= width percentile × highest width multiplier; otherwise [50].
Calculation: Destruction score = let body ratio be the current absolute candle body divided by the SMA of absolute candle bodies over a body lookback ending at the previous bar; [90] (close > previous key high OR close < previous key low) AND body ratio > high destruction-body threshold AND volume ratio > destruction-volume threshold; [75] (close > previous key high OR close < previous key low) AND body ratio > low destruction-body threshold; [55] close > previous key high × near-high multiplier OR close < previous key low × near-low multiplier; [10] (high > previous key high OR low < previous key low) AND close <= previous key high AND close >= previous key low AND (close - open) × (previous close - previous open) < 0; [25] (high > previous key high OR low < previous key low) AND close <= previous key high AND close >= previous key low; otherwise [40].
Calculation: Range ratio = (high - low) divided by its SMA, including the current bar.
Calculation: Absorption score = [90] range ratio > high absorption-range threshold AND absolute return < lowest absorption-return threshold AND volume ratio > high absorption-volume threshold; [75] range ratio > middle absorption-range threshold AND absolute return < low absorption-return threshold AND volume ratio > middle absorption-volume threshold; [55] range ratio > low absorption-range threshold AND absolute return < middle absorption-return threshold AND volume ratio > low absorption-volume threshold; [25] absolute return > high absorption-return threshold AND volume ratio > breakout absorption-volume threshold; otherwise [40].
Calculation: Expansion score = let range percentile be the rolling upper percentile of high minus low; [90] range ratio > range percentile × highest expansion multiplier AND volume ratio > high expansion-volume threshold; [75] range ratio > range percentile × high expansion multiplier AND volume ratio > middle expansion-volume threshold; [55] range ratio > range percentile × middle expansion multiplier AND volume ratio > low expansion-volume threshold; [40] range ratio >= range percentile × low expansion multiplier AND range ratio <= range percentile × middle expansion multiplier; [20] range ratio < range percentile × lowest expansion multiplier; otherwise [50].
Calculation: Impact score = let average return be the SMA of absolute return over an impact lookback ending at the previous bar; [90] absolute return > average return × highest impact multiplier AND volume ratio > highest impact-volume threshold AND (close > previous key high OR close < previous key low); [75] absolute return > average return × high impact multiplier AND volume ratio > high impact-volume threshold; [55] absolute return > average return × middle impact multiplier AND volume ratio > middle impact-volume threshold; [20] absolute return < average return × low impact multiplier AND volume ratio < low impact-volume threshold; otherwise [40].
Calculation: Decay score = [90] absolute return has decreased on each of the last two bar-to-bar comparisons AND volume ratio has decreased on each of those comparisons; [75] absolute return has decreased on each of the last two comparisons; [55] current absolute return < previous absolute return AND previous absolute return > absolute return two bars ago; [40] absolute return has neither decreased on both of the last two comparisons nor increased on both; [20] absolute return has increased on both comparisons AND volume ratio has not increased on both; [5] absolute return and volume ratio have each increased on both comparisons; otherwise [50].
Calculation: Directional combination score = mean of direction, momentum, velocity, and behavior scores. Overall score = mean of all twelve factor scores.
Long: Directional combination score >= bullish combination threshold
Short: Directional combination score < bearish combination threshold
Long: Overall score >= bullish overall threshold
Short: Overall score < bearish overall threshold
