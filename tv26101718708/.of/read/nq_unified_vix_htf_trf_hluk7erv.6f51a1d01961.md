Calculation: Twin Range Filter = For each of a shorter and a longer lookback, smooth the absolute change in close with an EMA of that lookback, then an EMA of length twice that lookback minus one, and multiply by its respective multiplier. Average the two results to obtain the range. Set the filtered value to max(previous filtered value, close minus range) when close exceeds the previous filtered value; otherwise set it to min(previous filtered value, close plus range). Replace an unavailable previous filtered value with zero. Set the upper band to filtered value plus range if that is below the previous upper band or the previous close is above the previous upper band; otherwise retain the previous upper band. Set the lower band to filtered value minus range if that is above the previous lower band or the previous close is below the previous lower band; otherwise retain the previous lower band. Replace unavailable previous bands with zero for these band updates. If the previous filter line equals the previous upper band, use the upper band when close is at or below it and otherwise use the lower band. If the previous filter line equals the previous lower band, use the lower band when close is at or above it and otherwise use the upper band. Otherwise use the upper band. Replace an unavailable previous filter line with zero for these comparisons.
Calculation: Extension levels = From the last completed higher-timeframe trading-day bar, calculate its low plus its range multiplied by an extension ratio for the upper extension, and its low plus its range multiplied by one minus that ratio for the lower extension. After the configured opening range ends, calculate the same extensions from its high and low; use the greater upper extension and the lesser lower extension. Before then, use the prior-day extensions.
Calculation: Trade levels = At entry, set the stop distance to ATR multiplied by a stop multiplier and the target distance to that stop distance multiplied by a reward-to-risk ratio. Set the initial stop below entry and target above entry for a long, and the initial stop above entry and target below entry for a short. Before testing exits on each bar, move the long stop to entry when close reaches or exceeds the upper extension, or the short stop to entry when close reaches or falls below the lower extension; retain that stop until exit.
Long: close > Twin Range Filter.
Short: close <= Twin Range Filter.
Long: last completed higher-timeframe close > its Twin Range Filter.
Short: last completed higher-timeframe close <= its Twin Range Filter.
Exit: long, low <= stop OR high >= target OR a new trading-day bar begins OR local time >= configured session end.
Exit: short, high >= stop OR low <= target OR a new trading-day bar begins OR local time >= configured session end.
