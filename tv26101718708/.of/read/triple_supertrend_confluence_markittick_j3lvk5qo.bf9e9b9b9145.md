Calculation: Source = HL2, optionally smoothed by SMA, EMA, Wilder's RMA, HMA, two successive WMAs, three successive VWMAs, a slope-adjusted average, or a Kalman filter, all using the same smoothing lookback. Slope-adjusted average = SMA(HL2) + (HL2 - HL2 one lookback ago) / 2. Kalman filter: initialize estimate to HL2 and error covariance to 1; on each bar set predicted covariance = previous covariance + 1 / lookback, gain = predicted covariance / (predicted covariance + 1), estimate = previous estimate + gain * (HL2 - previous estimate), and covariance = (1 - gain) * predicted covariance.
Calculation: Core Supertrend = Supertrend of Source using the core ATR lookback and either a fixed multiplier or an adaptive multiplier. The adaptive multiplier linearly maps the percentile rank of core ATR over its rank lookback to the configured minimum-to-maximum multiplier range; use the fixed multiplier when the rank is unavailable. The fast and slow Supertrends use the same Source with fixed multipliers; the fast instance has a shorter ATR lookback and smaller multiplier than the slow instance.
Calculation: Supertrend direction = down initially when previous ATR is unavailable; otherwise, if the previous Supertrend line equals the previous upper band, direction is up when close > current upper band and down otherwise; if it does not, direction is down when close < current lower band and up otherwise. Basic bands are source plus or minus multiplier times ATR. The lower band is the current basic lower band when it exceeds the previous lower band or previous close is below the previous lower band, and is the previous lower band otherwise. The upper band is the current basic upper band when it is below the previous upper band or previous close is above the previous upper band, and is the previous upper band otherwise. Replace unavailable previous bands with zero. The Supertrend line is the lower band in an uptrend and the upper band in a downtrend.
Calculation: Higher-timeframe direction = Supertrend direction calculated on the last completed higher-timeframe bar using that timeframe's HL2, the core ATR lookback, and the fixed core multiplier.
Calculation: Directional cooldown = on each bar, if the core direction flipped on the previous bar and the number of bars between that flip and the preceding flip is at most the cooldown length, set the cooldown end for the direction before that flip to the previous bar index plus the cooldown length. Initialize the preceding flip index to zero. A direction is in cooldown through its cooldown end, inclusive.
Calculation: Confirmed up flip = core direction changes from down to up on the current closed bar AND, if enabled, ADX is at least its threshold AND, if enabled, at least one of the fast and slow Supertrend directions is up AND, if enabled, higher-timeframe direction is up AND, if enabled, volume is unavailable or nonpositive OR volume is at least its SMA times the volume multiplier AND, if enabled, the up-direction cooldown has ended. Parenthesize each optional filter and its alternatives independently.
Calculation: Confirmed down flip = core direction changes from up to down on the current closed bar AND, if enabled, ADX is at least its threshold AND, if enabled, at least one of the fast and slow Supertrend directions is down AND, if enabled, higher-timeframe direction is down AND, if enabled, volume is unavailable or nonpositive OR volume is at least its SMA times the volume multiplier AND, if enabled, the down-direction cooldown has ended. Parenthesize each optional filter and its alternatives independently.
Calculation: Trade risk distance = core-lookback ATR on the confirmed entry bar times the stop multiplier. Each of three take-profit distances equals the trade risk distance times its independently configured reward-to-risk multiplier. Levels are fixed at the signal bar's close and are active starting on the following bar; replace them on each subsequent confirmed signal when trade levels are enabled. Each level can trigger once per signal.
Long: Core Supertrend direction = up.
Short: Core Supertrend direction = down.
Long: Confirmed up flip = true.
Short: Confirmed down flip = true.
Exit: long, confirmed down flip = true.
Exit: short, confirmed up flip = true.
Exit: long, active long stop has not previously triggered AND low <= entry price - trade risk distance.
Exit: short, active short stop has not previously triggered AND high >= entry price + trade risk distance.
Exit: long, any active long take-profit level has not previously triggered AND high >= entry price + that level's take-profit distance.
Exit: short, any active short take-profit level has not previously triggered AND low <= entry price - that level's take-profit distance.
