Calculation: EMA_f, EMA_m, EMA_s = EMA of close on the chart timeframe, with lengths fast < mid < slow.
Calculation: M = mean over four distinct timeframes, each higher than the chart timeframe, of (K + D) / 2, where K = SMA(Stochastic of RSI(close), smoothK) and D = SMA(K, smoothD) are computed on that timeframe's bars. Each timeframe contributes its last completed bar, so the value is carried unchanged on chart bars until that timeframe's next bar completes. M is on a 0-100 scale.
Calculation: ConfLow and ConfHigh = booleans from a per-bar state machine on M. The steps run in this order on every chart bar. Initially both watch flags are off and both tracks are off. (1) If M <= lowLevel and no watch flag is on, watchLow = on. If M >= highLevel and no watch flag is on, watchHigh = on. lowLevel < 50 < highLevel. (2) trigLow = watchLow AND M >= 50. trigHigh = watchHigh AND M <= 50. If trigLow OR trigHigh, both watch flags are cleared. (3) If trigHigh: minRef = M, minTrack = on, cntMin = 0. If trigLow: maxRef = M, maxTrack = on, cntMax = 0. (4) ConfLow = false. If minTrack: if M < minRef then minRef = M and cntMin = 0, else cntMin += 1. If cntMin >= confirmBars then minTrack = off and ConfLow = true on this bar. ConfHigh = false. If maxTrack: if M > maxRef then maxRef = M and cntMax = 0, else cntMax += 1. If cntMax >= confirmBars then maxTrack = off and ConfHigh = true on this bar.
Calculation: SetupLong = boolean from a per-bar state machine on EMA_f, with state s starting at 0. The steps run in this order on every closed chart bar. (a) If EMA_f crosses above EMA_m OR EMA_f crosses above EMA_s: s = 1, base = EMA_f, peak = EMA_f. (b) If s == 1: if EMA_f > EMA_f[1] then peak = max(peak, EMA_f). If EMA_f < EMA_f[1] AND EMA_f[1] < EMA_f[2] then s = 2. (c) If s == 2: H = peak - base. If H > 0 AND (peak - EMA_f) >= H * pullbackRatio then s = 3. (d) SetupLong = false. If s == 3: H = peak - base. If EMA_f >= peak - H * (1 - earlyRatio) then SetupLong = true on this bar and s = 4. The setup is consumed on that bar whether or not the trend condition passes.
Calculation: SetupShort = mirror of SetupLong. (a) If EMA_f crosses below EMA_m OR EMA_f crosses below EMA_s: s = 1, base = EMA_f, trough = EMA_f. (b) If s == 1: if EMA_f < EMA_f[1] then trough = min(trough, EMA_f). If EMA_f > EMA_f[1] AND EMA_f[1] > EMA_f[2] then s = 2. (c) If s == 2: H = base - trough. If H > 0 AND (EMA_f - trough) >= H * pullbackRatio then s = 3. (d) SetupShort = false. If s == 3: H = base - trough. If EMA_f <= trough + H * (1 - earlyRatio) then SetupShort = true on this bar and s = 4.
Long: SetupLong AND EMA_m > EMA_s AND ConfLow was true on at least one of the last N chart bars (including the current bar).
Short: SetupShort AND EMA_m < EMA_s AND ConfHigh was true on at least one of the last N chart bars (including the current bar).
