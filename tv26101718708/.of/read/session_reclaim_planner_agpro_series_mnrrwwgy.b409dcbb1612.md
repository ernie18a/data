Calculation: Session rails = highest high and lowest low of the latest completed build session; require high > low. Reset the watch and active plan when a new build session begins.
Calculation: Volatility = maximum of ATR, current true range, and a minimum positive price increment; use current true range when ATR is unavailable.
Calculation: Reclaim watch = during the monitor session after the build session, when no plan or watch is active, start a low-rail watch if (session low - low) / volatility >= minimum sweep depth, or a high-rail watch if (high - session high) / volatility >= minimum sweep depth, subject to the selected rail mode. If both qualify, select the greater depth, choosing the low rail on a tie. Track the lowest low or highest high from the watch start on evaluated monitor-session bars. Expire the watch when its age exceeds the reclaim window. A reclaim may occur on the sweep bar.
Calculation: Active plan = on a valid reclaim, fix the reclaimed rail as the level, set acceptance count to one, and fix the risk edge at min(watch lowest low, level - pocket multiplier * volatility) - risk buffer * volatility for a low reclaim, or max(watch highest high, level + pocket multiplier * volatility) + risk buffer * volatility for a high reclaim. On subsequent bars, increment acceptance count up to the required count when close remains on the reclaimed side of the level, otherwise reset it to zero. Keep the plan active until its age exceeds the plan expiry or a new build session starts; failure or target does not immediately end it.
Calculation: Target = choose the opposite session rail, the level plus side * risk distance * target risk multiple, or the hybrid. Side is +1 for a low reclaim and -1 for a high reclaim; risk distance is max(abs(level - risk edge), minimum positive price increment), and range distance is max(session high - session low, minimum positive price increment). The hybrid is min(max(opposite rail, level + half the range distance), risk-multiple target) for a low reclaim, and max(min(opposite rail, level - half the range distance), risk-multiple target) for a high reclaim.
Calculation: Reclaim score = 0.25 * close score + 0.25 * acceptance score + 0.18 * participation score + 0.22 * room score + 0.10 * range-fit score. Normalize(x, a, b) = clamp(100 * (x - a) / max(b - a, a small positive constant), 0, 100). Close score = Normalize(side * (close - level) / volatility, 0, 0.50); acceptance score = clamp(100 * acceptance count / required acceptance count, 0, 100); participation score = Normalize(volume / SMA(volume), 0.70, 1.55), using volume ratio 1 when its SMA is unavailable or nonpositive; room score = Normalize(abs(target - close) / risk distance, 0.35, 1.65); range-fit score = Normalize(session range / volatility, 0.45, 2.20) when that ratio <= 2.20, otherwise clamp(100 * (6.00 - ratio) / (6.00 - 2.20), 0, 100).
Long: Low-rail watch age <= reclaim window AND close >= watched session low + minimum reclaim distance * volatility.
Short: High-rail watch age <= reclaim window AND close <= watched session high - minimum reclaim distance * volatility.
Long: Active low-reclaim plan has not failed or reached its target AND reclaim score >= plan-review threshold AND acceptance count >= required acceptance count AND this plan has not previously met these conditions.
Short: Active high-reclaim plan has not failed or reached its target AND reclaim score >= plan-review threshold AND acceptance count >= required acceptance count AND this plan has not previously met these conditions.
Exit: long, active low-reclaim plan AND close <= risk edge OR active low-reclaim plan has not failed AND high >= target.
Exit: short, active high-reclaim plan AND close >= risk edge OR active high-reclaim plan has not failed AND low <= target.
