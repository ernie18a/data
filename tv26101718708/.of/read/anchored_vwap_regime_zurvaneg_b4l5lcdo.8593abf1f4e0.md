Calculation: Anchor = reset at a configured time of day, exchange session start, or start of a higher-timeframe period; use chart bars accumulated in the current, still-forming anchor period.
Calculation: Weight = bar volume, or 1 for time weighting; automatic weighting uses volume when available and 1 otherwise.
Calculation: Anchored mean = sum(source × weight) / sum(weight) since the anchor reset, where source is a configured OHLC-derived price; anchored deviation = sqrt(max(sum(weight × source²) / sum(weight) − anchored mean², 0)); effective deviation = max(anchored deviation, configured ATR multiple).
Calculation: Mature = number of chart bars since anchor reset, including the current bar, is at least the configured formation duration converted to chart bars and rounded up, with a minimum of one bar, AND anchored mean is available.
Calculation: Gate = reset to 0 at each anchor; count consecutive closes above anchored mean plus a configured effective-deviation multiple and consecutive closes below anchored mean minus the same multiple, resetting each count when its condition fails; once mature, set gate to 1 or −1 when the respective count reaches its acceptance threshold, otherwise retain its previous value. Counts accumulate even before maturity.
Calculation: Spread = (shorter-length EMA(source × weight) / EMA(weight) − longer-length EMA(source × weight) / EMA(weight)) / ATR; the EMAs run continuously across anchors. Use 0 when ATR is not positive or the ratio is unavailable.
Calculation: Side = 1 when mature AND close > anchored mean + the gate's effective-deviation multiple; −1 when mature AND close < anchored mean − that multiple; otherwise 0. Rotation count = number of changes between nonzero sides in a rolling chart-bar window clipped to the current anchor, retaining the last nonzero side across zero-side bars. Persistence = sum of sides in that window divided by the greater of the count of mature bars in the window and half the full window length; use 0 if there are no mature bars.
Calculation: Regime = reset to unknown at each anchor, while the last confirmed trend direction persists across anchors. Before maturity, regime is unknown. Once mature, choose the candidate in this priority order: balance if rotation count >= the balance threshold; uptrend if the current regime is uptrend AND gate != −1 AND spread > −the lower spread threshold; downtrend if the current regime is downtrend AND gate != 1 AND spread < the lower spread threshold; uptrend if gate = 1 AND spread >= the lower spread threshold when the last confirmed trend was uptrend, otherwise >= the higher spread threshold, AND rotation count <= the trend rotation limit; downtrend if gate = −1 AND spread <= minus the lower spread threshold when the last confirmed trend was downtrend, otherwise <= minus the higher spread threshold, AND rotation count <= the trend rotation limit; otherwise transition. The balance threshold exceeds the trend rotation limit. Change the confirmed regime only after the same different candidate persists for the configured number of consecutive bars; update the last confirmed trend when an uptrend or downtrend is confirmed.
Calculation: Score = reset previous score to 0 at each anchor. Let z = (close − anchored mean) / effective deviation when mature and effective deviation > 0, otherwise unavailable; z-out = max(z − the gate deviation multiple, 0) for positive z, min(z + that multiple, 0) for nonpositive z, or 0 when unavailable. Let exhaustion = clamp(1 − (abs(z) − saturation threshold) / configured exhaustion width, 0, 1), treating unavailable z as 0; position component = tanh(z-out / configured scale) × exhaustion. Let regime direction be 1 for confirmed uptrend, −1 for confirmed downtrend, otherwise 0. Raw score = weighted average of tanh(spread / the higher spread threshold), position component, persistence, and regime direction, using their respective configured positive weights. Rotation factor = clamp(1 − (rotation count − trend rotation limit) / (balance threshold − trend rotation limit), 0, 1). Drift = (longer-length exponential volume-weighted price − its value a configured number of bars ago) / (that number of bars × ATR), or 0 if unavailable or ATR is not positive. Drift factor = configured minimum factor + (1 − that minimum) × min(abs(drift) / configured drift scale, 1). Maturity factor = min(bars since anchor reset / required maturity bars, 1). Target = raw score × rotation factor × drift factor × maturity factor; score = previous score + clamp(target − previous score, −configured maximum score change, configured maximum score change).
Long: Score > 0.
Short: Score < 0.
