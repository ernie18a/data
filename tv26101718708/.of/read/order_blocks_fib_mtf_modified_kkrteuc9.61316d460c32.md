Calculation: Break = bullish when close > previous high, bearish when close < previous low, otherwise none; bullish takes precedence.
Calculation: Candidate high = on a bearish break immediately following a bullish break, the highest high over bars since the latest bearish break plus a longer lookback offset; if that equals the previous corrected high, use the same calculation with a shorter offset. Candidate low = on a bullish break immediately following a bearish break, the lowest low over bars since the latest bullish break plus the longer offset; if that equals the previous corrected low, use the shorter offset. Use a one-bar lookback before a corresponding break exists. Corrected high and low equal the current candidate if present, otherwise the candidate from the immediately preceding bar; they are undefined if neither exists. Record the bar of each candidate.
Calculation: Major high and low = initialize each to zero. Update the major high to the corrected high when the major high is zero or the corrected high is higher; update it to a lower corrected high only when the preceding bar had a bearish structure break whose bar is at or after the latest candidate-high bar. Update the major low symmetrically, using a bullish structure break and candidate-low bar. Otherwise retain the previous major value. A bullish structure break occurs when close > current major high AND previous close <= current major high; otherwise a bearish structure break occurs when close < current major low AND previous close >= current major low. Record the latest bar of each structure break, initially zero.
Calculation: Demand source bar = the bar immediately preceding the latest change in corrected low. Supply source bar = the bar immediately preceding the latest change in corrected high. Create a demand block on a bullish structure break if its source bar differs from the source of the last created demand block; create a supply block symmetrically on a bearish structure break. Initialize the last-used source bars to zero. Freeze each block's boundaries at creation and retain them until the next block of the same side.
Calculation: Unrefined demand boundaries = source-bar high as proximal and source-bar low as distal. Unrefined supply boundaries = source-bar low as proximal and source-bar high as distal.
Calculation: Refinement inputs = current ATR and source-bar range; use the minimum and maximum of each OHLC field across the source bar, its preceding bar, and its following bar, also including the second following bar when already available. If the specified bars are unavailable, the corresponding values are undefined. Retain the preceding refined boundaries whenever a branch below does not assign them.
Calculation: Refined demand preliminary boundaries = if source range <= a lower ATR multiple, proximal is source high and distal is minimum low. If source range is above that multiple and <= ATR, proximal is source close when current close >= current open, otherwise source open; distal is minimum low. If source range > ATR AND preceding-bar low < source high AND preceding-bar low > source low, proximal is preceding-bar low and distal is source low. If source range > ATR AND preceding-bar low < source high AND preceding-bar low <= source low, distal is minimum low; proximal is maximum open if the preceding bar is bearish OR its range > ATR, otherwise maximum close if its range < ATR. If source range > ATR AND preceding-bar low >= source high, compare minimum low minus minimum open with minimum low minus minimum close; use minimum open or minimum close respectively as proximal when its corresponding difference is greater and lies between the lower ATR multiple and ATR, inclusive; distal is minimum low.
Calculation: Refined supply preliminary boundaries = if source range <= the lower ATR multiple, proximal is source low and distal is maximum high. If source range is above that multiple and <= ATR, proximal is source close when current close >= current open, otherwise source open; distal is maximum high. If source range > ATR AND following-bar high > source low AND following-bar high > source high, proximal is following-bar high and distal is source high. If source range > ATR AND following-bar high > source low AND following-bar high <= source high, use preceding-bar range relative to ATR: for a nonbearish following bar, proximal is minimum close when that range > ATR and minimum open when it < ATR, with distal maximum high; for a bearish following bar, proximal is minimum open and distal maximum high when that range > ATR, otherwise proximal is maximum high and distal following-bar high when that range < ATR. If source range > ATR AND following-bar high <= source low AND preceding-bar high <= source low, use minimum open as proximal and maximum high as distal when maximum high minus minimum open exceeds maximum high minus minimum close and lies between the lower ATR multiple and ATR, inclusive; otherwise use supply minimum close as proximal and supply maximum high as distal when supply maximum high minus demand minimum open is less than supply maximum high minus demand minimum close and the latter difference lies in that interval.
Calculation: Refined boundaries = in aggressive mode use the preliminary boundaries. In defensive mode retain the preliminary distal boundary and move the proximal boundary toward it by a fraction of the preliminary width; choose the fraction by comparing that width with increasing ATR multiples, using progressively larger fractions for wider ranges and zero fraction at or below ATR. Demand width is proximal minus distal; supply width is distal minus proximal. Select either refined or unrefined boundaries as configured.
Calculation: Each side's alert lock starts at zero. After evaluating its signal on each bar, set the lock to one if the signal occurred, then reset it to zero if that side's current proximal boundary differs from its previous-bar value.
Long: current low <= current demand proximal boundary AND previous low > current demand proximal boundary AND demand alert lock = zero.
Short: current high >= current supply proximal boundary AND previous high < current supply proximal boundary AND supply alert lock = zero.
