Calculation: Timeframe state = bullish when close > short-term EMA > long-term EMA AND trend Supertrend is bullish AND RSI > RSI threshold AND MACD histogram > its previous value AND ADX >= that timeframe's minimum; bearish when close < short-term EMA < long-term EMA AND trend Supertrend is bearish AND RSI < RSI threshold AND MACD histogram < its previous value AND ADX >= that timeframe's minimum; otherwise flat. Calculate independently on the chart timeframe and each enabled higher timeframe; higher-timeframe values use the previous completed higher-timeframe bar with lookahead off. Use either a common ADX minimum or separate higher-timeframe minimums.
Calculation: Bull count and bear count = counts of enabled timeframes in the respective states; enabled count includes the chart timeframe; active count includes enabled non-flat states.
Calculation: Required count = if adaptive denominator is enabled, max(active count - allowed disagreements, min(enabled count, 2)); otherwise max(enabled count - allowed disagreements, 1).
Calculation: Directional weighted percentage = 100 times the sum of weights of enabled timeframes in that direction divided by the sum of enabled weights; if adaptive denominator is enabled AND active count >= 2, use the sum of non-flat enabled weights as denominator instead. If the denominator is zero, the percentage is zero.
Calculation: Directional entry gate = in equal-weight mode, directional count >= required count AND directional count > 0; in weighted mode, directional weighted percentage >= threshold. Additionally, if the higher-timeframe opposition veto is enabled and its designated higher timeframe is enabled, its state must not be opposite; if the average-ADX gate is enabled, the average ADX across enabled timeframes must be >= its threshold; if the rising-ADX gate is enabled, chart ADX must be greater than every ADX value in the preceding lookback bars.
Calculation: Exit Supertrend = chart-timeframe Supertrend with a separate ATR length and factor from the trend Supertrend. If the profit ladder and stop tightening are both enabled, its factor on each bar is max(base factor × (1 - tightening fraction × number of enabled profit tiers reached since entry), base factor × 0.25); otherwise use the base factor. A tier is reached once the position's percentage return based on close and entry price is >= its threshold, and remains reached until the next entry.
Long: Any enabled timeframe state = bullish.
Short: Any enabled timeframe state = bearish.
Long: Background tint enabled AND bull count > bear count.
Short: Background tint enabled AND bear count > bull count.
Long: Exit Supertrend line enabled AND exit Supertrend is bullish.
Short: Exit Supertrend line enabled AND exit Supertrend is bearish.
Long: Bull count > bear count AND bull count > 0 AND bull count < required count AND this conjunction was false on the preceding bar.
Short: Bear count > bull count AND bear count > 0 AND bear count < required count AND this conjunction was false on the preceding bar.
Long: Long entry gate has held for at least the confirmation lookback AND had not held for that many consecutive bars on the preceding bar AND position side is not long AND (volume confirmation disabled OR volume >= volume SMA × volume multiplier) AND (cooldown disabled OR no previous long trailing-stop exit exists OR bars since that exit >= cooldown). Enter at close and close any short position at the same close.
Short: Short entry gate has held for at least the confirmation lookback AND had not held for that many consecutive bars on the preceding bar AND position side is not short AND (volume confirmation disabled OR volume >= volume SMA × volume multiplier) AND (cooldown disabled OR no previous short trailing-stop exit exists OR bars since that exit >= cooldown). Enter at close and close any long position at the same close.
Exit: long, exit Supertrend changes from bullish on the preceding bar to bearish on the current bar; evaluate after entries.
Exit: short, exit Supertrend changes from bearish on the preceding bar to bullish on the current bar; evaluate after entries.
Exit: long, after trailing-stop exits, chart ADX is lower than every ADX value in the preceding weakening lookback bars OR histogram-decay warning is enabled AND MACD histogram < previous histogram < histogram two bars ago, AND this position-specific warning condition was false on the preceding bar.
Exit: short, after trailing-stop exits, chart ADX is lower than every ADX value in the preceding weakening lookback bars OR histogram-decay warning is enabled AND MACD histogram < previous histogram < histogram two bars ago, AND this position-specific warning condition was false on the preceding bar.
Exit: long, profit ladder enabled AND an enabled profit tier's percentage return from entry is >= its threshold for the first time in the current position; evaluate after entries and before trailing-stop exits.
Exit: short, profit ladder enabled AND an enabled profit tier's percentage return from entry is >= its threshold for the first time in the current position; evaluate after entries and before trailing-stop exits.
