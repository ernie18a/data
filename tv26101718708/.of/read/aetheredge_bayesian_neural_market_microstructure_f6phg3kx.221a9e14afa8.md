Calculation: Order-flow pressure = EMA(sign(close − open) × volume, volume-delta lookback) / SMA(volume, normalization lookback), or zero when the denominator is zero; clamp to [−3, 3].
Calculation: Network features = order-flow pressure and the rolling z-scores of normalized momentum, spread regime, and liquidity regime. Normalized momentum is (shorter EMA of close − longer EMA of close) / ATR, or zero when ATR is zero. Spread regime is SMA((high − low) / close, spread lookback) / SMA(that SMA, normalization lookback) − 1, using 1 as the close denominator when close is zero and zero when the outer denominator is zero. Liquidity regime is SMA(volume / range, liquidity lookback) / SMA(that SMA, normalization lookback) − 1, using the instrument's minimum price increment when high equals low and zero when the outer denominator is zero. Each z-score uses the normalization lookback, is zero when its standard deviation is zero, and is clamped to [−3, 3].
Calculation: Forecast mean and uncertainty = outputs of an online network with four feature inputs, a parameterized number of tanh hidden units, and one linear output. Initialize hidden and output weights as (R(seed) − 0.5) × 0.6, incrementing each layer's seed by 2654435761 before each weight; the layer seeds are initialization seed × 2654435761 and initialization seed × 40503 + 101. Initialize biases to zero. R(s) is the fractional part of sin((abs(s % 2147483647) + 1) × 12.9898 + 78.233) × 43758.5453. Process only bars with bar index greater than final bar index minus training horizon. On each confirmed bar, append the preceding bar's features and (close − close[prediction horizon]) / ATR to a bounded FIFO replay buffer; use zero for the target when ATR is zero. For each training update, select buffer index floor(R((bar index × 7919 + update index × 104729 + initialization seed) % 2147483647) × buffer size) % buffer size. Run a deterministic forward pass, clamp prediction minus target to [−5, 5], and apply gradient descent with the learning-rate parameter to the output and hidden weights and biases, using the pre-update output weights for hidden gradients. Then compute multiple stochastic forward passes on the current features. For sample k use seed (bar index × 2246822519 + initialization seed) % 2147483647 + k × 99991. For hidden unit h, drop it when R(seed × 31 + h × 17 + 5) is below the dropout parameter; otherwise multiply its activation by 1 / (1 − dropout parameter). Add weight-noise parameter × G(seed × 13 + h × 7 + input index) to each input weight and weight-noise parameter × G(seed × 23 + h × 3) to each output weight, where G(s) = (R(s) + R(s × 7919 + 1) + R(s × 104729 + 2) − 1.5) × 1.1547. Clamp tanh inputs to [−20, 20]. Forecast mean is the sample mean; uncertainty is the square root of max(0, mean of squared samples − forecast mean squared). Use zero as forecast mean when unavailable.
Calculation: Normalized uncertainty = current uncertainty divided by its rolling maximum over an uncertainty lookback, capped at 1; use zero when the maximum is zero and replace unavailable uncertainty with zero.
