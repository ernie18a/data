Calculation: Timeframe sampling = For every configured bias, key-level, and execution timeframe, use the last completed bar when it is higher than the chart timeframe; when it is lower, use the last completed intrabar returned for each chart bar; when equal, use the chart bar. Confirmation uses the previous completed execution-timeframe bar and is evaluated when a new execution-timeframe period begins.
Calculation: Fair value gap = A bullish gap exists when low > high two bars earlier, with bottom = that earlier high and top = current low. A bearish gap exists when high < low two bars earlier, with bottom = current high and top = that earlier low. Keep only the latest gap of each direction per timeframe. A bullish gap is invalidated when close < bottom; a bearish gap is invalidated when close > top. Gap time is the opening time of its creation bar.
Calculation: Bias = On each configured bias timeframe, track whether the latest gap of each direction has ever been touched since creation, with touch defined by low <= top AND high >= bottom, and whether it has ever been invalidated. Bull evidence is the count of a touched, uninvalidated bullish gap and an invalidated bearish gap; bear evidence is the count of a touched, uninvalidated bearish gap and an invalidated bullish gap. The timeframe state is positive, negative, or zero according to whether bull evidence is greater than, less than, or equal to bear evidence. Sum the states using equal greatest weights for the two longest timeframes, a smaller weight for the next, and an optionally included still smaller weight for the shortest. Bullish bias requires this score >= a positive threshold; bearish bias requires it <= the negative threshold. Manual bullish or bearish bias may replace the score.
Calculation: Key zones = On each enabled key-level timeframe, use the latest active bullish and bearish fair value gaps. An active gap becomes inactive on invalidation. A confirmed pivot low inside the active bullish gap is the bullish internal-level candidate; a confirmed pivot high inside the active bearish gap is the bearish candidate. Confirm pivots using equal numbers of bars on both sides. A bullish internal level becomes active when low < its candidate AND close > its candidate; a bearish internal level becomes active when high > its candidate AND close < its candidate. Candidates persist until replaced. Center each internal-level zone on its level with half-width equal to the greater of ATR multiplied by a parameter and a minimum price increment parameter. Deactivate a bullish internal level when close < its zone bottom and a bearish one when close > its zone top. A bullish base touch is overlap of the bar with an active bullish gap or internal-level zone; a bearish base touch is overlap with an active bearish gap or internal-level zone. On a bullish base touch with close > open AND low < min(open, close), create an active bullish rejection zone from low to min(open, close); deactivate it when close < its bottom. On a bearish base touch with close < open AND high > max(open, close), create an active bearish rejection zone from max(open, close) to high; deactivate it when close > its top. On a bullish base touch with close < open, store the open of the oldest candle in the contiguous bearish series ending at that bar, limited by a lookback parameter; replace any pending bullish value. When close > the pending value, create an active bullish zone centered on that value with the same half-width and clear the pending value; deactivate the zone when close < its bottom. Apply the mirror image to a bearish base touch and contiguous bullish series, confirming when close < the pending value and deactivating when close > the zone top. Keep the latest zone of each type and direction; record the creation time of each zone.
Calculation: Selected key zone = For bullish bias, retain active bullish zones whose bottom <= chart close and minimize max(chart close - zone top, 0). For bearish bias, retain active bearish zones whose top >= chart close and minimize max(zone bottom - chart close, 0). Within a timeframe, break equal-distance ties in order: rejection zone, confirmed opposing-series zone, internal-level zone, fair value gap. Across enabled timeframes, break ties in favor of the higher timeframe.
Calculation: Armed setup = During the permitted session, a chart bar touching the selected key zone, meaning low <= zone top AND high >= zone bottom, arms a setup in the current bias direction if no setup is armed or the selected zone creation time or direction differs from the armed setup. Save the zone boundaries and direction. At that touch, find the time of the highest high among a configured number of preceding chart bars for a bullish setup, or the lowest low for a bearish setup; on ties use the most recent bar. On each enabled execution timeframe, consider only its latest opposite-direction fair value gap if its creation time is between that extreme's time and the touch bar's time, inclusive; optionally require it to remain uninvalidated at the touch. Select the eligible gap on the highest execution timeframe and save its boundaries. A new setup replaces the previous selection. An armed setup remains armed even if no gap was selected, until replaced, invalidated, or signaled. After checking for a signal on each bar, cancel a bullish setup if chart close < saved key-zone bottom, or a bearish setup if chart close > saved key-zone top. A signal disarms the setup. Changes in bias alone do not cancel it.
Calculation: Session allowance = If the session restriction is enabled, permit only bars whose opening times fall inside the configured session in its configured timezone, and reset the signal count at session start. If disabled, permit all bars and reset the count at the start of each chart day. Increment the count after each confirmed entry signal.
Long: Bullish bias AND permitted session AND chart low <= selected bullish key-zone top AND chart high >= selected bullish key-zone bottom AND (no setup is armed OR selected key-zone creation time differs from the armed setup's key-zone time OR the armed setup direction is bearish).
Short: Bearish bias AND permitted session AND chart low <= selected bearish key-zone top AND chart high >= selected bearish key-zone bottom AND (no setup is armed OR selected key-zone creation time differs from the armed setup's key-zone time OR the armed setup direction is bullish).
Long: Armed bullish setup AND selected opposite-direction gap exists AND a new selected execution-timeframe period begins AND the last completed execution-timeframe close > selected gap top AND session is permitted AND signal count < session limit.
Short: Armed bearish setup AND selected opposite-direction gap exists AND a new selected execution-timeframe period begins AND the last completed execution-timeframe close < selected gap bottom AND session is permitted AND signal count < session limit.
