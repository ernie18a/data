Calculation: Feature vector = z-scores of RSI of close, rate of change of close, volume, and ATR divided by close times 100, each using the same normalization lookback; each z-score is (value minus its simple moving average) divided by its standard deviation, or zero when the standard deviation is not positive.
Calculation: KNN probability score = Compare the current feature vector with a rolling buffer of previously resolved vectors using the square root of the sum of each squared feature difference multiplied by its configurable nonnegative feature weight. Select up to K vectors with the smallest distances. Each selected vector's outcome is 1 if close at the end of its prediction horizon was above close at the vector's bar, otherwise 0. The score is 100 times the weighted mean of these outcomes, with each neighbor's weight either 1 or 1/(1 + distance), according to the chosen weighting mode. Use 50 if the buffer is empty or the total weight is zero. Calculate the score before appending the current bar's newly resolved vector; then append the vector from one prediction horizon ago and its outcome if all its features are available, removing the oldest entry if the buffer exceeds its maximum size.
Long: KNN probability score >= bullish threshold.
Long: KNN probability score crosses above bullish threshold AND buffer size before the current bar's append >= minimum sample size.
Short: KNN probability score < bullish threshold AND KNN probability score <= bearish threshold.
Short: KNN probability score crosses below bearish threshold AND buffer size before the current bar's append >= minimum sample size.
