Calculation: Source = a selected price series derived from the bar fields.
Calculation: Active box = when no box is active and a full box lookback is available, set the ceiling to the highest high and the floor to the lowest low over that lookback, including the current bar, if the height is at least ATR times a minimum-height multiplier and, when the rising-box filter is enabled, the ceiling is above the previous completed box ceiling or no previous ceiling exists. Hold both levels fixed until a breakout. On a breakout, record its ceiling as the previous completed box ceiling and deactivate the box; do not start another box on that bar.
Calculation: Upward breakout = an active box exists and, according to the selected breakout mode, close > box ceiling or high > box ceiling. Downward breakout = an active box exists and, according to the same mode, close < box floor or low < box floor, AND no upward breakout occurs on the same bar.
Calculation: Base stop = the active box floor, the active box ceiling, or source minus ATR times a stop multiplier, according to the selected stop mode. On a qualifying upward breakout while flat, enter long at source and initialize the stop to the base stop. While long, on any box breakout, if trailing to higher boxes is enabled and the completed box ceiling exceeds the previous completed box ceiling, raise the stop to the maximum of its current value and the base stop. Also raise it to that maximum on a qualifying upward breakout with source above entry price when trailing is enabled. Use the updated stop for the current bar's exit decision.
Long: Upward breakout AND (volume filter disabled OR volume >= volume SMA times a volume multiplier) AND (trend filter disabled OR source > source EMA) AND (position at the start of the bar is flat OR source > entry price).
Short: Position at the start of the bar is flat AND downward breakout.
Exit: long, source < stop OR downward breakout.
