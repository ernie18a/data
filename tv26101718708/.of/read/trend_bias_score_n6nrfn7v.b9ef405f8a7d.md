Calculation: Timeframe bias = weighted average of trend, momentum, acceleration, and energy scores, using positive component weights. Calculate each score on the selected timeframe: trend is a weighted average of three signs for close > short moving average, short moving average > medium moving average, and medium moving average > long moving average; each sign is +1 if true, -1 if false, and 0 if its inputs are unavailable. Use the same moving-average type for all three. Momentum is (RSI - 50) / 50, or 0 if RSI is unavailable. Acceleration is +1 if the MACD histogram increased from the preceding timeframe bar, -1 otherwise, or 0 if the histogram is unavailable. Signed volume is volume multiplied by +1 when close >= open and -1 otherwise; volume bias is +1 when signed volume > its EMA and close >= open, -1 when signed volume > its EMA and close < open, and 0 otherwise. ATR bias is +1 when ATR > its EMA, -1 otherwise, or 0 if the EMA is unavailable. Energy is the weighted average of volume bias and ATR bias using positive weights; open interest is unavailable in the backtest data. Each timeframe uses its own short, medium, and long moving-average lookbacks.
Calculation: Composite bias = weighted average of the available timeframe biases across six progressively longer timeframes, using positive timeframe weights. For each requested timeframe, use the bar still forming if it is higher than the chart timeframe; if lower, use the last completed lower-timeframe bar within the chart bar.
Calculation: Table bias = timeframe bias calculated independently for each of six selectable timeframes, with its own short, medium, and long moving-average lookbacks. Use the bar still forming if the selected timeframe is higher than the chart timeframe; if lower, use the last completed lower-timeframe bar within the chart bar.
Long: composite bias > 0 OR any table bias > 0
Short: composite bias < 0 OR any table bias < 0
