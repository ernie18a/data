Calculation: VWAP = volume-weighted average of hlc3 with accumulation reset on every bar; Band_up = VWAP + k*stdev(hlc3 - VWAP, n); Band_lo = VWAP - k*stdev(hlc3 - VWAP, n)
Calculation: RSI_c = RSI(close) on chart timeframe; RSI_h = same RSI on a higher timeframe, using the still-forming higher-timeframe bar (no lookahead); oversold < 50 < overbought
Calculation: MACD line, signal line, hist = line - signal (fast < slow); ADX, DI+, DI-; EMA = EMA(close); pivot swing high/low = extreme over L bars on each side, confirmed L bars later
Calculation: Scores (units; sum compared to a threshold T in the same units). Buy side: S_vwap = 2 if low <= Band_lo*(1+tol) AND close > VWAP, else 1 if close > VWAP, else 0. S_rsi = 2 if RSI_c < oversold AND RSI_h > 50, else 1 if 50 < RSI_c < overbought AND RSI_h > 50, else 0. S_macd = 2 if MACD line crosses above signal line, else 1 if line > signal AND hist > 0 AND hist > previous hist, else 0. S_adx: tier = 3 if ADX >= strong level, 2 if ADX >= mid level, 1 if ADX >= weak level, else 0 (strong > mid > weak); S_adx = tier if DI+ > DI-, else tier/2. S_struct = 1 if close crosses above last confirmed swing high, else 0.5 if structure state is up (state before this bar), else 0; structure state: initially up, set up when close crosses above last confirmed swing high, set down when close crosses below last confirmed swing low. S_ema = 1 if close > EMA AND EMA > EMA[3 bars ago], else 0.5 if close > EMA, else 0. S_vol = 1 if volume > hi*SMA(volume) AND close > open, else 0.5 if lo*SMA(volume) <= volume <= hi*SMA(volume) AND close > open, else 0 (hi > 1 > lo). S_div = 1 if low < lowest low of previous 5 bars AND RSI_c > lowest RSI_c of previous 5 bars AND RSI_c < level below 50, else 0.
Calculation: Sell side mirrors buy side: S_vwap = 2 if high >= Band_up*(1-tol) AND close < VWAP, else 1 if close < VWAP; S_rsi = 2 if RSI_c > overbought AND RSI_h < 50, else 1 if oversold < RSI_c < 50 AND RSI_h < 50; S_macd = 2 if MACD line crosses below signal line, else 1 if line < signal AND hist < 0 AND hist < previous hist; S_adx = tier if DI- > DI+, else tier/2; S_struct = 1 if close crosses below last confirmed swing low, else 0.5 if structure state is down; S_ema = 1 if close < EMA AND EMA < EMA[3 bars ago], else 0.5 if close < EMA; S_vol uses close < open; S_div = 1 if high > highest high of previous 5 bars AND RSI_c < highest RSI_c of previous 5 bars AND RSI_c > level above 50
Calculation: BuyConf = sum of buy-side scores; SellConf = sum of sell-side scores
Long: BuyConf >= T AND previous-bar BuyConf < T AND the most recent fired signal is not a Long (none or Short)
Short: SellConf >= T AND previous-bar SellConf < T AND the most recent fired signal is a Long
