Calculation: Sample trigger = Choose one method: (1) trigger every N chart bars, with the first bar numbered 1 and a trigger when (bar number − offset) modulo N = 0; (2) for an interval multiplier greater than 1, trigger offset chart bars after the start of each higher-timeframe bar; for a multiplier of 1, trigger on every chart bar; or (3) initialize a price-action reference to zero, replace it with the source whenever the absolute difference between source and reference is at least the range, and trigger offset chart bars after the reference changes. The interval method uses the still-forming higher-timeframe bar.
Calculation: Price-action range = Choose an absolute amount, pips converted to price, points converted using point value, ticks converted using minimum tick size, a percentage of close, a multiple of EMA of true range, or a multiple of EMA of absolute close change. Optionally smooth the chosen range with an EMA. A zero range parameter makes the price-action method trigger on every chart bar. Point value and minimum tick size are instrument-specific parameters.
Calculation: Sampled filter = Apply the selected filter to the source only on sample-trigger bars and hold its value between triggers. Choose SMA, EMA, ZLEMA, DEMA, RMA, WMA, VWMA, ALMA, HMA, exponentially weighted HMA, two-pole Butterworth, two-pole Gaussian, or super smoother. EMA and RMA initialize to the first sample; SMA and weighted averages use available samples until their window fills. ZLEMA applies EMA to twice the current sample minus the sample round((length − 1)/2) samples earlier, using the oldest available sample during warm-up. DEMA is twice EMA minus EMA of EMA. HMA applies WMA of length round(sqrt(length)) to twice WMA of length round(length/2) minus WMA of length; exponentially weighted HMA substitutes EMA for each WMA. ALMA uses its conventional offset and width. VWMA weights each sampled source by the sum of volume since the preceding sample, excluding the preceding sample and including the current one; if volume is missing, substitute absolute open-to-close movement in ticks, carrying forward the previous movement when it is smaller than one tick.
Calculation: Two-pole sampled filters = On each sample, let x be the current sampled source, x1 and x2 the previous two sampled sources, y1 and y2 the previous two filter outputs, and n the filter length. Start output on the third sample, initializing both previous outputs to that sample. For Butterworth, let a = exp(−sqrt(2) × pi / n), b = 2a × cos(sqrt(2) × pi / n), c = a²; output b × y1 − c × y2 + (1 − b + c) × (x + 2 × x1 + x2) / 4. For Gaussian, let beta = (1 − cos(2 × pi / n)) / (sqrt(2) − 1), alpha = −beta + sqrt(beta² + 2 × beta); output alpha² × x + 2 × (1 − alpha) × y1 − (1 − alpha)² × y2. For super smoother, let a = exp(−sqrt(2) × pi / n), b = 2a × cos(sqrt(2) × pi / n), c = −a²; output (1 − b − c) × x + b × y1 + c × y2.
Calculation: Filter direction = 1 when the sampled filter rises from the previous chart bar, −1 when it falls, and otherwise its previous direction; initialize to 0.
Long: Filter direction = 1
Short: Filter direction = −1
