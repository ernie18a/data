Calculation: Pivot sequence = Use either ordinary or Heikin Ashi candles. On each selected-timeframe bar, define up as close >= open and down as close <= open. Set direction to down if the previous bar was up and the current bar is down; otherwise set it to up if the previous bar was down and the current bar is up; otherwise retain the previous direction, initialized to neutral. On an up-to-down transition, emit the highest high of the current and previous bars if the previous direction was not down; otherwise, on a down-to-up transition, emit the lowest low of those bars if the previous direction was not up. Use the chart timeframe or an alternative timeframe. For a higher alternative timeframe, sample only at the start of each new higher-timeframe bar, using its still-forming bar; historical evaluation exposes that bar's final value. For a lower alternative timeframe, sample only when its time changes, using the first completed lower-timeframe bar within the chart bar. Retain the five most recent emitted pivots in chronological order as X, A, B, C, D.
Calculation: Pattern ratios = R1 = abs(B-A)/abs(X-A), R2 = abs(B-C)/abs(A-B), R3 = abs(C-D)/abs(B-C), R4 = abs(A-D)/abs(X-A). A pattern matches when each of its applicable ratios is within that pattern's independently parameterized inclusive bounds. Use separate bound sets for Bat, Anti Bat, Alternative Bat, Butterfly, Anti Butterfly, ABCD, Gartley, Anti Gartley, Crab, Anti Crab, Shark, Anti Shark, 5-O, Wolf Wave, Head and Shoulders, Contracting Triangle, and Expanding Triangle. ABCD constrains only R2 and R3; Bat and Alternative Bat have no lower R4 bound, and Alternative Bat and Butterfly have no lower R1 bound. All other listed patterns constrain all four ratios. A bullish match also requires D < C; a bearish match also requires D > C.
Calculation: Retracement level at rate r = D - r * abs(D-C) if D > C, otherwise D + r * abs(D-C). Entry, profit-target, and stop-loss rates are separately parameterized.
Long: Any bullish pattern matches AND that same bullish pattern did not match on the previous chart bar.
Short: Any bearish pattern matches AND that same bearish pattern did not match on the previous chart bar.
Long: Any bullish pattern matches AND close <= retracement level at the entry rate.
Short: Any bearish pattern matches AND close >= retracement level at the entry rate.
Exit: long, high >= retracement level at the profit-target rate OR low <= retracement level at the stop-loss rate.
Exit: short, low <= retracement level at the profit-target rate OR high >= retracement level at the stop-loss rate.
