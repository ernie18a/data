Calculation: Model inputs = log return ln(close/previous close), using zero on the first bar; standardized return = (log return − SMA(log return))/standard deviation(log return); normalized volatility = (ATR/close − SMA(ATR/close))/standard deviation(ATR/close); normalized RSI = (RSI − 50)/50; normalized slope = clamp((shorter EMA(close) − longer EMA(close))/ATR, −3, 3)/3; normalized momentum = clamp(5 × rate of change of close as a fraction, −1, 1). Add a small positive constant to every standard-deviation or ATR denominator.
Calculation: Higher-timeframe inputs = on each chart bar, use the last completed higher-timeframe close and RSI, and the last completed still-higher-timeframe close and EMA. Higher-timeframe return is ln(current higher-timeframe close/its value on the previous chart bar); standardize it by dividing by twice the chart-timeframe log-return standard deviation plus a small positive constant, clamp to [−3, 3], and divide by 3. Normalize higher-timeframe RSI as (RSI − 50)/50. Still-higher-timeframe bias is sign(close − EMA) × min(1, abs(close − EMA)/(3 × chart-timeframe ATR + a small positive constant)). When higher-timeframe inputs are disabled, all three inputs are zero. Replace unavailable inputs with zero.
Calculation: Hidden states = initialize each cell and hidden state to zero; update once per completed chart bar after the initial warm-up. For unit index u from zero to unit count minus one, set its memory factor τ evenly from 0.6 to 0.98. For input index k from zero through seven, in the order standardized return, normalized volatility, normalized RSI, normalized slope, normalized momentum, higher-timeframe return, higher-timeframe RSI, still-higher-timeframe bias, calculate weight w(u,k) = 0.6 sin(1.73u + 2.41k) + 0.4 cos(1.3 × (1.73u + 2.41k)); let z = sum(input[k] × w(u,k)) + 0.1 sin(0.7u). With sigmoid and tanh arguments clamped to [−20, 20], calculate forget gate = sigmoid(0.3 × (z + 2)) × τ + (1 − τ) × forget-base parameter; input gate = sigmoid(0.3z) × learning-rate parameter × (1 + higher-timeframe-weight parameter × abs(still-higher-timeframe bias)); candidate = tanh(0.5z); output gate = sigmoid(0.3 × (z + 0.5)). New cell = forget gate × previous cell + input gate × candidate; when residual connection is enabled and u is less than half the unit count, add residual-mix parameter × standardized return × (1 − τ). Hidden state = output gate × tanh(new cell).
Calculation: Attention return = retain the most recent attention-lookback completed chart bars, including the current bar, storing each bar's mean hidden state and log return. When attention is enabled and the history has reached its minimum size, score each stored bar i as (current mean hidden × stored mean hidden[i] − 0.5 × abs(current mean hidden − stored mean hidden[i])) × exp(−age[i]/(0.8 × attention lookback)) / temperature parameter. Apply softmax to the scores and sum the stored log returns weighted by those softmax weights. Otherwise attention return is zero.
Calculation: Expected return = clamp(mean hidden state × longer-lookback standard deviation of log returns × 0.5 + attention return × 0.35 when attention is enabled + standardized return × the same longer-lookback standard deviation × residual-mix parameter × 0.3 when residual connection is enabled, −return cap, return cap). Add a small positive constant to the standard deviation. The longer standard-deviation lookback exceeds the standardized-return lookback.
Long: Expected return > 0.
Short: Expected return ≤ 0.
Long: Expected return > longer-lookback standard deviation of log returns AND (attention is disabled OR attention return > 0).
Short: Expected return < −longer-lookback standard deviation of log returns AND (attention is disabled OR attention return < 0).
Long: Expected return > 0 AND previous expected return ≤ 0.
Short: Expected return < 0 AND previous expected return ≥ 0.
Long: A hidden state > positive hidden-state threshold.
Short: A hidden state < negative hidden-state threshold.
Long: Any model input > positive input threshold.
Short: Any model input < negative input threshold.
Long: Close > previous close.
Short: Close < previous close.
