Calculation: Control VWAP = rolling sum of typical price multiplied by adjusted volume divided by rolling sum of adjusted volume, where typical price = (high + low + close) / 3 and adjusted volume = volume if volume > 0, otherwise 1.
Calculation: Control band = control VWAP plus or minus the greater of a multiplier times the rolling population standard deviation of (typical price minus its contemporaneous control VWAP) and another multiplier times ATR. Use ATR in place of the standard deviation when the latter is unavailable.
Calculation: Acceptance direction = bullish if every close in the acceptance lookback is above its contemporaneous upper control band, bearish if every close in that lookback is below its contemporaneous lower control band, otherwise neutral.
Calculation: Control direction and rejection memory = initially neutral and false. On each bar, if acceptance direction is nonneutral AND (acceptance direction differs from control direction OR rejection memory is true AND close is outside the control band), set control direction to acceptance direction, record the current bar as the shift bar, and set rejection memory to false. Then, if control direction is nonneutral AND the number of bars since the shift bar is at most the rejection window AND close is inside or on the control band, set rejection memory to true. Otherwise retain both values.
Long: Control direction is bullish.
Short: Control direction is bearish.
