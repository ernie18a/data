Calculation: Grid reference = initialize to close; on each bar set to high if high >= prior reference + grid gap, otherwise set to low if low <= prior reference - grid gap, otherwise retain prior reference
Calculation: Upper/lower Bollinger Band = simple moving average of close ± standard-deviation multiplier × standard deviation of close
Calculation: Fractal breakout levels = latest confirmed pivot high/low, with equal left and right lookback
Calculation: Reversal fractals = pivot high/low with the source's 3-left/0-right or 4-left/1-right pattern, combined with the corresponding current and prior candle direction or higher-low/lower-high condition
Calculation: Pin bars = candle wick exceeds body × sensitivity, with a same-bar pivot high/low and the source's wick-dominance condition
Calculation: Ichimoku cloud = max/min of the two leading spans, each displaced by the cloud shift; Tenkan and Kijun = midpoint of the highest high and lowest low over their respective lookbacks
Calculation: Fractal trend lines = lines through the two latest confirmed pivot highs/lows, extended to the current bar
Calculation: Segments = three successive lower-low segments for a long setup, or higher-high segments for a short setup, each within the maximum bar spacing
Long: Any selected entry signal: grid reference rises; low < lower Bollinger Band; high crosses above the latest fractal high; reversal-fractal low pattern; or bullish pin bar. AND each selected entry filter passes: upward fractal trend-line break; bullish segment breakout; lower-band Bollinger event since the last upper-band event; price-filtered bullish cloud flip; high > prior high and the three-segment long setup; high > latest fractal high; latest fractal low > preceding fractal low AND high > latest fractal high; high > SuperTrend; high > Parabolic SAR; high > EMA and SMA; high > EMA21 and SMA20 AND EMA21 > SMA20; MACD line > signal line; MACD line rising; RSI > 50; EMA1 > EMA2; HMA rising; short-period HMA variant > HMA; TRIX rising; ADX rising; ADX > threshold; close > Kijun; close > cloud top; close > Tenkan; Tenkan > cloud top; Tenkan > Kijun; cloud spans bullish; Chikou > prior price or cloud; or bullish reversal-fractal pattern. The two entry-signal slots are OR-connected; selected filters are AND-connected. Entry filters and signals use the chart timeframe or a configured higher timeframe; higher-timeframe values use the forming bar when repainting is allowed, otherwise the preceding completed higher-timeframe bar. No-timeframe filters use the chart timeframe.
Short: Any selected entry signal: grid reference falls; high > upper Bollinger Band; low crosses below the latest fractal low; reversal-fractal high pattern; or bearish pin bar. AND each selected entry filter passes: downward fractal trend-line break; bearish segment breakout; upper-band Bollinger event since the last lower-band event; price-filtered bearish cloud flip; low < prior low and the three-segment short setup; low < latest fractal low; latest fractal high < preceding fractal high AND low < latest fractal low; low < SuperTrend; low < Parabolic SAR; low < EMA and SMA; low < EMA21 and SMA20 AND EMA21 < SMA20; MACD line < signal line; MACD line not rising; RSI < 50; EMA1 < EMA2; HMA falling; short-period HMA variant < HMA; TRIX not rising; ADX not rising; ADX > threshold; close < Kijun; close < cloud bottom; close < Tenkan; Tenkan < cloud bottom; Tenkan < Kijun; cloud spans bearish; Chikou < prior price or cloud; or bearish reversal-fractal pattern. The two entry-signal slots are OR-connected; selected filters are AND-connected. Entry filters and signals use the chart timeframe or a configured higher timeframe; higher-timeframe values use the forming bar when repainting is allowed, otherwise the preceding completed higher-timeframe bar. No-timeframe filters use the chart timeframe.
Exit: Long, any selected bearish exit filter: low crosses below the lower Bollinger Band; TRIX falls; EMA1 crosses below EMA2; short-period HMA variant crosses below HMA; HMA or ALMA turns falling; bearish reversal-fractal pattern; MACD line crosses below signal line or turns falling; RSI crosses below 50; low crosses below the latest fractal low; low crosses below SuperTrend or Parabolic SAR; prior close crosses below SMA; +DI crosses below −DI; ADX turns falling or crosses below threshold; low crosses below cloud bottom or Kijun; or price crosses below the bearish fractal trend line. Exit filters are OR-connected and use the chart timeframe or configured higher timeframe, with the same forming-versus-completed-bar rule as entry filters. Also exit when the long grid stop reference steps down and close < average entry price if the average-loss restriction is enabled; when the long grid profit reference steps up and close > average entry price if the average-profit restriction is enabled; when close crosses average entry price after prior net profit is positive and break-even close is enabled; when low crosses below average entry price after the prior low was above it and partial break-even is enabled; when a configured close-and-stop level is crossed; or when a configured border is crossed and border behavior is Close All.

Exit filters are OR-connected and use the chart timeframe or configured higher timeframe, with the same forming-versus-completed-bar rule as entry filters. Also exit when the short grid stop reference steps up and close > average entry price if the average-loss restriction is enabled; when the short grid profit reference steps down and close < average entry price if the average-profit restriction is enabled; when close crosses average entry price after prior net profit is positive and break-even close is enabled; when high crosses above average entry price after the prior high was below it and partial break-even is enabled; when a configured close-and-stop level is crossed; or when a configured border is crossed and border behavior is Close All.
