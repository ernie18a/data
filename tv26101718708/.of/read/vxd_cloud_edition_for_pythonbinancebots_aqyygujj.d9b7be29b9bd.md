Calculation: Smoothed regression = EMA of the endpoint of the linear regression of close; its slope is rising when its current value exceeds every value in its slope lookback, and falling when it is below every value in that lookback.
Calculation: Volatility trend = in Cloud-MA mode, recursively use max(low − multiplier × SMA(true range), previous volatility trend) when RSI is at least its threshold, otherwise min(high + multiplier × SMA(true range), previous volatility trend), with a missing previous value replaced by zero; in either pivot mode use Supertrend.
Calculation: Cloud high and cloud low = respectively the maximum and minimum of the fast EMA of close, smoothed regression, and volatility trend at a fixed bar lag. The slow EMA has a longer period than the fast EMA.
Calculation: Andean components = set alpha = 2 / (lookback + 1); recursively set upper first moment to max(close, open, previous upper first moment + alpha × (close − previous upper first moment)), upper second moment to max(close², open², previous upper second moment + alpha × (close² − previous upper second moment)), and lower moments analogously using min. Initialize missing prior moments with close and close² respectively. Bull component = sqrt(lower second moment − lower first moment²); bear component = sqrt(upper second moment − upper first moment²).
Calculation: Cloud line = when the bull component exceeds the bear component, max(cloud low, previous cloud line); when the bear component exceeds the bull component, min(cloud high, previous cloud line); otherwise the previous cloud line. Replace a missing previous cloud line with zero. Cloud direction becomes positive when the cloud line exceeds every value in its direction lookback, negative when it is below every value in that lookback, and otherwise retains its previous direction.
Calculation: Pivot high and pivot low = the latest confirmed high or low pivot, respectively, using equal numbers of bars on each side. Swing high = highest recorded pivot high over the sizing lookback; swing low = lowest recorded pivot low over that lookback.
Calculation: Long action = position is flat or short AND datetime is inside the configured backtest range AND close > cloud high AND, in either pivot mode, close > pivot high AND, in filtered pivot mode, smoothed regression is rising; in Cloud-MA mode, substitute cloud direction > 0 for the pivot and regression conditions. Short action = position is flat or long AND datetime is inside the configured backtest range AND close < cloud low AND, in either pivot mode, close < pivot low AND, in filtered pivot mode, smoothed regression is falling; in Cloud-MA mode, substitute cloud direction < 0 for the pivot and regression conditions. An action changes when its Boolean value differs from its previous value, including a change from true to false.
Calculation: Long exit signal = cloud direction changes to negative in Cloud-MA mode, or close < cloud low AND close < pivot low in either pivot mode. Short exit signal = cloud direction changes to positive in Cloud-MA mode, or close > cloud high AND close > pivot high in either pivot mode.
Calculation: While a position is open, tracked high updates to high only when high > previous bar high and otherwise retains its previous value; tracked low updates to low only when low < previous bar low and otherwise retains its previous value. When flat, reset them to the current high and low.
Calculation: On a long action change, store the current open trade's entry price as the long reference price if the position is flat or long, and calculate the long risk unit as current open trade entry price − swing low. On a short action change, store the current open trade's entry price as the short reference price if the position is flat or short, and calculate the short risk unit as swing high − current open trade entry price. These values follow the source's missing-value behavior when no open trade exists. Long profit targets are long reference price + risk unit × each configured reward multiplier; short profit targets are short reference price − risk unit × each configured reward multiplier. The two target multipliers and exit quantities are independently configurable.
Calculation: Long stop = swing low whenever the short exit signal is true; otherwise, if long and tracked high > long reference price + long risk unit, set it to long reference price; otherwise retain the previous stop. Short stop = swing high whenever the long exit signal is true; otherwise, if short and tracked low < short reference price − short risk unit, set it to short reference price; otherwise retain the previous stop.
Calculation: Long permission state becomes 1 when cloud direction changes to positive, otherwise 0 when tracked low crosses below the long stop, otherwise 1 while long, otherwise 0 when cloud direction is negative, otherwise retains its previous value. Short permission state becomes 1 when cloud direction changes to negative, otherwise 0 when tracked high crosses above the short stop, otherwise 1 while short, otherwise 0 when cloud direction is positive, otherwise retains its previous value. Apply these tests in the stated order.
Long: Long entries enabled AND long action changes AND previous long permission state = 0.
Short: Short entries enabled AND short action changes AND previous short permission state = 0.
Long: In unfiltered pivot mode, close > cloud high.
Short: In unfiltered pivot mode, close < cloud low.
Long: In filtered pivot mode, close > cloud high AND smoothed regression is rising.
Short: In filtered pivot mode, close < cloud low AND smoothed regression is falling.
Long: In Cloud-MA mode, cloud line exceeds every value in its direction lookback.
Short: In Cloud-MA mode, cloud line is below every value in its direction lookback.
Long: High-volume bars enabled AND close > open AND volume > multiplier × SMA(volume).
Short: High-volume bars enabled AND close < open AND volume > multiplier × SMA(volume).
Exit: long, long exit signal.
Exit: short, short exit signal.
Exit: long, take-profit/stop enabled AND low <= long stop OR take-profit/stop enabled AND high >= either long profit target; each target exits its configured quantity.
Exit: short, take-profit/stop enabled AND high >= short stop OR take-profit/stop enabled AND low <= either short profit target; each target exits its configured quantity.
