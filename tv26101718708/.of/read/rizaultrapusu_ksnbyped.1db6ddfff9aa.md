Calculation: Order-block swing = Maintain a swing state, initially high. If the high N chart bars ago is greater than the highest high of the latest N bars, set the state to high; otherwise, if the low N bars ago is less than the lowest low of the latest N bars, set it to low; otherwise retain the state. On a change to high or low, record respectively the high or low N bars ago as the latest swing of that kind and mark it uncrossed.
Calculation: Order block = For each swing high, on the first close above it, create a bullish block from the bar with the lowest selected lower price between the swing bar and the current bar, excluding both. For each swing low, on the first close below it, create a bearish block from the bar with the highest selected upper price over the same interval. Selected upper and lower prices are either candle-body maximum and minimum or high and low, consistently. The block boundaries are the selected prices of that bar; resolve equal extrema in favor of the oldest bar. If no intervening bar exists, use the previous bar. A bullish block becomes a bearish breaker when min(open, close) falls below its lower boundary; remove that breaker when close rises above its upper boundary. A bearish block becomes a bullish breaker when max(open, close) rises above its upper boundary; remove that breaker when close falls below its lower boundary. Evaluate removal starting after the bar that created the breaker.
Calculation: Breaker confirmation = A bearish breaker confirmation is true if the latest swing high is strictly inside any of the most recent retained bullish blocks that is a bearish breaker and has not been removed. A bullish breaker confirmation is true if the latest swing low is strictly inside any of the most recent retained bearish blocks that is a bullish breaker and has not been removed. The number of retained blocks considered is a parameter, separately for each side.
Long: Chart-timeframe shorter-period close SMA > chart-timeframe longer-period close SMA.
Short: Chart-timeframe shorter-period close SMA <= chart-timeframe longer-period close SMA.
Long: Either higher-timeframe shorter-period close SMA > its corresponding longer-period close SMA. Calculate each of the two SMA pairs on its own higher timeframe using the bar still forming; on historical bars, the source uses lookahead and assigns the final higher-timeframe bar value throughout that bar.
Short: Either higher-timeframe shorter-period close SMA <= its corresponding longer-period close SMA. Calculate each of the two SMA pairs on its own higher timeframe using the bar still forming; on historical bars, the source uses lookahead and assigns the final higher-timeframe bar value throughout that bar.
Long: Close > latest uncrossed swing high.
Short: Close < latest uncrossed swing low.
Long: Max(open, close) > upper boundary of a retained bearish order block that has not already become a breaker.
Short: Min(open, close) < lower boundary of a retained bullish order block that has not already become a breaker.
Long: Bullish breaker confirmation is true AND its previous-bar value is false.
Short: Bearish breaker confirmation is true AND its previous-bar value is false.
