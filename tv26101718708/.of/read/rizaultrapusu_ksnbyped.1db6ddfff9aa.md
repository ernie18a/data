Calculation: Short SMA = average close over a shorter lookback than the long SMA; calculated on the chart timeframe or on each configured non-chart timeframe, using its current bar (still forming, including when that timeframe is higher than the chart timeframe).
Calculation: Long SMA = average close over a longer lookback than the short SMA; calculated on the chart timeframe or on each configured non-chart timeframe, using its current bar (still forming, including when that timeframe is higher than the chart timeframe).
Calculation: Order-block swing levels = Maintain a state initially 0. Compare the high from the swing-lookback bars ago with the highest high of the current bar and preceding swing-lookback-minus-one bars; if greater, set state to 0, otherwise compare the low from swing-lookback bars ago with the lowest low over those bars and, if lower, set state to 1. On a state change to 0, store that earlier high as the latest swing high; on a state change to 1, store that earlier low as the latest swing low. Each stored level can be crossed only once.
Long: Short SMA > Long SMA on the chart timeframe OR Short SMA > Long SMA on either configured non-chart timeframe OR close > the latest uncrossed swing high.
Short: Short SMA <= Long SMA on the chart timeframe OR Short SMA <= Long SMA on either configured non-chart timeframe OR close < the latest uncrossed swing low.
Long: A bearish order block has been broken upward and is a breaker, and the latest swing low lies strictly inside its price range, and this confirmation was not true on the preceding bar.
Short: A bullish order block has been broken downward and is a breaker, and the latest swing high lies strictly inside its price range, and this confirmation was not true on the preceding bar.
