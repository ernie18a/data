Calculation: Regression(offset) = For each i from offset through offset + lookback - 1, weight close[i] by K(i - offset) times V(i), and divide the weighted close sum by the weight sum; if the weight sum is zero, use close[offset]. K(j) is selectable: Gaussian exp(-(j/bandwidth)^2), rational quadratic (1 + j^2/(2 * alpha * bandwidth^2))^(-alpha), or Epanechnikov max(0, 1 - (j/bandwidth)^2). V(i) is 1 if volume weighting is disabled; otherwise max((volume[i] / max(highest volume over the normalization lookback ending on the current bar, 1))^volume power, volume floor). The offset is selectable between the current bar and the preceding bar.
Calculation: Regression slope = Regression(offset) - Regression(offset + 1), with both regressions using the current bar's volume normalization maximum.
Calculation: Bands = Regression(offset) plus or minus a selectable half-width: ATR of the current bar times a multiplier; standard deviation of close over the regression lookback ending at offset times a multiplier; or Regression(offset) times a percentage.
Calculation: Signal state = Initially the last signal bar is undefined and direction is 0. A signal is eligible when no signal has occurred or the bars since the last signal are at least the minimum gap. Process the long signal first, then the short signal, using the same eligibility computed at the start of the bar. On a signal, set the last signal bar to the current bar and direction to 1 for long or -1 for short. After processing signals, reset direction to 0 if close is strictly between the bands.
Long: close < lower band
Short: close > upper band
Long: regression slope > 0
Short: regression slope <= 0
Long: signal generation enabled AND signal eligible AND direction <= 0 AND ((extension mode enabled AND close < lower band) OR (extension mode disabled AND close > lower band AND previous close <= previous lower band AND (slope filter disabled OR regression slope > 0)))
Short: signal generation enabled AND signal eligible AND direction >= 0 AND ((extension mode enabled AND close > upper band) OR (extension mode disabled AND close < upper band AND previous close >= previous upper band AND (slope filter disabled OR regression slope <= 0)))
