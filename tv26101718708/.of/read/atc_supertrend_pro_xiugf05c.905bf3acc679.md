Calculation: Volatility regime = Calculate ATR and its lower and higher rolling percentiles using linear interpolation. Start in Normal. If ATR or either percentile is unavailable, set Normal. Otherwise, from Low, switch to High if ATR > higher percentile × (1 + hysteresis fraction), else to Normal if ATR > lower percentile × (1 + hysteresis fraction), else remain Low. From High, switch to Low if ATR < lower percentile × (1 - hysteresis fraction), else to Normal if ATR < higher percentile × (1 - hysteresis fraction), else remain High. From Normal, switch to Low if ATR < lower percentile × (1 - hysteresis fraction), else to High if ATR > higher percentile × (1 + hysteresis fraction), else remain Normal.
Calculation: Adaptive SuperTrend bands and direction = Select a price source from close, (high + low)/2, (high + low + close)/3, or (open + high + low + close)/4. Multiply ATR by a base multiplier adjusted downward in the Low regime, upward in the High regime, and unchanged in the Normal regime. Basic upper and lower bands equal source plus and minus this product. Initialize each band to its basic band; subsequently, reset the upper band to its current basic band if that basic band < previous upper band OR previous close > previous upper band, otherwise retain the previous upper band. Reset the lower band to its current basic band if that basic band > previous lower band OR previous close < previous lower band, otherwise retain the previous lower band. Initialize direction as bullish and keep it bullish while previous ATR is unavailable; thereafter switch from bearish to bullish if close > current upper band, or from bullish to bearish if close < current lower band; otherwise retain the previous direction.
Long: Previous ATR is available AND previous direction = bearish AND current direction = bullish
Short: Previous ATR is available AND previous direction = bullish AND current direction = bearish
Exit: long, previous ATR is available AND previous direction = bullish AND current direction = bearish
