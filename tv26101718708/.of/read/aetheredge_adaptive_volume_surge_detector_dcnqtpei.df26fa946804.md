Calculation: Volume z-score = (volume - SMA(volume)) / standard deviation of volume over the same window; return 0 when the standard deviation is 0.
Calculation: Body ratio = abs(close - open) / (high - low); return 0 when the range is 0.
Calculation: Real-surge probability = sigmoid of the dot product of weights and features [1, clamp(volume z-score with missing values replaced by 0, -4, 4), clamp(abs(close - open) / ATR, -4, 4), clamp(2 * body ratio - 1, -1, 1), clamp((close - previous close) / ATR, -4, 4)]; division by zero returns 0. Initialize all weights to 0. On each bar, calculate probability before updating weights. If the classifier is enabled, store the features, close and candle direction of every bar with volume z-score >= surge threshold, body ratio >= body-ratio threshold and close != open. On each confirmed bar, including the stored bar, increment each pending sample's age; when age >= follow-through horizon, label it 1 if its stored direction * (current close - stored close) >= follow-through multiplier * current ATR, otherwise 0. Update weights as weights - learning rate * (sigmoid(weights dot stored features) - label) * stored features, processing pending samples newest first, then discard the sample.
Long: Volume z-score >= surge threshold AND body ratio >= body-ratio threshold AND close > open AND (classifier disabled OR real-surge probability >= probability threshold).
Short: Volume z-score >= surge threshold AND body ratio >= body-ratio threshold AND close < open AND (classifier disabled OR real-surge probability >= probability threshold).
