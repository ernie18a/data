Calculation: Bands = a selected SMA, EMA, WMA, RMA, HMA, DEMA, TEMA or VWMA of a selected price source is the middle band; deviation is either ATR or the standard deviation of that source over the middle-band lookback. The unsmoothed upper and lower bands are the middle band plus and minus their respective deviation multipliers. Compute these on the selected ordinary or synthetic candle series. For a higher timeframe use the last completed bar; for a lower timeframe use the last completed lower-timeframe bar within each chart bar; otherwise use the chart bar.
Calculation: Band width = (upper band - lower band) / middle band.
Calculation: Percent B = (selected candle-series close - lower band) / (upper band - lower band), using the same timeframe and completed-bar selection as the bands.
Calculation: Eligible comparisons = chart close crossing above, crossing below, being above or being below any one of the unsmoothed upper, middle or lower bands; band width crossing above, crossing below, being above or being below either of two independently configured thresholds; or percent B crossing above or crossing below either of two independently configured thresholds. A cross above requires the current value to be greater and the previous value to be less than or equal; a cross below requires the current value to be less and the previous value to be greater than or equal.
Calculation: Selected comparison result = for the independently selected entry or exit comparisons, all mode requires at least one selection and every selected comparison true; minimum-count mode requires the number of true selected comparisons to be at least the configured minimum; any mode uses only the result of the last selected comparison in this order: close cross above upper, cross below upper, cross above middle, cross below middle, cross above lower, cross below lower, above upper, below upper, above middle, below middle, above lower, below lower; width cross above first threshold, cross above second, cross below first, cross below second, above first, above second, below first, below second; percent B cross above first threshold, cross above second, cross below first, cross below second. With no selected comparisons the result is false.
Long: datetime is within the configured inclusive trading window AND the selected entry comparison result is true AND the selected exit comparison result is false.
Exit: long, datetime is outside the configured inclusive trading window OR the selected exit comparison result is true OR high reaches entry price plus the configured profit fraction of the chart close at the latest long signal OR low reaches entry price minus the configured loss fraction of the chart close at the latest long signal.
