Calculation: Relative Vigor Index = sum over a lookback of the 4-bar weighted average of (close − open), with weights 1,2,2,1, divided by the corresponding sum of the 4-bar weighted average of (high − low); use 0 if the denominator is 0
Calculation: Relative Vigor signal = 4-bar weighted average of the Relative Vigor Index, with weights 1,2,2,1
Calculation: Renko bands = initialize upper and lower bands at the midpoint of the last completed higher-timeframe bar’s high and low, plus or minus half its ATR. On each chart bar, let H be the prior upper band minus the prior lower band. In order, if chart close is at least prior upper + 3H, set upper/lower to prior upper + 3ATR / prior upper + 2ATR; else if at least prior upper + 2H, set them to prior upper + 2ATR / prior upper + ATR; else if at least prior upper + H, set them to prior upper + ATR / prior upper. Otherwise, if chart close is at most prior lower − 3H, set lower/upper to prior lower − 3ATR / prior lower − 2ATR; else if at most prior lower − 2H, set them to prior lower − 2ATR / prior lower − ATR; else if at most prior lower − H, set them to prior lower − ATR / prior lower. If no condition holds, retain both bands. ATR and high/low use the last completed higher-timeframe bar.
Long: chart close >= prior Renko upper band + H
Short: chart close <= prior Renko lower band − H
Exit: long, Relative Vigor Index < Relative Vigor signal AND prior Relative Vigor Index >= prior Relative Vigor signal
Exit: short, Relative Vigor Index > Relative Vigor signal AND prior Relative Vigor Index <= prior Relative Vigor signal
