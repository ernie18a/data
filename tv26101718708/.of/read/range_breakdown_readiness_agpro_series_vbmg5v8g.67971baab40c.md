Calculation: Prior range = highest high and lowest low over the range lookback, excluding the current bar; range height = high minus low; inside count = number of closes within those boundaries over the same bars. ATR uses the chart timeframe. A mature range requires sufficient history, inside count >= minimum age, and range height / ATR between the minimum and maximum permitted widths.
Calculation: Active breakdown = a sequence started when no sequence is active, the range is mature, and close < prior range low - minimum breakdown distance × ATR. Fix its support and range height at their values on the starting bar. Before checking for a new sequence on each subsequent bar, end the active sequence if close > fixed support + reclaim buffer × current ATR or its age exceeds the review window.
Calculation: Normalize-high(x, a, b) = clamp(100 × (x - a) / (b - a), 0, 100); normalize-low(x, a, b) = clamp(100 × (b - x) / (b - a), 0, 100); either returns 0 when a = b. Range maturity = 0.58 × normalize-high(current inside count, minimum age, mature age) + 0.42 × range-width score, where range-width score = normalize-high(current range height / ATR, 0.65, ideal width) when width <= ideal width, otherwise normalize-low(width, ideal width, maximum width).
Calculation: Breakdown progress = normalize-high((fixed support - close) / ATR, minimum breakdown distance, follow-through distance). Bearish close quality = 100 × (high - close) / (high - low), clamped to 0–100. Lower-wick percentage = 100 × (min(open, close) - low) / (high - low), clamped to 0–100. Volume score = normalize-high(volume / SMA(volume), 0.85, strong relative volume) when volume and its SMA are positive and available, otherwise 55. Retest touched = high between fixed support - retest tolerance × ATR and fixed support + 2 × retest tolerance × ATR, inclusive. Retest rejected = retest touched AND close < fixed support AND close < open. Retest score = 100 if rejected, 70 if touched but not rejected, otherwise 48. Target = fixed support - fixed range height × target multiple. Target-room score = normalize-high(max(close - target, 0) / ATR, 0.60, 2.65).
Calculation: Breakdown score = clamp(0.22 × range maturity + 0.24 × breakdown progress + 0.14 × bearish close quality + 0.16 × volume score + 0.12 × retest score + 0.12 × target-room score, 0, 100). Failure risk = clamp(0.28 × (100 - breakdown progress) + 0.22 × normalize-high(lower-wick percentage, 20, 68) + 0.18 × (100 - volume score) + 0.20 × normalize-low(abs(close - fixed support) / ATR, 0, follow-through distance) + 0.12 × (100 - range maturity), 0, 100).
Short: A new active breakdown starts.

Short: Active breakdown AND retest rejected AND the preceding bar did not have an active breakdown with retest rejected.
Short: Active breakdown AND (fixed support - close) / ATR >= follow-through distance AND failure risk < failure-risk threshold AND the preceding bar did not satisfy this condition.
Exit: short, active breakdown on the preceding bar AND close > fixed support + reclaim buffer × current ATR.
