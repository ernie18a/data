Calculation: Directional RSI = RSI for short decisions; 100 minus RSI for long decisions. Transform the lower extreme, cooling, re-entry, and optional abort levels in the same way for long decisions. Maintain independent short and long setup states, initially idle, and process the following steps in order on each completed chart bar.
Calculation: First extreme event = 1 when an idle setup has directional RSI >= its extreme level, or when a cooled or pivot-waiting setup has directional RSI > its stored first extreme + tolerance; otherwise 0. On the event, store the current directional RSI and bar as the first extreme and start bar, and enter the extreme state. In the extreme state, update the stored first extreme to the maximum of itself and current directional RSI; if directional RSI <= the cooling level AND < the re-entry level, enter the cooled state. Before these steps, reset any active setup to idle if directional RSI reaches the opposite extreme, or if the optional abort is enabled AND directional RSI <= the abort level, or if the optional maximum search window is enabled AND bars since the start bar >= that window. An idle setup may start again on the same bar.
Calculation: Retest event = 1 when a pivot-waiting setup has directional RSI strictly decreasing for the required number of consecutive bars AND the current bar is later than the stored pivot bar AND directional RSI <= the stored first extreme + tolerance; otherwise 0. In the cooled state, if directional RSI <= the stored first extreme + tolerance AND a valid pivot is confirmed, store the pivot and enter the pivot-waiting state; confirmation starts no earlier than the next bar. A valid pivot is directional RSI at the pivot bar >= the re-entry level AND <= the stored first extreme minus the minimum gap AND strictly greater than each of the specified number of later RSI values AND greater than or equal to each of the same number of earlier RSI values. In the pivot-waiting state, replace the stored pivot with any higher valid pivot before checking confirmation. On a retest event, reset to idle unless directional RSI >= the extreme level, in which case restart the extreme state with current directional RSI and bar as the first extreme and start bar. Apply the same aborts and first-extreme restart as above before retest confirmation.
Calculation: Confirmation line = the selected EMA, SMA, WMA, RMA, VWMA, HMA, DEMA, TEMA, ZLEMA, KAMA, Kalman filter, ALMA, or Kijun. ZLEMA is EMA of source + (source minus source lagged by max(1, floor((length minus 1) / 2))). KAMA uses the absolute source change over its length divided by the sum of absolute one-bar changes over that length, or zero if the denominator is zero; square the interpolation between shorter and longer EMA smoothing constants using that ratio, then update the previous KAMA toward the source by that factor, initializing at source. Kalman initializes estimate to source and error to 1; each bar add process noise to error, set gain to predicted error / (predicted error + measurement noise), update estimate by gain times (source minus estimate), and set error to (1 minus gain) times predicted error. Kijun is the midpoint of the highest high and lowest low over its lookback.
Calculation: Price confirmation event = 1 when a retest event has started or restarted that direction's entry search AND the current bar is within the inclusive entry search window AND the fraction of the candle body beyond the confirmation line in that direction is >= the required fraction; otherwise 0. The search includes the retest bar, expires when bars since the retest > the window, and stops at its first confirmation. Body fraction is zero for a zero-size body; otherwise it is the length of the body above the line for long or below the line for short divided by total body length. A new same-direction retest restarts the search.
Long: Long first extreme event = 1 OR long retest event = 1 OR long price confirmation event on the previous bar = 1, with entry at the current bar open for the price-confirmed event.
Short: Short first extreme event = 1 OR short retest event = 1 OR short price confirmation event on the previous bar = 1, with entry at the current bar open for the price-confirmed event.
