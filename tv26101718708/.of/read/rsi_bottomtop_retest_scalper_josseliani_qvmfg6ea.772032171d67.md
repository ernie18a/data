Calculation: RSI = relative strength index of the selected source
Calculation: Local RSI bottom = candidate RSI value is strictly below the next S newer values and less than or equal to the S older values; candidate is S bars before confirmation
Calculation: Local RSI peak = candidate RSI value is strictly above the next S newer values and greater than or equal to the S older values; candidate is S bars before confirmation
Calculation: Confirmation line = selected price line (EMA, SMA, WMA, RMA/SMMA, VWMA, HMA, DEMA, TEMA, ZLEMA, KAMA, Kalman, ALMA, or midpoint of the highest high and lowest low over its lookback)
Calculation: Body above line % = 100 × portion of the open-close body above the confirmation line ÷ body size; 0 when body size is zero
Calculation: Body below line % = 100 × portion of the open-close body below the confirmation line ÷ body size; 0 when body size is zero
Long: After RSI <= lower extreme, RSI later >= lower cooling level and > second-bottom re-entry maximum; a confirmed local RSI bottom is <= the re-entry maximum and >= the first bottom + minimum gap; RSI then rises for the required consecutive bars after that bottom, without RSI falling below the first bottom by more than the peak tolerance, an opposing extreme, or an enabled setup timeout or midline abort; within the entry search window after this retest signal, Body above line % >= required body percentage; enter at the next bar's open
Short: After RSI >= upper extreme, RSI later <= upper cooling level and < second-peak re-entry minimum; a confirmed local RSI peak is >= the re-entry minimum and <= the first peak - minimum gap; RSI then falls for the required consecutive bars after that peak, without RSI rising above the first peak by more than the peak tolerance, an opposing extreme, or an enabled setup timeout or midline abort; within the entry search window after this retest signal, Body below line % >= required body percentage; enter at the next bar's open
