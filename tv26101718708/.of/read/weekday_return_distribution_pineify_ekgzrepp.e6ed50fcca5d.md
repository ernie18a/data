Calculation: Weekday samples = for each weekday, retain up to a parameterized maximum number of the most recent completed daily-bar returns ending on that weekday; each return is 100 × ln(completed bar close / preceding bar close), included only when both closes are positive. Weekend samples are included only if enabled. Update samples at the start of each daily bar.
Calculation: Current weekday statistics = select the sample count, median, and percentage of returns strictly above zero for the weekday of the daily bar. The daily timeframe is the chart timeframe or a lower timeframe; use the current bar when it is forming, and otherwise the last completed bar mapped to the chart bar. Compute the median by sorting the samples and linearly interpolating at index (count − 1) / 2.
Long: Current weekday sample count >= minimum sample threshold AND median >= nonnegative median threshold AND positive-return percentage >= positive-rate threshold.
Short: Current weekday sample count >= minimum sample threshold AND median <= negative median threshold AND positive-return percentage <= 100 − positive-rate threshold AND NOT (median >= median threshold AND positive-return percentage >= positive-rate threshold).
