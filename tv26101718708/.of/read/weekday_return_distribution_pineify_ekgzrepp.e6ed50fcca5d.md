Calculation: Weekday statistics = For each weekday, keep up to the configured maximum number of previous completed daily close-to-close returns, optionally excluding weekends. Each return is 100 × ln(close of the completed daily bar / close of the daily bar before it), assigned to the weekday on which it ended. Compute the median by linear interpolation of the sorted returns and the positive-return rate as the percentage strictly above zero; N is the number of retained returns. Use the weekday of the latest daily bar to select the active statistics. Daily bars are equal to the chart timeframe on daily charts and lower than it on weekly charts; use only completed daily bars for return samples.
Long: Active weekday N >= configured minimum sample count AND active weekday median return >= configured minimum median magnitude AND active weekday positive-return rate >= configured positive-return threshold
Short: Active weekday N >= configured minimum sample count AND active weekday median return <= -configured minimum median magnitude AND active weekday positive-return rate <= 100% - configured positive-return threshold
