Calculation: Active CISD levels = Run the following state machine independently on each of two higher timeframes, one shorter and one longer, using only completed bars. Map each update to the chart bar on which the higher-timeframe bar completes. Initialize the upper structure boundary to max(open, close), the lower boundary to min(open, close), both pullback flags to false, both candidates and the active level to undefined, and delivery to neutral. Process each subsequent higher-timeframe bar in this order, preserving all state between bars:
1. A valid pullback requires the previous bar's absolute body size to be at least a configurable fraction of the body size two bars ago, and that older body size to be positive. If valid and the previous bar is bullish, start a bearish pullback if one is not already active, setting its anchor price to the previous open and its anchor index to the previous bar. If valid and the previous bar is bearish, analogously start a bullish pullback.
2. While a bullish pullback is active, set its anchor to the current open and index if the open is below its anchor price, or if the current bar is bearish and its open is above its anchor price. While a bearish pullback is active, set its anchor to the current open and index if the open is above its anchor price, or if the current bar is bullish and its open is below its anchor price.
3. If min(open, close) is below the lower structure boundary, set that boundary to min(open, close). If a bearish pullback is active and its anchor is not the current bar, set the upper boundary to the greater body high of the anchor bar and the bar preceding it, end that pullback, and record its anchor price as a new bullish candidate. Otherwise, if the previous bar is bullish and the current bar is bearish, set the upper boundary to the previous body's high, end the bearish pullback, and record its anchor price as a new bullish candidate if that price exists.
4. If max(open, close) is above the upper structure boundary, including any update in step 3, set that boundary to max(open, close). If a bullish pullback is active and its anchor is not the current bar, set the lower boundary to the lesser body low of the anchor bar and the bar preceding it, end that pullback, and record its anchor price as a new bearish candidate. Otherwise, if the previous bar is bearish and the current bar is bullish, set the lower boundary to the previous body's low, end the bullish pullback, and record its anchor price as a new bearish candidate if that price exists. Retain each latest candidate until replaced.
5. If delivery is neutral, initialize it to bearish with the bullish candidate active if a new bullish candidate exists; otherwise initialize it to bullish with the bearish candidate active if a new bearish candidate exists. Do not confirm a change on this initialization bar. During bearish delivery, first replace the active level with any new bullish candidate, then confirm bullish delivery if the close is above the active level; on confirmation, activate the latest bearish candidate, or clear the active level if none exists. During bullish delivery, first replace the active level with any new bearish candidate, then confirm bearish delivery if the close is below the active level; on confirmation, activate the latest bullish candidate, or clear the active level if none exists. An undefined active level cannot be confirmed.
Long: On either higher timeframe, delivery before confirmation is bearish AND the last completed bar's close is above the active bullish CISD level after any same-bar candidate update.
Short: On either higher timeframe, delivery before confirmation is bullish AND the last completed bar's close is below the active bearish CISD level after any same-bar candidate update.
