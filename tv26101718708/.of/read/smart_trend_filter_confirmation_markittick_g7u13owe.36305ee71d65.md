Calculation: Adaptive source = prior-bar (high + low) / 2, optionally smoothed by either a Kalman filter or an adaptive average. For the Kalman filter, initialize estimate to source and covariance to 1; each bar, predicted covariance = previous covariance + process noise, gain = predicted covariance / (predicted covariance + measurement noise), estimate = previous estimate + gain × (source - previous estimate), and covariance = (1 - gain) × predicted covariance. For the adaptive average, de-lagged source = source + (source - source at the rounded half-length lag), with lag at least 1; efficiency = min(abs(de-lagged source - de-lagged source one lookback ago) / sum of absolute bar-to-bar changes over that lookback, 1), or 0 when the sum is zero; smoothing factor = (efficiency × (fast EMA coefficient - slow EMA coefficient) + slow EMA coefficient)²; average = previous average + smoothing factor × (de-lagged source - previous average), initialized to the de-lagged source. Use the raw source when the selected average is unavailable.
Calculation: Trailing line = adaptive source ± band half-width, where ATR is the prior-bar ATR, normalized movement = abs(prior close - close two bars ago) / max(close two bars ago, minimum price increment), capped at its nearest-rank upper percentile over a movement lookback; half-width is the EMA of ATR × (base multiplier + ATR weight × ATR / prior close + movement weight × capped normalized movement). Initialize the line to the upper band; thereafter, if prior close > previous line, set it to max(lower band, previous line), otherwise set it to min(upper band, previous line).
Calculation: Displayed direction = initially bullish; on each bar retain the previous displayed direction if any enabled flat filter is true and the enabled breakout override is false; otherwise set it bullish if prior close > previous trailing line and bearish otherwise. Flat filters are: abs(previous line - line two bars ago) < ATR × stall threshold; abs(linear-regression slope of the previous-line series) / max(ATR, minimum price increment) < slope threshold; prior volume <= its prior-bar SMA, treating an unavailable SMA as prior volume plus 1; prior high - prior low <= the nearest-rank range percentile over a range lookback, treating an unavailable percentile as the range plus 1; abs(previous line - line two bars ago) / max(close two bars ago, minimum price increment), converted to basis points, < movement threshold; and prior-bar ADX < ADX threshold, treating unavailable ADX as zero. The breakout override is true when abs(prior close - close two bars ago) > ATR × breakout multiplier.
Long: Displayed direction = bullish.
Short: Displayed direction = bearish.
Exit: long, displayed direction = bearish AND previous displayed direction = bullish.
Exit: short, displayed direction = bullish AND previous displayed direction = bearish.
