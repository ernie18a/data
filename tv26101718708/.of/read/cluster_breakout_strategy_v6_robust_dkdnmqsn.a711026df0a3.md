Calculation: Cluster high = highest high over the cluster lookback; update the active breakout boundary to this value whenever a new cluster is detected
Calculation: Cluster low = lowest low over the cluster lookback; update the active breakout boundary to this value whenever a new cluster is detected
Calculation: Cluster range = cluster high - cluster low
Calculation: Cluster is detected = cluster range <= ATR × tightness threshold AND (contraction requirement disabled OR ATR < ATR from the contraction comparison lookback bars earlier)
Calculation: Breakout buffer = ATR × breakout buffer multiplier
Calculation: Close position in bar = (close - low) / (high - low), or 0.5 if high = low
Calculation: Active volume average = average volume over the volume lookback
Calculation: Active stop and target = for a long, initially entry price × (1 - stop percentage) and entry price × (1 + first target percentage); after the first target, entry price × (1 + breakeven stop percentage) and entry price × (1 + first target percentage × second target multiplier). For a short, reverse the signs.
Long: position is flat AND (session restriction disabled OR datetime is within the configured session) AND entries today < daily entry limit AND (no exit cooldown is active OR bars since last exit >= cooldown length) AND an active cluster boundary exists AND close > active cluster high + breakout buffer AND previous close <= previous active cluster high + previous breakout buffer AND cluster range <= ATR × tightness threshold AND (contraction requirement disabled OR ATR < ATR from the contraction comparison lookback bars earlier) AND (trend filter disabled OR (close > long-term EMA AND ADX > minimum)) AND (volume confirmation disabled OR volume <= 0 OR volume > active volume average × volume multiplier) AND (strong-close filter disabled OR close position in bar >= strong-close threshold)
Short: position is flat AND (session restriction disabled OR datetime is within the configured session) AND entries today < daily entry limit AND (no exit cooldown is active OR bars since last exit >= cooldown length) AND an active cluster boundary exists AND close < active cluster low - breakout buffer AND previous close >= previous active cluster low - previous breakout buffer AND cluster range <= ATR × tightness threshold AND (contraction requirement disabled OR ATR < ATR from the contraction comparison lookback bars earlier) AND (trend filter disabled OR (close < long-term EMA AND ADX > minimum)) AND (volume confirmation disabled OR volume <= 0 OR volume > active volume average × volume multiplier) AND (strong-close filter disabled OR close position in bar <= 1 - strong-close threshold)
Exit: long, close >= first target (close half and advance to phase two) OR low <= active stop OR high >= active target OR max-hold enabled AND bars in trade >= max-hold limit OR session-end exit enabled AND datetime is outside the session
Exit: short, close <= first target (close half and advance to phase two) OR high >= active stop OR low <= active target OR max-hold enabled AND bars in trade >= max-hold limit OR session-end exit enabled AND datetime is outside the session
