Calculation: Active bullish order block = On each completed bar, confirm a pivot high using equal numbers of bars on both sides. Replace the tracked high with each newly confirmed pivot and mark it already broken if the previous close was above it. The first bullish candle whose close crosses above an unbroken tracked high consumes that high, even if no block forms. Form a block from the high and low of the most recent bearish candle if that candle is before the break, at or after the pivot, within the origin search window, and the break candle's absolute body divided by ATR meets the minimum displacement threshold; use zero displacement when ATR is unavailable or zero. Retain only the latest block and deactivate it when a completed bar closes below its low.
Calculation: Active bearish order block = On each completed bar, confirm a pivot low using equal numbers of bars on both sides. Replace the tracked low with each newly confirmed pivot and mark it already broken if the previous close was below it. The first bearish candle whose close crosses below an unbroken tracked low consumes that low, even if no block forms. Form a block from the high and low of the most recent bullish candle if that candle is before the break, at or after the pivot, within the origin search window, and the break candle's absolute body divided by ATR meets the minimum displacement threshold; use zero displacement when ATR is unavailable or zero. Retain only the latest block and deactivate it when a completed bar closes above its high.
Long: The latest bullish order block is active on the chart timeframe OR on a monitored higher timeframe using its last completed bar.
Short: The latest bearish order block is active on the chart timeframe OR on a monitored higher timeframe using its last completed bar.
