Calculation: Smoothed RSI = EMA of RSI of the selected price source. Calculate RSI volatility as the EMA of the EMA of the absolute change in smoothed RSI, using a length of twice the RSI length minus one for both EMAs, multiplied by a factor.
Calculation: QQE line = Maintain a lower band and an upper band at smoothed RSI minus and plus RSI volatility. If both current and previous smoothed RSI are above the previous lower band, the lower band is the greater of its previous value and its new value; otherwise use its new value. If both current and previous smoothed RSI are below the previous upper band, the upper band is the lesser of its previous value and its new value; otherwise use its new value. Set trend to long when smoothed RSI crosses the previous upper-band series in either direction, otherwise set it to short when the previous lower-band series crosses smoothed RSI in either direction; otherwise retain the previous trend, initially long. The QQE line is the lower band in a long trend and the upper band in a short trend.
Calculation: Directional filter = A medium moving average is rising when its current value exceeds every value in its preceding direction lookback, and falling when it is below every value in that lookback. The alternate moving averages use the same chart-timeframe source and types as their corresponding moving averages, with lengths multiplied by an adjustable factor; they are not calculated on another timeframe. Fast, medium, and slow moving averages have respectively shorter, intermediate, and longer lengths.
Calculation: Long filter = If the alternate length multiplier equals one, the optional moving-average filter requires source > medium MA AND medium MA > slow MA AND fast MA > medium MA, and the optional directional filter requires the medium MA to be rising. If the multiplier exceeds one, the optional moving-average filter requires medium MA > alternate medium MA AND source > fast MA AND fast MA > medium MA, and the optional directional filter requires both medium MAs to be rising AND source > medium MA. An enabled filter must pass.
Calculation: Short filter = If the alternate length multiplier equals one, the optional moving-average filter requires source < medium MA AND medium MA < slow MA AND fast MA < medium MA, and the optional directional filter requires the medium MA to be falling. If the multiplier exceeds one, the optional moving-average filter requires medium MA < alternate medium MA AND source < fast MA AND fast MA < medium MA, and the optional directional filter requires both medium MAs to be falling AND source < medium MA. An enabled filter must pass.
Calculation: Long QQE cross = Smoothed RSI > QQE line AND previous smoothed RSI <= previous QQE line. Short QQE cross = smoothed RSI < QQE line AND previous smoothed RSI >= previous QQE line. Long center cross = smoothed RSI >= RSI midpoint AND previous smoothed RSI < RSI midpoint. Short center cross = smoothed RSI < RSI midpoint AND previous smoothed RSI >= RSI midpoint. Long channel exit = smoothed RSI > RSI midpoint plus threshold AND previous smoothed RSI <= RSI midpoint plus threshold. Short channel exit = smoothed RSI < RSI midpoint minus threshold AND previous smoothed RSI >= RSI midpoint minus threshold.
Calculation: Entry candidate = Select channel exit, QQE cross, or center cross for both directions. The selected event and its directional filter must hold on the previous bar. For a QQE-cross candidate, an optional threshold filter additionally requires previous smoothed RSI > RSI midpoint plus threshold OR previous smoothed RSI < RSI midpoint minus threshold. If first-signal-only mode is enabled, accept a candidate only if no earlier candidate in that direction has occurred since the most recent opposite-direction candidate; initially accept the first candidate in either direction.
Calculation: Long close event = If channel exit is selected for closing, short channel exit. If center cross is selected, short center cross. If QQE cross is selected and QQE cross is also selected for entry, short QQE cross. Otherwise, short QQE cross OR smoothed RSI < RSI midpoint OR smoothed RSI < RSI midpoint minus threshold. Short close event = If channel exit is selected for closing, long channel exit. If center cross is selected, long center cross. If QQE cross is selected and QQE cross is also selected for entry, long QQE cross. Otherwise, long QQE cross OR smoothed RSI >= RSI midpoint OR long channel exit. A close event triggers only on its first consecutive bar.
Calculation: Signal state = Initially flat. While flat, enter long state on a long entry candidate, otherwise enter short state on a short entry candidate. While in a long or short state, return to flat on the corresponding close event. Update this state on every bar regardless of the backtest date window; entry candidates do not reverse an existing state.
Long: Signal state changes from flat to long AND datetime is within the selected backtest window.
Short: Signal state changes from flat to short AND datetime is within the selected backtest window.
Long: Long channel exit AND signal state does not change from flat to long.
Short: Short channel exit AND signal state does not change from flat to short.
Long: Long QQE cross AND no long channel exit AND signal state does not change from flat to long.
Short: Short QQE cross AND no short channel exit AND signal state does not change from flat to short.
Long: Long center cross AND no long channel exit AND no long QQE cross AND signal state does not change from flat to long.
Short: Short center cross AND no short channel exit AND no short QQE cross AND signal state does not change from flat to short.
Exit: long, signal state changes from long to flat AND datetime is within the selected backtest window.
Exit: short, signal state changes from short to flat AND datetime is within the selected backtest window.
