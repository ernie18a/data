Calculation: Active liquidity zones = On each bar, confirm pivot highs and lows using equal left and right lookbacks. For each new pivot, find the closest existing zone of the same pivot type within a percentage tolerance of the new pivot price. If found, mark the zone as merged, set its price to the higher price for a high zone or the lower price for a low zone, add the pivot-bar volume to its stored volume, and retain its original pivot bar. Otherwise, append a zone with the pivot price, pivot bar, pivot-bar volume, and pivot type. Remove high zones when high > zone price, low zones when low < zone price, and any zone whose age exceeds the maximum age or whose absolute log(zone price / close) exceeds the distance limit; remove the oldest zones if the maximum zone count is exceeded.
Calculation: Zone score = max(minimum score, strength weight × strength + proximity weight × proximity + age weight × maturity + momentum weight × alignment), where strength is min(stored zone volume / current volume SMA, volume cap), or a fallback value if stored volume is unavailable or the volume SMA is nonpositive, multiplied by a bonus for a merged zone; proximity is a piecewise function of absolute log(zone price / close): a fixed value below the nearest distance threshold, max(middle-region floor, peak value − absolute distance from the preferred distance × middle-region decay) below the next threshold, and max(far-region floor, peak value − distance beyond that threshold × far-region decay) otherwise; maturity is a fresh-zone value below the minimum age, a mature-zone value below the older-age threshold, and max(old-zone floor, mature-zone value − age beyond the older-age threshold / decay period) otherwise; alignment is a base value plus the clamped product of the direction to the zone, the difference between a shorter and a longer close EMA, and a scale factor divided by close; use zero for the normalized EMA difference when close is nonpositive. Direction to the zone is positive when zone price > close and negative otherwise.
Calculation: Magnet bias = Select the active zone with the highest score, breaking ties in favor of the earliest zone in the active list. Divide the sum of scores of zones with the same pivot type as that zone by the sum of scores of all active zones; use a positive sign for a high zone and a negative sign for a low zone. Use zero when no zone exists.
Long: Magnet bias > pull threshold.
Short: Magnet bias < negative pull threshold.
Long: Magnet bias > bullish shift threshold AND previous-bar magnet bias <= bullish shift threshold.
Short: Magnet bias < negative bearish shift threshold AND previous-bar magnet bias >= negative bearish shift threshold.
