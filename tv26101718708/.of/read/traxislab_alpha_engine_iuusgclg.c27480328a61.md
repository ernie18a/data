Calculation: ATR-normalized HMA slope = (current HMA − previous HMA) / ATR × 100; bullish if above the positive slope threshold, bearish if below its negative, otherwise flat.
Calculation: Squeeze = ATR / its longer-lookback moving average < squeeze threshold; squeeze release = previous bar was in a squeeze and current bar is not.
Calculation: Trend state = start at neutral; set neutral during a squeeze; otherwise set bullish when slope is bullish and (prior state is not bearish or there is a bullish squeeze release), set bearish when slope is bearish and (prior state is not bullish or there is a bearish squeeze release), set neutral when slope is flat; otherwise retain prior state.
Calculation: VWMO = apply the Ehlers Super Smoother to a 0–100 normalization of the sum over the momentum lookback of (close − previous close) × (volume / its moving average); normalize using the lowest and highest cumulative momentum over a longer lookback, with 50 when that range is zero.
Calculation: Overbought/oversold = VWMO above/below the configured fixed level, adaptive mean ± standard deviation × multiplier, or either level when fixed and adaptive zones are combined.
Long: bullish squeeze release with bullish slope OR VWMO enters the oversold zone OR VWMO crosses above the oversold level OR (trend state is bullish or there is a bullish squeeze release) AND (VWMO crosses above an oversold level OR (VWMO > 50 AND VWMO > previous VWMO AND VWMO is not overbought)) AND close > HMA AND more than the cooldown interval has elapsed since the previous confluence signal
Short: bearish squeeze release with bearish slope OR VWMO enters the overbought zone OR VWMO crosses below the overbought level OR (trend state is bearish or there is a bearish squeeze release) AND (VWMO crosses below an overbought level OR (VWMO < 50 AND VWMO < previous VWMO AND VWMO is not oversold)) AND close < HMA AND more than the cooldown interval has elapsed since the previous confluence signal
