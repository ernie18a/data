Calculation: Liquidity levels = Confirmed pivot highs and lows from enabled higher or lower timeframes, using the last completed bar of each requested timeframe; and highs and lows of completed enabled UTC sessions. Add a level when a mapped pivot value changes from its preceding chart-bar value or follows an unavailable value, or when a session ends. Merge a new level into the first unswept level of the same high/low type within the merge tolerance, retaining the existing price and session status. Remove the oldest unswept levels when their count exceeds the limit.
Calculation: Sweep = An unswept high level is swept when high > level and, in wick-only mode, close < level. An unswept low level is swept when low < level and, in wick-only mode, close > level. Mark each swept level as swept immediately.
Calculation: Valid bullish gap = A chart bar's low > high two chart bars earlier AND the difference is between the minimum and maximum ATR multiples inclusive, using ATR on the decision bar. A valid bearish gap = A chart bar's high < low two chart bars earlier AND the difference is between the same ATR limits inclusive.
Calculation: Gap detection = For each eligible sweep, scan from the sweep bar backward through the configured lookback, stopping at the first valid gap permitted by the reversal-only setting that has not already been recorded for that gap bar and direction; require the candidate bar index to be at least three. Also open a forward search through the configured number of chart bars after the sweep, replacing any existing search for the same swept-level direction. Process forward searches newest first, including on the sweep bar; record the first permitted valid current-bar gap not already recorded for that bar and direction, then close that search. A sweep is eligible when gap detection is enabled AND, if session-only mode is enabled, the swept level retains session status. In reversal-only mode, bullish gaps require a low-level sweep and bearish gaps require a high-level sweep. Recorded gaps remain recorded until their mitigated history is pruned: a bullish gap is mitigated when a later bar's low < its upper edge, and a bearish gap when a later bar's high > its lower edge; prune the oldest mitigated gaps when their count exceeds the limit.
Long: Gap detection records a valid bullish gap.
Short: Gap detection records a valid bearish gap.
