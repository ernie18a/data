Calculation: All calculations use chart bars unless identified as primary or local. Primary calculations use a higher timeframe than the chart; local calculations use a lower timeframe than the chart and the last available completed local bar within each chart bar. On historical chart bars, higher-timeframe calculations use the last completed higher-timeframe bar, with its value carried forward. Previous primary or local values in chart-bar conditions mean their values on the previous chart bar.
Calculation: Range high = highest high over the range lookback excluding the current bar; range low = lowest low over the same bars; range midpoint = (range high + range low) / 2.
Calculation: Range efficiency = absolute change in close over the range lookback divided by the sum of absolute one-bar close changes over that lookback; use zero when the denominator is zero. Sideways = range efficiency < efficiency threshold.
Calculation: High slope and low slope = the respective linear-regression slopes of high and low over the structure lookback. OBV slope and accumulation/distribution slope = the respective linear-regression slopes over the same flow lookback.
Calculation: Trend score = round(clamp(sum of clamp(10 × (close − short EMA) / ATR, −18, 18), clamp(12 × (short EMA − long EMA) / ATR, −22, 22), clamp(15 × change in short EMA over the slope lookback / ATR, −18, 18), clamp(18 × change in long EMA over the same slope lookback / ATR, −16, 16), clamp(2 × change in close over the momentum lookback / ATR, −14, 14), and clamp(30 × (high slope + low slope) / (2 × ATR), −12, 12), −100, 100)). Use 1 when ATR is zero or unavailable; the short EMA has a shorter lookback than the long EMA.
Calculation: Relative volume = volume / SMA of volume over the volume lookback; use zero if the SMA is not positive. Up volume and down volume = SMA over that same lookback of volume on bars whose close respectively rises or falls from the preceding close, and zero otherwise.
Calculation: Low sweep = low < range low AND close > range low. High sweep = high > range high AND close < range high. A recent sweep is a corresponding sweep on the current bar or within the sweep-memory lookback.
Calculation: Bullish recovery = close > range midpoint AND close > short EMA AND low slope > 0. Bearish damage = close < range midpoint AND close < short EMA AND high slope < 0.
Calculation: Spring = recent low sweep AND sideways AND bullish recovery AND CMF > 0 AND OBV slope > 0. Upthrust = recent high sweep AND sideways AND bearish damage AND CMF < 0 AND OBV slope < 0. Strength breakout = close > range high AND relative volume >= breakout-volume threshold AND CMF > 0. Weakness breakout = close < range low AND relative volume >= breakout-volume threshold AND CMF < 0.
Calculation: Accumulation pressure = clamp(sum of 20 if sideways, 20 if CMF >= bullish CMF threshold else 10 if CMF > 0, 15 if OBV slope > 0, 10 if accumulation/distribution slope > 0, 10 if up volume > down volume, 5 if recent low sweep, 10 if spring, and 10 if bullish recovery; otherwise add zero for each condition, 0, 100).
Calculation: Distribution pressure = clamp(sum of 20 if sideways, 20 if CMF <= bearish CMF threshold else 10 if CMF < 0, 15 if OBV slope < 0, 10 if accumulation/distribution slope < 0, 10 if down volume > up volume, 5 if recent high sweep, 10 if upthrust, and 10 if bearish damage; otherwise add zero for each condition, 0, 100).
Calculation: Accumulation dominance = accumulation pressure >= phase-pressure threshold AND accumulation pressure >= distribution pressure + pressure margin. Distribution dominance = distribution pressure >= phase-pressure threshold AND distribution pressure >= accumulation pressure + pressure margin.
Calculation: Raw phase = when sideways and accumulation dominance holds: re-accumulation if trend score >= re-accumulation threshold, else re-distribution if trend score <= re-distribution threshold AND bullish recovery is false, else accumulation; otherwise when sideways and distribution dominance holds: re-accumulation if trend score >= trend-context threshold AND bearish damage is false AND weakness breakout is false, else re-distribution if trend score <= re-distribution threshold, else distribution; otherwise when sideways: re-accumulation if trend score >= trend-context threshold, else re-distribution if trend score <= negative trend-context threshold, else neutral; otherwise: markup if trend score >= strong-trend threshold, else markdown if trend score <= negative strong-trend threshold, else neutral. The re-accumulation threshold is nonnegative and the re-distribution threshold is nonpositive.
Calculation: Phase = raw phase if it is unchanged for the phase-confirmation lookback including the current bar; otherwise neutral.
Calculation: Primary bullish context = primary trend score >= bullish-bias threshold OR primary phase = markup OR primary phase = re-accumulation. Primary bearish context = primary trend score <= negative bullish-bias threshold OR primary phase = markdown OR primary phase = re-distribution. Local bullish context = local trend score >= bullish-bias threshold OR local phase = markup OR local phase = re-accumulation. Local bearish context = local trend score <= negative bullish-bias threshold OR local phase = distribution OR local phase = markdown OR local phase = re-distribution.
Long: Low sweep = true OR spring = true OR strength breakout = true.
Short: High sweep = true OR upthrust = true OR weakness breakout = true.
Long: Phase = accumulation OR phase = re-accumulation OR phase = markup OR trend score >= bullish-bias threshold OR CMF > 0.
Short: Phase = distribution OR phase = re-distribution OR phase = markdown OR trend score <= negative bullish-bias threshold OR CMF < 0.
Long: Primary bullish context = true OR (primary bearish context = false AND local bullish context = true).
Short: Primary bullish context = false AND (primary bearish context = true OR local bearish context = true).
Short: (primary trend score < bullish-bias threshold OR primary distribution pressure >= high-pressure threshold OR primary phase = distribution OR primary phase = markdown OR primary phase = re-distribution) AND local phase = distribution AND local distribution pressure >= strong-distribution threshold AND local weakness breakout = true AND the complete condition was false on the preceding chart bar.
