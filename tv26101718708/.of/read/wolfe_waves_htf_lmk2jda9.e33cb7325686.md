Calculation: Confirmed pivots = pivot highs and pivot lows on each configured higher timeframe, using the last completed higher-timeframe bar and the same number of bars on each side for confirmation; retain the most recent eight confirmed pivots of each kind, including their prices and bar opening times.
Calculation: Selected bullish pattern = search retained pivot-low triples as P5, P3, P1, each from newest to oldest with P1 before P3 before P5; for each triple choose P2 as the highest retained pivot high strictly between P1 and P3 and P4 as the highest retained pivot high strictly between P3 and P5, breaking equal-price ties in favor of the most recent pivot. Select the first triple for which both exist, P3 < P1, P3 < P4 < P2, P5 is below the straight line through P1 and P3 evaluated at P5's time, and abs((P3 time - P1 time) / (P5 time - P3 time) - 1) <= the symmetry tolerance.
Calculation: Selected bearish pattern = search retained pivot-high triples as P5, P3, P1, each from newest to oldest with P1 before P3 before P5; for each triple choose P2 as the lowest retained pivot low strictly between P1 and P3 and P4 as the lowest retained pivot low strictly between P3 and P5, breaking equal-price ties in favor of the most recent pivot. Select the first triple for which both exist, P3 > P1, P3 > P4 > P2, P5 is above the straight line through P1 and P3 evaluated at P5's time, and abs((P3 time - P1 time) / (P5 time - P3 time) - 1) <= the symmetry tolerance.
Calculation: Target = the selected pattern's straight line through P2 and P4 evaluated at the current chart bar's opening time, using pivot opening times as the horizontal coordinates.
Long: A selected bullish pattern exists on any configured higher timeframe.
Short: A selected bearish pattern exists on any configured higher timeframe.
Exit: long, a selected bullish pattern exists AND (chart close < its P5 price OR chart close >= its target).
Exit: short, a selected bearish pattern exists AND (chart close > its P5 price OR chart close <= its target).
