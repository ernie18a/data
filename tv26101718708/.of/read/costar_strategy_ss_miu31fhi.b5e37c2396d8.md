Calculation: Expected value = rolling ordinary least-squares prediction of the chart instrument’s close from the paired instrument’s close, using selected higher-timeframe closes from the still-forming bar; select the shortest candidate lookback whose residual passes a Dickey–Fuller stationarity test.
Calculation: Upper and lower bands = expected value plus or minus the regression residual standard error, respectively.
Long: close crosses above the lower band
Short: close crosses below the upper band
Exit: long, close crosses above the expected value
Exit: short, close crosses below the expected value
