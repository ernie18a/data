Calculation: Timeframe vote = +1 when the selected price source is greater than or equal to its EMA on that timeframe, otherwise -1. Vote age is the number of that timeframe's bars since the vote last changed, or 0 if no change has been observed. All timeframe EMAs use the same length. For a higher timeframe, use either the still-forming bar or the last completed bar; for a lower timeframe, sample its last available bar within each chart bar. In the delayed mode, use the prior chart bar's sampled result; otherwise use the current chart bar's result.
Calculation: Group score = 100 times the sum of each included timeframe's vote multiplied by its weight, divided by the sum of weights. Base weights are equal, increase by timeframe rank, or equal timeframe duration. For the short-term group, multiply each base weight by 1 + boost × max(0, 1 − vote age / freshness window). For the long-term group, multiply each base weight by min(1 + vote age / persistence divisor, persistence cap). Short-term timeframes are shorter than long-term timeframes; the shortest short-term timeframe is optional. Overall score = long-term weight × long-term score + (1 − long-term weight) × short-term score.
Calculation: Band zone = +1 when chart close is above both selected timeframe EMAs, -1 when chart close is below both, otherwise 0. Both EMAs use the common EMA length and the same timeframe sampling and delay rules as the votes; optionally smooth each sampled EMA with an EMA calculated on chart bars. The displayed zone initially equals the raw zone and changes to a new raw zone only after that zone persists for the confirmation number of consecutive chart bars.
Long: Selected price source on any included timeframe >= its EMA on that timeframe.
Short: Selected price source on any included timeframe < its EMA on that timeframe.
Long: Short-term group score >= positive threshold OR long-term group score >= positive threshold OR overall score >= positive threshold.
Short: Short-term group score <= negative threshold OR long-term group score <= negative threshold OR overall score <= negative threshold.
Long: Displayed band zone = +1.
Short: Displayed band zone = -1.
