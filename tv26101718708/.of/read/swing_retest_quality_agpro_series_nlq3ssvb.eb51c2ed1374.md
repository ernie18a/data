Calculation: Active swing = the latest confirmed pivot high and pivot low, each confirmed using the same number of bars on both sides; direction d is +1 if the high occurred later and -1 if the low occurred later. The earlier pivot is the origin O and the later pivot is the terminal T. Height H = abs(T - O), duration B = terminal bar index - origin bar index. The swing is active when H > ATR times a minimum-height parameter, B > 0, and terminal age <= a maximum-age parameter.
Calculation: Pocket = for an active swing, the interval between T - d * H * shallow depth and T - d * H * deep depth, where shallow depth < ideal depth < deep depth. Its midpoint is M and its height is P. A pocket touch occurs when low <= its upper boundary AND high >= its lower boundary. A recent touch means a pocket touch occurred within a response-window number of bars, including the current bar; historical touches use the swing and pocket active on each historical bar.
Calculation: Defense = O - d * ATR * defense-buffer parameter. Target = T + d * H * target-extension parameter. Target room = max(d * (Target - close), 0) / ATR.
Calculation: Peak score(x, low, ideal, high) = clamp((x - low) / (ideal - low), 0, 1) when x <= ideal; otherwise clamp((high - x) / (high - ideal), 0, 1).
Calculation: Swing clarity = a weighted sum of peak scores for H / ATR and B, each with its own low, ideal, and high parameters; the duration-score parameters depend on the pivot length and maximum swing age.
Calculation: Retest depth score = peak score of clamp(d * (T - probe) / H, 0, maximum depth), where probe is low for d = +1 and high for d = -1; its low, ideal, and high parameters are derived from the shallow, ideal, and deep pocket depths.
Calculation: Rejection score = clamp(a * directional wick / candle range + b * directional close location, 0, 1), where directional wick is min(open, close) - low for d = +1 and high - max(open, close) for d = -1; directional close location is (close - low) / candle range for d = +1 and (high - close) / candle range for d = -1.
Calculation: Close response score = clamp(c * d * (close - M) / P + e * directional close location, 0, 1).
Calculation: Volume score = clamp((volume / SMA(volume) - weak relative-volume parameter) / (strong relative-volume parameter - weak relative-volume parameter), 0, 1); use neutral relative volume when the volume average is unavailable or nonpositive, and use a fixed neutral score when volume support is disabled.
Calculation: Quality score = clamp(weighted sum of swing clarity, retest depth score, rejection score, close response score, and volume score, minus a sensitivity adjustment, 0, 1).
Long: Active swing direction = +1 AND recent touch = true AND close >= defense AND close >= pocket midpoint AND target room >= minimum target-room parameter AND quality score >= valid threshold.
Short: Active swing direction = -1 AND recent touch = true AND close <= defense AND close <= pocket midpoint AND target room >= minimum target-room parameter AND quality score >= valid threshold.
