Calculation: Best signal = maintain a fixed-size population of five-weight genomes and indexed fitness values. Initialize each weight at flat index i to 2 * Pseudorandom(seed * 2654435761 + (i + 1) * 40503) - 1, fitness to zero, and pending signals to unavailable. A genome signal is tanh of the sum of its weights multiplied by the corresponding genes, with the sum clipped to [-20, 20] before tanh. Starting after the warm-up bar index, on each completed bar update each available indexed pending signal's fitness to decay * fitness + (1 - decay) * pending signal * clip((close - close[fitness lookback]) / nonzero ATR / 2, -1, 1); then replace each pending signal with that index's current genome signal. Thus the pending signal used is from the preceding eligible bar, even when the fitness lookback is longer. On each eligible bar whose zero-based bar index is divisible by the evolution interval, increment generation count, copy the highest-fitness genomes into the first slots in descending fitness order, breaking ties by lowest index, and fill the remaining slots in ascending index order as follows: set r = (bar index * 104729 + slot * 7919 + seed + generation count * 31) remainder 2147483647; for each parent use tournament seed t = r for the first parent and t = r * 13 + 101 for the second, choose indices floor(Pseudorandom(t) * population size) and floor(Pseudorandom(t * 7919 + 13) * population size), and select the higher-fitness index, breaking ties in favor of the first. For gene index g from zero, set q = r * 3 + 5 + g * 131, inherit the first parent's weight if Pseudorandom(q) < 0.5, otherwise the second parent's; if Pseudorandom(q * 31 + 7) < mutation probability, add (Pseudorandom(q * 17 + 3) - 0.5) * 2 * mutation scale; clip the result to [-1.5, 1.5]. Replace the population with these offspring, halve fitness in place without reordering it, and leave pending signals in place. After this update and any evolution, select the lowest-index genome with maximum fitness and calculate its current signal.
