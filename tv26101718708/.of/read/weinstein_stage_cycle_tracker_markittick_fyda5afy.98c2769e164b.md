Calculation: Source = a selected price series, optionally smoothed with an SMA, EMA, WMA, HMA, or RMA.
Calculation: Stage average = SMA of Source.
Calculation: Slope = 100 × (Stage average − Stage average at the slope lookback) / Stage average at the slope lookback; undefined when the earlier average is zero or unavailable.
Calculation: Distance = 100 × (Source − Stage average) / Stage average; undefined when the average is zero or unavailable.
Calculation: Upside breakout = Source > highest high of the preceding range-lookback bars AND Source > Stage average AND Slope ≥ negative slope threshold.
Calculation: Downside breakdown = Source < lowest low of the preceding range-lookback bars AND Source < Stage average AND Slope ≤ slope threshold.
Calculation: Stage = a sequential state, initially undefined. When Slope is undefined, Stage is undefined. From an undefined Stage, assign Stage 2 when Slope > slope threshold AND Source > Stage average, or Stage 4 when Slope < negative slope threshold AND Source ≤ Stage average; otherwise leave it undefined. From Stage 1 or Stage 3, assign Stage 4 on a downside breakdown, otherwise Stage 2 on an upside breakout, otherwise retain the stage. From Stage 2, assign Stage 4 on a downside breakdown; otherwise assign Stage 3 when Slope ≤ slope threshold and Slope has exceeded the threshold at least once since the current stage began, including the current bar; otherwise assign Stage 1 when Slope ≤ slope threshold AND Source ≤ Stage average; otherwise retain Stage 2. From Stage 4, assign Stage 2 on an upside breakout; otherwise assign Stage 1 when Slope ≥ negative slope threshold and Slope has been below the negative threshold at least once since the current stage began, including the current bar; otherwise assign Stage 3 when Slope ≥ negative slope threshold AND Source ≥ Stage average; otherwise retain Stage 4. Reset the stage start bar whenever a defined stage is first assigned or changes.
Long: Stage = 2 OR Slope > slope threshold OR Distance > 0 OR (higher-timeframe confirmation enabled AND Slope > slope threshold AND Source > Stage average on the last completed higher-timeframe bar, using the same calculation parameters as the chart timeframe).
Short: Stage = 4 OR Slope < negative slope threshold OR Distance < 0 OR (higher-timeframe confirmation enabled AND Slope < negative slope threshold AND Source ≤ Stage average on the last completed higher-timeframe bar, using the same calculation parameters as the chart timeframe).
