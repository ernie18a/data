Calculation: Volume consensus count for a tier = count of the short, medium, and long lookback windows in which current volume is greater than or equal to the tier's linearly interpolated volume percentile; each window includes the current bar. The medium lookback is longer than the short lookback and shorter than the long lookback; the medium-tier percentile is higher than the small-tier percentile and lower than the big-tier percentile.
Long: ((high + low) / 2 <= min(open, close) AND (high + low) / 2 >= low AND (direction filter disabled OR close < open) AND (small-tier consensus count >= required consensus count OR medium-tier consensus count >= required consensus count OR big-tier consensus count >= required consensus count)) OR ((high + low) / 2 > min(open, close) AND (high + low) / 2 < max(open, close) AND close > open AND (medium-tier consensus count >= required consensus count OR big-tier consensus count >= required consensus count))
Short: ((high + low) / 2 >= max(open, close) AND (high + low) / 2 <= high AND (direction filter disabled OR close > open) AND (small-tier consensus count >= required consensus count OR medium-tier consensus count >= required consensus count OR big-tier consensus count >= required consensus count)) OR ((high + low) / 2 > min(open, close) AND (high + low) / 2 < max(open, close) AND close < open AND (medium-tier consensus count >= required consensus count OR big-tier consensus count >= required consensus count))
