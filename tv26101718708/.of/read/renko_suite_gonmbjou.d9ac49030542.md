Calculation: Synthetic Renko state = For each independently configured brick size, initialize bottom = floor(first close / brick size) × brick size, top = bottom + brick size, and direction = up if first close >= first open, otherwise down. On each bar, including the first, if direction is up, first check low <= bottom − brick size; if true, set top = bottom, subtract brick size from bottom, and set direction to down. Then, while direction is down and low <= bottom − brick size, set top = bottom and subtract brick size from bottom. Otherwise, while direction remains up and high >= top + brick size, set bottom = top and add brick size to top. If direction was down at the start of the bar, first check high >= top + brick size; if true, set bottom = top, add brick size to top, and set direction to up. Then, while direction is up and high >= top + brick size, set bottom = top and add brick size to top. Otherwise, while direction remains down and low <= bottom − brick size, set top = bottom and subtract brick size from bottom. A brick trigger occurs when at least one step is made in its direction; a flip occurs when direction changes. Use the selected standard or macro brick size for trigger decisions; the macro size is larger than the standard size.
Calculation: Anchored VWAP = sum(OHLC4 × volume) / sum(volume) over chart bars in the current equal-length New York time block, with blocks starting at midnight and including the current bar; OHLC4 = (open + high + low + close) / 4. It is unavailable when cumulative volume is zero.
Long: Standard synthetic Renko direction = up OR macro synthetic Renko direction = up
Short: Standard synthetic Renko direction = down OR macro synthetic Renko direction = down
Long: Selected synthetic Renko has an upward brick trigger AND (the color-change-only filter is disabled OR direction flipped on the current bar)
Short: Selected synthetic Renko has a downward brick trigger AND (the color-change-only filter is disabled OR direction flipped on the current bar)
Long: Close >= anchored VWAP
Short: Close < anchored VWAP
