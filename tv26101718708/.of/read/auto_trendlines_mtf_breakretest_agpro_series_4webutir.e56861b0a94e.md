Calculation: Chart trendlines = Separately for resistance pivot highs and support pivot lows, confirm symmetric pivots after the required right-hand bars. Build two chart-timeframe sets using shorter and longer pivot sensitivities. Pair each of the most recent anchor candidates with older pivots separated by more than the minimum gap and within the lookback; interpolate their log prices by bar index, or prices directly if linear geometry is selected. Reject slopes outside the allowed nonzero range. Count the anchors and other pivot wicks within a percentage tolerance as touches; count intervening pivot bodies beyond the tolerance on the breakout side as violations, and mark a candidate broken if a newer pivot body exceeds that tolerance. Optionally use pivot wicks instead of bodies. Rank candidates by touches raised to a power times log of anchor separation, divided by a violation penalty and reduced for broken candidates, excessive slope and distance from close in ATR units. Discard candidates too close in slope and price, or in ATR price separation, to an already accepted candidate. Keep the highest-ranked candidates up to the configured slot count. In locked mode retain existing slots until replacement of broken lines is enabled and their break condition is met; fill empty slots with the highest-ranked nonduplicate candidates. In dynamic mode reselect on each scan. The longer-sensitivity set uses its own gap, tolerance, slope and slot parameters.
Calculation: Higher-timeframe trendline = Confirm symmetric pivot highs and lows on the last completed higher-timeframe bar, keeping separate resistance and support pivot histories; use longer-sensitivity chart-timeframe pivots as fallback when higher-timeframe pivots are unavailable. Pair recent anchors with older pivots separated by more than the minimum higher-timeframe duration, and interpolate their log prices by timestamp, or prices directly if linear geometry is selected. Reject slopes outside the allowed nonzero range. Count touches and violations as for chart trendlines, using the larger of a percentage tolerance and a higher-timeframe ATR-based tolerance; also mark the candidate broken when the current close exceeds that tolerance on the breakout side. Rank by a power of touches times log of anchor duration, with bonuses for longer lines and extreme recent anchors and a penalty for broken lines. Select the highest-ranked candidate within the violation limit; if none qualifies, select the highest score after a violation penalty; if no candidate qualifies, connect the oldest and newest pivots if sufficiently separated. Retain the selected line in locked mode until replacement of broken lines is enabled and its break condition is met; otherwise reselect. Higher-timeframe ATR uses the last completed higher-timeframe bar.
Calculation: Chart-line quality = Round and clamp to the permitted score range the sum of a capped touch-count score, an exponentially decaying score for the age of the newer anchor, a score decreasing with absolute slope relative to its limit, and an exponentially decaying score for distance from close in ATR units, minus a capped violation-count penalty. In locked mode retain the quality calculated when the line was selected.
Calculation: Break source = Close, midpoint of high and low, or the high for resistance and low for support, according to the selected break mode.
Calculation: Break event = For each selected line slot and side, the break comparison is true on this bar and was false on the preceding bar for that slot. For chart lines the slot's current quality must also meet the minimum. Record the broken line and bar when this event occurs, before applying the event cooldown.
Calculation: Retest event = The first bar within the relevant scale's retest window, including the break bar, on which the recorded broken line satisfies the retest comparison. For chart lines the current quality of the corresponding slot must meet the minimum. Mark the retest done before applying the event cooldown. Use the recorded line's original anchors and slope even if the selected line changes.
Calculation: Event cooldown = For each scale, side and event type separately, accept an event only when the number of bars since the preceding accepted event of that type exceeds the cooldown. The chart-line events consider only the configured highest-ranked slots; the higher-timeframe events consider the primary line.
Calculation: Retest outcome = After an accepted short-sensitivity resistance retest, store the current primary resistance line value and set the outcome to testing; set it to failed if close is below that stored value or low is below it by more than an ATR multiple. Otherwise, on the next bar set it to held if neither bar's low went below that value, or overlap if either low went below it. For a support retest use the mirrored comparisons with close and high. A new accepted break on that side clears its outcome. A new accepted retest resets it to testing.
Calculation: Planner score = Take the maximum of the primary resistance and support quality scores from both chart-line sets and the short-sensitivity resistance and support quality scores adjusted by the respective retest outcome; scale and offset that maximum, then round and clamp it to the permitted score range. The planner direction is resistance if the latest live retest outcome is resistance, or if neither side has a live outcome and primary resistance quality is at least primary support quality; otherwise it is support.
Long: For a selected resistance line, break source > line value × (1 + that scale's break tolerance) AND break event = true AND event cooldown passes.
Short: For a selected support line, break source < line value × (1 - that scale's break tolerance) AND break event = true AND event cooldown passes.
Long: For a recorded resistance break, low <= recorded line value × (1 + retest tolerance) AND close > recorded line value AND retest event = true AND event cooldown passes.
Short: For a recorded support break, high >= recorded line value × (1 - retest tolerance) AND close < recorded line value AND retest event = true AND event cooldown passes.
Long: Planner direction = resistance AND at least one retest outcome = held AND neither retest outcome = failed AND planner score >= minimum AND the preceding planner action was not ready.
Short: Planner direction = support AND at least one retest outcome = held AND neither retest outcome = failed AND planner score >= minimum AND the preceding planner action was not ready.
Exit: long, at least one retest outcome = failed AND planner direction = resistance AND the preceding planner action was not invalidated.
Exit: short, at least one retest outcome = failed AND planner direction = support AND the preceding planner action was not invalidated.
