Calculation: Use chart-timeframe bars throughout. The source is (high + low + close) / 3. Treat each named weight, multiplier, threshold, and lookback as an independently adjustable parameter unless the same name is reused. Clamp(x, a, b) limits x to [a, b]; safe division returns the stated fallback when the denominator is zero or either operand is unavailable. Z-score is (value - SMA(value)) / standard deviation(value), with fallback 0. Compress(x) = 100 * tanh(clamp(x / compression scale, -tanh limit, tanh limit)). Sign(x) is 1, 0, or -1 according to its sign.
Calculation: Structure = 1 when short EMA(source) > medium EMA(source) > long EMA(source) AND close > trend EMA(close); -1 when short EMA(source) < medium EMA(source) < long EMA(source) AND close < trend EMA(close); otherwise 0. The trend EMA lookback is longer than the long EMA lookback.
Calculation: Trend pressure = EMA(weighted sum of (close - trend EMA(close)) / ATR and (trend EMA(close) - its previous value) / ATR). Each division has fallback 0. Trend strength = clamp(abs(trend pressure) / trend strength scale, 0, 1).
Calculation: Efficiency = abs(source - source at the efficiency lookback) / sum(abs(change in source), efficiency lookback), with fallback 0. ATR ratio = ATR / long EMA(ATR), with fallback 1. Volume z-score = z-score(volume) when volume > 0 and available, otherwise 0. ADX score, efficiency score, and volatility score each equal clamp((their respective value - lower threshold) / (upper threshold - lower threshold), 0, 1). Volume score = clamp((volume z-score + volume offset) / volume scale, 0, 1) when volume > 0 and available, otherwise 1. Quality = clamp(weighted sum of ADX, efficiency, volatility, and volume scores, 0, 1). Chop load = weighted sum of one minus each of those four scores. Minimum quality = clamp(quality baseline + chop weight * chop load - trend weight * trend strength, minimum bound, maximum bound). Quality passes when quality >= minimum quality.
Calculation: Fast impulse = (short EMA(source) - medium EMA(source)) / ATR; slow impulse = (medium EMA(source) - long EMA(source)) / ATR; range impulse = (close - medium EMA(source)) / ATR; each has fallback 0. Price impulse = z-score(rate of change of source over the short EMA lookback). Momentum = fast impulse + slow impulse. Volatility impulse = (ATR ratio - 1) * sign(momentum). Volume impulse = clamp(volume z-score / volume impulse scale, -1, 1) * sign(momentum) when volume > 0 and available, otherwise 0. Alignment = neutral alignment factor if either trend pressure or momentum is zero, aligned factor if their signs agree, otherwise opposed factor. Engine = weighted sum of fast impulse, slow impulse, price impulse, range impulse, trend pressure, structure, volatility impulse, and volume impulse, multiplied by alignment and by (quality floor + (1 - quality floor) * quality). Oscillator = compress(EMA(engine)).
Calculation: Signal baseline = EMA(oscillator). Velocity = EMA(change in oscillator); acceleration = EMA(change in velocity), using the same lookback as velocity. Signal = clamp(EMA(signal baseline + velocity weight * velocity + acceleration weight * acceleration), -100, 100), using a shorter smoothing lookback than velocity.
Calculation: Trend bias = 0 if trend pressure is zero, trend strength if trend pressure and momentum have the same sign, otherwise -trend strength * opposed-bias factor. Raw histogram = weighted sum of (oscillator - signal baseline), velocity, acceleration, compress(engine * engine scale), and trend bias, clamped to [-100, 100]. Histogram = EMA(raw histogram) * (histogram floor + quality * histogram quality weight), using the shortest histogram lookback when quality > upper quality threshold, the medium lookback when quality > lower quality threshold, otherwise the longest lookback. Histogram slope = histogram - previous histogram, using the current histogram if the previous value is unavailable.
Calculation: Bull momentum passes when (histogram > positive momentum threshold AND histogram slope > 0) OR (histogram > 0 AND histogram slope >= 0) OR (histogram > negative momentum threshold AND histogram slope > 0 AND velocity > 0). Bear momentum passes when (histogram < negative momentum threshold AND histogram slope < 0) OR (histogram < 0 AND histogram slope <= 0) OR (histogram < positive momentum threshold AND histogram slope < 0 AND velocity < 0). The positive and negative momentum thresholds have equal magnitude.
Calculation: Bull regime score = quality weight * quality plus separate weights when structure = 1, trend pressure > 0, momentum > 0, and oscillator > 0. Bear regime score uses the same weights with structure = -1 and the other three values < 0. Bull candidate = quality passes AND bull score >= regime activation threshold AND bull score > bear score + regime edge. Bear candidate is the symmetric comparison. Regime starts neutral; on each bar set it to bullish if bull candidate, else bearish if bear candidate; otherwise reset a bullish regime to neutral if close < long EMA(source) OR trend pressure < negative invalidation threshold OR short EMA(source) < medium EMA(source) < long EMA(source) OR bull score < regime deactivation threshold. Reset a bearish regime to neutral if close > long EMA(source) OR trend pressure > positive invalidation threshold OR short EMA(source) > medium EMA(source) > long EMA(source) OR bear score < regime deactivation threshold. Otherwise retain the prior regime. The deactivation threshold is lower than the activation threshold; the invalidation thresholds have equal magnitude.
Calculation: Bull reload = bullish regime AND quality passes AND oscillator > negative reload threshold AND oscillator < signal baseline AND histogram > negative histogram reload threshold AND histogram slope > 0 AND velocity > previous velocity. Bear reload = bearish regime AND quality passes AND oscillator < positive reload threshold AND oscillator > signal baseline AND histogram < positive histogram reload threshold AND histogram slope < 0 AND velocity < previous velocity. Opposite thresholds have equal magnitudes. Reload strength = clamp((reload threshold - abs(oscillator)) / reload threshold, 0, 1) * quality for bull reload, its negative for bear reload, otherwise 0. Reload line = EMA(reload strength * reload scale).
Calculation: Band basis = EMA(oscillator). Band deviation = maximum of a weighted sum of standard deviation(oscillator) and EMA(abs(oscillator - band basis)) times a deviation adjustment, and a minimum deviation; all use the same band lookback. Inner and outer bands = clamp(band basis plus or minus band deviation times the respective multiplier, -100, 100), with the outer multiplier greater than the inner multiplier.
Calculation: Bull continuation = bullish regime AND quality passes AND oscillator > 0 AND oscillator > signal baseline AND signal > negative signal threshold AND bull momentum passes. Bear continuation = bearish regime AND quality passes AND oscillator < 0 AND oscillator < signal baseline AND signal < positive signal threshold AND bear momentum passes. Signal thresholds have equal magnitude. Bull expansion = bull continuation AND oscillator > upper inner band AND velocity > 0 AND histogram > positive momentum threshold AND histogram slope > 0. Bear expansion = bear continuation AND oscillator < lower inner band AND velocity < 0 AND histogram < negative momentum threshold AND histogram slope < 0.
Calculation: Exhaustion = (bullish regime AND ((oscillator > positive exhaustion threshold AND velocity < 0 AND histogram slope < 0) OR (oscillator > upper outer band AND velocity < previous velocity AND histogram slope < 0))) OR (bearish regime AND ((oscillator < negative exhaustion threshold AND velocity > 0 AND histogram slope > 0) OR (oscillator < lower outer band AND velocity > previous velocity AND histogram slope > 0))) OR (neutral regime AND oscillator > positive neutral exhaustion threshold AND velocity < 0 AND histogram slope < 0) OR (neutral regime AND oscillator < negative neutral exhaustion threshold AND velocity > 0 AND histogram slope > 0). Each positive and negative threshold pair has equal magnitude.
Calculation: Flow = EMA(clamp(weighted sum of oscillator, histogram, velocity, acceleration, and trend pressure, -100, 100)), using the shortest flow lookback when quality > upper quality threshold, the medium lookback when quality > lower quality threshold, otherwise the longest lookback. Flow slope = flow - previous flow, using current flow if the previous value is unavailable. Extreme pressure = bull expansion OR bear expansion OR exhaustion OR (flow >= positive reversal threshold AND (flow slope < 0 OR velocity < 0 OR histogram slope < 0 OR acceleration < 0 OR exhaustion)) OR (flow <= negative reversal threshold AND (flow slope > 0 OR velocity > 0 OR histogram slope > 0 OR acceleration > 0 OR exhaustion)); reversal thresholds have equal magnitude.

Short: Regime = bearish.

Short: Reload line < 0.
Long: Quality passes AND extreme pressure is false AND flow > 0.
Short: Quality passes AND extreme pressure is false AND flow < 0.

Short: Bear continuation is true AND was false on the previous bar.

Short: Bear reload is true AND was false on the previous bar.

Short: Bear expansion is true AND was false on the previous bar.
