Calculation: VWAP = cumulative sum of selected price source times volume divided by cumulative volume, resetting at the start of each calendar day.
Calculation: Long setup state = initially idle. On each bar, apply only the transition for the state at the start of that bar: if idle, change to awaiting retest when close crosses above VWAP AND the optional session filter passes AND the optional VWAP slope filter passes; if awaiting retest, reset to idle when close < VWAP OR bars since the reclaim > the reclaim-to-retest limit, otherwise change to armed and record the current high when low <= VWAP + proximity allowance AND close > VWAP; if armed, reset to idle when close < VWAP OR bars since the retest > the retest-to-trigger limit OR high > the recorded high. The optional slope filter passes when VWAP >= VWAP at the slope lookback.
Calculation: Short setup state = initially idle. On each bar, apply only the transition for the state at the start of that bar: if idle, change to awaiting retest when close crosses below VWAP AND the optional session filter passes AND the optional VWAP slope filter passes; if awaiting retest, reset to idle when close > VWAP OR bars since the reclaim > the reclaim-to-retest limit, otherwise change to armed and record the current low when high >= VWAP - proximity allowance AND close < VWAP; if armed, reset to idle when close > VWAP OR bars since the retest > the retest-to-trigger limit OR low < the recorded low. The optional slope filter passes when VWAP <= VWAP at the slope lookback.
Long: State at the start of the bar = armed AND close >= VWAP AND bars since retest <= the retest-to-trigger limit AND high > the recorded retest high.
Short: State at the start of the bar = armed AND close <= VWAP AND bars since retest <= the retest-to-trigger limit AND low < the recorded retest low.
