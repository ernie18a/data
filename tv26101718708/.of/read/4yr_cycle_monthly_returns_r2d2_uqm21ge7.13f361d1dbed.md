Calculation: Monthly return = (monthly close − monthly open) / monthly open × 100, using the monthly bar still forming for the current year and month and completed monthly bars for prior years (monthly timeframe)
Calculation: Cycle forecast = average monthly return for the current calendar month across prior years with the same year modulo 4 as the current year
Long: Cycle forecast ≥ 0 AND at least one prior year has a valid return for the current calendar month
Short: Cycle forecast < 0 AND at least one prior year has a valid return for the current calendar month
