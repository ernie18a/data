Calculation: Range high H and range low L = highest high and lowest low over the preceding range-lookback bars; midpoint M = (H + L) / 2; width W = (H - L) / ATR; range position P = clamp((close - L) / (H - L), 0, 1).
Calculation: Normalize-high(x, weak, strong) = clamp((x - weak) / (strong - weak), 0, 1); normalize-low(x, good, bad) = clamp((bad - x) / (bad - good), 0, 1); either function returns 0 when its denominator is 0.
Calculation: Range quality Q = normalize-high(W, minimum width, ideal width) when W <= ideal width, otherwise normalize-low(W, ideal width, maximum width). A mature range has H > L, more than the range-lookback bars available, W <= maximum width, and Q >= minimum quality.
Calculation: For each edge, the edge is H for the upper edge and L for the lower edge. Edge distance D = absolute distance from the bar high to H for the upper edge or from the bar low to L for the lower edge, divided by ATR. Wick share K = upper wick / candle range for the upper edge or lower wick / candle range for the lower edge. Close-back distance B = (H - close) / ATR for the upper edge or (close - L) / ATR for the lower edge. Midline room R = max(close - M, 0) / ATR for the upper edge or max(M - close, 0) / ATR for the lower edge.
Calculation: Edge score E = normalize-low(D, 0, edge-distance limit) if the corresponding edge is touched, otherwise 0. Wick score V = normalize-high(K, weak wick share, strong wick share). Close-back score C = normalize-high(B, weak close-back distance, strong close-back distance). Room score T = normalize-high(R, weak room, strong room). Volume score U = normalize-high(volume / SMA(volume), weak relative volume, strong relative volume), or a neutral score if the volume average is unavailable or nonpositive. Edge score S = round(clamp(weighted sum of E, V, C, U, T and Q, 0, 1) × score scale); use the same weights and normalization parameters for both edges.
Calculation: An upper candidate requires a mature range, an enabled upper edge, high >= H - edge-zone ATR multiple × ATR, B >= minimum close-back distance, close < H, K >= minimum candidate wick share, and R >= minimum candidate room. A lower candidate requires a mature range, an enabled lower edge, low <= L + edge-zone ATR multiple × ATR, B >= minimum close-back distance, close > L, K >= minimum candidate wick share, and R >= minimum candidate room. Select the eligible candidate with the higher edge score, resolving ties in favor of the upper candidate.
Calculation: An event is eligible when the number of bars since the latest ready, watch, midline-hit, failure, or enabled review event is at least the event cooldown, or no such event has occurred. A ready event occurs for the selected candidate when its score >= ready threshold and the event is eligible; it stores its side, current midpoint, current edge plus an invalidation ATR multiple for an upper candidate or minus it for a lower candidate, score, and start bar. A new ready event replaces the previous plan. A watch event occurs when the selected candidate's score >= watch threshold and < ready threshold and the event is eligible. The watch threshold is lower than the ready threshold.
Calculation: A plan is active from its ready bar through its review-window age, until its first failure or midline hit. Failure occurs when close > the stored invalidation for an upper plan or close < it for a lower plan. A midline hit occurs when low <= the stored midpoint for an upper plan or high >= it for a lower plan; failure takes precedence if both occur. An enabled review event occurs for an active plan after its start bar when neither failure nor midline hit occurs, the stored score >= watch threshold, and the event is eligible.
Calculation: A context event occurs when the range is mature, a candidate or active plan exists or P is above the upper context threshold or below the lower context threshold, and at least the context-spacing number of bars has elapsed since the preceding context event, or no such event has occurred. The lower context threshold is below the upper context threshold.
Long: The selected candidate is lower AND a ready event or watch event occurs; OR an enabled review event occurs for a lower plan; OR a context event occurs AND P < 0.5 AND no ready, watch, midline-hit, failure, or review event occurs on the bar.
Short: The selected candidate is upper AND a ready event or watch event occurs; OR an enabled review event occurs for an upper plan; OR a context event occurs AND P >= 0.5 AND no ready, watch, midline-hit, failure, or review event occurs on the bar.
Exit: long, an active lower plan has a failure or midline hit.
Exit: short, an active upper plan has a failure or midline hit.
