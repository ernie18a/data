Calculation: Candle range = high − low
Calculation: Lower wick % = (min(open, close) − low) / candle range × 100; upper wick % = (high − max(open, close)) / candle range × 100; body % = |close − open| / candle range × 100; close location % = (close − low) / candle range × 100
Calculation: Directional bar counts = counts over the exhaustion lookback of consecutive closes rising and falling, respectively
Calculation: Exhaustion move = |close − close N bars ago| / ATR
Calculation: Bullish score = clamp(exhaustion move / selected move threshold × 25, 0, 25) + clamp(falling-bar count / lookback × 10, 0, 10) + clamp(lower wick % / selected wick threshold × 20, 0, 20) + clamp(close location % / close threshold × 15, 0, 15) + clamp(body % / minimum body threshold × 10, 0, 10) + 10 if volume filter passes + 10 if RSI filter passes
Calculation: Bearish score = clamp(exhaustion move / selected move threshold × 25, 0, 25) + clamp(rising-bar count / lookback × 10, 0, 10) + clamp(upper wick % / selected wick threshold × 20, 0, 20) + clamp((100 − close location %) / close threshold × 15, 0, 15) + clamp(body % / minimum body threshold × 10, 0, 10) + 10 if volume filter passes + 10 if RSI filter passes
Calculation: Risk distance = selected risk mode's distance from entry to stop (signal-candle extreme plus buffer, ATR-based distance, or the larger of those); target distance = risk distance × selected reward-to-risk ratio
Long: On a completed bar, close is below close N bars ago AND exhaustion move ≥ selected move threshold AND falling-bar count ≥ minimum AND lower wick % ≥ selected wick threshold AND close location % ≥ close threshold AND close > open AND body % ≥ minimum AND (volume filter disabled OR volume ≥ its moving average × minimum multiplier) AND (RSI filter disabled OR RSI > RSI N bars ago AND RSI ≤ bullish RSI maximum) AND bullish score ≥ selected minimum score AND bullish score ≥ bearish score AND cooldown passed AND (single-active-trade disabled OR no active trade)
Short: On a completed bar, close is above close N bars ago AND exhaustion move ≥ selected move threshold AND rising-bar count ≥ minimum AND upper wick % ≥ selected wick threshold AND close location % ≤ 100 − close threshold AND close < open AND body % ≥ minimum AND (volume filter disabled OR volume ≥ its moving average × minimum multiplier) AND (RSI filter disabled OR RSI < RSI N bars ago AND RSI ≥ bearish RSI minimum) AND bearish score ≥ selected minimum score AND bearish score > bullish score AND cooldown passed AND (single-active-trade disabled OR no active trade)
Exit: Long, an active trade has high ≥ entry + target distance OR low ≤ entry − risk distance
Exit: Short, an active trade has low ≤ entry − target distance OR high ≥ entry + risk distance
