Calculation: Confirmed double-top setup = Confirm a pivot high after the specified number of right-side bars, with its high greater than or equal to the highs in the specified left and right windows. Store the first confirmed pivot. For each later confirmed pivot, if its relative difference from the stored pivot is within the match tolerance, set or retain the setup only if the new pivot is within the EMA-distance tolerance of either the chart-timeframe long EMA or the higher-timeframe long EMA evaluated at confirmation; use the last completed higher-timeframe bar. Set the neckline to the lowest low from the new pivot back through the stored pivot, limited to a maximum lookback. A matching pivot that fails the EMA test leaves the existing setup and neckline unchanged. A nonmatching pivot replaces the stored pivot and clears the setup. A short entry clears the setup and stored pivot.
Calculation: Initial stop and target = At the signal close, set the short stop above close and target below close using either independent fixed price distances or ATR multiplied by separate stop and target multipliers; alternatively set the target distance to the stop distance multiplied by a risk-reward parameter. Retain these prices for the trade. The partial target is entry signal close minus a configured fraction of the distance from signal close to target.
Calculation: Active stop = Start at the initial stop. Measure favorable movement as actual entry price minus the current low and target distance as the absolute difference between target and actual entry price. When favorable movement reaches the configured break-even fraction of target distance, move the stop to actual entry price if break-even is enabled and trailing has not already started. When favorable movement reaches the configured trailing fraction, activate trailing if enabled; thereafter set the stop on each bar to the smaller of its previous value and the chart-timeframe short EMA. Apply stage changes before testing the current bar's stop.
Calculation: Loss streak = Count consecutive closed trade portions with negative profit, excluding exits whose price is within a configured fraction of entry price. Reset to zero on a profitable exit or an exit within that entry-price tolerance; a zero-profit exit outside the tolerance leaves the count unchanged.
Short: Confirmed double-top setup exists AND close < neckline AND position is flat AND datetime is within the configured backtest range AND bar time is within the configured Paris-time trading session AND exchange-time clock is outside the configured session gap AND, if weekend exclusion is enabled, exchange-time weekday is not a weekend AND, if daily cap is enabled, entries since the exchange-time weekday changed < daily cap AND, if cooldown is enabled, bars since the last entry >= cooldown, with the initial last-entry bar index set to zero AND, if trend filter is enabled, close < chart-timeframe long EMA AND, if candle-size filter is enabled, (high - low) / close <= candle-size threshold AND, if neckline-distance filter is enabled, abs(close - neckline) / close <= neckline-distance threshold AND, if direction filter is enabled, close < open AND, if ADX filter is enabled, ADX >= threshold AND, if wick filter is enabled, high > low AND max(high - max(open, close), min(open, close) - low) / (high - low) <= wick threshold AND, if loss-streak filter is enabled, loss streak < limit AND initial stop distance / close <= maximum stop-distance fraction.
Exit: short, partial exits enabled AND low <= partial target, for the configured position fraction.
Exit: short, low <= target, for the remaining position.
Exit: short, high >= active stop, for the remaining position.
Exit: short, low <= signal close multiplied by one minus the configured sky-cap fraction.
Exit: short, session-end closing enabled AND bar time is outside the configured Paris-time trading session.
