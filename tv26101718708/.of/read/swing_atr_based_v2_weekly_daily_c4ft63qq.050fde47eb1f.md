Calculation: Higher-timeframe inputs = higher-than-chart-timeframe OHLC and ATR, requested with lookahead off: on historical chart bars, the completed higher-timeframe bar is available at its final constituent chart bar and its values are carried forward until the next completed bar. Process a higher-timeframe swing update only when the carried close differs from its value on the preceding chart bar, or when there is no preceding value.
Calculation: Swing confirmations and levels = maintain independent state for the chart timeframe and the higher timeframe, using each timeframe's OHLC, ATR, candle-size multiplier, and range multiplier. Initialize direction upward, extremum to the first available high, candidate count to zero, candidate high and low as unset, and swing maximum and minimum closes as unset. On each swing update, first include the current close in the swing maximum and minimum. In an upward swing, if high exceeds the extremum, set extremum to high and candidate count to zero; then increment the count if close < open AND absolute close-minus-open >= ATR times the candle-size multiplier. In a downward swing, if low is below the extremum, set extremum to low and candidate count to zero; then increment the count if close > open AND absolute close-minus-open >= ATR times the candle-size multiplier. Whenever count > zero, extend candidate high and low with the current high and low, including candles that did not increment the count. If count >= two AND candidate high minus candidate low >= ATR times the range multiplier, confirm a reversal: an upward-to-downward reversal creates a resistance at the swing maximum close; a downward-to-upward reversal creates a support at the swing minimum close. Switch direction, set extremum to the current low for a downward swing or current high for an upward swing, reset count to zero, and reset both swing close extrema to the current close. Clear candidate high and low on higher-timeframe confirmation only; on the chart timeframe retain them even after confirmation or a new extremum. Store each new level as active.
Calculation: Structural score = separately for each timeframe, initialize the score to a configurable bullish, neutral, or bearish state and pending score as unset. On every chart bar, after adding any confirmed levels, remove all active supports whose timeframe close is below the level and all active resistances whose timeframe close is above the level, counting each type removed. Apply any pending score and clear it. If supports were removed, set pending score bearish when no supports remain OR at least two supports were removed OR the current score is not bullish; otherwise set it neutral. If resistances were removed, subsequently set pending score bullish when no resistances remain OR at least two resistances were removed OR the current score is not bearish; otherwise set it neutral. Thus resistance breaks take precedence if both types break on the same bar, and the pending score takes effect on the next chart bar.
Long: Chart-timeframe upward swing confirmation = true
Short: Chart-timeframe downward swing confirmation = true
Long: Chart-timeframe structural score = bullish OR higher-timeframe structural score = bullish
Short: Chart-timeframe structural score = bearish OR higher-timeframe structural score = bearish
