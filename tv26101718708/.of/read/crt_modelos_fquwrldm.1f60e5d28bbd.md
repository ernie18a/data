Calculation: Reference bars = retain a bounded pool of completed model-timeframe bars added at the start of a new model-timeframe bar when the current chart bar passes the optional session and gap filters; remove the oldest when the pool limit is exceeded. Each reference remains eligible until it produces a confirmed model.
Calculation: Model timeframe = the chart timeframe or an optional higher timeframe. Confirmed models compare the last completed model-timeframe bar, called V2, with every eligible reference bar, which need not be adjacent to V2. Evaluate at the first chart bar of a new model-timeframe bar, only when that chart bar passes the optional session and gap filters.
Calculation: Gap filter = absolute difference between the current chart bar open and the previous chart bar close is less than a configured multiple of chart-timeframe ATR; pass if the filter is disabled or ATR is unavailable or nonpositive. Session filter = current chart bar opening time, adjusted by the configured time-zone offset, is within the configured session; pass if disabled.
Calculation: Upward sweep = V2 high minus reference high is greater than or equal to the manipulation threshold. Downward sweep = reference low minus V2 low is greater than or equal to the manipulation threshold. The manipulation and close-beyond thresholds are separately configured multiples of model-timeframe ATR, or zero when the ATR filter is disabled or ATR is unavailable. For a higher timeframe, ATR uses the last completed higher-timeframe bar on historical chart bars and the still-forming higher-timeframe bar in realtime.
Calculation: Live sweep direction = for each eligible reference, record the first chart-bar high above its high or low below its low while the session filter passes; if both occur on the same chart bar, record the high sweep first. Retain that direction until the reference is consumed or a confirmed-model evaluation produces no model for it, when it is reset.
Long: Session filter passes AND first live sweep direction is below the reference low.
Short: Session filter passes AND first live sweep direction is above the reference high.
Long: Confirmed-model evaluation passes AND downward sweep AND NOT upward sweep AND V2 close >= reference low.
Short: Confirmed-model evaluation passes AND upward sweep AND NOT downward sweep AND V2 close <= reference high.
Long: Confirmed-model evaluation passes AND upward sweep AND NOT downward sweep AND V2 close > reference high AND V2 close - reference high >= close-beyond threshold.
Short: Confirmed-model evaluation passes AND downward sweep AND NOT upward sweep AND V2 close < reference low AND reference low - V2 close >= close-beyond threshold.
Long: Confirmed-model evaluation passes AND upward sweep AND downward sweep AND V2 close > V2 open AND V2 close > reference high AND V2 close - reference high >= close-beyond threshold.
Short: Confirmed-model evaluation passes AND upward sweep AND downward sweep AND V2 close < V2 open AND V2 close < reference low AND reference low - V2 close >= close-beyond threshold.
Long: Confirmed-model evaluation passes AND upward sweep AND downward sweep AND V2 close >= reference low AND V2 close <= reference high AND V2 close > V2 open.
Short: Confirmed-model evaluation passes AND upward sweep AND downward sweep AND V2 close >= reference low AND V2 close <= reference high AND V2 close <= V2 open.
Calculation: Confirmed-model exit levels = for a reversal, target 1 is the V2 high for long or V2 low for short, target 2 is the reference high for long or reference low for short, and stop is the V2 low for long or V2 high for short. For a single-sweep continuation, the target is the V2 high for long or V2 low for short, and stop is the V2 low for long or V2 high for short. For a double-sweep continuation, the target is the V2 high for long or V2 low for short, and stop is the reference low for long or reference high for short. A reversal is any confirmed model closing within the reference range, or a single-sweep model closing back across the swept boundary; the other confirmed models are continuations.
Calculation: Exit state = evaluate each confirmed model starting on its creation chart bar. Before target 1 is reached, if target 1 and stop are both touched, target 1 wins only when it is strictly closer to the chart bar open; otherwise stop wins. If that simultaneous case does not apply, stop takes priority over target 2, which takes priority over target 1. For a reversal, target 1 alone advances the model to its second-target state; a direct target 2 touch closes it. In the second-target state, if target 2 and stop are both touched, target 2 wins only when strictly closer to the chart bar open; otherwise stop wins. A model closes at its first winning stop or final target. Live-sweep markings have no defined exit levels.
Exit: long, confirmed-model stop wins OR final target wins.
Exit: short, confirmed-model stop wins OR final target wins.
