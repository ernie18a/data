Calculation: Bar notation = O, H, L, C and V are open, high, low, close and volume; subscript 1 or 2 denotes that many completed chart bars ago. Evaluate on each completed chart bar. Each named threshold, multiplier, weight and lookback is a parameter; identically named parameters have the same value wherever used.
Calculation: Candle anatomy = range R = max(H − L, positive price floor); body B = abs(C − O); body fraction F = B / R; upper wick U = H − max(O, C); lower wick D = min(O, C) − L; close position P = (C − L) / R. A bullish body has C > O; a bearish body has C < O. The same definitions apply to previous bars.
Calculation: Regression field = linear regression of close at the current bar over a regression lookback, with slope equal to its change from the previous bar; deviation is the standard deviation over that lookback of the series close minus its contemporaneous regression value. Lower location means C <= regression − inner multiplier × deviation OR L <= regression − outer multiplier × deviation; upper location means C >= regression + inner multiplier × deviation OR H >= regression + outer multiplier × deviation. The outer multiplier exceeds the inner multiplier.
Calculation: Trend direction = bullish when shorter-lookback EMA of close > longer-lookback EMA of close AND regression slope >= 0; bearish when shorter EMA < longer EMA AND regression slope <= 0; otherwise neutral.
Calculation: Structure levels = most recently confirmed pivot high and pivot low, using separately parameterized left and right bar counts; update each level on the bar that confirms its pivot, before evaluating that bar. A bullish structure break is C > current pivot high AND C1 <= the same current pivot high; a bearish structure break is C < current pivot low AND C1 >= the same current pivot low. A comparison with an unavailable level is false.
Calculation: Bullish wick match = D >= B × wick multiplier AND P >= bullish wick-position threshold; bearish wick match = U >= B × wick multiplier AND P <= bearish wick-position threshold.
Calculation: Bullish location match = lower location OR trend direction is bullish AND C > shorter EMA; bearish location match = upper location OR trend direction is bearish AND C < shorter EMA. Bullish structure match = C > current pivot high; bearish structure match = C < current pivot low. Bullish momentum match = RSI > momentum midpoint AND RSI > previous RSI; bearish momentum match = RSI < momentum midpoint AND RSI < previous RSI. Volume match = V / SMA(V) >= volume threshold, using a volume ratio of 1 when the volume average is not positive. Strong body match = F >= strong-body threshold.
Calculation: Pattern candidates = the following conditions, with each named fraction, multiplier and tolerance independently parameterized unless the name is repeated. Bullish engulfing: bullish body AND previous bearish body AND O <= C1 AND C >= O1 AND B >= B1 × engulfing body multiplier. Bearish engulfing: bearish body AND previous bullish body AND O >= C1 AND C <= O1 AND B >= B1 × engulfing body multiplier. Hammer: bullish body AND D >= B × hammer wick multiplier AND U <= R × hammer opposite-wick fraction AND P >= hammer close-position threshold. Inverted hammer: bullish body AND U >= B × inverted wick multiplier AND P >= inverted close-position threshold AND lower location. Shooting star: bearish body AND U >= B × hammer wick multiplier AND D <= R × hammer opposite-wick fraction AND P <= shooting-star close-position threshold. Hanging man: bearish body AND D >= B × inverted wick multiplier AND upper location AND P <= hanging-man close-position threshold.
Calculation: More pattern candidates = Morning star: bearish body two bars ago AND F1 <= star middle-body threshold AND bullish body AND C > (O2 + C2) / 2. Evening star: bullish body two bars ago AND F1 <= star middle-body threshold AND bearish body AND C < (O2 + C2) / 2. Piercing: previous bearish body AND bullish body AND O < C1 AND C > (O1 + C1) / 2 AND C < O1. Dark cloud: previous bullish body AND bearish body AND O > C1 AND C < (O1 + C1) / 2 AND C > O1. Bullish harami: previous bearish body AND bullish body AND H <= H1 AND L >= L1 AND C > O1. Bearish harami: previous bullish body AND bearish body AND H <= H1 AND L >= L1 AND C < O1.
Calculation: More pattern candidates = Bullish inside break: H1 < H2 AND L1 > L2 AND C > H1. Bearish inside break: H1 < H2 AND L1 > L2 AND C < L1. Bullish marubozu: bullish body AND F >= marubozu body threshold AND P >= bullish marubozu position threshold AND D <= R × marubozu opposite-wick fraction. Bearish marubozu: bearish body AND F >= marubozu body threshold AND P <= bearish marubozu position threshold AND U <= R × marubozu opposite-wick fraction. Three soldiers: bullish bodies on current and two preceding bars AND C > C1 AND C1 > C2 AND F >= sequence body threshold. Three crows: bearish bodies on current and two preceding bars AND C < C1 AND C1 < C2 AND F >= sequence body threshold.
Calculation: More pattern candidates = Bullish tweezer: abs(L − L1) <= ATR × tweezer tolerance AND previous bearish body AND bullish body AND P >= bullish tweezer position threshold. Bearish tweezer: abs(H − H1) <= ATR × tweezer tolerance AND previous bullish body AND bearish body AND P <= bearish tweezer position threshold. Bullish rail: previous bearish body AND bullish body AND F >= rail body threshold AND abs(B − B1) <= ATR × rail tolerance AND C > H1. Bearish rail: previous bullish body AND bearish body AND F >= rail body threshold AND abs(B − B1) <= ATR × rail tolerance AND C < L1. Bullish reclaim: L < current pivot low AND C > current pivot low AND bullish wick match. Bearish rejection: H > current pivot high AND C < current pivot high AND bearish wick match.
Calculation: Candidate score = base score plus a trend adjustment for matching, neutral or opposing trend; plus location weight when location matches; plus structure weight when structure matches; plus momentum reward when momentum matches or momentum penalty otherwise; plus volume weight when volume matches; plus wick weight when wick matches; plus min(max(abs(regression slope) / ATR × slope multiplier, 0), slope cap), using zero slope contribution when ATR is not positive. For bullish and bearish inside breaks, marubozu, soldiers or crows, and rails, location match means respectively C > shorter EMA or C < shorter EMA and wick match means strong body match. For hammer, inverted hammer, shooting star and hanging man, wick match is always true. For reclaim and rejection, location, structure and wick matches are always true. All other candidates use their direction's location, structure and wick matches. Base scores have the following descending order, with bullish and bearish counterparts sharing a base: reclaim/rejection, morning/evening star, soldiers/crows, engulfing, rail, piercing/dark cloud, inside break, hammer/shooting star, marubozu, tweezer, inverted hammer/hanging man, harami.
Calculation: Best candidate = highest positive score among true candidates, with ties resolved by first occurrence in this order: bullish engulfing, bearish engulfing, hammer, inverted hammer, shooting star, hanging man, morning star, evening star, piercing, dark cloud, bullish harami, bearish harami, bullish inside break, bearish inside break, bullish marubozu, bearish marubozu, soldiers, crows, bullish tweezer, bearish tweezer, bullish rail, bearish rail, bullish reclaim, bearish rejection. If no candidate has a positive score, there is no best candidate.
Calculation: Accepted candidate = best candidate score >= minimum score AND either no earlier candidate has been accepted OR bars elapsed since the most recent accepted candidate of either direction > cooldown length. Update the most recent accepted bar after this test.
