Calculation: Directional swing state = Independently for each direction and each of three higher timeframes, use the last completed higher-timeframe bar. For long, use higher-timeframe high, low and close as H, L and C; for short, use negative low, negative high and negative close as H, L and C. A pivot high or low is confirmed after the same configurable number of bars on each side. Initialize phase to 0 and the previous target as undefined. Process one phase per bar in this order: phase 0: on a confirmed pivot low, set P1 to it and phase to 1. Phase 1: replace P1 with any lower confirmed pivot low, then set P2 to any confirmed pivot high above P1 and phase to 2. Phase 2: replace P2 with any higher confirmed pivot high, then on a confirmed pivot low above P1 set P3 to it and phase to 3; otherwise, on a confirmed pivot low at or below P1, set P1 to it, clear P2 and P3, and set phase to 1. Phase 3: set target to P3 + P2 - P1. If H is at or above target, save target as previous target, clear P1, P2 and P3, and set phase to 0. Otherwise, remember if C falls below P1; once remembered, on a confirmed pivot low save target as previous target, set P1 to that pivot low, clear P2 and P3, clear the remembered break, and set phase to 1. The midpoint is (P1 + P2) / 2 when phase is at least 2; the target exists only in phase 3. For comparisons between directions, reverse the sign of short-direction levels back to original prices.
Long: Long-direction phase >= 1
Short: Short-direction phase >= 1
Long: Long-direction previous target > 0 AND absolute difference between long-direction P1 and previous target divided by previous target < twice the intersection tolerance
Short: Short-direction previous target > 0 AND absolute difference between short-direction P1 and previous target divided by previous target < twice the intersection tolerance
Long: Short-direction midpoint > 0 AND absolute difference between long-direction target and short-direction midpoint divided by short-direction midpoint < intersection tolerance
Short: Long-direction midpoint > 0 AND absolute difference between short-direction target and long-direction midpoint divided by long-direction midpoint < intersection tolerance AND the long intersection condition is false
