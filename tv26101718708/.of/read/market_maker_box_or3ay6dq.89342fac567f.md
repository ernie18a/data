Calculation: Box = high, low, open and close of either the last completed or the forming higher-timeframe bar, selected consistently; range = high - low; body = (close - open) / range; close location = (close - low) / range. The box is valid when its range is positive.
Calculation: Normalization range = ATR of the forming higher-timeframe box bar if positive and available, otherwise the positive box range, otherwise a positive fallback. All EMA, RSI, ATR and volume-average calculations below use the box timeframe; forming-bar values update with each chart bar. Clip(x, limit) constrains x to the symmetric interval from -limit to +limit.
Calculation: Trend component = clip((shorter-period EMA - longer-period EMA) / normalization range × trend weight, trend limit). Slope component = clip((current shorter-period EMA - its value a configurable number of chart bars earlier) / normalization range × slope weight, slope limit).
Calculation: Structural bias = clip(trend component + slope component + stretch component + RSI component + body component + volume component, bias limit). Stretch component is zero unless the absolute distance of the forming close from the longer-period EMA, divided by normalization range, exceeds a threshold; then it is the clipped negative of that normalized distance times a weight. RSI component is a negative constant above an upper RSI threshold, a positive constant below a lower RSI threshold, and otherwise a clipped weighted deviation from the RSI midpoint. Body component is the clipped weighted box body. Volume component is the clipped weighted box body when box volume divided by the forming-bar volume moving average exceeds an upper threshold, its clipped negative with a separate weight when the ratio is below a lower threshold, and zero otherwise; use a neutral ratio when the average is unavailable or nonpositive.
Calculation: Trend score = trend component + slope component + completed-body component + completed-body sequence component + longer-timeframe body component + location component. The completed-body component is the clipped weighted body of the last completed bar of a higher-than-chart timeframe, divided by normalization range; its sequence component is the clipped weighted last body divided by normalization range when the last two completed bodies have the same sign, otherwise zero. The longer-timeframe body component is the clipped weighted body of the last completed bar of another higher-than-chart timeframe, divided by normalization range. Missing completed bodies contribute zero. The location component is the clipped weighted difference between box close and the forming longer-period EMA, divided by normalization range.
Calculation: Prediction score = trend score + clipped weighted box body + clipped weighted deviation of box close location from the range midpoint + sweep component + live component × live weight, followed by the trend lock and clipping to a symmetric score limit. Sweep component is negative when box high exceeds the preceding box-timeframe bar's high AND box close is below that high AND box close location is below the midpoint; it is positive when box low is below the preceding bar's low AND box close is above that low AND box close location is above the midpoint; otherwise it is zero. The positive condition takes precedence if both hold. Live component is the clipped weighted difference between forming box-timeframe close and open divided by the greater of its current high-low range and a fraction of normalization range. Elapsed fraction is the chart bar's opening time within the current box-timeframe window divided by the window duration, clipped between its start and end. Trend direction is positive or negative when trend score reaches the corresponding signed trend threshold, otherwise zero. Live weight is elapsed fraction times a weight when trend direction is zero or live component agrees with it; otherwise it is the positive part of elapsed fraction minus a delay, times a separate weight. A reversal is permitted when sweep component is nonzero AND elapsed fraction reaches a threshold AND trend direction is zero or opposes the sweep AND live component agrees with the sweep. Unless reversal is permitted, a strong positive or negative trend floors or caps the score at the corresponding signed prediction threshold; a weaker nonzero trend replaces an oppositely signed score with zero.
Long: Box range > 0 AND structural bias > positive bias threshold.
Short: Box range > 0 AND structural bias < negative bias threshold.
Long: Box range > 0 AND prediction score >= positive prediction threshold.
Short: Box range > 0 AND prediction score <= negative prediction threshold.
Long: Box range > 0 AND chart-bar low <= box low AND previous chart-bar low > current box low.
Short: Box range > 0 AND chart-bar high >= box high AND previous chart-bar high < current box high.
Long: Box range > 0 AND a new box-timeframe window begins AND box close > previous chart-bar box high.
Short: Box range > 0 AND a new box-timeframe window begins AND box close < previous chart-bar box low.
