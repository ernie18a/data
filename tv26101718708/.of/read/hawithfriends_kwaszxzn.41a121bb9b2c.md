Calculation: HA = Heiken Ashi candle: haClose=(open+high+low+close)/4; haOpen=(previous haOpen+previous haClose)/2, first bar (open+close)/2; haHigh=max(high,haOpen,haClose); haLow=min(low,haOpen,haClose); HA bullish: haClose>=haOpen; HA bearish: haClose<haOpen
Calculation: HA ratios = body=|haClose-haOpen|; range=haHigh-haLow; body ratio=body/range*100 (0 if range=0); lower wick ratio=(min(haOpen,haClose)-haLow)/range*100; upper wick ratio=(haHigh-max(haOpen,haClose))/range*100
Calculation: RenkoDir = ATR-brick Renko direction: brickSize=ATR; ref starts at 0; hi/lo = bar's upper/lower reference price (close, or max/min of open and close, or high/low); if hi>ref+brickSize then ref=hi, else if lo<ref-brickSize then ref=lo, else ref unchanged; direction=up if ref rose this bar, down if ref fell, otherwise previous direction
Calculation: WaveDir = LazyBear wave direction: mov=sign(close-previous close); trend=mov if mov!=0 and mov!=previous bar's mov, else previous trend; trending = close strictly rising or strictly falling over the last N consecutive bars; wave=trend if trend!=previous wave AND trending, else previous wave; wave up when wave=+1
Long: HA bullish AND body ratio >= min body ratio threshold AND lower wick ratio <= max wick ratio threshold AND body >= min body size (price units), and this is the first bar satisfying all of this since the current HA bullish run began (the run begins at a bullish bar whose previous bar is bearish, and that start bar itself may qualify); at most one signal per run
Long: (HA bullish AND RenkoDir up AND WaveDir up AND MACD histogram >= 0) is true on this bar AND was not true on the previous bar (MACD with fast length shorter than slow length)
Short: HA bearish AND body ratio >= min body ratio threshold AND upper wick ratio <= max wick ratio threshold AND body >= min body size (price units), and this is the first bar satisfying all of this since the current HA bearish run began (the run begins at a bearish bar whose previous bar is bullish, and that start bar itself may qualify); at most one signal per run
Short: (HA bearish AND RenkoDir down AND WaveDir not up AND MACD histogram < 0) is true on this bar AND was not true on the previous bar (MACD with fast length shorter than slow length)
