Calculation: Range midpoint = (highest high + lowest low) / 2 over its lookback; use short, longer, and longest lookbacks for fast midpoint, slow midpoint, and cloud base respectively.
Calculation: Efficiency ratio = absolute change in the selected price source over its lookback / sum of absolute one-bar changes in that source over the same lookback; use zero when the denominator is zero.
Calculation: Cloud A = (fast midpoint + slow midpoint) / 2; cloud B = longest-lookback range midpoint; cloud top and bottom are their maximum and minimum. Use the undisplaced cloud for decisions.
Calculation: Spine = efficiency ratio × fast midpoint + (1 − efficiency ratio) × slow midpoint when adaptation is enabled, otherwise slow midpoint; spine slope = spine minus its value a slope lookback ago.
Calculation: Safe ATR = ATR when positive, otherwise close × a fallback factor. Channel width = safe ATR × width multiplier × volatility factor. The volatility factor is ATR / its longer-lookback SMA, clamped to lower and upper bounds, when volatility adaptation is enabled and the SMA is positive; otherwise it is 1. Upper and lower rails = spine + width and spine − width. Range position = (close − lower rail) / (upper rail − lower rail), clamped to [0, 1], or the midpoint of that interval if the rails coincide.
Calculation: Trend state = strong up if close > cloud top AND cloud A > cloud B AND spine slope > 0 AND efficiency ratio > a threshold AND ADX > a threshold; otherwise up if close > cloud top AND (cloud A > cloud B OR spine slope > 0); otherwise strong down if close < cloud bottom AND cloud A <= cloud B AND spine slope < 0 AND efficiency ratio > the threshold AND ADX > the threshold; otherwise down if close < cloud bottom AND (cloud A <= cloud B OR spine slope < 0); otherwise neutral.
Calculation: Higher-timeframe trend state = trend state calculated on the last completed higher-timeframe bar, using close for efficiency ratio and slow midpoint slope instead of spine slope. Lower-timeframe bias = close compared with its EMA on the last completed lower-timeframe bar within the chart bar.
Calculation: Liquidity pools = on confirmation of a symmetric pivot high or low, compare it with each of the most recent limited number of confirmed pivots of the same kind; for every pair within an ATR-scaled tolerance measured on the confirmation bar, add the higher high or lower low as a pool. Remove high pools when current high exceeds them and low pools when current low falls below them; retain a limited number of the newest pools. The long target is the nearest remaining high pool above close and the short target the nearest remaining low pool below close when liquidity targets are enabled and such a pool exists; otherwise use the upper or lower rail respectively.
Calculation: Setup stop = cloud bottom − an ATR-scaled buffer for a long, or cloud top + an ATR-scaled buffer for a short. Freeze the stop and target at the setup entry bar's close; process an existing setup's exit before allowing a new setup on the same bar.
Calculation: Breakout bar range = max(high − low, safe ATR × a floor factor); body fraction = absolute close − open divided by breakout bar range; volume ratio = volume / its SMA when volume and its SMA are positive, otherwise 1.
Long: Cloud A > cloud B AND previous cloud A <= previous cloud B.
Short: Cloud A <= cloud B AND previous cloud A > previous cloud B.
Long: Trend state is up or strong up AND range position < discount threshold AND previous range position >= discount threshold.
Short: Trend state is down or strong down AND range position > premium threshold AND previous range position <= premium threshold.
Long: Trend state is up or strong up AND range position < discount threshold AND close > open AND no setup is active AND (higher-timeframe confirmation is disabled OR higher-timeframe trend state is up or strong up) AND (lower-timeframe confirmation is disabled OR lower-timeframe close > its EMA) AND (trend-clarity filtering is disabled OR (efficiency ratio > clarity threshold AND (higher-timeframe confirmation is enabled AND higher-timeframe trend state is up or strong up OR higher-timeframe confirmation is disabled AND trend state is strong up))) AND close > setup stop AND long target − close >= minimum reward-to-risk ratio × (close − setup stop).
Short: Trend state is down or strong down AND range position > premium threshold AND close < open AND no setup is active AND (higher-timeframe confirmation is disabled OR higher-timeframe trend state is down or strong down) AND (lower-timeframe confirmation is disabled OR lower-timeframe close < its EMA) AND (trend-clarity filtering is disabled OR (efficiency ratio > clarity threshold AND (higher-timeframe confirmation is enabled AND higher-timeframe trend state is down or strong down OR higher-timeframe confirmation is disabled AND trend state is strong down))) AND setup stop > close AND close − short target >= minimum reward-to-risk ratio × (setup stop − close).
Long: A symmetric pivot low is confirmed AND its low < the preceding confirmed pivot low AND its spine minus low, measured at the pivot bar, < the preceding pivot's spine minus low.
Short: A symmetric pivot high is confirmed AND its high > the preceding confirmed pivot high AND its high minus spine, measured at the pivot bar, < the preceding pivot's high minus spine.

Short: Close < lower rail AND previous close >= previous lower rail AND (lower rail − close) / safe ATR >= displacement threshold AND body fraction >= body threshold AND volume ratio >= volume threshold AND (high − close) / breakout bar range >= close-location threshold.

Short: Trend state is down or strong down AND range position > premium threshold.
