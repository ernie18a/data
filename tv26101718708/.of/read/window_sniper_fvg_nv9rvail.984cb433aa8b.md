Calculation: Selected window = the first matching configured intraday window in fixed priority order, evaluated using a fixed UTC offset; no window is selected when window display is disabled or no window matches.
Calculation: Gap state = on the configured detection timeframe, reset to empty whenever the selected window changes; then retain the first bullish or bearish gap until the next reset. A gap qualifies when a window is selected, the bar two detection bars earlier has the same selected window, and either the current low is above that earlier high or the current high is below that earlier low. If both qualify, retain the bullish gap. Sample this state on the chart timeframe: for a higher detection timeframe use the last completed detection bar; for a lower detection timeframe use the last completed detection bar within the chart bar; for the same timeframe use the current chart bar. A state is new when it is nonempty and its gap's earlier bar timestamp differs from that of the last emitted gap.
Long: Gap state is new AND its current detection-bar low is above the high two detection bars earlier.
Short: Gap state is new AND its current detection-bar high is below the low two detection bars earlier.
