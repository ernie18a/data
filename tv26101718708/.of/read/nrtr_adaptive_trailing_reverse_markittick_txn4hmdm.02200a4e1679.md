Calculation: Adaptive source = Select close, SMA, EMA, RMA, HMA, two consecutive WMAs of close, three consecutive VWMAs of close, a slope projection, or a recursive estimate, using the same lookback for each stage. Slope projection = SMA(close) + (close - close one lookback ago) / 2. For the recursive estimate, initialize estimate to close and error to 1; on each bar set predicted error = error + 1 / lookback, gain = predicted error / (predicted error + 1), estimate = estimate + gain * (close - estimate), and error = (1 - gain) * predicted error.
Calculation: Trailing state = Initialize trend as up, extreme as adaptive source, and trail as adaptive source minus offset; offset is either a percentage of the previous bar's adaptive source or a multiple of the previous bar's ATR. On each subsequent bar, replace an unavailable previous extreme or trail with zero. If the prior trend is up, set extreme to max(previous extreme, previous adaptive source) and trail to max(previous trail, extreme - offset); if previous adaptive source < trail, switch trend to down, set extreme to previous adaptive source and trail to extreme + offset. If the prior trend is down, set extreme to min(previous extreme, previous adaptive source) and trail to min(previous trail, extreme + offset); if previous adaptive source > trail, switch trend to up, set extreme to previous adaptive source and trail to extreme - offset. The initial offset is unavailable because it uses the previous bar.
Calculation: Directional cooldown = On each raw flip to up with low <= the new trail, set the long cooldown end to the current bar index plus the cooldown length; on each raw flip to down with high >= the new trail, set the short cooldown end likewise. A side is in cooldown through its end bar, inclusive, including the bar that starts it.
Calculation: Valid flip = A raw flip to the specified side AND (ADX filtering is disabled OR previous-bar ADX >= threshold, with equal DI and ADX smoothing lengths) AND (cooldown is disabled OR that side is not in cooldown).
Calculation: Trade levels = On each valid flip, record the current close as entry and the new trail as stop, replacing the previous trade levels. Risk = absolute difference between entry and stop. Each of three independently configured long targets is entry + risk multiplied by its target multiple; each short target is entry - risk multiplied by its target multiple.
Long: Trailing trend = up
Short: Trailing trend = down
Exit: long, valid flip to down
Exit: short, valid flip to up
Exit: long, raw flip to up AND low <= new trail
Exit: short, raw flip to down AND high >= new trail
Exit: long, high >= any recorded long target
Exit: short, low <= any recorded short target
