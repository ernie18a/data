Calculation: Window VWAP = volume-weighted mean of a configurable chart-bar price source from the start of a fixed lookback window through its end, substituting weight 1 when volume is missing or nonpositive. Lookbacks use one anchor timeframe that is the chart timeframe or higher; use either the still-forming anchor bar and the current chart bar, or the last completed anchor bar and its last chart bar.
Calculation: Price score = 100 times the fraction of enabled window VWAPs strictly below the window-end close.
Calculation: Stack score = 100 times (signed stack total plus number of adjacent pairs) divided by twice the number of adjacent pairs. Sort enabled window VWAPs by increasing lookback; for each adjacent pair add 1 if the shorter-lookback VWAP exceeds the longer by more than an ATR-based tolerance, subtract 1 if it is below the longer by more than that tolerance, and otherwise add 0. The ATR uses the same anchor timeframe and forming or completed bar as the windows; if unavailable, use chart-timeframe ATR, or zero tolerance if that is also unavailable.
Calculation: Structure score = (price score + stack score) / 2.
Long: Every enabled window VWAP is available AND enabled lookbacks are distinct AND price score >= bullish threshold
Long: Every enabled window VWAP is available AND enabled lookbacks are distinct AND number of enabled windows >= 2 AND stack score >= bullish threshold
Long: Every enabled window VWAP is available AND enabled lookbacks are distinct AND number of enabled windows >= 2 AND structure score >= bullish threshold
Short: Every enabled window VWAP is available AND enabled lookbacks are distinct AND price score < neutral threshold
Short: Every enabled window VWAP is available AND enabled lookbacks are distinct AND number of enabled windows >= 2 AND stack score < neutral threshold
Short: Every enabled window VWAP is available AND enabled lookbacks are distinct AND number of enabled windows >= 2 AND structure score < neutral threshold
