Calculation: C1, C2, C3 = respectively the second-last completed, last completed, and still-forming bars of a timeframe higher than the chart timeframe; Oi, Hi, Li, Ci denote their open, high, low, close; Ri = max(Hi − Li, ε), Bi = abs(Ci − Oi), qi = Bi / Ri, pi = (Ci − Li) / Ri, M = (O1 + C1) / 2, and A = max(ATR of the still-forming higher-timeframe bar, ε), where ε is a positive denominator floor
Calculation: I(condition) = 1 if the condition is true, otherwise 0; clip(x) = max(0, min(1, x)); near(x, y, scale) = 1 − min(abs(x − y) / max(scale, ε), 1); U = clip((small-body threshold − q2) / small-body scale); inside = H2 < H1 AND L2 > L1
Calculation: Pattern scores = the following twelve scores, using shared positive weights a < b < c < d < e and positive parameters proximity scale k, body scales t1 and t2, close-position threshold m and scale v, range threshold r and scale s, small-body threshold and scale, and gap-proximity multiplier g: bullish sweep = b·I(C1 < O1) + e·I(L2 < L1) + b·I(L2 ≥ L1)·near(L2,L1,kA) + d·I(C2 > L1) + b·I(C2 ≤ L1)·near(C2,L1,kA) + b·I(C2 > O2) + b·I(C3 > O3) + d·(I(C3 > H2) + I(C3 ≤ H2)·near(C3,H2,A)) + a·q1; bearish sweep = b·I(C1 > O1) + e·I(H2 > H1) + b·I(H2 ≤ H1)·near(H2,H1,kA) + d·I(C2 < H1) + b·I(C2 ≥ H1)·near(C2,H1,kA) + b·I(C2 < O2) + b·I(C3 < O3) + d·(I(C3 < L2) + I(C3 ≥ L2)·near(C3,L2,A)) + a·q1
Calculation: Bullish gap score = c·I(C2 > O2) + d·clip(q2/t1) + c·clip(R2/A) + e·(I(L3 > H1) + g·I(L3 ≤ H1)·near(L3,H1,kA)) + b·I(C3 > O3) + c·(I(C3 > C2) + I(C3 ≤ C2)·near(C3,C2,A)); bearish gap score = c·I(C2 < O2) + d·clip(q2/t1) + c·clip(R2/A) + e·(I(H3 < L1) + g·I(H3 ≥ L1)·near(H3,L1,kA)) + b·I(C3 < O3) + c·(I(C3 < C2) + I(C3 ≥ C2)·near(C3,C2,A))
Calculation: Bullish sequence score = d·clip((r − R1/A)/s) + e·I(L2 < L1) + c·I(C2 > L1) + e·(I(C3 > H1) + I(C3 ≤ H1)·near(C3,H1,A)) + c·I(C3 > O3); bearish sequence score = d·clip((r − R1/A)/s) + e·I(H2 > H1) + c·I(C2 < H1) + e·(I(C3 < L1) + I(C3 ≥ L1)·near(C3,L1,A)) + c·I(C3 < O3)
Calculation: Bullish expansion score = c·I(C1 > O1) + c·I(C2 > O2) + c·I(C3 > O3) + b·I(C2 > C1) + b·I(C3 > C2) + c·I(B2 ≥ B1) + b·I(B3 ≥ B2) + b·I(H3 > H2); bearish expansion score = c·I(C1 < O1) + c·I(C2 < O2) + c·I(C3 < O3) + b·I(C2 < C1) + b·I(C3 < C2) + c·I(B2 ≥ B1) + b·I(B3 ≥ B2) + b·I(L3 < L2)
Calculation: Bullish compression score = f·I(inside) + c·I(C3 > O3) + h·(I(C3 > H1) + I(C3 ≤ H1)·near(C3,H1,A)) + b·clip(q3/t2) + b·clip((p3 − m)/v); bearish compression score = f·I(inside) + c·I(C3 < O3) + h·(I(C3 < L1) + I(C3 ≥ L1)·near(C3,L1,A)) + b·clip(q3/t2) + b·clip((m − p3)/v), where e < h < f
Calculation: Bullish star score = d·I(C1 < O1) + c·clip(q1/t2) + d·U + d·I(C3 > O3) + d·(I(C3 > M) + I(C3 ≤ M)·near(C3,M,A)) + a·I(C3 > O1); bearish star score = d·I(C1 > O1) + c·clip(q1/t2) + d·U + d·I(C3 < O3) + d·(I(C3 < M) + I(C3 ≥ M)·near(C3,M,A)) + a·I(C3 < O1)
Calculation: Pattern rank = descending rank among all twelve scores, breaking equal scores by their stated order: bullish sweep, bearish sweep, bullish gap, bearish gap, bullish sequence, bearish sequence, bullish expansion, bearish expansion, bullish compression, bearish compression, bullish star, bearish star
