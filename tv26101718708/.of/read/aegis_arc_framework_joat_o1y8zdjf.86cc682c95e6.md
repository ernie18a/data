Calculation: Anchored VWAPs = For each of three calendar anchors, ordered from shortest to longest, accumulate ((high + low) / 2) × volume and volume from the start of the current anchor period through the current chart bar; divide the two sums, or use (high + low) / 2 when accumulated volume is zero. Each anchor uses the still-forming period. Choose the shortest, middle, or longest anchor as the reference; when the gate uses any or all anchors, use the shortest as the reference.
Calculation: Arc state = Calculate ATR on chart bars. Set distance to max(ATR × distance multiplier, 2 × price increment), bullish target to low − distance, and bearish target to high + distance. Once ATR is available, initialize direction to bullish if close ≥ reference VWAP, otherwise bearish; initialize trail to the corresponding target, velocity to 1, run length to 0, and bars since flip to 1000. On each bar with available ATR, including the initialization bar, calculate extension = clamp(abs(close − reference VWAP) / ATR / 4, 0, 1), using zero when ATR ≤ 0; acceleration = base acceleration × (1 + (VWAP boost − 1) × extension) × (1 + min(run length / run window, 2) × 0.12); velocity = clamp(previous bar's velocity × velocity decay + acceleration, 0, velocity cap), using 1 when the previous velocity is unavailable; and chase = clamp(minimum chase + velocity × 0.03 + extension × 0.08, minimum chase, maximum chase). Evaluate the long and short flip conditions using the direction and bars-since-flip count before updating them and the previous bar's trail. On a flip, set direction to the new direction, trail to its raw target, velocity to 1, and both run length and bars since flip to 0. Otherwise, for a bullish direction set trail to min(previous trail + (max(bullish target, previous trail) − previous trail) × chase, low − price increment); for a bearish direction set trail to max(previous trail + (min(bearish target, previous trail) − previous trail) × chase, high + price increment). If the previous trail is unavailable, use the corresponding raw target before applying the price-increment limit. Increment run length and bars since flip. The price increment is a configurable parameter.
Long: Previous direction = bearish AND close > previous trail AND bars since flip ≥ minimum flip gap AND the selected bullish VWAP gate passes, where the gate requires close ≥ the selected anchor VWAP, or ≥ any anchor for any-anchor mode, or ≥ every anchor for all-anchor mode.
Short: Previous direction = bullish AND close < previous trail AND bars since flip ≥ minimum flip gap AND the selected bearish VWAP gate passes, where the gate requires close < the selected anchor VWAP, or < any anchor for any-anchor mode, or < every anchor for all-anchor mode.
Long: Arc direction = bullish.
Short: Arc direction = bearish.
Long: Close ≥ at least two anchored VWAPs.
Short: Close < at least two anchored VWAPs.
