Let A and B be its start and end prices. On each confirmed bar, first replace A and B with the latest downward segment if its B time differs from the stored B time. Then, if waiting for the first entry and close < B, set B to the current low and its time to the current bar time.
Calculation: Levels = B + fraction × (A − B), using separate configurable fractions ordered from lowest to highest as first stop, first entry, first target, second entry, and second target.
Calculation: Setup state = no setup initially; whenever the stored B time changes or is first initialized, reset to waiting for first entry and clear the flag recording whether the first entry has occurred. Evaluate at most one transition per confirmed bar: first-entry state → in first trade on first entry; first-entry state → in second trade on direct second entry; in first trade → waiting for second entry on first target or → waiting for first entry on first stop; waiting for second entry → in second trade on second entry; in second trade → played on second target or, on second stop, → waiting for second entry if the first entry has occurred since the last reset, otherwise → waiting for first entry. Played persists until the next reset. A reset takes precedence over transitions, and a direct second entry takes precedence over a first entry.
