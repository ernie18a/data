Calculation: Participation wave = EMA of the raw wave using a smoothing length. For each bar let range = max(high - low, positive price floor), close position = 2 * ((close - low) / range - 0.5), body pressure = (close - open) / range, buy volume = volume if close > open else 0.35 * volume, and sell volume = volume if close < open else 0.35 * volume. Using a common wave length, let total = EMA(max(volume, 1)); raw wave = 65 * (EMA(buy volume) - EMA(sell volume)) / total + 22 * EMA(volume * close position) / total + 13 * EMA(volume * body pressure) / total.
Calculation: Wave signal = EMA of participation wave using a separate signal length.
Calculation: Confirmed wave pivot = a wave value that is the highest or lowest over equal numbers of preceding and following bars, confirmed on the last following bar; ties select the most recent extreme. Associate its price with the high for a wave high pivot or the low for a wave low pivot. Compare each confirmed pivot with the immediately preceding confirmed pivot of the same type, including pivots that did not produce a divergence. Measure price displacement as the absolute difference between pivot prices divided by ATR at the newer pivot, floored by a positive price floor.
Long: A wave low pivot is confirmed AND the pivot gap >= minimum gap AND absolute wave displacement >= minimum wave displacement AND price displacement >= minimum price displacement AND ((regular divergence is enabled AND newer pivot price < previous pivot price AND newer pivot wave > previous pivot wave) OR (hidden divergence is enabled AND newer pivot price > previous pivot price AND newer pivot wave < previous pivot wave)).
Short: A wave high pivot is confirmed AND the pivot gap >= minimum gap AND absolute wave displacement >= minimum wave displacement AND price displacement >= minimum price displacement AND ((regular divergence is enabled AND newer pivot price > previous pivot price AND newer pivot wave < previous pivot wave) OR (hidden divergence is enabled AND newer pivot price < previous pivot price AND newer pivot wave > previous pivot wave)).
Long: Participation wave crosses above zero OR crosses above wave signal.
Short: Participation wave crosses below zero OR crosses below wave signal.
Long: Participation wave >= positive upper threshold OR (participation wave > 0 AND wave signal >= its previous value) OR (participation wave > upper threshold * 0.35 AND participation wave < upper threshold AND wave signal < its previous value).
Short: Participation wave <= negative lower threshold OR (participation wave < 0 AND wave signal <= its previous value) OR (participation wave < lower threshold * 0.35 AND participation wave > lower threshold AND wave signal > its previous value).
Long: Participation wave has been > 0 for at least the configured streak length AND the preceding bar's positive streak was shorter than that length.
Short: Participation wave has been < 0 for at least the configured streak length AND the preceding bar's negative streak was shorter than that length.
