Calculation: Selected regression = For each lookback from a minimum to a longer maximum in fixed steps, regress closes on bar age, with age 0 for the newest bar. Compute the Pearson correlation between the closes and their fitted values. Select the lookback with the lowest defined correlation, breaking ties in favor of the shorter lookback; accept it only if its correlation is at or below the channel threshold. Use chart-timeframe closes, or closes from a higher timeframe using its last completed bar, or closes from a lower timeframe using the last completed lower-timeframe bar in each chart bar. Require the maximum lookback of source bars before calculating.
Calculation: Channel boundaries = The selected regression's fitted value at age 0 plus or minus a deviation multiplier times the square root of the sum of squared regression residuals divided by max(1, lookback minus 2). When no regression is accepted, retain the last accepted boundaries.
Long: min(open, close) > retained upper channel boundary
Short: max(open, close) < retained lower channel boundary
Long: selected regression is accepted AND its correlation < crossover threshold AND the last previously accepted correlation recorded while crossover labels were enabled >= crossover threshold
Short: selected regression is accepted AND its correlation > crossover threshold AND the last previously accepted correlation recorded while crossover labels were enabled <= crossover threshold
