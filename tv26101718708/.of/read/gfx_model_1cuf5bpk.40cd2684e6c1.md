Calculation: CISD state = Initialize structure top and bottom to 0, both pullback flags to false, and both candidate prices and their bar indices as undefined. On each bar, process these steps in order: (1) If the previous bar closed above its open and the upward-pullback flag is false, set that flag and set the upward candidate and its index to the previous bar's open and index. If the previous bar closed below its open and the downward-pullback flag is false, do the analogous operation for the downward candidate. (2) While the downward flag is set, replace its candidate and index with the current open and index if the open is below the candidate, or if close is below open and open is above the candidate. While the upward flag is set, replace its candidate and index with the current open and index if the open is above the candidate, or if close is above open and open is below the candidate. (3) If low is below structure bottom, set bottom to low. If the upward flag is set and its candidate index differs from the current index, set structure top to the maximum high at offsets min(current index minus candidate index plus 1, current index) and one less than that offset, clear the upward flag, and create a bullish level at the upward candidate. Otherwise, if the previous bar closed above its open, the current bar closes below its open, and the upward candidate index is defined, set structure top to the previous high, clear the upward flag, and create a bullish level at the upward candidate. (4) Using the resulting structure top, if high is above it, set top to high. If the downward flag is set and its candidate index differs from the current index, set structure bottom to the minimum low at offsets min(current index minus candidate index plus 1, current index) and one less than that offset, clear the downward flag, and create a bearish level at the downward candidate. Otherwise, if the previous bar closed below its open, the current bar closes above its open, and the downward candidate index is defined, set structure bottom to the previous low, clear the downward flag, and create a bearish level at the downward candidate. Store bullish and bearish levels in separate creation-order queues, initially uncompleted. If retaining old levels is disabled, discard the oldest level in a queue whenever its size exceeds one. After creation and discarding, inspect only the oldest level in each queue; mark an uncompleted bullish level completed when close is above it, and mark an uncompleted bearish level completed when close is below it.
Long: A bullish level is created OR close is above the oldest uncompleted bullish level selected from the bullish-level queue before its completion update.
Short: A bearish level is created OR close is below the oldest uncompleted bearish level selected from the bearish-level queue before its completion update.
