Calculation: Gap creation = On each confirmed chart bar, create a bullish chart gap when low > high two bars earlier, with top = low and bottom = that earlier high; create a bearish chart gap when high < low two bars earlier, with top = that earlier low and bottom = high. Require top - bottom >= a configurable multiple of the current chart-bar ATR. Optionally also require the preceding chart bar's high - low > another configurable multiple of the current chart-bar ATR. Optionally, on the first confirmed chart bar of a new higher-timeframe period, create higher-timeframe gaps using the same three-bar comparisons and boundaries, with the latest compared bar being the last completed higher-timeframe bar. Apply the same size filter using current chart-bar ATR, but do not apply the displacement filter to higher-timeframe gaps. Add chart gaps before higher-timeframe gaps; after each addition, discard the oldest tracked gap if the configurable maximum count is exceeded.
Calculation: Gap state = Process all tracked gaps on each confirmed chart bar, including their creation bar. A fresh bullish gap inverts when close < bottom; a fresh bearish gap inverts when close > top. Inversion requires the configurable inversion mode to be enabled. When it is disabled, remove a fresh gap from tracking when its fill condition is met: close < bottom for bullish or close > top for bearish in close-fill mode; low <= bottom for bullish or high >= top for bearish in wick-fill mode. An inverted bullish gap is removed when close > top; an inverted bearish gap is removed when close < bottom. Otherwise, starting after the inversion bar, record the first retest of an inverted bullish gap when high >= bottom, or of an inverted bearish gap when low <= top; subsequent retests of that gap do not signal.
Long: A bullish gap is created OR a bearish gap inverts OR the first retest of an inverted bearish gap occurs.
Short: A bearish gap is created OR a bullish gap inverts OR the first retest of an inverted bullish gap occurs.
