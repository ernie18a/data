Calculation: Higher-timeframe values = Aggregate bars into a higher timeframe. With lookahead off, update each requested value only when that higher-timeframe bar completes and otherwise carry forward its last returned value. The EMA uses the completed higher-timeframe close; previous high, low, and close use the preceding higher-timeframe bar relative to the bar being evaluated.
Calculation: Bias = Either chart close or previous higher-timeframe close, selected by a parameter, compared with the higher-timeframe EMA.
Calculation: Swing high and swing low = The most recently confirmed symmetric fractal high and low, respectively: the center bar's high is strictly greater than every surrounding high, or its low is strictly less than every surrounding low. Confirm after the required following bars have completed. Retain swings across higher-timeframe boundaries.
Calculation: Structure state = Reset both directions at each new higher-timeframe period. Set bullish and clear bearish when close > swing high AND previous close <= that same swing high; set bearish and clear bullish when close < swing low AND previous close >= that same swing low. Evaluate the bearish update after the bullish update. A new structure shift occurs when its resulting state is true and its previous chart-bar state was false.
Calculation: Sweep state = Reset at each new higher-timeframe period. Set the low-swept state when low < previous higher-timeframe low AND close > previous higher-timeframe low; set the high-swept state when high > previous higher-timeframe high AND close < previous higher-timeframe high. Retain each state through the period.
Calculation: Order block = Reset both blocks at each new higher-timeframe period. On a new bullish structure shift with bullish bias, select the nearest earlier bearish candle within a lookback; on a new bearish structure shift with bearish bias, select the nearest earlier bullish candle within the same lookback. If none is found, retain the existing block. Initially use the selected candle's high and low as the block boundaries. With defensive refinement enabled, if its range exceeds a configurable multiple of the current chart-bar ATR, replace the bullish block's high or the bearish block's low with that candle's close. Otherwise retain the full range. Retain each block until replaced, reset, or invalidated. A bullish block is invalidated when low <= its low; a bearish block is invalidated when high >= its high. Evaluate block markings before invalidation and entry conditions after invalidation.
Calculation: Entry risk levels = At an entry signal, fix the stop at the corresponding order block's opposite boundary and fix the target at signal close plus, for a long, or minus, for a short, a configurable multiple of the distance between signal close and stop.
Long: New bullish structure shift AND bullish bias.
Short: New bearish structure shift AND bearish bias.
Long: Bullish order block exists before invalidation AND order block display is enabled.
Short: Bearish order block exists before invalidation AND order block display is enabled.
Long: Bullish bias AND low-swept state AND bullish structure state AND chart-bar opening time is within the configured New York time window AND bullish order block exists after invalidation AND low <= bullish order block high AND close >= bullish order block low.
Short: Bearish bias AND high-swept state AND bearish structure state AND chart-bar opening time is within the configured New York time window AND bearish order block exists after invalidation AND high >= bearish order block low AND close <= bearish order block high.
Exit: Long, low <= fixed entry stop OR high >= fixed entry target.
Exit: Short, high >= fixed entry stop OR low <= fixed entry target.
