Calculation: KMCM = EMA(100*tanh(z), smoothing length), where z = (E - SMA(E, mPeriod)) / stdev(E, mPeriod); E = 0.5 * mass * velocity^2, with its sign set to the sign of velocity (negative when velocity < 0); mass = volume / SMA(volume, mPeriod); velocity = rate of change (percent) of close over vPeriod bars; vPeriod = round(clamp(base velocity period / volRatio, min velocity period, max velocity period)), where the base velocity period equals the max velocity period; mPeriod = round(clamp(base volume period / volRatio, min volume period, max volume period)), where the volume-period range is longer than the velocity-period range; volRatio = ATR(short lookback) / SMA(ATR(short lookback), much longer lookback). All on chart timeframe, using the current bar.
Calculation: slope = KMCM - KMCM of previous bar
Long: KMCM > upper threshold AND slope > 0
Short: KMCM < lower threshold AND slope < 0 (lower threshold is negative, upper threshold is positive, symmetric around 0)
