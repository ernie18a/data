Calculation: Confirmed pivot high/low = a bar whose high/low is strictly greater/less than every high/low in the same-length lookback on each side; use the same lookback on chart and higher timeframes. On each higher timeframe, use the pivot result from the last completed bar; on the chart timeframe, use the current bar’s pivot result and act only on a confirmed chart bar.
Calculation: ATR = average true range on the chart timeframe; node tolerance = ATR × a configurable coefficient.
Calculation: Active high/low nodes = separately track pivot highs/lows from three configured higher timeframes and, when enabled, the chart timeframe. On each confirmed chart bar, register each nonempty source pivot: if it is within node tolerance of an existing node of the same type, use the last matching node, increment its strength by one up to four, and refresh its age; otherwise create a strength-one node. Prune nodes older than a configurable number of chart bars since refresh. A qualified resistance/support is the nearest active high/low node above/below close whose strength meets the configurable minimum.
Calculation: Rejection wick fraction = lower wick / (high − low) for bullish rejection; upper wick / (high − low) for bearish rejection.
Calculation: Long stop = qualified support − ATR × configurable buffer; long target 3 = entry price + |entry price − long stop| × configurable reward multiple. Short stop = qualified resistance + ATR × configurable buffer; short target 3 = entry price − |short stop − entry price| × configurable reward multiple.
Long: A qualified support exists AND |low − support| ≤ node tolerance AND (rejection-wick requirement is disabled OR (high > low AND rejection wick fraction ≥ configurable minimum)) AND close > open.
Short: A qualified resistance exists AND |high − resistance| ≤ node tolerance AND (rejection-wick requirement is disabled OR (high > low AND rejection wick fraction ≥ configurable minimum)) AND close < open.
Exit: Long, low ≤ long stop OR high ≥ long target 3 OR Short.
Exit: Short, high ≥ short stop OR low ≤ short target 3 OR Long.
