Calculation: Pivot = the high or low of a bar whose value is strictly higher or lower, respectively, than every corresponding value in the same number of bars before and after it; it becomes available on the last bar needed for confirmation.
Calculation: Nodes = separate ordered collections for pivot highs and pivot lows. On each completed chart bar, register, in timeframe order, each pivot reported by the last completed bar of each higher timeframe, then optionally the chart-timeframe pivot. Register higher-timeframe pivots again on every chart bar for which they are reported. For each pivot, find the last existing same-side node within the current chart ATR multiplied by the node-tolerance parameter; increase its strength by one, up to the number of timeframes, and update its last-registration bar. If none matches, append a node at the pivot price with strength one. Keep node prices unchanged when matched. After registration, remove nodes whose age since last registration exceeds the maximum age parameter.
Calculation: Bull node = the highest-priced low node strictly below the current close whose strength is at least the minimum strength parameter. Bear node = the lowest-priced high node strictly above the current close whose strength is at least the minimum strength parameter.
Calculation: Trade levels = at an accepted long signal, set stop to the bull node minus chart ATR times the stop-buffer parameter and final target to entry price plus the absolute entry-to-stop distance times the final-target reward-to-risk parameter. At an accepted short signal, set stop to the bear node plus chart ATR times the stop-buffer parameter and final target to entry price minus the absolute entry-to-stop distance times the final-target reward-to-risk parameter. Freeze these levels until the next accepted signal.
Calculation: Trade lock = when locking is enabled, an accepted signal activates the lock; a subsequent completed bar reaching the frozen stop or final target releases it before evaluating that bar's signals. When locking is disabled, the lock is inactive.
Long: trade lock is inactive AND bull node exists AND absolute difference between low and bull node <= chart ATR times the node-tolerance parameter AND close > open AND (rejection filter is disabled OR (high > low AND (min(open, close) - low) / (high - low) >= minimum wick fraction))
Short: trade lock is inactive AND bear node exists AND absolute difference between high and bear node <= chart ATR times the node-tolerance parameter AND close < open AND (rejection filter is disabled OR (high > low AND (high - max(open, close)) / (high - low) >= minimum wick fraction))
Exit: long, low <= frozen stop OR high >= frozen final target OR short condition
Exit: short, high >= frozen stop OR low <= frozen final target OR long condition
