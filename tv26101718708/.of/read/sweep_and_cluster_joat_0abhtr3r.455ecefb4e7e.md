Calculation: Pivot reference = Scan the most recently confirmed pivot highs and lows together, newest first, within a limited cache and scan depth. For each side, select the first pivot whose pivot bar meets the minimum age. A pivot is confirmed using equal numbers of bars on either side.
Calculation: Bullish sweep = Low < pivot-low reference AND close > pivot-low reference AND min(open, close) - low >= ATR multiplied by the wick threshold AND (min(open, close) - low) / max(high - low, a small positive constant) >= the wick-to-range threshold AND bars since the previous accepted bullish sweep > the cooldown AND (overlap is allowed OR no bullish sweep is pending). Initially, there is no pending sweep and the previous sweep is sufficiently far in the past.
Calculation: Bearish sweep = High > pivot-high reference AND close < pivot-high reference AND high - max(open, close) >= ATR multiplied by the wick threshold AND (high - max(open, close)) / max(high - low, a small positive constant) >= the wick-to-range threshold AND bars since the previous accepted bearish sweep > the cooldown AND (overlap is allowed OR no bearish sweep is pending). Initially, there is no pending sweep and the previous sweep is sufficiently far in the past.
Calculation: Cluster confirmation = For each accepted sweep, starting on the following bar, accumulate all subsequent bar volumes and count bars closing in the sweep's reversal direction: close >= open for bullish sweeps and close < open for bearish sweeps. For qualifying bars, accumulate absolute candle bodies and ranges. On each monitored bar through the cluster-window limit, confirm when qualifying-bar count >= its minimum AND sum of qualifying bodies / sum of qualifying ranges >= the body-ratio threshold AND cumulative volume / (sweep-bar volume SMA multiplied by elapsed monitored bars) >= the volume threshold. Use zero for a ratio with a nonpositive denominator; if the sweep-bar volume SMA is unavailable, use sweep-bar volume. Resolve each sweep at its first confirmation or at window expiration, whichever occurs first. Test new sweeps against pending events before resolving existing events on the same bar. If multiple events confirm on one bar, the oldest confirming event supplies the displayed confirmation direction.
Long: Bullish sweep.
Short: Bearish sweep.

Short: Cluster confirmation direction = bearish.

Short: Most recent cluster confirmation direction = bearish.
