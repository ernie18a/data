Calculation: Analysis bars = three independently selectable timeframes A, B, and C, each potentially higher than, lower than, or equal to the chart timeframe. For a higher timeframe, use its last completed bar on historical chart bars and its still-forming bar in real time; for a lower timeframe, use the last available intrabar within each chart bar. Run the following calculations independently for each timeframe and direction.
Calculation: Bars per day = for intraday bars, count bars per calendar day and update an exponential average of completed daily counts with smoothing factor 1/5; before the first completed day use the current day's running count. For daily or longer bars, use the reciprocal of the bar's duration in trading days, with the source's daily, weekly, and monthly calendar categories.
Calculation: Long anchors = maintain a prior top and subsequent bottom. On each bar, find the highest high within the trend lookback and the lowest low among the most recent max(top's offset, minimum scan length) bars, choosing the most recent low on ties. Update anchors if the current low is below the stored bottom or if the top's offset is at least the sum of the minimum prior-leg and active-leg lengths and the bottom's offset is at least the minimum active-leg length. Replace the top only if it is newer than the stored top; when replaced, clear the bottom. Replace the bottom only if it is newer than the stored bottom and differs from the top. The prior-leg deviation is the maximum vertical distance of highs above the straight line through the anchors, inclusive. The active-leg slope is the minimum slope from the bottom to any subsequent low; recalculate it when the bottom changes.
Calculation: Short anchors = mirror the long-anchor procedure across the price axis: find the lowest low and the highest subsequent high, replace the stored peak when the current high exceeds it, measure the maximum distance of lows below the anchor line, and use the maximum slope from the peak to subsequent highs.
Calculation: For either direction, let prior price P and pivot price Q occur at bar indices p and q, let D be the prior-leg deviation, and let S be the active-leg slope. The active rate is 100 × S / Q × bars per day. The prior rate is 100 × (P + D − Q) / (p − q) / P × bars per day for long and 100 × (P − D − Q) / (p − q) / P × bars per day for short. Use zero for a rate when its required slope or denominator is unavailable. Trend is active rate plus prior rate. Extend the anchor line to the current bar to obtain B. V-Fib is (high − B) / (D / 0.236) for long and (B − low) / (D / 0.236) for short; when the anchors or deviation are unavailable it is unavailable, and when the resulting ratio is undefined use zero. Leading gain is 100 × (low − Q − S × (current index − q)) / Q for long and 100 × (high − Q − S × (current index − q)) / Q for short; use zero if S is unavailable or zero.
Calculation: Directional readiness = the weighted average of zone, trend, and lead components, using the same component weights for both directions. Zone is zero when V-Fib is unavailable, max(0, V-Fib / lower entry bound) below that bound, 1 within the inclusive entry zone, and max(0, (unlock level − V-Fib) / max(unlock level − upper entry bound, epsilon)) above it. For short, negate active rate, trend, and leading gain before computing the other components. Define soft(x, threshold, band) = clamp(1 + (x − threshold) / max(band, epsilon), 0, 1). Trend component = min(soft(active rate, minimum active rate, minimum active rate), soft(trend, minimum trend, minimum active rate)); lead component = soft(leading gain, minimum leading gain, minimum leading gain). Divide the weighted sum by max(sum of component weights, epsilon).
Calculation: Directional score = three times the weighted average of that direction's readiness across A, B, and C, with the weight sum floored at epsilon. Calculate a display score and two entry-filter scores using independently configurable timeframe-weight profiles; the entry-filter profiles emphasize shorter and longer timeframes respectively. Net score = long display score − short display score.
Calculation: Long entry state = B long active rate >= minimum active rate AND B long prior rate <= maximum prior rate AND B long trend >= minimum trend AND B long V-Fib >= lower entry bound AND B long V-Fib <= upper entry bound AND B long leading gain >= minimum leading gain AND both short entry-filter scores < maximum short score.
Calculation: Short entry state = B short active rate <= negative minimum active rate AND B short prior rate >= negative maximum prior rate AND B short trend <= negative minimum trend AND B short V-Fib >= lower entry bound AND B short V-Fib <= upper entry bound AND B short leading gain <= negative minimum leading gain AND both long entry-filter scores < maximum long score.
Long: Long entry state = true AND previous chart bar's long entry state = false
Short: Short entry state = true AND previous chart bar's short entry state = false
Long: Any analysis timeframe's long V-Fib >= lower entry bound AND its long V-Fib <= upper entry bound
Short: Any analysis timeframe's short V-Fib >= lower entry bound AND its short V-Fib <= upper entry bound
Long: Any analysis timeframe's long trend >= minimum trend
Short: Any analysis timeframe's short trend <= negative minimum trend
Long: Net score >= 0 OR long display score >= maximum long score
Short: Net score < 0 OR short display score >= maximum short score
