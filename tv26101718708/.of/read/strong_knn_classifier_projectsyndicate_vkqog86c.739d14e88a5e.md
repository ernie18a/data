Calculation: Order flow = For each chart bar, compare consecutive completed lower-timeframe closes within that bar, starting with the second lower-timeframe bar. For an increase, add the current lower-timeframe volume to delta and buy; for a decrease, subtract it from delta and add it to sell; for an unchanged close, add half its volume to each of buy and sell. Optionally use a weight of one instead of volume for each comparison. If lower-timeframe data is unavailable, use chart-bar volume as the weight and compare the chart close with the preceding chart close using the same rules. Initialize delta, buy, and sell to zero for each chart bar.
Calculation: Feature vector = Independently standardize each of these five series using its rolling mean and population standard deviation over the same lookback, returning zero when the standard deviation is zero: delta / (volume + 1); (buy - sell) / (buy + sell), or zero if the denominator is zero; (volume's rolling standard score if volume exceeds a multiple of its moving average, otherwise zero) / (1 + abs(close - open) / ATR); (cumulative delta - cumulative delta a lookback ago) / (that lookback × (average volume + 1)); (close - session VWAP of typical price) / ATR. Use zero for the last two ATR-dependent raw features when ATR is not positive, and zero for abs(close - open) / ATR when ATR is not positive. The volume standard score uses the same normalization lookback as the five features.
Calculation: Reversal probability = Maintain a bounded first-in-first-out training pool. On each closed chart bar, once the bar index exceeds the normalization lookback plus the outcome horizon plus two, calculate past direction as sign(close at the horizon - close at the horizon plus the trend-reference lookback). If past direction is nonzero, ATR at the horizon is positive, and abs((close - close at the horizon) × past direction) exceeds a multiple of ATR at the horizon, add the feature vector from the horizon to the pool, labeled continuation if that signed move is positive and reversal otherwise. Include the newly resolved sample in the current classification. Once the pool reaches its minimum size, select up to a specified number of samples with the smallest sum across the five features of log(1 + abs(current feature - sample feature)); retain earlier samples on equal distances. Give each selected sample weight exp(-distance / temperature). Let reversal weight and continuation weight be the sums for their respective labels, total weight their sum, and margin (reversal weight - continuation weight) / total weight, or zero when total weight is zero. Shrink margin by total weight / (total weight + prior strength), and apply the logistic function to the result multiplied by probability sharpness. Before the pool is ready, use probability 0.5.
Calculation: Confidence = 2 × abs(reversal probability - 0.5).
Long: Training-pool size >= minimum pool size AND confidence >= confidence threshold AND reversal probability <= 0.5.
Short: Training-pool size >= minimum pool size AND confidence >= confidence threshold AND reversal probability > 0.5.
