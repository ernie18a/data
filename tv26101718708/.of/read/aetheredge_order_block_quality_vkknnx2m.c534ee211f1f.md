Calculation: Safe ATR = max(ATR if available, otherwise true range if available, otherwise close × 0.001, 1e-8).
Calculation: Bullish structure break = close crosses above the highest high of the preceding structure-lookback bars; bearish structure break = close crosses below the lowest low of the preceding structure-lookback bars. A crossover requires the previous close to be at or below the previous bar's corresponding preceding-window high; a crossunder requires it to be at or above the previous bar's corresponding preceding-window low.
Calculation: Order blocks = on each completed bar with absolute candle body / safe ATR > displacement threshold and a structure break, create a bullish block for a bullish break or a bearish block for a bearish break. Its bounds are the high and low of the most recent opposing candle within the origin lookback; create no block if none exists. Store its formation bar, features and quality, and initialize it as unretested and unresolved. If both breaks occur, choose bullish. Keep at most the maximum number of blocks, removing the oldest when a new block exceeds the limit; resolved blocks also count toward this limit.
Calculation: Block features = at formation, with direction d = 1 for bullish or -1 for bearish, compute and store: clamp((block high - block low) / safe ATR, 0, 10); clamp(absolute candle body / safe ATR, 0, 10); clamp(tanh(clamp((shorter EMA of close - longer EMA of close) / safe ATR, -10, 10)) × d, -3, 3); clamp((RSI of close - 50) / 50 × d, -1, 1); and clamp(origin candle volume / max(volume SMA at formation, 1e-8), 0, 5).
Calculation: Block quality = sigmoid(clamp(bias + sum of feature × corresponding weight, -30, 30)), stored at formation. Initialize bias and all weights to zero. On resolution, recompute prediction p using the stored features and current weights; with label y, update bias to bias - learning rate × (p - y), and each weight to weight - learning rate × ((p - y) × its stored feature + regularization × weight).
Calculation: Block processing = after creating a block on each completed bar, process all retained unresolved blocks newest first, including the new block. A bullish block becomes retested when low <= block high; a bearish block becomes retested when high >= block low. On that first retest, evaluate its entry decision before resolving it. Then resolve a bullish block with label 0 if close < block low, otherwise with label 1 if retested and close > block high; resolve a bearish block with label 0 if close > block high, otherwise with label 1 if retested and close < block low. Otherwise, when age >= resolution horizon, resolve with label 1 if retested and 0 if not. Train immediately on each resolution. Retests during warmup still consume the first retest.
Calculation: Nearest active block = the retained unresolved block minimizing absolute(close - block midpoint) / safe ATR after block processing; ties select the oldest retained block.
Calculation: Structure bias = 1 after a bullish structure break and -1 after a bearish structure break, retaining its previous value between breaks and starting at 0; if both breaks occur, set it to -1.
Long: Completed-bar index > warmup length AND an unresolved bullish block has its first retest on this bar AND its stored quality >= quality threshold.
Short: Completed-bar index > warmup length AND an unresolved bearish block has its first retest on this bar AND its stored quality >= quality threshold.
Long: Nearest active block direction = bullish.
Short: Nearest active block direction = bearish.
Long: Structure bias > 0.
Short: Structure bias < 0.
