Calculation: Delta = if lower-timeframe bars are available and selected, sum their signed volumes within the current chart bar, including the still-forming lower-timeframe bar when evaluating a forming chart bar; sign each volume by the change from the preceding lower-timeframe close, carrying forward the preceding sign on an unchanged close and starting at zero. Otherwise use volume × ((close − low) − (high − close)) / (high − low), or zero when high equals low.
Calculation: Upside flow = max(delta, 0); downside flow = max(−delta, 0); travel = close − previous close, using open in place of a missing previous close.
Calculation: Normal volume, upside flow, downside flow, and absolute travel = independently maintained baselines for those four series. The recent-bar baseline is an EMA including the current bar, initialized with its first value and reset whenever the delta estimator changes; it becomes ready after a configurable fraction of its lookback. Alternatively, use a separate prior-bar baseline for each time-of-day slot: initialize each with its first observation, then update after each completed chart bar with alpha = max(2 / (session lookback + 1), 1 / (slot observation count + 1)). Clear slot baselines when intrabar delta first becomes available, and update them only with the estimator used since that point. Use the slot baselines only on eligible intraday charts when their observation count meets the configured minimum, all four are positive, and the current estimator matches the slot estimator; otherwise use the recent-bar baselines.
Calculation: Quiet weight = min(1, (volume / normal volume) / quiet-volume threshold), or 1 if normal volume is unavailable or nonpositive.
Calculation: Upside and downside cores = repeated EMAs, using the same shortest ribbon smoothing length and number of passes, of 1 + (min(side flow / normal side flow, flow cap) − 1) × quiet weight. Calculate each only when the selected baseline is ready and its normal side flow is positive; initialize each EMA pass from its first available input and retain its previous state when the input is unavailable.
Calculation: Net flow = EMA(delta, event lookback) / (normal upside flow + normal downside flow) × quiet weight, when the denominator is positive.
Calculation: Price response = EMA(travel, event lookback) / normal absolute travel × sign(net flow) / max(abs(net flow), flow floor) ^ response exponent, when normal absolute travel is positive; use a positive sign when net flow is zero.
Calculation: Absorbed flow = abs(net flow) >= absorption threshold AND price response <= response threshold.
Calculation: Surge = abs(net flow) >= surge threshold AND absorbed flow is false AND price response > response threshold, substituting a configurable fallback response when price response is unavailable.
Long: upside core > downside core
Short: upside core <= downside core
Long: net flow > 0 AND (absorbed flow OR surge)
Short: net flow < 0 AND (absorbed flow OR surge)
