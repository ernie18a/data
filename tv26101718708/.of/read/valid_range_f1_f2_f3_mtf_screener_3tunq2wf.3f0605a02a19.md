Calculation: Directional bars = for uptrend use open, high, low, close; for downtrend use -open, -low, -high, -close respectively. Apply the following formation calculations independently to each direction and formation on completed bars.
Calculation: Formation start = when that direction and formation have no active setup, the previous directional close > open AND the current directional close < open AND one of: formation 1 has current high < previous high AND absolute difference between those highs > equality tolerance AND, if the wick filter is enabled, previous high > previous close; formation 2 has current close > previous high; formation 3 has absolute difference between current and previous highs <= equality tolerance AND current close <= previous high. On a start, store the previous low as the invalidation level; store the previous high as the break level and set pullback count to one for formation 1, or store the current high as the break level and set count to zero for formations 2 and 3.
Calculation: Structure break = for an active setup, the current directional high > break level, or current directional close > break level when close-trigger mode is selected, AND pullback count >= one AND pullback count multiplied by bar duration >= minimum pullback duration. On every subsequent bar, test the break first; any break ends the setup even if the count or duration requirement fails. If there is no break, end the setup when invalidation is enabled AND current directional low < invalidation level, or when pullback count >= maximum pullback count; otherwise increment the count. Do not start a replacement setup on the bar that ends one. Each formation and direction can be enabled independently.
Calculation: Timeframe bias = on each selected higher or lower timeframe, use the state through its last completed bar; bias is up when the most recent enabled uptrend structure break is more recent than the most recent enabled downtrend structure break or no downtrend break exists, and down under the opposite comparison. Equal-age breaks or no breaks give neither bias.
Long: An enabled uptrend formation start occurs OR an enabled uptrend structure break occurs.
Short: An enabled downtrend formation start occurs OR an enabled downtrend structure break occurs.
Long: A selected higher or lower timeframe's bias = up OR the count of selected timeframes with up bias > the count with down bias.
Short: A selected higher or lower timeframe's bias = down OR the count of selected timeframes with down bias > the count with up bias.
