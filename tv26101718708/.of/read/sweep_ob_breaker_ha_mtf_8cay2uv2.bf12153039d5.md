Calculation: Heikin-Ashi bars = standard Heikin-Ashi OHLC calculated separately on the chart timeframe and on the higher timeframe; on historical chart bars, use the last completed higher-timeframe bar, updated when that bar completes.
Calculation: Swing levels = the latest confirmed Heikin-Ashi pivot high and pivot low, each confirmed using equal numbers of bars on either side; calculate independently on each timeframe with independently configurable lookbacks. Project confirmed higher-timeframe pivots onto chart bars when available.
Calculation: Bullish sweep = Heikin-Ashi low < latest swing low AND Heikin-Ashi close > latest swing low. Bearish sweep = Heikin-Ashi high > latest swing high AND Heikin-Ashi close < latest swing high.
Calculation: Change of character = maintain independent bullish and bearish pending states for each timeframe, evaluated on every chart bar using that timeframe's available Heikin-Ashi values and swing levels. A bullish sweep starts a bullish pending state if none exists and captures the current swing high; cancel it if Heikin-Ashi close < the latest swing low; otherwise a bullish change of character occurs when Heikin-Ashi close > the captured high, then clear the state. A bearish sweep starts a bearish pending state if none exists and captures the current swing low; cancel it if Heikin-Ashi close > the latest swing high; otherwise a bearish change of character occurs when Heikin-Ashi close < the captured low, then clear the state. A state may start and complete on the same chart bar; an unavailable captured level cannot trigger a change of character.
Calculation: Higher-timeframe direction = the direction of the latest higher-timeframe change of character; initially neutral; if both occur on the same chart bar, bearish takes precedence.
Calculation: Zones = maintain the latest active order block and breaker separately for each direction and timeframe. On a bullish change of character, create or replace the bullish order block with the Heikin-Ashi high and low of the most recent prior bearish Heikin-Ashi candle within the search lookback; on a bearish change of character use the most recent prior bullish candle for the bearish order block. Search chart-bar offsets even for higher-timeframe values, using projected higher-timeframe Heikin-Ashi values and an independently configurable search lookback. If no opposing candle is found, do not create a block. After block creation on each chart bar, chart close < bullish block low deactivates that block and creates or replaces a bearish breaker with the same bounds; chart close > bearish block high similarly creates or replaces a bullish breaker. Then deactivate a bullish breaker when chart close < its low and a bearish breaker when chart close > its high.
Long: Chart-timeframe bullish sweep OR chart-timeframe bullish change of character OR higher-timeframe direction = bullish OR chart close > an active chart-timeframe or higher-timeframe bearish order block high OR higher-timeframe direction = bullish AND chart low is between the bounds of an active higher-timeframe bullish order block or breaker, inclusive.
Short: Chart-timeframe bearish sweep OR chart-timeframe bearish change of character OR higher-timeframe direction = bearish OR chart close < an active chart-timeframe or higher-timeframe bullish order block low OR higher-timeframe direction = bearish AND chart high is between the bounds of an active higher-timeframe bearish order block or breaker, inclusive.
