Calculation: Volume profile = On each chart bar, use a trailing window including the current bar, with length equal to the greater of the configured profile length and bin count. Divide the window's lowest low to highest high into equal bins. Assign each bar's volume to the bin containing (high + low + close) / 3, clamping the bin index to the valid range. The point of control (POC) is the center of the highest-volume bin; choose the lowest-index bin on a tie. Starting there, add the heavier adjacent bin until the accumulated volume reaches the configured fraction of total volume; choose the upper bin on a tie. The value-area low (VAL) is the lower edge of the lowest included bin and the value-area high (VAH) is the upper edge of the highest included bin. If the price range is zero, the levels are undefined.
Calculation: Control state = Initially neutral. On each completed bar after the first, a bullish break is close > previous high, or close >= previous high when non-strict breaks are enabled; a bearish break is close < previous low, or close <= previous low when non-strict breaks are enabled. Optionally require close > open for a bullish break or close < open for a bearish break, and optionally require high - low >= a configured multiple of ATR. A qualifying bullish break changes control to bullish if it was not already bullish; otherwise a qualifying bearish break changes control to bearish if it was not already bearish. Control persists between qualifying changes, including changes whose flip is suppressed.
Calculation: Flip class = For a bullish control change, breakout if close > VAH, otherwise reversion if close <= POC, otherwise in-value. For a bearish control change, breakout if close < VAL, otherwise reversion if close >= POC, otherwise in-value. If profile levels are undefined, the class is in-value.
Calculation: Last shown flip = Initially none; after each qualifying, unsuppressed flip, store its direction and class. Suppressed flips do not update it.
Calculation: Node flow = For each profile bin index, maintain buy volume, sell volume and touch count, initially zero. On each completed bar with a nonzero profile bin width, multiply all three accumulators by a configured decay factor. Map the bar's low and high to clamped bin indices in the current profile. For each index in that inclusive range, count a touch if the bin center lies within the bar's low-high range or its distance from close is <= the greater of a configured ATR multiple and a configured minimum price increment multiple. For each touched bin, add one to its touch count and add respectively volume * max((close - open) / max(high - low, configured minimum price increment), 0) and volume * max((open - close) / max(high - low, configured minimum price increment), 0) divided by the number of indices in that range to its buy and sell accumulators. Accumulators remain attached to their bin indices as the profile moves. For each of POC, VAH and VAL, select its clamped current bin index and calculate net flow = (buy - sell) / max(buy + sell, 1). A node is absorbed when its touch count >= a configured threshold AND absolute net flow <= a configured neutral threshold.
Long: Control state = bullish, when control-state markings are enabled.
Short: Control state = bearish, when control-state markings are enabled.
Long: A bullish control change occurs AND its direction and class differ from the last shown flip AND (its class = reversion OR its class = in-value AND in-value flips are enabled OR its class = breakout AND (the extension filter is disabled OR VAH - POC <= 0 OR close - VAH <= a configured fraction of VAH - POC)).
Short: A bearish control change occurs AND its direction and class differ from the last shown flip AND (its class = reversion OR its class = in-value AND in-value flips are enabled OR its class = breakout AND (the extension filter is disabled OR POC - VAL <= 0 OR VAL - close <= a configured fraction of POC - VAL)).
Long: For any defined POC, VAH or VAL node, net flow > the configured neutral threshold AND the node is not absorbed.
Short: For any defined POC, VAH or VAL node, net flow < negative the configured neutral threshold AND the node is not absorbed.
