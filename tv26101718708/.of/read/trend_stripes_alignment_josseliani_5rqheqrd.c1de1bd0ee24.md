Calculation: Trend state = for each of two independently configured series, initialize to 0 and retain its previous state unless a new direction is confirmed. For a two-MA series, set it to 1 when the shorter MA > the longer MA AND their absolute separation >= ATR times a threshold AND the longer MA > its value a specified number of series bars ago; set it to -1 when the shorter MA < the longer MA AND their absolute separation >= ATR times the threshold AND the longer MA < its value the same number of series bars ago. For a single-MA series, set it to 1 when close > EMA and -1 when close < EMA. Use the chart timeframe or a higher timeframe for each series; on a higher timeframe use the last completed bar. Auto configurations use close-based EMAs; custom configurations use a selectable source and MA method and two MAs.
Calculation: Alignment = 1 when both trend states = 1, -1 when both = -1, otherwise 0.
Calculation: Setup and retest state = initialize both directional first-signal arms and retest-ready flags false. When the higher-series state reverses from -1 to 1 or from 1 to -1, block new setups in its new direction until the other series has been in that direction, then in the opposite direction, then returns to the new direction; cancel the block if the higher-series state changes again. When the other series changes to the higher-series direction and that direction is not blocked, arm its first signal and clear the opposite first-signal arm and both retest-ready flags. Clear a direction's arm and retest-ready flag whenever alignment is not in that direction. A first signal clears its arm and retest-ready flag. After evaluating signals, if a first signal occurred or a ready retest touched the entry EMA and passed its candle and filters, clear that direction's retest-ready flag; otherwise set it when alignment is in that direction, its first-signal arm is false, and high >= entry EMA + ATR times a distance threshold for long or low <= entry EMA - ATR times that threshold for short. Evaluate retest readiness using its value before this update.
Calculation: Directional body fraction = for a nonzero candle body, the fraction of the body above the entry EMA for long or below it for short, clipped to the range from 0 to 1; for a zero body it is 0. The entry EMA uses chart-timeframe close.
Calculation: Signed extension = (close - reference MA) / ATR, or 0 when ATR <= 0. The reference MA uses a selectable chart-timeframe source and MA method. Extension percentile is the percentile rank of the absolute signed extension over a configurable chart-bar lookback.
Calculation: Activity percentile = percentile rank of ATR over a configurable lookback, using the chart timeframe or a higher timeframe; for a higher timeframe use the last completed bar.
Calculation: Trend separation = absolute difference between the two values defining the higher-series trend divided by that series' ATR, or 0 when ATR <= 0. When the higher-series trend uses close versus one EMA, use those two values; in the auto configuration with a higher-series single EMA and a chart-series MA pair, instead use the chart-series MA pair and chart ATR. Higher-timeframe inputs use the last completed bar.
Long: Either trend state = 1.
Short: Either trend state = -1.
Long: Alignment = 1 AND close > open AND directional body fraction >= body threshold AND (signed extension <= 0 OR extension percentile is unavailable OR extension percentile < maximum extension percentile) AND (activity percentile is unavailable OR activity percentile >= minimum activity percentile) AND trend separation >= minimum separation AND (long first-signal arm = true OR (long retest-ready flag = true AND low <= entry EMA)).
Short: Alignment = -1 AND close < open AND directional body fraction >= body threshold AND (signed extension >= 0 OR extension percentile is unavailable OR extension percentile < maximum extension percentile) AND (activity percentile is unavailable OR activity percentile >= minimum activity percentile) AND trend separation >= minimum separation AND (short first-signal arm = true OR (short retest-ready flag = true AND high >= entry EMA)).
