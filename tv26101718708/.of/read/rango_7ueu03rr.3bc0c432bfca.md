Calculation: Regression channel = for source series x and lookback n, let slope be the linear-regression fitted value at offset 0 minus that at offset 1, mean be SMA(x, n), intercept = mean - slope × floor(n/2) + (1 - (n mod 2)) × slope/2, middle = intercept + slope × (n - 1), deviation = sqrt(sum over i = 0 to n - 1 of (x[i] - (slope × (n - i) + intercept))² / n), upper = middle + deviation multiplier × deviation, and lower = middle - deviation multiplier × deviation. Use the main lookback for the main channel and a shorter lookback for the short channel.
Calculation: Range state = let weighted mean be sum(close[i] × weight[i]) / sum(weight[i]) over the range lookback, where weight[i] = abs(close[i] - close[i+1]) / close[i+1]; omit terms with missing values or zero close[i+1], and use current close if the weight sum is zero. Let volatility be the standard deviation of close changes, and its average be its SMA over the same lookback. Range width = ATR × base multiplier × clamp(volatility / average volatility, lower bound, upper bound) when adaptive mode is enabled; use a ratio of 1 if average volatility is zero, and omit the adaptive factor when disabled. The range is active when its width is positive, enough range-lookback bars exist, and every close in that lookback is within the width of the current weighted mean. When the range first becomes active, fix its upper and lower boundaries at weighted mean plus and minus width until the next activation.
Calculation: Support and resistance levels = maintain an initially empty ordered list, adding levels only on the last dataset bar when support/resistance analysis is enabled. In order, add newly activated range upper and lower boundaries with resistance and support types and fixed strength; confirmed pivot high and low prices with resistance and support types and strength equal to the greater of one and the count of prior closes within a tolerance of the pivot over a lookback; main and shorter-channel upper and lower boundaries with resistance and support types and their respective fixed strengths; and, when enabled, Fibonacci fractions of the main channel width above its lower boundary as neutral levels with their respective fixed strengths. If a new price is within a matching tolerance of the first existing level, retain that level's price and type and replace its strength with the greater strength; otherwise append the new level. Add range, channel, and Fibonacci levels only when their respective features are enabled.
Calculation: Bull and bear states = initialize both false and the last accepted signal bar index to zero. On each bar, compute both candidates using the same pre-update cooldown: the current bar index minus the last accepted signal bar index must be at least the cooldown. A bullish candidate requires close > current main upper boundary AND previous close <= current main upper boundary, OR an active range AND close > fixed range upper boundary AND previous close <= that boundary, OR signals enabled AND a resistance level with strength at least the threshold AND close > that level AND previous close <= that level. A bearish candidate uses close < current main lower boundary AND previous close >= current main lower boundary, OR an active range AND close < fixed range lower boundary AND previous close >= that boundary, OR signals enabled AND a support level with strength at least the threshold AND close < that level AND previous close >= that level. Accept a candidate when the cooldown passes and volume confirmation is disabled or volume / SMA(volume) >= its threshold; use a ratio of 1 when the SMA is not positive. An accepted candidate sets its corresponding state true and updates the last accepted signal bar index. After processing both candidates and pullback states, reset the bull state and bullish pullback state when the range is inactive AND (close <= main lower boundary OR close >= main upper boundary × upper reset multiplier); reset the bear state and bearish pullback state when the range is inactive AND (close >= main upper boundary OR close <= main lower boundary × lower reset multiplier).
Calculation: Pullback states = initialize both false. Before the state resets on each bar, set the bullish pullback state true when the bull state is true AND close <= main middle boundary AND close > main lower boundary; set the bearish pullback state true when the bear state is true AND close >= main middle boundary AND close < main upper boundary. Each remains true until its corresponding state reset.
Long: Bull state = true AND previous bull state = false.
Short: Bear state = true AND previous bear state = false.
Long: Bullish pullback state = true AND previous bullish pullback state = false.
Short: Bearish pullback state = true AND previous bearish pullback state = false.
Long: Range active AND close > fixed range upper boundary AND previous close <= fixed range upper boundary.
Short: Range active AND close < fixed range lower boundary AND previous close >= fixed range lower boundary.
Long: Main channel slope < 0 AND close > main upper boundary.
Short: Main channel slope > 0 AND close < main lower boundary.
Long: Main channel slope > 0.
Short: Main channel slope < 0.
