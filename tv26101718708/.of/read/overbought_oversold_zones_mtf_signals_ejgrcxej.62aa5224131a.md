Calculation: Pressure index = EMA of the weighted sum of persistence and displacement, with persistence weighted more heavily. The baseline is SMA(close) minus close standard deviation over the same lookback multiplied by a volatility coefficient. The coefficient is a clamped affine function of short-term ATR divided by longer-term ATR; use a ratio of 1 when either ATR is unavailable or the longer-term ATR is not positive. Persistence is the average, over its lookback, of clamp((close − baseline) / short-term ATR, 0, a positive cap) / cap; contribute 0 for bars with unavailable baseline or nonpositive or unavailable ATR. Displacement is (clamp((close − baseline) / short-term ATR, −a positive cap, the same positive cap) + cap) / (2 × cap). Calculate persistence and displacement only when the current baseline and positive short-term ATR are available; require the baseline and persistence lookbacks to have started. Return the smoothed index only when the current unsmoothed index is available.
Long: Chart-timeframe pressure index <= oversold threshold.
Short: Chart-timeframe pressure index >= overbought threshold.
Long: Chart-timeframe pressure index <= oversold threshold AND previous chart bar's pressure index > oversold threshold.
Short: Chart-timeframe pressure index >= overbought threshold AND previous chart bar's pressure index < overbought threshold.
Long: Chart-timeframe pressure index > oversold threshold AND pressure index <= lower directional threshold.
Short: Chart-timeframe pressure index >= upper directional threshold AND pressure index < overbought threshold.
Long: Last completed higher-timeframe bar's pressure index <= oversold threshold OR last completed higher-timeframe bar's pressure index > oversold threshold AND pressure index <= lower directional threshold.
Short: Last completed higher-timeframe bar's pressure index >= overbought threshold OR last completed higher-timeframe bar's pressure index >= upper directional threshold AND pressure index < overbought threshold.
Long: A chart-timeframe oversold phase is active AND the number of consecutive bars since pressure index was last <= oversold threshold > gap-tolerance parameter; activate the phase when pressure index <= oversold threshold and deactivate it after this decision.
Short: A chart-timeframe overbought phase is active AND the number of consecutive bars since pressure index was last >= overbought threshold > gap-tolerance parameter; activate the phase when pressure index >= overbought threshold and deactivate it after this decision.
