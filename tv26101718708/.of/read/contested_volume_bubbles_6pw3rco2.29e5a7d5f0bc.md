Calculation: Estimated buy and sell volume = for each completed lower-timeframe bar within the completed chart bar, allocate volume to buy as volume × (close − low) / (high − low) and to sell as volume × (high − close) / (high − low); if high = low, allocate half to each unless flat bars are skipped. Sum each allocation across the chart bar. If lower-timeframe sampling is disabled or unavailable, apply the same allocation to the chart bar; when lower-timeframe data is required and sampling is enabled, suppress decisions if no lower-timeframe bars are available.
Calculation: Contested volume = minimum of estimated buy and sell volume; net delta = estimated buy volume − estimated sell volume.
Calculation: Standard trigger source = EMA of contested volume. Standard activity condition = trigger source > 0 AND highest trigger source over the preceding trigger lookback > lowest trigger source over the preceding trigger lookback AND (activity floor = 0 OR trigger source >= activity floor × SMA of trigger source over the activity lookback).
Calculation: Time-of-day baseline = mean of the available prior-session EMAs of log(1 + contested volume) for the current clock slot and its adjacent slots, clamping adjacent slots at the day boundaries. Update the current slot's EMA only after calculating the current bar's baseline. Raw residual = log(1 + contested volume) − baseline. Session adjustment = session-strength parameter × count / (count + shrinkage parameter) × mean of prior current-session raw residuals clamped to a symmetric configured range; reset the count and mean at the start of each day. Time-of-day trigger source = raw residual − session adjustment, replacing missing values with zero. Time-of-day activity condition = contested volume > 0 AND prior observations of the current slot >= warm-up parameter AND no raw residual is missing in the trigger lookback AND (activity floor = 0 OR contested volume >= activity floor × (exp(baseline) − 1)).
Calculation: Trigger = on a completed chart bar, use the time-of-day trigger source and activity condition when time-of-day normalization is selected and available; otherwise use the standard trigger source and activity condition. The trigger is true when the selected activity condition is true AND the percentile rank of the selected trigger source over the trigger lookback >= the trigger percentile. Time-of-day normalization is available on eligible intraday time-based charts.
Long: Trigger = true AND net delta >= 0
Short: Trigger = true AND net delta < 0
