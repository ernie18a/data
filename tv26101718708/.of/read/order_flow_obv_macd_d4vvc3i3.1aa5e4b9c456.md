Calculation: Cumulative flow = cumulative sum of sign(close - previous close) * volume.
Calculation: Transformed flow = EMA of (high + shadow if shadow > 0, otherwise low + shadow), where shadow = (cumulative flow - SMA(cumulative flow)) / standard deviation(cumulative flow - SMA(cumulative flow)) * standard deviation(high - low). The two standard deviations use the same lookback; the SMA may use a different lookback.
Calculation: Fast flow average = a selectable EMA, DEMA, TEMA, TDEMA, TTEMA, THMA, ZLEMA, ZLDEMA, ZLTEMA, DZLEMA, TZLEMA, LLEMA, NMA, or average of TTEMA and TDEMA of transformed flow. DEMA(x) = 2 EMA(x) - EMA(EMA(x)); TEMA(x) = 3 EMA(x) - 3 EMA(EMA(x)) + EMA(EMA(EMA(x))). TDEMA, TTEMA, and THMA apply the TEMA combination to three successive DEMA, TEMA, or HMA applications. ZLEMA, ZLDEMA, and ZLTEMA apply the respective average to 2x - x[round((length - 1)/2)]. DZLEMA and TZLEMA apply the DEMA and TEMA combinations to successive ZLEMA applications. LLEMA = EMA(0.25x + 0.5x[1] + 0.25x[2]). NMA = (1 + alpha) EMA(x, length1) - alpha EMA(EMA(x, length1), length2), where alpha = (length1 / length2) * (length1 - 1) / (length1 - length1 / length2).
Calculation: Flow MACD = fast flow average - slow close average. The slow close average is either EMA(close) or an adaptive EMA initialized to close and updated as alpha * close + (1 - alpha) * previous adaptive EMA, where alpha = 2 / (effective length + 1), effective length = max(1, base length * (1 + strength * (1 - 2 * min(1, abs(previous confidence) / 50)))), and initial previous confidence is 0.
Calculation: Channel projection = the fitted value at the newest bar of a linear regression of flow MACD over the slope lookback.
Calculation: Channel direction = initialize channel line and direction to 0; on each bar, threshold = cumulative sum of abs(channel projection - previous channel line) divided by the number of elapsed bars since the first bar. Replace the channel line with the projection when the projection is strictly above previous channel line + threshold or strictly below previous channel line - threshold; otherwise retain the previous line. Set direction to 1 when the line increases, -1 when it decreases, and otherwise retain the previous direction. If the previous line is unavailable, use the current projection in its place.
Calculation: Confidence = 50 * (MACD weight * MACD direction + channel weight * channel direction) / (MACD weight + channel weight + 1), when footprint data is unavailable. MACD direction is sign(flow MACD). Each weight is the SMA over the same lookback of 0.5 if the component's previous direction or current sign(close - previous close) is zero, 1 if those directions agree, and 0 otherwise; use 0.5 when the SMA is unavailable. This includes the two neutral footprint-related components, each with weight 0.5.
Calculation: Running projection high = reset to channel projection whenever the current projection is the highest over the pivot lookback; otherwise retain the previous running high, initializing it to the current projection when unavailable, then replace it with the current projection if that is higher.
Calculation: Running projection low = reset to channel projection whenever the current projection is the lowest over the pivot lookback; otherwise retain the previous running low, initializing it to the current projection when unavailable, then replace it with the current projection if close is below the running low or the current projection is below the running low.
Long: channel direction = 1
Short: channel direction != 1
Long: channel direction > previous channel direction
Short: channel direction < previous channel direction
Long: confidence >= 0
Short: confidence < 0
Long: running projection low = running projection low 2 bars ago AND running projection low 2 bars ago != running projection low 3 bars ago
Short: running projection high = running projection high 2 bars ago AND running projection high 2 bars ago != running projection high 3 bars ago
