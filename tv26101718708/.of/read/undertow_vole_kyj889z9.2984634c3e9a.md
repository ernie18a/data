Calculation: Engine candles = either chart OHLC or Heikin Ashi OHLC, selected consistently for all calculations and candle filters.
Calculation: Effective volume = volume when nonzero; otherwise the absolute value of the most recent engine close minus open whose absolute value is at least the tick-size parameter, divided by that parameter. Initialize the retained difference to the tick-size parameter.
Calculation: Loud and quiet volume indices = initialize each to 1; on each bar multiply the loud index by 1 + engine close return when effective volume exceeds its previous value, and multiply the quiet index by 1 + engine close return when effective volume is below its previous value. Otherwise retain the respective index. Use return 0 when the previous close is zero or unavailable, and previous effective volume 0 when unavailable.
Calculation: Loud and quiet oscillators = 100 times the respective index minus its EMA, divided by the highest minus lowest value of that EMA over a longer lookback; use 0 when the range is zero. Use the same EMA and range lengths for both indices.
Calculation: Band oscillator = 100 times engine close minus its SMA, divided by twice a band-width parameter times the standard deviation of engine close over the same lookback; use 0 when the denominator is zero.
Calculation: Stochastic component = SMA of 100 times engine close minus the lowest engine low, divided by the highest engine high minus the lowest engine low over the same lookback; use 50 when the range is zero.
Calculation: Trend = (RSI of engine close + MFI using engine close and original volume + band oscillator + stochastic component / 3) / 2. Use the same lookback for RSI and MFI and substitute 50 for unavailable MFI.
Calculation: Crowd = trend + loud oscillator. Trend average = EMA of trend.
Calculation: Guard state = initially neutral; after each filtered long or short event, set it to that event's side, including events on an untracked side. If the optional guard is enabled, an event is filtered out when the state already equals its side.
Long: Quiet oscillator crosses above trend average AND quiet oscillator > 0 AND crowd < 0 AND (candle filter disabled OR engine close > engine open) AND (guard disabled OR guard state is not long).
Short: Quiet oscillator crosses below 0 AND crowd > trend AND crowd > trend average AND (strength filter disabled OR quiet oscillator < trend average) AND (candle filter disabled OR engine close < engine open) AND (guard disabled OR guard state is not short).
