Calculation: Upside breakout = close crosses above the tracked high AND volume exceeds its moving average times a multiplier AND close > open; tracked high is the prior bar’s rolling highest high and updates when the rolling highest high changes
Calculation: Downside breakdown = close crosses below the tracked low; tracked low is the prior bar’s rolling lowest low and updates when the rolling lowest low changes
Calculation: Stage moving average = simple moving average of close; slope = current stage moving average − previous stage moving average
Calculation: Rising slope = current and preceding three slopes > 0; falling slope = current and preceding three slopes < 0; flattening slope = range of the four latest slopes < 5% of the moving average of high − low
Calculation: Market stage = persistent state initialized to stage 1; in stage 1, change to stage 2 on upside breakout with close above the stage moving average; in stage 2, change to stage 3 if (close < stage moving average AND flattening slope) OR (downside breakdown AND slope ≤ 0), otherwise change to stage 4 if downside breakdown AND close < stage moving average AND falling slope; in stage 3, change to stage 4 if downside breakdown OR (close < stage moving average AND falling slope), otherwise change to stage 2 if upside breakout AND close > stage moving average AND rising slope; in stage 4, change to stage 1 if close > stage moving average AND flattening slope AND NOT falling slope
Calculation: Stage transition = market stage differs from its previous-bar value
Calculation: Bullish base event = an upside breakout after the minimum base width; on transition into stage 2, set base count to 1 and signal base 1; while in stage 2 with a positive base count, signal the next base when the close is at least the required percentage above the last breakout close, then update the last breakout close and base count
Calculation: Bearish base event = stage transition into stage 4 OR downside breakdown, when base count is positive; reset base count and last breakout close on either condition
Long: stage transition into stage 1 OR stage transition into stage 2 OR bullish base event
Short: stage transition into stage 3 OR stage transition into stage 4 OR bearish base event
