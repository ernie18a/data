Calculation: Bullish gap = [high two bars ago, current low] when current low > high two bars ago; bearish gap = [current high, low two bars ago] when current high < low two bars ago. A gap is valid when its height >= a minimum-size multiple of the previous bar's ATR, provided that ATR exists.
Calculation: Gap memory = independently for the chart timeframe and a higher timeframe, retain valid gap intervals in insertion order. Before processing each new bar, remove oldest intervals while their age exceeds the memory limit or the interval count exceeds the memory cap. Record the first bar whose close is below a bullish interval's bottom or above a bearish interval's top; remove the interval when the bars since that breach exceed the pairing window. For each new valid gap, scan retained intervals oldest first. If an opposite-direction interval overlaps the remaining new-gap interval by a positive amount AND the intersection of their full original gaps has height >= the minimum-size multiple of the previous bar's ATR, record an inversion and subtract the overlap from both intervals. Retain old interval remnants at least as tall as the previous bar's ATR multiplied by the larger of the minimum-size multiplier and a separate minimum-remnant multiplier; remnants inherit the original gap and breach time. If subtraction splits the new interval, retain only its upper part. Stop pairing when the new interval is exhausted or smaller than the minimum-remnant height; otherwise remember its remainder with the full new gap as its original extent. Process the higher-timeframe memory once on the first confirmed chart bar of each new higher-timeframe bar, using the last completed higher-timeframe bar and earlier higher-timeframe bars.
Long: A valid bullish chart-timeframe gap has no inversion OR a valid bullish gap produces an inversion on the chart timeframe OR a valid bullish gap produces an inversion using the last completed higher-timeframe bar.
Short: A valid bearish chart-timeframe gap has no inversion OR a valid bearish gap produces an inversion on the chart timeframe OR a valid bearish gap produces an inversion using the last completed higher-timeframe bar.
