Calculation: Session reference = at the start of any enabled session, store the high and low of the last completed higher-timeframe bar; retain them until the next enabled session starts. The active session is the most recently started enabled session; if several start on the same bar, use the last one in configured session order. Reset all sweep, entry, breakout, and trap flags and consecutive-close counts when a new session starts with a valid reference. A reference is valid when its high is greater than its low.
Calculation: Volume filter = disabled OR volume > SMA(volume) × volume multiplier.
Calculation: Low sweep = valid reference AND active session AND low < session reference low AND volume filter AND (wick-only mode OR close > session reference low). Record the first low sweep since the last reset, including the current bar.
Calculation: High sweep = valid reference AND active session AND high > session reference high AND volume filter AND (wick-only mode OR close < session reference high). Record the first high sweep since the last reset, including the current bar.
Long: Low sweep AND no earlier low sweep since the last reset.
Short: High sweep AND no earlier high sweep since the last reset.
Long: A low sweep has been recorded since the last reset AND close > highest high of the preceding delivery-shift lookback bars AND (one sweep entry per side is disabled OR no prior long sweep entry since the last reset).
Short: A high sweep has been recorded since the last reset AND close < lowest low of the preceding delivery-shift lookback bars AND (one sweep entry per side is disabled OR no prior short sweep entry since the last reset).
Long: Breakout model enabled AND valid reference AND active session AND close > session reference high for at least the configured number of consecutive chart bars since the last reset AND (displacement filter disabled OR abs(close - open) >= ATR × displacement multiplier) AND volume filter AND (one breakout per side is disabled OR no prior long breakout since the last reset).
Short: Breakout model enabled AND valid reference AND active session AND close < session reference low for at least the configured number of consecutive chart bars since the last reset AND (displacement filter disabled OR abs(close - open) >= ATR × displacement multiplier) AND volume filter AND (one breakout per side is disabled OR no prior short breakout since the last reset).
Long: Trap model enabled AND valid reference AND active session AND a close below the session reference low occurred during the active session since the last reset AND close > session reference low AND no prior long trap since the last reset.
Short: Trap model enabled AND valid reference AND active session AND a close above the session reference high occurred during the active session since the last reset AND close < session reference high AND no prior short trap since the last reset.
