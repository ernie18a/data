Calculation: Moving averages = Independently select SMA, EMA, WMA, RMA, HMA, VWMA, TEMA, KAMA, or JMA and a source from open, high, low, close, (high + low)/2, (high + low + close)/3, or (open + high + low + close)/4. Calculate each average on the chart timeframe or an independently selected higher or lower timeframe. For historical chart bars, use the last completed higher-timeframe bar, including one completing with the chart bar, or the last lower-timeframe bar within the chart bar.
Calculation: KAMA = Let efficiency be abs(source - source n bars ago) divided by the sum of absolute one-bar source changes over n bars, or zero if that sum is zero. Let smoothing be (efficiency × (fast EMA coefficient - slow EMA coefficient) + slow EMA coefficient) squared. Initialize KAMA to source; thereafter KAMA = previous KAMA + smoothing × (source - previous KAMA).
Calculation: JMA = Let phase ratio = phase / 100 + 1.5, beta = 0.45 × (length - 1) / (0.45 × (length - 1) + 2), and alpha = beta raised to power. Initialize previous e0, e1, e2, and JMA to zero. On each bar, e0 = (1 - alpha) × source + alpha × previous e0; e1 = (source - e0) × (1 - beta) + beta × previous e1; e2 = (e0 + phase ratio × e1 - previous JMA) × (1 - alpha) squared + alpha squared × previous e2; JMA = previous JMA + e2.
Calculation: Band state for a pair of series = Initialize to zero. On each chart bar, set state to 1 if the first series minus the second exceeds a configurable multiple of chart-timeframe ATR, to -1 if the difference is below the negative of that band, and otherwise retain the previous state. If the difference is unavailable, retain the previous state. Maintain separate state for each pair.
Long: For any enabled moving average, close crosses above that average, defined as current close > current average AND previous close <= previous average; OR, with the optional noise band enabled, its close-versus-average band state changes from -1 to 1.
Short: For any enabled moving average, close crosses below that average, defined as current close < current average AND previous close >= previous average; OR, with the optional noise band enabled, its close-versus-average band state changes from 1 to -1.
Long: For any enabled crossover pair or selected golden-cross pair, the designated fast moving average crosses above the designated slow moving average, defined as fast > slow AND previous fast <= previous slow; OR, with the optional noise band enabled, their band state changes from -1 to 1. The pair's averages are independently configurable and the designated fast average need not have a shorter lookback.
Short: For any enabled crossover pair or selected death-cross pair, the designated fast moving average crosses below the designated slow moving average, defined as fast < slow AND previous fast >= previous slow; OR, with the optional noise band enabled, their band state changes from 1 to -1.
Long: At least two available included moving averages, sorted by increasing lookback length multiplied by their timeframe duration, have each faster average strictly above the next slower average.
Short: At least two available included moving averages, sorted by increasing lookback length multiplied by their timeframe duration, have each faster average strictly below the next slower average.
Long: The first of a selected pair of moving averages is greater than or equal to the second.
Short: The first of a selected pair of moving averages is less than the second.
