Calculation: Ichimoku lines = the short-lookback and longer-lookback midpoints of their respective rolling highest high and lowest low; span A is their average, and span B is the midpoint of the highest high and lowest low over a still longer lookback. The displayed cloud uses both spans from the longer-lookback number of bars ago.
Calculation: Bullish Ichimoku tests = close above both displayed cloud spans; short-lookback midpoint crosses above longer-lookback midpoint; close above the high from the longer-lookback number of bars ago. Bearish tests use close below both spans, a cross below, and close below the corresponding past low.
Long: RSI >= bullish threshold
Short: RSI <= bearish threshold
Long: displayed cloud span A > displayed cloud span B
Short: displayed cloud span A <= displayed cloud span B
Long: at least two bullish Ichimoku tests are true
Short: at least two bearish Ichimoku tests are true AND fewer than two bullish Ichimoku tests are true
Long: close > previous close AND (close - previous close) / ATR >= impulse threshold AND previous open != previous close AND count of previously created bullish order blocks < maximum bullish order-block count
Short: close < previous close AND (previous close - close) / ATR >= impulse threshold AND previous open != previous close AND count of previously created bearish order blocks < maximum bearish order-block count
Long: low - high from two bars ago > minimum gap size in ATR multiples * ATR
Short: low from two bars ago - high > minimum gap size in ATR multiples * ATR
