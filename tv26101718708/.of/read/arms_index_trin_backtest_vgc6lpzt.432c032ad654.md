Calculation: Arms Index (TRIN) = (advancing issues / declining issues) / (advancing volume / declining volume), using closes from the higher-timeframe bar still forming
Calculation: Trade signal = -1 when TRIN > upper band, +1 when TRIN < lower band, otherwise retain the previous value (initially 0); swap +1 and -1 when reverse is enabled
Long: Trade signal = +1
Short: Trade signal = -1
