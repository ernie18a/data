Calculation: decision score = +2 if short-term EMA > longer-term EMA AND close > medium-term EMA; otherwise -2 if short-term EMA < longer-term EMA AND close < medium-term EMA; otherwise 0; +1 if close > long-term EMA, otherwise -1 if close < long-term EMA, otherwise 0; +2 if MACD line > signal line AND MACD histogram > 0, otherwise -2 if MACD line < signal line AND MACD histogram < 0, otherwise 0; +1 if MACD line crosses above signal line, otherwise -1 if MACD line crosses below signal line, otherwise 0; +1 if RSI > its midpoint threshold, otherwise -1 if RSI < its lower threshold, otherwise 0; +1 if ADX >= its trend threshold AND +DI > -DI, otherwise -1 if ADX >= its trend threshold AND -DI > +DI, otherwise 0; +1 if volume > its moving average AND close > open, otherwise -1 if volume > its moving average AND close < open, otherwise 0; +1 if higher-timeframe close > its EMA, otherwise -1 if higher-timeframe close < its EMA, otherwise 0. Use a higher timeframe's last completed bar; EMA lengths are ordered short-term, medium-term, then long-term, and MACD fast length is shorter than its slow length.
Long: MACD line crosses above signal line OR decision score >= 5 AND prior bar's decision score < 5
Short: MACD line crosses below signal line OR decision score <= -5 AND prior bar's decision score > -5
