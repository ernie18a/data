Calculation: Delta = For each requested timeframe, volume × (2 × close − high − low) ÷ (high − low); use 0 when high = low. Use the current requested-timeframe bar, which may still be forming; the requested timeframe may be higher or lower than the chart timeframe.
Long: For each requested timeframe, close ≥ open
Short: For each requested timeframe, close < open
Long: For each requested timeframe, Delta ≥ 0
Short: For each requested timeframe, Delta < 0
