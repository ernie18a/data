Calculation: Filtered close = initialize state to the first close and error to 1; on each bar set error = prior error + noise parameter, gain = error / (error + disturbance parameter), state = prior state + gain * (close - prior state), and error = (1 - gain) * error. Its slope is state minus prior state, or 0 on the first bar.
Calculation: Efficiency = SMA of squared correlation between close and bar index. Its threshold is the SMA of efficiency plus a parameter times its standard deviation, both over the same lookback as the correlation. Initialize the efficiency gate as false; set it true when efficiency > threshold, then set it false when efficiency < threshold times a hysteresis factor. Otherwise retain its previous state.
Calculation: Chop = 1 - abs(close - close one chop lookback ago) / sum of abs(close - previous close) over that lookback; use 1 if the denominator is 0.
Calculation: Regime = bullish if the efficiency gate is true AND chop <= its threshold AND filtered-close slope >= 0; bearish if the efficiency gate is true AND chop <= its threshold AND filtered-close slope < 0; otherwise ranging.
Calculation: Laguerre RSI = set gamma = 1 - alpha; initialize four levels to 0 and update them in order: L0 = alpha * close + gamma * previous L0; L1 = -gamma * L0 + previous L0 + gamma * previous L1; L2 = -gamma * L1 + previous L1 + gamma * previous L2; L3 = -gamma * L2 + previous L2 + gamma * previous L3. Sum positive differences L0-L1, L1-L2, L2-L3 as gains and the absolute values of negative differences as losses. Return 100 * gains / (gains + losses), or the neutral midpoint if the denominator is 0.
Calculation: Smoothed momentum = apply this JMA to Laguerre RSI: for period p, phase and power parameters, set phase factor = clamp(phase * 0.01 + 1.5, 0.5, 2.5), beta = power * (p - 1) / (power * (p - 1) + 2), exponent = max(max(log2(sqrt(0.5 * (p - 1))) + 2, 0) - 2, 0.5), and alpha = beta raised to (1 / exponent). Initialize m and output to the first input and d0 and d1 to 0. Thereafter update in order: m = input + alpha * (previous m - input); d0 = (input - m) * (1 - beta) + beta * previous d0; d1 = (m + phase factor * d0 - previous output) * (1 - alpha)^2 + alpha^2 * previous d1; output = previous output + d1.
Calculation: Cumulative volume delta = cumulative sum of volume when close > open, negative volume when close < open, and 0 otherwise. Its slope is its EMA minus the prior EMA, or 0 on the first bar.
Calculation: Smoothed ATR = 2 * EMA(ATR) - EMA(EMA(ATR)), with the same smoothing length for both EMAs. Stop and target distances are separate multipliers of smoothed ATR at the entry signal bar; their price levels use that bar's close and remain fixed.
Long: regime = bullish.
Short: regime = bearish.
Long: cumulative volume delta slope > 0.
Short: cumulative volume delta slope <= 0.
Long: position side = flat AND regime = bullish AND smoothed momentum > bullish entry threshold AND cumulative volume delta slope > 0 AND volume / volume SMA >= minimum volume ratio AND (session filter disabled OR bar time within configured session) AND bars since last exit >= cooldown.
Short: position side = flat AND regime = bearish AND smoothed momentum < bearish entry threshold AND cumulative volume delta slope < 0 AND volume / volume SMA >= minimum volume ratio AND (session filter disabled OR bar time within configured session) AND bars since last exit >= cooldown.
Exit: long, low <= entry signal close - stop distance OR high >= entry signal close + target distance OR regime != bullish OR smoothed momentum < long exit threshold.
Exit: short, high >= entry signal close + stop distance OR low <= entry signal close - target distance OR regime != bearish OR smoothed momentum > short exit threshold.
