Calculation: Assigned price = start at zero; on each chart bar, set the upper and lower source prices to close and close, max(open, close) and min(open, close), or high and low, according to the selected price source. Set the assignment distance to a fixed price amount, ATR, or close divided by a parameter. If the upper source price exceeds the previous assigned price plus the distance, use the upper source price; otherwise, if the lower source price is below the previous assigned price minus the distance, use the lower source price; otherwise retain the previous assigned price.
Calculation: Wave direction = +1 if assigned price rises, -1 if it falls, otherwise retain the previous direction, initially zero. A wave begins when direction changes and ends immediately before the next change.
Calculation: Wave effort = cumulative volume since the wave began; optionally use true range instead of volume, or use true range only when volume is unavailable.
Calculation: Wave result = absolute difference between the wave's starting price and its extreme. For an up-wave, starting price is min(open, close) on its first bar and extreme is the highest max(open, close) in the wave; for a down-wave, starting price is max(open, close) and extreme is the lowest min(open, close).
Calculation: Effort state and result state = compare each current wave measurement with the preceding completed same-direction wave: percentage change at least the material-change threshold gives +1; otherwise percentage change at most the negative threshold gives -1; otherwise give 0. Missing or zero previous measurements give 0.
Long: Wave direction = +1 OR (wave direction = -1 AND result state = -1 AND effort state != 0) OR (wave direction = -1 AND wave has completed AND effort state = +1 AND result percentage increase from the preceding completed down-wave >= climax-extension threshold)
Short: Wave direction = -1 OR (wave direction = +1 AND result state = -1 AND effort state != 0) OR (wave direction = +1 AND wave has completed AND effort state = +1 AND result percentage increase from the preceding completed up-wave >= climax-extension threshold)
