Calculation: Session open = open of the first bar of the current trading session; retain it until the next session starts.
Calculation: Previous session high, low, and close = high, low, and final close of the most recently completed trading session; update them when that session ends.
Calculation: Gap direction = compare the session open with the previous session close at the start of the session; retain this comparison until the next session starts.
Calculation: Normalized gap = absolute difference between the session open and previous session close at the start of the session, divided by ATR of the last completed higher-timeframe bar; retain this value until the next session starts. The ATR must be available and greater than zero.
Long: (Gap direction is down AND (normalized gap < smallest threshold OR (normalized gap < middle threshold AND session open >= previous session low AND session open <= previous session high))) OR (gap direction is up AND (normalized gap >= largest threshold OR (normalized gap >= middle threshold AND (session open < previous session low OR session open > previous session high))))
Short: (Gap direction is up AND (normalized gap < smallest threshold OR (normalized gap < middle threshold AND session open >= previous session low AND session open <= previous session high))) OR (gap direction is down AND (normalized gap >= largest threshold OR (normalized gap >= middle threshold AND (session open < previous session low OR session open > previous session high))))
