Calculation: Smoothed relative performance = EMA((current close / close N bars ago − 1) × 100); calculate for the stock and each EGX30, EGX70 EWI, and EGX100 EWI benchmark using the same lookback and smoothing length. Relative strength vs. a benchmark = stock smoothed relative performance − benchmark smoothed relative performance.
Calculation: Rolling trend = initialize segment at close, direction bullish, and slope at zero. Each bar, compare close − segment with ATR × reversal threshold; reverse direction when this distance exceeds the threshold against the current direction. Set fast mode when |close − segment| > ATR × fast threshold, otherwise slow mode. When direction reverses, fast mode changes, or slope is zero, set slope to ATR divided by the fast-mode lookback in fast mode, or the longer slow-mode lookback otherwise. Advance segment by direction × slope.
Long: relative strength vs. EGX30 ≥ 0 OR relative strength vs. EGX70 EWI ≥ 0 OR relative strength vs. EGX100 EWI ≥ 0 OR rolling trend direction is bullish
Short: relative strength vs. EGX30 < 0 OR relative strength vs. EGX70 EWI < 0 OR relative strength vs. EGX100 EWI < 0 OR rolling trend direction is bearish
