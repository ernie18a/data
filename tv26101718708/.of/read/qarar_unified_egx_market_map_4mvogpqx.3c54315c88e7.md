Calculation: Rolling trend = Initialize the trend to bullish, the segment to the first close, the active slope to zero, and fast mode to false. Until ATR is available, set the segment to each bar's close. Thereafter, on each bar, measure the distance from the close to the previous segment. If the trend is bearish and the distance exceeds a reversal threshold times ATR, set the trend to bullish; if the trend is bullish and the negative distance exceeds that threshold times ATR, set it to bearish. Fast mode is active when the absolute distance exceeds a speed threshold times ATR. On a reversal, a change of fast mode, or a zero active slope, reset the active slope to ATR divided by the fast slope length in fast mode or the longer slow slope length otherwise. Update the segment by adding the active slope in a bullish trend or subtracting it in a bearish trend.
