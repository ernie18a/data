Calculation: Structural pivots = a high or low at a candidate bar strictly above or below every other high or low from twice the lookback through one bar ago, excluding the candidate at the lookback; the current bar is excluded. On confirmation, replace the latest pivot of that type and mark it active. A structural break deactivates the broken pivot; a newer pivot reactivates it.
Calculation: Sweep state = before updating pivots, set the bullish state when the previous low is below the active latest pivot low and clear it when the previous close is below that pivot; set the bearish state when the previous high is above the active latest pivot high and clear it when the previous close is above that pivot. The close test takes precedence. A bullish or bearish structural break respectively clears its sweep state. While active, retain the lowest swept low or highest swept high since the state was last cleared.
Calculation: Structural range = initially both bounds are zero. On a bullish structural break, set the lower bound to the retained bullish sweep low if the sweep filter is enabled and that low exists, otherwise to the latest pivot low; set the upper bound to the latest pivot high. On a bearish structural break, set the lower bound to the latest pivot low and the upper bound to the retained bearish sweep high if the sweep filter is enabled and that high exists, otherwise to the latest pivot high. Evaluate both break conditions using the range before either update.
Calculation: Zigzag = use structural pivot detection with an independent lookback. Process a confirmed high before a confirmed low. Append the first pivot; for a same-type pivot, replace the last point only if it is more extreme; for an opposite-type pivot, append it only if its absolute price difference from the last point is at least either a multiple of current ATR or a percentage of current close, according to the selected threshold mode. Keep the latest bounded number of points.
Calculation: ABC structure = the latest three zigzag points A, B, C. A new structure is one whose three point bar indices do not match any retained structure. Add new structures before evaluating invalidation and retain only the latest configured number; an invalidated structure remains retained unless the selected invalidation action deletes it. Same-type zigzag replacement can update points already referenced by a retained structure.
Long: The latest pivot high is active AND the previous close is above it AND, if full-body confirmation is enabled, the previous open is also above it AND, if the sweep filter is enabled, the bullish sweep state is active AND, if the higher-timeframe filter is enabled, the last completed higher-timeframe close is above its simple moving average AND, if the premium/discount filter is enabled and the structural range bounds differ, the previous close is below their midpoint.
Short: The latest pivot low is active AND the previous close is below it AND, if full-body confirmation is enabled, the previous open is also below it AND, if the sweep filter is enabled, the bearish sweep state is active AND, if the higher-timeframe filter is enabled, the last completed higher-timeframe close is below its simple moving average AND, if the premium/discount filter is enabled and the structural range bounds differ, the previous close is above their midpoint.
Long: A new ABC structure has A low, B high, C low AND A price < C price < B price.
Short: A new ABC structure has A high, B low, C high AND A price > C price > B price.
Exit: long, structure invalidation is enabled AND any retained active bullish ABC structure has previous close < A price.
Exit: short, structure invalidation is enabled AND any retained active bearish ABC structure has previous close > A price.
