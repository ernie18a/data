Calculation: Clamp(x, a, b) = min(b, max(a, x)); z(x, n) = 0 if the n-bar standard deviation of x is zero, otherwise clamp((x - SMA(x, n)) / standard deviation(x, n), -3, 3).
Calculation: Sentiment proxies = (1) clamp(z(volume, volume window) × sign(close - open), -3, 3); (2) z(volatility ratio, normalization window), where volatility ratio = ATR(volatility window) / SMA(ATR(volatility window), normalization window) - 1, replacing a zero denominator with 1; (3) clamp((close - close[velocity window]) / (velocity window × ATR(ATR window)), -3, 3), replacing a zero ATR with 1; (4) clamp(2 × (lower wick - upper wick) / bar range, -3, 3), where lower wick = min(open, close) - low, upper wick = high - max(open, close), and a zero bar range is replaced by ATR(ATR window), then by 1 if still zero; (5) clamp(3 × sum(sign(close - previous close), run window) / run window, -3, 3).
Calculation: Sentiment = the EMA of the output of a sequentially trained neural network with five proxy inputs, one hidden layer of configurable size, tanh hidden units and one tanh output. Clamp each tanh input to [-20, 20]. Initialize all biases to zero. Initialize each weight array independently: start its integer state at seed × 2654435761 for input weights and seed × 40503 + 101 for output weights; for each weight add 2654435761 to the state, then set the weight to 0.6 × (random(state) - 0.5), where random(s) is the fractional part of sin((abs(s % 2147483647) + 1) × 12.9898 + 78.233) × 43758.5453. Process only the final training-horizon bars of the dataset. On each completed bar, first append the previous processed bar's five proxies and clamp((close - close[outcome lookback]) / ATR(ATR window), -1, 1) as its target to a FIFO replay buffer capped at 200 samples, replacing a zero ATR with 1. If the buffer is nonempty, perform four sequential stochastic-gradient updates: for step 0 through 3, select index floor(random((bar index × 7919 + step × 104729 + seed) % 2147483647) × buffer size) % buffer size. For each selected sample, calculate output y and hidden activations h; set output gradient e = clamp(y - target, -3, 3) × (1 - y²), and hidden gradients d = e × old output weights × (1 - h²). Subtract learning rate × gradient from each bias and learning rate × gradient × its input from each weight. Then calculate the current bar's network output using the updated weights and current proxies. Initialize the sentiment EMA with the first available output and use smoothing factor 2 / (smoothing length + 1); substitute zero for unavailable current or previous sentiment.
