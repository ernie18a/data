Calculation: Pivot-anchored regression = On each bar, record confirmed pivot highs and lows using equal left and right confirmation lengths, keeping the most recent registry limit. Scan the most recent configured number of pivots, newest first. For each anchor, let N be the current bar index minus the anchor index; fit ordinary least squares to the most recent N closes, including the current close, with x increasing from zero to N-1. Require the minimum regression length, nonzero variance in x and close, and R² at least the quality threshold. Select the candidate maximizing R² × ln(N), retaining the newest candidate on ties. The midline is the fitted value at x = N-1, and the regression error is sqrt(sum of squared residuals / (N-2)).
Calculation: Smoothed entropy = EMA of the base-2 Shannon entropy of log(close / previous close), using the current close as the previous close on the first bar. For each entropy window, divide its return range into equal-width bins, clamp the maximum return to the last bin, and use one bin if the range is zero.
Calculation: Inner bands = regression midline plus or minus the inner-band multiplier times regression error times (1 + entropy scaling factor × clamp((smoothed entropy - entropy offset) / entropy range, 0, 1)).
Calculation: Higher-timeframe slope = the pivot-anchored regression slope calculated independently on the higher timeframe, carried forward when no valid regression exists, initially zero, and taken from the last completed higher-timeframe bar.
Calculation: Channel Z-score = (close - regression midline) / entropy-adjusted regression error when that error is positive; otherwise zero.
Long: Valid pivot-anchored regression AND slope >= 0.
Short: Valid pivot-anchored regression AND slope < 0.
Long: Valid pivot-anchored regression AND channel Z-score < negative extension threshold.
Short: Valid pivot-anchored regression AND channel Z-score > positive extension threshold.
