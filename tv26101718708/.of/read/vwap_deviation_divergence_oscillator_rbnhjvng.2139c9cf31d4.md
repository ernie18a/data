Calculation: Deviation = selected price source minus volume-weighted average of a selected price source since the start of the current trading day, using chart-bar volume.
Calculation: Oscillator = deviation standardized over a rolling window using either (deviation minus mean) / standard deviation, with zero when standard deviation is zero, or (deviation minus median) / (1.4826 × median absolute deviation). Optionally replace the result with the median of standardized deviations calculated using shorter, medium, and longer windows, where the shorter window is half the medium window and the longer window is twice the medium window. Optionally smooth the result with an EMA or Ehlers UltimateSmoother. Use zero when the daily volume-weighted average is unavailable.
Calculation: Divergence pivot pair = the latest two consecutive confirmed price highs or lows, using a selected high source for highs and a selected low source for lows. Each pivot has the same configurable number of bars on both sides and is evaluated on its confirmation bar. Pair each price pivot with either the oscillator at that pivot or, optionally, the highest oscillator for a high pivot or lowest oscillator for a low pivot across the full pivot confirmation window. Compare the latest pair even if an earlier pair did not produce a signal.
Calculation: Minimum divergence gap = a configurable multiplier of the rolling standard deviation of the oscillator, measured on the current confirmation bar.
Long: Oscillator <= negative overbought/oversold threshold.
Short: Oscillator >= positive overbought/oversold threshold.
Long: A price low pivot is confirmed AND the distance from the preceding low pivot <= maximum pivot distance AND the latest price low < the preceding price low AND its paired oscillator > the preceding paired oscillator AND their oscillator difference >= minimum divergence gap AND, if the extreme filter is enabled, the latest paired oscillator <= negative overbought/oversold threshold.
Long: A price low pivot is confirmed AND the distance from the preceding low pivot <= maximum pivot distance AND the latest price low > the preceding price low AND its paired oscillator < the preceding paired oscillator AND their oscillator difference >= minimum divergence gap.
Short: A price high pivot is confirmed AND the distance from the preceding high pivot <= maximum pivot distance AND the latest price high > the preceding price high AND its paired oscillator < the preceding paired oscillator AND their oscillator difference >= minimum divergence gap AND, if the extreme filter is enabled, the latest paired oscillator >= positive overbought/oversold threshold.
Short: A price high pivot is confirmed AND the distance from the preceding high pivot <= maximum pivot distance AND the latest price high < the preceding price high AND its paired oscillator > the preceding paired oscillator AND their oscillator difference >= minimum divergence gap.
Long: An oscillator low pivot is confirmed using the same configurable number of bars on both sides AND the pivot value <= negative extreme threshold.
Short: An oscillator high pivot is confirmed using the same configurable number of bars on both sides AND the pivot value >= positive extreme threshold.
