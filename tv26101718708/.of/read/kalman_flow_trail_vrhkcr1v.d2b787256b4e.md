Calculation: Scalar Kalman estimate = initialize estimate to close and error to an initial error; on each bar set gain = (previous error + process noise) / (previous error + process noise + measurement noise), estimate = previous estimate + gain * (close - previous estimate), and error = (1 - gain) * (previous error + process noise). Apply independently to close with fast and slow process noise inversely related to their respective lengths, with the fast length shorter than the slow length.
Calculation: Confirmed swing high or low = a pivot high or low with equal numbers of bars on either side, available only after the right-hand bars have completed. Retain the latest confirmed high and low independently.
Calculation: Structure break = bullish when close > the currently retained swing high AND previous close <= that same high; bearish when close < the currently retained swing low AND previous close >= that same low. For the chart structure markings, clear the broken swing after a break; also clear the opposite swing when the break reverses the preceding break direction. For the adaptive basis, retain both swings until replaced by new confirmed pivots, without clearing them after breaks.
Calculation: Adaptive basis = use the retained swings without break resets. Set structure impulse to positive on a bullish break, negative on a bearish break, and zero otherwise, giving the bullish break priority if both occur. Calculate activity as the Wilder moving average of absolute impulse and bias as the Wilder moving average of impulse over the same lookback. Interpolate a smoothing coefficient between slow and fast exponential coefficients using activity as the weight. Initialize the basis to the fast Kalman estimate; thereafter move the previous basis toward that estimate by the interpolated coefficient. Add bias multiplied by ATR, a push coefficient, and an agreement factor: use the full factor when bias and the difference between fast and slow Kalman estimates have the same nonzero sign, otherwise use a smaller factor. If both retained swings exist, move the result toward their midpoint by activity multiplied by an anchor coefficient.
Calculation: Trail direction = initialize to bullish when close >= adaptive basis and bearish otherwise. Subsequently set it bullish when close > adaptive basis + ATR * boundary multiplier AND, if slope confirmation is enabled, adaptive basis > previous adaptive basis; set it bearish when close < adaptive basis - ATR * boundary multiplier AND, if slope confirmation is enabled, adaptive basis < previous adaptive basis; otherwise retain the previous direction.
Long: Close > the retained chart structure swing high AND previous close <= that same high.
Short: Close < the retained chart structure swing low AND previous close >= that same low.
Long: Trail direction = bullish.
Short: Trail direction = bearish.
Long: Fast Kalman estimate > previous fast Kalman estimate.
Short: Fast Kalman estimate < previous fast Kalman estimate.

Short: On each selected higher timeframe, close < that timeframe's adaptive basis, using the last completed higher-timeframe bar.
Long: On each selected lower timeframe, close > that timeframe's adaptive basis, using the last completed lower-timeframe bar within the chart bar.
Short: On each selected lower timeframe, close < that timeframe's adaptive basis, using the last completed lower-timeframe bar within the chart bar.
