Calculation: Uptrend = short-period EMA of close > long-period EMA of close AND short-period EMA > its value at the slope lookback AND close > long-period EMA.
Calculation: Downtrend = short-period EMA of close < long-period EMA of close AND short-period EMA < its value at the slope lookback AND close < long-period EMA.
Calculation: Range = Uptrend is false AND Downtrend is false AND highest high minus lowest low over the range lookback <= ATR multiplied by the range-height threshold. The range boundaries include the current bar.
Calculation: Bullish signal bar = high - low > 0 AND high - low <= ATR multiplied by the bar-size threshold AND abs(close - open) / (high - low) >= the body threshold AND close > open AND (close - low) / (high - low) >= the close-strength threshold.
Calculation: Bearish signal bar = high - low > 0 AND high - low <= ATR multiplied by the bar-size threshold AND abs(close - open) / (high - low) >= the body threshold AND close < open AND (high - close) / (high - low) >= the close-strength threshold.
Calculation: Bullish trigger = Bullish signal bar is true AND high > previous bar's high.
Calculation: Bearish trigger = Bearish signal bar is true AND low < previous bar's low.
Calculation: Long attempt = while Uptrend is true, set a pullback flag when low <= short-period EMA; an attempt occurs when the flag is set AND Bullish trigger is true, including on the bar that sets the flag. Count the attempt and clear the flag. Reset the count and flag whenever Uptrend is false.
Calculation: Short attempt = while Downtrend is true, set a pullback flag when high >= short-period EMA; an attempt occurs when the flag is set AND Bearish trigger is true, including on the bar that sets the flag. Count the attempt and clear the flag. Reset the count and flag whenever Downtrend is false.
Calculation: Daily signal count = number of main long and short signals since the start of the current calendar day, excluding the current bar; reset at each new day.
Calculation: Main long signal = long direction enabled AND the daily limit is disabled OR long direction enabled AND Daily signal count < daily limit, AND either (Long attempt is true AND the second-entry requirement is disabled or the long attempt count is at least the second attempt) OR (Range is true AND close <= lowest low over the range lookback + range height multiplied by the edge fraction AND Bullish trigger is true).
Calculation: Main short signal = short direction enabled AND the daily limit is disabled OR short direction enabled AND Daily signal count < daily limit, AND either (Short attempt is true AND the second-entry requirement is disabled or the short attempt count is at least the second attempt) OR (Range is true AND close >= highest high over the range lookback - range height multiplied by the edge fraction AND Bearish trigger is true).
Long: Uptrend is true OR Bullish signal bar is true OR Long attempt is true OR Main long signal is true.
Short: Downtrend is true OR Bearish signal bar is true OR Short attempt is true OR Main short signal is true.
