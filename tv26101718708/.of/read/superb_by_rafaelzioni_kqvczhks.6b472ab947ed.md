Calculation: Adjusted price = Let spread-volume be ((close − open) / (high − low)) × volume; let cumulative flow be the cumulative sum of spread-volume; let flow mean be its shorter-lookback simple moving average; let flow deviation be the longer-lookback standard deviation of cumulative flow minus flow mean; let price deviation be the longer-lookback standard deviation of high − low; let shadow be (cumulative flow − flow mean) / flow deviation × price deviation; adjusted price = high + shadow when shadow > 0, otherwise low + shadow.
Calculation: Upper threshold = EMA of adjusted price − multiplier × ATR; lower threshold = EMA of adjusted price + multiplier × ATR.
Calculation: Trend state = Initialize trend neutral, upper state to the first bar's upper threshold, and lower state to its lower threshold. On the second bar, set trend up and upper state to the upper threshold if that threshold is at least the prior upper state; otherwise set trend down and lower state to the lower threshold. On each later bar, carry the prior trend forward unless a flip condition applies. If prior trend is up, update upper state to the current upper threshold when it is at least the prior upper state; otherwise, if current lower threshold is less than prior upper state × (1 − factor), set trend down and lower state to current lower threshold. If prior trend is down, update lower state to current lower threshold when it is at most the prior lower state; otherwise, if current upper threshold is greater than prior lower state × (1 + factor), set trend up and upper state to current upper threshold. Retain each state value when not updated.
Long: Trend state is up AND prior bar's trend state was down.
Short: Trend state is down AND prior bar's trend state was up.
Exit: Long, Trend state is down AND prior bar's trend state was up.
Exit: Short, Trend state is up AND prior bar's trend state was down.
