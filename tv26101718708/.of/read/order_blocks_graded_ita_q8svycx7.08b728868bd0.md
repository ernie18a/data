Calculation: Break flags = Initialize the bullish and bearish flags to false. On each bar, evaluate both break conditions using the flags carried from the preceding bar and the latest confirmed pivot high and pivot low, including pivots confirmed on the current bar. After evaluating both conditions, if the bullish break is true, set the bullish flag true and the bearish flag false; then, if the bearish break is true, set the bearish flag true and the bullish flag false. Finally, reset the bullish flag to false if a pivot high is confirmed on the current bar, and reset the bearish flag to false if a pivot low is confirmed on the current bar. Pivot highs and lows use equal numbers of bars on each side.
Long: Close > latest confirmed pivot high AND bullish flag = false
Short: Close < latest confirmed pivot low AND bearish flag = false
