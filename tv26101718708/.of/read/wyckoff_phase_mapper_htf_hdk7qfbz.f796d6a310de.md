Calculation: Wyckoff state = Run an independent state machine on each higher timeframe, using the last completed higher-timeframe bar on historical chart bars and the still-forming higher-timeframe bar in real time. A confirmed pivot high or low uses equal numbers of bars on both sides; evaluate the pivot only when its right-side bars have elapsed. At each higher-timeframe bar, execute the following steps in order, allowing multiple steps on the same bar. Start in state 0. In state 0, if the short-period close EMA is below the long-period close EMA and a pivot low is confirmed, and that pivot bar's volume exceeds a multiple of its volume SMA or its high-minus-low exceeds a multiple of its ATR, set state to 1 and store the pivot low as the first level. In state 1, a confirmed pivot high sets state to 2 and is stored as the second level. In state 2, a confirmed pivot low below the first level sets state to 3; then a confirmed pivot high above the second level sets state to 4, even if state just changed to 3. In state 3, a confirmed pivot high above the second level sets state to 4. In state 4, a confirmed pivot low above the first level sets state to 5. In state 0, if the short-period EMA is above the long-period EMA and a pivot high is confirmed, and that pivot bar's volume exceeds a multiple of its volume SMA or its high-minus-low exceeds a multiple of its ATR, set state to -1 and store the pivot high as the first level. In state -1, a confirmed pivot low sets state to -2 and is stored as the second level. In state -2, a confirmed pivot high above the first level sets state to -3; then a confirmed pivot low below the second level sets state to -4, even if state just changed to -3. In state -3, a confirmed pivot low below the second level sets state to -4. In state -4, a confirmed pivot high below the first level sets state to -5. After these transitions, latch a broken flag if state is positive and close is below the first level by an invalidation percentage, or state is negative and close is above the first level by that percentage. Reset state to 0, clear levels and clear the broken flag if state is 5 and close exceeds the second level by an expiry percentage, or state is -5 and close falls below the second level by that percentage. Then reset and clear the same fields if the broken flag is set and either state is positive with the short-period EMA above the long-period EMA, or state is negative with the short-period EMA below the long-period EMA. The broken flag remains set until reset. Transitions cleared by a reset on the same bar produce no decision.
Long: Wyckoff state transitions to 1, 2, 3, 4, or 5.
Short: Wyckoff state transitions to -1, -2, -3, -4, or -5.
