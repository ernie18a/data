Calculation: PrevHigh1H = high of the last completed 1-hour bar (higher timeframe than the chart, not the forming bar), computed separately for the primary instrument and for a correlated reference instrument; PrevLow1H = low of that same bar
Short: highest high of the last N chart-timeframe bars (including the current bar) of the primary instrument > primary PrevHigh1H AND NOT (highest high of the last N chart-timeframe bars of the reference instrument > reference PrevHigh1H), where N is the same for both instruments
Long: lowest low of the last N chart-timeframe bars (including the current bar) of the primary instrument < primary PrevLow1H AND NOT (lowest low of the last N chart-timeframe bars of the reference instrument < reference PrevLow1H), where N is the same for both instruments
