Calculation: Pattern = Use the two most recent confirmed pivot highs H1, H2 and lows L1, L2, where 1 is most recent and each pivot has the same number of bars on either side. Require max(H1,H2) - min(L1,L2) >= pattern-height multiplier × ATR and the age of the more recent of H1 and L1 <= freshness limit. Flat highs or lows have absolute pivot difference <= flat-tolerance multiplier × ATR; rising or falling highs or lows differ by more than the trend-tolerance multiplier × ATR. In priority order: flat highs AND rising lows gives bullish bias; flat lows AND falling highs gives bearish bias; flat highs AND flat lows gives neutral bias; rising highs AND rising lows gives bullish bias; falling highs AND falling lows gives bearish bias. For the first three cases resistance = max(H1,H2) and support = min(L1,L2); for the last two resistance = H1 and support = L1. Otherwise there is no pattern and bias is neutral.
Calculation: Break state = Initially direction = 0 and true = false and fake = false. On each bar, a pattern with nonnegative bias AND close > current resistance + break multiplier × current ATR AND previous close <= that same current threshold sets direction = 1, level = current resistance, age = 0, true = false and fake = false. A pattern with nonpositive bias AND close < current support - break multiplier × current ATR AND previous close >= that same current threshold sets direction = -1, level = current support, age = 0, true = false and fake = false. A new break replaces any existing state. Otherwise increment age. Before evaluating signals, set fake = true if age <= fakeout window AND either direction = 1 AND close < level AND (high - max(open,close)) / (high - low) >= wick threshold, OR direction = -1 AND close > level AND (min(open,close) - low) / (high - low) >= wick threshold. Set true = true if fake = false AND age >= confirmation length - 1 AND either direction = 1 AND the lowest close over the confirmation length > level, OR direction = -1 AND the highest close over the confirmation length < level. Both flags persist once set. After evaluating signals, clear the state on a qualified triangle signal; otherwise clear it if age > fakeout window AND true = false.
Calculation: Directional RSI alignment = For long, short-lookback RSI of close > long threshold AND longer-lookback RSI of close > 50 AND short-lookback RSI > its value at the slope lookback AND longer-lookback RSI >= its value at the slope lookback. For short, short-lookback RSI < short threshold AND longer-lookback RSI < 50 AND short-lookback RSI < its value at the slope lookback AND longer-lookback RSI <= its value at the slope lookback.
Calculation: Higher-timeframe alignment = On the higher timeframe, use close and short- and long-lookback EMAs of close from the last completed higher-timeframe bar for historical bars; the still-forming higher-timeframe bar is used in real time. Bullish alignment requires short EMA > long EMA AND close > short EMA; bearish alignment requires short EMA < long EMA AND close < short EMA.
Calculation: Choppiness = 100 × log10(sum of true range over the choppiness lookback / (highest high - lowest low over that lookback)) / log10(choppiness lookback); use 50 when the high-low denominator is zero.
Calculation: Quality score = 2 if current pattern height >= pattern-height multiplier × current ATR, otherwise 0; plus 2 if current directional RSI alignment holds, otherwise 0; plus 1 for a trap candidate, otherwise 2; plus 1 if volume confirmation is disabled OR volume >= its moving average × volume multiplier; plus 1 if the chop filter is disabled OR choppiness < chop threshold; plus 1 if the higher-timeframe scoring layer is disabled, otherwise 2 if higher-timeframe alignment agrees with the candidate direction and 0 otherwise. Cap at 10.
Calculation: Qualified triangle signal = A true-break candidate has true = true AND break direction equal to signal direction AND corresponding directional RSI alignment. A trap candidate has fake = true AND break direction opposite to signal direction AND trap reversals enabled AND short-lookback RSI crosses 50 in the signal direction AND its slope over the slope lookback has that direction. Either candidate additionally requires bars since the last qualified triangle signal >= cooldown, or no earlier signal; the chop filter disabled OR choppiness < chop threshold; hard higher-timeframe alignment disabled OR higher-timeframe alignment agrees with the signal; and quality score >= minimum. Score a direction as a trap whenever its trap candidate is present. Evaluate these conditions before clearing the break state.
Long: Qualified triangle signal direction = long.
Short: Qualified triangle signal direction = short.
Long: Break state direction = -1 AND age <= fakeout window AND close > level AND (min(open,close) - low) / (high - low) >= wick threshold.
Short: Break state direction = 1 AND age <= fakeout window AND close < level AND (high - max(open,close)) / (high - low) >= wick threshold.
Long: After triangle-signal clearing and expiry, break state direction = 1 OR break state direction = 0 AND pattern bias = bullish.
Short: After triangle-signal clearing and expiry, break state direction = -1 OR break state direction = 0 AND pattern bias = bearish.
Long: Higher-timeframe alignment = bullish.
Short: Higher-timeframe alignment = bearish.
