Calculation: Rolling VWAP = sum(typical price × volume) / sum(volume) over its lookback, where typical price = (high + low + close) / 3.
Calculation: Structure step = fast ATR × structure multiplier × (0.5 + 1.5 / (1 + exp(-(4 × (volatility ratio - 1) + 0.75 × clamped ATR z-score))))). The slow ATR length is four times the fast ATR length. Volatility ratio = fast ATR / slow ATR, or 1 when slow ATR is zero. ATR z-score = (fast ATR - its simple moving average) / its standard deviation, or 0 when the standard deviation is zero; clamp it to [-3, 3]. Both statistics use a lookback four times the rolling VWAP lookback.
Calculation: Structure direction and bounds = initially direction 0 and undefined bounds. On the first bar with a defined rolling VWAP and a positive, defined structure step, set upper bound to rolling VWAP, lower bound to rolling VWAP minus structure step, and direction to 1. On each subsequent bar with valid inputs, if rolling VWAP > previous upper bound + current structure step, set n = floor((rolling VWAP - previous upper bound) / current structure step), lower bound = previous upper bound + (n - 1) × current structure step, upper bound = previous upper bound + n × current structure step, and direction = 1. Otherwise, if rolling VWAP < previous lower bound - current structure step, set n = floor((previous lower bound - rolling VWAP) / current structure step), upper bound = previous lower bound - (n - 1) × current structure step, lower bound = previous lower bound - n × current structure step, and direction = -1. Otherwise retain the previous bounds and direction.
Calculation: Anchored VWAP = cumulative sum of typical price × volume divided by cumulative sum of volume, starting at the first bar and resetting on every change in structure direction, including the initial change from 0 to 1. It is undefined when cumulative volume is zero.
