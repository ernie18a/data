Calculation: CPR top and bottom = from the prior completed daily bar: pivot = (high + low + close) / 3; BC = (high + low) / 2; TC = 2 × pivot − BC; top = max(BC, TC); bottom = min(BC, TC)
Calculation: CPR width = CPR top − CPR bottom
Calculation: Danger CPR = (volatility-index value < threshold 1 AND CPR width > width threshold 1) OR (volatility-index value in band 2 AND CPR width > width threshold 2) OR (volatility-index value in band 3 AND CPR width > width threshold 3) OR (volatility-index value in band 4 AND CPR width > width threshold 4) OR (volatility-index value in band 5 AND CPR width > width threshold 5); the volatility bands and width thresholds increase successively
Calculation: Projected next-session CPR width = CPR width calculated from the current, still-forming daily bar's high, low, and close
