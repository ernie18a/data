Calculation: Confirmed pivot high/low = a bar’s high/low is the highest/lowest within the pivot-strength bars on both sides; use the latest confirmed pivot, and allow each pivot to qualify only once
Calculation: Cycle displacement z-score = ((close − EMA(close, cycle length)) − SMA(cycle displacement, cycle length)) / standard deviation(cycle displacement, cycle length)
Calculation: Cycle rotation = current cycle displacement − previous cycle displacement
Calculation: Relative volume = volume / SMA(volume, relative-volume lookback)
Calculation: Absorption proxy = relative volume ≥ minimum relative volume AND abs(close − open) / max(high − low, minimum tick) ≤ maximum body/range
Long: On a completed chart bar, low < latest unused confirmed pivot low AND close > that pivot low AND (cycle displacement z-score ≤ −stretch threshold AND cycle rotation > 0 OR absorption proxy in Balanced mode; cycle displacement z-score ≤ −stretch threshold AND cycle rotation > 0 AND absorption proxy in Strict mode) AND no simultaneous qualified bearish sweep AND no bullish setup already armed OR a bullish setup is armed and, within the confirmation window after its sweep bar, a later completed bar closes above the sweep bar’s high AND (EMA context filter disabled OR close ≥ EMA(close, context length))
Short: On a completed chart bar, high > latest unused confirmed pivot high AND close < that pivot high AND (cycle displacement z-score ≥ stretch threshold AND cycle rotation < 0 OR absorption proxy in Balanced mode; cycle displacement z-score ≥ stretch threshold AND cycle rotation < 0 AND absorption proxy in Strict mode) AND no simultaneous qualified bullish sweep AND no bearish setup already armed OR a bearish setup is armed and, within the confirmation window after its sweep bar, a later completed bar closes below the sweep bar’s low AND (EMA context filter disabled OR close ≤ EMA(close, context length))
