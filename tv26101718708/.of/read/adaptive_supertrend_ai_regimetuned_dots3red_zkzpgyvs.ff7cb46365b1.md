Calculation: Regime = classify each bar as volatile if baseline ATR / max(SMA of baseline ATR, epsilon) > volatility threshold; otherwise trending if trend score > trending threshold; otherwise ranging if trend score < ranging threshold; otherwise uncertain. Trend score = (min(ADX / ADX normalization scale, 1) + 1 - min((Choppiness Index - choppiness offset) / choppiness scale, 1)) / 2. Choppiness Index = 100 * log10(sum of true range / max(highest high - lowest low, epsilon)) / log10(lookback). Smooth the classifications using their mode over a lookback; break ties in the order volatile, trending, ranging, uncertain. Treat unavailable classifications as uncertain.
Calculation: Adaptive SuperTrend = assign an ATR multiplier to each regime. Initialize the active multiplier to the current regime's multiplier; subsequently update it each bar as previous active multiplier + (current regime's multiplier - previous active multiplier) / transition length. Basic upper and lower bands are (high + low) / 2 plus and minus active multiplier * SuperTrend ATR. Initialize each final band to its basic band. Thereafter, set the upper band to the current basic upper band if it is below the previous upper band OR the previous close is above the previous upper band; otherwise retain the previous upper band. Set the lower band to the current basic lower band if it is above the previous lower band OR the previous close is below the previous lower band; otherwise retain the previous lower band. Initialize direction as up; change from up to down when close < current lower band, and from down to up when close > current upper band; otherwise retain the previous direction.
Long: Adaptive SuperTrend direction = up
Short: Adaptive SuperTrend direction = down
Long: previous Adaptive SuperTrend direction = down AND current Adaptive SuperTrend direction = up
Short: previous Adaptive SuperTrend direction = up AND current Adaptive SuperTrend direction = down
