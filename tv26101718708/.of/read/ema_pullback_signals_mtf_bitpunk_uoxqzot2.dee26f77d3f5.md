Calculation: Setup references = On the last completed higher-timeframe bar, calculate a short EMA and a longer EMA of close, ATR, and efficiency = min(1, absolute change in close over the short EMA lookback / sum of absolute successive close changes over that lookback), or zero when the sum is zero. Each EMA zone is its EMA plus or minus the same ATR-multiple half-width. Setup direction is +1 when close is above the longer EMA and that EMA is above its value a slope-lookback ago; -1 when both comparisons reverse; otherwise 0. Require sufficient history for all references and positive ATR.
Calculation: Recovery state = Process each completed chart bar in order. Reset the state and spacing reference when setup direction is zero, changes, or required data is unavailable. For direction d, separation means low is above both zone upper edges when d = +1, or high is below both zone lower edges when d = -1. A zone overlaps when low <= its upper edge AND high >= its lower edge. Start in the waiting state; arm when separation AND setup efficiency >= an efficiency threshold. From armed or consumed, start a pending recovery on a zone overlap; after a prior consumption, also require efficiency >= the threshold, a newly overlapping zone that did not overlap on the preceding chart bar, and d * (prior favorable close extreme - current low for d = +1 or current high for d = -1) >= a rearm multiple of the ATR frozen at consumption. On first touch select the longer-EMA zone if it overlaps, otherwise the shorter-EMA zone; record the completed higher-timeframe bar index. While pending, upgrade to the longer-EMA zone whenever it overlaps, without changing the recorded index. Before processing a pending bar, expire the recovery when the current completed higher-timeframe index minus the recorded index >= a confirmation-window parameter. On each pending bar, including the touch bar, use the current selected zone's upper edge for d = +1 or lower edge for d = -1. If the reclaim and momentum conditions in the entry lines hold, consume the recovery even if its extension exceeds the entry limit; freeze current setup ATR and set the favorable close extreme to current close. Otherwise, after evaluating the entry, if separation occurs on a later chart bar than the touch, replace pending with armed if efficiency >= the threshold, otherwise waiting. After consumption, update the favorable close extreme with each chart close: maximum for d = +1, minimum for d = -1. Use the extreme from before the current bar when testing rearm spacing.
Calculation: Momentum confirmation = For direction d, chart-bar range > 0 AND d * (close - open) / range >= a body threshold AND (close - low for d = +1 or high - close for d = -1) / range >= a directional-close threshold; OR d * (chart-timeframe MACD histogram - previous histogram) > 0 AND d * (Heikin-Ashi close - Heikin-Ashi open) > 0. Heikin-Ashi close = (open + high + low + close) / 4; Heikin-Ashi open = (previous Heikin-Ashi open + previous Heikin-Ashi close) / 2, initialized as (open + close) / 2. MACD uses a shorter and a longer EMA of chart close and an EMA signal line; initialize each EMA from its first available input.
Long: Setup direction = +1 AND recovery state = pending AND close > selected zone upper edge AND close > open AND close > previous chart close AND momentum confirmation for +1 AND (close - selected zone upper edge) / setup ATR <= an extension limit.
Short: Setup direction = -1 AND recovery state = pending AND close < selected zone lower edge AND close < open AND close < previous chart close AND momentum confirmation for -1 AND (selected zone lower edge - close) / setup ATR <= an extension limit.
