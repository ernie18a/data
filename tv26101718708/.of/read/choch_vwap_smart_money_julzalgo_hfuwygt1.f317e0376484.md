Calculation: Confirmed pivot high/low = a high/low with the same number of bars on each side used to confirm it; retain the latest confirmed value. A newly confirmed pivot resets its taken flag before evaluating breaks on that bar.
Calculation: High break = either close crosses above the latest confirmed pivot high, comparing the previous close with the previous bar's latest pivot high, or high is above the current latest pivot high AND previous high is at or below that same pivot high. Low break = either close crosses below the latest confirmed pivot low, comparing the previous close with the previous bar's latest pivot low, or low is below the current latest pivot low AND previous low is at or above that same pivot low. Use the same selected close or wick method for both breaks.
Calculation: Structure direction = initially neutral; after decisions on each bar, set it to bullish when an untaken high break occurs and mark that high taken, then set it to bearish when an untaken low break occurs and mark that low taken.
Long: High break AND latest pivot high is untaken AND structure direction is bearish.
Short: Low break AND latest pivot low is untaken AND structure direction is bullish.
