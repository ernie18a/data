Calculation: All decisions use completed chart bars. Treat numeric thresholds, lookbacks, weights, row counts, fractions, and the minimum positive price increment as parameters. Initialize persistent states to neutral and reset the intraday volume profile at each calendar-day boundary.
Calculation: Intraday volume profile = divide the price span from the lowest low to the highest high of the current day’s available chart bars, up to a maximum lookback, into equal price rows. Allocate each bar’s volume across rows in proportion to the overlap of its high-low range with each row. The control price is the midpoint of the highest-volume row, choosing the lowest row on ties. Starting at that row, repeatedly add the adjacent row with greater volume, choosing the lower row on ties, until the accumulated volume reaches the specified fraction of total allocated volume. The resulting row boundaries define the core; repeat with a larger fraction to define the outer range. If total allocated volume is zero, profile levels are undefined. The premium and discount are the core midpoint plus and minus a parameterized fraction of the core width, respectively, subject to a minimum distance. Prior profile levels are the preceding bar’s levels and are undefined on the first bar of a day.
Calculation: Directional evidence = weighted sum of directional-movement balance, EMA alignment sign, clipped EMA of close change divided by ATR, and clipped distance of close from an EMA of typical price divided by ATR. Directional-movement balance is (positive DI minus negative DI) divided by their sum, or zero when their sum is zero. EMA alignment sign is +1, -1, or 0 according to whether the short EMA of close is above, below, or equal to the long EMA. Clip each normalized momentum and price-distance component to a symmetric parameterized interval.
Calculation: Acceptance = EMA of the EMA of typical price plus directional evidence multiplied by ATR and a positive scale parameter.
Calculation: Strong bullish body = close > open AND absolute close-open distance / high-low range >= a body-ratio threshold AND absolute close-open distance / ATR >= a body-size threshold. Strong bearish body uses close < open and the same thresholds. Apply the minimum positive price increment to the range and ATR denominators.
Calculation: Bullish source = strong bullish body AND directional evidence >= a positive threshold AND positive DI > negative DI AND ADX >= a threshold AND close > acceptance AND close > current control price AND ((low < prior outer lower boundary AND close > prior outer lower boundary) OR (low <= prior discount AND low <= prior control price AND close > prior discount AND close > prior control price) OR (min(open, close) > acceptance AND acceptance > prior acceptance) OR (prior close <= prior core upper boundary AND close > prior core upper boundary + ATR times a positive buffer AND close > prior control price)).
Calculation: Bearish source = strong bearish body AND directional evidence <= the negative counterpart of the bullish threshold AND negative DI > positive DI AND ADX >= the same threshold AND close < acceptance AND close < current control price AND ((high > prior outer upper boundary AND close < prior outer upper boundary) OR (high >= prior premium AND high >= prior control price AND close < prior premium AND close < prior control price) OR (max(open, close) < acceptance AND acceptance < prior acceptance) OR (prior close >= prior core lower boundary AND close < prior core lower boundary - ATR times a positive buffer AND close < prior control price)).
Calculation: Signal state starts neutral. On each bar, if neutral, set it bullish when the bullish source is true and the bearish source is false, or bearish when the bearish source is true and the bullish source is false. Otherwise switch to the opposite state when its source is true and at least a parameterized number of bars has elapsed since the preceding signal. Record the bar of each state change. Evaluate the following cloud calculations after updating signal state.
Calculation: Cloud sideways condition = highest high minus lowest low over a lookback <= ATR times a threshold AND absolute close displacement over that lookback divided by the sum of absolute consecutive close changes <= an efficiency threshold AND absolute separation of a short and a longer EMA of typical price <= ATR times a threshold AND absolute change in the short EMA over a slope lookback <= ATR times a threshold. Set efficiency to 1 when the path length does not exceed the minimum positive price increment.
Calculation: Bullish outside-body fraction = max(max(open, close) - max(min(open, close), acceptance + ATR times a positive offset), 0) / max(abs(close - open), minimum positive price increment). Bearish outside-body fraction = max(min(max(open, close), acceptance - ATR times the same offset) - min(open, close), 0) / max(abs(close - open), minimum positive price increment).
Calculation: Bullish cloud start = signal state is bullish AND cloud sideways condition is false AND close > short typical-price EMA AND short typical-price EMA >= longer typical-price EMA AND ((short EMA - its value at a previous slope lookback) / ATR >= a positive threshold OR close - its value at a progress lookback > 0) AND (bullish outside-body fraction >= a higher threshold OR bullish outside-body fraction and its prior value are both >= a lower threshold). Bearish cloud start reverses all directional comparisons and uses bearish outside-body fraction and the negative slope threshold.
Calculation: Sharp bullish reversal = close > open AND absolute body >= ATR times a threshold AND body / high-low range >= a threshold AND close > short typical-price EMA AND close > prior high. Sharp bearish reversal reverses the directional comparisons and compares close with the prior low.
Calculation: Cloud state starts neutral. On each bar, reset a bullish cloud to neutral if signal state is bearish OR sharp bearish reversal is true OR cloud sideways condition is true; reset a bearish cloud symmetrically. Then, if neutral, set it bullish when bullish cloud start is true, otherwise set it bearish when bearish cloud start is true.
Long: Signal state changes to bullish OR cloud state is bullish.
Short: Signal state changes to bearish OR cloud state is bearish.
