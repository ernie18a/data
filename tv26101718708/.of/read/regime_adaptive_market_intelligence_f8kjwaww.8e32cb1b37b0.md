Calculation: Normalized EMA separation = (shorter-period EMA of close − longer-period EMA of close) / ATR; undefined when ATR <= 0.
Calculation: Normalized EMA slope = (longer-period EMA of close − its value a lookback number of bars ago) / current ATR; undefined when ATR <= 0.
Calculation: Regime = on each completed bar, after a warm-up and when ADX, normalized separation, and normalized slope are defined, classify the candidate as Bull when ADX >= trend-entry threshold AND separation >= positive trend-separation threshold AND slope >= positive trend-slope threshold; otherwise Bear when ADX >= trend-entry threshold AND separation <= negative trend-separation threshold AND slope <= negative trend-slope threshold; otherwise Range when ADX <= lower trend-exit threshold AND absolute separation <= range-entry separation threshold AND absolute slope <= range-entry slope threshold; otherwise Transition. Count consecutive identical non-Transition candidates, resetting the count on a candidate change or Transition. When the count reaches the applicable trend or Range confirmation count, set the regime to that candidate. Otherwise retain the previous Bull regime while ADX >= trend-exit threshold AND separation > 0 AND slope > 0, the previous Bear regime while ADX >= trend-exit threshold AND separation < 0 AND slope < 0, or the previous Range regime while ADX < trend-entry threshold AND absolute separation < range-holding separation threshold AND absolute slope < range-holding slope threshold; set the regime to Transition otherwise. Range-holding separation and slope thresholds are greater than their corresponding Range-entry thresholds. Before the warm-up or when the required inputs are undefined, the regime is undefined. Calculate this independently on the chart timeframe and the higher timeframe; use the last completed higher-timeframe bar.
Long: Chart-timeframe regime = Bull OR last completed higher-timeframe regime = Bull OR chart-timeframe RSI >= positive-momentum threshold.
Short: Chart-timeframe regime = Bear OR last completed higher-timeframe regime = Bear OR chart-timeframe RSI <= lower negative-momentum threshold.
