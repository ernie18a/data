Calculation: Prior range = highest high and lowest low over a lookback ending on the previous bar; midpoint is their average and width is their difference.
Calculation: Failure candidate = upper when high > prior range high + ATR × probe multiplier AND prior range low < close < prior range high AND (prior range high − close) / range width >= inside-depth threshold; lower when low < prior range low − ATR × probe multiplier AND prior range low < close < prior range high AND (close − prior range low) / range width >= inside-depth threshold. Require range width > 0. If both qualify, select upper when close <= midpoint, otherwise lower.
Calculation: Active failure = most recent failure candidate, replacing any earlier one; retain its direction, boundary, range midpoint, inside-depth fraction, and bar index indefinitely. Age = current bar index − failure bar index. The boundary is the prior range high for an upper failure and the prior range low for a lower failure.
Calculation: Probe distance = current ATR × probe multiplier; shelf distance = current ATR × shelf multiplier. Reclaim = close >= boundary + probe distance for an upper failure, or close <= boundary − probe distance for a lower failure.
Calculation: Confirmed failure = no reclaim AND either age > 0 AND, for an upper failure, high >= boundary AND close < boundary − shelf distance, or, for a lower failure, low <= boundary AND close > boundary + shelf distance; OR age >= 2 AND, for an upper failure, close < stored range midpoint, or, for a lower failure, close > stored range midpoint.
Calculation: Recovery score = clamp(0.18 × stored inside-depth percentage + 0.20 × reclaim-speed score + 0.31 × response score + 0.16 × volume score + 0.15 × time-decay score, 0, 100). Clamp limits a value to the stated interval.
Calculation: Recovery progress = (close − boundary) / (probe distance + shelf distance) for an upper failure, or (boundary − close) / (probe distance + shelf distance) for a lower failure. Close location = clamp((close − low) / (high − low), 0, 1); body efficiency = abs(close − open) / (high − low). A recovery candle has close >= open for an upper failure or close <= open for a lower failure. Directional close location is close location for an upper failure and 1 − close location for a lower failure. Candle score = 70 × body efficiency + 30 × directional close location for a recovery candle, otherwise 35 × directional close location. Response score = clamp(70 × recovery progress + 35 + 0.25 × candle score, 0, 100), capped at 24 when failure is confirmed.
Calculation: Relative volume = volume / its simple moving average, or 1 when that average is not positive; missing volume is zero. Relative-volume slope = relative volume − relative volume at a fixed earlier bar, using current relative volume if that earlier value is unavailable. Volume score = clamp(clamp((relative volume − 0.65) / max(volume-support threshold − 0.65, 0.10) × 70, 0, 85) + 80 × relative-volume slope + 15 if the candle is a recovery candle, 0, 100), with the last addition zero otherwise.
Calculation: Speed score = clamp(100 − 100 × age / recovery window, 0, 100). Reclaim-speed score = speed score when reclaimed, otherwise clamp(0.62 × speed score + 0.38 × response score, 0, 100). Time-decay score = clamp(100 − 100 × age / (1.35 × recovery window), 0, 100).
Calculation: Watch marking = active failure AND age <= recovery window AND no confirmed failure AND NOT (reclaim AND recovery score >= active threshold) AND recovery score >= watch threshold + watch margin AND bars since the last event marking >= label cooldown. Event markings use a shorter cooldown for a new failure or a newly true reclaim, and the longer cooldown for a newly true confirmed failure or watch marking; a new failure takes precedence over reclaim, which takes precedence over confirmed failure, which takes precedence over watch.
