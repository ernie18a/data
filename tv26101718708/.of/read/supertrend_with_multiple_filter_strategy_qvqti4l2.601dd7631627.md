Calculation: Cross above = current value > current comparison value AND previous value <= previous comparison value; cross below = current value < current comparison value AND previous value >= previous comparison value.
Calculation: Adaptive trend average = initialize to close; thereafter update previous average by adding (close minus previous average) multiplied by the square of the SMA of an indicator that is 1 when the rolling highest high increases or the rolling lowest low decreases, otherwise 0. The SMA and extrema use the same lookback.
Calculation: CCI channel = compute CCI of close and two ATRs with independent lookbacks. Maintain a series set to low minus the first ATR when CCI >= 0 and to high plus the first ATR when CCI <= 0, with the latter assignment taking precedence at zero. Maintain two lines initialized to zero: when CCI crosses from negative to nonnegative, set the first to the previous second line; when CCI crosses from positive to nonpositive, set the second to the previous first line. While CCI > 0, set the first to low minus the second ATR, but do not let it fall below its previous value if previous CCI >= 0. While CCI < 0, set the second to high plus the second ATR, but do not let it rise above its previous value if previous CCI <= 0. Average the maximum of those two lines with eight EMAs of the first series, ordered from shorter to longer lookback, with the fourth EMA duplicating the third. The channel is an SMA of that average plus or minus its standard deviation over the same lookback.
Calculation: Cloud bounds = the midpoint of the rolling highest high and lowest low over the longest cloud lookback, displaced by the cloud displacement, and the average of the corresponding midpoints over the shorter conversion and longer base lookbacks, both displaced by the base lookback.
Calculation: Pattern trend oscillator = 100 times (close minus the rolling lowest close) divided by (the rolling highest close minus the rolling lowest close), using the pattern trend lookback. Body = absolute value of close minus open.
Calculation: Bullish candle pattern = pattern trend oscillator < midpoint AND either (minimum of open and close minus low > 2 times body AND high minus maximum of open and close < body / 4) OR (high minus maximum of open and close > 2 times body AND minimum of open and close minus low < body / 4); alternatively, close > open AND the sum of upper and lower wick lengths < body / 10 AND body > ATR AND previous pattern trend oscillator < midpoint.
Calculation: Bearish candle pattern = pattern trend oscillator > midpoint AND either (high minus maximum of open and close > 2 times body AND minimum of open and close minus low < body / 4) OR (minimum of open and close minus low > 2 times body AND high minus maximum of open and close < body / 4); alternatively, close < open AND the sum of upper and lower wick lengths < body / 10 AND body > ATR AND previous pattern trend oscillator > midpoint. Both candle patterns use the ATR from the ATR-band exit calculation.
Calculation: Confirmed resistance and support = the latest pivot high and pivot low, respectively, confirmed using configurable left and right bar counts, made available one bar after confirmation and carried forward until replaced.
Calculation: Cascaded weighted average = six successive WMAs starting with close. The first two lookbacks are independently configurable as fast and slow; each subsequent lookback is the sum of the preceding two lookbacks.
Calculation: Transformed CCI = tanh(WMA(CCI(close) / 40)), using independently configurable CCI and WMA lookbacks.
Calculation: Long filter set = AND of every enabled filter: shorter EMA of close crosses above longer EMA; close > adaptive trend average; each independently enabled supertrend is bullish; close > long-term EMA AND previous close > current long-term EMA; stochastic %K crosses above its oversold threshold AND previous %K < that threshold; MACD line > signal line AND shorter SMA of close crosses above longer SMA; MFI of typical price crosses above its EMA; close crosses above the CCI channel upper bound; close > close-based anchored VWAP; Chaikin money flow > 0; close > both cloud bounds; bullish candle pattern = true; previous close > current confirmed resistance AND close > current confirmed resistance; cascaded weighted average crosses above its own previous value; transformed CCI > positive threshold. The VWAP is available only on intraday charts and resets at the configured calendar anchor.
Calculation: Short filter set = AND of every enabled filter: shorter EMA of close crosses below longer EMA; close < adaptive trend average; each independently enabled supertrend is bearish; close < long-term EMA AND previous close < current long-term EMA; stochastic %K crosses below its overbought threshold AND previous %K > that threshold; MACD line > signal line AND shorter SMA of close crosses above longer SMA; MFI of typical price crosses below its EMA; close crosses below the CCI channel lower bound; close < close-based anchored VWAP; Chaikin money flow < 0; close < both cloud bounds; bearish candle pattern = true; previous close < current confirmed support AND close < current confirmed support; cascaded weighted average crosses below its own previous value; transformed CCI < negative threshold. The VWAP is available only on intraday charts and resets at the configured calendar anchor.
Calculation: Signal state = initially neither long nor short; calculate both signals from the previous state, then set the state long if the long signal occurs and short if the short signal occurs, with short taking precedence if both occur. Position exits do not reset this state.
Calculation: ATR trailing line = close during the initial warmup bars; thereafter the rolling highest value of high minus an ATR multiple, using a separate highest-value lookback.
Calculation: Long indicator exit set = AND of every enabled condition: close > open + ATR times the profit multiplier; close > upper Bollinger band; close crosses below the ATR trailing line. Short indicator exit set = AND of every enabled condition: close < open - ATR times the stop multiplier; close < lower Bollinger band; close crosses above the ATR trailing line. An empty set is true.
Calculation: Percentage trailing stop = for a long position, the running maximum of close times (1 - trailing percentage), initialized from zero; for a short position, the running minimum of close times (1 + trailing percentage), initialized from a large positive value. Reset when the corresponding position is absent.
Calculation: Trailing profit trigger = signal-bar close times (1 + long trigger percentage) for a long or (1 - short trigger percentage) for a short, retained while that side is active. Once price reaches the trigger, trail the most favorable price by trigger times the configured deviation percentage and exit when price reaches that trailing level.
Long: long filter set = true AND previous signal state != long.
Short: short filter set = true AND previous signal state != short.
Long: bullish candle pattern = true AND candle-pattern filter enabled = true.
Short: bearish candle pattern = true AND candle-pattern filter enabled = true.
Long: displayed supertrend direction = bullish.
Short: displayed supertrend direction = bearish.
Long: displayed cascaded weighted average > its previous value.
Short: displayed cascaded weighted average < its previous value.
Exit: long, close < entry price times (1 - long stop percentage).
Exit: short, close > entry price times (1 + short stop percentage).
Exit: long, indicator exits enabled = true AND datetime within configured backtest range AND long indicator exit set = true.
Exit: short, indicator exits enabled = true AND datetime within configured backtest range AND short indicator exit set = true.
Exit: long, indicator exits enabled = false AND fixed profit enabled = true AND datetime within configured backtest range AND close > entry price times (1 + long profit percentage).
Exit: short, indicator exits enabled = false AND datetime within configured backtest range AND close < entry price times (1 - short profit percentage).
Exit: long, percentage trailing stop enabled = true AND signal state = long AND low <= percentage trailing stop.
Exit: short, percentage trailing stop enabled = true AND signal state = short AND high >= percentage trailing stop.
Exit: long, trailing profit enabled = true AND signal state = long AND trailing profit trigger reached AND low <= trailing profit level.
Exit: short, trailing profit enabled = true AND signal state = short AND trailing profit trigger reached AND high >= trailing profit level.
Exit: long, short filter set = true AND previous signal state != short AND long-only mode = false AND datetime within configured backtest range.
Exit: short, long filter set = true AND previous signal state != long AND short-only mode = false AND datetime within configured backtest range.
