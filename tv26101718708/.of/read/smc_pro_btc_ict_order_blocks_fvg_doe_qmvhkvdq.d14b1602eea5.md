Calculation: Confirmed swing high/low = a pivot high/low using the same number of bars on each side, available only after the right-side bars have completed. Retain the latest confirmed high and low separately.
Calculation: Structure direction = initially neutral; on each bar, update confirmed swings, set direction bullish if close > latest swing high, then set direction bearish if close < latest swing low; otherwise retain the previous direction. Calculate independently on the direction timeframe and the shorter confirmation timeframe using the same swing length. For either timeframe, use the last completed bar when it is higher than the chart timeframe, the last completed intrabar when lower, and the current completed bar when equal.
Calculation: Bullish order block = on a chart bar where close crosses above the latest swing high, retain the high and low of the most recent bearish candle within the order-block lookback. Bearish order block = on a chart bar where close crosses below the latest swing low, retain the high and low of the most recent bullish candle within that lookback. A crossover compares the current close with the current swing and the previous close with the previous swing. If no qualifying candle is found, retain the previous block and its validity. Invalidate a bullish block when close < its low and a bearish block when close > its high.
Calculation: Bullish fair value gap = when low > high two bars ago AND the previous close > previous open, retain the zone from that earlier high to current low. Bearish fair value gap = when high < low two bars ago AND the previous close < previous open, retain the zone from current high to that earlier low. Retain only the latest gap per direction; invalidate the bullish gap when close < its lower boundary and the bearish gap when close > its upper boundary.
Calculation: Bullish zone match = a valid bullish order block or gap with low <= its upper boundary AND close >= its lower boundary. Bearish zone match = a valid bearish order block or gap with high >= its lower boundary AND close <= its upper boundary.
Calculation: Bullish sweep = low < latest chart swing low AND close > that swing low. Bearish sweep = high > latest chart swing high AND close < that swing high. A sweep is recent if it occurred on the current bar or within the sweep-memory lookback.
Calculation: Long stop = the lower boundary of the matched bullish order block, or of the matched bullish gap if the block does not match, multiplied by one minus the stop buffer fraction. Short stop = the upper boundary of the matched bearish order block, or of the matched bearish gap if the block does not match, multiplied by one plus the stop buffer fraction. Fix the stop at the signal bar.
Calculation: Long target = signal-bar close + (signal-bar close - long stop) × reward-to-risk ratio. Short target = signal-bar close - (short stop - signal-bar close) × reward-to-risk ratio. Fix the target at the signal bar.
Long: Position is flat AND direction-timeframe structure direction = bullish AND confirmation-timeframe structure direction = bullish AND bullish sweep is recent AND bullish zone match = true AND close > open AND (selective mode is off OR close < latest chart swing low + (latest chart swing high - latest chart swing low) × zone threshold).
Short: Position is flat AND direction-timeframe structure direction = bearish AND confirmation-timeframe structure direction = bearish AND bearish sweep is recent AND bearish zone match = true AND close < open AND (selective mode is off OR close > latest chart swing high - (latest chart swing high - latest chart swing low) × zone threshold).
Exit: long, low <= long stop OR high >= long target.
Exit: short, high >= short stop OR low <= short target.
