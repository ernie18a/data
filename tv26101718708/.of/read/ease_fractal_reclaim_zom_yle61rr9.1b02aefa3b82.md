Calculation: Ease of Movement = SMA of ((current and previous bar midpoint difference) / box ratio), where midpoint = (high + low) / 2; box ratio = 1 when volume or high-low range is zero, otherwise (volume / 10000) / (high - low)
Calculation: Recent fractal midpoint = average of the latest recorded fractal high and low; a fractal high/low is the center bar's high/low when it equals the highest/lowest value in a centered window extending the lookback length on each side
Calculation: Bullish score = count of: Ease of Movement > 0 and rising; close > recent fractal midpoint; CCI > 0; close > open and absolute(close - open) > ATR × thrust multiplier
Calculation: Bearish score = count of: Ease of Movement < 0 and falling; close < recent fractal midpoint; CCI < 0; close < open and absolute(close - open) > ATR × thrust multiplier
Long: (bullish score >= selected signal threshold - 1 AND bullish score < selected signal threshold AND close > recent fractal midpoint) OR (bullish score >= selected signal threshold AND close > recent fractal midpoint AND current bar index - previous bar's last bullish signal bar index > cooldown length)
Short: (bearish score >= selected signal threshold - 1 AND bearish score < selected signal threshold AND close < recent fractal midpoint) OR (bearish score >= selected signal threshold AND close < recent fractal midpoint AND current bar index - previous bar's last bearish signal bar index > cooldown length)
