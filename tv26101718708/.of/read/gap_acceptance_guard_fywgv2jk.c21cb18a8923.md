Calculation: Acceptance boundary = previous close + gap size × acceptance-depth fraction, where gap size = event-bar open − previous close; freeze at episode start.
Calculation: Path efficiency = max(directional close-to-close progress from event-bar close, 0) ÷ cumulative absolute close-to-close movement since the event, × 100.
Long: On a confirmed bar with no active gap episode, current open − previous close ≥ minimum-gap multiple × ATR from the previous completed chart-timeframe bar, current close > acceptance boundary, and (full-gap filter is off OR current open > previous high), with intraday events limited to the first bar of each exchange day; OR during an active bullish gap episode, consecutive closes above the frozen acceptance boundary ≥ required count AND current high ≥ frozen event-bar high + extension multiple × frozen ATR AND path efficiency ≥ minimum.
Short: On a confirmed bar with no active gap episode, current open − previous close ≤ −minimum-gap multiple × ATR from the previous completed chart-timeframe bar, current close < acceptance boundary, and (full-gap filter is off OR current open < previous low), with intraday events limited to the first bar of each exchange day; OR during an active bearish gap episode, consecutive closes below the frozen acceptance boundary ≥ required count AND current low ≤ frozen event-bar low − extension multiple × frozen ATR AND path efficiency ≥ minimum.
Exit: Long, during an active bullish gap episode, current close < frozen acceptance boundary.
Exit: Short, during an active bearish gap episode, current close > frozen acceptance boundary.
