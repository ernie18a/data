Calculation: Active channel = Maintain confirmed pivot highs and lows using the same number of bars on each side; retain a limited number of the most recent pivots of each kind. When no channel is active, after the warmup period, scan on each new confirmed pivot or at a periodic rescan interval. For each side, use a limited number of the most recent pivots within the channel lookback. Test every pair as a straight line, in newest-first order. An upper candidate is valid when no selected high pivot exceeds it by more than an ATR-scaled deviation; a lower candidate is valid when no selected low pivot falls below it by more than that deviation. Count pivots within an ATR-scaled touch tolerance of each candidate, and select the valid candidate with the most touches on each side, keeping the first candidate on ties. Both lines must have at least the minimum touch count. At the earliest of their four anchor bars, calculate starting width as upper minus lower; calculate current width the same way. Accept the channel when current width > 0, convergence 1 − current width / starting width is at least the minimum convergence rate, current width is at least the minimum and less than the maximum ATR-scaled width, and the previous close lies between the two lines projected to the current bar. If starting width is not positive, use zero convergence. If the optional volume-contraction filter is enabled and current volume > 0, average volume from the bar after the earliest anchor through the detection bar must be less than a threshold times average volume over the preceding, equally long period, shortened if necessary to the available history; use the current volume SMA if a period is empty and use a ratio of one if the preceding average is zero. Freeze the selected line anchors until breakout or timeout. A channel remains active through the bar on which its age first exceeds the channel lookback, unless a breakout occurs, and is then deactivated. A breakout also deactivates it; a new scan cannot occur until a subsequent bar.
Calculation: Directional bias = Clamp to the range from zero to the full scale the midpoint plus half the full scale times the weighted sum of slope bias, RSI bias, and position bias. Slope bias is the channel midpoint's change per bar divided by an ATR-scaled slope normalization, clamped between negative and positive one. RSI bias is RSI's deviation from its midpoint divided by that midpoint. Position bias is twice the close's fraction of current channel width measured from the lower boundary, minus one; use zero if channel width is not positive. Slope and RSI have equal weights, each greater than the position weight, and all weights sum to one.
Long: Active channel exists AND close > upper channel boundary projected to the current bar.
Short: Active channel exists AND close < lower channel boundary projected to the current bar.
Long: Active channel exists AND directional bias > its midpoint.
Short: Active channel exists AND directional bias <= its midpoint.
