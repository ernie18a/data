Calculation: Directional sources = selectable backtest price fields for each long or short source; a source is active when its value > 0.
Calculation: Conditional direction = for each of three selectable long/short source pairs, either long when its long source > 0 and short source <= 0, and short when its short source > 0 and long source <= 0; or a persistent state initialized from those exclusive conditions and changed to long on a long-source transition from <= 0 to > 0 and to short on a short-source transition from <= 0 to > 0, with short taking precedence if both transition together.
Calculation: Conditional agreement = among enabled conditional pairs, require all, at least one, or at least the lesser of two and the number enabled to have the specified direction; with no enabled pairs, both directions pass.
Calculation: Signal agreement = among four selectable sources for the specified direction, require a selectable combination: the first, the first two, any of the four, the first three, any two of the first three, all four, any two of the four, or any three of the four sources > 0.
Calculation: Directional entry condition = signal agreement AND conditional agreement AND, if enabled, close > chart-timeframe HMA AND HMA minus its value a configurable number of bars earlier > minimum slope distance AND close minus HMA >= minimum price distance for long; close < chart-timeframe HMA AND HMA minus its value a configurable number of bars earlier < negative minimum slope distance AND HMA minus close >= minimum price distance for short; AND, if enabled, close > higher-timeframe HMA for long or close < higher-timeframe HMA for short. The higher-timeframe HMA uses the last completed higher-timeframe bar on historical bars and the still-forming higher-timeframe bar in real time.
Calculation: Entry gate = bar time in a configured New York time window if the time filter is enabled AND bar weekday in the configured weekdays if the day filter is enabled AND daily entry count below its limit or position is open if the daily limit is enabled AND position is not opposite if opposite entries are blocked. Daily entry count resets on each New York calendar day and increments when an entry-condition edge passes the gate while flat.
Calculation: Entry extremes = minimum and maximum entry prices of currently open legs; for long, the minimum is the trailing reference and maximum is the initial-stop reference; for short, the maximum is the trailing reference and minimum is the initial-stop reference.
Calculation: Long stop = initial-stop reference minus the configured static-stop distance if static stop is enabled; otherwise, if the floor of (peak since entry minus trailing reference) divided by brick size, with a small rounding tolerance, reaches the trailing activation threshold, peak minus trailing distance; otherwise initial-stop reference minus initial-stop distance. Peak is the highest high or highest close since entry, as selected.
Calculation: Short stop = initial-stop reference plus the configured static-stop distance if static stop is enabled; otherwise, if the floor of (trailing reference minus trough since entry) divided by brick size, with a small rounding tolerance, reaches the trailing activation threshold, trough plus trailing distance; otherwise initial-stop reference plus initial-stop distance. Trough is the lowest low or lowest close since entry, as selected.
Long: An enabled conditional pair's long source > 0 AND its short source <= 0 AND the same exclusive condition was false on the previous bar.
Short: An enabled conditional pair's short source > 0 AND its long source <= 0 AND the same exclusive condition was false on the previous bar.
Long: Long conditional agreement passes AND short conditional agreement fails.
Short: Short conditional agreement passes AND long conditional agreement fails.
Long: Directional entry condition for long changes from false to true AND entry gate passes AND, in per-source entry mode, at least one long source also changes from <= 0 to > 0 AND at least one long leg is available.
Short: Directional entry condition for short changes from false to true AND entry gate passes AND, in per-source entry mode, at least one short source also changes from <= 0 to > 0 AND at least one short leg is available.
Long: Automatic leg increment is enabled AND position is long AND directional entry condition for long passes AND time and weekday gates pass AND number of active long sources > number of open long legs.
Short: Automatic leg increment is enabled AND position is short AND directional entry condition for short passes AND time and weekday gates pass AND number of active short sources > number of open short legs.
Exit: long, low <= long stop OR static take profit is enabled AND high >= long trailing reference plus take-profit distance.
Exit: short, high >= short stop OR static take profit is enabled AND low <= short trailing reference minus take-profit distance.
Exit: long, forced window-end closure is enabled AND previous bar time was inside a configured New York time window AND current bar time is outside all configured windows; OR forced specific-time closure is enabled AND current New York time >= configured close time AND previous New York time < configured close time on the same day or the New York day changed.
Exit: short, forced window-end closure is enabled AND previous bar time was inside a configured New York time window AND current bar time is outside all configured windows; OR forced specific-time closure is enabled AND current New York time >= configured close time AND previous New York time < configured close time on the same day or the New York day changed.
Exit: long, opposite entries are allowed AND a short entry is triggered.
Exit: short, opposite entries are allowed AND a long entry is triggered.
