Calculation: Supertrend state = for each independently parameterized Supertrend, set basic lower and upper bands to source minus and plus ATR times multiplier. Set the lower band to max(basic lower, previous lower) when previous close > previous lower, otherwise basic lower; set the upper band to min(basic upper, previous upper) when previous close < previous upper, otherwise basic upper. Initialize the state as up; change down to up when close > previous upper, and up to down when close < previous lower; otherwise retain the previous state.
Calculation: Waddah momentum = sensitivity times the change in (shorter-lookback close moving average minus longer-lookback close moving average); positive and negative magnitudes are max(momentum, 0) and max(-momentum, 0). Explosion = Bollinger upper band minus lower band; dead zone = a multiplier times RMA of true range, with unavailable RMA replaced by zero.
Calculation: Entry-time exit levels = freeze the following at the signal bar close C: choose the first enabled method in ATR, candle extreme, percentage, pip order, or ATR if none is enabled. Let R be the base risk multiplier and Q the reward/risk ratio. ATR method: A = smoothed true range truncated to the configured decimal precision; long target and stop are C + A × R × Q and C - A × R; short target and stop are C - A × R × Q and C + A × R. Candle-extreme method: L and H are the lowest low and highest high over the lookback including the signal bar; long target and stop are C + (C - L) × R × Q and L × R; short target and stop are C - (H - C) × R × Q and H × R. Percentage method: with fraction P, long target and stop are C + C × P × R × Q and C - C × P × R; short target and stop are C - C × P × R × Q and C + C × P × R. Pip method: with configured price distance D, long target and stop are C + D × R × Q and C - D; short target and stop are C - D × R × Q and C + D.
Long: Any Supertrend state changes from down to up.
Short: Any Supertrend state changes from up to down.
Long: An entry-enabled Supertrend state changes from down to up AND every Supertrend matches its independently selected long-side state or has no state restriction AND each enabled filter holds: volume > its moving average; truncated smoothed true range > lower boundary AND < upper boundary AND, if selected, > or < its moving average; explosion > or < dead zone as selected; Waddah momentum > 0 for all trends, or positive magnitude >= its previous value for strong trends, or positive magnitude < its previous value for soft trends; Waddah magnitude > explosion AND > dead zone; close > the long-side price moving average; bar time strictly between the date boundaries; bar time within an enabled market session; bar time within an allowed trading day and session. When no individual trading-day filter is enabled, the global allowed days apply all day; otherwise an enabled hours window applies with its own enabled day set or the global day set, and any matching window qualifies.
Short: An entry-enabled Supertrend state changes from up to down AND every Supertrend matches its independently selected short-side state or has no state restriction AND each enabled filter holds: volume > its moving average; truncated smoothed true range > lower boundary AND < upper boundary AND, if selected, > or < its moving average; explosion > or < dead zone as selected; Waddah momentum <= 0 for all trends, or negative magnitude >= its previous value for strong trends, or negative magnitude < its previous value for soft trends; Waddah magnitude > explosion AND > dead zone; close < the short-side price moving average; bar time strictly between the date boundaries; bar time within an enabled market session; bar time within an allowed trading day and session. When no individual trading-day filter is enabled, the global allowed days apply all day; otherwise an enabled hours window applies with its own enabled day set or the global day set, and any matching window qualifies.
Exit: long, high >= frozen long target OR low <= frozen long stop.
Exit: short, low <= frozen short target OR high >= frozen short stop.
Exit: long OR short, an enabled custom session contained the previous sampled bar AND does not contain the current sampled bar; sample session membership using the bar still forming on the configured session-sampling timeframe, which may be higher or lower than the chart timeframe.
