Calculation: Relative strength = the stock’s return minus the benchmark’s return over the same lookback, using higher-timeframe daily bars and the current bar.
Calculation: Daily close location = (daily close − daily low) / (daily high − daily low), or 0.5 if the range is zero; use the higher-timeframe daily bar still forming.
Calculation: Daily breakdown = daily close < previous completed daily low OR (daily close < previous completed daily close AND daily close location < 20%).
Calculation: Healthy daily pullback = NOT daily breakdown AND daily close ≥ previous completed daily close AND daily close location ≥ 40%.
Calculation: Strong daily bar = daily close > previous completed daily close AND daily close > daily open AND daily close location ≥ 65%.
Calculation: Daily range in ATR = 100 × (daily high − daily low) / daily ATR; daily distance from high in ATR = (daily close − daily high) / daily ATR. Use higher-timeframe daily bars, with the current bar still forming.
Calculation: Same-time relative volume = cumulative regular-session volume so far divided by the average cumulative volume at the same intraday slot across prior sessions; use higher-timeframe intraday bars, including the bar still forming.
Long: daily close > daily 200-period EMA AND relative strength ≥ 0 AND (strong daily bar OR healthy daily pullback OR (daily close > daily open AND daily close location ≥ 50%)) AND NOT daily breakdown AND NOT (daily close < daily open AND daily close location < 20%) AND NOT (daily close ≤ daily 200-period EMA AND relative strength < 0) AND NOT ((daily range in ATR ≥ 150% AND daily close location < 30%) OR daily close location < 15% OR daily distance from high in ATR ≤ −1.00) AND (outside live regular session OR same-time relative volume unavailable OR same-time relative volume ≥ 0.80)
