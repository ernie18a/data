Calculation: Cyclic RSI = Let the cycle length be a parameter and the RSI length be half that cycle length. Calculate RSI from close using Wilder-smoothed gains and losses; use 100 when smoothed losses are zero and 0 when smoothed gains are zero. Let torque = 2 / (vibration + 1) and lag = integer((vibration - 1) / 2), where vibration is a parameter. Cyclic RSI = torque * (2 * RSI - RSI[lag]) + (1 - torque) * prior cyclic RSI, with missing prior cyclic RSI replaced by 0.
Calculation: Cyclic RSI bands = Over a memory length proportional to the cycle length, initialize maximum and minimum to 0; scan cyclic RSI from current to oldest, updating maximum if the value exceeds maximum, otherwise updating minimum if it is below minimum. Divide the resulting range into equal steps. The lower band is the first ascending step at which the fraction of memory values strictly below the step reaches a parameterized fraction. The upper band is the first descending step at which the fraction of memory values greater than or equal to the step reaches that fraction. Initialize each band to 0 if no step qualifies.
Calculation: Cyclic RSI top and bottom = A top occurs when cyclic RSI was rising for the selected detector lookback and falls on the current bar; a bottom occurs when it was falling for that lookback and rises on the current bar. The detector has a shorter and a longer setting; the longer setting requires one more consecutive prior move. Comparisons are strict. The extremum is on the preceding bar, but the decision occurs on the current bar.
Calculation: Corrective wave sequence = A candidate A is a cyclic RSI bottom with the preceding bar's cyclic RSI below its lower band. A candidate B is a cyclic RSI top with the preceding bar's cyclic RSI below its cyclic RSI WMA or below a parameterized midpoint. A candidate C is a candidate A or a cyclic RSI bottom with the preceding bar's cyclic RSI below its cyclic RSI WMA. An AB sequence occurs at a candidate B if a candidate A is found within a parameterized prior-bar search window and cyclic RSI is below its WMA on every scanned prior bar through that candidate. Extend AB to ABC with candidate C, ABC to ABCD with candidate B, ABCD to ABCDE with candidate C, ABCDE to ABCDEF with candidate B, and ABCDEF to ABCDEFG with candidate C, applying the same bounded backward search and below-WMA requirement at each extension. Wave A is candidate A excluding ABC and ABCDE; wave B is AB excluding ABCD; waves C, D, E, F and G are respectively ABC, ABCD, ABCDE, ABCDEF and ABCDEFG. Sequence matches can overlap.
Calculation: Divergence comparison points = A low point is a candidate C. A high point is a cyclic RSI top whose preceding cyclic RSI is at or above its upper band, or whose preceding cyclic RSI is below its upper band and current cyclic RSI is above its WMA. Compare current cyclic RSI and current close with their values on the most recent earlier point of the same kind within a parameterized search window; use the detection bars, not the preceding extremum bars.
Calculation: Filtered strategy signal = Accept a raw strategy signal only if no previously accepted signal of the same side occurred within a parameterized preceding-bar window; apply this recursively to accepted signals.
Calculation: Strategy order size = Normalize a band to a parameterized interval by clamping it to the interval and scaling it to zero through one. The sell fraction is the normalized upper band; replace it with a larger parameterized fraction when cyclic RSI exceeds an extreme threshold. The buy fraction is one minus the normalized lower band; replace it with a parameterized full-size fraction if wave E or G occurred within a parameterized window including the current bar. Set a fraction below a parameterized minimum to zero, multiply by the corresponding maximum order size, and round to the nearest whole unit.
