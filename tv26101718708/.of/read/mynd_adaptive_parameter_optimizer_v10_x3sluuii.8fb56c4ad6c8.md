Calculation: Adaptive length = At each recalibration, choose the candidate length with the highest mean signed forward close return over the evaluation window, considering only candidates with enough events; test up to 25 configured candidate lengths. In moving-average mode, events are close crossings above or below the candidate SMA, scored respectively by forward return or its negative. In RSI mode, events are RSI below the oversold threshold or above the overbought threshold, scored respectively by forward return or its negative. Keep the prior length if no candidate qualifies; use the minimum candidate length before the first recalibration.
Calculation: Adaptive RSI = RSI calculated with Wilder smoothing using the adaptive length.
Long: In moving-average mode, previous close <= previous SMA using the adaptive length AND current close > current SMA using the adaptive length AND (volume confirmation disabled OR current volume >= volume moving average × confirmation multiplier)
Long: In RSI mode, previous adaptive RSI <= oversold threshold AND current adaptive RSI > oversold threshold AND (volume confirmation disabled OR current volume >= volume moving average × confirmation multiplier)
Short: In moving-average mode, previous close >= previous SMA using the adaptive length AND current close < current SMA using the adaptive length AND (volume confirmation disabled OR current volume >= volume moving average × confirmation multiplier)
Short: In RSI mode, previous adaptive RSI >= overbought threshold AND current adaptive RSI < overbought threshold AND (volume confirmation disabled OR current volume >= volume moving average × confirmation multiplier)
