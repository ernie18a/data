Calculation: Adopted length = Initialize to the minimum candidate length. On bars whose zero-based index is divisible by the recalibration interval, once a rolling close buffer contains evaluation-window length + maximum candidate length + forward-evaluation length + 60 bars, score up to 25 candidate lengths in ascending order from the minimum by the candidate step; each candidate is capped at the maximum. If the maximum is below the minimum, test only the maximum. For each candidate, score events in the current buffer using the selected mode. In moving-average mode, examine buffer indices from the maximum candidate length through the last index minus the forward-evaluation length; an event is a close crossing above or below the candidate-length close SMA. In RSI mode, seed average gain and loss with the mean gains and losses over the first candidate-length close changes, then apply Wilder smoothing with that length through the last index minus the forward-evaluation length; examine indices starting at candidate length + 30, counting every RSI value below the oversold level or above the overbought level as an event. For each event, calculate the forward close return over the forward-evaluation length, using zero if the event close is not positive; retain its sign for upward-cross or oversold events and reverse it for downward-cross or overbought events. Candidate fitness is the mean signed return. Among candidates with at least the minimum event count, adopt the one with the highest fitness, choosing the shortest tested candidate on a tie; if none qualifies, retain the previous length. Recalibrate before calculating the current bar's live values.
Calculation: Adaptive RSI = Initialize average gain and average loss to the first available close gain and loss. On every subsequent bar, update each as (previous average × (current adopted length − 1) + current gain or loss) / current adopted length, without resetting when the length changes. Gain is max(close change, 0) and loss is max(−close change, 0). Relative strength is average gain / average loss when average loss > 0, 999999 when average loss = 0 and average gain > 0, and 0 otherwise. Adaptive RSI is 100 − 100 / (1 + relative strength). Use the same relative-strength convention for candidate RSI.
Long: ((moving-average mode AND close crosses above the adopted-length close SMA) OR (RSI mode AND adaptive RSI crosses above the oversold level)) AND (volume confirmation disabled OR volume >= volume SMA × volume multiplier)
Short: ((moving-average mode AND close crosses below the adopted-length close SMA) OR (RSI mode AND adaptive RSI crosses below the overbought level)) AND (volume confirmation disabled OR volume >= volume SMA × volume multiplier)
