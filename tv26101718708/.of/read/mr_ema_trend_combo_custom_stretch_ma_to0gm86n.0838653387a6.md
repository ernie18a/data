Calculation: fastEMA, slowEMA = EMA of close; fastEMA uses the shorter lookback, slowEMA the longer one. Both are computed on the chart timeframe with the current bar's values.
Calculation: z = EMA(zRaw, smoothing length shorter than the lookback of the EMA in zRaw), where zRaw = (close - EMA(close, mean lookback)) / max(sigma, tiny epsilon). sigma = sqrt(max(ewVar, tiny epsilon)). ewMean = ewMean + a*(close - ewMean), seeded with the first close. dev = close - ewMean, using the updated ewMean. ewVar = (1-a)*ewVar + a*dev^2, seeded with dev^2. a = 1 - exp(-ln2 / halfLife). All on the chart timeframe.
Calculation: stretchMA = moving average of close (EMA by default, other types selectable) with a lookback of its own, computed separately for the long side and the short side (long-side and short-side parameters may differ). stretchPrice = close, or low on the long side and high on the short side if wick mode is chosen. The wick option is a single setting shared by both sides.
Calculation: ArmedLong = state, initially false. It becomes true on a bar where the Long MR trigger (first Long line) is true AND fastEMA < slowEMA. It resets to false on a bar where fastEMA crosses above slowEMA, after that bar's signals are evaluated. A bar that starts a run also counts as armed for the signals on that same bar. LongStretchFired = flag that is cleared whenever a run starts or ends. It is set after a stretch signal fires.
Calculation: ArmedShort = state, initially false. It becomes true on a bar where the Short MR trigger (first Short line) is true AND fastEMA >= slowEMA. It resets to false on a bar where fastEMA crosses below slowEMA, after that bar's signals are evaluated. A bar that starts a run also counts as armed for the signals on that same bar. ShortStretchFired = flag that is cleared whenever a run starts or ends. It is set after a stretch signal fires.
Long: z[1] <= -longWeakThreshold AND z[1] is a local minimum of z (z[1] < z[0] AND z[1] <= z[2]); evaluated on the bar after the pivot, with no trend filter. The 'strong' variant is the same condition with a larger threshold magnitude and is a subset of it.
Long: ArmedLong AND fastEMA crosses above slowEMA (previous fastEMA <= previous slowEMA AND current fastEMA > current slowEMA).
Long: stretch override enabled AND ArmedLong AND NOT LongStretchFired AND stretchMA > 0 AND (stretchMA - stretchPrice) / stretchMA * 100 >= longStretchPct. This fires once per armed run (early signal; it does not clear the run).
Short: z[1] >= shortWeakThreshold AND z[1] is a local maximum of z (z[1] > z[0] AND z[1] >= z[2]); evaluated on the bar after the pivot, with no trend filter. The 'strong' variant is the same condition with a larger threshold and is a subset of it.
Short: ArmedShort AND fastEMA crosses below slowEMA (previous fastEMA >= previous slowEMA AND current fastEMA < current slowEMA).
Short: stretch override enabled AND ArmedShort AND NOT ShortStretchFired AND stretchMA > 0 AND (stretchPrice - stretchMA) / stretchMA * 100 >= shortStretchPct. This fires once per armed run (early signal; it does not clear the run).
