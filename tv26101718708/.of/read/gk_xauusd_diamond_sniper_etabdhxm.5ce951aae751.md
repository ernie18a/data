Calculation: Zero-lag EMA = EMA of close + (close - close lagged by floor((EMA length - 1) / 2) bars); when the lag is zero, use close as the EMA input. Use a shorter length for the fast line and a longer length for the main line.
Calculation: Prior range high and low = highest high and lowest low over the range lookback, excluding the current bar.
Calculation: Base long event = on a completed bar, close > prior range high + breakout buffer AND fast line > main line AND close > main line AND main line - previous main line > ATR × minimum slope factor AND abs(fast line - main line) > ATR × minimum separation factor AND high - low > ATR × minimum candle factor AND close > previous high AND close > open AND abs(close - main line) >= ATR × minimum distance factor AND the most recent base event was not long AND bars since the most recent base event >= cooldown; permit the first event when no previous base event exists. Calculate and maintain this event independently on each source timeframe.
Calculation: Base short event = on a completed bar, close < prior range low - breakout buffer AND fast line < main line AND close < main line AND main line - previous main line < -ATR × minimum slope factor AND abs(fast line - main line) > ATR × minimum separation factor AND high - low > ATR × minimum candle factor AND close < previous low AND close < open AND abs(close - main line) >= ATR × minimum distance factor AND the most recent base event was not short AND bars since the most recent base event >= cooldown; permit the first event when no previous base event exists. Calculate and maintain this event independently on each source timeframe.
Calculation: Projected event = the source timeframe's base event mapped to the chart with gaps filled and no lookahead. For a higher source timeframe use its last completed bar; for a lower source timeframe use the last source bar within each chart bar; for an equal timeframe use the chart bar. An event is newly projected when the mapped event is true and its value on the preceding chart bar was not true.
Long: chart timeframe is permitted AND fast line > main line AND close > main line.
Short: chart timeframe is permitted AND fast line < main line AND close < main line.
Long: chart timeframe is permitted AND chart-timeframe base long event is true.
Short: chart timeframe is permitted AND chart-timeframe base short event is true.
Long: chart timeframe is permitted AND a base long event is newly projected from the configurable arrow source timeframe, which may be higher than, equal to, or lower than the chart timeframe.
Short: chart timeframe is permitted AND a base short event is newly projected from the configurable arrow source timeframe, which may be higher than, equal to, or lower than the chart timeframe.
Long: chart timeframe is permitted AND a base long event is newly projected from a lower source timeframe AND the most recent diamond event was not long; permit the first diamond event when none exists.
Short: chart timeframe is permitted AND a base short event is newly projected from a lower source timeframe AND the most recent diamond event was not short; permit the first diamond event when none exists.
Exit: long, chart timeframe is permitted AND the position follows a chart-timeframe base long event AND the current chart bar is after the entry bar AND high >= entry price + main target distance AND this target has not already been hit since that entry.
Exit: short, chart timeframe is permitted AND the position follows a chart-timeframe base short event AND the current chart bar is after the entry bar AND low <= entry price - main target distance AND this target has not already been hit since that entry.
Exit: long, chart timeframe is permitted AND the position follows a diamond long event AND the current chart bar is after the entry bar AND high >= entry price + diamond target distance AND this target has not already been hit since that entry; use the projected lower-timeframe signal bar's close as entry price, or the chart close if unavailable.
Exit: short, chart timeframe is permitted AND the position follows a diamond short event AND the current chart bar is after the entry bar AND low <= entry price - diamond target distance AND this target has not already been hit since that entry; use the projected lower-timeframe signal bar's close as entry price, or the chart close if unavailable.
