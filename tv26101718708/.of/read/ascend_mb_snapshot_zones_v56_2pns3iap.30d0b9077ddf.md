Calculation: Snapshot zones = At each enabled snapshot time, build volume profiles over the configured source windows: at the first snapshot, a longer historical lookback and a shorter recent lookback; at the second, the preceding auction window and the recent lookback; at the optional later snapshot, the preceding auction window. Each lookback includes the current chart bar; an auction window supplies its number of completed bars as the lookback length and is used only when it contains at least two bars. For each profile, divide its high-to-low range into equal price bins and allocate each bar's volume to bins in proportion to their overlap with the bar's high-to-low range, using a minimum price increment as the minimum bar range and as bin width if the profile range is zero. Sort bin volumes ascending and set the threshold to the configured percentile element, using the floored bin-count times percentile as its zero-based index. Select positive-volume bins at or below the threshold in ascending volume order, breaking ties by ascending price, subject to the maximum number of zones and minimum distance between selected bin midpoints for that profile. Process each selected bin in order: if merging is enabled and it overlaps an existing zone within the configured price tolerance, merge it into the first such zone in insertion order, extend the zone to the union of their price ranges, increment its count, and add the current snapshot tag; otherwise create a zone with count one and the current snapshot tag. Retain at most the configured maximum number of zones, deleting the oldest first. Optionally clear all zones at each new day. For each snapshot tag, select the zone with that tag and the highest count at or above the configured minimum; break count ties in favor of the latest zone in insertion order.
Long: For any selected snapshot zone, close > zone top + configured price buffer.
Short: For any selected snapshot zone, close < zone bottom - configured price buffer.
