Calculation: Snapshot zones = at each configured snapshot, use chart-timeframe bars to build volume-by-price bins over the configured lookback; the historical lookback is longer than the recent-trend lookback, while auction lookbacks cover their configured auction window. Allocate each bar’s volume to each intersecting bin in proportion to the overlap with its high-low range. Select the lowest-volume bins at or below the configured volume percentile, subject to configured count and spacing limits; each bin’s price bounds form a zone. Merge overlapping zones within the configured tolerance and count merged zones. For each snapshot, select its highest-count merged zone that meets the configured minimum overlap count; otherwise there is no zone.
Calculation: Confirmation buffer = configured price-distance threshold.
Long: For any selected snapshot zone, close > zone upper bound + confirmation buffer
Short: For any selected snapshot zone, close < zone lower bound - confirmation buffer
