Calculation: Opening range = highest high and lowest low of chart bars in the configured opening-range session, using the configured session timezone; reset at the start of each opening-range session and mark complete on the first bar outside it.
Calculation: Evaluation window = opening range is complete AND the current bar is in the configured active session AND outside the opening-range session.
Calculation: Retest-zone width = ATR multiplied by a parameter, clamped between configured minimum and maximum widths.
Calculation: Break and failure state = reset both directional break flags and failure flags at the start of each opening-range session. During the evaluation window, set each break flag on the first close beyond its corresponding opening-range boundary. On a later bar, set the corresponding failure flag when close crosses back inside that boundary. Flags remain set until reset.
Calculation: Confirmation state = reset both directional active flags and stored confirmation levels at the start of each opening-range session. On each long confirmation, set the long active flag and store that bar's high; on each short confirmation, set the short active flag and store that bar's low. A trigger uses the active flag and stored level from the previous bar, then clears its corresponding active flag after current-bar confirmations have been recorded.
Calculation: Relative volume = volume divided by its simple moving average, defined only when that average is positive.
Long: Evaluation window AND upper break flag was false before this bar AND close > opening-range high.
Short: Evaluation window AND lower break flag was false before this bar AND close < opening-range low.
Long: Evaluation window AND upper break flag is true AND upper failure flag is false AND low <= opening-range high + retest-zone width AND high >= opening-range high - retest-zone width AND close > opening-range high AND close > open.
Short: Evaluation window AND lower break flag is true AND lower failure flag is false AND high >= opening-range low - retest-zone width AND low <= opening-range low + retest-zone width AND close < opening-range low AND close < open.
Long: Evaluation window AND previous-bar long active flag is true AND upper failure flag is false AND high > previous-bar stored long confirmation high AND (volume filter is disabled OR relative volume >= configured threshold).
Short: Evaluation window AND previous-bar short active flag is true AND lower failure flag is false AND low < previous-bar stored short confirmation low AND (volume filter is disabled OR relative volume >= configured threshold).
Long: Upper break flag is true AND lower break flag is false AND upper failure flag is false.
Short: Lower break flag is true AND upper break flag is false AND lower failure flag is false.
Long: Neither trigger occurs on the current bar AND (long active flag is true OR (short active flag is false AND evaluation window AND upper break flag is true AND upper failure flag is false AND low <= opening-range high + retest-zone width AND high >= opening-range high - retest-zone width)).
Short: Neither trigger occurs on the current bar AND long active flag is false AND (short active flag is true OR (evaluation window AND lower break flag is true AND lower failure flag is false AND high >= opening-range low - retest-zone width AND low <= opening-range low + retest-zone width AND NOT (upper break flag is true AND upper failure flag is false AND low <= opening-range high + retest-zone width AND high >= opening-range high - retest-zone width))).
