Calculation: Candle measures = range = max(high - low, epsilon); close location = (close - low) / range; body ratio = abs(close - open) / range; upper wick = high - max(open, close); lower wick = min(open, close) - low; wick imbalance = (upper wick - lower wick) / range.
Calculation: Market measures = volume ratio = volume / SMA(volume); volume trend = short-term SMA(volume) / long-term SMA(volume); compression = short-term ATR / long-term ATR; ATR expansion = ATR / its value a lookback ago; slope = current linear-regression estimate of close minus the preceding estimate from the same regression; breakout distance = (close - prior rolling highest high) / ATR when close is above that high, (prior rolling lowest low - close) / ATR when close is below that low, otherwise zero. Use epsilon as the minimum denominator.
Calculation: Event families = volatility breakout when true range > ATR times a threshold AND close location > an upper threshold OR close location < a lower threshold, with optional volume confirmation; structure break when close > prior rolling highest high OR close < prior rolling lowest low, AND breakout distance > a threshold, with optional volume confirmation; volume shock when volume ratio > a threshold AND (true range > ATR times a threshold OR body ratio > a threshold); absorption when volume ratio > a threshold AND body ratio < a threshold AND (upper wick > range times a threshold OR lower wick > range times a threshold); regime shift when (ATR expansion > a threshold AND compression a lookback ago < a threshold) OR (ADX increase over a lookback > a threshold AND true range > ATR times a threshold). Volume confirmation means volume ratio > its threshold. Parenthesize the volatility breakout close-location alternatives together.
Calculation: Event direction sum = sum the active families' directions: volatility breakout is +1 for close location above its upper threshold and -1 otherwise; structure break is +1 for an upward break and -1 otherwise; volume shock is +1 when close > open, -1 when close < open, otherwise zero; absorption is +1 when lower wick > upper wick and -1 otherwise; regime shift is +1 when close > close a lookback ago and -1 otherwise. An inactive family contributes zero.
Calculation: Event = the selected event family is active, or at least a threshold number of families are active in composite mode; the bar is complete; sufficient history exists for the shape window, projection horizon and an additional warm-up; and at least the minimum event gap has elapsed since the previous event. The dominant event type is the first active family in this order: structure break, volatility breakout, volume shock, absorption, regime shift.
Calculation: Market regime = volume shock if volume ratio and true range relative to ATR exceed their respective thresholds; otherwise volatility expansion if ATR expansion or compression exceeds its respective threshold; otherwise compression if compression is below its threshold; otherwise uptrend if ADX exceeds a threshold, positive directional indicator exceeds negative directional indicator and slope is positive; otherwise downtrend if ADX exceeds the threshold, negative directional indicator exceeds positive directional indicator and slope is negative; otherwise range.
Calculation: Fingerprint = the vector of tanh((close - close at the start of the shape window) / (ATR * square root of window length)), tanh(slope / ATR times a scale), tanh(compression - 1), tanh(true range / ATR - 1), close location mapped from [0,1] to [-1,1], body ratio mapped likewise, tanh(wick imbalance times a scale), tanh((rolling highest high - close) / ATR times a scale), tanh((close - rolling lowest low) / ATR times a scale), tanh(breakout distance), tanh(volume ratio - 1), tanh(volume trend - 1), ATR percentile rank mapped from [0,1] to [-1,1], tanh(ATR expansion - 1), tanh(ADX / a scale - 1), and evenly spaced shape samples tanh((sample close - close at the start of the shape window) / (ATR * square root of window length)). Use epsilon as the minimum denominator.
Calculation: Analog bias = anchor at the current bar or latest event. Anchor direction is the sign of close change over the shape window for a current-bar anchor, or the sign of the event direction sum for an event anchor. For an event anchor, search earlier stored events within the memory lookback and at least the projection horizon plus event gap before the anchor; optionally require matching direction and dominant event type. Score each candidate as capped exponential decay of its weighted root-mean-square fingerprint distance plus regime, direction and type mismatch penalties, multiplied by a recency boost. Regime mismatch is penalized less when both regimes are trends. Select the highest-scoring candidates up to the maximum count, subject to minimum match quality; if enabled and too few qualify, select from all candidates instead. If no event analogs are selected and bar-window fallback is enabled, search all historical bars within the memory lookback and at least the horizon plus event gap before the anchor; score them using the same fingerprint distance, regime penalty and recency boost, without event direction or type penalties; select the highest scores up to the maximum count, applying the quality threshold unless fallback to closest is enabled. For each selected analog, project its close change over the horizon from the anchor, scaled by a bounded anchor-ATR-to-analog-ATR ratio and a path scale; optionally reverse the change when analog direction opposes nonzero anchor direction. Analog direction is the stored event direction for event candidates and the sign of the analog's close change over its shape window for bar candidates. Up fraction = number of projected final closes above the anchor divided by the number of selected analogs. When analogs exist and engine-driven bias is enabled, bias is up if up fraction >= an upper threshold, down if up fraction <= a lower threshold, and mixed otherwise. Otherwise bias is the anchor direction.
Long: Event AND (event direction sum > 0 OR (event direction sum = 0 AND close > close at the start of the shape window)).
Short: Event AND (event direction sum < 0 OR (event direction sum = 0 AND close < close at the start of the shape window)).
Long: Analog bias = up.
Short: Analog bias = down.
