Calculation: Profile period = a configurable higher timeframe; select the shortest permitted period at least a configured minimum number of chart bars long. Use the last completed period for prior value and the still-forming period through the current closed chart bar for developing POC. The first loaded period is incomplete; a prior profile is valid only if its period was complete and contains at least the configured minimum number of chart bars.
Calculation: Time-at-price profile = at each period open, set the row width to the preceding period's high-low range divided by a configurable row count; if that range is unavailable or nonpositive, use the opening chart bar's range times a configurable fallback factor. Floor the width at a configurable minimum price increment. Anchor a fixed-size row grid at the period's opening price, with the anchor at its configured center index; clamp prices outside the grid to its edge rows. For each closed chart bar, increment every row from its low's row through its high's row. Update the POC incrementally while visiting those rows in ascending order: replace the current POC when the updated row count is greater, or when equal and its midpoint is strictly closer to that bar's close. The POC price is the selected row's midpoint.
Calculation: Prior value area = for the last completed valid profile, start at its POC row and expand until the included row counts reach a configured fraction of all counts. At each step compare the sum of the next two available row counts above with the sum of the next two below, treating missing rows as zero; add one row on the greater side, choosing above on a tie, unless that side is exhausted. The lower edge is the bottom of the lowest included row and the upper edge is the top of the highest included row. Require upper edge > lower edge.
Calculation: Excursion state = within each profile period, count consecutive closes strictly above the prior upper edge and separately strictly below the prior lower edge; reset each count to zero when its condition fails. An acceptance threshold is a configurable duration converted to chart bars by rounding up, subject to a configurable minimum bar count. Remember whether each direction's count has ever reached the threshold during the period, regardless of POC migration. Reset all counts, acceptance flags and per-signal emitted flags at each new period. Track the highest high of the current above excursion and lowest low of the current below excursion.
Long: Prior value area is valid AND the above count is at least the acceptance threshold AND no long acceptance signal has occurred in the current period AND (migration filtering is disabled OR developing POC > prior POC).
Short: Prior value area is valid AND the below count is at least the acceptance threshold AND no short acceptance signal has occurred in the current period AND (migration filtering is disabled OR developing POC < prior POC).
Long: Prior value area is valid AND close is within or on its edges AND the preceding bar's below count is greater than zero and less than the acceptance threshold AND the below acceptance flag is false AND no long failed-auction signal has occurred in the current period.
Short: Prior value area is valid AND close is within or on its edges AND the preceding bar's above count is greater than zero and less than the acceptance threshold AND the above acceptance flag is false AND no short failed-auction signal has occurred in the current period.
Calculation: Active plan = on every signal, replace any existing plan and fix its entry at the signal close. Let width be the prior upper edge minus the prior lower edge. For long acceptance, stop = upper edge minus a configurable fraction of width and target = upper edge plus a larger configurable fraction of width; for short acceptance, stop = lower edge plus the stop fraction and target = lower edge minus the target fraction. For long failed auction, stop = minimum of the completed below-excursion low and signal-bar low minus the developing profile's row width, and target = prior upper edge; for short failed auction, stop = maximum of the completed above-excursion high and signal-bar high plus the developing profile's row width, and target = prior lower edge. Evaluate plan exits only after the signal bar; stop takes precedence if stop and target are both touched on the same bar.
Exit: long, a later bar's low <= active-plan stop OR a later bar's high >= active-plan target OR a new profile period begins.
Exit: short, a later bar's high >= active-plan stop OR a later bar's low <= active-plan target OR a new profile period begins.
