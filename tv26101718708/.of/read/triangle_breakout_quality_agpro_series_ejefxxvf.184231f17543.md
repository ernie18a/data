Calculation: Triangle = On each bar, retain the two most recent confirmed pivot highs and the two most recent confirmed pivot lows, using the same number of bars on each side for all pivots. Project a straight upper boundary through the highs and a straight lower boundary through the lows. The start bar is the earlier of the older high and older low; age is the current bar index minus the start bar. Starting width and current width are upper minus lower at the respective bars. Compression is 100 × (starting width − current width) / starting width. The apex is the intersection of the boundaries, rounded to the nearest bar; bars to apex is its bar index minus the current bar index.
Calculation: Valid triangle = Both pairs of anchors exist AND age is between the minimum and maximum pattern ages, inclusive AND starting width > 0 AND current width > 0 AND starting width / ATR >= minimum starting-width threshold AND current width / ATR <= maximum current-width threshold AND compression >= minimum compression threshold AND upper boundary slope < lower boundary slope AND bars to apex is between the permitted past-apex limit and maximum forward-apex limit, inclusive. ATR is floored at a minimum price increment; before ATR is available, use true range instead.
Calculation: Breakout score = Round the sum of: 22 × clamp((compression − minimum compression) / max(compression score ceiling − minimum compression, 1), 0, 1); 22 × (0.45 × clamp(1 − abs(bars to apex − preferred apex distance) / max(maximum forward-apex limit, 1), 0, 1) + 0.55 × clamp(1 − current width / ATR / max(maximum current-width threshold, 0.1), 0, 1)); 22 × clamp(breakout distance / max(ATR × impulse scale, minimum price increment), 0, 1); 16 × clamp(abs(close − open) / bar range, 0, 1); 8 × clamp(close position, 0, 1); and volume participation. Bar range is max(high − low, minimum price increment). Breakout distance is close minus upper boundary for an upward breakout, or lower boundary minus close for a downward breakout. Close position is (close − low) / bar range for an upward breakout, or (high − close) / bar range for a downward breakout. Volume participation is 10 × clamp((volume / SMA(volume) − 1) / max(full-score volume ratio − 1, 0.1), 0, 1) when enabled, using a volume ratio of 1 if the average is unavailable or nonpositive; otherwise it is 7. Clamp(x, 0, 1) limits x to the inclusive range from 0 to 1.
Calculation: Tracked breakout = A breakout whose rounded breakout score >= minimum score AND whose structure key differs from the last tracked breakout's key OR whose bar is more than the cooldown number of bars after the last tracked breakout. Apply the score requirement to both alternatives. The key is the sum of the four pivot bar indices. On a tracked breakout, replace any previously tracked breakout and save its side, bar, and broken boundary anchors. Project that saved boundary forward on subsequent bars. Tracking ends at the first held retest, failed retest, or bar after the retest window; a failed retest occurs after the breakout bar when close is below the saved upper boundary minus ATR × retest tolerance for an upward breakout, or above the saved lower boundary plus ATR × retest tolerance for a downward breakout.
Long: Valid triangle AND close > current upper boundary + ATR × breakout buffer AND previous close <= the current triangle's upper boundary projected to the previous bar.
Short: Valid triangle AND close < current lower boundary − ATR × breakout buffer AND previous close >= the current triangle's lower boundary projected to the previous bar.
Long: Tracked upward breakout is still active AND bars since breakout are within the retest window, inclusive AND high >= saved boundary − ATR × retest tolerance AND low <= saved boundary + ATR × retest tolerance AND close > saved boundary AND low >= saved boundary − ATR × retest tolerance.
Short: Tracked downward breakout is still active AND bars since breakout are within the retest window, inclusive AND high >= saved boundary − ATR × retest tolerance AND low <= saved boundary + ATR × retest tolerance AND close < saved boundary AND high <= saved boundary + ATR × retest tolerance.
