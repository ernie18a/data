Calculation: Pressure = EMA-smoothed weighted average (non-negative weights) of four components, all on the chart timeframe, each clipped to [-1,+1]. Pressure is the result scaled to a -100..+100 oscillator. (1) Momentum = (close - close N bars ago) / (ATR * scale). (2) Flow = F / (SMA(volume) * multiple), where F = F_prev * decay + (volume if close>open, -volume if close<open, else 0) per bar, and F resets to 0 at the first bar of each day. (3) Trend = average of the slopes of a shorter-length EMA of close and a longer-length EMA of close, each slope = (EMA - EMA k bars ago) / k, each divided by (ATR * scale). (4) Body = (close - open) / (high - low) * min(volume / SMA(volume), cap).
Long: Pressure crosses above 0 (previous <= 0, current > 0) OR Pressure crosses above +strong threshold OR Pressure > +extreme threshold (extreme threshold > strong threshold > 0)
Short: Pressure crosses below 0 (previous >= 0, current < 0) OR Pressure crosses below -strong threshold OR Pressure < -extreme threshold (same thresholds, negated)
