Calculation: total score = adaptive RSI direction score (+3 if its adaptive filtered value rises, −3 if it falls, otherwise 0) + TD count score (+2 if the current up count exceeds its prior reset count, else −2 if the down count does, else 0) + custom Supertrend trend score (+1 up, −1 down) + ROC(20) score (+1 if positive, otherwise −1) + DMI(5) score (+2 if +DI−−DI ≥ 0, otherwise −2) + CCI(21) score (+2 if positive, otherwise −2) + Weis Wave volume trend score (+2 for up wave, otherwise −2) + recursive SMA(20) score (add 1 when close > SMA(20), otherwise subtract 1) + Awesome Oscillator score (+1 if positive, −1 if negative, otherwise 0) + 14-bar momentum score (+1 if positive, −1 if negative, otherwise 0) + MACD histogram direction score (+3 if the histogram rises, otherwise −3) + 30-bar bull/bear balance score (+1 if its smoothed balance is positive, otherwise −1) + Ichimoku base-line score (+1 if close is above the 26-bar base line, otherwise −1) + Hull moving average score (+2 if close is above HMA(close, 21), otherwise −2). The custom Supertrend uses an EMA(5) of a volume-weighted price-spread series as its center, ATR(7) bands at 3 ATR, and the usual trailing-band trend state. The adaptive RSI direction score uses a 2-period EMA of close to separate gains and losses, recursively smooths each over 14 bars, forms an RSI, then applies an adaptive dead-band filter using 20-bar efficiency ratio and 7-/13-bar standard deviations of twice the RSI; score the filtered value's direction.
