Calculation: Pivot source = Apply the selected filter independently to high and low: none, SMA, EMA, RMA, HMA, WMA applied twice, VWMA applied three times, slope-adjusted SMA, or Kalman filter. The slope-adjusted SMA is SMA(source, length) + (source - source[length]) / 2. For the Kalman filter, initialize estimate to the first source and error to 1; on each bar set predicted error = error + 1 / length, gain = predicted error / (predicted error + 1), estimate = estimate + gain × (source - estimate), and error = (1 - gain) × predicted error.
Calculation: Zigzag points = On each completed chart bar, test the pivot source at the configured depth bars ago against source values at offsets 1 through twice the depth, excluding the candidate offset. A high must be strictly greater than every compared high; a low must be strictly less than every compared low. Process a high before a low when both occur. Add the first pivot. For a subsequent pivot of the same type, replace the last point only if the new high is higher or the new low is lower. For an opposite-type pivot, append it only if its absolute price distance from the last point is at least the current bar's threshold, chosen as ATR × multiplier or close × percentage. Retain the most recent 100 points.
Calculation: Tracked structures = On each completed bar, inspect the latest three zigzag points A, B, C, even if no pivot was added on that bar. A structure is new if its three point bar indices do not match any currently tracked structure. When accepted, store references to its points and mark it active; later replacement of a referenced zigzag point also updates that stored point. Retain only the configured maximum number of structures, removing the oldest first. After adding a structure, invalidate each active tracked structure whose direction-specific exit condition is met; either remove it or retain it as inactive according to the configured invalidation action. Inactive retained structures still count for duplicate detection and the maximum.
Long: The latest zigzag points are low A, high B, low C AND A price < C price < B price AND the structure is new AND (the Bollinger filter is disabled OR previous close > previous SMA of close) AND (the ADX filter is disabled OR current ADX >= threshold) AND signal lock is inactive.
Short: The latest zigzag points are high A, low B, high C AND B price < C price < A price AND the structure is new AND (the Bollinger filter is disabled OR previous close < previous SMA of close) AND (the ADX filter is disabled OR current ADX >= threshold) AND signal lock is inactive.
Exit: long, invalidation is enabled AND an active tracked bullish structure exists AND previous close < its A price.
Exit: short, invalidation is enabled AND an active tracked bearish structure exists AND previous close > its A price.
