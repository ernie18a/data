Calculation: Momentum = clamp((HMA(MFI of typical price or RSI of close, momentum smoothing length) - 50) × 2 × amplification, -100, 100), replacing an unavailable HMA with 50.
Calculation: Price current = either clamp(100 × scale × (HMA(VWMA(close)) - its value two bars earlier) / its value two bars earlier, -100, 100), using zero when the earlier value is unavailable or zero, or clamp(HMA(signed ADX), -100, 100), replacing an unavailable HMA with zero. Signed ADX is positive when +DI >= -DI and negative otherwise. Its HMA length is independent of the momentum smoothing length.
Calculation: Forecast of a series = clamp(current value + (current value - value at the slope lookback) / slope lookback × forecast horizon × decay^forecast horizon, -100, 100); the slope lookback is capped at the forecast horizon.
Calculation: Angle of a price series = atan(((current value - value at lookback) / lookback) / standard deviation of its one-bar changes over that lookback), in degrees. If the standard deviation is zero, use signed saturation for a nonzero mean change and zero otherwise.
Calculation: Price-series regime = up if both its short- and long-lookback angles are >= the trend threshold; otherwise down if both are <= the negative trend threshold; otherwise sideways if both absolute angles are < the sideways threshold; otherwise neutral.
Calculation: Angle consensus = up or down when that category has strictly more votes than each other category among the close, high, and low price-series regimes; otherwise sideways.
Calculation: Choppiness index = 100 × log10(sum of true range over the lookback / (highest high - lowest low over the lookback)) / log10(lookback), or the neutral midpoint when the range or true-range sum is nonpositive.
Calculation: Markov probabilities = maintain separate decaying transition-count tables for short and long durations of the angle-consensus state. On each bar decay every count, then increment the cell for (state two bars ago, previous state) to current state in the table selected by the previous state's duration. For the next-state probabilities, select the table by current state duration and the row by (previous state, current state); add a pseudocount to each of the three counts and normalize. Confidence requires the undecorated row-count sum to be >= the minimum sample threshold. The predicted state is the highest-probability state, with ties favoring up, then down, then sideways.
Calculation: Bull confluence = momentum forecast > 0 AND price-current forecast > 0 AND (choppiness filter disabled OR (choppiness index < threshold AND angle consensus is up or down)).
Calculation: Bear confluence = momentum forecast < 0 AND price-current forecast < 0 AND (choppiness filter disabled OR (choppiness index < threshold AND angle consensus is up or down)).
Calculation: Bull hatchling = Markov enabled AND Markov confidence threshold met AND angle consensus is sideways AND up probability >= hatchling threshold.
Calculation: Bear hatchling = Markov enabled AND Markov confidence threshold met AND angle consensus is sideways AND down probability >= hatchling threshold.
Calculation: Bull projection = momentum forecast > 0 AND price-current forecast > 0 AND (Markov disabled OR confidence threshold not met OR predicted state is not down).
Calculation: Bear projection = momentum forecast < 0 AND price-current forecast < 0 AND (Markov disabled OR confidence threshold not met OR predicted state is not up).
Long: Bull confluence is true AND bull confluence was false on the preceding bar.
Short: Bear confluence is true AND bear confluence was false on the preceding bar.
Long: (choppiness filter disabled OR choppiness index < threshold) AND (choppiness filter disabled OR angle consensus is up or down OR bull hatchling OR bear hatchling) AND (bull projection OR (bull hatchling AND bear projection is false)).
Short: (choppiness filter disabled OR choppiness index < threshold) AND (choppiness filter disabled OR angle consensus is up or down OR bull hatchling OR bear hatchling) AND (bear projection OR (bear hatchling AND bull hatchling is false AND bull projection is false)).
Long: Choppiness index < threshold AND angle consensus is up.
Short: Choppiness index < threshold AND angle consensus is down.
Long: Markov enabled AND confidence threshold met AND current angle consensus is not up AND up probability >= down probability when current consensus is sideways AND up probability >= sideways probability when current consensus is down.
Short: Markov enabled AND confidence threshold met AND current angle consensus is not down AND down probability > up probability when current consensus is sideways AND down probability >= sideways probability when current consensus is up.
