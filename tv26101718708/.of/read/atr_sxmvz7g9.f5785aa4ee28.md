Calculation: Other-indicator filter = (CCI filter disabled OR (long: CCI > oversold threshold and CCI > prior CCI; short: CCI < overbought threshold and CCI < prior CCI)) AND (volatility filter disabled OR ATR(14)/close >= minimum) AND (distance/structure filter disabled OR (long: close - Alligator lips >= minimum distance in ticks AND lips > teeth > jaw AND close > lips; short: lips - close >= minimum distance in ticks AND lips < teeth < jaw AND close < lips)). Use unshifted Alligator lines; each is an SMMA of (high+low)/2, with jaw lookback longest, teeth intermediate, lips shortest.
Calculation: Dow signal = +1 when volume > its 20-bar SMA times a threshold, ATR(14)/close exceeds a volatility threshold, and close > SMA(close,20) > SMA(close,50); -1 when the volume and volatility conditions hold and close < SMA(close,20) < SMA(close,50); otherwise 0. Use chart-timeframe bars.
Calculation: Dow filter = Other-indicator filter AND (volume > volume SMA(20) times a threshold) AND (ATR(14)/close > a volatility threshold).
Calculation: KAMA state = +1 on the fast KAMA crossing above the slow KAMA, -1 on it crossing below, otherwise retain the prior state; fast KAMA uses the shorter lookback. KAMA is Kaufman’s adaptive moving average.
Calculation: VWMA state = +1 when close crosses above VWMA(close), -1 when it crosses below, otherwise retain the prior state.
Calculation: Alligator state = +1 when lips > teeth > jaw and close > lips; -1 when lips < teeth < jaw and close < lips; otherwise retain the prior state.
Calculation: ATR trail state = +1 when fast ATR trailing stop > medium stop > slow stop, -1 when fast < medium < slow, otherwise 0. Each stop uses a close-based ATR trailing stop; its distance is ATR times a multiplier, and the stop trails in the direction of price. Filtered ATR trail state changes to +1 when the ATR trail state changes from nonpositive to +1, to -1 when it changes from nonnegative to -1, and otherwise retains its prior state; a direction is filtered to 0 when its Other-indicator filter fails.
Calculation: Gaussian trend = DEMA(close) smoothed by a finite Gaussian-weighted average, then by an SMMA. Its upper band is the smoothed value plus standard deviation of that value times an upper multiplier; its lower band is the smoothed value minus standard deviation times a lower multiplier. GST state is +1 when close is above the upper band, -1 when close is below the lower band, otherwise 0. Filtered GST state is 0 when its direction's Other-indicator filter fails.
Calculation: Filtered KAMA, VWMA, and Alligator states = their respective states set to 0 when the Other-indicator filter for that direction fails.
Calculation: Long score = 2 for bullish Dow signal + 2 for bullish filtered ATR trail state + 1 each for bullish filtered GST, KAMA, VWMA, and Alligator states, counting only enabled signals. Short score is the corresponding weighted sum of bearish states. Dow signals use the Dow filter.
Long: Long score >= 3 AND flat AND optional enabled long ADX, RSI, and NATR filters pass; OR an enabled KAMA bullish crossover, VWMA bullish crossover, Alligator state change to +1, Dow state change to +1, filtered ATR trail state change to +1, or GST state change to +1, with the corresponding direction filter passing.
Short: Short score >= 3 AND flat AND optional enabled short ADX, RSI, and NATR filters pass; OR an enabled KAMA bearish crossover, VWMA bearish crossover, Alligator state change to -1, Dow state change to -1, filtered ATR trail state change to -1, or GST state change to -1, with the corresponding direction filter passing.
Exit: long, short score >= 3 OR close <= entry price times (1 - stop-loss percentage).
Exit: short, long score >= 3 OR close >= entry price times (1 + stop-loss percentage).
