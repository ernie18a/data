Calculation: Alligator lines = SMMA of (high + low) / 2, with shortest lookback for lips, intermediate lookback for teeth, and longest lookback for jaw; use unshifted values.
Calculation: ATR trail = recursively, with previous trail defaulting to zero and distance = ATR × multiplier: if current and previous close are both above previous trail, max(previous trail, close − distance); else if both are below previous trail, min(previous trail, close + distance); otherwise close − distance if close > previous trail, else close + distance. Calculate fast, medium, and slow trails with progressively longer ATR lookbacks and larger multipliers.
Calculation: ATR trail state = initially neutral; change to long when fast > medium > slow and the preceding bar did not have that alignment; change to short when fast < medium < slow and the preceding bar did not have that alignment; otherwise retain the previous state.
Calculation: KAMA state = initially neutral; change to long when shorter-lookback KAMA crosses above longer-lookback KAMA, change to short on the opposite cross, and otherwise retain the previous state. Both use the same fast and slow smoothing parameters.
Calculation: VWMA state = initially neutral; change to long when close crosses above VWMA, change to short when close crosses below VWMA, and otherwise retain the previous state.
Calculation: Alligator state = initially neutral; change to long when lips > teeth > jaw AND close > lips; change to short when lips < teeth < jaw AND close < lips; otherwise retain the previous state.
Calculation: Dow state = long when close > shorter-lookback close SMA > longer-lookback close SMA AND volume SMA > 0 AND volume > volume SMA × volume threshold AND NATR > volatility threshold; short when close < shorter-lookback close SMA < longer-lookback close SMA AND the same volume and volatility comparisons hold; otherwise neutral.
Calculation: Gaussian trend = DEMA of close followed by a Gaussian weighted average of current and preceding DEMA values, with weight exp(−0.5 × ((lag − (lookback − 1) / 2) / sigma)²), normalized by the sum of weights; smooth the result recursively with coefficient 1 / smoothing lookback, using the Gaussian value before the smoothing lookback is reached and seeding with DEMA of the Gaussian value if the previous smoothed value is unavailable.
Calculation: Gaussian trend state = long when close > Gaussian trend + upper multiplier × standard deviation of Gaussian trend; short when close < Gaussian trend − lower multiplier × standard deviation of Gaussian trend; otherwise neutral.
Calculation: Directional confirmation score = weighted sum of enabled indicator states matching the direction: Dow and ATR trail each have twice the weight of Gaussian trend, KAMA, VWMA, and Alligator. Count a matching state only when its directional filter comparisons in the corresponding signal line below hold; Dow is always enabled.
Long: position side is flat AND long confirmation score >= confirmation threshold AND, when enabled, long minimum <= ADX <= long maximum AND, when enabled, long minimum <= RSI <= long maximum AND, when enabled, long minimum <= NATR <= long maximum.
Short: position side is flat AND short confirmation score >= confirmation threshold AND, when enabled, short minimum <= ADX <= short maximum AND, when enabled, short minimum <= RSI <= short maximum AND, when enabled, short minimum <= NATR <= short maximum AND the long entry condition is false.
Long: shorter-lookback KAMA crosses above longer-lookback KAMA AND, when enabled, CCI > oversold threshold AND CCI > previous CCI AND, when enabled, NATR >= minimum volatility AND, when enabled, close − lips >= minimum price distance AND lips > teeth > jaw AND close > lips.
Short: shorter-lookback KAMA crosses below longer-lookback KAMA AND, when enabled, CCI < overbought threshold AND CCI < previous CCI AND, when enabled, NATR >= minimum volatility AND, when enabled, lips − close >= minimum price distance AND lips < teeth < jaw AND close < lips.

Short: close crosses below VWMA AND the optional short CCI, volatility, distance, and Alligator comparisons in the KAMA short line hold.

Short: ATR trail state changes to short AND the optional short CCI, volatility, distance, and Alligator comparisons in the KAMA short line hold.
