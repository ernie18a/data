Calculation: Pair log-ratio z-score = standardize ln(close(A) / close(B)) by its rolling mean and standard deviation; use closes from the engine timeframe (equal to or higher than the chart timeframe), using the last completed engine bar.
Calculation: Pair integrity score = 100 × (0.45 × normalized rolling return correlation + 0.30 × normalized absolute change in the rolling log-ratio mean over a shorter lookback, scaled by the z-score standard deviation + 0.25 × normalized ratio of short-lookback to longer-lookback log-ratio standard deviations); each component is clamped to [0, 1], with drift and volatility components decreasing as drift or volatility expansion increases.
Long: z-score < 0 AND pair integrity score >= minimum AND ((absolute z-score >= entry threshold for the configured number of consecutive engine bars, with no active stretch state) OR (absolute z-score >= deep-stretch threshold AND previous absolute z-score < deep-stretch threshold))
Short: z-score > 0 AND pair integrity score >= minimum AND ((absolute z-score >= entry threshold for the configured number of consecutive engine bars, with no active stretch state) OR (absolute z-score >= deep-stretch threshold AND previous absolute z-score < deep-stretch threshold))
Exit: long or short, absolute z-score <= reversion threshold AND previous absolute z-score > reversion threshold
