Calculation: Timeframe score = 0.35 × trend score + 0.25 × momentum score + 0.20 × candle score + 0.20 × (trend score × volume score), where trend score is 1 if close is above the mid-term EMA, −1 if below, else 0; momentum score is 1 if close is above its longer-lookback close, −1 if below, else 0; candle score is 1 if (close − open) / (high − low) > 0.25, −1 if < −0.25, else 0 (use 0 when high = low); volume score is 1 if volume / its moving-average volume ≥ 1.5, 0.5 if ≥ 1, else 0. For each configured timeframe, calculate from that timeframe’s bars; the timeframes may be higher or lower than the chart timeframe, using the latest completed bar in the backtest.
Calculation: Final score = 0.10 × first timeframe score + 0.15 × second timeframe score + 0.25 × third timeframe score + 0.30 × fourth timeframe score + 0.20 × fifth timeframe score.
Long: final score > 0 OR (final score ≥ 0.70 AND close > mid-term EMA AND short-term EMA > mid-term EMA)
Short: final score < 0 OR (final score ≤ −0.70 AND close < mid-term EMA AND short-term EMA < mid-term EMA)
