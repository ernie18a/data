Calculation: Smoothed regression = EMA of the linear regression of close at the current bar, using independently configurable regression and smoothing lengths.
Calculation: Andean components = with alpha = 2 / (length + 1), recursively set upper first moment to max(close, open, previous upper first moment + alpha × (close − previous upper first moment)), upper second moment to max(close², open², previous upper second moment + alpha × (close² − previous upper second moment)), lower first moment to min(close, open, previous lower first moment + alpha × (close − previous lower first moment)), and lower second moment to min(close², open², previous lower second moment + alpha × (close² − previous lower second moment)). Initialize the moments to close, close², close, and close² respectively. Bull component = sqrt(lower second moment − lower first moment²); bear component = sqrt(upper second moment − upper first moment²).
Calculation: ATR trend = if RSI of close is at least its midpoint, max(previous ATR trend, low − multiplier × SMA of true range); otherwise min(previous ATR trend, high + multiplier × SMA of true range). Replace a missing previous ATR trend with zero.
Calculation: Cloud = if bull component > bear component, max(previous cloud, min(fast EMA of close, smoothed regression, ATR trend two bars ago)); otherwise, if bear component > bull component, min(previous cloud, max(fast EMA of close, smoothed regression, ATR trend two bars ago)); otherwise previous cloud. Replace a missing previous cloud with zero.
Calculation: Cloud direction = long if cloud exceeds each of its preceding two values; short if cloud is below each of its preceding two values; otherwise its previous direction.
Calculation: Confirmed pivot high or low = a high or low identified using the same number of bars on each side, available only after the right-hand bars have completed. Upper swing = highest value of the latest confirmed pivot high over a sizing lookback; lower swing = lowest value of the latest confirmed pivot low over that lookback.
Calculation: Long stop = lower swing when cloud direction changes to long or is not long; otherwise previous long stop. Short stop = upper swing when cloud direction changes to short or is not short; otherwise previous short stop.
Calculation: Tracked high = current high when flat; when in a position, current high if it exceeds the previous bar's high, otherwise previous tracked high. Tracked low = current low when flat; when in a position, current low if it is below the previous bar's low, otherwise previous tracked low.
Calculation: Long eligibility = cloud direction is long AND close > cloud AND datetime is inside the configured backtest interval AND position side is flat or short. Short eligibility = cloud direction is short AND close < cloud AND datetime is inside the configured backtest interval AND position side is flat or long.
Calculation: Long entry flag = if cloud direction changes to long, 1; otherwise, if re-entry is enabled AND tracked low crosses below long stop, 0; otherwise, if position side is long, 1; otherwise, if cloud direction is short, 0; otherwise its previous value. Short entry flag = if cloud direction changes to short, 1; otherwise, if re-entry is enabled AND tracked high crosses above short stop, 0; otherwise, if position side is short, 1; otherwise, if cloud direction is long, 0; otherwise its previous value.
Calculation: On any change of long eligibility, long reference price = current open position's entry price if position side is flat or long; otherwise unavailable. On other bars retain the preceding long reference price while position side is flat or long; otherwise it is unavailable. Calculate short reference price symmetrically on any change of short eligibility, retaining it only while position side is flat or short.
Calculation: On any change of long eligibility, each long target = long reference price × (1 + ((current open position's entry price − lower swing) / current open position's entry price) × its risk-reward parameter); otherwise retain its previous value while long and set it to zero while not long. On any change of short eligibility, each short target = short reference price × (1 − ((upper swing − current open position's entry price) / current open position's entry price) × its risk-reward parameter); otherwise retain its previous value while short and set it to zero while not short. Each side has two targets with separate risk-reward and position-percentage parameters.
Long: Long entries enabled AND long eligibility differs from its previous value AND previous long entry flag = 0.
Short: Short entries enabled AND short eligibility differs from its previous value AND previous short entry flag = 0.
Long: High-volume bar marking enabled AND close > open AND volume > multiplier × SMA of volume.
Short: High-volume bar marking enabled AND close < open AND volume > multiplier × SMA of volume.
Exit: long, cloud direction changes to short.
Exit: short, cloud direction changes to long.
Exit: long, take-profit/stop-loss enabled AND low <= long stop.
Exit: short, take-profit/stop-loss enabled AND high >= short stop.
Exit: long, take-profit/stop-loss enabled AND high >= a long target; exit that target's configured percentage of the position.
Exit: short, take-profit/stop-loss enabled AND low <= a short target; exit that target's configured percentage of the position.
