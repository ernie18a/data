Calculation: Confirmed swing high/low = a pivot high/low with the configured number of chart bars on both sides; use only after the right-side bars have closed.
Calculation: Breakout quality score = clamp to 0–10 and round to 0.1: add 2 for at least 5 zone tests, 1.5 for 4, 1 for 3, otherwise 0.5; add 1/0.7/0.4 for zone age >=120/60/25 bars; add 1/0.7/0.4 for breakout candle body/range >=0.85/0.70/0.55; add 1/0.7/0.4 for candle range/ATR >=2.5/1.7/1.1; add 1.5/1.1/0.7/0.4 for volume/20-bar volume SMA >=2.5/2.0/1.5/1.3; add momentum points: when both 3-bar and 5-bar close changes point in the trade direction, add min(1.5, 0.4*abs(3-bar change)/(close*0.001)+0.3*abs(5-bar change)/(close*0.001)); when only one does, add min(0.8, 0.3*abs(3-bar change)/(close*0.001)); when neither does, subtract 0.5. Add 0.5 if close is more than 0.3 zone widths beyond the broken level and RSI(14) is >55 for long or <45 for short; otherwise add 0.25 if the distance condition alone holds. Add 1 if both breakout engines trigger, and 0.5 if aligned with the higher-timeframe EMA filter.
Calculation: Higher-timeframe EMA = EMA of close on a timeframe higher than the chart timeframe, using the last completed higher-timeframe bar.
Calculation: Risk distance = clamp the distance from entry price to a stop beyond the broken zone by an ATR buffer, between the configured minimum and maximum ATR risk distances. Long stop = entry price − risk distance; short stop = entry price + risk distance. Targets 1, 2, and 3 = entry price ± risk distance times their respective configured R multiples, positive for long and negative for short.
Long: Flat position AND cooldown elapsed (or disabled) AND (bullish break of a tested pivot-high zone OR bullish break above the latest confirmed swing high) AND breakout quality score >= minimum score (and >= strong threshold if that filter is enabled) AND (higher-timeframe filter disabled, EMA unavailable, or close > higher-timeframe EMA) AND (no valid short setup or long score >= short score). A tested-zone break requires a bullish candle opening at/below a resistance zone and closing above it, with close above the highest high of the preceding pivot-period bars; the zone contains at least the configured minimum number of confirmed pivot highs within one ATR-based zone width of its highest level, and that level is above the preceding pivot-period highest high. A swing-high break requires close (or high if wick confirmation is selected) above the latest confirmed swing high.
Short: Flat position AND cooldown elapsed (or disabled) AND (bearish break of a tested pivot-low zone OR bearish break below the latest confirmed swing low) AND breakout quality score >= minimum score (and >= strong threshold if that filter is enabled) AND (higher-timeframe filter disabled, EMA unavailable, or close < higher-timeframe EMA) AND (no valid long setup or short score > long score). A tested-zone break requires a bearish candle opening at/above a support zone and closing below it, with close below the lowest low of the preceding pivot-period bars; the zone contains at least the configured minimum number of confirmed pivot lows within one ATR-based zone width of its lowest level, and that level is below the preceding pivot-period lowest low. A swing-low break requires close (or low if wick confirmation is selected) below the latest confirmed swing low.
Exit: long, low <= stop OR high >= target 3; if stop and any target are touched on the same bar, count the stop unless target 3 had already been reached on an earlier bar. If target 1 or 2 was reached earlier, a subsequent stop touch exits at the highest target reached.
Exit: short, high >= stop OR low <= target 3; if stop and any target are touched on the same bar, count the stop unless target 3 had already been reached on an earlier bar. If target 1 or 2 was reached earlier, a subsequent stop touch exits at the highest target reached.
