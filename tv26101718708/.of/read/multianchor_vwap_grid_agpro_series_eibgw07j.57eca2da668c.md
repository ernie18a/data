Calculation: Active anchored VWAPs = enabled, available volume-weighted averages of (high + low + close) / 3, accumulated from each anchor through the current chart bar. The anchors are the latest confirmed swing high, latest confirmed swing low, start of the currently forming higher-timeframe period, latest strictly highest high in loaded history, and start of the current session. Confirm swing pivots using equal numbers of preceding and subsequent chart bars; when confirmed, accumulate from the pivot bar. The session VWAP is available only during the session. Exclude the highest-high VWAP on intraday charts if its intraday-hiding option is enabled.
Long: The number of active anchored VWAPs below close is greater than the number at or above close.
Short: The number of active anchored VWAPs below close is less than the number at or above close.
