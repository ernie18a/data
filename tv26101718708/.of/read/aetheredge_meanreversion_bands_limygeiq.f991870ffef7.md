Calculation: Stretch = (close − basis) / standard deviation(close, basis lookback), where basis is an EMA or SMA.
Calculation: Fade features = [clamp(|stretch|, 0, 5), clamp(|EMA(short) − EMA(long)| / ATR, 0, 5), clamp(side × (RSI − 50) / 50, −1, 1), clamp(standard deviation / SMA(standard deviation, longer lookback) − 1, −1, 3), clamp(volume / SMA(volume, lookback) − 1, −1, 3), clamp(side × (basis − basis[3]) / ATR, −3, 3), clamp(consecutive bars with |stretch| ≥ 1 / 10, 0, 3)]; side is +1 for positive stretch and −1 otherwise.
Calculation: Reversion probability = sigmoid of a learned linear score on the fade features; train online by logistic gradient descent when each touch resolves. A touch resolves as success if stretch changes side or |stretch| ≤ revert level; otherwise as failure if |stretch| ≥ its touch |stretch| + extend distance; otherwise at the horizon it succeeds if |stretch| ≤ half its touch |stretch|, and fails otherwise. Check these outcomes in that order.
Calculation: Adaptive threshold = max(minimum probability floor, threshold arm with the highest UCB score for the current regime). Regime is the tercile of the 100-bar percentile rank of |EMA(short) − EMA(long)| / ATR. Use candidate probability-threshold arms; update each arm's mean reward and count for every resolved touch in that touch's regime. Reward is the outcome (1/0) when reversion probability meets that arm's threshold, otherwise the updated overall success rate; UCB score is mean reward + exploration coefficient × sqrt(log(regime touch count + 1) / arm count), treating untried arms as highest priority.
Long: bar close is confirmed AND bar index exceeds warmup AND |stretch| ≥ touch threshold AND previous bar |stretch| < touch threshold AND stretch < 0 AND reversion probability ≥ adaptive threshold.
Short: bar close is confirmed AND bar index exceeds warmup AND |stretch| ≥ touch threshold AND previous bar |stretch| < touch threshold AND stretch > 0 AND reversion probability ≥ adaptive threshold.
