Calculation: Bull score = count of true conditions: fast EMA of close > slow EMA of close AND close > slow EMA; MACD line > MACD signal; RSI > midpoint AND RSI < upper bound; ADX > threshold AND positive DI > negative DI; volume > volume SMA multiplied by a factor; higher-timeframe close > higher-timeframe EMA of close. Higher-timeframe calculations use the last completed higher-timeframe bar on historical chart bars, becoming available at its closing chart bar; they use the forming higher-timeframe bar in real time.
Calculation: Bear score = count of true conditions: fast EMA of close < slow EMA of close AND close < slow EMA; MACD line < MACD signal; RSI < midpoint AND RSI > lower bound; ADX > threshold AND negative DI > positive DI; volume > volume SMA multiplied by a factor; higher-timeframe close < higher-timeframe EMA of close. Use the same higher-timeframe bar selection and corresponding parameters as the bull score.
Calculation: Long setup = bull score >= entry threshold AND bull score > bear score AND absolute difference between scores >= neutral-gap threshold AND, if enabled, close > session VWAP AND, if enabled, bar time within configured session AND bars since most recent exit > cooldown threshold, or no previous exit exists, AND, if enabled, absolute difference between fast and slow EMA > ATR multiplied by a factor AND, if enabled, at least an alignment threshold of these conditions hold: higher-timeframe fast EMA > higher-timeframe slow EMA, higher-timeframe close > higher-timeframe EMA, higher-timeframe RSI > midpoint AND, if enabled, the latest confirmed pivot high > the preceding confirmed pivot high AND the latest confirmed pivot low > the preceding confirmed pivot low AND, if enabled, (low < lowest low of the preceding lookback bars AND close > that lowest low) OR close > highest high of the preceding lookback bars AND, if enabled, close > open AND candle body divided by high minus low >= body threshold AND close >= high minus candle range multiplied by a factor. Pivots use equal numbers of bars on each side and are available only after the right-side bars complete; the higher-timeframe alignment uses the same bar selection as the bull score.
Calculation: Short setup = bear score >= entry threshold AND bear score > bull score AND absolute difference between scores >= neutral-gap threshold AND, if enabled, close < session VWAP AND, if enabled, bar time within configured session AND bars since most recent exit > cooldown threshold, or no previous exit exists, AND, if enabled, absolute difference between fast and slow EMA > ATR multiplied by a factor AND, if enabled, at least an alignment threshold of these conditions hold: higher-timeframe fast EMA < higher-timeframe slow EMA, higher-timeframe close < higher-timeframe EMA, higher-timeframe RSI < midpoint AND, if enabled, the latest confirmed pivot high < the preceding confirmed pivot high AND the latest confirmed pivot low < the preceding confirmed pivot low AND, if enabled, (high > highest high of the preceding lookback bars AND close < that highest high) OR close < lowest low of the preceding lookback bars AND, if enabled, close < open AND candle body divided by high minus low >= body threshold AND close <= low plus candle range multiplied by a factor. Use corresponding parameters and higher-timeframe bar selection as in the long setup.
Calculation: Trailing stop = for a long, the maximum of entry close minus entry ATR multiplied by the trailing factor and each subsequent close minus its ATR multiplied by that factor; for a short, the minimum of entry close plus entry ATR multiplied by the trailing factor and each subsequent close plus its ATR multiplied by that factor. Update it before testing the trailing exit.
Calculation: Phase = initially neutral; evaluate both entries and the score/VWAP exits using the phase and most recent exit bar from before the current bar. Apply score/VWAP exits first, setting phase to neutral and recording the exit bar; then apply long entry followed by short entry, setting phase to the corresponding side and initializing its trailing stop. Update the trailing stop and evaluate trailing exits afterward; a trailing exit sets phase to neutral and records the exit bar. A direct reversal can produce an entry and an exit on the same bar.
Long: Long setup is true AND prior phase is not long AND, if close confirmation is enabled, the chart bar is closed.
Short: Short setup is true AND prior phase is not short AND, if close confirmation is enabled, the chart bar is closed.
Exit: long, prior phase is long AND (short setup is true OR bull score <= exit threshold OR close < session VWAP) AND, if close confirmation is enabled, the chart bar is closed.
Exit: short, prior phase is short AND (long setup is true OR bear score <= exit threshold OR close > session VWAP) AND, if close confirmation is enabled, the chart bar is closed.
Exit: long, phase after score/VWAP exits and entries is long AND close < updated trailing stop AND, if close confirmation is enabled, the chart bar is closed.
Exit: short, phase after score/VWAP exits and entries is short AND close > updated trailing stop AND, if close confirmation is enabled, the chart bar is closed.
