Calculation: Calendar-week bin = calendar week of the chart bar's closing time, with the final week capped at the preceding bin.
Calculation: Bernstein probability for a target calendar-week bin = percentage of eligible chart bars in the selected lookback and maximum bar count whose close exceeds the previous close, among bars in that bin whose closing time and previous bar's closing time are in the same calendar year and whose previous close is positive; use 50% if there are no eligible bars. Include the current bar if eligible.
Calculation: Seasonal probability for a target calendar-week bin = percentage of all available chart bars in that bin after the first bar whose close exceeds the previous close; use 50% if there are no samples. Include the current bar.
Calculation: Monthly probability = percentage of eligible observations for the target calendar month that rose, or 50% if none. Use either chart bars selected and tested as for Bernstein probability but grouped by closing month, or monthly observations constructed from chart bars: compare the last available close in each month with the last close of the preceding month, require the preceding close to be positive, and group by the newer month's closing month. Apply the selected monthly lookback and maximum bar count; include the current observation.
Calculation: Trading-day probability = percentage of eligible lower-timeframe bars for the target trading-day ordinal whose close exceeds their open, or 50% if none. Number available lower-timeframe bars from one within each calendar month; use valid nonzero-open bars from the selected number of complete prior calendar years, either matching the target month or pooling all months. Include only ordinals within the configured maximum. Use completed lower-timeframe bars and any bar still forming. The sample requirement is the selected number of years for a matching month, or that number multiplied by the number of calendar months when pooling.
Calculation: Future-window probability = mean Bernstein probability for the configured number of successive calendar-week bins after the current bin, wrapping at the year boundary.
Calculation: Current-window probability = mean Bernstein probability for the configured number of successive calendar-week bins starting with the current bin, wrapping at the year boundary.
Long: Bernstein probability for a displayed target calendar-week bin >= reliability threshold OR (Bernstein probability for that bin < reliability threshold AND 100% - Bernstein probability for that bin < reliability threshold AND Bernstein probability for that bin >= directional threshold).
Short: Bernstein probability for a displayed target calendar-week bin < reliability threshold AND (100% - Bernstein probability for that bin >= reliability threshold OR Bernstein probability for that bin <= 100% - directional threshold).
Long: Selected Bernstein probability or seasonal probability for a displayed target calendar-week bin >= reliability threshold OR (selected probability < reliability threshold AND 100% - selected probability < reliability threshold AND selected probability >= directional threshold).
Short: Selected Bernstein probability or seasonal probability for a displayed target calendar-week bin < reliability threshold AND (100% - selected probability >= reliability threshold OR selected probability <= 100% - directional threshold).
Long: Bernstein probability for a displayed target calendar-week bin >= directional threshold OR current-window probability >= directional threshold OR future-window probability >= directional threshold OR monthly probability for the current month >= directional threshold.
Short: Bernstein probability for a displayed target calendar-week bin <= 100% - directional threshold OR current-window probability <= 100% - directional threshold OR future-window probability <= 100% - directional threshold OR monthly probability for the current month <= 100% - directional threshold.
Long: Trading-day sample count >= sample requirement AND trading-day probability for the current ordinal >= directional threshold.
Short: Trading-day sample count >= sample requirement AND trading-day probability for the current ordinal <= 100% - directional threshold.
Long: Trading-day sample count >= sample requirement AND trading-day probability for a displayed target ordinal >= reliability threshold AND trading-day probability for that ordinal >= directional threshold.
Short: Trading-day sample count >= sample requirement AND 100% - trading-day probability for a displayed target ordinal >= reliability threshold AND trading-day probability for that ordinal <= 100% - directional threshold.
