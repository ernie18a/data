Calculation: Bullish confluence = count of these five conditions: close above the Hull moving average; higher-timeframe close above its Hull moving average; RSI above 50; higher-timeframe RSI above 50; close above the midpoint of the rolling highest high and lowest low. The higher-timeframe conditions use the current higher-timeframe bar, including while it is forming. Use the same Hull and RSI lookbacks on both timeframes.
Calculation: Bearish confluence = five minus bullish confluence.
Calculation: Bullishly aligned symbol count = number of the seven monitored symbols whose rolling close-price correlation with the chart symbol meets the configured threshold and whose own bullish confluence exceeds its bearish confluence. Calculate correlation on the chart timeframe; calculate symbol confluence on the configured monitoring timeframe and higher timeframe, using the current higher-timeframe bar, including while it is forming. Use the same confluence calculations and lookback relationships as for the chart.
Calculation: Bearishly aligned symbol count = number of the seven monitored symbols whose rolling close-price correlation with the chart symbol meets the configured threshold and whose own bearish confluence exceeds its bullish confluence.
Long: bullish confluence > bearish confluence OR (bullish confluence > bearish confluence AND bullishly aligned symbol count >= configured minimum AND VIX bearish confluence > VIX bullish confluence)
Short: bearish confluence > bullish confluence OR (bearish confluence > bullish confluence AND bearishly aligned symbol count >= configured minimum AND VIX bullish confluence > VIX bearish confluence)
