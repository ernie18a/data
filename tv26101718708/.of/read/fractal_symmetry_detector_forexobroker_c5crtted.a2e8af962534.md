Calculation: Pivot sequence = Confirm a pivot high or low using equal numbers of chart bars on each side. If both confirm on the same bar, use the low. Maintain alternating pivot types: append an opposite-type pivot; replace a same-type pivot only if it is more extreme; otherwise retain the sequence. A new pivot event occurs whenever either pivot confirms, even if the sequence is unchanged. A, B, and C are the last three retained pivots in chronological order.
Calculation: Valid pattern = At least three pivots exist AND abs(B price - A price) > 0 AND abs(abs(C price - B price) / abs(B price - A price) - an enabled Fibonacci retracement level) <= tolerance.
Calculation: Pending state = Initially neither direction is pending. On each bar, if a new pivot event produces a valid low-high-low pattern and the immediate long signal fails, set long pending and clear short pending; do the mirror operation for a high-low-high pattern and the immediate short signal. Record the current bar as the pending start. Clear both pending states when the age exceeds five bars. After evaluating signals, clear both pending states if either signal fires. A new valid pattern can reset the pending start even if the pivot sequence did not change.
Calculation: Immediate signal = On a closed bar, a new pivot event produces a valid pattern of the corresponding direction AND volume >= volume SMA multiplied by the volume confirmation multiplier AND bars since either direction's last signal >= cooldown AND (reversal-candle requirement is disabled OR the current candle confirms that direction). Initialize the last signal bar index to zero. A long-confirming candle has close > open AND close > (high + low) / 2; a short-confirming candle has close < open AND close < (high + low) / 2.
Calculation: Delayed signal = Before the pending states are cleared for a signal, the corresponding pending state is active AND the current candle confirms that direction AND volume >= volume SMA multiplied by the volume confirmation multiplier AND bars since either direction's last signal >= cooldown, evaluated on a closed bar. Update the last signal bar index whenever an immediate or delayed signal fires.
Long: (Valid pattern AND A is a low AND B is a high AND C is a low) OR long pending after signal processing OR delayed long signal
Short: (Valid pattern AND A is a high AND B is a low AND C is a high) OR short pending after signal processing OR delayed short signal
