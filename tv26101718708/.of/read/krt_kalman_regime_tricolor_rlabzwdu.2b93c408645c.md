Calculation: Kalman filter = On the specified timeframe, let x = log(close), r = x - previous x, and R = max(median of the most recent noise-window squared returns, noise floor) after the warm-up count; before then use the current squared return, or the initial noise value when unavailable. Initialize level to x, slope to 0, and covariance P to [[initial variance, 0], [0, initial variance]]. For each bar predict level L = level + slope and slope S = slope; set A00 = P00 + P10 + P01 + P11, A01 = P01 + P11, A10 = P10 + P11, A11 = P11 + q*R, K0 = A00/(A00+R), K1 = A10/(A00+R), and V = A11 - K1*A01. Update level = L + K0*(x-L), slope = S + K1*(x-L), and P = [[A00-K0*A00, A01-K0*A01], [A10-K1*A00, V]]. The slope statistic is slope/sqrt(max(V, variance floor)). When K1 exceeds the gain floor, the predicted price for a target slope statistic z is exp(L + (z*sqrt(max(V, variance floor))-S)/K1); otherwise it is unavailable.
Calculation: Trend state and flip levels = Run the faster Kalman filter on the higher trend timeframe. The lower and upper flip levels are its predicted prices for the negative and positive trend thresholds. Initialize trend state to +1; change +1 to -1 when the slope statistic is below the negative threshold, and -1 to +1 when it is above the positive threshold. The confirmed trend state is the state of the last completed trend bar, updated at the start of the next trend bar. The flip levels use the trend bar still forming.
Calculation: Slow level = Run the slower Kalman filter on the higher trend timeframe bar still forming; its predicted price for target slope statistic zero is the slow level.
Calculation: Installed regime = Run a Kalman filter on the higher regime timeframe, which is longer than the trend timeframe. Use the slope statistic of the last completed regime bar, updated at the start of the next regime bar. Initialize bullish and bearish regime switches off. Turn the bullish switch on when the statistic exceeds the positive entry threshold and off when it falls below the negative exit threshold; turn the bearish switch on when it falls below the negative entry threshold and off when it exceeds the positive exit threshold. A regime is installed when its switch remains on for at least the installation duration since it was turned on.
Calculation: Chart trend state = Initialize to +1. When both trend flip levels are available, change +1 to -1 if chart close is below the lower level, and change -1 to +1 if chart close is above the upper level. Record the chart bar time at each change; initialize this time to the first chart bar time.
Calculation: Curve availability = The curve is available when its selected flip level, optionally smoothed, is available and neither trend state changed on the current chart bar and the elapsed time since the previous chart bar is at most the gap threshold. Select the lower flip level when confirmed trend state is +1 and the upper level when it is -1. If smoothing is enabled, initialize or reset the smoothed curve to the selected level on a state change or gap; otherwise update it by exponential smoothing with a coefficient determined by the ratio of trend timeframe to chart timeframe and the smoothing parameter.
Calculation: Downward bias filter = The chart bar's GMT hour is within the configured start-inclusive, end-exclusive time window OR the elapsed time since the chart trend state last changed is at most the fresh-leg duration OR (chart close minus the selected flip level) divided by the higher trend timeframe's still-forming simple moving average of absolute close changes is below the negative fall threshold. If that average is unavailable or nonpositive, use zero for the ratio.
Long: Bullish regime is installed.
Short: Bearish regime is installed AND bullish regime is not installed.
Long: Chart trend state changes from -1 to +1.
Short: Chart trend state changes from +1 to -1.
Long: Confirmed trend state changes from -1 to +1.
Short: Confirmed trend state changes from +1 to -1.
Long: Bullish regime becomes installed AND confirmed trend state equals +1.
Short: Bearish regime becomes installed AND confirmed trend state equals -1.
Long: Curve is available AND chart trend state equals +1 AND (bullish regime is installed OR chart close is above the slow level).
Short: Curve is available AND chart trend state equals -1 AND (bearish regime is installed OR downward bias filter is true).
