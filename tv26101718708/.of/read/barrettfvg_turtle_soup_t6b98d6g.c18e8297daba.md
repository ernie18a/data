Calculation: Swing levels = On each enabled chart or higher timeframe, confirm pivot highs and lows using the same parameterized number of bars on each side. Keep separate capped lists of unbroken highs and lows, dropping the oldest when a list exceeds its cap. On each completed source bar, remove every high level with high > level and every low level with low < level; add newly confirmed pivots after processing breaks. Use the last completed higher-timeframe bar; chart and higher-timeframe pivot lengths are independent.
Calculation: Sweep = Among levels broken on one source bar, select the most recently formed level for which a high break also has close < level or a low break also has close > level; on equal origin times, prefer the high. Record its direction, level, source bar extreme, source timeframe and chart bar of detection. Retain at most a parameterized number of setups, dropping the oldest. When sweep markers are enabled, remove an unfired setup if a subsequent completed source-timeframe close is below its low-sweep level or above its high-sweep level; use the last completed higher-timeframe close. Expire setups after a parameterized number of chart bars. Extend each live low-sweep extreme with each chart bar's low and each high-sweep extreme with each chart bar's high.
Calculation: Gap zones = A bullish gap has bottom = high two chart bars earlier and top = current low; a bearish gap has bottom = current high and top = low two chart bars earlier. A gap is accepted when top > bottom AND its size > a parameterized multiple of chart-timeframe ATR AND, if overlap filtering is enabled, it does not intersect a retained zone of the same effective direction. Retain accepted zones up to a parameterized cap, removing the oldest inverted zone first, otherwise the oldest zone. A bullish gap inverts bearish when close < bottom; a bearish gap inverts bullish when close > top. Reject and remove an inversion that intersects another retained zone of its new direction when overlap filtering is enabled. Otherwise retain the inverted zone if inversion display is enabled; remove it if disabled. Remove an inverted bearish zone when close > top and an inverted bullish zone when close < bottom. Process existing zones newest first after adding and capping new gaps.
Calculation: Delivery state = Classify each chart bar as up when close > open, down when close < open, and neutral otherwise. Track consecutive non-neutral bars of the same direction; neutral bars leave the run unchanged. Once a run reaches a parameterized minimum length, remember its first open as the latest opening for that direction. Set state bullish when close > latest down-run opening + a parameterized multiple of chart-timeframe ATR; otherwise set state bearish when close < latest up-run opening - that clearance. A state-change event occurs when the state changes or the reclaimed opening differs from the previously recorded opening; bullish has priority if both qualify. The delivery ATR lookback is longer than the gap ATR lookback.
Calculation: Qualified gap setup = An accepted gap or accepted inversion matches a same-direction sweep detected more than zero and no more than the entry-window parameter chart bars earlier, with bullish zone bottom > swept level + parameterized price clearance or bearish zone top < swept level - clearance. Select the most recently detected eligible sweep, breaking equal detection-bar ties by registration order. A match is consumed only within an enabled session window. Session windows are evaluated from chart-bar datetime in the configured session timezone. Gaps and sweeps continue to be tracked outside sessions.
Calculation: Held setup = If a qualified gap setup occurs within a session while the optional delivery filter opposes it, consume the sweep and hold the signal; a newer held signal replaces the older one. Extend its sweep extreme on each following chart bar. Release it only on a later bar within the parameterized hold window and an enabled session, when the delivery filter allows its direction; discard it after the window. The filter allows a long when state is not bearish OR close > the last reclaimed opening, and allows a short when state is not bullish OR close < the last reclaimed opening. A disabled filter allows both directions.
Calculation: Trade levels = At each entry, use chart close as entry price and the sweep extreme extended through the entry bar as reference. Long initial stop = min(reference - parameterized price buffer, entry price - price increment); short initial stop = max(reference + buffer, entry price + price increment). Target = entry price plus, for long, or minus, for short, a parameterized multiple of absolute initial risk. If enabled, breakeven threshold = entry price + a parameterized fraction of (target - entry price). Starting on the next chart bar, first move the stop to entry if high reaches the long threshold or low reaches the short threshold, then evaluate stop and target; stop has priority if both are touched. Manage the previous trade before recording a new entry; a new entry replaces any still-tracked trade. If both entry directions occur on a bar, track long using the last assigned entry reference.
Long: Completed source bar low < an unbroken swing low AND close > that level AND the sweep is selected over other qualifying sweeps on that source bar.
Short: Completed source bar high > an unbroken swing high AND close < that level AND the sweep is selected over other qualifying sweeps on that source bar.
Long: Accepted bullish gap OR accepted bullish inversion.
Short: Accepted bearish gap OR accepted bearish inversion.
Long: Bullish delivery state-change event.
Short: Bearish delivery state-change event.
Long: Qualified bullish gap setup AND delivery filter allows long OR held long setup is released.
Short: Qualified bearish gap setup AND delivery filter allows short OR held short setup is released.
Exit: long, chart bar after entry AND low <= current stop OR chart bar after entry AND high >= target.
Exit: short, chart bar after entry AND high >= current stop OR chart bar after entry AND low <= target.
