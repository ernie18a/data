Calculation: Timeframe score = On each selected timeframe, calculate standard MACD and its signal using the same parameters across timeframes. Record the direction and bar index of the most recent MACD-line crossover above or below its signal. Freshness is exp(-decay rate × bars since that crossover in the selected timeframe). The score is crossover direction (+1 above, -1 below) × freshness; it is zero before any crossover or when freshness is below the freshness floor. For a lower timeframe, use the score from the bar preceding the last lower-timeframe bar within the chart bar; for a higher timeframe, use the last completed bar. Replace unavailable scores with zero.
Calculation: Composite score = EMA of the weighted mean of enabled timeframe scores, evaluated on chart bars. Each weight is its manual weight, optionally multiplied by (timeframe duration / chart timeframe duration) raised to an auto-weight exponent. Use zero when the sum of weights is zero. The higher-timeframe composite uses only the enabled higher-timeframe slots; the overall composite uses all enabled slots. Use the same smoothing length for both.
Long: Overall composite score > 0 OR higher-timeframe composite score > 0
Short: Overall composite score < 0 OR higher-timeframe composite score < 0
