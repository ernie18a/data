Calculation: Reference return = either (reference-bar close − previous reference-bar close) / previous reference-bar close or ln(reference-bar close / previous reference-bar close), using one selected method throughout. The reference timeframe may be higher than, equal to, or lower than the chart timeframe.
Calculation: Live return = the reference return formula using the current chart-bar close and the last completed reference-bar close.
Calculation: Return distribution = the most recent configured number of confirmed reference-bar returns, including the current reference bar only once it is confirmed; require at least two returns. Use linear interpolation for percentiles. The lower extreme percentile is configured independently of the lower warning percentile; each upper percentile is the complement of its corresponding lower percentile.
Long: Live return >= 0 OR (return distribution is available AND (live return >= upper extreme percentile OR live return >= upper warning percentile OR live return > median return))
Short: Live return < 0 OR (return distribution is available AND (live return <= lower extreme percentile OR (live return < upper extreme percentile AND live return < upper warning percentile AND live return <= median return)))
