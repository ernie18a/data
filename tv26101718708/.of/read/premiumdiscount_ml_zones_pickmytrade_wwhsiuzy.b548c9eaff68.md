Calculation: Dealing range = On the chart timeframe or a higher timeframe, use confirmed pivot highs and lows with configurable left and right bar counts; for a higher timeframe use the last completed bar. Update the range high to each new pivot high only if the range low is unavailable or the pivot high is above it; then update the range low to each new pivot low only if the updated range high is unavailable or the pivot low is below it. The range is valid when both exist and high > low. Let range size = high - low, midpoint = (high + low) / 2, lower boundary = midpoint - band fraction × range size, and upper boundary = midpoint + band fraction × range size.
Calculation: Model features = Position is clamp((close - range low) / max(range size, minimum price increment), 0, 1), or zero if the range is invalid. Dwell is the number of closes, including the current close, in a configurable lookback whose distance from the current close is at most range size / number of scan intervals, divided by the full lookback length; use zero if the range is invalid. Momentum is (close - close at the momentum lookback) / (close at the momentum lookback + minimum price increment). Standardize each feature using its rolling mean and population standard deviation over the same configurable window; use zero when its standard deviation is unavailable or not positive, and also for standardized position and dwell when the range is invalid.
Calculation: Bull probability = Initialize bias and three feature weights to zero. Starting at zero-based bar index equal to the standardization window plus the label horizon plus two, update once per bar using the previous bar's standardized features and label. The label is 1 if (previous close - close one label horizon before the previous close) / (close one label horizon before the previous close + minimum price increment) > 0, otherwise 0. With prediction = sigmoid(bias + sum of weight × previous feature) and error = label - prediction, update bias by adding learning rate × error, and each weight by adding learning rate × (error × previous feature - L2 coefficient × weight). Use the updated weights and current features to calculate bull probability = sigmoid(bias + sum of weight × current feature); bear probability = 1 - bull probability. Sigmoid(x) = 1 / (1 + exp(-x)). The minimum price increment is a configurable constant.
Calculation: Scanned probabilities = Divide each interval from range low to lower boundary and from upper boundary to range high into the same configurable number of equal scan intervals used by dwell, including both endpoints. At each level, calculate standardized position as ((level - range low) / range size - current rolling position mean) / current rolling position standard deviation, and calculate bull and bear probabilities using the current updated weights and current standardized dwell and momentum.

Short: Valid range AND training update count >= required training count AND close >= upper boundary AND close <= range high AND bear probability >= entry threshold AND the preceding bar did not satisfy all these conditions.
