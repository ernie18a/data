Calculation: Swing level = the most recently confirmed pivot high or pivot low, using equal numbers of bars on both sides; make it available only on its confirmation bar.
Calculation: Candle range = max(high - low, positive price epsilon); ATR denominator = max(ATR, positive price epsilon); upper wick ratio = (high - max(open, close)) / candle range; lower wick ratio = (min(open, close) - low) / candle range; relative range = candle range / ATR denominator; relative volume = volume / its simple moving average, or 1 if that average is unavailable or nonpositive; relative ATR = ATR / its simple moving average, or 1 if that average is unavailable or nonpositive.
Calculation: Bullish EMA regime = shorter EMA > longer EMA AND close >= shorter EMA; bearish EMA regime = shorter EMA < longer EMA AND close <= shorter EMA. A strong regime persists when its condition has held for at least the regime-hold lookback since the last bar on which it was false.
Calculation: Cloud = the undisplaced Ichimoku cloud: span A is the average of the short-lookback and medium-lookback high-low midpoints; span B is the long-lookback high-low midpoint. Bullish cloud = close > max(span A, span B) AND span A >= span B; bearish cloud = close < min(span A, span B) AND span A <= span B; otherwise the cloud is neutral.
Calculation: Bullish sweep = low < latest swing low - minimum penetration × ATR denominator AND close > latest swing low AND low <= the lowest low over the local-extreme lookback including the current bar AND (latest swing low - low) / ATR denominator <= maximum penetration AND, if wick-reclaim mode is selected, lower wick ratio >= minimum wick ratio AND common sweep filters pass AND, if the EMA filter is enabled, bullish EMA regime OR the bearish EMA regime is not strong AND, if the cloud filter is enabled, the cloud is bullish or neutral AND, if the hard regime block is enabled, neither an enabled strong bearish EMA regime nor an enabled bearish cloud exists AND the bullish level and cooldown filters pass.
Calculation: Bearish sweep = high > latest swing high + minimum penetration × ATR denominator AND close < latest swing high AND high >= the highest high over the local-extreme lookback including the current bar AND (high - latest swing high) / ATR denominator <= maximum penetration AND, if wick-reclaim mode is selected, upper wick ratio >= minimum wick ratio AND common sweep filters pass AND, if the EMA filter is enabled, bearish EMA regime OR the bullish EMA regime is not strong AND, if the cloud filter is enabled, the cloud is bearish or neutral AND, if the hard regime block is enabled, neither an enabled strong bullish EMA regime nor an enabled bullish cloud exists AND the bearish level and cooldown filters pass.
Calculation: Common sweep filters = optional close confirmation AND, if enabled, relative ATR >= minimum activity AND, if enabled, relative volume >= minimum activity AND, if enabled, ADX >= minimum ADX AND, if low-energy blocking is enabled, ADX > chop threshold OR abs(+DI - -DI) > DI-gap threshold AND, if spike blocking is enabled, relative range <= maximum range AND, if the post-spike lookback is positive, no relative range > maximum range has occurred within that lookback including the current bar AND, if near-trap suppression is enabled, the elapsed bars since the last valid or strong trap exceed the suppression lookback or no such trap exists.
Calculation: Side-specific level and cooldown filters = elapsed bars since the previous same-side sweep >= cooldown AND absolute difference between the current sweep extreme and the previous same-side sweep extreme > same-level distance × current ATR denominator, with each test passing when its previous value is unavailable AND, if mitigated-level blocking is enabled, the current swing level is not within same-level distance × current ATR denominator of the last same-side swept level already marked mitigated. Before evaluating each bar's sweep, mark the last bearish level mitigated when mitigation tracking is enabled AND close > that level in close mode OR high > that level + 0.20 × ATR denominator in wick mode; mark the last bullish level mitigated when mitigation tracking is enabled AND close < that level in close mode OR low < that level - 0.20 × ATR denominator in wick mode. Each same-side sweep replaces its stored extreme and level and resets that level's mitigation flag.
Calculation: Trap score = clamp to [0, 100] the sum of: 22 for reclaim; 15 for wick ratio >= its minimum; 12 if normalized penetration is between its minimum and 0.65 × its maximum inclusive, otherwise 6 if penetration <= its maximum; 14 if relative volume >= strong-volume threshold, otherwise 8 if >= valid-volume threshold; 10 if ADX >= strong-ADX threshold, otherwise 6 if >= minimum ADX; 10 if -DI > +DI for bearish or +DI > -DI for bullish, otherwise subtract the DMI penalty if enabled; 8 if the corresponding EMA regime or cloud is aligned, otherwise subtract the regime penalty; if dealing-range scoring is enabled, add 9 when bearish close is in premium or bullish close is in discount, otherwise subtract 5; add 5 if relative range <= maximum range, otherwise subtract 10. Premium and discount compare (close - lowest low) / max(highest high - lowest low, positive price epsilon), over the dealing-range lookback including the current bar, with their respective thresholds. Evaluate the score on the sweep bar regardless of whether the EMA or cloud filters are enabled.
Calculation: Pending trap = maintain at most one pending sweep; arm a bearish sweep first, otherwise a bullish sweep, only when no trap is pending. Save its side, bar, score and target: sweep close minus confirmation distance × sweep-bar ATR denominator for bearish, plus it for bullish. Without follow-through, trigger on the sweep bar. With follow-through, trigger when age >= minimum confirmation bars AND bearish close <= target or bullish close >= target; evaluate the trigger before expiring a pending trap whose age > maximum confirmation bars. At a trigger, require the elapsed bars since the last triggered trap of either side >= minimum trap gap; clear the pending trap whether or not the gap passes. A gap-passing trigger updates the last triggered trap bar; it also updates the last valid-or-strong trap bar if its saved score >= valid-score threshold.
Long: Bullish sweep AND, if same-bar sweep suppression is enabled, no bullish trap triggers on the same bar.
Short: Bearish sweep AND, if same-bar sweep suppression is enabled, no bearish trap triggers on the same bar.
Long: A pending bullish trap triggers AND the minimum trap gap passes.
Short: A pending bearish trap triggers AND the minimum trap gap passes.
