Calculation: Session gap = (current session open - previous session close) / previous session close; use the forming higher-timeframe session bar's open and the last completed session bar's close.
Calculation: Previous session return = (previous session close - previous session open) / previous session open; use the last completed higher-timeframe session bar.
Calculation: Blocked season = the configured month and segment of the month containing the session date, with segments covering days 1–7, 8–15, 16–22, and 23 through month-end.
Long: Mode = best gaps AND current bar = first bar of session AND session year is within the configured date range AND seasonal filter is disabled OR mode = best gaps AND current bar = first bar of session AND session year is within the configured date range AND session is outside blocked seasons; AND session gap >= minimum move AND session gap ranks among the highest configured number of valid enabled instruments.
Long: Mode = worst gaps AND current bar = first bar of session AND session year is within the configured date range AND (seasonal filter is disabled OR session is outside blocked seasons) AND session gap <= negative minimum move AND session gap ranks among the lowest configured number of valid enabled instruments.
Long: Mode = overnight AND current bar = last bar of session AND next session year is within the configured date range AND (seasonal filter is disabled OR next session is outside blocked seasons) AND current session return >= minimum move AND current session return ranks among the highest configured number of valid enabled instruments; current session return is the previous session return evaluated at the next session open.
Exit: long, mode = best gaps OR mode = worst gaps, AND current bar = last bar of entry session.
Exit: long, mode = overnight AND current bar = first bar of session following entry.
