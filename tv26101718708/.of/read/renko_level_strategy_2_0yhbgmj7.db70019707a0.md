Calculation: Renko level = first chart close, then the close on any bar where close > prior Renko level + prior ATR or close < prior Renko level − prior ATR; otherwise unchanged
Calculation: Upward-cross count = increments when close > prior Renko level + prior ATR; resets to zero when close < prior Renko level − prior ATR; otherwise unchanged
Long: close > prior Renko level + prior ATR AND prior upward-cross count = 1
Exit: long, close < prior Renko level − prior ATR
