Calculation: Session tracking = Use two configurable session windows and a configurable timezone. A window starts when the current chart bar is inside it and the previous bar was outside; it ends when the previous bar was inside and the current bar is outside. Maintain one shared state, initially idle. On either window's start, reset an active or forming state to idle; if idle, start tracking that window, choosing the first configured window if both start together. Ignore starts while confirmed or failed. Set session open to the start bar's open and initialize the window high and low to that open. While active and inside the tracked window, update them with each bar's high and low. At the tracked window's end, calculate upward excursion = window high - session open and downward excursion = session open - window low. The fake direction is up if upward excursion >= downward excursion, otherwise down. If the larger excursion >= the current bar's ATR multiplied by the fake-move threshold, enter forming and set the deadline to the current bar's opening datetime plus the reversal-window duration; otherwise return to idle. Evaluate reversal on the window-end bar and subsequent forming bars using each current bar's ATR. On the first reversal, enter confirmed; otherwise enter failed when the bar's opening datetime >= the deadline. Evaluate reversal before expiration, including on the first bar at or after the deadline. After these checks, reset confirmed or failed to idle when the bar's opening datetime >= the deadline plus a reset delay, or when the daily boundary changes.
