Calculation: MA pair = the same selectable moving-average type and parameters applied separately to open and close on the MA timeframe; the source supports SMA, EMA, DEMA, TEMA, WMA, VWMA, SMMA, Hull MA, linear regression MA, and ALMA. For SMMA, use (previous-bar WMA × (length − 1) + current source) / length, falling back to SMA when the previous WMA is unavailable. For a higher MA timeframe, use the last completed bar for entry and exit decisions and the still-forming bar for the displayed MA trend; for a lower MA timeframe, use its last completed bar within each chart bar.
Calculation: MA trend state = bullish when the close MA is greater than the open MA, bearish when it is less, and otherwise the previous state.
Calculation: ATR trend line = on chart bars, take the WMA of true range from a selectable lower timeframe, where true range uses that timeframe's high, low, and previous close; use the last completed lower-timeframe bar. Set the upper limit to the previous chart bar's rolling highest high minus the previous WMA multiplied by a parameter, and the lower limit to the previous chart bar's rolling lowest low plus that product. If the lower-timeframe close is above both limits, set the line to the upper limit; if it is below both limits, set the line to the lower limit; otherwise retain the previous line, initialized to zero.
Calculation: Correlation trend line = use the last completed close from a selectable lower timeframe. On each chart bar, set source to tuner × lower-timeframe close + (1 − tuner) × previous regression value, substituting the lower-timeframe close if the previous regression value is unavailable. Retain the previous source when no new lower-timeframe bar starts. Set efficiency ratio to 1 − absolute change in source over the lookback divided by the sum of absolute one-bar source changes over that lookback. Set threshold to cumulative absolute distance between source and the previous trend line, substituting source for an unavailable previous line, divided by the number of elapsed chart bars after the first and multiplied by (1 + efficiency ratio). Set the trend line to source if source is above the previous line plus threshold or below the previous line minus threshold; otherwise retain the previous line, substituting source if unavailable. Set slope to correlation(source, trend line) × standard deviation(source) / standard deviation(trend line), retaining the last valid slope if unavailable; set regression value to slope × trend line + SMA(source) − slope × SMA(trend line). Correlation, standard deviations, and SMAs use the same lookback. When no new lower-timeframe bar starts, retain the previous trend line and regression value.
Calculation: Combined trend line = ATR trend line × combination weight + correlation trend line × (1 − combination weight).
Long: A new MA-timeframe bar starts AND the previous chart bar's close MA is greater than or equal to its open MA AND the last such evaluated comparison was false, initialized to false.
Short: A new MA-timeframe bar starts AND the previous chart bar's close MA is less than its open MA AND the last such evaluated comparison was true.
Exit: long, a new MA-timeframe bar starts AND the previous chart bar's close MA is less than its open MA AND the last such evaluated comparison was true.
Exit: short, a new MA-timeframe bar starts AND the previous chart bar's close MA is greater than or equal to its open MA AND the last such evaluated comparison was false, initialized to false.
Long: MA trend state is bullish.
Short: MA trend state is bearish.
Long: The last completed lower-timeframe close used by the ATR trend line is greater than or equal to the combined trend line on the previous chart bar OR on the chart bar before that.
Short: The last completed lower-timeframe close used by the ATR trend line is less than the combined trend line on the previous chart bar OR on the chart bar before that.
