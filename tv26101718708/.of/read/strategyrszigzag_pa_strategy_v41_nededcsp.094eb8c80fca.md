Calculation: Zigzag pivots = On either chart bars or alternate-timeframe bars, optionally replace OHLC with Heikin-Ashi OHLC. A bar is up when close >= open and down when close <= open. Set direction to down when the preceding bar is up and the current bar is down; otherwise set it to up when the preceding bar is down and the current bar is up; otherwise retain the preceding direction. On the first transition to down, emit the highest high of the current and preceding bars; on the first transition to up, emit their lowest low. For a higher alternate timeframe, evaluate using the completed alternate bar corresponding to the current chart bar, with historical lookahead, and emit only on the first chart bar of that alternate bar. For a lower alternate timeframe, use its first completed bar within the chart bar and emit only when the alternate-timeframe timestamp changes. Retain the five most recent nonzero emitted pivots as X, A, B, C, D, from oldest to newest.
Calculation: Pattern ratios = (abs(B-A)/abs(X-A), abs(B-C)/abs(A-B), abs(C-D)/abs(B-C), abs(A-D)/abs(X-A)). A pattern has its own inclusive parameter bounds for these ratios. There are seventeen pattern parameter sets; the ABCD set bounds only the second and third ratios, the alternative bat set has only upper bounds on the first and fourth ratios, and the butterfly set has only an upper bound on the first ratio. All other sets have lower and upper bounds on all four ratios, except the bat set, which has only an upper bound on the fourth ratio. A missing bound imposes no restriction.
Calculation: Pivot level(rate) = D + (C-D) * rate, using the latest pivots on each bar.
Long: D < C AND all applicable ratio bounds of any one pattern set are satisfied AND the same pattern set with D < C was not satisfied on the preceding chart bar.
Short: D > C AND all applicable ratio bounds of any one pattern set are satisfied AND the same pattern set with D > C was not satisfied on the preceding chart bar.
Long: D < C AND all applicable ratio bounds of any one pattern set are satisfied AND close <= pivot level(entry rate for the target).
Short: D > C AND all applicable ratio bounds of any one pattern set are satisfied AND close >= pivot level(entry rate for the target).
Exit: long, high >= pivot level(profit-target rate for the position's target) OR low <= pivot level(stop-loss rate for the position's target).
Exit: short, low <= pivot level(profit-target rate for the position's target) OR high >= pivot level(stop-loss rate for the position's target).
