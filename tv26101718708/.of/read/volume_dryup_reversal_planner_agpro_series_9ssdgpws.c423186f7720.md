Calculation: Dry-up candidate = volume / SMA(volume) <= volume threshold AND (high - low) / SMA(high - low) <= range threshold. If the applicable average is unavailable or nonpositive, use 1 for that ratio.
Calculation: Pocket = on a completed bar where the dry-up candidate is true and was false on the preceding bar, record the highest high and lowest low over a pocket lookback including that bar, and the current ATR. Create or replace a pocket only when no reversal is active AND there is no pocket, the existing pocket has expired, or its age is at least the refresh age. Pocket age is the number of bars since creation; it expires when age exceeds the maximum age. Expiration clears the active reversal. An invalidation also clears the active reversal; the pocket remains available until replaced or expired.
Calculation: Reversal state = inactive initially; set it to long or short on the corresponding reversal entry and record that bar. Clear it on pocket expiration or invalidation. Evaluate pocket creation and expiration before reversal entries, then evaluate invalidation after reversal entries.
Calculation: Readiness score = round(clamp(20 + V + R + C + J + F, 0, 100)), where clamp(x, a, b) limits x to [a, b], relative volume is current volume / SMA(volume), range ratio is current bar range / SMA(bar range), and volatility ratio is current ATR / SMA(ATR), using the range lookback for the last average. V = clamp((volume threshold - min(relative volume, volume threshold)) / max(volume threshold, 0.01) * 26, 0, 26); R = clamp((range threshold - min(range ratio, range threshold)) / max(range threshold, 0.01) * 22, 0, 22); C = clamp((close - pocket high) / ATR * 24, 0, 20) for an active long reversal or clamp((pocket low - close) / ATR * 24, 0, 20) for an active short reversal; J = clamp((close - low) / bar range * 14, 0, 14) for an active long reversal or clamp((high - close) / bar range * 14, 0, 14) for an active short reversal; F = clamp(18 - abs(volatility ratio - 1) * 18, 0, 18). Use true range when ATR is unavailable, a positive price floor for zero bar range or ATR, and 1 for a ratio whose average is unavailable or nonpositive.
Calculation: Ready state = reversal state is active AND pocket age <= maximum age AND the active reversal is not invalidated AND readiness score >= readiness threshold. A ready event occurs when ready state is true and was false on the preceding bar.
Long: Pocket exists AND pocket age > 0 AND pocket age <= maximum age AND reversal state is inactive AND close > pocket high + pocket ATR * reversal-buffer multiplier AND close > open.
Short: Pocket exists AND pocket age > 0 AND pocket age <= maximum age AND reversal state is inactive AND close < pocket low - pocket ATR * reversal-buffer multiplier AND close < open.
Long: Ready event AND reversal state is long.
Short: Ready event AND reversal state is short.
Exit: long, reversal state is long AND close < pocket low - pocket ATR * failure-shelf multiplier.
Exit: short, reversal state is short AND close > pocket high + pocket ATR * failure-shelf multiplier.
