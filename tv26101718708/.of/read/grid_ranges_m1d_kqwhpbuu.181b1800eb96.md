Calculation: Reference range = the highest high and lowest low of chart bars whose opening times fall within a configured New York time window; freeze it on the first bar after that window ends and reset it at the start of each New York day.
Calculation: Bias state = reset the state to unset and both sweep flags to false at the start of each New York day. On each closed chart bar after the reference range is complete, using the open of the first chart bar of the New York day, perform these steps in order: set the upper sweep flag if the bar opens within a configured New York sweep window and its high exceeds both the reference range high and the day open; set the lower sweep flag if the bar opens within that window and its low is below both the reference range low and the day open; set the state to bearish if the upper sweep flag is set, the close is below the reference range high, and the state is not bearish; set the state to bullish if the lower sweep flag is set, the close is above the reference range low, and the state is not bullish; set the state to invalidated and clear the upper sweep flag if the state is bearish and the close is above the reference range high; set the state to invalidated and clear the lower sweep flag if the state is bullish and the close is below the reference range low. Sweep flags persist until cleared or reset.
Long: Bias state is bullish AND previous bar's bias state is not bullish.
Short: Bias state is bearish AND previous bar's bias state is not bearish.
Exit: long, bias state changes from bullish to invalidated.
Exit: short, bias state changes from bearish to invalidated.
