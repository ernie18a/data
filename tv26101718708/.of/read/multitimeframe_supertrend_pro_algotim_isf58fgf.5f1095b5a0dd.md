Calculation: Supertrend direction = Independently calculate ATR and raw bands midpoint(high, low) minus and plus factor × ATR. Initialize direction to bullish and previous bands to unavailable, treated as zero when updating bands. Set the current lower-price band to its raw value if it exceeds the previous lower-price band or the previous close is below that previous band; otherwise retain the previous band. Set the current upper-price band to its raw value if it is below the previous upper-price band or the previous close is above that previous band; otherwise retain the previous band. Change bearish direction to bullish if close exceeds the previous upper-price band; change bullish direction to bearish if close is below the previous lower-price band; otherwise retain direction. Use independently configurable ATR lengths and factors for the chart, confirmation, and reference calculations. A blank confirmation timeframe duplicates the chart calculation. For a specified different timeframe, use the last completed higher-timeframe bar or the last lower-timeframe bar within the chart bar. The reference timeframe is independently selectable and uses the same bar-selection rule.
Calculation: Bullish and bearish votes = Counts of the three Supertrend directions that are bullish and bearish, respectively, including the duplicated chart direction when confirmation is blank.
Calculation: Consensus direction = Bullish if bullish votes reach the configurable threshold; otherwise bearish if bearish votes reach the threshold; otherwise neutral. Initialize the previous consensus as neutral.

Short: Chart Supertrend direction is bearish OR confirmation Supertrend direction is bearish OR reference Supertrend direction is bearish OR bearish votes reach the threshold AND bullish votes are below the threshold OR consensus direction is bearish AND previous consensus direction is not bearish OR chart Supertrend direction is bearish AND previous chart Supertrend direction is bullish OR bearish votes equal the number of Supertrend calculations AND previous bearish votes are less than that number.
