Calculation: Gaussian midline = Apply a configurable number of cascaded recursive filters to the selected price source, defaulting to (high + low + close) / 3. For each stage, output = alpha * current input + (1 - alpha) * previous output, with previous output initially zero; each stage after the first takes the current output of the preceding stage as input. Let beta = (1 - cos(4 * pi / period)) / (1.414^(2 / number of stages) - 1), and alpha = -beta + sqrt(beta^2 + 2 * beta).
Calculation: VWAP deviation = sqrt(cumulative sum of volume * ((high + low + close) / 3 - session VWAP)^2 divided by cumulative sum of volume), accumulated from the beginning of the dataset without a session reset. Session VWAP uses (high + low + close) / 3 and resets each trading day.
Calculation: Opening range high and low = The highest high and lowest low within the opening-range window, reset when the chart's daily bar changes. The window uses New York time: its start is the regular-session open; when the configured window is less than half an hour, its end is a quarter hour after the open; otherwise its end is constructed in the opening hour with the configured duration as the minute field. A breakout is valid only during regular trading hours after this window, with an available range level.
Calculation: Long trigger = close crosses above the shortest-period close EMA OR close crosses above session VWAP OR opening-range breakout is valid AND close > opening range high AND previous close <= the current opening range high. A cross above means the current value is greater and the previous value was less than or equal to the corresponding previous reference value.
Calculation: Short trigger = close crosses below the shortest-period close EMA OR close crosses below session VWAP OR opening-range breakout is valid AND close < opening range low AND previous close >= the current opening range low. A cross below means the current value is less and the previous value was greater than or equal to the corresponding previous reference value.
Calculation: Long score = Count the true conditions among: shortest-period close EMA > intermediate-period close EMA AND intermediate-period close EMA > longest-period close EMA; close > session VWAP; close > Gaussian midline AND Gaussian midline > previous Gaussian midline; MACD histogram > 0 AND MACD histogram > previous MACD histogram; RSI > its neutral midpoint AND RSI < the configured upper threshold; volume >= a configured multiplier * SMA of volume; long trigger is true. MACD uses a shorter fast EMA than slow EMA.
Calculation: Short score = Count the true conditions among: shortest-period close EMA < intermediate-period close EMA AND intermediate-period close EMA < longest-period close EMA; close < session VWAP; close < Gaussian midline AND Gaussian midline <= previous Gaussian midline; MACD histogram < 0 AND MACD histogram < previous MACD histogram; RSI < its neutral midpoint AND RSI > the configured lower threshold; volume >= a configured multiplier * SMA of volume; short trigger is true. Use the same indicator parameters as the long score.
Calculation: Session passes = The bar is within the configurable New York prime-hours session when that filter is enabled AND outside the New York lunch interval when the lunch filter is enabled.
Calculation: Cooldown passes = Current bar index minus the index of the most recent long, short, or caution signal is at least the configured cooldown. Initialize the most recent signal index to a negative index before the dataset. Evaluate all signals using the prior index, then update it to the current index if any signal occurs.
Long: long score >= configured minimum AND long trigger is true AND session passes AND cooldown passes AND the bar is closed when bar confirmation is enabled.
Short: short score >= configured minimum AND short trigger is true AND session passes AND cooldown passes AND the bar is closed when bar confirmation is enabled.
Short: high >= session VWAP + configured outer-band multiplier * VWAP deviation AND RSI >= configured upper threshold AND close < open AND session passes AND cooldown passes AND the bar is closed when bar confirmation is enabled AND neither the long nor short confluence signal occurs on this bar.
Long: low <= session VWAP - configured outer-band multiplier * VWAP deviation AND RSI <= configured lower threshold AND close > open AND session passes AND cooldown passes AND the bar is closed when bar confirmation is enabled AND neither the long nor short confluence signal occurs on this bar.
