Calculation: Upper drift = mean of up to the most recent specified number of confirmed pivot highs; a pivot high is confirmed after the same specified number of bars on each side.
Calculation: Lower drift = mean of up to the most recent specified number of confirmed pivot lows, using the same confirmation and averaging parameters as upper drift.
Calculation: Trend = bullish initially; when both drift lines exist, set bullish if close crosses above upper drift, otherwise set bearish if close crosses below lower drift; retain the previous trend otherwise. A crossover requires the current close to be above the current line and the previous close to be at or below the previous line; a crossunder is the reverse.
Long: Trend = bullish
Short: Trend = bearish
Long: Previous trend = bearish AND trend = bullish
Short: Previous trend = bullish AND trend = bearish
