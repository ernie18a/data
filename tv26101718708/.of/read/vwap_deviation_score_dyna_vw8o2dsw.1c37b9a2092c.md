Calculation: Session deviation score = For each configured session, reset cumulative sums and the score. On each in-session bar, accumulate source × weight, source² × weight, and weight, where source is a configurable price derived from OHLC and weight is max(volume, 1), treating missing volume as zero. The session mean is cumulative source × weight divided by cumulative weight; the session variance is max(cumulative source² × weight divided by cumulative weight minus session mean², 0). Once the session bar count reaches the minimum and variance is positive, calculate raw score = (close − session mean) / sqrt(session variance). Smooth valid raw scores with an EMA initialized to the first valid raw score; retain its last value when no new raw score is available.
Calculation: Extension flag = Reset to false at each new session and after a return-to-zero event. Before evaluating a return-to-zero event, set it to true if the current bar is not the first bar of the session and the absolute value of the previous bar's session deviation score is at least the extreme threshold. A return-to-zero event occurs when the flag is true and the score crosses above or below zero.
Long: Session deviation score <= negative extreme threshold.
Short: Session deviation score >= positive extreme threshold.
Exit: long, extension flag is true AND session deviation score crosses above zero OR extension flag is true AND session deviation score crosses below zero.
Exit: short, extension flag is true AND session deviation score crosses above zero OR extension flag is true AND session deviation score crosses below zero.
