Calculation: Rolling trend and raw wave = Initialize trend to +1, raw wave to the first close, active slope to 0, and fast mode to false. On each bar with available ATR, calculate distance as close minus the previous raw wave. Set trend to +1 if the previous trend is -1 AND distance is greater than a reversal threshold times ATR; otherwise set trend to -1 if the previous trend is +1 AND negative distance is greater than the reversal threshold times ATR; otherwise retain the previous trend. Set new fast mode to whether the absolute distance is greater than a speed threshold times ATR. If trend reversed OR fast mode changed OR active slope is 0, set fast mode to the new fast mode and set active slope to ATR divided by the shorter slope length in fast mode or the longer slope length otherwise; otherwise retain the previous fast mode and active slope. Set raw wave to the previous raw wave plus trend times active slope. When ATR is unavailable, set raw wave to close and retain the other states.
Long: Rolling trend = +1
Short: Rolling trend = -1
