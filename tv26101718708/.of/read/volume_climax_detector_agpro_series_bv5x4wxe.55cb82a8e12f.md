Calculation: Volume statistics = volume SMA and population standard deviation over the same lookback, including the current bar; relative volume = volume / volume SMA if the SMA is positive, otherwise 0; volume Z-score = (volume - volume SMA) / volume standard deviation if the standard deviation is positive, otherwise 0.
Calculation: Bar quality = range = high - low; spread ratio = range / SMA(range) over the volume lookback if that SMA is positive, otherwise 0; close location = (close - low) / range if range is positive, otherwise 0.5; body fraction = abs(close - open) / range if range is positive, otherwise 0.
Calculation: Event direction = upward if close location >= close-location threshold; otherwise downward if close location <= 1 - close-location threshold; otherwise upward if close >= open, downward if close < open.
Calculation: Trend context = upward if close > EMA(close) AND EMA(close) - EMA(close) at a fixed earlier bar > trend-slope threshold × ATR; downward if close < EMA(close) AND EMA(close) - EMA(close) at that same earlier bar < -trend-slope threshold × ATR; otherwise neutral.
Calculation: Event score = round(clamp(24 × clamp(relative volume / (2 × relative-volume threshold), 0, 1) + 20 × clamp(spread ratio / (1.8 × spread threshold), 0, 1) + 20 × directional close quality + 12 × body fraction + trend points, 0, 90)), where directional close quality is close location for an upward event and 1 - close location for a downward event; trend points are 14 when trend context matches event direction, 4 when it opposes it, and 8 when neutral.
Calculation: Event eligibility = (volume Z-score >= Z-score threshold OR relative volume >= relative-volume threshold) AND spread ratio >= spread threshold AND (close location >= close-location threshold OR close location <= 1 - close-location threshold OR body fraction >= body-fraction threshold) AND event score >= minimum event score AND (no previous eligible event exists OR bars since the previous eligible event >= cooldown) AND (no previous eligible event exists OR bars since the previous eligible event > follow-through window). Evaluate and record eligible events at bar close.
Long: Event eligibility AND event direction = downward.
Short: Event eligibility AND event direction = upward.
