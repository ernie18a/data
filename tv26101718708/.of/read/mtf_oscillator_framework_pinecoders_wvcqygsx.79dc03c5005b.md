Calculation: Instant oscillator = sign(close - open) × true range.
Calculation: Chart oscillator = the instant oscillator averaged on the chart timeframe using a selectable SMA, EMA, WMA, VWMA, ALMA, linear regression, or HMA; use the current bar, or the previous completed bar when chart repainting is disabled in real time.
Calculation: Medium and highest oscillators = the instant oscillator calculated on two progressively higher timeframes, using either the last completed higher-timeframe bar or the still-forming bar according to the repainting setting; these values are not averaged.
Calculation: Main oscillator = selectable chart oscillator, medium oscillator, highest oscillator, or their weighted average; omit unavailable higher-timeframe values and their weights from the average.
Calculation: Divergence level = the main oscillator value on the latest chart bar where a down bar coincides with a rising main oscillator or an up bar coincides with a falling main oscillator. Determine bar direction using open and close rounded to tick precision; a doji is up or down when its close is respectively above or below the preceding close. Rising and falling compare the main oscillator with its preceding value.
Calculation: Bull state = at least one selectable condition is enabled and every enabled condition is true: main oscillator > centerline; main oscillator > highest main oscillator over the preceding lookback; main oscillator > divergence level; main oscillator > medium oscillator; main oscillator > highest oscillator; chart oscillator > medium oscillator; chart oscillator > highest oscillator; medium oscillator > centerline; highest oscillator > centerline. A selectable volatility filter additionally requires short-term ATR > long-term ATR for high volatility, short-term ATR <= long-term ATR for low volatility, or imposes no restriction.
Calculation: Bear state = at least one selectable condition is enabled and every enabled condition is true: main oscillator < centerline; main oscillator < lowest main oscillator over the preceding lookback; main oscillator < divergence level; main oscillator < medium oscillator; main oscillator < highest oscillator; chart oscillator < medium oscillator; chart oscillator < highest oscillator; medium oscillator < centerline; highest oscillator < centerline. Apply the same selectable volatility filter as for the bull state.
Long: Bull state is true.
Short: Bear state is true.
Long: Bull state is true AND the preceding bar's bull state is false.
Short: Bear state is true AND the preceding bar's bear state is false.

Short: Main oscillator < centerline OR main oscillator < lowest main oscillator over the preceding lookback OR main oscillator < divergence level OR main oscillator < medium oscillator OR main oscillator < highest oscillator OR chart oscillator < medium oscillator OR chart oscillator < highest oscillator OR medium oscillator < centerline OR highest oscillator < centerline; each comparison is independently selectable.
Long: Divergence level equals its preceding value AND main oscillator > divergence level.
Short: Divergence level equals its preceding value AND main oscillator < divergence level.
