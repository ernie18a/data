Calculation: Smoothed chart-timeframe RSI = EMA of RSI computed from chart-timeframe closes.
Calculation: Chart-timeframe RSI signal = EMA of smoothed chart-timeframe RSI.
Calculation: Weekly smoothed RSI = EMA of RSI computed from weekly closes; use the current weekly bar (higher timeframe, still forming in live data).
Calculation: Weekly RSI signal = EMA of weekly smoothed RSI; use the current weekly bar (higher timeframe, still forming in live data).
Calculation: Relative volume = current chart-timeframe volume divided by its longer-lookback average volume.
Calculation: Recent-high drawdown = percentage by which chart-timeframe close is below the highest chart-timeframe high in the lookback.
Calculation: Daily score = weighted points for smoothed RSI in the buy zone, above its signal, rising versus the prior bar, passing the chart-timeframe trend filter, and passing the relative-volume filter.
Calculation: Weekly score = weighted points for weekly smoothed RSI above its minimum, above its signal, rising versus the prior weekly bar, and passing the weekly trend filter; use weekly (higher timeframe, current bar still forming in live data).
Calculation: Composite score = rounded weighted average of daily and weekly scores, with the daily weight greater than the weekly weight.
Long: (composite score >= approval threshold AND composite score < high-conviction threshold AND smoothed chart-timeframe RSI <= avoid-above level AND this approved state was false on the prior bar) OR (composite score >= high-conviction threshold AND smoothed chart-timeframe RSI > chart-timeframe RSI signal AND weekly smoothed RSI > weekly RSI signal AND relative volume >= high-conviction minimum AND smoothed chart-timeframe RSI <= avoid-above level AND this high-conviction state was false on the prior bar) OR (recent-high drawdown >= extreme drawdown minimum AND weekly smoothed RSI <= extreme weekly RSI maximum AND smoothed chart-timeframe RSI <= extreme daily RSI maximum AND, if required, smoothed chart-timeframe RSI > its prior-bar value AND, if required, smoothed chart-timeframe RSI > chart-timeframe RSI signal AND this extreme-opportunity state was false on the prior bar).
