Calculation: Swing state = initially bearish; on each bar, set it bearish if the high N bars ago is greater than the highest high of the latest N bars, otherwise set it bullish if the low N bars ago is less than the lowest low of the latest N bars; otherwise retain the state. On a change to bearish, record the high N bars ago as the latest swing top and mark it uncrossed; on a change to bullish, record the low N bars ago as the latest swing bottom and mark it uncrossed.
Calculation: Order blocks = on the first close above an uncrossed swing top, mark that swing crossed and create a bullish block from the lowest-low candle between the swing and the current bar, excluding both; on the first close below an uncrossed swing bottom, mark that swing crossed and create a bearish block from the highest-high candle in the equivalent interval. Select extrema and block boundaries using either candle wicks or candle bodies consistently; resolve equal extrema in favor of the oldest candle. A bullish block becomes broken when min(open, close) is below its bottom and is removed on a subsequent bar when close is above its top. A bearish block becomes broken when max(open, close) is above its top and is removed on a subsequent bar when close is below its bottom. Retain only the most recent configured maximum number of blocks per side.
Calculation: Breaker confirmation = for bullish blocks, whether the latest swing top is strictly inside any broken bullish block among the configured number of most recent bullish blocks, excluding blocks broken or removed on the current bar; for bearish blocks, whether the latest swing bottom is strictly inside any equivalently selected broken bearish block. Compare each result with its value on the previous processed bar.
Calculation: Gap threshold = optionally a configurable fraction of the simple moving average of high minus low over a lookback including the current bar; before that average is available, use the average range of all available bars. If the filter is disabled, the threshold is zero.
Long: Close is above the latest uncrossed swing top.
Short: Close is below the latest uncrossed swing bottom.
Short: An unbroken bullish order block exists AND min(open, close) is below its bottom.
Long: An unbroken bearish order block exists AND max(open, close) is above its top.
Short: Bullish-block breaker confirmation changes from false to true.
Long: Bearish-block breaker confirmation changes from false to true.
Long: Close is above open on each of the current and previous two bars AND current low is above the high two bars ago AND previous close is above the high two bars ago AND current low minus the high two bars ago is at least the gap threshold.
Short: Close is below open on each of the current and previous two bars AND current high is below the low two bars ago AND previous close is below the low two bars ago AND the low two bars ago minus current high is at least the gap threshold.
