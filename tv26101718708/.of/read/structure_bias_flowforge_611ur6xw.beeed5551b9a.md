Calculation: Structure state = Independently for each of two configurable timeframes, one higher than the other, use the same symmetric pivot lookback to confirm swing highs and lows. Track the latest confirmed high and low, each initially unavailable and reset to unbroken whenever a new corresponding pivot is confirmed. Initialize trend, change-of-character direction, and break-of-structure direction to neutral. On each timeframe bar, if close is above the latest unbroken high, mark that high broken; set change-of-character direction to bullish if the prior trend was neutral or bearish, otherwise set break-of-structure direction to bullish; then set trend to bullish. Next, if close is below the latest unbroken low, mark that low broken; set change-of-character direction to bearish if the current trend is neutral or bullish, otherwise set break-of-structure direction to bearish; then set trend to bearish. Each event direction persists until another event of its own type changes it. Evaluate both timeframes independently. Each configured timeframe can be higher than, lower than, or equal to the chart timeframe. On historical chart bars, use the last completed requested bar when it is higher than the chart timeframe, the last completed intrabar when it is lower, and the current completed bar when equal; carry forward the latest available state. On a live chart bar, a higher-timeframe bar may still be forming.
Long: Either timeframe's change-of-character direction = bullish OR either timeframe's break-of-structure direction = bullish OR both timeframes' trends = bullish.
Short: Either timeframe's change-of-character direction = bearish OR either timeframe's break-of-structure direction = bearish OR both timeframes' trends = bearish.
