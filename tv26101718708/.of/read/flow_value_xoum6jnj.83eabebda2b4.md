Calculation: RSI target price = On the last completed higher-timeframe bar, let C be the previous higher-timeframe close, U and D the previous higher-timeframe Wilder moving averages of gains and losses, N the RSI length, and R = target RSI / (100 - target RSI). Let X = (R * D - U) * (N - 1) and Y = (U / R - D) * (N - 1). The target price is C + X if X > 0, otherwise C - Y if Y > 0, otherwise C. Use zero for missing previous values.
Calculation: Higher-timeframe gaps = Process completed higher-timeframe bars in order. When low > high two bars earlier, replace the bullish gap bounds with top = low and bottom = high two bars earlier. If a bullish gap exists, delete it when low < bottom; otherwise, if low < top, set top = low. When high < low two bars earlier, replace the bearish gap bounds with top = high and bottom = low two bars earlier. If a bearish gap exists, delete it when high > top; otherwise, if high > bottom, set bottom = high.
Long: Bullish gap exists AND oversold RSI target price <= bullish gap top AND oversold RSI target price >= bullish gap bottom
Short: Bearish gap exists AND overbought RSI target price <= bearish gap top AND overbought RSI target price >= bearish gap bottom
