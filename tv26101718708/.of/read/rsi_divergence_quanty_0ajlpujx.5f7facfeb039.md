Calculation: Confirmed RSI pivot = an RSI low or high whose value is respectively <= or >= every RSI value in the specified number of preceding bars and strictly < or > every RSI value in the specified number of following bars; confirm it on the close of the last following bar. Use independently adjustable preceding and following counts.
Calculation: Pivot price extreme = the lowest low for an RSI low pivot or highest high for an RSI high pivot, over the pivot bar and the same number of bars on each side as the pivot's following-bar count.
Calculation: Prior anchor = among the most recently retained confirmed RSI pivots of the same kind, select the pivot with the lowest RSI for a low pivot or highest RSI for a high pivot, subject to the inclusive minimum and maximum separation from the current pivot. Retain a limited number of pivots of each kind; if RSI values tie, select the most recent.
Long: A new RSI low pivot is confirmed AND a prior anchor exists AND the new pivot price extreme < the anchor price extreme AND the new pivot RSI >= the anchor RSI + minimum RSI difference AND (the RSI zone filter is disabled OR (the anchor RSI <= the lower zone threshold AND the new pivot RSI < the RSI midpoint)).
Short: A new RSI high pivot is confirmed AND a prior anchor exists AND the new pivot price extreme > the anchor price extreme AND the new pivot RSI <= the anchor RSI - minimum RSI difference AND (the RSI zone filter is disabled OR (the anchor RSI >= the upper zone threshold AND the new pivot RSI > the RSI midpoint)).
