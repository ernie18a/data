Calculation: Reversal distance = ATR multiplied by either a manual multiplier or an adaptive multiplier; the adaptive multiplier is a bounded linear function of 1 minus the EMA-smoothed Kaufman efficiency ratio of close.
Calculation: Zigzag pivots = initialize an upward leg with extreme = high. On an upward leg, update the extreme when high >= extreme; otherwise, if close < extreme - reversal distance, confirm the extreme as a high pivot, switch to a downward leg, and set extreme = low. On a downward leg, update the extreme when low <= extreme; otherwise, if close > extreme + reversal distance, confirm the extreme as a low pivot, switch to an upward leg, and set extreme = high. P1, P2, ... are confirmed pivot prices in reverse chronological order.
Calculation: Bear state = enter when the leg is downward, at least five pivots exist, P1 < P3 < P5, P2 < P4, and extreme < P2; set the break level to P1. While in this state, on a flip to a downward leg, lower the break level to P1 if P1 is lower. Leave the state when close > the break level.
Calculation: Wave state = classify each bar in the following priority order, then replace the result with bear state whenever bear state is active. For an upward leg: B if the state immediately before the latest leg flip was A, P2 > P1, and (extreme - P1) / (P2 - P1) is within the B classification range; otherwise 5 if at least five pivots exist, P3 > P5, P1 > P4, P2 > P4, P4 - P5 > 0, and P2 - P3 > 0; otherwise 3 if at least three pivots exist, P1 > P3, and P2 > P3. For a downward leg: A if at least six pivots exist, P4 > P6, P3 > P5, P2 > P5, P1 > P3, P5 - P6 > 0, P3 - P4 > 0, P1 - P2 > 0, and P3 - P4 is not smaller than both P5 - P6 and P1 - P2; otherwise 4 if at least four pivots exist, P2 > P4, P1 > P3, P1 - P2 > 0, and P3 - P4 > 0; otherwise C if at least three pivots exist, P3 > P1 > P2, and (P1 - P2) / (P3 - P2) is within the C classification range; otherwise 2 if at least two pivots exist and P1 > P2.
Calculation: Invalidation level = P2 for wave 2, P1 for waves 3 and 5, P3 for wave 4, and P1 for wave C. Waves 2, 3, 4, and 5 are invalid when close < their level; wave C is invalid when close > its level. Invalid waves are excluded from the entry and target-exit decisions on that bar.
Calculation: Entry zone = for wave 2, P1 minus two retracement fractions of P1 - P2; for wave 4, the lower bound is the greater of P3 and P1 minus a retracement fraction of P1 - P2, and the upper bound is P1 minus a smaller retracement fraction of P1 - P2. For wave C, let A = P3 - P2 and B = (P1 - P2) / A: if B >= the deep-retracement threshold, the zone is from P2 minus a fraction of A to P2; otherwise it is from P1 minus a larger multiple of A to P1 minus a smaller multiple of A.
Calculation: Wave 5 target lower bound = let L1 = P4 - P5 and L3 = P2 - P3. If L3 / L1 >= the extension threshold, use P1 plus a fraction of L1 as the lower bound and P1 plus a larger multiple of L1 as the upper bound; otherwise use the smaller and larger, respectively, of P1 + L1 and P1 plus a fraction of P2 - P5. If L3 < L1, cap the upper bound at P1 plus a fraction of L3 and cap the lower bound at that upper bound.
Calculation: Bullish reversal = (close > open AND previous close < previous open AND close >= previous open AND open <= previous close) OR (absolute body > 0 AND lower wick > a body multiple AND upper wick < a body multiple) OR (close > previous high AND previous close < previous open).
Calculation: Bearish reversal = (close < open AND previous close > previous open AND close <= previous open AND open >= previous close) OR (absolute body > 0 AND upper wick > a body multiple AND lower wick < a body multiple) OR (close < previous low AND previous close > previous open).
Long: Wave state is 2, 4, or C AND the wave is not invalid AND close >= entry-zone lower bound AND close <= entry-zone upper bound AND bullish reversal.
Exit: long, wave state is 5 AND the wave is not invalid AND close >= wave 5 target lower bound AND bearish reversal.
Exit: long, wave state before invalidation is 2, 3, 4, or 5 AND close < its invalidation level.
