Calculation: Daily ATR percentage reached = current daily high-low range / current daily ATR × 100; use the higher-than-chart daily bar still forming.
Calculation: Price fulfillment percentage = (chart close − current daily low) / current daily ATR × 100; use the higher-than-chart daily bar still forming.
Calculation: Average daily ATR percentage = longer-lookback average of daily (high-low) / daily ATR × 100; use higher-than-chart daily bars, including the bar still forming.
Calculation: Volume ratio = current daily volume / longer-lookback average daily volume; use the higher-than-chart daily bar still forming.
Long: Daily close > daily open AND (daily ATR percentage reached > 1.5 × average daily ATR percentage OR price fulfillment percentage > 80)
Short: Daily close < daily open AND (daily ATR percentage reached > 1.5 × average daily ATR percentage OR price fulfillment percentage < 20)
Exit: Long, daily ATR percentage reached > 150 OR price fulfillment percentage > 80
Exit: Short, daily ATR percentage reached > 150 OR price fulfillment percentage > 80
