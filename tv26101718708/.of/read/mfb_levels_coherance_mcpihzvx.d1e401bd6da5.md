Calculation: Session state = Start a new trading session at the first chart bar inside any enabled session window, using the configured session timezone; reset all opening ranges on that bar. A session is active from its start until the end of its configured signal window or until another enabled session starts, whichever occurs first.
Calculation: Opening-range high and low = Highest high and lowest low of chart bars whose opening times are within the short opening-range duration after the most recent trading-session start, including the current bar while the range is forming. Reset them at each trading-session start.
Calculation: External levels = High and low of the last completed bar of each of three successively higher timeframes, and the running high and low of each of two configured reference sessions in the session timezone. Reset each reference-session high and low at its start, update them through its current bar, and retain them until its next start.
Calculation: Nearest external level and distance = For each opening-range boundary, scan the available external levels in fixed order and select the first level with the smallest absolute distance, starting with a configured maximum distance; retain that maximum distance and an unavailable nearest level if none is closer.
Calculation: Bullish FVG event = When current low > high two chart bars ago AND previous close > previous open, replace the active bullish gap top with current low and clear its retracement flag. Then set the flag when current low <= the active gap top. An event occurs when the flag is set AND current close > the active gap top; clear the active gap top immediately after the event, whether or not an entry occurs.
Calculation: Bearish FVG event = When current high < low two chart bars ago AND previous close < previous open, replace the active bearish gap bottom with current high and clear its retracement flag. Then set the flag when current high >= the active gap bottom. An event occurs when the flag is set AND current close < the active gap bottom; clear the active gap bottom immediately after the event, whether or not an entry occurs.
Calculation: Low sweep state = Set the state when the opening-range low's distance to its nearest external level <= the confluence threshold AND current low < the minimum of the opening-range low and its nearest external level. Retain the state across bars and session starts; clear it after a long sweep entry.
Calculation: High sweep state = Set the state when the opening-range high's distance to its nearest external level <= the confluence threshold AND current high > the maximum of the opening-range high and its nearest external level. Retain the state across bars and session starts; clear it after a short sweep entry.
Long: Session active AND low sweep state set AND close > opening-range low AND bullish FVG event.
Long: Session active AND opening-range high's distance to its nearest external level > confluence threshold AND close > opening-range high AND bullish FVG event.
Short: Session active AND high sweep state set AND close < opening-range high AND bearish FVG event.
Short: Session active AND opening-range low's distance to its nearest external level > confluence threshold AND close < opening-range low AND bearish FVG event.
