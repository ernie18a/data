Calculation: Supersmoother(x, length) = c1*x + c2*previous output + c3*output two bars ago, where a = exp(-sqrt(2)*pi/length), c2 = 2*a*cos(sqrt(2)*pi/length), c3 = -a^2, and c1 = 1-c2-c3; substitute the corresponding previous x when a previous output is unavailable.
Calculation: Core = Supersmoother((high+low+close)/3, long lookback).
Calculation: Wall and wall direction = initially direction is long and wall is zero; on each bar calculate upper and lower bands as Supersmoother(close, shorter lookback) plus and minus a multiplier times ATR. In a long direction, set wall to the greater of the lower band and previous wall; in a short direction, set it to the lesser of the upper band and previous wall. After a specified number of consecutive closes below the wall in a long direction, switch to short and reset wall to the upper band; after the same number of consecutive closes above the wall in a short direction, switch to long and reset wall to the lower band. Reset the consecutive count on a failed comparison or direction change.
Calculation: Guide direction = initially long; let range be ATR times a multiplier, initialize guide to the current (high+low+close)/3 and held range to current range. If current (high+low+close)/3 exceeds previous guide plus previous held range, increase guide by current range and set held range to current range; if it is below previous guide minus previous held range, decrease guide by current range and set held range to current range; otherwise retain both. Set direction long when guide increases, short when it decreases, and otherwise retain its previous direction.
Calculation: Flow = SMA of MFI calculated from (high+low)/2 and volume minus its neutral midpoint; its smoothing lookback is shorter than its MFI lookback.
Calculation: Flow averages = maintain separate lists of positive and negative flow values. On each completed bar, prepend a nonzero flow value to its sign's list, cap that list at a specified length, and remove the oldest value from the opposite list if that list has more than one value. Each average is the mean of its list and is unavailable when its list is empty.
Calculation: Strong positive flow = flow > max(positive flow average, positive threshold); strong negative flow = flow < min(negative flow average, negative threshold).
Calculation: Stretch distance = Supersmoother(true range, a shorter lookback than Core) times pi times a multiplier times an adaptive factor. The adaptive factor is a linear function of the EMA-smoothed ratio of the standard deviation of (high+low+close)/3 over a shorter lookback than Core to its longer-lookback EMA, clamped between specified lower and upper bounds; use a ratio of one if the denominator is zero.
Calculation: Upper stretch touch = high >= Core + stretch distance; lower stretch touch = low <= Core - stretch distance.
Calculation: Setup touch = upper stretch touch OR lower stretch touch OR (previous wall direction = long AND low <= previous wall + multiplier * previous wall ATR) OR (previous wall direction = short AND high >= previous wall - multiplier * previous wall ATR).
Calculation: MACD = MACD of either (high+low+close)/3 or Core, with fast lookback shorter than slow lookback; histogram = MACD line minus its signal line.
Calculation: Range threshold of a series = a positive multiplier times its highest value minus its lowest value over a longer lookback; the threshold is unavailable when that range is zero.
Calculation: Long flow bias = flow minus flow a shorter lookback ago > flow range threshold OR (flow > 0 AND flow > previous flow). Short flow bias = flow minus flow a shorter lookback ago < negative flow range threshold OR (flow < 0 AND flow < previous flow).
Calculation: Core slope = Core minus Core a shorter lookback ago. Long slope bias = Core slope > Core slope range threshold. Short slope bias = Core slope < negative Core slope range threshold.
Calculation: Histogram magnitude change = absolute histogram minus absolute histogram a shorter lookback ago. Long histogram bias = (histogram > 0 AND histogram magnitude change > histogram range threshold) OR (histogram < 0 AND histogram magnitude change < negative histogram range threshold). Short histogram bias = (histogram < 0 AND histogram magnitude change > histogram range threshold) OR (histogram > 0 AND histogram magnitude change < negative histogram range threshold).
Calculation: Long context score = previous bar's SMA over a context lookback of the weighted sum of long flow, slope, and histogram biases; short context score is calculated identically from short biases. Each true bias contributes its own positive weight and each false bias contributes zero; use zero when the SMA is unavailable.
Calculation: Long watch score = long context score plus a positive stretch weight when lower stretch touch is true. Short watch score = short context score plus the same stretch weight when upper stretch touch is true.
Calculation: Long watch allowed = upper stretch touch is false AND strong negative flow occurred zero times in the preceding context lookback bars. Short watch allowed = lower stretch touch is false AND strong positive flow occurred zero times in the preceding context lookback bars.
Long: wall direction = long.
Short: wall direction = short.
Long: MACD line > 0 AND MACD histogram > 0.
Short: MACD line < 0 AND MACD histogram < 0.
Long: wall direction = long AND guide direction = long.
Short: wall direction = short AND guide direction = short.
Long: flow > 0 AND flow >= positive flow average.
Short: flow < 0 AND flow <= negative flow average.
Long: setup touch = true AND long watch allowed = true AND (short watch allowed = false OR long watch score > short watch score).
Short: setup touch = true AND short watch allowed = true AND (long watch allowed = false OR short watch score > long watch score).
