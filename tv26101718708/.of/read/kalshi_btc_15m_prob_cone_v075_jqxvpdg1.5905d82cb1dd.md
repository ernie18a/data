Calculation: Interval target = the chart-timeframe close SMA from the bar immediately before the current epoch-aligned settlement interval began, held fixed throughout that interval.
Calculation: Historical samples = chart-timeframe close SMA, volume, and time remaining in the settlement interval, stored at the first chart bar in each epoch-aligned sampling bucket after the SMA warmup; retain only the most recent configured maximum number of samples.
Calculation: Sample weight = exp(-recency decay × sample index distance from the newest stored sample) × exp(-(sample volume - current volume)² / (2 × volume scale²)), where volume scale is the configured volume-similarity fraction × current volume; use a volume factor of 1 when that scale is zero. If phase weighting is enabled, multiply by exp(-(sample remaining time - current remaining time)² / (2 × phase scale²)).
Calculation: Historical windows = the most recent configured maximum number of sampled SMA windows whose length in samples is the current remaining interval time, rounded to the configured time increment and divided by the sampling interval, rounded to the nearest integer. Require history length greater than window length plus the configured history buffer; retain windows with nonzero starting SMA and positive starting-sample weight. Each window return is ending SMA / starting SMA - 1.
Calculation: Effective sample size = (sum of historical-window weights)² / sum of squared historical-window weights, or zero if the denominator is zero. Recalculate the historical windows and effective sample size on confirmed bars entering a new scan-update bucket and retain the last result between updates.
Calculation: Probability above = sum of weights of historical windows whose return is greater than interval target / current SMA - 1, divided by the sum of all historical-window weights; probability below is the corresponding fraction for returns less than or equal to that threshold.
Calculation: Terminal cone median = at each configured cone horizon up to the rounded remaining interval time, project current SMA × (1 + historical-window return), using windows of that horizon and the separate cone window limit. Sort projections ascending and calculate their weighted median by linearly interpolating from the preceding projection and cumulative weight to the first projection whose cumulative weight reaches half the total; use the first projection as its own predecessor. The terminal cone median is the last available horizon median. Refresh on confirmed bars entering a new cone-update bucket and retain the last result between updates.
Long: On a confirmed scan-update bar, interval target is available AND current SMA > interval target.
Short: On a confirmed scan-update bar, interval target is available AND current SMA <= interval target.
Long: On a confirmed scan-update bar, effective sample size >= minimum sample size AND probability above > one half.
Short: On a confirmed scan-update bar, effective sample size >= minimum sample size AND probability above <= one half.
Short: On a confirmed scan-update bar, effective sample size >= minimum sample size AND probability below > one half.
Long: On a confirmed scan-update bar, effective sample size >= minimum sample size AND probability below <= one half.
Long: On a confirmed cone-update bar, interval target is available AND current SMA != 0 AND rounded remaining interval time >= cone horizon step AND effective sample size >= minimum sample size AND terminal cone median > interval target.
Short: On a confirmed cone-update bar, interval target is available AND current SMA != 0 AND rounded remaining interval time >= cone horizon step AND effective sample size >= minimum sample size AND terminal cone median < interval target.
