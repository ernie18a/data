Calculation: Chart SMA = simple average of chart-bar closes over a lookback.
Calculation: Interval target = Chart SMA from the bar immediately before the current interval began; hold fixed until the next interval.
Calculation: Weighted historical above-target probability = sum of weights for historical windows whose end SMA, scaled by current SMA / window-start SMA, is above the interval target, divided by total window weight. Use windows matching the current remaining interval duration; weight by recency and volume similarity, and by settlement-phase similarity when enabled.
Calculation: Terminal projected median = weighted median of historical end SMAs, scaled by current SMA / each window-start SMA, using windows matching the remaining duration and the same weights as the historical probability; interpolate between sorted projected values at the 50% cumulative-weight point.
Long: Effective sample size >= configured minimum AND weighted historical above-target probability > 50% OR effective sample size >= configured minimum AND remaining interval duration >= cone step AND terminal projected median > interval target
Short: Effective sample size >= configured minimum AND weighted historical above-target probability < 50% OR effective sample size >= configured minimum AND remaining interval duration >= cone step AND terminal projected median < interval target
