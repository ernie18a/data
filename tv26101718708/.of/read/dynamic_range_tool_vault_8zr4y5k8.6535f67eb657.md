Calculation: Momentum = 100 × (open − open a fixed number of chart bars ago) / open a fixed number of chart bars ago.
Calculation: Bullish block = on a momentum cross above a positive threshold, if the number of chart bars since the preceding momentum cross of either threshold exceeds a spacing parameter, create a block bounded by the high and low of the most recent bearish candle within a specified historical lookback interval; use the current candle if none exists. Remove the block when the selected mitigation price is below its low. The mitigation price is either the previous chart bar's close or the current chart bar's low.
Calculation: Bearish block = on a momentum cross below the negative of the same threshold, if the number of chart bars since the preceding momentum cross of either threshold exceeds the same spacing parameter, create a block bounded by the high and low of the most recent bullish candle within the same historical lookback interval; use the current candle if none exists. Remove the block when the selected mitigation price is above its high. The mitigation price is either the previous chart bar's close or the current chart bar's high.
Long: Momentum crosses above the positive threshold AND bars since the preceding momentum cross of either threshold exceed the spacing parameter.
Long: Current low < high of an active bullish block AND bullish mitigation price >= that block's low.
Short: Momentum crosses below the negative threshold AND bars since the preceding momentum cross of either threshold exceed the spacing parameter.
Short: Current high > low of an active bearish block AND bearish mitigation price <= that block's high.
