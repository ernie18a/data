Calculation: Base high and base low = highest high and lowest low over the base lookback, excluding the current bar.
Calculation: Base width = 100 × (base high − base low) / base low; undefined when base low ≤ 0.
Calculation: Average range = SMA over the base lookback of 100 × (high − low) / close; the current bar is included and a bar's range is undefined when its close ≤ 0.
Calculation: Volume ratio = SMA of volume over the base lookback / SMA of volume over the longer baseline lookback; undefined when baseline volume ≤ 0.
Calculation: Prior advance = 100 × (base high − prior low) / prior low, where prior low is the lowest low over the prior-advance lookback ending immediately before the base; undefined when prior low ≤ 0.
Calculation: Close location = 100 × (close − base low) / (base high − base low), or 0 when base high ≤ base low.
Calculation: Stop = minimum of close minus a configurable minimum price increment and the selected reference: lowest low over a recent lookback including the current bar; base low; close minus a configurable ATR multiple; or close reduced by a configurable percentage.
Calculation: Risk = 100 × (close − stop) / close; undefined when close ≤ 0.
Calculation: Range contraction = SMA of the per-bar percentage range over a shorter recent lookback / average range; undefined when average range ≤ 0.
Calculation: Score = 20 × clamp((maximum base width − base width) / maximum base width, 0, 1) + 15 × clamp((1 − volume ratio) / 0.6, 0, 1) + 15 × clamp(prior advance / (2 × minimum prior advance), 0, 1) + 15 × clamp(close location / 100, 0, 1) + 10 × clamp((1.2 − range contraction) / 0.7, 0, 1) + 10 if close is above both the shorter and longer close SMAs, otherwise 0, + 15 × clamp((maximum risk − risk) / maximum risk, 0, 1). Replace undefined range contraction with 1.2; clamp(x, 0, 1) limits x to the interval from 0 to 1.
Long: Bar index ≥ max(prior-advance lookback + base lookback + 2, max(volume baseline lookback, ATR lookback) + 2) AND close ≥ minimum price AND baseline volume ≥ minimum average volume AND base width ≤ maximum base width AND average range ≤ maximum average range AND volume ratio ≤ maximum volume ratio AND prior advance ≥ minimum prior advance AND close location ≥ minimum close location AND (trend filter disabled OR (close > shorter close SMA AND close > longer close SMA)) AND current percentage close-to-previous-close gain < maximum gain AND close ≤ base high AND risk ≤ maximum risk AND score ≥ minimum score.
