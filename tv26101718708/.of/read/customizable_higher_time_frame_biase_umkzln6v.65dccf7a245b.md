Calculation: CISD bias and level = Initialize after more than 10 bars with the current candle direction, or the most recent non-doji direction among the prior 50 bars if the current candle is a doji. Seed the level with the current open if the current candle is a doji or opposes the bias; otherwise use the minimum open in the current same-direction candle run for bullish bias, or maximum open for bearish bias, skipping dojis. While bullish, a new high updates the level to the minimum open in the backward same-direction run if the current candle is bullish; otherwise search backward, skipping candles until a bullish candle is found, then use the minimum open in its backward same-direction run. While bearish, a new low updates the level analogously, using bearish candles and the maximum open. On a bias reversal, reset the level using the seed rule for the new bias.
Long: CISD bias is bearish AND close > CISD level
Short: CISD bias is bullish AND close < CISD level
