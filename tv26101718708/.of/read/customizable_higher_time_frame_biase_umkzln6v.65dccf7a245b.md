Calculation: RunOpenCur(dir) = start with the current bar's open; walk back over previous bars, skipping doji bars (close = open) and stopping at the first bar of the opposite direction (bullish bar: close > open, bearish bar: close < open); among the current open and the opens of all same-direction (dir) bars passed, take the lowest if dir is bullish, the highest if dir is bearish.
Calculation: RunOpenPrev(dir) = ignore the current bar; going back, skip doji bars and opposite-direction bars until the most recent bar of direction dir is found; continue back over consecutive dir bars (skipping dojis, stopping at the first opposite-direction bar); take the lowest open of these bars if dir is bullish, the highest if bearish.
Calculation: State = bullish or bearish, with Level and Extreme, updated once per bar on the chart timeframe in this order. Init: on the first bar after a short warmup whose candle is not a doji (use the latest non-doji bar if the current one is a doji), State = that candle's direction, Level = RunOpenCur(State), Extreme = high if bullish, low if bearish. Step 1 (level update, before the decision check): if State is bullish and high > Extreme, then Extreme = high and Level = RunOpenCur(bullish) if the current bar is bullish, else RunOpenPrev(bullish); if State is bearish and low < Extreme, then Extreme = low and Level = RunOpenCur(bearish) if the current bar is bearish, else RunOpenPrev(bearish). Step 2: evaluate Long/Short below. On a Long, State becomes bullish, Level = RunOpenCur(bullish), Extreme = high. On a Short, State becomes bearish, Level = RunOpenCur(bearish), Extreme = low.
Long: State is bearish AND close > Level
Short: State is bullish AND close < Level
