Calculation: For each GUSS side, maintain an independent inactive or active state. A long setup starts when inactive and high exceeds the highest high of the preceding setup lookback, high minus the shorter EMA is at least the overextension multiplier × ATR, and the optional impulsive-candle requirement is disabled OR the bar is green. A short setup starts when inactive and low is below the lowest low of the preceding setup lookback, the shorter EMA minus low is at least the overextension multiplier × ATR, and the optional impulsive-candle requirement is disabled OR the bar is red. Starting records the current bar. On subsequent bars, process the active state before checking for a new setup: for long, deactivate first if green, otherwise if low<=shorter EMA, otherwise after an entry, otherwise if age>maximum wait; for short, deactivate first if red, otherwise if high>=shorter EMA, otherwise after an entry, otherwise if age>maximum wait. An inactive state can start again on the same bar. The entry test precedes the maximum-wait test.
