Calculation: Main adaptive HMA = Hull moving average of close; its length starts midway between its minimum and maximum, then each bar shrinks by an adaptation fraction toward the minimum when the plug condition is true, or grows by that fraction toward the maximum otherwise.
Calculation: Minor adaptive HMA = Same adaptive Hull moving average as the main one, using a shorter length range.
Calculation: Plug condition = Either ATR over a shorter lookback > ATR over a longer lookback, or HMA(RSI(volume, shorter lookback), shorter lookback) > a threshold, according to the selected adaptation mode.
Calculation: Adaptive HMA slope = A signed angle based on (HMA from two bars ago − current HMA) / close, scaled by the recent high-low range; the sign is inverted, so rising HMA gives a positive slope.
Long: (close > Main adaptive HMA AND Main adaptive HMA slope >= flat threshold AND plug condition AND RSI(close, lookback) > 50) OR (Main adaptive HMA slope >= flat threshold AND plug condition AND NOT (previous bar's Main adaptive HMA slope >= flat threshold AND plug condition)
Short: (close < Main adaptive HMA AND Main adaptive HMA slope <= −flat threshold AND plug condition AND RSI(close, lookback) < 50) OR (Main adaptive HMA slope <= −flat threshold AND plug condition AND NOT (previous bar's Main adaptive HMA slope <= −flat threshold AND plug condition)
Exit: Long, Main adaptive HMA slope >= flat threshold AND NOT plug condition AND close < Minor adaptive HMA AND NOT (previous bar's Main adaptive HMA slope >= flat threshold AND NOT plug condition AND close < Minor adaptive HMA)
Exit: Short, Main adaptive HMA slope <= −flat threshold AND NOT plug condition AND close > Minor adaptive HMA AND NOT (previous bar's Main adaptive HMA slope <= −flat threshold AND NOT plug condition AND close > Minor adaptive HMA)
