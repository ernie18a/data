Calculation: Bullish order block = On a higher timeframe, the prior completed bar is bearish, the latest completed bar closes above the prior bar’s high, and the latest bar’s range is at least the prior bar’s range multiplied by the impulse ratio
Calculation: Bearish order block = On a higher timeframe, the prior completed bar is bullish, the latest completed bar closes below the prior bar’s low, and the latest bar’s range is at least the prior bar’s range multiplied by the impulse ratio
Calculation: Bullish breaker block = A previously identified, unbroken bearish order block’s later completed higher-timeframe bar closes above the block’s high
Calculation: Bearish breaker block = A previously identified, unbroken bullish order block’s later completed higher-timeframe bar closes below the block’s low
Long: Bullish order block OR bullish breaker block
Short: Bearish order block OR bearish breaker block
