Calculation: Structure = Maintain two independent chart-timeframe structures, one with a shorter pivot lookback and one with a longer pivot lookback. For each, confirm a pivot high or low only after the same number of bars on each side; for equal highs or lows, use the rightmost extreme. Store the latest confirmed high and low separately, resetting the corresponding taken flag whenever a new pivot is confirmed. Initialize trend as neutral. A close-confirmed upward break occurs when close is above the current stored high and the previous close was at or below the previous bar's stored high; a close-confirmed downward break is the inverse using the stored low. A wick-confirmed upward break occurs when high is above the current stored high and the previous high was at or below that same current high; a wick-confirmed downward break is the inverse using lows. Select either close or wick confirmation. After evaluating decisions on each bar, an upward break of an untaken high sets trend bullish and marks that high taken; a downward break of an untaken low sets trend bearish and marks that low taken. Process upward before downward breaks if both occur.
Calculation: Other-timeframe structure = Apply the same structure calculation independently to aggregated bars of a higher or lower timeframe, using either the shorter or longer pivot lookback. For a higher timeframe use the last completed bar; for a lower timeframe use the last completed constituent bar within the chart bar.
Long: Either chart-timeframe structure has an upward break of an untaken high AND its trend before the break is bearish.
Short: Either chart-timeframe structure has a downward break of an untaken low AND its trend before the break is bullish.
Long: Other-timeframe structure trend is bullish.
Short: Other-timeframe structure trend is bearish.
