Calculation: risk = average of r1, r2, r3 (a component that cannot be computed counts as 0). r1 = ((close - SMA(close, long lookback)) / stdev(close, same long lookback)) / time_scale1, using base-timeframe bars (same as chart, last completed bar). r2 = (ln(close / SMA(close, medium lookback)) + time_offset2) / time_scale2, where the SMA uses higher-timeframe bars (last completed bar). r3 = (SMA(close, short lookback; base timeframe) / SMA(close, medium lookback; higher timeframe)) / time_scale3, using last completed bars; the r3 short lookback is shorter than the r2 lookback, and the r3 base-timeframe SMA is shorter than the r1 lookback. time_scale1..3 and time_offset2 are deterministic functions of the bar's calendar time that normalize each component for market maturity.
Long: risk <= buy threshold (evaluated every bar, no position filter; repeated entries allowed; any Long bar resets all sell stages to not-triggered)
Exit: long, risk >= sell threshold 1 AND sell stage 1 not yet triggered since the last Long (partial close of the long position; mark stage 1 triggered)
Exit: long, risk >= sell threshold 2 AND sell stage 1 triggered AND sell stage 2 not yet triggered since the last Long (partial close; mark stage 2 triggered; sell threshold 2 > sell threshold 1)
Exit: long, risk >= sell threshold 3 AND sell stage 2 triggered AND sell stage 3 not yet triggered since the last Long (partial close; mark stage 3 triggered; sell threshold 3 > sell threshold 2)
