Calculation: Bandwidth ratio = Bollinger Band width as a percentage of its basis, divided by its moving average; use 1 when that average is not positive.
Calculation: Volume ratio = volume divided by its moving average; use 1 when that average is not positive.
Calculation: Structural slope = the current endpoint minus the oldest endpoint of a linear regression of close over the structure lookback, divided by close and expressed as a percentage; use 0 when close is not positive.
Calculation: Range position = (close minus the lowest low) divided by (the highest high minus the lowest low) over the structure lookback; use the midpoint when the range is zero.
Calculation: Historical regime = breakout if bandwidth ratio, volume ratio, and absolute rate of change each exceed their respective breakout thresholds; otherwise reversal if RSI is above its upper threshold or below its lower threshold AND the sign of rate of change differs from its sign at a specified earlier bar, substituting the current rate of change if the earlier value is unavailable; otherwise trending up if ADX exceeds its trend threshold AND positive DI exceeds negative DI AND structural slope > 0; otherwise trending down if ADX exceeds its trend threshold AND negative DI exceeds positive DI AND structural slope < 0; otherwise range.
Calculation: Feature vector = ADX, positive DI minus negative DI, bandwidth ratio, RSI, log of volume ratio, structural slope, range position, and rate of change, each centered and scaled by its respective fixed normalization parameters; clamp all components except range position to [-1, 1], and map range position from [0, 1] to [-1, 1].
Calculation: Predicted regime = on each completed chart bar, stage its feature vector and historical regime after the structure lookback plus the bandwidth-average lookback has elapsed, provided ADX and bandwidth ratio are defined. Commit staged observations after a forward validation delay, keeping only the most recent observations up to the memory limit. Once memory reaches the minimum sample count, replace undefined current feature components with 0 and select up to the configured number of nearest stored vectors using the selected Euclidean, Manhattan, or cosine distance; break equal-distance ties in favor of the older observation. Sum votes by historical regime, using either equal weights or inverse distance with a positive stabilizing constant. Select the greatest vote total; break ties in the order trending up, trending down, range, breakout, reversal.
Long: Memory count >= minimum sample count AND predicted regime = trending up.
Short: Memory count >= minimum sample count AND predicted regime = trending down.
