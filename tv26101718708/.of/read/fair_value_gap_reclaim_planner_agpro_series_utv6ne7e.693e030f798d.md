Calculation: Active gap = On each completed bar, accept a bullish gap when low > high two bars earlier, gap size >= ATR times the minimum gap-size multiplier, and volume meets the minimum; accept a bearish gap when high < low two bars earlier, gap size >= ATR times the minimum gap-size multiplier, and volume meets the minimum. Bullish bounds are [high two bars earlier, current low]; bearish bounds are [current high, low two bars earlier]. Accept a new gap if replacement is enabled or no gap is active. Store its direction, bounds, ATR, and formation index equal to the current bar index minus one; reset its reclaim state. Expire the gap when current index minus formation index exceeds the maximum gap age. After evaluating the current bar, remove it if a bullish gap closes below its lower bound minus stored ATR times the invalidation multiplier, or a bearish gap closes above its upper bound plus stored ATR times the invalidation multiplier.
Calculation: Gap interaction = Current high >= active gap lower bound AND current low <= active gap upper bound. Recent interaction means an interaction occurred within the touch lookback, including the current bar; interaction history is not reset when a gap is replaced.
Calculation: Reclaim reference = Active gap midpoint, or its upper bound for a bullish gap and lower bound for a bearish gap, according to the selected reference mode.
Calculation: Reclaim score = Clamp the sum of these terms to [0,100]: 18 times clamp((100 - abs(fill percentage - 50))/100, 0, 1); 22 times clamp(directional close distance divided by current ATR and by 0.65, 0, 1); 17 times clamp(directional wick fraction / 0.55, 0, 1); 12 times clamp(body fraction / 0.62, 0, 1); 14 times clamp(gap size / stored ATR / 0.65, 0, 1); 7 times clamp(1 - gap age / maximum gap age, 0, 1); and, if relative-volume scoring is enabled, 10 times clamp(relative volume / 1.6, 0, 1), otherwise 7. Bullish fill percentage is 100 times clamp((gap upper bound - low) / gap size, 0, 1); bearish fill percentage is 100 times clamp((high - gap lower bound) / gap size, 0, 1). Directional close distance is close minus reference for bullish gaps and reference minus close for bearish gaps. Directional wick fraction is (min(open, close) - low) / (high - low) for bullish gaps and (high - max(open, close)) / (high - low) for bearish gaps; body fraction is abs(close - open) / (high - low). Relative volume is volume divided by its SMA, or 1 when the average is not positive. Use a small positive denominator floor for zero ranges or ATR. Gap age is current index minus formation index.
Calculation: Active reclaim = A qualified reclaim starts an active reclaim on its bar. It ends when the gap is replaced, expires or is invalidated, or when bars since the qualified reclaim exceed the reclaim window. A qualified reclaim requires no active reclaim, a recent gap interaction, and reclaim score >= the selected minimum score adjusted by the selected confirmation mode. Fast, balanced and strict modes respectively subtract, leave unchanged, or add their confirmation adjustment to the minimum, clamped to the score range.
Long: A bullish gap is accepted.
Short: A bearish gap is accepted.
Long: An active bullish gap exists AND recent interaction is true AND close > reclaim reference AND previous close <= current reclaim reference AND reclaim score >= adjusted minimum score AND no reclaim is active.
Short: An active bearish gap exists AND recent interaction is true AND close < reclaim reference AND previous close >= current reclaim reference AND reclaim score >= adjusted minimum score AND no reclaim is active.
Long: An active bullish gap exists AND its invalidation condition is false AND (the current bar interacts with the gap OR an active reclaim is within its reclaim window).
Short: An active bearish gap exists AND its invalidation condition is false AND (the current bar interacts with the gap OR an active reclaim is within its reclaim window).
Exit: long, an active bullish gap exists AND close < its lower bound minus stored ATR times the invalidation multiplier.
Exit: short, an active bearish gap exists AND close > its upper bound plus stored ATR times the invalidation multiplier.
