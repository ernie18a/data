Calculation: Directional-change events = For each enabled agent, initialize its mode to up and its high and low extremes to the first close. On each chart bar, using the extremes from before that bar: in up mode, if low <= high extreme × (1 − threshold), emit a down directional change, switch to down mode, and set the low extreme to low; otherwise, if high > high extreme, emit an up overshoot and set the high extreme to high. In down mode, if high >= low extreme × (1 + threshold), emit an up directional change, switch to up mode, and set the high extreme to high; otherwise, if low < low extreme, emit a down overshoot and set the low extreme to low. Agents have independent thresholds and state.
Calculation: Chop = The short-term close EMA is not above the long-term close EMA with ADX >= the trend threshold AND the short-term close EMA is not below the long-term close EMA with ADX >= the trend threshold AND the SMA of body ratio < the chop threshold; body ratio is abs(close − open) / (high − low), or zero when high = low.
Long: An enabled agent emits an up directional change OR an up overshoot.
Short: An enabled agent emits a down directional change OR a down overshoot.
Long: The selected agent is enabled AND the session filter is disabled or the bar is in the configured session AND the volume filter is disabled or volume > volume SMA × volume multiplier AND Chop is false AND ((filter mode is trend AND short-term close EMA > long-term close EMA AND ADX >= trend threshold AND (selected agent emits an up directional change OR an up overshoot)) OR (filter mode is range AND ADX <= range threshold AND selected agent emits an up directional change) OR (filter mode is off AND (selected agent emits an up directional change OR an up overshoot))).
Short: The selected agent is enabled AND the session filter is disabled or the bar is in the configured session AND the volume filter is disabled or volume > volume SMA × volume multiplier AND Chop is false AND ((filter mode is trend AND short-term close EMA < long-term close EMA AND ADX >= trend threshold AND (selected agent emits a down directional change OR a down overshoot)) OR (filter mode is range AND ADX <= range threshold AND selected agent emits a down directional change) OR (filter mode is off AND (selected agent emits a down directional change OR a down overshoot))).
