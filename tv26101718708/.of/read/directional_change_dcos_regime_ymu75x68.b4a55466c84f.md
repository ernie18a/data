Calculation: Directional Change/Overshoot event = Initialize mode as up and both tracked extremes at the first close. While mode is up, a bar with low <= tracked high × (1 − threshold) produces a down DC and switches mode to down; otherwise, high > tracked high produces an up OS and updates the tracked high. While mode is down, a bar with high >= tracked low × (1 + threshold) produces an up DC and switches mode to up; otherwise, low < tracked low produces a down OS and updates the tracked low. On each DC, set the new mode’s corresponding extreme to the event bar’s low (down DC) or high (up DC). A DC takes priority over an OS on the same bar.
Calculation: Trend up = fast EMA > slow EMA AND ADX >= trend-strength threshold
Calculation: Trend down = fast EMA < slow EMA AND ADX >= trend-strength threshold
Calculation: Range = ADX <= range-strength threshold
Calculation: Chop = NOT Trend up AND NOT Trend down AND 20-bar simple moving average of (abs(close − open) / max(high − low, minimum tick)) < chop threshold
Calculation: Volume spike = volume > volume moving average × volume multiplier
Long: selected agent is enabled AND session gate passes (if enabled) AND volume spike passes (if required) AND bar-close confirmation passes (if required) AND NOT Chop AND ((filter mode is Trend only AND Trend up AND (up OS OR up DC)) OR (filter mode is Range only AND Range AND up DC) OR (filter mode is Off/map only AND (up OS OR up DC)))
