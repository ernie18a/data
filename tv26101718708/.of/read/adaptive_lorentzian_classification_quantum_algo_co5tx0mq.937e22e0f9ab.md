Calculation: Source = a configurable price series derived from the input OHLC fields; use the same source throughout the classifier and kernel calculations.
Calculation: Feature vector = a configurable number of independently selected and weighted features. RSI feature is EMA(RSI(source, lookback), smoothing length)/100; CCI feature is expanding-minimum/maximum normalization of EMA(CCI(source, lookback), smoothing length); ADX feature is ADX/100 with equal directional-movement and ADX smoothing lengths; MFI feature is MFI(typical price)/100. Replace unavailable RSI, ADX and MFI feature values with 0.5. For expanding normalization, return (value - lowest value seen)/(highest value seen - lowest value seen), or 0.5 when the range is unavailable or zero.
Calculation: WaveTrend feature = expanding normalization of fast line minus slow line, where basis = EMA(typical price, first length), deviation = EMA(abs(typical price - basis), first length), fast line = EMA((typical price - basis)/max(0.015 × deviation, 1e-10), second length), and slow line = SMA(fast line, smoothing length).
Calculation: Fisher feature = atan(fisher)/pi + 0.5, where midpoint = (high + low)/2, raw = 0.66 × ((midpoint - lowest midpoint)/(max(highest midpoint - lowest midpoint, 1e-10)) - 0.5) + 0.67 × prior raw, raw is clamped to [-0.999, 0.999], and fisher = 0.5 × log((1 + raw)/(1 - raw)) + 0.5 × prior fisher. Highest and lowest use the feature lookback; initialize prior raw and fisher to zero.
Calculation: Classifier = on each bar append a training sample with the feature vector from the prediction-horizon bars ago, substituting each current feature if its historical value is unavailable. Label it +1 if source minus source at that horizon exceeds the neutral-zone multiplier times ATR at that horizon, -1 if the change is below the negative threshold, and otherwise 0; substitute zero for an unavailable threshold. Process only bars whose index is at least max(0, final dataset bar index minus training-window length); before that, prediction and confidence are zero. On each processed bar scan the latest training-window samples oldest to newest at a configurable index spacing, beginning with the first sample in that window. Distance is the sum across enabled features of feature weight times a selectable component: log(1 + absolute difference), absolute difference, squared difference, or the mean of the first two; take the square root of the sum for squared-difference distance. Keep persistent FIFO distance and label arrays across bars. Reset the acceptance threshold to -1 before each scan; accept a sample when its distance is at least the threshold, set the threshold to that distance, and append its distance and label. Whenever the pool exceeds K, set the threshold to the distance at zero-based index min(pool size - 1, round(3 × K/4)) before removing the oldest pair. After scanning, remove oldest pairs until at most K remain. K is either a fixed neighbor count or max(3, round(base count × (1 - 0.4 × percentile rank of short-lookback ATR over its rank lookback/100))); use 0.5 for an unavailable normalized rank. Each retained label has weight 1/(1 + its stored distance), or weight 1 when distance weighting is disabled. Prediction is the weighted label sum divided by total weight and multiplied by K when distance weighting is enabled and total weight is positive; otherwise it is the weighted label sum. Confidence is 100 × abs(weighted label sum)/total weight, or zero when total weight is zero.
Calculation: Direction state = +1 when prediction > 0 AND confidence >= its threshold AND every enabled common filter passes; -1 when prediction < 0 AND confidence >= its threshold AND every enabled common filter passes; otherwise retain the prior direction state, initially 0. The optional common filters are short-lookback ATR > long-lookback ATR, abs(short-lookback EMA(close) - long-lookback EMA(close))/max(ATR, 1e-10) > trend threshold, and ADX > its threshold.
Calculation: Rational-quadratic kernel = weighted mean of source from the current bar through min(regression level + 2 × kernel lookback + 10, current bar index) bars ago, with weight at lag i equal to (1 + i²/(2 × relative weight × kernel lookback²))^(-relative weight).
Calculation: Gaussian kernel = weighted mean of source over the same construction, using its own shorter lookback equal to max(rational-quadratic lookback - configurable lag, minimum lookback), and weight at lag i equal to exp(-i²/(2 × Gaussian lookback²)).
Calculation: Long entry = direction state changes to +1 AND each enabled directional filter passes: close > EMA(close), close > SMA(close), close > higher-timeframe EMA(close), and bullish kernel. Short entry = direction state changes to -1 AND each enabled directional filter passes: close < EMA(close), close < SMA(close), close < higher-timeframe EMA(close), and bearish kernel. The higher-timeframe EMA uses the last completed higher-timeframe bar on historical bars and the still-forming higher-timeframe bar on a realtime bar. Bullish kernel means rational-quadratic kernel > its prior value, or, with smoothing enabled, Gaussian kernel >= rational-quadratic kernel; bearish kernel means rational-quadratic kernel < its prior value, or, with smoothing enabled, Gaussian kernel <= rational-quadratic kernel.
Calculation: Bars held = bars since the most recent direction-state change, with zero on the change bar. A prior long signal at the prediction horizon means direction state was +1 and the enabled EMA and SMA directional filters passed at that bar; a prior short signal is the symmetric condition. These prior-signal checks do not include the higher-timeframe or kernel filters.
Calculation: Bearish kernel change = rational-quadratic kernel < its prior value AND its prior value > its value two bars ago. Bullish kernel change = rational-quadratic kernel > its prior value AND its prior value < its value two bars ago. A bearish kernel alert is bearish kernel change, or, with smoothing enabled, Gaussian kernel crossing below rational-quadratic kernel. A bullish kernel alert is bullish kernel change, or, with smoothing enabled, Gaussian kernel crossing above rational-quadratic kernel.
Calculation: Trailing stop = on a long entry set close - ATR × stop multiplier; on a short entry set close + ATR × stop multiplier. On subsequent bars without a new entry, update a long stop to max(previous stop, close - ATR × stop multiplier), or a short stop to min(previous stop, close + ATR × stop multiplier). Test the previous stop before updating it; clear the stop on exit. A new entry takes precedence over updating or clearing the stop.
Long: prediction > 0
Short: prediction < 0

Short: direction state = -1
Long: long entry = true
Short: short entry = true

Exit: short, dynamic exits enabled AND EMA filter disabled AND SMA filter disabled AND kernel smoothing disabled AND bullish kernel change = true AND, on the prior bar, bars since the latest bullish kernel alert > bars since the latest short entry
Exit: long, (dynamic exits disabled OR EMA filter enabled OR SMA filter enabled OR kernel smoothing enabled) AND long entry occurred at the prediction horizon AND prior long signal at the prediction horizon = true AND (bars held = prediction horizon OR bars held > 0 AND bars held < prediction horizon AND direction state changes to -1 AND all enabled short EMA, SMA and higher-timeframe filters pass)
Exit: short, (dynamic exits disabled OR EMA filter enabled OR SMA filter enabled OR kernel smoothing enabled) AND short entry occurred at the prediction horizon AND prior short signal at the prediction horizon = true AND (bars held = prediction horizon OR bars held > 0 AND bars held < prediction horizon AND direction state changes to +1 AND all enabled long EMA, SMA and higher-timeframe filters pass)
Exit: long, trailing stop enabled AND close < previous trailing stop
Exit: short, trailing stop enabled AND close > previous trailing stop
