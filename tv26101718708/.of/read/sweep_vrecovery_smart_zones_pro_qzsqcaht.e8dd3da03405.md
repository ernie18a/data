Calculation: Indexing and parameters = All bars are chart bars; [k] means k bars ago. Thresholds, lookbacks, windows, and enable switches are parameters. A zone is an interval [bottom, top]; a bar touches it when low <= top AND high >= bottom. Two zones overlap within tolerance when max(bottoms) <= min(tops) + tolerance.
Calculation: Fair value gaps = On low > high[2], replace the latest bullish gap with [high[2], low] and record its creation bar. On high < low[2], replace the latest bearish gap with [high, low[2]] and record its creation bar. Gap detection can be disabled.
Calculation: Order blocks = On close > high[1] AND close > open AND close[1] < open[1], replace the latest bullish block with [low[1], open[1]]. On close < low[1] AND close < open AND close[1] > open[1], replace the latest bearish block with [open[1], high[1]]. Optionally also require abs(close - open) > SMA(abs(close - open)) on the displacement bar. Block detection can be disabled.
Calculation: Breakers = On close > the latest bearish block top, replace the latest bullish breaker with that block. On close < the latest bullish block bottom, replace the latest bearish breaker with that block. Evaluate after updating blocks on the current bar; breaker detection can be disabled.
Calculation: Inverted gaps = On close > the latest bearish gap top, replace the latest bullish inverted gap with that gap and record the current bar and source gap creation bar. On close < the latest bullish gap bottom, do the symmetric operation for the bearish inverted gap. Evaluate after updating gaps on the current bar; inversion detection can be disabled. Optionally, maintain a bounded, age-limited collection of displayed gap instances: when broken-zone removal and gap conversion are enabled and inverted-gap boxes are enabled, low < a stored bullish gap bottom converts it to the latest bearish inverted gap, and high > a stored bearish gap top converts it to the latest bullish inverted gap; record the current bar with no source bar. Process broken stored gaps newest to oldest after ordinary inversions, removing each broken gap. Stored gaps are created only when gap boxes are enabled, are capped by a count parameter, and expire by a time-age parameter or are cleared at a new day when cross-day retention is disabled. Removing or expiring boxes does not clear the latest zone values.
Calculation: Inverted gap eligibility = A touched inverted gap passes when its width >= an optional minimum price distance AND its inversion bar minus source gap creation bar <= an optional maximum bar count. If the source bar is absent, the age test fails when enabled. Each test can be disabled independently.
Calculation: Recovery state = For each direction, a new sweep replaces the previous sweep and resets that direction's active recovery and signal count. A bullish sweep occurs when low < the minimum low over the preceding sweep lookback bars; a bearish sweep occurs when high > the maximum high over those bars. Require bar index > sweep lookback. Record the sweep bar's high and low. A recovery becomes active within the recovery window after the latest sweep when either enabled recovery test passes: (1) on a later bar, bullish close > sweep midpoint or bearish close < sweep midpoint; (2) bullish open[1] > close[1] AND close > open AND low < low[1] AND close > open[1], or bearish close[1] > open[1] AND close < open AND high > high[1] AND close < open[1]. The second test may pass on the sweep bar. Optionally require abs(close - open) >= ATR multiplied by a recovery threshold for either test. An active recovery remains valid through sweep age <= recovery window + retest window; otherwise it expires. A sweep without an active recovery expires after the recovery window.
Long: Bullish recovery is active AND sweep age <= recovery window + retest window AND (current bar touches an enabled bullish order block OR current bar touches an enabled bullish breaker OR current bar touches an enabled bullish inverted gap AND that inverted gap is eligible) AND (retest confirmation disabled OR close > open) AND (overlap filter disabled OR neither the latest bullish and bearish gaps nor the latest bullish and bearish inverted gaps overlap within the filter tolerance) AND (multiple signals per sweep enabled OR no earlier long signal since the latest bullish sweep).
Short: Bearish recovery is active AND sweep age <= recovery window + retest window AND (current bar touches an enabled bearish order block OR current bar touches an enabled bearish breaker OR current bar touches an enabled bearish inverted gap AND that inverted gap is eligible) AND (retest confirmation disabled OR close < open) AND (overlap filter disabled OR neither the latest bullish and bearish gaps nor the latest bullish and bearish inverted gaps overlap within the filter tolerance) AND (multiple signals per sweep enabled OR no earlier short signal since the latest bearish sweep).
