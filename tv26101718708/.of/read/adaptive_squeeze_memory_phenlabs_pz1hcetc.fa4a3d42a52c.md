Calculation: Squeeze event = on a completed chart bar, normalized Bollinger Band width is less than normalized Keltner Channel width and was not less on the preceding bar, and the zero-based bar index is greater than the largest indicator lookback plus the forward-return horizon. Bollinger width is twice the Bollinger multiplier times the population standard deviation of close divided by the absolute SMA of close. Keltner width is twice the Keltner multiplier times ATR divided by the absolute EMA of (high + low + close) / 3. Undefined widths do not satisfy the squeeze condition.
Calculation: Memory sample = at each squeeze event with defined features, compare its feature vector (ATR / absolute close, RSI / 100, volume / SMA of volume) with those of the most recent retained prior squeeze events whose forward-return horizon has completed. Require nonzero close and positive volume SMA. Rank by Euclidean distance after multiplying each feature difference by its respective weight; break equal-distance ties by older event first. Select up to the configured match count. Each selected return is 100 × (close at the end of the forward-return horizon / squeeze-event close − 1). Add the current event to memory only after matching.
Calculation: Memory state = when a squeeze event has defined features and at least the minimum number of matches, update median return to the nearest-rank 50th percentile of matched returns and bullish probability to the percentage of matched returns strictly above zero. Nearest rank sorts returns ascending and selects rank ceiling(0.5 × sample size), using one-based ranks. Otherwise retain the previous values and directional state; initially the directional state is undefined.
Long: Memory state is defined AND median return > positive edge threshold AND bullish probability >= directional probability threshold.
Short: Memory state is defined AND median return < negative edge threshold AND bullish probability <= 100% − directional probability threshold.
Long: Memory state is defined AND NOT (median return > positive edge threshold AND bullish probability >= directional probability threshold) AND NOT (median return < negative edge threshold AND bullish probability <= 100% − directional probability threshold) AND (median return > 0 OR bullish probability >= directional probability threshold).
Short: Memory state is defined AND NOT (median return > positive edge threshold AND bullish probability >= directional probability threshold) AND NOT (median return < negative edge threshold AND bullish probability <= 100% − directional probability threshold) AND NOT (median return > 0 OR bullish probability >= directional probability threshold) AND (median return < 0 OR bullish probability <= 100% − directional probability threshold).
Long: Squeeze event AND features are defined AND matched sample size >= minimum number of matches AND median return >= 0.
Short: Squeeze event AND features are defined AND matched sample size >= minimum number of matches AND median return < 0.
