Calculation: Calendar day = day number within the calendar year, using daily bars.
Calculation: Historical window return = (daily close on the window end day / daily close on the window start day − 1) × 100, calculated for each available historical year with both closes.
Calculation: Window hit rate = percentage of sampled years whose window return is positive for a bullish window or negative for a bearish window.
Calculation: Directional average = mean window return for a bullish window; negative mean window return for a bearish window.
Calculation: Window score = clamp((hit rate × directional average × sample adjustment / square root of window length) × score scale, 0, 1000); sample adjustment is 1 when disabled, otherwise 1 + (square root(sample count / effective minimum samples) − 1) × confidence weight.
Calculation: Best bullish/bearish window = highest-scoring eligible window on that side, after minimum-sample, hit-rate, score, and positive directional-average filters; reject windows whose overlap with a higher-ranked retained window reaches the overlap threshold, and retain at most the configured number per side. Candidate windows use calendar-day start/end dates and bounded lengths.
Long: Trend SMA is below close AND (EMA filter disabled OR EMA is below close) AND (best bullish window starts within the soon-days lookahead OR starts today OR started within the recent-days lookback OR is active AND its hit rate ≥ alert hit-rate threshold OR starts within the soon-days lookahead AND its hit rate ≥ alert hit-rate threshold OR starts within the soon-days lookahead AND its score ≥ either score threshold OR is active AND its average return ≥ alert average-move threshold)
Short: Trend SMA is above close AND (EMA filter disabled OR EMA is above close) AND (best bearish window starts within the soon-days lookahead OR starts today OR started within the recent-days lookback OR started within the recent-days lookback AND its hit rate ≥ alert hit-rate threshold)
