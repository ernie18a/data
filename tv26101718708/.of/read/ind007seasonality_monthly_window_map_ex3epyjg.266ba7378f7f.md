Calculation: Monthly average = for each calendar month and each available year, calculate the percentage change from the first available chart-bar close to the last available chart-bar close within the month's fixed non-leap-year day-of-year range; average those changes across years with data.
Calculation: Seasonal window statistics = for each start day of year and each allowed window length, with end day no later than the final day of a non-leap year, use years with closes on both exact day-of-year indices. Calculate each return as 100 × (end close / start close − 1), the sample count as the number of those years, the average return as their mean, and each directional hit rate as the percentage of returns strictly positive for bullish or strictly negative for bearish. Day-of-year indices are actual elapsed calendar days from the beginning of each year, including leap days.
Calculation: Directional window score = clamp to the allowed score range the product of directional hit rate, directional average return, sample adjustment, and score scale, divided by the square root of window length. Directional average return is the average return for bullish windows and its negative for bearish windows. Effective minimum samples is the greater of the fixed minimum and the lesser of the configured minimum and the number of stored years. Sample adjustment is 1 when disabled; otherwise it is 1 + (sqrt(sample count / effective minimum samples) − 1) × adjustment weight.
Calculation: Selected directional windows = scan candidate windows in ascending start day, then ascending length. Require sample count ≥ effective minimum samples, directional hit rate ≥ minimum hit rate, directional score ≥ minimum score, and, when enabled, directional average return > 0. Separately for each direction, reject a candidate if its overlap with any currently retained window is ≥ the overlap threshold, where overlap is 100 × max(0, min(end days) − max(start days)) / min(window lengths). Otherwise insert it after retained windows with equal or higher scores and discard the lowest-scoring windows beyond the configured count. The best window is the first retained window.
Long: Monthly average > neutral band.
Short: Monthly average < −neutral band.

Short: A best bearish window exists AND close < SMA of close AND (EMA confirmation is disabled OR close < EMA of close) AND ((window start > current day of year AND window start ≤ current day of year + soon interval) OR window start = current day of year OR (window start < current day of year AND window start ≥ current day of year − recent interval)).
