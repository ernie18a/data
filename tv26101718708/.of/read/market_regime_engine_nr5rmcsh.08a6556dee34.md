Calculation: Confirmed swing high or low = a pivot high or low with the same lookback on both sides, available only after the right-hand bars have completed; retain the latest and preceding confirmed pivot of each type.
Calculation: Structure direction = initially neutral; set to bullish when close > the latest confirmed swing high AND previous close <= that same swing high; then set to bearish when close < the latest confirmed swing low AND previous close >= that same swing low. Apply both updates in this order if both occur on one bar.
Calculation: Bullish or bearish displacement = respectively close > open or close < open AND absolute candle body / ATR >= a displacement threshold; use zero for the ratio when ATR <= 0.
Calculation: Active bullish order block = the most recent bearish candle within a search lookback preceding the latest bullish displacement that found such a candle; it remains active while its age from the candle <= an age limit AND close >= its low. Active bearish order block is the symmetric construction using a bullish candle, bearish displacement, and close <= its high. A displacement that finds no qualifying candle leaves the previous block unchanged.
Calculation: Regime score = sum these signed components, using zero for an unmet condition: price above/below its close SMA has weight +3/-3; (SMA minus its value a slope lookback ago) / ATR above/below positive/negative slope threshold has +3/-3; bullish/bearish displacement has +2/-2; volume / SMA of volume >= a relative-volume threshold AND close above/below open has +2/-2; latest confirmed swing high AND low both above/below their respective preceding pivots has +2/-2; a bullish/bearish structure break within a memory lookback with no opposite break in that lookback has +4/-4; a bullish/bearish change of character within that lookback with no opposite change in that lookback has +2/-2; ADX >= its threshold AND positive/negative DI > the other DI AND close above/below the SMA has +1/-1; a bullish/bearish fair value gap within its memory lookback with no opposite gap in that lookback has +0.5/-0.5; an active bullish/bearish order block without an active opposite block has +0.5/-0.5. A bullish gap is low > high two bars earlier; a bearish gap is high < low two bars earlier. A break is a swing-level crossing in the current structure direction or from neutral; a change of character is a crossing opposite to the preceding structure direction. Memory lookbacks include the current bar. Use zero for slope when ATR <= 0 or the earlier SMA is unavailable, and for relative volume when its average <= 0.
Calculation: Confirmed regime = initially neutral; classify the score on each bar as strong bullish, bullish, neutral, bearish, or strong bearish using ordered positive bullish and negative bearish thresholds, with strong thresholds farther from zero. A different raw classification replaces the confirmed regime only after it persists for a confirmation number of consecutive bars; reset the candidate count when the raw classification equals the confirmed regime or changes to another candidate.
Calculation: Rising or falling SMA = (current close SMA minus its value a slope lookback ago) / ATR > a positive slope threshold or < its negative, respectively; use zero when ATR <= 0 or the earlier SMA is unavailable. Flat means neither rising nor falling.
Calculation: Distribution condition = structure direction is bullish AND (latest confirmed swing high < preceding confirmed swing high AND SMA is not rising OR SMA is flat AND close <= SMA).
Long: close > latest confirmed swing high AND previous close <= that same swing high.
Short: close < latest confirmed swing low AND previous close >= that same swing low.
Long: bullish displacement.
Short: bearish displacement.
Long: bullish fair value gap occurred within its memory lookback AND bearish fair value gap did not occur within that lookback.
Short: bearish fair value gap occurred within its memory lookback AND bullish fair value gap did not occur within that lookback.
Long: active bullish order block AND no active bearish order block.
Short: active bearish order block AND no active bullish order block.
Long: bullish structure break occurred within its memory lookback AND bearish structure break did not occur within that lookback.
Short: bearish structure break occurred within its memory lookback AND bullish structure break did not occur within that lookback.
Long: bullish change of character occurred within its memory lookback AND bearish change of character did not occur within that lookback.
Short: bearish change of character occurred within its memory lookback AND bullish change of character did not occur within that lookback.
Long: confirmed regime is bullish OR strong bullish.
Short: confirmed regime is bearish OR strong bearish.
Long: close > SMA AND SMA is rising AND structure direction is bullish AND ADX >= its threshold AND distribution condition is false.
Short: close < SMA AND SMA is falling AND structure direction is bearish AND ADX >= its threshold.
