Calculation: Score = sum of nine tiered point terms, with more points for stronger or more overbought readings and fewer for weaker or more oversold ones. (1) Price location: most points if close > SMA(long-term) AND close > EMA(longer-term than the SMA) AND close > session VWAP; zero if close is below all three; otherwise middle. (2) RSI: most points if above the overbought level; zero if below the oversold level; else more points if RSI > 50 than if RSI <= 50. (3) VWMO = (VWMA(n) - VWMA(n) from n bars earlier) / VWMA(n) from n bars earlier * 100: most points if above a positive threshold; zero if below the negative threshold; else more points if > 0 than if <= 0. (4) ADX: most points if above a high threshold; middle if above a lower threshold; else zero. (5) Raw Stochastic %K (unsmoothed): same tiers as RSI. (6) CCI: same tiers as RSI with midline 0. (7) MFI: same tiers as RSI. (8) Volatility: most points if ATR > a multiple (>1) of SMA(ATR, longer lookback than the ATR); zero if ATR < a multiple (<1) of that SMA; else middle. (9) Cumulative delta, where delta = +volume if close > previous close, -volume if close < previous close, else 0: most points if cumulative delta rose this bar (close > previous close); zero if it fell; middle if unchanged.
Calculation: LongStop = max(entry*(1-hard stop pct), entry + offset*ATR if close-entry >= k1*ATR, close - d*TrailATR if close-entry >= k2*TrailATR). The last two terms are optional. The ATR is the main ATR; TrailATR is a separate ATR whose length may differ. Compute at the bar close; it applies from the next bar and only ratchets upward while the position is open.
Calculation: ShortStop = min(entry*(1+hard stop pct), entry - offset*ATR if entry-close >= k1*ATR, close + d*TrailATR if entry-close >= k2*TrailATR). Same conventions, mirrored; it only ratchets downward.
Long: Score < low threshold AND CCI crosses above its oversold level (previous CCI <= level AND current CCI > level) AND entries already taken today < daily cap AND (if a trading window is enabled) bar is inside the window
Short: Score > mid threshold AND Score < upper cap (a band, not just a minimum) AND CCI crosses below its overbought level (previous CCI >= level AND current CCI < level) AND entries already taken today < daily cap AND (if a trading window is enabled) bar is inside the window
Exit: long, low <= LongStop OR high >= entry + target multiple*ATR
Exit: short, high >= ShortStop OR low <= entry - target multiple*ATR
Exit: long or short, trading window is enabled AND the previous bar was inside the window AND the current bar is outside it (close at that bar)
