Calculation: New York time = the chart bar's opening time expressed in America/New_York, including daylight-saving changes.
Calculation: Range-build window = New York time >= configured session start AND New York time < configured range-build end.
Calculation: Trading window = New York time >= configured range-build end AND (New York time < configured session end OR New York time >= configured session start).
Calculation: Opening-range high and low = the highest high and lowest low accumulated during the range-build window since the previous trading-window start; lock them when the trading window changes from false to true. Opening-range midpoint = (locked high + locked low) / 2; range size = locked high - locked low.
Calculation: Session trade count = number of entry orders placed since the trading window most recently changed from false to true; reset to zero on that change.
Calculation: Higher-timeframe EMA = EMA of higher-timeframe closes using the last completed higher-timeframe bar.
Calculation: Latest pivot high or low = most recently confirmed chart-bar pivot high or low, using the same number of bars on each side for confirmation.
Calculation: Breakout volume condition = volume filter disabled OR volume > volume SMA multiplied by the breakout volume multiplier. Fade volume condition = volume filter disabled OR volume > volume SMA multiplied by the fade volume multiplier; the breakout multiplier is greater than the fade multiplier.
Calculation: Long range breakout = range size >= minimum range size AND range size <= maximum range size AND close > locked range high + breakout buffer AND previous close <= current locked range high + breakout buffer AND RSI > long breakout threshold AND breakout volume condition AND (higher-timeframe filter disabled OR close > higher-timeframe EMA).
Calculation: Short range breakout = range size >= minimum range size AND range size <= maximum range size AND close < locked range low - breakout buffer AND previous close >= current locked range low - breakout buffer AND RSI < short breakout threshold AND breakout volume condition AND (higher-timeframe filter disabled OR close < higher-timeframe EMA).
Calculation: Long pivot breakout = close > latest pivot high AND previous close <= current latest pivot high AND close > higher-timeframe EMA AND RSI > long breakout threshold AND breakout volume condition.
Calculation: Short pivot breakout = close < latest pivot low AND previous close >= current latest pivot low AND close < higher-timeframe EMA AND RSI < short breakout threshold AND breakout volume condition.
Calculation: Long fade = range size >= minimum range size AND range size <= maximum range size AND low <= locked range low + fade buffer AND close > locked range low AND previous close <= current locked range low AND RSI < oversold threshold AND fade volume condition AND (higher-timeframe filter disabled OR close > higher-timeframe EMA).
Calculation: Short fade = range size >= minimum range size AND range size <= maximum range size AND high >= locked range high - fade buffer AND close < locked range high AND previous close >= current locked range high AND RSI > overbought threshold AND fade volume condition AND (higher-timeframe filter disabled OR close < higher-timeframe EMA).
Calculation: Long stop = the smaller of signal-bar close - ATR multiplied by the stop multiplier and latest pivot low - stop buffer; if no pivot low is available, use the ATR stop. Short stop = the larger of signal-bar close + ATR multiplied by the stop multiplier and latest pivot high + stop buffer; if no pivot high is available, use the ATR stop. Freeze the stop at the entry signal.
Calculation: Long target = opening-range midpoint if long fade is true and both long breakout conditions are false; otherwise signal-bar close + (signal-bar close - long stop) multiplied by the reward-to-risk ratio. Short target = opening-range midpoint if short fade is true and both short breakout conditions are false; otherwise signal-bar close - (short stop - signal-bar close) multiplied by the reward-to-risk ratio. Freeze the target at the entry signal.
Long: Trading window = true AND long fade = true.
Short: Trading window = true AND short fade = true.
Long: Trading window = true AND session trade count < maximum trades AND position side = flat AND (blackout disabled OR New York time < blackout start OR New York time >= blackout end) AND (long range breakout = true OR long pivot breakout = true).
Short: Trading window = true AND session trade count < maximum trades AND position side = flat AND (blackout disabled OR New York time < blackout start OR New York time >= blackout end) AND (short range breakout = true OR short pivot breakout = true).
Exit: long, low <= frozen long stop OR high >= frozen long target.
Exit: short, high >= frozen short stop OR low <= frozen short target.
Exit: long OR short, range-build window = false AND trading window = false AND (previous bar range-build window = true OR previous bar trading window = true).
