Calculation: SessionMA = moving average (one type and length shared by all sessions) of close, updated only on bars inside that session's time-of-day window, so its lookback counts only in-window bars (concatenated across days); undefined outside the window. There are three fixed daily windows (they may overlap), each with its own SessionMA, break state and fakeout state, all evaluated independently. The state resets at the start of each window instance.
Calculation: FirstBreak = within a window instance, the first bar where SessionMA is defined and (close > SessionMA AND previous close <= SessionMA, which is an up break) OR (close < SessionMA AND previous close >= SessionMA, which is a down break). The previous close is compared with the current SessionMA value. Only one FirstBreak occurs per window instance; its direction and bar are stored.
Long: current bar is inside a window, no FirstBreak has yet occurred in this window instance, AND the FirstBreak up condition is true on this bar
Short: current bar is inside a window, no FirstBreak has yet occurred in this window instance, AND the FirstBreak down condition is true on this bar
Long: inside the window, the FirstBreak of this window instance was down, AND bars elapsed since the FirstBreak bar >= a fixed small bar count, AND no fakeout long has yet been issued in this window instance, AND close > SessionMA (failed down break)
Short: inside the window, the FirstBreak of this window instance was up, AND bars elapsed since the FirstBreak bar >= a fixed small bar count, AND no fakeout short has yet been issued in this window instance, AND close < SessionMA (failed up break)
