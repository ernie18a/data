Calculation: range direction (state machine on completed bars of a timeframe, chart timeframe or higher, last completed bar only) = start with range high/low from the first bar and direction 0; on each completed bar, if close > range high then direction = up, else if close < range low then direction = down; on either break, the range high/low are reset to that bar's own high/low and the old direction is pushed into a history (previous range 1 = direction held just before the latest break, previous range 2 = the one before that, and so on); if there is no break, range high/low and direction stay unchanged (range does not expand).
Long: current range direction is up OR the direction of a previous range n (n >= 1, n up to the number of ranges shown) is up
Short: current range direction is down OR the direction of a previous range n (n >= 1, n up to the number of ranges shown) is down
