Calculation: Tracked levels = an insertion-ordered list of resistance and support prices. On each bar, process confirmed pivot highs first and pivot lows second. For each pivot, if the first existing level of the same type within an ATR-based distance exists, retain its price; otherwise append the pivot price as a new level, removing the oldest level first if the list is at capacity. The shared capacity is twice the level-count parameter. Pivots use independently parameterized left and right bar counts and are available only when confirmed by the right bars.
Calculation: First crossed level = the first tracked level in insertion order that is either resistance with close > level + price buffer AND previous close <= level + price buffer, or support with close < level - price buffer AND previous close >= level - price buffer. Compare both closes with the current level and buffer. Update tracked levels before this comparison.
Calculation: Bars since signal = current bar index minus the bar index of the most recent breakout signal of either direction; initialize the most recent signal index to zero.
Long: First crossed level is resistance AND volume > volume SMA AND bars since signal >= cooldown.
Short: First crossed level is support AND volume > volume SMA AND bars since signal >= cooldown.
