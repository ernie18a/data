Calculation: Channel = previous bar's selected moving average of a selected price source, plus or minus a multiplier times the previous bar's true range smoothed by a selected EMA, SMA, WMA, or RMA; the plus and minus values are the upper and lower bands.
Calculation: Trend = initially neutral; change to up when the selected upper confirmation source (close or high) has been above the upper band for exactly the confirmation number of consecutive bars, preceded by a bar where that condition was false; change to down when the selected lower confirmation source (close or low) has been below the lower band for exactly the same number of consecutive bars, preceded by a bar where that condition was false. Otherwise retain the previous trend. If both changes occur on the same bar, apply the up change first and the down change second.
Calculation: Automatic take-profit and stop-loss percentages = selected percentile, calculated by linear interpolation between sorted observations, of separate rolling collections of positive favorable and adverse excursion percentages from completed trends. For each trend, start at the close of its first bar; initialize its highest and lowest prices to that close, then update them with each subsequent trend bar's high and low, excluding the bar on which the next trend begins. For an uptrend, favorable excursion is highest minus start and adverse excursion is start minus lowest; for a downtrend, favorable excursion is start minus lowest and adverse excursion is highest minus start. Divide each by the start price and multiply by 100; retain only positive observations, separately, up to a maximum sample count. Update the collections when a trend ends, before calculating the current bar's thresholds. A threshold is unavailable when its collection is empty.
Long: Position is flat AND (ATR filter is disabled OR previous bar's smoothed true range > current bar's SMA of true range) AND ((breakout mode AND trend changes to up and does not subsequently change to down on the same bar) OR (moving-average-cross mode AND trend is up AND low crosses below the previous bar's moving average)).
Short: Position is flat AND (ATR filter is disabled OR previous bar's smoothed true range > current bar's SMA of true range) AND ((breakout mode AND trend changes to down) OR (moving-average-cross mode AND trend is down AND high crosses above the previous bar's moving average)).
Exit: Long, high >= entry price × (1 + take-profit percentage / 100) OR low <= entry price × (1 - stop-loss percentage / 100).
Exit: Short, low <= entry price × (1 - take-profit percentage / 100) OR high >= entry price × (1 + stop-loss percentage / 100).
