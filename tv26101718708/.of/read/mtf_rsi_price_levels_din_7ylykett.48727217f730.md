Calculation: Requested-timeframe series = for a higher timeframe, use the last completed bar; for a lower timeframe, use the last completed intrabar within each chart bar; for the chart timeframe, use the current bar.
Calculation: RSI target price = for a requested timeframe, let n be the RSI length, C its close, G and L Wilder-smoothed gains and losses of the selected source, and R = target RSI / (100 - target RSI). If L * (n - 1) / n > 1e-10 and d = R * L * (n - 1) - G * (n - 1) >= 0, the price is C + d; otherwise, if R > 1e-10 and d = G * (n - 1) / R - L * (n - 1) >= 0, the price is C - d; otherwise it is undefined.
Calculation: Confluence = sum across four requested timeframes, ordered from fastest to slowest, of +1 if the chart-timeframe EMA of requested-timeframe close RSI is below the bullish threshold, -1 if it is above the bearish threshold, and 0 otherwise; replace unavailable requested RSI with 50 before smoothing.
Calculation: Confirmed pivot = a value at the center of a chart-bar window with equal left and right lookbacks that is the highest or lowest in that window; on ties, the most recent equal extreme is the pivot. Evaluate it when the right-hand lookback has completed.
Long: Confluence > 0
Short: Confluence < 0
Long: Chart close <= the defined oversold RSI target price for any of the four independently configured requested timeframes
Short: Chart close >= the defined overbought RSI target price for any of the four independently configured requested timeframes
Long: A chart-low pivot and a requested-timeframe close RSI low pivot are confirmed on the same chart bar AND the chart-low pivot < the preceding chart-low pivot AND the RSI low pivot > the preceding RSI low pivot
Short: A chart-high pivot and a requested-timeframe close RSI high pivot are confirmed on the same chart bar AND the chart-high pivot > the preceding chart-high pivot AND the RSI high pivot < the preceding RSI high pivot
