Calculation: Session VWAP = cumulative sum of typical price × volume divided by cumulative volume, reset at the start of each trading day; typical price = (high + low + close) / 3.
Calculation: Neutral-zone width = a fraction of the absolute distance between session VWAP and its upper standard-deviation band; the band uses the same typical price, volume weighting, session reset, and a band multiplier.
Long: Close > session VWAP + neutral-zone width AND session VWAP > previous bar's session VWAP.
Short: Close < session VWAP - neutral-zone width AND session VWAP < previous bar's session VWAP.
