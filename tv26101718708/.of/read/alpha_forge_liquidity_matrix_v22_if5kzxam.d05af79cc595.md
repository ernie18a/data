Calculation: Analysis bars = chart bars, or bars aggregated to a higher or lower analysis timeframe. On historical chart bars, use the last completed higher-timeframe bar, or the last completed lower-timeframe bar within the chart bar. Calculate analysis OHLCV, ATR, volume SMA, EMA, and confirmed swing highs and lows on that timeframe; update the remaining state once per chart bar. Relative volume = analysis volume / volume SMA, or 1 when the SMA is unavailable or zero.
Calculation: Liquidity levels = maintain separate ordered lists for swing highs and swing lows. Insert a confirmed symmetric pivot only when its returned value changes from unavailable to available on consecutive chart bars. Its initial weight is 1 plus an optional coefficient times clamp(relative volume from the pivot-length number of chart bars ago minus 1, 0, 2). Merge it into the first existing same-side level within ATR times a merge-distance coefficient times a sensitivity multiplier: replace the level by the old and new levels' weight-weighted mean, and replace its weight by clamp(old weight + initial weight + max(0, 1 - distance / max(merge distance, minimum price increment)), 1, maximum weight). Otherwise prepend a new level. When the list exceeds its capacity, remove the last level below the major-weight threshold, or the last level if none qualifies. After insertion, update every weight: an upper level receives a bounce increment when high >= level - merge distance AND close < level AND high < level + merge distance times a bounce-overshoot coefficient AND close < level - merge distance times a bounce-rejection coefficient; a lower level uses low <= level + merge distance AND close > level AND low > level - merge distance times the overshoot coefficient AND close > level + merge distance times the rejection coefficient. The increment is a base increment plus an optional coefficient times clamp(relative volume - 1, 0, 2). Otherwise multiply the weight by a decay factor. Clamp each resulting weight between 1 and the maximum weight.
Calculation: Upper level = the stored swing-high level nearest to and strictly above analysis close; lower level = the stored swing-low level nearest to and strictly below analysis close. Each level's upper and lower boundaries are its value plus and minus ATR times a zone-height coefficient.
Calculation: Upper base event = upper level exists AND analysis high > its upper boundary AND analysis close < its upper boundary in wick mode, or analysis close < the level in close or follow-through mode AND level weight >= minimum sweep weight AND upper wick >= ATR times minimum wick coefficient times exit-mode multiplier AND (high - close) / max(high - lower boundary, minimum price increment) >= minimum rejection coefficient times exit-mode multiplier AND optional relative-volume minimum passes AND optional chart-time session filter passes AND, in strict trend mode, analysis close <= analysis EMA AND chart bars since the previous upper base event > cooldown. Upper wick = high - max(open, close). Record each upper base event immediately for cooldown.
Calculation: Lower base event = lower level exists AND analysis low < its lower boundary AND analysis close > its lower boundary in wick mode, or analysis close > the level in close or follow-through mode AND level weight >= minimum sweep weight AND lower wick >= ATR times minimum wick coefficient times exit-mode multiplier AND (close - low) / max(upper boundary - low, minimum price increment) >= minimum rejection coefficient times exit-mode multiplier AND optional relative-volume minimum passes AND optional chart-time session filter passes AND, in strict trend mode, analysis close >= analysis EMA AND chart bars since the previous lower base event > cooldown. Lower wick = min(open, close) - low. Record each lower base event immediately for cooldown.
Calculation: Upper sweep = upper base event in wick or close mode; in follow-through mode, an existing pending upper base event confirms when its age is within the follow-through window AND analysis high <= saved sweep high + minimum price increment AND analysis close < saved level AND analysis close < saved sweep close. Cancel it when high > saved high + minimum price increment OR close > saved level OR its age exceeds the window. Lower sweep = lower base event in wick or close mode; in follow-through mode, an existing pending lower base event confirms when its age is within the follow-through window AND analysis low >= saved sweep low - minimum price increment AND analysis close > saved level AND analysis close > saved sweep close. Cancel it when low < saved low - minimum price increment OR close < saved level OR its age exceeds the window. Process pending events before saving new base events; a new same-side base event replaces the pending event.
Calculation: Bearish state = the latest upper sweep or long structural exit is within the post-sweep memory window AND no later lower sweep or short structural exit has replaced it. Bullish state = the latest lower sweep or short structural exit is within that window AND no later upper sweep or long structural exit has replaced it; a simultaneous lower event takes precedence. A structural exit also activates its side's circuit-breaker state for the memory window.
Long: Lower sweep occurs.
Short: Upper sweep occurs.
Exit: long, upper base event occurs AND upper level weight >= structural-exit minimum weight AND analysis close < analysis open AND analysis close < upper level - ATR times structural-exit offset.
Exit: short, lower base event occurs AND lower level weight >= structural-exit minimum weight AND analysis close > analysis open AND analysis close > lower level + ATR times structural-exit offset.
Long: Neither circuit-breaker state is active AND no current long structural exit occurs AND no upper sweep with signal weight >= major-weight threshold occurs AND bearish state is inactive AND (short structural exit occurs OR lower sweep with signal weight >= major-weight threshold occurs OR bullish state is active OR analysis close >= analysis EMA).
Short: Neither circuit-breaker state is active AND no current long structural exit occurs AND no upper sweep with signal weight >= major-weight threshold occurs AND bearish state is inactive AND no current short structural exit occurs AND no lower sweep with signal weight >= major-weight threshold occurs AND bullish state is inactive AND analysis close < analysis EMA.
