Calculation: SSL state = Set state to bullish when close > the selected moving average of high; otherwise set it to bearish when close < the same type and length of moving average of low; otherwise retain the previous state, initialized bullish. The SSL line is the low moving average in the bullish state and the high moving average in the bearish state. The selected moving average may be SMA, EMA, WMA, HMA, RMA, or VWMA.
Calculation: Normalized channel width = absolute difference between the high and low moving averages divided by ATR; use zero when ATR is not positive.
Calculation: Scale(x, lower, upper) = clamp((x - lower) / (upper - lower), 0, 1) when upper > lower; otherwise zero.
Calculation: Directional quality score = round(clamp(transition + momentum + trend + regime + participation + context - risk, 0, score ceiling)). Use separate directional calculations for long and short. Each named weight, threshold, and scale bound below is a parameter; corresponding long and short components use the same parameters.
Calculation: Transition = base transition weight + breakout weight × Scale(breakout distance, breakout lower bound, breakout upper bound) + body weight × body ratio + close-location weight × close location. Breakout distance is max(close - high moving average, 0) / ATR for long and max(low moving average - close, 0) / ATR for short, or zero if ATR is not positive. Body ratio is abs(close - open) / (high - low). Close location is (close - low) / (high - low) for long and (high - close) / (high - low) for short, clamped to [0, 1]. Use zero for these ratios when high equals low.
Calculation: Momentum = momentum weight × Scale(directional RSI distance from its midpoint, momentum lower bound, momentum upper bound) + RSI-rise weight when RSI rises for long or falls for short, otherwise the first term alone. Directional RSI distance is RSI - midpoint for long and midpoint - RSI for short.
Calculation: Trend = base trend weight + ADX weight × Scale(ADX, profile ADX threshold, profile ADX upper bound) + DI weight × directional DI dominance + ADX-rise weight when ADX rises, otherwise omit the ADX-rise weight. Directional DI dominance is clamp((positive DI - negative DI) / max(positive DI + negative DI, small positive floor), 0, 1) for long, with the DI terms reversed for short. The profile ADX upper bound equals its threshold for the responsive and selective profiles, and equals its threshold plus an ADX increment for the balanced profile.
Calculation: Regime = base regime weight + width weight × Scale(normalized channel width, profile width threshold, profile width upper bound) + width-rise weight when normalized channel width rises, otherwise omit the width-rise weight. The profile width upper bound equals its threshold for the responsive and selective profiles; for the balanced profile it equals its threshold plus max(profile width threshold × width multiplier, width increment floor).
Calculation: Participation = participation weight × Scale(volume / SMA of volume, volume lower bound, volume upper bound); use a fixed fallback contribution when volume or its SMA is unavailable or the SMA is not positive.
Calculation: Context = fixed alignment contribution when higher-timeframe confirmation is enabled and the last completed higher-timeframe SSL state agrees with the direction; otherwise zero when confirmation is enabled. When confirmation is disabled, context = SSL-line slope weight if the SSL line rises for long or falls for short, otherwise zero, plus distance weight × Scale(directional distance from the SSL line / ATR, distance lower bound, distance upper bound). Directional distance is max(close - SSL line, 0) for long and max(SSL line - close, 0) for short; use zero when ATR is not positive.
Calculation: Risk = wick weight × opposing wick ratio + extension weight × Scale(absolute distance from close to SSL line / ATR, extension lower bound, extension upper bound). Opposing wick ratio is (high - max(open, close)) / (high - low) for long and (min(open, close) - low) / (high - low) for short; use zero when high equals low. Use zero for normalized extension when ATR is not positive.
Calculation: Signal-quality profile = responsive, balanced, or selective; the ADX threshold, normalized-width threshold, and minimum quality score are each lower for responsive than balanced and lower for balanced than selective.
Long: SSL state = bullish
Short: SSL state = bearish
Long: SSL state changes from bearish to bullish on a completed chart bar AND RSI > its midpoint AND ADX > profile ADX threshold AND positive DI > negative DI AND normalized channel width >= profile width threshold AND (higher-timeframe confirmation disabled OR last completed higher-timeframe SSL state = bullish) AND long directional quality score >= profile minimum quality score
Short: SSL state changes from bullish to bearish on a completed chart bar AND RSI < its midpoint AND ADX > profile ADX threshold AND negative DI > positive DI AND normalized channel width >= profile width threshold AND (higher-timeframe confirmation disabled OR last completed higher-timeframe SSL state = bearish) AND short directional quality score >= profile minimum quality score
