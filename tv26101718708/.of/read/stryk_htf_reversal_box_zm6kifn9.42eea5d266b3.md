Calculation: Higher-timeframe band position = (close − (EMA(close) − band-width multiplier × ATR)) / (2 × band-width multiplier × ATR), or 0.5 if the denominator is not positive. Calculate all inputs on the higher timeframe using the preceding completed higher-timeframe bar; map them to chart bars with lookahead disabled, updating at the end of each higher-timeframe interval.
Calculation: Box state = Initially forming. On the first chart bar of each higher-timeframe interval, if forming or armed, set the box high and low to the highest high and lowest low over a configurable lookback of completed higher-timeframe bars, mapped with the same preceding-bar offset and lookahead disabled. Using the mapped band position and higher-timeframe volume and its SMA, arm short if band position ≥ upper threshold and volume ≥ volume multiplier × volume SMA; otherwise arm long if band position ≤ lower threshold and volume ≥ volume multiplier × volume SMA; otherwise set state to forming. Upper-threshold qualification takes precedence if both qualify. On the same bar, an armed box can lock upward if chart close > box high and chart volume ≥ chart-volume multiplier × chart-volume SMA, or downward if chart close < box low and the same volume filter holds. A locked box keeps its edges and direction until, on a subsequent bar, its target is hit, its opposite edge is closed through, or its timeout expires, checked in that order. A target hit resets it to forming. An opposite-edge close reverses its direction and sets a new target and timeout without a volume filter. At timeout, a close inside or on the box edges changes the state to consolidating; a close outside resets it to forming. A consolidating box locks in the direction of a close beyond either edge when the chart-volume filter holds. A reset does not requalify the box until the next higher-timeframe interval.
Calculation: Locked target = At each lock or reversal, the broken box edge plus the direction sign times an ATR multiplier times ATR. ATR is either chart-timeframe ATR or the mapped preceding completed higher-timeframe ATR, using the same ATR lookback for both. The multiplier is either fixed or the base multiplier plus slope × (chart volume / chart-volume SMA − 1), bounded by a minimum and maximum; use a volume ratio of 1 when the SMA is unavailable or nonpositive. A target is hit when chart high ≥ an upward target or chart low ≤ a downward target. The timeout counts chart bars from the latest lock or reversal.
Long: Box state = armed long OR box state = locked upward.
Short: Box state = armed short OR box state = locked downward.
