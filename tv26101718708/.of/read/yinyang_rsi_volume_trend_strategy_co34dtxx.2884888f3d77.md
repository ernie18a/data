Calculation: Midpoint = average of the volume-weighted moving average of the rolling highest high and the volume-weighted moving average of the rolling lowest low; both use the same trend lookback.
Calculation: Smoothed midpoint = exponential moving average of the midpoint using the trend lookback.
Calculation: Volume-adjusted midpoint = volume-weighted moving average, using a shorter lookback, of the smoothed midpoint multiplied by current volume divided by the volume-weighted moving average of volume over the trend lookback.
Calculation: Band offset = RSI of the volume-adjusted midpoint over the trend lookback, expressed as a fraction, multiplied by the simple moving average over the trend lookback of the difference between the volume-weighted rolling highest high and volume-weighted rolling lowest low.
Calculation: Upper band = smoothed midpoint + band offset; lower band = smoothed midpoint - band offset; basis = average of upper and lower bands.
Calculation: Upper stop = upper band multiplied by one plus the stop percentage; lower stop = lower band multiplied by one minus the stop percentage.
Calculation: Long availability = initially false; on each bar set true if purchase source crosses below the upper band, or if the reset mode is stop and exit source crossed below the lower stop on the preceding bar, or if the reset mode is entry and purchase source crosses below the lower band; otherwise set false if a long entry occurs, and otherwise retain the preceding value. Evaluate long entries using the preceding value.
Calculation: Short availability = initially false; on each bar set true if purchase source crosses above the lower band, or if the reset mode is stop and exit source crossed above the upper stop on the preceding bar, or if the reset mode is entry and purchase source crosses above the upper band; otherwise set false if a short entry occurs, and otherwise retain the preceding value. Evaluate short entries using the preceding value.
Calculation: Long take-profit availability = initially false; set true when exit source crosses above the basis, otherwise set false when exit source crosses above the upper band, otherwise retain the preceding value.
Calculation: Short take-profit availability = initially false; set true when exit source crosses below the basis, otherwise set false when exit source crosses below the lower band, otherwise retain the preceding value.
Long: Purchase source crosses above the lower band AND preceding long availability is true.
Short: Purchase source crosses below the upper band AND preceding short availability is true.
Exit: long, no long entry occurs on the current bar AND (exit source crosses above the upper band OR stop loss is enabled AND exit source crosses below the lower stop OR take profit is enabled AND long take-profit availability is true AND exit source crosses below the basis).
Exit: short, no short entry occurs on the current bar AND (exit source crosses below the lower band OR stop loss is enabled AND exit source crosses above the upper stop OR take profit is enabled AND short take-profit availability is true AND exit source crosses above the basis).
