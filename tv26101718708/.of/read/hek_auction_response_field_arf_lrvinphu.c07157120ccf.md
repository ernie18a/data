Calculation: Level(x, reference, exponent) = 100 * (max(x, 0) / max(reference, epsilon))^exponent / (1 + (max(x, 0) / max(reference, epsilon))^exponent), with the result zero when the numerator is zero; epsilon is a small positive parameter.
Calculation: Weighted evidence = 100 * exp(sum(weight_i * ln(max(component_i, epsilon)))); each evidence type has its own weights, which sum to one.
Calculation: Bar features = previous close defaults to current close when unavailable; true range is max(high - low, abs(high - previous close), abs(low - previous close)); safe true range and safe ATR are each floored at epsilon. ATR is Wilder's moving average of true range over the context lookback. Body is abs(close - open); upper wick is max(high - max(open, close), 0); lower wick is max(min(open, close) - low, 0). Close location is clamp(((close - low) - (high - close)) / safe true range, -1, 1).
Calculation: Effort and response = relative participation is volume / SMA(volume, context lookback), or 1 when volume or its average is unavailable or the average is nonpositive. Effort level is Level(sqrt(max(true range / safe ATR, 0) * max(relative participation, 0)), effort reference, level exponent). Response level is Level(weighted sum of body / safe ATR and abs(close - previous close) / safe ATR, response reference, level exponent); the two response weights sum to one.
Calculation: Direction and efficiency = path efficiency is clamp(abs(close - close at context lookback) / sum(abs(close - previous close), context lookback), 0, 1), or zero when the denominator is at most epsilon; substitute current close for an unavailable lookback close. Raw direction is clamp(weighted sum of close location and sign(close - open) * clamp(body / safe true range, 0, 1), -1, 1), with weights summing to one. Direction equals raw direction when its absolute value is at least the direction dead zone, otherwise zero. Direction conviction is Level(abs(direction), direction reference, evidence exponent); efficiency evidence is Level(path efficiency, efficiency reference, evidence exponent).
Calculation: Rejection = lower rejection is clamp(lower wick / safe true range * wick multiplier, 0, 1) * clamp((close location + 1) / 2, 0, 1); upper rejection is clamp(upper wick / safe true range * wick multiplier, 0, 1) * clamp((1 - close location) / 2, 0, 1). Bull one-sided rejection is lower rejection * (1 - upper rejection); bear one-sided rejection is upper rejection * (1 - lower rejection); two-sided rejection is sqrt(max(lower rejection * upper rejection, 0)).
Calculation: State evidence = let effort high, response high, efficiency high and direction conviction be their respective levels divided by 100; each low component is one minus its high component. Bull direction evidence is direction conviction when direction > 0, otherwise zero; bear direction evidence is direction conviction when direction < 0, otherwise zero; direction neutrality is one minus direction conviction. Bull and bear drive evidence are weighted evidence of effort high, response high, efficiency high and the respective direction evidence. Bull and bear absorption evidence are weighted evidence of effort high, response low, the respective one-sided rejection and efficiency low. Churn evidence is weighted evidence of effort high, response low, two-sided rejection and direction neutrality. Balance evidence is weighted evidence of effort low, response low and efficiency low. Each state has its own component weights.
Calculation: Vacuum evidence = leverage is Level(max(ln(max((response level + vacuum offset) / (effort level + vacuum offset), epsilon)), 0), ln(vacuum leverage reference), vacuum exponent) / 100. Bull and bear vacuum evidence are weighted evidence of leverage, response high, efficiency high and the respective direction evidence, using common vacuum weights.
Calculation: Response field = EMA(response level * direction * (field baseline + field efficiency weight * path efficiency), field smoothing lookback), where the baseline and efficiency weight sum to one. Display field is an additional EMA of the response field with its own smoothing lookback.
Calculation: Primary regime = update on each completed chart bar, initially transition. The active candidate is the highest evidence among bull drive, bear drive, bull absorption, bear absorption and churn, resolving ties in that order; its separation is its evidence minus the second-highest evidence. A candidate qualifies when its evidence >= active entry threshold AND its separation >= entry separation. From transition, enter a qualifying candidate; otherwise enter balance when balance evidence >= balance entry threshold AND candidate evidence < active entry threshold. From balance, enter the same qualifying candidate after it qualifies for the balance-escape confirmation count of consecutive bars; while a qualifying candidate is pending, retain balance. If no candidate qualifies, reset the escape count and retain balance only when balance evidence >= balance hold threshold, otherwise enter transition. From an active regime, first track a different qualifying candidate whose evidence exceeds the current regime's evidence by at least the switch margin; switch after the same candidate meets these conditions for the switch confirmation count of consecutive bars. Reset the switch count whenever eligibility fails or the candidate changes. While a switch is eligible but not yet confirmed, reset the weak-exit and balance-entry counts before continuing the remaining checks. If no switch commits, count consecutive bars in bull drive with response field <= 0 or in bear drive with response field >= 0; reset this count otherwise. At the field-guard confirmation count, leave drive for balance if balance evidence >= active-to-balance threshold AND candidate evidence < active entry threshold, otherwise leave for transition. If the guard does not fire, reset weak-exit and balance-entry counts when current regime evidence >= active hold threshold; otherwise increment the weak-exit count and increment the balance-entry count only while balance evidence >= active-to-balance threshold AND candidate evidence < active entry threshold, resetting that count otherwise. When the weak-exit count reaches its confirmation count, enter balance if the balance-entry count also reaches its confirmation count, otherwise enter transition. Reset relevant counts on leaving their regime or completing a transition.
Calculation: Timeline regime = initially transition; on each completed chart bar, if primary regime equals timeline regime reset the pending count; otherwise count consecutive bars with the same primary regime, restarting the count when it changes, and set timeline regime to that primary regime when the timeline confirmation count is reached.
Long: Primary regime = bull drive OR primary regime = bull absorption OR timeline regime = bull drive OR timeline regime = bull absorption OR display field > 0 OR response field >= bullish field threshold OR (bull vacuum evidence >= vacuum threshold AND direction > 0).
Short: Primary regime = bear drive OR primary regime = bear absorption OR timeline regime = bear drive OR timeline regime = bear absorption OR display field < 0 OR response field <= negative bearish field threshold OR (bear vacuum evidence >= vacuum threshold AND direction < 0).
