Calculation: Directional indicators and ADX = Select either classic Wilder ADX and directional indicators, or the following variant: true range is max(high − low, abs(high − previous close), abs(low − previous close)), with missing previous values replaced by zero. Positive directional movement is max(high − previous high, 0) if that increase exceeds previous low − low, otherwise zero; negative directional movement is max(previous low − low, 0) if that decrease exceeds high − previous high, otherwise zero. Smooth each series recursively as previous smoothed value − previous smoothed value / length + current value, starting from zero. Each directional indicator is 100 times its smoothed movement divided by smoothed true range. ADX is the simple moving average of 100 × abs(positive indicator − negative indicator) / (positive indicator + negative indicator).
Calculation: Range filter = Let source be an input price series, defaulting to open. Range is a multiplier times the EMA of the EMA of abs(source − previous source), with the outer EMA length equal to twice the inner length minus one. Initialize the previous filter to zero when missing. If source > previous filter, filter = max(source − range, previous filter); otherwise filter = min(source + range, previous filter). The upward count increments when the filter rises, resets to zero when it falls, and otherwise retains its previous value; the downward count does the opposite. Both start at zero. Upper and lower bands are filter + range and filter − range.
Calculation: Relative momentum index = Let up be the EMA of max(close − close from a momentum lookback ago, 0), and down be the EMA of max(close from that lookback ago − close, 0), using the same smoothing length. The index is zero when down is zero, otherwise 100 − 100 / (1 + up / down).
Calculation: Adaptive cloud line = Use the range filter source. Efficiency ratio is abs(source − source from a lookback ago) divided by the sum of abs(source − previous source) over that lookback. Define H(x) = 0.0962x + 0.5769x[2] − 0.5769x[4] − 0.0962x[6], replacing missing lagged values with zero. On each bar set multiplier = 0.075 × previous period + 0.54; smooth = (4 × source + 3 × source[1] + 2 × source[2] + source[3]) / 10; detrender = H(smooth) × multiplier; I1 = detrender[3]; Q1 = H(detrender) × multiplier; jI = H(I1) × multiplier; jQ = H(Q1) × multiplier. Set I2 = 0.2 × (I1 − jQ) + 0.8 × previous I2 and Q2 = 0.2 × (Q1 + jI) + 0.8 × previous Q2. Set Re = 0.2 × (I2 × previous I2 + Q2 × previous Q2) + 0.8 × previous Re and Im = 0.2 × (I2 × previous Q2 − Q2 × previous I2) + 0.8 × previous Im. Start period at zero each bar; when Re and Im are both nonzero set it to 2π / atan(Im / Re), clamp it first between 0.67 and 1.5 times previous period and then between 6 and 50, and smooth it as 0.2 × period + 0.8 × previous period. Phase is degrees(atan(Q1 / I1)) when I1 is nonzero, otherwise zero. Delta phase = max(previous phase − phase, 1); a = max(efficiency ratio / delta phase, 0.1 × efficiency ratio); b = a / 2; alpha = (efficiency ratio × (b − a) + a)². Cloud line = alpha × source + (1 − alpha) × previous cloud line. Replace missing historical values in these recurrences with zero.
Calculation: Signal reference price and state = Record each basic long or short decision's close and time, even if no trade is filled. The active signal side is whichever has the later recorded time; equal times give neither side. For each side, a swap event occurs when its active side's low crosses below its latest long-decision close times one minus the swap percentage, or its high crosses above its latest short-decision close times one plus the swap percentage, respectively, with no same-side basic decision on that bar. A final swap event additionally requires that the previous same-side swap state was reset by a same-side basic decision since its previous swap event. Track consecutive same-side basic decisions and final swap events, resetting the opposite side's count and sum; add the decision close for a basic decision or the corresponding swap level for a final swap event. If both sides occur on one bar, process long then short. Reference price is the applicable sum divided by count on an event bar, carried forward from the most recent nonmissing reference price otherwise. After a take-profit marking, reset both sums and counts. A take-profit marking occurs at most once since the latest same-side basic decision, when high crosses above reference price times one plus the profit percentage for an active long signal, or low crosses below reference price times one minus the profit percentage for an active short signal, with no same-side basic decision on that bar. Crosses compare both current and previous bars against their respective bar's threshold.
Long: Positive directional indicator > negative directional indicator AND ADX > ADX threshold
Short: Positive directional indicator < negative directional indicator AND ADX > ADX threshold
Long: (RSI of session VWAP of close crosses above its lower threshold OR relative momentum index crosses above its lower threshold) AND high > upper range band AND upward count > 0 AND NOT (positive directional indicator < negative directional indicator AND ADX > ADX threshold)
Short: (RSI of session VWAP of close crosses below its upper threshold OR relative momentum index crosses below its upper threshold) AND low < lower range band AND downward count > 0 AND NOT (positive directional indicator > negative directional indicator AND ADX > ADX threshold)
Long: Positive directional indicator > negative directional indicator AND ADX > ADX threshold AND volume > volume simple moving average × volume multiplier AND RSI of an input price series, defaulting to low, < upper RSI threshold AND adaptive cloud line > previous adaptive cloud line
Short: Positive directional indicator < negative directional indicator AND ADX > ADX threshold AND volume > volume simple moving average × volume multiplier AND RSI of an input price series, defaulting to low, > lower RSI threshold AND adaptive cloud line < previous adaptive cloud line
Exit: long, high >= reference price × (1 + profit percentage), for a partial position
Exit: short, low <= reference price × (1 − profit percentage), for a partial position
Exit: long, low <= reference price × (1 − stop percentage)
Exit: short, high >= reference price × (1 + stop percentage)
