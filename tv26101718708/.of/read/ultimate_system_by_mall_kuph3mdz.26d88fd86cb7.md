Calculation: Per-timeframe sentiment score = round((sum of eight votes + 8) / 16 × 100). For each configured sentiment timeframe, votes are: +1 if close > open, −1 if close < open; +1 if close position within high-low range ≥ bullish-position threshold, −1 if ≤ bearish-position threshold; +1 if short-, medium-, and long-lookback EMAs are stacked upward, −1 if stacked downward; +1 if RSI > bullish threshold, −1 if RSI < bearish threshold; +1 if MACD histogram > 0, −1 if < 0; +1 if close > open and volume > volume-average × confirmation multiplier, −1 if close < open and volume > that level; +1 if stochastic > bullish threshold, −1 if < bearish threshold; +1 if close > prior close > two-bars-prior close, −1 if close < prior close < two-bars-prior close. Other votes are 0. For a timeframe above the chart timeframe use its still-forming bar; below, its most recent completed bar; equal, the current chart bar.
Calculation: Recovery condition = daily close is above the midpoint of the preceding 20 daily-bar high-low range and above the daily short-lookback EMA. For daily bars above the chart timeframe use the still-forming bar; below, the most recent completed bar; equal, the current chart bar.
Calculation: Bias score = sum of eight 1/0 conditions: weekly close > weekly open; weekly close > weekly short-lookback EMA; daily close > daily open; daily close > daily short-, medium-, and long-lookback EMAs; daily short-lookback EMA > daily medium-lookback EMA; recovery condition. For weekly/daily bars above the chart timeframe use the still-forming bar; below, the most recent completed bar; equal, the current chart bar.
Long: A new bullish signal occurs when all three shorter configured sentiment-timeframe scores are ≥ bullish-signal threshold, this was not true on the previous chart bar, the bullish cooldown has elapsed, and either the longest configured sentiment-timeframe score is below threshold or all four scores were not ≥ threshold on the previous chart bar; OR all four scores are ≥ threshold, they were not all ≥ threshold on the previous chart bar, and the bullish cooldown has elapsed; OR bias score ≥ long-label threshold and the short-ban condition is false; OR any configured sentiment-timeframe score ≥ bullish-mark threshold; OR total weighted sentiment score ≥ bullish-label threshold; OR bias score ≥ bullish-color threshold.
Short: A new bearish signal occurs when all three shorter configured sentiment-timeframe scores are ≤ bearish-signal threshold, this was not true on the previous chart bar, the bearish cooldown has elapsed, and either the longest configured sentiment-timeframe score is above threshold or all four scores were not ≤ threshold on the previous chart bar; OR all four scores are ≤ threshold, they were not all ≤ threshold on the previous chart bar, and the bearish cooldown has elapsed; OR bias score ≤ short-label threshold and the short-ban condition is false; OR any configured sentiment-timeframe score ≤ bearish-mark threshold; OR total weighted sentiment score ≤ bearish-label threshold; OR bias score ≤ bearish-color threshold.
