Calculation: Currency strength = for each of the 28 major currency pairs, add 1 to the base currency when its close is above its reference moving average; otherwise add 1 to the quote currency. The reference moving average is an SMA or EMA with one lookback length, calculated on the requested timeframe, which is equal to or higher than the chart timeframe; use the bar still forming.
Calculation: Pair strength difference = base currency strength − quote currency strength.
Long: Pair strength difference > 0
Short: Pair strength difference < 0
