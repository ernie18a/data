Calculation: Reference high and low = the high and low of either the last completed bar on a higher timeframe or the chart timeframe, or the last completed session, measured from chart bars whose open times fall within the session window. Replace each pair when its next period or session completes.
Long: For any reference low, the current or an earlier chart bar since the reference became active has low < reference low AND current close > reference low AND no prior long decision has occurred for that reference low since it became active.
Short: For any reference high, the current or an earlier chart bar since the reference became active has high > reference high AND current close < reference high AND no prior short decision has occurred for that reference high since it became active.
