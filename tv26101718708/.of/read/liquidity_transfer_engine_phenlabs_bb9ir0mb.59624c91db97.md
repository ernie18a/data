Calculation: Latest swing high/low = most recently confirmed pivot high/low, using the same number of bars on each side; update it before evaluating the current bar.
Calculation: Session high/low = highest high/lowest low accumulated during the most recent configured session; evaluate session sweeps only on the first bar outside that session.
Calculation: Reclaim boundary = selected one of (1) current bar's open–close midpoint, (2) midpoint of the latest swing high and low, substituting the current high or low for a missing swing, or (3) latest swing low for a bullish sweep or latest swing high for a bearish sweep, substituting the current low or high if missing. In automatic mode, use the swing high–low midpoint if both swings exist and that midpoint is above the swept level for a bullish sweep or below it for a bearish sweep; otherwise use the current bar's open–close midpoint.
Calculation: Bullish sweep event = on a completed bar, choose the latest swing low, or the session low on the first bar outside the session, as the swept level; low < swept level − penetration multiplier × ATR AND close > swept level AND close > reclaim boundary.
Calculation: Bearish sweep event = on a completed bar, choose the latest swing high, or the session high on the first bar outside the session, as the swept level; high > swept level + penetration multiplier × ATR AND close < swept level AND close < reclaim boundary.
Calculation: Finalized sweep event = a sweep event whose observation window has elapsed, counting completed bars after the sweep bar; retain only the most recent configured maximum number of events, removing the oldest event after processing each bar.
Long: bullish sweep event occurs OR bullish sweep event finalizes.
Short: bearish sweep event occurs OR bearish sweep event finalizes.
