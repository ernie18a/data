Calculation: Ordered score levels = a < b < c < d < e < f < g < h < i < j; use the same levels across all four component scores.
Calculation: Direction score = first matching result: j if close > short SMA > long SMA AND short SMA > its previous value AND close > high minus a small fraction of the bar range; i if close > short SMA > long SMA; h if close > short SMA AND short SMA < long SMA; f if close < short SMA AND short SMA > long SMA; b if close < short SMA < long SMA AND short SMA < its previous value AND close < low plus a small fraction of the bar range; d if close < short SMA < long SMA; otherwise g.
Calculation: Momentum score = first matching result: j if RSI >= upper RSI threshold AND RSI > previous RSI AND close > previous close by a minimum fraction; i if RSI >= lower bullish RSI threshold AND RSI < upper RSI threshold AND RSI > previous RSI; h if RSI is between the lower neutral RSI threshold and lower bullish RSI threshold inclusive AND absolute close-to-close percentage change < small-change threshold; e if RSI >= lower bearish RSI threshold AND RSI < lower neutral RSI threshold AND RSI < previous RSI; c if RSI >= extreme-low RSI threshold AND RSI < lower bearish RSI threshold AND RSI < previous RSI AND close < previous close by a minimum fraction; a if RSI < extreme-low RSI threshold OR RSI > extreme-high RSI threshold; otherwise g.
Calculation: Accumulation score = first matching result: j if absolute close-to-close percentage change is below a small-change threshold for a longer consecutive run AND Bollinger Band width < its rolling upper percentile multiplied by the smallest width factor; i if that change is below the same threshold for a shorter consecutive run AND width < that percentile multiplied by a larger width factor; h if that change <= a moderate-change threshold AND width is between the larger width factor and a still larger width factor times that percentile inclusive; e if that change > a large-change threshold AND width > that percentile multiplied by a higher width factor; b if that change > a larger-change threshold AND width > that percentile multiplied by a still higher width factor; a if that change > the largest-change threshold; otherwise g. Bollinger Band width = (upper band - lower band) / middle band; its rolling percentile includes the current bar.
Calculation: Flow score = first matching result: j if CMF > high positive threshold AND MFI of close > high threshold; i if CMF > lower positive threshold AND MFI of close >= middle threshold; h if CMF is between a small negative threshold and the lower positive threshold inclusive AND MFI of close >= lower threshold AND MFI of close < middle threshold; e if CMF >= a larger negative threshold AND CMF < the small negative threshold; c if CMF < the larger negative threshold AND MFI of close < low threshold; a if CMF < a still larger negative threshold AND MFI of close < a still lower threshold; otherwise g. CMF uses zero money-flow volume when high equals low and returns zero when rolling volume sums to zero.
Calculation: Composite directional score = (direction score + momentum score + accumulation score + flow score) / number of component scores.
Long: composite directional score >= bullish threshold.
Short: composite directional score < bearish threshold.
