Calculation: Momentum = EMA of RSI of close.
Calculation: Velocity = momentum minus its previous-bar value.
Calculation: Acceleration z-score = (EMA of the one-bar change in EMA of velocity minus its rolling SMA) divided by its rolling population standard deviation; use zero when that standard deviation is zero.
Calculation: Higher-timeframe momentum = momentum calculated on higher-timeframe bars, shifted back one higher-timeframe bar, then merged onto chart bars with lookahead off: update on the final chart bar of each higher-timeframe bar and forward-fill between updates.
Calculation: Decision bar for a setup and velocity direction = the setup bar when confirmation is disabled. When confirmation is enabled, maintain one pending setup per signal type: start it on a setup bar only if none is pending; starting with the next bar, emit on the first bar whose velocity has the specified sign, including the last bar of the confirmation window. If no such bar occurs by the end of the window, discard it. Process confirmation or expiry before accepting a new setup on the same bar.
Long: Current bar = decision bar for an ignition-long setup with positive velocity, where the setup requires acceleration z-score crossing above the positive ignition threshold AND velocity > 0 AND oversold threshold < momentum < overbought threshold AND (higher-timeframe filter disabled OR higher-timeframe momentum < overbought threshold).
Short: Current bar = decision bar for an ignition-short setup with negative velocity, where the setup requires acceleration z-score crossing below the negative ignition threshold AND velocity < 0 AND oversold threshold < momentum < overbought threshold AND (higher-timeframe filter disabled OR higher-timeframe momentum > oversold threshold).
Short: Current bar = decision bar for an exhaustion-top setup with negative velocity, where the setup requires acceleration z-score crossing below the negative exhaustion threshold AND momentum >= overbought threshold AND previous-bar momentum > every momentum value in the preceding trend lookback AND (higher-timeframe filter disabled OR higher-timeframe momentum >= overbought threshold) AND (volume filter disabled OR volume >= volume multiplier × SMA of volume).
Long: Current bar = decision bar for an exhaustion-bottom setup with positive velocity, where the setup requires acceleration z-score crossing above the positive exhaustion threshold AND momentum <= oversold threshold AND previous-bar momentum < every momentum value in the preceding trend lookback AND (higher-timeframe filter disabled OR higher-timeframe momentum <= oversold threshold) AND (volume filter disabled OR volume >= volume multiplier × SMA of volume).
