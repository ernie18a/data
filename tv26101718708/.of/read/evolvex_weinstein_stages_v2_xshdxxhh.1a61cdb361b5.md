Calculation: Higher-timeframe values = OHLCV aggregated to the stage timeframe. On historical chart bars, use the last completed higher-timeframe bar; on the current live chart bar, use the higher-timeframe bar still forming. If the stage timeframe is lower than the chart timeframe, use the last lower-timeframe bar within each chart bar.
Calculation: Trend average = SMA of higher-timeframe close. Its change is the current trend average minus its value a specified number of higher-timeframe bars ago. Rising means change > 0 AND absolute change / current trend average × 100 > the flatness threshold; falling means change < 0 AND absolute change / current trend average × 100 > the flatness threshold.
Calculation: Upward volume surge = higher-timeframe volume > its higher-timeframe volume SMA × the breakout multiplier AND higher-timeframe close > higher-timeframe open. Downward volume surge = higher-timeframe volume > its higher-timeframe volume SMA × the breakdown multiplier AND higher-timeframe close < higher-timeframe open.
Calculation: Stage = a persistent state updated on every chart bar, initially unassigned. Using the previous chart bar's stage, apply the first matching rule: set stage to 2 if previous stage is 1, 3, or unassigned AND higher-timeframe close > trend average AND trend average is rising AND volume confirmation is disabled or there is an upward volume surge; or if previous stage is 2 AND higher-timeframe close > trend average. Otherwise set stage to 4 if previous stage is 3 AND higher-timeframe close < trend average AND trend average is falling AND volume confirmation is disabled or there is a downward volume surge; or if previous stage is 4 AND higher-timeframe close < trend average. Otherwise set stage to 3 if previous stage is 2; or previous stage is 1 AND higher-timeframe close < trend average AND trend average is falling; or previous stage is 3. Otherwise set stage to 1 if previous stage is 4, 1, or unassigned. Retain the previous stage if no rule matches.

Long: Upward volume surge AND stage = 1 OR upward volume surge AND stage = 2
Short: Stage = 4
Short: Downward volume surge AND stage = 3 OR downward volume surge AND stage = 4
Exit: long, stage = 4
