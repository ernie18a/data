Calculation: Pivot sequence = On each chart bar, detect pivot highs and lows using the same configurable number of bars on each side. Maintain ordered pivot prices, indices, and types H, HH, LH, L, HL, LL. For a new high, classify it H if the sequence has at most two pivots; otherwise classify it HH if the pivot two positions before the insertion point is lower, else LH. Classify a new low analogously as L, HL if that earlier pivot is lower, else LL. With only a high pivot: append after a low if the high is above the last pivot; if it is below, replace the last pivot with the most recently detected low; after a high, replace it only if the new high is higher. With only a low pivot, apply the mirror rule. With simultaneous pivots: after L or LL, replace the last pivot with the new low if lower, otherwise append the new high; after H or HH, replace it with the new high if higher, otherwise append the new low. After LH, append the low if the new high is lower; if the new high is higher, replace the last pivot with the high when close is below the last pivot, or append the low when close is above it. After HL, append the high if the new low is higher; if the new low is lower, replace the last pivot with the low when close is above the last pivot, or append the high when close is below it. Equalities in the conditional branches cause no update. Retain the most recent pivots and expose the latest five as O, X, A, B, C only after more than eleven pivots are stored; each point includes its price and bar index.
Calculation: Candidate D and extreme E = For a downward candidate, D is the low and E is the lowest low observed since C became the latest pivot; for an upward candidate, D is the high and E is the highest high observed since C became the latest pivot. Reset E to the current bar's extreme whenever C's index changes. D is taken from the current bar, or, if final-pivot confirmation is enabled, from a configurable number of bars ago capped at one less than the pivot period. In the latter case D must equal the lowest low or highest high, respectively, from D's bar through the current bar. D's index must be later than C's.
Calculation: Ratios = For each candidate, let r1 = abs(A-B)/abs(X-A), r2 = abs(B-C)/abs(A-B), r3 = abs(C-D)/abs(B-C), r4 = abs(A-D)/abs(X-A), e1 = abs(A-E)/abs(X-A), and e2 = abs(C-E)/abs(B-C). A ratio with a zero denominator is unavailable. All range bounds are inclusive and are independently configurable for each named pattern; the lower and upper bounds of each range are distinct parameters.
Calculation: XABCD match = X, A, B, C and D have strictly increasing indices AND X < A AND X < B for a downward candidate, or X > A AND X > B for an upward candidate AND r1, r2, r3 and r4 each lie within their respective pattern-specific ranges AND, if structural validation is enabled, e1 is at most the upper bound of that pattern's r4 range. Apply this separately to Gartley, Butterfly, Shark, Bat, Deep Crab, Cypher, Alternative Shark, Alternate Bat, Nen-Star and Dragon, each with its own four ratio ranges.
Calculation: Five-point extension match = O, X, A, B, C and D have strictly increasing indices AND X < O AND X < A for a downward candidate, or X > O AND X > A for an upward candidate AND r1, r2 and r3 each lie within their respective pattern-specific ranges AND, if structural validation is enabled, e2 is at most the upper bound of the r3 range.
Calculation: Three-leg match = A, B, C and D have strictly increasing indices AND A > B for a downward candidate, or A < B for an upward candidate AND r2 and r3 each lie within their respective pattern-specific ranges AND abs(C-D)/abs(A-B) lies within its symmetry range AND, if structural validation is enabled, e2 is at most the upper bound of the r3 range.
Calculation: Three-drive match = O, X, A, B, C and D have strictly increasing indices AND X < O AND O > A AND C < A for a downward candidate, or X > O AND O < A AND C > A for an upward candidate AND r1 and r3 each lie within their respective pattern-specific ranges AND, if structural validation is enabled, e2 is at most the upper bound of the r3 range AND O-X is at least a configurable multiple of A-B for a downward candidate, or X-O is at least that multiple of B-A for an upward candidate.
Calculation: New pattern event = At chart-bar close, a pattern match whose direction and pattern are enabled and whose anchor index differs from the last emitted anchor for that pattern and direction; update that stored anchor for every matching event, including events suppressed by priority. The anchor is X for XABCD, O for five-point extension and three-drive, and A for three-leg. If multiple events occur on the same bar, select the first in this order: Gartley, Butterfly, Bat, Deep Crab, Cypher, Alternate Bat, Nen-Star, Alternative Shark, Shark, Dragon, five-point extension, three-leg, three-drive; within each pattern select bullish before bearish. Downward candidates are bullish and upward candidates bearish, except Dragon, whose upward candidate is bullish and downward candidate bearish.
Calculation: Confirmation state = Each selected new pattern event stores its direction and anchor, resets confirmation to false and starts a pending confirmation, replacing any previously pending event. Cancel pending confirmation if its current family anchor changes. While pending, set confirmation true and stop waiting when a bullish event has close above the previous high, or a bearish event has close below the previous low, AND abs(close-open)/(high-low) exceeds a configurable body-ratio threshold; use zero for that ratio when high equals low. Confirmation may occur on the event bar. The confirmation pulse occurs only when confirmation is true on the current bar and was false on the previous bar.
Long: The selected new pattern event is bullish OR the confirmation pulse occurs AND the stored event direction is bullish.
Short: The selected new pattern event is bearish OR the confirmation pulse occurs AND the stored event direction is bearish.
