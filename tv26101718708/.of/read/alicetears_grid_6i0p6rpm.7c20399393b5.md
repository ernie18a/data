Calculation: Session start = when custom sessions are enabled, a bar is in the configured session and either the previous bar was outside it or the calendar day of the month changed; otherwise, when the calendar day of the month changed. Session membership uses the configured timezone.
Calculation: Baseline = open of the session-start bar when custom sessions are enabled; otherwise, open of the still-forming higher-timeframe calendar-day bar at session start. Hold the baseline until the next session start.
Calculation: Grid levels = for each integer index from 1 through the configured maximum, long level = baseline × (1 − index × grid-step fraction), short level = baseline × (1 + index × grid-step fraction), and target = the same formula with index minus 1. Reset all per-side, per-index traded and breached states at each session start. Each level can enter once per session.
Calculation: Trailing exit = after its activation price is reached, track the most favorable price for the position and exit when price reverses by the configured trailing-offset fraction of the close used when the exit order was placed or updated. Standard-mode orders are placed or updated while the position is open; reversal-mode orders are placed or updated only on a target-reversal bar and remain active afterward. The optional stop on an active trailing order is the current grid level adjusted away from the baseline by grid-step fraction × stop multiplier.
Long: The level has not traded this session AND the bar is within the configured date range when the date filter is enabled AND the bar is in the configured session when custom sessions are enabled AND ((entry reversal mode is enabled AND a prior close below the current long level has been recorded while these filters were satisfied since the session start AND close > current long level) OR (entry reversal mode is disabled AND close crosses below the long level)).
Short: The level has not traded this session AND the bar is within the configured date range when the date filter is enabled AND the bar is in the configured session when custom sessions are enabled AND ((entry reversal mode is enabled AND a prior close above the current short level has been recorded while these filters were satisfied since the session start AND close < current short level) OR (entry reversal mode is disabled AND close crosses above the short level)).
Exit: long, target reversal mode enabled AND trailing disabled AND previous close > current target AND close < current target.
Exit: short, target reversal mode enabled AND trailing disabled AND previous close < current target AND close > current target.
Exit: long, target reversal mode disabled AND trailing disabled AND close >= current target.
Exit: short, target reversal mode disabled AND trailing disabled AND close <= current target.
Exit: long, trailing enabled AND price reaches the active trailing exit or its enabled stop; activate at the current target in standard mode or at the close of a bar where previous close > current target AND close < current target in reversal mode.
Exit: short, trailing enabled AND price reaches the active trailing exit or its enabled stop; activate at the current target in standard mode or at the close of a bar where previous close < current target AND close > current target in reversal mode.
Exit: long, manual stop enabled AND close <= current long grid level × (1 − grid-step fraction × stop multiplier).
Exit: short, manual stop enabled AND close >= current short grid level × (1 + grid-step fraction × stop multiplier).
Exit: long, force-close enabled AND custom sessions enabled AND previous bar in session AND current bar outside session.
Exit: short, force-close enabled AND custom sessions enabled AND previous bar in session AND current bar outside session.
