Calculation: Take-profit reference = the position's average entry price and size immediately after the initial entry or a scale-in; retain both through partial exits and add-backs. Reset the take-profit step count to zero after each initial entry or scale-in.
Calculation: Take-profit target step = the lesser of floor(((close - take-profit reference price) / take-profit reference price) / profit-step fraction) and max(1, floor(1 / close fraction)). On an exit, close the reference size multiplied by the close fraction and the number of newly reached steps, capped at the current position size; at the maximum step, close the entire position. Set the take-profit step count to the target step. After a nonfinal exit, schedule an add-back on the next bar equal to an add-back fraction of the estimated remaining position.
Calculation: Scale-in count = number of scale-ins since the current position opened, excluding add-backs; reset to zero when a new position opens.

Short: Close crosses below Supertrend.

Long: A nonfinal partial take-profit scheduled a positive add-back on the preceding bar AND position is long.
Exit: long, take-profit reference price is nonzero AND (close - take-profit reference price) / take-profit reference price >= profit-step fraction AND take-profit target step > take-profit step count.
