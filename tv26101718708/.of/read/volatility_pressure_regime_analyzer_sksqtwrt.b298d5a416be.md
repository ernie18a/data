Calculation: Price source = a selectable price derived from the chart bar’s OHLC fields.
Calculation: Efficiency ratio = absolute change in price source over the efficiency lookback divided by the sum of absolute one-bar price-source changes over that lookback; use zero if the denominator is zero.
Calculation: Compression = 100 minus the percentile rank of ATR over the ranking lookback.
Calculation: Convexity = percentile rank, over the ranking lookback, of the absolute one-bar change in log price-source return.
Calculation: Price-only pressure = (compression + 1.5 × convexity + 100 × (1 − efficiency ratio)) / 3.5; pressure percentile = its percentile rank over the ranking lookback.
Calculation: Release strength = clamp(((high − low) / ATR − 0.8) / 1.2, 0, 1); use a range-to-ATR ratio of zero when ATR is zero.
Calculation: Up score = 2 × indicator(close > highest high of the preceding trigger-lookback bars) + indicator(close − low >= high − close) + indicator(price source >= its value at the direction lookback). Down score = 2 × indicator(close < lowest low of the preceding trigger-lookback bars) + indicator(close − low < high − close) + indicator(price source < its value at the direction lookback).
Calculation: Raw release = highest pressure percentile over the loading lookback, including the current bar, >= pressure threshold AND release strength >= release threshold. A release event occurs only when the consecutive raw-release count equals the confirmation count AND the bars since the previous accepted release event >= minimum gap. Reset the count to zero when raw release is false; update the previous-event bar only when an event is accepted.
Calculation: Cloud bias = +1 when close is above both displaced Ichimoku spans, −1 when below both, and 0 otherwise. Span A is the mean of the conversion and base midranges; span B is the longer-lookback high-low midrange. Compare close with the spans displaced by the cloud displacement. Conversion, base, and span B use distinct short, medium, and long lookbacks.
Calculation: Pinning regime = variance of the multi-bar log return divided by the horizon times variance of the one-bar log return <= 1 − neutral band AND, when significance is required, its standardized deviation from 1 <= negative significance threshold. Use variance ratio 1 when the one-bar variance is zero; standardize using sqrt(max(epsilon, 2 × (2 × horizon − 1) × (horizon − 1) / (3 × horizon × variance lookback))).
Long: Up score >= down score.
Short: Up score < down score.
Long: Pressure percentile >= candle-pressure threshold AND close > EMA of close.
Short: Pressure percentile >= candle-pressure threshold AND close <= EMA of close.
Long: Compression has just ceased after a compression box was established AND close > the box’s stored upper boundary. Establish the box when the consecutive count of compression above its threshold reaches the box-confirmation count; store the highest high over the box lookback at that bar and retain it until compression ceases.
Short: Compression has just ceased after a compression box was established AND close <= the box’s stored upper boundary.
Long: A chart-timeframe release event is accepted AND up score >= down score AND, if the cloud filter is enabled and the event is not exempt on an expiry session, the number of matching +1 cloud biases across the chart timeframe and three higher timeframes >= agreement threshold AND, if the regime filter is enabled and the event is not exempt on an expiry session, the pinning regime is false. Each higher-timeframe cloud bias uses either the last completed bar or the still-forming bar according to the selected mode.
Short: A chart-timeframe release event is accepted AND up score < down score AND, if the cloud filter is enabled and the event is not exempt on an expiry session, the number of matching −1 cloud biases across the chart timeframe and three higher timeframes >= agreement threshold AND, if the regime filter is enabled and the event is not exempt on an expiry session, the pinning regime is false. Each higher-timeframe cloud bias uses either the last completed bar or the still-forming bar according to the selected mode.
Long: For any enabled higher timeframe, its price-only release event AND up score >= down score changes from false to true on the chart timeframe. Compute all release-event inputs and state on that higher timeframe, using close as the price source; use either its last completed bar or its still-forming bar according to the selected mode.
Short: For any enabled higher timeframe, its price-only release event AND up score < down score changes from false to true on the chart timeframe. Compute all release-event inputs and state on that higher timeframe, using close as the price source; use either its last completed bar or its still-forming bar according to the selected mode.
