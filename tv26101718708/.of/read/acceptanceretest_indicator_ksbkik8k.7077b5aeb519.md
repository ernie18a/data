Calculation: Levels = the high and low of the last completed regular session and the high and low of the current overnight session so far, or of the last completed overnight session when outside it. Calculate session extremes from chart bars. Each level's range is its session high minus its session low. If the two high levels differ by at most close times a clustering percentage, disable the lower high; if the two low levels differ by at most that tolerance, disable the higher low. Equal levels remain enabled.
Calculation: Attempt = maintain separate state for each level, using its current value on each bar. Reset all attempts at the start of a regular session. Process an attempt only while its level exists and is enabled; otherwise preserve its state. An idle level starts a long attempt when previous close <= current level AND close > current level, or a short attempt when previous close >= current level AND close < current level, provided the bar is in a trading window. On subsequent processed bars, cancel the attempt if a long close <= level or a short close >= level. After a configurable number of consecutive processed bars without cancellation, start the watch on that bar, initializing the pull extreme to its low for a long or high for a short, the recovery frontier to its high for a long or low for a short, and the base high, low and bar count to that bar's high, low and one. On each subsequent processed watch bar, check for a trigger using the stored values before updating them. If no trigger occurs, update the long pull extreme and recovery frontier to the current low and high when low is below the stored extreme; otherwise retain the extreme and set the frontier to the greater of its stored value and current high. For a short, use the current high and low when high is above the stored extreme; otherwise retain the extreme and set the frontier to the lesser of its stored value and current low. Expand the base high and low with the current high and low and increment its bar count. Cancel the attempt after a configurable maximum number of processed watch bars without a trigger; check for a trigger before applying this limit. Any trigger ends the attempt, including one that fails the entry filters.
Calculation: Structure trigger = for a long attempt, close > the stored recovery frontier, or close > the stored base high AND stored base bar count >= a configurable minimum AND stored base high minus stored base low <= a configurable multiple of current ATR. For a short attempt, close < the stored recovery frontier, or close < the stored base low AND the same base count and range conditions hold. If both trigger, use the recovery structure.
Calculation: Planned stop = for a recovery-structure trigger, the stored pull extreme minus a configurable percentage of current close for a long, or plus it for a short; for a base trigger, the stored base low minus that buffer for a long, or the stored base high plus it for a short. Risk = absolute difference between current close and planned stop. The risk cap is the greater of the current level's range and a configurable multiple of current ATR, divided by a configurable divisor; if the level range is unavailable, use the ATR multiple alone.
Calculation: Planned target = current level plus its current session range for a long, or minus that range for a short; replace this with the nearest other enabled level strictly between the current level and that projection, if one exists. Reward = absolute difference between planned target and current close. Fix the planned stop and target at entry. Track one active signal; a new valid signal replaces the prior signal, and when several occur on the same bar, process regular-session high, regular-session low, overnight high, then overnight low. Check exits on the entry bar as well. Clear the tracked signal at the start of a regular session after processing that bar.
Long: long attempt is in the watch stage AND close > current level AND long structure trigger AND bar is in a trading window AND risk > 0 AND risk <= risk cap AND reward / risk >= configurable minimum.
Short: short attempt is in the watch stage AND close < current level AND short structure trigger AND bar is in a trading window AND risk > 0 AND risk <= risk cap AND reward / risk >= configurable minimum.
Exit: long, low <= fixed stop OR high >= fixed target OR bar opening time in the configured session time zone >= configured cutoff time.
Exit: short, high >= fixed stop OR low <= fixed target OR bar opening time in the configured session time zone >= configured cutoff time.
