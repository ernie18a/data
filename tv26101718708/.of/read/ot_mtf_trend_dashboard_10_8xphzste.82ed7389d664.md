Calculation: OT trailing stop = recursively updated stop using source price and ATR: while source and prior source are above prior stop, use the greater of prior stop and source minus ATR-scaled loss; while both are below, use the lesser of prior stop and source plus ATR-scaled loss; otherwise set it to source minus loss if source is above prior stop, or source plus loss if below. Source is Heikin Ashi close when that option is enabled, otherwise close.
Calculation: Dashboard Up/Down = on each dashboard timeframe, short EMA above/below long EMA, short EMA rising/falling versus its slope lookback, short/long EMA separation above a minimum threshold, and ADX at or above its trend minimum. Use aggregated bars from timeframes higher or lower than the chart timeframe; use the last completed bar of each timeframe.
Calculation: Dashboard AVG Up/Down = the count of Dashboard Up/Down timeframes differs by at least two in that direction.
Long: source crosses above OT trailing stop AND source is above OT trailing stop AND Supertrend is bullish AND ADX is within its active range OR Dashboard Up OR Dashboard AVG Up
Short: source crosses below OT trailing stop AND source is below OT trailing stop AND Supertrend is bearish AND ADX is within its active range OR Dashboard Down OR Dashboard AVG Down
