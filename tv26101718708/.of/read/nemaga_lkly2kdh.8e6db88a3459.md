Calculation: ALMA-smoothed percentage change = ALMA of the source’s percentage change over its smoothing interval.
Calculation: Gaussian adaptive moving average = EMA of a Gaussian-weighted average of recent ALMA-smoothed percentage-change ranges; each range is the sum of the highest and lowest values from the current value through a progressively longer lookback, divided by two. Gaussian width uses close-price standard deviation when adaptive parameters are enabled, otherwise a fixed width.
Long: ALMA-smoothed percentage change ≥ Gaussian adaptive moving average AND (RSI > prior RSI) AND (Chande Momentum Oscillator > prior value) AND (close > EMA AND EMA > prior EMA) AND (higher-timeframe close > higher-timeframe EMA AND higher-timeframe EMA > its prior value, if higher-timeframe confirmation is enabled) AND prior bar did not satisfy the long filters AND last signal side is not long AND bars since last signal > cooldown interval; evaluate on a completed chart-timeframe bar. Higher-timeframe values use the last completed higher-timeframe bar.
Short: ALMA-smoothed percentage change < Gaussian adaptive moving average AND (RSI < prior RSI) AND (Chande Momentum Oscillator < prior value) AND (close < EMA AND EMA < prior EMA) AND (higher-timeframe close < higher-timeframe EMA AND higher-timeframe EMA < its prior value, if higher-timeframe confirmation is enabled) AND prior bar did not satisfy the short filters AND last signal side is not short AND bars since last signal > cooldown interval; evaluate on a completed chart-timeframe bar. Higher-timeframe values use the last completed higher-timeframe bar.
