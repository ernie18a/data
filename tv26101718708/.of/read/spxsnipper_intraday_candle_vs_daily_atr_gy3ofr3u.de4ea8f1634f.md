Calculation: Candle size = high − low or absolute(close − open), according to the selected measurement mode
Calculation: ATR = Average True Range calculated on a higher timeframe, using either its last completed bar or its still-forming bar according to the selected mode
Long: Candle size >= selected percentage of ATR AND close > open AND (chart bar is closed if close-only mode is enabled)
Short: Candle size >= selected percentage of ATR AND close < open AND (chart bar is closed if close-only mode is enabled)
