Calculation: Active pivot pairs = Confirm chart-timeframe pivot highs and lows using left and right lookbacks. For each confirmed pivot, create a pair unless its primary price is within the same-level percentage threshold of either price of an active pair of the same type. The primary price is the pivot wick; the secondary price is the next bar's low for a pivot low or high for a pivot high. If the two wick prices differ by at most the too-close percentage of the primary price, use the next bar's lower body edge for a pivot low or upper body edge for a pivot high as the secondary price. Process newly confirmed lows before highs. On each bar, evaluate all pairs, then remove pivot-low pairs when close < primary and pivot-high pairs when close > primary. After removal, select the most recently created pair and, excluding it, the pivot-high pair and pivot-low pair whose primary prices are respectively nearest to close.
Calculation: Pending reversal level = For each selected pair, if a pivot-low pair has low < primary AND close > secondary AND close <= open, save its secondary price for the next bar's long decision; if a pivot-high pair has high > primary AND close < secondary AND close >= open, save its secondary price for the next bar's short decision. Process the latest pair, then the nearest pivot-high pair, then the nearest pivot-low pair; later qualifying levels overwrite earlier levels for the same direction. Expire each saved level after the next bar.
Long: For any active pivot-low pair, bar index > pivot bar index AND ((low < primary AND close >= primary) OR (bar index > next bar index AND low < secondary AND close >= secondary)).
Long: For any active pivot-high pair, bar index > pivot bar index AND close > primary.
Long: Close > previous bar's pending long reversal level AND close > open.
Short: For any active pivot-high pair, bar index > pivot bar index AND ((high > primary AND close <= primary) OR (bar index > next bar index AND high > secondary AND close <= secondary)).
Short: For any active pivot-low pair, bar index > pivot bar index AND close < primary.
Short: Close < previous bar's pending short reversal level AND close < open.
