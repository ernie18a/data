Calculation: Source = (open + high + low + close) / 4, or another selectable OHLC-derived price source. Fast and slow baseline = WMA of source, with the slow lookback longer than the fast lookback.
Calculation: Baseline supertrend state = for each base B independently, set raw upper band U = B - ATR × multiplier and raw lower band D = B + ATR × multiplier. Set upper band to max(U, previous upper band) if previous close > previous upper band, otherwise U; set lower band to min(D, previous lower band) if previous close < previous lower band, otherwise D. Initialize each band to its raw value and state to bearish. Set state to bullish if close > previous lower band, otherwise bearish if close < previous upper band, otherwise retain the previous state. The three bases are the fast baseline and the fast baseline multiplied by one plus and one minus the same envelope percentage.
Calculation: Retest = for either baseline and direction, count bars since the most recent close crossover above it for a bullish retest or crossunder below it for a bearish retest; initialize each count to zero and reset it on its respective cross. A retest is eligible when the count is within its baseline-specific minimum and maximum window and no retest of that direction has fired since that count was last reset; only the first qualifying retest fires.
Calculation: RSI = RSI of source on the selected timeframe. For a higher timeframe use the previous completed higher-timeframe bar, mapped with no lookahead; for a lower timeframe use the previous lower-timeframe bar evaluated at the last lower-timeframe bar mapped to the chart bar; for the chart timeframe use the previous chart bar.
Calculation: Active stop = the latest long signal's low multiplied by one minus the stop percentage or the latest short signal's high multiplied by one plus the stop percentage, if the signal-candle anchor is selected; alternatively, entry price multiplied by one minus the stop percentage for a long or one plus it for a short, set when the position opens. Clear the stop when flat without a new signal.
Long: Any baseline supertrend state = bullish.
Short: Any baseline supertrend state = bearish.
Long: Eligible bullish retest of either baseline AND low <= baseline × (1 + that baseline's proximity percentage) AND low >= baseline × (1 - that baseline's penetration percentage) AND close > open AND close > baseline.
Short: Eligible bearish retest of either baseline AND high >= baseline × (1 - that baseline's proximity percentage) AND high <= baseline × (1 + that baseline's penetration percentage) AND close < open AND close < baseline.
Long: (Enabled close crossover above either baseline OR enabled high crossover above either baseline OR enabled bullish retest of either enabled baseline) AND close > SMA of source AND (macro filter disabled OR close > slow baseline) AND (RSI filter disabled OR RSI >= long minimum AND RSI <= long maximum) AND (supertrend filter disabled OR fast-baseline supertrend state = bullish). The execution mode selects baseline crosses, retests, or both; if the price-action module is disabled or both cross-type toggles are disabled, use close crosses.
Short: (Enabled close crossunder below either baseline OR enabled low crossunder below either baseline OR enabled bearish retest of either enabled baseline) AND close < SMA of source AND (macro filter disabled OR close < slow baseline) AND (RSI filter disabled OR RSI >= short minimum AND RSI <= short maximum) AND (supertrend filter disabled OR fast-baseline supertrend state = bearish). The execution mode selects baseline crosses, retests, or both; if the price-action module is disabled or both cross-type toggles are disabled, use close crosses.
Exit: long, short entry condition occurs.
Exit: short, long entry condition occurs.
Exit: long, three-target module selected AND high >= entry price × (1 + target percentage); apply separately to each of three increasing target percentages and its configured partial exit quantity.
Exit: short, three-target module selected AND low <= entry price × (1 - target percentage); apply separately to each of three increasing target percentages and its configured partial exit quantity.
Exit: long, three-target module selected AND low <= (entry price if breakeven is enabled and high has reached the first target since entry, otherwise active stop).
Exit: short, three-target module selected AND high >= (entry price if breakeven is enabled and low has reached the first target since entry, otherwise active stop).
Exit: long, WMA trail module selected AND low <= max(active stop, WMA of low × (1 - trail buffer percentage)); use the WMA value alone if active stop is unavailable.
Exit: short, WMA trail module selected AND high >= min(active stop, WMA of high × (1 + trail buffer percentage)); use the WMA value alone if active stop is unavailable.
Exit: long, candle trail module selected AND low <= max(active stop, highest close since position opened × (1 - candle trail percentage)); use the trailing value alone if active stop is unavailable.
Exit: short, candle trail module selected AND high >= min(active stop, lowest close since position opened × (1 + candle trail percentage)); use the trailing value alone if active stop is unavailable.
Exit: long, all exit modules disabled AND low <= active stop.
Exit: short, all exit modules disabled AND high >= active stop.
