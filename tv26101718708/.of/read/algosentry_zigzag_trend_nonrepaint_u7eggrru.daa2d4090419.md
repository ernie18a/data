Calculation: Tracking price = (open + high + low + close) / 4. Extreme high and low are either tracking price or Heikin-Ashi high and low, respectively. The selected moving average is an SMA or EMA of either close or tracking price.
Calculation: ZigZag state = Initialize pivot and leg extreme to tracking price, their indices to the first bar, direction to zero, and pivot and extreme regular highs and lows to the first bar's high and low. On each bar, set deviation to either a fixed percentage or max(ATR / close × ATR multiplier × 100, a positive minimum). With zero direction, set direction up if the absolute percentage change from pivot to extreme high is at least deviation, otherwise set it down if the corresponding change to extreme low is at least deviation; set the leg extreme, its index and regular high and low to the current bar. For an up leg, replace the extreme and its index and regular high and low whenever extreme high is at least the leg extreme; for a down leg, do so whenever extreme low is at most the leg extreme. A reversal occurs when bars since the pivot index are at least the depth parameter and the absolute percentage change from the nonzero leg extreme to the opposite extreme is at least deviation and that opposite extreme is below the leg extreme for an up leg or above it for a down leg. Evaluate decisions before finalizing a reversal. After decisions, on reversal, save the absolute leg length as the previous closed leg length, replace the pivot and its index and regular high and low with the leg extreme and its saved index and regular high and low, reverse direction, and initialize the new leg extreme to current tracking price and its index and regular high and low to the current bar.
Calculation: Correction state = A correction is active when tracking price is above the moving average and the ZigZag direction is down, or tracking price is below the moving average and the direction is up. A correction starts when this condition is true and was false on the preceding bar; treat it as false on the preceding bar immediately after a ZigZag reversal. On a start, save the pivot as correction start, the leg extreme as correction extreme, and the pivot's regular high and low as correction pivot high and low; reset the start, reversal, touch and armed flags. While active, update correction extreme to the minimum of itself and the leg extreme when tracking price is above the moving average, or the maximum when below. When inactive, clear correction start and extreme and reset the touch flag. Correction depth is 100 × absolute current leg length / previous closed leg length, defined only when the previous closed leg length is positive. Its tier is the highest tier if depth is below the smallest threshold, the middle tier if below the next threshold, the lowest tier if below the largest threshold, and otherwise zero. The selected tier filter accepts the highest tier alone, the highest and middle tiers, or all three nonzero tiers.
Calculation: Directional gate = For long, optionally require both moving average and close above a separate SMA of close, optionally require close above an EMA of close on the last completed higher-timeframe bar using the same length as the selected moving average, and optionally require ADX at or above its threshold. For short, reverse the price comparisons and use the same ADX condition. ADX uses the same length for directional movement and smoothing.
Calculation: Correction events = Evaluate the following in order on every closed chart bar, using the selected signal-mode and tier-filter settings. Start event: correction starts AND correction depth is defined AND tier passes AND the selected mode includes the start event AND the first-three slope rule and directional gate pass. Touch event: correction is active AND a start event has occurred in the current correction, including this bar AND no reversal event has occurred since correction start AND no touch event has occurred since correction start or the most recent reversal event AND low ≤ moving average AND high ≥ moving average AND depth is defined AND tier passes AND the selected mode includes the touch event AND the first-three slope rule and directional gate pass. Reversal event: correction is active AND ZigZag reversal occurs AND depth is defined AND tier passes AND the selected mode includes the reversal event AND the first-three slope rule and directional gate pass. For these three events, the first-three slope rule requires the moving average to rise for long or fall for short, and optionally also requires its absolute percentage change from the preceding bar to be at least the slope threshold. Events can occur on the same bar; a touch sets the touch flag and a reversal then resets it. A start event sets the start flag, a reversal event sets the reversal flag, and either event sets the armed flag. A confirmation event requires the start, reversal and armed flags, including events on the current bar; after a confirmation event reset all four flags. Signal modes and filters also govern the events that arm confirmation.
Calculation: Confirmation break = Select one method: tracking price exceeds the highest tracking price of the preceding lookback bars for long or falls below their lowest for short, with correction active; OR tracking price reaches or exceeds correction extreme plus a selected fraction of the positive difference between correction start and extreme for long, or reaches or falls below correction extreme minus that fraction of the positive difference between extreme and start for short, with correction active; OR tracking price is above the moving average and current high, or optionally close, exceeds correction pivot high for long, or tracking price is below the moving average and current low, or optionally close, falls below correction pivot low for short. The first two methods also require the corresponding tracking-price relation to the moving average.
Long: Start event OR touch event OR reversal event, with moving average rising AND long directional gate passing.
Short: Start event OR touch event OR reversal event, with moving average falling AND short directional gate passing.
Long: Confirmation mode selected AND start flag set AND reversal flag set AND armed flag set AND confirmation break for long AND moving average rising AND absolute moving-average percentage change at least the slope threshold AND long directional gate passing.
Short: Confirmation mode selected AND start flag set AND reversal flag set AND armed flag set AND confirmation break for short AND moving average falling AND absolute moving-average percentage change at least the slope threshold AND short directional gate passing.
