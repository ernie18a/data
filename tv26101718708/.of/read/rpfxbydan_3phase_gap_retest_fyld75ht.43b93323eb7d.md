Calculation: Reference ATR = ATR on the chart timeframe, or optionally ATR on another timeframe; that timeframe may be higher or lower than the chart timeframe and uses the last completed bar available at the chart bar close. For a lower timeframe, use the last completed constituent bar.
Calculation: Cycle = A daily-reset state machine evaluated in the following order on every bar, allowing transitions to later stages on the same bar. Start idle. When the highest high minus lowest low over the consolidation lookback is less than a multiple of reference ATR, enter consolidation and set its bounds to those extrema. In consolidation, compare low and high with the stored lower bound minus an ATR multiple and upper bound plus the same ATR multiple. If neither is breached, extend both bounds to include the current bar. If both are breached, reset to idle. If exactly one is breached, accept a lower sweep when (close - low) / max(high - low, minimum price denominator) is at least the wick threshold, or accept an upper sweep when (high - close) / max(high - low, minimum price denominator) is at least the wick threshold; optionally also require volume > its moving average. Otherwise extend both bounds to include the bar. An accepted lower sweep sets the cycle direction long; an accepted upper sweep sets it short. Record the sweep bar and enter the structure stage. Set the structure level to the consolidation upper bound for a long cycle and lower bound for a short cycle in strict mode, their midpoint in midpoint mode, or the lower bound for a long cycle and upper bound for a short cycle in basic mode. In the structure stage, a long structure break is close > structure level and a short structure break is close < structure level; record the break bar and enter the gap stage. After checking for a break, reset to idle if bars since the sweep exceed the structure timeout, even if a break occurred on that bar. In the gap stage, starting at least one bar after the break, accept a directional gap and enter the retest stage. Check for a gap before resetting to idle when bars since the break exceed the gap timeout, so a qualifying gap on the first bar beyond the timeout is accepted. In the retest stage, compute elapsed bars since the stored gap bar before checking for a wider directional gap. If a wider directional gap occurs, replace the zone and gap bar and clear the touched flag, but use the previously computed elapsed count for the current bar's signal and timeout checks. In break mode, set the touched flag when a long cycle has low <= zone top or a short cycle has high >= zone bottom, including on the signal bar. After checking signals, reset to idle if the pre-upgrade elapsed count exceeds the retest timeout. Reset to idle after an entry signal. Reset the entire cycle at each new day before processing that bar.
Calculation: Directional gap = For a long cycle, gap size is low - high two bars ago, zone bottom is that earlier high, and zone top is current low. For a short cycle, gap size is low two bars ago - high, zone bottom is current high, and zone top is that earlier low. Require gap size >= a multiple of reference ATR. Optionally require the current or previous bar to close in the cycle direction and have absolute close - open divided by max(high - low, minimum price denominator) >= the displacement threshold. A replacement gap must additionally be wider than the current zone.
Calculation: Directional filter = For long, optionally require the last completed higher-timeframe close > each of three higher-timeframe EMAs with short, intermediate, and long lengths, and optionally require chart close > session VWAP and zone bottom > session VWAP. For short, use close < each EMA, chart close < session VWAP, and zone top < session VWAP. Evaluate each enabled filter on the signal bar.
Long: Accepted lower sweep.
Short: Accepted upper sweep.
Long: Long structure break.
Short: Short structure break.
Long: A long directional gap is accepted or replaces the existing zone.
Short: A short directional gap is accepted or replaces the existing zone.
Long: Retest stage AND long cycle AND pre-upgrade elapsed bars >= one bar AND <= retest timeout AND directional filter passes AND ((touch mode AND previous close >= zone bottom AND low <= zone top AND close >= zone bottom) OR (break mode AND touched flag is set AND close > zone top)).
Short: Retest stage AND short cycle AND pre-upgrade elapsed bars >= one bar AND <= retest timeout AND directional filter passes AND ((touch mode AND previous close <= zone top AND high >= zone bottom AND close <= zone top) OR (break mode AND touched flag is set AND close < zone bottom)).
