Calculation: Valid-bar features = RSI of close; ATR divided by close; CCI of close; volume divided by its SMA, defaulting to 1 if unavailable; close divided by its SMA; percentage change in close over a lookback, defaulting to 0 before enough bars exist; Bollinger Band width divided by its SMA basis, defaulting to 0 if the basis is not positive; and ADX. Retain a bar only when RSI, ATR/close, CCI, close/SMA, Bollinger Band width, and ADX are available.
Calculation: Predicted return at a horizon = the corresponding output of a seeded multi-output random forest regressor trained from scratch on a rolling window of retained bars ending before the forecast-horizon buffer. Each training row contains that bar's features and, for each horizon through the maximum, the percentage change from its close to the close that many retained bars later. Use bootstrap samples, CART mean-squared-error splits, random candidate thresholds, feature subsampling, a maximum tree depth, and a minimum leaf size; predict from the latest retained bar's features and average tree outputs. Require the retained-bar count to be at least the training-window length plus the maximum horizon plus a history buffer.
Long: Predicted return at the maximum horizon >= 0 OR predicted return at an available diagnostic horizon >= 0.
Short: Predicted return at the maximum horizon < 0 OR predicted return at an available diagnostic horizon < 0.
Calculation: Diagnostic horizons = three increasing fixed forecast horizons; each is available only when it does not exceed the maximum forecast horizon.
