Calculation: Outside sweep = current high > previous high AND current low < previous low AND current open >= previous low AND current open <= previous high AND current close >= previous low AND current close <= previous high.
Calculation: Previous candle is bullish = previous close > previous open OR (previous close = previous open AND previous high - previous open < previous open - previous low).
Calculation: CHoCH flags = for each current higher-timeframe candle, reset both flags and the stored swing high and low. On each chart bar, sample the close and newly confirmed symmetric pivot highs and lows from the configured CHoCH timeframe, which is lower than the higher timeframe. If it is lower than the chart timeframe, sample its last completed intrabar; if it is higher than the chart timeframe, use its last completed bar historically and its still-forming bar in real time; if equal, use the chart bar. A pivot uses the same lookback on each side. Replace each stored swing with the latest sampled confirmed pivot of that kind. Set the bearish flag when the sampled close < stored swing low AND stored swing low >= current midpoint AND stored swing low <= current high. Set the bullish flag when the sampled close > stored swing high AND stored swing high >= current low AND stored swing high <= current midpoint. Keep each flag set until the next higher-timeframe candle. Current midpoint = (current high + current low) / 2.
