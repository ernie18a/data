Calculation: Period state = Use a higher timeframe and the last completed higher-timeframe bar for its prior high, low, open, and close. Activate on the first chart bar of each new higher-timeframe period; ignore the initial partial period. At activation, classify the prior bar as up if its close >= its open, otherwise down. Classify the gap using the first chart bar's open minus the prior close: up if greater than the minimum gap parameter times safe chart-timeframe ATR, down if less than the negative of that amount, otherwise no gap. Safe ATR is the maximum of chart-timeframe ATR and a small positive floor; if ATR is unavailable, use true range, or the chart close times a small positive fallback factor if true range is unavailable. Fix these classifications for the period. For an up gap, mark it filled once any chart bar in the period has low <= prior close; for a down gap, mark it filled once any chart bar has high >= prior close. Include the current completed chart bar before evaluating signals.
Calculation: Posterior counts = Maintain separate alpha and beta counts for prior-high taps and prior-low taps by prior-bar direction, and gap fills by gap direction. Initialize every count to the same prior-strength parameter. At the first completed chart bar of each new period, before evaluating its signal, update the buckets corresponding to the preceding active period: a high tap succeeds if that period's high >= its prior high; a low tap succeeds if its low <= its prior low; a gap fill succeeds if its gap was filled. Update the gap bucket only if there was a qualifying gap. For each updated bucket, set alpha = prior strength + decay × (previous alpha − prior strength) + success indicator and beta = prior strength + decay × (previous beta − prior strength) + failure indicator. Leave other buckets unchanged.
Calculation: Gap-fill probability = alpha / (alpha + beta) for the current period's gap-direction bucket, after updating the preceding period.
Calculation: Observation measure = (alpha + beta − 2 × prior strength) for the down-prior-bar high-tap bucket plus the same quantity for both prior-bar-direction low-tap buckets.
Long: On a completed chart bar, period is active AND gap direction = down AND gap is unfilled through the current bar AND observation measure >= minimum observations parameter AND gap-fill probability > probability threshold parameter AND number of earlier long or short signals in the current period = 0.
Short: On a completed chart bar, period is active AND gap direction = up AND gap is unfilled through the current bar AND observation measure >= minimum observations parameter AND gap-fill probability > probability threshold parameter AND number of earlier long or short signals in the current period = 0.
