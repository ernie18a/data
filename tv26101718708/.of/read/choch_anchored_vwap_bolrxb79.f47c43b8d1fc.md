Calculation: Pivot high / pivot low (length n) = a bar whose high (low) is the highest (lowest) among the n bars before and the n bars after it. It is confirmed only after n further bars have closed. Latest pivot high / latest pivot low = most recent confirmed one.
Calculation: Break up (n) = close crosses above the latest pivot high (previous close <= level AND current close > level) AND that pivot-high level has not been broken before. Break down (n) = close crosses below the latest pivot low (previous close >= level AND current close < level) AND that pivot-low level has not been broken before. A broken level is marked as used and can never trigger again.
Calculation: Bias (n) = state per pivot length, initially 0. It is set to +1 on every Break up (n) and to -1 on every Break down (n). It is evaluated for each bar using its value before the current bar's break.
Long: for ANY of several pivot lengths n, each evaluated independently with its own pivots, broken levels and bias, with lengths ranging from short-term to long-term: Break up (n) on the current bar AND Bias (n) before this bar = -1.
Short: for ANY of several pivot lengths n, each evaluated independently: Break down (n) on the current bar AND Bias (n) before this bar = +1.
