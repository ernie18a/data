Calculation: Setup bars = higher-timeframe bars; use the last completed bar on historical chart bars and the still-forming bar in real time. Carry requested setup-bar values forward between updates.
Calculation: Opening range = highest high and lowest low of setup bars in a configurable daily session and timezone; reset all sweep, confirmation, gap and setup-entry state at the start of each session. The range is available after the session ends.
Calculation: High sweep = setup-bar high > opening-range high AND close < opening-range high. Low sweep = setup-bar low < opening-range low AND close > opening-range low. Retain whether each side has been swept since the session began. On a low sweep after an earlier high sweep, set the candidate direction to long and record the current setup bar; on a high sweep after an earlier low sweep, set it to short and record the current setup bar. If both updates occur on the same bar, the short update takes precedence. Update the retained sweep flags after these checks.
Calculation: Delta = volume × ((close − low) − (high − close)) / (high − low); use zero when high equals low. Strong positive delta = delta > 0 AND absolute delta >= a configurable multiple of the simple moving average of absolute delta. Strong negative delta = delta < 0 AND absolute delta >= that multiple. Calculate these separately on setup and chart bars with independently configurable parameters.
Calculation: Long confirmation = candidate direction = long AND setup bars since the recorded second sweep <= a configurable window AND close > open AND absolute candle body >= a configurable multiple of ATR AND absolute candle body / candle range >= a configurable minimum AND close > the highest high of the preceding configurable number of setup bars AND setup-bar delta is strongly positive. Short confirmation reverses the candle direction, structure comparison and delta sign, using the lowest low. A zero-range candle cannot confirm. Each confirmation creates a new setup and resets its selected gap and setup-bar entry state; subsequent confirmations replace the existing setup.
Calculation: Primary gap = for a long setup, among setup bars from the confirmation bar through a configurable scan length after it, select the gap with the lowest midpoint where current low > high two setup bars earlier AND the difference >= a configurable multiple of current ATR; its bottom is that earlier high and its top is current low. For a short setup, select the gap with the highest midpoint where current high < low two setup bars earlier AND the difference >= the configurable multiple of current ATR; its bottom is current high and its top is that earlier low. Include the final scan bar before locking the gap; if no gap exists, keep checking for a candidate on later bars but do not scan for new gaps. The locked gap persists until the next confirmation or session reset.
Calculation: Gap retest = gap is locked AND bar low <= gap top AND bar high >= gap bottom. Gap midpoint = (gap top + gap bottom) / 2.
Long: High sweep changes from false to true on the chart = false AND low sweep changes from false to true on the chart = true.
Short: High sweep changes from false to true on the chart = true.
Long: Long confirmation changes from false to true on the chart = true.
Short: Short confirmation changes from false to true on the chart = true.
Long: Current setup direction = long AND chart-bar gap retest = true AND chart close > gap midpoint AND chart close > chart open AND chart-bar delta is strongly positive AND no prior chart-bar long entry has occurred for this setup.
Short: Current setup direction = short AND chart-bar gap retest = true AND chart close < gap midpoint AND chart close < chart open AND chart-bar delta is strongly negative AND no prior chart-bar short entry has occurred for this setup.
Long: Current setup direction = long AND setup-bar gap retest = true AND setup close > gap midpoint AND setup close > setup open AND setup-bar delta is strongly positive AND no prior setup-bar entry has occurred for this setup AND this setup-bar entry condition changes from false to true on the chart.
Short: Current setup direction = short AND setup-bar gap retest = true AND setup close < gap midpoint AND setup close < setup open AND setup-bar delta is strongly negative AND no prior setup-bar entry has occurred for this setup AND this setup-bar entry condition changes from false to true on the chart.
