Calculation: Standard RSI = RSI of close, optionally smoothed with a selected moving average.
Calculation: Enhanced RSI = When KNN is disabled, standard RSI. Otherwise, form a feature vector from standard RSI and, optionally in order, its momentum, its standard deviation, its linear-regression slope, and close momentum. Normalize each feature at its own bar over the KNN lookback as (value - rolling minimum) / (rolling maximum - rolling minimum), or the midpoint of the normalized range when the range is zero. Compare the current vector by Euclidean distance with vectors at preceding offsets through the KNN lookback, excluding offsets greater than or equal to the current bar index. If there are at least two distances, sort ascending, retaining the more recent offset first on ties, and select up to the requested number of nearest neighbors. For each selected offset, use standard RSI at one bar more recent than that offset, weighted by inverse distance, except use unit weight for a distance below a small cutoff. Exclude neighbors with unavailable RSI from the weighted average. If the total weight is positive, blend that average with current standard RSI using the KNN weight and clamp the result to the RSI range; otherwise use standard RSI.
Calculation: Final RSI = Enhanced RSI, optionally filtered by one selected method: recursive filter initialized to enhanced RSI and updated as previous filtered value plus filter strength times the difference between enhanced RSI and previous filtered value; two successive EMAs with separately scaled lengths derived from filter strength; or ALMA with length derived from filter strength and its own offset and sigma.
Long: Final RSI > RSI midpoint.
Short: Final RSI <= RSI midpoint.
Long: Final RSI > overbought threshold AND impulse mode is selected.
Short: Final RSI < oversold threshold AND impulse mode is selected.
