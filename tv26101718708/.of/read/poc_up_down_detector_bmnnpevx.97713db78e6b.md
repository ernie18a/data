Calculation: Profile POC = At each calendar-day change, or session start when session filtering is enabled, finalize the preceding profile and clear it. Accumulate completed lower-timeframe OHLCV bars within each chart bar, including only bars inside the configured session when filtering is enabled; if no lower-timeframe bars are available, use the chart bar when allowed by the session filter. Include only bars with positive volume. Divide the profile's lowest low to highest high into equal price bins. Allocate each bar's volume using the selected method: all to the close bin; all to the HLC3 bin; uniformly across its low-high range; or uniformly across each wick and body segment with body volume weighted by a configurable multiplier relative to wick volume. Clamp bin indices to the profile range. Select the bin with greatest allocated volume; for volumes equal within max(greatest volume × 0.000001, 0.0000001), prefer the midpoint closest to the profile's close-volume-weighted average, retaining the earlier bin if distances tie. Round the selected midpoint to the configured price increment. A profile with no positive volume or no price range has no POC. Retain the two most recent valid completed profile POCs; an invalid profile does not replace them.
Calculation: Market state = Initialize neutral, with no neutral reference, previous direction 0 and previous trend 0. Update only when a valid profile POC is finalized and two valid POCs exist. Let direction be 1, -1 or 0 according to whether the latest completed POC is greater than, less than or equal to the preceding completed POC. In bullish state, remain bullish if direction is 1; otherwise become neutral, store the latest POC as the neutral reference, store previous trend as bullish and reset range direction and count to 0. In bearish state, remain bearish if direction is -1; otherwise become neutral, store the latest POC as the neutral reference, store previous trend as bearish and reset range direction and count to 0. In neutral state without a reference, become bullish if direction and previous direction are both 1, or bearish if both are -1. In neutral state with a reference, become bullish and clear the reference if direction is 1 and the latest POC is above the reference; if direction is -1 and the latest POC is below the reference, become bearish and clear the reference when previous trend is bullish, otherwise become ranging with range direction -1 and count 1. In ranging state, if direction is nonzero and equals range direction, increment the count and, when it reaches 2, become bullish for direction 1 or bearish for direction -1, clear the reference and reset range direction and count to 0; otherwise set range count to 1 and range direction to direction. After each update, set previous direction to direction.
Calculation: Daily average volume = Sum of chart-bar volume since the current calendar day began, including the current bar, divided by the number of those bars.
Calculation: Initial long signal = Market state is bullish AND at least one chart-bar low since the current calendar day began, including the current bar, was below the latest completed profile POC in effect on that bar AND current close is above the latest completed profile POC AND at least 3 chart bars have occurred today AND daily average volume is positive AND current volume is greater than daily average volume multiplied by a configurable factor AND no earlier initial long signal occurred today.
Calculation: Initial short signal = Market state is bearish AND at least one chart-bar high since the current calendar day began, including the current bar, was above the latest completed profile POC in effect on that bar AND current close is below the latest completed profile POC AND at least 3 chart bars have occurred today AND daily average volume is positive AND current volume is greater than daily average volume multiplied by a configurable factor AND no earlier initial short signal occurred today.
Long: A valid profile POC is finalized AND market state is bullish.
Long: Market state is bullish AND at least one chart-bar low since the current calendar day began, including the current bar, was below the latest completed profile POC in effect on that bar AND close is above the latest completed profile POC AND at least 3 chart bars have occurred today AND daily average volume is positive AND volume is greater than daily average volume multiplied by a configurable factor.
Long: An initial long signal occurred earlier today AND no strong long signal has occurred since it AND open is below close AND close is above the latest completed profile POC.
Short: A valid profile POC is finalized AND market state is bearish.
Short: Market state is bearish AND at least one chart-bar high since the current calendar day began, including the current bar, was above the latest completed profile POC in effect on that bar AND close is below the latest completed profile POC AND at least 3 chart bars have occurred today AND daily average volume is positive AND volume is greater than daily average volume multiplied by a configurable factor.
Short: An initial short signal occurred earlier today AND no strong short signal has occurred since it AND open is above close AND close is below the latest completed profile POC.
