Calculation: PressureAtom = (((close-low)/range-0.5)*2*0.42 + ((close-open)/range)*0.42 + wickBalance*0.16) * volume, where range = high-low (floored at a tiny positive value) and wickBalance = ((min(open,close)-low) - (high-max(open,close)))/range
Calculation: Tensor = short-lookback EMA of (PressureAtom / medium-lookback EMA of |PressureAtom|), taking 0 if the denominator is about 0; the smoothing lookback is shorter than the medium lookback
Calculation: Velocity = Tensor - previous Tensor; Curvature = Velocity - previous Velocity; Jerk = Curvature - previous Curvature
Calculation: StressRank = percentile rank (0-100, 50 if unavailable) of ATR/close*100 over a long lookback; RangeRank = percentile rank of (high-low)/close*100 over the same long lookback; the long lookback is longer than the entropy lookback, which is longer than the medium lookback
Calculation: Entropy% = 100 * (-(u*ln(u) + d*ln(d)))/ln(2), where u = sum(max(PressureAtom,0)) / sum(|PressureAtom|) over the entropy lookback (0.5 if the denominator is 0), d = 1-u, and a term with zero share counts as 0; Certainty = 100 - Entropy%
Calculation: Impulse = clamp(|Tensor|*34 + RangeRank*0.25 + Certainty*0.35, 0, 100); Convexity = clamp(|Curvature|*55 + |Jerk|*25, 0, 100); StressComposite = clamp(StressRank*0.38 + Impulse*0.34 + Convexity*0.28, 0, 100)
Calculation: Basis = EMA(close, medium lookback, same as the Tensor normalization lookback); Skew = EMA(Tensor, same medium lookback); Width = ATR*(0.85 + StressComposite/90); UpperBand = Basis + Width*(1 + max(Skew,0)*0.12); LowerBand = Basis - Width*(1 + max(-Skew,0)*0.12)
Long: on a completed bar, (Tensor > 0 AND Curvature > 0 AND StressComposite >= shock threshold) OR (close < LowerBand AND Curvature > 0 AND StressComposite >= reversion threshold); the reversion threshold is lower than the shock threshold
Short: on a completed bar, (Tensor < 0 AND Curvature < 0 AND StressComposite >= shock threshold) OR (close > UpperBand AND Curvature < 0 AND StressComposite >= reversion threshold)
