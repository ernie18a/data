Calculation: Session high and low = highest high and lowest low of chart bars in the specified reference session since the latest exchange-day boundary; reset both at each exchange-day boundary.
Calculation: Bullish structure formed = at least one chart bar since the latest exchange-day boundary was in the structure window and closed above both the session high and the EMA; reset at each exchange-day boundary after evaluating the bar.
Calculation: Bearish structure formed = at least one chart bar since the latest exchange-day boundary was in the structure window and closed below both the session low and the EMA; reset at each exchange-day boundary after evaluating the bar.
Calculation: EMA = exponential moving average of close on the selected timeframe; when higher than the chart timeframe, use the last completed bar on historical data and the still-forming bar in real time; when lower, use the last available lower-timeframe bar within the chart bar.
Calculation: Average daily range = simple moving average of high minus low over the preceding completed higher-timeframe daily bars.
Calculation: Daily upper threshold = current higher-timeframe daily low plus a fraction of average daily range if the current daily range is smaller than that amount or the daily close is at least the daily open; otherwise the current daily high. Use the final values of the current daily bar on historical data and its still-forming values in real time.
Calculation: Daily lower threshold = current higher-timeframe daily high minus the same fraction of average daily range if the current daily range is smaller than that amount or the daily close is below the daily open; otherwise the current daily low. Use the final values of the current daily bar on historical data and its still-forming values in real time.
Long: Bullish structure formed = true AND current bar is in the entry window AND low <= EMA AND (ADR filter disabled OR high < daily upper threshold).
Short: Bearish structure formed = true AND current bar is in the entry window AND high >= EMA AND (ADR filter disabled OR low > daily lower threshold).
Exit: long first portion, high >= entry price + first profit distance OR low <= entry price - stop distance.
Exit: long second portion, high >= entry price + second profit distance OR low <= entry price - stop distance when break-even is disabled or the first profit level has not been reached since entry OR low <= entry price when break-even is enabled and the first profit level has been reached since entry.
Exit: short first portion, low <= entry price - first profit distance OR high >= entry price + stop distance.
Exit: short second portion, low <= entry price - second profit distance OR high >= entry price + stop distance when break-even is disabled or the first profit level has not been reached since entry OR high >= entry price when break-even is enabled and the first profit level has been reached since entry.
