Calculation: Hull midpoint = WMA(2 × WMA(close, floor(Hull length / 2)) − WMA(close, Hull length), floor(sqrt(Hull length))); use close when the result is unavailable.
Calculation: Cloud width = ATR × cloud-width multiplier; upper cloud = Hull midpoint + cloud width; lower cloud = Hull midpoint − cloud width.
Calculation: Custom ADX = RMA(DX, ADX length), where upward movement = high − previous high, downward movement = previous low − low, positive directional movement = max(upward movement, 0) if upward movement > downward movement else 0, negative directional movement = max(downward movement, 0) if downward movement > upward movement else 0, positive and negative DI = 100 × RMA(the respective directional movement, ADX length) / RMA(true range, ADX length), and DX = 100 × abs(positive DI − negative DI) / (positive DI + negative DI); use 0 for division by zero or an unavailable denominator.
Calculation: Retest score = floor(min(proximity score + volume score + RSI score + ADX score, 100)). For a long retest, depth = max(upper cloud − low, 0) and RSI score = min(max(55 − RSI, 0) × 0.5, 15). For a short retest, depth = max(high − lower cloud, 0) and RSI score = min(max(RSI − 45, 0) × 0.5, 15). Proximity score = min(50 × depth / cloud width, 50), using 0 if cloud width is zero or unavailable; volume score = min(15 × volume / max(volume SMA, 1), 25), using 0 if the denominator is unavailable; ADX score = min(custom ADX × 0.4, 10).

Short: Bar index >= max(3 × Hull length, 50) AND high >= lower cloud AND close < Hull midpoint AND close < open AND EMA of close with half the Hull length < EMA of close with the Hull length AND short retest score >= minimum score.
