Calculation: Smoothed source = choose previous chart-bar close, its SMA, EMA, RMA, HMA, two successive same-length WMAs, three successive same-length VWMAs using current-bar volume at each pass, a slope-adjusted average, or a recursive estimator. The slope-adjusted average is SMA(source, length) + (source - source[length]) / 2. The recursive estimator initializes estimate to source and error to 1; on each bar set predicted error = error + 1 / length, gain = predicted error / (predicted error + 1), estimate = estimate + gain * (source - estimate), and error = (1 - gain) * predicted error.
Calculation: Channel = initialize anchor at bar index 1. On each bar, let channel length be current bar index - anchor + 1; fit ordinary least squares to the most recent channel-length smoothed-source values, capped at the available maximum regression lookback, with index 0 at the current value and increasing into the past. The current endpoint is the fitted value at index 0; residual deviation is the square root of residual sum of squares divided by fitted sample count minus 1; fit is the Pearson correlation of source and fitted values, or zero if either has zero variance. Upper and lower bands are the endpoint plus and minus a deviation multiplier times residual deviation. After evaluating the current bar's decisions, reset the anchor on each new valid upper or lower breakout, regardless of the ADX filter: choose the latest strictly confirmed pivot low for an upper breakout or pivot high for a lower breakout, using previous-bar highs or lows and equal numbers of bars on both sides; accept it only if it is later than the anchor and earlier than the current bar and a channel fitted from that pivot has absolute fit at least the fit threshold; otherwise choose the current bar. If merging is enabled and the pivot is accepted, retain the old anchor when the nonnegative gap between the old and candidate channel bands at the candidate pivot is at most a tolerance multiplier times the old channel's residual deviation; otherwise use the chosen anchor.
Calculation: Valid upper breakout = previous chart-bar close > current upper band AND current channel length >= minimum length AND absolute current fit >= fit threshold.
Calculation: Valid lower breakout = previous chart-bar close < current lower band AND current channel length >= minimum length AND absolute current fit >= fit threshold.
Calculation: Previous upper breakout = close two chart bars ago > previous bar's upper band AND previous bar index - current anchor + 1 >= minimum length AND absolute previous bar's fit >= fit threshold. Previous lower breakout uses the same tests with close below the previous lower band.
Long: Current channel regression slope with time increasing into the past < 0 AND absolute current fit >= fit threshold.
Short: Current channel regression slope with time increasing into the past >= 0 AND absolute current fit >= fit threshold.
Long: Valid upper breakout.
Short: Valid lower breakout.
Long: Valid upper breakout AND previous upper breakout = false AND (ADX filter disabled OR current ADX >= ADX threshold).
Short: Valid lower breakout AND previous lower breakout = false AND (ADX filter disabled OR current ADX >= ADX threshold).
Exit: long, valid lower breakout AND previous lower breakout = false AND (ADX filter disabled OR current ADX >= ADX threshold).
Exit: short, valid upper breakout AND previous upper breakout = false AND (ADX filter disabled OR current ADX >= ADX threshold).
