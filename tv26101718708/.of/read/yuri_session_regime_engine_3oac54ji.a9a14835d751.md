Calculation: VWAP = session-anchored cumulative sum(volume*(high+low+close)/3) / cumulative sum(volume), regular-session bars only, reset at each session start
Calculation: OR high/low = highest high / lowest low of the first opening-range duration of the session; OR is set only once the session has run longer than that duration; OR width = OR high - OR low
Calculation: DayOpen = open of the first session bar; Gap% = (DayOpen - previous day close) / previous day close * 100
Calculation: UpVotes = count of true among: (1) close > VWAP; (2) VWAP now > VWAP one slope-lookback ago; (3) OR is set AND close > OR high; (4) close of a timeframe higher than the chart timeframe (bar still forming) > SMA of that timeframe's closes (vote is 0 if that timeframe is not higher than the chart timeframe); (5) close > previous day high
Calculation: DownVotes = count of true among the mirrored conditions: close < VWAP; VWAP now < VWAP one slope-lookback ago; OR is set AND close < OR low; higher-timeframe close < its SMA (same validity rule); close < previous day low
Calculation: Candidate = first matching rule: OR not set -> OPENING; UpVotes >= vote threshold -> TREND UP; DownVotes >= vote threshold -> TREND DOWN; Gap% >= large-gap threshold AND close < DayOpen -> GAP FILL DOWN; Gap% <= -large-gap threshold AND close > DayOpen -> GAP FILL UP; time since session open >= range-call duration (longer than the OR duration) AND close <= OR high + 0.25*OR width AND close >= OR low - 0.25*OR width -> RANGE; Active = OPENING -> MIXED; otherwise Candidate = Active
Calculation: Active = starts as OPENING each session; evaluated on session bars only: if Candidate = Active the hold counter = 0; else if Candidate = previous bar's Candidate the counter += 1; else the counter = 1; when counter >= hold duration (converted to bars), Active = Candidate and counter = 0; Active is unchanged outside the session
Long: Active = TREND UP OR Active = GAP FILL UP
Short: Active = TREND DOWN OR Active = GAP FILL DOWN
