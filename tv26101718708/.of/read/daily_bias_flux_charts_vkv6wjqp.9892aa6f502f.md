Calculation: Liquidity levels = The highs and lows of the last completed bars of three successively longer higher timeframes, and the highs and lows of the most recently completed instance of each of three sequential, non-overlapping intraday sessions. Session windows and timezone are parameters. Only enabled sources have levels. Use the levels stored at the end of the preceding chart bar; update completed bars and sessions after evaluating the current chart bar.
Calculation: Previous session profile = During an active session, select the immediately preceding session in the fixed session sequence. Compare its last completed high, low, and close on every chart bar with the currently stored levels of the three higher timeframes and the other two sessions. A high sweep means its high is above at least one available high level; a low sweep means its low is below at least one available low level. If both occur, the profile is complex; if neither occurs, it is consolidation. For a low sweep alone, the direction is bullish and the profile is reversal if the session close is above the lowest swept low level, otherwise manipulation. For a high sweep alone, the direction is bearish and the profile is reversal if the session close is below the highest swept high level, otherwise manipulation. Missing comparisons are false.
Calculation: Remembered event = For each enabled liquidity source, clear its stored event when a new source timeframe begins or a new completed session high is recorded. On each chart bar, assign the first applicable event in this priority order: bullish reversal if low < source low AND close > source low; bearish reversal if high > source high AND close < source high; neutral low sweep if low < source low AND previous chart bar low >= current source low; neutral high sweep if high > source high AND previous chart bar high <= current source high. Otherwise retain the stored event. When a source's event changes, assign it a new sequence number; process sources in increasing higher-timeframe length followed by the three sessions in their fixed sequence. The remembered event is the nonempty stored event with the latest sequence number, including events recorded outside the active session.
Calculation: Bullish structure = Chart close > the last completed high of either of two lower timeframes, one shorter than the other.
Calculation: Bearish structure = Chart close < the last completed low of either of the same two lower timeframes.
Long: Chart low < any enabled liquidity low AND previous chart bar low >= that same current liquidity low
Short: Chart high > any enabled liquidity high AND previous chart bar high <= that same current liquidity high
Long: An active session exists AND previous session profile = reversal AND previous session direction = bullish
Short: An active session exists AND previous session profile = reversal AND previous session direction = bearish
Long: Remembered event = bullish reversal
Short: Remembered event = bearish reversal
Long: Structure confirmation is enabled AND bullish structure = true
Short: Structure confirmation is enabled AND bullish structure = false AND bearish structure = true
Long: An active session exists AND (structure confirmation is disabled OR bullish structure = true) AND ((previous session profile = consolidation AND remembered event = bullish reversal) OR (previous session profile = manipulation AND previous session direction = bullish AND remembered event = bullish reversal) OR (previous session profile = reversal AND previous session direction = bullish))
Short: An active session exists AND (structure confirmation is disabled OR bearish structure = true) AND ((previous session profile = consolidation AND remembered event = bearish reversal) OR (previous session profile = manipulation AND previous session direction = bearish AND remembered event = bearish reversal) OR (previous session profile = reversal AND previous session direction = bearish))
