Calculation: True day open = open of the lower-timeframe bar at the start of the day’s second quarter, using that bar while it is forming
Calculation: True week open = open of the lower-timeframe bar at the start of the week’s second quarter, using that bar while it is forming
Calculation: True month open = open of the lower-timeframe bar at the start of the month’s second quarter, using that bar while it is forming
Long: close >= True day open AND close >= True week open AND close >= True month open
Short: close < True day open AND close < True week open AND close < True month open
