Calculation: Order blocks = Maintain independent bullish and bearish blocks for each selected higher, lower, or chart timeframe. Evaluate other-timeframe calculations on the last completed bar; for a lower timeframe, use the last intrabar returned within each chart bar. On each source bar, calculate the percentage change in open over a lookback. A bullish candidate occurs when this change crosses above a positive threshold; a bearish candidate occurs when it crosses below the corresponding negative threshold. For each direction separately, accept a candidate for processing only if its source-bar distance from the previous processed candidate exceeds a minimum spacing; update the previous processed candidate even if no block is created. Search a bounded range of earlier source bars, starting with the most recent, for the first bearish candle for a bullish block or bullish candle for a bearish block. Use that candle's high and low as the block top and bottom. Create the block only if, from the bar after that candle through the candidate bar, the lowest low or lowest close, respectively, is not below the bullish block bottom, or the highest high or highest close, respectively, is not above the bearish block top. Use wick or close consistently as the selected mitigation mode. Publish a block only when its source-candle identifier differs from the last published identifier for that direction and timeframe. Keep a limited number of active blocks per direction and timeframe, removing the oldest when the limit is exceeded. On each chart bar after adding new blocks, remove a bullish block if the current low in wick mode or previous chart close in close mode is below its top minus a penetration fraction of its height; remove a bearish block if the current high in wick mode or previous chart close in close mode is above its bottom plus that fraction of its height.
Long: A new bullish order block is published OR the chart low is below the top of an active bullish order block after mitigation.
Short: A new bearish order block is published OR the chart high is above the bottom of an active bearish order block after mitigation.
