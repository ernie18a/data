Calculation: Source = selected open, high, low, close, (open + high + low + close) / 4, (high + low + close) / 3, or (high + low) / 2.
Calculation: Moving average = independently selected SMA, EMA, WMA, VWMA, RMA, Hull moving average, or TEMA of Source, with independently selected lengths; no length ordering is required.
Calculation: MACD = shorter-length moving average of Source minus longer-length moving average of Source, using either SMA or EMA for both; signal = SMA or EMA of MACD; histogram = MACD minus signal.
Calculation: Higher-timeframe values = moving averages, close, RSI, and MACD calculated on their respective selected higher timeframes using the current bar still forming; historical lookahead uses the final value of that higher-timeframe bar throughout the bar.
Calculation: RSI filter = chart-timeframe RSI > selected lower threshold AND chart-timeframe RSI <= selected upper threshold AND higher-timeframe RSI > its selected lower threshold AND higher-timeframe RSI <= its selected upper threshold. The same thresholds apply to both directions.
Calculation: Buy condition = datetime >= selected start AND datetime <= selected end AND RSI filter AND one selected primary condition (first moving average > second moving average OR Source > first moving average OR RSI filter OR MACD > signal OR MACD > 0 OR signal > 0) AND one selected chart-timeframe filter (no filter OR MACD > signal OR MACD > 0 OR signal > 0 OR previous histogram < 0 AND histogram > previous histogram) AND one selected higher-timeframe filter (no filter OR MACD > signal OR MACD > 0 OR signal > 0 OR first moving average > second moving average OR close > first moving average).
Calculation: Sell condition = NOT Buy condition OR (datetime >= selected start AND datetime <= selected end AND RSI filter AND one selected primary condition (third moving average <= fourth moving average OR Source <= third moving average OR RSI filter OR MACD <= signal OR MACD <= 0 OR signal <= 0) AND one selected chart-timeframe filter (no filter OR MACD <= signal OR MACD <= 0 OR signal <= 0 OR previous histogram > 0 AND histogram < previous histogram) AND one selected higher-timeframe filter (no filter OR MACD <= signal OR MACD <= 0 OR signal <= 0 OR third moving average <= fourth moving average OR close <= third moving average)); the NOT Buy condition and the other primary conditions are mutually exclusive selections.
Long: Buy condition.
Short: Sell condition.
Exit: long, Sell condition OR low <= entry price * (1 - stop-loss fraction) OR high >= entry price * (1 + take-profit fraction).
Exit: short, Buy condition OR high >= entry price * (1 + stop-loss fraction) OR low <= entry price * (1 - take-profit fraction).
