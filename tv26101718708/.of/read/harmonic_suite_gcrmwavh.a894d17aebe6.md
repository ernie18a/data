Calculation: Pivot buffer = Confirm pivot highs and lows using configurable left and right bar counts. On each bar process the confirmed high before the confirmed low. Keep the five most recent alternating pivot types; append an opposite-type pivot and replace a same-type pivot only when it is more extreme. An append is a new pivot; a replacement is not. Label the retained pivots oldest to newest X, A, B, C, D, or A, B, C, D when using only four.
Calculation: Ratio tests = A near-target test passes when the absolute difference between a ratio and its positive target, divided by the target, is at most the tolerance. A range test passes when the ratio is between the lower bound multiplied by one minus the tolerance and the upper bound multiplied by one plus the tolerance, inclusive. Each named pattern has its own configurable targets and bounds.
Calculation: Completed pattern = For five pivots, let XA, AB, BC, CD and AD be the absolute price differences between the respective points. All five differences must be positive. BC/AB must pass the common range test. At least one enabled pattern must pass its tests: Gartley uses near-target tests for AB/XA and AD/XA and a range test for CD/BC; Bat uses range tests for AB/XA and CD/BC and a near-target test for AD/XA; Butterfly uses a near-target test for AB/XA and range tests for CD/BC and AD/XA; Crab uses range tests for AB/XA and CD/BC and a near-target test for AD/XA.
Calculation: Projected pattern = For four pivots X, A, B, C, let XA, AB and BC be the absolute price differences between the respective points. All three differences must be positive. BC/AB must pass the common completed-pattern range test. At least one enabled pattern must pass its completed-pattern AB/XA test.
Calculation: Dashboard direction = On each independently selected higher or lower timeframe, calculate the latest completed-pattern long or short signal and retain its direction until another such signal occurs. For historical higher-timeframe bars use the last completed bar; for a higher-timeframe bar still forming in real time use that forming bar. For a lower timeframe use the last available intrabar.
Long: A new pivot is appended AND X, A, B, C, D are respectively low, high, low, high, low pivots AND completed pattern tests pass.
Short: A new pivot is appended AND X, A, B, C, D are respectively high, low, high, low, high pivots AND completed pattern tests pass.
Long: X, A, B, C are respectively low, high, low, high pivots AND C < A AND projected pattern tests pass.
Short: X, A, B, C are respectively high, low, high, low pivots AND C > A AND projected pattern tests pass.
Long: Dashboard direction = long.
Short: Dashboard direction = short.
