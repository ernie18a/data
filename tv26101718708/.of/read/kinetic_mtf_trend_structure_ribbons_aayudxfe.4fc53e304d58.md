Calculation: Requested-timeframe value = for a higher timeframe, use the last completed bar; for a lower timeframe, use the last completed lower-timeframe bar within the chart bar. Carry the last available value forward.
Calculation: Gaussian line = on a selected timeframe, recursively filter close with G[t] = alpha^p * close[t] + sum over k from 1 to p of (-1)^(k+1) * binomial(p,k) * (1-alpha)^k * G[t-k], replacing unavailable prior G values with zero. Here p is the pole count, alpha = sqrt(b*b + 2*b) - b, and b = (1 - cos(2*pi / length)) / (1.414^(2/p) - 1). Apply linear regression to G over a smoothing length, evaluated at a configurable offset, then map the result to the chart using the requested-timeframe rule.
Calculation: Gaussian trailing band = on the Gaussian line's timeframe, calculate ATR and raw upper and lower bands as the Gaussian line plus and minus an ATR multiple. Set the lower band to its raw value if it exceeds the previous lower band or the previous Gaussian line was below the previous lower band; otherwise retain the previous lower band. Set the upper band to its raw value if it is below the previous upper band or the previous Gaussian line was above the previous upper band; otherwise retain the previous upper band. Replace unavailable previous bands with zero. Initially select the upper band when the previous ATR is unavailable. If the previous selected band was the previous upper band, select the lower band when the Gaussian line is above the current upper band and otherwise select the upper band. Otherwise select the upper band when the Gaussian line is below the current lower band and otherwise select the lower band. Map the selected band to the chart using the requested-timeframe rule.
Long: Gaussian line > Gaussian trailing band.
Short: Gaussian line <= Gaussian trailing band.
Long: Each of the five shortest close EMAs is above every one of the six longer close EMAs AND the sixth-shortest close EMA is above every longer close EMA AND on the previous chart bar the sixth-shortest EMA was at or below at least one longer EMA. Calculate all EMAs on the same selected timeframe and map them to the chart using the requested-timeframe rule.

Calculate all EMAs on the same selected timeframe and map them to the chart using the requested-timeframe rule.
Short: Any of six progressively longer close EMAs calculated on one selected timeframe, or either of two close EMAs calculated on a second selected timeframe, is below its value a fixed number of chart bars ago. Map each EMA to the chart using the requested-timeframe rule before comparing.
