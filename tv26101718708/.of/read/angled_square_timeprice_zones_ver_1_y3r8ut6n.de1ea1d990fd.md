Calculation: Reference bar = the completed higher-timeframe bar selected by a lookback equal to the base cycle length divided by the number of chart bars in the configured session, rounded up and bounded to the available reference lookbacks. Use its high, low, and close. Locate the chart bar at or immediately before the start of the last completed higher-timeframe bar.
Calculation: Anchor swing = when the reference close changes or no swing exists, search backward from the located chart bar through a window whose length is the greater of the base cycle length and the number of chart bars in the session. Collect local high and low pivots using equal numbers of neighboring bars on each side, plus the window's absolute high and low. Among high-low pairs with positive range, sufficient bar separation, and range at least a configured fraction of the window's full range, choose the pair minimizing abs((price range / triple A) / max(1, scaled bar separation) - triple B / triple A). Scaled separation is either the full separation or half of it, bounded below by 1. If no pair qualifies, use the absolute high and low. Retain the previous swing if the search cannot produce a positive range.
Calculation: Grid = let the origin bar be the later swing endpoint, the origin price be the reference close, and the width basis be the full swing bar separation or its truncated half, bounded below by 1. Column width is max(1, trunc(triple B × width basis)). Row height is either the swing price range or triple A × reference close / session duration × chart-bar duration × width basis × triple B / triple A, according to the configured height method. At bar b, the column starts at origin bar + floor((b - origin bar) / column width) × column width and ends one column width later; its center is the rounded midpoint. Row r runs from origin price + r × row height to one row height above that. For rectangular grids its lower and upper edges are the row boundaries. For angled grids, each edge is linear from the row midpoint at the column start to its respective row boundary at the column center and back to the row midpoint at the column end; bound each interpolation denominator below by 1.
Calculation: Active row = floor((close - origin price) / row height), initialized from the first valid row and changed only after the same different row occurs on two consecutive bars. The current close is classified as above if above the active row's current upper edge, below if below its current lower edge, and inside otherwise; initialize the previous classification as inside.
Calculation: Optional filters = each enabled filter must pass: time filter, abs((bar index - origin bar) remainder column width - column width / 2) <= max(1, round(sqrt(column width))); price filter, abs(high - active-row upper edge) < sqrt(row height) OR abs(low - active-row lower edge) < sqrt(row height); reference filter, abs(close - reference close) < sqrt(row height) OR abs(close - reference high) < sqrt(row height) OR abs(close - reference low) < sqrt(row height).
Long: Optional filters pass AND ((previous classification is inside or below AND current classification is above) OR (previous classification is below AND current classification is inside or above) OR (high >= current upper edge of the row containing the current close AND close < that edge)).
Short: Optional filters pass AND ((previous classification is inside or above AND current classification is below) OR (previous classification is above AND current classification is inside or below) OR (low <= current lower edge of the row containing the current close AND close > that edge)).
