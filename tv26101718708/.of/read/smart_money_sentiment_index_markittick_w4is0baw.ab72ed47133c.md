Calculation: Structural state = Start neutral, with inactive high and low pivots and zero cooldown. On each bar, snapshot the pivot prices and active flags retained at the end of the preceding bar. A new high pivot is the high swing-length bars ago if it is strictly higher than every other high from one through twice the swing length bars ago; define a low pivot symmetrically using strictly lower lows. Replace and activate each pivot when confirmed. Retain the resulting pivot prices and active flags as the next bar's snapshot before processing breaks. Decrease cooldown by one if positive. A bullish break occurs when the snapshotted high pivot is active, the previous close is above its price, and cooldown is zero; a bearish break occurs when the snapshotted low pivot is active, the previous close is below its price, and cooldown is zero. Evaluate both breaks before processing either. On a bullish break, set state bullish, deactivate the current high pivot, and reset cooldown to the swing length. On a bearish break, set state bearish, deactivate the current low pivot, and reset cooldown to the swing length. Process the bullish break first if both occur.
