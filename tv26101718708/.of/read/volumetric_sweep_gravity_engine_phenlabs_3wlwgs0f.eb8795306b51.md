Calculation: Liquidity pools = the latest confirmed pivot low and pivot high; each pivot uses the same number of bars on each side and becomes available on its confirmation bar. Update the pools before evaluating that bar.
Calculation: Lower wick = min(open, close) - low; upper wick = high - max(open, close); body = abs(close - open).
Calculation: Volume ratio = volume / SMA(volume), or 0 when SMA(volume) is not positive. Wick ratio = the relevant wick / body when body > 0, otherwise 5 when the relevant wick > 0, otherwise 0.
Calculation: Delta proxy = volume * (close - open) / (high - low) when high > low, otherwise 0. Delta ratio = delta proxy / abs(SMA(delta proxy)) when the denominator is positive, otherwise 0. The delta SMA and volume SMA use the same lookback.
Calculation: Absorption score = (volume weight * clamp(100 * volume ratio / (volume threshold * 1.8), 0, 100) + wick weight * clamp(100 * wick ratio / (wick threshold * 2), 0, 100) + delta weight * clamp(100 * max(directional delta ratio, 0) / 2, 0, 100)) / weight sum; use 1 as the denominator when the weight sum is 0. Directional delta ratio is delta ratio for long and -delta ratio for short.
Long: ATR > 0 AND low < latest confirmed pivot low - ATR * sweep buffer AND lower wick >= ATR * minimum wick length AND (close-back filter disabled OR close > latest confirmed pivot low) AND low < previous low AND (EMA filter disabled OR close > EMA(close)) AND (ATR filter disabled OR SMA(ATR) unavailable OR SMA(ATR) = 0 OR ATR >= SMA(ATR) * ATR floor multiplier) AND volume ratio >= volume threshold AND lower wick ratio >= wick threshold AND long absorption score >= score threshold.
Short: ATR > 0 AND high > latest confirmed pivot high + ATR * sweep buffer AND upper wick >= ATR * minimum wick length AND (close-back filter disabled OR close < latest confirmed pivot high) AND high > previous high AND (EMA filter disabled OR close < EMA(close)) AND (ATR filter disabled OR SMA(ATR) unavailable OR SMA(ATR) = 0 OR ATR >= SMA(ATR) * ATR floor multiplier) AND volume ratio >= volume threshold AND upper wick ratio >= wick threshold AND short absorption score >= score threshold.
