Calculation: Features = selected anchor oscillator, trend feature, and momentum feature. The anchor is RSI of close, MFI of typical price, stochastic of close against high and low, or clamp(50 + 16.67 × (close − SMA(close)) / standard deviation(close), 0, 100), with 50 when standard deviation is zero. The trend feature is 50 + 50 × correlation(close, bar index). The momentum feature is clamp(50 + 16.67 × momentum(close) / ATR, 0, 100), using zero for the momentum-to-ATR ratio when ATR is not positive. Each feature uses its own lookback; momentum and its ATR share a lookback.
Calculation: Training set = on each confirmed bar, append the preceding bar's features and the current target, then retain the most recent training-window samples. The classifier target is 1 when close > previous close and 0 otherwise; the regression target is close − previous close. Train only when the window is full.
Calculation: Bull probability = retrain a classifier on each bar. For each stump, randomly select one feature and repeatedly sample training rows with replacement as candidate thresholds. Split all samples at feature ≤ threshold versus > threshold; discard empty-sided splits and retain the first candidate with maximum reduction in weighted Gini impurity. Each leaf outputs its fraction of class-1 samples; if no valid split exists, both leaves output 0.5. Route current features through every stump and average their outputs.
Calculation: Expected return = retrain a regression forest after the classifier on each bar. For each stump, randomly select a feature and a training row's value as its threshold; split all samples at feature ≤ threshold versus > threshold. Each leaf outputs the mean regression target in that leaf, or zero if empty. Route current features through every stump and average their outputs. Random selections are unseeded, so exact predictions depend on the random sequence.
Calculation: Effective threshold = base probability threshold plus an optional adaptive boost. Initially the boost is zero. After each signal trade resolves, append its percentage PnL to a rolling history of resolved signal trades; if the history's mean is negative, set the boost to min(abs(mean) / 2, maximum boost), otherwise set it to zero. Use the boost calculated after the preceding bar's trade resolutions for the current bar's signals.
Calculation: Signal trade resolution = record each fresh signal independently at its bar's close, with target and stop fixed at entry price plus or minus their respective ATR multiples using ATR at entry. Check high and low starting on the entry bar; resolve on the first target hit, stop hit, or expiry after the configured number of bars. If target and stop both hit on the same bar, use the stop. PnL is 100 × position sign × (resolution price − entry price) / entry price, using the target or stop price when hit and close on expiry. Process simultaneously resolved trades in signal insertion order.
Long: Bull probability ≥ effective threshold AND previous bar's bull probability < previous bar's effective threshold or unavailable AND bars since the previous fresh long signal ≥ cooldown AND (ADX filter disabled OR ADX ≥ ADX threshold).
Short: 1 − bull probability ≥ effective threshold AND previous bar's bear probability < previous bar's effective threshold or unavailable AND bars since the previous fresh short signal ≥ cooldown AND (ADX filter disabled OR ADX ≥ ADX threshold).
Long: Bull probability ≥ base probability threshold.
Short: 1 − bull probability ≥ base probability threshold AND bull probability < base probability threshold.
Long: Bull probability > 0.5.
Short: Bull probability ≤ 0.5.
Long: Expected return > 0.
Short: Expected return ≤ 0.
Exit: long, high ≥ entry price + target multiple × ATR at entry OR low ≤ entry price − stop multiple × ATR at entry OR bars since entry ≥ expiry.
Exit: short, low ≤ entry price − target multiple × ATR at entry OR high ≥ entry price + stop multiple × ATR at entry OR bars since entry ≥ expiry.
