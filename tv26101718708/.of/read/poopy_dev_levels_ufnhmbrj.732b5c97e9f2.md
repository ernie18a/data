Calculation: Sweep setup = On either the chart timeframe or a higher timeframe using its last completed bar, confirm pivot highs and lows using the same number of bars on each side. A bullish setup occurs when a newly confirmed pivot low is below the preceding confirmed pivot low and the latest confirmed pivot high occurred before that low; its anchor is that pivot high. A bearish setup occurs when a newly confirmed pivot high is above the preceding confirmed pivot high and the latest confirmed pivot low occurred before that high; its anchor is that pivot low. Track the latest valid pending setup independently for each direction and timeframe; replace it when a new valid setup of the same direction and timeframe occurs, and remove it when confirmed.
Long: A bullish sweep setup occurs AND confirmation is not required, OR a bullish setup is pending AND the chart close is above its anchor.
Short: A bearish sweep setup occurs AND confirmation is not required, OR a bearish setup is pending AND the chart close is below its anchor.
