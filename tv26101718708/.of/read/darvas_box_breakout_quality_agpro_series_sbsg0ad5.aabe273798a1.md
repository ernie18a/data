Calculation: Darvas box = When no candidate or active box exists, start a candidate if high exceeds the highest high of the preceding seed lookback bars. Set its top to high, bottom to low, and age to one. On each subsequent candidate bar, if high exceeds the top, reset top, bottom, and age to that bar's high, low, and one; otherwise set bottom to the lowest low since the candidate started and increment age. Activate the box when age is at least the minimum age and (top − bottom) / ATR is between the minimum and maximum height thresholds inclusive. If it has not activated and age exceeds the maximum age, discard it. Once active, keep its boundaries fixed; discard it before evaluating breakouts when its age exceeds the maximum age. Discard it after any breakout, whether qualified or not. A new candidate may start on the same bar an active box expires.
Calculation: Breakout = On a completed bar with an active box, an upward breakout occurs when close > box top if close confirmation is required, otherwise when high > box top. A downward breakout occurs when close < box bottom if close confirmation is required, otherwise when low < box bottom. If both occur, select the upward breakout.
Calculation: Failure watch = After every breakout, store its direction, bar, and broken boundary, replacing any previous watch. On each later bar through the failure window inclusive, an upward breakout fails if close < its stored top, and a downward breakout fails if close > its stored bottom. Stop watching after the first failure or after the window expires. Evaluate an existing watch before storing a new breakout on the same bar.
Long: Upward breakout.
Short: Downward breakout.
Exit: Long, upward breakout fails.
Exit: Short, downward breakout fails.
