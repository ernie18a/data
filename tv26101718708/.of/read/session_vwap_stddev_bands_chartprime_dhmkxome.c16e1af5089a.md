Calculation: Session bands = For each chart bar, obtain the opening time of the last completed higher-timeframe bar. When that time changes, start a new accumulation on the current chart bar; remain inactive until the first such change. For chart bars from that start through the current bar, inclusive, let price be a selected OHLC-derived source, defaulting to (high + low + close) / 3; let VWAP = sum(price * volume) / sum(volume), and weighted deviation = sqrt(max(sum(price^2 * volume) / sum(volume) - VWAP^2, 0)). When accumulated volume is positive, compute three upper and three lower bands as VWAP plus or minus weighted deviation times each of three independently selectable multipliers, ordered from inner to outer by their defaults.
Calculation: Directional cooldown = Current bar index minus the bar index of the last emitted signal of the same direction; initialize each direction's last signal index to -999 and do not reset it at session changes.
Long: For any one upper or lower session band, current low <= current band AND previous low > previous value of that same band AND directional cooldown >= cooldown parameter.
Short: For any one upper or lower session band, current high >= current band AND previous high < previous value of that same band AND directional cooldown >= cooldown parameter.
