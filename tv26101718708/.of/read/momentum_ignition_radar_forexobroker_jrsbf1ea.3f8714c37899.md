Calculation: Ignition score = round(volume score + range score + close score + compression score), where ATR is the current-bar average true range; volume average is the current-bar simple moving average of volume; range is high - low; prior average range is the simple moving average of range ending on the previous bar; volume ratio is volume / volume average if volume average > 0, otherwise 0; range ratio is range / ATR if ATR > 0, otherwise 0; close position is (close - low) / range if range > 0, otherwise 0.5; compression ratio is prior average range / ATR if ATR > 0 and prior average range is available, otherwise 1; volume score = min(25 * volume ratio / volume multiplier, 25); range score = min(25 * range ratio / range multiplier, 25); close score = max(0, min(25 * (close position - (1 - extreme threshold)) / extreme threshold, 25)) if close > open, otherwise max(0, min(25 * (extreme threshold - close position) / extreme threshold, 25)); compression score = max(0, min(25 * (compression threshold - compression ratio) / compression threshold, 25)).
Calculation: Bars since signal = current zero-based bar index minus the bar index of the most recent long or short signal satisfying the cooldown; use zero as the last signal index until the first such signal.
Long: Ignition score >= ignition threshold AND close > open.
Short: Ignition score >= ignition threshold AND close <= open.
Long: Ignition score >= ignition threshold AND close > open AND bars since signal >= cooldown.
Short: Ignition score >= ignition threshold AND close <= open AND bars since signal >= cooldown.
