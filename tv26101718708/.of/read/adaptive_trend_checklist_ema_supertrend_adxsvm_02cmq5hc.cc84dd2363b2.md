Calculation: Ultra mode = ultra-aggressive mode selected AND ADX enabled AND ADX >= strong-trend threshold; otherwise a selected ultra-aggressive mode falls back to aggressive mode.
Calculation: Bullish base = close > selected EMA or SMA AND (ultra mode OR close > Supertrend). Bearish base = close < selected EMA or SMA AND (ultra mode OR close < Supertrend).
Calculation: Higher-timeframe bullish state = higher-timeframe close > higher-timeframe EMA AND higher-timeframe close > higher-timeframe Supertrend; bearish state = higher-timeframe close < higher-timeframe EMA AND higher-timeframe close < higher-timeframe Supertrend. Use the last completed higher-timeframe bar on historical bars and the still-forming bar in real time. Use the chart moving-average length for the higher-timeframe EMA and the chart Supertrend parameters for the higher-timeframe Supertrend.
Calculation: Directional score = sum of the weights of enabled higher timeframes in the corresponding directional state; maximum score = sum of all enabled higher-timeframe weights. Later-listed higher timeframes have larger weights. Active score = directional score plus a bonus when chart close is on the corresponding side of both the selected moving average and Supertrend.
Calculation: Range state = close = selected moving average OR close = Supertrend OR (ADX enabled AND ADX < minimum threshold) OR either of the first two enabled higher timeframes is neither bullish nor bearish.
Calculation: Stored risk state starts neutral. Before evaluating each bar's signals, preliminary risk state = no-trade if range state, otherwise stored risk state. A risk transition occurs when the previous bar's final risk state was no-trade AND the current preliminary risk state is not no-trade. After evaluating signals, update stored risk state only if a signal occurs AND preliminary risk state is not no-trade: set it to normal if the corresponding directional score >= a fraction of maximum score AND (ADX disabled OR ADX >= the mode-specific trend threshold); otherwise set it to reduced if effective mode is aggressive OR ADX is enabled and below the mode-specific trend threshold; otherwise set it to no-trade. With no enabled higher timeframes, the directional score test passes. The aggressive trend threshold is below the conservative threshold; the ultra threshold is lower still.
Calculation: Final risk state = no-trade if ultra-aggressive mode was selected but ultra mode is inactive OR a signal occurs and its active score < a fraction of maximum score; otherwise it equals the preliminary risk state computed before the stored risk update.
Long: Bullish base AND ((ultra mode AND close > previous close) OR (ultra mode inactive AND close > previous high)) AND (previous bar's bullish base is false OR risk transition).
Short: Bearish base AND ((ultra mode AND close < previous close) OR (ultra mode inactive AND close < previous low)) AND (previous bar's bearish base is false OR risk transition).
