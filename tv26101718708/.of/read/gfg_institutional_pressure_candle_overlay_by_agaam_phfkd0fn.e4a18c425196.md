Calculation: Candle range = max(high - low, minimum price increment); body fraction = abs(close - open) / candle range; close location = (close - low) / candle range; upper wick fraction = (high - max(open, close)) / candle range; lower wick fraction = (min(open, close) - low) / candle range.
Calculation: Volume ratio = volume / SMA(volume), or 1 if the SMA is not positive; range ratio = candle range / ATR, or 1 if ATR is not positive.
Calculation: Bullish absorption = absorption enabled AND volume ratio >= absorption volume threshold AND body fraction <= absorption body threshold AND lower wick fraction >= absorption wick threshold AND close location >= 0.45. Bearish absorption = absorption enabled AND volume ratio >= absorption volume threshold AND body fraction <= absorption body threshold AND upper wick fraction >= absorption wick threshold AND close location <= 0.55.
Calculation: Shared pressure points = volume points + range points. Volume points are 2 if volume filtering is enabled and volume ratio >= high-volume threshold, 1 if filtering is disabled or volume ratio >= 1, otherwise 0. Range points are 2 if ATR filtering is enabled and range ratio >= expansion threshold, 1 if filtering is disabled or range ratio >= 0.85, otherwise 0.
Calculation: Bullish pressure score = min(10, shared pressure points + body points + close points + VWAP points + wick points). Body points are 2 if close > open AND body fraction >= strong-body threshold, otherwise 1 if close > open AND body fraction >= 0.70 * strong-body threshold, otherwise 0. Close points are 2 if close location >= strong-close threshold, otherwise 1 if close location >= 0.60, otherwise 0. VWAP points are 1 if VWAP filtering is disabled, otherwise 2 if close >= session VWAP of (high + low + close) / 3, otherwise 0. Wick points are 1 if lower wick fraction > upper wick fraction AND lower wick fraction >= 0.20, otherwise 0.
Calculation: Bearish pressure score = min(10, shared pressure points + body points + close points + VWAP points + wick points). Body points are 2 if close < open AND body fraction >= strong-body threshold, otherwise 1 if close < open AND body fraction >= 0.70 * strong-body threshold, otherwise 0. Close points are 2 if close location <= 1 - strong-close threshold, otherwise 1 if close location <= 0.40, otherwise 0. VWAP points are 1 if VWAP filtering is disabled, otherwise 2 if close <= session VWAP of (high + low + close) / 3, otherwise 0. Wick points are 1 if upper wick fraction > lower wick fraction AND upper wick fraction >= 0.20, otherwise 0.
Calculation: Buy pressure = bullish pressure score >= medium-score threshold AND bullish pressure score > bearish pressure score AND bearish absorption is false. Sell pressure = bearish pressure score >= medium-score threshold AND bearish pressure score > bullish pressure score AND bullish absorption is false.
Long: Buy pressure is true OR (buy pressure is false AND sell pressure is false AND bullish absorption is true).
Short: Sell pressure is true OR (buy pressure is false AND sell pressure is false AND bullish absorption is false AND bearish absorption is true).
