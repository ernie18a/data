Calculation: For any chart bar indexed i, i=0 is the current bar and i=1,2 are preceding bars; body[i]=abs(close[i]-open[i]), range[i]=high[i]-low[i], upper wick[i]=high[i]-max(open[i],close[i]), and lower wick[i]=min(open[i],close[i])-low[i].
Calculation: Uptrend = shorter-period EMA of close > longer-period EMA of close; downtrend = shorter-period EMA of close <= longer-period EMA of close.
Calculation: Significant body = body[0] >= minimum-size parameter * ATR; significant range = range[0] >= minimum-size parameter * ATR.
Calculation: Lower-wick shape = body[0] > 0 AND significant range = true AND lower wick[0] >= wick-to-body parameter * body[0] AND upper wick[0] <= 0.5 * body[0].
Calculation: Upper-wick shape = body[0] > 0 AND significant range = true AND upper wick[0] >= wick-to-body parameter * body[0] AND lower wick[0] <= 0.5 * body[0].
Calculation: Bullish lower-wick pattern = lower-wick pattern enabled AND lower-wick shape = true AND downtrend = true; bearish lower-wick pattern = lower-wick pattern enabled AND lower-wick shape = true AND uptrend = true.
Calculation: Bullish upper-wick pattern = upper-wick pattern enabled AND upper-wick shape = true AND downtrend = true; bearish upper-wick pattern = upper-wick pattern enabled AND upper-wick shape = true AND uptrend = true.
Calculation: Bullish engulfing = engulfing enabled AND close[1] < open[1] AND close[0] >= open[0] AND significant body = true AND close[0] >= open[1] AND open[0] <= close[1] AND body[0] >= engulfing-ratio parameter * body[1].
Calculation: Bearish engulfing = engulfing enabled AND close[1] >= open[1] AND close[0] < open[0] AND significant body = true AND close[0] <= open[1] AND open[0] >= close[1] AND body[0] >= engulfing-ratio parameter * body[1].
Calculation: Bullish harami = harami enabled AND close[1] < open[1] AND close[0] >= open[0] AND range[1] >= minimum-size parameter * current ATR AND high[0] < high[1] AND low[0] > low[1] AND body[0] < 0.6 * body[1].
Calculation: Bearish harami = harami enabled AND close[1] >= open[1] AND close[0] < open[0] AND range[1] >= minimum-size parameter * current ATR AND high[0] < high[1] AND low[0] > low[1] AND body[0] < 0.6 * body[1].
Calculation: Bullish gap reference = low[1] when the strict gap setting is selected, otherwise close[1]; bearish gap reference = high[1] when the strict gap setting is selected, otherwise close[1].
Calculation: Piercing pattern = piercing pattern enabled AND close[1] < open[1] AND close[0] >= open[0] AND significant body = true AND open[0] < bullish gap reference AND close[0] > close[1] + (open[1]-close[1]) * penetration-fraction parameter.
Calculation: Dark-cloud pattern = piercing pattern enabled AND close[1] >= open[1] AND close[0] < open[0] AND significant body = true AND open[0] > bearish gap reference AND close[0] < close[1] - (close[1]-open[1]) * penetration-fraction parameter.
Calculation: Morning star = star pattern enabled AND close[1] < open[1] AND close[2] < open[2] AND range[1] > 0 AND body[1] / range[1] < 0.3 AND close[0] >= open[0] AND significant body = true AND close[0] > (open[2]+close[2])/2.
Calculation: Evening star = star pattern enabled AND close[1] >= open[1] AND close[2] > open[2] AND range[1] > 0 AND body[1] / range[1] < 0.3 AND close[0] < open[0] AND significant body = true AND close[0] < (open[2]+close[2])/2.
Calculation: Three soldiers = three-candle pattern enabled AND close[0] >= open[0] AND close[1] > open[1] AND close[2] > open[2] AND close[0] > close[1] AND close[1] > close[2] AND open[0] < close[1] AND open[0] > open[1] AND significant body = true.
Calculation: Three crows = three-candle pattern enabled AND close[0] < open[0] AND close[1] < open[1] AND close[2] < open[2] AND close[0] < close[1] AND close[1] < close[2] AND open[0] > close[1] AND open[0] < open[1] AND significant body = true.
Calculation: A pattern starts when its condition is true on the current bar and false on the preceding bar. Cooldown passes when the number of bars since the most recent emitted long or short decision is at least the cooldown parameter; evaluate both sides before updating the shared last-decision bar.
Long: Cooldown passes = true AND (with-trend-only setting = false OR uptrend = true) AND (bullish lower-wick pattern starts = true OR bullish upper-wick pattern starts = true OR bullish engulfing starts = true OR bullish harami starts = true OR piercing pattern starts = true OR morning star starts = true OR three soldiers starts = true).
Short: Cooldown passes = true AND (with-trend-only setting = false OR downtrend = true) AND (bearish lower-wick pattern starts = true OR bearish upper-wick pattern starts = true OR bearish engulfing starts = true OR bearish harami starts = true OR dark-cloud pattern starts = true OR evening star starts = true OR three crows starts = true).
