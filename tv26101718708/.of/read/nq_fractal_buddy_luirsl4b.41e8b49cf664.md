Calculation: Higher-timeframe bars = bars aggregated above the chart timeframe; for completed-bar decisions, A is the last completed bar, B is the preceding bar, and C is the bar before B. Evaluate once when A completes.
Calculation: Bullish C2 = A.low < B.low AND A.close > B.low AND (A.low >= B.low OR A.high <= B.high).
Calculation: Bearish C2 = A.high > B.high AND A.close < B.high AND (A.low >= B.low OR A.high <= B.high).
Calculation: Delivery state and level = process bars on the selected chart, higher, or lower timeframe in order. Initialize the state to the direction of the current non-doji bar, or the most recent non-doji direction within a lookback if the current bar is a doji; initialize the level to the current open if it is a doji, otherwise to the lowest open in the current bullish run or highest open in the current bearish run, ignoring dojis and stopping at the opposite direction or a lookback limit. Initialize the tracked extreme to the current high for bullish state or low for bearish state. In bullish state, when a bar makes a higher high than the tracked extreme, update the extreme and set the level to the lowest open of the current bullish run if the bar is bullish, otherwise the most recent preceding bullish run; in bearish state, when a bar makes a lower low, update the extreme and set the level to the highest open of the current bearish run if the bar is bearish, otherwise the most recent preceding bearish run. Ignore dojis within runs, search only within a lookback, and retain the old level if no preceding run exists. After updating the level, a close above it in bearish state switches the state to bullish; a close below it in bullish state switches the state to bearish. On a switch, reset the level to the current open if the bar is a doji or to the corresponding current-run extreme open, and reset the tracked extreme to the current high for bullish state or low for bearish state. Use the last completed selected-timeframe bar; for a lower timeframe, sample the last available result per chart bar.
