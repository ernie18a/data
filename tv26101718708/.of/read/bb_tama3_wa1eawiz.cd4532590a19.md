Calculation: Zero-lag regression = 2 × linear regression of HLC3 minus linear regression of that regression, using the same lookback for both.
Calculation: Normalized value = 2 × (value − lowest value over the normalization lookback) / (highest value over that lookback − lowest value over that lookback) − 1; use 0 when the range is 0.
Calculation: Price oscillator = average of the normalized zero-lag regression and its normalized smoothed angle. The angle is atan((current zero-lag regression − previous zero-lag regression) / previous zero-lag regression) in degrees, smoothed with an SMA and multiplied by a scale factor. The SMA lookback is one bar shorter than the regression lookback; both normalization lookbacks equal the regression lookback.
Calculation: Box boundaries = when bars since the latest high exceeding the prior bar's rolling highest high equals the box-length parameter minus 2 AND the current rolling highest high over the shortest lookback is below that over the middle lookback, record that latest breakout high as the upper boundary and the current rolling lowest low as the lower boundary. The highest-high lookbacks are consecutive lengths, with the longest equal to the lowest-low lookback. Carry each boundary forward until the next qualifying bar, then apply linear regression to each boundary using the longest highest-high lookback.
Calculation: Box oscillator = average of the normalized upper and lower box boundaries. For both normalizations, use the rolling highest of the greater boundary and the rolling lowest of the lesser boundary over the zero-lag regression lookback; use 0 for each normalized boundary when the range is 0.
Calculation: Signed directional index = EMA of (positive directional movement − negative directional movement) / (positive directional movement + negative directional movement), using 0 when the denominator is 0. Positive directional movement is max(high − previous high, 0) when high − previous high exceeds previous low − low, otherwise 0; negative directional movement is max(previous low − low, 0) when previous low − low exceeds high − previous high, otherwise 0. Smooth each movement recursively as previous smoothed value − previous smoothed value / lookback + current movement, starting at 0; use the same lookback for the EMA. Treat missing previous OHLC values as 0.
Long: Price oscillator crosses above box oscillator AND (signed directional index >= 0 OR signed directional index two bars ago < 0 AND signed directional index two bars ago < signed directional index one bar ago AND signed directional index one bar ago < current signed directional index).
Short: Price oscillator crosses below box oscillator AND (signed directional index <= 0 OR signed directional index two bars ago > 0 AND signed directional index two bars ago > signed directional index one bar ago AND signed directional index one bar ago > current signed directional index).
