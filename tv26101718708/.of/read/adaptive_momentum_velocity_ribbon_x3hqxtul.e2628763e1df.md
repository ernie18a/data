Calculation: Fast HMA velocity = HMA of close with the shortest lookback minus that HMA lookback bars earlier
Calculation: Mid HMA velocity = HMA of close with the middle lookback minus that HMA lookback bars earlier
Calculation: Slow HMA velocity = HMA of close with the longest lookback minus that HMA lookback bars earlier
Long: Fast HMA velocity > 0 AND Mid HMA velocity > 0 AND Slow HMA velocity > 0 OR Fast HMA velocity crosses above the signal threshold
Short: Fast HMA velocity < 0 AND Mid HMA velocity < 0 AND Slow HMA velocity < 0 OR Fast HMA velocity crosses below the signal threshold
