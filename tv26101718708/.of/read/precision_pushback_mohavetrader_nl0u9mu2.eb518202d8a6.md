Calculation: Pressure oscillator = EMA of Williams %R; use a shorter lookback with longer smoothing and a longer lookback with shorter smoothing. For the trend detector, substitute the midpoint of the Williams %R range when its high-low denominator is zero.
Calculation: Bullish pressure = both smoothed oscillators above the upper pressure threshold; bearish pressure = both below the lower pressure threshold. The trend detector uses strict comparisons; the separate event detector includes equality. A completed run ends on the first bar when its pressure condition is false; its high, low, and duration use only the preceding consecutive pressure bars.
Calculation: Trend event rails = the latest completed bullish run's low and the latest completed bearish run's high, respectively. Update these before evaluating the campaign on each bar.
Calculation: Body-weighted midpoint = (high + low) / 2 + abs(close - open) / (high - low) * (close - (high + low) / 2); use zero for the fraction when high equals low.
Calculation: Adaptive rail = initialize to the body-weighted midpoint; subsequently add (midpoint - previous rail) / max(base length / (1 + abs(midpoint - previous rail) / ATR), 1), limiting the absolute step to an ATR multiple. Use zero displacement when ATR is zero. The structure rail has a longer base length and a smaller step-limit multiple than the fast rail.
Calculation: Fast rail direction = initially up; set up when its current rise exceeds an ATR-scaled deadzone, down when its current fall exceeds that deadzone, and otherwise retain its previous direction.
Calculation: Structure direction = initially down; set up when the body-weighted midpoint crosses above the structure rail plus a multiple of a longer-period ATR, down when it crosses below the structure rail minus that multiple, and otherwise retain its previous direction. A cross compares both current and previous values of the midpoint and boundary.
Calculation: Campaign = initially unset, with no defended level or ceiling. Process each bar in order: if unset, a completed bullish trend run starts a bullish campaign defended by its lower rail; otherwise a completed bearish run starts a bearish campaign defended by its upper rail. In a bullish campaign, first replace the defended level with any newly completed bullish run's lower rail; if close is below both the defended level and an existing upper rail, switch bearish and defend the upper rail. Then update the ceiling to the highest completed bullish run high seen while processing a bullish campaign. If still bullish and a ceiling exists and the fast rail is down, switch bearish and defend the ceiling; otherwise, if still bullish, no ceiling exists, and both rail directions are down, switch bearish with no defended level. In a bearish campaign, first replace the defended level with any newly completed bearish run's upper rail; if close is above both the defended level and an existing lower rail, switch bullish and defend the lower rail. If still bearish and both rail directions are up, switch bullish with no defended level. Clear the ceiling whenever the campaign switches bullish. An unset campaign's first bullish run does not set the ceiling on that bar.
Calculation: Sequence reference = separately for completed bullish and bearish trend runs, start unset and clear on every campaign switch. For a completed bullish run, initialize the reference to its low if unset; otherwise replace it only when the run low is lower. For a completed bearish run, initialize the reference to its high if unset; otherwise replace it only when the run high is higher. Compare before updating the reference.
Long: The inclusive bullish event-detector pressure run ends.
Short: The inclusive bearish event-detector pressure run ends.
Long: The campaign switches bullish.
Short: The campaign switches bearish.
Long: A bullish trend run completes AND its low is greater than or equal to the existing bullish sequence reference.
Short: A bullish trend run completes AND its low is below the existing bullish sequence reference.
Long: A bearish trend run completes AND its high is above the existing bearish sequence reference.
Short: A bearish trend run completes AND its high is less than or equal to the existing bearish sequence reference.
Long: The fast rail direction is up.
Short: The fast rail direction is down.
Long: The structure direction is up.
Short: The structure direction is down.
Long: The campaign is bullish AND RSI is greater than or equal to its bullish control threshold OR the campaign is bearish AND RSI is above its higher bearish control threshold.
Short: The campaign is bullish AND RSI is below its lower bullish control threshold OR the campaign is bearish AND RSI is less than or equal to its bearish control threshold.
Long: Close is greater than or equal to open.
Short: Close is below open.
