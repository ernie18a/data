Calculation: Active swing-high levels = highs greater than the highs of the preceding and following lookback bars; add each level after the following bars complete, retain only the configured number of most recent unswept levels, and remove a level when a bar's high exceeds it and close is below it
Calculation: Active swing-low levels = lows lower than the lows of the preceding and following lookback bars; add each level after the following bars complete, retain only the configured number of most recent unswept levels, and remove a level when a bar's low is below it and close is above it
Calculation: Higher-timeframe EMA = EMA of higher-timeframe closes, using the higher-timeframe bar still forming
Long: low < any active swing-low level AND close > that level AND (rejection-body filter disabled OR abs(close - open) >= minimum rejection body × ATR) AND (trend filter is All sweeps OR trend filter is HTF trend only AND close > higher-timeframe EMA OR trend filter is Counter-HTF only AND close < higher-timeframe EMA)
Short: high > any active swing-high level AND close < that level AND (rejection-body filter disabled OR abs(close - open) >= minimum rejection body × ATR) AND (trend filter is All sweeps OR trend filter is HTF trend only AND close < higher-timeframe EMA OR trend filter is Counter-HTF only AND close > higher-timeframe EMA)
