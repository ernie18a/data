Calculation: Average daily body range = mean of absolute close minus open over the lookback of completed daily bars
Calculation: Daily ATR = average true range over the lookback of the last completed daily bar
Calculation: Daily anchored VWAP = cumulative (hlc3 × volume) divided by cumulative volume since the start of the day, using volume 1 when volume is missing or nonpositive
Calculation: VWAP neutral buffer = confirmation-bar close × neutral-buffer percentage
Long: average daily body range > 0 AND range distance >= minimum range distance AND (ATR percentage <= maximum ATR percentage OR ATR filter disabled) AND (Daily ATR / average daily body range <= maximum ATR/body ratio OR ATR shock filter disabled) AND (absolute difference between the chart-timeframe fast EMA and slow EMA <= Daily ATR × trend limit OR trend filter disabled) AND (entry time is within the configured start and end times OR time filter disabled) AND (VWAP trade type disabled OR confirmation-bar close > daily anchored VWAP + VWAP neutral buffer)
Short: average daily body range > 0 AND range distance >= minimum range distance AND (ATR percentage <= maximum ATR percentage OR ATR filter disabled) AND (Daily ATR / average daily body range <= maximum ATR/body ratio OR ATR shock filter disabled) AND (absolute difference between the chart-timeframe fast EMA and slow EMA <= Daily ATR × trend limit OR trend filter disabled) AND (entry time is within the configured start and end times OR time filter disabled) AND VWAP trade type enabled AND confirmation-bar close < daily anchored VWAP - VWAP neutral buffer
