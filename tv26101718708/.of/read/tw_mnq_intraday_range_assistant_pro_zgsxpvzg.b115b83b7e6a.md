Calculation: ADR = average of daily high−low ranges over 20 higher-timeframe daily bars, including the current daily bar while it is forming
Calculation: Intraday range completion = (current higher-timeframe daily high − low) / ADR × 100; use the current daily bar while it is forming
Calculation: Intraday position percentage = (chart-bar close − current higher-timeframe daily low) / (current higher-timeframe daily high − low) × 100; use the current daily bar while it is forming, and use 50 when its range is zero
Long: chart-bar close > VWAP AND intraday position percentage ≥ 60
Short: chart-bar close < VWAP AND intraday position percentage ≤ 40
