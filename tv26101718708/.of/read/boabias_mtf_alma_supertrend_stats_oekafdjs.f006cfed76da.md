Calculation: ALMA regime = On each timeframe, calculate ALMA and population standard deviation of the selected OHLC price source. Set raw upper and lower bands to ALMA plus and minus a factor times standard deviation. Set the upper band to the raw upper band if it is below the previous upper band or the previous source is above the previous upper band; otherwise retain the previous upper band. Set the lower band to the raw lower band if it is above the previous lower band or the previous source is below the previous lower band; otherwise retain the previous lower band. Replace missing previous bands with zero. Initialize the regime as bearish while the previous standard deviation is unavailable. Thereafter, if the previous SuperTrend equals the previous upper band, the regime is bullish when the source is above the current upper band and bearish otherwise; otherwise it is bearish when the source is below the current lower band and bullish otherwise. The SuperTrend is the lower band in a bullish regime and the upper band in a bearish regime.
Calculation: Multi-timeframe values = Calculate each ALMA, regime and run statistic on its own timeframe with independent parameters. For a higher timeframe use its last completed bar, including a bar completing at the chart bar close; for a lower timeframe use the last completed lower-timeframe bar within the chart bar.
Calculation: Regime run statistics = For each timeframe and regime, the current run is the number of consecutive native-timeframe bars in that regime. The average run is the mean full length of runs of that regime whose ending transitions occurred within the rolling native-timeframe window; it is unavailable if there are no such runs.
Calculation: Overheated regime count = Count the selected timeframes whose regime is the specified side and whose current run exceeds a timeframe-specific multiplier times its positive average run.
Long: The selected chart-timeframe or multi-timeframe ALMA regime is bullish.
Short: The selected chart-timeframe or multi-timeframe ALMA regime is bearish.
Long: The ALMA on a shorter timeframe is greater than or equal to the ALMA on the adjacent longer timeframe.
Short: The ALMA on a shorter timeframe is less than the ALMA on the adjacent longer timeframe.
Long: The bullish overheated regime count is at least the minimum count AND reversal filtering is disabled.
Short: The bearish overheated regime count is at least the minimum count AND reversal filtering is disabled.
Long: The previous chart bar's bullish overheated regime count is at least the minimum count AND the chart-timeframe ALMA regime changes from bullish to bearish AND reversal filtering is enabled.
Short: The previous chart bar's bearish overheated regime count is at least the minimum count AND the chart-timeframe ALMA regime changes from bearish to bullish AND reversal filtering is enabled.
