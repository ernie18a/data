Calculation: Fingerprint = for each bar, let range = high - low, safe range = max(range, minimum price increment), and safe ATR = ATR if ATR > 0, otherwise minimum price increment. Its five mandatory components are abs(close - open) / safe range, (high - max(open, close)) / safe range, (min(open, close) - low) / safe range, (min(open, close) - low) / safe range, and min(volume / SMA(volume), 3) / 3 if SMA(volume) > 0, otherwise 0.5. Independently optional components are min(range / safe ATR, 2) / 2; (clamp((close - EMA(close)) / safe ATR, -2, 2) + 2) / 4; and 0 if high <= previous high AND low >= previous low, otherwise 1 if high > previous high AND low < previous low, otherwise 0.5. Treat minimum price increment as a configurable parameter.
Calculation: Candidate outcome = for a historical candidate, let up = (high of the single bar at the forward outcome offset after the candidate - candidate close) / max(candidate ATR, minimum price increment), and down = (candidate close - low of that same bar) / max(candidate ATR, minimum price increment). Outcome = up if up > down, otherwise -down.
Calculation: Best match = among historical candidates at offsets from forward outcome offset + 2 through min(lookback, current zero-based bar index - forward outcome offset - 2), inclusive, retain candidates with abs(candidate outcome) >= minimum outcome threshold and similarity score > 0. Similarity score = 100 × (1 - min(Euclidean distance between current and candidate fingerprints, sqrt(number of active components)) / sqrt(number of active components)). Select the highest score; if tied, select the candidate with the smallest offset. If no candidate qualifies, score and outcome are 0.
Calculation: Bars since signal = current zero-based bar index minus the zero-based bar index of the most recent long or short signal; initialize the latter to 0 and update it on every long or short signal.
Long: Best match score >= minimum score AND bars since signal >= cooldown AND best match outcome > 0
Short: Best match score >= minimum score AND bars since signal >= cooldown AND best match outcome <= 0
