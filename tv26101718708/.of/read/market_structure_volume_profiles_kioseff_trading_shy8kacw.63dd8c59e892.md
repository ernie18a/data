Calculation: Structure state = Initialize the running extreme to the first close, swing direction to neutral, and structure direction to unset. Use chart bars in chronological order. The reversal distance is a multiple of ATR calculated on the chart timeframe or a higher timeframe; for a higher timeframe, use its last completed bar, except on the chart bar that completes it, when that just-completed bar is used. From neutral, if high >= running extreme + reversal distance, set swing direction and structure direction to up and set the running extreme to high; otherwise, if low <= running extreme + reversal distance, set both directions to down and set the running extreme to low. In an up swing, update the running extreme to the maximum of itself and high; a downward reversal occurs when low <= running extreme - reversal distance AND high != running extreme. In a down swing, update the running extreme to the minimum of itself and low; an upward reversal occurs when high >= running extreme + reversal distance AND low != running extreme. On reversal, save the old running extreme as the latest confirmed swing, set the swing direction to the reversal direction, and reset the running extreme to the current low for a downward reversal or high for an upward reversal. The preceding confirmed swing is the confirmed swing saved before the latest one. Initialize the last marked level to zero and the last marked level for each combination of direction and continuation or reversal to unset. Process break decisions before updating the running extreme and reversal decisions; on a reversal, evaluate the reversal decision against the latest confirmed swing before saving the old running extreme. After each accepted decision, update the last marked level and the last marked level for its direction and type to the broken level; update structure direction to the decision direction. A decision is a continuation when its direction matches structure direction and a reversal otherwise. A level is eligible when it differs from the last marked level AND the last marked level for that direction and type is unset or differs from it. Except for an upward break while structure direction is down, decisions require a confirmed chart bar and, when the ATR timeframe is higher, the chart bar that completes that higher-timeframe bar.
Long: Swing direction = up AND structure direction = up AND preceding confirmed swing exists AND preceding confirmed swing is eligible for an upward continuation AND previous close <= preceding confirmed swing AND close > preceding confirmed swing
Long: Swing direction = up AND structure direction = down AND preceding confirmed swing exists AND preceding confirmed swing is eligible for an upward reversal AND previous close <= preceding confirmed swing AND close > preceding confirmed swing
Long: Swing direction = down AND upward reversal occurs AND latest confirmed swing exists AND latest confirmed swing is eligible for an upward decision of its applicable type AND close > latest confirmed swing
Short: Swing direction = down AND preceding confirmed swing exists AND preceding confirmed swing is eligible for a downward decision of its applicable type AND previous close > preceding confirmed swing AND close <= preceding confirmed swing
Short: Swing direction = up AND downward reversal occurs AND latest confirmed swing exists AND latest confirmed swing is eligible for a downward decision of its applicable type AND close < latest confirmed swing
Long: Structure direction = up
Short: Structure direction = down
