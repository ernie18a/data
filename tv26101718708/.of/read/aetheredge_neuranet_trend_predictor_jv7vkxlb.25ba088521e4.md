Calculation: Neural-network probability = On each chart bar, form nine inputs: (1) clamp the percentage deviation of close from the shorter EMA to symmetric bounds and divide by the positive bound; (2) apply the same normalization to the percentage deviation of the shorter EMA from the longer EMA; (3) center RSI at its midpoint and divide by that midpoint; (4) calculate the rolling z-score of ATR as a percentage of close, clamp it to symmetric bounds and divide by the positive bound; (5) apply the same z-score normalization to the logarithm of volume divided by its SMA; (6) clamp the MACD histogram divided by close and multiplied by a scaling factor to symmetric unit bounds; (7) clamp twice the centered Bollinger Band position to symmetric unit bounds; (8) clamp the positive DMI minus the negative DMI, divided by a scaling factor, to symmetric unit bounds; (9) map close's position between the rolling lowest low and highest high to symmetric unit bounds, or use zero if the range is zero. Replace unavailable inputs with zero. Initialize a single-hidden-layer network deterministically: each input-to-hidden and hidden-to-output weight is (2 × fract(sin(seed × hash multiplier + hash offset) × hash scale) − 1) × sqrt(6 / (fan-in + fan-out)), using consecutive integer seeds for the input-to-hidden weights followed by the hidden-to-output weights; initialize biases and all momentum velocities to zero. On each bar, before updating weights, calculate hidden activations as tanh of the weighted inputs plus hidden biases, and probability as sigmoid of the weighted hidden activations plus output bias, with the sigmoid argument clamped to symmetric bounds. Beginning after the initial bars, train on each completed bar using the preceding bar's saved inputs, hidden activations and probability and the target 1 if the current close exceeds the previous close, otherwise 0. Let error = previous probability − target. Update output weights first using gradient error × previous hidden activation + regularization × weight; update output bias using gradient error. Then calculate each hidden gradient as error × the updated output weight × (1 − previous hidden activation squared); update its bias using that gradient + regularization × bias, and its input weights using that gradient × previous input + regularization × weight. For every update, velocity = momentum × previous velocity − learning rate × gradient, and parameter = previous parameter + velocity. Save the current pre-update inputs, activations and probability for the next bar.
Calculation: Confidence = twice the absolute difference between neural-network probability and its midpoint.
