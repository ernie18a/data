Calculation: Adaptive trend state = On each bar, let core be the linear regression of (high + low) / 2 over the shorter lookback; let bull base = core − ATR × multiplier and bear base = core + ATR × multiplier. Initialize direction bullish when close ≥ core, otherwise bearish, and set the rail to the corresponding base. Thereafter, switch bearish to bullish when close > prior rail, or bullish to bearish when close < prior rail; otherwise, while bullish set rail to max(prior rail, bull base), and while bearish set rail to min(prior rail, bear base).
Calculation: Bullish higher-timeframe votes = number of four configured higher-timeframe states that are bullish, each computed from aggregated bars using its last completed bar and the same adaptive trend state.
Long: Close > prior chart-timeframe adaptive rail AND prior chart-timeframe direction is bearish AND bullish higher-timeframe votes ≥ 3
Short: Close < prior chart-timeframe adaptive rail AND prior chart-timeframe direction is bullish AND bullish higher-timeframe votes ≤ 1
