Calculation: Lower-timeframe volume measure = volume, close × volume, or ((high + low + close) / 3) × volume, according to the selected measure; use each lower-timeframe bar within the current chart bar, including the bar still forming.
Calculation: Anomaly score = (log of the current positive volume measure − mean log volume measure) / population standard deviation of log volume measure, calculated from the preceding positive-volume-measure lower-timeframe bars within the current chart bar, up to the reference-window length; use zero if the standard deviation is effectively zero. Require at least the warmup number of preceding observations, or the full reference-window length when that option is selected.
Calculation: Print direction = compare the lower-timeframe close with its open; if equal, compare the close with (high + low) / 2; if still equal, compare the close with the preceding positive-volume-measure lower-timeframe bar's close within the current chart bar. Return positive for greater, negative for less, and zero if unresolved.
Long: Lower-timeframe volume measure > 0 AND anomaly score >= the selected detection threshold AND print direction > 0. For the entry-band display mode, anomaly score must also be < the higher surge threshold.
Short: Lower-timeframe volume measure > 0 AND anomaly score >= the selected detection threshold AND print direction < 0. For the entry-band display mode, anomaly score must also be < the higher surge threshold.
