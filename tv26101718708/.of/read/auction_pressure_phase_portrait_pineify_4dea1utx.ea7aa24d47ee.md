Calculation: Valid sample = current OHLC values exist, high >= max(open, close), low <= min(open, close), high >= low, volume > 0, previous close exists, and every bar in the preceding baseline window has valid OHLC and positive volume; the preceding window's mean true range and median volume exist and its median volume > 0.
Calculation: Pressure memories = for each valid sample, let range scale be the maximum of current true range, mean true range over the preceding baseline window, and a positive price-floor parameter; let weight = sqrt(min(volume / median volume over the preceding baseline window, full-weight volume multiple) / full-weight volume multiple). Let direction sample = weight * (0.65 * (close - open) + 0.35 * (2 * close - high - low)) / range scale, and rejection sample = weight * (min(open, close) - low - high + max(open, close)) / range scale. Update each memory as (1 - alpha) * previous memory + alpha * its sample, where alpha = 1 - 0.5^(1 / memory half-life). Seed both memories at zero after a reset. An invalid sample resets both memories and the consecutive valid-sample count; decisions require the count to reach the maturity threshold.
Calculation: Confirmed phase = after maturity, choose the first matching candidate in this order, using direction memory D, rejection memory R, entry threshold E, lower release threshold L, rejection dominance ratio K, and the previous confirmed phase P: balance if abs(D) <= L AND abs(R) <= L; upward or downward rejection according to sign(R) if abs(R) >= E AND abs(R) >= K * abs(D); upward or downward accumulation according to sign(D) if abs(D) >= E AND (D + R) * sign(D) > 0; retain rejection phase P if P is a rejection phase AND R * sign(P) >= L AND (D + R) * sign(P) > 0; retain accumulation phase P if P is an accumulation phase AND D * sign(P) >= L AND (D + R) * sign(P) > 0 AND abs(R) < K * abs(D); otherwise mixed. Confirm a candidate only after it occurs for the required number of consecutive mature bars; retain the previous confirmed phase until then. An invalid sample resets the confirmed phase, candidate, and candidate count to unavailable.
Calculation: Last accumulation = the direction of the most recently confirmed accumulation phase; reset it to none on invalid data, confirmation of balance, or confirmation of a rejection phase opposite to the stored accumulation direction.
Long: Confirmed phase = upward accumulation OR confirmed phase = upward rejection.
Long: Confirmed phase changes to upward rejection AND last accumulation immediately before the change = downward.
Short: Confirmed phase = downward accumulation OR confirmed phase = downward rejection.
Short: Confirmed phase changes to downward rejection AND last accumulation immediately before the change = upward.
