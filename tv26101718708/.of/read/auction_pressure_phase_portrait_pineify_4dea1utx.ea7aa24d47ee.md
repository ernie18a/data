Calculation: Valid sample = valid OHLC geometry, positive volume, a prior close, a prior-window mean true range and median volume, positive median volume, and complete valid OHLCV coverage across the prior window; the prior window excludes the current bar.
Calculation: Direction memory D = zero-seeded half-life memory of sqrt(min(current volume / prior-window median volume, volume cap) / volume cap) × [0.65 × (close − open) + 0.35 × (2 × close − high − low)] / max(current true range, prior-window mean true range, minimum tick); update only on confirmed closes with valid samples.
Calculation: Rejection memory R = zero-seeded half-life memory of sqrt(min(current volume / prior-window median volume, volume cap) / volume cap) × (lower wick − upper wick) / max(current true range, prior-window mean true range, minimum tick); update only on confirmed closes with valid samples.
Calculation: Mature = at least the configured maturity count of consecutive valid samples since reset.
Calculation: Candidate phase = 0 if |D| ≤ release level and |R| ≤ release level; otherwise 2 × sign(R) if |R| ≥ entry level and |R| ≥ rejection ratio × |D|; otherwise sign(D) if |D| ≥ entry level and (D + R) × sign(D) > 0; otherwise the current phase if it is a rejection phase and R × sign(current phase) ≥ release level and (D + R) × sign(current phase) > 0; otherwise the current phase if it is an accumulation phase and D × current phase ≥ release level and (D + R) × current phase > 0 and |R| < rejection ratio × |D|; otherwise 3. Apply these tests in the stated order.
Calculation: Confirmed phase transition = Mature and the same candidate phase occurs on the configured number of consecutive confirmed closes, and candidate phase differs from current phase; invalid samples reset memories, maturity count, phase, pending candidate, and last accumulation to initial state. Set last accumulation to the new phase on accumulation transitions; reset it to zero on balance transitions or rejection transitions that oppose it.
Long: Confirmed phase transition to +1 OR confirmed phase transition to +2 when last accumulation is −1
Short: Confirmed phase transition to −1 OR confirmed phase transition to −2 when last accumulation is +1
Exit: long, confirmed phase transition to 0
Exit: short, confirmed phase transition to 0
