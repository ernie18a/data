Calculation: For each of three stochastic legs, use the chart timeframe and two successively higher timeframes with the same stochastic and smoothing parameters. %K is the simple moving average of stochastic %K; %D is the simple moving average of %K; velocity is %K minus the preceding bar's %K within that leg's timeframe. In confirmed mode use the previous chart bar and the last completed higher-timeframe bars. In developing mode use the current chart bar and the still-forming higher-timeframe bars.
Calculation: Normalize the three nonnegative leg weights by their sum, using a small positive floor for the denominator. Let x for each leg be (%K - 50) / 50, and let mean be its weighted sum. Composite = 50 + 50 * mean. Coherence = 1 - clamp(sqrt(weighted sum of (x - mean)^2), 0, 1).
Calculation: For each leg, bullish position = clamp((oversold threshold + soft-band width - %K) / soft-band width, 0, 1); bearish position = clamp((%K - overbought threshold + soft-band width) / soft-band width, 0, 1). Bullish turn = clamp(velocity / full-turn slope, 0, 1); bearish turn = clamp(-velocity / full-turn slope, 0, 1). Bullish cross = 1 if %K > %D, otherwise 0; bearish cross = 1 if %K < %D, otherwise 0. For each direction, take the weighted sum of each of its three leg values for position, turn, and cross. Directional score = 100 * position * (0.30 + 0.25 * coherence + 0.30 * turn + 0.15 * cross).
Calculation: A direction's fired flag starts false. Before evaluating each bar, reset the bullish flag if composite > an upper reset threshold or the bullish armed condition is false; reset the bearish flag if composite < a lower reset threshold or the bearish armed condition is false. The upper reset threshold is above the stochastic midpoint and the lower reset threshold is below it. Set the corresponding flag true after its confluence trigger fires.
Long: All three legs' %K <= the oversold threshold.
Short: All three legs' %K >= the overbought threshold.
Long: Each leg's %K has been <= the oversold threshold within the inclusive clustering window of chart bars AND (the turning filter is disabled OR at least two legs have velocity > 0) AND bullish score >= the score threshold AND the bullish fired flag is false.
Short: Each leg's %K has been >= the overbought threshold within the inclusive clustering window of chart bars AND (the turning filter is disabled OR at least two legs have velocity < 0) AND bearish score >= the score threshold AND the bearish fired flag is false.
