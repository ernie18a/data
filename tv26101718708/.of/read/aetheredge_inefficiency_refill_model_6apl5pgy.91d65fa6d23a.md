Calculation: Void oscillator = z-score of the one-bar log close return, multiplied by 1 when volume is below its SMA and by a configurable fade factor otherwise. Replace an unavailable return with 0 and floor the return standard deviation at 1e-10.
Calculation: Refill probability = online logistic regression prediction from six features: absolute void oscillator; clamp(1 - volume / max(volume SMA, 1e-8), -1, 2); absolute return z-score; clamp(abs(close - close at an efficiency lookback) / max(sum of absolute one-bar close changes over that lookback, 1e-8), 0, 1); clamp(safe ATR / max(SMA of safe ATR, 1e-8), 0, 3); and clamp(abs(close - origin) / safe ATR, 0, 10). Origin is the close at a displacement lookback. Safe ATR is ATR when available, otherwise true range when available, otherwise close * 0.001, floored at 1e-8. Replace unavailable feature values with 0. Initialize each feature mean to 0 and variance to 1. On every completed bar, before prediction, update each mean to mean + alpha * (feature - mean), then update variance to (1 - alpha) * (variance + alpha * (feature - updated mean)^2). Standardize using the updated mean and sqrt(max(variance, 1e-10)), and clamp each standardized feature to [-6, 6]. Initialize the intercept and feature weights to 0; predict sigmoid(clamp(intercept + dot product of weights and standardized features, -30, 30)). After prediction, register each oscillator threshold crossing with its direction, origin, bar index, and standardized features. Then process pending events newest first, including the new event: an upward event fills when low <= its origin, and a downward event fills when high >= its origin. On a fill, train with label 1; otherwise, when age >= the configurable refill horizon, train with label 0. Remove each trained event. For each training step, predict again using its saved features and current weights, set error = prediction - label, subtract learning rate * error from the intercept, and subtract learning rate * (error * saved feature + L2 coefficient * current weight) from each feature weight.
Long: Completed-bar index > warmup length AND void oscillator crosses below the negative void threshold AND refill probability > minimum refill probability.
Short: Completed-bar index > warmup length AND void oscillator crosses above the positive void threshold AND refill probability > minimum refill probability.
