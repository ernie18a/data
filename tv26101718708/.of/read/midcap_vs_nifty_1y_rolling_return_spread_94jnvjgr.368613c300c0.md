Calculation: Rolling return = (current higher-timeframe close / higher-timeframe close at the start of the return lookback − 1) × 100; use the current higher-timeframe bar, which may still be forming.
Calculation: Relative return spread = first series’ rolling return − second series’ rolling return.
Calculation: Upper band = long-term average of the relative return spread + its long-term standard deviation, using the same lookback for both.
Calculation: Lower band = long-term average of the relative return spread − its long-term standard deviation, using the same lookback for both.
Long: Relative return spread > upper band
Short: Relative return spread < lower band
