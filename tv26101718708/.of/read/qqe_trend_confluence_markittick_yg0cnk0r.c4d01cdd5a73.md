Calculation: Adapted source = a selected OHLC-derived price series, optionally smoothed by SMA, EMA, RMA, two successive WMAs, three successive volume-weighted moving averages, HMA, slope projection, or a recursive Kalman filter, all using the same selected lookback. Slope projection is SMA(source, lookback) + (source - source[lookback]) / 2. For the Kalman filter, initialize estimate to source and error to 1; on each bar set predicted error = error + 1 / lookback, gain = predicted error / (predicted error + 1), estimate = estimate + gain * (source - estimate), and error = (1 - gain) * predicted error.
Calculation: QQE pair = EMA of RSI of the adapted source and its recursive trail. Set distance to a factor times the EMA of the EMA of the absolute change in smoothed RSI, with both EMA lengths equal to twice the RSI length minus one. Once distance is available, use the previous trail, or current smoothed RSI if no previous trail exists. If current smoothed RSI is below that trail, set the trail to current smoothed RSI + distance, capped at the previous trail when previous smoothed RSI was also below it. If current smoothed RSI is above that trail, set the trail to current smoothed RSI - distance, floored at the previous trail when previous smoothed RSI was also above it. Otherwise retain the previous trail. The secondary pair uses the same RSI length and adapted source, a longer RSI smoothing length, and its own distance factor.
Calculation: Confirmed QQE side = the sign of primary smoothed RSI minus its trail on the preceding chart bar; retain the preceding confirmed side when equal, starting at zero.
Calculation: Trade levels = on each qualifying entry signal, set the reference price to the preceding chart bar's close and risk distance to current chart bar ATR times a stop multiplier. For a long, stop = reference price - risk distance and each of three targets = reference price + risk distance times its own reward ratio; for a short, reverse the signs. Store these levels until a new qualifying signal replaces them or the third target or stop is hit. Evaluate touches on the signal bar as well.
Long: Confirmed QQE side changes from negative to positive AND (secondary confirmation is disabled OR preceding chart bar secondary smoothed RSI > secondary trail) AND (ADX filter is disabled OR preceding chart bar ADX >= threshold) AND (higher-timeframe filter is disabled OR primary smoothed RSI > primary trail on the last completed higher-timeframe bar).
Short: Confirmed QQE side changes from positive to negative AND (secondary confirmation is disabled OR preceding chart bar secondary smoothed RSI < secondary trail) AND (ADX filter is disabled OR preceding chart bar ADX >= threshold) AND (higher-timeframe filter is disabled OR primary smoothed RSI < primary trail on the last completed higher-timeframe bar).
Long: Current chart bar primary smoothed RSI >= primary trail.
Short: Current chart bar primary smoothed RSI <= primary trail.
Long: Current chart bar DI+ > DI-.
Short: Current chart bar DI+ <= DI-.
Long: Higher-timeframe filter is enabled AND primary smoothed RSI > primary trail on the last completed higher-timeframe bar.
Short: Higher-timeframe filter is enabled AND primary smoothed RSI <= primary trail on the last completed higher-timeframe bar.
Long: Secondary confirmation is enabled AND preceding chart bar secondary smoothed RSI > secondary trail.
Short: Secondary confirmation is enabled AND preceding chart bar secondary smoothed RSI < secondary trail.
Exit: long, confirmed QQE side changes from positive to negative AND (secondary confirmation is disabled OR preceding chart bar secondary smoothed RSI < secondary trail) AND (ADX filter is disabled OR preceding chart bar ADX >= threshold) AND (higher-timeframe filter is disabled OR primary smoothed RSI < primary trail on the last completed higher-timeframe bar).
Exit: short, confirmed QQE side changes from negative to positive AND (secondary confirmation is disabled OR preceding chart bar secondary smoothed RSI > secondary trail) AND (ADX filter is disabled OR preceding chart bar ADX >= threshold) AND (higher-timeframe filter is disabled OR primary smoothed RSI > primary trail on the last completed higher-timeframe bar).
Exit: long, active long trade levels exist AND (low <= stop OR high >= any of the three targets).
Exit: short, active short trade levels exist AND (high >= stop OR low <= any of the three targets).
