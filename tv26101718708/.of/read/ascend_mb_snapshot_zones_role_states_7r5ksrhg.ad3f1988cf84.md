Calculation: Snapshot zone = At each enabled snapshot time, build each enabled volume profile from its specified chart-bar lookback, including the current bar; auction lookbacks use the number of bars in the preceding auction, but include the current bar. Divide the profile's highest-high-to-lowest-low range into equal bins. Allocate each bar's volume to each bin in proportion to the overlap of their high-low ranges, using at least one price increment as the bar-range denominator. Select nonzero-volume bins at or below the configured volume percentile, in ascending volume and then ascending bin order, subject to the configured maximum count and minimum distance between selected bin midpoints. Process profiles in snapshot order: the first snapshot may use longer historical and shorter recent lookbacks; the second may use the preceding auction and the recent lookback; the optional later snapshot may use its preceding auction. Merge each selected bin into the first existing zone overlapping within the configured tolerance, expanding its bounds to the union, incrementing its overlap count, and adding the current snapshot tag; otherwise create a zone with count one. If merging is disabled, always create a new zone. Remove oldest zones when the configured retention limit is exceeded, and optionally clear zones on a new day. For each snapshot tag, select the last stored zone with the highest overlap count at or above the configured confluence threshold; its current bounds are the snapshot zone. Recompute selection on every bar, so later merges can change earlier snapshot zones.
Long: Close > snapshot zone top + configured price buffer.
Short: Close < snapshot zone bottom - configured price buffer.
