Calculation: Conversion line = (highest high + lowest low) / 2 over the conversion lookback; base line = the same midpoint over the base lookback; span B = the same midpoint over the span B lookback. The lookbacks are independently configurable, typically from shortest to longest in that order.
Calculation: Span A = (conversion line + base line) / 2. Cloud top and bottom are the maximum and minimum of span A and span B from a configurable displacement number of bars ago.
Calculation: Price state = +1 if close > cloud top, -1 if close < cloud bottom, otherwise 0. Future-cloud state = +1 if current span A > current span B, -1 if current span A < current span B, otherwise 0. Line state = +1 if conversion line > base line, -1 if conversion line < base line, otherwise 0.
Calculation: Lagging state = +1 if current close > both the greater of open and close from one displacement ago and the cloud top from one displacement ago; -1 if current close < both the lesser of open and close from one displacement ago and the cloud bottom from one displacement ago; otherwise 0. A state is 0 when its required values are unavailable.
Calculation: Score = price state + future-cloud state + line state + lagging state. Calculate chart score on chart bars and higher-timeframe score on the last completed higher-timeframe bar, using the same lookback and displacement parameters. Use positive configurable score thresholds for higher-timeframe confirmation, breakout, and bounce; the breakout threshold is lower than the bounce threshold.
Long: Higher-timeframe score >= confirmation threshold AND chart score >= breakout threshold AND previous close >= previous cloud bottom AND previous close <= previous cloud top AND close > cloud top AND the complete preceding condition was false on the previous chart bar.
Short: Higher-timeframe score <= negative confirmation threshold AND chart score <= negative breakout threshold AND previous close >= previous cloud bottom AND previous close <= previous cloud top AND close < cloud bottom AND the complete preceding condition was false on the previous chart bar.
Long: Higher-timeframe score >= confirmation threshold AND price state = +1 AND future-cloud state = +1 AND line state = +1 AND lagging state = +1 AND the complete preceding condition was false on the previous chart bar.
Short: Higher-timeframe score <= negative confirmation threshold AND price state = -1 AND future-cloud state = -1 AND line state = -1 AND lagging state = -1 AND the complete preceding condition was false on the previous chart bar.
Long: Higher-timeframe score >= confirmation threshold AND chart score >= bounce threshold AND price state = +1 AND future-cloud state = +1 AND low <= base line AND close > base line AND close > open AND previous close > previous base line AND the complete preceding condition was false on the previous chart bar.
Short: Higher-timeframe score <= negative confirmation threshold AND chart score <= negative bounce threshold AND price state = -1 AND future-cloud state = -1 AND high >= base line AND close < base line AND close < open AND previous close < previous base line AND the complete preceding condition was false on the previous chart bar.
Exit: long, (line state = -1 AND previous line state != -1) OR close < base line OR close <= cloud top.
Exit: short, (line state = +1 AND previous line state != +1) OR close > base line OR close >= cloud bottom.
