Calculation: Direction = +1 when the short-term EMA > the medium-term EMA > the long-term EMA AND (medium-term EMA − medium-term EMA a slope-lookback number of bars ago) / ATR > the positive slope threshold; −1 when the inequalities are reversed and normalized slope < the negative slope threshold; otherwise 0. Restrict direction to the selected planning side, if one is selected. Direction is 0 until the bar index exceeds the maximum of the EMA, volume, ATR and target lookbacks plus the slope lookback, ATR lookback and a warmup buffer.
Calculation: Pocket = medium-term EMA ± pocket-width multiplier × ATR. A recent touch exists when, within the pullback review window, a bar with nonzero direction has low <= its pocket upper edge AND high >= its pocket lower edge. Touches are shared between directions.
Calculation: Directional metrics = depth is max(direction × (short-term EMA − recent pullback extreme) / ATR, 0), where the extreme is the lowest low for direction +1 and highest high for direction −1 over the pullback review window; acceptance distance is direction × (close − directional pocket edge) / ATR, using the upper edge for +1 and lower edge for −1; risk rail is min(lower pocket edge, long-term EMA) − risk buffer × ATR for +1 and max(upper pocket edge, long-term EMA) + risk buffer × ATR for −1; risk distance is max(direction × (close − risk rail) / ATR, 0); room is max(direction × (prior obstruction − close) / ATR, 0), where obstruction is the highest high for +1 or lowest low for −1 over the target lookback excluding the current bar. If raw room is below a fallback threshold or unavailable, set room to the clean-room parameter. Relative volume is volume divided by the maximum of its moving average and a positive volume floor.
Calculation: Normalized score H(x,a,b) = clamp(100 × (x − a) / max(b − a, epsilon), 0, 100); L(x,a,b) = clamp(100 × (b − x) / max(b − a, epsilon), 0, 100); peak score P(x,a,b,c) = H(x,a,b) when x <= b, otherwise L(x,b,c).
Calculation: Acceptance score = round(clamp(weighted sum of depth, close, trend, volume, risk and room scores, 0, 100)). Depth score = P(depth, shallow-depth parameter, ideal-depth parameter, deep-depth parameter). Close score = H(acceptance distance × sensitivity multiplier, accepted-close lower parameter, accepted-close upper parameter) when acceptance distance > acceptance buffer, otherwise H(acceptance distance × sensitivity multiplier, other-close lower parameter, other-close upper parameter). Trend score = H(abs(normalized medium-term EMA slope) × sensitivity multiplier, lower slope-score parameter, upper slope-score parameter). Volume score = H(relative volume, recovery-volume lower parameter, recovery-volume upper parameter) when acceptance distance > acceptance buffer, otherwise L(relative volume, preferred dry-volume parameter, weak-volume parameter). Risk score = P(risk distance, lower risk parameter, ideal risk parameter, upper risk parameter). Room score = H(room, lower room parameter, clean-room parameter). The six weights and all scoring bounds are parameters; the accepted threshold is greater than the watch threshold.
Calculation: Accepted state = recent touch AND acceptance distance > acceptance buffer AND acceptance score >= accepted threshold. Rejected state = recent touch AND direction × (close − risk rail) < 0. Room-review state = recent touch AND room < clean-room parameter × room-review multiplier AND acceptance score >= watch threshold AND accepted state = false AND rejected state = false. Watch state = recent touch AND acceptance score >= watch threshold AND accepted state = false AND rejected state = false AND room-review state = false. Forming state = recent touch AND accepted state = false AND rejected state = false AND room-review state = false AND watch state = false.
Long: direction = +1 AND accepted state = true
Short: direction = −1 AND accepted state = true
Long: direction = +1 AND room-review state = true
Short: direction = −1 AND room-review state = true
Long: direction = +1 AND watch state = true
Short: direction = −1 AND watch state = true
Long: direction = +1 AND forming state = true AND acceptance score >= forming threshold
Short: direction = −1 AND forming state = true AND acceptance score >= forming threshold
