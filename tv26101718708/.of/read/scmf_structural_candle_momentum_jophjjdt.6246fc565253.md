Calculation: Lower-timeframe bars = bars within the current chart bar, including the lower-timeframe bar still forming; use separate shorter and longer lower timeframes. A dimension requiring lower-timeframe data is unavailable until its minimum bar-count parameter is met.
Calculation: Validity = chart volume > 0 AND chart timeframe belongs to the permitted timeframe set. Doji = chart high - low < doji multiplier × ATR. Gap = chart open - previous chart close, or 0 if the previous close is unavailable.
Calculation: Close position = if doji, gap sign × doji fallback factor; otherwise 2 × (close - low) / (high - low) - 1, or 0 when the range is zero. It is unavailable when validity fails.
Calculation: Wick absorption = with upper wick = high - max(open, close), lower wick = min(open, close) - low, and body fraction = abs(close - open) / (high - low): if not doji and range > 0, clamp((lower wick - upper wick) / range × (1 + body fraction) / 2, -1, 1); if doji and wick sum > 0, clamp((lower wick - upper wick) / wick sum × doji wick factor, -1, 1); if doji and wick sum = 0, 0; otherwise unavailable. It is unavailable when validity fails.
Calculation: Volume concentration = sum of squared shorter lower-timeframe volume shares when the minimum bar count is met and total volume > 0; otherwise a fallback parameter.
Calculation: Net volume delta = for each shorter lower-timeframe bar, let range = high - low, average range = mean of nonnegative ranges in the current chart bar, close fraction = (close - low) / range when range > 0 else 0.5, and tick fraction = 1 if its close exceeds the preceding lower-timeframe close, 0 if lower, else close fraction; for the first lower-timeframe bar use the previous chart close, or its own close if unavailable. Let buy fraction = (close fraction + tick fraction) / 2 and range weight = 1 / (1 + max(0, range / average range - 1)) when average range > 0, otherwise a fallback parameter. Delta = sum(volume × range weight × (2 × buy fraction - 1)) / sum(volume × range weight). Multiply delta by a penalty parameter if (delta > 0 AND chart close <= session VWAP) OR (delta <= 0 AND chart close > session VWAP), where session VWAP is sum((high + low + close) / 3 × volume) / sum(volume) over the shorter lower-timeframe bars. Delta is unavailable if validity fails, the minimum bar count is not met, or its denominator is zero.
Calculation: Phase volumes = sums of the longer lower-timeframe volumes in consecutive opening, discovery, and remaining conviction segments; the opening and discovery segment lengths are parameters. If the minimum longer-timeframe bar count is not met, all phase volumes are zero. Event = abs(gap) / ATR > event gap threshold, using 0 when ATR <= 0, OR opening volume / SMA of opening volume > volume surprise threshold when that SMA > 0. Structural gap = abs(gap) / ATR > a higher gap threshold, using 0 when ATR <= 0.
Calculation: Temporal volume distribution = clamp((opening weight × opening volume + discovery weight × discovery volume + conviction weight × conviction volume) / total phase volume × direction, -1, 1). Use one set of phase weights on event bars and another otherwise. Direction is the sign of the difference between the last longer lower-timeframe close and the close a parameterized number of bars before it, with the reference index floored at the first bar; if equal, use the sign of close position. It is unavailable if validity fails, the minimum longer-timeframe bar count is not met, close position is unavailable, or total phase volume is zero.
Calculation: Price path topology = with the longer lower-timeframe closes in order, direction = sign(last close - first close), monotonicity = fraction of consecutive close changes strictly matching direction, midpoint index = clamp(floor(number of closes / 2), 1, number of closes - 2), and scale = chart high - low if positive else ATR: clamp(direction × monotonicity + acceleration weight × clamp(((last close - midpoint close) / late step count - (midpoint close - first close) / early step count) / scale, -1, 1), -1, 1). It is unavailable if validity fails or the minimum longer-timeframe bar count is not met.
Calculation: Regime = trending if ADX > higher ADX threshold AND ATR / SMA(ATR) > higher ATR-ratio threshold; ranging if ADX < lower ADX threshold AND ATR / SMA(ATR) < lower ATR-ratio threshold; otherwise transitional. Use an ATR-ratio fallback of 1 when SMA(ATR) <= 0. Select fixed dimension weights or regime-dependent weights; trending assigns more weight to net volume delta and temporal volume distribution and less to close position and wick absorption than ranging.
Calculation: Quality = clamp(validity factor × volume-classification factor × event factor × liquidity factor × doji factor × regime factor, 0, 1). Validity factor is 1 when validity passes and 0 otherwise. Volume-classification factor uses a missing-data parameter when the shorter lower-timeframe minimum bar count is not met; otherwise it equals min(1, shorter bar count / expected shorter bar count) times one of three parameters selected by low, intermediate, or high volume-concentration thresholds. Event factor uses its structural-gap parameter, else its event parameter, else 1. Liquidity factor is the product of a concentration factor and an Amihud factor: concentration factor is 0 above the abort threshold, otherwise uses successively less severe penalty parameters above the intermediate and liquid thresholds, else 1; Amihud factor is a penalty parameter when the rolling percentile rank of abs(close / previous close - 1) / scaled volume exceeds its threshold, else 1, using 0 for the Amihud value when volume is nonpositive or previous close is unavailable and 1 for the factor when the rank is unavailable. Doji factor is a penalty parameter for a doji, else 1. Regime factor uses a transitional parameter or a non-transitional parameter.
Calculation: Composite = clamp(weighted sum of available close position, wick absorption, net volume delta, temporal volume distribution, and price path topology divided by the sum of their available weights, -1, 1). It is unavailable when validity fails, the weight sum is nonpositive, quality is below its threshold, or volume concentration exceeds its abort threshold.
Long: composite > positive composite threshold.
Short: composite <= negative composite threshold.

Short: close position <= negative dimension threshold OR wick absorption <= negative dimension threshold OR net volume delta <= negative dimension threshold OR temporal volume distribution <= negative dimension threshold OR price path topology <= negative dimension threshold.

Short: composite is available AND close position > positive distribution threshold AND net volume delta < negative distribution threshold AND temporal volume distribution < negative distribution threshold.
