Calculation: Daily VWAP = cumulative ( (high + low + close) / 3 × volume ) / cumulative volume, reset at the start of each day
Calculation: Asia session VWAP = cumulative ( (high + low + close) / 3 × volume ) / cumulative volume during the Asia session, reset at session start
Calculation: London session VWAP = cumulative ( (high + low + close) / 3 × volume ) / cumulative volume during the London session, reset at session start
Calculation: New York session VWAP = cumulative ( (high + low + close) / 3 × volume ) / cumulative volume during the New York session, reset at session start
Long: High >= any of the four VWAPs AND Low <= that VWAP (High/Low touch mode), OR any of the four VWAPs is between Open and Close, inclusive (Open/Close touch mode)
