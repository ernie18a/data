Calculation: Rational-quadratic smoothing = weighted average of the current and preceding source values over a kernel window, with weight at lag i equal to (1 + i² / (2 × kernel lookback² × relative weight))^(-relative weight); optionally apply it independently to HL2, close, and ATR.
Calculation: Original SuperTrend and original direction = form raw bands as optionally smoothed HL2 ± factor × optionally smoothed ATR. Set the lower band to its raw value when it exceeds the previous lower band or previous optionally smoothed close is below the previous lower band; otherwise retain the previous lower band. Set the upper band to its raw value when it is below the previous upper band or previous optionally smoothed close is above the previous upper band; otherwise retain the previous upper band. Treat missing previous bands as zero. Set the original stop to lower band × (1 − stop-loss multiplier) if previous original direction is bullish, otherwise upper band × (1 + stop-loss multiplier). Initialize direction bearish when previous ATR is unavailable; otherwise, if previous original SuperTrend equals previous upper band, direction is bullish when optionally smoothed close > original stop and bearish otherwise; in all other cases direction is bearish when optionally smoothed close < original stop and bullish otherwise. Original SuperTrend is the lower band in a bullish direction and the upper band otherwise.
Calculation: Decision SuperTrend = optionally use the original SuperTrend unchanged; or average the current and historical SuperTrend values over the machine-learning lookback, optionally retaining only bars whose final direction equals the current original direction; or calculate shorter- and longer-lookback SMA, EMA, or VWMA of the SuperTrend series and form signed distances as longer average minus shorter average over the machine-learning lookback. Optionally retain distances whose historical final direction equals the current original direction. Determine minimum and maximum from the first nearest-neighbor-count retained distances, ordered newest first; retain distances within the selected minimum bound, maximum bound, or both. When only the maximum bound is selected, apply that bound; when only the minimum is selected, apply that bound. For each retained distance at index i, use the mean of the longer and shorter averages at index i in the original unfiltered arrays, and, if direction filtering is enabled, also require the direction at that original index to equal the current original direction. Return the mean of these values, or the first value for the exponential option. Historical SuperTrend values refer to the final decision SuperTrend series.
Calculation: Decision stop and final direction = without machine learning, use the original stop and original direction. With machine learning, set the stop to decision SuperTrend × (1 − stop-loss multiplier) when original direction is bullish, otherwise decision SuperTrend × (1 + stop-loss multiplier); final direction is bullish when close > stop and bearish otherwise.
Calculation: Take-profit level = decision SuperTrend × (1 + take-profit multiplier) in a bullish final direction, otherwise decision SuperTrend × (1 − take-profit multiplier).
Long: Final direction changes from bearish to bullish AND a buy stop order at the decision stop is filled.
Short: Final direction changes from bullish to bearish AND a sell stop order at the decision stop is filled.
Exit: Long, take-profit multiplier ≠ 0 AND final direction is bullish AND close > take-profit level.
Exit: Short, take-profit multiplier ≠ 0 AND final direction is bearish AND close < take-profit level.
Exit: Long, same-bar entry and exit is enabled AND stop-loss multiplier ≠ 0 AND previous final direction is bullish AND close < previous decision stop.
Exit: Short, same-bar entry and exit is enabled AND stop-loss multiplier ≠ 0 AND previous final direction is bearish AND close > previous decision stop.
