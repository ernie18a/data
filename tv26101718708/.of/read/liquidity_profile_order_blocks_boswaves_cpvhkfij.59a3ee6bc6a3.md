Calculation: Order blocks = At each confirmed pivot low or high, using the same pivot lookback on both sides, create respectively a bullish block if current close minus pivot low >= ATR at the pivot times an impulse multiplier, or a bearish block if pivot high minus current close >= ATR at the pivot times that multiplier. Formation bars run from the pivot bar forward for a configurable count, stopping at the bar before confirmation. For a bullish block, raw top is the maximum of formation-bar opens and closes and raw bottom is the minimum low; for a bearish block, raw top is the maximum high and raw bottom is the minimum of opens and closes. Expand the height symmetrically to the minimum ATR multiple, then compress it symmetrically to the maximum ATR multiple, using ATR at the pivot. The midpoint is the average of the resulting boundaries. When configured to remove overlaps, remove the most recently created existing same-side block whose range overlaps the new block. Before adding a block, remove the oldest block if the maximum block count has been reached. Process bullish creation before bearish creation. After evaluating signals on each bar, remove bullish blocks when close or low, according to the selected invalidation mode, is below the bottom; remove bearish blocks when close or high, according to that mode, is above the top.
Calculation: Block interaction = A bar is inside a block when high >= block bottom AND low <= block top. Each block starts unarmed and with its previous inside state false. On a confirmed bar, arm it when it is inside and the preceding inside state was false; disarm it after its retest confirmation. Update the previous inside state on every bar. Newly created blocks participate on their creation bar.
Calculation: Profile row net volume = Divide each block into equal-height price rows. For each formation bar, allocate volume to each row in proportion to the overlap of the bar's high-low range with the row divided by the bar's range, floored at the minimum price increment. Add allocated volume when close >= open and subtract it otherwise. Optionally apply the same allocation on each confirmed bar inside the block.
Long: A bullish order block is created.
Short: A bearish order block is created.
Long: A bullish block is inside AND armed AND close > its midpoint AND (previous close <= its midpoint OR low <= its midpoint).
Short: A bearish block is inside AND armed AND close < its midpoint AND (previous close >= its midpoint OR high >= its midpoint).
Long: Shorter-period EMA of close >= longer-period EMA of close.
Short: Shorter-period EMA of close < longer-period EMA of close.
Long: Any block's profile row net volume >= 0.
Short: Any block's profile row net volume < 0.
