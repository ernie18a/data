Calculation: Confirmed pivot levels = the most recently confirmed pivot high and pivot low, each using the same number of bars on either side; replace each level and mark it unbroken when a new pivot of that type is confirmed.
Calculation: Structure state = initially neutral; on an unbroken pivot-high break that passes the optional moving-average filter, mark that high broken and set the state bullish; then, on an unbroken pivot-low break that passes the filter, mark that low broken and set the state bearish. A break uses close beyond the level or, if configured, high above the pivot high or low below the pivot low.
Calculation: Setup = a filtered break when the previous structure state is opposite to the break and the reversal engine is enabled, or the previous state is the same as the break and the continuation engine is enabled. Process upward breaks before downward breaks. For an upward setup, set the range endpoints to the break bar's high and the latest pivot low; for a downward setup, set them to the latest pivot high and the break bar's low. The bullish entry-zone endpoints are high endpoint minus 0.382 and 0.618 times the range; the bearish endpoints are low endpoint plus 0.382 and 0.618 times the range. Retain the latest setup separately for each engine.
Long: An upward setup occurs AND the moving-average filter is disabled OR an upward setup occurs AND close > the selected moving average of close.
Short: A downward setup occurs AND the moving-average filter is disabled OR a downward setup occurs AND close < the selected moving average of close.
Long: The latest setup of an enabled engine is bullish AND close >= the lower entry-zone endpoint AND close <= the upper entry-zone endpoint.
Short: The latest setup of an enabled engine is bearish AND close >= the lower entry-zone endpoint AND close <= the upper entry-zone endpoint.
