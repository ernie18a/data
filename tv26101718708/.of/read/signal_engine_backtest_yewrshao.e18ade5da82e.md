Calculation: Signal trigger = for a selected chart-bar data source A and, where applicable, source B or a threshold: A crosses above B, A crosses below B, A crosses above the threshold, A crosses below the threshold, or A changes from zero to nonzero; select one mode independently for each direction. A crossover requires A > B now and A <= B on the previous bar; a crossunder requires A < B now and A >= B on the previous bar.
Calculation: Volatility ratio = volatility ATR divided by its SMA; use a ratio of 1 when the SMA is not positive.
Calculation: Support/resistance levels = the high and low of the last completed bar of each enabled higher timeframe; the two timeframes have different lengths.
Calculation: Stop and target distances = separately configured distances, either multiples of ATR measured on the entry bar or fixed price distances. Freeze them at entry.
Long: long signal trigger AND no open position AND, if enabled, close > baseline EMA, SMA, HMA, or WMA AND, if enabled, datetime is within the inclusive date range AND, if enabled, ADX >= threshold AND, if enabled, volatility ratio is within inclusive thresholds AND, if enabled, absolute distance from close to every enabled support/resistance level > entry-bar ATR multiplied by a buffer.
Short: short signal trigger AND no open position AND, if enabled, close < baseline EMA, SMA, HMA, or WMA AND, if enabled, datetime is within the inclusive date range AND, if enabled, ADX >= threshold AND, if enabled, volatility ratio is within inclusive thresholds AND, if enabled, absolute distance from close to every enabled support/resistance level > entry-bar ATR multiplied by a buffer.
Exit: long, low <= entry price minus stop distance OR high >= entry price plus first target distance OR, if enabled, high >= entry price plus second target distance.
Exit: short, high >= entry price plus stop distance OR low <= entry price minus first target distance OR, if enabled, low <= entry price minus second target distance.
