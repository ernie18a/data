Calculation: ATR step trend = Set basic upper and lower bands to (high + low) / 2 plus and minus ATR multiplied by an ATR multiplier. Initialize final bands to their basic bands. Thereafter, set the final upper band to the current basic upper band if it is below the previous final upper band or the previous close is above the previous final upper band; otherwise retain the previous final upper band. Set the final lower band to the current basic lower band if it is above the previous final lower band or the previous close is below the previous final lower band; otherwise retain the previous final lower band. Initialize trend to +1. On each bar set it to +1 if close is above the previous final upper band, otherwise to -1 if close is below the previous final lower band, otherwise retain the previous trend; use the current basic band when its previous final band is unavailable.
Calculation: Bias = Clamp the sum of these votes to [-100, 100] and round to an integer: +20 if ATR step trend is +1, otherwise -20; +20 if main EMA >= slow EMA, otherwise -20; +10 if fast EMA >= mid EMA, otherwise -10; +15 if the change in the current-end linear regression of close is >= 0, otherwise -15, treating an unavailable change as zero; +10 if positive DI >= negative DI, otherwise -10; RSI contributes +15 if >= the upper RSI threshold, otherwise -15 if <= the lower RSI threshold, otherwise +8 if >= the middle RSI threshold, otherwise -8; volume contributes +5 if volume is above its SMA and close >= open, -5 if volume is above its SMA and close < open, otherwise 0. The fast EMA has a shorter lookback than the mid EMA, and the slow EMA has a longer lookback than the main EMA. The upper RSI threshold is above the middle threshold, which is above the lower threshold.
Calculation: Score = round(clamp(50 + abs(bias) / 2, 0, 100)).
Long: Bias >= 0
Short: Bias < 0
