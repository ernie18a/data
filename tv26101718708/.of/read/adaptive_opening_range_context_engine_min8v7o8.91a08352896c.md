Calculation: Opening range = the highest high and lowest low, or alternatively the highest of open and close and lowest of open and close, across chart bars in the configured opening session. Lock the range on the first bar after that session; its midpoint is the average of its boundaries.
Calculation: Lifecycle state = reset to forming, with neutral bias, zero outside count, and no retest, at each opening-session start. On confirmed chart bars in the display session after the lock bar, apply the first matching rule: (1) if bias is neutral and close is above the range high or below the range low, set bias to upper or lower respectively, set outside count to one, and set state to the corresponding break attempt; (2) if bias is upper and no retest has occurred, increment outside count when close is above the range high and set state to upper accepted if the count reaches the acceptance threshold; otherwise, if close is below the midpoint, set state to upper rejected, bias to neutral, and count to zero; otherwise, if close equals the range high, set retest and state to upper retest; (3) if bias is lower and no retest has occurred, increment outside count when close is below the range low and set state to lower accepted if the count reaches the acceptance threshold; otherwise, if close is above the midpoint, set state to lower rejected, bias to neutral, and count to zero; otherwise, if close equals the range low, set retest and state to lower retest; (4) if bias is upper and retested, set state to upper expansion when close is above the range high plus a configured multiple of range width; otherwise, if close is below the midpoint, set state to upper failed, bias to neutral, count to zero, and clear retest; (5) if bias is lower and retested, set state to lower expansion when close is below the range low minus the same multiple of range width; otherwise, if close is above the midpoint, set state to lower failed, bias to neutral, count to zero, and clear retest. Preserve state and counters when no rule changes them. Evaluate only on supported intraday chart timeframes.
Long: Lifecycle state changes to upper break attempt OR upper accepted OR upper retest OR upper expansion OR lower rejected OR lower failed.
Short: Lifecycle state changes to lower break attempt OR lower accepted OR lower retest OR lower expansion OR upper rejected OR upper failed.
