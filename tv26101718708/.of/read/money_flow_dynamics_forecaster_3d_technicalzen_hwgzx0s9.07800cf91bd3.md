Calculation: Centered momentum = 2 × amplification × (HMA of the selected MFI or RSI − 50)
Calculation: Signed ADX = ADX multiplied by +1 when +DI ≥ −DI, otherwise by −1
Calculation: Hull-VWMA rate = scaled percentage change in the HMA of VWMA(close) over two chart bars
Calculation: Momentum slope = change in centered momentum over the lookback (current value minus the value lookback bars ago, divided by the lookback)
Calculation: Confirmation slope = change over the lookback (current value minus the value lookback bars ago, divided by the lookback) of either the Hull-VWMA rate or, in ADX mode, the HMA of signed ADX
Long: Momentum slope > 0 AND confirmation slope > 0
Short: Momentum slope < 0 AND confirmation slope < 0
Exit: long, Momentum slope < 0 AND confirmation slope < 0
