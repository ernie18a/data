Calculation: Oscillator weight = subtract the oscillator's centerline from its value; divide a positive result by its highest value since the start of history, or a negative result by the absolute value of its lowest value since the start of history; use zero at the centerline. Average the weights of the selected data-derived oscillators and optionally multiply by the percentile rank of current volume over a configurable lookback, scaled to 0–1.
Calculation: Reference line = a selected moving average of a selected bar-data source. Weighted line = the same moving average and length applied to the source plus sign(oscillator weight) multiplied by the smaller of source × absolute oscillator weight and a configurable cap × either the source's standard deviation over the reference length or ATR over a separate lookback.
Calculation: Oscillator bull state = weighted line > reference line. Oscillator bear state = weighted line <= reference line. Strong bull state = oscillator bull state AND close > reference line AND both lines > their respective previous values. Strong bear state = oscillator bear state AND close < reference line AND both lines < their respective previous values.
Calculation: Divergence = the signs of the changes in the reference and weighted lines differ, OR, when the alternative detection mode is selected, the signs of the changes in oscillator weight and close differ.
Calculation: Divergence channel = on a divergence, start a channel from either high and low or the higher and lower of open and close if no channel exists or the previous channel has been breached; otherwise expand its top and bottom to include those sources. An upper breach occurs when a selected upper-breach source > the channel top; a lower breach occurs when a selected lower-breach source < the channel bottom. The breach sources are either low and high respectively, high and low respectively, or the same selected source from open, close, hl2, hlc3, hlcc4 and ohlc4. A breach sets the channel's direction until a new channel starts. Before a breach, an optional bullish or bearish bias occurs when the count of top-level increases is respectively greater or less than the count of bottom-level decreases.
Calculation: Strong bullish divergence-channel state = bullish divergence-channel state AND strong oscillator bull state. Strong bearish divergence-channel state = bearish divergence-channel state AND strong oscillator bear state. A transition into a state occurs when it is true on the current bar and was false on the preceding bar.
Long: Weighted line > reference line.
Short: Weighted line <= reference line.
Long: Divergence-channel direction is bullish OR unbreached channel has optional bullish bias.
Short: Divergence-channel direction is bearish OR unbreached channel has optional bearish bias.
Long: Transition into a selected oscillator bull or strong bull state OR transition into a selected bullish or strong bullish divergence-channel state; AND, if enabled, close > previous close; AND, if enabled, volume > previous volume; AND, if enabled, a divergence occurred within the configured lookback; AND, if enabled, a separately selected oscillator > its centerline.
Short: Transition into a selected oscillator bear or strong bear state OR transition into a selected bearish or strong bearish divergence-channel state; AND, if enabled, close < previous close; AND, if enabled, volume > previous volume; AND, if enabled, a divergence occurred within the configured lookback; AND, if enabled, a separately selected oscillator < its centerline.
