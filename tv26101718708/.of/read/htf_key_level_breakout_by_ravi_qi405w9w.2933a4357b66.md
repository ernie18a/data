Calculation: Key high, key low and key ATR = high, low and ATR of the last completed higher-timeframe bar.
Calculation: Break buffer = chart-timeframe ATR multiplied by a buffer parameter. A breakout requires a flat position, the current bar index at or beyond the exit bar index plus a cooldown parameter, and either the body-size parameter equals zero or abs(close - open) > chart-timeframe ATR multiplied by the body-size parameter.
Calculation: Long breakout = breakout conditions AND long entries enabled AND key high available AND no successful long entry since key high last changed AND close > key high + break buffer AND open <= key high + break buffer. Short breakout = breakout conditions AND short entries enabled AND key low available AND no successful short entry since key low last changed AND close < key low - break buffer AND open >= key low - break buffer. If both occur, select the long breakout.
Calculation: Entry candidate = the selected breakout if retests are disabled. If retests are enabled, each selected breakout sets or replaces the pending direction and pending bar; while flat, a pending long becomes a candidate when low <= current key high, and a pending short becomes a candidate when high >= current key low. Clear the pending direction when it becomes a candidate; otherwise clear it when current bar index - pending bar index > retest-window parameter. Check the retest before expiration, including on the breakout bar. A pending retest does not require the breakout conditions to remain true.
Calculation: Entry risk = chart-timeframe ATR on the candidate bar multiplied by a stop-distance parameter. Target distance = key ATR on the candidate bar multiplied by a target-distance parameter. Reward-to-risk ratio = target distance / entry risk.
Long: Long entry candidate AND entry risk > 0 AND (minimum-stop parameter <= 0 OR chart-timeframe ATR <= 0 OR entry risk >= chart-timeframe ATR multiplied by the minimum-stop parameter) AND reward-to-risk ratio >= minimum reward-to-risk parameter AND (maximum reward-to-risk parameter <= 0 OR reward-to-risk ratio <= maximum reward-to-risk parameter). Enter at close.
Short: Short entry candidate AND entry risk > 0 AND (minimum-stop parameter <= 0 OR chart-timeframe ATR <= 0 OR entry risk >= chart-timeframe ATR multiplied by the minimum-stop parameter) AND reward-to-risk ratio >= minimum reward-to-risk parameter AND (maximum reward-to-risk parameter <= 0 OR reward-to-risk ratio <= maximum reward-to-risk parameter). Enter at close.
Calculation: Long stop = entry price - entry risk initially; short stop = entry price + entry risk initially. From the bar after entry, update the favorable peak to the highest high for a long or lowest low for a short, including the current bar and initialized at entry price. If the trailing parameter > 0 AND favorable peak distance from entry / entry risk >= trailing parameter, update the long stop to the greater of its current value and peak - trailing parameter multiplied by entry risk, or the short stop to the lesser of its current value and peak + trailing parameter multiplied by entry risk. Entry risk and target distance remain fixed at entry.
Exit: long, bar index > entry bar index AND (low <= long stop OR high >= entry price + target distance OR bar index - entry bar index > maximum-holding-bars parameter). If multiple conditions occur, use stop price first, then target price, then close.
Exit: short, bar index > entry bar index AND (high >= short stop OR low <= entry price - target distance OR bar index - entry bar index > maximum-holding-bars parameter). If multiple conditions occur, use stop price first, then target price, then close.
