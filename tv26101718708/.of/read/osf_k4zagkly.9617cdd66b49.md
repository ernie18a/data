Calculation: Bullish reclaim level = Maintain a chart-bar level and its source-bar index across higher-timeframe periods. When the current chart bar's low equals the developing higher-timeframe bar's low and is below the last completed higher-timeframe bar's low: if the current bar is down or flat and the previous bar is up or flat, excluding two flat bars, set the level to the current open and its index to the current bar. Otherwise scan backward from two chart bars ago through a lookback; stop if a scanned low is below the current low. At the first up or flat bar immediately followed by a down bar, set the level and index to that down bar's open and index. Scan from that down bar forward through the current bar, replacing the level and index whenever a down bar opens above the level. If the resulting level is below the current open, replace it with the current high when the current bar is up, otherwise the current open, and set the index to the current bar. If no candidate is found, retain the existing level and index.
Calculation: Bearish reclaim level = Maintain a chart-bar level and its source-bar index across higher-timeframe periods. When the current chart bar's high equals the developing higher-timeframe bar's high and is above the last completed higher-timeframe bar's high: if the current bar is up or flat and the previous bar is down or flat, excluding two flat bars, set the level to the current open and its index to the current bar. Otherwise scan backward from two chart bars ago through a lookback; stop if a scanned high is above the current high. At the first down or flat bar immediately followed by an up bar, set the level and index to that up bar's open and index. Scan from that up bar forward through the current bar, replacing the level and index whenever an up bar opens below the level. If the resulting level is above the current open, replace it with the current low when the current bar is down, otherwise the current open, and set the index to the current bar. If no candidate is found, retain the existing level and index.
Calculation: Reclaim state = For each direction, reset the reclaimed state when its reclaim level's source-bar index changes. Set it on the first chart bar whose close is above the bullish level or below the bearish level, respectively, even if that bar does not sweep the previous higher-timeframe bar.
Calculation: Active sweep setup = At the start of a new higher-timeframe bar, create a separate bullish or bearish setup when the corresponding completed-bar sweep condition holds. Capture that completed bar's low or high, respectively, and the corresponding reclaim level, index, and reclaim state from the previous chart bar. Replace any previous setup of the same direction. The setup remains active during the two subsequent higher-timeframe bars, unless a chart-bar low falls below its captured bullish low or a chart-bar high rises above its captured bearish high; check invalidation before a new reclaim confirmation. A setup captured with its reclaim state already set is confirmed at creation; otherwise confirm it once when the chart close first exceeds its captured bullish level or falls below its captured bearish level. In the second subsequent higher-timeframe bar, also deactivate a setup whose first confirmation occurred in that bar when the previous chart close is below the lower, or above the upper, respectively, of that higher-timeframe bar's opening chart-bar open and the midpoint of the preceding completed higher-timeframe bar's high and low.
Long: At the start of a new higher-timeframe bar, the last completed higher-timeframe bar's low is below the preceding completed bar's low AND its close is above that preceding low.
Short: At the start of a new higher-timeframe bar, the last completed higher-timeframe bar's high is above the preceding completed bar's high AND its close is below that preceding high.
Long: The bullish reclaim state is set for the first time for its current source-bar index AND the developing higher-timeframe bar's low is below the last completed higher-timeframe bar's low.
Short: The bearish reclaim state is set for the first time for its current source-bar index AND the developing higher-timeframe bar's high is above the last completed higher-timeframe bar's high.
Long: An active bullish sweep setup is confirmed for the first time.
Short: An active bearish sweep setup is confirmed for the first time.
