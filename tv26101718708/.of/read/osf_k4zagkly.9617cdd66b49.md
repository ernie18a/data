Calculation: Bullish CISD level = on the chart timeframe, when the current higher-timeframe period makes a low below the previous higher-timeframe period’s low, find the swing open that preceded the down move producing that low: use the current bar’s open if it is down/equal and the prior bar is up/equal (except both equal); otherwise search backward for the nearest up/equal bar immediately before a down bar, then use the highest open among down bars from that bar through the current bar. If this level is below the current bar’s open, use the current bar’s high when it is up, otherwise its open.
Calculation: Bearish CISD level = mirror the bullish CISD level: when the current higher-timeframe period makes a high above the previous period’s high, find the swing open preceding the up move producing that high; use the current bar’s open if it is up/equal and the prior bar is down/equal (except both equal), otherwise search backward for the nearest down/equal bar immediately before an up bar, then use the lowest open among up bars from that bar through the current bar. If this level is above the current bar’s open, use the current bar’s low when it is down, otherwise its open.
Long: Higher-timeframe last completed bar’s low < the preceding completed bar’s low AND its close > the preceding completed bar’s low OR chart-timeframe close > bullish CISD level
Short: Higher-timeframe last completed bar’s high > the preceding completed bar’s high AND its close < the preceding completed bar’s high OR chart-timeframe close < bearish CISD level
