Calculation: Candidate range = highest high and lowest low over the evaluation lookback; width = highest high − lowest low.
Calculation: Compression index = 100 × (0.40 × inefficiency + 0.35 × volatility compression + 0.25 × containment). Inefficiency = 1 − min(1, absolute close change over the evaluation lookback / sum of absolute bar-to-bar close changes over that lookback), with the ratio set to 0 when the path sum is zero or unavailable. Volatility compression = clamp((1.15 − short ATR / long ATR) / 0.75, 0, 1), with the ATR ratio set to 1 when long ATR is unavailable or nonpositive; short ATR uses the evaluation lookback and long ATR uses a longer lookback. Containment = min(1, the evaluation-lookback average of an indicator that each bar's close is inside the central 90% of its own candidate range / containment threshold); use 0 for unavailable containment.
Calculation: Range state = start in seeking state and update once per completed chart bar only when the bar index exceeds the long ATR lookback and the breakout ATR is available and positive. Compression holds when the compression index is at least its threshold AND candidate width is positive AND candidate width is at most the maximum width multiple of breakout ATR. In seeking state, start a forming count at 1 when compression holds. In forming state, increment the count on each consecutive compressed bar; otherwise return to seeking. When the count reaches the minimum range duration, fix the range borders to that bar's candidate high and low, record the first forming bar, reset the edge-update count, and enter live state. In live state, test the long and short breakout conditions before updating the borders. If neither breakout occurs, independently widen the upper border to the high and the lower border to the low when the respective wick exceeds its border by no more than the edge-tolerance multiple of current breakout ATR; count each border update separately. Return to seeking if the update count exceeds its limit OR the updated width exceeds the maximum width multiple of current breakout ATR. On a breakout, freeze the borders and width and enter the corresponding breakout state. On subsequent bars, return to seeking if the close is inside the frozen range within the fakeout window; otherwise return to seeking if the high reaches the upper border plus the projection multiple of range width after an upward breakout, or the low reaches the lower border minus that multiple after a downward breakout; otherwise return to seeking when bars since breakout exceed the resolution window. The resolution window is either a configured duration or a multiple of the number of bars from the first forming bar to the breakout, subject to a cap. Apply these checks in that order, including the projection check before expiry, and do not process the new state again on the same bar.
Calculation: Volume gate = volume confirmation is disabled OR volume is unavailable OR the rolling median of volume, treating unavailable volume as zero, is zero or unavailable OR current volume is at least the volume multiple of that median.
Long: Range state is live AND close > upper range border + breakout buffer multiple × current breakout ATR AND volume gate holds.
Short: Range state is live AND close < lower range border − breakout buffer multiple × current breakout ATR AND volume gate holds.
