Calculation: Open reference = open of the last completed higher-timeframe trading-day bar, carried forward until the next higher-timeframe bar completes.
Calculation: Tolerance = max(two minimum price increments, ATR multiplied by a tolerance parameter); if ATR is unavailable, substitute ATR with twenty minimum price increments, and floor ATR at one minimum price increment.
Calculation: Reclaim up = close crosses above the open reference AND close > open reference + tolerance AND a low < open reference − 0.25 × tolerance has occurred since the current trading day began, including the current bar AND no earlier reclaim up has occurred that day. Reclaim down is the symmetric condition using a high above the reference and a close crossing below it.
Calculation: Required hold = max(1, hold parameter − 1) after the corresponding first reclaim of the current trading day if the reclaim bonus is enabled; otherwise it is the hold parameter. Count consecutive closes beyond the corresponding tolerance boundary, resetting the count at the start of each trading day.
Calculation: Acceptance up = close > open reference + tolerance AND the corresponding consecutive-close count >= required hold. Acceptance down = close < open reference − tolerance AND the corresponding consecutive-close count >= required hold.
Calculation: Rejection up event = close crosses above the open reference AND a low < open reference − tolerance occurred within the rejection lookback, including the current bar AND acceptance up is false AND reclaim up is false. Rejection down event is symmetric, using a high > open reference + tolerance and a close crossing below the reference. Each event sets its rejection direction and a remaining-bar counter to the rejection-duration parameter; on subsequent bars without either rejection event, decrement the counter to a minimum of zero. Reset the counter at the start of each trading day.
Calculation: Directional state = acceptance up if acceptance up is true, otherwise acceptance down if acceptance down is true, otherwise the most recent rejection direction if its remaining-bar counter > 0, otherwise neutral. Preserve the previous bar's state across trading-day boundaries.
Long: The chart bar is intraday AND reclaim up is true.
Long: The chart bar is intraday AND directional state is acceptance up AND the previous bar's state was not acceptance up.
Long: The chart bar is intraday AND directional state is rejection up AND the previous bar's state was not rejection up.
Short: The chart bar is intraday AND reclaim down is true.
Short: The chart bar is intraday AND directional state is acceptance down AND the previous bar's state was not acceptance down.
Short: The chart bar is intraday AND directional state is rejection down AND the previous bar's state was not rejection down.
