Calculation: Session gap = At each new session-opening reference bar, pair its open with the most recent prior-session reference bar's close, provided that bar closed no later than the session-opening bar began. Use the last completed reference-timeframe bar with no lookahead; the reference timeframe may be higher than, lower than, or equal to the chart timeframe. Replace the previous session gap even if the new gap is below the minimum size.
Long: Session gap size >= minimum gap size AND session-opening reference open <= prior-session reference close AND no chart bar whose opening time is at or after the session-opening reference bar's opening time has a high >= prior-session reference close.
Short: Session gap size >= minimum gap size AND session-opening reference open > prior-session reference close AND no chart bar whose opening time is at or after the session-opening reference bar's opening time has a low <= prior-session reference close.
