Calculation: EMA stack = four close EMAs with successively longer lengths, calculated on the chart timeframe or an optional override timeframe; for a higher override timeframe use the last completed bar, and for a lower override timeframe use the last completed lower-timeframe bar within the chart bar.
Long: Shortest stack EMA > second-shortest stack EMA AND second-shortest stack EMA > second-longest stack EMA AND second-longest stack EMA > longest stack EMA.
Short: Shortest stack EMA < second-shortest stack EMA AND second-shortest stack EMA < second-longest stack EMA AND second-longest stack EMA < longest stack EMA.
Long: Close crosses either above or below the chart-timeframe EMA of a selected price source AND close > previous close AND, if the optional stack filter is enabled, shortest stack EMA > second-shortest stack EMA AND second-shortest stack EMA > second-longest stack EMA AND second-longest stack EMA > longest stack EMA.
Short: Close crosses either above or below the chart-timeframe EMA of a selected price source AND close < previous close AND, if the optional stack filter is enabled, shortest stack EMA < second-shortest stack EMA AND second-shortest stack EMA < second-longest stack EMA AND second-longest stack EMA < longest stack EMA.
Long: Close > highest high over a lookback ending at the previous chart bar AND, if the optional stack filter is enabled, shortest stack EMA > second-shortest stack EMA AND second-shortest stack EMA > second-longest stack EMA AND second-longest stack EMA > longest stack EMA.
Short: Close < lowest low over a lookback ending at the previous chart bar AND, if the optional stack filter is enabled, shortest stack EMA < second-shortest stack EMA AND second-shortest stack EMA < second-longest stack EMA AND second-longest stack EMA < longest stack EMA.
