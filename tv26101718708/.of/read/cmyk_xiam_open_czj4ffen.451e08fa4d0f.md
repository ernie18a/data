Calculation: Relative Momentum Index = let up = EMA(max(close − close[momentum lookback], 0), smoothing lookback), down = EMA(max(close[momentum lookback] − close, 0), smoothing lookback); if down = 0, 0, else 50 − 100 / (1 + up / down). Use longer lookbacks for the primary index and shorter lookbacks for the active index.
Calculation: Force = change(SMA(close, lookback), 1) / prior-bar SMA(volume, same lookback). Fast force = shorter-lookback SMA of Force; slow force = longer-lookback SMA of Force.
Calculation: Bull phase = set active when fast force crosses above slow force while slow force < 0; set inactive when fast force crosses below slow force while slow force < 0 or when the bear phase activates; otherwise retain its prior state. Bear phase = set active when fast force crosses below slow force while slow force > 0; set inactive when fast force crosses above slow force while slow force > 0 or when the bull phase activates; otherwise retain its prior state.
Calculation: Primary-index upper event price = close when the primary Relative Momentum Index crosses below its upper threshold; primary-index lower event price = close when it crosses above its lower threshold.
Calculation: Bull-phase exit sweep = the rolling average of bull-phase exit events over a lookback is > 0 while the bull phase is inactive; a bull-phase exit event is fast force crossing below slow force while slow force < 0. Bear-phase exit sweep = the rolling average of bear-phase exit events over the same lookback is > 0 while the bear phase is inactive; a bear-phase exit event is fast force crossing above slow force while slow force > 0.
Long: active Relative Momentum Index < its lower threshold AND primary Relative Momentum Index < its lower threshold AND bull phase is active OR active Relative Momentum Index < its lower threshold AND close > SMA(close, long lookback) AND close < primary-index lower event price.
Short: active Relative Momentum Index > its upper threshold AND primary Relative Momentum Index > its upper threshold AND bear phase is active OR active Relative Momentum Index > its upper threshold AND close < SMA(close, long lookback) AND close > primary-index upper event price.
Exit: Long, the bear-phase exit sweep ended on the previous bar AND bear phase is inactive.
Exit: Short, the bull-phase exit sweep ended on the previous bar AND bull phase is inactive.
