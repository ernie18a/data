Calculation: CPR bounds = For the last completed higher-timeframe bar, set pivot = (high + low + close) / 3, midpoint = (high + low) / 2, and reflected midpoint = 2 * pivot - midpoint; the lower and upper bounds are the minimum and maximum of the two midpoints.
Calculation: Session VWAP = Cumulative sum of typical price * volume divided by cumulative volume, reset at the start of each trading session.
Calculation: Consolidation pivot = Mark a bar's high when it is the highest high over a lookback and its low when it is the lowest low over that lookback. Maintain direction as up when only the high is marked, down when only the low is marked, and otherwise unchanged. If both are marked, select the high in an up direction and the low otherwise; if only one is marked, select it. The pivot is the most extreme selected value in the current uninterrupted direction, looking back up to a limit.
Calculation: Consolidation zone = Maintain a count initially zero. When the consolidation pivot changes, increment the count if the prior count is positive and the new pivot is within the existing zone inclusive; otherwise reset it to zero. When the pivot does not change, increment the count. When the count first reaches a minimum length, set the zone high and low to the highest high and lowest low over that length. While the count exceeds that length, expand the zone to include each bar's high and low. Retain the last zone until a new zone is initialized.
Long: The close of a still-forming higher-timeframe bar > its CPR upper bound.
Short: The close of a still-forming higher-timeframe bar < its CPR lower bound.
Long: Close >= session VWAP.
Short: Close < session VWAP.
Long: Session open or current close > CPR upper bound AND session open or current close > first resistance, using the same price in both comparisons; first resistance = 2 * pivot - low of the last completed higher-timeframe bar.
Short: Session open or current close < CPR lower bound AND session open or current close < first support, using the same price in both comparisons; first support = 2 * pivot - high of the last completed higher-timeframe bar.
Long: Consolidation pivot changes AND prior consolidation count > minimum consolidation length AND consolidation pivot > prior zone high.
Short: Consolidation pivot changes AND prior consolidation count > minimum consolidation length AND consolidation pivot < prior zone low.
