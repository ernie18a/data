Calculation: Structure = Confirm pivot highs and lows using the same number of bars on each side; retain the latest confirmed pivot of each kind. Test breaks before incorporating pivots confirmed on the current bar. An upward break requires close > retained pivot high and previous close <= the pivot high retained on the previous bar. A downward break requires close < retained pivot low and previous close >= the pivot low retained on the previous bar. Initialize structure direction as neutral and both continuation counts as zero. On an upward break, increment the bullish continuation count if structure is bullish; otherwise, if the bearish continuation count >= its required minimum, record an upward reversal, set structure bullish, and reset both counts. On a downward break without an upward break on the same bar, increment the bearish continuation count if structure is bearish; otherwise, if the bullish continuation count >= its required minimum, record a downward reversal, set structure bearish, and reset both counts.
Calculation: Market score = Weighted sum of direction, quality, participation, and cost scores. Direction score is highest when bullish structure agrees with close > KAMA or bearish structure agrees with close <= KAMA, intermediate when structure is directional but disagrees, and lowest when structure is neutral. Quality score is smoothed Kaufman efficiency ratio divided by its trending threshold, capped at its maximum. Effort is volume divided by its simple moving average, or zero if that average is not positive; result is absolute close-to-close change divided by ATR, or zero if ATR is not positive. In priority order, participation score is highest for effort >= high-effort threshold AND result >= high-result threshold, lowest for effort >= high-effort threshold AND result <= low-result threshold, second-lowest for effort <= low-effort threshold AND result >= high-result threshold, and intermediate otherwise. Cost score is the maximum score minus the rolling percentile rank of the OHLC EDGE effective spread estimator, or a neutral score when that rank is unavailable. Direction and quality have equal weights, participation has a smaller weight, and cost has the smallest weight.
Calculation: Signal eligibility = Bars since the most recent eligible long or short signal >= cooldown AND ((market score >= minimum signal score AND market score >= minimum non-C-grade score) OR C-grade visibility is enabled). Update the most recent signal bar only when an eligible long or short signal occurs.
