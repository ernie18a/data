Calculation: Anchored VWAP = cumulative sum of typical price × volume divided by cumulative volume, resetting at the start of the selected calendar anchor period; typical price is (high + low + close) / 3. If cumulative volume is zero, use typical price.
Calculation: VWAP bands = anchored VWAP ± a configurable multiplier × sqrt(max(cumulative sum of volume × typical price² / cumulative volume − anchored VWAP², 0)), using the same anchor; use zero standard deviation if cumulative volume is zero. The first, second and third band pairs have separately configurable multipliers.
Calculation: VWAP slope percent = 100 × (current anchored VWAP − anchored VWAP at the selected lookback) / anchored VWAP at that lookback; use zero if the lookback VWAP is unavailable.
Calculation: VWAP deviation in ATR = (close − anchored VWAP) / ATR; use zero if ATR is not positive.
Long: Position is flat AND, in trend mode, close crosses above the selected anchored VWAP, first upper band or second upper band AND, if enabled, volume > its SMA × threshold AND, if enabled, 100 × ATR / close > threshold AND, if enabled, 100 × (first upper band − first lower band) / close > threshold AND, if enabled, VWAP slope percent > positive threshold AND, if RSI confluence is selected, RSI > long threshold OR, if EMA confluence is selected, close > EMA; no confluence condition applies when none is selected.
Short: Position is flat AND, in trend mode, close crosses below the selected anchored VWAP, first lower band or second lower band AND, if enabled, volume > its SMA × threshold AND, if enabled, 100 × ATR / close > threshold AND, if enabled, 100 × (first upper band − first lower band) / close > threshold AND, if enabled, VWAP slope percent < negative threshold AND, if RSI confluence is selected, RSI < short threshold OR, if EMA confluence is selected, close < EMA; no confluence condition applies when none is selected.
Long: Position is flat AND, in mean reversion mode, the selected trigger is satisfied: close < selected lower band OR close crosses below selected lower band OR low < selected lower band AND close > selected lower band AND, if enabled, volume > its SMA × threshold AND, if enabled, 100 × ATR / close > threshold AND, if enabled, 100 × (first upper band − first lower band) / close > threshold AND, if enabled, ADX < threshold AND absolute VWAP deviation in ATR ≤ threshold AND, if RSI confluence is selected, RSI crosses above the oversold threshold OR, if EMA confluence is selected, close > EMA; no confluence condition applies when none is selected. Select the lower band from the first, second or third pair.
Short: Position is flat AND, in mean reversion mode, the selected trigger is satisfied: close > selected upper band OR close crosses above selected upper band OR high > selected upper band AND close < selected upper band AND, if enabled, volume > its SMA × threshold AND, if enabled, 100 × ATR / close > threshold AND, if enabled, 100 × (first upper band − first lower band) / close > threshold AND, if enabled, ADX < threshold AND absolute VWAP deviation in ATR ≤ threshold AND, if RSI confluence is selected, RSI crosses below the overbought threshold OR, if EMA confluence is selected, close < EMA; no confluence condition applies when none is selected. Select the upper band from the first, second or third pair.
Calculation: Initial stop = signal-bar close minus the selected stop distance for a long, or plus it for a short. The distance is either signal-bar ATR × multiplier or the absolute difference between signal-bar close and the signal-bar lower band for a long or upper band for a short; use the first band pair in trend mode and the third in mean reversion mode.
Calculation: Break-even stop = initial stop until the optional break-even trigger occurs; thereafter use the greater of initial stop and entry price for a long, or the lesser for a short. The trigger is high ≥ entry price + signal-bar ATR × multiplier for a long, or low ≤ entry price − signal-bar ATR × multiplier for a short.
Calculation: Profit target = anchored VWAP when the VWAP target is selected or in mean reversion mode; otherwise use the second upper band for a trend long or second lower band for a trend short. Use the signal-bar target when target locking is enabled; otherwise update it each bar.
Exit: long, low ≤ break-even stop OR high ≥ profit target.
Exit: short, high ≥ break-even stop OR low ≤ profit target.
