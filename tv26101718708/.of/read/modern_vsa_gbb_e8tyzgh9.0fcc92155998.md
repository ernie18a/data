Calculation: Accepted bars = all chart bars, or only bars inside the configured session when the session filter is enabled; all calculations below use accepted bars unless stated otherwise.
Calculation: Relative volume = current volume divided by the median volume of prior accepted bars at the same time of day, using a capped lookback, when time-of-day normalization is enabled and the minimum same-time history exists; otherwise current volume divided by the mean volume of a fixed number of prior accepted bars. Time-of-day normalization is disabled in classic mode and on daily-or-higher charts.
Calculation: Percentile rank = 100 × (number of values below the current value + half the number equal to it) / number of values, using a fixed window of prior accepted bars. Volume rank ranks relative volume; spread rank ranks (high - low) / previous accepted bar's ATR. Both use the same window length.
Calculation: Leg = (previous accepted close - accepted close a fixed lookback before it) / previous accepted bar's ATR. ATR is Wilder's moving average of true range on accepted bars, seeded with the mean of its initial true ranges; true range uses the previous accepted close.
Calculation: Close location = (close - low) / (high - low), or one-half when high equals low.
Calculation: No supply = close < previous accepted close AND spread rank <= low spread threshold AND volume rank <= low volume threshold AND volume < each of the two preceding accepted volumes.
Calculation: No demand = close > previous accepted close AND spread rank <= low spread threshold AND volume rank <= low volume threshold AND volume < each of the two preceding accepted volumes.
Calculation: Spring = low < the minimum low of a fixed number of prior accepted bars AND close location >= upper spring threshold AND volume rank >= spring volume threshold.
Calculation: Upthrust = high > the maximum high of the same number of prior accepted bars used for Spring AND close location <= lower upthrust threshold AND volume rank >= spring volume threshold.
Calculation: Bull absorption = volume rank >= absorption volume threshold AND spread rank <= absorption spread threshold AND close location >= midpoint AND leg <= negative leg threshold.
Calculation: Bear absorption = volume rank >= absorption volume threshold AND spread rank <= absorption spread threshold AND close location <= midpoint AND leg >= positive leg threshold.
Calculation: Bull climax = volume rank >= climax volume threshold AND spread rank >= climax spread threshold AND close < previous accepted close AND close location >= lower climax threshold AND leg <= negative leg threshold.
Calculation: Bear climax = volume rank >= climax volume threshold AND spread rank >= climax spread threshold AND close > previous accepted close AND close location <= upper climax threshold AND leg >= positive leg threshold.
Calculation: Threshold relationships = climax volume threshold > absorption volume threshold > spring volume threshold > low volume threshold; climax spread threshold > absorption spread threshold > low spread threshold; upper spring threshold > upper climax threshold > midpoint > lower climax threshold > lower upthrust threshold; positive and negative leg thresholds have equal magnitude and opposite signs.
Calculation: Selected pattern = the last true pattern in this priority order: No supply, No demand, Spring, Upthrust, Bull absorption, Bear absorption, Bull climax, Bear climax. Select before applying pattern-visibility or trend filters. A pattern is eligible only when volume rank, spread rank, and leg are available and the previous accepted ATR is nonzero.
Calculation: Higher-timeframe EMA slope = EMA of higher-timeframe closes on the last completed higher-timeframe bar minus its value on the preceding higher-timeframe bar; calculate it using all bars, including bars outside the optional session.
Long: Current bar is accepted AND selected pattern is No supply, Spring, Bull absorption, or Bull climax AND the selected pattern is enabled AND (higher-timeframe trend filter is disabled OR higher-timeframe EMA slope is unavailable OR higher-timeframe EMA slope > 0).
Short: Current bar is accepted AND selected pattern is No demand, Upthrust, Bear absorption, or Bear climax AND the selected pattern is enabled AND (higher-timeframe trend filter is disabled OR higher-timeframe EMA slope is unavailable OR higher-timeframe EMA slope < 0).
