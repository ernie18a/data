Calculation: Session open = open of the chart bar starting at the configured session time, reset each local calendar day.
Calculation: Rejection candle = the last completed bar of a configurable timeframe equal to or higher than the chart timeframe; evaluate each rejection candle once.
Calculation: Body = absolute value of rejection candle close minus open; upper wick = high minus maximum of open and close; lower wick = minimum of open and close minus low.
Calculation: Doji = rejection candle high > low AND body / (high - low) <= configured fraction, OR rejection candle high = low AND configured fraction >= 1.
Long: Session open is available AND rejection candle start time >= session start AND rejection candle start time <= configured cutoff AND (first-only mode is disabled OR no prior long rejection has been marked this session) AND (wick filter is disabled OR lower wick > body) AND ((doji is false AND (candle-color filter is disabled OR close > open) AND open >= session open AND low < session open AND close > session open) OR (doji is true AND larger-wick doji mode is enabled AND low <= session open AND high >= session open AND lower wick > upper wick AND close > session open)).
Short: Session open is available AND rejection candle start time >= session start AND rejection candle start time <= configured cutoff AND (first-only mode is disabled OR no prior short rejection has been marked this session) AND (wick filter is disabled OR upper wick > body) AND ((doji is false AND (candle-color filter is disabled OR close < open) AND open <= session open AND high > session open AND close < session open) OR (doji is true AND larger-wick doji mode is enabled AND low <= session open AND high >= session open AND upper wick > lower wick AND close < session open)).
