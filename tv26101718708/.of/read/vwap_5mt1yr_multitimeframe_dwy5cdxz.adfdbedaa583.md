Calculation: Anchored VWAP = cumulative sum of source price × volume divided by cumulative volume, reset at each new anchor period; source price is a selectable OHLC-derived price, defaulting to (high + low + close) / 3. Calculate separate VWAPs for multiple shorter and longer anchor periods. For the shorter anchor periods and one longer anchor period, use chart bars. For the other longer anchor periods, use bars of a configured calculation timeframe; longer anchor periods may share the same calculation timeframe. When that timeframe is lower than the chart timeframe, use the last completed lower-timeframe bar within each chart bar. When it is higher, use the last completed higher-timeframe bar on historical bars and the still-forming higher-timeframe bar in real time.
Long: Close >= any anchored VWAP
Short: Close < any anchored VWAP
