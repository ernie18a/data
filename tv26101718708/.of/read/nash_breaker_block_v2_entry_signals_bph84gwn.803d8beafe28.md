Calculation: Session opens = Open prices of lower-timeframe bars at three ordered configurable session anchor times. At the first anchor, reset all three levels; retain each subsequent level until the next reset. Use completed lower-timeframe bars available within the current chart bar.
Calculation: Structure levels = Most recently confirmed chart-timeframe pivot high and pivot low, using the same number of bars on each side. Replace the corresponding level when a new pivot is confirmed. On confirmation, mark the high level used if the chart close is above it and the low level used if the chart close is below it. Otherwise mark it unused. Mark a level used on its first break, even if no signal results.
Calculation: Fair value gaps = On the first chart bar after a higher-timeframe bar completes, compare that completed bar with the higher-timeframe bar two bars before it. A bullish gap has completed-bar low > earlier-bar high, with those prices as top and bottom; a bearish gap has completed-bar high < earlier-bar low, with those prices as bottom and top. Record its age from the chart bar on which the completed higher-timeframe bar closed. A gap is touched when a chart bar has high >= gap bottom AND low <= gap top; for a decision, count only touches on earlier chart bars.
Long: At the third session anchor, first session open < second session open AND second session open < third session open.
Short: At the third session anchor, first session open >= second session open AND second session open >= third session open.
Long: Close > higher-timeframe EMA; use its last completed bar on historical data.
Short: Close <= higher-timeframe EMA; use its last completed bar on historical data.

Short: An unused structure low exists AND the selected break price, chart low in wick mode or chart close in close mode, < structure low AND a fair value gap exists with age > 0 AND age <= maximum age AND gap bottom >= structure low AND gap bottom - structure low <= maximum distance AND (direction matching disabled OR gap is bearish) AND (untouched-gap filter disabled OR gap has no earlier touch) AND (EMA filter disabled OR selected break price < EMA of the last completed higher-timeframe bar).

Short: At least one available session open has previous chart close >= that open AND selected break price < that open, using chart low in wick mode or chart close in close mode AND (EMA filter disabled OR chart close < higher-timeframe EMA using its last completed bar on historical data).
