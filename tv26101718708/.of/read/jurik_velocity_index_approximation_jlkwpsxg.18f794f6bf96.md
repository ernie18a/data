Calculation: VEL = Apply the Jurik filter below to momentum. Momentum = close minus close from the momentum lookback bars earlier; optionally normalize as momentum / ATR × 100. ATR uses the ATR lookback. The Jurik filter uses beta = 0.45 × (length − 1) / (0.45 × (length − 1) + 2), alpha = beta^power, and phase ratio = phase / 100 + 1.5. Recursively: e0 = (1 − alpha) × input + alpha × previous e0; e1 = (input − e0) × (1 − beta) + beta × previous e1; e2 = (e0 + phase ratio × e1 − previous output) × (1 − alpha)^2 + alpha^2 × previous e2; output = previous output + e2. Initialize previous states to zero, using the current input where the source does so.
Calculation: Confirmed VEL pivot low/high = a VEL low/high with the configured number of lower and higher bars on each side; confirm after the higher bars have completed.
Long: VEL crosses above 0 OR close at the latest confirmed VEL pivot low is below close at the preceding confirmed VEL pivot low AND VEL at the latest pivot low is above VEL at the preceding pivot low OR VEL ≥ 0
Short: VEL crosses below 0 OR high at the latest confirmed VEL pivot high is above high at the preceding confirmed VEL pivot high AND VEL at the latest pivot high is below VEL at the preceding pivot high OR VEL < 0
