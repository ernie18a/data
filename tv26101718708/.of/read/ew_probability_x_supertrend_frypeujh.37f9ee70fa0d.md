Calculation: SuperTrend direction = Choose a price source from close, (high + low) / 2, (high + low + close) / 3, or (open + high + low + close) / 4. Set raw upper and lower bands to the source plus and minus an ATR multiple. On each bar, set the upper band to its raw value if that value is below the previous upper band or the previous close is above the previous upper band; otherwise retain the previous upper band. Set the lower band to its raw value if that value is above the previous lower band or the previous close is below the previous lower band; otherwise retain the previous lower band. Initialize both bands to their raw values and direction to long. If the previous SuperTrend line equals the previous upper band, direction is long when close is above the current upper band and short otherwise. Otherwise, direction is short when close is below the current lower band and long otherwise. The SuperTrend line is the lower band in the long direction and the upper band in the short direction.
Long: SuperTrend direction changes from short to long.
Short: SuperTrend direction changes from long to short.
