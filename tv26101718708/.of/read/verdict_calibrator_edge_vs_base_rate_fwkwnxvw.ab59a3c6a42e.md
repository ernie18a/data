Calculation: Direction = the selected signal mode’s current direction: (1) source slope: +1 if the selected data field exceeds its previous value, -1 if lower, otherwise 0; (2) source mean: +1 if the selected data field exceeds its SMA, -1 if below, otherwise 0; (3) source level: +1 if the selected data field exceeds a threshold, -1 if below, otherwise 0; (4) EMA: +1 if the shorter-period close EMA exceeds the longer-period close EMA, -1 if below, otherwise 0; (5) MACD: +1 if the MACD line exceeds its signal line, -1 if below, otherwise 0; (6) Supertrend: +1 in an uptrend, -1 in a downtrend; (7) RSI midpoint: +1 if close RSI exceeds its scale midpoint, -1 if below, otherwise 0; (8) RSI reversal: initialize at 0, set to +1 when RSI rises from below the oversold threshold to at least that threshold, set to -1 when RSI falls from above the overbought threshold to at most that threshold, otherwise retain its previous value; (9) stochastic: +1 if smoothed stochastic %K exceeds its SMA signal line, -1 if below, otherwise 0; (10) breakout: initialize at 0, set to +1 if close exceeds the highest high over the lookback ending at the previous bar, set to -1 if close is below the lowest low over that lookback, otherwise retain its previous value; (11) VWAP: +1 if close exceeds session VWAP of typical price, -1 if below, otherwise 0; (12) Bollinger fade: initialize at 0, set to +1 if close is below the lower Bollinger Band, set to -1 if close is above the upper Bollinger Band, otherwise retain its previous value; (13) deterministic control: let x = sin(zero-based bar index × 12.9898) × 43758.5453; direction is +1 if x - floor(x) > 0.5, otherwise -1.
Long: Direction = +1 AND previous bar’s Direction != +1 AND bars since the most recent accepted long or short decision >= minimum gap.
Short: Direction = -1 AND previous bar’s Direction != -1 AND bars since the most recent accepted long or short decision >= minimum gap.
