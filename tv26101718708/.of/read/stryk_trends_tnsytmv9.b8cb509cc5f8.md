Calculation: Reference line = blend a recursive volume-weighted price with an EMA of the same price and lookback; price is (high + low + close) / 3; recursive value starts at price and thereafter equals previous recursive value plus weight times (price minus previous recursive value), where weight is min(volume times a gain divided by the rolling sum of volume, 1), or zero if that sum is not positive.
Calculation: Stretch = (close - reference line) / master ATR, or zero when master ATR is not positive.
Calculation: Smoothed stretch = EMA of stretch, optionally unsmoothed.
Calculation: Coil rank = 100 times (coil volatility - its rolling minimum) / (its rolling maximum - its rolling minimum), or 50 when the maximum is not greater than the minimum; coil volatility is the SMA of true range using its own lookback.
Calculation: Coil release = coil rank exceeds its threshold after the previous bar's rank was at or below the threshold. Count bars from the release bar as zero, and permit at most one coil fade per release.
Calculation: Reversal leg = track the maximum and minimum stretch since the latest bar with absolute stretch below a reset threshold; on that reset bar set both extremes to zero and clear both reversal-fired flags. After calculating the extremes, set each side's flag when its reversal fires.
Calculation: Long reversal count = number of these conditions true on the current bar: previous RSI is at or below an oversold threshold AND current RSI exceeds previous RSI; previous low is at or below the previous reference line minus a reversal-band multiple of master ATR AND current close is above the current lower band; a pivot low is confirmed on the current bar using specified left and right bars; volume is at least a specified multiple of its current volume SMA.
Calculation: Short reversal count = number of these conditions true on the current bar: previous RSI is at or above an overbought threshold AND current RSI is below previous RSI; previous high is at or above the previous reference line plus a reversal-band multiple of master ATR AND current close is below the current upper band; a pivot high is confirmed on the current bar using specified left and right bars; volume is at least a specified multiple of its current volume SMA.
Calculation: Volume confirmation = after a coil fade, save the preceding bar's volume SMA as baseline and its direction; replace any pending confirmation on a new coil fade. From the next bar through the confirmation window inclusive, fire at most once if baseline is positive and the current recent-volume SMA is at least baseline times a specified surge factor.
Calculation: Candle direction = sign of smoothed stretch outside a symmetric neutral threshold, otherwise zero. An enabled coil fade, reversal, volume confirmation, or directional volume spike overrides this direction if its direction differs from the current direction; simultaneous opposite overrides resolve short. Keep the override until a later bar has stretch above zero for a long override or below zero for a short override, or the maximum hold expires; a fresh opposite override replaces it.
Calculation: Trailing loss = a multiplier times the SMA of true range, using either the chart timeframe's current bar or the last completed bar of a higher timeframe. The primary and optional reference trails use separately configurable lengths and multipliers.
Calculation: Always-on trail = initialize the previous trail to current close if unavailable. If current and previous closes are both above the previous trail, use max(previous trail, close - trailing loss); if both are below it, use min(previous trail, close + trailing loss); otherwise use close - trailing loss when close is above the previous trail, and close + trailing loss otherwise. Trail direction is long when close is above the resulting trail, otherwise short.
Calculation: Signal-armed trail = on an allowed coil fade, arm or rearm in its direction at close minus trailing loss for long or close plus trailing loss for short. On later bars without an allowed coil fade, while armed, set the long trail to max(previous trail, close - trailing loss), or the short trail to min(previous trail, close + trailing loss); disarm when close is below the previous long trail or above the previous short trail. A new allowed coil fade takes precedence over an exit.
Calculation: Band-opening gap = absolute difference between current and previous primary trail on an armed bar where trail direction changes or the trail re-arms. Compare it with the average of the preceding configurable number of valid band-opening gaps, requiring a configurable minimum count before comparison; add the current gap only after the comparison.
