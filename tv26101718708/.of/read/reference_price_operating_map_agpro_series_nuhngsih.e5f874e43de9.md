Calculation: Reference = the open of a still-forming reference-period bar, or the close of the last completed bar of the shortest reference period. Use three ordered reference periods: short, medium, and long; each is equal to or higher than the chart timeframe. Reset each open reference at the start of its own period and the previous-close reference at the start of the shortest period.
Calculation: Reference state = independently for each reference, initialize and reset the state to untouched and the confirmation count to zero at its period boundary. On each completed chart bar, leave the state unchanged if ATR is nonpositive or the absolute distance from close to reference exceeds the far-distance ATR multiple. Otherwise, define touch as absolute close-to-reference distance at most the touch ATR multiple, OR low at most reference plus that distance AND high at least reference minus that distance. Define above as close greater than reference. Define rejection as (max(high - low, minimum price tick) - abs(close - open)) / max(high - low, minimum price tick) greater than a wick-ratio threshold AND absolute close-to-reference distance greater than a fraction of the touch distance. From untouched, touch changes state to first touch and stores above as the reference side. From first touch or tested, touch AND rejection changes state to rejected and stores above as the side; no touch AND above equal to the stored side changes state to held and resets the count; no touch AND above unequal to the stored side increments the count and changes state to reclaimed, stores above as the side, and resets the count when strict confirmation is disabled or the count reaches its confirmation threshold. From held, reclaimed, or rejected, touch changes state to tested and resets the count; otherwise above unequal to the stored side increments the count and, subject to the same confirmation rule, changes state to reclaimed, stores above as the side, and resets the count; otherwise reset the count. In all other cases retain the state, side, and count.
Long: An enabled reference state is held or reclaimed AND its stored side is above.
Short: An enabled reference state is held or reclaimed AND its stored side is not above.
