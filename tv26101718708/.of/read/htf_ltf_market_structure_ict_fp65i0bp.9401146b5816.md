Calculation: Structure levels = For each stream independently, let n be its fractal length and p = floor(n / 2). On each completed stream bar, confirm a high pivot if highs strictly rise for p consecutive bars into the bar p bars ago, then strictly fall for p consecutive bars, and that pivot high equals the highest high of the latest n bars. Confirm a low pivot if lows strictly fall for p consecutive bars into the bar p bars ago, then strictly rise for p consecutive bars, and that pivot low equals the lowest low of the latest n bars. Each confirmed pivot replaces the corresponding stored level and marks it unbroken. A level becomes broken after its first qualifying close cross; it remains broken until replaced.
Calculation: Bullish structure break = On a completed stream bar, the latest high pivot level is unbroken AND close > that level AND previous close <= that same level; then mark the level broken.
Calculation: Bearish structure break = On a completed stream bar, the latest low pivot level is unbroken AND close < that level AND previous close >= that same level; then mark the level broken.
Calculation: Higher-timeframe break series = Calculate structure breaks independently on higher-timeframe bars using their last completed bars, and carry each completed higher-timeframe break result forward across chart bars until the next higher-timeframe result is available.
Long: Chart-timeframe bullish structure break = true OR higher-timeframe bullish break series = true AND its previous chart-bar value = false
Short: Chart-timeframe bearish structure break = true OR higher-timeframe bearish break series = true AND its previous chart-bar value = false
