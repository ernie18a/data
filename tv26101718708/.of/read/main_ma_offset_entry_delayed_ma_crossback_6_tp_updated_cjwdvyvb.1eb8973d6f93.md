Calculation: Main line = selectable EMA, SMA, WMA or VWMA of close, or session-anchored VWAP of (high + low + close) / 3.
Calculation: Slope = linear regression slope of close over a configurable lookback on a configurable timeframe. On historical bars, use the last completed higher-timeframe bar or, for a lower timeframe, the last completed intrabar; the timeframe may also equal the chart timeframe.
Calculation: Previous daily candle = the last completed daily bar, a higher timeframe than the chart timeframe when the chart is intraday.
Long: While flat, close crosses above the main line within the configured date range and, if weekly closing is enabled, before the Friday cutoff AND, if the slope filter is enabled, slope > 0, otherwise if the daily filter is enabled, previous daily close > previous daily open. Save that bar's low and main line plus the entry offset; enter at the saved stop-entry level when price reaches it on a subsequent bar. Replace the setup on a later qualifying long cross; cancel it on a close crossing below the main line, a qualifying short setup, a weekly close or completion of a trade. The filters and date range apply when the setup is created, not when it fills.
Short: While flat, close crosses below the main line within the configured date range and, if weekly closing is enabled, before the Friday cutoff AND, if the slope filter is enabled, slope < 0, otherwise if the daily filter is enabled, previous daily close < previous daily open. Save that bar's high and main line minus the entry offset; enter at the saved stop-entry level when price reaches it on a subsequent bar. Replace the setup on a later qualifying short cross; cancel it on a close crossing above the main line, a qualifying long setup, a weekly close or completion of a trade. The filters and date range apply when the setup is created, not when it fills.
Exit: Long, if the initial stop is enabled, price reaches the saved low of the entry setup bar.
Exit: Short, if the initial stop is enabled, price reaches the saved high of the entry setup bar.
Exit: Long, price reaches entry price plus any of six independently configurable profit distances; exit one of six equal position units at each target.
Exit: Short, price reaches entry price minus any of six independently configurable profit distances; exit one of six equal position units at each target.
Exit: Long, if cross-back protection is enabled, high has reached entry price plus the activation distance since entry AND close crosses below the main line; exit all remaining units.
Exit: Short, if cross-back protection is enabled, low has reached entry price minus the activation distance since entry AND close crosses above the main line; exit all remaining units.
Exit: Long OR short, if weekly closing is enabled, the bar's opening time in the configured timezone is Friday at or after the configured cutoff and this is the first such bar since the weekly-close flag was reset; exit all remaining units. Reset the flag on bars outside that period.
