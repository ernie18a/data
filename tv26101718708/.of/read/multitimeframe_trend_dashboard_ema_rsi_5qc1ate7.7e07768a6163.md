Calculation: Per-timeframe score = +1 if fast EMA > slow EMA, -1 if fast EMA < slow EMA, otherwise 0; plus +1 if close > slow EMA, -1 if close < slow EMA, otherwise 0; plus +1 if RSI > 50, -1 if RSI < 50, otherwise 0. Fast EMA uses a shorter length than slow EMA. Use enabled, valid selected timeframes equal to or higher than the chart timeframe; sample each timeframe’s last completed bar by default, or its still-forming bar in live mode.
Long: On any enabled, valid selected timeframe, fast EMA > slow EMA OR close > slow EMA OR RSI > 50 OR per-timeframe score > 0; OR the number of timeframes with score >= the trend threshold exceeds the number with score <= the negative trend threshold
Short: On any enabled, valid selected timeframe, fast EMA < slow EMA OR close < slow EMA OR RSI < 50 OR per-timeframe score < 0; OR the number of timeframes with score <= the negative trend threshold exceeds the number with score >= the trend threshold
