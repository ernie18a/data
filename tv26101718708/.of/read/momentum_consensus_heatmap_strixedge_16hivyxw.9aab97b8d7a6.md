Calculation: Oscillators = RSI of close; stochastic RSI, calculated as the SMA of the stochastic of RSI of close using the same lookback for RSI and stochastic; SMA-smoothed stochastic of close, high, and low; CCI of close; Williams %R; and MFI of typical price. Each oscillator has its own lookback and thresholds. Evaluate each on four independently selected timeframes: use the last completed bar for higher timeframes, the last completed lower-timeframe bar within the chart bar for lower timeframes, and the chart bar for the chart timeframe.
Calculation: Overbought count and oversold count = for each oscillator, the number of its four timeframe values respectively greater than or equal to its overbought threshold or less than or equal to its oversold threshold; unavailable values do not count.
Calculation: Overbought consensus count and oversold consensus count = respectively, the number of oscillators whose overbought count or oversold count reaches the minimum timeframe consensus.
Long: Any oscillator value <= its oversold threshold AND that value < its overbought threshold.
Short: Any oscillator value >= its overbought threshold.
Long: Any oscillator's oversold count >= the minimum timeframe consensus AND its overbought count < the minimum timeframe consensus.
Short: Any oscillator's overbought count >= the minimum timeframe consensus.
Long: Oversold consensus count >= the minimum indicator consensus AND (trend filter disabled OR close > chart-timeframe EMA) AND (overbought consensus count < the minimum indicator consensus OR (trend filter enabled AND close >= chart-timeframe EMA)).
Short: Overbought consensus count >= the minimum indicator consensus AND (trend filter disabled OR close < chart-timeframe EMA).
Long: Oversold consensus count >= the minimum indicator consensus AND (trend filter disabled OR close > chart-timeframe EMA) AND (previous bar's oversold consensus count < the minimum indicator consensus OR (trend filter enabled AND previous close <= previous chart-timeframe EMA)).
Short: Overbought consensus count >= the minimum indicator consensus AND (trend filter disabled OR close < chart-timeframe EMA) AND (previous bar's overbought consensus count < the minimum indicator consensus OR (trend filter enabled AND previous close >= previous chart-timeframe EMA)).
