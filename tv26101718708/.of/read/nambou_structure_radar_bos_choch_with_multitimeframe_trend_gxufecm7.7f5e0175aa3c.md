Calculation: Confirmed swing high and low = A pivot high or low with the same number of bars on each side, confirmed only after the right-side bars have completed. For equal extrema, use the most recent occurrence. Compare each confirmed swing with the preceding confirmed swing of the same type.
Calculation: Structure trend = Initially neutral. On each completed bar, replace each live swing with any newly confirmed swing of the same type and mark it unbroken. If the selected upward source is above the unbroken live swing high, set trend bullish and mark that high broken. Then, if the selected downward source is below the unbroken live swing low, set trend bearish and mark that low broken. The sources are either close for both directions or high for upward breaks and low for downward breaks. Calculate separately on the chart timeframe and on each selected higher timeframe; use the last completed higher-timeframe bar.
Long: Newly confirmed swing high > preceding swing high OR newly confirmed swing low >= preceding swing low
Short: Newly confirmed swing high <= preceding swing high OR newly confirmed swing low < preceding swing low
Long: Selected upward source > unbroken live swing high
Short: Selected downward source < unbroken live swing low
Long: Chart-timeframe structure trend = bullish OR last completed higher-timeframe structure trend = bullish
Short: Chart-timeframe structure trend = bearish OR last completed higher-timeframe structure trend = bearish
Long: Number of bullish structure trends across the chart and selected higher timeframes > number of bearish structure trends across those timeframes
Short: Number of bearish structure trends across the chart and selected higher timeframes > number of bullish structure trends across those timeframes
