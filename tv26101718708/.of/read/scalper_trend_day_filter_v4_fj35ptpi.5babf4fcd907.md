Calculation: Session = bars whose time is within the configured session; opening range = highest high and lowest low during the initial configured session window, fixed when that window ends
Calculation: Long acceptance = opening range is complete AND the lowest close over the configured acceptance lookback is above opening-range high; short acceptance = opening range is complete AND the highest close over that lookback is below opening-range low
Calculation: Relative volume = volume / SMA(volume, long lookback); strong volume = volume >= SMA(volume, long lookback) + configured multiplier × standard deviation(volume, same lookback); moderate level volume = volume >= 1.2 × SMA(volume, same lookback)
Calculation: Long/short level volume = volume on the most recent bar whose close is within the configured percentage of opening-range high/low, respectively; level-volume score = 2 if it meets strong volume, else 1 if it meets moderate level volume, else 0
Calculation: Daily ATR = ATR on a higher timeframe, using the last completed bar; ATR available = absolute distance from session opening price to current close < configured percentage of daily ATR
Calculation: Static bullish/bearish context = close above previous daily high / below previous daily low, using the last completed daily bar; neutral context = neither
Calculation: Session VWAP = cumulative volume-weighted typical price (high+low+close)/3 since session start; prior-session VWAP = the final VWAP of the preceding session
Calculation: Session POC = price midpoint of the fixed volume bucket with greatest accumulated session volume; prior-session POC = preceding session's final POC. Use 50 equal buckets across 1.5 × prior daily range, starting 10% of that range below prior daily low; if prior daily range is unavailable, use 1.5 × daily ATR as the range fallback.
Calculation: Effective bullish/bearish context = static bullish/bearish context OR (static neutral context AND close above/below all available current session VWAP, current session POC, and prior-session POC)
Calculation: Tape ratio = bullish volume / (bearish volume + absorbed volume) when bullish volume is greater; otherwise negative bearish volume / (bullish volume + absorbed volume) when bearish volume is greater; otherwise 0. For a lower timeframe, use lower bars within the chart bar, comparing adjacent closes and assigning each earlier bar's volume to bullish, bearish, or absorbed when closes rise, fall, or stay equal; if fewer than two lower bars are available, classify the chart bar by close versus open. Tape ratio uses 1-minute bars when available; on a higher chart timeframe these are lower bars, using completed bars.
Calculation: Bullish/bearish tape score = 2 if tape ratio >= 3 / <= -3, else 1 if >= configured positive threshold / <= its negative, else 0; tape defended = absorbed volume is at least the configured percentage of total classified tape volume
Calculation: Breakout quality score, long/short = bullish/bearish tape score + 1 if 1-minute MACD (fast EMA minus slow EMA) is positive/negative + 1 if 1-minute RSI is at or above configured overbought / at or below configured oversold threshold + 1 if corresponding level volume is strong + 1 if close is above/below both prior-session POC and prior-session VWAP (each unavailable reference is treated as passed). RSI and MACD use 1-minute bars, last completed when that is a lower timeframe than the chart.
Calculation: ORB score, long/short = 1 for corresponding acceptance + corresponding level-volume score + 1 if relative volume meets its minimum + 1 if ATR is available + 1 if static context is bullish/bearish
Calculation: Tight balance = highest high and lowest low over the configured lookback ending on the previous bar have positive range no greater than the configured percentage of current close
Long: In session AND bullish static context AND long acceptance AND ORB score = 5 AND long breakout quality score >= 3 AND bullish tape score > 0 AND prior-session POC is not above close by less than 0.3% of close AND no bearish static context; emit once per continuous long-acceptance period
Long: In session AND long acceptance AND thesis not invalidated (no close below opening-range low after long acceptance) AND close >= opening-range high AND distance above opening-range high <= configured retest percentage AND (strong current volume OR tape defended) AND relative volume meets minimum AND ATR is available AND no bearish static context AND long breakout quality score >= 2 AND (ORB score minus static-context point) >= 3 AND effective bullish context AND (bullish tape score > 0 OR tape defended); emit on the first bar the condition becomes true

Short: In session AND bearish static context AND short acceptance AND ORB score = 5 AND short breakout quality score >= 3 AND bearish tape score > 0 AND prior-session POC is not below close by less than 0.3% of close AND no bullish static context; emit once per continuous short-acceptance period
