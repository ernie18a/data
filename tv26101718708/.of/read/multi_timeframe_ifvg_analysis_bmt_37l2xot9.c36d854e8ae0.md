Calculation: Fair value gap = on each enabled source timeframe, bullish when the current bar’s low is above the high two bars earlier and the middle bar’s close is above that high; bearish when the current bar’s high is below the low two bars earlier and the middle bar’s close is below that low. The gap must exceed a configurable minimum relative size. Use the current source-timeframe bar, which may still be forming; higher-timeframe rows use higher-timeframe bars.
Calculation: Inverted fair value gap = a bullish fair value gap becomes bearish when price crosses its lower boundary; a bearish fair value gap becomes bullish when price crosses its upper boundary. The crossing uses either close or high/low, according to the mitigation setting.
Long: bullish fair value gap forms OR bearish fair value gap is crossed upward into an inverted fair value gap OR price enters a live bullish fair value gap for the first time (bar low < gap top AND bar high > gap bottom).
Short: bearish fair value gap forms OR bullish fair value gap is crossed downward into an inverted fair value gap OR price enters a live bearish fair value gap for the first time (bar low < gap top AND bar high > gap bottom).
