Calculation: Buy share = clamp to [0,1] the selected model: bar direction gives 1 for close > open, 0 for close < open, and either 0.5 or (close − low) / range for a doji; close position gives (close − low) / range; body-and-close gives the weighted mean of (close − low) / range, (1 + clamp((close − open) / range, −1, 1)) / 2, and 1, 0, or 0.5 according as close is above, below, or equal to (high + low) / 2. In the latter two models, optionally replace the result with 0.5 when the body is no larger than the minimum price increment. Range is max(high − low, minimum price increment).
Calculation: Estimated buy and sell volume = volume × buy share and volume × (1 − buy share). Optionally sum these estimates over all available lower-timeframe bars within each chart bar, including the lower-timeframe bar still forming; if none have positive volume, either use the chart-bar estimates or zero, according to the fallback setting.
Calculation: Historical net percentage = 100 × (sum of estimated buy volume − sum of estimated sell volume) / (sum of estimated buy volume + sum of estimated sell volume), over a rolling chart-bar lookback, optionally capped by a maximum length, or over the current configured session. It is undefined when the denominator is zero.
Calculation: Profile = divide the range from the lowest low to the highest high of the selected rolling lookback or current session into equal price rows; the range is at least the number of rows times the minimum price increment. Optionally cap the number of included bars. Allocate each bar's estimated buy and sell volume to rows touched by its low-to-high range. Use either equal row weights, body-overlap × body weight plus wick-overlap × wick weight, or that segment weight multiplied by 1 + close-bias strength × clamp(1 − abs(row midpoint − close) / bar range, 0, 1). Normalize weights across touched rows; use equal weights if their sum is at or below the fallback threshold. With lower-timeframe reconstruction, optionally allocate each available lower-timeframe bar of the current chart bar separately, including the bar still forming; allocate earlier chart bars using their reconstructed totals and chart-bar ranges. Row total is allocated buy plus sell volume.
Calculation: Profile POC = midpoint of the highest-total-volume profile row, choosing the lowest row on a tie. Profile VWMP = sum of row midpoint × row total divided by total profile volume. Live net percentage = 100 × (total profile buy volume − total profile sell volume) / total profile volume.
Calculation: Row imbalance percentage = 100 × abs(row buy volume − row sell volume) / max(row buy volume + row sell volume, a small denominator floor). An eligible row has total volume at least a configured fraction of the POC row's volume. Its imbalance rank is either its imbalance percentage or that percentage multiplied by its total volume divided by the POC row's volume.
Calculation: Buy and sell clusters = maximal sequences of adjacent eligible rows whose respective buy or sell volume exceeds the other and whose imbalance percentage is at least the cluster threshold; require at least the configured number of rows. A cluster's score is the sum of its rows' imbalance percentages. The top cluster of each side has the greatest score, with the lowest cluster winning ties. Its boundaries are the outer edges of its first and last rows. Buffer = profile row height × buffer multiplier.
Calculation: Structure score = sign(close − profile POC) + sign(close − profile VWMP). Flow score = sign of live net percentage outside its positive and negative flow thresholds, plus 1 or 0.5 if the top buy cluster exists and has a greater score than the top sell cluster or no sell cluster exists, minus 1 or 0.5 under the symmetric sell-cluster condition; use magnitude 1 when the winning cluster score is at least its strong-score threshold, otherwise 0.5. Bias score = structure score + flow score.
Calculation: Reclaim armed state = set when close < top sell cluster upper edge − buffer; clear after a bullish reclaim. Reject armed state = set when close > top buy cluster lower edge + buffer; clear after a bearish rejection. Update these states before evaluating each decision.
Calculation: Bullish absorption armed state = set when low <= top sell cluster upper edge + buffer, then clear if close > that edge + 2 × buffer or after bullish absorption. Bearish absorption armed state = set when high >= top buy cluster lower edge − buffer, then clear if close < that edge − 2 × buffer or after bearish absorption. Update the set and price-based clear before evaluating each decision.
Calculation: Bearish structure failure = (low <= POC + buffer AND high >= POC − buffer AND close > POC + buffer) OR (low <= VWMP + buffer AND high >= VWMP − buffer AND close > VWMP + buffer) OR close > top sell cluster upper edge + buffer. Bullish structure failure = (low <= POC + buffer AND high >= POC − buffer AND close < POC − buffer) OR (low <= VWMP + buffer AND high >= VWMP − buffer AND close < VWMP − buffer) OR close < top buy cluster lower edge − buffer. A cluster comparison requires that cluster to exist.
Calculation: Bear-pressure-failure armed state = set when historical net percentage <= negative strong-pressure threshold AND bearish structure failure is false; clear when historical net percentage > negative strong-pressure threshold or after a bear-pressure-failure decision. Bull-pressure-failure armed state = set when historical net percentage >= strong-pressure threshold AND bullish structure failure is false; clear when historical net percentage < strong-pressure threshold or after a bull-pressure-failure decision. Update these states before evaluating each decision.
