Calculation: Swing levels = the most recently confirmed pivot high and pivot low, using the same number of bars on each side; update them before evaluating the current bar.
Calculation: Structure state = initially neutral; set to bullish when a bullish structure break occurs and bearish when a bearish structure break occurs. Evaluate the bullish break before the bearish break on each bar, updating the state immediately.
Calculation: Structure-break features = for each break, let duration be the bars since the broken pivot, bounded by a minimum and a maximum. Average bar volume delta over the shorter of duration and a maximum feature lookback, including the break bar; bar volume delta is ((close - low) - (high - close)) / max(high - low, a small positive constant) when volume > 0, otherwise zero. Displacement is abs(break close - open at duration bars ago) / ATR, or a fixed fallback if ATR is not positive. Velocity is that absolute price move / duration.
Calculation: Neighbors = maintain a capacity-limited chronological database of structure breaks. After a fixed lookahead has elapsed, record the break's direction, features, and maximum favorable and adverse excursions from its close over the subsequent lookahead bars; a success has favorable excursion > adverse excursion. On a new break, before adding any record resolved on that bar, select up to K records of the same direction whose break bars are within the historical memory window, ranked by Euclidean distance between their three features and the new break's features; resolve distance ties in database order.
Calculation: Targets = when neighbors exist, calculate their favorable excursions' mean, upper median, and percentile value at the rounded percentile rank, with ranks starting at one. The three targets are the break close plus, for a bullish break, or minus, for a bearish break, respectively: mean excursion multiplied by a conservative scalar, upper median excursion, and percentile excursion. Add the first and third targets only if both are positive; add the second if it is positive and differs from the first; add the third if it differs from the second. Track all added targets until hit, beginning on the bar after their creation.
Long: close > latest confirmed pivot high AND structure state <= neutral.
Short: close < latest confirmed pivot low AND structure state >= neutral.
Exit: long, high >= any outstanding bullish target.
Exit: short, low <= any outstanding bearish target.
