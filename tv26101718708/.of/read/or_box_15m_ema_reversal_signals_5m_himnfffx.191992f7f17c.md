Calculation: Opening range = the running high and low of completed lower-timeframe bars whose opening times fall within a configurable opening window in the America/New_York timezone; reset at each new day. Lock the range when the chart first enters the configured post-opening session, and retain it until the next day.
Calculation: Selected EMA = EMA of higher-timeframe closes, using either the last completed higher-timeframe bar or the still-forming higher-timeframe bar, as configured.
Calculation: Live EMA = EMA of higher-timeframe closes using the still-forming higher-timeframe bar, with the same length as the selected EMA.
Calculation: Bullish state = reset armed and awaiting-touch flags at each new day; after the opening range is locked, arm when the selected EMA > opening-range high. While armed, disarm and clear the awaiting-touch flag when close is between the opening-range low and high inclusive OR the selected EMA <= opening-range high. Clear the awaiting-touch flag when it is set AND low > selected EMA. Set it after each bullish touch, regardless of confirmation.
Calculation: Bearish state = reset armed and awaiting-touch flags at each new day; after the opening range is locked, arm when the selected EMA < opening-range low. While armed, disarm and clear the awaiting-touch flag when close is between the opening-range low and high inclusive OR the selected EMA >= opening-range low. Clear the awaiting-touch flag when it is set AND high < selected EMA. Set it after each bearish touch, regardless of confirmation.
Calculation: Bullish touch = bullish state is armed AND awaiting-touch flag is clear before processing the current touch AND low <= selected EMA AND close > selected EMA AND, if the structure filter is enabled, close > opening-range high.
Calculation: Bearish touch = bearish state is armed AND awaiting-touch flag is clear before processing the current touch AND high >= selected EMA AND close < selected EMA AND, if the structure filter is enabled, close < opening-range low.
Calculation: Target distance = a configured absolute price amount OR entry price multiplied by a configured percentage.
Long: Bullish touch AND, if higher-timeframe confirmation is enabled, the still-forming higher-timeframe low < live EMA AND its close > live EMA.
Short: Bearish touch AND, if higher-timeframe confirmation is enabled, the still-forming higher-timeframe high > live EMA AND its close < live EMA.
Exit: long, high >= entry price + target distance OR close < selected EMA OR bars elapsed since entry >= configured limit.
Exit: short, low <= entry price - target distance OR close > selected EMA OR bars elapsed since entry >= configured limit.
