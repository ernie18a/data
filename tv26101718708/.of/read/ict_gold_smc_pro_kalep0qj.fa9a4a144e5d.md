Calculation: Bullish sweep = current low < lowest low of the preceding sweep-lookback bars AND current close > that lowest low. Bearish sweep = current high > highest high of the preceding sweep-lookback bars AND current close < that highest high.
Calculation: Structure levels = most recently confirmed pivot high and pivot low, each using equal numbers of bars on either side. Bullish structure break = close > latest pivot high AND previous close <= that same pivot high. Bearish structure break = close < latest pivot low AND previous close >= that same pivot low. Structure direction starts neutral and changes to the direction of each break; process a bullish break before a bearish break on the same bar. A change-of-character break is a break opposite the preceding structure direction.
Calculation: Higher-timeframe bias = on each of two higher timeframes, using the last completed bar, bullish when close > short-period EMA > long-period EMA and bearish when close < short-period EMA < long-period EMA. The second timeframe is higher than the first.
Calculation: Order-block zones = on a bullish change-of-character break, select the nearest preceding bearish candle within the order-block lookback whose body exceeds a configured multiple of current ATR; its zone extends from its close to its open. On a bearish change-of-character break, select the nearest preceding bullish candle meeting the same body condition; its zone extends from its open to its close. A bullish zone is touched when low <= zone top AND close >= zone bottom; a bearish zone is touched when high >= zone bottom AND close <= zone top. After checking touches, remove bullish zones when close < zone bottom and bearish zones when close > zone top. Retain only the configured maximum number of newest zones.
Calculation: Fair-value-gap zones = create a bullish zone from the high two bars ago to current low when current low > that high AND the gap is at least a configured multiple of current ATR. Create a bearish zone from current high to the low two bars ago when current high < that low AND the gap is at least the same configured multiple of current ATR. Touch conditions are the same as for order-block zones. After checking touches, remove bullish zones when low < zone bottom and bearish zones when high > zone top. Retain only the configured maximum number of newest zones.
Calculation: Discount and premium = close is below the lower configured fraction or above the upper configured fraction, respectively, of the range from the lowest low to the highest high over the same range lookback, including the current bar.
Calculation: Directional confluence score = sum configurable weights for the following matching-direction conditions: current sweep, otherwise recent sweep; both higher-timeframe biases aligned, otherwise first higher-timeframe bias aligned; current structure break, otherwise recent structure break, otherwise matching structure direction; current bar in either configured UTC kill-zone interval, otherwise in either configured UTC session interval; order-block touch; fair-value-gap touch; discount for bullish or premium for bearish; ATR above its longer-period SMA. Subtract a configured weight when ATR exceeds a configured multiple of that SMA, then clamp the score to a configured minimum and maximum. A recent event occurred within the configured event lookback, including the current bar.
Calculation: Dominant momentum = normalized momentum is (close minus close at the momentum lookback) divided by current ATR times the momentum lookback. Bullish momentum is dominant when normalized momentum > a positive threshold OR the count of bullish candles in that lookback >= a configured fraction of the lookback; bearish momentum is dominant when normalized momentum < the negative threshold OR the count of bearish candles >= that fraction.
Calculation: Signal setup = for the selected sensitivity, strict requires a recent matching sweep AND recent matching structure break AND matching order-block or fair-value-gap touch AND matching score >= threshold; standard requires the same conditions without the zone touch; aggressive requires matching score >= threshold AND previous matching score < threshold AND matching first higher-timeframe bias; maximum requires matching score >= threshold AND matching first higher-timeframe bias. The optional momentum filter additionally requires no dominant opposite momentum. Evaluate on completed chart bars. A fired signal requires the setup AND more than a configured number of bars since the last fired signal of either direction; evaluate both directions before updating that shared bar. Dashboard waiting signals use the setup without the cooldown.
Calculation: Trade levels = at each fired signal, replace the tracked trade and record entry at close. Set the stop either to entry plus or minus a configured fixed price distance or ATR multiple, or beyond the latest matching sweep wick by a configured ATR buffer; if no matching sweep exists, use the lowest low or highest high over a configured lookback including the entry bar. Set each profit target at entry plus or minus a configured fixed price distance or entry-bar ATR multiple, with the final target using the longest target distance. Freeze all levels at the signal bar.
Long: Bullish sweep = true OR bullish structure break = true OR bullish structure direction = true OR both higher-timeframe bullish biases = true OR bullish order-block touch = true OR bullish fair-value-gap touch = true OR discount = true OR bullish signal setup = true.
Short: Bearish sweep = true OR bearish structure break = true OR bearish structure direction = true OR both higher-timeframe bearish biases = true OR bearish order-block touch = true OR bearish fair-value-gap touch = true OR premium = true OR bearish signal setup = true.
Exit: long, bar index > tracked entry bar AND (low <= stop OR high >= final profit target OR bars since tracked entry > configured expiry).
Exit: short, bar index > tracked entry bar AND (high >= stop OR low <= final profit target OR bars since tracked entry > configured expiry).
