Calculation: Channel = EMA of a selectable price source for the upper band and EMA of a selectable price source for the lower band, using the same length.
Calculation: Bias candle = OHLC of the last completed higher-timeframe bar. Bullish bias requires its range > 0 AND (min(open, close) - low) / range >= a rejection threshold AND close >= (high + low) / 2. Bearish bias requires its range > 0 AND (high - max(open, close)) / range >= the same threshold AND close <= (high + low) / 2.
Calculation: Clearing test = close crosses above the upper band for a bullish test or crosses below the lower band for a bearish test; alternatively, select close > upper band or close < lower band. An optional side-specific ATR filter requires either true range >= a multiplier times smoothed true range OR channel width >= another multiplier times the same smoothed true range; select RMA, SMA, EMA, or WMA smoothing. An optional bias filter requires the corresponding bias. An optional session filter requires the bar time to fall in any enabled session, with session times interpreted in the exchange timezone.
Calculation: Signal state = initialize to 0. On each bar, set to 1 if the bullish clearing test passes, then set to -1 if the bearish clearing test passes. Record the early long or short event when this state differs from the previous bar's final state and equals 1 or -1, respectively. Next, if optional safety is enabled, reset state 1 to 0 when low < lower band and state -1 to 0 when high > upper band. Record smart events using the resulting state. If one-entry-per-clearing-bar is enabled, reset the state to 0 after a smart event. An early event resets a countdown to a configurable number of chart bars; when the optional window is enabled, decrement a positive countdown on the same bar and each subsequent bar, and reset the state to 0 when the countdown reaches 0. The resulting state is the final state for the bar.
Calculation: Smart long event = signal state equals 1 after safety AND either max(open, close) <= upper band AND min(open, close) >= lower band, or high <= upper band AND low >= lower band, according to the selected containment mode AND the selected bullish intent: close > open, close > previous high, or close > previous bar's (high + low) / 2. Smart short event = signal state equals -1 after safety AND the same selected containment test AND the selected bearish intent: close < open, close < previous low, or close < previous bar's (high + low) / 2.
Long: Bullish bias AND bearish bias is false.
Short: Bearish bias AND bullish bias is false.
Long: Early long event OR smart long event.
Short: Early short event OR smart short event.
Long: Final signal state equals 1 AND previous bar's final state does not equal 1, OR smart long event; alternatively, if alert direction is flipped, final signal state equals -1 AND previous bar's final state does not equal -1, OR smart short event.
Short: Final signal state equals -1 AND previous bar's final state does not equal -1, OR smart short event; alternatively, if alert direction is flipped, final signal state equals 1 AND previous bar's final state does not equal 1, OR smart long event.
Exit: Long, low <= entry price - stop multiplier times ATR at the smart-entry signal bar OR high >= entry price + target multiplier times ATR at the smart-entry signal bar.
Exit: Short, high >= entry price + stop multiplier times ATR at the smart-entry signal bar OR low <= entry price - target multiplier times ATR at the smart-entry signal bar.
