Calculation: Lower-timeframe close = close from a timeframe lower than the chart timeframe; use the current lower-timeframe bar when repainting is enabled, otherwise use its previous completed bar
Calculation: Generated series = 1.25 × square root of chart close + (second of current chart-bar time × previous chart-bar close)
Calculation: OLS prediction = β × x + α, where β = correlation(x, y) × standard deviation(y) / standard deviation(x), α = mean(y) − β × mean(x), calculated over a lookback; evaluate at the current x
Calculation: Karobein oscillator = 2 × ((r / (r + c × a)) − 0.5), where m = EMA(x), a = EMA(m falling from prior bar ? m / prior m : 0), b = EMA(m rising from prior bar ? m / prior m : 0), r = m / prior m, and c = r / (r + b); use the same lookback for each EMA as for the OLS prediction
Calculation: Forecast oscillator = Karobein oscillator of the OLS prediction of the lower-timeframe close (x) against the generated series (y)
Long: forecast oscillator one bar ago < forecast oscillator two bars ago AND forecast oscillator one bar ago < current forecast oscillator AND year >= configured start year AND month >= configured start month AND day-of-month >= configured start day
Short: forecast oscillator one bar ago > forecast oscillator two bars ago AND forecast oscillator one bar ago > current forecast oscillator AND year >= configured start year AND month >= configured start month AND day-of-month >= configured start day
Exit: long, year >= configured start year AND month >= configured start month AND day-of-month >= configured start day AND price has risen by the configured trail activation distance from entry AND low <= highest high since activation − configured trailing offset
Exit: short, year >= configured start year AND month >= configured start month AND day-of-month >= configured start day AND price has fallen by the configured trail activation distance from entry AND high >= lowest low since activation + configured trailing offset
