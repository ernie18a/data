Calculation: Confirmed pivot high/low = the high/low of the bar a chosen number of bars ago, strictly greater/less than every other high/low within the same number of bars on each side. The latest confirmed pivot of each kind replaces the previous one and is active until its corresponding structure break.
Calculation: Structure state = initialize trend, last broken high, last broken low, range high and range low to zero. On a bullish structure break, set trend to bullish, last broken high to the active pivot high, range high to that pivot and range low to the lowest accumulated bullish sweep low if the sweep filter is enabled, otherwise the latest pivot low. On a bearish structure break, set trend to bearish, last broken low to the active pivot low, range low to that pivot and range high to the highest accumulated bearish sweep high if the sweep filter is enabled, otherwise the latest pivot high. Update confirmed pivots before testing breaks; process the bullish break before the bearish break.
Calculation: Bullish sweep state = while the pivot low is active, set the state when the previous bar's low is below it, accumulating the lowest such low; clear the state and accumulated low when the previous close is below the pivot low or after a bullish structure break. Bearish sweep state is symmetric using the active pivot high, previous high above it, highest accumulated high and previous close above it. Evaluate sweeps before updating pivots.
Calculation: Bullish structure break = the latest pivot high is active AND the previous close is above it AND, if full-body confirmation is enabled, the previous open is also above it AND, if the sweep filter is enabled, bullish sweep state is set AND, if the higher-timeframe filter is enabled, the last completed higher-timeframe close is above its simple moving average AND, if the premium/discount filter is enabled and the structure range high differs from its low, the previous close is at or below the midpoint of that range.
Calculation: Bearish structure break = the latest pivot low is active AND the previous close is below it AND, if full-body confirmation is enabled, the previous open is also below it AND, if the sweep filter is enabled, bearish sweep state is set AND, if the higher-timeframe filter is enabled, the last completed higher-timeframe close is below its simple moving average AND, if the premium/discount filter is enabled and the structure range high differs from its low, the previous close is at or above the midpoint of that range.
Calculation: Inducement levels = when trend is nonzero, retain each newly confirmed pivot high or low strictly between the last broken low and last broken high. Before processing structure breaks, mark each unbroken high level broken when the previous low is below it, and each unbroken low level broken when the previous high is above it. After processing, remove the oldest level if more than the retained-level limit exist.
Long: Bullish structure break.
Long: Structure trend is bullish.
Long: The previous high is above an unbroken inducement pivot low.
Short: Bearish structure break.
Short: Structure trend is bearish.
Short: The previous low is below an unbroken inducement pivot high.
