Calculation: Timeframe pairs = independent pairs of a context timeframe and a shorter confirmation timeframe. Either timeframe may be higher than, equal to, or lower than the chart timeframe. Process only the last completed bars of each timeframe, once per bar, within a configurable history depth.
Calculation: Context levels = for each consecutive pair of context bars with neither bar a doji, create a fresh level at the first bar's close after processing existing levels on the second bar. The level is support if the second bar is bullish and resistance if it is bearish. Retain a configurable maximum number of levels, discarding the oldest. On each later completed context bar, a close below support or above resistance flips its side and makes it fresh; otherwise, fresh support is rejected when low <= level + tolerance AND close > level, and fresh resistance is rejected when high >= level - tolerance AND close < level. A rejected level becomes unfresh. If multiple levels are rejected on one side, select the lowest support or highest resistance. Tolerance is a configurable price increment.
Calculation: Pending setups = each selected rejection creates a separate setup for its side. Retain a configurable maximum per side, discarding the oldest. Before adding new setups, cancel existing support setups when the latest completed context close < their rejected level and resistance setups when it > their rejected level. For each new setup, replay retained completed confirmation bars starting at the rejection bar's open; subsequently process each completed confirmation bar once. The first bar with low <= rejected support + tolerance or high >= rejected resistance - tolerance is the touch. At that touch, lock the most recent confirmation-timeframe level at the first bar's close of a bullish-then-bearish pair for support setups or a bearish-then-bullish pair for resistance setups; the pair may complete on the touch bar. If no such level exists at the touch, the setup cannot confirm. On a later confirmation bar, a support setup confirms when close > its locked level; a resistance setup confirms when close < its locked level. Remove every confirmed setup. Retain a configurable confirmation-bar replay window.
Calculation: Trend = initially neutral for each timeframe pair. On each processing step, select the earliest confirmation on each side, resolving same-side ties in favor of the newer setup. If both sides confirm, set trend to the side with the later selected confirmation, resolving a simultaneous tie as bearish; otherwise set it to the confirming side. Trend persists until another confirmation changes it.
Long: Any pair's trend = bullish AND its preceding chart-bar trend != bullish.
Short: Any pair's trend = bearish AND its preceding chart-bar trend != bearish.
