Calculation: Active liquidity levels = Maintain separate ordered lists of confirmed pivot highs and pivot lows, using equal left and right pivot lengths. On each completed chart bar, add newly confirmed pivots before testing levels. Merge a new pivot into the first active same-side level within current ATR times a merge-tolerance parameter, replacing the level with the higher price for pivot highs or the lower price for pivot lows; otherwise append it. Limit each list to a configurable maximum: evict the oldest inactive level first, or the oldest active level if none is inactive. A swept or broken level becomes inactive or is removed according to the configured retention setting.
Calculation: High-level sweep = high > active pivot-high level + current ATR times a minimum-pierce parameter AND close < that level. Low-level sweep = low < active pivot-low level - current ATR times the same minimum-pierce parameter AND close > that level. Use zero for the ATR product when it is unavailable.
Calculation: Confluence score = On the sweep bar, add one for an enabled EMA filter when the shorter, middle and longer close EMAs are strictly descending for a long setup or strictly ascending for a short setup; add one for an enabled relative-volume filter when volume divided by its same-bar SMA is at least a threshold. A disabled filter contributes zero.
Calculation: Pending setup = Keep at most one setup. After resolving the existing setup on each bar, replace it with that bar's low-level sweep for long or high-level sweep for short. If both occur, choose long when close > open, otherwise short. Store the sweep bar's high, low, index and directional confluence score. Cancel the setup when its age exceeds the confirmation window, when a long setup's close < its sweep low, or when a short setup's close > its sweep high. Also clear it on the first trigger crossing, even if its score is below the minimum.
Long: Low-level sweep.
Short: High-level sweep.
Long: Close > an active pivot-high level.
Short: Close < an active pivot-low level.
Long: Pending long setup age > 0 AND age <= confirmation window AND close >= sweep low AND close > sweep high AND stored confluence score >= minimum score.
Short: Pending short setup age > 0 AND age <= confirmation window AND close <= sweep high AND close < sweep low AND stored confluence score >= minimum score.
