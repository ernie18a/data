Calculation: Session profile bars = chart bars from the most recent transition into a configurable trading session through the current bar, including bars outside session hours; require the session to have started after the first available bar and at least one bar before the current bar. Limit history to a maximum lookback.
Calculation: Range profile bars = chart bars from a configurable lookback before the current bar through the current bar, inclusive, limited by available history and the same maximum lookback.
Calculation: Profile value area = divide the profile's highest high to lowest low into a configurable number of equal price rows; if the range is zero, use a configurable minimum price increment as row width. Assign each bar's entire volume, treating missing volume as zero, to the row containing its high-low midpoint, clamped to the first or last row. Start the value area at the row with the greatest volume, choosing the lowest row on a tie. Expand one adjacent row at a time toward the higher-volume neighbor, choosing the upper neighbor on a tie and the available neighbor at an edge, until the included volume reaches a configurable fraction of total volume or all rows are included. Value area high is the upper edge of the highest included row; value area low is the lower edge of the lowest included row. Calculate session and range profiles independently with their respective row counts and the same volume fraction.
Calculation: Value area midpoint = (value area high + value area low) / 2.
Long: close > session value area high AND close > range value area high
Short: close < session value area low AND close < range value area low
Long: range value area high > range value area low AND session value area midpoint - range value area midpoint >= configurable divergence fraction × (range value area high - range value area low)
Short: range value area high > range value area low AND range value area midpoint - session value area midpoint >= configurable divergence fraction × (range value area high - range value area low)
