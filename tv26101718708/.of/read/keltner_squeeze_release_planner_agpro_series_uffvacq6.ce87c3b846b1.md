Calculation: Keltner basis = EMA of close; upper and lower bands = basis plus and minus an ATR multiple; width = upper band minus lower band; width percentage = 100 × width / absolute basis, undefined when basis is zero.
Calculation: Width rank = clamp(100 × (width percentage − rolling minimum width percentage) / max(rolling maximum width percentage − rolling minimum width percentage, 0.0000001), 0, 100). A bar is compressed when width rank <= the squeeze threshold. Prior compression requires every bar in a consecutive lookback ending on the previous bar to be compressed.
Calculation: Expansion ratio = current width / previous width when previous width > 0, otherwise 1. Relative volume = volume / its moving average when that average > 0, otherwise 1.
Calculation: Release score = clamp(24 × clamp((squeeze threshold − width rank + 10) / max(squeeze threshold + 10, 1), 0, 1) + 22 × clamp((expansion ratio − 1) / 0.45, 0, 1) + 22 × clamp(close pressure / 0.75, 0, 1) + 14 × clamp(abs(close − open) / max(high − low, positive price increment) / 0.70, 0, 1) + volume component + 8 × clamp(abs(basis − basis three bars ago) / safe ATR, 0, 1), 0, 100). Close pressure is (close − upper band) / safe ATR for a bullish release and (lower band − close) / safe ATR for a bearish release. The volume component is 10 × clamp(relative volume / 1.6, 0, 1) when enabled, otherwise 7. Safe ATR is ATR when positive and available, otherwise a positive price-increment-based fallback. The required score is the score threshold adjusted by the selected confirmation mode and bounded to 1–100.
Calculation: Active release = the most recent qualified release, replacing any previous active release. Freeze its direction, bar, corresponding Keltner band, and safe ATR at that bar. It remains active through the configured release window, inclusive, until its failure condition occurs; it expires afterward. Its failure level is the frozen upper band minus a frozen ATR multiple for a bullish release, or the frozen lower band plus that multiple for a bearish release.
Long: Prior compression AND close > upper band + safe ATR × release buffer parameter AND expansion ratio >= expansion threshold AND bullish release score >= required score.
Long: Active release direction is bullish AND bars since release <= release window AND close >= failure level.
Short: Prior compression AND close < lower band − safe ATR × release buffer parameter AND expansion ratio >= expansion threshold AND bearish release score >= required score.
Short: Active release direction is bearish AND bars since release <= release window AND close <= failure level.
Exit: long, active release direction is bullish AND bars since release <= release window AND close < failure level.
Exit: short, active release direction is bearish AND bars since release <= release window AND close > failure level.
