Calculation: ATR = Wilder ATR, falling back to current true range until ATR is available. The source also floors this at the instrument's minimum tick, which cannot be derived reliably from the specified backtest fields.
Calculation: Gap candidates = evaluate in this order: bullish open > previous high gives bounds [previous high, open]; bullish low > previous high gives [previous high, low]; bullish min(open, close) > previous max(open, close) gives [previous body high, current body low]; enabled bullish displacement with close > previous high AND abs(close - open) >= ATR times displacement threshold gives [previous high, close]; bearish open < previous low gives [open, previous low]; bearish high < previous low gives [high, previous low]; bearish max(open, close) < previous min(open, close) gives [current body high, previous body low]; enabled bearish displacement with close < previous low AND abs(close - open) >= ATR times displacement threshold gives [close, previous low]. Use the first matching candidate for the bounds, even if its type or direction is not enabled by the selected gap mode. Candidate height is the absolute difference between its bounds.
Calculation: Qualifying gap = candidate height >= ATR times minimum gap-size threshold AND a bullish or bearish gap condition permitted by the selected mode. The classic mode permits open gaps; the open-and-wick mode also permits wick gaps; the body-separation mode also permits body gaps; adaptive mode also permits enabled displacement gaps. If both directions qualify, select bullish. Set the gap top and bottom to the larger and smaller candidate bounds; the bullish edge is the top and the bearish edge is the bottom.
Calculation: Active gap = retain the latest qualifying gap with its direction, bounds, creation bar, and unresolved or reclaimed state. At the start of each bar, determine whether replacement is allowed from the previous state: no gap exists OR bars since creation > gap cooldown. Clear the gap if abs(close - edge) / ATR > maximum distance OR it is resolved AND its age > active-gap window. Then register a qualifying gap if replacement was allowed, even if the previous gap was just cleared. A new gap is unresolved. After evaluating the current bar, mark it reclaimed and resolved on a ready event; clear it on an unresolved invalidation or expiration, or when a reclaimed gap's current fill risk >= fill-risk threshold. Expiration means age > active-gap window. Evaluate ready, invalidation, and expiration from the same pre-update state; a ready event can coincide with expiration. On the creation bar, age is unavailable because it was computed before registration.
Calculation: Fill risk = clamp(100 times (gap top - low) / gap height, 0, 100) for a bullish gap; clamp(100 times (high - gap bottom) / gap height, 0, 100) for a bearish gap.
Calculation: Reclaim score = clamp(T + Z + C + V + S + R, 0, 100), where clamp(x, a, b) limits x to [a, b]; T = clamp(18 times (1 - gap age / reclaim-window length), 0, 18), or 0 when age is unavailable; Z = 16 if high >= gap bottom AND low <= gap top, otherwise 0; C = 26 if close is on or beyond the edge in the gap direction, otherwise 10 if the bar intersects the gap, otherwise 0; V = 14 times clamp(relative volume / 1.6, 0, 1) when volume scoring is enabled, otherwise 10, with relative volume = volume / SMA(volume) or 1 if the average is not positive; S = 12 times clamp(gap height / (ATR times 0.75), 0, 1); R = 14 times clamp(directional distance from close to first target / (ATR times 1.2), 0, 1). The first target is edge plus gap height times target multiplier for bullish gaps and edge minus that distance for bearish gaps. Required score = clamp(minimum ready score - confirmation adjustment, 1, 100), with adjustment 4 for fast, 0 for balanced, and -6 for strict confirmation.
Long: active gap direction = bullish.
Short: active gap direction = bearish.
Long: active gap direction = bullish AND gap is unresolved AND high >= gap bottom AND low <= gap top AND close >= gap edge AND reclaim score >= required score AND fill risk < fill-risk threshold.
Short: active gap direction = bearish AND gap is unresolved AND high >= gap bottom AND low <= gap top AND close <= gap edge AND reclaim score >= required score AND fill risk < fill-risk threshold.
