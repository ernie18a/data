Calculation: Qualifying bullish gap = the selected gap mode accepts at least one of: open > previous high (gap bounds: open to previous high); low > previous high (low to previous high); min(open, close) > max(previous open, previous close) (min(open, close) to max(previous open, previous close)); or, when displacement fallback is enabled, close > previous high and abs(close − open) >= ATR × displacement-strength parameter (close to previous high). Gap height must be >= ATR × minimum-gap-size parameter.
Calculation: Qualifying bearish gap = the selected gap mode accepts at least one of: open < previous low (previous low to open); high < previous low (previous low to high); max(open, close) < min(previous open, previous close) (max(open, close) to min(previous open, previous close)); or, when displacement fallback is enabled, close < previous low and abs(close − open) >= ATR × displacement-strength parameter (previous low to close). Gap height must be >= ATR × minimum-gap-size parameter.
Calculation: Reclaim score = clamp(time score + zone score + close score + volume score + size score + room score, 0, 100), where time score = clamp(18 × (1 − bars since gap / reclaim-window parameter), 0, 18); zone score = 16 if the bar overlaps the gap zone, otherwise 0; close score = 26 if close reclaims the edge, otherwise 10 if the bar overlaps the gap zone, otherwise 0; volume score = clamp((volume / SMA(volume, relative-volume lookback)) / 1.6, 0, 1) × 14 when relative-volume scoring is enabled, otherwise 10; size score = clamp(gap height / (ATR × 0.75), 0, 1) × 12; room score = clamp(room to first target in ATR units / 1.2, 0, 1) × 14. The first target is reclaim edge plus gap height × target-gap parameter for bullish gaps, or minus it for bearish gaps.
Calculation: Fill risk = clamp((gap top − low) / gap height × 100, 0, 100) for bullish gaps; clamp((high − gap bottom) / gap height × 100, 0, 100) for bearish gaps.
Long: a qualifying bullish gap is the active gap, is unresolved and unreclaimed, is within the reclaim window, the bar overlaps the gap zone, close >= the gap's top edge, reclaim score >= the configured minimum ready score adjusted by confirmation mode (Fast: −4; Balanced: 0; Strict: +6), and fill risk < the configured fill-risk threshold.
Short: a qualifying bearish gap is the active gap, is unresolved and unreclaimed, is within the reclaim window, the bar overlaps the gap zone, close <= the gap's bottom edge, reclaim score >= the configured minimum ready score adjusted by confirmation mode (Fast: −4; Balanced: 0; Strict: +6), and fill risk < the configured fill-risk threshold.
