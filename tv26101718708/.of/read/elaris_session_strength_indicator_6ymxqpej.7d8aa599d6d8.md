Calculation: SessionOpen = open of the first bar of the current intraday time-of-day session (a new session starts when the active session changes to another non-empty one; where windows overlap, the earlier-priority window wins); the value persists after the session ends until the next session starts
Calculation: SignedStrength = Strength * Bias, where Strength = EMA(short smoothing) of the weighted average (fixed positive weights) of four scores, each 0-100: (1) range score = min((high-low)/ATR, cap)/cap*100; (2) volume score = min(volume/SMA(volume), cap)/cap*100; (3) efficiency score = |close-open|/(high-low)*100 (0 if high==low); (4) displacement score = min(|close-SessionOpen|/ATR, cap)/cap*100. Bias = w_session*sign(close-SessionOpen) + w_bar*sign(close-open), with w_session > w_bar, clamped to [-1,1]. ATR is on the chart timeframe
Long: SignedStrength crosses above +StrongThreshold (previous bar below or equal, current bar above) OR SignedStrength crosses above 0
Short: SignedStrength crosses below -StrongThreshold (previous bar above or equal, current bar below) OR SignedStrength crosses below 0
