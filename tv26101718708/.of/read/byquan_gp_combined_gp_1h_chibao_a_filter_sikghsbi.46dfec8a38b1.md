Calculation: EMAf, EMAm, EMAs = EMA of close with short, medium and long lengths (f<m<s).
Calculation: SRSI(close) = K + D, where r = RSI(close); st = 100*(r - lowest r)/(highest r - lowest r) over a lookback window; K = SMA(st, short window); D = SMA(K, short window). Range 0-200.
Calculation: M = (sum of SRSI(close) computed on four timeframes, all higher than the chart timeframe and of distinct increasing durations, each using the still-forming higher-timeframe bar as of the current chart bar) / 8. Range 0-100.
Calculation: LowConf and HighConf (booleans per bar), from M with low level lo<50<high level hi and N confirm bars: (1) if neither arm is active: M<=lo sets armLow, M>=hi sets armHigh. (2) riseTrig = armLow and M>=50; fallTrig = armHigh and M<=50; either trigger clears both arms. (3) fallTrig starts a min-tracker (ext=M, cnt=0); riseTrig starts a max-tracker (ext=M, cnt=0); the two trackers are independent. (4) Each bar while a min-tracker is active (including its trigger bar): if M<ext then ext=M and cnt=0, else cnt+=1; when cnt>=N the tracker stops and LowConf=true on that bar. Max-tracker is mirrored (M>ext), giving HighConf=true.
Calculation: LongRetest (true on a single bar), state s starts at 0, with p = pullback fraction and e = early-retest fraction (both between 0 and 1). On a bar where EMAf crosses above EMAm or above EMAs: s=1, base=EMAf, peak=EMAf (restarts any prior state). Then, in order on the same bar: if s==1 { if EMAf>EMAf[1] then peak=max(peak,EMAf); if EMAf<EMAf[1] and EMAf[1]<EMAf[2] then s=2 }; if s==2 { h=peak-base; if h>0 and peak-EMAf>=h*p then s=3 }; if s==3 { if EMAf>=peak-h*(1-e) then s=4 and LongRetest=(EMAm>EMAs) }.
Calculation: ShortRetest (true on a single bar), mirror: on a bar where EMAf crosses below EMAm or below EMAs: s=1, top=EMAf, trough=EMAf. Then in order on the same bar: if s==1 { if EMAf<EMAf[1] then trough=min(trough,EMAf); if EMAf>EMAf[1] and EMAf[1]>EMAf[2] then s=2 }; if s==2 { h=top-trough; if h>0 and EMAf-trough>=h*p then s=3 }; if s==3 { if EMAf<=trough+h*(1-e) then s=4 and ShortRetest=(EMAm<EMAs) }.
Long: LongRetest is true on the current bar AND LowConf was true on at least one of the last L bars including the current bar (L much larger than N).
Short: ShortRetest is true on the current bar AND HighConf was true on at least one of the last L bars including the current bar.
