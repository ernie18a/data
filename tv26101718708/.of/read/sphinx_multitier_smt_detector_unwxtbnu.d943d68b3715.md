Calculation: Swing pivot high/low = a high/low exceeding the longer lookback of bars on both sides; at the pivot bar, record each correlated instrument's high/low, then latch sweeps when later completed higher-timeframe bars trade beyond the references. Use higher timeframes relative to the chart timeframe and confirmed, completed bars.

Apply the same condition to confirmed higher-timeframe swing-pivot references.

Apply the same condition to confirmed higher-timeframe swing-pivot references.

Exit: Short, chart instrument's high-sweep flag equals the selected diverging sister's high-sweep flag for a session/cycle reference, OR all enabled instruments' high-sweep flags are true for a swing-pivot reference.
