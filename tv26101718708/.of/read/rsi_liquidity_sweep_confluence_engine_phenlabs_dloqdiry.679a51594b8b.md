Calculation: RSI-derived support = Calculate RSI from a configurable price source. On each confirmed RSI pivot low, store the low of the pivot bar and retain only the most recent configured number of such lows. An RSI pivot low is less than or equal to all RSI values in the left lookback and strictly less than all RSI values in the right lookback; confirm it after the right lookback has elapsed. On each bar, select the highest stored low at or below the current close. If none qualifies, retain the previous selected support; it is undefined until first selected.
Calculation: RSI-derived resistance = Calculate RSI from the same source and with the same parameters as for support. On each confirmed RSI pivot high, store the high of the pivot bar and retain only the most recent configured number of such highs. An RSI pivot high is greater than or equal to all RSI values in the left lookback and strictly greater than all RSI values in the right lookback; confirm it after the right lookback has elapsed. On each bar, select the lowest stored high at or above the current close. If none qualifies, retain the previous selected resistance; it is undefined until first selected.
Long: Low < lowest low over the sweep lookback excluding the current bar AND (close-back filter disabled OR close > that lowest low) AND RSI-derived support is defined AND (ATR tolerance multiplier <= 0 OR absolute difference between low and RSI-derived support <= ATR × tolerance multiplier) AND (volume multiplier <= 0 OR (volume SMA > 0 AND volume >= volume SMA × volume multiplier)).
Short: High > highest high over the sweep lookback excluding the current bar AND (close-back filter disabled OR close < that highest high) AND RSI-derived resistance is defined AND (ATR tolerance multiplier <= 0 OR absolute difference between high and RSI-derived resistance <= ATR × tolerance multiplier) AND (volume multiplier <= 0 OR (volume SMA > 0 AND volume >= volume SMA × volume multiplier)).
