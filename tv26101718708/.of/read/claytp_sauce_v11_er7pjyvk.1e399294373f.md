Calculation: Structure = The latest confirmed pivot high and low, each defined using equal numbers of preceding and following chart bars. A newly confirmed pivot activates its level. An active high is deactivated when high reaches it in stop-entry mode or close exceeds it in close-entry mode; an active low is deactivated when low reaches it in stop-entry mode or close falls below it in close-entry mode. Record each break direction even if no entry occurs; if both break on one bar, process the high first. Optionally reset pivots, activation, and break direction at each new exchange day.
Calculation: Entry-type filter = A bullish break is continuation when the preceding break was not downward; a bearish break is continuation when the preceding break was not upward. Otherwise it is a change of character. Select continuation only, change of character only, or both.
Calculation: Trend filter = Optionally require the slopes of all three close SMAs, any two, the shortest and middle, or the shortest alone to be positive for longs and negative for shorts, or require close above all three for longs and below all three for shorts. Independently, optionally require the short, middle, and long SMAs to be strictly descending for longs and ascending for shorts, and optionally require their one-bar changes to be strictly descending for longs and ascending for shorts.
Calculation: Anchored VWAP = Cumulative sum of volume multiplied by (open + high + low + close) / 4 divided by cumulative volume, reset on the first chart bar at or after a configurable daily anchor time in its configured timezone. The two optional VWAP filters have independently configured anchors and timezones.
Calculation: Entry filters = The selected entry type and directional trend filter pass AND, for each enabled anchored VWAP filter, close is above its VWAP for longs or below it for shorts AND, if enabled, bar time is within the configured trading window, including overnight windows AND the daily trade limit is not reached AND the direction is permitted AND the position is flat or opposite AND the relevant pivot differs from the last pivot used for an order in that direction by more than the minimum price increment, or no such pivot has been used since the new exchange day. Count a trade when a position changes from flat to open; reset the count and used-pivot guards each new exchange day.
Calculation: Stop and target = At order placement, choose a reference price equal to the active pivot for a stop entry or the signal close for a close entry. For a long, choose the stop base as the latest pivot low, the reference price minus a configurable fraction of its distance to that low, the signal bar low, or the reference price reduced by a configurable percentage. Subtract a configurable fixed buffer and a configurable percentage of the reference price. For a short, use the latest pivot high, the reference price plus a configurable fraction of its distance to that high, the signal bar high, or the reference price increased by a configurable percentage; add the same kinds of buffers. The target is the reference price plus the long risk or minus the short risk, multiplied by a configurable reward-to-risk ratio. Freeze these levels at order placement; the ratio may differ by direction.
Long: In stop-entry mode, the entry filters pass AND the high pivot is active AND the latest pivot high > the latest pivot low AND the pivot high > the current high AND stop < reference price < target; place a buy stop at the pivot high, mark that pivot used immediately, and cancel the pending order when these conditions no longer pass. A later bar reaching the stop triggers the entry.
Short: In stop-entry mode, the entry filters pass AND the low pivot is active AND the latest pivot low < the latest pivot high AND the pivot low < the current low AND target < reference price < stop; place a sell stop at the pivot low, mark that pivot used immediately, and cancel the pending order when these conditions no longer pass. A later bar reaching the stop triggers the entry.
Long: In close-entry mode, the entry filters pass AND the high pivot is active AND close > the latest pivot high AND the latest pivot high > the latest pivot low AND stop < reference price < target AND, if the strong-candle filter is enabled, close > open AND absolute close-minus-open >= total wick length multiplied by a configurable factor. Enter at the next bar open and mark the pivot used.
Short: In close-entry mode, the entry filters pass AND the low pivot is active AND close < the latest pivot low AND the latest pivot low < the latest pivot high AND target < reference price < stop AND, if the strong-candle filter is enabled, close < open AND absolute close-minus-open >= total wick length multiplied by a configurable factor. Enter at the next bar open and mark the pivot used.
Exit: Long, low <= frozen stop OR high >= frozen target, provided frozen stop < entry price < frozen target.
Exit: Short, high >= frozen stop OR low <= frozen target, provided frozen target < entry price < frozen stop.
Exit: Long, frozen stop >= frozen target OR frozen stop >= entry price OR frozen target <= entry price.
Exit: Short, frozen stop <= frozen target OR frozen stop <= entry price OR frozen target >= entry price.
Exit: Long, end-of-day closing is enabled AND a new exchange day begins.
Exit: Short, end-of-day closing is enabled AND a new exchange day begins.
