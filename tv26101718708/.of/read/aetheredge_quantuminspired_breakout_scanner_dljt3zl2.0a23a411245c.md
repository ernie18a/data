Calculation: Feature vector = [clamp((close − close[return lookback]) / (ATR × return lookback + ε)), clamp((ATR − SMA(ATR)) / (standard deviation of ATR + ε)), clamp(3 × (RSI(close) − 50) / 50), clamp((close − close[momentum lookback]) / (ATR × return lookback + ε)), clamp((volume − SMA(volume)) / (standard deviation of volume + ε)), clamp(3 × (+DI − −DI) / 100)]; clamp limits each component to [−3, 3], and a disabled feature is zero. Momentum lookback is longer than return lookback. +DI and −DI use Wilder-smoothed directional movement divided by ATR. ε is a small positive numerical stabilizer.
Calculation: KNN probabilities = on each completed bar after the initial warmup and prediction horizon, append the feature vector from one prediction horizon ago and its outcome: up if current close minus that bar's close exceeds that bar's ATR times the sideways threshold, down if it is below the negative of that threshold, otherwise sideways. Retain at most the history-depth parameter's most recent samples. If KNN is enabled and at least the neighbor-count samples exist, select the nearest samples by Euclidean distance to the current feature vector using ascending distance and the source's partial selection sort, weight each by 1 / (1 + distance²), and divide each outcome's total weight by the sum of all weights plus ε. Otherwise assign each outcome probability 1/3.
Calculation: Neural probabilities = if enabled, let x1 through x6 be the feature vector and w1 through w6 their respective weights; set raw = w1×x1 + 0.3×w2×x2 + w3×x3 + w4×x4 + 0.5×w5×x5 + w6×x6 and magnitude = w1×abs(x1) + w4×abs(x4) + w6×abs(x6). Apply softmax with the temperature parameter to scores [raw, −raw, −0.5×magnitude + 0.5×w2×x2], adding ε to the softmax denominator. If disabled, assign each outcome probability 1/3.
Calculation: Up, down, and sideways probabilities = for each outcome, mix its KNN and neural probabilities as (1 − mix) × KNN probability + mix × neural probability, then divide each mixed probability by the sum of all three mixed probabilities plus ε.
Long: Up probability >= down probability AND up probability >= sideways probability
Short: Down probability > up probability AND down probability >= sideways probability
