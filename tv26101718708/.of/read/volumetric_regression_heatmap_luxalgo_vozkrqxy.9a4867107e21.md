Calculation: Lookback = base lookback; if dynamic adjustment is enabled and both short-term and long-term ATR are positive, use the base lookback multiplied by long-term ATR / short-term ATR, rounded to the nearest integer and clamped between minimum and maximum lookbacks.
Calculation: Regression start, end, and previous fitted value = least-squares linear regression of the selected price source over the current lookback, evaluated at the oldest, current, and previous bars respectively, using the same current-bar fit. Standard deviation is the population standard deviation of that source over the same lookback.
Long: Absolute value of regression end minus regression start < standard deviation multiplied by the flatness threshold AND previous close >= previous fitted value minus standard deviation multiplied by the signal-band multiplier AND current close < regression end minus standard deviation multiplied by the signal-band multiplier.
Short: Absolute value of regression end minus regression start < standard deviation multiplied by the flatness threshold AND previous close <= previous fitted value plus standard deviation multiplied by the signal-band multiplier AND current close > regression end plus standard deviation multiplied by the signal-band multiplier.
