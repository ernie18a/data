Calculation: Timeframe series = use the chart timeframe or a selectable higher or lower timeframe; on historical chart bars, use the last completed requested-timeframe bar, including the last completed intrabar for a lower timeframe. Request OHLC and ATR on that timeframe; calculate all other series and their history on chart bars from the requested values.
Calculation: Midpoint = (highest requested high + lowest requested low) / 2 over a lookback. Conversion uses the shortest lookback, base a longer lookback, and span B a still longer lookback. Span A = (conversion + base) / 2. Cloud upper and lower = maximum and minimum of span A and span B, respectively, displaced backward by the displacement parameter minus one chart bar.
Calculation: Market bias = initially 0; set to 1 when requested close > cloud upper, to -1 when requested close < cloud lower, otherwise retain its previous value.
Calculation: Trend = initially 0. If market bias = 1, first reset trend to 0 if previous market bias = -1; then, if trend < 4 AND requested close > cloud upper, set trend to 1 plus one each for requested close > cloud upper displaced backward by the displacement parameter minus one chart bar, conversion >= base AND either conversion > its previous value OR base > its previous value, and span A >= span B; otherwise set trend to 0 if conversion < base - tolerance. If market bias = -1, first reset trend to 0 if previous market bias = 1; then, if trend > -4 AND requested close < cloud lower, set trend to -1 minus one each for requested close < cloud lower displaced backward by the displacement parameter minus one chart bar, conversion <= base AND either conversion < its previous value OR base < its previous value, and span A <= span B; otherwise set trend to 0 if conversion > base + tolerance. Tolerance is a selectable ATR multiple or zero.
Calculation: Oscillator = for market bias = 1, requested close - cloud lower + max(requested close - displaced cloud upper, 0) + max(conversion - base, 0) + max(span A - span B, 0); for other market bias values, requested close - cloud upper + min(requested close - displaced cloud lower, 0) + min(conversion - base, 0) + min(span A - span B, 0). Displaced cloud boundaries use the displacement parameter minus one additional chart bar.
Calculation: Timeframe trend = evaluate the trend calculation in the selected timeframe context and merge it onto the chart using the last completed requested-timeframe bar; for a lower timeframe use its last completed intrabar.
Long: trend = 4 AND previous trend != 4.
Long: trend = 4 AND requested close > cloud upper AND previous requested close >= previous cloud lower AND previous requested close <= previous cloud upper.
Long: timeframe trend = 4.
Short: trend = -4 AND previous trend != -4.
Short: trend = -4 AND requested close < cloud lower AND previous requested close >= previous cloud lower AND previous requested close <= previous cloud upper.
Short: timeframe trend = -4.
Exit: long, previous trend = 4 AND trend != previous trend.
Exit: short, previous trend = -4 AND trend != previous trend.
Exit: long, trend = 4 AND (base crosses above conversion OR EMA of oscillator crosses above oscillator).
Exit: short, trend = -4 AND (conversion crosses above base OR oscillator crosses above EMA of oscillator).
