Calculation: EMA_f, EMA_m, EMA_s, EMA_t = exponential moving averages of close with lookbacks increasing in that order (fast < mid < slow < trend)
Calculation: Hist = MACD histogram (MACD line minus its signal line); rising = greater than previous bar and previous bar greater than the bar before; falling = the mirror
Calculation: RSI_rising = RSI > RSI[1] > RSI[2]; RSI_falling = RSI < RSI[1] < RSI[2]
Calculation: Squeeze = (Bollinger upper - lower) < SMA of that width over a lookback longer than the Bollinger lookback
Calculation: StochRSI_K = (RSI - lowest RSI over lookback) / (highest RSI - lowest RSI over lookback) * 100
Calculation: W = window of N bars (the same N for both divergences); prior window = the N bars ending N bars earlier
Calculation: Light/Heavy = point weights, Heavy > Light, the same for long and short; all indicators use chart-timeframe bars (no other timeframe)
Calculation: LongScore = sum of: Heavy if EMA_f > EMA_m > EMA_s > EMA_t; Light if close > EMA_f AND close > EMA_m; Heavy if EMA_f crosses above EMA_m on this bar; Light if 50 < RSI < overbought level AND RSI_rising; Heavy if lowest close over W < lowest close over prior window AND lowest RSI over W > lowest RSI over prior window; Light if MACD line > signal AND Hist > 0 AND Hist rising; Heavy if MACD line crosses above signal; Light if Squeeze; Light if close <= lower Bollinger * (1 + small tolerance); Heavy if close crosses above upper Bollinger; Light if ADX > threshold AND +DI > -DI; Heavy if ADX > threshold * factor (factor > 1) AND +DI > -DI; Light if ADX > ADX 3 bars ago AND +DI > -DI; Light if volume > factor (>1) * SMA(volume); Light if volume > SMA(volume); Light if StochRSI_K < oversold level
Calculation: ShortScore = sum of: Light if close < EMA_f AND close < EMA_m; Heavy if EMA_f crosses below EMA_m; Light if oversold level < RSI < 50 AND RSI_falling; Heavy if highest close over W > highest close over prior window AND highest RSI over W < highest RSI over prior window; Light if MACD line < signal AND Hist < 0 AND Hist falling; Heavy if MACD line crosses below signal; Light if Squeeze; Light if close >= upper Bollinger * (1 - small tolerance); Heavy if close crosses below lower Bollinger; Light if ADX > threshold AND -DI > +DI; Heavy if ADX > threshold * factor (factor > 1) AND -DI > +DI; Light if ADX > ADX 3 bars ago AND -DI > +DI; Light if volume > factor (>1) * SMA(volume); Light if volume > SMA(volume); Light if StochRSI_K > overbought level
Long: flat (no position) AND LongScore >= minimum score AND close > EMA_t AND ATR > multiplier * SMA(ATR, lookback longer than the ATR lookback) AND volume > SMA(volume)
Short: flat (no position) AND ShortScore >= minimum score AND close < EMA_t AND ATR > multiplier * SMA(ATR, lookback longer than the ATR lookback) AND volume > SMA(volume)
Exit: long, low <= entry * (1 - stop%) OR high >= entry * (1 + target%) OR (high has reached entry * (1 + trail%) since entry AND low <= highest high since that activation - entry * trail%)
Exit: short, high >= entry * (1 + stop%) OR low <= entry * (1 - target%) OR (low has reached entry * (1 - trail%) since entry AND high >= lowest low since that activation + entry * trail%)
