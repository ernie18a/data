Calculation: Opening-range high = highest high of chart bars in the configured opening session; reset at the start and end of each trading day and valid only after that session ends.
Calculation: Pivot resistance levels = using the last completed higher-timeframe trading-day bar, let P = (high + low + close) / 3; R1 = 2P - low, R2 = P + high - low, R3 = 2P + high - 2low, R4 = 3P + high - 3low, and R5 = 4P + high - 4low. Let H0 = opening-range high + abs(R1 - opening-range high) / 2; H1 = R1 + abs(R1 - R2) / 2; H2 = R2 + abs(R2 - R3) / 2; H3 = R3 + abs(R3 - R4) / 2; H4 = R4 + abs(R4 - R5) / 2.
Calculation: Setup signal = opening-range high is valid AND open < opening-range high AND high > opening-range high AND R1 > opening-range high.
Calculation: Setup counter = zero during the opening session and at exchange day end; otherwise increment when the setup signal is true and no long position is open, regardless of the entry limit or backtest window. Use the previous chart bar's counter for the entry limit.
Calculation: Long stop entry order = at each chart-bar close, submit or update an order at the opening-range high when the opening-range high is valid, no long position is open, the previous setup counter is below its limit, the bar time is strictly inside the configured backtest window, and open < opening-range high. The order remains active until filled, updated, canceled at exchange day end, or canceled on the bar following a setup signal that also met the position and counter conditions. Store the low preceding that setup bar for the previous-low initial stop.
Calculation: Initial stop = minimum of entry price and either entry price multiplied by one minus the configured stop percentage, or the stored low preceding the setup bar, according to the selected mode. For a zero percentage, use a multiplier of 1 - 99999.
Calculation: Trailing stop = zero on entry and while flat. On each later bar in a long position, use the first pair in this descending-priority list whose trigger is below the current high and whose replacement is above the previous trailing stop: (R5, R4), (H4, H3), (R4, R3), (H3, H2), (R3, R2), (H2, H1), (R2, R1), (H1, H0), (H0, opening-range high). Set the trailing stop to that replacement; if no pair qualifies, retain its previous value. Reset at exchange day end.
Long: A previously submitted long stop entry order is active AND high >= its stop price.
Exit: long, low <= the active stop price, where the stop price is the maximum of the initial stop and trailing stop computed at the preceding chart-bar close.
Exit: long, chart-bar close time = exchange trading-day close time.
