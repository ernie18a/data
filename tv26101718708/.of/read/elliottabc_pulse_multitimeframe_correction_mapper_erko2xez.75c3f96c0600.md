Calculation: Confirmed pivot = a pivot high or pivot low identified using configurable left and right bar counts, available only after the right-side bars have completed.
Calculation: Zigzag pivots = process confirmed highs before confirmed lows on each bar. Accept a high when its price divided by the current close meets the minimum swing percentage; accept a low when its absolute distance from the current close divided by the current close meets that percentage. Append an accepted pivot if its type differs from the latest stored pivot; otherwise replace the latest pivot only if the new high is higher or the new low is lower. Retain a configurable maximum number of pivots.
Calculation: ABC window = four consecutive zigzag pivots P0, P1, P2, P3, selected from a configurable number of the most recent four-pivot windows. For H-L-H-L, A = P0 - P1, B = (P2 - P1) / A, and C = (P2 - P3) / A. For L-H-L-H, A = P1 - P0, B = (P1 - P2) / A, and C = (P3 - P2) / A. B and C must each be within their respective inclusive minimum and maximum thresholds.
Calculation: New chart pattern = on a bar with an accepted pivot, an ABC window whose P0 bar is absent from the corresponding bounded history of previously marked P0 bars; record P0 when the pattern is marked. Maintain separate histories for ABC labels and direction markings.
Calculation: Dashboard pattern = the first valid ABC window found when scanning from the newest window toward older windows, recalculated on each bar using a separately maintained zigzag with a shorter pivot-history limit. For a higher timeframe use the last completed higher-timeframe bar; for a lower timeframe use the last completed lower-timeframe bar within the chart bar.
Long: A confirmed pivot low exists.
Short: A confirmed pivot high exists.

Short: Current chart-timeframe RSI is above its upper threshold.

Short: A new chart pattern has L-H-L-H pivots AND B and C are within their respective inclusive bounds AND P3 > P1 AND P2 > P0 AND the optional RSI filter is disabled or current chart-timeframe RSI is above its midpoint.
Short: A new direction pattern has H-L-H-L pivots AND A > 0 AND B and C are within their respective inclusive bounds AND P3 < P1 AND P2 < P0.
Long: A new direction pattern has L-H-L-H pivots AND A > 0 AND B and C are within their respective inclusive bounds AND P3 > P1 AND P2 > P0.

Long: A dashboard pattern has L-H-L-H pivots AND A > 0 AND B and C are within their respective inclusive bounds AND P3 > P1 AND P2 > P0 AND the optional RSI filter is disabled or the dashboard-timeframe RSI is above its midpoint.
