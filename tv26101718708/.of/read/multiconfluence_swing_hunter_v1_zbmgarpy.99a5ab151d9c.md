Calculation: Entry score = 2 if RSI is below its oversold threshold + 2 if RSI is below its more extreme oversold threshold + 1 if RSI rises from the prior bar + 1 if MACD is below zero + 2 if MACD rises from the prior bar + 2 if MACD histogram rises from the prior bar + 2 if the lower wick is more than the configured fraction of the bar range + 1 if the body is less than 30% of the bar range + 1 if close > open + 2 if a prior high within the configured recovery lookback is above close increased by the configured recovery percentage + 4 if a bullish reversal signal occurs. Bullish and bearish divergence points are always zero: the comparison uses the current bar as part of the window that defines the lowest low or highest high, so the current low cannot be lower than that lowest low and the current high cannot be higher than that highest high.
Calculation: Exit score = 2 if RSI is above its overbought threshold + 2 if RSI is above its more extreme overbought threshold + 1 if RSI falls from the prior bar + 1 if MACD is above zero + 2 if MACD falls from the prior bar + 2 if MACD histogram falls from the prior bar + 2 if the upper wick is more than the configured fraction of the bar range + 1 if close < open + 1 if a bearish reversal signal occurs. Bearish divergence points are always zero for the same window-boundary reason.
Calculation: Bullish reversal signal = after at least all but one of the configured prior bars have lows below the current close, record that bar's low and high as a candidate; within the configured confirmation window, signal when close exceeds the candidate high, unless close first falls below the candidate low. If volume confirmation is enabled, also require volume > its 20-bar simple moving average.
Calculation: Bearish reversal signal = after at least all but one of the configured prior bars have highs above the current close, record that bar's low and high as a candidate; within the configured confirmation window, signal when close falls below the candidate low, unless close first rises above the candidate high. If volume confirmation is enabled, also require volume > its 20-bar simple moving average.
Calculation: Long stop = the lowest low from the current bar and configured prior-bar lookback, reduced by the configured buffer percentage.
Calculation: Long target = entry price + (entry price − long stop) × configured risk/reward ratio.
Long: Entry score ≥ configured minimum AND datetime is within the configured date range AND position is flat
Long: Bullish reversal signal
Short: Bearish reversal signal
Exit: Long, Exit score ≥ configured minimum
Exit: Long, low ≤ long stop OR high ≥ long target, when risk/reward exits are enabled
