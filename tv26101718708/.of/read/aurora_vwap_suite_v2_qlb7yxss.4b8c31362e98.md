Calculation: Reset-period VWAP = cumulative volume-weighted average of the selected bar price from the configured reset time; start a new period at each reset.
Calculation: Extreme-anchor VWAP = cumulative volume-weighted average of the selected bar price from a confirmed pivot low or high through the current bar. A pivot qualifies when its bar is in the current or previous observed reset period and its distance from the lowest low or highest high across those periods, measured at confirmation, is at most a multiple of ATR at the pivot. Confirm pivots using equal numbers of preceding and following bars. Expire an anchor when its pivot leaves those periods; replace it according to the selected policy: every qualifying pivot, only a more extreme pivot, or never before expiry.
Calculation: Winning-session VWAP = the cumulative volume-weighted average of the selected bar price for the confirmed winning active session, reset at the session start and reset-period boundary. Eligible sessions have positive accumulated volume and at least a minimum number of observed bars. Score each eligible session by the selected method: accumulated volume relative to the largest eligible total; average volume per observed bar relative to the largest eligible rate; relative activity; or a weighted combination of relative activity and price proximity. Relative activity is recent actual volume divided by expected volume for corresponding elapsed-session slots, transformed to ratio / (1 + ratio); expected slot volume is an EMA learned only from completed sessions whose opens were observed. Until every eligible session has enough trained slot observations, use each session's rate relative to the largest eligible rate instead. Price proximity is exp(-abs(close - session VWAP) / ATR / a scale parameter). Clear the winner at each reset-period boundary or when it is ineligible. Select a unique highest-scoring qualifying candidate after it persists for a configured number of closed bars; an eligible incumbent survives ties, and a challenger must exceed its score by a configured margin throughout confirmation. The winning VWAP is unavailable outside its active session.
Calculation: Bias = sum of votes divided by the number of available votes. Each available reset-period, winning-session, low-anchor, and high-anchor VWAP contributes +1 if close is above it, -1 if close is below it, and 0 if equal. The reset-period VWAP slope contributes +1 if above its value a configured number of bars earlier, -1 if below, and 0 if equal; include it only when both values belong to the same reset period. Unavailable references contribute neither a vote nor to the denominator.
Long: Bias >= positive bias threshold
Short: Bias <= negative bias threshold
Long: Close > low extreme-anchor VWAP + ATR tolerance
Short: Close < low extreme-anchor VWAP - ATR tolerance
Long: Close > high extreme-anchor VWAP + ATR tolerance
Short: Close < high extreme-anchor VWAP - ATR tolerance
