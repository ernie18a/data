Calculation: Feature vector = using a selected price series derived from the backtest fields, calculate centered RSI; RSI change over a lookback; the change in that RSI change over the same lookback; shorter-length RSI minus longer-length RSI; RSI percentile rank; RSI standard deviation; centered RSI of higher-timeframe close using the last completed higher-timeframe bar; selected price minus its trend EMA, divided by ATR, or zero if ATR is zero; ADX; and ATR percentile rank. Center and scale these features respectively as (RSI-50)/50, RSI change/10, change in RSI change/10, RSI spread/50, percentile rank/100-0.5, standard deviation/20, (higher-timeframe RSI-50)/50, price distance in ATR, unscaled ADX, and ATR percentile rank/100-0.5. Use the same RSI length for the chart and higher-timeframe RSI, a shorter length for the fast RSI, and a longer length for the slow RSI.
Calculation: Network probabilities = initialize a one-hidden-layer, three-class neural network with zero biases and seeded uniform random weights scaled by the inverse square root of each layer's input count; initialize feature means to zero, variances to one, and Adam moments to zero. On each completed chart bar, update each available feature's exponentially weighted mean and variance using d=feature-mean, mean=mean+alpha*d, variance=(1-alpha)*(variance+alpha*d*d), with alpha determined by the normalization window. Once the required history is available and all features from the forecast horizon ago are defined, add those raw features to the front of a bounded replay buffer with a label: up if the selected price change since that bar exceeds its ATR times the move threshold, down if it is below the negative threshold, otherwise neutral. After the minimum replay-buffer size is reached, perform the specified number of epochs over the most recent replay batch, newest first, standardizing each stored feature using the current mean and variance. Train using tanh hidden activations, three-class softmax, cross-entropy gradients, bias-corrected Adam, and L2 regularization on weights only. After training, standardize the current features using the current statistics and run the network to obtain up and down probabilities. Count each valid added sample for warm-up.
Calculation: Conviction = 50+50*(up probability-down probability).
Calculation: Center = either 50 or an exponentially updated mean of conviction initialized to 50 and updated on each completed bar before evaluating the current bar.
Calculation: Direction = neutral if absolute conviction minus center is strictly less than the neutral-zone width; otherwise up if conviction exceeds center, and down otherwise.
Long: Conviction > center.
Short: Conviction < center.
Long: Conviction > 50.
Short: Conviction < 50.
Long: Direction = up AND previous-bar direction != up.
Short: Direction = down AND previous-bar direction != down.
Long: Valid sample count >= warm-up sample threshold AND direction = up.
