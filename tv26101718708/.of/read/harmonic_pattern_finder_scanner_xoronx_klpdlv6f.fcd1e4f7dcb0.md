Calculation: ATR ZigZag pivots = Rebuild over a configurable rolling history on each chart bar. Initialize a trough at the first bar, direction down, last pivot, preceding pivot and opposite-extreme indices at that bar, and smoothed true range at zero. For each subsequent bar except the current bar, update smoothed true range with EMA of max(high, previous close) - min(low, previous close). In an up swing, reversal is mandatory when low is below the preceding pivot bar's low, or allowed when low is below the tracked opposite extreme, the distance from the last peak to low exceeds smoothed true range times a multiplier, and the minimum pivot spacing has elapsed. Mirror these tests in a down swing using highs and the last trough. Update the tracked opposite extreme whenever its low or high is surpassed. Move the current pivot to a more extreme high or low; if the same bar also reverses, retain both pivots according to candle direction: a bearish candle permits peak then trough, and a bullish candle permits trough then peak. Otherwise reverse at the current bar when the reversal test passes. If the maximum pivot spacing is exceeded without reversal, place the opposite pivot at the most extreme low or high since the last pivot, choosing the latest equal extreme and excluding the pivot bar when it already has both pivots or its candle direction implies the opposite extreme occurred first. If realtime mode is enabled, the current bar can only move the latest pivot to a more extreme high or low; it cannot create a reversal. Otherwise exclude the current bar. Emit pivots in chronological order; on a bar containing both, emit trough then peak when close >= open, otherwise peak then trough.
Calculation: Harmonic candidates = Search pivot events within a configurable lookback for alternating X, A, B, C and optionally D. X is a trough for bullish candidates and a peak for bearish candidates. For bullish candidates, stop each nested search if a later trough before A breaks below X, a later peak before B breaks above A, a later trough before C breaks below B, or a later peak before D breaks above C; mirror all inequalities for bearish candidates. Consider only successive record extremes for A, B, C and D in their respective swing directions. Require nonzero XA, AB, BC and XC, and require each active pattern-specific ratio AB/XA, BC/AB and XC/XA to lie within its configured range expanded by an additive tolerance, with separate tolerances for fixed-ratio and range constraints. Use configurable ratio ranges separately for Bat, Butterfly, Shark, Cypher, Crab, Deep Crab and Gartley; inactive ratios impose no constraint. For each active D constraint, project its tolerance-expanded minimum and maximum from A using XA for AD/XA, or from C using BC for CD/BC or XC for CD/XC, downward for bullish and upward for bearish. The completion window is the intersection of these projected price intervals, with endpoints floored at zero; reject an empty window or one whose endpoints are both zero. Optionally require every unexpanded D constraint interval to overlap this window. Optionally require each leg's bar count to meet a minimum, each successive leg-count ratio to lie within configured bounds, and CD/XA bar-count ratio to be at most its configured maximum. Optionally reject D before B plus floor(early factor times X-to-B bars), or at or after B plus ceil(late factor times X-to-B bars); for projections apply only the late filter using the current bar.
Calculation: Completed candidate = A harmonic candidate whose D pivot is inside its completion window, inclusive. Stop searching later D pivots after the first D beyond the far edge. For each pattern type, process completed candidates by increasing D bar and reject a candidate sharing all four X/A/B/C indices, or more than a configurable maximum number of X/A/B/C/D indices, with an earlier accepted candidate of that type.
Calculation: Projected candidate = A harmonic candidate whose D pivot has not yet reached the near edge of its completion window, provided no later same-kind pivot is more extreme than C or D; alternatively C is the latest pivot in its direction and D is projected at the current bar and the near edge. Apply the leg-count and optional projection filters. Reject candidates overlapping accepted completed candidates as above. For each pattern type and direction, process remaining projections in near-edge price order, ascending for bearish and descending for bullish, rejecting any sharing more than the configurable maximum number of X/A/B/C indices with an earlier accepted projection of that type and direction.
Long: X is a trough AND a completed candidate exists OR X is a trough AND a projected candidate exists.
Short: X is a peak AND a completed candidate exists OR X is a peak AND a projected candidate exists.
