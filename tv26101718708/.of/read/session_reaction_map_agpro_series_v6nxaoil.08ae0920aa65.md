Calculation: Reference = the enabled level nearest the session-start bar's open, with ties resolved in this order: previous-period high, previous-period low, their midpoint, current-period open, longer-period open. The first four use a higher timeframe than the chart; the last uses a still higher timeframe. Map these higher-timeframe values to historical chart bars with lookahead off: update them on the higher-timeframe bar's last chart bar and forward-fill between updates. Previous-period high and low use the preceding completed higher-timeframe bar; current-period and longer-period opens use the higher-timeframe bar still forming.
Calculation: Reaction window = start on the first chart bar in an enabled session when no other window is active, the ATR warmup is complete, and the absolute distance between that bar's open and the reference is at most an ATR-based tolerance. Include the start bar and a configurable number of consecutive chart bars, then end the window. Ignore session starts while a window is active.
Calculation: Upside excursion = max(0, highest high since the reaction window started minus its fixed reference); downside excursion = max(0, its fixed reference minus the lowest low since the window started).
Long: A reaction window is active AND upside excursion >= downside excursion.
Short: A reaction window is active AND upside excursion < downside excursion.
