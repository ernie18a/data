Calculation: Normalized high score H(x,a,b) = 0 if a = b; otherwise clamp(100 × (x − a) / (b − a), 0, 100). Normalized low score L(x,a,b) = 0 if a = b; otherwise clamp(100 × (b − x) / (b − a), 0, 100).
Calculation: Event measurements = relative volume is volume divided by its rolling SMA, or 1 if the SMA is unavailable or nonpositive; range is max(high − low, a positive price precision); safe ATR is max(ATR, or true range when ATR is unavailable, a positive price precision); spread is range / safe ATR; body share is abs(close − open) / range; bullish close edge is (close − low) / range; bearish close edge is 1 − bullish close edge. Use a shorter and a longer EMA of close; EMA slope is the longer EMA minus its value a configurable number of bars earlier, using the current longer EMA if that earlier value is unavailable.
Calculation: Event score for direction d, where d is +1 for bullish and −1 for bearish = clamp(0.32 × volume score + 0.20 × spread score + 0.18 × directional close score + 0.14 × body score + 0.16 × directional trend score, 0, 100). Volume score is H(relative volume, adjusted minimum volume × 0.72, ideal volume) when relative volume ≤ ideal volume, otherwise L(relative volume, ideal volume, volume ceiling); use an ideal volume at least adjusted minimum volume + 0.10 and a ceiling for this score at least the configured ideal volume + 0.10. Spread score is H(spread, adjusted minimum spread × 0.70, adjusted minimum spread + 0.95); body score is H(body share, adjusted minimum body share × 0.80, 0.82); directional close score is H(directional close edge, adjusted minimum close edge × 0.88, 0.95). Trend score is clamp(A + B + C, 0, 100), where A is 34 if d × (close − longer EMA) ≥ 0, otherwise 12; B is 36 if d × (shorter EMA − longer EMA) ≥ 0, otherwise 0; C is 0.30 × H(abs(EMA slope) / safe ATR, 0.01, 0.28) if d × EMA slope ≥ 0, otherwise 0. Adjust the minimum volume and spread by a sensitivity multiplier, and adjust the minimum body share and close edge by sensitivity offsets, clamping the latter to their respective allowed ranges.
Calculation: Active event = the most recent qualified directional event after the event cooldown; a new event replaces the previous one. Store its direction, close, high, low, safe ATR and event score. Its risk rail is event low − event ATR × risk buffer for bullish events or event high + event ATR × risk buffer for bearish events; its target is event close + direction × event ATR × target distance. The event is unresolved until its first rail break, target touch, ready condition, one-bar condition, replacement, or tracking-window expiry.
Calculation: Follow-through score = clamp(0.28 × event score + 0.28 × progress score + 0.18 × next-bar score + 0.12 × close-count score + 0.10 × defense score + 0.04 × time score, 0, 100). On each bar after the event within the tracking window, best favorable price is the highest high for a bullish event or lowest low for a bearish event since and including the event; progress is max(direction × (best favorable price − event close), 0) / event ATR. Worst adverse movement is the maximum since the event of max(event close − low, 0) / event ATR for bullish events or max(high − event close, 0) / event ATR for bearish events. Progress score is H(progress, required progress × 0.25, required progress × 1.70). Next-bar score is clamp(100 × direction × (next bar close − event close) / event ATR / max(required progress × 0.80, 0.05), 0, 100). Close-count score is H(number of closes in the follow-through window strictly beyond the event close in the event direction, 0, required close count + 1). Defense score is 0 if the current close breaks the rail, otherwise L(worst adverse movement, 0.10, adverse limit). Time score is L(bars since event, follow-through window × 0.25, follow-through window + 4) within that window, otherwise L(bars since event, follow-through window, tracking window).
Long: relative volume ≥ adjusted minimum volume AND relative volume ≤ volume ceiling AND spread ≥ adjusted minimum spread AND body share ≥ adjusted minimum body share AND close ≥ open AND bullish close edge ≥ adjusted minimum close edge AND bullish event score ≥ minimum event score AND bullish events are enabled AND no previous event exists OR relative volume ≥ adjusted minimum volume AND relative volume ≤ volume ceiling AND spread ≥ adjusted minimum spread AND body share ≥ adjusted minimum body share AND close ≥ open AND bullish close edge ≥ adjusted minimum close edge AND bullish event score ≥ minimum event score AND bullish events are enabled AND bars since previous event ≥ event cooldown; if both directional candidates qualify, select the bullish candidate when its event score ≥ the bearish event score.
Short: relative volume ≥ adjusted minimum volume AND relative volume ≤ volume ceiling AND spread ≥ adjusted minimum spread AND body share ≥ adjusted minimum body share AND close ≤ open AND bearish close edge ≥ adjusted minimum close edge AND bearish event score ≥ minimum event score AND bearish events are enabled AND no previous event exists OR relative volume ≥ adjusted minimum volume AND relative volume ≤ volume ceiling AND spread ≥ adjusted minimum spread AND body share ≥ adjusted minimum body share AND close ≤ open AND bearish close edge ≥ adjusted minimum close edge AND bearish event score ≥ minimum event score AND bearish events are enabled AND bars since previous event ≥ event cooldown; if both directional candidates qualify, select the bearish candidate only when its event score > the bullish event score.
Long: active event is bullish AND event is unresolved AND bars since event > 0 AND bars since event ≤ tracking window AND close > risk rail AND high < target AND follow-through score ≥ minimum follow-through score AND progress score ≥ ready progress threshold AND follow-through close count ≥ required close count.
Short: active event is bearish AND event is unresolved AND bars since event > 0 AND bars since event ≤ tracking window AND close < risk rail AND low > target AND follow-through score ≥ minimum follow-through score AND progress score ≥ ready progress threshold AND follow-through close count ≥ required close count.
Long: shorter EMA > longer EMA AND longer EMA slope ≥ 0.
Short: shorter EMA < longer EMA AND longer EMA slope ≤ 0.
Exit: long, active event is bullish AND event is unresolved AND bars since event > 0 AND bars since event ≤ tracking window AND close ≤ risk rail.
Exit: short, active event is bearish AND event is unresolved AND bars since event > 0 AND bars since event ≤ tracking window AND close ≥ risk rail.
