Calculation: Follow line = On each bar, calculate Bollinger Bands from the simple moving average and standard deviation of close. If close is above the upper band, set the candidate to low minus ATR when the optional ATR offset is enabled, otherwise low, and set the line to the greater of the candidate and previous line. If close is below the lower band, set the candidate to high plus ATR when the optional ATR offset is enabled, otherwise high, and set the line to the lesser of the candidate and previous line. If there is no previous line, use the candidate. Otherwise carry the previous line forward. Before the first valid candidate, the line is undefined. For the higher timeframe only, use low or high without the offset if ATR is unavailable.
Calculation: Trend = 1 when the follow line rises and -1 when it falls; retain the previous trend when the line is unchanged. When the first valid line appears, set trend to 1 if close is above the upper Bollinger Band or -1 if close is below the lower band. Use 0 while the line is undefined.
Calculation: Higher-timeframe trend = Trend calculated on higher-timeframe bars with the same indicator parameters as the chart timeframe, using the last completed higher-timeframe bar; use 0 if unavailable or if both higher-timeframe confirmation and higher-timeframe line display are disabled.
Long: Chart trend = 1 AND previous chart trend <= 0 AND chart ATR is available
Long: Chart trend = 1 AND previous chart trend <= 0 AND position side is flat or short AND (session filter is disabled OR bar is within the configured session) AND (higher-timeframe confirmation is disabled OR higher-timeframe trend = 1)
Short: Chart trend = -1 AND previous chart trend >= 0 AND chart ATR is available
Short: Chart trend = -1 AND previous chart trend >= 0 AND position side is flat or long AND (session filter is disabled OR bar is within the configured session) AND (higher-timeframe confirmation is disabled OR higher-timeframe trend = -1)
Exit: long, chart trend = -1 OR higher-timeframe trend = -1
Exit: short, chart trend = 1 OR higher-timeframe trend = 1
