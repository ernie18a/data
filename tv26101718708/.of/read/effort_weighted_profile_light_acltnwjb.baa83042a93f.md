Calculation: Analysis bars = completed lower-timeframe bars within each completed chart bar, or the completed chart bar itself when the analysis timeframe equals the chart timeframe.
Calculation: Row directional ratio = for each independent session profile, divide the sum of signed weights by the sum of weights across each group of adjacent price rows. Partition the session's fixed-width price grid into consecutive groups using a configurable maximum group count; group size is the ceiling of the grid row count divided by that maximum. Include only positive-weight groups. Accumulate each session from analysis bars fully contained in its configurable session window; optionally restrict weekdays and apply an earlier session cutoff. A bar's direction is +1 if close > open, -1 if close < open, and for a doji +1 if close > previous analysis-bar close, -1 if close < previous analysis-bar close, otherwise 0. Allocate volume to each intersected row in proportion to its overlap with the bar's high-low range; for a zero-range bar allocate all volume to its containing row. The row contribution is allocated volume, optionally multiplied by inhibition × (1 + memory strength × old memory). Inhibition is 1 - min(1, abs(close - open) / (high - low)), or 1 for a zero-range bar. Old memory is the row's stored memory decayed exponentially by elapsed time since its last visit, using a configurable half-life. After weighting each analysis bar, update memory once per visited row across all overlapping sessions: add one on a return after at least one intervening analysis bar without a visit when inhibition meets a configurable minimum, cap the result, and store it with the visit time. Initialize memory to zero; evict the oldest inserted row when the configurable memory capacity is reached. Signed weight is contribution × bar direction. Evaluate profiles at chart-bar close, including completed session profiles when they finish.
Long: Row directional ratio > configurable positive tolerance
Short: Row directional ratio < negative configurable positive tolerance
