Calculation: On-chain composite = moving average of the weighted average of four smoothed Z-scores: NVT (market capitalization / transaction volume), MVRV (market capitalization / realized capitalization), AVIV (price / EMA of realized price, where realized price = realized capitalization / supply), and SOPR. Each Z-score is (value − rolling mean) / rolling standard deviation. The four source series use daily data; on a higher timeframe, use its last completed bar historically and its still-forming bar in real time.
Long: composite > long threshold OR (composite <= long threshold AND composite >= short threshold AND previous state = long)
Short: composite < long threshold AND composite < short threshold OR (composite <= long threshold AND composite >= short threshold AND previous state = short)
