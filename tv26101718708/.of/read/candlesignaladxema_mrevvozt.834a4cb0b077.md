Calculation: Reference bar = the first confirmed chart bar when the pattern state is idle. On the next confirmed bar, if neither sweep setup qualifies, replace the reference with that bar. If a sweep setup qualifies, evaluate the immediately following bar as the breakout bar; after that bar, return to idle if a filtered breakout qualified and no trade was active at its start, otherwise make that bar the new reference. Pattern state continues updating during trades.
Calculation: Long stop = reference-bar low minus entry-bar ATR multiplied by the stop-distance parameter; long target = entry price plus the entry-to-stop distance multiplied by the reward-to-risk parameter. Short stop = reference-bar high plus entry-bar ATR multiplied by the stop-distance parameter; short target = entry price minus the entry-to-stop distance multiplied by the reward-to-risk parameter. Entry price is the reference high for a long and the reference low for a short; retain these levels from entry.
Calculation: Exit evaluation = inspect lower-timeframe completed bars in chronological order. On the entry chart bar, begin with the first lower-timeframe bar whose high reaches the long entry price or whose low reaches the short entry price; include that entire lower-timeframe bar. On subsequent chart bars, begin with the first lower-timeframe bar. If both stop and target are reached in the same lower-timeframe bar, the stop is first. If no lower-timeframe bars are available, use the chart bar's high and low only after the entry chart bar, with the stop first if both are reached.
Long: No trade active at the start of the breakout bar AND the immediately preceding confirmed bar has low < reference low AND high <= reference high AND close >= reference low AND close <= reference high AND breakout-bar high >= reference high + breakout-bar ATR multiplied by the breakout-buffer parameter AND (MA filter disabled OR breakout-bar close > selected EMA or SMA) AND (ADX filter disabled OR ADX >= threshold) AND (session filter disabled OR breakout-bar exchange time is within the inclusive session, including overnight sessions).
Short: No trade active at the start of the breakout bar AND the immediately preceding confirmed bar has high > reference high AND low >= reference low AND close >= reference low AND close <= reference high AND breakout-bar low <= reference low - breakout-bar ATR multiplied by the breakout-buffer parameter AND (MA filter disabled OR breakout-bar close < selected EMA or SMA) AND (ADX filter disabled OR ADX >= threshold) AND (session filter disabled OR breakout-bar exchange time is within the inclusive session, including overnight sessions).
Long: Previous close < previous open AND current close > previous high AND (displacement filter disabled OR current close - current open > current ATR multiplied by the displacement parameter).
Short: Previous close > previous open AND current close < previous low AND (displacement filter disabled OR current open - current close > current ATR multiplied by the displacement parameter).
Long: Close > EMA OR close > SMA.
Short: Close < EMA OR close < SMA.
Exit: Long, the first eligible lower-timeframe bar has low <= long stop OR high >= long target, using exit evaluation.
Exit: Short, the first eligible lower-timeframe bar has high >= short stop OR low <= short target, using exit evaluation.
