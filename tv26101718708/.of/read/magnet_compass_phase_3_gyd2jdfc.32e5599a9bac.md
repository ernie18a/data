Calculation: Reference bar = last completed higher-timeframe bar, captured on the first chart bar of each new higher-timeframe period; retain its high, low, close, opening time, ATR and midpoint until the next period.
Calculation: Prior = configured signed value keyed by the reference bar's opening time in the configured timezone; use zero for unlisted times or, when the optional session filter is enabled, times outside the configured session.
Calculation: Close location = (reference close − reference low) / (reference high − reference low), or the range midpoint as a fraction when the range is zero.
Calculation: Live score = prior sign + close-location score + VWAP score + trend score. Close-location score is positive above or at a configured upper threshold, negative below or at a configured lower threshold, otherwise zero. VWAP score is positive when reference close exceeds the session VWAP of chart-bar typical price on the chart bar preceding the new period, negative when it does not, and zero if VWAP is unavailable. Trend score is the sign of short-term EMA minus long-term EMA of higher-timeframe closes, using the last completed higher-timeframe bar; it is zero if either EMA is unavailable.
Calculation: Armed = prior is nonzero AND live score has the same sign as prior AND close location is within its configured inclusive band AND absolute live score is at least its configured minimum AND, in scalp mode, reference high minus reference low is at least the configured minimum range.
Calculation: Swing stop = for a long, the highest retained unswept confirmed pivot low below entry, or reference low if none exists, minus a configured price buffer; for a short, the lowest retained unswept confirmed pivot high above entry, or reference high if none exists, plus the buffer. A pivot is confirmed after the configured number of chart bars on each side; retain only the configured maximum number of most recent pivots of each type, and remove a pivot low when a chart-bar low reaches or falls below it and a pivot high when a chart-bar high reaches or exceeds it.
Calculation: Swing-mode stop = selected swing stop, buffered opposite reference extreme, buffered reference midpoint, entry plus or minus a configured fixed distance and buffer, or entry plus or minus a configured multiple of reference ATR and buffer; subtract distances for long and add them for short. If reference ATR is unavailable, use zero for its contribution. Swing-mode target = selected reference midpoint or bias-side reference extreme.
Calculation: Scalp limit = reference low minus a configured offset for a long, or reference high plus that offset for a short. Scalp stop = entry minus the configured stop distance for a long, or entry plus it for a short. Scalp target = entry plus the configured target distance for a long, or entry minus it for a short; when scaling is enabled, use the configured runner distance instead. Partial target = entry plus the configured target distance for a long, or entry minus it for a short.
Long: Swing mode AND armed AND prior > 0 AND current chart bar is the first bar of the new higher-timeframe period.
Short: Swing mode AND armed AND prior < 0 AND current chart bar is the first bar of the new higher-timeframe period.
Long: Scalp mode AND armed AND prior < 0 AND current chart bar is the first bar of the new higher-timeframe period.
Short: Scalp mode AND armed AND prior > 0 AND current chart bar is the first bar of the new higher-timeframe period.
Long: Swing mode AND armed AND prior > 0 AND current chart bar is the second bar of the higher-timeframe period AND high < reference high; entry price = current open.
Short: Swing mode AND armed AND prior < 0 AND current chart bar is the second bar of the higher-timeframe period AND low > reference low; entry price = current open.
Long: Scalp mode AND armed AND prior < 0 AND no entry has occurred in the current period AND current chart bar is after the first bar of the period AND low <= scalp limit; entry price = scalp limit.
Short: Scalp mode AND armed AND prior > 0 AND no entry has occurred in the current period AND current chart bar is after the first bar of the period AND high >= scalp limit; entry price = scalp limit.
Exit: Long, swing mode AND low <= swing-mode stop OR high >= swing-mode target; evaluate on the entry bar and subsequent bars, with stop taking precedence if both are reached.
Exit: Short, swing mode AND high >= swing-mode stop OR low <= swing-mode target; evaluate on the entry bar and subsequent bars, with stop taking precedence if both are reached.
Exit: Long, scalp mode AND scaling enabled AND no partial has been taken AND high >= partial target AND low > current stop; exit half and move the remaining stop to entry for subsequent bars.
Exit: Short, scalp mode AND scaling enabled AND no partial has been taken AND low <= partial target AND high < current stop; exit half and move the remaining stop to entry for subsequent bars.
Exit: Long, scalp mode AND low <= current stop OR high >= scalp target; evaluate on the entry bar and subsequent bars using the stop in force at the start of the bar, with stop taking precedence if both are reached.
Exit: Short, scalp mode AND high >= current stop OR low <= scalp target; evaluate on the entry bar and subsequent bars using the stop in force at the start of the bar, with stop taking precedence if both are reached.
Exit: Long, a position remains open at the start of the next higher-timeframe period; exit at the preceding chart bar's close.
Exit: Short, a position remains open at the start of the next higher-timeframe period; exit at the preceding chart bar's close.
