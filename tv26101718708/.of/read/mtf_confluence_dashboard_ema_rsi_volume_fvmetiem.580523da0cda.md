Calculation: Timeframe score = EMA score + RSI score + volume score. EMA score is +1 when four close EMAs are strictly ordered from shortest to longest in descending value, -1 when they are strictly ordered in ascending value, and 0 otherwise. RSI score is +1 when RSI is above an upper threshold, -1 when RSI is below a lower threshold, and 0 otherwise. Volume score is +1 when volume exceeds its SMA multiplied by a spike multiplier AND close > open, -1 when volume exceeds that product AND close < open, and 0 otherwise.
Calculation: Confluence = sum of the timeframe scores for four distinct timeframes. On the chart timeframe use the current bar; on a higher timeframe use the last completed bar on historical data and the still-forming bar in real time; on a lower timeframe use the last available intrabar within the chart bar.
Calculation: Signal state = initially no direction, reset achieved, and bar gap satisfied. On each chart bar, first mark reset achieved if absolute confluence <= a neutral-zone threshold. An aligned buy event occurs when confluence >= the aligned threshold and previous confluence < that threshold; an aligned sell event occurs when confluence <= the negative aligned threshold and previous confluence > that threshold. A lean buy event occurs when confluence >= the lower lean threshold AND confluence < the aligned threshold AND previous confluence < the lean threshold. A lean sell event occurs when confluence <= the negative lean threshold AND confluence > the negative aligned threshold AND previous confluence > the negative lean threshold. Accept an event if its direction matches the last accepted direction or there is no last accepted direction, OR if its direction is opposite AND the number of chart bars since the last accepted event >= a minimum gap AND reset is achieved when reset is required. After an accepted event, store its direction, set the bar gap to zero, and mark reset unachieved. Both aligned and lean events update this state.
Long: Any timeframe score >= 2.
Short: Any timeframe score <= -2.
Long: Any timeframe close > its long-term close EMA, using the same timeframe bar selection as the timeframe score.
Short: Any timeframe close <= its long-term close EMA, using the same timeframe bar selection as the timeframe score.
Long: Confluence >= the lean threshold.
Short: Confluence <= the negative lean threshold.
Long: An aligned buy event or lean buy event is accepted by the signal state.
Short: An aligned sell event or lean sell event is accepted by the signal state.
