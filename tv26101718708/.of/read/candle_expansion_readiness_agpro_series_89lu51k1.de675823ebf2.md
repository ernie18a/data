Calculation: Direction = bullish or bearish as selected; in automatic mode use bullish if close > open, bearish if close < open, and for a doji use bullish if close >= previous close, otherwise bearish; on the first bar use the current close as the previous close.
Calculation: Candle measures = range is max(high - low, a positive price floor); body is abs(close - open); upper wick is high - max(open, close); lower wick is min(open, close) - low; directional close location is (close - low) / range for bullish direction and (high - close) / range for bearish direction; directional wick is upper wick / range for bullish direction and lower wick / range for bearish direction. Safe ATR is max(ATR, a positive price floor), substituting true range when ATR is unavailable.
Calculation: High-good score = clamp((value - weak) / (strong - weak), 0, 1); low-good score = clamp((bad - value) / (bad - good), 0, 1); either score is zero if its denominator is zero. Peak score = high-good score between a lower bound and an ideal when value <= ideal, otherwise low-good score between the ideal and an upper bound.
Calculation: Readiness score = round the weighted sum of: high-good score of body / range; low-good score of max((upper wick + lower wick) / range, directional wick multiplied by a wick factor); high-good score of volume / SMA(volume), or a neutral score when volume or its average is unavailable or nonpositive; peak score of range / safe ATR; high-good score of directional close location; and peak score of range / SMA(high - low), substituting a neutral ratio when the average is unavailable or nonpositive. Each component has its own bounds and weight; use a consistent scoring scale.
Calculation: Ready = readiness score >= ready threshold AND body score >= body-quality threshold AND directional close-location score >= close-quality threshold AND, if volume confirmation is selected, volume score >= volume-confirmation threshold AND, if edge confirmation is selected, bullish close > previous high or bearish close < previous low.
Calculation: Watch = readiness score >= watch threshold AND body score >= body-quality threshold AND directional close-location score >= close-quality threshold AND Ready = false; the watch threshold is lower than the ready threshold.
Calculation: Active plan = start on a Ready bar if no plan is monitoring, no plan outcome occurred on that bar, and the required follow-through spacing has elapsed since the previous plan started. Save its direction, start bar, risk edge and target. For a bullish plan, risk edge = start-bar low - safe ATR times a buffer and target = start-bar close + max(body times a target multiplier, safe ATR times a minimum-target multiplier); reverse the signs and use start-bar high for a bearish plan. Evaluate outcomes only after the start bar, in order: risk-edge breach, target reached, then age greater than the follow-through window. Stop monitoring at the first outcome.
Long: Direction = bullish AND (Ready = true OR Watch = true).
Short: Direction = bearish AND (Ready = true OR Watch = true).
Exit: long, active bullish plan is monitoring AND (close < its risk edge OR high >= its target OR plan age > follow-through window).
Exit: short, active bearish plan is monitoring AND (close > its risk edge OR low <= its target OR plan age > follow-through window).
