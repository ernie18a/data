Calculation: Source = (high + low + close) / 3; price change = source minus prior source; path = sum of absolute price changes over the main lookback; efficiency = absolute net source change over the main lookback divided by path, or zero if path is zero or unavailable.
Calculation: Impulse = EMA of price change divided by EMA of absolute price change using the same shorter-than-main lookback, or zero if the denominator is zero.
Calculation: Adaptive basis = slow EMA of source plus (fast EMA of source minus slow EMA of source) multiplied by the weighted sum of efficiency and absolute impulse, clamped between zero and one. The slow EMA uses the main lookback; the fast EMA uses a shorter lookback.
Calculation: Adaptive band = (weighted sum of RMA of true range and EMA of absolute source-to-basis distance, using the same shorter-than-main lookback) multiplied by a band multiplier and a volatility regime factor. The regime factor is the ratio of short-lookback EMA of true range to main-lookback EMA of true range, clamped to lower and upper bounds, or one if the denominator is zero. The short volatility lookback is shorter than the band lookback.
Calculation: Bullish setup = close > adaptive basis + adaptive band multiplied by reversal buffer AND impulse > positive momentum threshold AND adaptive basis > its value a shorter-than-main slope lookback ago. Bearish setup = close < adaptive basis - adaptive band multiplied by reversal buffer AND impulse < negative momentum threshold AND adaptive basis < its value the same slope lookback ago.
Calculation: Trend state = initially neutral; set to bullish when the bullish setup has held for the required consecutive bars and was not confirmed on the prior bar; set to bearish when the bearish setup has held for the required consecutive bars and was not confirmed on the prior bar; otherwise retain the previous state. Calculate independently on the chart timeframe and each selected timeframe.
Calculation: Selected-timeframe state = chart trend state when the selected timeframe equals the chart timeframe; for a higher timeframe, use the last completed higher-timeframe bar's state; for a lower timeframe, use the state of the bar preceding the last lower-timeframe bar within the chart bar.
Calculation: Overall score = sum of selected-timeframe states weighted by log(1 + timeframe duration / shortest selected timeframe duration), divided by the sum of weights; encode bullish as +1, bearish as -1, and neutral or unavailable as 0.
Long: Chart trend state = bullish OR any selected-timeframe state = bullish OR overall score >= positive overall threshold.
Short: Chart trend state = bearish OR any selected-timeframe state = bearish OR overall score <= negative overall threshold.
