Calculation: Window move = percentage change from the close at the start of the trailing window to the latest close, using the latest available lower-timeframe bar (including a still-forming bar where available).
Calculation: EMA separation = (short-lookback EMA of lower-timeframe closes − long-lookback EMA of lower-timeframe closes) / long-lookback EMA × 100; use the latest available lower-timeframe bar, including a still-forming bar where available.
Calculation: RSI = Wilder RSI of lower-timeframe closes sampled at a fixed stride, anchored at the latest close; use the latest available data, including a still-forming bar where available.
Calculation: Volume ratio = volume in the trailing window divided by the average volume of prior non-overlapping windows of the same length; use the latest available lower-timeframe bars, including a still-forming bar where available.
Calculation: Micro momentum = EMA of lower-timeframe close-to-close percentage returns; use the latest available bar, including a still-forming bar where available.
Calculation: Acceleration = current micro momentum − micro momentum from a fixed number of lower-timeframe bars earlier.
Calculation: Tick net = sum of the signs of close-to-close changes across the latest fixed number of lower-timeframe bars.
Calculation: Realized volatility = population standard deviation of lower-timeframe close-to-close percentage returns over the trailing window.
Calculation: EMA vote = +1 if EMA separation exceeds its positive deadband, −1 if below its negative deadband, otherwise 0.
Calculation: RSI vote = +1 if RSI is at or above its bullish threshold, −1 if RSI is at or below its bearish threshold, otherwise 0.
Calculation: Volume vote = sign of Window move if Volume ratio is at or above its surge threshold and Window move is nonzero, otherwise 0.
Calculation: Move vote = +1 if Window move exceeds its positive deadband, −1 if below its negative deadband, otherwise 0.
Calculation: Momentum vote = +1 if Micro momentum exceeds its positive deadband, −1 if below its negative deadband, otherwise 0.
Calculation: Acceleration vote = +1 if Acceleration exceeds its positive deadband, −1 if below its negative deadband, otherwise 0.
Calculation: Tick vote = +1 if Tick net is at least 2, −1 if Tick net is at most −2, otherwise 0.
Calculation: Bull votes = count of positive EMA, RSI, Volume, Move, Momentum, Acceleration, and Tick votes.
Calculation: Bear votes = count of negative EMA, RSI, Volume, Move, Momentum, Acceleration, and Tick votes.
Calculation: Bullish momentum count = count of positive RSI, Momentum, Acceleration, and Tick votes.
Calculation: Bearish momentum count = count of negative RSI, Momentum, Acceleration, and Tick votes.
Long: absolute Window move is at least the strong-trend threshold AND EMA separation × Window move > 0 AND Bullish momentum count > 0 AND Bearish momentum count = 0 AND Bull votes > Bear votes AND previous state is neither UPTREND nor WARMUP.
Short: absolute Window move is at least the strong-trend threshold AND EMA separation × Window move < 0 AND Bearish momentum count > 0 AND Bullish momentum count = 0 AND Bear votes > Bull votes AND previous state is neither DOWNTREND nor WARMUP.
