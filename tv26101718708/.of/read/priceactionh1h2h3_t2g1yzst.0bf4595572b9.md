Calculation: Bull trend = short-period EMA of close > medium-period EMA of close AND medium-period EMA of close > long-period EMA of close.
Calculation: Pullback bar = close < previous close OR low < previous low.
Calculation: Bull surge = bull trend AND ((close > open AND high − low >= surge multiplier × previous bar's ATR) OR (close > open AND previous close > previous open AND maximum high of current and previous bars − minimum low of current and previous bars >= surge multiplier × ATR two bars ago)).
Calculation: Tight bear channel = bearish candle count over the channel lookback >= channel lookback − 1 AND highest high − lowest low over that lookback <= channel multiplier × current ATR AND close < close at the channel lookback.
Calculation: Setup state = process confirmed bars in order, executing only the branch for the state entered on that bar. Start idle. Whenever bull trend is false, reset a non-idle state to idle before processing the bar. In idle, a bull surge starts tracking, with surge top and bottom set to the current high and low if the single-bar surge condition holds, otherwise to the maximum high and minimum low of the current and previous bars; set attempt count to 1. In tracking, first raise surge top to the current high if higher; on a pullback bar, set reference high to current high, abandonment level to surge top − retracement fraction × (surge top − surge bottom), pullback minimum to current close, and switch to pullback state. In pullback state, first lower pullback minimum to current close if lower and, on a pullback bar, replace reference high with current high. If close < abandonment level, reset to idle. Otherwise, if high > reference high AND reference high > pullback minimum − stop multiplier × current ATR, emit a setup breakout; if the tight bear channel condition holds, replace reference high with current high and remain in pullback state; otherwise enter active state, set trailing stop to pullback minimum − stop multiplier × current ATR, clear the stop candidate and set follow-through pending. On the next bar in active state, clear follow-through pending; if close < open, increment attempt count and return to pullback state with reference high set to current high, or reset to idle if the count exceeds three. On an active-state bar after this check, if still active, first raise the trailing stop to the candidate low if a candidate exists, high > candidate high and candidate low > trailing stop; clear the candidate whenever high > candidate high. Then, if low < previous low, replace the candidate with the current low and high. If close < trailing stop, emit a trailing-stop exit and reset to idle. Returning to pullback state preserves the abandonment level and pullback minimum.
Calculation: Swing-high state = while bull trend holds, initialize the running maximum high to the first bar's high and the count to zero. On a later bar with high > running maximum, update the maximum, reset the count to zero and clear pullback readiness. Otherwise, set readiness on a pullback bar; if readiness is set AND the current bar is not a pullback bar AND high > previous high AND count < three, emit a swing-high breakout, increment the count and clear readiness. Reset all swing-high state when bull trend is false.
Long: Setup breakout is emitted.
Long: Swing-high breakout is emitted.
Exit: long, trailing-stop exit is emitted.
