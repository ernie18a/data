Calculation: Previous profile = Use chart bars in the last completed higher-timeframe session. Divide its high-low range into equal price bins. Allocate each bar's volume to bins in proportion to its high-low overlap; allocate a zero-range bar entirely to its containing bin, and replace nonpositive or missing volume with one. POC is the center of the highest-volume bin, choosing the lowest bin on a tie. Starting at that bin, expand the value area one adjacent bin at a time toward the larger volume, choosing the upper bin on a tie, until the included volume reaches the selected fraction of total volume. VAL and VAH are the lower and upper edges of the included bins. If the completed session has zero range, retain the last valid profile.
Calculation: Shape = P if (POC - previous session low) / (previous session high - previous session low) >= upper threshold; otherwise b if that ratio <= lower threshold; otherwise D. The upper threshold is greater than the lower threshold.
Calculation: Session state = Reset continuation and failure counts, both edge-fade counts, consecutive closes beyond each value-area edge, and the D-range-disabled flag at the start of each higher-timeframe session. Count consecutive closes above VAH and below VAL separately, resetting each count when its condition fails. While flat, disable D fades for the rest of the session after evaluating entries on a bar whose count reaches the acceptance threshold. Entry requires a flat position at the start of entry evaluation; continuation and failure may each fire at most once per session. For D fades, the VAH fade takes precedence over the VAL fade when both qualify.
Calculation: Volume spike = Current volume > volume SMA multiplied by a threshold OR previous-bar volume > its corresponding volume SMA multiplied by the same threshold; replace missing volume with zero. The volume filter may be disabled.
Calculation: Trade levels = Fix levels at entry using the entry bar and its previous profile; entry price is the signal-bar close and buffer is an ATR multiple. P continuation: stop = min(previous bar low, VAL) - buffer, target 1 = previous session high, target 2 = previous session high + VAH - VAL. b continuation: stop = max(previous bar high, VAH) + buffer, target 1 = previous session low, target 2 = previous session low - (VAH - VAL). P failure: stop = POC + buffer, target 1 = VAL - (VAH - VAL), target 2 = previous session low. b failure: stop = POC - buffer, target 1 = VAH + (VAH - VAL), target 2 = previous session high. D VAH fade: stop = VAH + max(buffer, a fraction of VAH - VAL), target 1 = POC, target 2 = VAL. D VAL fade: stop = VAL - max(buffer, the same fraction of VAH - VAL), target 1 = POC, target 2 = VAH. From the entry bar onward, if a long's high >= target 1 or a short's low <= target 1, mark target 1 reached and optionally move the stop to entry price before evaluating exits; evaluate target 2 before the stop on each bar, including the entry bar.
Long: Position = flat AND shape = P AND continuation count = 0 AND current session open >= VAL AND previous bar low <= VAH AND previous bar close >= VAL AND low >= previous bar low AND close > open AND close >= POC.
Long: Position = flat AND shape = b AND failure count = 0 AND consecutive closes above VAH >= acceptance threshold AND volume spike = true.
Long: Position = flat AND shape = D AND current session open >= VAL AND current session open <= VAH AND D-range-disabled = false AND VAL fade count < per-edge limit AND low <= VAL AND close > VAL AND NOT (VAH fade count < per-edge limit AND high >= VAH AND close < VAH).
Short: Position = flat AND shape = b AND continuation count = 0 AND current session open <= VAH AND previous bar high >= VAL AND previous bar close <= VAH AND high <= previous bar high AND close < open AND close <= POC.
Short: Position = flat AND shape = P AND failure count = 0 AND consecutive closes below VAL >= acceptance threshold AND volume spike = true.
Short: Position = flat AND shape = D AND current session open >= VAL AND current session open <= VAH AND D-range-disabled = false AND VAH fade count < per-edge limit AND high >= VAH AND close < VAH.
Exit: long, high >= target 2 OR low <= current stop.
Exit: short, low <= target 2 OR high >= current stop.
