Calculation: References = enabled or disabled higher-timeframe period opens at three nested period lengths, and the previous close of the shortest of those periods. On historical chart bars, higher-timeframe requests use the last completed higher-timeframe bar; on a still-forming realtime chart bar, they use the higher-timeframe bar still forming. The previous-close reference is the close preceding that requested higher-timeframe bar. Update every reference's state even when it is disabled.
Calculation: Reference state and bias = initialize each state as untouched, bias as +1, and confirmation count as 0. At each reference's corresponding higher-timeframe period boundary, reset its state to untouched and count to 0, retaining its bias. On each allowed chart-bar update, let zone = ATR × touch-distance parameter; in-zone = low <= reference + zone AND high >= reference - zone; above = close > reference + zone; below = close < reference - zone; range = max(high - low, positive price floor); body = max(abs(close - open), positive price floor). Bullish rejection = in-zone AND close > reference AND min(open, close) - low > body × rejection-wick parameter AND close > low + range × upper close-position threshold. Bearish rejection = in-zone AND close < reference AND high - max(open, close) > body × rejection-wick parameter AND close < low + range × lower close-position threshold. Up-cross = above AND previous close <= current reference; down-cross = below AND previous close >= current reference. Increment the count if above AND prior bias <= 0, OR below AND prior bias >= 0; otherwise reset it to 0. Apply these updates in order: if prior state is untouched AND in-zone, set state to touched and bias to +1 if close >= reference, otherwise -1; otherwise, if in-zone AND prior state is not untouched, set state to tested. If either rejection occurs, set state to rejected and bias to +1 for bullish rejection, otherwise -1. If either cross occurs, set bias to +1 for an up-cross, otherwise -1; if count >= confirmation-count parameter, also set state to reclaimed and emit a reclaim event. Finally, if prior state was reclaimed AND in-zone AND neither rejection occurred, set state to held. Emit a rejection event whenever either rejection occurs. State updates occur on confirmed bars only when confirmed-bar mode is enabled; otherwise they also occur on forming bars.
Calculation: Control = for each enabled reference, score = max(0, 1 - abs(close - reference) / ATR / distance parameter) × state weight; disabled references have score 0. If ATR <= 0, substitute the source's large fallback distance. State weights, in descending order, are reclaimed, rejected, touched, tested, held, and untouched. Select the greatest score, breaking ties in order from the shortest-period open through the longer-period opens, then previous close; control price and bias are those of the selected reference. If the greatest score is 0, there is no active control.
Calculation: Pressure = 100 × rolling sum(volume × (2 × buy share - 1)) / rolling sum(volume), or 0 when the denominator is not positive; buy share = clamp(close position × 0.56 + body direction × 0.28 + body power × (body direction - 0.5) × 0.32 + 0.14, 0, 1), where close position = (close - low) / max(high - low, positive price floor), body power = abs(close - open) / max(high - low, positive price floor), and body direction is 1 when close > open, 0 when close < open, otherwise 0.5.
Calculation: Long quality = clamp to 0–100 the sum of: a control-score contribution selected by whether the best score >= minimum-score parameter; a larger trend contribution if close > EMA AND EMA >= its value at a specified earlier bar, otherwise a smaller contribution if close > EMA; a larger pressure contribution if pressure > positive pressure threshold, otherwise a smaller contribution if pressure > 0; a contribution if control bias >= 0; a contribution if the bar overlaps control price ± zone OR abs(close - control price) / ATR <= distance threshold; a contribution if close > open; and a contribution if any reference emits a reclaim event. The below-minimum control-score contribution is proportional to the best score.
Calculation: Short quality = the corresponding long-quality calculation with close < EMA, EMA <= its value at the same earlier-bar offset, pressure < negative pressure threshold or pressure < 0, control bias < 0, and close < open; retain the same control-score, proximity, and any-reclaim contributions.
Long: A confirmed bar AND any reference emits a reclaim or rejection event with its resulting bias >= 0 AND best control score >= minimum-score parameter AND long quality >= quality threshold AND long quality > short quality AND bars since the last long or short setup > cooldown parameter, or no prior setup exists.
Short: A confirmed bar AND any reference emits a reclaim or rejection event with its resulting bias < 0 AND best control score >= minimum-score parameter AND short quality >= quality threshold AND short quality > long quality AND bars since the last long or short setup > cooldown parameter, or no prior setup exists.
Long: An enabled reference's bias >= 0.
Short: An enabled reference's bias < 0.
Long: An enabled reference's state = rejected AND its bias < 0.
Short: An enabled reference's state = rejected AND its bias >= 0.
Long: Best control score > 0 AND close >= control price.
Short: Best control score > 0 AND close < control price.
Long: Pressure > positive pressure threshold.
Short: Pressure < negative pressure threshold.
