Calculation: Previous reference high, low, and close = high, low, and close of the preceding reference-timeframe bar. The reference timeframe may be higher than, equal to, or lower than the chart timeframe. For a higher timeframe, use the last completed bar; for an equal timeframe, use the preceding chart bar; for a lower timeframe, use the bar preceding the first lower-timeframe bar within the chart bar.
Long: close > previous reference close
Short: close < previous reference close
Long: high > previous reference high on the current or an earlier chart bar in the current reference period AND close > previous reference high
Short: high > previous reference high on the current or an earlier chart bar in the current reference period AND close < previous reference high
Long: low < previous reference low on the current or an earlier chart bar in the current reference period AND close > previous reference low
Short: low < previous reference low on the current or an earlier chart bar in the current reference period AND close < previous reference low
