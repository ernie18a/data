Calculation: Shelves = On each bar, confirm pivot highs and lows using equal numbers of bars on each side; process the high before the low. For each pivot, merge it into the first existing shelf within a cluster-distance multiple of current ATR, replacing shelf price with the touch-count-weighted mean and incrementing touches; otherwise create a shelf at the pivot price with one touch. Add a higher strength weight if pivot-bar volume is at least a volume multiple of its volume SMA; otherwise add a lower weight. Record each shelf's first and latest pivot bars. Remove a shelf when its latest pivot is older than the shelf lookback, or when its touches are below the minimum and its first pivot is older than one-third of that lookback. A shelf is eligible when its touches meet the minimum; optionally exclude reused shelves. Rank eligible shelves by descending strength, retaining creation order for ties, and select up to the maximum visible count.
Calculation: Shelf reaction = For each shelf, including ineligible shelves, initialize state to idle and reused to false. On each completed bar after pivot registration and cleanup, set buffer to a multiple of current ATR and intersection to low <= shelf price + buffer / 4 AND high >= shelf price - buffer / 4. Compare the previous close with the current shelf price. If intersection, set state to touch, then override it with held if previous close > shelf price AND close >= shelf price + buffer; otherwise lost if previous close > shelf price AND close < shelf price - buffer; otherwise rejected if previous close < shelf price AND close <= shelf price - buffer; otherwise, if previous close < shelf price AND close > shelf price + buffer, set state to reclaimed if previously reused, or lost otherwise. If there is no intersection, keep the prior state except that the same previous-close and close conditions for lost or reclaimed apply. When state changes, record the current bar as the state bar and set reused to true if the new state is reclaimed or lost. If state remains touch and intersection is true, update the state bar to the current bar. A state is active while its state bar is within the active-reaction lookback.
Long: Any selected shelf has an active state equal to held OR reclaimed.
Short: Any selected shelf has an active state equal to rejected OR lost.
