Calculation: Pivot states = For each pivot length in a configurable inclusive range, independently track confirmed pivot lows and highs, using equal numbers of bars on each side of the pivot. On confirmation of a pivot low, replace the previous/current stored lows with the old current low and the new pivot low; a long setup exists if the new low is greater than the old current low. On confirmation of a pivot high, similarly replace the stored highs; a short setup exists if the new high is less than the old current high. Reset the setup's breakout state whenever a new pivot is confirmed. For a long setup, the break level is the highest high strictly between the stored low indices; for a short setup, it is the lowest low strictly between the stored high indices. Limit the scan to the available historical window of 4990 bars. A setup without a break level is unavailable. On each confirmed bar, invalidate a long setup if the selected invalidation price, close or low, is below its current low; invalidate a short setup if the selected invalidation price, close or high, is above its current high. On invalidation, replace the current pivot and its index with the current low or high if it extends beyond that pivot. While a setup is inactive, likewise update its current low or high and index whenever a new lower low or higher high occurs.
Calculation: Breakout and retest events = For each valid long setup, a breakout occurs when close is above its break level and the previous close is at or below it; for a short setup, when close is below its break level and the previous close is at or above it. Record the current bar as the breakout bar on every breakout. If late capture is enabled and no breakout has yet been recorded, also record a late breakout when the current close is beyond the break level and a corresponding close crossover occurred after the current pivot index within the available historical window. A long retest occurs after the recorded breakout bar when low is at or below the break level and close is above it; a short retest occurs after the recorded breakout bar when high is at or above the break level and close is below it.
Calculation: Quality score = Add 25 for an active setup and 25 if its breakout has been recorded. Add 20 if displacement scoring is disabled or long close exceeds the break level plus ATR times a configurable multiplier, or short close is below the break level minus ATR times that multiplier. Add 15 if volume scoring is disabled or volume is at least its SMA times a configurable multiplier. Add 15 if higher-timeframe bias scoring is disabled or the last completed higher-timeframe close is above its EMA for a long setup or below its EMA for a short setup.
Calculation: Selected setup = For each permitted direction, select an available setup by the configured priority: lowest break level, highest break level, longest pivot length, shortest pivot length, or most recent current pivot index. Resolve ties by the shortest pivot length. If both directions are permitted and have selected setups, select the one with the higher quality score; on equal scores select the one with the more recent current pivot index, and select long if those indices are equal.
Calculation: Alert eligibility = The selected setup's quality score is at least the configured threshold or score gating is disabled. The current signal's direction, current pivot index, pivot length and event kind differ from those of the most recent eligible signal; remember that identity whenever an eligible signal occurs, even if alerts are disabled. Retest takes precedence as the event kind when breakout and retest signals coincide.
Long: The selected setup is long AND its current pivot index, pivot length or direction differs from the previously selected setup.
Short: The selected setup is short AND its current pivot index, pivot length or direction differs from the previously selected setup.
Long: The selected setup is long AND alert eligibility holds AND ((breakout entry mode is enabled AND a breakout or late breakout event occurs) OR (retest entry mode is enabled AND a retest event occurs)).
Short: The selected setup is short AND alert eligibility holds AND ((breakout entry mode is enabled AND a breakout or late breakout event occurs) OR (retest entry mode is enabled AND a retest event occurs)).
