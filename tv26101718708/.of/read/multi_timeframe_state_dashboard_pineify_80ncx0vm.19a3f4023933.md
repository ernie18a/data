Calculation: Trend score = clip((EMA(close) - EMA(close) slope-lookback bars ago) / (ATR × positive slope scale), -1, 1); undefined when ATR is not positive.
Calculation: Momentum score = clip((RSI(close) - 50) / 25, -1, 1).
Calculation: Directional score = trend weight × trend score + momentum weight × momentum score; the positive weights sum to 1 and the trend weight is larger.
Calculation: Conflict = absolute trend score >= conflict threshold AND absolute momentum score >= conflict threshold AND trend score × momentum score < 0.
Calculation: Bullish state = directional score >= bias threshold AND conflict = false; bearish state = directional score <= -bias threshold AND conflict = false. Both require defined trend score, momentum score, and ATR percentile rank, AND quiet percentile threshold < hot percentile threshold. The bias threshold is a positive fraction of the directional state threshold.
Calculation: Valid reference = enabled chart or higher timeframe that does not duplicate an earlier enabled reference. Confirmed calculations use the current completed chart bar for a chart-timeframe reference and the last completed higher-timeframe bar for a higher-timeframe reference. Live calculations use the current chart bar for a chart-timeframe reference and the still-forming higher-timeframe bar for a higher-timeframe reference.
Long: Bullish state on the chart timeframe OR bullish state on any valid reference using live calculations OR bullish state on any valid reference using confirmed calculations.
Short: Bearish state on the chart timeframe OR bearish state on any valid reference using live calculations OR bearish state on any valid reference using confirmed calculations.
Long: Confirmed trend score on any valid reference > positive trend-text threshold OR confirmed RSI on any valid reference >= upper RSI threshold.
Short: Confirmed trend score on any valid reference < negative trend-text threshold OR confirmed RSI on any valid reference <= lower RSI threshold. The trend-text thresholds are symmetric around zero and the RSI thresholds are symmetric around 50.
Long: Valid reference count > 0 AND every valid reference has a bullish confirmed state AND the same all-bullish condition was false on the preceding chart bar.
Short: Valid reference count > 0 AND every valid reference has a bearish confirmed state AND the same all-bearish condition was false on the preceding chart bar.
