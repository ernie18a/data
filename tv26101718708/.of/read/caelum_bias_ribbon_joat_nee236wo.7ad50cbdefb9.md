Calculation: Per-horizon direction = calculate ALMA(close) and standard deviation of close using the configured lengths; form upper/lower bands at ALMA ± deviation factor × standard deviation. Trail the upper band to the lower of its current value and prior trailed value unless prior close exceeded the prior trailed upper band; trail the lower band to the higher of its current value and prior trailed value unless prior close fell below the prior trailed lower band. If the prior selected band was the upper band, direction is bullish when close exceeds the current trailed upper band, otherwise bearish; if it was the lower band, direction is bullish when close is below the current trailed lower band, otherwise bearish. Use the same parameters for all five horizons, ordered shortest to longest, and the last completed bar of each horizon, whether it is higher or lower than the chart timeframe.
Calculation: Consensus = bullish horizon count minus bearish horizon count across the five horizons.
Long: Consensus ≥ 3
Short: Consensus ≤ -3
