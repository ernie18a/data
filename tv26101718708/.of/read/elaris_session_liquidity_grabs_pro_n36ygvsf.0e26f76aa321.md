Calculation: Session high/low = highest high and lowest low during each enabled session, finalized when that session ends
Calculation: ATR = average true range on chart bars
Calculation: EMA = exponential moving average of close on chart bars
Calculation: Volume average = simple moving average of volume on chart bars
Long: An enabled session has ended and low < its session low; in wick-sweep mode close > session low, or in close-break mode close < session low; abs(low − session low) ≥ ATR × minimum sweep distance; close > session low if close-back-inside is required; volume > volume average × volume multiplier if volume filtering is enabled; close > EMA if trend filtering is enabled; outside all sessions if that filter is enabled; bullish displacement and body percentage meet their minimums if a strong reversal close is required; and the number of bars since the previous long signal is at least the cooldown
Short: An enabled session has ended and high > its session high; in wick-sweep mode close < session high, or in close-break mode close > session high; abs(high − session high) ≥ ATR × minimum sweep distance; close < session high if close-back-inside is required; volume > volume average × volume multiplier if volume filtering is enabled; close < EMA if trend filtering is enabled; outside all sessions if that filter is enabled; bearish displacement and body percentage meet their minimums if a strong reversal close is required; and the number of bars since the previous short signal is at least the cooldown
