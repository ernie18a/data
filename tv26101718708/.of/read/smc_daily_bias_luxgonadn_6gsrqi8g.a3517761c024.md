Calculation: Reference timeframe = a configurable timeframe that may be higher than, equal to, or lower than the chart timeframe. For a lower reference timeframe, sample the first reference bar inside each chart bar for the previous-bar candle and current open, and the last reference bar for pivots.
Calculation: Candle vote = +1 if the last completed reference bar closes above its open, -1 if it closes below its open, otherwise 0.
Calculation: Structure vote = +1 if the latest confirmed reference-timeframe pivot high is greater than the preceding pivot high AND the latest confirmed pivot low is greater than the preceding pivot low; -1 if both latest pivots are less than or equal to their respective preceding pivots; otherwise 0. Use the same configurable number of reference bars on each side to confirm each pivot. Map the pivot series to chart bars with lookahead off and carry values between reference-bar updates. On every chart bar where a mapped pivot is non-null, compare it with the previously processed pivot of that kind and then store it, including repeated mapped values. Retain each pivot type until another non-null pivot of that kind is processed; its initial type is 0.
Calculation: Open vote = +1 if the chart close is above the open of the currently forming reference bar, -1 if it is below that open, otherwise 0.
Calculation: Combined vote = candle vote + structure vote + open vote.
Long: candle vote = +1 OR structure vote = +1 OR open vote = +1 OR combined vote >= 2.
Short: candle vote = -1 OR structure vote = -1 OR open vote = -1 OR combined vote <= -2.
