Calculation: Reference session high and low = the maximum high and minimum low of chart bars whose opening times fall within the most recently completed occurrence of a configurable, enabled session, using a configurable time zone; retain these levels until that session next completes.
Long: Chart timeframe is intraday AND current bar is closed AND its opening time is outside the reference session AND reference session high is available AND close > reference session high AND previous close <= current reference session high AND (first-breakout-only is disabled OR count of earlier long breakouts since the reference session last ran = 0).
Short: Chart timeframe is intraday AND current bar is closed AND its opening time is outside the reference session AND reference session low is available AND close < reference session low AND previous close >= current reference session low AND (first-breakout-only is disabled OR count of earlier short breakouts since the reference session last ran = 0).
