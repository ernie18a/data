Calculation: Confirmed swing high/low = most recent pivot high/low, confirmed after an equal number of bars on each side of the pivot.
Calculation: Support proximity = close minus the confirmed swing low, divided by ATR; resistance proximity = confirmed swing high minus close, divided by ATR. A proximity is near when it is nonnegative and less than a proximity threshold.
Calculation: Trend vote = +1 if the short EMA of close > the medium EMA > the long EMA; -1 if the short EMA < the medium EMA < the long EMA; otherwise 0.
Calculation: Support/resistance vote = +1 if support is near and resistance is not near; -1 if resistance is near and support is not near; otherwise 0.
Calculation: Volume vote = +1 if the volume z-score is at least its threshold, OBV is above its value at a specified lookback, and close > open; -1 if the volume z-score is at least its threshold, OBV is below its value at that lookback, and close < open; otherwise 0. Volume z-score = (volume - SMA of volume) / standard deviation of volume, or 0 when the standard deviation is 0.
Calculation: Momentum vote = +1 if RSI > its midpoint, MACD histogram > 0, and SMA of stochastic %K > its midpoint; -1 if RSI < its midpoint, MACD histogram < 0, and SMA of stochastic %K < its midpoint; otherwise 0.
Calculation: Bollinger width = (upper Bollinger band - lower Bollinger band) / middle Bollinger band, or 0 when the middle band is 0. Expansion is width > a multiplier times its longer-lookback SMA; squeeze is width < a smaller multiplier times that SMA.
Calculation: Volatility vote = +1 if expansion AND close > open; -1 if expansion AND close < open; otherwise 0.
Calculation: Consensus = sum of the trend, support/resistance, volume, momentum, and volatility votes.
Calculation: Strong-signal state = initially 0; after evaluating each completed bar, set it to +1 when consensus >= its positive threshold AND trend vote = +1 AND support/resistance vote >= 0; set it to -1 when consensus <= the negative of that threshold AND trend vote = -1 AND support/resistance vote <= 0; otherwise reset it to 0 when absolute consensus < the threshold minus one; otherwise retain its previous value. Entry signals use the state before the current bar's update.
Calculation: Initial stop distance = clamp(max(base ATR distance multiplied by the expansion, squeeze, or normal regime multiplier, min(structure distance, a cap times base ATR distance)), lower ATR bound, upper ATR bound). Base ATR distance is an ATR multiple. Structure distance defaults to base ATR distance; for a long with a confirmed swing low below entry it is max(entry - swing low + an ATR buffer, a minimum ATR distance), and for a short with a confirmed swing high above entry it is max(swing high - entry + an ATR buffer, the same minimum ATR distance). Evaluate and freeze these values at entry.
Calculation: Target distances = at entry, base target distance is initial stop distance times a risk/reward multiplier. First target distance is the smaller of a cap times the base target distance and the structure target distance. Structure target distance defaults to a fraction of base target distance; for a long with a confirmed swing high above entry it is max(swing high - entry, a minimum ATR distance), and for a short with a confirmed swing low below entry it is max(entry - swing low, the same minimum ATR distance). Second target distance = base target distance times a momentum multiplier; third target distance = second target distance times a further multiplier. The momentum multiplier is greater when the momentum vote agrees with the entry side. Freeze target distances at entry.
Calculation: Stop price = entry minus initial stop distance for a long, entry plus initial stop distance for a short. If trailing is enabled and the trade remains open after the current bar's hit checks, update the stop for the next bar to max(previous stop, close - an ATR multiple) for a long when momentum vote = +1, or min(previous stop, close + an ATR multiple) for a short when momentum vote = -1; otherwise retain it.
Long: Trend vote = +1 OR support/resistance vote = +1 OR volume vote = +1 OR momentum vote = +1 OR consensus > 0.
Short: Trend vote = -1 OR support/resistance vote = -1 OR volume vote = -1 OR momentum vote = -1 OR consensus < 0.
Long: Consensus >= its positive threshold AND trend vote = +1 AND support/resistance vote >= 0 AND prior strong-signal state != +1.
Short: Consensus <= the negative of its positive threshold AND trend vote = -1 AND support/resistance vote <= 0 AND prior strong-signal state != -1.
Exit: long, low <= stop price OR (low > stop price AND high >= entry + first target distance AND first target has not previously been hit) OR (low > stop price AND high >= entry + second target distance AND second target has not previously been hit AND the enabled target count >= 2) OR (low > stop price AND high >= entry + third target distance AND third target has not previously been hit AND the enabled target count >= 3).
Exit: short, high >= stop price OR (high < stop price AND low <= entry - first target distance AND first target has not previously been hit) OR (high < stop price AND low <= entry - second target distance AND second target has not previously been hit AND the enabled target count >= 2) OR (high < stop price AND low <= entry - third target distance AND third target has not previously been hit AND the enabled target count >= 3).
