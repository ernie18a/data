Calculation: Volume-centered SuperTrend = For each of two parameter sets, calculate a center as the selected moving average of close × volume divided by the same moving average of volume. Use the first set's center and moving-average length for both SuperTrends. For each set, calculate ATR using that set's length, and raw upper and lower bands as center ± ATR × that set's multiplier. Set each final lower band to its raw value if it is above the previous final lower band or the previous close is below that previous band; otherwise retain the previous band. Set each final upper band to its raw value if it is below the previous final upper band or the previous close is above that previous band; otherwise retain the previous band. Treat an unavailable previous band as zero. Initialize direction as bearish when the previous ATR is unavailable. Otherwise, if the previous SuperTrend equals the previous upper band, direction is bullish if close is above the current upper band and bearish otherwise; if it does not, direction is bearish if close is below the current lower band and bullish otherwise. The SuperTrend is the lower band when bullish and the upper band when bearish. The first set uses a longer ATR length and larger multiplier than the second.
Calculation: Classification = For each SuperTrend, label each bar 1 if a WMA of close is above a WMA of that SuperTrend, otherwise 0. From a lookback that includes the current bar, select the SuperTrend values nearest to the current SuperTrend by absolute distance; preserve most-recent-first order for equal distances. Classification is the weighted mean of their labels, with each weight equal to the reciprocal of its distance plus a small positive constant. Use separate neighbor counts and WMA lengths for the two classifications, but use the first classification's lookback for both; that lookback is at least the first neighbor count. The first close WMA is shorter than the second; the two SuperTrend WMA lengths are equal.
Long: Either SuperTrend direction is bullish.
Short: Either SuperTrend direction is bearish.
Long: Either classification equals 1.
Short: Either classification equals 0.
Long: Either classification equals 1 AND its previous value did not equal 1.
Short: Either classification equals 0 AND its previous value did not equal 0.
Long: Either SuperTrend direction changes from bearish to bullish AND its corresponding classification equals 1.
Short: Either SuperTrend direction changes from bullish to bearish AND its corresponding classification equals 0.
Long: Both SuperTrend directions are bullish AND both classifications equal 1.
Short: Both SuperTrend directions are bearish AND both classifications equal 0.
Exit: long, low reaches or falls below the active stop. At each bar close, submit or update the stop to the first SuperTrend minus its ATR × its multiplier if neither SuperTrend has just changed from bearish to bullish with its corresponding classification equal to 1; an existing stop remains active when this condition is false.
Exit: short, high reaches or exceeds the active stop. At each bar close, submit or update the stop to the first SuperTrend plus its ATR × its multiplier if neither SuperTrend has just changed from bullish to bearish with its corresponding classification equal to 0; an existing stop remains active when this condition is false.
