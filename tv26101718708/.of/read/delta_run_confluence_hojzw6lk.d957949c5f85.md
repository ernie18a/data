Calculation: Volume delta = sum of signed volume over the completed lower-timeframe bars within the current chart bar. Sign each bar positive if close > open, negative if close < open; if close = open, use the sign of close minus the preceding lower-timeframe close within the same chart bar, or zero if there is no preceding bar. If there are no lower-timeframe bars, use chart-bar volume signed by close minus open.
Calculation: Signed streak = consecutive chart bars ending at the current bar with strictly positive volume delta, counted positively, or with strictly negative volume delta, counted negatively; zero delta resets it to zero.
Calculation: Run efficiency = sum of high minus low over the run-length chart bars divided by the sum of absolute volume delta over those bars; undefined when the denominator is zero. Its baseline is the simple moving average of run efficiency over the baseline lookback, ending on the previous chart bar.
Calculation: Isolation distance = the greater of one chart bar and the isolation window divided by chart-bar duration, rounded to the nearest integer. The last opposite run is the most recent earlier chart bar whose signed streak first reached the opposite run length, regardless of filters.
Long: Signed streak = positive run length AND (efficiency filter = any OR efficiency filter = efficient AND run efficiency >= baseline OR efficiency filter = absorbed AND run efficiency < baseline) AND (isolation disabled OR no earlier opposite run exists OR bars since last opposite run > isolation distance).
Short: Signed streak = negative run length AND (efficiency filter = any OR efficiency filter = efficient AND run efficiency >= baseline OR efficiency filter = absorbed AND run efficiency < baseline) AND (isolation disabled OR no earlier opposite run exists OR bars since last opposite run > isolation distance).
Long: Completed-run dots enabled AND signed streak = positive run length AND NOT ((efficiency filter = any OR efficiency filter = efficient AND run efficiency >= baseline OR efficiency filter = absorbed AND run efficiency < baseline) AND (isolation disabled OR no earlier opposite run exists OR bars since last opposite run > isolation distance)).
Short: Completed-run dots enabled AND signed streak = negative run length AND NOT ((efficiency filter = any OR efficiency filter = efficient AND run efficiency >= baseline OR efficiency filter = absorbed AND run efficiency < baseline) AND (isolation disabled OR no earlier opposite run exists OR bars since last opposite run > isolation distance)).
Long: All-run-bar dots enabled AND (signed streak = 1 OR signed streak = 2).
Short: All-run-bar dots enabled AND (signed streak = -1 OR signed streak = -2).
