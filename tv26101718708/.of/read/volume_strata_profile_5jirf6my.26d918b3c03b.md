Calculation: Volume profile = For each chart bar, take the available lookback including the current bar and divide its high-low range into equal price rows. Divide the chart bars chronologically into approximately equal strata using floor(chronological bar index × number of strata / number of bars). Allocate each lower-timeframe bar's volume across overlapping rows in proportion to its high-low overlap; use the bar still forming when available. If lower-timeframe data is disabled or unavailable for a chart bar, allocate that chart bar's volume instead. Assign all volume to its row when its high and low occupy the same row. Sum allocated volume by row and stratum; resolve maximum-volume ties in favor of the lowest row.
Calculation: Stratum POC = Index of the highest-volume row within a stratum. The previous stratum POC is reused as the second-previous POC when fewer than three strata exist.
Calculation: Half-stratum POCs = POC row indices of the two nonoverlapping halves of the newest stratum; the newer half receives the extra bar when its length is odd.
Calculation: Composite POC = Midpoint of the highest-volume row across all strata.
Calculation: Value area high = Starting at the composite POC row, repeatedly add the larger-volume adjacent row until the selected share of total profile volume is included; choose the upper row on a tie. Return the upper edge of the highest included row.
Calculation: Migration quality = Sign(newest stratum POC − oldest stratum POC) × migration efficiency × min(1, absolute POC displacement divided by the number of profile rows and a magnitude scale). Migration efficiency is absolute POC displacement divided by the sum of absolute POC changes between consecutive strata, or zero when that sum is zero.
Calculation: Activity ratio = Average allocated volume per chart bar in the newest stratum divided by average allocated volume per chart bar across the profile.
Calculation: Structure score = Count of these satisfied comparisons: newest stratum POC − previous stratum POC > POC row tolerance; previous stratum POC − second-previous stratum POC > POC row tolerance; newer half-stratum POC >= older half-stratum POC − POC row tolerance; migration quality >= migration quality threshold AND newest stratum POC − previous stratum POC > POC row tolerance; close >= composite POC; close >= value area high − ATR × near-value-area distance parameter.
Calculation: Recent intrabar quality = Square root of coverage × density for the newest three strata, or all strata if fewer exist. Coverage is the fraction of chart bars containing lower-timeframe bars. Density is the average lower-timeframe bar count among covered chart bars divided by the maximum count in any chart bar, capped at one. Use lower-timeframe bars available through the current chart bar, including the bar still forming.
Long: Available chart bars >= twice the number of strata AND profile price range > 0 AND total profile volume > 0 AND newest stratum POC − previous stratum POC > POC row tolerance AND newer half-stratum POC >= older half-stratum POC − POC row tolerance AND newest stratum POC > oldest stratum POC
Long: Available chart bars >= twice the number of strata AND profile price range > 0 AND total profile volume > 0 AND structure score >= lower setup score threshold AND (lower-timeframe mode is inactive OR no chart bar in the quality window contains lower-timeframe bars OR recent intrabar quality >= quality threshold)
