Calculation: Regression statistics = For each of three increasing lookback lengths, regress close on x = 1 for the current bar, 2 for the preceding bar, and so on. Use available closes; require at least the greater of a minimum count and a minimum fraction of the lookback. Return slope, correlation, and R² = correlation squared; if insufficient data, set these three values to zero. A zero regression or correlation denominator produces zero for the respective statistic.
Calculation: Adaptive R² threshold = When adaptation is enabled and the adaptation lookback has elapsed, retain the latest short-regression R² observations up to the adaptation lookback; after a minimum sample count, use their nearest-rank percentile, clamped between lower and upper bounds. Otherwise use the fixed R² threshold.
Calculation: Layer significance = Primary significance requires R² >= adaptive R² threshold AND absolute correlation >= correlation threshold AND absolute slope >= slope threshold. Fallback significance requires R² >= fallback R² threshold AND absolute correlation >= fallback correlation threshold; use separate fallback thresholds for the short layer and for the other layers.
Calculation: Layer quality = weighted sum of R², absolute correlation, and min(1, absolute slope multiplied by a slope scale).
Calculation: Layer signal = If primary significance holds, use +1 when slope > 0 and -1 otherwise. Otherwise, if fallback significance holds, multiply layer quality by a positive fallback scale when slope > 0 and by its negative otherwise. Otherwise, if quality > a threshold, multiply quality by a smaller positive scale when slope > 0 and by its negative otherwise; otherwise use zero.
Calculation: Layer weights = Use three base weights. When dynamic weighting is enabled, its warm-up has elapsed, and total layer quality > 0, blend each layer's share of total quality with its base weight and normalize the three results to sum to one; otherwise use the base weights.
Calculation: Ensemble score = Sum of each layer signal multiplied by its layer weight.
Calculation: Validation accuracy and short-layer reliability = After a validation lookback plus a prediction horizon has elapsed, on each bar calculate actual return over the prediction horizon and each layer's slope from that many bars ago, replacing unavailable slopes with zero. Calculate ensemble prediction as the current weighted sum of those past slopes multiplied by the horizon. Retain a validation-lookback window of max(0, 1 minus a scale times the absolute difference between actual return and ensemble prediction), and a window of the absolute difference between actual return and the past short-layer slope multiplied by the horizon. After a minimum sample count, validation accuracy is the mean of the first window and short-layer reliability is 1 minus the mean of the second; before then each uses its default value.
Calculation: Overall confidence = A weighted sum of agreement, weighted R², and validation accuracy, multiplied by min(1, short-layer reliability plus a reliability offset). Agreement is the absolute sum of layer signals whose absolute values exceed a threshold divided by their count, or zero if none qualify. Weighted R² is the sum of each layer's R² multiplied by its current weight.
Calculation: Positive flip gate = The medium-regression slope OR ensemble score most recently crossed above zero within a flip lookback AND that same series has remained strictly positive for at least a persistence lookback since its last nonpositive value.
Calculation: Negative flip gate = The medium-regression slope OR ensemble score most recently crossed below zero within a flip lookback AND that same series has remained strictly negative for at least a persistence lookback since its last nonnegative value.
Long: Ensemble score > positive display threshold.
Short: Ensemble score < negative display threshold.
Long: Any layer signal > 0.
Short: Any layer signal < 0.
Long: Ensemble score > positive signal threshold AND overall confidence > confidence threshold AND short-layer primary OR fallback significance AND medium-layer primary OR fallback significance AND positive flip gate.
Short: Ensemble score < negative signal threshold AND overall confidence > confidence threshold AND short-layer primary OR fallback significance AND medium-layer primary OR fallback significance AND negative flip gate.
Exit: long, medium-regression slope < 0 when the regression exit is enabled OR ensemble score <= 0 when the ensemble exit is enabled OR bars since entry >= time-stop lookback.
Exit: short, medium-regression slope > 0 when the regression exit is enabled OR ensemble score >= 0 when the ensemble exit is enabled OR bars since entry >= time-stop lookback.
