Calculation: Fast and slow ribbon averages = the same selected moving-average method and price source, with the fast average using a shorter length; the slow length is the fast length plus a positive fixed step multiplied by the selected line count minus one. The available methods are SMA, EMA, RMA, WMA, VWMA, HMA, DEMA, TEMA, ALMA, LSMA, SWMA, KAMA, FRAMA, VIDYA, T3, McGinley Dynamic, Super Smoother, rolling median, and the variants defined below. SWMA has the same value for both lengths.
Calculation: Repeated WMA or VWMA = apply the respective average to its own output once for the double variant or twice for the triple variant, using the same length each time. TRIMA = SMA of SMA using the same length twice. ZLEMA = EMA of 2 × source minus source lagged by (length − 1) / 2 bars, with integer lag. EHMA = EMA with rounded square-root length of 2 × EMA with rounded half length minus EMA with full length. THMA = WMA with full length of 3 × WMA with rounded one-third length minus WMA with rounded half length minus WMA with full length; rounded lengths have a minimum of one.
Calculation: Jurik-style average = recursively compute beta = 0.45 × (length − 1) / (0.45 × (length − 1) + 2), alpha = beta ^ power, phase ratio = phase / 100 + 1.5, x0 = (1 − alpha) × source + alpha × previous x0, x1 = (source − x0) × (1 − beta) + beta × previous x1, x2 = (x0 + phase ratio × x1 − previous average) × (1 − alpha)² + alpha² × previous x2, and average = x2 + previous average; initialize previous values to zero.
Calculation: Kalman average = recursively set predicted variance = previous variance + process noise / length, gain = predicted variance / max(predicted variance + measurement noise, a small positive floor), average = previous average + gain × (source − previous average), and variance = (1 − gain) × predicted variance; initialize average to source and variance to one.
Calculation: Adaptive forecast average = for each prior bar in a lookback, weight the sign of close[i − 1] − close[i] by 1 / (1 + log(1 + absolute difference between current and prior short RSI) + log(1 + absolute difference between current and prior long RSI)); the long RSI length is twice the short RSI length. Replace unavailable RSI values with zero. Forecast is the weighted mean of the signs, or zero if total weight is zero. Effective length = max(base length × (1 + range parameter × forecast), 2); average = alpha × source + (1 − alpha) × previous average, where alpha = 2 / (effective length + 1), initialized to source.
