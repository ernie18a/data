Calculation: Intrabar delta (%) = 100 × (buy volume − sell volume) / total volume across lower-timeframe bars within the current chart bar; allocate each bar’s volume to buy if close > open, sell if close < open, and split it equally if close = open. Include the lower-timeframe bar still forming.
Calculation: Lookback delta (%) = 100 × 0.6 × (volume of bullish bars − volume of bearish bars) / total volume over the lookback of chart-timeframe bars, including the current bar; doji bars contribute zero to the numerator.
Calculation: Session CVD delta = cumulative buy volume − sell volume from the selected day or session start through the current chart bar, using chart-timeframe bars and splitting doji volume equally. Previous CVD delta uses the same accumulation but excludes the current bar.
Long: Intrabar delta (%) >= 0 OR lookback delta (%) > the up threshold OR (intrabar delta (%) > the up threshold AND lookback delta (%) < the down threshold) OR session CVD delta >= 0 OR (session CVD delta > 0 AND previous CVD delta <= 0) OR (abs(session CVD delta) >= 0.97 × abs(previous CVD delta) AND session CVD delta > previous CVD delta)
Short: Intrabar delta (%) < 0 OR lookback delta (%) < the down threshold OR (intrabar delta (%) < the down threshold AND lookback delta (%) > the up threshold) OR session CVD delta < 0 OR (session CVD delta < 0 AND previous CVD delta >= 0) OR (abs(session CVD delta) >= 0.97 × abs(previous CVD delta) AND session CVD delta < previous CVD delta)
