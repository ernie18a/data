Calculation: Active range = Select one range mode. Pivot: use the most recently confirmed pivot high and pivot low, each confirmed by the same number of bars on both sides; set the boundaries to their maximum and minimum and the start to the earlier pivot bar. Lookback: use the highest high and lowest low over a rolling lookback, starting at its first bar. Compression: when short-term ATR divided by the greater of long-term ATR and a minimum price increment is below a threshold, use the highest high and lowest low over a compression window, starting at its first bar. Manual: on the first bar in a specified date window, set both boundaries to that bar's high and low; while in the window and the range is not frozen, expand the boundaries with each bar's high and low. For the automatic modes, rebuild only when the prior range is absent, frozen, or old enough, and any cooldown since freezing has elapsed; require a positive midpoint and a boundary width divided by midpoint at least equal to a minimum. Pivot mode also requires an earlier start and either no prior range, a frozen range, or a boundary change greater than a minimum price increment threshold. On rebuild, reset the control state and counters. Freeze the range when a close is outside either boundary.
Calculation: Control line = On range rebuild, sum typical price times volume and volume from the range start through the bar preceding the rebuild; use a fallback volume for missing volume. If that history exceeds the supported retrospective window, start both sums at zero. On each later bar before the range freezes, add that bar's typical price times volume and volume. Divide the sums when total volume is positive; otherwise use the range midpoint on rebuild and retain the previous line on later bars. Replace the resulting value with the midpoint whenever it lies within a specified fraction of the range width from either boundary. The rebuild bar is excluded from the sums.
Calculation: Control state = Initialize to inside and reset both consecutive-side counters on each range rebuild. On each subsequent unfrozen bar, compare a source with the current control line: in strict mode use close; in loose mode use high if close is above the line, otherwise low. Above the line increments the above counter and resets the below counter; below the line increments the below counter and resets the above counter; equality leaves both unchanged. If close is outside the range, set state to failed and freeze the range; otherwise set state to upper if the above counter reaches the confirmation length, lower if the below counter reaches it, and inside otherwise.
Long: control state equals upper
Short: control state equals lower
