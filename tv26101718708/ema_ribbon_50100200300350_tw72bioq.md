# EMA Ribbon 50/100/200/300/350

- url: https://www.tradingview.com/script/TW72Bioq/
- type: indicator
- pine_id: PUB;2be81a8be055475b9d2466d5a8d23977
- version: 1.0

## Description

A clean five-line EMA ribbon — 50 · 100 · 200 · 300 · 350 — built around one
idea: the COLOR alone tells you which average you're looking at.

The lines follow a warm→cool ramp (amber → orange → magenta → blue → indigo), so
warmth and brightness fall as the EMA slows: a warm, bright line is always a fast
average, a cool, deep one always slow. Pure red and green are avoided so a line
is never mistaken for a bull/bear candle. The 200 is drawn a touch thicker to
keep the most-watched average prominent.

Every line has its own on/off toggle, length, and color. The averages are
standard ta.ema on price — fully causal, so nothing repaints.

A visual reference for moving-average structure, not a signal generator: no
arrows, no alerts.

Settings: a shared price source, plus a show toggle, length, and color for each
of the five EMAs.

Open-source. Not financial advice.

## Source Code

````pine
//@version=6
// =============================================================================
//  EMA RIBBON — 50 / 100 / 200 / 300 / 350         (a visual reference, NOT a signal)
// -----------------------------------------------------------------------------
//  Five exponential moving averages drawn as a clean, colour-coded ribbon on the
//  price chart. The whole point is the PALETTE: a monotonic warm→cool ramp so the
//  COLOUR ALONE tells you which EMA you're looking at — the fastest (50) is warm
//  and bright, the slowest (350) is cool and deep. The eye maps colour → speed
//  with no legend. A per-line tag at the last bar ("EMA 200", in that line's own
//  colour) makes the mapping explicit and reinforces it.
//
//  Per EMA you get three controls: an enable/disable toggle, an editable length,
//  and an editable colour. The 200 — the most-watched line — is drawn a hair
//  thicker (linewidth 2) so it stays salient inside the ribbon.
//
//  WHY warm→cool, and why NOT red/green (the headline design choice):
//    • A perceptual ramp — amber → orange → magenta → blue → indigo — is
//      monotonic in warmth/brightness, so the speed ordering reads at a glance
//      and survives on BOTH the dark and the light TradingView themes (mid-tones
//      carry both; the bright amber and the deep indigo sit at the extremes).
//    • Pure red / pure green are deliberately avoided for the LINES — they would
//      collide with candle bull/bear semantics. The warm→cool ramp sidesteps
//      both, so a ribbon line is never mistaken for a candle colour.
//
//  NO REPAINT: every line is ta.ema(src, …) — causal, computed only from bars up
//  to and including the current one, with no request.security and no future
//  reference. Historical bars do not repaint; only the live (rightmost) bar
//  updates intrabar until it closes, exactly like any plot.
//
//  Pine v6, overlay. This is a lens: no buy/sell, no alerts, no strategy() — it
//  draws moving averages, nothing more.
// =============================================================================

indicator("EMA Ribbon — 50/100/200/300/350", shorttitle = "EMA Ribbon", overlay = true)

// =============================================================================
// GENERAL
// =============================================================================
gGen = "General"
src = input.source(close, "Source", group = gGen,
     tooltip = "Price series the EMAs are computed from (default: close).")

// =============================================================================
// THE FIVE EMAs — one group each. Enable + colour share row 1 (inline); the
// length is on row 2. Defaults form the warm→cool ramp:
//   50 amber  ·  100 orange  ·  200 magenta  ·  300 blue  ·  350 indigo
// All colours are editable; pure red / pure green are avoided on purpose.
// =============================================================================

g50 = "EMA · 50  — fastest (default amber)"
show50 = input.bool(true,  "Show", group = g50, inline = "50")
col50  = input.color(#FFCA28, "",   group = g50, inline = "50")
len50  = input.int(50,  "Length", minval = 1, group = g50)

g100 = "EMA · 100 — fast (default orange)"
show100 = input.bool(true, "Show", group = g100, inline = "100")
col100  = input.color(#FB8C00, "",  group = g100, inline = "100")
len100  = input.int(100, "Length", minval = 1, group = g100)

g200 = "EMA · 200 — anchor (default magenta, drawn salient)"
show200 = input.bool(true, "Show", group = g200, inline = "200")
col200  = input.color(#EC407A, "",  group = g200, inline = "200")
len200  = input.int(200, "Length", minval = 1, group = g200)

g300 = "EMA · 300 — slow (default blue)"
show300 = input.bool(true, "Show", group = g300, inline = "300")
col300  = input.color(#42A5F5, "",  group = g300, inline = "300")
len300  = input.int(300, "Length", minval = 1, group = g300)

g350 = "EMA · 350 — slowest (default indigo)"
show350 = input.bool(true, "Show", group = g350, inline = "350")
col350  = input.color(#5C6BC0, "",  group = g350, inline = "350")
len350  = input.int(350, "Length", minval = 1, group = g350)

// =============================================================================
// LABELS — one colour-coded period tag per enabled line, floated at the last bar.
// =============================================================================
gLab = "Labels (period tags at last bar)"
showLabels  = input.bool(true, "Show period labels", group = gLab)
labelOffset = input.int(3, "Offset (bars right of last)", minval = 0, maxval = 50, group = gLab,
     tooltip = "How far to the right of the last bar the tags float, so they don't " +
               "sit on top of the most recent candles.")

// =============================================================================
// COMPUTE — ta.ema is causal (no repaint). Lengths are simple ints from inputs,
// which is what ta.ema requires; the source is the shared `src` series.
// =============================================================================
ema50  = ta.ema(src, len50)
ema100 = ta.ema(src, len100)
ema200 = ta.ema(src, len200)
ema300 = ta.ema(src, len300)
ema350 = ta.ema(src, len350)

// =============================================================================
// PLOT — only when enabled; the 200 is a hair thicker so it stays salient.
// Plot titles use the default periods (stable identifiers in the Style / Data
// windows); the dynamic labels below reflect the actually-configured lengths.
// =============================================================================
plot(show50  ? ema50  : na, "EMA 50",  color = col50,  linewidth = 1)
plot(show100 ? ema100 : na, "EMA 100", color = col100, linewidth = 1)
plot(show200 ? ema200 : na, "EMA 200", color = col200, linewidth = 2)
plot(show300 ? ema300 : na, "EMA 300", color = col300, linewidth = 1)
plot(show350 ? ema350 : na, "EMA 350", color = col350, linewidth = 1)

// =============================================================================
// LABELS — recreated whenever the last bar updates, so exactly one set persists.
//   Each tag is text-only (label.style_none → no box, no marker): just the period
//   string in the line's own colour. We clear the previous set first; deleting a
//   na / already-deleted handle is a safe no-op, which is the standard idiom.
// =============================================================================
f_tag(int len, color col, int lx, float y) =>
    label.new(lx, y, "EMA " + str.tostring(len),
         style     = label.style_none,
         textcolor = col,
         color     = color.new(color.gray, 100),  // transparent; unused by style_none
         size      = size.small,
         textalign = text.align_left)

var label l50  = na
var label l100 = na
var label l200 = na
var label l300 = na
var label l350 = na

if barstate.islast
    label.delete(l50)
    label.delete(l100)
    label.delete(l200)
    label.delete(l300)
    label.delete(l350)
    if showLabels
        lx = bar_index + labelOffset
        l50  := show50  ? f_tag(len50,  col50,  lx, ema50)  : na
        l100 := show100 ? f_tag(len100, col100, lx, ema100) : na
        l200 := show200 ? f_tag(len200, col200, lx, ema200) : na
        l300 := show300 ? f_tag(len300, col300, lx, ema300) : na
        l350 := show350 ? f_tag(len350, col350, lx, ema350) : na
````
