# OB/FVG + Volume Profile Confluence

## Description

█ OVERVIEW
OB/FVG + Volume Profile Confluence identifies the most relevant supply and demand zones by combining three complementary market analysis concepts: Order Blocks (OB), Fair Value Gaps (FVG), and Volume Profile.

Not every Order Block or Fair Value Gap carries the same weight. Markets create many of them, but only a small fraction actually influences future price action. This script addresses that by cross-checking every newly formed zone against a local volume profile, keeping only the zones that align with areas of increased market participation. Unlike standard Volume Profile tools that rely on a single POC (Point of Control), this script detects multiple local volume peaks (Vol Peaks), allowing several independent high-activity price levels to be tracked at once.

Each zone is continuously analyzed for its internal volume flow, tracking how much of the volume within it was generated by buyers versus sellers. This updates bar by bar, so the user can see which side of the market is gradually gaining control over a given area.
The indicator can also generate break and exit signals, but only for Order Blocks and Fair Value Gaps that are confluent with the Volume Profile, filtering out a large share of less significant levels.
The result is a tool that combines market structure, supply/demand imbalance, and real volume activity — giving traders not just the location of potential reaction zones, but also a read on their quality and historical strength.

█ CONCEPTS
Volume Profile (Vol Peaks)
Volume Profile shows how volume is distributed across price levels rather than looking only at the volume of each individual candle. Most Volume Profile tools focus on a single POC — the price level with the highest traded volume in the analyzed period. In practice, markets often form several local high-activity areas that can also act as meaningful support/resistance levels. Instead of a single POC, this indicator searches for Vol Peaks — local volume maxima across the entire price profile. Each one marks a level where the market showed above-average trading interest, and these levels are later used to score the quality of Order Blocks and Fair Value Gaps.

Order Blocks (OB)
Order Blocks are price zones where significant activity from large market participants previously occurred — areas where strong bullish or bearish impulses began, and where institutions may have built or closed positions. A bullish Order Block marks a demand zone that often preceded a strong upward move; a bearish Order Block marks a supply zone that preceded a strong decline. The script detects Order Blocks from local pivots and the direction of the candles preceding a structure shift, and can use either the full candle range (including wicks) or the body only.
Note: because Order Blocks require a confirmed pivot, each zone is drawn with a delay of roughly pivot_length + 1 bars after the point where it actually formed. This is a structural property of pivot-based detection, not a defect — it should be kept in mind when reading the chart, since the zone is confirmed only after the fact.

Fair Value Gaps (FVG)
A Fair Value Gap marks an imbalance between buyers and sellers. It forms during a strong price impulse, when the market moves fast enough that a gap remains between consecutive candles — evidence that supply and demand were not being matched evenly. These areas frequently attract price during later corrections, as the market tends to retest zones where trading did not occur smoothly. The indicator detects both bullish and bearish FVGs and can optionally display additional, informational gaps regardless of their confluence with the Volume Profile.

Why combine Order Blocks, Fair Value Gaps, and Volume Profile?
Each method looks at the market from a different angle: an Order Block points to where large participants may have acted; a Fair Value Gap shows where a sharp imbalance between buyers and sellers occurred; Volume Profile shows which price levels actually saw the highest concentration of trading activity. Combining the three isolates zones that simultaneously:
• arise from market structure,
• formed during a strong impulse,
• are confirmed by above-average volume activity.

Volume analysis inside zones
No zone is treated as a static rectangle. From the moment it forms, the indicator analyzes every following candle and calculates how much volume was generated by buyers versus sellers. Based on this, it displays the total volume accumulated inside the zone, the volume delta, and the percentage dominance of one side of the market.

Dynamic zone updates
Most indicators draw an Order Block or Fair Value Gap once and leave it unchanged. In this script, every active zone is updated on every new candle — volume calculations, buyer/seller dominance, labels, and zone appearance all change dynamically as the market develops. This means the user sees not just where a zone historically formed, but its current state.

Break and Exit signals
The indicator can generate two types of signals. Break signals mark a definitive break of a zone, meaning it has lost its validity. Exit signals appear when price leaves a zone after having entered it, which can indicate the end of a retest and a return of the dominant market direction. Both signal types are generated only for zones that are confluent with the Volume Profile.

█ APPLICATIONS
Filtering higher-quality supply and demand zones
The indicator lets you focus only on the Order Blocks and Fair Value Gaps that overlap with local volume peaks, filtering out most of the lower-relevance zones that otherwise clutter the chart.

Reading zone strength in real time
The dynamic volume split shows which side of the market is gradually taking control of a given area. A shift in dominance from buyers to sellers (or vice versa) can indicate a weakening zone.

Retests and breaks as areas of interest
• Exit signals mark potential continuation points after a zone has been retested
• Break signals confirm that a zone has lost validity, which can be relevant when tracking a breakout move

Break and Exit signals mark areas of interest, not automatic entry points. They are not standalone trade triggers — before treating a signal as significant, it is worth checking whether other tools, such as momentum indicators, are aligned with it.

Mapping market structure together with real activity
Vol Peaks combined with OB/FVG form a map of levels where large-participant activity historically concentrated and where a supply/demand imbalance also occurred.

Confirming setups from other methods
Confluent zones can serve as an additional filter for strategies based on market structure, order flow, or classic support/resistance — for example, treating a confluent supply zone as a reason for caution before going long into it, or using a test or break of a confluent zone as one factor among several when evaluating a trade.

Matching lookback to market structure and strategy
The lookback value should be chosen based on the timeframe and trading style. Too large a lookback causes many locally significant zones to be diluted, as the profile "smooths out" short-term peaks. Too small a lookback produces excessive noise and an overly dense grid of levels.

█ NOTES
• A larger lookback and higher bin count produce a more precise profile, but also increase script load. If you run into timeout issues, increase "Recalculate Volume Profile every N bars."
• Order Block zones are drawn with an inherent delay of roughly pivot_length + 1 bars, since they require a confirmed pivot before they can be plotted.
• Only zones with Vol Peak confluence generate Break/Exit signals — all other zones are purely informational.
• Dynamic changes in a zone's color and label reflect current volume flow, not just the historical moment the zone formed.
• Break and Exit signals represent different market behaviors and should be interpreted separately. They are not automatic entry signals — it is recommended to check for alignment with other tools (e.g., momentum indicators) before acting on them.

// Removes a zone once price breaks it (without a signal) OR once the zone is older than 1000 bars.
f_manageSimpleFvg(array<SimpleFVG> zones) =>
    if array.size(zones) > 0
        for i = array.size(zones) - 1 to 0 by 1
            SimpleFVG z = array.get(zones, i)
            bool broken = z.isBull ? close < z.bot : close > z.top
            bool tooOld = bar_index - z.leftIdx > 1000
            if broken or tooOld
                f_deleteSimpleFvg(z)
                array.remove(zones, i)

// bull/bear volume "from history" for the zone at the moment it was created
f_backfill(int span, float top, float bot) =>
    float bfBull = 0.0
    float bfBear = 0.0
    for off = 0 to span by 1
        float bf_h = high[off]
        float bf_l = low[off]
        float bf_c = close[off]
        float bf_v = volume[off]
        float bf_rng = math.max(bf_h - bf_l, syminfo.mintick)
        if bf_h > bot and bf_l < top
            float ov_h = math.min(bf_h, top)
            float ov_l = math.max(bf_l, bot)
            float added = bf_v * (ov_h - ov_l) / bf_rng
            bfBull += added * (bf_c - bf_l) / bf_rng
            bfBear += added * (bf_h - bf_c) / bf_rng
    [bfBull, bfBear]

// updates a single active zone on the current bar: volume, Vol Peak confluence, box, split, label
// The border and label color always reflects the DOMINANT volume in the zone (bull vs bear)
// and can change over time as new volume flows in.
f_zoneUpdate(Zone z, color bullCol, color bearCol, int transp, bool showProp, bool showVolLabel) =>
    if z.active
        float top = z.top
        float bot = z.bot
        int leftBar = z.leftIdx
        int rightBar = bar_index
        float candle_range = math.max(high - low, syminfo.mintick)

        if high > bot and low < top
            float ov_h = math.min(high, top)
            float ov_l = math.max(low, bot)
            float added_vol = volume * (ov_h - ov_l) / candle_range
            z.bullVol += added_vol * (close - low) / candle_range
            z.bearVol += added_vol * (high - close) / candle_range

        color domCol = z.bullVol >= z.bearVol ? bullCol : bearCol

        bool conf = containsPeak(z.confTop, z.confBot)
        z.confluent := conf

        box.set_right(z.mainBox, rightBar)
        color mainBg  = showProp ? color.new(color.white, 100) : (conf ? color.new(domCol, transp) : color.new(domCol, 100))
        color mainBrd = showProp ? na : (conf ? domCol : color.new(domCol, 100))
        box.set_bgcolor(z.mainBox, mainBg)
        box.set_border_color(z.mainBox, mainBrd)

        if showProp
            float total = z.bullVol + z.bearVol
            float bullPct = total > 0 ? z.bullVol / total : 0.5
            int bullRight = math.max(leftBar, math.min(rightBar, leftBar + math.round((rightBar - leftBar) * bullPct)))
            color bullBg  = conf ? color.new(bullCol, transp) : color.new(bullCol, 100)
            color bearBg  = conf ? color.new(bearCol, transp) : color.new(bearCol, 100)
            color bullBrd = conf ? bullCol : color.new(bullCol, 100)
            color bearBrd = conf ? bearCol : color.new(bearCol, 100)
            if na(z.bullBox)
                z.bullBox := box.new(leftBar, top, bullRight, bot, border_color = bullBrd, border_width = 1, border_style = line.style_solid, bgcolor = bullBg, xloc = xloc.bar_index)
                z.bearBox := box.new(bullRight, top, rightBar, bot, border_color = bearBrd, border_width = 1, border_style = line.style_solid, bgcolor = bearBg, xloc = xloc.bar_index)
            else
                box.set_left(z.bullBox, leftBar)
                box.set_right(z.bullBox, bullRight)
                box.set_top(z.bullBox, top)
                box.set_bottom(z.bullBox, bot)
                box.set_bgcolor(z.bullBox, bullBg)
                box.set_border_color(z.bullBox, bullBrd)
                box.set_left(z.bearBox, bullRight)
                box.set_right(z.bearBox, rightBar)
                box.set_top(z.bearBox, top)
                box.set_bottom(z.bearBox, bot)
                box.set_bgcolor(z.bearBox, bearBg)
                box.set_border_color(z.bearBox, bearBrd)
                z.bearBox   

        if showVolLabel
            float totalVol = z.bullVol + z.bearVol
            float deltaVol = z.bullVol - z.bearVol
            float deltaPct = totalVol > 0 ? (deltaVol / totalVol) * 100 : 0.0
            string txt = "Vol: " + format_volume(totalVol) + " | Δ: " + (deltaVol >= 0 ? "+" : "") + format_volume(deltaVol) + " (" + (deltaPct >= 0 ? "+" : "") + str.tostring(deltaPct, "#.#") + "%)"
            color labelCol = conf ? domCol : color.new(domCol, 100)
            if na(z.volLabel)
                z.volLabel := label.new(rightBar, (top + bot) / 2, txt, xloc = xloc.bar_index, yloc = yloc.price, style = label.style_label_left, color = color.new(color.white, 100), textcolor = labelCol, size = size.normal, textalign = text.align_left)
            else
                label.set_x(z.volLabel, rightBar)
                label.set_y(z.volLabel, (top + bot) / 2)
                label.set_text(z.volLabel, txt)
                label.set_textcolor(z.volLabel, labelCol)
                z.volLabel   

// creates a new OB zone
f_createOB(int sourceIdx, bool isBull) =>
    float ob_high = use_wicks ? high[sourceIdx] : math.max(open[sourceIdx], close[sourceIdx])
    float ob_low  = use_wicks ? low[sourceIdx]  : math.min(open[sourceIdx], close[sourceIdx])
    // Confluence is always checked against the FULL candle range (wicks included),
    // regardless of the "Include Wicks in OB" display setting, so toggling that
    // setting only changes how the box is drawn — not whether it is confluent.
    float ob_high_wick = high[sourceIdx]
    float ob_low_wick  = low[sourceIdx]
    if (ob_high - ob_low) >= avg_body_ob * ob_size_multiplier
        f_trimOldest(obZones)
        int obIdx = bar_index - sourceIdx
        bool conf = containsPeak(ob_high_wick, ob_low_wick)
        [bfBull, bfBear] = f_backfill(sourceIdx, ob_high, ob_low)
        color domCol = bfBull >= bfBear ? bull_ob_color : bear_ob_color
        color bgCol = show_ob_vol_proportions ? color.new(color.white, 100) : (conf ? color.new(domCol, ob_transp) : color.new(domCol, 100))
        color brdCol = show_ob_vol_proportions ? na : (conf ? domCol : color.new(domCol, 100))
        newBox = box.new(left = obIdx, top = ob_high, right = bar_index, bottom = ob_low, bgcolor = bgCol, border_color = brdCol, border_style = line.style_solid, border_width = 1, extend = extend.none, xloc = xloc.bar_index)
        Zone z = Zone.new(top = ob_high, bot = ob_low, leftIdx = obIdx, isBull = isBull, active = true, wasInside = false, confluent = conf, mainBox = newBox, bullBox = na, bearBox = na, volLabel = na, bullVol = bfBull, bearVol = bfBear, confTop = ob_high_wick, confBot = ob_low_wick)
        array.push(obZones, z)

// creates a new FVG zone
f_createFVG(float top, float bot, bool isBull) =>
    if (top - bot) >= avg_body_fvg * fvg_size_multiplier
        f_trimOldest(fvgZones)
        int fvgIdx = bar_index - 2
        bool conf = containsPeak(top, bot)
        [bfBull, bfBear] = f_backfill(2, top, bot)
        color domCol = bfBull >= bfBear ? bull_fvg_color : bear_fvg_color
        color bgCol = show_fvg_vol_proportions ? color.new(color.white, 100) : (conf ? color.new(domCol, fvg_transp) : color.new(domCol, 100))
        color brdCol = show_fvg_vol_proportions ? na : (conf ? domCol : color.new(domCol, 100))
        newBox = box.new(left = fvgIdx, top = top, right = bar_index, bottom = bot, bgcolor = bgCol, border_color = brdCol, border_style = line.style_solid, border_width = 1, extend = extend.none, xloc = xloc.bar_index)
        Zone z = Zone.new(top = top, bot = bot, leftIdx = fvgIdx, isBull = isBull, active = true, wasInside = false, confluent = conf, mainBox = newBox, bullBox = na, bearBox = na, volLabel = na, bullVol = bfBull, bearVol = bfBear, confTop = top, confBot = bot)
        array.push(fvgZones, z)

// creates a new informational FVG (without Volume Profile) — simple, static box with a fixed length
f_createSimpleFVG(float top, float bot, bool isBull) =>
    if (top - bot) >= avg_body_fvg * fvg_size_multiplier
        f_trimOldestSimpleFvg(simpleFvgZones)
        int fvgIdx = bar_index - 2
        color col = isBull ? bull_fvg_color : bear_fvg_color
        box newBox = box.new(left = fvgIdx, top = top, right = fvgIdx + simple_fvg_length, bottom = bot, bgcolor = color.new(col, fvg_transp), border_color = col, border_style = line.style_solid, border_width = 1, extend = extend.none, xloc = xloc.bar_index)
        SimpleFVG z = SimpleFVG.new(top = top, bot = bot, isBull = isBull, leftIdx = fvgIdx, b = newBox)
        array.push(simpleFvgZones, z)


// VOLUME PROFILE — calculations
bool doRecalc = barstate.islast or barstate.isrealtime or (bar_index % recalcEvery == 0)

if doRecalc
    int start_bar = bar_index - len + 1
    if len > 0 and start_bar >= 0
        int effective_start = math.max(start_bar, bar_index - 4900)

        float min_low  = 1e99
        float max_high = -1e99
        for i = effective_start to bar_index by 1
            int off = bar_index - i
            min_low  := math.min(min_low, low[off])
            max_high := math.max(max_high, high[off])

        float rg = max_high - min_low

        if array.size(polLines) > 0
            for i = 0 to array.size(polLines) - 1
                line.delete(array.get(polLines, i))
        if array.size(polLabels) > 0
            for i = 0 to array.size(polLabels) - 1
                label.delete(array.get(polLabels, i))
        array.clear(polLines)
        array.clear(polLabels)
        array.clear(peakPrices)

        if rg >= syminfo.mintick * 5
            float binH = rg / (BINS - 1)
            array.fill(vol, 0)

            for i = effective_start to bar_index by 1
                int off = bar_index - i
                float h = high[off]
                float l = low[off]
                float v = volume[off]
                if h > l
                    float frac = binH / (h - l)
                    int b1 = math.max(0, math.floor((l - min_low) / binH))
                    int b2 = math.min(BINS - 1, math.floor((h - min_low) / binH))
                    if b1 <= b2
                        for b = b1 to b2 by 1
                            array.set(vol, b, array.get(vol, b) + v * frac)

            float maxV = array.max(vol)

            if maxV > 0
                array.fill(workVol, 0)
                
                
                for i = 0 to BINS - 1
                    float v      = array.get(vol, i)
                    float vLeft  = i > 0 ? array.get(vol, i - 1) : -1.0
                    float vRight = i < BINS - 1 ? array.get(vol, i + 1) : -1.0
                    bool isLocalMax = v > 0 and v >= vLeft and v >= vRight and (v > vLeft or v > vRight)
                    array.set(workVol, i, isLocalMax ? v : -1.0)

                float threshold  = maxV * (minVolPct / 100.0)
                int   minDistBin = math.max(1, math.round(BINS * (minDistPct / 100.0)))
                int   x1 = math.max(0, bar_index - len + 1)

                for k = 0 to maxPeaks - 1
                    float bestV = array.max(workVol)
                    if bestV < threshold or bestV <= 0
                        break
                    int bestB = array.indexof(workVol, bestV)
                    float peakPrice = min_low + binH * (bestB + 0.5)
                    array.push(peakPrices, peakPrice)

                    color col = lineColor
                    if rankColors
                        float strength = bestV / maxV
                        int transpPeak = int(math.max(0, math.min(70, (1 - strength) * 70)))
                        col := color.new(lineColor, transpPeak)

                    if showPOCLines
                        line ln = line.new(x1, peakPrice, bar_index, peakPrice, color = col, width = lineWidth, style = lineStyle_, extend = extend.right)
                        array.push(polLines, ln)
                        if showLabels
                            string txt = "Peak " + str.tostring(peakPrice, format.mintick)
                            label lbl = label.new(x1, peakPrice, txt, style = label.style_label_left, color = col, textcolor = color.white, size = size.small)
                            array.push(polLabels, lbl)

                    int lo = math.max(0, bestB - minDistBin)
                    int hi = math.min(BINS - 1, bestB + minDistBin)
                    for j = lo to hi by 1
                        array.set(workVol, j, -1)


// UPDATING EXISTING ZONES
if array.size(obZones) > 0
    for i = 0 to array.size(obZones) - 1
        f_zoneUpdate(array.get(obZones, i), bull_ob_color, bear_ob_color, ob_transp, show_ob_vol_proportions, show_ob_vol_label)

if show_fvg and array.size(fvgZones) > 0
    for i = 0 to array.size(fvgZones) - 1
        f_zoneUpdate(array.get(fvgZones, i), bull_fvg_color, bear_fvg_color, fvg_transp, show_fvg_vol_proportions, show_fvg_vol_label)


// PIVOTS → ORDER BLOCKS
pivot_low = ta.pivotlow(low, pivot_length, pivot_length)
pivot_high = ta.pivothigh(high, pivot_length, pivot_length)

if not na(pivot_low)
    int idx = pivot_length
    bool pivot_green = is_green(idx)
    bool prev_green = is_green(idx + 1)
    bool next_green = is_green(idx - 1)
    if not pivot_green and next_green
        f_createOB(idx, true)
    else if pivot_green and not prev_green
        f_createOB(idx + 1, true)
    else if pivot_green and prev_green and next_green
        f_createOB(idx + 1, false)

if not na(pivot_high)
    int idx = pivot_length
    bool pivot_green = is_green(idx)
    bool prev_green = is_green(idx + 1)
    bool next_green = is_green(idx - 1)
    if pivot_green and not next_green
        f_createOB(idx, false)
    else if not pivot_green and prev_green
        f_createOB(idx + 1, false)
    else if not pivot_green and not prev_green and not next_green
        f_createOB(idx + 1, true)


// FVG — creation
if show_fvg
    if low > high[2]
        f_createFVG(low, high[2], true)
    if high < low[2]
        f_createFVG(low[2], high, false)

// informational FVG (without Volume Profile)
if show_simple_fvg
    if low > high[2]
        f_createSimpleFVG(low, high[2], true)
    if high < low[2]
        f_createSimpleFVG(low[2], high, false)

// SIGNALS — from OB, only when the zone was confluent with a Vol Peak
bool buySignal = false
bool sellSignal = false
bool exitBuySignal = false
bool exitSellSignal = false

if array.size(obZones) > 0
    for i = 0 to array.size(obZones) - 1
        Zone z = array.get(obZones, i)
        if z.active
            bool isInside = close >= z.bot and close <= z.top
            bool wasInside = z.wasInside
            z.wasInside := isInside
            if z.isBull and close < z.bot
                z.active := false
                f_deleteZone(z)
                if z.confluent
                    sellSignal := true
            else if not z.isBull and close > z.top
                z.active := false
                f_deleteZone(z)
                if z.confluent
                    buySignal := true
            else if wasInside and not isInside
                if z.isBull and close > z.top and z.confluent
                    exitBuySignal := true
                else if not z.isBull and close < z.bot and z.confluent
                    exitSellSignal := true

// DRAWING OB SIGNALS
plotshape(showBreakSignals and buySignal, title = 'OB Break Up', location = location.belowbar, style = shape.triangleup, color = bull_ob_color, size = size.tiny)
plotshape(showBreakSignals and sellSignal, title = 'OB Break Down', location = location.abovebar, style = shape.triangledown, color = bear_ob_color, size = size.tiny)
plotshape(showExitSignals and exitBuySignal, title = 'OB Exit Up', location = location.belowbar, style = shape.circle, color = bull_ob_color, size = size.tiny)
plotshape(showExitSignals and exitSellSignal, title = 'OB Exit Down', location = location.abovebar, style = shape.circle, color = bear_ob_color, size = size.tiny)

// SIGNALS — from FVG, only when the zone was confluent with a Vol Peak
bool buySignalFVG = false
bool sellSignalFVG = false
bool exitBuySignalFVG = false
bool exitSellSignalFVG = false

if show_fvg and array.size(fvgZones) > 0
    for i = 0 to array.size(fvgZones) - 1
        Zone z = array.get(fvgZones, i)
        if z.active
            bool isInside = close >= z.bot and close <= z.top
            bool wasInside = z.wasInside
            z.wasInside := isInside
            if z.isBull and close < z.bot
                z.active := false
                f_deleteZone(z)
                if z.confluent
                    sellSignalFVG := true
            else if not z.isBull and close > z.top
                z.active := false
                f_deleteZone(z)
                if z.confluent
                    buySignalFVG := true
            else if wasInside and not isInside
                if z.isBull and close > z.top and z.confluent
                    exitBuySignalFVG := true
                else if not z.isBull and close < z.bot and z.confluent
                    exitSellSignalFVG := true

// DRAWING FVG SIGNALS
plotshape(showBreakSignals and buySignalFVG, title = 'FVG Break Up', location = location.belowbar, style = shape.triangleup, color = bull_fvg_color, size = size.tiny)
plotshape(showBreakSignals and sellSignalFVG, title = 'FVG Break Down', location = location.abovebar, style = shape.triangledown, color = bear_fvg_color, size = size.tiny)
plotshape(showExitSignals and exitBuySignalFVG, title = 'FVG Exit Up', location = location.belowbar, style = shape.circle, color = bull_fvg_color, size = size.tiny)
plotshape(showExitSignals and exitSellSignalFVG, title = 'FVG Exit Down', location = location.abovebar, style = shape.circle, color = bear_fvg_color, size = size.tiny)

// CLEANING UP ZONES
f_cleanupOld(obZones)
if show_fvg
    f_cleanupOld(fvgZones)
if show_simple_fvg
    f_manageSimpleFvg(simpleFvgZones)

// ALERTS

alertcondition(showBreakSignals and buySignal,  title = "OB Break Up",   message = "OB Break Up")
alertcondition(showBreakSignals and sellSignal, title = "OB Break Down", message = "OB Break Down")

// OB: Exits (Test)
alertcondition(showExitSignals and exitBuySignal,  title = "OB Exit Up",   message = "OB Exit Up")

// FVG: Breaks
alertcondition(showBreakSignals and buySignalFVG,  title = "FVG Break Up",   message = "FVG Break Up")

// FVG: Exits (Test)
alertcondition(showExitSignals and exitBuySignalFVG,  title = "FVG Exit Up",   message = "FVG Exit Up")
