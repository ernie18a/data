# SMA & EMA 9/10/20/21/50/100/200

- url: https://www.tradingview.com/script/BC2fEAXz/
- type: indicator
- pine_id: PUB;5395a33d8f6647209f43d2e2010b71e4
- version: 1.0

## Description

Dual-Type Averages: Combines 5 Simple Moving Averages (SMAs) and 5 Exponential Moving Averages (EMAs) into a single, unified indicator.

## Source Code

````pine
//@version=6
indicator(title="SMA & EMA 9/10/20/21/50/100/200", overlay=true)

// --- Simple Moving Averages (SMAs) ---
sma_10  = ta.sma(close, 10)
sma_20  = ta.sma(close, 20)
sma_50  = ta.sma(close, 50)
sma_100 = ta.sma(close, 100)
sma_200 = ta.sma(close, 200)

// --- Exponential Moving Averages (EMAs) ---
ema_9   = ta.ema(close, 9)
ema_21  = ta.ema(close, 21)
ema_50  = ta.ema(close, 50)
ema_100 = ta.ema(close, 100)
ema_200 = ta.ema(close, 200)

// --- Plot SMAs as Solid Lines ---
plot(sma_10,  color=color.purple, linestyle=plot.linestyle_solid, linewidth=2, title="SMA 10")
plot(sma_20,  color=color.blue,   linestyle=plot.linestyle_solid, linewidth=2, title="SMA 20")
plot(sma_50,  color=color.green,  linestyle=plot.linestyle_solid, linewidth=2, title="SMA 50")
plot(sma_100, color=color.orange,   linestyle=plot.linestyle_solid, linewidth=2, title="SMA 100")
plot(sma_200, color=color.red,linestyle=plot.linestyle_solid, linewidth=2, title="SMA 200")

// --- Plot EMAs as Dotted Lines ---
plot(ema_9,   color=color.purple, linestyle=plot.linestyle_dotted, title="EMA 9")
plot(ema_21,  color=color.blue,   linestyle=plot.linestyle_dotted, title="EMA 21")
plot(ema_50,  color=color.green,  linestyle=plot.linestyle_dotted, title="EMA 50")
plot(ema_100, color=color.orange, linestyle=plot.linestyle_dotted, title="EMA 100")
plot(ema_200, color=color.red,    linestyle=plot.linestyle_dotted, title="EMA 200")
````
