# Multi SMA (20/50/100/200)

- url: https://www.tradingview.com/script/5D9b301h/
- type: indicator
- pine_id: PUB;ebaaf18921064d5eb8c012d29f6222ce
- version: 1.0

## Description

Multi SMA (20/50/100/200) = เป็นมัลติ sma ทั้งเส้น 200 เส้น 100 เส้น 50 และเส้น 20 ที่สามารถอ่านค่าความผันผวนของตลาดได้

## Source Code

````pine
//@version=6
indicator("Multi SMA (20/50/100/200)", overlay = true)

// --- Inputs ---
showSma1 = input.bool(true, "Show SMA 20", group = "SMA 1")
len1     = input.int(20, "Length 1", minval = 1, group = "SMA 1")
col1     = input.color(color.blue, "Color 1", group = "SMA 1")

showSma2 = input.bool(true, "Show SMA 50", group = "SMA 2")
len2     = input.int(50, "Length 2", minval = 1, group = "SMA 2")
col2     = input.color(color.orange, "Color 2", group = "SMA 2")

showSma3 = input.bool(true, "Show SMA 100", group = "SMA 3")
len3     = input.int(100, "Length 3", minval = 1, group = "SMA 3")
col3     = input.color(color.green, "Color 3", group = "SMA 3")

showSma4 = input.bool(true, "Show SMA 200", group = "SMA 4")
len4     = input.int(200, "Length 4", minval = 1, group = "SMA 4")
col4     = input.color(color.red, "Color 4", group = "SMA 4")

// --- Calculations ---
sma1 = ta.sma(close, len1)
sma2 = ta.sma(close, len2)
sma3 = ta.sma(close, len3)
sma4 = ta.sma(close, len4)

// --- Plotting ---
plot(showSma1 ? sma1 : na, "SMA 20", color = col1, linewidth = 1)
plot(showSma2 ? sma2 : na, "SMA 50", color = col2, linewidth = 1)
plot(showSma3 ? sma3 : na, "SMA 100", color = col3, linewidth = 1)
plot(showSma4 ? sma4 : na, "SMA 200", color = col4, linewidth = 2)
````
