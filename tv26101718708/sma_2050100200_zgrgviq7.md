## Description

SMA 20/50/100/200 – Indikator-Beschreibung:

Dieser Indikator zeichnet bis zu vier Simple Moving Averages (SMAs) gleichzeitig auf dem Chart ein und gibt damit einen schnellen Überblick über kurz-, mittel- und langfristige Trendrichtungen.

Was der Indikator macht
Berechnet werden die gleitenden Durchschnitte der letzten 20, 50, 100 und 200 Kerzen auf Basis einer frei wählbaren Quelle (Standard: Schlusskurs). Jede Linie kann einzeln ein- oder ausgeblendet werden.

SMA 20/50/100/200 – Indicator Description
This indicator plots up to four Simple Moving Averages (SMAs) simultaneously on the chart, providing a quick overview of short-, medium-, and long-term trend directions.

What the Indicator Does
It calculates the moving averages of the last 20, 50, 100, and 200 candles based on a freely selectable source (default: close price). Each line can be toggled on or off individually.

## Source Code

````pine
// This Pine Script® code is subject to the terms of the Mozilla Public License 2.0 at https://mozilla.org/MPL/2.0/
// © chrishaschke89

//@version=5
indicator("SMA 20/50/100/200", overlay=true)

// ── Inputs ──────────────────────────────────────────────
src = input.source(close, title="Quelle")

show20  = input.bool(true, title="SMA 20 anzeigen")
show50  = input.bool(true, title="SMA 50 anzeigen")
show100 = input.bool(true, title="SMA 100 anzeigen")
show200 = input.bool(true, title="SMA 200 anzeigen")

// ── Berechnungen ─────────────────────────────────────────
sma20  = ta.sma(src, 20)
sma50  = ta.sma(src, 50)
sma100 = ta.sma(src, 100)
sma200 = ta.sma(src, 200)

// ── Plots ────────────────────────────────────────────────
plot(show20  ? sma20  : na, title="SMA 20",  color=color.new(color.blue,   0), linewidth=1)
plot(show50  ? sma50  : na, title="SMA 50",  color=color.new(color.orange, 0), linewidth=1)
plot(show100 ? sma100 : na, title="SMA 100", color=color.new(color.red,    0), linewidth=2)
plot(show200 ? sma200 : na, title="SMA 200", color=color.new(color.purple, 0), linewidth=2)
````
