Instead of treating these as guaranteed reversal zones, the system presents them as contextual areas of interest, which can be used alongside structure for more informed analysis. Real-time updates during candle formation are normal, and the structure becomes more reliable once conditions are fully confirmed.
In essence, the core concept of StructureX is to provide a structured lens through which market behavior can be interpreted, combining clarity, consistency, and multiple layers of context. ⚙️ How It Works – StructureX 

StructureX operates as a rule-based analytical engine that processes price data step by step to build a structured view of the market. Instead of generating signals from a single condition, it follows a logical sequence of detection → validation → visualization, where each layer depends on the previous one.

🔹 1. Price Data Processing & Swing Identification
The system begins by scanning historical and current price data to detect swing highs and swing lows within a defined lookback range. These swings represent natural turning points in the market and form the base structure. Since this process requires surrounding candles for confirmation, there is a built-in delay that helps filter out noise and avoid premature signals.

🔹 2. Structure Formation & Bias Tracking
Once swings are identified, the system uses them to construct a market structure framework. By comparing current swings with previous ones, it determines whether the market is forming:


Higher highs / higher lows → bullish structure


Lower highs / lower lows → bearish structure


This comparison allows the system to maintain a dynamic market bias, which updates only when specific structural conditions are met. The bias is not predicted—it is derived from confirmed price behavior.

🔹 3. Break Validation (BOS & CHoCH)
After establishing structure, the system monitors how price interacts with key levels:


If price breaks a level in the direction of the current bias, it is marked as a Break of Structure (BOS), indicating continuation.


If price breaks a level against the current bias, it is marked as a Change of Character (CHoCH), suggesting a potential transition.


These events are only recognized when price clearly crosses and confirms the level, which helps reduce false interpretations and ensures consistency.

🔹 4. Contextual Zone Detection (Order Blocks & FVG)
Once a structural event (BOS/CHoCH) occurs, the system identifies contextual zones around that movement:


Order Blocks are derived from the last opposing candles before a strong move, highlighting areas where price previously showed strong reaction.


Fair Value Gaps (FVGs) are detected when price moves quickly, leaving behind areas of imbalance.


These zones are not treated as guaranteed reaction points. Instead, they are presented as areas of interest, providing additional context for how price might behave if revisited.

🔹 5. Liquidity Interaction Monitoring
The system also evaluates liquidity behavior, specifically looking for scenarios where price moves beyond recent highs or lows and then rejects. These are marked as liquidity sweeps, which can indicate short-term shifts in order flow. This feature helps users observe how price interacts with commonly targeted levels, without assuming a fixed outcome.

🔹 6. Continuous Update & Object Management
StructureX continuously updates all elements in real time:


Active zones (OBs/FVGs) are extended forward until they are invalidated


Old or mitigated zones are removed to keep the chart clean


Structure levels are maintained and updated as new data forms


This ensures the chart reflects the current state of the market, not outdated conditions.

🔹 7. Visualization & User Interaction
All detected elements are displayed using lines, labels, boxes, and optional background coloring. The goal is to provide clear visual feedback without overwhelming the user. Additionally, customizable inputs allow users to adjust sensitivity and visibility based on their preferences, while alerts notify them of key structural events.

🔄 Real-Time Behavior Note
Because the system relies on confirmation-based logic, some elements (especially swings) require multiple candles to finalize. During live candle formation, temporary changes may occur, but the structure becomes more stable once conditions are confirmed. This behavior is normal and helps improve reliability by reducing noise.

var array<float> fvgTopArr  = array.new<float>()
var array<float> fvgBotArr  = array.new<float>()

// ─────────────────────────────────────────────────────────────────────────────
// ██  FUNCTIONS
// ─────────────────────────────────────────────────────────────────────────────

// ── Swing High Detection ──
isSwingHigh(int len) =>
    high[len] == ta.highest(high, 2 * len + 1)

// ── Swing Low Detection ──
isSwingLow(int len) =>
    low[len] == ta.lowest(low, 2 * len + 1)

// ── Create Structure Line (same-to-same like reference image) ──
// Draws horizontal dashed line from swing point → breakout bar
// Label placed at breakout point (right end)
drawStructureLine(int x1, float priceLvl, int x2, color col, string txt, bool isBullBreak, bool isDashed) =>
    lineStyle = isDashed ? line.style_dashed : line.style_solid
    ln = line.new(x1, priceLvl, x2, priceLvl, color = col, width = structLineWidth, style = lineStyle)
    // Label at centre of the line
    midX = math.round((x1 + x2) / 2)
    lblStyle = isBullBreak ? label.style_label_down : label.style_label_up
    lb = label.new(midX, priceLvl, txt, color = color.new(col, 100), textcolor = col, style = lblStyle, size = size.tiny)
    [ln, lb]

// ─────────────────────────────────────────────────────────────────────────────
// ██  SWING POINT DETECTION
// ─────────────────────────────────────────────────────────────────────────────

pivotHigh = isSwingHigh(swingLen)
pivotLow  = isSwingLow(swingLen)

// Internal structure pivots
iPivotHigh = isSwingHigh(internalLen)
iPivotLow  = isSwingLow(internalLen)

// ─────────────────────────────────────────────────────────────────────────────
// ██  MARKET STRUCTURE TRACKING
// ─────────────────────────────────────────────────────────────────────────────

// ── Track new Swing High ──
if pivotHigh
    prevSwingHigh    := swingHighPrice
    prevSwingHighBar := swingHighBar
    swingHighPrice   := high[swingLen]
    swingHighBar     := bar_index - swingLen
    highBroken       := false  // Reset flag for new level

// ── Track new Swing Low ──
if pivotLow
    prevSwingLow    := swingLowPrice
    prevSwingLowBar := swingLowBar
    swingLowPrice   := low[swingLen]
    swingLowBar     := bar_index - swingLen
    lowBroken        := false  // Reset flag for new level

// ─────────────────────────────────────────────────────────────────────────────
// ██  BOS & CHoCH DETECTION
// ─────────────────────────────────────────────────────────────────────────────

// BOS  = Break of Structure → trend continuation
// CHoCH = Change of Character → trend reversal (Market Structure Shift)

var bool bosUp       = false
var bool bosDn       = false
var bool chochUp     = false
var bool chochDn     = false

bosUp   := false
bosDn   := false
chochUp := false
chochDn := false

// ── Bullish BOS: price closes above previous swing high in bullish trend ──
if not na(swingHighPrice) and not highBroken and close > swingHighPrice and marketBias == 1
    bosUp      := true
    highBroken := true // Only write once
    if showBOS
        drawStructureLine(swingHighBar, swingHighPrice, bar_index, bullStructColor, "BOS", true, false)
    lastConfirmedHigh    := swingHighPrice
    lastConfirmedHighBar := swingHighBar

// ── Bearish BOS: price closes below previous swing low in bearish trend ──
if not na(swingLowPrice) and not lowBroken and close < swingLowPrice and marketBias == -1
    bosDn     := true
    lowBroken := true // Only write once
    if showBOS
        drawStructureLine(swingLowBar, swingLowPrice, bar_index, bearStructColor, "BOS", false, false)
    lastConfirmedLow    := swingLowPrice
    lastConfirmedLowBar := swingLowBar

// ── Bullish CHoCH (MSS): bearish trend → price closes above swing high ──
if not na(swingHighPrice) and not highBroken and close > swingHighPrice and marketBias != 1
    chochUp     := true
    highBroken  := true // Only write once
    marketBias  := 1
    if showCHoCH
        drawStructureLine(swingHighBar, swingHighPrice, bar_index, bullStructColor, "CHoCH", true, true)
    lastConfirmedHigh    := swingHighPrice
    lastConfirmedHighBar := swingHighBar

// ── Bearish CHoCH (MSS): bullish trend → price closes below swing low ──
if not na(swingLowPrice) and not lowBroken and close < swingLowPrice and marketBias != -1
    chochDn     := true
    lowBroken   := true // Only write once
    marketBias  := -1
    if showCHoCH
        drawStructureLine(swingLowBar, swingLowPrice, bar_index, bearStructColor, "CHoCH", false, true)
    lastConfirmedLow    := swingLowPrice
    lastConfirmedLowBar := swingLowBar

// ─────────────────────────────────────────────────────────────────────────────
// ██  INTERNAL STRUCTURE (Optional)
// ─────────────────────────────────────────────────────────────────────────────

var float iSwingHigh = na
var int   iSwingHighBar = na
var float iSwingLow  = na
var int   iSwingLowBar = na

if showInternalStr
    if iPivotHigh
        iSwingHigh    := high[internalLen]
        iSwingHighBar := bar_index - internalLen

    if iPivotLow
        iSwingLow    := low[internalLen]
        iSwingLowBar := bar_index - internalLen

    // Internal bullish BOS
    if not na(iSwingHigh) and close > iSwingHigh and marketBias == 1
        line.new(iSwingHighBar, iSwingHigh, bar_index, iSwingHigh, color = color.new(bullStructColor, 50), width = 1, style = line.style_dotted)
        label.new(math.round((iSwingHighBar + bar_index) / 2), iSwingHigh, "iBOS", color = color.new(bullStructColor, 70), textcolor = bullStructColor, style = label.style_label_down, size = size.tiny)
        iSwingHigh := na

    // Internal bearish BOS
    if not na(iSwingLow) and close < iSwingLow and marketBias == -1
        line.new(iSwingLowBar, iSwingLow, bar_index, iSwingLow, color = color.new(bearStructColor, 50), width = 1, style = line.style_dotted)
        label.new(math.round((iSwingLowBar + bar_index) / 2), iSwingLow, "iBOS", color = color.new(bearStructColor, 70), textcolor = bearStructColor, style = label.style_label_up, size = size.tiny)
        iSwingLow := na

// ─────────────────────────────────────────────────────────────────────────────
// ██  SWING POINT LABELS (HH, HL, LH, LL)
// ─────────────────────────────────────────────────────────────────────────────

if showSwingPoints
    if pivotHigh
        isHH = not na(prevSwingHigh) and swingHighPrice > prevSwingHigh
        txt  = isHH ? "HH" : "LH"
        col  = isHH ? bullStructColor : bearStructColor
        label.new(swingHighBar, swingHighPrice, txt, color = color.new(col, 100), textcolor = col, style = label.style_label_down, size = size.tiny)

    if pivotLow
        isHL = not na(prevSwingLow) and swingLowPrice > prevSwingLow
        txt  = isHL ? "HL" : "LL"
        col  = isHL ? bullStructColor : bearStructColor
        label.new(swingLowBar, swingLowPrice, txt, color = color.new(col, 100), textcolor = col, style = label.style_label_up, size = size.tiny)

// ─────────────────────────────────────────────────────────────────────────────
// ██  ORDER BLOCK DETECTION
// ─────────────────────────────────────────────────────────────────────────────

if showOB
    // ── Bullish OB: last bearish candle before a bullish CHoCH/BOS ──
    if chochUp or bosUp
        obTop = high[1]
        obBot = low[1]
        // Search for the last bearish candle
        for i = 1 to swingLen
            if close[i] < open[i]
                obTop := high[i]
                obBot := low[i]
                break

        bx = box.new(bar_index - 1, obTop, bar_index + 20, obBot, border_color = color.new(bullOBColor, 60), bgcolor = bullOBColor, border_width = 1, text = "+OB", text_color = color.new(color.white, 20), text_size = size.normal, text_halign = text.align_center, text_valign = text.align_center)
        array.push(obBoxes, bx)
        array.push(obTypes, 1)
        array.push(obTopArr, obTop)
        array.push(obBotArr, obBot)

        // Cap the number of OBs
        if array.size(obBoxes) > obMaxBoxes
            box.delete(array.shift(obBoxes))
            array.shift(obTypes)
            array.shift(obTopArr)
            array.shift(obBotArr)

    // ── Bearish OB: last bullish candle before a bearish CHoCH/BOS ──
    if chochDn or bosDn
        obTop = high[1]
        obBot = low[1]
        for i = 1 to swingLen
            if close[i] > open[i]
                obTop := high[i]
                obBot := low[i]
                break

        bx = box.new(bar_index - 1, obTop, bar_index + 20, obBot, border_color = color.new(bearOBColor, 60), bgcolor = bearOBColor, border_width = 1, text = "-OB", text_color = color.new(color.white, 20), text_size = size.normal, text_halign = text.align_center, text_valign = text.align_center)
        array.push(obBoxes, bx)
        array.push(obTypes, -1)
        array.push(obTopArr, obTop)
        array.push(obBotArr, obBot)

        if array.size(obBoxes) > obMaxBoxes
            box.delete(array.shift(obBoxes))
            array.shift(obTypes)
            array.shift(obTopArr)
            array.shift(obBotArr)

    // ── OB Mitigation (remove when price trades through) ──
    if array.size(obBoxes) > 0
        for i = array.size(obBoxes) - 1 to 0
            if i >= array.size(obBoxes)
                continue
            obType = array.get(obTypes, i)
            obT    = array.get(obTopArr, i)
            obB    = array.get(obBotArr, i)
            mitigated = false

            priceRef = obMitigationType == "Close" ? close : (obType == 1 ? low : high)
            if obType == 1 and priceRef < obB
                mitigated := true
            if obType == -1 and priceRef > obT
                mitigated := true

            if mitigated
                box.delete(array.get(obBoxes, i))
                array.remove(obBoxes, i)
                array.remove(obTypes, i)
                array.remove(obTopArr, i)
                array.remove(obBotArr, i)
            else
                // Extend active OBs to current bar
                box.set_right(array.get(obBoxes, i), bar_index + 5)

// ─────────────────────────────────────────────────────────────────────────────
// ██  FAIR VALUE GAP (FVG) DETECTION
// ─────────────────────────────────────────────────────────────────────────────

if showFVG
    // ── Bullish FVG: gap between candle [2] high and candle [0] low ──
    bullFVG = low > high[2] and close[1] > open[1]
    if bullFVG and (fvgFilter == "All" or fvgFilter == "Bullish")
        fTop = low
        fBot = high[2]
        bx = box.new(bar_index - 1, fTop, bar_index + 15, fBot, border_color = color.new(bullFVGColor, 70), bgcolor = bullFVGColor, border_width = 0, text = "FVG", text_color = color.new(color.white, 50), text_size = size.small, text_halign = text.align_center, text_valign = text.align_center)
        array.push(fvgBoxes, bx)
        array.push(fvgTypes, 1)
        array.push(fvgTopArr, fTop)
        array.push(fvgBotArr, fBot)

        if array.size(fvgBoxes) > fvgMaxBoxes
            box.delete(array.shift(fvgBoxes))
            array.shift(fvgTypes)
            array.shift(fvgTopArr)
            array.shift(fvgBotArr)

    // ── Bearish FVG: gap between candle [0] high and candle [2] low ──
    bearFVG = high < low[2] and close[1] < open[1]
    if bearFVG and (fvgFilter == "All" or fvgFilter == "Bearish")
        fTop = low[2]
        fBot = high
        bx = box.new(bar_index - 1, fTop, bar_index + 15, fBot, border_color = color.new(bearFVGColor, 70), bgcolor = bearFVGColor, border_width = 0, text = "FVG", text_color = color.new(color.white, 50), text_size = size.small, text_halign = text.align_center, text_valign = text.align_center)
        array.push(fvgBoxes, bx)
        array.push(fvgTypes, -1)
        array.push(fvgTopArr, fTop)
        array.push(fvgBotArr, fBot)

        if array.size(fvgBoxes) > fvgMaxBoxes
            box.delete(array.shift(fvgBoxes))
            array.shift(fvgTypes)
            array.shift(fvgTopArr)
            array.shift(fvgBotArr)

    // ── FVG Fill / Mitigation ──
    if array.size(fvgBoxes) > 0
        for i = array.size(fvgBoxes) - 1 to 0
            if i >= array.size(fvgBoxes)
                continue
            fType = array.get(fvgTypes, i)
            fTop  = array.get(fvgTopArr, i)
            fBot  = array.get(fvgBotArr, i)
            filled = false

            if fType == 1 and low <= fBot
                filled := true
            if fType == -1 and high >= fTop
                filled := true

            if filled
                box.delete(array.get(fvgBoxes, i))
                array.remove(fvgBoxes, i)
                array.remove(fvgTypes, i)
                array.remove(fvgTopArr, i)
                array.remove(fvgBotArr, i)
            else
                box.set_right(array.get(fvgBoxes, i), bar_index + 3)

// ─────────────────────────────────────────────────────────────────────────────
// ██  LIQUIDITY SWEEP DETECTION
// ─────────────────────────────────────────────────────────────────────────────

if showLiqSweep
    // ── High Sensitivity Sweep of Lows ──
    // Detects sweep of the most significant low in the lookback period
    majorLow = ta.lowest(low[1], liqLookback)
    
    // Displacement check: Price must wick below major low AND close significantly above it
    // We also check if it's a 'rejection' candle (wick is at least 30% of total candle size)
    candleSize = high - low
    lowerWick  = math.min(open, close) - low
    isRejection = lowerWick > (candleSize * 0.3)
    
    sweptLow = low < majorLow and close > majorLow and isRejection and close > open
    if sweptLow
        label.new(bar_index, low, "🔻 Sweep", color = color.new(liqSweepColor, 80), textcolor = liqSweepColor, style = label.style_label_up, size = size.tiny)

    // ── High Sensitivity Sweep of Highs ──
    majorHigh = ta.highest(high[1], liqLookback)
    
    upperWick = high - math.max(open, close)
    isBearishRejection = upperWick > (candleSize * 0.3)
    
    sweptHigh = high > majorHigh and close < majorHigh and isBearishRejection and close < open
    if sweptHigh
        label.new(bar_index, high, "🔺 Sweep", color = color.new(liqSweepColor, 80), textcolor = liqSweepColor, style = label.style_label_down, size = size.tiny)
