## Description

​Strategy: 9:30 AM Institutional Open (Precision Body Edition)
​General Description
​This automated strategy captures the volatility expansion generated by the New York Stock Exchange (NYSE) open. Unlike standard breakout indicators, this algorithm is designed under Institutional Trading principles, prioritizing body close confirmation over wicks to avoid "fakeouts" or initial liquidity sweeps.
​The goal is to filter noise and execute a single high-probability trade based on real price displacement.
​Execution Logic (SMC/ICT)
​Reference Range: The script automatically captures the high and low of the 5-minute candle between 09:30 and 09:35 AM (NY Time). This zone is defined as the "Institutional Point of Interest."
​Body Validation: The entry is only triggered if a subsequent candle (suggested timeframe: 1 min) closes its body outside the range. If there is only a wick touch, the script ignores it, treating it as a simple liquidity grab.
​One Shot, One Opportunity: Adhering to professional discipline, the script allows only one trade per day. Whether the Stop Loss or Take Profit is hit, the system locks until the next day's open, eliminating the risk of overtrading or revenge trading.
​Dynamic Risk Filter: Includes a minimum safety floor for the Stop Loss (10 pips for Forex / 1500 ticks for Gold and Indices), ensuring the position has enough "room to breathe" even in very tight opening ranges.
​Visual Features
​Automated Position Boxes: Upon entry, the script draws the position tool (Green/Red boxes) with an adjustable ratio (default 1:2), anchored exactly to the institutional zone for clear risk/reward visualization.
​Daily Liquidity Levels: Automatically plots PDH (Previous Day High) and PDL (Previous Day Low), allowing traders to identify if the 9:30 AM breakout aligns with previous day liquidity pools.
​Configuration Parameters
​NY Candle: 0930-0935 (Do not change for official session trading).
​R/R Ratio: Adjustable (Suggested 1:1 or 1:2 depending on the asset).
​Min SL Forex: 10.0 Pips.
​Min SL Indices/Gold: 1500 Ticks.
​Backtesting Instructions
​To obtain accurate profitability results in the Strategy Tester:
​Ensure your chart is set to New York Time Zone (UTC-4 or UTC-5).
​In the Properties tab, set "Order Size" to Percentage of Equity (1% or 2%).
​Use the 1-Minute timeframe for surgical precision regarding body closes.

## Source Code

````pine
//@version=5
strategy("Estrategia 9:30 AM - PRECISIÓN TOTAL", overlay=true, initial_capital=10000, process_orders_on_close=true)

// ==========================================
// CONFIGURACIÓN DE PARÁMETROS
// ==========================================
session_ref = input.session("0930-0935", "Vela Referencia (NY)", group="Horario")
tp_ratio    = input.float(2.0, "Ratio R/B", group="Riesgo")
min_sl_fx   = 10.0 
min_sl_idx  = 1500.0 

// Control de una sola operación
var int trades_count = 0
var bool trade_active = false
if ta.change(time("D", "America/New_York"))
    trades_count := 0
    trade_active := false

// ==========================================
// CAPTURA DE LA VELA INSTITUCIONAL
// ==========================================
var float hi_930 = na
var float lo_930 = na

if ta.change(time("D", "America/New_York"))
    hi_930 := na
    lo_930 := na

in_ref = time(timeframe.period, session_ref, "America/New_York")
if not na(in_ref)
    hi_930 := na(hi_930) ? high : math.max(hi_930, high)
    lo_930 := na(lo_930) ? low : math.min(lo_930, low)

// Dibujo de niveles (Líneas Azules)
plot(hi_930, "Zona Alta", color=color.blue, linewidth=2, style=plot.style_linebr)
plot(lo_930, "Zona Baja", color=color.blue, linewidth=2, style=plot.style_linebr)

// ==========================================
// LÓGICA DE RUPTURA POR CUERPO (1 MINUTO)
// ==========================================
is_forex = syminfo.type == "forex"
min_sl = is_forex ? (min_sl_fx * syminfo.mintick * 10) : (min_sl_idx * syminfo.mintick)
sl_dist = math.max(hi_930 - lo_930, min_sl)

// Condición de entrada: Solo si el cuerpo Cierra (close) fuera del rango
can_trade = time(timeframe.period, "0936-1550", "America/New_York") and trades_count == 0

long_body_break  = can_trade and close > hi_930
short_body_break = can_trade and close < lo_930

// --- EJECUCIÓN COMPRA ---
if long_body_break
    sl_p = hi_930 - sl_dist
    tp_p = hi_930 + (sl_dist * tp_ratio)
    
    strategy.entry("L", strategy.long, comment="ENTRY")
    
    // Cuadro visual pegado EXACTAMENTE a la zona
    box.new(bar_index, tp_p, bar_index + 40, hi_930, bgcolor=color.new(color.green, 80), border_color=color.green)
    box.new(bar_index, hi_930, bar_index + 40, sl_p, bgcolor=color.new(color.red, 80), border_color=color.red)
    
    strategy.exit("Exit L", "L", stop=sl_p, limit=tp_p)
    trades_count := 1

// --- EJECUCIÓN VENTA ---
if short_body_break
    sl_p = lo_930 + sl_dist
    tp_p = lo_930 - (sl_dist * tp_ratio)
    
    strategy.entry("S", strategy.short, comment="ENTRY")
    
    // Cuadro visual pegado EXACTAMENTE a la zona
    box.new(bar_index, lo_930, bar_index + 40, tp_p, bgcolor=color.new(color.green, 80), border_color=color.green)
    box.new(bar_index, sl_p, bar_index + 40, lo_930, bgcolor=color.new(color.red, 80), border_color=color.red)
    
    strategy.exit("Exit S", "S", stop=sl_p, limit=tp_p)
    trades_count := 1
````
