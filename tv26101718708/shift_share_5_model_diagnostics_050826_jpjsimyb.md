## Description

[b]Shift Share - 5 Model Diagnostics 050826[/b]
(updated version of **Shift Share - Full Diagnostics & R2 Public** indicator

[b]User Guide: Shift-Share 5 Model Diagnostics 050826
[/b] 
This indicator is a sophisticated regression-based tool designed to "clean" a stock's price action. It separates the raw return of a ticker into specific drivers: the Market, the Sector, their Interaction, and the stock’s own Unique (Idiosyncratic) strength.

[list=1]
[*] Key Concept: What are you looking at?
[*]
[/list]
The indicator plots cumulative returns broken down by source. Instead of just seeing "the stock is up 5%," this tool tells you: 
[list]
[*] The stock is up 5%, but 4% of that was just the S&P 500 rising, and only 1% was the company actually doing well.
[*] Market (Blue): Return driven by the broad index (e.g., SPY).
[*] Sector (Orange): Return driven by the specific industry (e.g., XLF), adjusted to remove market overlap.
[*] Interaction (Purple): Return generated by the synergy between the market and sector.
[*] Unique (Red): The "Alpha." This is the movement left over that belongs only to the stock.
[*] Stock Total (White): The actual cumulative return of the ticker.
[*]
[/list]
[list=2]
[*] Input Parameters
[/list]
Model Selection (model_type)

This determines how the math decomposes the returns.

[*]* Interaction (Default): The most complex model. It looks for Market, Sector, and the "Interaction" effect between them.
[*]* Simple Linear: Looks at Market and Sector individually without the interaction variable.
[*]* Market Only / Sector Only: Strips away everything except the chosen benchmark. Use this to see how much a stock is "tethered" to just one factor.
[*]* No Variable: Shows only the raw stock return vs. its residual.
[/list]

Benchmarks & Logic
[list]
[*] Sector ETF / Market Index: Enter the tickers you want to compare against (e.g., QQQ for tech, SPY for market).
[*] Rolling Window: The number of bars (default 60) used to calculate the correlation (Beta). A shorter window reacts faster; a longer window is more stable.
[/list]

[list=3]
[*] Reading the Diagnostic Table
[/list]

The table at the bottom of your chart provides the statistical "health check" of the stock.

R2 (R-Squared)
How much of the stock's move is explained by the Market/Sector. High R2 means the stock is a "slave" to the index. Low R2 means the stock moves on its own news.

Share %
The percentage of the total move attributed to that specific source.

Beta
The sensitivity. A Market Beta of 1.5 means for every 1% the market moves, this stock tends to move 1.5%.

T-Stat
CRITICAL: If the T-Stat is > 2.0 (highlights Green), the relationship is "Statistically Significant." If it’s low, the connection might just be random noise.

[list=4]
[*] Strategic Interpretation
[/list]

[list]
[*] *The "Pure Play" Signal: If the Unique (Red) line is trending higher while the Total (White) line is flat, the stock is showing hidden internal strength even if the price isn't moving yet.]
[*] The "Hollow" Rally: If the White line is rising but the Red line is falling, the stock is "weak" and is only being dragged up by a strong market. This is a high-risk long position.
[*] The Alpha Hunt: Professional traders look for stocks where the Unique component is the largest contributor to the total return, indicating a company with a specific catalyst independent of the macro economy.
[/list]

Note on Orthogonalization: This script uses "orthogonalized" returns. This means it mathematically strips the "Market influence" out of the "Sector return" before calculating. This prevents "double counting" and ensures the Sector Shift is truly about the industry, not just the market rising.

## Source Code

````pine
// © Stephen_F
//@version=5
indicator("Shift Share - 5 Model Diagnostics 050826", overlay=false, max_lines_count=500)

// ---------- Inputs ----------
model_type = input.string("Interaction", "Select Model", options=["Simple Linear", "Interaction", "Market Only", "Sector Only", "No Variable"])
sector_id  = input.symbol("XLF", "Sector ETF")
market_id  = input.symbol("SPY", "Market Index")
win        = input.int(60, "Rolling Window", minval=20)

col_mkt    = input.color(#2196f3, "Market Color")
col_sec    = input.color(#ff9800, "Sector Color")
col_int    = input.color(#9c27b0, "Interaction Color")
col_idio   = input.color(#f44336, "Unique Color")
col_total  = input.color(color.white, "Stock Total Color")

// ---------- Helper Functions ----------
cov(x, y, length) =>
    ta.sma(x * y, length) - ta.sma(x, length) * ta.sma(y, length)

// ---------- Global TA Buffers ----------
r_s = nz(math.log(close / close[1]), 0.0)
m_close = request.security(market_id, timeframe.period, close)
e_close = request.security(sector_id, timeframe.period, close)

r_m = nz(math.log(m_close / m_close[1]), 0.0)
r_e = nz(math.log(e_close / e_close[1]), 0.0)
r_i = r_m * r_e

// ---------- Baseline Variances & Orthogonalization ----------
v_m = ta.variance(r_m, win)
b_em_raw = v_m != 0 ? cov(r_e, r_m, win) / v_m : 0.0
r_ec = r_e - (b_em_raw * r_m)
v_ec = ta.variance(r_ec, win)

b_im_raw = v_m != 0 ? cov(r_i, r_m, win) / v_m : 0.0
b_ie_raw = v_ec != 0 ? cov(r_i, r_ec, win) / v_ec : 0.0
r_ic = r_i - (b_im_raw * r_m) - (b_ie_raw * r_ec)
v_ic = ta.variance(r_ic, win)

// ---------- Expanded Model Selection Logic ----------
use_mkt = (model_type == "Simple Linear" or model_type == "Interaction" or model_type == "Market Only")
use_sec = (model_type == "Simple Linear" or model_type == "Interaction" or model_type == "Sector Only")
use_int = (model_type == "Interaction")

b_m = use_mkt and v_m != 0 ? cov(r_s, r_m, win) / v_m : 0.0
b_e = use_sec and v_ec != 0 ? cov(r_s, r_ec, win) / v_ec : 0.0
b_i = use_int and v_ic != 0 ? cov(r_s, r_ic, win) / v_ic : 0.0

// ---------- Component Returns ----------
c_m = b_m * r_m
c_e = b_e * r_ec
c_i = b_i * r_ic
res = r_s - (c_m + c_e + c_i)

// ---------- Statistics ----------
v_s = ta.variance(r_s, win)
r2 = v_s > 0 ? 1.0 - (ta.variance(res, win) / v_s) : 0.0

int k = 2
if model_type == "Interaction"
    k := 4
else if model_type == "Simple Linear"
    k := 3
else if model_type == "No Variable"
    k := 1

rss = math.sum(math.pow(res, 2), win)
sig = (win - k) > 0 ? rss / (win - k) : 0.0

t_m = (use_mkt and sig > 0 and v_m > 0) ? b_m / math.sqrt(sig / (v_m * (win - 1))) : 0.0
t_e = (use_sec and sig > 0 and v_ec > 0) ? b_e / math.sqrt(sig / (v_ec * (win - 1))) : 0.0
t_i = (use_int and sig > 0 and v_ic > 0) ? b_i / math.sqrt(sig / (v_ic * (win - 1))) : 0.0

// ---------- Cumulative Series ----------
cum_s = ta.cum(r_s)
cum_m = ta.cum(c_m)
cum_e = ta.cum(c_e)
cum_i = ta.cum(c_i)
cum_r = ta.cum(res)

// ---------- Unified Table ----------
// Moved back to bottom_center. Frame and border settings remain for visibility.
var table tbl = table.new(position.bottom_center, 6, 6, bgcolor=color.new(#1e222d, 5), frame_width=2, frame_color=color.gray, border_width=1, border_color=color.gray)

if barstate.islast
    table.clear(tbl, 0, 0, 5, 5)
    n = math.abs(cum_m) + math.abs(cum_e) + math.abs(cum_i) + math.abs(cum_r)
    h_bg = color.new(color.gray, 50)

    // Header Row
    table.cell(tbl, 0, 0, "Model: " + model_type + " | R2: " + str.tostring(r2, "#.###"), bgcolor=h_bg, text_color=color.white)
    table.merge_cells(tbl, 0, 0, 5, 0)

    // Column Labels
    table.cell(tbl, 0, 1, "Source", bgcolor=h_bg, text_color=color.white)
    table.cell(tbl, 1, 1, "Abs Return", bgcolor=h_bg, text_color=color.white)
    table.cell(tbl, 2, 1, "Share %", bgcolor=h_bg, text_color=color.white)
    table.cell(tbl, 3, 1, "Beta", bgcolor=h_bg, text_color=color.white)
    table.cell(tbl, 4, 1, "T-Stat", bgcolor=h_bg, text_color=color.white)
    table.cell(tbl, 5, 1, "Stock Total", bgcolor=h_bg, text_color=color.white)

    // Market Row
    table.cell(tbl, 0, 2, "Market", text_color=col_mkt)
    table.cell(tbl, 1, 2, use_mkt ? str.tostring(math.exp(cum_m) - 1, format.percent) : "---", text_color=color.white)
    table.cell(tbl, 2, 2, use_mkt ? str.tostring(cum_m / n, format.percent) : "---", text_color=color.white)
    table.cell(tbl, 3, 2, use_mkt ? str.tostring(b_m, "#.##") : "---", text_color=color.white)
    table.cell(tbl, 4, 2, use_mkt ? str.tostring(t_m, "#.##") : "---", text_color=math.abs(t_m) >= 2 ? color.lime : color.gray)

    // Sector Row
    table.cell(tbl, 0, 3, "Sector", text_color=col_sec)
    table.cell(tbl, 1, 3, use_sec ? str.tostring(math.exp(cum_e) - 1, format.percent) : "---", text_color=color.white)
    table.cell(tbl, 2, 3, use_sec ? str.tostring(cum_e / n, format.percent) : "---", text_color=color.white)
    table.cell(tbl, 3, 3, use_sec ? str.tostring(b_e, "#.##") : "---", text_color=color.white)
    table.cell(tbl, 4, 3, use_sec ? str.tostring(t_e, "#.##") : "---", text_color=math.abs(t_e) >= 2 ? color.lime : color.gray)

    // Interaction Row
    table.cell(tbl, 0, 4, "Interact", text_color=col_int)
    table.cell(tbl, 1, 4, use_int ? str.tostring(math.exp(cum_i) - 1, format.percent) : "---", text_color=color.white)
    table.cell(tbl, 2, 4, use_int ? str.tostring(cum_i / n, format.percent) : "---", text_color=color.white)
    table.cell(tbl, 3, 4, use_int ? str.tostring(b_i, "#.##") : "---", text_color=color.white)
    table.cell(tbl, 4, 4, use_int ? str.tostring(t_i, "#.##") : "---", text_color=math.abs(t_i) >= 2 ? color.lime : color.gray)

    // Unique Row
    table.cell(tbl, 0, 5, "Unique", text_color=col_idio)
    table.cell(tbl, 1, 5, str.tostring(math.exp(cum_r) - 1, format.percent), text_color=color.white)
    table.cell(tbl, 2, 5, str.tostring(cum_r / n, format.percent), text_color=color.white)

    // Summary Result
    table.cell(tbl, 5, 2, str.tostring(math.exp(cum_s) - 1, format.percent), bgcolor=color.new(color.gray, 80), text_color=col_total)
    table.merge_cells(tbl, 5, 2, 5, 5)

// ---------- Plots ----------
plot(cum_s, "Total", color=col_total, linewidth=2)
plot(use_mkt ? cum_m : na, "Mkt", color=col_mkt)
plot(use_sec ? cum_e : na, "Sec", color=col_sec)
plot(use_int ? cum_i : na, "Int", color=col_int)
plot(cum_r, "Uniq", color=col_idio)
````
