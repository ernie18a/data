## Description

Trend State Signals is an adaptive trend-state indicator designed to identify changes in market direction while filtering out insignificant price fluctuations.
Instead of reacting to every short-term price movement, the indicator updates its state only when price travels far enough to exceed a dynamically calculated movement threshold.
The result is a step-like trend line that remains stable during periods of market noise and changes direction only after a meaningful price movement has occurred.
Unlike many traditional trend-following indicators that continuously track price, Trend State Signals intentionally ignores minor fluctuations, providing a cleaner and more objective view of whether the market is currently in a bullish or bearish state.

⚙️ How It Works
The indicator estimates the current level of market activity by measuring the average absolute price movement over a user-defined lookback period.
Unlike many similar indicators, ATR is not used. Instead, the calculation follows these steps:
✔️ The absolute price change is calculated for every bar.
✔️ These values are smoothed using a Running Moving Average (RMA).
✔️ The smoothed result becomes a dynamic estimate of current market volatility.
✔️ This value is multiplied by the Range Multiplier, defining the minimum distance price must travel before the filter is allowed to update.
This adaptive threshold determines how far price must move before the internal filter changes its position.
If price remains inside the calculated range, the filter stays unchanged.
Once price exceeds that range, the filter shifts toward price while maintaining the adaptive distance.
Because the filter only updates after meaningful price expansion, the indicator naturally filters out a large amount of random market noise and significantly reduces unnecessary trend changes.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
📊 Trend State Detection
The market state is determined solely by the direction of the adaptive filter.
🟢 Filter moving upward → Bullish
🔴 Filter moving downward → Bearish
⚪ Filter unchanged → Previous market state is maintained
Signals are generated only when the filter changes direction.
Rather than producing continuous buy or sell signals on every candle, the indicator highlights transitions between bullish and bearish market environments.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
✅ Signal Confirmation
The indicator includes an optional signal confirmation mode.
When Confirm Signals On Bar Close is enabled, a new trend state is confirmed only after the current candle has closed.
When disabled, trend changes can appear immediately while the current bar is still forming.
This allows traders to choose between earlier signals or additional confirmation.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
🎛 Settings
Sensitivity Length
Defines the lookback period used to calculate the average market movement.
• Lower values make the indicator more responsive.
• Higher values produce a smoother adaptive filter.
Range Multiplier
Controls how much price movement is required before the filter changes its state.
Higher values
✔️ Fewer trend changes
✔️ Stronger noise filtering
✔️ Smoother trend line
Lower values
✔️ Earlier reactions
✔️ More frequent state changes
✔️ Higher sensitivity

🎨 Visual Features
The indicator includes several independent visualization options, each of which can be enabled or disabled separately.
✔️ Adaptive Trend Line
✔️ Glow Effect
✔️ Gradient Ribbon Between Price and Filter
✔️ Bullish / Bearish Transition Labels
✔️ Optional Candle Coloring

🔔 Alerts
Two alert conditions are available.
🟢 Bullish Trend State
🔴 Bearish Trend State
Alerts are triggered only when a new trend state is confirmed according to the selected confirmation mode.
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
💡 Typical Use
Trend State Signals is primarily designed as a market state filter rather than a complete trading system.
It can be used to:
✔️ Identify the dominant market direction
✔️ Filter signals generated by other trading strategies
✔️ Trade only in the direction of the prevailing trend
✔️ Reduce trades caused by short-term market noise
Like any trend-following methodology, the indicator confirms trend changes only after the market has moved a sufficient distance. As a result, signals may appear after the initial turning point. This is an intentional design choice that helps reduce the impact of random price fluctuations while improving trend stability.

## Source Code

````pine
// This Source Code Form is subject to the terms of the Mozilla Public License 2.0.
// https://mozilla.org/MPL/2.0/
//
// Trend State Signals
// Developed by Market Structure Lab
//
// An open-source indicator for identifying bullish
// and bearish market trend states.
//
// © Market Structure Lab

//@version=6
indicator(
     title = "Trend State Signals [Market Structure Lab]",
     shorttitle = "TSS",
     overlay = true
)

//──────────────────────────────────────────────────────────────
// SETTINGS
//──────────────────────────────────────────────────────────────

groupCalculation = "Calculation"
groupVisuals     = "Visuals"

source = input.source(
     close,
     "Source",
     group = groupCalculation
)

length = input.int(
     20,
     "Sensitivity Length",
     minval = 1,
     tooltip = "Controls the period used to estimate normal price movement.",
     group = groupCalculation
)

multiplier = input.float(
     3.5,
     "Range Multiplier",
     minval = 0.1,
     step = 0.1,
     tooltip = "Higher values produce fewer trend changes. Lower values make the indicator more responsive.",
     group = groupCalculation
)

confirmOnClose = input.bool(
     true,
     "Confirm Signals On Bar Close",
     tooltip = "Confirms a new signal only after the current candle closes.",
     group = groupCalculation
)

//──────────────────────────────────────────────────────────────
// VISUAL SETTINGS
//──────────────────────────────────────────────────────────────

bullColor = input.color(
     #00FFAA,
     "Bullish Color",
     group = groupVisuals
)

bearColor = input.color(
     #FF0000,
     "Bearish Color",
     group = groupVisuals
)

showGlow = input.bool(
     true,
     "Show Line Glow",
     group = groupVisuals
)

showRibbon = input.bool(
     true,
     "Show Gradient Ribbon",
     group = groupVisuals
)

showLabels = input.bool(
     true,
     "Show Bullish/Bearish Labels",
     group = groupVisuals
)

labelDistance = input.float(
     1.0,
     "Label Vertical Distance",
     minval = 0.0,
     maxval = 5.0,
     step = 0.1,
     tooltip = "Controls the vertical distance between signal labels and the trend line.",
     group = groupVisuals
)

paintCandles = input.bool(
     false,
     "Color Candles",
     group = groupVisuals
)

//──────────────────────────────────────────────────────────────
// ADAPTIVE RANGE
//──────────────────────────────────────────────────────────────

// Absolute price movement from one bar to the next.
priceMovement = math.abs(ta.change(source))

// Smoothed estimate of current market noise.
smoothedMovement = ta.rma(priceMovement, length)

// Dynamic distance required for the filter to move.
adaptiveRange = smoothedMovement * multiplier

//──────────────────────────────────────────────────────────────
// STEP FILTER
//──────────────────────────────────────────────────────────────

var float rangeFilter = na

previousFilter = nz(rangeFilter[1], source)

upperTrigger = previousFilter + adaptiveRange
lowerTrigger = previousFilter - adaptiveRange

if source > upperTrigger
    rangeFilter := source - adaptiveRange
else if source < lowerTrigger
    rangeFilter := source + adaptiveRange
else
    rangeFilter := previousFilter

//──────────────────────────────────────────────────────────────
// TREND STATE
//──────────────────────────────────────────────────────────────

var int trend = 0

if rangeFilter > rangeFilter[1]
    trend := 1
else if rangeFilter < rangeFilter[1]
    trend := -1
else
    trend := nz(trend[1], 0)

bullishState = trend == 1
bearishState = trend == -1

bullishChange = bullishState and nz(trend[1], 0) != 1
bearishChange = bearishState and nz(trend[1], 0) != -1

signalConfirmed = not confirmOnClose or barstate.isconfirmed

bullishSignal = bullishChange and signalConfirmed
bearishSignal = bearishChange and signalConfirmed

//──────────────────────────────────────────────────────────────
// COLORS
//──────────────────────────────────────────────────────────────

trendColor =
     bullishState ? bullColor :
     bearishState ? bearColor :
     color.gray

//──────────────────────────────────────────────────────────────
// VISUALIZATION
//──────────────────────────────────────────────────────────────

// Soft glow behind the main trend line.
plot(
     showGlow ? rangeFilter : na,
     title = "Trend Line Glow",
     color = color.new(trendColor, 82),
     linewidth = 7,
     editable = false
)

// Main step-filter line.
filterPlot = plot(
     rangeFilter,
     title = "Trend State Line",
     color = trendColor,
     linewidth = 3
)

// Hidden price midpoint used as the second edge of the ribbon.
pricePlot = plot(
     hl2,
     title = "Price Midpoint",
     display = display.none,
     editable = false
)

// Gradient between the filter and the middle of the candle.
ribbonColor = showRibbon ? color.new(trendColor, 20) : na

fill(
     filterPlot,
     pricePlot,
     hl2,
     rangeFilter,
     na,
     ribbonColor,
     title = "Trend State Ribbon"
)

//──────────────────────────────────────────────────────────────
// SIGNAL LABEL POSITIONS
//──────────────────────────────────────────────────────────────

// Bullish labels appear below the trend line.
bullishLabelPosition =
     rangeFilter - adaptiveRange * labelDistance

// Bearish labels appear above the trend line.
bearishLabelPosition =
     rangeFilter + adaptiveRange * labelDistance

//──────────────────────────────────────────────────────────────
// SIGNAL LABELS
//──────────────────────────────────────────────────────────────

plotshape(
     showLabels and bullishSignal ? bullishLabelPosition : na,
     title = "Bullish Signal",
     style = shape.labelup,
     location = location.absolute,
     color = bullColor,
     text = "BULLISH",
     textcolor = color.black,
     size = size.tiny,
     force_overlay = true
)

plotshape(
     showLabels and bearishSignal ? bearishLabelPosition : na,
     title = "Bearish Signal",
     style = shape.labeldown,
     location = location.absolute,
     color = bearColor,
     text = "BEARISH",
     textcolor = color.white,
     size = size.tiny,
     force_overlay = true
)

// Optional candle coloring.
barcolor(
     paintCandles ? trendColor : na
)

//──────────────────────────────────────────────────────────────
// ALERTS
//──────────────────────────────────────────────────────────────

alertcondition(
     bullishSignal,
     title = "Trend State Bullish",
     message = "Trend State Signals: bullish state confirmed on {{exchange}}:{{ticker}} at {{close}}"
)

alertcondition(
     bearishSignal,
     title = "Trend State Bearish",
     message = "Trend State Signals: bearish state confirmed on {{exchange}}:{{ticker}} at {{close}}"
)

//──────────────────────────────────────────────────────────────
// DEVELOPED BY MARKET STRUCTURE LAB
//──────────────────────────────────────────────────────────────
````
