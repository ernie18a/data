## Description

Plots five Exponential Moving Averages used in multi-timeframe trend analysis and stage analysis methodology:

EMA 10  (Green) — Short-term trend momentum
EMA 21  (Navy) — Pullback support / swing trade baseline
EMA 30  (Orange) — Stage analysis reference (Weinstein methodology)
EMA 40  (Red) — Uptrend defence line; loss signals weakening trend
EMA 63  (Maroon) — Downtrend defence line; ~3-month average

Usage:
   • Price above all EMAs in correct order (10 > 21 > 30 > 40 > 63) signals a strong uptrend.
   • Price crossing below EMA 40 or 63 is an early warning of trend reversal.
   • Pullbacks to EMA 21 in an uptrend are common buy-the-dip opportunities.

## Source Code

````pine
// This Pine Script® code is subject to the terms of the Mozilla Public License 2.0 at https://mozilla.org/MPL/2.0/
// © vodapn
//@version=6

indicator(
 title       = "EMA 10/21/30/40/63",
  overlay     = true
 )

ShortTermTrend       = ta.ema(close, 10)
PullbackSupport      = ta.ema(close, 21)
StageAnalysis        = ta.ema(close, 30)
UptrendDefenceLine   = ta.ema(close, 40)
DowntrendDefenceLine = ta.ema(close, 63)

plot(ShortTermTrend,       color = color.green,    title = "EMA 10  — Short-Term Trend")
plot(PullbackSupport,      color = color.navy, title = "EMA 21  — Pullback Support")
plot(StageAnalysis,        color = color.orange,  title = "EMA 30  — Stage Analysis")
plot(UptrendDefenceLine,   color = color.red,   title = "EMA 40  — Uptrend Defence")
plot(DowntrendDefenceLine, color = color.maroon, title = "EMA 63  — Downtrend Defence")
plot(close)
````
