Calculation: symbol RSI = RSI(close of listed symbol on T1, RSI length)
Calculation: RSI divergence = (newest RSI pivot low, confirmed within max age bars, has lower T1 low and higher symbol RSI than an earlier RSI pivot low) OR (newest RSI pivot high, confirmed within max age bars, has higher T1 high and lower symbol RSI than an earlier RSI pivot high), where the earlier pivot is the immediately preceding pivot if strict mode, otherwise any pivot whose bar is within search range bars before the newest pivot's confirmation; RSI pivot low = bar whose symbol RSI is the lowest over pivot lookback bars on each side of it, confirmed pivot lookback bars later; RSI pivot high = same with highest; T1 low/high = low/high of the symbol on T1 at the pivot bar
Short: symbol RSI ≥ overbought level AND symbol RSI is within the top max entries per side of all listed symbols ranked by symbol RSI descending
Long: symbol RSI ≤ oversold level AND symbol RSI is within the top max entries per side of listed symbols with symbol RSI ≤ oversold level ranked by symbol RSI descending
Short: symbol RSI ≥ overbought level AND no OB/OS alert on symbol since last bar with oversold level + hysteresis < symbol RSI < overbought level − hysteresis (or since first bar if none) AND bars since last OB/OS alert on symbol ≥ cooldown bars
Long: symbol RSI ≤ oversold level AND no OB/OS alert on symbol since last bar with oversold level + hysteresis < symbol RSI < overbought level − hysteresis (or since first bar if none) AND bars since last OB/OS alert on symbol ≥ cooldown bars
Short: symbol RSI ≥ overbought level AND RSI divergence AND no OB/OS + divergence alert on symbol since last bar with oversold level + hysteresis < symbol RSI < overbought level − hysteresis and without RSI divergence (or since first bar if none) AND bars since last OB/OS + divergence alert on symbol ≥ cooldown bars
Long: symbol RSI ≤ oversold level AND RSI divergence AND no OB/OS + divergence alert on symbol since last bar with oversold level + hysteresis < symbol RSI < overbought level − hysteresis and without RSI divergence (or since first bar if none) AND bars since last OB/OS + divergence alert on symbol ≥ cooldown bars
