Calculation: Percent above EMA(series, length) = if EMA(series, length) ≠ 0 then (series close − EMA(series, length)) / EMA(series, length) × 100 else 0
Calculation: Range percentage = if chart close ≠ 0 then (chart high − chart low) / chart close × 100 else 0
Calculation: ATR percentage = if chart close ≠ 0 then ATR(ATR length) / chart close × 100 else 0
Calculation: Consecutive(condition, bars) = condition is true on the current chart bar and the preceding bars, for the specified number of consecutive chart bars
Long: (start-date filter disabled OR chart time ≥ start date) AND position is flat AND (trend exit disabled OR chart close ≥ EMA(chart close, slow EMA length) × (1 − trend-exit buffer percentage / 100)) AND Consecutive((macro exit disabled OR dollar-index proxy close ≤ EMA(dollar-index proxy close, dollar-index EMA length) OR Percent above EMA(dollar-index proxy close, dollar-index EMA length) ≤ dollar-index maximum above-EMA percentage) AND (macro exit disabled OR 10-year Treasury yield proxy close ≤ EMA(10-year Treasury yield proxy close, yield EMA length) OR Percent above EMA(10-year Treasury yield proxy close, yield EMA length) ≤ yield maximum above-EMA percentage), macro calm bars) AND (flush exit disabled OR no flush shock has occurred, or the most recent flush shock was more than the flush cooldown bars ago, OR (chart close > EMA(chart close, recovery EMA length) AND Consecutive(Range percentage ≤ ATR percentage × ATR shock multiplier, volatility calm bars)))
Exit: Long, (start-date filter enabled AND chart time ≥ start date) AND ((trend exit enabled AND chart close < EMA(chart close, slow EMA length) × (1 − trend-exit buffer percentage / 100)) OR Consecutive((macro exit enabled AND dollar-index proxy close > EMA(dollar-index proxy close, dollar-index EMA length) AND Percent above EMA(dollar-index proxy close, dollar-index EMA length) > dollar-index maximum above-EMA percentage AND dollar-index proxy close > highest dollar-index proxy high over the preceding breakout-lookback bars) OR (macro exit enabled AND 10-year Treasury yield proxy close > EMA(10-year Treasury yield proxy close, yield EMA length) AND Percent above EMA(10-year Treasury yield proxy close, yield EMA length) > yield maximum above-EMA percentage AND 10-year Treasury yield proxy close > highest yield proxy high over the preceding yield breakout-lookback bars), stress bars) OR (flush exit enabled AND ((if prior chart close ≠ 0 then (chart close / prior chart close − 1) × 100 else 0) ≤ −one-bar loss threshold percentage OR (if chart close two bars ago ≠ 0 then (chart close / chart close two bars ago − 1) × 100 else 0) ≤ −two-bar loss threshold percentage OR (Range percentage > ATR percentage × ATR shock multiplier AND chart close < chart open)))
