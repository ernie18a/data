Calculation: Gap size percentage = abs(first chart-bar open of a T1 period - preceding chart-bar close) / preceding chart-bar close * 100
Calculation: Gap fill percentage = for a gap up, (gap-start open - current low) / gap range * 100; for a gap down, (current high - gap-start open) / gap range * 100
Calculation: Active gap = latest gap at a T1 boundary with gap size percentage >= minimum gap percentage and gap fill percentage < gap deactivation fill percentage; a later gap below minimum clears it; gap boundaries are the gap-start open and preceding chart-bar close
Calculation: Partial fill recorded = active gap fill percentage has reached the partial-fill percentage on the current or an earlier bar since gap formation
Calculation: Outside-bar body percentage = if high > low, abs(close - open) / (high - low) * 100; otherwise 0
Calculation: Bullish common filters = (minimum-volume filter disabled OR volume >= minimum volume) AND (relative-volume filter disabled OR Relative Volume(volume, relative-volume lookback) >= relative-volume threshold) AND (ATR-range filter disabled OR high - low >= ATR(ATR length) * minimum bar-range ATR multiple) AND (minimum-price filter disabled OR close >= minimum price) AND (session filter disabled OR bar is within session window) AND (EMA trend filter disabled OR close > EMA(close, EMA length)) AND (index-alignment filter disabled OR selected index close > EMA(selected index close, EMA length))
Calculation: Bearish common filters = (minimum-volume filter disabled OR volume >= minimum volume) AND (relative-volume filter disabled OR Relative Volume(volume, relative-volume lookback) >= relative-volume threshold) AND (ATR-range filter disabled OR high - low >= ATR(ATR length) * minimum bar-range ATR multiple) AND (minimum-price filter disabled OR close >= minimum price) AND (session filter disabled OR bar is within session window) AND (EMA trend filter disabled OR close < EMA(close, EMA length)) AND (index-alignment filter disabled OR selected index close < EMA(selected index close, EMA length))
