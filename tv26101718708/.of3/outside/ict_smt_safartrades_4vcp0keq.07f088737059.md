Calculation: Correlated swing-high value = at a traded-instrument swing-high bar, use the correlated instrument's high when the source uses wicks and inversion is off, negative low when the source uses wicks and inversion is on, close when the source uses closes and inversion is off, or negative close when the source uses closes and inversion is on.
Calculation: Correlated swing-low value = at a traded-instrument swing-low bar, use the correlated instrument's low when the source uses wicks and inversion is off, negative high when the source uses wicks and inversion is on, close when the source uses closes and inversion is off, or negative close when the source uses closes and inversion is on.
Calculation: SMT divergence = (current traded swing price > previous traded swing price AND current correlated swing value <= previous correlated swing value) OR (current traded swing price < previous traded swing price AND current correlated swing value >= previous correlated swing value) OR (current traded swing price = previous traded swing price AND current correlated swing value != previous correlated swing value).
