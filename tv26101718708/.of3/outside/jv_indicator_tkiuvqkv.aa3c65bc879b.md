Calculation: Matching higher-timeframe FVG zone = latest detected same-direction FVG on T1 if available, otherwise T2, otherwise T3
Calculation: Recent bullish liquidity sweep = a confirmed pivot low, using the swing-pivot span, below the preceding confirmed pivot low within the sweep-age parameter bars
Calculation: Recent bearish liquidity sweep = a confirmed pivot high, using the swing-pivot span, above the preceding confirmed pivot high within the sweep-age parameter bars
Calculation: Liquidity pattern = count of consecutive higher highs over the liquidity lookback parameter >= the liquidity-count threshold OR count of consecutive lower lows over that lookback >= the liquidity-count threshold
Calculation: Session gate = during the New York-local core session OR during the New York-local extended session AND ATR(volatility ATR length) > SMA(ATR(volatility ATR length), ATR-average window) * volatility multiplier
Calculation: ES SMT confirmation = ES SMT filter disabled OR ES futures close within the proximity-percent parameter of the prior T1 high or low of ES futures
Calculation: Impulsive non-doji candle = high - low > ATR(impulse ATR period) * impulse ATR multiplier AND abs(close - open) > (high - low) * impulse body fraction
Calculation: Directional score = high score weight for each true condition of close within the matching higher-timeframe FVG zone and recent same-direction liquidity sweep, plus low score weight for each true condition of session gate, ES SMT confirmation, liquidity pattern, and impulsive non-doji candle
Calculation: Directional grade = S if directional score >= S-grade cutoff, else A if directional score >= A-grade cutoff, else B if directional score >= B-grade cutoff, else C
Long: close > top of a bearish chart-timeframe FVG formed within the FVG-age parameter bars AND impulsive non-doji candle AND recent bullish liquidity sweep AND session gate AND bullish grade meets the minimum-grade setting AND no long signal has fired since the running leg high last advanced
Short: close < bottom of a bullish chart-timeframe FVG formed within the FVG-age parameter bars AND impulsive non-doji candle AND recent bearish liquidity sweep AND session gate AND bearish grade meets the minimum-grade setting AND no short signal has fired since the running leg low last declined
