Calculation: Session VWAP = volume-weighted average of typical price ((base high + base low + base close) / 3), reset at each T1 boundary
Calculation: Opening range boundaries = highest base high and lowest base low over the first max(1, ceiling(P1 / chart-bar duration in minutes)) chart bars after each T1 boundary
Calculation: VWAP distance filter = absolute difference between base close and session VWAP > base close × P7 / 100
Option: buy call, base close > session VWAP AND MACD(base close, P2, P3, P4) line > signal line AND (inverse confirmation disabled OR inverse close < inverse open OR inverse close < prior inverse close) AND VWAP distance filter
Option: buy put, base close < session VWAP AND MACD(base close, P2, P3, P4) line < signal line AND (inverse confirmation disabled OR inverse close > inverse open OR inverse close > prior inverse close) AND VWAP distance filter
