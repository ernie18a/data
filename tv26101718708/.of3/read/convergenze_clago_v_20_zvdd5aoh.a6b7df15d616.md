Calculation: CVD = cumulative chart-bar delta, where delta = volume × (close − low − (high − close)) / (high − low) when high > low, otherwise 0; reset continuously or at each T2 or T3 boundary according to a reset parameter, including the reset bar's delta.
Calculation: Wave = (r4 + r3 × L4/L3 + r2 × L4/L2 + r1 × L4/L1) / 4 × volume factor, where ri = 0 if MA(selected price from T1, Li) = 0, otherwise scale × (MA(selected price from T1, L0) − MA(selected price from T1, Li)) / MA(selected price from T1, Li), for i = 1, 2, 3, 4; L0 < L1 < L2 < L3 < L4; MA is the selected RMA, EMA, or SMA. Each T1 price is requested with lookahead off; the MAs run on chart bars over that series, using the still-forming T1 value live and the last completed T1 value historically. The volume factor is a parameterized multiplier when volume weighting is enabled and chart-bar volume > SMA(chart-bar volume, volume lookback) × volume threshold multiplier, otherwise 1.
Calculation: Wave signal = DEMA(Wave, shortest signal lookback) when ADX(ADX lookback, used for both DMI and ADX smoothing) > high ADX threshold; otherwise DEMA(Wave, middle signal lookback) when ADX > trend ADX threshold; otherwise DEMA(Wave, longest signal lookback), with shortest < middle < longest signal lookbacks.
Long: (EMA(selected EMA source, shortest EMA lookback) > EMA(selected EMA source, middle EMA lookback) > EMA(selected EMA source, longest EMA lookback) AND CVD >= EMA(CVD, CVD signal lookback) AND Wave > Wave signal) OR (ADX(ADX lookback) > trend ADX threshold AND (Wave crosses above 0 OR (Wave > 0 AND EMA(Wave − Wave[1], reentry velocity lookback) > 0 AND EMA(Wave − Wave[1], reentry velocity lookback)[1] <= 0)))
Short: (EMA(selected EMA source, shortest EMA lookback) < EMA(selected EMA source, middle EMA lookback) < EMA(selected EMA source, longest EMA lookback) AND CVD < EMA(CVD, CVD signal lookback) AND Wave < Wave signal) OR (ADX(ADX lookback) > trend ADX threshold AND (Wave crosses below 0 OR (Wave < 0 AND EMA(Wave − Wave[1], reentry velocity lookback) < 0 AND EMA(Wave − Wave[1], reentry velocity lookback)[1] >= 0)))
Exit: long, NOT (EMA(selected EMA source, shortest EMA lookback) > EMA(selected EMA source, middle EMA lookback) > EMA(selected EMA source, longest EMA lookback)) OR Wave <= Wave signal OR (PivotHigh(Wave, peak/trough pivot-left lookback, peak/trough pivot-right lookback) exists AND PivotHigh > minimum amplitude AND (ADX peak filter is disabled OR ADX(ADX lookback) > trend ADX threshold) AND no prior qualifying peak exists or at least peak/trough cooldown bars have elapsed since the last qualifying peak).
Exit: short, NOT (EMA(selected EMA source, shortest EMA lookback) < EMA(selected EMA source, middle EMA lookback) < EMA(selected EMA source, longest EMA lookback)) OR Wave >= Wave signal OR (PivotLow(Wave, peak/trough pivot-left lookback, peak/trough pivot-right lookback) exists AND PivotLow < −minimum amplitude AND (ADX peak filter is disabled OR ADX(ADX lookback) > trend ADX threshold) AND no prior qualifying trough exists or at least peak/trough cooldown bars have elapsed since the last qualifying trough).
