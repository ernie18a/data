Calculation: Candle range = max(high - low, minimum price increment)
Calculation: Close location = (close - low) / candle range
Calculation: Body share = abs(close - open) / candle range
Calculation: Upper wick share = (high - max(open, close)) / candle range
Calculation: Lower wick share = (min(open, close) - low) / candle range
Calculation: Adjusted ATR = max(ATR(ATR lookback) if available, otherwise high - low; minimum price increment)
Calculation: Shelf half-width = max(Adjusted ATR * shelf-width ATR parameter, minimum price increment)
Calculation: Volume score = clamp(volume-score baseline + (volume ratio - normal-volume ratio) * volume-score sensitivity, 0, 100), where volume ratio = volume / max(SMA(volume, volume-baseline lookback) if available, otherwise volume; one volume unit) when volume > 0, otherwise normal-volume ratio
Calculation: Directional room score(side) = clamp(abs(target - close) / Adjusted ATR / target-room ATR multiple * 100, 0, 100), where for long target is Highest(high[1], room lookback) if it exceeds close, otherwise close + Adjusted ATR * target-room ATR multiple; for short target is Lowest(low[1], room lookback) if it is below close, otherwise close - Adjusted ATR * target-room ATR multiple
Calculation: Failure score(side, shelf, half-width) = clamp(depth weight * clamp(depth / max(2 * half-width, minimum price increment) * 100, 0, 100) + close weight * clamp(close-score baseline + signed close distance / Adjusted ATR * close-distance scale + close bonus when close location meets the side's score-bonus threshold, 0, 100) + wick weight * clamp(rejection-side wick share * wick scale, 0, 100) + volume weight * volume score + room weight * Directional room score(side) + follow weight * clamp(favorable close location * follow-location scale + body share * follow-body scale + follow bonus when close moves in the side's direction from the prior bar, 0, 100), 0, 100); for long, depth = shelf + half-width - low, signed close distance = close - shelf, wick share = lower wick share, and favorable close location = close location; for short, depth = high - (shelf - half-width), signed close distance = shelf - close, wick share = upper wick share, and favorable close location = 1 - close location; the component weights and scales are shared by both sides
Calculation: Active broken shelf = latest qualifying swing-high break for long or swing-low break for short; an opposite-side break replaces it, a same-side break does not replace it while active, and it is cleared on a bar allowed by the close-confirmation setting after a long shelf closes below shelf - current half-width, a short shelf closes above shelf + current half-width, or elapsed bars exceed the retest-window parameter; it is eligible for retests only on bars 1 through the retest window after its break
Long: The close-confirmation setting permits evaluation AND close > latest confirmed Pivot high(high, swing-left bars, swing-right bars) + Adjusted ATR * sensitivity-selected break-buffer multiplier AND close location >= long shelf-break threshold AND no active long broken shelf
Short: The close-confirmation setting permits evaluation AND close < latest confirmed Pivot low(low, swing-left bars, swing-right bars) - Adjusted ATR * sensitivity-selected break-buffer multiplier AND close location <= short shelf-break threshold AND no active short broken shelf
Long: The close-confirmation setting permits evaluation AND an active long broken shelf from an earlier bar is within its retest window AND low <= shelf + current half-width AND close > shelf + confirmation-mode ATR rejection offset AND close location >= long rejection threshold AND lower wick share >= sensitivity-selected minimum wick share AND Failure score(long, shelf, current half-width) >= minimum failure-score parameter
Short: The close-confirmation setting permits evaluation AND an active short broken shelf from an earlier bar is within its retest window AND high >= shelf - current half-width AND close < shelf - confirmation-mode ATR rejection offset AND close location <= short rejection threshold AND upper wick share >= sensitivity-selected minimum wick share AND Failure score(short, shelf, current half-width) >= minimum failure-score parameter
