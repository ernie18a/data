Calculation: volatility = ATR(ATR lookback) when available and positive; otherwise max(high - low, minimum price increment).
Calculation: fault strength = min(strength cap, min(relative volume / relative-volume scale, relative-volume cap) * relative-volume weight + min(prominence / prominence scale, prominence cap) * prominence weight + min(touches, touch cap) / touch cap * touch weight), where relative volume = volume[L] / SMA(volume, relative-volume lookback), or 1 if that average is unavailable or nonpositive; prominence = (upper level - Lowest(low, 2 * L + 1)) / volatility for upper faults or (Highest(high, 2 * L + 1) - lower level) / volatility for lower faults.
Calculation: fault relevance = fault strength - min(1, abs(close - level) / volatility / relevance-distance scale) * distance penalty - min(1, age / relevance-age scale) * age penalty, where age is measured in chart bars.
Calculation: fault zones = on confirmed chart bars, create upper candidates at PivotHigh(high, L, L) and lower candidates at PivotLow(low, L, L), with L bars on each side and each level set to the pivot price; candidate width = max(volatility * zone-height multiplier, minimum price increment * minimum band ticks); upper bounds are level - width * inner band fraction and level + width * outer band fraction, and lower bounds are level - width * outer band fraction and level + width * inner band fraction. Candidate relative volume uses volume[L] and the current chart bar's SMA; prominence uses the current chart bar's Lowest or Highest over 2 * L + 1 bars. Merge each candidate into the first same-side intact or tested fault within merge-distance multiplier * volatility when that multiplier is positive, updating the level to the more extreme price, expanding bounds to include the candidate bounds, retaining the greater relative volume and prominence, and incrementing touches; otherwise create it only if its strength is at least minimum strength, starting with zero touches and age from the pivot bar. After insertion, keep at most the maximum live faults per side by dropping the least relevant. On each confirmed chart bar, evaluate faults in this order: an upper fault ruptures if close > level, otherwise sweeps if high > level, otherwise becomes tested if intact and high >= its lower bound; a lower fault ruptures if close < level, otherwise sweeps if low < level, otherwise becomes tested if intact and low <= its upper bound. A sweep changes the state to swept; it signals only if the prior state was not swept. A test changes intact to tested and increments touches only if more than L bars have passed since the last touch. Retire faults after evaluation if age exceeds maximum zone age or abs(close - level) exceeds maximum zone distance in ATR units; remove ruptured faults after their signal. Newly confirmed faults are evaluated on that bar.
Long: on a confirmed chart bar, (an active lower fault has low < level AND close >= level AND its prior state was not swept) OR (an active upper fault has close > level).
Short: on a confirmed chart bar, (an active upper fault has high > level AND close <= level AND its prior state was not swept) OR (an active lower fault has close < level).
