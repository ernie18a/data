Calculation: CISD levels = initialize structure high and low to 0, pullback flags false, and candidate prices and indices unset; when close[1] > open[1] and the bearish pullback is inactive, seed its candidate with open[1] and its index with the prior bar; when close[1] < open[1] and the bullish pullback is inactive, seed its candidate and index likewise. While a bearish pullback is active, replace its candidate with open and its index with the current bar if open > candidate or (close > open and open < candidate); while a bullish pullback is active, do so if open < candidate or (close < open and open > candidate). Process low breaks before high breaks: if low < structure low, set structure low to low; if the bearish pullback seed index is earlier than the current bar, add a bullish level at its candidate and set structure high to max(high[n], high[max(n-1, 0)]), where n = min(current bar index - seed index + 1, current bar index), then deactivate that pullback; otherwise, if close[1] > open[1] and close < open and a bearish seed exists, add the same level, set structure high to high[1], and deactivate that pullback. If high > structure high, set structure high to high; if the bullish pullback seed index is earlier than the current bar, add a bearish level at its candidate and set structure low to min(low[n], low[max(n-1, 0)]) using the same n formula, then deactivate that pullback; otherwise, if close[1] < open[1] and close > open and a bullish seed exists, add the same level, set structure low to low[1], and deactivate that pullback. Added levels are appended to their direction's list; the first stored bullish level is completed when close > its level, and the first stored bearish level when close < its level, before alert conditions are evaluated.
Long: low < structure low AND ((bearish pullback active AND bearish seed index < current bar index) OR (close[1] > open[1] AND close < open AND bearish seed exists))
Short: high > structure high AND ((bullish pullback active AND bullish seed index < current bar index) OR (close[1] < open[1] AND close > open AND bullish seed exists))
Long: close > first stored bullish CISD level AND that level is uncompleted
Short: close < first stored bearish CISD level AND that level is uncompleted
