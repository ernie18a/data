Calculation: Bar range = max(high - low, minimum tick)
Calculation: Candle body = abs(close - open)
Calculation: Upper wick = high - max(close, open)
Calculation: Lower wick = min(close, open) - low
Calculation: Volume percentile = PercentRank(volume, volume lookback)
Calculation: Cumulative volume delta = cumulative sum on chart bars of T1 volume when T1 close > T1 open, negative T1 volume when T1 close < T1 open, and zero otherwise; use the latest T1 value without lookahead (still-forming in realtime, latest completed value historically)
Calculation: Premium z-score = (external premium index close sampled from T1 on chart bars without lookahead - SMA(sampled premium index, premium lookback)) / max(StDev(sampled premium index, premium lookback), positive floor)
Calculation: Hurst proxy = 1 - log10(sum(TrueRange, Hurst lookback) / max(highest(high, Hurst lookback) - lowest(low, Hurst lookback), minimum tick)) / log10(Hurst lookback)
Calculation: Mathematical regime state = persistent chart-bar state, initially neutral; when Hurst proxy > trend threshold and ADX > high ADX threshold, set bullish if RSI(close, RSI lookback) > RSI midpoint, plus DI > minus DI, EMA(Cumulative volume delta - prior chart-bar Cumulative volume delta, CVD trend lookback) >= 0, and close > EMA(close, regime lookback), or set bearish if RSI < RSI midpoint, minus DI > plus DI, that CVD EMA <= 0, and close < that EMA; otherwise retain state. When that trend condition is false and Hurst proxy < neutral threshold or ADX < low ADX threshold, set neutral. Then set neutral if bullish and close < regime EMA, or bearish and close > regime EMA.
Calculation: Displayed mathematical regime = neutral on a chart bar when mathematical regime state changes from the prior chart bar; otherwise mathematical regime state
Calculation: Visual regime state = persistent chart-bar state, initially neutral; use the same bullish and bearish conditions as mathematical regime state when Hurst proxy > trend threshold and ADX > high ADX threshold. When binary-only display is disabled, set neutral when Hurst proxy < neutral threshold or ADX < low ADX threshold, and apply the same EMA structural neutralization; when binary-only display is enabled, omit those neutralizations.
Calculation: Displayed visual regime = neutral on a chart bar when visual regime state changes from the prior chart bar; otherwise visual regime state
Calculation: Whittaker upper and lower boundaries = asymmetric Whittaker quantile smooths of high and low over the topological window, using the kinematic smoothness parameter, recalculated from the current full window
Calculation: Polynomial regression center = degree-parameter least-squares polynomial regression of the selected source over the regression window, fit using the latest chart bars and recalculated on the current last chart bar. Channel width = Highest(SMA(high - low, regression window), regression window) * channel width multiplier / 2. Upper and lower polynomial channel boundaries = center plus or minus channel width.
Calculation: Tether z-score = (close - EMA(close, tether lookback)) / max(StDev(close, tether lookback), positive floor)
Calculation: Latest confirmed pivot high and low = persist the prior-bar high or low when it is respectively greater or less than the current bar and all highs or lows across the pivot confirmation lookback before the candidate
Calculation: Causal z-score = (close - mean of stored anchored VWAPs, or close when there are none) / StDev(close, causal z-score lookback), or zero when that standard deviation is zero
Calculation: Bearish absorption star = an unlocked star event when close >= midpoint of the Whittaker boundaries, Volume percentile > star volume threshold, and (Candle body < Bar range * tight-body fraction OR Upper wick > Bar range * star-wick fraction), and either an upper Whittaker boundary or upper polynomial channel boundary was touched within the arming window while displayed mathematical regime was not bullish, or a bearish shockwave or bearish pivot sweep occurred. Bearish shockwave means Bar range > ATR(ATR lookback) * ATR expansion multiplier, Upper wick > Bar range * shockwave-wick fraction, volume > SMA(volume, volume-average lookback) * volume-climax multiplier, and Tether z-score > shockwave z threshold. Bearish pivot sweep means high > latest confirmed pivot high, close < that pivot high, close < open, and volume > SMA(volume, volume-average lookback).
Calculation: Bullish absorption star = an unlocked star event when close <= midpoint of the Whittaker boundaries, Volume percentile > star volume threshold, and (Candle body < Bar range * tight-body fraction OR Lower wick > Bar range * star-wick fraction), and either a lower Whittaker boundary or lower polynomial channel boundary was touched within the arming window while displayed mathematical regime was not bearish, or a bullish shockwave or bullish pivot sweep occurred. Bullish shockwave means Bar range > ATR(ATR lookback) * ATR expansion multiplier, Lower wick > Bar range * shockwave-wick fraction, volume > SMA(volume, volume-average lookback) * volume-climax multiplier, and Tether z-score < negative shockwave z threshold. Bullish pivot sweep means low < latest confirmed pivot low, close > that pivot low, close > open, and volume > SMA(volume, volume-average lookback).
Calculation: Bearish cleared-star cycle = active after a bearish absorption star while Causal z-score >= 0, and remains active until Causal z-score < 0; each trigger type fires at most once per cycle
Calculation: Bullish cleared-star cycle = active after a bullish absorption star while Causal z-score <= 0, and remains active until Causal z-score > 0; each trigger type fires at most once per cycle
