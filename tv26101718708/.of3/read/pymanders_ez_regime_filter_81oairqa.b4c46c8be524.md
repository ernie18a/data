Calculation: Regime band = Highest(ATR(lookback), floor(lookback * volatility-window factor)) * band multiplier
Calculation: Regime(T) uses the same lookback, volatility-window factor, and band multiplier on T bars; initialize to 0, set to 1 when close crosses above ZLEMA(close, lookback) + Regime band, set to -1 when close crosses below ZLEMA(close, lookback) - Regime band, otherwise retain the prior value; for T1–T5, compute on T bars and sample on chart bars with lookahead off (last completed T bar historically, still-forming T bar in realtime)
Calculation: Weighted score on chart bars = Regime(chart) * chart weight + Regime(T1) * T1 weight + Regime(T2) * T2 weight + Regime(T3) * T3 weight + Regime(T4) * T4 weight + Regime(T5) * T5 weight; chart weight equals T1 weight, and T1 weight < T2 weight < T3 weight < T4 weight < T5 weight
Long: Weighted score crosses above 0 OR crosses above ZLEMA(close, lookback) AND weighted score > 0 OR close > ZLEMA(close, lookback) AND weighted score > 0 OR EMA(close, shorter cloud lookback) > EMA(close, longer cloud lookback) OR Regime(chart) = 1 OR Regime(T1) = 1 OR Regime(T2) = 1 OR Regime(T3) = 1 OR Regime(T4) = 1 OR Regime(T5) = 1
Short: Weighted score crosses below 0 OR crosses below ZLEMA(close, lookback) AND weighted score < 0 OR close < ZLEMA(close, lookback) AND weighted score < 0 OR EMA(close, shorter cloud lookback) <= EMA(close, longer cloud lookback) OR Regime(chart) = -1 OR Regime(T1) = -1 OR Regime(T2) = -1 OR Regime(T3) = -1 OR Regime(T4) = -1 OR Regime(T5) = -1
