Calculation: weight = configured volume weight or unit time weight, with automatic weighting using volume when available and unit weight otherwise
Calculation: anchored VWAP = sum(weight × source) / sum(weight) since the selected anchor
Calculation: effective deviation = max(weighted standard deviation of source since the selected anchor, ATR(ATR lookback) × deviation-floor parameter)
Calculation: normalized distance = (close − anchored VWAP) / effective deviation
Calculation: VWAP side = 1 when close > anchored VWAP + dead-zone parameter × effective deviation, −1 when close < anchored VWAP − dead-zone parameter × effective deviation, otherwise 0
Calculation: rotations = count of non-neutral VWAP-side changes in the rotation lookback, clipped to the current anchor
Calculation: persistence = sum of VWAP side in the rotation lookback, clipped to the current anchor, / max(mature-bar count in that lookback, rotation lookback / 2)
Calculation: acceptance gate resets at each anchor; when mature, it becomes Up after the acceptance count of consecutive closes above anchored VWAP + dead-zone parameter × effective deviation, Down after that count below anchored VWAP − dead-zone parameter × effective deviation, and otherwise retains its prior side
Calculation: normalized spread = (EVWAP(source, weight, shorter lookback) − EVWAP(source, weight, longer lookback)) / ATR(ATR lookback)
Calculation: normalized drift = (longer-lookback EVWAP − its value drift lookback bars ago) / (drift lookback × ATR(ATR lookback))
Calculation: candidate regime is Unknown before anchor maturity; otherwise Balance when rotations ≥ max(minimum balance rotations, entry rotation limit + rotation increment); otherwise retain Trend Up when the current regime is Trend Up, the acceptance gate is not Down, and normalized spread > −trend exit threshold; otherwise retain Trend Down when the current regime is Trend Down, the acceptance gate is not Up, and normalized spread < trend exit threshold; otherwise enter Trend Up when the acceptance gate is Up, rotations ≤ entry rotation limit, and normalized spread ≥ the lower re-entry threshold if the last confirmed trend was Up or the new-trend threshold otherwise; otherwise enter Trend Down when the acceptance gate is Down, rotations ≤ entry rotation limit, and normalized spread ≤ the negative of the lower re-entry threshold if the last confirmed trend was Down or the negative of the new-trend threshold otherwise; otherwise Transition
Calculation: confirmed regime resets to Unknown at each anchor and before maturity; otherwise it changes to the candidate regime after the regime confirmation count of consecutive bars with that candidate
Calculation: directional score resets to zero at each anchor; z = normalized distance; position = tanh(sign(z) × max(abs(z) − dead-zone parameter, 0) / position scale) × clamp(1 − (abs(z) − saturation threshold) / exhaustion width, 0, 1); raw score = (spread weight × tanh(normalized spread / spread scale) + position weight × position + persistence weight × persistence + regime weight × regime direction) / sum of weights, where regime direction is 1 for Trend Up, −1 for Trend Down, and 0 otherwise; chop factor = clamp(1 − (rotations − entry rotation limit) / (balance rotation threshold − entry rotation limit), 0, 1); drift factor = drift floor + (1 − drift floor) × min(abs(normalized drift) / drift scale, 1); maturity factor = min(anchor bar count / maturity bar count, 1); target = raw score × chop factor × drift factor × maturity factor; score = prior score + clamp(target − prior score, −score step limit, score step limit)
Long: confirmed regime = Trend Up OR directional score > 0 OR same-anchor normalized distance changes from ≤ −saturation threshold to abs(normalized distance) < saturation threshold AND (trend reversal filter is disabled OR confirmed regime ≠ Trend Down)
Short: confirmed regime = Trend Down OR directional score < 0 OR same-anchor normalized distance changes from ≥ saturation threshold to abs(normalized distance) < saturation threshold AND (trend reversal filter is disabled OR confirmed regime ≠ Trend Up)
