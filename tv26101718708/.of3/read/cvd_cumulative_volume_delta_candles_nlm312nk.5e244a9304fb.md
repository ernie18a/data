Calculation: bar volume delta = on each chart bar, use all available lower-timeframe T1 intrabars, including the still-forming intrabar; classify each as upward if close > open, downward if close < open, otherwise upward if close > T1 close[1], downward if close < T1 close[1], otherwise inherit the previous T1 intrabar's direction if present, else upward; sum upward volume minus downward volume, or divide that sum by total intrabar volume in percent mode.
Calculation: CVD reset = the selected reset event: never; a chart-timeframe-dependent higher-timeframe boundary; a selected higher-timeframe T1 boundary; the intraday chart bar containing the selected exchange-time clock time; the first regular-session chart bar; the first visible chart bar; or a selected trend-indicator direction change (Supertrend direction change, AroonUp crossing AroonDown in either direction, or Parabolic SAR crossing close).
Calculation: CVD close = bar volume delta plus the prior chart bar's CVD close, starting from zero on the first chart bar and after each reset.
Calculation: CVD average = SMA(CVD close, lookback) when CVD reset mode is none; otherwise the arithmetic mean of CVD close from the latest reset through the current chart bar.
Long: bar volume delta > 0 OR CVD close > 0 OR (no CVD reset on the current chart bar AND CVD average > 0) OR (CVD reset mode is trend changes AND selected reset trend is Supertrend(ATR length, ATR multiplier) AND Supertrend direction changes to up) OR (CVD reset mode is trend changes AND selected reset trend is Aroon(lookback) AND AroonUp crosses above AroonDown) OR (CVD reset mode is trend changes AND selected reset trend is Parabolic SAR(start, increment, maximum) AND Parabolic SAR crosses below close).
Short: bar volume delta <= 0 OR CVD close <= 0 OR (no CVD reset on the current chart bar AND CVD average <= 0) OR (CVD reset mode is trend changes AND selected reset trend is Supertrend(ATR length, ATR multiplier) AND Supertrend direction changes to down) OR (CVD reset mode is trend changes AND selected reset trend is Aroon(lookback) AND AroonUp crosses below AroonDown) OR (CVD reset mode is trend changes AND selected reset trend is Parabolic SAR(start, increment, maximum) AND Parabolic SAR crosses above close).
