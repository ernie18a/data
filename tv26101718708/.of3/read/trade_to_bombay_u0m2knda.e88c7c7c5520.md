Calculation: Chart SuperTrend = SuperTrend(hl2, factor parameter, ATR(ATR lookback parameter)) on chart bars
Calculation: Main SuperTrend direction = SuperTrend direction updated on chart bars using hl2, close, and ATR(ATR lookback parameter) from the current (still-forming) T1 bar, with the same factor and ATR lookback parameters as Chart SuperTrend
Long: close crosses above Chart SuperTrend line
Short: close crosses below Chart SuperTrend line
Long: Chart SuperTrend direction changes from short to long AND Main SuperTrend direction is long
Short: Chart SuperTrend direction changes from long to short AND Main SuperTrend direction is short
