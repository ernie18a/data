Calculation: Long risk basis = Stop ATR, signal close - lowest low(candle lookback), signal close * percentage fraction, or pip count * minimum tick, using the first enabled stop mode in ATR, candle low/high, percentage, pip order, and ATR if none is enabled
Calculation: Short risk basis = Stop ATR, highest high(candle lookback) - signal close, signal close * percentage fraction, or pip count * minimum tick, using the first enabled stop mode in ATR, candle low/high, percentage, pip order, and ATR if none is enabled

Calculation: Short target = signal close - short risk basis * risk multiplier * reward ratio, calculated on the short signal bar and held for the position
