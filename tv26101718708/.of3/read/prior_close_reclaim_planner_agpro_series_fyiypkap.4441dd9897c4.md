Calculation: prior close = close of the last completed T1 bar, sampled on chart bars
Calculation: chart ATR = max(ATR(chart bars, ATR lookback) if available, otherwise True Range, minimum price increment)
Calculation: reference ATR = max(ATR(ATR lookback, T1, last completed bar) if available, otherwise chart ATR, minimum price increment), sampled on chart bars
Calculation: upper pocket = prior close + reference ATR * pocket width in ATR
Calculation: lower pocket = prior close - reference ATR * pocket width in ATR
Calculation: relative volume = chart-bar volume, treating missing volume as zero, divided by SMA(volume, volume lookback), or one if that average is not positive
Calculation: distance in ATR = abs(chart close - prior close) / reference ATR
Calculation: reclaim score = zero if prior close is unavailable; otherwise round(clamp(score base + close quality + wick quality + clamp(relative volume * volume-score multiplier, score floor, volume-score cap) + clamp((magnet radius in ATR - distance in ATR) / max(magnet radius in ATR, magnet denominator floor) * magnet-score multiplier, score floor, magnet-score cap) + clamp(volatility-score base - abs(chart ATR / SMA(chart ATR, volume lookback), or one if that average is not positive, minus volatility target) * volatility-deviation multiplier, score floor, volatility-score cap) + (confirmation mode includes wick plus close and either rejection condition is true ? confirmation bonus : score floor) - (distance in ATR > magnet radius in ATR ? clamp((distance in ATR - magnet radius in ATR) * distance-penalty multiplier, score floor, distance-penalty cap) : score floor) + (chart close > upper pocket ? clamp((chart close - upper pocket) / chart ATR * close-distance multiplier, score floor, close-distance cap) : chart close < lower pocket ? clamp((lower pocket - chart close) / chart ATR * close-distance multiplier, score floor, close-distance cap) : neutral close score) + (chart close > upper pocket ? clamp((chart close - chart low) / max(chart high - chart low, minimum price increment) * wick-score multiplier, score floor, wick-score cap) : chart close < lower pocket ? clamp((chart high - chart close) / max(chart high - chart low, minimum price increment) * wick-score multiplier, score floor, wick-score cap) : clamp(abs(chart close - chart open) / max(chart high - chart low, minimum price increment) * inside-body multiplier, score floor, inside-body cap)), score floor, score ceiling))
Long: on a confirmed chart bar, crosses above upper pocket, reclaim score >= minimum ready score, relative volume >= minimum relative volume, prior close is available, and reference age in chart bars since the start of the current T1 period <= maximum reference age
Short: on a confirmed chart bar, crosses below lower pocket, reclaim score >= minimum ready score, relative volume >= minimum relative volume, prior close is available, and reference age in chart bars since the start of the current T1 period <= maximum reference age
Long: on a confirmed chart bar, chart low <= upper pocket, chart close > upper pocket, chart close > chart open, reclaim score >= minimum ready score, relative volume >= minimum relative volume, prior close is available, and reference age in chart bars since the start of the current T1 period <= maximum reference age
Short: on a confirmed chart bar, chart high >= lower pocket, chart close < lower pocket, chart close < chart open, reclaim score >= minimum ready score, relative volume >= minimum relative volume, prior close is available, and reference age in chart bars since the start of the current T1 period <= maximum reference age
Long: on a confirmed chart bar, prior close is available, chart close > upper pocket, distance in ATR <= magnet radius in ATR * ready-distance multiple, reclaim score >= minimum ready score, relative volume >= minimum relative volume, reference age in chart bars since the start of the current T1 period <= maximum reference age, and neither bullish nor bearish ready condition was true on the prior chart bar
Short: on a confirmed chart bar, prior close is available, chart close < lower pocket, distance in ATR <= magnet radius in ATR * ready-distance multiple, reclaim score >= minimum ready score, relative volume >= minimum relative volume, reference age in chart bars since the start of the current T1 period <= maximum reference age, and neither bullish nor bearish ready condition was true on the prior chart bar
Exit: long, on a confirmed chart bar later than the still-active qualified bullish reclaim, chart close < lower pocket
Exit: short, on a confirmed chart bar later than the still-active qualified bearish reclaim, chart close > upper pocket
