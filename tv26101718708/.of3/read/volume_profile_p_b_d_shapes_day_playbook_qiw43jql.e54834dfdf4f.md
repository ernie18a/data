Calculation: Previous completed T1 profile = on chart bars, for each T1 period divide its high-low range into a parameterized number of equal-price rows; distribute each chart bar's nz(volume, 0) among rows in proportion to price-range overlap, assigning all volume to the row containing high when high <= low; choose the highest-volume row as POC (lowest row on ties); expand the value area from POC by adding the adjacent row with more volume (upper row on ties) until included volume >= total volume times the parameterized value-area fraction; VAL and VAH are the bottom and top included row prices, and POC is its row midpoint. Use this profile's levels on chart bars only after that T1 period completes.
Calculation: Previous shape = P when (previous POC - previous T1 low) / (previous T1 high - previous T1 low) >= upper POC threshold; otherwise b when that ratio <= lower POC threshold; otherwise D, provided the previous T1 range is positive.
Calculation: Value-area width = previous VAH - previous VAL.
Calculation: ATR buffer = ATR(chart bars, ATR lookback) * stop-buffer multiple.
Calculation: TP1 at entry = previous T1 high for P continuation long; previous VAL - value-area width for P failure short; previous T1 low for b continuation short; previous VAH + value-area width for b failure long; previous POC for either D fade.
Calculation: TP2 at entry = previous T1 high + value-area width for P continuation long; previous T1 low for b continuation short; previous T1 low for P failure short; previous T1 high for b failure long; previous VAL for D fade short; previous VAH for D fade long.
Calculation: Initial stop captured at entry = min(previous chart-bar low, previous VAL) - ATR buffer for P continuation long; previous POC + ATR buffer for P failure short; max(previous chart-bar high, previous VAH) + ATR buffer for b continuation short; previous POC - ATR buffer for b failure long; previous VAL - max(ATR buffer, value-area width * fade-stop width fraction) for D fade long; previous VAH + max(ATR buffer, value-area width * fade-stop width fraction) for D fade short.
Calculation: Active stop = initial stop, changed to entry price after TP1 is reached when break-even-at-TP1 is enabled.
