Calculation: Opening-range high = highest high of chart bars during the opening-range session parameter for the current calendar date; available after the session ends until the next date reset
Calculation: Opening-range low = lowest low of chart bars during the opening-range session parameter for the current calendar date; available after the session ends until the next date reset
Calculation: ORB trend state = bullish after an opening-range-complete close above the opening-range high, bearish after an opening-range-complete close below the opening-range low, otherwise retain the prior state; initially neutral
Calculation: Long marker allowance = at the start of the chart bar, no prior accepted impulse, breakout-confirmation, or reversal marker exists or more than the cooldown parameter chart bars have elapsed since the latest one, and the carried long-marker count since the current date reset or latest accepted short marker is below the per-side maximum parameter
Calculation: Short marker allowance = at the start of the chart bar, no prior accepted impulse, breakout-confirmation, or reversal marker exists or more than the cooldown parameter chart bars have elapsed since the latest one, and the carried short-marker count since the current date reset or latest accepted long marker is below the per-side maximum parameter
Long: ORB trend state is bullish
Short: ORB trend state is bearish
