Calculation: Currency strength(C) = raw return(C) minus the arithmetic mean of the raw returns for EUR, GBP, AUD, NZD, CAD, CHF, JPY, NOK, and USD; raw return(USD) = 0; for other currencies, raw return = 100 × (current USD-reference price / anchor price − 1), except that with spot data CAD, CHF, JPY, and NOK use 100 × (anchor price / current USD-reference price − 1); the anchor price is the close N bars ago on T1 or the open of the current T2 bar, according to the anchor setting; use current T1 closes and the current T2 open sampled on chart bars, with the current requested bars still forming until they close; use the same data source, N, anchor setting, and T1 for base and quote currencies.
Calculation: Decision strength(C) = Currency strength(C) when smoothing is disabled; otherwise, on chart bars let a = 2/(L+1), initialize memory M(C) to the first Currency strength(C), update M(C) to a × Currency strength(C)[1] + (1−a) × M(C) when time(T1) changes, and retain M(C) otherwise; output a × Currency strength(C) + (1−a) × M(C); use the same L and smoothing setting for base and quote currencies.
Calculation: Strength gap = abs(Decision strength(base currency) − Decision strength(quote currency)) on each chart bar.
Long: Decision strength(base currency) crosses above Decision strength(quote currency)
Short: Decision strength(base currency) crosses below Decision strength(quote currency)
Long: Strength gap <= contraction threshold AND prior chart-bar Strength gap > contraction threshold AND Decision strength(base currency) <= Decision strength(quote currency)
Short: Strength gap <= contraction threshold AND prior chart-bar Strength gap > contraction threshold AND Decision strength(base currency) > Decision strength(quote currency)
Calculation: Currency line(c) = optionally smooth the relative return of c, where relative return is its return minus the mean return of eight non-USD currencies and USD; USD return is zero, and each other return is 100 × (current corresponding USD pair or futures price / reference price − 1), except spot pairs quoted as USD/currency use 100 × (reference price / current price − 1); the reference is the close a lookback parameter number of selected-timeframe bars earlier or the T2 open, and the selected timeframe is the chart timeframe, T1, or T2; smoothing uses α = 2 / (smoothing-length parameter + 1), initializes memory to the current relative return, updates memory to α × previous relative return + (1 − α) × memory on each new selected-timeframe bar, and outputs α × current relative return + (1 − α) × memory
Calculation: Currency distance = absolute difference between the base and quote currency lines

Short: Alerts enabled AND instrument is a forex pair AND bar closes AND base currency line crosses below quote currency line
Long: Alerts enabled AND instrument is a forex pair AND bar closes AND currency distance ≤ squeeze-threshold parameter AND previous currency distance > squeeze-threshold parameter AND base currency line ≤ quote currency line
Short: Alerts enabled AND instrument is a forex pair AND bar closes AND currency distance ≤ squeeze-threshold parameter AND previous currency distance > squeeze-threshold parameter AND base currency line > quote currency line
