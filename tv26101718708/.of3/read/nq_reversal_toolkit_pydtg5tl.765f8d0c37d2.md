Calculation: Fib pivot levels(H,L,C, enabled coefficients) = PP=(H+L+C)/3 and PP±coefficient×(H−L) for each enabled coefficient
Calculation: T1 candle body = abs(close−open); T1 upper wick = high−max(open,close); T1 lower wick = min(open,close)−low, using the last completed T1 bar
Calculation: HUD level list = enabled Fib pivot levels from current NY-session high, low, and close, in order (PP, then positive and negative levels by increasing coefficient); followed by the T2 PP and enabled positive and negative levels for the three smallest Fib coefficients from the last completed T2 bar when its range is positive; followed by the latest selected-session volume-profile POC, VAH, and VAL, when available
Calculation: HUD bias level = HUD level list[floor(length(HUD level list)/2)], using zero-based indexing
Long: On chart bars at each new T1 boundary, using the last completed T1 bar: T1 candle body > 0 AND T1 lower wick > wick/body ratio parameter × T1 candle body AND (ATR(ATR lookback parameter, T1, last completed bar) is unavailable OR T1 lower wick > minimum ATR-wick multiple parameter × ATR(ATR lookback parameter, T1, last completed bar)) AND NOT (T1 upper wick > wick/body ratio parameter × T1 candle body AND (ATR(ATR lookback parameter, T1, last completed bar) is unavailable OR T1 upper wick > minimum ATR-wick multiple parameter × ATR(ATR lookback parameter, T1, last completed bar)))
Short: On chart bars at each new T1 boundary, using the last completed T1 bar: T1 candle body > 0 AND T1 upper wick > wick/body ratio parameter × T1 candle body AND (ATR(ATR lookback parameter, T1, last completed bar) is unavailable OR T1 upper wick > minimum ATR-wick multiple parameter × ATR(ATR lookback parameter, T1, last completed bar))
Long: On chart bars, HUD level list is nonempty AND close > HUD bias level
Short: On chart bars, HUD level list is nonempty AND close ≤ HUD bias level
