Calculation: Stage slope = SMA(close, stage MA lookback) - SMA(close, stage MA lookback)[1]
Calculation: Flattening = highest(Stage slope, flattening lookback) - lowest(Stage slope, flattening lookback) < SMA(high - low, range lookback) * flattening factor
Calculation: Rising slope = Stage slope > 0 on the current and preceding slope persistence lookback - 1 bars; falling slope = Stage slope < 0 on those bars
Calculation: Tracked range levels = tracked high updates to highest(high, range lookback)[1] while the prior stage is 1 and otherwise holds; tracked low updates to lowest(low, range lookback)[1] while the prior stage is 3 and otherwise holds
Calculation: Breakout = close crosses above tracked high AND volume > SMA(volume, volume average lookback) * breakout volume multiplier AND close > open
Calculation: Breakdown = close crosses below tracked low
Calculation: Stage = starts at 1; from stage 1, changes to 2 on Breakout AND close > SMA(close, stage MA lookback); from stage 2, changes to 3 on (close < SMA(close, stage MA lookback) AND Flattening) OR (Breakdown AND Stage slope <= 0); from stage 3, changes to 4 on Breakdown OR (close < SMA(close, stage MA lookback) AND falling slope), otherwise changes to 2 on Breakout AND close > SMA(close, stage MA lookback) AND rising slope; from stage 4, changes to 1 on close > SMA(close, stage MA lookback) AND Flattening AND NOT falling slope; otherwise retains its prior value
Calculation: Base events = base count starts at 0, stored breakout price at 0, and bars since breakout at 0; increment bars since breakout each bar; when Breakout AND bars since breakout >= minimum base width, if Stage changes to 2 set base count to 1, stored breakout price to close, and bars since breakout to 0 and emit base 1; otherwise, if Stage = 2 AND base count > 0 AND 100 * (close - stored breakout price) / stored breakout price >= minimum rally percent, increment base count, set stored breakout price to close and bars since breakout to 0, and emit base 2 when count = 2, base 3 when count = 3, or base 4+ when count >= 4; after this, if Stage changes to 4 OR Breakdown, emit breakdown when base count > 0 and reset base count, stored breakout price, and bars since breakout to 0
Long: chart timeframe = T1 AND (Stage changes to 1 OR Stage changes to 2 OR Base events emits base 1, base 2, base 3, or base 4+)
Short: chart timeframe = T1 AND (Stage changes to 3 OR Stage changes to 4 OR Base events emits breakdown)
