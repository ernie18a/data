Calculation: Relative strength versus a benchmark = close / that benchmark's close on the chart timeframe
Calculation: Relative strength strong = relative strength versus each of two benchmark series > SMA(that relative strength, relative-strength lookback) for both series
Calculation: Relative strength weak = relative strength versus each of two benchmark series < SMA(that relative strength, relative-strength lookback) for both series
Calculation: ADL = cumulative sum of volume * (((close - low) - (high - close)) / max(high - low, money-flow range-floor parameter))
Calculation: ADL bullish = ADL > SMA(ADL, ADL lookback)
Calculation: Price-volume score = clamp(higher-high weight * (1 if high > high[1] else 0) + higher-low weight * (1 if low > low[1] else 0) + up-volume weight * (1 if close > open AND volume > SMA(volume, shorter volume-average lookback) else 0) - heavy-sell penalty * (1 if close < open AND volume > SMA(volume, longer volume-average lookback) * heavy-volume factor else 0) - failed-breakout penalty * (1 if high > highest(high, breakout lookback)[1] AND close < open else 0), -component-score cap, component-score cap); shorter volume-average lookback < longer volume-average lookback
Calculation: Smart-money score = clamp(ADL-bullish weight * (1 if ADL bullish else 0) + absorption weight * (1 if abs(close - VWAP(close)) / close < smallness parameter AND volume > SMA(volume, shorter volume-average lookback) AND abs(close - open) / close < smallness parameter else 0) + low-volume-pullback weight * (1 if close < close[1] AND volume < SMA(volume, shorter volume-average lookback) else 0) - breakdown penalty * (1 if close < lowest(low, breakout lookback)[1] AND volume > SMA(volume, shorter volume-average lookback) else 0), -component-score cap, component-score cap)
Calculation: Institutional-activity score = clamp(accumulation weight * (1 if relative strength strong AND close > EMA(close, medium EMA lookback) AND ADL bullish else 0) + strong-relative-strength weight * (1 if relative strength strong else 0) - distribution penalty * (1 if relative strength weak AND close < EMA(close, medium EMA lookback) else 0), -component-score cap, component-score cap)
Calculation: Fundamental-momentum score = clamp(bullish-fundamental weight * (1 if close > EMA(close, medium EMA lookback) AND RSI(close, RSI lookback) > bullish RSI lower threshold AND RSI(close, RSI lookback) < bullish RSI upper threshold else 0) + long-EMA weight * (1 if close > EMA(close, long EMA lookback) else 0) - bearish-fundamental penalty * (1 if close < EMA(close, medium EMA lookback) AND RSI(close, RSI lookback) < bearish RSI threshold else 0), -component-score cap, component-score cap); bullish RSI upper threshold > bullish RSI lower threshold > bearish RSI threshold
Calculation: Relative-strength score = clamp(strong-relative-strength weight * (1 if relative strength strong else 0) + positive-momentum weight * (1 if ROC(close, momentum lookback) > momentum threshold else 0) - weak-relative-strength penalty * (1 if relative strength weak else 0), -component-score cap, component-score cap)
Calculation: Technical-structure score = clamp(breakout weight * (1 if close > highest(high, breakout lookback)[1] AND volume > SMA(volume, shorter volume-average lookback) else 0) + short-EMA weight * (1 if EMA(close, short EMA lookback) > EMA(close, medium EMA lookback) else 0) + medium-EMA weight * (1 if EMA(close, medium EMA lookback) > EMA(close, long EMA lookback) else 0) - resistance-rejection penalty * (1 if high >= highest(high, resistance lookback)[1] AND close < open else 0), -component-score cap, component-score cap); short EMA lookback < medium EMA lookback < long EMA lookback; resistance lookback > breakout lookback
Calculation: Volatility score = clamp(compression weight * (1 if ATR(ATR lookback) < SMA(ATR(ATR lookback), ATR-average lookback) else 0) - expansion penalty * (1 if ATR(ATR lookback) > SMA(ATR(ATR lookback), ATR-average lookback) * expansion factor AND close < EMA(close, medium EMA lookback) else 0), -component-score cap, component-score cap); ATR-average lookback > ATR lookback
Calculation: Market-cycle score = clamp(long-EMA weight * (1 if close > EMA(close, long EMA lookback) else 0) + strong-relative-strength weight * (1 if relative strength strong else 0) - weak-relative-strength penalty * (1 if relative strength weak else 0), -component-score cap, component-score cap)
Calculation: Normalized institutional score = (price-volume coefficient * price-volume score + smart-money coefficient * smart-money score + institutional-activity coefficient * institutional-activity score + fundamental-momentum coefficient * fundamental-momentum score + relative-strength coefficient * relative-strength score + technical-structure coefficient * technical-structure score + volatility coefficient * volatility score + market-cycle coefficient * market-cycle score + score offset) / score scale
Calculation: Smoothed institutional score = SMA(normalized institutional score, score-smoothing lookback)
Long: smoothed institutional score >= accumulation threshold
Short: smoothed institutional score <= distribution threshold
