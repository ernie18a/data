Calculation: Fisher trend state = on chart bars, compute the selected price source from the current forming T1 bar’s running open, high, and low and current chart close, or from the current chart bar when chart-interval mode is selected; set the range high and low to the maximum and minimum of the current source and the highest and lowest source over max(lookback minus one, 1) last completed T1 bars, or over the lookback chart bars in chart-interval mode; weight 2 times ((source minus range low) divided by (range high minus range low) minus 0.5) with the prior normalized value captured at the first chart bar of T1 and held through T1, or the prior chart bar in chart-interval mode; clip the result to a fixed magnitude below one and apply the Fisher Transform; set smoothed Fisher to the average of current Fisher and the prior smoothed Fisher captured and held the same way; update state only on the last chart bar of T1, or each chart bar in chart-interval mode, to +1 if Fisher > smoothed Fisher AND change in rounded smoothed Fisher >= 0, to -1 if Fisher < smoothed Fisher AND change in rounded smoothed Fisher <= 0, otherwise retain the prior state, initially 0
Long: Fisher trend state > 0
Short: Fisher trend state < 0
Long: Fisher trend state changes upward AND chart datetime is within the configured entry window, inclusive
Short: Fisher trend state changes downward AND chart datetime is within the configured entry window, inclusive
Exit: Long, low reaches the stop level the stop-loss distance below entry price OR high has reached the trail-activation distance above entry price AND low reaches the trailing stop at the highest high since activation minus the long trail offset
Exit: Short, high reaches the stop level the stop-loss distance above entry price OR low has reached the trail-activation distance below entry price AND high reaches the trailing stop at the lowest low since activation plus the short trail offset
