Calculation: Candle weight = body-weight parameter × abs(close − open) + wick-weight parameter × (high − max(open, close) + min(open, close) − low)
Calculation: Active setup range = high and low of the selected candle; on T1 bars, use each enabled session’s configured session hour to select a candidate candle, choosing the highest-weight candle in the Dawn selection window or the highest-weight candle among the current and prior bar for Morning or Evening, with ties going to the newest candle; use the candidate with the latest candle time, with ties ordered Dawn, Morning, Evening; carry the T1 result onto chart bars. Use the current T1 bar, including while it is forming in real time.
Long: an active setup range exists AND low < active setup low when wick-break mode is enabled, otherwise close < active setup low; AND close > active setup low when close-return mode is enabled; AND high − low > ATR(lookback) × minimum-range multiplier AND abs(close − open) / (high − low) ≥ minimum-body ratio AND (min(open, close) − low) / (high − low) ≥ minimum-lower-wick ratio AND more than the cooldown parameter bars have elapsed since the prior sweep signal
Short: an active setup range exists AND high > active setup high when wick-break mode is enabled, otherwise close > active setup high; AND close < active setup high when close-return mode is enabled; AND high − low > ATR(lookback) × minimum-range multiplier AND abs(close − open) / (high − low) ≥ minimum-body ratio AND (high − max(open, close)) / (high − low) ≥ minimum-upper-wick ratio AND more than the cooldown parameter bars have elapsed since the prior sweep signal
