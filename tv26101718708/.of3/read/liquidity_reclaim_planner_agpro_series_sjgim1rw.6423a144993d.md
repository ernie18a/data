Calculation: Safe ATR = max(ATR(ATR length), true range if ATR is unavailable, minimum tick)
Calculation: Low-side sweep depth = max(0, latest confirmed PivotLow(low, pivot strength, pivot strength) - low) / Safe ATR when that pivot is within max level age, otherwise 0
Calculation: High-side sweep depth = max(0, high - latest confirmed PivotHigh(high, pivot strength, pivot strength)) / Safe ATR when that pivot is within max level age, otherwise 0
