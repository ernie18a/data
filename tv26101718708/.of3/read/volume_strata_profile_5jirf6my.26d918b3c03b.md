Calculation: Volume Strata Profile row volume(row, stratum) = on each chart bar, partition the range from the lowest low to the highest high over the profile lookback into equal price rows and assign bars chronologically to strata; allocate each bar's volume to rows in proportion to the overlap of its high-low range with each row. When intrabar volume is enabled and T1 is lower than the chart timeframe, use available T1 high, low, and volume for a chart bar if any are available, including a T1 bar still forming; otherwise use the chart bar's high, low, and volume. Assign all volume to one row when the range has no width or lies in one row.
Calculation: Stratum POC row(stratum) = the lowest-price row with the greatest Volume Strata Profile volume in that stratum; its price is the row midpoint.
Calculation: Profile POC = the lowest-price row with the greatest total Volume Strata Profile volume across strata; its price is the row midpoint.
Calculation: Profile VAH = the upper boundary of the POC-centered value area, expanding toward the adjacent row with greater volume until the configured share of total profile volume is included.
Calculation: Newest-half POC row(half) = the lowest-price row with the greatest allocated volume in the older or newer chronological half of the newest stratum; split chart bars into halves, with the newer half containing the most recent bars.
Calculation: Latest POC shift = newest stratum POC row - preceding stratum POC row.
Calculation: Previous POC shift = preceding stratum POC row - the POC row two strata earlier; use zero shift when that earlier stratum is unavailable.
Calculation: New value acceptance = newer-half POC row >= older-half POC row - POC noise tolerance.
Calculation: Newest activity ratio = newest-stratum volume per chart bar / total profile volume per chart bar.
Calculation: Migration quality score = sign(newest-stratum POC price - oldest-stratum POC price) * migration efficiency * capped absolute normalized migration / migration magnitude scale, expressed as a percentage; migration efficiency = absolute net POC price change / sum of absolute adjacent-stratum POC price changes, and normalized migration = net POC price change / profile price range.
Calculation: Quality gate pass = intrabar quality is not applicable OR recent intrabar quality >= minimum intrabar quality. Recent intrabar quality is calculated on chart bars over the configured number of newest strata as the square root of coverage multiplied by density, expressed as a percentage; coverage = chart bars with T1 intrabars / chart bars in that window, and density = the lesser of full density and average intrabars per covered chart bar / maximum observed intrabars per covered chart bar. Intrabar quality is not applicable when T1 is not enabled, is not lower than the chart timeframe, or has no intrabars in that window.
Calculation: Setup pass count = count of these conditions: latest POC shift > POC noise tolerance; previous POC shift > POC noise tolerance; new value acceptance; migration quality score >= minimum migration score AND latest POC shift > POC noise tolerance; newest activity ratio >= minimum activity ratio; close >= Profile POC; close >= Profile VAH - ATR(ATR lookback) * near-VAH ATR multiplier.
Calculation: Strong setup = quality gate pass AND setup pass count >= strong-setup pass threshold AND latest POC shift > POC noise tolerance AND close >= Profile POC.
