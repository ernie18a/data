Calculation: Trailing DD line = tick-rounded line from a peak reference. The peak reference starts at entry price plus (full-DD distance − entry-buffer distance) for long, or minus that amount for short; it then ratchets to the maximum for long or minimum for short of its prior value and the selected reference. In intraday mode, use the entry-bar close and then each chart bar’s high for long or low for short. In bar-close mode, use each chart bar’s close. In end-of-day mode, on the first chart bar of each T1 period after entry, use the prior chart bar’s close. Full-DD distance and entry-buffer distance are their separate dollar parameters divided by dollar value per price point (contract count × point value). The raw line is peak reference minus full-DD distance for long or plus it for short. A configured manual lock price takes precedence over an auto lock; when starting balance and entry equity are provided, auto lock is entry price plus the direction sign (+1 long, −1 short) × (starting balance + lock offset − entry equity) / dollar value per price point. Apply a lock only when it is at or beyond the initial line in the favorable direction; clamp the long line to the lower of raw line and lock, or the short line to the higher. Round long up and short down to the minimum tick size.
Exit: Long, close <= trailing DD line OR (chart-bar time > entry time AND low <= prior trailing DD line in bar-close mode, using the current line if no prior line exists, OR current trailing DD line in intraday or end-of-day mode)
Exit: Short, close >= trailing DD line OR (chart-bar time > entry time AND high >= prior trailing DD line in bar-close mode, using the current line if no prior line exists, OR current trailing DD line in intraday or end-of-day mode)
