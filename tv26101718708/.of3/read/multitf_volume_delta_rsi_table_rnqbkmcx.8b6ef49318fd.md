Calculation: Buy-volume share(T) = if volume(T) > 0 AND high(T) > low(T), then (close(T) - low(T)) / (high(T) - low(T)), else 0.5; use the current T-bar fields mapped to chart bars (with lookahead off, historical chart bars use the last completed T bar and realtime chart bars can use the forming T bar)
Calculation: T signal = 1 if Buy-volume share(T) >= delta-dominance parameter AND RSI(close, shared RSI-lookback parameter) on T bars < overbought parameter; otherwise -1 if Buy-volume share(T) <= 1 - delta-dominance parameter AND RSI(close, shared RSI-lookback parameter) on T bars > oversold parameter; otherwise 0; evaluate on chart bars using the current mapped T values, with the same lookahead-off behavior
Long: count of enabled T1–T8 signals equal to 1 >= minimum bullish-timeframe parameter AND the count on the previous chart bar < minimum bullish-timeframe parameter
Short: count of enabled T1–T8 signals equal to -1 >= minimum bearish-timeframe parameter AND the count on the previous chart bar < minimum bearish-timeframe parameter
