Calculation: Gap ratio = abs(first regular-session chart-bar open - previous regular-session close) / ATR(lookback) computed on T1 bars using the last completed T1 bar and sampled on chart bars
Calculation: Gap tier = Tiny if gap ratio < smallest cutoff; Small if gap ratio >= smallest cutoff and < middle cutoff; Medium if gap ratio >= middle cutoff and < largest cutoff; Large if gap ratio >= largest cutoff
Calculation: Stop distance = selected ATR-stop multiplier * ATR(the same lookback, T1, last completed bar) sampled on chart bars, or selected fixed-point stop parameter
Long: At the first regular-session chart bar, open <= previous regular-session close AND gap size >= minimum gap size AND gap tier is enabled AND (inside-range filter is disabled OR open is between previous regular-session low and high) AND abs(previous regular-session close - current chart-bar close) / stop distance >= minimum reward-to-risk parameter
Short: At the first regular-session chart bar, open > previous regular-session close AND gap size >= minimum gap size AND gap tier is enabled AND (inside-range filter is disabled OR open is between previous regular-session low and high) AND abs(previous regular-session close - current chart-bar close) / stop distance >= minimum reward-to-risk parameter
Exit: long, On a chart bar after entry, low <= entry price - stop distance OR high >= previous regular-session close OR chart-bar time is outside the entry/exit session window in New York time
Exit: short, On a chart bar after entry, high >= entry price + stop distance OR low <= previous regular-session close OR chart-bar time is outside the entry/exit session window in New York time
