Calculation: Confirmed pivot high = high[pivot lookback] if high[n] < high[pivot lookback] for every integer n from 1 through twice the pivot lookback, excluding n = pivot lookback; otherwise undefined.
Calculation: Confirmed pivot low = low[pivot lookback] if low[n] > low[pivot lookback] for every integer n from 1 through twice the pivot lookback, excluding n = pivot lookback; otherwise undefined.
Calculation: Active pivot high = the latest confirmed pivot high; each newly confirmed pivot high activates it, and a long structural-break entry deactivates it.
Calculation: Active pivot low = the latest confirmed pivot low; each newly confirmed pivot low activates it, and a short structural-break entry deactivates it.
Calculation: Bullish sweep state = using the active pivot low at the start of each chart bar, set active and update its extreme to the minimum low[1] when low[1] < pivot low; clear the state and extreme when close[1] < pivot low, taking precedence; otherwise retain the state and extreme.
Calculation: Bearish sweep state = using the active pivot high at the start of each chart bar, set active and update its extreme to the maximum high[1] when high[1] > pivot high; clear the state and extreme when close[1] > pivot high, taking precedence; otherwise retain the state and extreme.
Calculation: Last structure range midpoint = the mean of the last break's lower and upper bounds, initially both zero; a bullish break sets the lower bound to the bullish sweep extreme if the sweep filter is enabled and the extreme exists, otherwise the active pivot low, and the upper bound to the broken pivot high; a bearish break sets the lower bound to the broken pivot low and the upper bound to the bearish sweep extreme if the sweep filter is enabled and the extreme exists, otherwise the active pivot high.
Long: On a confirmed chart bar, an active pivot high exists and close[1] > pivot high; if full-body confirmation is enabled, also open[1] > pivot high; AND, if the sweep filter is enabled, bullish sweep state is active; AND, if the T1 bias filter is enabled, chart bars use last completed T1 values satisfying close > SMA(close, lookback, T1, last completed bar); AND, if the premium/discount filter is enabled, the last structure range bounds are equal or close[1] < last structure range midpoint.
Short: On a confirmed chart bar, an active pivot low exists and close[1] < pivot low; if full-body confirmation is enabled, also open[1] < pivot low; AND, if the sweep filter is enabled, bearish sweep state is active; AND, if the T1 bias filter is enabled, chart bars use last completed T1 values satisfying close < SMA(close, lookback, T1, last completed bar); AND, if the premium/discount filter is enabled, the last structure range bounds are equal or close[1] > last structure range midpoint.
Long: On a confirmed chart bar, a new unique ABC structure forms from the last three ZigZag pivots, with A and C pivot lows, B a pivot high, and A.price < C.price < B.price.
Short: On a confirmed chart bar, a new unique ABC structure forms from the last three ZigZag pivots, with A and C pivot highs, B a pivot low, and B.price < C.price < A.price.
Exit: Long, when structure invalidation is enabled and close[1] < A.price for a tracked active bullish ABC structure, newly invalidating at least one such structure.
Exit: Short, when structure invalidation is enabled and close[1] > A.price for a tracked active bearish ABC structure, newly invalidating at least one such structure.
