Calculation: Print direction = sign(close − open); if 0, sign(close − (high + low) / 2); if 0, sign(close − previous positive-measure T1 intrabar close within the same chart bar); 0 if no such prior intrabar. Computed on each T1 intrabar, using the current intrabar, which may still be forming.
Calculation: Volume anomaly z-score = ZScore(ln(selected volume measure), preceding positive-measure T1 intrabars within the same chart bar, up to the reference lookback; population standard deviation; 0 when standard deviation ≤ epsilon. Computed on each T1 intrabar, using the current intrabar, which may still be forming.
Calculation: Cluster symbol count = number of distinct enabled symbols represented in the retained anomalous-print tape, up to the tape length.
Calculation: Cluster net = sum over retained anomalous prints of (print direction ≥ 0 ? 1 : −1) × print volume anomaly z-score.
Long: enabled symbol AND selected volume measure > 0 AND prior positive-measure T1 intrabar count within the same chart bar meets the configured sample requirement AND ((admission mode selects all events AND volume anomaly z-score ≥ lower threshold) OR (admission mode selects surges AND volume anomaly z-score ≥ upper threshold) OR (admission mode selects the entry band AND lower threshold ≤ volume anomaly z-score < upper threshold)) AND print direction > 0
Short: enabled symbol AND selected volume measure > 0 AND prior positive-measure T1 intrabar count within the same chart bar meets the configured sample requirement AND ((admission mode selects all events AND volume anomaly z-score ≥ lower threshold) OR (admission mode selects surges AND volume anomaly z-score ≥ upper threshold) OR (admission mode selects the entry band AND lower threshold ≤ volume anomaly z-score < upper threshold)) AND print direction < 0
Long: cluster line enabled AND cluster symbol count ≥ cluster minimum AND cluster net ≥ 0
