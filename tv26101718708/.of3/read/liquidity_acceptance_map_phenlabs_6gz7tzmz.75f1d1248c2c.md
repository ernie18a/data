Calculation: LowPool = (newer + older) / 2 if ABS(newer - older) / older * 100 <= equal level tolerance, else N/A; newer and older = the two most recent confirmed PivotLow(low, S, S) values, S = max(swing lookback / 2, minimum pivot side)
Calculation: HighPool = (newer + older) / 2 if ABS(newer - older) / older * 100 <= equal level tolerance, else N/A; newer and older = the two most recent confirmed PivotHigh(high, S, S) values, S = max(swing lookback / 2, minimum pivot side)
Calculation: AcceptanceScore = clamp((volume / SMA(volume, score lookback) - 1) / max(volume multiplier - 1, 0.001) * 100, 0, 100) * volume weight / 100 + clamp((ATR(score lookback) / SMA(ATR(score lookback), score lookback) - 1) / max(ATR multiplier - 1, 0.001) * 100, 0, 100) * (100 - volume weight) / 100
Calculation: HTFBias = 0 if not HTF filter, else sign(X - X[1]), where X = EMA(close, HTF EMA length, T1, last completed bar), computed on T1 bars and taken on chart bars, and X[1] = X one chart bar earlier
Long: (close if require-close, else low) <= LowPool * (1 - sweep margin / 100) AND AcceptanceScore >= minimum acceptance score AND HTFBias >= 0 AND (no earlier bar where Long was true OR ABS(LowPool - LowPool at most recent earlier bar where Long was true) / LowPool at that bar * 100 > equal level tolerance)
Short: (close if require-close, else high) >= HighPool * (1 + sweep margin / 100) AND AcceptanceScore >= minimum acceptance score AND HTFBias <= 0 AND (no earlier bar where Short was true OR ABS(HighPool - HighPool at most recent earlier bar where Short was true) / HighPool at that bar * 100 > equal level tolerance)
Exit: long, close < (entry price - zone height multiple * ATR(score lookback) at entry bar) * (1 - invalidation offset / 100)
Exit: short, close > (entry price + zone height multiple * ATR(score lookback) at entry bar) * (1 + invalidation offset / 100)
