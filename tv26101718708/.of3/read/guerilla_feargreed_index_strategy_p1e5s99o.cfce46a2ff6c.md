Calculation: Weekly survey component = (if EMA(NAAIM close from T1 mapped onto chart bars, shared lookback; using the current T1 bar, including while it is forming) < survey fear threshold then 0; else if EMA(...) > survey greed threshold then 100; else ((EMA(...) - survey fear threshold) / (survey greed threshold - survey fear threshold)) * 100) * (survey weight / 100)
Calculation: Daily put-call component = (if EMA(put-call close from T2 mapped onto chart bars, shared lookback; using the current T2 bar, including while it is forming) > put-call fear threshold then 0; else if EMA(...) < put-call greed threshold then 100; else ((put-call fear threshold - EMA(...)) / (put-call fear threshold - put-call greed threshold)) * 100) * (put-call weight / 100)
Calculation: Composite sentiment = Weekly survey component + Daily put-call component
Long: EMA(Composite sentiment, composite lookback)[1] < buy threshold AND EMA(Composite sentiment, composite lookback) > EMA(Composite sentiment, composite lookback)[1] AND EMA(Composite sentiment, composite lookback)[2] > EMA(Composite sentiment, composite lookback)[1] AND datetime is on or after the configured start date
Exit: long, (EMA(Composite sentiment, composite lookback)[1] > sell threshold AND EMA(Composite sentiment, composite lookback) < EMA(Composite sentiment, composite lookback)[1] AND EMA(Composite sentiment, composite lookback)[2] < EMA(Composite sentiment, composite lookback)[1] AND datetime is on or after the configured start date) OR (close-date exit is enabled AND chart date equals the configured close date)
