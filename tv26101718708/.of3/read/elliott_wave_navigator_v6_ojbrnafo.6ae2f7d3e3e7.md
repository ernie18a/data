Calculation: Reversal distance on chart bars = ATR(ATR lookback) × (automatic threshold enabled ? clamp(adaptive base + ER sensitivity × (1 − EMA(Kaufman Efficiency Ratio(close, ER lookback; use the zero-sum ER fallback when its denominator is zero), ER smoothing length)), adaptive floor, adaptive ceiling) : manual ATR multiple)
Calculation: Confirmed main zigzag pivots on chart bars = initialize rising with the first high as the extreme; while rising, if high >= extreme, set extreme to high, otherwise if close < extreme − reversal distance, confirm the extreme as a pivot, switch to falling, and set the extreme to low; while falling, if low <= extreme, set extreme to low, otherwise if close > extreme + reversal distance, confirm the extreme as a pivot, switch to rising, and set the extreme to high. Keep confirmed pivots oldest to newest; p1 is newest, p2 is the previous pivot, and so on; n is the pivot count; extP is the active extreme.
Calculation: Bullish reversal candle = (close > open AND close[1] < open[1] AND close >= open[1] AND open <= close[1]) OR (abs(close − open) > 0 AND min(open, close) − low > long-wick multiple × abs(close − open) AND high − max(open, close) < short-wick body cap × abs(close − open)) OR (close > high[1] AND close[1] < open[1])
Calculation: Bearish reversal candle = (close < open AND close[1] > open[1] AND close <= open[1] AND open >= close[1]) OR (abs(close − open) > 0 AND high − max(open, close) > long-wick multiple × abs(close − open) AND min(open, close) − low < short-wick body cap × abs(close − open)) OR (close < low[1] AND close[1] > open[1])
Calculation: Bear mode = initialize inactive. When inactive, start it if the main zigzag direction is falling, n >= 5, p1 < p3 < p5, p2 < p4, and extP < p2; set its break level to p1. While active, when the direction changes to falling and p1 is below the break level, lower the break level to p1; if close > the break level, deactivate it. An active bear mode overrides the wave state.
Calculation: Wave state and trade zone on each chart bar = using the confirmed pivots and direction, select the first matching candidate in this order: while falling, Wave A if n >= 6, p4 > p6, p3 > p5, p2 > p5, p1 > p3, L1 = p5 − p6 > 0, L3 = p3 − p4 > 0, L5 = p1 − p2 > 0, and NOT (L3 < L1 AND L3 < L5); otherwise Wave 4 if n >= 4, p2 > p4, p1 > p3, p1 − p2 > 0, and p3 − p4 > 0; otherwise Wave C if n >= 3, p3 > p1 > p2, and the ratio (p1 − p2) / (p3 − p2) is within the Wave C retracement bounds; otherwise Wave 2 if n >= 2 and p1 > p2. While rising, select Wave B if the saved finalized state at the latest direction change was Wave A, n >= 2, p2 > p1, and (extP − p1) / (p2 − p1) is within the Wave B retracement bounds; otherwise select Wave 5 if n >= 5, p3 > p5, p1 > p4, p2 > p4, L1 = p4 − p5 > 0, and L3 = p2 − p3 > 0. Save the prior bar's finalized state at each direction change. Invalidate selected Wave A, Wave B, Wave 4, Wave C, Wave 2, or Wave 5 respectively when close > p1, close > p2, close < p3, close > p1, close < p2, or close < p1; an invalid candidate becomes BROKEN and does not fall through to a later candidate. For Wave 2, set the zone to [p1 − Wave 2 deep retracement × (p1 − p2), p1 − Wave 2 shallow retracement × (p1 − p2)]. For Wave 4, set L1 = p3 − p4 and L3 = p1 − p2, then set the zone to [max(p1 − Wave 4 deep retracement × L3, p3), p1 − Wave 4 shallow retracement × L3]. For Wave C, set A = p3 − p2 and r = (p1 − p2) / A; if r >= the flat cutoff, set the zone to [p2 − flat target fraction × A, p2], otherwise set it to [p1 − deeper zigzag projection × A, p1 − shallower zigzag projection × A]. For Wave 5, set L1 = p4 − p5 and L3 = p2 − p3; if L3 / L1 >= the third-wave extension threshold, set the zone to [p1 + extended target lower fraction × L1, p1 + extended target upper fraction × L1]; otherwise set t1 = p1 + first target factor × L1 and t2 = p1 + alternate target factor × (p2 − p5), then set the zone to [min(t1,t2), max(t1,t2)]. If L3 < L1, cap the zone high at min(zone high, p1 + Wave 5 cap fraction × L3) and set the zone low to min(zone low, zone high).
Long: Wave state is Wave 2, Wave 4, or Wave C AND close >= trade zone low AND close <= trade zone high AND bullish reversal candle
Short: Bear mode is inactive AND main zigzag direction is falling AND n >= 5 AND p1 < p3 < p5 AND p2 < p4 AND extP < p2
Exit: Long, Wave state is Wave 5 AND close >= trade zone low AND bearish reversal candle
Exit: Short, bear mode is active AND close > bear mode break level
