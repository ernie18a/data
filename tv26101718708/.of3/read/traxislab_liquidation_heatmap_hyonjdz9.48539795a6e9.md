Calculation: Volatility = ATR(chart bars, lookback parameter), falling back to close × fallback-fraction parameter when unavailable
Calculation: Active liquidation zones = on chart bars, compute pivot highs and lows from selected-source high and low using the same pivot-lookback parameter on both sides; use the current T1 bar, still forming, sampled on chart bars when the selected source uses T1, and chart high/low when the selected source is unavailable or is the chart. For each confirmed pivot and each configured leverage parameter, create a zone centered at pivot high × (1 + 1 / leverage) or pivot low × (1 - 1 / leverage). On each bar, use half of current volatility × zone-height parameter as the hit half-width; remove short zones when high >= center - hit half-width, long zones when low <= center + hit half-width, or either type when its age in chart bars > maximum-age parameter.
Calculation: Liquidation clusters = traverse active zones in insertion order; each unassigned zone seeds a cluster with itself and every other unassigned zone whose center is at an absolute distance < volatility × cluster-radius parameter from the seed center. Mark members assigned; cluster count is its number of zones and cluster center is their mean center.
Long: any liquidation cluster has count >= minimum-cluster-count parameter AND center < close AND absolute distance from center to close < volatility × proximity parameter
Short: any liquidation cluster has count >= minimum-cluster-count parameter AND center > close AND absolute distance from center to close < volatility × proximity parameter
