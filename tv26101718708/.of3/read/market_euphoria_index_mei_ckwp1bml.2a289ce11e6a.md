Calculation: MEI = (RSI euphoria score + VWAP euphoria score + bullish-candle percentage) / 3 - (RSI panic score + VWAP panic score + bearish-candle percentage) / 3, where RSI euphoria score = if RSI(close, RSI lookback) > upper RSI threshold then the percentage of the RSI range from the upper RSI threshold to its maximum, else 0; RSI panic score = if RSI(close, RSI lookback) < lower RSI threshold then the percentage of the RSI range from its minimum to the lower RSI threshold, else 0; VWAP euphoria score = 100% if close - VWAP(hlc3) > VWAP stretch multiplier * ATR(lookback), else 0; VWAP panic score = 100% if close - VWAP(hlc3) < -VWAP stretch multiplier * ATR(lookback), else 0; bullish-candle percentage = 100% * SUM(close > open ? 1 : 0, lookback) / lookback; bearish-candle percentage = 100% * SUM(close < open ? 1 : 0, lookback) / lookback
Long: (MEI > standard MEI threshold AND MEI <= extreme MEI threshold) OR MEI < -extreme MEI threshold
Short: MEI > extreme MEI threshold OR (MEI >= -extreme MEI threshold AND MEI < -standard MEI threshold)
