Calculation: Bias(T) = set to bullish when the requested T close is above the latest confirmed T pivot high, set to bearish when below the latest confirmed T pivot low, and otherwise retain its prior direction; pivots use the HTF pivot lookback and are calculated on T bars, while comparisons run on chart bars using requested T values with lookahead off (the forming T bar in realtime and the last completed T bar historically)
Long: Bias(T1) = bullish OR Bias(T2) = bullish
Short: Bias(T1) = bearish OR Bias(T2) = bearish
Calculation: BOS direction = bullish when a bullish BOS within the BOS recency parameter is more recent than a bearish BOS or no bearish BOS is within that window; bearish when a bearish BOS within that window is more recent or no bullish BOS is within it; otherwise neutral. A bullish BOS is close crossing above the latest confirmed pivot high using the chart swing pivot lookback, then that level resets to the breakout bar high until another pivot high confirms; a bearish BOS is the corresponding cross below the latest confirmed pivot low, resetting the level to the breakout bar low.
Calculation: FVG direction = direction of the most recent bullish or bearish FVG within the FVG recency parameter, or neutral if neither occurred; bullish if the bullish FVG is more recent or no bearish FVG occurred, otherwise bearish. A bullish FVG is low > high[FVG gap lookback] AND low - high[FVG gap lookback] >= FVG minimum size multiple × ATR(ATR lookback), using the ATR fallback parameter when ATR is unavailable; a bearish FVG is low[FVG gap lookback] > high AND low[FVG gap lookback] - high >= the same minimum size.
Calculation: Order block touch = (the latest bullish order block is within BOS recency + order block search lookback bars of its source candle AND low <= its high AND close >= its low) OR (the latest bearish order block is within that same age AND high >= its low AND close <= its high). At each bullish BOS, the bullish block is the nearest bearish candle among the preceding order block search lookback bars; at each bearish BOS, the bearish block is the nearest bullish candle in that range.
Long: Bias(T1) = bullish AND Bias(T2) = bullish AND BOS direction = bullish AND (FVG direction = bullish OR Order block touch)
Short: Bias(T1) = bearish AND Bias(T2) = bearish AND BOS direction = bearish AND (FVG direction = bearish OR Order block touch)
