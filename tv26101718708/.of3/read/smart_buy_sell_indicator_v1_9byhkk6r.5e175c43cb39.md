Calculation: Short-lookback average = selected EMA or SMA of close with shorter lookback
Calculation: Long-lookback average = selected EMA or SMA of close with longer lookback, using the same selected type as the short-lookback average
Calculation: Relative strength index = RSI(close, lookback)
Long: short-lookback average crosses above long-lookback average AND relative strength index >= long-entry RSI threshold
Short: short-lookback average crosses below long-lookback average AND relative strength index <= short-entry RSI threshold
