Calculation: ZLS(source, lookback, regression offset) = linreg(source, lookback, regression offset) + (linreg(source, lookback, regression offset) - linreg(linreg(source, lookback, regression offset), lookback, regression offset)
Calculation: Range map(value, range low, range high) = 2 * (value - range low) / (range high - range low) - 1, or 0 when range high equals range low
Calculation: Smoothed angle = SMA(atan((ZLS(hlc3, TA3 lookback) - ZLS(hlc3, TA3 lookback)[1]) / ZLS(hlc3, TA3 lookback)[1]), shorter angle lookback)
Calculation: TA3 price-angle score = average(Range map(Smoothed angle, lowest(Smoothed angle, TA3 lookback), highest(Smoothed angle, TA3 lookback)), Range map(ZLS(hlc3, TA3 lookback), lowest(ZLS(hlc3, TA3 lookback), TA3 lookback), highest(ZLS(hlc3, TA3 lookback), TA3 lookback)))
Calculation: Box breakout = high > highest(high, base box lookback)[1]
Calculation: Box setup = barssince(Box breakout) equals box persistence length less the box event-age offset AND highest(high, shorter box lookback) < highest(high, intermediate box lookback), where shorter < intermediate < base box lookback
Calculation: Box upper line = linreg(valuewhen(Box setup, valuewhen(Box breakout, high, most recent occurrence), most recent occurrence), base box lookback, regression offset)
Calculation: Box lower line = linreg(valuewhen(Box setup, lowest(low, base box lookback), most recent occurrence), base box lookback, regression offset)
Calculation: TA3 box score = average(Range map(Box upper line, lowest(min(Box upper line, Box lower line), TA3 lookback), highest(max(Box upper line, Box lower line), TA3 lookback)), Range map(Box lower line, lowest(min(Box upper line, Box lower line), TA3 lookback), highest(max(Box upper line, Box lower line), TA3 lookback)))
Calculation: Signed directional EMA = EMA((R(+DM) - R(-DM)) / (R(+DM) + R(-DM)), directional smoothing lookback), or 0 when the denominator is 0; R(x) recursively equals its prior value minus its prior value divided by directional smoothing lookback plus x, initialized at 0
Long: TA3 price-angle score crosses above TA3 box score AND (Signed directional EMA >= 0 OR (Signed directional EMA two bars ago < 0 AND Signed directional EMA two bars ago < Signed directional EMA one bar ago AND Signed directional EMA one bar ago < Signed directional EMA))
Short: TA3 price-angle score crosses below TA3 box score AND (Signed directional EMA <= 0 OR (Signed directional EMA two bars ago > 0 AND Signed directional EMA two bars ago > Signed directional EMA one bar ago AND Signed directional EMA one bar ago > Signed directional EMA))
