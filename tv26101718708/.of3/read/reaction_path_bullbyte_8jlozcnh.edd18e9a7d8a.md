Calculation: Wick-weighted Fair Price and half-band = over the fair/volume lookback chart bars, weight each Weighted Close by 1 minus abs(close-open)/(high-low), using a body/range ratio of 1 when range is zero; Fair Price is the weighted mean (falling back to the newest Weighted Close when total weight is zero), and half-band is the weighted mean absolute deviation from Fair Price (falling back to abs(newest close-Fair Price) times the half-band fallback fraction and floored at minimum tick times the band tick floor multiplier).
Calculation: Pressure Centre = over the pressure lookback chart bars, the weighted mean of (close-low)/(high-low), weighted by 1 minus abs(close-open)/(high-low); use close location 0.5 and body/range ratio 1 for zero ranges, and return 0.5 if total weight is zero.
Calculation: Current and previous pressure migration = Pressure Centre - Pressure Centre[pressure migration lag], and Pressure Centre[1] - Pressure Centre[pressure migration lag + 1], respectively.
Calculation: Displacement = (close - Fair Price) / Fair Price half-band.
Calculation: Long and short directional efficiency = mean abs(close-open)/(high-low) among the last short candle lookback chart bars closing respectively above or below their opens, using 1 for a zero-range bar and 0 if there are no qualifying bars; directional dominance = the corresponding qualifying bar count divided by the short candle lookback.
Calculation: Depth below Fair Price = max of 0 and (Fair Price-low[i])/Fair Price half-band for i from 1 through the short candle lookback; depth above Fair Price = max of 0 and (high[i]-Fair Price)/Fair Price half-band over the same bars.
Calculation: Speed ratio = current high-low divided by the mean high-low of the previous short candle lookback chart bars, using current high-low if that mean is zero and ratio 1 if the divisor is zero.
Calculation: Volume ratio = current volume divided by mean volume of the previous fair/volume lookback chart bars, using ratio 1 if the divisor is zero; use ratio 1 instead whenever the coefficient of variation of volume over the current fair/volume lookback bars is not greater than the volume reliability threshold.
Calculation: Bar efficiency = abs(close-open)/(high-low), using 1 for zero range; upper and lower wick ratios = (high-max(open,close))/(high-low) and (min(open,close)-low)/(high-low), using 0 for zero range. Normal bar = not (current range > spike range multiplier times mean previous short-window range AND bar efficiency < spike efficiency threshold) AND not (previous range > spike range multiplier times that same mean range AND abs(previous close-previous open)/max(previous range, minimum tick) < spike efficiency threshold AND current close is within the previous bar's high-low range).
Calculation: New expansion = current high-low >= maximum high-low of the previous short candle lookback bars AND current high-low >= ATR(ATR lookback) times the ATR expansion floor.
Calculation: Effective reaction displacement threshold = base reaction displacement threshold / setup sensitivity + failure count times displacement increase per failure; effective directional efficiency threshold = base reaction efficiency threshold times setup sensitivity + failure count times efficiency increase per failure; effective speed threshold = base speed threshold times setup sensitivity + failure count times speed increase per failure; effective depth threshold = base depth threshold / setup sensitivity + failure count times depth increase per failure; effective volume threshold = base volume threshold times setup sensitivity + failure count times volume increase per failure. Base continuation wick threshold = continuation wick threshold / setup sensitivity; ATR expansion floor = base expansion floor / setup sensitivity; trend efficiency threshold = base trend efficiency threshold times setup sensitivity; stall threshold = base stall threshold times setup sensitivity.
Calculation: Exhaustion = Pressure Centre >= upper exhaustion boundary OR Pressure Centre <= lower exhaustion boundary. Reversing = not Exhaustion AND ((current migration >= stall threshold AND previous migration <= -stall threshold) OR (current migration <= -stall threshold AND previous migration >= stall threshold)). Approaching build = Pressure Centre >= build boundary minus build approach distance AND Pressure Centre < build boundary AND Pressure Centre > Pressure Centre[pressure migration lag]. Building = not Exhaustion AND not Reversing AND (Approaching build OR Pressure Centre >= build boundary) AND current migration > 0.
Calculation: Migrating up = not Exhaustion AND not Reversing AND not Building AND current migration > stall threshold. Migrating down = not Exhaustion AND not Reversing AND not Building AND not Migrating up AND current migration < -stall threshold. Pressure up = current migration > 0 AND (Migrating up OR Building OR Reversing). Pressure down = current migration < 0 AND (Migrating down OR Reversing). Continuation pressure up = current migration > 0 AND (Building OR Migrating up). Continuation pressure down = current migration < 0 AND Migrating down.
Calculation: Long continuation bar gate = close > Fair Price + Fair Price half-band AND New expansion AND upper wick ratio < base continuation wick threshold AND Bar efficiency > minimum continuation body-to-range ratio AND Speed ratio >= base speed threshold times setup sensitivity AND Volume ratio >= base volume threshold times setup sensitivity AND close > close[trend lookback] AND Efficiency Ratio(close, trend lookback) >= base trend efficiency threshold times setup sensitivity AND Normal bar. Short continuation bar gate mirrors this with close < Fair Price - Fair Price half-band, lower wick ratio, close < close[trend lookback], and the same Efficiency Ratio threshold.
Calculation: Failure count starts at zero, increases by one on invalidation up to the maximum failure count, and resets on Path Level 2 completion or when bars since the last invalidation exceed the failure memory window.
Calculation: Failure behaviour reset while failed-environment memory is active = abs(Displacement) < memory displacement reset threshold OR abs(current migration) < memory migration reset threshold OR (failed direction long AND current migration < -memory migration reset threshold) OR (failed direction short AND current migration > memory migration reset threshold) OR current range/ATR > stored failed range/ATR times the memory range expansion factor; failed range/ATR is the invalidation-bar range divided by its ATR. Memory also expires when bars since invalidation exceed the failure memory window.
Calculation: Rearm is initially ready and becomes ready on Path Level 2 completion; after invalidation it remains unready until Failure behaviour reset, and remains unready if memory expires first without that reset.
Calculation: A signal locks its direction and family until its reset condition. A long Reaction lock resets when Displacement > reaction lock reset distance AND current migration <= 0; a short Reaction lock resets when Displacement < -reaction lock reset distance AND current migration >= 0. A long Continuation lock resets when close <= Fair Price + Fair Price half-band AND current migration <= -stall threshold; a short Continuation lock resets when close >= Fair Price - Fair Price half-band AND current migration >= stall threshold.
Calculation: At signal, entry price = signal-bar close; Path Level 2 = entry price plus the position-side sign times the Path Level 2 ATR distance times signal-bar ATR. Reaction invalidation = signal-bar low minus that ATR times the reaction invalidation ATR distance for long, or signal-bar high plus it for short; Continuation invalidation = signal-bar Fair Price. While an active setup remains open, each confirmed bar with continuation enabled, a same-direction base continuation bar gate, matching continuation pressure, and extension count below the maximum extends Path Level 2 by position-side sign times the Path Level 1 ATR distance times current ATR.
Long: On a confirmed chart bar, with no active setup, rearm ready, no setup closed on this bar, Reaction enabled, and no locked long Reaction event; Displacement < -effective reaction displacement threshold AND long directional efficiency >= effective directional efficiency threshold AND long directional dominance >= minimum directional dominance AND lower wick > upper wick AND Speed ratio >= effective speed threshold AND Volume ratio >= effective volume threshold AND depth below Fair Price >= effective depth threshold AND Normal bar AND Pressure up.
Short: On a confirmed chart bar, with no active setup, rearm ready, no setup closed on this bar, Reaction enabled, and no locked short Reaction event; Displacement > effective reaction displacement threshold AND short directional efficiency >= effective directional efficiency threshold AND short directional dominance >= minimum directional dominance AND upper wick > lower wick AND Speed ratio >= effective speed threshold AND Volume ratio >= effective volume threshold AND depth above Fair Price >= effective depth threshold AND Normal bar AND Pressure down.
Long: On a confirmed chart bar, with no active setup, rearm ready, no setup closed on this bar, Continuation enabled, and no locked long Continuation event; Long continuation bar gate AND Speed ratio >= effective speed threshold AND Volume ratio >= effective volume threshold AND Continuation pressure up.
Short: On a confirmed chart bar, with no active setup, rearm ready, no setup closed on this bar, Continuation enabled, and no locked short Continuation event; Short continuation bar gate AND Speed ratio >= effective speed threshold AND Volume ratio >= effective volume threshold AND Continuation pressure down.
Exit: long, on a confirmed bar, low <= active setup invalidation level.
Exit: long, on a confirmed bar, low > active setup invalidation level AND high >= active Path Level 2.
Exit: short, on a confirmed bar, high >= active setup invalidation level.
Exit: short, on a confirmed bar, high < active setup invalidation level AND low <= active Path Level 2.
