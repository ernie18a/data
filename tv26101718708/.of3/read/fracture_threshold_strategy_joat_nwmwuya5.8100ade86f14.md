Calculation: SessionMinute = hour(datetime, session timezone) * 60 + minute(datetime, session timezone)
Calculation: BullAlignmentScore = count of true among (EMA(close, fast EMA lookback) > EMA(close, slow EMA lookback)), (RSI(close, RSI lookback) > RSI threshold), (close > EMA(close, trend EMA lookback)), (EMA(close, trend EMA lookback) > SMA(close, mid SMA lookback)), (SMA(close, mid SMA lookback) > EMA(close, intermediate EMA lookback)), (EMA(close, intermediate EMA lookback) > EMA(close, longer intermediate EMA lookback)), (close > EMA(close, long-term EMA lookback))
Calculation: BearAlignmentScore = count of true among (EMA(close, fast EMA lookback) < EMA(close, slow EMA lookback)), (RSI(close, RSI lookback) < RSI threshold), (close < EMA(close, trend EMA lookback)), (EMA(close, trend EMA lookback) < SMA(close, mid SMA lookback)), (SMA(close, mid SMA lookback) < EMA(close, intermediate EMA lookback)), (EMA(close, intermediate EMA lookback) < EMA(close, longer intermediate EMA lookback)), (close < EMA(close, long-term EMA lookback))
Calculation: VolumeRatio = EMA(SMA(volume, shorter volume lookback) / max(SMA(volume, longer volume lookback), volume floor), volume smoothing lookback)
Calculation: StopDistance = ATR(ATR lookback) * stop multiple, evaluated on the entry bar
Long: EMA(close, fast EMA lookback) crosses above EMA(close, slow EMA lookback) AND BullAlignmentScore >= minimum alignment score AND VolumeRatio >= minimum volume ratio AND (session filter disabled OR (window A enabled AND SessionMinute >= window A start AND SessionMinute < window A end) OR (window B enabled AND SessionMinute >= window B start AND SessionMinute < window B end)) AND position side is flat
Short: EMA(close, fast EMA lookback) crosses below EMA(close, slow EMA lookback) AND BearAlignmentScore >= minimum alignment score AND VolumeRatio >= minimum volume ratio AND (session filter disabled OR (window A enabled AND SessionMinute >= window A start AND SessionMinute < window A end) OR (window B enabled AND SessionMinute >= window B start AND SessionMinute < window B end)) AND position side is flat
Long: BullAlignmentScore >= minimum alignment score
Short: BearAlignmentScore >= minimum alignment score
Exit: long, low <= entry price - StopDistance OR high >= entry price + reward-to-risk ratio * StopDistance
Exit: short, high >= entry price + StopDistance OR low <= entry price - reward-to-risk ratio * StopDistance
