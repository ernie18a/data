Calculation: Selected MA = SMA, EMA, WMA, Hull MA, VWMA, RMA, or TEMA of the selected source over its lookback; each of the four chart MAs and four T1 MAs has its own type and lookback parameter. T1 MAs are calculated on T1 bars using the still-forming T1 bar, and their values are read on chart bars.
Calculation: MACD line and signal line = MACD of the selected source using separate fast and slow lookbacks, a shared SMA-or-EMA choice for the fast and slow averages, a separate signal lookback, and an independent SMA-or-EMA signal-average choice. Chart values use chart bars; T3 values are calculated on T3 bars using the still-forming T3 bar and read on chart bars.
Calculation: RSI filter = RSI(selected source, RSI lookback) > chart lower threshold AND RSI(selected source, same RSI lookback) <= chart upper threshold AND RSI(selected source, same RSI lookback) on the still-forming T2 bar > T2 lower threshold AND RSI(selected source, same RSI lookback) on the still-forming T2 bar <= T2 upper threshold; T2 RSI is calculated on T2 bars and read on chart bars. The chart and T2 RSI use the same lookback; their thresholds are separate parameters. T1, T2, and T3 are independent timeframe parameters.
Calculation: Long trigger = chart-bar datetime is within the selected inclusive date window AND the selected entry condition (first chart MA > second chart MA; selected source > first chart MA; RSI filter; MACD line > signal line; MACD line > 0; or signal line > 0) AND the selected chart extra condition (none; MACD line > signal line; MACD line > 0; signal line > 0; or MACD histogram[1] < 0 AND MACD histogram > MACD histogram[1]) AND the selected second extra condition (none; T3 MACD line > signal line; T3 MACD line > 0; T3 signal line > 0; first T1 MA > second T1 MA; or T1 close > first T1 MA) AND RSI filter unless RSI filter is the selected entry condition. T3 MACD and signal values and T1 close are from their still-forming bars and are read on chart bars. The MA lookbacks and types are independently selected.
Calculation: Short trigger = NOT long trigger if the selected short condition is NOT long trigger; otherwise chart-bar datetime is within the selected inclusive date window AND the selected short condition (third chart MA <= fourth chart MA; selected source <= third chart MA; RSI filter; MACD line <= signal line; MACD line <= 0; or signal line <= 0) AND the selected chart extra condition (none; MACD line <= signal line; MACD line <= 0; signal line <= 0; or MACD histogram[1] > 0 AND MACD histogram < MACD histogram[1]) AND the selected second extra condition (none; T3 MACD line <= signal line; T3 MACD line <= 0; T3 signal line <= 0; third T1 MA <= fourth T1 MA; or T1 close <= third T1 MA) AND RSI filter unless RSI filter is the selected short condition. T3 MACD and signal values and T1 close are from their still-forming bars and are read on chart bars. The MA lookbacks and types are independently selected.
Calculation: Long stop/target flag = long-enabled mode AND long trigger[1] AND (low <= entry price[1] × (1 − stop-loss percentage parameter / 100) OR high >= entry price[1] × (1 + take-profit percentage parameter / 100)).
Calculation: Short stop/target flag = short-enabled mode AND short trigger[1] AND (high >= entry price[1] × (1 + stop-loss percentage parameter / 100) OR low <= entry price[1] × (1 − take-profit percentage parameter / 100)).
Long: mode is Long Only or Long & Short AND long trigger AND (NOT long trigger[1] OR long stop/target flag[1] OR short stop/target flag[1]).
Short: mode is Short Only or Long & Short AND short trigger AND (NOT short trigger[1] OR long stop/target flag[1] OR short stop/target flag[1]).
Exit: long, low <= entry price × (1 − stop-loss percentage parameter / 100) OR high >= entry price × (1 + take-profit percentage parameter / 100).
Exit: short, high >= entry price × (1 + stop-loss percentage parameter / 100) OR low <= entry price × (1 − take-profit percentage parameter / 100).
