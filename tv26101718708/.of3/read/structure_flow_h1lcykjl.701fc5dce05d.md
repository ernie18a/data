Calculation: Calendar-anchored VWAP = cumulative(HLC3 × volume, reset at calendar-year boundaries) ÷ cumulative(volume, reset at calendar-year boundaries), substituting the VWAP missing-volume fallback parameter for missing volume; use HLC3 if cumulative volume is zero.
Calculation: Bullish stack = EMA(close, long-term lookback) > calendar-anchored VWAP AND close > both.
Calculation: Bearish stack = EMA(close, long-term lookback) < calendar-anchored VWAP AND close < both.
Calculation: Normalized volume pressure = EMA((((close - low) ÷ max(high - low, minimum tick)) × flow-safe volume) - (((high - close) ÷ max(high - low, minimum tick)) × flow-safe volume), flow lookback) ÷ max(EMA(flow-safe volume, flow lookback), minimum volume denominator), where flow-safe volume substitutes the flow missing-volume fallback parameter for missing volume.
Calculation: Bullish BOS event = on a confirmed chart bar, the latest confirmed pivot high (using the pivot lookback on both sides) is higher than the preceding confirmed pivot high, close > latest pivot high + ATR(ATR lookback) × BOS buffer parameter, and either no prior bullish BOS pivot level exists or its distance from the latest pivot high exceeds one minimum tick; this raw condition was false on the preceding chart bar. Record the latest pivot high as the prior bullish BOS pivot level when the event occurs.
Calculation: Bearish BOS event = on a confirmed chart bar, the latest confirmed pivot low (using the pivot lookback on both sides) is lower than the preceding confirmed pivot low, close < latest pivot low - ATR(ATR lookback) × BOS buffer parameter, and either no prior bearish BOS pivot level exists or its distance from the latest pivot low exceeds one minimum tick; this raw condition was false on the preceding chart bar. Record the latest pivot low as the prior bearish BOS pivot level when the event occurs.
Calculation: Bullish OB zone = on each bullish BOS event, search the preceding chart bars up to min(max(OB search lookback, pivot lookback × search-floor multiplier), search cap). From bearish candles whose absolute body divided by max(high - low, minimum tick) meets the OB body threshold, choose the candle with the lowest score: distance weight × abs(candle high - latest pivot high) + range weight × candle range + wick weight × upper wick - body weight × body - departure weight × max(current close - candle high, zero). Ties select the most recent candle. Set the zone to that candle's low and high; clear it if no candidate exists. The zone is active only while OB display is enabled, it has not expired after the OB extension bars, it has not been hidden by the enabled far-distance rule (distance from close to zone midpoint > ATR × maximum-distance parameter), and it has not been mitigated. Mitigation is low < zone low in wick mode or close < zone low in close-through mode; a new bullish BOS resets mitigation.
Calculation: Bearish OB zone = on each bearish BOS event, search the preceding chart bars up to min(max(OB search lookback, pivot lookback × search-floor multiplier), search cap). From bullish candles whose absolute body divided by max(high - low, minimum tick) meets the OB body threshold, choose the candle with the lowest score: distance weight × abs(candle low - latest pivot low) + range weight × candle range + wick weight × lower wick - body weight × body - departure weight × max(candle low - current close, zero). Ties select the most recent candle. Set the zone to that candle's low and high; clear it if no candidate exists. The zone is active only while OB display is enabled, it has not expired after the OB extension bars, it has not been hidden by the enabled far-distance rule (distance from close to zone midpoint > ATR × maximum-distance parameter), and it has not been mitigated. Mitigation is high > zone high in wick mode or close > zone high in close-through mode; a new bearish BOS resets mitigation.
Calculation: ATR base = EMA(ATR(ATR lookback), width lookback).
Calculation: EMA-to-VWAP gap base = EMA(abs(EMA(close, long-term lookback) - calendar-anchored VWAP), width lookback).
Calculation: Trail = EMA(EMA(raw trail, trail smoothing), edge smoothing), where raw trail is max(EMA, calendar-anchored VWAP) in a bullish stack, min(EMA, calendar-anchored VWAP) in a bearish stack, EMA when chart timeframe <= T2 and gap base > ATR base × maximum-gap parameter, and otherwise the arithmetic mean of EMA and calendar-anchored VWAP.
Calculation: Smoothed zone width = EMA(zone width, edge smoothing), where gap cap = ATR base × maximum-gap parameter; used gap = min(gap base, gap cap); gap weight = min(zone-gap parameter, lower-timeframe gap weight) when chart timeframe <= T2 and otherwise the zone-gap parameter; raw width = ATR base × zone-width parameter + used gap × gap weight; width floor = ATR base × (minimum-zone-floor parameter + lower-timeframe floor boost when chart timeframe <= T2); base width = max(raw width, width floor); zone width is base width on the first bar and otherwise max(base width, prior zone width × (one minus the compression-step parameter)).
Calculation: Support band = [EMA(trail - smoothed zone width × outer-band parameter, edge smoothing), EMA(trail - smoothed zone width × inner-band parameter, edge smoothing)].
Calculation: Resistance band = [EMA(trail + smoothed zone width × inner-band parameter, edge smoothing), EMA(trail + smoothed zone width × outer-band parameter, edge smoothing)].
Calculation: Market active = (close != 0 ? ATR(ATR lookback) ÷ close : zero) >= minimum ATR percentage × lower-timeframe relaxation factor when chart timeframe <= T2, and >= minimum ATR percentage otherwise.
Calculation: Location tolerance = ATR(ATR lookback) × location-tolerance parameter.
Calculation: Long location = location gate disabled OR the chart bar's range overlaps the active bullish OB zone expanded by location tolerance OR overlaps the latest confirmed pivot high expanded by location tolerance OR overlaps the support band expanded by location tolerance × band-tolerance ratio OR overlaps calendar-anchored VWAP expanded by location tolerance. A level overlap means low <= level + tolerance AND high >= level - tolerance; a zone overlap means high >= zone bottom - tolerance AND low <= zone top + tolerance.
Calculation: Short location = location gate disabled OR the chart bar's range overlaps the active bearish OB zone expanded by location tolerance OR overlaps the latest confirmed pivot low expanded by location tolerance OR overlaps the resistance band expanded by location tolerance × band-tolerance ratio OR overlaps calendar-anchored VWAP expanded by location tolerance.
Calculation: Full-tier long setup = market active AND long location AND bullish stack AND bullish BOS event AND confirmed chart-bar normalized volume pressure > delta threshold AND confirmed chart-bar RVOL(volume, RVOL lookback, zero-average fallback) >= RVOL threshold AND (HTF filter disabled OR T1 is valid and its last completed bar's close > EMA(close, long-term lookback, T1, last completed bar)). Calculate the T1 EMA on T1 bars and place its last completed value on chart bars; T1 must be higher than the chart timeframe.
Calculation: Full-tier short setup = market active AND short location AND bearish stack AND bearish BOS event AND confirmed chart-bar normalized volume pressure < -delta threshold AND confirmed chart-bar RVOL(volume, RVOL lookback, zero-average fallback) >= RVOL threshold AND (HTF filter disabled OR T1 is valid and its last completed bar's close < EMA(close, long-term lookback, T1, last completed bar)). Calculate the T1 EMA on T1 bars and place its last completed value on chart bars; T1 must be higher than the chart timeframe.
Calculation: Signal cooldown passed = no prior full-tier or B-tier long or short signal exists, or the number of chart bars since the most recent such signal is >= cooldown parameter.
