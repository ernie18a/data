VWMO = if VWMA(close, VWMO lookback)[VWMO lookback] is nonzero, (VWMA(close, VWMO lookback) - VWMA(close, VWMO lookback)[VWMO lookback]) / VWMA(close, VWMO lookback)[VWMO lookback] × 100; otherwise zero.
Cumulative Delta = cumulative sum of volume when close > close[1], negative volume when close < close[1], and zero when close = close[1].
Momentum Score = price score + RSI score + VWMO score + ADX score + stochastic score + CCI score + MFI score + volatility score + cumulative-delta score. Price score: if close > SMA(close, SMA lookback), EMA(close, EMA lookback), and session VWAP, use price-above score; else if close is below all three, use price-below score; otherwise use mixed-price score. RSI score: if RSI(close, RSI lookback) > RSI overbought threshold, use RSI-overbought score; else if RSI < RSI oversold threshold, use RSI-oversold score; else if RSI > RSI midpoint, use RSI-above-midpoint score; otherwise use RSI-below-midpoint score. VWMO score: if VWMO > VWMO upper threshold, use VWMO-high score; else if VWMO < VWMO lower threshold, use VWMO-low score; else if VWMO > VWMO midpoint, use VWMO-above-midpoint score; otherwise use VWMO-below-midpoint score. ADX score: if ADX(DI lookback, same smoothing lookback) > ADX high threshold, use ADX-high score; else if ADX > ADX lower threshold, use ADX-middle score; otherwise use ADX-low score. Stochastic score: if Stochastic(close, high, low, stochastic lookback) > stochastic overbought threshold, use stochastic-overbought score; else if it < stochastic oversold threshold, use stochastic-oversold score; else if it > stochastic midpoint, use stochastic-above-midpoint score; otherwise use stochastic-below-midpoint score. CCI score: if CCI(close, CCI lookback) > CCI overbought threshold, use CCI-overbought score; else if CCI < CCI oversold threshold, use CCI-oversold score; else if CCI > CCI midpoint, use CCI-above-midpoint score; otherwise use CCI-below-midpoint score. MFI score: if MFI(MFI lookback) > MFI high threshold, use MFI-high score; else if MFI < MFI low threshold, use MFI-low score; else if MFI > MFI midpoint, use MFI-above-midpoint score; otherwise use MFI-below-midpoint score. Volatility score: if ATR(main ATR lookback) > SMA(ATR(main ATR lookback), volatility-average lookback) × high-volatility multiplier, use high-volatility score; else if ATR < that average × low-volatility multiplier, use low-volatility score; otherwise use medium-volatility score. Cumulative-delta score: if cumulative delta > cumulative delta[1], use rising-delta score; else if cumulative delta < cumulative delta[1], use falling-delta score; otherwise use unchanged-delta score. Each distinct threshold, midpoint, score, lookback, and multiplier is a separate parameter.
Long: Momentum Score < low-score threshold AND CCI(close, CCI lookback) crosses above long-entry CCI threshold AND daily entry count is below daily trade limit AND (session filter is disabled OR current bar is in the configured session).
Short: Momentum Score > high-score lower threshold AND Momentum Score < high-score upper threshold AND CCI(close, CCI lookback) crosses below short-entry CCI threshold AND daily entry count is below daily trade limit AND (session filter is disabled OR current bar is in the configured session).
Exit: Long, low <= the maximum of entry price × (1 − hard-stop percentage), entry price + ATR(main ATR lookback) × breakeven offset when breakeven is enabled and close − entry price >= ATR(main ATR lookback) × breakeven trigger, and close − ATR(main ATR lookback, trailing ATR lookback) × trailing distance when trailing is enabled and close − entry price >= ATR(trailing ATR lookback) × trailing trigger; OR high >= entry price + ATR(main ATR lookback) × target multiplier; OR force-flat is enabled, session filtering is enabled, and the prior bar was in the configured session while the current bar is outside it.
Exit: Short, high >= the minimum of entry price × (1 + hard-stop percentage), entry price − ATR(main ATR lookback) × breakeven offset when breakeven is enabled and entry price − close >= ATR(main ATR lookback) × breakeven trigger, and close + ATR(trailing ATR lookback) × trailing distance when trailing is enabled and entry price − close >= ATR(trailing ATR lookback) × trailing trigger; OR low <= entry price − ATR(main ATR lookback) × target multiplier; OR force-flat is enabled, session filtering is enabled, and the prior bar was in the configured session while the current bar is outside it.
