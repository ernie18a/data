Calculation: Theil-Sen channel = over the lookback bars, slope is the median of all pairwise close changes per bar; midpoint is the median fitted value at the current bar; MAD is the median absolute residual from the fitted line; upper and lower rails are midpoint ± rail-width parameter × MAD; upper and lower invalidation levels are midpoint ± invalidation-width parameter × MAD
Calculation: EVT stop distance = if the POT-GPD tail quantile of absolute log(close / close[1]) over the return lookback, using the threshold-percentile and tail-quantile parameters, is available and positive, tail quantile × close × sqrt(holding-horizon parameter); otherwise ATR(close, high, low, ATR fallback length) × ATR fallback multiplier
Calculation: Volume Profile levels = assign each bar's volume to the bin containing (high + low + close) / 3, across bins spanning the highest high and lowest low over the profile lookback; POC is the midpoint of the highest-volume bin, and VAH/VAL bound the value area expanded from POC toward the adjacent bin with greater volume until it contains the value-area percentage of total volume
Calculation: Long stop distance = max(EVT stop distance, max(0, close − lower channel rail), volume-profile distance), where volume-profile distance is close − VAL only when profile display and stop anchoring are enabled, volume exists, VAL < close, and close − VAL ≤ VP stop-cap parameter × EVT stop distance; otherwise it is 0
Calculation: Short stop distance = max(EVT stop distance, max(0, upper channel rail − close), volume-profile distance), where volume-profile distance is VAH − close only when profile display and stop anchoring are enabled, volume exists, VAH > close, and VAH − close ≤ VP stop-cap parameter × EVT stop distance; otherwise it is 0
Calculation: Active stop level = if Theil-Sen slope > 0 then close − Long stop distance else close + Short stop distance
Calculation: Active target 1 = if Theil-Sen slope > 0 then, when VP target mode is enabled, volume exists, and VAH > close, POC if POC > close else VAH; otherwise close + target-1 R parameter × Long stop distance; if slope ≤ 0 then, when VP target mode is enabled, volume exists, and VAL < close, POC if POC < close else VAL; otherwise close − target-1 R parameter × Short stop distance
Calculation: Active target 2 = if Theil-Sen slope > 0 then, when VP target mode is enabled, volume exists, and VAH > close, VAH; otherwise close + target-2 R parameter × Long stop distance; if slope ≤ 0 then, when VP target mode is enabled, volume exists, and VAL < close, VAL; otherwise close − target-2 R parameter × Short stop distance
Calculation: Active invalidation level = if Theil-Sen slope > 0 then lower invalidation level else upper invalidation level
Long: Theil-Sen slope > 0
Short: Theil-Sen slope ≤ 0
Exit: long, Theil-Sen slope > 0 AND ((low ≤ Active stop level AND low[1] > Active stop level[1]) OR (high ≥ Active target 1 AND high[1] < Active target 1[1]) OR (high ≥ Active target 2 AND high[1] < Active target 2[1]) OR (low ≤ Active invalidation level AND low[1] > Active invalidation level[1]))
Exit: short, Theil-Sen slope ≤ 0 AND ((high ≥ Active stop level AND high[1] < Active stop level[1]) OR (low ≤ Active target 1 AND low[1] > Active target 1[1]) OR (low ≤ Active target 2 AND low[1] > Active target 2[1]) OR (high ≥ Active invalidation level AND high[1] < Active invalidation level[1]))
