Calculation: T1 bias = on chart bars, use the latest available T1 high and low (the T1 bar still forming in realtime, completed T1 values historically), mapped to chart bars; evaluate the following lookbacks on chart bars: HH = mapped high > highest(mapped high, bias lookback)[1], LL = mapped low < lowest(mapped low, bias lookback)[1], HL = mapped low > lowest(mapped low, bias lookback)[1] AND NOT LL, LH = mapped high < highest(mapped high, bias lookback)[1] AND NOT HH. Start neutral with both counters zero. If HH AND HL, set bullish and increment the bullish counter, resetting the bearish counter; else if LL AND LH, set bearish and increment the bearish counter, resetting the bullish counter; else if HH, increment the bullish counter and set bullish and reset the bearish counter when it reaches the separate confirmation-count parameter; else if LL, increment the bearish counter and set bearish and reset the bullish counter when it reaches that parameter; otherwise retain state and counters.
Long: T1 bias is bullish
Short: T1 bias is bearish
Calculation: Structure pivots = confirmed pivot highs and lows using the shared pivot/body lookback and a separate pivot-confirmation lookback; append alternating high and low pivots, replacing the latest pivot with a more extreme pivot of the same type. Structure high = third-most-recent pivot if it is a high, otherwise second-most-recent; structure low = third-most-recent pivot if it is a low, otherwise second-most-recent.
Calculation: Structure direction = initially neutral; set bullish when close > structure high and the prior direction was not bullish; set bearish when close < structure low and the prior direction was not bearish; otherwise retain direction.
Long: close > structure high AND prior structure direction was not bullish
Short: close < structure low AND prior structure direction was not bearish
Long: prior structure direction was bullish AND close > structure high AND structure high differs from the latest bullish MSS level and latest bullish BOS level, if one exists
Short: prior structure direction was bearish AND close < structure low AND structure low differs from the latest bearish MSS level and latest bearish BOS level, if one exists
Calculation: Bullish displacement candle = abs(close - open) > SMA(abs(close - open), shared pivot/body lookback) AND high - max(open, close) < abs(close - open) * wick-fraction parameter AND min(open, close) - low < abs(close - open) * wick-fraction parameter AND close > open.
Calculation: Bearish displacement candle = abs(close - open) > SMA(abs(close - open), shared pivot/body lookback) AND high - max(open, close) < abs(close - open) * wick-fraction parameter AND min(open, close) - low < abs(close - open) * wick-fraction parameter AND close < open.
Long: bullish displacement candle
Short: bearish displacement candle
Long: bullish displacement candle[1] AND ((gap-mode parameter is standard AND low > high[2]) OR (gap-mode parameter is inverted AND low < high[2]))
Short: bearish displacement candle[1] AND ((gap-mode parameter is standard AND high < low[2]) OR (gap-mode parameter is inverted AND high > low[2]))
Calculation: Order-block swing levels = on chart bars, set swing direction to high when high[OB swing lookback] > highest(high, OB swing lookback), else to low when low[OB swing lookback] < lowest(low, OB swing lookback), else retain direction; update the stored swing high or low only when direction changes. On a break of a stored swing, create an order-block zone from the intervening candle with the lowest selected lower boundary for bullish blocks or highest selected upper boundary for bearish blocks; the range-source parameter selects candle body boundaries or full candle boundaries, and ties select the candle closest to the break. A bullish block becomes a breaker when min(open, close) < its bottom and is removed if a later close > its top; a bearish block becomes a breaker when max(open, close) > its top and is removed if a later close < its bottom.
Long: close > the latest stored order-block swing high AND that swing has not previously created a bullish order block
Short: close < the latest stored order-block swing low AND that swing has not previously created a bearish order block
Short: a bullish order block among the latest bullish-block display-count parameter has been a breaker since an earlier bar, close has not reclaimed its top, and the latest stored order-block swing high lies strictly between its bottom and top; this is the first bar this condition is true for any selected bullish block
Long: a bearish order block among the latest bearish-block display-count parameter has been a breaker since an earlier bar, close has not fallen below its bottom, and the latest stored order-block swing low lies strictly between its bottom and top; this is the first bar this condition is true for any selected bearish block
