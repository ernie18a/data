Calculation: Typical price = (high + low + close) / 3
Calculation: T1-anchored VWAP = sum(typical price × volume) / sum(volume) over chart bars from the current T1 period start through the current bar, including the current forming bar; use close if cumulative volume is zero
Calculation: T1-anchored deviation = sqrt(sum(volume × (typical price − VWAP on that chart bar)^2) / sum(volume)) over chart bars from the current T1 period start through the current bar, including the current forming bar; use (high − low) / 2 if cumulative volume or cumulative weighted squared deviation is not positive
Calculation: Candle body = abs(close − open)
Calculation: Candle range = high − low
Calculation: Upper wick = high − max(close, open)
Calculation: Lower wick = min(close, open) − low
