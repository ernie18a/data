Calculation: Channel index = (HLC3 - selected VWMA or EMA(HLC3, channel lookback)) / STDEV(HLC3, channel lookback) × oscillator scale, or zero when the standard deviation is zero
Calculation: Kalman-smoothed channel index = recursive Kalman filter of the channel index, initialized with the first channel index and initial covariance; each bar, adapted process noise = process noise × ATR ratio clipped to its lower and upper bounds when ATR adaptation is enabled, otherwise process noise; ATR ratio = ATR(ATR lookback) / max(SMA(ATR(ATR lookback), ATR baseline lookback), denominator floor); predicted covariance = prior covariance + adapted process noise; gain = predicted covariance / (predicted covariance + measurement noise); estimate = prior estimate + gain × (channel index - prior estimate); covariance = (1 - gain) × predicted covariance
Calculation: Smoothed Hurst estimate = EMA(log(ratio) / log(2), Hurst smoothing lookback), where ratio = STDEV(HLC3, Hurst lookback) / STDEV(HLC3, half Hurst lookback), or 1 when the short-window standard deviation is zero; use the neutral Hurst level for an undefined estimate
Calculation: Smoothed return entropy = EMA(normalized Shannon entropy of HLC3 - HLC3[1] returns over the entropy lookback, grouped into equal-width bins spanning their rolling minimum-to-maximum range and normalized by log(bin count); use the fallback entropy when undefined, with the entropy smoothing lookback
Calculation: Oscillator rank = PercentRank(Kalman-smoothed channel index, rank lookback)
