Calculation: reversal state on chart bars = 1 when close[longer bar lookback] < close[shorter bar lookback] AND close > close[shorter bar lookback] AND SMA(Stochastic(close, high, low, stochastic lookback), first smoothing length) < SMA(SMA(Stochastic(close, high, low, stochastic lookback), first smoothing length), second smoothing length) AND SMA(Stochastic(close, high, low, stochastic lookback), first smoothing length) > stochastic threshold; -1 when close[longer bar lookback] > close[shorter bar lookback] AND close < close[shorter bar lookback] AND SMA(Stochastic(close, high, low, stochastic lookback), first smoothing length) > SMA(SMA(Stochastic(close, high, low, stochastic lookback), first smoothing length), second smoothing length) AND SMA(Stochastic(close, high, low, stochastic lookback), first smoothing length) < stochastic threshold; otherwise its prior value; longer bar lookback > shorter bar lookback
Calculation: pivot state on chart bars = 1 when chart-bar close > PP + (PP - low(T1, last completed bar)); -1 when chart-bar close < PP - (high(T1, last completed bar) - PP); otherwise its prior value, where PP = (high(T1, last completed bar) + low(T1, last completed bar) + close(T1, last completed bar)) / 3
Long: (reverse is off AND reversal state = 1 AND pivot state = 1) OR (reverse is on AND reversal state = -1 AND pivot state = -1)
Short: (reverse is off AND reversal state = -1 AND pivot state = -1) OR (reverse is on AND reversal state = 1 AND pivot state = 1)
Exit: long, NOT ((reversal state = 1 AND pivot state = 1) OR (reversal state = -1 AND pivot state = -1))
Exit: short, NOT ((reversal state = 1 AND pivot state = 1) OR (reversal state = -1 AND pivot state = -1))
