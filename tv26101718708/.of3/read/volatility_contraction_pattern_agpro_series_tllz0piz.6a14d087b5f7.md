Calculation: swing sequence = confirmed Pivot High(high, swing strength, swing strength) and Pivot Low(low, swing strength, swing strength) points on chart bars, kept alternating within the swing-memory limit; append opposite-type pivots and replace the last same-type pivot only with a more extreme price
Calculation: contraction count = compare the absolute price differences between adjacent swing points, starting with the latest pair; count 1 if that pair exists, then increase by 1 for each successive older difference that is strictly larger than the preceding difference, stopping at the first failed comparison or after four differences
Calculation: volatility scale = max(ATR(ATR lookback), current true range when ATR is unavailable, instrument minimum price increment)
Calculation: base structure = use the latest min(max(contraction count + 1, minimum base swing count), base swing cap) swing points; its range is their highest and lowest prices, its breakout level is the most recent retained swing high, and it is valid only with at least the minimum base swing count and a retained swing high and low
Calculation: risk reference = most recent retained swing low if it is below close; otherwise base low if it is below close; otherwise lowest(low, fallback-low lookback)
Calculation: readiness score = round(contraction score × contraction weight + tightness score × tightness weight + trend score × trend weight + volume score × volume weight), where contraction score is min(max(contraction count / contraction-score full-scale count × score ceiling, 0), score ceiling); tightness score is min(max(score ceiling − (latest swing-pair amplitude / volatility scale / tightness-score ATR scale × score ceiling), 0), score ceiling); trend score is the uptrend score when close > EMA(close, trend EMA length) and that EMA > its value trend-slope lookback bars ago, the above-EMA score when only close > that EMA, the downtrend score when close < that EMA and that EMA < its value trend-slope lookback bars ago, and otherwise the neutral trend score; volume score is the neutral volume score when volume dry-up scoring is disabled, otherwise min(max(score ceiling − (volume ratio − volume reference ratio) × score ceiling, 0), score ceiling), where volume ratio is SMA(volume, shorter recent-volume window) / SMA(volume, longer baseline-volume window), or the neutral volume ratio if the baseline SMA is unavailable or zero
Long: valid base structure AND close > breakout level
Long: valid base structure AND close <= breakout level AND breakout level − close <= pivot-proximity-in-ATR parameter × volatility scale AND latest swing-pair amplitude / volatility scale <= ready-tightness-in-ATR parameter AND readiness score >= readiness-score threshold
Exit: long, valid base structure AND close < risk reference
