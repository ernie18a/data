Calculation: Multi-timeframe SRSI close = on chart bars, take each still-forming bar of T1, T2, T3, and T4; for each timeframe compute K = SMA(StochRSI(close, RSI lookback, Stochastic lookback), K smoothing) and D = SMA(K, D smoothing), then average the four K + D values by dividing their sum by 8.
Calculation: Filtered SRSI extrema = on chart bars, confirm pivot highs and lows of Multi-timeframe SRSI close using the extreme lookback on each side; emit a high only when the immediately preceding raw pivot was a low and high value minus low value >= minimum swing difference, or emit a low only when the immediately preceding raw pivot was a high and high value minus low value >= minimum swing difference; update the preceding raw pivot after every raw pivot, whether emitted or not.
Long: a filtered local low; OR the latest three filtered-extrema signals are MIN-MAX-MIN and their first-to-third confirmation bars span <= cluster window chart bars; OR when neither watch is active, Multi-timeframe SRSI close <= lower watch level starts a low watch, then on the first bar with Multi-timeframe SRSI close >= midlevel emit long and clear both watches; OR after a short midline trigger, track the running minimum, restarting on each short midline trigger, set the counter to zero whenever Multi-timeframe SRSI close makes a new low and otherwise increment it on each tracking bar including the trigger bar, then emit long and stop tracking when the counter >= confirmation bars.
Short: a filtered local high; OR the latest three filtered-extrema signals are MAX-MIN-MAX and their first-to-third confirmation bars span <= cluster window chart bars; OR when neither watch is active, Multi-timeframe SRSI close >= upper watch level starts a high watch, then on the first bar with Multi-timeframe SRSI close <= midlevel emit short and clear both watches; OR after a long midline trigger, track the running maximum, restarting on each long midline trigger, set the counter to zero whenever Multi-timeframe SRSI close makes a new high and otherwise increment it on each tracking bar including the trigger bar, then emit short and stop tracking when the counter >= confirmation bars.
