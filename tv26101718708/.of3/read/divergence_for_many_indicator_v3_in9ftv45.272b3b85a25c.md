Calculation: High-pivot offset = left pivot lookback when PivotHigh(high, left pivot lookback, confirmed right pivot lookback) confirms; otherwise prior offset + 1, using zero when no prior offset.
Calculation: Low-pivot offset = left pivot lookback when PivotLow(low, left pivot lookback, confirmed right pivot lookback) confirms; otherwise prior offset + 1, using zero when no prior offset.
Calculation: Indicator set = the enabled subset of {RSI(close, RSI lookback), MACD line(close, MACD fast lookback, MACD slow lookback, MACD signal lookback), MACD histogram(close, same MACD lookbacks), Momentum(close, momentum lookback), CCI(close, CCI lookback), OBV(close, volume), SMA(Stochastic(close, high, low, stochastic lookback), stochastic smoothing lookback), DI oscillator, VWMA(close, MACD fast lookback) - VWMA(close, MACD slow lookback), CMF(high, low, close, volume, CMF lookback), MFI(close, MFI lookback)}; each indicator has its own enable parameter.
Calculation: DI oscillator = 100 * RMA(change(high) + change(low), DI lookback) / RMA(TrueRange(high, low, close), same DI lookback), carrying forward the last valid value when undefined.
Calculation: PricePathNotBrokenAbove(close, anchor, current, n) = for every integer k from 1 through n-1, close[k] <= current - (current - anchor) * k / n.
Calculation: PricePathNotBrokenBelow(close, anchor, current, n) = for every integer k from 1 through n-1, close[k] >= current - (current - anchor) * k / n.
Calculation: IndicatorPathNotBrokenBelow(x, n) = for every integer k from 1 through n-1, x[k] <= x - (x - x[n]) * k / n.
Calculation: IndicatorPathNotBrokenAbove(x, n) = for every integer k from 1 through n-1, x[k] >= x - (x - x[n]) * k / n.
