Calculation: Displacement(X) = abs(Close - Open)[0] >= SMA(abs(Close - Open), body lookback of X)[1] * displacement multiplier of X, where for X = T1 the reference bar is the last completed T1 bar and for X = chart it is the current chart bar; [n] = n bars before the reference bar
Calculation: Bull FVG = Low(T1)[0] > High(T1)[2]
Calculation: Bear FVG = High(T1)[0] < Low(T1)[2]
Calculation: Sell sweep level(T1) = max{L in S : L > Low(T1)[0]}, where S = defined levels among: Low(T2)[0] if PD enabled; low of latest completed Asia session if Asia enabled; low of latest completed London session if London enabled; last confirmed Pivot Low(T1, pivot length T1)[0] if T1 swing enabled; last confirmed Pivot Low(T3, pivot length T3)[0] if T3 swing enabled; computed at the first chart bar of each T1 bar
Calculation: Buy sweep level(T1) = min{H in S' : H < High(T1)[0]}, where S' = defined levels among: High(T2)[0] if PD enabled; high of latest completed Asia session if Asia enabled; high of latest completed London session if London enabled; last confirmed Pivot High(T1, pivot length T1)[0] if T1 swing enabled; last confirmed Pivot High(T3, pivot length T3)[0] if T3 swing enabled; computed at the first chart bar of each T1 bar
Calculation: Latest Bull FVG zone = (bottom, top) = (High(T1)[2], Low(T1)[0]) at the most recent T1 bar up to the current one where Bull FVG holds
Calculation: Latest Bear FVG zone = (bottom, top) = (High(T1)[0], Low(T1)[2]) at the most recent T1 bar up to the current one where Bear FVG holds
Calculation: Bull confirmation = none unless Close(T1)[0] > Open(T1)[0] AND Displacement(T1) AND, for some n >= 0 with Sell sweep level(T1)[n] defined, m = max{m in [0, n] : Close(T1)[m] > Sell sweep level(T1)[n]} exists with n - m <= reclaim window and m <= confirmation window; otherwise iFVG if Close(T1)[0] > top of Latest Bear FVG zone, else FVG if Bull FVG, else DISP
Calculation: Bull invalidation = min Low(T1) over T1 bars from m through n, for the sweep n and reclaim m of the Bull confirmation
Calculation: Armed bull reason = reason of the Bull confirmation at the latest T1 bar k at or before the current chart bar whose value is not none, provided no Bear confirmation occurred after k, no chart bar from k through the current one has Low < Bull invalidation of k, chart bars since k <= entry window, no long entry occurred after k and before the current chart bar, and, if a bull pullback occurred at or after k, chart bars since its first occurrence <= pullback window; otherwise none
Calculation: Bull MSS level = last confirmed Pivot High(chart, pivot length chart) as of the first chart bar at or after k that is a bull pullback (Close < Open, or Low < Low[1], or Low <= zone top AND High >= zone bottom, with zone = Latest Bear FVG zone at k if Armed bull reason is iFVG, Latest Bull FVG zone at k if FVG, no zone if DISP), defined from the chart bar after that pullback on
Calculation: Bear confirmation = none unless Close(T1)[0] < Open(T1)[0] AND Displacement(T1) AND, for some n >= 0 with Buy sweep level(T1)[n] defined, m = max{m in [0, n] : Close(T1)[m] < Buy sweep level(T1)[n]} exists with n - m <= reclaim window and m <= confirmation window; otherwise iFVG if Close(T1)[0] < bottom of Latest Bull FVG zone, else FVG if Bear FVG, else DISP
Calculation: Bear invalidation = max High(T1) over T1 bars from m through n, for the sweep n and reclaim m of the Bear confirmation
Calculation: Armed bear reason = reason of the Bear confirmation at the latest T1 bar k at or before the current chart bar whose value is not none, provided no Bull confirmation occurred after k, no chart bar from k through the current one has High > Bear invalidation of k, chart bars since k <= entry window, no short entry occurred after k and before the current chart bar, and, if a bear pullback occurred at or after k, chart bars since its first occurrence <= pullback window; otherwise none
Calculation: Bear MSS level = last confirmed Pivot Low(chart, pivot length chart) as of the first chart bar at or after k that is a bear pullback (Close > Open, or High > High[1], or Low <= zone top AND High >= zone bottom, with zone = Latest Bull FVG zone at k if Armed bear reason is iFVG, Latest Bear FVG zone at k if FVG, no zone if DISP), defined from the chart bar after that pullback on
