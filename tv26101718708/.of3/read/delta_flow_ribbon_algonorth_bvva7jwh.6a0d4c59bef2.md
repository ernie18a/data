Calculation: Delta = on each chart bar, sum available T1 bar volumes signed by the direction of their close change from the prior T1 close, carrying the prior nonzero direction across unchanged closes and using open when no prior close exists, when intrabar delta is selected and available; otherwise volume × ((close - low) - (high - close)) / (high - low), or zero when the range is zero
Calculation: Calibration baselines = normal volume, positive delta, negative delta, and absolute close-to-close change, using same-time-slot averages from prior sessions when time-of-day calibration is selected, supported, and warmed up; otherwise use EMAs over chart bars with the recent-bars lookback, unavailable until its warm-up requirement is met
Calculation: Quiet weight = neutral weight when normal volume is unavailable; otherwise min(neutral weight, volume / normal volume / quiet-volume threshold)
Calculation: Net flow = EMA(Delta, short lookback) / (normal positive flow + normal negative flow) × quiet weight
Calculation: Price response = EMA(close - close[1], same short lookback) / normal absolute close-to-close change × sign(net flow) / max(abs(net flow), minimum-flow floor)^flow-to-movement exponent
Calculation: Upside core = apply EMA with the fastest lookback for the configured smoothing passes to neutral multiple + (min(max(Delta, 0) / normal positive flow, flow cap) - neutral multiple) × quiet weight
Calculation: Downside core = apply EMA with the fastest lookback for the configured smoothing passes to neutral multiple + (min(max(-Delta, 0) / normal negative flow, flow cap) - neutral multiple) × quiet weight
Long: Upside core > Downside core OR (net flow > 0 AND abs(net flow) >= surge-flow threshold AND price response, treating unavailable response as neutral, > price-response threshold) OR (net flow > 0 AND abs(net flow) >= absorption-flow threshold AND price response <= price-response threshold)
Short: Downside core >= Upside core OR (net flow < 0 AND abs(net flow) >= surge-flow threshold AND price response, treating unavailable response as neutral, > price-response threshold) OR (net flow < 0 AND abs(net flow) >= absorption-flow threshold AND price response <= price-response threshold)
