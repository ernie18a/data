Calculation: chart basis = selected SMA or EMA(close, chart lookback)
Calculation: chart band(m) = chart basis +/- m * standard deviation(close, chart lookback); entry and exit use separate multipliers, and the entry multiplier is selected from three separate parameters
Calculation: T1 basis = selected SMA or EMA(close, T1 lookback), calculated on T1 bars using the bar still forming and mapped to chart bars
Calculation: T1 band(d) = T1 basis +/- d * standard deviation(close, T1 lookback), calculated on T1 bars using the bar still forming and mapped to chart bars; narrower and wider bands use separate multipliers, with the wider multiplier greater than the narrower
Calculation: expected profit = abs(close - chart basis) * most recently recorded absolute position size
Calculation: stop distance = loss-to-ticks multiplier * per-trade loss limit / absolute position size * minimum tick
