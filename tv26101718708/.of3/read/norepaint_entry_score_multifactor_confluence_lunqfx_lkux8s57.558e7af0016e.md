Calculation: Body ratio = high > low ? abs(close - open) / (high - low) : 0
Calculation: Session score = the selected session's New York-time hourly lookup: Crypto uses its flat score; NY uses five configured hour bands and a fallback score; London uses four configured hour bands and a fallback score; Tokyo uses two configured hour bands and a fallback score. Each band's hours and score, each fallback score, the Crypto score, and the selected session are separate parameters.
Calculation: Prime streak = consecutive confirmed chart bars with Entry score >= prime threshold
Calculation: Entry score = round((structure weight * round(min(aligned ? aligned base + Body ratio * aligned scale : misaligned base + Body ratio * misaligned scale, 100)) + proximity weight * (both latest confirmed chart-timeframe swing pivots missing ? neutral proximity score : round(clamp(100 - proximity scale * minimum available distance from close to the latest confirmed chart-timeframe pivot high or low in ATR units, 0, 100))) + session weight * Session score + momentum weight * round(Body ratio * 100) + volatility weight * volatility score) / (structure weight + proximity weight + session weight + momentum weight + volatility weight)); aligned = (close > EMA(close, EMA lookback, T1, last completed bar) AND close >= open) OR (close <= EMA(close, EMA lookback, T1, last completed bar) AND close < open); the EMA is calculated on T1 and its last completed value is sampled on chart bars; pivot high and low use the same left and right lookback on chart bars and become available when confirmed; distance uses abs(close - pivot) / max(ATR(ATR lookback), minimum tick size * tick guard); volatility ratio = ATR(ATR lookback) / SMA(ATR(ATR lookback), longer ATR-average lookback), or 1 if the SMA is not positive; volatility score = 100 when the ratio is between the lower and upper volatility thresholds inclusive, round(ratio / lower threshold * 100) below the lower threshold, or max(0, round(100 - (ratio - upper threshold) * upper penalty)) above the upper threshold. Each weight, score base and scale, lookback, proximity parameter, volatility threshold and penalty, neutral proximity score, and tick guard is a separate parameter.
Long: close > EMA(close, EMA lookback, T1, last completed bar) AND (Entry score >= signal threshold OR (confirmed bar AND Entry score >= prime threshold AND Entry score[1] < prime threshold) OR (confirmed bar AND Entry score >= good threshold AND Entry score < prime threshold AND Entry score[1] < good threshold) OR (confirmed bar AND (Prime streak = sustained streak parameter OR Prime streak = elite streak parameter)))
Short: close <= EMA(close, EMA lookback, T1, last completed bar) AND (Entry score >= signal threshold OR (confirmed bar AND Entry score >= prime threshold AND Entry score[1] < prime threshold) OR (confirmed bar AND Entry score >= good threshold AND Entry score < prime threshold AND Entry score[1] < good threshold) OR (confirmed bar AND (Prime streak = sustained streak parameter OR Prime streak = elite streak parameter)))
