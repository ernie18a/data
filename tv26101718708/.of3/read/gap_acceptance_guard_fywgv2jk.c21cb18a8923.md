Calculation: Gap size = open - close[1]
Calculation: Acceptance boundary = close[1] + Gap size × acceptance-depth parameter / 100
Calculation: Path efficiency = max(direction × (close - event close), 0) / sum(abs(close[i] - close[i-1]) over confirmed bars after the event through the current bar) × 100; 0 when the sum is 0
Long: On a confirmed chart bar, when no gap observation is active, prior-bar ATR(ATR-lookback parameter) is available and positive, and more than the ATR-lookback parameter's number of chart bars have elapsed: on the first exchange-day bar if intraday, or any bar otherwise, Gap size ≥ prior-bar ATR × minimum-gap/ATR parameter, the full-range parameter is off or open > high[1], and close > Acceptance boundary; OR an active bullish gap observation has the required number of consecutive confirmed closes above its frozen Acceptance boundary, counting the event close, and high ≥ event-bar high + frozen prior-bar ATR × extension/ATR parameter, and Path efficiency for direction +1 ≥ minimum path-efficiency parameter before the observation-duration parameter expires
Short: On a confirmed chart bar, when no gap observation is active, prior-bar ATR(ATR-lookback parameter) is available and positive, and more than the ATR-lookback parameter's number of chart bars have elapsed: on the first exchange-day bar if intraday, or any bar otherwise, Gap size ≤ -prior-bar ATR × minimum-gap/ATR parameter, the full-range parameter is off or open < low[1], and close < Acceptance boundary; OR an active bearish gap observation has the required number of consecutive confirmed closes below its frozen Acceptance boundary, counting the event close, and low ≤ event-bar low - frozen prior-bar ATR × extension/ATR parameter, and Path efficiency for direction -1 ≥ minimum path-efficiency parameter before the observation-duration parameter expires
Exit: long, an active bullish gap observation and confirmed close < its frozen Acceptance boundary
Exit: short, an active bearish gap observation and confirmed close > its frozen Acceptance boundary
