Calculation: Small-cap volume ratio = current volume / SMA(volume, volume-average lookback) on T1 bars, including the still-forming bar.
Calculation: Yield change in basis points = (current yield close − yield close[yield-change lookback]) × basis-point conversion on T1 bars, including the still-forming bar.
Calculation: Composite score = (small-cap close > EMA(small-cap close, shorter EMA lookback) ? small-cap price/short-EMA weight : −small-cap price/short-EMA weight) + (EMA(small-cap close, shorter EMA lookback) > EMA(small-cap close, longer EMA lookback) ? small-cap EMA-order weight : −small-cap EMA-order weight) + (Nasdaq close > EMA(Nasdaq close, shorter EMA lookback) ? Nasdaq price/short-EMA weight : −Nasdaq price/short-EMA weight) + (ROC(small-cap close, relative-strength lookback) > ROC(broad-market benchmark close, the same lookback) ? relative-strength weight : −relative-strength weight) + (Efficiency Ratio(small-cap close, efficiency lookback) >= trend-efficiency threshold ? efficiency weight : 0) + (small-cap volume ratio >= strong-volume ratio AND ROC(small-cap close, short ROC lookback) > 0 ? positive-volume weight : 0) − (small-cap volume ratio >= strong-volume ratio AND ROC(small-cap close, the same short ROC lookback) < 0 ? negative-volume weight : 0) − (yield change in basis points >= yield-pressure threshold ? rising-yield weight : 0) + (yield change in basis points <= −yield-pressure threshold ? falling-yield weight : 0). EMA, ROC, volume, and efficiency inputs are computed on T1 bars including the still-forming bar; the score is evaluated on chart bars using those T1 values.
Long: Efficiency Ratio(small-cap close, efficiency lookback, T1, current bar) >= trend-efficiency threshold AND Composite score >= bullish-score threshold
Short: (Composite score <= bearish-score threshold OR (small-cap close < EMA(small-cap close, longer EMA lookback, T1, current bar) AND ROC(small-cap close, relative-strength lookback, T1, current bar) < 0 AND Efficiency Ratio(small-cap close, efficiency lookback, T1, current bar) >= trend-efficiency threshold)) AND NOT (Composite score >= bullish-score threshold AND Efficiency Ratio(small-cap close, efficiency lookback, T1, current bar) >= trend-efficiency threshold)
