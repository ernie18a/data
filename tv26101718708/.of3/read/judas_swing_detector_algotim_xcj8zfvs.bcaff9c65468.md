Calculation: Initial Range high = highest(high) on chart bars from the configured session start through the configured opening-window duration; lock when that duration elapses.
Calculation: Initial Range low = lowest(low) on chart bars from the configured session start through the configured opening-window duration; lock when that duration elapses.
Calculation: body ATR = abs(close - open) / ATR(ATR lookback) on chart bars, or 0 when ATR is 0.
Calculation: bars since sweep = current chart bar index - that candidate's sweep bar index.
Calculation: HTF separation = abs(EMA(close, shorter HTF lookback, T1 bars) - EMA(close, longer HTF lookback, T1 bars)) / ATR(ATR lookback) on chart bars, or 0 when ATR is 0; map both EMA values to chart bars with lookahead_off, using completed T1 values historically and the still-forming T1 value in realtime.
Calculation: bullish confidence score = round(weighted mean of: min((Initial Range low - sweep-bar low) / confirmation-bar ATR / sweep-depth score saturation, score-factor upper bound) × confidence-score scale; min(body ATR / displacement-score saturation, score-factor upper bound) × confidence-score scale; min(HTF separation / HTF-score saturation, score-factor upper bound) × confidence-score scale; rejection factor; and max(speed-score floor, confidence-score scale - (bars since sweep - speed-free delay) × speed penalty per bar), using separate weights for sweep depth, displacement, HTF agreement, rejection quality, and reversal aggression; rejection factor is (sweep-bar close - sweep-bar low) / (sweep-bar high - sweep-bar low) × confidence-score scale when confirmation is on the sweep bar and its range is nonzero, the zero-range rejection fallback when that range is zero, or the later-confirmation rejection score otherwise; score is 0 if the weights sum to 0.
Calculation: bearish confidence score = round(weighted mean of: min((sweep-bar high - Initial Range high) / confirmation-bar ATR / sweep-depth score saturation, score-factor upper bound) × confidence-score scale; min(body ATR / displacement-score saturation, score-factor upper bound) × confidence-score scale; min(HTF separation / HTF-score saturation, score-factor upper bound) × confidence-score scale; rejection factor; and max(speed-score floor, confidence-score scale - (bars since sweep - speed-free delay) × speed penalty per bar), using separate weights for sweep depth, displacement, HTF agreement, rejection quality, and reversal aggression; rejection factor is (sweep-bar high - sweep-bar close) / (sweep-bar high - sweep-bar low) × confidence-score scale when confirmation is on the sweep bar and its range is nonzero, the zero-range rejection fallback when that range is zero, or the later-confirmation rejection score otherwise; score is 0 if the weights sum to 0.
Long: EMA(close, shorter HTF lookback, T1 bars) > EMA(close, longer HTF lookback, T1 bars), calculated on T1 bars and mapped to chart bars with lookahead_off; historical chart bars use completed T1 values and realtime chart bars can use the still-forming T1 value.
Short: EMA(close, shorter HTF lookback, T1 bars) < EMA(close, longer HTF lookback, T1 bars), calculated on T1 bars and mapped to chart bars with lookahead_off; historical chart bars use completed T1 values and realtime chart bars can use the still-forming T1 value.
