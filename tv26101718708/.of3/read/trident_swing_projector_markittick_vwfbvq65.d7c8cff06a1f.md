Calculation: Swing size = absolute distance between the latest confirmed pivot high and latest confirmed pivot low on each chart bar
Calculation: Projected leg = the selected swing-unit transform of |B−A|, multiplied by the selected smoother of the chart-bar swing-size series over the smoothing lookback divided by swing size, using an identity ratio when swing size is zero; the percentage-distance transform is C×|B−A|/A when A≠0 and |B−A| otherwise
Calculation: Stop buffer = zero, tick-buffer parameter × minimum tick size, or ATR(high, low, close, ATR lookback) × ATR-buffer fraction, evaluated when the setup arms
Calculation: Managed stop = C−stop buffer for a long or C+stop buffer for a short, fixed from setup arming and moved to the entry price after TP1 when breakeven management is enabled
Long: A is the latest confirmed Pivot Low(low, pivot-left lookback, pivot-right lookback) before B, the latest confirmed Pivot High(high, pivot-left lookback, pivot-right lookback), and C is a newer confirmed Pivot Low(low, pivot-left lookback, pivot-right lookback); C>A; minimum-pullback parameter ≤ (B−C)/(B−A)×100 ≤ maximum-pullback parameter; trend filter disabled or a prior confirmed pivot high exists and B exceeds it; HTF filter disabled or, on chart bars, the last completed T1 close exceeds the preceding completed T1 close; ADX filter disabled or chart-bar ADX(high, low, close, ADX lookback, ADX lookback) ≥ ADX threshold; projected leg > 0; when this setup arms there was no armed or active setup at bar start and none remains armed or active, and signal lock is disabled or arming is not on the last chart bar; later, while armed, elapsed chart bars since arming < armed-expiry parameter, low[1] ≥ C, and close[1] ≥ C + entry-fraction parameter × projected leg
Short: A is the latest confirmed Pivot High(high, pivot-left lookback, pivot-right lookback) before B, the latest confirmed Pivot Low(low, pivot-left lookback, pivot-right lookback), and C is a newer confirmed Pivot High(high, pivot-left lookback, pivot-right lookback); C<A; minimum-pullback parameter ≤ (C−B)/(A−B)×100 ≤ maximum-pullback parameter; trend filter disabled or a prior confirmed pivot low exists and B is below it; HTF filter disabled or, on chart bars, the last completed T1 close is below the preceding completed T1 close; ADX filter disabled or chart-bar ADX(high, low, close, ADX lookback, ADX lookback) ≥ ADX threshold; projected leg > 0; when this setup arms there was no armed or active setup at bar start and none remains armed or active, and signal lock is disabled or arming is not on the last chart bar; later, while armed, elapsed chart bars since arming < armed-expiry parameter, high[1] ≤ C, and close[1] ≤ C − entry-fraction parameter × projected leg
Exit: Long, the long setup is active or a long entry triggers this bar, and (low ≤ managed stop or (state is Active or a long entry triggers this bar) and high ≥ C + TP1-fraction parameter × projected leg, or (state is Active or TP1 hit or a long entry triggers this bar) and high ≥ C + TP2-fraction parameter × projected leg, or (state is Active or TP1 hit or TP2 hit or a long entry triggers this bar) and high ≥ C + TP3-fraction parameter × projected leg)
Exit: Short, the short setup is active or a short entry triggers this bar, and (high ≥ managed stop or (state is Active or a short entry triggers this bar) and low ≤ C − TP1-fraction parameter × projected leg, or (state is Active or TP1 hit or a short entry triggers this bar) and low ≤ C − TP2-fraction parameter × projected leg, or (state is Active or TP1 hit or TP2 hit or a short entry triggers this bar) and low ≤ C − TP3-fraction parameter × projected leg)
