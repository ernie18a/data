Calculation: Long target = signal-bar close × (1 + minimum profit / 100); after each chart-bar close above the current target, advance one step to entry price × (1 + current target gain + minimum profit / 100), starting current target gain at minimum profit / 100 and increasing it by minimum profit / 100 per step
Calculation: Short target = signal-bar close × (1 - minimum profit / 100); after each chart-bar close below the current target, advance one step to entry price × (1 - current target gain - minimum profit / 100), starting current target gain at minimum profit / 100 and increasing it by minimum profit / 100 per step
Calculation: Long stop = max(previous long stop, current long stop); at entry, current long stop = signal-bar close × (1 - maximum stop / 100) and the previous long stop = signal-bar low - SMA(high - low, Kaufman lookback) × Kaufman multiplier; after each chart-bar close above the long target, set current long stop = entry price × (1 + current stop gain / 100), starting current stop gain at zero and increasing it by minimum profit × profit factor per target step
Calculation: Short stop = min(previous short stop, current short stop); at entry, current short stop = signal-bar close × (1 + maximum stop / 100) and the previous short stop = signal-bar high + SMA(high - low, Kaufman lookback) × Kaufman multiplier; after each chart-bar close below the short target, set current short stop = entry price × (1 - current stop gain / 100), starting current stop gain at zero and increasing it by minimum profit × profit factor per target step
Exit: long, chart low <= long stop
Exit: short, chart high >= short stop
