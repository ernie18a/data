Calculation: Trend = 0 initially; at each confirmed pivot high H (PivotHigh(high, pivot length, pivot length)): 1 if H > prior pivot high AND latest pivot low > prior pivot low, -1 if H < prior pivot high; at each confirmed pivot low L (PivotLow(low, pivot length, pivot length)): -1 if L < prior pivot low AND latest pivot high < prior pivot high, 1 if L > prior pivot low; otherwise unchanged
Calculation: Displacement(direction) = min(score maximum, body term + range term + CISD term); body term = body points 1 if abs(close[1] - open[1]) / (high[1] - low[1]) > body cutoff 1, body points 2 if > body cutoff 2, body points 3 if > body cutoff 3, else 0; range term = range points 1 if (high[1] - low[1]) / ATR(ATR length) > range cutoff 1, range points 2 if > range cutoff 2, range points 3 if > range cutoff 3, range points 4 if > range cutoff 4, else 0; CISD term = CISD points if bull: close[1] > open[2] AND close[2] < open[2], or bear: close[1] < open[2] AND close[2] > open[2], else 0; body cutoffs and range cutoffs decrease with index
Calculation: Sweep(direction, start) = min(score maximum, base term + bonus term); for bull, base term = sweep points 1 if low[j] < latest pivot low, else sweep points 2 if low[j] < prior-day low, else sweep points 3 if abs(low[j] - latest pivot low) <= swing proximity * ATR(ATR length), where j is the first bar from start to start + sweep window at which any of these holds (0 if none), and bonus term = sweep bonus points if low[j] <= Lowest(low, IPDA lookback) for any j in that same range, else 0; for bear, mirror with high, > in place of <, latest pivot high, prior-day high, and high[j] >= Highest(high, IPDA lookback); prior-day low/high = low/high of last completed T1 bar (T1 value on chart bars)
Calculation: PremiumDiscount(direction, top, bottom) = 0 if highest high - lowest low over dealing range length <= 0; else with pct = ((top + bottom) / 2 - lowest low over dealing range length) / (highest high - lowest low over dealing range length): bull: PD points 1 if pct <= discount cutoff 1, PD points 2 if pct <= discount cutoff 2, PD points 3 if pct <= discount cutoff 3, PD points 4 if pct <= discount cutoff 4, else 0; bear: PD points 1 if pct >= premium cutoff 1, PD points 2 if pct >= premium cutoff 2, PD points 3 if pct >= premium cutoff 3, PD points 4 if pct >= premium cutoff 4, else 0; discount cutoffs increase with index, premium cutoffs decrease with index
Calculation: StructureScore(direction) = structure aligned points if Trend = 1 for bull or -1 for bear; structure neutral points if Trend = 0; else structure counter points
Calculation: HTFScore(direction) = HTF aligned points if sign(close - open) of last completed T2 bar (T2 value on chart bars) is 1 for bull or -1 for bear; HTF neutral points if that sign is 0; else HTF misaligned points
Calculation: OTE(direction, top, bottom) = 0 if highest high - lowest low over dealing range length <= 0; else with mid = (top + bottom) / 2, range = highest high - lowest low over dealing range length, level(x) = highest high - x * range for bull or lowest low + x * range for bear (OTE fractions 1, 2, 3 increase with index): OTE sweet points if mid is between level(OTE fraction 1) and level(OTE fraction 3) inclusive AND abs(mid - level(OTE fraction 2)) / abs(level(OTE fraction 1) - level(OTE fraction 3)) <= OTE sweet tolerance; else OTE inside points if mid is between level(OTE fraction 1) and level(OTE fraction 3) inclusive; else OTE near points if mid is between those two levels each extended outward by OTE near tolerance * ATR(ATR length); else 0
Calculation: Mitigated(zone) = true if on any bar after the zone formed up to the prior bar, for bull low or close (per mitigation basis parameter) <= zone bottom, for bear high or close (per mitigation basis parameter) >= zone top; else false
Calculation: Overlap(direction, type, top, bottom) = overlap points 1 if fraction > overlap cutoff 1, overlap points 2 if fraction > overlap cutoff 2, else overlap points 3; fraction = (min(top, E.top) - max(bottom, E.bottom)) / (top - bottom), where E is the oldest previously marked zone that is not mitigated as of the prior bar, has the other type, has the same direction, and has min(top, E.top) > max(bottom, E.bottom); 0 if no such E; overlap cutoffs decrease with index
Calculation: Volume(bar) = 0 if SMA(volume, volume length) <= 0; else with ratio = volume[bar] / SMA(volume, volume length): volume points 1 if ratio > volume cutoff 1, volume points 2 if > volume cutoff 2, volume points 3 if > volume cutoff 3, volume points 4 if > volume cutoff 4, else volume points 5; volume cutoffs decrease with index
Calculation: Session = session points 1 if last completed bar's time is in the NY AM window; else session points 2 if in the London window, Silver Bullet 1 window, or Silver Bullet 2 window; else session points 3 if in the NY PM window; else session points 4 if in the Asian window; else session points 5 (windows in NY time)
Calculation: BullOB = first j from 2 to OB scan depth with close[j] < open[j], else OB scan depth + 1
Calculation: BearOB = first j from 2 to OB scan depth with close[j] > open[j], else OB scan depth + 1
Calculation: Score(direction, type, top, bottom, start, volume bar) = Displacement(direction) + Sweep(direction, start) + PremiumDiscount(direction, top, bottom) + StructureScore(direction) + HTFScore(direction) + OTE(direction, top, bottom) + Overlap(direction, type, top, bottom) + Volume(volume bar) + Session + freshness points
Long: low > high[2] AND Score(bull, FVG, low, high[2], 2, 1) >= min score
Long: low > high[2] AND BullOB <= OB scan depth AND Score(bull, OB, high[BullOB], low[BullOB], BullOB, BullOB) >= min score
Short: high < low[2] AND Score(bear, FVG, low[2], high, 2, 1) >= min score
Short: high < low[2] AND BearOB <= OB scan depth AND Score(bear, OB, high[BearOB], low[BearOB], BearOB, BearOB) >= min score
