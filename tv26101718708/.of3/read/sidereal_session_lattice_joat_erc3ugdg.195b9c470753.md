Calculation: Session VWAP = sum(hlc3 × volume) / sum(volume) over bars in the current configured session, using hlc3 if the absolute volume sum is at most the division epsilon.
Calculation: Harmonic blend = first-harmonic weight × sin(2πp) + second-harmonic weight × sin(4πp + quarter-cycle offset), where p is the zero-based number of chart bars since the current session began modulo the cycle-length parameter, divided by that cycle-length parameter.
Calculation: Drift ATR = EMA(close − session VWAP, drift smoothing parameter) / ATR(ATR lookback parameter), using zero if the absolute ATR is at most the division epsilon.
Calculation: Session orbit width = ATR(ATR lookback parameter) × (base-width parameter + abs(harmonic blend) × harmonic-width parameter + abs(drift ATR) × drift-width parameter).
Calculation: Session orbit mean = session VWAP + harmonic blend × session orbit width × orbit-offset parameter.
Calculation: Phase pressure = clamp(((close − current-session low) / max(current-session high − current-session low, minimum-range parameter) − 0.5) × range-pressure parameter + drift ATR × drift-pressure parameter + harmonic blend × harmonic-pressure parameter, to ±pressure-cap parameter).
Calculation: Anomaly rank = PercentRank(anomaly ratio, anomaly memory parameter), where anomaly ratio is abs(log(close / close[1])) / SMA(abs(log(close / close[1])), anomaly memory parameter), using zero for the log return when close[1] is zero, one for the ratio when the SMA denominator is at most the division epsilon in absolute value, and 50 if the rank is unavailable.
Calculation: Entropy percentage = normalized binary Shannon entropy, expressed as a percentage, of the up and down shares over the entropy memory parameter; each share is the rolling sum of max(close − open, 0) × volume or max(open − close, 0) × volume divided by their combined rolling sum, using an up share of 0.5 when the absolute denominator is at most the division epsilon and a down share of one minus the up share.
Calculation: Lattice score = anomaly rank × anomaly weight + abs(phase pressure) × pressure weight + (100 − entropy percentage) × low-entropy weight, clamped to 0–100.
Long: On a confirmed chart bar within the configured session, close > session orbit mean + session orbit width AND phase pressure > 0 AND lattice score ≥ phase anomaly threshold parameter.
Short: On a confirmed chart bar within the configured session, close < session orbit mean − session orbit width AND phase pressure < 0 AND lattice score ≥ phase anomaly threshold parameter.
