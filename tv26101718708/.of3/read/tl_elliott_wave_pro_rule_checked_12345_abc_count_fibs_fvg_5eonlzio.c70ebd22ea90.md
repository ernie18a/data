Calculation: ZigZag(Lz, Dz, n) = alternating pivot highs and lows, where a bar is a pivot high (low) when its high (low) is the highest (lowest) of the Lz bars on each side, known Lz bars later; a new pivot replaces the last pivot when it is of the same type and more extreme; a pivot of the opposite type is appended only when it is at least Dz × ATR(n) from the last pivot
Calculation: Retrace(S, E, C) = |E − C| / |E − S|
Calculation: FibLevel(E, S, r) = E + (S − E) × r
Calculation: Impulse(Q0, Q1, …, Qm) = with d = up if Q0 is a low, else down, each condition applied only when its pivots exist: (Q1 − Q0) × d > 0; (Q2 − Q1) × d < 0; (Q3 − Q2) × d > 0 and (Q3 − Q1) × d > 0; (Q4 − Q3) × d < 0; (Q5 − Q4) × d > 0 and, unless a truncated fifth is allowed, (Q5 − Q3) × d > 0; Rule 1 default: wave 3 length ≥ min(wave 1 length, wave 5 length) when Q5 exists; Rule 1 strict: wave 3 length ≥ wave 1 length and, when Q5 exists, ≥ wave 5 length; Rule 2: (Q2 − Q0) × d > 0; Rule 3: (Q4 − Q1) × d > 0; each enabled rule only
Calculation: Diagonal(Q0, Q1, …, Qm) = with d as in Impulse, each condition applied only when its pivots exist: (Q1 − Q0) × d > 0; (Q2 − Q1) × d < 0; (Q3 − Q2) × d > 0 and (Q3 − Q1) × d > 0; (Q4 − Q3) × d < 0; (Q4 − Q1) × d < 0; (Q4 − Q2) × d > 0; (Q5 − Q4) × d > 0; wave 3 length ≤ (1 + W) × wave 1 length; wave 5 length ≤ (1 + W) × wave 3 length when Q5 exists; Rule 1 and Rule 2 as in Impulse
Calculation: Count = the first pattern below that matches, tested in order on the latest confirmed ZigZag pivots z1 (latest), z2, z3, …; within a pattern P0 is wave 1 start, P1 wave 1 end, P2 wave 2 end, P3 wave 3 end, P4 wave 4 end, P5 wave 5 end, A, B, C are corrective pivots, and d is the pattern direction; Count is recomputed only when a pivot is added or replaced and is held otherwise. Patterns: (stage 8) Impulse(z9…z4) with A = z3, B = z2, C = z1, where (z3 − z4) × d < 0, (z2 − z3) × d > 0, (z1 − z2) × d < 0, (z2 − z4) × d < 0; (stage 7) Impulse(z8…z3) with A = z2, B = z1, where (z2 − z3) × d < 0, (z1 − z2) × d > 0, (z1 − z3) × d < 0; (stage 6) Impulse(z7…z2) with A = z1, where (z1 − z2) × d < 0; (stage 5) Impulse(z6…z1), else Diagonal(z6…z1), flagged diagonal if the latter; (stage 4) Impulse(z5…z1), else Diagonal(z5…z1), flagged diagonal if the latter; (stage 2) z3, z2, z1 as P0, P1, P2 with (P1 − P0) × d > 0, (P2 − P1) × d < 0, and Rule 2 (P2 − P0) × d > 0 when enabled
Calculation: Kind(S, E, C) = sharp if Retrace(S, E, C) ≥ Ds or (bar of C − bar of E) / (bar of E − bar of S) ≤ Ts, else flat
Calculation: Guidelines = count of the following that hold, each tested only where its pivots exist: (a) |L5 − L1| ≤ Ge × L1; (b) Kind(P0, P1, P2) differs from Kind(P2, P3, P4) for an impulse, or equals it for a diagonal; (c) |C − P4| ≤ max(Ca × |P3 − P4|, ATR(n)), with C the end of the corrective wave after wave 5; (d) |L3 − L1| ≤ Ge × L1, or |L5 − L3| ≤ Ge × L3, or |L5 − L1| ≤ Ge × L1, or |L5 − Gr × L1| ≤ Ge × L1; (e) volume guideline on and mean volume from the P4 bar to the P5 bar (or to the current bar while wave 5 runs) < mean volume from the P2 bar to the P3 bar; where L1 = |P1 − P0|, L3 = |P3 − P2|, L5 = |P5 − P4|
Calculation: GapInZone(d, zone, since) = a fair value gap of direction d formed at or after bar since that overlaps the zone; for up, the gap is [high two bars earlier, low] when low − high two bars earlier ≥ Gp × ATR(n); for down, the gap is [high, low two bars earlier] when low two bars earlier − high ≥ Gp × ATR(n); overlap means gap top ≥ zone bottom and gap bottom ≤ zone top
Calculation: Stop(d, trade) = min(anchor, low) − B × ATR(n) when d is up, or max(anchor, high) + B × ATR(n) when d is down, where anchor is the corrective pivot of the trade (P2 for trade 3, P4 for trade 5, B for trade C) or, by stop mode, the invalidation pivot (P0 for trade 3, P1 for trade 5, B for trade C) or the trade's entry price − d × A × ATR(n)
Calculation: Invalidated = kill switch on AND ((stage ≥ 2 AND (close − P0) × d < 0 AND Rule 2 on) OR (stage ≥ 4 AND not diagonal AND (close − P1) × d < 0 AND Rule 3 on) OR (stage ≥ 4 AND diagonal AND (close − P2) × d < 0)), where stage, diagonal and d are those of Count
Calculation: Setup3(d) = Count stage 2 with direction d AND Retrace(P0, P1, P2) ≥ F2 × min(Lo2, Hi2) AND Retrace(P0, P1, P2) ≤ Cap2 AND Guidelines ≥ K AND (GapInZone(d, the interval between FibLevel(P1, P0, Lo2) and FibLevel(P1, P0, Hi2), P1 bar) OR gap requirement off) AND no open trade AND no trigger has yet occurred for this P2 pivot AND bars since P2 bar ≤ T3 AND not Invalidated
Calculation: Setup5(d) = Count stage 4 with direction d AND Retrace(P2, P3, P4) ≥ F4a × min(Lo4, Hi4) AND Retrace(P2, P3, P4) ≤ F4b × max(Lo4, Hi4) AND Guidelines ≥ K AND (GapInZone(d, the interval between FibLevel(P3, P2, Lo4) and FibLevel(P3, P2, Hi4), P3 bar) OR gap requirement off) AND no open trade AND no trigger has yet occurred for this P4 pivot AND bars since P4 bar ≤ T5 AND not Invalidated
