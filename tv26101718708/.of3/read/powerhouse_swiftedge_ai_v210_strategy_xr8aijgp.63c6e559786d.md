Calculation: Momentum threshold = base momentum threshold * (1 + ATR(ATR lookback) / close * volatility multiplier)
Calculation: Pre-momentum threshold = momentum threshold * base pre-momentum factor * (1 - ATR(ATR lookback) / close * pre-momentum volatility adjustment)
Calculation: Trend sum = Trend(T1) + Trend(T2) + Trend(T3)
