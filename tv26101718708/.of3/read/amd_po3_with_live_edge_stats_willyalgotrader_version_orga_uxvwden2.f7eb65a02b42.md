Calculation: Compressed range candidate = after the statistical lookback is warmed up and the post-cycle cooldown has elapsed, PercentRank(Highest(high, Donchian lookback) − Lowest(low, Donchian lookback), statistical lookback) <= compression threshold and Donchian width >= minimum-width percentage × close; optionally trim oldest bars while removing each shrinks the full-window width by more than the tail-trim percentage, stopping before the retained window is younger than the minimum range age.
Calculation: Accumulation range = use the retained window’s highest high and lowest low in absolute mode; in pivot mode use the highest confirmed PivotHigh and lowest confirmed PivotLow whose pivot bars are in the window, falling back to the corresponding raw extreme when that side has no pivot; require resulting width >= minimum-width percentage × close. During accumulation, absolute boundaries extend with highs or lows only within the boundary-tolerance fraction of width; pivot boundaries update only on confirmed pivots within that tolerance.
Calculation: Confirmed sweep = in an accumulation range at least the minimum age and before its maximum age budget expires (the budget restarts on rearm), breach exactly one boundary beyond the boundary-tolerance fraction of range width; an immature or two-sided breach invalidates the range. A valid breach must pass enabled filters: if the hard killzone filter is on, it occurs in an enabled session; if the sweep-depth cap is on, excursion <= PercentileNearestRank(TrueRange, statistical lookback, sweep-depth percentile); if the liquidity filter is on, the count of confirmed PivotHighs for an upper breach or PivotLows for a lower breach, within the EQ lookback and boundary-distance tolerance, meets the required pivot count. A rejected breach with a close outside the range invalidates it; a close inside leaves it active. Track the maximum high or minimum low from the breach until a close returns inside the range within the return-bar limit, including a same-bar return; otherwise classify it as a breakout. If the resulting entry is rejected by an enabled hard HTF or confluence filter, an enabled rearm permits one sweep of the opposite boundary and refreshes the age budget.
Calculation: Confluence score = count of enabled components satisfied on the confirmed-sweep bar. On chart bars, use the last completed T2 bar’s high/low as the prior daily levels and the still-forming T2 bar’s open as the daily open. For a long, count prior T2 low swept by the sweep extreme with the range low within the liquidity-level tolerance × ATR of the bar before range start; count the analogous last completed London-session low condition; count close > current T2 open; and count close > current-session VWAP. For a short, use prior T2 high, London-session high, close < current T2 open, and close < current-session VWAP, respectively. London levels use the last completed configured reference session; session VWAP is reset at the configured session start and uses chart-bar HLC3 weighted by volume. Use current ATR if the range-start ATR is unavailable.
Long: Confirmed sweep below the accumulation range AND (hard HTF filter off OR, on chart bars, last completed T1 close > EMA(close, lookback, T1, last completed bar)) AND (minimum-confluence filter off OR Confluence score >= minimum score).
Short: Confirmed sweep above the accumulation range AND (hard HTF filter off OR, on chart bars, last completed T1 close < EMA(close, lookback, T1, last completed bar)) AND (minimum-confluence filter off OR Confluence score >= minimum score).
Calculation: Reference target = for long, upper accumulation boundary + (extension factor − 1) × (upper accumulation boundary − sweep low); for short, lower accumulation boundary − (extension factor − 1) × (sweep high − lower accumulation boundary).
Calculation: Reference stop = for long, sweep low − stop-buffer multiplier × ATR(lookback) from the bar before range start; for short, sweep high + stop-buffer multiplier × that ATR.
Exit: long, after the entry bar, low <= Reference stop OR high >= Reference target OR bars since entry > timeout-bar limit.
Exit: short, after the entry bar, high >= Reference stop OR low <= Reference target OR bars since entry > timeout-bar limit.
