Calculation: BSL = PivotHigh(high, shared pivot-left lookback, shared pivot-right lookback, T1), valid only if every right-lookback T1 high is < the pivot; merge with the first active untouched BSL within absolute price difference <= merge-tick parameter × minimum tick, at max(new pivot, existing level). PivotHigh runs on T1 bars and is mapped with lookahead off to chart bars (last completed T1 bar historically, forming T1 bar live).
Calculation: SSL = PivotLow(low, the same pivot-left and pivot-right lookbacks, T1), valid only if every right-lookback T1 low is > the pivot; merge with the first active untouched SSL within the same threshold, at min(new pivot, existing level). PivotLow runs on T1 bars and is mapped with lookahead off to chart bars (last completed T1 bar historically, forming T1 bar live).
Long: On chart bars, an active BSL is first touched when high >= BSL and, at the first chart bar of the next T1 period, the previous chart-bar close > BSL; OR an active SSL is first touched when low <= SSL and, at the first chart bar of the next T1 period, the previous chart-bar close >= SSL.
