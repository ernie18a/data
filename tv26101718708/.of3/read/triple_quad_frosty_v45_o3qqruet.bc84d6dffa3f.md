Calculation: Long source condition = the selected signal-logic combination of long sources 1–4 being > 0: source 1; sources 1 AND 2; any source; all first three; the selected vote count among the first three; all four; or the selected vote count among all four.
Calculation: Short source condition = the selected signal-logic combination of short sources 1–4 being > 0: source 1; sources 1 AND 2; any source; all first three; the selected vote count among the first three; all four; or the selected vote count among all four.
Calculation: For each enabled A/B/C conditional filter, bar-by-bar mode is bullish when its buy source > 0 and sell source <= 0, bearish when its sell source > 0 and buy source <= 0, and neutral otherwise; persistent mode initializes from those exclusive conditions and updates bullish on a rising edge of buy source > 0 or bearish on a rising edge of sell source > 0, with the bearish update last if both occur.
Calculation: Conditional pass for a side = the selected combination of enabled A/B/C filters whose persistent or bar-by-bar direction matches that side; when no filters are enabled, both sides pass.
Calculation: Forced-close trigger = force-at-window-end mode AND the previous chart bar was inside a configured New York trading window AND the current chart bar is outside it, OR specific-time mode AND ((the New York calendar day changed and current time is at or after the configured time) OR (the day is unchanged and previous time was before the configured time and current time is at or after it)).
Calculation: Long furthest entry price = the minimum entry price among open long legs, or the long position average entry price if no leg entry price is available.
Calculation: Long closest entry price = the maximum entry price among open long legs, or the long position average entry price if no leg entry price is available.
Calculation: Short furthest entry price = the maximum entry price among open short legs, or the short position average entry price if no leg entry price is available.
Calculation: Short closest entry price = the minimum entry price among open short legs, or the short position average entry price if no leg entry price is available.
Calculation: Long running peak = Highest(high, bars since the long position opened) when high/low trailing is selected, otherwise Highest(close, bars since the long position opened).
Calculation: Short running trough = Lowest(low, bars since the short position opened) when high/low trailing is selected, otherwise Lowest(close, bars since the short position opened).
Long: A, B, or C buy source > 0 AND its corresponding sell source <= 0 crosses above true.
Short: A, B, or C sell source > 0 AND its corresponding buy source <= 0 crosses above true.
Long: Conditional pass for long AND NOT conditional pass for short.
Short: Conditional pass for short AND NOT conditional pass for long.
Long: Long source condition AND (local HMA filter disabled OR (close > HMA(close, local HMA lookback) AND HMA(close, local HMA lookback) - HMA(close, local HMA lookback)[slope lookback] > minimum slope in bricks × brick size AND abs(close - HMA(close, local HMA lookback)) >= minimum distance in bricks × brick size)) AND (HTF HMA filter disabled OR close > HMA(close, HTF HMA lookback, T1, current bar still forming, sampled on chart bars with lookahead off)) AND conditional pass for long crosses from false to true on the chart bar; long signals are enabled; aggregate entry mode is selected OR per-source entry mode is selected and at least one of long sources 1–4 > 0 crosses above true; the time filter is disabled OR current New York time is within a configured trading window; the day filter is disabled OR the current New York weekday is enabled; the trade limit is disabled OR trades opened on the current New York day are below the configured limit OR a position is open; and opposite-entry blocking is disabled OR the position is flat or long.
Short: Short source condition AND (local HMA filter disabled OR (close < HMA(close, local HMA lookback) AND HMA(close, local HMA lookback) - HMA(close, local HMA lookback)[slope lookback] < -minimum slope in bricks × brick size AND abs(close - HMA(close, local HMA lookback)) >= minimum distance in bricks × brick size)) AND (HTF HMA filter disabled OR close < HMA(close, HTF HMA lookback, T1, current bar still forming, sampled on chart bars with lookahead off)) AND conditional pass for short crosses from false to true on the chart bar; short signals are enabled; aggregate entry mode is selected OR per-source entry mode is selected and at least one of short sources 1–4 > 0 crosses above true; the time filter is disabled OR current New York time is within a configured trading window; the day filter is disabled OR the current New York weekday is enabled; the trade limit is disabled OR trades opened on the current New York day are below the configured limit OR a position is open; and opposite-entry blocking is disabled OR the position is flat or short.
Exit: long, low <= (static stop enabled ? long closest entry price - static stop-loss bricks × brick size : ((long running peak - long furthest entry price) >= trail-start bricks × brick size ? long running peak - trailing-distance bricks × brick size : long closest entry price - initial-stop bricks × brick size)) OR (static take-profit enabled AND high >= long furthest entry price + take-profit bricks × brick size) OR forced-close trigger.
Exit: short, high >= (static stop enabled ? short closest entry price + static stop-loss bricks × brick size : ((short furthest entry price - short running trough) >= trail-start bricks × brick size ? short running trough + trailing-distance bricks × brick size : short closest entry price + initial-stop bricks × brick size)) OR (static take-profit enabled AND low <= short furthest entry price - take-profit bricks × brick size) OR forced-close trigger.
