Calculation: Band length = clamp(round(cycle multiplier * Hilbert dominant cycle period of (high + low) / 2), adaptive minimum, adaptive maximum)
Calculation: Midline = by midline type: SMA(close, Band length), EMA(close, Band length), rolling VWAP(close, volume, Band length) (SMA when window volume is zero), or median(close, Band length)
Calculation: Tail factor = clamp(1 + fat-tail gain * (Kurtosis(close about Midline, Band length) / 3 - 1), 1, tail factor cap)
Calculation: Containment multiplier = clamp(Containment multiplier[1] + controller gain * (containment target / 100 - SMA(In band, containment window)), multiplier floor, multiplier cap), where In band = 1 if Lower band(main) <= close <= Upper band(main), else 0
Calculation: Upper deviation = Deviation method * Tail factor * Containment multiplier[1], where Deviation method is chosen by a deviation-method parameter among: sqrt(mean over Band length of (close - Midline)^2); sqrt(2) * sqrt(mean over Band length of max(close - Midline, 0)^2); 1.4826 * median over Band length of abs(close - median of close over Band length); sqrt(EWMA of squared close changes with EWMA decay); max(Percentile(close, upper quantile level, Band length) - Midline, 0) / main band multiplier, where upper quantile level = 100 - (100 - containment target) / 2
Calculation: Lower deviation = Deviation method (lower side) * Tail factor * Containment multiplier[1], where the lower side is sqrt(2) * sqrt(mean over Band length of min(close - Midline, 0)^2) for the semi-deviation method; max(Midline - Percentile(close, (100 - containment target) / 2, Band length), 0) / main band multiplier for the quantile method; other methods as for the upper deviation
Calculation: Upper band(M) = Midline + Upper deviation * M, where M is the inner, main, or outer band multiplier, with inner < main < outer
Calculation: Lower band(M) = Midline - Lower deviation * M
Calculation: Percent B = (close - Lower band(main)) / (Upper band(main) - Lower band(main)), or the midpoint when that denominator is zero
Calculation: Band z-score = (close - Midline) / Upper deviation if close >= Midline, else (close - Midline) / Lower deviation; 0 when the used deviation is not positive
Calculation: Trend state = ADX(ADX length) > ADX threshold AND Efficiency ratio(close, efficiency length) > efficiency threshold
Calculation: Volatility cluster = (I - SMA(I, normalization window)) / STDEV(I, normalization window) > cluster threshold, where I = I[1] * exp(-cluster decay) + abs(ln(close) - ln(close[1]))
Calculation: Market regime = Trend if Trend state; else Volatile if Volatility cluster; else Range
Calculation: Bull trend = close > EMA(close, trend MA length)
Calculation: Walk up count = Walk up count[1] + 1 if close > Upper band(main), else 0
Calculation: Walk down count = Walk down count[1] + 1 if close < Lower band(main), else 0
Calculation: Mean-reverting = Variance ratio < 1, where Variance ratio = Variance(close - close[q], VR window) / (q * Variance(close - close[1], VR window)), q = VR period, and false when undefined
Calculation: Half-life = -ln(2) / ln(b) when 0 < b < 1, otherwise undefined, where b = Cov(spread, spread[1]) / Var(spread[1]) over Half-life window and spread = close - Midline
Calculation: Volume thrust = Volume > volume multiple * SMA(Volume, volume length) OR cumulative Volume = 0
Calculation: Side(T) = sign(close - SMA(close, side length)) computed on bars of T, using the last completed bar of T; T5 is the higher timeframe
Calculation: MTF bull count = number of T1..T4 with Side(T) > 0, where T1 < T2 < T3 < T4
Calculation: MTF bear count = number of T1..T4 with Side(T) < 0
Calculation: Order-flow sign = sign(CVD - CVD[flow lookback]), where CVD = running sum of bar deltas, and each chart bar's delta = sum over its T6 sub-bars of (+1 if sub-bar close >= open, else -1) * sub-bar volume, or (+1 if close >= open, else -1) * volume when it has no T6 sub-bars
Calculation: Class edge(C) = clamp(Hit share(C) - Base rate(C), -edge cap, edge cap) when C has at least calibration min samples resolved, else 0. C events are Fade signal bars (C = Fade) or Ride signal bars (C = Ride) occurring at least calibration min gap bars after the previous C event; each carries its signal direction, entry = close, ATR at entry, and uniqueness weight 1 / (1 + count of unresolved events of all classes). An event resolves on the first bar from its own bar onward where the adverse extreme (low for long, high for short) reaches calibration stop multiple * ATR at entry (checked first), or the favorable extreme reaches calibration profit multiple * ATR at entry, or calibration horizon bars have passed with the close at least calibration profit multiple * ATR beyond entry in its direction. Hit share(C) = running sum of weights of resolved C wins / running sum of weights of resolved C events, where each resolution first multiplies both running sums by calibration decay. Base rate(C) = mean over resolved C events of the share of resolved past per-bar samples in the event's regime whose close, calibration horizon bars later, was at least calibration profit multiple * that sample's ATR beyond its close in the event's direction.
Calculation: Conviction(d) = round(100 * clamp((stretch weight * Stretch + regime weight * Regime fit + MTF weight * MTF agreement + half-life weight * Half-life score + edge weight * Edge score + volume weight * Volume score + flow weight * Flow score) / (sum of the seven weights), 0, 1)); for a Fade signal: Stretch = clamp(abs(Band z-score) / outer band multiplier, 0, 1), Regime fit = (Market regime = Range ? 1 : off-regime factor) * (Mean-reverting ? 1 : mismatch factor), MTF agreement = 1 - abs(MTF bull count - MTF bear count) / number of MTF timeframes, Half-life score = (Half-life undefined ? missing fade half-life score : clamp(1 - Half-life / (Half-life window * half-life reference fraction), 0, 1)), Edge score = clamp(edge offset + Class edge(Fade), 0, 1); for a Ride signal: Stretch = clamp(max(Walk up count, Walk down count) / (walk stretch scale * walk streak length), 0, 1), Regime fit = (Trend state ? 1 : off-regime factor) * (Mean-reverting ? mismatch factor : 1), MTF agreement = (MTF bull count if d = +1, else MTF bear count) / number of MTF timeframes, Half-life score = (Half-life undefined ? missing ride half-life score : present ride half-life score), Edge score = clamp(edge offset + Class edge(Ride), 0, 1); for both: Volume score = (Volume thrust ? 1 : volume miss score), Flow score = (Order-flow sign = d ? 1 : flow miss score)
Calculation: Squeeze fire = (Percent rank of Bandwidth over squeeze window > squeeze threshold) AND (bars since last bar with Percent rank <= squeeze threshold) <= expansion window AND Bandwidth > Bandwidth[1], where Bandwidth = (Upper band(main) - Lower band(main)) / Midline
Calculation: Fade long signal = Market regime = Range AND low <= Lower band(main) AND close > Lower band(main) AND (Percent B[1] <= 0 OR Band z-score[1] <= -main band multiplier) AND Volume thrust
Calculation: Fade short signal = Market regime = Range AND high >= Upper band(main) AND close < Upper band(main) AND (Percent B[1] >= 1 OR Band z-score[1] >= main band multiplier) AND Volume thrust
Calculation: Ride long signal = Trend state AND Bull trend AND (Walk up count >= walk streak length OR (close > Upper band(inner) AND close > close[1])) AND Volume thrust AND Side(T5) >= 0
Calculation: Ride short signal = Trend state AND NOT Bull trend AND (Walk down count >= walk streak length OR (close < Lower band(inner) AND close < close[1])) AND Volume thrust AND Side(T5) <= 0
Calculation: Fade signal = Fade long signal OR Fade short signal
Calculation: Ride signal = Ride long signal OR Ride short signal
Calculation: Long signal = Fade long signal OR Ride long signal
Calculation: Short signal = Fade short signal OR Ride short signal
Calculation: Volatility spike = Volatility-index z-score >= spike threshold, where Volatility-index z-score = (volatility-index close - SMA(volatility-index close, z window)) / STDEV(volatility-index close, z window), and 0 when no volatility-index close is available
Calculation: Cross-asset momentum = sign(cross-asset close - cross-asset close[momentum length]) * cross-asset sign, and 0 when no cross-asset close is available
Calculation: Initial long stop = by stop mode: Lower band(outer) - ATR(ATR length) * stop padding; or entry price - ATR(ATR length) * (1 + stop padding); or entry price - (Half-life undefined ? missing-half-life ATR multiple * ATR(ATR length) : abs(entry price - Midline)) - ATR(ATR length) * stop padding; evaluated on the entry bar, where entry price = close of the entry bar
Calculation: Initial short stop = by stop mode: Upper band(outer) + ATR(ATR length) * stop padding; or entry price + ATR(ATR length) * (1 + stop padding); or entry price + (Half-life undefined ? missing-half-life ATR multiple * ATR(ATR length) : abs(entry price - Midline)) + ATR(ATR length) * stop padding; evaluated on the entry bar
Calculation: Long second target = if Fade signal on the entry bar then Upper band(inner) on the entry bar, else entry price + second target multiple * (entry price - Initial long stop), with first target multiple < second target multiple
Calculation: Short second target = if Fade signal on the entry bar then Lower band(inner) on the entry bar, else entry price - second target multiple * (Initial short stop - entry price)
Calculation: Long stop = entry price if any bar from the entry bar through the previous bar had high >= Long first target, else Initial long stop, where Long first target = if Fade signal on the entry bar then Midline on the entry bar, else entry price + first target multiple * (entry price - Initial long stop)
Calculation: Short stop = entry price if any bar from the entry bar through the previous bar had low <= Short first target, else Initial short stop, where Short first target = if Fade signal on the entry bar then Midline on the entry bar, else entry price - first target multiple * (Initial short stop - entry price)
Long: Fade long signal
Short: Fade short signal
Long: Ride long signal
Short: Ride short signal
Long: Squeeze fire AND close > Midline
Short: Squeeze fire AND close <= Midline
Long: pivot low of Percent B, with left length and right length, confirmed on this bar AND a previous pivot low of Percent B exists AND close[right length] < close at previous pivot low AND Percent B[right length] > Percent B at previous pivot low
Short: pivot high of Percent B, with left length and right length, confirmed on this bar AND a previous pivot high of Percent B exists AND close[right length] > close at previous pivot high AND Percent B[right length] < Percent B at previous pivot high
Long: position side is flat AND Long signal AND Conviction(+1) >= min conviction AND NOT (Volatility spike AND Fade signal) AND NOT (Ride signal AND MTF bull count < min alignment) AND NOT (Ride signal AND Cross-asset momentum = -1)
Short: position side is flat AND Short signal AND NOT Long signal AND Conviction(-1) >= min conviction AND NOT (Volatility spike AND Fade signal) AND NOT (Ride signal AND MTF bear count < min alignment) AND NOT (Ride signal AND Cross-asset momentum = +1)
Exit: long, low <= Long stop OR high >= Long second target
Exit: short, high >= Short stop OR low <= Short second target
