Calculation: Regular bullish divergence(oscillator) = at a confirmed pivot low, the current pivot low is below the previous confirmed pivot low and the oscillator value sampled at the current pivot is above its value at the previous pivot; regular bearish divergence is the reverse comparison at confirmed pivot highs.
Calculation: Directional divergence stack = count, separately for bullish and bearish divergence, the most recent same-direction regular divergence event for each of RSI(close, lookback), MACD histogram(close, shorter fast lookback, longer slow lookback, signal lookback), CCI(close, lookback), MFI(hlc3, lookback), and OBV. The strict count includes events on the current confirmed pivot bar; the window count includes events within the tolerance, in chart bars, of that pivot. Use the strict count when it reaches the minimum stack; otherwise use the window count when near-stack events are enabled and it reaches the minimum stack; otherwise use zero.
Calculation: Normalized(value, lower bound, upper bound) = clamp((value - lower bound) / (upper bound - lower bound), unit interval).
Calculation: Swing ATR = absolute difference between the current and previous same-direction pivot prices divided by ATR at the current pivot; use current ATR if ATR at the pivot is unavailable, and use at least the minimum price increment. Distance ATR = absolute difference between current close and the current pivot price divided by the greater of current ATR and the minimum price increment.
Calculation: Directional confirmation = confirmed in pivot-only mode; in close-confirmation mode, current close must be above the pivot candle high for bullish or below the pivot candle low for bearish; in strict-close mode, it must also be above the shorter-lookback EMA(close) for bullish or below it for bearish.
Calculation: Directional trend points = favorable-trend points when the shorter-lookback EMA(close) is below the longer-lookback EMA(close) for bullish or above it for bearish; otherwise use intermediate-trend points when close is below the shorter EMA for bullish or above it for bearish; otherwise use neutral-trend points.
Calculation: Readiness score(direction) = round(clamp(stack × points per oscillator × oscillator weight + Normalized(swing ATR, swing lower bound, swing upper bound) × score cap × swing weight + trend points × trend weight + confirmation points × confirmation weight + (score cap - Normalized(distance ATR, distance lower bound, distance upper bound) × score cap) × proximity weight + sensitivity adjustment, score floor, score cap)). Confirmation points use the confirmed points when directional confirmation is true and unconfirmed points otherwise.
Calculation: Active event is replaced by a newly accepted event when no event is active, the prior event is invalidated, followed, or expired, the new direction differs, its score is at least the active score, or it is ready; if both directions are accepted on the same bar, the bearish event replaces the bullish event. An event expires when chart bars since its pivot exceed the expiry duration.
Calculation: Bullish invalidation level = pivot low - ATR at pivot × invalidation-distance parameter; bearish invalidation level = pivot high + ATR at pivot × invalidation-distance parameter.
Calculation: Bullish follow-through target = the most recent confirmed pivot high if it is above current close, otherwise current close + ATR at pivot × max(minimum target multiple, swing ATR × target swing multiple); bearish follow-through target = the most recent confirmed pivot low if it is below current close, otherwise current close - ATR at pivot × max(minimum target multiple, swing ATR × target swing multiple).
Long: confirmed pivot low AND bullish stack >= minimum stack AND bullish readiness score >= max(score floor, minimum ready score - watch-score margin).
Short: confirmed pivot high AND bearish stack >= minimum stack AND bearish readiness score >= max(score floor, minimum ready score - watch-score margin).
Long: SMT module enabled AND confirmed pivot low AND ((same-direction correlation setting AND chart lower-low status differs from correlated-symbol lower-low status) OR (inverse-direction correlation setting AND the statuses match)), comparing chart and correlated-symbol lows sampled at the current and previous confirmed chart pivot lows.
Short: SMT module enabled AND confirmed pivot high AND ((same-direction correlation setting AND chart higher-high status differs from correlated-symbol higher-high status) OR (inverse-direction correlation setting AND the statuses match)), comparing chart and correlated-symbol highs sampled at the current and previous confirmed chart pivot highs.
Exit: long, active event is bullish, unexpired, and neither previously invalidated nor followed AND low <= bullish invalidation level.
Exit: long, active event is bullish, unexpired, and neither previously invalidated nor followed AND low > bullish invalidation level AND high >= bullish follow-through target.
Exit: short, active event is bearish, unexpired, and neither previously invalidated nor followed AND high >= bearish invalidation level.
Exit: short, active event is bearish, unexpired, and neither previously invalidated nor followed AND high < bearish invalidation level AND low <= bearish follow-through target.
