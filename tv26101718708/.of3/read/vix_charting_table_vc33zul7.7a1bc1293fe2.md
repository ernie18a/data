Calculation: Dual-range filter line(short lookback, short multiplier, long lookback, long multiplier) = on each source bar, let R be the average of EMA(EMA(abs(close-close[1]), short lookback), 2×short lookback−1)×short multiplier and EMA(EMA(abs(close-close[1]), long lookback), 2×long lookback−1)×long multiplier; recursively set F to max(close−R,F[1]) if close>F[1], otherwise min(close+R,F[1]); set U to close-filtered value F plus R if F+R<U[1] OR close[1]>U[1], otherwise U[1]; set L to F−R if F−R>L[1] OR close[1]<L[1], otherwise L[1]; set the line to U if its prior value equals U[1] and close≤U, else L if its prior value equals U[1], else L if its prior value equals L[1] and close≥L, else U if its prior value equals L[1], otherwise U; recursive prior values default to zero. Use the same four parameters for both timeframe calculations.
Long: selected reference series close on the chart timeframe, or its last completed T1 close when chart-timeframe data is unavailable, ≤ Dual-range filter line computed on T1 bars and sampled on chart bars from the last completed T1 bar
Short: selected reference series close on the chart timeframe, or its last completed T1 close when chart-timeframe data is unavailable, > Dual-range filter line computed on T1 bars and sampled on chart bars from the last completed T1 bar
Exit: long, selected reference series close on the chart timeframe, or its last completed T1 close when chart-timeframe data is unavailable, crosses above Dual-range filter line computed on T2 bars and sampled on chart bars from the last completed T2 bar
Calculation: TRF(price, fast period, fast multiplier, slow period, slow multiplier) = average of the fast and slow smoothed ranges, each smoothed range = multiplier × EMA(EMA(abs(price − prior price), period), 2 × period − 1); filtered price = max(prior filtered price, price − range) when price > prior price, otherwise min(prior filtered price, price + range); upper band = filtered price + range when it is below the prior upper band or prior price is above the prior upper band, otherwise prior upper band; lower band = filtered price − range when it is above the prior lower band or prior price is below the prior lower band, otherwise prior lower band; when the prior line is the upper band, use the current upper band if price ≤ it and the lower band otherwise; when the prior line is the lower band, use the current lower band if price ≥ it and the upper band otherwise
Short: chart-timeframe VIX close (or prior confirmed T1 VIX close if unavailable) > prior confirmed T1 TRF(VIX close, fast period, fast multiplier, slow period, slow multiplier)
Long: chart-timeframe VIX close (or prior confirmed T1 VIX close if unavailable) ≤ prior confirmed T1 TRF(VIX close, fast period, fast multiplier, slow period, slow multiplier)
Exit: long, chart-timeframe VIX close (or prior confirmed T1 VIX close if unavailable) > prior confirmed T2 TRF(VIX close, fast period, fast multiplier, slow period, slow multiplier) after not being above it on the prior chart bar
