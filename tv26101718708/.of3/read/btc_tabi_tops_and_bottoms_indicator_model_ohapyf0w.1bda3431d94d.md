Calculation: composite score = EMA of 100 times the weighted mean of these 18 components, using a separate weight for each component and the shared percentile lookback: percentile rank(close / SMA(close, long SMA lookback)); percentile rank(close / SMA(close, Mayer SMA lookback)); percentile rank((SMA(close, short Pi SMA lookback) - Pi multiplier × SMA(close, long SMA lookback)) / SMA(close, long SMA lookback)); percentile rank(close / SMA(close, Puell SMA lookback)); RSI(close, RSI lookback) normalized to 0–1; percentile rank(log(close) - zero-offset LinReg(log(close), percentile lookback), percentile lookback); percentile rank(ATR(ATR lookback) / SMA(ATR(ATR lookback), ATR average lookback), percentile lookback); percentile rank(MVRV series, percentile lookback); one minus percentile rank(dominance series, percentile lookback); percentile rank((close - SMA(close, NUPL SMA lookback)) / close, percentile lookback); percentile rank(SMA(close, shorter holder SMA lookback) / SMA(close, longer holder SMA lookback), percentile lookback); percentile rank(clamp(short-lookback return / (absolute long-lookback return + stabilization offset), lower clamp parameter, upper clamp parameter), percentile lookback); percentile rank(close / sqrt(EMA(close, reserve-risk EMA lookback) × SMA(close, shorter holder SMA lookback)), percentile lookback); percentile rank(RSI(close on T2 bars, RSI lookback) from the last completed T2 bar, normalized to 0–1, percentile lookback); percentile rank(ETH/BTC close series, percentile lookback); percentile rank(BTC market-cap series / (USDT market-cap series + USDC market-cap series + stabilization offset), percentile lookback); percentile rank(EMA(exchange premium, premium EMA lookback), percentile lookback); percentile rank(SMA(hash-rate series, shorter hash SMA lookback) / SMA(hash-rate series, longer hash SMA lookback), percentile lookback). The score EMA uses its separate smoothing parameter. T1 series are sampled on chart bars using the last completed T1 bar historically and the forming T1 bar in real time; their EMA, SMA, and percentile-rank calculations run on chart bars. RSI on T2 runs on T2 bars, and its completed-bar value is ranked on chart bars. Missing MVRV, dominance, monthly RSI, ETH/BTC, or stablecoin-ratio inputs use the neutral percentile rank; missing USDC market cap contributes zero; missing exchange-price inputs produce zero premium; missing hash-rate input uses chart close.
