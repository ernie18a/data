Calculation: Bull trend score = fast/slow trend points if EMA(close, shorter fast lookback) > EMA(close, longer slow lookback), plus price/macro trend points if close > EMA(close, longest macro lookback), plus fast-slope points if (EMA(close, fast lookback) - EMA(close, fast lookback)[slope lookback]) / slope lookback > 0, plus slow-slope points if (EMA(close, slow lookback) - EMA(close, slow lookback)[slope lookback]) / slope lookback > 0; each contribution is zero when its condition is false.
Calculation: Bear trend score = the corresponding trend points if EMA(close, fast lookback) < EMA(close, slow lookback), close < EMA(close, macro lookback), the fast EMA slope < 0, and the slow EMA slope < 0, respectively; each contribution is zero when its condition is false.
Calculation: Bull momentum score = RSI points if RSI(close, RSI lookback) > RSI midline, plus MACD points if MACD line > MACD signal line, plus histogram points if MACD histogram > its prior-bar value; each contribution is zero when its condition is false. MACD uses a shorter fast lookback, longer slow lookback, and separate signal lookback.
Calculation: Bear momentum score = the corresponding momentum points if RSI(close, RSI lookback) < RSI midline, MACD line < MACD signal line, and MACD histogram < its prior-bar value, respectively; each contribution is zero when its condition is false.
Calculation: Volume ratio = volume / SMA(volume, volume-average lookback) when that SMA is positive, otherwise 1.
Calculation: Bull volume score = volume-spike points if volume ratio >= spike threshold and close > open, plus volume-expansion points if volume > volume[1] and close > open; each contribution is zero when its condition is false.
Calculation: Bear volume score = the corresponding volume points if volume ratio >= spike threshold and close < open, and if volume > volume[1] and close < open, respectively; each contribution is zero when its condition is false.
Calculation: Confirmed pivot high = high[pivot lookback + 1] when it is strictly greater than every other high at offsets 1 through 2 × pivot lookback + 1; retain the two most recent confirmed pivot highs.
Calculation: Confirmed pivot low = low[pivot lookback + 1] when it is strictly less than every other low at offsets 1 through 2 × pivot lookback + 1; retain the two most recent confirmed pivot lows.
Calculation: Bull BOS event = close[1] > the latest confirmed pivot high and the prior BOS direction is bearish or neutral; record bullish as the BOS direction when this event occurs. Initial BOS direction is neutral.
Calculation: Bear BOS event = close[1] < the latest confirmed pivot low and the prior BOS direction is bullish or neutral; record bearish as the BOS direction when this event occurs. Initial BOS direction is neutral.
Calculation: Bull structure score = structure-sequence points if the latest two confirmed pivot highs and latest two confirmed pivot lows are both rising, plus BOS points if a bull BOS event occurs; each contribution is zero when its condition is false.
Calculation: Bear structure score = the corresponding structure-sequence points if the latest two confirmed pivot highs and latest two confirmed pivot lows are both falling, plus BOS points if a bear BOS event occurs; each contribution is zero when its condition is false.
Calculation: Bull score = (bull trend score × trend leg weight + bull momentum score × momentum leg weight + bull volume score × volume leg weight + bull structure score × structure leg weight) / the sum of the four leg weights, using 1 as the divisor when that sum is zero. Bear score is calculated the same way from the bear scores. All these scores use chart bars.
Calculation: Initial risk distance = ATR(ATR lookback) on the latest signal bar × stop-distance multiplier.
Long: On chart-bar values, bull score > bear score AND bull score >= medium-score threshold.
Short: On chart-bar values, bear score > bull score AND bear score >= medium-score threshold.
Long: On a confirmed chart bar, bull score >= medium-score threshold AND bull score - bear score >= minimum-score-gap parameter AND (HTF filter disabled OR prior completed close on T1 is available and > prior completed EMA(close, slow EMA lookback) on T1) AND (volatility filter disabled OR ATR as a percentage of close >= minimum ATR-percentage parameter, with ATR percentage zero when close <= 0) AND no prior long signal exists OR chart bars since the prior long signal >= minimum-bars-gap parameter. T1 resolves to the selected timeframe when it is at least the chart timeframe, otherwise the chart timeframe; the filter uses its last completed bar on chart bars.
Short: On a confirmed chart bar, bear score >= medium-score threshold AND bear score - bull score >= minimum-score-gap parameter AND (HTF filter disabled OR prior completed close on T1 is available and < prior completed EMA(close, slow EMA lookback) on T1) AND (volatility filter disabled OR ATR as a percentage of close >= minimum ATR-percentage parameter, with ATR percentage zero when close <= 0) AND no prior short signal exists OR chart bars since the prior short signal >= minimum-bars-gap parameter. T1 resolves to the selected timeframe when it is at least the chart timeframe, otherwise the chart timeframe; the filter uses its last completed bar on chart bars.
Exit: long, latest signal direction is long AND (high >= entry price + initial risk distance × first target R:R parameter OR high >= entry price + initial risk distance × second target R:R parameter OR high >= entry price + initial risk distance × third target R:R parameter).
Exit: short, latest signal direction is short AND (low <= entry price - initial risk distance × first target R:R parameter OR low <= entry price - initial risk distance × second target R:R parameter OR low <= entry price - initial risk distance × third target R:R parameter).
