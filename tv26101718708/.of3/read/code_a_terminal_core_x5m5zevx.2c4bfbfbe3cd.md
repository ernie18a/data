Calculation: Projected HMA = previous-bar HMA(source, trend length) + (previous-bar HMA(source, trend length) - HMA(source, trend length)[trend lookback + one bar]) / trend lookback
Calculation: Wave difference = round(WaveTrend main line(hlc3, channel lookback, average lookback) - SMA(WaveTrend main line(hlc3, channel lookback, average lookback), wave-signal lookback), rounding precision)
Calculation: Money flow = SMA(((close - open) / (high - low)) * money-flow multiplier, money-flow lookback) - money-flow offset
Calculation: Bias score = WMA(sum over each lag from shorter bias lag through longer bias lag, inclusive, of +1 when close > close[lag] and -1 otherwise), score-smoothing lookback) * score scale / score divisor
Calculation: Upward sequence count = close > close[sequence lag] ? previous-bar upward sequence count + 1 : 0, with initial count 0
Calculation: Downward sequence count = close < close[sequence lag] ? previous-bar downward sequence count + 1 : 0, with initial count 0
Calculation: Upward run measure = upward sequence count - ValueWhen(upward sequence count < previous-bar upward sequence count, upward sequence count, previous occurrence)
Calculation: Downward run measure = downward sequence count - ValueWhen(downward sequence count < previous-bar downward sequence count, downward sequence count, previous occurrence)
