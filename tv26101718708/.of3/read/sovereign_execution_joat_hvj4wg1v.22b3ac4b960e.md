Calculation: Regime MA = core MA * (1 - ATR ratio) + core MA[1] * ATR ratio, where base MA = selected moving average(sqrt(close), regime MA lookback), coefficient = 2 / (1 + regime MA lookback), core MA = base MA * (base MA * coefficient + base MA[1] * (1 - coefficient)), and ATR ratio = ATR(regime ATR lookback) / ATR(rounded half regime ATR lookback)
Calculation: Regime state = 1 when close > Regime MA + ATR(regime ATR lookback) * regime ATR factor, -1 when close < Regime MA - ATR(regime ATR lookback) * regime ATR factor, otherwise the previous regime state; initially 0
Calculation: Compression = 2 * Bollinger multiplier * StDev(close, Bollinger lookback) < SMA(2 * Bollinger multiplier * StDev(close, Bollinger lookback), width average lookback) * compression factor
Calculation: Displacement = EMA(momentum composite * momentum weight + volume displacement * volume weight, displacement smoothing lookback), where momentum composite = (normalized Bollinger %B + normalized CCI + normalized ROC) / 3, normalized Bollinger %B = clamp(2 * (Bollinger %B - 0.5), -1, 1), Bollinger %B = (close - (SMA(close, Bollinger lookback) - Bollinger multiplier * StDev(close, Bollinger lookback))) / (2 * Bollinger multiplier * StDev(close, Bollinger lookback)) or 0.5 when the denominator is 0, normalized CCI = clamp(CCI(close, CCI lookback) / CCI normalization scale, -1, 1), normalized ROC = clamp(ROC(close, ROC lookback) / (StDev(ROC(close, ROC lookback), ROC normalization lookback) * ROC deviation multiplier), -1, 1) or 0 when the denominator is 0, and volume displacement = candle direction * body ratio * volume intensity, with candle direction = 1 if close > open, -1 if close < open, otherwise 0; body ratio = abs(close - open) / (high - low) or 0 when high = low; and volume intensity = clamp(volume / SMA(volume, volume lookback) - 1, -1, 1) or 0 when the average is 0
Calculation: Structure state = 0 when high[swing lookback] > Highest(high, swing lookback), otherwise 1 when low[swing lookback] < Lowest(low, swing lookback), otherwise the previous structure state; structure score = 1 when structure state = 1, otherwise -1
Calculation: Current timeframe score = (trend score + momentum composite + volatility score + structure score + volume conviction) / 5, where trend score = 1 if close > EMA(close, regime MA lookback), otherwise -1; volatility score = clamp((Bollinger width / SMA(Bollinger width, width average lookback) - 1) * volatility score scale, -1, 1) or 0 when the average is 0; Bollinger width = 2 * Bollinger multiplier * StDev(close, Bollinger lookback); and volume conviction = candle direction * volume intensity
Calculation: Higher timeframe score = (trend score + Bollinger bias) / 2, where trend score = 1 if close > EMA(close, regime MA lookback), otherwise -1, and Bollinger bias = 1 if Bollinger %B > 0.5, -1 if Bollinger %B < 0, otherwise 0; calculate on T1 bars using the T1 bar still forming, and carry the result onto chart bars
Calculation: Confluence score = clamp(round(100 * (current timeframe weight * current timeframe score + higher timeframe weight * higher timeframe score + 1) / 2), 0, 100)
Calculation: Long protective stop = max(entry price - ATR(stop ATR lookback at entry) * stop multiplier, highest since entry of close - ATR(stop ATR lookback) * trail multiplier) when trailing is enabled; otherwise entry price - ATR(stop ATR lookback at entry) * stop multiplier
Calculation: Short protective stop = min(entry price + ATR(stop ATR lookback at entry) * stop multiplier, lowest since entry of close + ATR(stop ATR lookback) * trail multiplier) when trailing is enabled; otherwise entry price + ATR(stop ATR lookback at entry) * stop multiplier
Long: Regime state = 1
Short: Regime state = -1
Long: Displacement > StDev(Displacement, displacement threshold lookback) * displacement threshold multiplier
Short: Displacement < -StDev(Displacement, displacement threshold lookback) * displacement threshold multiplier
Long: Confluence score >= long bias threshold OR Confluence score >= strong long bias threshold
Short: Confluence score <= short bias threshold OR Confluence score <= strong short bias threshold
Long: Regime state = 1 AND NOT Compression AND Confluence score >= long entry threshold AND Displacement > StDev(Displacement, displacement threshold lookback) * displacement threshold multiplier AND (session filter disabled OR UTC hour is within any configured session range) AND (FVG filter disabled OR there exists a chart bar offset n from 1 through FVG lookback where low[n] > high[n + 2] AND close[n + 1] > high[n + 2]) AND bar is confirmed AND the same setup was false on the previous chart bar
Short: Regime state = -1 AND NOT Compression AND Confluence score <= short entry threshold AND Displacement < -StDev(Displacement, displacement threshold lookback) * displacement threshold multiplier AND (session filter disabled OR UTC hour is within any configured session range) AND (FVG filter disabled OR there exists a chart bar offset n from 1 through FVG lookback where high[n] < low[n + 2] AND close[n + 1] < low[n + 2]) AND bar is confirmed AND the same setup was false on the previous chart bar
Exit: Long, low <= Long protective stop OR high >= entry price + ATR(stop ATR lookback at entry) * stop multiplier * reward-risk ratio OR Regime state = -1 OR Compression OR Displacement < -StDev(Displacement, displacement threshold lookback) * displacement threshold multiplier
Exit: Short, high >= Short protective stop OR low <= entry price - ATR(stop ATR lookback at entry) * stop multiplier * reward-risk ratio OR Regime state = 1 OR Compression OR Displacement > StDev(Displacement, displacement threshold lookback) * displacement threshold multiplier
