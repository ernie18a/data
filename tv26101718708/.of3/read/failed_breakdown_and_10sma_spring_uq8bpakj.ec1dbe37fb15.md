Calculation: liquidity filter = SMA(volume, volume-average lookback parameter) >= minimum-average-volume parameter AND close >= minimum-price parameter
Calculation: short-SMA wick depth percent = 100 * (SMA(close, short lookback) - low) / SMA(close, short lookback)
Calculation: medium-SMA stretch percent = 100 * (close - SMA(close, medium lookback)) / SMA(close, medium lookback)
Calculation: close-strength ratio = (close - low) / (high - low)

Calculation: wick-spring cooldown count = 1 after a wick spring fires; otherwise prior count + 1; initially above cooldown parameter
