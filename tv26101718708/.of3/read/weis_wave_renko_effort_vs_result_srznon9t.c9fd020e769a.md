Calculation: Renko direction = direction of the recursive Renko price change, carrying the prior direction when unchanged; from a prior price initially zero, the Renko price moves to the selected high when it exceeds the prior price by the assignment size, to the selected low when it falls below the prior price by the assignment size, and otherwise holds; assignment size is ATR(rounded assignment lookback), fixed assignment amount, or close/price divisor according to the assignment method; selected high and low are close, max(open, close)/min(open, close), or high/low according to the price source
Calculation: Wave effort = sum(volume) or sum(TrueRange) over consecutive chart bars with the same Renko direction, using the effort-source setting and falling back to TrueRange when that setting selects automatic fallback and volume is unavailable; reset when direction changes
Calculation: Wave result = absolute difference between the wave start and directional extreme; start is min(open, close) for an up-wave or max(open, close) for a down-wave; extreme is the maximum of max(open, close) for an up-wave or the minimum of min(open, close) for a down-wave
Calculation: Percentage change(current, previous) = (current / previous - 1) * 100, undefined when previous is absent or zero
Calculation: Comparison state(current, previous, comparison threshold) = +1 when Percentage change(current, previous) >= comparison threshold, -1 when it is <= -comparison threshold, and 0 otherwise or when undefined
Calculation: Effort state = Comparison state(current or completed wave effort, preceding completed effort of the same Renko direction, comparison threshold)
Calculation: Result state = Comparison state(current or completed wave result, preceding completed result of the same Renko direction, comparison threshold)
Calculation: Reversal count = consecutive chart bars in the current Renko direction, starting at one when direction changes
Long: A current or newly completed up-wave with a preceding completed up-wave has (effort state = +1 AND result state = +1) OR (effort state = -1 AND result state >= 0) OR (effort state = 0 AND result state = +1), OR a current or newly completed down-wave with a preceding completed down-wave has (effort state = -1 AND result state = -1) OR (effort state = +1 AND result state = -1)
