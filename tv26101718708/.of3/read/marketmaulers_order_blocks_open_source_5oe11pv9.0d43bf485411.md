Calculation: latest unbroken swing high = the most recent confirmed Pivot High(high, swing strength, swing strength), cleared when a bar closes above it
Calculation: latest unbroken swing low = the most recent confirmed Pivot Low(low, swing strength, swing strength), cleared when a bar closes below it
Calculation: chart bullish OB zones = on a confirmed close above the latest unbroken swing high, select an opposing down candle within the origin scan depth using the shared origin mode; Cluster uses the nearest down candle and the contiguous down-candle run behind it, with top=max body high and bottom=min low; Nearest uses the nearest down candle, with top=body high and bottom=low; Extreme uses the down candle with the lowest low, with top=body high and bottom=low; require top>bottom, and, when enabled, require abs(close - open[origin]) >= displacement multiple × ATR(close, ATR lookback), a bullish FVG with low[j]>high[j+2] for some j from max(0, origin offset - FVG distance) through origin offset, and the origin candle time within an enabled configured kill-zone window; retain each zone until a chart-bar close is below its bottom
Calculation: chart bearish OB zones = on a confirmed close below the latest unbroken swing low, select an opposing up candle within the origin scan depth using the shared origin mode; Cluster uses the nearest up candle and the contiguous up-candle run behind it, with top=max high and bottom=min body low; Nearest uses the nearest up candle, with top=high and bottom=body low; Extreme uses the up candle with the highest high, with top=high and bottom=body low; require top>bottom, and, when enabled, require abs(close - open[origin]) >= displacement multiple × ATR(close, ATR lookback), a bearish FVG with high[j]<low[j+2] for some j from max(0, origin offset - FVG distance) through origin offset, and the origin candle time within an enabled configured kill-zone window; retain each zone until a chart-bar close is above its top
Calculation: higher-timeframe bullish and bearish OB zones = apply the corresponding chart OB structure, origin, range, and optional displacement rules on bars of enabled T1 or T2 slots that exceed the chart timeframe; omit the FVG and kill-zone filters, and track each zone using its own timeframe's close, supplied to chart bars from the last completed T1 or T2 bar
Long: bullish OB markings enabled AND confirmed chart-bar close > latest unbroken swing high
Short: bearish OB markings enabled AND confirmed chart-bar close < latest unbroken swing low
Long: a new bullish OB forms on the last completed bar of an enabled higher-timeframe slot T1 or T2, with that slot above the chart timeframe; surface it on chart bars using the last completed slot bar, once per slot bar
Short: a new bearish OB forms on the last completed bar of an enabled higher-timeframe slot T1 or T2, with that slot above the chart timeframe; surface it on chart bars using the last completed slot bar, once per slot bar
Exit: long, chart close < bottom of an unbroken chart bullish OB zone OR last completed T1/T2 close < bottom of an unbroken higher-timeframe bullish OB zone
Exit: short, chart close > top of an unbroken chart bearish OB zone OR last completed T1/T2 close > top of an unbroken higher-timeframe bearish OB zone
