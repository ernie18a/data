Calculation: L = any enabled prior T2-bar high, low, or close; prior T3-bar high or low; still-forming T3-bar open; still-forming T4-bar open; opening-range high (maximum chart-bar high) or low (minimum chart-bar low) during the opening-range duration after regular-session open; or current-session premarket high or low, available after premarket. Use last completed T2/T3 bars for prior-period levels and carry these levels onto chart bars. Prior-T2 levels are available when the chart timeframe is <= T2; prior-T3 levels and T3/T4 opens when it is < T3; opening-range and premarket levels on intraday charts.
Calculation: C = close of each newly completed confirmation bar, sampled on the first following chart bar; use T1 unless it is shorter than the chart timeframe, in which case use the chart timeframe. When regular-session filtering applies on an intraday chart with an intraday confirmation timeframe, count only confirmation bars whose preceding chart bar was in regular session; otherwise count every completed confirmation bar.
Long: for any enabled L, either on the first chart bar after a counted confirmation close, the latest counted C > L[1] AND the preceding counted C <= L[1] AND, when first-event-only filtering applies, this is the first break of L in this direction this session; OR low < L AND open >= L AND close >= L AND, when regular-session filtering applies on an intraday chart, the chart bar is in regular session AND, when first-event-only filtering applies, this is the first probe of L in this direction this session.
Short: for any enabled L, either on the first chart bar after a counted confirmation close, the latest counted C < L[1] AND the preceding counted C >= L[1] AND, when first-event-only filtering applies, this is the first break of L in this direction this session; OR high > L AND open <= L AND close <= L AND, when regular-session filtering applies on an intraday chart, the chart bar is in regular session AND, when first-event-only filtering applies, this is the first probe of L in this direction this session.
