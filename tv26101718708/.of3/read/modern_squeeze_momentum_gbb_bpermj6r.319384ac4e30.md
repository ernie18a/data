Calculation: Lookback = if not Classic mode and adaptive length is enabled, round(clamp(first-value-seeded recursive EMA(Homodyne Discriminator(hl2), smoothing factor), minimum length, maximum length)); otherwise fixed length
Calculation: Squeeze = if not Classic mode and percentile ranking is enabled, Keltner channel width is nonzero and PercentRank((2 × Bollinger multiplier × StDev(close, Lookback)) / (2 × Keltner multiplier × SMA(TrueRange, Lookback)), rank window) ≤ compression threshold; otherwise Bollinger lower band > Keltner lower band AND Bollinger upper band < Keltner upper band, where both bands use SMA(close, Lookback) as their basis
Calculation: Momentum = LinearRegression(close − ((Highest(high, Lookback) + Lowest(low, Lookback)) / 2 + SMA(close, Lookback)) / 2, Lookback, offset 0), divided by SMA(TrueRange, Lookback) only when not Classic mode and normalized momentum is enabled
Calculation: Prior squeeze duration = number of consecutive completed chart bars ending at the previous bar for which Squeeze was true
Long: Squeeze[1] AND NOT Squeeze AND Momentum > 0 AND (Classic mode OR qualified release filter disabled OR (close > open AND ABS(Momentum) ≥ momentum threshold AND Prior squeeze duration ≥ minimum squeeze bars AND (range break not required OR close > Highest(high[1], Prior squeeze duration))))
Short: Squeeze[1] AND NOT Squeeze AND Momentum < 0 AND (Classic mode OR qualified release filter disabled OR (close < open AND ABS(Momentum) ≥ momentum threshold AND Prior squeeze duration ≥ minimum squeeze bars AND (range break not required OR close < Lowest(low[1], Prior squeeze duration))))
