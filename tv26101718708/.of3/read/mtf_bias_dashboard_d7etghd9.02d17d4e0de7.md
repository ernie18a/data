Calculation: T1 through T7 are the configured timeframes in increasing duration. Calculate each score on its timeframe bars; chart-bar decisions use the last completed bar, while live previews use the bar still forming.
Calculation: SmoothedRSI(T) = EMA(RSI(close on T, RSI lookback), RSI smoothing lookback), using a neutral RSI fallback when unavailable.
Calculation: ATRratio(T) = clamp(ATR(T, ATR lookback) / ATR baseline, ATR-ratio floor, ATR-ratio ceiling), where ATR baseline is SMA(ATR(T, ATR lookback), ATR baseline lookback), falling back to max(ATR, minimum tick size) when unavailable and to a neutral ratio when nonpositive; ATR lookback is shorter than ATR baseline lookback.
Calculation: Score(T) = clamp((piecewise(EMAfast > EMAmid AND EMAmid > EMAslow: +full-stack points; EMAfast < EMAmid AND EMAmid < EMAslow: -full-stack points; EMAfast > EMAslow: +partial-stack points; EMAfast < EMAslow: -partial-stack points; otherwise zero) + clamp((EMAslow - EMAslow[EMA-slope lookback]) / max(ATR(T, ATR lookback), minimum tick size) × EMA-slope multiplier, -EMA-slope cap, +EMA-slope cap) + piecewise(SmoothedRSI >= upper-extreme threshold: +upper-extreme points; SmoothedRSI >= upper-moderate threshold: +upper-moderate points; SmoothedRSI <= lower-extreme threshold: -upper-extreme points; SmoothedRSI <= lower-moderate threshold: -upper-moderate points; otherwise zero) + clamp((SmoothedRSI - SmoothedRSI[RSI-slope lag]) × RSI-slope multiplier, -RSI-slope cap, +RSI-slope cap) + piecewise(close > max(EMAfast, EMAmid, EMAslow): +outside-band points; close < min(EMAfast, EMAmid, EMAslow): -outside-band points; close > (max + min)/2: +inside-band points; close < (max + min)/2: -inside-band points; otherwise zero) + piecewise(VWAP(HLC3) available AND close > VWAP(HLC3): +VWAP points; VWAP(HLC3) available AND close <= VWAP(HLC3): -VWAP points; otherwise zero)) × piecewise(ATRratio < low-volatility-quality cutoff: low-volatility quality multiplier; ATRratio > high-volatility-quality cutoff: high-volatility quality multiplier; otherwise neutral multiplier), -score limit, +score limit); EMA lookbacks are ordered fast < middle < slow, and RSI upper thresholds and lower thresholds are ordered from extreme to moderate.
Calculation: Direction(T) = bullish when Score(T) >= trend threshold, bearish when Score(T) <= -trend threshold, otherwise neutral.
Calculation: EMA stack(T) = bullish when EMA(close, fast lookback) > EMA(close, middle lookback) > EMA(close, slow lookback) AND close > EMA(close, middle lookback); bearish when EMA(close, fast lookback) < EMA(close, middle lookback) < EMA(close, slow lookback) AND close < EMA(close, middle lookback); otherwise mixed.
Calculation: Session multiplier = neutral session multiplier when session weighting is disabled; otherwise overlap multiplier when chart-bar datetime is in both configured London and New York sessions, London/New York multiplier when in either, Asia multiplier when in the configured Asia session, and outside-session multiplier otherwise. Session windows and time zones are parameters.
Calculation: Confluence = clamp((weighted sum of Score(T1) through Score(T6)) × session multiplier × (weighted ATRratio(T1) through ATRratio(T6) below low-average-ATR threshold ? low-volatility multiplier : neutral volatility multiplier), -score limit, +score limit); use separate weights for each of T1 through T6 for each preset and entry-weighting selection, normalize them by their sum, and use the same normalized weights for the ATRratio average.
Long: Score(T) >= display directional threshold for any T1 through T7 OR live preview is enabled AND Score(T, still-forming bar) >= display directional threshold for any T1 through T7 OR Confluence >= display directional threshold OR EMA stack(T) is bullish for any T1 through T7 OR Direction(T5) is bullish AND Direction(T6) is bullish OR (the preset branch using T2/T3 confirmation is selected AND Direction(T5) is bullish AND Score(T3) > neutral-score boundary AND Score(T2) > -trend threshold) OR (the preset branch using T3/T4 confirmation is selected AND Direction(T5) is bullish AND Score(T3) >= trend threshold AND Score(T4) > -trend threshold) OR (the preset branch requiring T5/T6 alignment is selected AND Direction(T5) is bullish AND Direction(T6) is bullish).
Short: Score(T) <= -display directional threshold for any T1 through T7 OR live preview is enabled AND Score(T, still-forming bar) <= -display directional threshold for any T1 through T7 OR Confluence <= -display directional threshold OR EMA stack(T) is bearish for any T1 through T7 OR Direction(T5) is bearish AND Direction(T6) is bearish OR (the preset branch using T2/T3 confirmation is selected AND Direction(T5) is bearish AND Score(T3) < neutral-score boundary AND Score(T2) < trend threshold) OR (the preset branch using T3/T4 confirmation is selected AND Direction(T5) is bearish AND Score(T3) <= -trend threshold AND Score(T4) < trend threshold) OR (the preset branch requiring T5/T6 alignment is selected AND Direction(T5) is bearish AND Direction(T6) is bearish).
