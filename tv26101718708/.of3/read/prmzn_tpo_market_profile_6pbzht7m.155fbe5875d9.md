Calculation: Active TPO profile = the current profile for the configured profile period and sessions; in session mode select the current New York, then London, then Asia profile, or the configured composite when no session profile applies; in custom mode use the current custom-session profile.
Calculation: TPO row counts = count each price row intersected by a chart bar's high-low range once per TPO block, using the configured profile period, block duration, and price-row size; update through the current bar.
Calculation: TPO POC row and VAH/VAL = choose the row with the greatest TPO count, breaking ties by proximity to the profile center; expand the value area from the POC toward the adjacent row with the greater count until it reaches the configured fraction of total TPO count, adding the upper row first on ties and the lower row if still needed; VAH and VAL are the outer price boundaries of the included rows.
Calculation: POC location = zero-based POC row index / (profile row count − 1).
Calculation: Lower/upper tail length = consecutive rows from the respective profile edge with TPO count no greater than maximum row TPO count × configured tail fraction.
Calculation: Minimum tail length = integer part of max(configured minimum tail rows, profile row count × configured minimum tail fraction).
Long: active profile has at least the configured minimum row count AND maximum row TPO count > 0 AND POC location >= configured upper POC threshold AND lower tail length > upper tail length AND lower tail length >= minimum tail length.
Short: active profile has at least the configured minimum row count AND maximum row TPO count > 0 AND POC location <= configured lower POC threshold AND upper tail length > lower tail length AND upper tail length >= minimum tail length.
Long: VA-break alerts enabled AND active profile valid AND chart interval is intraday and no longer than the configured maximum AND (bar-close confirmation disabled OR chart bar confirmed) AND close > current active-profile TPO VAH AND close[1] <= current active-profile TPO VAH.
Short: VA-break alerts enabled AND active profile valid AND chart interval is intraday and no longer than the configured maximum AND (bar-close confirmation disabled OR chart bar confirmed) AND close < current active-profile TPO VAL AND close[1] >= current active-profile TPO VAL.
