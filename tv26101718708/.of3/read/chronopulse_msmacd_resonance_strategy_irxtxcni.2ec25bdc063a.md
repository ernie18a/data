Calculation: Bullish structure-break event = chart high > the latest non-na ta.pivothigh of high sampled from T1 onto chart bars (or chart high if T1 is unset), multiplied by (1 + structure-break buffer), and this threshold comparison was false on the prior chart bar. With T1, use request.security lookahead_off: its forming bar in realtime and its completed value historically; calculate pivots on chart bars.
Calculation: Bearish structure-break event = chart low < the latest non-na ta.pivotlow of low sampled from T1 onto chart bars (or chart low if T1 is unset), multiplied by (1 - structure-break buffer), and this threshold comparison was false on the prior chart bar. With T1, use request.security lookahead_off: its forming bar in realtime and its completed value historically; calculate pivots on chart bars.
Calculation: Risk ATR = ATR(ATR lookback, T3 bars if T3 is configured, otherwise chart bars); if the T3 ATR is unavailable, use chart-bar ATR with the same lookback. Calculate T3 ATR on T3 bars with lookahead_off, using its forming bar in realtime and completed value historically.
Calculation: MACD momentum state = bullish when the classic profile has MACD line > signal line, MACD line > 0, and histogram > histogram[1], and (fusion is disabled or the fusion profile meets the same bullish conditions); bearish when the classic profile has MACD line < signal line, MACD line < 0, and histogram < histogram[1], and (fusion is disabled or the fusion profile meets the same bearish conditions); otherwise neutral. Both profiles use MACD(price source, fast lookback, slow lookback, signal lookback), with separate lookback parameters, fast < slow in each, and longer lookbacks for the classic profile than the fusion profile. If T2 is configured, sample price source from T2 with lookahead_off (forming T2 bar in realtime, completed value historically) and calculate MACD on chart bars; otherwise use chart price source. histogram[1] is the prior chart bar.
Calculation: Entry quality score = the arithmetic mean of (1 if bullish structure-break event, else 0 if bearish structure-break event, else 0.5), (1 if MACD momentum state is bullish, else 0 if bearish, else 0.5), (1 if close > EMA(price source, trend-guide lookback), else 0 if close < that EMA, else 0.5), (min(max(Risk ATR / SMA(Risk ATR, ATR-baseline lookback), 0), score cap) / score cap if the SMA is > 0, else 1), and (min(max(volume intensity / volume threshold, 0), score cap) / score cap if the volume gate is enabled, else 1); volume intensity = volume / SMA(volume, volume lookback) when that SMA exists and is > 0, else 1.
Long: Bullish structure-break event.
Short: Bearish structure-break event.
Long: configured ATR is available AND (Risk ATR >= minimum ATR filter OR minimum ATR filter = 0) AND bullish structure-break event AND MACD momentum state is bullish AND close > EMA(price source, directional lookback) AND close > EMA(price source, trend-guide lookback) AND (volume gate disabled OR (SMA(volume, volume lookback) exists AND volume > SMA(volume, volume lookback) * volume threshold)) AND (quality gate disabled OR entry quality score >= quality threshold) AND entries on the current UTC date < daily trade limit AND (no prior entry OR chart bars since last entry >= cooldown bars) AND (crypto bias disabled OR EMA(price source, impulse-fast lookback) > EMA(price source, impulse-slow lookback)). The directional EMA lookback is longer than the trend-guide lookback; impulse-fast lookback is shorter than impulse-slow lookback.
Short: configured ATR is available AND (Risk ATR >= minimum ATR filter OR minimum ATR filter = 0) AND bearish structure-break event AND MACD momentum state is bearish AND close < EMA(price source, directional lookback) AND close < EMA(price source, trend-guide lookback) AND (volume gate disabled OR (SMA(volume, volume lookback) exists AND volume > SMA(volume, volume lookback) * volume threshold)) AND (quality gate disabled OR entry quality score >= quality threshold) AND entries on the current UTC date < daily trade limit AND (no prior entry OR chart bars since last entry >= cooldown bars) AND shorts are enabled AND (crypto bias disabled OR EMA(price source, impulse-fast lookback) <= EMA(price source, impulse-slow lookback)). The directional EMA lookback is longer than the trend-guide lookback; impulse-fast lookback is shorter than impulse-slow lookback.
Exit: Long, low <= max(close - Risk ATR * stop-loss multiple, if highest high since entry - entry price >= Risk ATR * trail-activation multiple then highest high since entry - Risk ATR * trail-distance multiple else close - Risk ATR * stop-loss multiple) OR high >= close + Risk ATR * take-profit multiple.
Exit: Short, high >= min(close + Risk ATR * stop-loss multiple, if entry price - lowest low since entry >= Risk ATR * trail-activation multiple then lowest low since entry + Risk ATR * trail-distance multiple else close + Risk ATR * stop-loss multiple) OR low <= close - Risk ATR * take-profit multiple.
