Calculation: Basis = selected SMA(close, basis lookback) or EMA(close, basis lookback)
Calculation: Standardized distance = (close - basis) / max(STDEV(close, basis lookback), volatility floor)
Calculation: Trend strength = abs(EMA(close, fast trend lookback) - EMA(close, slow trend lookback)) / max(ATR(ATR lookback), volatility floor), with fast lookback shorter than slow lookback
Calculation: Trend regime = lower, middle, or upper tercile of percentRank(trend strength, regime lookback)
Calculation: Mean slope = (basis - basis[mean slope lag]) / max(ATR(ATR lookback), volatility floor)
Calculation: Width expansion = STDEV(close, basis lookback) / max(SMA(STDEV(close, basis lookback), width averaging lookback), volatility floor), expressed as excess over its baseline
Calculation: Volume surge = volume / max(SMA(volume, volume averaging lookback), volatility floor), expressed as excess over its baseline
Calculation: Exhaustion persistence = consecutive chart bars where abs(standardized distance) meets the exhaustion distance threshold, resetting otherwise
Calculation: Feature vector(side) = clipped values of abs(standardized distance), trend strength, side-adjusted RSI(close, RSI lookback) centered and scaled by configured parameters, width expansion, volume surge, side-adjusted mean slope, and exhaustion persistence scaled by a configured parameter; use separate configured clip bounds for each feature; side denotes the upper-distance side for a short fade and the lower-distance side for a long fade
Calculation: Online reversion probability = logistic(intercept + weighted sum of the feature vector); initialize model weights to their configured initial values. At each completed chart bar, age pending touch records and resolve them in creation order: label success if the distance changes sides or abs(distance) reaches the reversion distance threshold; otherwise label failure if abs(distance) reaches the touch's initial abs(distance) plus the extension distance; otherwise, at the outcome horizon, label success if abs(distance) is at most the initial abs(distance) times the configured reduction fraction, and failure otherwise. For each resolved record, update every model weight by subtracting learning rate times (predicted probability - label) times its feature, using the intercept feature for the intercept; update the cumulative success rate, then predict again with the updated weights.
Calculation: Adaptive probability threshold = among the ordered candidate probability thresholds, choose the one with greatest regime-specific UCB score; an untried candidate has infinite score, otherwise its score is mean reward plus exploration parameter times sqrt(log(regime resolved-touch count plus configured offset) / candidate count); ties select the lowest candidate. For each resolved record, update every candidate's count and mean reward for that record's regime, using the post-training model prediction compared with the candidate threshold to choose the label or the updated cumulative success rate as reward.
Long: On a completed chart bar, chart bar index exceeds the warmup parameter AND abs(standardized distance) meets or exceeds the entry distance threshold AND abs(standardized distance one chart bar ago) is below the entry distance threshold AND standardized distance is below zero AND online reversion probability(feature vector for a long fade) >= max(adaptive probability threshold(current trend regime), minimum probability floor)
Short: On a completed chart bar, chart bar index exceeds the warmup parameter AND abs(standardized distance) meets or exceeds the entry distance threshold AND abs(standardized distance one chart bar ago) is below the entry distance threshold AND standardized distance is above zero AND online reversion probability(feature vector for a short fade) >= max(adaptive probability threshold(current trend regime), minimum probability floor)
