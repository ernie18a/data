Calculation: Relative volume = volume / SMA(volume, volume lookback)[1] when that SMA is positive, otherwise 0
Calculation: Candle body fraction = high > low ? abs(close - open) / (high - low) : 0
Calculation: Close position in range = high > low ? (close - low) / (high - low) : 0.5
Calculation: Long weighted score = volume weight if relative volume >= relative-volume minimum, else 0, plus trend weight if close > VWAP(hlc3) AND EMA(close, shorter lookback) > EMA(close, longer lookback) AND close > EMA(close, shorter lookback) AND T1 close > EMA(close, longer lookback) on the current T1 bar, mapped to chart bars with gaps off and lookahead off, else 0, plus momentum weight if RSI(close, RSI lookback) > long RSI lower bound AND RSI(close, RSI lookback) < long RSI upper bound, else 0, plus breakout weight if close > Highest(high, breakout lookback)[1], else 0, plus candle-pressure weight if close > open AND Close position in range > long close-position threshold AND Candle body fraction > body-fraction threshold, else 0
Calculation: Short weighted score = volume weight if relative volume >= relative-volume minimum, else 0, plus trend weight if close < VWAP(hlc3) AND EMA(close, shorter lookback) < EMA(close, longer lookback) AND close < EMA(close, shorter lookback) AND T1 close < EMA(close, longer lookback) on the current T1 bar, mapped to chart bars with gaps off and lookahead off, else 0, plus momentum weight if RSI(close, RSI lookback) < short RSI upper bound AND RSI(close, RSI lookback) > short RSI lower bound, else 0, plus breakout weight if close < Lowest(low, breakout lookback)[1], else 0, plus candle-pressure weight if close < open AND Close position in range < short close-position threshold AND Candle body fraction > body-fraction threshold, else 0
Long: session bypass enabled OR within configured trade session, AND Long weighted score >= score threshold
Short: shorts enabled AND (session bypass enabled OR within configured trade session) AND Short weighted score >= score threshold
Exit: long, low <= entry price - ATR(ATR lookback) on the position-opening bar * stop multiple OR high >= entry price + ATR(ATR lookback) on the position-opening bar * stop multiple * target multiple OR chart bars since entry >= holding-bar limit OR session bypass disabled AND outside configured trade session
Exit: short, high >= entry price + ATR(ATR lookback) on the position-opening bar * stop multiple OR low <= entry price - ATR(ATR lookback) on the position-opening bar * stop multiple * target multiple OR chart bars since entry >= holding-bar limit OR session bypass disabled AND outside configured trade session
