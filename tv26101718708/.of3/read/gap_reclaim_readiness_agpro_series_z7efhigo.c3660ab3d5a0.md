Calculation: Gap ATR = max(ATR(ATR lookback) when defined, otherwise TrueRange; minimum price increment)
Calculation: Bullish gap candidate = choose the first eligible pattern in classic, wick, body, displacement priority: classic when open > high[1], with upper/lower boundaries open/high[1]; wick when low > high[1], with boundaries low/high[1]; body when min(open, close) > max(open[1], close[1]), with boundaries min(open, close)/max(open[1], close[1]); displacement when enabled in adaptive mode, close > high[1] and abs(close - open) >= Gap ATR * displacement body threshold, with boundaries close/high[1]. Classic mode accepts classic only, open-wick mode accepts classic or wick, open-body mode accepts classic, wick, or body, and adaptive mode accepts all four. The selected gap height must be >= Gap ATR * minimum gap size multiple; otherwise there is no candidate.
Calculation: Bearish gap candidate = choose the first eligible pattern in classic, wick, body, displacement priority: classic when open < low[1], with upper/lower boundaries low[1]/open; wick when high < low[1], with boundaries low[1]/high; body when max(open, close) < min(open[1], close[1]), with boundaries min(open[1], close[1])/max(open, close); displacement when enabled in adaptive mode, close < low[1] and abs(close - open) >= Gap ATR * displacement body threshold, with boundaries low[1]/close. Classic mode accepts classic only, open-wick mode accepts classic or wick, open-body mode accepts classic, wick, or body, and adaptive mode accepts all four. The selected gap height must be >= Gap ATR * minimum gap size multiple; otherwise there is no candidate.
Calculation: Active gap = the latest registered qualifying bullish or bearish gap, with a bullish candidate taking priority if both occur on the same bar; register a candidate when there is no active gap or the active gap age exceeds the gap cooldown. An unresolved gap clears when close crosses its reclaim edge by the invalidation buffer or its age exceeds the active gap window. A gap that reaches READY remains resolved and active until its fill risk reaches the fill-risk threshold, unless replaced by a later registered gap.
Calculation: First target = bullish gap upper boundary + gap height * first-target gap multiple for a bullish active gap; bearish gap lower boundary - gap height * first-target gap multiple for a bearish active gap.
Calculation: Reclaim score = clamp(clamp(time-score maximum * (1 - active gap age / max(reclaim-window bars, minimum divisor)), zero, time-score maximum) + (current high >= gap lower boundary and current low <= gap upper boundary ? gap-overlap points : zero) + (close on the reclaimed side of the edge ? reclaim-close points : current high >= gap lower boundary and current low <= gap upper boundary ? partial-close points : zero) + (relative-volume scoring enabled ? clamp((volume / SMA(volume, relative-volume lookback)) / relative-volume normalization, zero, one) * relative-volume weight : disabled-volume points) + clamp(gap height / (Gap ATR * gap-size normalization), zero, one) * gap-size weight + clamp((distance from close to First target in the active gap direction / Gap ATR) / continuation-room normalization, zero, one) * continuation-room weight, zero, maximum score)
Calculation: Fill risk = clamp((bullish gap upper boundary - low) / gap height * percentage scale, zero, percentage scale) for a bullish active gap, or clamp((high - bearish gap lower boundary) / gap height * percentage scale, zero, percentage scale) for a bearish active gap.
Calculation: Required ready score = clamp(minimum ready score - confirmation-mode score adjustment, minimum score, maximum score)
Long: active gap is bullish
Short: active gap is bearish
Long: active bullish gap is unresolved AND high >= gap lower boundary AND low <= gap upper boundary AND close >= gap upper boundary AND Reclaim score >= Required ready score AND Fill risk < fill-risk threshold
Short: active bearish gap is unresolved AND high >= gap lower boundary AND low <= gap upper boundary AND close <= gap lower boundary AND Reclaim score >= Required ready score AND Fill risk < fill-risk threshold
Exit: long, active bullish gap is unresolved AND close < gap upper boundary - Gap ATR * invalidation buffer multiple
Exit: short, active bearish gap is unresolved AND close > gap lower boundary + Gap ATR * invalidation buffer multiple
