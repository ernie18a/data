Long: RSI(close of chart symbol, RSI period, T1, still-forming bar) crosses above RSI(close of comparison symbol, RSI period, T1, still-forming bar), evaluated on chart bars using T1 values
Short: RSI(close of chart symbol, RSI period, T1, still-forming bar) crosses below RSI(close of comparison symbol, RSI period, T1, still-forming bar), evaluated on chart bars using T1 values
Exit: long, high >= entry price * (1 + take-profit percentage / 100)
Exit: short, low <= entry price * (1 - take-profit percentage / 100)
