Calculation: Chart/T1 MA pair = EMA(close, shorter MA lookback) and EMA(close, longer MA lookback), or SMA for both under one MA-type parameter; calculate chart values on chart bars and T1 values on T1 bars, sampled on chart bars from the last completed T1 bar historically and the still-forming T1 bar in real time; T1 is the auto-selected higher timeframe.
Calculation: Internal pivot levels = initialize the leg state to high-pivot state; on each chart bar set it to high-pivot state if high[pivot lookback] > highest(high, pivot lookback), else to low-pivot state if low[pivot lookback] < lowest(low, pivot lookback), else retain it; when the state changes to low-pivot state store low[pivot lookback] as the latest low pivot, and when it changes to high-pivot state store high[pivot lookback] as the latest high pivot; each stored level is eligible for one close crossing.
Calculation: Prior ribbon touch = prior chart-bar state set true when low <= max(chart short MA, chart long MA) AND high >= min(chart short MA, chart long MA), reset false on either bullish or bearish internal structure break, with reset taking precedence when both occur on one bar.
Long: T1 short MA > T1 long MA AND chart short MA > chart long MA AND chart short MA - chart short MA[slope lookback] > ATR(ATR lookback) * slope sensitivity AND abs(chart short MA - chart long MA) > ATR(ATR lookback) * separation sensitivity AND prior ribbon touch AND close crosses above the latest unbroken internal pivot high AND, if candle confirmation is enabled, the chart bar is confirmed.
Short: T1 short MA < T1 long MA AND chart short MA < chart long MA AND chart short MA[slope lookback] - chart short MA > ATR(ATR lookback) * slope sensitivity AND abs(chart short MA - chart long MA) > ATR(ATR lookback) * separation sensitivity AND prior ribbon touch AND close crosses below the latest unbroken internal pivot low AND, if candle confirmation is enabled, the chart bar is confirmed.
