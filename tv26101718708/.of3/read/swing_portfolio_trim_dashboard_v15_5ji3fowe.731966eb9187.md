Calculation: VolatilityAdjustedMomentum(h) = log(close / close[h]) / (StDev(log(close / close[previous T1 bar]), h) * sqrt(h)); unavailable when the denominator is not positive; calculated on T1 bars, with chart bars taking values from the still-forming T1 bar.
Calculation: ATRDistance(e) = (close - EMA(close, e, T1, still-forming bar)) / ATR(ATR lookback, T1, still-forming bar), where e is the medium or long EMA lookback.
Calculation: TrendScore = scale * (fast-price points * I(close > EMA(close, short lookback, T1, still-forming bar)) + medium/long-price points * [I(close > EMA(close, medium lookback, T1, still-forming bar)) + I(close > EMA(close, long lookback, T1, still-forming bar)] + structure points * [I(EMA(close, short lookback, T1, still-forming bar) > EMA(close, medium lookback, T1, still-forming bar)) + I(EMA(close, medium lookback, T1, still-forming bar) > EMA(close, long lookback, T1, still-forming bar)) + I(EMA(close, medium lookback, T1, still-forming bar) > EMA(close, medium lookback, T1, still-forming bar)[short comparison lag T1 bars ago]) + I(EMA(close, long lookback, T1, still-forming bar) > EMA(close, long lookback, T1, still-forming bar)[short comparison lag T1 bars ago])]) / trend-point normalizer; I(condition) is one when true and zero otherwise; short, medium, and long lookbacks are ordered shortest to longest.
Calculation: ATRHealth = mid-health weight * clamp(scale + min(ATRDistance(medium EMA lookback), 0) * mid-health slope, 0, scale) + long-health weight * clamp(scale + min(ATRDistance(long EMA lookback), 0) * long-health slope, 0, scale); the two weights sum to one; available only when both distances are available.
Calculation: PeerPercentile(x) = scale * count(configured portfolio securities with valid x strictly below x) / (valid x count - 1) when valid x count is greater than one, otherwise scale / 2; calculated on the last chart bar from values at the same T1 bar.
Calculation: TechnicalScore = wROCshort * PeerPercentile(ROC(close, short lookback, T1, still-forming bar)) + wROCmedium * PeerPercentile(ROC(close, medium lookback, T1, still-forming bar)) + wROClong * PeerPercentile(ROC(close, long lookback, T1, still-forming bar)) + wVAshort * PeerPercentile(VolatilityAdjustedMomentum(short lookback)) + wVAmedium * PeerPercentile(VolatilityAdjustedMomentum(medium lookback)) + wVAlong * PeerPercentile(VolatilityAdjustedMomentum(long lookback)) + wTrend * TrendScore + wATR * ATRHealth; the eight weights are separate and sum to one; available only when all inputs are available; calculated on the last chart bar from T1 values, ranking lagged values against portfolio securities at the same T1 lag.
Calculation: PortfolioRank(s) = 1 + count(configured portfolio securities with valid score strictly greater than s); calculated on the last chart bar from scores at the same T1 bar.
Calculation: ScoreChange(n) = TechnicalScore - TechnicalScore n T1 bars ago.
Calculation: RankChange(n) = PortfolioRank(TechnicalScore) n T1 bars ago - PortfolioRank(TechnicalScore).
Exit: long, TechnicalScore is available at the current T1 bar and at short comparison lag and long comparison lag T1 bars ago AND ((PortfolioRank(TechnicalScore) > floor(N * exit-rank proportion) AND ATRDistance(long EMA lookback) <= -damage ATR threshold AND TrendScore < severe-trend threshold) OR (PortfolioRank(TechnicalScore) > floor(N * trim-rank proportion) AND (ATRDistance(medium EMA lookback) <= -damage ATR threshold OR ((ScoreChange(short comparison lag) <= -score-fall threshold OR RankChange(short comparison lag) <= -rank-fall threshold) AND ATRDistance(medium EMA lookback) < 0))) OR (NOT (TechnicalScore < recovery-score threshold AND ScoreChange(short comparison lag) >= recovery-rise threshold) AND PortfolioRank(TechnicalScore) > floor(N * watch-rank proportion) AND (ATRDistance(medium EMA lookback) < 0 OR ScoreChange(short comparison lag) <= -score-fall threshold OR RankChange(short comparison lag) <= -rank-fall threshold))); N is the number of configured portfolio securities; watch-rank proportion < trim-rank proportion < exit-rank proportion; short comparison lag < long comparison lag.
