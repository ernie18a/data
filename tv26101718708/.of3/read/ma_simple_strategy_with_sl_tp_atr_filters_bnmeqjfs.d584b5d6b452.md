Calculation: M(close, lookback) = selected SMA(close, lookback), EMA(close, lookback), WMA(close, lookback), HMA(close, lookback), RMA(close, lookback), SWMA(close), ALMA(close, lookback, offset, sigma), VWMA(close, lookback), or VWAP(close)
Long: M(close, shortest lookback) >= M(close, next-shortest lookback) >= M(close, next-longest lookback) >= M(close, longest lookback)
Short: M(close, shortest lookback) <= M(close, next-shortest lookback) <= M(close, next-longest lookback) <= M(close, longest lookback)
Long: M(close, shortest lookback) >= M(close, next-shortest lookback) >= M(close, next-longest lookback) >= M(close, longest lookback) AND (when the ATR filter is enabled, ATR(ATR lookback) >= SMA(ATR(ATR lookback), ATR filter lookback))
Short: M(close, shortest lookback) <= M(close, next-shortest lookback) <= M(close, next-longest lookback) <= M(close, longest lookback) AND (when the ATR filter is enabled, ATR(ATR lookback) >= SMA(ATR(ATR lookback), ATR filter lookback))
Calculation: Long stop price = initialize on the entry signal bar using its close as the source; thereafter use the entry price as source, or the highest high since entry when trailing is enabled; in percent mode the candidate is source * (1 - long stop percentage / 100), and in ATR mode it is source - long stop ATR multiplier * ATR(ATR lookback) captured on the entry signal bar; retain the greater of the candidate and the previous stop price
Calculation: Short stop price = initialize on the entry signal bar using its close as the source; thereafter use the entry price as source, or the lowest low since entry when trailing is enabled; in percent mode the candidate is source * (1 + short stop percentage / 100), and in ATR mode it is source + short stop ATR multiplier * ATR(ATR lookback) captured on the entry signal bar; retain the lesser of the candidate and the previous stop price
Calculation: Long take-profit price = fixed from the entry signal bar close; in percent mode use close * (1 + long take-profit percentage / 100), in ATR mode use close + long take-profit ATR multiplier * ATR(ATR lookback) on that bar, and in risk-reward mode use close + long risk-reward ratio * (close - the selected long stop formula evaluated at that close)
Calculation: Short take-profit price = fixed from the entry signal bar close; in percent mode use close * (1 - short take-profit percentage / 100), in ATR mode use close - short take-profit ATR multiplier * ATR(ATR lookback) on that bar, and in risk-reward mode use close - short risk-reward ratio * (close - the selected long stop formula evaluated at that close)
Exit: long, (M(close, shortest lookback)[1] >= M(close, next-shortest lookback)[1] >= M(close, next-longest lookback)[1] >= M(close, longest lookback)[1] AND NOT (M(close, shortest lookback) >= M(close, next-shortest lookback) >= M(close, next-longest lookback) >= M(close, longest lookback))) OR low <= long stop price OR high >= long take-profit price
Exit: short, (M(close, shortest lookback)[1] <= M(close, next-shortest lookback)[1] <= M(close, next-longest lookback)[1] <= M(close, longest lookback)[1] AND NOT (M(close, shortest lookback) <= M(close, next-shortest lookback) <= M(close, next-longest lookback) <= M(close, longest lookback))) OR high >= short stop price OR low <= short take-profit price
