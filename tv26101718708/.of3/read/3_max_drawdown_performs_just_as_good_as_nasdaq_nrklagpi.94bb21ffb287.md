Calculation: T1 source series = request.security values mapped onto chart bars with lookahead off; realtime values may use the still-forming T1 bar
Calculation: Prior reference ATH = highest reference-series close on earlier chart bars, or current close on the first chart bar
Calculation: Bars since reference ATH = 0 when current reference close >= prior reference ATH; otherwise previous count + 1
Calculation: Reference drawdown = prior reference ATH > 0 ? 1 - current reference close / prior reference ATH : 0
Calculation: Crash armed = becomes true when reference drawdown >= crash-trigger parameter; remains true until recovery target is reached or, with no recovery hold active, reference close >= prior reference ATH
Calculation: Recovery hold = activates while long when reference drawdown >= crash-trigger parameter, or upon entering long while crash armed; target is prior reference ATH; clears when reference close >= target or the long position closes
Long: position side is flat or short AND datetime >= timestamp(start-year parameter, start-month parameter, start-day parameter) AND (bars since reference ATH < stale-bars parameter OR reference close > EMA(reference close, longest EMA lookback) * (1 + extension parameter)) AND ((reference low > EMA(reference close, medium EMA lookback) on the current and previous 3 chart bars AND traded low > EMA(traded close, shorter EMA lookback) AND traded low > EMA(traded close, medium EMA lookback) AND NOT (traded close < traded close[1] AND traded close < traded close[2] AND traded close < traded close[3]) AND ADX(reference high, reference low, reference close, DI-length parameter, ADX-smoothing parameter; T1 bars) > ADX-threshold parameter) OR (EMA(assist close, shorter EMA lookback) > EMA(assist close, medium EMA lookback) AND assist low > EMA(assist close, medium EMA lookback) AND assist close > assist close[1] AND reference close > SMA(reference close, short reference-SMA lookback)))
Exit: long, datetime >= timestamp(start-year parameter, start-month parameter, start-day parameter) AND (NOT recovery hold active OR reference close >= recovery target) AND ((traded close < entry price AND traded close < EMA(traded close, medium EMA lookback) AND reference close < SMA(reference close, short reference-SMA lookback)) OR (traded close >= entry price AND ((SMA(reference close, short reference-SMA lookback) < SMA(reference close, long reference-SMA lookback)[1] AND reference close < SMA(reference close, short reference-SMA lookback) AND traded close < EMA(traded close, medium EMA lookback)) OR (traded low < entry price * (1 - stop-loss parameter) AND traded low < SMA(traded close, traded-SMA lookback))))
