Calculation: MACD line = MACD(close, fast length, slow length, MA type)
Calculation: Signal line = MA(MACD line, signal length, signal MA type)
Calculation: Histogram = MACD line - Signal line
Calculation: MACD slope = MACD line - MACD line[1]
Calculation: Momentum acceleration = MACD slope - MACD slope[1]
Calculation: Normalized histogram strength = abs(Histogram) / ATR(normalization ATR length) * 100
Calculation: Histogram change = abs(Histogram - Histogram[1])
Calculation: Histogram baseline = EMA(abs(Histogram), quality lookback)
Calculation: Histogram change baseline = EMA(Histogram change, quality lookback)
Calculation: Slope baseline = EMA(abs(MACD slope), quality lookback)
Calculation: Acceleration baseline = EMA(abs(Momentum acceleration), quality lookback)
Calculation: Component score(value, baseline, target, points) = points * clamp(value / (baseline * target), 0, 1)
Calculation: Target score(value, target, points) = points * clamp(value / target, 0, 1)
Calculation: Bullish momentum quality = clamp(alignment points + Component score(abs(Histogram), Histogram baseline, histogram strength target, strength points) + (if Histogram > Histogram[1] then Component score(Histogram change, Histogram change baseline, histogram expansion target, expansion points) else 0) + (if MACD slope > 0 then Component score(abs(MACD slope), Slope baseline, MACD slope target, slope points) else 0) + (if Momentum acceleration > 0 then Component score(abs(Momentum acceleration), Acceleration baseline, acceleration target, acceleration points) else 0), 0, 100)
Calculation: Bearish momentum quality = clamp(alignment points + Component score(abs(Histogram), Histogram baseline, histogram strength target, strength points) + (if Histogram < Histogram[1] then Component score(Histogram change, Histogram change baseline, histogram expansion target, expansion points) else 0) + (if MACD slope < 0 then Component score(abs(MACD slope), Slope baseline, MACD slope target, slope points) else 0) + (if Momentum acceleration < 0 then Component score(abs(Momentum acceleration), Acceleration baseline, acceleration target, acceleration points) else 0), 0, 100)
Calculation: Bullish persistence = bars since Histogram <= 0
Calculation: Bearish persistence = bars since Histogram >= 0
Calculation: Bullish entry score = clamp(Target score(max(close - open, 0) / (high - low), body target, body points) + Target score((close - low) / (high - low), close location target, close location points) + Component score(abs(Histogram), Histogram baseline, entry separation target, separation points) + Target score(Bullish persistence, persistence target, persistence points) + Target score(max(close - close[1], 0) / ATR(normalization ATR length), impulse target, impulse points) + trigger points, 0, 100)
Calculation: Bearish entry score = clamp(Target score(max(open - close, 0) / (high - low), body target, body points) + Target score((high - close) / (high - low), close location target, close location points) + Component score(abs(Histogram), Histogram baseline, entry separation target, separation points) + Target score(Bearish persistence, persistence target, persistence points) + Target score(max(close[1] - close, 0) / ATR(normalization ATR length), impulse target, impulse points) + trigger points, 0, 100)
Calculation: Market regime score = clamp(Target score(ADX(ADX length, ADX smoothing), ADX target, ADX points) + Target score(Kaufman efficiency ratio(close, efficiency length), efficiency target, efficiency points) + Target score(abs(EMA(close, regime fast length) - EMA(close, regime slow length)) / ATR(normalization ATR length), EMA separation target, EMA separation points) + Target score(ATR(normalization ATR length) / SMA(ATR(normalization ATR length), volatility lookback), volatility target, volatility points), 0, 100)
Calculation: Bullish raw setup = (enable reversal AND MACD line crosses above Signal line AND MACD line < 0) OR (enable continuation AND MACD line crosses above Signal line AND MACD line >= 0) OR (enable zero-line reclaim AND MACD line crosses above 0 AND Histogram > 0) OR (enable momentum expansion AND Histogram > 0 AND Histogram > Histogram[1] AND Histogram[1] <= Histogram[2] AND MACD slope > 0 AND NOT (MACD line crosses above Signal line) AND NOT (MACD line crosses above 0))
Calculation: Bearish raw setup = (enable reversal AND MACD line crosses below Signal line AND MACD line > 0) OR (enable continuation AND MACD line crosses below Signal line AND MACD line <= 0) OR (enable zero-line reclaim AND MACD line crosses below 0 AND Histogram < 0) OR (enable momentum expansion AND Histogram < 0 AND Histogram < Histogram[1] AND Histogram[1] >= Histogram[2] AND MACD slope < 0 AND NOT (MACD line crosses below Signal line) AND NOT (MACD line crosses below 0))
Calculation: Bullish armed = (1 <= bars since Bullish raw setup <= confirmation window) AND (bars since (Bearish raw setup OR Bullish entry OR Bearish entry) > bars since Bullish raw setup)
Calculation: Bearish armed = (1 <= bars since Bearish raw setup <= confirmation window) AND (bars since (Bullish raw setup OR Bullish entry OR Bearish entry) > bars since Bearish raw setup)
Calculation: Bullish entry candidate = (early-trigger mode AND Bullish raw setup) OR (NOT early-trigger mode AND Bullish armed AND Histogram > 0 AND Histogram > Histogram[1] AND MACD slope > 0)
Calculation: Bearish entry candidate = (early-trigger mode AND Bearish raw setup) OR (NOT early-trigger mode AND Bearish armed AND Histogram < 0 AND Histogram < Histogram[1] AND MACD slope < 0)
Calculation: Bullish trend pass = (NOT chart trend filter OR (close > EMA(close, trend length) AND close - EMA(close, trend length) >= ATR(normalization ATR length) * trend buffer AND (NOT slope confirmation OR EMA(close, trend length) > EMA(close, trend length)[chart slope lookback]))) AND (NOT HTF trend filter OR (close(T1, last completed bar) > EMA(close, trend length, T1, last completed bar) AND close(T1, last completed bar) - EMA(close, trend length, T1, last completed bar) >= ATR(normalization ATR length, T1, last completed bar) * trend buffer AND (NOT slope confirmation OR EMA(close, trend length, T1, last completed bar) > EMA(close, trend length, T1, second-last completed bar))))
Calculation: Bearish trend pass = (NOT chart trend filter OR (close < EMA(close, trend length) AND EMA(close, trend length) - close >= ATR(normalization ATR length) * trend buffer AND (NOT slope confirmation OR EMA(close, trend length) < EMA(close, trend length)[chart slope lookback]))) AND (NOT HTF trend filter OR (close(T1, last completed bar) < EMA(close, trend length, T1, last completed bar) AND EMA(close, trend length, T1, last completed bar) - close(T1, last completed bar) >= ATR(normalization ATR length, T1, last completed bar) * trend buffer AND (NOT slope confirmation OR EMA(close, trend length, T1, last completed bar) < EMA(close, trend length, T1, second-last completed bar))))
Calculation: Bullish entry = Bullish entry candidate AND (NOT zero-line filter OR MACD line > 0) AND (NOT absolute strength filter OR Normalized histogram strength >= minimum absolute strength) AND Bullish momentum quality >= minimum quality score AND Bullish trend pass AND Market regime score >= minimum regime score AND Bullish entry score >= minimum entry score AND close > open AND abs(Histogram) / Histogram baseline >= minimum separation multiplier AND bars since (Bullish entry OR Bearish entry) >= cooldown bars AND (NOT trade engine enabled OR (position side is flat AND no exit on current bar))
Calculation: Bearish entry = Bearish entry candidate AND (NOT zero-line filter OR MACD line < 0) AND (NOT absolute strength filter OR Normalized histogram strength >= minimum absolute strength) AND Bearish momentum quality >= minimum quality score AND Bearish trend pass AND Market regime score >= minimum regime score AND Bearish entry score >= minimum entry score AND close < open AND abs(Histogram) / Histogram baseline >= minimum separation multiplier AND bars since (Bullish entry OR Bearish entry) >= cooldown bars AND (NOT trade engine enabled OR (position side is flat AND no exit on current bar))
Long: Bullish entry
Short: Bearish entry
Long: Histogram >= 0
Short: Histogram < 0
Long: Bullish trend pass AND (chart trend filter OR HTF trend filter)
Short: Bearish trend pass AND (chart trend filter OR HTF trend filter)
Calculation: Stop distance = (if ATR-based risk model then ATR(trade ATR length) at entry bar * ATR stop multiplier else pip size * stop pips)
Calculation: TP3 distance = (if ATR-based risk model then Stop distance * TP3 risk-reward else pip size * TP3 pips)
Exit: LONG, trade engine enabled AND (low <= entry price - Stop distance OR high >= entry price + TP3 distance)
Exit: SHORT, trade engine enabled AND (high >= entry price + Stop distance OR low <= entry price - TP3 distance)
