Calculation: Candle range = max(high - low, minimum tick)
Calculation: Body percentage = abs(close - open) / candle range
Calculation: Close location = (close - low) / candle range
Calculation: Upper wick percentage = (high - max(open, close)) / candle range
Calculation: Lower wick percentage = (min(open, close) - low) / candle range
Calculation: Volume ratio = volume / SMA(volume, volume lookback) if SMA(volume, volume lookback) is positive; otherwise the volume baseline ratio
Calculation: Range-to-ATR ratio = candle range / ATR(ATR lookback) if ATR(ATR lookback) is positive; otherwise the ATR fallback ratio
Calculation: Bullish body points = full score weight if close > open and body percentage >= strong-body threshold; otherwise partial score weight if close > open and body percentage >= strong-body threshold × body-partial multiplier; otherwise no points
Calculation: Bearish body points = full score weight if close < open and body percentage >= strong-body threshold; otherwise partial score weight if close < open and body percentage >= strong-body threshold × body-partial multiplier; otherwise no points
Calculation: Bullish close-location points = full score weight if close location >= strong-close threshold; otherwise partial score weight if close location >= bullish secondary close threshold; otherwise no points
Calculation: Bearish close-location points = full score weight if close location <= the complement of the strong-close threshold; otherwise partial score weight if close location <= bearish secondary close threshold; otherwise no points
Calculation: Volume points = if volume pressure is enabled, full score weight when volume ratio >= high-volume multiplier, partial score weight when volume ratio >= volume baseline ratio, and no points otherwise; if disabled, partial score weight
Calculation: ATR-range points = if ATR expansion is enabled, full score weight when range-to-ATR ratio >= ATR expansion multiplier, partial score weight when range-to-ATR ratio >= ATR baseline ratio, and no points otherwise; if disabled, partial score weight
Calculation: Bullish VWAP points = full score weight if VWAP filter is enabled and close >= VWAP((high + low + close) / 3); partial score weight if VWAP filter is disabled; otherwise no points
Calculation: Bearish VWAP points = full score weight if VWAP filter is enabled and close <= VWAP((high + low + close) / 3); partial score weight if VWAP filter is disabled; otherwise no points
Calculation: Bullish wick points = partial score weight if lower wick percentage > upper wick percentage and lower wick percentage >= wick threshold; otherwise no points
Calculation: Bearish wick points = partial score weight if upper wick percentage > lower wick percentage and upper wick percentage >= wick threshold; otherwise no points
Calculation: Bull score = min(score ceiling, bullish body points + bullish close-location points + volume points + ATR-range points + bullish VWAP points + bullish wick points)
Calculation: Bear score = min(score ceiling, bearish body points + bearish close-location points + volume points + ATR-range points + bearish VWAP points + bearish wick points)
