Calculation: Return(asset, lookback) = percentage change in the asset's close over the lookback on chart bars
Calculation: Acceleration(asset) = Return(asset, fast lookback) − Return(asset, fast lookback)[acceleration lookback]
Calculation: Relative rank(value, other values) = high-rank score if value exceeds both other values, low-rank score if below both, otherwise middle-rank score
Calculation: RSI quality(asset) = low RSI score if RSI(asset, RSI length) ≤ lower RSI level; otherwise low RSI score + (RSI − lower RSI level) × first rising slope if RSI < middle RSI level; otherwise middle RSI score + (RSI − middle RSI level) × second rising slope if RSI ≤ upper RSI level; otherwise high RSI score − (RSI − upper RSI level) × falling slope if RSI ≤ overbought level; otherwise clamp(extreme RSI score − (RSI − overbought level) × extreme falling slope, 0, extreme RSI score)
Calculation: Trend quality(asset) = highest trend score if close > EMA(close, fast EMA length) > EMA(close, slow EMA length); otherwise next trend score if close > EMA(close, slow EMA length); otherwise third trend score if EMA(close, fast EMA length) > EMA(close, slow EMA length); otherwise lowest trend score
Calculation: Volume quality(asset) = base if Return(asset, fast lookback) ≥ 0, otherwise score ceiling − base, where base = clamp((volume / SMA(volume, volume lookback) − volume baseline) / volume scale × score ceiling, 0, score ceiling)
Calculation: Exhaustion penalty(asset) = maximum penalty × max(RSI penalty, EMA-extension penalty) if enabled, otherwise 0; RSI penalty = clamp((RSI − overbought level) / (score ceiling − overbought level), 0, 1) when RSI > overbought level, otherwise 0; EMA-extension penalty = clamp((extension − maximum EMA extension) / maximum EMA extension, 0, 1) when extension > maximum EMA extension, otherwise 0; extension = percentage difference between close and EMA(close, slow EMA length)
Calculation: Score(asset) = clamp(weighted sum of the relative ranks of its fast, medium, slow, and acceleration returns, its RSI quality, trend quality, and volume quality, minus its exhaustion penalty, 0, score ceiling); each component has its own weight parameter
Calculation: Leader = asset with the highest score among A, B, and C, resolving ties in the order A, then B, then C
Calculation: Cash regime = cash enabled AND Leader score < cash threshold AND each of A, B, and C has close < EMA(close, slow EMA length)
Calculation: Holding score = Score(current holding) if the holding is A, B, or C; otherwise 0
Calculation: Target = Cash in a cash regime, otherwise Leader
Calculation: Cooldown ready = no previous rotation signal OR current bar index − previous signal bar index > cooldown; update previous signal bar index on each rotation signal
Long: Target is A, B, or C AND Target differs from current holding AND cash regime is false AND Leader score ≥ minimum leader score AND Leader score − Holding score ≥ minimum score edge AND cooldown ready AND (close confirmation is disabled OR the chart bar is confirmed)
Exit: long, Target is Cash AND Target differs from current holding AND cooldown ready AND (close confirmation is disabled OR the chart bar is confirmed)
