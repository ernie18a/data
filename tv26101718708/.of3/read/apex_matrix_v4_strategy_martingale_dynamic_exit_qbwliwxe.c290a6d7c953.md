Calculation: Total open interest = sum of the open-interest feeds’ close values, treating missing values as zero
Long: Bars since (low < lowest(low, swing lookback)[1] AND close > lowest(low, swing lookback)[1]) <= signal-expiry parameter AND (volume > SMA(volume, volume lookback) + standard-deviation multiplier * standard deviation(volume, volume lookback) OR abs(close - open) < abs(high - low) * absorption ratio) AND macro proxy close < SMA(macro proxy close, macro/OI lookback) AND total open interest <= SMA(total open interest, macro/OI lookback) AND current bar index - prior long-signal bar index > signal-expiry parameter (initial prior index is zero)
Short: Bars since (high > highest(high, swing lookback)[1] AND close < highest(high, swing lookback)[1]) <= signal-expiry parameter AND (volume > SMA(volume, volume lookback) + standard-deviation multiplier * standard deviation(volume, volume lookback) OR abs(close - open) < abs(high - low) * absorption ratio) AND macro proxy close > SMA(macro proxy close, macro/OI lookback) AND total open interest > SMA(total open interest, macro/OI lookback) AND current bar index - prior short-signal bar index > signal-expiry parameter (initial prior index is zero)
Calculation: Profit percentage = (close - entry price) / entry price for long positions; (entry price - close) / entry price for short positions
Calculation: Long ratchet stop = unset while flat; set to entry price * (1 + higher lock parameter) when high >= that level; otherwise, if unset, set to entry price * (1 + lower lock parameter) when high >= that level; otherwise retain the prior value, with lower lock parameter < higher lock parameter
Calculation: Short ratchet stop = unset while flat; set to entry price * (1 - higher lock parameter) when low <= that level; otherwise, if unset, set to entry price * (1 - lower lock parameter) when low <= that level; otherwise retain the prior value, with lower lock parameter < higher lock parameter
Exit: long, close <= entry price * (1 - logical stop parameter) OR low <= long ratchet stop when set, otherwise entry price * (1 - catastrophe stop parameter) OR high >= entry price * (1 + maximum take-profit parameter) OR (profit percentage >= minimum-profit parameter AND close < EMA(close, short lookback))
Exit: short, close >= entry price * (1 + logical stop parameter) OR high >= short ratchet stop when set, otherwise entry price * (1 + catastrophe stop parameter) OR low <= entry price * (1 - maximum take-profit parameter) OR (profit percentage >= minimum-profit parameter AND close > EMA(close, short lookback))
