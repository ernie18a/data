Calculation: Latest pivot leg = the segment from the prior pivot price to the latest pivot price on chart bars; a pivot high/low is high/low[half-depth] equal to highest(high)/lowest(low) over the centered 2 × half-depth + 1 bars; replace a same-direction pivot only with a more extreme one, and accept an opposite-direction pivot only when |100 × (candidate price − prior pivot price) / candidate price| > ATR(deviation ATR lookback) / close × 100 × deviation multiplier; initialize the prior pivot at price zero on bar zero.
Calculation: Fibonacci retracement level(ratio) = start price + (end price − start price) × ratio, using the latest pivot leg with its endpoints swapped when the reverse parameter is enabled.
Long: Choppiness Index(lookback, T1 bars, still-forming T1 bar, sampled on chart bars) >= threshold AND Fibonacci retracement level(entry ratio) > Fibonacci retracement level(stop ratio) AND Fibonacci retracement level(profit ratio) > Fibonacci retracement level(entry ratio) AND close crosses above Fibonacci retracement level(entry ratio)
Exit: Long, close crosses above Fibonacci retracement level(profit ratio) OR close crosses below Fibonacci retracement level(stop ratio)
