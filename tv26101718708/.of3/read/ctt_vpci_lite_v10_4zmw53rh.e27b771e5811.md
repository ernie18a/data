Calculation: Chart daily change % = 0 if the reference close is missing or zero; otherwise 100 × (chart-bar close − reference close) ÷ reference close, where the reference close is the previous completed T1 close if day-of-month(T1 timestamp sampled on the chart bar) = day-of-month(chart-bar time), otherwise the T1 close sampled on that chart bar. T1 values are sampled by chart bars; the current T1 bar is forming in realtime and completed on historical bars.
Calculation: Displayed-asset daily change % = na if either T1 close is missing or the previous completed T1 close ≤ 0; otherwise 100 × (current T1 close sampled on the chart bar − previous completed T1 close) ÷ previous completed T1 close. T1 values are sampled by chart bars; the current T1 bar is forming in realtime and completed on historical bars.
Long: Chart daily change % > 0 OR chart close ≥ chart open OR RSI(chart close, RSI lookback) ≤ oversold threshold OR any displayed asset's daily change % > 0 OR current T1 volume ÷ selected volume baseline ≥ RVOL threshold. The baseline is previous completed T1 volume, an SMA of prior completed T1 volumes using the selected lookback, or a weighted sum of shorter- and longer-lookback SMA-based RVOLs; the blended lookbacks are separate parameters with the longer greater than the shorter, and the weights are separate parameters. For SMA-based modes, multiply each baseline by a session factor: 1 outside regular intraday hours; otherwise min(1, progress + adjustment coefficient × sin(progress × π)), where progress = max(progress floor, min(1, max(0, minutes since regular-session start) ÷ session length)). Use a factor of 1 for the previous-volume mode. Current T1 volume is sampled by chart bars; it is forming in realtime and completed on historical bars. T1 SMAs use prior completed T1 bars.
