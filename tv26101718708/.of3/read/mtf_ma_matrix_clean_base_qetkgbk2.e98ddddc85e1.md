Calculation: MA angle proxy = (MA(source, longest lookback) - MA(source, longest lookback)[slope lookback]) / MA(source, longest lookback)
Calculation: normalized MA distance = abs(MA(source, first lookback) - MA(source, second lookback)) / ATR(ATR lookback)
Calculation: weighted separation score = first weight * normalized MA distance(shortest, second-shortest lookbacks) + second weight * normalized MA distance(second-shortest, third-shortest lookbacks) + third weight * normalized MA distance(third-shortest, longest lookbacks); each weight is a separate parameter and unavailable distance values count as zero
