Calculation: Swing stop = while flat, latest confirmed PivotLow(low, pivot-low lookback parameter, same parameter); while long, previous Swing stop if entry price ≤ the previous bar's latest confirmed PivotLow(low, pivot-low lookback parameter, same parameter), otherwise the latest confirmed PivotLow.
Calculation: MA trail level = latest low at a crossunder of low below the selected trailing moving average after the current long position began; undefined before that event. The selected average uses the shorter or intermediate lookback parameter on T1. Calculate the crossunder on T1 bars when the trail-timeframe parameter selects the moving-average timeframe, or on chart bars using T1 values when it selects the chart timeframe. T1 values use lookahead off: prior completed T1 values on historical intrabars and the developing T1 bar in real time.
Calculation: Exit stop = Swing stop if Swing stop > MA trail level; otherwise MA trail level if the previous close > MA trail level and the previous close > the selected trailing moving average; otherwise Swing stop.
Long: high crosses above the latest confirmed PivotHigh(high, pivot-high lookback parameter, same parameter) AND (MA filter disabled OR latest confirmed PivotHigh > the longest-lookback moving average) AND (ADR filter disabled OR latest confirmed PivotHigh − previous Swing stop < ADR percentage parameter × SMA((high − low) / abs(low) × 100, ADR lookback parameter, T2) / 100) AND datetime > start-date parameter AND datetime < end-date parameter. The three moving averages use close on T1, share a moving-average-type parameter (SMA or EMA), and have separate lookback parameters ordered shorter, intermediate, longest. T1 and T2 values use lookahead off: prior completed timeframe values on historical intrabars and the developing timeframe bar in real time.
Exit: Long, low ≤ Exit stop
