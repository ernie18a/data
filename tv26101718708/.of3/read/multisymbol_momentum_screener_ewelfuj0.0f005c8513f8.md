Calculation: Momentum score = mean(RSI(close, momentum RSI lookback)[1], PercentRank(ROC(close, momentum ROC lookback), momentum rank lookback)[1])
Calculation: Trend score = mean(clamp(trend midpoint + percent_difference(EMA(close, trend fast EMA lookback)[1], EMA(close, trend slow EMA lookback)[1]) * trend scaling, score floor, score ceiling), ADX(trend ADX lookback)[1]); trend slow EMA lookback is adjusted to exceed trend fast EMA lookback
Calculation: Volatility score = clamp(ATR(ATR lookback)[1] / SMA(ATR(ATR lookback), ATR normalization lookback)[1] * volatility scaling, score floor, score ceiling)
Calculation: Total score = clamp((Momentum score * momentum weight + Trend score * trend weight + Volatility score * volatility weight) / (momentum weight + trend weight + volatility weight), score floor, score ceiling); if all three input weights sum to zero, use 1 for each weight
Calculation: T1 direction = 0 if the absolute percent difference between EMA(close, T1 fast EMA lookback) and EMA(close, T1 slow EMA lookback) is below T1 flat threshold; otherwise 1 if the fast EMA is above the slow EMA, else -1; T1 slow EMA lookback is adjusted to exceed T1 fast EMA lookback; calculate on T1 bars using the last completed T1 bar and carry values to chart bars
Long: T1 direction > 0 OR (Total score >= high signal-score threshold AND T1 direction = 0) OR Momentum score >= bullish score-color threshold OR Trend score >= bullish score-color threshold OR Volatility score >= bullish score-color threshold OR Total score >= bullish score-color threshold
Short: T1 direction < 0 OR Momentum score < bearish score-color cutoff OR Trend score < bearish score-color cutoff OR Volatility score < bearish score-color cutoff OR Total score < bearish score-color cutoff
