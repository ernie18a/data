Calculation: ChartRange = (high, low) of the current chart bar if close > ChartRange.high[1] or close < ChartRange.low[1], else ChartRange[1]
Calculation: ChartRangeDir = +1 if close > ChartRange.high[1], -1 if close < ChartRange.low[1], else ChartRangeDir[1]
Calculation: T1Range = (high, low) of the last completed T1 bar if that bar's close > previous T1Range.high or < previous T1Range.low, else previous T1Range; updated when a new T1 bar starts
Calculation: T1Mid = (T1Range.high + T1Range.low) / 2
Calculation: BOS(tf, L) = +1 if last completed tf bar close > last confirmed pivothigh(L, L) of tf, -1 if it < last confirmed pivotlow(L, L) of tf, else BOS(tf, L)[1]
Calculation: HHHL(tf, L) = +1 if last confirmed pivothigh(L, L) of tf > previous confirmed pivothigh of tf AND last confirmed pivotlow(L, L) of tf > previous confirmed pivotlow of tf; -1 if both are lower than their previous values; else 0
Calculation: Structure(tf, L, rule) = BOS(tf, L) if rule = BOS; HHHL(tf, L) if rule = HH-HL; if rule = Both, BOS(tf, L) if BOS(tf, L) = HHHL(tf, L), else 0
Calculation: VolOk(T3) = volatility filter off OR (PercentRank(ATR(vol ATR length), vol lookback) >= min percentile if volatility metric = ATR pct, else ATR(vol ATR length) / SMA(ATR(vol ATR length), vol lookback) >= min ratio), both on the last completed T3 bar
Calculation: VWAPDist = abs(close - VWAP(hlc3, VWAP anchor)) / ATR(VWAP ATR length)
Calculation: StopCandLow = last confirmed pivotlow(stop pivot length) if stop reference = Swing pivot, low if stop reference = Flip candle range, ChartRange.low[1] if stop reference = Previous range
Calculation: StopCandHigh = last confirmed pivothigh(stop pivot length) if stop reference = Swing pivot, high if stop reference = Flip candle range, ChartRange.high[1] if stop reference = Previous range
Calculation: StopLong = (min(low, StopCandLow) if StopCandLow < close, else low) - stop buffer ticks * tick size
Calculation: StopShort = (max(high, StopCandHigh) if StopCandHigh > close, else high) + stop buffer ticks * tick size
Calculation: BEArmed = false if flat, else breakeven enabled for position side AND (BEArmed[1] OR (Long position AND high >= entry price + BE arm R * (entry price - StopLong at decision bar)) OR (Short position AND low <= entry price - BE arm R * (StopShort at decision bar - entry price)))
Calculation: StopLevel = (entry price + BE offset ticks * tick size if Long position, entry price - BE offset ticks * tick size if Short position) if BEArmed, else (StopLong at decision bar if Long position, StopShort at decision bar if Short position)
Long: close > ChartRange.high[1] AND ChartRangeDir[1] != +1 AND (structure filter off OR Structure(T1, structure pivot length, structure rule) = +1) AND (location mode = off OR (location mode = pullback AND close < T1Mid) OR (location mode = breakout AND close > T1Mid)) AND (regime filter off OR Structure(T2, structure pivot length, regime rule) != -1) AND VolOk(T3) AND (VWAP mode = off OR (VWAPDist <= max VWAP distance AND (VWAP mode = distance only OR (VWAP mode = long above AND close > VWAP(hlc3, VWAP anchor)) OR (VWAP mode = long below AND close < VWAP(hlc3, VWAP anchor))))) AND (depth gate off OR depth gate side = shorts OR (close - T1Range.low) / (T1Range.high - T1Range.low) < depth threshold) AND StopLong < close AND (min stop ticks = 0 OR close - StopLong >= min stop ticks * tick size) AND (max stop ticks = 0 OR close - StopLong <= max stop ticks * tick size) AND (backtest date filter off OR bar time within backtest date range) AND bar time within long entry session AND long side enabled AND position flat
Short: close < ChartRange.low[1] AND ChartRangeDir[1] != -1 AND (structure filter off OR Structure(T1, structure pivot length, structure rule) = -1) AND (location mode = off OR (location mode = pullback AND close > T1Mid) OR (location mode = breakout AND close < T1Mid)) AND (regime filter off OR Structure(T2, structure pivot length, regime rule) != +1) AND VolOk(T3) AND (VWAP mode = off OR (VWAPDist <= max VWAP distance AND (VWAP mode = distance only OR (VWAP mode = long above AND close < VWAP(hlc3, VWAP anchor)) OR (VWAP mode = long below AND close > VWAP(hlc3, VWAP anchor))))) AND (depth gate off OR depth gate side = longs OR (T1Range.high - close) / (T1Range.high - T1Range.low) < depth threshold) AND StopShort > close AND (min stop ticks = 0 OR StopShort - close >= min stop ticks * tick size) AND (max stop ticks = 0 OR StopShort - close <= max stop ticks * tick size) AND (backtest date filter off OR bar time within backtest date range) AND bar time within short entry session AND short side enabled AND position flat
Exit: Long, low <= StopLevel
Exit: Long, high >= entry price + long R:R * (entry price - StopLong at decision bar)
Exit: Short, high >= StopLevel
Exit: Short, low <= entry price - short R:R * (StopShort at decision bar - entry price)
