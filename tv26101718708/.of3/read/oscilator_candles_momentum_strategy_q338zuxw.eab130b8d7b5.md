Calculation: Oscillator OHLC = apply the selected RSI, Stochastic, Center of Gravity, MACD line, TSI, CCI, CMO, or MFI to open, high, low, and close; use the lookback parameter for RSI, Stochastic, Center of Gravity, CCI, CMO, and MFI, the short and long lookbacks for TSI, and the short, long, and signal lookbacks for MACD.
Calculation: Supertrend direction = calculate true range as max(Oscillator high, previous Oscillator close) - min(Oscillator low, previous Oscillator close), and ATR as the selected moving average of true range times the ATR multiplier; set the long band to Oscillator close - ATR and the short band to Oscillator close + ATR; carry the prior long band forward as the maximum of the current and prior long bands when (wicks enabled ? previous Oscillator low : previous Oscillator close) > prior long band, otherwise use the current long band; carry the prior short band forward as the minimum of the current and prior short bands when (wicks enabled ? previous Oscillator high : previous Oscillator close) < prior short band, otherwise use the current short band; initialize direction up and retain the prior direction unless the prior direction is down and (wicks enabled ? Oscillator high : Oscillator close) > prior short band, which sets it up, or the prior direction is up and (wicks enabled ? Oscillator low : Oscillator close) < prior long band, which sets it down; when a prior band is unavailable, use the current band.
Long: Supertrend direction is up AND datetime is within the configured start and end times.
Short: Supertrend direction is down AND datetime is within the configured start and end times.
Exit: long, Supertrend direction is down AND datetime is outside the configured start and end times.
Exit: short, Supertrend direction is up AND datetime is outside the configured start and end times.
