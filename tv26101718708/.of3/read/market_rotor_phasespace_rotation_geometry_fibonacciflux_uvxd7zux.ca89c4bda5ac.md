Calculation: selected raw-axis pair = on chart bars, use (log(close) − EMA(log(close), detrending lookback), EMA(one-bar log return, shorter momentum lookback) − EMA(one-bar log return, longer momentum lookback)); (log(close) − EMA(log(close), detrending lookback), signed T1 intrabar volume delta divided by chart-bar volume, falling back to close-location value if no T1 intrabars or chart-bar volume is not positive); (log(close) − EMA(log(close), detrending lookback), close-location value); (one-bar log return, change in realized volatility); or (log(close) − EMA(log(close), detrending lookback), change in open-interest close), according to the selected axis mode. One-bar log return = log(close / close[1]); signed T1 delta sums T1 volume when T1 close rises, subtracts it when T1 close falls, and adds zero when unchanged; close-location value = 2 × (close − low) / (high − low) − 1, or zero when high equals low; realized volatility = sqrt(SMA(one-bar log return squared, realized-volatility lookback)); change in realized volatility and open-interest close are current minus prior chart-bar value.
Calculation: first and second phase coordinates = separately rolling-z-score the selected raw axes using the normalization lookback, optionally apply the symmetric inverse square root of their rolling 2×2 covariance matrix using that lookback, then clip each coordinate to the configured absolute bound. In anchored mode, freeze the normalization and covariance statistics at the configured anchor after warm-up plus anchor delay; otherwise use rolling statistics. These calculations and the decisions run on chart bars; T1 intrabars are aggregated into each chart bar.
Calculation: radius = sqrt(first phase coordinate squared + second phase coordinate squared).
Calculation: angular change = zero when the current or prior radius is below the central dead-zone radius; otherwise atan2(prior first phase coordinate × current second phase coordinate − prior second phase coordinate × current first phase coordinate, prior first phase coordinate × current first phase coordinate + prior second phase coordinate × current second phase coordinate).
Calculation: phase coherence = sum(angular change, consistency lookback) / sum(abs(angular change), consistency lookback), defined only when the denominator exceeds the total-turn gate.
Calculation: spiral score = sum of log(radius + radius offset) changes over the consistency lookback, treating a change as zero when the current or prior radius is below the central dead-zone radius, divided by sum(abs(angular change), consistency lookback); defined only when that denominator exceeds the total-turn gate.
Calculation: hazard score = clamp(angular surprise + coherence-drop penalty + coherence-flip bonus, zero, hazard-score cap). Angular surprise = abs(angular change − EMA(angular change, hazard smoothing lookback)) / max(STDEV(angular change, hazard dispersion lookback), hazard dispersion floor). Coherence-drop penalty = max(0, abs(prior phase coherence) − abs(current phase coherence)) × coherence-drop weight. Coherence-flip bonus is added when prior phase coherence × current phase coherence < 0 and abs(prior phase coherence) exceeds the flip threshold; treat undefined coherence values as zero.
Calculation: multi-bar log return = log(close / close[reversal-return lookback]).
Long: chart bars since start ≥ warm-up multiplier × max(normalization, detrending, winding, area, and consistency lookbacks) AND (anchored normalization is off OR chart bars since start ≥ those warm-up bars + anchor delay) AND no long or short reversal or breakout signal occurred within the cooldown interval AND ((first phase coordinate < −reversal threshold AND multi-bar log return crosses above zero AND phase coherence and spiral score are defined AND abs(phase coherence) > minimum coherence AND spiral score < spiral threshold AND hazard score < reversal hazard ceiling) OR (prior first phase coordinate ≤ breakout threshold AND first phase coordinate > breakout threshold AND multi-bar log return > 0 AND radius > minimum breakout radius AND spiral score is defined AND spiral score > spiral threshold AND hazard score < breakout hazard ceiling)).
Short: chart bars since start ≥ warm-up multiplier × max(normalization, detrending, winding, area, and consistency lookbacks) AND (anchored normalization is off OR chart bars since start ≥ those warm-up bars + anchor delay) AND no long or short reversal or breakout signal occurred within the cooldown interval AND ((first phase coordinate > reversal threshold AND multi-bar log return crosses below zero AND phase coherence and spiral score are defined AND abs(phase coherence) > minimum coherence AND spiral score < spiral threshold AND hazard score < reversal hazard ceiling) OR (prior first phase coordinate ≥ −breakout threshold AND first phase coordinate < −breakout threshold AND multi-bar log return < 0 AND radius > minimum breakout radius AND spiral score is defined AND spiral score > spiral threshold AND hazard score < breakout hazard ceiling)).
