Calculation: Z-score(x) = 0 when stdev(x, z lookback) = 0; otherwise (x − SMA(x, z lookback)) / stdev(x, z lookback)
Calculation: Range normalization(x) = percentage midpoint when highest(x, normalization lookback) = lowest(x, normalization lookback); otherwise percentage scale × (x − lowest(x, normalization lookback)) / (highest(x, normalization lookback) − lowest(x, normalization lookback))
Calculation: Trend score(bars) = weighted sum of: clamp(EMA(trend Z weight × Z-score(EMA(close, trend lookback) − EMA(close, trend lookback)[1]) + momentum Z weight × Z-score(ROC(close, momentum lookback)) + volume Z weight × Z-score(change(OBV(close, volume))) + volatility Z weight × Z-score((ATR(score ATR lookback) − ATR(score ATR lookback)[1]) × (close > EMA(close, price-direction EMA lookback) ? positive unit : negative unit)), organ smoothing lookback) transformed by the organ scale, offset, and percentage bounds; clamp((close − (resistance + support) / 2) / max(resistance − support, minimum price increment) × MATC scale + MATC offset, MATC lower bound, MATC upper bound), where resistance = EMA(hl2 + hl2 × MATC band fraction × MATC mirror, MATC smoothing lookback) and support = EMA(hl2 − hl2 × MATC band fraction × MATC mirror, MATC smoothing lookback); ribbon score = above-ribbon value when EMA(close, shorter ribbon lookback) > EMA(close, longer ribbon lookback), below-ribbon value when it is lower, otherwise equal-ribbon value; and RSI(close, RSI lookback) clamped to its bounds
Calculation: Volume impulse score(bars) = weighted sum of EMA((correlation(change(close), change(volume), correlation lookback) defaulting to zero when unavailable + correlation offset) × correlation scale, correlation smoothing lookback); EMA(Range normalization(ATR(PVM ATR lookback) / max(EMA(ATR(PVM ATR lookback), ATR baseline lookback), minimum price increment) × volume / max(EMA(volume, relative-volume lookback), relative-volume floor), normalization lookback), impulse smoothing lookback); and EMA(Range normalization(ROC(close, PVM ROC lookback), normalization lookback), direction smoothing lookback)
Calculation: Power = clamp((when MTF is enabled, chart Trend score blended by chart-score weight with the weighted Trend scores of T1, T2, and T3; otherwise chart Trend score) blended by MTF blend weight with the corresponding chart and T1/T2/T3 Volume impulse scores when MTF is enabled, otherwise chart Volume impulse score, then blended with that PVM power by PVM boost weight when PVM boost is enabled, otherwise left as the raw power), between power lower and upper bounds; chart calculations use the current chart bar, while T1, T2, and T3 calculations use each timeframe’s last completed bar, carried onto chart bars
Calculation: Direction state = neutral initially; after each confirmed chart bar, set long if the Long entry condition is true, then set short if the Short entry condition is true; otherwise retain the prior state
Long: On a confirmed chart bar, Power ≥ long-entry threshold AND direction state at the start of the bar is not long
Short: On a confirmed chart bar, Power ≤ short-entry threshold AND direction state at the start of the bar is not short
Long: Power ≥ strong bullish-power threshold
Long: Power ≥ bullish-power threshold AND Power < strong bullish-power threshold
