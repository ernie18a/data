Calculation: Candle body ratio = abs(close - open) / max(high - low, minimum price tick).
Calculation: Bullish displacement = (close > open AND abs(close - open) >= ATR(ATR lookback) * strong-body ATR multiple AND candle body ratio >= minimum body ratio AND close >= high - max(high - low, minimum price tick) * close-to-high fraction) OR (at least the required count of up-closes in the three-bar displacement window AND close > close[2] AND close - lowest(low, three-bar displacement window) >= ATR(ATR lookback) * displacement ATR multiple).
Calculation: Bearish displacement = (close < open AND abs(close - open) >= ATR(ATR lookback) * strong-body ATR multiple AND candle body ratio >= minimum body ratio AND close <= low + max(high - low, minimum price tick) * close-to-low fraction) OR (at least the required count of down-closes in the three-bar displacement window AND close < close[2] AND highest(high, three-bar displacement window) - close >= ATR(ATR lookback) * displacement ATR multiple).
Calculation: Recent bullish displacement = bullish displacement occurred within the displacement memory chart bars.
Calculation: Recent bearish displacement = bearish displacement occurred within the displacement memory chart bars.
Calculation: Bullish candle pattern = bullish engulfing (prior close < prior open, current close > current open, current open <= prior close, current close >= prior open) OR morning star (close[2] < open[2], body ratio[1] <= middle-candle body fraction, close > open, close > (open[2] + close[2]) / 2) OR three advancing bullish candles (close > open, close[1] > open[1], close[2] > open[2], close > close[1] > close[2], body ratio >= current-candle fraction, body ratio[1] and body ratio[2] >= prior-candle fraction).
Calculation: Bearish candle pattern = bearish engulfing (prior close > prior open, current close < current open, current open >= prior close, current close <= prior open) OR evening star (close[2] > open[2], body ratio[1] <= middle-candle body fraction, close < open, close < (open[2] + close[2]) / 2) OR three declining bearish candles (close < open, close[1] < open[1], close[2] < open[2], close < close[1] < close[2], body ratio >= current-candle fraction, body ratio[1] and body ratio[2] >= prior-candle fraction).
Calculation: Recent bullish candle pattern = bullish candle pattern occurred within the pattern memory chart bars.
Calculation: Recent bearish candle pattern = bearish candle pattern occurred within the pattern memory chart bars.
Calculation: Bullish fair value gap = low > high[2].
Calculation: Bearish fair value gap = high < low[2].
Calculation: Recent bullish fair value gap = bullish fair value gap occurred within the FVG memory chart bars.
Calculation: Recent bearish fair value gap = bearish fair value gap occurred within the FVG memory chart bars.
Calculation: Volume expansion = highest(volume / SMA(volume, volume-average lookback), volume-memory lookback) >= volume-expansion multiple.
Calculation: Bullish liquidity sweep = confirmed low < lowest(low[1], structure lookback) AND close > lowest(low[1], structure lookback).
Calculation: Bearish liquidity sweep = confirmed high > highest(high[1], structure lookback) AND close < highest(high[1], structure lookback).
Calculation: Recent bullish liquidity sweep = bullish liquidity sweep occurred within the sweep memory chart bars.
Calculation: Recent bearish liquidity sweep = bearish liquidity sweep occurred within the sweep memory chart bars.
Calculation: Bullish formation quality = quality baseline + bullish FVG quality weight if recent bullish fair value gap + candle-pattern quality weight if recent bullish candle pattern + volume quality weight if volume expansion + sweep quality weight if recent bullish liquidity sweep.
Calculation: Bearish formation quality = quality baseline + bearish FVG quality weight if recent bearish fair value gap + candle-pattern quality weight if recent bearish candle pattern + volume quality weight if volume expansion + sweep quality weight if recent bearish liquidity sweep.
Calculation: Bullish zone = bounds of the nearest preceding bearish candle within the opposite-candle search lookback: refined mode uses open to low, body mode uses max(open, close) to min(open, close), and full-candle mode uses high to low.
Calculation: Bearish zone = bounds of the nearest preceding bullish candle within the opposite-candle search lookback: refined mode uses high to open, body mode uses max(open, close) to min(open, close), and full-candle mode uses high to low.
Calculation: Zone size ATR = (zone top - zone bottom) / max(ATR(ATR lookback), minimum price tick), using ATR on the zone-creation chart bar.
Calculation: Bullish OB reversal power = clamp(round(bullish formation quality * quality weight + size-fit score + clamp(round(max(0, close - lowest(low, displacement window)) / ATR(ATR lookback) * impulse weight), 0, impulse-score cap)), 0, score maximum).
Calculation: Bearish OB reversal power = clamp(round(bearish formation quality * quality weight + size-fit score + clamp(round(max(0, highest(high, displacement window) - close) / ATR(ATR lookback) * impulse weight), 0, impulse-score cap)), 0, score maximum).
Calculation: Size-fit score = piecewise score by zone size ATR, using separate thresholds below the preferred minimum, within the preferred range, and above the preferred range.
Calculation: Freshness score = piecewise age score, with separate age thresholds and scores for newest, progressively older, and oldest zones.
Calculation: Mitigation score = un-retested bonus if the zone has not been retested, otherwise retested penalty.
Calculation: Depletion penalty = zero outside HOLD; in HOLD, zero for the first test, then the second-test penalty, plus the third-test increment, plus the fourth-test increment, plus an additional per-test penalty after the fourth test, capped at the maximum depletion penalty.
Calculation: Zone context = reversal power + freshness score + mitigation score - depletion penalty.
Calculation: Opposing-zone conflict penalty = for each active opposing zone that overlaps the zone or lies in its expected reaction path and is within the conflict ATR range, take the maximum of the gap penalty plus a strength penalty; gap penalty is selected by overlap or gap ATR bands, strength penalty is the stronger-opponent penalty when opposing context exceeds own context by the strength margin, the weaker-opponent penalty when opposing context is at least own context, and zero otherwise. Add the multiple-conflict penalty when at least the required number of opposing zones qualify, then cap at the conflict-penalty maximum. Gap ATR is the gap between zone bounds divided by current ATR; reaction path is an opposing-zone center at or beyond the current zone center in the expected reaction direction.
Calculation: Quality cap = piecewise score cap by formation-quality bands.
Calculation: Structural score = min(quality cap, clamp(reversal power + freshness score + mitigation score - opposing-zone conflict penalty - depletion penalty, 0, score maximum)).
Calculation: Distance to zone = zero when price is inside the zone, otherwise the distance from price to the nearest zone boundary.
Calculation: Interaction score = inside-zone score when price is inside; otherwise a piecewise score by distance-to-zone ATR bands.
Calculation: State action bonus = approach-state bonus for APPROACH, in-zone bonus for IN ZONE, and zero otherwise.
Calculation: Action score = min(quality cap, clamp(structural score + interaction score + state action bonus, 0, score maximum)).
Calculation: Active OB set = created zones not invalidated on a confirmed chart bar and not removed when the retained-zone count exceeds its configured maximum. Bullish zones invalidate when close < zone bottom in close mode or low < zone bottom in wick mode; bearish zones invalidate when close > zone top in close mode or high > zone top in wick mode.
Calculation: OB lifecycle state = on confirmed chart bars, a zone becomes armed after close departs beyond its expected boundary by the retest-departure ATR distance; an armed zone is IN ZONE on a touch after the minimum age, otherwise APPROACH when close is within the approach ATR distance and FRESH when farther away. IN ZONE becomes HOLD on a later confirmed close departing beyond the expected boundary by the hold-confirmation ATR distance; if it is no longer touched before that, it becomes APPROACH or FRESH by the same distance test. HOLD persists until invalidation. A touch is low <= zone top AND high >= zone bottom.
Calculation: OB test count = count of separate confirmed touch episodes after arming and after the minimum zone age; a new episode begins when the zone is touched and was not touched on the prior bar.
Calculation: Panel price and ATR = current close and ATR on a confirmed chart bar; on a forming chart bar, use the prior chart bar close and ATR.
Calculation: Panel interaction score = interaction score using panel price, zone bounds, and panel ATR.
Calculation: Effective OB score = structural score for FRESH or HOLD; for APPROACH or IN ZONE, clamp(structural score + panel interaction score + state action bonus, 0, score maximum).
Calculation: State weight = configured weight selected by lifecycle state, with separate weights for FRESH, APPROACH, IN ZONE, and HOLD.
Calculation: Proximity weight = configured weight selected by panel distance-to-zone ATR bands, with a separate inside-zone weight.
Calculation: OB weighted power = effective OB score * state weight * proximity weight.
Calculation: Dominance edge = 100 * bullish active-zone weighted power / total active-zone weighted power - 100 * bearish active-zone weighted power / total active-zone weighted power; when total power is zero, dominance is equal for both sides and the edge is zero.

Short: confirmed close < lowest(low[1], structure lookback) - ATR(ATR lookback) * BOS buffer AND close[1] >= lowest(low[2], structure lookback) - ATR(ATR lookback)[1] * BOS buffer.
