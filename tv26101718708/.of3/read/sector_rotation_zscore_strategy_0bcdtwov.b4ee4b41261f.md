Calculation: relative-strength signal = if signal smoothing is enabled, SMA(Z-score(ln(first comparison instrument close / second comparison instrument close), z-score lookback), signal smoothing length), otherwise Z-score(ln(first comparison instrument close / second comparison instrument close), z-score lookback)
Calculation: pivot-relative bias = EMA(traded instrument close / latest pivot high × 100, pivot smoothing length) - EMA(latest pivot low / traded instrument close × 100, pivot smoothing length), using latest pivots defined by separate left and right pivot widths
Long: (relative-strength signal crosses above negative z-score buffer OR (pivot-relative bias > 0 AND an unconsumed crossover above the negative z-score buffer occurred within the pivot match window)) AND (PPP entry filter disabled OR pivot-relative bias > 0 now or within the pivot match window) AND (ADX entry filter disabled OR ADX >= minimum ADX) AND (date filter disabled OR date is between start and end dates)
Short: short side enabled AND (relative-strength signal crosses above short-entry z-score level OR (pivot-relative bias < 0 AND an unconsumed crossover above the short-entry z-score level occurred within the pivot match window)) AND (PPP entry filter disabled OR pivot-relative bias < 0 now or within the pivot match window) AND (ADX entry filter disabled OR ADX >= minimum ADX) AND (date filter disabled OR date is between start and end dates)
Exit: Long, (PPP-confirmed exit enabled AND relative-strength signal crossed below positive z-score buffer during this long position AND pivot-relative bias < 0) OR (PPP-confirmed exit disabled AND (relative-strength signal crosses below positive z-score buffer OR (ADX exit enabled AND ADX crosses below ADX exit threshold) OR (PPP-flip exit enabled AND pivot-relative bias < 0)) )
Exit: Short, short side enabled AND ((PPP-confirmed exit enabled AND relative-strength signal crossed above negative z-score buffer during this short position AND pivot-relative bias > 0 AND no long entry occurs) OR (PPP-confirmed exit disabled AND ((relative-strength signal crosses above negative z-score buffer AND no long entry occurs) OR (ADX exit enabled AND ADX crosses below ADX exit threshold) OR (PPP-flip exit enabled AND pivot-relative bias > 0)))
