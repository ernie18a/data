Calculation: breakout buffer = ATR(ATR lookback) * ATR buffer multiplier when the ATR buffer is enabled, otherwise 0
Long: on a confirmed chart bar, close > the latest confirmed Pivot High(high, pivot left strength, pivot right strength) + breakout buffer AND close[1] <= that same level + the current breakout buffer AND (the volume filter is disabled OR volume > SMA(volume, volume average lookback) * volume multiplier) AND that pivot high has not already triggered a bullish signal since becoming the latest confirmed pivot high
Short: on a confirmed chart bar, close < the latest confirmed Pivot Low(low, pivot left strength, pivot right strength) - breakout buffer AND close[1] >= that same level - the current breakout buffer AND (the volume filter is disabled OR volume > SMA(volume, volume average lookback) * volume multiplier) AND that pivot low has not already triggered a bearish signal since becoming the latest confirmed pivot low
