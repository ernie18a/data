Calculation: bounded value(x, lower bound, upper bound) = max(lower bound, min(upper bound, x))
Calculation: signed unit scaling(x, scale) = bounded value(x / scale, -1, 1)
Calculation: unsigned unit scaling(x, scale) = bounded value(x / scale, 0, 1)
Calculation: inclusive trailing rank(x, lookback) = the fraction of the current and previous lookback-minus-one chart-bar values of x that are less than or equal to the current x
Calculation: composite directional bias = percentage-scaled bounded value(short-slope weight × signed unit scaling((EMA(close, short EMA lookback) - EMA(close, short EMA lookback)[1]) / close, short-slope scale) + intermediate-slope weight × signed unit scaling((EMA(close, intermediate EMA lookback) - EMA(close, intermediate EMA lookback)[1]) / close, intermediate-slope scale) + long-slope weight × signed unit scaling((EMA(close, long EMA lookback) - EMA(close, long EMA lookback)[1]) / close, long-slope scale) + stack weight × stack sign + RSI weight × signed unit scaling(RSI(close, RSI lookback) - RSI neutral level, RSI scale), -1, 1), where stack sign is 1 when the short-lookback EMA > intermediate-lookback EMA > long-lookback EMA, -1 when the reverse inequalities hold, and 0 otherwise
Calculation: market tension = percentage-scaled bounded value(compression weight × (1 - (compression BB weight × inclusive trailing rank(Bollinger Band width(close, BB lookback, BB multiplier), rank lookback) + compression ATR weight × inclusive trailing rank(ATR(ATR lookback) / close, rank lookback))) + coupling weight × bounded value(the mean of abs(correlation(ROC(close, short return lookback), one-chart-bar change of RSI(close, RSI lookback), correlation lookback)), abs(correlation(ROC(close, longer return lookback), (EMA(close, short EMA lookback) - EMA(close, long EMA lookback)) / close, correlation lookback)), and abs(correlation(ROC(close, short return lookback), ATR(ATR lookback) / close, correlation lookback)), 0, 1) + persistence weight × the fraction of the current and previous persistence-lookback chart bars whose bias state matches the current non-neutral state (bias state is bullish above the bias-state threshold, bearish below its negative, and neutral otherwise; use 0 when current state is neutral) + expansion weight × unsigned unit scaling(max(ROC(ATR(ATR lookback), ATR ROC lookback), 0), ATR expansion scale) + volume weight × (volume filter enabled ? unsigned unit scaling(max(z-score(volume, volume lookback), 0), volume scale) : 0), 0, 1)
Calculation: session opening-range high = highest chart-bar high from the start of the configured session until the opening-range duration elapses
Calculation: session opening-range low = lowest chart-bar low from the start of the configured session until the opening-range duration elapses
Long: market tension >= tension threshold AND composite directional bias >= bullish bias threshold
Short: market tension >= tension threshold AND composite directional bias <= bearish bias threshold
Long: opening range is defined AND ((bar-close confirmation is enabled AND close > session opening-range high) OR (bar-close confirmation is disabled AND high > session opening-range high)) AND market tension >= tension threshold AND composite directional bias >= bullish bias threshold AND EMA(close, short EMA lookback) > EMA(close, intermediate EMA lookback) AND this setup was false on the preceding chart bar
Short: opening range is defined AND ((bar-close confirmation is enabled AND close < session opening-range low) OR (bar-close confirmation is disabled AND low < session opening-range low)) AND market tension >= tension threshold AND composite directional bias <= bearish bias threshold AND EMA(close, short EMA lookback) < EMA(close, intermediate EMA lookback) AND this setup was false on the preceding chart bar
Exit: long, current long breakout setup conditions above AND (composite directional bias < 0 OR close < EMA(close, short EMA lookback))
Exit: short, current short breakout setup conditions above AND (composite directional bias > 0 OR close > EMA(close, short EMA lookback))
