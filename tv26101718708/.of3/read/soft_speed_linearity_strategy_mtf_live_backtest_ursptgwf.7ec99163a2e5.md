Calculation: Speed = (close(T1) − open(T1)) / elapsed seconds, using T1 values mapped onto chart bars; LIVE uses the forming T1 bar and elapsed time since its open (or T1 duration after it closes), while BACKTEST uses the last completed T1 bar and T1 duration.
Calculation: Smoothed speed = EMA(Speed, smoothing lookback), calculated on chart bars.
Calculation: Linearity score = initialize at the lowest score; when |close(T1) − open(T1)| / max(ATR(T1, ATR lookback), tick-size floor) ≥ minimum progress, successively assign the second, third, fourth, and highest score when adverse movement / max(ATR(T1, ATR lookback), tick-size floor) is ≤ the respective adverse threshold, in that order; adverse movement is max(0, open(T1) − low(T1)) when close(T1) ≥ open(T1), otherwise max(0, high(T1) − open(T1)); calculate on chart bars using T1 values and ATR, with the forming T1 bar in LIVE and the last completed T1 bar in BACKTEST.
Calculation: Entry speed metric = |Smoothed speed| when weighted entry is disabled; otherwise |Smoothed speed × Linearity score / maximum score|.
Long: close(T1) > open(T1), using T1 values mapped onto chart bars; use the forming T1 bar in LIVE and the last completed T1 bar in BACKTEST.
Short: close(T1) < open(T1), using T1 values mapped onto chart bars; use the forming T1 bar in LIVE and the last completed T1 bar in BACKTEST.
Long: execution mode is LIVE or the chart bar is confirmed in BACKTEST; long is permitted by the direction setting; cooldown is disabled, no prior entry signal exists, or at least the cooldown number of chart bars have elapsed since the prior entry signal; close(T1) > open(T1); Linearity score ≥ entry minimum score; and Entry speed metric ≥ the LIVE or BACKTEST minimum speed for the selected execution mode.
Short: execution mode is LIVE or the chart bar is confirmed in BACKTEST; short is permitted by the direction setting; cooldown is disabled, no prior entry signal exists, or at least the cooldown number of chart bars have elapsed since the prior entry signal; close(T1) < open(T1); Linearity score ≥ entry minimum score; and Entry speed metric ≥ the LIVE or BACKTEST minimum speed for the selected execution mode.
Exit: Long, execution mode is LIVE or the chart bar is confirmed in BACKTEST, AND (symmetric exit mode AND (Linearity score < entry minimum score OR Entry speed metric < the LIVE or BACKTEST minimum speed for the selected execution mode) OR hysteresis exit mode AND (Linearity score ≤ hysteresis exit score threshold OR |Smoothed speed| ≤ hysteresis exit speed threshold) OR momentum exit mode AND Smoothed speed ≤ 0 OR channel and channel-reentry exits are enabled AND −lower channel threshold ≤ Smoothed speed ≤ upper channel threshold).
Exit: Short, execution mode is LIVE or the chart bar is confirmed in BACKTEST, AND (symmetric exit mode AND (Linearity score < entry minimum score OR Entry speed metric < the LIVE or BACKTEST minimum speed for the selected execution mode) OR hysteresis exit mode AND (Linearity score ≤ hysteresis exit score threshold OR |Smoothed speed| ≤ hysteresis exit speed threshold) OR momentum exit mode AND Smoothed speed ≥ 0 OR channel and channel-reentry exits are enabled AND −lower channel threshold ≤ Smoothed speed ≤ upper channel threshold).
