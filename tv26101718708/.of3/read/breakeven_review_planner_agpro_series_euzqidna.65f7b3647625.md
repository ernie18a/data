Calculation: body ratio = abs(close - open) / max(high - low, minimum tick size)
Calculation: long invalidation shelf = at context activation, latest confirmed PivotLow(low, swing confirmation length) - ATR(ATR lookback) * invalidation ATR buffer, or Lowest(low, structure lookback) - ATR(ATR lookback) * invalidation ATR buffer if no confirmed swing low exists; hold fixed for the context
Calculation: short invalidation shelf = at context activation, latest confirmed PivotHigh(high, swing confirmation length) + ATR(ATR lookback) * invalidation ATR buffer, or Highest(high, structure lookback) + ATR(ATR lookback) * invalidation ATR buffer if no confirmed swing high exists; hold fixed for the context
Calculation: context initial risk = entry price - long invalidation shelf for a long context, or short invalidation shelf - entry price for a short context
Calculation: current R = (close - entry price) / context initial risk for a long context, or (entry price - close) / context initial risk for a short context
