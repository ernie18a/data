EMA(EMA(close, fast EMA period), EMA smoothing period) > EMA(EMA(close, slow EMA period), EMA smoothing period) : EMA(close, fast EMA period) > EMA(close, slow EMA period)))
Short: (start-date filter disabled OR time >= start date) AND (end-date filter disabled OR time <= end date) AND (DI filter disabled OR +DI < -DI) AND (EMA filter disabled OR (EMA smoothing enabled ? EMA(EMA(close, fast EMA period), EMA smoothing period) < EMA(EMA(close, slow EMA period), EMA smoothing period) : EMA(close, fast EMA period) < EMA(close, slow EMA period)))
Exit: long, (start-date filter enabled AND time < start date) OR (end-date filter enabled AND time > end date)
