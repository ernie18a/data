Calculation: Pivot center(pivot lookback) = start with the first confirmed PivotHigh(pivot lookback, pivot lookback), or PivotLow(pivot lookback, pivot lookback) if no PivotHigh is present; thereafter, when either is newly confirmed, use PivotHigh if both are present, and set the center to (2 × prior center + new pivot)/3; otherwise retain the prior center.
Calculation: Pivot-centered trend(pivot lookback, trend ATR lookback, ATR multiplier) = initialize lower and upper trailing bands to 0; on each chart bar, let raw lower and upper bands be Pivot center(pivot lookback) −/+ ATR multiplier × ATR(trend ATR lookback); set the lower trailing band to max(raw lower band, prior lower trailing band) if close[1] > prior lower trailing band, else to the raw lower band; set the upper trailing band to min(raw upper band, prior upper trailing band) if close[1] < prior upper trailing band, else to the raw upper band; the trend is bullish if close > prior upper trailing band, bearish if close < prior lower trailing band, and otherwise the prior trend, defaulting to bullish.
Calculation: VWAP margin = ATR(margin ATR lookback) × margin percentage.
Calculation: Active pivot levels(pivot lookback) = retain the latest confirmed PivotHigh(pivot lookback, pivot lookback) and PivotLow(pivot lookback, pivot lookback), replacing each level when a new corresponding pivot confirms; clear the active high after close > it and clear the active low after close < it.
Long: Pivot-centered trend(pivot lookback, trend ATR lookback, ATR multiplier) is bullish AND close > VWAP(hlc3) + VWAP margin AND no prior main long signal since the current bullish trend began.
Short: Pivot-centered trend(pivot lookback, trend ATR lookback, ATR multiplier) is bearish AND close < VWAP(hlc3) − VWAP margin AND no prior main short signal since the current bearish trend began.
Long: Pivot-centered trend(pivot lookback, trend ATR lookback, ATR multiplier) is bullish AND low ≤ VWAP(hlc3) + 3 × VWAP margin AND close > open AND close > close[1] AND NOT (close > VWAP(hlc3) + VWAP margin AND no prior main long signal since the current bullish trend began).
Short: Pivot-centered trend(pivot lookback, trend ATR lookback, ATR multiplier) is bearish AND high ≥ VWAP(hlc3) − 3 × VWAP margin AND close < open AND close < close[1] AND NOT (close < VWAP(hlc3) − VWAP margin AND no prior main short signal since the current bearish trend began).
Exit: Long, Pivot-centered trend(pivot lookback, trend ATR lookback, ATR multiplier) is bullish AND an active pivot low exists AND close < active pivot low.
Exit: Short, Pivot-centered trend(pivot lookback, trend ATR lookback, ATR multiplier) is bearish AND an active pivot high exists AND close > active pivot high.
