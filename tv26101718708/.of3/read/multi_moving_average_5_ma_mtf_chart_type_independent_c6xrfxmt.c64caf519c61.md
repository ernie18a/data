Calculation: first moving average = first moving-average-type parameter(first source parameter, first lookback parameter), calculated on T1 bars and mapped to chart bars using the last completed T1 bar when confirmed values are enabled, otherwise the T1 bar still forming
Calculation: second moving average = second moving-average-type parameter(second source parameter, second lookback parameter), calculated on T2 bars and mapped to chart bars using the last completed T2 bar when confirmed values are enabled, otherwise the T2 bar still forming
Calculation: fifth moving average = fifth moving-average-type parameter(fifth source parameter, fifth lookback parameter), calculated on T5 bars and mapped to chart bars using the last completed T5 bar when confirmed values are enabled, otherwise the T5 bar still forming
Long: chart-timeframe close crosses above the first moving average OR chart-timeframe close crosses above the second moving average OR the first moving average crosses above the second moving average OR the second moving average crosses above the fifth moving average
Short: chart-timeframe close crosses below the first moving average OR chart-timeframe close crosses below the second moving average OR the first moving average crosses below the second moving average OR the second moving average crosses below the fifth moving average
