Calculation: original SuperTrend value and direction = ATR bands around raw or Rational Quadratic Kernel-smoothed HL2, using raw ATR or its Rational Quadratic Kernel value and a factor parameter; lower band is the current lower band when it exceeds the prior lower band or prior close source is below the prior lower band, otherwise the prior lower band; upper band is the current upper band when it is below the prior upper band or prior close source is above the prior upper band, otherwise the prior upper band; missing prior bands are zero; close source is raw close or Rational Quadratic Kernel-smoothed close; the stop level is lower band × (1 − stop-loss parameter) when prior direction is bullish, otherwise upper band × (1 + stop-loss parameter); when prior value equals prior upper band, direction is bullish iff close source > stop level, otherwise bearish; otherwise direction is bearish iff close source < stop level, otherwise bullish; the first valid ATR bar is bearish; value is lower band when bullish and upper band when bearish; all Rational Quadratic Kernel calls share lookback, relative-weight, and start-offset parameters.
Calculation: ML SuperTrend = original SuperTrend value when machine-learning averaging is disabled; otherwise, for simple averaging, the mean of values over the ML lookback, optionally keeping only values whose historical final direction matches the current original SuperTrend direction; for KNN averaging, calculate fast and slow SMA, EMA, or VWMA of the SuperTrend values using separate shorter and longer lookbacks, then distances as slow minus fast over the ML lookback, optionally retaining only matching-direction distances; take the minimum and maximum of the first k retained distances, retain distances within the configured minimum and/or maximum bounds, and average the corresponding fast/slow midpoints; for KNN exponential averaging, use the first retained midpoint, or zero if none; an empty arithmetic mean is undefined.
Calculation: ML stop level = ML SuperTrend − ML SuperTrend × stop-loss parameter when original SuperTrend direction is bullish, otherwise ML SuperTrend + ML SuperTrend × stop-loss parameter
Calculation: ML trend direction = bullish when close > ML stop level, otherwise bearish
Long: ML trend direction changes from bearish to bullish
Short: ML trend direction changes from bullish to bearish
Exit: long, take-profit parameter != 0 AND ML trend direction = bullish AND close > ML SuperTrend + ML SuperTrend × take-profit parameter
Exit: short, take-profit parameter != 0 AND ML trend direction = bearish AND close < ML SuperTrend − ML SuperTrend × take-profit parameter
Exit: long, same-bar entry and exit enabled AND stop-loss parameter != 0 AND ML trend direction[1] = bullish AND close < ML stop level[1]
Exit: short, same-bar entry and exit enabled AND stop-loss parameter != 0 AND ML trend direction[1] = bearish AND close > ML stop level[1]
