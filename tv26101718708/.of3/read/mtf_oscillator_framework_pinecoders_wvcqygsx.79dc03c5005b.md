Calculation: Oscillator source = configured alternate source, or sign(close - open) × True Range when the alternate source is close
Calculation: Chart average = selected SMA, EMA, WMA, VWMA, ALMA, linear regression, or HMA of Oscillator source with its lookback, evaluated on chart bars; ALMA and linear regression use their configured offset parameters, and ALMA uses its configured sigma parameter; on real-time bars with chart repainting disabled, use the prior chart bar's value
Calculation: T1 source = Oscillator source evaluated on T1 bars and mapped to chart bars using either the still-forming or last completed T1 bar, according to the higher-timeframe repaint setting
Calculation: T2 source = Oscillator source evaluated on T2 bars and mapped to chart bars using either the still-forming or last completed T2 bar, according to the higher-timeframe repaint setting
Calculation: Weighted aggregate = weighted mean of Chart average, T1 source, and T2 source, using separate weights and omitting missing T1 or T2 values and their weights
Calculation: Selected oscillator line = selected Weighted aggregate, Chart average, T1 source, or T2 source
Calculation: Saved divergence level = the latest Selected oscillator line value from a bar where sign(close - open) differs from sign(change(Selected oscillator line))
Long: At least one main-line coloring condition is enabled, every enabled condition agrees: Selected oscillator line > centerline; Selected oscillator line > highest(Selected oscillator line, channel lookback)[1]; Selected oscillator line > Saved divergence level; Selected oscillator line > T1 source; Selected oscillator line > T2 source; Chart average > T1 source; Chart average > T2 source; T1 source > centerline; or T2 source > centerline; and the configured volatility filter passes: unrestricted, ATR(short volatility lookback) > ATR(long volatility lookback), or ATR(short volatility lookback) <= ATR(long volatility lookback)
