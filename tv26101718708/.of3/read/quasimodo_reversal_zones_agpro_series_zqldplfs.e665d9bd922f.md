Calculation: Normalized ATR = if ATR(ATR lookback) is unavailable, max(high − low, minimum price increment); otherwise max(ATR(ATR lookback), minimum price increment)
Calculation: Head extension = bullish: P1 low − P3 low; bearish: P3 high − P1 high
Calculation: Sequence-break displacement = bullish: P4 high − P2 high; bearish: P2 low − P4 low
Calculation: Relative volume = volume with missing values replaced by zero / SMA(volume with missing values replaced by zero, relative-volume lookback) when the average is positive, otherwise 1
Calculation: Normalized score(value, target) = if target <= 0 then 0, otherwise clamp(value / target, 0, 1)
Calculation: QM score = clamp(round(major-component weight × normalized score(head extension, normalized ATR × minimum head-extension ATR multiple × score normalization multiplier) + major-component weight × normalized score(sequence-break displacement, normalized ATR × minimum sequence-break ATR multiple × score normalization multiplier) + minor-component weight × normalized score(minimum of the three pivot gaps in bars, minimum pivot spacing × score normalization multiplier) + minor-component weight × normalized score(mean absolute price change between adjacent pivots, normalized ATR × swing-range target ATR multiple) + quality-component weight × (1 − clamp(abs(first pivot gap − second pivot gap) / max(1, mean of the three pivot gaps), 0, 1)) + (relative-volume scoring enabled ? quality-component weight × normalized score(relative volume, relative-volume target) : quality-component weight), 0, maximum score)
