Calculation: Latest pivot high = most recent PivotHigh(high, pivot lookback on both sides, T1 bars using the current T1 series via lookahead on), with its center-bar datetime; replace it on each new pivot report and clear it after a chart bar whose high exceeds its price.
Calculation: Latest pivot low = most recent PivotLow(low, pivot lookback on both sides, T1 bars using the current T1 series via lookahead on), with its center-bar datetime; replace it on each new pivot report and clear it after a chart bar whose low falls below its price.
Calculation: Latest structure-line endpoint = on an upward break, chart-bar datetime if the structure state was bullish before the break, otherwise the datetime of the last completed T1 bar; on a downward break, the datetime of the last completed T1 bar if the structure state was bullish before the break, otherwise chart-bar datetime.
Calculation: Active high pivot = on each new pivot-high report, set to that pivot if empty; clear on an upward break; set to the latest valid pivot high if available on a downward break; while bearish after a structure line exists, replace it when the active level and current and prior-chart-bar latest valid pivot highs exist, their prices differ, and the current pivot's center-bar datetime is no later than the latest structure-line endpoint.
Calculation: Active low pivot = on each new pivot-low report, set to that pivot if empty; clear on a downward break; set to the latest valid pivot low if available on an upward break; while bullish after a structure line exists, replace it when the active level and current and prior-chart-bar latest valid pivot lows exist, their prices differ, and the current pivot's center-bar datetime is no later than the latest structure-line endpoint.
Calculation: Structure state = initially bearish; on each chart bar test the upward break first and set the state bullish if it occurs, then test the downward break and set the state bearish if it occurs.
Long: Active high pivot exists AND (structure state is bullish ? chart-bar high : close of the last completed T1 bar) > active high pivot price.
Short: Active low pivot exists AND (structure state is bullish ? close of the last completed T1 bar : chart-bar low) < active low pivot price.
Calculation: Latest bullish continuation-break level = active high pivot price at the latest upward break that occurred while the structure state was already bullish.
Calculation: Latest bullish reversal-break level = active high pivot price at the latest upward break that occurred while the structure state was bearish.
Calculation: Latest bearish continuation-break level = active low pivot price at the latest downward break that occurred while the structure state was bearish.
Calculation: Latest bearish reversal-break level = active low pivot price at the latest downward break that occurred while the structure state was bullish.
Calculation: Selected bullish break level = latest bullish continuation-break level when the selected break class is continuation, otherwise latest bullish reversal-break level.
Calculation: Selected bearish break level = latest bearish continuation-break level when the selected break class is continuation, otherwise latest bearish reversal-break level.
Calculation: Trend state = initially neutral; set to long after a long entry signal and short after a short entry signal; reset to neutral whenever close > SMA(low, moving-average lookback) AND close < SMA(high, same moving-average lookback).
Long: close crosses above selected bullish break level AND close > SMA(high, moving-average lookback) AND close > SMA(low, same moving-average lookback) AND trend state is not long.
Short: close crosses below selected bearish break level AND close < SMA(high, moving-average lookback) AND close < SMA(low, same moving-average lookback) AND trend state is not short.
