Calculation: smoothed RSI = EMA(RSI(source field, RSI lookback), RSI smoothing lookback)
Calculation: adaptive upper level = SMA(smoothed RSI, band lookback) + band multiplier × standard deviation(smoothed RSI, band lookback)
Calculation: adaptive lower level = SMA(smoothed RSI, band lookback) − band multiplier × standard deviation(smoothed RSI, band lookback)
Calculation: T1 EMA = EMA(close, trend lookback) on T1 bars, sampled on chart bars with lookahead off; use T1 close sampled the same way (last completed T1 bar on historical chart bars; current forming T1 bar in real time)
Long: (adaptive bands selected AND smoothed RSI[confirmation count] <= adaptive lower level[confirmation count] AND smoothed RSI > adaptive lower level on each of the confirmation count consecutive closed chart bars ending now OR fixed bands selected AND smoothed RSI[confirmation count] <= fixed oversold level AND smoothed RSI > fixed oversold level on each of the confirmation count consecutive closed chart bars ending now) AND (trend filter disabled OR T1 close > T1 EMA)
Short: (adaptive bands selected AND smoothed RSI[confirmation count] >= adaptive upper level[confirmation count] AND smoothed RSI < adaptive upper level on each of the confirmation count consecutive closed chart bars ending now OR fixed bands selected AND smoothed RSI[confirmation count] >= fixed overbought level AND smoothed RSI < fixed overbought level on each of the confirmation count consecutive closed chart bars ending now) AND (trend filter disabled OR T1 close < T1 EMA)
