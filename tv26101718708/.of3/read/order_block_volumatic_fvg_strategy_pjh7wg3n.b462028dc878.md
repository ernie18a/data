Calculation: gap-size percentage = if close[1] > open[1] then (low - high[2]) / low * 100, else (low[2] - high) / high * 100
Calculation: FVG size score = gap-size percentage / highest(gap-size percentage, lookback) * 100, using chart bars
Calculation: active intersected FVG = a detected gap not invalidated by its mitigation source crossing below a bullish gap's bottom or above a bearish gap's top, not pruned because another live gap's top lies strictly inside its bounds, and intersected by the current chart bar (high >= bottom AND low <= top); the mitigation source is close or, when high/low is selected, low for bullish gaps and high for bearish gaps
Calculation: gap mitigation percentage = for bullish gaps, clamp((top - source) / max(positive floor, top - bottom) * 100, 0, 100); for bearish gaps, clamp((source - bottom) / max(positive floor, top - bottom) * 100, 0, 100), using the configured mitigation source
Calculation: per-gap total volume and shares = sum volume from lower-timeframe T1 bars with close > prior T1 close and sum volume from T1 bars with close < prior T1 close, taking those sums from the previous completed chart bar and using current still-forming chart-bar sums if previous sums are unavailable; total volume is the sum of those directional volumes; if that sum is zero, use previous chart-bar volume (or current volume if unavailable) and set bullish share to 100 * clamp((close[1] - low[1]) / max(positive floor, high[1] - low[1]), 0, 1), or 50 if total volume remains zero; bearish share is 100 minus bullish share, and each share is rounded to the nearest integer when stored
Long: while flat and at least the cooldown parameter in chart bars after the prior entry, enter long if bullish-gap detection is enabled and the most recently created qualifying active intersected bullish FVG differs from the last traded long FVG; the gap forms when high[2] < low AND high[2] < high[1] AND low[2] < low AND FVG size score > the size threshold; gap mitigation percentage >= the long mitigation threshold; if candle confirmation is enabled, close > open; if the volume filter is enabled, per-gap total volume >= the long minimum and <= the long maximum when its upper cap is enabled; if the age filter is enabled, chart bars since gap creation >= the long minimum age; if the share filter is enabled, rounded bullish share >= the long minimum and rounded bearish share <= the long maximum
Short: while flat and at least the cooldown parameter in chart bars after the prior entry, enter short if bearish-gap detection is enabled and the most recently created qualifying active intersected bearish FVG differs from the last traded short FVG; the gap forms when low[2] > high AND low[2] > low[1] AND high[2] > high AND FVG size score > the size threshold; gap mitigation percentage >= the short mitigation threshold; if candle confirmation is enabled, close < open; if the volume filter is enabled, per-gap total volume >= the short minimum and <= the short maximum when its upper cap is enabled; if the age filter is enabled, chart bars since gap creation >= the short minimum age; if the share filter is enabled, rounded bearish share >= the short minimum and rounded bullish share <= the short maximum
Exit: long, low <= entry price * (1 - stop-loss parameter / 100) OR, after high reaches entry price * (1 + trailing-trigger parameter / 100), low <= highest high since activation - entry price * trailing-distance parameter / 100
Exit: short, high >= entry price * (1 + stop-loss parameter / 100) OR, after low reaches entry price * (1 - trailing-trigger parameter / 100), high >= lowest low since activation + entry price * trailing-distance parameter / 100
