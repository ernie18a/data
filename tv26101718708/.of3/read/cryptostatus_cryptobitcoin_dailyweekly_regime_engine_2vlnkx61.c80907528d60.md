Calculation: RibbonTrend(source, fast-outer lookback, fast-inner lookback, slow-inner lookback, slow-outer lookback, neutral-gap threshold) = 0 if tangled or abs(spread) < neutral-gap threshold; otherwise -1 if fast-outer SMMA(source) < slow-outer SMMA(source), else 1; spread = 0 if slow-outer SMMA = 0, else (fast-outer SMMA - slow-outer SMMA) / slow-outer SMMA * percentage scale; tangled when (fast-outer SMMA < fast-inner SMMA) differs from (fast-outer SMMA < slow-outer SMMA), or (slow-inner SMMA < slow-outer SMMA) differs from (fast-outer SMMA < slow-outer SMMA)
Calculation: BufferedRegime(raw regime, confirmation-bar count) = adopts a different raw regime after the same value occurs for the required number of consecutive chart bars; adopts the raw regime immediately when the confirmation-bar count is zero
Calculation: OscillatorPivotDivergence(high, low, oscillator, left pivot strength, right pivot strength, maximum pivot separation) = bearish when the latest confirmed pivot high is above the preceding confirmed pivot high and the oscillator at the latest pivot is below its value at the preceding pivot; bullish when the latest confirmed pivot low is below the preceding confirmed pivot low and the oscillator at the latest pivot is above its value at the preceding pivot; compare consecutive pivots of the same kind only when their separation is within the maximum
Calculation: ADXPivotExhaustion(high, low, ADX, left pivot strength, right pivot strength, maximum pivot separation) = bearish when the latest confirmed pivot high is above the preceding confirmed pivot high and ADX at the latest pivot is below ADX on the immediately preceding bar; bullish when the latest confirmed pivot low is below the preceding confirmed pivot low and ADX at the latest pivot is below ADX on the immediately preceding bar; compare consecutive pivots of the same kind only when their separation is within the maximum
Calculation: DivergenceConfluence(RSI, ADX, open-interest signals, chart-bar window, minimum signal kinds) = for either direction, at least the minimum number of signal kinds of that direction occurred within the window and at least one occurs on the current chart bar
Calculation: MarketScore(regime, RSI, MFI, OBV, ADX, separate regime/RSI/MFI/OBV weights, separate RSI and MFI lookbacks, OBV slope lag, OBV volatility lookback, oscillator center and scale, unit-range bounds, OBV normalization divisor, ADX conviction base/cap/divisor, score midpoint/scale/floor/ceiling) = clip(score midpoint + weighted mean(regime, clip((RSI - oscillator center) / oscillator scale), clip((MFI - oscillator center) / oscillator scale), OBV component) * score scale * (ADX conviction base + min(ADX conviction cap, ADX / ADX conviction divisor)), score floor, score ceiling); OBV component is zero when the rolling standard deviation of OBV minus its lagged value is zero, otherwise clip((OBV - OBV[OBV slope lag]) / (OBV normalization divisor * stdev(OBV - OBV[OBV slope lag], OBV volatility lookback))); weighted mean divides by the sum of weights, or by one when that sum is zero
