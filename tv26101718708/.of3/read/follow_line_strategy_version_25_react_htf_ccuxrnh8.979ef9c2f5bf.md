Calculation: FollowLineTrend(T, band lookback B, band deviation D, ATR lookback A) = on T bars, form bands as SMA(close, B) ± stdev(close, B) × D; signal is +1 when close is above the upper band, −1 when below the lower band, otherwise 0; candidate line is low − ATR(A) for +1 or high + ATR(A) for −1 when ATR offset is enabled, otherwise low or high (on T1 bars, use raw low or high when ATR is unavailable); set the line to max(candidate, prior line) for +1, min(candidate, prior line) for −1, otherwise carry the prior line; trend is +1 when the line rises, −1 when it falls, otherwise the prior trend, initialized from the signal; an invalid line gives trend 0. Use the same B, D, A, and ATR-offset setting on chart bars and T1 bars; calculate T1 on T1 bars and sample its latest available value on chart bars with lookahead off (completed T1 bars historically, forming T1 bar in real time).
Long: FollowLineTrend(chart bars)[1] ≤ 0 AND FollowLineTrend(chart bars) = +1 AND ATR(A) is valid
Short: FollowLineTrend(chart bars)[1] ≥ 0 AND FollowLineTrend(chart bars) = −1 AND ATR(A) is valid
Long: FollowLineTrend(chart bars)[1] ≤ 0 AND FollowLineTrend(chart bars) = +1 AND position is flat or short AND inside the configured session if the session filter is enabled AND (HTF confirmation is disabled OR latest available FollowLineTrend(T1) = +1)
Short: FollowLineTrend(chart bars)[1] ≥ 0 AND FollowLineTrend(chart bars) = −1 AND position is flat or long AND inside the configured session if the session filter is enabled AND (HTF confirmation is disabled OR latest available FollowLineTrend(T1) = −1)
Exit: Long, FollowLineTrend(chart bars) = −1 OR active latest available FollowLineTrend(T1) = −1 (T1 is active when HTF confirmation or HTF line display is enabled)
Exit: Short, FollowLineTrend(chart bars) = +1 OR active latest available FollowLineTrend(T1) = +1 (T1 is active when HTF confirmation or HTF line display is enabled)
