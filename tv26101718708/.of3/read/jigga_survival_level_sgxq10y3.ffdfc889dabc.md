Calculation: majority score = MACD vote + MACD histogram vote + smoothed RSI vote + EMA crossover vote + ADX-filtered price vote + smoothed Williams %R vote + Chaikin Money Flow vote + Supertrend direction. MACD vote is +1 when MACD line > 0 and above its signal line, -1 when MACD line <= 0 and <= its signal line, else 0; its fast lookback is shorter than its slow lookback, with a separate signal lookback. MACD histogram vote is +1 when histogram >= 0 and > histogram[1], -1 when histogram < 0 and <= histogram[1], else 0. Smoothed RSI vote is +1 when EMA(RSI(close, shared RSI/ADX lookback), separate RSI smoothing) > the shared upper cutoff, -1 when < the shared lower cutoff, else 0. EMA crossover vote is +1 when EMA(close, shorter crossover lookback) > EMA(close, longer crossover lookback), else -1. ADX-filtered price vote is 0 unless ADX(high, low, close, shared RSI/ADX lookback, same lookback) > EMA(ADX, separate ADX comparison smoothing); then it is +1 when close > EMA(close, separate price smoothing), else -1. Smoothed Williams %R vote is +1 when EMA(Williams %R(high, low, close, shared Williams %R/CMF lookback), separate %R smoothing) > the negative shared lower cutoff, -1 when < the negative shared upper cutoff, else 0. RSI and Williams %R share their upper and lower cutoff parameters. Chaikin Money Flow vote is +1 when CMF(high, low, close, volume, same Williams %R/CMF lookback) > a threshold, -1 when < the negative threshold, else 0. Supertrend direction is +1 in an uptrend and -1 in a downtrend, using separate ATR lookback and multiplier parameters.
Calculation: adjusted majority score = 0 when the majority score and its prior value are on opposite sides of zero or either is zero; otherwise the majority score.
Calculation: signal level and state = initialize to zero and bullish; when adjusted majority score[1] < 0 and the current adjusted majority score >= 0, set the level to high times an upper-level factor and the state to bullish; when adjusted majority score[1] > 0 and the current adjusted majority score <= 0, set the level to low times a lower-level factor and the state to bearish; otherwise retain the prior level and state.
Long: (high > signal level AND signal state is bullish) OR (adjusted majority score[1] > 0 AND adjusted majority score > 0)
Exit: long, (low < signal level AND signal state is bearish) OR (adjusted majority score[1] < 0 AND adjusted majority score < 0)
