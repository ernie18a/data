Calculation: Stop price = for a long, if the stop-source parameter selects wick then min(low, low[1]) else open; for a short, if it selects wick then max(high, high[1]) else open, using the signal bar
Calculation: Risk distance = abs(planned entry price (signal-bar close) - stop price)
Calculation: T2 equity change = current strategy equity - strategy equity recorded at the start of the current T2 period
Long: On chart bars, close(T1, still-forming bar, projected onto chart bars with lookahead on) crosses above the latest PivotHigh(high, pivot lookback, pivot lookback), calculated on T1 bars and projected onto chart bars with lookahead on; set bullish BOS bias until a bearish BOS
Short: On chart bars, close(T1, still-forming bar, projected onto chart bars with lookahead on) crosses below the latest PivotLow(low, pivot lookback, pivot lookback), calculated on T1 bars and projected onto chart bars with lookahead on; set bearish BOS bias until a bullish BOS
Long: Flat position AND chart bars since the most recent exit >= cooldown parameter AND T2 equity change < daily profit limit AND T2 equity change > -daily loss limit AND consecutive losing exits since the start of the current T2 period < loss-streak limit (an exit is losing when its exit-bar close <= planned entry price for a long or >= planned entry price for a short) AND (session filter disabled OR current chart-bar time is within the session-window parameter) AND (BOS filter disabled OR latest BOS bias is bullish) AND open[1] > close[1] AND close > open AND close > max(open[1], close[1]) AND risk distance × point value > 0 AND cash-risk parameter >= risk distance × point value
Short: Flat position AND chart bars since the most recent exit >= cooldown parameter AND T2 equity change < daily profit limit AND T2 equity change > -daily loss limit AND consecutive losing exits since the start of the current T2 period < loss-streak limit (an exit is losing when its exit-bar close <= planned entry price for a long or >= planned entry price for a short) AND (session filter disabled OR current chart-bar time is within the session-window parameter) AND (BOS filter disabled OR latest BOS bias is bearish) AND close[1] > open[1] AND close < open AND close < min(open[1], close[1]) AND risk distance × point value > 0 AND cash-risk parameter >= risk distance × point value
Exit: Long, low <= stop price OR high >= planned entry price + risk distance × reward/risk parameter
Exit: Short, high >= stop price OR low <= planned entry price - risk distance × reward/risk parameter
