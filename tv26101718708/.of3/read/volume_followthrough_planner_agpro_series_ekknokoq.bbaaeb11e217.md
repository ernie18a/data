Calculation: Safe ATR = max(ATR(ATR lookback) when available, otherwise true range, minimum tick size)
Calculation: Relative volume = volume / SMA(volume, volume lookback) when the baseline is available and positive; otherwise the fallback relative-volume value
Calculation: Body share = abs(close - open) / event range
Calculation: Close location = (close - low) / event range
Calculation: Bull close edge = close location
Calculation: Bear close edge = 1 - close location
Calculation: Spread ATR = event range / safe ATR
Calculation: Trend slope = EMA(close, slow EMA lookback) - EMA(close, slow EMA lookback)[slope lookback bars ago], using zero change when the prior EMA is unavailable
Calculation: Qualified volume threshold = minimum volume multiple * sensitivity-selected volume multiplier
Calculation: Qualified spread threshold = minimum spread ATR * the same sensitivity-selected multiplier
Calculation: Qualified close threshold = clamp(minimum close edge + sensitivity-selected close shift, close-edge lower bound, close-edge upper bound)
Calculation: Qualified body threshold = clamp(minimum body share + sensitivity-selected body shift, body lower bound, body upper bound)
Calculation: High-good score(x, weak, strong) = zero if strong equals weak; otherwise clamp((x - weak) / (strong - weak) * score ceiling, score floor, score ceiling)

Calculation: Trend score(side) = clamp(side-aligned price points relative to the slow EMA, otherwise side-misaligned price points, plus side-aligned fast/slow EMA stack points (fast EMA has the shorter lookback), plus slope weight * high-good score(abs(trend slope) / safe ATR, slope weak threshold, slope strong threshold) when trend slope has the side's sign, otherwise zero, from zero to score ceiling
Calculation: Event score(side) = clamp(volume weight * peak score(relative volume, qualified volume * volume weak factor, max(ideal volume multiple, qualified volume + volume ideal gap), max(climax ceiling multiple, ideal volume multiple + volume ceiling gap)) + spread weight * high-good score(spread ATR, qualified spread * spread weak factor, qualified spread + spread strong span) + close-edge weight * high-good score(the side's close edge, qualified close * close-edge weak factor, close-edge strong point) + body weight * high-good score(body share, qualified body * body weak factor, body strong point) + trend weight * trend score(side), from zero to score ceiling)
Calculation: Risk rail for a bullish event = event-bar low - event-bar safe ATR * risk buffer ATR; for a bearish event = event-bar high + event-bar safe ATR * risk buffer ATR
Calculation: Best favorable progress ATR = the greatest favorable movement from event close, divided by event-bar safe ATR, using highs for bullish events and lows for bearish events, floored at zero
Calculation: Worst adverse movement ATR = the greatest adverse movement from event close, divided by event-bar safe ATR, using lows for bullish events and highs for bearish events, floored at zero
Calculation: Follow-through closes = count of confirmed subsequent chart bars within the follow-through window that close above the event close for bullish events or below it for bearish events
Calculation: First-bar score = clamp(first subsequent bar's close progress from event close, in the event direction and divided by event-bar safe ATR, divided by max(required progress ATR * first-bar progress factor, minimum first-bar denominator), then multiplied by score ceiling, from score floor to score ceiling); capture it on that bar
Calculation: Progress score = high-good score(best favorable progress ATR, required progress ATR * progress weak factor, required progress ATR * progress strong factor)
Calculation: Close-count score = high-good score(follow-through closes, zero, minimum follow-through closes + close-count headroom)
Calculation: Defense score = zero if the risk rail is broken; otherwise low-good score(worst adverse movement ATR, adverse good threshold, adverse limit ATR)
Calculation: Time score = low-good score(bars since event, follow-through window * early-time factor, follow-through window + time allowance) within the follow-through window; otherwise low-good score(bars since event, follow-through window, tracking bars)
Calculation: Follow-through score = clamp(event score * event contribution weight + progress score * progress contribution weight + first-bar score * first-bar contribution weight + close-count score * close-count contribution weight + defense score * defense contribution weight + time score * time contribution weight, from score floor to score ceiling)
Calculation: One-bar condition = the event is not rail-broken or target-touched, bars since event >= follow-through window, follow-through score < minimum planner score, and progress score < one-bar progress threshold
