Calculation: Div(X, side, kind) = smallest D with MinPivotDistance < D <= MaxBars among the MaxPivots most recent pivots of side confirmed by the current bar for which the test holds, else 0; 0 if kind is not selected by DivergenceType or the gate fails; s = 0 if NoConfirmation else 1; P = close if PivotSource is Close, else low for bull and high for bear; pivots of side = PivotLow(P, PivotPeriod, PivotPeriod) for bull and PivotHigh(P, PivotPeriod, PivotPeriod) for bear; gate = NoConfirmation OR X > X[1] OR close > close[1] for bull, NoConfirmation OR X < X[1] OR close < close[1] for bear; test for side and kind: bull regular X[s] > X[D] AND P[s] < P[D]; bull hidden X[s] < X[D] AND P[s] > P[D]; bear regular X[s] < X[D] AND P[s] > P[D]; bear hidden X[s] > X[D] AND P[s] < P[D]; AND every k with s < k < D satisfies bull: X[k] >= lineX(k) AND close[k] >= lineC(k), bear: X[k] <= lineX(k) AND close[k] <= lineC(k), where lineX is the straight line through (s, X[s]) and (D, X[D]) and lineC is the straight line through (s, close[s]) and (D, close[D])
Calculation: Hits(side, kind) = number of series X with Div(X, side, kind) > 0, over the series whose indicator is enabled among: ExternalSeries; MACD(close, MacdFast, MacdSlow, MacdSignal) with MacdSlow longer than MacdFast; MACD histogram(close, MacdFast, MacdSlow, MacdSignal); RSI(close, RsiLength); SMA(Stochastic(close, high, low, StochLength), StochSmoothing); CCI(close, CciLength); MOM(close, MomLength); OBV(close, volume); VWMA(close, volume, VwmaFast) - VWMA(close, volume, VwmaSlow) with VwmaSlow longer than VwmaFast; CMF(close, high, low, volume, CmfLength); MFI(close, volume, MfiLength)
Calculation: Distinct(side, kind) = number of distinct values greater than 0 of Div(X, side, kind) over the same series as Hits
Calculation: TotalHits = Hits(bull, regular) + Hits(bull, hidden) + Hits(bear, regular) + Hits(bear, hidden)
Calculation: BullPass = if MultipleHiddenFilter is on: Distinct(bull, hidden) >= 2; else if MultipleRegularFilter is on: Distinct(bull, regular) >= 2; else if ConfluenceFilter is on: Hits(bull, regular) > 0 AND Hits(bull, hidden) > 0; else true
Calculation: BearPass = if MultipleHiddenFilter is on: Distinct(bear, hidden) >= 2; else if MultipleRegularFilter is on: Distinct(bear, regular) >= 2; else if ConfluenceFilter is on: Hits(bear, regular) > 0 AND Hits(bear, hidden) > 0; else true
Long: Hits(bull, regular) > 0 AND BullPass AND TotalHits >= MinDivergenceCount
Long: Hits(bull, hidden) > 0 AND BullPass AND TotalHits >= MinDivergenceCount
Short: Hits(bear, regular) > 0 AND BearPass AND TotalHits >= MinDivergenceCount
Short: Hits(bear, hidden) > 0 AND BearPass AND TotalHits >= MinDivergenceCount
