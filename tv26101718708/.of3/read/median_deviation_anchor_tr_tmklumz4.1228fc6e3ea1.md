Calculation: Median anchor = nearest-rank percentile(selected moving average(selected bar field, moving-average type, moving-average lookback, factor, sigma), median lookback, percentile parameter)
Calculation: Deviation oscillator = clamp(EMA(raw deviation, smoothing lookback), -clamp limit, clamp limit), where ATR band = ATR multiplier × ATR(high, low, close, ATR lookback), deviation zone = standard deviation(median anchor, deviation lookback), raw deviation = (selected bar field - median anchor) / (median anchor - (median anchor - ATR band)) × percentage scale if selected bar field > median anchor - ATR band AND selected bar field >= median anchor + deviation zone; otherwise (selected bar field - median anchor) / ((median anchor + ATR band) - median anchor) × percentage scale if selected bar field < median anchor + ATR band AND selected bar field <= median anchor - deviation zone; otherwise 0
Calculation: Trend regime = -1 if deviation oscillator < short threshold, otherwise 1 if deviation oscillator > long threshold, otherwise previous trend regime (initially neutral)
Long: trend regime = 1 OR deviation oscillator > long threshold OR deviation oscillator crosses above 0
Short: trend regime = -1 OR deviation oscillator < short threshold OR deviation oscillator crosses below 0
