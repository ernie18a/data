Calculation: Active session = chart-bar time-of-day >= session-start hour:minute and < session-end hour:minute.
Calculation: ORB high/low = highest high/lowest low from the first active-session bar through the ORB-duration parameter; ORB is complete when elapsed time from that first bar reaches the ORB duration.
Calculation: Long acceptance = ORB complete AND lowest(close, acceptance lookback) > ORB high; short acceptance = ORB complete AND highest(close, acceptance lookback) < ORB low.
Calculation: Volume average = SMA(volume, session-duration lookback); volume standard deviation = stdev(volume, session-duration lookback), or zero if unavailable; RVOL = volume / volume average when the average is positive, otherwise zero; moderate volume threshold = volume average * moderate-volume multiplier; strong volume threshold = volume average + volume-standard-deviation multiplier * volume standard deviation.
Calculation: Latest ORB test volume for each side = the most recent chart-bar volume in the retest zone around that side's ORB level, where distance from close to the level divided by the level <= retest-zone percentage / 100; reset at session start.
Calculation: ORB test-volume score = strong-test-volume weight if latest ORB test volume >= strong volume threshold, else moderate-test-volume weight if it >= moderate volume threshold, else zero.
Calculation: ATR eligible = not na(ATR(ATR lookback, T2, bar still forming; chart bars take values from T2)) AND abs(close - first active-session open) / ATR * 100 < maximum-used-ATR percentage.
Calculation: Static bullish context = close > high(T2, last completed bar; chart bars take values from T2); static bearish context = close < low(T2, last completed bar; chart bars take values from T2); neutral context = neither.
Calculation: Session VWAP = cumulative sum(typical price * volume) / cumulative volume during the active session; prior-session VWAP = the final session VWAP from the preceding session, saved at the next session start.
Calculation: Session POC = center of the equal-width bin with greatest cumulative volume among a parameterized number of bins spanning a reference range; reference range = (prior completed T2 high - prior completed T2 low) * POC range multiplier when both are available, otherwise ATR(T2, bar still forming) or an ATR fallback parameter, multiplied by the same multiplier; lower bin edge = prior completed T2 low - reference range * lower-edge offset when available, otherwise close - reference range * fallback anchor fraction; each active-session bar adds its volume to the clamped bin containing typical price; ties select the lowest-index bin. Prior-session POC = the preceding session's POC, saved at the next session start.
Calculation: Effective bullish context = static bullish context OR (neutral context AND close is above every available current-session VWAP, current-session POC, and prior-session POC); effective bearish context = static bearish context OR (neutral context AND close is below every available one of those levels); unavailable levels are ignored.
Calculation: Tape ratio when enabled = classify each T1 intrabar pair within the chart bar by comparing the earlier close with the next close, adding the earlier bar's volume to bullish volume if greater, bearish volume if lower, and absorbed volume if equal; when there is no pair, use chart-bar close versus open and chart-bar volume. Ratio = bullish volume / max(bearish volume + absorbed volume, 1) when bullish volume is greater, negative bearish volume / max(bullish volume + absorbed volume, 1) when bearish volume is greater, otherwise zero. T1 intrabars are taken within each chart bar and may include a forming bar. When tape analysis is disabled or there is no pair, ratio = positive fallback tape ratio if chart close > open, negative fallback tape ratio if close < open, otherwise zero. Tape absorption percentage = absorbed volume / total tape volume * 100 when total is positive, otherwise zero.
Calculation: Long ORB score = long-acceptance weight if long acceptance + ORB test-volume score + RVOL weight if RVOL >= minimum RVOL parameter + ATR weight if ATR eligible + static-bull-context weight if static bullish context; short ORB score uses short acceptance, the low-level test volume, and static bearish context.
Calculation: Tape points for either side = strong-tape weight when tape ratio in that direction reaches the strong-tape-ratio parameter, else ordinary-tape weight when it reaches the minimum-tape-ratio parameter, else zero. MACD line = EMA(close, shorter EMA lookback, T1, current bar; chart bars take values from T1) - EMA(close, longer EMA lookback, T1, current bar; chart bars take values from T1), using close for a missing EMA; RSI = RSI(close, RSI lookback, T1, current bar; chart bars take values from T1), using its fallback parameter if unavailable. Long BQ score = long tape points + BQ confirmation weight for MACD line > zero + BQ confirmation weight for RSI >= overbought parameter + BQ confirmation weight when latest high-level test volume >= strong volume threshold + BQ confirmation weight when close > both prior-session POC and prior-session VWAP, ignoring unavailable references. Short BQ score uses negative tape ratio, MACD line < zero, RSI <= oversold parameter, latest low-level test volume, and close below both references.
Calculation: Tight balance = highest(high, balance lookback) and lowest(low, balance lookback) over completed chart bars before the current bar define balance high/low; their positive range must be <= close * balance maximum percentage / 100.
Long: On the first qualifying bar in each uninterrupted long-acceptance episode, emit A+ when active session AND static bullish context AND long ORB score = A+ ORB target parameter AND long BQ score >= A+ BQ minimum parameter AND long tape points > zero AND NOT (prior-session POC > close AND (prior-session POC - close) / close < prior-POC proximity fraction parameter); rearm when long acceptance becomes false and reset at session start.
Short: On the first qualifying bar in each uninterrupted short-acceptance episode, emit A+ when active session AND static bearish context AND short ORB score = A+ ORB target parameter AND short BQ score >= A+ BQ minimum parameter AND short tape points > zero AND NOT (prior-session POC < close AND (close - prior-session POC) / close < prior-POC proximity fraction parameter); rearm when short acceptance becomes false and reset at session start.
Long: On the first bar this condition becomes true, enter RET when active session AND long acceptance AND close >= ORB high AND (close - ORB high) / ORB high <= retest-zone percentage / 100 AND (volume >= strong volume threshold OR tape absorption percentage >= defended-absorption percentage parameter) AND RVOL >= minimum RVOL parameter AND ATR eligible AND NOT static bearish context AND long BQ score >= shared RET/balance BQ minimum parameter AND (long ORB score - static-bull-context weight) >= retest net-ORB minimum parameter AND effective bullish context AND (long tape points > zero OR tape absorption percentage >= defended-absorption percentage parameter).
Short: On the first bar this condition becomes true, enter RET when active session AND short acceptance AND close <= ORB low AND (ORB low - close) / ORB low <= retest-zone percentage / 100 AND (volume >= strong volume threshold OR tape absorption percentage >= defended-absorption percentage parameter) AND RVOL >= minimum RVOL parameter AND ATR eligible AND NOT static bullish context AND short BQ score >= shared RET/balance BQ minimum parameter AND (short ORB score - static-bearish-context weight) >= retest net-ORB minimum parameter AND effective bearish context AND (short tape points > zero OR tape absorption percentage >= defended-absorption percentage parameter).
Long: On the first bar this condition becomes true, enter INV when active session AND short acceptance AND tight balance AND close > balance high AND volume >= strong volume threshold AND RVOL >= minimum RVOL parameter AND ATR eligible AND NOT static bearish context AND long BQ score >= shared RET/balance BQ minimum parameter AND effective bullish context.
Short: On the first bar this condition becomes true, enter INV when active session AND long acceptance AND tight balance AND close < balance low AND volume >= strong volume threshold AND RVOL >= minimum RVOL parameter AND ATR eligible AND NOT static bullish context AND short BQ score >= shared RET/balance BQ minimum parameter AND effective bearish context.
Long: On the first bar this condition becomes true, enter CNT when active session AND long acceptance AND tight balance AND close > balance high AND volume >= strong volume threshold AND RVOL >= minimum RVOL parameter AND ATR eligible AND NOT static bearish context AND long BQ score >= shared RET/balance BQ minimum parameter AND effective bullish context.
Short: On the first bar this condition becomes true, enter CNT when active session AND short acceptance AND tight balance AND close < balance low AND volume >= strong volume threshold AND RVOL >= minimum RVOL parameter AND ATR eligible AND NOT static bullish context AND short BQ score >= shared RET/balance BQ minimum parameter AND effective bearish context.
