Calculation: Chaikin Fisher = on each chart bar, let c be the Chaikin Oscillator with a shorter fast EMA lookback and a longer slow EMA lookback; let r=(c−lowest(c, normalization lookback))/(highest(c, normalization lookback)−lowest(c, normalization lookback))−0.5, or 0 if the range is 0; let v=clamp(0.66*r+0.67*v[1], −0.999, 0.999); Chaikin Fisher=0.5*ln((1+v)/(1−v))+0.5*Chaikin Fisher[1]; initialize v and Chaikin Fisher to 0
