Calculation: Risk = mean(r1, r2, r3), or the risk fallback parameter if the mean is undefined; r1 = ((close(T1) - SMA(close, T1 long lookback)) / StDev(close, same T1 long lookback)) / (risk-one log-time coefficient * ln(chart-bar timestamp in milliseconds) + risk-one offset), defined only when StDev != 0; r2 = (ln(close(T1) / SMA(close, T2 short lookback)) + risk-two log-time coefficient * ln(chart-bar timestamp in milliseconds) + risk-two offset) / (risk-two timestamp coefficient * chart-bar timestamp in milliseconds + risk-two denominator offset), defined only when SMA != 0; r3 = (SMA(close, T1 short lookback) / SMA(close, T2 long lookback)) / (risk-three log-time coefficient * ln(chart-bar timestamp in milliseconds) + risk-three offset), defined only when SMA != 0. T1 is shorter than T2; calculate indicators on their timeframe bars using the current, unoffset bars (lookahead on), and sample their values on chart bars.
Calculation: Buy amount = L1 amount + L2 amount + L3 amount if Risk <= L3 buy threshold; otherwise L1 amount + L2 amount if Risk <= L2 buy threshold; otherwise L1 amount if Risk <= L1 buy threshold; otherwise zero, using the first matching condition.
Long: Buy amount > 0 AND on each chart bar or the first chart bar of the selected signal timeframe T3.
Exit: long, long position open AND on each chart bar or the first chart bar of the selected signal timeframe T3 AND first partial exit not yet made since the latest increase in long position AND Risk >= L1 sell threshold.
Exit: long, long position open AND on each chart bar or the first chart bar of the selected signal timeframe T3 AND first partial exit made since the latest increase in long position AND second partial exit not yet made since the latest increase in long position AND Risk >= L2 sell threshold.
Exit: long, long position open AND on each chart bar or the first chart bar of the selected signal timeframe T3 AND second partial exit made since the latest increase in long position AND Risk >= L3 sell threshold.
