Calculation: Range-filter state = smooth range is multiplier * EMA(EMA(abs(source - source[1]), sampling period), 2 * sampling period - 1); filtered value is initialized to source and thereafter is max(previous filtered value, source - smooth range) when source > previous filtered value, otherwise min(previous filtered value, source + smooth range); rising count increments when filtered value rises, resets to zero when it falls, and holds when unchanged; falling count increments when it falls, resets to zero when it rises, and holds when unchanged; upper and lower bands are filtered value ± smooth range.
Calculation: Hilbert-adaptive average = recursively alpha * source + (1 - alpha) * previous average, where efficiency = abs(source - source[lookback]) / SUM(abs(source - source[1]), lookback), delta phase = max(previous phase - phase, 1), fast alpha = max(efficiency / delta phase, 0.1 * efficiency), and alpha = (fast alpha * (1 - efficiency / 2))^2. For phase, smooth source as (4 * source + 3 * source[1] + 2 * source[2] + source[3]) / 10; use H(x) = 0.0962*x + 0.5769*x[2] - 0.5769*x[4] - 0.0962*x[6], multiplier = 0.075 * previous period + 0.54, detrender = H(smoothed source) * multiplier, I1 = detrender[3], Q1 = H(detrender) * multiplier, jI = H(I1) * multiplier, and jQ = H(Q1) * multiplier; I2 and Q2 are respectively 0.2*(I1-jQ)+0.8*previous I2 and 0.2*(Q1+jI)+0.8*previous Q2; Re and Im are respectively 0.2*(I2*I2[1]+Q2*Q2[1])+0.8*previous Re and 0.2*(I2*Q2[1]-Q2*I2[1])+0.8*previous Im; period is the 0.2/0.8-smoothed value of 2*pi/atan(Im/Re) when Re and Im are nonzero (otherwise zero), first constrained to 0.67–1.5 times the previous period and then to 6–50; phase is 180/pi*atan(Q1/I1), or zero when I1 is zero.
Calculation: Position reference price = the running mean of each same-side signal bar's close and each qualifying signal-stop price since the latest opposite-side signal or qualified target crossing; update on each such event and retain the latest value between events. A qualifying long signal-stop price is the latest long-signal close * (1 - signal-stop percentage), when low crosses below it after a long signal newer than the latest short signal, with no long signal on that bar, and only on the first such crossing after a long signal; the short case is symmetric using high crossing above latest short-signal close * (1 + signal-stop percentage). A qualified target crossing is high crossing above the position reference price * (1 + target percentage) for long or low crossing below it * (1 - target percentage) for short, with no same-side signal on that bar and a same-side signal newer than the previous target crossing; it resets both running means.
Long: (RSI(VWAP(close), VWAP-RSI lookback) crosses above VWAP-RSI oversold level AND high > range-filter upper band AND rising count > 0 AND NOT (DIMinus(ADX type, ADX lookback) > DIPlus(ADX type, ADX lookback) AND ADX(ADX type, ADX lookback) > ADX threshold)) OR (DIPlus(ADX type, ADX lookback) > DIMinus(ADX type, ADX lookback) AND ADX(ADX type, ADX lookback) > ADX threshold AND volume > SMA(volume, volume lookback) * volume multiplier AND RSI(RSI source, RSI lookback) < long RSI ceiling AND Hilbert-adaptive average(source, cloud lookback) > its previous value) OR (RMI(close, RMI lookback, momentum lookback) crosses above RMI oversold level AND high > range-filter upper band AND rising count > 0 AND NOT (DIMinus(ADX type, ADX lookback) > DIPlus(ADX type, ADX lookback) AND ADX(ADX type, ADX lookback) > ADX threshold)).
Short: (RSI(VWAP(close), VWAP-RSI lookback) crosses below VWAP-RSI overbought level AND low < range-filter lower band AND falling count > 0 AND NOT (DIPlus(ADX type, ADX lookback) > DIMinus(ADX type, ADX lookback) AND ADX(ADX type, ADX lookback) > ADX threshold)) OR (DIPlus(ADX type, ADX lookback) < DIMinus(ADX type, ADX lookback) AND ADX(ADX type, ADX lookback) > ADX threshold AND volume > SMA(volume, volume lookback) * volume multiplier AND RSI(RSI source, RSI lookback) > short RSI floor AND Hilbert-adaptive average(source, cloud lookback) < its previous value) OR (RMI(close, RMI lookback, momentum lookback) crosses below RMI overbought level AND low < range-filter lower band AND falling count > 0 AND NOT (DIPlus(ADX type, ADX lookback) > DIMinus(ADX type, ADX lookback) AND ADX(ADX type, ADX lookback) > ADX threshold)).
Exit: long, low <= position reference price * (1 - protective stop percentage) OR high >= position reference price * (1 + target percentage)
Exit: short, high >= position reference price * (1 + protective stop percentage) OR low <= position reference price * (1 - target percentage)
