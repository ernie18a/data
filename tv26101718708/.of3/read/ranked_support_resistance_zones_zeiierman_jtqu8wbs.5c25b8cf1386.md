Calculation: ResistanceSwing = (PivotHigh(high, pivot length, pivot length) - MAX(high[pivot length - 1], high[pivot length + 1])) / ATR(ATR length)
Calculation: SupportSwing = (MIN(low[pivot length - 1], low[pivot length + 1]) - PivotLow(low, pivot length, pivot length)) / ATR(ATR length)
Calculation: ResistanceZone = envelope of member intervals, each member being PivotHigh(high, pivot length, pivot length) +/- zone width ATR * ATR(ATR length) / 2 for a confirmed pivot high with ResistanceSwing >= min swing ratio; a new member joins the existing ResistanceZone when |zone midpoint - PivotHigh(high, pivot length, pivot length)| <= absorb ATR * ATR(ATR length) OR intersection / min(zone width, member width) >= overlap threshold, otherwise it starts a new ResistanceZone
Calculation: SupportZone = envelope of member intervals, each member being PivotLow(low, pivot length, pivot length) +/- zone width ATR * ATR(ATR length) / 2 for a confirmed pivot low with SupportSwing >= min swing ratio; a new member joins the existing SupportZone when |zone midpoint - PivotLow(low, pivot length, pivot length)| <= absorb ATR * ATR(ATR length) OR intersection / min(zone width, member width) >= overlap threshold, otherwise it starts a new SupportZone
Long: for some ResistanceZone not yet broken and with bars since its first pivot <= expiry bars, Close > ResistanceZone top + break buffer ATR * ATR(ATR length)
Short: for some SupportZone not yet broken and with bars since its first pivot <= expiry bars, Close < SupportZone bottom - break buffer ATR * ATR(ATR length)
