Calculation: Profile control and cloud edges = On each chart bar, build a rolling volume profile from the configured number of chart bars, dividing the full price range into the configured number of rows. Within each chart bar, use available T1 closes and volumes, including any still-forming T1 bar while the chart bar forms, and map each close into the configured number of equal slots across the chart bar range clipped to the candle body plus or minus the configured multiple of ATR with the configured ATR lookback; cap each T1 volume at the configured multiple of the median T1 volume in that chart bar. If T1 data is disabled or unavailable, distribute chart-bar volume across those slots, weighting body slots and other slots by their separate configured weights and normalizing the weights; use unit volume when volume is unavailable. Weight chart bars equally unless age fading is enabled, in which case weight each by (1 - age/profile-window)^fade-exponent. Smooth row volume as center-row weight times its volume plus neighbor-row weight times the sum of adjacent row volumes. The profile control is the densest row, retaining the prior control row when its density is at least the configured fraction of maximum density; its price is the row midpoint and it updates only when raw control differs by at least the configured row-height threshold. The value-area cluster expands from the control row while the average density of the configured outward rows is at least the configured fraction of control density. Grow the value area from the control toward the side with greater summed density in the configured outward rows, adding rows until it contains the configured share of cluster volume. Retain prior upper and lower rows when they fall within the bounds calculated using the configured share hysteresis. Convert these rows to raw price edges, take a median over the configured edge lookback, move each prior edge toward that median by the lesser of the gap and the greater of ATR times configured cloud speed and gap divided by the configured edge-relocation divisor, then EMA-smooth with the configured cloud smoothing lookback. Run on chart bars; when using T1, use its bars inside each chart bar, completed at chart-bar confirmation.
Long: close > profile cloud upper edge
Short: close < profile cloud lower edge

Short: profile control side changes to below after two consecutive chart-bar closes below the control price; on the initial side assignment, the first non-equal close sets the side
