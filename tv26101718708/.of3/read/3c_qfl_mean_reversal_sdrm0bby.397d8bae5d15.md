Calculation: Base low = latest Williams Fractal low on T1 bars whose center-bar volume > SMA(volume, volume-MA lookback) at the center; use the last completed T1 value on chart bars
Calculation: Base high = latest Williams Fractal high on T1 bars whose center-bar volume > SMA(volume, volume-MA lookback) at the center; use the last completed T1 value on chart bars
Calculation: Base age = barssince(Base high != Base high[1]) on chart bars
Calculation: Cumulative safety-order deviation(n) = sum from k=1 to n of safety-order deviation * safety-order step scale^(k-1)
Long: strategy direction is long AND close < Base low * (1 - entry deviation / 100) AND (maximum base age is disabled OR Base age < maximum base age) AND (allow consecutive signals OR NOT (close[1] < Base low[1] * (1 - entry deviation / 100) AND (maximum base age is disabled OR Base age[1] < maximum base age)) OR Base low != Base low[1]) AND enabled date-range, session-time, and weekday filters pass
Short: strategy direction is short AND close > Base high * (1 + entry deviation / 100) AND (maximum base age is disabled OR Base age < maximum base age) AND (allow consecutive signals OR NOT (close[1] > Base high[1] * (1 + entry deviation / 100) AND (maximum base age is disabled OR Base age[1] < maximum base age)) OR Base high != Base high[1]) AND enabled date-range, session-time, and weekday filters pass
Exit: long, (take-profit type is percent from total volume AND high >= position average entry price * (1 + take-profit percent / 100)) OR (stop loss is enabled AND stop-loss percent > Cumulative safety-order deviation(maximum safety orders) AND low <= base-order entry price * (1 - stop-loss percent / 100))
Exit: short, (take-profit type is percent from total volume AND low <= position average entry price * (1 - take-profit percent / 100)) OR (stop loss is enabled AND stop-loss percent > Cumulative safety-order deviation(maximum safety orders) AND high >= base-order entry price * (1 + stop-loss percent / 100))
