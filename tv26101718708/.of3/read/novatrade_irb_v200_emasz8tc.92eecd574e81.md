Calculation: Normalized EMA slope = IF ATR(ATR lookback) > 0 THEN (EMA(close, middle EMA lookback) - EMA(close, middle EMA lookback)[slope lookback]) / ATR(ATR lookback) ELSE 0
Calculation: Overextension ratio = IF ATR(ATR lookback) > 0 THEN (high - low) / ATR(ATR lookback) ELSE 0
Calculation: Long stop = maximum of the IRB signal bar low minus stop buffer and EMA(close, trailing EMA lookback) values from entry through the current chart bar
Calculation: Short stop = minimum of the IRB signal bar high plus stop buffer and EMA(close, trailing EMA lookback) values from entry through the current chart bar
Long: chart bar index >= max(warm-up lookback, confirmation lookback, trailing EMA lookback) AND high > low AND open <= high - (IRB fraction * (high - low)) AND close <= high - (IRB fraction * (high - low)) AND normalized EMA slope >= slope threshold AND both current and longer-lookback-ago mapped EMA values exist AND EMA(close, middle EMA lookback) computed on T1 bars and mapped to chart bars with lookahead off (last completed T1 bar historically, forming T1 bar in realtime) > that mapped series value [MTF lookback chart bars ago] AND ADX(ADX lookback) >= ADX threshold AND overextension ratio <= overextension threshold AND EMA(close, shortest EMA lookback) > EMA(close, middle EMA lookback) > EMA(close, longest EMA lookback) AND close > EMA(close, shortest EMA lookback) on each of the current and preceding (confirmation lookback - 1) chart bars
Short: chart bar index >= max(warm-up lookback, confirmation lookback, trailing EMA lookback) AND high > low AND open >= low + (IRB fraction * (high - low)) AND close >= low + (IRB fraction * (high - low)) AND normalized EMA slope <= -slope threshold AND both current and longer-lookback-ago mapped EMA values exist AND EMA(close, middle EMA lookback) computed on T1 bars and mapped to chart bars with lookahead off (last completed T1 bar historically, forming T1 bar in realtime) < that mapped series value [MTF lookback chart bars ago] AND ADX(ADX lookback) >= ADX threshold AND overextension ratio <= overextension threshold AND EMA(close, shortest EMA lookback) < EMA(close, middle EMA lookback) < EMA(close, longest EMA lookback) AND close < EMA(close, shortest EMA lookback) on each of the current and preceding (confirmation lookback - 1) chart bars
Exit: long, low <= Long stop OR bars since entry >= time-stop lookback
Exit: short, high >= Short stop OR bars since entry >= time-stop lookback
