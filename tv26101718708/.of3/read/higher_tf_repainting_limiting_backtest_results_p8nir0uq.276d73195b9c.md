Calculation: Signal direction = Supertrend(multiplier, lookback) calculated on T1 bars and mapped to chart bars with the selected lookahead and gaps mode, or Supertrend(multiplier, lookback, ATR moving-average type) calculated on chart bars from T1 high/low/close values fetched using the selected custom security mode, or Supertrend(multiplier, lookback) calculated on chart bars; T1 is the chart timeframe multiplied by the higher-timeframe multiplier; lookahead-on uses final T1 values historically and the forming T1 bar in realtime, lookahead-off uses completed T1 bars historically and the forming T1 bar in realtime; gaps mode controls whether missing chart-bar values remain missing or are carried forward; the built-in T1 result may be shifted by one chart bar; custom security mode uses historical T1 values shifted by one chart bar and previous T1 values in realtime, while secure mode uses last-completed T1 values.
Long: Signal direction == uptrend AND datetime >= start-of-day timestamp from current date minus the configured backtest lookback amount in the selected calendar unit
Short: Signal direction == downtrend AND datetime >= start-of-day timestamp from current date minus the configured backtest lookback amount in the selected calendar unit
