Calculation: Normalized value = (value - lowest(value, normalization lookback)) / (highest(value, normalization lookback) - lowest(value, normalization lookback)); use the range midpoint when the range is zero.
Calculation: Standard RSI = selected moving average (SMA, EMA, DEMA, TEMA, WMA, VWMA, SMMA, HMA, LSMA, or ALMA) of RSI(close, RSI lookback), or RSI(close, RSI lookback) when RSI smoothing is disabled; ALMA uses its offset and sigma parameters.
Calculation: KNN-enhanced RSI = clamp((1 - KNN weight) × standard RSI + KNN weight × inverse-distance-weighted mean of the one-bar-forward standard RSI values for the K nearest prior bars, to the RSI range; rank bars within the KNN lookback by Euclidean distance between feature vectors containing normalized standard RSI and, according to feature count, normalized RSI momentum (RSI momentum lookback), RSI standard deviation (RSI volatility lookback), RSI linear-regression slope (RSI slope lookback), and close momentum (close momentum lookback). Use unit weight for distances below the zero-distance cutoff; use standard RSI if fewer than two candidates or no positive weight sum.
Calculation: Final RSI = apply the selected filter to KNN-enhanced RSI when KNN is enabled, or to standard RSI otherwise; use that source unchanged when filtering is disabled. Filters are identity, recursive smoothing (previous filtered value + filter strength × (source - previous filtered value), initialized to source), double EMA (EMA(source, rounded filter strength × first EMA scale), then EMA of that result using rounded filter strength × second EMA scale), or ALMA(source, rounded filter strength × ALMA length scale, ALMA offset, ALMA sigma).
Long: final RSI > RSI midpoint threshold
Short: final RSI <= RSI midpoint threshold
