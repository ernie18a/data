Calculation: Footprint cell(row, chart bar) = (delta, activity, strength, touched). Recomputed on the latest chart bar for each of the last lookback-parameter chart bars, using T1 bars within each chart bar; the latest T1 bar may still be forming. Set padding to the mean ATR(ATR-length parameter) over those chart bars, using high minus low when ATR is unavailable, times the padding-multiplier parameter. Set the row origin to the lowest chart low minus padding; set tick to the greater of minimum-price-increment parameter and tick-floor parameter; set range to the greater of highest chart high plus padding minus origin and tick times row-count parameter; set row step to the greater of range divided by row count and tick. Map prices to rows by clamping floor((price minus origin) divided by row step) to valid row indices. For each row and chart bar, divide each T1 bar's signed weight and weight equally over the rows from its low row through its high row; signed weight is weight times direction, where direction is +1 if close > open, -1 if close < open, otherwise +1 if close > prior T1 close, -1 if close < prior T1 close, and 0 otherwise; weight is volume when positive, otherwise the volume-fallback parameter. If a chart bar has no T1 bars, use its OHLCV and prior chart close by the same rules. Delta and activity are the resulting signed weights and weights accumulated by row from oldest to newest across the lookback chart bars, each new value equal to the prior accumulated value times exp(log(decay-base parameter) divided by persistence parameter) plus the row's current signed weight or weight. touched is true when the chart bar's low-to-high range maps across the row. Let maximum magnitude be the greatest absolute accumulated delta across rows for that chart bar. Strength is clamp(magnitude-weight parameter times abs(delta) divided by maximum magnitude plus dominance-weight parameter times abs(delta) divided by activity, 0, 1), treating a ratio with zero denominator as 0.
Long: Footprint cell(row, chart bar).activity > 0 AND Footprint cell(row, chart bar).strength >= minimum-stripe-strength parameter AND (gap-on-touch parameter is false OR Footprint cell(row, chart bar).touched is false) AND Footprint cell(row, chart bar).delta >= 0
Short: Footprint cell(row, chart bar).activity > 0 AND Footprint cell(row, chart bar).strength >= minimum-stripe-strength parameter AND (gap-on-touch parameter is false OR Footprint cell(row, chart bar).touched is false) AND Footprint cell(row, chart bar).delta < 0
