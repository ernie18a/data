Calculation: HTF FVG bias state on T10, T9, T8, and optionally T6 = On each timeframe's bars, retain the latest bullish FVG (low > high[2], zone [high[2], low]) and latest bearish FVG (high < low[2], zone [high, low[2]]). A new FVG resets its touch and invalidation flags; a bullish FVG is touched by range overlap and invalidated by close below its bottom, and a bearish FVG is touched by range overlap and invalidated by close above its top. State is bullish when (bullish FVG touched and not invalidated) + bearish FVG invalidated exceeds (bearish FVG touched and not invalidated) + bullish FVG invalidated; bearish when the reverse holds; otherwise neutral. Read requested values with lookahead off, using the forming timeframe bar in realtime.
Calculation: Automatic bias score = T10 state × P_high + T9 state × P_high + T8 state × P_mid + (include-T6 parameter ? T6 state × P_low : 0); P_high, P_mid, P_low, and the minimum absolute score P_min are separate parameters.
Long: Manual bullish bias mode OR (automatic bias mode AND automatic bias score >= P_min)
Short: Manual bearish bias mode OR (automatic bias mode AND automatic bias score <= -P_min)
Calculation: Liquidity target on T11 = Track the two latest confirmed pivot highs and pivot lows, using separate swing-strength parameter P_swing on both pivot sides. For bullish bias, choose the newest pivot high above chart close, or the second-newest if the newest is not above; for bearish bias, choose the newest pivot low below chart close, or the second-newest if the newest is not below. Use requested T11 values with lookahead off, using the forming T11 bar in realtime.
Long: Bullish bias AND a liquidity target exists above chart close
Short: Bearish bias AND a liquidity target exists below chart close
Calculation: Directional key zones on T3, T5, T6, T7, T8, and T9, in increasing duration = On each timeframe's bars, use a separate enable parameter for each timeframe; read requested values with lookahead off, using the forming timeframe bar in realtime. Thin width = max(ATR(P_ATR) × P_thin, minimum tick × P_tick). A bullish FVG is low > high[2], zone [high[2], low], active until close < its bottom; a bearish FVG is high < low[2], zone [high, low[2]], active until close > its top. A bullish ITL candidate is the latest confirmed pivot low of strength P_pivot inside an active bullish FVG; activate it when low < candidate AND close > candidate, as a zone candidate ± thin, and deactivate when close < candidate − thin. A bearish ITH candidate mirrors this using confirmed pivot highs inside an active bearish FVG, activating when high > candidate AND close < candidate and deactivating when close > candidate + thin. Bullish base touch means range overlap with an active bullish FVG or ITL zone; bearish base touch means overlap with an active bearish FVG or ITH zone. Create a bullish rejection block on bullish base touch when close > open AND low < min(open, close), with zone [low, min(open, close)]; deactivate on close < its bottom. Create a bearish rejection block on bearish base touch when close < open AND high > max(open, close), with zone [max(open, close), high]; deactivate on close > its top. On bullish base touch with a down candle, set pending CISD to the open of the oldest contiguous down candle, up to separate parameter P_series; activate when a later close > that open, as a zone ± thin, and deactivate when close < its lower edge. On bearish base touch with an up candle, use the oldest contiguous up candle's open; activate when a later close < that open, as a zone ± thin, and deactivate when close > its upper edge. From active rejection block, CISD, ITL/ITH, and FVG zones, choose the nearest bullish support with chart close >= zone bottom or nearest bearish resistance with chart close <= zone top. Distance is max(close − zone top, 0) for bullish zones and max(zone bottom − close, 0) for bearish zones; ties within a timeframe prefer rejection block, then CISD, then ITL/ITH, then FVG. Zone identity time is FVG formation, ITL/ITH sweep and reclaim, rejection block formation, or CISD confirmation time.
Calculation: Active key zone = From enabled key timeframes, choose the eligible directional key zone nearest chart close; ties prefer the longer timeframe. Bullish candidates require close >= zone bottom; bearish candidates require close <= zone top.
Calculation: Execution window = On chart bars, true at all times if the session-only parameter is disabled; otherwise true only when the bar's datetime is within session parameter P_session in time zone P_timezone.
Calculation: Armed setup = On a chart bar, when the execution window is true, bias is directional, the bar range overlaps the active aligned key zone, and no setup is armed or its stored key identity time or side differs, arm or replace the setup. Store its side and key zone. Set manipulation start to the most recent occurrence of the highest high for a bullish setup, or lowest low for a bearish setup, among the preceding P_manip chart bars excluding the touch bar. At setup arming, select once the latest bearish FVG for a bullish setup or latest bullish FVG for a bearish setup among enabled T1-T5, ordered shortest to longest. A bullish FVG is low > high[2], zone [high[2], low], and becomes closed when close < its bottom; a bearish FVG is high < low[2], zone [high, low[2]], and becomes closed when close > its top. Only consider gaps formed from manipulation start through key-touch time; if the separate open-at-touch parameter is enabled, require the gap still open at touch. Select the eligible gap from the highest timeframe. Use requested values with lookahead off, using the forming timeframe bar in realtime. Keep the setup armed until a signal or, if no signal is evaluated on that bar, chart close below the stored bullish key-zone bottom or above the stored bearish key-zone top; a signal clears the setup.
Calculation: Signal quota = The number of long and short signals in the current session is below P_max. Reset the count at session start when session-only is enabled; otherwise reset it when datetime changes calendar date. Increment it for either signal.
Long: A new armed setup has bullish side AND its key-touch bar overlaps the active bullish key zone
Short: A new armed setup has bearish side AND its key-touch bar overlaps the active bearish key zone
Long: An armed bullish setup has a selected bearish FVG AND the last completed bar close on its selected timeframe is above the FVG's upper boundary, evaluated on chart bars when a new selected-timeframe bar begins AND the execution window is true AND the signal quota is true
Short: An armed bearish setup has a selected bullish FVG AND the last completed bar close on its selected timeframe is below the FVG's lower boundary, evaluated on chart bars when a new selected-timeframe bar begins AND the execution window is true AND the signal quota is true
