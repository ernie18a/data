Calculation: Effective engine = selected engine, with Intensity replacing Delta on non-time-based charts; all decisions run on chart bars.
Calculation: Delta flow = on each chart bar, sum the volume of its T1 sub-bars with close > open as buy volume, close < open as sell volume, and all sub-bar volume as total volume; use the T1 bar still forming.
Calculation: Delta ratio = (buy volume − sell volume) / total volume, or zero when total volume is zero.
Calculation: Intensity magnitude(basis) = volume for raw-volume basis, or volume / max(bar duration, minimum duration) for volume-rate basis.
Calculation: Unified magnitude = Intensity magnitude using the unified volume basis when the effective unified engine is Intensity, otherwise Delta total volume.
Calculation: Parallel buy magnitude = Intensity magnitude using the parallel volume basis × (close − low) / (high − low), or an equal split when high = low, when the effective parallel engine is Intensity; otherwise Delta buy volume.
Calculation: Parallel sell magnitude = Intensity magnitude using the parallel volume basis × (high − close) / (high − low), or an equal split when high = low, when the effective parallel engine is Intensity; otherwise Delta sell volume.
Calculation: Thresholds(magnitude, method) = (Bang threshold, Bang-Bang threshold), using lookback completed chart bars ending at the previous chart bar: for Sigma, (SMA + StDev × sensitivity, SMA + StDev × (sensitivity + tier spacing)); for MAD, (median + MAD scale × MAD × sensitivity, median + MAD scale × MAD × (sensitivity + tier spacing)), where MAD is the rolling median of absolute deviations from the prior-bar rolling median; for Percentile, the interpolated lookback percentile using the Bang percentile and the Bang-Bang percentile, respectively.
Calculation: Unified thresholds = Thresholds(unified magnitude, unified threshold method).
Calculation: Parallel buy thresholds = Thresholds(parallel buy magnitude, parallel threshold method).
Calculation: Parallel sell thresholds = Thresholds(parallel sell magnitude, parallel threshold method).
Calculation: Parallel buy active threshold = parallel buy Bang-Bang threshold when parallel buy magnitude exceeds it, otherwise parallel buy Bang threshold.
Calculation: Parallel sell active threshold = parallel sell Bang-Bang threshold when parallel sell magnitude exceeds it, otherwise parallel sell Bang threshold.
Calculation: Parallel excess(magnitude, active threshold, method) = (magnitude − active threshold) / prior-bar rolling StDev for Sigma, / prior-bar rolling MAD for MAD, or / active threshold for Percentile.
Calculation: Close position = 2 × (close − low) / (high − low) − 1, or zero when high = low.
