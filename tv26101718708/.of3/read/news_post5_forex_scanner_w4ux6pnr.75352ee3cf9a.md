Calculation: News move = close of the first T1 bar whose closing time is at or after the configured news timestamp plus the delay parameter, minus the open of the T1 bar containing the configured news timestamp; the timestamp is set by year, month, day, hour, minute, and timezone parameters.
Calculation: News score = min(score-cap parameter, movement-weight parameter * min(ATR(T1, ATR lookback parameter) > 0 ? abs(News move) / ATR(T1, ATR lookback parameter) : 0, movement-cap parameter) + (ATR(T1, ATR lookback parameter) > SMA(ATR(T1, ATR lookback parameter), ATR-average lookback parameter, T1) ? volatility-weight parameter : 0) + (((News move > 0 AND close(T1) > post-news close) OR (News move < 0 AND close(T1) < post-news close)) ? continuation-weight parameter : 0) + (((News move > 0 AND close(T1) > VWAP(hlc3, T1)) OR (News move < 0 AND close(T1) < VWAP(hlc3, T1))) ? VWAP-weight parameter : 0) + (Bollinger direction condition ? Bollinger-weight parameter : 0) + (Bollinger direction condition AND Bollinger width > SMA(Bollinger width, Bollinger-width average lookback parameter, T1) ? expansion-bonus parameter : 0) + (T2 trend condition ? T2 trend-weight parameter : 0) + (T3 trend condition ? T3 trend-weight parameter : 0)); Bollinger direction condition means close(T1) > SMA(close, Bollinger lookback parameter, T1) when News move > 0, or close(T1) < that SMA when News move < 0; Bollinger width is upper band minus lower band, with bands at SMA(close, Bollinger lookback parameter, T1) plus or minus standard deviation(close, Bollinger lookback parameter, T1) times the Bollinger-deviation parameter. T2 trend condition means News move > 0 and EMA(close, shorter T2 lookback parameter, T2) > EMA(close, longer T2 lookback parameter, T2), or News move < 0 and the shorter EMA <= the longer EMA; T3 trend condition is the same using separate shorter and longer T3 lookback parameters. T1 is the event and volatility timeframe, T2 the intermediate trend timeframe, and T3 the slower trend timeframe; indicators run on their respective timeframe bars and requested values are sampled on chart bars with lookahead off (last completed timeframe bars historically and forming timeframe bars in real time).
Long: chart-bar time >= configured news timestamp + delay parameter AND News move > 0 AND News score >= minimum-display-score parameter
Short: chart-bar time >= configured news timestamp + delay parameter AND News move < 0 AND News score >= minimum-display-score parameter
