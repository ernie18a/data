Calculation: timeframe score = clamp(ADX quality multiplier × [EMA-structure weight × EMA-structure state + price-location weight × price state + slope weight × slope state + RSI weight × RSI state + MACD weight × MACD-histogram state + Supertrend weight × Supertrend-direction state + alignment-bonus weight × alignment state], −score limit, +score limit). EMA-structure state is +1 when EMA(close, fast lookback) > EMA(close, longer slow lookback), −1 when lower, otherwise 0; price state uses close relative to the fast EMA; slope state is +1 when the fast EMA minus its value slope-lookback bars ago exceeds ATR(ATR lookback) × neutral-band multiple, −1 when below the negative band, otherwise 0; RSI state is +1 above its bullish threshold, −1 below its bearish threshold, otherwise 0; MACD-histogram and Supertrend-direction states are +1 bullish, −1 bearish, otherwise 0; alignment state is their common nonzero direction only when EMA structure, price, slope, MACD histogram, and Supertrend all agree, otherwise 0. ADX quality multiplier = clamp(lower multiplier + min(ADX(DI lookback, smoothing lookback), ADX reference) / ADX reference × multiplier increment, lower multiplier, maximum multiplier). Calculate on each timeframe’s bars, using its last completed bar for higher timeframes and its current bar for the chart timeframe.
Calculation: aggregate score = weighted average of the scores for selected timeframes T1, T2, … that are at least as large as the chart timeframe and have positive timeframe weights, or 0 if none qualify; calculate on chart bars using each timeframe’s score, with higher-timeframe scores from their last completed bars and the chart-timeframe score from its current bar.
