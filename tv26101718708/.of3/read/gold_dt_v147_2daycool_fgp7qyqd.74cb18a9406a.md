Calculation: Initial short stop = at entry, entry plus stop-points times tick size in points mode, entry plus ATR(ATR lookback) times stop-ATR multiplier in ATR mode, or entry plus tick size times stop-ticks in ticks mode
Calculation: Final short target = at entry, entry minus the absolute distance from entry to initial short stop times test reward/risk in test mode; otherwise entry minus target-points times tick size in points mode, entry minus ATR(ATR lookback) times target-ATR multiplier in ATR mode, or entry minus tick size times target-ticks in ticks mode
Calculation: First partial target = entry minus the absolute distance from entry to final short target times the partial-target fraction
Calculation: Short stop state = start at initial short stop; while stage is below one, if break-even is enabled and entry minus low reaches the final-target distance times the break-even fraction, set stop to entry and stage to one; while stage is below two, if trailing is enabled and entry minus low reaches the final-target distance times the trail-start fraction, set stage to two; at stage two or higher, update stop each chart bar to the minimum of its prior value and EMA(close,shorter lookback)
Calculation: Consecutive-loss count = start at zero; for each closed trade, increment on negative per-unit profit unless exit price is within entry price times the break-even tolerance of entry; reset on positive per-unit profit or a break-even close; otherwise retain the count
