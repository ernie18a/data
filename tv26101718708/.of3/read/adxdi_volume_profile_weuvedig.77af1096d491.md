Calculation: Directional row ratio(DI) = the row’s DI energy divided by the greatest DI energy among rows in that profile, using 1 as the denominator if the maximum is nonpositive. DI energy is accumulated over chart bars: add DI(high, low, close, DMI lookback) × volume weight × (1 + abs(+DI − −DI) / (+DI + −DI)) divided by the number of equal-price rows touched by each bar’s low-to-high range; use 0 for the fraction when +DI + −DI is 0. Rows evenly divide the profile’s low-to-high range. Volume weight is volume when volume weighting is enabled and volume is positive, otherwise 1. When MTF is enabled, DI and volume use T1 values mapped to chart bars, with T1’s last completed value on historical bars and its forming value in real time; otherwise they use chart-bar values. Each current or displayed historical profile spans the profile-length parameter multiplied by rounded chart bars per T1 bar when MTF is enabled, capped by the maximum profile-length parameter.
Long: Directional row ratio(+DI) >= noise threshold
Short: Directional row ratio(−DI) >= noise threshold
