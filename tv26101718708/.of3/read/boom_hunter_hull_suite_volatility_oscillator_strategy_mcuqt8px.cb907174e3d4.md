Calculation: EOT quotient(close, high-pass lookback, low-pass lookback, response parameter, peak-decay parameter) = (normalized value + response parameter) / (response parameter × normalized value + 1), where filtered value = two-pole Ehlers Super Smoother(Ehlers high-pass filter(close, high-pass lookback), low-pass lookback), peak = max(abs(filtered value), peak-decay parameter × prior peak), normalized value = filtered value / peak; missing prior recursive values are zero.
Calculation: Long stop = min(entry-signal-bar close − ATR(ATR lookback), lowest(low, swing lookback)), set on the entry-signal bar and held for the position.
Calculation: Short stop = max(entry-signal-bar close + ATR(ATR lookback), highest(high, swing lookback)), set on the entry-signal bar and held for the position.
Calculation: Long target = entry-signal-bar close + (entry-signal-bar close − Long stop) × reward multiple, set on the entry-signal bar and held for the position.
Calculation: Short target = entry-signal-bar close − (Short stop − entry-signal-bar close) × reward multiple, set on the entry-signal bar and held for the position.
Long: SMA(EOT quotient(close, shared high-pass lookback, shorter low-pass lookback, first response parameter, shared peak-decay parameter), trigger lookback) crosses above EOT quotient(close, shared high-pass lookback, longer low-pass lookback, second response parameter, shared peak-decay parameter) AND selected HMA/EHMA/THMA(source, base length × length multiplier), using the current still-forming T1 bar sampled on chart bars when T1 mode is enabled and chart bars otherwise, is greater than its value at the configured direction lag in chart bars ago AND close is above that Hull MA value AND close − open > stdev(close − open, volatility lookback) AND datetime ≥ configured start AND datetime < configured end AND position side is not long.
Short: SMA(EOT quotient(close, shared high-pass lookback, shorter low-pass lookback, first response parameter, shared peak-decay parameter), trigger lookback) crosses below EOT quotient(close, shared high-pass lookback, longer low-pass lookback, second response parameter, shared peak-decay parameter) AND selected HMA/EHMA/THMA(source, base length × length multiplier), using the current still-forming T1 bar sampled on chart bars when T1 mode is enabled and chart bars otherwise, is less than its value at the configured direction lag in chart bars ago AND close is below that Hull MA value AND close − open < −stdev(close − open, volatility lookback) AND datetime ≥ configured start AND datetime < configured end AND position side is not short.
Exit: long, low ≤ Long stop OR high ≥ Long target.
Exit: short, high ≥ Short stop OR low ≤ Short target.
