Calculation: Trailing-stop direction = ATR = ATR(high, low, close, ATR lookback); raw long stop = highest(close, ATR lookback) - ATR multiplier * ATR; raw short stop = lowest(close, ATR lookback) + ATR multiplier * ATR; long stop is the raw long stop when the prior long stop is undefined or close[1] <= long stop[1], otherwise max(raw long stop, long stop[1]); short stop is the raw short stop when the prior short stop is undefined or close[1] >= short stop[1], otherwise min(raw short stop, short stop[1]); initialize direction as long, then set it to long if close > prior short stop (or current short stop if the prior value is undefined), short if close < prior long stop (or current long stop if the prior value is undefined), otherwise retain prior direction.
Calculation: HTF long eligibility = higher-timeframe filter disabled OR mode selects the HTF-bypass option OR (EMA(close, shorter HTF lookback, T1 current still-forming bar) > EMA(close, longer HTF lookback, T1 current still-forming bar) AND EMA(close, shorter HTF lookback, T2 current still-forming bar) > EMA(close, longer HTF lookback, T2 current still-forming bar)); T1 and T2 are distinct higher timeframes, and chart bars use the values computed on their current still-forming bars.
Calculation: HTF short eligibility = higher-timeframe filter disabled OR mode selects the HTF-bypass option OR (EMA(close, shorter HTF lookback, T1 current still-forming bar) < EMA(close, longer HTF lookback, T1 current still-forming bar) AND EMA(close, shorter HTF lookback, T2 current still-forming bar) < EMA(close, longer HTF lookback, T2 current still-forming bar)); T1 and T2 are distinct higher timeframes, and chart bars use the values computed on their current still-forming bars.
Calculation: Volume points = when SMA(volume, volume lookback) > 0, strong-volume points if volume / SMA(volume, volume lookback) >= strong-volume ratio threshold, else good-volume points if the ratio >= good-volume ratio threshold, else okay-volume points if the ratio >= okay-volume ratio threshold, else zero; zero when the SMA is not positive; strong > good > okay for both ratio thresholds and points.
Calculation: Long score = shared trend/Chandelier weight if EMA(close, shorter chart fast lookback) > EMA(close, longer chart slow lookback), plus the same shared trend/Chandelier weight if trailing-stop direction is long, plus shared momentum/HTF weight if EMA(RSI(close, RSI lookback), RSI smoothing lookback) > RSI midpoint threshold and > its prior value, plus the same shared momentum/HTF weight if HTF long eligibility, plus Volume points.
Calculation: Short score = shared trend/Chandelier weight if EMA(close, shorter chart fast lookback) < EMA(close, longer chart slow lookback), plus the same shared trend/Chandelier weight if trailing-stop direction is short, plus shared momentum/HTF weight if EMA(RSI(close, RSI lookback), RSI smoothing lookback) < RSI midpoint threshold and < its prior value, plus the same shared momentum/HTF weight if HTF short eligibility, plus Volume points.
Calculation: Direction = long when Long score > Short score, short when Short score > Long score, neutral when equal.
Calculation: Confidence = Long score when Direction is long, Short score when Direction is short, zero when Direction is neutral.
Long: Direction is long AND HTF long eligibility AND Confidence >= minimum score AND (Confidence >= high-confidence threshold OR low <= EMA(close, shorter chart fast lookback) OR close > high[1]); high-confidence threshold > minimum score.
Short: Direction is short AND HTF short eligibility AND Confidence >= minimum score AND (Confidence >= high-confidence threshold OR high >= EMA(close, shorter chart fast lookback) OR close < low[1]); high-confidence threshold > minimum score.
