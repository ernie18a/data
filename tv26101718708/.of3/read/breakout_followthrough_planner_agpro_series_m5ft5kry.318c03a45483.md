Calculation: High-good score(x, lower, upper) = 100 * clamp((x - lower) / (upper - lower), 0, 1)
Calculation: Safe ATR = max(ATR(ATR length), true range when ATR is unavailable, instrument minimum tick)
Calculation: Prior structure edges = (highest(high[1], structure lookback), lowest(low[1], structure lookback))
Calculation: Trend score(side) = clamp(price-alignment points + EMA-stack points + slope points, 0, 100); price-alignment points are the aligned-price points when close is on the breakout side of EMA(close, slow EMA length), otherwise the opposed-price points; EMA-stack points are the aligned-stack points when EMA(close, fast EMA length) is on the breakout side of EMA(close, slow EMA length), otherwise zero; slope points are maximum slope points times high-good score(abs(EMA(close, slow EMA length) - EMA(close, slow EMA length)[slope lookback]) / safe ATR, slope-strength lower bound, slope-strength upper bound) / 100 when that EMA slope is in the breakout direction, otherwise zero; use the current EMA if its past value is unavailable
Calculation: Structure score = high-good score((prior structure high - prior structure low) / safe ATR, minimum structure height, minimum structure height + narrow-structure score span) when structure height in ATR is at or below the midpoint of the minimum and maximum structure heights; otherwise it is 100 minus high-good score of that height using maximum structure height - wide-structure score span as the lower bound and maximum structure height as the upper bound
Calculation: Break quality(side) = clamp(distance weight * high-good score(side-directional close clearance / safe ATR, break buffer ATR, break buffer ATR + break-distance score span) + body weight * high-good score(abs(close - open) / max(high - low, instrument minimum tick), body-share lower bound, body-share upper bound) + close-location weight * high-good score(side-specific close location, close-location lower bound, close-location upper bound) + volume weight * high-good score(relative volume, volume-support lower bound, full-volume-support ratio) + trend weight * trend score(side) + structure weight * structure score, 0, 100); side-specific close location is (close - low) / max(high - low, instrument minimum tick) for long and (high - close) / max(high - low, instrument minimum tick) for short; relative volume is volume / SMA(volume, volume-baseline lookback), or 1 when the baseline is unavailable or nonpositive; each score weight and score bound is a separate parameter
Long: (confirmation mode is realtime or the bar is confirmed) AND long is permitted by the side-selection parameter AND (prior structure high - prior structure low) / safe ATR is between the minimum and maximum structure heights AND no prior breakout plan exists or at least the breakout cooldown has elapsed AND close > prior structure high + safe ATR * break buffer ATR AND break quality(long) >= minimum break quality
Short: (confirmation mode is realtime or the bar is confirmed) AND short is permitted by the side-selection parameter AND (prior structure high - prior structure low) / safe ATR is between the minimum and maximum structure heights AND no prior breakout plan exists or at least the breakout cooldown has elapsed AND close < prior structure low - safe ATR * break buffer ATR AND break quality(short) >= minimum break quality
