Calculation: Sell-side score = 0 when no sell-side pool exists; otherwise clamp(proximity weight * clamp(100 - ((close - nearest sell-side pool) / ATR(ATR lookback)) / maximum-distance-in-ATR * 100, 0, 100) + pool-strength weight * (strength blend weight * (nearest pool is prior low ? max(clamp(untapped swing lows within equal-level ATR tolerance * ATR(ATR lookback) of the pool / touch normalization * 100, 0, 100), prior-pool strength floor) : clamp(untapped swing lows within equal-level ATR tolerance * ATR(ATR lookback) of the pool / touch normalization * 100, 0, 100)) + freshness blend weight * (nearest pool is prior low ? prior-pool freshness score : clamp(100 - age in chart bars / freshness window * 100, 0, 100))) + trend weight * (Downtrend ? 100 : close < EMA(close, trend lookback) ? below-EMA trend score : Uptrend ? opposing-trend score : neutral trend score) + range-position weight * clamp(50 + (Range position - 0.5) * 100, 0, 100), 0, 100)
