Calculation: Short SMA = SMA(close, shorter lookback)
Calculation: Long SMA = SMA(close, longer lookback)
Calculation: Chart MACD line and signal line = MACD(close, fast MACD lookback, slow MACD lookback, signal lookback)
Calculation: T1 MACD line and signal line = MACD(close, fast MACD lookback, slow MACD lookback, signal lookback) on T1 bars, using the still-forming T1 bar's values on chart bars
Calculation: Heikin-Ashi red-to-green = Heikin-Ashi close > Heikin-Ashi open AND Heikin-Ashi close[1] < Heikin-Ashi open[1]
Calculation: Heikin-Ashi green-to-red = Heikin-Ashi close < Heikin-Ashi open AND Heikin-Ashi close[1] > Heikin-Ashi open[1]
Calculation: Long add threshold = close < (most recent long-add price if any, otherwise initial entry price) × (1 − long add step)
Calculation: Short add threshold = close > (most recent short-add price if any, otherwise initial entry price) × (1 + short add step)
Long: Short SMA crosses above Long SMA
Short: Short SMA crosses below Long SMA
Long: Chart MACD line crosses above Chart MACD signal line AND ((Short SMA > Long SMA AND T1 MACD line < T1 MACD signal line) OR (Short SMA < Long SMA AND T1 MACD line > T1 MACD signal line))
Long: T1 MACD line crosses above T1 MACD signal line on chart bars using T1's still-forming bar values
Short: T1 MACD line crosses below T1 MACD signal line on chart bars using T1's still-forming bar values
Long: Long position AND Heikin-Ashi red-to-green AND Long add threshold
Long: Long position AND close < initial entry price AND Heikin-Ashi red-to-green AND Long add threshold
Short: Short position AND Heikin-Ashi green-to-red AND Short add threshold
Short: Short position AND close > initial entry price AND Heikin-Ashi green-to-red AND Short add threshold
