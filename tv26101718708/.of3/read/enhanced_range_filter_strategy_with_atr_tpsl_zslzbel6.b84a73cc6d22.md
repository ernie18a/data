Calculation: Rising filter run = previous rising filter run + 1 when range filter > previous range filter, 0 when range filter < previous range filter, otherwise previous rising filter run; initialize to 0
Calculation: Falling filter run = previous falling filter run + 1 when range filter < previous range filter, 0 when range filter > previous range filter, otherwise previous falling filter run; initialize to 0
Calculation: Direction state = 1 when close > range filter AND close != close[1] AND rising filter run > 0, -1 when close < range filter AND close != close[1] AND falling filter run > 0, otherwise previous direction state; initialize to 0
