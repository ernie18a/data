Calculation: VWAP reaction corridor = Session VWAP ± max(ATR(lookback), or true range if unavailable, minimum tick) × corridor width
Long: during the selected session on intraday chart bars, close > Session VWAP
Short: during the selected session on intraday chart bars, close < Session VWAP
Long: during the selected session, close crosses above Session VWAP after the prior-side lookback bars each closed below their corresponding Session VWAP; the cross bar and following bars close above Session VWAP for the confirmation lookback consecutive bars, with the current bar the final confirmation bar; at least the cooldown bars have elapsed since the previous accepted reaction event, if any; and, when confirmed-events-only is enabled, the current bar is confirmed
Short: during the selected session, close crosses below Session VWAP after the prior-side lookback bars each closed above their corresponding Session VWAP; the cross bar and following bars close below Session VWAP for the confirmation lookback consecutive bars, with the current bar the final confirmation bar; at least the cooldown bars have elapsed since the previous accepted reaction event, if any; and, when confirmed-events-only is enabled, the current bar is confirmed

Short: during the selected session, the prior-side lookback bars each closed below their corresponding Session VWAP, high >= the upper corridor edge, close < Session VWAP, close < open, and (the slope filter is disabled or Session VWAP <= Session VWAP[slope lookback]); at least the cooldown bars have elapsed since the previous accepted reaction event, if any; and, when confirmed-events-only is enabled, the current bar is confirmed
