Calculation: Trend state = Bull strong if close > EMA(close, mid EMA lookback) AND EMA(close, fast EMA lookback) > EMA(close, mid EMA lookback) AND EMA(close, mid EMA lookback) > SMA(close, long SMA lookback); else Bull basic if close > mid EMA AND fast EMA > mid EMA; else Bear if close < mid EMA AND mid EMA < long SMA; else Neutral. Fast EMA lookback < mid EMA lookback < long SMA lookback.
Calculation: Confirmed pivot highs and lows = PivotHigh(high, left-bars parameter, right-bars parameter) and PivotLow(low, left-bars parameter, right-bars parameter), confirmed on chart bars. On each new confirmed pivot low, shift the previous latest pivot-low price, its RSI value at the pivot bar, and its bar index to the preceding values, then store the new values; on each new confirmed pivot high, store its price and bar index.
Calculation: Impulse low, impulse high, and impulse range = on a new confirmed pivot high whose bar index is later than the latest confirmed pivot low, set impulse low to that pivot low and impulse high to the new pivot high; otherwise retain them; range = impulse high - impulse low.
Calculation: Price confirmation = latest confirmed pivot-low price > preceding confirmed pivot-low price AND close > EMA(close, fast EMA lookback) AND close > high[1] AND close > open.
Calculation: Stochastic K = SMA(Stochastic(close, high, low, Stochastic lookback), K smoothing lookback); Stochastic D = SMA(Stochastic K, D smoothing lookback).
Calculation: Stochastic reset active = a reset occurred when Lowest(Stochastic K, oversold scan lookback) < oversold threshold AND (Stochastic K crosses above Stochastic D OR Stochastic K > Stochastic K[1] AND Stochastic D > Stochastic D[1]) AND Stochastic K < reset ceiling; reset is active while bars since the latest reset <= reset-active window. Oversold threshold < reset ceiling < overbought threshold.
Calculation: Stochastic rollover = Stochastic K > overbought threshold AND Stochastic D > overbought threshold AND Stochastic K crosses below Stochastic D.
Calculation: Active bullish RSI divergence = hidden bullish divergence at a new confirmed pivot low, where latest pivot-low price > preceding pivot-low price and latest pivot-low RSI < preceding pivot-low RSI, OR regular bullish divergence where latest pivot-low price < preceding pivot-low price and latest pivot-low RSI > preceding pivot-low RSI; either divergence remains active through the divergence lookback window.
Calculation: Timing score = trend points (Bull strong points for Bull strong; otherwise Bull basic points for Bull basic; otherwise zero) + pullback points when close is between impulse high - impulse range × lower Fibonacci retracement parameter and impulse high - impulse range × upper Fibonacci retracement parameter, close > impulse low, and trend state is Bull strong or Bull basic + divergence points (hidden-divergence points if active hidden divergence; otherwise regular-divergence points if active regular divergence; otherwise zero) + stochastic-reset points if Stochastic reset is active + Wolfe-structure points when latest pivot-low price < preceding pivot-low price, a latest pivot high exists, close > latest pivot-low price, and trend state is Bull strong or Bull basic + price-confirmation points if Price confirmation. Lower Fibonacci retracement parameter < upper Fibonacci retracement parameter.
Calculation: Relative-strength line = close / benchmark close, using benchmark close from matching chart-timeframe bars. Relative-strength status = line > SMA(line, relative-performance lookback) AND traded-instrument return over that same lookback > benchmark return over that lookback. Relative-strength new high = line >= Highest(line, relative-strength new-high lookback) × relative-strength high-proximity parameter.
Calculation: Distance from T1 high = (close / Highest(high, high lookback, T1) - 1) × 100; on chart bars, take the value from the still-forming T1 bar.
Calculation: Volume status = volume / SMA(volume, volume-average lookback) × 100; strong when this percentage >= breakout-volume threshold, decent when >= average-volume threshold.
Calculation: Accumulation status = count over accumulation lookback of bars where close > close[1] AND volume > SMA(volume, volume-average lookback), compared with the count of bars where close < close[1] AND volume > that volume average; positive when the first count > the second count + accumulation-count margin, negative when the second count > the first count + that margin, otherwise neutral.
Calculation: Pivot status uses pivot level = Highest(high, base lookback)[1]; near pivot when close <= pivot level AND close >= pivot level × near-pivot factor; breakout when close > pivot level AND volume status is strong; quiet above pivot when close > pivot level AND volume status is not strong; extended when close > pivot level × extension factor.
Calculation: CANSLIM score = relative-strength points (strong points for strong status, otherwise outperformance points if the traded instrument return > benchmark return, otherwise zero) + new-high points if Relative-strength new high + high-distance points (top-band points if distance >= top high-distance boundary; otherwise middle-band points if >= middle boundary; otherwise lower-band points if >= lower boundary; otherwise zero) + volume points (strong points if volume is strong; otherwise decent points if volume is decent; otherwise zero) + accumulation points (positive points if accumulation is positive; otherwise neutral points if accumulation is not negative; otherwise zero) + pivot points (breakout points; otherwise near-pivot points; otherwise quiet-above-pivot points; otherwise extended points; otherwise zero).
Calculation: CANSLIM filter pass = CANSLIM score >= filter-score threshold AND Distance from T1 high >= acceptable-high-distance boundary AND (Relative-strength status is strong OR Relative-strength new high).
Calculation: Timing score percentage = Timing score normalized by the timing-score maximum and expressed on a 0-to-100 scale.
Calculation: ATR stretch = (close - EMA(close, fast EMA lookback)) / ATR(ATR lookback). Mean-reversion discount when ATR stretch < 0 AND close > EMA(close, mid EMA lookback); normal when absolute ATR stretch <= normal ATR limit; extended when ATR stretch > normal ATR limit AND <= extended ATR limit; stretched when ATR stretch > extended ATR limit; broken when close < EMA(close, mid EMA lookback). Normal ATR limit < extended ATR limit.
Calculation: Invalidation = impulse low exists AND close < impulse low.
Calculation: Positive target available = Timing score >= target-activation threshold AND not Invalidation AND impulse range > 0 AND close > 0 AND impulse low + impulse range × target-extension parameter > close.
Calculation: Aggregate score = CANSLIM score × CANSLIM weight + relative-strength component × relative-strength weight + price component × price weight + trend component × trend weight + pivot component × pivot weight + high-distance component × high-distance weight + Timing score percentage × timing weight + volume component × volume weight + mean-reversion component × mean-reversion weight + accumulation component × accumulation weight + stochastic component × stochastic weight + invalidation component × invalidation weight + target component × target weight. Relative-strength component is strong score if Relative-strength status is strong, otherwise outperforming score if the traded instrument outperforms the benchmark, otherwise zero. Price component is confirmed score if Price confirmation, otherwise waiting score. Trend component is strong score for Bull strong, otherwise basic score for Bull basic, otherwise bear score for Bear, otherwise neutral score. Pivot component is breakout score, otherwise near-pivot score, otherwise quiet-above-pivot score, otherwise extended score, otherwise base score. High-distance component is good score when distance >= acceptable-high-distance boundary, caution score when below that boundary but >= caution boundary, bad score when below caution boundary, otherwise unavailable score. Volume component is strong score if volume is strong, otherwise decent score if volume is decent, otherwise weak score. Accumulation component is positive score if accumulation is positive, otherwise negative score if accumulation is negative, otherwise neutral score. Mean-reversion component is discount score, otherwise normal score, otherwise extended score, otherwise stretched score, otherwise broken score, otherwise unavailable score. Stochastic component is reset score if Stochastic reset is active, otherwise positive-momentum score if Stochastic K > Stochastic D, otherwise rollover score if Stochastic rollover, otherwise neutral score. Invalidation component is invalidated score if Invalidation, otherwise valid score. Target component is available score if Positive target available, otherwise unavailable score. Use a separate parameter for each component weight and each component score value.
Long: Aggregate score >= trigger-score parameter AND Price confirmation AND not Invalidation AND not mean-reversion stretched AND (CANSLIM filter requirement is disabled OR CANSLIM filter pass).
Long: Aggregate score >= watch-score parameter AND Aggregate score < trigger-score parameter AND not Invalidation. Watch-score parameter < trigger-score parameter.
Exit: long, Aggregate score >= trim-score parameter AND (Stochastic rollover OR mean-reversion stretched).
Exit: long, Invalidation.
