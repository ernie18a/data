Calculation: RVOL = volume / SMA(volume, volume average length)
Calculation: Base range percent = (Highest(high, VCP base lookback) - Lowest(low, VCP base lookback)) / Lowest(low, VCP base lookback) * 100
Calculation: ATR ratio = ATR(ATR length) / SMA(ATR(ATR length), ATR length)
Calculation: BB width ratio = BBWidth(close, BB length, BB multiplier) / SMA(BBWidth(close, BB length, BB multiplier), BB length)
Calculation: VCP third = max(floor(VCP base lookback / 3), 1)
Calculation: Continuation third = max(floor(continuation base lookback / 3), 1)
Calculation: Above-EMA extension percent = (close - EMA(close, shorter EMA length)) / EMA(close, shorter EMA length) * 100
Calculation: Below-EMA extension percent = (EMA(close, shorter EMA length) - close) / EMA(close, shorter EMA length) * 100
Calculation: Long shelf variation percent = (Highest(high[1], shelf lookback) - Lowest(high[1], shelf lookback)) / Highest(high[1], shelf lookback) * 100
Calculation: Short shelf variation percent = (Highest(low[1], shelf lookback) - Lowest(low[1], shelf lookback)) / Lowest(low[1], shelf lookback) * 100
Calculation: Continuation resistance variation percent = (Highest(high[1], continuation shelf lookback) - Lowest(high[1], continuation shelf lookback)) / Highest(high[1], continuation shelf lookback) * 100
Calculation: Continuation support variation percent = (Highest(low[1], continuation shelf lookback) - Lowest(low[1], continuation shelf lookback)) / Lowest(low[1], continuation shelf lookback) * 100
Calculation: Continuation range percent = (Highest(high, continuation base lookback) - Lowest(low, continuation base lookback)) / Lowest(low, continuation base lookback) * 100
Calculation: Long breakout = close > Highest(high[1], shelf lookback) * (1 + breakout buffer / 100) AND close > open
Calculation: Short breakdown = close < Lowest(low[1], shelf lookback) * (1 - breakout buffer / 100) AND close < open
Calculation: Continuation long breakout = close > Highest(high[1], continuation shelf lookback) * (1 + breakout buffer / 100) AND close > open
Calculation: Continuation short breakdown = close < Lowest(low[1], continuation shelf lookback) * (1 - breakout buffer / 100) AND close < open
Calculation: Bottom breakout = close > Highest(high[1], shorter bottom base lookback) * (1 + breakout buffer / 100) AND close > open
Calculation: Bottom base range percent = (Highest(high[1], shorter bottom base lookback) - Lowest(low, shorter bottom base lookback)) / Lowest(low, shorter bottom base lookback) * 100
Calculation: Prior impulse percent = (Highest(high, longer impulse lookback) - Lowest(low, longer impulse lookback)) / Lowest(low, longer impulse lookback) * 100
Calculation: Pullback depth percent = (Highest(high, longer impulse lookback) - Lowest(low, shorter pullback lookback)) / (Highest(high, longer impulse lookback) - Lowest(low, longer impulse lookback)) * 100
Calculation: Rally pullback depth percent = (Highest(high, shorter pullback lookback) - Lowest(low, longer impulse lookback)) / (Highest(high, longer impulse lookback) - Lowest(low, longer impulse lookback)) * 100
Calculation: EMA slope percent = abs(EMA(close, shorter EMA length) - EMA(close, shorter EMA length)[slope lookback]) / EMA(close, shorter EMA length)[slope lookback] * 100
Calculation: Trend fast EMA = EMA(close, shorter trend EMA length) if trend mode A, else EMA(close, shorter EMA length)
Calculation: Trend slow EMA = EMA(close, longer trend EMA length) if trend mode A, else EMA(close, longer EMA length)
Calculation: Uptrend = close > Trend slow EMA AND Trend fast EMA > Trend slow EMA
Calculation: Downtrend = close < Trend slow EMA AND Trend fast EMA < Trend slow EMA
Calculation: Trend strength OK = NOT consolidation filter on OR (ADX(ADX length, ADX smoothing length) >= min ADX AND EMA slope percent >= min EMA slope)
Calculation: Normal long gate = (NOT trend filter on OR Uptrend) AND Trend strength OK
Calculation: Bottom long gate = (bottom bypass trend on OR NOT trend filter on OR Uptrend) AND (bottom bypass consolidation on OR Trend strength OK)
Calculation: Short gate = (NOT trend filter on OR Downtrend) AND Trend strength OK
Calculation: Cooldown ready = no prior long or short entry OR bars since last long or short entry >= cooldown bars
Calculation: Long VCP score = count of true in (close > EMA(close, shorter EMA length) AND (NOT strict trend on OR EMA(close, shorter EMA length) > EMA(close, longer EMA length)), Long shelf variation percent <= max shelf variation, Base range percent <= max base range, Lowest(low[2 * VCP third], VCP third) < Lowest(low[VCP third], VCP third) AND Lowest(low[VCP third], VCP third) <= Lowest(low, VCP third), ATR ratio <= max ATR compression, BB width ratio <= max BB width compression, RVOL >= RVOL threshold, RSI(close, RSI length) >= long minimum RSI)
Calculation: Short VCP score = count of true in (close < EMA(close, shorter EMA length) AND (NOT strict trend on OR EMA(close, shorter EMA length) < EMA(close, longer EMA length)), Short shelf variation percent <= max shelf variation, Base range percent <= max base range, Highest(high[2 * VCP third], VCP third) > Highest(high[VCP third], VCP third) AND Highest(high[VCP third], VCP third) >= Highest(high, VCP third), ATR ratio <= max ATR compression, BB width ratio <= max BB width compression, RVOL >= RVOL threshold, RSI(close, RSI length) <= short maximum RSI)
Calculation: Continuation long score = count of true in (close > EMA(close, shorter EMA length), Continuation resistance variation percent <= max continuation shelf variation, Continuation range percent <= max continuation range, Lowest(low[2 * Continuation third], Continuation third) <= Lowest(low[Continuation third], Continuation third) AND Lowest(low[Continuation third], Continuation third) <= Lowest(low, Continuation third), RVOL >= RVOL threshold, RSI(close, RSI length) >= long minimum RSI, (BB width ratio <= max BB width compression OR ATR ratio <= max ATR compression))
Calculation: Continuation short score = count of true in (close < EMA(close, shorter EMA length), Continuation support variation percent <= max continuation shelf variation, Continuation range percent <= max continuation range, Highest(high[2 * Continuation third], Continuation third) >= Highest(high[Continuation third], Continuation third) AND Highest(high[Continuation third], Continuation third) >= Highest(high, Continuation third), RVOL >= RVOL threshold, RSI(close, RSI length) <= short maximum RSI, (BB width ratio <= max BB width compression OR ATR ratio <= max ATR compression))
Calculation: Context long score = count of true in (Prior impulse percent >= minimum prior impulse percent, Pullback depth percent <= max pullback percent, close > EMA(close, shorter EMA length), close > EMA(close, longer EMA length), EMA(close, shorter EMA length) > EMA(close, longer EMA length), RSI(close, RSI length) >= RSI midline, RVOL >= context minimum RVOL, RVOL >= context strong RVOL, close >= Highest(high, longer impulse lookback) * (near-high percent / 100))
Calculation: Context short score = count of true in (Prior impulse percent >= minimum prior impulse percent, Rally pullback depth percent <= max pullback percent, close < EMA(close, shorter EMA length), close < EMA(close, longer EMA length), EMA(close, shorter EMA length) < EMA(close, longer EMA length), RSI(close, RSI length) <= RSI midline, RVOL >= context minimum RVOL, RVOL >= context strong RVOL, close <= Lowest(low, longer impulse lookback) * (2 - near-high percent / 100))
Calculation: Bottom score = count of true in (close <= Lowest(low, longer bottom lookback) * (1 + max distance from bottom low / 100), Bottom base range percent <= max bottom base range, Bottom breakout, close > EMA(close, shorter EMA length), EMA(close, shorter EMA length) > EMA(close, shorter EMA length)[1], RSI(close, RSI length) >= bottom RSI minimum, RSI(close, RSI length) crosses above RSI midline, (NOT bottom volume required on OR SMA(volume, volume average length) <= 0 OR volume <= 0 OR RVOL >= RVOL threshold))
Calculation: VCP long = Long breakout AND Long VCP score >= minimum VCP score AND Above-EMA extension percent <= max extension
Calculation: Classic continuation long = continuation scanner on AND Continuation long breakout AND Continuation long score >= minimum continuation score AND Above-EMA extension percent <= max extension
Calculation: Contextual continuation long = continuation scanner on AND context continuation on AND Continuation long breakout AND Context long score >= minimum context score AND Above-EMA extension percent <= max extension
Calculation: Bottom ignition long = bottom ignition on AND Bottom breakout AND Bottom score >= minimum bottom score AND Above-EMA extension percent <= max extension
Calculation: VCP short = Short breakdown AND Short VCP score >= minimum VCP score AND Below-EMA extension percent <= max extension
Calculation: Classic continuation short = continuation scanner on AND Continuation short breakdown AND Continuation short score >= minimum continuation score AND Below-EMA extension percent <= max extension
Calculation: Contextual continuation short = continuation scanner on AND context continuation on AND Continuation short breakdown AND Context short score >= minimum context score AND Below-EMA extension percent <= max extension
Calculation: Long stop = max(base, PivotLow(low, swing left bars, swing right bars)) if that pivot low is confirmed on this bar, otherwise base; base = min(close - ATR(ATR length) * initial ATR stop multiplier, low) if the long entry condition holds on this bar, otherwise Long stop[1]
Calculation: Short stop = min(base, PivotHigh(high, swing left bars, swing right bars)) if that pivot high is confirmed on this bar, otherwise base; base = max(close + ATR(ATR length) * initial ATR stop multiplier, high) if the short entry condition holds on this bar, otherwise Short stop[1]
Long: long trading on AND Cooldown ready AND position side is not short AND (position side is not long OR pyramiding on) AND (((VCP long OR Classic continuation long OR Contextual continuation long) AND Normal long gate) OR (Bottom ignition long AND Bottom long gate))
Short: short trading on AND Short gate AND (VCP short OR Classic continuation short OR Contextual continuation short) AND Cooldown ready AND position side is not long AND (position side is not short OR pyramiding on)
Exit: long, (exit on close AND close < Long stop) OR (NOT exit on close AND low < Long stop)
Exit: short, (exit on close AND close > Short stop) OR (NOT exit on close AND high > Short stop)
