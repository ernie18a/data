Calculation: delta = on each chart bar, sum the sign of each consecutive T1 intrabar close change multiplied by that intrabar’s volume when volume weighting is enabled, or by 1 otherwise; ignore the first intrabar and ties; if T1 data is unavailable, use the sign of the chart-bar close change multiplied by chart-bar volume, or 0 when the close is unchanged or the prior close is unavailable. Use available lower-timeframe T1 bars within each chart bar, including a still-forming T1 bar when available.
Calculation: CVD = cumulative sum of delta on chart bars, starting from zero.
Calculation: slope ratio = clamp(slope-ratio midpoint + EMA(normalized CVD change, slope lookback) / slope-ratio divisor, 0, 1), where normalized CVD change = (CVD − CVD[1]) / EMA(abs(CVD − CVD[1]), slope lookback), using 0 when the denominator is zero or the prior CVD is unavailable.
Calculation: divergence strength(price change, CVD change) = clamp(50 × ((1 − exp(−abs(price change) / ATR(ATR lookback))) + (1 − exp(−abs(CVD change) / (standard deviation(delta, delta standard-deviation lookback) × CVD strength scaling parameter)))), 0, 100); use 0 for either normalized move when its denominator is zero.
