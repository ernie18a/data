Calculation: Return(source, return lookback) = (source - source[return lookback]) * 100 / source, with lookback measured in chart bars
Calculation: Relative return = Return(chart close, return lookback) - Return(T1 still-forming close sampled on chart bars, return lookback)
Long: MA(Return(chart close, return lookback), MA type, MA lookback) crosses above MA(Return(T1 still-forming close sampled on chart bars, return lookback), same MA type and lookback)
Short: MA(Return(chart close, return lookback), MA type, MA lookback) crosses below MA(Return(T1 still-forming close sampled on chart bars, return lookback), same MA type and lookback)
Long: datetime is within the configured date range AND ((stock/index-return comparison and MA comparison are selected AND MA(Return(chart close, return lookback), MA type, MA lookback) > MA(Return(T1 still-forming close sampled on chart bars, return lookback), same MA type and lookback)) OR (stock/index-return comparison and raw-return comparison are selected AND Return(chart close, return lookback) > Return(T1 still-forming close sampled on chart bars, return lookback)) OR (relative-return comparison is selected AND Relative return > MA(Relative return, MA type, MA lookback)))
Exit: Long, (stock/index-return comparison and MA comparison are selected AND MA(Return(chart close, return lookback), MA type, MA lookback) < MA(Return(T1 still-forming close sampled on chart bars, return lookback), same MA type and lookback)) OR (stock/index-return comparison and raw-return comparison are selected AND Return(chart close, return lookback) < Return(T1 still-forming close sampled on chart bars, return lookback)) OR (relative-return comparison is selected AND Relative return < MA(Relative return, MA type, MA lookback))
