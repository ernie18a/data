Calculation: Eligible bar = volume > 0 AND chart timeframe is T1 or T2
Calculation: Doji = high - low < doji ATR multiple * ATR(ATR lookback)
Calculation: Close-position score = NA outside an eligible bar; if Doji, sign(open - close[1]) * doji-gap score magnitude; otherwise, if high > low, 2 * (close - low) / (high - low) - 1, else 0
Calculation: Wick-absorption score = NA outside an eligible bar; when not Doji and high > low, clamp(((lower wick - upper wick) / (high - low)) * (1 + abs(close - open) / (high - low)) / 2, -1, 1); when Doji, clamp((lower wick - upper wick) / (lower wick + upper wick) * doji-wick factor, -1, 1) if total wick > 0, else 0; upper wick = high - max(open, close), lower wick = min(open, close) - low
Calculation: Opening-phase volume = sum of volume from the first opening-phase count of T4 intrabars within the current T1 or T2 chart bar
Calculation: Discretionary-phase volume = sum of volume from the next discretionary-phase count of T4 intrabars within the current T1 or T2 chart bar
Calculation: Conviction-phase volume = sum of volume from the remaining T4 intrabars within the current T1 or T2 chart bar
Calculation: Event bar = abs(open - close[1]) / ATR(ATR lookback) > event-gap ATR multiple OR (SMA(Opening-phase volume, shared averaging lookback) > 0 AND Opening-phase volume / SMA(Opening-phase volume, shared averaging lookback) > opening-volume surprise multiple)
Calculation: Market regime = trending if ADX(ADX lookback) > trending ADX boundary AND ATR(ATR lookback) / SMA(ATR(ATR lookback), shared averaging lookback) > trending ATR-ratio boundary; ranging if ADX(ADX lookback) < ranging ADX boundary AND that ATR ratio < ranging ATR-ratio boundary; otherwise transitional
Calculation: Intrabar pressure score = NA outside an eligible bar or when T3 intrabar count is below its minimum; on each eligible chart bar, use all available T3 intrabars within that bar, including any still-forming intrabar; for each intrabar i, b = (closeᵢ - lowᵢ) / (highᵢ - lowᵢ) if its range is positive, else 0.5; t = 1 if closeᵢ > prior close, 0 if closeᵢ < prior close, else b; prior close for the first intrabar is the previous chart close, or its own close if unavailable; h = (b + t) / 2; k = 1 / (1 + max(0, rangeᵢ / mean T3 range - 1)) if mean T3 range > 0, else range-confidence fallback; score = sum(volumeᵢ * (2h - 1) * k) / sum(volumeᵢ * k); multiply by the VWAP-disagreement factor if (score > 0 AND chart close <= volume-weighted mean of (high + low + close) / 3) OR (score <= 0 AND chart close > that mean)
Calculation: Intrabar volume-path score = NA outside an eligible bar, when T4 intrabar count is below its minimum, when the close-position score is NA, or when total T4 volume is zero; on each eligible chart bar, use all available T4 intrabars within that bar, including any still-forming intrabar; raw volume score = (opening weight * Opening-phase volume + discretionary weight * Discretionary-phase volume + conviction weight * Conviction-phase volume) / total T4 volume, with event-specific weights on an Event bar and non-event weights otherwise; direction = sign(last T4 close - T4 close at max(0, count - conviction-reference offset)), or sign(Close-position score) if equal; score = clamp(raw volume score * direction, -1, 1)
Calculation: Intrabar price-path score = NA outside an eligible bar or when T4 intrabar count is below the path minimum; on each eligible chart bar, use all available T4 intrabars within that bar, including any still-forming intrabar; direction = sign(last T4 close - first T4 close); path fraction = count of consecutive T4 close changes matching that direction / (count - 1); midpoint = floor(count / 2), bounded from 1 to count - 2; scale = chart high - low if positive, else ATR(ATR lookback); early slope = (midpoint close - first close) / (midpoint * scale); late slope = (last close - midpoint close) / ((count - 1 - midpoint) * scale); score = clamp(direction * path fraction + acceleration factor * clamp(late slope - early slope, -1, 1), -1, 1)
Calculation: Quality score = clamp(eligibility factor * intrabar-coverage quality * phase quality * liquidity quality * doji quality * regime quality, 0, 1), where eligibility factor is 1 on an eligible bar and 0 otherwise; T3 coverage = min(1, T3 count / expected T3 count); T3 quality is the no-T3 quality below the minimum count, otherwise the high-coverage multiplier * coverage if HHI < low-HHI boundary, the mid-coverage multiplier * coverage if HHI < upper-HHI boundary, or the low-coverage multiplier * coverage; HHI = sum of squared T3 volume shares, or the default equal-share HHI if total T3 volume is zero; phase quality is structural-gap quality if abs(open - close[1]) / ATR(ATR lookback) > structural-gap ATR multiple, else event quality on an Event bar, else 1; HHI liquidity quality is 0 if HHI > HHI-abort boundary, else abort-band quality if HHI > HHI-abort boundary * half-abort factor, else liquid-band quality if HHI > HHI-liquid boundary, else 1; Amihud quality is the Amihud penalty if PercentRank(abs(close / close[1] - 1) / (volume / volume-unit scale), Amihud lookback) > Amihud rank boundary, else 1; liquidity quality = HHI liquidity quality * Amihud quality; doji quality is the doji penalty on a Doji, else 1; regime quality is transitional-regime quality in a transitional regime, else other-regime quality
Calculation: Adjusted composite score = NA unless the bar is eligible, Quality score >= suppression boundary, HHI <= HHI-abort boundary, and available dimension weights sum to more than zero; otherwise clamp the weighted mean of the available Close-position, Wick-absorption, Intrabar pressure, Intrabar volume-path, and Intrabar price-path scores to [-1, 1]. Use separate manual weights for each score when automatic regime weights are disabled or the regime is transitional; otherwise use the separate ranging and trending weights for each score. Exclude unavailable scores and their weights from the weighted mean. Regime weights are selected using Market regime.
