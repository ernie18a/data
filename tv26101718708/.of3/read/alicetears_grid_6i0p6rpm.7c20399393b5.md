Calculation: baseline = open of the still-forming T1 bar, sampled on chart bars, when the session filter is disabled; otherwise, open of the first chart bar in each selected session
Calculation: grid level(side,n) = baseline × (1 + side-sign × n × grid-step-parameter / 100), where side-sign is +1 for upper/short levels and −1 for lower/long levels, and n ranges from 0 through the max-grid-lines parameter
Long: for each lower grid level n not already triggered, (entry-reversal mode enabled AND a prior close was below grid level(long,n) AND close > grid level(long,n) OR entry-reversal mode disabled AND close[1] >= grid level(long,n) AND close < grid level(long,n)) AND (date-range filter disabled OR datetime is within the configured date range) AND (session filter disabled OR the chart bar is within the configured session)
Short: for each upper grid level n not already triggered, (entry-reversal mode enabled AND a prior close was above grid level(short,n) AND close < grid level(short,n) OR entry-reversal mode disabled AND close[1] <= grid level(short,n) AND close > grid level(short,n)) AND (date-range filter disabled OR datetime is within the configured date range) AND (session filter disabled OR the chart bar is within the configured session)
Exit: short, for a position entered at upper grid level n, (TP-reversal mode enabled AND close[1] < grid level(short,n−1) AND close > grid level(short,n−1) AND (trailing disabled OR, after activation at that signal close, high >= lowest(low since activation) + activation close × trailing-offset-parameter / 100)) OR (TP-reversal mode disabled AND (trailing disabled AND close <= grid level(short,n−1) OR trailing enabled AND, after price reaches grid level(short,n−1), high >= lowest(low since target activation) + close × trailing-offset-parameter / 100)) OR (manual stop loss enabled AND close >= grid level(short,n) × (1 + grid-step-parameter × stop-loss-multiplier / 100)) OR (TP-reversal mode enabled AND trailing enabled AND the trail is armed AND high >= grid level(short,n) × (1 + grid-step-parameter × stop-loss-multiplier / 100)) OR (force-close-at-session-end enabled AND session filter enabled AND the prior chart bar was in session AND the current chart bar is outside session)
Exit: long, for a position entered at lower grid level n, (TP-reversal mode enabled AND close[1] > grid level(long,n−1) AND close < grid level(long,n−1) AND (trailing disabled OR, after activation at that signal close, low <= highest(high since activation) − activation close × trailing-offset-parameter / 100)) OR (TP-reversal mode disabled AND (trailing disabled AND close >= grid level(long,n−1) OR trailing enabled AND, after price reaches grid level(long,n−1), low <= highest(high since target activation) − close × trailing-offset-parameter / 100)) OR (manual stop loss enabled AND close <= grid level(long,n) × (1 − grid-step-parameter × stop-loss-multiplier / 100)) OR (TP-reversal mode enabled AND trailing enabled AND the trail is armed AND low <= grid level(long,n) × (1 − grid-step-parameter × stop-loss-multiplier / 100)) OR (force-close-at-session-end enabled AND session filter enabled AND the prior chart bar was in session AND the current chart bar is outside session)
