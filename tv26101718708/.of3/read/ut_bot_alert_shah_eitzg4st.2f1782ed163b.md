Calculation: ATR trailing stop = initialize to close − key parameter × ATR(ATR lookback); on each later chart bar, if close and prior close are above the previous stop, use max(previous stop, close − key parameter × ATR); otherwise, if both are below the previous stop, use min(previous stop, close + key parameter × ATR); otherwise use close − key parameter × ATR if close is above the previous stop, else close + key parameter × ATR
Calculation: Long target n = entry price + profit-distance parameter n (n = 1 through 5; distances increase with n)
Calculation: Short target n = entry price − profit-distance parameter n (n = 1 through 5; distances increase with n)
Calculation: Long dynamic stop = Long target 3 if Long target 4 has been hit since entry; otherwise Long target 2 if Long target 3 has been hit since entry; otherwise Long target 1 if Long target 2 has been hit since entry; otherwise entry price if Long target 1 has been hit since entry; otherwise entry price − initial stop-distance parameter
Calculation: Short dynamic stop = Short target 3 if Short target 4 has been hit since entry; otherwise Short target 2 if Short target 3 has been hit since entry; otherwise Short target 1 if Short target 2 has been hit since entry; otherwise entry price if Short target 1 has been hit since entry; otherwise entry price + initial stop-distance parameter
Long: close crosses above ATR trailing stop AND EMA(close, fast lookback) > EMA(close, slow lookback) AND close > EMA(close, slow lookback) AND EMA(close, fast lookback, T1 still-forming bar, sampled on chart bars) > EMA(close, slow lookback, T1 still-forming bar, sampled on chart bars) AND ADX(ADX lookback) > ADX threshold parameter AND Supertrend(factor parameter, ATR lookback parameter) is bullish (direction < 0) AND volume > SMA(volume, volume lookback) AND datetime is within either session-window parameter in the exchange timezone AND no previous entry exists or more than the cooldown parameter in chart bars has elapsed since the most recent entry
Short: close crosses below ATR trailing stop AND EMA(close, fast lookback) < EMA(close, slow lookback) AND close < EMA(close, slow lookback) AND EMA(close, fast lookback, T1 still-forming bar, sampled on chart bars) < EMA(close, slow lookback, T1 still-forming bar, sampled on chart bars) AND ADX(ADX lookback) > ADX threshold parameter AND Supertrend(factor parameter, ATR lookback parameter) is bearish (direction > 0) AND volume > SMA(volume, volume lookback) AND datetime is within either session-window parameter in the exchange timezone AND no previous entry exists or more than the cooldown parameter in chart bars has elapsed since the most recent entry
Exit: Long, high >= any Long target 1 through 5 OR low <= Long dynamic stop
Exit: Short, low <= any Short target 1 through 5 OR high >= Short dynamic stop
