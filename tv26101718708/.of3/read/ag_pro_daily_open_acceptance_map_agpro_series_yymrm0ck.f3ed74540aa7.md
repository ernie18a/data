Calculation: T1 open = open of the current, still-forming T1 bar, sampled on chart bars
Calculation: open-distance threshold = max(minimum price increment × minimum-increment multiplier parameter, ATR(ATR-length parameter on chart bars) × selected tolerance parameter (separate Normal and Strict parameters, selected by filter mode))
Calculation: first bullish reclaim event = confirmed intraday chart bar AND no earlier bullish reclaim event since the current T1 bar began AND some chart bar since it began had low < that bar's T1 open − that bar's open-distance threshold × probe-fraction parameter AND crossover(close, T1 open) AND close > T1 open + open-distance threshold
Calculation: first bearish reclaim event = confirmed intraday chart bar AND no earlier bearish reclaim event since the current T1 bar began AND some chart bar since it began had high > that bar's T1 open + that bar's open-distance threshold × probe-fraction parameter AND crossunder(close, T1 open) AND close < T1 open − open-distance threshold
Calculation: bullish acceptance = intraday chart bar AND close > T1 open + open-distance threshold AND the number of consecutive chart bars since the current T1 bar began, through the current bar, whose closes exceeded their T1 open plus their open-distance threshold is at least max(minimum consecutive-bars parameter, selected hold-bars parameter (separate Normal and Strict parameters, selected by filter mode) − reclaim-reduction parameter if the reclaim-bonus parameter is enabled and a first bullish reclaim event has occurred this T1 bar, otherwise 0)
Calculation: bearish acceptance = intraday chart bar AND close < T1 open − open-distance threshold AND the number of consecutive chart bars since the current T1 bar began, through the current bar, whose closes were below their T1 open minus their open-distance threshold is at least max(minimum consecutive-bars parameter, selected hold-bars parameter (separate Normal and Strict parameters, selected by filter mode) − reclaim-reduction parameter if the reclaim-bonus parameter is enabled and a first bearish reclaim event has occurred this T1 bar, otherwise 0)
Calculation: bullish rejection trigger = confirmed intraday chart bar AND crossover(close, T1 open) AND barsSince(low < T1 open − open-distance threshold) <= selected rejection-lookback parameter (separate Normal and Strict parameters, selected by filter mode) AND NOT bullish acceptance AND NOT first bullish reclaim event
Calculation: bearish rejection trigger = confirmed intraday chart bar AND crossunder(close, T1 open) AND barsSince(high > T1 open + open-distance threshold) <= selected rejection-lookback parameter (separate Normal and Strict parameters, selected by filter mode) AND NOT bearish acceptance AND NOT first bearish reclaim event
Calculation: daily-open state = bullish acceptance if true, otherwise bearish acceptance if true, otherwise the latest rejection direction while its rejection timer is positive, otherwise neutral; a bullish rejection trigger sets the direction to Down Reject and a bearish rejection trigger sets it to Up Reject, each trigger sets the timer to the rejection-duration parameter, each later chart bar without a trigger decrements the timer before state selection, and direction and timer reset when T1 changes
Long: first bullish reclaim event OR daily-open state is bullish acceptance OR daily-open state is Down Reject
Short: first bearish reclaim event OR daily-open state is bearish acceptance OR daily-open state is Up Reject
