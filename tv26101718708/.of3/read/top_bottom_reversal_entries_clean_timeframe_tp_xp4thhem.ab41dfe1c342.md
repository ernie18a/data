Calculation: candle range = high - low
Calculation: RSI value = RSI(close, RSI lookback)
Calculation: ATR value = ATR(high, low, close, ATR lookback)
Calculation: preceding swing low = lowest(low[1], swing lookback)
Calculation: preceding swing high = highest(high[1], swing lookback)
Calculation: long reversal score = long RSI weight * (RSI value <= oversold threshold OR RSI value crosses above oversold threshold OR (RSI value < long rebound threshold AND RSI value > RSI value[1])) + long lower-wick weight * (candle range > 0 AND (min(open, close) - low) / candle range >= minimum wick fraction AND close > low + candle range * rejection close fraction) + long swing-low sweep weight * (low < preceding swing low AND close > preceding swing low) + long lower-band weight * (low <= lower Bollinger Band(close, band lookback, band deviation multiplier) OR close <= lower Bollinger Band(close, band lookback, band deviation multiplier) + ATR value * near-band ATR fraction) + long bullish-engulfing weight * (close > open AND close[1] < open[1] AND close > open[1] AND open <= close[1]) + long higher-close weight * (close > close[1]) + long range weight * (candle range > ATR value * minimum candle-range ATR fraction)
Calculation: short reversal score = short RSI weight * (RSI value >= overbought threshold OR RSI value crosses below overbought threshold OR (RSI value > short reversal threshold AND RSI value < RSI value[1])) + short upper-wick weight * (candle range > 0 AND (high - max(open, close)) / candle range >= minimum wick fraction AND close < high - candle range * rejection close fraction) + short swing-high sweep weight * (high > preceding swing high AND close < preceding swing high) + short upper-band weight * (high >= upper Bollinger Band(close, band lookback, band deviation multiplier) OR close >= upper Bollinger Band(close, band lookback, band deviation multiplier) - ATR value * near-band ATR fraction) + short bearish-engulfing weight * (close < open AND close[1] > open[1] AND close < open[1] AND open >= close[1]) + short lower-close weight * (close < close[1]) + short range weight * (candle range > ATR value * minimum candle-range ATR fraction)
Long: chart bar confirmed at close AND long reversal score >= long minimum score AND (volume filter disabled OR volume > SMA(volume, volume-average lookback) * volume multiplier) AND (soft EMA context enabled OR close > EMA(close, EMA lookback)) AND (no previous long signal OR chart bars since previous long signal >= signal cooldown) AND (alternation disabled OR last signal was not long)
Short: chart bar confirmed at close AND short reversal score >= short minimum score AND (volume filter disabled OR volume > SMA(volume, volume-average lookback) * volume multiplier) AND (soft EMA context enabled OR close < EMA(close, EMA lookback)) AND (no previous short signal OR chart bars since previous short signal >= signal cooldown) AND (alternation disabled OR last signal was not short)
Exit: long, TP/SL system enabled AND exit clearing enabled AND (low <= entry price - ATR at entry * stop-loss ATR multiplier selected by automatic chart-timeframe mode or manual mode OR high >= entry price + ATR at entry * TP3 ATR multiplier selected by automatic chart-timeframe mode or manual mode)
Exit: short, TP/SL system enabled AND exit clearing enabled AND (high >= entry price + ATR at entry * stop-loss ATR multiplier selected by automatic chart-timeframe mode or manual mode OR low <= entry price - ATR at entry * TP3 ATR multiplier selected by automatic chart-timeframe mode or manual mode)
