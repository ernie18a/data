Calculation: VolumeProfile(T1, lookback, profile rows) = over chart bars of the last lookback completed T1 sessions, volume split over profile rows equal price bins spanning the high-low range of those bars, each bar's volume divided evenly among the bins from its low bin to its high bin
Calculation: POC(T1, lookback, profile rows) = center price of the highest-volume bin of VolumeProfile(T1, lookback, profile rows)
Calculation: VAH(T1, lookback, profile rows, value area %) = top price of the value area of VolumeProfile(T1, lookback, profile rows), grown from the POC bin by repeatedly adding the larger adjacent bin (above or below) until it holds value area % of total volume
Calculation: VAL(T1, lookback, profile rows, value area %) = bottom price of the value area of VolumeProfile(T1, lookback, profile rows), grown from the POC bin by repeatedly adding the larger adjacent bin (above or below) until it holds value area % of total volume
Calculation: NakedPOC(T1, profile rows) = for each completed T1 session, POC of the VolumeProfile of that single session with profile rows bins; a price is removed once a chart bar has high >= price and low <= price
Calculation: HVNMidpoint(T1, lookback, profile rows, peak threshold, peak window, min prominence, zone width, max zones) = midpoints of up to max zones HVN zones of VolumeProfile(T1, lookback, profile rows) with the highest peak volumes; a peak is a bin whose volume >= peak threshold * highest bin volume and is greater than every bin within peak window bins on each side, and it qualifies if its prominence >= min prominence * peak volume, where prominence = peak volume minus the higher of the lowest volumes between the peak and the nearest higher bin on each side; a zone is the contiguous bins around the peak with volume >= peak volume - zone width * prominence, and its midpoint is the average of the zone's bottom and top prices
Calculation: BreakoutLong = close crosses above VAH(T1, lookback, profile rows, value area %) AND volume > SMA(volume, volume average length) * breakout volume multiple AND trade mode allows breakout
Calculation: BreakoutShort = close crosses below VAL(T1, lookback, profile rows, value area %) AND volume > SMA(volume, volume average length) * breakout volume multiple AND trade mode allows breakout
Calculation: LongStop = min(VAH(T1, lookback, profile rows, value area %) - stop ATR multiple * ATR(ATR length), last confirmed PivotLow(low, pivot length, pivot length)) if BreakoutLong, else min(low - fade stop ATR multiple * ATR(ATR length), last confirmed PivotLow(low, pivot length, pivot length)); fade stop ATR multiple is half the stop ATR multiple; a missing pivot low is ignored
Calculation: ShortStop = max(VAL(T1, lookback, profile rows, value area %) + stop ATR multiple * ATR(ATR length), last confirmed PivotHigh(high, pivot length, pivot length)) if BreakoutShort, else max(high + fade stop ATR multiple * ATR(ATR length), last confirmed PivotHigh(high, pivot length, pivot length)); a missing pivot high is ignored
Calculation: LongTarget = if BreakoutLong, the nearer to entry price of the nearest HVNMidpoint above entry price and, if naked POC targeting is on, the nearest NakedPOC above entry price, or if neither exists, entry price + R multiple * (entry price - LongStop); otherwise POC(T1, lookback, profile rows)
Calculation: ShortTarget = if BreakoutShort, the nearer to entry price of the nearest HVNMidpoint below entry price and, if naked POC targeting is on, the nearest NakedPOC below entry price, or if neither exists, entry price - R multiple * (ShortStop - entry price); otherwise POC(T1, lookback, profile rows)
Long: ((low[1] < VAL(T1, lookback, profile rows, value area %) AND close > VAL(T1, lookback, profile rows, value area %) AND close > close[1] AND RSI(close, RSI length) <= RSI oversold level AND trade mode allows fade) OR BreakoutLong) AND LongStop < close AND (single-position restriction off OR no position is open)
Short: ((high[1] > VAH(T1, lookback, profile rows, value area %) AND close < VAH(T1, lookback, profile rows, value area %) AND close < close[1] AND RSI(close, RSI length) >= RSI overbought level AND trade mode allows fade) OR BreakoutShort) AND ShortStop > close AND (single-position restriction off OR no position is open)
Exit: Long, low <= LongStop(entry bar) OR high >= LongTarget(entry bar)
Exit: Short, high >= ShortStop(entry bar) OR low <= ShortTarget(entry bar)
