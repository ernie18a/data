Calculation: Anchor return(X) = the percent change of X's current chart-bar close from its selected anchor price; the anchor is the current anchor-period open, the configured cash-session first-bar open, or the prior completed session close, with other-timeframe values sampled on chart bars using the still-forming bar for opens and the last completed bar for prior closes.
Calculation: Gap-adjusted return(X) = close(X) / close(X)[1] − 1, set to zero when an intraday gap exceeds the gap-duration parameter.
Calculation: Residual z-score = [Anchor return(symbol) − Beta(gap-adjusted symbol returns, gap-adjusted Nasdaq returns, beta lookback, through prior chart bar) × Anchor return(Nasdaq)] / [StDev(100 × (gap-adjusted symbol return − Beta × gap-adjusted Nasdaq return), beta lookback) × sqrt(max(chart bars since anchor, 1))], multiplied by the damping factor when this undamped score is positive and the current chart close is below SMA(close, damping lookback, T1, last completed T1 bar), sampled on chart bars.
Calculation: Lead state = activates after the residual z-score is above the residual threshold for the persistence count of consecutive chart bars, remains active while the score is above zero, and resets when the score is zero or undefined.
Calculation: Bar residual z-score = 100 × [(close(symbol) / close(symbol)[1] − 1) − Beta(gap-adjusted symbol returns, gap-adjusted Nasdaq returns, beta lookback, through prior chart bar) × (close(Nasdaq) / close(Nasdaq)[1] − 1)] / StDev(100 × (gap-adjusted symbol return − Beta × gap-adjusted Nasdaq return), beta lookback).
Long: Lead state AND close(symbol) ≥ Highest(close(symbol), chart bars since anchor) AND close(Nasdaq) < Highest(close(Nasdaq), chart bars since anchor) AND Beta is defined AND (Correlation(gap-adjusted symbol returns, gap-adjusted Nasdaq returns, link lookback, through prior chart bar) is undefined OR its value ≥ minimum link correlation and < tracker correlation threshold). The link lookback is at least the beta lookback.
Short: Residual z-score < −residual threshold AND Beta is defined AND (Correlation(gap-adjusted symbol returns, gap-adjusted Nasdaq returns, link lookback, through prior chart bar) is undefined OR its value ≥ minimum link correlation and < tracker correlation threshold). The link lookback is at least the beta lookback.
Long: Anchor return(Nasdaq) ≤ −residual threshold × StDev(100 × gap-adjusted Nasdaq returns, beta lookback) × sqrt(max(chart bars since anchor, 1)) AND Anchor return(symbol) ≥ 0 AND Correlation(gap-adjusted symbol returns, gap-adjusted Nasdaq returns, link lookback, through prior chart bar) > 0 AND NOT (Beta is defined AND that correlation ≥ tracker correlation threshold).
Long: Bar residual z-score ≥ bar-alpha threshold AND Beta is defined AND (Correlation(gap-adjusted symbol returns, gap-adjusted Nasdaq returns, link lookback, through prior chart bar) is undefined OR its value ≥ minimum link correlation and < tracker correlation threshold). The link lookback is at least the beta lookback.
Short: Bar residual z-score ≤ −bar-alpha threshold AND Beta is defined AND (Correlation(gap-adjusted symbol returns, gap-adjusted Nasdaq returns, link lookback, through prior chart bar) is undefined OR its value ≥ minimum link correlation and < tracker correlation threshold). The link lookback is at least the beta lookback.
