Calculation: prior structural bias = persistent bias at the start of the chart bar, initially neutral; after each bar, if neutral set it bullish when close > the latest confirmed pivot high, otherwise bearish when close < the latest confirmed pivot low; if bullish, switch it to bearish when close < the latest confirmed pivot low; if bearish, switch it to bullish when close > the latest confirmed pivot high; otherwise retain it. A pivot must exist for its comparison; pivot highs and lows use the same swing-lookback parameter on each side.
Long: prior structural bias is bullish AND a confirmed pivot low exists AND close < the latest confirmed pivot low AND EMA(close, shorter lookback), computed on T1 bars and sampled from the last completed T1 bar on each chart bar, > EMA(close, longer lookback), computed on T1 bars and sampled from the last completed T1 bar on each chart bar, AND (session filter disabled OR the chart bar is within US Eastern session window 1 OR the chart bar is within US Eastern session window 2)
Short: prior structural bias is bearish AND a confirmed pivot high exists AND close > the latest confirmed pivot high AND EMA(close, shorter lookback), computed on T1 bars and sampled from the last completed T1 bar on each chart bar, < EMA(close, longer lookback), computed on T1 bars and sampled from the last completed T1 bar on each chart bar, AND (session filter disabled OR the chart bar is within US Eastern session window 1 OR the chart bar is within US Eastern session window 2)
Exit: long, low <= entry price - stop-distance parameter OR high >= entry price + target-distance parameter
Exit: short, high >= entry price + stop-distance parameter OR low <= entry price - target-distance parameter
