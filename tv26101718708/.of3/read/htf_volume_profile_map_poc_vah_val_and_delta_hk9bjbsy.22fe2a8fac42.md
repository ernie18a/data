Calculation: T1 profile row size = if the row-size mode selects automatic sizing, ceil(max(minimum tick, ATR(lookback, T1, last completed bar) / auto-row-count) / minimum tick) * minimum tick; otherwise manual ticks per row * minimum tick
Calculation: T1 profile row volumes = On chart bars, accumulate completed T2 intrabars into their containing T1 profile; split each accepted intrabar's volume equally across row indices from floor(low / row size) through floor(high / row size); classify shares as buying when close > open and selling when close < open; for a doji, compare its close with the preceding accepted T2 intrabar close in that T1 profile, carrying the preceding direction if equal and defaulting to buying if there is no preceding intrabar; skip zero-volume intrabars and intrabars whose touched rows or resulting profile row span exceeds the maximum-row guard parameter
Calculation: T1 profile POC, VAH and VAL = For each completed T1 profile, select the highest-volume row as POC, choosing the lowest row index on a tie; start the value area at POC and repeatedly add the adjacent row with greater volume, choosing upward on a tie, until included volume reaches the value-area percentage of total volume or the maximum-row guard parameter is reached; POC is (POC row index + 0.5) * row size, VAH is (highest included row index + 1) * row size, and VAL is the lowest included row index * row size
Calculation: T1 profile delta percentage = 100 * (total buying volume - total selling volume) / total profile volume
Calculation: T1 profile row delta = row buying volume - row selling volume
Long: A completed T1 profile exists AND (chart close >= its POC OR its delta percentage >= the directional delta threshold OR any nonempty row in a completed T1 profile has row delta >= 0)
Short: A completed T1 profile exists AND (chart close < its POC OR its delta percentage <= -the directional delta threshold OR any nonempty row in a completed T1 profile has row delta < 0)
