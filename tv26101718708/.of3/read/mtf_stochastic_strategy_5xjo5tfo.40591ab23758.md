Calculation: Higher-timeframe K = linear regression on chart bars of the still-forming T1 bar's SMA(Stochastic(close, high, low, lookback), K smoothing lookback), using the same lookback
Calculation: Higher-timeframe D = linear regression on chart bars of the still-forming T1 bar's SMA(SMA(Stochastic(close, high, low, lookback), K smoothing lookback), D smoothing lookback), using the same lookback
Long: crossover(Higher-timeframe K, midline) AND SMA(Stochastic(close, high, low, lookback), K smoothing lookback) > midline AND change(SMA(Stochastic(close, high, low, lookback), K smoothing lookback), change lookback) > 0 AND SMA(Stochastic(close, high, low, lookback), K smoothing lookback) > SMA(SMA(Stochastic(close, high, low, lookback), K smoothing lookback), D smoothing lookback) AND Higher-timeframe K > Higher-timeframe D
Short: crossunder(Higher-timeframe D, midline) AND SMA(Stochastic(close, high, low, lookback), K smoothing lookback) < midline AND change(SMA(Stochastic(close, high, low, lookback), K smoothing lookback), change lookback) < 0 AND SMA(Stochastic(close, high, low, lookback), K smoothing lookback) < SMA(SMA(Stochastic(close, high, low, lookback), K smoothing lookback), D smoothing lookback) AND Higher-timeframe K < Higher-timeframe D
Exit: long, crossunder(Higher-timeframe D, upper exit threshold)
Exit: short, crossover(Higher-timeframe K, lower exit threshold)
