Calculation: McGinley Dynamic(source, lookback, K) = SMA(source, lookback) when the prior value is unavailable; otherwise prior value + (source - prior value) / (K × lookback × (source / prior value)^4), retaining the prior value when the denominator is zero or undefined
Calculation: Signal entry reference = close[1] on the chart bar where the latest signal fires
Calculation: Long target(multiplier) = signal entry reference + ATR(lookback) on the signal chart bar × multiplier
Calculation: Short target(multiplier) = signal entry reference - ATR(lookback) on the signal chart bar × multiplier
Long: McGinley Dynamic(source, shorter fast lookback, shared K) > McGinley Dynamic(source, longer slow lookback, shared K)
Short: McGinley Dynamic(source, shorter fast lookback, shared K) <= McGinley Dynamic(source, longer slow lookback, shared K)
Long: McGinley Dynamic(source, shorter fast lookback, shared K)[1] > McGinley Dynamic(source, longer slow lookback, shared K)[1] AND McGinley Dynamic(source, shorter fast lookback, shared K)[2] <= McGinley Dynamic(source, longer slow lookback, shared K)[2] AND (no prior long signal OR chart bars since prior long signal >= cooldown bars) AND (HTF filter disabled OR source on T1's last completed bar, sampled on chart bars > McGinley Dynamic(source, fast lookback, shared K) calculated on T1 bars and sampled on chart bars from T1's last completed bar)
Short: McGinley Dynamic(source, shorter fast lookback, shared K)[1] < McGinley Dynamic(source, longer slow lookback, shared K)[1] AND McGinley Dynamic(source, shorter fast lookback, shared K)[2] >= McGinley Dynamic(source, longer slow lookback, shared K)[2] AND (no prior short signal OR chart bars since prior short signal >= cooldown bars) AND (HTF filter disabled OR source on T1's last completed bar, sampled on chart bars < McGinley Dynamic(source, fast lookback, shared K) calculated on T1 bars and sampled on chart bars from T1's last completed bar)
Exit: long, high >= Long target(first target multiplier) OR high >= Long target(second target multiplier) OR high >= Long target(third target multiplier)
Exit: short, low <= Short target(first target multiplier) OR low <= Short target(second target multiplier) OR low <= Short target(third target multiplier)
