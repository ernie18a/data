Calculation: PairClose(T) = close(A,T) + close(B,T), replacing each missing close with the missing-close fallback; sample the current T bar on chart bars (developing in realtime and last completed historically)
Calculation: CustomST(x, ATR lookback, multiplier) = maintain separate bands and direction per T series on chart bars, with x the chart-bar PairClose(T) series; initialize direction bearish and missing bands to raw bands; on each bar let q=RMA(abs(x-x[1]), ATR lookback), raw upper=x+multiplier*q, raw lower=x-multiplier*q, upper=min(raw upper, prior upper), lower=max(raw lower, prior lower); if prior direction is bearish and x>upper, set direction bullish and lower=raw lower; if prior direction is bullish and x<lower, set direction bearish and upper=raw upper; otherwise retain direction
