Calculation: Bull bias = ALMA(close, fast ALMA lookback, fast ALMA offset, ALMA sigma) > ALMA(close, slow ALMA lookback, slow ALMA offset, ALMA sigma) AND linear regression(close, regression lookback, offset 0) > linear regression(close, regression lookback, offset 1) AND (HTF gate disabled OR ALMA(close, fast ALMA lookback, fast ALMA offset, ALMA sigma, T1, last completed bar) > ALMA(close, slow ALMA lookback, slow ALMA offset, ALMA sigma, T1, last completed bar); the T1 values are sampled on chart bars, and fast ALMA lookback is shorter than slow ALMA lookback
Calculation: Bear bias = ALMA(close, fast ALMA lookback, fast ALMA offset, ALMA sigma) < ALMA(close, slow ALMA lookback, slow ALMA offset, ALMA sigma) AND linear regression(close, regression lookback, offset 0) < linear regression(close, regression lookback, offset 1) AND (HTF gate disabled OR ALMA(close, fast ALMA lookback, fast ALMA offset, ALMA sigma, T1, last completed bar) < ALMA(close, slow ALMA lookback, slow ALMA offset, ALMA sigma, T1, last completed bar); the T1 values are sampled on chart bars
Calculation: Lower sweep = chart bar is confirmed AND a confirmed PivotLow(low, symmetric pivot lookback, symmetric pivot lookback) exists AND low < the most recent confirmed pivot low AND close > that pivot low
Calculation: Upper sweep = chart bar is confirmed AND a confirmed PivotHigh(high, symmetric pivot lookback, symmetric pivot lookback) exists AND high > the most recent confirmed pivot high AND close < that pivot high
Calculation: Momentum phase impulse = EMA(phase - phase[1], phase impulse lookback), where phase = (RSI(close, phase RSI lookback) - EMA(RSI(close, phase RSI lookback), phase smoothing lookback)) / phase scale; all bars are chart bars
Calculation: Compression = clamp(1 - STDEV(close, short compression lookback) / max(STDEV(close, long compression lookback), minimum price increment), 0, 1), with short compression lookback shorter than long compression lookback
Calculation: Normalized execution slope = (ALMA(close, fast ALMA lookback, fast ALMA offset, ALMA sigma) - ALMA(close, fast ALMA lookback, fast ALMA offset, ALMA sigma)[execution slope lag]) / max(ATR(ATR lookback), minimum price increment)
Calculation: Entry stretch = abs(close - ALMA(close, fast ALMA lookback, fast ALMA offset, ALMA sigma)) / max(ATR(ATR lookback), minimum price increment)
Calculation: Regression channel width = max(STDEV(close - linear regression(close, regression lookback, offset 0), regression lookback), ATR(ATR lookback) * channel ATR floor multiplier) * channel width multiplier
Calculation: Lower channel bound = linear regression(close, regression lookback, offset 0) - regression channel width
Calculation: Upper channel bound = linear regression(close, regression lookback, offset 0) + regression channel width
Calculation: Long score = clamp(bias contribution + HTF contribution + clamp(clamp((ALMA(close, fast ALMA lookback, fast ALMA offset, ALMA sigma) - low) / max(ATR(ATR lookback), minimum price increment), 0, pullback depth cap) / pullback score divisor * pullback score weight, 0, pullback score cap) + (lower sweep ? sweep contribution : 0) + clamp((min(open, close) - low) / max(high - low, minimum price increment) * wick score weight, 0, wick score cap) + (close > ALMA(close, fast ALMA lookback, fast ALMA offset, ALMA sigma) AND close > open AND momentum phase impulse > 0 ? impulse contribution : 0) + clamp((Z-score(nz(volume, 0), volume z-score lookback; zero when standard deviation is zero) + volume z-score offset) * volume score multiplier, 0, volume score cap) + clamp(compression * compression score multiplier, 0, compression score cap) + clamp(normalized execution slope * execution slope score multiplier, 0, execution slope score cap) + clamp(clamp((close - low) / max(high - low, minimum price increment), 0, 1) * reversion score multiplier, 0, reversion score cap) + (session gate disabled OR chart bar is in the configured session window ? session contribution : 0), 0, score cap); used when bull bias holds
Calculation: Short score = clamp(bias contribution + HTF contribution + clamp(clamp((high - ALMA(close, fast ALMA lookback, fast ALMA offset, ALMA sigma)) / max(ATR(ATR lookback), minimum price increment), 0, pullback depth cap) / pullback score divisor * pullback score weight, 0, pullback score cap) + (upper sweep ? sweep contribution : 0) + clamp((high - max(open, close)) / max(high - low, minimum price increment) * wick score weight, 0, wick score cap) + (close < ALMA(close, fast ALMA lookback, fast ALMA offset, ALMA sigma) AND close < open AND momentum phase impulse < 0 ? impulse contribution : 0) + clamp((Z-score(nz(volume, 0), volume z-score lookback; zero when standard deviation is zero) + volume z-score offset) * volume score multiplier, 0, volume score cap) + clamp(compression * compression score multiplier, 0, compression score cap) + clamp(-normalized execution slope * execution slope score multiplier, 0, execution slope score cap) + clamp(clamp((high - close) / max(high - low, minimum price increment), 0, 1) * reversion score multiplier, 0, reversion score cap) + (session gate disabled OR chart bar is in the configured session window ? session contribution : 0), 0, score cap); used when bear bias holds
Calculation: Cooldown satisfied = no earlier long or short impulse event OR the number of chart bars since the most recent earlier long or short impulse event is at least the cooldown length
Calculation: Long entry state = chart bar is confirmed AND cooldown satisfied AND long score >= signal score threshold AND entry stretch <= maximum stretch in ATRs AND close > lower channel bound AND bull bias
Calculation: Short entry state = chart bar is confirmed AND cooldown satisfied AND short score >= signal score threshold AND entry stretch <= maximum stretch in ATRs AND close < upper channel bound AND bear bias
Calculation: Long impulse event = long entry state is true AND its value on the preceding chart bar was false
Calculation: Short impulse event = short entry state is true AND its value on the preceding chart bar was false
Long: long impulse event OR (lower sweep AND bull bias)
Short: short impulse event OR (upper sweep AND bear bias)
