Calculation: VWIR Z = (VWIR raw - SMA(VWIR raw, Z-score lookback)) / (STDEV(VWIR raw, Z-score lookback) if STDEV(VWIR raw, Z-score lookback) > 0, else 1), where VWIR raw = information clarity * (volume / SMA(volume, lookback) if SMA(volume, lookback) > 0, else 1) * LN(close / close[1]), and information clarity = 1 - entropy / log2(bins), where entropy = -SUM(p_i * log2(p_i)) over bins with p_i > 0; p_i is the count of log returns in [lowest log return over lookback + i * bin width, lowest log return over lookback + (i + 1) * bin width) divided by lookback, for i from 0 to bins - 1; bin width = max((highest log return over lookback - lowest log return over lookback) / bins, minimum bin width parameter).
Long: VWIR Z crosses above signal threshold.
Short: VWIR Z crosses below negative signal threshold.
