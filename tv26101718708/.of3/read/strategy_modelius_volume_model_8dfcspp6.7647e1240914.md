Calculation: volume oscillator = use true range when selected or when true-range mode is Auto and volume is unavailable, otherwise use volume; use close as both price bounds for Close source, max(open, close) and min(open, close) for Open / Close source, or high and low for High / Low source; use ATR(rounded threshold lookback) as the threshold and, when normalization is enabled, divide close by that threshold; each bar, set model price to the upper bound if it exceeds prior model price plus threshold, otherwise to the lower bound if it is below prior model price minus threshold, otherwise to prior model price; direction is up or down when model price rises or falls, otherwise retain prior direction; accumulate activity during each uninterrupted direction run, divide by the run's bar count when normalization is enabled, and negate the result only when oscillation is enabled and direction is down
Long: volume oscillator crosses above zero
Short: volume oscillator crosses below zero
Exit: Long, (profit-distance parameter > 0 AND high >= entry price + profit-distance parameter) OR (loss-distance parameter > 0 AND low <= entry price - loss-distance parameter) OR (trailing-activation parameter > 0 AND trailing-offset parameter > 0 AND high has reached entry price + trailing-activation parameter AND low <= highest high since activation - trailing-offset parameter)
Exit: Short, (profit-distance parameter > 0 AND low <= entry price - profit-distance parameter) OR (loss-distance parameter > 0 AND high >= entry price + loss-distance parameter) OR (trailing-activation parameter > 0 AND trailing-offset parameter > 0 AND low has reached entry price - trailing-activation parameter AND high >= lowest low since activation + trailing-offset parameter)
