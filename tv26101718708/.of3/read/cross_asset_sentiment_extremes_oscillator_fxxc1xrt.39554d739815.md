Calculation: External score = mean of available values in the selected equity/index or crypto branch. Equity/index branch: inverse PercentRank(volatility-index close, chart rank lookback); inverse PercentRank(TRIN close, chart rank lookback); inverse PercentRank(put/call ratio, T1 rank lookback); inverse PercentRank(high-yield credit spread, T1 rank lookback); PercentRank(long-term breadth, T1 rank lookback); PercentRank(short-term breadth, T1 rank lookback). Crypto branch: PercentRank(perpetual-to-spot premium, chart rank lookback); PercentRank(U.S.-venue spot premium, chart rank lookback); inverse PercentRank(stablecoin dominance, chart rank lookback); PercentRank(ROC(crypto cross-rate close, crypto momentum lookback), chart rank lookback); inverse PercentRank(dollar-strength close, chart rank lookback). Chart-timeframe ranks run on chart bars. T1 ranks run on T1 bars and are sampled onto chart bars with lookahead off: historical chart bars use the last completed T1 value, while realtime chart bars can use the T1 bar still forming.
Calculation: Internal score = mean of PercentRank(RSI(close, RSI lookback), chart rank lookback), PercentRank(close / SMA(close, extension lookback) - 1, chart rank lookback), and inverse PercentRank(StDev(change(log(close)), realized-volatility lookback), chart rank lookback); all run on chart bars.
Calculation: Composite sentiment oscillator = SMA(weighted mean of external score and internal score, using the external-weight fraction and its complement as weights; use the available score if the other is unavailable; undefined if neither is available), smoothing lookback.
Long: (selected trigger is zone exit AND composite sentiment oscillator crosses above fear threshold) OR (selected trigger is zone entry AND composite sentiment oscillator crosses below fear threshold)
Short: (selected trigger is zone exit AND composite sentiment oscillator crosses below greed threshold) OR (selected trigger is zone entry AND composite sentiment oscillator crosses above greed threshold)
