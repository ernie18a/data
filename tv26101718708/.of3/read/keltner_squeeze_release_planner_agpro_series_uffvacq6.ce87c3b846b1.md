Calculation: ATR-safe = ATR(ATR lookback), or minimum price increment × ATR fallback multiplier when ATR is missing or nonpositive
Calculation: Keltner width rank = clamp((current Keltner width percentage − lowest Keltner width percentage over squeeze lookback) / max(highest − lowest Keltner width percentage over squeeze lookback, width-range floor) × rank scale, rank floor, rank ceiling), where Keltner width percentage = Keltner Channel width / abs(EMA(close, basis lookback)) × percentage scale; undefined when the basis is zero
Calculation: Keltner width expansion ratio = current Keltner Channel width / prior bar's Keltner Channel width, or the expansion-ratio fallback parameter when prior width is nonpositive
Calculation: Release score(direction) = clamp(compression weight × clamp((squeeze threshold − Keltner width rank + compression offset) / max(squeeze threshold + compression offset, compression denominator floor), component floor, component ceiling) + expansion weight × clamp((Keltner width expansion ratio − expansion-score baseline) / expansion-score scale, component floor, component ceiling) + close-pressure weight × clamp(directional channel distance in ATR-safe units / close-pressure scale, component floor, component ceiling) + body weight × clamp((abs(close − open) / max(high − low, minimum price increment)) / body-ratio scale, component floor, component ceiling) + (relative-volume scoring enabled ? volume weight × clamp(relative volume / volume-score scale, component floor, component ceiling) : disabled-volume points) + slope weight × clamp(abs(EMA(close, basis lookback) − EMA(close, basis lookback) at slope lookback ago) / ATR-safe, component floor, component ceiling), score floor, score ceiling), where directional channel distance is (close − upper Keltner Channel) for bullish releases or (lower Keltner Channel − close) for bearish releases, and relative volume is volume / SMA(volume, volume lookback), or its neutral fallback when the average is nonpositive
Calculation: Required release score = minimum ready score + confirmation-mode adjustment, with a lower adjustment for fast confirmation, no adjustment for balanced confirmation, and a higher adjustment for strict confirmation
Long: A bullish release qualifies when every bar in the minimum-squeeze-bars ending on the prior bar has Keltner width rank <= squeeze threshold AND close > upper Keltner Channel + ATR-safe × release-buffer parameter AND Keltner width expansion ratio >= required expansion ratio AND bullish release score >= required release score; or the most recent qualified release is bullish and its release window remains active
Short: A bearish release qualifies when every bar in the minimum-squeeze-bars ending on the prior bar has Keltner width rank <= squeeze threshold AND close < lower Keltner Channel − ATR-safe × release-buffer parameter AND Keltner width expansion ratio >= required expansion ratio AND bearish release score >= required release score; or the most recent qualified release is bearish and its release window remains active
Exit: long, the most recent qualified release is bullish and within its release window AND close < its frozen upper Keltner Channel edge − its frozen ATR-safe × failure give-back parameter
Exit: short, the most recent qualified release is bearish and within its release window AND close > its frozen lower Keltner Channel edge + its frozen ATR-safe × failure give-back parameter
