Calculation: Active range = the selected manual high/low (valid when both are positive and high > low), latest confirmed T1 pivot high/low (same configurable lookback on each side), or T1 lookback highest(high)/lowest(low); compute lookback extrema on chart bars using the equivalent chart-bar count when available, otherwise on T1 bars; sample T1 values on chart bars with lookahead off (historical bars use completed T1 bars; realtime may use the still-forming T1 bar).
Calculation: Goldbach level(q) = rangeLow + (rangeHigh - rangeLow) × q; use separate mirrored fraction parameters for RB, OB, FVG, LV, and BRK, ordered from each range extreme inward as RB, OB, FVG, LV, BRK, with EQ at the midpoint.
Calculation: PO3 state = at each configured T3 anchor-period boundary, set true open to that bar's open, phase to accumulation, Judas direction unset, and bias unresolved; on chart bars, when abs(close - true open) > accumulation threshold × ATR(lookback), set phase to manipulation and Judas direction up if close > true open or down if close < true open; while in manipulation with unresolved bias, resolve bearish when Judas direction is up and close < true open, or bullish when Judas direction is down and close > true open, provided abs(close - true open) >= PO3 displacement threshold × ATR(lookback) and either FVG confirmation is disabled or a matching-polarity FVG exists (bullish: low > high[2] OR low[1] > high[3]; bearish: high < low[2] OR high[1] < low[3]); record abs(close - true open)/ATR(lookback) at resolution.
Calculation: HTF trend = compare close with SMA(close, lookback) on T2, sampled onto chart bars with lookahead off (historical bars use completed T2 bars; realtime may use the still-forming T2 bar); bullish when close > SMA and bearish otherwise.
