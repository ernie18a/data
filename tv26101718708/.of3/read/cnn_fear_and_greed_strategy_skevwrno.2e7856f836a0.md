Calculation: sentiment score = the arithmetic mean of seven scores, each clipped to [0, 100]: momentum score = 50 + momentum / stdev(momentum, normalization lookback) * scaling factor, where momentum = 100 * (equity-market close / SMA(equity-market close, momentum lookback) - 1); strength score = 50 + (strength - SMA(strength, normalization lookback)) / stdev(strength, normalization lookback) * scaling factor, where strength = 100 * advance count / (advance count + decline count + denominator epsilon); breadth score = 50 + (breadth oscillator - SMA(breadth oscillator, normalization lookback)) / stdev(breadth oscillator, normalization lookback) * scaling factor, where breadth oscillator = EMA(up volume - down volume, shorter EMA lookback) - EMA(up volume - down volume, longer EMA lookback); put/call score = 50 + (SMA(smoothed put/call ratio, normalization lookback) - smoothed put/call ratio) / stdev(smoothed put/call ratio, normalization lookback) * scaling factor, where smoothed put/call ratio = SMA(put/call ratio, put/call smoothing lookback); volatility score = 50 - volatility change / stdev(volatility change, normalization lookback) * scaling factor, where volatility change = 100 * (volatility-index close / SMA(volatility-index close, volatility lookback) - 1); safe-haven score = 50 + (safe-haven demand - SMA(safe-haven demand, normalization lookback)) / stdev(safe-haven demand, normalization lookback) * scaling factor, where safe-haven demand = ROC(equity-market close, returns lookback) - ROC(bond close, returns lookback); junk-bond score = 50 + (SMA(yield spread, normalization lookback) - yield spread) / stdev(yield spread, normalization lookback) * scaling factor, where yield spread = high-yield bond yield - government bond yield. Clip each score to [0, 100]. Source values are T1 closes sampled on chart bars (last completed T1 bar historically and the still-forming T1 bar in realtime); rolling calculations run on chart bars. The longer EMA lookback exceeds the shorter EMA lookback.
