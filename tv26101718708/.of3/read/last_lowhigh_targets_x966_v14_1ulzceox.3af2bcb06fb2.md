Calculation: Quality score = setup weight + breakout weight if a breakout has been recorded, otherwise 0 + displacement weight if displacement scoring is disabled or (long: close > entry + ATR(high, low, close, ATR lookback) × displacement multiplier; short: close < entry − ATR(high, low, close, ATR lookback) × displacement multiplier), otherwise 0 + volume weight if volume scoring is disabled or volume ≥ SMA(volume, volume lookback) × volume multiplier, otherwise 0 + HTF weight if HTF bias scoring is disabled or (long: close(T1, last completed bar) > EMA(close, HTF EMA lookback, T1, last completed bar); short: close(T1, last completed bar) < EMA(close, HTF EMA lookback, T1, last completed bar)), otherwise 0; T1 values are sampled on chart bars.
Calculation: Long candidate = for each pivot lookback in the inclusive range bounded by the separate minimum-length and maximum-length parameters, initialize a reference at the first confirmed PivotLow(low, lookback, lookback); on each confirmed chart bar without an active setup, lower the reference to low if low is lower; at each newly confirmed pivot low, set up if it is above the reference, then replace the reference with that pivot low; the break level is the highest high strictly between the prior reference and the new pivot center; invalidate when close < the setup pivot low under close invalidation, or low < it under wick invalidation, clearing the setup and lowering the reference to the current low if lower.
Calculation: Short candidate = for each pivot lookback in the inclusive range bounded by the separate minimum-length and maximum-length parameters, initialize a reference at the first confirmed PivotHigh(high, lookback, lookback); on each confirmed chart bar without an active setup, raise the reference to high if high is higher; at each newly confirmed pivot high, set up if it is below the reference, then replace the reference with that pivot high; the break level is the lowest low strictly between the prior reference and the new pivot center; invalidate when close > the setup pivot high under close invalidation, or high > it under wick invalidation, clearing the setup and raising the reference to the current high if higher.
Calculation: Active candidate = the valid candidate selected by the priority parameter (lowest or highest break level, longest or shortest pivot lookback, or most recent pivot); in Both direction mode choose the side with the higher quality score, ties going to the more recent pivot and then long; in Long or Short mode choose that side.
Long: the active candidate is a valid long setup.
Short: the active candidate is a valid short setup.
Long: the active candidate is long AND its entry mode includes breakout AND (confirmed close > break level AND close[1] ≤ break level OR late breakout capture is enabled AND no breakout has been recorded AND confirmed close > break level AND a close crossover above the break level occurred after the setup pivot) OR the active candidate is long AND its entry mode includes retest AND a breakout was recorded on an earlier bar AND confirmed low ≤ break level AND confirmed close > break level; score gating is disabled OR quality score ≥ minimum score.
Short: the active candidate is short AND its entry mode includes breakout AND (confirmed close < break level AND close[1] ≥ break level OR late breakout capture is enabled AND no breakout has been recorded AND confirmed close < break level AND a close crossover below the break level occurred after the setup pivot) OR the active candidate is short AND its entry mode includes retest AND a breakout was recorded on an earlier bar AND confirmed high ≥ break level AND confirmed close < break level; score gating is disabled OR quality score ≥ minimum score.
