Calculation: Trend state = bullish when source > EMA(source, base lookback) + ATR(ATR lookback) * ATR multiplier; bearish when source < EMA(source, base lookback) - ATR(ATR lookback) * ATR multiplier; otherwise the prior state, initially neutral
Calculation: Trend-reset cumulative delta = (volume if close > open, otherwise -volume) when trend state changes; otherwise prior trend-reset cumulative delta + (volume if close > open, otherwise -volume)
Long: Trend state = bullish OR (pivot low(Trend-reset cumulative delta, left lookback, right lookback) exists right lookback bars ago AND abs(Z-score(Trend-reset cumulative delta, Z-score lookback)[right lookback]) >= Z-score threshold AND Trend-reset cumulative delta < 0)
Short: Trend state = bearish OR (pivot high(Trend-reset cumulative delta, left lookback, right lookback) exists right lookback bars ago AND abs(Z-score(Trend-reset cumulative delta, Z-score lookback)[right lookback]) >= Z-score threshold AND Trend-reset cumulative delta > 0)
