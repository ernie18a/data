Calculation: ATR trailing stop = let s be the selected close (regular or Heikin-Ashi), p be the prior stop (zero initially), and d = ATR multiplier x ATR(ATR lookback); max(p, s - d) if s > p and s[1] > p; min(p, s + d) if s < p and s[1] < p; s - d if s > p; otherwise s + d
Calculation: Hull = selected HMA, EHMA, or THMA of the selected OHLC source with length parameter x length multiplier (THMA uses half that length), calculated on chart bars or on T1 bars and returned to chart bars when the higher-timeframe option is enabled; T1 uses last completed bars historically and the still-forming bar in realtime; Hull[n_Hull] is the value n_Hull chart bars ago
Long: selected source > ATR trailing stop
Short: selected source < ATR trailing stop
Long: selected source crosses above ATR trailing stop
Short: selected source crosses below ATR trailing stop
Long: STC(close, cycle lookback, shorter EMA lookback, longer EMA lookback, smoothing factor)[n_old] >= STC(close, cycle lookback, shorter EMA lookback, longer EMA lookback, smoothing factor)[n_mid] AND STC(close, cycle lookback, shorter EMA lookback, longer EMA lookback, smoothing factor)[n_mid] < STC(close, cycle lookback, shorter EMA lookback, longer EMA lookback, smoothing factor)[n_prior] AND STC(close, cycle lookback, shorter EMA lookback, longer EMA lookback, smoothing factor) < lower threshold; n_old > n_mid > n_prior
Short: STC(close, cycle lookback, shorter EMA lookback, longer EMA lookback, smoothing factor)[n_old] <= STC(close, cycle lookback, shorter EMA lookback, longer EMA lookback, smoothing factor)[n_mid] AND STC(close, cycle lookback, shorter EMA lookback, longer EMA lookback, smoothing factor)[n_mid] > STC(close, cycle lookback, shorter EMA lookback, longer EMA lookback, smoothing factor)[n_prior] AND STC(close, cycle lookback, shorter EMA lookback, longer EMA lookback, smoothing factor) > upper threshold; n_old > n_mid > n_prior
Long: Hull trend coloring enabled AND Hull > Hull[n_Hull]
Short: Hull trend coloring enabled AND Hull <= Hull[n_Hull]
Long: Hull crosses above Hull[n_Hull]
Short: Hull crosses below Hull[n_Hull]
Long: long entries enabled AND Hull trend coloring enabled AND position is not long AND STC(close, cycle lookback, shorter EMA lookback, longer EMA lookback, smoothing factor) > STC(close, cycle lookback, shorter EMA lookback, longer EMA lookback, smoothing factor)[n_prior] AND STC(close, cycle lookback, shorter EMA lookback, longer EMA lookback, smoothing factor) < lower threshold AND Hull > Hull[n_Hull] AND the most recent selected-source cross above the ATR trailing stop is later than the most recent cross below it
Short: short entries enabled AND Hull trend coloring enabled AND position is not short AND STC(close, cycle lookback, shorter EMA lookback, longer EMA lookback, smoothing factor) < STC(close, cycle lookback, shorter EMA lookback, longer EMA lookback, smoothing factor)[n_prior] AND STC(close, cycle lookback, shorter EMA lookback, longer EMA lookback, smoothing factor) > upper threshold AND Hull <= Hull[n_Hull] AND the most recent selected-source cross below the ATR trailing stop is later than the most recent cross above it
Exit: long, close < entry price x (1 - stop-loss percentage / 100) OR high >= entry price x (1 + target-1 percentage / 100) OR high >= entry price x (1 + target-2 percentage / 100) OR high >= entry price x (1 + target-3 percentage / 100) OR high >= entry price x (1 + target-4 percentage / 100)
Exit: short, close > entry price x (1 + stop-loss percentage / 100) OR low <= entry price x (1 - target-1 percentage / 100) OR low <= entry price x (1 - target-2 percentage / 100) OR low <= entry price x (1 - target-3 percentage / 100) OR low <= entry price x (1 - target-4 percentage / 100)
