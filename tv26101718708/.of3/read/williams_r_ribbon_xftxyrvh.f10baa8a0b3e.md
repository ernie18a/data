Calculation: Williams %R = Williams %R(source, lookback), using the high/low lookback range and returning -50 when the range is zero; calculated on T1 bars and mapped to chart bars with lookahead off (last completed T1 value historically, current forming T1 value in real time).
Calculation: Signal line = selected signal MA(Williams %R, signal lookback, ALMA offset and sigma when applicable), calculated on T1 bars and mapped to chart bars with lookahead off (last completed T1 value historically, current forming T1 value in real time).
Calculation: Ribbon %R = selected visual MA(Williams %R, visual smoothing lookback) on chart bars when visual smoothing is enabled; otherwise Williams %R.
Calculation: Ribbon signal = selected visual MA(Signal line, visual smoothing lookback) on chart bars when visual smoothing is enabled; otherwise Signal line.
Long: Ribbon %R > Ribbon signal AND abs(Ribbon %R - Ribbon signal) >= neutral spread OR Williams %R crosses above Signal line OR Williams %R crosses above oversold level OR Williams %R crosses below lower moderate threshold OR Williams %R crosses below lower extended threshold OR Williams %R crosses below lower very extended threshold OR Williams %R crosses below lower extremely extended threshold.
Short: Ribbon %R < Ribbon signal AND abs(Ribbon %R - Ribbon signal) >= neutral spread OR Williams %R crosses below Signal line OR Williams %R crosses below overbought level OR Williams %R crosses above upper moderate threshold OR Williams %R crosses above upper extended threshold OR Williams %R crosses above upper very extended threshold OR Williams %R crosses above upper extremely extended threshold.
