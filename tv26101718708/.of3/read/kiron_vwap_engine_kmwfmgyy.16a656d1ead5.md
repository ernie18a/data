Calculation: BarPrice = sum(source price * volume) / sum(volume) over the completed T3 bars inside each chart bar
Calculation: BarSecondMoment = sum(source price^2 * volume) / sum(volume) over the completed T3 bars inside each chart bar
Calculation: VWAP(anchor) = sum(BarPrice * volume) / sum(volume) over chart bars from the start of the current anchor bar (still forming) through the current bar; anchor is T1 or T2
Calculation: VWAP SD(T1) = sqrt(sum(BarSecondMoment * volume) / sum(volume) - VWAP(T1)^2) over the same chart bars as VWAP(T1)
Calculation: Band(k, s) = VWAP(T1) + s * k * VWAP SD(T1), where k is k1 (band 1 multiplier) or k2 (band 2 multiplier), and s = +1 for upper, -1 for lower
Calculation: BarsSinceAnchor = number of chart bars since the start of the current T1 bar, 0 on its first chart bar
Calculation: VWAP slope = (VWAP(T1) - VWAP(T1)[k]) / ATR(atr length), where k = min(slope lookback, BarsSinceAnchor)
Calculation: Lower wick ratio = (min(open, close) - low) / (high - low)
Calculation: Upper wick ratio = (high - max(open, close)) / (high - low)
Calculation: Long stop = lowest low over the last (setup window + 1) bars - stop buffer * ATR(atr length)
Calculation: Short stop = highest high over the last (setup window + 1) bars + stop buffer * ATR(atr length)
Calculation: Armed(type, side) = no bar b with R <= b < current bar satisfies the rule for that type and side, where R is the latest bar up to the current bar that starts a new T1 bar or meets the re-arm condition for that type and side; re-arm conditions: Long PB close > Band(k1, +1); Short PB close < Band(k1, -1); Long MR close >= VWAP(T1); Short MR close <= VWAP(T1)
