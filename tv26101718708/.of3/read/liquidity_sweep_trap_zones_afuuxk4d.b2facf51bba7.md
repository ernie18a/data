Calculation: ATR floor = max(ATR(ATR lookback), minimum tick)
Calculation: Relative volume = volume / SMA(volume, volume lookback), or neutral activity ratio if SMA is unavailable or nonpositive
Calculation: Relative ATR = ATR(ATR lookback) / SMA(ATR(ATR lookback), ATR MA lookback), or neutral activity ratio if SMA is unavailable or nonpositive
Calculation: Candle range ATR = max(high - low, minimum tick) / ATR floor
Calculation: Upper wick ratio = (high - max(open, close)) / max(high - low, minimum tick)
Calculation: Lower wick ratio = (min(open, close) - low) / max(high - low, minimum tick)
Calculation: Bullish EMA regime = EMA(close, fast EMA lookback) > EMA(close, slow EMA lookback) AND close >= EMA(close, fast EMA lookback)
Calculation: Bearish EMA regime = EMA(close, fast EMA lookback) < EMA(close, slow EMA lookback) AND close <= EMA(close, fast EMA lookback)
Calculation: Strong bullish EMA regime = bullish EMA regime has persisted for at least the strong regime hold bars
Calculation: Strong bearish EMA regime = bearish EMA regime has persisted for at least the strong regime hold bars
Calculation: Tenkan = (highest(high, Tenkan lookback) + lowest(low, Tenkan lookback)) / two
Calculation: Kijun = (highest(high, Kijun lookback) + lowest(low, Kijun lookback)) / two
Calculation: Current Span A = (Tenkan + Kijun) / two
Calculation: Current Span B = (highest(high, Span B lookback) + lowest(low, Span B lookback)) / two
Calculation: Cloud top = max(Current Span A, Current Span B)
Calculation: Cloud bottom = min(Current Span A, Current Span B)
Calculation: Bullish cloud regime = close > Cloud top AND Current Span A >= Current Span B
Calculation: Bearish cloud regime = close < Cloud bottom AND Current Span A <= Current Span B
Calculation: Neutral cloud regime = neither bullish nor bearish cloud regime
Calculation: Premium/discount position = (close - lowest(low, dealing range lookback)) / max(highest(high, dealing range lookback) - lowest(low, dealing range lookback), minimum tick)
Calculation: Sweep penetration ATR(side) = (high - latest confirmed PivotHigh(high, swing length, swing length)) / ATR floor for bearish side; (latest confirmed PivotLow(low, swing length, swing length) - low) / ATR floor for bullish side
Calculation: Sweep wick ratio(side) = Upper wick ratio for bearish side; Lower wick ratio for bullish side
