Calculation: Session VWAP = VWAP(hlc3, volume, market-session bars since the current date reset)
Calculation: Context vote = 1 if T2 is greater than the chart timeframe and close from the still-forming T2 bar is above SMA(close, context lookback) computed on T2 bars using that bar; -1 if it is below; otherwise 0; map the T2 values to chart bars
Calculation: Up votes = (close > Session VWAP ? 1 : 0) + (change(Session VWAP, slope lookback converted to chart bars) > 0 ? 1 : 0) + (opening range set and close > highest(high, opening-range duration converted to chart bars from the first market-session bar of the current date) ? 1 : 0) + (Context vote = 1 ? 1 : 0) + (close > high(T1, last completed bar) ? 1 : 0)
Calculation: Down votes = (close < Session VWAP ? 1 : 0) + (change(Session VWAP, slope lookback converted to chart bars) < 0 ? 1 : 0) + (opening range set and close < lowest(low, opening-range duration converted to chart bars from the first market-session bar of the current date) ? 1 : 0) + (Context vote = -1 ? 1 : 0) + (close < low(T1, last completed bar) ? 1 : 0)
Calculation: Opening gap (%) = (open of the first market-session bar of the current date - close(T1, last completed bar)) / close(T1, last completed bar) * 100, when that close is positive and available
Long: Opening range is set AND Up votes >= vote threshold AND this TREND UP condition holds for the hold-duration parameter converted to chart bars, counting only market-session bars
Long: Opening range is set AND Up votes < vote threshold AND Down votes < vote threshold AND Opening gap (%) <= -gap-size parameter AND close > open of the first market-session bar of the current date AND this GAP FILL UP condition holds for the hold-duration parameter converted to chart bars, counting only market-session bars
Short: Opening range is set AND Up votes < vote threshold AND Down votes >= vote threshold AND this TREND DOWN condition holds for the hold-duration parameter converted to chart bars, counting only market-session bars
Short: Opening range is set AND Up votes < vote threshold AND Down votes < vote threshold AND Opening gap (%) >= gap-size parameter AND close < open of the first market-session bar of the current date AND this GAP FILL DOWN condition holds for the hold-duration parameter converted to chart bars, counting only market-session bars
