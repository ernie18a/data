Calculation: daily ATR = ATR(ATR lookback, T1, last completed bar)
Calculation: prior-range high = High(T1, last completed bar)[1]
Calculation: prior-range low = Low(T1, last completed bar)[1]
Calculation: prior T1 close = Close(T1, last completed bar)[1]
Calculation: day return = (close / prior T1 close - 1) * 100, using the close of the traded instrument, or of another instrument X with its own close and prior T1 close
Calculation: benchmark return = day return of the benchmark for the gate type: semiconductor index for semis, growth index for growth, software and high-beta, small-cap index for small-cap, energy sector for energy, financial sector for bank, healthcare sector for defensive and biotech, broad-market ETF for all others
Calculation: relative edge = day return of traded instrument - benchmark return
Calculation: close location = (close - low) / max(high - low, minimum price increment)
Calculation: relative volume = volume / SMA(volume, RVOL lookback)
Calculation: opening-range high = highest high of bars in the first opening-range minutes of the regular session
Calculation: opening-range low = lowest low of bars in the first opening-range minutes of the regular session
Calculation: opening-range size = max(opening-range high - opening-range low, minimum range size)
Calculation: event remap needed = set on the first bar of each regular session and held for that session: event setup AND (abs(open - prior T1 close) / daily ATR >= gap threshold OR (long side mapped AND open below long hard invalidation level) OR (short side mapped AND open above short hard invalidation level) OR (long side mapped AND open - long trigger level >= gap consumption share * abs(long target 1 level - long trigger level)) OR (short side mapped AND short trigger level - open >= gap consumption share * abs(short trigger level - short target 1 level)))
Calculation: event remap active = event remap needed AND minutes since session open >= opening-range minutes
Calculation: long trigger level = opening-range high if event remap active, else long trigger
Calculation: long confirm level = opening-range high + confirm offset * opening-range size if event remap active, else long confirm
Calculation: long invalidation level = min(session VWAP(hlc3), opening-range high) if event remap active, else long invalidation
Calculation: long hard invalidation level = opening-range low if event remap active, else long hard invalidation
Calculation: long target 1 level = opening-range high + target 1 offset * opening-range size if event remap active, else long target 1
Calculation: long target 2 level = opening-range high + opening-range size if event remap active, else long target 2
Calculation: long target 3 level = opening-range high + target 3 offset * opening-range size if event remap active, else long target 3
Calculation: long zone low = min(session VWAP(hlc3), opening-range high) if event remap active, else long zone low
Calculation: long zone high = opening-range high if event remap active, else long zone high
Calculation: short trigger level = opening-range low if event remap active, else short trigger
Calculation: short confirm level = opening-range low - confirm offset * opening-range size if event remap active, else short confirm
Calculation: short invalidation level = max(session VWAP(hlc3), opening-range low) if event remap active, else short invalidation
Calculation: short hard invalidation level = opening-range high if event remap active, else short hard invalidation
Calculation: short target 1 level = opening-range low - target 1 offset * opening-range size if event remap active, else short target 1
Calculation: short target 2 level = opening-range low - opening-range size if event remap active, else short target 2
Calculation: short target 3 level = opening-range low - target 3 offset * opening-range size if event remap active, else short target 3
Calculation: short zone low = opening-range low if event remap active, else short zone low
Calculation: short zone high = max(session VWAP(hlc3), opening-range low) if event remap active, else short zone high
Calculation: factor-sensitive setup = gate type is index, semis, growth, software, high-beta or small-cap
Calculation: exempt setup = gate type is index or volatility, or event setup
Calculation: chart volume unreliable = instrument is index or CFD
Calculation: breadth score = clamp(up-volume score + TICK score + volatility-curve score + VIX score, 0, 100), where up-volume score is a clamped linear map of up-volume share = up-volume index / (up-volume index + down-volume index), TICK score is a clamped linear map of SMA(tick index, TICK smoothing), volatility-curve score is high if the 1-day/9-day volatility ratio is calm and the 9-day/VIX ratio is calm or unavailable, zero if the 1-day/9-day ratio is stressed, else middle, and VIX score is a stepped map of the volatility index close
Calculation: data integrity = sum of weights of available feeds (up-volume and down-volume, tick index, 1-day and 9-day volatility indexes, core market closes, chart volume, map freshness) - staleness penalty - non-intraday penalty, where staleness penalty = scaled excess of the oldest internals timestamp age over max internals age, capped, or a fixed penalty if any internals timestamp is missing
Calculation: structural surface = clamp(weighted sum of: close distance from session VWAP(hlc3) in daily ATR units, scaled and clamped; EMA(hl2, exec fast) - EMA(hl2, exec slow) in daily ATR units, scaled and clamped; EMA(hl2, struct fast) - EMA(hl2, struct slow) in daily ATR units, scaled and clamped; day return minus broad-market ETF day return, scaled and clamped, -1, 1)
Calculation: hedge surface = clamp(weighted sum of: breadth component = clamp((breadth score - neutral breadth score) / breadth half-range, -1, 1); volatility component = +1 if front-end calm, -1 if front-end stressed, else +partial if VIX below VIX warning level, -partial if VIX above VIX expansion level, else 0; regime component = +1 if index bull regime, -1 if index bear regime, +partial if gamma repair regime, -partial if risk-off regime, else 0, -1, 1)
Calculation: composite surface = clamp(weighted structural surface + weighted hedge surface, -1, 1)
Calculation: index bull regime = cash broad-market index close above SPX bull gate AND broad-market ETF close above broad bull gate AND growth index close above growth bull gate AND small-cap index close above small-cap bull gate AND semiconductor index close above semis bull gate AND VIX below VIX calm level AND (breadth score >= bull breadth score OR (up-volume share >= bull up-volume share AND SMA(tick index, TICK smoothing) >= bull TICK))
Calculation: index bear regime = cash broad-market index close below SPX bear gate AND broad-market ETF close below broad bear gate AND growth index close below growth bear gate AND small-cap index close below small-cap bear gate AND semiconductor index close below semis bear gate AND VIX above VIX expansion level AND (breadth score <= bear breadth score OR (up-volume share <= bear up-volume share AND SMA(tick index, TICK smoothing) <= bear TICK))
Calculation: gamma repair regime = cash broad-market index close >= SPX repair gate AND broad-market ETF close >= broad repair gate AND growth index close >= growth repair gate AND semiconductor index close >= semis repair gate AND small-cap index close >= small-cap repair gate AND VIX below VIX warning level
Calculation: risk-off regime = growth index close below growth risk gate AND small-cap index close below small-cap risk gate AND semiconductor index close below semis risk gate AND VIX >= VIX warning level
Calculation: long market gate = by gate type: index -> index bull regime OR gamma repair regime; semis -> growth index close >= growth gate AND semiconductor index close >= semis gate AND VIX below VIX warning level; growth -> growth index close >= growth gate AND VIX below VIX warning level; software -> growth index close >= growth gate AND software sector day return >= growth index day return - software tolerance AND VIX below VIX warning level; high-beta -> growth index close >= high-beta gate AND VIX below VIX warning level; small-cap -> small-cap index close >= small-cap gate AND VIX below VIX warning level; energy -> energy sector day return >= broad-market ETF day return AND crude oil futures close >= crude gate; bank -> financial sector day return >= broad-market ETF day return AND financial sector day return > 0; defensive -> (healthcare sector day return >= broad-market ETF day return AND healthcare sector day return > 0) OR broad-market ETF close >= defensive gate; quality -> broad-market ETF close >= quality gate AND growth index close >= quality growth gate AND VIX below VIX warning level; biotech -> healthcare sector day return >= broad-market ETF day return AND healthcare sector day return > 0 AND VIX below biotech VIX ceiling; volatility -> VIX >= VIX warning level; otherwise -> broad-market ETF close >= broad gate AND VIX below VIX warning level
