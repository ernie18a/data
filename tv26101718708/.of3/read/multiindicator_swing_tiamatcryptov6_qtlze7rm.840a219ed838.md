Calculation: ADX = SMA(DX, lookback), where TR = max(high-low, abs(high-close[1]), abs(low-close[1])), DI+ = 100*SMA(high>high[1] ? max(high-high[1],0) : 0, lookback)/SMA(TR, lookback) (or 0 if SMA(TR, lookback) <= 0), DI- = 100*SMA(low[1]>low ? max(low[1]-low,0) : 0, lookback)/SMA(TR, lookback) (or 0 if SMA(TR, lookback) <= 0), and DX = 100*abs(DI+-DI-)/(DI++DI-) (or 0 if DI++DI- <= 0)
Calculation: Liquidity Delta = EMA(SMA(bid volume - ask volume, delta lookback)/SMA(volume, delta lookback), smoothing lookback), where bid volume = volume if close<open, otherwise volume*(high-close)/(high-low+denominator offset), and ask volume = volume if close>open, otherwise volume*(close-low)/(high-low+denominator offset)
Long: long trading enabled AND datetime >= start-date parameter AND datetime <= end-date parameter AND (PSAR filter disabled OR close > Parabolic SAR(start, increment, maximum)) AND (Supertrend filter disabled OR Supertrend direction(factor, ATR lookback) > 0) AND (ADX filter disabled OR ADX(lookback) > strength threshold) AND (Liquidity Delta filter disabled OR Liquidity Delta(delta lookback, smoothing lookback, denominator offset) > delta threshold)
Short: short trading enabled AND datetime >= start-date parameter AND datetime <= end-date parameter AND (PSAR filter disabled OR close < Parabolic SAR(start, increment, maximum)) AND (Supertrend filter disabled OR Supertrend direction(factor, ATR lookback) < 0) AND (ADX filter disabled OR ADX(lookback) > strength threshold) AND (Liquidity Delta filter disabled OR Liquidity Delta(delta lookback, smoothing lookback, denominator offset) < -delta threshold)
Exit: Long, (stop-loss enabled AND low <= latest long-signal bar close*(1-stop-loss percentage/100)) OR (take-profit enabled AND high >= latest long-signal bar close*(1+take-profit percentage/100))
Exit: Short, (stop-loss enabled AND high >= latest short-signal bar close*(1+stop-loss percentage/100)) OR (take-profit enabled AND low <= latest short-signal bar close*(1-take-profit percentage/100))
