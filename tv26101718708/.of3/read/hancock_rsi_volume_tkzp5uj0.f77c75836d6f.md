Calculation: Up volume(T1, wick-weighting setting) = on each T1 bar, if wick-weighting is enabled and close > open, volume * (high - low) / (2 * (high - close) + (close - open) + 2 * (open - low)); if enabled and close < open, volume * ((high - open) + (close - low)) / (2 * (high - open) + (open - close) + 2 * (close - low)); if enabled and close = open, 0; otherwise, volume when close >= open and 0 otherwise. Sum over the T1 bars spanning each chart bar, and use that value on chart bars; the current T1 bar is used live and the latest available completed T1 bar historically.
Calculation: Down volume(T1, wick-weighting setting) = on each T1 bar, if wick-weighting is enabled and close > open, volume * ((high - close) + (open - low)) / (2 * (high - close) + (close - open) + 2 * (open - low)); if enabled and close < open, volume * (high - low) / (2 * (high - open) + (open - close) + 2 * (close - low)); if enabled and close = open, 0; otherwise, volume when close < open and 0 otherwise. Sum over the T1 bars spanning each chart bar, and use that value on chart bars; the current T1 bar is used live and the latest available completed T1 bar historically.
Calculation: Volume RSI = 100 * U / (U + D), where U = RMA(abs(source - source[1]) * up volume(T1) when source > source[1], lookback) and D = RMA(abs(source - source[1]) * down volume(T1) when source < source[1], lookback); use 0 for either term when its condition is false. Evaluate on chart bars.
Calculation: Volume RSI trend state = 1 when Volume RSI > 50 + 50 * threshold, or when Volume RSI > 50 - 50 * threshold and the previous chart bar's state > 0; otherwise -1 when Volume RSI < 50 - 50 * threshold, or when Volume RSI < 50 + 50 * threshold and the previous chart bar's state < 0; otherwise 0.
Long: Volume RSI trend state = 1
Short: Volume RSI trend state = -1
