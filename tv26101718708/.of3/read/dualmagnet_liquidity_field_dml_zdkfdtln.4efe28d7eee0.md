Calculation: MaxScore(side) = maximum over the most recent pivots of the side (at most maximum candidates; PivotHigh(high, swing length, swing length) for up, PivotLow(low, swing length, swing length) for down) that lie on the side's close test (level above close for up, below close for down) of: distance weight * exp(-|level - close| / ATR(ATR length) / distance decay length) + volume weight * min(volume at pivot bar / SMA(volume, volume baseline length), volume cap) / volume cap + recency weight * exp(-(bars since pivot bar) / recency decay length) + touch weight * min(touch count, touch cap) / touch cap + range-position weight * position, where position = (level - lowest(low, range length)) / (highest(high, range length) - lowest(low, range length)) for up and 1 - position for down; 0 if no such pivot
Calculation: Strength(side) = 100 * (MaxScore(side) - lowest(MaxScore(side), normalization window)) / (highest(MaxScore(side), normalization window) - lowest(MaxScore(side), normalization window)), or 0 if highest is not above lowest
Calculation: Qualified(side) = some pivot of the side lies on its side of close AND Strength(side) >= minimum probability
Calculation: UpShare = 100 * Strength(up) / (Strength(up) + Strength(down)) if Strength(up) + Strength(down) > 0, else 50
Calculation: Gate = no earlier bar on which Gate and Signal held, or bars since the latest such bar >= cooldown length, where Signal = Qualified(up) AND Qualified(down) AND (UpShare >= dominance threshold OR 100 - UpShare >= dominance threshold OR (Strength(up) >= coil floor AND Strength(down) >= coil floor AND UpShare < dominance threshold AND 100 - UpShare < dominance threshold))
Long: UpShare >= dominance threshold AND Qualified(up) AND Qualified(down)
Long: UpShare >= dominance threshold AND Qualified(up) AND Qualified(down) AND Gate
Short: 100 - UpShare >= dominance threshold AND Qualified(up) AND Qualified(down)
Short: 100 - UpShare >= dominance threshold AND Qualified(up) AND Qualified(down) AND Gate
