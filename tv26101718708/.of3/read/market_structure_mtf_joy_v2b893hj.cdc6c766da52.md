Calculation: Major trend = start neutral with both pending-structure flags false; on chart bars, use ta.pivothigh(high, P_major, P_major) and ta.pivotlow(low, P_major, P_major) computed on T1 and sampled with lookahead off (the last completed T1 result historically and the developing T1 result in real time); set the lower-high flag when a new T1 pivot high is below the preceding T1 pivot high, set the trend bearish and clear both flags when a new pivot low is below the preceding T1 pivot low while the lower-high flag is set, set the higher-low flag when a new pivot low is above its predecessor, and set the trend bullish and clear both flags when a new pivot high is above its predecessor while the higher-low flag is set; process these updates in this order and otherwise retain the trend
Calculation: Minor CHoCH bar indexes = on chart bars, maintain the latest confirmed ta.pivothigh(high, P_minor, P_minor) and ta.pivotlow(low, P_minor, P_minor) levels and a break trend initially neutral; using levels stored before any pivot confirmed on the current bar, a close crossing above the stored pivot high (close > level and close[1] <= level) sets the break trend bullish and records the current bar index as the bullish CHoCH index only if the prior break trend was bearish; a close crossing below the stored pivot low (close < level and close[1] >= level) sets it bearish and records the current index as the bearish CHoCH index only if the prior break trend was bullish; initialize both CHoCH indexes to chart bar index zero
Calculation: Recent bullish minor CHoCH = current chart bar index minus the bullish CHoCH index is greater than zero and <= P_sniper
Calculation: Recent bearish minor CHoCH = current chart bar index minus the bearish CHoCH index is greater than zero and <= P_sniper
Calculation: Valid supply and demand zones = when zones are enabled, on chart bars create supply zones from ta.pivothigh(high, P_zone, P_zone) and demand zones from ta.pivotlow(low, P_zone, P_zone); seed each zone with the pivot candle's high and low, then include each of the preceding P_base bars whose high is below the supply pivot high or whose low is above the demand pivot low, respectively, extending the zone bounds to the maximum high and minimum low; process supply pivots before demand pivots, retain the newest P_maxZones zones total, invalidate supply when close > its top and demand when close < its bottom, and otherwise retain each zone as valid
Calculation: Recent sellside and buyside sweeps = when liquidity is enabled, on chart bars store levels from ta.pivotlow(low, P_liq, P_liq) and ta.pivothigh(high, P_liq, P_liq), retaining the newest P_maxLevels levels combined and processing pivot highs before pivot lows; mark a stored low level swept when low < level and a stored high level swept when high > level, retain swept levels until removed as oldest, and record the current bar index as the latest sellside or buyside sweep index, respectively; initialize both indexes to chart bar zero; Recent sellside sweep is current chart bar index minus the latest sellside sweep index <= P_sniper, and Recent buyside sweep is current chart bar index minus the latest buyside sweep index <= P_sniper
Long: sniper signals enabled AND chart timeframe duration <= P_maxChartDuration AND Major trend is bullish AND Recent bullish minor CHoCH AND close is within a valid demand zone AND Recent sellside sweep
Short: sniper signals enabled AND chart timeframe duration <= P_maxChartDuration AND Major trend is bearish AND Recent bearish minor CHoCH AND close is within a valid supply zone AND Recent buyside sweep
