Calculation: Trend price = close when no adaptive filter is selected, KalmanFilter(close, adaptive filter length) when Kalman is selected, or SMA(close, adaptive filter length) + (close - close[adaptive filter length]) / adaptive filter length * (adaptive filter length / 2) when LLAMA is selected
Long: On a confirmed chart bar, ZScore(illiquidity impact, stress lookback)[1] >= stress threshold AND Trend price[1] < EMA(Trend price, trend length)[1] AND close[1] < open[1] AND (ADX filter disabled OR ADX(ADX length)[1] >= ADX threshold)
