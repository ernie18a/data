Calculation: Long RSI points = deep points if RSI(close, RSI lookback) <= oversold threshold - RSI deep offset; else medium points if <= oversold threshold; else light points if <= oversold threshold + RSI warning offset; else zero.
Calculation: Short RSI points = deep points if RSI(close, RSI lookback) >= overbought threshold + RSI deep offset; else medium points if >= overbought threshold; else light points if >= overbought threshold - RSI warning offset; else zero.
Calculation: Smoothed %K = SMA(Stochastic %K(close, high, low, %K lookback), %K smoothing lookback); %D = SMA(smoothed %K, %D lookback).
Calculation: Long Stochastic points = deep points if smoothed %K crosses above %D and is <= oversold threshold - deep-zone offset; else medium points if it crosses above and is <= oversold threshold; else light points if it crosses above and is <= oversold threshold + cross-zone offset, or if smoothed %K <= oversold threshold; else zero.
Calculation: Short Stochastic points = deep points if smoothed %K crosses below %D and is >= overbought threshold + deep-zone offset; else medium points if it crosses below and is >= overbought threshold; else light points if it crosses below and is >= overbought threshold - cross-zone offset, or if smoothed %K >= overbought threshold; else zero.
Calculation: Long Bollinger points = deep points if close <= lower Bollinger Band(close, lookback, standard-deviation multiplier) - band width * deep-band fraction; else medium points if close <= the lower band; else light points if close <= lower band + (middle band - lower band) * inner-zone fraction; else zero.
Calculation: Short Bollinger points = deep points if close >= upper Bollinger Band(close, lookback, standard-deviation multiplier) + band width * deep-band fraction; else medium points if close >= the upper band; else light points if close >= upper band - (upper band - middle band) * inner-zone fraction; else zero.
Calculation: Long CCI points = deep points if CCI(close, lookback) <= -deep threshold; else medium points if <= -medium threshold; else light points if <= -light threshold; else zero.
Calculation: Short CCI points = deep points if CCI(close, lookback) >= deep threshold; else medium points if >= medium threshold; else light points if >= light threshold; else zero.
Calculation: Long Williams %R points = deep points if Williams %R(high, low, close, lookback) <= -deep threshold; else medium points if <= -medium threshold; else light points if <= -light threshold; else zero.
Calculation: Short Williams %R points = deep points if Williams %R(high, low, close, lookback) >= -(100 - deep threshold); else medium points if >= -(100 - medium threshold); else light points if >= -(100 - light threshold); else zero.
Calculation: Long MFI points = deep points if MFI((high + low + close) / 3, volume, lookback) <= deep threshold; else medium points if <= medium threshold; else light points if <= light threshold; else zero.
Calculation: Short MFI points = deep points if MFI((high + low + close) / 3, volume, lookback) >= 100 - deep threshold; else medium points if >= 100 - medium threshold; else light points if >= 100 - light threshold; else zero.
Calculation: Long ADX/DI points = deep points if +DI crosses above -DI and ADX >= strong-trend threshold; else medium points if +DI > -DI and ADX > ADX from the rising-bars lookback ago; else light points if +DI > -DI; else zero, using DMI(high, low, close, lookback, same lookback).
Calculation: Short ADX/DI points = deep points if -DI crosses above +DI and ADX >= strong-trend threshold; else medium points if -DI > +DI and ADX > ADX from the rising-bars lookback ago; else light points if -DI > +DI; else zero, using DMI(high, low, close, lookback, same lookback).
Calculation: Bullish divergence = on each confirmed pivot low using the pivot lookback on both sides, compare its low and RSI(close, RSI lookback) value at the pivot with the previous pivot low and its RSI; it occurs when the low is lower, RSI is higher, and pivot RSI is below the RSI midpoint threshold; update the previous pivot values at every confirmed pivot low.
Calculation: Bearish divergence = on each confirmed pivot high using the pivot lookback on both sides, compare its high and RSI(close, RSI lookback) value at the pivot with the previous pivot high and its RSI; it occurs when the high is higher, RSI is lower, and pivot RSI is above the RSI midpoint threshold; update the previous pivot values at every confirmed pivot high.
Calculation: Long divergence points = zero when divergence scoring is disabled; otherwise deep points if the latest bullish divergence is no older than the fresh-divergence bars, else medium points if no older than the divergence expiry, else light points if no older than expiry plus the divergence grace bars, else zero.
Calculation: Short divergence points = zero when divergence scoring is disabled; otherwise deep points if the latest bearish divergence is no older than the fresh-divergence bars, else medium points if no older than the divergence expiry, else light points if no older than expiry plus the divergence grace bars, else zero.
Calculation: Long raw score = sum of the eight long component point values; short raw score = sum of the eight short component point values.
Calculation: Long voters = count of long component point values at least the light-point value; short voters = count of short component point values at least the light-point value.
Calculation: Volume multiplier = strong-volume boost if volume / SMA(volume, volume lookback) >= strong-spike threshold; else weak-volume boost if that ratio >= spike threshold; else one, treating a zero average as a zero ratio.
Calculation: Long effective score = long raw score * volume multiplier; short effective score = short raw score * volume multiplier.
Calculation: Long raw signal = long voters >= minimum voters AND long effective score >= minimum total score AND bar is confirmed when the bar-confirmation filter is enabled AND the optional EMA trend filter is disabled or close >= EMA(close, trend lookback).
Calculation: Short raw signal = short voters >= minimum voters AND short effective score >= minimum total score AND bar is confirmed when the bar-confirmation filter is enabled AND the optional EMA trend filter is disabled or close <= EMA(close, trend lookback).
Long: Long raw signal AND position is flat or short AND long trading is enabled.
Short: Short raw signal AND position is flat or long AND short trading is enabled.
Long: Bar is confirmed when the bar-confirmation filter is enabled AND long raw signal is false AND long voters >= minimum voters minus warning-voter gap AND long effective score >= minimum total score minus warning-score gap.
Short: Bar is confirmed when the bar-confirmation filter is enabled AND short raw signal is false AND short voters >= minimum voters minus warning-voter gap AND short effective score >= minimum total score minus warning-score gap.
Long: Divergence scoring is enabled AND the latest bullish divergence is no older than the divergence expiry AND no long entry signal is present.
Short: Divergence scoring is enabled AND the latest bearish divergence is no older than the divergence expiry AND no short entry signal is present.
Long: Re-entry is enabled AND position is flat after a long-position exit AND bars since exit >= re-entry cooldown and <= re-entry timeout AND re-entry count < maximum re-entries AND (highest high since exit - low) / highest high since exit * 100 >= minimum pullback percentage AND close > EMA(close, shorter EMA lookback) AND close > EMA(close, longer EMA lookback) AND long voters >= re-entry minimum voters AND bar is confirmed when the bar-confirmation filter is enabled.
Short: Re-entry is enabled AND position is flat after a short-position exit AND bars since exit >= re-entry cooldown and <= re-entry timeout AND re-entry count < maximum re-entries AND (high - lowest low since exit) / lowest low since exit * 100 >= minimum pullback percentage AND close < EMA(close, shorter EMA lookback) AND close < EMA(close, longer EMA lookback) AND short voters >= re-entry minimum voters AND bar is confirmed when the bar-confirmation filter is enabled.
Calculation: Pullback touch = during the current bar or the preceding bounce-confirmation lookback plus touch-extension bars, any high or low is within touch-distance factor * maximum EMA distance percentage of the current EMA(close, slower EMA lookback).
Long: Pullback entry is enabled AND position is not long AND close > EMA(close, trend EMA lookback) AND +DI > -DI AND ADX >= strong-trend threshold AND long voters >= pullback minimum voters AND pullback touch AND every bar in the bounce-confirmation lookback has close > open AND close > EMA(close, slower EMA lookback) AND bar is confirmed when the bar-confirmation filter is enabled.
Short: Pullback entry is enabled AND position is not short AND close < EMA(close, trend EMA lookback) AND -DI > +DI AND ADX >= strong-trend threshold AND short voters >= pullback minimum voters AND pullback touch AND every bar in the bounce-confirmation lookback has close < open AND close < EMA(close, slower EMA lookback) AND bar is confirmed when the bar-confirmation filter is enabled.
Calculation: ATR trail factor = 1 + (clamp(ATR(ATR lookback) / SMA(ATR(ATR lookback), ATR-average lookback), lower ATR-scale bound, upper ATR-scale bound) - 1) * ATR blend weight.
Calculation: Position trail score factor = clamp(1 - opposite-side raw score / maximum possible raw score * trail-tightening rate + same-side raw score / maximum possible raw score * trail-loosening rate, lower score-factor bound, upper score-factor bound).
Calculation: Effective trail activation percentage = base trail-activation percentage * ATR trail factor; effective trail distance percentage = base trail-distance percentage * ATR trail factor * position trail score factor.
Exit: Long, stop loss is enabled AND low <= the long stop price, initialized from entry price using the stop-loss percentage (multiplied by the pullback stop ratio for pullback entries); when breakeven and stop loss are enabled, raise it to at least entry price after the phase-two profit threshold and to at least entry price * (1 + locked-profit percentage / 100) after the phase-three profit threshold.
Exit: Short, stop loss is enabled AND high >= the short stop price, initialized from entry price using the stop-loss percentage (multiplied by the pullback stop ratio for pullback entries); when breakeven and stop loss are enabled, lower it to at most entry price after the phase-two profit threshold and to at most entry price * (1 - locked-profit percentage / 100) after the phase-three profit threshold.
Exit: Long, trailing is enabled AND the trail is active after highest high since entry has reached the effective trail-activation profit percentage AND low <= highest high since entry * (1 - effective trail distance percentage / 100).
Exit: Short, trailing is enabled AND the trail is active after lowest low since entry has reached the effective trail-activation profit percentage AND high >= lowest low since entry * (1 + effective trail distance percentage / 100).
Exit: Long, long-only mode AND position is long AND short raw signal.
Exit: Short, short-only mode AND position is short AND long raw signal.
