Calculation: Gap threshold = max(ATR(ATR lookback), minimum price increment) * minimum gap ATR multiple
Calculation: Displacement threshold = max(gap threshold * displacement gap multiplier, max(ATR(ATR lookback), minimum price increment) * minimum displacement ATR multiple)
Calculation: Displacement zone height = max(gap threshold, min(abs(close - close[1]) * displacement zone fraction, max(ATR(ATR lookback), minimum price increment) * displacement zone ATR cap))
Calculation: Gap bounds = for a bullish gap, use classic open-gap bounds [max(open, close[1]), min(open, close[1])] if the classic gap qualifies; otherwise use wick-gap bounds [low, high[1]] if permitted and qualifying; otherwise body-gap bounds [min(open, close), max(open[1], close[1])] if permitted and qualifying; otherwise displacement bounds [close[1] + displacement zone height, close[1]]. For a bearish gap, use classic bounds [max(open, close[1]), min(open, close[1])] if qualifying; otherwise wick bounds [low[1], high] if permitted and qualifying; otherwise body bounds [min(open[1], close[1]), max(open, close)] if permitted and qualifying; otherwise displacement bounds [close[1], close[1] - displacement zone height].
Calculation: Gap fill percent = 100 * clamp(maximum fill since gap creation of bullish (gap top - low) / max(gap height, minimum price increment) or bearish (high - gap bottom) / max(gap height, minimum price increment), 0, 1)
Calculation: Gap state = on confirmed bars after gap creation and through the zone projection, accepted if bullish close <= gap bottom or bearish close >= gap top; otherwise rejected if fill percent >= minimum rejection fill, fill percent < full-fill threshold, and bullish close > gap top or bearish close < gap bottom; otherwise full if fill percent >= full-fill threshold; otherwise partial if fill percent >= minimum rejection fill; otherwise fresh. An accepted state persists, and a prior rejected state remains rejected if the next state would be partial.
Calculation: Readiness score = round(clamp(gap-size score + fill score + reaction score + participation score + recency score, 0, score maximum)), where gap-size score = clamp((gap height / max(ATR(ATR lookback), minimum price increment)) / gap-score ATR scale, 0, 1) * gap-size score weight; fill score = clamp(if fill percent >= minimum rejection fill then fill-score cap - abs(fill percent - preferred fill percent) * fill-deviation penalty else below-minimum-fill score, 0, fill-score cap); reaction score = rejected-state weight if rejected, else touched-zone weight if high >= gap bottom and low <= gap top, else partial-fill weight if partial, else other-state weight; participation score = clamp(clamp(((high - low) / max(ATR(ATR lookback), minimum price increment)) / range-score ATR scale, 0, 1) * range weight + volume factor * volume weight, 0, 1) * participation weight; volume factor = clamp(volume / SMA(volume, volume-average lookback), 0, volume-ratio cap) / volume-ratio cap if that SMA is positive, else neutral volume factor; recency score = clamp(1 - clamp(zone age bars / projection bars, 0, 1), 0, 1) * recency weight.
Long: a bullish gap candidate exists (open - close[1] >= gap threshold, or the selected detection mode permits wick gaps and low - high[1] >= gap threshold, or it permits body gaps and min(open, close) - max(open[1], close[1]) >= gap threshold, or it permits displacement gaps and close > high[1] and close - close[1] >= displacement threshold) AND the gap-confirmation setting permits the current bar AND no prior gap exists or the current bar is at least the minimum gap spacing after the prior gap creation
Short: a bearish gap candidate exists (close[1] - open >= gap threshold, or the selected detection mode permits wick gaps and low[1] - high >= gap threshold, or it permits body gaps and min(open[1], close[1]) - max(open, close) >= gap threshold, or it permits displacement gaps and close < low[1] and close[1] - close >= displacement threshold) AND no bullish gap candidate exists AND the gap-confirmation setting permits the current bar AND no prior gap exists or the current bar is at least the minimum gap spacing after the prior gap creation
Long: an active bullish gap zone within its projection is in the rejected state AND readiness score >= readiness threshold
Short: an active bearish gap zone within its projection is in the rejected state AND readiness score >= readiness threshold
Long: an active bearish gap zone within its projection is accepted
Short: an active bullish gap zone within its projection is accepted
