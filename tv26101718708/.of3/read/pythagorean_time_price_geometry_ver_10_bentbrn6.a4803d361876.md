Calculation: selected swing = in manual mode, the specified prior high and low when both offsets are positive; otherwise, retain confirmed pivot highs and lows within a history length of base period × history multiplier, using pivot half-width max(pivot-width floor, int(base period / swing-width divisor)); expected duration = base period × selected period fraction; search radius = max(search-radius floor, 2 × int(base period / swing-width divisor)); minimum range = ATR(base period) × minimum-swing ATR multiple; ideal ratio = minimum range / expected duration. Scan stored high-low pivot pairs in order, rejecting pairs at the same bar, with nonpositive range, range below minimum, duration outside the search radius, ratio above ideal ratio × stability-mode ratio limit, failing the stability test, or with both endpoints within one base period of the respective prior endpoints. The stability test passes without a prior swing; otherwise it passes when candidate range ≥ prior range × stability threshold OR candidate high > prior high + prior range × boundary fraction OR candidate low < prior low − prior range × boundary fraction. Score each eligible pair as 1 / (abs(ratio − ideal ratio) / (ideal ratio × score offset + score epsilon) + score offset) + 1 / (abs(duration − expected duration) / search radius + score offset) + range / (minimum range + score epsilon). Starting with best score −1, update the best pair when its score exceeds best score × first score-growth factor and either there is no prior swing or its score exceeds best score × second score-growth factor and both endpoints are farther than two base periods from the respective prior endpoints. Use the best pair if its score is positive; otherwise retain the prior swing.
Calculation: Pythagorean time node = for either the base or doubled scale, let G = swing duration × scale, P = round(sqrt(G² + G²)), H = round(sqrt(G² + (G / 2)²)), and R = (current bar index − earlier swing endpoint bar) modulo P; true when P > 0 and R = H modulo P OR R = G modulo P.
Calculation: grid cell = cell height (selected Pythagorean triple’s second leg / first leg) × selected swing range × square scale; origin is negative cell height in option calculation mode, otherwise max(min(swing low, lowest(low, grid-origin lookback)) − grid-origin offset multiplier × cell height, 0); bottom = origin + int((close − origin) / cell height) × cell height; top = bottom + cell height.
