Calculation: CurrencyStrength(C) = cumulative sum over chart bars of the per-bar mean signed (close-open)/open*100 return of C against every other configured non-gold currency; for gold, use its returns against all configured non-gold currencies. Use the pair return when C is first and its negation when C is second.
Calculation: CurrencyPriority(C) = case-insensitive rank in the fixed order gold, euro, pound, Australian dollar, New Zealand dollar, US dollar, Canadian dollar, Swiss franc, yen, then all other currencies; a lower rank has higher priority.
Long: For a candidate gap, let S be the currency with greater CurrencyStrength and W the currency with lesser CurrencyStrength (on a tie, use the later configured currency as S; for the gold/first-currency gap, use the first configured currency as S); the absolute strength difference is among the top K candidate gaps, and CurrencyPriority(S) < CurrencyPriority(W). Candidate gaps are all pairs of configured non-gold currencies plus gold versus the first configured currency; rank them by descending gap, preserving generation order for ties (configured currency pairs in input order, then gold versus the first configured currency). Buy S/W.
