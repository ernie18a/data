Calculation: Alignment = using the same selected MA type (SMA, EMA, HMA, RMA, VWMA, or WMA) for seven lookbacks P1 < P2 < P3 < P4 < P5 < P6 < P7, let score be the number of true comparisons among close > MA(close,P1), MA(close,P1) > MA(close,P2), ..., MA(close,P6) > MA(close,P7); return 1 if close > MA(close,P1) > ... > MA(close,P7), -1 if close < MA(close,P1) < ... < MA(close,P7), otherwise 0.5 if score > 5, -0.5 if score < 2, 0.25 if score > 3, and -0.25 otherwise.
Calculation: Signal state = +1 if (lowest(Alignment, alignment lookback) > 0 OR highest(Alignment, alignment lookback) = 1) AND highest(high, shorter high-low lookback) = highest(high, longer high-low lookback); else -1 if NOT that +1 condition AND (highest(Alignment, alignment lookback) < 0 OR lowest(Alignment, alignment lookback) = -1) AND lowest(low, shorter high-low lookback) = lowest(low, longer high-low lookback); otherwise 0. The shorter high-low lookback is less than the longer one.
Long: Signal state = +1
Short: Signal state = -1
Calculation: Long stop = if Signal state > 0 OR position is long, let C = close - stop-multiple * ATR(ATR lookback); use C if C >= Long stop[1] AND close >= Short stop[1], otherwise Long stop[1]; else if Signal state < 0 OR position is short, let C = close - compound-multiple * ATR(ATR lookback); use Long stop[1] if C > Long stop[1] OR close > Long stop[1], otherwise C; otherwise close - stop-multiple * ATR(ATR lookback).
Calculation: Short stop = if Signal state > 0 OR position is long, let C = close + compound-multiple * ATR(ATR lookback); use Short stop[1] if C < Short stop[1] OR close < Short stop[1], otherwise C; else if Signal state < 0 OR position is short, let C = close + stop-multiple * ATR(ATR lookback); use Short stop[1] if C > Short stop[1] OR close > Long stop[1], otherwise C; otherwise close + stop-multiple * ATR(ATR lookback).
Calculation: T1 high filter = let H be the high of the last completed T1 bar, sampled on chart bars, and P be a chart-bar offset; ((H is missing OR H[P] is missing OR H > H[P]) AND (H is missing OR H[2P] is missing OR H > H[2P])) OR (if H is missing then true, else if H[P] is missing then close > H, else if H[2P] is missing then close > max(H,H[P]), else close > max(H,min(H[P],H[2P]))).
Calculation: T1 low filter = let L be the low of the last completed T1 bar, sampled on chart bars, and use the same chart-bar offset P as for the T1 high filter; ((L is missing OR L[P] is missing OR L < L[P]) AND (L is missing OR L[2P] is missing OR L < L[2P])) OR (if L is missing then true, else if L[P] is missing then close < L, else if L[2P] is missing then close < min(L,L[P]), else close < min(L,max(L[P],L[2P]))).
Long: Signal state = +1 AND close - re-entry-multiple * ATR(ATR lookback) > Long stop AND T1 high filter AND datetime is on or after January 1 in the instrument timezone of the current year minus a backtest-lookback-years parameter AND the trade-direction setting permits long entries.
Short: Signal state = -1 AND close + re-entry-multiple * ATR(ATR lookback) < Short stop AND T1 low filter AND datetime is on or after January 1 in the instrument timezone of the current year minus a backtest-lookback-years parameter AND the trade-direction setting permits short entries.
Exit: long, low <= Long stop OR (Signal state = -1 AND exit-on-signal is enabled)
Exit: short, high >= Short stop OR (Signal state = +1 AND exit-on-signal is enabled)
