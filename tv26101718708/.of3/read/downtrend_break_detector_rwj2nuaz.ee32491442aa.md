Calculation: StoredPivots = list of (bar, price); on each bar where PivotHigh(high, pivot length, pivot length) is confirmed, append (current bar - pivot length, that PivotHigh value), then remove entries whose bar is more than max history bars before the current bar
Calculation: RightAnchorBar = most recent bar among the last pivot length bars, including the current bar, whose high equals highest(high, pivot length)
Calculation: LatestPivotLowPrice = value of the most recent PivotLow(low, pivot length, pivot length) confirmed on or before the current bar; undefined if none
Calculation: BestLine = the candidate line with the largest (RightAnchorBar - leftBar) among stored pivots (leftBar, leftPrice) meeting all of: current bar - leftBar <= max left-anchor age; leftPrice > high at RightAnchorBar; RightAnchorBar - leftBar >= min anchor span; 100 * (leftPrice - high at RightAnchorBar) / leftPrice >= min anchor drop; violations <= max violations; min touches <= touches <= max touches; where the candidate runs from (leftBar, leftPrice) to (RightAnchorBar, high at RightAnchorBar), lineValue(k) = leftPrice + slope * (k - leftBar), slope = (high at RightAnchorBar - leftPrice) / (RightAnchorBar - leftBar), violations = count of bars k with leftBar < k < RightAnchorBar and high at k > lineValue(k) * (1 + pierce tolerance / 100), and touches = count of stored pivots (k, price) with leftBar < k < RightAnchorBar and lineValue(k) * (1 - touch tolerance / 100) <= price <= lineValue(k) * (1 + pierce tolerance / 100); BestLine is none if no candidate qualifies, otherwise it carries leftBar, leftPrice, rightBar = RightAnchorBar, slope, touches, spacing = population std dev of differences between consecutive touch bars (0 if fewer than 2 touches), and touch age = current bar - newest touch bar
Calculation: Line = (PivotHigh confirmed on the current bar OR RightAnchorBar != RightAnchorBar[1]) ? BestLine : Line[1]
Calculation: Up(x, cuts, points) = points of the first cut c, cuts in listed descending order, with x >= c; otherwise the last entry of points (points has one more entry than cuts)
Calculation: Down(x, cuts, points) = points of the first cut c, cuts in listed ascending order, with x <= c; otherwise the last entry of points (points has one more entry than cuts)
Calculation: QualityScore = Up(Line touches, touch cuts, touch points) + Down(Line spacing / (Line rightBar - Line leftBar), spacing cuts, spacing points) + Down(Line touch age, recency cuts, recency points) + HL points, where HL points = 0 if LatestPivotLowPrice or the second most recent PivotLow value is undefined; HL high points if LatestPivotLowPrice > that value * (1 + HL margin / 100); HL low points if LatestPivotLowPrice > that value; otherwise 0
Calculation: ConfirmBars = (auto-confirm on) ? (QualityScore >= confirm split score ? fast confirm bars : slow confirm bars) : manual confirm bars
Calculation: ConsecutiveAbove = number of consecutive bars ending at the current bar such that, on each such bar k, close > (Line leftPrice + Line slope * (k - Line leftBar)) * (1 + break buffer / 100) AND close > open
Calculation: Fired = Line exists AND Line[1] exists AND Line leftBar = Line[1] leftBar AND ((Breakout[1] AND NOT Breakout[2]) OR Fired[1])
Calculation: Breakout = Line exists AND NOT Fired AND current bar - Line rightBar <= max right-anchor age AND LatestPivotLowPrice exists AND close > LatestPivotLowPrice * (1 - recent-low tolerance / 100) AND QualityScore >= min quality score AND ConsecutiveAbove >= ConfirmBars AND volume / SMA(volume, volume MA length) >= volume surge multiple
Long: Breakout AND NOT Breakout[1]
Calculation: Target(m, p) = entry price + (ATR switch on ? m * ATR(ATR length) at entry bar : entry price * p / 100)
Calculation: Stop = entry price - (ATR switch on ? SL multiple * ATR(ATR length) at entry bar : entry price * SL percent / 100)
Calculation: HighSinceEntry = highest high over bars after the entry bar through the current bar
Calculation: TrailStop = HighSinceEntry >= Target(TP2 multiple, TP2 percent) ? Target(TP1 multiple, TP1 percent) : HighSinceEntry >= Target(TP1 multiple, TP1 percent) ? entry price : Stop, where TP1 < TP2 < TP3 in distance
Exit: long, bar after entry bar AND high >= Target(TP3 multiple, TP3 percent)
Exit: long, bar after entry bar AND low <= TrailStop
