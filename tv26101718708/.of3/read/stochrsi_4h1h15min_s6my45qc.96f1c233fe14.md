Calculation: Volume-weighted RSI = RSI(EMA(cumulative sum(change(close) * volume), delta smoothing lookback), RSI lookback) on T3 bars
Calculation: Volume-weighted RSI spread = EMA(volume-weighted RSI, shorter EMA lookback) - EMA(volume-weighted RSI, longer EMA lookback) on T3 bars; these lookbacks are shared with MACD
Calculation: Long trailing stop level = max(entry price, highest close since entry) * (1 - trailing parameter)
Calculation: Short trailing stop level = min(entry price, lowest close since entry) * (1 + trailing parameter)
Calculation: Long ramp stop level starts at entry price * (1 - ramp start parameter) and is multiplied by (1 + per-bar ramp parameter) on each subsequent long-position chart bar
Calculation: Short ramp stop level starts at entry price * (1 + ramp start parameter) and is multiplied by (1 - per-bar ramp parameter) on each subsequent short-position chart bar
Long: MACD Histogram(close, shorter EMA lookback, longer EMA lookback, signal lookback) > 0 and volume-weighted RSI spread > 0, calculated on T3 bars and sampled onto chart bars using the current T3 bar while it forms
Short: MACD Histogram(close, shorter EMA lookback, longer EMA lookback, signal lookback) < 0 and volume-weighted RSI spread < 0, calculated on T3 bars and sampled onto chart bars using the current T3 bar while it forms
Long: long entries enabled and position flat on a confirmed chart bar and Stochastic %D on the chart bars < long entry threshold and current Stochastic %D > prior chart-bar value and Stochastic %D on T1, sampled onto chart bars, at the shorter chart-bar lag >= its value at the longer chart-bar lag and (RSI clause disabled or the latest RSI SMA crossing event was upward through the long RSI threshold) and (MACD/RVSI filter disabled or MACD Histogram(close, shorter EMA lookback, longer EMA lookback, signal lookback) > 0 and volume-weighted RSI spread > 0, calculated on T3 bars and sampled onto chart bars using the current T3 bar while it forms); the Stochastic %D values use shared stochastic length, %K smoothing, and %D smoothing parameters, and the T1 value uses the current T1 bar while it forms
Short: short entries enabled and position flat on a confirmed chart bar and Stochastic %D on the chart bars > short entry threshold and current Stochastic %D < prior chart-bar value and Stochastic %D on T1, sampled onto chart bars, at the shorter chart-bar lag <= its value at the longer chart-bar lag and (RSI clause disabled or the latest RSI SMA crossing event was downward through the short RSI threshold) and (MACD/RVSI filter disabled or MACD Histogram(close, shorter EMA lookback, longer EMA lookback, signal lookback) < 0 and volume-weighted RSI spread < 0, calculated on T3 bars and sampled onto chart bars using the current T3 bar while it forms); the Stochastic %D values use shared stochastic length, %K smoothing, and %D smoothing parameters, and the T1 value uses the current T1 bar while it forms
Exit: Long, Stochastic %D on the chart bars crosses below the long exit threshold or close > entry price * (1 + take-profit parameter) or low <= long trailing stop level or close < long ramp stop level
Exit: Short, Stochastic %D on the chart bars crosses above the short exit threshold or close < entry price * (1 - take-profit parameter) or high >= short trailing stop level or close > short ramp stop level
