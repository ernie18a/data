Calculation: normalized momentum = clamp(z-score((EMA(close, shorter lookback) - EMA(close, longer lookback)) / ATR(ATR lookback), normalization lookback), -3, 3)
Calculation: normalized volume delta = clamp(EMA(sign(close - open) * volume, volume-delta lookback) / SMA(volume, normalization lookback), -3, 3), or 0 when the denominator is 0
Calculation: normalized spread regime = clamp(z-score(SMA((high - low) / (close == 0 ? 1 : close), spread lookback) / SMA(SMA((high - low) / (close == 0 ? 1 : close), spread lookback), normalization lookback) - 1, normalization lookback), -3, 3), or 0 when the spread average or standard deviation is 0
Calculation: normalized liquidity = clamp(z-score(SMA(volume / (high - low == 0 ? tick size : high - low), liquidity lookback) / SMA(SMA(volume / (high - low == 0 ? tick size : high - low), liquidity lookback), normalization lookback) - 1, normalization lookback), -3, 3), or 0 when the liquidity average or standard deviation is 0
Calculation: forecast = mean of stochastic forward passes from an online-trained, single-hidden-layer tanh neural network using normalized momentum, normalized volume delta, normalized spread regime, and normalized liquidity as inputs, with Monte Carlo dropout and Gaussian weight noise; train on replayed feature vectors against close change over the forecast horizon divided by ATR
Calculation: normalized forecast uncertainty = min(1, current forecast standard deviation / rolling maximum forecast standard deviation over an uncertainty lookback), or 0 when the maximum is 0
Long: forecast is available AND forecast > positive forecast threshold AND normalized forecast uncertainty < uncertainty threshold
Short: forecast is available AND forecast < negative forecast threshold AND normalized forecast uncertainty < uncertainty threshold
