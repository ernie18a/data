Calculation: T1 POC = midpoint of the maximum-volume price bin spanning the last completed T1 bar’s high-low, using T2 OHLCV bars, bin-count, profile-allocation method, body-weight parameter, and profile-session filter; break ties by proximity to VWAP(close, those T2 bars), then the lower bin, and round to minimum tick
Calculation: Consecutive-POC state = initialize neutral with no reference or prior trend; update when a new completed T1 POC becomes available by comparing it with the preceding completed T1 POC: bullish state stays bullish while POC rises, otherwise becomes neutral with current POC as reference and prior trend bullish; bearish state stays bearish while POC falls, otherwise becomes neutral with current POC as reference and prior trend bearish; neutral without a reference becomes bullish or bearish after the POC direction confirmation count consecutive rises or falls; neutral with a reference becomes bullish when a rising POC exceeds the reference, or when a falling POC drops below the reference becomes bearish if prior trend was bullish, otherwise possible ranging with direction down and count one; possible ranging becomes bullish or bearish after the POC direction confirmation count consecutive nonzero POC changes in the same direction, resetting count to one and direction to the latest change on a mismatch or zero; store each POC change direction for the next update
Calculation: Mean chart-bar volume in current T1 period = sum(chart-bar volume since the period began) / count(chart bars since the period began)
Long: On chart bars, Consecutive-POC state is bullish
Short: On chart bars, Consecutive-POC state is bearish
Long: On chart bars, Consecutive-POC state is bullish AND MAX(chart-bar high since the current T1 period began) > T1 POC AND close > T1 POC AND volume > Mean chart-bar volume in current T1 period * volume multiplier AND count(chart bars in current T1 period) >= minimum chart-bar count
Short: On chart bars, Consecutive-POC state is bearish AND MAX(chart-bar high since the current T1 period began) > T1 POC AND close < T1 POC AND volume > Mean chart-bar volume in current T1 period * volume multiplier AND count(chart bars in current T1 period) >= minimum chart-bar count
Long: The first later chart bar in the same T1 period after a Long setup signal where open < close AND close > T1 POC
Short: The first later chart bar in the same T1 period after a Short setup signal where open > close AND close < T1 POC
