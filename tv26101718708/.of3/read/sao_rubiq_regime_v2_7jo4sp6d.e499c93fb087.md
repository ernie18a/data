Calculation: Confirmed pivot-high label = on a confirmed PivotHigh(high, shared left/right pivot lookback), HH if its price exceeds the previous confirmed pivot high, otherwise LH; undefined for the first pivot high.
Calculation: Confirmed pivot-low label = on a confirmed PivotLow(low, shared left/right pivot lookback), HL if its price is greater than or equal to the previous confirmed pivot low, otherwise LL; undefined for the first pivot low.
Calculation: S/R bounce event = process every confirmed pivot high and low into shared price clusters: match the nearest stored cluster within current ATR(high, low, close, ATR lookback) × cluster-tolerance parameter when that tolerance is positive, keeping the earliest cluster on distance ties; otherwise create a cluster. Increment its touch count and retain its first pivot bar. On insertion, evict the oldest cluster if the active-level cap is reached. Emit resistance reversal for a high pivot or support reversal for a low pivot when its cluster touch count reaches the touch-count threshold parameter and the pivot-bar distance from the first touch is at most the maximum-age parameter; emit again on each qualifying touch.
Calculation: Effective trend = initialize structural trend as UNKNOWN, pivot labels as undefined, and reversal as inactive. On each chart bar, process any confirmed high pivot before any confirmed low pivot, updating the corresponding latest label and setting the reversal direction and remaining count to the reversal-persistence parameter on each S/R bounce event. If either pivot occurs and the latest labels are HH and HL, change structural trend to UP and clear the reversal only if structural trend was not already UP; else, if the labels are LH and LL, change it to DOWN and clear the reversal only if structural trend was not already DOWN; else, set it to RANGE if both labels exist. Effective trend is the active reversal direction while its remaining count is positive, otherwise structural trend; decrement the count after each bar on which reversal overrides structural trend.
Calculation: Bullish RSI agreement = count across T1, T2, T3, T4, and T5 of RSI(close, shared RSI lookback) exceeding that timeframe's separate bullish-threshold parameter. RSI runs on each T's bars and is sampled on chart bars with lookahead off: the last completed T bar historically and the T bar still forming in real time. Use the bullish missing-value fallback parameter when RSI is unavailable.
Calculation: Bearish RSI agreement = count across T1, T2, T3, T4, and T5 of RSI(close, shared RSI lookback) below that timeframe's separate bearish-threshold parameter. RSI runs on each T's bars and is sampled on chart bars with lookahead off: the last completed T bar historically and the T bar still forming in real time. Use the bearish missing-value fallback parameter when RSI is unavailable.
Calculation: Normalized realized volatility = StDev(log(close / close[1]), realized-volatility lookback) × sqrt(realized-volatility lookback) divided by the median of that same series over the shared normalization lookback; undefined when the median is zero.
Calculation: Normalized ATR deviation = (ATR(high, low, close, ATR lookback) − median of that ATR over the shared normalization lookback) / StDev of that ATR over the shared normalization lookback; undefined when the standard deviation is zero. Use the same ATR lookback as in the S/R bounce calculation.
Calculation: Raw regime = STRESS if normalized realized volatility exceeds its stress threshold parameter or normalized ATR deviation exceeds its separate stress threshold parameter (undefined measures count as non-stress); otherwise BULL_CALM if effective trend is UP and bullish RSI agreement is at least the RSI-agreement threshold parameter; otherwise BEAR_CALM if effective trend is DOWN and bearish RSI agreement is at least that threshold; otherwise CHOPPY if effective trend is UP with bullish agreement below the threshold, DOWN with bearish agreement below the threshold, or either reversal direction; otherwise RANGE if effective trend is RANGE; otherwise UNCERTAIN.
Calculation: Committed regime = initialize committed and previous raw regime as UNCERTAIN and candidate count as zero. On each chart bar, increment the candidate count if raw regime equals the previous raw regime; otherwise set previous raw regime to raw regime and candidate count to one. When candidate count reaches the minimum-run parameter, set committed regime to raw regime; otherwise retain the prior committed regime.
