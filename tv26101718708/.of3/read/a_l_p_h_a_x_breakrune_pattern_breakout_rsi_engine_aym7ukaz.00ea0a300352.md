Calculation: Pattern = on chart bars, use the two latest confirmed pivot highs and lows, with the same pivot lookback on both sides. A pattern requires all four pivots, the latest pivot bar within the freshness lookback, and max(high pivots) - min(low pivots) >= minimum pattern height * ATR(chart-bar lookback). In priority order: ascending triangle if abs(highs' difference) <= flat tolerance * ATR and latest low > previous low + trend tolerance * ATR (resistance = max(highs), support = min(lows), bullish bias); descending triangle if abs(lows' difference) <= flat tolerance * ATR and latest high < previous high - trend tolerance * ATR (same levels, bearish bias); range if both differences are within flat tolerance * ATR (same levels, neutral bias); bull channel if latest high > previous high + trend tolerance * ATR and latest low > previous low + trend tolerance * ATR (resistance = latest high, support = latest low, bullish bias); bear channel if latest high < previous high - trend tolerance * ATR and latest low < previous low - trend tolerance * ATR (resistance = latest high, support = latest low, bearish bias). Otherwise there is no pattern. The pivot lookback, freshness, flat tolerance, trend tolerance, minimum pattern height, and ATR lookback are separate parameters.
Calculation: Pending break state = on chart bars, start or replace the pending state when a valid pattern's close first crosses above resistance + break threshold * ATR, with the previous close at or below that boundary and pattern bias neutral or bullish, or first crosses below support - break threshold * ATR, with the previous close at or above that boundary and pattern bias neutral or bearish. Store the direction, broken resistance or support, and bar. While its age is within the fakeout window, mark an upward break fake if close < stored resistance and (high - max(open, close)) / max(high - low, minimum price increment) >= wick rejection threshold; mark a downward break fake if close > stored support and (min(open, close) - low) / max(high - low, minimum price increment) >= that threshold. Mark an upward break true once age >= confirmation count - one and all closes in the confirmation lookback exceed stored resistance, if no fakeout has been marked; mark a downward break true when all those closes are below stored support. True and fake flags persist until a signal or a new pending break. Clear an unconfirmed true break after the fakeout window expires; a true break remains pending.
Calculation: Fast RSI slope = RSI(close, shorter RSI lookback) - RSI(close, shorter RSI lookback) from the slope lookback bars ago; the slope lookback is a separate chart-bar parameter.
Calculation: Core RSI slope = RSI(close, longer RSI lookback) - RSI(close, longer RSI lookback) from the slope lookback bars ago; the longer RSI lookback is separate from and longer than the fast RSI lookback.
Calculation: HTF bias = bullish when EMA(close, shorter EMA lookback, T1) > EMA(close, longer EMA lookback, T1) and T1 close > the shorter EMA; bearish when both comparisons are reversed; otherwise neutral. These T1 values are sampled onto chart bars with lookahead off: historical bars use completed T1 values, while realtime bars can use the still-forming T1 bar. The T1 timeframe and the two EMA lookbacks are parameters; the shorter EMA lookback is shorter than the longer one.
Calculation: Volume confirmation = volume confirmation disabled OR volume >= SMA(volume, volume-average lookback) * volume multiple. These calculations use chart bars.
Calculation: Choppiness pass = chop filter disabled OR Choppiness Index(high, low, close, chop lookback) < chop threshold. This calculation uses chart bars.
Calculation: Quality score(direction, setup) = min(score cap, size weight if two confirmed pivot highs and lows exist and max(high pivots) - min(low pivots) >= minimum pattern height * ATR, plus RSI weight if that direction's true-break RSI condition holds, plus true-break setup weight or trap setup weight according to setup, plus volume weight if volume confirmation passes, plus chop weight if Choppiness pass, plus HTF points). HTF points are the neutral weight when the HTF bias layer is disabled; otherwise they are the aligned weight when HTF bias matches direction and zero when it does not. All weights, score cap, and minimum score are separate parameters. ATR and pivots use chart bars; size and score are evaluated on the current chart bar.
Long: active bias is bullish (pending-break direction when one exists; otherwise the qualified pattern bias).
Short: active bias is bearish (pending-break direction when one exists; otherwise the qualified pattern bias).
Long: signal display enabled AND cooldown elapsed AND (hard HTF alignment disabled OR HTF bias bullish) AND Choppiness pass AND quality score for the true-break setup >= minimum score AND (active pending upward break marked true AND RSI(close, fast lookback) > long trigger AND RSI(close, longer RSI lookback) > RSI midpoint AND Fast RSI slope > 0 AND Core RSI slope >= 0 OR trap reversals enabled AND active pending downward break marked fake AND RSI(close, fast lookback) crosses above the RSI midpoint on this bar AND Fast RSI slope > 0).
Short: signal display enabled AND cooldown elapsed AND (hard HTF alignment disabled OR HTF bias bearish) AND Choppiness pass AND quality score for the true-break setup >= minimum score AND (active pending downward break marked true AND RSI(close, fast lookback) < short trigger AND RSI(close, longer RSI lookback) < RSI midpoint AND Fast RSI slope < 0 AND Core RSI slope <= 0 OR trap reversals enabled AND active pending upward break marked fake AND RSI(close, fast lookback) crosses below the RSI midpoint on this bar AND Fast RSI slope < 0).
Long: an active pending downward break is marked fake within the fakeout window.
Short: an active pending upward break is marked fake within the fakeout window.
