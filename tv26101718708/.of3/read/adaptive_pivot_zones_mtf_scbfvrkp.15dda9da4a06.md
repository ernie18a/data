Calculation: Pivot zone(T) = on T bars, let H and L be the latest confirmed PivotHigh(high, pivot lookback, pivot lookback) and PivotLow(low, pivot lookback, pivot lookback); apply SMA(smoothing lookback) to each of L + (H - L) × each of three separate level coefficients; the zone boundaries are the minimum and maximum of the three smoothed levels, and the middle line is the smoothed level using the second coefficient.
Calculation: Trend state(T) = initialize bullish; in full-band mode, set bearish when close < the lower boundary and bullish when close > the upper boundary; in mid-line mode, set bearish when close < the middle line and bullish when close > the middle line; otherwise set neutral if neutral mode is enabled for the chart timeframe, or retain the previous state. Neutral mode is disabled for T1 and T2.
Calculation: T1 trend state = Trend state(T1), calculated on T1 bars and sampled on chart bars with lookahead off; it can use the forming T1 bar in real time and is confirmed at its close historically.
Calculation: T2 trend state = Trend state(T2), calculated on T2 bars and sampled on chart bars with lookahead off; it can use the forming T2 bar in real time and is confirmed at its close historically.
Long: chart-timeframe trend state is bullish OR T1 trend state is bullish OR T2 trend state is bullish
Short: chart-timeframe trend state is bearish OR T1 trend state is bearish OR T2 trend state is bearish
