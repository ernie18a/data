Calculation: Relative effort = clamp(raw effort / (selected baseline + epsilon), 0, relative-effort cap); raw effort is volume when volume is available and its validity-lookback SMA is positive, otherwise true range; the global baseline is EMA(raw effort, fallback lookback); each intraday local-minute bucket is seeded with its first raw-effort value and thereafter updated using its seasonal smoothing lookback, with the pre-update bucket baseline selected only after the minimum sample count, otherwise use the global baseline.
Calculation: Gravity metrics = effort is SMA(relative effort, gravity lookback); close location is clamp((2 × close − high − low) / (high − low), −1, 1), or 0 when high = low; positive and negative effort are SMA(relative effort × max(close location, 0), gravity lookback) and SMA(relative effort × max(−close location, 0), gravity lookback); effort imbalance is (positive effort − negative effort) / (positive effort + negative effort + epsilon); log return is ln(close / close[1]) when both closes are positive, otherwise 0; signed net log move is ln(close / close[gravity lookback]) when both closes are positive, otherwise undefined; path length is SUM(abs(log return), gravity lookback); expected move is STDEV(log return, volatility lookback) × sqrt(gravity lookback); displacement is abs(signed net log move) / (expected move + epsilon); path efficiency is clamp(abs(signed net log move) / (path length + epsilon), 0, 1); upward and downward displacement are SUM(max(log return, 0), gravity lookback) / (expected move + epsilon) and SUM(max(−log return, 0), gravity lookback) / (expected move + epsilon); inefficiency is max(1 − path efficiency, epsilon); raw gravity is ln(1 + effort) − ln(displacement + epsilon) + inefficiency weight × ln(inefficiency + epsilon); gravity is EMA(raw gravity, gravity smoothing lookback); upward and downward gravity use the same formula as raw gravity with positive effort and upward displacement, or negative effort and downward displacement, respectively; directional gravity spread is upward gravity − downward gravity; gravity change is change(gravity), and gravity acceleration is change(gravity change).
Calculation: Robust z(x) = (x − median(x, distribution lookback)) / (1.4826 × median(abs(x − median(x, distribution lookback)), distribution lookback) + epsilon); apply to gravity, effort, displacement, and gravity change.
Calculation: Short checklist score = sum of nine indicators: signed net log move < 0; path efficiency >= min(pre-efficiency threshold, max(high-efficiency threshold − priming margin, 0)); change(path efficiency) > 0; robust z(gravity change) < 0; change(robust z(displacement)) > 0; robust z(effort) > low z threshold; effort imbalance < 0; directional gravity spread > 0; and at least one of (the highest prior-bar robust z(gravity) over the release lookback exceeds the high z threshold, a prior-bar pressure flag is positive within the release lookback, gravity acceleration <= 0). A pressure flag is positive when all are true: robust z(effort) > high z threshold, robust z(displacement) < low z threshold, robust z(gravity change) > slope z threshold, and path efficiency < low-efficiency threshold. The score counts the final OR condition once.
Calculation: Structure bands = KAMA(close, KAMA efficiency lookback, faster smoothing, slower smoothing), with faster smoothing shorter than slower smoothing; structure efficiency is Efficiency Ratio(close, separate structure-efficiency lookback); normalized slope is (KAMA − KAMA[slope lookback]) / ATR(structure ATR lookback); half-width is ATR(structure ATR lookback) × (base width + (1 − clamp(structure efficiency, 0, 1)) × noise expansion); upper and lower bands are KAMA ± half-width.
Calculation: Structure regime = on confirmed chart bars, bullish raw state requires close > KAMA, normalized slope >= minimum positive slope, and structure efficiency >= minimum efficiency; bearish raw state requires close < KAMA, normalized slope <= negative minimum positive slope, and structure efficiency >= minimum efficiency. From neutral, set bullish if bullish raw state, else bearish if bearish raw state, else neutral. From bullish, remain bullish until close is below the lower band for the required consecutive closed bars; then set bearish if bearish raw state, otherwise neutral. From bearish, remain bearish until close is above the upper band for the required consecutive closed bars; then set bullish if bullish raw state, otherwise neutral.
Calculation: Projected wedge = use the latest two confirmed pivot highs and latest two confirmed pivot lows, found with separate left and right pivot lookbacks; project a straight line through each pair to the current chart bar. The wedge start is the later of the older high-pivot and older low-pivot bars. Each edge slope is its pivot price change divided by its pivot-bar change; current and start widths are upper edge minus lower edge at those bars.
Calculation: Mature wedge events = an ascending wedge requires wedge age <= maximum age, each latest pivot higher than its prior pivot, upper slope > 0, lower slope > upper slope, current width > minimum tick size, start width > 0, and current width <= start width × tightness parameter. A descending wedge requires wedge age <= maximum age, each latest pivot lower than its prior pivot, lower slope < 0, upper slope < lower slope, current width > minimum tick size, start width > 0, and current width <= start width × tightness parameter. Each direction's consecutive qualifying-bar run resets to zero when unqualified. A confirmed bullish armed event occurs when the descending run reaches the shared pattern-maturity parameter; a confirmed bearish armed event occurs when the ascending run reaches it. After a prior run reached maturity, a confirmed close above the descending wedge upper edge is an upward break, and a confirmed close below the ascending wedge lower edge is a downward break, subject to the separate direction-specific break cooldowns.
Calculation: Cup candidate = cup rim is highest(high, cup lookback)[1]; cup base is lowest(low, cup lookback); cup depth is rim − base; handle high is highest(high, handle lookback)[1]; handle low is lowest(low, handle lookback); handle depth fraction is (rim − handle low) / cup depth when cup depth > minimum tick size, otherwise an invalid fraction; a candidate requires structure regime >= neutral, cup depth >= ATR(structure ATR lookback) × minimum cup-depth multiple, close >= rim − cup depth × rim-tolerance parameter, handle depth fraction between 0 and maximum handle-depth fraction, and handle high >= rim − cup depth × rim-tolerance parameter.
Calculation: Managed distances = at entry, select either ATR-based or cash-based mode and freeze the resulting distances. In ATR-based mode, stop distance is ATR(management lookback) × stop multiplier; target-one, target-two, target-three, and lock distances are stop distance multiplied by their separate ratio parameters. In cash-based mode, each separate stop, target, and lock cash amount is divided by point value. Round every distance to the nearest minimum tick and floor it at one minimum tick.

Short: On a confirmed chart bar, the structure regime changes into bearish.
Long: On a confirmed chart bar, the descending wedge run reaches the pattern-maturity parameter.
Short: On a confirmed chart bar, the ascending wedge run reaches the pattern-maturity parameter.
Long: On a confirmed chart bar, the cup candidate was true for at least the pattern-maturity parameter before this bar, close > handle high, and the cup-break cooldown has elapsed since the prior cup breakout.
Long: A bullish armed event occurred no more than the armed-to-entry window ago AND (the structure regime changes into bullish OR a matured descending wedge closes above its projected upper edge after its downward-wedge break cooldown).
Short: On a confirmed chart bar, gravity metrics are ready, signed net log move < 0, path efficiency >= high-efficiency threshold, and short checklist score >= score threshold; the raw short condition was false on the prior bar; no SIG9 breakout occurs on this bar; and the short cooldown has elapsed since the most recent SIG9 breakout or short signal.
Long: On chart bars below T1, the signal calculated on the last completed T1 bar changes from false to true, where T1-bar close > SMA(close, trend lookback), T1-bar close crosses above EMA(close, faster lookback), and T1-bar volume / SMA(volume, volume lookback) >= volume threshold; evaluate this signal on confirmed chart-bar closes. On a T1 chart, evaluate it on confirmed T1 bars. On chart timeframes above T1, no signal.
Short: On chart bars below T1, the signal calculated on the last completed T1 bar changes from false to true, where T1-bar close < SMA(close, trend lookback), T1-bar close crosses below EMA(close, faster lookback), and T1-bar volume / SMA(volume, volume lookback) >= volume threshold; evaluate this signal on confirmed chart-bar closes. On a T1 chart, evaluate it on confirmed T1 bars. On chart timeframes above T1, no signal.
Exit: Long, while the managed long is active on a standard chart, on a bar after its entry bar: low <= the active stop OR high − entry price >= target-three distance OR bars since entry >= maximum holding bars; the active stop is entry price − stop distance until target one is reached, then entry price + lock distance starting on the bar after target one.
Exit: Short, while the managed short is active on a standard chart, on a bar after its entry bar: high >= the active stop OR entry price − low >= target-three distance OR bars since entry >= maximum holding bars; the active stop is entry price + stop distance until target one is reached, then entry price − lock distance starting on the bar after target one.
