# 21-50-100-200 Day SMA

- url: https://www.tradingview.com/script/rJn9p4ec-21-50-100-200-Day-SMA/
- type: indicator
- pine_id: PUB;4b0e3fa0efa543b7b2e52cc127605c45
- version: 1.0

## Description

Day Averages regardless of what time period your chart is set too.

## Source Code

````pine
//@version=5
indicator("21-50-100-200 Day SMA", overlay=true)

d21_sma = request.security(syminfo.tickerid, "D", ta.sma(close, 21))
plot(d21_sma, title="21 Day MA", color=color.yellow, linewidth=2)

d50_sma = request.security(syminfo.tickerid, "D", ta.sma(close, 50))
plot(d50_sma, title="50 Day MA", color=color.lime, linewidth=2)

d100_sma = request.security(syminfo.tickerid, "D", ta.sma(close, 100))
plot(d100_sma, title="100 Day MA", color=color.blue, linewidth=2)

d200_sma = request.security(syminfo.tickerid, "D", ta.sma(close, 200))
plot(d200_sma, title="200 Day MA", color=color.red, linewidth=2)
````
