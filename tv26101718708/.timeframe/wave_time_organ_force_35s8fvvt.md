## Description

🌊 WAVE TIME ORGAN FORCE

WAVE TIME ORGAN FORCE is a multi-timeframe market flow and synchronization engine designed to combine organ-based market pressure analysis, EMA-smoothed visual flow, timeframe force propagation, and cinematic wave-style visualization into one clean and powerful trading system.

The indicator was built with two main goals:

1. To measure how market pressure behaves internally.
2. To visualize how that pressure propagates through multiple timeframe layers.

Instead of functioning as a simple oscillator or signal generator, WAVE TIME ORGAN FORCE focuses on market rhythm, synchronization, pressure quality, and directional propagation.

━━━━━━━━━━━━━━━━━━
THE MAIN PHILOSOPHY
━━━━━━━━━━━━━━━━━━

Most traditional indicators analyze only one dimension of the market.

Examples:
• RSI measures momentum strength.
• MACD measures moving average relationship.
• ATR measures volatility.
• OBV measures volume pressure.

WAVE TIME ORGAN FORCE combines several internal market behaviors into one synchronized system.

The indicator tries to answer questions such as:

Is the current movement supported by volume?
Is volatility supporting expansion?
Are multiple timeframes aligned together?
Is momentum propagating upward through the timeframe stack?
Is the market synchronized or internally conflicted?
Is the current structure smooth or chaotic?

The goal is not only to identify direction, but to understand the internal quality of market movement.

ORGAN ENGINE
━━━━━━━━━━━━━━━━━━

Trend Organ

Each organ measures a different type of market behavior.

━━━━━━━━━━━━━━━━━━
TREND ORGAN
━━━━━━━━━━━━━━━━━━

The Trend Organ measures directional pressure using EMA slope behavior.

Instead of only checking whether price is above or below a moving average, the system measures how aggressively the trend itself is moving.

This allows the engine to detect acceleration and directional force more naturally.

━━━━━━━━━━━━━━━━━━
MOMENTUM ORGAN
━━━━━━━━━━━━━━━━━━

The Momentum Organ measures the speed and force of price movement using ROC-based calculations.

This helps the system determine whether the market movement is weak, expanding, slowing down, or accelerating.

━━━━━━━━━━━━━━━━━━
VOLUME ORGAN
━━━━━━━━━━━━━━━━━━

The Volume Organ uses OBV-style pressure calculations to determine whether volume supports the current market movement.

A bullish move without volume support is considered weaker than a move supported by synchronized volume behavior.

━━━━━━━━━━━━━━━━━━
VOLATILITY ORGAN
━━━━━━━━━━━━━━━━━━

The Volatility Organ uses ATR-based directional behavior.

This layer helps the system detect:

Expansion
Compression
Directional volatility pressure

The volatility component is important because strong trends usually expand volatility while weak or exhausted movements often compress.

━━━━━━━━━━━━━━━━━━
RAW ORGAN VALUE
━━━━━━━━━━━━━━━━━━

All organ layers are normalized and merged into a single internal value called the Raw Organ.

The Raw Organ represents the true internal market pressure.

This raw value is preserved internally and is not destroyed by visual smoothing.

This is extremely important.

The calculation engine remains mathematically intact while the visualization becomes smoother and easier to read.

━━━━━━━━━━━━━━━━━━

## Source Code

````pine
//@version=6
indicator("🌊 WAVE TIME ORGAN FORCE", shorttitle="WAVE TIME", overlay=false, max_labels_count=500, max_lines_count=500)

//━━━━━━━━━━━━━━━━━━
// INPUTS
//━━━━━━━━━━━━━━━━━━
trendLen  = input.int(55, "Organ Trend EMA", group="🧠 Organ Engine")
momLen    = input.int(10, "Organ Momentum ROC", group="🧠 Organ Engine")
atrLen    = input.int(14, "Organ ATR Length", group="🧠 Organ Engine")
volLen    = input.int(20, "Volume Direction EMA", group="🧠 Organ Engine")
zLen      = input.int(34, "Z-Score Lookback", group="🧠 Organ Engine")
baseSmooth = input.int(8, "Base Smooth", group="🧠 Organ Engine")
flowSmooth = input.int(21, "EMA Visual Flow Smooth", group="🧠 Organ Engine")

tf1 = input.timeframe("1", "Layer 1", group="🚀 Timeframe Force")
tf2 = input.timeframe("5", "Layer 2", group="🚀 Timeframe Force")
tf3 = input.timeframe("15", "Layer 3", group="🚀 Timeframe Force")
tf4 = input.timeframe("30", "Layer 4", group="🚀 Timeframe Force")
tf5 = input.timeframe("60", "Layer 5", group="🚀 Timeframe Force")
tf6 = input.timeframe("120", "Layer 6", group="🚀 Timeframe Force")

showGlow   = input.bool(true, "Glow / Aura", group="🎨 Visual")
showPanel  = input.bool(true, "Premium Panel", group="🎨 Visual")
showBands  = input.bool(true, "Guide Levels", group="🎨 Visual")
colorBars  = input.bool(true, "Color Main Chart Candles", group="🎨 Visual")
showSignals = input.bool(false, "Show BUY/SELL Labels", group="🎨 Visual")

//━━━━━━━━━━━━━━━━━━
// HELPERS
//━━━━━━━━━━━━━━━━━━
z(src, len) =>
    mean = ta.sma(src, len)
    dev  = ta.stdev(src, len)
    dev != 0 ? (src - mean) / dev : 0.0

barMeter(v, maxv) =>
    n = int(math.round(math.max(math.min(v / maxv, 1.0), 0.0) * 8.0))
    n == 8 ? "████████" :
     n == 7 ? "███████░" :
     n == 6 ? "██████░░" :
     n == 5 ? "█████░░░" :
     n == 4 ? "████░░░░" :
     n == 3 ? "███░░░░░" :
     n == 2 ? "██░░░░░░" :
     n == 1 ? "█░░░░░░░" :
     "░░░░░░░░"

//━━━━━━━━━━━━━━━━━━
// ORGAN FUNCTION
//━━━━━━━━━━━━━━━━━━
organCore() =>
    emaTrend = ta.ema(close, trendLen)
    trendRaw = emaTrend - emaTrend[1]

    momentumRaw = ta.roc(close, momLen)

    obvVal = ta.obv
    obvRaw = obvVal - obvVal[1]

    atr = ta.atr(atrLen)
    priceDir = close > ta.ema(close, volLen) ? 1.0 : -1.0
    atrRaw = (atr - atr[1]) * priceDir

    trendZ = z(trendRaw, zLen)
    momZ   = z(momentumRaw, zLen)
    obvZ   = z(obvRaw, zLen)
    atrZ   = z(atrRaw, zLen)

    rawOrgan = trendZ + momZ + obvZ + atrZ
    baseOrgan = ta.ema(rawOrgan, baseSmooth)

    baseOrgan

//━━━━━━━━━━━━━━━━━━
// MAIN ORGAN VALUE
//━━━━━━━━━━━━━━━━━━
organRaw = organCore()

// Değeri bozmuyoruz: organRaw içeride ana değer.
// Görsel için EMA ile yumuşatılmış akış:
organFlow = ta.ema(organRaw, flowSmooth)
organSignal = ta.ema(organFlow, flowSmooth)

//━━━━━━━━━━━━━━━━━━
// MTF ORGAN FORCE
//━━━━━━━━━━━━━━━━━━
o1 = request.security(syminfo.tickerid, tf1, organRaw[1], gaps=barmerge.gaps_off, lookahead=barmerge.lookahead_off)
o2 = request.security(syminfo.tickerid, tf2, organRaw[1], gaps=barmerge.gaps_off, lookahead=barmerge.lookahead_off)
o3 = request.security(syminfo.tickerid, tf3, organRaw[1], gaps=barmerge.gaps_off, lookahead=barmerge.lookahead_off)
o4 = request.security(syminfo.tickerid, tf4, organRaw[1], gaps=barmerge.gaps_off, lookahead=barmerge.lookahead_off)
o5 = request.security(syminfo.tickerid, tf5, organRaw[1], gaps=barmerge.gaps_off, lookahead=barmerge.lookahead_off)
o6 = request.security(syminfo.tickerid, tf6, organRaw[1], gaps=barmerge.gaps_off, lookahead=barmerge.lookahead_off)

tfForceRaw =
     o1 * 0.10 +
     o2 * 0.13 +
     o3 * 0.17 +
     o4 * 0.18 +
     o5 * 0.20 +
     o6 * 0.22

tfForce = ta.ema(tfForceRaw, flowSmooth)

bullCount =
     (o1 > 0 ? 1 : 0) +
     (o2 > 0 ? 1 : 0) +
     (o3 > 0 ? 1 : 0) +
     (o4 > 0 ? 1 : 0) +
     (o5 > 0 ? 1 : 0) +
     (o6 > 0 ? 1 : 0)

bearCount =
     (o1 < 0 ? 1 : 0) +
     (o2 < 0 ? 1 : 0) +
     (o3 < 0 ? 1 : 0) +
     (o4 < 0 ? 1 : 0) +
     (o5 < 0 ? 1 : 0) +
     (o6 < 0 ? 1 : 0)

cascadeBull = bullCount == 6
cascadeBear = bearCount == 6

//━━━━━━━━━━━━━━━━━━
// QUALITY / CROSS ENGINE
//━━━━━━━━━━━━━━━━━━
crossUp = ta.crossover(organFlow, organSignal)
crossDown = ta.crossunder(organFlow, organSignal)

forceBull = tfForce > 0 and bullCount >= 4
forceBear = tfForce < 0 and bearCount >= 4

qualityBuy =
     crossUp and
     forceBull and
     organFlow > 0

qualitySell =
     crossDown and
     forceBear and
     organFlow < 0

//━━━━━━━━━━━━━━━━━━
// WAVE VISUAL STACK
//━━━━━━━━━━━━━━━━━━
wave1 = ta.ema(o1, flowSmooth)
wave2 = ta.ema(o2, flowSmooth)
wave3 = ta.ema(o3, flowSmooth)
wave4 = ta.ema(o4, flowSmooth)
wave5 = ta.ema(o5, flowSmooth)
wave6 = ta.ema(o6, flowSmooth)

//━━━━━━━━━━━━━━━━━━
// COLORS
//━━━━━━━━━━━━━━━━━━
bullC = color.lime
bearC = color.red
aquaC = color.aqua
goldC = color.yellow
purpleC = color.fuchsia
neutralC = color.gray

mainColor =
     cascadeBull ? goldC :
     cascadeBear ? purpleC :
     organFlow > organSignal and organFlow > 0 ? bullC :
     organFlow < organSignal and organFlow < 0 ? bearC :
     aquaC

barCol =
     qualityBuy ? color.yellow :
     qualitySell ? color.orange :
     forceBull ? color.new(bullC, 0) :
     forceBear ? color.new(bearC, 0) :
     color.new(neutralC, 55)

barcolor(colorBars ? barCol : na)

bgcolor(
     cascadeBull ? color.new(goldC, 90) :
     cascadeBear ? color.new(purpleC, 90) :
     forceBull ? color.new(bullC, 94) :
     forceBear ? color.new(bearC, 94) :
     na
)

//━━━━━━━━━━━━━━━━━━
// PLOTS
//━━━━━━━━━━━━━━━━━━
hline(0, "Zero", color=color.new(color.gray, 70))

plot(showBands ? 3 : na, "Upper Guide", color=color.new(color.red, 75), style=plot.style_circles)
plot(showBands ? -3 : na, "Lower Guide", color=color.new(color.lime, 75), style=plot.style_circles)

plot(showGlow ? organFlow : na, "Organ Glow Outer", color=color.new(mainColor, 88), linewidth=10)
plot(showGlow ? organFlow : na, "Organ Glow Inner", color=color.new(mainColor, 78), linewidth=6)

pOrgan = plot(organFlow, "WAVE TIME Organ Flow", color=mainColor, linewidth=4)
pSignal = plot(organSignal, "EMA Signal", color=color.new(color.white, 10), linewidth=2)

plot(showGlow ? tfForce : na, "TF Force Glow", color=color.new(mainColor, 84), linewidth=8)
pForce = plot(tfForce, "Timeframe Force", color=color.new(mainColor, 0), linewidth=3)

p1 = plot(wave1, "TF Wave 1", color=color.new(color.blue, 78), linewidth=1)
p2 = plot(wave2, "TF Wave 2", color=color.new(color.aqua, 68), linewidth=1)
p3 = plot(wave3, "TF Wave 3", color=color.new(color.lime, 58), linewidth=2)
p4 = plot(wave4, "TF Wave 4", color=color.new(color.yellow, 48), linewidth=2)
p5 = plot(wave5, "TF Wave 5", color=color.new(color.orange, 38), linewidth=3)
p6 = plot(wave6, "TF Wave 6 Macro", color=color.new(mainColor, 0), linewidth=4)

fill(p1, p6, color=color.new(mainColor, 92), title="Wave Stack Aura")
fill(pOrgan, pForce, color=organFlow > tfForce ? color.new(bullC, 90) : color.new(bearC, 90), title="Organ / TF Force Aura")

//━━━━━━━━━━━━━━━━━━
// OPTIONAL SIGNALS
//━━━━━━━━━━━━━━━━━━
plotshape(
     showSignals and qualityBuy,
     title="Quality Buy",
     style=shape.triangleup,
     location=location.bottom,
     color=color.yellow,
     text="BUY",
     textcolor=color.black,
     size=size.small
)

plotshape(
     showSignals and qualitySell,
     title="Quality Sell",
     style=shape.triangledown,
     location=location.top,
     color=color.orange,
     text="SELL",
     textcolor=color.white,
     size=size.small
)

//━━━━━━━━━━━━━━━━━━
// PANEL
//━━━━━━━━━━━━━━━━━━
var table panel = table.new(position.top_right, 2, 8, border_width=1)

if barstate.islast
    stateTxt =
         cascadeBull ? "BULL CASCADE" :
         cascadeBear ? "BEAR CASCADE" :
         forceBull ? "BULL FORCE" :
         forceBear ? "BEAR FORCE" :
         "MIXED WAVE"

    stateCol =
         cascadeBull ? goldC :
         cascadeBear ? purpleC :
         forceBull ? bullC :
         forceBear ? bearC :
         neutralC

    signalTxt =
         qualityBuy ? "QUALITY BUY" :
         qualitySell ? "QUALITY SELL" :
         "WAIT"

    signalCol =
         qualityBuy ? goldC :
         qualitySell ? color.orange :
         neutralC

    rowBG = color.new(color.rgb(12, 15, 25), 5)

    table.cell(panel, 0, 0, "🌊 WAVE TIME", bgcolor=color.black, text_color=color.white)
    table.cell(panel, 1, 0, stateTxt, bgcolor=color.black, text_color=stateCol)

    table.cell(panel, 0, 1, "Organ Flow EMA", bgcolor=rowBG, text_color=color.white)
    table.cell(panel, 1, 1, str.tostring(organFlow, "#.##") + " " + barMeter(math.abs(organFlow), 6), bgcolor=rowBG, text_color=mainColor)

    table.cell(panel, 0, 2, "Raw Organ", bgcolor=rowBG, text_color=color.white)
    table.cell(panel, 1, 2, str.tostring(organRaw, "#.##"), bgcolor=rowBG, text_color=mainColor)

    table.cell(panel, 0, 3, "TF Force", bgcolor=rowBG, text_color=color.white)
    table.cell(panel, 1, 3, str.tostring(tfForce, "#.##") + " " + barMeter(math.abs(tfForce), 6), bgcolor=rowBG, text_color=stateCol)

    table.cell(panel, 0, 4, "Bull Layers", bgcolor=rowBG, text_color=color.white)
````
