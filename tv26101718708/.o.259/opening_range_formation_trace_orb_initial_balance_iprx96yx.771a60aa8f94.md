定義：開場から設定分（既定15分）をオープニングレンジ(OR)とする。H=区間最高値、L=区間最安値、W=H-L、O=区間最初の始値、C=区間最後の終値。

【形成分類による方向（OR確定後に判定。上から順に最初に合致したもの）】
指標：
- 経路効率 eff = |C-O| ÷ 累積経路。累積経路は |最初の終値-O| に、以降の各バーで |終値-前バー終値| を足したもの。上限1。
- 終値位置 cl = (C-L)/W。
- 拡張偏り skew = ((H-O)-(O-L))/W。
- 後半比率 late = (W - 区間前半(50%地点)までに形成済みの幅)/W。
判定：
1. eff>=0.55 かつ cl>=0.72 かつ skew>=0.18 → 上側主導ドライブ＝做多。
2. eff>=0.55 かつ cl<=0.28 かつ skew<=-0.18 → 下側主導ドライブ＝做空。
3. late>=0.35 かつ skew>=0.18 → 後半上側拡張＝做多。
4. late>=0.35 かつ skew<=-0.18 → 後半下側拡張＝做空。
5. late>=0.35 でどちらでもない場合、または回転型、両側形成、混合は方向なし。
OR開始前半のデータが欠けた不完全なORは分類しない。

【OR確定後の受容離脱による方向】
OR確定後の各バーで buf=0.05×W とする。
- 上抜け証拠：終値>H+buf。
- 下抜け証拠：終値<L-buf。
- 両方成立、またはどちらも不成立なら連続カウントを0に戻す。
判定：
- 上抜け証拠が連続2本 → 上側受容離脱＝做多。
- 下抜け証拠が連続2本 → 下側受容離脱＝做空。
- 最初に成立した方向だけを採用する。
- 受容離脱を判定するのは、ORが確定してから設定した持続時間（既定390分）以内のバーだけ。

【離脱後の再侵入と反対端到達】
- 再侵入：上側離脱後、受容離脱の時点より後のバーで終値<=H、または下側離脱後に終値>=L。これは離脱方向の建玉の出場。
- 反対端到達：再侵入後、それより後のバーで、上側離脱だった場合は安値<=L、下側離脱だった場合は高値>=H。上側離脱だった場合は做空、下側離脱だった場合は做多。
- 再侵入と反対端到達を同じバーで成立させない。
