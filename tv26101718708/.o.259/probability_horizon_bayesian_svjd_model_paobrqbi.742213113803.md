【多空判斷】做多：最終機率 P ≥ 0.62，且五個子模型中至少 3 個的 P > 0.5。做空：P ≤ 0.38，且至少 3 個子模型的 P < 0.5。其餘為中性。另外 P > 0.505 為偏多方向，P < 0.495 為偏空方向。READ 沒有出場規則。

【P 的計算】
五個子模型各給出 P(up)。方向 d 為 +1、-1 或 0，強度 s 在 0 到 1 之間。P = 0.5 + 0.1·d·s，d=0 時 P=0.5。

1. 趨勢模型：KAMA(close, 週期10, fast2, slow30)。ER = |close − close[10]| / 近10根 |close 差| 之和。sc = (ER·(2/3 − 2/31) + 2/31)²。KAMA = 前值 + sc·(close − 前值)。n = (KAMA − KAMA[5]) / close。d = sign(n)，s = min(1, |n|·500)。
2. 均值回歸模型：殘差 = close − KAMA。z = (殘差 − SMA60(殘差)) / STDEV60(殘差)。z < −1.5 時 d=+1，z > 1.5 時 d=−1，其餘為 0。s = min(1, |z|/3)。
3. 小波模型：W = 對 close 連續做三次 SMA(2)。n = (W − W[5]) / close。n > 0.0005 時 d=+1，n < −0.0005 時 d=−1，其餘為 0。s = min(1, |n|·400)。
4. Kalman 模型：x 初值為 close，p 初值為 1。每根先令 pp = p + 0.001，K = pp / (pp + 0.1)。再更新 x += K·(close − x)，p = (1 − K)·pp。n = (x − x[5]) / close。d 與 s 的算法同小波模型。
5. Hamilton 模型（週期 ≥15 分鐘才啟用，否則 P=0.5）：
   - r = ln(close / close[1])，m = SMA60(r)，sd = STDEV60(r)。
   - 多頭：均值 max(0.0001, m + 0.5·sd)，標準差 max(0.0001, 0.7·sd)。
   - 空頭：均值 min(−0.0001, m − 0.5·sd)，標準差同多頭。
   - 盤整：均值 0，標準差 max(0.0002, 1.5·sd)。
   - 狀態機率初值為 pBull=0.333、pBear=0.333、pRange=0.334。
   - 每根先做轉移：留在原狀態 0.95，轉到其他兩狀態各 0.025。
   - 再乘上 r 在各狀態常態分布下的密度，最後正規化。
   - P = clamp(0.5 + 0.1·(pBull − pBear), 0.05, 0.95)。

【加權平均】五個權重初值皆為 0.2。每根收盤記錄五個模型的 P。10 根後以 close > 當時 close 判定實際漲跌。損失 = −ln(P)（上漲時）或 −ln(1−P)（下跌時），P 先限制在 [0.01, 0.99]。更新方式為 w ← w·exp(−0.15·損失)，再取 max(0.10, w)，最後正規化使權重和為 1。P_raw = Σ w·P。

【Hawkes 壓縮】事件 = |r| > 2·STDEV20(r)。baseline = SMA100(事件 ? 1 : 0)。λ = λ·e^(−0.2) + (事件 ? 0.5 : 0)。ratio = λ / baseline。ratio > 2 時，mod = min(0.5, (ratio − 2)/2)，否則 mod=0。P1 = 0.5 + (P_raw − 0.5)·(1 − mod)。

【校準壓縮】依 |P1 − 0.5| 分箱：<0.05 不分箱，<0.15 為箱0，<0.25 為箱1，<0.35 為箱2，<0.45 為箱3，其餘為箱4。每根若箱 ≥0 且方向不為 0（P1 > 0.505 為多，P1 < 0.495 為空），就記錄預測。20 根後，若 close > 當時 close 與預測方向一致，即算命中。某箱累積預測 ≥30 次時，命中率 h = 命中數 / 預測數，箱中點 mid = 0.55 + 0.1·箱號。若 h < mid，因子 = max(0.5, h/mid)，否則為 1。最終 P = 0.5 + (P1 − 0.5)·因子。
