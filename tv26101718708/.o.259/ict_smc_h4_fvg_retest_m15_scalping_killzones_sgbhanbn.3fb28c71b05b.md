做多：每根K線先定義 K線做多缺口 = 當根low > 兩根前high（缺口範圍：下緣=兩根前high，上緣=當根low）；缺口高度 = 當根low − 兩根前high，需 ≥ 最小缺口點數（預設6，可關閉）。做空：K線做空缺口 = 當根high < 兩根前low（上緣=兩根前low，下緣=當根high），高度 = 兩根前low − 當根high，需 ≥ 最小缺口點數。

追蹤區域：以較高週期（需高於回測週期）的三根已收盤K線判斷FVG。向上FVG：前1根low > 前3根high，區域上緣=前1根low，下緣=前3根high，方向做多；向下FVG：前1根high < 前3根low，上緣=前3根low，下緣=前1根high，方向做空。新區域在確認後才啟用，最多同時追蹤10個，較舊的捨棄。區域失效：已收盤K線close收破區域——向下FVG的close > 上緣，向上FVG的close < 下緣，失效後不再使用。

觸碰判定（near-touch 緩衝 B = max(2檔×最小跳動, ATR(14)×3%)）：精確觸碰 = high ≥ 區域下緣 且 low ≤ 區域上緣；向上FVG近觸 = low > 上緣 且 low ≤ 上緣+B；向下FVG近觸 = high < 下緣 且 high ≥ 下緣−B。方向過濾（預設啟用）：向下FVG需 前一根close ≤ 下緣 且 當根open ≤ 下緣+B；向上FVG需 前一根close ≥ 上緣 且 當根open ≥ 上緣−B；不符則觸碰無效。

【即時觸碰進場（預設啟用，盤中即觸發）】對每個仍存在（未失效）的區域，當根為新的有效觸碰（上一根未處於有效觸碰狀態）時：向上FVG→做多；向下FVG→做空。進場價=觸碰當下價（以close計）。同一根多區域同時觸發時選區域中點距close最近者。

【回測進場（K線收盤確認）】區域未被使用、仍有效，且有效觸碰後在8根內（觸碰K線起算含當根）：向上FVG→做多，向下FVG→做空（預設 Wick tag 觸發，等同觸碰即可；觸碰需為有效觸碰，預設不要求先離開區域）。可選觸發：收盤回到區域外（做多 close > 上緣；做空 close < 下緣）；或當根出現同向K線缺口（缺口達最小高度）。若設定要求先離開區域：嚴格模式=做空需曾有close < 下緣、做多需曾有close > 上緣；寬鬆模式=做空需曾有low < 下緣、做多需曾有high > 上緣。直接模式=不需離開，觸碰當根且（若啟用）有同向K線缺口即進場。區域一旦產生交易即視為已用，不再進場（止損後若收盤仍未穿越區域——向上FVG close ≥ 下緣、向下FVG close ≤ 上緣——則重新啟用）。

【延續進場（K線收盤確認，回測優先）】區域未被使用且仍有效、同根無回測/觸碰進場時：做多 = 向上FVG且close > 區域上緣、當根出現做多K線缺口（達最小高度）、區域確認後16根內、close − 上緣 ≤ ATR(14)×3；做空 = 向下FVG且close < 區域下緣、當根出現做空K線缺口、16根內、下緣 − close ≤ ATR(14)×3。可選結構突破過濾（預設關）：做多需close > 前4根最高high；做空需close < 前4根最低low。

出場（持倉中逐根）：做多止損 = 區域下緣與觸碰期間最低點取低者再減2檔（延續單：該K線缺口下緣−2檔）；且止損距離至少20檔。做空對稱（區域上緣與觸碰期間最高點取高者加2檔；延續單：缺口上緣+2檔；至少20檔）。目標：優先取方向上最近的流動性價位（前日高/低、已凍結或進行中的各時段高低、較高週期擺動高低點，且距進場 ≥ 1×風險，並位於區域之外），否則固定 2.0R（延續單 3.0R），且目標須越過區域外緣。做多：low ≤ 止損 即止損出場；否則 high ≥ 目標 即停利；做空：high ≥ 止損 止損，否則 low ≤ 目標 停利；同根兩者皆觸及以止損優先。
