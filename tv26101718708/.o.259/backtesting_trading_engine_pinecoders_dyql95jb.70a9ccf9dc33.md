進場判斷（都只在目前沒有持倉時成立，做多/做空的過濾條件必須同時通過；預設的過濾是吊燈趨勢方向，預設的進場來源是隨機訊號，隨機沒有比較條件可重現，故不列）。

一、進場來源（擇一或兩種並用）：
1. 過濾轉態進場：做多過濾條件由不成立變成成立的那一根做多；做空過濾條件由不成立變成成立的那一根做空。
2. 過濾狀態進場：沒有持倉且做多過濾條件成立就做多；沒有持倉且做空過濾條件成立就做空。
3. RSI 穿越進場：RSI(收盤,14) 由下往上穿越30做多；由上往下穿越70做空。
4. 一目均衡（轉換線/基準線）交叉進場：轉換線 = 最近9根最高價最大值與最低價最小值的平均；基準線 = 最近26根的同樣平均。轉換線由下往上穿越基準線做多；由上往下穿越做空。

二、過濾條件（做多條件與做空條件，所有啟用的過濾須全部成立）：
- 吊燈趨勢方向（預設啟用）：L = 最近20根最高價最大值 - 3*ATR(20)；S = 最近20根最低價最小值 + 3*ATR(20)。多方停損線 LS：若前一根收盤 > 前一根 LS 則取 max(L, 前一根 LS)，否則取 L。空方停損線 SS：若前一根收盤 < 前一根 SS 則取 min(S, 前一根 SS)，否則取 S。方向初值為多；收盤 > 前一根 SS 則方向為多；否則收盤 < 前一根 LS 則方向為空；其餘沿用前一根方向。方向為多才允許做多，方向為空才允許做空。
- 單根方向：做多要求收盤 > 開盤；做空要求收盤 < 開盤。
- 成交量：成交量大於前一根成交量時，做多與做空才都允許。
- 均線斜率：SMA(收盤,50) 連續 1 根上升才允許做多；連續 1 根下降才允許做空。
- 停損幅度上限：做多要求 收盤 - min(開盤,收盤) + 1.5*ATR(14) 小於 收盤*6%；做空要求 max(開盤,收盤) + 1.5*ATR(14) - 收盤 小於 收盤*6%。
- 漲跌幅上限：做多要求收盤 < 前收*(1+6%)；做空要求收盤 > 前收*(1-6%)。
- RSI 超買超賣：RSI(收盤,20) 不大於75才允許做多；不小於25才允許做空。
- MA 擠壓：fast=EMA(收盤,5)，slow=EMA(收盤,21)，差=|fast-slow|；門檻 = 0.4*ATR(50)。差不小於門檻（非擠壓狀態）且 fast>slow 才允許做多；差不小於門檻且 fast<slow 才允許做空。
- 一目均衡雲帶：轉換線=20期高低中點，基準線=60期高低中點，雲A=(轉換線+基準線)/2，雲B=120期高低中點；以30根前的雲A、雲B取較大值為雲頂。多方：(雲A>雲B 且 30根前雲A>30根前雲B 且 收盤>雲頂) 或 (轉換線>基準線>雲頂 且 收盤>雲頂 且 基準線與轉換線皆上升)。空方為對稱：(雲A<雲B 且 30根前雲A<30根前雲B 且 收盤<雲頂) 或 (轉換線<基準線<雲頂 且 收盤<雲頂 且 基準線與轉換線皆下降)。

三、出場判斷（持多單或空單時）：
1. 停損出場（預設啟用，波動停損）：以20期ATR乘3為距離的波動停損。維護最高收盤/最低收盤（max/min 的延續值）；上升趨勢時停損 = 最高收盤 - 3*ATR(20)，下降趨勢時停損 = 最低收盤 + 3*ATR(20)；上升趨勢時停損只取較大值、下降趨勢時只取較小值；收盤 - 停損 >= 0 為上升趨勢，趨勢改變時最高/最低收盤重設為收盤。持多單時，收盤跌破前一根的停損線即出場；持空單時，收盤升破前一根的停損線即出場。進場時的初始停損為進場前一根的 min(開盤,收盤) - 1.5*ATR(14)（多）或 max(開盤,收盤) + 1.5*ATR(14)（空），之後停損只往有利方向移動，且新停損需比進場初始停損更接近價格才採用。
2. 過濾反向出場：持多單時，做空過濾條件由不成立變成成立即出場；持空單時，做多過濾條件由不成立變成成立即出場。
3. RSI 穿越出場：RSI(收盤,20) 由上往下穿越70，出多單；由下往上穿越30，出空單。
4. 轉換線/基準線交叉出場：轉換線(9)由上往下穿越基準線(26)出多單；由下往上穿越出空單。
5. 停利出場：進場價 +（進場價 - 初始停損）*2 為多單目標價（空單為對稱減），收盤高於目標價（空）則收盤低於目標價時出場。
