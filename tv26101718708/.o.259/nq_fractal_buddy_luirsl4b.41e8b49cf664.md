【判斷一：K 線 C2 掃價收回】以前一根為 C1、當根為 C2。外包 = 當根低<前低 且 當根高>前高。
做多：當根低<前低 且 收盤>前低 且 非外包。
做空：當根高>前高 且 收盤<前高 且 非外包。

【判斷二：C3 吞噬反轉】前前根為 B，前根為 P，當根為 C。上下沿 = P 的 max/min(開,收)。
做多：P 收<開；C 低>=P 低；C 開<=P 下沿；C 收>P 上沿；P 不是做多 C2（P 低<B 低 且 P 收>B 低）；C 不是做多 C2，也不是做空 C2。
做空：P 收>開；C 高<=P 高；C 開>=P 上沿；C 收<P 下沿；P 不是做空 C2（P 高>B 高 且 P 收<B 高）；C 不是做多 C2，也不是做空 C2。

【判斷三：已完成 C2 的方向，所有時間週期都適用】C1 = 往前第 2 根，C2 = 往前第 1 根，兩者都已收盤。
低掃 = C2 低<C1 低；高掃 = C2 高>C1 高。
做多：(低掃 且 C2 收>C1 高) 或 (低掃 且 非高掃 且 C2 收>C1 低 且 C2 收<=C1 高)。
做空：(高掃 且 C2 收<C1 低) 或 (高掃 且 非低掃 且 C2 收>=C1 低 且 C2 收<C1 高)。
過濾：C1 高≠C1 低；ATR20>0。ATR20 為真實波幅 TR 的 Wilder 平滑（RMA 20）。
做多與做空不可同時成立。新的有效 C2 會取代舊的。
出場／失效：做多時，之後任一根低<C2 低就失效；做空時，之後任一根高>C2 高就失效。C2 之後再過 2 根收盤也結束（C3、C4 走完）。

【判斷四：CISD 狀態轉換】K 線方向：收>開為 +1，收<開為 -1，收=開為 0。連續同向 K 線稱為一段 run，遇到 0 的 K 線略過，遇到反向 K 線就中斷。
初始：第一根方向非 0 的 K 線決定 bias。水平 level = 當前同向 run 中最低的開盤價（bias=+1）或最高的開盤價（bias=-1）。追蹤極值 = 該根高（bias=+1）或低（bias=-1）。
bias=+1 時，若當根高>追蹤極值：更新追蹤極值。若當根為陽線，level = 當前陽線 run 最低開盤；否則 level = 上一段陽線 run 最低開盤（當根之前最近一段）。
bias=-1 時，若當根低<追蹤極值：更新追蹤極值。若當根為陰線，level = 當前陰線 run 最高開盤；否則 level = 上一段陰線 run 最高開盤。
做多：bias=-1 且 收盤>level。做空：bias=+1 且 收盤<level。
事件發生後，bias 翻轉。新 bias=+1 時，level = 當前陽線 run 最低開盤，追蹤極值 = 當根高。新 bias=-1 時，level = 當前陰線 run 最高開盤，追蹤極值 = 當根低。
出場：持倉後出現反向的判斷一、二、三或四，或判斷三的失效條件成立，即出場或反手。
