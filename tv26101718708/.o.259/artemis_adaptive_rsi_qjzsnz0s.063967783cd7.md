【指標】
1. 兩極低通濾波 LP(x,p)：d=exp(-√2·π/p)；a=2·d·cos(√2·π/p)；b=-d²；c=1-a-b；y=c·(x+x[1])/2 + a·y[1] + b·y[2]（初值以 x 代入）。
2. 平滑 RSI(len,sm)：Δ=close-close[1]；up=LP(max(Δ,0),sm)；dn=LP(max(-Δ,0),sm)；RSI=100-100/(1+up/dn)，dn=0 時為 na。
3. 候選池共 60 組：len∈{7,10,14,21,28}、sm∈{6,10,16}、(OS,OB)∈{(15,85),(20,80),(25,75),(30,70)}。
4. 自適應選參（逐根更新）：
- 對每組候選，在偏移 b 的 bar 判斷事件。OS 進入：RSI[b+1]>=OS 且 RSI[b]<OS，報酬=close[b-5]/close[b]-1。OB 退出：RSI[b+1]>OB 且 RSI[b]<OB，報酬=-(close[b-5]/close[b]-1)。
- 每組累計最近 300 根內已滿 5 根前瞻的事件報酬總和與次數。每根新增 b=5 的事件、扣除 b=300 的事件。
- 初始採用 len=14、sm=10、(25,75)，分數為空。從第 306 根起，在事件數>=5 的組合中取平均報酬最高者 top。
- 若尚無現任分數，直接採用 top。否則先以現任（事件數>=5 時）重算平均分數，再僅在 top 分數 > 現任分數+|現任分數|×10% 時換成 top。
- 之後 liveRSI、OS、OB 皆取現任組合。

【做多】
- OS 進入：liveRSI[1]>=OS 且 liveRSI<OS（RSI 向下跌破自適應 OS）→ 做多。
- 狀態標示：liveRSI<OS 視為做多區（bar 色用多方色）。
- 常規看漲背離 → 做多：以 high/low 左右各 5 根確認 pivot，pivot 低點在確認後 5 根才成立。新 pivot 低點價 < 前一 pivot 低點價，且 liveRSI（取兩個 pivot bar 上的目前 liveRSI 值）新值 > 前值。
- 隱藏看漲背離 → 做多：新 pivot 低點價 > 前一 pivot 低點價，且 RSI 新值 < 前值。
- 中線上穿：RSI 上穿 50 → 偏多（預設關閉的多方提示）。
- RSI>=60 為多方色（偏多）。

【做空】
- OB 退出：liveRSI[1]>OB 且 liveRSI<OB（RSI 從上方向下跌破自適應 OB）→ 做空。
- 狀態標示：liveRSI>OB 視為做空區（bar 色用空方色）。
- 常規看跌背離 → 做空：新 pivot 高點價 > 前一 pivot 高點價，且 RSI 新值 < 前值。
- 隱藏看跌背離 → 做空：新 pivot 高點價 < 前一 pivot 高點價，且 RSI 新值 > 前值。
- 中線下穿：RSI 下穿 50 → 偏空（預設關閉的空方提示）。
- RSI<40 為空方色（偏空）。

【背離過濾（預設關閉，開啟時須同時通過才有效）】
- 兩 pivot 的 RSI 差絕對值>=5。
- 兩 pivot 的價差絕對值>=(最近 80 根最高 high - 最低 low)×0.3%。
- 看漲背離的新 pivot RSI <= (OS+50)/2；看跌背離的新 pivot RSI >= (50+OB)/2。

【出場】
- 沒有獨立的出場判斷；反向訊號即為反向方向。
