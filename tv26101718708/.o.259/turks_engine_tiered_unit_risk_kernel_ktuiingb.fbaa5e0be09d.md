只做多，不做空。持倉比例分四檔 0、1/3、2/3、1，只看收盤價，每根收盤 K 判斷一次。

【多方比例（目標權重）】
1. 算 ATR14（TR 的 RMA）。
2. 對 n=20、50、100、200 各算 SMA(close,n)，並定 d20=2*sqrt(20/200)≈0.632、d50=1.0、d100≈1.414、d200=2.0。
3. 每條均線算 ramp_n = clamp((close - SMA_n)/(d_n*ATR14), 0, 1)。四個 ramp 取平均得 raw，範圍 0 到 1。SMA200 還沒有值時不持倉。
4. 把 raw 量化成三等分並加遲滯。保留一個 held 值。只有 |raw - held| >= 0.25 時，才更新 held = round(raw*3)/3，否則 held 不變。unit = held。

【高斯平滑過濾（限制減碼）】
1. 平滑線 S = 對 i=0..30 的 close[i]*exp(-i^2/50) 加權和，除以同樣權重的總和（高斯核，h=5）。
2. 若 close >= S，gated = unit。
3. 若 close < S，gated = max(上一根的 gated, unit)。也就是收盤在平滑線下方時只准加碼、不准減碼。

【判斷】
- 做多：gated > 0。持倉比例等於 gated，起始本金的 gated 倍。
- 加碼（買進，做多）：gated 比上一根大。
- 減碼（賣出，部分出場）：gated 比上一根小。
- 出場（全部平倉）：gated 回到 0，也就是四個 ramp 平均後四捨五入為 0，且沒被平滑線過濾擋住。

【可選的替代模式，同一份程式裡有】
- 平滑線帶：MAE = SMA(|close - S|, 499)，上軌 = S + 3*MAE，下軌 = S - 2.5*MAE。已賣出檔數 sold 從 0 開始，上限 20。close 由下往上穿越上軌（前一根 close <= 前一根上軌）時，sold 加 1（賣一檔，減碼）。close 由上往下穿越下軌（前一根 close >= 前一根下軌）時，sold 減 1（買回一檔，加碼）。此時多方比例 = 1 - sold/20。
- 二元閘門：close > SMA200 連續 5 根開多，close < SMA200 連續 5 根平倉，且須 SMA200 > 20 根前的 SMA200 才算做多。
