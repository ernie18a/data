多空進場皆在每根K棒收盤確認後判斷，需先有5分鐘級別缺口作為背景。

【5分鐘缺口】把1分鐘K棒聚合成滾動5分鐘K棒（每遇新5分鐘邊界，把前一根完成的5分K棒移入歷史）。取最近三根完成的5分K棒（c0最新、c2最舊）：
- 多方缺口(BISI)：c0.low > c2.high 且 (c0.low − c2.high) >= 5分最小缺口(預設6點)；區間 bot=c2.high、top=c0.low。
- 空方缺口(SIBI)：c0.high < c2.low 且 (c2.low − c0.high) >= 最小缺口；區間 top=c2.low、bot=c0.high。
- 缺口需在允許交易時段內形成才記錄。

【缺口失效】每根1分K：多方缺口在收盤價 < 區間bot 時失效；空方缺口在收盤價 > 區間top 時失效。另可因缺口年齡超過上限（預設不限）、同方向有效缺口超過6個（保留最新、淘汰最舊）而失效。每個交易日（CME 17:00 CT換日）開始時清空所有缺口、冷卻與持倉記錄。

【反轉缺口(IFVG)模式】訊號來源可選 FVG（只用未被收盤穿越的原始缺口）、IFVG、Both。IFVG/Both模式下，缺口第一次被收盤穿越時不失效，而是方向反轉（原多方缺口變空方區、原空方缺口變多方區），標記為反轉缺口；反轉缺口存活超過240根後失效，被第二次收盤穿越則失效。IFVG只用反轉缺口，FVG只用未反轉缺口，Both兩者皆可。

【1分鐘巢狀訊號，做多】當前1分K收盤確認時：low > high[2] 且 (low − high[2]) >= 1分最小缺口(預設2點)；1分缺口 top1=low、bot1=high[2]。若存在一個有效、方向為多、來源符合訊號來源設定的5分缺口，滿足 bot1 >= 5分區bot − 容差 且 top1 <= 5分區top + 容差（容差預設3點），即為巢狀成立。
【做空】high < low[2] 且 (low[2] − high) >= 最小缺口；top1=low[2]、bot1=high。若存在有效、方向為空的5分缺口且 bot1 >= 區bot − 容差 且 top1 <= 區top + 容差，則成立。

【訊號過濾】全部須同時滿足才進場：
- 在設定交易時段內；
- 啟用交易視窗時，當前時間落在任一已啟用的視窗內；
- 當日累計虧損(點數×每點金額)未達日虧損上限（預設$400）；
- 距上次任一方向訊號 >= 30根，且距同方向上次訊號 >= 30根；
- 沒有未平倉或待成交的部位（一次只一單）。

【進場價】預設「Immediate」：以訊號K棒收盤價進場，方向依訊號（多單/空單）。

【出場】以進場價 E 為基準（預設以進場成交價為錨），多單（空單反向）：
- 停損：E − 20點（空單 E + 20）。
- 部分出場(Partial)：E + 20點；尚未觸及部分出場前，K棒 low <= 停損 即全數停損出場；同一根若 high >= 部分出場價則先判部分出場（停損優先於部分出場，部分出場優先於目標）。觸及後平1口，並把停損移到持倉平均成交價（保本）；保本停損自觸發K棒的下一根起生效。
- 目標T1：E + 45點，平1口；部分出場後 high >= T1 觸發。
- 延伸目標T2：E + 60點，平1口。
- 若啟用4口跑者模式：剩餘1口續持，到 E + 100點(T3)出場；T1/T2/T3 之後，若K棒 low <= 保本停損（下一根起）則剩餘部位於保本價出場。未啟用跑者時，T2觸及後全數平倉。
- 部分出場後、T1之前，若 low <= 保本停損（需在觸發保本K棒之後）則剩餘部位於保本價出場。
- 單筆最大虧損：每根確認K棒，若持倉未實現虧損（(收盤−成交均價)×剩餘口數×每點金額，空單反向）超過$120，則全數於收盤出場。

【空單出場】把以上價位方向全部取反：停損用 high >= 停損、目標用 low <= 目標價、保本停損用 high >= 停損。
