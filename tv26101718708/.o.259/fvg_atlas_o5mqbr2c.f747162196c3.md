只重現「FVG 首次回測拒絕」的多空判斷，出場判斷無。

以圖表週期逐根計算（高週期層用同一方法對聚合K線計算；預設為圖表週期加上聚合週期，邏輯相同）。

1. 缺口定義（三根K線 c1、c2、c3，c3 為最新一根）
- 多方缺口：c3.low > c1.high，區間 bot0 = c1.high、top0 = c3.low。
- 空方缺口：c3.high < c1.low，區間 top0 = c1.low、bot0 = c3.high。
- 缺口大小不得小於最小缺口值，預設為 0。
- 缺口在 c3 收完後的下一根K線開始生效，該根K線即可作首次觸及判斷。

2. 首次觸及（每個缺口只算第一次）
- 多方缺口：該根 low <= top0，且 high >= bot0。
- 空方缺口：該根 high >= bot0，且 low <= top0。
- 觸及K線收盤確認後，開始觀察，觀察窗口共 3 根K線（含觸及那根）。

3. 做多判斷（多方缺口的拒絕）
- 在窗口內逐根以收盤價判斷。
- 若 close <= bot0，視為失敗，該缺口不再觀察。
- 否則若 close > top0，判定為做多。
- 窗口內都沒有出現 close > top0，則作廢。
- 觸及K線本身也可以直接成立。

4. 做空判斷（空方缺口的拒絕）
- 與做多判斷鏡像。
- 若 close >= top0，視為失敗。
- 否則若 close < bot0，判定為做空。
- 窗口內沒成立則作廢。

5. 缺口失效與保留
- 缺口失效不影響已進入觀察的拒絕判斷。
- 預設失效條件為 Wick Sweep：多方 low <= bot0，空方 high >= top0。
- 另可選 Any Touch、Midpoint Reached 或 Body Beyond，均不影響判斷。
