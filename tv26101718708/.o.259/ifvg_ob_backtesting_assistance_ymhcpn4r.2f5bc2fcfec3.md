【通則】判斷以已收盤K線逐根計算。多空各自獨立，同一區域只觸發一次。進場價為下列水平價，出場見最後一節。

【IFVG 做多／做空】
1. 來源缺口：多方缺口為 low > high[2]，區間 [high[2], low]，缺口大小 low-high[2] >= 0.75。空方缺口為 high < low[2]，區間 [high, low[2]]，大小 low[2]-high >= 0.75。連續K線都出現同向缺口算同一串，串長為缺口數。
2. 反轉：空方缺口被 close > 區間上緣收破，即轉為多方 IFVG。多方缺口被 close < 區間下緣收破，即轉為空方 IFVG。
3. 成立：同一串缺口串長只有 1 或 2，且全部已被收破，才成立。串長 >= 3 不採用。成立區間取最後被收破的那個缺口，同根收破時取較早形成的缺口。新的 IFVG 成立時，取代同方向舊的。
4. 失效：多方 IFVG 在 close < 區間下緣時失效。空方 IFVG 在 close > 區間上緣時失效。
5. 做多：多方 IFVG 成立後的下一根起，第一次出現 low <= 上緣 且 high >= 上緣，則在上緣價做多。
6. 做空：空方 IFVG 成立後的下一根起，第一次出現 high >= 下緣 且 low <= 下緣，則在下緣價做空。
（可改用區間中點 (上緣+下緣)/2 作為觸及價，預設用邊緣。）

【OB 做空】
1. 找出連續 2~4 根陽線（close>open），且每根 close > 前一根 close。串中第一根實體 |close-open| >= 1.0。串長超過 4 則放棄。
2. 串長達 2 根時建立候選。串延長到 3 或 4 根時更新，之後的觀察從串的最後一根重新起算：以串末根 close 為錨點，並清零計數。
3. 其後每根累計：路徑和 += |close-close[1]|，觀察根數 += 1，若 close < close[1] 則下跌步數 += 1。
4. 確認：close < 串中第一根陽線的 low，且同時滿足 下跌步數 >= 2、下跌步數/觀察根數 >= 0.6、(錨點-close)/路徑和 >= 0.55，則該陽線串成為空方 OB。
5. 做空價為串中第一根陽線的實體下緣 min(open, close)。確認後的下一根起，第一次出現 low <= 該價 且 high >= 該價，且距確認不超過 30 根，則在該價做空。
6. 失效：high >= 做空價+20 時失效。

【OB 做多】
1. 找出連續 2~4 根陰線（close<open），且每根 close < 前一根 close。串中第一根實體 >= 1.0。
2. 其後每根累計：路徑和、觀察根數、上漲步數（close > close[1]）。
3. 確認：close > 串中第一根陰線的 high，且同時滿足 上漲步數 >= 2、上漲步數/觀察根數 >= 0.6、(close-錨點)/路徑和 >= 0.55，其中錨點為串末根 close。
4. 做多價為串中第一根陰線的實體上緣 max(open, close)。確認後的下一根起，第一次出現 low <= 該價 且 high >= 該價，且距確認不超過 30 根，則在該價做多。
5. 失效：low <= 做多價-20 時失效。

【出場】
進場的下一根起逐根判斷。
- 多單：high >= 進場價+55 為停利。low <= 進場價-20 為停損。
- 空單：low <= 進場價-55 為停利。high >= 進場價+20 為停損。
- 同一根同時觸及停利與停損時，視為無法判定而排除。
- 進場後超過 1440 根仍未觸及者放棄。
