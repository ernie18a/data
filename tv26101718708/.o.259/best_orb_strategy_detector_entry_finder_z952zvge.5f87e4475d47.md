【區間】每個交易日／交易時段的第一根K棒開始計時，取開盤後前N分鐘（預設5，可選15/30/60）所有K棒的最高價為區間高、最低價為區間低，區間寬度＝高－低。N分鐘結束後區間才算完成，之後的K棒才判斷。區間完成後，區間內的K棒不判斷。

【做多】區間完成後，若收盤價 > 區間高×1.002（突破緩衝0.2%），且前一根收盤價 <= 區間高×1.002（剛穿越），且該方向目前沒有進行中的突破旗標，則在這根K棒收盤標示向上突破（做多）。成立後把「向上突破進行中」旗標設為真，並記下這根K棒的序號。

【做空】區間完成後，若收盤價 < 區間低×0.998，且前一根收盤價 >= 區間低×0.998，且該方向目前沒有進行中的突破旗標，則在這根K棒收盤標示向下突破（做空）。成立後把「向下突破進行中」旗標設為真，並記下這根K棒的序號。

【進場】突破K棒的下一根K棒開盤價為進場價，方向同突破方向。若同時有多空待進場，以做空為準。

【假突破取消】突破後逐根統計「連續收在區間外的K棒數」：做多看收盤價 > 區間高，做空看收盤價 < 區間低；不符合就歸零。做多另外記錄收盤價 > 區間高×1.005是否發生過，做空另外記錄收盤價 < 區間低×0.995是否發生過。突破後1～5根內，若收盤價回到區間內（低 < 收盤價 < 高），且連續收在區間外的K棒數 < 2，視為假突破，把該方向的突破旗標清除，允許之後重新突破。

【出場】以進場價與方向計算。
1. 停損：做多停損價＝區間低－區間寬度×20%，做空停損價＝區間高＋區間寬度×20%。做多當K棒最低價 <= 停損價就出場，做空當K棒最高價 >= 停損價就出場。停損觸發後清除該方向的突破旗標，允許再次突破。
2. 停利：風險＝|進場價－停損價|。倍數調整係數：進場價<1000為1.0，<5000為0.8，其餘為0.6。第k個停利價（k＝1、2，預設啟用TP1與TP2）：做多＝min(進場價＋區間寬度×k, 進場價＋風險×k×調整係數)，做空＝max(進場價－區間寬度×k, 進場價－風險×k×調整係數)。做多當K棒最高價 >= 停利價，做空當K棒最低價 <= 停利價，視為該級停利達成。最高一級已啟用的停利（預設TP2）達成就全部出場，TP1只標示達成。

【過濾，預設關閉，開啟後才限制突破】
- 成交量過濾：Increasing＝突破K棒成交量 > 前一根成交量；Above Average＝成交量 >= 20根成交量簡單均線×1.2；Both＝兩者皆需成立。
- FVG過濾：向上突破需存在看漲缺口（兩根前最高價 < 當根最低價，缺口為[兩根前最高價, 當根最低價]），且區間高落在「缺口下緣－缺口大小×2」到「缺口上緣＋缺口大小×2」之內；向下突破需存在看跌缺口（兩根前最低價 > 當根最高價，缺口為[當根最高價, 兩根前最低價]），且區間低落在同樣的擴張範圍內。
