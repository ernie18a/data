## Description

Volume + MA — Понятный объём для новичков
Индикатор показывает объём торгов с цветовой индикацией и линией среднего значения. Главная задача — помочь понять, стоит ли доверять движению цены.

Цвета столбиков
Голубой яркий — объём выше среднего, свеча бычья. Покупатели активны, движению вверх можно доверять.
Красный яркий — объём выше среднего, свеча медвежья. Продавцы активны, движению вниз можно доверять.
Оранжевый — аномальный объём, превышает среднее в 2.5 раза и более. Самый важный сигнал. Появляется редко но всегда означает важное событие на рынке.
Тусклый зелёный или красный — обычный объём ниже среднего. Движению доверять не стоит, вероятен разворот или ложный пробой.

Белая линия
Это скользящая средняя объёма за 20 баров. Служит ориентиром: всё что выше — повышенная активность, всё что ниже — рынок вялый.

Как использовать
При пробое уровня смотри на цвет столбика. Если голубой и выше белой линии — пробой настоящий, можно входить в сторону пробоя. Если тусклый и ниже белой линии — это ловушка, цена вернётся обратно.
При сильном падении с оранжевым столбиком — возможная кульминация продаж. Все кто хотел продать уже продали. Часто после такого бара следует разворот вверх.
Если цена растёт несколько баров подряд, но столбики становятся всё тусклее и опускаются ниже белой линии — тренд слабеет и скоро будет коррекция.

Настройки
Период MA — по умолчанию 20. Уменьши до 10 для скальпинга на малых таймфреймах, увеличь до 50 для торговли на дневном графике.
Множитель аномалии — по умолчанию 2.5. Если оранжевых столбиков слишком много, увеличь до 3 или 4.

Совет
Используй этот индикатор вместе с уровнями поддержки и сопротивления. Объём подтверждает уровень — уровень даёт точку входа. Вместе они работают значительно лучше чем по отдельности.

## Source Code

````pine
//@version=6
indicator("Volume + MA — Понятный объём", overlay = false)

// ── Настройки ──────────────────────────────────────────────
ma_length     = input.int   (20,    "Период MA объёма",          minval = 1)
anom_mult     = input.float (2.5,   "Множитель аномалии (xMA)",  minval = 1.0, step = 0.1)
col_bull_norm = input.color (color.new(#26a69a, 20), "Обычная бычья свеча")
col_bear_norm = input.color (color.new(#ef5350, 20), "Обычная медвежья свеча")
col_bull_high = input.color (color.new(#00bcd4,  0), "Высокий объём — бычья")
col_bear_high = input.color (color.new(#ff1744,  0), "Высокий объём — медвежья")
col_anom      = input.color (color.new(#ff9800,  0), "Аномальный объём (!)")
show_labels   = input.bool  (true,  "Показывать подсказки")

// ── Расчёт ─────────────────────────────────────────────────
vol_ma  = ta.sma(volume, ma_length)
is_bull = close >= open
is_high = volume > vol_ma
is_anom = volume >= vol_ma * anom_mult

// ── Цвет каждого столбика ──────────────────────────────────
var color bar_color = na
if is_anom
    bar_color := col_anom
else if is_high and is_bull
    bar_color := col_bull_high
else if is_high and not is_bull
    bar_color := col_bear_high
else if is_bull
    bar_color := col_bull_norm
else
    bar_color := col_bear_norm

// ── Столбики объёма ────────────────────────────────────────
plot(volume, "Объём", style = plot.style_columns, color = bar_color)

// ── Линия средней MA ───────────────────────────────────────
plot(vol_ma, "Средний объём (MA)", color = color.new(color.white, 30),
     linewidth = 2, style = plot.style_line)

// ── Подсказки на аномальных барах ─────────────────────────
if is_anom and show_labels
    mult_str = str.tostring(math.round(volume / vol_ma, 1))
    txt      = is_bull ? "ПОКУПКА x" + mult_str : "ПРОДАЖА x" + mult_str
    lbl_col  = is_bull ? color.new(#00bcd4, 20) : color.new(#ff1744, 20)
    label.new(bar_index, volume,
              text      = txt,
              style     = label.style_label_down,
              color     = lbl_col,
              textcolor = color.white,
              size      = size.small)

// ── Алерты ────────────────────────────────────────────────
alertcondition(is_anom and is_bull,      "Аномальный объём — покупка",  "Аномальный объём на бычьей свече!")
alertcondition(is_anom and not is_bull,  "Аномальный объём — продажа",  "Аномальный объём на медвежьей свече!")
````
