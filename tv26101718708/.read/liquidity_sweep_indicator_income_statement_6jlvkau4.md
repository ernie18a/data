## Description

[b]Liquidity Sweep & Reversal Detector[/b]
This indicator is built around a specific market structure concept: liquidity sweeps (also called stop-hunts), where price temporarily violates a known swing level to trigger resting orders, then immediately reverses back inside range. That failed breakout is the signal, not the breakout itself.

The three filters are not independent features — they are a deliberate confirmation stack designed to answer one question: is this reversal likely to be institutional, or is it retail noise?

[b]HOW THE LOGIC WORKS[/b]
[b]1. Swing Structure (Pivot Detection)[/b]
The script continuously tracks the most recent confirmed pivot highs and lows using a user-defined lookback period. These pivots represent visible liquidity pools — price levels where stop-loss orders from trapped traders are clustered.

[b]2. The Sweep Condition[/b]
A bullish sweep is confirmed when: (a) the current bar's low dips below the most recent pivot low, and (b) the bar closes back above that level. This closing behaviour is critical — it distinguishes a genuine stop-hunt from a continuation breakdown. The reverse applies for bearish sweeps. A minimum sweep depth (%) filter prevents the script from triggering on negligible edge-grazes.

[b]3. Volume Confirmation (Smart Money Filter)[/b]
Institutional absorption of liquidity typically produces above-average volume. The script compares the sweep bar's volume against a 20-bar simple moving average and requires it to exceed a configurable multiplier (default 1.7×). This single filter eliminates the majority of false positives generated by low-liquidity sweeps in off-hours or thin markets.

[b]4. EMA Trend Alignment[/b]
To avoid taking counter-trend reversals in strong momentum environments, an optional EMA filter restricts bullish sweep signals to bars closing above the EMA, and bearish sweep signals to bars closing below it. This transforms the detector from a range-bound tool into one that works across trending and ranging conditions.

[b]5. ATR-Based Targets[/b]
Take Profit levels are calculated as a multiple of the 14-period ATR from the close of the sweep bar. Because ATR is normalised to the instrument's volatility, the same multiplier setting produces sensible targets across assets with very different price scales — stocks, crypto, forex, and commodities. Targets are displayed in the asset's native tick precision using syminfo.mintick.

[b]SETTINGS GUIDE[/b]
[b]Swing Length (2–20):[/b][i][/i] Controls the pivot lookback. Lower values (2–5) detect intraday liquidity pools; higher values (10–20) track significant swing highs/lows on higher timeframes.

[b]Minimum Sweep % [/b][i][/i]: Sets the minimum wick penetration beyond the pivot before a sweep is considered valid. Prevents false signals from minor wicks that barely exceed the level.

[b]Volume Multiplier[/b][i][/i]: Sweep bar volume must exceed this multiple of the 20-bar average. Increase for stricter institutional confirmation; decrease in lower-volume instruments.

[b]EMA Length & Trend Filter Toggle[/b][i][/i]: The EMA acts as a macro regime filter. When enabled, it restricts signals to the trend direction. Disable it in ranging/mean-reverting markets.

[b]ATR Target Multiplier[/b][i][/i]: Scales the Take Profit distance relative to recent volatility. 1.5 is a balanced default; tighten for scalping, widen for swing trades.

[b]USAGE NOTES[/b]
This indicator works best when sweep signals align with additional confluence — for example, a bullish sweep occurring at a higher-timeframe support zone, a Fair Value Gap, or a daily demand area. The script does not predict reversals; it identifies the structural conditions under which reversals statistically have higher probability. 
[b]Always use proper risk management and do not rely on any single indicator in isolation[/b][i][/i].

## Source Code

````pine
// This Pine Script® code is subject to the terms of the Mozilla Public License 2.0 at https://mozilla.org/MPL/2.0/
// © Income_Statement

//@version=6
indicator("Liquidity Sweep Indicator [Income Statement]", overlay = true, max_labels_count = 500, max_lines_count = 200)

// INPUTS
pivotLen       = input.int(4, "Swing Length", minval = 2, maxval = 20)

useTrendFilter = input.bool(true, "Use EMA Trend Filter")
emaLen         = input.int(150, "EMA Length")

useVolume      = input.bool(true, "Use Volume Confirmation")
volMultiplier  = input.float(1.7, "Volume Multiplier", step = 0.1)

showSweepLines = input.bool(true, "Show Sweep Levels")
showTargets    = input.bool(true, "Show ATR Targets")

atrMult        = input.float(1.5, "ATR Target Multiplier", step = 0.1)
sweepStrength  = input.float(0.15, "Minimum Sweep %", step = 0.01) / 100

//COLORS
var color bullColor    = #00f3ff  
var color bearColor    = #ff0055  
var color electricGlow = #cdea4c  
var color textDark     = #ffffff  
var color colorBg      = #131722
var color colorBar     = #b2b5be

// CORE CALCULATIONS
ema200 = ta.ema(close, emaLen)
atr    = ta.atr(14)

plot(useTrendFilter ? ema200 : na, color = color.new(#ffaa00, 50), linewidth = 1, title="Trend Filter")

// PIVOTS
ph = ta.pivothigh(pivotLen, pivotLen)
pl = ta.pivotlow(pivotLen, pivotLen)

var float lastHigh = na
var float lastLow  = na
var int lastHighBar = na
var int lastLowBar  = na

if not na(ph)
    lastHigh := high[pivotLen]
    lastHighBar := bar_index[pivotLen]

if not na(pl)
    lastLow := low[pivotLen]
    lastLowBar := bar_index[pivotLen]

// VOLUME
avgVol = ta.sma(volume, 20)
volConfirmed = volume > avgVol * volMultiplier

// SWEEP CONDITIONS
bullSweep = not na(lastLow) and low < lastLow and close > lastLow
bearSweep = not na(lastHigh) and high > lastHigh and close < lastHigh

// SWEEP STRENGTH
bullStrength = not na(lastLow) ? math.abs((lastLow - low) / lastLow) * 100 : 0
bearStrength = not na(lastHigh) ? math.abs((high - lastHigh) / lastHigh) * 100 : 0

// FILTERS
bullTrendOK  = not useTrendFilter or close > ema200
bearTrendOK  = not useTrendFilter or close < ema200
volumeOK     = not useVolume or volConfirmed

bullSignal = bullSweep and bullTrendOK and volumeOK and (bullStrength > sweepStrength * 100)
bearSignal = bearSweep and bearTrendOK and volumeOK and (bearStrength > sweepStrength * 100)


if bullSignal and showSweepLines
    line.new(lastLowBar, lastLow, bar_index, lastLow, color = color.new(bullColor, 40), style = line.style_dotted, width = 3)

if bearSignal and showSweepLines
    line.new(lastHighBar, lastHigh, bar_index, lastHigh, color = color.new(bearColor, 40), style = line.style_dotted, width = 3)

if bullSignal
    bullTargetVal = close + atr * atrMult    
    labelText = "▲ SWEEP (" + str.tostring(math.round(bullStrength, 2)) + "%)"
    if showTargets
        labelText := labelText + "\n🎯 TP: " + str.tostring(bullTargetVal, str.tostring(syminfo.mintick))

    label.new(
         bar_index, 
         low - (atr * 0.4), 
         labelText, 
         style = label.style_label_up, 
         color = color.new(bullColor, 55), 
         textcolor = textDark, 
         size = 10
         )

if bearSignal
    bearTargetVal = close - atr * atrMult    
    labelText = "▼ SWEEP (" + str.tostring(math.round(bearStrength, 2)) + "%)"
    if showTargets
        labelText := labelText + "\n🎯 TP: " + str.tostring(bearTargetVal, str.tostring(syminfo.mintick))

    label.new(
         bar_index, 
         high + (atr * 0.4), 
         labelText, 
         style = label.style_label_down, 
         color = color.new(bearColor, 55), 
         textcolor = textDark, 
         size = 10
         )

//bgcolor(bullSignal ? color.new(bullColor, 96) : bearSignal ? color.new(bearColor, 96) : na)
barcolor(bullSignal ? bullColor : bearSignal ? bearColor : colorBar)

// Alerts
alertcondition(bullSignal, "Bull Sweep", "Bullish liquidity sweep detected")
alertcondition(bearSignal, "Bear Sweep", "Bearish liquidity sweep detected")
````
