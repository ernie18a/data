## Description

Ultimate Sideways Market Detector PRO

Advanced Sideways Market, Consolidation, Trend & Volatility Analysis System



OVERVIEW

Ultimate Sideways Market Detector PRO is a multi-factor market condition analysis indicator designed to identify whether the market is currently trending, consolidating, compressing, or preparing for a breakout.

Most traders struggle because they apply trend-following strategies in sideways markets or breakout strategies in trending markets. This indicator helps solve that problem by analyzing multiple market conditions simultaneously and classifying the current market environment.

Instead of relying on a single indicator, this script combines trend strength, volatility compression, range analysis, moving average behavior, and market structure filters into one easy-to-read system.

WHAT PROBLEM DOES THIS SOLVE?

One of the biggest reasons traders lose money is entering trades in the wrong market condition.

Examples:

• Trend-following strategy used inside a range
• Breakout strategy used during low volatility
• Scalping against strong trends
• Entering before consolidation is complete
• Trading fake breakouts without confirmation

This indicator helps traders understand the current market condition before taking a trade.

HOW THE INDICATOR WORKS

The script combines multiple independent filters.

1. ADX Trend Strength Filter

Measures trend strength.

Low ADX values usually indicate weak trends and higher probability of sideways movement.

Helps identify:
• Weak trends
• Sideways conditions
• Transition phases

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

2. Choppiness Index

Measures how directional or non-directional the market is.

Higher values indicate the market is moving sideways instead of trending.

Helps identify:
• Choppy markets
• Range-bound environments
• Consolidation phases

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

3. ATR Compression

Measures volatility contraction.

Low ATR values often occur before major market expansion.

Helps identify:
• Volatility compression
• Potential breakout preparation
• Quiet market conditions

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

4. Bollinger Band Width Compression

When Bollinger Bands contract, price is often entering a squeeze phase.

Helps identify:
• Squeeze setups
• Compression zones
• Breakout preparation

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

5. EMA Flatness Detection

Trending markets generally create angled moving averages.

Sideways markets often create flat moving averages.

Helps identify:
• Flat markets
• Range environments
• Trend exhaustion

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

6. Range Compression Analysis

The script measures recent price range width.

Small price ranges usually indicate consolidation.

Helps identify:
• Sideways zones
• Consolidation structures
• Support and resistance clusters

7. Optional Volume Compression

Volume often decreases before major expansion moves.

This filter can be enabled or disabled according to preference.

Helps identify:
• Reduced participation
• Compression environments
• Potential breakout setups

## Source Code

````pine
//@version=6
indicator("Ultimate Sideways Market Detector PRO", overlay=true, max_boxes_count=50)

//=========================
// INPUTS
//=========================

groupFilters = "Filters"

useADX      = input.bool(true, "Enable ADX Filter", group=groupFilters)
useCI       = input.bool(true, "Enable Choppiness Filter", group=groupFilters)
useATR      = input.bool(true, "Enable ATR Compression", group=groupFilters)
useBBW      = input.bool(true, "Enable BB Width Compression", group=groupFilters)
useEMA      = input.bool(true, "Enable EMA Flatness", group=groupFilters)
useRange    = input.bool(true, "Enable Range Compression", group=groupFilters)
useVolume   = input.bool(false, "Enable Volume Compression", group=groupFilters)

adxLen      = input.int(14, "ADX Length")
ciLen       = input.int(14, "CI Length")
atrLen      = input.int(14, "ATR Length")
emaLen      = input.int(50, "EMA Length")
rangeLen    = input.int(20, "Range Length")

sidewaysThreshold = input.int(70, "Sideways Score Threshold", minval=10, maxval=130)

//=========================
// MANUAL ADX
//=========================

upMove   = high - high[1]
downMove = low[1] - low

plusDM  = (upMove > downMove and upMove > 0) ? upMove : 0
minusDM = (downMove > upMove and downMove > 0) ? downMove : 0

trur = ta.rma(ta.tr(true), adxLen)

plusDI  = 100 * ta.rma(plusDM, adxLen) / trur
minusDI = 100 * ta.rma(minusDM, adxLen) / trur

dx = 100 * math.abs(plusDI - minusDI) / math.max(plusDI + minusDI, 1)

adx = ta.rma(dx, adxLen)

adxScore = useADX ? (adx < 20 ? 25 : 0) : 0

//=========================
// CHOPPINESS INDEX
//=========================

trSum = ta.sma(ta.tr(true), ciLen) * ciLen

hh = ta.highest(high, ciLen)
ll = ta.lowest(low, ciLen)

ci = 100 * math.log10(trSum / math.max(hh - ll, syminfo.mintick)) / math.log10(ciLen)

ciScore = useCI ? (ci > 61.8 ? 25 : 0) : 0

//=========================
// ATR COMPRESSION
//=========================

atr = ta.atr(atrLen)
atrMA = ta.sma(atr, 50)

atrScore = useATR ? (atr < atrMA * 0.8 ? 15 : 0) : 0

//=========================
// BB WIDTH
//=========================

basis = ta.sma(close, 20)
dev = ta.stdev(close, 20)

upper = basis + dev * 2
lower = basis - dev * 2

bbw = (upper - lower) / basis
bbwMA = ta.sma(bbw, 50)

bbwScore = useBBW ? (bbw < bbwMA * 0.8 ? 20 : 0) : 0

//=========================
// EMA FLATNESS
//=========================

ema50 = ta.ema(close, emaLen)

flatEMA = math.abs(ema50 - ema50[10]) < atr

emaScore = useEMA ? (flatEMA ? 15 : 0) : 0

//=========================
// RANGE COMPRESSION
//=========================

rangeHigh = ta.highest(high, rangeLen)
rangeLow  = ta.lowest(low, rangeLen)

rangeWidth = rangeHigh - rangeLow

rangeScore = useRange ? (rangeWidth < atr * 8 ? 20 : 0) : 0

//=========================
// VOLUME COMPRESSION
//=========================

volMA = ta.sma(volume, 20)

volScore = useVolume ? (volume < volMA ? 10 : 0) : 0

//=========================
// FINAL SCORE
//=========================

score =
     adxScore +
     ciScore +
     atrScore +
     bbwScore +
     emaScore +
     rangeScore +
     volScore

isSideways = score >= sidewaysThreshold

//=========================
// MARKET STATES
//=========================

trendUp =
     adx > 25 and
     close > ema50

trendDown =
     adx > 25 and
     close < ema50

volatile =
     atr > atrMA * 1.3 and
     adx > 20

marketState =
     isSideways ? "SIDEWAYS" :
     trendUp ? "UPTREND" :
     trendDown ? "DOWNTREND" :
     volatile ? "VOLATILE" :
     "TRANSITION"

//=========================
// SIDEWAYS BOX
//=========================

var box zone = na

newZone = isSideways and not isSideways[1]

if newZone
    zone := box.new(
         left=bar_index-rangeLen,
         top=rangeHigh,
         right=bar_index,
         bottom=rangeLow,
         bgcolor=color.new(color.yellow, 88),
         border_color=color.yellow)

if isSideways and not na(zone)
    box.set_right(zone, bar_index)
    box.set_top(zone, rangeHigh)
    box.set_bottom(zone, rangeLow)

//=========================
// BREAKOUT
//=========================

bullBreakout =
     not isSideways and
     isSideways[1] and
     close > rangeHigh[1]

bearBreakout =
     not isSideways and
     isSideways[1] and
     close < rangeLow[1]

plotshape(
 bullBreakout,
 title="Bull Breakout",
 style=shape.triangleup,
 location=location.belowbar,
 color=color.lime,
 size=size.large)

plotshape(
 bearBreakout,
 title="Bear Breakout",
 style=shape.triangledown,
 location=location.abovebar,
 color=color.red,
 size=size.large)

//=========================
// BACKGROUND
//=========================

bgcolor(
 isSideways ?
 color.new(color.yellow,92) :
 na)

//=========================
// ALERTS
//=========================

alertcondition(
 isSideways,
 "Sideways Detected",
 "Sideways Market Detected")

alertcondition(
 bullBreakout,
 "Bullish Breakout",
 "Bullish Breakout From Sideways Zone")

alertcondition(
 bearBreakout,
 "Bearish Breakout",
 "Bearish Breakout From Sideways Zone")

//=========================
// DASHBOARD
//=========================

var table dash = table.new(position.top_right, 2, 3)

if barstate.islast

    stateColor =
         marketState == "UPTREND" ? color.lime :
         marketState == "DOWNTREND" ? color.red :
         marketState == "SIDEWAYS" ? color.yellow :
         color.orange

    table.cell(dash, 0, 0, "STATE")
    table.cell(dash, 1, 0, marketState, text_color=stateColor)

    table.cell(dash, 0, 1, "SCORE")
    table.cell(dash, 1, 1, str.tostring(score))

    table.cell(dash, 0, 2, "ADX")
    table.cell(dash, 1, 2, str.tostring(math.round(adx)))

//=========================

plot(ema50, color=color.aqua, linewidth=2)
````
