# SMA 50 / 100 / 200

## Description

Simple SMA 50/100/200 - all three most important SMAs in one indicator

## Source Code

````pine
// @version=6
// Simple SMA indicator
indicator("SMA 50 / 100 / 200", overlay=true)
// TAGS: SMA, Simple Moving Average, Moving Average, Trend Indicator, Technical Analysis, MA50, MA100, MA200, Crypto, Stocks, Forex, Market Trend, Long Term Trend, Short Term Trend, Medium Term Trend, Trading Indicator, Price Action, Trend Following

// SMA calculations
sma50 = ta.sma(close, 50)
sma100 = ta.sma(close, 100)
sma200 = ta.sma(close, 200)

// Plotting
plot(sma50, title="SMA 50", color=color.blue, linewidth=1)
plot(sma100, title="SMA 100", color=color.orange, linewidth=2)
plot(sma200, title="SMA 200", color=color.red, linewidth=3)
````
