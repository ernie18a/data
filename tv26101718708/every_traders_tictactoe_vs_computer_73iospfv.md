## Description

[b]Every Trader's Tic-Tac-Toe vs Computer[/b]

Sometimes watching the markets means waiting.

Waiting for a setup.
Waiting for confirmation.
Waiting for the next candle.

So why not have a little fun while you wait?

[b]Every Trader's Tic-Tac-Toe vs Computer[/b] brings the classic game of [i]Tic-Tac-Toe[/i] directly onto your TradingView chart, giving you a simple, interactive game to play without leaving your chart.

Built with the same attention to detail as the World Financial Freedom trading tools, this isn't just a basic Tic-Tac-Toe board. It was designed to feel like a [b]small, polished game that belongs on your trading screen.[/b]


 🎮 [b]PLAY AGAINST THE COMPUTER[/b]

Challenge the computer in a classic Tic-Tac-Toe game. You make your move, and the computer responds. The game keeps track of the board, recognizes [b]wins, losses, and draws,[/b] and clearly displays the current game status.

The computer isn't simply placing symbols randomly. It plays strategically, creating an actual opponent rather than just filling empty squares.

[b][i]Can you beat it?[/i][/b]


[b]
 SIMPLE MOVE SYSTEM[/b]

Your moves are entered through the [b]TradingView indicator settings[/b] using a familiar coordinate system:
[b]A1 · B1 · C1
A2 · B2 · C2
A3 · B3 · C3[/b]

Simply enter your moves in order:

[b]Move 1 → Move 2 → Move 3 → ...[/b]

The board automatically reconstructs the game from your selected moves and displays the resulting position directly on the chart.

This keeps the game simple to understand while still giving you [i]complete control over every move you make.
[/i]

The game clearly tells you what's happening at every stage. You'll see messages such as: [b]YOUR TURN / YOU WIN! / COMPUTER WINS! / DRAW!
[/b]

getComputerMove(int[] b) =>
    int chosen = -1

    // Win if possible.
    chosen := findWinningMove(b, 2)

    // Block player if necessary.
    if chosen == -1
        chosen := findWinningMove(b, 1)

    // Center.
    if chosen == -1 and array.get(b, 4) == 0
        chosen := 4

    // Corners.
    if chosen == -1
        if array.get(b, 0) == 0
            chosen := 0
        else if array.get(b, 2) == 0
            chosen := 2
        else if array.get(b, 6) == 0
            chosen := 6
        else if array.get(b, 8) == 0
            chosen := 8

    // Any remaining square.
    if chosen == -1
        for i = 0 to 8
            if chosen == -1 and array.get(b, i) == 0
                chosen := i

    chosen
