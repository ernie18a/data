## Description

🖊️ Overview
AetherEdge AI Dynamic Trendline Architect is a next-generation automatic trendline system powered by a four-layer AI architecture: pivot detection, KNN pattern memory, a neural quality network, and structural prior validation. Every candidate line is evaluated through machine learning, ensuring that only truly meaningful, high-quality lines are drawn and lifecycle-managed — delivering accuracy and practicality unreachable by conventional approaches.

🔶 Key Features

Pivot Engine: High-precision swing high/low detection with dynamic candidate pairing
5D Feature Extraction: Slope, duration, volatility ratio, RSI state, angle
KNN Pattern Memory: Stores up to 300 historical line patterns
Neural Quality Network: Online learning updates quality scores in real time
Structural Prior: Physical validation via touch counts and violations
Dynamic Hybrid Fusion: Mixes NN predictions with structural prior
Line Lifecycle Management: TTL, break detection, minimum score threshold
Break Detection: ATR-buffered to suppress false signals
Premium Visuals: Age fading, strength labels, support/resistance color coding

🧠 Technical Architecture

This indicator is a multi-layer decision system centered on AI-based line quality evaluation.

Pivot Engine: Detects swings via ta.pivothigh/low, maintaining up to 25 pivots per side. From each new pivot, candidate pairs are generated by scanning back scanBack pivots.
Feature Engineering: ①ATR-normalized slope, ②normalized duration, ③ATR-ratio volatility, ④RSI deviation, ⑤atan-based angle — all standardized to [-2, 2] or [-1, 1].
KNN Pattern Memory: Up to maxMemory historical patterns with outcome labels. Each candidate undergoes Euclidean distance comparison in the 5D feature space; Top-K neighbors are weighted by inverse distance to produce a consensus score.
Neural Quality Network: An online neural net learns to predict line quality, updated via real outcomes (breaks, bounces) over nnEpochs.
Structural Prior: Physically verifies the line by counting actual touches and violations along its projection, computing touchScore + durationQuality − violationPenalty.
Hybrid Score Fusion: priorMix dynamically blends NN prediction with structural prior — only lines with consensus from both layers reach top-tier scoring.
Line Lifecycle: Only lines above minScore are drawn; ttlBars triggers auto-expiry; breaks exceeding breakBuf × ATR change color and are recorded.

⚙️ Recommended Settings & Tuning Guide

Crypto Defaults:

BTC/ETH (4H–1D): pivLen=5, maxLines=6, ttlBars=80, minScore=0.55
SOL/XRP (1H): pivLen=4, maxLines=8, ttlBars=60, minScore=0.50
Scalping (5M–15M): pivLen=3, maxLines=4, ttlBars=40, knnK=3
Long Swing (1D): pivLen=8, maxLines=10, ttlBars=200, minScore=0.65
Parameter Tuning:

Too many lines: Raise minScore to 0.65–0.75 to display only premium lines
Too few lines: Increase scanBack to 6 and lower minScore to 0.45
Choppy markets: Raise breakBuf to 0.30 to avoid fake breaks
Quiet ranges: Set priorMix=0.6 for structure-favored detection
Trending markets: Set priorMix=0.3 to leverage NN learning

💡 How to Use in Practice

High-Score Line Reversal: Long at score ≥ 0.70 supports, short at resistances
Breakout Strategy: Color shifts (colBkU/colBkD) signal trend-following entries
S/R Flip: Capture the moment a broken resistance flips to support
Multi-Timeframe: Use 1D strong lines as zones for 1H precision entries
AetherEdge Combinations: Hybrid AI Bias bullish + high-score support bounce = elite long setup

⚠️ Important Notes

NN weights start from defaults; memory requires 50–100 events to mature
KNN memory and NN weights reset on indicator reload
Too-small pivLen creates noise; too-large delays detection
Excessive maxLines clutters the chart
Extreme gaps or flash crashes may trigger false break detection

## Source Code

````pine
//@version=5
indicator("AetherEdge AI Dynamic Trendline Architect", shorttitle="AE-DTA", overlay=true, max_lines_count=500, max_labels_count=200)

// ============================================================
// ▼ INPUTS
// ============================================================
grpPiv = "📍 Pivot Engine"
pivLen   = input.int(5,  "Pivot Length",          minval=2,  maxval=30, group=grpPiv)
maxLines = input.int(6,  "Max Active Trendlines", minval=2,  maxval=12, group=grpPiv)
scanBack = input.int(4,  "Scan-back Pivots",      minval=2,  maxval=8,  group=grpPiv, tooltip="新ピボットから何個前まで対と試すか")

grpKNN = "🔍 KNN Pattern Memory"
knnK      = input.int(5,   "K Neighbors",         minval=3,   maxval=15,  group=grpKNN)
maxMemory = input.int(100, "Pattern Memory Size", minval=30,  maxval=300, group=grpKNN)

grpNN = "🧠 Neural Quality Network"
nnRate   = input.float(0.04, "Learning Rate", minval=0.001, maxval=0.3, step=0.005, group=grpNN)
nnEpochs = input.int(2, "Epochs/event", minval=1, maxval=5, group=grpNN)

grpLine = "📏 Line Lifecycle"
ttlBars   = input.int(80,    "Line TTL (bars)",       minval=20,  maxval=500, group=grpLine)
minScore  = input.float(0.55, "Min Quality Score",    minval=0.30, maxval=0.95, step=0.01, group=grpLine)
breakBuf  = input.float(0.15, "Break Buffer (× ATR)", minval=0.0,  maxval=2.0, step=0.05, group=grpLine)
priorMix  = input.float(0.4,  "Structural Prior Mix", minval=0.0,  maxval=1.0, step=0.05, group=grpLine, tooltip="0=NNのみ, 1=構造的事前確率のみ")

grpVis = "🎨 Visuals"
colSup  = input.color(color.rgb(80,  200, 220), "Support Color",         group=grpVis)
colRes  = input.color(color.rgb(255, 150, 100), "Resistance Color",      group=grpVis)
colBkU  = input.color(color.rgb(80,  220, 180), "Bullish Break Color",   group=grpVis)
colBkD  = input.color(color.rgb(240, 90,  130), "Bearish Break Color",   group=grpVis)
showLbl = input.bool(true, "Show Strength Labels", group=grpVis)
fadeAge = input.bool(true, "Fade by Age",          group=grpVis)

// ============================================================
// ▼ CONTEXT
// ============================================================
atrV   = ta.atr(14)
atrV50 = ta.atr(50)
rsiV   = ta.rsi(close, 14)

// ============================================================
// ▼ TYPES
// ============================================================
type Pivot
    float price
    int   bar

type Pattern
    float f1
    float f2
    float f3
    float f4
    float f5
    float label

type TLine
    line  ln
    label lbl
    int   b1
    int   b2
    float p1
    float p2
    int   created
    int   expires
    float score
    bool  isSup
    bool  broken
    int   breakBar

// ============================================================
// ▼ STORAGE
// ============================================================
var array<Pivot>   highs       = array.new<Pivot>()
var array<Pivot>   lows        = array.new<Pivot>()
var array<Pattern> memory      = array.new<Pattern>()
var array<TLine>   activeLines = array.new<TLine>()

// Pivot detection
ph = ta.pivothigh(high, pivLen, pivLen)
pl = ta.pivotlow(low,  pivLen, pivLen)

if not na(ph)
    array.push(highs, Pivot.new(ph, bar_index - pivLen))
    if array.size(highs) > 25
        array.shift(highs)

if not na(pl)
    array.push(lows, Pivot.new(pl, bar_index - pivLen))
    if array.size(lows) > 25
        array.shift(lows)

// ============================================================
// ▼ FEATURE ENGINEERING
// ============================================================
extractFeatures(float p1, int b1, float p2, int b2) =>
    barDiff   = math.max(b2 - b1, 1)
    priceDiff = p2 - p1
    slopeNorm = priceDiff / math.max(atrV * barDiff, 1e-10)
    durationN = math.min(barDiff / 50.0, 2.0) - 1.0
    volRatio  = (atrV / math.max(atrV50, 1e-10)) - 1.0
    rsiNorm   = (rsiV - 50.0) / 50.0
    angleN    = math.atan(slopeNorm) / (math.pi / 2.0)
    [math.max(-2.0, math.min(2.0, slopeNorm)), durationN, volRatio, rsiNorm, angleN]

// ============================================================
// ▼ STRUCTURAL PRIOR
// ============================================================
structuralPrior(float p1, int b1, float p2, int b2, bool isSup) =>
    barDiff = math.max(b2 - b1, 1)
    slope   = (p2 - p1) / barDiff
    int touches    = 0
    int violations = 0
    maxLook = math.min(barDiff, 50)
    if maxLook >= 2
        for k = 1 to maxLook - 1
            offset = bar_index - (b1 + k)
            if offset >= 0 and offset < 500
                proj = p1 + slope * k
                hi = high[offset]
                lo = low[offset]
                if isSup
                    if math.abs(lo - proj) < atrV * 0.4
                        touches += 1
                    if lo < proj - atrV * 0.5
                        violations += 1
                else
                    if math.abs(hi - proj) < atrV * 0.4
                        touches += 1
                    if hi > proj + atrV * 0.5
                        violations += 1
    touchScore  = math.min(touches / 3.0, 1.0)
    violPenalty = math.min(violations * 0.25, 1.0)
    durQual     = math.min(barDiff / 30.0, 1.0)
    prior = math.max(0.0, math.min(1.0, 0.5 * touchScore + 0.3 * durQual - 0.6 * violPenalty + 0.2))
    [prior, violations]

// ============================================================
// ▼ KNN CONSENSUS
// ============================================================
knnQuery(float f1, float f2, float f3, float f4, float f5) =>
    memSize = array.size(memory)
    float result = 0.5
    if memSize >= knnK
        dists  = array.new<float>()
        labels = array.new<float>()
        for i = 0 to memSize - 1
            p = array.get(memory, i)
            d = math.sqrt(math.pow(p.f1 - f1, 2) + math.pow(p.f2 - f2, 2) + math.pow(p.f3 - f3, 2) + math.pow(p.f4 - f4, 2) + math.pow(p.f5 - f5, 2))
            array.push(dists, d)
            array.push(labels, p.label)
        sumL = 0.0
        sumW = 0.0
        for k = 0 to knnK - 1
            int   minIdx = 0
            float minD   = array.get(dists, 0)
            for j = 1 to array.size(dists) - 1
                if array.get(dists, j) < minD
                    minD   := array.get(dists, j)
                    minIdx := j
            w = 1.0 / (1.0 + minD)
            sumL += array.get(labels, minIdx) * w
            sumW += w
            array.set(dists, minIdx, 1e9)
        result := sumW > 0 ? sumL / sumW : 0.5
    result

// ============================================================
// ▼ NEURAL NET — weights stored in arrays so they can be
//   updated from inside functions (Pine v5 reference semantics)
//
//   Architecture: 6 inputs → 4 hidden (tanh) → 1 output (sigmoid)
//   W1 layout: row = input idx (0..5), col = hidden idx (0..3)
//              flat index = inputIdx * 4 + hiddenIdx  (size 24)
// ============================================================
var array<float> W1 = array.from( 0.18, -0.14,  0.22,  0.07,   // x1 → h1..h4
                                   0.12,  0.20, -0.10,  0.15,   // x2
                                  -0.08,  0.13,  0.18, -0.16,   // x3
                                   0.11,  0.06, -0.19,  0.14,   // x4
                                   0.21, -0.12,  0.16, -0.07,   // x5
                                   0.30,  0.25,  0.20,  0.35)   // x6 (KNN vote)
var array<float> bH    = array.from(0.0, 0.0, 0.0, 0.0)
var array<float> Vw    = array.from(0.32, -0.22, 0.28, 0.36)
var array<float> bOarr = array.from(0.0)

tanhF(float x) =>
    cx = math.max(-15.0, math.min(15.0, x))
    e1 = math.exp(cx)
    e2 = math.exp(-cx)
    (e1 - e2) / (e1 + e2)

sigF(float x) =>
    1.0 / (1.0 + math.exp(-math.max(-15.0, math.min(15.0, x))))

forwardNN(float x1, float x2, float x3, float x4, float x5, float x6) =>
    inputs = array.from(x1, x2, x3, x4, x5, x6)
    hidden = array.new<float>(4, 0.0)
    for j = 0 to 3
        float z = array.get(bH, j)
        for i = 0 to 5
            z += array.get(inputs, i) * array.get(W1, i * 4 + j)
        array.set(hidden, j, tanhF(z))
    float y = array.get(bOarr, 0)
    for j = 0 to 3
        y += array.get(hidden, j) * array.get(Vw, j)
    [sigF(y), array.get(hidden, 0), array.get(hidden, 1), array.get(hidden, 2), array.get(hidden, 3)]

trainNN(float x1, float x2, float x3, float x4, float x5, float x6, float yt) =>
    [p, h1, h2, h3, h4] = forwardNN(x1, x2, x3, x4, x5, x6)
    inputs = array.from(x1, x2, x3, x4, x5, x6)
    hidden = array.from(h1, h2, h3, h4)
    // Snapshot V before update so backprop uses the pre-update values
    Vold = array.from(array.get(Vw, 0), array.get(Vw, 1), array.get(Vw, 2), array.get(Vw, 3))
    dY = p - yt
    // Output-layer updates: V and bO
    for j = 0 to 3
        array.set(Vw, j, array.get(Vw, j) - nnRate * dY * array.get(hidden, j))
    array.set(bOarr, 0, array.get(bOarr, 0) - nnRate * dY)
    // Hidden-layer updates: W1 and bH
    for j = 0 to 3
        hj  = array.get(hidden, j)
        dHj = dY * array.get(Vold, j) * (1.0 - hj * hj)
        for i = 0 to 5
            xi  = array.get(inputs, i)
            idx = i * 4 + j
            array.set(W1, idx, array.get(W1, idx) - nnRate * dHj * xi)
        array.set(bH, j, array.get(bH, j) - nnRate * dHj)

// ============================================================
// ▼ DUPLICATE CHECK
// ============================================================
isDuplicate(int b1, float p1, int b2, float p2, bool isSup) =>
    bool dup = false
    n = array.size(activeLines)
    if n > 0
        for i = 0 to n - 1
            tl = array.get(activeLines, i)
            if tl.isSup == isSup
                if math.abs(tl.b2 - b2) < 4 and math.abs(tl.p2 - p2) < atrV * 0.5
                    dup := true
                    break
    dup

// ============================================================
// ▼ SCAN FOR NEW TRENDLINES
// ============================================================
scanForLines(bool sup) =>
    pivots = sup ? lows : highs
    n = array.size(pivots)
    if n >= 2
        latest   = array.get(pivots, n - 1)
        startIdx = math.max(0, n - 1 - scanBack)
        if startIdx <= n - 2
            for i = startIdx to n - 2
                prev = array.get(pivots, i)
                if not isDuplicate(prev.bar, prev.price, latest.bar, latest.price, sup)
                    [f1, f2, f3, f4, f5] = extractFeatures(prev.price, prev.bar, latest.price, latest.bar)
                    [prior, viol] = structuralPrior(prev.price, prev.bar, latest.price, latest.bar, sup)
                    if viol < 2 and prior > 0.3
                        knnVote = knnQuery(f1, f2, f3, f4, f5)
                        [nnScore, hh1, hh2, hh3, hh4] = forwardNN(f1, f2, f3, f4, f5, knnVote * 2.0 - 1.0)
                        finalScore = priorMix * prior + (1.0 - priorMix) * nnScore
                        if finalScore >= minScore and array.size(activeLines) < maxLines
                            baseCol    = sup ? colSup : colRes
                            startTrans = math.max(10, math.min(60, math.round((1.0 - finalScore) * 70)))
                            ln = line.new(prev.bar, prev.price, latest.bar, latest.price, color=color.new(baseCol, startTrans), width=2, extend=extend.right)
                            label lbl = na
                            if showLbl
                                lbl := label.new(latest.bar, latest.price, str.tostring(finalScore, "0.00"), color=color.new(baseCol, 75), textcolor=color.white, style=sup ? label.style_label_up : label.style_label_down, size=size.tiny)
                            tl = TLine.new(ln, lbl, prev.bar, latest.bar, prev.price, latest.price, bar_index, bar_index + ttlBars, finalScore, sup, false, 0)
                            array.push(activeLines, tl)

if not na(ph)
    scanForLines(false)
if not na(pl)
    scanForLines(true)

// ============================================================
// ▼ UPDATE ACTIVE LINES
// ============================================================
var bool brokeUpThisBar = false
var bool brokeDnThisBar = false
brokeUpThisBar := false
brokeDnThisBar := false

if array.size(activeLines) > 0
    i = array.size(activeLines) - 1
    while i >= 0
        tl = array.get(activeLines, i)
        slope     = (tl.p2 - tl.p1) / math.max(tl.b2 - tl.b1, 1)
        projPrice = tl.p2 + slope * (bar_index - tl.b2)

        // Break detection
        if not tl.broken
            broken = tl.isSup ? close < projPrice - atrV * breakBuf : close > projPrice + atrV * breakBuf
            if broken
                tl.broken   := true
                tl.breakBar := bar_index
                breakColor = tl.isSup ? colBkD : colBkU
                line.set_color(tl.ln, color.new(breakColor, 0))
                line.set_width(tl.ln, 3)
                line.set_extend(tl.ln, extend.none)
                line.set_x2(tl.ln, bar_index)
                line.set_y2(tl.ln, projPrice)
                if tl.isSup
                    brokeDnThisBar := true
                else
                    brokeUpThisBar := true
                // Train: line broken → label 0
                [f1, f2, f3, f4, f5] = extractFeatures(tl.p1, tl.b1, tl.p2, tl.b2)
                array.push(memory, Pattern.new(f1, f2, f3, f4, f5, 0.0))
                if array.size(memory) > maxMemory
                    array.shift(memory)
                kv = knnQuery(f1, f2, f3, f4, f5)
                for ep = 0 to nnEpochs - 1
                    trainNN(f1, f2, f3, f4, f5, kv * 2.0 - 1.0, 0.0)

        // Expiry → learn from outcome
        if bar_index >= tl.expires
            if not tl.broken
                [f1, f2, f3, f4, f5] = extractFeatures(tl.p1, tl.b1, tl.p2, tl.b2)
                array.push(memory, Pattern.new(f1, f2, f3, f4, f5, 1.0))
                if array.size(memory) > maxMemory
                    array.shift(memory)
                kv = knnQuery(f1, f2, f3, f4, f5)
                for ep = 0 to nnEpochs - 1
                    trainNN(f1, f2, f3, f4, f5, kv * 2.0 - 1.0, 1.0)
            line.delete(tl.ln)
            if not na(tl.lbl)
                label.delete(tl.lbl)
            array.remove(activeLines, i)
        else
            // Age-based fading for unbroken lines
            if fadeAge and not tl.broken
                age     = bar_index - tl.created
                ageR    = math.min(age / float(ttlBars), 1.0)
                qFactor = 1.0 - tl.score
                trans   = math.round(15 + ageR * 50 + qFactor * 25)
                baseCol = tl.isSup ? colSup : colRes
                line.set_color(tl.ln, color.new(baseCol, math.min(92, trans)))
        i := i - 1

// Cap to maxLines
while array.size(activeLines) > maxLines
    int   minIdx = 0
    float minS   = array.get(activeLines, 0).score
    for j = 1 to array.size(activeLines) - 1
        s = array.get(activeLines, j).score
        if s < minS
            minS   := s
            minIdx := j
    tlR = array.get(activeLines, minIdx)
    line.delete(tlR.ln)
    if not na(tlR.lbl)
        label.delete(tlR.lbl)
    array.remove(activeLines, minIdx)

// ============================================================
// ▼ ALERTS
// ============================================================
alertcondition(brokeUpThisBar, title="AE-DTA → Bullish Trendline Break", message="AE-DTA: Resistance trendline broken upward")
alertcondition(brokeDnThisBar, title="AE-DTA → Bearish Trendline Break", message="AE-DTA: Support trendline broken downward")

// Diagnostics
plot(array.size(activeLines), title="Active Lines",  display=display.data_window)
plot(array.size(memory),      title="Memory Size",   display=display.data_window)
````
