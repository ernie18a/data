## Description

Fibonacci-based EMA set for H4 support/resistance. The thicker lines (89 and 144) are your stronger, more respected levels — so they stand out visually on the chart.

When all four EMAs fan out and align in order, that signals a strong trend. When they cluster tightly together, the market is consolidating — often before a breakout.

## Source Code

````pine
//@version=6
indicator("EMA 21/55/89/144", overlay=true)

// Inputs — adjust lengths if needed
len1 = input.int(21,  "EMA 21",  minval=1)
len2 = input.int(55,  "EMA 55",  minval=1)
len3 = input.int(89,  "EMA 89",  minval=1)
len4 = input.int(144, "EMA 144", minval=1)

src = input.source(close, "Source")

// Calculate EMAs
ema1 = ta.ema(src, len1)
ema2 = ta.ema(src, len2)
ema3 = ta.ema(src, len3)
ema4 = ta.ema(src, len4)

// Plot
plot(ema1, "EMA 21",  color=color.aqua,    linewidth=1)
plot(ema2, "EMA 55",  color=color.yellow,  linewidth=1)
plot(ema3, "EMA 89",  color=color.orange,  linewidth=2)
plot(ema4, "EMA 144", color=color.red,     linewidth=2)
````
