## Description

SBP Sideways Range and Structure Navigator is a rule-based market analysis indicator designed to distinguish confirmed sideways consolidation from directional market phases while generating a single alternating sequence of BUY and SALE signals.

This script is an indicator, not a trading strategy. It does not place trades, calculate position size, manage risk, or predict future price movement. All signals should be evaluated together with market context, timeframe, liquidity, and the user's own trading plan.

Methodology

The indicator follows one integrated state-driven analytical workflow rather than combining unrelated indicators.

The sideways engine identifies genuine price compression using multiple market characteristics, including:

Range width relative to ATR
Net price displacement
Price-path choppiness
Regression slope
Directional balance
Candle overlap
Candle-body compression
ADX behaviour
EMA compression

When these conditions agree, a confirmed sideways range is displayed as a fixed yellow box that remains active until a confirmed breakout or breakdown occurs.

Sideways Bias

Each confirmed range is analysed to determine internal directional pressure using EMA alignment, EMA slope, directional movement, and price position within the range.

A bullish assessment generates Bull Bias, while a bearish assessment generates Bear Bias. Bias events must alternate, preventing repeated Bull or Bear Bias signals. Bull Bias is merged into the master BUY engine, while Bear Bias becomes part of the master SALE engine.

Trend Structure Engine

Outside confirmed sideways markets, the indicator evaluates:

Confirmed swing structure
EMA alignment and slope
ATR-normalised EMA separation
Directional movement
ADX strength
Controlled pullbacks
Pullback depth
Candle quality
Price resumption

The objective is to identify structured continuation rather than reacting to every short-term fluctuation.

Master Signal Engine

All qualified signal sources are combined into one master signal router.

BUY signals may originate from:

Bullish trend resumption
Bull Bias

SALE signals may originate from:

Bearish trend resumption
Bear Bias

The router enforces strict signal alternation:

BUY → SALE → BUY → SALE

After a BUY, additional BUY signals are ignored until a SALE occurs, and vice versa. Signal spacing is determined by market conditions rather than a fixed bar delay.

An optional Early Base Breakout BUY can be enabled to identify selected early bullish recoveries while remaining subject to the same master alternation rules.

Inputs

The indicator allows control of:

Sideways range display
Bull/Bear Bias labels
BUY/SALE labels
Label size
Range colours and transparency
Bias colours
BUY/SALE colours
Optional Early Base Breakout BUY
Usage

Yellow boxes highlight confirmed consolidation where directional movement may be limited.

BUY and SALE labels represent qualified analytical events generated by the integrated signal engine. They are informational and should not be interpreted as automatic trading instructions.

Calculation

The script uses confirmed-bar calculations and confirmed pivot information. It does not use future-data lookahead or request.security().

Limitations

Like any price-based analytical tool, performance depends on market conditions. Highly volatile markets, gaps, news events, and sudden regime changes can reduce signal quality. Strict signal alternation intentionally suppresses repeated signals in the same direction, which may omit some re-entry opportunities during strong trends.

Alerts

Range Breakout

Early BUY
BUY
SALE

This indicator is intended to provide a structured visual interpretation of sideways compression, directional bias, market structure, pullbacks, and trend resumption. It is an analytical tool and does not guarantee trading performance or future market direction.

//@version=6
indicator("SBP Sideways Range and Structure Navigator", overlay=true, max_bars_back=400, max_boxes_count=20, max_labels_count=100)
// INPUTS: SIGNALS, RANGE, AND MOMENTUM DISPLAY
groupSignals = "01 Buy and Sale Signals"
showBuySaleSignals = input.bool(true, "Show Buy and Sale Signals", group=groupSignals)
signalDisplayType = input.string("Labels", "Signal Display", options=["Labels", "Triangles", "Arrows"], group=groupSignals)
signalSizeInput = input.string("Normal", "Signal Size", options=["Tiny", "Small", "Normal"], group=groupSignals)
buySignalColor = input.color(color.lime, "Buy Signal Color", group=groupSignals)
saleSignalColor = input.color(color.red, "Sale Signal Color", group=groupSignals)
signalTextColor = input.color(color.white, "Signal Text Color", group=groupSignals)
signalDistanceAtr = input.float(0.35, "Label Distance (ATR)", minval=0.10, maxval=3.00, step=0.05, group=groupSignals)
groupRange = "02 Sideways Range Boxes"
showSidewaysZones = input.bool(true, "Show Sideways Range Boxes", group=groupRange)
sidewaysFillColor = input.color(color.yellow, "Box Fill Color", group=groupRange)
sidewaysBorderColor = input.color(color.orange, "Box Border Color", group=groupRange)
sidewaysTransparency = input.int(76, "Box Fill Transparency", minval=0, maxval=100, group=groupRange)
sidewaysBorderTransparency = input.int(0, "Box Border Transparency", minval=0, maxval=100, group=groupRange)
sidewaysBorderWidth = input.int(2, "Box Border Width", minval=1, maxval=4, group=groupRange)
groupCloud = "03 Bull and Bear Clouds"
showClouds = input.bool(true, "Show Bull and Bear Clouds", group=groupCloud)
bullCloudColor = input.color(color.rgb(35, 90, 205), "Bull Cloud Color", group=groupCloud)
bearCloudColor = input.color(color.rgb(165, 95, 15), "Bear Cloud Color", group=groupCloud)
cloudTransparency = input.int(56, "Cloud Transparency", minval=0, maxval=100, group=groupCloud)
signalSize = signalSizeInput == "Normal" ? size.normal : signalSizeInput == "Small" ? size.small : size.tiny
// SHARED MARKET MEASURES
confirmed = barstate.isconfirmed
newDay = timeframe.change("D")
changeClose = ta.change(close)
atr = math.max(ta.atr(14), syminfo.mintick)
fast = ta.ema(close, 9)
slow = ta.ema(close, 21)
[plusDI, minusDI, adx] = ta.dmi(14, 14)
diBull = plusDI > minusDI
diBear = minusDI > plusDI
// DEVELOPING PARTICIPATION STRUCTURE
f_expand(array<float> vols, int peak, float total, float fraction, int rows) =>
    int lo = peak
    int hi = peak
    float included = array.get(vols, peak)
    float target = total * fraction
    while included < target and (lo > 0 or hi < rows - 1)
        float lowerVol = lo > 0 ? array.get(vols, lo - 1) : -1.0
        float upperVol = hi < rows - 1 ? array.get(vols, hi + 1) : -1.0
        if upperVol > lowerVol
            hi += 1
            included += math.max(upperVol, 0.0)
        else
            lo -= 1
            included += math.max(lowerVol, 0.0)
    [lo, hi]
f_build(int length, int rows, float lowRange, float highRange, float coreFraction) =>
    float span = highRange - lowRange
    float rowSize = span > 0 ? span / rows : syminfo.mintick
    array<float> vols = array.new_float(rows, 0.0)
    if span > 0
        for i = 0 to length - 1
            float sampleLow = math.min(low[i], high[i])
            float sampleHigh = math.max(low[i], high[i])
            float sampleRange = math.max(sampleHigh - sampleLow, syminfo.mintick)
            int firstRow = math.max(0, math.min(rows - 1, int(math.floor((sampleLow - lowRange) / rowSize))))
            int lastRow = math.max(0, math.min(rows - 1, int(math.floor((sampleHigh - lowRange) / rowSize))))
            for row = firstRow to lastRow
                float rowLow = lowRange + row * rowSize
                float rowHigh = rowLow + rowSize
                float overlapSize = math.max(math.min(sampleHigh, rowHigh) - math.max(sampleLow, rowLow), 0.0)
                if overlapSize > 0
                    array.set(vols, row, array.get(vols, row) + nz(volume[i], 0.0) * overlapSize / sampleRange)
    float total = 0.0
    float peakVolume = -1.0
    int peakRow = 0
    for row = 0 to rows - 1
        float rowVolume = array.get(vols, row)
        total += rowVolume
        if rowVolume > peakVolume
            peakVolume := rowVolume
            peakRow := row
    [coreLoRow, coreHiRow] = f_expand(vols, peakRow, total, coreFraction, rows)
    [outerLoRow, outerHiRow] = f_expand(vols, peakRow, total, 0.94, rows)
    float coreLowerValue = total > 0 ? lowRange + coreLoRow * rowSize : na
    float coreUpperValue = total > 0 ? lowRange + (coreHiRow + 1.0) * rowSize : na
    float outerLowerValue = total > 0 ? lowRange + outerLoRow * rowSize : na
    float outerUpperValue = total > 0 ? lowRange + (outerHiRow + 1.0) * rowSize : na
    float controlValue = total > 0 ? lowRange + (peakRow + 0.5) * rowSize : na
    [coreLowerValue, coreUpperValue, outerLowerValue, outerUpperValue, controlValue]
var float coreLower = na
var float coreUpper = na
var float outerLower = na
var float outerUpper = na
var float control = na
dayLength = math.min(math.max(nz(ta.barssince(newDay)) + 1, 1), 300)
profileLow = ta.lowest(low, dayLength)
profileHigh = ta.highest(high, dayLength)
if confirmed
    [newCoreLower, newCoreUpper, newOuterLower, newOuterUpper, newControl] =
         f_build(dayLength, 30, profileLow, profileHigh, 0.68)
    coreLower := newCoreLower
    coreUpper := newCoreUpper
    outerLower := newOuterLower
    outerUpper := newOuterUpper
    control := newControl
channelCenter = not na(coreUpper) and not na(coreLower) ? (coreUpper + coreLower) * 0.5 : na
channelHalf = not na(coreUpper) and not na(coreLower) ? math.max((coreUpper - coreLower) / 2.5, syminfo.mintick * 2) : na
channelPremium = not na(channelCenter) ? channelCenter + channelHalf * 0.5 : na
channelDiscount = not na(channelCenter) ? channelCenter - channelHalf * 0.5 : na
// DIRECTIONAL QUALIFICATION
dirCenter = ta.ema(hlc3, 21)
dirMomentum = ta.ema(changeClose, 8) / atr
diTotal = plusDI + minusDI
diBalance = diTotal > 0 ? (plusDI - minusDI) / diTotal : 0.0
dirEvidence =
     diBalance * 0.32 +
     (fast > slow ? 0.24 : fast < slow ? -0.24 : 0.0) +
     math.max(-1.0, math.min(1.0, dirMomentum / 0.30)) * 0.22 +
     math.max(-1.0, math.min(1.0, (close - dirCenter) / atr / 1.25)) * 0.22
acceptance = ta.ema(dirCenter + dirEvidence * atr * 0.35, 5)
pCoreUpper = not newDay ? coreUpper[1] : na
pCoreLower = not newDay ? coreLower[1] : na
pOuterUpper = not newDay ? outerUpper[1] : na
pOuterLower = not newDay ? outerLower[1] : na
pControl = not newDay ? control[1] : na
pPremium = not newDay ? channelPremium[1] : na
pDiscount = not newDay ? channelDiscount[1] : na
barRange = math.max(high - low, syminfo.mintick)
body = math.abs(close - open)
bodyLow = math.min(open, close)
bodyHigh = math.max(open, close)
bodyRatio = body / barRange
safeBody = math.max(body, syminfo.mintick)
strongBullBody = confirmed and close > open and bodyRatio >= 0.45 and body / atr >= 0.40
strongBearBody = confirmed and close < open and bodyRatio >= 0.45 and body / atr >= 0.40
outerBuy = not na(pOuterLower) and low < pOuterLower and strongBullBody and close > pOuterLower
outerSale = not na(pOuterUpper) and high > pOuterUpper and strongBearBody and close < pOuterUpper
dualBuy =
     not na(pDiscount) and not na(pControl) and
     low <= pDiscount and low <= pControl and
     strongBullBody and close > pDiscount and close > pControl
dualSale =
     not na(pPremium) and not na(pControl) and
     high >= pPremium and high >= pControl and
     strongBearBody and close < pPremium and close < pControl
acceptBuy = strongBullBody and bodyLow > acceptance and acceptance > acceptance[1] and dirEvidence >= 0.18
acceptSale = strongBearBody and bodyHigh < acceptance and acceptance < acceptance[1] and dirEvidence <= -0.18
continuationBuy =
     not na(pCoreUpper) and not na(pControl) and
     strongBullBody and close[1] <= pCoreUpper and
     close > pCoreUpper + atr * 0.12 and close > pControl and
     diBull and adx >= 20
continuationSale =
     not na(pCoreLower) and not na(pControl) and
     strongBearBody and close[1] >= pCoreLower and
     close < pCoreLower - atr * 0.12 and close < pControl and
     diBear and adx >= 20
bullAcceptanceGate =
     dirEvidence >= 0.18 and diBull and adx >= 20.0 and
     close > acceptance and close > control
bearAcceptanceGate =
     dirEvidence <= -0.18 and diBear and adx >= 20.0 and
     close < acceptance and close < control
sourceBuyQuality =
     (outerBuy or dualBuy or acceptBuy or continuationBuy) and
     bullAcceptanceGate
sourceSaleQuality =
     (outerSale or dualSale or acceptSale or continuationSale) and
     bearAcceptanceGate
// ALTERNATING SIGNAL ROUTER
var int signalState = 0
var int lastSignalBar = na
buySignal = false
saleSignal = false
gapReady = na(lastSignalBar) or bar_index - lastSignalBar >= 4
if confirmed
    if signalState == 0
        if sourceBuyQuality and not sourceSaleQuality
            buySignal := true
        else if sourceSaleQuality and not sourceBuyQuality
            saleSignal := true
    else
        int requiredSide = -signalState
        bool oppositeNow = requiredSide == 1 ? sourceBuyQuality : sourceSaleQuality
        if oppositeNow and gapReady
            buySignal := requiredSide == 1
            saleSignal := requiredSide == -1
if buySignal
    signalState := 1
    lastSignalBar := bar_index
if saleSignal
    signalState := -1
    lastSignalBar := bar_index
// DIRECTIONAL MOMENTUM ZONES
strengthFast = ta.ema(hlc3, 3)
strengthSlow = ta.ema(hlc3, 6)
strengthProgress = close - close[4]
strengthSlopeNorm = (strengthFast - strengthFast[2]) / atr
strengthSideHigh = ta.highest(high, 8)
strengthSideLow = ta.lowest(low, 8)
float strengthSidePath = 0.0
for i = 0 to 6
    strengthSidePath += math.abs(close[i] - close[i + 1])
strengthEfficiency = strengthSidePath > syminfo.mintick ? math.abs(close - close[7]) / strengthSidePath : 1.0
strengthSeparation = math.abs(strengthFast - strengthSlow)
strengthSideways =
     strengthSideHigh - strengthSideLow <= atr * 1.65 and
     strengthEfficiency <= 0.34 and
     strengthSeparation <= atr * 0.18 and
     math.abs(strengthFast - strengthFast[3]) <= atr * 0.16
strengthBuyDirectional =
     close > strengthFast and strengthFast >= strengthSlow and
     (strengthSlopeNorm >= 0.020 or strengthProgress > 0.0)
strengthSaleDirectional =
     close < strengthFast and strengthFast <= strengthSlow and
     (strengthSlopeNorm <= -0.020 or strengthProgress < 0.0)
strengthBuyOutside = math.max(bodyHigh - math.max(bodyLow, acceptance + atr * 0.45), 0.0)
strengthSaleOutside = math.max(math.min(bodyHigh, acceptance - atr * 0.45) - bodyLow, 0.0)
strengthBuyOutsidePct = strengthBuyOutside / safeBody * 100.0
strengthSaleOutsidePct = strengthSaleOutside / safeBody * 100.0
strengthBuyStart =
     confirmed and signalState == 1 and not strengthSideways and strengthBuyDirectional and
     (strengthBuyOutsidePct >= 76.0 or
     (strengthBuyOutsidePct >= 55.0 and strengthBuyOutsidePct[1] >= 55.0))
strengthSaleStart =
     confirmed and signalState == -1 and not strengthSideways and strengthSaleDirectional and
     (strengthSaleOutsidePct >= 76.0 or
     (strengthSaleOutsidePct >= 55.0 and strengthSaleOutsidePct[1] >= 55.0))
sharpBullReverse =
     close > open and body >= atr * 0.55 and bodyRatio >= 0.48 and
     close > strengthFast and close > high[1]
sharpBearReverse =
     close < open and body >= atr * 0.55 and bodyRatio >= 0.48 and
     close < strengthFast and close < low[1]
var int strengthState = 0
if confirmed
    if strengthState == 1 and (signalState == -1 or sharpBearReverse or strengthSideways)
        strengthState := 0
    else if strengthState == -1 and (signalState == 1 or sharpBullReverse or strengthSideways)
        strengthState := 0
    if strengthState == 0
        if strengthBuyStart
            strengthState := 1
        else if strengthSaleStart
            strengthState := -1
// Range detection follows the finalized cloud state so both visuals agree.
cloudActive = showClouds and strengthState != 0
barsInSession = math.max(1, nz(ta.barssince(newDay)) + 1)
barsSinceCloud = ta.barssince(cloudActive)
quietBars = na(barsSinceCloud) ? barsInSession : math.min(barsInSession, barsSinceCloud)
shortLookback = 7
longLookback = 14
shortHigh = ta.highest(bodyHigh, shortLookback)
shortLow = ta.lowest(bodyLow, shortLookback)
longHigh = ta.highest(bodyHigh, longLookback)
longLow = ta.lowest(bodyLow, longLookback)
shortTravel = math.sum(math.abs(changeClose), shortLookback - 1)
longTravel = math.sum(math.abs(changeClose), longLookback - 1)
shortSlope = ta.linreg(close, shortLookback, 0) - ta.linreg(close, shortLookback, 1)
longSlope = ta.linreg(close, longLookback, 0) - ta.linreg(close, longLookback, 1)
shortBarSize = ta.sma(high - low, shortLookback)
shortBodySize = ta.sma(math.abs(close - open), shortLookback)
shortEfficiency = shortTravel > 0 ? math.abs(close - close[shortLookback - 1]) / shortTravel : 1.0
longEfficiency = longTravel > 0 ? math.abs(close - close[longLookback - 1]) / longTravel : 1.0
quietShort = shortHigh - shortLow <= atr * 2.75 and shortEfficiency <= 0.50 and math.abs(shortSlope) <= atr * 0.24 and shortBodySize <= shortBarSize * 0.65
quietLong = longHigh - longLow <= atr * 3.45 and longEfficiency <= 0.41 and math.abs(longSlope) <= atr * 0.19

var int rangeCount = 0
var int upperBreakCount = 0
var int lowerBreakCount = 0

var float storedRangeLow = na

    rangeCount := 0
    upperBreakCount := 0
    lowerBreakCount := 0
    lastRangeEnd := na

    storedRangeLow := na

    rangeState := 1
    rangeCount := 0
    upperBreakCount := 0
    lowerBreakCount := 0

    storedRangeLow := (seedLength == longLookback ? longLow : shortLow) - atr * 0.12

    lowerBreakCount := close < storedRangeLow - rangeBuffer ? lowerBreakCount + 1 : 0
rangeEnd = confirmed and rangeState == 1 and (upperBreakCount >= 2 or lowerBreakCount >= 2 or cloudActive)

        if na(rangeBox)
            rangeBox := box.new(storedRangeStart, storedRangeHigh, rightEdge, storedRangeLow, xloc=xloc.bar_index, border_color=color.new(sidewaysBorderColor, sidewaysBorderTransparency), border_width=sidewaysBorderWidth, bgcolor=color.new(sidewaysFillColor, sidewaysTransparency))

            box.set_border_width(rangeBox, sidewaysBorderWidth)
            box.set_bgcolor(rangeBox, color.new(sidewaysFillColor, sidewaysTransparency))

    rangeState := 0
    rangeCount := 0
    upperBreakCount := 0
    lowerBreakCount := 0
    lastRangeEnd := bar_index
    storedRangeHigh := na
    storedRangeLow := na
    storedRangeStart := na
    rangeBox := na
strengthWidth =
     math.max(
         atr * 0.20,
         math.min(
             atr * 0.30 +
             strengthSeparation * 0.95 +
             math.abs(strengthProgress) / 4.0 * 0.38,
             atr * 0.95))
strengthUpper = strengthState != 0 ? strengthFast + strengthWidth * 0.5 : na
strengthLower = strengthState != 0 ? strengthFast - strengthWidth * 0.5 : na
strengthColor = not showClouds ? na : strengthState == 1 ? color.new(bullCloudColor, cloudTransparency) : strengthState == -1 ? color.new(bearCloudColor, cloudTransparency) : na

showSignalLabels = showBuySaleSignals and signalDisplayType == "Labels"
