Calculation: Liquidity line = a smoothed price basis plus or minus a smoothed absolute-close deviation; the upper line applies in bearish state and the lower line in bullish state. The state turns bullish when close exceeds the upper line and bearish when close falls below the lower line; otherwise it persists.
Calculation: Heatmap trail = an ATR-based trailing stop that ratchets upward in bullish state and downward in bearish state; the state turns bullish when close exceeds the prior bearish stop and bearish when close falls below the prior bullish stop; otherwise it persists.
Calculation: BASS bullish count = number of bullish conditions among MACD histogram > 0, RSI(14) > 50, smoothed stochastic K > D, Awesome Oscillator > 0, and Alligator lips > teeth > jaw; bearish count uses the corresponding bearish comparisons. If volume is included, add VWMA(hlc3) > SMA(hlc3) for bullish and < for bearish. These use the same lookbacks for both directions.
Calculation: VAPI = 100 × SMA(volume × (2 × close − high − low) / (high − low), lookback) / SMA(volume, lookback); when high = low, the numerator input is zero.
Long: On the trigger timeframe, close > liquidity line AND close > heatmap trail when both trigger checks are required, otherwise either condition; the trigger is bullish and the required number of active trigger, confirmation, and optional third timeframes are bullish, with bullish timeframe count > bearish timeframe count; ADX on its configured timeframe meets its minimum and, when required, is not falling; BASS on its configured timeframe has at least the required bullish count and bullish count > bearish count; any enabled bias filter is bullish (fast EMA > slow EMA and/or close > VWAP as configured); any enabled VAPI required filter has VAPI > 0 and, when required, VAPI >= its prior value.
Long: On any configured timeframe, close > its liquidity line or heatmap trail according to that timeframe's confirmation mode.
Long: On the configured bias timeframe, fast EMA > slow EMA and/or close > VWAP according to the selected bias mode.
Long: On the configured BASS timeframe, bullish BASS count >= required count and bullish count > bearish count.
Long: On the configured VAPI timeframe, VAPI > 0 and, when slope confirmation is required, VAPI >= its prior value.
Short: On the trigger timeframe, close < liquidity line AND close < heatmap trail when both trigger checks are required, otherwise either condition; the trigger is bearish and the required number of active trigger, confirmation, and optional third timeframes are bearish, with bearish timeframe count > bullish timeframe count; ADX on its configured timeframe meets its minimum and, when required, is not falling; BASS on its configured timeframe has at least the required bearish count and bearish count > bullish count; any enabled bias filter is bearish (fast EMA < slow EMA and/or close < VWAP as configured); any enabled VAPI required filter has VAPI < 0 and, when required, VAPI <= its prior value.
Short: On any configured timeframe, close < its liquidity line or heatmap trail according to that timeframe's confirmation mode.
Short: On the configured bias timeframe, fast EMA < slow EMA and/or close < VWAP according to the selected bias mode.
Short: On the configured BASS timeframe, bearish BASS count >= required count and bearish count > bullish count.
Short: On the configured VAPI timeframe, VAPI < 0 and, when slope confirmation is required, VAPI <= its prior value.
Exit: Long, opposite short entry alignment is present or bullish timeframe count falls below the required count, according to the selected exit mode.
Exit: Short, opposite long entry alignment is present or bearish timeframe count falls below the required count, according to the selected exit mode.
