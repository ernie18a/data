Calculation: Top-7 contribution = sum of each of the seven component prices minus its reference price, divided by the Dow divisor; reference is either the current session open or the previous completed daily close.
Calculation: YM movement = current YM close minus its reference price; use the same reference choice as for the Top-7 contribution.
Calculation: VWAP balance = price-weighted percentage balance of component prices above versus below their current-session VWAPs; weights use each component's reference price.
Calculation: Session move (%) = (component price − current-session open) / current-session open × 100.
Calculation: Opening gap (%) = (current-session open − previous completed daily close) / previous completed daily close × 100.
Calculation: Previous-day VWAP = final VWAP of the previous completed session.
Long: Top-7 contribution > 0 AND VWAP balance > 0 OR any component price > its current-session VWAP OR any component price > its previous-day VWAP OR any component session move (%) > behavior threshold AND (its opening gap (%) ≤ −behavior threshold OR its opening gap (%) ≤ behavior threshold) OR any component session move (%) > behavior threshold AND its opening gap (%) ≤ behavior threshold OR YM movement > 0 OR any component contribution > 0 OR Top-7 gap > 0 OR YM opening gap > 0 OR number of components up > number of components down
