計算：雲上界／雲下界＝短期收盤價 EMA、平滑回歸線、延後的趨勢線三者最大值／最小值
計算：ATR 趨勢線＝以 RSI 高於中線時沿用前值或採用低點減 ATR 倍數；RSI 不高於中線時沿用前值或採用高點加 ATR 倍數
計算：多方／空方動能＝以開盤價與收盤價遞迴平滑的一階、二階高低界差平方根；多方動能取低界，空方動能取高界
計算：雲均線＝多方動能較大時取雲下界與前值較大者；空方動能較大時取雲上界與前值較小者；兩者相等時沿用前值
計算：趨勢方向＝雲均線連續上升／下降時標記多／空，否則沿用前值
計算：風險距離＝入場價與回看期內已確認 pivot 低點的最低值／pivot 高點的最高值之差；做多取入場價減最低值，做空取最高值減入場價
計算：停損價＝做多初始為回看期內最低 pivot 低點，做空初始為回看期內最高 pivot 高點；持倉有利波動超過一個風險距離後移至入場價
計算：停利價＝做多入場價加風險距離乘風險報酬倍數，做空入場價減風險距離乘風險報酬倍數
做多：選用雲與 pivot 模式時，收盤價高於最近已確認 pivot 高點且高於雲上界；選用附回歸方向過濾的模式時，收盤價高於最近已確認 pivot 高點且高於雲上界且平滑回歸線上升；選用雲均線模式時，趨勢方向為多且收盤價高於雲上界
做空：選用雲與 pivot 模式時，收盤價低於最近已確認 pivot 低點且低於雲下界；選用附回歸方向過濾的模式時，收盤價低於最近已確認 pivot 低點且低於雲下界且平滑回歸線下降；選用雲均線模式時，趨勢方向為空且收盤價低於雲下界
出場：多倉，雲均線模式下趨勢方向由多轉空；其他模式下收盤價低於雲下界且低於最近已確認 pivot 低點；若啟用停損停利，最低價低於或等於停損價，或最高價高於或等於停利價
出場：空倉，雲均線模式下趨勢方向由空轉多；其他模式下收盤價高於雲上界且高於最近已確認 pivot 高點；若啟用停損停利，最高價高於或等於停損價，或最低價低於或等於停利價
