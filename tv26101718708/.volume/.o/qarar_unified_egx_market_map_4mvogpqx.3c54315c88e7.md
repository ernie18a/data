Calculation: Rolling trend direction = On each bar, compare the close with a rolling segment using ATR from the same timeframe. Initialize the segment at the first close, direction upward, active slope zero, and fast mode off. If ATR is available, reverse direction when the close is more than a reverse-threshold multiple of ATR beyond the segment against the current direction. Fast mode is active when the absolute close-to-segment distance exceeds a fast-threshold multiple of ATR. When direction reverses, fast mode changes, or active slope is zero, set the slope to ATR divided by the fast lookback in fast mode or by the longer, slow lookback otherwise. Advance the segment by the slope in the current direction. If ATR is unavailable, set the segment to the close.

Short: Rolling trend direction is downward
