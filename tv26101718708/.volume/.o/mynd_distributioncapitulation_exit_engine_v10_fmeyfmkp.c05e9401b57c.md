Calculation: Distribution score = Let distribution days be bars where (close − previous close) / previous close × 100 ≤ −minimum decline and volume ≥ volume multiplier × previous-bar volume. Distribution-day component = min(100, count of distribution days in lookback / critical count × 100). Down-volume ratio = 100 × sum(volume when close < previous close) / sum(volume) over its lookback (50 if total volume is zero); ratio component = max(0, 2 × (ratio − 50)). Momentum component = min(100, 10 × (RSI lookback bars ago − current RSI)) if that earlier RSI ≥ 55 and current RSI is lower, otherwise 0. Raw score = weighted average of these three components (0 if total weight is zero). Final score = raw score if close ≥ highest high over the near-high lookback × (1 − near-high percentage / 100), otherwise half the raw score.
Calculation: Capitulation score = Volume component: let volume z-score be (current volume − its lookback mean) / its lookback standard deviation (0 if standard deviation is zero); component = clamp(100 × z-score / volume threshold, 0, 100). Candle component = average of clamp(100 × ((high − low) / ATR) / minimum range-in-ATR, 0, 100) and clamp(100 × close position / minimum close position, 0, 100), where close position = (close − low) / (high − low), or 0.5 if range is zero; the second value is 100 if minimum close position is zero. Momentum component = min(100, 5 × extremity + 5 × uptick), where uptick = max(0, current RSI − RSI bars ago), and extremity = max(0, oversold level − min(current RSI, RSI bars ago)) if uptick > 0, otherwise 0. Score = weighted average of volume, candle, and momentum components (0 if total weight is zero).
Exit: Long position, (current Distribution score > long warning threshold AND previous Distribution score ≤ long warning threshold AND current Distribution score < long exit threshold) OR (current Distribution score > long exit threshold AND previous Distribution score ≤ long exit threshold)
Exit: Short position, (current Capitulation score > short warning threshold AND previous Capitulation score ≤ short warning threshold AND current Capitulation score < short exit threshold) OR (current Capitulation score > short exit threshold AND previous Capitulation score ≤ short exit threshold)
