Calculation: Up probability = sigmoid output of an online-trained 9-input, one-hidden-layer tanh MLP. Inputs are clipped and normalized: close deviation from EMA; fast/slow EMA spread; RSI centered at 50 and scaled by 50; ATR as a percentage of close, z-scored over a longer lookback than the feature lookback; log of volume/current volume moving-average ratio, z-scored over the same longer lookback; normalized MACD histogram; close position within Bollinger Bands; directional-indicator difference; and close position within the rolling high-low range. Train on each completed bar using the prior bar's inputs and whether the current close exceeds the previous close, with binary cross-entropy backpropagation, momentum, and L2 regularization; use the current inputs for the probability.
Calculation: Confidence = 2 × absolute value of (up probability − 0.5)
Long: bar index > warmup period AND training steps > 50 AND up probability > long threshold AND confidence > minimum confidence AND current up probability > long threshold AND previous up probability ≤ long threshold
Short: bar index > warmup period AND training steps > 50 AND up probability < short threshold AND confidence > minimum confidence AND current up probability < short threshold AND previous up probability ≥ short threshold
