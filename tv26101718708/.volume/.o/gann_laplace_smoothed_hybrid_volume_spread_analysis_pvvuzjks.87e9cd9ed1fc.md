Calculation: Relative volume = volume divided by Fourier-smoothed prior volume; if volume smoothing is disabled, divide by prior-bar volume
Calculation: Volume-weighted spread = (EMA of Fourier-smoothed close − EMA of Fourier-smoothed open) × relative volume; both EMAs use the same Gann-adjusted length
Calculation: Smoothed spread = EMA of volume-weighted spread
Long: Smoothed spread > 0 AND volume-weighted spread > 0
Short: Smoothed spread < 0 AND volume-weighted spread < 0
Exit: long or short, smoothed spread ≤ 0 OR volume-weighted spread ≤ 0, when close-all is enabled AND (Gann position is zero OR Gann-entry is disabled)
