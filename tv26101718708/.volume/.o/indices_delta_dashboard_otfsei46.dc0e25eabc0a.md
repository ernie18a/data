Calculation: Delta = volume when close > open, −volume when close < open, otherwise 0, using the current bar of the selected table timeframe while it is forming
Calculation: Session Delta = sum of Delta for bars since the start of the selected daily or Globex session, using the current table-timeframe bar while it is forming
Long: Delta >= 0 OR Session Delta >= 0
Short: Delta < 0 OR Session Delta < 0
