Calculation: ACO z-score = On current chart-timeframe bars, calculate ATR over the volatility lookback and its SMA over the same lookback. Set adaptive length to clamp(base momentum length / max(ATR / ATR SMA, 0.25), 3, 3 × base momentum length). Recursively average positive and negative close-to-close changes using alpha = 2 / (adaptive length + 1), seeded with the first change. Raw RSI = 100 if average loss is zero, otherwise 100 − 100 / (1 + average gain / average loss). Smooth raw RSI recursively with KAMA: efficiency ratio = absolute change over the base momentum length / sum of absolute one-bar changes over that length; square the interpolation between fast and slow smoothing constants, where the fast constant is shorter than the slow constant. Seed KAMA with the first raw RSI. ACO z-score = (KAMA − its SMA over the normalization window) / its standard deviation over that window; use zero when standard deviation is zero.
