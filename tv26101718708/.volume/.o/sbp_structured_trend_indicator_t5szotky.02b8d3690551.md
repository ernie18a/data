Calculation: Bull evidence = (close > fast EMA) + (close > HMA(hlc3, phase lookback)) + (phase HMA rising) + (momentum change > 0) + (DI pressure change > 0) + (pressure index > 0) + 0.75×(pressure index rising) + 0.75×bull volume filter + 0.75×bull effort filter + 0.75×(bull candle and close in upper 45% of range); each unweighted true condition adds 1, each weighted true condition adds its weight
Calculation: Bear evidence = (close < fast EMA) + (close < HMA(hlc3, phase lookback)) + (phase HMA falling) + (momentum change < 0) + (DI pressure change < 0) + (pressure index < 0) + 0.75×(pressure index falling) + 0.75×bear volume filter + 0.75×bear effort filter + 0.75×(bear candle and close in lower 45% of range); each unweighted true condition adds 1, each weighted true condition adds its weight
Calculation: Phase distance = (close − phase HMA) / ATR; phase slope = phase HMA − its value two bars earlier; momentum = EMA of close change; momentum change = current momentum/ATR minus prior momentum/ATR; DI pressure = (plus DI − minus DI) / max(plus DI + minus DI, 1); DI pressure change = current minus prior
Calculation: Pressure index = clamp(EMA(EMA(bull raw − bear raw, pressure lookback), smoothing lookback) / highest absolute value of that EMA over normalization lookback, −1, 1), or 0 if the denominator is 0; bull raw = 35×bull candle body/range + 30×(close−low)/range + 20×max((lower wick−upper wick)/range,0) + 15×max(range/SMA(range, normalization lookback)−1,0); bear raw = 35×bear candle body/range + 30×(high−close)/range + 20×max((upper wick−lower wick)/range,0) + 15×max(range/SMA(range, normalization lookback)−1,0); range = max(high−low, minimum price increment)
Calculation: Bull volume filter = volume participation disabled or volume unavailable or (volume/SMA(volume, volume lookback) ≥ minimum relative volume and volume flow > 0); bear volume filter uses volume flow < 0; volume flow = clamp(EMA(volume×(2×(close−low)/range−1), 7) / SMA(abs(volume×(2×(close−low)/range−1)), volume lookback), −2, 2); unavailable volume means na or ≤ 0
Calculation: Bull effort filter = volume participation disabled or volume unavailable or (bull candle and volume flow > 0 and (relative volume / max(abs(close−prior close)/ATR, 0.10) ≤ effort threshold or body/range ≥ body threshold); bear effort filter uses bear candle and volume flow < 0
Calculation: Top exhaustion score = count of (body < prior value of SMA(body, body lookback)), (abs(phase slope/ATR) < slope threshold or lower than its prior value), (momentum change < 0), (DI pressure change < 0), (upper wick/range ≥ wick threshold), and (ADX ≥ minimum and ADX ≤ prior ADX); bottom exhaustion score uses momentum change > 0, DI pressure change > 0, and lower wick/range ≥ wick threshold instead
Calculation: Setup state = on a confirmed bar, set top setup at a new high over the prior extreme lookback when structure is bullish, or bottom setup at a new low over that lookback when structure is bearish; initialize its score to the corresponding exhaustion score and update its score to the maximum of itself and the corresponding current exhaustion score; expire after setup life bars; clear setup after either final signal. Structure is bullish when fast EMA > slow EMA, close > phase HMA, and phase slope > 0; bearish when all three comparisons are reversed, otherwise neutral
Calculation: Top armed = active top setup and setup score ≥ arming threshold; bottom armed = active bottom setup and setup score ≥ arming threshold
Calculation: Trend long = bullish structure and phase distance ≥ minimum phase distance and bull evidence ≥ entry threshold and bull evidence > bear evidence + margin; trend short = bearish structure and phase distance ≤ −minimum phase distance and bear evidence ≥ entry threshold and bear evidence > bull evidence + margin
Calculation: Reversal long = bottom armed and bull candle and close > fast EMA and momentum change > 0 and bull evidence ≥ reversal threshold; reversal short = top armed and bear candle and close < fast EMA and momentum change < 0 and bear evidence ≥ reversal threshold
Long: confirmed bar and (trend long or reversal long) and not (trend short or reversal short) and prior signal state ≠ long and bull evidence ≥ bear evidence + switch margin
Short: confirmed bar and (trend short or reversal short) and not (trend long or reversal long) and prior signal state ≠ short and bear evidence ≥ bull evidence + switch margin
