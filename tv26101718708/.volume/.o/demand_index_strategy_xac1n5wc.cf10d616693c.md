Calculation: Demand Index = Let P = high + low + 2×close; range = max(high, prior high) − min(low, prior low); range average and volume average are EMAs with the same short-term length. Let H0 and L0 be the high and low of the first loaded bar, and S = max(H0−L0, minimum tick). Let V = volume / volume average (or 1 if the average is zero), and k = 0.375. If P < prior P, buy power = V / exp(k×(P+prior P)/S × (prior P−P)/P), sell power = V. If P > prior P, buy power = V, sell power = V / exp(k×(P+prior P)/S × (P−prior P)/prior P); otherwise both equal V. Smooth buy and sell power with EMAs using the same short-term length. If smoothed buy power > smoothed sell power, Demand Index = 100×(1−sell/buy); if buy < sell, Demand Index = 100×(buy/sell−1); otherwise 0.
Long: The longer-timeframe Demand Index has been ≤ the deep level since its most recent value > 0, and is currently > the recovery level, AND the shorter-timeframe Demand Index crosses above its signal EMA. Use the latest available values for both timeframe series (the bar still forming in real time; the last completed bar historically); calculate the signal EMA on the chart-timeframe series of shorter-timeframe Demand Index values.
Exit: long, low ≤ stop OR high ≥ target; set the stop and target from the close of the long-entry signal bar using the configured stop and target percentages. In trailing-stop mode, update the stop to the greater of its prior value and current close×(1−stop percentage); in fixed-stop mode, do not update it.
