Calculation: Estimated volume delta = sum of lower-timeframe intrabar volume signed +1 when intrabar close > open, -1 when close < open, and by comparison with the preceding intrabar close when close = open; if no intrabars are available, use chart-bar volume signed by chart-bar close versus open (zero if equal). Use completed chart bars.
Calculation: Run efficiency ratio = sum of high − low over the consecutive same-sign delta run divided by the sum of absolute delta over that run, divided by the trailing average of this measure over a longer lookback, using the prior completed chart bar's average.
Long: On a completed chart bar, estimated volume delta is positive for the configured number of consecutive bars, and the efficiency filter is Any or Efficient with run efficiency ratio ≥ 1 or Absorbed with run efficiency ratio < 1, and isolation is disabled or no opposite-direction run completed within the configured prior time window.
Short: On a completed chart bar, estimated volume delta is negative for the configured number of consecutive bars, and the efficiency filter is Any or Efficient with run efficiency ratio ≥ 1 or Absorbed with run efficiency ratio < 1, and isolation is disabled or no opposite-direction run completed within the configured prior time window.
