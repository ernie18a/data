Calculation: Volume exhaustion line = Use confirmed fractal pivots of highs and lows, each requiring a configurable number of bars on both sides. Evaluate each pivot when its right-side bars have completed, using volume and its simple moving average on the pivot bar. Classify volume as weak when it is below that average; otherwise classify it as strong. Set the trend to up when the latest two confirmed highs and latest two confirmed lows are both rising, down when both are falling, and none otherwise. In an uptrend, set an exhaustion warning when a weak-volume high follows a strong-volume high; keep it set for subsequent weak-volume highs, clear it on a strong-volume high, and reset it when the trend is no longer up. Apply the same rules to lows in a downtrend. Calculate a simple moving average of close and an ATR, using independently configurable lookbacks; offset the average by a configurable multiple of ATR. In an uptrend, use the lower offset band without a warning and the upper offset band with a warning. In a downtrend, use the upper offset band without a warning and the lower offset band with a warning. The exhaustion line is undefined when the trend is none or not yet established.
