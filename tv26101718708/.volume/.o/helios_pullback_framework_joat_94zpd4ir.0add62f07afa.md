Calculation: Fast ALMA = ALMA of close using the shorter ALMA lookback; slow ALMA = ALMA of close using the longer ALMA lookback.
Calculation: HTF fast and slow ALMAs = the corresponding ALMAs on the last completed higher-timeframe bar; if higher-timeframe bias is disabled, use the current-timeframe fast and slow ALMAs.
Calculation: Regression slope = (current linear regression of close − its prior-bar value) / max(ATR, minimum tick).
Calculation: Bias = bullish when fast ALMA > slow ALMA, regression slope > 0, and HTF fast ALMA > HTF slow ALMA; bearish when all three comparisons are reversed; otherwise neutral. Ignore the HTF comparison when higher-timeframe bias is disabled.
Calculation: Pullback depth = bullish bias ? clamp((fast ALMA − low) / max(ATR, minimum tick), 0, 5) : bearish bias ? clamp((high − fast ALMA) / max(ATR, minimum tick), 0, 5) : 0.
Calculation: Fast ALMA slope = (fast ALMA − its value 5 bars earlier) / max(ATR, minimum tick).
Calculation: Phase impulse = EMA(phase − its prior-bar value, 3), where phase = (RSI(close, phase lookback) − EMA(RSI(close, phase lookback), 7)) / 10.
Calculation: Lower sweep = on a confirmed bar, low < latest confirmed pivot low (8 bars left and right) and close > that pivot low. Upper sweep = on a confirmed bar, high > latest confirmed pivot high (8 bars left and right) and close < that pivot high.
Calculation: Wick buy = (min(open, close) − low) / max(high − low, minimum tick). Wick sell = (high − max(open, close)) / max(high − low, minimum tick).
Calculation: Volume z-score = (volume − SMA(volume, lookback)) / standard deviation(volume, lookback). Compression = clamp(1 − standard deviation(close, shorter lookback) / max(standard deviation(close, longer lookback), minimum tick), 0, 1).
Calculation: Long score = clamp(22 if bullish bias else 0 + 14 if HTF fast ALMA > HTF slow ALMA (or HTF bias disabled) else 0 + clamp(pullback depth / 1.4 × 16, 0, 16) + 12 if lower sweep else 0 + clamp(wick buy × 14, 0, 14) + 11 if bullish bias and close > fast ALMA and close > open and phase impulse > 0 else 0 + clamp((volume z-score + 1) × 4, 0, 10) + clamp(compression × 7, 0, 7) + clamp(fast ALMA slope × 5, 0, 6) + clamp(bullish reversion force × 8, 0, 8) + 6 if session gate passes else 0, 0, 100), where bullish reversion force = clamp((close − low) / max(high − low, minimum tick), 0, 1).
Calculation: Short score = clamp(22 if bearish bias else 0 + 14 if HTF fast ALMA < HTF slow ALMA (or HTF bias disabled) else 0 + clamp(pullback depth / 1.4 × 16, 0, 16) + 12 if upper sweep else 0 + clamp(wick sell × 14, 0, 14) + 11 if bearish bias and close < fast ALMA and close < open and phase impulse < 0 else 0 + clamp((volume z-score + 1) × 4, 0, 10) + clamp(compression × 7, 0, 7) + clamp(−fast ALMA slope × 5, 0, 6) + clamp(bearish reversion force × 8, 0, 8) + 6 if session gate passes else 0, 0, 100), where bearish reversion force = clamp((high − close) / max(high − low, minimum tick), 0, 1).
Long: confirmed bar AND cooldown has elapsed since the prior long or short signal AND long score ≥ signal threshold AND abs(close − fast ALMA) / max(ATR, minimum tick) ≤ maximum stretch AND close > regression floor AND bullish bias AND prior bar did not satisfy this full long-state condition.
Short: confirmed bar AND cooldown has elapsed since the prior long or short signal AND short score ≥ signal threshold AND abs(close − fast ALMA) / max(ATR, minimum tick) ≤ maximum stretch AND close < regression ceiling AND bearish bias AND prior bar did not satisfy this full short-state condition.
