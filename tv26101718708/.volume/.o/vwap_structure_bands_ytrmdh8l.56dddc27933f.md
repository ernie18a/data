Calculation: Session VWAP = cumulative ((high + low + close) / 3 × volume) ÷ cumulative volume, reset at each new day and including the current bar
Long: close crosses above Session VWAP (current close > current Session VWAP AND previous close ≤ previous Session VWAP)
Short: close crosses below Session VWAP (current close < current Session VWAP AND previous close ≥ previous Session VWAP)
