Calculation: Price pivot code = +1 at a pivot high or −1 at a pivot low; double its sign when that pivot is higher or lower, respectively, than the previous same-direction price pivot. Detect pivots from rolling-window close prices or highs/lows, according to the selected source.
Calculation: Oscillator pivot code = +1 at an oscillator value associated with a price high pivot or −1 at one associated with a price low pivot; double its sign when that value is higher or lower, respectively, than the previous same-direction oscillator value at a price pivot.
Calculation: Trend direction = pivot-history Supertrend state, initially +1. Set candidate buy/sell stops to the lowest/highest of the recent price pivots minus/plus ATR times a multiplier. Reverse +1 to −1 when the previous close is below the prior buy stop, and −1 to +1 when it is above the prior sell stop. While direction is +1, ratchet the buy stop upward; while −1, ratchet the sell stop downward.
Calculation: Divergence class = continuation if price and oscillator pivot codes are equal and either they are both doubled with price code/2 equal to trend direction, or they are not doubled and price code differs from trend direction; regular divergence if price code equals twice oscillator code and oscillator code equals trend direction; hidden divergence if oscillator code equals twice price code and price code equals negative trend direction; otherwise indeterminate.
Calculation: Bias = +1 if both pivot codes are +2; −1 if both are −2; −1 if price pivot code is positive; +1 if price pivot code is negative; otherwise 0.
Long: Bias = +1 AND divergence class is continuation, regular divergence, or hidden divergence.
Short: Bias = −1 AND divergence class is continuation, regular divergence, or hidden divergence.
