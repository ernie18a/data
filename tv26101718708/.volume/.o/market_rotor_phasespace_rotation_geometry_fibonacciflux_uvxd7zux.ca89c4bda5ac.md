Calculation: x = z-score the selected x-axis over a rolling lookback, optionally whiten it jointly with y using their rolling covariance, then clip to a configurable range; x-axis is log(close) minus its EMA, or log(close) minus prior log(close) for the return/volatility-change mode.
Calculation: y = z-score the selected second axis over the same rolling lookback as x, optionally whiten jointly with x, then clip to the same configurable range; choices are EMA(short)-minus-EMA(long) of log returns, signed lower-timeframe volume delta divided by chart-bar volume (falling back to (2×(close−low)/(high−low)−1)), that same price-range proxy, change in rolling realized volatility, or change in open interest. Lag y by a configurable number of bars before normalization.
Calculation: r = sqrt(x² + y²).
Calculation: dθ = signed angle atan2(x[1]×y − y[1]×x, x[1]×x + y[1]×y); set it to zero when either endpoint has radius below the configurable dead-zone radius.
Calculation: C = sum(dθ, N) / sum(|dθ|, N), valid only when sum(|dθ|, N) exceeds a configurable gate.
Calculation: S* = sum(change(log(r + ε)), N) / sum(|dθ|, N), using the same N and validity gate as C.
Calculation: H = clamp(surprise + coherence-drop + flip-penalty, 0, maximum), where surprise = |dθ − EMA(dθ, slow lookback)| / max(stdev(dθ, longer lookback), floor); coherence-drop = 2.5×max(0, |C[1]|−|C|); flip-penalty = 1.5 when C[1]×C < 0 and |C[1]| > 0.40, otherwise zero.
Calculation: R3 = log(close) − log(close[3]).
Long: ready and outside cooldown since the last signal, and ((x < −reversal threshold AND R3 > 0 AND R3[1] <= 0 AND C valid AND |C| > 0.32 AND S* valid AND S* < spiral threshold AND H < 3.2) OR (x[1] <= breakout threshold AND x > breakout threshold AND R3 > 0 AND r > breakout-radius threshold AND S* valid AND S* > spiral threshold AND H < 4.2)).
Short: ready and outside cooldown since the last signal, and ((x > reversal threshold AND R3 < 0 AND R3[1] >= 0 AND C valid AND |C| > 0.32 AND S* valid AND S* < spiral threshold AND H < 3.2) OR (x[1] >= −breakout threshold AND x < −breakout threshold AND R3 < 0 AND r > breakout-radius threshold AND S* valid AND S* > spiral threshold AND H < 4.2)).
