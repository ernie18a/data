Calculation: Selected price = the configured choice of open, high, low, close, (high+low)/2, (open+close)/2, (open+high+low)/3, (high+low+close)/3, or (open+high+low+close)/4.
Calculation: Base price = selected price from the configured resolution; use the current resolution bar on historical bars and the preceding completed resolution bar in real time.
Calculation: Scaled loss = map the model loss linearly from its rolling minimum and maximum over the normalization lookback to the rolling minimum and maximum of base price over that same lookback. Each bar, initialize weight to 0 and repeat for the configured training iterations: set h = sigmoid(sum(X × 0, lookback)) = 0.5; loss = −1/lookback × sum(sum(Y × (ln(h) + 1 − Y), lookback) × ln(1 − h), lookback); update weight by subtracting learning rate/lookback × sum(X × (h − Y), lookback). Use X = time and Y = base price when optional calculation is enabled; otherwise X = base price and Y = ln(abs(base price² − 1) + 0.5). sigmoid(z) = 1/(1 + exp(−z)).
Calculation: Scaled prediction = map sigmoid(sum(X × weight, lookback)) linearly from its rolling minimum and maximum over the normalization lookback to the rolling minimum and maximum of base price over that same lookback, using X and weight as defined for Scaled loss.
Calculation: Volatility filter = ATR(1) > ATR(10). Volume filter = HMA(RSI(volume, 14), 10) > 49. The configured filter passes when volatility, volume, both, or neither filter is selected and passes.
Long: Filter passes AND previous signal is not long AND ((price-based signals are selected AND base price > scaled loss) OR (price-based signals are not selected AND scaled loss crosses above scaled prediction)).
Short: Filter passes AND previous signal is not short AND ((price-based signals are selected AND base price < scaled loss) OR (price-based signals are not selected AND scaled loss crosses below scaled prediction)).
Exit: Long, holding-period counter reaches the configured holding period without a signal change OR signal changes to short.
Exit: Short, holding-period counter reaches the configured holding period without a signal change OR signal changes to long.
