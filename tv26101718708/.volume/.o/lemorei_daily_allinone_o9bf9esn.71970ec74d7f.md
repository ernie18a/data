Calculation: Daily close location = (current daily close − current daily low) / (current daily high − current daily low); use the current, still-forming daily bar.
Calculation: Daily relative strength = the instrument’s percentage return minus the benchmark’s percentage return over the same lookback of daily bars; use current daily bars, which may still be forming.
Calculation: Strong day = current daily close > previous completed daily close AND current daily close > current daily open AND daily close location ≥ 65%.
Calculation: Healthy pullback = NOT breakdown AND current daily close ≥ previous completed daily close AND daily close location ≥ 40%.
Calculation: Breakdown = current daily close < previous completed daily low OR (current daily close < previous completed daily close AND daily close location < 20%).
Calculation: Stretch danger = (current daily range / daily ATR ≥ 150% AND daily close location < 30%) OR daily close location < 15% OR (current daily close − current daily high) / daily ATR ≤ −1.00; use the current daily bar and daily ATR.
Calculation: Same-time relative volume = cumulative regular-session volume through the current slot divided by the average cumulative regular-session volume through that slot in prior sessions; use during the regular session.
