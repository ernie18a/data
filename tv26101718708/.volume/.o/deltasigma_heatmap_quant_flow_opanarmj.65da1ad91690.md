Calculation: Log return = ln(close / previous chart-bar close).
Calculation: Signed sigma score = (current log return − reference center) / reference scale; choose Rolling (mean and population SD of the same number of prior chart-bar returns), EWMA (mean and SD from prior returns using the same half-life), or robust MAD (median and 1.4826 × median absolute deviation of the same prior-return window). The current return is excluded from the reference; require a positive scale and a full valid reference.
Calculation: Delta ratio = clamp(WMA of signed volume / SMA of volume / gradient scale, −1, 1); signed volume is +volume when close ≥ open and −volume otherwise, or the sum of signed lower-timeframe volume estimates when that source is selected. WMA and volume SMA use the same length. For lower-timeframe doji bars, use close versus the previous lower-timeframe close; if equal, retain the prior direction.
Calculation: RTH flow percent = 100 × RTH cumulative signed volume / RTH volume, using 1-minute bars from the RTH open through the latest RTH minute; signed volume uses the same OHLCV direction estimate as above. RTH price change = latest RTH minute close − RTH open.
Long: Signed sigma score ≥ the selected sigma threshold.
Long: Delta ratio ≥ 1 AND previous bar's delta ratio < 1 AND both bars have valid delta calculations.
Long: RTH price change ≤ −minimum price increment AND RTH flow percent ≥ the selected positive threshold AND this disagreement was not present on the previous bar or the RTH session has changed.
Short: Signed sigma score ≤ −the selected sigma threshold.
Short: Delta ratio ≤ −1 AND previous bar's delta ratio > −1 AND both bars have valid delta calculations.
Short: RTH price change ≥ minimum price increment AND RTH flow percent ≤ −the selected positive threshold AND this disagreement was not present on the previous bar or the RTH session has changed.
