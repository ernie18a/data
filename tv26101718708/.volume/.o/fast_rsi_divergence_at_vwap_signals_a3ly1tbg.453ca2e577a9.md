Calculation: RSI = standard RSI of close over the selected lookback.
Calculation: Divergence price = high for bearish and low for bullish divergence in wick mode; close for both in close mode.
Calculation: Daily anchored VWAP and deviation bands = from the start of the current calendar day through the current bar, use volume-weighted hl2 for VWAP and the square root of volume-weighted hl2 squared minus VWAP squared for standard deviation; upper/lower bands = VWAP plus/minus their selected standard-deviation multiples. Include the current bar, which may still be forming.
Calculation: Bearish reference = clear when RSI is below the bearish reset level; expire when its age exceeds the maximum divergence lookback; when RSI is above the overbought level and exceeds the stored reference RSI, set reference price to current bearish divergence price, reference RSI to current RSI, and reference bar to the current bar. After a short signal, replace it with the signal bar's values.
Calculation: Bullish reference = clear when RSI is above the bullish reset level; expire when its age exceeds the maximum divergence lookback; when RSI is below the oversold level and is below the stored reference RSI, set reference price to current bullish divergence price, reference RSI to current RSI, and reference bar to the current bar. After a long signal, replace it with the signal bar's values.
Long: bullish reference exists AND current bullish divergence price < bullish reference price AND (bullish reference price / current bullish divergence price - 1) × 100 ≥ minimum price extension AND current RSI - bullish reference RSI ≥ minimum RSI difference AND (RSI turn confirmation disabled OR current RSI ≥ previous bar RSI) AND (candle direction confirmation disabled OR close > open) AND (VWAP filter disabled OR (wick validation and low ≤ lower band) OR (close validation and close ≤ lower band)) AND (close confirmation disabled OR current bar is confirmed) AND no prior long signal exists OR current bar index - last long signal bar > cooldown
Short: bearish reference exists AND current bearish divergence price > bearish reference price AND (current bearish divergence price / bearish reference price - 1) × 100 ≥ minimum price extension AND bearish reference RSI - current RSI ≥ minimum RSI difference AND (RSI turn confirmation disabled OR current RSI ≤ previous bar RSI) AND (candle direction confirmation disabled OR close < open) AND (VWAP filter disabled OR (wick validation and high ≥ upper band) OR (close validation and close ≥ upper band)) AND (close confirmation disabled OR current bar is confirmed) AND no prior short signal exists OR current bar index - last short signal bar > cooldown
