Calculation: Session-row directional balance = the sum of each included analysis candle’s row contribution multiplied by its direction, divided by the sum of row contributions. Allocate each candle’s volume to each intersected price row in proportion to price overlap. Direction is +1 when close > open, −1 when close < open, otherwise +1 or −1 by comparison with the previous analysis candle’s close, or 0 if unchanged or unavailable. A contribution is allocated volume in LTF Volume mode; in W-Weighted mode, multiply allocated volume by (1 − min(1, |close − open| / (high − low))) × (1 + memory strength × decayed row memory). Row memory decays by elapsed time using its half-life, increases by 1 up to its cap on a return visit after at least one sample without a visit when inhibition meets the revisit threshold, and otherwise does not increase. Include positive-volume analysis candles fully contained in each session window. Use the last completed chart bar’s available analysis candles; developing session rows can change until collection ends.
Long: Session-row directional balance > 0.000001
Short: Session-row directional balance < −0.000001
