Calculation: Bar return over a lookback = (current close / close the specified number of chart-timeframe bars earlier − 1) × 100; use the current bar, including while it is forming.
Calculation: Relative strength = (SMA of sector close / SPY close over a lookback / SMA of that ratio over three times the lookback) − 1; use chart-timeframe bars, including the current bar.
Calculation: Chaikin Money Flow = sum over a lookback of (((close − low) − (high − close)) / (high − low)) × volume, divided by summed volume; use zero for the multiplier when high equals low. Use chart-timeframe bars, including the current bar.
Calculation: Volume ratio = current volume / its chart-timeframe SMA over a lookback; use the current bar.
Calculation: Trend = bullish when close > short-period EMA and short-period EMA > long-period EMA; bearish when close < short-period EMA and short-period EMA < long-period EMA; otherwise neutral. The long EMA period is longer than the short EMA period; use the current bar.
Calculation: Price-volume score = +1 when volume ratio > 1.2, (close − low) / (high − low) > 0.60, and close > open; −1 when volume ratio > 1.2, (close − low) / (high − low) < 0.40, and close < open; otherwise 0. Use 0 for the close-location ratio when high equals low. Use the current bar.
Calculation: Composite sector score = sum of: +1 if relative strength > 0.02, +0.5 if > 0.005, −1 if < −0.02, −0.5 if < −0.005, otherwise 0; +1 if Chaikin Money Flow > 0.07, +0.5 if > 0.02, −1 if < −0.07, −0.5 if < −0.02, otherwise 0; +0.5 if volume ratio > 1.5, −0.3 if volume ratio < 0.6, otherwise 0; 0.5 × trend (+1 bullish, −1 bearish, 0 neutral); and 0.5 × price-volume score. Clamp the result to [−3, 3]. Use chart-timeframe bars and current values.
Calculation: Futures divergence = the mean of (ES bar return − SPY bar return) and (NQ bar return − XLK bar return), using the same lookback for all four returns and chart-timeframe bars, including the current bar.
Long: Composite sector score ≥ 0.5 OR trend is bullish OR any of the 1-, 5-, or 20-bar sector returns > 0 OR relative strength > 0 OR Chaikin Money Flow > 0 OR futures divergence > 0
Short: Composite sector score < −0.5 OR trend is bearish OR any of the 1-, 5-, or 20-bar sector returns ≤ 0 OR relative strength ≤ 0 OR Chaikin Money Flow ≤ 0 OR futures divergence ≤ 0
