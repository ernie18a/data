Calculation: Regime center = moving average of the midpoint between the latest confirmed pivot high and pivot low; use the current high or low until each pivot exists. Regime bands = smoothed regime center ± ATR × a configurable multiplier. Bullish/bearish regime = close crosses above/below the corresponding band and remains there for a configurable hold period; initialize from close ≥/< regime center.
Calculation: Regime strength = abs(close − regime center) / ATR; normalized regime position = (close − regime center) / ATR.
Calculation: Pressure signal = EMA of 100 × (close − configurable moving average) / the largest absolute close-to-moving-average distance over a longer lookback.
Calculation: Participation axis = midpoint of the equal-width price bin with the greatest summed volume, using recent closes and volumes over a configurable lookback; axis deviation = (close − participation axis) / ATR.
Calculation: Delta wave = EMA of the EMA-smoothed up-bar volume minus EMA-smoothed down-bar volume, divided by EMA-smoothed volume, multiplied by 100, then EMA-smoothed again. Delta slope = current delta wave − prior bar's delta wave.
Calculation: Recent bullish structure = within a configurable lookback, a bearish bar is followed by a bullish bar whose body is at least a configurable multiple of prior-bar ATR, or a bullish gap occurs (current low > high two bars ago and prior close > that high). Recent bearish structure = the inverse: bullish bar followed by qualifying bearish bar, or bearish gap (current high < low two bars ago and prior close < that low).
Calculation: Higher-timeframe bullish bias = on the last completed higher-timeframe bar, EMA(21) > EMA(55) and close > EMA(55). Bearish bias = EMA(21) < EMA(55) and close < EMA(55). Only use when the selected higher timeframe is at least the chart timeframe.
Calculation: Long confluence score = 2 if bullish regime + 1 if normalized regime position ≥ 0 + 1 if regime strength ≥ a configurable threshold + 1 if pressure signal > 0 + 1 if delta wave > 0 + 1 if delta slope ≥ 0 + 1 if recent bullish structure + 1 if close > participation axis + 1 if axis deviation > 0 + 1 if higher-timeframe filter is disabled, invalid, or bullish bias.
Calculation: Short confluence score = 2 if bearish regime + 1 if normalized regime position ≤ 0 + 1 if regime strength ≥ the same configurable threshold + 1 if pressure signal < 0 + 1 if delta wave < 0 + 1 if delta slope ≤ 0 + 1 if recent bearish structure + 1 if close < participation axis + 1 if axis deviation < 0 + 1 if higher-timeframe filter is disabled, invalid, or bearish bias. Score spread = long score − short score.
Long: confirmed bar AND long score ≥ configurable confluence threshold AND score spread ≥ 2 AND flat or short position AND session filter disabled or within configured session AND cooldown elapsed since last entry; OR bullish regime begins; OR higher-timeframe filter enabled and valid and bullish bias; OR long score ≥ confluence threshold AND score spread ≥ 3.
Short: confirmed bar AND short score ≥ configurable confluence threshold AND score spread ≤ −2 AND flat or long position AND session filter disabled or within configured session AND cooldown elapsed since last entry; OR bearish regime begins; OR higher-timeframe filter enabled and valid and bearish bias; OR short score ≥ confluence threshold AND score spread ≤ −3.
Exit: long, low ≤ long stop OR high ≥ long target OR bearish regime OR score spread ≤ 0 OR pressure signal < 0 OR close < regime center
Exit: short, high ≥ short stop OR low ≤ short target OR bullish regime OR score spread ≥ 0 OR pressure signal > 0 OR close > regime center
Calculation: Long initial stop = the lower of entry-bar close − ATR × configurable stop multiplier and regime center − ATR × 0.25; while long, raise it to the greater of its prior value and close − ATR × configurable trailing multiplier when trailing is enabled. Long target = entry-bar close + ATR × configurable target multiplier.
Calculation: Short initial stop = the higher of entry-bar close + ATR × configurable stop multiplier and regime center + ATR × 0.25; while short, lower it to the lesser of its prior value and close + ATR × configurable trailing multiplier when trailing is enabled. Short target = entry-bar close − ATR × configurable target multiplier.
