Calculation: Block midpoint = (highest high + lowest low within the block) / 2; blocks are equal-sized groups of chart bars in the recent analysis window, using the selected current or last completed bar basis.
Calculation: Block delta = total buying volume minus total selling volume within the block; buying and selling volume use the selected geometric or lower-timeframe intrabar calculation.
Long: block delta > 0 OR the latest trend channel is classified as uptrend
Short: block delta < 0 OR the latest trend channel is classified as downtrend
