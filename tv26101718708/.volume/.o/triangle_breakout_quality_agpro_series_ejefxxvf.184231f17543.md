Calculation: Confirmed pivot high/low = a bar whose high/low is the highest/lowest across equal lookbacks on both sides, available only after the right-side bars complete; retain the latest two of each.
Calculation: Upper/lower boundary = line through the latest two confirmed pivot highs/lows, projected to the current bar; previous boundary = same line projected to the prior bar.
Calculation: Triangle valid = all four pivots exist and each second pivot is later than its first; age from the earliest first pivot is within configured minimum and maximum; starting and current widths (upper minus lower at earliest first pivot and now) are positive; starting width / ATR meets its minimum, current width / ATR is below its maximum, and (starting width − current width) / starting width meets minimum compression; upper slope < lower slope; current upper > lower; projected line intersection is between 5 bars behind and the configured maximum bars ahead.
Calculation: ATR = average true range on the chart timeframe. Triangle compression = (starting width − current width) / starting width × 100; current and starting width in ATR = respective width / ATR; bars to apex = projected intersection bar − current bar.
Calculation: Breakout score = compression score + apex score + impulse score + body score + close-position score + volume score. Compression score = clamp((compression % − minimum compression %) / (80 − minimum compression %), 0, 1) × 22. Apex score = (0.45 × clamp(1 − abs(bars to apex − 18) / maximum forward apex bars, 0, 1) + 0.55 × clamp(1 − current width in ATR / maximum current width in ATR, 0, 1)) × 22. Impulse score = clamp(distance beyond boundary / (1.25 × ATR), 0, 1) × 22. Body score = clamp(abs(close − open) / max(high − low, minimum tick), 0, 1) × 16. Close-position score = bullish: clamp((close − low) / max(high − low, minimum tick), 0, 1) × 8; bearish: clamp((high − close) / max(high − low, minimum tick), 0, 1) × 8. Volume score = if enabled, clamp((volume / volume average − 1) / (full-score volume ratio − 1), 0, 1) × 10; otherwise 7. Round total to nearest integer. Clamp denominators use their configured safeguards.
Calculation: Retest boundary = the broken upper boundary for a long breakout or lower boundary for a short breakout, projected to the current bar; tolerance = ATR × configured retest tolerance.
Long: (valid triangle AND close > current upper boundary + ATR × minimum break distance AND prior close <= prior upper boundary AND rounded breakout score >= minimum label score AND (triangle anchor-index sum differs from the last displayed breakout's sum OR bars since that breakout > cooldown)) OR (active breakout side is long AND breakout age is within the configured retest window AND current high >= retest boundary − tolerance AND current low <= retest boundary + tolerance AND close > retest boundary AND low >= retest boundary − tolerance).
Short: (valid triangle AND close < current lower boundary − ATR × minimum break distance AND prior close >= prior lower boundary AND rounded breakout score >= minimum label score AND (triangle anchor-index sum differs from the last displayed breakout's sum OR bars since that breakout > cooldown)) OR (active breakout side is short AND breakout age is within the configured retest window AND current high >= retest boundary − tolerance AND current low <= retest boundary + tolerance AND close < retest boundary AND high <= retest boundary + tolerance).
Exit: long, active breakout side is long AND breakout age > 0 AND close < retest boundary − tolerance.
Exit: short, active breakout side is short AND breakout age > 0 AND close > retest boundary + tolerance.
