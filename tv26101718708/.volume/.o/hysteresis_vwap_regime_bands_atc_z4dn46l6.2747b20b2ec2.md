Calculation: VWAP price-location zone = Using the current chart bar, calculate VWAP and its 1-standard-deviation width from the selected Session, Week, or Month anchor; the outer bands are VWAP ± 2 times that width. Set the buffer to the absolute 1-standard-deviation width times a configurable percentage. Update the zone to upper extreme if close > upper 2SD + buffer; else upper bias if close > upper 1SD + buffer AND close < upper 2SD - buffer; else neutral if close > lower 1SD + buffer AND close < upper 1SD - buffer; else lower bias if close > lower 2SD + buffer AND close < lower 1SD - buffer; else lower extreme if close < lower 2SD - buffer. If none applies, retain the previous zone.
Long: VWAP price-location zone = upper bias OR upper extreme
Short: VWAP price-location zone = lower bias OR lower extreme
