Calculation: Session VWAP = cumulative volume-weighted average of (high + low + close) / 3, reset at each new day; include the current bar.
Calculation: Session standard deviation = square root of cumulative volume-weighted squared deviations of each bar’s typical price from the current Session VWAP, divided by cumulative volume; include the current bar.
Calculation: Upper and lower 2-standard-deviation bands = Session VWAP + 2 × Session standard deviation, and Session VWAP − 2 × Session standard deviation.
Calculation: Candle body = |close − open|; upper wick = high − max(open, close); lower wick = min(open, close) − low; candle range = high − low.
Long: While flat and after the configured start time, a lower 2-standard-deviation band touch without an upper-band touch arms a long setup; if both bands are touched, arm long when close < Session VWAP. On a later bar within the configured expiry, enter long if close > Session VWAP; (close > open AND current candle body > prior candle body) OR (close > open AND prior close > prior open AND current body + prior body > body two bars earlier); close > prior close; body / candle range > 0.10; |close − Session VWAP| ≥ configured minimum standard-deviation distance × Session standard deviation; and the candle is not an inverted hammer (upper wick / range ≥ configured dominant-wick fraction AND lower wick / range ≤ configured opposite-wick fraction). Cancel the armed setup if, before entry, high ≥ Session VWAP − configured proximity ticks × tick size, or if the expiry is exceeded. Reset setup at each new day.
Short: While flat and after the configured start time, an upper 2-standard-deviation band touch without a lower-band touch arms a short setup; if both bands are touched, arm short when close ≥ Session VWAP. On a later bar within the configured expiry, enter short if close > Session VWAP; (close < open AND current candle body > prior candle body) OR (close < open AND prior close < prior open AND current body + prior body > body two bars earlier); close < prior close; body / candle range > 0.10; |close − Session VWAP| ≥ configured minimum standard-deviation distance × Session standard deviation; and the candle is not a hammer (lower wick / range ≥ configured dominant-wick fraction AND upper wick / range ≤ configured opposite-wick fraction). Cancel the armed setup if, before entry, low ≤ Session VWAP + configured proximity ticks × tick size, or if the expiry is exceeded. Reset setup at each new day.
Exit: Long, low ≤ entry-bar lowest low over the configured stop lookback minus configured stop-buffer ticks × tick size, OR high ≥ Session VWAP − configured proximity ticks × tick size.
Exit: Short, high ≥ entry-bar highest high over the configured stop lookback plus configured stop-buffer ticks × tick size, OR low ≤ Session VWAP + configured proximity ticks × tick size.
