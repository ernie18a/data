Calculation: Fast EMA and slow EMA = EMAs of close using a shorter lookback for the fast EMA than the slow EMA.
Calculation: Eclipse proximity = ATR > 0 and the maximum, over the proximity window ending on the current bar, of |fast EMA − slow EMA| divided by ATR is at most the maximum spread threshold.
Calculation: Eclipse Score = round(min(100, proximity score + volume score + RSI score + cross score)), where proximity score is 0 when proximity is false, otherwise min((maximum spread threshold − maximum spread / ATR) × 150 + 20, 35); volume score is 0 when average volume is not positive, otherwise min(max((volume / average volume − 1) × 45, 0), 25); RSI score is min((RSI − 50) × 2, 25) for a bullish base eclipse, min((50 − RSI) × 2, 25) for a bearish base eclipse, and 0 otherwise; cross score is 20 for either base eclipse and 0 otherwise. A bullish base eclipse is a fast EMA cross above the slow EMA with proximity, volume confirmation, and RSI above the bullish floor; a bearish base eclipse is a fast EMA cross below the slow EMA with proximity, volume confirmation, and RSI below the bearish ceiling.
