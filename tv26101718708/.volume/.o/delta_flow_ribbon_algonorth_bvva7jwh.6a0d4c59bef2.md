Calculation: Estimated delta = sum the volumes of lower-timeframe bars within the current chart bar, assigning each bar's volume the sign of its close change from the prior lower-timeframe close; unchanged closes retain the prior sign. If lower-timeframe data is unavailable, use volume × ((close − low) − (high − close)) / (high − low), or zero when high = low. Use available lower-timeframe bars in the current chart bar, including a forming bar on live data.
Calculation: Normal upside flow and normal downside flow = averages of positive and negative estimated delta, respectively, for the same time slot over prior completed sessions; use rolling averages over recent completed chart bars when time-slot history is unavailable.
Calculation: Quiet-volume weight = min(1, current volume / (normal volume × quiet-volume threshold)).
Calculation: Normalized upside flow and normalized downside flow = each side's current flow divided by its corresponding normal flow, capped at the configured maximum, then move each value toward 1 in proportion to the quiet-volume weight.
Calculation: Net flow = EMA(estimated delta, short lookback) / (normal upside flow + normal downside flow) × quiet-volume weight.
Calculation: Price response = EMA(close − prior close, same short lookback) × sign(net flow) / normal close-to-close travel / abs(net flow)^flow-to-movement exponent.
Calculation: Upside core and downside core = repeated EMAs of normalized upside flow and normalized downside flow, respectively, using the same short smoothing length and number of passes.
Long: upside core crosses above downside core OR net flow > 0 AND abs(net flow) ≥ surge threshold AND price response > absorption response threshold OR net flow > 0 AND abs(net flow) ≥ absorption flow threshold AND price response ≤ absorption response threshold
Short: upside core crosses below downside core OR net flow < 0 AND abs(net flow) ≥ surge threshold AND price response > absorption response threshold OR net flow < 0 AND abs(net flow) ≥ absorption flow threshold AND price response ≤ absorption response threshold
