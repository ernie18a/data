Calculation: Direction score = 90 if close > shorter-period SMA > longer-period SMA, shorter SMA is rising, and close is in the top 10% of the bar range; otherwise 75 if close > both SMAs, 55 if close > shorter SMA > longer SMA, 40 if close < shorter SMA while shorter SMA > longer SMA, 15 if close < both SMAs, shorter SMA is falling, and close is in the bottom 10% of the range, 25 if close < both SMAs, otherwise 50.
Calculation: Momentum score = 90 if RSI ≥ 65, RSI is rising, and close is more than 1% above prior close; otherwise 75 if 55 ≤ RSI < 65 and RSI is rising, 55 if 45 ≤ RSI ≤ 55 and absolute close change is < 0.5%, 35 if 35 ≤ RSI < 45 and RSI is falling, 20 if 20 ≤ RSI < 35, RSI is falling, and close is more than 1% below prior close, 5 if RSI < 20 or RSI > 80, otherwise 50.
Calculation: Accumulation score = 90 if absolute close change is < 0.5% for three consecutive bars and Bollinger Band width is below 0.2 times its rolling 90th percentile; otherwise 75 if that change is < 0.5% for two consecutive bars and width is below 0.4 times that percentile, 55 if change ≤ 1% and width is 0.4–0.7 times that percentile, 35 if change > 1.5% and width > 0.8 times that percentile, 15 if change > 3% and width > 0.9 times that percentile, 5 if change > 5%, otherwise 50.
Calculation: Flow score = 90 if CMF > 0.10 and MFI > 60; otherwise 75 if CMF > 0.05 and MFI ≥ 50, 55 if −0.03 ≤ CMF ≤ 0.05 and 40 ≤ MFI < 50, 35 if −0.10 ≤ CMF < −0.03, 20 if CMF < −0.10 and MFI < 30, 5 if CMF < −0.20 and MFI < 20, otherwise 50. CMF is the rolling sum of close-location-value times volume divided by rolling volume.
Calculation: C1 score = the mean of Direction score, Momentum score, Accumulation score, and Flow score.
Long: C1 score ≥ 60
Short: C1 score < 40
