Calculation: C1 score = mean(Direction, Momentum, Velocity, Behavior)
Calculation: Direction = 90 if close > shorter EMA > longer EMA, shorter EMA rising, and close is in the top 10% of the bar range; else 75 if close > shorter EMA > longer EMA; else 55 if close > shorter EMA and shorter EMA < longer EMA; else 40 if close < shorter EMA and shorter EMA > longer EMA; else 15 if close < shorter EMA < longer EMA, shorter EMA falling, and close is in the bottom 10% of the bar range; else 25 if close < shorter EMA < longer EMA; otherwise 50
Calculation: Momentum = 90 if RSI >= 65, rising, and close > prior high; else 75 if 55 <= RSI < 65 and rising; else 55 if 45 <= RSI <= 55 and absolute close change < 0.3%; else 35 if 35 <= RSI < 45 and falling; else 20 if 20 <= RSI < 35, falling, and close < prior low; else 5 if RSI < 20 or RSI > 80; otherwise 50
Calculation: Velocity = 90 if absolute one-bar percent close change > 2.5 × mean absolute percent close change over the velocity lookback and volume / volume moving average > 2; else 75 if change > 1.8 × that mean and volume ratio > 1.5; else 55 if change is between 0.6 and 1.5 × that mean; else 35 if change is between 0.3 and 0.6 × that mean; else 15 if change < 0.3 × that mean and volume ratio < 0.8; else 5 if change < 0.05%; otherwise 50
Calculation: Behavior = 90 if body / range > 0.8 and total wick length < 0.25 × body; else 75 if body / range > 0.7 and total wick length < 0.5 × body; else 55 if body / range is 0.5–0.7; else 35 if 0.3 <= body / range < 0.5; else 15 if 0.15 <= body / range < 0.3; else 5 if body / range < 0.15 and total wick length > 3 × body; otherwise 50
Calculation: C2 score = mean(Battle, Hunting, Squeeze, Destruction)
Calculation: Battle = 90 for alternating candle directions across the current and prior two bars; else 75 if current and prior candle directions alternate; else 55 if not three consecutive bullish candles; else 30 if three but not five consecutive bullish candles; else 5 if five consecutive bullish candles
Calculation: Hunting = 90 if price sweeps above the prior key-lookback high and closes at/below it, or sweeps below the prior key-lookback low and closes at/above it, with volume > 1.3 × volume moving average; else 55 if high is within 2% below the prior key-lookback high or low is within 2% above the prior key-lookback low; else 10 if close breaks either prior key-lookback boundary on volume > 1.5 × volume moving average; else 25 if close breaks either boundary; otherwise 40
Calculation: Squeeze = 90 if Bollinger width < 0.1 × its 90th percentile over 20 bars and ATR / ATR moving average < 0.7; else 75 if width < 0.25 × that percentile and ATR ratio < 0.8; else 55 if width < 0.5 × that percentile and ATR ratio < 0.9; else 40 if width is 0.5–0.8 × that percentile; else 25 if width is 0.8–1.2 × that percentile; else 10 if width >= 1.2 × that percentile; otherwise 50
Calculation: Destruction = 90 if close breaks the prior key-lookback high/low, current body > 1.8 × mean body of the prior 10 bars, and volume > 1.3 × volume moving average; else 75 if it breaks that boundary and body > 1.3 × that mean; else 55 if close is above 98% of the prior high or below 102% of the prior low; else 10 if a boundary is swept but close stays inside and current candle direction opposes the prior candle; else 25 if a boundary is swept but close stays inside; otherwise 40
Calculation: C3 score = mean(Absorption, Expansion, Impact, Decay)
Calculation: Absorption = 90 if current range / mean range <not used> and absolute percent close change < 0.15% and volume ratio > 1.5; else 75 if range ratio > 1 and change < 0.2% and volume ratio > 1.2; else 55 if range ratio > 0.8 and change < 0.3% and volume ratio > 1; else 25 if change > 0.5% and volume ratio > 1.3; else 10 if change > 1% and volume ratio > 1.5; otherwise 40
Calculation: Expansion = 90 if range ratio > 1.8 × the 90th percentile of range over 20 bars and volume ratio > 1.5; else 75 if range ratio > 1.4 × that percentile and volume ratio > 1.2; else 55 if range ratio > 1.1 × that percentile and volume ratio > 1; else 40 if range ratio is 0.7–1.1 × that percentile; else 20 if range ratio < 0.5 × that percentile; else 5 if range ratio < 0.3 × that percentile; otherwise 50
Calculation: Impact = 90 if absolute percent close change > 3 × mean absolute percent close change over prior 10 bars, volume ratio > 1.8, and close breaks the prior key-lookback high/low; else 75 if change > 2 × that mean and volume ratio > 1.3; else 55 if change > 1.5 × that mean and volume ratio > 1; else 20 if change < 0.5 × that mean and volume ratio < 0.8; else 5 if change < 0.3 × that mean and volume ratio < 0.6; otherwise 40
Calculation: Decay = 90 if absolute percent close changes and volume ratios each decline over the current and prior two bars; else 75 if changes decline; else 55 if current change < prior change and prior change > the change two bars ago; else 40 if changes are neither strictly declining nor strictly rising; else 20 if changes rise but volume ratios do not; else 5 if changes and volume ratios both rise; otherwise 50
Calculation: Total score = mean(C1 score, C2 score, C3 score)
Long: Total score >= 60
Short: Total score < 40
