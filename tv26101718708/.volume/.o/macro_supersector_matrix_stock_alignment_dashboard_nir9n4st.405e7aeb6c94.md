Calculation: Supersector change = average percentage change from the previous completed daily close to the current, still-forming daily close of the supersector’s constituents
Calculation: Macro bias = 25 points for each supersector with positive change, weighted 25 if any constituent’s daily volume exceeds its daily volume SMA and 12.5 otherwise; plus 25 points if the broad-market ETF’s change is positive
Calculation: Charted asset change = percentage change from the previous chart bar’s close to the current bar’s close
Long: Any supersector change > 0 OR broad-market ETF change > 0 OR charted asset change > 0 OR macro bias > 50
Short: Any supersector change <= 0 OR broad-market ETF change <= 0 OR charted asset change <= 0 OR macro bias <= 50
