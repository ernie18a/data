Calculation: Qualifying gap event = first regular-session bar with valid OHLC and positive volume, a complete prior chart-bar baseline, and absolute(open − last regular-session close) ≥ minimum gap threshold × ATR from prior completed chart bars; freeze that prior ATR, prior median volume, gap direction, opening gap, and regular-session close as the event reference
Calculation: Gap position = clip(2 × gap-direction × (close − event reference close) / absolute opening gap − 1, −1, 1)
Calculation: Recent flow = (sum of gap-direction-adjusted close changes over the latest event-path lookback, including the current completed event bar ÷ sum of their absolute values) × min(square root of mean capped relative volume, 1); each relative volume is current bar volume ÷ frozen prior median volume, capped at 4
Calculation: Mean capped relative volume = mean of capped relative volumes over the same latest event-path lookback
Calculation: Confirmed continuation state = continuation candidate condition holds for the confirmation count of consecutive completed event bars and state changes from a different state; candidate condition is (mean capped relative volume ≥ minimum participation AND gap position ≥ 0.20 AND recent flow ≥ flow-entry threshold) when not already in continuation, or (gap position ≥ 0 AND recent flow ≥ flow-entry threshold × release fraction AND mean capped relative volume ≥ 0.75 × minimum participation) when already in continuation
Calculation: Confirmed repair state = repair candidate condition holds for the confirmation count of consecutive completed event bars and state changes from a different state; candidate condition is (mean capped relative volume ≥ minimum participation AND close fill ≥ 0.20 AND recent flow ≤ −flow-entry threshold) when not already in repair, or (close fill ≥ 0.10 AND recent flow ≤ −flow-entry threshold × release fraction AND mean capped relative volume ≥ 0.75 × minimum participation) when already in repair; close fill = clip(1 − gap-direction × (close − event reference close) / absolute opening gap, 0, 1)
Long: qualifying gap event AND ((gap direction = up AND confirmed continuation state) OR (gap direction = down AND confirmed repair state))
Short: qualifying gap event AND ((gap direction = down AND confirmed continuation state) OR (gap direction = up AND confirmed repair state))
Exit: long or short, active qualifying gap event AND (low ≤ event reference close when gap direction is up OR high ≥ event reference close when gap direction is down)
