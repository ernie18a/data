Calculation: Market Memory Average = EMA of the current close multiplied by (1 + the similarity-weighted mean of the top historical 5-bar close percentage changes / 100). For each candidate historical bar, compare its 1-, 3-, and 5-bar close percentage changes, RSI, ATR as a percentage of close, and volume divided by its moving average with the current bar’s same features. Weight absolute feature differences by 1/2, 1/4, 1/6, 2, 1/2, and 1/1.5 respectively, sum them as distance, then calculate similarity as 100 × exp(−distance × sensitivity). Use the highest-similarity candidates from the scan, excluding the most recent pattern-length bars; average their 5-bar close percentage changes weighted by similarity. The EMA smoothing length and slope lookback are separate parameters.
Long: close > Market Memory Average AND previous close <= previous Market Memory Average OR Market Memory Average > its value at the slope lookback bars ago
Short: close < Market Memory Average AND previous close >= previous Market Memory Average OR Market Memory Average < its value at the slope lookback bars ago
