Calculation: Adaptive arc = EMA of the weighted blend of fast and slow source EMAs, where weight is clamp(0.38 + clamp(abs(EMA(source change, 4)) / ATR, 0, 2.5) * 0.18 + clamp((EMA(ATR, 5) / EMA(ATR, 55) - 1) * volatility boost, 0, 1.3) * 0.22, 0.25, 0.82); smooth the blend with EMA length 3. Fast EMA length is shorter than slow EMA length.
Calculation: Trail bands = adaptive arc ± ATR times clamp(base width * (1 - volatility speed * 0.22), base width * 0.55, base width * 1.25), adjusted by EMA(adaptive arc change, 3): add max(arc slope, 0) * (2 + volatility speed) to the lower band and add min(arc slope, 0) * (2 + volatility speed) to the upper band. ATR uses the current chart bars.
Calculation: Arc trail and regime = initially set regime bullish when close ≥ adaptive arc, otherwise bearish, and set trail to the corresponding lower or upper band. Thereafter, flip bearish from bullish only when close < prior trail, close ≤ VWAP, and adaptive arc ≤ its prior value; flip bullish from bearish only when close > prior trail, close ≥ VWAP, and adaptive arc ≥ its prior value. On a flip, set trail to the new side's band; otherwise, while bullish set trail to max(lower band, prior trail), and while bearish set trail to min(upper band, prior trail).
Long: Prior regime bearish AND close > prior arc trail AND close ≥ current session VWAP AND adaptive arc ≥ its prior value AND bar is confirmed
Short: Prior regime bullish AND close < prior arc trail AND close ≤ current session VWAP AND adaptive arc ≤ its prior value AND bar is confirmed
