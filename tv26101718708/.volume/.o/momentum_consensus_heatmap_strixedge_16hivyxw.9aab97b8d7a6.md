Long: At least the configured minimum number of the six indicators each have values at or below their respective oversold thresholds on at least the configured minimum number of the four selected timeframes, AND (if the EMA trend filter is enabled) close > EMA, AND the full long condition was false on the preceding bar. Use each timeframe’s bars; higher-timeframe values use the last completed bar, while values on the chart timeframe may use the forming bar.
Short: At least the configured minimum number of the six indicators each have values at or above their respective overbought thresholds on at least the configured minimum number of the four selected timeframes, AND (if the EMA trend filter is enabled) close < EMA, AND the full short condition was false on the preceding bar. Use each timeframe’s bars; higher-timeframe values use the last completed bar, while values on the chart timeframe may use the forming bar.
