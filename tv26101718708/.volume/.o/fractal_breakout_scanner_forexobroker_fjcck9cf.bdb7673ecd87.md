Calculation: Tracked resistance/support levels = Confirmed pivot highs/lows, respectively, using configured left- and right-bar lookbacks; add each pivot price unless a same-type tracked level is within 0.3 × ATR(14), in which case retain the existing price. Keep at most the configured maximum number of levels of each type, removing the oldest level first.
Long: Bar is confirmed AND current volume > its configured-length SMA AND bars since last breakout ≥ configured cooldown AND tracked resistance level exists AND close > resistance level + configured tick buffer AND prior close ≤ that same level + configured tick buffer
Short: Bar is confirmed AND current volume > its configured-length SMA AND bars since last breakout ≥ configured cooldown AND tracked support level exists AND close < support level − configured tick buffer AND prior close ≥ that same level − configured tick buffer
