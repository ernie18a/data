Calculation: Bull score = 100 × min(1, bull raw points ÷ active maximum), where active maximum = 70 + 15 if average volume is available + 10 if multi-timeframe analysis is enabled + 5 if relative strength is available. Bull raw points are: trend (3 if close > EMA 21, 4 if EMA 9 > EMA 21, 4 if EMA 21 > EMA 50, 4 if EMA 50 > EMA 200, 3 if both EMA 9 and EMA 21 rose over the slope lookback, 2 if EMA 9 crossed above EMA 21 within the fresh-cross window); RSI (6 if RSI ≥ its bullish threshold, 4 if RSI rose over its slope lookback); MACD (4 if MACD line > signal line, 3 if histogram > 0, 3 if histogram rose from the prior bar); DMI/ADX (4 if +DI > −DI, plus 3 if that holds and ADX ≥ its minimum, plus 3 if that holds and ADX rose from the prior bar); bullish volume (0 unless close > open and close > prior close, then 15/12/8/3 points when relative volume is respectively ≥ strong/run/elevated thresholds, ≥ run/elevated thresholds, ≥ elevated threshold, or below it); structure (15 if close > prior-bar N-bar highest high + ATR buffer, else 12 if close > that high, else 9/6/3 if distance below that high is ≤ 0.25/0.50/1.00 ATR, else 0); volatility (5 if a squeeze occurred within the recent-squeeze window, Bollinger width is expanding, and close > basis; else 3 if currently squeezed; else 2 if expanding and close > basis; else 0); multi-timeframe (10 × bullish states among short-, main-, and long-term timeframes ÷ 3, or 0 if disabled); relative strength (0 if unavailable, otherwise 3 if ratio > its EMA plus 2 if ratio rose over its slope lookback). Use the current chart bar and its prior bars for these calculations; for the multi-timeframe states use the latest available bars, including a still-forming higher-timeframe bar.
Calculation: Bear score = 100 × min(1, bear raw points ÷ the same active maximum). Bear raw points mirror the bull score: trend points are 3 if close < EMA 21, 4 if EMA 9 < EMA 21, 4 if EMA 21 < EMA 50, 4 if EMA 50 < EMA 200, 3 if both EMA 9 and EMA 21 fell over the slope lookback, and 2 if EMA 9 crossed below EMA 21 within the fresh-cross window; RSI points are 6 if RSI ≤ its bearish threshold and 4 if RSI fell over its slope lookback; MACD points are 4 if MACD line < signal line, 3 if histogram < 0, and 3 if histogram fell from the prior bar; DMI/ADX points are 4 if −DI > +DI, plus 3 if that holds and ADX ≥ its minimum, plus 3 if that holds and ADX rose from the prior bar; bearish volume uses close < open and close < prior close with the same relative-volume tiers; structure uses close below the prior-bar N-bar lowest low, with the same ATR buffer and distance tiers; volatility mirrors the bull rule with close < Bollinger basis; multi-timeframe points count bearish states; relative-strength points are 3 if ratio < its EMA plus 2 if ratio fell over its slope lookback. Relative strength ratio = instrument close ÷ benchmark close on the chart timeframe; use the latest available benchmark bar, including a still-forming bar.
Calculation: Bullish higher-timeframe state = close > EMA 21 AND EMA 9 > EMA 21 AND RSI > 50; bearish state = close < EMA 21 AND EMA 9 < EMA 21 AND RSI < 50; otherwise neutral. Calculate each on the short-, main-, and long-term timeframes from their latest available bars, including a still-forming bar.
Calculation: Bullish breakout = close > prior-bar N-bar highest high + ATR × breakout buffer; bearish breakout = close < prior-bar N-bar lowest low − ATR × breakout buffer. Raw breakout uses the same comparisons without the ATR buffer.
Calculation: Bullish RSI divergence = a confirmed pivot low has a lower price low and a higher RSI than the preceding confirmed pivot low; bearish RSI divergence = a confirmed pivot high has a higher price high and a lower RSI than the preceding confirmed pivot high. Confirm pivots using the configured bars on both sides; signal on confirmation and mark the pivot bar.
Calculation: Bull retest = within the configured bars after a bullish breakout, low ≤ breakout level + ATR × tolerance and close ≥ breakout level; bearish retest = within the configured bars after a bearish breakout, high ≥ breakdown level − ATR × tolerance and close ≤ breakdown level. A held retest additionally requires close > open for bull or close < open for bear.
Long: bull score crosses upward through the early threshold OR crosses upward through the setup threshold OR bullish run condition becomes true OR bullish strong condition becomes true OR bullish state increases to at least the early state and the signal is ready and cooldown has elapsed OR bullish overall status (breakout status requires bull score > bear score; setup/early status requires bull score > bear score + 5) OR a bullish RSI divergence is confirmed OR a bullish held-retest signal occurs. Bullish run condition = bull score ≥ run threshold AND bullish breakout AND relative volume ≥ run-volume threshold AND close > open AND close > prior close. Bullish strong condition = bull score ≥ strong threshold AND bullish breakout AND relative volume ≥ strong-volume threshold AND +DI > −DI AND ADX ≥ strong-trend threshold. State signal readiness requires a confirmed bar when close-only confirmation is enabled; cooldown is measured from the preceding same-side state signal.
Short: bear score crosses upward through the early threshold OR crosses upward through the setup threshold OR bearish run condition becomes true OR bearish strong condition becomes true OR bearish state increases to at least the early state and the signal is ready and cooldown has elapsed OR bearish overall status (breakdown status requires bear score > bull score; warning/early status requires bear score > bull score + 5) OR a bearish RSI divergence is confirmed OR a bearish held-retest signal occurs. Bearish run condition = bear score ≥ run threshold AND bearish breakout AND relative volume ≥ run-volume threshold AND close < open AND close < prior close. Bearish strong condition = bear score ≥ strong threshold AND bearish breakout AND relative volume ≥ strong-volume threshold AND −DI > +DI AND ADX ≥ strong-trend threshold. State signal readiness and cooldown follow the long-side rules.
