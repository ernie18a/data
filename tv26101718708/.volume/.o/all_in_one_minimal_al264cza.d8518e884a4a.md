Short: RSI on each selected timeframe (using that timeframe’s current bar, including the still-forming bar in real time) >= 70 OR close <= each of the four EMAs (from shortest to longest lookback) OR (%K > %D AND %K > 80) OR (%K <= %D AND %K >= 20) OR MACD line <= signal line OR DI+ <= DI− OR (MFI >= 80 OR (MFI > 20 AND MFI <= 50)) OR close <= VWAP OR OBV <= its EMA OR indicator score <= -2
Calculation: Indicator score = sum of 3 RSI votes, 4 EMA votes, and one vote each for stochastic, MACD, ADX, MFI, VWAP, and OBV; each RSI vote is -1 if RSI >= 70, +1 if RSI <= 30, +1 if RSI > 50, otherwise -1; each EMA vote is +1 if close > EMA, otherwise -1; remaining votes are +1 respectively if %K > %D, MACD line > signal line, DI+ > DI−, MFI > 50, close > VWAP, and OBV > its EMA, otherwise -1
