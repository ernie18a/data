Calculation: Reference high = high of the bar at the configured reference time for the current day
Calculation: Reference low = low of the bar at the configured reference time for the current day
Long: During the active window after the reference bar and before the configured end time, close > reference high AND no long signal has been generated since the reference bar or most recent short signal
Long: During the active window, the last signal was long AND close < reference low
Short: During the active window after the reference bar and before the configured end time, close < reference low AND no short signal has been generated since the reference bar or most recent long signal
Short: During the active window, the last signal was short AND close > reference high
