Calculation: Previous positive peak = highest volume oscillator value in the most recently completed above-zero run
Calculation: Previous negative trough = lowest volume oscillator value in the most recently completed below-zero run

Short: Volume oscillator crosses zero in either direction AND previous positive peak > absolute value of previous negative trough
