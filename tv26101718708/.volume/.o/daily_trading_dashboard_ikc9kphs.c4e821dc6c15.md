Calculation: Daily ΔqADR% = 100 × (current daily close − current daily open) / [(SMA over the lookback of (daily high / daily low − 1) × 100) × current daily close / 100]; use the daily bar still forming.
Long: Daily chart AND Daily ΔqADR% > 0 OR Daily ΔqADR% ≥ 100
Short: Daily chart AND Daily ΔqADR% ≤ 0 OR Daily ΔqADR% ≤ −100
