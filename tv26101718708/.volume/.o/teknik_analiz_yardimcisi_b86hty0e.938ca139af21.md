Calculation: EMA set = four EMAs with progressively longer lookbacks
Calculation: Supertrend direction = ATR-based bands around hl2; upper band trails at max(current hl2 − multiplier × ATR, prior upper band) when prior close > prior upper band, otherwise current hl2 − multiplier × ATR; lower band trails at min(current hl2 + multiplier × ATR, prior lower band) when prior close < prior lower band, otherwise current hl2 + multiplier × ATR. Start direction up; switch down when close < upper band, switch up when close > lower band, otherwise retain prior direction.
Calculation: OBV MACD direction = OBV is cumulative sign(change(close)) × volume; form an OBV-based price as high + shadow when shadow > 0, otherwise low + shadow, where shadow = (OBV − SMA(OBV, shorter lookback)) / stdev(OBV − SMA(OBV, shorter lookback), longer lookback) × stdev(high − low, same longer lookback), or zero if the denominator is zero. Fast line = double EMA of that price with the same shorter lookback; slow line = EMA(close, longer lookback); MACD = fast − slow. Smooth MACD by retaining its prior value unless the current MACD differs from it by more than the cumulative mean absolute MACD-to-prior-smoothed difference. Direction is up when the smoothed value rises, down when it falls, otherwise retain prior direction; initialize direction neutral.
Calculation: Net signal balance = count of bullish signals minus bearish signals among the four EMAs, RSI, Bollinger Bands, session VWAP, Supertrend direction, and OBV MACD direction; neutral RSI and Bollinger signals count as neither.
Long: close > each EMA in the set OR RSI <= oversold threshold OR close <= lower Bollinger Band OR close > session VWAP OR Supertrend direction is up OR Supertrend changes from down to up OR OBV MACD direction is up OR net signal balance >= 1
Short: close <= each EMA in the set OR RSI >= overbought threshold OR close >= upper Bollinger Band OR close <= session VWAP OR Supertrend direction is down OR Supertrend changes from up to down OR OBV MACD direction is down OR net signal balance <= -1
