Calculation: Direction memory = an exponentially weighted average, seeded at zero and updated on each valid completed bar with weight α = 1 − 0.5^(1/half-life), of [sqrt(min(current volume / prior median volume, volume saturation) / volume saturation) × (0.65 × (close − open) + 0.35 × (2 × close − high − low)) / max(current true range, prior mean true range)]; prior mean true range and prior median volume use the same lookback of completed bars, excluding the current bar.
Calculation: Rejection memory = the same exponentially weighted average and volume weight as direction memory, applied to [(lower wick − upper wick) / max(current true range, prior mean true range)]; lower wick = min(open, close) − low; upper wick = high − max(open, close).
Calculation: Candidate phase = balance if both absolute memories are at most the release threshold; otherwise upward/downward rejection if absolute rejection memory is at least the entry threshold and at least the rejection dominance ratio times absolute direction memory, with direction given by the rejection memory's sign; otherwise upward/downward accumulation if absolute direction memory is at least the entry threshold and (direction memory + rejection memory) × sign(direction memory) > 0, with direction given by the direction memory's sign; otherwise hold the prior rejection phase if rejection memory × its sign is at least the release threshold and (direction memory + rejection memory) × its sign > 0; otherwise hold the prior accumulation phase if direction memory × its sign is at least the release threshold, (direction memory + rejection memory) × its sign > 0, and absolute rejection memory is less than the rejection dominance ratio times absolute direction memory; otherwise mixed pressure. The release threshold is below the entry threshold.
Calculation: Confirmed phase = candidate phase after it remains unchanged for the configured number of consecutive valid completed bars, once the memories have accumulated the configured number of valid samples; invalid samples reset memories, phase, pending candidates, and last accumulation. Track the last confirmed accumulation direction; clear it on balance or a rejection phase that opposes it.
Long: Confirmed phase changes to upward accumulation OR confirmed phase changes to upward rejection while the last accumulation direction is downward.
Short: Confirmed phase changes to downward accumulation OR confirmed phase changes to downward rejection while the last accumulation direction is upward.
Exit: long or short, confirmed phase changes to balance.
