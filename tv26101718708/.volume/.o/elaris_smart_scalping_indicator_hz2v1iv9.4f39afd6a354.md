Calculation: Bull trend = (aggressive mode AND close > fast EMA) OR (balanced mode AND fast EMA > slow EMA AND close > fast EMA) OR (strict mode AND fast EMA > slow EMA AND close > fast EMA AND fast EMA > its previous-bar value AND slow EMA > its previous-bar value); fast EMA uses a shorter lookback than slow EMA
Calculation: Bear trend = (aggressive mode AND close < fast EMA) OR (balanced mode AND fast EMA < slow EMA AND close < fast EMA) OR (strict mode AND fast EMA < slow EMA AND close < fast EMA AND fast EMA < its previous-bar value AND slow EMA < its previous-bar value); fast EMA uses a shorter lookback than slow EMA
Calculation: Long score = 25 if bull trend + 20 if RSI > bullish RSI threshold + 20 if MACD histogram > 0 + 15 if volume filter passes + 10 if ATR filter passes + 10 if higher-timeframe filter passes; otherwise each term is 0
Calculation: Short score = 25 if bear trend + 20 if RSI < bearish RSI threshold + 20 if MACD histogram < 0 + 15 if volume filter passes + 10 if ATR filter passes + 10 if higher-timeframe filter passes; otherwise each term is 0
Long: current bar is closed AND current long raw condition is true AND previous bar's long raw condition was false, where long raw condition = bull trend AND RSI > bullish RSI threshold AND MACD histogram > 0 AND (volume filter disabled OR volume > volume SMA × strength multiplier) AND (ATR filter disabled OR ATR / close × 100 >= minimum ATR percentage) AND (higher-timeframe filter disabled OR last completed higher-timeframe close > its EMA) AND (session filter disabled OR bar is within configured session) AND long score >= minimum score
Short: current bar is closed AND current short raw condition is true AND previous bar's short raw condition was false, where short raw condition = bear trend AND RSI < bearish RSI threshold AND MACD histogram < 0 AND (volume filter disabled OR volume > volume SMA × strength multiplier) AND (ATR filter disabled OR ATR / close × 100 >= minimum ATR percentage) AND (higher-timeframe filter disabled OR last completed higher-timeframe close < its EMA) AND (session filter disabled OR bar is within configured session) AND short score >= minimum score
