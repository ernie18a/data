Calculation: Stripe delta = For each chart bar in the lookback, take each lower-timeframe candle’s direction as +1 if close > open, −1 if close < open, otherwise +1/−1 if close is above/below its previous close, otherwise 0; multiply by volume, using 1 when volume is zero or unavailable. Distribute that value equally among the price stripes crossed by the candle. For each stripe, accumulate from the oldest chart bar to the newest, multiplying the prior total by an exponential decay based on the persistence parameter before adding the current bar’s value. Use lower-timeframe candles inside each chart bar, including the still-forming chart bar and its available lower-timeframe data; if none are available, use the chart bar.
Calculation: Stripe strength = clamp(0.70 × abs(stripe delta) / the greatest absolute stripe delta in that chart-bar column + 0.30 × abs(stripe delta) / accumulated stripe volume, 0, 1). Accumulated stripe volume uses the same distribution and decay as stripe delta, with absolute candle volume (or 1 when zero or unavailable).
Long: Stripe delta > 0 AND accumulated stripe volume > 0 AND stripe strength >= minimum stripe strength AND the stripe’s price level has not been crossed by any chart bar in the lookback.
Short: Stripe delta < 0 AND accumulated stripe volume > 0 AND stripe strength >= minimum stripe strength AND the stripe’s price level has not been crossed by any chart bar in the lookback.
