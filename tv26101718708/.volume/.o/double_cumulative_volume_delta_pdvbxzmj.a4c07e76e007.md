Calculation: Shorter-anchor CVD = cumulative up-volume minus down-volume from lower-timeframe bars, reset each shorter anchor period; uses bars within the current chart bar, including the still-forming bar, and the current anchor period, including while it is forming.
Calculation: Longer-anchor CVD = the same calculation as shorter-anchor CVD, with a longer anchor period.
Long: shorter-anchor CVD close >= shorter-anchor CVD open OR longer-anchor CVD close >= longer-anchor CVD open
Short: shorter-anchor CVD close < shorter-anchor CVD open OR longer-anchor CVD close < longer-anchor CVD open
