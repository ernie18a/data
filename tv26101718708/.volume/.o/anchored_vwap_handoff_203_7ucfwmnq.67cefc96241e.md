Calculation: Anchored VWAP = cumulative selected source × volume divided by cumulative volume from the selected start date, using bars at or after that date
Calculation: Cascading VWAP = cumulative selected source × volume divided by cumulative volume since the latest cross of the selected source and the preceding VWAP; the first cascading VWAP uses the anchored VWAP, and each later one uses the previous cascading VWAP
Long: selected source > any configured VWAP leg
Short: selected source < any configured VWAP leg
