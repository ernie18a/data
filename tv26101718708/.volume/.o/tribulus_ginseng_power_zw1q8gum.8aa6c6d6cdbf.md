Calculation: A local swing event occurs when a confirmed close crosses above the latest confirmed swing high or below the latest confirmed swing low; a local trendline event occurs when close breaks above a descending pivot-high line or below an ascending pivot-low line. A paired swing event occurs when the two events of the same direction occur in either order within the configured pairing window.
Calculation: A local kernel lower-band event occurs when close crosses below a Gaussian-weighted close average minus its average absolute deviation times a multiplier; the upper-band event is the corresponding cross above the average plus the deviation. A local trailing-stop direction changes bullish when close crosses above the prior trailing stop and bearish when it crosses below; the kernel event direction is retained until the next kernel event.
Calculation: A local reversal event is a kernel lower-band event while trailing-stop direction is bullish, or a bullish trailing-stop change while the retained kernel event is bullish; require an optional recent liquidity sweep in the matching direction and the optional ADX threshold. A liquidity sweep is a low below the prior lookback lows followed by a close above those lows, or a high above the prior lookback highs followed by a close below those highs.
Calculation: A local shock reversal event is generated by the local reversal events and the shock phase: a shock is a volume threshold breach; after a shock, the first reversal event sets phase one, the next sets phase two, and the next returns to phase zero. In phase one, a bearish reversal event generates a bullish shock event and a bullish reversal event generates a bearish shock event; in phase two, the mapping is normal (bullish reversal to bullish shock event and bearish reversal to bearish shock event).
Calculation: A local combined event occurs when a local shock event and a paired swing event of the same direction occur in either order within the configured pairing window. A local bearish combined event is the local bearish combined event; a local bullish combined event is the local bullish combined event.
Calculation: A macro bullish or bearish event is the corresponding combined event calculated on same-chart-timeframe CRYPTOCAP:TOTAL bars or CRYPTOCAP:BTC.D bars; use their current bars, which may still be forming. A macro event is active on its event bar and for the configured macro window afterward.
Calculation: A long-blocking RSI condition is RSI below its lower boundary at any point in its configured scan window; a short-blocking RSI condition is RSI above its upper boundary in that window. A long-blocking MACD condition is a negative, falling MACD histogram; a short-blocking MACD condition is a positive, rising MACD histogram. A long-blocking volatility condition is a bearish candle body in the scan window exceeding ATR times a multiplier; a short-blocking volatility condition is a bullish candle body exceeding that threshold. Each filter applies only when enabled.
Long: (local bearish combined event AND NOT any enabled long-blocking condition) OR (TOTAL bullish event active AND BTC.D bullish event active AND NOT (previous bar had both active) AND NOT (local bearish combined event AND NOT any enabled long-blocking condition))
Short: (local bullish combined event AND NOT any enabled short-blocking condition) OR (TOTAL bearish event active AND BTC.D bearish event active AND NOT (previous bar had both active) AND NOT (local bullish combined event AND NOT any enabled short-blocking condition))
Exit: Long, short condition
Exit: Short, long condition
