Calculation: Acceleration-adjusted radius = ATR × base multiplier × (1 + min(abs(EMA(change(EMA(change(close, acceleration length)), acceleration length), acceleration length) / ATR), 2)) ^ curve strength
Calculation: Upper and lower bands = hl2 ± acceleration-adjusted radius; upper band is max(current upper basic band, previous upper band) when previous close > previous upper band, otherwise current upper basic band; lower band is min(current lower basic band, previous lower band) when previous close < previous lower band, otherwise current lower basic band
Calculation: Trend state = 1 when close > previous upper band; −1 when close < previous lower band; otherwise previous trend state (initially 1)
Calculation: Expansion state = 2 if expansion score > 35, 1 if > 12, −2 if < −35, −1 if < −12, otherwise 0; expansion score is the EMA(5) of 45 × signed efficiency + 25 × (1 − binary entropy of up/down close changes) + clamped participation score − clamped liquidity penalty. Signed efficiency = (close − close[length]) / sum(abs(change(close)), length). Participation score = clamp((volume / max(SMA(volume, impact length), 1) − 1) × 15 + abs(close − open) / max(high − low, minimum tick) × ((2 × (close − low) / max(high − low, minimum tick)) − 1) × 15, −25, 25). Liquidity penalty = clamp((impact ratio − 1) × 15, −20, 20), where impact ratio = EMA(abs(log(close / previous close)) / max(close × volume, 1) × 100000000, impact length) / SMA(that EMA, impact length), or 1 if the SMA is not positive.
Long: On a completed bar, (trend state = 1 AND previous trend state = −1) OR (expansion layer enabled AND expansion state > 0 AND previous expansion state ≤ 0)
Short: On a completed bar, (trend state = −1 AND previous trend state = 1) OR (expansion layer enabled AND expansion state < 0 AND previous expansion state ≥ 0)
