Calculation: Volume average = simple moving average of volume over a lookback independent of the run length, including the completed trigger bar.
Calculation: Support origin = search backward up to the configured maximum lookback for a bearish candle whose immediately following candle has a lower low; in First Only mode test only the nearest bearish candle, and in Off mode use the nearest bearish candle without a sweep test.
Calculation: Resistance origin = search backward up to the configured maximum lookback for a bullish candle whose immediately following candle has a higher high; in First Only mode test only the nearest bullish candle, and in Off mode use the nearest bullish candle without a sweep test.
Long: On a completed bar, each of the last N close-to-close changes is nonnegative AND current volume >= configured multiple of its volume average AND a support origin is found AND its candle has not already generated a support zone.
Short: On a completed bar, each of the last N close-to-close changes is nonpositive AND current volume >= configured multiple of its volume average AND a resistance origin is found AND its candle has not already generated a resistance zone.
