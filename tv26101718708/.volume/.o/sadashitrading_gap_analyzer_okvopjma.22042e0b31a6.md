Calculation: Gap percentage = (current daily open − previous completed daily close) / previous completed daily close × 100
Calculation: Relative volume = current daily volume / average volume of the preceding completed daily bars
Long: gap percentage ≥ minimum gap size AND (relative volume filter disabled OR relative volume ≥ minimum relative volume)
Short: gap percentage ≤ −minimum gap size AND (relative volume filter disabled OR relative volume ≥ minimum relative volume)
Exit: long, current bar is the configured evaluation number of daily bars after any long or short gap signal
Exit: short, current bar is the configured evaluation number of daily bars after any long or short gap signal
