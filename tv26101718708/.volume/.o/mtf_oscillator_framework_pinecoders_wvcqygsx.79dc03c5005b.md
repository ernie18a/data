Calculation: Signed true range = true range multiplied by +1 when close > open, −1 when close < open, and 0 when close = open; an alternate input source may be used instead.
Calculation: Oscillator line = selected moving average of the signal on the chart, medium, or highest timeframe, or the weighted average of available values from those three timeframes, as configured. Higher-timeframe values use the last completed bar when repainting is off and the forming bar when it is on.
Calculation: Divergence level = oscillator-line value on the latest bar where bar direction opposes the line’s direction (line rising or falling over one bar); bar direction is up/down when rounded close is above/below rounded open, or when equal and rounded close is above/below the previous rounded close.
Long: At least one coloring condition is enabled AND every enabled condition is bullish AND the configured volatility filter passes AND the previous bar was not bullish. Bullish conditions are: line > centerline; line > prior bar’s Donchian high; line > divergence level; line > medium-timeframe value; line > highest-timeframe value; chart-timeframe value > medium-timeframe value; chart-timeframe value > highest-timeframe value; medium-timeframe value > centerline; highest-timeframe value > centerline.
Short: At least one coloring condition is enabled AND every enabled condition is bearish AND the configured volatility filter passes AND the previous bar was not bearish. Bearish conditions are the corresponding comparisons reversed. The volatility filter is unrestricted, short-term ATR > long-term ATR, or short-term ATR ≤ long-term ATR, as configured.
