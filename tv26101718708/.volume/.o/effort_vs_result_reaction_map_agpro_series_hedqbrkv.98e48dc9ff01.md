Calculation: True range = max(high − low, abs(high − previous close), abs(low − previous close))
Calculation: ATR-normalized effort = relative volume × volume weight + true range / ATR × (1 − volume weight), where relative volume = volume / its longer-lookback simple moving average
Calculation: Effort score = clamp(ATR-normalized effort / high-effort threshold × 100, 0, 150)
Calculation: Progress direction = sign(current close − close N bars ago); if equal, use +1 when close ≥ open, otherwise −1
Calculation: Result score = clamp(0.62 × clamp(abs(current close − close N bars ago) / ATR / strong-progress ATR × 100, 0, 130) + 0.38 × directional close score, 0, 100), where directional close score = 100 × (close − low) / (high − low) for upward progress and 100 × (1 − (close − low) / (high − low)) for downward progress
Calculation: Wick balance = (upper wick − lower wick) / (high − low), where upper wick = high − max(open, close) and lower wick = min(open, close) − low
Calculation: Attempt direction = +1 when close > open, −1 when close < open, otherwise progress direction; when abs(wick balance) ≥ wick-dominance threshold, use +1 if wick balance > 0, otherwise −1
Calculation: Failed-progress confidence = clamp(0.50 × effort score + 0.35 × (100 − result score) + 0.15 × abs(wick balance) × 100, 0, 100)
Calculation: Low-effort-progress confidence = clamp(0.35 × (100 − effort score) + 0.50 × result score + 0.15 × directional close score, 0, 100)
