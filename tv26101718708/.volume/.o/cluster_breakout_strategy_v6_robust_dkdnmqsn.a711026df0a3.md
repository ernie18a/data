Calculation: cluster high/low = highest high / lowest low over the configured cluster lookback; cluster range = cluster high - cluster low
Calculation: squeeze = cluster range <= ATR * configured tightness multiplier AND, when contraction is required, current ATR < ATR from the configured contraction lookback
Calculation: breakout buffer = ATR * configured buffer multiplier
Calculation: strong-close position = (close - low) / (high - low), or 0.5 when high = low
Calculation: volume confirmation = volume unavailable or zero, or volume > average volume over the configured volume lookback * configured volume multiplier
Calculation: long/short trend filter, when enabled = close above/below configured EMA AND ADX > configured minimum
Calculation: initial stop = entry price * (1 -/+ configured stop percentage)
Calculation: first target = entry price * (1 +/- configured first-target percentage); second target = entry price * (1 +/- configured first-target percentage * configured target multiplier); post-target stop = entry price * (1 +/- configured post-target stop percentage)
Long: active cluster AND close > cluster high + breakout buffer AND previous close <= previous cluster high + previous breakout buffer AND (strong-close filter disabled OR strong-close position >= configured threshold) AND (volume confirmation disabled OR volume confirmation) AND (trend filter disabled OR long trend filter) AND within configured session if session restriction is enabled AND daily entries below configured maximum AND cooldown elapsed AND flat
Short: active cluster AND close < cluster low - breakout buffer AND previous close >= previous cluster low - previous breakout buffer AND (strong-close filter disabled OR strong-close position <= 1 - configured threshold) AND (volume confirmation disabled OR volume confirmation) AND (trend filter disabled OR short trend filter) AND within configured session if session restriction is enabled AND daily entries below configured maximum AND cooldown elapsed AND flat
Exit: Long, before first target, low <= initial stop OR close >= first target; after first target, low <= post-target stop OR high >= second target; configured maximum bars held reached; configured session has ended
Exit: Short, before first target, high >= initial stop OR close <= first target; after first target, high >= post-target stop OR low <= second target; configured maximum bars held reached; configured session has ended
