Calculation: Daily VWAP = volume-weighted average of hlc3 from the current calendar day’s start through the current forming bar.
Calculation: Rolling VWAP = volume-weighted average of hlc3 for bars within the configured rolling time window through the current forming bar.
Calculation: NY VWAP = volume-weighted average of hlc3 from the configured NY session start through the current forming bar; reset at each session start.
Calculation: European VWAP = volume-weighted average of hlc3 from the configured European session start through the current forming bar; reset at each session start.
Calculation: Asian VWAP = volume-weighted average of hlc3 from the configured Asian session start through the current forming bar; reset at each session start.
Long: close crosses above Daily VWAP OR close crosses above Rolling VWAP OR close crosses above NY VWAP OR close crosses above European VWAP OR close crosses above Asian VWAP
Short: close crosses below Daily VWAP OR close crosses below Rolling VWAP OR close crosses below NY VWAP OR close crosses below European VWAP OR close crosses below Asian VWAP
