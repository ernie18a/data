Calculation: VWMO histogram = 7-bar WMA of (close − volume-weighted median of the last N calculation-timeframe closes, weighted by their volumes) / max(14-bar EMA of high − low, positive floor); use the raw ratio when smoothing is disabled. The calculation-timeframe bar is still forming in realtime and completed on historical bars.
Calculation: VWMO main line = 7-bar WMA of (volume-weighted median of the last N calculation-timeframe closes, weighted by their volumes − 3N-bar EMA of that median) / max(14-bar EMA of high − low, positive floor); use the raw ratio when smoothing is disabled. Use the same calculation timeframe and bar status as the VWMO histogram.
Calculation: VWMO signal = N-bar EMA of the VWMO main line.
Long: VWMO histogram >= 0 OR VWMO histogram crosses above 0 OR VWMO main line >= VWMO signal OR VWMO main line crosses above VWMO signal OR VWMO main line crosses above 0 OR VWMO main line crosses below the oversold threshold
Short: VWMO histogram < 0 OR VWMO histogram crosses below 0 OR VWMO main line < VWMO signal OR VWMO main line crosses below VWMO signal OR VWMO main line crosses below 0 OR VWMO main line crosses above the overbought threshold
