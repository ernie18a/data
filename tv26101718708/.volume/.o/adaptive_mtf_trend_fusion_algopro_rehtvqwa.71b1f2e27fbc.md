Calculation: Fusion line = EMA-smoothed weighted average of the selected moving average and selected VWAP, each calculated on three configured or automatically selected timeframes using the same MA type and length and the same VWAP mode and length on each; on timeframes higher than the chart, use the last completed timeframe bar, otherwise use the bar still forming.
Calculation: Upper and lower volatility thresholds = fusion line plus or minus the chart-timeframe ATR, EMA-smoothed with the fusion line’s smoothing length and multiplied by a volatility multiplier.
Long: The configured number of consecutive calculation candles have calculation close above the upper volatility threshold and calculation close above calculation open, and the prior trend state is not bullish; OR trend state is bullish, calculation close previously crossed below the fusion line since the last trend-state change, and calculation close crosses above the fusion line.
Short: The configured number of consecutive calculation candles have calculation close below the lower volatility threshold and calculation close below calculation open, and the prior trend state is not bearish; OR trend state is bearish, calculation close previously crossed above the fusion line since the last trend-state change, and calculation close crosses below the fusion line.
