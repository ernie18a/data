Calculation: Composite = 100 × (mean of seven 1–5 grades − 1) / 4. Grades: RSI: 5 if RSI < 20, 4 if < 30, 1 if > 80, 2 if > 70, else 3. EMA stack (9/21/50/100/200/250, shortest to longest): 1 if strictly descending; 2 if EMA9 < EMA21 < EMA50; 3 if EMA9 > EMA21 > EMA50 and EMA50 < EMA100; 4 if EMA9 > EMA21 > EMA50 > EMA100 but not the full ascending stack; 5 if the full stack is ascending; else 3. MACD (fast MA minus slow MA, with signal MA): 1 if MACD < 0, histogram < 0 and falling for 3 bars; 2 if MACD < 0 and (histogram ≥ 0 or rising for 3 bars); 3 if MACD/signal cross with MACD ≤ 0 on an upward cross or ≥ 0 on a downward cross; 5 if MACD > 0, histogram > 0 and both MACD (5 bars) and histogram (3 bars) are rising; 4 if MACD > 0, histogram > 0 and (MACD > signal or histogram rising for 3 bars); else 3. ADX/DI: 1 if ADX < 20 and −DI > +DI; 2 if 20 ≤ ADX < 25 and −DI > +DI; 3 if 20 ≤ ADX < 25 and |+DI − −DI| is within the DI tolerance; 4 if 25 ≤ ADX ≤ 40 and +DI > −DI; 5 if ADX > 40 and +DI > −DI; else 3. Ichimoku: use conversion/base lines, cloud at the configured displacement, close versus that cloud, close versus its displaced past close, and whether the current cloud is bullish and widening. Grade 1 if conversion < base, close below cloud and below displaced past close; 2 if conversion < base and (inside cloud or not below displaced past close); 3 if conversion/base cross inside cloud; 5 if conversion > base, close above cloud and displaced past close, and bullish cloud widening; 4 if the same without widening; else 3. Bollinger: 1 if close < lower band or (close ≤ lower band and lower band or basis is falling for 3 bars); 5 if close > upper band or (close ≥ upper band and upper band or basis is rising for 3 bars); 2 if lower band ≤ close < basis; 4 if basis < close ≤ upper band; else 3. OBV: cumulative volume signed by close direction; compare with its moving average. Grade 1 if below and falling over the short lookback; 2 if below and (rising over the short lookback or OBV ≥ MA × (1 − near tolerance)); 3 if within near tolerance of MA; 4 if above and rising over the short lookback; 5 if above, rising over the longer lookback, and current OBV change > spike multiplier × average absolute OBV change; else 3.
Calculation: Confirmed pivot low/high = pivot whose low/high is an extreme against the configured number of bars on both sides, available only after the right-side bars complete; use the pivot bar's Composite for classification.
Calculation: Support/resistance zone = pivot price anchor with ATR-scaled height; support bounds are [anchor − height, anchor + 0.12 × height], resistance bounds [anchor − 0.12 × height, anchor + height].
Long: Composite ≥ oversold threshold OR (Composite ≥ oversold threshold AND previous Composite < threshold) OR (confirmed pivot low with pivot-bar Composite ≥ threshold, zone accepted by same-side deduplication and zone cap, and bar range intersects an active support zone).
Short: Composite ≤ overbought threshold OR (Composite ≤ overbought threshold AND previous Composite > threshold) OR (confirmed pivot high with pivot-bar Composite ≤ threshold, zone accepted by same-side deduplication and zone cap, and bar range intersects an active resistance zone).
Exit: long, close < support-zone lower bound × (1 − invalidation offset).
Exit: short, close > resistance-zone upper bound × (1 + invalidation offset).
