Calculation: Oscillator candle OHLC = apply the selected RSI, stochastic, center of gravity, MACD line, TSI, CCI, CMO, or MFI calculation separately to the bar’s open, close, high, and low; for stochastic, use each price as the source and the bar’s high and low as range inputs.
Calculation: Oscillator supertrend direction = start at +1. Compute true range as max(oscillator high, prior oscillator close) − min(oscillator low, prior oscillator close), then multiply its selected moving average by the ATR multiplier. Set the long stop to oscillator close minus this value; ratchet it to the maximum of the current and prior long stop when the prior oscillator low (or close, if wick mode is off) is above the prior long stop. Set the short stop to oscillator close plus this value; ratchet it to the minimum of the current and prior short stop when the prior oscillator high (or close, if wick mode is off) is below the prior short stop. Change direction from −1 to +1 when the current oscillator high (or close, if wick mode is off) exceeds the prior short stop; change from +1 to −1 when the current oscillator low (or close, if wick mode is off) falls below the prior long stop; otherwise retain direction.
Long: oscillator supertrend direction = +1 AND datetime is within the configured start and end times
Short: oscillator supertrend direction = −1 AND datetime is within the configured start and end times
Exit: long, oscillator supertrend direction = −1
Exit: short, oscillator supertrend direction = +1
