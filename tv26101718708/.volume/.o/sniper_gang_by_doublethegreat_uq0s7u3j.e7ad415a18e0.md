Calculation: Profit targets = entry price + (1, 2, 3, 4, or 5) × ATR(14) × configurable stop-distance multiplier for long positions; entry price − the same distances for short positions. Use ATR from the entry bar.
Long: Fast EMA crosses above slow EMA AND previous signal state ≤ 0
Short: Fast EMA crosses below slow EMA AND previous signal state ≥ 0
Exit: Long, high ≥ any profit target
Exit: Short, low ≤ any profit target
