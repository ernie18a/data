Calculation: Daily ATR % reached = current daily bar’s high-low range divided by daily ATR, times 100; use the daily bar still forming.
Calculation: Average daily ATR % = 50-bar simple moving average of daily high-low range divided by daily ATR, times 100; use daily bars, including the bar still forming.
Calculation: Price fulfillment % = (current close − current daily low) divided by daily ATR, times 100; use the daily bar still forming.
Long: current daily close > current daily open AND Daily ATR % reached > 1.5 × Average daily ATR %
Short: current daily close < current daily open AND Daily ATR % reached > 1.5 × Average daily ATR %
Exit: long, Daily ATR % reached > 150 OR Price fulfillment % > 80
Exit: short, Daily ATR % reached > 150
