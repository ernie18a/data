Calculation: First and second SuperTrend = on two different higher timeframes, calculate a selectable moving average of (higher-timeframe close × chart-bar volume) divided by the same moving average of chart-bar volume, then add/subtract its respective factor times higher-timeframe ATR; trail the bands using the prior band and prior chart-bar close, and set direction to -1 when price is above the active upper band or below the active lower band, otherwise 1. Use the higher-timeframe bar currently forming.
Calculation: First and second AI labels = for each SuperTrend, form samples from the current and prior max(neighbor count, data-point count) bars, each feature being that SuperTrend and each binary label being 1 when the price-length WMA of close exceeds the prediction-length WMA of that SuperTrend, else 0; for the current SuperTrend, take the weighted mean of the k nearest features by absolute distance, weighted by inverse distance, and classify as 1 if the mean equals 1, 0 if it equals 0, otherwise neutral. The two classifiers use separate SuperTrends and lengths; the second uses the first classifier’s sample count and neighbor count in the source logic.
Calculation: Higher-timeframe +DI, -DI, and ADX = WMA-smoothed directional indicators and ADX from the separately selected higher timeframe, using its currently forming bar.
Calculation: Pivot trend value = bull count − bear count + weak-bull count − weak-bear count. For each of high and low, calculate 75th and 25th nearest-rank percentiles over lookbacks L, 2L, 3L, 6L, and 7L; compare these with the 75th percentile of high and 25th percentile of low over 144 bars. Bull count adds one for each high or low percentile above the 144-bar high percentile; bear count adds one for each below the 144-bar low percentile. Weak-bull count adds one for each low percentile between those thresholds; weak-bear count adds one for each high percentile between them.
Calculation: Bullish trend-flip signal = first direction changes from 1 to -1 and first AI label is 1; second bullish trend-flip signal uses the second direction and label. Bearish trend-flip signals use the corresponding change from -1 to 1 and label 0.
Calculation: Bullish AI-start signal = AI label is 1 and its prior value was not 1 or was neutral; bearish AI-start signal = AI label is 0 and its prior value was not 0 or was neutral. Apply separately to each classifier.
Calculation: Long trailing stop = first SuperTrend − first higher-timeframe ATR × first factor; short trailing stop = first SuperTrend + first higher-timeframe ATR × first factor.
Long: first direction < 0 AND first AI label = 1 AND second direction < 0 AND second AI label = 1 AND (ADX > 20 AND +DI > -DI when the ADX/DMI filter is enabled) AND pivot trend value > 0; OR bullish AI-start signal; OR bullish trend-flip signal.
Short: first direction > 0 AND first AI label = 0 AND second direction > 0 AND second AI label = 0 AND (ADX > 20 AND -DI > +DI when the ADX/DMI filter is enabled) AND pivot trend value < 0; OR bearish AI-start signal; OR bearish trend-flip signal.
Exit: long, (NOT (first or second bullish trend-flip signal) OR pivot trend value < 0) AND low ≤ long trailing stop.
Exit: short, (NOT (first or second bearish trend-flip signal) OR pivot trend value > 0) AND high ≥ short trailing stop.
