Calculation: total points = Parabolic SAR score (+3 if open is above SAR, otherwise −3) + SuperTrend score (+3 in uptrend, otherwise −3) + ZigZag score (+1 if its current low pivot is more recent than its high pivot, otherwise −1) + ROC score (+1 if positive, otherwise −1) + DMI score (+2 if +DI ≥ −DI, otherwise −2) + CCI score (+1 if positive, otherwise −1) + Weis Wave score (+2 if up-wave volume exceeds down-wave volume, otherwise −2) + SMA score (+1 if open is above its 20-bar SMA, otherwise −1) + Awesome Oscillator score (+1 if positive, −1 if negative, otherwise 0; 5-bar SMA of hl2 minus 34-bar SMA of hl2) + momentum score (+1 if open exceeds its value 14 bars earlier, −1 if below, otherwise 0) + MACD histogram score (+3 if the histogram rises from the prior bar, otherwise −3; MACD uses shorter- and longer-lookback EMAs and an EMA signal line) + bull-bear score (+1 if the 30-bar SMA of bull minus bear is positive, otherwise −1) + Ichimoku baseline score (+2 if open is above the baseline, otherwise −2; baseline is the midpoint of the highest high and lowest low over its lookback) + HMA score (+1 if open is above the Hull moving average, otherwise −1). All lookbacks use chart bars.
Long: (total points > entry threshold OR ZigZag score = +1) AND SuperTrend is up
Short: (total points < negative entry threshold OR ZigZag score = −1) AND SuperTrend is down
