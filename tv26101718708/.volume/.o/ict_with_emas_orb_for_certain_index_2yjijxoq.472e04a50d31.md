Calculation: SMA(high) and SMA(low) = simple moving averages of high and low over the same lookback
Calculation: Bullish structure level = most recent active swing-high level broken upward on the selected structure timeframe; classify the break as BOS when the prior structure state is bullish, otherwise MSS. Bearish structure level = most recent active swing-low level broken downward; classify the break as BOS when the prior structure state is bearish, otherwise MSS. Swing highs and lows use equal left and right pivot lookbacks. For a bullish structure state, test upward breaks against the chart bar's high and downward breaks against the last completed structure-timeframe close; for a bearish state, test upward breaks against the last completed structure-timeframe close and downward breaks against the chart bar's low.
Calculation: Signal state = bullish after a long signal, bearish after a short signal, and neutral when close is strictly between SMA(high) and SMA(low); retain the prior state otherwise
Long: Close crosses above the latest bullish BOS level if BOS mode is selected, or the latest bullish MSS level if MSS mode is selected AND close > SMA(high) AND close > SMA(low) AND signal state is not bullish
Short: Close crosses below the latest bearish BOS level if BOS mode is selected, or the latest bearish MSS level if MSS mode is selected AND close < SMA(high) AND close < SMA(low) AND signal state is not bearish
