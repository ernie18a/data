Calculation: Prior range high/low = highest high / lowest low over the preceding range lookback bars, excluding the current bar; use only when both exist and high > low.
Calculation: ATR = average true range on the chart timeframe, including the current bar.
Calculation: Break buffer = ATR × minimum-break parameter.
Calculation: Break attempt = current high > prior range high + break buffer (upper), or current low < prior range low − break buffer (lower); if both, choose upper when its excess is at least the lower excess, otherwise lower.
Calculation: New break event = a break attempt when there is no active event, its side differs from the active event, or the active event is eligible for replacement: a same-side break after a confirmed trap; a same-side break after an accepted break that exceeds the stored extreme by a break buffer; or an unresolved event older than the acceptance-bar parameter. Freeze the prior range high, low, midpoint, current ATR, and break-bar index at event start; update the event extreme to the greatest high (upper) or least low (lower) while unresolved.
Calculation: Event age = current bar index − event start bar. Event is fresh when unresolved and age ≤ acceptance-bar parameter. Clear a resolved event after the resolved-display-bar parameter; clear an unresolved event when older than the acceptance-bar parameter and close is back inside its frozen range, or when older than the sum of acceptance-bar and resolved-display-bar parameters.
Calculation: Reclaim watch = unresolved active event, event fresh, not trap-confirmed, and (current bar reaches back across the frozen broken edge, close has moved back across that edge, or trap risk ≥ watch-score parameter). For an upper event, crossing/back means low ≤ frozen high / close < frozen high; for a lower event, high ≥ frozen low / close > frozen low.
Calculation: Trap risk = clamp(0.22 × failure-speed score + 0.25 × reclaim score + 0.18 × wick score + 0.15 × volume-spike score + 0.20 × inside-close score, 0, 100); multiply this sum by 0.65 when the break is still holding and break quality > 72. Failure-speed score = clamp((reclaim-window parameter − event age) / reclaim-window parameter × 100, 0, 100). Reclaim score = clamp(reclaim distance in ATR / strong-reclaim parameter × 100, 0, 100). Wick score = clamp(140 × active-side wick / current bar range × 100, 0, 100), where active-side wick is upper wick for an upper event and lower wick for a lower event. Volume-spike score = clamp((relative volume − 0.90) / (volume-spike parameter − 0.90) × 100, 0, 100), where relative volume = current volume / its chart-timeframe simple moving average. Inside-close score = 100 when close is inside the frozen range, 55 when the bar reaches back across the broken edge, otherwise 0. Reclaim distance is max(frozen high − close, 0) / ATR for upper events and max(close − frozen low, 0) / ATR for lower events.
Calculation: Trap confirmed = unresolved active event, close back inside frozen range, trap risk ≥ trap-confirmed-score parameter, and event age ≤ acceptance-bar parameter. Break accepted = unresolved active event, close remains beyond the frozen broken edge for at least the acceptance-bar parameter consecutive bars, and initial break quality ≥ 48. Initial break quality = clamp(0.42 × close-through score + 0.18 × penetration score + 0.20 × body-efficiency score + 0.20 × volume score, 0, 100), captured at event start. Close-through score = clamp((close distance beyond frozen edge in ATR − 0.03) / (2.2 × minimum-break parameter − 0.03) × 100, 0, 100). Penetration score = clamp((penetration in ATR − 0.70 × minimum-break parameter) / (3.0 × minimum-break parameter − 0.70 × minimum-break parameter) × 100, 0, 100). Body-efficiency score = abs(close − open) / max(high − low, minimum tick) × 100. Volume score = clamp((relative volume − 0.85) / (1.25 × volume-spike parameter − 0.85) × 100, 0, 100). Penetration is max(event extreme − frozen high, 0) / ATR for upper events and max(frozen low − event extreme, 0) / ATR for lower events. The normalized-score formulas return 0 if their denominator is 0.
Long: new upper break event OR upper break accepted OR active lower event with reclaim watch OR active lower event with trap confirmed.
Short: new lower break event OR lower break accepted OR active upper event with reclaim watch OR active upper event with trap confirmed.
