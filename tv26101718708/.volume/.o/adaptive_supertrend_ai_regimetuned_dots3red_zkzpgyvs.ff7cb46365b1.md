Calculation: Smoothed regime = classify each bar as VOLATILE if ATR(14) / its longer-period SMA > volatility threshold; otherwise classify as TRENDING if (min(ADX / 60, 1) + 1 - min((Choppiness Index - 38) / 62, 1)) / 2 > trend threshold; RANGING if that score < range threshold; else UNCERTAIN. Use the most frequent classification in the smoothing lookback; ties resolve VOLATILE, then TRENDING, then RANGING, then UNCERTAIN.
Calculation: Active ATR multiplier = target multiplier for the smoothed regime on the first bar; thereafter previous multiplier + (target multiplier - previous multiplier) / transition length.
Calculation: Adaptive SuperTrend bands and direction = basic upper/lower bands are hl2 ± active ATR multiplier × ATR(band lookback). Ratchet upper to the basic upper when it is lower than the prior upper or prior close was above prior upper; otherwise keep prior upper. Ratchet lower to the basic lower when it is higher than the prior lower or prior close was below prior lower; otherwise keep prior lower. Start direction UP. While UP, change to DOWN when close < lower band; while DOWN, change to UP when close > upper band. A flip is a change from the prior bar's direction.
Long: prior direction was DOWN AND current close > current upper band (confirmed bar)
Short: prior direction was UP AND current close < current lower band (confirmed bar)
