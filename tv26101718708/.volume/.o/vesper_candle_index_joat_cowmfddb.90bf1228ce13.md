Calculation: Bullish candidate score = for each qualifying bullish pattern, its base score + (13 if bullish trend, 5 if mixed trend, otherwise -11) + (13 if bullish location) + (17 × structure weight if bullish structure) + (8 if bullish momentum, otherwise -2) + (7 if volume expansion) + (7 if wick confirmation) + min(max(abs(regression slope) / ATR × 100, 0), 9); bases: bullish engulfing 52, hammer 48, inverted hammer 43, morning star 57, piercing 50, bullish harami 42, inside break up 49, bullish marubozu 47, three soldiers 55, tweezer low 45, bullish rail 51, reclaim 58. Qualifying patterns use their standard candle definitions; all pattern conditions are evaluated on completed bars. Bullish trend = fast EMA > slow EMA and regression slope >= 0; mixed trend = neither bullish nor bearish trend. Bullish location = close in or below the lower regression field, or bullish trend and close > fast EMA. Bullish structure = close breaks above the latest confirmed pivot high. Bullish momentum = RSI > 50 and rising. Volume expansion = volume >= 1.25 × its 30-bar simple average. Wick confirmation = lower wick >= 1.45 × body and close position >= 0.58; for hammer, inverted hammer, morning star, piercing, bullish harami, and tweezer low, use true instead. For inside break up, marubozu, three soldiers, and rail, use strong body instead (body / range >= 0.55). Bullish reclaim requires low below the latest confirmed pivot low, close above it, and wick confirmation.
Calculation: Bearish candidate score = for each qualifying bearish pattern, its base score + (13 if bearish trend, 5 if mixed trend, otherwise -11) + (13 if bearish location) + (17 × structure weight if bearish structure) + (8 if bearish momentum, otherwise -2) + (7 if volume expansion) + (7 if wick confirmation) + min(max(abs(regression slope) / ATR × 100, 0), 9); bases: bearish engulfing 52, shooting star 48, hanging man 43, evening star 57, dark cloud 50, bearish harami 42, inside break down 49, bearish marubozu 47, three crows 55, tweezer high 45, bearish rail 51, reject 58. Qualifying patterns use their standard candle definitions; all pattern conditions are evaluated on completed bars. Bearish trend = fast EMA < slow EMA and regression slope <= 0; mixed trend = neither bullish nor bearish trend. Bearish location = close in or above the upper regression field, or bearish trend and close < fast EMA. Bearish structure = close breaks below the latest confirmed pivot low. Bearish momentum = RSI < 50 and falling. Volume expansion is as defined above. Wick confirmation = upper wick >= 1.45 × body and close position <= 0.42; for shooting star, hanging man, evening star, dark cloud, bearish harami, and tweezer high, use true instead. For inside break down, marubozu, three crows, and rail, use strong body instead. Bearish reject requires high above the latest confirmed pivot high, close below it, and wick confirmation.
Calculation: Latest confirmed pivot high/low = most recent high/low confirmed using the selected left and right pivot lengths.
Long: On a completed bar, cooldown is ready and the highest-scoring qualifying candidate is bullish with score >= minimum accepted score, OR close crosses above the latest confirmed pivot high.
Short: On a completed bar, cooldown is ready and the highest-scoring qualifying candidate is bearish with score >= minimum accepted score, OR close crosses below the latest confirmed pivot low.
