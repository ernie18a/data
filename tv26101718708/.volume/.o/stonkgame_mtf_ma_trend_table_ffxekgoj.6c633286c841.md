Calculation: Moving average = selected moving average of source-timeframe close; each horizon uses its configured source timeframe and length.
Calculation: Displacement Z-score = (log(close / moving average) - historical mean) / historical standard deviation, over an adaptive sample up to a configurable maximum; valid only after a configurable minimum sample.
Calculation: Slope Z-score = historical Z-score of log(moving average / moving average k source bars ago) / k, where k is at least 2 and otherwise the rounded product of moving-average length and a configurable fraction; use the same adaptive sample rules as displacement.
Calculation: Path efficiency = min(1, abs(moving average - moving average k bars ago) / (k × mean absolute one-bar moving-average change over k bars)); adjusted slope Z-score = slope Z-score × (efficiency floor + path efficiency × (1 - efficiency floor)).
Calculation: Horizon state = EMA-smoothed weighted average of displacement Z-score and adjusted slope Z-score, each clipped to a configurable absolute limit; weights are normalized, or 50/50 if both are zero. Require both Z-scores to have the minimum sample. Calculate on each horizon's source timeframe using the last completed source bar by default; the optional chart-timeframe state uses the current chart bar.
Long: Any available hourly, daily, weekly, monthly, quarterly, half-year, yearly, multi-year, or chart-timeframe state >= 0.50 OR selected horizon state crosses above the positive shift threshold after having reached <= -min(0.25, half the shift threshold) OR selected horizon state crosses above the negative recovery threshold after having reached <= -1.05 × the recovery threshold.
Short: Any available hourly, daily, weekly, monthly, quarterly, half-year, yearly, or multi-year state <= -0.50 OR selected horizon state crosses below the negative shift threshold after having reached >= min(0.25, half the shift threshold) OR selected horizon state crosses below the positive recovery threshold after having reached >= 1.05 × the recovery threshold.
