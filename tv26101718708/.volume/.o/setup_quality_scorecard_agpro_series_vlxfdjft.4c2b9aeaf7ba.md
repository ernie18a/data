Calculation: Bullish bias = bullish vote count exceeds bearish vote count; votes are EMA fast > EMA mid > EMA slow, higher-timeframe close > higher-timeframe fast EMA > higher-timeframe slow EMA, fast EMA > its value 5 bars ago, close > fast EMA, and close > open. Bearish bias uses the inverse comparisons. Ties produce no valid side.
Calculation: Higher-timeframe close and EMAs = values from the selected higher-timeframe bar using lookahead-off data; use the current forming higher-timeframe bar when available and otherwise the last completed higher-timeframe bar.
Calculation: Active pivot high/low = latest confirmed pivot high/low, each formed with the configured pivot length on both sides, if its pivot bar is within the context lookback; otherwise unavailable.
Calculation: Decision reference = active pivot low for bullish bias or fast EMA if unavailable; active pivot high for bearish bias or fast EMA if unavailable.
Calculation: ATR-normalized location score = 100 minus the distance between close and decision reference divided by ATR, normalized linearly from the configured good distance to bad distance and clamped to 0–100; cap at 28 if bullish close is below the reference or bearish close is above it. Use the configured sensitivity in the bad-distance threshold.
Calculation: Trend support score = 45% stack score + 35% higher-timeframe score + 20% slope score. For bullish bias, stack score is 100 for the bullish EMA stack, else 66 if close > mid EMA, else 44 if close > slow EMA, else 20; higher-timeframe score is 100 for bullish higher-timeframe alignment, else 62 if higher-timeframe close > its fast EMA, else 30; slope score is 100 if fast EMA > its value 5 bars ago, else 35. For bearish bias use inverse comparisons. Clamp to 0–100.
Calculation: Momentum score = 36% directional RSI score + 22% RSI delta score + 24% candle quality score + 18% volume score, clamped to 0–100. RSI is 14-period; delta is RSI minus RSI 3 bars ago. Directional RSI score is RSI normalized upward from 48 to 65 for bullish bias, or (52 − RSI) normalized upward from 0 to 17 for bearish bias. Delta score is RSI delta normalized upward from −1 to 6 for bullish bias, or its negation normalized the same way for bearish bias. Candle quality is absolute body/range normalized upward from 0.18 to 0.72 when candle direction agrees with bias; otherwise normalize downward from 0.10 to 0.75. Volume score is volume / 30-bar volume SMA normalized upward from 0.85 to 1.65; use 55 if volume context is disabled. Linear normalization is clamped to 0–100.
Calculation: Invalidation edge = active pivot low − 0.12 ATR for bullish bias, or active pivot high + 0.12 ATR for bearish bias; if the corresponding pivot is unavailable, use low − ATR × configured ideal risk distance for bullish bias, or high + ATR × configured ideal risk distance for bearish bias.
Calculation: Risk-fit score = 0 if invalidated; otherwise score the absolute distance from close to invalidation edge divided by ATR with a peak at configured ideal risk distance, rising linearly from 0 at 0.12 ATR to the peak and falling linearly to 0 at configured maximum risk distance. Apply sensitivity to the ideal and maximum distances.
Calculation: Target room = distance from close to the active pivot high above close for bullish bias, or active pivot low below close for bearish bias; if unavailable, use risk distance × configured target R multiple. Target-room score = target room in ATR normalized upward from 45% to 185% of configured minimum target room, clamped to 0–100. Apply sensitivity inversely to minimum target room.
Calculation: Readiness score = 24% location score + 22% trend support score + 22% momentum score + 16% risk-fit score + 16% target-room score, clamped to 0–100. Bias passes when a side is valid and trend support score ≥ 48. Location, momentum, and risk pass at score ≥ 55. Room passes when target-room score ≥ 55 and target room in ATR ≥ configured minimum target room.
Calculation: READY state = valid side, not invalidated, risk distance in ATR ≤ configured maximum, target room in ATR ≥ configured minimum, readiness score ≥ READY threshold, and at least 4 of bias/location/momentum/risk/room pass. MONITOR state = valid side, not invalidated, not READY, readiness score ≥ MONITOR threshold, and at least 3 of those 5 pass.
Long: bullish bias AND READY state now AND NOT READY state on the previous bar AND confirmed bar.
Long: bullish bias AND MONITOR state now AND NOT MONITOR state on the previous bar AND confirmed bar.
Short: bearish bias AND READY state now AND NOT READY state on the previous bar AND confirmed bar.
Short: bearish bias AND MONITOR state now AND NOT MONITOR state on the previous bar AND confirmed bar.
Exit: long, close ≤ invalidation edge AND not invalidated on the previous bar.
Exit: short, close ≥ invalidation edge AND not invalidated on the previous bar.
