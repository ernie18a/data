Calculation: Daily CPR = from the last completed daily bar, pivot=(high+low+close)/3, center=(high+low)/2, other center=2×pivot−center; CPR top and bottom are the greater and lesser center. Daily CPR width = top−bottom. CPR width percentile = current daily CPR width’s percentile rank among recent daily CPR widths.
Calculation: First structural target = daily R1 for a bullish CPR break, or daily S1 for a bearish CPR break, calculated from the last completed daily bar’s high, low, and close using floor pivots.
Calculation: One-standard-deviation expected move = daily open × implied volatility as a decimal × √(expiry days/365); use the configured expiry horizon.
Calculation: IV rank = current implied volatility’s position between its rolling daily high and low. Realized volatility = annualized volatility estimated from daily OHLC bars. Volatility risk premium = implied volatility minus realized volatility; classify it as rich when its rolling robust z-score (median and median absolute deviation) exceeds the configured threshold.
Long: current intraday close > daily CPR top AND daily CPR width percentile ≤ the configured narrow threshold AND implied volatility and volatility risk premium are not rich AND days to expiry ≥ the configured suppression threshold AND distance from daily open to daily R1 ≥ the one-standard-deviation expected move
Short: current intraday close < daily CPR bottom AND daily CPR width percentile ≤ the configured narrow threshold AND implied volatility and volatility risk premium are not rich AND days to expiry ≥ the configured suppression threshold AND distance from daily open to daily S1 ≥ the one-standard-deviation expected move
