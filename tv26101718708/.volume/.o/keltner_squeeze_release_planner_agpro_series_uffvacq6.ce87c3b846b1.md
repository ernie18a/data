Calculation: Keltner basis = EMA(close, basis lookback); upper/lower band = basis ± ATR(ATR lookback) × channel multiplier
Calculation: Channel width rank = current (upper − lower) / abs(basis), expressed as a percentage and ranked from 0 to 100 between its rolling lookback low and high
Calculation: Squeeze = channel width rank ≤ squeeze threshold; squeeze context = squeeze holds for the minimum consecutive bars
Calculation: Expansion ratio = current channel width / prior bar channel width
Calculation: Release score = clamp(compression score + expansion score + close pressure score + candle body score + volume score + basis slope score, 0, 100); the six component scores are respectively clamp((squeeze threshold − width rank + 10) / (squeeze threshold + 10), 0, 1) × 24; clamp((expansion ratio − 1) / 0.45, 0, 1) × 22; clamp(close distance beyond the release band / (ATR × 0.75), 0, 1) × 22; clamp(abs(close − open) / (bar high − low) / 0.70, 0, 1) × 14; when enabled, clamp(current volume / its moving average / 1.6, 0, 1) × 10, otherwise 7; and clamp(abs(current basis − basis 3 bars earlier) / ATR, 0, 1) × 8
Calculation: Required ready score = minimum ready score − 5 in Fast mode, minimum ready score in Balanced mode, or minimum ready score + 8 in Strict mode, bounded to 1–100
Long: Prior completed bar had squeeze context AND close > current upper band + ATR × release buffer AND expansion ratio ≥ required expansion ratio AND release score ≥ required ready score
Short: Prior completed bar had squeeze context AND close < current lower band − ATR × release buffer AND expansion ratio ≥ required expansion ratio AND release score ≥ required ready score
Exit: long, within the release window after a qualified long release AND close < frozen release upper band − release-bar ATR × failure buffer
Exit: short, within the release window after a qualified short release AND close > frozen release lower band + release-bar ATR × failure buffer
