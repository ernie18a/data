Calculation: Directional sequence = consecutive bars with close > open (bullish) or close < open (bearish); a doji (close = open) ends the sequence. The sequence open is the opening price of its first bar.
Calculation: CISD+ reference level = In “Every candle sequence” mode, the open of each new bearish sequence. In “Swing reversals” mode, at each confirmed swing high (high pivot using configurable preceding and following bars), use the open of the first bearish sequence from the pivot onward; if the pivot is within a bearish sequence, use that sequence’s first bar, even if it precedes the pivot. If no bearish sequence has appeared, wait for one. Discard a swing candidate if any close after its source bar and before swing confirmation is above it. Each source bar arms a level at most once; a newer qualifying level replaces the prior one. A level expires after its configured lifetime from its source bar.
Calculation: CISD- reference level = In “Every candle sequence” mode, the open of each new bullish sequence. In “Swing reversals” mode, at each confirmed swing low (low pivot using configurable preceding and following bars), use the open of the first bullish sequence from the pivot onward; if the pivot is within a bullish sequence, use that sequence’s first bar, even if it precedes the pivot. If no bullish sequence has appeared, wait for one. Discard a swing candidate if any close after its source bar and before swing confirmation is below it. Each source bar arms a level at most once; a newer qualifying level replaces the prior one. A level expires after its configured lifetime from its source bar.
Long: On a closed bar, close > the active CISD+ reference level AND current bar is later than that level’s source bar.
Short: On a closed bar, close < the active CISD- reference level AND current bar is later than that level’s source bar.
