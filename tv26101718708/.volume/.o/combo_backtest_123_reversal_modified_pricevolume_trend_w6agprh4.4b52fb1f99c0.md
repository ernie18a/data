Calculation: 3-bar reversal state = bullish when close from two bars ago < prior close < current close AND fast stochastic < slow stochastic AND fast stochastic > the level; bearish when close from two bars ago > prior close > current close AND fast stochastic > slow stochastic AND fast stochastic < the level; otherwise retain the prior state. Fast stochastic = stochastic oscillator smoothed over a shorter lookback; slow stochastic = fast stochastic smoothed over a longer lookback.
Calculation: Modified price-volume trend state = bullish when Level + Scale × cumulative sum of (volume / constant × change in OHLC4 / prior OHLC4) is above its moving average; bearish when below; otherwise retain the prior state. OHLC4 = (open + high + low + close) / 4. The moving average uses a longer lookback than the stochastic fast smoothing.
Long: 3-bar reversal state is bullish AND modified price-volume trend state is bullish
Short: 3-bar reversal state is bearish AND modified price-volume trend state is bearish
Exit: long or short, NOT (3-bar reversal state is bullish AND modified price-volume trend state is bullish) AND NOT (3-bar reversal state is bearish AND modified price-volume trend state is bearish)
