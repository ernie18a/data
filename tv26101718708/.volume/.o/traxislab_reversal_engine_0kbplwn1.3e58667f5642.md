Calculation: ATR = average true range
Calculation: Fast EMA slope = (fast EMA now − fast EMA 3 bars ago) / ATR × 100
Calculation: Relative volume = current volume / 20-bar simple moving average of volume
Calculation: Daily VWAP = cumulative (HLC3 × volume) / cumulative volume since the current day began
Calculation: Bullish vector candle = close > open, body / (high − low) ≥ minimum body ratio, and volume × (high − low) / its lookback average ≥ vector threshold
Calculation: Bearish vector candle = close ≤ open, body / (high − low) ≥ minimum body ratio, and volume × (high − low) / its lookback average ≥ vector threshold
Calculation: Confirmed pivot high/low = highest high / lowest low over the pivot lookback, confirmed with one bar to the right
Calculation: Bullish BOS = close crosses above the latest confirmed pivot high; bullish CHoCH = bullish BOS while the stored structure trend is bearish
Calculation: Bearish BOS = close crosses below the latest confirmed pivot low; bearish CHoCH = bearish BOS while the stored structure trend is bullish
Calculation: Per-timeframe direction score = +1 if EMA(21) > EMA(50), −1 if EMA(21) < EMA(50); +1 if close > EMA(200), −1 if close < EMA(200); +1 if RSI(14) > 55, −1 if RSI(14) < 45. Per-timeframe direction is bullish at score ≥ 2, bearish at score ≤ −2, otherwise neutral. Count bullish and bearish directions across the enabled 5-minute, 15-minute, 1-hour, 4-hour, and daily bars; request with lookahead disabled.
Calculation: Long score = capped at 100: add 7 if fast EMA > mid EMA, 5 if close > slow EMA, 3 if fast EMA slope > minimum when slope filtering is enabled; otherwise add 8 when EMA trend filtering is disabled. Add 12 if RSI < oversold threshold, else 5 if RSI < 40; add 8 if stochastic(14) < 20, else 3 if < 35; add 18 for bullish CHoCH, else 10 for bullish BOS; add 12 for bullish engulfing, else 10 for hammer, else 5 if bullish candle body / range > 0.5; add 8 if relative volume exceeds its threshold when volume filtering is enabled, else 5 when disabled; add 8 if close is in the bottom fifth of the recent swing range; add 5 if ADX exceeds its minimum when ADX filtering is enabled, else 3 when disabled; add 5 if close is above daily VWAP and within 0.5 ATR of it; add 4 for bullish vector candle; add 2 per bullish timeframe direction when MTF scoring is enabled.
Calculation: Short score = capped at 100: add 7 if fast EMA < mid EMA, 5 if close < slow EMA, 3 if fast EMA slope < negative minimum when slope filtering is enabled; otherwise add 8 when EMA trend filtering is disabled. Add 12 if RSI > overbought threshold, else 5 if RSI > 60; add 8 if stochastic(14) > 80, else 3 if > 65; add 18 for bearish CHoCH, else 10 for bearish BOS; add 12 for bearish engulfing, else 10 for shooting star, else 5 if bearish candle body / range > 0.5; add 8 if relative volume exceeds its threshold when volume filtering is enabled, else 5 when disabled; add 8 if close is in the top fifth of the recent swing range; add 5 if ADX exceeds its minimum when ADX filtering is enabled, else 3 when disabled; add 5 if close is below daily VWAP and within 0.5 ATR of it; add 4 for bearish vector candle; add 2 per bearish timeframe direction when MTF scoring is enabled.

Short: bearish vector candle OR bearish BOS OR bearish CHoCH OR (short score ≥ configured threshold AND (long qualification is false OR short score > long score) AND absolute difference between long and short scores ≥ configured minimum gap AND bars since prior short signal > configured cooldown AND ADX is not below its minimum when ADX filtering is enabled AND bearish timeframe count meets configured minimum when MTF filtering is enabled AND fast EMA slope < negative configured minimum when slope filtering is enabled AND confirmed bar when confirmation is enabled AND not locked by a recent long AND no active short position)
Short: pending short warning when enabled AND short signal is false AND pending cooldown has elapsed AND short entry gates hold except short score is at least the configured fraction of threshold but below threshold AND short score > long score AND score gap meets configured minimum
