Calculation: Opening range high/low = highest high and lowest low during the configured London or New York opening window, fixed after that window completes.
Calculation: Vector volume ratio = current volume / simple moving average of volume over a lookback.
Calculation: Vector range ratio = current bar high-low / simple moving average of high-low over the same lookback.
Long: After the opening range completes, close > opening range high AND (EMA with shorter lookback > EMA with longer lookback if EMA filter enabled) AND close > VWAP if VWAP filter enabled AND last completed 15-minute close > opening range high if 15-minute confirmation enabled AND last completed 5-minute close > opening range high if 5-minute confirmation enabled AND last completed higher-timeframe EMA with shorter lookback > its longer-lookback EMA if higher-timeframe filter enabled AND opening range size is within configured bounds if range filter enabled AND quality score meets its configured minimum if quality filter enabled AND a confirmed retest of the opening range high has occurred if retest filter enabled AND this is the first long signal of the session if first-signal-only enabled AND daily trade limit is not reached if enabled AND current time is within configured trading windows if enabled; OR close crosses above VWAP; OR close > open AND vector volume ratio >= configured minimum.
Short: After the opening range completes, close < opening range low AND (EMA with shorter lookback < EMA with longer lookback if EMA filter enabled) AND close < VWAP if VWAP filter enabled AND last completed 15-minute close < opening range low if 15-minute confirmation enabled AND last completed 5-minute close < opening range low if 5-minute confirmation enabled AND last completed higher-timeframe EMA with shorter lookback < its longer-lookback EMA if higher-timeframe filter enabled AND opening range size is within configured bounds if range filter enabled AND quality score meets its configured minimum if quality filter enabled AND a confirmed retest of the opening range low has occurred if retest filter enabled AND this is the first short signal of the session if first-signal-only enabled AND daily trade limit is not reached if enabled AND current time is within configured trading windows if enabled; OR close crosses below VWAP; OR close < open AND vector volume ratio >= configured minimum.
Exit: long, low <= entry price - configured stop distance OR high >= entry price + configured target distance (fixed or configured multiple of opening range); close at current close during configured forced-close window if enabled.
Exit: short, high >= entry price + configured stop distance OR low <= entry price - configured target distance (fixed or configured multiple of opening range); close at current close during configured forced-close window if enabled.
