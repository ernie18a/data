Calculation: Bullish engulfing = previous signal-timeframe bar is bearish, current signal-timeframe bar is bullish, and the current body engulfs the previous body (strict: current open ≤ previous close and current close ≥ previous open; loose: current close ≥ previous open and current close > previous close); when enabled, current low < previous low, current body ≥ ATR × minimum ATR multiple, and current body ≥ previous body × minimum body factor.
Calculation: Bearish engulfing = previous signal-timeframe bar is bullish, current signal-timeframe bar is bearish, and the current body engulfs the previous body (strict: current open ≥ previous close and current close ≤ previous open; loose: current close ≤ previous open and current close < previous close); when enabled, current high > previous high, current body ≥ ATR × minimum ATR multiple, and current body ≥ previous body × minimum body factor.
Calculation: Signal-timeframe EMA = EMA of signal-timeframe closes; signal-timeframe EMA slope = current EMA compared with its value at the configured lookback; daily EMA = EMA of daily closes.
Calculation: Entry level = signal-bar high for a long breakout or signal-bar low for a short breakout; for a pullback, long signal-bar high − signal-bar range × pullback percentage, or short signal-bar low + signal-bar range × pullback percentage.
Long: Bullish engulfing AND enabled filters pass (signal-timeframe close > signal-timeframe EMA; signal-timeframe EMA > its value at the configured lookback; signal-timeframe close is within the configured maximum percentage distance of the signal-timeframe EMA; if daily bias is enabled, signal-timeframe close > EMA of the last completed daily bar; if VWAP filter is enabled, selected price > selected session VWAP; if VWAP distance filter is enabled, selected price is within the configured maximum percentage distance of selected session VWAP; if session or weekday filters are enabled, datetime is in an allowed session and weekday) AND, if one-setup-per-trend-phase is enabled, no long signal has occurred in the current phase AND the signal is allowed on the chart timeframe; on a lower chart timeframe, use a newly confirmed signal-timeframe bar and its last completed values; on the signal timeframe, use the confirmed current bar.
Short: Bearish engulfing AND enabled filters pass (signal-timeframe close < signal-timeframe EMA; signal-timeframe EMA < its value at the configured lookback; signal-timeframe close is within the configured maximum percentage distance of the signal-timeframe EMA; if daily bias is enabled, signal-timeframe close < EMA of the last completed daily bar; if VWAP filter is enabled, selected price < selected session VWAP; if VWAP distance filter is enabled, selected price is within the configured maximum percentage distance of selected session VWAP; if session or weekday filters are enabled, datetime is in an allowed session and weekday) AND, if one-setup-per-trend-phase is enabled, no short signal has occurred in the current phase AND the signal is allowed on the chart timeframe; on a lower chart timeframe, use a newly confirmed signal-timeframe bar and its last completed values; on the signal timeframe, use the confirmed current bar.
Long: A pending long setup exists AND (breakout mode: current high ≥ long entry level; pullback mode: current low ≤ long entry level).
Short: A pending short setup exists AND (breakout mode: current low ≤ short entry level; pullback mode: current high ≥ short entry level).
Exit: long, a short entry is triggered.
Exit: short, a long entry is triggered.
