Calculation: Daily Bollinger basis = selected moving average of daily closes over the Bollinger lookback, using the last completed daily bar
Calculation: Z stretch = (bar close, high, or low − daily Bollinger basis) / standard deviation of daily closes over the same Bollinger lookback, using the last completed daily bar
Calculation: ATR stretch = (bar close, high, or low − daily Bollinger basis) / daily ATR, using the last completed daily bar
Long: close-based Z stretch ≤ −Z threshold AND close-based ATR stretch ≤ −ATR stretch threshold
Short: close-based Z stretch ≥ Z threshold AND close-based ATR stretch ≥ ATR stretch threshold
