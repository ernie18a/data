Calculation: Current VARSI = RSI of close changes weighted by each bar’s volume (use weight 1 if volume is unavailable or volume weighting is disabled); average gains and losses with the same selected averaging method and lookback, then calculate 100 − 100/(1 + average gains/average losses), returning 100 if average losses are zero and 0 if average gains are zero. Optionally smooth this result with a moving average.
Calculation: Context VARSI = the same volume-weighted RSI calculation on bars aggregated to a higher timeframe that is a multiple of the chart timeframe, using the same RSI lookback, averaging method, and volume-weighting setting as the current VARSI; use either the forming higher-timeframe bar or the last completed higher-timeframe bar, according to the context-update setting. Do not apply the current VARSI’s optional smoothing.
Long: Current VARSI crosses above 50 OR Current VARSI > 50 AND Context VARSI > 50 AND the previous chart bar did not have both VARSI values > 50
Short: Current VARSI crosses below 50 OR Current VARSI ≤ 50 AND Context VARSI ≤ 50 AND the previous chart bar did not have both VARSI values ≤ 50
