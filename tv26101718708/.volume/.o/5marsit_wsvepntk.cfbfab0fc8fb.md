Calculation: Pivot trendlines = use confirmed pivot highs and lows with equal left/right lookbacks; update the upper line from each pivot high and project it down by the stored slope per bar, and update the lower line from each pivot low and project it up by the stored slope per bar. The slope is selected from ATR/lookback, standard deviation of close/lookback, or the absolute close/index regression covariance divided by index variance and by 2, each multiplied by a slope factor. Store each slope when its corresponding pivot forms.
Long: No new pivot high and close > upper pivot trendline projected down by one lookback, and the prior upper-break state is 0
Short: No new pivot low and close < lower pivot trendline projected up by one lookback, and the prior lower-break state is 0
