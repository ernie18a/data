Calculation: Hurst exponent = clamp(log(variance(close − close[q], L) / max(variance(close − close[1], L), 1e−10)) / (2 × log(q)), 0, 1), using current-timeframe bars.
Calculation: Volume-weighted price = the selected moving average of close × volume over L divided by the same selected moving average of volume over L; VWMA may be selected directly.
Calculation: Adaptive Kalman value = previous value + clamp(base gain × (0.5 + Hurst), 0.01, 0.99) × (volume-weighted price − previous value); initialize to volume-weighted price.
Calculation: Adaptive SuperTrend = recursively maintained upper and lower bands using the adaptive Kalman value ± ATR(L) × (base multiplier + scale × (1 − Hurst)); trend is bullish when the Kalman value exceeds the previous lower band, bearish when it is below the previous upper band, otherwise it retains the previous trend. The bullish band is the maximum of the current lower candidate and previous bullish band; the bearish band is the minimum of the current upper candidate and previous bearish band. Use the band matching the trend as the SuperTrend line.
Calculation: AI score = inverse-distance-weighted average of binary labels for the k nearest of the latest n SuperTrend line values, with distance equal to absolute difference from the current SuperTrend line and weight 1 / (distance + 1e−6). Each stored label is 1 when the shorter WMA of close exceeds the longer WMA of the SuperTrend line, otherwise 0. Before n values are available, score = 0.5.
Calculation: Trend state = 1 when AI score = 1 and trend is bullish; −1 when AI score = 0 and trend is bearish; otherwise set to 0 when the previous state is 1 and (AI score < 0.5 or trend is bearish), or when the previous state is −1 and (AI score > 0.5 or trend is bullish); otherwise retain the previous state.
Long: (AI score = 1 AND previous AI score < 1 AND previous signal direction != 1) OR trend state = 1
Short: (AI score = 0 AND previous AI score > 0 AND previous signal direction != −1) OR trend state = −1
