Calculation: Per-price row delta = accumulated buy volume minus accumulated sell volume; on each close through a positive-delta row from above or a negative-delta row from below, multiply both accumulated volumes by the same remaining-size fraction. In proxy data, classify each lower-timeframe bar as buy when close > open, sell when close < open, and otherwise by close versus the preceding lower-timeframe close (ties keep the prior direction); spread its volume across the price rows it covers. If no lower-timeframe bars are available, split the chart bar's volume between buy and sell by the close's position in its high-low range.
Calculation: Displayed BUY nodes = positive-delta rows at or below the current close; displayed SELL nodes = negative-delta rows at or above the current close. Apply the configured recency filter, merge same-side rows whose total price span fits the configured cluster range, then select the configured number of largest absolute-delta nodes on each side.

Short: current bar's high >= a displayed SELL node's lower bound AND current bar's low <= its upper bound
