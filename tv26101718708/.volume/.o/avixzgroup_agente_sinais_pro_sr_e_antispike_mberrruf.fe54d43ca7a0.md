Calculation: Resistance = highest value in each group of resistance pivot highs within the grouping threshold; retain up to 20 groups, replacing a group's value only with a higher pivot. Support = lowest value in each group of support pivot lows within the grouping threshold; retain up to 20 groups, replacing a group's value only with a lower pivot. Pivots use the analysis-timeframe bars with pivot_len bars on each side, surfaced on the forming analysis-timeframe bar. If enabled, accept a pivot only when its volume is at least volume_mult times the volume SMA of vol_len bars, both measured at the pivot bar.
Calculation: Active resistance = cached resistance groups copied at the start of each day, or current groups if caching is disabled; nearest active resistance = lowest active resistance above close. Active support = cached support groups copied at the start of each day, or current groups if caching is disabled; nearest active support = highest active support below close.
Long: low <= nearest active support AND close >= nearest active support × (1 − anti_spike) AND (live volume filter disabled OR volume >= vol_mult × volume SMA over vol_len bars)
Short: high >= nearest active resistance AND close <= nearest active resistance × (1 + anti_spike) AND (live volume filter disabled OR volume >= vol_mult × volume SMA over vol_len bars)
