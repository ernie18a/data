Use a correlated reference instrument’s candles and daily closing-price moving average. Define a gap up when the current low is above the previous high by at least a minimum gap size, and a gap down when the current high is below the previous low by at least that size; set the minimum as a configurable fraction of the reference instrument’s recent average candle range. Enter long when there is a gap up and the reference close is above its daily moving average; enter short when there is a gap down and the close is below it. Enter only when that same direction is not already open. On a long entry, set a target by extending the entry close upward by the proportional distance from the recent rolling low to that close. Exit the long when an opposite short-entry condition occurs or the reference high exceeds the target. On a short entry, set a target by extending the entry close downward by the proportional distance from that close to the recent rolling high. Exit the short when an opposite long-entry condition occurs or the reference low falls below the target. Optionally reverse the mapping so long signals trade short and short signals trade long.
