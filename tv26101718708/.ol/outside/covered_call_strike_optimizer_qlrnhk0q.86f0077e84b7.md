For covered-call strike selection, at the start of each period project OTM strike candidates from the period open using volatility-scaled ATR, closing-price standard deviation, annualized historical volatility adjusted for the period length, fixed percentage offsets, and the prior period’s high. At each period’s end, measure each candidate’s absolute percentage distance from the actual close and average that error across completed periods. Select the enabled candidate with the lowest historical average error as the primary strike candidate for selling a covered call. The framework provides no separate condition to enter, exit, or buy options.
