Track confirmed swing highs and lows. When price breaks the latest unbroken swing high, classify it as bullish; when it breaks the latest unbroken swing low, classify it as bearish. A break may require a close beyond the level or allow a wick beyond it, according to the selected setting. Create a long signal only when a bullish break follows a bearish structural break, and a short signal only when a bearish break follows a bullish structural break. Accept the signal only if all enabled filters pass: directional alignment with session VWAP and/or an EMA, minimum relative volume, signal-candle range within configured ATR bounds, bar-close confirmation, and minimum spacing since the last accepted zone. Same-direction breaks update structural direction but do not create another signal. No exit rule is defined.
