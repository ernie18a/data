On each confirmed bar, measure the close’s position within the recent high–low range and derive directional strength from its distance from the range midpoint. Generate a bullish event when positive direction crosses into either configured strength tier from below, or a bearish event when negative direction crosses into either tier from below. If enabled, allow bullish events only above the long-term EMA and bearish events only below the shorter-term EMA. Emit a buy only when the stored trend is not already bullish, and a sell only when it is not already bearish; initialize the trend reference at the recent range low for a buy or high for a sell. Clear the stored trend after its configured hold period, without emitting an exit signal. The cotangent state does not affect trade signals.
