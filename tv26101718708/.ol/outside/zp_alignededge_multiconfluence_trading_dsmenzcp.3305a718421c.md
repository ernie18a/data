On each confirmed bar, track the latest confirmed swing high and low. A close crossing above the latest swing high sets the bullish-break state and clears the bearish state; a close crossing below the latest swing low sets the bearish-break state and clears the bullish state. While the bullish state is active, signal long when either the fast EMA crosses above the medium EMA or the medium EMA crosses above a longer-period weighted moving average, provided the selected higher-timeframe trend is bullish: its fast, medium, and slow EMAs are stacked in ascending order. While the bearish state is active, signal short when either the fast EMA crosses below the medium EMA or the medium EMA crosses below the longer-period weighted moving average, provided the selected higher-timeframe trend is bearish, with those EMAs stacked in descending order. The higher-timeframe filter can be disabled; when enabled, assess it using the last completed higher-timeframe bar. There is no exit rule.
