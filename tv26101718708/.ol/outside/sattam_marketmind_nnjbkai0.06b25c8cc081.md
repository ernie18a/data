Build Heikin-Ashi candles and ATR, then calculate fast and slow SuperTrend directions from them. In either flip mode, signal long when the selected trend changes from down to up and short when it changes from up to down. In breakout-filter mode, signal long when the trend is up and price breaks above the prior lookback high, or short when the trend is down and price breaks below the prior lookback low; alternate directions so consecutive signals cannot repeat the same side. Optionally block either signal during the configured news blackout. Optionally apply the macro filter: when the selected dollar index and/or Treasury yield is above its moving average, block longs; when it is not above, block shorts (with both sources selected, block longs only when both are above and shorts only when both are not above). Separately, during an existing uptrend, signal a continuation long on an early-run bullish Heikin-Ashi candle whose body meets configured strength thresholds and whose lower wick is short; during a downtrend, apply the mirrored bearish-candle rule using its upper wick. Enforce the configured minimum gap between confirmation signals and suppress confirmations adjacent to a primary signal. The script calculates and displays stop, target, pullback-entry, and trailing-stop levels, but does not issue exit decisions.
