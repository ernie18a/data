When flat, enter long if enabled and the selected fast moving average crosses above the selected medium moving average. If enabled, require the candle to close above a selected slower moving average and/or require the momentum line to cross above its signal line on that same bar; an optional filter requires the momentum line to be above or below zero, or allows either. Enter short by the mirrored rules: fast average crosses below medium, close below the slower average, and/or momentum line crosses below its signal line, with the same optional zero-line filter. While in a position, exit on an adverse cross of the selected exit averages, once the maximum holding-bar count is reached, or when price reaches the ATR-based stop-loss or take-profit level set from entry price and ATR captured at entry. Apply only the enabled direction and confirmation and exit rules.
