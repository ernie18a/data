Use the previous completed higher-timeframe bar’s high, low, and close to calculate the Central Pivot Range (CPR). On an enabled weekday and within the configured date range, buy a call when the selected price crosses above the CPR top, or buy a put when it crosses below the CPR bottom, subject to the configured option-type restriction. Suppress a signal if that option type is already held. A qualifying opposite-type signal exits the existing position and enters the new one; otherwise, no exit is specified. Select the call and put strikes using the configured pivot or resistance/support method, rounding calls up and puts down to the selected strike interval.
