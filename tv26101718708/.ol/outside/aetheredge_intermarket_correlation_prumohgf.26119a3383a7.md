On each confirmed bar, update an online linear regression that predicts the traded instrument’s next-bar return from standardized prior-bar returns of up to six reference markets and the instrument’s own prior-bar momentum. After the model has completed its warmup, go long when the predicted return exceeds a positive volatility-scaled threshold; go short when it falls below the corresponding negative threshold; otherwise remain flat. Emit signals when the bias changes into long or short. No separate exit rule is specified.
