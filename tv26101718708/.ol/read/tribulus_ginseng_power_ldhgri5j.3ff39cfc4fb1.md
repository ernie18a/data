Calculation: Local swing-break bullish event = after a confirmed swing high or low, close crosses above the stored swing high or below the stored swing low, respectively.
Calculation: Local pivot-trend bullish event = after a confirmed pivot high, close crosses above its descending line; local pivot-trend bearish event = after a confirmed pivot low, close crosses below its rising line. Each line advances by the latest slope estimate per bar, using the selected ATR, standard-deviation, or linear-regression slope method.
Calculation: Local paired swing-long event = a local swing-break bullish event and a local pivot-trend bullish event occur in either order within 12 bars; paired swing-short event = the corresponding bearish events occur in either order within 12 bars.
Calculation: Local momentum event = following a pump bar (volume above its threshold on the chart), the first valid reversal event is bearish when the reversal uses a bearish Monalisa/UT confirmation, or bullish when it uses a bullish Monalisa/UT confirmation; after that first event, the next valid reversal event uses the opposite confirmation, then the pump phase resets. A Monalisa/UT confirmation requires either a Monalisa envelope cross with matching UT direction or a UT direction change matching the last Monalisa envelope cross; liquidity-sweep recency and ADX filters apply when enabled.
Calculation: Local bullish ULT event = a local momentum bullish event and a local paired swing-long event occur in either order within 16 bars; local bearish ULT event = a local momentum bearish event and a local paired swing-short event occur in either order within 16 bars.
Calculation: Total-market bullish ULT event and dominance bullish ULT event = the corresponding bullish ULT event calculated on CRYPTOCAP:TOTAL and CRYPTOCAP:BTC.D bars, respectively; bearish events are calculated the same way. These use bars at the chart timeframe.
Calculation: Recent event = the event occurred on the current bar or within the macro alignment lookback.
Long: Local bearish ULT event AND (Recent total-market bearish ULT event AND Recent dominance bearish ULT event OR Recent total-market bearish ULT event AND Recent dominance bullish ULT event OR Recent total-market bearish ULT event AND Recent dominance bearish ULT event began aligning on this bar while the local long condition is false) AND no enabled long-blocking RSI, MACD, or ATR filter is true.
Short: Local bullish ULT event AND (Recent total-market bullish ULT event AND Recent dominance bullish ULT event OR Recent total-market bullish ULT event AND Recent dominance bearish ULT event OR Recent total-market bullish ULT event AND Recent dominance bullish ULT event began aligning on this bar while the local short condition is false) AND no enabled short-blocking RSI, MACD, or ATR filter is true.
Exit: Long, short-entry condition.
Exit: Short, long-entry condition.
