Calculation: Bull strength = 0 if RSI > 70; otherwise sum 1 for each true condition: RSI rising, −DI falling, close below the Bollinger basis and above the lower Bollinger Band, close below the lower Keltner Channel, Bollinger Bands outside the Keltner Channels (lower BB < lower KC AND upper BB > upper KC), lowest low over the last 5 bars <= current lower BB, ADX rising, RSI < 30.
Calculation: Bear strength = 0 if RSI < 30; otherwise the negative of the sum of 1 for each true condition: RSI falling, +DI rising, close above the Bollinger basis and below the upper Bollinger Band, close above the upper Keltner Channel, Bollinger Bands outside the Keltner Channels (lower BB < lower KC AND upper BB > upper KC), highest high over the last 5 bars >= current upper BB, ADX falling, RSI > 70.
Calculation: Market daily change (%) = (current daily close − prior completed daily close) / prior completed daily close × 100; use the current daily bar (still forming when daily is higher than the chart timeframe) and the prior completed daily bar.
Long: Bull strength > 0 OR (close < Bollinger basis AND Bull strength >= configured signal-strength threshold AND market daily change is below the configured hot threshold AND above the configured cold threshold AND entry price <= signal-bar close)
Short: Bear strength < 0
Exit: long, bars since entry >= configured holding-period threshold AND weekday = Thursday
