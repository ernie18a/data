Calculation: CVD Delta = Sum of lower-timeframe volume multiplied by the sign of each lower-timeframe close minus its prior close, over the current chart bar; use lower-timeframe bars available within the chart bar, including any still forming.
Calculation: CVD Acceleration = Current CVD Delta minus the prior chart bar's CVD Delta.
Long: Selected histogram value (CVD Delta or CVD Acceleration) >= 0
Short: Selected histogram value (CVD Delta or CVD Acceleration) < 0
