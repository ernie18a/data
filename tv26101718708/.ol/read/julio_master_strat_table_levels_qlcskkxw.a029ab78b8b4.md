Calculation: Strat bar type = inside if high <= previous high and low >= previous low; else outside if high > previous high and low < previous low; else bullish 2U if close > open; else bearish 2D if close < open; else neutral
Calculation: Higher-timeframe midpoint = (high + low) / 2 of the previous completed bar
Long: Strat bar type = bullish 2U on the chart bar or on a current or displayed higher-timeframe bar
Short: Strat bar type = bearish 2D on the chart bar or on a current or displayed higher-timeframe bar
Long: close >= each higher-timeframe midpoint
Short: close < each higher-timeframe midpoint
