Calculation: compressed score = featComp × (corr(F1, close−close[5], lookback)×F1 + corr(F3, close−close[5], lookback)×F3 + corr(F4, close−close[5], lookback)×F4 + corr(F5, close−close[5], lookback)×F5 + corr(F6, close−close[5], lookback)×F6) + (1−featComp)×F1; use 0 for missing correlations. F1 = clip((close−SMA(close, 20))/ATR(20), −3, 3); F3 = clip((volume/(SMA(volume, 20)+1e−10))×sign(close−open), −3, 3); F4 = 0.5×(HTF1 close > HTF1 EMA(close, 20) ? 1 : −1) + 0.5×(HTF2 close > HTF2 EMA(close, 20) ? 1 : −1), using the latest completed bars of both higher timeframes; F5 = (RSI(close, 14)−50)/50; F6 = clip(ROC(close, 10)/stdev(ROC(close, 10), 50), −3, 3), or 0 when the standard deviation is zero. Correlations use the chart timeframe.
Calculation: probability = initialize at 0.5; each bar, form a memory of up to lookback samples, each containing compressed score from 5 bars earlier and label +1 if current close > close[5], −1 if current close < close[5], otherwise 0. When memory has at least kNeighbors samples, average the labels of the kNeighbors samples with smallest absolute score distance from the current compressed score; otherwise vote = 0. Convert vote to raw probability 1/(1+exp(−2.5×vote)); update probability = previous probability + adaptRate×(raw probability−previous probability).
Long: probability >= high probability threshold AND previous bar probability < high probability threshold
Short: probability <= low probability threshold AND previous bar probability > low probability threshold
