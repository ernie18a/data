Calculation: CPR upper/lower bounds = for each CPR period, use the previous completed bar on a timeframe higher than the chart: pivot = (high + low + close) / 3, bottom = (high + low) / 2, top = 2 × pivot − bottom; upper = max(top, bottom), lower = min(top, bottom).
Calculation: Dominant zigzag pivot = within the current uninterrupted zigzag-direction run, the highest pivot high when direction is up, or the lowest pivot low when direction is down. A pivot high/low occurs when the bar is the highest high/lowest low over the lookback; direction changes to up for a pivot high alone, down for a pivot low alone, and otherwise persists. If both occur, use the pivot selected by the current direction.
Calculation: Consolidation bounds = after the consolidation count first reaches the minimum length, set the high and low to the highest high and lowest low over that length; while the count remains above the minimum, extend the bounds to include each bar's high and low. The count increments each bar without a dominant-pivot change; on a change, increment it if the new pivot is within the bounds, otherwise reset it to zero.
Long: Current close on a higher timeframe bar still forming > that timeframe's CPR upper bound OR dominant zigzag pivot changes and consolidation count > minimum length and dominant zigzag pivot > consolidation high.
Short: Current close on a higher timeframe bar still forming < that timeframe's CPR lower bound OR dominant zigzag pivot changes and consolidation count > minimum length and dominant zigzag pivot < consolidation low.
