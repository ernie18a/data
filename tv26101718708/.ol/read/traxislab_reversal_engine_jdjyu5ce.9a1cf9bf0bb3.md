Calculation: Bullish BOS = close crosses above the latest confirmed pivot high; bearish BOS = close crosses below the latest confirmed pivot low. Bullish CHoCH = bullish BOS while the prior structure trend is bearish; bearish CHoCH = bearish BOS while it is bullish.
Calculation: Bullish candle patterns = bullish engulfing, else hammer, else bullish candle with body/range > 0.6. Bearish candle patterns = bearish engulfing, else shooting star, else bearish candle with body/range > 0.6. A hammer has lower wick > 2× body and upper wick < 0.5× body; a shooting star has upper wick > 2× body and lower wick < 0.5× body. Engulfing requires the current candle’s body to engulf the prior candle’s body.
Calculation: Near support/resistance = close is in the bottom/top 20% of the range between the lowest low and highest high over twice the pivot lookback.
Calculation: Long score = add 8 if fast EMA > medium EMA (or 8 if the EMA trend filter is disabled); add 7 if close > slow EMA; add 15 if RSI < oversold threshold, else 5 if RSI < 40; add 10 if Stochastic %K < 20, else 4 if %K < 35; add 20 for bullish CHoCH, else 12 for bullish BOS; add 15 for bullish engulfing, else 12 for hammer, else 6 for a bullish candle with body/range > 0.6; add 10 if volume > 1.1× its 20-bar average (or 5 if the volume filter is disabled); add 10 near support; add 5 if ADX > its minimum (or 3 if the ADX filter is disabled). Cap at 100.
Calculation: Short score = add 8 if fast EMA < medium EMA (or 8 if the EMA trend filter is disabled); add 7 if close < slow EMA; add 15 if RSI > overbought threshold, else 5 if RSI > 60; add 10 if Stochastic %K > 80, else 4 if %K > 65; add 20 for bearish CHoCH, else 12 for bearish BOS; add 15 for bearish engulfing, else 12 for shooting star, else 6 for a bearish candle with body/range > 0.6; add 10 if volume > 1.1× its 20-bar average (or 5 if the volume filter is disabled); add 10 near resistance; add 5 if ADX > its minimum (or 3 if the ADX filter is disabled). Cap at 100.
Long: Long score ≥ signal threshold AND bars since prior long signal > cooldown AND (ADX filter disabled OR ADX ≥ its minimum)
Short: Short score ≥ signal threshold AND bars since prior short signal > cooldown AND (ADX filter disabled OR ADX ≥ its minimum)
