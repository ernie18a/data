Calculation: Quantum class probabilities = for each of the three features, sum Gaussian amplitudes with class targets +1, −1, and 0 and phase offsets 0, π/6, and π/3; square and sum each class's real and imaginary amplitudes, normalize across classes, then blend each probability with 1/3.
Calculation: K-nearest-neighbor class probabilities = distance-weighted class shares (weight 1/(1+Euclidean distance)) among the nearest K historical three-feature vectors; each historical label is UP if its forward return over the forecast horizon exceeds the positive move threshold, DOWN if below its negative, and SIDE otherwise. Use only samples whose forecast horizon has completed.
Calculation: Neural class probabilities = three-class softmax of linear scores on the three features; update weights and biases online from completed-horizon labels by cross-entropy gradient descent with weight decay.
Calculation: UP, DOWN, and SIDE probabilities = normalized weighted averages of the corresponding quantum, K-nearest-neighbor, and neural class probabilities.
Calculation: Dominant state = UP if UP probability is at least both others, otherwise DOWN if DOWN probability is at least both others, otherwise SIDE; dominant probability = maximum class probability.
Calculation: Confidence = 1 − entropy(UP, DOWN, SIDE probabilities)/ln(3).
