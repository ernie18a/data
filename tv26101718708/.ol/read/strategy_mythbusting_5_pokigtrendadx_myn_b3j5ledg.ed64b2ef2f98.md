Calculation: POKI oscillator = assign a synthetic close each bar: current close if it exceeds the previous synthetic close by more than the brick size, current close if it falls below the previous synthetic close by more than the brick size, otherwise keep the previous synthetic close; use a fixed traditional brick size and close prices. Direction is up or down when the synthetic close rises or falls, otherwise retain the previous direction. The oscillator is positive volume accumulated since the last direction change when direction is up, and negative accumulated volume when direction is down.
Calculation: G-Channel bullish state = recursively calculate upper = max(OHLC4, previous upper) − (previous upper − previous lower) / lookback, and lower = min(OHLC4, previous lower) + (previous upper − previous lower) / lookback. Define a lower-line crossing as previous lower < previous close AND current lower > current close; define an upper-line crossing as previous upper < previous close AND current upper > current close. The state is bullish when bars since the lower-line crossing ≤ bars since the upper-line crossing.
Long: POKI oscillator crosses above 0 AND G-Channel bullish state AND ADX > threshold
Short: POKI oscillator crosses below 0 AND NOT G-Channel bullish state AND ADX > threshold
Exit: Long, close < entry price × (1 − stop-loss percentage) OR high ≥ entry price × (1 + any configured take-profit percentage)
Exit: Short, close > entry price × (1 + stop-loss percentage) OR low ≤ entry price × (1 − any configured take-profit percentage)
