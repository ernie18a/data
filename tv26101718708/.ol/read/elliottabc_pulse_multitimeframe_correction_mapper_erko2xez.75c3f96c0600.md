Calculation: Confirmed swing pivots = chart-timeframe pivot highs and lows confirmed after the configured right bars; retain a pivot only if its distance from the confirmation bar close meets the minimum swing-size percentage, and for consecutive pivots of the same type keep only the more extreme one.
Calculation: Wave A length = absolute price distance from pivot 0 to pivot 1; B retracement = distance from pivot 1 to pivot 2 divided by Wave A length; C extension = distance from pivot 2 to pivot 3 divided by Wave A length.
Long: The latest newly confirmed pivot completes four consecutive alternating pivots in low-high-low-high order AND B retracement is between the configured minimum and maximum inclusive AND C extension is between the configured minimum and maximum inclusive AND pivot 3 is above pivot 1 AND pivot 2 is above pivot 0
Short: The latest newly confirmed pivot completes four consecutive alternating pivots in high-low-high-low order AND B retracement is between the configured minimum and maximum inclusive AND C extension is between the configured minimum and maximum inclusive AND pivot 3 is below pivot 1 AND pivot 2 is below pivot 0
