Calculation: Adaptive composite oscillator = Compute ATR and its simple moving average over the same volatility lookback; set adaptive length to base momentum length divided by max(ATR / ATR average, 0.25), clamped between 3 and three times the base momentum length. From close-to-close gains and losses, recursively smooth each with alpha 2 / (adaptive length + 1), initializing each average with the first gain or loss; compute RSI as 100 when average loss is zero, otherwise 100 − 100 / (1 + average gain / average loss). Smooth RSI with a KAMA-style recursion: efficiency ratio is the absolute RSI change over the base momentum length divided by the sum of absolute RSI changes over that same lookback (zero if the sum is zero); square the interpolation between fast and slow smoothing constants 2 / (constant + 1) using that ratio, then apply it to the change from the prior smoothed value to current RSI, initializing with RSI. Z-score the smoothed RSI against its rolling mean and standard deviation over the normalization window (zero if standard deviation is zero).
