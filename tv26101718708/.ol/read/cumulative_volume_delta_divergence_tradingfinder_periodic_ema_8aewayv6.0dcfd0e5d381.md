Calculation: Cumulative volume delta histogram = the rolling sum or exponential moving average, according to the selected mode, of per-bar delta; per-bar delta is volume × (2 × close − high − low) / (high − low), or zero when high equals low.
Calculation: Trend-qualified pivot low/high = a confirmed pivot low/high using the same lookback on each side, where close at the pivot bar is below/above the current bar’s exponential moving average of close.
Long: The latest two trend-qualified pivot lows are less than the configured maximum number of bars apart, the latest is within that maximum age, the latest low is lower than the prior low by more than the configured minimum price difference, both histogram values at the pivots are below zero, and the latest histogram value is higher than the prior value
Short: The latest two trend-qualified pivot highs are less than the configured maximum number of bars apart, the latest is within that maximum age, the latest high is higher than the prior high by more than the configured minimum price difference, both histogram values at the pivots are above zero, and the latest histogram value is lower than the prior value
