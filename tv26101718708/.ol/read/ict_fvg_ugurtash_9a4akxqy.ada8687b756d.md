Calculation: Bullish implied FVG = newest high > oldest high, oldest low < newest low <= oldest high, oldest high - max(oldest open, oldest close) > (oldest body size)/2, min(newest open, newest close) - newest low > (newest body size)/2, newest low > middle low, (oldest high + max(oldest open, oldest close))/2 < (min(newest open, newest close) + newest low)/2, newest high > middle high, and middle close > middle open
Calculation: Bearish implied FVG = newest low < oldest low, oldest high > newest high >= oldest low, min(oldest open, oldest close) - oldest low > (oldest body size)/2, newest high - max(newest open, newest close) > (newest body size)/2, newest high < middle high, (min(oldest open, oldest close) + oldest low)/2 > (newest high + max(newest open, newest close))/2, newest low < middle low, and middle close < middle open
Calculation: Volume imbalance = one of the following adjacent-bar conditions: bullish type 1, current open > prior close, current low <= prior high, both closes > their opens; bearish type 1, current open < prior close, current high >= prior low, both closes < their opens; bullish type 2, current open < prior close, current close > current open, prior close > prior open, current high >= prior low; bearish type 2, current open > prior close, current close < current open, prior close < prior open, current low <= prior high; bullish type 3, current open != prior close, current close > current open, prior close < prior open, current high >= prior low, current low <= prior high; bearish type 3, current open != prior close, current close < current open, prior close > prior open, current low <= prior high, current high >= prior low
Calculation: Bullish order block = close breaks above the latest unbroken confirmed swing high; its zone is the lowest-low candle between that swing and breakout, using the full range by default (or candle body if configured). A confirmed swing high is identified when the high N bars ago exceeds the highest high of the latest N bars, and is accepted when the swing-state changes to high. Each swing can trigger once.
Calculation: Bearish order block = close breaks below the latest unbroken confirmed swing low; its zone is the highest-high candle between that swing and breakout, using the full range by default (or candle body if configured). A confirmed swing low is identified when the low N bars ago is below the lowest low of the latest N bars, and is accepted when the swing-state changes to low. Each swing can trigger once.
