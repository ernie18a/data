Calculation: Confirmed swing high/low = a pivot high/low confirmed after the selected number of right-side chart bars has closed; it becomes usable only on its confirmation bar.
Calculation: Structure state = bullish when a confirmed bar closes above the latest unbroken confirmed swing high, bearish when it closes below the latest unbroken confirmed swing low, otherwise retain the prior state; each swing level can be broken only once.
Calculation: ATR trend direction = Supertrend direction, bullish when its direction is bullish and fast EMA is above slow EMA, bearish when its direction is bearish and fast EMA is below slow EMA; the two EMAs use different lengths, with the fast length shorter.
Calculation: Flow bias = persistent confirmed state. Set bullish on a bullish structure break with bullish ATR trend, or when structure is bullish and the fast EMA crosses above the slow EMA with bullish ATR trend; set bearish by the inverse rules. If bias is neutral, initialize it from a matching structure state and ATR trend. Otherwise retain the prior bias.
Calculation: Normalized momentum = (shorter-length EMA of close − longer-length EMA of close) / ATR; momentum signal = EMA of normalized momentum.
Calculation: Bullish momentum = shorter-length EMA > longer-length EMA AND normalized momentum > 0 AND normalized momentum > momentum signal. Bearish momentum is the inverse.
Calculation: Dealing range = highest high and lowest low over a rolling lookback; discount boundary = range low + range width × discount fraction; premium boundary = range high − range width × premium fraction.
Calculation: Active order block = the zone made from the nearest prior opposing candle found within a lookback after a same-direction confirmed structure break or qualifying displacement. Candidate candles must meet configured minimum range relative to ATR and minimum body percentage, and any enabled volume filter. The zone uses either the candle wick range or body range as configured; reject it if price already mitigated it between that candle and the trigger. A bullish zone is active until its configured mitigation test closes or wicks below its bottom, expires by age, or is removed by the zone limit; bearish zones use the inverse rules.
Calculation: Order block touch = current chart bar's high is at or above an active zone's bottom AND its low is at or below that zone's top; the zone must match the direction and the bar must be after its creation.
Calculation: Long confluence score = 25 if flow bias is bullish + 15 if structure state is bullish + 15 if bullish momentum + 25 if a bullish order block is touched + 20 if close is at or below the discount boundary; absent conditions contribute 0.
Calculation: Short confluence score = 25 if flow bias is bearish + 15 if structure state is bearish + 15 if bearish momentum + 25 if a bearish order block is touched + 20 if close is at or above the premium boundary; absent conditions contribute 0.
Long: On a confirmed chart bar, flow bias changes to bullish OR normalized momentum crosses above its signal OR (flow bias is bullish AND structure state is bullish AND (active bullish order block is touched if required) AND (close is at or below the discount boundary if required) AND (bullish momentum if required) AND long confluence score ≥ configured minimum AND these complete requirements were false on the prior bar AND the configured cooldown since the prior long signal has elapsed).
Short: On a confirmed chart bar, flow bias changes to bearish OR normalized momentum crosses below its signal OR (flow bias is bearish AND structure state is bearish AND (active bearish order block is touched if required) AND (close is at or above the premium boundary if required) AND (bearish momentum if required) AND short confluence score ≥ configured minimum AND these complete requirements were false on the prior bar AND the configured cooldown since the prior short signal has elapsed).
