Calculation: Non-commercial net = reported non-commercial long contracts − reported non-commercial short contracts, from weekly CFTC COT data.
Calculation: Commercial net = reported commercial long contracts − reported commercial short contracts, from weekly CFTC COT data.
Calculation: COT index = 100 × (current net − lowest net in the lookback) ÷ (highest net − lowest net); use the same weekly COT bars, with the short-term lookback shorter than the 52-week lookback and the long-term lookback longer than it.
Calculation: Net-position change = current non-commercial net − previous weekly non-commercial net.
Calculation: Flip% = 100 × non-commercial net ÷ open interest.
Calculation: Weekly open-interest change = 100 × (current open interest − previous weekly open interest) ÷ previous weekly open interest.
Calculation: Net-change streak = count consecutive weekly non-commercial net changes with the same nonzero sign, positive for increases and negative for decreases.
Calculation: Flip age = number of weekly bars since Flip% last changed sign; zero if its current sign has not changed within the lookback.
Long: 52-week non-commercial COT index ≤ 20 AND 52-week commercial COT index ≥ 80 OR 52-week non-commercial COT index ≥ 55 AND Flip% > 0 AND net-position change > 0 OR 52-week non-commercial COT index > 50 AND net-position change > 0 OR (52-week non-commercial COT index ≤ 10 AND 52-week commercial COT index ≥ 90) OR (52-week non-commercial COT index ≤ 25 AND net-position change > 0 AND net-change streak ≥ 2) OR (Flip age ≤ 4 AND Flip% ≥ 0) OR (net-change streak ≥ 4 AND weekly open-interest change > 0) OR (weekly open-interest change < 0 AND net-position change > 0 AND 52-week non-commercial COT index < 50) OR (long-term COT index ≥ 70 AND short-term COT index ≤ 30).
Short: 52-week non-commercial COT index ≥ 80 AND 52-week commercial COT index ≤ 20 OR 52-week non-commercial COT index ≤ 45 AND Flip% < 0 AND net-position change < 0 OR 52-week non-commercial COT index < 50 AND net-position change < 0 OR (52-week non-commercial COT index ≥ 90 AND 52-week commercial COT index ≤ 10) OR (52-week non-commercial COT index ≥ 75 AND net-position change < 0 AND net-change streak ≤ −2) OR (Flip age ≤ 4 AND Flip% < 0) OR (net-change streak ≤ −4 AND weekly open-interest change > 0) OR (weekly open-interest change < 0 AND net-position change < 0 AND 52-week non-commercial COT index > 50) OR (long-term COT index ≤ 30 AND short-term COT index ≥ 70).
Exit: Long, 52-week non-commercial COT index ≥ 80 AND 52-week commercial COT index ≤ 20.
Exit: Short, 52-week non-commercial COT index ≤ 20 AND 52-week commercial COT index ≥ 80.
