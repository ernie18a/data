Calculation: MACD histogram = MACD line minus signal line; MACD line = shorter-lookback EMA of higher-timeframe close minus longer-lookback EMA of higher-timeframe close; signal line = EMA of MACD line using a shorter lookback than the MACD line lookbacks. Use the higher-timeframe bar value revealed from the future on historical bars (lookahead on), and the developing higher-timeframe bar in real time.
Calculation: MACD histogram state = rising above zero → rising-positive; falling above zero → falling-positive; falling at or below zero → falling-nonpositive; rising at or below zero → rising-nonpositive. If the histogram is unchanged, carry forward the previous state.
Long: datetime >= configured start datetime AND datetime <= configured end datetime AND (MACD histogram state is rising-nonpositive OR MACD histogram state is rising-positive)
Short: datetime >= configured start datetime AND datetime <= configured end datetime AND MACD histogram state is falling-positive
Exit: Long, datetime >= configured start datetime AND datetime <= configured end datetime AND MACD histogram state is falling-nonpositive AND previous higher-timeframe MACD histogram state is rising-nonpositive
