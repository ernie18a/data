Calculation: Fast and slow entry averages = simple moving averages of chart-timeframe close, with fast lookback shorter than slow; use completed chart bars.
Calculation: Higher-timeframe signal lines = ALMA, fast linear regression, and slow linear regression of close; fast regression lookback is shorter than slow regression lookback. Use the last completed higher-timeframe bar.
Calculation: Higher-timeframe trend line = DEMA of close with a longer timeframe than the signal lines; use the last completed bar.
Calculation: Chart EMA = exponential moving average of chart-timeframe close; use completed chart bars.
Calculation: Higher-timeframe stochastic = stochastic of high, low, and close on the trend timeframe, smoothed by two successive short simple moving averages; use the last completed trend-timeframe bar.
Calculation: Chart stochastic = stochastic of high, low, and close, smoothed by two successive short simple moving averages; use completed chart bars.
Calculation: Higher-timeframe ALMA Z-score = (ALMA − its longer-lookback simple moving average) / standard deviation of that difference over the same lookback; use the last completed signal-timeframe bar.
Calculation: Rise/fall event = since ALMA crossed above/below fast linear regression, the favorable/adverse chart-close movement from the close at that cross, normalized by minimum tick size and the configured price normalizer, meets its minimum net-change threshold and its net change divided by elapsed chart bars meets its minimum rate threshold.
Calculation: EMA rise/fall event = since chart EMA crossed above/below higher-timeframe ALMA, the favorable/adverse chart-close movement from the close at that cross, normalized by minimum tick size and the configured price normalizer, meets its minimum net-change threshold and its net change divided by elapsed chart bars meets its minimum rate threshold.
Long: fast entry average crosses above slow entry average AND (chart close > higher-timeframe trend line AND mode is not Range OR long nascent entry is enabled AND higher-timeframe ALMA > slow linear regression AND fast linear regression > slow linear regression AND slow linear regression < trend line).
Short: fast entry average crosses below slow entry average AND (chart close < higher-timeframe trend line AND mode is not Range OR short nascent entry is enabled AND higher-timeframe ALMA < slow linear regression AND fast linear regression < slow linear regression AND slow linear regression > trend line).
Long: higher-timeframe ALMA > fast linear regression AND rise event.
Short: higher-timeframe ALMA < fast linear regression AND fall event.
Long: chart EMA > higher-timeframe ALMA AND EMA rise event.
Short: chart EMA < higher-timeframe ALMA AND EMA fall event.
Long: higher-timeframe fast linear regression > slow linear regression AND ((chart EMA > ALMA AND ALMA > fast linear regression AND fast linear regression > slow linear regression AND higher-timeframe fast stochastic D > overbought threshold) OR (chart EMA > ALMA AND ALMA > slow linear regression AND fast linear regression > slow linear regression AND slow linear regression > trend line AND higher-timeframe slow stochastic D > higher overbought threshold) OR (chart EMA > ALMA AND ALMA > slow linear regression AND fast linear regression > slow linear regression AND higher-timeframe fast stochastic D > higher overbought threshold AND chart close > most recent rise-event close)).
Short: higher-timeframe fast linear regression < slow linear regression AND ((chart EMA < ALMA AND ALMA < fast linear regression AND fast linear regression < slow linear regression AND higher-timeframe fast stochastic D < oversold threshold) OR (chart EMA < ALMA AND ALMA < slow linear regression AND fast linear regression < slow linear regression AND slow linear regression < trend line AND higher-timeframe slow stochastic D < lower oversold threshold) OR (chart EMA < ALMA AND ALMA < slow linear regression AND fast linear regression < slow linear regression AND higher-timeframe fast stochastic D < lower oversold threshold AND chart close < most recent fall-event close)).
Exit: Long, position profit meets the minimum profit threshold AND (higher-timeframe ALMA < fast linear regression OR (higher-timeframe ALMA > fast linear regression AND rise event AND higher-timeframe Z-score has reached its positive threshold) OR (EMA rise event AND chart EMA > ALMA AND ALMA > fast linear regression AND chart EMA > trend line AND ALMA > trend line) OR long stochastic condition above).
Exit: Short, position profit meets the minimum profit threshold AND (higher-timeframe ALMA > fast linear regression OR (higher-timeframe ALMA < fast linear regression AND fall event AND higher-timeframe Z-score has reached its negative threshold) OR (EMA fall event AND chart EMA < ALMA AND ALMA < fast linear regression AND chart EMA < trend line AND ALMA < trend line) OR short stochastic condition above).
Exit: Long, chart low at entry − stop offset is breached.
Exit: Short, chart high at entry + stop offset is breached.
Exit: Long, bale-out enabled AND chart close > trend line AND long stochastic condition above AND ALMA > slow linear regression AND fast linear regression > slow linear regression AND slow linear regression > trend line AND open profit > twice the minimum-profit amount multiplied by position size.
Exit: Short, bale-out enabled AND chart close < trend line AND EMA fall event AND chart EMA < ALMA AND ALMA < fast linear regression AND chart EMA < trend line AND ALMA < trend line AND slow linear regression < trend line AND open profit > twice the minimum-profit amount multiplied by position size.
Exit: Long, Flip Flop mode AND chart close < entry price AND EMA fall event AND chart EMA < ALMA AND ALMA < fast linear regression AND chart EMA < trend line AND ALMA < trend line AND slow linear regression < trend line AND ((nascent entry AND hemi-transit) OR (nascent entry AND ALMA < slow linear regression AND fast linear regression < slow linear regression AND fall event AND long accumulation disabled) OR (entry trend direction is up AND not nascent entry AND long-only mode disabled)).
Exit: Short, Flip Flop mode AND chart close > entry price AND EMA rise event AND chart EMA > ALMA AND ALMA > fast linear regression AND chart EMA > trend line AND ALMA > trend line AND slow linear regression > trend line AND ((nascent entry AND hemi-transit) OR (nascent entry AND ALMA > slow linear regression AND fast linear regression > slow linear regression AND rise event AND short accumulation disabled) OR (entry trend direction is down AND not nascent entry AND short-only mode disabled)).
