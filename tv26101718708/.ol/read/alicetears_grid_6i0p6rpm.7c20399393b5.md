Calculation: Baseline = open of the session-start bar when a custom session is enabled; otherwise, the open of the current daily bar (higher timeframe, still forming)
Calculation: Grid level = Baseline × (1 ± step percentage × level index), where the index is a positive integer
Calculation: Stop-loss level = entry grid level ± (entry grid level × step percentage × stop multiplier), subtracting for longs and adding for shorts
Calculation: Trailing stop = stop offset from the favorable price extreme by the trailing offset percentage; in standard take-profit mode, trailing activates at the target grid level, and in reversal take-profit mode, it activates at the close that triggers the reversal
Long: date filter passes AND session filter passes AND this grid level has not triggered this session AND (reversal mode AND a prior close since session start was below the grid level AND current close > grid level OR standard mode AND close crosses below the grid level)
Short: date filter passes AND session filter passes AND this grid level has not triggered this session AND (reversal mode AND a prior close since session start was above the grid level AND current close < grid level OR standard mode AND close crosses above the grid level)
Exit: Long, (manual stop loss enabled AND close <= stop-loss level) OR (reversal take-profit mode AND prior close > target grid level AND current close < target grid level AND trailing disabled) OR (standard take-profit mode AND trailing disabled AND close >= target grid level) OR (trailing enabled AND low <= active trailing stop) OR (force session close enabled AND prior bar was in session AND current bar is outside session)
Exit: Short, (manual stop loss enabled AND close >= stop-loss level) OR (reversal take-profit mode AND prior close < target grid level AND current close > target grid level AND trailing disabled) OR (standard take-profit mode AND trailing disabled AND close <= target grid level) OR (trailing enabled AND high >= active trailing stop) OR (force session close enabled AND prior bar was in session AND current bar is outside session)
