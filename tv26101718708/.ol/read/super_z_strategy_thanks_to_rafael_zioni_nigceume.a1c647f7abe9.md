Calculation: Modified SuperTrend line = Set the upper trailing level to the current higher-timeframe low minus a multiplier times chart-timeframe ATR; if the previous higher-timeframe close exceeds the previous upper trailing level, use the greater of this value and the previous upper trailing level. Set the lower trailing level to the current higher-timeframe high plus the same multiplier times chart-timeframe ATR; if the previous higher-timeframe close is below the previous lower trailing level, use the lesser of this value and the previous lower trailing level. Set direction to +1 if the current higher-timeframe close exceeds the previous lower trailing level, otherwise −1 if it is below the previous upper trailing level, otherwise keep the previous direction (initially +1). The line is the upper trailing level when direction is +1 and the lower trailing level otherwise. Use the higher-timeframe bar still forming for its OHLC values.
