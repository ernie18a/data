Calculation: DWO = percentage distance between the shorter-lookback WMA and the longer-lookback WMA: ((shorter-lookback WMA − longer-lookback WMA) / longer-lookback WMA) × 100, calculated on higher-timeframe bars using the last completed bar
Calculation: Histogram = DWO − EMA of DWO, calculated on higher-timeframe bars using the last completed bar
Long: DWO > 0 OR Histogram >= 0
Short: DWO < 0 OR Histogram < 0
