Calculation: ATR = average true range of chart-timeframe bars
Calculation: Session high/low = highest high and lowest low during a configured session; levels become active when that session closes
Long: An active session low is swept for the first time (low < level AND close >= level - 0.1 × ATR) OR an active session low is run (close < level - 0.1 × ATR)
Short: An active session high is swept for the first time (high > level AND close <= level + 0.1 × ATR) OR an active session high is run (close > level + 0.1 × ATR)
