Calculation: Opening-range high/low = highest high / lowest low from the session open through the configured opening-range end; use chart-timeframe bars, including the bar still forming, and use the levels only after the range ends.
Calculation: Premarket high/low = highest high / lowest low during the premarket session, using chart-timeframe bars including the bar still forming.
Calculation: Previous day/week/month/quarter/year high and low, and previous day open = corresponding values from the last completed daily/weekly/monthly/quarterly/yearly bar (higher timeframe bars).
Calculation: All-time high/low = highest high / lowest low over the available monthly bars (higher timeframe, including the bar still forming); use chart-timeframe running extremes if monthly values are unavailable.
Calculation: Current day open = open of the first chart-timeframe bar of the day.
Long: For any enabled static level (opening-range high, premarket high, current day open, previous day open, previous day/week/month/quarter/year high, or all-time high), the configured alert mode's upward break condition is met: Touch: high >= level AND prior high < level; Close Break: close > level AND prior close <= level; Confirmed Break: close > level + configured ATR buffer AND prior close <= level. Apply the configured per-level cooldown and RTH-only restriction when enabled.
Short: For any enabled static level (opening-range low, premarket low, current day open, previous day open, previous day/week/month/quarter/year low, or all-time low), the configured alert mode's downward break condition is met: Touch: low <= level AND prior low > level; Close Break: close < level AND prior close >= level; Confirmed Break: close < level - configured ATR buffer AND prior close >= level. Apply the configured per-level cooldown and RTH-only restriction when enabled.
