Calculation: External swing levels = latest confirmed pivot highs and lows, using separate BOS and CHoCH lookbacks; a pivot is confirmed only after the same number of bars have formed to its right.
Calculation: Internal swing levels = latest confirmed pivot highs and lows, using a shorter lookback than the external structure pivots; each level becomes eligible for a new break when confirmed.
Calculation: Break source = close for close-confirmed breaks, otherwise high for upward breaks and low for downward breaks.
Calculation: External structure state = initialize to bullish when close is at or above the midpoint of the latest CHoCH high/low levels (falling back to BOS levels where a CHoCH level is absent), otherwise bearish. A break above an unbroken CHoCH high changes a non-bullish state to bullish; a break below an unbroken CHoCH low changes a non-bearish state to bearish. In a bullish state, a break above an unbroken BOS high is bullish; in a bearish state, a break below an unbroken BOS low is bearish. Each level can break only once before a new pivot confirms.
Calculation: Master trend = external structure state, except set to neutral when the HTF veto is enabled and the external state opposes the higher-timeframe EMA bias. HTF bias is bullish when chart close is above the EMA of the still-forming higher-timeframe bar, bearish when below it.
Long: (external structure state is non-bullish AND break source > unbroken CHoCH high) OR (external structure state is bullish AND break source > unbroken BOS high) OR (break source > unbroken internal swing high AND master trend is bullish)
Short: (external structure state is non-bearish AND break source < unbroken CHoCH low) OR (external structure state is bearish AND break source < unbroken BOS low) OR (break source < unbroken internal swing low AND master trend is bearish)
