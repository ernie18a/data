Calculation: HTF bias total = sum across six configured bias timeframes of (+1 if timeframe close > 200-period EMA, else -1) + (+1 if fast EMA > slow EMA, else -1) + (+1 if timeframe close > fast EMA, else -1); fast EMA lookback is shorter than slow EMA lookback. Use lookahead-off values: the last completed bar on historical data and the forming bar in real time. Each configured timeframe may be higher, lower, or equal to the chart timeframe.
Calculation: Bull score = 2 if HTF bias total >= 4, plus 1 if HTF bias total is >= 2 and < 4, plus 1 for bullish BOS or CHoCH this bar, plus 1 for a bearish fair value gap inverted bullish this bar, plus 1 for a bullish liquidity sweep this bar, plus 1 if close is below the midpoint of the previous completed daily high-low range, plus 1 if cumulative volume delta is rising, plus 1 if close is above the current New York midnight open, plus 1 during any configured London or New York killzone, plus 1 if close is below its value vdLen bars ago and cumulative volume delta is above its value vdLen bars ago. Cumulative volume delta is the vdLen-bar sum of volume for bars closing above open, minus volume for bars closing below open; unchanged bars contribute zero. The daily range uses the previous completed daily bar.
Calculation: Bear score = 2 if HTF bias total <= -4, plus 1 if HTF bias total is <= -2 and > -4, plus 1 for bearish BOS or CHoCH this bar, plus 1 for a bullish fair value gap inverted bearish this bar, plus 1 for a bearish liquidity sweep this bar, plus 1 if close is above the midpoint of the previous completed daily high-low range, plus 1 if cumulative volume delta is falling, plus 1 if close is below the current New York midnight open, plus 1 during any configured London or New York killzone, plus 1 if close is above its value vdLen bars ago and cumulative volume delta is below its value vdLen bars ago.
Calculation: Bullish BOS or CHoCH = close crosses above the latest confirmed pivot high; classify as CHoCH if prior trend state was bearish, otherwise BOS. A pivot requires swingLen bars on both sides; trend state changes to bullish on the crossing.
Calculation: Bearish BOS or CHoCH = close crosses below the latest confirmed pivot low; classify as CHoCH if prior trend state was bullish, otherwise BOS. A pivot requires swingLen bars on both sides; trend state changes to bearish on the crossing.
Calculation: Bullish liquidity sweep = high exceeds the previous confirmed pivot high and close is below that pivot high. Bearish liquidity sweep = low falls below the previous confirmed pivot low and close is above that pivot low.
Calculation: Bullish fair value gap inversion = an unmitigated bearish three-bar gap (current high < low two bars ago) is closed through upward (close > its gap top). Bearish fair value gap inversion = an unmitigated bullish three-bar gap (current low > high two bars ago) is closed through downward (close < its gap bottom).
Long: Bull score >= minimum confluence score AND Bull score > Bear score OR bullish BOS or CHoCH OR bullish fair value gap inversion OR bullish liquidity sweep
Short: Bear score >= minimum confluence score AND Bear score > Bull score OR bearish BOS or CHoCH OR bearish fair value gap inversion OR bearish liquidity sweep
