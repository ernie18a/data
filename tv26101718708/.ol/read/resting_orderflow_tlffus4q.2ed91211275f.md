Calculation: Row buy/sell volume = for each chart bar, classify each lower-timeframe intrabar as buy if close > open, sell if close < open; if flat, use its close versus the previous intrabar close, retaining the previous direction if equal. Distribute its volume across the fixed price rows it spans in proportion to row overlap. Use lower-timeframe bars; accumulate only after the chart bar is complete. If no lower-timeframe intrabars are available, split chart-bar volume between buy and sell in proportion to the chart close’s location within its high-low range, then distribute across the rows it spans.
Calculation: Row delta = accumulated buy volume − accumulated sell volume, reduced after each qualifying close-through by the configured absorption fraction.
Calculation: Buy node = a positive-delta row at or below the current close; sell node = a negative-delta row at or above the current close. Optionally merge same-side rows whose total price span is within the configured cluster range; node delta is the sum of row deltas. Exclude expired rows and, when enabled, rows not touched within the configured recent-bar window. Rank nodes on each side by absolute delta.
Long: The current bar’s high-low range overlaps any of the highest-ranked eligible buy-node price ranges.
Short: The current bar’s high-low range overlaps any of the highest-ranked eligible sell-node price ranges.
