Calculation: Estimated volume delta = sum of lower-timeframe candle volumes signed +1 when close > open, −1 when close < open, and by close versus the previous lower-timeframe close when open = close (0 if equal or no previous close); use completed lower-timeframe bars within each chart bar, and if none are available use chart-bar volume signed by chart-bar direction (0 when open = close). The lower timeframe is below the chart timeframe.
Calculation: Run efficiency ratio = [sum of high − low over N consecutive bars / sum of absolute estimated volume delta over those bars] / the trailing average of that same per-bar ratio over the configured baseline, ending on the previous chart bar.
Long: estimated volume delta is positive for N consecutive completed chart bars AND (efficiency filter is Any OR efficiency filter is Efficient and run efficiency ratio ≥ 1 OR efficiency filter is Absorbed and run efficiency ratio < 1) AND (isolation is disabled OR no opposite-direction run completed within the configured lookback window)
Short: estimated volume delta is negative for N consecutive completed chart bars AND (efficiency filter is Any OR efficiency filter is Efficient and run efficiency ratio ≥ 1 OR efficiency filter is Absorbed and run efficiency ratio < 1) AND (isolation is disabled OR no opposite-direction run completed within the configured lookback window)
