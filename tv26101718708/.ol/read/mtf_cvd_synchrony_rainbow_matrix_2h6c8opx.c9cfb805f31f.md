Calculation: CVD score = clamp to [0,100] of 50 + 50 × smoothed directional flow / rolling highest absolute smoothed directional flow; directional flow is EMA of volume × ((close − low) − (high − close)) / (high − low), using zero when high = low; use 50 when the normalization denominator is zero. For each configured timeframe, use its latest available bar: a higher timeframe may still be forming in real time, while lower-timeframe data uses the latest available bar within the chart bar.
