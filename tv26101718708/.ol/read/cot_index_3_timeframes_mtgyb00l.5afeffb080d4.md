Calculation: Commercial COT Index (short-, medium-, and long-term) = 100 × (current commercial net position − lowest commercial net position over the lookback) ÷ (highest commercial net position over the lookback − lowest commercial net position over the lookback), where commercial net position = commercial long positions − commercial short positions. Use three lookbacks ordered short < medium < long. The source is weekly COT reports: when the chart timeframe is below weekly, use the weekly report series; when it is above weekly, use the last weekly report within the chart bar. Use the current week's report only from its Friday release when hide-current-week is enabled; otherwise use it from the start of the week.
Long: Long and short extremes enabled AND at least one index visible AND every visible, valid index ≥ upper threshold
Short: Long and short extremes enabled AND at least one index visible AND every visible, valid index ≤ lower threshold
