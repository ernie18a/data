Calculation: Active profile VAH and VAL = build a TPO count for each price row, adding at most one count per row per time block when any chart-timeframe bar in that block intersects it. Use the configured row size: manual tick step, or automatic sizing from the average range of the last 5 completed daily bars divided by the target row count, falling back to ATR from completed daily bars with a configured lookback. The daily bars are higher timeframe bars. POC is the row with the highest count, ties going to the row nearest the profile midpoint. Starting at POC, expand the value area toward the adjacent row with the higher count (both sides on a tie) until the configured percentage of total TPO counts is reached; the resulting bounds are VAH and VAL. Use the current, still-forming active profile selected by the configured profile mode and session.
Long: active profile VAH is defined AND close > active profile VAH AND previous close <= active profile VAH
Short: active profile VAL is defined AND close < active profile VAL AND previous close >= active profile VAL
