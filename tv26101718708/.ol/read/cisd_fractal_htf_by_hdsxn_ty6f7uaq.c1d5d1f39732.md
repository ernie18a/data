Calculation: Delivery state and CISD reference = For each calculation timeframe, classify each candle as bullish when close >= open and bearish otherwise; track the consecutive same-direction candle run, including its first open and highest high and lowest low. Initialize delivery bias to the first candle’s direction, reference to its run’s first open, and tracked extreme to that run’s high for bullish bias or low for bearish bias. While bias is bullish, update the tracked extreme only when a candle makes a strictly higher high; on that update, set the reference to the current run’s first open if the run is bullish. While bias is bearish, update the tracked extreme only when a candle makes a strictly lower low; on that update, set the reference to the current run’s first open if the run is bearish. On a CISD, reverse the bias, set the reference to the current run’s first open, and reset the tracked extreme to the current run’s high for bullish bias or low for bearish bias. Calculate separately on confirmed chart-timeframe bars and on last completed bars of each selected higher timeframe.
