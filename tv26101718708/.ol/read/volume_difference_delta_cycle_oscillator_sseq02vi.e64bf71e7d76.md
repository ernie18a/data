Calculation: Histogram = apply three successive EMAs, each with its own smoothing length, to (close Bollinger %B − volume-delta Bollinger %B). Close Bollinger %B uses close, a rolling SMA basis, and rolling standard deviation. Volume-delta Bollinger %B uses an EMA of the EMA of the normalized volume-difference delta, an EMA basis, and rolling standard deviation. The normalized volume-difference delta is the change in (cumulative signed volume from close changes − cumulative volume × close percentage change), scaled using its expanding historical minimum and maximum to [−1, 1]. Each Bollinger %B is (value − lower band) / (upper band − lower band); the two Bollinger calculations have independently configurable lookbacks and standard-deviation multipliers. All calculations use chart-timeframe bars.
Long: Histogram < oversold threshold AND datetime >= configured start timestamp AND datetime < configured end timestamp
Short: Histogram > overbought threshold AND datetime >= configured start timestamp AND datetime < configured end timestamp
Exit: long, Histogram > overbought threshold AND datetime >= configured start timestamp AND datetime < configured end timestamp
Exit: short, Histogram < oversold threshold AND datetime >= configured start timestamp AND datetime < configured end timestamp
