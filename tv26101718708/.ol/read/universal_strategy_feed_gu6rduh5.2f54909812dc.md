Long: (Signal Mode = Pulse AND Source A > Level OR Signal Mode = Sign Cross AND Source A crosses above Level OR Signal Mode = Level Cross AND Source A crosses above Up Level OR Signal Mode = Two Sources Cross AND Source A crosses above Source B OR Signal Mode = Two Trigger Sources AND Source A is nonzero and not missing OR Signal Mode = Three Sources with A above both B and C AND Source A > Source B AND Source A > Source C OR Signal Mode = Three Sources with A crosses B, filter C AND Source A crosses above Source B AND Source C > Filter OR Signal Mode = Three Sources with A>C long / B>C short AND Source A > Source C OR Signal Mode = Volume AND Volume > Volume MA (or Source B when Volume MA Length is zero) AND Close >= Open), restricted to the date window when enabled and only if the last accepted signal is not long; swap long and short conditions when Invert is enabled. A long signal wins a same-bar tie.
Short: (Signal Mode = Pulse AND Source A < Level OR Signal Mode = Sign Cross AND Source A crosses below Level OR Signal Mode = Level Cross AND Source A crosses below Down Level OR Signal Mode = Two Sources Cross AND Source A crosses below Source B OR Signal Mode = Two Trigger Sources AND Source B is nonzero and not missing OR Signal Mode = Three Sources with A above both B and C AND Source A < Source B AND Source A < Source C OR Signal Mode = Three Sources with A crosses B, filter C AND Source A crosses below Source B AND Source C < Filter OR Signal Mode = Three Sources with A>C long / B>C short AND Source B > Source C OR Signal Mode = Volume AND Volume > Volume MA (or Source B when Volume MA Length is zero) AND Close < Open), restricted to the date window when enabled and only if the last accepted signal is not short; swap long and short conditions when Invert is enabled. A short signal is accepted only if there is no long signal on the bar.
Exit: Long, TP/SL Method = Percent AND (High >= entry price × (1 + Take Profit %) OR Low <= entry price × (1 − Stop Loss %))
Exit: Long, TP/SL Method = ATR AND (High >= entry price + entry-bar ATR × TP multiplier OR Low <= entry price − entry-bar ATR × SL multiplier)
Exit: Short, TP/SL Method = Percent AND (Low <= entry price × (1 − Take Profit %) OR High >= entry price × (1 + Stop Loss %))
Exit: Short, TP/SL Method = ATR AND (Low <= entry price − entry-bar ATR × TP multiplier OR High >= entry price + entry-bar ATR × SL multiplier)
Exit: Long or Short, TP/SL Method = Feed AND (TP feed or SL feed changes from zero to nonzero) AND no long or short signal on that bar
Exit: Long, TP/SL Method = Signal AND short signal
Exit: Short, TP/SL Method = Signal AND long signal
