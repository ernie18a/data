Calculation: Daily percentage change = (current daily close − previous daily close) / previous daily close × 100; use the current, still-forming daily bar on a higher timeframe than the chart.
Calculation: Breadth ratio = (number of tracked series with daily percentage change > 0.05% − number with daily percentage change < −0.05%) / number of tracked series.
Calculation: Breadth magnitude = mean of the absolute daily percentage changes across tracked series.
Calculation: Signed breadth magnitude = breadth magnitude if breadth ratio ≥ 0, otherwise −breadth magnitude.
Calculation: Premarket change = current futures daily percentage change − its value when the premarket window began.
Long: Breadth uses at least 3 series AND breadth ratio ≥ 0.2 OR breadth uses fewer than 3 series AND signed breadth magnitude ≥ 0.2
Long: Futures daily percentage change ≥ 0.2
Long: Premarket window is active AND a premarket anchor exists AND premarket change ≥ 0
Short: Breadth uses at least 3 series AND breadth ratio ≤ −0.2 OR breadth uses fewer than 3 series AND signed breadth magnitude ≤ −0.5
Short: Futures daily percentage change ≤ −0.5
Short: Premarket window is active AND a premarket anchor exists AND premarket change < 0
