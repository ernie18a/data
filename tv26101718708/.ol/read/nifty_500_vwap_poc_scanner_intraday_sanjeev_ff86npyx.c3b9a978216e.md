Calculation: Session VWAP = cumulative volume-weighted HLC3 since the start of the session, using chart-timeframe bars including the forming bar
Calculation: Rolling HLC3 average = simple average of HLC3 over a lookback, using chart-timeframe bars including the forming bar
Long: close > Session VWAP AND close > Rolling HLC3 average
Short: close <= Session VWAP AND close <= Rolling HLC3 average
