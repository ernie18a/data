Calculation: Fast and slow Kalman estimates = recursive Kalman filters of OHLC4; the fast estimate uses a shorter length than the slow estimate. At each bar, estimate = prior estimate + gain × (OHLC4 − prior estimate), where gain = (prior error + process noise) / (prior error + process noise + measurement noise); update error = (1 − gain) × (prior error + process noise), with process noise inversely proportional to the respective length.
Calculation: Adaptive flow basis = recursively smooth the fast Kalman estimate with an alpha interpolated from a slower to a faster smoothing rate according to recent pivot-break activity; add an ATR-scaled impulse from recent pivot-break bias, weighted by whether the fast estimate agrees with the slow estimate and the bias; then partially pull the result toward the midpoint of the latest confirmed pivot high and low according to pivot-break activity. Pivot breaks occur when close crosses above the latest confirmed pivot high or below the latest confirmed pivot low. Use the same lookback for pivot confirmation and for the RMA of pivot-break activity and bias. Use bars of the screener timeframe (equal to or higher than the chart timeframe; if the selected timeframe is lower, use the chart timeframe). Use the last completed bar when waiting for the screener bar to close; otherwise use the forming bar.
Calculation: ATR boundaries = adaptive flow basis ± ATR × boundary multiplier.
Calculation: Kalman flow direction = initialize bullish when close ≥ adaptive flow basis, otherwise bearish; change to bullish when close > upper ATR boundary and the basis is rising, or to bearish when close < lower ATR boundary and the basis is falling; otherwise retain the prior direction. Slope checks are omitted when slope confirmation is disabled.
Long: Kalman flow direction is bullish OR (Kalman flow direction is bearish AND close ≥ upper ATR boundary − ATR × flip-risk distance)
Short: Kalman flow direction is bearish OR (Kalman flow direction is bullish AND close ≤ lower ATR boundary + ATR × flip-risk distance)
