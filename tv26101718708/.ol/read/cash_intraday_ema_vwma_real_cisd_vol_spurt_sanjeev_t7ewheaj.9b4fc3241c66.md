Calculation: CISD state and level = Start with the direction of the first non-doji candle. The level is the minimum open in the latest contiguous bullish-candle run when state is bullish, or the maximum open in the latest contiguous bearish-candle run when state is bearish; skip doji candles when finding a run. While bullish, each new running high resets the level using the latest bullish run ending at that bar (or the nearest preceding bullish run if the bar is not bullish); while bearish, each new running low resets it using the latest bearish run in the same way. If the close crosses below the level while bullish, emit bearish CISD and switch to bearish; if it crosses above while bearish, emit bullish CISD and switch to bullish. On a switch, reset the level from the new state’s candle run ending at that bar, or to that bar’s open if its candle does not match the new state.
Long: (EMA(9) > VWMA(20) AND previous EMA(9) <= previous VWMA(20) AND EMA(20) > VWMA(50)) OR (close > open AND volume > 20-bar average volume × volume multiplier) OR (bearish CISD state AND close > CISD level)
Short: (EMA(9) < VWMA(20) AND previous EMA(9) >= previous VWMA(20) AND EMA(20) < VWMA(50)) OR (close < open AND volume > 20-bar average volume × volume multiplier) OR (bullish CISD state AND close < CISD level)
