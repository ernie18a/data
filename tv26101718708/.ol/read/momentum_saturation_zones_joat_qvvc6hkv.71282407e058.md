Calculation: Momentum = selected RSI, ROC, MFI, Stochastic %D, or their arithmetic mean; for composite, normalize ROC as clamp(50 + 50 × ROC / (2 × 100-bar standard deviation of ROC + ε), 0, 100) before averaging
Calculation: Extreme-gate momentum = selected RSI, normalized ROC, MFI, Stochastic %D, or their arithmetic mean, using normalized ROC for the ROC selection
Calculation: Adaptive pullback threshold = configured pullback percentage × clamp((ATR / close) / 50-bar SMA(ATR / close), configured lower bound, configured upper bound); use the configured pullback percentage directly when adaptation is disabled
Calculation: Bear strength = clamp((peak extreme-gate momentum − 50) × 40 / 50, 0, 40) + clamp((bear pullback percentage − adaptive pullback threshold) × 2 + 10, 0, 20) + clamp((peak-bar volume / 20-bar average volume − 1) × 20, 0, 20) + 20 if enabled bearish divergence
Calculation: Bull strength = clamp((50 − trough extreme-gate momentum) × 40 / 50, 0, 40) + clamp((bull pullback percentage − adaptive pullback threshold) × 2 + 10, 0, 20) + clamp((trough-bar volume / 20-bar average volume − 1) × 20, 0, 20) + 20 if enabled bullish divergence
Calculation: Bear pullback percentage = (rolling momentum high − current momentum) / (rolling momentum high + ε) × 100
Calculation: Bull pullback percentage = (current momentum − rolling momentum low) / (abs(rolling momentum low) + ε) × 100
Calculation: Bearish divergence = current rolling-high bar high > previous accepted rolling-high bar high AND current rolling momentum high < previous accepted rolling momentum high; update the previous values when a bearish signal occurs
Calculation: Bullish divergence = current rolling-low bar low < previous accepted rolling-low bar low AND current rolling momentum low > previous accepted rolling momentum low; update the previous values when a bullish signal occurs
Long: bar is confirmed AND current momentum >= rolling momentum low + abs(rolling momentum low) × adaptive pullback threshold / 100 AND (absolute-extreme gate disabled OR trough extreme-gate momentum <= configured oversold level) AND (volume filter disabled OR trough-bar volume > configured multiplier × 20-bar average volume) AND (pivot confirmation is zero OR trough age >= configured confirmation bars) AND bull strength >= configured minimum AND this rolling-low bar differs from the last accepted bullish rolling-low bar AND current bar index − last accepted zone-signal bar index >= configured cooldown bars
Short: bar is confirmed AND current momentum <= rolling momentum high × (1 − adaptive pullback threshold / 100) AND (absolute-extreme gate disabled OR peak extreme-gate momentum >= configured overbought level) AND (volume filter disabled OR peak-bar volume > configured multiplier × 20-bar average volume) AND (pivot confirmation is zero OR peak age >= configured confirmation bars) AND bear strength >= configured minimum AND this rolling-high bar differs from the last accepted bearish rolling-high bar AND current bar index − last accepted zone-signal bar index >= configured cooldown bars
