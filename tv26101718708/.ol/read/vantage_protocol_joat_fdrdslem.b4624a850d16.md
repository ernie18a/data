Calculation: H-Infinity filtered close = recursively update each filter state toward close using gain = state error / (state error + disturbance); update state error to (1 − gain) × state error. Initialize signal states to the first close and error states equally. H-Infinity slope = current filtered close − prior filtered close.
Calculation: R-squared efficiency gate = square the rolling correlation of close and bar index, smooth with a short SMA, then compare it with its rolling mean plus a parameter-scaled rolling standard deviation; open above that threshold and close below its lower hysteresis threshold.
Calculation: Chop score = 1 − abs(close − close from the longer lookback ago) / sum of absolute close-to-close changes over that lookback; classify as choppy when above its threshold.
Calculation: Regime bias = 0 unless the efficiency gate is open and the market is not choppy; otherwise bullish when H-Infinity slope ≥ 0, bearish when H-Infinity slope < 0.
Calculation: Laguerre RSI = 100 × upward movement / (upward movement + downward movement), where movements are summed positive and negative differences between four recursively Laguerre-filtered close states; use 50 if the denominator is zero. Smooth this value with a Jurik Moving Average (JMA) to get momentum.
Calculation: CVD = cumulative signed volume, with positive volume when close > open, negative volume when close < open, and zero otherwise. CVD slope = current EMA-smoothed CVD − prior EMA-smoothed CVD.
Calculation: Volume ratio = volume / 50-bar SMA(volume), using 1 as the denominator when that SMA is zero.
Calculation: ZEMA-smoothed ATR = 2 × EMA(ATR) − EMA(EMA(ATR)), using the same smoothing length for both EMAs.
Long: flat AND regime bias = 1 AND JMA-smoothed Laguerre RSI > bull threshold AND CVD slope > 0 AND volume ratio ≥ minimum ratio AND (session filter disabled OR current time is within configured session) AND bars since last exit ≥ cooldown.
Short: flat AND regime bias = −1 AND JMA-smoothed Laguerre RSI < bear threshold AND CVD slope < 0 AND volume ratio ≥ minimum ratio AND (session filter disabled OR current time is within configured session) AND bars since last exit ≥ cooldown.
Exit: long, low ≤ entry price − entry-time ZEMA-smoothed ATR × stop multiplier OR high ≥ entry price + entry-time ZEMA-smoothed ATR × target multiplier OR regime bias ≤ 0 OR JMA-smoothed Laguerre RSI < exit threshold.
Exit: short, high ≥ entry price + entry-time ZEMA-smoothed ATR × stop multiplier OR low ≤ entry price − entry-time ZEMA-smoothed ATR × target multiplier OR regime bias ≥ 0 OR JMA-smoothed Laguerre RSI > exit threshold.
