Calculation: Volume-weighted smoothed open-close spread = (EMA of Fourier-smoothed close × volume normalization) − (EMA of Fourier-smoothed open × volume normalization); both EMAs use the same Gann-adjusted length.
Calculation: Volume normalization = volume divided by Fourier-smoothed prior-bar volume.
Calculation: Smoothed spread = EMA of the volume-weighted smoothed open-close spread, using a longer lookback than the price EMAs.
Long: volume-weighted smoothed open-close spread > 0 AND smoothed spread > 0
Short: volume-weighted smoothed open-close spread < 0 AND smoothed spread < 0
Exit: long or short, (volume-weighted smoothed open-close spread ≤ 0 OR smoothed spread ≤ 0) AND close-all enabled AND (Gann position = 0 OR Gann entry disabled)
