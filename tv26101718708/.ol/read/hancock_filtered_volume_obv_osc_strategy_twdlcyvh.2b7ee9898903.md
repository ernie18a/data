Calculation: Filtered volume OBV oscillator = cumulatively add sign(change(close)) × volume, except hold the prior value when the volume filter is enabled and volume < abs(average(volume, longer lookback) − standard deviation(volume, same lookback) × multiplier); when enabled, subtract the configured moving average of this cumulative value over a shorter lookback, otherwise use the cumulative value directly.
Calculation: Donchian upper/lower channel = highest high / lowest low over the configured lookback; calculate separate longer-lookback (slow) and shorter-lookback (fast) channels. Apply the same calculation to the filtered volume OBV oscillator using its values as both high and low. All channels use chart-timeframe bars; each reference to the prior channel value uses the last completed chart-timeframe bar.
Calculation: Long protective stop = entry close − entry close × stop percentage / leverage until the running long high exceeds entry close + entry close × trail-threshold percentage / leverage; after that, long high − long high × trail percentage / leverage. Initialize the running long high to the entry-bar low and update it when a later bar's high is greater.
Calculation: Short protective stop = entry close + entry close × stop percentage / leverage until the running short low falls below entry close − entry close × trail-threshold percentage / leverage; after that, short low + short low × trail percentage / leverage. Initialize the running short low to the entry-bar high and update it when a later bar's low is lower.
Long: high > prior slow price-channel upper value AND filtered volume OBV oscillator > prior slow oscillator-channel upper value AND (oscillator disabled OR filtered volume OBV oscillator > 0)
Short: low < prior slow price-channel lower value AND filtered volume OBV oscillator < prior slow oscillator-channel lower value AND (oscillator disabled OR filtered volume OBV oscillator < 0)
Exit: long, low <= long protective stop OR (low < prior fast price-channel lower value AND filtered volume OBV oscillator < prior fast oscillator-channel lower value)
Exit: short, high >= short protective stop OR (high > prior fast price-channel upper value AND filtered volume OBV oscillator > prior fast oscillator-channel upper value)
