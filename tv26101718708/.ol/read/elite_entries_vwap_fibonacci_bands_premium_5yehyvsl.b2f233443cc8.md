Calculation: Anchored VWAP = volume-weighted mean of typical price (high + low + close) / 3, accumulated from the selected timeframe reset or date anchor
Calculation: 23.6 core bands = Anchored VWAP ± (volume-weighted population standard deviation of typical price × deviation multiplier × 0.236)
Calculation: Reaction-zone boundaries = each 23.6 core band ± half-width, where half-width is ATR × multiplier or tick size × tick count
Calculation: Session VWAP = volume-weighted mean of the selected source during the current session
Calculation: Fast and slow moving averages = selected moving average types and sources; fast uses a shorter lookback than slow. Higher-timeframe values use the last completed bar; lower-timeframe values use the last available intrabar; chart-timeframe values use the current bar. HEMA uses Heikin Ashi close.
Calculation: Gann HiLo = bullish when close exceeds the prior-bar SMA of highs, bearish when close falls below the prior-bar SMA of lows, otherwise retains its prior direction; level is the SMA of lows in bullish direction and SMA of highs in bearish direction. Higher-timeframe values use the last completed bar; lower-timeframe values use the last available intrabar; chart-timeframe values use the current bar.
Calculation: Trailing stop = entry close minus (long) or plus (short) the ATR-based or tick-based distance; thereafter ratchets using each confirmed standard close and the current distance, tightening only
Long: Confirmed close crosses above an enabled Anchored VWAP or upper Fibonacci band, excluding anchor-reset bars, AND breakout filters pass: if enabled, fast moving average > slow moving average and close > both; if enabled, Gann direction is bullish and close > Gann HiLo level; if enabled, selected session VWAPs are passed by close > each (All Selected) or close > at least one (Any Selected); OR, at either 23.6 core band, a reaction signal qualifies: (a) zone touched, prior close was above the upper boundary (or, in Aggressive Hold mode, prior close ≥ core), and close ≥ core in Conservative mode or close ≥ lower boundary otherwise; OR (b) zone touched, prior close was below the lower boundary, close < core, and close < open; OR (c) after a prior close below the lower boundary, close crosses above the core within the reclaim window; OR (d) after a fresh close below the lower boundary, the required consecutive closes remain below it
Short: Confirmed close crosses below an enabled Anchored VWAP or lower Fibonacci band, excluding anchor-reset bars, AND breakout filters pass: if enabled, fast moving average < slow moving average and close < both; if enabled, Gann direction is bearish and close < Gann HiLo level; if enabled, selected session VWAPs are passed by close < each (All Selected) or close < at least one (Any Selected); OR, at either 23.6 core band, a reaction signal qualifies: (a) zone touched, prior close was below the lower boundary (or, in Aggressive Hold mode, prior close ≤ core), and close ≤ core in Conservative mode or close ≤ upper boundary otherwise; OR (b) zone touched, prior close was above the upper boundary, close > core, and close > open; OR (c) after a prior close above the upper boundary, close crosses below the core within the reclaim window; OR (d) after a fresh close above the upper boundary, the required consecutive closes remain above it
Exit: Long, a later confirmed standard close < the previous trailing stop
Exit: Short, a later confirmed standard close > the previous trailing stop
