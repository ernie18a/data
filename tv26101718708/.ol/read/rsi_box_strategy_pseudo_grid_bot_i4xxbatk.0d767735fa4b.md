Calculation: RSI = relative strength index of the source over a lookback; the same lookback is used for the highest/lowest source and their volume-weighted moving averages
Calculation: Upper grid boundary = latest volume-weighted moving average of the lookback highest source, recorded when RSI crosses below the overbought threshold
Calculation: Lower grid boundary = latest volume-weighted moving average of the lookback lowest source, recorded when RSI crosses above the oversold threshold
Calculation: Five grid lines = upper and lower boundaries, their midpoint, and the midpoint between each boundary and the midpoint
Calculation: Long trigger line = when source crosses above any grid line, select the nearest grid line to the source; set the trigger to the next grid line above it (lower boundary → lower midpoint → midpoint → upper midpoint → upper boundary)
Calculation: Short trigger line = when source crosses below any grid line, select the nearest grid line to the source; set the trigger to the next grid line below it (upper boundary → upper midpoint → midpoint → lower midpoint → lower boundary)
Long: Source crosses above the long trigger line
Short: Shorts enabled AND source crosses below the short trigger line
Exit: Long, source crosses below the short trigger line
