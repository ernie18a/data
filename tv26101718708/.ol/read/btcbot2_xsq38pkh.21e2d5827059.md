Calculation: Unrealized dollar P&L = (current close − entry price) × position quantity for a long position; (entry price − current close) × position quantity for a short position
Long: Previous completed daily bar’s open > chart source AND no open position AND datetime is within the configured backtest window AND symbol 1 HMA(current selected source, lookback) > symbol 1 HMA(previous requested-timeframe bar’s selected source, same lookback) AND symbol 2 HMA(current selected source, lookback) < symbol 2 HMA(previous requested-timeframe bar’s selected source, same lookback) AND symbol 3 HMA(current selected source, lookback) > symbol 3 HMA(previous requested-timeframe bar’s selected source, same lookback); symbol HMAs use the configured symbol timeframe, which may be higher, lower, or equal to the chart timeframe, and the current requested-timeframe bar with lookahead enabled
Short: Previous completed daily bar’s open < chart source AND no open position AND datetime is within the configured backtest window AND symbol 1 HMA(current selected source, lookback) < symbol 1 HMA(previous requested-timeframe bar’s selected source, same lookback) AND symbol 2 HMA(current selected source, lookback) > symbol 2 HMA(previous requested-timeframe bar’s selected source, same lookback) AND symbol 3 HMA(current selected source, lookback) < symbol 3 HMA(previous requested-timeframe bar’s selected source, same lookback); symbol HMAs use the configured symbol timeframe, which may be higher, lower, or equal to the chart timeframe, and the current requested-timeframe bar with lookahead enabled
Exit: Long, (symbol 3 HMA(current selected source, lookback) < symbol 3 HMA(previous requested-timeframe bar’s selected source, same lookback) AND previous completed daily bar’s open < chart source) OR unrealized dollar P&L < configured stop-loss threshold OR (unrealized dollar P&L > configured target threshold AND symbol 1 HMA(current selected source, lookback) > symbol 1 HMA(previous requested-timeframe bar’s selected source, same lookback))
Exit: Short, (symbol 3 HMA(current selected source, lookback) > symbol 3 HMA(previous requested-timeframe bar’s selected source, same lookback) AND previous completed daily bar’s open > chart source) OR unrealized dollar P&L < configured stop-loss threshold OR (unrealized dollar P&L > configured target threshold AND symbol 1 HMA(current selected source, lookback) < symbol 1 HMA(previous requested-timeframe bar’s selected source, same lookback))
