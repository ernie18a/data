Calculation: Confirmed swing high = high N bars ago when it exceeds the highest high of the latest N bars and the swing state changes to high; confirmed swing low = low N bars ago when it is below the lowest low of the latest N bars and the swing state changes to low.
Calculation: Bullish order-block zone (Volumized) = the low-to-high range of the bar with the lowest low between the broken swing high and the break bar; bearish order-block zone (Volumized) = the low-to-high range of the bar with the highest high between the broken swing low and the break bar.
Calculation: Bullish order-block zone (ICT) = the range spanning the consecutive opposing down candles nearest the break bar, or only the nearest such candle in single-candle mode; bearish order-block zone (ICT) = the range spanning the consecutive opposing up candles nearest the break bar, or only the nearest such candle in single-candle mode. Search only bars between the swing and break bars.
Calculation: Bullish fair value gap = current low > high two bars ago; bearish fair value gap = current high < low two bars ago.
Long: Close > latest unbroken confirmed swing high AND (Volumized mode: the bullish order-block zone height <= ATR × maximum-zone-size parameter OR ICT mode: current candle body size >= ATR × displacement parameter AND a prior opposing down candle exists AND (FVG requirement disabled OR bullish fair value gap) AND the bullish order-block zone height <= ATR × maximum-zone-size parameter)
Short: Close < latest unbroken confirmed swing low AND (Volumized mode: the bearish order-block zone height <= ATR × maximum-zone-size parameter OR ICT mode: current candle body size >= ATR × displacement parameter AND a prior opposing up candle exists AND (FVG requirement disabled OR bearish fair value gap) AND the bearish order-block zone height <= ATR × maximum-zone-size parameter)
