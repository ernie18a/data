Calculation: Session VAH/VAL = upper/lower bounds of the session value area, calculated from chart-timeframe bars in the configured session through the current bar. Assign each bar’s volume to the price row containing its (high + low) / 2; the profile spans the session’s highest high to lowest low. Start at the highest-volume row and add the adjacent row with greater volume (ties upward) until the configured share of total volume is included.
Calculation: Range VAH/VAL = upper/lower bounds of the value area calculated by the same method from the configured lookback of chart-timeframe bars through the current bar.
Long: close > Session VAH AND close > Range VAH OR (Session VAH + Session VAL) / 2 - (Range VAH + Range VAL) / 2 >= configured divergence threshold × (Range VAH - Range VAL) / 100
Short: close < Session VAL AND close < Range VAL OR (Session VAH + Session VAL) / 2 - (Range VAH + Range VAL) / 2 <= -configured divergence threshold × (Range VAH - Range VAL) / 100
