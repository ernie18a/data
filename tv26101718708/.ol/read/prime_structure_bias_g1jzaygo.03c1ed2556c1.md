Calculation: Confirmed swing structure = On higher-timeframe bars, detect pivot highs and lows using equal left and right lookbacks; a pivot becomes usable only after the right-side bars complete. Compare each new pivot high with the preceding pivot high (higher = HH, otherwise LH), and each new pivot low with the preceding pivot low (higher = HL, otherwise LL); retain the latest classifications.
Calculation: Higher-timeframe market is ranging = (highest high over the range lookback − lowest low over the range lookback) ÷ ATR(14) < range lookback × range threshold; use the higher-timeframe bar still forming for these values.
Calculation: Market bias = Start neutral. Using the higher-timeframe close still forming, set bullish when it is above the latest confirmed swing high; set bearish when it is below the latest confirmed swing low, with bearish taking precedence if both conditions hold. Then set bullish if the latest high and low classifications are HH and HL and the close is not below the latest confirmed swing low; set bearish if they are LH and LL and the close is not above the latest confirmed swing high. Otherwise retain the existing bias.
Long: higher-timeframe market is not ranging AND market bias is bullish
Short: higher-timeframe market is not ranging AND market bias is bearish
