Calculation: Current-session CPR = From the last completed bar of the higher daily timeframe: P = (high + low + close) / 3; BC = (high + low) / 2; TC = 2 × P − BC; CPR bottom = min(TC, BC); CPR top = max(TC, BC)
Calculation: Previous-session CPR = From the completed daily bar immediately before the one used for Current-session CPR, calculate P, BC, TC, CPR bottom, and CPR top using the same formulas
Calculation: R1 = 2 × P − low, using the last completed bar of the higher daily timeframe
Calculation: R2 = P + (high − low), using the last completed bar of the higher daily timeframe
Calculation: Cross above a level = current chart-bar close > current level AND previous chart-bar close ≤ previous chart-bar level
Calculation: Cross below a level = current chart-bar close < current level AND previous chart-bar close ≥ previous chart-bar level
Long: Current-session CPR bottom > Previous-session CPR top OR Cross above R1 OR Cross above R2
Short: Current-session CPR top < Previous-session CPR bottom OR Cross below S1 OR Cross below S2
