Calculation: Selected source = close, open, high, low, (open + high + low + close) / 4, (high + low + close) / 3, or (high + low) / 2
Calculation: Selected moving average = selected SMA, EMA, WMA, VWMA, RMA, Hull moving average, or TEMA of the selected source
Calculation: RSI = relative strength index of the selected source
Calculation: MACD = fast moving average of the selected source − slow moving average of the selected source
Calculation: Signal = selected moving average of MACD
Calculation: Histogram = MACD − Signal
Long: Within the configured date interval AND (selected long trigger is shorter-lookback moving average > longer-lookback moving average OR selected source > selected shorter-lookback moving average OR RSI is within its configured bounds OR MACD > Signal OR MACD > 0 OR Signal > 0) AND any enabled long filters hold: (MACD > Signal OR MACD > 0 OR Signal > 0 OR Histogram[1] < 0 AND Histogram > Histogram[1]) AND (higher-timeframe MACD > higher-timeframe Signal OR higher-timeframe MACD > 0 OR higher-timeframe Signal > 0 OR higher-timeframe shorter-lookback moving average > longer-lookback moving average OR higher-timeframe close > higher-timeframe shorter-lookback moving average); RSI bounds also apply to non-RSI triggers. Higher-timeframe calculations use the current, still-forming higher-timeframe bar. A long marking occurs when this condition becomes true after being false, or when it is true and a stop/take-profit event occurred on the prior bar; suppress it when a short-only closing event occurs.
Short: Within the configured date interval AND (selected short trigger is shorter-lookback moving average ≤ longer-lookback moving average OR selected source ≤ selected shorter-lookback moving average OR RSI is within its configured bounds OR MACD ≤ Signal OR MACD ≤ 0 OR Signal ≤ 0 OR the long condition is false) AND any enabled short filters hold: (MACD ≤ Signal OR MACD ≤ 0 OR Signal ≤ 0 OR Histogram[1] > 0 AND Histogram < Histogram[1]) AND (higher-timeframe MACD ≤ higher-timeframe Signal OR higher-timeframe MACD ≤ 0 OR higher-timeframe Signal ≤ 0 OR higher-timeframe shorter-lookback moving average ≤ longer-lookback moving average OR higher-timeframe close ≤ higher-timeframe shorter-lookback moving average); RSI bounds also apply to non-RSI triggers. Higher-timeframe calculations use the current, still-forming higher-timeframe bar. A short marking occurs when this condition becomes true after being false, or when it is true and a stop/take-profit event occurred on the prior bar; suppress it when a long-only closing event occurs.
Exit: Long, low ≤ entry price × (1 − configured stop-loss fraction) OR high ≥ entry price × (1 + configured take-profit fraction) OR the short condition is true
Exit: Short, high ≥ entry price × (1 + configured stop-loss fraction) OR low ≤ entry price × (1 − configured take-profit fraction) OR the long condition is true
