Calculation: Vol Peaks = From the chart-timeframe bars in the rolling profile lookback, divide the range from the lowest low to highest high into equal price bins. For each bar, add volume × bin height ÷ bar range to every bin its high-low range touches. A Vol Peak is a local bin-volume maximum meeting the minimum strength threshold; select peaks strongest first, enforcing the minimum distance and maximum peak count.
Calculation: Confluent zone = A zone whose full range contains a Vol Peak or is within ATR × tolerance of one.
Calculation: Bullish OB = At a confirmed pivot low, select the pivot candle if it is bearish and the next candle is bullish; otherwise select the following candle if the pivot candle is bullish and the candle before it is bearish; otherwise, if pivot and adjacent candles are all bullish, select the following candle as a bearish OB. The selected candle range (wicks or body per setting) must be at least the OB size multiplier × the average absolute candle body over the OB lookback, excluding the current bar. For the pivot-low cases, label the zone bullish except the all-bullish case, which is bearish.
Calculation: Bearish OB = At a confirmed pivot high, select the pivot candle if it is bullish and the next candle is bearish; otherwise select the following candle if the pivot candle is bearish and the candle before it is bullish; otherwise, if pivot and preceding candles are all bearish, select the following candle as a bullish OB. Apply the same OB size filter. For the pivot-high cases, label the zone bearish except the all-bearish case, which is bullish. Pivots require the configured number of chart bars on both sides; use only after confirmed.
Calculation: Bullish FVG = Current low > high two bars earlier, with gap size at least the FVG size multiplier × the average absolute candle body over the FVG lookback, excluding the current bar; zone is [high two bars earlier, current low].
Calculation: Bearish FVG = Current high < low two bars earlier, with gap size meeting the same FVG size filter; zone is [current high, low two bars earlier].
Calculation: Active zone state = A zone stays active until its close breaks its invalidation boundary: bullish zone close < bottom; bearish zone close > top. Track whether the previous bar's close was inside each active zone.
Long: Active, confluent bearish OB or bearish FVG and close > zone top OR active, confluent bullish OB or bullish FVG, previous close inside zone, and current close > zone top.
Short: Active, confluent bullish OB or bullish FVG and close < zone bottom OR active, confluent bearish OB or bearish FVG, previous close inside zone, and current close < zone bottom.
