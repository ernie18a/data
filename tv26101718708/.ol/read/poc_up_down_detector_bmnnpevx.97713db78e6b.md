Calculation: Daily POC = price midpoint of the highest-volume bin in the day’s volume profile, built from lower-timeframe bars; use completed bars for completed days. Divide the day’s low-to-high range into configured bins and allocate each bar’s volume by the configured profile method (Close, HLC3, range overlap, or weighted OHLC); break ties by choosing the bin midpoint nearest that day’s volume-weighted average close.
Calculation: Market state = update only when a new completed daily POC is available. Compare it with the preceding completed daily POC. In bullish state, remain bullish if it rises; otherwise become neutral and save that POC and the prior trend as bullish. In bearish state, remain bearish if it falls; otherwise become neutral and save that POC and the prior trend as bearish. In neutral state without a saved neutral POC, enter bullish or bearish when the POC moves in the same direction as the immediately preceding daily POC change. With a saved neutral POC, an upward change above it enters bullish; a downward change below it enters bearish if the saved prior trend was bullish, otherwise possible ranging. In possible ranging, enter bullish or bearish after two consecutive daily POC changes in the same direction. Track the immediately preceding daily POC change direction; equal POCs have no direction.
Calculation: High volume = current chart-bar volume > configured multiplier × the mean chart-bar volume from the start of the current calendar day through the current bar, with at least three bars counted.
Long: Market state is bullish AND the current calendar day has not fired a bullish signal AND a chart bar since the start of the current calendar day has had low < latest completed daily POC AND current close > latest completed daily POC AND high volume.
Long: A bullish signal has occurred earlier in the current calendar day AND current open < current close AND current close > latest completed daily POC.
Short: Market state is bearish AND the current calendar day has not fired a bearish signal AND a chart bar since the start of the current calendar day has had high > latest completed daily POC AND current close < latest completed daily POC AND high volume.
Short: A bearish signal has occurred earlier in the current calendar day AND current open > current close AND current close < latest completed daily POC.
