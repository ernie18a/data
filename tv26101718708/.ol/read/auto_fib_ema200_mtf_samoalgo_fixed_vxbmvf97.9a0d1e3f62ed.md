Calculation: Confirmed pivot high/low = a high/low greater/less than the highs/lows in the configured number of bars on both sides; confirmed only after the right-side bars complete
Calculation: Swing size = latest pivot high − latest pivot low
Calculation: Long Fib entry = latest pivot low + swing size × configured retracement fraction, using a pivot low that occurred before the pivot high
Calculation: Short Fib entry = latest pivot high − swing size × configured retracement fraction, using a pivot high that occurred before the pivot low
Calculation: MTF EMA agreement = count, across four requested timeframes, of chart close above (long) or below (short) that timeframe’s EMA; use the last completed bar for a higher timeframe and the current bar for a lower timeframe
Long: A long setup is active after a qualifying low-then-high swing whose size exceeds ATR × minimum swing multiple; close > long Fib entry; no open position; enough MTF EMA agreements if enabled; ATR > ATR moving average × minimum volatility multiple if enabled; datetime is within the enabled session if enabled; ADX > threshold if enabled; estimated reward/risk ≥ minimum if enabled; trades today < daily maximum if enabled; bars since last entry ≥ cooldown; and the setup’s pivot low differs from the last traded pivot low if same-swing avoidance is enabled
Short: A short setup is active after a qualifying high-then-low swing whose size exceeds ATR × minimum swing multiple; close < short Fib entry; no open position; enough MTF EMA agreements if enabled; ATR > ATR moving average × minimum volatility multiple if enabled; datetime is within the enabled session if enabled; ADX > threshold if enabled; estimated reward/risk ≥ minimum if enabled; trades today < daily maximum if enabled; bars since last entry ≥ cooldown; and the setup’s pivot high differs from the last traded pivot high if same-swing avoidance is enabled
Exit: Long, low ≤ stop price OR high ≥ target price; stop and target are set at entry using either ATR distances or the configured swing stop and Fibonacci extension (or fixed reward/risk target)
Exit: Short, high ≥ stop price OR low ≤ target price; stop and target are set at entry using either ATR distances or the configured swing stop and Fibonacci extension (or fixed reward/risk target)
