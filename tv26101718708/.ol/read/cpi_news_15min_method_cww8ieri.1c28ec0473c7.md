Calculation: Reference high = high of the higher-timeframe bar still forming
Calculation: Reference low = low of the higher-timeframe bar still forming
Calculation: Buy base = reference high in HTF mode, or current bar close in LTP mode
Calculation: Sell base = reference low in HTF mode, or current bar close in LTP mode
Calculation: Buy stop level = buy base + stop distance
Calculation: Buy limit level = sell base − limit distance
Calculation: Sell stop level = sell base − stop distance
Calculation: Sell limit level = buy base + limit distance
Long: bar high ≥ buy stop level OR bar low ≤ buy limit level
Short: bar low ≤ sell stop level OR bar high ≥ sell limit level
