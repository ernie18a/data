Calculation: True Strength Index = 100 × EMA with shorter lookback of EMA with longer lookback of change in close ÷ EMA with shorter lookback of EMA with longer lookback of absolute change in close; close is from the last completed bar at a lower or chart timeframe
Calculation: Signal line = EMA of True Strength Index
Long: True Strength Index crosses above signal line OR signal line > True Strength Index AND RSI(14) > 50
Short: True Strength Index crosses below signal line OR signal line < True Strength Index AND RSI(14) < 50
Exit: long, True Strength Index crosses below signal line OR signal line < True Strength Index AND RSI(14) < 50
Exit: short, True Strength Index crosses above signal line OR signal line > True Strength Index AND RSI(14) > 50
