Calculation: Adaptive flow = Kaufman adaptive moving average of price source: efficiency ratio = absolute change over the lookback divided by the sum of absolute one-bar changes over that lookback; smoothing constant = (ER × (2/(fast constant+1) − 2/(slow constant+1)) + 2/(slow constant+1))², where the fast constant is shorter than the slow constant; flow = previous flow + smoothing constant × (source − previous flow), but when the noise filter is enabled update only if the absolute change in the proposed flow exceeds ATR × noise threshold; otherwise retain previous flow. Initialize flow to source.
Calculation: Selected stop and trend = initialize trend bullish and stop to flow − ATR × multiplier. Use the selected mode: ATR trailing or Supertrend, in bullish trend set stop to max(previous stop, flow − ATR × multiplier), switching bearish and setting stop to flow + ATR × multiplier if flow < previous stop; in bearish trend set stop to min(previous stop, flow + ATR × multiplier), switching bullish and setting stop to flow − ATR × multiplier if flow > previous stop. Chandelier: bullish stop candidate = highest flow over stop lookback − ATR × multiplier; switch bearish and set stop to lowest flow over lookback + ATR × multiplier if flow < candidate, otherwise stop = max(previous stop, candidate); bearish uses the inverse rules. Donchian: use highest and lowest flow over stop lookback; bullish switches bearish and sets stop to highest flow if flow < lowest flow, otherwise stop = max(previous stop, lowest flow); bearish switches bullish and sets stop to lowest flow if flow > highest flow, otherwise stop = min(previous stop, highest flow). Volatility pivot: use last confirmed flow pivot low minus ATR × pivot buffer as bullish stop candidate, or flow − ATR × multiplier if unavailable; switch bearish if flow < candidate, setting stop to last confirmed flow pivot high plus ATR × pivot buffer, or flow + ATR × multiplier if unavailable; otherwise stop = max(previous stop, candidate). Bearish uses the inverse rules.
Calculation: Confirmed price swing high/low = pivot high/low confirmed using left and right bar lookbacks; compare the current close with the latest confirmed swing levels.
Long: selected trend changes from bearish to bullish AND source > EMA(200) AND (ADX filter disabled OR ADX ≥ threshold) AND (session filter disabled OR current bar is in session) AND bars since prior bullish signal ≥ cooldown; OR close > latest confirmed swing high AND structural trend is bullish AND structural bullish BOS count increases; OR close > latest confirmed swing high AND bearish BOS count ≥ required BOS count before CHoCH, causing structural trend to become bullish.
Short: selected trend changes from bullish to bearish AND source < EMA(200) AND (ADX filter disabled OR ADX ≥ threshold) AND (session filter disabled OR current bar is in session) AND bars since prior bearish signal ≥ cooldown; OR close < latest confirmed swing low AND structural trend is bearish AND structural bearish BOS count increases; OR close < latest confirmed swing low AND bullish BOS count ≥ required BOS count before CHoCH, causing structural trend to become bearish.
