Calculation: RSI = relative strength index of close prices
Calculation: Daily anchored VWAP and deviation bands = volume-weighted mean and standard deviation of hl2 since the start of each day; upper/lower band = VWAP plus/minus its respective configurable standard deviation multiple
Calculation: Divergence price = high/low when wick mode is selected, otherwise close
Calculation: Bear reference = latest saved divergence price and RSI from an overbought bar where RSI exceeds the saved reference RSI; clear when RSI < bear reset level or its age exceeds the maximum lookback; after a short signal, replace with the signal bar's values
Calculation: Bull reference = latest saved divergence price and RSI from an oversold bar where RSI is below the saved reference RSI; clear when RSI > bull reset level or its age exceeds the maximum lookback; after a long signal, replace with the signal bar's values
Long: RSI < oversold level AND (no active bull reference OR RSI < bull reference RSI)
Short: RSI > overbought level AND (no active bear reference OR RSI > bear reference RSI)
Long: active bull reference AND divergence price < bull reference price AND (bull reference price / divergence price - 1) * 100 >= minimum price extension AND RSI - bull reference RSI >= minimum RSI difference AND (RSI >= prior bar RSI when RSI turn confirmation is enabled) AND (close > open when bullish candle confirmation is enabled) AND (low <= lower VWAP band when VWAP filter is enabled in wick-touch mode; close <= lower VWAP band when enabled in close-outside mode) AND signal bar is confirmed when close confirmation is enabled AND no same-side signal occurred within the cooldown interval
Short: active bear reference AND divergence price > bear reference price AND (divergence price / bear reference price - 1) * 100 >= minimum price extension AND bear reference RSI - RSI >= minimum RSI difference AND (RSI <= prior bar RSI when RSI turn confirmation is enabled) AND (close < open when bearish candle confirmation is enabled) AND (high >= upper VWAP band when VWAP filter is enabled in wick-touch mode; close >= upper VWAP band when enabled in close-outside mode) AND signal bar is confirmed when close confirmation is enabled AND no same-side signal occurred within the cooldown interval
