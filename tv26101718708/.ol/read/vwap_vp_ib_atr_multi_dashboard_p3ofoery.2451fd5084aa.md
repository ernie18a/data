Calculation: Globex VWAP = volume-weighted average of each bar’s (open + high + low + close) / 4, reset at the Globex day boundary.
Calculation: Session VWAP = volume-weighted average of each bar’s (open + high + low + close) / 4, reset at each Tokyo, London, or RTH session open and accumulated only while one of those sessions is active.
Calculation: Globex value area = split each bar’s volume across fixed price rows in proportion to each row’s overlap with the bar; set the row range from the first bar’s midpoint ± 3 × max(first bar’s range, 500 minimum price increments). Start at the highest-volume row and add adjacent rows in descending volume order (ties go up) until the accumulated volume reaches the value-area percentage of total volume. Globex VAH and VAL are the upper and lower boundaries of the resulting rows; reset the profile at the Globex day boundary.
Calculation: Session value area = calculate VAH and VAL using the same row allocation and expansion method as the Globex value area, with the same row count and value-area percentage. Set the row range from the first bar’s midpoint ± 3 × max(first bar’s range, 500 minimum price increments); reset the profile at each Tokyo, London, or RTH session open and accumulate only while one of those sessions is active.
Calculation: Completed IB high/low = highest high and lowest low during the initial-balance window, available after that window ends and until the next one begins.
Long: close >= Globex VWAP OR (Session VWAP is defined AND close >= Session VWAP) OR (Globex VAH is defined AND close > Globex VAH) OR (Session VAH is defined AND close > Session VAH) OR (Completed IB high is defined AND close > Completed IB high)
Short: close < Globex VWAP OR (Session VWAP is defined AND close < Session VWAP) OR (Globex VAL is defined AND close < Globex VAL) OR (Session VAL is defined AND close < Session VAL) OR (Completed IB low is defined AND close < Completed IB low)
