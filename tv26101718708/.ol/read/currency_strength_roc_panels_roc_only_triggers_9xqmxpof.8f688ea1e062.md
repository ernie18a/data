Calculation: Currency RoC = For each of EUR, USD, JPY, CHF, GBP, AUD, CAD, and NZD, calculate its strength as the average of its seven signed log returns against the other currencies. Each pair return is 10,000 × ln(current pair close / reference pair close), using the configured anchor timeframe (higher or lower than the chart timeframe) close from the configured number of completed anchor bars back. Currency RoC is the linear-regression slope of strength over a lookback, optionally normalized as a z-score over a longer lookback; use the current chart bar value, or the prior completed chart bar value when closed-bar mode is enabled.
Calculation: Positive and negative trigger thresholds = either configured fixed levels, or plus and minus the configured multiplier times the standard deviation of the maximum absolute Currency RoC across the eight currencies over a lookback.
Long: Any currency's Currency RoC crosses above the positive trigger threshold
Short: Any currency's Currency RoC crosses below the negative trigger threshold
