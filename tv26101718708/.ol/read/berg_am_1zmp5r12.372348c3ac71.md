Calculation: Moving average = selected simple or exponential moving average of close; use progressively longer lookbacks for the ordered averages.
Calculation: Relative volume = volume divided by its moving average.
Calculation: Distance from moving average = (close − moving average) / moving average.
Long: close > each of the ordered moving averages
Short: close < each of the ordered moving averages
Long: shorter moving average > next longer moving average
Short: shorter moving average < next longer moving average
Long: absolute distance from the middle moving average <= the configured distance limit
Short: absolute distance from the middle moving average > the configured distance limit
Long: absolute distance from the shortest moving average <= the configured extension limit
Short: absolute distance from the shortest moving average > the configured extension limit
Long: relative volume >= the configured above-normal threshold
Short: relative volume < the configured above-normal threshold
