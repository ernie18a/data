Calculation: Fixed-window VWAP = volume-weighted average of HLC3 over each lookback window on the anchor timeframe (same as or higher than the chart timeframe), using the still-forming bar by default or the last completed bar when confirmed-only is enabled.
Calculation: Structure score = 50 × (number of window VWAPs below close / number of valid enabled VWAPs) + 50 × (signed stack total + adjacent-pair count) / (2 × adjacent-pair count); sort windows from shorter to longer, score each adjacent pair +1 when the shorter-window VWAP exceeds the longer by more than an ATR-based equality tolerance, −1 when it is below by more than the tolerance, and 0 otherwise. The tolerance uses ATR from the anchor timeframe, same as or higher than the chart timeframe, on the still-forming bar by default or the last completed bar when confirmed-only is enabled. Score is available only when all enabled VWAPs are valid and their lookbacks are distinct.
