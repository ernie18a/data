Calculation: Relative gap volume = average volume per price row inside the gap divided by average volume per row in the rolling composite volume profile; spread each chart bar’s volume evenly across the price rows from its low to high, and omit the gap’s two edge rows when it spans at least three rows.
Long: On an enabled same-or-higher timeframe, using completed bars, the latest bar’s low > the bar’s high three bars earlier AND the gap size >= the configured minimum × ATR of that timeframe AND (volume-profile confirmation is disabled OR relative gap volume <= the configured LVN threshold) OR the latest completed bar of an existing bearish FVG’s own timeframe closes > that gap’s top AND (iFVG creation allows unconfirmed FVGs OR the FVG is LVN-confirmed).
Short: On an enabled same-or-higher timeframe, using completed bars, the latest bar’s high < the bar’s low three bars earlier AND the gap size >= the configured minimum × ATR of that timeframe AND (volume-profile confirmation is disabled OR relative gap volume <= the configured LVN threshold) OR the latest completed bar of an existing bullish FVG’s own timeframe closes < that gap’s bottom AND (iFVG creation allows unconfirmed FVGs OR the FVG is LVN-confirmed).
