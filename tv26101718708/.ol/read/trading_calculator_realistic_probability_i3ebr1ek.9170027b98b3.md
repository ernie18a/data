Calculation: Momentum score = arithmetic mean of 14-period RSI, 14-period Stochastic, and 14-period MFI, calculated on the selected timeframe (chart timeframe if unset); use the bar still forming when the selected timeframe differs from the chart timeframe.
Calculation: Bullish probability = 100 × bullish wins / (bullish wins + bearish wins); bearish probability = 100 × bearish wins / (bullish wins + bearish wins). For each historical bar from the prediction horizon plus one bars ago through the historical lookback, count it as a match when the absolute difference between its momentum score and the current momentum score is within the similarity threshold. For each match, use that bar’s close and ATR to set targets at close plus and minus ATR times the target multiplier. Scan the following bars, from the bar after the historical bar through the prediction horizon: a bar that reaches only the upper target gives a bullish win; one that reaches only the lower target gives a bearish win; if both are reached on the same bar, continue scanning. If neither target is reached alone, or both are reached together on every scanned bar, the case is neutral and excluded from both probabilities. Use the selected timeframe (chart timeframe if unset); when it differs from the chart timeframe, use the bar still forming.
Long: bullish probability > bearish probability AND bullish wins + bearish wins > 0
Short: bearish probability > bullish probability AND bullish wins + bearish wins > 0
