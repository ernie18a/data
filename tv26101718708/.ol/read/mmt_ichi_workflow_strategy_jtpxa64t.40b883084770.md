Calculation: Tenkan-sen = midpoint of the highest high and lowest low over a shorter lookback
Calculation: Kijun-sen = midpoint of the highest high and lowest low over a longer lookback than Tenkan-sen
Calculation: Leading Span A = midpoint of Tenkan-sen and Kijun-sen
Calculation: Leading Span B = midpoint of the highest high and lowest low over a lookback longer than the Kijun-sen lookback
Calculation: Current cloud top/bottom = maximum/minimum of Leading Span A and Leading Span B from the displacement lookback bars ago
Calculation: Price state = 1 when close is above the current cloud top, -1 when close is below the current cloud bottom, otherwise 0
Calculation: Future cloud state = 1 when current Leading Span A is above current Leading Span B, -1 when below, otherwise 0
Calculation: Tenkan-Kijun state = 1 when Tenkan-sen is above Kijun-sen, -1 when below, otherwise 0
Calculation: Chikou state = 1 when close is above both the open/close body high from the displacement lookback bars ago and the cloud top from twice the displacement lookback bars ago; -1 when close is below both the body low and cloud bottom at those respective lookbacks; otherwise 0
Calculation: Chart-timeframe score = price state + future cloud state + Tenkan-Kijun state + Chikou state
Calculation: Higher-timeframe score = the same four-state sum calculated on the last completed bar of a higher timeframe
Long: Flat position AND longs permitted by the direction filter AND ((higher-timeframe score >= 3 AND chart-timeframe score >= 2 AND previous close was within the previous cloud AND close > current cloud top AND this breakout condition was false on the previous bar) OR (higher-timeframe score >= 3 AND price state = 1 AND future cloud state = 1 AND Tenkan-Kijun state = 1 AND Chikou state = 1 AND chart-timeframe score = 4 AND this checklist condition was false on the previous bar) OR (higher-timeframe score >= 3 AND chart-timeframe score >= 3 AND price state = 1 AND future cloud state = 1 AND low <= Kijun-sen AND close > Kijun-sen AND close > open AND previous close > previous Kijun-sen AND this Kijun bounce condition was false on the previous bar))
Short: Flat position AND shorts permitted by the direction filter AND ((higher-timeframe score <= -3 AND chart-timeframe score <= -2 AND previous close was within the previous cloud AND close < current cloud bottom AND this breakout condition was false on the previous bar) OR (higher-timeframe score <= -3 AND price state = -1 AND future cloud state = -1 AND Tenkan-Kijun state = -1 AND Chikou state = -1 AND chart-timeframe score = -4 AND this checklist condition was false on the previous bar) OR (higher-timeframe score <= -3 AND chart-timeframe score <= -3 AND price state = -1 AND future cloud state = -1 AND high >= Kijun-sen AND close < Kijun-sen AND close < open AND previous close < previous Kijun-sen AND this Kijun bounce condition was false on the previous bar))
Exit: Long, Tenkan-Kijun state = -1 AND previous Tenkan-Kijun state != -1 OR close < Kijun-sen OR close <= current cloud top
Exit: Short, Tenkan-Kijun state = 1 AND previous Tenkan-Kijun state != 1 OR close > Kijun-sen OR close >= current cloud bottom
