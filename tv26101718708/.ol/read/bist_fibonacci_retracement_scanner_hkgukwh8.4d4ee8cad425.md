Calculation: Confirmed swing high/low = a bar whose high/low is respectively greater/less than the bars on both sides over the same swing lookback; update the latest and previous swing values when confirmed, using chart-timeframe bars.
Calculation: Uptrend = when both latest swings exist, latest swing low > previous swing low if a previous swing low exists, otherwise close > latest swing low; if neither previous swing exists, use close > EMA(close, longer lookback). Downtrend = when both latest swings exist, latest swing high < previous swing high if a previous swing high exists, otherwise close < latest swing high; if neither previous swing exists, use close < EMA(close, longer lookback).
Calculation: Uptrend Fibonacci retracement level = latest swing high - (latest swing high - latest swing low) × configured retracement ratio. Downtrend Fibonacci retracement level = latest swing low + (latest swing high - latest swing low) × configured retracement ratio.
Calculation: Near a Fibonacci level = absolute(close - level) / level × 100 <= configured tolerance percentage.
Long: Uptrend AND close is near any enabled uptrend Fibonacci level AND (RSI confirmation is disabled OR RSI(14) < configured oversold threshold) AND (volume confirmation is disabled OR volume / SMA(volume, longer lookback) >= configured minimum ratio)
Short: Downtrend AND close is near any enabled downtrend Fibonacci level AND (RSI confirmation is disabled OR RSI(14) > configured overbought threshold) AND (volume confirmation is disabled OR volume / SMA(volume, longer lookback) >= configured minimum ratio)
