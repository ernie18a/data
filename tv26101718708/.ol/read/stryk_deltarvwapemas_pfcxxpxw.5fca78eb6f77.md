Calculation: Rolling VWAP and bands = volume-weighted mean of the selected price over the selected rolling or anchored chart-bar window, with volume-weighted standard deviation bands; includes the forming chart bar. The selected session window controls which bars contribute.
Calculation: Delta = footprint buy volume minus sell volume when available; otherwise sum lower-timeframe bar volume as positive for an up bar and negative for a down bar, with chart-bar direction as fallback. Lower-timeframe bars are aggregated from the backtest bars.
Calculation: Max Delta Print = a qualifying in-session bar meeting either (aggression: absolute modified delta z-score against a rolling median/MAD baseline >= its threshold AND relative volume against the same-time-of-day baseline, or rolling volume baseline when that slot is not ready, >= its threshold AND absolute delta >= its floor) OR (absorption: the same relative-volume threshold AND either selected effort/result test passes, where effort is volume per tick of bar range or absolute body, relative to its rolling median, and result is range or body ticks relative to its rolling median). Aggression requires unusually large absolute delta; absorption requires unusually large effort and unusually small result. In session-record mode, retain a qualifying print only if its score is at least the prior score of the same print type in the session; otherwise every qualifying bar is a print. Use longer rolling baselines for scale and same-time-of-day baselines for slot-specific volume and absolute delta.
Calculation: VWAP slope = current rolling VWAP minus its value at the longer slope lookback; rising/falling means the change exceeds the configured flat threshold in the corresponding direction.
Calculation: Print direction and score = at a one-sided VWAP deviation edge, a reversal print points toward VWAP and scores one point for reaching the edge, one for flow failure (absorption delta points into the edge, or aggression delta points toward VWAP), and one for a strong close toward VWAP. An aggression print away from the edge is continuation only when its close is on the delta side of VWAP; it scores one point each for that close side, VWAP slope aligned with delta, and a strong close in the delta direction. Reversal direction is toward VWAP; continuation direction follows delta. A bar reaching both edges is not an edge print.
Calculation: EMA bias = enabled chart-timeframe, daily, and weekly moving-average lines vote up when close is above the line and down when below; daily and weekly lines use their respective higher-timeframe bars, each either including the forming bar or using the last completed bar. Optionally require each vote's line slope to agree. A configured bias filter requires either a directional majority or all enabled votes to agree.
Long: (Max Delta Print AND reversal direction is up AND reversal score >= configured arming threshold AND (reversal source allows this print type) AND within the configured bars after the print close > lower VWAP deviation edge AND selected VWAP-slope rule passes AND selected EMA-bias filter passes AND no intervening close below the print low) OR (Max Delta Print AND continuation direction is up AND continuation score >= configured arming threshold AND VWAP slope rising AND selected EMA-bias filter passes AND the configured number of subsequent consecutive closes remain above VWAP while VWAP is not falling) OR (directional reversal context print is up AND its score >= configured label threshold) OR (directional continuation context print is up AND its score >= configured label threshold).
Short: (Max Delta Print AND reversal direction is down AND reversal score >= configured arming threshold AND (reversal source allows this print type) AND within the configured bars after the print close < upper VWAP deviation edge AND selected VWAP-slope rule passes AND selected EMA-bias filter passes AND no intervening close above the print high) OR (Max Delta Print AND continuation direction is down AND continuation score >= configured arming threshold AND VWAP slope falling AND selected EMA-bias filter passes AND the configured number of subsequent consecutive closes remain below VWAP while VWAP is not rising) OR (directional reversal context print is down AND its score >= configured label threshold) OR (directional continuation context print is down AND its score >= configured label threshold).
