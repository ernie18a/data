Calculation: Stable regime = On each new analysis-timeframe bar (same as or higher than the chart timeframe), use the last completed analysis-timeframe bar: smooth the short-end and long-end yields with the same lookback, then measure each smoothed yield’s change over the same observation horizon. Level move = (short-yield change + long-yield change) / 2; curve move = long-yield change − short-yield change. Classify an observation as bull steepener when level move is negative and curve move positive, bull flattener when both are negative, bear steepener when both are positive, and bear flattener when level move is positive and curve move negative; an observation is neutral if either move is zero or its absolute value is below its configured minimum. Over the configured rolling window, score each regime using either equal votes or magnitude weights equal to sqrt(abs(level move) × abs(curve move)); calculate classified coverage, each regime’s share of total score, and the runner-up share. The leader qualifies only when the configured history, coverage, minimum dominant share, and minimum lead conditions are met. Switch the stable regime to a different qualified leader only after it remains qualified for the configured consecutive analysis bars; when no leader qualifies, hold the previous stable regime if configured, otherwise set it to unclear.
Long: Stable regime changes to bull steepener OR bull flattener
Short: Stable regime changes to bear steepener OR bear flattener
