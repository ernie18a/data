Calculation: CAGR = (current higher-timeframe close / close N higher-timeframe bars ago)^(365 / elapsed days between those bars) − 1; use the still-forming higher-timeframe bar
Calculation: Z-score = (CAGR − its N-bar simple moving average) / its N-bar standard deviation; use the still-forming higher-timeframe bar
Calculation: Slope = current signal value − signal value N bars ago, where signal value is CAGR or Z-score according to the selected mode
Long: Z-score mode AND Extremes mode AND Z-score ≤ lower threshold OR Z-score mode AND Trend mode AND Slope ≥ 0
Short: Z-score mode AND Extremes mode AND Z-score ≥ upper threshold OR Z-score mode AND Trend mode AND Slope < 0
