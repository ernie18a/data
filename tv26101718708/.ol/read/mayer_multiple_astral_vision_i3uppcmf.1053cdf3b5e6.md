Calculation: Mayer Multiple = higher-timeframe close divided by the simple moving average of higher-timeframe closes, using the current higher-timeframe bar, including while it is still forming
Calculation: Mayer Multiple MA = simple moving average of the Mayer Multiple
Long: Mayer Multiple < oversold threshold OR (color mode = Trend AND Mayer Multiple > Mayer Multiple MA)
Short: Mayer Multiple > overbought threshold OR (color mode = Trend AND Mayer Multiple < Mayer Multiple MA)
