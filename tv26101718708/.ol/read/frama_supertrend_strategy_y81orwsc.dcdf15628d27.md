Calculation: FRAMA = fractal adaptive moving average of close using higher-timeframe bars, evaluated on the last completed higher-timeframe bar
Calculation: FRAMA signal = FRAMA applied to FRAMA on the same higher timeframe, using the same lookback
Long: FRAMA crosses above FRAMA signal OR (close crosses above the Supertrend line AND close > the Supertrend line) OR Supertrend changes from bearish to bullish
Short: FRAMA crosses below FRAMA signal OR (close crosses below the Supertrend line AND close < the Supertrend line) OR Supertrend changes from bullish to bearish
Exit: long, Supertrend is bearish
Exit: short, Supertrend is bullish
