Calculation: Demand Index = Let P = high + low + 2×close; range = max(high, prior high) − min(low, prior low); range average and volume average are EMAs over the same lookback. Let H0 and L0 be the high and low of the first loaded bar, and R = max(H0−L0, minimum tick). Let V = volume / volume average (or 1 if the average is zero). If P < prior P, buy power = V / exp(0.375×(P+prior P)/R×(prior P−P)/P), sell power = V. If P > prior P, buy power = V, sell power = V / exp(0.375×(P+prior P)/R×(P−prior P)/prior P). Otherwise both equal V. Smooth buy and sell power with EMAs over the same lookback. If smoothed buy power > smoothed sell power, Demand Index = 100×(1−sell/buy); if buy < sell, it = 100×(buy/sell−1); otherwise 0.
Calculation: Setup active = becomes true when higher-timeframe Demand Index <= deep level; becomes false when it > 0; otherwise retains its prior state. Use the current higher-timeframe bar, which may still be forming.
Calculation: Trigger EMA = EMA of lower-timeframe Demand Index sampled on the chart timeframe; use the current lower-timeframe bar, which may still be forming.
Calculation: Long stop = entry price×(1−stop-loss fraction) in fixed mode; in trailing mode it is the greater of the prior stop and close×(1−stop-loss fraction), updated while long. Long target = entry price×(1+take-profit fraction).
Long: Setup active AND higher-timeframe Demand Index > recovery level AND lower-timeframe Demand Index crosses above Trigger EMA.
Exit: Long, low <= Long stop OR high >= Long target.
