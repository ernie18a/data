Calculation: Bullish sweep count = number of the lookback bars whose low is above the current close
Calculation: Bearish sweep count = number of the lookback bars whose high is below the current close
Calculation: Active bullish sweep = set on a bar when bullish sweep count ≥ floor(lookback × threshold); store that bar’s low and high, reset its age to 1 and fired state to false; increment age on each later bar; clear if close < stored low; a new qualifying sweep resets the state
Calculation: Active bearish sweep = set on a bar when bearish sweep count ≥ floor(lookback × threshold); store that bar’s low and high, reset its age to 1 and fired state to false; increment age on each later bar; clear if close > stored high; a new qualifying sweep resets the state
Long: Active bullish sweep on the last completed chart bar AND not fired AND its age ≤ confirmation window + 1 AND that bar’s close > the stored sweep high AND its volume > volume SMA × minimum volume multiplier AND it is within the configured session AND current higher-timeframe close > current higher-timeframe EMA
Short: Active bearish sweep on the last completed chart bar AND not fired AND its age ≤ confirmation window + 1 AND that bar’s close < the stored sweep low AND its volume > volume SMA × minimum volume multiplier AND it is within the configured session AND current higher-timeframe close < current higher-timeframe EMA
