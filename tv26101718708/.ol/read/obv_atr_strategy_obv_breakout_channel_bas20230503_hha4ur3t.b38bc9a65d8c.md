Calculation: OBV = cumulative sum of volume multiplied by the sign of the current close minus the previous close
Calculation: OBV mode = bullish when OBV crosses above the prior bar’s rolling highest OBV; bearish when OBV crosses below the prior bar’s rolling lowest OBV; otherwise retains its prior state; initially neutral
Long: OBV crosses above the prior bar’s rolling highest OBV AND prior mode is not bullish
Short: OBV crosses below the prior bar’s rolling lowest OBV AND prior mode is not bearish
Exit: long, OBV crosses below the prior bar’s rolling lowest OBV AND prior mode is not bearish
Exit: short, OBV crosses above the prior bar’s rolling highest OBV AND prior mode is not bullish
