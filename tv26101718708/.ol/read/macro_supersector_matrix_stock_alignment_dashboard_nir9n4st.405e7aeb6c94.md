Calculation: Daily percentage change = (current daily close − previous daily close) / previous daily close × 100, using the still-forming daily bar and the last completed daily bar
Calculation: Macro bias = sum of four scores: for each of Growth, Cyclicals, and Defensives, 25 if its mean daily percentage change is > 0 and at least one constituent’s daily volume exceeds its 20-bar daily volume SMA, otherwise 12.5 if the mean change is > 0, otherwise 0; plus 25 if SPY’s daily percentage change is > 0, otherwise 0. Use the still-forming daily bar for current close and volume, and the last completed daily bar for previous close. Each volume SMA uses the daily bars, including the still-forming bar.
Calculation: Growth mean daily percentage change = arithmetic mean of XLK, XLY, and XLC daily percentage changes
Calculation: Cyclicals mean daily percentage change = arithmetic mean of XLF, XLI, XLB, and XLE daily percentage changes
Calculation: Defensives mean daily percentage change = arithmetic mean of XLV, XLP, XLU, and XLRE daily percentage changes
Long: Macro bias > 50
Short: Macro bias <= 50
