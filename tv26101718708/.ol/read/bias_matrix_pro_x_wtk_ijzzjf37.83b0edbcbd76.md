Calculation: Timeframe score = clamp(ADX-adjusted sum of directional component scores, −100, 100). Calculate each component on that timeframe’s bars: EMA structure is +1 when fast EMA > slow EMA, −1 when <, otherwise 0; price location is +1 when close > fast EMA, −1 when <, otherwise 0; EMA slope is +1 when fast EMA minus its value at a shorter lookback exceeds ATR times a neutral-band parameter, −1 when below the negative band, otherwise 0; RSI regime is +1 above its bullish threshold, −1 below its bearish threshold, otherwise 0 (bearish threshold < bullish threshold); MACD momentum is +1 when histogram > 0, −1 when < 0, otherwise 0 (fast length < slow length); Supertrend direction is +1 bullish and −1 bearish. Sum each state times its component weight, then add the alignment-bonus weight times the common nonzero state when EMA structure, price location, EMA slope, MACD, and Supertrend all agree. Multiply by clamp(0.65 + 0.45 × min(ADX, ADX reference) / ADX reference, 0.65, 1.10). For a selected timeframe higher than the chart timeframe, use its last completed bar; for the chart timeframe use the active bar; exclude selected timeframes lower than the chart timeframe.
