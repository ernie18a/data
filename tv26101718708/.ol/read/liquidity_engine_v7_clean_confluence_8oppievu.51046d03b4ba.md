Calculation: Previous-day high/low = high/low of the last completed daily bar (higher timeframe).
Calculation: Bullish liquidity sweep = opening range is complete AND (low < previous-day low AND close > previous-day low OR low < opening-range low AND close > opening-range low).
Calculation: Bearish liquidity sweep = opening range is complete AND (high > previous-day high AND close < previous-day high OR high > opening-range high AND close < opening-range high).
Calculation: Bullish sweep active = a bullish liquidity sweep occurred within the configured sweep-memory bars.
Calculation: Bearish sweep active = a bearish liquidity sweep occurred within the configured sweep-memory bars.
Calculation: Bullish trendline break = close crosses above the active resistance trendline, with the prior close at or below that line on the prior bar.
Calculation: Bearish trendline break = close crosses below the active support trendline, with the prior close at or above that line on the prior bar.
Calculation: Bullish trendline break active = a bullish trendline break occurred within the configured confirmation-memory bars.
Calculation: Bearish trendline break active = a bearish trendline break occurred within the configured confirmation-memory bars.
Calculation: Confirmed swing high/low = a pivot high/low confirmed using the configured number of bars on each side.
Calculation: Bullish structure break = close crosses above the latest confirmed swing high, with the prior close at or below that swing high.
Calculation: Bearish structure break = close crosses below the latest confirmed swing low, with the prior close at or above that swing low.
Calculation: Bullish structure break active = a bullish structure break occurred within the configured structure-memory bars.
Calculation: Bearish structure break active = a bearish structure break occurred within the configured structure-memory bars.
Calculation: Bullish fair value gap = current low > high two bars earlier AND the gap is at least the configured minimum ATR multiple.
Calculation: Bearish fair value gap = current high < low two bars earlier AND the gap is at least the configured minimum ATR multiple.
Calculation: Bearish inversion gap event = close breaks below the bottom of an unexpired bullish fair value gap.
Calculation: Bullish inversion gap event = close breaks above the top of an unexpired bearish fair value gap.
Calculation: Bullish order block trigger = bullish structure break AND bullish candle range meets the configured ATR displacement threshold AND an opposite, bearish candle is found within the configured preceding-bar search.
Calculation: Bearish order block trigger = bearish structure break AND bearish candle range meets the configured ATR displacement threshold AND an opposite, bullish candle is found within the configured preceding-bar search.
Calculation: Bullish flow score = sum of threshold-based points for relative volume, candle range divided by ATR, candle body divided by candle range, and absolute close-to-VWAP distance divided by session standard deviation.
Calculation: Bearish flow score = same flow score as bullish flow score.
Calculation: Bullish flow mark = close > open AND bullish flow score meets the configured minimum bubble score AND the bullish bubble cooldown has elapsed.
Calculation: Bearish flow mark = close < open AND bearish flow score meets the configured minimum bubble score AND the bearish bubble cooldown has elapsed.
Calculation: Bullish flow confirmation = close > open AND bullish flow score meets the configured strong-flow threshold.
Calculation: Bearish flow confirmation = close < open AND bearish flow score meets the configured strong-flow threshold.
Calculation: Bullish VWAP condition = close > session VWAP.
Calculation: Bearish VWAP condition = close < session VWAP.
Calculation: Bullish opening-range retest = after a close breakout above the completed opening-range high, within the configured confirmation window, low reaches the high plus configured tick tolerance and close remains above the high.
Calculation: Bearish opening-range retest = after a close breakout below the completed opening-range low, within the configured confirmation window, high reaches the low minus configured tick tolerance and close remains below the low.
Calculation: Bullish opening-range confirmation = bullish opening-range retest occurred within the configured confirmation-memory bars OR close > completed opening-range high.
Calculation: Bearish opening-range confirmation = bearish opening-range retest occurred within the configured confirmation-memory bars OR close < completed opening-range low.
Calculation: Bullish zone confirmation = a bullish fair value gap, bullish inversion gap event, or bullish order block trigger occurred within the configured confirmation-memory bars.
Calculation: Bearish zone confirmation = a bearish fair value gap, bearish inversion gap event, or bearish order block trigger occurred within the configured confirmation-memory bars.
Calculation: Bullish confluence score = count of true conditions among bullish sweep active, bullish trendline break active, bullish structure break active, bullish VWAP condition, bullish flow confirmation, bullish zone confirmation, and bullish opening-range confirmation.
Calculation: Bearish confluence score = count of true conditions among bearish sweep active, bearish trendline break active, bearish structure break active, bearish VWAP condition, bearish flow confirmation, bearish zone confirmation, and bearish opening-range confirmation.
Long: bullish liquidity sweep OR bullish trendline break OR bullish structure break OR bullish flow mark OR bullish fair value gap OR bullish inversion gap event OR bullish order block trigger OR (bullish confluence score meets the configured minimum confirmation count AND bullish confluence score > bearish confluence score).
Short: bearish liquidity sweep OR bearish trendline break OR bearish structure break OR bearish flow mark OR bearish fair value gap OR bearish inversion gap event OR bearish order block trigger OR (bearish confluence score meets the configured minimum confirmation count AND bearish confluence score > bullish confluence score).
