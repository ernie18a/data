Calculation: Hull value of a series = WMA(2 × WMA(series, shorter lookback) − WMA(series, longer lookback), square-root lookback), with the shorter lookback approximately half the longer; calculate one value from the series and one from the same series lagged by one chart bar. For currency-index and gold-in-local-currency series, use the last completed bar of the requested timeframe, whether higher or lower than the chart timeframe; apply Hull lookbacks to the sampled series at the chart timeframe.
Calculation: Daily OHLC4 change = (previous completed daily bar's OHLC4 − OHLC4 from two completed daily bars ago) / OHLC4 from two completed daily bars ago.
Long: position side = flat AND currency-index Hull value < its one-chart-bar-lagged Hull value AND gold-in-local-currency Hull value > its one-chart-bar-lagged Hull value AND chart-series Hull value > its one-chart-bar-lagged Hull value AND Daily OHLC4 change > a positive threshold
Short: position side = flat AND currency-index Hull value > its one-chart-bar-lagged Hull value AND gold-in-local-currency Hull value < its one-chart-bar-lagged Hull value AND chart-series Hull value < its one-chart-bar-lagged Hull value AND Daily OHLC4 change < a positive threshold
Exit: long, currency-index Hull value > its one-chart-bar-lagged Hull value AND Daily OHLC4 change < a positive threshold
Exit: short, currency-index Hull value < its one-chart-bar-lagged Hull value AND Daily OHLC4 change > a positive threshold
