Calculation: Long-term swing highs and lows = Stateful pivots detected with the longer swing lookback: compare the bar `lookback` bars ago with the highest high and lowest low over the current lookback bars; record a pivot high when the detector switches to high mode and a pivot low when it switches to low mode. The detector switches to high mode when the current low is below that lowest low, and to low mode when the current high is above that highest high.
Calculation: Short-term swing highs and lows = The same stateful pivot calculation using a shorter lookback than the long-term swing calculation.
Calculation: Bullish structure = Close has crossed above the latest long-term swing high and the structure state changes from bearish to bullish; remain bullish until close crosses below the latest long-term swing low, then change to bearish. Bearish structure is the converse.
Calculation: Bullish mean-reversion marker = The close-selected outer band is the lowest low over the longer cloud lookback when close is above the cloud value, otherwise the highest high over that lookback. The cloud value becomes the highest high when low equals the lowest low, becomes the lowest low when high equals the highest high, and otherwise retains its prior value. The inner band uses the same rule with a shorter lookback. The marker condition is low crossing above the prior inner band, prior inner band equaling prior low, current low differing from the current inner band, no current-bar crossing of the outer band, and the outer band unchanged from the prior bar.
Calculation: Bearish mean-reversion marker = Using the same cloud bands, high crosses below the prior inner band, prior inner band equals prior high, current high differs from the current inner band, there is no current-bar crossing of the outer band, and the outer band is unchanged from the prior bar.
Calculation: Trend state = Calculate a zero-lag EMA as an EMA of close plus the difference between close and close from floor((length − 1) / 2) bars ago. Calculate the band width as the highest ATR over three times the EMA length, multiplied by a parameter. Set the state bullish when close crosses above the EMA plus band width; set it bearish when close crosses below the EMA minus band width; otherwise retain the prior state.
Calculation: Bullish BOS marker = Close is above the running structure maximum, the short-term swing low has been crossed below while structure is bullish, and that short-term swing low differs from the latest long-term swing low. The short-term swing-low-crossed flag resets on a structure change and after this marker.
Calculation: Bullish liquidity-sweep marker = Structure is bullish, the current high exceeds the running structure maximum, the close is below that maximum, and the maximum was last updated more than one bar ago.
Calculation: Bearish liquidity-sweep marker = Structure is bearish, the current low is below the running structure minimum, the close is above that minimum, and the minimum was last updated more than one bar ago.
Long: Bullish mean-reversion marker AND trend state is bullish OR bearish BOS marker OR bearish liquidity-sweep marker
Short: Bearish mean-reversion marker AND trend state is bearish OR bullish BOS marker OR bullish liquidity-sweep marker
