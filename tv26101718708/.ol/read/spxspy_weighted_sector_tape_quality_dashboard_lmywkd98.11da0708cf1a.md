Calculation: Sector weighted contribution = sector percent move multiplied by that sector's weight
Calculation: Net weighted contribution = sum of all sector weighted contributions
Calculation: Positive sector count = number of sectors with positive weighted contribution
Calculation: Weighted positive participation = sum of weights for sectors with positive weighted contribution
Calculation: Cyclical score = sum of weighted contributions for technology, financials, consumer discretionary, communication services, industrials, energy, and materials
Calculation: Defensive score = sum of weighted contributions for healthcare, consumer staples, and utilities
Calculation: Risk tone = cyclical score minus defensive score
Calculation: Mega-cap impact = technology, communication services, and consumer discretionary weighted contributions summed
Calculation: Mega-cap concentration = sum of the absolute weighted contributions for those three sectors divided by the sum of absolute weighted contributions for all sectors; zero if the denominator is zero
Calculation: Tape quality score = EMA of the sum of: net contribution score (25 if net contribution > 0.40, 15 if > 0.15, 7 if > 0, -25 if < -0.40, -15 if < -0.15, -7 if < 0, otherwise 0); weighted participation score (25 if >= 75, 15 if >= 60, 5 if >= 50, -25 if <= 25, -15 if <= 40, -5 if < 50, otherwise 0); sector breadth score (20 if count >= 9, 12 if >= 7, 5 if >= 6, -20 if <= 2, -12 if <= 4, -5 if <= 5, otherwise 0); risk tone score (15 if > 0.20, 8 if > 0.05, -15 if < -0.20, -8 if < -0.05, otherwise 0); and VIX move score (15 if < -1.00%, 8 if < -0.25%, -15 if > 1.00%, -8 if > 0.25%, otherwise 0)
