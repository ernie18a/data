Calculation: Volume and absolute net volume delta thresholds = interpolated percentiles over short-, medium-, and long-lookback windows, with short < medium < long; use the configured percentile for each tier.
Calculation: A metric qualifies at a tier when it meets that tier’s threshold in the configured number of the three lookback windows. Test tiers in order: big, medium, small.
Calculation: A cluster qualifies when the selected detection method is met: volume only, delta only, both, or either. If lower-timeframe delta is unavailable, use volume only. Delta is net buy-sell volume delta from bars lower than the chart timeframe within the current chart bar, using the latest available lower-timeframe data.
Long: An enabled cluster tier qualifies AND the selected classification is bullish: close >= open for candle direction; net volume delta > 0 for delta direction; or both conditions for both mode. If delta is unavailable, use close >= open.
Short: An enabled cluster tier qualifies AND the selected classification is bearish: close < open for candle direction; net volume delta < 0 for delta direction; or both conditions for both mode. If delta is unavailable, use close < open.
