Calculation: Candle anatomy = range = max(high − low, minimum price increment); body = |close − open|; body fraction = body / range; upper wick = high − max(open, close); lower wick = min(open, close) − low; close position = (close − low) / range. Bullish body: close > open; bearish body: close < open; strong body: body fraction ≥ 0.55; thin body: body fraction ≤ 0.24.
Calculation: Trend state = bullish when fast EMA > slow EMA and linear-regression slope ≥ 0; bearish when fast EMA < slow EMA and slope ≤ 0; otherwise neutral. Fast EMA uses a shorter lookback than slow EMA. Regression slope = current linear-regression value − its prior-bar value.
Calculation: Regression field = regression base ± 1.35 × standard deviation of (close − regression base); mid-field boundaries = regression base ± 0.45 × that standard deviation. Near lower field: close ≤ lower mid-field boundary OR low ≤ lower field boundary. Near upper field: close ≥ upper mid-field boundary OR high ≥ upper field boundary.
Calculation: Momentum = bullish when RSI > 50 and greater than its prior-bar value; bearish when RSI < 50 and less than its prior-bar value.
Calculation: Volume expansion = volume / 30-bar simple moving average of volume ≥ 1.25 (use 1 when the average is zero).
Calculation: Wick rejection = bullish when lower wick ≥ 1.45 × body and close position ≥ 0.58; bearish when upper wick ≥ 1.45 × body and close position ≤ 0.42.
Calculation: Structure levels = latest confirmed pivot high and pivot low, each using the configured left- and right-bar counts. Bullish structure break: close > latest pivot high; bearish structure break: close < latest pivot low. CHoCH up: current close > latest pivot high and prior close ≤ it. CHoCH down: current close < latest pivot low and prior close ≥ it. A pivot is available only after its right-side bars complete.
Calculation: Bullish location match = near lower field OR (bullish trend state AND close > fast EMA). Bearish location match = near upper field OR (bearish trend state AND close < fast EMA). For inside-break, marubozu, three-candle sequence, and rail candidates, location match instead means close > fast EMA for bullish candidates or close < fast EMA for bearish candidates.
Calculation: Pattern candidates (evaluate only on a completed chart-timeframe bar): bullish/bearish engulfing = opposite-color prior body and current body engulfing it (bullish: open ≤ prior close, close ≥ prior open; bearish: open ≥ prior close, close ≤ prior open), current body ≥ 0.75 × prior body. Hammer: bullish body, lower wick ≥ 1.8 × body, upper wick ≤ 0.22 × range, close position ≥ 0.60. Inverted hammer: bullish body, upper wick ≥ 1.65 × body, close position ≥ 0.48, near lower field. Shooting star: bearish body, upper wick ≥ 1.8 × body, lower wick ≤ 0.22 × range, close position ≤ 0.40. Hanging man: bearish body, lower wick ≥ 1.65 × body, near upper field, close position ≤ 0.55. Morning star: bearish body two bars earlier, middle bar body fraction ≤ 0.38, current bullish body, current close > midpoint of the first bar's open and close. Evening star: bullish body two bars earlier, middle bar body fraction ≤ 0.38, current bearish body, current close < that midpoint. Piercing: prior bearish body, current bullish body, current open < prior close, current close > prior-body midpoint and < prior open. Dark cloud: prior bullish body, current bearish body, current open > prior close, current close < prior-body midpoint and > prior open. Bullish/bearish harami: prior opposite-color body, current body contained within prior bar's high-low range, and current close respectively > or < prior open. Inside break up/down: prior bar is inside the bar two bars earlier, and current close > prior high or < prior low, respectively. Bullish/bearish marubozu: matching body direction, body fraction ≥ 0.78, close position ≥ 0.82 or ≤ 0.18 respectively, and direction-opposite wick ≤ 0.12 × range. Three soldiers/crows: three consecutive bullish/bearish bodies, closes strictly rising/falling, current body fraction ≥ 0.45. Tweezer low/high: current and prior lows/highs differ by ≤ 0.12 × ATR, prior body is bearish/bullish respectively, current body is bullish/bearish respectively, and close position ≥ 0.62/≤ 0.38 respectively. Rail bull/bear: prior body bearish/bullish, current body bullish/bearish, current body fraction ≥ 0.5, body sizes differ by ≤ 0.28 × ATR, and current close > prior high/< prior low respectively. Reclaim bull: current low < latest pivot low, close > that pivot low, and bullish wick rejection. Reject bear: current high > latest pivot high, close < that pivot high, and bearish wick rejection.
Calculation: Candidate score = base score + (13 if trend state matches candidate direction, 5 if neutral, otherwise −11) + (13 if location matches) + (17 × structure weight if structure matches) + (8 if momentum matches, otherwise −2) + (7 if volume expansion) + (7 if wick match) + clamp(|regression slope| / ATR × 100, 0, 9). Structure match means a break in candidate direction; reclaim bull and reject bear always match structure and location. Wick match is wick rejection for engulfing, hammer/star, morning/evening star, piercing/dark cloud, harami, and tweezers; it is true for hammer, inverted hammer, shooting star, hanging man, reclaim, and reject. For inside break, marubozu, three-soldier/crow, and rail candidates, wick match means strong body. Base scores: engulfing 52; hammer/shooting star 48; inverted hammer/hanging man 43; morning/evening star 57; piercing/dark cloud 50; harami 42; inside break 49; marubozu 47; soldiers/crows 55; tweezers 45; rail 51; reclaim/reject 58. Rank all candidates in this order: bullish engulfing, bearish engulfing, hammer, inverted hammer, shooting star, hanging man, morning star, evening star, piercing, dark cloud, bullish harami, bearish harami, inside break up, inside break down, bullish marubozu, bearish marubozu, three soldiers, three crows, tweezer low, tweezer high, rail bull, rail bear, reclaim bull, reject bear. Select the strictly highest score above zero; ties retain the earlier candidate.
Calculation: Signal eligibility = completed chart-timeframe bar AND (no prior accepted signal OR current bar index − last accepted signal bar index > cooldown bars) AND highest candidate score ≥ minimum accepted score. Update the last accepted signal bar when eligible.
Long: Signal eligibility AND highest-scoring candidate is bullish.
Short: Signal eligibility AND highest-scoring candidate is bearish.
