Calculation: Intraday POC = (high + low + close) / 3 of the current session bar with the greatest volume so far
Long: close > any prior close from a higher-timeframe last completed bar OR close > Intraday POC, AND previous close <= that same level
Short: close < any prior close from a higher-timeframe last completed bar OR close < Intraday POC, AND previous close >= that same level
