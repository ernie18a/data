Calculation: Opening range high/low = highest high / lowest low during the active session opening range
Calculation: Opening range size = opening range high − opening range low
Calculation: Value area high = opening range high − a fraction of opening range size
Calculation: Value area low = opening range low + the same fraction of opening range size
Calculation: Long stop = opening range low; short stop = opening range high
Calculation: Long targets = entry price + opening range size multiplied by each of three increasing target fractions
Calculation: Short targets = entry price − opening range size multiplied by each of three increasing target fractions
Long: Opening range is complete AND close is above opening range high OR value area high for the configured number of consecutive bars
Short: Opening range is complete AND close is below opening range low OR value area low for the configured number of consecutive bars
Exit: Long, low ≤ long stop OR high ≥ any long target
Exit: Short, high ≥ short stop OR low ≤ any short target
