Calculation: Conversion line = midpoint of the highest high and lowest low over the shorter Ichimoku lookback.
Calculation: Base line = midpoint of the highest high and lowest low over the longer Ichimoku lookback.
Calculation: Leading span A = average of the Conversion and Base lines; Leading span B = midpoint of the highest high and lowest low over the longest Ichimoku lookback; cloud bounds = minimum and maximum of these spans, each shifted back by the displacement.
Calculation: Main trend = +1 when close is above the upper cloud bound, -1 when below the lower bound, otherwise retain the prior value.
Calculation: ATR tolerance = ATR times its multiplier when enabled, otherwise zero.
Calculation: Trend score = state initialized to 0. When main trend is +1, reset to 0 if the prior main trend was -1; if score < 4 and close is above the upper cloud, set it to 1 + (close > upper cloud bound from displacement bars earlier) + (Conversion >= Base AND either line is rising) + (Leading span A >= Leading span B); otherwise set it to 0 if Conversion < Base - ATR tolerance, and otherwise retain it. When main trend is -1, reset to 0 if the prior main trend was +1; if score > -4 and close is below the lower cloud, set it to -1 - (close < lower cloud bound from displacement bars earlier) - (Base >= Conversion AND either line is falling) - (Leading span A <= Leading span B); otherwise set it to 0 if Conversion > Base + ATR tolerance, and otherwise retain it.
Calculation: Fourth oscillator layer = first layer + the positive part of (close - upper cloud bound from displacement bars earlier) in an uptrend, or the negative part of (close - lower cloud bound from displacement bars earlier) in a downtrend; first layer = close - lower cloud bound in an uptrend, or close - upper cloud bound in a downtrend.
Long: Trend score = 4 AND previous trend score != 4 OR (trend score = 4 AND close > upper cloud bound AND previous close was inside the cloud).
Short: Trend score = -4 AND previous trend score != -4 OR (trend score = -4 AND close < lower cloud bound AND previous close was inside the cloud).
Exit: Long, previous trend score = 4 AND trend score != 4 OR (close > entry price AND (Base crosses above Conversion OR the EMA of the fourth oscillator layer crosses above the fourth oscillator layer)).
Exit: Short, previous trend score = -4 AND trend score != -4 OR (close < entry price AND (Conversion crosses above Base OR the fourth oscillator layer crosses above its EMA)).
