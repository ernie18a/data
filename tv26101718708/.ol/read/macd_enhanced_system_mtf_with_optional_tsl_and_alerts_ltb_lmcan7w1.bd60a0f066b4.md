Calculation: MACD = EMA(close, shorter lookback) − EMA(close, longer lookback); signal line = EMA(MACD, lookback); histogram = MACD − signal line
Calculation: MACD direction score = Add a positive direction weight plus a positive histogram weight when MACD and histogram both rise; add the direction weight when MACD rises and histogram is unchanged; add the direction weight minus the histogram weight when MACD rises and histogram falls. Apply the corresponding negative values when MACD falls, using the histogram’s direction in the same way. When MACD is unchanged, add the histogram weight if the histogram rises, subtract it if the histogram falls, or add zero if unchanged. Add the cross weight on a MACD crossover above the signal line, subtract it on a crossover below, and add 0.6 times the preceding bar’s cross contribution. Use the preceding bar’s direction score.
Calculation: Combined score = (higher-timeframe MACD direction score × higher-timeframe weight + chart-timeframe MACD direction score) / (higher-timeframe weight + 1); use the last completed bar for both timeframes, with the higher timeframe above the chart timeframe.
Long: Combined score[1] > 0 AND Combined score[2] < 0
Short: Combined score[1] < 0 AND Combined score[2] > 0
