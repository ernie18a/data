Calculation: Current regime = Assign Breakout if band-width ratio > breakout threshold AND volume-to-average-volume ratio > volume-spike threshold AND absolute rate of change > breakout threshold; otherwise assign Reversal if RSI is above its upper threshold or below its lower threshold AND the sign of rate of change differs from its value several bars earlier; otherwise assign Trending Up if ADX > trend threshold AND positive directional index > negative directional index AND structural slope > 0; otherwise assign Trending Down if ADX > trend threshold AND negative directional index > positive directional index AND structural slope < 0; otherwise assign Range if ADX < range threshold AND band-width ratio < range threshold; otherwise assign Range. Band-width ratio is current Bollinger Band width divided by its moving average over a longer lookback. Volume ratio is current volume divided by its moving average. Structural slope is the difference between the current linear regression value of close and its value at the oldest offset in the structural lookback; slope percentage is slope divided by close. Band-width ratio is current band width divided by its longer-lookback average. Use rate of change over a lookback and RSI, ADX, and directional indices over their configured lookbacks.
Calculation: Eight-feature vector = clamp each component to [-1, 1]: (ADX − trend reference) / trend scale; (positive DI − negative DI) / scale; (band-width ratio − 1) / scale; (RSI − midpoint) / scale; log(volume ratio) / scale; slope percentage / scale; 2 × ((close − lowest low in structural lookback) / (highest high − lowest low in that lookback) − 0.5); rate of change / scale. Use 0.5 for range position when highest high equals lowest low. The first six components are clamped; range position is not clamped.
Calculation: Predicted regime = Once at least the configured minimum number of examples is available, find the configured number of stored examples nearest to the current eight-feature vector, using the configured distance metric (Euclidean, Manhattan, or cosine distance). Each example is a confirmed historical vector paired with its regime at that bar; add examples to memory only after the configured forward-labeling delay, then discard oldest examples beyond the configured memory limit. Predict the regime with the greatest neighbor vote, using either equal votes or inverse-distance weights; resolve ties in favor of the lowest regime order: Trending Up, Trending Down, Range, Breakout, Reversal. Classify on confirmed bars.
