Calculation: Directional True Range = sign(close − open) × True Range, where True Range = max(high − low, abs(high − previous close), abs(low − previous close))
Calculation: Chart oscillator = the configured moving average of Directional True Range
Calculation: Medium and highest timeframe oscillators = Directional True Range on each progressively higher timeframe; use the last completed higher-timeframe bar by default, or the still-forming bar when higher-timeframe repainting is enabled
Calculation: Aggregate oscillator = the configured weighted average of the chart, medium-timeframe, and highest-timeframe oscillators
Calculation: Main line = the configured chart, medium-timeframe, highest-timeframe, or aggregate oscillator
Calculation: Divergence level = the main-line value saved on each bar when bar direction disagrees with the main line's direction (rising or falling versus up or down); an up bar has close > open, or close = open and close > previous close; a down bar has close < open, or close = open and close < previous close
Long: On transition into a bullish state, when every enabled condition is bullish and the configured volatility filter passes: main line > centerline; main line > prior-bar Donchian high of the main line; main line > divergence level; main line > medium-timeframe oscillator; main line > highest-timeframe oscillator; chart oscillator > medium-timeframe oscillator; chart oscillator > highest-timeframe oscillator; medium-timeframe oscillator > centerline; highest-timeframe oscillator > centerline. At least one condition must be enabled. The volatility filter is unrestricted, short-term ATR > long-term ATR, or short-term ATR ≤ long-term ATR, according to its configuration.
Short: On transition into a bearish state, when every enabled condition is bearish and the configured volatility filter passes: main line < centerline; main line < prior-bar Donchian low of the main line; main line < divergence level; main line < medium-timeframe oscillator; main line < highest-timeframe oscillator; chart oscillator < medium-timeframe oscillator; chart oscillator < highest-timeframe oscillator; medium-timeframe oscillator < centerline; highest-timeframe oscillator < centerline. At least one condition must be enabled. The volatility filter is unrestricted, short-term ATR > long-term ATR, or short-term ATR ≤ long-term ATR, according to its configuration.
