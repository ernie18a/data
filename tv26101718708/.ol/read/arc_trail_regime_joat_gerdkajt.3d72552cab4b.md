Calculation: Arc core = the 3-bar EMA of two identical EMAs of typical price (high + low + close)/3, using the same lookback.
Calculation: Active trail = initialize the regime as bullish when close ≥ arc core, otherwise bearish; set the trail to arc core − ATR × band width + max(arc-core change, 0) × (2 + volatility speed) when bullish, or arc core + ATR × band width + min(arc-core change, 0) × (2 + volatility speed) when bearish. On each later bar, flip bullish when the prior regime was bearish, close > prior trail, close ≥ VWAP, and arc core ≥ prior arc core; otherwise retain the bearish regime and set trail to the minimum of the short band and prior trail. Flip bearish when the prior regime was bullish, close < prior trail, close ≤ VWAP, and arc core ≤ prior arc core; otherwise retain the bullish regime and set trail to the maximum of the long band and prior trail. ATR is chart-timeframe ATR; volatility speed = clamp((EMA(ATR, 5)/EMA(ATR, 55) − 1) × speed boost, 0, 1.3); band width = clamp(base width × (1 − volatility speed × 0.22), base width × 0.55, base width × 1.25). Long band = arc core − ATR × band width + max(arc-core change, 0) × (2 + volatility speed); short band = arc core + ATR × band width + min(arc-core change, 0) × (2 + volatility speed).
Long: prior regime was bearish AND close > prior active trail AND close ≥ VWAP AND arc core ≥ prior arc core AND current chart bar is confirmed.
Short: prior regime was bullish AND close < prior active trail AND close ≤ VWAP AND arc core ≤ prior arc core AND current chart bar is confirmed.
