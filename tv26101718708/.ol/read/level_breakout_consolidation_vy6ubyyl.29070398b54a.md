Calculation: Daily pivot high = a high higher than the highs of the specified number of daily bars on each side; use the latest confirmed value from the higher timeframe, based on completed bars.
Calculation: Daily pivot low = a low lower than the lows of the specified number of daily bars on each side; use the latest confirmed value from the higher timeframe, based on completed bars.
Long: (close crosses above the latest daily pivot high AND exactly N chart bars have elapsed since that crossover without any intervening close below 0.999 × the current daily pivot high AND the N lows immediately before the crossover are strictly rising toward it AND the lowest close of the last N chart bars is above the current daily pivot high) OR (low < the latest daily pivot low AND open > the latest daily pivot low AND close > the latest daily pivot low)
Short: (close crosses below the latest daily pivot low AND exactly N chart bars have elapsed since that crossover without any intervening close above 1.001 × the current daily pivot low AND the N highs immediately before the crossover are strictly falling toward it AND the highest close of the last N chart bars is below the current daily pivot low) OR (high > the latest daily pivot high AND open < the latest daily pivot high AND close < the latest daily pivot high)
