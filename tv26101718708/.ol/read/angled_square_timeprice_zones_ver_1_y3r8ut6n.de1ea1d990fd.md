Calculation: Prior-day levels = Close, High, and Low from the daily bar that is at least one and otherwise ⌈configured base-cycle bars / bars per session⌉ completed daily bars before the current bar; the daily timeframe is higher than the chart timeframe and uses completed bars.
Calculation: Balanced swing = among local pivot-high/pivot-low pairs in the window starting at the bar of the selected prior-day Close and extending by the greater of the configured base-cycle length or one session, select the pair with the smallest absolute difference between (price range / first triple leg) / (bar separation, adjusted by configured swing scale) and (second triple leg / first triple leg); eligible pairs have at least half the configured base-cycle bar separation and at least half the window's high-low range. Recalculate when the selected prior-day Close changes or no swing is available.
Calculation: Square geometry = the swing end is the later pivot; square width is the pivot separation adjusted by configured swing scale. Square height is the swing price range divided by the first triple leg. Each block is second triple leg × square width bars wide and first triple leg × square height high, centered vertically on the selected prior-day Close. Within each block, the upper and lower boundaries are the configured square's upper and lower edges (diagonal for a diamond, flat for a rectangle); for a diamond each edge runs between the row midpoint at the block's time boundaries and the row's outer price boundary at the time midpoint.
Calculation: Active row = the row containing the close; change the active row only after the close has remained in a different row for two consecutive bars.
Calculation: Sync state = above when close is above the active row's upper edge, below when close is below its lower edge, and inside otherwise.
Calculation: Confluence filters = if enabled, require the bar to be within √block width bars of the block's time midpoint, and/or the current high to be within √block height of the upper edge or current low within √block height of the lower edge, and/or the close to be within √block height of the square centerline, prior-day High, or prior-day Low.
Long: Sync state changes from inside or below to above AND all enabled confluence filters pass.
Short: Sync state changes from inside or above to below AND all enabled confluence filters pass.
Long: Current bar high reaches or exceeds the current close's row upper edge AND close is below that edge AND all enabled confluence filters pass.
Short: Current bar low reaches or falls below the current close's row lower edge AND close is above that edge AND all enabled confluence filters pass.
Exit: Short, Sync state changes from below to inside or above AND all enabled confluence filters pass.
Exit: Long, Sync state changes from above to inside or below AND all enabled confluence filters pass.
