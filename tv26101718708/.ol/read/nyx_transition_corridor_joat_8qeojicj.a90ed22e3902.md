Calculation: Bull state = shorter-lookback EMA(close) > longer-lookback EMA(close) AND close > EMA(close) AND standardized log return > -0.25; bear state = shorter-lookback EMA(close) < longer-lookback EMA(close) AND close < EMA(close) AND standardized log return < 0.25; otherwise neutral. The standardized log return is the current log return minus its lookback mean, divided by its lookback standard deviation.
Calculation: Bull probability = rolling conditional frequency of the current state being bull given the preceding state; bear probability = rolling conditional frequency of the current state being bear given the preceding state. Use the same transition lookback for both. Select the relevant preceding-state conditionals for the current state; probability spread = absolute difference between bull and bear probabilities.
Calculation: Adaptive basis = recursively smoothed close, initialized with EMA(close); each bar's smoothing factor is clamp(0.08 + 0.32 × efficiency, 0.05, 0.45), where efficiency = clamp(abs(close − close at the efficiency lookback) / (mean absolute close change over that lookback × lookback), 0, 1).
Calculation: Upper rail = adaptive basis + corridor width; lower rail = adaptive basis − corridor width. Corridor width = ATR × (1.05 + volatility rank / 100) × (1.28 if state is neutral, otherwise 0.92) × (1 + abs(continuation probability − 50) / 140). Continuation probability is the transition probability of the current state persisting, as selected by the current state and preceding-state conditionals. Volatility rank is the percentile rank of ATR as a percentage of close over its lookback; use 50 when unavailable.
Calculation: Confirmed higher-timeframe EMA = EMA(close) on a higher timeframe, using the last completed higher-timeframe bar.
Long: bull state AND bull probability >= continuation threshold AND probability spread >= minimum spread AND close > confirmed higher-timeframe EMA AND close crosses above adaptive basis
Long: bull state AND bull probability >= continuation threshold AND probability spread >= minimum spread AND close > confirmed higher-timeframe EMA AND close > upper rail AND prior close <= prior upper rail
Short: bear state AND bear probability >= continuation threshold AND probability spread >= minimum spread AND close < confirmed higher-timeframe EMA AND close crosses below adaptive basis
Short: bear state AND bear probability >= continuation threshold AND probability spread >= minimum spread AND close < confirmed higher-timeframe EMA AND close < lower rail AND prior close >= prior lower rail
Exit: long, state is not bull OR close < lower rail OR bear probability > bull probability + minimum spread
Exit: short, state is not bear OR close > upper rail OR bull probability > bear probability + minimum spread
