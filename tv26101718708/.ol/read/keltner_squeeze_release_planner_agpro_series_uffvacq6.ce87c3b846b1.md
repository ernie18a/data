Calculation: Keltner upper/lower channel = EMA(close, basis length) plus/minus ATR times channel multiplier
Calculation: Channel width rank = 100 times (current channel width percentage minus its rolling low) divided by (rolling high minus rolling low), clamped to 0–100; channel width percentage = channel width / absolute EMA basis * 100; rolling low and high use the same lookback
Calculation: Release quality score = clamp(compression score + expansion score + close pressure score + candle body score + relative volume score + basis slope score, 0–100); compression score = clamp((squeeze threshold - channel width rank + 10)/(squeeze threshold + 10), 0–1)*24; expansion score = clamp((current channel width / prior-bar channel width - 1)/0.45, 0–1)*22; close pressure score = clamp((close's distance beyond the release-side channel edge / ATR)/0.75, 0–1)*22; candle body score = clamp((absolute close-open / high-low)/0.70, 0–1)*14; relative volume score = clamp((volume / its moving average)/1.6, 0–1)*10 when enabled, otherwise 7; basis slope score = clamp((absolute change in EMA basis over 3 bars / ATR), 0–1)*8
Long: the prior bar had at least the configured minimum consecutive bars with channel width rank at or below the squeeze threshold AND close > upper Keltner channel + ATR-based release buffer AND current channel width / prior-bar channel width >= required expansion ratio AND release quality score >= required ready score
Short: the prior bar had at least the configured minimum consecutive bars with channel width rank at or below the squeeze threshold AND close < lower Keltner channel - ATR-based release buffer AND current channel width / prior-bar channel width >= required expansion ratio AND release quality score >= required ready score
Exit: Long, an active bullish release is within its configured release window AND close < its frozen upper-channel release edge - release-bar ATR * failure buffer
Exit: Short, an active bearish release is within its configured release window AND close > its frozen lower-channel release edge + release-bar ATR * failure buffer
