Calculation: Cloud high/low = max/min of the fast EMA, smoothed linear regression of close, and AlphaTrend from two bars ago.
Calculation: Smoothed linear regression = EMA of linear regression of close at offset 0; its trend is rising/falling when it has risen/fallen on each of the last two bars.
Calculation: AlphaTrend = supertrend in either pivot-break mode; in Cloud-MA mode, if RSI is at least 50, use the prior AlphaTrend unless low minus ATR × multiplier is higher, otherwise use that value; if RSI is below 50, use the prior AlphaTrend unless high plus ATR × multiplier is lower, otherwise use that value.
Calculation: CloudMA = if Andean bull component exceeds bear component, use the greater of cloud low and prior CloudMA; if bear exceeds bull, use the lesser of cloud high and prior CloudMA; otherwise retain prior CloudMA. The bull and bear components are the square roots of the exponentially smoothed downside and upside price variances, respectively, using open and close.
Calculation: Cloud trend = positive when CloudMA has risen on each of the last two bars; negative when it has fallen on each of the last two bars; otherwise retain its prior value.
Calculation: Pivot top/bottom = latest confirmed pivot high/low, each requiring the configured number of bars on both sides.
Calculation: Long stop = lowest pivot bottom over the configured lookback; short stop = highest pivot top over that lookback. After a long trade's high exceeds its 1R level, set the long stop to entry price; after a short trade's low falls below its 1R level, set the short stop to entry price.
Calculation: Long profit targets = entry price plus the long entry-to-stop risk multiplied by each configured reward multiple; short profit targets = entry price minus the short stop-to-entry risk multiplied by each configured reward multiple.
Long: The applicable bullish entry condition changes state AND no long latch was active on the prior bar AND the configured time range applies. Bullish entry condition is: (pivot-break mode AND close > pivot top AND close > cloud high) OR (pivot-break plus trend filter mode AND close > pivot top AND close > cloud high AND smoothed linear regression is rising) OR (Cloud-MA mode AND cloud trend is positive AND close > cloud high). Entry is allowed when flat or short.
Short: The applicable bearish entry condition changes state AND no short latch was active on the prior bar AND the configured time range applies. Bearish entry condition is: (pivot-break mode AND close < pivot bottom AND close < cloud low) OR (pivot-break plus trend filter mode AND close < pivot bottom AND close < cloud low AND smoothed linear regression is falling) OR (Cloud-MA mode AND cloud trend is negative AND close < cloud low). Entry is allowed when flat or long.
Exit: Long, (pivot-break mode OR pivot-break plus trend filter mode) AND close < cloud low AND close < pivot bottom OR Cloud-MA mode AND cloud trend turns negative OR low crosses below the long stop OR price reaches either long profit target.
Exit: Short, (pivot-break mode OR pivot-break plus trend filter mode) AND close > cloud high AND close > pivot top OR Cloud-MA mode AND cloud trend turns positive OR high crosses above the short stop OR price reaches either short profit target.
