Calculation: Rolling volume profile = Divide the price range of the lookback bars ending at the pivot bar into rows; allocate each bar’s volume to each row in proportion to the overlap between the bar’s high-low range and that row. Estimate buying volume as allocated volume × (close − low) / (high − low), and selling volume as allocated volume minus buying volume; use a 50/50 split when high = low. The POC is the row with the greatest total volume.
Calculation: Confirmed pivot low/high = A low/high greater/less than the lows/highs of the selected number of bars on both sides; it becomes available after the right-side bars complete.
Calculation: Profile candidate node = The row center within the selected ATR search distance of the pivot that maximizes evidence: 50% node strength + 20% local peak quality + 20% directional volume + 10% proximity. Node strength is row volume / POC volume. Local peak quality is clip((row volume / max(mean adjacent-row volume, 1% of POC volume) − 0.85) / 0.65). Directional volume is buying / total volume for a support candidate, selling / total volume for a resistance candidate. Proximity is 1 − distance from pivot / search radius. Clip values to [0,1].
Calculation: Profile-confirmed level = Candidate qualifies when its node strength and evidence each meet their respective minimums. Pull the raw pivot toward the candidate node by profile pull × clip(evidence / 0.65). The final score is 100 × (50% evidence + 20% absorption + 15% pivot relative-volume score + 15% wick-rejection score). Absorption is the greatest, across bars within the selected radius of the pivot, of sqrt(small-body score × elevated-volume score); small-body score = clip((0.40 − body/range) / 0.40), elevated-volume score = clip((volume/recent average volume − 1) / (1.5 − 1)). Pivot relative-volume score = clip((pivot volume / recent average volume − 0.8) / (2.2 − 0.8)). Wick-rejection score = clip((support lower wick or resistance upper wick) / (0.50 × pivot bar range)). A zero pivot range uses the minimum price increment. Create the level only if its final score meets the minimum score.
Calculation: Active profile levels = Keep created support and resistance levels until broken. Merge a new level with the nearest active level of the same side within the merge ATR distance, replacing it only when the new score is greater; otherwise add it. If the active-level limit is exceeded, remove the lowest-scoring level. On each confirmed bar, remove support when close < level − ATR × break buffer, and remove resistance when close > level + ATR × break buffer.
Long: A profile-confirmed support level is created from a confirmed pivot low.
Short: A profile-confirmed resistance level is created from a confirmed pivot high.
Exit: Long, confirmed close < an active support level − ATR × break buffer.
Exit: Short, confirmed close > an active resistance level + ATR × break buffer.
