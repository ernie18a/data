Calculation: Fast Kalman trend state = a two-state local-linear-trend Kalman filter on log close, with measurement noise estimated as the rolling median of squared log returns and process noise scaled by that estimate; switch bearish when slope divided by its standard deviation falls below the negative hysteresis threshold, and bullish when it rises above the positive threshold.
Calculation: Fast Kalman flip levels = price levels at which the fast filter’s predicted slope t-statistic reaches the negative or positive hysteresis threshold, respectively; calculate on the higher trend timeframe while its bar is forming.
Calculation: Confirmed trend state = fast Kalman trend state from the last completed higher trend-timeframe bar.
Calculation: Regime gate = a separate two-state local-linear-trend Kalman filter on log close, using the same noise estimate and a separate process-noise parameter; its slope divided by its standard deviation is the gate value, calculated on the higher regime timeframe.
Calculation: Installed bull regime = gate exceeds its positive entry threshold to turn on, turns off when the gate falls below the negative exit threshold, and is active only after remaining on for the specified installation age; evaluate using the last completed higher regime-timeframe bar.
Calculation: Installed bear regime = gate falls below the negative entry threshold to turn on, turns off when the gate exceeds the positive exit threshold, and is active only after remaining on for the specified installation age; evaluate using the last completed higher regime-timeframe bar.
Calculation: Realtime trend state = chart-timeframe state that switches bearish when close falls below the lower fast Kalman flip level and bullish when close rises above the upper flip level.
Calculation: Slow Kalman level = predicted zero-slope price level from a second Kalman trend filter with a lower process-noise parameter than the fast filter; calculate on the higher trend timeframe while its bar is forming.
Calculation: Breather condition = chart-timeframe GMT hour is within the configured breather window, or elapsed time since the last realtime trend-state flip is within the configured fresh-leg duration, or (close minus the trend curve, where the curve is the lower flip level when confirmed trend is bullish and the upper flip level when bearish) divided by the higher trend-timeframe 24-bar SMA of absolute close changes is below the negative free-fall threshold.
Long: installed bull regime OR (realtime trend state is bullish AND close > slow Kalman level) OR realtime trend state changes bearish to bullish OR confirmed trend state changes bearish to bullish OR installed bull regime turns on while confirmed trend state is bullish
Short: installed bear regime OR (realtime trend state is bearish AND breather condition) OR realtime trend state changes bullish to bearish OR confirmed trend state changes bullish to bearish OR installed bear regime turns on while confirmed trend state is bearish
