Calculation: Eligible gap = on the first regular-session bar, valid OHLC and positive volume, a prior regular-session close exists, the preceding chart-bar baseline is fully valid, and |open − prior regular-session close| ≥ minimum gap size × ATR from the preceding chart bar.
Calculation: Gap direction = +1 when the eligible opening gap is up; −1 when it is down. Freeze the prior regular-session close as anchor, the absolute opening gap as gap size, and the preceding chart-bar ATR and median volume as event references.
Calculation: Gap retention = gap direction × (close − anchor) / gap size; close fill = clip(1 − gap retention, 0, 1); gap position = clip(2 × gap retention − 1, −1, 1).
Calculation: Recent flow = [sum of gap-direction-adjusted close changes over the latest event bars, including the current bar, divided by the sum of their absolute changes] × min(sqrt(mean capped relative volume), 1). Relative volume = clip(volume / frozen median volume, 0, 4). Use a rolling event-bar lookback; start changes from the event open and thereafter from the prior event close.
Calculation: Continuation candidate = eligible active event, regular session, valid OHLC and positive volume, no range touch of the anchor, mean capped relative volume ≥ minimum participation, gap position ≥ 0.20, and recent flow ≥ flow-entry threshold.
Calculation: Repair candidate = eligible active event, regular session, valid OHLC and positive volume, no range touch of the anchor, mean capped relative volume ≥ minimum participation, close fill ≥ 0.20, and recent flow ≤ −flow-entry threshold.
Calculation: Keep-continuation candidate = current confirmed state is continuation, gap position ≥ 0, recent flow ≥ flow-entry threshold × release fraction, and mean capped relative volume ≥ 0.75 × minimum participation.
Calculation: Keep-repair candidate = current confirmed state is repair, close fill ≥ 0.10, recent flow ≤ −flow-entry threshold × release fraction, and mean capped relative volume ≥ 0.75 × minimum participation.
Calculation: Confirmed continuation or repair = the corresponding candidate (entry or keep candidate) is the desired state on the required number of consecutive event-bar closes, and the confirmed state changes to that state. A range touch ends the event before state confirmation. Reset the candidate count when the desired state equals the confirmed state; otherwise count consecutive closes with the same desired state.
Long: (gap direction = +1 AND confirmed continuation) OR (gap direction = −1 AND confirmed repair)
Short: (gap direction = −1 AND confirmed continuation) OR (gap direction = +1 AND confirmed repair)
