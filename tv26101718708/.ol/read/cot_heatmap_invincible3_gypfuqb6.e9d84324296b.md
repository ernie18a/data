Calculation: Participant net position = participant long contracts − participant short contracts
Calculation: Positioning difference = selected participant net position − other participant group net position
Calculation: Stochastic positioning score = 100 × (current value − lowest value over a lookback) / (highest value over that lookback − lowest value over that lookback); use 50 when the range is zero. Calculate this for positioning difference using short, medium, and long lookbacks, and for selected participant net position using shorter and longer lookbacks.
Calculation: Market-bias axis = stochastic positioning score for Commercial data; 100 − stochastic positioning score for Non-Commercial data
Calculation: Composite market-bias score = weighted average of the market-bias-axis scores for the three positioning-difference lookbacks and the two net-position lookbacks, with greater weight on longer lookbacks
Calculation: Market-bias flow = change in Commercial net position from the prior completed higher-timeframe COT bar; for Non-Commercial data, use the negative of that change. Use the current higher-timeframe COT bar while it is forming.
Long: Composite market-bias score ≥ upper extreme threshold AND previous completed higher-timeframe score < upper extreme threshold OR composite market-bias score ≥ upper extreme threshold AND previous completed higher-timeframe score ≥ upper extreme threshold AND current score has fallen from the previous score by more than a reversal threshold OR composite market-bias score ≥ bullish threshold AND market-bias flow ≥ 0
Short: Composite market-bias score ≤ lower extreme threshold AND previous completed higher-timeframe score > lower extreme threshold OR composite market-bias score ≤ lower extreme threshold AND previous completed higher-timeframe score ≤ lower extreme threshold AND current score has risen from the previous score by more than a reversal threshold OR composite market-bias score ≤ bearish threshold AND market-bias flow ≤ 0
Exit: Long, composite market-bias score ≥ bullish threshold AND market-bias flow < 0 AND NOT (composite market-bias score ≥ upper extreme threshold AND previous completed higher-timeframe score ≥ upper extreme threshold AND current score has fallen from the previous score by more than a reversal threshold)
Exit: Short, composite market-bias score ≤ bearish threshold AND market-bias flow > 0 AND NOT (composite market-bias score ≤ lower extreme threshold AND previous completed higher-timeframe score ≤ lower extreme threshold AND current score has risen from the previous score by more than a reversal threshold)
