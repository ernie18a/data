Calculation: Volume average = rolling mean of volume over the configurable lookback, on chart bars.
Calculation: Volume shelf = confirmed pivot highs and lows, each requiring the configured number of chart bars on both sides. For each pivot, add a shelf or merge it with the first existing shelf within clustering-distance × chart-bar ATR; on merge, update price as the touches-weighted mean and add one touch. Add 1.7 strength if pivot-bar volume ≥ volume average × volume filter, otherwise add 1; initialize new shelves with one touch and the same strength rule. Remove shelves whose latest pivot is older than the lookback, or whose touches are below minimum after one-third of the lookback.
Calculation: Reaction state = on each confirmed chart bar, set buffer = chart-bar ATR × reaction sensitivity and consider the shelf intersected when low ≤ shelf price + 0.25 × buffer and high ≥ shelf price − 0.25 × buffer. If the prior close was above the shelf: on intersection, state is HELD if close ≥ price + buffer, LOST if close < price − buffer, otherwise TOUCH; without intersection, state is LOST if close < price − buffer. If the prior close was below: on intersection, state is REJECT if close ≤ price − buffer, RECLAIM if close > price + buffer and shelf is reused, LOST if close > price + buffer and shelf is fresh, otherwise TOUCH; without intersection, state is RECLAIM if close > price + buffer and shelf is reused, or LOST if close > price + buffer and shelf is fresh. Otherwise retain the prior state. A shelf becomes reused after RECLAIM or LOST.
Long: The strongest shelf by strength among eligible shelves (touches ≥ minimum; exclude reused shelves when fresh-only is enabled) changes state to HELD or RECLAIM on this confirmed bar, and the reaction-tag cooldown has elapsed.
Short: The strongest shelf by strength among eligible shelves (touches ≥ minimum; exclude reused shelves when fresh-only is enabled) changes state to REJECT or LOST on this confirmed bar, and the reaction-tag cooldown has elapsed.
