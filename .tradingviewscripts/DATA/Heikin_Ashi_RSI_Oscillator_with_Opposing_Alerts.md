# Heikin Ashi RSI Oscillator with Opposing Alerts

Source: https://www.tradingview.com/script/hCGw8hla-Heikin-Ashi-RSI-Oscillator-with-Opposing-Alerts/

## Description

Heikin Ashi RSI Indicator

The Heikin Ashi RSI Indicator combines price action with a Heikin Ashi RSI oscillator to highlight potential fake pullbacks within an established trend.

The indicator compares the direction of the normal price candle with the direction of the Heikin Ashi candle inside the RSI oscillator.

When both candles move in the same direction, momentum is aligned. When they oppose one another, the signal is classed as an Imposter.

An diversion appears when:

The price candle closes bearish, but the HARSI candle closes bullish.
The price candle closes bullish, but the HARSI candle closes bearish.

This difference suggests that the visible price move may not reflect the underlying momentum. When it occurs during a clear trend, the opposing price candle can be considered a potential fake pullback, rather than an immediate trend reversal.

The indicator includes chart markers and alert conditions for both types of candles.

Trend rules

signals should only be considered in the direction of the established trend.

Bullish trend

The RSI line is above the Heikin Ashi RSI candles.

In a bullish trend, focus on bearish price candles that close against bullish HARSI candles. These may represent fake bearish pullbacks before the upward trend continues.

Bearish trend

The RSI line is below the Heikin Ashi RSI candles.

In a bearish trend, focus on bullish price candles that close against bearish HARSI candles. These may represent fake bullish pullbacks before the downward trend continues.

Suggested use

The indicator is best suited to the:

30-minute timeframe
1-hour timeframe

For cleaner signals, allow the candle to close before acting and set TradingView alerts to Once Per Bar Close.

This indicator should be used as a confirmation tool rather than a standalone entry system. Always assess the wider market structure, trend direction, support and resistance, and your own risk-management rules before taking a trade.

// Zero-median RSI.
// Standard RSI values range from 0 to 100.
// Subtracting 50 centres the oscillator around zero.

f_zrsi(float sourceValue, int lengthValue) =>
    ta.rsi(sourceValue, lengthValue) - 50.0

// Zero-median stochastic calculation with user-selected scaling.

f_zstoch(
     float sourceValue,
     int lengthValue,
     int smoothValue,
     int scaleValue
 ) =>
    float zStoch = ta.stoch(
         sourceValue,
         sourceValue,
         sourceValue,
         lengthValue
     ) - 50.0

    float smoothedStoch = ta.sma(zStoch, smoothValue)
    float scaledStoch = (smoothedStoch / 100.0) * scaleValue

    scaledStoch

// Standard or smoothed zero-median RSI.

f_rsi(
     float sourceValue,
     int lengthValue,
     bool smoothMode
 ) =>
    float zeroRSI = f_zrsi(sourceValue, lengthValue)

    var float smoothedRSI = na

    smoothedRSI := na(smoothedRSI[1]) ?
         zeroRSI :
         (smoothedRSI[1] + zeroRSI) / 2.0

    smoothMode ? smoothedRSI : zeroRSI

// RSI-based Heikin Ashi candle calculation.

f_rsiHeikinAshi(int lengthValue) =>
    float closeRSI = f_zrsi(close, lengthValue)
    float openRSI = nz(closeRSI[1], closeRSI)

    float highRSIRaw = f_zrsi(high, lengthValue)
    float lowRSIRaw = f_zrsi(low, lengthValue)

    float highRSI = math.max(highRSIRaw, lowRSIRaw)
    float lowRSI = math.min(highRSIRaw, lowRSIRaw)

    float haClose = (
         openRSI +
         highRSI +
         lowRSI +
         closeRSI
     ) / 4.0

    var float haOpen = na

    haOpen := na(haOpen[i_smoothing]) ?
         (openRSI + closeRSI) / 2.0 :
         (
              (haOpen[1] * i_smoothing) +
              haClose[1]
         ) / (i_smoothing + 1.0)

    float haHigh = math.max(
         highRSI,
         math.max(haOpen, haClose)
    )

    float haLow = math.min(
         lowRSI,
         math.min(haOpen, haClose)
    )

    [haOpen, haHigh, haLow, haClose]

float RSI = f_rsi(
     i_source,
     i_lenRSI,
     i_mode
)

     i_stochFit

     i_smoothD
)

// Retrieve HARSI candle values.

[O, H, L, C] = f_rsiHeikinAshi(i_lenHARSI)

//=============================================================================
// CANDLE DIRECTION CONDITIONS
//=============================================================================

// HARSI oscillator candle direction.

bool harsiBullish = C > O
bool harsiBearish = C < O
bool harsiDoji = C == O

// Standard price candle direction.

bool chartBullish = close > open
bool chartBearish = close < open
bool chartDoji = close == open

// Confirm the signal at candle close when that option is enabled.

bool candleConfirmed = not i_alertOnClose or barstate.isconfirmed

// Direction filter selections.

bool allowBearishPriceBullishHARSI =
     i_alertDirection == "Both" or
     i_alertDirection == "Bearish Price / Bullish HARSI"

bool allowBullishPriceBearishHARSI =
     i_alertDirection == "Both" or
     i_alertDirection == "Bullish Price / Bearish HARSI"

// Red price candle with bullish HARSI candle.

bool bearishChartBullishHARSI =
     i_enableAlerts and
     candleConfirmed and
     allowBearishPriceBullishHARSI and
     chartBearish and
     harsiBullish

// Green price candle with bearish HARSI candle.

bool bullishChartBearishHARSI =
     i_enableAlerts and
     candleConfirmed and
     allowBullishPriceBearishHARSI and
     chartBullish and
     harsiBearish

// Combined opposing-candle condition.

bool anyOpposingCandle =
     bearishChartBullishHARSI or
     bullishChartBearishHARSI
